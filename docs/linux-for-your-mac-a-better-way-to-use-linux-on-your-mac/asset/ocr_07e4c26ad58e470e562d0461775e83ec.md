# ## Stopping an X11 Session

To stop an X session, use the window manager's logout menu. This can be accessed through a start menu, root display menu, or in the case of KDE or GNOME, through the desktop panel. You can also use a keyboard combination to kill the running X server if your XFree86 configuration file, `XF86Config`, contains the following:

```
```
# Uncomment this to disable the <Ctrl><Alt><B8> server abort sequence
# This allows clients to receive this key event.
#DontZap
```
```

To not allow users to kill an X session by using Ctrl+Alt+Delete (the Backspace key, and not the three-fingered salute, Ctrl+Alt+Del), remove the comment (pound sign) in front of `DontZap`. Under XFree86 4.0 and greater, this option is off by default, but may be placed under the `serverFlag` section. It looks like this:

```
```
Option    "DontZap"
