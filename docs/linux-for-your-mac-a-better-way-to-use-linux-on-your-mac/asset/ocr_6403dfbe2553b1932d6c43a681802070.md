# # Using nedit

The nedit text editor is a graphical client for X11. This program has nearly every feature a system administrator, writer, or programmer desires in a text editor. Included with many Linux distributions, nedit provides extensive menus, line-number display, import and export of DOS-format text files, handling of international character sets, macros (compressed procedural shortcuts), sorting, electronic mail handling, programming environment features, and more.

You can start nedit from the command line with an optional text filename like this:

```
```bash
$ nedit linumpr.txt &
```
```
