Table 14.1 Linux User Commands
| Command | Description |
| --- | --- |
| ac | Show users' connect time |
| adduser | Symbolic link to useradd |
| alter_user | Change user account information |
| autolog | Log out idle users |
| chage | Set user password expiration |
| crontab | Maintain a user's crontab file |
| edquota | Change or edit user quotas |
| finger | User information lookup program |
| ftpw ho | Show current ftp user process |
| last | Print a list of last logged in users |
| loginame | Show a user's login name |
| newusers | Use a batch file to updates and create new users in batch |
| nologin | Do not allow non-root users to log in |
| passwd | Change a user's password |
| su | Execute command as root or another user |
| su1 | Execute one command as root operator |
| userdel | Remove a user account and related files |
| usermod | Change a user account |
| userpasswd | GUI tool to allow password changes |
| users | Show currently logged in users |
| who | Display logged in users |
| whoami | Display user ID |

```
luser:x:501:100::/home/luser:/usr/bin/emacs
```
