
## Installation and Partitioning

You are first asked to select a language. Select your language, and click the Next button. The next dialog box asks you to select your time zone and keyboard. Click to select your keyboard and time zone, and then press the Next button.

The main install dialog box appears and asks if you want to perform a new installation or update an existing system. Choose the New install, and then click Next to continue. You are asked to choose your hard drive. Click the Custom partitioning and click Next.

You see a list of your partitions. Click on the root Linux partition, and then click the Edit button. In the next dialog box, type a forward slash (/) in the Mount point field, and then select the Format with Ext2 button. Press Enter when finished.

When you return to the partition list, click to select your Swap partition, and then click the Edit button. In the next dialog box, select the Format with Swap button, and then press Enter when finished. You return to your partition list. Click the Next button.

## Software and Kernel Selection

The yast2 installer presents a dialog box that asks you to select software and a kernel. Your initial software choices are:

- All packages. This can take several hours and requires 6GB hard drive space.
- Minimal. This installation requires about 150MB hard drive space.
- Default. A default installation requires nearly 1GB of hard drive space. This is generally a good choice for getting started when first using Linux.

You can also choose to make your own software selections if you click the Detailed selection button.

You should also choose a Linux kernel. You can install a 2.2.18 or Linux 2.4-series kernel on your computer. If you use quite a few USB devices with your system, choose the 2.2.18 kernel, as it provides better USB support right now. If you want to use a cutting-edge kernel with support for newer graphics cards, larger files and greater amounts of memory, choose the 2.4 kernel. Click the Next button after making your choice.

## User Creation and Finalization

The next dialog box asks you to create a user for your system. Enter your first name, last name, username (such as "smith"), and password (twice). Click the Next button when finished. The next dialog box asks for the root password. Enter it twice and do not forget it! Press Enter, and then press Enter again, and yet again to confirm the start of the installation. Go have a soft drink while the software installs.

After installation, a dialog box appears. Press Enter to reboot your system. If you perform a default or large install, you are asked to insert a new CD. After the software installs, SuSE Linux runs a configuration script that can take some time to configure software and files on your system (possibly several minutes). You are asked if you want to view the installation log. Click No to continue. You are asked if you want to configure a printer, sound, or modem (all these may be configured after installation if you wish).

When finished, click the Finish installation button. A dialog box appears. Click the OK button.

You now reboot directly to SuSE Linux. You should configure the LILO bootloader. At the command line, open the file /etc/lilo.conf using the pico editor, like this:

```
# pico -w /etc/lilo.conf
```

> The version of lilo installed with PPC Linux is vastly different than the lilo distributed with Intel-based Linux distributions. The PPC lilo creates and modifies Apple Open Firmware scripts for booting.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_54_0.png)

After you press Enter, scroll through the file and look for the following entries:

- boot=
- default=
- root=
- other=

Edit these entries to point to your HFS boot partition, the default Linux kernel, the root Linux partition, and the partition used by Mac OS:

- boot= /dev/hda9
- default= linux
- root= /dev/hda10
- other= /dev/hda8

After making these changes, run the lilo command:

```
# lilo
```

Next, use the shutdown command at the command line of a terminal window to reboot:

```
# shutdown -r now
```

After you press Enter, Linux reboots to Mac OS. To configure your computer to boot Linux, insert CD-ROM 1, and drag a copy of the suseboot folder to your 32MB HFS volume. Open the folder on the HFS volume, and then click the file yaboot.conf to edit it with SimpleText. Look for:

```
...
default = install
...
```

Change this entry to point to the kernel you selected during your Linux install. Use linux22 if you selected the 2.2.18 Linux kernel, or linux if you selected the 2.4 kernel, like this:

```
...
default = linux
...
```

This example shows that Linux is to be booted using the 2.4 kernel. Scroll down the file, and then look for the linux entry. Insert the following line, using the partition number of your root Linux partition:

```
image=vmLinux-2.4
label=linux
root = /dev/hda10
```

Save the file and exit SimpleText. Next, click the file named os-chooser.example, and then save it as os-chooser. Before exiting, edit this file to insert the partition numbers of your Mac OS partition and root Linux partition, like this.

```
"Booting MacOS ..." cr "boot ultra08:\\tbxl" eval
else
"Booting Yaboot ..." cr "boot ultra09:\\yaboot" eval
```

These entries designate that Mac OS resides on the first IDE drive (ultra0) in the eighth partition (8). The second entry points to the Yaboot loader, which resides on the HFS boot partition (/dev/hda9).

Now open the Tools folder and run the script named make-os-chooser-bootable. In the resulting dialog box click the Change it! boxi button. The Startup Disk control panel appears. Click to select the boot partition in the Startup Disk dialog box. You can then choose Restart from the Special menu to boot Linux. When you reboot, you should be able to hold down the Option key to boot to Mac OS or Linux through a graphical chooser.

## Logging in and Out

Always log in as a regular user. You should never have to log in as the root operator except during installation or system recovery!

## Shutting down and Rebooting

If you boot Linux directly to an X session, and log in via a graphic dialog box, use the shutdown or system button to shut down or reboot your computer. If you use Linux without its graphical interface, the *shutdown* command should always be used to shut down or reboot Linux. To shut down a current session immediately, use the *shutdown* command, like this:

```
shutdown -h now
```

After you press Enter, the session halts immediately by first turning off processes, and then unmounting any mounted volume. If automated power management is properly enabled, your Power Mac should also turn off.

Also use the *shutdown* command to reboot your system. To reboot right away, use the *shutdown* command, like this:

```
shutdown -r now
```

After you press Enter, the session halts, and the system reboots by first turning off processes, and then unmounting any mounted volume. It is critical that this process is followed, as data corruption or filesystem corruption may occur if the system is improperly halted. Although you will not damage your computer, you are taking chances on having to perform a reinstallation if you simply turn off the computer. Linux has built-in filesystem checking during the boot process, so if you do lose power or turn off the system, all known Linux partitions are rechecked the next time you boot.
