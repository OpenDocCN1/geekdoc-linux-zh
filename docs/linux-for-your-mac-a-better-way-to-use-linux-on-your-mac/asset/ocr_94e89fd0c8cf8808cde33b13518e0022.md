The program works by querying known dictionary databases on remote servers. Another client that works the same way, and that is included with many Linux distributions is *gdict*, a GNOME client that also performs lookups. Launch *gdict* from the GNOME panel or the command-line of an X terminal window like this:

```
$ *gdict*
```

The *gdict* entry field will appear in your GNOME desktop panel. You can then type an entry in the field. After you press Enter, if the definition is found, it will appear in a window as shown in Figure 6.12.
