# # GNOME Clients for the Network and Internet

Like KDE, GNOME comes with a number of network- and Internet-related utilities, and you will find many additional GNOME-aware clients available over the Internet. This section introduces some of the more popular utilities you can use for system monitoring, transfer of files, and electronic mail.

# ## Network Clients

This section introduces two convenient network clients you use with GNOME during X sessions. If you would like to keep track of your system, you will find that these clients can help you with information about your computer.

To get detailed information about your computer, similar to Apple’s System Profiler, use GNOME’s System Info client. This client provides a quick way to get summary information about the current version of Linux in use, and detailed information about your system’s disk, memory, and CPU.

Launch this client by using the desktop panel’s menu. You will initially see a dialog box, as shown in Figure 11.7.
