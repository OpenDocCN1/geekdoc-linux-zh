# Linux and the PowerPC

Thanks to corporate and individual efforts, you can now enjoy Linux on the Apple PowerPC platform. Early Mac adopters know that the first Macs used the Motorola 68000-series CPUs. The first Linux port for computers running these CPUs were not created for Macs however, but for the Amiga (from Commodore) and the Atari ST in 1994. The development of these platforms continues, with better support for those machines than for the early Apple Macintosh line of computers. Two other Open Source ports, NetBSD and OpenBSD, were the first to bring UNIX to the M68K line of Macs. The Linux/m68K Project now provides Linux for those CPUs, but only for machines with a MMU (*Memory Management Unit*).

The PowerPC CPU was first introduced in 1992, and uses a radically different internal architecture than M68K or Intel-based CPUs. A number of Apple Macintosh models quickly followed. The advent of the PowerPC line of Macintosh computers brought USB peripherals, IDE hard drives, and AGP and PCI video cards, which replaced earlier ADB, SCSI, and NuBus equipment.

In 1994, a programmer named Gary Thomas started work on porting Linux to the PowerPC chip. Thomas’ work was followed closely by Joseph Brothies and Cort Dougan who created the first Linux software to run on the new chip (kernel version 1.2). It was up and running the next year. At about the same time in 1995, the Open Group (then known as OS/F, or the Open Software Foundation) and Apple started the MkLinux project, which was created to develop a version of Linux that would use the Carnegie-Mellon University’s Mach kernel. The first version, DR1, was released in 1996. That same year, Yance Morotola created Linux PPC, which could boot Linux on many non-Apple PowerPC computers.

A third version of Linux by Paul MacKerras, termed Linux-ppc, was then introduced. This version had the advantage of supporting the newer Apple PowerPC computers. Despite two successful releases, Apple dropped support of MkLinux within two years, and in 1998 turned development efforts over to MkLinux users.

During this period, LinuxPPC and Linux-pmac commingled features and source code, creating a single PowerPC Linux kernel source. At about the same time in 1998, LinuxPPC released its first distribution, which used a modified Red Hat installer. Following the efforts of Mark Hatle, further refinements were made to the LinuxPPC distribution, and an attempt was made to roll in the best code from existing distributions.

Efforts by incredible LinuxPPC programmers, such as Benjamin Herrenschmidt, helped introduce additional tools. These tools include the BootX control panel for booting Linux from Mac OS, and the MountX control panel for mounting Linux native ext2 filesystems on the Mac OS Desktop (you can also mount Apple HFS volumes when using Linux—support for HFS+ is due at the time of this writing).

At this point, the 2.4-series of the Linux kernel (with the official blessing of Linus) for the PowerPC closely tracks the development of Linux on other platforms. When you install Linux for the PowerPC, you are not installing old or outdated software. Because of refinements to the Linux kernel, the efforts of PowerPC Linux kernel hackers, and portability of software, Linux users encounter a familiar experience across product lines, platforms, and even distributions. Nearly all code in a Linux kernel source distribution is shared between platforms.

## Choosing a PPC Linux Distribution

The work of the Open Source community, Linux distributors, and the efforts of PowerPC Linux programmers have enabled you to have a choice of Linux distributions to use on your Apple PowerPC. This was not true less than two years ago! PowerPC Linux users now have the same choice of Linux users operating Intel-based PCs.

Before jumping into this subject, keep in mind that all Linux distributions are really the same; they all use the Linux kernel. Linux distributions are different in their methods of installation, software installation tools, administrative tools, and value-added software included with the distribution. The following is a quick run-down of your choices at the time of this writing:

- [http://www.linuxppc.com](http://www.linuxppc.com). LinuxPPC 2000 Q4 is the latest release from the folks who brought you the first bootable CD-ROM. This release features a new installer, commercial Mac OS disk partitioning software, the ability to boot to the install from the hard disk, the latest GNOME desktop software from Ximian, Mac-on-Linux Mac OS software emulation, and Red Hat Linux package management. This distribution (one or more CD-ROMs) is available for purchase with or without printed documentation.
- http://www.yellowdoglinux.com. Yellow Dog Linux 2.0 is the current release of Linux for the PowerPC from Terra Soft Solutions, Inc. Earlier versions of this distribution of Linux closely resembled the Intel-based Red Hat Linux distribution, and features many familiar administrative and management tools, such as printtool, timedtool, rpm, netcfg, etc. If you are familiar with Red Hat Linux on Intel-based PCs, you will feel right at home after installing YDL. This distribution includes three CD-ROMs and printed documentation.
- http://www.suse.com/us/products/susesoft/ppc/index.html. SuSE Linux 7.1 PPC for PowerPC-based computers provides SuSE's brand of Linux, along with five CD-ROMS of software. This is in keeping with SuSE's tradition of providing a nearly complete snapshot of every available software package that has been ported to a particular platform. The Intel-based SuSE Linux distribution is also available on DVD-ROM (a PPC version should appear soon). SuSE Linux provides a unique Linux experience, with nearly all of the administrative functions under the control of YaST (yet-another-setup-tool). This distribution also includes a 480-page book covering technical details.
- http://www.debian.org/ports/powerpc/. The PowerPC port of Debian GNU/Linux is one of a family of nearly one dozen different versions of Linux for different CPUs and computer platforms. Debian GNU/Linux is considered the "purest" Linux distribution, because the only software included with the distribution is distributed under the GNU GPL. This means you will not find shareware or crippled demo-ware versions of commercial software packages included with this distribution. You will only receive Linux and GPL software. This port of Linux was started in 1997, and closely resembles its Intel-based cousin, including software package management using .deb archives and the apt-get networking software installer. You can purchase a three CD-ROM set of CDs for the PowerPC from http://www.cheapybytes.com for a nominal fee; the Debian Linux maintainers do not sell CD-ROMs.
- http://www.rocklinux.org/. One of the newest ports of Linux for the PowerPC is Rock Linux, which provides a minimalist, but functional, Linux installation that uses a script-based installation rather than a network. You can find complete directions on how to install Rock Linux on your PowerPC box at: http://www.rocklinux.org/projects/doc/GUIDE/GUIDE.ext. The Rock Linux installer, a 1.5MB utility, is used to download the 300MB distribution, which consists of more than 200 software packages. Various CD-ROM sets are available for purchase (payment in Euros).

If you do not want to buy a boxed set of CD-ROMs from a PowerPC Linux vendor, you can download and create your own CD-ROMs, either from links via the vendor's Web page or through Linux CD-ROM image Web sites (i.e., http://www.linuxiso.org). Note that in some cases (i.e., when using LinuxPPC 2000) you will need to be able to create HFS formatted CD-ROMs, and/or be certain that the CD image is actually in the Mac OS Disk Copy image format. (This requires installation by booting from the current Startup Disk.)

Choosing a distribution to install can be a matter of personal preference, taste, economics, or bias. If you are an Intel-based PC user running a particular Linux distribution (i.e., SuSE), then choose a compatible PowerPC distribution. If you are completely new to Linux, each distribution has a lot to offer. The best way to choose a distribution is to read the comp.os.linux.powerpc Usenet newsgroup, and ask questions to determine which distribution works best with your computer.

# Choosing Workstation or Server

Before installing Linux, you will have to decide how you want to use Linux on your Mac. Installations vary according to the amount of hard drive space you want to devote to Linux and how you plan to use your computer. The good news is that with the advent of ever-larger hard drives complementing today's PCs, you should have plenty of room. If, however, you use PowerPC for video editing you may be limited in hard drive space, even with one or more 30GB drives. There should be plenty of extra storage, even on a primary drive, to install a full Linux system.

When you install Linux to operate as a server, you will not need to install as much software. Linux and its host of networking software require only several hundred megabytes. Unless you plan to host an active Web site or a farm of FTP servers with lots of software and documents, two gigabytes of hard drive space is more than adequate. On the other hand, if you want to use Linux as a development platform, or workstation, you will need extra storage for temporary disk space, software libraries, documentation, and programming tools. If you have the storage and want to learn Linux, go ahead and install everything. This will save you the effort of having to return to your Linux CD-ROM(s) to install extra software or search for needed packages.
