# # Working As root

Every Linux system should, at a minimum, have at least two users: the root opera- tor, more of a functional user than a regular user; and a traditional, or regular user with restricted permissions (The only exception might be for using Linux on an embedded device).

Working as root operator is potentially dangerous, because you have permission to do anything to the system. This includes running commands such as:

```
$ rm -rf /*
```

This handy command will not only wipe out your entire Linux filesystem, but also any remote filesystems that are currently mounted. Every user should at least use the following *alias*, or command shortcut for the *rm* command:

```
alias rm='rm -i'
```

This alias definition, which can be placed in a user's *.bashrc* file, or applied sys- tem-wide in */etc/profile* or */etc/profile.local*, can at least protect against accidental deletion of files. It will not, however, protect against the wholesale slau ghter of *rm*5 -fx* option.

Fortunately, many GNOME and KDE clients (and other administrative tools such as *yast2*) will recognize when root access is needed and will prompt for a password.
