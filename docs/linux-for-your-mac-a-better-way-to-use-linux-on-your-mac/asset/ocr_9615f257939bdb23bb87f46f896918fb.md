Another file that may be used for settings is a file named .profile, which is generally read when a user first logs in. In addition to locally configurable shell resource files, every Linux distribution also includes skeletal system-wide default shell settings, usually in a file under the /etc or /etc/skel directory. For some systems, this file is named profile. In other systems, such as SUSE, the default user settings are derived from a series of system configuration values in /etc/rc.config, then read in to create /etc/profile. In this case, according to SUSE, you should put custom system-wide changes (and custom aliases) into /etc/profile.local.
