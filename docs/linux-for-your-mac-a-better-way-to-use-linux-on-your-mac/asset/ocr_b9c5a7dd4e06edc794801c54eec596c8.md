with your IP address, you can substitute your system's hostname for the IP address. For example:

```
192.168.2.33  stinkypad.home.org  stinky
```

You can then use the abbreviated (alias) hostname, like this:

```
# ifconfig eth0 stinky up
```

After you press Enter, your Ethernet interface should be active. Next, edit your system's /etc/resolv.conf file to contain the one or two (most likely) DNS numbers:

```
nameserver 199.45.32.38
nameserver 199.45.32.43
```

Following this, you should then be able to add your LAN's gateway (as root) to your Linux kernel's routing table (which is contained in memory) by using the route command, like this:

```
# route add default gw yourgateway
```

In this example, yourgateway could be a hostname or IP address. The route command will then force your system to send and receive packets of information through the gateway computer.

Congratulations! You should now be able to check your Internet connection.

# Checking Mac Connectivity

Linux comes with hundreds of networking utilities, but most users employ the ping command to check network connectivity after connecting to a LAN and the Internet. This command may be employed by any user, and its reports on the time (in milliseconds) that it takes to echo a packet transmission from a remote computer. Use this command with the name of a known remote Internet host, like this:

```
# ping -c3 www.usu.com
PING www.usu.com (213.95.15.200): 56 data bytes
```
