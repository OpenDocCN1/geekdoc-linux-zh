As with other window managers, KDE uses the left mouse button to click, select, launch, drag, resize, or controls objects. Under KDE, when you click the right mouse button in a blank area of the desktop, you’ll see a short menu, as shown in Figure 10.3.

This menu is used to create new desktop items, jump to a bookmark, get help, configure the background or desktop, manage windows and icons, and lock or unlock the screen. The middle mouse button, if clicked in the root display, is used as a navigation tool, enabling you to jump to different windows or desktops.

Files, represented by icons, may be dragged to and from the root display or desktop. You can delete files by dragging them to your desktop’s Trash. Trash may be emptied by right-clicking the can, and selecting the Empty trash bin menu item.

Desktop files may be renamed, deleted, or copied by right-clicking and selecting the appropriate menu. If you select the Delete menu item, the file is sent to the Trash. If you select the Shred menu item, the file is deleted automatically. If the file’s icon is a CD-ROM, hard drive, or floppy you can mount or unmount the device by using the mount menu item (or unmount if the device is mounted).
