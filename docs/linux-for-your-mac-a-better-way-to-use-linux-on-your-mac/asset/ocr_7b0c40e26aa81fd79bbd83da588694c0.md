On one hand, Linux is the *kernel*, or core of the operating system. On the other hand, however, a *Linux distribution* is the kernel, along with thousands of specially chosen programs and a vendor-specific installation scheme or software installer. Therefore, it does not make sense to ask, “What is the best Linux to use?” Rather, one should ask, “What Linux distribution is right for me?” It is important to remember that all distributions are in essence the same; they all use a *Linux* kernel.

# **C’mon, Be Honest Here!**

Not all distributions are the same. They may use or include different or more than one Linux kernel. You will also discover that distributions will differ in the location and names of important files and directories. At the time of this writing, each Linux distribution for the PowerPC provides different methods and graphic clients for a number of administrative tasks. However, many major software packages are the same across distributions. You will generally find more commonality than disparity across distribution lines.

It is important to understand the difference between Linux and its graphical interface, which is provided by The XFree86 Project’s distribution of the X Window System. You can install and run Linux without a graphical interface, or the *X Window System*. A great percentage of computer servers running the Internet certainly do. When you use Linux without a graphical interface, you are using it in text-only, or *console* mode. This is how Linux started out. Many early users quite happily used the first Linux releases without a graphic interface for nearly a year until program-mers finally ported the X Window System and got it to run with Linux.

Another important distinction is that the graphical interface for Linux, XFree86, is a port of The X Window System. The X Window System, referred to as X11R6, X11, or more simply, X, is not Linux! X consists of thousands of files including fonts, graphics, and software libraries. It is a separate addition to your Linux distribution, but is not crucial to a successful Linux install. X is, however, critical to enjoying a graphical desktop environment and for some users it is even more important than support for sound.
