# Launching and Quitting a Terminal

To launch a terminal client, click the appropriate menu item from your window manager's desktop panel or root display menu. As you have seen, you can also arrange to have a terminal launch before your X session. Once the terminal has launched you can move your pointer to its window and start using the shell. Whether or not you have to click on the terminal window to make it active depends upon your window manager's current focus policy settings.

You can then use the shell to launch additional X clients, preferably in the background (as a process in memory), and then go back to work. This is accomplished by using the shell's background operator, the ampersand (&), to launch a new instance of the xterm terminal. It is done like this:

```
$ xterm &
```

This approach detaches the xterm process from your shell command line, and the new xterm will be displayed in its own window. This is how you can (and most often should) launch nearly all graphical clients during an X session.

Quitting a terminal session can be accomplished in a number of ways. If the GNOME or KDE terminal has a File menu, select the Quit menu item. You can also type exit at the terminal's command line to close the terminal session. If the window manager provides window decorations such as a close box, then click the box to destroy the window. Finally, you can also use the shell's kill command, along with a process ID number, to kill the terminal's process (This is a messy and inconvenient, but is often a necessary way to close a terminal).

# Selecting a Terminal

You'll find quite a few terminal clients included with PPC Linux. Some clients are part of the GNOME and KDE distributions, while others, such as xterm, are default terminals included with XFree86. Table 8.1 lists several X terminal clients included with most Linux distributions.

Some of the features to look for when choosing a terminal are the terminal's ability to handle scrolling, color, different fonts, emulate different terminal protocols, and perhaps the use of background images or a transparent background (to give the illusion of translucency).
