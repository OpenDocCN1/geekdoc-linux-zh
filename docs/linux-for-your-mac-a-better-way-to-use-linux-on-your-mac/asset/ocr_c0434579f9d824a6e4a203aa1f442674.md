After you press Enter, you will see its main dialog box, as shown in Figure 11.5. Click on a menu item on the left side of the window. You will then see a configuration dialog box on the right side. The stand-alone Enlightenment e-conf tool offers a number of major options:

+   - **Basic Options.** Window movement, resizing, and focus

+   - **Desktops.** The number of virtual desktops, size of the pager, and ability to navigate through desktops

+   - **Behavior.** Advanced focus settings, tooltip (balloon help) controls, and window placement

+   - **Audio.** Use of sounds for the Enlightenment session

+   - **Special FX.** Window drag appearances and window and menu animation controls

+   - **Backgrounds.** Backgrounds and color controls for the root display

+   - **Themes.** Theme chooser

+   - **Shortcuts.** Keyboard shortcuts for window control and workspace navigation

Like Sawfish, Enlightenment offers a series of shortcut keystrokes users can use instead of the mouse. The keystrokes are listed and controlled by e-conf's Shortcut dialog box.
