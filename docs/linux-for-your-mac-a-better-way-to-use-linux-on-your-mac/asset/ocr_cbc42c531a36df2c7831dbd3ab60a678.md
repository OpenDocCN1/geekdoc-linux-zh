# Virtual Fish

While you can use various X clients to set the desktop color or place images in the root window, only the xfishtank client provides an animated desktop with swimming fish. Start the client from the command line of an X terminal window, like this:

```
$ xfishtank &
```

> Note that the xroach and xfishtank clients may only work with legacy X window managers such as fvwm2 or twm. For example, KDE maintains private versions of its desktops, and the clients will not work.
