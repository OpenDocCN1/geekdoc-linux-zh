### Configuring DSL with rp-pppoe

The latest rage in broadband access is the Digital Subscriber Line (DSL). This Internet service, unlike slightly faster cable modems (to which Linux can easily connect and use), uses a server form of PPP instead of Ethernet, and is known as PPPoE. Low-end package deals from big providers such as Verizon generally provide 640Kbps download and 90Kbps upload speeds. Despite the growth pains, poor management, and initial incompetence by big telephone companies shouldering smaller ISPs out of the ISP business, consumers have been flocking to DSL service in droves.

A typical connection involves the use of a DSL modem connected to the home phone line. An Ethernet cable is then run from the modem to the Linux computer. The premiere DSL connection software for Linux is from Roaring Penguin, a small computer consultant shop in Ottawa, Ontario. Without the wonderful efforts and generosity of rp-pppoe's author, David F. Skoll, life would be more difficult for Linux DSL users.

The primary components in the `rp-pppoe` package are the following commands:

| Command | Description |
| :--- | :--- |
| `adsl-setup` | A configuration utility used to set up DSL service |
| `adsl-start` | A script used to start a DSL connection |
| `adsl-stop` | A script used to stop the DSL connection |
| `adsl-connect` | The command used in the connection script |
| `adsl-status` | A client that reports on the connection's status |
| `pppoe` | A client that works with the `pppd` daemon |

To get connected, you must have an active account, including a username and password. You will most likely need the DNS addresses from your DSL provider. Make sure all cables are connected properly. Setting up your connection is a snap once all the hardware is in place and your provider has properly set up your account.

Start the `adsl-setup` script (as root) from the command line of your console or an X terminal window, like this:

```
# adsl-setup
```

After you press Enter, you will be asked a series of questions regarding your service. You will need to have your username, password, and an understanding of how you want your system set up. The `rp-pppoe` software will automatically initiate IP *masquerading* or Internet connection sharing for your LAN, along with a firewall if you desire. If you only have a single workstation connected to the DSL modem, at least allow the script to set up firewalling. If your computer is on a LAN, and you wish other users to be able to share the connection, you will need an additional Ethernet interface for your computer. You will also need to use IP masquerading.

After the service is installed and configured for your system, connecting to the Internet is instantaneous, and as simple as this:

```
# adsl-start
```

To shut down service, use:

```
# adsl-stop
```

## Using Netscape Communicator

The premiere free—but commercial—software Web browser for Linux is Netscape Communicator. This section covers the commercial version of Communicator, which is generally included with all Linux distributions (except Debian). A free and open source version, named *mozilla*, is also available for Linux and has steadily matured after Netscape released the source code for the browser nearly two years ago. This move stunned the industry and forced many corporations to rethink archaic views regarding the Open Source paradigm (similar views, along with Fear, Uncertainty, and Doubt, [FUD], are still being spread by the monopolistic software industry). Many Mac OS users are familiar with Netscape’s software, despite the fact that Apple adopted a less popular product in 1997 after a $150 million cash infusion.

Netscape Communicator is, in fact, several programs embodied in a single client. As you will see in the following sections, Netscape can be used for browsing the Web, electronic mail, and reading Usenet newsgroups.

### Web-Browsing

Browsing the Web is generally a no-brainer for most savvy Internet users, and using the Netscape Navigator component of Communicator is generally the same across every supported platform. However, if you are new to Linux, you may not know that Communicator has many different command-line options, and can be launched in many different ways. For example:

- `-component-bar` Displays a small, floating toolbar launcher
- `-composer` Or `-edit` Opens Communicator to its Web-page editor
- `-messenger` Or `-mail` Launches Netscape Messenger for electronic mail
- `-discussions` Or `-news` Launches Netscape Discussions for newssreading

For example, if your desktop space is at a premium, launch Netscape from the command line, like this:

```
$ netscape -component-bar &
```

After you press Enter, you will see a small floating toolbar, as shown in Figure 9.11. Click on a component in the toolbar (shown in Figure 9.11) to launch the desired component. One of the first things Mac OS users will notice is the difference between Mac OS and Linux and X11. In Mac OS the menu bar is embedded in the top menu bar of the desktop, whereas under Linux and X11, each window has its own menu bar and menus. When finished with a Netscape component, click the component’s File menu and select the Close menu item. You will still have access to Netscape’s components.

Customizing Netscape is accomplished in at least two ways. The first is to use the Preferences menu item found under the Edit menu. The Preferences dialog box (shown in Figure 9.12) offers many different ways to change the way Netscape works.

Click on the drop-down menus along the left-hand side of the dialog box and the right-hand side will change in order to offer new choices. Another way to maximize screen real estate and get the most out of your browser window is to use the Appearance preferences dialog box (shown in Figure 9.12) and then select Text only for the Toolbar. You can also use Navigator's View menu (while browsing) to remove any unwanted menus. This will provide the largest maximum window area for browser information.

Another way to customize Netscape is to edit its X resources. Navigator's resources are text strings that can be used to customize default window sizes, colors, and even how Navigator reacts to keyboard and mouse pointer events. For example, if you have a USB three-button mouse with a middle mouse button that is also a scroll wheel, use the following resource settings:

```
!## NETSCAPE

Netscape*drawingArea.translation: #replace \\
<Button1Down>: ArmLink() \n\
<Button2Down>: ArmLink() \n\
-Shift<Btn1Up>: ActivateLink() \n
```
