# Usenet

Here are some Usenet newsgroups with discussions focused on Linux, PPC Linux, and X. You will find additional groups with information. Check your ISP's news server or use your favorite search engine on the Web.

+   **alt.os.linux** Alternative discussions about Linux
+   **comp.os.linux.advocacy**. Flame wars and rants of rabid Linux fanatics
+   **comp.os.linux.hardware**. Discussions about Linux and hardware
+   **comp.os.linux.x**. Discussion about Linux and X
+   **comp.os.linux.powerpc**. Exchange ideas and solutions with other Linux PPC users
+   **comp.os.linux.portable**. Issues regarding laptops (Intel-centric)
+   **comp.sys.mac.portable**. Discussions regarding PowerBooks
+   **comp.unix.aux**. Discussions about Apple's defunct AU/X
+   **comp.unix.bsd.openbsd.misc**. Discussions about OpenBSD
+   **comp.unix.machten**. Discussions about Tenon's BSD for Mac OS
+   **comp.windows.x.announce**. Announcements about X
+   **comp.windows.x.apps**. X-based applications
+   **comp.windows.x.kde**. KDE and X discussions
+   **comp.windows.x**. Discussions about X in general
