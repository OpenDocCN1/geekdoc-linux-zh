+   • The number of built-in commands. Every shell has a limited number of built-in commands that may be used in lieu of external binary commands. For example, some shells contain code that prints the current working directory (though most Linux distributions include a pwd command under the /bin directory). Other built-in commands are listed in Table 5.2.

+   • History. This feature allows you to scroll through a preset number of previous command lines, including those commands from a previous login. This can save time, especially if you need to recall and use complex commands.

+   • Job control. Offers the ability to send a currently running program into the background, start a new program, and then selectively recall and use running programs. This adds a new dimension to a single command line. Some shells, and a few but not all Linux programs, support this feature. Job control also features the ability to selectively destroy programs in memory.

+   • Command-line editing. This feature makes it easy to correct mistakes or edit recalled command lines before use. Not all shells feature editing of the command line.

+   • Language syntax. Conditional grammar and other language features can make writing shell scripts a lot easier, especially if a selected shell has a rich assortment of list and control operators.

+   • Built-in variables. Many shells feature an extensive list of built-in variables that may be modified and customized to suit your system or users’ needs. Some variables, such as PWD (the current working directory), are constantly updated, while others, such as HOSTNAME, OSTYPE, or MACHINETYPE, will depend on your system and its hardware. Some of the most important variables are HOME (the location or pathname of your home directory, usually /home/yourname) and PATH (the location of executable programs you can use on your system, typically /bin, /usr/bin, /usr/X11R6/bin, and possibly /usr/local/bin).

+   • Prompt functions. This feature usually operates according to the number and type of internal variables recognized by a shell. It allows you to redefine the shell prompt to provide useful information. At a minimum, the prompt should show the current working directory. Many Linux users use a shell prompt with the user’s name, computer hostname, and working directory.

+   • Expansion. If this feature is supported, the shell will be able to fill in, or expand the command line based on certain keystrokes. There are a number of types of expansion such as command, variable, arithmetic, and pathname.
