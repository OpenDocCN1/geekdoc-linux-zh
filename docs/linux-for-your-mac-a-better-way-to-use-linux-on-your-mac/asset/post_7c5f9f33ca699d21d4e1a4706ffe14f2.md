# Introduction

Welcome to *Linux for Your Mac*. This book is an introductory guide to choosing, installing, using, and managing Linux on your PowerPC Macintosh computer. You will find this book full of useful tidbits, tricks, and tips you can use when first choosing the path to Linux.

This book is written with the beginner in mind. You will find insights on shifting from the Mac mindset to expounding on the command line interesting, helpful, and timesaving. You will soon be able to make Linux work effectively for you. If you are an advanced user and want to explore more technical territory, then details about the X Window System, and/or how Linux interacts with your Apple hardware may prove to be more useful for you.

If you have an original 6100, 7100, or 8100 Mac, you will find that most of the material about Linux can be applied to the MkLinux release. However, this book focuses on the latest versions of the Yellow Dog Linux, LinuxPPC, and SuSE PPC Linux distributions of Linux for PowerPC Macs. These latest distributions enable Linux to run on G4 Macs, such as the Cube and the latest G4 PowerBooks, as well as on multiprocessor desktop G4s.

The Macintosh models supported by these Linux distributions are divided into “OldWorld” and “NewWorld” Macs. OldWorld Macs begin with the first PowerPC models that supported PCI slots and had supporting Mac OS routines in read-only memory (ROM). The advent of NewWorld Macs begin with the use of CHRP (*Common Hardware Reference Platform*) specification design and have the Mac OS in a ROM file in the System Folder. According to Apple, the NewWorld architecture also includes big changes in memory handling, hardware addressing, interrupts, and video. This book will help you get your Old or NewWorld Mac working with the three most popular distributions of Linux available for PowerPCs.

Using Linux (pronounced “lih-nuxs”, as in *linen*) is fun! Only in rare circumstances can you hurt your hardware by trying *Linux*. Armed with backups in hand or on the shelf you can confidently take the plunge and begin what will be a long relationship with Linux.

This book introduces the new user (“Linux newbie”) to the language and lingo of the GNU (pronounced “guh-new”) generation. In no time at all you will be competent in the use of one of the newest and hottest operating systems to hit the personal computer market in years. This book also helps you understand fundamental concepts about Linux and dispels ungrounded myths.

On one hand, Linux is the *kernel*, or core of the operating system. On the other hand, however, a *Linux distribution* is the kernel, along with thousands of specially chosen programs and a vendor-specific installation scheme or software installer. Therefore, it does not make sense to ask, “What is the best Linux to use?” Rather, one should ask, “What Linux distribution is right for me?” It is important to remember that all distributions are in essence the same; they all use a *Linux* kernel.

## C’mon, Be Honest Here!

Not all distributions are the same. They may use or include different or more than one Linux kernel. You will also discover that distributions will differ in the location and names of important files and directories. At the time of this writing, each Linux distribution for the PowerPC provides different methods and graphic clients for a number of administrative tasks. However, many major software packages are the same across distributions. You will generally find more commonality than disparity across distribution lines.

It is important to understand the difference between Linux and its graphical interface, which is provided by The XFree86 Project’s distribution of the X Window System. You can install and run Linux without a graphical interface, or the *X Window System*. A great percentage of computer servers running the Internet certainly do. When you use Linux without a graphical interface, you are using it in text-only, or *console* mode. This is how Linux started out. Many early users quite happily used the first Linux releases without a graphic interface for nearly a year until program-mers finally ported the X Window System and got it to run with Linux.

Another important distinction is that the graphical interface for Linux, XFree86, is a port of The X Window System. The X Window System, referred to as X11R6, X11, or more simply, X, is not Linux! X consists of thousands of files including fonts, graphics, and software libraries. It is a separate addition to your Linux distribution, but is not crucial to a successful Linux install. X is, however, critical to enjoying a graphical desktop environment and for some users it is even more important than support for sound.

Lastly, an important point to keep in mind is that although Linux is free software, not all the software included with a Linux distribution is free. You should always check the software's documentation for licensing or copyright terms. The exception to this rule is the Debian Linux distribution, which includes only free software. The term, "free software" means software that is distributed under the GNU General Public License, or GPL. This license, created by the venerated author of the emacs editing environment, Richard M. Stallman, provides a kind of "copyleft" agreement under which software must be distributed in source code form. The original authors retain copyright, while ownership is delegated to anyone possessing the software (under the license's "freedoms"). The agreement mandates that the software must forever be available in source code form. This concept contrasts with the more recent "open source" definitions of software, which often allow for distribution of software in source code form, but may be more restrictive in terms of freedom of use.

## What Is Linux?

As previously mentioned, Linux is the kernel of the operating system. Linux was first developed and released to the world over the Internet on Oct. 5, 1991 by Linus B. Torvalds, then a grad student at the University of Helsinki, Finland. Developed from the ground up and from scratch, Linux is free of any AT&T legacy UNIX code, but has inherited the best features and software from SysV UNIX and the Berkeley Software Distribution UNIX, or BSD. After one initial version, Torvalds then released Linux under the GNU GPL. The ramifications of this approach to licensing and distribution, combined with the explosive growth of the Internet and interest by thousands of programmers worldwide is now clear. While the open source release of the excellent BSD UNIX was mired in lawsuits and the courts, Linux grew leaps and bounds in features and its user base.

When installed (usually under the `/usr/src/linux` directory), the source code to Linux consists of nearly 7,000 files and more than 2.6 million lines of documentation, comments, and C language. When compiled and loaded at boot time, the Linux kernel can be anywhere from less than one-half a megabyte to nearly three megabytes in size.

A Linux distribution can be as small as the contents of a 1.44MB floppy diskette, or take up more than five gigabytes of compressed files on a DVD-ROM.
