Use different tabs and dialog boxes to navigate through `xdmconfig`'s configuration. You can change the greeting, select different wallpapers, control user access, or assign a graphic (or scanned photo) for each user.

# ## Configuring gdm

The gdm client, like `xdm`, provides a graphical login to Linux and X. This client may be used by editing `/etc/inittab` and a gdm runlevel five entry like this:

```
`x:5:respawn:/usr/bin/gdm -nodadaemon`
```

Note that under SuSE PPC Linux 7.0 this entry will look like this:

```
`x:5:respawn:/opt/gnome/bin/gdm -nodadaemon`
```

You can configure gdm (as root) by editing the file `gdm.conf` under the `/etc/X11/gdm` directory. The file is organized into different sections, such as daemon, security, xdmcp, gui, greeter, debug, and servers. For example, you can change the appearance of the login dialog box by editing the "greeter" section:

```
`...
Icon=/usr/share/pixmaps/gdm.xpm
LocaleFile=/etc/X11/gdm/locale.alias
Logo=/usr/share/pixmaps/gnome-logo-large.png
QuitVer=0
SystemMenu=
Welcome=Welcome to &\n
...`
```

In this example, the icon, logo, and welcome message of the dialog box can be changed. Another way to customize the desktop of your gdm login is to edit the file named `default` under the `/etc/X11/gdm/init` directory. For example, you can add the following:

```
`/usr/bin/play /usr/share/sounds/retina.wav &
/usr/bin/xclock -bg '#363047' -fg yellow -update 1 -geometry 256x256+20+250 &`
```

When the screen first appears, the user is asked to prepare for a retina scan prior to logging in (OK, it is a joke!). A large, floating clock with yellow hands will appear next to the login dialog box. (This is handy way to put idle terminals to use!)
