# IceWM

The IceWM window manager provides modern window manager features such as window decorations, themes, virtual desktops and a taskbar with a hierarchical start menu. Like all other window managers discussed so far, this window manager may be used for your X session by including its name in your home directory's .xinitrc file like this:

```
`icewm`
```

When your X session starts, IceWM's desktop appears as shown in Figure 7.10. IceWM's system-wide configuration files and themes are located under the /usr/X11R6/lib/X11/icewm directory. A directory named .icewm in a user's home directory contains personal IceWM preferences.
