When you use X11, the X server handles all display issues. This allows X to easily display programs running on remote hardware. This means that you can use clients locally, on hardware that may not otherwise support the client. This can be handy, especially if there are problems due to memory, hard drive or platform restriction.

# Using the DISPLAY Environment Variable

The DISPLAY environment variable has an in-memory value assigned to every instance of an X server on your computer, and contains a host name, a display number, and a screen number. You need to know this information if you want to use X effectively on a network.

When you launch X and start your session, your DISPLAY will have this value:

```
yourcomputerhostname:0.0
```

If you examine the env command's output, the variable could also look like this:

```
:0
```

or this:

```
:0.0
```

After logging into a remote computer using the telnet command, you should see:

```
[bball@green bball]$ env | egrep DISPLAY
DISPLAY=cubie.home.org:0
```

Here you can see your local host name (cubie), display (o) and screen number (assumed to be 0, as none is shown). Remember, this refers to the local display, and not that of the remote host, which is named green. You can then sit down and launch a graphical client on the remote computer, such as the xv graphic utility, and it will appear locally on your display.
