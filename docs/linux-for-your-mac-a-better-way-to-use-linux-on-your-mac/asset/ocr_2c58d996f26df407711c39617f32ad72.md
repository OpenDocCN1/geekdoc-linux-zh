# # Downloading and Installing RealPlayer

Real's RealPlayer may be used as a stand-alone program or launched as an application helped via Netscape Navigator. To use this player, you must navigate to Real's Web site, register, download, and then install the RealPlayer client. After downloading the appropriate file for your system, start the installation, like this:

```
$ chmod +x rp8_linux_powerpc_csl.bin
$ ./rp8_linux_powerpc_csl.bin
```

Follow instructions for the installation. RealPlayer will be installed in a directory named RealPlayer8 in your home directory. Note that you do not need to perform the install as root!

# # Using xanim

Mark Podlipiec's xanim player for Linux can play more than a dozen different animation and video formats, including QuickTime. Start xanim from the command line with the name of the video file, like this:

```
$ xanim video.avi &
```

A small video window will appear, along with a separate control window. You can find thousands of free video clips on the Internet, and other animation players for Linux including the aktion command (a xanim-based client for KDE).
