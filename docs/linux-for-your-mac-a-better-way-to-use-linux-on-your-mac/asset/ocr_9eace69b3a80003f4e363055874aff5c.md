These window managers range in features from simple to complex. Some include graphical configuration clients, while others are traditional window managers that have been updated to perform well with the GNOME libraries, and support the display and use of GNOME clients.

Many GNOME distributions now use the Sawfish window manager (formerly known as Sawmill) as the standard GNOME window manager. Sawfish uses a scripting language for configuration and features, and also works quite well as a stand-alone window manager. Its user-interface configuration tool, the `sawfish-ui` command, is used to create scripts to control how Sawfish manages your windows and pointer events.

# Using the GNOME Desktop

Using a GNOME desktop environment for your X sessions is convenient and easy. Like KDE, the GNOME desktop includes several major elements:

+   * **Root display**. Also known as the *desktop*, this is the main work area and hosts floating windows, toolbars, and icons. You may generally have up to eight desktops available during your X sessions. The root display can be configured by using the GNOME control center, or through menu items accessed by pressing the right mouse button in a blank area of the display. Files may be copied, deleted, moved, and renamed by right clicking and dragging.
