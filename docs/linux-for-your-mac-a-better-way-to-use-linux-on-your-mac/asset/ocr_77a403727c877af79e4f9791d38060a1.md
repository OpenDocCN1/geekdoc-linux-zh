# # Setting up PPP Accounts

If you'd prefer just to provide a PPP account with a static IP address, create your remote user's account, but instead of providing a shell entry in the /etc/passwd file, use the name of a shell script, such as start_ppp.

For example,

```
bball:x:501:501:billy ball:/home/bball:/usr/local/bin/start_ppp
```

The start_ppp shell script looks like:

```
exec /usr/sbin/pppd detach
```

You'll also need a companion entry in the /etc/ppp directory to provide settings for your modem's port. Create a file named options.ttySO (to match your modem's port; for example if your modem is on /dev/ttyS1, then the name of the file should be options.ttyS1) that contains the IP address of the server and the IP address you'd like to assign to the remote computer, such as:

```
192.168.2.37:192.168.2.99
```

You'll also need an /etc/ppp/options file that contains:

+   asympap 0
+   netmask 255.255.255.0
+   proxyarp
+   lock
+   crtscts
+   modem

These settings are essential in order to support networking over your modem. You can now allow your remote user to dial in and connect!
