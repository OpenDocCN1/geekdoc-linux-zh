Pick a session type using the Up and Down arrow keys, then click the Load Session button to launch your previously saved custom session. This is a powerful way to "remember" or organize your X sessions and keep track of what applications were in use. Using a session manager can also save time and effort if you have several different clients launched at the same time. Note that session-management is a staple feature in the KDE and GNOME desktop environments; xsd is only required for older window managers without session management.

Also, nearly every distribution includes a file (which is actually a shell script) named .Xsession, but it is employed when you use the xdm display manager to log into Linux and X. This shell script is used to configure and set up the login screen and dialog box. Although .Xsession has nothing to do with xsd, it may, especially on some Red Hat-based distributions, create a file named .Xsession-errors to log errors encountered while using X, and execute window managers and clients found in the home directory’s .Xsession file.

# ## Yet More X Files!

You may also find an .Xclients file in your home directory. This file, along with its system-wide counterpart xclients (possibly found under the /etc/X11/xinit directory), can be used like .Xinitrc to launch specific X clients. Another file, named .xauthority, is used to store authorization records when you log into X using a display manager.

# # Using X11 Terminal Clients

As you use the Linux console, you will become more proficient at using the shell. Using the shell during an X session requires the use of a terminal client (although KDE’s Konsole client may be used for one-line commands). As with the vast choice of shells for Linux, you will also have a variety of terminal clients to choose from during your sessions.

Finding a terminal of choice may depend on your needs, personal tastes, or the client’s features. Nearly all terminal clients may be configured in some way to work a bit better, and nearly every window manager supports resizing of a terminal window so that it may fit more comfortably in your display area.
