# ## Emulating Mouse Buttons

If your Power Mac has a mouse with only one button (as most do), you may consider getting a three-button mouse. Linux and X are designed to support and use three-button rodentsimeters. This does not mean that you cannot use Linux and X productively using a single-button mouse, but life will be a bit easier if your mouse has at least two buttons.

If you have installed Linux on an iBook and want three-button emulation, you can pass a command string known as an argument to the Linux kernel at boot time. For example, the following setting in your `yaboot.conf` file enables F11 and F12 as the middle and right mouse buttons:

```
append="adb,buttons=103,111"
```
