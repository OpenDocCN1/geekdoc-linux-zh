# Using GNOME's grip Client

GNOME users can use the grip client to rip audio and convert tracks to .mp3 format. Insert an audio CD, then launch the grip client, like this:

```
$ grip &
```

Use grip's tabs to configure the client. First, click the Config tab to set CD, ripping, encoding, and remote database options. Insert an audio CD, and then click the Tracks tab. Select tracks by clicking your middle mouse button in the Rip column (as shown in Figure 13.17).

When you have finished, click the Rip tab, and then click the Rip+Encode button to start the process.
