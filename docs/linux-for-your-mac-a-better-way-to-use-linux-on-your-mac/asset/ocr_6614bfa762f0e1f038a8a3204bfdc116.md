# USB

USB (*Universal Serial Bus*) support has improved at an amazing rate for Linux. 
Nearly all mice and keyboards, including PFU AMERICA, INC.'s USB Happy Hacking 
keyboard (used to write more than half this book), are supported. Many other USB 
devices, such as parallel-port, serial adapters, printers, and scanners are also supported.

One of the first places to check for USB support under Linux is the Linux USB 
project at http://www.linux-usb.org. Note however, that support for a particular 
device under PPC Linux is not assured; it all depends on how well the Intel-based 
driver works on the PowerPC platform. The good news is that many devices are 
well supported, and most work very well.

# Adding USB Devices

USB support is generally compiled into the Linux kernel, with support for differ-
ent devices provided by loadable kernel modules. Look under the `/lib/modules/`
`2.x.x/usb` directory, where `2.x.x` is the version of your Linux kernel. Under the 
`usb` directory you will find various kernel modules to support different devices. Some
USB modules have names for a specific device, such as *keyspan_pda.o* for Keyspan's 
USB-to-serial PDA adapter. Other modules, such as *scanner.o*, support a wide 
variety of devices.

# Adding a Scanner

If you are a graphic artist, and want to use a scanner with PPC Linux, do not 
worry; there are many different scanners that work with PPC Linux and various 
Power Mac computers. In the past, most scanners for Mac OS have used SCSI 
interfaces. Today, however, most scanners are supported by the USB interface.

Support for USB scanners is contained in the `scanner.o` module. This module 
supports a wide variety of scanners. However, in order to use a scanner with Linux 
you need corresponding driver support. This support is usually provided by the SANE 
(*Scanner Access Now Easy*) collection of "back- and front-end" software utilities.
