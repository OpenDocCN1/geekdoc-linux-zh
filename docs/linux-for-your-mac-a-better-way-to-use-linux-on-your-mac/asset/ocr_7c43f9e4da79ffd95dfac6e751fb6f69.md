# Railroad Tycoon II

Railroad Tycoon II combines strategy simulation and adds a great deal of detail in its animation. As you wheel and deal your way to buy and build your railroad empire, you can watch trains run across the track you have laid and bridges you’ve built.

Although released only to work with Intel-based PCs running Linux, there are two patches you can download to enable the install and play of Railroad Tycoon II while using PPC Linux. Here are the basic steps needed to patch and install and play the game. First, download two PPC patches, like this:

```
```
rt2-1.54b-ppc.run
rt2-dynamic-1.54b-ppc.run
```
```

You will find copies at: `ftp://boudicca.tux.org/misc/lokigames/patches/rt2/`

Next, insert mount the game CD, then run the first patch (as root), like this:

```
```
# sh rt2-1.54b-ppc.run
```
```

This will allow you to install RailroadTycoon onto your PowerPC hard drive, with a 200MB install typical. You can choose various types of installation, but more complex scenarios and campaigns are available if you insert and mount your Railroad Tycoon CD-ROM during game play.

During the install, the second patch should automatically be used. After the software is installed, you must run the game in a window (instead of the default full-screen), like this:

```
```
$ rt2 --windowed
```
```

Game play is as shown in Figure 18.12. The only thing you will miss by using the patch to make this game work is video (which is only used in the introduction or cutaway scenes).
