# **Table 5.3 Built-in sash Commands**

Command Description -ar Display or extract archive files -chattr Change file attributes -chgrp Change group attributes -chmod Change permission tags -chown Change ownership values -cmp Compare two files -cp Copy files, directories -dd Direct data copy -echo Echo strings or characters -ed Simple line editor -grep Regular expression searches -help Display help -file Display file type -find Search for files -gunzip Decompress files -gzip Compress files -kill Kill processes -ln Create symbolic link -ls List directory contents -lsattr Display file attributes -mkdir Create directory -mknod Create device -more Text file pager -mount Mount file, filesystem -mv Rename file, directory -printenv Display environment variables -pwd Print current working directory -rm Delete file -rmdir Delete directory -sum Calculate, display checksum -sync Flush disk buffers -tar Create, extract, or display tar archives -touch Create or update a file's timestamp -umount Unmount a filesystem -where Display PATH environment variable
