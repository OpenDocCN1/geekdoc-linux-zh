This chapter provides greater detail about GNOME (GNU Network Object Model Environment) and the X Window System. More specifically, you will learn about using GNOME, and how to install a special version of GNOME, from Ximian, Inc., which is usable with your PowerPC Linux system. Nearly every Linux distribution includes and installs a copy of GNOME, although you can build (compile) and install GNOME straight from source code.

# What Is GNOME?

The GNOME Project grew out of a graphics software project for the GIMP (GNU Image Manipulation Program). GNOME is a set of software libraries that evolved from the need for a base set of drawing functions used to create an interface for the GIMP. These drawing functions, also known as APIs (Application Programming Interfaces), grew to form a construction set for an X desktop environment.

A desktop environment, such as GNOME and KDE (discussed in more detail in Chapter 10), includes a window manager, but also provides additional elements that enable support beyond traditional window management. These elements may include additional software libraries for standard client GUIs, server-client communications protocols to support drag-and-drop, object-linking and other data sharing, a set of matching clients, and traditional features such as graphic configuration tools and session management (also known as state-saving).

GNOME’s suite of clients and the GNOME office suite of applications comprise a complete GNOME installation. This can require 200MB or more, depending on the number of clients and window managers you have installed on your system. The current version of GNOME is 1.4, and typical GNOME installations for PowerPC Linux include nearly 200 GNOME clients.

Newer GNOME installations also include elements of the GNOME Office. This entails a suite of advanced applications that are described, according to GNOME developers, to accommodate the need for a full, free suite of office productivity applications. GNOME is a staple desktop for nearly all Red Hat Linux-based distributions, such as LinuxPPC 2000 Q4. The individual GNOME clients usually reside under the /usr/X11R6 directory, while configuration files, libraries, and other files are stored under the /etc/gnome and /usr/share/gnome directories. Under SoSF PPC Linux, these files reside under the /opt/gnome directory and are not part of the /etc:* directories. Individual settings are stored in a user’s home directory under a directory named .gnome, or various other directories with names starting with _gnome.
