You can also use konqueror from the command line to launch and display a specific Web page. For example, type konqueror, followed by a specific URL like this:

$ konqueror http://www.prima-ech.com

After you press Enter, the Web page will be displayed in konqueror’s window. You can quickly see other command-line features by using the --help command-line option, or by using konqueror’s Help menu.

The Kt client is a KDE 2.0 instant messaging client you can use with AOL’s Instant Messaging service. When you first launch Kit, you will be taken to AOL’s sign-up Web page where you can get a screen name and password. If you already have a screen name and password, you can then use Kit’s Preferences dialog box to enter your information and create lists of buddies you want to track. Your list of friends and family will show up in a list in Kit’s main window. A yellow circle indicates a buddy is online and a large X indicates a buddy is off-line. You can then double-click on an online buddy, and chat with one or more online buddies using Kit’s simple message dialog box, as shown in Figure 10.15.
