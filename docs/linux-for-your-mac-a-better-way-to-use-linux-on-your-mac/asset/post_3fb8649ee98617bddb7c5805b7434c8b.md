## Use X to Configure X11

The XFree86 4.0.1 XFree86 server may be used to configure X. To attempt a configuration, log in as root, and use the server on the command line like this:

```
# xfre86 --configure
```

After you press Enter, your screen may blink several times. When done, you will find a file named XFree86Config.new in /root directory. You can then use the startx command to start a test X session like this:

```
# startx -- -xf86config /root/XFree86Config.new
```

### What Is a Window Manager?

An X window manager is simply an X client that manages the drawing and controls of windows, icons, and other items of the X desktop. A window manager generally responds to one or more specific configuration files that can contain customized settings. X window managers range from simple to complex, and from small (i.e., less than 200,000 bytes) to large (i.e., distributions that may require 150MB or more hard drive space).

Window managers tell X how to handle new windows, window decorations (such as scrollbars), window movement and placement, and resizing of windows. Window managers also can create icons, manage focus policy, or how and when windows become active. They also offer additional features such as supporting icon drag and drop for copying, linking or deleting files, and printing documents.

### Window Managers and Desktop Environments for Linux

This section introduces a number of window managers and desktop environments (i.e., window managers with a compatible suite of clients) that you can use for your X sessions. Each section provides a short description, points out any pertinent configuration files, and includes a picture of the desktop in action. Note that not all of the window managers discussed here may be installed on your system. However, you will find versions available for your Linux distribution.

After using Linux for a while, experiment with different window managers. You will develop a personal taste and will probably find a favorite one to use. Certain users prefer window managers with a wealth of features, while others prefer those with minimum resource requirements and limited features.

### GNOME

The GNOME (*GNU Network Object Model Environment*) is not a window manager, but a set of software libraries derived from a programming project, which is used to create the GIMP (*GNU Image Manipulation Program*). GNOME includes a suite of clients that have sophisticated windowing, event, and drawing capabilities. GNOME provides the framework for GNOME-aware window managers to support these features. These features include session-management, drag-and-drop, animation, and a consistent client interface during the X session.

GNOME includes a control center client that hosts a window manager-specific configuration client. For example, note a typical GNOME desktop, and the *sawfish* window manager's *sawfish-ui* client running in the GNOME control center, which is shown in Figure 7.3.

GNOME offers nearly all the features of a modern graphical interface, and is covered in more detail in Chapter 11, “Using GNOME and X11.”

### Ximian

The KDE (*K Desktop Environment*), like GNOME, also includes a suite of clients for X and Linux. ### fvwm and fvwm2

The FVWM family of window managers has been around for a while, and is popular with X power users for a number of reasons. Like the Tab Window Manager tWM (which is distributed with XF86), an FVWM window manager can host nearly any X client. But the FVWM window manager also provides additional features, such as virtual desktops, or additional in-memory root displays. Another benefit is that FVWM, according to its manual page, requires only “one-half to one-third” the memory consumption of twm.

FVWM (and a newer version, FVWM2) may be configured to enable all users to edit a system-wide resource file named system.fvwmrc or system.fvwm2rc. These files are generally found under the /etc/X11/fvwm or /etc/X11/fvwm2 directories. User settings are located in the home directory in a file named .fvwm2rc or .fvwmrc.

A typical FVWM desktop is shown in Figure 7.6.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_169_0.png)

**Figure 7.8** The FVWM2 window manager provides modern graphical interface features such as virtual desktops and window decorations.

Virtual windows are navigated by using a desktop *pager*, or navigation mini-window. A dock on the desktop also hosts mail notification, the system load, and the time.

### FVWM95

Robert Nation's fvwm95 window manager is based on fvwm2, but also includes a start menu and a task bar like GNOME and KDE. Like the earlier versions, you can build custom menus and change effects by editing a configuration file.

Under SuSE PPC Linux, this window manager's support files are located under the `/usr/X11R6/lib/X11/fvwm95` directory, along with its system-wide configuration file, *system.fvwm95rc*. This file may be customized on a per-user basis if copied to the home directory with the name .fvwm95rc.

One customization, called *focus*, pertains to pointer movement and window placement. This shows when or how a window should be made active. It can have one of the following modes:

```
#Style *** ClickToFocus
Style *** MouseFocus
#Style *** SloppyFocus
```

![](img/1ea833f5a3e3c1547e3dd2891f52804a_170_0.png)

**Figure 7.7** The FVWM95 window manager features a taskbar and Start menu for launching X clients and other commands.

In this example, a window becomes active when your pointer simply passes over the window. To require a user to click a window (in order to make it active), comment, or place a pound sign (#) in front of the MouseFocus line and remove (or uncomment) the pound sign in front of the clickToFocus line. This edit will disable the MouseFocus policy and enable clickToFocus. You must, however, restart your X session in order to use this change.

fvwm95 has 3D icons and, like fvwm, supports virtual desktops. However, fvwm95 also includes a *taskbar*, or floating menu similar to KDE’s and GNOME’s desktop panels. A typical fvwm95 session is shown in Figure 7.7.
