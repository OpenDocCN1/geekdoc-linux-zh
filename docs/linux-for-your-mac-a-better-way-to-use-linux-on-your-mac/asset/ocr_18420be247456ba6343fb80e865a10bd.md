In this (somewhat lengthy) exchange, smbclient is used to access the share on host green. The internal ls command is used to find some PCX graphics. A question mark (?) displays some built-in help, and then the built-in mget command is used to retrieve a PCX graphic. The exit command is then used to quit the session. For more information, see the samba manual page or browse to http://www.samba.org.

# ## NetaTalk

NetaTalk is a port of the AppleTalk protocol that can be used with Linux and other UNIX operating systems. Using NetaTalk is a handy way to access remote Mac OS or Linux systems posing as shared volumes!

The primary daemon is named atalkd, and is used to support AppleTalk over Ethernet. Under SuSE PPC Linux, NetaTalk's configuration file is /etc/atald/atalkd.conf.

This file simply contains the word:

```
eth0
```

This designates the interface to use. You can then start NetaTalk (as root) like this:

```
# /etc/rc.d/init.d/atald start
Starting netatalk:	done
```

Other files found under the /etc/atald directory include:

+   AppleVolumes.default	afpd.conf	netatalk.pamd
+   AppleVolumes.system	atalkd.conf	papd.conf

These files contain information and settings needed to adequately support accurate file translation and provide resource fork information for Mac OS files (as Linux does not support files with data and resource components).

To access your Linux system from Mac OS, go to the Apple menu and select the Chooser. Click on the AppleShare icon (as shown in Figure 15.13) and the hostname of any Linux workstations on your LAN running NetaTalk will appear.

Next, click your mouse on a desired host in the Chooser list. You'll then see a dialog box, as shown in Figure 15.14.

Enter your username and password, then click the Connect button to access the Linux system. Note that you should have a username and password on the remote system in order to access the files. You'll then see a dialog box, as shown in Figure 15.15.
