# ## Setting Date, Time, and Locale

Keeping accurate time on your computer is important. It is also important to know that there are two times on your computer: the Linux system time, and your computer's hardware clock. Keeping accurate track of time can be critical, especially when dealing with other users, clients, or remote computers. Some tasks, such as backups, at times must be performed during certain hours of the day. Time and date stamps on electronic mail or documents can prove to be critical in business or the legal profession.

Many savvy Linux users keep the Power Mac's hardware clock set to UTC (*Coordinated Universal Time*) while setting the system time according to the computer's location (a plus or minus offset to UTC).

Because the world is split into many different time zones, every Linux system comes with a database of time zone information (found under the *`/usr/share/zoneinfo`* directory). This information is used in conjunction with different commands to help keep accurate time. Like UNIX, Linux system time is based on the number of seconds since Jan. 1, 1970, and many Linux time utilities use the returned value as a yardstick to determine the current local time.

Displaying the date and time is easy. All you need to do is run the *date* command, like this:

```
```
$ date
Fri May 11 14:47:08 EDT 2001
```
```

In this example, the system's current date and time are extrapolated from the number of seconds and are displayed in a readable format. The *date* command may also be used to set the system time. Use the *date* command (as root) with the month, day, hour, and minute in a single numerical string, like this:

```
```
$ date 06291200
Fri Jun 29 12:00:00 EDT 2001
```
```
