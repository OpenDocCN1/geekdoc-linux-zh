# ## Using kspread

The kspread spreadsheet client is part of KDE's KOffice office suite, and requires an active X session. This program, like gnusmeric, has rapidly evolved into a capable spreadsheet client.

You can start kspread from the KDE desktop's panel menu, or the command line of an X11 terminal window like this:

```
# kspread &
```
