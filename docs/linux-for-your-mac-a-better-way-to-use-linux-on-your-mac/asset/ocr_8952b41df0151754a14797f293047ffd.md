This chapter introduces text editors you will find included with nearly every Linux distribution. You will also get an introduction to spell checking with *Linux*, and then see how to print using Linux printing software.

There are many different editors available for the Linux console and the X Window System. The first half of this chapter will discuss editors that may be used with or without an active X session. You will then read about editors with graphical interfaces that feature traditional menus and dialog boxes.

If you are new to Linux, but have experience with Mac OS, using a graphical editor may seem more familiar during your first editing sessions when using X11. However, it is important that you learn how to use console-based text editors, because there may be times when you are not running X but still have to edit text on your system. This is especially true if you have booted into a rescue mode, or if you have accessed Linux via a dialup shell account or telnet session. There are ways, however, to run graphical clients over a network (see “Using X11 on a Net-work” in Chapter 8, “Using X11”).
