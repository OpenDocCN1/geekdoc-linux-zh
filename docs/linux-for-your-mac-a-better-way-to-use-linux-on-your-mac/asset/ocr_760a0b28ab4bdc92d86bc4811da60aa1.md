# Logging in and Out

Always log in as a regular user. You should never have to log in as the root operator except during installation or system recovery!

# Shutting down and Rebooting

If you boot Linux directly to an X session, and log in via a graphic dialog box, use the shutdown or system button to shut down or reboot your computer. If you use Linux without its graphical interface, the *shutdown* command should always be used to shut down or reboot Linux. To shut down a current session immediately, use the *shutdown* command, like this:

```
shutdown -h now
```

After you press Enter, the session halts immediately by first turning off processes, and then unmounting any mounted volume. If automated power management is properly enabled, your Power Mac should also turn off.

Also use the *shutdown* command to reboot your system. To reboot right away, use the *shutdown* command, like this:

```
shutdown -r now
```

After you press Enter, the session halts, and the system reboots by first turning off processes, and then unmounting any mounted volume. It is critical that this process is followed, as data corruption or filesystem corruption may occur if the system is improperly halted. Although you will not damage your computer, you are taking chances on having to perform a reinstallation if you simply turn off the computer. Linux has built-in filesystem checking during the boot process, so if you do lose power or turn off the system, all known Linux partitions are rechecked the next time you boot.
