This chapter introduces you to the graphical interface for Linux. It is known as the X Window System, X11R6, X11, or simply, X (pronounced "ex," rather than like Roman numeral "ten"). Unlike the traditional Mac OS (and more like the newer Mac OS X, which is pronounced "ten"), Linux uses an add-on software system that provides a graphical interface for the desktop. Properly configuring X to work with your computer's graphics hardware is essential if you want to enjoy the benefits of windows, icons, menus, and other screen elements, which were first brought to the corporate stage by Apple's Lisa, and then popularized by the 128K Macintosh.

In this chapter, you will learn about a version of X named XFree86, which is a free networking *client* and *server* software system. In this system the server component handles graphics requests from a remote client (application). It handles these requests independent of a remote computer's drawing capabilities.

X predates the commercial graphical desktop and server software from the industry's software monopoly, and was designed from the ground up to support the use of remote applications. In many ways X exceeds the capabilities of closed-source, proprietary commercial operating systems. It also comes with complete source code, which enhances its portability to new hardware platforms. X works quite well on nearly every hardware platform in existence. Even the XFree86 version of X has been ported to run under the new Mac OS X!

This chapter also includes information about special X clients, known as *window managers*, that are used to handle pointer clicks, icons, buttons, and window management for your graphical Linux sessions. You will also learn how to configure X using a variety of software tools, and see how to configure different graphical X login clients, known as *display managers*.

# # What is X11?

X is a protocol and networking graphical interface. It was developed in 1984 by the Massachusetts Institute of Technology and the Digital Equipment Corporation as part of a project aimed to produce a distributed computing environment for thousands of users. Since then, X has gone through at least six major revisions, with the current version being X11R6.5. The source code to the X Window System is released under the stewardship of the X Consortium (http://www.x.org). Free versions of X are released by the XFree86 Project, Inc. It is a non-profit organization aimed at providing free versions of X for a number of platforms, including the PowerPC CPU.
