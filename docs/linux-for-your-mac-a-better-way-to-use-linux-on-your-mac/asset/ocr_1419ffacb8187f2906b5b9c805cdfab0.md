Note that some distributions, such as LinuxPPC 2000 Q4, do not include the older companion xsession client, which can be used to switch between window managers. Most distributions use the xsm session manager instead.

A session manager is used to launch one or more groups of clients that you specify in .xsession (if you use xdm), or if you use xsm, in a file named .xsmstartup or a default system.xsm (the location of which depends on how the xsm was compiled). If you want to use xsm, the format of your .xsmstartup file can be as simple as:

```
twm
xprop
xcalc
xclock
xterm
```

Save the file, then use the xsm client, followed by an active X session’s display number like this:

```
$ xsm -display :0
```

You can then navigate to the active session by using the keyboard (if you are running a stand-alone workstation) by pressing Cmd+F7 (console 7 is the default Linux console used for X). The first time you use xsm, each client will launch, and you will see a xsm control dialog box, used to control the session. As you work, and possibly launch additional clients, you can then use xsm to save your work state with a session name.

For example, if you conduct an extensive word processing session with a text editor, calculator, and online dictionary, you can save the session as "My Editing Session."
