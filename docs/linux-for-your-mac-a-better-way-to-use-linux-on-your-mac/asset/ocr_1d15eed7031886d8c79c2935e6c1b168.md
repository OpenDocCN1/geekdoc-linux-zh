# K Menu

The K menu (represented by the capital 'K' on the desktop panel) is the entry point to KDE's clients and other applications. You can use this menu to log out, lock the screen, get information about your system and KDE, get help, manage the panel, and launch applications. A KDE menu editor is available to help you customize the menu.

# Desktop Menu

The desktop menu is an optional menu that may be displayed across the top of the screen. This menu provides access to the same menus provided by the panel, and may be used to create new files, directories, icons, URLs, or client-launching icons. A new feature in KDE 2.0 and beyond is a Bookmarks menu. This menu is a copy of your Netscape Navigator bookmarks, and may be used to launch KDE's konqueror client, which allows you to quickly jump to a favorite Web site. The desktop menu also provides a Desktop, Windows, and Help menu, which are used to manage the root display, navigate windows and the desktop, and get help with KDE.

# The Konqueror Client

KDE's capable konqueror client may be used as a file manager. If you click the home icon on the desktop panel, konqueror will launch and display the contents of your home directory. However, konqueror is much more than a simple file- and icon-management client. You can use the Location field of konqueror's window to not only view your Linux file system, but the file systems of any locally mounted remote computer's hard drive or CD-ROM. You can also enter Web addresses in the Location field, as konqueror may be used as a Web browser (see Figure 10.2).

If you type in an FTP URL, such as ftp://ftp.tux.org, you can then use drag-and-drop to copy files or even entire directories of files using FTP! Finally, konqueror is also used to display help and manual pages for KDE and its clients, and will display the contents of any text file and the image of many different graphics files.
