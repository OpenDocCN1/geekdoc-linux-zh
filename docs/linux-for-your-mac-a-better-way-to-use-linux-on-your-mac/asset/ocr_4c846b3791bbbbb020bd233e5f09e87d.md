# fvwm and fvwm2

The FVWM family of window managers has been around for a while, and is popular with X power users for a number of reasons. Like the Tab Window Manager tWM (which is distributed with XFreek86), an FVWM window manager can host nearly any X client. But the FVWM window manager also provides additional features, such as virtual desktops, or additional in-memory root displays. Another benefit is that FVWM, according to its manual page, requires only “one-half to one-third” the memory consumption of twm.

FVWM (and a newer version, FVWM2) may be configured to enable all users to edit a system-wide resource file named system.fvwmrc or system.fvwm2rc. These files are generally found under the /etc/X11/fvwm or /etc/X11/fvwm2 directories. User settings are located in the home directory in a file named .fvwm2rc or .fvwmrc.
