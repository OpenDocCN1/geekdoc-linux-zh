Under PPC Linux however, this command does not work, and the clock command must be used instead. Use `clock -w` to set the hardware clock to the system time. Use `clock -s` to set the system time from the hardware clock. Don’t confuse the clock command with the X11 client named *clock*! You’ll find the hardware- and system-based `clock` command under the `/sbin` directory. The other *clock* client will be found under the `/usr/X11R6/bin` directory.

# Using printtool

The *printtool* command, as you have learned in Chapter 3, “Post Installation Configuration,” is a printer configuration tool that uses a database of printer capabilities and Red Hat’s print filtering system to properly incorporate or accommodate your printer for use with Linux. This client may be launched from the panel or the command line of an X11 terminal window like this:

```
# printtool &
```

After you press Enter, you will see the *printtool* dialog box, as shown in Figure 14.4. This client may be used to fine-tune printer control settings, or to make adjustments to your system, such as adding or removing printing service.

# Using kernelcfg

The *kernelcfg* client is a graphical kernel module handling tool that you can use to load or unload kernel modules. This client depends on a specific database under the /boot directory that contains relationship settings for modules used for the currently running kernel. Launch this client from the panel or the command line of an X11 terminal window like this:

```
# kernelcfg &
```
