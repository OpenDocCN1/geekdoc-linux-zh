You can quickly graph the data in a simple bar chart by using the following steps:

+   1. Press backslash (\), then g and press Enter.
+   2. Select bar graph and press Enter.
+   3. To enter the X axis values or labels, press x, then type A and press Enter.
+   4. Type 0 to enter the start of the range and press Enter.
+   5. Type 2 to enter the end of the range and press Enter.
+   6. To enter the Y axis values, type A, then type B and press Enter.
+   7. Type 0 to enter the start of the range, then press Enter.
+   8. Type 2 to enter the end of the range, then press Enter.
+   9. Press v to view graph (as shown in Figure 12.19).
+   10. Screen copy your graph and then press the spacebar to kill the graph window.
