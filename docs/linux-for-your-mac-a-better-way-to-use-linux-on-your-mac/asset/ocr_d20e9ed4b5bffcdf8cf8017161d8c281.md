To log into a remote host, type in the hostname or IP address in the Host field. You can then type in a username and password, or just leave the fields blank for an anonymous FTP session. When connected, you will see a list of the remote computer's files on the right. Click on a file or directory folder icon, then click an appropriate arrow button (left or right) between the two listings in the dialog box. As the transfer proceeds, you will see progress messages in the lower portion of the dialog box. Use gftp's menu to control the types of file transfers, refresh directory listings, set bookmarks, initiate transfers, log results, or get help.
