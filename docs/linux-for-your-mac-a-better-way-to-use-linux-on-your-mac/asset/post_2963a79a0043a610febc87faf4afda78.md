## Partitioning

Partitioning is the process of splitting a hard drive’s storage capacity to support additional volumes or filesystems. When you install or restore Mac OS to your hard drive from the supplied restore CD-ROM, the Mac OS software creates eight smaller partitions to hold various parts of the Mac OS (this is not, however, readily apparent).

Preparing your hard drive to support a Linux install is fairly easy, as the preferred partitioning tool is currently Apple’s Drive Setup. This graphical tool supports the creation of Mac OS HFS Extended, HFS Standard, A/UX (Apple’s legacy UNIX), and in newer incarnations, Linux PPC native, and swap (virtual memory) partitions.

## Partitioning before Installation

When planning your Linux installation, keep in mind that Linux requires at least two partitions: a single root partition and a swap partition that is typically two times the size of installed RAM. Along with the Mac OS and Linux partitions, you should also create a small HFS Standard (not HFS+) partition. This Linux boot partition can be as small as 32MB, and is used to hold the bootloader software and the Linux kernel to be booted.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_45_0.png)

If you anticipate sharing large files between Mac OS and Linux, create a larger additional HFS partition, or enlarge your HFS boot partition. This is necessary because Linux does not support reading and writing of HFS+ partitions at this time.

Therefore, when you use Drive Setup remember to create:

- A Mac OS HFS+ partition (minimum of 800MB to 1GB).
- A small HFS (Linux boot) partition (about 32MB).
- A single Linux (type A/UX or Linux) partition (1.5GB or more).

Another approach would be to create:

- A Mac OS HFS+ partition (minimum of 800MB to 1GB).
- A small HFS (Linux boot) partition (about 32MB).
- A root Linux partition (type A/UX or Linux) (1.5GB or more).
- A swap Linux partition (type A/UX or swap) (128MB or more).

If you create a single Linux partition, you will need to repartition again during the Linux installation process. To avoid this, create any needed partitions ahead of time with Drive Setup.

To begin, reboot your Power Mac with its Restore CD-ROM. Hold down the e key while rebooting to boot from the CD-ROM. Next, start the Drive Setup application (found in the Utilities folder). Select your Macintosh hard drive, and click the Initialize button.

In the next dialog box, click the Custom Select button. The pop-up menu offers a variety of partitioning schemes, including a preferred Linux PPC setup. However, you do not have to choose this setup. Instead, select four partitions. Click and drag the first partition to size your HFS+ Mac OS partition. When finished, click on the second partition and drag to size it for your 32MB HFS Standard partition (you can also just type 32 in the Size field). After this, click in the fourth partition and size it for swap memory, which should be twice the amount of installed RAM. Make sure to assign it a type of A/UX swap. Finally, the fourth partition remains for Linux, and should be at least 1.5GB. Make sure to assign it a type of A/UX root. You should end up with the following:

- **Partition 1.** HFS+ partition (perhaps 800MB)
- **Partition 2.** HFS partition (32MB)
- **Partition 3.** A/UX root (for Linux)
- **Partition 4.** A/UX swap (for Linux swap)

When finished, click the OK button and initialize the hard drive. After the drive is initialized, two Mac OS volumes appear on the Desktop. Click the Restore software icon and restore your Mac OS system onto the HFS+ volume.

You are now ready to install Linux.

## Partitioning Tools during Installation

LinuxPPC 2000 uses a partitioning tool during installation named `perlisk`. Another tool that is commonly used is `pdisk` (Intel-based Linux installers use a tool named `fdisk`). If you partition your drive ahead of time using Drive Setup, you avoid using native Linux tools.

After installation of Linux, you can add additional drives, but you will not be able to create Extended HFS partitions (you can use the `mke2fs` command to create a Standard HFS volume).

## Installing Yellow Dog Linux 2.0

This section details installation of YDL 2.0. As before, if you have a newer Apple Power Mac, you’ll need to create a small HFS partition to hold `yaboot` and a PPC Linux kernel. You’ll also need to make room for Linux. You should perform this partitioning prior to using the YDL 2.0 CD-ROM in order to preserve existing Mac OS files. Reboot your computer with your Yellow Dog Linux CD-ROM by holding down the **e** key. Linux boots, and you are greeted with an initial Yellow Dog Linux boot prompt. Press **Enter** to begin, or tap the **Tab** key to view various installation options. For example, to install YDL on a legacy iBook, which requires a text-based install, you should type:

```
boot: install-novideo
```

Other options include installation from a hard drive partition, graphical install, and combinations of installs with or without the use of video. After pressing **Enter**, the installer will load the Linux PPC kernel, then boot. You’ll then be asked to agree or disagree with the YDL license agreement. If you’re performing a text-based install, use the **Tab** key to navigate through the dialog boxes to highlight a desired button, then press **Enter**. Use the spacebar to toggle selections. If you’re performing a graphical install, use your mouse to click the appropriate buttons.

You are asked to select a language. Click or select your language, then click the OK button to continue.

YDL offers a Default or Custom installation option. Choosing a Default installation is probably a good idea if you are reinstalling, or installing on a known system and know what to expect during the installation. Default installation uses autoprobing of hardware and the installer’s internal logic to make choices. The rest of this section covering YDL goes through a Custom install.

You are asked to select your keyboard. Press Enter or click OK to continue, then choose your type of keyboard. You are asked to choose your mouse. Again, press Enter or click OK to continue and choose your mouse.

## Configuring Partitions and Installation

Next you'll be asked about drive partitioning. After selecting the designated drive, click the Edit button. You'll then be presented with a partition map of the selected drive. If the current partitioning is OK, then continue the install. Otherwise, you'll need to either delete or add partitions to create the minimal HFS boot, / (root), and swap partitions. Adding or deleting partitions will cause the new partitions to be formatted. Existing partitions remain untouched.

You'll then be asked to choose the mount points for your partitions. Click on each partition and type in its Linux mount point (such as /mnt, /boot, /, or /home). Note that you do not assign a mount point for your swap partition! After confirming the mount points, you'll then proceed to package selection.

You'll have your choice of a base, home/office, development workstation, Internet server, LAN/WAN server, or Everything installations. A base install is not recommended, as you won't be able to use X. Choose an installation that suits your needs. The installations range from 500MB to 2GB for everything. Select an installation, then press Enter or click the OK button.

The installer will read a database of software packages, choose the appropriate software and support libraries, and copy the packages to your hard drive. Go take a coffee break, but keep an eye on the Overall Progress indicator on the screen.

## Saving Settings

After Linux and the distribution software are installed, you'll be offered the opportunity to save your previous settings. This can be handy, especially if you've never installed Linux before, and need to return to the install. When finished, press Enter, or click OK.

You are asked if you want to configure your LAN. If you say Yes, you are asked if you want to assign an Internet Protocol address. You can assign a static IP (used every time you boot). If you do not want to network your computer, highlight No and press Enter. You can always add a networking interface later on. You'll also be asked to enter your domain name (such as home.org), along with a hostname (such as "stinky") for your computer. If you know the IP addresses of your LAN's nameserver, enter those addresses as well.
