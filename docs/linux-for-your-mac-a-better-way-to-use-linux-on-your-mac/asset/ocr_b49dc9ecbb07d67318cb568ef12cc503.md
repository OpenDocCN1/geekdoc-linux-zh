This chapter covers getting connected to the Internet. This is generally one of the first tasks Linux users accomplish after installing Linux. For many users, it is a necessary ingredient in the daily fare of personal computing. In this chapter you will learn about some of the traditional command-line tools, and will get an idea of how to start, configure, and use the newer, more sophisticated graphical Internet utilities included with every Linux distribution.

Use this chapter as a launch point for learning more about connecting to the Internet. There are also hundreds, if not a thousand other Internet utilities available for Linux. These utilities range from instant messaging to a simple display of stock tickers in your desktop panel.

# ## Serial Port and Modem Setup

Until the communications revolution is complete and everyone has ultra-high-speed broadband access to the Internet, most users will continue to connect to the Internet using a dial-up connection through an ISP (*Internet Service Provider*). In order to successfully connect to your ISP, you will need to be aware of your PowerPC's hardware capabilities and be able to recognize and configure Linux to work with and use your system's serial port or internal modem.

Fortunately, most modern Linux distributions and Internet connection utilities are able to recognize, configure, and report on any modem or serial port. After booting Linux, use the dmesg command to check for any found serial or modem ports, like this:

```
$ dmesg | fgrep tty
tty00 at 0xd415b020 (irq = 22) is a 28530 ESCC (cobalt modem)
tty01 at 0xd4162000 (irq = 23) is a 28530 ESCC (IrDA)
```

This example shows that two serial ports were found and may (possibly) be used. Linux denotes serial communications ports as /dev/ttyx where x is often a number between zero and three. In this example (using a TiBook running LinuxPPC 2000 Q4), the internal modem is correctly identified and has been assigned /dev/tty0. You can then use the ln command (as root) to create the symbolic modem link, like this:

```
# ln -s /dev/ttyS0 /dev/modem
```
