*Figure 14.10 The yast command is SuSE's comprehensive administration tool.*

After you press Enter, its main dialog box will appear, as shown in Figure 14.10. The `yast` command provides user, system, network, and software management. Several of its initial menu items lead to further menus you can use to maintain your system. For example, choosing the Adjustments menu item provides for changing the language setup, keymaps, location of SuSE Linux installation software, and partition management. However, the main functions are found under the System administration menu item.

This menu provides for:

+   - **Hardware configuration.** New keyboards, pointing devices, printers, scanners, modem, CD-ROM drives, and networking interfaces. 
+   - **Configuration.** For nearly all networking services, and devices. 
+   - **Boot mode management.** Such as using an X11 display manager. 
+   - **Managing users and groups.** 
+   - **Performing system backups.** 
+   - **Security settings.** To restrict system access or enable other security features. 
+   - **Date, time, and time zone settings.**

To use the graphical yast2 client, type its name on the command line of an X11 terminal window like this:

```
# yast2 &
```

After you press Enter, its main administration tool will appear, as shown in Figure 14.11.
