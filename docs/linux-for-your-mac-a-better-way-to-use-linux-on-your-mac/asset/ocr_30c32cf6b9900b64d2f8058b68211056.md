# ### Using kpackage

The **kpackage** client is the handy graphical interface to the **rpm** command when using KDE. Like **gnorpm**, this client provides dialog boxes, buttons, menus, and icons you can use when administering software on your system. Again, you must run the client as the root operator.

Start **kpackage** (as root) by using the desktop panel's Utilities menu (Package Manager), or by typing **kpackage** on the command line of an X11 terminal window like this:

```
`# kpackage &`
```

After you press Enter, the client will start, query your system's RPM database (usually found under the */var/lib/rpm* directory), and display a window as shown in Figure 14.14.

Your system's installed software will be displayed in a hierachical list along the left side of the window. Click on a group of packages, and the associated applications and software installed in the group will be displayed. A vertical navigation toolbar is embedded in the window frame on the left side. Click on a package, and its information will be shown on the right side of the window. As with **gnorpm**, you can then install, query, verify, or uninstall packages by clicking appropriate buttons in the window.
