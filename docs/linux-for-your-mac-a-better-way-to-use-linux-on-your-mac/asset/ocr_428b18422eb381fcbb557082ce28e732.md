Creating an archive is quite easy. For example, if you have the disk space, navigate to a new directory and use `mkdir` to create a directory to hold the archive contents:

```
$ mkdir home
```

Next, use the `cp` command with its `-ar` option to recursively copy the specified directory into your new home directory like this:

```
$ cp -ar /home/bball home
```

To create a CD-ROM image of the directory, use the `mkisofs` command with the name of the desired CD-ROM image and the specified directory like this:

```
$ mkisofs -r -o home.iso home
```

You can then use a utility, such as the `mc` command, to compare the two directories. When satisfied with the integrity of your archive, unmount the archive using the `umount` command like this:

```
# umount isotest
```
