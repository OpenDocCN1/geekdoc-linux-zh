# **Editing /etc/printcap**

The *yast*, *yast2*, and *printtool* commands save your printer definitions in your system's printer capability database, /etc/printcap. You do not need to edit this file! Of course, as the root operator you can do anything you want, but in general you should not have to make any changes.

However, if you use SuSE Linux, and use the *yast* command to create a printer definition for a USB printer, you'll need to edit your system's /etc/printcap.
