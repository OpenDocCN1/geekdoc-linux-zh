to work as root is to use the *su* command, which allows you to log in and become
any user for a temporary time (in order to accomplish a specific task). This is much
safer and will avoid the heartache of having to reinstall or rebuild a system. Linux
works on the concept of user, group, and world permissions for reading, writing,
and execution. You will learn more about permissions later on in this book.
Suffice it to say that as root, you have permission to do anything.

The best approach to assuming root status is to log in with your normal username
and password. Then, when you need to work as root, use the *su* command to ac-
complish a specific task, like this:

```
$ su -c "pico -w /etc/inittab"
Password:
```

In this example, the *pico* text editor is launched and opens the system's initialization
table for editing. After you edit the file and close the application, you will be returned
to your normal status. For more lengthy forays as root, you can also use *su*, like this:

```
$ su
Password:
#
```

Note how your command line or shell prompt changes after you use the *su* com-
mand. You are now working as the root operator. To quit working as root, use the
shell's built-in *exit* command, like this:

```
# exit √
$
```

As you can see, you will then return to your normal user status. You need to know
how to work as root, especially after installing Linux on a new computer. You will
use your accumulated Linux skills and knowledge to help overcome any problems
or obstacles in configuring Linux to get the most out of your machine. Use your
root status only when needed, and you will never get into trouble.
