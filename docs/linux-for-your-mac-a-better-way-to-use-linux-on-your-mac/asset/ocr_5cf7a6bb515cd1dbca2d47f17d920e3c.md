http://www.linux-ide.org/hdparm-flisk.html. Home page for the hdparm and fdisk commands where you can download the latest source code and build an up-to-date version of these commands.

http://e2fsprogs.sourceforge.net/ext2.html. Home page for many different ext2fs utilities.

http://olstrans.sourceforge.net/release/OLS2000-ext3/OLS2000-ext3.html. A transcript of a talk concerning the proposed ext3 journaling filesystem for Linux.

http://www.namesys.com/. Home page for the ReiserFS journaling filesystem for Linux, with links to download the latest version. You will also find instructions on how to install and use this new filesystem on your system.

http://linux-xfs.sgi.com/projects/xfs/. Home page for the SGI Linux XFS filesystem development project. You can download the source code and instructions on how to install XFS.
