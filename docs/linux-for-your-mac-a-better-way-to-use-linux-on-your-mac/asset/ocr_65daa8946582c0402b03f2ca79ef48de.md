# Other Printing Systems

There are other printing systems available for Linux, primarily on other computer platforms, such as Intel-based PCs. Patrick Powell's LPng print service is a security enabled, network printing system included with many popular distributions. Another printing system is the Common UNIX Printing System, or CUPS. CUPS has the advantage of being distributed under the GNU GPL, unlike all other printing systems for Linux, and is available for a variety of distributions, including PPC Linux.

# Starting a Print Job

Print jobs are started at the command line using the lpr command. The lpr command has a number of command-line options, but in its simplest form may be used to send a document to the default system printer like this:

```
$ lpr mydocument.txt
```

In this example, after you press Enter, the document will be spooled to your personal printing directory (under the /var/spool/lpd directory). The lpq command, which checks the directory for new jobs, will then spawn a printing process and send the document to the printer. You can also use lpr -P option, followed by a printer's name, to send a job to a specific printer, like this:

```
$ lpr -Promote1p mydocument.txt
```

In this example, the print job will be sent to the printer named remote1p (and in this case, a printer attached to a different computer on the network). The lpr command can also use input redirection. Using the previous style command as an example, you can send the readability report directly to a specific printer like this:

```
$ style linuxpr.txt | lpr -Pmp400
```

In this example, the report will be printed on the printer named mp400.
