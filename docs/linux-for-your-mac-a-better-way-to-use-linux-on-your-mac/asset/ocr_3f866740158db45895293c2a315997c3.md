After the build finishes, you can then simply copy the resulting *scanner.o* module into your */lib/modules/2.2.x/USB* directory to replace your original. Note that this works only if you use the same Linux source used to build the currently running kernel (the structure of the *scanner.h* source has changed with the new 2.4-series Linux kernel, but the scanner information still remains valid).

# ## Printing

Installing a printer for use with PPC Linux is fast and easy, because every Linux distribution comes with tools that make the task easy. Red Hat-based systems come with the graphical *printtool* client, while SuSE PPC Linux users can use the *yast* command or *yast2* client to configure a printer.

The good news for Intel-based Linux users migrating to PPC Linux is that your older, Linux-supported parallel port printer can work with USB while running PPC Linux! If you have a legacy parallel port printer and want to use it with PPC Linux on your Power Mac, the D-Link DSB-P36 USB parallel port printer adapter is indispensable; you are able to connect your parallel port printer and attach it to your computer's USB port.

Setting up a parallel port or USB printer under Linux can be accomplished in a matter of a few seconds. For example, under SuSE PPC Linux, launch the *yast2* client. Select the Hardware/Printer menu item, and then click the Launch Module button. You see a dialog box that lists five different printers: Novell, parallel, re-mote, Samba, and USB.

If you have a USB printer, or a printer connected to the D-Link adapter, click USB and then click the Add button. You see a dialog box, as shown in Figure 3.10.
Pick a printer device name, such as */dev/usb/p0* (if you have only one printer), and then click the *Next* button. Then you see a dialog box that lists a variety of printer manufacturers and devices. Click on your printer's manufacturer, such as Hewlett Packard, and a list of supported printers for that manufacturer appears, as shown in Figure 3.11.

Do not panic if you do not see a printer model that matches your printer exactly. There are many different printers on the market, but many printers from the same manufacturer and family will work with one or more printer drivers. For example, an HP 658C USB printer functions quite well using the Deskjet 500 printer driver. When finished, click the *Next* button.

You are now asked to give your printer a name. Give your printer a name, or accept the default name. Remember this name because you will use it later for printing!
