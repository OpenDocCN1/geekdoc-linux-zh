If you use the startx command, you can begin an X session using GNOME by including the following (as the last line) in your .xinitrc file:

```
exec gnome-session
```

If you use SuSE PPC Linux, you can begin an X session with startx and GNOME like this:

```
$ startx gnome
```

# Choosing a Window Manager for GNOME

Unlike KDE, GNOME is made up of software libraries and a set of clients that use the software libraries. It does not, however, include a window manager. This means that you are free to use any GNOME-aware window manager to run your desktop.
