# twm

The `twm` window manager is the only window manager included with XFree86. Known as the Tab Window Manager, `twm` sports a bare bones set of features. It does, however, provide window decorations, customizable root desktop menus, icons, and other desirable features.

A system-wide resource file, `system.twmrcc`, is located under the `/etc/X11/twm` directory. User settings are in a file named `.twmrcc` in a user's home directory. A typical `twm` desktop is shown in Figure 7.13.
