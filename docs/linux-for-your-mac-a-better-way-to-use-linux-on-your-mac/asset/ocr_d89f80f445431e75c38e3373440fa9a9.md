the Yellow Dog Linux and LinuxPPC 2000 distributions define the following runlevels like this:

```
# Default runlevel. The runlevels used by RHS are:
# 0 - halt (Do NOT set initdefault to this)
# 1 - Single user mode
# 2 - Multiuser, with out NFS (The same as 3, if you do not have networking)
# 3 - Full multiuser mode
# 4 - unused
# 5 - X11
# 6 - reboot (Do not set initdefault to this)
```

The runlevels most commonly used here are 1 (or single user mode), used for file system repair or administrative work; 3, used for normal console-login multi-user mode (for using startx); and 5, used for multi-user mode with a graphical X login using a display manager.

SuSE PPC Linux defines these runlevels like this:

```
# runlevel 0 is halt
# runlevel S is single-user
# runlevel 1 is multi-user without network
# runlevel 2 is multi-user with network
# runlevel 3 is multi-user with network and xdm
# runlevel 4 is unused
# runlevel 5 is unused
# runlevel 6 is reboot
```

Note that SuSE’s multi-user, console-mode uses runlevel 2, while a graphical login with a display manager and X is runlevel 3. The default runlevel is specified using the initdefault setting in /etc/inittab.

Under LinuxPPC 2000, booting to xdm uses:

```
id:5:initdefault:
```

With SuSE PPC Linux, use the following:

```
# default runlevel
id:3:initdefault:
```

The default display manager can be specified in /etc/inittab with a runlevel description like this:

```
x:5:respawn:/usr/bin/xdm -nodaedmon
```
