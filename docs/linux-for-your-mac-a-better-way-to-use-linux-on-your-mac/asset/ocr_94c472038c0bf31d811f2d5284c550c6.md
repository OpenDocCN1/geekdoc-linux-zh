Use the Up and Down arrow keys to scroll through previous commands. If you use the `!c` built-in command, you can edit the history list. By default, `bash` will remember 500 commands. This value may be changed, however, by defining or editing the value of the `HISTSIZE` environment variable.

# ## Regular and Extended Expressions

If you are new to Linux, you may not have much experience in using wildcard characters or search patterns in a task known as using *regular or extended regular expressions*, or *globbing*. You will use these expressions on the command line in conjunction with searching, editing, and navigation commands, such as `ls`, `find`, and `sed`. You will also use them with the `grep` family of commands: `agrep`, `egrep`, `grep`, and `fgrep`.

There is not enough room in this chapter (or book) to fully cover using these commands and expressions. For the most part, many Linux users are quite content to learn simple uses for regular expressions, such as `,` to match all characters, `?` to match three characters, or extended regular expressions like `*[a-z] [0-9]*` for matching embedded letters and numbers.

More complex, extended regular expressions, use general-purpose search characters. These are known as *metacharacters* and are used for crafting search expressions; *quantifiers* (single or multiple character-matching expressions), *anchors* (positional characters, such as specifying the beginning or end of a line), *escape characters* (for specifying end-of-line, carriage-returns, etc.), and *alternation* (which provides for Boolean logic).

![](bbox=[0.07, 0.7, 0.14, 0.82])

> For a simple introduction to using regular expressions, read the `ed` or `grep` manual pages, where you will find different examples and uses for complex search strings.

The best way to learn how to use expressions in searching is to read a command's manual page, and to practice. While the `ls` command can use expressions for searching, you'll find meatier tasks when searching through text files using one or more `grep` commands. While the `grep` and `fgrep` commands may be used for sophisticated searches, the most complex and capable family member is the `egrep` command.
