j`ed`, by John E. Davis. Like `vim`, this editor includes a version for the console (`j`ed) and another that works with X and your pointer.

The `j`ed editor by default uses keyboard commands similar to those used by the `emacs` editor. But you can create custom keystrokes and command by editing its user's resource file (named `.j`ed`rc` in your home directory. Copy the file `/usr/share/jed/lib/jed.rc` to your home directory as `.jedrc`, then edit to incorporate your changes.

If you are familiar with computers and know who Mr. Peabody and Sherman are, you most likely remember the WordStar word processing program and the diamond, a use of the Ctrl key and the `e, r, a, s, d, f, x`, and `c` keys for cursor navigation. This system was eliminated by the introduction of the PC keyboard (the Caps Lock key is where the Ctrl key should be). You can now operate the diamond by using a Happy Hacking keyboard (which has the keys in the right place), and by starting `j`ed in WordStar mode. Do this by inserting the following command in your `.jedrc` home directory:

```
"wordstar.sl"       evalfile    pop
```

You can start `j`ed` from the command line of the console or an X terminal window like this:

```
$ jed myfile.txt
```

After you press Enter, the file `myfile.txt` will be opened for editing or created if it does not exist. To start the X version, `xjed`, type at the command line of an X11 terminal window like this:

```
$ xjed &
```

After you press Enter, you will see the `xjed` editor, as shown in Figure 6.3.

When you launch `j`ed` in X mode, you can use your mouse to click on and activate its menu items.
