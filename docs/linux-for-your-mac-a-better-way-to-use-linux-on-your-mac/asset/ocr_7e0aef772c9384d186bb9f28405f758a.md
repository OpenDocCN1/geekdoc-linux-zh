# ### KDE Desktop Elements

You will use different elements of your KDE desktop at different times. For example, when you first start using KDE, you will want to explore different menus. Navigate through the menu system to find out how applications are organized on the menus. You will also want to learn how to use the desktop to mimic shell command-line features, such as deleting files, creating new directories, and so on. What follows are short descriptions of the various desktop elements.

# ### KDE Panel

The KDE panel is a re-sizable, movable object that may be displayed or hidden with a single click of the pointer (located on the arrow at each end of the panel). The panel is an important part of conducting work while using KDE, and offers quick access to menus, lists of windows, your home directory, new terminals, help, configuration dialog boxes, and other applications.
