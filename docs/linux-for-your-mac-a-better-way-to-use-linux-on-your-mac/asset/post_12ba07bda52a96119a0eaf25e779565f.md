## Ripping Audio CDs to .mp3

Using .mp3 audio provides a great way to store lots of music in a compressed format. For example, you can store 10 audio CDs’ worth of .mp3 files on a single CD-R, enabling you to compress your music collection and archive your original music CDs. Many Linux users convert their entire audio CD collection into .mp3 format and store the collection on a local server.

You will need several easily available commands and clients in order to convert your audio CDs into .mp3 format. Once installed, the process of converting audio CDs into .mp3 format is automatic.

## Encoders and Decoders

Most of the work in converting analog audio to digital form is done by the cdparanoia client, known as a ripper, and a command such as lame, known as an encoder. You will need approximately 200MB or so of extra hard drive storage while ripping and encoding .mp3 files (i.e., a single audio track in .wav format can require more than 25MB). With multiple tracks residing on your hard drive awaiting the encoding process, you can see that storage requirements grow quickly.

The “LAME Ain’t an Mp3 Encoder,” or lame client is distributed in source code form. In order to use lame you must download, decompress, configure, build, and then install the client, like this:

```
$ tar xvf lame*.gz
$ cd lame*
$ make
$ su -c "make install"
```

Note that you must have Linux development tools and libraries installed in order to build software packages. The last command line uses the su command to install the file under the `/usr/local/bin` directory. If `/usr/local/bin` is not in your `$PATH`, you can either edit your default `$PATH` setting or configure the software to install under a different directory. You are now set to start ripping audio CDs!

### Using the krabber Client

KDE's `krabber` client, by Adrian Schroeter, is an easy to use audio CD ripping and encoding front-end that is also network aware. This means that you can use `krabber` to automatically retrieve information about your audio CD and save converted tracks with the song's name in a directory with the name of the album. Start `krabber` from the command line of an X11 terminal window like this:

```
$ krabber &
```

When you first use `krabber` it will look for a number of external commands that can be used to rip CDs. Its main window is shown in Figure 13.16 (just before ripping begins).

![](img/1ea833f5a3e3c1547e3dd2891f52804a_337_0.png)

**Figure 13.16** KDE's `krabber` can automate the conversion of audio CDs into `.mp3` files.

Set the CPU priority in order to devote the majority of your system's CPU horsepower to the task of encoding files. Select an appropriate bitrate for the resulting music files (higher rates result in larger `.mp3` files), along with various audio filters. Ripping an audio CD then consists of four steps:

- 1. Select audio tracks from the inserted audio CD. Press the first button and you will be asked for the tracks to convert. Click the Done button, and then `krabber` will attempt to query a remote Internet music database in order to label your tracks.
- 2. Choose the directory to use during the ripping and encoding process. If you have more room on another partition, then use the other partition.
- 3. Name your tracks. Click button three to bring up a dialog box used to name your tracks.
- 4. Start ripping audio files from a CD, and then start the encoding process. `krabber` will display a progress indicator.

## Using GNOME's grip Client

GNOME users can use the grip client to rip audio and convert tracks to .mp3 format. Insert an audio CD, then launch the grip client, like this:

```
$ grip &
```

Use grip's tabs to configure the client. First, click the Config tab to set CD, ripping, encoding, and remote database options. Insert an audio CD, and then click the Tracks tab. Select tracks by clicking your middle mouse button in the Rip column (as shown in Figure 13.17).

When you have finished, click the Rip tab, and then click the Rip+Encode button to start the process.

## Video and Animation Clients

Video and animation playback is now a popular pastime with many Linux users, especially since Linux comes with and supports a variety of players. If you have broadband access (such as a high-speed Digital Subscriber Line or cable modem) you can easily watch streaming video (movies) over the Internet.

One popular commercial video client supported by Linux is Real, Inc.'s RealPlayer. You will also find free software players such as xanim and mpeg_play. Finally, after nearly a year's work, French programmers have successfully developed and released a free DVD player for Linux. Read on to learn more about these clients.

### Downloading and Installing RealPlayer

Real's RealPlayer may be used as a stand-alone program or launched as an application helped via Netscape Navigator. To use this player, you must navigate to Real's Web site, register, download, and then install the RealPlayer client. After downloading the appropriate file for your system, start the installation, like this:

```
$ chmod +x rp8_linux_powerpc_csl.bin
$ ./rp8_linux_powerpc_csl.bin
```

Follow instructions for the installation. RealPlayer will be installed in a directory named RealPlayer8 in your home directory. Note that you do not need to perform the install as root!

![](img/1ea833f5a3e3c1547e3dd2891f52804a_339_0.png)

> When selecting the version of RealPlayer for Linux at Real's Web site, choose the Linux/PC 2000 version even if you use SuSE PPC, Debian PPC, or Yellow Dog Linux.

After installation, launch Netscape Navigator, browse to and then click on a live or supported video link. When in use, RealPlayer's main window appears as shown in Figure 13.18.

### Using xanim

Mark Podlipiec's xanim player for Linux can play more than a dozen different animation and video formats, including QuickTime. Start xanim from the command line with the name of the video file, like this:

```
$ xanim video.avi &
```

A small video window will appear, along with a separate control window. You can find thousands of free video clips on the Internet, and other animation players for Linux including the aktion command (a xanim-based client for KDE).

### Playing DVDs

Linux users on the PowerPC platform can now enjoy the use of a free digital video disc (DVD) viewer to watch many different types of DVD videos, including encrypted discs. Despite the best efforts of the movie industry, the DVD Control Association, and the Motion Picture Association of America, the decryption algorithm has now been reduced to six lines of C code and is available to anyone through the Internet.

The vlc client, available in source form, allows the playing of most types of DVDs on nearly every Linux platform, including the PowerPC. This free DVD player is the result of a project by students at the École Centrale in Paris, and supports network broadcasting of MPEG streams.

Several hardware and software solutions have been available for Intel-based PCs. After a long hiatus, IBM released its ThinkPad model T22 on April 1, 2001. It is installed with Caldera OpenLinux 2.4 and includes InterVideo’s LinDVD software DVD player. This represented the first instance of a commercial software DVD player for Linux (even though it is only for one model laptop and the Intel CPU platform). This, however, does little good for the rest of the Linux market.

LinDVD, according to InterVideo, “Is currently available only to manufacturers for evaluation and integration.”

To use `vlc`, browse to http://www.videolan.org, and follow the links to download the compressed source tarball (currently about 536KB in size). As before, you must have Linux development tools and libraries installed. You must also have a PowerPC with a DVD drive. Slot-loading PowerPCs, such as the Apple G4 Cube and Titanium PowerBook, need to access the DVD through the `/dev/sr0` device (as you would in order to play audio CDs). You can do this (as root) by loading the `idescsi.o` module, like this:

```
# insmod idescsi.o
```

Next, use the `ln` command to create a link named `/dev/dvd` that points to the `/dev/sr0` device, like this:

```
# ln -s /dev/sr0 /dev/dvd
```

For some reason, `LinuxPPC 2000 Q4` does not come with a `/dev/sr0` device! As root, use the `mknod`, `chgrp`, and `chmod` commands to create this device, like this:

```
# mknod /dev/sr0 b 11 0
# chgrp disk /dev/sr0
# chmod 666 /dev/sr0
```

These commands create the device with proper group permissions so that anyone can access the device. If sound is working on your system, you should be set up to build and use the `vlc` client. Decompress the source, and then navigate into the source directory and run the `configure` script to prepare the source for the build, like this:

```
$ bunzip2 vlc*2
$ tar xf vlc*.tar
$ cd vlc*
$ ./configure
```

The `configure` script will check your system for proper support, libraries, and other software tools. After the script finishes, edit the file `Makefile.opts` to tailor the build for your system (such as perhaps removing support for the `sdl` plug-in). Then use the `make` command to build the program, like this:

```
$ make
```

After the build finishes, you can then insert a DVD and start the client, like this:

```
$ ./vlc
```
