# # Using tkrat

The `tkrat` mail client by Martin Forssen is to be used only during an X11 session, because it requires the use of the `tk/tk` graphic interpreters. This mail client is written in more than 20,000 lines of the `tk` language, and provides a sophisticated mail interface, as shown in Figure 9.19. You can start this program like this:
