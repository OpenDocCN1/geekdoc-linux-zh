Therefore, PowerPC systems that used a ToolBox ROM are labeled OldWorld Macs, while all newer Macs are NewWorld.

# Yaboot, lilo, or BootX?

NewWorld Macintoshes include models such as the Blue and White G3s and G4 Power Macs, PowerBooks, the iMac, and the iBook. OldWorld Macintoshes include pre-iMac (beige) Power Macs. For information regarding compatibility of specific models, or PreP and CHRP PowerPC computers, browse to your Linux distributor's Web site.

The following sections introduce the commonly used software tools you can use to set up a dual-boot Mac OS and PPC Linux system. Currently, booting Linux on the PowerPC platform almost always involves the need to have at least one Mac OS partition, and the initial use of Mac OS to partition the system's hard drive. This is unlike Intel-based PCs, which most often use a boot loader embedded in the Master Boot Record of the first IDE hard drive.

# Configuring BootX
