# ## Myth II

Myth II: Soulblighter is a strategy simulation that combines role-playing, sound, and animation to provide lots of action. You are in charge of a band of soldiers, knights, dwarves, and other creatures, and are assigned missions as part of your tasks. A version of this game from Loki Entertainment is available for PPC Linux (and was included with *LinuxPPC 2000 Q4* for a time).

Insert and mount the game CD-ROM, and then start the install as root. After Myth II is installed, the software resides under the `/usr/local/games/myth2` directory. A full installation requires nearly 650MB of hard drive space. Start the game, like this:

```
```
$ /usr/local/bin/myth
