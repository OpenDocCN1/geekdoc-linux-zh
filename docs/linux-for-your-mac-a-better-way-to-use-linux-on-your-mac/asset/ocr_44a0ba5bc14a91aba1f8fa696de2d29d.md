Are you ready to take the plunge? If so, this chapter will help you get started. Using Linux and the X Window System on a Power Mac is a wonderful experience. Getting there does not have to be a painful process, but there are some steps you need to take before you arrive at your first login.

This chapter explores initial considerations regarding the installation process and the ideal candidate platform for installation. You will get some basic pointers on the rudimentary requirements, and learn about performing a process rarely required for Mac OS—partitioning of the hard drive. Finally, you will get a laundry list of steps required to install three different Linux distributions: Yellow Dog Linux, LinuxPPC 2000, and SuSE PPC Linux.

Installing Linux is not hard, and with a little guidance you can easily perform the following basic steps:

+   1. Boot your Power Mac with its System Restore CD-ROM.
+   2. Partition your hard drive.
+   3. Reboot and restore Mac OS.
+   4. Reboot and install Linux.
+   5. Reboot to Mac OS and configure your bootloader.

Most users create a dual-boot system that supports Mac OS and Linux. If you plan to use Mac OS, Mac OS X, and Linux, you may want to install each operating system on its own partition. This chapter only covers installation of a Mac OS and Linux dual-boot configuration.

# Initial Considerations

Experienced Linux users migrating to different platforms discover that using Linux on Intel-based PC hardware on PowerPC-based hardware is exactly the same. The only difference is how to get there, and even that process has similarities. This section introduces a few concepts to keep in mind before you travel down the road towards installation.

The first concept concerns display requirements. You will then learn about how Linux uses memory. Finally, you will get a rough idea about the type of hard drive storage requirements needed for various types of installations.
