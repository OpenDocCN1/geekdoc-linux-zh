## Commercial Linux Games

Linux and the X Window System are not all work and no play. In fact, some of the earliest programs for Linux and X were games (according to legend, they were impetus for the initial development of UNIX). This chapter introduces some of the wacky and wild software you will find included with every PPC Linux distribution. You will also get a peek at a couple commercial games, and will learn how to build your own copy of that legendary first-person shooter, DOOM.

Many early games for Linux were ports, or translations of classic games included with the BSD UNIX. However, the recent explosion in interest and use of Linux in the last year or so has spurred commercial game development, resulting in more than a dozen titles for Intel-based Linux distribution.

These games include: Civilization, Call to Power, Descent 3, Myth II, Quake III, SimCity 3000, Soldier of Fortune, and others. While some of these games require 3D graphics hardware and special software support libraries, many others are available for PPC Linux and X that do not require upgrades to your computer's graphics system.

You will benefit most by having a 1024x768 display supporting thousands of colors. You should also have a working sound system.

## Games for the Console

Most of the games for the Linux console are part of the badgames package. This is a collection of text-based games originally designed to be played via an alphanumeric terminal window, and not the bit-mapped display of an X session.

These games include: airttraffic, abc, backgammon, battleship, bcd, bog, caesar, canfield, cfcores, cribbage, factor, fish, fortune, hangman, hunt, mille, monop, morse, number, paranoia, pom, ppr, primes, rain, robots, sail, snake, nscore, teachgammon, trek, wargames, worm, worms, and wump.

The game of fortune prints a random fortune from a large installed database. For example:

```
$ fortune
Fortune is a poor excuse for not having sense enough to be lazy.
~ Charlie McCarthy
```

With a little imagination, this command may be used to print out a random saying for each login on your system. Other games in the package require the use of a VT100 terminal, or a cursor-addressable display in which cursors may be specifically placed in different locations on the screen through software. This adds realism and rudimentary animation, such as that seen in the atc (air traffic controller) game.

## X11 Games

X includes a number of fun clients, such as strategy games, board games, and arcade games. Nearly all use graphics and sound, while some also feature music. Strategy games, such as board, puzzle, and solitaire games require thinking and logic. Other games, such as action arcades, may require manual dexterity. And a new form of game, the simulation strategy, may require both!

### Strategy Games

You will find a number of strategy games included with your PPC Linux distribution. These include graphical board games modeled in reality (such as backgammon or solitaire).

One of the legacy X card solitaire games is *xpat2*. This game provides 13 different card solitaire games. Start playing by using *xpat2* on the command line, like this:

```
$ xpat2 &
```

After you press Enter, you will see its card table, as shown in Figure 18.3.

Start game play by using the Rules menu. Use the Game menu to quit.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_462_0.png)

Figure 18.3 The xpat2 client features sound and provides a baker’s dozen of card solitaire games.

The most comprehensive, feature-laden, and game-filled card solitaire client for PPC Linux is pysol. It is usually installed under the /usr/games/bin directory. This game is written entirely in the Python language, and consists of more than 6,000 files!

To play a great game of backgammon, try the xgammon client. Launch xgammon from the command line, like this:

```
$ xgammon &
```

After you press Enter, you will see two windows, as shown in Figure 18.4.

Play starts by clicking on the dice. You will view the game progress, view dice rolls and betting action in the control window, while pieces are moved or dragged in the board window. Click the Quit button to end a match.

KDE and GNOME also offer various card solitaire games. When you install KDE, you will find the kpat, lsakat, kpoker, and kfun21 card game clients. GNOME includes an accurate rendition of freecell.

Other solitaire games combine a board and puzzle. One of the classic and playable solitaire board games is xmahjongg, developed more than 10 years ago. The object of this colorful tiles game is to remove as many tiles as possible from the board by clicking matching tiles. The game ends when no more matching tiles are available (which is rare). xmahjongg needs a display of at least 1024x768. Start the game from the command line of a terminal window, like this:

```
$ xmahjongg &
```

After you press Enter, you will see the initial board, as shown in Figure 18.5.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_463_0.png)

![](img/1ea833f5a3e3c1547e3dd2891f52804a_464_0.png)

Figure 18.5 The xmahjongg client features colorful matching tiles and good game play.

You will find other mahjongg clients installed with Linux including KDE's *kmahjongg* and GNOME's *mahjongg* client. Both clients offer beautiful tile sets, work with 800x600 displays, and have built-in help.

Another type of board puzzle is the game of matching balls. KDE's *ksame* and GNOME's *same-gnome* clients (shown in Figure 18.6) have many of the same features as the Apple Macintosh game named SameGame. The object of these games is to remove as many adjacent, matching balls as possible from the playing field.

For example, you can start *same-gnome* from the command line of a terminal window, like this:

```
$ same-gnome &
```

After you press Enter, the game board will appear. Start the play by selecting sets of matching balls. You can also use the Settings menu Preferences menu item to select different shapes for the playing pieces.

To experience a different strategy that combines graphics animation and simulation, try the *xkinetic* client. The object of this game is to build a productive, safe, and functional region-state using various geo-political building blocks. You can watch the game in sped-up time, while animation and the game's internal logic determine what paths your creation takes.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_465_0.png)

Figure 18.6 The GNOME same-gnome game features quick game play.

Start the xlinCity client, like this:

```
$ xlinCity &
```

To get started quickly, press the spacebar when its initial splash window appears, then load a default scenario. Use the built-in help, and click on various buttons (shown in Figure 18.7) to control game play.
