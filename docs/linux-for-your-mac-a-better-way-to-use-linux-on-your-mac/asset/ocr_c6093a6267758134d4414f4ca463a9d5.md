You really should not have to change your drive's settings, because Linux generally works fine with default IDE hard drive settings. Some distributions, such as LinuxPPC 2000 Q4, include logic in the `/etc/rc.d/rc.sysinit` startup script that looks for a file named `hardisaks` under the `/etc/sysconfig` directory. This Red Hat-based approach provides for some optimizations of the system's IDE drive, such as using 32-bit Input/Output or DMA.

You can get information about your computer's internal hard drive by using one or more information options to the `hdparm` command (as root), like this:
