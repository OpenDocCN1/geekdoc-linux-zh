LinDVD, according to InterVideo, “Is currently available only to manufacturers for evaluation and integration.”

To use `vlc`, browse to http://www.videolan.org, and follow the links to download the compressed source tarball (currently about 536KB in size). As before, you must have Linux development tools and libraries installed. You must also have a PowerPC with a DVD drive. Slot-loading PowerPCs, such as the Apple G4 Cube and Titanium PowerBook, need to access the DVD through the `/dev/sr0` device (as you would in order to play audio CDs). You can do this (as root) by loading the `idescsi.o` module, like this:

```
```
# insmod idescsi.o
```
```

Next, use the `ln` command to create a linked named `/dev/dvd` that points to the `/dev/sr0` device, like this:

```
```
# ln -s /dev/sr0 /dev/dvd
```
```

For some reason, `LinuxPPC 2000 Q4` does not come with a `/dev/sr0` device! As root, use the `mknod`, `chgrp`, and `chown` commands to create this device, like this:

```
```
# mknod /dev/sr0 b 11 0
# chgrp disk /dev/sr0
# chmod 666 /dev/sr0
```
```

These commands create the device with proper group permissions so that anyone can access the device. If sound is working on your system, you should be set up to build and use the `vlc` client. Decompress the source, and then navigate into the source directory and run the `configure` script to prepare the source for the build, like this:

```
```
$ bunzip2 vlc*2
$ tar xf vlc*.tar
$ cd vlc*
$ ./configure
```
```

The `configure` script will check your system for proper support, libraries, and other software tools. After the script finishes, edit the file `Makefile.opts` to tailor the build for your system (such as perhaps removing support for the `sdl` plug-in). Then use the `make` command to build the program, like this:

```
```
$ make
```
```

After the build finishes, you can then insert a DVD and start the client, like this:

```
```
$ ./vlc
```
```
