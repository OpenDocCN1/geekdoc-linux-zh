If you have trouble connecting to your ISP's news server, try creating a shell environment variable named `NTTPSERVER`. You can do this quickly and easily at the command line (if you use *bash*, like this:

```
$ export NTTPSERVER=news.mysp.com
```

This will create a variable that is used by many newsreading clients, and should cure any connection problems, especially if you are trying to reach a newsreader maintained by your ISP, and not some other ISP.
