## Alternatives

Intel-based Linux users can take advantage of a number of commercial software programs that emulate other operating systems. For example, you can use VMware's emulator to run Linux in a window under Windows, or run Windows in a window during a Linux X session.

Intel-based Linux users can also use Ardi's Executor client to run some legacy Macintosh applications in an X window while running Linux. Ardi's CarbonIce Copies application can also be used to bundle the emulator's engine onto a Mac OS application to enable it to run under Windows, Linux, DOS, or OS/2. Fortunately, Mac users can run Linux in a window while using the Mac OS. Connectix's Virtual PC 3.0 with Red Hat Linux offers several features not available in other emulators. One such feature is "Save State," which preserves the system's state and allows you to stop or restart your Linux session without shutting down or rebooting. Copy and paste, in addition to several USB devices, are also supported.

This is an excellent way to run Linux without partitioning your Mac hard drive, because the emulator uses a virtual filesystem, or a large file on your hard drive, to support the foreign operating system.

Even with the advent of Mac OS X, which uses BSD UNIX along with a new Mach kernel at the core, and supports a selective port of XFree86, you will still find that Linux for the PowerPC is a viable alternative computing environment and platform. It has an overwhelming number of applications you can use immediately.

## Initial Considerations

Experienced Linux users migrating to different platforms discover that using Linux on Intel-based PC hardware or PowerPC-based hardware is almost the same. The only difference is how to get there, and even that process has similarities. This section introduces a few concepts to keep in mind before you travel down the road towards installation.

The first concept concerns display requirements. You will then learn about how Linux uses memory. Finally, you will get a rough idea about the type of hard drive storage requirements needed for various types of installations.

## Display Requirements

Linux is the kernel, or core of the operating system. A collection of programs and documents bundled with Linux on a CD-ROM is known as a Linux distribution.

The graphical interface for Linux is the X Window System (known as X11R6, X11, or X, which is a free software package maintained by X.org, a non-profit consortium of companies). The version of X included with most Linux distributions is a free port of X prepared by the XFree86 Project, Inc.

The issue regarding display requirements generally concerns the default size of the desktop. This size is most often referred to in terms of resolution, or the number of pixels (dots) running horizontally and vertically across your computer's monitor or LCD panel.

Most early desktop PowerPCs (with small monitors), older PowerBooks, and until this year, iBooks, feature resolutions of 800x600. (The legacy Macintosh had a resolution of 512x384!) While 800x600 may be considered enough resolution to accomplish work, you should consider 1024x768 to be the minimum resolution to aim for when configuring X to work with your system. Fortunately, nearly all monitors in use today support this resolution as a minimum.

Another consideration is color depth, or the number of simultaneous colors that may be displayed on the screen. This factor is determined by your Power Mac's video hardware, the amount of video memory available, and the resolution used. Obviously, greater resolution requires more video memory. When using Linux and X, consider thousands of colors, or 16-bpp (bit-planes) resolution a minimum.

Unless you have an older PowerBook or iBook, you should aim at configuring X at 1024x768 using 16-bpp. Newer iBooks now sport a resolution of 1024x768.

## Memory Requirements

Linux is an amazing operating system that works well even on systems with little memory. One of its biggest growth areas has been in the embedded market, where it has been shoehorned to run in as little as 2MB RAM. However, if you plan to use X, along with other applications such as Netscape Communicator, RealPlayer G2, and perhaps a commercial office suite such as Applixware, consider 64MB the bare minimum. If you have an older PowerBook with less memory, you will want to beef it up to bring the total to at least 64MB.

The last PowerPC Apple Computer sold with less than 64MB was the original iBook, which was sold with 32MB. This computer has a spare slot for memory, so an additional 32MB may be added inexpensively.
