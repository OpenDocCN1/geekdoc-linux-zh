# ### Enlightenment

Enlightenment was one of the first window managers to support GNOME. Known early on as *E*, Enlightenment was developed by Carsten Haitzler and Geoff Harrison. This window manager may be used with or without GNOME, and recent versions include many unique built-in desktop environment features. Themes are one of the main attractions. Literally thousands of Enlightenment themes are available for download from various Internet sites.

A typical desktop session using this window manager is shown in Figure 7.9.

Enlightenment has most of the features of a modern X desktop, such as a pager, taskbar, virtual desktops, and root menus. The directory named *.enlightenment* in your home directory contains settings for session backgrounds, icons, and *themes*. Other support files may be stored under your system's */usr/X11R6/share/enlightenment* directory.
