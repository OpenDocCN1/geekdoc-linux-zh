This example, run under a SuSE Linux system, shows that `init` is responsible for starting a variety of programs, such as scheduling, console mouse control, and KDE. Note that not all output is shown, as many other services may be initially started on a system. Here you can see that various services have started. But how does the `init` command start these services? Understanding how Linux starts these services and the relationship between various runlevels can help you diagnose problems when booting, or help overcome problems in initializing hardware items, such as network interface cards.
