# Downloading Files

This section introduces some file transfer commands and clients you will use during your Internet sessions. As you already know, downloading files with Netscape is easy. Simply hold down the Shift key, and then click on a file's name and use the Save dialog box to save the file to the current directory. The commands covered here do the same thing, but may be used to download multiple files or even directories of files at one time.

# Command-Line Utilities

Files may be downloaded from (retrieved) or uploaded to (sent) remote computers in a variety of ways, but the most often used method of file transfer is still the FTP (*File Transfer Protocol*). The main FTP client used from the command line is `ftp`. This command features built-in help, and is easy to use.

For example, to connect to remote host, use the `ftp` command, followed by a hostname, like this:

```
$ ftp ftp.tux.org
Connected to gwyn.tux.org.
220 ProFTPD 1.2_Oprel0 Server (ProFTPD on ftp.tux.org) [gwyn.tux.org]
Name (ftp.tux.org:iball): anonymous
331 Anonymous login ok, send your complete e-mail address as password.
Password:

230 Anonymous access granted, restrictions apply.
Remote system type is UNIX.
Using binary mode to transfer files.
ftp>
```

Many remote servers and system administrators graciously allow anonymous login and retrieval of files from public directories. It is customary to enter your e-mail address as the password when logging in as an anonymous user. You can use the `ftp` command on your LAN if other computers are running an FTP server. This is one way to transfer files between different computers and operating systems.

Some important commands to use at the `ftp` command line are:

| Command | Description |
| --- | --- |
| `ascii` | Download the desired file as text. Note that you should not do this if you are downloading compressed archives, image files, or other binary information. |
