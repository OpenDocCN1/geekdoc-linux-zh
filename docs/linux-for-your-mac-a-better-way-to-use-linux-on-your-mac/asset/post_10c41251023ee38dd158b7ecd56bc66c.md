During your X sessions, you will most likely continue using the default terminals provided by your desktop environment. ## Setting Terminal Fonts

When you use a KDE- and GNOME-compliant terminal, you will use menus and dialog boxes to change the terminal’s fonts, color scheme, or size (although some support undocumented command-line options). Other terminals require command-line options or other methods to alter or activate features.

For example, by pressing Ctrl and the right mouse button (button 3), you can choose a new font size for the xterm client. Launch the terminal like this:

```
$ xterm &
```

The xterm window will appear on your desktop. If you press Ctrl, then click and hold down the right mouse button, a pop-up font menu will appear, as shown in Figure 8.2.

Scroll, then release your mouse button on a desired font size. The xterm’s window will then resize to use the new font size.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_195_0.png)

**Figure 8.2** *The xterm client's fonts may be changed on the fly by using a pop-up menu.*

Using command-line options is another way to force a terminal to use a specific font and font size. These command-line options, known as X Toolkit options, also allow you to specify foreground and background colors and other features, such as the window’s title. For example, to launch `xterm` with a lavender background and red text, use the `-bg` and `-fg` options like this:

```
$ xterm -fg red -bg Lavender &
```

You can also specify different fonts. For example, to launch a `xterm` with very large text, use the `-fn` option, followed by the name of a font, like this:

```
$ xterm -fn 10x20 &
```

After you press Enter, an extremely large terminal window will appear on your desktop!

![](img/1ea833f5a3e3c1547e3dd2891f52804a_195_1.png)

> Color names may be found in the file `rgb.txt`, perhaps under the `/usr/X11R6/lib/X11` directory. You may also look for additional fonts under the `/usr/X11R6/lib/X11/fonts/misc` directory.

## Keyboard Issues

When you use X, you can reconfigure your keyboard or rearrange keys to suit your needs. For Macintosh users, figuring out what keys to use can be confusing, because many X clients and applications may refer to the Alt or Meta keys. It is important to read the documentation for your *Linux* distribution to determine exactly how these and other keys are mapped by default when you use *Linux* or X11.

For example, when using SuSE PCLinux with the Apple USB extended keyboard, each Option key is labeled "Alt." However, when using the emacs editor, the Cmd+x key combination is pressed to use the Meta key. Intel-based PCs running Linux use the Alt+x combination.

### Customizing the Keyboard

Remap your keyboard using the xmodmap client. This client can be used to swap keys or load new keyboard layouts using the command line and a file named `.Xmodmap` in your home directory. Entries in `.Xmodmap` are known as *xmodmap expressions*, and are used to redefine keys or other X input events, such as mouse clicks. A system-wide default file named xmodmap may be found under the `/etc/X11` or in the case with SuSE PCLinux, under the `/usr/X11R6/lib/X11` directory.

You can check current key definitions with the xev client, or X event client. Start xev from the command line of a terminal window like this:

```
$ xev
```

After you press Enter, its window will appear, as shown in Figure 8.3. To find the value for your Mac keyboard's Cmd key, press the key. The values of the key press and its release will be displayed in your terminal. You then crosscheck this value by using the xmodmap with the -pk option like this:

```
$ xmodmap -pk
61    0xff1b (Escape)
62    0xff1e3 (Control_L)
63    0xff59 (Alt_L)
```

![](img/1ea833f5a3e3c1547e3dd2891f52804a_196_0.png)

64    0xffe1 (Shift_L)
65    0xffe5 (Caps_Lock)
66    0xff7e (Mode_switch)    0xfff20 (Multi_key)
67    0xfff51 (Left)
68    0xfff53 (Right)
69    0xfff54 (Down)
70    0xfff52 (Up)

Not all the output is shown here, however, the values returned (those from an Apple USB extended keyboard) correspond with the Ctrl and Caps Lock keys (values 62 and 65). To swap these keys, you can enter the following in your .Xmodmap file:

```
remove Lock = Caps_Lock
remove Control = Control_L
keysym Control_L = Caps_Lock
keysym Caps_Lock = Control_L
add Lock = Caps_Lock
add Control = Control_L
```

You can then put the change into effect by using the xmodmap client like this:

```
$ xmodmap .Xmodmap
```

After you press Enter, the keys will be swapped!

> Another handy client is xkeycaps, which displays a graphic of your keyboard. This client has a database of more than 100 keyboards, and can be used to generate xmodmap expression files to remap your entire keyboard.

## Pointer Issues

This section is not about configuring your mouse for use with Linux, but about changing the visual representation of your pointer, and changing how your mouse button(s) work during your X session. The information presented here, especially concerning button reconfiguration, can make life a bit easier and a little more fun for you or users on your system.

While the traditional pointing device for use during an X session is a three-button mouse, many Apple computers only come with a single-button ADB (Apple Desktop Bus), or USB (Universal Serial Bus) mouse or trackpad. Various tricks are used in the console and X to re-map other keys (such as F11 and F12), or key combinations (such as Fn+Ctrl and Fn+Option), to the middle and right mouse buttons. For example, if you have a one-button USB mouse, you can use the following script to map the middle and right mouse buttons to your keyboard's F11 and F12 keys:

```sh
#!/bin/sh
echo "1" > /proc/sys/dev/mac_hid/mouse_button_emulation
echo "87" > /proc/sys/dev/mac_hid/mouse_button2_keycode
echo "88" > /proc/sys/dev/mac_hid/mouse_button3_keycode
```

The traditional mouse buttons are labeled 1, 2, and 3. The left mouse button (button 1) is generally used to press buttons, click menu items, select objects, and close boxes. The middle button (button 2) is used to paste data between clients or when held down, to scroll through scrollbars. The right button (button 3) is used for Properties menus or other information in the root display.

To demonstrate text copy and paste, first highlight text in one terminal window, then click the middle mouse button in another X terminal window. You can use this technique to copy URLs from a browser, paste commands into terminal windows, or move text between editing sessions.

### Changing the Pointer

The X pointer is the representation of your cursor when moving around the root window of your display or desktop. It generally changes to an “I” or text-editing cursor inside an active window. If you are a Mac OS user, you are probably familiar with a variety of pointers, such as the standard arrow and the animated watch.

Changing the root display pointer for your X session is fun and easy. The X pointers have names that correspond to definitions in the file `cursorfont.h`, found under the `/usr/X11R6/include/X11` directory. To change your pointer, use the `xsetroot` client with its `-cursor_name` option, followed by the name of a cursor like this:

```sh
# xsetroot -cursor_name gumbi
```

After you press Enter, your pointer will become an old and familiar friend. To reset your cursor, use the default pointer’s name like this:

```sh
# xsetroot -cursor_name X_cursor
```

Use the `xfd` client and its `-fn` option, followed by the name, which allows you to view available cursors, like this:

```sh
# xfd -fn cursor
```

After you press Enter, you will see the cursors in a dialog box, as shown in Figure 8.4.
