# # Alternatives

Intel-based Linux users can take advantage of a number of commercial software programs that emulate other operating systems. For example, you can use VMware's emulator to run Linux in a window under Windows, or run Windows in a window during a Linux X session.

Intel-based Linux users can also use Ardi's Executor client to run some legacy Macintosh applications in an X window while running Linux. Ardi's CarbonIce Copies application can also be used to bundle the emulator's engine onto a Mac OS application to enable it to run under Windows, Linux, DOS, or OS/2. Fortunately, Mac users can can run Linux in a window while using the Mac OS. Connectix's Virtual PC 3.0 with Red Hat Linux offers several features not available in other emulators. One such feature is "Save State," which preserves the system's state and allows you to stop or restart your Linux session without shutting down or rebooting. Copy and paste, in addition to several USB devices, are also supported.
