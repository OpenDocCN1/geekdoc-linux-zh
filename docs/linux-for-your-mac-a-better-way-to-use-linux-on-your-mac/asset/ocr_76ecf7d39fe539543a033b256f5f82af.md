Early digital cameras typically used serial I/O to transfer images. This was a slow, tedious process, generally circumvented by using removable Compact Flash or Smart Media devices.

Today, many scanners, cameras, and printers use the Universal Serial Bus (USB) port. Before you buy a USB scanner, however, check to make sure there is a supporting driver for Linux! Some scanners are supported by the USB scanner kernel module, while others require a stand-alone application in order to acquire documents. One great place to check before you buy is http://www.linux-usb.org, which lists the status of many drivers, along with user feedback on how well the drivers work.

Along with a driver, you will also need a client that provides either a command-line interface or a graphical interface with traditional controls, such as previewing, cropping, contrast, brightness, or color adjustment. In this arrangement, the driver is known as a back end, while the client is known as the front end. The most popular Linux back-end and front-end software used for many scanners (and some cameras) is SANE (Scanner Access Now Easy) software, discussed next.

# Using SANE

SANE consists of a set of software libraries, configuration files, and one or more command-line or X front-end clients. These will include xscan, xscancimage, xscan (for cameras), and saned (which supports scanning over a network). The libraries and clients should be installed from your distribution's CD-ROM.
