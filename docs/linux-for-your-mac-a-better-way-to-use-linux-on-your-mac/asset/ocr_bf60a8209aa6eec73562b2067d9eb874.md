# What Is a vCard?

A vCard is the file format of an electronic business card, used by PDAs (Personal Data Assistants), PIMs (Personal Information Managers), Web browsers, newer cell phones, and e-mail clients. Defined by the specifications from the Internet Mail Consortium and the IETF (Internet Exchange Task Force), the vCard Specification allows for encapsulation of name, address, phone, e-mail address, Universal Resource Locator (URL), graphics, multimedia, and geographic and time zone information. If you have a Palm PDA and have beamed a business card, then you have used a vCard. The formal specifications are contained in RFC 2425, MIME Content-Type for Directory Information, and RFC 2426, (which is the vCard MIME Directory Profile).

# Introduction to Advanced Database Systems

There is not room in this chapter or the entire book to fully cover the myriad of advanced RDBMS (Relational Database Management Systems) software available for Linux. You will find two systems most often included with a Linux distribution are MySQL and PostgreSQL. These open source SQL (Structured Query Language) database servers consist of a server daemon and a host of supporting commands and clients, which you can use to build and query sophisticated databases running under Linux.
