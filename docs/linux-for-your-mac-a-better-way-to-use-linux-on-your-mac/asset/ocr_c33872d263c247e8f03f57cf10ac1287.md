32MB HFS volume. Open the folder on the HFS volume, and then click the file yaboot.conf to edit it with SimpleText. Look for:

```
...
default = install
...
```

Change this entry to point to the kernel you selected during your Linux install. Use linux22 if you selected the 2.2.18 Linux kernel, or linux if you selected the 2.4 kernel, like this:

```
...
default = linux
...
```

This example shows that Linux is to be booted using the 2.4 kernel. Scroll down the file, and then look for the linux entry. Insert the following line, using the partition number of your root Linux partition:

```
image=vmLinux-2.4
label=linux
root = /dev/hda10
```

Save the file and exit SimpleText. Next, click the file named os-chooser.example, and then save it as os-chooser. Before exiting, edit this file to insert the partition numbers of your Mac OS partition and root Linux partition, like this.

```
"Booting MacOS ..." cr "boot ultrao8:\\tbxl" eval
else
"Booting Yaboot ..." cr "boot ultrao9:\\yaboot" eval
```

These entries designate that Mac OS resides on the first IDE drive (ultrao) in the eighth partition (8). The second entry points to the Yaboot loader, which resides on the HFS boot partition (/dev/hda9).

Now open the Tools folder and run the script named make-os-chooser-bootable. In the resulting dialog box click the Change it! boxi button. The Startup Disk control panel appears. Click to select the boot partition in the Startup Disk dialog box. You can then choose Restart from the Special menu to boot Linux. When you reboot, you should be able to hold down the Option key to boot to Mac OS or Linux through a graphical chooser.
