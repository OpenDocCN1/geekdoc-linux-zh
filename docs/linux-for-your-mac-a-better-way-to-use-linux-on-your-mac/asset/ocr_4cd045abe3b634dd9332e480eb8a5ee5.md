# ### Using modemtool

The `modemtool` client, shown in Figure 14.8, is a simple graphical interface client that merely creates a symbolic link named `/dev/modem` that points to your system's modem port. The actual modem port could be `/dev/ttyS0`, `/dev/ttyUSB0`, or even `/dev/ttyS14`, depending on your Macintosh hardware.

You can launch `modemtool` by using its icon on the panel, or from the command line of an X terminal window like this:

```
# modemtool &
```

After you press Enter, its small dialog box will appear, as shown in Figure 14.8. Unfortunately, `modemtool` is brain-dead, with no built-in logic or search capability, as is possessed by the modem configuration feature of KDE's `kppp` client. You can accomplish the same task as `modemtool` by using the `ln` command like this:

```
# ln -s /dev/ttyS0 /dev/modem
```

In this example, the `/dev/ttyS0` device is known to have an attached modem. The `ln` command is then used to create the symbolic link `/dev/modem`.

# ### Using linuxconf

The `linuxconf` client is a comprehensive configuration and control client that is somewhat on a par with SUSE's `yast` command (discussed later in this chapter). Launch the `linuxconf` command from the control-panel client or the command line of an X terminal like this:

```
# linuxconf
```
