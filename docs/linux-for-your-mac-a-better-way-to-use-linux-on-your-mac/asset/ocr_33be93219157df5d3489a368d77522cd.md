# ## Configuring FTP

Most Linux distributions enable FTP service by default. However, if your system does not allow you to FTP in from the command line, first check your `/etc/inetd.conf` settings (as shown earlier). Next, ensure that the inetd daemon has started by using its script (as root) like this:

```
```
$ /etc/rc.d/init.d/inetd status
INET up
```
```

You should now be able to use the ftp command to get into your system. For example, if you're working on a host named **cubie**, you should be able to FTP into cubie like this:

```
```
$ ftp cubie
Trying 192.168.2.66...
Connected to cubie.home.org.
220 cubie.home.org FTP server (Version 6.4/OpenBSD/Linux-ftpd-0.17) ready.
Name (cubie:ball1):
331 Password:
Password:
230- Have a lot of fun...
230 User ball1 logged in.
Remote system type is UNIX.
Using binary mode to transfer files.
ftp> exit
221 Goodbye.
```
```

Note that if you use `ftp` and log in with your username and password, you'll end up in your home directory. Outside users will log in with the username `anonymous` and then use their e-mail address as the password:

```
```
$ ftp titanium
Connected to titanium.home.org.
220 ProFTPD 1.2.0pre9 Server (ProFTPD) [titanium.home.org]
Name (titanium:ball): anonymous
331 Anonymous login ok, send your complete e-mail address as password.
Password:
230 Anonymous access granted, restrictions apply.
Remote system type is UNIX.
```
```
