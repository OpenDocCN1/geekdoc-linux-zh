## Customizing Your KDE Desktop

There are many different ways to customize your KDE desktop. KDE offers a variety of customization to the appearance of your root display, window controls, colors, and size. The main software tool used to control how KDE works and looks is the K Control Center, a client named `kcontrol`.

This client may be launched by clicking its icon on the desktop's panel, then clicking the start menu, and finally selecting the Control Center menu item. You can also use the command line of a terminal window or the mini-command-line dialog box and typing:

```
kcontrol &
```

After you press Enter, you will see the control center's main window, as shown in Figure 10.7.

## Changing Colors, Backgrounds, and Themes

Altering the appearance of your desktop is easily accomplished by using various menu items available under the Look & Feel control module. For example, to change color schemes used for windows, menus, buttons, text, links and other screen widgets, use the Colors menu item. Click on the item, and you will see a dialog box as shown in Figure 10.10.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_258_0.png)

**Figure 10.10** Change your window color schemes easily using Look & Feel’s Colors dialog box.

You can choose one of 18 different color schemes to use for your sessions. When finished, click the Apply button. To change the background of your root display, use the Desktop’s Background menu item. Note that you must use KDE’s Background dialog box. The standard X11 xsetroot client, normally used with legacy window managers to change background colors or patterns, will not work, along with other fun animation clients such as xhihankan or xpenguins. This is because KDE takes over management of the desktop. In the kcontrol Background dialog box, shown in Figure 10.11, use the drop-down color palette to choose a background color. Note that a different background may be used with each active virtual desktop.

If you click on the Wallpaper tab, you can choose a background image, or wallpaper, to use in your root display. Wallpapers are found under the /usr/share/wallpapers directory, and are in JPEG format. If you use wallpaper, the Advanced tab offers additional color controls.

Theme management, or the ability to implement wholesale changes to a session’s appearance, first appeared for KDE as a neat hack, accomplished by running a separate client. Today you will find theme control in a separate module named Themes, found under the Look & Feel module. Click the Themes item in the kcontrol window to reveal separate controls for icons and style. To change the overall appearance of buttons, menus, and windows, click the Style item. You will see a dialog box, as shown in Figure 10.12.

Scroll through the list of different themes, then click the Apply button to try a theme for your desktop. Note that this dialog box offers a redundant control for the appearance of the Desktop menu. You can also control various toolbar appearance settings using the Style dialog box. When finished, click the OK button, or Cancel to reset to your original settings.

## KDE Clients for the Network and Internet

Although you can be quite productive using KDE and its clients on a stand-alone workstation, you will find that KDE comes with a wealth of network- and Internet-related utilities. This section introduces some of the more popular utilities you can use during on-line sessions. These clients may be used for monitoring, file transfer, chatting, electronic mail, news reading, and browsing.

### Network Clients

This section introduces two convenient network clients you can use with KDE during your X sessions. If you are a casual Internet user or a system manager who wants to keep track of what is going on, or coming into or out of a workstation, these clients will help.

The ksysguard client is a basic performance monitor and task manager that works by tracking processes running in your system’s memory. This information is then displayed in a custom grid you design (such as the one shown in Figure 10.13), using drag and drop of various “sensors.” One such sensor displays the number of sent or received kilobytes over a specified Ethernet interface. Launch the ksysguard client from the command line or by using the desktop panel’s menu.

The kwftpd client is an administrative utility that provides a graphical interface to administering your system’s /etc/ftpaccess file, use for File Transfer Protocol, or FTP service. This client (as shown in Figure 10.14), should only be run by the root operator.
