## Adding Users

Managing users on a Linux system is the job of the system administrator. But if you use Linux on a stand-alone workstation, you are the system administrator! One of your first jobs is to create a username and password for yourself, because you should not use Linux as the root operator (unless performing rescue operations or system maintenance).

Red Hat Linux-based systems include a variety of graphical and command-line tools used to create and manage users. SuSE Linux administrators can use the graphical `yast` utility or other command-line tools. Creating users from the command line is painless and easy, and probably faster than using a graphical tool.

The Linux user-creation program commonly used with all Linux systems is the `useradd` command. If you have a user named Fred Smith, then use the `useradd` command, like this:

```
# useradd fsmith
```

Next, you should assign a default password to the new user using the `passwd` command, like this:

```
# passwd fsmith
New password:
Re-enter new password:
Password changed
```

The new user “fsmith” will now have a directory named `/home/fsmith`, a designated login shell in `/etc/passwd`, and a new password.

> Do you have a big system, or need to create hundreds of new users? Use the `newusers` command, which uses a file containing a list of new users and passwords. See the `newusers` manual page for more information.


After you press Enter, click the **User accounts** button on the main window. A new dialog box appears. Click the **Add** button, and you will see a dialog box as shown in Figure 3.3.

## Using the *passwd* Command

As you have already learned, the *passwd* command is used to create or change a user's password. If you are in charge of a large Linux installation, have numerous users, and want to implement a bit more security, you can turn to a technique called *password expiration*, or *password aging*. This is also an effective technique for use with contract employees or temporary users. When you enforce *expiration*, users must renew or change passwords after a preset amount of time. You can also enforce actual user expiration for temporary accounts.

For Red Hat-based Linux systems, again use the *userconf* command (as root), like this:

```
# userconf &
```

Navigate to the User dialog box (previously shown in Figure 3.3), and click on the Params tab. You see the User information tab as shown in Figure 3.5.

Use this tab to set the number of days before passwords must be changed, how long a user account is viable, when to send warnings about impending expirations, and the length of time an account or password is good after a warning is issued.

## Network Configuration

Creating a network interface (see Chapter 9, "Connecting to the Internet") is relatively easy using Linux and certainly won't involve a number of robots as with other commercial operating systems. Like Mac OS, once your internal hardware (such as the network interface) is recognized, you can set up your Power Mac to run Linux. This allows you to become a member of the LAN in a matter of 30 seconds.

If you have a computer with an internal Ethernet interface, check the diagnostic output provided by the Linux kernel during the boot process. Use the `dmesg` command to display this information, and look to see if your internal card has been recognized, like this:

```
$ dmesg | less
...
eth0: GMAC at 00:30:65:fd:df:a0, driver v1.3k2
3c59x.c © 1999/200 Donald Becker and others http://www.scyclad.com/network/vortex.html
...
```

In this example from an Apple TiBook running LinuxPPC 2000, the output of the `dmesg` command is *piped* through the `less` pager. This means that the output, a stream of text, is sent through the `less` command, which allows you to scroll (page) through text. Press the q key when finished.

If you do not see any output, your card may not be recognized. Check to make sure that networking support is enabled in your Linux kernel, that you have booted with the correct Linux kernel, and/or that your hardware is supported (by checking your distribution vendor's Web site).

### Creating Network Interfaces

Creating a network interface means configuring Linux to work with your hardware, and then properly assigning an IP (Internet Protocol) address to your card. You do not need to use a network interface if you only use your computer as a stand-alone workstation. When you connect to the Internet, a different kind of interface, known as a PPP (Point-to-Point Protocol) interface, is created.

Networking interfaces under Linux are created in memory, and are generally numbered and named in the order in which they are created. For example, the first PPP interface you create is named ppp0, while the first Ethernet interface you create will be named eth0.

### Using the netcfg Client

The netcfg client included with many Red Hat-based Linux systems may be used to create a variety of new network interfaces. Start the client (as root) from the command line, like this:

```
# netcfg &
```

After you press Enter, click the Interfaces button on the main dialog box. A new dialog box appears. Click the Add button, and you see a dialog box as shown in Figure 3.7. Select the desired interface, and then click the OK button. You are presented with an appropriate dialog box to further configure the interface.

### Using YaST2 and YaST

The SuSE Linux yast command and yast2 clients may be used to create new interfaces. For example, you can use yast to jump right into configuring a network interface from the command line, like this:

```
# yast --mask network
```
