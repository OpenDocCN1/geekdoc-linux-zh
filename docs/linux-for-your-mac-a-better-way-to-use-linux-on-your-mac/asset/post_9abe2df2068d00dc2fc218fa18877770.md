
The GNOME desktop supports drag-and-drop, so you can use your pointer to move, copy, rename, delete, link, or change permissions on a file. Like KDE, GNOME also supports a graphical interface to your home directory. By using the `gnome` client, you can view your directory’s contents as icons or as a list of files. Files may be dragged into and out of the home directory to your desktop. If a file is executable and you click on its icon, the client will launch. View the click on a file that is a Web address, Netscape Navigator will be launched to view the site. If you click on a graphics document, an appropriate viewer or editor will be launched to edit or display the image.

The desktop panel is a client that hosts menus, launchers, applets, and other items. Use the panel as a handy place to store icons of frequently used clients, such as an editor or Web browser. Add applets by clicking the start menu, selecting the Applets menu, and finally selecting the Add to panel menu item.

Click the middle mouse button on a panel icon to drag the icon to a new place on the panel. This is a handy way to rearrange how your panel appears. Right-click on a panel icon to move the icon, get help, or change the icon’s properties. Right-click on a blank area of the panel to add an additional icon or access your GNOME menus. Click on either end of the panel to hide or reveal the panel.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_273_0.png)

> **GNOME offers a small command-line launcher similar to KDE’s `kcli` command.** Press Alt+F2 to bring up a dialog box for the Run button. You can then type in a short command line to launch a client. This is handy, especially if the client is not currently installed on your GNOME menus.

As you begin to use GNOME for your desktop sessions and run GNOME clients, you will quickly understand how the GNOME software libraries provide a consistent look and feel for the desktop. Nearly every GNOME client (such as the GNOME `gedit` client, shown in Figure 11.2) features a window menu, window controls, scrollbars, a floating menu bar, and a floating toolbar of icons. The menu bar and toolbar may also be “turn off,” and dragged around the root display. (Click, then drag using the small vertical band at the left end of the menu.)

Many GNOME clients share similar keystrokes (i.e., Ctrl+s to save, Ctrl+o to open, and Ctrl+x, Ctrl+c, and Ctrl+v to cut, copy, and paste) and menus (i.e., File, Edit, and Help). Copy and paste operations allow a text editor, such as `gedit`, to share data with other applications. Nearly every client features a Help menu.

## Configuring Your Window Manager

This section introduces window manager configuration when using GNOME and a GNOME-aware X window manager to manage your desktop. Remember, unlike KDE, which uses built-in window management via the *kwin* client, GNOME depends on window-management facilities provided by a compliant window manager. This applies to managing the behavior of windows, although GNOME can control many other aspects of windows and dialog boxes, such as appearance. Two of the most popular window managers for GNOME are Sawfish and Enlightenment.

## Using Configuration Tools

The Sawfish and Enlightenment packages include separate configuration tools you can use during your GNOME session to change how these window managers handle windows, icons, buttons, dialog boxes, text, and fonts. You will also be able to enable or disable a variety of features using the configuration tools.

The primary configuration tool you will use to configure your desktop session will be the GNOME control center. This comprehensive tool provides a shell for nearly all configuration menus and services required during an X session. You can launch the control center by using the desktop's panel menu, or by typing the control center's name at the command line of an X terminal window like this:

```
$ gnomecc &
```

![](img/1ea833f5a3e3c1547e3dd2891f52804a_275_0.png)

> Figure 11.3 *The GNOME control center is the center of operations for configuration menus, and the best place to start if you are looking to change desktop or window behavior during your GNOME sessions.*

After you press Enter, you will see the control center, as shown in Figure 11.3.

Note that the control center provides menus for the following topics (with the exception of the Sawfish window manager, which is discussed next):

- **Desktop.** Handles background, panel, screen saver, theme selector, and window manager controls.
- **Document Handlers.** Controls the default system editor, MIME (mail attachment formats and clients), types, and URL handlers (the default browser).
- **Multimedia.** Manages the sound server and system events (i.e., startup, shutdown, logout, window events, and so on).
- **Peripherals.** Controls keyboard and mouse settings.
- **Session.** Controls startup hints (splash screens, etc.) and startup clients.
- **User Interface.** Manages application and dialog box appearance, and GNOME's MDI (*Multiple Document Interface*) mode. (This is how multiple documents are displayed by GNOME-compliant applications.)

Click the small plus (+) sign to the left of each main item, and you will see a drop-down menu of additional controls. Click on a control to make the control's dialog box appear in the control center's main window.

Four main buttons will be active following any change to default behavior or actions; they are: Try, Revert, OK, and Cancel. Use the Try button to try out your changes before exiting the control center. Use the Revert button to undo a change. If you are satisfied with a change, click the OK button to exit that particular dialog box. If you would prefer to ignore any changes, click the Cancel button to exit the current control center dialog box.

## Configuring Sawfish

The Sawfish window manager includes a companion program named `sawfish-ui` that you can use to customize many different aspects of how your desktop and windows are handled. The `sawfish-ui` component may be launched as a stand-alone program with its own interface, or by accessing it through the GNOME control center interface. In either case, you will be able to configure this window manager in a number of ways, including changing appearance, focus, built-in help, window movement, placement and re-sizing policies, use of sound, and many workspaces or virtual desktops.

You can launch `sawfish-ui` from the command line of an X11 terminal window like this:

```
$ sawfish-ui &
```

After you press Enter, you will see its main dialog box, as shown in Figure 11.4.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_276_0.png)

Figure 11.4 *The Sawfish window manager is GNOME-aware and provides a graphical configuration client named sawfish-ui.*

Click on a menu item on the left side of the window. You will then see additional drop-down menu items in the list. Use these items to change how Sawfish works.

For example, by default, you must click on a workspace in the panel's pager or use a desktop menu to navigate to a new workspace. However, by using the Workspaces dialog box's Edge-flipping settings, you can configure transparent borders and easily move between workspaces by dragging your pointer to an edge of the display.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_277_0.png)

> If you have not noticed already, you can also access Sawfish configuration settings through the GNOME control center.

One frequently asked question when using GNOME is whether there is a list of documented shortcut keystrokes users can use instead of the mouse. To see the family of keystrokes available when using Sawfish for your GNOME window manager, click the Shortcut menu item, and then click on each Keymap family.

There are nearly 30 default keystrokes and combination key and mouse-clicks that may be used to manipulate, navigate, or move windows or pop up helpful menus. You can also define your own, or redefine default key combinations for your use. Some helpful default keystrokes are:

| Keystroke | Action |
| :--- | :--- |
| Meta+Button 1 | Grab and move window |
| Meta+Tab | Cycle through windows |
| Ctrl+Right Cursor | Cycle to next workspace |
| Ctrl+Left Cursor | Cycle to previous workspace |
| Meta+Ctrl+Right Cursor | Send current window to next workspace |
| Meta+Ctrl+Left Cursor | Send current window to previous workspace |
| Meta+Ctrl+Up Cursor | Raise current window |
| Meta+Ctrl+Down Cursor | Lower current window |

### Configuring Enlightenment

The Enlightenment window manager, like Sawfish, includes a companion configuration program named e-conf. This client is used as a stand-alone program. This client provides nearly all the same controls as the sawfish-ui program, and may be launched from the command line of an X11 terminal window like this:

```
$ e-conf &
```
