# # Calendars

Calendars are an important part of life for many people. For many Linux users, the paper calendar has been replaced by one or more calendar programs. What better way to use a computer than to calculate a calendar? This section introduces a few calendar applications you will find included with your Linux distribution.

# ## Using Calendar Clients and Commands

Some of the calendar programs included with Linux simply display a calendar or allow you to specify a date and see the calendar for that date. When a calendar program incorporates schedules or appointments, the program moves out of the realm of a simple calendar into a more complex form of productivity application, known as a scheduler or organizer.

This section shows how to use one or more simple calendar clients, then introduces calendar clients that begin to cross the line into more capable and sophisticated productivity software.

# ## Creating Simple Calendars

One of the simplest, but most useful calendar clients is **cal**. You will find this client included with every Linux distribution. The function of this command is simple—display a calendar for the current month:

```
```
$ cal

    March 2001

25  26  27  28  29  30  31
