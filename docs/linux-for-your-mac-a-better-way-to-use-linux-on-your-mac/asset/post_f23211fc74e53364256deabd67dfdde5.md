## Usenet Etiquette

The following is a short list of things to keep in mind when reading Usenet news. If you choose to participate in discussions, you will need to keep an open mind and should be on your best behavior. Although no one can be forced to follow any sort of rules on Usenet, there are some generally accepted mores that most users adhere to, which include:

- Do expect to get help with a Linux problem when asking for help on Usenet.
- Do ask your question in the right Linux news group.
- Don't expect to get an answer to your Linux question right away.
- Don't *cross-post*, or post the same message in a number of Linux newsgroups.
- Do edit out potential cross-posting message headers when replying to a Linux question.
- Do realize that Usenet is global—not everyone is from your country.
- Do realize that humor is global and that jokes may not be.
- Don't ever SPAM a Linux newsgroup—you will be sorry.
- Do be civil, even when someone asks what seems like a dumb Linux question.
- Do be objective in your views about free software.
- Don't denigrate free software—it is a gift from someone.
- Do ask specific questions and provide as much information or details as possible when posting a Linux question (i.e., version numbers, type of distribution, or hardware).
- Don't chime in on “me-too” messages.
- Do post helpful information.
- Do be friendly.
- Don't post in anger or frustration—wait a few minutes to cool down.
- Do post a summary if you get several responses to a Linux question.
- Don't be surprised if someone is nasty—there are a lot of troubled people out there.
- Don't be surprised when a fellow Linux user is very helpful.

# Downloading Files

This section introduces some file transfer commands and clients you will use during your Internet sessions. As you already know, downloading files with Netscape is easy. Simply hold down the Shift key, and then click on a file's name and use the Save dialog box to save the file to the current directory. The commands covered here do the same thing, but may be used to download multiple files or even directories of files at one time.

## Command-Line Utilities

Files may be downloaded from (retrieved) or uploaded to (sent) remote computers in a variety of ways, but the most often used method of file transfer is still the FTP (*File Transfer Protocol*). The main FTP client used from the command line is `ftp`. This command features built-in help, and is easy to use.

For example, to connect to remote host, use the `ftp` command, followed by a hostname, like this:

```
$ ftp ftp.tux.org
Connected to gwyn.tux.org.
220 ProFTPD 1.2_Oprel0 Server (ProFTPD on ftp.tux.org) [gwyn.tux.org]
Name (ftp.tux.org:iball): anonymous
331 Anonymous login ok, send your complete e-mail address as password.
Password:

230 Anonymous access granted, restrictions apply.
Remote system type is UNIX.
Using binary mode to transfer files.
ftp>
```

Many remote servers and system administrators graciously allow anonymous login and retrieval of files from public directories. It is customary to enter your e-mail address as the password when logging in as an anonymous user. You can use the `ftp` command on your LAN if other computers are running an FTP server. This is one way to transfer files between different computers and operating systems.

Some important commands to use at the `ftp` command line are:

| Command | Description |
| --- | --- |
| `ascii` | Download the desired file as text. Note that you should not do this if you are downloading compressed archives, image files, or other binary information. |
| `binary` | Download the desired file in binary form. |
| `exit` | Log off and quit the `ftp` command. |
| `get file` | Retrieve designated file. |
| `mget pattern` | Get one or more files with names that match the pattern. |
| `mput pattern` | Send one or more files with names that match the pattern. |
| `prompt` | Toggle `mget` or `mput` yes and no prompting. If the command is off, then matching files are retrieved or sent without intervention. |
| `put file` | Send designated file from your current directory. |

Other clients you can use for retrieving files using FTP include the `ncftp` command and the `wget` command. The `ncftp` client features a graphical indicator of the download progress, while `wget` has the ability to retrieve entire directory trees of HTML files or FTP directories—a very handy way to quickly mirror, or copy, one or more Web or FTP sites.

## Graphical FTP Utilities

Combining the power of the `ftp` command with a graphical interface provides a great way to transfer files quickly and easily across computers on a LAN or over the Internet. This section introduces the `gftp` client, one of several graphical FTP clients you can use during your Linux, X, and Internet session to send or retrieve files.

Using `gftp` is easy. You can launch this command from the command line of an X terminal or menu item (if available) from your GNOME desktop panel menu. For example:

```
$ gftp &
```

After you press Enter, `gftp`'s main window will appear. You can then type in the name of a remote host, your username and password (or an anonymous name and e-mail address). When you press Enter, the client will appear as shown in Figure 9.26.

One of the great features of `gftp` is that it can be used to transfer entire directories of files. This is similar to using the `ftp` command's `mget` command; however, destination directories will be created automatically, and the task of transferring entire server sites can be reduced to a single mouse click!

The `gftp` client also features bookmarks. If you have favorite FTP sites for retrieving software, images, or other documents, then you can quickly navigate and log into the remote site using a menu item.

## Security Issues

This section provides a few hints and tips about safely conducting business on the Internet. Although millions of users happily traverse cyberspace each day, many users worry about privacy issues, credit card usage, and unwarranted intrusions into local computers.

Your e-mail address may be personal or work related, but it is a unique identifier that points to you. If you do a lot of Web browsing and visit a lot of different sites that require a login, password, and e-mail address, you may want to consider getting a “throwaway” e-mail address from a remote provider. This is an e-mail address that you can quickly abandon if you suddenly find yourself being bombarded by unwanted electronic mail.

There’s not much you can do about your work-related address, but dividing your e-mail sessions to keep mail separated between work and pleasure can be a good idea. Many employers frown on company servers and storage being used for personal reasons. You also take the risk of a friend unknowingly forwarding a risky message or attachment, which might get you into trouble.
