Like Sawfish, Enlightenment offers a series of shortcut keystrokes users can use instead of the mouse. The keystrokes are listed and controlled by e-conf's Shortcut dialog box.

## GNOME Clients for the Network and Internet

Like KDE, GNOME comes with a number of network- and Internet-related utilities, and you will find many additional GNOME-aware clients available over the Internet. This section introduces some of the more popular utilities you can use for system monitoring, transfer of files, and electronic mail.

### Network Clients

This section introduces two convenient network clients you use with GNOME during X sessions. If you would like to keep track of your system, you will find that these clients can help you with information about your computer.

To get detailed information about your computer, similar to Apple’s System Profiler, use GNOME’s System Info client. This client provides a quick way to get summary information about the current version of Linux in use, and detailed information about your system’s disk, memory, and CPU.

Launch this client by using the desktop panel’s menu. You will initially see a dialog box, as shown in Figure 11.7.

To get more detailed information, click the Detailed information button (as shown in Figure 11.7). You will then see a dialog box with Tabs for Disk Information,

Memory Information, and CPU Information. For example, click the CPU Information Tab, and you will see a listing in a dialog box (shown in Figure 11.8) that shows the type of CPU and, which Apple computer model is in use.

To graphically monitor your system’s activity, you can use the GNOME Stripchart Viewer. This small client can show how busy your CPU is, the System load (an average of activities), swap file usage, network activity, the PPP connection (if you have one), and the traffic activity on the current PPP device (usually *pppd*).

### Internet Clients

GNOME includes a number of Internet clients you can use during online sessions. Although many users turn to Netscape Communicator as a comprehensive solution for Web browsing, HTML editing, electronic mail, and Usenet newsreading, you may find some special-purpose GNOME clients easier and more efficient.

```
$ gftp &

When connected, you will see a list of the remote computer's files on the right. Click on a file or directory folder icon, then click an appropriate arrow button (left or right) between the two listings in the dialog box. As the transfer proceeds, you will see progress messages in the lower portion of the dialog box. Use gftp's menu to control the types of file transfers, refresh directory listings, set bookmarks, initiate transfers, log results, or get help.

Use GNOME's Balsa to handle electronic mail. Launch this client from the desktop's panel, or from the command line of an X terminal window like this:

```
$ balsa &
```

The first time you run Balsa, you will be taken through a series of set up dialog boxes. You will be asked for your name, e-mail address, SMTP server (usually localhost), and the location of a local mailbox (named mail in your home directory by default). You will then be asked to verify the locations of your inbox, outbox, sentbox, draftbox, and trash. When finished, click the Finish button to begin using the client.

After Balsa starts, click its Settings menu and select Preferences. If you retrieve mail from a remote ISP's server, click the Mail Servers tab and add your ISP's server settings by clicking the Add button (as shown in Figure 11.11).

When finished, you can click the Check button in Balsa's main window. Incoming mail will be located in your Inbox. Click the Inbox button on the left to view your messages, as shown in Figure 11.12.

## Installing Ximian GNOME

Browse to http://www.ximian.com for directions on how to download and install Ximian's fine-tuned distribution of GNOME for PowerPC Linux. At the time of this writing, Yellow Dog Linux and LinuxPPC 2000 Q4 Linux users are able to use Ximian's GNOME. SuSE PPC Linux users are still left out in the cold (hopefully this situation will change by the time you read this).

Ximian GNOME looks, acts, and feels like the port of GNOME that came with your PowerPC Linux distribution. However, there are a number of advantages to using Ximian GNOME, such as the ability to download and install the entire system using a graphical installer, online and automatic bug fixes and security updates, and access to the very latest of your favorite GNOME clients.

Start by logging in as root and downloading the Ximian installer like this:

```bash
$ lynx -source http://go-gnome.com/ | sh
```
