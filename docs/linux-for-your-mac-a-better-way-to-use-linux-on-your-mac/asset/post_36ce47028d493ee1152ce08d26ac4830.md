
This example shows the `efax` command running on the Apple TiBook. To send a fax, use the `fax` command and its `send` option, along the remote fax number and document name, like this:

The `fax` script takes care of dialing and converting your document into the proper format for transmission.

Many experienced Linux users carefully research equipment purchases with Linux compatibility specifically in mind. However, if you have a computer that is not fully supported by Linux, do not worry. This includes the G4 Cube, the latest Titanium PowerBooks, and the latest iBooks.

Your best bet in getting support for your equipment is to carefully monitor various PPC Linux-centric Web sites for details on how others using similar equipment have come up with solutions. As PPC Linux vendors improve distributions, support for newer machines will be added. Every new version of the Linux kernel brings additional support, and you are sure to find a number of computers on which all equipment works.

You should also use the various resources listed in the Appendix as starting points for more information. You can also get help from your local LUG (*Linux User Group*). Joining a LUG is the best way to learn more about Linux, gain exposure to new ideas, and talk with other users who may have similar equipment. The LUG experience is rewarding, and many LUGs sponsor talks, demonstrations, and Install Fests where new users can bring equipment and get Linux quickly installed and configured by experts.

## Chapter 4: All about Booting

![](img/1ea833f5a3e3c1547e3dd2891f52804a_88_0.png)

This chapter covers the installation, configuration, and use of various boot utilities for starting Linux on an Apple PowerPC. It is important to know what type of boot mechanism to use depending on the target platform if you have to replace a hard drive, reinstall Linux, or install Linux on a new computer.

Bootloaders can also be used for rescue operation, tweaking video and graphics hardware, or enabling certain features of the Linux kernel. Many PowerPC Linux users simply install a bootloader and then happily conduct business on their systems. More advanced PowerPC Linux users, however, try to get the most out of their systems and are more successful in overcoming obstacles when problems arise.

The good news is that you can configure your PowerPC Mac to properly boot to either Linux or Mac OS without problems, and you do not have to master arcane technical skills that you will only need to use once or twice. Once armed with more information, you should never have a problem and you may learn a little troubleshooting.

### Choosing a Boot Method

Your choice of boot method depends primarily on the type of Apple Macintosh model on hand. Although some Apple PowerPC computers can use BootX and Yaboot (such as early iBooks), benefits will generally be obtained by using the more proper bootloader in order to either install or run Linux.

The following general rules apply:

- If your Macintosh is an “OldWorld” PowerPC Mac, use the BootX Control Panel.
- If your Macintosh is a “NewWorld” PowerPC Mac, use the Yaboot kernel loader.
- If your Macintosh can use either BootX or Yaboot, use Yaboot instead.

### What’s the Difference?

Earlier Macintoshes used a ROM (*Read-only Memory*) chip, called the ToolBox ROM. This ROM chip held various parts of the Mac OS and was used not only to boot the computer, but also to support graphics and other operations while the computer was in use. Starting in late 1999, Apple changed this approach and removed this information from the ROM.

The new approach, labeled *NewWorld Architecture*, positions Mac OS boot code and system software into two parts, with some boot code in a ROM called the Boot ROM, and system software support routines in a file called a ToolBox ROM image. The Boot ROM contains a FORTH language interpreter, started by software called Open Firmware.

Therefore, PowerPC systems that used a ToolBox ROM are labeled OldWorld Macs, while all newer Macs are NewWorld.

### Yaboot, lilo, or BootX?

NewWorld Macintoshes include models such as the Blue and White G3s and G4 Power Macs, PowerBooks, the iMac, and the iBook. OldWorld Macintoshes include pre-iMac (beige) Power Macs. For information regarding compatibility of specific models, or PreP and CHRP PowerPC computers, browse to your Linux distributor's Web site.

The following sections introduce the commonly used software tools you can use to set up a dual-boot Mac OS and PPC Linux system. Currently, booting Linux on the PowerPC platform almost always involves the need to have at least one Mac OS partition, and the initial use of Mac OS to partition the system's hard drive. This is unlike Intel-based PCs, which most often use a boot loader embedded in the Master Boot Record of the first IDE hard drive.

### Configuring BootX

BootX, created by the extraordinary Mac and Linux programmer Benjamin Herrenschmidt, is a Mac OS Control Panel that provides a graphical boot loader interface to boot Linux or Mac OS. To use this software, download or copy the BootX distribution (shown in Figure 4.1) to your Mac OS Desktop.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_90_0.png)

Figure 4.1 The BootX Control Panel is used to boot Linux or Mac OS on OldWorld and some NewWorld Power Macs.

To install BootX, drag the BootX Control Panel and BootX Extension to your Mac OS System Folder. The Control Panel is placed in the Control Panels folder, while the Extension file is placed in the Extensions folder. Next, copy the folder named Linux Kernels to your System Folder. This folder can hold different versions of the PPC Linux kernel, and is useful for testing new kernels when using Linux.

BootX is used to enable a Linux installation, and after installation, to choose between booting Linux or the Mac OS, to choose a proper Linux kernel, to set proper video settings, and to pass kernel *arguments*, or boot messages (similar to those at the LILO boot: prompt for Intel-based Linux users).

Use BootX’s Kernel pop-up menu to choose a Linux kernel. Any Linux kernel placed in the Linux Kernels folder in your System Folder will be listed (BootX, however, will also look for a kernel named vmlinux in the System Folder). The Root Device field should contain the partition number of your root Linux partition. For example, if the Linux PPC 2000 Q4 installer reports that your root partition is */dev/hda12*, enter *hda12* in the Root Device field.

The More kernel arguments field is used to pass arguments to the Linux kernel for use when Linux boots. These arguments can range from video device settings to *runlevels*, or Linux system states.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_91_0.png)

> If you use BootX, you do not need a copy of the Linux kernel in the /boot directory.

For example, if you would like to boot PPC Linux to runlevel 1, or system-maintenance mode (with networking, multi-users, and X off), use the keyword *single* in the argument field. Linux will boot to the root prompt. If you are an iBook user with a one-button ADB mouse, you can use *adb_buttons=103,111* which sets the F11 and F12 keys to the middle and right mouse buttons (USB users use a different approach).

Video options may look something like:

```
video-attyb:vmode:18,cmode:16
```

In this example, the Linux kernel is being told to use a type of video (framebuffer) at a resolution (*vmode*) of 1152x870, with a colordepth (*cmode*) of thousands of colors. The valid range for *vmode* settings is 5, 6, and 10 through 20, representing resolutions of 640x480 up to 1280x1024. Valid *cmodes* are 8, 15, 16, 24, and 32 (ranging from 256 colors through millions of colors).
