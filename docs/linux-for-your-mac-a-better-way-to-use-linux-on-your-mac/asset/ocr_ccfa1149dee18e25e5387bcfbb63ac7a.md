GNOME offers nearly all the features of a modern graphical interface, and is covered in more detail in Chapter 11, “Using GNOME and X11.”

# ## Ximian

The Ximian GNOME desktop is nearly identical to the GNOME desktop. However, **Ximian GNOME** (formerly known as Helix Code's GNOME) is available for automatic download and upgrade via the Internet. Installation takes place by downloading a graphical installer. After the download and installation of nearly 130 different software packages, Ximian GNOME presents a polished GNOME interface that uses the *sawfish* window manager (as shown in Figure 7.4).

Ximian GNOME is available for a number of PowerPC Linux distributions, such as Linux PPC 2000 Q4 and Yellow Dog Linux 2.0 and Champion Server 1.2. It is not, however, available for SuSE PPC Linux (at least at the time of this writing).

# ## KDE

KDE hosts features such as session management, drag and drop, and other features found in modern desktop interfaces.
