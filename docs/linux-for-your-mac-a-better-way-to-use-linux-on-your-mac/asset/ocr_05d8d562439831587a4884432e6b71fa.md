Next, click the Mail Servers menu item, select the existing server, and then click the Edit button. You will see a dialog box, as shown in Figure 9.14, which you can use to enter the mail server information from your ISP.

Enter the name of your ISP's mail server. This is the name of the mail server from which you will retrieve mail. The mail server may have a name beginning with pop, which stands for Post Office Protocol (other mail servers may use the Internet Message Access Protocol, or IMAP). Click the OK button when done, and then enter the name of your ISP's outgoing mail server. This mail server may have a name beginning with smtp, which stands for the Simple Mail Transfer Protocol. You will also need to enter your username. When finished, click the OK button.

You can now launch the Messenger component of Communicator either through the command line or by using the Messenger menu item under the Communicator menu in any Communicator component. When Messenger appears, click on the Get Msg box. You will then see a dialog box, as shown in Figure 9.15.

Messages will be retrieved and a list of the incoming messages will appear in a field in the Messenger window. Click on a message to read it, and you will see a dialog box as shown in Figure 9.16. You can then click on the various buttons in the Messenger window to reply, forward, file, print, or delete the message. After composing a reply, use the Send Msg button to send the message.

> Make sure to use the Mail & Newsgroups' Formatting Preferences item to ensure that your messages are sent in text form, especially if you plan to post on Usenet (discussed next). Posting messages as HTML is a big No-no on Usenet, and many Linux users will refuse to respond to electronic mail sent as HTML.
