
## AbiWord Personal

AbiWord is a free, open-source word processor that works on various computer platforms. This client, which requires an active X session, has many desired features present in modern-day word processors, but may also be used to edit text files. You can apply many different styles and formats to your text while editing, and AbiWord also has the ability to align text, perform spell-check, and convert word processing documents from other systems into text.

You will find that AbiWord is included with most Linux PPC distributions. You can use this word processor to perform many essential text editing tasks. You can start abiword from the command line with an optional text filename like this:

```bash
$ abiword linusprc.txt &
```

After you press Enter, you will see abiword’s main window, as shown in Figure 6.7.

This word processor should not be used to edit system configuration files, which are subject to breaking if reformed by line-wrapping in an editor. You can, however, adjust and control line-wrap in abiword by using the Format menu’s Paragraph menu item.

## KDE and GNOME Text Editors

The KDE and GNOME software suites include a number of graphical text editors you can use during your X sessions. These editors vary in features and reliability but have steadily matured over the last several years. Each new version of these editors introduces new features and capabilities.

These clients will generally be launched via the KDE or GNOME desktop panel. Table 6.2 lists each editor’s name and a short description.

The benefits of using these text editors during an X session is that many are drag-and-drop aware, work well in their designated environment (KDE or GNOME), and come with built-in help.

### Using nedit

The nedit text editor is a graphical client for X11. This program has nearly every feature a system administrator, writer, or programmer desires in a text editor. Included with many Linux distributions, nedit provides extensive menus, line-number display, import and export of DOS-format text files, handling of international character sets, macros (compressed procedural shortcuts), sorting, electronic mail handling, programming environment features, and more.

You can start nedit from the command line with an optional text filename like this:

```bash
$ nedit linumpr.txt &
```

After you press Enter, you will see nedit’s main window, as shown in Figure 6.8.

## Applix for Linux

The Applix office suite, available from VistaSource, is a relatively inexpensive software package for the X Window System that provides a database, email, spreadsheet, graphics, and of course, a word processing program. The software, which requires a serial number, must be purchased and installed on your system before use, and runs on many different operating systems including Intel and PowerPC-based Linux systems.

Using the graphical editing component of Applix, known as Words, is easy. You can start the word processor by clicking on the Applix toolbar window, or from the command line like this:

```bash
$ applix -wp
```

After you press Enter, you will see the Applix Words window, as shown in Figure 6.9. You can create text documents using Words, but you will then need to use its File menu's Export menu item to export the document as text. Using Words can be a handy way to convert other word-processing documents into text form.

## Spell Checking

The ability to check spelling within documents is important for everyone. Sharing text or publishing documents with misspellings can be harmful to one's reputation, and can detract interest from the content of one's writing. Spell-checking is a required feature for many commercial word processing or office suite packages.

Fortunately, every Linux distribution comes with two or more free spell-check programs. These include the spell filter command, the dictionary look command, and the interactive ispell program. They also come with one or more 45,000- and 100,000-word dictionaries, usually found under /usr/dict or /usr/share/dict directory with the filename words. The spell check ispell, can be found under the /usr/lib/ispell directory.

Commercial UNIX operating systems, such as those derived from AT&T's System V, have traditionally included the spell and look commands. As originally designed, both commands use the system dictionary words as the basis for comparing, cross-referencing and lookups. For example, to quickly look up the spelling of a word, use the look command, followed by a partial spelling of the desired word, like this:

```bash
$ look gira
giraffe
giraffes
```

After you press Enter, the ispell command searches the system dictionary and displays matching words. On the other hand, the spell command is designed to display words in a given text file or stream that do not match. You can use the spell command interactively like this:

```bash
$ spell
giraffe
<EOT>
```

In this example, after you press Enter, the word giraffe is typed. After pressing Enter, type a Ctrl+d (the end-of-text marker), and the spell command will respond with:

```bash
giraffe
```

This indicates that the word is either misspelled or not in the system dictionary. If no word is echoed, the word is correct. As you can see, the spell command returns non-matching words. For example, to check the contents of a document such as linumpr.txt, you can use the spell command on the command-line with input redirection and other commands in a pipe like this:

```bash
$ spell < linumpr.txt | sort | uniq >misspelled.txt
```

This command line pipes the output stream of misspelled words in the document through the sort and uniq commands and saves the result in a file named misspelled.txt. You can then use the sed command or a text editor to fix the file. Spell checking documents interactively and fixing errors in context is, however, a much easier way to correct misspelling. That is the job of the ispell command, discussed next.

> **Note:** SuSE Linux includes the ispell command, but does not provide a spell command. However, you can use the ispell command to emulate spell. Create a shell script containing these lines:
> ```bash
> #!/bin/sh
> exec ispell -1 $*
> ```
> Save the file with the name spell, then use the chmod +x command to make the script executable and save it under the /usr/bin directory.

### Using ispell

The ispell, or International Ispell command, is an interactive spell-check program for Linux and a number of UNIX operating systems. This program is included with nearly every Linux distribution, and supports 24 languages. It is also a speedy and efficient screen-oriented spell check that shows errors in context, displays suggested replacement words, and then corrects your file.

The languages supported include: Afrikaans, Belarusian, Catalan, Czech, Danish, Dutch, English, Esperanto, Finnish, French, German, Greek, Hebrew, Italian, Irish, Norwegian, Polish, Portuguese, Romanian, Russian, Slovenian, Spanish, Swedish, and Ukrainian.

ispell is also supported by pico, emacs, and xemacs editors. You can use the menus in the X versions of GNU emacs and xemacs to start a spell-check session, or press Ctrl+Alt+x, then type one of the following:

- `ispell-buffer`: Spell-check the current document.
- `ispell-region`: Spell-check highlighted or marked block of text.
- `ispell-word`: Spell-check a word.

After you press Enter, the editors will use ispell for spell checking. To use ispell to check the spelling of a file, specify the file's name on the command line like this:

```bash
$ ispell linuxpr.txt
```

The program will then begin, as shown in Figure 6.10.

After you press Enter, ispell will highlight the first misspelled word. If there are several suggested replacements, you can type the number of the suggested word. You can also manually fix the word by tapping the r key. If you tap the i key, ispell will accept the word as is and continue to the next suspect word.
