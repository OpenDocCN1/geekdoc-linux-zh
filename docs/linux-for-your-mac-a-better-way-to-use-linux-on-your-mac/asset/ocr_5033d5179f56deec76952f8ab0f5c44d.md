You will next need to set the client’s default preferences (for the device, speed, and PDA username) by using the File menu’s Settings menu item. You can then use the Backup or Restore File menu items to save or restore your PDA data.

# Using JPilot

The *jpilot* client, by Judd Montgomerie, is part of a suite of graphical clients for Linux, X, and your Palm PDA. It is a comprehensive and sophisticated backup and syncing tool that picks up where *kpilot* has stopped.

To use *jpilot*, launch the application from the command line of an X11 terminal window like this:

```
$  jpilot &
```

After you press Enter, you will see the *jpilot* window as shown in Figure 12.21.

As with *kpilot*, you will first need to set communications preferences, such as the name of the PDA device (most likely a symbolic link named */dev/pilot*), along with baud rate for the information transfer. To do this, click the File menu, and then click the Preferences menu item. You can also press Ctrl+e. You will then see a dialog box, as shown in Figure 12.22.
