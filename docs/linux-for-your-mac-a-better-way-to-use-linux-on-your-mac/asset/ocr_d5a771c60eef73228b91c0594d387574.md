+     - Shade or un-shade a window (double-click a window’s titlebar to use a windowshade effect)
+   - Ctrl+Alt+Right Cursor
+     - Jump to next workspace
+   - Ctrl+Alt+Left Cursor
+     - Jump to previous workspace
+   - Ctrl+Alt i
+     - Iconify current window
+   - Ctrl+Alt k
+     - Kill current window
+   - Ctrl+Alt x
+     - Close current window
+   - Alt+Shift+Down Cursor
+     - Jump to workspace below current desktop
+   - Alt+Shift+Up Cursor
+     - Jump to workspace above current desktop
+   - Alt+FX
+     - Jump to desktop X
+   - Alt+Tab
+     - Set focus to next window

If you do not want to use e-conf to configure Enlightenment, simply use Enlightenment’s configuration dialog boxes. These dialog boxes are accessed by right-clicking a blank area of the desktop and selecting items from a Settings menu.
