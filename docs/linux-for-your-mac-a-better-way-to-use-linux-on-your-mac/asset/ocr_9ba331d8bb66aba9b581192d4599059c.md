# Applix for Linux

The Applix office suite, available from VistaSource, is a relatively inexpensive software package for the X Window System that provides a database, email, spreadsheet, graphics, and of course, a word processing program. The software, which requires a serial number, must be purchased and installed on your system before use, and runs on many different operating systems including Intel and PowerPC-based Linux systems.

Using the graphical editing component of Applix, known as Words, is easy. You can start the word processor by clicking on the Applix toolbar window, or from the command line like this:

```
$ applix -wp
```

After you press Enter, you will see the Applix Words window, as shown in Figure 6.9. You can create text documents using Words, but you will then need to use its File menu's Export menu item to export the document as text. Using Words can be a handy way to convert other word-processing documents into text form.
