
key, the suspect word is added to a file named `.ispell_english` in your home directory, and becomes your personal dictionary (you can always edit this file later on if you add a truly misspelled word). The `u` key adds a lowercase version of the suspect word to your dictionary. The `q` key will quit without making changes, and the `x` key saves your changes and quits. To get a quick help screen, tap the question mark (`?`).

You can also use ispell to interactively check or look up individual words by using its `-a` command-line option.

Multiple documents can also be checked by specifying an expression on the command line like this:

In this example, all files beginning with `my` and a `.txt` extension will be checked. You can learn more about ispell, including how to build your own dictionaries, by reading its manual page and documentation.

## Dictionary Lookups

As you have seen, Linux comes with utilities you can use to quickly verify the spelling of a word, based on the system dictionary. However, you will also find other utilities that can help you not only check the spelling of a word, but also its definition, synonyms, antonyms, and usage. Although this function is available from various Web sites on the Internet, using them requires an active browser, such as Netscape Navigator, which may not be convenient. The following section introduces two graphical clients included with KDE and GNOME that you can use to directly query online Internet dictionary databases.

## Checking Grammar and Readability

Few text editors or word processors (with the exception of Corel's WordPerfect 8 for Linux) include the ability to check the grammar of text files. However, you can get new versions of two legacy UNIX tools, style and diction, from the GNU software project. Michael Haardt's version of these tools supports English and German, and can be used to check the readability and style in your documents.

You can download and install these utilities quite easily. After downloading, use a command line like this (as the root operator):

```bash
# tar xzf diction.gz ; cd diction ; ./configure ; make install
```

The files will be installed in the `/usr/bin` directory. To use diction, specify the name of the file you would like to check, like this:

```bash
$ diction linuxpr.txt
```

```
linuxpr.txt:70: The Linux user has access to an entire global community with [its -> "it is" or "its?"].
Wealth of knowledge and [its -> "it is" or "its?"]. Invaluable venue for the exchange of information.

linuxpr.txt:74: Yet it is the [nature -> Omit if redundant.] of Linux open-forum business model that GartnerGroup and others believe [could -> (do not confuse with "may")]. Harm Linux's chance of becoming a mainstream, general-purpose NOS.
```

After you press Enter, the diction command will print diagnostic information, pointers, tips, and suspect text. You can redirect the output of the program to a pager, such as less, or a file for later reading. The program may also be used interactively, like this:

```bash
$ diction
We should utilize our resources better.
(stdin):1: We should [utilize -> use] our resources better.
<EOF>
1 phrase in 1 sentence found.
```

In this example, you type in a sentence after pressing Enter. If diction detects suspect phrases or wordiness, you will see a response after you press Enter at the end of the sentence. When finished, press Ctrl+C or Ctrl+D to end the session.

The style command is used to check the readability of text. This program analyzes your writing style, then applies a number of readability benchmarks and prints a report. For example, to check the readability of one of your documents, use the `style` command like this:

```
$ style linuxpr.txt
readability grades:

  Kincaid: 12.1

  ARI: 13.4

  Coleman-Liau: 13.6

  Flesch Index: 48.5

  Fog Index: 15.0

  WSTP Index: 2.9

  Wheeler-Smith Index: 33.7 = school year 8

  Lix: 52.4 = school year 10

  SMOG-Grading: 13.1

sentence info:

  10651 characters

  2136 words, average length 4.99 characters = 1.60 syllables

  94 sentences, average length 22.7 words

  41% (39) short sentences (at most 18 words)

  14% (14) long sentences (at least 33 words)

  31 paragraphs, average length 3.0 sentences

  3 questions, 15 imperatives

  longest sent 53 wds at sent 91; shortest sent 1 wds at sent 42
```

In this example, the report indicates that the text is quite easily read, but could be improved or perhaps aimed at a higher-level audience. The `style` command has other command-line options you can use to generate custom reports about text. In order to understand any report, you will definitely need to read its manual page for more information about the readability indexes and formulas.

## Introduction to Printing

There are a variety of line-printer spooling systems available for Linux. Although you can set up KDE and GNOME to support drag-and-drop printing, you should also understand how to use the Linux printing system from the command line. Without this knowledge, you may find it difficult to print during console and text-only sessions, or to use many of the X clients for printing.

Many Linux distributions use a print spooling inherited from BSD UNIX that uses a daemon named `lpd` to spawn printing processes in response to a print request. As you learned in Chapter 3, "Post-Installation Configuration," the `lpd` daemon uses definitions in your system's printer capabilities database for printer names, location, paper size, filtering, and so on.

This section introduces you to the basics of starting, stopping, and managing your printing tasks with the BSD line-printer spooling system.

## Other Printing Systems

There are other printing systems available for Linux, primarily on other computer platforms, such as Intel-based PCs. Patrick Powell's LPng print service is a security enabled, network printing system included with many popular distributions. Another printing system is the Common UNIX Printing System, or CUPS. CUPS has the advantage of being distributed under the GNU GPL, unlike all other printing systems for Linux, and is available for a variety of distributions, including PPC Linux.

## Starting a Print Job

Print jobs are started at the command line using the lpr command. The lpr command has a number of command-line options, but in its simplest form may be used to send a document to the default system printer like this:

```
$ lpr mydocument.txt
```

In this example, after you press Enter, the document will be spooled to your personal printing directory (under the `/var/spool/lpd` directory). The lpq command, which checks the directory for new jobs, will then spawn a printing process and send the document to the printer. You can also use `lpr -P` option, followed by a printer's name, to send a job to a specific printer, like this:

```
$ lpr -P remote1p mydocument.txt
```

In this example, the print job will be sent to the printer named remote1p (and in this case, a printer attached to a different computer on the network). The lpr command can also use input redirection. Using the previous style command as an example, you can send the readability report directly to a specific printer like this:

```
$ style linuxpr.txt | lpr -P mp400
```

In this example, the report will be printed on the printer named mp400.
