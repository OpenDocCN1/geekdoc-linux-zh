This window manager may be used with or without GNOME, and recent versions include many unique built-in desktop environment features. Themes are one of the main attractions. Literally thousands of Enlightenment themes are available for download from various Internet sites.

## Window Maker

The Window Maker window manager, like AfterStep, provides a wharf, root desktop menus, and virtual desktops, which are accessed by clicking on a pager in the upper-left corner of the root display. Two unique features are a configurable application dock, and the ability to place floating menus on the root desktop. You will also like its wealth of *applets*, or small applications that are active and useful, but compressed into icons—a feature highly desired by Linux laptop users!

System-wide configuration files are located under the /usr/X11R6/share/wmakerconf directory. User defaults are stored under the GNUstep/Defaults directory in a user’s home directory. Window Maker also supports different styles and themes.

## Starting an X11 Session

After you install Linux on your Macintosh, you will probably launch directly into an _X_ session. When the screen clears, you will be at the login prompt of an _X_ display manager. This is an X client that requests a username and password in order to use X and Linux. Several display managers are available for XFree86 and PowerPC Linux distributions. These include the XFree86 display manager xdm, KDE's K display manager, called kdm, and GNOME's gdm.

However, another way to start an X session is with a shell script named startx. The startx command offers a lot of flexibility and command line options. This section describes how to use startx to launch your X session.

## Using the startx Command

The startx client uses the xinit client to launch your X session. This client first looks for a file named .xinitrc in your home directory, which can contain a customized X session with designated clients and a specific window manager. A default .xinitrc file named xinitrc is installed under the /etc/X11/xinit directory. Under Suse Linux, a default .xinitrc file is installed under each user's home directory, and contains logic to support the launching of different window managers. The file (a shell script) looks something like this:

```bash
if test -z "$WINDOWMANAGER" ; then
    if test -x /usr/X11R6/bin/kde ; then
            WINDOWMANAGER=/usr/X11R6/bin/kde
    elif test -x /usr/X11R6/bin/startkde ; then
        WINDOWMANAGER=/usr/X11R6/bin/startkde
    elif test -x /usr/X11R6/bin/fvwm2 ; then
        WINDOWMANAGER=/usr/X11R6/bin/fvwm2
    elif test -x /usr/X11R6/bin/wmlist ; then
        for i in `/usr/X11R6/bin/wmlist` ; do
            WINDOWMANAGER=`type -p $i`
            test -n "$WINDOWMANAGER" && break
        done
    fi
fi
fi
```

...

This logic, which is not supported by other Linux PowerPC distributions, allows the user to specify a desired window manager in the startx command line like this:

```bash
$ startx wmaker
```

However, a sample .xinitrc file could instead contain the following:

```bash
xsetroot -solid lightblue
rclock -fg white -bg blue -geometry 100x100-5+5 &
xcalc -geometry -155+5 &
rxvt -geometry 80x50-5+15 &
exec twm
```

Using these settings, the desktop background will become light blue, a clock will appear in the upper-right corner of the display with a calculator along with an X11 terminal window that is 80-characters wide and has 50 lines. The twm window manager is used for the X session.

The startx command is then used to launch the X session like this:

```bash
# startx
```

After you press Enter, the twm desktop will appear as shown in Figure 7.14.

You can also use the startx command to specify different color depths and font resolutions. For example, to start an X11 session with XFree86 version 4.0 or greater (using 256 colors and 100 dots per inch), use the command along with the -depth and -dpi option and a number representing the number of color bit planes and resolution, like this:

```bash
# startx -- -depth 8 -dpi 100
```
