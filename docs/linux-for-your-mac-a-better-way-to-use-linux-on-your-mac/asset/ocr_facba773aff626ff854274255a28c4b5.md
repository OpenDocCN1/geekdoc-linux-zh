# ## Managing Resources

When you use Linux on your Macintosh as a stand-alone workstation, you are the only system administrator, root operator, user, and you also have access to the entire system’s resources. No one will be looking over your shoulder to check on how much disk space, memory, or other system resources you are using.

However, when Linux is used on a Macintosh as a server or multi-use workstation to provide support for numerous users, the system administrator must occasionally step in or have pre-defined rules of use for the system. If CPU or RAM resources are valuable, limits may need to be placed on users who want to rip audio CDs or conduct program development work using multiple instances of the *gcc* compiler. If hard drive space is at a premium, downloading entire CD-ROMs of data can pose a problem. Such actions can quickly exhaust resources for other users, and is certainly not fair.

As root, you can impose limits on your users through the use of CPU priority programs such as *nice* and *ulimit* settings in *bash* (to control file size, number of processes, and pipe size), and disk quotas (to control storage use). Setting disk quotas can sometimes be necessary, especially if you have many users sharing limited drive space.

# ## Quotas

Enabling disk quotas is easy. As with other services, quota enforcement may be started, stopped, restarted, or queried through the use of system initialization scripts. Under SuSE PPC Linux, *yast* may be used to set quotas, with the settings saved in the /*etc/rc* .config directory. A script named *quota* is used under the /*sbin/init* .d directory to start the service at boot time.

Under Linux/PPC 2000 Q4, quota use is determined by the /*etc/rc.d/rc*.sysinit script. With both Linux distributions, quota use can be controlled for groups or users through the use of files named *quota.group* *or* *quota.user*. However, you will also need to include an *usrquota* *mount* *command option* in your system’s filesystem table. For example, the original entry may look like this:

/dev/hda12 / ext2 defaults 1 1

To enable quotas, change the entry to look like this:

/dev/hda12 / ext2 defaults,usrquota 1 1
