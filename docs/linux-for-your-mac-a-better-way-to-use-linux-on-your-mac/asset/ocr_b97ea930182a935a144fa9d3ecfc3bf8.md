# KDE Clients for the Network and Internet

Although you can be quite productive using KDE and its clients on a stand-alone workstation, you will find that KDE comes with a wealth of network- and Internet-related utilities. This section introduces some of the more popular utilities you can use during on-line sessions. These clients may be used for monitoring, file transfer, chatting, electronic mail, news reading, and browsing.

# Network Clients

This section introduces two convenient network clients you can use with KDE during your X sessions. If you are a casual Internet user or a system manager who wants to keep track of what is going on, or coming into or out of a workstation, these clients will help.

The ksysguard client is a basic performance monitor and task manager that works by tracking processes running in your system’s memory. This information is then displayed in a custom grid you design (such as the one shown in Figure 10.13), using drag and drop of various “sensors.” One such sensor displays the number of sent or received kilobytes over a specified Ethernet interface. Launch the ksysguard client from the command line or by using the desktop panel’s menu.

The kwftpd client is an administrative utility that provides a graphical interface to administering your system’s /etc/ftpaccess file, use for File Transfer Protocol, or FTP service. This client (as shown in Figure 10.14), should only be run by the root operator.
