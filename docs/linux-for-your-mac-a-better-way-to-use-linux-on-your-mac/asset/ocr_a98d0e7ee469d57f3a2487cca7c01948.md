This chapter covers the installation, configuration, and use of various boot utilities for starting Linux on an Apple PowerPC. It is important to know what type of boot mechanism to use depending on the target platform if you have to replace a hard drive, reinstall Linux, or install Linux on a new computer.

Bootloaders can also be used for rescue operation, tweaking video and graphics hardware, or enabling certain features of the Linux kernel. Many PowerPC Linux users simply install a bootloader and then happily conduct business on their systems. More advanced PowerPC Linux users, however, try to get the most out of their systems and are more successful in overcoming obstacles when problems arise.

The good news is that you can configure your PowerPC Mac to properly boot to either Linux or Mac OS without problems, and you do not have to master arcane technical skills that you will only need to use once or twice. Once armed with more information, you should never have a problem and you may learn a little troubleshooting.

# ## Choosing a Boot Method

Your choice of boot method depends primarily on the type of Apple Macintosh model on hand. Although some Apple PowerPC computers can use BootX and Yaboot (such as early iBooks), benefits will generally be obtained by using the more proper bootloader in order to either install or run Linux.

The following general rules apply:

+   - If your Macintosh is an “OldWorld” PowerPC Mac, use the BootX Control Panel.
+   - If your Macintosh is a “NewWorld” PowerPC Mac, use the Yaboot kernel loader.
+   - If your Macintosh can use either BootX or Yaboot, use Yaboot instead.

# ### What’s the Difference?
