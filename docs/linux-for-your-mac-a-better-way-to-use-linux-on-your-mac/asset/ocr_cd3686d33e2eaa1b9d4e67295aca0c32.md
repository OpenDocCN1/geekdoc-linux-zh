# Linux, X11, and the Palm PDA

The Palm PDA has always been supported under Linux because of 3Com's, and later Palm Computing's willingness to share information about the Palm PDA platform with developers. This is in direct contrast to another commercial platform whose manufacturer is just starting to "get it." PDAs are becoming as ubiquitous as the small address book or day planner, and you can pick up a relatively inexpensive handheld device with an easy-to-use interface for less than $200 (US). Because Palm Computing does "the right thing" by sharing platform and operation system information, the Palm (and Handspring) PDAs rule the hand- held industry with a greater than 80 percent market share.

# Linking with the pilot-link Suite

The pilot-link suite of utilities is the definitive and easy-to-use software for backing up, restoring, or syncing a Palm-type PDA with Linux. You will find this soft- ware included with nearly every Linux distribution. You can use the software to handle nearly any type of Palm OS file, such as programs or databases.

To get started, first create an environment variable named PILOTRATE like this (if you are using the bash shell):

```
$ export PILOTRATE=57600
```
