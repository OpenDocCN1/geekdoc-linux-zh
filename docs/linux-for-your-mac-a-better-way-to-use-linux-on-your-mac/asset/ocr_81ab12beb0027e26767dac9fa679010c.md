# Remote Launching of Clients

By combining proper access permissions and use of the `DISPLAY` variable, you can also launch a local client and have it available for use on a remote display. Use the -
`display X` Toolkit option, along with the remote computer's display name like this:

```
[bbail@cube] $ xcalc -display cello:0.0 &
```

In this example, the user `bbail` has launched the X calculator, `xcalc`, which will appear on the display attached to the host named `cello`. As you can see, using X on a network can be fun, flexible, and a great way to accomplish work.
