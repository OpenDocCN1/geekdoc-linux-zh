Note that gcal marks the current day automatically. If you use the -n or -N options, you will see a list of holidays. The gcal client has many additional features, including the ability to automatically e-mail notifications of holidays or other functions according to holiday lists and other files stores under the /usr/share/gcal directory.

Of course, you can use cal and gcal during your X sessions by running them in a terminal window. What if, however, you want a small, floating calendar in a window? In this case, you can use the power of the Linux shell to combine the output of one of these calendar commands with the input and display of an X client named xmessage.

The xmessage client, by Chris Peterson and Stephen Gildea, is a simple echo-based windowing client. This means that you can put nearly any message in an X window using this program. xmessage will read its input from a file, the command line, or the output of any program. For example, to quickly create a floating calendar, pipe the output of the gcal command into xmessage, like this:

```
$ gcal | xmessage -file - -title "Calendar" &
```

The -file option specifies where to take the input for the xmessage window. In this case, it is the standard input (specified by -). The -title command-line option allows you to specify a title for the xmessage window. After you press Enter, you will see the calendar window appear, as shown in Figure 12.2.

By combining scheduling features of other appointment programs, you can build calendar notification systems with a graphical interface quickly and easily. You are only limited by your imagination when using these programs!
