The Linux user-creation program commonly used with all Linux systems is the `useradd` command. If you have a user named Fred Smith, then use the `useradd` command, like this:

```
```
# useradd fsmith
```
```

Next, you should assign a default password to the new user using the `passwd` com-mand, like this:

```
```
# passwd fsmith
New password:
Re-enter new password:
Password changed
```
```

The new user “fsmith” will now have a directory named `/home/fsmith`, a designated login shell in `/etc/passwd`, and a new password.

> Do you have a big system, or need to create hundreds of new users? Use the `newusers` command, which uses a file containing a list of new users and passwords. See the `newusers` manual page for more information.

# Using userconf

The `userconf` component of the `linuxconf` client included with many Red Hat-based Linux systems (such as LinuxPPC 2000 and Yellow Dog Linux) may be used to create new users. Start the client (as root) from the command line, like this:

```
```
# userconf &
```
```

After you press Enter, click the **User accounts** button on the main window. A new dialog box appears. Click the **Add** button, and you will see a dialog box as shown in Figure 3.3.

Enter the login name and full name for the new user. Other settings may be left empty, because `userconf` will use system defaults. When finished, click the **Accept** button to create the new user.
