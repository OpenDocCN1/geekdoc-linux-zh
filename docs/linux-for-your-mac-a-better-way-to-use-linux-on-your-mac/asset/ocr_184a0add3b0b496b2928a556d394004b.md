Therefore, when you use Drive Setup remember to create:

+   • A Mac OS HFS+ partition (minimum of 800MB to 1GB).
+   • A small HFS (Linux boot) partition (about 32MB).
+   • A single Linux (type A/UX or Linux) partition (1.5GB or more).

Another approach would be to create:

+   • A Mac OS HFS+ partition (minimum of 800MB to 1GB).
+   • A small HFS (Linux boot) partition (about 32MB).
+   • A root Linux partition (type A/UX or Linux) (1.5GB or more).
+   • A swap Linux partition (type A/UX or swap) (128MB or more).

If you create a single Linux partition, you will need to repartition again during the Linux installation process. To avoid this, create any needed partitions ahead of time with Drive Setup.

To begin, reboot your Power Mac with its Restore CD-ROM. Hold down the e key while rebooting to boot from the CD-ROM. Next, start the Drive Setup application (found in the Utilities folder). Select your Macintosh hard drive, and click the Initialize button.

In the next dialog box, click the Custom Select button. The pop-up menu offers a variety of partitioning schemes, including a preferred Linux PPC setup. However, you do not have to choose this setup. Instead, select four partitions. Click and drag the first partition to size your HFS+ Mac OS partition. When finished, click on the second partition and drag to size it for your 32MB HFS Standard partition (you can also just type 32 in the Size field). After this, click in the fourth partition and size it for swap memory, which should be twice the amount of installed RAM. Make sure to assign it a type of A/UX swap. Finally, the fourth partition remains for Linux, and should be at least 1.5GB. Make sure to assign it a type of A/UX root. You should end up with the following:

+   • **Partition 1.** HFS+ partition (perhaps 800MB)
+   • **Partition 2.** HFS partition (32MB)
+   • **Partition 3.** A/UX root (for Linux)
+   • **Partition 4.** A/UX swap (for Linux swap)

When finished, click the OK button and initialize the hard drive. After the drive is initialized, two Mac OS volumes appear on the Desktop. Click the Restore software icon and restore your Mac OS system onto the HFS+ volume.

You are now ready to install Linux.
