# Stopping a Print Job

If you start a print job, then decide you would like to stop it, use the `lprm` command, followed by the number of the print job. In order to know the job numbers, use the `lpq` command to list the current queue of print jobs. For example, if you start a print job, the `lpq` command may report a queue list like this:

```
$ lpq
lp is ready and printing
Rank Owner Job Files Total Size
active bhall 4 linuxpr.txt 13558 bytes
```

You can kill the print job by using the `lprm` command, followed by the "Job" number like this:

```
$ lprm 4
dfA004\cube dequeued
cfA004\cube dequeued
```

After you press Enter, the names of the spooled files that have been deleted will be printed.

# Managing the Print Queue

In a multi-user environment, there may be many users and print jobs vying for a printer's attention, and lined up in the print queue. As the *root* operator, you can manage this queue and your system's printer(s) with the `lpc` and `lprm` commands. Since *root* is the *superuser*, the root operator may remove pending print jobs that are owned by anyone (normal users may only remove owned print jobs).

Although normally not needed on a standalone workstation, the `lpc` command may be used by *root* in a networked printer environment to disable or enable any system printer, rearrange the print queue, start and stop printing, and hold and release print jobs. See the `lpc` manual page for more information.
