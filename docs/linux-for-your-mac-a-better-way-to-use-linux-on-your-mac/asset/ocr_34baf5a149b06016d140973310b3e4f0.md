# ## Editing PATH

The **PATH** shell environment variable presents the pathnames of your system’s executable files to a user. You can quickly see your current **PATH** definitions by using the `printenv` or `env` command, along with the `fgrep` command like this:

```
`$ env | fgrep PATH` `...` `PATH=/usr/local/bin:/usr/bin:/usr/X11R6/bin:/bin:/usr/lib/java/bin:/usr/games/bin:/usrX/games:/opt/gnome/bin:/opt/kde/bin:/usr/openwin/bin:.`
```

Note that not all the **PATH** definitions are shown here. You may have one or more additional environment variables that define a particular **PATH** (such as the **MANPATH** variable, which points to various manual page directories on your system).

Commands on a Linux system are generally organized into directories according to use. For example, traditional user paths include `/bin`, `/usr/bin`, `/usr/local/bin`, `/usr/X11R6/bin`, and perhaps even `bin` in the home directory. Paths for the root operator usually include `/sbin`, `/usr/sbin`, and perhaps even `/usr/local/sbin`. Other paths may be defined and added to a user’s environment. This is especially helpful if software is installed elsewhere on your system, such as the `/opt` directory, a default location for software packages, or office suites such as Applixware or StarOffice.
