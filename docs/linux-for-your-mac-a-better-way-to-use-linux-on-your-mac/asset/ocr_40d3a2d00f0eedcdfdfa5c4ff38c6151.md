# # X11 Games

X includes a number of fun clients, such as strategy games, board games, and arcade games. Nearly all use graphics and sound, while some also feature music. Strategy games, such as board, puzzle, and solitaire games require thinking and logic. Other games, such as action arcades, may require manual dexterity. And a new form of game, the simulation strategy, may require both!

# ## Strategy Games

You will find a number of strategy games included with your PPC Linux distribution. These include graphical board games modeled in reality (such as backgammon or solitaire).

One of the legacy X card solitaire games is *xpat2*. This game provides 13 different card solitaire games. Start playing by using *xpat2* on the command line, like this:

```
$ xpat2 &
```

After you press Enter, you will see its card table, as shown in Figure 18.3.

Start game play by using the Rules menu. Use the Game menu to quit.
