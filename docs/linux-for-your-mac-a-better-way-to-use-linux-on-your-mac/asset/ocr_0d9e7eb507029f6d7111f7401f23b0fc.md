If you do not want to buy a boxed set of CD-ROMs from a PowerPC Linux vendor, you can download and create your own CD-ROMs, either from links via the vendor's Web page or through Linux CD-ROM image Web sites (i.e., http://www.linuxiso.org). Note that in some cases (i.e., when using LinuxPPC 2000) you will need to be able to create HFS formatted CD-ROMs, and/or be certain that the CD image is actually in the Mac OS Disk Copy image format. (This requires installation by booting from the current Startup Disk.)

Choosing a distribution to install can be a matter of personal preference, taste, economics, or bias. If you are an Intel-based PC user running a particular Linux distribution (i.e., SuSE), then choose a compatible PowerPC distribution. If you are completely new to Linux, each distribution has a lot to offer. The best way to choose a distribution is to read the comp.os.linux.powerpc Usenet newsgroup, and ask questions to determine which distribution works best with your computer.

# # Choosing Workstation or Server

Before installing Linux, you will have to decide how you want to use Linux on your Mac. Installations vary according to the amount of hard drive space you want to devote to Linux and how you plan to use your computer. The good news is that with the advent of ever-larger hard drives complementing today's PCs, you should have plenty of room. If, however, you use PowerPC for video editing you may be limited in hard drive space, even with one or more 30GB drives. There should be plenty of extra storage, even on a primary drive, to install a full Linux system.

When you install Linux to operate as a server, you will not need to install as much software. Linux and its host of networking software require only several hundred megabytes. Unless you plan to host an active Web site or a farm of FTP servers with lots of software and documents, two gigabytes of hard drive space is more than adequate. On the other hand, if you want to use Linux as a development platform, or workstation, you will need extra storage for temporary disk space, software libraries, documentation, and programming tools. If you have the storage and want to learn Linux, go ahead and install everything. This will save you the effort of having to return to your Linux CD-ROM(s) to install extra software or search for needed packages.
