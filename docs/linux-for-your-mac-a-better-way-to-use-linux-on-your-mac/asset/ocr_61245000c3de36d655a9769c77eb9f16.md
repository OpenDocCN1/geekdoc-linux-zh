# Checking Grammar and Readability

Few text editors or word processors (with the exception of Corel's WordPerfect8 for Linux) include the ability to check the grammar of text files. However, you can get new versions of two legacy UNIX tools, style and diction, from the GNU software project. Michael Haardt's version of these tools supports English and German, and can be used to check the readability and style in your documents.

You can download and install these utilities quite easily. After downloading, use a command line like this (as the root operator):

```
```bash
# tar xzf diction.gz ; cd diction ; ./configure ; make install
```
```

The files will be installed in the /usr/bin directory. To use diction, specify the name of the file you would like to check, like this:

```
```bash
$ diction linuxpr.txt
```
```

```
```
linuxpr.txt:70: The Linux user has access to an entire global community with [its -> "it is" or "its?"].
Wealth of knowledge and [its -> "it is" or "its?"]. Invaluable venue for the exchange of information.

linuxpr.txt:74: Yet it is the [nature -> Omit if redundant.] of Linux open-forum business model that GartnerGroup and others believe [could -> (do not confuse with "may")]. Harm Linux's chance of becoming a mainstream, general-purpose NOS.
```
```

After you press Enter, the diction command will print diagnostic information, pointers, tips, and suspect text. You can redirect the output of the program to a pager, such as less, or a file for later reading. The program may also be used interactively, like this:

```
```bash
$ diction
We should utilize our resources better.
(stdin):1: We should [utilize -> use] our resources better.
<EOF>
1 phrase in 1 sentence found.
```
```

In this example, you type in a sentence after pressing Enter. If diction detects suspect phrases or wordiness, you will see a response after you press Enter at the end of the sentence. When finished, press Ctrl+c or Ctrl+d to end the session.
