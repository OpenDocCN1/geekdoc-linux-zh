As a user, you will immediately know if the /sbin directory is not in your PATH. For example, try using the ismod command like this:

```
$ ismod

bash: ismod: command not found
```

Adding a new PATH to your existing PATH is easy. For example, if you use the bash shell, use its built-in export command like this:

```
$ export PATH=$PATH:/usr/local/bin
```

In this example, the /usr/local/bin directory is appended to the existing PATH variable. Be careful when redefining your PATH so that you do not lose the /bin or /usr/bin pathnames! However, if you do, simply log out and log back in (using the export command is not a permanent change). However, when making changes on a system-wide basis as root, you should carefully avoid making editing mistakes.

The system-wide PATH variables may be defined in various places, but the /etc/profile file is generally used on many systems. Under SuSE Linux, edit the /etc/profile.local file to add custom PATHS.

# ## Administering Groups

Groups are used on a Linux system to associate sets of users. You can use group identification to allow access to groups of users to different files. Groups are defined in the /etc/group file on your system, with default group membership assigned to the group named users (with a group ID of 100) for all new users.

As a SuSE system administrator, you can use the gpawsw command to create new groups and assign membership. This is because SuSE Linux uses a shadow group, which is a more secure group system than LinuxPPC 2000. Although groups are listed in /etc/group on a SuSE Linux system, membership to the groups is hidden in a root-owned file named /etc/gshadow.

On a LinuxPPC 2000 system, you can see the groups and members by simply examining /etc/group. This file may look like (in part):

```
root::0:root
bin::1:root,bin,daemon
daemon::2:root,bin,daemon
gys::3:root,bin,adm
adm::4:root,adm,daemon

wheel::10:root
```
