# Using the startx Command

The startx client uses the xinit client to launch your X session. This client first looks for a file named .xinitrc in your home directory, which can contain a customized X session with designated clients and a specific window manager. A default .xinitrc file named xinitrc is installed under the /etc/X11/xinit directory. Under Suse Linux, a default .xinitrc file is installed under each user's home directory, and contains logic to support the launching of different window managers.
