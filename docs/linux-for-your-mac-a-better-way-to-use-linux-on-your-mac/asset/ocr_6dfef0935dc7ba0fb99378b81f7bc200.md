If you use SuSE Linux PPC and have a one-button USB mouse (included on newer desktop Power Macs), the following commands sent to the Linux kernel USB driver enables F11 and F12 as the middle and right mouse buttons (as root, you can add these lines to your SuSE system’s /etc/rc.d/boot.1ocal1 file):

```
```
echo "1" > /proc/sys/dev/mac_hid/mouse_button_emulation
echo "87" > /proc/sys/dev/mac_hid/mouse_button2_keycode #F11
echo "88" > /proc/sys/dev/mac_hid/mouse_button3_keycode #F12
```
```

However, Apple TiBook users will find that pressing F12 by itself will not work for emulation as it is used for a media (CD-ROM) eject button. In this case, use the previous USB approach. In addition, map the middle and right mouse buttons to F10 and F11, like this:

```
```
echo "1" > /proc/sys/dev/mac_hid/mouse_button_emulation
echo "68" > /proc/sys/dev/mac_hid/mouse_button2_keycode
echo "87" > /proc/sys/dev/mac_hid/mouse_button3_keycode
```
```

> Yellow Dog Linux and TiBook users will find that the mouse-button and keyboard mapping is automatically configured. Pressing F11 during an X session emulates the middle mouse button. Pressing F12 emulates the right mouse button.

Using a three-button mouse may solve some problems when using X11. A typical entry for a three-button USB mouse in the system’s XF86Config file (which can only be edited by root) looks like:

```
```text
Section "Pointer"
    Device      "/dev/input/mice"
    Protocol    "IMPS/2"
EndSection
```
```

In this example the pointer should be properly recognized. However, using a scroll wheel mouse requires an additional setting to enable the scrolling, which must be added, like this:

```
```text
Section "Pointer"
    Device      "/dev/input/mice"
    Protocol    "IMPS/2"
    ZAxisMapping 4 5
EndSection
```
