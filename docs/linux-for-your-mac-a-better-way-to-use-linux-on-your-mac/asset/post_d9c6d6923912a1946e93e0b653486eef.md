This chapter introduces the basics of system administration for Linux using software and graphical administrative tools included with Linux distributions for the PowerPC. Why learn system administration? Because you have to! Whether you run Linux and X11 on your Mac as a workstation to take advantage of the benefits of the X desktop, or simply use your Mac as a server platform to host unique services—every system requires system administration. If you are the only one using your computer, you are the system administrator!

Does this mean that you have to put a lot of effort into the job? Of course not! However, you will have to learn and understand a few of the basic concepts, especially if you want to keep your system safe, secure, and stable. Macintosh computers running Linux, especially later models outfitted with modest RAM and larger hard drives, are quite capable of hosting hundreds of users. When functioning as a system administrator, it does not matter whether you have to handle one, 10, 100, or 1,000 users. The object is to ensure maximum uptime with minimum fuss, changes, or other inconveniences.

Experienced Mac users may initially have trouble understanding the capabilities that Linux provides for Apple hardware. As the owner and user of a Mac running Linux, you are in the driver’s seat when it comes to managing every running process or user logged into your system. The sooner you learn a modicum of skills, the faster you will be able to troubleshoot and fix problems.

Being a system administrator can mean being responsible for different tasks within different jobs. When using Linux on a Mac, however, you will discover that there are common skills shared by every owner. Typical system administration duties include:

- **Adding or replacing system hardware.** This can be as simple as adding a USB device or changing a printer, or as serious as surgery in hard drive replacement.
- **Configuring and controlling system services.** Do you need a running Web server? What do you do when users complain that they cannot telnet or FTP into your box? How do you control what services are enabled or disabled when using your Linux distribution?
- **Ensuring data integrity.** Devising regular backups, a backup schedule, or even performing a backup can save hours of work and loads of grief over lost data.
- **Ensuring system security.** Do you want anyone to be able to access your system? What steps can you take to make your system safe from intruders?—Especially if your computer connects to the Internet.
- **Managing system software.** When the time comes to remove old software and install new packages, knowing what to do can save a lot of trouble. Adding a new device driver or upgrading the Linux kernel can make all the difference in the world.
- **Managing users and passwords.** How do you want to handle users on your system? Are there certain rules you want in place for guests? How can you limit access to system resources, such as RAM or hard drive space, or portions of your directory tree?

Fortunately, Linux includes the software tools you need to administer your system. Some distributions include specialized graphical tools that can make the job a lot easier. This chapter provides an introduction for the use of these tools (and command-line equivalent actions), but the rest will be up to you. Learning system administration can take some effort, but the time spent will be well rewarded.

## Graphical Administrative Tools

Every Linux distribution, especially those from commercial vendors, touts a toolbox of graphical software tools aimed at making Linux management easier. Early software tools were in the form of shell scripts, but as Linux has matured, commercial distributors such as Red Hat, Inc. wrapped various system administration tools in graphical interfaces. To Red Hat’s credit, many of these original tools survive today in the Yellow Dog Linux and LinuxPPC 2000 Q4 distributions.

SuSE, Inc. includes a text-based console administrative tool named YaST, and another setup tool named Yet, which has a legacy stemming back to 1995. More recently, SuSE has included a graphical, X-based version, the YaST2 client. These tools can be used by SuSE PPC Linux users, in the same way the Yellow Dog Linux and LinuxPPC 2000 linuxconf clients are—to control nearly every aspect of a Linux system.

Keep in mind however, that you will still benefit from learning how to manually configure your system. Relying on X-based administrative tools can lead to an inconvenient situation, especially if you are suddenly dropped into single-user mode, or have to reboot your system to a runlevel that does not support X and networking.

## Using Legacy Red Hat Tools

Red Hat, Inc.’s version of Linux has had a profound impact on nearly all Linux distributions for Intel-based PCs, Sun SPARC workstations, and Alpha-based CPU servers. This impact is also evident in PowerPC Linux distributions such as Yellow Dog and LinuxPPC 2000 Q4, because both distributions include legacy Red Hat tools.

The oldest, all-encompassing tool is the control-panel, a GUI dock (developed in the Python and Tcl/Tk languages) that holds one or more additional administrative tools. Under LinuxPPC for example, the `control-panel`, when launched, provides a dock for seven legacy and one newer system-administration tool popularized by Red Hat's distribution. The `control-panel` client may be launched from the command line of an X11 terminal window like this:

```
# control-panel &
```

After you press Enter, you will see its window, as shown in Figure 14.1.

Click on a specific icon to launch a particular administrative tool. The tools docked in `control-panel`'s window include a rnel/vel editor, time configuration client, printer setup tool, kernel configuration client, help and search tool, `linuxconf`, network interface configuration tools, and a modem tool.
