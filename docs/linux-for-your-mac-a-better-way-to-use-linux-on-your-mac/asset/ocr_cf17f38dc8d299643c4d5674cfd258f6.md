# ## Required Information

You will first need to know your computer’s hostname and IP address. You can find the hostname by looking at a login or shell prompt, in the file named HOSTNAME under the /etc directory, or in the file named hosts under the /etc directory. If your LAN administrator uses DHCP (Dynamic Host Control Protocol) assignment for IP addresses, then you will be assigned what is termed a dynamic IP address. If you are assigned an IP number such as 192.168.2.55, then you have been assigned a static IP address. The difference between a dynamic and static IP address is that with a dynamic address, you will be assigned a new IP address each time you disconnect and then reconnect to your LAN while a static IP address stays the same.

> If you need dynamic addressing, make sure that you have installed the dhcp client on your system. For LinuxPPC 2000, this will be the dhcp-2.0 RPM file. Under SuSE PPC Linux, this will be the dhcp RPM file.

You will also need to know the IP address of your LAN’s Internet gateway. A gateway is nothing more than the device that connects two or more networks; in this case, it is the workstation, server, firewall, or other hardware device that connects your LAN to the Internet.

Finally, you will need to know the IP address(es) of your LAN’s Domain Name Servers (that provide DNS). These are one or more computers that hold tables of constantly updated information that quickly translate a numerical IP address to a name (usually in the form of XXX.XXX.XXX.XXX). For example, www.prima-tech.com or www.applecomputer.com.

Once you have this information in hand, you are ready to configure your system. First, make sure your Ethernet interface is installed and recognized by Linux. Next, use one of the administrative tools covered in Chapter 15, “Managing Services,” to properly configure your interface. You can also do this quickly (as root) if you have a static IP address, by using the ifconfig command, like this:

```
# ifconfig eth0 yourIPaddress up
```
