# Introduction to Printing

There are a variety of line-printer spooling systems available for Linux. Although you can set up KDE and GNOME to support drag-and-drop printing, you should also understand how to use the Linux printing system from the command line. Without this knowledge, you may find it difficult to print during console and text-only sessions, or to use many of the X clients for printing.
