
After the build finishes, you can then simply copy the resulting *scanner.o* module into your */lib/modules/2.2.x/USB* directory to replace your original. Note that this works only if you use the same Linux source used to build the currently running kernel (the structure of the *scanner.h* source has changed with the new 2.4-series Linux kernel, but the scanner information still remains valid).

## Printing

Installing a printer for use with PPC Linux is fast and easy, because every Linux distribution comes with tools that make the task easy. Red Hat-based systems come with the graphical *printtool* client, while SuSE PPC Linux users can use the *yast* command or *yast2* client to configure a printer.

The good news for Intel-based Linux users migrating to PPC Linux is that your older, Linux-supported parallel port printer can work with USB while running PPC Linux! If you have a legacy parallel port printer and want to use it with PPC Linux on your Power Mac, the D-Link DSB-P36 USB parallel port printer adapter is indispensable; you are able to connect your parallel port printer and attach it to your computer's USB port.

Setting up a parallel port or USB printer under Linux can be accomplished in a matter of a few seconds. For example, under SuSE PPC Linux, launch the *yast2* client. Select the Hardware/Printer menu item, and then click the Launch Module button. You see a dialog box that lists five different printers: Novell, parallel, remote, Samba, and USB.

If you have a USB printer, or a printer connected to the D-Link adapter, click USB and then click the Add button. You see a dialog box, as shown in Figure 3.10.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_80_0.png)

![](img/1ea833f5a3e3c1547e3dd2891f52804a_80_1.png)

Pick a printer device name, such as */dev/usb/p0* (if you have only one printer), and then click the *Next* button. Then you see a dialog box that lists a variety of printer manufacturers and devices. Click on your printer's manufacturer, such as Hewlett Packard, and a list of supported printers for that manufacturer appears, as shown in Figure 3.11.

Do not panic if you do not see a printer model that matches your printer exactly. There are many different printers on the market, but many printers from the same manufacturer and family will work with one or more printer drivers. For example, an HP 658C USB printer functions quite well using the Deskjet 500 printer driver. When finished, click the *Next* button.

You are now asked to give your printer a name. Give your printer a name, or accept the default name. Remember this name because you will use it later for printing!

When finished, click the Next button. You will then see a dialog box, as shown in Figure 3.12.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_81_0.png)

Figure 3.12 Make sure to select a correct paper size for your printer when using yast2.

Click the paper size item in the top dialog box, and then select a default paper size for your printer.

When finished, click the Next button, and then click the Finish button to add your printer to the system. You can now print documents to your printer using the lpr command, like this:

```
# lpr -Pprintername mydocument.ps
```

In this example, the -P command-line option is used to specify a printer. This is important, as you can have any number of printers attached to your system, or even print to a remote printer attached to another computer.

Printing works through the lpd printer daemon. This service, which starts when you boot Linux, monitors the /var/spool/lpd directory, and looks for documents that are waiting to be printed. When one is found, the lpd daemon starts a printing process, and sends the document to the designated printer (which has its own directory under /var/spool/lpd).

### Editing /etc/printcap

The *yast*, *yast2*, and *printtool* commands save your printer definitions in your system's printer capability database, /etc/printcap. You do not need to edit this file! Of course, as the root operator you can do anything you want, but in general you should not have to make any changes.

However, if you use SuSE Linux, and use the *yast* command to create a printer definition for a USB printer, you'll need to edit your system's /etc/printcap.

Since the `yast` command was designed to create legacy type parallel-port printers, any newly created printer uses `/dev/lp*` device names, such as `/dev/lp0`. You can still use `yast` to create a printer definition for your USB printer, but afterwards, you need to edit the resulting `/etc/printcap` entries. Look for the following:

```
...
   :lp:/dev/lp0:\n...
```

To set the correct device, change this entry to look like this:

```
...
   :lp:/dev/usb/lp0:\n...
```

This ensures that printing works after configuring your printer using `yast`.

## Creating Remote Printers

Linux has many great networking features. If you use PPC Linux and have access to a LAN, you can set up remote printing services. This is relatively easy.

First, go to the remote computer with the attached printer. Make sure that the printer is attached, configured properly, and working. Next, sit down and edit the system's `/etc/hosts.lpd` file and insert the name or names of various hosts you would want to have access to the local printer. Also note the printer's name on the remote computer. Save the file, and then restart the `lpd` daemon on the computer like this:

```
# /etc/rc.d/init.d/lpd restart
```

Next, go to your workstation and use `yast` or `printtool` to create a remote printer. For example, Figure 3.15 shows a printer definition entry dialog box.

![](img/1ea833f5a3e3c1547e3dd2891f52804a_83_0.png)

Figure 3.15 *Make sure to use the correct remote printer's name when using printtool to create a remote printer entry.*

Give the printer entry a local name, and then specify the name of the remote host and the printer's name (the remote queue) on the remote host. You then need to select an appropriate printer filter for the remote printer entry that matches the remote printer. Save the definition. You can then print to the remote printer, like this:

```
# lpr -Premoteprintername mydocument.ps
```

# Serial Ports and Modems

No newer Power Mac comes with a serial (RS-232 or RS-422) port, although every PowerBook and some desktops, such as the Apple G4 Cube, come with an internal modem. Most internal modems are supported. For more information about using serial ports, see Chapter 9, "Connecting to the Internet." This chapter contains additional details about detecting, configuring, and setting up a serial port or modem, and some possible workaround solutions for adding a serial port to your computer.

Fax services are provided by several utilities included with most Linux distributions. SuSE Linux includes a complex fax support system named HylaFAX. However, you may want to explore the use of the efax software. Using this software is very easy. First, use your favorite text editor (as root) to edit the file named `fax` under the `/usr/bin` directory. Look for various entries, such as:

```
...
# Your fax number in international format, 20 characters maximum.
# Use only digits, spaces, and the "*" character.

FROM="+0 000 000 0000"

# Your name as it should appear on the page header.

NAME="from a Red Hat Linux system"
...
```

Change these entries to include your fax number and name. If you have properly configured your modem, you can then turn your Linux system into a fax machine waiting for faxes, like this:

```
# efax

efax: Sun May 13 16:18:27 2001 efax v 0.9 Copyright 1999 Ed Casas

efax: Sun May 13 16:18:27 2001 efax v 0.9 Copyright 1999 Ed Casas

efax: 18:27 compiled Aug 21 2000 01:25:22

efax: 18:30 opened /dev/modem

efax: 18:31 using V2.300-V90_2M_DLS CONEXANT AC/K56 in class 2
```
