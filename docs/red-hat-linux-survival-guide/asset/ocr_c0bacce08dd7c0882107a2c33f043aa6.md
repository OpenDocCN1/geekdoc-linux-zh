# SCSI support

If you have SCSI disks, a CD-ROM, tape drives, or other SCSI devices, this section allows you to configure support for such devices. You should answer the following questions based on available SCSI hardware:

```
SCSI support (CONFIG_SCSI) [Y/m/n/?]
```

```
SCSI disk support (CONFIG_BLK_DEV_SD) [Y/m/n/?]
```

```
SCSI tape support (CONFIG_CHR_DEV_ST) [N/y/m/?]
```

```
SCSI CD-ROM support (CONFIG_BLK_DEV_SR) [N/y/m/?]
```

```
SCSI generic support (CONFIG_CHR_DEV_SG) [N/y/m/?]
```

```
Probe all LUNs on each SCSI device (CONFIG_SCSI_MULTI_LUN) [Y/n/?]
```

Unless you have a SCSI device with multiple Logical Unit Numbers (LUN), choose no here.

```
Verbose SCSI error reporting (kernel size +=12K)
(CONFIG_SCSI_CONSTANTS) [Y/n/?]
```

The error messages regarding your SCSI hardware are easier to understand if you choose yes here.

```
SCSI logging facility (CONFIG_SCSI_LOGGING) [N/y/?]
```

This turns on a logging facility you can use to debug a number of SCSI-related problems. If you choose yes, you have to enable logging by using the following command in /etc/rc.d/rc.local.

```
echo "scsi log token [level]" > /proc/scsi/scsi
```
