# Adding a network interface with netcfg

You must run netcfg as a superuser (such as root) from within a graphical environment such as GNOME. The initial window, shown in Figure 6-1, displays the current host name, domain name, and name server configuration.

![](bbox=[0.07, 0.23, 0.65, 0.49])

Figure 6-1 The Names tab of the Network Configurator.

To change the host name, the domain name, or the name servers, click the Names tab. Simply modify the values and click Save.

![](bbox=[0.07, 0.61, 0.18, 0.67])

The program does not display any status message when you click Save, and this can be a bit confusing at first. Also note that the domain name displayed in the program comes from the search list (the first entry in the list) in the /etc/resolv.conf file. If you do not have any search list set up in this file, netcfg does not display a domain name.

To add, modify, or remove a network interface, click the Interfaces tab. This tab, shown in Figure 6-2, displays the current network interfaces.
