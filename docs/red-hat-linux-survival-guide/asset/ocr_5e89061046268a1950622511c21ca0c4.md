Apache Web server is more popular than any other Web server software in the world. In fact, Apache is used in approximately 60 percent of all the Web sites in the world. Apache Web server supports many platforms, including Linux. In this chapter I will discuss how you can install, configure, and manage Apache Web Server on Red Hat Linux.
