If the automatic updating of certain packages could be very sensitive, or if you simply do not feel comfortable about Update Agent updating something automatically, you can add these packages in the exception list. By default, any kernel packages are considered an exception. After all, if a kernel update starts behaving in a bizarre fashion, you might not be able to access your system.
