# Working with Files and Directories

# IN THIS CHAPTER

+   - Understanding the Linux File Hierarchy Structure
+   - Accessing files and directories

When you work on a computer, you work with files. Some of these files are executable programs, some are data files needed by the programs, and some files are storage for the data that the user creates. Files and directories are the most commonly used objects within a computer. In Linux, these objects can be manipulated only by those who have privileges to do so. Therefore, it is very important to understand the way files and directories work under Linux. In this chapter I discuss working with the Linux file system, as well as how to control access to who has what on a network: permissions.
