Figure 10-5 shows the main GNOME Panel of a typical X Window System desktop. Notice the four rectangles on the bottom-right side of the screen. Each of these rectangles represents a workspace window. If you click on any of these rectangles, you automatically switch to that work- space. In a workspace, you can run a number of client programs such as Netscape Navigator, xterms, etc. to organize your screen space in the way you like.
