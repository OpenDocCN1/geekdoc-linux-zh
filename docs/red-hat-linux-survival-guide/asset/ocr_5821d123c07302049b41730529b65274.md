To install an RPM package from a CD-ROM, insert the CD-ROM and mount it (GNOME automatically mounts the CD-ROM unless you disable this option using GNOME Control Center). Click the Install icon or select the Install option under the Packages menu (top left). The window should look like that shown in Figure 10-10.
