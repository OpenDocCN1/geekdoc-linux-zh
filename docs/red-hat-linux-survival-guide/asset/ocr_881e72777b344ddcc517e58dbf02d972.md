Here, all the files and subdirectories of the directory called important_dir are archived in a file called backup.tar.gz. Notice that the z option is compressing this file; hence, you should give the resulting file a .gz extension. Often, the .tar.gz extension is shortened by many users to be .tgz as well.

To extract an archive file called backup.tar, you can run the following command:

```
tar xf backup.tar
```

To extract a compressed tar file (such as backup.tgz or backup.tar.gz), you can run the following command:

```
tar xzf backup.tgz
```

# uncompress

Syntax: uncompress [-v] file(s)

When you use the compress command to compress a file, the file is no longer in its original form. To return a compressed file to its original form, use the uncompress command.

![](bbox=[0.06, 0.6, 0.15, 0.68])

The uncompress command expects to find a file with a .Z extension, so the command line “uncompress inbox” is equivalent to “uncompress inbox.Z”

The -v option produces verbose output.

```
uncompress -v inbox.Z
```

```
inbox.Z: -replaced with inbox
```

# unzip

Syntax: unzip file(s)

This command decompresses files with the .zip extension (the single most popular Windows compression format). You can compress these files with the unzip command, Phil Katz’s PKZIP, or any other PKZIP-compatible program.
