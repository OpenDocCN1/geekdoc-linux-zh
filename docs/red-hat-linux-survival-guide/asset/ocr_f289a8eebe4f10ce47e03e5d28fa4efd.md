# Create a service level on Red Hat Network

Follow these steps to create a service level on the Red Hat Network:

+   1. Log on to www.redhat.com/network using your registered Red Hat Network user account information.
+   2. Create a service level for your system.
+   3. Click the Your Network link
+   4. Click the Assign Service Levels link
+   5. Locate your registered system in the unassigned system list (labeled “no service”) and use the Upgrade button to move it to the Software Manager list on the right side.
+   6. Click the log out button on the top right corner. That’s it; you’ve enabled the Software Manager service for the named host.
