# Configuring authentication options

Red Hat Linux can authenticate users using standard password file (/etc/passwd), or use shadow password files (/etc/passwd and /etc/shadow), or authenticate using remote authentication servers such as the Network Information System (NIS) server, Lightweight Directory Access Protocol (LDAP) server, or even Kerberos authentication server. Figure 1-26 shows your authentication configuration options.

![](bbox=[0.08, 0.3, 0.88, 0.58])

Figure 1-26 Configuring authentication options.

NOTE Unless you have existing remote NIS, LDAP, or Kerberos servers set up you should not enable them. You should definitely use the shadow password support and also enable MD5-based password support as shown in Figure 1-26.
