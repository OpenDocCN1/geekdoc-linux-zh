The following example shows the command and resulting output for a quota check on user kabir:

```
quota -u kabir
Disk quotas for user kabir (uid 500):
Filesystem blocks quota limit grace files quota limit grace
/dev/sda5 0 1024 4096 1 128 512
```

You can run the same command to monitor disk usage of a group by using the -g (g for “group”) option as follows:

```
quota -g group
```

When you find users or groups that are over the limit, you can work with them (perhaps by e-mail) to ensure that disk usage is brought down to acceptable limits.
