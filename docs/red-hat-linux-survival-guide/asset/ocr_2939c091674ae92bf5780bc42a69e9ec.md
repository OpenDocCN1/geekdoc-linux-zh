The default /etc/ftpaccess file is shown in Listing 14-1.

# Listing 14-1 The default /etc/ftpaccess file

```
class all real,guest,anonymous *

email root@localhost

loginfails 5

readme README* login
readme README* cwd=*

message /welcome.msg login
message .message cwd=*

compress yes all
tar yes all
chmod no guest,anonymous
delete no guest,anonymous
overwrite no guest,anonymous
rename no guest,anonymous

log transfers anonymous,real inbound,outbound

shutdown /etc/shutmsg

passwd--check rfc822 warn
```

This file is the most important configuration file for the server, and I discuss it in great detail in the following sections. You can specify five types of configuration information in this file, which are access configuration, informational configuration, logging configuration, permission configuration, and miscellaneous configuration.
