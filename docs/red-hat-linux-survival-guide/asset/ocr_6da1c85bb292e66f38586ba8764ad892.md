+   - **XkbRules:** You can specify this option to specify the keyboard rules file. The default rules file is `xfree86`.

# Pointer section

Use this section to set up the pointer device, which is typically a mouse. An example Pointer section follows:

    Device      "/dev/mouse"

EndSection
