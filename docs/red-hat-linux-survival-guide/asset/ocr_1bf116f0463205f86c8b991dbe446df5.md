+   - **High:** Disables all incoming remote access to the system
+   - **Medium:** Allows remote access via secure protocols such as SSH but blocks FTP, Telnet, and services such as printing daemons that can print documents sent from remote systems
+   - **No firewall:** Allows all incoming traffic including Telnet and FTP
