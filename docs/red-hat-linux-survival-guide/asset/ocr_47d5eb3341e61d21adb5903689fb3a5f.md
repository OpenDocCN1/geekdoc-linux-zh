# Configuring your window manager

The Sawfish window manager can be configured from within the GNOME Control Center. Click on the Sawfish window manager option in the tree menu to expand all the options as shown in Figure 10-4.

You can configure various look-and-feel related features of the window manager by clicking on the appropriate option. Because customizing a window is a matter of personal taste, there is no right or wrong approach in changing them. Try out different options and find out what you like.
