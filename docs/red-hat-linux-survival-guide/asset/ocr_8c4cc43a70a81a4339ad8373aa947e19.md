Before you actually go ahead with this method, consider carefully whether you can avoid creating multiple main server instances and simply go with <VirtualHost> containers instead.

For example, say you have 16 IP addresses and want to provide 16 different clients (or departments) with their own httpd.conf files so that each entity can manage everything on its own; they can even create virtual hosts of their own by using <VirtualHost> containers within their own httpd.conf files.

Listing 12-2 shows a simplified version of httpd.conf (called httpd-100.conf) that uses the Listen directive to tell Apache to only service the 192.168.1.100 IP address associated with the system it is running.
