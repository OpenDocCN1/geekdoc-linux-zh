# /etc/ftpusers

The file /etc/ftpusers specifies the list of users who are not allowed to access the FTP server. The default /etc/ftpusers file contains the following users:

+   - root
+   - bin
+   - daemon
+   - adm
+   - lp
+   - sync
+   - shutdown
+   - halt
+   - mail
+   - news
+   - uucp
+   - operator
+   - games
+   - nobody

These accounts are not allowed to log on because they are not real user accounts. If you need to stop a real user from being able to FTP to the server, you can put the username in this file.
