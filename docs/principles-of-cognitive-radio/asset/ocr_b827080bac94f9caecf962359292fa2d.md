$P_{FA}=Q\left(\sqrt{N}\frac{\theta}{\sqrt{P\sigma_w^2}}\right),$ $P_{MD}=Q\left(\sqrt{N}\frac{P-\theta}{\sqrt{P\sigma_w^2}}\right),$

with $Q$ the Gaussian tail function.

# Unknown phase

If the carrier phase of the received signal is unknown but constant, then coherent detection can be modified by computing the test statistic

$Y = \left|\frac{1}{N}\sum_{n=0}^{N-1}y_nx_n^*\right|^2 = \left|P + \frac{1}{N}\sum_{n=0}^{N-1}w_nx_n^*\right|^2.\quad(4.32)$

# Imperfect time alignment

Coherent detection assumes perfect time alignment at the receiver of the transmitted data sequence, which is usually not verified in practice. If there is a maximum time offset of $\nu$ time instants, then the detector may rather form the following test statistic, based on an exhaustive search of the actual time offset:

$Y = \max_{0\le\tau\le\nu}\left|\frac{1}{N}\sum_{n=0}^{N-1}y_{n+\tau}x_n^*\right|^2.\quad(4.33)$

# Coherent detection using a pilot tone

In practice, since the sequence $(x_n)$ is not known at the receiver if it consists of random information data, detection may be performed with the aid of pilot tones. With this model, the primary signal includes a known pilot tone $x_n^P$, orthogonal to the white information signal $x_n$ and to which a fraction $\delta$ of energy is allocated. The observed-signal model becomes [37]

$y_n = \sqrt{\delta}\,x_n^P + \sqrt{1-\delta}\,x_n + z_n.\quad(4.34)$

The test statistic is

$Y = \frac{1}{N}\sum_{n=0}^{N-1}y_nx_n^{P*}.\quad(4.35)$

where $(x_n^P)$ is a sequence parallel to the pilot tone.
