Figure 4.6 shows the evolution of the convex hull of P_FA with the noise power (here θ = 0.5). The convex hull contains all possible values of P_FA for a given value of σ_I^2 = E[I^2]. Similar results hold for P_MD.

It may be observed that upper and lower envelopes of both P_FA and P_MD converge at a single point for σ_I^2 = 0 (corresponding to f_I(x) = δ(x)) and for σ_I^2 = 1 (corresponding to the unique symmetric density with that variance, i.e., f_I(x) = 0.5 δ(x + 1) + 0.5 δ(x - 1). A simple calculation shows that the starting points of the envelopes are

P_FA|σ_I^2=0 = Q( θ / σ ), (4.130)

P_MD|σ_I^2=0 = Q( (1 - θ) / σ ), (4.131)

and the endpoints

P_FA|σ_I^2=1 = 1/4 [ Q( (θ -1)/σ ) + Q( (θ +1)/σ ) ], (4.132)

P_MD|σ_I^2=1 = 1/4 [ Q( -θ / σ ) + Q( (2 - θ)/σ ) ], (4.133)
