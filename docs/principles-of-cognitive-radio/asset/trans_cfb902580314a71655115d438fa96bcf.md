**图 2.16** 互织次级用户的信道模型：随机开关位置表示检测到主用户的存在（OFF）或不存在（ON）。

活动可以被正确检测为频谱空洞，也可以不被检测。我们首先考虑在频谱空洞完美检测下单个次级用户的随机开关模型，如图 2.16 所示。当检测到主用户活动时，开关处于 OFF 状态，信道不可用。当未检测到主用户活动时，开关处于 ON 状态，表示信道可供次级用户使用。信道是随机变化的，因为在任意时间区间 [0, *T*] 内，开关处于 ON 或 OFF 的时间 *T*_{on} 和 *T*_{off} 分别是随机的。假设当开关处于 ON 时，次级用户信道的容量为 *C*_{s}，例如对于 AWGN 信道 *C*_{s} = *W* log$_{2}$(1 + *P*_{s}/(*N*$_{0}$*W*))，其中 *W* 是与频谱空洞相关的信道带宽，*P*_{s} 是次级接收机处的接收信号功率，*N*$_{0}$/2 是次级接收机噪声的 PSD。请注意，由于假设检测是完美的，该信道是无干扰的。

一般而言，随机开关信道的容量取决于在发送端和接收端对开关位置的了解程度。在互织范式下，假设开关位置在次级发送端和接收端均已知：次级发送端必须知道开关位置，以便在主用户传输期间不进行传输，而次级接收端必须知道开关位置以解码次级用户的传输。由于开关位置已知且检测是完美的，在每个时间瞬间，信道在发送端和接收端均已知，因此合适的容量度量是遍历容量或中断容量。特别地，当开关处于 ON 时，次级用户可以以任意速率 *R* < *C*_{s} 可靠传输。在时间区间 [0, *T*] 上，次级用户传输的时间比例为 *T*_{on}/*T*。对于平稳且遍历的主用户活动，当 *T* 趋于无穷大时，这等于开关处于 ON 的概率 *P*_{on}。该双态信道的遍历容量于是为 *C*_{erg} = *P*_{on}*C*_{s}，因为当开关处于 OFF 时次级用户获得零速率，而该情况发生的概率为 *P*_{off} = 1 − *P*_{on}。该信道的中断容量也为 *P*_{on}*C*_{s}，因为当开关处于 ON 时次级用户可以以任意速率 *R* < *C*_{s} 可靠传输，而当开关处于 OFF 时处于中断状态。请注意，如 [45] 中所述，导致开关处于 ON 或 OFF 的检测细节与容量分析无关；只需要概率 *P*_{on}，该概率可根据主用户活动特性及给定的检测策略确定。

相同的开关模型在检测不完美时也适用，在这种情况下，次级用户和主用户的容量度量不再是遍历容量或中断容量，因为信道不再为发送端所知。考虑最简单的情况，即一个主用户和一个次级用户，两者均具有固定的发射功率和到各自接收机的静态信道。当主用户的传输未被检测到（漏检）时，其信道由于次级用户的干扰而退化。在这些传输期间，次级用户的信道也由于主用户的干扰而退化。设 $C_p^q$ 等于次级用户不活跃时主用户信道的容量，设 $C_p^i$ 等于次级用户活跃时主用户信道的容量。对于带宽为 $W$、噪声 PSD 为 $N_0/2$ 且将干扰视为噪声的 AWGN 信道，这些分别对应于 $C_p^q = W \log_2(1 + P_p/(N_0W))$ 和 $C_p^i = W \log_2(1 + P_p/(N_0W + I_s))$，其中 $P_p$ 为主用户接收机处的接收功率，$I_s$ 为次级发射机对主用户接收机造成的干扰功率。

设 $P_{\mathrm{MD}}$ 表示漏检概率，即主用户活动未被检测到的概率。我们首先研究漏检对主用户在传输期间容量的影响；主用户在不传输时速率为零。假设主用户不知道次级用户的传输，其在传输时的性能正确度量为容量与中断的关系。这由 $C_p^q$ 给出，当 $P_{\text{out}} < P_{\mathrm{MD}}$ 时，因为主用户以概率 $P_{\mathrm{MD}}$ 受到次级用户干扰，以及当中断概率 $P_{\text{out}} \geq P_{\mathrm{MD}}$ 时的 $C_p^i$。请注意，主用户通常不知道次级用户的干扰，因此它不知道 $C_p^i$。因此，它必须在没有此知识的情况下选择一个 *固定* 的传输速率 $R \leq C_p^i$。如果中断概率 $P_{\text{out}} = P_{\mathrm{MD}}$ 可接受，则主用户可以以任意速率 $R < C_p^i$ 传输，并接受 $P_{\mathrm{MD}}$ 部分数据将被错误解码。如果该中断概率不可接受，则假设它可以将次级用户的最大干扰限制为 $I_{s, \text{max}}$，它可以以任意速率 $R < W \log_2(1 + P_p/(N_0W + I_{s, \text{max}}))$ 可靠传输。只要该界限准确，以此速率发送的数据将始终被正确解码。类似地，如果它确实知道 $C_p^i$，则可以以该速率发送且无中断。主用户在由于正确检测到主用户活动而开关处于 ON 时，或由于漏检主用户活动而开关处于 ON 时处于活跃状态。回顾 $P_{\mathrm{FA}}$ 为虚警概率，且令 $P_{\mathrm{MD}}$ 表示漏检概率，我们有主用户活跃的概率为 $(1 - P_{\mathrm{FA}})P_{\text{off}} + P_{\mathrm{MD}}P_{\text{on}}$。因此，在主用户活跃时以固定传输速率 $R$ 传输时，主用户在所有时间上的平均吞吐量为 $((1 - P_{\mathrm{FA}})P_{\text{off}} + P_{\mathrm{MD}}P_{\text{on}})R$。

主用户适应次级用户的行为对于互织信道而言是不典型的，在互织信道中，主用户被期望对次级传输的存在毫无察觉。然而，已提出了一些主用户可以对次级用户做出反应的系统。假设主用户可以测量由于漏检而由次级用户造成的干扰。那么它可以在传输期间自适应其传输速率，在没有次级干扰时（即开关处于 OFF 时）调整为 $R < C_p^i$，在有次级干扰时（即由于漏检而开关处于 ON 时）调整为 $R = C_p^i$。这使得主用户在传输期间的遍历速率为

$$C_{p,\text{erg}} = P_{\mathrm{MD}}C_p + (1 - P_{\mathrm{MD}})C_p^i. \qquad\qquad\qquad (2.63)$$

请注意，对于典型的无线信道，即使主用户发射机不根据干扰的有无自适应其速率，只要主用户接收机能够感知来自次级用户的干扰，就能实现该速率 [32, Section 4.2]。

漏检对次级用户的影响与对主用户的影响类似。特别是，次级用户在漏检期间不知道主用户的传输，而漏检发生的概率为 $P_{\mathrm{MD}}$。因此，次级用户的双态开关信道变为三态信道：当开关处于 OFF 时容量为零，因为次级用户不传输；当开关处于 ON 时，信道的容量等于频谱空洞被正确检测时的无干扰容量，且等于空洞被错误检测时受主用户干扰的容量。设 $C_s$ 等于主用户不活跃时次级用户在传输期间的信道容量，设 $C_s^I$ 等于主用户活跃时（漏检）次级用户在传输期间的信道容量。对于带宽为 $W$、噪声功率为 $N_0 W$ 且将干扰视为噪声的 AWGN 信道，这些分别对应于 $C_s = W \log_2(1 + P_s/(N_0 W))$ 和 $C_s^I = W \log_2(1 + P_s/(N_0 W + Z_p))$，其中 $P_s$ 为次级用户接收机处的接收信号功率，$Z_p$ 为主发射机对次级用户接收机造成的干扰。由于信道未知，次级用户在传输时的容量正确度量为容量与中断的关系。与漏检下主用户的情况类似，该函数由 $C_s^I$ 给出，当 $P_{\mathrm{out}} \leq P_{\mathrm{MD}}$ 时，以及 $C_s$ 给出，当 $P_{\mathrm{out}} > P_{\mathrm{MD}}$ 时。因此，如果中断概率 $P_{\mathrm{MD}}$ 可接受，则次级用户可以以任意速率 $R < C_s$ 传输，并接受 $P_{\mathrm{MD}}$ 部分数据将被错误解码。如果该中断概率不可接受，则假设它可以将主用户的最大干扰功率限制为 $I_{p, \max}$，它可以以任意速率 $R < W \log_2(1 + P_s/(N_0 W + I_{p, \max}))$ 传输，使得只要该界限准确，以此速率发送的数据将被正确解码。类似地，如果它确实知道 $C_s^I$，则可以以该速率发送且无中断。由于次级用户以概率 $P_{\mathrm{on}}$ 活跃，次级用户在活跃时以固定传输速率 $R$ 传输时，在所有时间上的平均吞吐量为 $P_{\mathrm{on}} R$。

除了错误检测频谱空洞外，次级用户在不存在主用户时以概率 $P_{FA}$ 检测到主用户的存在。因此，如果次级用户在开关处于 ON 时以速率 $R$ 传输，则由于错过的传输机会，相对于无虚警的情况，次级用户的容量将减少 $P_{FA} R$。请注意，在漏检和虚警下的容量计算中不需要确切的检测策略。这些容量计算仅使用漏检概率和虚警概率，而这对于任何给定的检测策略都可以确定，如第 4 章和第 5 章所述。
