the autocorrelation matrices

A_y ≜ E[y_n y_n^†], (4.56)
A_x ≜ E[x_n x_n^†], (4.57)
A_w ≜ E[w_n w_n^†], (4.58)

and the L × (L + K) "filtering matrix"
H = [ h0 h1 … hK 0 … 0 ; 0 h0 … hK-1 hK … 0 ; … ; 0 0 … h0 h1 … hK ], (4.59)

we obtain, under the usual assumption of uncorrelated signal and noise,
A_y = A_x + A_w, (4.60)

where
Λ_w = σ_w^2 G, (4.61)

with G the positive definite Hermitian matrix
G ≜ H H^†. (4.62)

With the new definitions
A_y ≜ G^{-1/2} A_y G^{-1/2}, (4.63)
A_x ≜ G^{-1/2} A_x G^{-1/2}, (4.64)

we obtain
A_y = A_x + σ_w^2 I_L (4.65)
as in (4.47).

# Eigenvalue-ratio test

This technique was introduced in [53, 54]. Denoting by ρ_min and ρ_max the minimum and maximum eigenvalues of A_x, and by μ_min and μ_max the minimum and maximum eigenvalues of A_y, respectively, we have
μ_max = ρ_max + σ_w^2 and μ_min = ρ_min + σ_w^2, (4.66)

so that
μ_max / μ_min = 1 (4.67)
when there is no primary signal, and
μ_max / μ_min > 1 (4.68)
