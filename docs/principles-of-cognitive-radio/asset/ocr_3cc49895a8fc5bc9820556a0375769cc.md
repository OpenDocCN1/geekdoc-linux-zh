# Notation

# General notation and symbols

$ A(\cdot) $ Autocorrelation function

$ \mathbf { A } ^ { \mathsf { T } } $ Transpose of the matrix $ \mathbf { A } $

$ \mathbf { A } ^ { \mathsf { H } } $ Hermitian of the matrix $ \mathbf { A } $

$ { \mathcal { A } } ^ { c } $ Complement of the set $ { \mathcal { A } } $

$ B _ { c } $ Coherence bandwidth

$ c ( \cdot ) $ Cost function

$ C $ Channel capacity

$ C _ { \mathrm { e r g } } $ Ergodic channel capacity

$ C _ { \mathrm { o u t } } $ Outage channel capacity

$ \mathbf { C } $ Channel capacity region

$ \mathbb { C } $ Set of complex numbers

$ { \bf { E } } [ \cdot ] $ Expectation operator

$ D ( \cdot ) $ Doppler power spectrum

$ f $ Frequency

$ f _ { c } $ Center frequency of the signal band

$ F ( \cdot ) $ Frequency correlation function

$ F _ { X } ( \cdot \, ) $ Cumulative distribution function of the RV $ X $

$ g _ { \mathrm { d } } ( \cdot ) , g _ { \mathrm { e } } ( \cdot ) $ Decoding, encoding function.

$ G $ Power gain

$ G _ { \mathrm { r } } , G _ { \mathrm { t } } $ Receive, transmit antenna gains, in dB

$ \gamma $ Signal-to-noise ratio, path loss exponent

$ h $ Complex channel gain

$ h ( t ) $ Channel impulse response

$ H ( f ) $ Complex frequency response of a channel or filter

$ H $ Mean-square value of $ | h | $

$ \mathbf { H } $ Channel gain matrix

$ \mathcal { H } _ { 0 } $ Null hypothesis

$ \mathcal { H } _ { 1 } $ Alternative hypothesis

$ \eta $ Efficiency

$ \mathbf { I } $ Identity matrix

$ \mathbf { I } _ { k } $ $ k \times k $ identity matrix

$ I ( X ; Y ) $ Mutual information between $ X $ and $ Y $
