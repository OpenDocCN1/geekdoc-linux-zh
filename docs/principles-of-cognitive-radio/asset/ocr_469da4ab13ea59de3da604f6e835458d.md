∫_j k_i(x) dG(x), i = 1,2, is also compact and convex. By restricting these CDFs to be unit step functions u(x − x0), with x0 ∈ I, the observation that ∫ k_i(x) du(x − x0) = k_i(x0), i = 1,2 shows that the curve C is in the moment space M. By considering convex combinations of these unit step functions, we see that the moment space contains the convex hull of C. Conversely, since any point of the moment space can be expressed as a convex combination of points of the curve, the convex hull of C contains the moment space, which proves our result.

As an example, suppose that we define k1(x) = x² and k2(x) = h(x), where h(·) is a known continuous function defined in [−1, 1], and that m1 ≜ E[I²] (4.115) is known, while we want to compute “sharp” upper and lower bounds (i.e., bounds that cannot be further tightened) to m2 ≜ E[h(I)]. (4.116)

This problem can be solved as follows. Build the curve Ĉ = (x², h(x)) as x ∈ I. The convex hull of Ĉ contains the pairs m1, m2 corresponding to all CDFs defined over I. In particular, for any given value of m1, the values of the lower and upper envelope at m1 yield sharp lower and upper bounds to m2 (see Fig. 4.2 for an illustration). The dashed curve has equation (x², h(x)), while the continuous lines represent the upper and lower envelope delimiting the convex hull for any value of m1, and hence describing the bounds on m2 achieved by the limiting CDFs.
