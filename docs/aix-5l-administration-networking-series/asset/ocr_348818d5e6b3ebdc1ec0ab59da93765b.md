# Summary Reports

A standard set of reports is produced at intervals by the runacct and monacct commands. These commands should be run by the adm crontab. The summaries and reports are recorded in the following directories:

```
/var/adm/acct/nite Daily files used by runacct
/var/adm/acct/sum Daily summaries created by runacct
/var/adm/acct/fiscal Monthly summaries created by monacct
```
