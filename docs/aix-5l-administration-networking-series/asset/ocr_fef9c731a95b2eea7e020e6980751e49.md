To create a bootable backup copy of the root volume group to the rmt0 tape device and create a new /image.data file, use the following syntax:

```
`# mkxsysb -i /dev/rmt0`
```

To create a bootable system image complete with disk map files, use the following command syntax:

```
`# mkxsysb -m /dev/rmt0`
```

To create a new /image.data file and exclude the files listed in the /etc/exclude.rootvg file, use the following syntax:

```
`# mkxsysb -i -e /dev/rmt0`
```
