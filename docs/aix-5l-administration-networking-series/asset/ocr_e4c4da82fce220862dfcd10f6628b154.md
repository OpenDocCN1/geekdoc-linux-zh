definition instructs the \textbf{mklv} command to create an Episode File System, but that is just a small part of the aggregate processing. The following command will make a logical volume named \texttt{lvlfso1} of type lfis with 100 logical partitions and mirrored (-c 2):

```
# mklv -yA lvlfso1 -t lfis -c 2 VolumeGroupName 100
```

Use the SMIT FastPath \textbf{mkdlsaggr} to format and export the aggregate. You may also want to tune the aggregate blocksize to match the intended use of the filesystem. For example, use a small blocksize for file systems that will hold many small files. This SMIT processing will run \textbf{newaggr} and \textbf{mkdlsfsls} with standard output listing their command-line arguments. User the following command, select Yes when prompted to INITIALIZE Device and refer to Figure 15-4 for details on naming, formatting, and exporting the aggregate:

```
# smitty mkdlsaggr $\leftarrow$ FastPath to Export an Aggregate from the Local Machine
```

A line entry is placed in the /opt/deco local/var/dss/dfstab file for each new aggregate. Use the following df command to see the new device mounted for export:

```
# df /dev/lvlfso1
Filesystem ... Mounted on
/dev/lvlfso1 ... /opt/deco local/var/dss/aggra/lfso1
```
