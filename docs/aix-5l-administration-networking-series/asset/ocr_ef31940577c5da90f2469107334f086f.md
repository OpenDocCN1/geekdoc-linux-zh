# # CONTROLLING SUPERUSER ACCESS

Great care should be taken with the root password, how it is used, and who has access to it. In general, root should never log in to the system directly; users with access to the superuser account should log in to their own accounts first, and then use the su command to become root. This way, all attempts to become root, whether they succeed or fail, are logged to /var/adm/sulog. To prevent direct logins to the root account from the network, run the command

```
```
# chuser rlogin='false' root
```
```

AIX provides additional protection by defining the groups who may use the su command to switch to a particular account, and by refusing to permit the use of su to switch to an account. These controls are set in the /etc/security/user file, on a per-user basis:

root:
    sgroups = system,security
