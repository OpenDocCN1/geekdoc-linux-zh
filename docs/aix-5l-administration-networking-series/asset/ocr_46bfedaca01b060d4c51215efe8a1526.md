The story always begins with the dreaded flashing 888 on the LED front panel. Before deciding to punt and hitting the Power switch, press the Reset button to cycle though the set of four halt status numbers. These numbers indicate the current system state, the reason for the halt, and the dump state. Write them down. You’re going to need them later in the analysis processes.
