The `iostat` command reports processor statistics and all system input and output device statistics. New command-line options shipped with AIX 5L add new adapter and system throughput header fields and reports. You must have the `iostat` attribute for `sys0` set to `true` before this command may collect data. Use the `lsattr` and `chdev` commands to list and change this attribute.

```
```
# lsattr -El sys0 -a iostat ◀──Check the iostat attribute
# chdev -l sys0 -a iostat=true ◀──Change the iostat attribute
