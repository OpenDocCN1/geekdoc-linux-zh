# ## COMPATIBILITY

With all the chip, system, and instruction architectures available in the POWER product line, one might be worrying about application compatibility in a mixed environment. The good news is that older binaries will likely run on newer architectures. Exceptions may include things like device drivers that have changed between releases of the AIX operating system. This should be less of a problem if all your boxes are running the same release.
