# ## Language Environment

Most likely, you got the correct language set during installation, but did you know that you can add other languages to the set? AIX will enable you to configure a hierarchy of language environments (see Figure 8-3). This may be helpful in multilingual communities. You can also use SMIT to translate messages, and flat files, into a new base language.

```
```
# smit mlang
```
```

# ## Set Characteristics of the Operating System

From just one panel in SMIT (see Figure 8-4), you can alter AIX kernel characteristics that hit most of the critical subsystems, including the virtual memory manager, the scheduler, and the dispatcher. It's a great screen for wreaking havoc on a system. Open the AIX Pandora's box by using the SMIT FastPath smit chgsys.

# smit chgsys
