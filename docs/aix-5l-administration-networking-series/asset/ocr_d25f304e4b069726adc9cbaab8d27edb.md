# Figure 12-1. Print Spooling SMIT panel

This SMIT panel is followed by the **Parent Interface Selection** panel, shown in Figure 12-7.

Now the final SMIT panel is displayed, **Add a Print Queue.** In this panel, you add the print queue name(s) that you want to add. For the IBM 4039 printer, there are two print queue options, PCL and PostScript. I am adding a queue for both types of printing, shown in Figure 12-8.

When you enter the print queue names and click **OK**, SMIT will create the print queue(s) and set the queue to an enabled state.
