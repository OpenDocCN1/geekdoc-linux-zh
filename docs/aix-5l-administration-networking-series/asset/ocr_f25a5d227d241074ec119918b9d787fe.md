.SH NAME
mycommand \- Does just what I want to do.
.SH SYNOPSIS
mycommand [will|wont] work
.SH DESCRIPTION
.B mycommand
is always used as a last resort. It can
be expected either to work or to fail.
.B mycommand
contains no surprises at all.
.SH OPTIONS
.TP 3
Will
Completes the work at hand.
.TP 3
wont
Take a vacation.
.SH BUGS
.B mycommand
is always error free!
.SH SEE ALSO
myprogram(1), myshell(1)
.SH AUTHOR
.B Me.
Who did you think it was?
