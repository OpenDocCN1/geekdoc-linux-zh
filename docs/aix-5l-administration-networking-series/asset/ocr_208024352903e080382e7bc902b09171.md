# WEB BROWSERS AND HELPER APPLICATIONS

AIX ships with Netscape Communicator that, like any browser, relies on MIME-type headers, sent from the Web server, to properly display images and other non text data. Browsers handle many common MIME data types internally or through browser plug-ins. When the browser is unable to handle the MIME type, either internally or via a plug-in, the browser usually asks the user how to handle the data.

+   □ Define virtual servers.
