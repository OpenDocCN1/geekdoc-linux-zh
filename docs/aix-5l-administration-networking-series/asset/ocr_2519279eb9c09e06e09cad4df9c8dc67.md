Once you have defined your network type, you may define each of the X stations being supported. You need to identify each X station’s network type, the hardware address of the adapter, whether xdm services will be used, and the initial application to be started. You may also define local printer support for X stations equipped with printers via the SMIT printer /plotter menu.
