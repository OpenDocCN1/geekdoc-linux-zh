# ## Registering Documents for Online Searching

Before documents on the documentation server can be searched or viewed, two things must take place: each document and document index must be created or installed on the DocSearch server, and the document and document index must be registered with the library service. There are two ways you can register the documents with the server. Most AIX applications have prebuilt indexes ready for the documentation server and will be automatically installed with the application. Or you can make the documents known to the server the hard way, manually creating the indexes for the documents on the server and then manually registering the indexes.
