When a JFS or JFS2 filesystem is created, a *log logical volume* is also created if it does not already exist. A log logical volume can support several filesystems within a volume group.

Create or update a JFS filesystem using the SMIT fast path or the **crfs** and **chfs**. A new JFS filesystem may be created in an existing empty logical volume, or a new logical volume will be built to hold the new filesystem (see Figure 11-8).
