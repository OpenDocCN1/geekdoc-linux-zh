# # CALLING FOR HELP

Once you have determined that a software or hardware problem exists, collect all the pertinent log, dump, and LED information before contacting IBM support. You might also want to run the **snap**, **lslpp -hc***<i>*filename</i>*, or **pmprmr** commands for a snapshot of the maintenance level and configuration of your system.

You can review the problem and service database yourself if you have network access to IBMLink or Support Line sites. If you don't have network access to these sites, IBM provides periodic snapshots of the IBMLink link and service databases on CD-ROM. You are now ready to contact IBM support. The following are the contact numbers for IBM support and the Web site for IBMLink:

+   *   1-800-CALL-AIX (software support)
+   *   1-800-IBM-SERV (hardware support)
+   *   `http://www.ibm.link.ibm.com/`
