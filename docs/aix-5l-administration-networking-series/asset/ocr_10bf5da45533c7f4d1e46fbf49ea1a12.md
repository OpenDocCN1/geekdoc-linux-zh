The kernel limits the maximum number of processes per user as specified by the kernel configuration parameter `maxproc`. The default value of 40 indicates that up to 40 processes may be running concurrently for a given user. The value may not be exceeded by logging into the system multiple times. The `maxproc` value may be altered using SMT, WebSM, or the `chdev` command (see the SMT panel in Figure 20-1).

```
# chdev -1 sys0 -a maxproc=80
# smit chgys
```
