oslevel -I.4.3.0 will help identify the missing filessets. The filessets used to determine the current AIX level are the BOS, base device, base printers, and X11.

Note that if you run the oslevel command after an ML update, the system will not report the ML in the oslevel command output. This output differs because the ML filessets are usually only a small subset of the operating system. The insfsfix command is a good tool for ML analysis. For example, the command insfsfix -i | grep AIX_ML will display all maintenance levels that have been installed on your system. To list only the latest maintenance level, you can use the oslevel -r command.

Another command that is useful for system information is the uname command. Issue the uname -a command to display the UNIX flavor, the system hostname, the operating system release, the operating system version, and the machine ID number. You can also get the version and release of the operating system with the uname -vr command. Note that uname will give the release level first, regardless of the argument order. Thus, “1 5” indicates version 5, release 1. The command uname -m displays machine ID in the form xxggggymmmss, which breaks down as follows:

| xx | 00 for RS6000 |
| --- | --- |
| gggg | CPU ID |
| mm | Model identifier |
| ss | Submodel identifier |

The command oslevel returns the AIX product level. Mine reads 5.1.0.0. Please refer to the man page for uname to help identify different machine models.

Your system maintenance level can be obtained from bos.rte history. Use the lslpp -h command to display the maintenance history and state. The -h option is best for reviewing which older filessets were installed and on what date the installation took place. The -o option will display the current patch level as updated to the /usr/lib/objrepos database. Please note that old filessets like DB2 version 2 will still need the -h option to see the current state (this problem was fixed with DB2 version 5).

```
# lslpp -h bos.rte

Fileset     Level Action Status  Date Time
Path: /usr/lib/objrepos
bos.rte
5.1.0.0 COMMIT COMPLETE 07/27/01 14:43:24
Path: /etc/objrepos
5.1.0.1 COMMIT COMPLETE 07/27/01 14:43:24
```

A quick snapshot of maintenance level and state can be obtained using the -L option to lslpp.

```
# lslpp -L bos.rte
```
