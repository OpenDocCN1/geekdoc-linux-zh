There are some tricks that will influence the hdisk number assignments that you may need to use at one point or another. An example is HASCMP clustered systems (see Chapter 28 for more details), where it is extremely important that the hdisk numbers for shared disks are in sync. One way of getting the hdisk numbers in sync is to power on the external disk sets one at a time and run **cfmgr** multiple times, one for each disk set power on. The trick is to duplicate the efforts on each machine at each step through the process.

The procedure would look something like the following:

+   1.  Stop all applications on both systems.
+   2.  Remove the hdisk definitions for all of the disks that you want to sync that are not in rootvg. Use the **rmdex -hdisk#** command for each disk. Repeat for all systems in the shared disk cluster.
+   3.  Run the **lssp** command to ensure that the all of the disks have been removed.
+   4.  Power down all of the disks for which you want the hdisk numbers to be in sync.
+   5.  Power on the first set of disks. These disks will receive the lowest hdisk numbers.
+   6.  Run **cfmgr -v** on each system. If you know the parent adapter for the disks, you can execute the **cfmgr -vl *adapter*** command.
+   7.  Run **lssp** to ensure that the disks are numbered as you want them on each system and to ensure that the disk numbers are in sync. You will need to refer to the PVID to ensure that the PVID and the hdisk numbers match on all systems.
+   8.  Repeat steps 5, 6, and 7 for the remaining disk sets.
