# ## DESKTOP SUMMARY

All the desktops can be customized, as seen in the following illustration, with the KDE panel, but the Common Desktop Environment (CDE) seems to be a few years ahead when it comes to ease of customization. I set up new users all the time and enjoy their amazement as I start pointing and clicking, opening windows, editing ".dprofile" then ".xinitrc," and copying over a custom ".twmrc" file before dragging the best little X calculator in the world to their main panel as I say: “there you are, all set up.” Just remember to make a snapshot of all the new configurations before you log off.
