# CHECKLIST

The following is a checklist for the key points in system monitoring and tuning:

+   Identify your workload as an AIX Systems Administrator.
+   Monitor and adjust are the CPU load, the system memory, disk input and output, and the network the system is attached to as part of the basic characteristics of the AIX operating system.
+   Identify the AIX tuning tools.
+   Identify the AIX monitoring tools.
