# What’s on CD-ROM?

The CD-ROMs that accompany this book contain Red Hat Linux 7.0. They also contain the Red Hat Linux 7 Weekend Crash Course Assessment Test. The following sections briefly explain both.

# Red Hat Linux 7.0

The CD-ROMs contain all Red Hat Linux 7.0 binary files with the Linux 2.2.16 kernel, which is the latest version of the Linux kernel available as of this writing (Fall 2000). Red Hat Linux 7.0 is designed to accommodate the version 2.4 kernel when it becomes available in late 2000 or early 2001. In addition to the Linux kernel, Red Hat Linux includes a large selection of Linux applications. Here are some significant software packages on the Red Hat Linux 7.0 CD-ROMs:

+   - Linux kernel 2.2.16 with driver modules for all major PC hardware configurations, including IDE/EIDE and SCSI drives, PCMCIA devices, some USB devices, and CD-ROM drives.
+   - Complete set of installation and configuration tools for setting up devices (such as keyboard and mouse) and services
+   - Graphical user interface based on the XFree86 package with GNOME and KDE desktops
+   - Full TCP/IP networking for Internet, LANs, and Intranets
+   - Tools for connecting your PC to your Internet Service Provider using PPP or dialup serial communications programs
