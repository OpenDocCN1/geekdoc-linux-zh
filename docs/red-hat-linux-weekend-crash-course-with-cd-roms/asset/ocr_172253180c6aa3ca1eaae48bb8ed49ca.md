# Sunday Morning Review Answers

+   1. The X server is a process (computer program) running on a computer that has a bitmapped display, a keyboard, and a mouse. X clients are applications that need to display graphical output and they do so by communicating with the X server. The X server controls the monitor, the keyboard, and the mouse. The X server responds to commands sent by X clients that open windows and draw in those windows.
+   2. The X configuration file is /etc/X11/XF86Config. I use the xf86config program to create a new X configuration file.
+   3. If the X graphical screen is partially working, I would press Ctrl+Shift+F1 to switch to the text console and log in as root at the text login prompt. Then I would run xf86config to create a new X configuration file. After that I'd type Ctrl+Alt+F7 to switch back to the graphical login screen and press Ctrl+Alt+Backspace to kill the X server and force it to restart with the new configuration file.
+   4. The processes that the init process starts at boot time depends on the run level, the contents of the /etc/inittab file, and a number of shell scripts (located in the /etc/rc.d directory and its subdirectories).
+   5. I'd look for the line with the keyword initdefault in the third field (the fields are separated by colons). The second field of this line specifies the default run level for my system.
+   6. The init process runs the /etc/rc.d/rc.sysinit script. This script, in turn, runs many other scripts from the subdirectories in the /etc/rc.d directory.
+   7. RPM refers to the Red Hat Package Manager, which is a system for packaging all the necessary files for a software product in a single file (referred to as an RPM file, or simply an RPM). Red Hat Linux and the bundled applications are distributed in the form of a large number of RPMs. To check if a specific RPM is installed on my system, I would type the command rpm -q package_name where package_name is the name of the RPM. For example, to check is the samba RPM is installed, I'd type rpm -q samba.
+   8. I can install RPMs by using the Gnome RPM graphical program or the rpm command line tool. To install an RPM with the command-line tool, I would change directory to the CD-ROM's RPM directory (usually, /mnt/cdrom/RedHat/RPMS) and type rpm -i filename where filename is the name of the RPM file.
