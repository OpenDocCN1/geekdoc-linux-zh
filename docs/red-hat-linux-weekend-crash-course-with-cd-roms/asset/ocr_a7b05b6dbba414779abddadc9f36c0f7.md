This session’s focus is on office applications — the ones that you need for day-to-day office work. This book’s companion CD-ROMs include all of the Red Hat Linux office tools discussed in this session: calendars, calculators, and spelling checkers. I also introduce you to several prominent commercially available office applications for Linux that are not included on the companion CD-ROMs.
