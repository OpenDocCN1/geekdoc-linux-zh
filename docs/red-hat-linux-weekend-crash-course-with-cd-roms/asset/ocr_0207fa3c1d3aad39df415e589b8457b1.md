Files from Red Hat Linux

To Go

Typically, you install Linux on a PC that previously had Microsoft Windows installed on it. If you happen to work in Windows as well as in Red Hat Linux, you probably want to access the DOS/Windows files from Red Hat Linux. This session shows you how to this, as well as how to mount and access MS-DOS/Windows floppy disks. You also learn about a package called mtools, which enables you to access and use MS-DOS/Windows files on a floppy disk in Red Hat Linux.
