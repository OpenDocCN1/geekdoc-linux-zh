As the output shows, all files with names starting with K and S are symbolic links to scripts that reside in the /etc/rc.d and /etc/rc.d/init.d directories. In fact, the /etc/rc.d/rc script executes these files exactly in the order that they appear in the directory listing.

Note that the last file in the directory listing is a symbolic link to the ../rc.local script. This means that /etc/rc.d/rc.local is executed after all other scripts. So you can place in that script any command you want executed whenever your Linux system boots.

Most of the startup scripts reside in the /etc/rc.d/init.d directory. You can manually invoke scripts in this directory to start, stop, or restart specific processes — usually servers. For example, to stop the Web server, type the following command:

```
/etc/rc.d/init.d/httpd stop
Shutting down http: [ OK ]
```

You can enhance your system administration skills by familiarizing yourself with the scripts in the /etc/rc.d/init.d directory. To see the listing, type the following command:
