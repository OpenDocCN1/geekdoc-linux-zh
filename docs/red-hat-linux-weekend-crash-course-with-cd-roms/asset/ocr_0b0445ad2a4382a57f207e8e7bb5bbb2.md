# Verifying the PPP connection is up

After you connect using the Dialup Configuration tool, you can verify that the PPP connection is up by typing the /sbin/ifconfig command, which shows a listing such as this:

```
/sbin/ifconfig

          inet addr:192.168.1.200  Bcast:192.168.1.255  Mask:255.255.255.0

          RX packets:4363 errors:0 dropped:0 overruns:0 frame:0

          collisions:0 txqueuelen:100
```
