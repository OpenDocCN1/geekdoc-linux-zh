# Set the time zone

After completing the network configuration, you have to select the time zone — the difference between the local time and the current time in Greenwich, England, which is the standard reference time. The time zone is also known as Greenwich Mean Time (GMT) or UTC, which was selected by the International Telecommunication Union (ITU) as a standard abbreviation for Coordinated Universal Time. The installation program shows you the Time Zone Selection screen (see Figure 3-3) from which you can select the time zone, either in terms of a geographic location or as an offset from the UTC. Figure 3-3 shows the selection of a time zone in a geographic location.
