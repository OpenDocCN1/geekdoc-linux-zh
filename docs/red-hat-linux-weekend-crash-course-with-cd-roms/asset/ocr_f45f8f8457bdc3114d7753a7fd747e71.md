The Minicom help screen

In the help screen, you can get information about other Minicom commands. From the help screen, press Enter to return to online mode. In online mode, you can use the modem’s AT commands to dial out. In particular, you can use the ATDT command to dial the phone number of another modem (for example, your Internet Service Provider’s computer or a system at your work), as shown in Figure 11-5. Once you get the login prompt, you can log in as usual and use the remote system.

![](bbox=[0.2, 0.53, 0.7, 0.75])

# Figure 11-5
Dialing a remote system using Minicom

When you log out of the other system and want to exit Minicom, press Ctrl+A and then type X to exit the program. Press Enter again in response to the Minicom prompt.
