
# Red Hat Linux 7 周末速成课程评估测试

CD-ROM 包含 60 道多项选择题及答案。这些测试题有两个用途。你可以用它们来评估你对 Red Hat Linux 已知的程度，从而确定可以跳过的章节。你也可以在阅读本书各章节后做这些题目，以评估你所学到的内容。题目按章节组织；因此它们遵循本书讨论主题的顺序。每个题目对应的章节在题目旁注明。
