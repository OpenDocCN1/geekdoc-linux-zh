Now that you have installed Red Hat Linux from this book’s companion CD-ROMs, you are ready to explore and learn it. In this session, you first learn how to log in, log out, and shut down your Linux system. Then you power up again and take a quick tour of the GNOME and KDE graphical user interfaces (GUIs — pronounced “gooe-ease”).
