The text fields are already filled in and you can accept these as is. You do have to select an input filter, which is a printer driver that depends on the make and model of the printer you are connecting to the parallel port. To do this, click the Select button next to the Input Filter text field. This brings up a large dialog box (Figure 4-6) that enables you to select the printer type and pick some other parameters such as the paper size and the resolution of the printer (typically 600×600 dots per inch in modern laser printers). You should select the appropriate values for all the fields.
