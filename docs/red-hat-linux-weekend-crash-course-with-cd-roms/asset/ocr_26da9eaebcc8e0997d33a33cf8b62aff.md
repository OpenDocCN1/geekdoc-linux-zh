# Building a New Kernel

# Session Checklist

+   ✓ Installing the source files and rebuilding the kernel
+   ✓ Configuring the kernel
+   ✓ Building and installing the kernel and modules
+   ✓ Rebooting the system with a rebuilt kernel

Sometimes you may have to rebuild the kernel — the core operating system — from source files. For example, you may want to take advantage of some experimental driver that is not supported by the version of kernel shipped on the CD-ROMs. This session shows you how to install the source files for the kernel; configure the kernel; and build and install the new kernel and modules. Finally, this session shows you how to reboot the system after you rebuild and install the kernel.
