# What Is KDE?

From the user’s perspective, KDE provides a graphical desktop environment that includes a window manager (kwm), a file manager (kfm), a panel (kpanel) for starting applications, a help system, a configuration tools, and many applications, including an image viewer, PostScript viewer, and mail and news programs.

From the developer’s perspective, KDE has class libraries and object models for easy application development in C++. KDE itself is a large development project.

You can always find out the latest information about KDE by visiting the KDE home page at http://www.kde.org/.
