# Working with Screen Savers and Playing Games

# Session Checklist

+   - ✓ Activating screen savers

+   - ✓ Playing games in KDE

![](bbox=[0.01, 0.6, 0.1, 0.7])

Now that you know how to customize the GNOME and KDE graphical desktops and switch from one to the other, you can turn to some fun. Both GNOME and KDE desktops in Red Hat Linux come with quite a few games and screen savers. In this session, you learn how to set up and activate the screen savers and explore some games.

![](bbox=[0.13, 0.7, 0.26, 0.77])

You should have the games installed on your system. This is assuming you selected the Games package group when you installed Red Hat Linux from this book’s companion CD-ROMs in Session 3.
