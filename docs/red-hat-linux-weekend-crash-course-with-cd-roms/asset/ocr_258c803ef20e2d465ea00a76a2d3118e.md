+   - On each client system, mount the directories exported by the Red Hat Linux server using the mount command.

The only problem in using NFS for file sharing is that each client system must support NFS. Most PCs do not come with NFS. That means you have to buy NFS software separately if you want to share files using NFS. It makes sense to use NFS if all systems on your LAN run Linux (or other variants of UNIX with built-in NFS support). I walk you through NFS setup using an example of two Red Hat Linux PCs on a LAN.

# Exporting a file system with NFS

On the server, you must run the NFS service and also designate one or file systems to export — make available to the client systems. You can perform both tasks using the Linuxconf graphical system administration tool.

To start Linuxconf, log in as root and select Main Menu ⇒ Programs ⇒ System ⇒ Linuxconf from the GNOME desktop. On the Linuxconf Config tab, select Net-working ⇒ Server tasks ⇒ Exported file systems (NFS) from the tree menu. This brings up the Exported file systems tab that shows the current contents of the /etc/exports file. If that file is empty, Linuxconf displays the empty Exported file systems dialog box (as shown in Figure 15-1).
