The window in the middle of the screen displays a welcome message with your system’s host name — the name you assign to your system when you configure the network. If the network is not configured, localhost.localdomain is used as the host name.

You can log in using any of the accounts, including root, which you define during the installation. For example, to log in as root, type root (move the mouse over the login window before you begin typing) in the text field and press Enter. Then type the root password (the one you set during installation) to log in as the super user.

Because the default GUI is GNOME, the GNOME desktop appears along with a warning dialog box from the GNOME File Manager. Click the OK button to dismiss the warning dialog box. The GNOME Hints window appears and you get a desktop (as shown in Figure 5-2).
