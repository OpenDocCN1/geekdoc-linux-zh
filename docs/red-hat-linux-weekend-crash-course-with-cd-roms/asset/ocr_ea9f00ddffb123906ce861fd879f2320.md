The Saturday afternoon sessions focus on data communications using a modem or an Ethernet local area network (LAN). This first session introduces you to serial ports through which you can connect modems to a Linux system. If you’re using Red Hat Linux at home or in your office, you probably want to use a modem for one or more of the following reasons: to dial out to another computer (such as a bulletin-board system) or another UNIX system; to enable other people to dial in and use your Linux system; or to use dial-up networking with Point-to-Point Protocol (PPP) to connect to the Internet through an Internet Service Provider (ISP). This session covers the first use of a modem: to dial out from your Red Hat Linux PC.
