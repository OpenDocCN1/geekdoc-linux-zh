As a system administrator, you have to worry about your Linux system’s security. For a standalone system or a system used in an isolated local area network (LAN), you must ensure that a user does not intentionally or inadvertently modify, delete, or destroy system files. If your Linux system is connected to the Internet, you must also secure the system from unwanted accesses. Intruders, also known as *crackers*, typically impersonate a user, steal or destroy information, and even deny access to your own system (known as *denial of service*). This session only briefly covers some key aspects of securing your Linux system. As you’ll see, Red Hat Linux already includes the tools you need to maintain system security.
