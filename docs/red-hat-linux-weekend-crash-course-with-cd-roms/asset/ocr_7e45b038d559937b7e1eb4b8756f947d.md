# Mounting and Accessing DOS/Windows Floppy Disks

Just as you can mount a DOS/Windows hard disk partition under Linux, you can mount a DOS/Windows floppy disk. Usually, you have to log in as root to mount a floppy, but you can follow the steps shown in the latter part of this session to set up your system so that any user can mount a DOS/Windows floppy disk. You also need to know the device name for the floppy drive. By default, Linux defines two generic floppy device names:

+   - /dev/fd0, which is the A: drive (the first floppy drive)
+   - /dev/fd1, which is the B: drive (the second floppy drive, if you have one)

As for the mount point, an existing directory named /mnt/floppy is meant specifically for this type of temporary mount operation. Thus, you can mount the DOS floppy disk on the /mnt/floppy directory with the following command:

```
mount -t vfat /dev/fd0 /mnt/floppy
```
