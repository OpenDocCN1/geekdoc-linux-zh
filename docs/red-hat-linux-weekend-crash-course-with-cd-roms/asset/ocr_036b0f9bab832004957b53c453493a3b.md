
When you install LILO, if you specify the Linux partition as the default, you can simply wait; after a few seconds, LILO boots Linux.

![](bbox=[0.18, 0.28, 0.3, 0.36])

If you want to boot from another partition (such as Windows), press the Tab key. LILO displays the names of the available bootable partitions. For example, a typical display might be:

```
linux dos
```

You can then type the name of the partition you want to boot or press Enter to boot from the first partition.

After LILO boots Linux, you should see a long list of opening messages — including the names of the devices that Linux detects. At the end of all the messages, you see a graphical login screen like the one in Figure 5-1.
