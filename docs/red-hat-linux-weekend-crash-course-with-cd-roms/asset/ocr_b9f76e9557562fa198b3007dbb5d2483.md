# Making Room for Red Hat Linux

# Session Checklist

+   - Repartitioning your hard drive with FIPS
+   - Starting the Red Hat Linux installation
+   - Partitioning the hard disk for Red Hat Linux

![](bbox=[0.01, 0.62, 0.1, 0.78])

In the previous session, you gathered information about your PC's hardware and prepared a Red Hat boot disk. This session shows you how to do one more preparatory task — setting aside disk space. It also demonstrates the next step: How to use the Red Hat boot disk to begin the Red Hat Linux installation and then partition (divide) the disk again — this time under Linux — to create the necessary Linux partitions. Then you move on to the next session, which shows you how to finish installing Red Hat Linux.

![](bbox=[0.12, 0.78, 0.24, 0.86])

If you plan to install Red Hat Linux on a second hard disk or you want to completely wipe out your current disk and install Red Hat Linux on it, you do not have to go through the process of repartitioning your hard disk under MS-DOS to create room for Red Hat Linux. Skip the next section and proceed to the “Starting the Red Hat Linux Installation” section.
