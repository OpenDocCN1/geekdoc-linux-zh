# Setting Up Internet Services

# Session Checklist

+   - ✓ Understanding Internet services
+   - ✓ Using the e-mail server
+   - ✓ Setting up the Apache Web server
+   - ✓ Setting up the FTP server

![](bbox=[0.01, 0.66, 0.1, 0.78])

You can use the Red Hat Linux PC as a server if it’s connected to the Internet or an intranet (a private TCP/IP network). Both the Internet and intranets rely on Internet services. Each Internet service involves configuring and running one or more servers on the Red Hat Linux system. This session introduces you to the commonly used Internet services. It then focuses on the servers that implement the mail, Web, and information retrieval Internet services: the e-mail server, the Apache Web server, and the FTP server (which enable anyone to download files from your system in a reasonably secure manner).
