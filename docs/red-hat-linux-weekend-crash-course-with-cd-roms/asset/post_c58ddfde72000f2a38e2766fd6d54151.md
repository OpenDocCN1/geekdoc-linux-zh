- 1. The X server is a process (computer program) running on a computer that has a bitmapped display, a keyboard, and a mouse. X clients are applications that need to display graphical output and they do so by communicating with the X server. The X server controls the monitor, the keyboard, and the mouse. The X server responds to commands sent by X clients that open windows and draw in those windows.
