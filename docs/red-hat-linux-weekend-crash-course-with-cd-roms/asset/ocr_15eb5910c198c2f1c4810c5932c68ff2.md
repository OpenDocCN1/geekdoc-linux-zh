Now you should have a file named fstab in your home directory. Type the following command to begin editing a file in ed:

```
ed -p: fstab
608
:
```

This example uses the -p option to set the prompt to the colon character (:) and opens the fstab file (in the current directory, which should be your home directory) for editing. The ed editor opens the file, reports the number of characters in the file (608), and displays the prompt (:), and waits for a command.

![](bbox=[0.15, 0.36, 0.27, 0.44])

When editing with ed, you may find it helpful to always turn on a prompt character using the -p option. Without the prompt, it’s difficult to tell whether ed is in input mode or command mode.

After ed opens a file for editing, the current line is the last line of the file. To see the current line number (the current line is the line to which ed applies your command), use the .= command:

```
:.=
8
```

This output tells you that the fstab file has eight lines. (Your system’s /etc/fstab file may have a different number of lines, in which case you see a different number.)

You can use the 1,$p command to see all lines in a file, as the following example shows:

```
:1,$p
LABEL=/                 /               ext2    defaults        1 1
/dev/hda1               /dos c          vfat    defaults        0 0
/dev/cdrom              /mnt/cdrom      iso9660 noauto,owner,ro 0 0
/dev/fd0                /mnt/floppy     auto    noauto,owner    0 0
/dev/zip                /mnt/zip        auto    noauto,owner    0 0
none                    /proc           proc    defaults        0 0
none                    /dev/pts        devpts  gid=5,mode=620  0 0
/dev/hda4               swap            swap    defaults        0 0
:
```

To go to a specific line, type the line number:

```
:8
/dev/hda4               swap            swap    defaults        0 0
:
```
