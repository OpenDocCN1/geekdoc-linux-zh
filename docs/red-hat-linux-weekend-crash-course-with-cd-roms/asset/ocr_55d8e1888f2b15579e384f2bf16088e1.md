The `/etc/services` file contains information about Internet services and the corresponding port numbers.

13. The Apache Web server configuration files are located in the `/etc/httpd/conf` directory. The `/var/log/httpd` directory is where the Apache Web server's log files (access logs and error logs) are located. The `/etc/rc.d/init.d/httpd` script starts the `httpd` process as the Red Hat Linux system boots.

14. When I use FTP to transfer files to or from a remote system, I have to log in to the remote system before I can use FTP. With anonymous FTP, I log in using the user name `anonymous`, which anyone can use with FTP to transfer files from a system. On my system, I would place in the `/home/ftp/pub` directory any files that I want others to download using anonymous FTP.

15. To set up a file server with Network File System (NFS), I would first export one or more directories by listing them in the `/etc/exports` file. Then I would start the NFS server using Linuxconf. On each client system, I would mount the directories exported by the server using the `mount` command.

16. I would have to configure the Samba software to make your Linux system work as a Windows server. To check if Samba is installed, I'd type the command `rpm -q samba` and look for the output to show a line with the Samba software's version. The Samba configuration file is named `/etc/smb.conf`. To restart the Samba software, I'd type:

`/etc/rc.d/init.d/smb restart`

18. The following command mounts the `/dev/hda2` file system at the mount point `/mnt/dos`:

`mount -t vfat /dev/hda2 /mnt/dos`

To make sure that Linux automatically mounts `/dev/hda2` whenever the system boots, I would add the following line to the `/etc/fstab` file:

`/dev/hda2  /mnt/dos  vfat  defaults  0 0`
