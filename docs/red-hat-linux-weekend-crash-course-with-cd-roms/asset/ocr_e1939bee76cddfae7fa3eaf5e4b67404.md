# CD-ROM Installation Instructions

This book’s companion CD-ROMs contain Red Hat Linux 7.0. These CD-ROMs include all Red Hat Linux 7.0 binary files with the Linux 2.2.16 kernel. Installing Red Hat Linux is a big job — too big to adequately describe in the space available here. For complete instructions, see Sessions 1, 2, and 3.
