If you want to log in as a normal user and play audio CDs on the CD-ROM drive, you should first log in as root and set the permissions settings on the CD-ROM device so that anyone can read the CD-ROM device. You have to set the permissions for the actual CD-ROM device, not the generic /dev/cdrom device. To set the permissions settings, follow these steps:

+   1. Log in as root. If you are already logged in, type the su command and enter the super user's password to assume the identity of root.
+   2. Make the CD-ROM device readable by all users using the chmod command as follows:

```
chmod o+r /dev/cdrom
```
