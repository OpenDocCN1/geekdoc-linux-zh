9. A typical RPM file has the form XFree86-3.3.6-20.i386.rpm. Everything up to the first dash is the RPM name (XFree86); the numbers between the two dashes is the version number (3.3.6); the next number is Red Hat’s release number (20); the next extension (i386) is the architecture; and the final extension is rpm to denote that this is an RPM file.

10. I might rebuild the Linux kernel after I patch the kernel sources, to add SCSI support directly into the kernel, or to add support for some experimental hardware.

11. I’d log in as root and mount the CD-ROM with the command mount /mnt/cdrom. Then I’d type the following commands:
```
cd /mnt/cdrom/RedHat/RPMS
rpm -ivh kernel-source*
```

12. To rebuild the kernel, I have to configure the kernel, make the kernel, make the modules, and install the kernel and a few other files.

13. I might want to back up files late in the night, download large files at nights, or send myself e-mail reminders at a future time. I can use the at command to submit commands to be executed at a future time. I can use the crontab facility to run programs automatically at regular intervals.

14. For example, suppose I want to execute the /usr/local/bin/ppp-off script at 11:35 P.M., I’d log in as root and type the following commands:
```
at 23:35
at> /usr/local/bin/ppp-off
at> (Press Ctrl+D)
```

15. I would first create a shell script with the commands that I want to execute periodically. I would then prepare a text file with information about the times when I want the shell script executed. Then I’ll submit this file using the crontab command.

16. I would create the /etc/at.allow file with the names of users who are allowed to submit one-time jobs. For recurring jobs, I’d create the /etc/cron.allow file with the names of the users who are allowed to submit recurring jobs with the crontab command.

17. Floppy disk, SCSI Zip disk, and SCSI tape are some of the backup media on which I can back up files. The device name for floppy drive is /dev/fd0, SCSI Zip drive is /dev/sda (assuming it’s the first drive), and SCSI tape drive is /dev/st0.
