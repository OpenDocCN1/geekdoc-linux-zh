## Linux 工具：应用安全

### Whisker

Rain.Forest.Puppy的CGI漏洞扫描器Whisker，是第一个包含检查常见漏洞所有方法的工具，具有针对HTTP响应代码做出反应的智能扫描功能以及入侵检测规避工具。Whisker是用Perl脚本编写的。

### Flawfinder

Flawfinder是一个Python程序，它搜索源代码中的潜在安全缺陷，并根据风险严重程度列出这些缺陷。风险级别取决于函数及其值和参数。

### 高级入侵检测环境 (AIDE)

AIDE（高级入侵检测环境）是Tripwire的免费替代品。AIDE中使用的配置文件类似于Tripwire，因此从一个转换到另一个很容易。AIDE在指定期望的权限/校验和的方法方面比Tripwire更好。AIDE的配置信息保存在aide.conf文件中。它根据配置文件中的正则表达式规则创建数据库。一旦数据库初始化，就可以用来验证文件的完整性。这个第一个AIDE数据库是系统正常状态的快照，也是衡量所有后续更新和变更的标准。AIDE可以配置以自定义检查的详细程度。它递归遍历宿主系统上的每个目录，以确定哪些文件应包含在数据库中。文件与用户指定的文件及路径名称进行匹配。在使用AIDE之前，应该创建一个初始数据库。为AIDE创建数据库的命令是 `aide -i -c /etc/aide.conf`。

该命令创建文件系统的第一幅快照。在将系统接入网络之前应创建数据库。AIDE可以不加-i选项运行，以检查是否有任何更改。如果更改似乎是真实的，则用户可以使用-u选项更新数据库，以防止AIDE报告自上次更新以来的变更。-u选项不会覆盖数据库。以下是AIDE中需要查找的几个状态检查定义：

- **i** (inode number)：inode number的变更表示文件已被删除或文件名已更改。
- **s** (file size)：文件大小的变更表示文件内容已更改。
- **m** (modification time)：显示文件最后一次修改的时间。

## Linux 工具：加密

### Stunnel

Stunnel是一个允许用户在SSL（安全套接字层）内部加密任意TCP连接的程序，在UNIX和Windows上均可用。Stunnel让用户通过由Stunnel提供加密而不改变守护程序代码的方式来保护非SSL感知的守护程序和协议（如POP3、IMAP、NNTP和LDAP）。Stunnel提供了inetd的相同功能，并增加了SSL加密。Stunnel还支持TCP Wrappers。

### OpenSSH/SSH

SSH（安全外壳）是一个用于登录远程机器和在远程机器上执行命令的程序。它在两个主机之间通过不安全的网络提供安全加密通信。它被描述为带有加密和RSA认证的R命令替代方案。

### GnuPG

GnuPG是PGP的替代品。由于它不使用专利的IDEA算法，因此可以无限制地使用。

## Linux 工具：日志和流量监控器

### MRTG (多路由流量绘图器)

多路由流量绘图器（MRTG）是一个用于监控网络链接上流量负载的工具。MRTG生成包含PNG图像的HTML页面，提供流量的实时视觉表示。MRTG由一个使用SNMP读取路由器流量计数器的Perl脚本和一个记录流量数据并创建代表被监控网络连接上流量的图表的快速C程序组成。

以下是MRTG的关键特性：

- 它是可移植的。
- 它附带一组使配置和设置变得非常简单的配置工具。
- 其生成的网页外观具有高度可配置性。

### Swatch

Swatch最初是为了主动监控通过UNIX syslog实用程序写入日志文件的消息而编写的。作为一个简单的演示，用户可以输入 `perl swatch --examine=FILENAME`，其中FILENAME是用户想要查看其内容的文件。

### Timbersee

Timbersee是一个与Swatch非常相似的程序。它使用正则表达式来监控日志文件中的重要消息，但其区别在于它可以同时监视多个日志文件，并且不会分出额外的进程。

### Logsurf

Logsurf被设计为实时监控系统上任何基于文本的日志文件。收集的大量日志信息（例如syslog守护程序处理的所有消息或信息服务的日志文件）使得手动检查日志以寻找异常活动几乎不可能。Logsurf实现了日志文件监控的自动化。

### IPLog

IPLog是一个TCP/IP流量记录器。它能够记录TCP、UDP和ICMP流量。其功能包括检测TCP端口扫描、TCP空扫描、FIN扫描、UDP和ICMP smurf攻击、虚假TCP标志（扫描器用于检测正在使用的操作系统）、TCP SYN扫描、TCP Xmas扫描、ICMP ping洪水、UDP扫描和IP碎片攻击的能力。它能够在混杂模式下运行并监控网络上所有主机的流量。它使用libpcap从网络读取数据，并且可以移植到任何支持pthreads且libcap能正常工作的系统。

### Ntop

Ntop是一个显示网络使用情况的网络流量探针，类似于流行的**top** UNIX命令所做的。Ntop基于libpcap，因此它可以在几乎每个UNIX平台以及Win32上运行。

Ntop的用户可以使用Web浏览器（例如Netscape）浏览Ntop（充当Web服务器）的流量信息，并获取网络状态转储。在后一种情况下，Ntop可以被视为一个带有嵌入式Web界面的简单RMON类代理。

### Linux安全审计工具 (LSAT)

Linux安全审计工具（LSAT）是用于Linux和UNIX的安装后安全审计员。它监控系统配置和系统上的网络设置，检查常见的安全/配置错误以及不需要的包。LSAT的所有模块都是用C编写的。LSAT软件包中的一些模块如下：

- **checkdotfiles**：此模块检查系统上的forward、exrc、rhosts和netrc文件。
- **checkfiles**：此模块检查/usr/var目录中的文件是否具有root所有权，除了检查/tmp和/var/tmp是否设置了粘滞位之外。
- **checkftpusers**：此模块检查/etc/passwd中的所有帐户是否都在/etc/ftpusers中。
- **checkinetd**：检查/etc/inetd.conf或/etc/xinetd.d/*。
- **checkkbd**：检查在Linux下是否禁用了Ctrl+Alt+Alt+Del功能。它还检查在Solaris下是否启用了KEYBOARD\_DISABLE。
- **checklogging**：一个简单的检查，以确保auth和authpriv日志设施已开启。
- **checkmodules**：检查以确保可加载内核模块已启用。
- **checknetp**：验证没有接口处于混杂模式。
- **checkopenfiles**：使用LSOV（如果LSOV已安装）检查系统上的所有打开文件。
- **checkpasswd**：此模块检查/etc/passwd中不需要的帐户。它还检查只有root的UID=0。
- **checkmd5**：对所有常规文件执行系统范围的MD5校验和，仅在-use -m开关时执行。

## Linux 安全对策

### 物理安全

- 将计算机锁在安全的地方。

### 密码安全

- 不要使用容易猜到的密码。
- 不要与另一个人共享你的帐户。
- 检查具有空密码的用户。
