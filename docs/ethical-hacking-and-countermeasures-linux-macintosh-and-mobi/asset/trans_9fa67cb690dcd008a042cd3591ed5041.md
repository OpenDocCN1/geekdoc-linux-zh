
许多与标签相关的技术控制措施要求标签执行额外的计算并拥有额外的易失性内存。因此，使用此类技术控制措施的标签比未使用此类控制措施的标签需要更精密的微芯片。对于无源标签，标签可能需要更接近阅读器才能获得执行这些计算所需的功率。或者，阅读器可能需要以更高的功率水平运行，尽管在许多情况下这可能不可行或不被允许。无源标签的这些固有特性可能会限制某些技术控制措施在特定环境中的应用。

针对 RFID 系统的所有组件，包括射频、企业和企业间子系统，都存在技术或逻辑控制措施。本节重点讨论射频子系统的技术控制措施。企业和企业间子系统也存在许多控制措施，但这些通常适用于一般的 IT 系统，而非特指 RFID 系统。

射频子系统控制措施的一般类型包括以下内容：

- 为 RFID 组件和交易提供认证和完整性服务
- 保护阅读器与标签之间的射频通信
- 保护存储在标签上的数据

## RFID 安全

RFID 通信应得到保护，以维护通信隐私并避免对存储在标签中的信息进行篡改。RFID 标签在标签的保留内存块中包含一个安全位。该安全位应始终开启。可以使用以下安全保护方法来保护标签免受读写操作的影响：

- *可重写标签上的随机交易 ID*：为了理解这个概念，可以以图书馆为例。在每次借书时，阅读器选择一个随机数 'r' 并读取标签数据 'D'。这对 (r, D) 被存储在 RFID 数据库中。然后，RFID 阅读器从标签中删除 D 并写入 r。对于每次还书，图书馆阅读器读取 r，从数据库中查找相应的 D，并将 D 写回标签。
- *通过持久状态改进密码*：存储在 RFID 标签中的持久密码容易受到窃听攻击。从标签到阅读器的通信比从阅读器到标签的通信更难被窃听。为了增强这些密码的安全性，RFID 标签向阅读器发送一个随机数（通知）。这个随机数是恢复标签密码所必需的。攻击者需要捕获这个随机数才能窃听密码，这使得窃听攻击变得困难。
- *标签和阅读器互认证且保护标签隐私的方案*：
    - *PRF（脉冲重复频率）私有认证方案*：此技术使用共享密钥和 PRF 来保护标签与阅读器之间通信时的消息。
    - *基于树的私有认证*：已构建了一种新的基于树的协议以提供私有认证。此树方案对阅读器和标签的所有实例采用单一安全参数 *k*。
    - *两阶段树方案*：此方案采用两个阶段的基于树的认证。在第一阶段，使用恒定安全参数创建的 R1 和 T1（阅读器和标签实例）运行树方案，并识别标签。在第二阶段，当检测到标签时，阅读器和标签可以执行以 *k* 作为安全参数的 R1 和 T1。

## 章节总结

- RFID（射频识别）是一种自动识别方法，使用无线电波、RFID 标签和 RFID 阅读器来识别对象并传输与该对象关联的数据。
- RFID 系统中的标签碰撞发生在许多标签被 RFID 标签阅读器激发，且标签同时向阅读器反射各自信号时。
- RFID 技术结合了多种不同的计算和通信技术。这种复杂性带来了以下风险：业务流程、商业智能、隐私和外部性。
- RFID 技术使组织能够显著改变其业务流程。然而，为了成功实施 RFID 技术，组织必须了解涉及的风险以及如何管理它们。
- 攻击者在尝试获取 RFID 标签上存储的信息的未授权访问时，会使用嗅探、追踪、欺骗、重放攻击和拒绝服务攻击。
- 用于避免 RFID 攻击的反制措施包括 RSA 屏蔽器标签、自毁开关、加密、检测和规避以及临时停用。
- RFID Guardian 是一种便携式、电池供电的设备，中介于 RFID 阅读器和 RFID 标签之间的交互，有助于检测未授权的 RFID 活动。
- 恶意软件是破坏和干扰计算机系统的有害软件。RFID 恶意软件通过 RFID 标签传输和执行恶意软件，包括 RFID 蠕虫、RFID 病毒和 RFID 漏洞利用。
- RFID 信用卡容易受到以下类型的攻击：追踪、窃听、刷卡窃取、重放和中继以及交叉污染。
- RFDump 是一种可利用 RFID 标签信息的黑客工具。
- RFID 安全控制措施包括管理、运营和技术控制措施。
- RFID 通信应得到保护，以维护通信隐私并避免对存储在标签中的信息进行篡改。

### 关键术语

- **电可擦除可编程只读存储器 (EEPROM)** USB 设备中使用的内存类型
- **外设** 物理输入/输出设备
- **USB（通用串行总线）设备** 一种可插入 USB 端口的外设类型
- **USB 端口** 一种即插即用硬件接口，用于将 USB 外设（如磁盘驱动器、打印机、内存棒、鼠标、键盘和游戏杆）连接到计算机

### 案例示例

2007 年 5 月，专家警告计算机用户注意一种通过 USB 驱动器传播的新蠕虫。名为 SillyFD-AA 的蠕虫安装到计算机系统中，在 Internet Explorer 中显示 “Hacked by lBYTE” 的消息，并在诸如 USB 驱动器和软盘等可移动设备上安装 AutoRun.inf 文件。此蠕虫可以充当后门并将恶意代码插入计算机。一旦受感染的 USB 设备连接到计算机，蠕虫会自动安装并传播。

提醒计算机用户不要将未知设备插入他们的计算机，因为这些设备可能包含恶意代码。用户还被建议关闭 AutoRun
