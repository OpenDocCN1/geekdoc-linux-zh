Previously used USB devices can be uninstalled, and currently connected USB devices can be disconnected. A user can run USBDev on a remote computer if he or she is logged in as an administrative user on that computer.

This utility does not require an installation process or additional DLL files. The executable file (USBDev.exe) is copied to any folder and then run. The main window of USBDev displays all USB devices installed on the system. A user can select one or more items, and then disconnect (unplug) them, uninstall them, or save the information into a text, XLM, or HTML file.

# AutoPlay

AutoDev allows users to automatically run a file on USB flash memory devices based on the commands in the Autorun.inf file. Users can manually activate the AutoPlay feature by selecting the desired device and pressing F8. Alternatively, a user can check the **AutoPlay When Device Is Connected** option, and then the AutoPlay feature automatically activates when a USB flash memory device is inserted.

# USB Blocker

USB Blocker integrates with Active Directory and enables system administrators to control access to USB ports on remote computers. The tool uses built-in Group Policy mechanisms to enforce centralized access control, so there is no need to install software on client computers. This control prevents unauthorized use of removable media that connect to USB ports and enables regulatory compliance, such as SOX, GLBA, and HIPAA.
