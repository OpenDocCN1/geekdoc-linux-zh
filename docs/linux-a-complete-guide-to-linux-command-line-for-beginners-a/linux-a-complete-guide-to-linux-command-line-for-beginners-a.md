### 操作系统是如何工作的？

在我们充分理解 Linux 是什么以及它是如何工作之前，我们首先需要了解什么是操作系统以及它是如何运作的。操作系统可以被认为是安装在你的计算机上的软件和硬件之间通信的中间人。你每天都会使用许多操作系统，但你最熟悉的可能是安装在你个人电脑上的那个系统。这可能是 Windows XP（特别是对于旧电脑）、Windows 7、Windows 8 或最近的 Windows 10。Macbook 用户可能熟悉某个 Mac OS 版本，如 Mac OS X。无论如何，这些操作系统的任务是管理你台式机或笔记本电脑内的所有资源。

操作系统由许多部分组成，每个部分都有自己的功能，帮助计算机执行你分配给它的任务。对于 Linux，这些部分包括：

- 引导程序 (The Bootloader) - 这是让你的计算机能够启动你需要使用的程序的软件。这通常是操作系统启动时出现的一个屏幕。引导程序启动所有为了以可用方式呈现你的系统所需的进程。

- 内核 (The Kernel) - 内核是一个控制整个操作系统的程序。它可以被认为是系统的核心，负责管理 CPU、内存和外围设备。内核是操作系统最基本的元素，意味着它确保了关键系统功能的运行。

- 守护进程 (Daemons) - 这些在后台运行的服务。它们仅为某些命令启用必要的进程。例如，它们管理文档打印、声音和调度等。这些服务通常在计算机启动或桌面启动时立即开始。

- 壳 (The Shell) - 在 Linux 早期，许多人对 Linux 命令行（shell）感到畏畏。shell 允许用户通过在文本界面中输入的命令向计算机发布任务。这并不是特别用户友好，对于技术或编程知识很少的用户来说这似乎是一项艰巨的任务。随着技术的进步，开发出了用户界面来吸引那些不太精通技术的人，变得简单得多。

- 图形服务器 (Graphical Server) - 这是你在屏幕上看到的内容；它允许通过图形用户界面发布命令。图形服务器被称为子系统或 X server。

- 桌面环境 (Desktop Environment) - 这是用户与操作系统交互的区域（而不是过去的命令行方法）。Linux 的优势之一是提供了多种桌面环境，包括 Unity、GNOME、Cinnamon、Enlightenment、KDE、XFCE 等等。每种桌面环境都内置了应用程序，帮助用户管理文件、配置计算机、使用互联网甚至玩游戏。

- 应用程序 (Applications) - 应用程序是执行一组协调任务的程序，如文字处理器或照片编辑器。某些应用程序可能随操作系统一起捆，还有成千上万的应用可以下载。Linux 提供了许多可以通过类似于 Apple App Store 的程序 Ubuntu Software Center 进行搜索、下载和安装的应用，它是作为 Ubuntu Linux 的一部分提供的。

### Linux 的优势

如果你已经习惯使用微软 Windows 或 Mac OS，那么学习使用 Linux 的意义何在，特别是因为它可能与你使用的操作系统不同，因此学习起来很困惑？

学习使用 Linux有很多理由，其中一些人们可能根本没有考虑。尽管面临无数病毒、恶意软件、间谍软件、运行缓慢、系统崩溃、维修甚至与许可证相关的费用，人们对自己的操作系统感到非常自满。这些问题不仅让人非常沮丧，而且昂贵。除了维修和保护的成本外，你可能还会丢失价值的数据。这些问题通常通过年度清理或定期格式化硬盘来管理，以确保系统刷新。

为什么人们花这么多精力去管理问题而不是修复它们？如果你认为没有替代方案，你通常会觉得必须接受现状。Linux 就是替代方案。一旦你理解 Linux 可以为你面临的许多问题提供解决方案，它将为你打开一个免受主流操作系统困扰的新世界。

Linux 的独特之处在于，它是免费提供给用户安装在计算机上的，而其他操作系统可能花费数百美元的许可证费用。安装这些操作系统，特别是在企业这样在多台计算机上安装，可能会非常昂贵。让我们看看设置 Windows 服务器的成本：2012 年，Windows 服务器的价格大约为 1200 美元。这个价格不包括 CAL（客户端访问许可证）以及在服务器上使用的任何其他软件。在经济优势方面，Linux 是明显的选择，因为它是完全免费的，包括运行系统所需的所有内容。它还可以根据需要安装在许多计算机上，而不会产生累积费用。

Linux 为什么可能是免费安装的？这听起来好得令人难以置信。

Linux 以开源许可协议发布。这意味着了几点点：首先，用户可以按照他们想要的方式和决定的目的运行程序。他们可以研究程序的工作原理，并根据自己的精确需求对程序进行定制。定制上没有任何限制，因为它是开放的，任何人都可以将未修改或已修改的软件副本分发给朋友、家人和邻居，从而鼓励该操作系统的共享和采用。

Linux 是一个社区驱动的平台。软件的开源特性鼓励用户更改和修改程序，以不断改进平台并为用户提供更多优势。Linux 代表了自由与灵活，是一个“为民服务、由民所有”的平台。

与主流操作系统相比，除了 Linux 具有显而易见的经济优势外，如果系统受到恶意软件、病毒或其他任何减速的影响，Linux 很少需要任何故障排除或干预。事实上，Linux 基本上可以多年不需要重启一次，而且仅在内核需要更新时才需要。系统管理员可以使用 Linux 花费更少的时间来管理服务器，因为它让他们基本上可以做到“设置后置忽略”。当然，仍然需要重启、重新配置和升级等基本操作，但服务器的大部分元素保持静态。Linux 的稳定性和可靠性是无与伦比的，为用户节省了时间和金钱。

#### Linux 发行版

之前提到了不同用户根据其特定需求创建的各种 Linux 版本。这些修改过的 Linux 版本被称为发行版（distributions），而不同的 Linux 发行版显然适用于不同类型的用户。适合 Linux 平台的初学者的可能对于高级用户来说是不够的。一个在高级用户手中是强大工具的版本，对于仍在学习如何使用该平台的初学者来说，可能过于复杂。

市上有许多许多不同的发行版，因此你应该能够找到一个符合你需求的版本。然后，你只需要下载其免费版本，将其放入 DVD 或 USB 驱动器中，并安装到你需要的所有系统中，无论是家庭还是公司。在许多发行版中，有几个因用户喜爱而颖而出：

- Ubuntu Linux

- Linux Mint

- Arch Linux

- Deepin（深度）

- Fedora

- Debian

- openSUSE

这些发行版中的每一个因不同的原因在不同的用户群体中而受欢迎。如果你非常擅长计算机，你可以选择带有某些额外功能的发行版，例如 Debian 或 Fedora。对于更高级且并享受其技能水平带来的灵活性的用户，他们可能会选择像 Gentoo 这样的发行版。对于 Linux 新手来说（如果你正在读这本书，那么你很有可能是该平台的新手），你可能想选择一个较简单的发行版来尝试，例如 Linux Mint、Ubuntu 或 Deepin。正如你所见的，有许多适用于所有技能水平的各种发行版，而 Linux 的优势之一是，即使当你决定了一个发行版……

对于像 Windows 这样的操作系统，在安装过程中需要完成一些工作，以确保一切运行顺利。

在这种情况下，第一步是对你的驱动器进行分区。这将告诉你的计算机你希望将 Linux 安装在何处。这是一个简单的任务，不需要你费费精力。你只需要在硬盘上选择一个空间，并将你拥的一些空闲空间分配给操作系统的安装和运行。

如果你正在安装 Ubuntu，程序通常会通过选择自己的空间为你完成操作。从那里开始，剩下的安装过程就简单了。

对于其他发行版，你将被要求自己划分空间，而某些分区工具可能会非常复杂。在这种情况下，你需要创建两个新分区。一个是为操作系统本身留空间，建议至少分配 10 GB。你应该将分区命名为“Ext4”，并将挂载点设置为“/”。然后创建第二个名为“swap”（交换分区）的分区。这里是用于存放内存的地方，以便运行操作系统并保持快速处理速度。如果你的可用内存（RAM）较少，请将交换分区的大小设为可用内存的两倍。如果你有足够的内存（超过 3GB），则将交换分区的大小设与可用 RAM 相同。

#### GRUB 及其他引导程序

在 Linux 完成安装过程之前，它会在你的系统上安装一个名为 GRUB 的新引导程序。这将替换你的标准引导程序，并在启动时为你提供使用 Windows 或 Linux 打开桌面的选项。在安装过程的这一部分，你不需要进行任何操作；只需坐好让你的发行版完成 GRUB 的安装即可。

对于使用 Mac 的用户，该过程的某些工作会有所不同，你需要手动将 GRUB 安装到 Linux 分区。

Windows 用户：请注意，如果你决定在任何时候卸载并重新安装 Windows，在重新设置好操作系统后，你需要手动安装 GRUB。

如果你更喜欢具有增强用户界面的程序，可能想要安装另一个与 Linux 兼容的引导程序。一个例子是名为 Burg 的引导程序。不过，你不需要立即这样做，可以等到完成 Linux 的安装后再设置新的引导程序。

如果你遵循了这些步骤，就就绪了。你的 Linux 分区现在应该已经安装，你需要做的只是重启计算机进入 GRUB 菜单。从那里，你可以决定是启动 Linux 还是 Windows。显然，就本书的目的而言，我们希望启动 Linux 以获得首次体验。你会发现你的 Linux 发行版附带了几个预装应用程序。其中一些对你有用，而另一些则没用，但你可以查看每一个并确定哪些是你可以使用的。

在某些情况下，安装新的操作系统会导致硬件变得不稳定。这通常是因为硬件没有意识到你正在使用 Linux，可能会发生一些误解。对于 Wi-Fi 尤为如此。你可以采取一些步骤确保你的硬件与新安装的系统兼容。我们将在下一章讨论这一点。

## 第 3 章：调优你的硬件

虽然这并非每次都会发生，但在某些安装 Ubuntu 或其他 Linux 发行版的情况下，你会发现并不是所有程序都运行良好。在本章中，我们将以 Ubuntu 为示例，介绍确保你的硬件与新安装的操作系统协同工作的步骤。

### Wi-Fi

在你可能遇到的硬件问题中，最关键的可能是你的 Wi-Fi 可能会出现故障。Wi-Fi 问题的问题在于你必须找另一个设备来在线搜索解决方案，但幸运的是，阅读本章可以确保在发生问题时，你已经知道如何让 Wi-Fi 恢复运行。

你可以在 Ubuntu 社区文档部分检查你的 Wi-Fi 卡和发行版的兼容性，在那里你可以找到人们讨论他们的网卡以及在安装 Ubuntu 时遇到的任何问题。你也可以搜索你的问题的答案，并在互联网的其他地方找到结果。

如果你无法解决问题，可以使用一些工具使你的网卡 Windows 驱动程序与 Linux 有效通信。为了做到这一点，你需要将该网卡的 Windows 驱动程序安装到系统中，然后安装 Ubuntu 自带的 `ndisgtk` 包。如果你无法访问互联网，可以使用以太线，或者将包下载到 USB 盘并连接到系统。然后从系统中安装该包并进入管理菜单。你可以使用“安装新驱动程序”按钮将 INF 文件加载到 Windows 包中。

### 专有驱动程序

对于那些没有开源驱动的用户，Linux 可能无法使用这些驱动，因为它们不允许用户将其用于自己的目的或将其打包进发行版。在这种情况下，你需要手动安装新驱动程序。

一些主流硬件驱动有开源驱动程序可用，例如 Nouveau，它是一个开源 Nvidia 驱动程序，并与许多 Linux 发行版一起打包。这些驱动提供了大量的支持，尽管它们永远不会像专有驱动那样流畅，这意味着你需要搜索适用于你发行版的版本。

此过程对于每个发行版都不同，但在 Ubuntu 的情况下，你有一个简单直观的驱动程序管理器，可以在“系统 > 管理 > 硬件驱动”下找到。这将提供你系统所有可用驱动程序的详细信息，允许你只需点击按钮即可安装它们。并不是所有的发行版都这么简单；某些需要通过在线搜索或阅读特定发行版的文档来花费更多精力。

一旦你安装了新的操作系统，对于任何可能出现问题的硬件，你都将需要这个过程。这些问题不需要担心；这只是一个找到正确的软件来替换之前在系统中的 Windows 驱动程序的问题。

### DVD、MP3、视频格式及更多

在切换到 Linux 时，事情会变得有点棘手，因为遗憾的是，某些发行版（如 Ubuntu）在某些方面仍然缺失功能，例如内置的 MP3、DVD 访问、授权字体以及你在使用 Windows 电脑时可能没有想到的其他项目。其原因是，对于开源程序来说，许可问题可能会有点困惑，但有一个非常简单的方法可以解决。

为了安装正确的项目以使这些功能运行，你需要采取两个步骤：

- 如果你目前正在运行 Ubuntu，只需点击此链接，它将带你进入正确的页面开始安装：`www.apt:ubuntu-restricted-extras?section=universe?section=multiverse`。你也可以选择来自 Ninite 的安装程序，甚至通过应用程序菜单中找到 Ubuntu 软件中心。从那里，你只需要搜索“ubuntu restricted”，这将为你生成安装扩展包的链接。

- 完成后，你需要打开终端。可以通过进入应用程序菜单，点击“辅助工具”，然后点击“终端”来实现。从那里你只需要输入 `sudo /usr/share/doc/libdvdread4/install-css.sh`。

这应该为你运行 MP3、商业 DVD 以及你日常使用的大多数其他视频音频格式提供所需的文件。虽然 Linux 在寻找正确文件方面可能会带来挑战，但它也将支持 Java 和 Windows 特定的字体。

解决方案从不嫌复杂，你只需要在首次安装新操作系统时操作一次即可。

### 鼠标和键盘

对于那些拥有带有额外按钮或功能的更高级鼠标或键盘的用户（例如为游戏定制的设备），你可能会发现在安装 Linux 之后丢失了其中某些功能。这可以通过让 Linux 知道所有额外按钮的用途来轻松解决。有几种方法可以重新映射鼠标上的额外按钮，每种方法都需要一些手动操作。

让 Linux 充分发挥鼠标潜能的最简单方法是使用 `xbindkeys` 命令。

如果你不熟悉使用命令，不用太担心，因为它实际上非常简单。例如，我们将取鼠标的一个侧指按键，并将其重新映射到 `Ctrl+T`，你可能知道这是在 Firefox 中打开新标签页的标准键盘命令。

我们首先需要考虑鼠标上每个按钮的名称，以确保我们向正确的按钮发送了正确的命令。仅凭肉眼很难做到这一点，因此我们需要运行另一个命令来识别可用的按钮：`xev`。

你会看到一个包含一个方框的小型白色窗口。将光标放在白色窗口内（避开方框），然后按下你想要发送命令的按钮。例如，按下侧指按键，我们会得到一些指示按钮名称的编码：

```
ButtonPress event, serial 33, synthetic NO, window ox4e00001, root ox142, subw ox0, time 568329, (93,19), root:(96,714), state ox0, button 10, same_screen YES
```

正如底部最后一行所示，我们刚刚点击的按钮被称为 button 10。我们现在需要的是使用 `Ctrl+C` 关闭 `xev` 并继续重新映射按键。然后通过运行以下命令安装两个新程序：`xbindkeys` 和 `xautation`。

```
sudo apt-get install xbindkeys xautation
```

然后通过运行以下命令为 `xbindkeys` 创建配置文件：

```
xbindkeys-defaults /home/your-user-name/.xbindkeysrc
```

你需要将 "your-user-name" 替换为实际用户名。这将为你提供一个文件，你可以打开文件浏览器并确保显示了隐藏文件来编辑它。完成后，你可以在列表顶部看到 `.xbindkeysrc`。双击它，你就可以在文件的末尾输入下一行命令。

#### 侧指按键 = Ctrl+T

```
"xte 'keydown Control_L' 'key T' 'keyup Control_L'
B:10
```

这模拟了按键动作；你需要确保在释放控制键之前同时按下了控制键和 T。末尾的 `B:10` 表示此命令绑定到我们鼠标上的第 10 号按钮。如你所见，这非常简单，几乎任何人都可以完成。该过程可以复制到任何需要更改的按钮上。

# Linux 的优势

Linux 的优势存在于内核之中。正如本书前面提到的，内核是一段在整个 Linux 系统中保持一致的代码。通过理解 Linux 内核，你可以修改操作系统以包含你想要的功能的支持。过去，许多人曾根据自己的需求专门修改内核，而这些功能已成为许多 Linux 发行版中不可或缺的一部分。

## 多用户

虽然你可以在 Windows 中拥有多个用户，但你缺乏让这些多个用户同时登录的能力。这意味着同时在系统中工作的人数受到限制。在 Linux 中，多个用户可以同时在系统上工作，每个用户都可以根据自己的需要定制自己的工作环境。

每个用户都有一个自己的唯一目录，用于存储文件，以及带有图标、菜单和应用程序的桌面。当然，你可以对这些账户进行密码保护，以保护你的应用程序和数据，并控制谁能够访问它们，即使在同一系统上。

## 多任务处理

Linux 的优势是可以同时运行许多程序。这意味着用户能够让程序在后台运行，同时同时运行多个程序。这还允许你的系统运行进程，使得 Linux 能够托管服务器；这些系统进程在后台运行，并在登录系统、搜索网页、复制文件或打印文档等请求时与网络通信。这些进程被称为守护进程（daemons）。

## 图形用户界面（X 窗口系统）

在处理任何涉及图形的内容时，Linux 为用户提供了一个强大的框架。这个框架被称为 X Window System，简称为“X”。X Window 系统管理任何基于 X 的图形界面应用程序的功能，并允许它们显示在通过服务器管理计算机设备（如屏幕、鼠标和键盘）的进程上。

你还拥有基于 X 的桌面环境的优势，这让你拥有 GUI 桌面和窗口管理器完整模拟，包含所有的图标、窗口框、菜单和颜色；即我们所说的所有主题（themes）。

在桌面环境和管理器方面，你有许多选择，每种都有自己的侧重点。

## 硬件支持

对于连接到计算机的硬件有许多支持选项。这涉及到从软驱器（如果你还有的话）、CD、DVD、USB、声卡、外部磁带设备以及基本上任何与计算机系统兼容的设备。

正如我们在早的章节中探索的那样，由于操作系统的开源性质，从常见的硬件制造商那里找到正确的驱动可能是困难的。但是，Linux 社区会在短时间内编写与你的发行版兼容的驱动程序。

## 应用支持

由于 Linux 兼容 POSIX 以及许多其他应用程序接口（或 API），Linux 提供了极其丰富的免费软件和共享软件。虽然可能需要一些精简和调整，但你将能够运行自由软件基金提供的绝多数 GNU 软件。

在早之前对 Linux 的介绍中，我们讨论了 Linux 是一个开源程序，有一个用户社区采纳并调整操作系统以满足他们的需求。由于这个原因，Linux 的功能在范围内几乎是无限的。如果你需要 Linux 执行特定功能，你可以修改软件并创建你自己的发行版。虽然并不是人都拥有这种技能，但这是可能的，而且你正在寻找的功能很可能是可以下载的。

## 无间谍软件

间谍软件已成为许多 Windows 用户的一个巨大问题。一旦下载了包含间谍软件的程序，它就会开始运行。用户可能完全没有意识到后台有应用程序运行，收集用户信息并将其发送给第三方，这些第三方使用这些数据可能窃取他们的身份或将信息卖给营销公司。这些应用程序还可以更改计算机解释信息的方式。正如前面提到的，许多为 PC 创建的病毒是 Windows 特有的，因此 Linux 免受了许多破坏性最强的病毒。更好的是，不需要花钱购买和升级防病毒软件，或支付昂贵的系统恢复费用。

## 无需碎片

Linux 拥有一种非常先进且高效的文件系统，不需要对数据进行碎片整理。对于普通的 Windows 计算机，这些文件系统可能会碎片化，从而导致系统崩溃、变慢和内存丢失。

## 不崩溃

如果你有一台 Windows 电脑，你对从不给出原因的随机崩溃并不陌生。例如，如果你正在运行 Windows 且浏览器崩溃了，整个操作系统可能会跟着崩溃，因为系统连接到了图形用户界面。这在几乎每个 Windows 用户身上发生过，在丢失数据或中断重要任务时，这是非常令人沮丧的。在 Linux 中你不会遇到这些崩溃，因为核心操作系统（内核）与 X 窗口中的图形用户界面以及你使用的 OpenOffice.org 等应用程序分开。如果应用程序由于任何原因（例如文件损坏）而崩溃，核心操作系统仍保持运行。

## 无需频繁重装

你会发现解决 Windows 问题的理想解决方案之一是重新安装整个操作系统并从头开始。当 Windows 崩溃且没有方法恢复已丢失的数据时，这将非常困难。如果你使用该系统运行业务，这可能会非常昂贵并对你的业务运营造成损害。另一方面，Linux 不会这种方式崩溃，这意味着当你面临任何问题时，你的数据是安全的且可以恢复的，而这些问题在 Linux 中是极少见的。你实际上可以将数据分开存储。

操作系统使得即使你选择重新安装操作系统，也能存储个人用户偏好。这可以通过创建一个新的分区来实现，该将保留你的主目录。同样，在 Windows 中，如果进行了任何更改（例如安装新硬件或软件），你会被不断要求重启系统以重新配置系统。而在 Linux 中，则不需要这样做。

## 许多文件系统

Windows 自带了两个文件系统。而 Linux 则带来了数百个文件系统，这对于那些需要在多台计算机之间工作、在不同系统之间交换硬件的用户来说非常有用。

## 强大的命令行

我们已经探索了使用命令行（或 shell 环境）的一些基础知识。在 Windows 中，命令行并不能走得多远，特别是对于基础用户而言。另一方面，正如我们之前提到的，Linux 拥有极其强大的命令行。通过 Linux 命令行，你可以为 Linux 编写整个程序，这意味着你可以通过自动化消除重复性任务。一个例子就是备份系统。这通常是一项极其艰巨的任务；想象一下如果你只需点击运行一个简单的程序，它就能完成整个过程。这以及许多其他简化操作通过 Linux 命令行都是可以实现的。

## 厂商独立性

在 Windows 中，如果你想保持系统更新，就会被锁定在单一厂商上。对于许多不想不断花钱来保持系统安全的人来说，这是一种负担。在 Linux 中，你永远不会被锁定在单一厂商上，因为社区提供了大量的厂商，每个厂商都有自己的发行版并提供支持。如果你觉得某个特定厂商在支持方面让你失望了，或者你遇到了不符合你预期的发行版，你可以转向社区寻求进一步的支持，或者完全采用一个新的厂商。你不需要从头开始，也不必感到受困于一个似乎没有考虑你最佳利益的厂商。更如此，如果某个厂商恰好放弃了他们的发行版，你并不被强制选择新的厂商或发行版，而是可以转向不断增长的社区继续发布你的发行版。请记住，在 Linux 方面不涉及许可协议，这意味着你可以根据自己的意愿自由下载、修改和重新封装。

## 无注册表

如果你用过 Windows 注册表（registry），你就会它可能是一场噩梦。你不仅需要特定的工具来打开和修改文件，如果任何数据损坏，管理起来将极其令人沮丧。在 Linux 中，大多数配置都存储在纯文本文件中。这允许你轻松地管理、备份并在系统之间传输这些文件。这比使用注册表要简单得多。

## 高水平的文档

你是否遇到过一个无法找到解决方案的问题？你翻阅手册却一无所获，你在论坛和搜索引擎中搜索答案，但根本没有记录显示其他人遇到过相同的问题。对于 Linux 的相关问题来说，这种情况几乎不会发生。Linux 是文档最全的操作系统之一，而且几乎所有的文档都是免费的。

这些文档并不是任何人随意拼凑的 PDF，而是编写良好的文档，详细描述了许多有助于解释 Linux 内部原理的概念。这也许是 Linux 社区最大的优势之一，该社区由位于几乎每个国家、城市和城镇的在线论坛、文章和群组组成。这意味着，如果你想让亲自帮助你处理系统运行机制，你离另一个 Linux 用户永远不会远。

你会发现，这个社区几乎就像一个家庭一样，因为在改进和开发开源操作系统方面，每个人都有共同的目标和任务。当你参与到这个社区并为其他成员提供价值时，就能开启最好的 Linux 体验，他们一定会会报答你的。

## 软件包管理

Linux 提供的优秀软件包管理允许用户访问可以简化安装和升级应用程序过程的工具。此外，如果你要升级当前的 Linux 发行版，这真的非常简单。此外，如果你是一个开发者，你就可以访问随软件包提供的大量开发工具、库和编译器。对于 Java 开发者或使用 PHP/Perl/Ruby 或 C 和 C++ 编码的 Web 开发者，你可以在 Linux 上大显身手。这让开发者能够随心所欲地使用 Linux，甚至可以向社区、朋友和家人提供并分享他们自己的 Linux 版本。

## 无开放端口

Windows 的一个主要问题是未使用的端口一直处于开放状态。这可能导致黑客的攻击，他们可以禁用并控制你的计算机，以对你的系统造成伤害或将你的计算机作为一种“攻击僵尸”进行进一步攻击。Linux 不留任何开放端口，这意味着你的数据非常安全，并免受未经授权的入侵。

## 更快的发布周期

为 Linux 发行版创建的补丁在几小时内完成，而不是其他操作系统的几天或几周。这意味着如果系统存在已知问题或安全威胁，提供保护的补丁生成会比专有软件快得多。此外，许多 Linux 发行版设置为每 6 个月发布一次，这使得能够获取最新的应用程序更新、补丁和错误修复，以及对集成到系统中的新硬件的支持变得很容易。相比之下，Windows 的发布周期是不一致的。有时需要几年才能有一个可靠的发行，而某些发行又糟糕又充满 Bug，真的不值得升级。

## 完全控制

使用 Windows 有时会感觉就像你坐在一列失控的火车上。你有许多自己几乎不了解的应用程序和进程在运行。有时你甚至不知道一个程序是什么，或者它正在对你的计算机做什么。这不仅会令人困惑，还会占用本应分配给想要和需要的程序的宝贵内存。在 Linux 中，你对哪些应用程序正在运行和更新以及它们何时运行有更大的控制权。在程序打开之前你需要给予权限，因此你总是确切计算机上发生了什么。

你对运行在系统上的 GUI（图形用户界面）也有完全控制权。如果你想更改在 Windows 中使用的 GUI 类型，将无法做到，因为你只有一个默认的 GUI。Linux 提供了各种 GUI，讽刺的是，它们被称为窗口管理器（Window Managers）。你可以选择你认为最适合你使用系统方式的 GUI。有几十种选择，从精美的视觉型 GUI 到快速、精简的选项都有。还有非常适合初者的选项，其中一些如 Gnome 和 KDE 在之前的章节中已经提到过。

## 捆绑

Windows 通常避免与操作系统捆绑应用程序，除了简单的文本编辑器、一个图像编辑应用程序以及其他几个之外。许多值得使用的应用程序需要外部下载和安装，并且通常带有高昂的价格。Linux 在发行版中捆绑了许多不同的应用程序。这些从像 Office 套件和照片编辑软件等知名程序，到一些对你来说可能是全新的开源应用程序不等。优势是，这些应用程序将随你的发行版免费提供。它们在不产生任何额外费用的情况下提升了你的计算机体验。这些开源程序中的一些可以在 Windows 系统上进行下载和使用，但这需要下载和安装时间，而在 Linux 中，它们默认情况下就已经就绪了。这些捆绑包可能是庞大的，包含成千上万个应用程序，有些甚至声称拥有超过 20,000 个。

对于你需要在下载到系统中的应用程序，你可以通过内置的应用程序商店来完成。对于 Ubuntu 来说，内置的应用商店有数千个应用程序，只需点击一下即可轻松下载。

## 浏览优势

大多数 Linux 发行版都预装了 Mozilla Firefox，大多数人对它都很熟悉。Firefox 是一款功能强大的浏览器，具有许多内置功能，例如广告拦截、弹出窗口限制，以及相比 Windows 自带标准浏览器的许多其他优势。由于 Linux 改进了网络能力，能够节省带宽并确保互联网连接稳定，这使得浏览变得更加简单和快速。

## 无自动更新

自动更新经常被吹称为 Windows 的一个优点，但这个过程不仅令人厌恼，还可能对你使用系统产生危害。大多数人可能不知道到底哪些文件被更新了。在 Linux 中，你可以选择点击并应用更新，而不是让它在未经你许可的情况下自动发生。如果你愿意，欢迎设置你自己的自动更新，但你不必盲目接受它们。在 Linux 中，你对计算机何时、如何以及更新什么拥有完全的控制权。

## 3D 桌面

Linux 允许用户通过 Compiz 利用先进的 3D 桌面，允许你同时切换和查看多个桌面。这一功能在创建时被认为是非常先进的，领先 Windows 许多倍。即使是现在，Compiz 也是最精简的 3D 桌面之一，且占用的显卡内存极少。

# 第 5 章：使用 Linux 命令行

我们已经涵盖了什么是命令行以及一些基础知识，但现在是时候进一步深入一下，看看究竟能实现什么。在本章中，我们将探索命令行界面（CLI）的一些功能以及它与图形用户界面（GUI）相比的优势。虽然 GUI 对于初学者和刚安装 Linux 体验新操作系统的用户来说非常棒，但真正的力量隐藏在命令行之中。这才是我们真正能够让 Linux 为我们服务的地方。

命令行允许你跳出特定发行版的限制进行工作。依赖于特定的发行版意味着你将习惯于以某种方式执行任务，如果你之后由于某些原因需要更换发行版，你将不得不重新学习即使是最基础的任务，因为不同的发行版之间执行任务有许多不同的方法。取决于你切换的是哪些发行版，这可能是一项相当复杂的任务，而使用命令行允许你跳过这种调整，无论你使用哪种发行版都能保持控制力。

通过理解基于 Debian 的系统，你可以使用 `apt-get` 或 `dpkg` 等基本命令来管理软件，无论你使用哪种发行版。这还让你避免了这种痛苦：发现你正在使用的发行版缺少某些你已经习惯的功能，或者发现这些功能被隐藏在更新后的 GUI 中。

使用命令行的优势不仅在于拥有对可用功能的控制权。使用 GUI 会导致许多系统资源被消耗，减慢系统速度，并导致任务花费的时间比使用命令行要长得多。

命令行起初可能令人畏惧，但一旦你理解了这种语言，它就像给你的 PC 发送一些关于你需要做什么的指令一样简单。想象一下第一次给一个青少年发短信，却不听懂他们的俚语。类似地，不了解命令行语言会让你感到非常隔阂和困惑。但一旦你掌握了它，你就可以轻松地交流，并希望避免让自己尴尬。

## 获取 Shell（外壳）

在你开始向电脑输入命令之前，你需要运行 Shell。Shell 是一个根据你输入的文本为计算机创建指令的程序。有一组特定的命令结构，它们对于你的操作系统是唯一的，因为不同的操作系统在执行类似任务时会使用不同的结构。

出于这个原因，Linux 有许多不同的 Shell 可用，但最常用且流行的（推荐使用，因为它拥有最大的社区支持）是 BASH（Bourne-Again shell）。BASH 是由 GNU 项目编写的，是初学者的首选。如果你更喜欢更现代且带有一些额外功能的选项，也可以选择 `zsh`，它可以从你的发行版中轻松安装。

如果你在桌面环境中工作，那么最好使用终端模拟器来模拟该特定界面的终端。你会发现不同的发行版会带有自己特定的终端模拟器。例如，KDE 带有 Konsole，而 Gnome 使用 Gnome Terminal。

## 你的第一个命令

当打开终端模拟器时，你会发现默认情况下你处于登录用户的家目录中。可以通过主机名之前的登录用户名看出这一点。看到 `$` 符号表示你正以普通用户身份登录，而看到 `#` 符号则表示你正以 root（超级用户）身份登录。

最好避免以 root 身份在命令行中工作，因为这可能会更改你处理过的所有文件的权限及其所属目录，并使 root 用户成为这些目录和文件的所有者。然而，如果你正在执行管理任务，或者在 root 目录内工作，那么以 root 用户身份登录是没有问题的。

如果你想查看当前工作目录中的所有目录和文件，可以通过 `ls` 命令列出所有内容，其命令行如下：

```
[swapnil@swaparch ~]$ ls
Desktop Documents Downloads Music Pictures Public Templates Videos
```

## 更改位置

你可以通过使用 `cd` 命令切换到任何目录来穿过系统。如果你想使用快捷键，也可以使用 Tab 键自动补全路径。要进入目录，你只需使用正斜杠 `/`。例如，如果你想进入家文件夹下的 downloads 目录，你使用 `cd` 命令更改目录，后跟上你想要访问的路径。你需要将用户名作为命令的一部分。在这个示例中，我们将使用 "swapnil"：

```
Documents/ Downloads/
[swapnil@swaparch ~/] cd /home/swapnil/Downloads/
[swapnil@swaparch Downloads]$
```

你会注意到在第三行中，我们的目录 "Downloads" 位于方括号内。这表示移动已成功，我们现在位于该目录内部。如果你愿意，可以再次使用 `ls` 命令查看 `Downloads` 内部的子目录和文件。

记住，当你从当前目录移动到子目录时，不需要提供完整路径。例如，如果你想前往位于 downloads 目录内的名为 "Test" 的子目录，你只需要输入 `cd` 然后是目录名（即 "Test"），而不需要正斜杠。

```
[swapnil@swaparch Downloads]$ cd Test
```

从一个目录切换到另一个目录时，你只需要按照相同的程序使用 `cd` 来反向操作返回刚才进入的目录，你需要使用 `cd ..`；如果你需要返回更远，比如两个目录，则使用 `cd ../..`。回溯的目录越多，命令就越长。

如果你想查看目录内部的内容，不需要切换目录。你可以使用 `ls` 命令，但方法稍有不同：

```
ls /目录的路径
```

回到之前的示例，如果我们想查看 Test 文件夹而不必进入那里，只需输入：

```
[swapnil@swaparch ~]$ ls /home/swapnil/Downloads/Test/
```

在目录被隐藏的情况下，你仍然可以通过 `ls` 命令中的一个特殊选项来看到它。在 `ls` 之后，你只需要输入 `-a`，如下例：

```
[swapnil@swaparch ~]$ ls -a /home/swapnil/Downloads/Test/
```

## 确定大小

如果你需要查看当前工作目录的大小怎么办？这通过命令行可以实现吗？可以！而且非常简单。你只需要在使用 `ls` 命令时配合 `-l` 选项即可。这还会提供其他信息的详情，例如文件和目录的权限、所有者以及最后修改的时间和日期。



```bash
[swapnil@swaparch ~]$ ls -l /home/swapnil/Downloads/Test/
total 4
drwxr-xr-x 2 swapnil users 4096 Mar 26 11:55 Test_2
```

如你所见，该命令提供的文件大小格式可能有点难以理解。我们有一种方法可以更改这种格式，使其呈现方式对于可能不熟悉编程的人来说更易于理解和具可读性。我们只需要像下面这样使用`ls -lh`命令即可：

```bash
[swapnil@swaparch ~]$ ls -lh /home/swapnil/Downloads/Test/
total 4.0K
drwxr-xr-x 2 swapnil users 4.0K Mar 26 11:55 Test_2
```

如果你想列出特定位置内所有目录和文件的详细拆解，你可以获得一个不包含任何额外信息的简单列表。这可以使用`ls -R`命令完成。你会发现，该命令生成的输出可能会非常长，因为它列出了该目录下的所有文件以及它们的位置。

## 创建新目录

现在为了执行此操作，你需要熟悉命令行。命令是`mkdir`。在输入此命令后，你会发现新目录默认会在当前目录下创建。如果你想在另一个位置创建此目录，可以通过提供你希望创建新目录的所在位置的完整路径来实现：

```bash
mkdir /path-of-the-parent-directory/name-of-the-new-directory
```

例如，如果我们想在下载目录中创建一个名为`distros`的新目录，用来存放下载 Linux 发行版时创建的所有文件，那么我们只需要运行以下命令即可：

```bash
$swapnil@swaparch ~/ mkdir /home/swapnil/Downloads/distros
```

现在，如果我们想在这个新创建的目录内部进一步创建一个子目录，我们需要需要配合`mkdir`命令使用`-p`选项。如果你想创建一个名为`distros`的新目录，同时在其中添加一个名为`opensense`的目录，你需要告诉系统：虽然这个目录不存在，但你希望现在创建它，以便将这个新目录存储在其中。让我们来看一个例子：

```bash
mkdir -p /home/swapnil/Downloads/distros/opensense
```

此操作将通过单个命令创建一个名为`distros`的新目录，并在其中创建另一个名为`opensense`的目录。你能用华丽的 GUI 实现这一点吗？不太可能。

## 删除目录

删除目录与创建目录一样简单直接。如果你想删除文件，需要使用`rm`命令；如果你想删除目录，则需要使用`rm -r`命令。记住这两者的区别，并注意你使用的是哪个命令，因为当你打算删除文件却实际上删除了整个目录时，后果可能是灾难性的。

```bash
rm /path-of-the-directory-or-file
```

在我们的示例中，我们将删除刚刚创建的`opensuse`目录。为了做到这一点，我们将使用命令行：

```bash
rm -r /home/swapnil/Downloads/distros/opensuse/
```

如果我们决定删除目录内的所有内容但保留目录本身，我们会在斜杠后使用星号（`*`）。例如，如果我们想删除`opensuse`目录中的所有内容，我们将使用命令行：

```bash
rm /home/swapnil/Downloads/distros/opensuse/*
```

如果内部还有子目录，你需要再次使用`-r`选项来告诉系统你认为清理范围包含了这些子目录。这看起来将会是：

```bash
rm -r /home/swapnil/Downloads/distros/opensuse/*
```

## 系统信息

除了与系统上的文件和目录交互外，你还可以使用命令行获取系统本身的信息。例如，如果你想根据分区评估文件系统上的磁盘空间大小，可以使用`df`命令；或者如果你想以更易理解的方式读取，可以使用`df -h`命令，它将以兆字节和 GB 为单位显示报告。如果你想查看空空间与已用内存的比较情况，请配合`-m`使用`free`命令，它将以兆字节报告数字。

如果你对系统的详情感兴趣，例如正在运行的进程和可用资源（这在初开始使用命令行时有用），你可以使用`top`命令。它将为你提供一份关于运行进程、CPU 和 RAM 使用情况以及正在运行任务总数的报告，你可能想将其与同类型的 GUI 报告进行比较。

## 总结

如你所见，使用命令行既简单又强大。与其仅仅依赖会占用宝贵处理资源的 GUI，命令行允许你以精确和快速的速度执行功能。起初看起来可能有点畏人，但一旦你习惯了，就会发现它是与你的计算机以及 Linux 操作系统交互的一种灵活得的方式。一旦你熟悉了命令行更基础的功能，就可以继续学习高级命令了。

# 第 6 章：高级命令

我们在上一章中探索了一些基础的命令，例如如何遍历目录和修改文件。在本章中，我们将为已经习惯 shell 和基础命令的用户考虑一些更高级的命令。请记住，虽然它们是更高级的命令，但它们对于命令行脚本编写的可能性可能仅仅是冰毛一角。现在，让我们为学习 Linux 命令的人看看下一个层级。

## FIND

`find`命令允许你在目录内搜索特定文件。这与你在文件管理器中执行的操作类似，但这个`find`命令在跟踪文件方面更加灵活、更强大。`find`命令将遍历父目录以及子目录，记录所有匹配你提供的选项的文件。以下是该操作显示方式的示例：

```bash
root@user:~# find -name *.sh
./Desktop/load.sh
./Desktop/test.sh
./Desktop/shutdown.sh
./Binary/firefox/run-mozilla.sh
./Downloads/kdewebdev-3.5.8/quanta/scripts/externalpreview.sh
./Downloads/kdewebdev-3.5.8/admin/doxygen.sh
./Downloads/kdewebdev-3.5.8/admin/cvs.sh
./Downloads/kdewebdev-3.5.8/admin/ltmain.sh
./Downloads/wheezy-nv-install.sh
```

你会注意到我们使用了`-name`选项。这使得该选项对大小写敏感，这意味着结果只会产生与搜索词大小写相似的结果；在这种情况下，是`-sh`。`*`是一个通配符，它将搜索所有扩展名为`.sh`的文件。如果你想获得更具体的结果，可以使用文件名对其进行修改。

## 命令：GREP

`grep`命令用于在特定文件中搜索术语以查找匹配项。这与你在浏览器中搜索术语的方式类似，但在命令行中你甚至不需要打开文件。

例如，如果你在查找文件（在此例中为`/etc/passwd`）中的术语“user”，它看起来像这样：

```bash
root@user:~# grep user /etc/passwd
user:x:1000:1000:user:/home/user/bin/bash
```

你可以通过使用`-i`选项忽略任何特定的单词大小写和其他组合，在这种情况下，命令行看起来如下：

```bash
root@user:~# grep -i USER /etc/passwd
user:x:1000:1000:user:/home/user/bin/bash
```

我们还可以通过`-r`搜索整个目录。例如，如果我们想找到字符串`127.0.0.1`：

```bash
root@user:~# grep -r "127.0.0.1" /etc/
```

```text
/etc/vlc/lua/http/.hosts:127.0.0.1
```

```text
/etc/speech-dispatcher/modules/ivona.conf:#IvonaServerHost 127.0.0.1
```

```text
/etc/mysql/my.cnf:bind-address = 127.0.0.1
```

```text
/etc/init/network-interface.conf: ifconfig lo 127.0.0.1 up || true
```

```text
/etc/java-6-openjdk/net.properties:# localhost & 127.0.0.1.
```

```text
/etc/java-6-openjdk/net.properties:#
httpnonProxyHosts=localhost|127.0.0.1
```

```text
/etc/java-6-openjdk/net.properties:# localhost & 127.0.0.1.
```

```text
/etc/java-6-openjdk/net.properties:#
ftpnonProxyHosts=localhost|127.0.0.1
```

```text
/etc/hosts:127.0.0.1 localhost
```

在使用`grep`命令时，你有几个可用选项，例如：

```text
-w 用于匹配单词（例如 egrep -w 'word1|word2' /path/to/file）
-c 用于计数（即模式匹配的次数次数）
(grep -c 'word' /path/to/file)
-color 用于彩色输出（grep -color server /etc/passwd）
```

### 命令：MAN

当你刚开始并想要查看特定命令的可用选项时，这个命令非常有用。`man`是系统的手册分页器，它基本上是从互联网上收集某个命令的所有可用文档，并通过为每个选项提供手册页来解释每个选项的作用。

### 命令：PS

“ps”代表 process（进程），它将为你提供系统上当前运行的所有进程状态，以及一个名为 PID 的唯一标识。它的显示方式如下：

```bash
root@user:~# ps
PID TTY             TIME CMD
4170 pts/1        00:00:00 bash
9628 pts/1        00:00:00 ps
```

如果你想查看正在运行的进程及其 ID 和 PID，请使用选项`-A`，它在你的命令行中的显示方式如下所示：

```bash
root@user:~# ps -A
PID TTY             TIME CMD
1 ?                 00:00:01 init
2 ?                 00:00:00 kthreadd
3 ?                 00:00:01 ksoftirqd/0
5 ?                 00:00:00 kworker/0:0
7 ?                 00:00:00 kworker/u:0
8 ?                 00:00:00 migration/0
9 ?                 00:00:00 rcu_bh
...
```

这帮助你理解哪些进程正在运行、它们运行了多久，以及是否由于某种原因需要停止。你可以将其与`grep`命令结合使用以获取自定义输出：

```bash
root@user:~# ps -A | grep -i ssh
1500 ?      00:09:58 sshd
4317 ?      00:00:00 sshd
```

### 命令：KILL

对于那些停止响应或与你当前任务无关的进程，你可以使用`kill`命令来停止它们。在结束那些占用大量 CPU 资源但实际上并没有帮助你完成任务的进程时，这变得非常有用。在 Windows 等操作系统上，这些进程通常很难杀死，有时可能需要你完全重启系统，但 Linux 则不会。

`kill`命令适用于任何进程（或`ps`）。例如，如果我们想要杀死已经停止响应的“apache2”程序，我们需要首先结合`grep`命令运行“ps -A”：

```bash
root@user:~# ps -A | grep -i apache2
1285 ?      00:00:00 apache2
```

然后你将看到 apache2 进程及其 PID，你将用该 PID 使用`kill`命令。在这个示例中，进程 ID 是 1285，对应我们的下一个命令：

```bash
root@user:~# kill 1285 (杀死进程 apache2)
```

如你所见，每当进程运行时，它都会生成一个新的 PID，你可以通过`ps`命令识别它。

### 命令：WHEREIS

当你想要查找特定命令的二进制文件、源代码或手册页时，可以使用`whereis`命令来显示它们。例如，如果我们想定位“ls”命令的二进制文件、源码和手册页并杀死它，看起来会这样：

```bash
root@user:~# whereis ls
ls: /bin/ls /usr/share/man/man1/ls.1.gz
root@user:~# kill
kill: /bin/kill /usr/share/man/man2/kill.2.gz
/usr/share/man/man1/kill.1.gz
```

### 命令：SERVICE

此命令允许通过启动、停止或重启特定服务来控制服务。这允许你在无需重启系统的情况下对服务进行更改。这样做的优势是，你不需要停止正在进行的工作就可以更改计算机运行的服务。

### 命令：ALIAS

此命令强烈推荐给刚开始接触 shell 的用户，它允许为你经常使用的命令分配一个名称，或者当命令太长而不方便每次手动输入。例如，你可能会频繁使用“ls -l”命令。原始命令有 4 个字符和一个空格，因此我们可以使用`alias`命令将其缩减为单个字符“l”。这将帮助你通过使用熟悉的简短命令来理解一些更复杂的命令。虽然这对于初学者很棒，但仍然建议在做出更改之前学习这些命令，以防将来忘记它们。以下是它的实际运行情况：

```bash
root@user:~# alias l='ls -l'
```

你可以在之后直接输入该命令来检查它是否有效：

```bash
root@user:~# l
total 36
drwxr-xr-x 3 user 4096 May 10 11:14 Binary
drwxr-xr-x 3 user 4096 May 21 11:21 Desktop
drwxr-xr-x 2 user 4096 May 21 15:23 Documents
drwxr-xr-x 8 user 4096 May 20 14:56 Downloads
drwxr-xr-x 2 user 4096 May 7 16:58 Music
drwxr-xr-x 2 user 4096 May 21 16:17 Pictures
drwxr-xr-x 2 user 4096 May 7 16:58 Public
drwxr-xr-x 2 user 4096 May 7 16:58 Templates
drwxr-xr-x 2 user 4096 May 7 16:58 Videos
```

你可以使用`unalias`命令来删除别名，看起来如下：

```bash
root@user:~# unalias l
```

然后你可以检查该命令是否仍然存在，理论上它应该不再存在。如果你操作正确，你会看到如下的消息：

```bash
root@user:~# |
```

```text
bash: l: command not found
```
