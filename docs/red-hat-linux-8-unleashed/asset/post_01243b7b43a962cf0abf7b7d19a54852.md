### The GTK Widget Set

In order to make it easier to program GUI applications, small pieces of code are prewritten to describe some graphical functions of the graphical interface; these functions include drop-down lists, radio buttons, Save dialogs, window buttons, and the like. Such functions are referred to as widgets, the collection of widgets is referred to as a tool or a widget set. Rather than write the code for all these functions from scratch, programmers need only reference the widgets. This writing GUI applications is easy. Whereas Windows and Mac programmers have only one set of widgets to work with, Unix and Linux programmers have many sets that are, unfortunately, incompatible with one another. The KDE desktop uses the Qt widget set, Netscape uses the Motif widget set, and GNOME applications use the GTK widget set.

GTK is an acronym for G Tool. The GIMP (the GNU Image Manipulation Program) is a graphics application that is very similar to Adobe Illustrator. By using the jargon GTK-based, we save ourselves hundreds of words of typing and help over our discussion of GNOME Office along. You may also see similar references to QT and Motif, as well as other widget sets, in these chapters.

Here are some of the primary components of the GNOME Office suite:

- AbiWord—This word-processing program enables you to compose, format, and organize text documents and has some compatibility with the Microsoft Word file format. It uses plug-ins (programs) that add functionality (such as language translation) to enhance its functionality.

- Evolution—Evolution is a mail client in the mold of Microsoft Outlook, providing email, scheduling, and calendaring. It is described in Chapter 19, “Handling Electronic Mail.
- Balsa—This lightweight mail client is in the mold of Microsoft Outlook Express. It is described in Chapter 19.

The loose association of applications that is known as GNOME Office includes several additional applications that duplicate the functionality of applications already provided by Red Hat. Those GNOME applications are not included with Red Hat 8.0, to eliminate redundancy. They are all available from the GNOME Office Web site, at http://www.gnome.org/gnome-office/.

Red Hat provides the AbiWord editor, shown in Figure 25.3. AbiWord can import XML, Microsoft Word, RTF, UTF-8, text files, and few other formats, but it can't yet save as Microsoft Word format. The AbiWord application icon is found in the Extras menu, under the Office menu (along with Gnumeric and the KOOffice applications we'll discuss later in this section). Simply click on the icon to launch the application. Or you can launch it from the command line, like:

$ Abiword &
```

If you are familiar with Microsoft Word, the AbiWord interface will be familiar to you because its designers used Word as their model.

# Working with KOffice

The KDE office suite, KOffice, was developed to provide tight integration with the KDE desktop. Integration enables objects in one application to be inserted in other applications via drag-and-drop, and all the applications can communicate with each other, so a change in an object is instantly communicated to other applications. If you use the KDE desktop you can enjoy the benefits of this integration, along with Konqueror Web and file browser.

The word processor for KOffice is KWord. KWord is a frames-based word processor, meaning that document pages can be formatted in framesets that hold text, graphics, and objects in enclosed areas. Framesets can be used to format text on a page that includes columnar text and images that the text needs to flow, making KWord an excellent choice for creating documents other than standard business letters, such as newsletters and brochures.

KWord and other components of KOffice are still under development and lack the polished feature of OpenOffice.org and AbiWord, as well as the necessary Microsoft file format support. If Microsoft compatibility is unimportant to you and you use the KDE desktop rather than GNOME, KOffice is worth considering.

You can access the KOffice components from the Office submenu under the Extras menu. You can also access them from the KOffice shell, which can be launched from the command line, like this:

```
$ koshell &
```

After you press Enter, you see the main window of KOffice, as shown in Figure 25.6.

You can click on icons on the left side of the main window to launch the KWord word processing client, the KSpread spreadsheet program, and other components. You can also launch individual clients from the command line, without using the KOffice workspace. For example, to use KWord, enter the following:

```
$ kword &
