Group-level quotas can also be enabled by using the grquota option. As the root operator, you may create a file (using our example of creating user quotas) named quota.user in the designated portion of the file system, like so:

```
# touch /quota.user
```

You should then turn on the use of quotas using the quotaon command:

```
# quotaon -av
```

You can edit user quotas with the edquota command to set hard and soft limits on filesystem use. The default system editor (vi unless you change your EDITOR environment variable) will be launched when editing a user's quota.

> NOTE\Any graphical tools supported by Red Hat can no longer be used to configure disk quotas. A Quota mini-HOWTO is maintained at http://www.tldp.org/HOWTO/mini/Quota.html.

# Related Red Hat and Linux Commands

—A user account-statistics command
chage—Sets or modifies password expiration policies
chfrn—Creates or modifies user finger information in /etc/passwd
chgrp—Modifies group memberships
chmod—Changes file permissions
chown—Changes file ownership
chpasswd—Batches user passwords
chsh—Modifies a user's shell
groups—Displays existing group memberships
logname—Displays a user's login name
newusers—Createsches user management command
passwd—Creates or modifies user passwords
redhat-config-users—Red Hat's graphical user management tool
su—Executes shell or command as another user
