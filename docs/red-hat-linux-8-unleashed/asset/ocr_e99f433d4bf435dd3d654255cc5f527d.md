The IP addresses listed in the /etc/resolv.conf are usually assigned by an ISP and represent the remote namesvers. Other optional keywords, such as domain and search, are used to specify a local domain and search list for queries; the few are mutually exclusive, however.

The information in /etc/resolv.conf can be configured from the redhat-config-network tool by launching the tool from the Network menu item in the System settings menu. The DNS tab allows you to enter or edit the DNS information, as shown in Figure 14.1.

# Understanding the /etc/hosts File

The redhat-config-network tool is also used to configure the /etc/hosts file—a file that contains a table of local hosts (hostnames and IP addresses) used for local DNS-type lookups. Using /etc/hosts to provide hostnames and hostname aliases can be effective when used on small networks. For example, a short /etc/hosts file might look like this:

...

```
192.168.2.30 odin.home.org odin
192.168.2.31 thor.home.org thor
192.168.2.32 balder.home.org balder
192.168.2.33 migard.home.org migard
```

...
