# CHAPTER 27 Using Emulators and Other Cross-Platform Tools in Red Hat Linux

Most people will want to read options from a file called .bochsrc, then immediately start the simulation. A quick way to do this is to press return three times to accept the default choices (shown in square brackets).

+   1. Read options from...
2. Edit options
3. Save options to...
4. Begin simulation
5. Quit now

Please choose one: [1]

The main menu allows you to specify a Bochs resource file (containing specifications and file locations for emulation). You can read a resource file (normally named .bochsrc), make and save changes, and then launch the emulator. FreeDOS directory contains everything you need, however, so all you have to do is press Enter, and you will see:

What is the configuration file name?
To cancel, type 'none'. [.bochsrc]

To launch Bochs and boot FreeDOS, press Enter to return to the main menu and then press Enter to choose the default option Start Simulation. You then see the Bochs window, as shown in Figure 27.1.
