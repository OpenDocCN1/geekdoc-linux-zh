# About the Apache Web Server

Apache is the most widely used Web server on the Internet today, according to a NetCraft survey of active Web sites in August 2002, which is shown in Table 16.1.

TABLE 16.1 NetCraft Survey Results (August 2002)

| Web Server | Number | Percentage* |
| --- | --- | --- |
| Apache | 11,001,650 | 66.64% |
| Microsoft IIS | 4,074,058 | 24.68% |
| iPlanet | 208,968 | 1.27% |
| Zeus | 184,143 | 1.12% |

*Of 35,991,815 surveyed

What's more revealing is the growth rate in the use of the Apache server versus the other server platforms in use by developers, according to NetCraft. Between July and August 2002, Apache gained 5.89% of the total market share, whereas IIS declined 6.48%.
