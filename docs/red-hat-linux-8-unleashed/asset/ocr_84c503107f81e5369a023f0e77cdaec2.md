 Hat’s graphical installation dialogs are convenient and easy to use. However, a text-based installation is outlined here as it should work with any PC, and it can be used as a starting point for learning more about installing Red Hat Linux.

# Starting the Install

To get started, insert the first Red Hat Linux CD-ROM and reboot your computer. You'll first see a boot screen that offers a variety of options for booting (see Figure 3.1). These options are

+   * <ENTER>Start the install using a graphical interface. The graphical interface supports a mouse and offers check boxes and fields for choosing software, configuring options, and entering information.
* linux text—Start the install using a graphical text interface. (This is the choice we will use here.)

To install Red Hat using a text-based interface (used for our example), type linux text and press Enter.
