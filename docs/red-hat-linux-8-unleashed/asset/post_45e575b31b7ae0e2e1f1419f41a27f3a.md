## Planning for Hard Drive Storage for Your Red Hat Linux Installation Class

Making room for Red Hat Linux requires you to decide on how to use existing hard drive space. You might decide to replace existing hard drives entirely, or you might decide to use only one system on your computer, making partitioning unnecessary. A full install of Red Hat from this book's CD-ROMs will require at least 5GB hard drive space for the software, so if you plan to install everything, a 10GB hard drive will be ideal for a workstation. That depending on how you plan to use Linux, a smaller capacity disk can be used, or a disk capacity many times the size of your system will be required.

The Red Linux installer offers a choice of installation types or classes, and each has its own hard drive storage requirements:

- Workstation—You’ll need a minimum of 2GB hard drive storage, but more if you choose to install everything. This installation is intended for developers and other users who want to use the entire spectrum of Linux software offered by the Red Hat distribution.
- Personal Desktop—This is a new installation class for SOHO (small office/home office) which installs a basic graphical desktop, along with office and Internet productivity software; you’ll need nearly 1.8GB of storage if you don’t customize the default software selections.
- Server—You need about 1.2 to 1.4GB of storage for the software, but you must take into consideration other storage requirements. For example, if you plan to run a Web site with a lot of graphics or other files, you might need to add storage to your system or accommodate remotely stored locally.
- Laptop—This class of installation, introduced with Red Hat Linux 7.1, is just for laptops and requires at least 1.5GB of hard drive.
- Custom—For a minimal installation, choose the 350MB custom, but you can also choose to install every package in the distribution as part of the custom installation; in which case, you’ll need 4.3GB or more of storage, along with several hundred megabytes of free space for temporary files.

The storage requirements for each of these classes can be revised somewhat, depending on the X desktop environment you choose (such as KDE or GNOME). Choosing the “expert” mode when installing Red Hat Linux will also let you choose specific software packages from the group package categories. Here are some software packages you might want to consider passing up in the installation process:

- Documentation
- X Windows System
- Graphics utilities
- Development software or libraries

## Checking Hardware Compatibility

Red Hat Linux software for Intel-based PCs is compiled for the minimum x86 platform supported by the Linux kernel, the x386 CPU family.

> The compatibility information in this chapter relates to Red Hat Linux. Other distributions, such as SuSE (which requires an x86) and Red Hat-based Mandrake Linux (which requires a Pentium-class CPU) might have different storage and CPU requirements.

Specific issues regarding hardware compatibility can be researched online through Red Hat, Inc’s hardware compatibility database at /hardware/.redhat.com/hcl1/genpage2.cgi?pagename=html&view=advsearch#form. You can select hardware class, manufacturer, version of Red Hat Linux, platform, and status of support. To narrow searches, you can also enter an optional keyword. This is a great resource to use before purchasing equipment to use Red Hat Linux or before installing potentially problematic hardware. ## Preparing for Potential Hardware Problems

Red Hat Linux will work "out-of-box" with nearly every motherboard and laptop. Red Hat Linux also includes drivers for thousands of different types of peripherals. But as you come into problems if Red Hat Linux doesn't recognize a hardware item, if Red Hat Linux doesn't initialize the hardware, or if an initialized item is incorrectly configured. For these reasons, some hardware items are prone to creating problems during Red Hat installation. In the sections that follow, you learn some important pointers for avoiding these problems or resolving those that occur.

## Controllerless Modems

As you read earlier, most Red Hat Linux hardware-related installation problems stem from a lack of technical specifications from the manufacturer or the lack of a driver. In the recent past, one hardware item that triggered both types of difficulties was the controllerless modem, also colloquially known as a WinMod. The good news is that modern chipset manufacturers have been more forthcoming with driver details. Some original equipment manufacturers, such as IBM, have made a concerted effort to provide Linux support. For the ACP Mwave modem, used in ThinkPad 600/Es and 770s, is included in the Linux kernel. Drivers have been developed for many of the controllerless modem chipsets that formally do not work with Linux.

If a driver isn't available for your controller modem, you have a few options. You can download the driver's source code and build the driver. Alternatively, you can download a binary-only software package and install the driver.

Some controllerless modems might also need to be initialized and configured using a rate utility program. The modem, if supported, should work normally after installing and configuring the driver.
