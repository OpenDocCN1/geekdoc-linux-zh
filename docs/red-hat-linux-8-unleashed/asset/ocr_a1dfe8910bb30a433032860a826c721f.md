Reference

useradd—Creates, modifies, or manages users
userinfo—Red Hat's graphical chfn command
usermod—Edits a user's login profile
userpasswd—Red Hat's graphical user password command

# # Reference

http://www.tldp.org/HOWTO/User-Authentication-HOWTO/index.html—The User-Authentication-HOWTO describes how user and group information is stored and used for authentication.

http://www.tldp.org/HOWTO/Shadow-Password-HOWTO.html—The Shadow-PASSWORD-HOWTO delves into the murky depths of shadow passwords and even why you might not want to use them.

http://www.tldp.org/HOWTO/Security-HOWTO.html—A “must read” HOWTO, the Security-HOWTO is a good overview of security issues. Especially applicable to this chapter sections on creating accounts, file permissions, and password security.

http://www.tldp.org/LDP/lasq/—A general guide, the Linux System Administrator's Security Guide has interesting sections on limiting and monitoring users.

http://www.tldp.org/LDP/lasq/administration/index.html—The LSAG Administration Tools Index is a good place to look at some administrative tools, but it is by no means an exhaustive list.

http://www.tldp.org/HOWTO/Config-HOWTO-4.html#config—How you can customize some user-specific settings? The Config HOWTO Configuration gives some advice.

http://www.tldp.org/HOWTO/mini/Path.html—How one can know the true path? The PATH words shines light on this issue. You need to understand paths if you want to guide users to their data and applications.

http://www.courtesan.com/sudo/—The SUDO command is a powerful and elegant way to delegate authority to users for specific tasks.

http://www.kernel.org/pub/linux/pam/index.html—The Pluggable Authentication Modules are complex and highly useful applications that provide additional security and logging for passwords. PAM is installed by default in Red Hat. It’s not necessary to understand the intricacies of PAM in order to use it effectively.

http://www.enteract.com/~1spritz/linux.html—“Armoring a Linux Box”; modifying Pam files to use MDS passwords, creating and using the mysterious wheel group.

http://localhost/localdomain—Your Red Hat system contains man and info pages just about everything covered. Use -k to search on a keyword.
