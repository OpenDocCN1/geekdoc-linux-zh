# Using Wine to Run Windows Programs in Red Hat Linux

/usr/shar/doc/wine-20020605. Included in the samples directory is a variation
of the configuration files named config; it's slightly different from what Red Hat has
provided. Also, the documentation for the configuration file is found at
usr/shar/doc/wine-20020605/wine-doc/c513.html. The following comments contain
information not found in the official documentation:

```
WINE REGISTRY Version 2
;; All keys relative to \Machine\\Software\\\Wine\\\Config
```

```
;
;; MS-DOS drives configuration
;;
;; Each section has the following format:
;; "Path="xxx" (Unix path for drive root)
;; "Type="xxx" (supported types are 'floppy', 'hd', 'cdrom' \
and 'network')
;; "Label="xxx" (drive label, at most 11 characters)
;; "Serial="xxx" (serial number, 8 characters hexadecimal number)
;; "Filesystem="xxx" (supported types are 'msdos'/'fat', \
win95'/'vfat', 'unix')
;;; This is the FS Wine is supposed to emulate on a certain
;; directory structure.
;; Recommended:
;; - "win95" for ext2fs, VFAT and FAT32
;; - "msdos" for FAT16 (ugly, upgrading to VFAT driver strongly recommended)
;; DON'T use "unix" unless you intend to port programs using Winolib !
;; "Device="dev/xx" (only if you want to allow raw device access)
```

The next section of the configuration file provides the definition of the A:\ drive. This is
t floppy drive that many Windows applications expect to see.

If you don't have an A:\ drive (many laptops and desktops don't), change the last line of
definition to look like the c:\ drive and mount an image file at /mnt/floppy. That's enough
of Wine.

```
Drive A
"Path" = "/mnt/floppy"
"Type" = "floppy"
"Label" = "Floppy"
```
