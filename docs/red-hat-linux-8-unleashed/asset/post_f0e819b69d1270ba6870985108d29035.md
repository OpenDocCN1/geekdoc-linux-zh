## Mail Daemons

Once installed (using the pm command or through the Packages graphical interface—see Chapter 8), the documentation will be found in /usr/share/doc/imap-201a and the README is brief; Red Hat has already done the configuration for: You only need to start the services (see Chapter 7).

Biff and its KDE Korn are small daemons that monitor your mail folder and notify when a message has been placed. These are installed by default. It is common to biff y in the .login or .profile files to automatically start it upon user login to use Biff. Korn can be started by adding the app to the KDE taskbar.

## The mail Application

A UNIX utility named mail is included with all UNIX and Linux distributions. Because it has a very Spartan interface, it's not used interactively. However, it is still an extremely useful program to use in shell scripting because it can take all the information it needs to send mail from the command line. No user interaction is required. It is also useful for sending quick notes because it starts up quickly and doesn't require going through menus to send a message.

## Using mail

To begin sending a message in mail, simply type mail at the shell prompt, followed by the email address that you want to send mail to; for example, mail@cheetah.org. mail will then prompt you for the subject of the message. Enter the subject and press Enter. The cursor will then move down to the next blank line. You can now start entering the body of message. When you have finished, press Ctrl+D on a blank line to exit the mail program and send the message. (You might be prompted for Cc: If you do not want to send carbon copies to anyone, simply press Here.) The message will be handed off to the MTA, and your shell prompt will return. Abandon the number and message you are currently writing, press Ctrl+C.
