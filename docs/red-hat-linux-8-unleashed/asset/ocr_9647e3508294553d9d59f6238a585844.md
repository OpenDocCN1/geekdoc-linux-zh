# Getting the Most from Red Hat and Linux Documentation

Along with the guides and updates, new users contemplating purchase of new hardware might want to check Red Hat's listing of certified hardware and hardware compatibility list. Checking for compatibility will help save time and trouble and avoid troubleshooting issues. For more technical information about Red Hat and Linux, a series of "white papers" are also available online.

Red Hat also provides a series of nearly fifty mailing lists you can subscribe to. These lists are exchanges of information between Red Hat users and developers about different topics, and they are grouped by subject. Subscribing is automatically handled by remote Red Hat servers, and is as easy as sending a request mail message. The following is a partial listing of the available mailing lists at https://www.redhat.com/mailing-lists/

+   * redhat-announce-list—General announcements about Red Hat Linux

+   * redhat-devel-list—Information for developers

+   * redhat-install-list—Discussions regarding installation

+   * redhat-list—General Red Hat Linux

+   * redhat-ppp-list—Discussions regarding Internet connectivity

+   * redhat-secure-server—Discussions about Red Hat's Secure Web Server

+   * redhat-watch-list—Announcements of updates, security and bug fixes

+   * rpm-list—Discussions regarding use of RPM

+   * under-the-brim—The Red Hat Linux newsletter

Savvy Red Hat users will turn to some of these discussions, which are archived online, for answers when searching for troubleshooting information. For example, if you're having trouble with a sound card, you can browse to Red Hat's mailing list page, and then click on the sound-1st list. You'll see a list of messages from users exchanging information about different sound cards with Red Hat. By subscribing to the list, you'll be able to ask for help by email or perhaps help someone else with a problem you have solved.

# Using Red Hat Linux Manual Pages and HOWTOs

If you choose to perform a full installation of Red Hat Linux, you'll find traditional Linux software package documentation, as manual pages, the /usr/share/doc directory. Manual pages are text files containing succinct information about how to use a program. Each manual page generally provides a short summary of a command's use, a synopsis of command-line options, an explanation of the command's purpose, potential caveats or bugs, the name of the author, and a list of related configuration files and programs.
