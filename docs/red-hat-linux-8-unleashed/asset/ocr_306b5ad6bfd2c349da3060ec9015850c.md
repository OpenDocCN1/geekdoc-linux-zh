# Checking Hardware Compatibility

Red Hat Linux software for Intel-based PCs is compiled for the minimum x86 platform supported by the Linux kernel, the x386 CPU family.

> The compatibility information in this chapter relates to Red Hat Linux. Other distributions, such as SuSE (which requires an x86) and Red Hat-based Mandrake Linux (which requires a Pentium-class CPU) might have different storage and CPU requirements.

Specific issues regarding hardware compatibility can be researched online through Red Hat, Inc’s hardware compatibility database at /hardware/.redhat.com/hcl1/genpage2.cgi?pagename=html&view=advsearch#form. You can select hardware class, manufacturer, version of Red Hat Linux, platform, and status of support. To narrow searches, you can also enter an optional keyword. Make your selections, and then click the Search button to view a result, as seen in Figure 2.1.

After you press Enter, matching returns with a compatibility graphic (checkmark), and any issues will be appended and displayed on the Web Page. This is a great resource to use before purchasing equipment to use Red Hat Linux or before installing potentially problematic hardware. Some of the hardware categories covered in the database include

+   - Controller cards—Such as SCSI, IDE, Firewire
- CPUs—Intel, AMD, and others
- Input devices—Keyboards
- Modems—External, PCMCIA, PCI, and controllerless workarounds
- Network cards—ISA, PCI, USB, and others
- Pointing devices—Mice, tablets, and possibly touchscreens
