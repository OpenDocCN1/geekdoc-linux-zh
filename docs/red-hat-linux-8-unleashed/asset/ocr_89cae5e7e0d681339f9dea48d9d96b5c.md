All files in the /etc directory will be saved to a file named etc.tar. With an impressive array of options (see the main page), tar is quite flexible and powerful in combination with shell scripts. With the -z option, it can even create and restore g-zipped compressed archives while the -j option works with bzipped files.

# Creating Full and Incremental Backups with tar

If you want to create a full backup,

```
# tar cjf fullbackup.tgz /
```

will create a bzip2 compressed tarball (the j option) of the entire system.
 perform an incremental backup, you must locate all the files that have been changed since the last backup. (For simplicity, assume that you do incremental backups on a daily basis.) To locate the files, use this find command:

```
# find / -newer <name of last backup file> ! -a type f -print
```

When run alone, find will generate a list of files systemwide and print it to the screen. The -type eliminates everything but regular files from the list; otherwise, the entire directory would be sent to tar even if the contents weren't all changed.

Pipe the output of our find command to tar as follows:

```
# find / -newer <name of last backup file> ! -type d -print |\ntar czT - <backup file name or device name>
```

Here, -option gets the filenames from a buffer (where the - is the shorthand name for buffer).

> NOTE The tar command can back up to a raw device (with no filesystem) as well as a formatted partition, for example,

```
# tar -cvzf /dev/hdd /boot /etc /home
```

backs those directories to device /dev/hdd.
The tar command can also back up over multiple floppy disks:

```
# tar -cvmf /dev/fd0 /home
```

will back up the contents of and spread the file out over multiple floppies, prompting with this message:
 Prepare volume #2 for /dev/fd0 and hit return:
