# CHAPTER 9 Managing Users

sudo will prompt you for a password and then check /etc/sudoers to see if you have permission to use that particular command. It issues a ticket that lasts for a brief time so that repeated use of the command can be made without additional hasle as long as the ticket is valid. The time limit can be determined by the superuser; otherwise, the five-minute default time is used. Extensive logging of sudo is maintained as a security measure.

If you desire customized of sudo, extensive options are available during the compilation process, and the available options to use in the configuration file are extensive as well. Alias support configuration easier.

The configuration file is at /etc/sudoers; it should only be edited with the visudo command through the vi editor (Chapter 5 for an introduction to vi). The sudo man page provides information on how to edit the sudoers file and is required for anyone who wants to use this command.

Briefly, a line in the sudoers file granting privileges to user may examine any file on the system (and using aliases to extend this to others easily if needed) would look like this:

```
User_Alias GURU=hoyt
Cmd_Alias FILE_TOOLS=/bin/ls,/bin/cat,/usr/bin/less

GURU ALL=FILE_TOOLS
```

Now, the regular user may use ls, cat, and less with superuser privileges. It is may add users to the alias GURU, with additional commands to FILE_TOOLS if their use were authorized. Note that ALL- permits privileges over the same network; it is possible to limit the privileges to the local machine on the network or a subnet on the local network (see Chapter 13, "Network Connectivity").

> sudo is a simple way to extend certain privileges to users other than the superuser. All sudo activity is recorded in the security log /var/log/secure, so the use (and potential misuse) of this command is easy to monitor.

# Control Via Restricted Shells

Using restricted shells is actually the opposite of granting privileges to users. There might be situations when you want to restrict a user to a very specific subset of privileges permitted to others. If you have a desire to restrict what a user can do (for reasons of security, distribution of a turnkey system, or custom system installation), you can provide him with a restricted shell. To run a restricted shell, you would use the -r option. It's easy to try yourself, just enter the following at your prompt:

```
$ bash -r
```
