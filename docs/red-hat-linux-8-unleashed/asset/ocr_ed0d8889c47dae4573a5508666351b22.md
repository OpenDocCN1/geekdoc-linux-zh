http://www.tld.org/LDP/tlk/—The Linux Kernel. Online book about the 2.2 Linux kernel describing the internals of the kernel.

http://www.tld.org/HOWTO/KernelAnalysis-HOWTO.html—KernelAnalysis-HOWTO. Describes the mysterious nature of the kernel.

http://www.tld.org/HOWTO/Module-HOWTO/index.html—Kernel Module HOWTO. Includes a good discussion about unresolved symbols.

http://www.tld.org/—The Linux Documentation Project. The Mecca of all Linux documentation. Excellent source of how-to documentation, as well as FAQs and online books, all about Linux.

http://www.minix.org—The unofficial minix Web site. It contains a selection of links to information about minix and a link to the actual homepage. Although minix is still copyrighted, the owner has granted unlimited rights to everyone. See for yourself the OS used to develop Linux.

http://ftp.linux.org.uk/pub/linux/links/~Home of the Embedded Linux Kernel Subset; the goal of which is to run a subset of Linux on machines with limited processor and memory. It does not appear to be in active development.

http://jungla.dit.upm.es/~jmseys/linux/kernel/hackers-docs.html—Web page with links to Linux kernel documentation, books, hacker tomes, and other helpful information for budding and experienced Linux kernel and kernel module developers. This list will also be found in the file /usr/src/linux-2.4/Documentation/kernel-docs.txt if you install the Red Hat Linux kernel sources.
