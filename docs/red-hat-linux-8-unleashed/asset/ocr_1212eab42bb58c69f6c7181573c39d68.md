Welcome to Red Hat Linux Unleashed! It might be hard to imagine, but you're holding nearly $1 billion worth of software in your hands. That is one estimate of what it would cost to develop an operating system, graphical interface, and related software to equal your copy of the latest Red Hat Linux included with this book.

Less than five years ago, any new major project involving the use of Linux by a large company, government agency, or academic entity would have been big news in the world of open source software. Today, Red Hat Linux is an increasingly common part of IS/IT strategies for success; over 25 percent of server installations use Linux as a base platform. With plenty of growth potential and Red Hat, Inc.'s sponsorship of development aimed at improving graphical user interface technologies as GNOME, Linux is poised to make even more significant penetrations into the desktop market.

> The list of current Red Hat Linux projects, efforts, and partners reads like Who's Who the software industry: Amazon, Ameritrade, Borland, Computer Associates, Dell, Hewlett-Packard/Compaq, IBM, Oracle, and SAP are some of the enterprise-level players using Red Hat Linux. Others include Disney, DreamWorks, and Pixar. Red Hat Linux is being used for special effects rendering in New Line Cinema's upcoming Lord of the Rings sequel, The Two Towers. Linux is also a key ingredient and shares an ever-increasing portion of server hardware sales from all large vendors, such as IBM, Hewlett-Packard/Compaq, and Dell.
