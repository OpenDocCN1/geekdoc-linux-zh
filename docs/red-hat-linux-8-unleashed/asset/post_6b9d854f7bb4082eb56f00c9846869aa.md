### Commercial Office Suites for Linux

Several commercial office suites are available for Linux, in addition to StarOffice, which was already mentioned. None of these commercial suites are provided with Red Hat except Hancom Office. Using the same widget in the KDE desktop, Hancom Office scores well on file compatibility. The suite includes a word processor, a spreadsheet presentation tool, and a graphics application. Corel produced a version of WordPerfect Office 2000 for Linux before it discontinued the release of any new products. It still offers a support page, but the software is no longer available.

### PDA Connectivity

The Red Hat Linux distribution provided on this book's CD-ROMs includes programs and clients for use with personal digital assistants (PDAs). You can use these programs to transfer information to and from a PDA, send and retrieve email, manage your calendars, and more.

### Command-Line PDA Software for Red Hat

The most popular PDA-related software suite is the collection of utilities included with Red Hat Linux. The utility is found in the Accessories menu as the Pilot/Handspring menu item. You can use the command line to perform a variety of tasks with this package, including the following:

- Extracting addresses
- Installing date information
- Transferring memos to and from the PDA
- Managing to-do lists
- Managing user settings
- Sending and retrieving email
- Installing new PDA programs
- Backing up the contents of a PDA
- Acquiring information

You use the pilotxfer command to perform many tasks although the suite includes separate programs. After configuring the software, determining the proper serial port, and connecting the PDA to a desktop or notebook that is running Red Hat Linux, you can back up the contents of the PDA with the pilotxfer command, like this:

```
$ pilotxfer /dev/tty1 -b directory
```

This command automatically creates a directory according to the -b option and then downloads and saves the contents of the PDA in the designated directory. Red Hat has GNOME graphical interface to these commands, which is accessed under the Accessories menu as Pilot/Handspring. We recommend either of the two applications, which provide more features.

### GUI PDA Client Software

To interact with a PDA using a graphical interface, you can use the Organizer client. You can use this application to install and retrieve text documents and back up the contents of a PDA. You need to properly configure the software by selecting the correct serial port, setting, and default file location. You open Organizer by opening the Accessories menu and choosing Pilot.

### Scanner Applications for Red Linux

The use of a scanner provides a wealth of options to enhance productivity. You can manipulate scanned images in graphics applications like the GIMP, OpenDraw, and Contour and then print them, or embed them in a word document. You can scan paper documents for archival purposes, or process them with optical character recognition (OCR) software to translate images into words that can be edited in a text editor or word processor. Red Hat has the Xsane (see Figure 25.12) and Kooka (see Figure 25.13) applications to assist you with scanning.

Scanner support is provided by Scanner Access Easy (SANE). If your scanner is supported, it is listed on the SANE support page, at http://www.linux.org/sane/backends.html.

The development version of SANE supports scanners that aren't supported in the regular version. If your scanner is supported only in the development version, you need to download and compile the CVS version of SANE. That's a complex operation that is suitable for advanced Linux users only, and it is beyond the scope of this chapter. For information on that process, see the CVS-RCS HOWTO Document for Linux (Source Code Control System) at http://www.linux.org/howto/CVS-RCS-HOWTO.html.

The Xsane application, as shown on Figure 25.12, is a graphical front end to SANE. It allows you to acquire and manipulate scanned images. It can run as a plug-in from the GIMP. The GIMP is discussed in more detail in Chapter 26.

![](img/446debe023486a07fde575245cf7a3ff_865_0.png)

FIGURE 25.12 Upon starting, Xsane presents several related screens on your desktop: a control interface, a histogram, a preview screen, and an options dialog.

Kooka is a KDE application that provides similar functionality to Xsane, but it provides OCR (optical character resolution) capabilities as well as an image gallery function. Because Kooka is a KDE application, it can provide scanning services to other KDE applications (such as KOffice and KView) when they are written to use. Kooka uses gocr (http://jocr.sourceforge.net/) as an application for character recognition, but support for Clara OCR (http://www.claraocr.org/) is planned for the future.
