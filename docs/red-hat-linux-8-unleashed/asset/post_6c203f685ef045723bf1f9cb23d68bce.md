
## Configuring Apache for Peak Performance

Use the options in the Performance Tuning tab to configure Apache to provide peak performance in your system. Options in this tab set the maximum number of connections, connection timeouts, and number of requests per connection. When setting this number, keep in mind that for each connection to your server, another instance of the httpd program may be running, depending on how Apache is built. Each instance takes resources such as CPU time and memory. You can also configure details about each connection such as how long, in seconds, before a connection times out and how many requests each connection can make to the server.

## Other Web Servers for Use with Red Hat Linux

There are, of course, other web servers that can be used with Red Hat Linux. Apache is by far the most popular, but this doesn't rule out the others.

To determine the best web server for your use, consider the needs of the site you manage. Does it need heavy security (for e-commerce), multimedia (music, video, and pictures), or the capability to download files easily? How much are you willing to spend for the software? Do you need software that is easy to maintain and troubleshoot or includes tech support? The answers to these questions might steer you to something other than Apache.

The following sections list some of the more popular alternatives to using Apache as your web server.

## httpd

It isn't entirely clear what the "t" in httpd stands for. Meanings between tiny, turbo, and throttling, depending on who you ask. Whatever meaning you opt for, it's clear that httpd is not big and slow.

Throttling, in the context of httpd, is a process in which incoming URL calls are kept under control for a certain page or collection of pages on the Web. If traffic hits a defined limit, the requesters for the page are sent a try again code until the traffic returns to a more manageable level.

httpd is, on the surface, a simple little HTTP server that can handle a fair amount of traffic with little strain. Although not as robust as Apache, it does feature a throttling control—something that isn't readily available for Apache.

httpd is available as freeware from the httpd Web site (http://www.acme.com/software/httpd).

## Sun ONE Web Server

Despite the NetCraft numbers shown in Table 16.1, there's evidence that the Sun ONE Web Server (formerly known as the iPlanet Web Server, Enterprise Edition, now a core component of Sun’s Open Net Environment), might even be the more popular than Apache in strictly corporate arenas. According to the Gartner Group, the former iPlanet software ranked highest among Web servers found at Fortune 100 Web servers last year.

Sun ONE Web is great for handling big Web needs, and it comes with an appropriate big price: $1495 (U.S.) for the basic enterprise server package. It’s definitely not something for the school Web site, unless your school happens to be a major university with several regional campuses. For more information on iPlanet, you can visit its Web site (http://www.sun.com/software/products/web_srvr/home_web_srvr.html).

## Stronghold

If you’re looking for a little more secure than Apache, but still don't want to lose the Apache functionality, you can purchase Stronghold from Red Hat Software.

Although not a Web server per se, Stronghold is an add-on that provides 128-bit cryptography and security certificates to the Apache Web server (which is included in your purchase of Stronghold).

Stronghold supports SSL and TLS security standards, as well as many of the certificate standards on the market today.

The price for this of security isn’t particularly light, which can be previewed at http://www.redhat.com/software/apache/stronghold/, costs $995 (U.S.).

## Zope

Zope is another Open Source Web server. Although it’s still relatively young and might not have as much flexibility as Apache, it is making inroads in the Web server market.

What makes Zope different from Apache is the fact that it’s managed through a completely Web-based graphic interface. This has broad appeal for those who aren’t enthused about a command-line-only interface.

Zope is a product of the Zope Corporation (formerly Digital Creations), the same firm that made the Python programming language. And, like all things open, it is free. Information on Zope can be found at http://www.zope.com (for the commercial version) and http://www.zope.org.

## Zeus Web Server

Zeus is a high-performance web server that was developed by SoftwareIQ America. Zeus is often considered the fastest web server in many performance comparisons, and it is frequently used for high-traffic websites.

Zeus is a commercial product, so it is not free. However, it offers many features that are not available in Apache, such as advanced load balancing and better support for concurrent connections.

Nginx is another open-source web server that is designed to be fast and lightweight. It is often used as a reverse proxy or load balancer. Nginx is very popular and is used by many large companies around the world.

Lighttpd is another open-source web server that is known for its speed and low memory usage. It is often used for hosting high-traffic websites.

Mongia is a powerful web server that is very flexible and extensible. It supports a wide range of server programming languages and databases.
