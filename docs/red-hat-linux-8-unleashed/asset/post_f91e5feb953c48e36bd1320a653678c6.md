
## CHAPTER 5 First Steps with Linux

You can start an editing session by using vi command like this:

```bash
vi file.txt
```

The vi command works by using insert, editing mode, and viewing (command) mode. When you start editing, you'll be in viewing mode. You can use your cursor or other navigation keys (as shown later) to scroll through the text. To start editing, tap i to insert text, or When finished, use Esc key to toggle out of insert or append modes into viewing (command) mode. To enter a command, type colon (:), followed by the command, as w to write the file, and press Enter.

Although vi supports many complex operations and numerous commands, you can accomplish work using a few basic commands. These basic vi commands are

- Cursor movement: h, j, k, l (left, down, up, and right)
- Delete character: x
- Delete line: dd
- Mode toggle: ESC
- Insert: i
- Quit: :q
- Quit without saving: :q!
- Run shell command: :sh
- Save file: :w
- Text search: /

## Working with emacs

Richard Stallman's GNU emacs editor, like vi, is included with Red Hat and nearly every Linux distribution. Unlike other text editors, emacs is much more than a simple text editor—it is an editing environment and can be used to compile and build programs, act as a diary and calendar, compose and send mail, read Usenet news, and even play games. The reason for this capability is emacs contains a built-in interpreter that uses Elisp (emacs LISP) programming language.

The GNU version of this editor requires more than 30MB of hard drive space. However, there are versions with less resource requirements, and one named joe, can be used as an emacs clone (albeit with fewer features). You can start an emacs editing session like this:

```bash
emacs file.txt
```

If you start emacs using X, the editor will launch in its graphical window. To force emacs to display inside a terminal window (which can be useful if you login at a remote computer), use the -nw command-line option like this:

```bash
emacs -nw file.txt
```

The emacs editor uses an extensive set of keystroke commands, but you can work with it using a basic subset. Many of these basic commands require you to hold down the Ctrl key, or first press a meta key (generally mapped to the Alt key). The basic commands are listed in Table 5.2.

## Working with Permissions

Under Red Hat Linux (UNIX), everything in the file system, including directories and devices, is a file. Every file on your system has a set of permissions based on ownership. These permissions form the basis for security under Linux, and designate each file's read, write, and execute permission for you, members of your group, and all others on the system.

You can examine the default permissions for a file you create by using the uname command, or as a practical example, by using the touch command and then the ls command's long-format listing like this:

```bash
touch file
ls -l -1 file
-rw-rw-r-- 1 bball bball Jul 23 12:28 file
```

In this example, the touch command is used to quickly create a file. The ls command then reports on the file, displaying information (from left to right) in the first field of output (such as -rw-rw-r--).

- The first character of the field is the type of file created—Common indicators of the type of file are a leading letter in the output. A blank (in the preceding example, which is represented by a dash) designates a plain file, d designates a directory, c designates a character device (such as /dev/tty0), and b is used for a block device (such as /dev/hda).
