# Other FTP Servers

Although wu-ftp is a respectable FTP server, it isn’t the optimal FTP server for sites that need to provide access to a high number of concurrent users. One alternative server is NcFTPd, available from http://www.ncftp.com. This server operates independently of xinetd (which is used to enable and start the wu-ftp server; see the section “xinetd Configuration” later in this chapter) and provides its optimized daemon. Additionally, NcFTPd has the capability to cache directory listings of the FTP server in memory, increasing the speed with which users can obtain a list of available files and directories. Although NcFTPd has many advantages over wu-ftp, NcFTPd isn't GPL licensed software, and its licensing fees vary according to the maximum number of simultaneous server connections ($99 for 50 more concurrent users and $99 for up 50 concurrent users). > Do not confuse the ncftp client with ncftpd. The package ncftp-3.1.3-1386.rpm on the CD-ROM is the client software, a replacement for ftp-0.17-13. ncftpd is the FTP server, which can be downloaded from www.ncftp.com.

Another FTP server package is ProFTpd, licensed under the GNU GPL. This server works well with Red Hat Linux and is by number of Linux sites, including ftp.kernel.org and ftp.sourceforge.net. ProFTpd is actively maintained and updated for bug fixes and security enhancements. Their developers recommend that you use the latest release (1.2.5 at the time of writing) to avoid exposure to exploits and vulnerabilities. Browse to http://www.proftpd.org to download a copy.

Yet another FTP server package is BSDftp-ssl, which is based on the BSD Unix ftp (and distributed under the BSD license). Bsdftp-ssl offers simultaneous standard and secure access using security enhancements; access requires a special client. For more details, browse to http://bsdftp-sssl.sc.ru/.

Finally, another alternative is to use Apache (and the HTTP protocol) for serving files. Using a Web server to provide data downloads can reduce the need to monitor and maintain a separate software service (or directories) on your server. This approach to serving files also reduces system requirements and gives more flexibility when downloading (such as enabling them to download multiple files at once). See Chapter 16, “Apache Web Server Management,” for more information about using Apache.
