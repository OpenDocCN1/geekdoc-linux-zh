# CHAPTER 10 Managing the Filesystem

http://www.ldp.org/HOWTO/mini/Ext2fs-Undeletion.html—You deleted a file on your ext2/3 partition? The Linux Ext2fs Undeletion mini-HOWTO is there to help you out, as is Chapter 11 of this book.

http://www.ldp.org/HOWTO/mini/Ext2fs-Undeletion-Dir-Struct/index.html—You deleted a directory on your ext2/3 partition? Read the Ext2fs Undeletion of Directory Structures HOWTO to see how to rescue yours.

http://www.ldp.org/HOWTO/Loopback-Root-FS.html——Here’s the concept: Not only can we have a traditional filesystem, but we also have a filesystem inside a large file located on some other filesystem. The Loopback Root Filesystem HOWTO examines how this is done.

http://www.ldp.org/HOWTO/Loopback-Encrypted-Filesystem-HOWTO.html—The Loopback Encrypted Filesystem HOWTO; making your data secure with encryption.

http://www.ldp.org/HOWTO/LVM-HOWTO.html—Throw away those that marry physical disks to finite-sized files; the Logical Volume Manager HOWTO explains how to overcome that kind of thinking.

http://www.sistina.com/products_lvm—The LVM homepage and the source of downloadable files via FTP.

http://linux.org/mt/article/lvm—A good overview and discussion of Logical Volume Managers.

http://www.coda.cs.cmu.edu/—The Coda network filesystem homepage.

http://www.intermezzo.org/—TheMezzo network filesystem homepage.

http://www.math.ualberta.ca/imaging/snfs/—Secure NFS via an SSH Tunnel is a very interesting attempt to address security shortcoming of NFS over a public network.

http://www.ldp.org/HOWTO/UMDSOS-HOWTO.html—If you are interested in using the umdos filesystem, the UMDOS provides ample information to you.

http://www.ldp.org/mini/NFS-Root—The NFS-Root mini-HOWTO, NFS-Root-Client Mini-HOWTO

http://www.ldp.org/mini/NFS-Root-Client-HOWTO/index.html—Explains in detail how to set up and use NFS for exporting filesystems.

http://www.nyk.net/~sgjoen/disk.html—The Multi Disk System contains explanations of the driver and controller hardware that are useful, as well as discussion of filesystems. It has an interesting section on optimizing multitask setups.

http://www.ldp.org/HOWTO/Software-RAID-HOWTO.html—The Software-RAID HOWTO is an excellent tool to de force of software RAID.
