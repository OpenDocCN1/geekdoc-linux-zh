```
BROADCAST=255.255.255.255
GATEWAY=192.122.60.1
HOSTNAME=dhcp-422-13
DOMAIN=domain.com
DNS=192.172.3.8,192.172.3.9
DHCPSID=192.122.64.45
DHCPGIADDR=0.0.0.0
DHCPCIADDR=0.0.0.0
DHCPCHADDR=00:68:8F:5A:D9
DHCPSHADDR=01:03:A4:21:09
DHCPSPAME=
LEASEASTIME=3600
RENEWALTIME=1800
REBINDTIME=3150
```

The first eight lines consist of the TCP/IP configuration information required to connect this system to the domain.com network. The IP address is 193.122.60.235; the netmask shows that this is a class C network; the network address is 192.122.60.0. The broadcast address is set at 255.255.255.255 because the client is initially unaware of where the DHCP server is, the client must request every network until assigned a server replies. The gateway shows to this network's router or switch, the hostname assigned by the DHCP server is dhcp-422-13, and the domain is the domainname of the network. Finally, the DHCP servers are at the IP addresses 192.172.3.8 and 192.172.3.9.

The last nine lines define the DHCP specific information for this client. DHCPCSID is the client's IP address: DHCPGIADDR, DHCPCIADDR, and DHCPHOSTNAME are not used. DHCPCHADDR is the hardware address of the client; DHCPSHADDR is the hardware address of the DHCP server (one hour) and LEASTIME is 3600 seconds (one hour) and represents the length of time that the lease is valid. RENEWAL TIME is the time in seconds the client tried to renew the lease; REBINDTIME is the time in seconds (57 minutes, 30 seconds) when the client gives up on renewing the current lease and starts to look for a whole new lease. If the LEASTIME reaches zero before the client's lease is renewed or a new lease is issued, the client's connection is cut because of the lack of a valid IP address. If the network capacity is planned correctly, no client should either lose or refuse a lease.
