# CHAPTER 4 Post-Installation Configuration

http://www.qbik.com/usb/devices/The place to check for compatibility of USB devices for Linux.

http://www.linmodems.org—This site provides links to server drivers for controller modem under Linux.

http://www.linux1394.org/Home page for the Linux IEEE 1394 project with new information, links to updated drivers, and lists of compatible chipsets and devices.

http://www.faqchest.com/The FAQChest, a searchable archive of FAQ's HOWTO's and mailing lists; an alternative to http://marc.theaimgroup.com/.

http://groups.google.com/Usenet group Google; another alternative at http://marc.theaimgroup.com/.

http://www.fokus.github.com/research/cc/glone/employees/joerg.schilling/private/cdrecord.html—Home page for the cdrecord command and related utilities.

http://www.tuxedo.org/--r/fags/smart-questions.html—How Ask Questions the Smart Way, a guide to getting help efficiently. This explains why people ignore your questions or tell you to RTFM.

http://csgrad.cs.vt.edu/~tjohnson/pinouts/—A collection of pinout information, helpful in fixing connector problems.

http://www.arstechnica.com/guide/building/bios/bios-1.html—An excellent discussion of BIOS options at ArTechnica.

http://www.yourvote.com/pci/PCI Vendors and Devices Lists; using the Vendor ID to get information on an unknown PCI device.

http://mandrakeforum.com/article.php?sid=2242&mode=thread&0&thold=0—A tutorial for configuring an unlisted monitor.

http://www.linuxnetmag.com/en/issue5/mdevs1.html—A brief article on how to use the information found in devices.txt.
