# TABLE 20.2 INN Package Configuration Files

| Configuration | Description |
|---|---|
| control.ctl | Specifies how control messages are handled. |
| expire.ctl | Specifies how articles are expired. |
| incoming.conf | Specifies addresses and authentication information for servers that send news to your news server. |
| inn.conf | Acts as the primary configuration file for the innd program. |
| innfeed.conf | Specifies parameters for the incoming newsfeed handler. |
| inwatch.ctl | Determines how the inwatch program monitors the INN system. Specifies email addresses for moderated newsgroups. |
| motd.news | Specifies what information is posted to newsreaders when a list motd command is set. |
| newsfeeds | Specifies which newsgroups are fed to other news servers from this server. Specifies newsreaders or servers that have their activity recorded during an NNTP session. |
| nnrpd.track | Specifies remote news servers that your server will feed articles to in batch mode. |
| ntpsend.nnt | Specifies passwords used to connect to remote news servers. |
| readers.conf | Specifies authorized remote readers and newsgroup permissions. |
| sasl.conf | Specifies file locations for the encryption keys used for the SASL configuration. |
| storage.conf | Specifies the method used for specific newsgroup articles. |
| subscriptions | Specifies a list of newsgroups that newsreaders can subscribe to. |

Don't let the long list of configuration files in Table 20.2 worry you; most of the parameters defined in the configuration files work with their default settings. Typically, you need to make only a few changes to configure the INN server to work in your particular network environment.

# Installing the INN Package

The Red Hat distribution uses two separate RPM files to install the INN package. The first package, simply called inn, installs the necessary configuration and application files needed for the INN package to work on the system. The second package, called inn-devel, is used to install INN header files that external newsreader programs use to work with inn. You don't need to install the inn-devel package for inn, but if you are using other newsreader programs on the server, you should install it. The default INN installation also installs the inews-2.3.3-5 and cleanfeed-0.95.7b-17 packages, which are used to forward articles to the server and filter out spam.
