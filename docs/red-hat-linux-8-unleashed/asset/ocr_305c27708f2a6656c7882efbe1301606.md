http://www.winehq.org/—The home of the Wine Project with links to documentation, source code, and Winelib.

http://cygwin.com/—The Cygwin Home page, source of a UNIX-like environment for all Windows platforms (except Windows CE).

http://www.libbsdl.org/Xmingw32/—Home page for a build of a cross-compiler for Windows (using Cygwin tools available through the preceding link).

http://corefonts.sourceforge.net/—An easy way to install Microsoft's TrueType core fonts into Linux. This site provides the tools and the downloadable win32 files to install the fonts useful for Wine and Wine variants. It complies with the Microsoft EULA.

http://www.purplet.demon.co.uk/linux/ibcs/—Linux support for non-Linux programs.
