Now that we have a hard copy of the partition table, it is possible to restore the MBR by hand.

Use the Red Hat Rescue Disk for this process. Simply boot from the first install CD-ROM and enter linux rescue at the LILO prompt. You will have the opportunity to mount your system/write, not to mount your system, or to mount any Linux partitions as read-only. If you plan to make any changes, you will need to have any desired partitions mounted with write permission.

Once logged on (you are root by default), start fdisk on the first drive:

```
# fdisk /dev/hda
```

Use the p command to display the partition information and compare it to the hard copy you have. If the entries are identical, you will have a problem somewhere else; it's not the partition table.

If there is a problem, use the d command to delete all the listed partitions.

Now use the n command to create new partitions that match the partition table of your hard copy. Make certain that the partition types (ext2, FAT, swap) are the same. If you have a FAT partition at /dev/hda1, make certain that you set the bootable flag for it; otherwise, Windows or OS does not boot.

If you find that you have made an error somewhere along the way, just use the q command to quit fdisk without saving any changes and start over.

When the partition table shows on your screen matches your printed version, write the changes to the disk with the w command; you will be automatically exited from fdisk. Restart fdisk to verify your handwork, and then remove the rescue disk and reboot.mk2fs.

It helps to practice on an old drive before you have to do it in an emergency situation.

# Booting the System from the Rescue CD

For advanced Linux users, you can use the rescue CD to boot the system (rather than boot the rescue operating system on the CDROM) if the bootloader on your computer is damaged or incorrect. To Use the Rescue CD to boot your system from /dev/hda1, for example, first boot the CD and press the F1 key. In the LILO prompt, enter something like this example. Note that you are telling the bootloader where your root is.

```
linux rescue root=/dev/hda1
```
