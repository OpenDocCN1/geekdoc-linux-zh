
## Choosing How to Install Red Hat Linux

Most of the BIOS listed in Table 3.1 support booting to an install. The pxboot directory contains a kernel that supports a remote booting protocol PXE that enables installation, booting, or upgrades of-only PCs. Use of this software requires a properly configured DHCP server and a supported BIOS. Although it may be possible to use a floppy disk, this method is not supported by Red Hat. Browse to http://www.compaq.com/products/servers/linux/redhat-whitepapers.html and read the Compaq page paper titled "Configuring a Boot Execution Environment (PXE) using Red Hat Linux 7.1 on Compaq ProLiant Servers" to see one way of booting to an install using PXE. Browse to http://www.europe.redhat.com/documentation/mini-HOWTO/Remote-Boot.php to read how to set up remote boot environments using older versions of Red Hat.

> TIP
> If your PC supports booting from a USB device, you can use a USB floppy disk to boot to an install. It is also possible to boot from an IEEE-1394 (FireWire) CD-ROM if supported by your PC's BIOS.

You can create free floppies using the DOS RAWWRITE command or the linux command. You will need one or more blank floppies. Use the RAWWRITE command after starting DOS do like this:

```
D:\dosutils\rawwrite
```

Follow the prompts to create the images, entering a source filename and a target drive (such as A or B).

To create a boot diskette while running Linux, use the dd command. The first step is to insert the Red Hat Linux CD-ROM and make sure that it is mounted:

| df | 1k-blocks | Available | Use% | Mounted on |
|---|---|---|---|---|
| /dev/hda2 | 18714368 | 1041280 | 7353444 | 59% |
| /dev/hda1 | 46636 | 13247 | 30981 | 30% | /boot |
| none | 120016 | 0 | 120016 | 0% | /dev/shm |
| /dev/cdrom | 655808 | 655808 | | 100% | /mnt/cdrom |

This example uses the disk free or the dd command to show free hard drive space and currently mounted devices and partitions. As you can see, the contents of the first Red Hat CD-ROM is found under the /mnt/cdrom directory. If the CD-ROM is not mounted, use the mount command to manually mount the CD-ROM. You will need to be the superuser operator to do this (see Chapter 5, "First Steps with Linux," for details about how to become root:

```
# mount -t iso9660 /dev/cdrom /mnt/cdrom
```

You can then use the convert and copy or dd command like so:

```
# dd if=/mnt/cdrom/images/nameofile.img of=/dev/fd0
```

This will take the contents of the specified image file (from Table 3.1) and create a diskette in the DOS drive A (represented by /dev/fd0). Use /dev/fd1 if you want to use an installed secondary floppy drive.

> TIP
> PC notebook users installing via a network or external CD-ROM drive using a PCMCIA adapter should use pcmcia.img and pciadd.img diskettes.

## Hard Drive Partition Installation

Another way to install Red Hat is to use a Linux or DOS hard partition to either boot the Red Hat Linux install or hold the software required for an install. The partition must be large enough to hold ...iso images (binary images of a CD-ROM). Copy the images of the first and second Red Hat Linux CD-ROMs to a directory on the local hard drive. If you use this type of install and don't need the required hard drive later on, keep the images on the hard drive because Red Hat can be quickly reinstalled from the partition.

The .iso images can be downloaded from Red Hat, Inc. or a mirror FTP site (see http://www.redhat.com/download/mirror.html for links). To perform this installation, you will need to know the hard drive's device name (such as /dev/hdb), along with the partition number.

## Installing via Network

Red Hat Linux can be installed using local network or over the Internet. Although you can use the Red Hat installer to set up network protection during install, it is best to check your system settings after install before opening any services (see the section “Firewall and Security” later in this chapter).

See Chapter 18 for details on how to configure an FTP server. Chapter 16 provides information on how to set up Apache. See Chapter 13 for Samba settings. Note that you can have your server perform all duties.
