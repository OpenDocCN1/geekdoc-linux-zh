# CHAPTER 10 Managing the Filesystem

Because the ext3 filesystem is a new version of the ext2 filesystem with journaling added, it supports the same options as ext2, as well as the following additions:

+   - noload—This option disables the ext3 file system's journal when mounting; it becomes an ext2 filesystem.
- data=journal / data=ordered / data=writeback—This option specifies the journaling mode; "ordered" is the default. Metadata is always journaled.
- journal—The slowest, most secure mode because all the data is written to the journal before it is written to the regular filesystem.
- ordered—This is the default mode in which all data is written to the main filesystem prior to its metadata being committed to the journal.
- writeback—With this option, data can be written into the main filesystem after its metadata has been committed to the journal. This option allows old data to appear in files after a crash and journal recovery, it is the fastest option.

# Using mkreiserfs

The Reiser filesystem joins file data and handles smaller files more efficiently than the ext3 filesystem. Although it is suitable for use root filesystem, Red Hat does not officially support its use in that way. You may use the mkreiserfs command to create a Reiser filesystem. The default values for mkreiserfs work well. To create a Reiser filesystem, use

```
# mkreiserfs device
```

# Creating a DOS Filesystem with mkdosfs

It's possible to create DOS files without owning any Microsoft software using the mkdosfs command. To create a DOS filesystem in an image file (useful with some emulators such as Bochs; see Chapter 27), use the -c option. The -n option allows you to specify a volume label. To create a 1.4M DOS filesystem as an image file the sector size (-S) should be 512 and the block count should be 1440. Use the -v option to provide verbose output that we can observe what happens.

```
# mkdosfs -n dosfloppy -C floppy.img -S 512 1440
```

To create a DOS filesystem on a disk drive, use

```
# mkisfs device
```

This creates a floppy-sized image file with a low-level DOS format. A complete review of all the argument options and syntax for creating a DOS filesystem can be found in man mkdosfs. In both cases, the new filesystem must be mounted (as described in the following-section) and then formatted with the mformat command—one of the Mtools described in Chapter 27.
