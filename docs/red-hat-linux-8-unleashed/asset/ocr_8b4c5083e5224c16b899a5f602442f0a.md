# CHAPTER 10 Managing the Filesystem

ReiserFS is offered primarily for compatibility with existing ReiserFS partitions you might want to access. Although the Reiser filesystem can be used as a root filesystem (meaning Linux can be booted from a Reiser filesystem), Red Hat has chosen not to support that option.

The ReiserFS filesystem has undergone a major update and release with Reiser4. The project, sponsored by the Defense Advanced Research Projects Agency (DARPA), aims to introduce improvements in a number of areas, such as maximum number of directories, files, links, of individual files and size of the filesystem (nearly 18 terabytes). Other improvements include performance improvements and encryption.

# JFS and XFS Filesystems

Two commercial UNIX systems have been ported (rewritten) to allow them to be used in Linux. IBM has provided its Journaled File System JFS that is used with its commercial UNIX named AIX. Silicon Graphics, Inc. (SGI) has provided its XFS filesystem which are generally suited for Enterprise systems rather than home or small office systems, it seems likely that they are offered in Red Hat Linux to ease the transition of IRIX and AIX users to Linux by eliminating the need for these users to reformat their very large files.

Because SGI offers a CD that enables the 7.3 version of Red Hat to be installed with XFS support; it is likely that SGI will offer one to support the current version of Red Hat.

# DOS Filesystems

The extent of DOS filesystem support in Linux is often surprising to newcomers, but the DOS filesystem proved to be a viable option in the early years of Linux. Because Microsoft has been the dominant operating system on Intel computers, Linux has always worked toward co-existence with DOS.

Microsoft DOS and the consumer-oriented Windows systems use a filesystem known as FAT (File Allocation Table). FAT32 is the typical system used today. The number following the FAT name indicates the size of the space for naming address pointers; the more space, the larger a section of contiguous space can be identified and accessed. FAT32 is the most recent version of FAT, and it's backward compatible with all versions of FAT. (Older versions aren't forward compatible.)

The Hat Linux kernel can access all versions of FAT formatted partitions (including floppy disks) by the vfat kernel module.
