# Using Wine to Run Windows Programs in Red Hat Linux

Wine is not an emulator (that's what it stands for), but for all practical purposes it acts like one. You can use Wine to select DOS and Windows applications in Red Hat Linux, as shown in Figure 27.2. Wine is a program that enables you to use Microsoft Windows and DOS programs on a Linux system. The Wine program includes a program loader to execute a Windows binary, along with a .dll library that can implement Windows commands using the equivalent UNIX and X command calls. The Wine .dll fool win32 binaries into thinking that they are running on a Microsoft operating system and translate win32 calls into something that can be handled by the Linux kernel.

> NOTE
W32.dlls are notoriously under-documented and have some interesting bugs—some of which are exploited for good use by adventurous Windows programmers, making Windows .dlls difficult to reproduce by reverse engineering.
