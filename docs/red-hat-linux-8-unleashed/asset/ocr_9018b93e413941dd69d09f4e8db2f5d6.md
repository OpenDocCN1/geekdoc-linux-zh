# OpenOffice.org Applications

OpenOffice.org Calc is a spreadsheet application that offers excellent Excel file computability and can work with files in Data Interchange Format and dBASE as well. There is also some limited compatibility with Excel macros, but macros will generally have to be rewritten.

OpenOffice.org Impress is a Microsoft PowerPoint clone that allows you to prepare presentation graphics. When it is opened, OpenOffice.orgimpress starts with a wizard that guides you through the creation of a new presentation, lets you use an existing template (although none are provided), or allows you to open an existing presentation.

OpenOffice.org Math is an editor that allows you to create complex mathematical formulas for inclusion in an OpenOffice.org document. It is of interest primarily to math and science writers, but it can be useful to others when the need arises to include a complex formula in text.
