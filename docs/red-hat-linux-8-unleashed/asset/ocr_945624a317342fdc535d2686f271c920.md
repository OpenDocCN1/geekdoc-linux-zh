# Configuring Nameservers with BIND

exhaustive reference, consult the BIND 9 ARM (Administrator Reference Manual); it is distributed with BIND, and Red Hat 7.3 installs it under /usr/share/doc/bind-9.2.1/arm/.

We start with a configuration file similar to this:

```
/named.conf

options {
    # This is where zone files are kept.
    directory "/var/named";
}

# Allow rndc running on localhost to send us commands.
controls {
    inet 127.0.0.1 {
        allow { 127.0.0.1; };
        keys { rndc };
    }\n}

# The same information as specified in rndc.conf
key rndc {
    algorithm hmac-md5;
    secret "MKKd2FiHMFe1JQX1/z4cfw==";
}

# Information about the root zone.
zone ". {
    type hint;
    file "root.hints";
}

# Lots of software depends on being able to resolve 127.0.0.1
zone "0.0.127.in-addr.arpa" {
    type master;
    file "rev/127.0.0.0";
}
```
