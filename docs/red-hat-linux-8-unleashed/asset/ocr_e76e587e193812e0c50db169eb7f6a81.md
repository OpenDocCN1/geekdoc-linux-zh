# CHAPTER 26 Multimedia Applications

Many arcade-style and action games are available for use with Red Linux. In addition, there are traditional card games like solitaire and traditional board games like chess. More sophisticated commercial games are also available for Linux, and Red Hat—with a little outside help—can be used to play these games as well.

Because of their popularity, we will examine the process of installing proprietary drivers for an NVIDIA graphics card and install the freely available demo of Unreal Tournament 2003 from Epic Games.

# Installing NVIDIA Video Drivers

Red Hat does not provide the official NVIDIA driver drivers because they're closed source. The use of these drivers is controversial in certain Linux communities because they aren't open source drivers. To the credit of those in Open Source community who might be opposed to them, it's still possible to install these drivers. The following steps assume that you have an NVIDIA card and have already configured it to run XFree86.

You should first obtain the drivers from the NVIDIA Web site at http://www.nvidia.com/view.asp?70=linux_archive. At this writing, the most current drivers available are version 1.0-3123. You should carefully read the installation instructions. The drivers come in two parts: the GLX code and the kernel driver. I chose to download the RPMs for each and reclaim them on my Red Hat 8.0 system. You'll also find precompiled Binary RPMs that work just as well, but there's no challenge in that.

After it was downloaded, each RPM was recompiled with the following command. (Disregard the RPM commands given in the NVIDIA instructions because they apply to earlier versions of RPM than are provided by Red Hat; the new RPM command separates the building of RPM out of rpm and now places them in rpmbuild).

```
# rpmbuild -recompile NVIDIA_kernel-1.0-3123.src.rpm
# rpmbuild -recompile NVIDIA_GLX-1.0-3123.src.rpm
```

After the command is completed, the new RPM files will be found in
/usr/src/redhat/rpms/i386. You may install them at the same time with the command:

+   - rpm -ivh NVIDIA_kernel-1.0-3123.src.rpm
- rpm -ivh NVIDIA_GLX-1.0-3123.src.rpm

You should stop the X server (use #init 3 to change to level 3), and edit the
/etc/X11/XFree86Config (make a backup copy of the existing configuration first) to comment out the following lines, if they exist:

```
Load dri
Load GLCore
```
