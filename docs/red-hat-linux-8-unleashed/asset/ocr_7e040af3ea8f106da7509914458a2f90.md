> TIP
Wine, by default, emulates a Windows 98 system. If you want it to emulate a Windows 3.1, 95, or NT system, if a particular Windows application requires a specific system, add a section like at the end of the configuration file:
[Version]
"Windows" = "winNT"

Remember to always make a backup of the default configuration file before making any changes.

# Launching Win32 Applications

Launching a Windows application in Wine would be easy except for two things that give people trouble: paths and spaces in names.

If the Wine script found in /etc/init.d is at boot by default, Win32 binaries are associated with Wine in the kernel. Unless binaries are located in C:\Windows, you need to be in their directory to run them from the command line (or add them to your PATH if you run them frequently). Otherwise, you must provide the full path to the binary. The TAB completion of the BASH shell makes this easier and handles spaces in pathnames as well.

After you have installed and configured Wine, use it to run Windows applications like this:

```
$ wine "C:\Program Files\Internet Explorer\IEXPLORE.EXE"
```

Be careful to use the quotes, spaces, and capitalization in the full pathname, exactly as shown here.

You can also create a MIME-type association for .exe or .EXE files in KDE and GNOME and associate those files with the Wine binary. Then just click on them from Konqueror or Nautilus to launch them.
