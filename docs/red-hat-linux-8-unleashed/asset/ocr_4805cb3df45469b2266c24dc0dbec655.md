# Putting Samba to Work

Samba uses the Session Message Block (SMB) protocol to allow the Windows operating system (or any operating system) to access Linux files. Using Samba, you can make your Red Hat Linux machine just like a Windows computer to other Windows computers on your network. You do not need to install Windows on your PC.

Samba is a very complex program—so much that the book Samba Unleashed (Sams Publishing, 2000, ISBN 0-672-31862-8) is more than 1,200 pages long. The Samba man (when converted to text) for the configuration file is 330KB and 7013 lines long. Although Samba is complex, setting it up and using it doesn't have to be difficult. There are many options, and that can account for Samba's complexity. Depending on what you want, Samba's use can be as easy or difficult as you would like it to be.

Fortunately, Red Hat includes the Samba Web Administration Tool, or SWAT, which can be used to configure Samba using the Mozilla browser. SWAT provides an easy way to start and stop the Samba server, set up printing services, define remote access permissions, and share Samba usernames, shared directories. This section delves into the basics of configuring Samba, and you should first read how to manually configure Samba to get an understanding of how the software works. At the end of this section, you'll see how to start, and use SWAT to set up simple file sharing.

Like most of the software that comes with Red Hat Linux, Samba is licensed under the GPL and is free. It comes as both an RPM and as source code. In both cases, installation is very straightforward, and the software can be installed when you install Red Hat or using RPM software packages. The Samba RPMs should be on your second Red Hat install disk, or the latest version can be downloaded from the Internet, preferably from Red Hat (at ftp.redhat.com) or an authorized mirror site. See Chapter 8 for more information on using RPM packages.

Installing from source code can be a bit more time-consuming. If you don't want to install using Red Hat's default locations, however, installing from the source code is a configurable method. Download the source from http://www.samba.org and unpack the files. Change into the source directory and run, root the command `/config along with any changes from the defaults and then run make, make test (if you want), followed by make install install Samba in the specified locations.

If you install Samba using your Red Hat Linux CD-ROMs, you can find a large amount of documentation in the directory tree starting at /usr/share/doc/samba-2.2.5/ in several formats including PDF, HTML, and text among others. Altogether, almost 3MB of documentation is included with the source code.

Once Samba is installed, you can either create the file /etc/samba.conf or use the .samba.conf file supplied with Samba, which is located by default under the /etc/samba directory with Red Hat Linux. Nearly a dozen sample configuration files can be found under the /usr/share/doc/samba-2.2.5/examples directory.
