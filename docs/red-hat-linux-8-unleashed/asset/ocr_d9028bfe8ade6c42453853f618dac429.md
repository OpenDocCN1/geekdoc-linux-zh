# Using the redhat-config-date Client

Red Hat provides a graphical tool named redhat-config-date that can be used to set your system date and time. Start the client by clicking the desktop menu's System Settings Date and Time item, or from the command line of X11 terminal window like this:
$ redhat-config-date &

After you press Enter, you'll be asked to enter the root password. Type in your root password and click the OK button. You'll see a window, as seen in Figure 4.10:

![](bbox=[0.158, 0.381, 0.786, 0.633])

FIGURE 4.10 Use Red Hat's redhat-config-date client to set your Linux date and time.

Set the date and time by using the calendar and time fields. You can also have your workstation obtain updated date and time information via the network by entering a remote time server hostname in the Network Time Protocol field. This will require that the ntpd daemon be properly configured and running.

> NOTE
HTML documentation for using the ntpd daemon is in /usr/share/doc/ntp-4.1.1a/ntpd.htm (if ntpd is installed on your system).
