# CHAPTER 27 Using Emulators and Cross-Platform Tools in Red Hat Linux

To run more than one operating system at the same time, simply start additional versions
VMware like this:

$ vmware &

After you click the Power On button, your operating system will boot, and you can run a
session in a VMware as shown in Figure 26.8. You can then launch another VMware
session in the same manner.

> TIP You can also create a dual-boot operating system configuration and installation, and then use a
of virtual systems. That solution works well if your computer does not have enough
memory to host multiple VMware sessions, but does have enough disk space for an adequate
virtual filesystems. You can't install VMware in a VMware virtual machine—however tempting the
might be.

# Microsoft Windows on Win4Lin

Win4Lin is a commercial application that uses a licensed version of Windows 95, 98, 98SE,
or to install and run Windows from within Linux. The parent company, Traverse,
provides a GUI installer that validates your license and downloads and installs the applic-
ation, along with a patched version of the supported kernel. It also manages the installation
of the Windows .cab files from the Windows CD.
