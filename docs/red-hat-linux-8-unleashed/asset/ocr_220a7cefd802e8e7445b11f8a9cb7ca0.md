# Getting the Most from Red Hat and Linux Documentation

Every commercial Linux distribution includes manuals and documentation covering installation and configuration. You'll find documentation from Red Hat, Inc. included on one of the CD-ROMs included with this book. You can also get copies of the Red Hat manuals online through http://www.redhat.com/docs/. There you'll find Red Hat's official manuals and guides:

+   - Red Hat Linux manuals—Information to help you install, and customize Red Hat Linux
- Red Hat Network manuals—Information to help with registration and upgrade processes when you purchase an official copy of Red Hat Linux
- Red Hat server, database, source code control system, and embedded development guides—Important to software developers or when creating software for Red Hat Linux
- Other official Red Hat documentation—A dozen other manuals with support information about Red Hat's various software products

These guides are available in Portable Document Format (PDF) and can be read using Adobe's Acrobat Reader for Linux or the xpdf client. The guides are also available as bundled HTML files for reading with a Web browser such as lynx, links, KDE's conquer, GNOME's galleon, or Mozilla. With these guides, Red Hat, Inc. provides various tips, Frequently Asked Questions (FAQs), and HOWTO documents.

For information regarding software management using the Red Hat Package Manager (RPM), you can also download a free copy of Ed Bailey's classic "Maximum RPM." Developers interested in writing or programming programs to Linux can also get a copy of "Linux Application Development" by Michael K. Johnson and Erik W. Trojan.

# Red Hat Technical Updates and Lists

After you install Red Hat, you'll want to check for upgrades, security updates, bug fixes, or new software enhancements. Browse to http://www.redhat.com/support/resources/howto/rh180.html for links to important information, as as

+   - Red Hat errata—A complete list of updated software for Red Hat
- Red Hat security advisories—List of Red Hat Linux security fixes and links to updated software
- Red Hat bug fixes—Descriptions of fixes and links to corrected software packages for installation
- Red Hat enhanced packages—Information about and links to downloads of improved software packages
