# DVD and Video Players

You can easily play digital video discs (DVDs) using Red Hat Linux as long as you install the appropriate software in light of the fact that Red Hat doesn't provide any.
Browse to http://www.videolan.org, and then download, build, and install the vlc client.

You'll need a CPU of at least 450MHz and working sound card to use a DVD player.
The default Red Hat Linux kernel supports the DVD CD-ROM filesystem. As mentioned earlier,
Xine and mPlayer do a great job of playing DVD files.

# Using Still Cameras with Red Hat Linux

Most still cameras used in connection with Red Hat Linux fall into one of two categories:
Web cams (small, low-resolution cameras connected to the computer's interface) handheld digital cameras that record image data on disks or memory cards for downloading and viewing on a PC. Red Hat Linux supports both types. Other types of cameras, such as
surveillance cameras that connect directly to a network via or wireless connections,
eed no special software (other than a network connection and viewing software) to be
used with a Linux computer.

Red Hat Linux supports hundreds of different cameras, from early parallel-port
(CPIA chipset-based) cameras to today's newer USB-based cameras. You can use Intel's
QX3 USB microscope with Red Hat. If you prefer a standalone network-based Web cam,
explore the capabilities of Linux-based cameras from Axis (at http://www.axis.com/
products/camera_servers/productguide.html). The following sections describe some
the more commonly used still camera hardware and software supported by Red Hat.

# Web Cams

Web cams are typically small, low-resolution cameras connected to your computer via a
parallel port or USB port. The camera can act in two modes: streaming (for a series
of a moving object) and grabbing (for a single image). The most common uses
for Web cams include video conferencing and Web voyeur. The latter isn't as lucid as it
might, although some Web cam sites are notorious for their pornographic content.
Web cams can be used to send almost-live images to an online correspondent; many people
include screen grabs of themselves at their computer workstations because they can.

One of the more interesting uses of a Web cam was the legendary "internet coffee pot"
(started in 1991, on August 22, 2001—a day that will live in infancy). A Web cam
was trained on a coffee maker and the sysadmin could see whether fresh coffee was available
without leaving his cubicle. Web cams take grabs of intersections in various cities. You'll
find some similar worthwhile for your Web cam.
