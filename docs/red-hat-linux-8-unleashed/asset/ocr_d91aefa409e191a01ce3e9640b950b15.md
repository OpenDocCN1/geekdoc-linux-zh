NOTE
browse to http://www.faqs.org/rfcs/rfc1179.html to read more about using the Strict RFC1179 Compliance option when configuring Red Hat to be able to print to a remote UNIX printer. This 12-year-old Request For Comments (RFC) document describes protocols for the BSD line printing system. The option is used to allow your documents to print to remote servers using the older printer system or software conforming to the standard.

Click the Forward button after entering this information; then continue to configure the new entry as if the remote printer were attached locally (use the same printer driver setting as the remote printer). When finished, don't forget to save the changes and restart the lpd daemon. The new remote printer entry /etc/printcap may look something like this:

```
hp648:
:ml#=\n:mx#=\n:sd=/var/pool/lpd/hp648:\n:af=/var/pool/lpd/hp648/hp648.acct=\n:sh=\n:rm=192.168.2.35:\n:rp=lp1:
  :lpd_bounce=true:
:if=/user/share/printconf/util/mf_wrapper:
```

In this example, the :rm entry defines the remote host (an IP address is used), whereas :rp entry defines the remote queue (1 lp in this example). As before, test the new remote printer by clicking the Tests menu item and using the ASCII or PostScript test pages. The
