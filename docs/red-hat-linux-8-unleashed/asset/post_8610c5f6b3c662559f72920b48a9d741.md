
Microsoft formats are the most commonly used in business settings, so compatibility with those formats is a primary concern of most businesses that are choosing office suites. OpenOffice contains applications that are largely compatible with Microsoft file formats, but they don't offer 100% compatibility. That level of compatibility is impossible for GNU Public Licence (GPL) applications because the file formats are proprietary, and import/export filters must be reverse-engineered. There may be some esoteric formatting that does not import or export well—you can only judge with a personal test on your own files—but all basics works well.

Many Red Hat Linux users prefer OpenOffice.org, because its interface is similar to that of the Microsoft applications they've used in the past. This is an important point if you are attempting to move from Microsoft Office in your home or office. OpenOffice.org recognizes and offers nearly 120 different file formats and types of documents, ranging from popular commercial office suites to various graphics file formats. The suite is able to export nearly 70 types of documents.

## What's in OpenOffice.org?

OpenOffice.org contains a number of productivity applications for use in creating text documents, preparing spreadsheets, organizing presentations, managing projects, and more. The following components of the OpenOffice.org package are included with Red Hat Linux:

- OpenWriter—This word-processing program enables you to compose, format, and organize text documents and it has excellent compatibility with the Microsoft Word file format.
- OpenCal—This spreadsheet program enables you to manipulate numbers in a spreadsheet format. Support for all but the most esoteric Microsoft Excel functions means that spreadsheets with Excel users should be successful.
- Impress—This presentation program is similar to Microsoft PowerPoint and enables you to create slide presentations that include graphs, diagrams, and other graphics. It works well with PowerPoint.
- Math—This math formula editor enables you to write mathematical formulas with a number of fonts and symbols for inclusion in a word processing document. Such symbols are highly specialized and not easily included in the basic functionality of a word processor.
- ODBC (Open Database Connectivity)—You must configure the provided database front end to use MySQL or PostgreSQL. After you do, it functions as a database organizer for Microsoft Access. (See Chapter 17, “Administering Database Services in Red Hat Linux,” for more information for MySQL and SQL)
- OpenDraw—This graphics application allows you to create images for inclusion in the documents produced with OpenOffice.org. It saves files only in OpenOffice format, and it can import common image formats.

## A Brief History of OpenOffice.org

OpenOffice.org suite has its roots in an application known as StarOffice. Originally developed by a German company, StarOffice was purchased by Sun Microsystems in the United States. One of the biggest complaints about the old StarOffice was that all the component applications were integrated under a StarOffice “desktop” that looked very like a Windows desktop, including a Start button and menus. This meant that in order to edit a simple document, unwanted applications had to be loaded, making the office suite slow to load, run, and manage system resources.

After the purchase of StarOffice, Sun Microsystems released a large part of the StarOffice code under the GPL, and development began on what became OpenOffice.org, which is freely available under the GPL. Sun continued development on StarOffice and released a commercial version of StarOffice 6.0. The significant differences between the free and commercial versions of the software are that StarOffice provides more filters and import/export filters than OpenOffice.org (these filters are not) and StarOffice provides its own relational database, Software AG’s Adabas D database. (If you are seeking a free alternative to the StarOffice odabase, see Chapter 17).

## Installing and Configuring OpenOffice.org

Red Linux provides an RPM package for OpenOffice.org. If you don't install the RPM package during your initial Red Linux installation, you can install it later, using the Packages tool or by using # rpm -ivh from the command line.

OpenOffice.org is constantly improving its productivity applications. You can check the OpenOffice.org site (http://www.openoffice.org) for the latest version. The Web site provides a link to download the source or a precompiled version of the most current installation files. A more current version may offer file format support that you need.

The Red Hat installation of OpenOffice.org is done on a systemwide basis, but no individual users are configured. All an individual user needs to install or his local files and use OpenOffice.org is click any OpenOffice.org icon on or his desktop, and the individual user’s files are installed. This takes some time, and unfortunately does not display a dialog about what is going in the background, so some users might assume that the application has not started. But that is not the case.

## OpenOffice.org Applications

OpenOffice.org Calc is a spreadsheet application that offers excellent Excel file computability and can work with files in Data Interchange Format and dBASE as well. There is also some limited compatibility with Excel macros, but macros will generally have to be rewritten.

OpenOffice.org Impress is a Microsoft PowerPoint clone that allows you to prepare presentation graphics. When it is opened, OpenOffice.org starts with a wizard that guides you through the creation of a new presentation, lets you use an existing template (although none are provided), or allows you to open an existing presentation.

OpenOffice.org Math is an editor that allows you to create complex mathematical formulas for inclusion in an OpenOffice.org document. It is of interest primarily to math and science writers, but it can be useful to others when the need arises to include a complex formula in text.
