# First Steps with Linux

Red Hat Linux offers a wonderful graphical interface for the desktop (see Chapter 6, “The Window System”), along with many capable graphical administration tools, but you can't manage or use Linux effectively if you don't know how to use text-based programs at the command line. In some situations, the command line offers the only means of interacting with a running system.

In this chapter, you learn the basics of how to use Red Hat Linux and how to accomplish many routine tasks at the command line. These basic operations include how to read files or other Red Hat documentation, list directories, move, copy, and rename files. New Red Hat system administrators will get an introduction to using the command line to create new users, manage file permissions, and to properly reboot or shut down Red Hat system.

Some of the basic command-line skills covered in, in this chapter include

+   - Performing routine tasks—Logging in and using the text console, changing passwords, listing and navigating directories.
- Basic file management—Creating, renaming, and deleting files and directories.
- Basic user management—Creating or deleting users from the command line.
- Basic system management—Shutting down or rebooting, reading manual pages or other documentation, and using text-based tools to edit system configuration files.

Read this chapter if you're migrating to Linux from another platform; or the information here is valuable for individual users or system administrators who are new to Linux and learning to use the command line for the first time.
