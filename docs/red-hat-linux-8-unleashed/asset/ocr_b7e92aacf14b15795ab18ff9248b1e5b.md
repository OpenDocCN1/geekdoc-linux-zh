
Next, start an X session, or if you are running X, select the desktop panel
and click the Samba Configuration menu item from the Server Settings menu.
Mozilla Web browser will launch, and you'll be presented with a login prompt to SWAT.
That Apache does not need to be running on your system. Enter the root username
and password, and then click the OK button. The screen will clear, and you'll see the main
SWAT page, as shown in Figure 13.5.

> TIP

You can also access SWAT by starting the Mozilla browser and then use a uniform resource
locator (URL) of http://localhost:901.
