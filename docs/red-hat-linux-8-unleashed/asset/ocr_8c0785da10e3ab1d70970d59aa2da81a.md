When you think about putting lines of code together
Linux, why not? Red Hat Linux includes Perl, Python, the Tool
Control Language (Tcl), and the bash, tsh, and zsh
shell, all of which support a wide range of commands that
can be combined, in the form of scripts, into reusable
programs. Command scripts for shell programs (and utilities)
need in order to customize your computing environments.
(You can learn more about scripting in Chapter 22, "Shell
Scripting," and Chapter 23, "Using Perl.")

Many programs that process scripts (such as the various
shells, the gawk command, and the Perl interpreter) are
written in the C and C++ languages.

Learning how to use a computer language such as C or
C++ can be more complex and difficult than learning shell
scripting. You must learn to think in terms of machine
resources and the way actions are accomplished within the
computer, taking into account the operating system, language
syntax, and asserted development tools, rather than in
terms of user-oriented commands. Linux and nearly all
related software is open source. So if a program doesn't work
the way you want it to, you can change it! You can also find
lot of "hidden" documentation in programmer comments
inside the story to nearly all Linux programs.

Red Hat Linux comes with an incredibly diverse toolbox
program development software. There are C and C++ compil-
ers, debuggers (used during the development process to find
diagnose errors), project organizing clients, graphical
protyping environments, and code management software.
