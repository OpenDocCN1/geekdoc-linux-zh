# Using the BIOS and Kernel to the Disk Drives

One method of tuning involves adjusting the settings in your BIOS. Because the BIOS is not Red Hat Linux and every BIOS seems different, read your motherboard manual for better possible settings and make sure that all the drives are detected correctly by the BIOS. Change only one at a time.

Linux provides a limited means to interact with BIOS settings during the boot process (mostly overriding them). In this section, you will learn about those commands.

Linux uses both hd.c and ide.c as IDE driver code. One or both can be compiled into the kernel; ide likely be a module. The hd.c code is used for compatibility with older IDE controllers and is used by default on ide0. If you have more hardware, the use of the new code using the LILO command line parameter ide=0x1f0. This can be entered at the initial LILO prompt, added by editing the GRUB boot menu, or placed in the append=line of /etc/lilo.conf or at the end of the kernel line in /boot/grub.conf. The use of this option might or might not have benefit to you.

Other options are in the following list, and are more fully outlined in the BOOTPROM HOWTO and the kernel documentation. These commands can be used to force the IDE controllers and drives to be optimally configured. Of course, YMMV (Your Mileage Vary) because these don't work for everyone.

ide=dna—This will DMA support to be turned on for the primary IDE bus, where x=0, or the secondary bus, x=1.

ide=autune—This command will attempt to tune the interface for optimal performance.

ide=ata66—If you have ATA66 drives and controllers, this command will enable support for it. hdx=scsi—This command will enable SCSI emulation of an IDE drive. This is required for CD-RW drives to work properly, and it might provide some performance improvements for CD-R drives as well.

idebus=xx—This can be any number from 20 to 66, autodetection is attempted, but this can set it manually if dmesg says it is not autodetected correctly or if you set it in the BIOS to a different value (overclocked). Most PCI controllers will be happy with 33.

pci=biosirq—Some motherboards might cause Linux to generate an error message saying that you should use this. Look in dmesg for if you don't need to use it.

These options can be entered in the same way as the ide0=0x1f0 tweak described previously.
