# Distribution Version and Kernel Number Schema

There is a specific numbering system for Linux kernels, kernel development, and Red Hat's kernels. Note that these numbers bear no relation to the version number of Red Hat's distribution. If this were true, by using Red Hat Linux 2.4 instead of 8.0. Red Hat distribution numbers are assigned by Red Hat, Inc., whereas most of the Linux version numbers are assigned by Linux Torvalds and his legion of kernel developers.

To date your Linux kernel compiled, use the uname command with -v option. To see the version of your Linux kernel, use the -r option. The numbers, such as 2.4.18-13, represent the major version (2), minor version (4), and patch level (18). The final number, (13), is the developer patch level and is assigned by Red Hat.

Even minor numbers are considered “stable” and generally fit for production environments, while old minor numbers (such as the current Linux 2.5 source tree) represent versions of the Linux kernel under development and testing. You will only find stable versions of the Linux kernel included with this book (and, of course, in Official Red Hat Linux).

# More Flexible Installation Process

The latest version of Red Hat Linux provides an installation process that offers several classes of installation:

+   Custom–This option is useful to install your own selection of software packages, which can be useful to trim unwanted software from your new Red Hat system.

+   Upgrade–Use this option to upgrade an existing Red Hat system with a new desktop and updated software packages.

+   Server–Select this option to create a Web, File Transfer Protocol (FTP), Network File System (NFS), or other server.

+   Personal Desktop–Choose this to get the benefits of the new Red Hat desktop and to create an Internet or multimedia workstation.

+   Workstation–Choose this to create a development system.

+   Laptop–Choose this notebook install to have laptop-related software installed.

Red Hat’s installation process also allows you to install Linux in a variety of ways, using a text-based or graphical interface. See Chapter 3, “Installing Red Hat Linux,” to see how to install using CD-ROM, a hard drive, or a network.
