# Interpreting Shell Scripts Through Specific Shells

The majority of shell scripts use a bang line (#1) at the beginning to control the type of shell used to run the script; this bang line calls for an sh-incantation of bash:

```
#!/bin/sh
```

A bang line tells the Linux kernel that a specific command (a shell, or in the case of other scripts, perhaps awk or Perl) is used to interpret the contents of the file. Using a bang line is common practice for all shell scripting. For example, if you write a shell script using bash, but want the script to execute as run by the Bourne shell, the first line of your script will contain #!/bin/sh, which is a link to the bash shell. Running bash as sh will cause bash to act as a Bourne shell. This is the reason for the symbolic link sh, which points to bash.

> NOTE
The bang line (#1) is also colloquially known as a hash-bang or she-bang. The bang line is also a magic number, defined in /usr/share/magic—a text database of magic numbers for the Linux file command. Magic numbers are used by many different Linux commands to quickly identify a type of file, and the database format is documented in the section five manual page named magic (read by man 5 magic). For example, magic numbers can be used by the Linux file command to display the identity of a script (no matter what filename is used) as a shell script or other interpreter such as awk or Perl.
