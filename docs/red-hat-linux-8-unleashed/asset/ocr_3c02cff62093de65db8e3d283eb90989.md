Which modes?

You enter one or more numbers to select the modes (which is useful if you want to try switching resolutions while using the Red Hat desktop), and then you press Enter. You are then asked about virtual resolution:

You can have a virtual screen (desktop), which is screen area that is larger than the physical screen and which is panned by moving the mouse to the edge of the screen. If you don't virtual desktop at a certain resolution, you cannot have modes listed that are larger. Each color depth can have a differently-sized virtual screen
