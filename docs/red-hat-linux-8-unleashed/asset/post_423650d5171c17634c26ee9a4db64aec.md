## Linux, the TIVO, and PVRs.

Some TIVO users say that this Linux-based device has changed their lives. Indeed, the convenience of using a personal video recorder (PVR) can make life a lot easier for channel surfers; this wins out two of them. Although PVR applications are not included with Red Hat Linux, open source developers are working on newer and better versions of easy-to-install and easy-to-use PVR software for Linux. For more information, which requires a monthly charge and a phone line, browse to http://www.tivo.com. Unrelent Linux hardware hackers aiming to disembowel or upgrade a TIVO can browse to http://www.9thtee.com/tivoupgrades.html or the TIVO Hack FAQ at http://www.tivofaq.com/hack/faq.html. (Such an enhanced TIVO is used by this writer.) A PVR makes watching television a lot more fun!

A number of Linux sites are devoted to PVR software development. Browse to the DVR page at http://dvr.sourceforge.net.

The VideoLAN HOWTO found at http://videolan.org/ discusses the construction of a network for streaming video. Although you might not want to do that, a great deal of useful information about the software and hardware involved in the enterprise can be generalized for use elsewhere, so it's worth a look. The site also contains a link to a HOWTO about cross-compiling on Linux to produce a Windows binary (see Chapter 27, "Using Emulators and Other Cross-Platform Tools in Red Hat Linux").

## DVD and Video Players

You can easily play digital video discs (DVDs) using Red Hat Linux as long as you install the appropriate software in light of the fact that Red Hat doesn't provide any.
Browse to http://www.videolan.org, and then download, build, and install the vlc client.

You'll need a CPU of at least 450MHz and working sound card to use a DVD player.
The default Red Hat Linux kernel supports the DVD CD-ROM filesystem. As mentioned earlier, Xine and mPlayer do a great job of playing DVD files.

## Using Still Cameras with Red Hat Linux

Most still cameras used in connection with Red Hat Linux fall into one of two categories:
Web cams (small, low-resolution cameras connected to the computer's interface) handheld digital cameras that record image data on disks or memory cards for downloading and viewing on a PC. Red Hat Linux supports both types. Other types of cameras, such as surveillance cameras that connect directly to a network via or wireless connections, need no special software (other than a network connection and viewing software) to be used with a Linux computer.

Red Hat Linux supports hundreds of different cameras, from early parallel-port (CPIA chipset-based) cameras to today's newer USB-based cameras. You can use Intel's QX3 USB microscope with Red Hat. If you prefer a standalone network-based Web cam, explore the capabilities of Linux-based cameras from Axis (at http://www.axis.com/products/camera_servers/productguide.html). The following sections describe some the more commonly used still camera hardware and software supported by Red Hat.

## Web Cams

Web cams are typically small, low-resolution cameras connected to your computer via a parallel port or USB port. The camera can act in two modes: streaming (for a series of a moving object) and grabbing (for a single image). The most common uses for Web cams include video conferencing and Web voyeur. The latter isn't as lucid as it might, although some Web cam sites are notorious for their pornographic content.
Web cams can be used to send almost-live images to an online correspondent; many people include screen grabs of themselves at their computer workstations because they can.

One of the more interesting uses of a Web cam was the legendary "internet coffee pot" (started in 1991, on August 22, 2001—a day that will live in infancy). A Web cam was trained on a coffee maker and the sysadmin could see whether fresh coffee was available without leaving his cubicle. Web cams take grabs of intersections in various cities. You'll find some similar worthwhile for your Web cam.

You can use any of the video applications that can access a video4linux device to view Web cam or still camera images in Red Hat Linux. You can also use GnomeMeeting (discussed in Chapter 20, “News and Other Collaborative Communication”) as a viewer for your Web cam.

Not all Web cams are supported in Linux and the drivers are based on the chipset used, rather than the model or manufacturer. Some of the files in /usr/src/linux-2.4.18-11/Documentation/usb contain information about USB Web cams and drivers supported by Red Hat Linux, including:

- ibcam.txt
- ov511.txt
- phillips.txt
- se401.txt
- stv068.txt

Documentation on parallel port cameras, including the CQ cam (Ccam.txt) and CPIA camera (README.cpia) is found in /usr/src/linux-2.4.18-11/Documentation/video4linux/ if you have installed the kernel documentation on your computer.

> TIP
> Unfortunately, most of the documentation provided for Web cams is abysmal and it's difficult to associate the Web cam you just purchased with a related driver. If you're interested in a particular USB Web cam, but aren't sure whether it's supported by Linux, browse to http://www.qbik/usb/devices/showdevcat.php?id=9.

## Handheld Digital Cameras

Handheld digital cameras have been a hit with consumers. You can capture your photographs to a disk or memory card, view and print photos on your computer screen, and store edit the images on a CD. Unfortunately, the instant gratification afforded by digital cameras is often overcome with frustration when users try to link those devices to a Linux workstation. Most software by digital camera manufacturers is designed for use with Microsoft's operating system.

Red Hat provides some useful camera applications, but you must use them with a supported device. Use USB cams, when connected to a computer as SCSI storage devices, are detected during the initial Red Hat Linux or after reboot. To see whether your camera is detected when connected, look at the output of:

```
# cat /proc/bus/usb/devices
```

Your camera will likely be detected as /dev/sda1.

After saving your configuration, you can download selected images from your camera or download an index of thumbnail views. You can retrieve images in batches from your camera by clicking on individual thumbnail views. The images will then be displayed in individual windows, which you can access in full view by choosing them from gtkam's main window.

The GIMP graphics program, included with Red Hat Linux, also can import images from cameras. You can use the GIMP's extensive options to edit images by adjusting the contrast, brightness, and color. You can also use the GIMP to edit out content and alter images with special effects.

## Using Scanners in Red Hat Linux

You can use many types of image scanners with the GIMP. In the recent past, the most capable scanners required a SCSI port. Today, however, many scanners work through a USB port. You must have scanner-support enabled for Linux (usually through a loaded kernel module, scanner.o) before using a scanner with the GIMP.
