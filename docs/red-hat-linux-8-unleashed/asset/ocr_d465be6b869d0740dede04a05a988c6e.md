If you do not use Red Hat’s automatic hardware detection and configuration, you can initialize network hardware by

+   - Manually editing the /etc/modules.conf file to prompt the system to recognize and support the new hardware upon reboot
- Manually load or unload the new device’s kernel module with the modprobe command

The following sections explain both processes.

# Editing /etc/modules.conf File

You can manually edit the /etc/modules.conf file to add a module dependency entry (also known as a directive) to support a new NIC or other network device. This entry includes the device’s name and its corresponding kernel module. After you do, the Linux kernel recognizes your networking hardware upon reboot. Red Hat runs a module dependency check upon booting.

For example, if your system uses a RealTek NIC, you could use an entry like:

alias eth0 8139t00

The example tells the Linux kernel to load the 8139t00.o kernel module to the eth0 network device. On the other hand, if you have an Intel Ethernet Pro NIC installed, you would use an entry like this:

alias eth0 eepro100

Other parameters can be passed to a kernel module using one or more option entries, if you need, to properly configure your NIC. The modules.conf manual page for information on using entries. For more specifics regarding NIC kernel modules, examine the module’s source code because no manual pages exist (a good opportunity for anyone willing to write the documentation).

> TIP
Red Hat includes Don Becker’s Intel Ethernet Pro NIC utility, named eepro100-diag under the /usr/bin directory. You can use this utility to get more information about your NIC. No manual page is included with Red Hat, but you can browse to http://www.scylid.com/diag/index.html for more information about this tool.
