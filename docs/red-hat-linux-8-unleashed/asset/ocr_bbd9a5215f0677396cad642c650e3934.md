# Red Hat Network Configuration Files

As previously stated, seven network configuration files can be modified to make changes to basic network interaction of your system. The files are

+   - /etc/hosts—Listing of addresses, hostnames, and aliases
- /etc/services—Network service and port connections
- /etc/nwitch.conf—Linux network information service configuration
- /etc/resol.conf—Domain Name Service domain (search) settings
- /etc/host.conf—Network information search order (by default, /etc/hosts and then DNS)
- /etc/HOSTNAME—the host; traditionally supported but not used by Red Hat Linux
- /etc/sysconfig/network—hostname, IP address, boot activation control, and gateway settings

As the first six of these files are modified, the changes are active. As with configuration files, comments can be added with a hash (#) preceding the comment. The last file (/etc/sysconfig/network) requires the networking daemons to be restarted after the file is used. All seven of these files have a man page written about them for information.

# Adding Hosts to /etc/hosts

The /etc/hosts file is a map of IP to hostnames. If you're not using DNS or another naming service, and you are connected to a large network, this file can get quite large and be a real headache to manage. A small /etc/hosts file can look something like this:

```
127.0.0.1       localhost.localdomain  localhost
128.112.50.69    myhost.mydomain.com    myhost
128.112.50.169   yourhost.mydomain.com  yourhost
```
