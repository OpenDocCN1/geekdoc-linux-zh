# Red Hat Linux® 8
UNLEASHED

Red Hat Linux 8 Unleashed offers comprehensive coverage of the latest version of the popular Linux distribution in the world—Red Hat Linux 8.0.

The book features beginner, intermediate, and advanced information on the all-new look and feel of Red Hat Linux 8. Inside you'll find the details on using Red Hat's easy-to-use desktop and productivity software, including a free, open-source office suite with word processing, spreadsheets, and graphics.

Also included detailed coverage of advanced topics such as the X Window System, Linux programming, Web server administration, system administration, and network administration.
