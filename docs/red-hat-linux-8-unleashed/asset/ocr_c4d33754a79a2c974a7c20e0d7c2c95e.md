> TIP

You can check the directory /usr/src/linux-2.4.18-11/ for documentation for each sound module. By be aware, however, that the documentation is likely to be out of date. Although even out-of-date documentation can be useful, you should research any new sound card you might purchase to ascertain its level of support in Linux. Use http://www.google.com/linux to search Linux Web sites and Linux newsgroups for mention of any sound card you are using.

Red Hat Linux detects sound cards during the original installation. If you add or replace a soundcard after the initial install, Red Hat’s “new hardware configuration” utility will automatically detect and configure it at the next reboot. To configure the sound card at any other time, use the sndconfig tool from the command line, or the redhat-config graphical tool provided by Red Hat Linux. The graphical tool can be found under the System Settings as the Sound Card Detection menu item. For additional details about configuring your sound card, refer to Chapter 4.

# Recording Sound

Red Hat Linux provides a number of tools that enable you to control volume, mix, and other sound recording functions. The Kmix sound mixer ax acts as a virtual mixing board, taking sound inputs from different sources, enabling you to adjust their individual volumes, mute them, and listen to them through your sound card.

If you need to control sound from the command line, use the amix command, which can be used to adjust balance or volume using command-line options. Your main sound channel’s volume can be controlled using one option, -v, followed by a number between 0 (mute) and 100 (make your roommate/neighbor scream). For example, to set your volume at 50 percent, use amix like so:

```
$ amix -v 50
```

The Sound Recorder is provided to enable you to play and record .wav files. You can use the SoX utility (covered in this chapter) to convert the recorded sound if necessary.

The Volume Control utility is similar in function to Kmix; open them both and observe how they interact. Each provides control in slightly different way, giving you a choice of controls.
