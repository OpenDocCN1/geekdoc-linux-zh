When you compile applications from source, they won't show up in the RPM database and-
fore-can't be managed by RPM.

You can provide RPM management for these applications by using a program named
CheckInstall. At its simplest, CheckInstall is a drop-in substitute for the make install step
building from source code.

For example, when compiling from source code, you would traditionally use

```
# /configure
# make
# make install
```

UsingCheckInstall, the steps would look like this:

```
# /configure
# make
# checkinstall
```

CheckInstall will create a binary .rpm package and install the application from it. This makes the
application part of the RPM database. The new .rpm file is left for you in
/usr/src/redhat/RPMS/i386. The new application can be uninstalled with rpm -e.
Some applications arrive in the frame of a shell wrapper. Using the shell script as the argu-
toCheckInstall will provide a .rpm file of the installed files and add them to your RPM data-
base. Not all applications will install with CheckInstall. Read its accompanying documentation
carefully.

CheckInstall can be downloaded from http://asic-linux.com/ex/-izto/checkinstall/
index.php.

# Graphical Package Management

The Hat Linux graphical package management tool, Package Management, is actually
an application named redhat-config-packages. This application replaces kpackage,
gnormp, and rpm, which are no longer provided. Package Management allows you to
select packages arranged in categories and install them or remove them. You cannot add
yown packages to the Red Hat graphical tool.

Launch the new Red Hat GUI by clicking the Start button on your desktop, and
then choose System Settings, Packages. The Package Management tool launches with the
Add or Remove Packages Package Management screen, shown in Figure 8.2.
