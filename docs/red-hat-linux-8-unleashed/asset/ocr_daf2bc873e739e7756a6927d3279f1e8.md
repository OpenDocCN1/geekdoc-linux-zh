When you have GnomeMeeting running, you must register with the server at http://ils.seconix.com/ to enable conferencing. GnomeMeeting is capable of working with Microsoft NetMeeting; you should ask NetMeeting users to register at http://ils.seconix.com/ so you can see them because NetMeeting can see only other NetMeeting users. You can find an informative FAQ at the GnomeMeeting home page at http://www.gnomemeeting.org/. An excellent article about VoIP is at http://freshmeat.net/articles/view/430.

> NOTE
If you use VoIP applications as GnomeMeeting, you'll tire of repetitively typing in long IP address to make connections. To avoid this hassle, you can use a “gatekeeper,” similar in purpose to a DNS server translate names into IP addresses. OpenH323 Gatekeeper is one such popular gatekeeper application. It is not provided with Red Hat 8.0, but you can obtain it from http://www.gnuk.org.
