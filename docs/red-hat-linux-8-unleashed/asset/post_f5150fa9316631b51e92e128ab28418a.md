## Installing the Apache Server

You can install Apache from RPMs or build yourself from source code. The Apache
source builds on just any Unix-like operating system and on Win32.

If you're about to install a new version of Apache, it's probably a good idea to shut down
the old server. Even if it's unlikely that the old server will interfere with the installation
procedure, shutting down ensures that there will be no problems. If you don't know how
to stop Apache, look at the "Starting and Stopping Apache" section later in this chapter.

## Installing from the RPM

You can find the Apache RPM either on the Red Hat installation media, on the Red
Hat FTP server, or one of its many mirror sites. You'll want to check the
updates.redhat.com FTP site (or one of the mirrors) as often as possible to download
updates as they become available. In the directory corresponding to your Red Hat version,
you'll occasionally find updates for Apache. The updated RPM files usually contain import-
tant updates that fix bugs or security breaches. When an updated version comes out,
install it as quickly as possible in order to be secure.

> NOTE
> Check Red Hat's errata page for bug and security fixes to Apache or stay current using Red's
email advisory list. Browse to http://www.redhat.com/apps/support/errata/index.html for
links to updates. Subscribe to a support list (such as linux-security) at http://www.redhat.com/
mailing-lists/

> If you want the most recent, experimental version of Apache for testing, check Red Hat Rawhide
distribution, which is also available on Red Hat's FTP server (ftp://ftp.redhat.com/pub/
redhat/rawhide/). This distribution is experimental and always contains the latest
versions of all RPMs. However note that the Apache package (httpd) might depend on new
functionality in other RPMs in the Rawhide distribution. Therefore, you might need to
install many new RPMs from Rawhide. If you want to use an
Apache version from the Rawhide distribution for testing, a better option might be to download
the source code (SRPM). That way, you will avoid dependencies on
other new packages. (Refer to the "Working with Source RPM Files" in Chapter 8,
"Managing Software and System Resources," for information about building and installing pack-ages from RPM files).

![](img/446debe023486a07fde575245cf7a3ff_540_0.png)

## CAUTION

You should be wary of installing experimental packages, and never on *production* servers (that is, servers used in “real life”). Very carefully test the packages beforehand on a host that isn't connected to a network!

After you have obtained an Apache RPM, you can install it with the command-line rpm tool by typing the following:

```
rpm -Uvh latest_apache.rpm
```

where *latest_apache.rpm* is the name of the latest Apache RPM. For more information on installing packages with RPM, refer to Chapter 8.

The Apache RPM installs files in the following directories:

- /etc/httpd/conf/—This directory contains the Apache configuration file, httpd.conf. See the section on configuring Apache later in this chapter for information.
- /etc/rc.d/—The tree under this directory contains the system startup scripts. The Apache RPM installs a startup script named httpd for the Web server. This script, which you can use to start and stop the server from the command line, automatically starts and stops the server when the computer is halted, started, or rebooted.
- /var/www—The RPM installs the default server icons, common gateway interface (CGI) programs, and HTML files in this location. If you want to keep Web content elsewhere, you can do so by making the appropriate changes in the server configuration.
- /var/html/manual/—If you've installed the apache-manual RPM.
- /usr/share/man/—If you've installed the apache-manual RPM.
- /sbin/—If you've installed the apache-manual RPM.
- /bin/—If you've installed the apache-manual RPM.
- /var/log/httpd/—If you've installed the apache-manual RPM.
- /var/run/—If you've installed the apache-manual RPM.
- /etc/httpd/—If you've installed the apache-manual RPM.
- /var/www/—If you've installed the apache-manual RPM.

## CAUTION

You should be wary of installing experimental packages, and never on *production* servers (that is, servers used in “real life”). Very carefully test the packages beforehand on a host that isn't connected to a network!

After you have obtained an Apache RPM, you can install it with the command-line rpm tool by typing the following:

```
rpm -Uvh latest_apache.rpm
```

where *latest_apache.rpm* is the name of the latest Apache RPM. For more information on installing packages with RPM, refer to Chapter 8.

The Apache RPM installs files in the following directories:

- /etc/httpd/conf/—This directory contains the Apache configuration file, httpd.conf. See the section on configuring Apache later in this chapter for information.
- /etc/rc.d/—The tree under this directory contains the system startup scripts. The Apache RPM installs a startup script named httpd for the Web server. This script, which you can use to start and stop the server from the command line, automatically starts and stops the server when the computer is halted, started, or rebooted.
- /var/www—The RPM installs the default server icons, common gateway interface (CGI) programs, and HTML files in this location. If you want to keep Web content elsewhere, you can do so by making the appropriate changes in the server configuration.
- /var/html/manual/—If you've installed the apache-manual RPM.
