Table 4.1 lists text-based and graphical commands you can use to manipulate or get information about your keyboard.

# TABLE 4.1 Red Hat Linux Keyboard-Related Commands

| dumpkeys | Displays keyboard translation tables |
| kbd_mode | Modifies current keyboard mode |
| kbdrate | Changes keypress delay, repeats |
| loadkeys | Loads new keyboard table |
| showkey | Prints keyboard, typeface, and other keystroke information |
| setled | Displays, changes keyboard light-emitting diode (LED) settings |
| xkbcomp | Shows, sets keyboard translations for X |
| xkbprint | Displays or saves X keyboard mappings |
| xset | Modifies keyboard settings for X |
| xmodmap | Changes key mappings for X |

The X11 keyboard clients can be used to input a keyboard description into a running X server, show current keyboard character translations, change a keyboard map, and set other keyboard (pointer) preferences. X11 settings are generally contained in a system's XF86Config-4 file (see Chapter 6, "The Window System" for more information).
