Choosing a window manager is a matter of preference, necessity, or policy. You may prefer to use one of the older window managers—such as the Tab Window Manager (twm) or the Motif Window Manager (mwm)—on legacy PCs because they have fewer system resource requirements (that is, they require less hard drive space, CPU horsepower, and system memory). Newer desktop environments require 64MB or even more memory for good performance. The following sections describe some of the most popular window managers and their uses.

# The Tab Window Manager (twm)

The Tab Window Manager (twm), which is included with XFree86 and also known as Tom's Window Manager, is a legacy client that provides modest but essential features in a small (less 1MB) memory footprint.It supports window decorations, menus, icons, and other features, but it does not support virtual desktops, session management, and other features, such as drag and drop.

The twm window manager is used as a fallback, or *failsafe*, window manager for Red Hat as it requires much less video and system memory. It is included with the XFree86 software distribution. The twm resource file, system.twrc, is located under `/etc/X11/twm` directory. You can configure this file to provide a default desktop with an application menu if you save custom settings to a file named `.twrc` in your home directory.
