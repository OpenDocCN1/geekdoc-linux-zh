# Compound Operators

Perl uses compound operators, similar to those used by C or awk, which can be used to combine other operations (such as comparisons or arithmetic) into more complex functions of logic. Table 23.3 shows the compound pattern operators and their behavior.

# TABLE 23.3 Compound Pattern Operators in Perl

| --- | --- |
