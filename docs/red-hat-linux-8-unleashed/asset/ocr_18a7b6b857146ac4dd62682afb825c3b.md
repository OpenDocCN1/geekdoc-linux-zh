You can also start the daemon using the services command like so:

```
# services ipd start
```

If you're using Red Hat's desktop, select the Printing menu item from the System Settings menu. You will be asked to enter the root password. If not, you're using X as root, which is a bad idea. Log out, and then log in as a regular user! After entering the root password, the printer configuration dialog appears.

You then simply follow the prompts to define your printer and add local remote printing services. You should print a test page before saving your changes. Use the printer configuration file or the File menu's Print menu item from a GNOME or KDE client.

> NOTE
Thered-config-printer utility is an update to the now-legacy printtool client included with previous distributions. Although you might find related tools (or symbolic links), such as printtool, printconf-tui, and /usr/sbin/printconf-gui installed on your system, Red Hat recommends that you use the redhat-config-printer client to manage printers.

# Console-based Printer Configuration Quickstart

Local or remote printer services can be configured locally or on a server without the Window System. To do so, you use Red Hat's text-based redhat-config-printer-tui printer configuration utility. You need to run this command as root:

```
# redhat-config-printer-tui
```

The screen clears after you press Enter, and you'll see the command's main dialog (you will see this screen in the section titled "Console-based Printer Commands," later in this chapter).

> NOTE
If you launch redhat-config-printer as root when not using X at a console, the redhat-config-printer-tui interface will be used.

You use the Tab key and spacebar to navigate the dialogs and expand lists of devices. You can create a new printer entry by highlighting the New button and pressing Enter. Use the Up or Down cursor keys to select and highlight an existing entry; then highlight the Edit button and press Enter to edit a previously defined printer.

You can print documents from the command line using the lpr command, and you control the print queue by using the lprm command.
