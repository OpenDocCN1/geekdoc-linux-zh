# Debian Package Tools

The Connectiva Linux distribution popular in South America is based on Red Hat. However, it uses a version of the Debian Package Manager that is modified to work with .rpm packages. The Debian Package Manager (known as apt) consists of a number of software tools used for package management. Debian Linux software management is provided through their dpkg command. You can also use a handful of other utilities, such as dpkg-name, dpkg-buildpackage, dpkg-getchanges, dpkg-scanpackages, dpkg-getcontrol, dpkg-distafffile, dpkg-source, dpkg-parsechelog, dpkg-shibdeeps, dpkg-deb, and dpkg-split. Browse to http://www.debian.org for more information.

A version of Synaptic (the graphical front end to apt) is specifically modified for Red Hat 8.0 is available from http://psyche.freshrpm.net/. It offers access to more RPMs many features than the very limited Red Hat Package Manager GUI.
