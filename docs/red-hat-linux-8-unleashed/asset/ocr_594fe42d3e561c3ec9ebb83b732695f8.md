Win4Lin uses the native Windows programs and dlls, but modifies some of them during the installation of the Windows CD. After installing the CD, each user must install his own copy of Windows, using a legitimate MS Windows license; the root user is prohibited from running a Win4Lin desktop for security reasons. Do you really want Windows to have root authority over your computer? The installation of Windows will proceed normally, just faster than you're used to.

# Configuring Win4Lin

As the root user, you can make systemwide settings in Win4Lin and enable hardware through a GUI interface. You access the interface by running winsetup from an xterm command line from the root desktop, like this:

```
$ winsetup
```

Win4Lin has some command-line options, but they are awkward to use—it's less trouble to install a minimal desktop environment for root (if one does not exist) in order to use the GUI tools. The root user only handles systemwide administration of Win4Lin; she cannot use Win4Lin to run Windows as root.

# Starting a Win4Lin Session

Start a Win4Lin session from the command line to launch either a Windows or DOS session:

```
$ win
```

or

```
$ dos
```

Win4Lin can provide an MS DOS environment as well because it's included with Windows. That DOS might be more useful and configurable than the one provided by FreeDOS running under Bochs.
