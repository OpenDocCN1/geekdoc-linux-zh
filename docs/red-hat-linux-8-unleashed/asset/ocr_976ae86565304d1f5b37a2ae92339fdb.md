# Using XFree86 to Create an XF86Config File

You use the xf86config command, which is part of the XFree86 server, to create a basic XF86Config file. The xf86config command works through the console or inside an X11 terminal. To begin, as root, start xf86config, like this:

```
# xf86config
```

After you press Enter, you see introductory text that looks like this:

This program will create a basic XF86Config file, based on menu selections you make.

TheF86Config file usually resides in /usr/X11R/etc/X11 or /etc/X11. A sample XF86Config file is supplied with XFree86; it is configured for a standard VGA card and monitor with 640x480 resolution. This program will ask for a pathname when it is ready to write the file.

You can either take the sample XF86Config as a base and edit it for your configuration, or let this program produce a base XF86Config file for your configuration and fine-tune it.

Before continuing with this program, make sure you know what video card you have, and preferably also the chipset and the amount of video memory on your video card. SuperProbe may be able to help with this.

Press enter to continue, or ctrl-c to abort.

> NOTE
The SuperProbe command mentioned in the opening xf86config screen is no longer needed or included with XFree86 4.0 and later versions.

You press Enter to start the configuration process. You are asked to select the pointer's protocol:

First specify a mouse protocol type. Choose one from the following list:

+   1. Microsoft compatible (2-button protocol)
2. Mouse Systems (3-button protocol)
3. Bus Mouse
4. PS/2 Mouse
5. Logitech Mouse (serial, old type, Logitech protocol)
6. Logitech MouseMan (Microsoft compatible)
7. MM Series
