## 控制区域传输 (Controlling Zone Transfers)

你还可以使用查询允许已知的从服务器从你的服务器执行区域传输。区域传输不仅消耗大量的资源（它们每次都需要派生一个 `named-xfer` 进程）并为拒绝服务攻击提供了途径，而且通过 `named-xfer` 的缓冲区溢出还存在远程漏洞，允许攻击者在受攻击的系统中获得 root 权限。为了防止这一点，请在区域定义中添加如下部分：

```
zone "example.com" {
  allow-transfer {
    192.0.2.96; // 已知的从服务器。
    localhost; // 通常测试时需要。
  }
};
```
