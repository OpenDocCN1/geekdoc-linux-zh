# lpm 530

The lpm command removes the spooled files from the printer's queue and kills the job. Print job owners, such as regular users, can only remove spooled jobs that they own. As the root operator, you can kill any job.

Only the root operator can use the lpc command. This command is used for printer and queue control. You can use it to rearrange the order of print jobs, and you can get a display of the status of any system printer. Start lpc on the command line like this:

```
# lpc
```

The lpc command has built-in help on command keywords and syntax. To display the help text, use the help keyword or press : so:

```
lpc> help
```

Several pages of help text will echo back to your display. Another helpful command is lpstat, which you use like this:

```
# lpstat
Printer: lp1@shuttle2
Queue: no printable jobs in queue
Status: job 'root@cello+301' removed at 17:47:07:633
```

This command lists waiting print jobs, along with information similar to that returned by lprpm.

# Using the Common Unix Printing System (CUPS)

Red Linux also includes a version of the Common Unix Printing System, known as CUPS. This print system supports the Internet Printing Protocol, known as IPP, and offers a number of unique features, such as network printer directory (printer browsing) services, support for encryption, and support for PostScript Printer Description (.ppd) files.

According to the Internet Engineering Task Force (IETF), IPP grew out of a 1996 proposal by Novell to create a printing protocol for use over the Internet. Then, the system has been developed and matured into a stable print system for use on a variety of Linux and UNIX operating platforms.
