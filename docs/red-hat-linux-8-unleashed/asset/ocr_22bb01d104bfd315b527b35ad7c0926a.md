[DllDefaults]
; "EXTRA_LD_LIBRARY_PATH" = "${HOME}/wine/cvs/lib"
"DefaultLoadOrder" = "native, builtin, so"

With dll overrides, you can make Wine use native Windows .dlls instead of the Wine versions of .dll: just reverse the order to "native, builtin". This selection can also be set from the command line (see the Wine documentation) when needed to run a particular program. The documentation explains how it can be defaulted on a per program basis here in the configuration file. The configuration would look like the following example taken from Codeweavers Crossover Wine configuration:

```
[AppDefaults\\msiexec.exe\\DllOverrides]
; Microsoft Installer = "builtin"
"ole32" = "builtin"
"ole2" = "builtin"
"compobj" = "builtin"
"storage" = "builtin"
"olepro32" = "builtin"
"ole2nls" = "builtin"
"ole2conv" = "builtin"
"ole2prox" = "builtin"
"ole2thk" = "builtin"
```

Note that the following defaults for some audio .dlls are set to "native". If the .dlls not yet exist on your computer, some applications will install them themselves. The Overrides section of the configuration file is as follows:

```
[DllOverrides]
"cmd32" = "builtin, native"
"comdlg32" = "builtin, native"
"ver" = "builtin, native"
"version" = "builtin, native"
"shell" = "builtin, native"
"shell32" = "builtin, native"
"lzexpand" = "builtin, native"
"lz32" = "builtin, native"
"comctli32" = "builtin, native"
"commctl" = "builtin, native"
"wsock32" = "builtin"
"winsock" = "builtin"
"advapi32" = "builtin, native"
"crtdll" = "builtin, native"
"mpr" = "builtin, native"
"winspool.drv" = "builtin, native"
```
