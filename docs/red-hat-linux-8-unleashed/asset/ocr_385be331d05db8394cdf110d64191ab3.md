# Commercial Office Suites for Linux

Several commercial office suites are available for Linux, in addition to StarOffice, which was already mentioned. None of these commercial suites are provided with Red Hat. Of is Hancom Office. Using the same Qt widget set in the KDE desktop, Hancom Office scores well on Microsoft file format compatibility. The suite includes a word processor, a spreadsheet presentation tool, and a graphics application. Corel produced a version of its WordPerfect Office 2000 for Linux before it discontinued the release of any new products. It still offers a support page, but the software is no longer available, nor is the excellent WordPerfect8 for Linux.
