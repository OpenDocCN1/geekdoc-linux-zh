# CHAPTER 18 Secure File Transfer Protocol (FTP) Service

# **LISTING 18.3** xinetd Configuration File for wu-ftupd

```
# default: on
# description: The wu-ftupd FTP server serves FTP connections. It uses \
#   normal, unencrypted usernames and passwords for authentication.
service ftp
{
    disable = yes
    socket_type        = stream
    wait               = no
    user               = root
    server             = /usr/sbin/in.ftpd
    server_args       = -1 -a
    log_on_success    += DURATION
    nice               = 10
}
```

Using an editor, change the disable = yes line to disable = no. Save the file and exit the editor. You then must restart xinetd because configuration files are only parsed at startup. To restart xinetd as root, issue the command `/etc/rc.d/init.d/xinetd restart`. This makes a call to the same shell script that is called at any runlevel to start or stop the xinetd daemon (and thus start or shut down the system). xinetd should report its status

```
# /etc/rc.d/init.d/xinetd restart
Stopping xinetd:[ OK ]
Starting xinetd:[ OK ]
```

Once restarted, the FTP server is accessible to all incoming requests.

# **Editing xinetd to Enable Access in the Very Secure FTP Server (vsftpd) Package**

You can use a similar approach to configure, enable and start the Very Secure FTP server, vsftpd. After installing the vsftpd RPM package, you must edit its xinetd file to enable access. Again, change the disable = yes to disable = no, as shown here:

```
# default: off
# description: The vsftpd FTP server serves FTP connections. It uses \
#   normal, unencrypted usernames and passwords for authentication.
service ftp
{
    disable = no
```
