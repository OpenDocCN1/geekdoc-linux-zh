# # Capturing Screen Images

You can use graphics manipulation tools to capture images that are displayed on your
computer screen. Although this technique was used for the production of this book, it
has broader uses; truth to the cliché that a picture is worth a thousand words.
Sometimes, it is easier to show an example than it is to describe it. A captured screen image
(also called a screen grab or a screenshot) can illustrate an error in the display of a
application (a font problem, for example) or an error dialog that's too complex to copy
down by hand. You might want to share an image of your beautifully crafted custom
des configuration with your friends or illustrate your written documents. In this
section, you learn how to capture screen images for these and other purposes.

When using GNOME desktop, you can take advantage of the built-in screenshot
mechanism (gnome-panel-screenshot). Access this tool by pressing the Print Screen key.
Captured images are saved in .png format.
