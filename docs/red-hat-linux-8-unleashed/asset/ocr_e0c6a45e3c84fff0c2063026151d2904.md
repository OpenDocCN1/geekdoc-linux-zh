Viewing Tv and Video 855

Capture chip. This card uses the Bt78 chipset. Your results will be different, depending on what card and chipset your computer has. This card happened to be the ATI All-in-Wonder VE (The VE means Value Edition; hence, there's no TV-out connector and no radio chip on the card.) The name of the chipset tells us that the card uses the bttv driver.

The documentation for the bt876 kernel sound module for recording sound is found in /usr/src/linux-2.4.18-11/Documentation/sound/btaudio. The documentation for the video driver is found under /usr/src/linux-2.4/Documentation/video4linux/bttv.

In the documentation, we find a file named CARDLIST, and in that file is the following entry, among others:

```
card=64 - ATI TV-Wonder VE
```

There are 84 cards listed as well as 39 radio cards, including

```
card=0 - *** UNKNOWN/GENERIC ***
```

which is what we would have used had we not known the manufacturer's name for our card.

The file Modules.conf, located in the same directory, gives us the following example of information to place in our /etc/modules.conf file:

```
# i2c
alias char-major-89    i2c-dev
options i2c-core      i2c_debug=1
options i2c-algo-bit  bit_test=1
```

```
# bttv
alias char-major-81  videov
alias char-major-81-0 bttv
options bttv          card=2 radio=1
options tuner        debug=1
```

All we need to do enter this information into /etc/modules.conf and change the value for card=2 to card=64. We can delete the reference to the radio card (radio=2) because we don't have one and leave the other values alone. Then we must execute

```
# depmod -a
```

to rebuild the modules dependency list so that all our modules are loaded automatically.
Finished, all we need to do is execute

```
# modprobe bttv
```

and our TV card should be fully functional. All the correct modules will be automatically loaded every we reboot.
