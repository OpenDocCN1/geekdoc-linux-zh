The KOffice KSpread client is a functional spreadsheet program that offers graphing capabilities. Like KWord, KSpread can also be launched from the command line. After you use a command line like this, you are asked to choose a type of document (new or previous document):

```
$ kspread &
```

A simple example of KSpread's graphing capabilities is shown in Figure 25.8. To create a graph, you click and drag to select the data in rows and columns, and then you click the Insert menu's Chart menu item. After your pointer turns into crosshairs, you can click and draw a blank area of the spreadsheet. A dialog box appears, from which you can select a graph type and create the graph.
