# CHAPTER 23 Using Perl

-T—This enables taint checking. In this mode, Perl assumes that all user input is tainted, or insecure, until the programmer tells it otherwise. This helps protect you from people trying to exploit security holes in your code and is especially important when writing CGI programs.

-U—This enables you to do unsafe things in your Perl program, such as unlinking directories running as superuser.

-V—This tells Perl to dump core after compiling this script. With much time and patience, you could presumably use this to create an executable file.

-V—This prints a summary of the major Perl configuration values and the current value of $INC.
V:names

This parameter displays the value of the names configuration variable.

-v—This prints the version and patch level of your Perl executable. For example:

```
$ perl -v
This is perl, v5.8.0 built for i386-linux-thread-multi
```

-W—This tells Perl to display all warning messages.

-w—This tells Perl to display warning messages about potential problems in the program, such as variables used only once (maybe be a typo), using = instead of == in a comparison, and like this one which is often used in conjunction with the -c flag to do a thorough program check.

```
$ perl -cw assignment.pl
```

-X—This tells Perl to disable all warning messages.

-x directory—This tells Perl that the script is embedded in something larger, such as an email message. Perl throws away everything before a line starting with !, containing the string 'perl', and everything after __END__. If a directory is specified, Perl changes to the directory before executing the script.
