# Pine as a New Client

Although the Program for Internet News and Email (Pine) package has gained popularity as a standard UNIX mail reader package, as its name suggests, it also allows you to read and post articles to newsgroups. The Pine package is included in the Red Hat distribution.

You must configure the news server address in the Pine setup screen (see Figure 20.2). You produce this by selecting the S (setup) option from the main Pine menu and then selecting the C (configure) option from the setup options.

You can enter the IP or domain name of the news server. When you enter the news server address, you can select the news server from the folders list by using the F option from the main menu. After you select the news server and press the Enter key, you use the F option in Pine to enter the name of the newsgroup you want to see articles from.
