# Copying Files

Often, when you have only a few files that need to protect from loss or corruption, it might make better to copy the files rather than create an archive of them. You can use the tar, cp or even the cpio commands to do this, as well as a handy file management tool known as. Using tar is traditional because older versions of cp didn't handle symbolic links and permissions at times, choosing those attributes (characteristics of the file) to be lost; tar handled those file attributes in a better manner. Now, cp has improved, and tar is more widely used.

Many choices exist for using copying as a backup technique, and your choice will depend on your priorities. If you're interested in the simplest method, choose cp -a. The tar alternative is the next option. cpio is better suited to creating archives than it is to simply copying files, me might offer the best combination of ease, power, and flexibility, but it cannot be counted on be found on every system; you should find tar and cp everywhere. The following sections describe how to use each of these methods so that you can determine which is best for your situation.
