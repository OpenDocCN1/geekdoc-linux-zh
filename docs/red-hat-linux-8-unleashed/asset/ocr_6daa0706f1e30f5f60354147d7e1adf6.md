# Relevant Red Hat Linux Commands

You can use the following commands to manage newsgroups and other collaborative communication processes in Red Hat Linux:

+   - emacs—The premiere editing environment that can also be used (surprise!) to read Usenet news
- inn—The INN daemon and its plethora of associated commands
- knode—KDE's graphical Usenet newsreading client
- mozilla—The mail and newsgroups component of the open-source Mozilla browser
- pan—An easy-to-use Usenet reader for GNOME
- pine—A text-based mail client that can also read Usenet news
- slrn—A text-based graphical Usenet newsreader
