# Using the chkconfig Text-Based Command-Tool

Traditionally, the command-line tool chkconfig has been used to effect administration of the services and their associations in the different runlevels. chkconfig was a major improvement over the process of configuring the symbolic links by hand. It is an effective, text-based command-line tool that you can use to display, diagnose, or change the starting or stopping of system services (as available under /etc/rc.d/init.d) in each runlevel.

For example, to list all services that will be turned on runlevel 5, you can pipe the output of chkconfig through grep '5:on' like this:

```
$ /sbin/chkconfig --list | grep '5:on' | sort
anacron 0:off 1:off 2:on 3:on 4:on 5:on 6:off
appmd       0:off 1:off 2:on 3:on 4:on 5:on 6:off
atd       0:off 1:off 2:on 3:on 4:on 5:on 6:off
autofs    0:off 1:off 2:off 3:on 4:on 5:on 6:off
canna     0:off 1:off 2:on 3:off 4:on 5:on 6:off
crond     0:off 1:off 2:on 3:on 4:on 5:on 6:off
```

The output is not shown here, but as you can see, chkconfig displays the value of off or on for each service and runlevel. The sample output only shows services that will be started in runlevel 5. The chkconfig command can be used to reassign or stop values for each runlevel and each service. As an example, to start power management (controlled by the apod script under /etc/rc.d/init.d) when using Red Linux during runlevel 5, use chkconfig like this:

```
# chkconfig --level 5 apmd on
```

You can verify this action by grepping chkconfig's output out like so:

```
# chkconfig --list | grep apmd
apmdd       0:off 1:off 2:on 3:on 4:on 5:on 6:off
```

ntsysys is a graphical interface you use to access chkconfig and a graphical interface. ntsys is an ncurses-based interface, meaning that it offers crude, block graphics and elements you can tab through and select by pressing the spacebar (see Figure 7.1).

When you have the ntsys open, you can scroll through the list of services and toggle a service or off by pressing the spacebar. When finished, use the Tab key to highlight the OK or Cancel button. Your changes will be saved and the next time Red Linux is booted.

ntsysys is simple to use and is an excellent tool for a system without X, but it only works for the runlevel you are currently in.

The Red tool setup is an ncurses-based menu for all the available ncurses-based command-line configuration tools (see Figure 7.2).
