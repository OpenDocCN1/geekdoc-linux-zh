
Add the following line if it doesn’t exist:

Load glx

Finally, change

Driver "nv"

to

Driver "nvidia"

Check that the new kernel module is installed. Look at the listing produced by # lsmod and see whether the NVdriver is listed. If not use # modprobe NVdriver to load it and check again.

If everything looks okay so far, test X by starting “naked” with # X. If you see a gray screen with an X for a cursor, you’re successful! Kill X with the Ctrl+Alt+Backspace key combination and then run to level 5 with # telinit 5.

If something goes amiss along the way, reread the NVdriver instructions and check your spelling (we misspelled nvidia twice during our attempts). The only problem that you’ll encounter is that the Red Hat XFree86 configuration tool won’t recognize the NVIDIA driver and will replace it with the XFree86 driver if you ever use the Red Hat graphical configuration tool.

You also learn how to use a number of cross-platform tools, including VNC (Virtual Networking Computing) to access the desktops of other computers running non-Linux operating systems or software.
