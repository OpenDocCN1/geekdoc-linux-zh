# Server Administration

# 65

| Field | Description |
| --- | --- |
| special-action-flag | One or more character flags indicating any special action taken by the server.<br>The values are<br>C for compressed files.<br>U for uncompressed files.<br>T for TARed files.<br>- for no special action taken. |
| direction | Indicates whether the file was sent from the server or received by the server.<br>The way in which the user logged to the server. The values are<br>a anonymous guest user. |
| access-mode | g guest user, corresponding to the guestgroup command in<br>/etc/ftpaccess file.<br>r real user on the local machine. |
| username | If logged in as a real user, the username.<br>If the access mode was guest, the password is given. |
| service-name | The name of the service used, usually FTP. |
| authentication-method | Type of authentication. The values are<br>ø: none.<br>1: RFC931 Authentication (a properly formed email address). |
| authenticated-user-id | This is the user ID returned to the server based on the authentication<br>method used to access the server. * is used when an authenticated user<br>ID cannot be found. |
| completion-status | A single character field indicating the status of the transfer. The values are<br>c: completed transfer.<br>i: incomplete transfer. |
