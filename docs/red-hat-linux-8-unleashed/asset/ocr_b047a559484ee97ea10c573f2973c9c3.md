For Linux/i386, partitions 1-4 are the primary partitions, and 5 and above are logical partitions.
Other versions of Linux use partitioning schemes appropriate to their respective architectures.

The number 3 at the upper left of the preceding listing represents the major number that identifies a class of device. In this case, major 3 identifies character devices (Pseudo-tty) and block devices (IDE drives). The columns of numbers that follow the device types are called the minor numbers; any device can be identified uniquely by its major and minor number. Linux uses these internally; you usually see the name of the device as it is in the /dev/ directory. major/minor numbers do show up in kernel error messages from time to time, and understanding the numbers help debug the problem. As you'll see in the next section, the mknod command needs to be told how numbers in order to create a device. /dev directory contains all the special files known as device files. The files are placed in /dev/ from the original installation, and you can also create device files to go there if you need them.

During the normal operation of Linux, you never need to bother with the files in /dev/, but if you want to look at all the files in /dev, use this command:

```
# ls -1 --sort=none | less
```

--sort=none argument keeps the devices mostly grouped by major numbers for your viewing pleasure; redirecting the output of the command (known as piping) through the less command allows you to use the PageUp and PageDown keys to navigate the long list rather than it scroll off the screen. There are too many to list here, but they will all either block or character devices.

A character device is a file that handles one data character at a time and processes them in order. Examples include TTY (display console) devices, SCSI tape drives, the keyboard, audio devices, the Coda network filesystem, and many more.
