# Using Binary Emulation in Red Hat Linux

The format of a compiled binary application is important because it's structured in the way the kernel expects to see the code when it's loaded into memory to be executed. If it is not in a format that can be used by the kernel, it simply can't run.

The Linux kernel can perform emulation of other binary formats used by other UNIX operating systems. By compiling support into the kernel or by loading the appropriate kernel module, Linux can load and run binaries that have been compiled for UNIX systems as if they were native to Linux and its own ELF binary format. As provided by Red Hat, non-native binary support is provided via modules and the following operating systems are supported:

+   - UnixWare 7.x
- Solaris 2.x
- iBCS2/iBCS4 (Intel Binary Compatibility Standard)
- ISC
- SCO OpenServer 5
- SCO UNIX 3
