# Web Design Tools

One of the simplest Web design tools is the text editor vi, because Web pages are really nothing more than text files with text formatting tags included. Few people want to use such a simple tool for Web page design, however. While the Windows and Mac world have emphasized WYSIWYG (What You See Is What You Get) page design tools, Linux users have, for the most part, opted for amounts fancy text editors such as the Quanta Plus application provided with Red Hat.

Quanta Plus is located in the Programming menu, found under the Extras. Launching the application presents you with a three-panel view: a file tree on the left, a files display on the upper right, you can preview your file in different browsers so you can see how the browsers display the code. Quanta uses the concept of "projects" to manage common pages from a Web site, downloading and uploading the pages using syntax coloring for debugging, as well as a number of tools for advanced page elements such as tables, lists, and forms.
