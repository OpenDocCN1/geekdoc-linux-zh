## Configuring, Installing, and Using VMware

Configuring Workstation 3.1 from VMware, Inc. is a commercial software package you can use to install and run other operating systems (such as DOS, Linux and BSD, or variants of the commercial Windows operating system). The software works by using your computer's hard drive to host different virtual filesystems; VMware emulates a virtual computer complete with Phoenix BIOS.

Given adequate CPU horse-power (over 1GHz) and enough memory (128MB per operating system) and hard drive space (1GB per operating system), system administrators or network engineers create virtual networks on a single computer running operating systems with separate instances of VMware sessions. A home user running one virtual machine at a time can get by less. Security specialists can also use this as a safe incubator in order to study or examine how a computer virus affects an operating system. VMware excels in OS testing and network testing, especially because a default image of a guest OS can be write-protected and used again.

## Installing VMware

The software can be downloaded and installed using the rpm or tar command. (Compressed tarballs or .rpm archives are available from VMware.) You will need to purchase a license key in order to use the software after installation, or you can register and use the software in demonstration mode, without charge, for 30 days. To install and configure the software, you will need root permission and the gcc compiler and related software installed on your system because the virtual network modules will need to be compiled for your kernel.

> CAUTION
> You must have the source for the Linux kernel and the gcc compiler installed on your system in order to build the VMware software modules; otherwise, the configuration phase will fail.

You'll need to begin at the VMware home page to follow the links to get to the download page: http://www.vmware.com. We recommend the RPM files, but you can also use the tarball files, although that's a bit trickier. If you download and extract the compressed tarball, a directory named vmware-dist will be created. You should then navigate into this directory and run a Perl script named vmware-install. Start the installation by

```bash
# ./vmware-install.pl
```

Follow the prompts to complete the installation.

## Configuring VMware

The tarball installation leads you into the configuration phase. If you used the rpm package, you need to start the configuration phase manually with

```bash
# vmware-config.pl
```

> NOTE
> You'll need to have the source for the Linux kernel and the gcc compiler installed on your system in order to build the VMware support modules or the configuration phase will fail. See Chapter 24 for details on how to do that.

The installer will build various kernel modules to support VMware during operation. You'll be asked about networking. Select the type of networking as described in the next paragraph if you will be able to use any networking connectivity from within VMware and the operating system installed in it.

Note that you can type help to get more information about networking, which, if enabled, supports bridging of virtual systems to a hardwired LAN or a "host-only" configuration. Bridging allows the guest operating system to appear as if it were running on a separate computer from the host (our Linux computer, in this case). Host-only sets up a network between the guest operating system and the host, and other computers on the network cannot communicate with the guest operating system.

The VMware-specific services will be started on your Red Hat Linux system from a script in /etc/init.d/vmware. The specific services depend on how you configured networking during the VMware setup phase. You can stop or restart VMware services by using that same vmware script in the odd chance that the software interferes with other services as networking or printing.

## Starting a VMware Session

VMware is generally started during an X session from the command line of a terminal like this:

```bash
$ vmware
```

The command supports several options—the most useful of which are -y to diagnose disk problems and -Y to allow repairs to the virtual disks. You can configure VMware from the GUI.

The first time you launch VMware, the VMware window will appear and request a license number. You can then start the Configuration Wizard by opening the File menu and selecting Wizard. A series of dialog boxes will appear (the first one is shown in Figure 27.7) that are used to select a guest operating system and prepare a filesystem on your hard drive for installation of the guest operating system.

VMware supports a number of operating systems, including DOS, Windows 3.1, 9X, ME, NT, 2000 Professional, Server, and Advanced Server editions), XP (Home and Professional Editions), Linux, FreeBSD. VMware also offers experimental support for Windows .NET Web Server, Standard Server, Enterprise Server, VMware 6.0, and other operating systems.

> TIP
> Ensure the proper CD-ROM device is used in the VMware configuration. Use the built-in editor to check. You might need to select /dev/scd0 rather than /dev/cdrom if you are using SCSI emulation for a CD writer.

**A Case of Being Too Helpful?**
If you intend to install a guest operating system by booting with a CD-ROM when using VMware, you might find Red Hat Linux will automatically mount the CD-ROM before VMware's BIOS can use the CD. To avoid this problem, don't use the daemon (which mounts devices and NFS hosts on demand) when using VMware. You can temporarily turn off this before starting a VMware session by executing /etc/rc.init.d/amd stop as root; or disable this feature entirely using the ntsysv or chconfig commands as described in Chapter 7, "Managing Services".

If you need to boot from a specific device, press F2 after using VMware's Power Button to change the virtual machine's BIOS settings. In the BIOS configuration, press the right arrow to access the BIOS Boot menu; press the plus or minus keys to reorder the virtual machine's boot devices; press F10 to save and reboot using your new settings. The new settings will be saved between VMware sessions for the configuration file.

To run more than one operating system at the same time, simply start additional versions of VMware like this:

```bash
$ vmware &
```

After you click the Power On button, your operating system will boot, and you can run a session in a VMware as shown in Figure 27.8.

## Microsoft Windows on Win4Lin

Win4Lin is a commercial application that uses a licensed version of Windows 95, 98, 98SE, or to install and run Windows from within Linux. The parent company, Traverse, provides a GUI installer that validates your license and downloads and installs the applic-ation, along with a patched version of the supported kernel. It also manages the installation of the Windows .cab files from the Windows CD.
