# The Shell Command Line

Multiple commands can be run on a single command line using a semicolon to separatencommands:

```
S w ; free ; df

```

This example displays the output of we, free, and df commands. Long shell command\lines can be extended inside shell scripts or at the command line by using the backslash
character (\). For example:

```
$ echo this is a line \
> command line and"; echo shows that multiple commands \
> may be strung out.\nthis is a long command line
shows multiple commands may be strung out.
```

The first three lines of this are a single command line. In that single line are
two instances of the echo command. Note that when you use the backslash as a line-\continuation character, it must be the last character on the command line (or in your
shell script, as you'll see later on in this chapter).

Using the basic features of the shell command line is easy, but mastering use of all features
c be difficult. Entire books have been devoted to using shells, writing shell scripts, and
using pattern-matching expressions. The following sections provide an overview of some
 of the shell command line relating to writing scripts.

> NOTE
If you plan to develop shell scripts to expand the capabilities of pattern-matching commands
as grep, you will benefit from learning more about using expressions. One of the definitive
guides to using the pattern-matching capabilities of UNIX and Linux commands is Mastering
Regular Expressions by Jeffrey E. Freidlich.
