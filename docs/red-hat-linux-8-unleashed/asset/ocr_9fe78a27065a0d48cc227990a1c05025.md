Red Hat Linux provides several date and time utilities you can use at the command line or during an X session, including these:

+   - date—Used to display, set, or adjust the system date and time from the command line
- hwclock—A root command to display, set, adjust, and synchronize hardware and system clocks
- redhat-config-date—A graphical date, time, and network time configuration tool

# Using the date Command

The date command to display or set your Linux system time. This command requires you to use a specific sequence of numbers to represent the desired date and time. To see your Linux system's idea of the current date and time, use the date command like this:

```
# date
Sep 22 15:53:19 EDT 2002
```

To adjust your system's time (say, to September 23, 2003 at 8 a.m.) use a command line, with the month, day, hour, minute, and year, like so:

```
# date 09230802003
Tue 23 08:00:00 EDT 2003
```

# Using the hwclock Command

The hwclock command to display or set your Linux system time, display or set your PC's hardware clock, or to synchronize the system and hardware times. To see your hardware date and time, use hwclock with its --show option like so:

```
# hwclock --show
Sun 22 Sep 2002 03:59:58 PM EDT -0.719146 seconds
```

Use hwclock with --set and --date options to manually set the hardware clock like so:

+   - hwclock --set --date "09/23/03 08:00:00"
- hwclock --show

```
Tue 23 Sep 2003 08:00:00 AM EDT -0.151718 seconds
```

In these examples, the hardware clock has been set using hwclock, which is then used to verify the new hardware date and time. You can also use hwclock to set the Linux system date and time date using your hardware clock's values with the Linux system date and time.

For example, to set the system time from your PC's hardware clock, use the --hctosys like so:

```
# hwclock --hctosys
```
