The necessity of choosing from a number of different desktop environments and, for example, dozens of text editors is a daunting task to the new Linux user, and it has been the source of many complaints from corporate users. Further, Red Hat must provide support for every application it includes in the distribution.

Beginning with version 8.0, Red Hat addressed these concerns by limiting the menu choices that are available from the main menu and limiting the overall number of available applications. Now, only a single application for any application category is presented in the main menu: only one processor, only one address book, and so on. In limiting, Red Hat has selected the productivity applications it believes are the best available, choosing an unofficial “Red Hat Suite” that is based on the OpenOffice.org suite. So that Red Hat has added applications taken from GNOME office applications and the KDE desktop.

The Red-selected office components are available in the main menu under the Accessories, Graphics, Office, and Sound & Video menus. All other applications are found in the Extras menu, which contains a duplication of the main menu. The Extras menu contains the menu entries for all the applications provided by Red Hat that did not make the cut to become the default choices. For the corporate IT manager and Red Hat, a simple edit to the menu configuration file removes the Extras from view and simplifies the support that must be provided to users.

For individual users, Red Hat’s approach causes a problem because Red Hat scatters applications throughout the menu tree. Worse, the default desktop environment chosen by Red Hat (GNOME version 2.0) does not provide a menu editor. Obviously, Red Hat has not finished with its menu design, and it is likely it will change in the future. You will see those changes as you update your installation of Red Hat over time.

# Office Suites for Red Hat Linux

Most office suites include productivity applications, such as word processors, spreadsheet programs, calculators, database programs, and drawing tools. A number of office suites have been created for use with Linux. Many of them are free, but a number of commercial products are available as well. Many of these office suites contain applications that mimic the functionality of popular Windows-based productivity applications, and many are designed to be compatible with the file formats of those applications.

Red Hat has not developed its own office suite, but it has provided a default set of office applications that are designed have wide appeal and provide general functionality. The core Red Hat office suite, OpenOffice.org, and the GNOME Office suite are included in this book’s CD-ROMs. In the following sections, you’ll learn about the applications included in these productivity packages and get some tips for installing and configuring them. You’ll also learn about the KDE office suite (KOffice) and other office suites that are available for free download or by purchase of use with Red Hat Linux.
