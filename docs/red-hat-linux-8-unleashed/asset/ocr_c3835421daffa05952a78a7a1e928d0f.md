Select a mode, such as High, Medium, or No Firewall. Use the High security mode for the most protection and restriction on outside access to your system; only DNS queries and DHCP access (for automatic network configuration) will be enabled. The Medium security mode can be used if you want to enable SSH, FTP, HTTP, telnet, or NFS access. Obviously, the No Firewall setting will leave your system unprotected.

Use the Customize button to select an interface (such as eth0) or more services, such as DHCP, SSH, Telnet (not recommended), HTTP, Mail, or FTP to allow through the interface. Once you are finished, use the OK button in the Customize dialog and then in the main dialog. Your firewall rules will be implemented immediately in memory.

# Red Hat Linux and Firewalling

Red Hat Linux also supports the older, but popular iptchains packet-filtering software, which can be used to construct effective firewall rules on Red Hat Linux firewalls, gateways, and workstations. Red Hat Linux also supports the more capable iptables, NetFilter system, which offers additional controls and logging facilities for building rules or filtering instructions.

Unfortunately, Red Hat Linux does not include any command-line or graphical interface utilities you can use to build, save, and test complex iptables rulesets (aside from the basic generated by lokkit under /etc/sysconfig). Many experienced Linux users will hand-tune rules for specific application in advanced network situations, such as development of routing rules
