## Planning Your Red Hat Linux Deployment

Before planning the specific steps of an installation, you need to make decisions about the type of deployment you want to undertake. Computing needs dictate the type of hardware and software solutions required for a successful deployment, but before making the plunge, some hard questions need to have been asked and answered, as “How will you use Red Hat Linux?”

### Business Considerations

Choosing an operating system for your business is an important decision. Migration to or adoption of a new hardware or software platform can have immediate and long-term effects on your organization. There is no magic formula to use in the decision-making process when contemplating a move, and freelance consultants, small business owners, medium-sized business, corporations, and other large business organizations will have different computing resources, objectives, and needs. For many businesses, computers are a critical and sometimes central component of business operations.

> NOTE Browse Red Hat's Migration Center at http://www.redhat.com/solutions/migration/ to read success stories, market analyses, and technical reports using Red Hat for business.

Fortunately, Red Hat Linux is flexible enough to provide a full or partial migration and supports all of the major computing services required in today's business operations. Some of the more traditional services include electronic mail, file servers, network services (including firewalls), Web hosting (Internet and intranet-based), and database services. Red Hat can provide one, more, or all of these services. It can also be work in stages to ease migration issues as training or support.

Some of the ideas, issues and concerns are listed in Table 2.1, “Deploying Red Hat Linux.” One consideration is how Red Hat will be put to work. In other words, how will Red Hat fit in with your existing hardware and software needs? Another consideration is the level of consensus in management and user willingness to change or adopt a new software environment. However, this can be sidestepped by deploying Red Hat Linux in such a way that the transition to it is invisible to users, such as when Linux-based Web, file, or printing services replace existing servers.

Money, or finance cost, is another issue to consider. Red Hat offers flexibility and reliability, but transitioning to a new platform can have unforeseen costs. Linux detractors sometimes point to added Total Cost of Ownership (TCO) factors, such as support and training, and argue that these issues add significantly to the cost of a Linux migration. While there may be some additional support costs, training may not be an issue, especially if Linux is invisibly deployed. Also, hidden charges may be offset by Red Hat’s cost in licensing, deployment, scaling, maintenance, resource requirements, and support of legacy hardware.

## Planning Your Red Hat Linux Deployment

You should know what you're going to with Linux before you install it. In other words, what is the objective of your migration? If Red Hat will be used as a replacement platform for network services, what services will be replaced? ### System Considerations

Red Hat is a perfect solution for many computing needs. But choosing an operating system demands consideration of a number of issues. Some of these issues are listed in Table 2.1. For example, how you choose to use Red Hat will affect your choice of computer hardware, may affect your network configuration, and could dictate policy issues (such as access, security, and allowable protocols).

Red Hat can be used to provide many different services. For example, one server may be boot management for a thin-client network where workstations boot to a desktop by drawing a kernel and remotely mounted filesystems over a network. This mechanism is not supported out of the box, so some effort can be expended if such a system is required. Other services easily implemented (literally in an hour or less) can be centralized server environments for file serving. Web hosting for a company intranet, or bridging of networks and routing services.

Linux supports nearly every protocol, which enables it to be used to good effect even in mixed operating system environments. The security features of the Linux kernel and companion security software also make Linux a good choice when security is a top priority. Although no operating system or software package is perfect, the benefit of open source of the kernel and other software for Linux allows review of pertinent code and rapid implementation of any necessary fixes. But even with the secure features of Linux, some effort will have to be in designing and implementing gateways, firewalls or secure network routers.

Red Hat can serve as a development platform for applications, e-commerce sites, new operating systems, foreign hardware systems, or design of new network devices using Linux as an embedded operating system. Setting up workstations, required servers, source code control systems, and industrial security will require additional effort.
