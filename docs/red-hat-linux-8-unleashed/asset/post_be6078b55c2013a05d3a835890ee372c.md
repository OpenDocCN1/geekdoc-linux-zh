The # line is technically not part of the Perl code at all. The # character indicates that the rest of the screen line is a comment. Exceptions to this practice include when the # character is in a quoted string and when it's being used as the delimiter in a regular expression. Comments are useful to document your scripts, like this:

## Perl Variables and Data Structures

Perl is a weakly typed language, meaning that it doesn’t require you to declare a data type, such as a value of (data) to be stored in a particular variable. C, for example, makes you declare that a particular variable is an integer, a character, a structure, or whatever the case may be. Perl variables are whatever they need to be, and can change type when you need them to.

## Perl Variable Types

There are three variable types in Perl: scalars, arrays, and hashes. In an attempt to make each data type visually distinct, a different character is used to signify each variable type.

Scalar variables are indicated with the $ character, as in $penguin. Scalars can be numerical or strings, and they can change type from one to the other as needed. If you treat a number like a string, it’s a string. If you treat a string like a number, it’s translated into a number if it makes sense to do so; otherwise, it probably evaluates as 0.

## CHAPTER 23 Using Perl

For example, the string "76trombones" will evaluate the number 76 if used in a numerical calculation, with the string "polar bear" will evaluate to 0.

Perl arrays are indicated with the @ character, as in @fish. An array is a list of values that are referenced by index number, starting with the first element 0, just as in C and awk. Each element in the array is a scalar value. Because scalar values are indicated with the $, a single element in an array is also indicated with a $ character.

$fish[2] refers to the third element in the @fish array. This tends to throw some people off, but is similar to arrays in C, in which a first element is 0.

Hashes are indicated with the % character, as in %employee. A hash, used to go by the cumbersome name associative array, is a list of name and values pairs. Individual elements in the hash are referenced by name, rather than by index (unlike an array). Again, because values are scalars, the $ is used for individual elements.

For example, %employee(name) gives you one value from the hash. Two rather useful functions for dealing with hashes are keys and values. The keys function returns an array containing all the keys of the hash, and values returns an array of the values of the hash. Using this approach, the Perl program in Listing 23.2 displays all the values in your environment, like typing the bash shell env command.

## LISTING 23.2 Displaying the Contents of the env Hash

```
#!/usr/bin/perl
foreach $key (keys %ENV) {
    print "$key = $ENV{$key}\n";
}
```

## Operators

Perl supports a number of operators to perform various operations. There are comparison operators (used to compare values, as the name implies), compound operators (used to combine operators or multiple comparisons), arithmetic operators (to perform math), and special constants.
