# CHAPTER 1 Introducing Red Hat Linux

Red Hat Linux, provided by Red Hat, Inc. of Raleigh, N.C., is the Linux distribution against which all other Linux distributions are compared. Red Hat Linux has spawned legions of imitators than any other Linux distribution, and is the distribution of choice for many computer hardware manufacturers, software shops, and Value-Added Resellers (VARS)—with good reason.

As you learn in this chapter, Red Hat Linux is one of the most up-to-date Linux distributions. Here, you see why Red Hat Linux is a good choice in a variety of computing environments and how, when combined with advances provided by the latest stable 2.4-series kernel, it provides multilayer support for the home, small business, and even enterprise-class corporate user.

# Inside Red Hat Linux

Red Hat, Inc. made a number of changes and added quite a few features to its latest version of Red Hat Linux. This new Red Hat distribution is intended as a base offer providing a framework operating system and desktop for more advanced Red Hat products. The most evident change is Red Hat's new desktop, which has a unique look and feel, them Bluecurve. This desktop provides a consistent interface that helps to provide harmony between popular but, but in Red Hat's case, previously different desktops—the GNU Network Object Model Environment (GNOME) and the K Desktop Environment (KDE).

Red Hat's new desktop also benefits from improved font handling. Red Hat is the first Linux distribution to provide the newest update to the X Window System's font system, the Xft2 and fontconfig libraries by Keith Packard. These new font software libraries are destined to become an integral feature of the X Window System, and are included and will be installed and set up automatically when you install Red Hat from this book's CD-ROMs.

Along with putting in improvements such as the new theme and font handling, Red Hat also spent a bit of effort on developing a comprehensive suite of graphical administrative programs, or software tools. The tools, shown in Table 1.1, combine and expand on the capabilities of the root operator (known as the superuser) to administer a Red Hat system. The software takes the place of (and in some cases upgrades and arguments) many of the legacy command-line tools traditionally used on a UNIX system. You'll see how to use these tools throughout this book.
