The important Red Hat directories in Table 5.1, such as those containing root commands or system configuration files, are discussed in the following sections. You'll use and edit files under these directories when you use Red Hat.

# Use Essential Commands from the /bin and /sbin Directories

The /bin directory (about 78MB if you do a full install) contains essential commands used by the system when running and booting Linux. In general, the root operator uses the commands in the /sbin directory. Many (though not all) of these commands are statically linked; such commands do not depend on software libraries residing within the /lib or /usr/lib directories. Nearly all the other applications on your system are dynamically linked—meaning they require external software libraries (also known as shared libraries) to run in.

> Because the system contains dynamically linked applications, you might sometimes get “dependency errors” when installing or upgrading software packages; in those situations, a supporting library (or application) might not be present. See Chapter 8, “Managing Software and System Resources,” for more information on working with dynamically linked applications.

# Store the Booted Kernel and View Stored Devices in the /boot and /dev Directories

The /boot directory contains the Linux kernel at boot time, with other files that describe the kernel or provide information for booting Linux. When you rebuild a new kernel, the kernel and related files are placed in this directory (see Chapter 24, “Kernel and Module Management,” for more information on rebuilding or installing a kernel).
