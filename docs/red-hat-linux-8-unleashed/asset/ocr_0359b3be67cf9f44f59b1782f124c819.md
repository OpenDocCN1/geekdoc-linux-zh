# CHAPTER 11 Backing Up, Restoring, and Recovery

**Restoring Files from an Archive with tar**
The xp option in tar restore the files from a backup and preserve the file attributes as well, and will create any subdirectories it needs. Be careful when using this option because the backups might have been created with relative or absolute paths. You should use the tvf option with tar to list the files in the archive before extracting so that you'll know where they will be placed.

For example, to restore a tar archive compressed with bzip2,

```
# tar xjvf RHLutest.tar.b22
```

To list the contents of a tar archive compressed with bzip2,

```
# tar tjvf RHLutest.tar.b22
drwxwxrxr-x //hoyt      2002-09-04 18:15:05 RHLutest/
-rw-rw-rw-- //hoyt      163 2002-09-03 22:33:49 RHLutest/screenshots.txt
-rw-rw-rw-- //hoyt      840 2002-09-01 19:27:59 RHLutest/RHLU_guideline.txt
-rw-rw-r-- //hoyt     1485 2002-09-01 18:14:23 RHLutest/style-sheet.txt
-rw-rw-rw-- //hoyt      931 2002-09-01 19:02:00 RHLutest/RHLU_TOC.txt
```

Note that the pathnames don't start with a backslash, they are relative pathnames and will install in your current working directory. If they were absolute pathnames, they would install exactly where the paths states.

# Backing Up Files with cpio

The cpio tool (installed by default) is great for saving individual files scattered throughout a filesystem as opposed to all the files located in a single directory. You can generate a list of files and pipe them to cpio; those files become part of the archive. Interestingly, RPM files (Red Hat Package Manager) are modified cpio files. The rpm2cpio command can be used to unpack (rather than install) RPM files if needed. (See Chapter 8 for more information on RPM).

Create a cpio Archive

To see how cpio works, you can create a list of files from the /etc directory and use that list to create the cpio archive:

```
# find /etc -print > filelist
# cat filelist | cpio -o > backup.cpio
```

To do all on one line, try:

```
# find /etc -print | cpio -o > backup.cpio
```
