## Displaying Free and Used with memory

Although top includes some memory information, the free utility will display the amount of free and used memory in the system in kilobytes (the -m switch displays in Megabytes). By one, the output looks like this:

```
total       used free shared cached
Mem 255452 251132 4320 0 19688 77548
buffers/cache: 138896 101556
Swap 136512 31528 104984
```

This output describes a machine with 256MB of RAM and a swap partition of 137MB. Note that some swap is used although the machine is not heavily loaded. Linux is very good at memory management and “grabs” all the memory it can in anticipation of future work.

## Disk Quotas

Disk quotas are a way to restrict the usage of disk space either by user or by groups. quotas rarely—if ever—used on a local or standalone workstation, quotas are definitely a way of at the enterprise level of computing. Usage limits on disk space not only conserve resources, but also provide a measure of operational safety by limiting the amount of disk space any user can consume.

Disk quotas are more fully covered in Chapter 10, "Managing the Filesystem".

## Graphical Process and System Management Tools

The Gnome and KDE desktop environments offer a rich set of network and system monitoring tools. Graphical interface elements, such as menus and buttons, and graphical output, including metering and real-time load charts, make these tools easy to use. These clients, which require an active X session and in some cases (but not all) root permission, are included with Red Linux.

If you view the graphical tools locally while they are on a server, you must have X properly installed and configured on your local machine. Although some tools can be used to remotely monitor systems or locally mounted remote systems, you'll need to properly configure pertinent X11 environment variables, such as $DISPLAY, in order to use the software or use the ssh client -X option when connecting to the remote host.

Red Hat Linux includes the xosview client, which provides load, CPU, memory and swap usage, disk I/O usage and activity, page swapping information, network activity, I/O rates, serial port status, and if APM is enabled, the battery level (such as for a laptop).

For example, to see some of these options, start the client like this:

```
# xosview -geometry 406x488 -font 8x16 +load +cpu +mem +swap \
+page +disk +int +net +battery &
```

After you press Enter, you'll see a display as shown in Figure 8.5.
The display can be customized for a variety of hardware and information, the exosview client (like most well-behaved X clients) obeys geometry settings such as size, placement, or font. If you have similar monitoring requirements, but want to try a similar but different client from xosview, try xpustate, which has features that allow it to monitor network CPU statistics foreign to Linux. None of these applications are installed with the base of packages; you need to install them manually if you want to use them.
