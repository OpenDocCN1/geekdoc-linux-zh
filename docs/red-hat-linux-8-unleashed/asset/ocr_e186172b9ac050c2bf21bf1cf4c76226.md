from http://www.ardi.com. Executor emulates a Motorola MC68040 CPU running System 6.0.7 and supports near 400 Macintosh applications. Some of the features and hardware not supported, however, are serial ports, LocalTalk, Control Panels, or INITs. On the other hand, Executor does not require the Apple Mac OS System files or binary ROM images.

> NOTE
Executor will not run newer OS X applications. However, you can download and install Apple Computer's Darwin distribution by browsing to http://gnu-darwin.sourceforge.net/. It doesn't include the proprietary OS X graphical interface, however, so it won't run those applications either. You would be better off installing the full version of BSD that Darwin is based on: http://www.freebsd.org.

The software is installed with the rm command under the /executor/bin directory with symbolic links to the /usr/local/bin directory. The client can started like this:

$ executor &
