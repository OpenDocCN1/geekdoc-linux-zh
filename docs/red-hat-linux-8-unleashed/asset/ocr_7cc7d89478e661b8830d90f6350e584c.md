# Qmail

Qmail is a direct competitor to Postfix. Postfix is designed to be easier to use than Sendmail, as well as faster and more secure. However, Qmail isn't a drop-in replacement for Sendmail, so migrating an existing Sendmail installation to Gmail isn't quite simple as migrating from Sendmail to Postfix. Qmail is relatively easy to administer, and integrates with a number of software add-ons, including Web mail systems and POP3 servers. Qmail is not provided as part of the Red Hat distribution, but is available from http://www.qmail.org/.

# MDIR Versus Mailbox

Qmail also introduced maildir

The traditional mbox format keeps all mail assigned to a folder as a single file and maintains an index of individual emails. With maildir, each mail folder has three subfolders: cur, new, and temp. Each email is kept in a separate, unique file. If you are running a large number of people, you should select a filesystem that can efficiently handle a large number of small files.

Mbox offers one major disadvantage. While you are accessing the monolithic mbox file that contains all your mail, suppose some type of corruption occurs, either to the file itself or the index. Recovery from this problem can be difficult. This is especially troublesome if the file is accessed over a network; one should avoid accessing mbox mail mounted over NFS, the Network File System, because file corruption can occur.

The choice of MUA affects your choice of mail directory format. For example, the mail program does not cache any directory information and must read the mail directory any time it accesses it. If you are using pine, maildir would be a more choice. Advanced MUAs perform choosing, so maildir might be a good choice, although the MUA cache can get out of synchronization. It seems that there is no perfect choice.

Red Hat Linux provides you with alternatives that have both strong and weak points. Be aware of the differences between the alternatives and frequently re-evaluate your selection to make certain it is the best for your circumstances.

Other MTAs are available for use with Red Hat, but these three are the most popular. Which one should you choose? That depends on what you need to do. Sendmail's main strengths are that it is probably already installed and can do things that most other MTAs cannot. However, if ease of use or speed is a concern to you, you might want to consider replacing Sendmail with Postfix or Qmail.
