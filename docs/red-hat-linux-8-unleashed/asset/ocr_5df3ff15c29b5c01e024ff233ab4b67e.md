# Meeting the Minimum Red Hat Linux Hardware Requirements

Red Hat, Inc. publishes general minimum hardware requirements for installing and using its base distribution. For the current release, your PC should have at least a Pentium CPU, 650MB hard drive space, and 64MB RAM for using (and installing) Linux without a graphical interface.

# Using Legacy Hardware

If you have an older PC based on an Intel 486 CPU with only 32MB RAM and a 500MB hard drive (which can be hard to find nowadays), you can install an older version of Red Hat Linux and upgrade to newer software packages from source or by using the rpm command. See Chapter 8, "Managing Software and System Resources," for information using rpm. If you prepare a hard drive in a PC with a different CPU, such as a Pentium, and then install it in a PC with a 486 CPU, you should make sure that a 486-based Linux kernel is installed, or perform a post-install of an appropriate kernel after moving the hard drive.

Installing Red Hat on legacy hardware will be easier if you choose older Pentium-class PCs. Such computers can be purchased at a fraction of their original cost, and can easily handle mundane but useful tasks. Some of the tasks suitable for older hardware include

+   - Acting as a firewall, router, or gateway
- Audio jukebox and music file storage server
- Handling electronic mail
- Hosting a remote printer and providing remote printing services
- Network font server
- Providing FTP server capture
- Remote logging capture
- Secondary network-attached backup server
- Serving as an Intranet (internal LAN) Web server
- Unattended dial-up gateway, voice mailbox, or fax machine
- Use as a "thin client" workstation for basic desktop tasks

Older PCs can handle any task that does not require a CPU with a lot of horsepower. To get the most out of your hardware, don't install any more software than required (a good idea in any case, especially if you're building a server).
