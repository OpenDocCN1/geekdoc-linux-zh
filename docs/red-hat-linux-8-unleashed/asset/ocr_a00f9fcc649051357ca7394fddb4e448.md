# Configuring Controllerless Modems for Laptops

Other issues regarding modems focus on Red Linux notebook users with laptops using controllerless modems. These modems use proprietary software to emulate a hardware controller. Despite the release of binary-only drivers to enable use of some of these modems, these devices remain the bane of Linux notebook and desktop users.

You might find support for Lucifer (but not Lucifer AMR), Motorola SM56-type, the IBM Mwave, and Conexant HSF (not HCF) controllers. At the time of this writing, there was no support for 3COM or U. Robotics controllerless modems. For links to drivers and more information, browse to the Linux Winmodem page at http://www.linnmodems.org.
