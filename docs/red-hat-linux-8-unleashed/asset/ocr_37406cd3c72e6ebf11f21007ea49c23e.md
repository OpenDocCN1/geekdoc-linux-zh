# Scanner Applications for Red Linux

The use of a scanner provides a wealth of options to enhance productivity. You can manipulate scanned images in graphics applications like the GIMP, OpenDraw, and Contour and then print them, for them, or embed them in a word document. You can scan paper documents for archival purposes, or process them with optical character recognition (OCR) software to translate images into words that can be edited in a text editor or word processor. Red Hat has the Xsane (see Figure 25.12) and Kooka (see Figure 25.13) applications to assist you with scanning.

Scanner support is provided by Scanners Access Easy (SANE). If your scanner is supported, it is listed on the SANE support page, at http://www.mostang.com/sane/ane-backends.html.

The development version of SANE supports scanners that aren't supported in the regular version. If your scanner is supported only in the development version, you need to download and compile the CVS version of SANE. That's a complex operation that is suitable for advanced Linux users only, and it is beyond the scope of this chapter. For information on that process, see the CVS-RCS HOWTO Document for Linux (Source Code Control System) at http://www.tld.org/HOWTO/CVS-RCS-HOWTO.html.
