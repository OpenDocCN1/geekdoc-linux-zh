# The Parted Command

In the past, Red Hat used a partition editor during its installation process named Disk Druid; the underlying code for Disk Druid has been replaced by GParted (also known simply as parted, the name of the command itself). Gnupart is the GNU partition editor and a very powerful utility. You used to create, delete, move, resize, and copy ext2 and FAT32 partitions. Although Gnupart displays a GUI interface during the installation process, it is also a console utility. It can be used from the command line or through scripts with sfdisk.

# Creating the Filesystem on the Partitioned Disk

After you have partitioned the disk for a specific filesystem, you can create the filesystem on it. In the DOS world, this two-part process is described by DOS as low-level formatting (creating the partitions and partition table) and formatting (creating the filesystem). In this section, you will learn to create a filesystem in Linux.

An unformatted storage device (a floppy disk, hard disk drive, or removable media) typically arrives to you with a low-level format, which has been done with a tool such as fdisk or superformat. Although the disk might have a boot block and partition information, it typically lacks the file structure needed for a filesystem.
