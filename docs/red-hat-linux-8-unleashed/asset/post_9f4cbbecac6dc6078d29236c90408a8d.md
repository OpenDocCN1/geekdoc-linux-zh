Begin by copying the scripts from the /usr/share/doc/ppp*/scripts directory to the
/etc/ppp directory, like so:

```
# cp -ar /usr/share/doc/ppp*/scripts/ppp-o* /etc/ppp
```

Using your favorite text editor, edit the ppp script (making sure to disable the line
wrapping returns within your editor—and line wrapping
inserts carries that cause these scripts to stop working) and change the first
entries to reflect your ISP's phone number and your username and password, like this:

```
TELEPHONE=555-1212      # The phone number for the connection
ACCOUNT=george               # The account name for login (as 'George Burns')
PASSWORD=gracie             # The password for this account (and 'Gracie Allen')
LOCAL_IP=0.0.0.0              # The Local IP address if known. Dynamic = 0.0.0.0
```

Change the values for TELEPHONE, ACCOUNT, and PASSWORD, substituting your ISP's
number and your username and password. Change the LOCAL_IP entry to an IP address
only if your ISP provides for one. (Dynamic IPs are typical of dial-up accounts).
Otherwise, leave the entry blank. Next, scroll through the script until you find the
dial setup, which can look like this:

```
exec /usr/sbin/pppd debug log mode crtsuts /dev/ttyS0 3840 \
asyncmap 20A0000 escape FF kde LOCAL_IP:$REMOTE_IP \
noipdefault netmask NETMASK default count DIALER_SCRIPT
```

These lines (actually a single script line) contain modem options for the chat script
in the ppp-on-dialer script and will start the pppd daemon on your computer after establishing a connection. Using a text editor, change the modem device (/dev/ttyS0 in
example) to /dev/modem.

> CAUTION
You can use /dev/modem only if the Red Hat's kudzu utility has recognized and configured the
computer's modem. (If /dev/modem does not exist, use the ln command to create the file as
symbolic link pointing to the correct serial port.) To create the symlink (from /dev/ttyS2, for
example)

```
# ln -s /dev/ttyS0 /dev/modem
```

If your modem was not automatically detected and the /dev/modem link configured, it is possible you have a software modem, also known as a WinModem or HSF modem (see earlier)

115200 or 57600. When finished, save the file.

# Configuring Dial-up Internet Access

Next, use the chmod command to make these scripts executable, like this:

```
# chmod +x /etc/ppp/ppp-o*
```

To debug or check the progress of your modem connection, dialing, and connection to your ISP, monitor the syslog messages by using the tail command with its -f “loop forever” option, like this:

```
# tail -f /var/log/messages
```

To connect to your ISP, run the ppp-on script:

```
# /etc/ppp/ppp-on
```

Use the ppp-off script to stop the PPP connection like so:

```
# /etc/ppp/ppp-off
```

You can also move the ppp-on and ppp-off scripts to a recognized $PATH, such as /usr/local/bin. Enabling the use of these scripts by normal users will entail changing permissions of the serial port and other files (which can be a security problem because unauthorized users can access it).

# Using the Internet Configuration Wizard

The Red Hat Internet Configuration Wizard can be used to set up any of the many kinds of network connections that exist. The example in this section uses the wizard to configure a modem connection, the most commonly encountered network connection. The other types, including xDSL, Ethernet, or Wireless connections, are configured essentially the same manner.

From the System Tool menu, select the Internet Configuration Wizard to configure a new internet connection. The Select Device Type screen, shown in Figure 15.1, is displayed. Red Hat refers to the type of connections as “Device Types”.

Select the Modem connection item in the Device Type list, and then click the Forward button. The Wizard will probe for an installed or attached modem and display default configuration values (such as the recognized serial port, speed, modem, and so on). You can keep the default configuration or modify the modem’s settings. When finished, click the Forward button to continue. You’ll then be asked to select a provider, designate a name for the service, enter your ISP’s phone number, and enter your username and password on the remote system, as shown in Figure 15.2. Additional special settings are also included for PPP users in various countries with different ISPs as shown by the country flags on the left.
