# Count the Number of Connections

/usr/bin/ftpcount counts the number of connected users to the FTP server and
maximum number of users allowed. This same information is found at the end of the
output for the ftpwho command. This command only takes one parameter, -V, which
displays the same output as in Listing 18.6.

```
# ftpcount
Service class all             4 users (no maximum)
```

# Use /usr/sbin/ftpshift to Schedule FTP Server Downtime

As with any server administration, it is good practice to let users of the FTP
server know about upcoming outages, when the server will be updated, and other relevant
site information. The ftpshift command allows the administrator to let the FTP server do\much of this automatically.

The ftpshift command allows the administrator to take the FTP server down at a specific
time based on some parameters passed to it. The format of the command is as follows
d documented in the ftpshift man page:

```
ftpshift [-V ] [ -l min ] [ -d min ] time [ warning-message ... ]
```
