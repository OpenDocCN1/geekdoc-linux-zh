# The dvrecord Command

Red Hat includes the dvrecord application to create DVDs if you have a DVD burner. The dvrecord command is used only from the command line and operates in a similar fashion to edrecord. In fact, it can be used in place of cdrecord because it works with os9660 filesystems as well as the Orange Book standard for DVD media.

# Sound and Music

Linux has a reputation of lacking good support for sound and multimedia applications in general. Certainly, there is less sound card support than in Microsoft Windows. (However, Microsoft no longer supports the Microsoft Sound Card, but Linux users still enjoy support for it, no doubt to tweak the folks in Redmond.) Unix has always had good multimedia support as David Taylor, UNIX author and guru, points out:

> The original graphics work for computers was done by Evans & Sutherland on UNIX systems. The innovations at MIT's Media Lab were done on UNIX workstations. In 1985, we at HP Labs were creating sophisticated multimedia work environments on UNIX workstations, so Unix is never multimedia than suggested. Limitations in Linux support doesn't mean UNIX has the same limitations. I think it was a matter of logistics, with hundreds of sound cards and thousands of possible PC configurations.

That last sentence sums it quite well. Unix has a limited range of hardware to support; Linux has hundreds of sound cards. Sound card device driver support has been long lacking from manufacturers, and there's still no single standard for the sound subsystem in Linux. The dominant system, OSS (Open Source Sound) is a combination of freedom and proprietary drivers. A new system, the Advanced Linux Sound Architecture (ALSA), is still under development.

In this section, you learn about sound cards, sound file formats, and the sound applications provided by Red Hat.

# Sound Cards

Red Hat Linux 8.0 supports a wide variety of sound hardware and software. The sound card is one of the most critical sound components in any PC, and two models compete for prominence in today's market:

+   - OSS, the Open Sound System, which offers free and commercial drivers
- ALSA, the Advanced Linux Sound Architecture, which is entirely open source

Red Hat uses OSS because OSS is the sound architecture for the 2.4 series kernels (the 2.6 series kernel is likely to use ALSA).
