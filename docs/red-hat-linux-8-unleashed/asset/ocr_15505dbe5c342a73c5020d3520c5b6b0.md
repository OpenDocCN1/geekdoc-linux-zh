# CHAPTER 15 Internet Connectivity

Many modems can use a modem string such ATE10QV1&C1&S0S0=1&W to auto answer calls, but this varies by modem manufacturer. Some terminal monitors, as ugetty, have configuration files that automatically set the modem for a particular serial port and use an entry in /etc/initab that looks like this:

```
3:2345:respawn:/sbin/ugetty ttyS1 38400 vt100
```

This entry assumes that a modem is attached to /dev/ttyS1.
Other commands, as agetty, can directly configure a modem port and use an /etc/initab, like this:

```
3:2345:respawn:/usr/local/bin/agetty -w -I 'ATE00Q1&D2&C1S0=1\015' \
115200 ttyS1 vt100
```

If you'd prefer to use the mgetty command, which is included with Red Hat Linux, as have an entry like this:

```
3:2345:respawn:/sbin/mgetty -n 1 -D ttyS1
```

You will also need to edit the file name /etc/mgetty+sendfax/mgetty.config to set connection speeds and whether data, fax, or data-only or fax-only connections are to be allowed.

> Red Hat Linux Voice Messaging
If you're the fortunate owner of a vgetty-supported voice modem, such as the Elsa MicroLink S6K Internet modem, you can download, install, and use the vgetty command to monitor the modem and have your system provide data, and fax services. Edit the file /etc/mgetty+sendfax/voice.conf, create your answering voice messages in /var/spool/voice/messages, and then use a vgetty /etc/initab entry such as S0:2345:respawn:/sbin/vgetty ttyS2

In order to host your outgoing message, you'll need to use the wavopvf and pvfspeed commands to convert your voice sound into formats used by the modem, like this:

+   # wavopvf myymessage.wav myymessage.pvf
# pvfspeed -s 7200 myymessage.pvf | pvftorm Elsa 4 > myymessage.rmd

To play your outgoing message (which should be stored in /var/spool/voice/messages with the name stamp.rmd), use the following command line:

```
# rmdtopvf myymessage.rmd | pvfspeed -s 8000 | pvftobasic /dev/audio
```

This technique can be used to listen to any messages left by callers (which ends up in the /var/spool/voice/incoming directory).

Browse to http://alpha.greenie.net/vgetty/ to download vgetty and its documentation.
