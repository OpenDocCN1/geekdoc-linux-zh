# Related Red Hat and Linux Commands

You'll use these commands to install, configure, and manage FTP services in Red Hat Linux:
ftp—A text-based interactive FTP command
ftcopy—Copy directories and files from an FTP server
ftpcp—Retrieve remote data from FTP server, but do not overwrite existing local files
ftpd—The FTP server daemon
gftp—A graphical FTP client for GNOME
wuftpd—A KDE utility used to edit the wu-ftp ftppass file
l1ftp—An advanced text-based FTP program
cftftp—A sophisticated, text-based FTP program
redhat-config-services—Red Hat's service GUI admin utility
sftp—Secure file transfer program
simpleftp—An FTP client written in Perl
smbclient—Samba FTP client to access SMB/CIFS resources on servers
vsftpd—The Very Secure FTP daemon
webcam—A Webcam-oriented FTP client included with xawt
