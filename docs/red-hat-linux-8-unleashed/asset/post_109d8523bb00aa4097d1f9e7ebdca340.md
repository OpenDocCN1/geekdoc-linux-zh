
You can use the following three configuration tools, among others, to create a working XF86Config file:

- redhat-config-xfree86—This is Red Hat's graphical configuration tool, which launches an X session to create an XF86Config file.
- xf86config—This is a text-based configuration tool that does not require an X session.
- XFree86—This can create a skeletal working configuration.

The sections that follow discuss how to use each of these software tools to create a working XF86Config file:

## Configuring X with the redhat-config-xfree86 Client

You can use the redhat-config-xfree86 client to create or update an XF86Config file. By begin, or root, start the client from the command line, like this:

```bash
# redhat-config-xfree86
```

The screen clears, and redhat-config-xfree86 attempts to start an X session. If this client during an X session, its main window appears, as shown in Figure 6.1.

## Using XFree86 to Create an XF86Config File

You use the xf86config command, which is part of the XFree86 server, to create a basic XF86Config file. The xf86config command works through the console or inside an X11 terminal. To begin, as root, start xf86config, like this:

```bash
# xf86config
```

After you press Enter, you see introductory text that looks like this:

This program will create a basic XF86Config file, based on menu selections you make.

The XF86Config file usually resides in /usr/X11R/etc/X11 or /etc/X11. A sample XF86Config file is supplied with XFree86; it is configured for a standard VGA card and monitor with 640x480 resolution. This program will ask for a pathname when it is ready to write the file.

You can either take the sample XF86Config as a base and edit it for your configuration, or let this program produce a base XF86Config file for your configuration and fine-tune it.

Before continuing with this program, make sure you know what video card you have, and preferably also the chipset and the amount of video memory on your video card. SuperProbe may be able to help with this.

Press enter to continue, or ctrl-c to abort.

> NOTE
> The SuperProbe command mentioned in the opening xf86config screen is no longer needed or included with XFree86 4.0 and later versions.

You press Enter to start the configuration process. You are asked to select the pointer's protocol:

First specify a mouse protocol type. Choose one from the following list:

If you have a two-button mouse, it is most likely of type 1, and if you have a three-button mouse, it can probably support both protocol 1 and 2. There are two main varieties of the latter type: mice with a switch to select the protocol, and that default to 1 and require a button to be held at boot-time to select protocol 2. Some mice can be convinced to do 2 by sending a special sequence to the serial port (see the ClearDTR/ClearRTS options).

Enter a protocol number:

The PC might support a PS/2 mouse, but USB pointing devices are becoming increasingly popular. > NOTE
> You can use a PS/2 definition in your configuration file even if you have a two-button USB mouse. Just ensure that /dev/mouse is a symbolic link to /dev/input/mice and that the mouse is configured properly for the console (using Red Hat's mouseconfig command).

Next, you type a number that matches your system's pointing device and press Enter. You are then asked if you want three-button emulation:

If your mouse has only two buttons, it is recommended that you enable Emulate3Buttons.

Please answer the following question with either 'y' or 'n'.
Do you want to enable Emulate3Buttons?

Three-button emulation is extremely important because the middle mouse button (which is emulated by simultaneously pressing the left and right buttons) is used for pasting text or graphics. The choice of mouse to use X is also a hardware consideration, especially if you are ordering hundreds of workstations. The best approach is to order three-button or two-button pointers for users.
