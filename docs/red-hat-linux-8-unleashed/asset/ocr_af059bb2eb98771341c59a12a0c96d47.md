# CHAPTER 4 Post-Installation Configuration

If you are experiencing X11 problems during installation, skip the configuration. Boot Red Hat Linux, and then look for a document under
/usr/X11R6/lib/X11/ directory with information about your computer's graphics card.
Various README files with specifics about a particular chipset are included with XFree86.
You can also check the XFree86 Web site (the "Reference" section at the end of this chapter) for any errata, changes, updates, or new releases.

> TIP
Before running any X configuration tool, be sure to copy or back up any working XF886Config configuration file.

# Configuring Sound Devices

Most workstation users want to have a configured sound card working with Red Hat Linux. Sound support is generally configured when Red Hat Linux first boots (or during the install process if the sound card is recognized). This section shows how to configure sound for Red Hat using the text-based sndconfig command, or the graphical redhat config.
If you cannot configure sound for your system using Red Hat's software, you can turn to software from the Advanced Linux Sound Architecture (ALSA) project at http://www.alsa-project.org. Download and install the ALSA driver, libraries, and utilities using RPM packages, or build and install ALSA from source according to directions at the Web site.
Using alternative sound software can be helpful. For example, users running Red Hat on a new Atom via EPIA mini-ITX motherboard (which uses the 8233 VIA audio chipset) will need to use ALSA in order use, as the included drivers will not work. One way to do this is to first download the compressed source-code archives:

```
```

alsa-driver-0.9.0rc5.tar.bz2
alsa-lib-0.9.0rc5.tar.bz2
alsa-utils-0.9.0rc5.tar.bz2
```
```

The archives have been decompressed:

```
# tar xjvf alsa*driver*; tar xjvf alsa*lib*; tar xjvf alsa*utils*
```

Next, navigate to the resulting ALSA driver directory, and then configure, build, and install the driver:

```
# cd alsa*driver*; ./configure; make; make install
```
