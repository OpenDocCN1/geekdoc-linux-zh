# Configuring Display Graphics

When you add or change the graphics devices used in your system after the initial Red Hat
Linux installation, you must configure those devices. Adding or changing the display for a
Red Hat system can be as simple as swapping out the monitor or replacing a display
adapter. For Intel-based PCs, this can mean switching from the use of the motherboard's
buid-in display adapter (if available)—by inserting a graphics card in the Accelerated
Graphics Port (AGP) or Peripheral Component Interface (PCI) slot—or adding a
second display adapter to support the use of multiple display monitors for X sessions.

Although a display monitor can be easily disconnected or reattached to a running Red Hat
Linux system, insertion or removal of a graphics display adapter will require downtime—nthe bane of academic, enterprise, corporate, or small-business operations.

# Red Hat Linux and KVM

Keyboard, video, and mouse (KVM) hardware provides the capability to quickly switch display
and control banks of individual computers using a single monitor, keyboard, and
pointer. This provides efficient organization and use of computers in larger installa-
s, allows a single operator to perform system administration tasks without physically
moving to each computer.

Using KVM can bring other costs. Eliminating the need for some monitors reduces the
am of storage required for the system and the amount of energy used to run and cool the
system.

Red Hat Linux administrators should be careful to research any hardware compatibilityefore implementing KVM. Many switches work regardless of the operating system and
application used; however, take time to research what keyboard and pointer devices you'll need
to use (such as whether I/O, PS/2, or USB devices may be required). Some KVM switches
come with some of an embedded operating system (even Linux) that provides hardware
emulation; these switches will have power requirements.

Other issues to include cable construction, compatibility, and distance limitations, hard-
ware software switch configuration (such as providing push-button or key-combination switch-\ing), and scalability.

If you use X and want to control the graphical desktops of remote hosts on your network, the
x2 and X2vnc clients. Although not included with Red Hat, you can find clients at
http://ftp.digital.com/pub/Digital/SRC/x2x/ and http://www.hubbe.net/~hubbe/
x2vnc.html.

Smaller Red-hat users can avoid the use of KVM switching hardware by leverage-\aging graphical networking features of X11, multiple terminal sessions, and virtual desktops.
Text-based virtual consoles can also be used on servers or workstations that do not use X11 to
manage computers or to receive messages from various services (such as email
or Web services or the kernel). See Chapter 5, "First Steps to Linux," to learn more
using virtual consoles. If you are limited to a single remote session window, the screen
command, a text-based window manager that allows a single terminal session to manage several
shells. For additional information on using virtual consoles, see http://www.tlp.org/HOWTO/
Keyboard-and-Console-HOWTO.html.
