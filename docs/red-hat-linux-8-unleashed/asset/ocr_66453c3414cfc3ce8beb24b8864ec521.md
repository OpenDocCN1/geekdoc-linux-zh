Driver(none) at the end of the seventh line tells us that the driver wasn't found in the lookup table. Because we have the "magic" vendor ID and device ID, we can attempt to load the driver manually with

```
# /sbin/modprobe scanner vendor=0x04a9 product=0x2206
```
