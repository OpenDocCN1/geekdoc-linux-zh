Red Hat Linux supports Internet connections and the use of Internet resources in many ways. You'll find a wealth of Internet-related software included with this book's version of Red Hat Linux, and you can download hundreds of additional free utilities from a variety of sources. To use them, you'll need a working Internet connection.

In this chapter, you'll learn how to set up an Internet connection in Red Hat Linux using Point-to-Point Protocol (PPP) as well as other connection methods, including Digital Subscriber Line (DSL) and cable modem service.

Although many experienced Red Hat Linux users continue to use manual scripts to establish their Internet connectivity, new users and experienced system administrators alike will find Red Hat's graphical network configuration interface, the Internet Connection Wizard, which much easier to use. You learn how to use the Internet Connection Wizard in this chapter, as well as how to quickly configure Red Hat Linux to provide dial-in PPP support. The chapter also describes how to use Penguin's DSL (Digital Subscriber Line) utilities for managing connectivity through a cable modem connection.

In this section of the chapter, you learn what to ask about and how to use the information.
