# Basilisk II

Basilisk II is a free Macintosh emulator that provides pre-PowerPC CPU emulation of the Mac OS in order to run selected Mac software. A copy of earlier versions of the Mac OS and a binary of an Apple Macintosh computer Read-Only Memory (ROM) chip are required to run Basilisk II. The emulator can use several versions of Mac OS, up to version 8.1.

Basilisk II supports various Mac displays, sound, floppy diskette, CD-ROM, and other drivers. Red Hat Linux does not support the latest Extended Hierarchical File System (HFS+), but does support the earlier "regular" HFS.

Basilisk II also supports Ethernet, serial, SCSI, and Apple Desktop Bus (ADB) drivers. You configure settings in Basilisk using a graphical editor; you can edit preferences in a file named .basilisk_ii_prefs in your home directory. You can use this to specify various hard drive, floppy diskette, video resolution, window geometry, color depth, sound, keyboard, mouse, network, and server or printer-port settings, along with the location of required files, allocated memory, and boot mode.

You have to download and build the Basilisk II emulator from scratch. You'll find the source code on the Basilisk II home page ("Reference" later) in a compressed archive or RPM package. An excellent Web reference for Basilisk II issues and installation is http://www.karning.net/-mhoffman/basiliskII/system753_tutorial/linux/.

# Remote Computer Operating

Modern operating systems support remote management and access tools; Linux is no exception. Many of the legacy UNIX commands, such as rep and telnet, have been superseded by more capable—and more secure—clients. This section provides an overview and introduction to the use of VNC (Virtual Network Computing). VNC is a popular networking serving client included in your Red Hat CD-ROMs. It allows you to display a window on your computer that is the desktop of a remote computer. Your local mouse and keyboard control the remote computer as if you were sitting in front of it. In this section, we examine VNC and show you how to install and run it, as well as some useful variations of VNC.

# Virtual Network Computing

Virtual Network Computing, or VNC, is a virtual network and management application manufactured by AT&T Laboratories in Cambridge, England. VNC includes the vserver and vncviewer components; you use VNC to access remote desktops on networked computers. The host must run a native version of vnc, but you can run it anywhere. Free downloadable versions of VNC are available for dozens of different operating systems, includinging, PalmOS, and PocketPC.
