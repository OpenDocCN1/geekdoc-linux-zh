# Session Message Block Printing

Printing to an SMB printer requires Samba, along with its utilities such as the smclient and associated smbprint utility. You can use the software included with Red Hat to print to a shared printer on a Windows network or set up a printer attached to your Red Hat system as an SMB printer. For details about Samba, see Chapter 13, "Network Connectivity." This section describes how to create a local printer to be able to print to a remote printer using SMB.

Setting up an SMB, or shared printer is usually accomplished under Windows operating systems through configuration settings using the Control Panel's Network device. After enabling printer sharing, reboot the computer. In My Computer, Printers folder, right-click the name/icon of the printer you want to share and select Sharing from the pop-up menu. Set the Shared As item; then enter a descriptive name, such as HP400, and a password.

You must enter a name and password in order to configure the printer when running Linux. You will also need to know the printer's group name, IP address, printer name, and the username and password on hand. To find this information, choose Start, Settings, Printers, and right-click on the shared printer's listing in the window, and choose Properties from the pop-up window. As before, create a local printer queue, assigning it a name, and then select Printer in the Set Queue Name and Type dialog box. Click the Forward button, and then enter the required information, as shown in Figure 12-11.

Create a printer queue with characteristics that match the remote printer. For example, if the remote printer is an HP 400 Deskjet, select the driver listed for that device in your configuration.) Do not forget to save and restart after creating or editing a local or remote printer queue. The new entry in /etc/printcap might look like this:

```
hp400deskjet:
:mx#0:\n:sd=/var/spool/hp400deskjet:\n:af=/var/spool/lpd/hp400deskjet/hp400deskjet.acct:\n:sh:
```
