# Graphic Interface Configuration of Apache

Some of Apache's basic behavior can be configured using Red Hat's redhat-config-http, a GUI tool for the X Window System. This can provide an easy way to configure settings such as Apache's user and group name, location of PID and process locks files, or perform settings (such as maximum number of connections), without manually editing configuration files.

> Red Hat advises that if you use redhat-config-http you shouldn't try to manually edit the http.conf file. Manual changes will be removed when Apache is restarted or you use redhat-config-http!

Launch this client using your X desktop panel's Server Settings' HTTP Server menu item, or from the command line of an X terminal window like this

+   $ redhat-config-http &

After you press Enter, you'll be asked to type the root password. You'll then see the main client window shown in Figure 16.2.

In the Main tab, you can set the server name, indicate where to send email to the Webmaster, and set the port that Apache will use. If you want, you can also configure specific virtual hosts to listen on different ports.

# Configuring Virtual Host Properties

In the Virtual Hosts tab, you can configure the properties of each virtual host. The Name box contains a list of all virtual hosts operating in Apache. Open the Virtual Hosts Properties dialog by highlighting the name of a virtual host in the Name box and clicking the Edit button at the right of the tab (see Figure 16.3). Use the General Options item in this dialog box to configure basic virtual host settings.

Click the Site Configuration listing in the General Options list of this dialog box to set defaults such as which files are loaded by default when no files are specified (the default is index.*) in the URL.
