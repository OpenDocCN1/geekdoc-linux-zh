**FIGURE 3.22** Create a user account for yourself with Red Hat Linux.

Create a user account for yourself and any additional users of the system. Users are
commonly assigned a username, traditionally consisting of the first letter of a person's
first name and the last name. For example, Cathy Taaffee would have a username of
ctaulbee. Enter the new password twice. If you create a user, but do not enter a pass-
word for the user, that will not be able to log in after installation. As the root
operator, will then have to log in and create the user's password. See Chapter 9,
“Managing Users,” for details on managing users with Red Hat Linux.
