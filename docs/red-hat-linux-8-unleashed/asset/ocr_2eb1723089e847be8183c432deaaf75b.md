# CHAPTER 27 Using Emulators and Other Cross-Platform Tools in Red Hat Linux

# Configuring VMware

The tarball installation leads you into the configuration phase. If you used the rpm package, you need to start the configuration phase manually with

# vmware-config.pl

> NOTE
nYou'll need to have the source for the Linux kernel and the gcc compiler installed on your system in order to build the VMware support modules or the configuration phase will fail. See Chapter 24 for details on how to do that.

The installer will build various kernel modules to support VMware during operation. You'll be asked about networking. Select the type of networking as described in the next paragraph if you will be able to use any networking connectivity from within VMware and the operating system installed in it.

Note that you can type help to get more information about networking, which, if enabled, supports bridging of virtual systems to a hardwired LAN or a "host-only" configuration. Bridging allows the guest operating system to appear as if it were running on a separate computer from the host (our Linux computer, in this case). Host-only sets up a network between the guest operating system and the host, and other computers on the network cannot communicate with the guest operating system.

The VMware-specific services will be started on your Red Hat Linux system from a script in /etc/init.d/vmware. The specific services depend on how you configured networking during the VMware setup phase. You can stop or restart VMware services by using that same vmware script in the odd chance that the software interferes with other services as networking or printing.

# Starting a VMware Session

VMware is generally started during an X session from the command line of a terminal like this:

```
$ vmware
```

The command supports several options—the most useful of which are -y to diagnose disk problems and -Y to allow repairs to the virtual disks. You can configure VMware from the GUI.

The first time you launch VMware, the VMware window will appear and request a license number. You can then start the Configuration Wizard by opening the File menu and selecting Wizard. A series of dialog boxes will appear (the first one is shown in Figure 27.7) that are used to select a guest operating system and prepare a filesystem on your hard drive for installation of the guest operating system.
