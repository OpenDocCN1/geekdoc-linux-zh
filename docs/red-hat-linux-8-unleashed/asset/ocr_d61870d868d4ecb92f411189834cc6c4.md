File Transfer Protocol (FTP) was once considered the primary method to transfer files over a network from computer. FTP is still heavily used today, although many graphical FTP clients supplement the original text-based interface command. As computers have evolved, so has FTP, and Red Hat Linux now includes many ways with to use a graphical user interface, or GUI, to transfer files using the FTP protocol.

This chapter contains an overview of the available FTP software-included with Red Hat Linux, with some details concerning its set up, configuration, and use of FTP-specific clients. Red Hat includes two FTP software packages and a number of associated programs you can use to transfer files with the FTP protocol. The following sections provide an overview of how to choose, install, and configure an FTP server.

# FTP Servers

FTP uses a client/server model. As a client, FTP accesses a server, and as a server, FTP provides access to files or storage. Just about every computer platform available software written to allow a computer to act as an FTP server, but Red Hat Linux provides the average user the ability to do this without paying hefty licensing fees and without regard for client usage limitations.
