# Compiling the Kernel

If you want to update the kernel from new source code you have downloaded, or you have applied a patch to add new functionality or hardware support, you'll need to compile and install a new kernel to actually use that new functionality. Compiling the kernel involves translating the kernel's contents from human-readable code to binary format. Installing involves putting all the compiled files where they belong in /boot and /lib.

The process of compiling the kernel is almost completely automated by the make utility as is the process of installing. By providing the necessary arguments and following the steps covered next, you can recompile and install a custom kernel for your use.

+   1. Verify your bootdisk for the old kernel to be able to reboot your system in case something went wrong with the new kernel.

> CAUTION

Before making any changes to your current, working kernel, make sure that you have a backup copy on a floppy disk. This will allow you to boot into your system with a new kernel in case something went wrong during configuration. The command to do this is follows:

```
# mkbootdisk --device /dev/fd0 -uname -r
```

This assumes that your floppy drive is /dev/fd0. (Here's a good shell script tip: the character tells the shell to execute within 'first and then returns that output as part of the input of the mkbootdisk command.) On this machine, the result is

```
# mkbootdisk --device /dev/fd0 2.4.19-7.80
```

This command won't be echoed to your screen, but it is what the system will execute.
