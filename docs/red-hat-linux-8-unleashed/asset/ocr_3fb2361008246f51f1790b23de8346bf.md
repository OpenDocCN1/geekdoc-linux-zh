# Editing Printer Settings

You use the redhat-config-printer tool to edit the newly defined printers on your Red Hat Linux system. To edit the printer settings, highlight the printer's listing in the Red Hat Printer Config dialog box, and then click on the toolbar's Edit button. The Edit Queue dialog appears, as shown in Figure 12.7.

The first tab in this dialog box enables you to assign an alias or synonym for the name of the new printer. This allows you to use different printer names when printing, such as when you use the lpr command (discussed in the section "Console-based Print Commands") later in this chapter).

Aliases are listed along with the printer's name in the /etc/printcap entry, and might look like this:

```
lp|sammie:\n  :sh:\n  :ml=0:\
```
