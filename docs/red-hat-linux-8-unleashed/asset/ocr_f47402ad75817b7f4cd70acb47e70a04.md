# Using the GUI-Based Configuration Tool

Red Hat's developers have added GUIs to many text-only, command-line-based administration tools as Linux has matured. These tools provide an easier-to-use interface and don't require memorization or lookup of command-line options. Red Hat provides its own Service Configuration tool for the control and administration of services (see Figure 7.3). You can access the GUI menu selection from the System Settings menu, and then select Services.

FIGURE 7.3 The new Service Configuration tool allows you to select runlevels to edit, displays all the available services, and provides an explanation of what the service does.

The KDE desktop provides a service management tool as well: ksys, or SysV-Init Editor, provides the same end result as the Red Hat tool. The SysV-Init Editor isn't in the menu tree, however, so you need to launch it from a virtual terminal.
