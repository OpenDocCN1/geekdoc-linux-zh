> NOTE
Red Hat Linux finds more than one network interface installed on your computer, you might be asked to configure a second Ethernet device. This might be the case, for if you are installing Red Hat on a computer that will serve as a gateway or firewall. If you configure more than one Ethernet device, the device named eth0 will be the first interface when you start Red Hat.

After making your selection, press Enter and you can then type in your system's host-name, such as lucky, as shown in Figure 3.17.
