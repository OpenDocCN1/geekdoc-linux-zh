# Other Office and Productivity Tools Included with Red Hat Linux

The /usr/bin/fax script provides a simple command-line interface to Efax that allows you to send, receive, view, or print faxes without a GUI. You can view the commands available for faxing by entering # fax help at the command line. You can use the # fax make command to turn a text file into a fax file. Red Hat also provides the ef command-line application to convert formats from fax, text, bitmap and grayscale formats, if necessary.

> NOTE
You can find more information on the workings of fax and Efax in the man pages and at the Efax home page, at http://casas2.ece.ucbc.ca/efax/

Efax is designed for a single user; the other fax applications mentioned here can handle entire offices. If you have one fax user, Efax is likely to be too simple for your needs.

The traditional Linux way to handle faxes is with mgetty+sendfax. The mgetty+sendfax application involves getty, a modem-aware getty (getty is an application that interacts with a terminal, known as a "tty", from its Teletype heritage). Unfortunately, the configuration of mgetty+sendfax is complex and beyond the scope of this chapter. You can find complete documentation for the installed version of mgetty+sendfax from the CD-ROMs that accompany this book, under /user/share/doc/mgetty-1.1.28. The files also include a directory of instructions on how to set up voice mail by using the vty command, which is discussed in more detail in Chapter 15, "Internet Connectivity.\ The documentation for getty can be found at http://alpha.greenie.net/mgetty/, which includes a HOWTO and a FAQ.

HylaFax is a management application that can utilize fax modems distributed around a network and serve a large number of users due to its client/server architecture. A FAQ is maintained by the HylaFax Web site at http://www.hylafax.org/HylaFAQ/index.html. RPM packages for Red Hat are available from the HylaFax FTP site at ftp://ftp.hylafax.org/binary/linux/redhat/RPMS/i386/, as are a HOWTO, setup information, and a FAQ.

# Other Office and Productivity Tools Included with Red Hat Linux

Red Hat Linux 8.0 is distributed with a number of other useful productivity tools. Under the Accessories menu, you can find a calculator, a Web-based dictionary (see Figure 25.17), and a word translator. You can also open the Graphics menu to access a PDF viewer.
