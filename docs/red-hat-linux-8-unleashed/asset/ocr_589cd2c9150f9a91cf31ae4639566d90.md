# Working with the Red Hat Linux System

To gain the full benefits of this universal layout, you must know how Red Hat Linux is organized, what the contents of files and directories on your system, and where files and software should be installed. Understanding the Linux system is part of learning how to administer and use Linux.

# Viewing the Red Hat Linux File System

Look at the layout of a Red Hat Linux system by using the list directory contents, ls, like this:

```
$ ls /\nbin dev home lib misc opt root tftpboot usr
boot etc initrd lastfound+found mnt proc sbin tmp var
```

> NOTE
 section provides an overview of the Red Hat file system. You might find fewer or more directories discussed here in your own system. When some software packages are installed, they create new directories. Updating software packages might also remove or change the name of some directories. See Chapter 8, "Managing Software and System Resources," for more information on installing, upgrading, or removing software from your Red Hat system.

To get a more detailed picture, use the tree command to show the root or base directory layout, along with associated subdirectories, like this (note that your system's /usr/src directory might be somewhat different, depending on the version of Red Hat you have installed or if you have updated Red Hat with a new kernel, and that not all subdirectories are listed):

```
$ tree -dx /
|-- bin
|-- boot
|-- dev
|-- etc
|   |-- X11
|   |   -- cron.d
|   |   -- ppp
|   |-- rc.d
|   |   -- ssh
|   |   -- sysconfig
|-- home
|   |-- bball
|-- lib
|   |-- modules
```
