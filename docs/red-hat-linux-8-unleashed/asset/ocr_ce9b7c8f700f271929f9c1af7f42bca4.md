smoothly through the installation process on a Red Hat Linux 8.0 system (this list assumes that you are performing an installation as the root user):

+   - You need to create the directory /home/twiki.
- The installation instructions mention the file /etc/httpd/httpd.conf. For Red Hat 8.0, this file is found at /etc/httpd/httpd.conf. You simply copy and paste the entries shown in the example supplied by the downloaded instructions.
- The path to Perl for Red Hat 8.0 is /usr/bin/perl.
- Red Hat 8.0 runs CGI scripts as the apache user, not the root user, as assumed in the default TWIKI installation. You can browse to http://localhost/twiki/bin/testenv and read the warnings that are displayed onscreen. This is a special script that is run on your local machine to help you diagnose any problems with your installation. The messages should be specific to your installation, and any warning should be accompanied by a suggestion on how to fix the problem.

The TWIKI installation directions suggest setting permissions and changing ownership. For Red Hat 8.0, the permissions are set correctly, but the ownership are wrong. To change the ownership, follow the steps below (after each step, you should reload http://localhost/twiki/bin/testenv page to check your progress):

+   1. Change the ownership of apache, but change the ownership of /home/twiki/templates back to root:

```bash
chgrp -r apache /home/httpd
chgrp -r root /home/twiki/templates
```

+   2. /home/httpd/twiki/lib/TWiki.cfg to reflect your own domain name instead of http://your.domain.com.

+   3. Change the ownership of the RCS repository files to the user apache:

```bash
# cd /home/twiki/data
# perl -pi -e 's/:noby:apache/:*V'
```

After you complete the installation, you should have a "virgin" TWIKI installation that you can view at http://localhost/twiki/bin/view. With any application, you need to further configure this file so that it suits your needs. The TWIKI documentation explains the many configuration options and processes that are available to you. This document is included in the TWIKI installation you just completed.
