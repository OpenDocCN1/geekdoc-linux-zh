# Managing the Filesystem

A Linux filesystem is more than just a format for your hard drive or floppy disk and not just the disk itself or the formatting process. The filesystem is the structure and organization of data on a data storage device. In other words, it's how your data is organized in files, disk drives, and removable media.

In this chapter, you learn about the structure of the filesystem and how to work with it. You also learn some background and history about the filesystems that Linux use. This chapter also provides some basic information about the filesystem's default settings, as well as how you can adapt those to better match your system and its needs. At the end of the chapter, you learn how to build a test filesystem so that you can safely explore all the filesystem commands without risking any damage to your system.

# The Red Hat Linux Filesystem Basics

The Red Hat Linux filesystem, like UNIX systems, is used for storing not only data, but also metadata (information about the files, such who the file owner, what permissions are associated with the file, and other file attributes).

The Red Hat Linux filesystem is much complex than most people care to know about. Its features are patterned after features found on commercial UNIX systems, as well as those included in research or experimental filesystems. In this section of the chapter, you learn what the Red Hat Linux filesystem is, how it's structured, and how you work with it in the management of the Red Hat Linux system—both as a user and a system administrator.
