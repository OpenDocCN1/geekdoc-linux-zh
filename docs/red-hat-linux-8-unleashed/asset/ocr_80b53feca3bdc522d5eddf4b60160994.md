hdd: DVDROM 10X, ATAPI CD/DVD-ROM drive

If you have a DVD-capable device, you generally should have a symbolic link named /dev/vdvd that points to your device because many DVD clients, such as xine or vlc, will look for /dev/vdvd by default. If you have a CDRW drive, the Red Hat Linux installer will insert your kernel argument into your boot loader's configuration file that specifies of the ide-scsi kernel. For example,

```
append="hd=ide-scsi"
```

A similar entry in the boot loader /etc/grub.conf file would look like this:
kernel vmlinuz-2.4.18-38 root=/dev/hda2 hdb=ide-scsi

The first CDRW drive will be assigned to the device /dev/scd0 (although it might still be initially recognized while booting as an IDE device), with subsequent drives assigned to /dev/scd1, and so on. In order to initialize your drive for use, the following modules should be loaded:

| Size Used Not tainted |
| sg | 30244 0 (autoclean) |
| sr_mod | 15192 0 (autoclean) |
| cdrom | 27872 0 (autoclean) [sr_mod] |
| ide-scsi | 8128 0 |
| scsi_mod | 96572 2 [sr_mod_ide-scsi] |

Look for kernel message output regarding the device such as this:

Attached scsi CD-ROM sr0 at scsi0, channel 0, id 0, lun 0
sr0: scsi3-mmc drive: 0/32x write/rw/form2 cda tray
Uniform CD-ROM driver Revision: 3.12

Your ATAPI-based CDRW drive will then work as a SCSI device under emulation, and the symbolic link /dev/cdrom should point to /dev/scd0. You can also use the cdrecord command (included with Red Hat's multimedia packages) to acquire SCSI information about your drive for use during burning operation like this:

```
# cdrecord-scanbus

 Using libscg version 'shilly-0.5'

0,0,0 0) 'HL-DT-ST' 'RW/DVD GCC-4120B' '2.01' Removable CD-ROM
```
