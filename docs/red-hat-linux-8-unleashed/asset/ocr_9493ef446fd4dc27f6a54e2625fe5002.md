# **The Kdat Backup Tool**

The Kdat utility is easy to use GUI backup tool. Kdat is found in the System Tools under the Extras menu in the main menu. Kdat provides a graphical interface under the tar program and uses KDE to implement drag-and-drop functionality. It is intended to be used with a tape drive and is of no use if you don't have one. One to Kdat, you need to create a Backup Profile, which is a description of the archive and a list of the files it will contain. Kdat keeps a record of these profiles, making it easier to search your archives and locate specific files to restore. Figure 11.3 shows us the process of creating a profile.
