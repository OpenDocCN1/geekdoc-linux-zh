# CAUTION

Pine is not written to be secure, and it has a history of security problems. Although all known problems have been fixed at the time of this writing, it is likely that many more will surface. Because of this, it makes little sense to choose Pine over other MUAs, especially if you are a new user. If you decide to use Pine or make it available to your users, make sure that you keep up with the latest versions of Pine. News and information regarding Pine can be found on the Web site located at http://www.washington.edu/pine.

Pine also does not come with a GPL software license, so it might not be included in future Hat Releases.

# Mutt

Mutt is a relatively new command-line mail client that is rapidly becoming popular with users. It is called Mutt because it is known as the "mongrel of email clients," in that it attempts to combine the best features of several other clients such as Elm and Pine. Mutt is an extremely feature-rich email client, although it isn't as easy to use as Pine. It is however, more secure than Pine. Figure 19.3 shows the Mutt interface.

The latest versions of Mutt, as well as news and information about it, are available at http://www.mutt.org. Mutt is proved to be a bug free program, but its authors believe it might have a few "fleas"—thankfully, these are free.

The systemwide configuration file is kept at /etc/Muttrc, and each user can have his own /.muttrc files. Mutt configuration is often an evolving process as each user attempts to configure this feature-rich mail client.
