# User Considerations

Humans are creatures of habit. So it can be hard to transition a workforce, customer base, or other community to a new environment. The Red Hat desktop, however, provides a friendly and familiar interface with menus and icons that new users can readily learn and put to work.

Part of the migration process can involve addressing user concerns, especially if Linux will take over the desktop. Red Hat can be deployed in stages to make the migration process a bit easier, but the issue of user training will need to be addressed early on. This is especially true if users will be required to develop new skills or be aware of any caveats when Linux (such as deleting all files in one's home directory). Although Red Hat can be configured to provide a “turn-key” desktop in which only graphical applications (such as a web browser, organizer, or word processor) can be used, some users will want and need to learn more about Linux.

You can turn to formal Linux training from commercial vendors. System administrators can also get training directly from Red Hat (go to http://www.redhat.com/training). For other issues concerning Linux in larger computing environments, browse to Linux Vegstas's Linux Enterprise Computing pages at http://linas.org/linux/.
