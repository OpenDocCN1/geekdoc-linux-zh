Since, the rpm command has the prime feature of Red's unique software management system, which is based on the concept of pristine sources, or the capability to use a single, initial archive of program's source code not only to build packages for different systems, but also to track versions. With the release of Red 8.0 (Psyche) in 2002, Red offered a slightly updated graphical interface for its venerable RPM application.

In addition to improving the package management of early software management scripts, RPM version 4.1 introduced software features designed to ease the task of building software for different platforms from a single set of source-code files. Changes can be tracked and kept outside a developer's initial source code and multiple packages can be built from scratch and installed at the same time -at the same time, RPM also verifies installation dependencies. Additional features, such as a checksum and GNU Privacy Guard (GPG) signatures, enable binary software packages to be safely distributed without the fear of virus infection or the inclusion of Trojan code.

The rpm command uses the RPM system to remove, (erase), upgrade, verify, and build software known as .rpm files. These archives, or packages, contain package identification (a signature), checksums (mathematically derived values), and any archive of the software, either in source or binary format. .rpm package also contains quite a bit of additional information, such as a name, a version, and basic description, and can include pre- post-installation scripts used for installation, erasure, and upgrading.

The RPM database installed on your computer keeps track of which versions of which packages are installed. ### Using RPM for Software Management

The primary database of installed software is contained in the file named Packages. As you can see from the preceding example, this database can grow as large as 33MB (and perhaps larger) if you perform a full installation of Red Hat Linux (more than 3GB of software). After you install Red Hat Linux, rpm and related commands will use this directory for software management operations.

## Command-Line and Graphical RPM Clients

As a Red Hat Linux administrator, you'll use the rpm command or one of your graphical clients to perform one of five basic tasks. These operations, which must be conducted by the root operator, include the following:

- Installing new software
- Erasing or removing outdated or unneeded packages
- Upgrading an installed software package
- Querying to get information about a software package
- Verifying the installation or integrity of a package installation

The rpm command has more than 60 different command-line options, but its administrative functions can be grouped according the previous five types of action. Graphical RPM clients provide easy-to-use interfaces to these operations. As a system administrator, you'll have a choice between using a graphical interface and using rpm's various command-line options. The general format of an rpm command is

```
# rpm option packagen
```

The basic options look like this:

- -e- Erase (removes) the selected package or packages.

> RPM is for Programmers Remember that RPM was not created only to provide an easy to use administrative tool, but also as a developer's tool for use in multi-platform source-code package management. Programmers using rpm for development and distribution will use its -b or build option, along with a myriad of additional command-line flags. ## RPM on the graphical Command Line

Because the new graphical RPM client can only install and uninstall RPM packages (for now—more functionality is promised), you will still end up administering RPM packages from the command line. You can perform all the basic rpm operations using the rpm command from the command line. This section gives you an introduction to performing those operations. It also provides examples of how to install, verify, query, remove, and upgrade a software package.

The most common rpm operation is software installation. Using rpm is an easy way to keep track of installed software, and can be used to quickly remove undesired packages. The -i option, along with the full or partial name (using expressions) of a software package, to install software with rpm. For example, to install the pine email package, use the rpm command like this:

```
# rpm -ivh pine-4.44-7.i386.rpm
Preparing...
########################################### [100%]
1:pine ############################################ [100%]
```
