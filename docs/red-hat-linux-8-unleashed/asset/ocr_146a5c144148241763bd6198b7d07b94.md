# Getting Started with Linux/C++ Programming

Linux is C and C++ programmers because of gcc and its suite of related software-development tools, as gdb, autoconf, and make. Complex C programs may have dozens or hundreds of separate object files that are created during the process. One, more, or all these (compiled) steps may be carried out automatically by the gcc compiler system, which is run by the make utility according to project rules contained in a makefile. After a program is compiled, it can be executed over and over without recompilation.

Writing C programs for Linux requires you to understand C syntax, have some understanding of how to interface with the Linux kernel (using one or more of 1,100 different functions, known as system calls), and how to use Linux programming tools such as gcc and make. You'll learn about each of these concepts and processes in this chapter.

To get started, you must make sure you have installed all the necessary software development packages (perhaps using the redhat-config-packages client; see Chapter 8, "Managing Software and System Resources") to support your project. Installation of basic development software requires around 90MB of hard drive space. If you plan to build programs for the Linux kernel, you need the Kernel development packages and an additional 134MB of storage space.

Developing programs for the X Window System requires installation of about 40MB of software libraries, programming support files, and documentation. If you want to build GNOME clients, you need more than 60MB of additional space. If you intend to develop programs for KDE, you should plan on reserving 220MB or so of your hard drive to store KDE development software. Don't forget that you need lots of space for temporary files when you're building programs, as many intermediate files will be created during your programming sessions.

You should also become familiar with a good text editor. Although GNUists use the emacs environment to write, edit, and compile programs, many other developers do just fine with an editor as vi or pico for editing source and then use the command line to run tools.

When programming for GNOME or KDE, you might find it most convenient to use a graphical development project manager, such as GNOME's Glade (the GTK+ User Interface Builder) or KDE's Kdevel (the KDE development environment). These clients allow you to prototype an application with graphical tools, which frees you to concentrate on your client's interface. You can use either to automatically generate all necessary project and source code files for skeletal applications. See the section "Graphical Development Tools," later in this chapter, for more information.
