# Avoiding Printer-Support Problems

Troubleshooting printer problems can be frustrating, especially if you find that your brand new printer is not working properly with Linux. First, keep in mind that nearly all printers on the market today work with Linux. However, there are some vendors with higher batting averages in the game of supporting Linux. If you can read a scorecard, browse to http://www.linuxprinting.org/vendors.html.

# All-in-One (Print/Fax/Scan) Devices

Problematic printers, or printing devices that may or not work with Red Hat include multi-function, or all-in-one type printers that combine scanning, faxing, and printing services. You would be well-advised to research any planned purchase, and avoid any vendor unwilling to support Linux with or development information.

One shining in the field of Linux support for multi-function printers is Hewlett Packard/Compaq's (whatever it is called nowadays) support of the HP Linux project at http://hoj.sourceforge.net/. Printing and scanning is supported on many models, with fax support in development.

# Using USB and Legacy Printers

Other problems can arise because of a lack of a printer's USB vendor and device information—a problem shared by some USB scanners under Linux. For information regarding USB printer support, you can check with the Linux printing folks (at the URL in the start of this section) or with the Linux project at http://www.linux-usb.org.

Many newer printers require Universal Serial Bus (USB), excellent support still for legacy parallel-port (IEEE-1284) printers with Linux, allowing sites to continue using older hardware. You can take advantage of Red Hat Linux workarounds to set up printing even if the host computer does not have a traditional parallel port printer or if you want to use a newer USB printer on an older computer.

For example, to host a parallel-port bridge on a USB-only computer, attach the printer to the computer using an inexpensive USB-to-parallel converter. USB-to-parallel converters typically provide a Centronics connector; one end of that connector is plugged in the older printer, whereas the other end is plugged in a USB connector. The USB connector is then plugged in your hub, desktop, or notebook USB port. On the other hand, you can use an add-PCI card to add USB support for printing (and other devices) if the legacy computer does not have a built-in USB. Most PCI interface cards add at two ports, and devices can be chained via a hub.

The following commands help you manage printing services in Red Hat Linux:

+   - 1pq—View print queues (pending print jobs)
