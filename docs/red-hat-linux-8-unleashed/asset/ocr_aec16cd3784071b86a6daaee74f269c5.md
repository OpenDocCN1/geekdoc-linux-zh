When configuring a kernel from scratch, click on the button Code Maturity Level Options, then continue to click the Next button in each subsection window to proceed through all the kernel configuration choices. When you have selected all options, the main menu is again displayed. The buttons on the lower right of the main menu are for saving and loading configurations. Their functions are self-explanatory. If you are upgrading kernels from a previous release, it isn't necessary to go through the entire configuration from scratch. You can use the directive **oldconfig**. It is the text interface that make **config** uses and it is non-interactive.

For simplicity's sake,during this brisk walk, we will assume that you are using **make xconfig**. Prior to this, we also assume that you have completed steps 1–5 in our kernel compilation checklist shown previously.

As you learned in the preceding section, you compile the kernel using make xconfig by making choices in several configuration subsection windows. This subsection window contains specific kernel options. With hundreds of choices, the kernel is daunting to configure. We can't really offer you detailed descriptions of options to choose because your configuration will match your system and setup.
