# Configuring and Using CD, DVD, and CDRW Drives

Next, look for relevant device information from the Linux kernel using the dmesg command:
ohci1394:$Revision: 1.80 $ Ben Collins <bcollins@debian.org>
PCI: Found IRQ 10 for device 00:0b.0
PCI: Sharing IRQ 10 on 00:07.5
ohci1394.0: OHCI-1394 1.0 (PCI): IRQ=[10] MMIO=[ee000000-ee000800] \ 
Max Packet=[2048]
eeee1394: Device added node 2:1023, GUID 0d0d010500007d8e
eee1394: sbp2: Driver forced to serialize I/O (serialize_io = 1)
eee1394: sbp2: Node 2:1023: Max speed [S400] - Max payload [2048]
scsi11: IEEE-1394 SBP-2 protocol driver
Vendor: TEAC Model: CD-W2BE Rev: 1.1A
Type: CD-ROM ANSI SCSI revision: 02

In this example, the IEEE 1394 drivers have recognized a CDRW drive (which will be assigned to /dev/sdc consider another CDRW is also present on the system). You might also find that the sbp2 kernel module has loaded:

| Module | Size Used by | tainted |
| sbp2 | 14400 | 0 |
| ohci1394 | 15872 | 0 (unused) |
| ieee1394 | 25768 | 0 [sbp2 ohci1394] |

> Red Hat should recognize any installed IEEE 1394 hardware in your PC during installation. Depending on your computer's hardware, you might find an entry in /etc/modules.conf as alias ieee1394-controller ohci1394.

Again, use the cdrecord command and its -scanbus option to obtain information needed to use the drive under SCSI emulation:
