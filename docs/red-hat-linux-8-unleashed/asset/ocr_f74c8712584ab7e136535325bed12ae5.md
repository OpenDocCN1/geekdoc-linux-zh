Wine is still in emulator active development, but it has been used in several commercial projects. Red Hat provides Wine version 20020605 (the number represents the year, month, and date of the development stage) in rpm format.

# Preparing to Run Wine

You can elect to emulator install Wine during the Red Hat Linux installation, or you can install it later using the rpm command or the Packages GUI as detailed in Chapter 8, "Managing Software and System Resources."

> NOTE
nYou can always obtain the most current version of Wine from http://www.winehq.com. There, you can find the Wine source code and precompiled binaries as well as documentation. If you have problems with Wine, remember that Google is your only friend on the Internet.

A startup script named wine (under the /etc/rc.d/init.directory) enables the automatic matching of Windows programs during GNOME or KDE X session. You can launch the programs using the command line or clicking icons. The script creates entries in /proc/sys/ to associate the Windows library with .exe files (by adding C:\Windows to their PATH) and enables the Red Hat Linux kernel to execute these files. When Wine is enabled, files such as C:\Windows\notepad.exe can be run from the command line like this:

```
$ notepad
```

You can find out if Wine supports your favorite application by going to http://appdb.winehq.org/ or browsing a database of nearly 800 Windows programs supported by Wine.

# Configuring Wine

The Wine behaves is governed by its configuration file. If you need to customize Wine for your own use (using a text editor), this file is referred to that customization take place. If you want to understand Wine, you will need to understand the content and the layout of the configuration file. The systemwide configuration file is located in /etc/wine.reg; the other files-/etc/wine.systemreg and /etc/wine.userreg—are the Windows Registry files. Regular user settings will be stored in ~/.wine/config, along with user-specific Registry settings. Older versions of Wine are referred to the configuration file as /etc/wine.conf.
