# CHAPTER 1 Introducing Red Linux

In addition to a personal and professional Linux distribution, the company also offers advanced versions for specific mid-sized and enterprise-level computing needs. High-performance enhancements such as hardware-tweaked Linux kernels, failover and load-balancing clustering, and integrated Java support make Red Linux a great choice for mission-critical applications.

# The Red Hat Linux Distribution on this Book's CDs

A free version of Red Hat Linux, known as a Publisher's Edition, is on the CD-ROMs included with this book. This distribution comprises the Linux kernel, installation utilities, thousands of pages of documentation, several thousand fonts, a comprehensive graphical networking interface, and several thousand individual commands and clients.

The Red Hat Linux distribution on this book's CD is the latest Red Hat Linux for IntelPCs. There are versions of Red Hat Linux for other processors and platforms, including AMD's upcoming 64-bit Hammer, Intel's Itanium, HP/Compaq's Alpha, Sun Microsystems' Scalable Processor Architecture (SPARC), and IBM's zSeries mainframe computers (such as the 32-bit S/90 and 64-bit z900).

> NOTE
The source code to the Red Hat Linux kernel and programs, in the form of more than 21 million lines of C and 5 million lines of C++ code is available for download from a variety of locations on the Internet. One good place to start is http://www.redhat.com/download/mirror.html.

A comprehensive suite of programming tools, including compilers, interpreters, and report-generation utilities are also included in the base distribution.

Red Hat, Inc. markets several Linux distributions, such as its Professional Edition, Advanced Server (using PostgreSQL), and Stronghold Enterprise Web Server (using Apache). Differences between the commercial versions on the amount and type of software included, along with the duration and type of technical support structure, ranging from 30 days to one year via the Web, networking, or phone.

> About Red Hat, Inc.
Red Hat, Inc. is also one of the world's foremost open source development houses, and returns nearly all of its development efforts back to the Linux development community.
​  
The company has been involved in many different open source and GNU GPL projects, such as the Apache Web server, the glibc software libraries, the GNU Network Object Model Environment (GNOME), various GNU software tools and packages, the Linux kernel and device drivers, the PostgreSQL database system, and the Red Hat Package Manager (RPM).
​
