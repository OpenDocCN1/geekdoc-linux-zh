# Creating the Print Queue

The Red Hat Linux redhat-config-printer tool walks you through a process to create a new print queue, which effectively defines a new printer on your system. To begin, click the New toolbar button in redhat-config-printer's main window. An Add New Print Queue configuration dialog box appears, as shown in Figure 12.1.

![](bbox=[0.301, 0.218, 0.696, 0.448])

**FIGURE 12.1** Click the New toolbar button to start the configuration of a new printer for your system; then click the Next to begin.

Click the Forward button; the Set the Print Queue Name and Type dialog box appears, as shown in Figure 12.2. Type the name of the printer in the Queue name text box, and then click an option to select the type of printer you are adding. You can configure a local, remote, Windows, Nestle, or HP JetDirect print server (an intelligent, remotely managed network application supporting print spooling and multiple printer queues). When you've selected a Print Queue type, click Forward.

![](bbox=[0.301, 0.653, 0.696, 0.878])

**FIGURE 12.2** Enter a name for your new printer, then click to select a type of printer for your system and click the Next button.
