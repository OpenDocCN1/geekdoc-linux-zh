You can also make a copy of a CD. It isn't necessary to have a second CD to do this; KOnCD will make the image and store it temporarily. When you click the Copy CD button from the main screen, the dialog shown in Figure 26.5 appears. Choose your options, and then click Start to begin making the copy.

For creating CDs, KOnCD offers options to include and exclude directories, exclude files, and others we customize the CD.

Use the Data Size indicator to determine whether your CD can hold the amount of data you're attempting to copy it. In the example shown in Figure 26.6, we have inadvertently selected too much data to fit on a CD. When that happens, the program issues a warning message when you click the Start button; then you can eliminate files to reduce the size of the material to be copied. Automatically writing to multiple CDs would be a nice option to have in KOnCD.
