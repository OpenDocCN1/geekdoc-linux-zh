# # Copying Files Using mc

The Midnight Commander is a command-line file manager that is useful for copying, moving, and archiving files and directories. The Midnight Commander has a look and feel similar to the Norton Commander of DOS fame. By executing mc at a shell prompt, a dual-pane view of the files is displayed. It contains drop-down menus and function keys to manipulate files. It also uses its own file system, allowing it to mount FTP directories and display the contents of tar files, DEB files, and RPM files as well as extract files from them. As if that weren't enough, it contains a File Ultimate filesystem for ext2/3 partitions. The font chosen for Red Hat makes the display of mc ugly when used in atty (as opposed to xterm), but doesn't affect its performance.

Figure 11.4 shows a shot of the default dual-panel display. Pressing the F9 key drops down the menu, and pressing F1 displays the Help file. a “feature” in the default GNOME terminal intercepts the F10 key used to edit mc, so use Shift+F10 to install. The configuration files are well documented, and it would appear easily to extend the functionality of mc for your system. It is an excellent choice for file management in servers not running X.
