+   - /usr/X11R/bin—This is the location of the X server and various X clients. (Note that all X clients require active sessions.)

The main components required for an active local X session will be installed on your Red Hat system if you choose to use a graphical desktop. These components are the X server, miscellaneous fonts, a terminal client (that is, a program that provides access to a shell prompt), and a client known as a *window manager*. Window managers, which are discussed later in this chapter (see the section Selecting and Using X Window Managers), administer onscreen displays, including overlapping and tiling windows, command buttons, bars, and other decorations and features.

# Elements of the XF86Config File

The single most important file to launch X on a desktop is the XF86Config configuration file. This text file is configured during Red Hat Linux installation, and is usually found the /etc/x11 directory. It contains hardware descriptions, and specifications needed by the XFree server in order to work with the computer's graphics card and display monitor.

You'll be better equipped to troubleshoot configuration problems and remove features of the X session if you understand the contents of the XF86Config file. The components, or sections, of XF86Config specify the X session, or server layout, along with paths for files used by the server, server options, optional support modules to load, descriptions of the mouse and keyboard, graphics device, monitor, screen layout, and video modes to use. Of the 12 sections of an XF86Config file, these are the essential components:

+   - ServerLayout—Defines the display, defines one or more screen layouts, and names input devices

+   - Files—Defines the location of colors, fonts, or port number of the font server
