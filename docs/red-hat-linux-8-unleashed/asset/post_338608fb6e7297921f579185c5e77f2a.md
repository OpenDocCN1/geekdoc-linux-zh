## Securing Your Network

The only way to make sure that your system is secure is to lock the system in a room and never ever turn it on. This isn't practical, but it's true.

As long as anyone has access to your system, whether physical or over a network, there is the threat that information stored on the network can be compromised. The more access given, the higher the threat. If your network is connected to the Internet, the threat of breaking into your computer is very real.

Not even a home computer that uses a cable modem, regular modem, or DSL to access the Internet is safe. As DSL and cable modems become more common, the home computer has become a favorite target for script kiddies to use as stepping stones to get larger corporate networks. This not only means that the private information on your computer can be accessed at will, but also, if a script kiddie uses your computer to launch a cyber attack or a virus, your computer can be taken as evidence.

If this information causes you concern, it should. Although there is no way to stop a serious cracker who is intent on getting into your computer or network, there are ways to make it harder for him and to warn you when he does. This section discusses system weak points and highlights a few security tools included with Red Hat Linux that you can to use right away.

## Using lokkit for Firewalling

First and foremost, use either a hardware-based or software-based firewall on the computer connected to the Internet. Red Hat Linux includes a basic console-based graphical firewall utility named lokkit (or, if you use X, the gnome-lokkit client) that can be used to implement selective or restrictive policies regarding what services may access your computer and LAN.

Using lokkit is a fast way to implement a simple packet-filtering ruleset or text file with filtering rules used to accept or reject TCP and UDP packets flowing through your host's Ethernet or designated device, such as eth0 or ppp0. The rules are created on-the-fly and implemented immediately. A short configuration file, named iptables, is saved under the /etc/sysconfig directory. Run lokkit as root at the command line like so:

```bash
# lokkit
```

Once you are finished, use the OK button in the Customize dialog and then in the main dialog. Your firewall rules will be implemented immediately in memory.

## Red Hat Linux and Firewalling

Red Hat Linux also supports the older, but popular iptchains packet-filtering software, which can be used to construct effective firewall rules on Red Hat Linux firewalls, gateways, and workstations. Red Hat Linux also supports the more capable iptables, NetFilter system, which offers additional controls and logging facilities for building rules or filtering instructions.
