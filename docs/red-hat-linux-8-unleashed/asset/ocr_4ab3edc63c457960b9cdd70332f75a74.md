# CHAPTER 2 Preparing to Install Red Hat Linux

# CAUTION

Notebook users should be careful when partitioning. Many notebooks use-a special partition equal to the size of install RAM in order to perform suspend-to-disk or other hibernation operations. Always examine your computer's initial partitioning scheme if configuring a dual-boot system, and leave the special partition alone. One way around this problem is to use a software approach as outlined at http://falcon.sch.bme.hu/~seasons/swsusp.html.

# Hosting Parts of the Linux Filesystem on Separate Partitions

The Red Hat installer can be used to automatically create a partition scheme according to the class of install. Your specific partitioning scheme will depend on how Red Hat will be used! However, on a system being designed for expansion, greater capacity, or the capability to host additional software or users, you can use separate partitions to host various parts of the Linux file system. Some candidates for these separate partitions include

+   * /home—Users will store hundreds upon hundreds of megabytes of data under their directories. This is important data, perhaps even more than the system itself. Using a separate partition (on a different volume) to store this user data helps make the data easier to find and it segregates user and system data. You'll have to decide ahead of how much storage to allocate to users. For a single workstation, you should reserve several gigabytes of storage.

+   * /opt—The home directory for additional software packages, this directory can have its own partition or remote filesystem. Red Hat does not populate this directory, but it may be used by other software packages you install on your Red Hat system. One gigabyte of storage should be adequate, depending on applications to be installed.

+   * /tmp—This directory can be used as temporary storage by users, especially if disk quotas are erased; such as, it could be placed on its own partition. This directory can be as small as 100MB.

+   * /usr—This directory holds only the software on a Red Hat system and can become quite large if additional software is added, especially on a workstation configuration. Using a separate partition can make sense, and a full install of Red Hat will require at least 4GB.

+   * /var—Placing this directory (or perhaps some of its subdirectories) on a separate partition can be a good idea, especially security logs, mail, and print spool-taking place under this tree. You should reserve at least one gigabyte of storage for /var, especially if using Red Hat as a print server (as spooled documents will reside under /var/spool).
