# Posting to Usenet

If some portion of your job requires periodic postings to Usenet—a FAQ listing, for example—the following Perl program can automate the process for you. In the sample code, the posted text is read from a text file, but your input can come from anywhere.

The program in Listing 23.8 uses the Net ::NNTP module, which is a standard of the Perl distribution. You can find more documentation on the Net ::NNTP module by typing perdoc Net::NNTP* at the command line.
