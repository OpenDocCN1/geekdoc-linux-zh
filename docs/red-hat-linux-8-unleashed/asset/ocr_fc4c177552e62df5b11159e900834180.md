# CHAPTER 24 Kernel Module Management

The process that you learned in the earlier section, "Getting the Kernel," you begin
t compile operation by obtaining and unpacking the new kernel code. Now it's time to
verify that your system has the necessary version of tools the kernel requires to compile
 run. This task has been automated with a script called ver_linux, located in the
usr/src/linux-2.4/scripts directory.

Just about every version of operating systems tools used to compile the kernel has a
version argument. The ver_linux script calls all the commands that the kernel relies on
query versions. It formats it into a nice output that is easily compared against
usr/src/linux-2.4/Documentation/Changes file, using a text editor to view the file.

To run the script, navigate to the /usr/src/linux-2.4/scripts directory and then execute
t ver_linux script like this:

```
# sh ./ver_linux
```

The output shown here is from a beta Hat 8.0 installation already running a custom
kernel. Comparing the versions to those in the Changes file, it is apparent that all version
requirements have been met. If any utilities are older than required by the new source
code, download the latest versions from the sites listed in the Changes file, install them
and you'll be ready to get started compiling the kernel.
