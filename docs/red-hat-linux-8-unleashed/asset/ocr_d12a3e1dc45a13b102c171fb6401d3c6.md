# CHAPTER 5 First Steps with Linux

The default shell for most Linux distributions, including Red Hat Linux, the GNU bash or Bourne Again, other shells, such as tcsh, ksh, and zsh are available for use. You can use a different shell by typing its name at the command line. Alternatively, the root operator might assign a user to another shell when she first creates that user account (see “Working as Root,” later in this chapter).

> CAUTION
If you're interested in trying a different shell on Linux, you can change your login shell using the csh command, and make sure that the shell is actually installed on your system. For example, to change your default shell to tcsh, first use the which command to verify that it is installed.

```
$ which tcsh
/bin/tcsh
```

This example shows that the tcsh shell is installed under the /bin directory. The tcsh shell should also be listed in your system's list of approved shells, /etc/shells. Check to make sure it is listed:

```
$ grep tcsh /etc/shells
/bin/tcsh
```

You can also use the csh command -l option to list valid system shells in order to verify that using tcsh is allowed. Because tcsh is installed and listed in /etc/shells, you can then change your shell using the csh command:

```
$ csh
```

Changing shell for winky.
Password:
New shell [/bin/bash]: /bin/ksh
chsh: "/bin/ksh" does not exist.

Note that the csh command will report an error if you enter the name of a shell not installed on your system.

```
$ csh -s /bin/tcsh
Changing shell for winky.
Password:
Shell changed.
```

If you now take a look at /etc/passwd entry, you will see /bin/tcsh as your default shell. The next time you log in, you'll use tcsh.
