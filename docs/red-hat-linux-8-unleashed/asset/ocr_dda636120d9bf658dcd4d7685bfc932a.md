```
# df -h /mnt/image
```

To unmount it, use this:

```
# ummount /mnt/image
```

Make a backup of the image just in case we break the original:

```
# cp /tmp/rhlstest.img *.bak
```

# Using dumpe2fs

You can use the program dumpe2fs to examine the structure of the ext3 filesystem. The program is provided in Red Hat Linux.

The syntax for the command is

```
dumpe2fs [-bfixV] [-ob superblock] [-oB blocksize] device
```

To examine our image filesystem using dumpe2fs, first unmount it, and then use this:

```
dumpe2fs /tmp/rhlstest.img
dumpe2fs 1.27 (8-Mar-2002)

Last mounted on: <available>

```
