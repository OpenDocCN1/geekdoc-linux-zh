# Motherboard-based Hardware

Small factor PCs, thin-clients, notebooks, and embedded devices are part of a growing trend in the PC industry. Manufacturers are cramping more functionality into fewer chips in order to simplify design and lower power requirements. Today, many computers with built-in video graphics, audio chipsets, and network interfaces, along with a host of peripheral support.

Common modern (1996-onward) PC motherboard form factors are designed according to industry-assigned specifications (usually from Intel), and ATX (12x9.6 inches); MicroATX (9.6x9.6 inches); and FlexATX (9x7.5 inches). A newer even smoother motherboard from Via Technologies, is mini-ITX (approximately 6.5x6.5 inches). CPUs used in these motherboards will vary, and have different socket requirements based on chipset pins: Socket 478 for K7-type CPUs (from AMD); Socket 370 for Pentium IIIs and Celeron from Intel, or C3s from VIA; and Socket 478 for Intel’s Pentium 4 (early versions of which used a 423-pin socket). Older socket types are Socket A, Socket 7 (and Super 7); Slot 1, and Slot 2.

# Hardware Requirements

Fortunately, nearly all controllers, bridges, and other chipsets are supported by Linux. Although flaky or unsupported built-in hardware can (usually) be sidestepped by installing a comparable PCI component, cutting-edge notebook users are at the most risk for compatibility problems because internal components are not user-replaceable. Potential pitfalls can be avoided through careful research (vote with your memory for Linux-compatible hardware), or by choosing PCI motherboards with a minimum of features, and then using PCI (Peripheral Component Interconnect) and AGP (Accelerated Graphics Port) cards known to work.

# CPU, Symmetric Multi-Processing (SMP), and Memory Problems

Red Hat supports all Intel-based CPUs. Code is included in the Linux kernel to recognize the CPU type when booting, and then to implement any required fixes for architecture bugs (such as the now-infamous divide-by-zero error). After you install Red Hat, you can rebuild the Linux kernel specifically to support and take advantage of the host PC's CPU. You may not realize improvements in computational speed, but you'll be assured that Linux is crafted for your CPU's architecture, which can help stability and reliability. Details rebuilding the Linux kernel are in Chapter 24. Some of the Intel-based CPUs with specific code include those from Advanced Micro Devices, Transmeta, and VIA Technologies.

The kernel also should automatically recognize and use the amount of installed RAM. The latest Linux kernel should also recognize and map out any memory holes in system memory (perhaps used for video graphics).
