# 保护用户目录内容——/home

Linux 系统上最重要的数据位于 /home 下的用户目录。将系统数据和用户数据分离有助于防止数据丢失并使备份过程更简单。例如，将用户数据存储在从远程计算机挂载的独立文件系统中，可能帮助用户在系统故障时防止数据丢失。
