After a while, Bob Behlendorf and Cliff Stolnick set up a centralized repository of these patches, and the Apache project was born. The project is still composed of a smaller core group of programmers, but anyone is welcome to submit patches to the group for possible inclusion in the code.

There's a surge of interest in the Apache project over the past several years, partially buoyed by a new interest in Open Source on the part of enterprise-level information services. It's also due to crippling security flaws that were found in Microsoft's IIS (Information Information Services) and the software's vulnerabilities to the now-infamous Code Red and Nimda worms. IBM made an early commitment to support and use Apache as the basis for its Web offerings, and has dedicated substantial resources to the project because it made more sense to use an established, proven web server.

In-1999, the Apache Software Foundation was incorporated as a not-for-profit company. A board of directors, who are elected on an annual basis by the ASF members, oversees the company. This company provides a foundation for several different Open Source software development projects, including the Apache Web project.

The best places to find out about Apache are the Apache Group's Web site, http://www.apache.org/, and the Apache Week site, http://www.apacheweek.com/, where you can subscribe to receive Apache Week by email to keep up on the latest developments in the project.

> TIP
You'll find an overview of Apache in its Frequently Asked Questions (FAQ) at http://httpd.apache.org/docs/misc/FAQ.html. In addition to extensive documentation, you'll also find the complete documentation for Apache in the HTML directory of your Apache server. You can access this documentation by looking at http://localhost/manual/index.html on your new Red Hat system with one of the Web browsers installed on your system.

Red Hat with Apache 2.0, and the server named httpd, is included on this book's CD-ROMs. You can obtain the latest version of Apache as an RPM (RPM Package Manager) installation file from Red Hat's FTP server, and you can get the source code from the Apache Web site, and in Linux tradition, build it for yourself.

To determine the version of Apache with your system, use the Web server's -V command-line option like this:

```
$ /usr/sbin/httpd -V
Server version: Apache/2.0.40
```
