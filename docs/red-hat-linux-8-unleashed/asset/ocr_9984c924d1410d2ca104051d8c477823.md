# Creating a Root Password and User Accounts

You're next asked to enter a root operator password, as shown in Figure 3.21. Type in a password, press Enter, and then type it to make sure that it is verified. The password, which is case sensitive, should be at least eight characters (or more) and consist of letters and numbers. Note that the password is not echo back to display. Your root password is important because you will need it to perform any system administration or user management with Red Hat Linux.

> CAUTION
Don't forget your BIOS, boot loader, or root passwords! Some equipment, as notebook computers, might require frequent replacement of motherboard components if the owner forgets the BIOS password. The BIOS settings on desktop PCs can usually be reset via a jumper or removal and insertion of the motherboard battery. If you forget your boot loader password, use a bootdisk (perhaps created during installation as shown later in this chapter) or boot to a rescue mode using your first Red Hat Linux CD-ROM and reset the root password using the passwd command.
