# CHAPTER 18 Secure File Transfer Protocol (FTP) Service

```
# rpm -qa | fgrep ftp | sort
anonftp-4.0-12
ftp-0.17-15
ftpcopy-0.5.1-1
gftp-2.0.13-5
lftp-2.5.2-5
nctftp-3.1.3-6
tftpd-0.29-3
tftpd-server-0.29-3
vsftpd-1.1.0-1
wu-ftpd-2.6.2-8
```

The example listing here might be different for your Red Hat system, depending on what software packages are installed. The package ftp-0.17-15 provides the ftp binary /usr/bin/pftp symlinked to /usr/bin/ftp directory as the corresponding man pages. The anonftp package installs the anonymous FTP directory structure and commands, which is located under the /var/ftp. Other installed packages in this example show additional text-based and graphical FTP clients, the network boot ftpd client and server, and other FTP-based servers (such as vsftpd).

> NOTE
Always check the Red Hat Errata page, http://www.redhat.com/support/errata/, for up-to-date security and bug fixes for all RPM packages.

> TIP
The Computer Emergency Response Team (http://www.cert.org) provides security advisories about current attacks and vulnerabilities on multiple platforms. Checking this site regularly for updates is a must for any site administrator. As a Red Linux administrator (or user), you should also subscribe to Red Hat's announcement lists (see Appendix A, "Red Hat Linux Internet Resources")

To install the wu-ftpd server or daemon in Red Hat Linux, along with the anonymous FTP package, you must select the Server or Custom option during the initial installation process. If you didn't install the FTP server packages at that time, you can install them from the installation CD with root with the rpm -Uvh command:

```
# rpm -Uhv anonftp-4.0-9.i1386.rpm wu-ftpd-2.6.2-5.i1386.rpm
Preparing... ################################# [ 100%]
1:wu-ftpd ################################# [ 50%]
2:anonftp ################################# [ 100%]
```
