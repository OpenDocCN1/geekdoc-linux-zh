After you select a depth, you press Enter to finish the configuration, and you see the following:

I am going to write the XF86Config file now. Make sure you don't accidentally overwrite a previously configured one.

Shall I write it to /etc/X11/XF86Config?

You can save the file by entering y. You can enter n to write the file elsewhere or to write with a different name.

At this point you are done configuring the XF86Config file. However, you might want to examine, edit, or test the file before you use it. You test it by launching XFree86 and using the -xf86 option. Regardless of the configuration tool you used for the XF86Config file, when you start or boot to an X session, the server looks for an XF86Config file to use for launching X in the following locations:

+   /etc/X11
-/usr/X11R6/etc/X11
-/etc
-/usr/X11R6/lib/X11
-/root

Note that the server is able to use a configuration file found under the /root directory only if you start an X session as root (which is advisable only when your PC is not connected to a network or for testing). After you test the XF86Config file, you should copy the resulting XF86Config file to its traditional location, /etc/X11, with the name XF86Config.

> NOTE If you have legacy video cards that are not supported by the current version of XFree86, you can go to http://www.xfree86.org to download XFree86 version 3.3.6. You might then be able to create a working environment on your platform.
