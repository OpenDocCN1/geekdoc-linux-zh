# Managing Users

TIP
To lock a user out of his account, use the command

```
# passwd -l username
```

This prepends a l to the user's encrypted password; the command to reverse the process uses the -u option. This is a more elegant and preferred solution to the problem than the traditional Unix way of manually editing the file.

usermod—This command changes several user attributes. The most commonly used arguments are -s to change the default and -u to change the UID. No changes can be made while the user is logged in or running a process.

chsh—This changes the user's default shell. For Red Hat Linux, the default shell is /bin/bash, known as the Bash, or Bourne Again Shell.

# Adding New Users

The command-line approach to adding this user is actually quite simple and can be accomplished on a single line. In the example shown here, the sysadmin will use the useradd command to add the new user kevin. The commandadduser (a variant found on Unix systems) is a symbolic link to useradd, both commands work the same. In this example we use the -p option to set the password the user requested; we use the -s to set his special shell, and the -u option to specify his UID. If we created a user with the default settings, we would not need to use these options. All we want to do can be accomplished on one line with

```
# useradd kevin -p guitarPlayerR -s /bin/zsh -u 549
```

The sysadmin can also use the graphical interface that Red hat provides, as shown in Figure 9.2. It is accessed as the Users and Groups item from the System Settings menu item. Here, the sysadmin is adding a new user to the system where kevin uses the zsh shell.

These are the steps we used to add the same account as shown in the preceding command, but using the graphical User Manager interface:

+   1. Launch the Red Hat User Manager graphical interface by clicking on the Users and Group menu item from the System Settings menu.

+   2. Click on Add User to bring up the Add User dialog.

+   3. Fill in the form with the appropriate information as described in the first paragraph in this section.

+   4. Click on the drop-down Login Shell menu to select the zsh shell.

+   5. Check the Specify User ID box to permit access to the UID dialog.
