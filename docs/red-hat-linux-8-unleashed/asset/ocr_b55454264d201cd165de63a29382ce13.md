To log in at the text-based prompt, type your username and press Enter. You'll then be prompted for your password. After you press Enter, you'll be at the Linux command line. If you use a graphical login, you can use the shutdown or reboot menus on the screen's dialog box to shut down or reboot your system. To immediately shut down your system from the command line of a text-based session, use the su command and its -c option to run the shutdown command. In addition, use the -h or halt option and the keyword now, or the numeral 0:

```
$ su - c /sbin/ shutdown -h now
```

You can also use

```
$ su -c "/sbin/ shutdown -h 0"
```

You can also use the shutdown command to immediately reboot your computer like this:

```
$ su -c "/sbin/ shutdown -r now"
```

Or, you can use

```
$ su -c "/sbin/ shutdown -r 0"
```
