Start xawtv from the command line

```
$ xawtv &
```

and right-click on it to bring up its Options menu. Adjust the settings to suit your hard-
ware, then run the scantv utility to ferret out all the TV channels available to you; run
scantv like this:

```
$ scantv &
```

The xawtv configuration file details are contained in the man page for xawtvrc.

# Personal Video Records

The best reason to attach a television antenna to your computer, however, is to use the
video card and the computer as a personal video recorder.

The commercial personal video recorder, TiVo, uses Linux running on a PowerPC process-
s to record television programming with a variety of customizations. TiVo has a clearer
interface and wonderful features, including a record/playback buffer, programmed record-
ing and, slow motion, and reverse effects. Red Hat doesn't provide any of the
many applications that attempt to mimic the TiVo functionality on a desktop PC running
Linux. However, several such applications, including DVR, the Linux TV Project, and PVR,
are listed at http://www.exploits.org/v41/.
