# CHAPTER 12 Printing Services

| Name | Description |
| --- | --- |
| lpm | Print queue management utility |
| mpage | PostScript text formatting utility |
| pap | Appletalk-based printer client |
| pbm[2ppa,page,to10x,toepson, tappa,toptx] | Portable bitmap conversion utilities |
| pr | Text formatting command |
| psmandup | Duplex printing utility for non-duplex printers |
| setup | Launch printer configuration tool |
| smbclient | $MB print spooler |
| smprint | $MB print shell script |
| smbspool | $MB printer spooler |
| thinkjetopbm | Portable bitmap to Thinkjet printer conversion utility |

You can use the Ghostscript interpreter to display its built-in printer devices by using the gs interpreter with --help command-line option like this:

```
# gs --help
```

> NOTE
Red Hat has graphical clients you can use to view many different types of documents. For example, to display PostScript documents (including compressed PostScript documents) or PostScript images, use the g client. To display Portable Document Format (PDF) documents, you can use ev or the xpdf viewer.
