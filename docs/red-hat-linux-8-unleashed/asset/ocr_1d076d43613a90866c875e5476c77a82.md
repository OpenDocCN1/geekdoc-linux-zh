This file exports (makes available) /usr/local/ localhost. The mount is read-only (which is good for a directory of binary files that don't get written to). It also allows users on yourself to see the contents of filesystems that may be mounted on /usr/local. The second export mounts /home/kennedy to any host in yourdomain.com. It doesn't allow subsidiary filesystems to be viewed, but you can read and write to the filesystem.

After you have finished with the /etc/exports file, the following command

```
# /usr/sbin/exportsfs -r
```

will export all the filesystems in the /etc/exports file to a list named xtab under /var/lib/nfs directory, which is used as a guide for mounting when a remote computer asks for a directory to export. The -r option to the command reads the /etc/exports file and mounts all the entries. The exportsfs command can also be used to export specific files temporarily. An example using exports to export a file system would be

```
/usr/sbin/exportsfs -o async localhost:/usr/tmp
```

This command will restart /usr/tmp to localhost with the async option.

Make sure to restart the NFS server after making any changes to /etc/exports. If you prefer, you can use Red Hat's redhat-config-nfs graphical client to set up NFS while using the X Window System. Start by clicking the NFS Server menu item on the desktop panel's Server settings menu. You can also start the client from the command line of an X terminal window, like so:

```
$ redhat-config-nfs &
```

After you press Enter, you will be prompted for the root password. Type in the password, click OK, click the Add button, and you'll see the Add NFS Share dialog box, as shown in Figure 13.4.

In the Directory text box, type in a name of a directory to be exported; in the Host(s) text box, type in a hostname or IP address of a remote host that is to be allowed access to the directory. By default, a directory is exported read-only, but you can choose read and write access by clicking either export option in the Basic Permissions area of the dialog box. When finished, click the OK button, click the Apply button, and then use the File menu to quit.

# NFS Client Configuration

To configure your host as an NFS client (to acquire remote files or directories), edit the /etc/fstab file as you would mount any local filesystem. However, instead of using a device name to mount (such as /dev/hda1), remove the remote host and desired filesystem to be imported. For example, one entry might look like this:

| Device Mount Point Type Options Freq Pass |
| yourhost:/usr/local /usr/local nfs nvers=3,ro 0 0 |
