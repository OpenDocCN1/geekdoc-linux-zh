# Iteration Statements

The script outputs the search, and then the sed and tr commands format the output. The result is a simple animation of a constantly updated single line of information:

Link Quality:92/92 Signal level:-11 dBm Noise level:-102 dBm

This technique could also be used to quickly create a graphical monitoring client for X that outputs traffic information and activity about a network interface:

```
#!/bin/sh
rxvt -geometry 75x2 -e \\
bash -c '\\n"while ; do \\n/sbin/ifconfig eth | \\nfgrep 'TX bytes' | \\nt -n '\\r'; \\
done'
```

The simple example uses a bash command-line script (enabled by -c) to repeatedly execute a command line. The command line pipes the output of the ifconfig command through fgrep, which searches ifconfig's output and then pipes a line containing the string "TX bytes" to the tr command. The tr command removes the carriage return at the end of the line to display the information inside an rxvt X11 terminal window, automatically sized by the -geometry option:

RX bytes:4117594780 (3926.8 Mb) TX bytes:4522309677 (431.2 Mb)

Endless loops can be so useful that Linux includes a command that will repeatedly execute a given command line. For example, you can get a quick report about a system's hardware by using the sensors command. But instead of using a shell script to endlessly loop the output, you can use watch -f to repeat the information and provide simple animation:

```
$ watch -sensors -f | cut -c 1-20
```

In pdsh and bash, the following format is used for the while flow control construct:

```
while expression
do
  statements
done
```

In tcsh, the following format is used:

```
while (expression)
  Statements
done
```
