# Red Hat Linux Runlevels

NOTE

Not all Linux distributions may use the same runlevel configurations or runlevel definitions! For example, although Red Hat Linux uses runlevel 3 for a full, console-based multiuser mode, pre-7.1 versions of SuSE Linux defined this system as runlevel 2. Red Hat and SUSE now use the same runlevels to conform to the Linux Standards Base, or LSB. As a system administrator, you should be aware of this issue, especially if you've devised any administrative scripts or tools to deal with system states.

Each runlevel is defined in /etc/initab, and in turn, tells the init command services to start or stop. Although runlevels may have all custom definitions, Red Hat Linux has adopted some standards for runlevels:

+   * Runlevel 0—Known as halt, this runlevel is used to shut down the system.

+   * Runlevel 1—This is a special runlevel, defined as single, which boots Red Linux to a root access prompt where only the root user may log in. It has networking, X, and multiuser access turned off. This is the maintenance or rescue mode. It allows the system administrator to perform work on the system, make backups, or repair configuration or other files.

+   * Runlevel 2—This runlevel is identical to runlevel 3, except that it does not start any networking services.

+   * Runlevel 3—This runlevel dictates that Red Hat Linux is booted to a console, or text-based mode, with networking and multiuser access.

+   * Runlevel 4—This runlevel is undefined, and it can readily be configured to boot Red Hat Linux to a custom system state.

+   * Runlevel 5—This runlevel boots Red Hat Linux to networking, multiuser state with an active X session. This is the most common runlevel for home users who want a graphical interface.

+   * Runlevel 6—This runlevel is used to reboot the system.

TIP

Runlevel 1 is most commonly used to repair filesystems and change the root password on a system when the password has been forgotten (or used when a trespasser with physical access to the machine wants in. Note that physical access is virtually a guarantee of access to your data by an intruder.
