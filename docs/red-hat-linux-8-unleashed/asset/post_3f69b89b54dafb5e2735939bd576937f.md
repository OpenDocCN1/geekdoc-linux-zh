
## Controlling PCMCIA Service

Although PCMCIA cards can be inserted or removed while using Red Hat, be careful while using these cards. For example, do not remove a network card while connected to a remote computer. Don't pull a compact flash card or other storage media card (such as an IBM microdrive) while the card's filesystem is mounted and in—you could corrupt the media's filesystem and experience loss of data.

You can control a PCMCIA device from the command line, and insert and remove the card without physically removing and then inserting the card. The cardctl command is to control PCMCIA service to one or more card slots on your notebook or desktop PC with a PCMCIA adapter. The cardctl command is used to get and print information about an inserted card, suspend or resume power to a card, reset, perform a safe insertion or removal, or to configure a card according to a particular, predefined "scheme" using a network in the office or at home. The format of the command is `cardctl command slot_number (as 0 or 1)`.

For example, if you have inserted a compact flash card, eject the card (after unmounting its filesystem) using the cardctl command and its eject option, along with the card's slot number like this:

```
# cardctl eject 0
```

This can save power when running a notebook. When the card is again needed, you can subsequently "insert" the card like so:

```
# cardctl insert 0
```

## Configuring and Using CD, DVD, and CDRW Drives

Red Hat Linux provides support for a variety of CD and DVD devices and media. This section shows how to determine what device has been assigned to your CD drive and how to get additional drive information if the drive supports recording on optical media.

AT Attachment Packet Interface, or ATAPI IDE-based CD drives, are recognized during installation and work through the ide-cd kernel module. A symbolic link named `/dev/cdrom` will be created and point to your CD's device (perhaps /dev/hdb or /dev/hdc). You can use many types of CD drives with Red Hat, and you can easily replace, add, or upgrade your system to use a new drive. Part of a successful configuration involves the proper installation of the hardware and being able to determine the drive's device when using Linux.

## Checking Drive Assignment

Red Hat Linux recognizes CD and DVD drives upon booting if they're attached to your computer's motherboard with proper cabling and if they're assigned as either master or slave on an IDE channel.

## Configuring and Using CD, DVD, and CDRW Drives

If you have a DVD-capable device, you generally should have a symbolic link named `/dev/cdvd` that points to your device because many clients, such as xine or vlc, will look for `/dev/cdvd` by default. If you have a CDRW drive, the Red Hat Linux installer will insert your kernel argument into your boot loader's configuration file that ide-scsi. For example,

```
append="ide-scsi"
```

A similar entry in the boot loader `/etc/grub.conf` would look like this:

```
kernel vmlinuz-2.4.18 root=/dev/hda db=ide-scsi
```

The first CDRW drive will be assigned to the device `/dev/scd0` (although it might still be initially recognized while booting as IDE device), with subsequent drives assigned to `/dev/scd1`, and so on. In order to initialize your drive for use, the following modules should be loaded:

Look for kernel output regarding the device such as this:

```
Attached scsi sr0 at scsi0, channel 0, lun 0 sr0: scsi-mmc driver: 3.12
```

Your ATAPI-based CDRW drive will then work as a SCSI device, and the symbolic link `/dev/cdrom` should point to `/dev/scd0`. You can also use the `cdrecord` command (included with Red Hat's multimedia packages) to acquire SCSI information about your drive during burning like this:

```
# cdrecord-scan
cdrecord 1.1 (i686-linux-gnu) Copyright (C) 1995-2001 Jörg Schilling Linux driver version: 3.1.22 libscg version:0.5
```

The pertinent information—0,0 in the example (SCSI bus, device ID, and Logical Number, or lun)—can be used during a operation like this:

```
scsi11: IEEE-1394 SBP-2 protocol driver
Vendor: TEAC Model: CD-W2BE Rev: 1.1A
Type: CD-ROM ANSI SCSI revision: 02
```

In this example, a CD-ROM data image named `file_name.img` is created on CDR or CDRW media at a speed of 8, and the new disk will be ejected after the write completed. Red Hat Linux also includes the `dvdrecord` command, which can be used with DVD-R and DVD-RW drives.

## Initializing IEEE1394 Drives

This section provides some basic information that you can use if you attach an IEEE1394 drive to your system. These drives use a high-speed serial interface, better known as Firewire, which supports data transfers more than 30 times faster than the first version of USB (at speeds up to 400Mbps), although USB 2.0 devices are a bit faster.

Linux has supported IEEE1394 since the advent of the 2.4-series kernel, and works with many devices, such as video cameras, VCRs, hard drives, scanners, PCMCIA cards, and CD, DVD, or CDRW drives. The Red Hat Linux installer should recognize most IEEE1394 interface hardware; if so, you will be able to use the device with Linux. Linux IEEE1394 component, the video kernel module, supports more than 120 different digital video cameras. General support exists for many different hard drives and DVD or CDRW drives.

If you install an IEEE1394 interface after Red Hat has been installed, you can initialize your device, such as a CDRW drive, by loading the `ee1394` and `ohci1394` kernel modules like this:

```
# insmod ieee1394
# insmod ohci1394
```
