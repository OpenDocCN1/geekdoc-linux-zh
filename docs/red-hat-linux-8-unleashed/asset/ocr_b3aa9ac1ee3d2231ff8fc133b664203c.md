# The e2fsck Command

This utility checks an ext3 filesystem as well as an ext2 filesystem. Some useful arguments taken from man e2fsck are as follows:

+   -c—Checks for bad blocks and then marks them as bad.
-f—Forces checking on a clean filesystem.
-v—Verbose mode.

# The badblocks Command

Although not a performance tuning per se, the utility badblocks checks a (preferably) unmounted partition for bad blocks. It is not recommended that you run this command by itself, but rather allow it to be called by fsck. It should only be used directly if you specify the block size accurately—don't guess or assume.

The options available for badblocks are detailed in the man page. They allow for very low-level manipulation of the filesystem that is useful for data recovery by filesystem experts or for filesystem hacking, but are beyond the scope of this chapter.

# The noat Option for the mount Command

This is an option for /etc/fstab. When the system doesn't update inode access times on the referenced filesystem, which results in faster access if the files are frequently accessed and you aren't concerned about the last access time information. This is useful for a filesystem containing Usenet News archives, for example.

# Managing Files for Character Devices, Block Devices, and Special Devices

In this section, you learn about special types of files found in Linux. These files represent all the devices on your system and handle all the input and output on your system. You learn how to identify and create them.

If you have installed the kernel documentation, which will contain a text file /usr/src/linux-2.4/Documentation/devices.txt, an excerpt of which reads

```
3 char Pseudo-TTY slaves
0 = /dev/tty0      First PTY slave
1 = /dev/tty1      Second PTY slave

255 = /dev/ttyef  256 PTY slave
```

These are the old-style (BSD) PTY devices; Unix98 devices are on major 136 and above.
