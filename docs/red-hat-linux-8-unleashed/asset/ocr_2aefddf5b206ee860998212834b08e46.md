# Using Wine to Run Windows Programs in Red Hat Linux

> NOTE

It is unlikely that Windows email viruses in emails you open in a Linux mail client will "infect"
your system if you have Windows installed. The self-executing viruses are usually some form of Word
macro written in Visual Basic—they won't run in Wine. If a .exe file containing malicious code\were run in Windows, the worst it could do is affect the fake .dlls. Remove and reinstall
Wine if you suspect a problem; your Wine configuration files will not get "infected" because they
are just text files.

It never hurts to be careful with email attachments at a matter of course.

# Gaming with WineX

Many older DOS and Windows games run well on the standard version of Wine, but the
Wine Project has not emphasized support for Microsoft's Direct3D software, so it does not
support many Windows games. A commercial company, TransGaming
Technologies, has done work on supporting Direct3D in Wine. TransGaming has incorpo-
rated the Loki installer to make installing Windows applications easier, and
they have licensed and included copy-protection code (to permit the use of copy-protection
Windows games CDs) to produce a Windows variant called WineX.

> CAUTION

The default kernel installed with Red Hat 8.0 includes kernel patches added by Red Hat that
degrade the performance of the games Ever and StarCraft. TransGaming Technologies
suggests that you install a plan "vanilla" kernel if you play these games. Installing a "vanilla"
kernel from source code is covered in Chapter 24, "Kernel and Module Management."
TransGaming expects these problems to be solved in futures of Wine.

Wine installs and runs many popular modern Windows 3D games,
including Max Payne, Warcraft III, Diablo 2, and others. In Figure 27.3, a Windows
game is installed in Red Hat. A full list of supported games can be found at
http://www.transgaming.com/searchgame.php.

Wine is not free, and it is far from perfect. Development continues and is supported by a
variant of the Street Performer Protocol, where users contribute money in support of
development as development proceeds, like giving money to a street performer. You
ob obtain the current Wine source code from TransGaming's CVS tree (Concurrent
Versioning System is a method of organizing and managing source code under devel-
ment) by following directions on the TransGaming Web site and agreeing to the
TransGaming license. That source code does not contain the licensed copy-protection
code, although many games will install, they cannot validate the CD-ROM in order to
run. Workarounds for that can be found at http://www.gamecopyworld.com/.
