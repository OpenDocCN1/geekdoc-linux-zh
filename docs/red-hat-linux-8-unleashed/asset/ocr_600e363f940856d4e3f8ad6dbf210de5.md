sawfish is not offered as a choice when you're using switchdex, but you can use it for your next X session by using this command:

$ exec sawfish >$HOME/.xinitrc

This command creates a .xinitrc file in your home directory. You can then start an X session using sawfish by the starttx command. (You delete the .xinitrc file to go back to your switchdex defaults.)

You access menus by pressing the middle mouse button (button 2) in a blank area of the root display. A sample sawfish desktop is shown in Figure 6.10.

The sawfish manager also supports themes, or sets of related relations that can change the appearance of the desktop. Different themes can sometimes be used to improve viewing and readability of the desktop, such as when using a PC in a room with very bright or very dim lighting. These settings are installed under the /usr/share/sawfish/2.0.pre1/themes directory.

You can create an .xinitrc file that specifies metacity instead of sawfish to run Red Hat's metacity window manager, which is used by default with GNOME. The metacity window manager is no-frills client, but it can use different themes.
