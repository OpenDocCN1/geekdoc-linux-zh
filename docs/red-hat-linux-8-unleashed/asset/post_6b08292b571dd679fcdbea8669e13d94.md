
# LISTING 18.4 fthosts Configuration File for Allowing or Denying Use Case

```
# Example host access file
#
# Everything after a '#' is treated as comment,
# empty lines are ignored
allow tdc 128.0.0.1.*
allow tdc 192.168.101.*
allow tdc insaneppenguin.net
allow tdc *.exodous.net
deny anonymous 201.*
deny anonymous *.pilot.net
```

The * is a wildcard that will match any combination of that address. For example, allow tdc *.exodous.net will allow the user tdc to log in to the FTP server from any address that contains the domain name exodous.net. Similarly, the anonymous user will not be allowed to access the FTP if he is coming from a 201 public class IP address.

Changes made to your system's FTP server configuration files only become active after you restart xinetd at root, which is the command /etc/rc.d/init.d/xinetd restart. This makes a call to the same shell script that called at system startup and shutdown for any runlevel to start or stop the xinetd daemon. xinetd should report its status as

```
# /etc/rc.d/init.d/xinetd restart
Stopping xinetd:      [ OK ]
Starting xinetd:      [ OK ]
```

Once restarted, the FTP server is accessible to all incoming requests.

# Server Administration

Wu-ftp provides a few commands to aid in the administration of the server. These commands are:

- ftpwho—Displays information about current FTP server users
- ftpcount—Displays information about current server users by class
- ftshutdown—Provides automated server shutdown and user notification
- ftprestart—Provides automated server restart and shutdown message removal

Each of these commands must be executed with superuser privileges because they reference the ftpaccess configuration file to obtain information about the FTP server.

# Display Information About Connected Users

This command provides information about users who are currently connected to the FTP server. Here's the command:

```
/usr/bin/ftpwho
```

Table 18.3 shows the format of output ftpwho displays.

| Name | Description |
| --- | --- |
| Process ID | The process ID of the FTP server. |
| TTY | The terminal ID of the process. This will always be an interactive login. |
| Status | Status of the FTP process. The values are S: sleeping, Z: zombie, R: running, N: normal |
| Time | The elapsed time the process has used in minutes and seconds. Tells what host the process is connecting from, the user who connected, and the status of his session. |

Listing 18.5 shows a typical output of this command. It lists the ftp daemon handling requests, the class that the particular user belongs to, the total time connected, what username the user connected as, and the status of his session. In addition to the information given about each connected user, ftpwho will also display the total number of users connected from any host that might have been seen in the ftpaccess file. This information can be used to monitor ftpwho. You can pass one parameter to ftpwho (using ftpwho--help). The single parameter you can pass to ftpwho is -V. This parameter prints out version and licensing information for wu-ftp, as shown here:

```
$ ftpwho
```

```
Service class all: 00:00
ftpd: localhost: IDLE users (no maximum)
```

# Count the Number of Connections

/usr/bin/ftpcount counts the number of connected users to the FTP server and maximum number of users allowed. This same information is found at the end of the output for the ftpwho command. This command only takes one parameter, -V, which displays the same output as in Listing 18.6.

```
ftpcount
Service class all             4 users (no maximum)
```

# Use /usr/sbin/ftshift to Schedule FTP Server Downtime

As with any server administration, it is good practice to let users of the FTP server know about upcoming outages, when the server will be updated, and other relevant site information. The ftshift command allows the administrator to let the FTP server do much of this automatically. The ftshift command allows the administrator to take the FTP server down at a specific time based on some parameters passed to it. The format of the command is as follows documented in the ftshift man page:

```
ftshift [-V ] [ -l min ] [ -d min ] time [ warning-message ... ]
```

The -V parameter displays the version information of the command, with output similar to that of Listing 18.5. The time parameter is when the ftshift command will stop the FTP servers. This parameter will take either a + number for the number of minutes from the current time, a specific hour or minute in 24-hour clock format with HH:MM.

The -l parameter allows the FTP server administrator to specify how long, in minutes, before shutdown the server will disable new connections. The default for this is 10 minutes. The time given to shut down the servers is less than 10 minutes, new connections will be disabled immediately.

The -d parameter is similar to the -l parameter, but controls when the FTP server will terminate the current connections. By default this will occur five minutes before the server shuts down. The shutdown time is less than five minutes, the server will terminate the connections immediately.

When you execute this command, the FTP server creates a file containing the shutdown information in the ftpaccess file.
