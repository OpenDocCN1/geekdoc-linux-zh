## Login and reboot

After rebooting your PC, you will be able to log in to a Linux session. If you didn't choose to have X configured during the installation, you'll log in at a text-based prompt. If you configured X and enabled graphical login, the screen will clear after Red Hat boots, and you'll be presented with a graphical login screen.

To log in at the text-based prompt, type your username and press Enter. You'll then be prompted for your password. After you press Enter, you'll be at the Linux command line. If you use graphical login, you can use the shutdown or reboot menus on the screen's dialog box to shut down or reboot your system. To immediately shut down your system from the command line of a text-based session, use the su command and its -c option to run the shutdown command. In addition, use the -h or halt option and the keyword now, or the numeral 0:

```
$ su -c /sbin/h now
```

You can also use

```
$ su -c "/sbin/h 0"
```

You can also use the shutdown command to immediately reboot your computer like this:

```
$ su -c "/sbin/r now"
```

Or, you can use

```
$ su -c "/sbin/r 0"
```
