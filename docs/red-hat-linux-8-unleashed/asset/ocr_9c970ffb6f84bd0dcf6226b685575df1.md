# Using RPM for Software Management

| Option | Used To |
| --- | --- |
| rpm -V | Verify Packages Against the RPM Database |
| -a | Verify all installed packages |
| rpm -K | Use PGP to Verify a Downloaded Package |

Useful options to -V:

-a

Useful options to -K:

-npgp

If you lack PGP encryption keys, do not have PGP installed, or are legally prohibited from using PGP, this still verifies the package using size and MD5 checksums.

Details on obtaining the Red Hat public PGP encryption key and using it are at http://www.rpm.org/rpm/s1-rpm-checksig-using-rpm-k.html.

> RPM is for Programmers Remember that RPM was not created only to provide an easy to use administrative tool, but also as a developer's tool for use in multi-platform source-code package management. Programmers using rpm for development and distribution will use its -b or build option, along with a myriad of additional command-line flags. RPM can be used to build binaries, execute programs, test installations, verify sign packages, build source packages, track versions, and target builds for specific architectures. Details can be found at the RPM home page (listed in the “Reference” section at the end of this chapter).

# RPM on the graphical Command Line

Because the new graphical RPM client can only install and uninstall RPM packages (for now—more functionality is promised), you will still end up administering RPM packages from the command line. You can perform all the basic rpm operations using the rpm command from the command line. This section gives you an introduction to performing those operations. It also provides examples of how to install, verify, query, remove, and upgrade a software package.

The most common rpm operation is software installation. Using rpm is an easy way to keep track of installed software, and can be used to quickly remove undesired packages. The -i option, along with the full or partial name (using expressions) of a software package, to install software with rpm. For example, to install the pine email package, use the rpm command like this:

```
# rpm -ivh pine-4.44-7.i386.rpm
Preparing...
########################################### [100%]
1:pine ############################################ [100%]
```
