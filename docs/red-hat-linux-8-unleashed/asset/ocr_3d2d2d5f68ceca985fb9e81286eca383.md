Linux device files are contained under the /dev directory. The directory contains more than 7,500 files representing devices that may or may not be in use on your system. Some of the most commonly used devices in this directory include

+   - IDE (Integrated Drive Electronics) hard drives, such as /dev/sda and /dev/hdb
- CD-ROM drives, some of which are IDE, whereas others are CDRW (CD read/write) drives emulated as SCSI (Small Computer Systems Interface) devices such as /dev/scd0
- Serial ports, such as /dev/ttyS0 for COM1, /dev/ttyS1 for COM2, and so on
- Pointing devices, including /dev/mouse and others
- Printers, such as /dev/lp0

> NOTE
Network interfaces (such as eth0 or ppp0) are not represented by Linux device files, but are created in memory when activated. Chapter 13, “Network Connectivity,” for more information.

# Use and Edit Files in the /etc Directory

More than 20MB of system configuration files and directories reside under the /etc directory if you install all software included with this book. Some major software packages, such as Apache, OpenSSH and xinetd, have directories of configuration under /etc. Other important system-related configuration files in /etc are

+   - fstab—The system filesystem is a text file listing each hard drive, CD-ROM, floppy or other storage device attached to your PC. The table indexes each device's partition with a place in your Linux file system (directory layout), and lists options for each device used with Linux (see Chapter 10, “Managing the Filesystem”)

+   - initab—The system initialization file defines the default runlevel. This file can determine whether your system boots to a graphical or text login, as well as whether or not dial-up access is enabled. (You can learn about default runlevels in the section “Red Linux Runlevels” located in Chapter 7, “Managing Services.”) See the section “Starting X” located in Chapter 6 to learn more about changing inittab to boot to a graphical interface. Chapter 15, “Internet Connectivity,” in the section “Setting Up a Dial-up PPP Server” discusses editing inittab to enable dial-up remote access.

+   - modules.conf—This configuration file contains directions and options used when loading kernel modules to enable various types of hardware, such as sound, USB, networking, and so on (discussed in the section “Building and Installing Modules” in Chapter 24).
