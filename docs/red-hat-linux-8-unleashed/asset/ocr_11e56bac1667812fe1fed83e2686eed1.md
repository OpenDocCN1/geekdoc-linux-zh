# Floppy-Based Linux Distributions

+   - http://crux.nu/—Home page for the CRUX i686-optimized Linux distribution.
- http://www.trustix.net/—Home page for the free version of the Trustic Linux distribution, which currently uses the latest 2.2 kernel. Trustius is RPM based.
- http://www.smoothwall.org/community/home/—The 22MB SmoothWall distribution, which easily fits on a bootable business card and is used to install a Web-administered firewall, router, or gateway with SSH, HTTP, and other services.
- http://www.phy.olemiss.edu/debian-cd/—A 185MB Debian 3.0 (Woody) distribution with enough software to bring up a working Debian system. X isn't included, so you must download and install all other packages to expand the system.
- http://www.linuxrouter.org—Home page for the Linux Router Project
- http://www.itm.tu-clausthal.de/—perle/hal91—Home page of the HAL91 distribution
- http://floppix.ccai.com/index.html—A Debian-based floppy
- http://www.toms.net/rb/—Tom’s root and boot disk distribution
- http://www.cotoyelinux.com/—Secure routing and embedded Linux disk distribution
- http://trinux.sourceforge.net/—An ultra-secure Linux distribution on floppy
- http://PenguinBackup.sourceforge.net/—A unique, floppy-based distribution that allows quick backup of your Palm-type PDA
