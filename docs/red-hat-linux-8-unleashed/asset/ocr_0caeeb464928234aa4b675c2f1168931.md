Unique Unix operating systems implement the group in various ways. Red Hat uses a scheme called UPG, the User Private Group, in which all users are assigned to a group with their own name by default. (The user's name and group name are identical). All the groups are listed in the /etc/group file.

Here is a partial list of a sample /etc/group file:

```
# cat /etc/group
root:x:0:root
bin:x:1:root,bin, daemon
demon:x:2:root, bin, daemon
sys:x:3:root, bin, adm
adm:x:4:root, adm, daemon
tty:x:5:
disk:x:6:root
lp:x:7:daemon, lp
mem:x:8:
kmem:x:9:
wheel:x:10:root
mail:x:12:mail, postfix
news:x:13:news
wine:x:101:
pcap:x:19:hoyt
floppy:x:45:
slipupers:x:46:
mailman:x:41:
ysql:x:27:\ldap:x:55:
pvm:x:24:
hoyt:x:500:
```

In this example, there are a number of groups, mostly mentioned, for services (mail, mysql, and so on) and devices (floppy, disk, and so on). As previously mentioned, the system groups allow those to have ownership and control of their files.
