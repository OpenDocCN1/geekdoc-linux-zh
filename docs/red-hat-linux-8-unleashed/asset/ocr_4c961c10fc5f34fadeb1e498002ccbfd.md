# Reference

dump—An ext2 filesystem backup utility
dumpe2fs—Shows information about an ext2 filesystem
e2fsadm—Administrators an LVM/ext2 filesystem
e2image—Creates an image file of ext2 filesystem data
fdisk—The Linux partition table editor
fsck—Checks or repairs a filesystem
lsraid—Displays information about Linux md
mformat—Formats a DOS floppy disk
mkfs—Creates various filesystems
mkisofs—Creates a CD-ROM filesystem
mkreiserfs—Creates a Linux ReiserFS file system
mkswap—Prepares a Linux swap device
mount—Mounts a supported filesystem
parted—The GNU partition editor and resizing utility
reiserfsck—Checks a Linux ReiserFS filesystem
resize_reiserfs—Resizes a Linux ReiserFS system
sdfdisk—A Linux partition table editor
sbmnt—Mounts an SMB filesystem
sbbmount—Mounts an smbfs filesystem
stat—Shows file or directory status
swapon—Displays swap usage or start using system swap usage
swappoff—Turns off swap usage
sync—Flushes filesystem buffers
tune2fs—Changes filesystem parameters on ext2 filesystem
umount—Unmounts a filesystem
usermount—The Red Hat graphical filesystem tool
