# Controlling Apache with Red Hat's redhat-config-services Client

You can also use a graphical version of the chkconfig command named redhat-config-services during an X session to set when Apache is started or stopped and at what run level. To start redhat-config-services, choose the Services menu item on the Server Settings menu from your desktop panel's main menu, or type the command like so in a terminal window:

```
$ redhat-config-services &
```

After you press Enter, you'll be prompted for the root password (as you shouldn't running X as root).

> NOTE
You can also use the ntsys command to set Apache to start at boot time.

This client is a graphical run editor. To have Apache start when run level 3, first use the Edit Runlevel menu to select run level 3, and then scroll through the list of services to find httpd. If you click the httpd check box as shown in Figure 16.1, and then click the toolbar's save button, Apache will be started at that run level the next time the system starts or reboots.

You can also use the Service Configuration client to instantly control a service. Use the Edit Runlevel menu to select the current runlevel in use, highlight httpd, and then click the Start, Stop, or Restart toolbar button.
