There are two ways to run commands with root privileges. The first is useful if you are the superuser and the user; the second if you aren't the regular user (as on a large, multiuser network).

# Temporarily Changing User Identity with the su Command

What if you are also root, but logged on as a regular user because you're performing nonadministrative tasks and you need to do something that the superuser can do? The command is available for this purpose. Contrary to popular belief, su means substitute user, not superuser; you can substitute the identity of any user for the one you are currently using as long as you know the password.

Because all Linux filesystem security revolves around file permissions, it can be useful to occasionally use a different user with permission to access files belonging to other users or groups or access certain files (such as the communications port /dev/tty8 when using a modem or the sound device /dev/audio when playing a game). You can use the command to temporarily switch to another identity and switch back. The command spawns a new shell, changing the UID and GID of the existing user and automatically changes the environmental variables associated with that user, inheriting the environment. See Chapter 5 for more information on environmental variables.

The syntax for the su command is this:

```
$ su username arguments
```

The main page for su gives more details, but some highlights of the su command are

+   -c,--command COMMAND to the shell with -c
  pass a single COMMAND to the shell
-m,--preserve-environment
  do not reset environment variables
-l a full login simulation for the substituted user,
  the same as specifying the dash alone

You can invoke the su command in different ways that yield diverse results. By using su alone, you can become root, but keep your regular user environment. This can be verified by using the printenv command before and after the change. Note that the working directory (you can execute pwd as a command line to print the current working directory) hasn't changed. By executing the following, you become root and inherit root's environment:

```
$ su -
```
