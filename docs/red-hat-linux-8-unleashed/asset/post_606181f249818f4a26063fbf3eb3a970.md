You can download VueScan for evaluation. The program is unrestricted but places a watermark on any scan until you purchase a serial number (current cost, US$40). The site offers some of the best documentation and support concerning scanner usage I have seen.

To install the software after you download it, create a directory in /usr/local named vuescan, copy the tar file there, and use tar to extract it:

```bash
# mkdir /usr/local/vuescan
# cp xvzf vuesca75.tgz /usr/local/vuescan/
# cd /usr/local/vuescan/
# tar xvzf vuesca75.tgz
```

This leaves a binary in the root directory as /usr/bin/vuescan/vuescan.html.

In order for the application to work correctly with Red Hat 8.0, you must set the language environment variable as you launch the program; otherwise, the fonts will not be displayed properly. Here is how you set it:

```bash
# env LANG=C /usr/local/vuescan/vuescan &
```

# Web Design Tools

One of the simplest Web design tools is the text editor vi, because Web pages are really nothing more than text files with text formatting tags included. Few people want to use such a simple tool for Web page design, however. While the Windows and Mac world have emphasized WYSIWYG (What You See Is What You Get) page design tools, Linux users have, for the most part, opted for amounts fancy text editors such as the Quanta Plus application provided with Red Hat.

Quanta Plus is located in the Programming menu, found under the Extras. Launching the application presents you with a three-panel view: a file tree on the left, a files display on the upper right, you can preview your file in different browsers so you can see how the browsers display the code. Quanta uses the concept of "projects" to manage common pages from a Web site, downloading and uploading the pages using syntax coloring for debugging, as well as a number of tools for advanced page elements such as tables, lists, and forms. Its interface is designed and intuitive, as shown in Figure 25.14.

![](img/446debe023486a07fde575245cf7a3ff_867_0.png)

FIGURE 25.14 Quanta Plus is a feature-rich HTML editor and development tool that is well-integrated into KDE.

The following are some of the many Web development tools that are not provided with Red Hat:

- Bluefish—Found at http://bluefisk.openoffice.nl/, Bluefish is a GTK-based HTML editor that is similar in function to Quanta Plus. It supports anti-aliased fonts and UTF8 encoding, so it is compatible with Red Hat 8.0.
- IBM WebSphere Studio Homepage—A commercial application available at http://www-3.ibm.com/software/webservers/hpbuilder/, this tool is a WYSIWYG editor.
- Coffee Cup—A free commercial editor available at http://www.coffeacup.com/linux, Coffee Cup provides a number of preconfigured templates and Java code examples.

OpenOffice.org (included with Red Hat Linux) can also be used as an effective HTML editor. From the File:Autopilot menu in OpenOffice Writer, you select the Web Page to create HTML pages.

# Fax Client Software

Red Hat 8.0 provides several clients that handle different aspects of composing, viewing, and sending faxes. Two graphical clients are available: the KFax application, shown in Figure 25.15, is used to view faxes, and the Kdeprint application is used to send faxes and comment a cover sheet for them (see Figure 25.16). The actual sending and receiving of faxes is handled by the Efax application.

You can use any text editor to create the document you will be faxing. If you want something fancy, you can select the OpenOffice.org Write Fax Wizard from the File:Autopilot menu. It steps you through the creation of an elaborate fax document. You can choose to simply select a plain-text document with Kdeprint, edit the cover page, and send it.

You access Kdeprint through the Extras menu as the Send Fax menu under the Accessories menu. To use it, you add the file you want to fax by using the Add File dialog. You can view your file by clicking the View File button. The application provides an address for your file. Note the "Efax" field in the bottom right of the screen, which confirms that Efax will be used to actually send the fax. Kdeprint simply collects the information and uses Efax to actually do the sending.
