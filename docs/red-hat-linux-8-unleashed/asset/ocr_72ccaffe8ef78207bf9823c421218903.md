The value of the default entry, the initdefault line in /etc/inabb, determines the particular system state in which Red Hat Linux will be when the login prompt is finally presented.

```
id:5:initdefault:
```

In this example, Red Hat Linux boots to runlevel 5, a networking, multiuser mode with an active X system and a graphical login. The value 5 is forwarded to the script name rc under /etc/rc.d directory. This script is used when booting or changing runlevels; it also acts as an interpreter when you boot Red Hat Linux in “Interactive” mode by pressing during boot.

Assuming that the value is 5, the rc script executes all the scripts under the /etc/rc.d/rc.5 directory and then launches the graphical login.

After /etc/rc.d/rc.sysinit has finished, init uses the corresponding /etc/inabb entry that matches a designated default runlevel. Using the previous example, the line in /etc/inabb would be

```
1:5:wait:/etc/rc.d/rc 5
```

Under the /etc/rc.d directory is a series of directories that correspond to each runlevel:

```
$ ls /etc/rc.d
init.d rc0.d rc2.d rc4.d rc6.d rc.sysinit
rc1.d rc3.d rc5.d rc.local
```

```
$ ls /etc/rc.d/rc.5
```
