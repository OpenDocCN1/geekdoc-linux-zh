# CHAPTER 14 Managing DNS

The type field is mandatory, and the RR in use, as A, NS, MX, or SOA. (We will only use few of the existing RRs here. Consult the DNS standards for a complete list.) The data field (or fields) contains data specific to this type of record. The appropriate syntax will be introduced as the use of each RR in turn.

Here is the zone file for the 0.0.127.in-addr.arpa zone:

```
/var/named/rev/127.0.0

STTL 2D
  localhost. hostmaster.example.com. (
      2001090101 ; Serial
      24h ; Refresh
      2h ; Retry
      3600000 ; Expire (1000h)
      1h) ; Minimum TTL
  NS PTR localhost.

```

TheTTL directive, which should begin every zone file, sets the default minimum time to live for the zone to 2 days. This is discussed further in the next section.

# The Zone File's SOA Record

The second line in the zone file uses the special @ name that you saw earlier. Here, it stands for 0.0.127.in-addr.arpa, to which the SOA (Start of Authority) record belongs. The rest of the fields (continued until the closing parenthesis) contain SOA-specific data.

The first field in the SOA record is the fully qualified name of the master server for the domain. The second field is the email address of the contact person for the zone. It is written as a DNS name by replacing the @ sign with a ". foo@example.com would be written as foo.example.com.. (The trailing .)

Don't use an address such as a.b.example.com because it is written as a.b.example.com, and will later be misinterpreted a@b.example.com.

> TIP
it is important to ensure that the email address specified in the SOA field is frequently read because it is used to report DNS setup problems and other potentially useful information.
