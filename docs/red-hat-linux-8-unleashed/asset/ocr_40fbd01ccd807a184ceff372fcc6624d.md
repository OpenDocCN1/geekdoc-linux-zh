# Twikki

Twikki is a Web-based collaboration tool. In use, it provides pages that resemble like a regular Web site, by logged-in users can add content or make other modifications using a Web browser. Content is generated while maintaining a log of all changes. Twikki is a collection of Perl scripts that can extend and complement Apache’s capabilities. Twikki is available at no cost under the GPL from http://www.Twikki.org.
