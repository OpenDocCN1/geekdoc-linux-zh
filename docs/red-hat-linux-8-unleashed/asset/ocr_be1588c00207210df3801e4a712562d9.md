# CHAPTER 25 Office Productivity Applications

# GUI PDA Client Software

To interact with a PDA using a graphical interface, you can use Dan Pilone's KPilot client. You can use this application to install and retrieve text documents and back up and restore the contents of a PDA.

You need to properly configure the software by selecting a correct serial port, speed setting, and default file location. You open KPilot by opening the Extras menu and choosing Accessories, KPilot.

Another graphical PDA client, shown in Figure 25.11, is the comprehensive J-Pilot application. You can use the J-Pilot program to manage, retrieve, install, back up, and sync any information for your Palm-related PDA. You can click on the Date Book, To-Do List, Address Book, and Memo Pad buttons to perform related tasks. Use the Sync and Backup buttons to update or preserve a copy of a PDA’s data. You open this client by choosing J-Pilot from the Accessories menu.
