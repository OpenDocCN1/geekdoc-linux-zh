## Increased Productivity with the Personal Desktop

A new installation feature, named Personal Desktop, is available in the latest version of Red Hat Linux. The Personal Desktop installs pre-selected software suitable for Small Office Home Office, or SOHO, users. This option, a refinement of the previous Workstation-class install (which now is aimed at software developers), will provide a wealth of productivity tools for document management, printing, communication, and personal productivity.

The Personal Desktop installation requires nearly 2GB of hard drive space, but contains administration tools, authorizing and publishing clients, a variety of editors, a GNOME-based X11 desktop, support for sound, graphics editing programs, graphical and text-based Internet tools, printing support, and office productivity tools. The installation can be customized to include or sidestep installation of unwanted software.

> Red Hat Linux in Education

In 2002, Red Hat, Inc. announced a “K-12 Red Hat Linux Pilot Program,” an extension of the company’s “open schools” initiative. Red Hat’s new program aims to provide open source software and support, according to Red Hat, “all schools, regardless of size or budget.” Although candidate schools must provide their own hardware and meet some minimum requirements, Red Hat has promised software and installation support.

To avoid the expense of software licensing fees, schools around the United States have installed and Linux. Linux-based computer labs in Portland schools are expected to save the school system (and Oregon tax payers) nearly one-quarter of a million dollars over the cost of using commercial software.

## Getting the Most from Red Hat and Linux Documentation

Every commercial Linux distribution includes manuals and documentation covering installation and configuration. You'll find documentation from Red Hat, Inc. included on one of the CD-ROMs included with this book. You can also get copies of the Red Hat manuals online through http://www.redhat.com/docs/. There you'll find Red Hat's official manuals and guides:

- Red Hat Linux manuals—Information to help you install, and customize Red Hat Linux
- Red Hat Network manuals—Information to help with registration and upgrade processes when you purchase an official copy of Red Hat Linux
- Red Hat server, database, source code control system, and embedded development guides—Important to software developers or when creating software for Red Hat Linux
- Other official Red Hat documentation—A dozen other manuals with support information about Red Hat's various software products

These guides are available in Portable Document Format (PDF) and can be read using Adobe's Acrobat Reader for Linux or the xpdf client. The guides are also available as bundled HTML files for reading with a Web browser such as lynx, links, KDE's conquer, GNOME's galleon, or Mozilla. With these guides, Red Hat, Inc. provides various tips, Frequently Asked Questions (FAQs), and HOWTO documents.

For information regarding software management using the Red Hat Package Manager (RPM), you can also download a free copy of Ed Bailey's classic "Maximum RPM." Developers interested in writing or programming programs to Linux can also get a copy of "Linux Application Development" by Michael K. Johnson and Erik W. Trojan.

## Using Red Hat Linux Manual Pages and HOWTOs

If you choose to perform a full installation of Red Hat, the zless pager allows you to scroll back and forth through documents (use less command to read plain files). You can start the command using less, followed by the complete directory specification and name of the file, `filename`, like this:

$ /usr/doc/ipchains-1.3.10/HOWTO.txt

After you press Enter, you can scroll through the document using your cursor keys. The q key to quit.

Many of the software packages also include separate documents known as HOWTOs that contain information regarding specific subjects.

If the HOWTO documents are simple text files in compressed form (with filenames ending in .gz), the zless pager allows you to scroll back and forth through documents. To read a compressed version of this file, use the zless command in the same way:

$ zless /usr/share/doc/ipchains-1.3.10/HOWTO.txt.gz
