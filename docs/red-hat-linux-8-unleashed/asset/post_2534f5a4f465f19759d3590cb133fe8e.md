
# Updated Device and Filesystem Software

Red Hat Linux has numerous features to detail, but the Linux kernel and the software included in the Red Hat Linux distribution create a powerful operating system with enough flexibility to provide support for many different users. For example, the included Linux kernel hosts updated support for many devices, such as Universal Serial Bus (USB), digital cameras, and scanners (discussed in Chapter 26, "Multimedia Applications”).

Red Hat also includes the most recent stable version of Mozilla, an open source Web browser, and provides graphical application prototyping environments (discussed in Chapter 21, "Introduction to C/C++ Programming Tools”). Because much of the software is licensed under the GNU GPL, you will always have access to the source code.

The latest version of Red Hat Linux includes default support for Red Hat's ext3 filesystem. ext3 supports a form of low-level storage data handling which previously only available under very expensive computer platforms. Journaling is accomplished using a variety of techniques, but the end result ensures that data remains intact on the disk despite a system crash, power outage, or other mishap.

> Technically, data journaling is supported and managed by ext3. Read a presentation by Red Hat's Dr. Stephen Tweedie, the creator of ext3, titled "Ext3, Journaling Filesystem at http://olstrans.sourceforge.net/release/OLS2000-ext3/OLS2000-ext3.html for details. You can also read how ext3 is used with the 2.4-series Linux kernel by browsing to Andrew Morton's page at http://www.zip.com.au/-akpm/linux/ext3/index.html.

Another journaling formats are supported by Red Hat Linux (such as reiserfs) and have similar features, ext3 offers several advantages in performance, safety, and ease of use and implementation.

For example, the ext3 filesystem is an extension of the existing ext2 filesystem previously used with nearly all Linux distributions, and it can be easily and safely convert ext2 partitions to ext3 or back in place. This remarkable feature avoids the normal practice of backing up, reformatting, and restoring existing data. In other words, ext3 not only offers necessary enterprise-level features for the corporate marketplace, but also makes migration of existing data much easier.

Red Hat Linux now also supports the creation of RAID arrays and configuration of Logical Volume Management, or LVM, a sophisticated filesystem handling feature allows parts of the file system (directory layout) to span one or more portions of physical storage media. This feature also allows resizing of the resulting partitions if system resource requirements change after initial configuration, and while the pertinent filesystems are unmounted or mounted.

Other improvements are the inclusion digital signature verification for RPM packages (for enhanced security), RPM package dependency resolution suggestion (to more easily fix dependency diagnosis), and the privoxy server (to help filter out unwanted Web page popups, and so on).

# Red Hat Linux in the Enterprise

As Linux has matured over the last 10 years, additional features that are essential to its placement and success in enterprise-level environments have been added. The addition of virtual memory (the capability to swap partitions of RAM to disk), one of the first features was a copyright-free implementation of the TCP/IP stack (mainly due to BSD UNIX being tied up in legal entangles at the time), followed by support for a variety of network protocols. Closely on the helps of network support, developers developed the ability to read and write a variety of popular filesystems, or low-level data structures used on read-write and read-only media.

Linux also has the capability to use multiple processors. This allows Linux to be deployed in more advanced computing environments with greater demands on CPU power. The ability to change kernel capabilities in the 2.2 series, ushering in support for a host of new features and hardware through the use of loadable and unloadable modules. With the advent of the 2.4 series of the Linux kernel, support has been added for at least eight CPUs, enabling Linux to run on ever more powerful hardware.

The 2.4 series of kernels also provides support for RAM sizes up to 64GB, individual file sizes in excess of 2GB (extremely important for database operations; some of the latest cutting-2.5-series Linux kernels now have limits to 2TB), and support for many millions—and theoretically, billions—of users. And to the efforts of Red Hat, IBM, SIG and individual programmers, the ability to use the ext3, JFS, or ReiserFS journaling filesystem has been arrived on the scene. These filesystems give Red Hat Linux the capability to stay and quickly recover from a catastrophic system event (such as loss of power). This capability validated Linux (and Red Hat into) the enterprise-class computing environment.

Corporations that depend on large-scale, high-volume, and high-availability systems can now turn to Red Hat Linux as a stable, robust, scalable, and inexpensive solution for various platform hosting. This means bringing a system with storage in the terabyte range following a power no longer requires filesystem checks. Downtime is reduced to a minimum in the instance of power problems, and with enterprise solutions, services can be maintained without interruption.
