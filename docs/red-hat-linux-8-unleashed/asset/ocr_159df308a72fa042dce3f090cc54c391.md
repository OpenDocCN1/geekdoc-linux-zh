The rc5.d links are prefixed with a letter, such as K15 or S10. The (K) or (S) in these prefixes indicate whether or not a particular service is killed (K) or started (S) and a value of stop to start the /etc/rc.d/init.d script in a particular order. The symlinks have numbers to delineate the order in which they are handled. Nothing is sacred about a specific order, some service needs to be running before others are started. You wouldn't want your system to attempt to mount a remote network, for example, File System (NFS) directory without first starting networking and NFS services.
