You print files (documents or images) using the lpr command, along with a designated printer and filename. For example, to print the file mydoc.txt using the printer named 1pr, use the lpr command and its -P command-line option and the printer's name, like this:

```
# 1pr -Plp mydoc.txt
```

The lpr command uses a default printer name determined by (in order of priority): the command line, the PRINTER, LPDEST, NPRINTER, or NGPRINTER environment variables, the first entry in your system's /etc/printcap, or the default printer specified in /etc/lpd.conf.

## Manage Print Jobs

You can also print multiple documents from the command line. For example, to print a number of files at once to the lpr printer like so:

```
# 1pr -Plp *.txt
```

This approach uses the wildcard capabilities of the shell to feed the lpr command all files in the current directory with a name ending in .txt for printing. Use the lpq command to view the printer's queue like:

```
# 1lpq
Printer: 1lp@thinkpad
Queue: 1 printable job
Server: pid 9531 active
Unsporer: pid 9532 active
Status: IF filter 'wrapper' filter msg - \
<</HW/Resolution[300 300]>>setageddevice at 12:29:03.569
```

| Rank | Owner/ID | Class | Job | Files | Size | Time |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | root@thinkpad+530 | A | 530 | CHANGES | 251703 | 10:29:02 |

The lprq reports on the printer, number of jobs, the lpd PID, information from the filter (such as dots per inch, or dpi), and a formatted list of print jobs—each with a job number (530 in this example), owner, name of file, size, and the time the job started. Job numbers are used by LPRng to keep track of documents waiting to be printed, and each job will have a unique job number. To stop the print job in this example, use the lpr-rm command, followed by the job number, like this:

The lpm command removes the spooled files from the printer's queue and kills the job. Print job owners, such as regular users, can only remove spooled jobs that they own. As the root operator, you can kill any job.

Only the root operator can use the lpc command. This command is used for printer and queue control. You can use it to rearrange the order of print jobs, and you can get a display of the status of any system printer. Start lpc on the command line like this:

```
# lpc
```

The lpc command has built-in help on command keywords and syntax. To display the help text, use the help keyword or press : so:

```
lpc> help
```

Several pages of help text will echo back to your display. Another helpful command is lpstat, which you use like this:

```
# lpstat
Printer: lp1@shuttle2
Queue: no printable jobs in queue
Status: job 'root@cello+301' removed at 17:47:07:633
```

This command lists waiting print jobs, along with information similar to that returned by lprpm.

## Using the Common Unix Printing System (CUPS)

Red Linux also includes a version of the Common Unix Printing System, known as CUPS. This print system supports the Internet Printing Protocol, known as IPP, and offers a number of unique features, such as network printer directory (printer browsing) services, support for encryption, and support for PostScript Printer Description (.ppd) files.

According to the Internet Engineering Task Force (IETF), IPP grew out of a 1996 proposal by Novell to create a printing protocol for use over the Internet. Then, the system has been developed and matured into a stable print system for use on a variety of Linux and UNIX operating platforms.

## Switching Between the LPRng and CUPS Print Systems

Red Linux provides a graphical print system administration utility named redhat-switch-printer you can use to switch between using LPRng and the CUPS system. If you use Red Hat's desktop, select the Extras menus System Settings Printer System Switcher menu item, or launch the client from the command line of an X terminal window like this:

```
# redhat-switch-printer &
```

# /etc/rc.d/init.d/lpd stop
```

You must make sure that xinetd has enabled cups-lpd service by editing /etc/xinetd.d/cups-lpd and restarting xinetd. For example, /etc/xinetd.d/cups-lpd to read

# /etc/rc.d/init.d/xinetd restart
```

```
# /etc/rc.d/init.d/cups start
```
