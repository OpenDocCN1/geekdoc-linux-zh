# Perl Versions

As of writing, the current production version of Perl is 5.8.0 (which is Perl version 5 point 8, patch level 0).

You can download the code from http://www.perl.com/ and build Perl yourself from source. Red Hat occasionally provides updated versions in RPM format for Red Hat Linux, which can be found by browsing your errata page at http://www.redhat.com/apps/support/errata/.

You can determine what version of Perl you installed by typing perl -v at a shell prompt. If you are installing the latest Red Hat distribution, you should have the latest version of Perl.

# A Simple Perl Program

This section introduces a very simple Perl program to get you started using Perl. Although trivial for experienced Perl hackers, a short example is necessary for new users who want to learn more about Perl.

> You'll also find a Perl program named perl installed with Red Hat Linux. This program can be used as a compiler to build executable commands out of Perl! The program may also be used to generate experimental C source code by the gcc compiler system (Chapter 21, "Introduction to C/C++ Programming Tools").

To introduce you to the absolute basics of Perl programming, Listing 23.1 illustrates a simple Perl program that brings a short message.

# LISTING 23.1 A Simple Perl Program

```
#!/usr/bin/perl
print 'Look at all the camels!\n';
```

That's the right type. Type that in and save it to a file named trivial.pl. Then make the file executable using the chmod command (see the sidebar "Command-line Error") and run it at the command prompt.

> If you get the message: trivial.pl: command not found or bash: ./trivial.pl: Permission denied, it means that you either typed the command line incorrectly or forgot to make trivial.pl executable (with the chmod command):
$ chmod +x trivial.pl
