# CHAPTER 4 Post-Installation Configuration

Click on the Time Zone tab to change or verify your system's time zone. The current system time zone is designated by a symbolic link named /etc/localtime, which points to a pertinent time zone database file under the /usr/share/zoneinfo directory. For example, to see your system's current time zone, use the ls command like so:

```
$ ls -l /etc/localtime
lrwxwxrxrwx 1 root root 36 Sep 22 15:15 /etc/localtime ->/usr/share/zoneinfo/America/New_York
```

This link will change if you make a time change using redhat-config-date.

# Managing PCMCIA

Red Hat notebook users take advantage of PCMCIA slots to add to 70-pin, credit-card sized devices to support Ethernet LAN connectivity, wireless operations, Firewire devices, Compact Flash hard drives, external storage devices, serial ports, and modems. Many different types of PCMCIA cards and Compact Flash form-factors in a PCMCIA caddy are supported by the Linux kernel and David Hinds' Card Services software.

Power is provided by PCMCIA devices and adapters directly through the card slot, although some external hardware might require an additional power source. PCMCIA support is enabled and configured at boot time according to the /etc/sysconfig/pcmia file and /etc/rc.d/init.d/pcmia startup script. The /etc/sysconfig/pcmia file might look like this

```
PCMCIA=yes
PCIC=yenta_socket
PCIC_OPTS=
CORE_OPTS=
```

Previous incarnations of Red Linux and PCMCIA used specific controller information in this file. With the newer Linux kernels however, support is provided by kernel modules or direct Linux kernel support.

# Using PCMCIA

The PCMCIA Card Services software provides diagnostic information by one or more high or low beeps upon insertion. One high and one low beep indicate that a card is recognized, but failed to be configured. A single beep indicates that the card was only recognized. Two high beeps indicate that a card was recognized and configured.

For example, if you use a compact storage device and insert it into your notebook while using Red Hat, you should hear two high beeps. You can then check to see what device has been assigned to the card by using the dmesg command:

```
$ dmesg
nhde: SunDisk SDCFB-8, ATA DISK drive
```
