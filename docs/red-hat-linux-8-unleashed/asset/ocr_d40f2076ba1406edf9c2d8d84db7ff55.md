# Dynamic Host Configuration Protocol

DHCP also allocates to clients temporary or permanent network (IP) addresses. Once a temporary assignment, known as a lease, has elapsed, the client can request to have the lease extended, or if the address is no longer needed, the client can relinquish the address. For hosts that are permanently connected to a network with adequate addresses available, DHCP allocates infinite leases.

DHCP offers your many advantages. First, it shifts responsibility for assigning IP addresses from the network administrator (who can accidentally assign duplicate IP addresses) to the DHCP server. DHCP makes better use of limited IP addresses. If a user is away from the office for whatever reason, the user's host can release its IP address for use by other hosts.

Like most in life, DHCP is not perfect. Servers cannot be configured through DHCP alone because DNS doesn't know what DHCP assigns to a host. This DNS look-ups aren't possible on machines configured through DHCP alone; therefore, services cannot be provided. However, DHCP can make assignments based on DNS entries when using subnet/hostname or subnet identifier.

NOTE

The problem of using DHCP to configure servers using registered hostnames is being addressed by Dynamic DNS which, when fully developed, allow DHCP to register a domain name (such as imalinuxuser.com) and be able to easily access that domain's Web server without needing to use static IP addressing of a specific host. The largest hurdle to overcome is the security imncation of allowing each host connecting to the system to update DNS. A few companies, such as http://www.dyndns.org, are already providing Dynamic DNS services and clients for Linux.

# Activating DHCP at Installation

If you install the DHCP RPMs or activate DHCP at install time, it will create a directory called /etc/dhcpcd, which has two files:

+   # 11
total 8
--rw-r-- 1 root root 124 Sep 15 18:03 dhcpcd-eth0.cache
-rw-r-- 1 root root 359 Sep 15 18:03 dhcpcd-eth0.info

The dhcpcd-eth0.cache file is a data file that lists the Linux kernel you are running. dhcpcd-eth0.info contains network information for your current DHCP lease and will look something like this:

```
# more dhcpcd-eth0.info
IPADDR=192.122.60.235
NETMASK=255.255.255.0
NETWORK=192.122.60.0
```
