
## Managing Printing Services

Printing services and job requests are handled by the lpd daemon, started by the /etc/rc.d/init.d/lpd startup script, which looks like this (in the part):

```
start () {
  echo -n $'Starting $prog: ""
  # Is this a printconf system?
  if [[ -x /usr/sbin/printconf-backend ]]; then
    run printconf-backend to rebuild printcap and spools
    if ! /usr/sbin/printconf-backend; then
      # If the backend fails, we dont start no printers defined
      echo -n "No Printers Defined"
      echo_success
    fi
    return 0
  fi
fi
```

Note that all the script is shown here. However, as you can see, the script first reports that the service is starting. Next, an associated command to the Red Hat `printconf` utility is used to check for the existence of your system's /etc/printcap database. The script starts the lpd daemon, which runs in the background as a process, waiting for any files to appear under a defined printer's directory under the /var/pool/lpd directory.

After defining a printer, you can use one or more traditional line printer spooler utilities to control printing services, manage printing (or print jobs), and enable, disable, or authorize remote printing services (see the section "Printing Tools" later in this chapter).

## Creating and Configuring Printers

Red Hat has graphical clients you can use to view many different types of documents. For example, to display PostScript documents (including compressed PostScript documents) or PostScript images, use the g client. To display Portable Document Format (PDF) documents, you can use ev or the xpdf viewer.

Creating a local printer for Red Hat can be accomplished in six steps. To launch redconfig-printer, select the Printing menu from the GNOME or KDE desktop or use the command:

```
# redconfig-printer
```

The redhatconfig-printer tool walks you through a process to create a new queue. To begin, click the New button in redconfig-printer. An Add New Queue dialog appears, as shown in Figure 12.1.

![img/446debe023486a07fde575245cf7a3ff_401_0.png]
FIGURE 12.1 Click the New button to start

Click the Forward button; the Set the Queue Name and Type dialog box appears, as shown in Figure 12.2. Type the name of the printer in the Queue name box, and then click an option to select the type of printer you are adding. When you've selected a Print Queue type, click Forward.

![img/446debe023486a07fde575245cf7a3ff_401_1.png]
FIGURE 12.2 Enter a name for your new printer, then click to select a type of printer for your system.

The Configure a Local Printer dialog box shown in Figure 12.3 presents a list of your Red Hat system’s printer devices. If your computer has a parallel port printer, you will see a /dev/lp0 device. If you have a USB printer attached to your computer, you will see a /dev/usb/1p0 device.

![img/446debe023486a07fde575245cf7a3ff_402_0.png]
FIGURE 12.3 Click to select the desired printer device you want to configure for your system.

In the example in Figure 12.3, a parallel-port printer device, /dev/lp0, is shown. You can configure a printer for Red Hat even if it isn’t attached to your computer, or if its device is not listed. In this case, appropriate the device by clicking the Custom Device button and typing in the device name. Otherwise, double-click on the listed device that you want to configure, and the Select a Printer dialog appears, as shown in Figure 12.4.

![img/446debe023486a07fde575245cf7a3ff_402_1.png]
FIGURE 12.4 Scroll through the list of manufacturers to select a printer and driver.
