# IM in Red Hat Linux with KIT and GAIM

IM has been popularized by America Online (AOL) as well for AOL users to chat directly with each other rather than speak in chat rooms. As long as the IM clients are running, alert you to any incoming messages that arrive. They also announce to the server that you are active and listening for messages, so your friends can be made aware that you are available to chat with them.

IM can be used in place of IRC for interoffice collaboration, if desired. Red Hat provides two IM clients, KIT and GAIM, for your use. To use them, you need to be communicating with a group of “buddies” that are active IM users.

GAIM is the default IM client for Red Hat 8.0. It is a GNOME (GTK-based) IM client that supports a wide range of protocols. GAIM is a feature-rich message client, and it has support for plug-ins that extend the functionality of the application.

> NOTE
GAIM supports Jabber, an open XML-based IM protocol that can be used to set up a corporate IM server. Jabber is not supplied with Red Hat, but you can obtain additional information about from the Jabber home page, at http://www.jabber.com/. You can obtain the Jabber server, Jabber, from http://jabber.jabberstudio.org/.

KIT is a simple KDE IM client. When you first launch KIT, offers to go to AOL to create a new profile. After you choose a screen name and password and have them accepted, you exit the “registration” process. You receive an email message that you must return in order to confirm your account, completing the registration.

# Videoconferencing with GnomeMeeting

GnomeMeeting is an Internet videoconferencing application that provides two-way voice and pictures over the Internet by using the H.323 protocol for IP telephony (also known as Voice over IP [VoIP]). It is provided with Red Hat Linux.

Before you can take full advantage of the phone and videoconferencing capabilities of GnomeMeeting, you must configure a full-duplex sound card and video device (see Chapter 26, “Multimedia Applications”) as well as a camera.

GnomeMeeting is found in the Menu as Video Conferencing; you click on the icon to launch it. When you start the GnomeMeeting application for the first time, you are greeted by the first of four configuration screens. You simply enter your name, email address, and location and select your connection type. The settings for your audio and video devices are automatically detected; you can view them by selecting the Preferences item from the Edit menu.

# Mail List Management with Mailman

Using a mail list is an increasingly common way for individuals in disparate geographic locations to collaborate. A mail list is a group discussion that takes place via email. However, instead of sending a separate message to everyone who is interested in participating, you send a single message to the automated mail list server, and it sends messages to each subscribed user. When you receive mail from the list and you reply to an individual message, that message is sent to the Mailman list manager, and the message is then re-sent to everyone on the list. Red Hat maintains numerous mail lists and uses the mailing list manager Mailman to do it. Red Hat provides Mailman with Red Hat 8.0.

Mailman keeps track of who is subscribed and who does not have email addresses. The mail list list manager handles all new subscriptions and unsubscriptions through a Web interface and can even generate an archive of all the messages on the list.

For each list, a person is designated as the mail list administrator. The administrator has password-protected access to a special Web. He or she can manually add and delete members from the list and remove emails that are determined to be offensive. It is also possible to configure the list to be moderated, in which case a moderator reads all messages before they are passed on Mailman for distribution to the subscribers. The list can also be configured to allow nonmembers to post, but that option is rarely used because most administrators want to keep unauthorized posts off the list.

Some lists, known as "high-traffic" have a large number of messages posted daily. Other lists, known as "low traffic" lists, have few, if messages posted daily. One configuration option is to have all messages consolidated into a digest, so only one message is sent for a preestablished number of messages that are received by Mailman. The maximum message size also can be established, and attachments to messages can be prohibited.

> Part of the testing and development for Red Hat 8.0 took place on a mail list. You can view the archives at https://listman.redhat.com/pipermail/limbo-list/ if you are curious.

With Mailman to manage a mail list, you must first have Sendmail installed and configured (see Chapter 19, "Handling Electronic Mail").

After installing the RPM (by using the package manager or manually, with # rpm -ivh), you can look at the installed documentation in /usr/share/doc/mailman-2.0.13, paying particular attention to the simple installation instructions in the README.REDHAT.
