# Using Wine to Run Windows Programs in Red Hat Linux

Active development of Codewanders Wine has been neglected for the two other Wine variants that in both cases, Codewanders uses Wine as a base to which Codewanders adds proprietary code, a better GUI configuration interface, and good documentation to offer enhanced functionality and usability to the Linux user. all enhancements to the Wine codebase are returned to the community; proprietary code is not.

Codewanders’ first commercial product is the Crossover Plugin, which allows Web browser plug-ins for Microsoft Explorer to be in the current Linux versions of the Netscape, Opera, Mozilla, Galeon, Skipstone, and Konquer Web browsers. Crossover supports the major plug-ins, including Shockwave, Quicktime, and Windows Media Player, as well as browser-based viewers for Word, Excel, and PowerPoint. The program provides a GUI installer and automatic download links to the major plug-ins themselves. The documentation is very good, and the Web site contains a good FAQ. The installation and configuration display is shown in Figure 27.5.

Crossover Office, another commercial product from Codewanders, provides support for installing and running Microsoft Office (97 through 2000, see Figure 27.6), Microsoft Internet Explorer 5.5, Lotus Notes, Microsoft Visio, Microsoft Outlook, and Intuit Quicker. It also provides a GUI installer for the applications and will download and install the freely available Microsoft fonts. Crossover Office can also be configured to be used as a standard Wine to run other Win32 binaries (it’s the only Wine you have installed) or it can coexist with other versions of Wine installed on your system—the Wine supplied with Red Hat and WineX.
