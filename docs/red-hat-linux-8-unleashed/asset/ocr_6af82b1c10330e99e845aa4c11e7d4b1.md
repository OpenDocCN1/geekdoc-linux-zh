# Controlling PCMCIA Service

Although PCMCIA cards can be inserted or removed while using Red Hat, be careful while using these cards. For example, do not remove a network card while connected to a remote computer. Don't pull a compact flash card or other storage media card (such as an IBM microdrive) while the card's filesystem is mounted and in—you could corrupt the media's filesystem and experience loss of data.

You can control a PCMCIA device from the command line, and insert and remove the card without physically removing and then inserting the card. The cardctl1 command to control PCMCIA service to one or more card slots on your notebook or desktop PC with a PCMCIA adapter. The cardctl1 command is used to get and print information about an inserted card, suspend or resume power to a card, reset, perform a safe insertion or removal, or to configure a card according to a particular, predefined "scheme" using a network in the office or at home. The format of the command is cardctl1 command slot_number (as 0 or 1).

For example, if you have inserted a compact flash card, eject the card (after unmounting its filesystem) using the cardctl1 command and its eject option, along with the card's slot number like this:

```
# cardctl eject 0
```

This can save power when running a notebook. When the card is again needed, you can subsequently "insert" the card like so:

```
# cardctl insert 0
```

# Configuring and Using CD, DVD, and CDRW Drives

Red Hat Linux provides support for a variety of CD and DVD devices and media. This section shows how to determine what device has been assigned to your CD drive and how to get additional drive information if the drive supports recording on optical media.

AT Attachment Packet Interface, or ATAPI IDE-based CD drives, are recognized during installation and work through the ide-cd kernel module. A symbolic link named /dev/cdrom will be created and point to your CD's device (perhaps /dev/hdb or /dev/hdc). You can use many types of CD drives with Red Hat, and you can easily replace, add, or upgrade your system to use a new drive. Part of a successful configuration involves the proper installation of the hardware and being able to determine the drive's device when using Linux.
