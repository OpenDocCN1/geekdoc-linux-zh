# Other Mail Clients

The mail clients included by Red Hat are only a few of those available. Sylphed-claws (not included) is very popular because it offers spell check while typing and is well-suited for use in large network environments in which network overhead and RAM usage are important considerations. You can find other mail clients and applications for use with Red Hat Linux by searching http://freshmeat.net.

# Attachments—Sending Binary Files As Text

The SMTP protocol can only transfer plain text, so to send images and binary files through email you must encode the binary data as text. You can then include the encoded data in ordinary email; the recipient converts the text back to a binary format. The penalty for using this method is that the text file sizes are much larger than the binary files they replace.

The Macintosh operating system uses a program named BinHex; UNIX has traditionally used uencodng and more recently, MIME encodings. A new player in the field is y encoding which claims to be faster and compress to smaller sizes.
