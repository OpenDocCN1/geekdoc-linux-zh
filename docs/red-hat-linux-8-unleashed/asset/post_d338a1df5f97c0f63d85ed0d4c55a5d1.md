## The KNode News Client

The KNode program is part of the KDE networks package, which is included in the Red Hat distribution as kdenetwork RPM package. KNode is installed by default if you select the KDE windows manager option in the Red Hat installation.

The KNode program is an excellent graphical program that allows you to connect to news servers (either the local server or a remote server) and select newsgroups where you can read and post articles. Before you begin, you must configure the address of your news server into KNode. You do this from the Settings menu item on the KNode window. From the Settings drop-down menu, you select the Configure KNode item. The KNode configuration window appears. Under the Accounts item, you can select the News item. A list of configured news servers appears in the window. To add a new news server, you click the New button. Figure 20.5 shows the KNode New Account window, where you can enter the new server information.

## The Mozilla News Client

The Mozilla Web browser supports graphical Usenet newsreading as well as Web browsing. Having numerous newsreading clients installed on a Red Hat system offers users a wealth of choice and opportunities for developing favorites, but in some cases it can complicate an administrator’s task of tracking and fixing client security liabilities. Using Mozilla help simplify this task by offering an all-in-one client that provides Web browsing, email, file transfer, and newsreading capabilities.

## Collaborating with TWIKI

Although Usenet is a useful interactive and collaboration tool, in some cases a Web-based tool is better suited to your needs. TWIKI (http://TWIKI.org) is a Web-based interactive collaboration tool that can also be used as a bulletin board, a knowledge base, a bug tracker, and a software archive.

> **TIP**
> You can examine the TWIKI Success Stories on the company's home page for any encouragement you need to explore TWIKI. You can also explore this linux-related public TWIKI site:
> `http://TWIKI.org/cgi-bin/view/Wikilearn/WebIndex`

TWIKI is not available from Red Hat, but you must download it from the TWIKI Web site after completing a brief registration. You then email instructions explaining how to download a .zip file from the site. (Use unzip to extract the files.) The program is licensed under the GPL.

You might want to first read the installation instructions located at http://TWIKI.org/cgi-bin/view/TWIKI/TWikiDocumentation. Here's a short list of advice for moving smoothly through the installation process on a Red Hat Linux 8.0 system (this list assumes that you are performing an installation as the root user):

- You need to create the directory /home/twiki.
- The installation instructions mention the file /etc/httpd/httpd.conf. For Red Hat 8.0, this file is found at /etc/httpd/httpd.conf. You simply copy and paste the entries shown in the example supplied by the downloaded instructions.
- The path to Perl for Red Hat 8.0 is /usr/bin/perl.
- Red Hat 8.0 runs CGI scripts as the apache user, not the root user, as assumed in the default TWIKI installation. You can browse to http://localhost/twiki/bin/testenv and read the warnings that are displayed onscreen. This is a special script that is run on your local machine to help you diagnose any problems with your installation. The messages should be specific to your installation, and any warning should be accompanied by a suggestion on how to fix the problem.

The TWIKI installation directions suggest setting permissions and changing ownership. For Red Hat 8.0, the permissions are set correctly, but the ownership are wrong. To change the ownership, follow the steps below (after each step, you should reload http://localhost/twiki/bin/testenv page to check your progress):

1. Change the ownership of apache, but change the ownership of /home/twiki/templates back to root:

```bash
chgrp -r apache /home/httpd
chgrp -r root /home/twiki/templates
```

2. /home/httpd/twiki/lib/TWiki.cfg to reflect your own domain name instead of http://your.domain.com.

3. Change the ownership of the RCS repository files to the user apache:

```bash
# cd /home/twiki/data
# perl -pi -e 's/:noby:apache/:*V'
```

After you complete the installation, you should have a "virgin" TWIKI installation that you can view at http://localhost/twiki/bin/view. With any application, you need to further configure this file so that it suits your needs. The TWIKI documentation explains the many configuration options and processes that are available to you. This document is included in the TWIKI installation you just completed.

## Internet Relay Chat (IRC)

As documented in RC 2812 and RFC 2813, the IRC protocol is used for text conferencing. Like mail and news, IRC uses a client/server model. Although it is rare for an individual to establish an IRC server, it can be done. Most people use public IRC servers and access them with IRC clients.

Red Hat provides a number of graphical IRC clients, including X-Chat, kirc, licq, and Mozilla-chat, but there is no default chat client. Red Linux also provides the console clients epic and 1q for those who eschew X. If you don't already have a favorite, you should try them all.

> **CAUTION**
> You should never use an IRC client while you are the root user. It is better to create a special user for IRC because of potential security problems. To use X-Chat in this manner, you open a terminal window, use su to change your IRC client, and start the xchat client.

X-Chat is a popular IRC client, and it is the client that is used in this chapter's example. The HTML documents for X-Chat are available in /usr/share/docs/xchat-1.8.10. It is a good idea to read them before you begin because they include an introduction to and some of the basics of IRC. To launch the X-Chat client, select the IRC Client item from the Internet menu found under the Extras menu, or you can launch it from the command line, like this

```
$ xchat
```

The X-Chat application allows you to assign yourself up to three nicknames. You can also specify your real name and your user name. Because many people choose not to use their real names in IRC chat, you are free to enter any names you desire in any of the spaces provided. You can select multiple nicknames; you may be banned from an IRC channel under one name, and you could then rejoin another. This seems slightly juvenile to you, then you are beginning to get an idea of the type of behavior on many IRC channels.

When you open the main X-Chat screen, a list of IRC servers appears, as shown on Figure 20.8.

After you choose a server by double-clicking, you can view a list of channels that are available on that server by choosing Window, List Window. The X-Chat Channel List appears. In that window, you can choose to join channels that feature topics that interest you. To join a channel, you double-click it.
