# Creating and Executing a Simple Shell Program with bash

```
$ mkdir bin
$ mv myenv bin
$ myenv
```

This works included because Red Hat, by default, includes the executable path $HOME/bin in your shell's environment, which can be viewed by piping the output of the env command through grep like so:

```
$ env | grep PATH
/usr/kerberos:bin:/usr/local/bin:/bin:/usr/bin:\n/usr/X11R/bin:/sbin:/home/bball/bin
```

As you can see, the user (bball in this example) can use bin to hold executable files.

> The pdsh included with Red Hat Linux was originally created by Eric Ginsburg and it is a public domain of the ksh shell. In Red Linux, pdsh is named ksh. Two symbolic links, /usr/bin/pdsh and /usr/bin/ksh, point to the pdsh shell, named /bin/ksh. For more information about pdsh, see the /usr/share/pdsh directory or read the ksh man page.
On March 1, 2000, AT&T released the official version of the ksh shell named KornShell 93, as open source. If you're interested in trying the original ksh shell by David Korn, it is available for Linux at http://www.research.att.com/sw/download/.

> Never put in $PATH in order to execute files or a command in the current directory—this presents a security risk, especially for the root operator, and even more so: is in your $PATH search order. Trojan scripts placed by crackers in directories such as /tmp can be used for malicious purposes, and will be executed immediately if the current working directory is part of your $PATH.

# Storing Shell Scripts for Systemwide Access

After you execute the command myenv, you should be able to use ls from the command line to get a list of files under the current directory and ll to get a list of files with attributes displayed. The best way to use the new commands in myenv is to put them into your shell's login or profile file. For Red Hat Linux users, the default shell is bash, so you can make these commands available for everyone on your system by putting them in the /etc/bashrc file. Systemwide aliases for tsh are contained in files with the extension .csh added to the /etc/profile.d directory. The pdsh shell can use these command aliases as well.
