# The Window Maker Window Manager (wmaker)

The Window Maker window manager mimics the legacy NeXT computer interface and provides a wharf (that is, an application dock), desktop menus, themes, and virtual desktops. You can set up Window Maker use with the wmaker utility, like so:

```
$ wmaker.inst
```
