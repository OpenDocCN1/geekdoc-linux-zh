
# An Overview of Emulators Available for Red Hat Linux

Some emulators mimic a "virtual" computer inside your real computer, and others translate other OS calls to Linux kernel system calls. Other software use emulation to provide system management or development environments; still others might be used to run virtual networks or install and then running operating systems. System administrators new to Red Hat Linux will quickly learn that Linux "plays well" with other operating systems, and emulators help make that happen.

Red Hat Linux provides the Wine software emulator that manages and runs Microsoft Windows software and the VNC software for accessing the desktops of other computers running other operating systems or Linux distributions. Many other emulators are available.

> Red Hat does not provide emulators other than Wine or cross-platform tools other than VNC and the Mtools (all discussed later in the chapter) because they choose not to offer support for other Open Source emulators and commercial emulators. They also do not provide Cygwin, a cross-platform development environment, although they do. Cygwin is discussed later in the chapter as well.

Other tools such as cross-compilers are available for Red Hat Linux and allow program development for different target CPUs and operating systems (for example, the Palmos, currently hosted by the Motorola Snapdragon processor). Many developers around the world use Red Hat Linux as an inexpensive platform for acquiring and using these cross-compilers and emulators when developing, testing, and producing software for other computers.

Some of the more sophisticated and powerful emulation software such as Win4Lin and VMware are commercial in nature and are not provided with Red Hat Linux. Those companies do, however, provide versions of their software adapted to Red Hat Linux.

# Using the Bochs Emulator and FreeDOS Utilities

Bochs is a free machine emulator that allows Red Hat Linux users to run a FreeDOS session (among other operating systems) in a window on your desktop. You can use this software to run many legacy DOS applications and games, create bootable DOS-formatted media, or create embedded applications using development tools that require a DOS environment. FreeDOS (http://www.freedos.org/) is a freely available disk operating system that is compatible with Microsoft DOS. Red Hat supplies neither FreeDOS nor Bochs, although both are Open Source software.

You can download a "ready to use" version of the Bochs emulator from the Bochs page (http://bochs.sourceforge.net), along with a FreeDOS tar archive containing a Bochs resource file and prepared FreeDOS hard drive image to use with the emulator.

# Using the Bochs Emulator and FreeDOS Utilities

The RPM package provides Bochs emulator and related files (such as BIOS and ROM images used for emulation), which will be installed under the /usr/bochs directory. The FreeDOS distribution of free DOS commands creates a directory named freedos-img. You do not have to be the root operator to use Bochs or to install the FreeDOS image directory.

Use the rpm command (as root) to install Bochs:

```bash
# rpm -ivh bochs-1.4.i386.rpm
```

The rpm command will extract Bochs and its support files into the /usr/bochs directory, and then will automatically set up support for running Bochs under X11.

> The /usr/bochs/dllinux directory contains a bootable disk image that will boot a Linux 1.3.89 kernel session under emulation. After installing Bochs, use the bochs-dlx command: bochs-dlx &

Next, extract the FreeDOS bootable hard and floppy drive image directory using the tar command as this:

```bash
$ tar xvzf freedos-img.tar.gz
```

This creates the freed-img directory in your home directory. To start a Bochs session using FreeDOS from an X11 terminal window, navigate into the freedos-img directory and use the bochs command like this:

```bash
$ cd freedos-img
$ bochs
```

After you press Enter, Bochs displays a main menu and text that explains the process for configuring Bochs to simulate the computer of your choice:

Bochs Configuration: Main Menu

This is the Bochs Configuration Interface, where you can describe the machine that you want to simulate. The first choice, "Read options from...", lets you read in a saved machine configuration from a file. The second choice lets you edit the current configuration. The third choice saves the current configuration to a file so that you can use it again next time. When you are satisfied with the configuration, go ahead and start the simulation.
