# CHAPTER 8 Managing Software and System Resources

# Two Handy Options

By appending -vh to any option, you get

+   - v Some status feedback
- h Hash marks as the work proceeds

| Option | Used To |
| --- | --- |
| rpm -i | Install a Package |

# Useful options to -i:

+   - excluded Don't install documentation to save space.

+   - replacepkg Replace the package with a new copy of itself.

+   - force The "big hammer"—ignore all warnings and install anyway.

+   - noscripts Don't execute any pre- or post-install scripts.

+   - nodeps Ignore any dependencies.

+   - root <path> Set an alternative root to <path>.

# rpm - Erase (delete) a Package

# Useful options to -e:

+   - nodeps Ignore any dependencies.

rpm -U Upgrade a package, removing the older one but keeping modified files, such as configurations.

# Useful options to -U:

+   - oldpackage Permits downgrading to an older version.

Other options are the same as with rpm -1.

# rpm -q Queries about Package Information

# Useful options to -q:

+   -p <file> Display all information about the package <file>.

+   - f <file> What package owns the file <file>?

+   - whatprovides <x> Determine what packages provide <x>.

+   - whatrequires <x> Determine what packages require <x>.

+   -i Summarize the package information.

+   - l List the files in package.

+   - scripts Display the contents of any install, uninstall, or verify scripts.

+   - provides Display the capabilities package provides.

+   - requires Display the capabilities package requires.
