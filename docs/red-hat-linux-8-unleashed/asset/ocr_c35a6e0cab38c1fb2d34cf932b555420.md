+   * /usr/local/apache2—The cgi-bin, icons, and hdocs subdirectories contain the CGI programs, standard icons, and default HTML documents, respectively.

+   * /usr/local/apache2/bin—The executable programs are placed in this directory.

+   * /usr/local/apache2/logs—The server log files are placed in this directory. By default, there are two log files—access_log and error_log—but you can define any number of custom logs containing a variety of information (see the "Logging" section later in this chapter). The default location for Apache's logs as installed by Red Hat Linux is /var/log/httpd.

# A Quick Guide to Getting Started with Apache

Setting up, testing a Web page, and starting Apache using Red Hat Linux can be accomplished in a few steps. First, make sure Apache is installed on your system by selecting it during installation or installing Red Hat's httpd and related RPM files (refer to Chapter 8 if you need to install the server software).

Next, set up a page for your system by editing (as root) the file index.html under the /var/http://www/html directory on your system. Make a backup copy of the original page or www directory before you begin so that you can restore your Web server to its default state if necessary.

Start Apache (again, as root) using the service command with the keywords httpd and start, like this:

```
# service httpd start
```

You can also use the httpd script under /etc/rc.d/init.d/ directory, like this:

```
# /etc/rc.d/init.d/httpd start
```

You can check your home page by running a favorite browser and using localhost, your system's hostname, or its Internet Protocol (IP) address in the Uniform Resource Locator (URL). For example, with the links text browser, use a command line like:

```
# links http://localhost/
```

Note that for security reasons you shouldn't start and run Apache as root if your host is connected to the Internet or a company intranet. Fortunately, Apache is set to run as the user and group apache no matter how it's started (by the User and Group settings in /etc/httpd/httpd.conf). This safe default, Apache should be started and managed by the user name (defined in /etc/passwd). After you are satisfied with your Web site, use the setup (select Services) or ntsysv (select httpd) commands to ensure Apache is started properly.
