# Stronghold

If you’re looking for a little more secure than Apache, but still don't want to lose the Apache functionality, you can purchase Stronghold from Red Hat Software.

Although not a Web server per se, Stronghold is a add-on that provides 128-bit cryptography and security certificates to the Apache Web server (which is included in your purchase of Stronghold).

Stronghold supports SSL and TLS security standards, as well as many of the certificate standards on the market today.

The price for this of security isn’t particularly light, which can be previewed at http://www.redhat.com/software/apache/stronghold/, costs $995 (U.S.).

# Zope

Zope is another Open Source Web server. Although it’s still relatively young and might not have as much flexibility as Apache, it is making inroads in the Web server market.

What makes Zope different from Apache is the fact that it’s managed through a completely Web-based graphic interface. This has broad appeal for those who aren’t enthused about a command-line-only interface.

Zope is a product of the Zope Corporation (formerly Digital Creations), the same firm that made the Python programming language. And, like all things open, it is free. Information on Zope can be found at http://www.zope.com (for the commercial version) and http://www.zope.org (for the open source version).
