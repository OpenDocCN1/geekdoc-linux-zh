> NOTE Not all software comes in RPM packages. For everything else, you can use KDE's arch to easily install, browse, read, and extract contents of compressed files, including legacy archives as tarballs or compressed tar archives (recognized by .gz or .tgz extensions). Other compressed files, such as those created with the compress command (ending in .2) or bzip2 files (ending in .bz2), are also supported by arch. The client will also convert archives between gzip and bzip2 formats. This client is included with the KDE distribution, but is not part of the Red Hat base KDE package. Use the Package Manager to install it.
