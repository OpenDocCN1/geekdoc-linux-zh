Although each Mtool is only a symlink to the solitary mtools binary, each has its own managepage. There are more than twenty Mtools, and you can identify their functions by their m* name. The most useful Mtools are

+   mdir--The DOS directory command
mcopy--The DOS copy command
mformat--The DOS format command

You use the Mtools as you would their DOS counterparts.

Note that the mformat command only does a high-level format of the filesystem and you need to use the Linux一起format command first; formats higher than 1.4M are possible with mformat. MtoolsFM is a graphical front end to the mtools that can be down-loaded from http://www.core-cutainville.org/MtoolsFM/; they provide an RPM file for download because Red Hat does not include the tool, as shown in Figure 27.11.
