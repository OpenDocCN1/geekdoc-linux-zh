NOTE
By default, Red Hat Linux uses the logwatch monitoring command (actually a Perl script) in your system's /etc/crontab.daily directory to generate various reports each day at 0402 (4:02 a.m.). Configure logwatch by editing the file /etc/log.d/logwatch.conf. Other system monitoring tools are included, such as tripwire. System logging can be controlled by editing
/etc/syslog.conf.

You can test the script by running it manually and feeding it a keyword and a pathname to the system log, /var/log/messages, with this:

```
# greplog failure /var/log/messages
```

Note that your system should be running the syslogd daemon. If any login failures occurred on your system, the root operator might get an email message that looks like this:

```
Date: Tue, 27 Aug 2002 17:22:53 -0400
From: root <root@shuttle.home.org>
To: root@shuttle.home.org
Subject: failure
```

```

Linux shuttle.home.org 2.4.18-3 #1 Apr 18 07:31:07 EDT i2686 unknown
Log report for shuttle.home.org on Tue 27 Aug 2002 05:22:53 PM EDT
======================================================
```

```

```

```

logname=bball uid=500 eid=0 tty= user=bball rhost= user=root
```

```

```

To further automate the process, you can include command lines using the script in another script to generate a series of searches and reports.

# Built-in Variables

Built-in variables are special variables provided to shell Linux that can be used to make decisions within a shell program. You cannot modify the values of these variables within the shell program.
