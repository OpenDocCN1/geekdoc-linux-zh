You can use the following three configuration tools, among others, to create a working XF86Config file:

+   - redhat-config-xfree86—This is Red Hat's graphical configuration tool, which launches an X session to create an XF86Config file.
- xf86config—This is a text-based configuration tool that does not require an X session.
- XFree86—This can create a skeletal working configuration.

The sections that follow discuss how to use each of these software tools to create a working XF86Config file:

# Configuring X with the redhat-config-xfree86 Client

You can use the redhat-config-xfree86 client to create or update an XF86Config file. By begin, or root, start the client from the command line, like this:

```
# redhat-config-xfree86
```

The screen clears, and redhat-config-xfree86 attempts to start an X session. If this client during an X session, its main window appears, as shown in Figure 6.1.
