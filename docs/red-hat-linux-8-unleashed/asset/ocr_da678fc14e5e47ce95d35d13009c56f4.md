The items shown are networking parameters, and actually tweaking these values beyond the scope of this book. If we wanted to change a value, however, the -w command is used:

```
# sysctl -w net.ipv4.tcp_retries = 20
```

This increases the value of that particular kernel parameter.

> NOTE
Red Hat provides a graphical interface to the sysctl command in redhat-config-proc. It's a beta-quality application, and it must be launched from the command line. The interface itself is unremarkable, and it does not provide a means to manipulate all the possible values, butit offer useful help for the kernel variables addresses.

If you find that a particular setting is useful, you can enter it into the /etc/sysctl.conf file. The format is as follows, with the earlier example:

```
net.ipv4.tcp_retries = 20
```

Of more interest to kernel hackers than regular users, sysctl is a potentially powerful tool that continues to be developed and documented.
