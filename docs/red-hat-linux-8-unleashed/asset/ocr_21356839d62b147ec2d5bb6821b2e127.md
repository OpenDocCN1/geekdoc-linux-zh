# Comparison of Expressions in pdsh and bash

The pdsh and bash shell syntax provide a command named to compare strings, numbers, and files. The syntax of the test command is as follows

```
expression
```

or

```
[ expression ]
```

Both forms of the test commands are processed the same way by pdsh and bash. The test commands support the following types of comparisons:

+   - String comparison
- Numeric comparison
- File operators
- Logical operators

# String Comparison

The following operators can be used to compare two string expressions:

```
=To compare whether two strings are equal
!-To compare whether two strings are not equal
-n—To evaluate whether the string length is greater than zero
-z—To evaluate whether the string length is equal to zero
```

