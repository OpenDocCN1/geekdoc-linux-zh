## Session Message Block Printing

Printing to to an SMB printer requires Samba, along with its utilities such as the smclient and associated smbprint utility. You can use the software included with Red Hat to print to a shared printer on a Windows network or set up a printer attached to your Red Hat system as an SMB printer. For details about Samba, see Chapter 13, "Network Connectivity." This section describes how to create a local printer to be able to print to a remote printer using SMB.

Setting up an SMB, or shared printer is usually accomplished under Windows operating systems through configuration settings using the Control Panel's Network device. After enabling printer sharing, reboot the computer. In My Computer, Printers folder, right-click the name/icon of the printer you want to share and select Sharing from the pop-up menu. Set the Shared As item; then enter a descriptive name, such as HP400, and a password.

You must enter a name and password in order to configure the printer when running Linux. You will also need to know the printer's group name, IP address, printer name, and the username and password on hand. To find this information, choose Start, Settings, Printers, and right-click on the shared printer's listing in the window, and choose Properties from the pop-up window. As before, create a local printer queue, assigning it a name, and then select Printer in the Set Queue Name and Type dialog box. Click the Forward button, and then enter the required information, as shown in Figure 12-11.

Create a printer queue with characteristics that match the remote printer. For example, if the remote printer is an HP 400 Deskjet, select the driver listed for that device in your configuration.) Do not forget to save and restart after creating or editing a local or remote printer queue. The new entry in /etc/printcap might look like this:

```
hp400deskjet:
:mx#0:\n:sd=/var/spool/hp400deskjet:\n:af=/var/spool/lpd/hp400deskjet/hp400deskjet.acct:\n:sh:
:lp|/usr/share/printconf/util/smbprint:
:lpd-bounce=true:
:if=/usr/share/printconf/util/mf_wrapper:
```

## Network-Attached Printer Configuration and Printing

Red Hat Linux supports other methods of remote printing, such as using a Novell Network-based print queue or using a printer attached directly to your network with an HP JetDirect adapter. Some manufacturers offer even Linux-specific drivers and help. For example, HP/Compa provides graphical printer configuration tools and software drivers for earlier versions of Red Hat Linux at http://h20000.www2.hp.com/bizsupport/index.jsp.

You can set up network-attached printing quickly and easily using Red Hat Linux. For example, GEARNET's PS101 print server adapter works well with Linux. This tiny device (a self-hosted print server) is an adapter that directly attaches to a Centronics jack, and eliminates the use of a parallel-port cable. The PS101 offers a single 10Mbps Ethernet jack, and after initial configuration and assignment of a static IP address, can be used to print to any supported printer by Red Hat Linux.

A JetDirect- or UNIX-based configuration using redhat-config-printer can be used to allow you to print to the device from your Red Hat system. To see any open ports or services on the device, use the nmap command with the print server adapter's IP address like:

```
$ nmap 192.168.2.52

## Using Print Commands

After configuring your printer, you can print from the Red Hat desktop using graphical clients. If you don’t use the desktop but prefer to use the command line, the main commands are as follows:

- lpr: Line printer spooling command; used to print documents using a specific printer
- lpq: Line printer queue display command; used to view the existing list of documents waiting to be printed
- lprm: Line printer queue management command; used to remove print jobs from a printer
- lpc: Line printer control program; used by the root operator to manage spooling, the lpd daemon, and printer activity

These commands provide all the basic features needed to start and control printers from the command line. By default, Red Hat Linux uses Patrick Powell's LPRng spooler, an improved and totally revised version of the 4.3BSD printing system. Configure this printing system by editing the /etc/lpd.conf file; default, no options are enabled in Red Hat Linux. You can get a status of the printing by using LPRng's checkpc command like this:
