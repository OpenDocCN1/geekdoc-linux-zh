# Changing Your User Information

Linux users are assigned a name, known as a username, by the root operator. One method
ofassigning usernames is to use one's first initial and last name in lowercase; for example,
Beth Smith would have a username of bsmith. Each user must also have a password, which
is used with the username either at a graphical or text-based login.

> NOTE
Older versions of Red Hat limited the length of usernames to eight characters. The current
version of Red Hat limits usernames to 32 characters. Good passwords should be a
minimum of eight characters and contain upper- and lowercase letters, along with numbers.
Random passwords for users can be generated using the mkpasswd command. For example,
automatically generate a 10-character password with three numbers and two digits, use
kpasswd -l 10 -d 3 -C 3.

You cannot change your username, but you can change your user information, such as
address, phone, and so on. You make these changes using the chfn or change finger infor-
m command. This command will modify the contents of your entry in the system
file /etc/passwd, which is used by the finger command to display information
about a system's user. For example, type chfn at the command line and press Enter:

$ chfn

Changing finger information for pjovanovich.
Password:
Name []: Pete Jovanovich
Office []: Suite 120 N. Arlington Blvd.
Office Phone ]: 202 555-1212
Home Phone ]: 202 555-1212
Finger information changed.

You're led through a series of prompts to enter new or updated information. Note that the
chfn command will not let you use commas when entering information. You can
verify this information in a couple of ways, for example, by looking at the contents of
/etc/passwd.
