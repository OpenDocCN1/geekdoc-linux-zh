> Autounting with the Automount Daemon (amd) and autofs

The automount daemon will watch specified devices and mount the devices when they are accessed and unmount them there has been no activity. The configuration files are /etc/auto.master and /etc/auto.misc. The former file contains only contents; the latter contains examples and the sole entry used by Red Hat to automount the CDROM. If you insert a CD, after a long pause, a file browser will appear on your desktop. Many people find this behavior annoying and prefer to disable automount.

Because autofs is started at boot time and controls the automount daemon, simply don't run autofs. Use the checkconfig, ntserv, or GUI clients to edit the startup scripts for your runlevel (see Chapter 7, “Managing Services,” for details).
