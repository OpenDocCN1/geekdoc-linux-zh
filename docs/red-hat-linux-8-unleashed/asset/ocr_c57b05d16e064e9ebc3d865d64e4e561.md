In this chapter, you learn about the process that Red Hat Linux goes through when it boots. After you turn on the power switch, the Linux boot process begins when the special boot loader code starts the Linux kernel and does not end until the login prompt appears. This chapter also discusses how system states or runlevels can control what system services are started up boot up. These “services” are simply applications running in the background that provide needed information from your mouse and sending it to the display; or a service could monitor the partitions to see whether they have enough free space left on them. Services are typically loaded and run (“started”) during the boot process.

As a system administrator, you’ll use the skills you learn in this chapter to control your system’s services and manage system states on your computer. Understanding these system services and states is essential to understanding how Linux works (especially in a multiser environment) and will help untangle some of the mysteries of your Red Hat Linux system’s configuration files.

You can manage nearly every aspect of your computer and how it behaves after booting through configuring and ordering-boot scripts, as well as using various system administration utilities included with Red Hat Linux. Here, you learn how to work with these boot scripts and system administration utilities. This chapter also offers advice for troubleshooting and fixing problems that might arise with software configuration or the introduction or removal of various types of hardware from your system.
