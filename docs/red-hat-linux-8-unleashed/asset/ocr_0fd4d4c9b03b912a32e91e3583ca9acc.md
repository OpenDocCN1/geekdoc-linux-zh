# Reading Documentation

Although you learn the basics of using Red Hat Linux in this book, you need time and
practice to master and troubleshoot more complex aspects of the operating system and
distribution. As with any operating system, you can expect to encounter some problems or
plexing questions as you continue to work with Red Hat Linux. The first place to turn
 help with these issues is the documentation included with your system; if you can't
find the information you need there, check Red Hat's Web site.

> Checking Red Hat's Web for security updates and bug fixes is a good idea. Browse to
http://www.redhat.com/apps/support/errata/index.html.

Linux, like UNIX, is a self-documenting system, with manual pages accessible through the
man command. Red Hat Linux offers many other helpful commands for accessing its docu-
mentation. You can use the apropos command—for example, with a keyword such as
partition—to find commands related to partitioning, like this:

+   $ apropos partition
