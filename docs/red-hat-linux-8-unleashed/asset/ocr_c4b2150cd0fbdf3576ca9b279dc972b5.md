# Configuring and Using Tripwire

Tripwire is a security tool that will check the integrity of normal system binaries and report any changes to syslog or by email. Tripwire is a good tool for ensuring that your binaries have not been replaced by Trojan horse programs. Trojan horses are malicious programs inadvertently installed because of identical filenames to distributed (expected) programs, and they can wreak havoc on a breached system. Red Hat Linux includes a free version of Tripwire that can be used to monitor your system. To set up Tripwire for the first time, run the twinstall.sh script (found under /etc/tripwire) as root like so:

```
# /etc/tripwire/twinstall.sh
```

The Tripwire site and local passphrases are used to sign a variety of files, such as the configuration, policy, and database files.

Passphrases should be at least 8 characters in length and contain both letters and numbers.

See the Tripwire manual for more information.

You'll need to enter a password of at least eight characters (perhaps best is a string of random amass, as 5fw4hn) at least twice. The script will generate keys for your site (host) and then ask you to enter a password (twice) for local use. You'll be asked to enter again the new site password. After following the prompts, (rather extensive) default configuration and policy files (tw.cfg and tw.pol) will be encrypted. You should back them up and delete the original plain-text files installed by Red Hat's RPM package.
