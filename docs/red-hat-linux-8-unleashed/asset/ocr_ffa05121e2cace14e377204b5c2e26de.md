# Red Hat and Linux Commands

You can use these commands to create and configure the X Window System in Red Hat Linux:
XFree86—The X server that is provided with the X Window System distribution from The XFree86 Project, Inc.

xf86-config—A console-based X configuration utility that is used with XFree86
mouseconfig—Red Hat's text-based GUI pointing-device-configuration program
kcontrol—The KDE Control Center client
redhat-config-xfree86—Red Hat's graphical XFree86 configuration tool
redhat-config-mouse—Red Hat's graphical mouse configuration tool
gdmconfig—The GNOME display manager configuration client
startx—A shell script that is used to start one or more X sessions from the shell line\xsri—Red Hat's display manager root desktop decoration client
