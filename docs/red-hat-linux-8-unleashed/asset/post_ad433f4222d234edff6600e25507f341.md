## User Considerations

Humans are creatures of habit. So it can be hard to transition a workforce, customer base, or other community to a new environment. The Red Hat desktop, however, provides a de friendly and familiar interface with menus and icons that new users can readily learn and put to work.

Part of the migration process can involve addressing user concerns, especially if Linux will take over the desktop. Red Hat can be deployed in stages to make the migration process a bit easier, but the issue of user training will need to be addressed early on. This is especially true if users will be required to develop new skills or be aware of any caveats when using Linux (such as deleting all files in one's home directory). Although Red Hat can be configured to provide a “turn-key” desktop in which only graphical applications (such as a web browser, organizer, or word processor) can be used, some users will want and need to learn more about Linux.

You can turn to formal Linux training from commercial vendors. System administrators can also get training directly from Red Hat (go to http://www.redhat.com/training). For other issues concerning Linux in larger computing environments, browse to Linux Vegas's Linux Enterprise Computing pages at http://linux.org/linux/.

## Planning the Installation

There are many factors in favor of using Red Hat Linux as a computing solution. The current distribution can fill many roles on various tiers and hardware platforms because Red Hat Linux offers preconfigured installation scripts to fit development, workstation, e-commerce, server, and mobile platform—only the required software will be installed.

Addressing concerns beforehand can help quell any worries or fears felt by new users. Some key factors include

- Preparation—Thoroughly discuss the migration or deployment, along with benefits, such as greater stability and availability of service.
- Preconfiguration—If possible, give users a voice in software choices or categories and poll for comments regarding concerns.
- Correct installation—Ensure that Linux is working properly.
- The right hardware—Make sure the hardware is compatible.

## Meeting Minimum Red Hat Hardware Requirements

Red Hat, Inc. publishes general minimum hardware requirements for installing and using Linux. For the current release, your PC should have at least a Pentium CPU, 650MB hard space, and 64MB RAM for using Linux without a graphical interface.

## Using Legacy Hardware

If you have an older PC based on a 486 CPU with only 32MB RAM and a 500MB hard drive, you can install an older version of Red Hat Linux and upgrade to newer software packages from source or by using the rpm command. If you prepare a hard drive in a PC with a different CPU, such as a Pentium, and then install it in a PC with 486 CPU, you should make sure that a 486-based kernel is installed.

Installing Red Hat on legacy hardware will be easier if you choose older Pentium-class PCs. Such computers can be purchased at a fraction of their original cost, and can easily handle mundane but useful tasks. Some of the tasks suitable for older hardware include

- Acting as a firewall, router, or gateway
- Audio jukebox and music file storage server
- Handling electronic mail
- Hosting a remote printer and providing remote printing services
- Network font server
- Providing FTP server capture
- Remote logging capture
- Secondary network-attached backup server
- Serving as an Intranet (internal LAN) Web server
- Unattended dial-up gateway, voice mailbox, or fax machine
- Use as a "thin client" workstation for basic desktop tasks

To get the most out of your hardware, don't install any more software than required. To get a little performance boost, add as much RAM as economically and practically feasible. If you can't, cut down on memory usage by turning off unwanted or unneeded services.
