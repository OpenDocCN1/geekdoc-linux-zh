Load glx

Driver "nv"

Driver "nvidia"

Check that the new kernel module is installed. Look at the listing produced by # lsmod and see whether the NVdriver is listed. If not use # modprobe NVdriver to load it and check again.

If everything looks okay so far, test X by starting “naked” with # X. If you see a gray screen with an X for a cursor, you’re successful! Kill X with the Ctrl+Alt+Backspace key combination and then run to level 5 with # telinit 5.

If something goes amiss along the way, reread the NVdriver instructions and check your spelling (we misspelled nvidia twice during our attempts). The PDF document available from NVIDIA contains not only the installation instructions, troubleshooting and tweaking information as well. The only problem that you’ll encounter is that the Red Hat XFree86 configuration tool won’t recognize the NVIDIA driver and will replace it with the XFree86 driver if you ever use the Red Hat graphical configuration tool.

# Installing Unreal Tournament 2003

The free demo can be downloaded from the homepage at http://www.unrealtourna-ment2003.com/ or from any other source on the Internet; it’s a 96MB download, however. After it’s downloaded, the game can be installed with

```
# sh ./ut2003-Demo-Linux.sh .bin
```

It will install in /usr/local/games/ut2003_demo/ by default. The game can be launched with

```
$ /usr/local/games/ut2003_demo_ut2003_demo &
```
