# Codewavers Crossover and Codewavers Wine 1.0

Codewavers, a software development company specializing in Wine development, has used Wine for several Open Source and commercial projects and has made many contribution to Wine development.

Codewavers' initial project is an attempt to produce a 1.0 release of Wine. (This particular Wine variant is older than the one currently provided by Red Hat, but contains code not included in the standard version of Wine provided by Red Hat.) While still not finished, this Wine version does sport a useful, no-cost, proprietary configuration tool. It is possible to download Codewavers' version of Wine, install it to get the GUI configuration tool (see Figure 27.4), and then update to the Red Hat by reinstalling the Red Hat after you have installed the Codewavers' version.

# CAUTION

Codewavers' configuration tool, although free of cost, is proprietary. Some might have an objection to its use on their computers. Read the licensing terms before installing.
