Enabling Spamassassin is simple. You must first have installed and configured Procmail. The README file found in /usr/share/doc/spamassassin-2.31 provides details on configuring the .procmail file to process mail through Spamassassin. It will tag probable spam with a unique header; you can then have Procmail filter the mail in any manner you choose. One interesting use of Spamassassin is to use it to tag email received at special email accounts solely for the purpose of attracting spam. This information is then shared with the Spamassassin site where "spam trap" generated hits help the authors fine-tune the rulesets.

# Squiremail

Perhaps you don't want to read your mail in a MUA. If you use your Web browser, it might make sense to read and send your mail via a Web interface, like the one used by Gmail or Yahoo! Red Hot has Squiremail for that purpose. Squiremail is written in PHP4 and uses IMAP and SMTP with all pages rendering in HTML 4.0 without using Java. It supports MIME attachments, as well as an address book and folders for segregating email.

You must configure your Web server with PHP4. Detailed installation instructions can be found in /usr/share/doc/squiremail-1.2.7/INSTALL. Once configured, point your Web browser to http://www.yourdomain.com/squiremail to read and send mail.

# Virus Scanners

Although the currently held belief that Linux is immune to email viruses targeted at Microsoft Outlook users, it certainly makes no sense for UNIX mail servers to permit infected email by sending through them. Red Hot does not provide a virus scanner, one of the more popular of such scanners is MailScanner, available from http://www.sng.ecs.soton.ac.uk/mailscanner/; a Red RPM package is available as well as the source code. It provides Sendmail and Exim (another MTA, not provided by Red Hot), but not Postfix or Qmail. Searching on the terms "virus" and "email" at Fresh.net will turn up a surprising list of GPL'd virus scanners that might serve your needs.

# Special Mail Delivery Agents

If you already use Hotmail or any other Web-based email account, the currently available MUAs will not be useful to you; formal POP3 access to a Hotmail account is not available free of charge. However, Microsoft Outlook Express can access Hotmail at no cost using a special protocol called HTTPMail. What that's done covered in RFC-2518 as "WebDAV extensions to HTTP/1.1." No specific solution is provided by Red Hot Linux, but the basic tools it provides are adequate when supplemented by some clever Perl programming.

Hotway is available from http://people.freetenet.de/courierave/ and implements this functionality, allowing you to use your favorite mail client to read mail from Hotmail.
