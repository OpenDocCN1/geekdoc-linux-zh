## Reverse Resolution

Given an IP address, it is often necessary to find the name associated with it (this process is known as reverse resolution or reverse lookup, accomplished with the help of filenames "backward" from DNS point of view). Because we can only associate RRs with names, we must find a way to write an IP address with left-to-right hierarchy (129.42.18.99 belongs to ibm.com). We do this by reversing the order of the octets and then appending .in-addr.arpa to the result. For example, 129.42.18.99 written as 99.18.42.129.in-addr.arpa (Pointer) records associated with this special name would then be the real name to which the IP belongs. We look for PTR records in the usual fashion—by following a chain of delegations from a root server. examine resolving 203.200.109.66 (which is one of the IP addresses that an ISP assigns to customers).
