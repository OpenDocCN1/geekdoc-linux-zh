Click the desired system, and click the OK button. You will then need to stop the lpd daemon and start or stop CUPS. For example, if you use LPRng, but want to switch to CUPS, stop lpd like so:

```
# /etc/rc.d/init.d/lpd stop
```

You must make sure that xinetd has enabled cups-lpd service by editing /etc/xinetd.d/cups-lpd and restarting xinetd. For example, /etc/xinetd.d/cups-lpd to read

```
disable = no
```

Save the file; then restart xinetd

```
# /etc/rc.d/init.d/xinetd restart
```

You can then start CUPS like this:

```
# /etc/rc.d/init.d/cups start
```

After starting CUPS, create a printer configuration by launching a browser (such as mozilla) and browsing to http://localhost:631. CUPS provides a Web-based administration interface, as shown in Figure 12.14.
