This output (from the dmesg command) shows that the eth0 device has been reported.
DHCP is in use, the device should automatically join the nearest wireless subnet and will
automatically assigned an IP address. If not, the next step is to use a wireless tool such
iwconfig to set various parameters of the wireless device. The iwconfig command,
along with the device name (eth0 in this example), will show the status:

```
# iwconfig eth0
eth0 IEEE 802.11-SSID:GreyUFO Nickname:Prism I"
Mode:Managed Frequency:2.412GHz Access Point: 00:02:2D:2E:FA:3C
Bit Rate:2MB/s Power-Tx=15dB Sensitivity:1/3
TS rt:off Fragment:off
Encryption key:off
Power Management:off
Link Quality:92/92 Signal level:-11 dB Noise level:-102 dB
Rx invalid nwid:0 Rx invalid crypt:0 invalid frag:0
Tx excessive retries:0 Invalid misc:4 Missed beacon:
```

This example shows a 2Mbps connection to a network named GreyUFO. To change a para-
meter, using the transmission rate, use a command-line option with the iwconfig
command like so:

```
# iwconfig eth0 rate 11M
```

Other options supported by the iwconfig command include ssid, used to set the NIC to
connect to a specific network by named; mode, used to allow the NIC to automatically
retrieve settings from an access point or connect to another wireless host; or freq, to set a
frequency to use for communication. Additional options include channel, frag, enc for
(encryption), power, and txpower. Details and examples of these options are in the
iwconfig manual page.

One can use the ifconfig command or perform a graphical Red Linux tool to set
the device networking parameters, and the interface will work as a hardwired LAN.
One handy output of the iwconfig command is the link quality output, which can be
used in shell scripts or other graphical utilities for signal monitoring purposes (see Chapter
22, "Shell Scripting," for an example).
