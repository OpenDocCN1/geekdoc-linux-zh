# Resetting the Date and Time

Red Hat Linux will query you for installation date time settings, and or not your computer's hardware clock is set to Greenwich Mean Time (GMT)—more properly known as UTC, or Coordinated Universal Time.

Linux provides a system date and time; your computer hardware provides a hardware clock-based time. In many cases, it is possible for the two to drift apart. Linux system is based on the number of seconds elapsed since Jan. 1970. Your computer's hardware time depends on the type of chips installed on your PC's motherboard, and many motherboard chipsets are notoriously subject to drift.

Keeping accurate time is not only on a single workstation, but also critically important in a network environment. Backups, scheduled downtimes, and other network-wide actions need to be accurately coordinated.
