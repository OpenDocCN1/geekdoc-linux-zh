In the dialog, click in the Path field under Base options and type the pathname of the directory, such as /music. Next, select No in the Read Only field under Security options to allow users read and write access to the share, or leave the default Yes to protect the directory's data. Make sure that the Guest Ok option is set to Yes to allow access from other users. In the Hosts Allow field, enter a hostname, IP address, or subnet (such as 192.168.2.—note the trailing period) to allow access. When finished, click the Commit Changes button. Remote users can access the shared folder.

# Wireless Networking

As stated earlier, Linux has support for wireless networking since the first standards were developed in the early 90s. With computers getting smaller and smaller, the uses for wireless networking increased; meanwhile, the transmission speeds are increasing all the time. There are different ways to create a wireless network. The following sections introduce you to several Linux commands you can use to initialize, configure, and manage wireless networking on your Red Hat system.

# Support for Wireless Networking in Red Hat Linux

With the 2.4 kernel, which ships with Red Hat now, support for wireless networking is now included in the kernel. Related wireless tools for configuring, managing, or displaying information about a wireless connection include

+   * iwconfig—Used to set the network name, encryption, transmission rate, and other features of a wireless network interface
* iwlist—Displays information about a wireless interface, such as rate, power level, or frequency used
* iwpriv—Used to set optional features, such as roaming, of a wireless network interface
* iwspy—Shows wireless statistics of a number of nodes

Support will vary for different wireless devices—most likely in the form of a PCMCIA adapter—although some USB devices now work with Linux. In general, Linux wireless software (usually in the form of a kernel module) will support the creation of an Ethernet device that can be managed by traditional interface tools such as ifconfig—with wireless features of the device managed by the various software tools.
