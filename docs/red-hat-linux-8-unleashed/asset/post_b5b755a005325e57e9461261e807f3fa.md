Sound service is started by the /etc/rc.d/rc.sysinit boot script and is specified in the file name soundcard under the /etc/sysconfig directory. As the example shows, this file is generated by the sndconfig command. Use this command if you install a new or different sound card in your PC. Start this command (root) like this:

- sndconfig

> NOTE you can also launch sndconfig using Red Hat's setup command like this:

# setup

After you press Enter, scroll down to the Sound card configuration item, and then tap the key to highlight the Run Tool button. The sndconfig command will start after you press Enter.

After you press Enter, sndconfig will probe for any installed sound hardware. Installing a sound card in a PC with built-in sound on the motherboard will usually disable the built-in sound chipset; however, you might need to specifically disable built-in sound hardware by changing the PC's BIOS settings.

## Detecting and Configuring a Modem

More than seven million users in the United States now connect to the Internet with cable DSL service, but for many users a modem is the standard way to connect with an Internet service provider (ISP) using the Point-to-Point Protocol (PPP). Other common tasks for modems include adding or changing your modem after the initial Red Hat Linux installation, you will need to configure the modem to perform all these tasks.

Red Hat Linux includes several tools you can use to configure and use an internal or external modem in your notebook or PC. Chapter 15, "Internet Connectivity," contains the details about configuring Red Hat Linux to connect to the Internet using a modem. This section covers how to configure Red Hat Linux to recognize and configure modems using serial ports (a standard formerly known as RS232, but now termed EIA32) or USB.

## Configuring a Serial-Port Modem

Linux uses /dev/ttySX, /dev/ttyUSB, or /dev/ttyUSB for serial ports, where X can range from 0 to 15. Many additional ports can be added to a system using multiport or chained USB devices. A PC's internal serial ports are generally recognized at boot time. To see a list of recognized ports for your system, pipe the dmesg output through grep command like:

```bash
# dmesg | grep tty
ttyS0 at 0x3f8 (irq = 4) is a 16550A
ttyS1 at 0x2f8 (irq = 3) is a 16550A
```

In this example, Linux reports that two serial ports have been recognized. Note that the device matching ttyS0 is /dev/ttyS0, despite the kernel output. The PC's external modem can be attached (most likely using a male DB9 adapter) to it here. Under Red Hat Linux, nearly all modem-based software can use a symbolic link named /dev/modem that points to the desired device. This link is not created by default, but as root, you can create this device manually using the ln command:

```bash
# ln -s /dev/ttyS0 /dev/modem
```

In this example, /dev/modem points to /dev/ttyS0.

# seterial -a /dev/ttyS0

Baud_base: 115200, close_delay: 50, divisor: 0
