If you receive a uencoded file and your email program doesn't recognize it, you will receive something that appears to be several hundred or even a thousand lines of garbage at first glance. However, the block of text will begin with a special line. Here is an example of the first few lines of a uencoded file might look like:

```
begin 64 lion_in_tree.jpg
M_C_X`$0$(D29)$$0'2'(($#[1I&4&A0&[S]:)P(#,N,$X0DE-`T'
M!H`'$!"2'$$0!(`01.))30/S------------------------------------------------$X0DE-_
M!H`'$#A*2DGT$$`0*!8`$(X0DE-_4$se
M+V9F'$;$F&8'$+$V9F$H9F:8'$,0$60'
```

The first line of the block gives permissions to the file should have when it is decoded (644) and the name of the file that should be created when the file is decoded. How do you decode this file? Simply save the email message as a text file (for example, lion_in_tree.txt). Next, use the uencode program to decode it:

```
$ uucode lion_in_tree.txt
```

This will create a new file, in which this case would be called lion_in_tree.jpg.
If you have a binary file that you want to encode so that you can email it to someone, you can do so with the uencode program. uencode uses the following syntax:

```
uencode local_file remote_file
```

local_file is the name of the binary file stored on your hard disk. remote_file is the name that you want to decode later when you or someone else uses uencode on it. Normally, you will probably want to use the same name for local_file and remote_file.

By default, this will send output to STDOUT, which is normally the screen. However, this is not very useful, so normally you use redirection with the uencode command. Here is an example:

```
$ uencode lion_in_tree.jpg lion_in_tree.jpg > lion_in_tree.txt
```

This command will encode the file lion_in_tree.jpg into a plain text file that you can decode as with the same name (lion_in_tree.jpg) and store the encoded file in the file lion_in_tree.txt. This text is suitable for emailing.

Of course, you can also use pipes to pipe the output of uencode to another application. For example, you could pipe the results to the standard mail program and have it mailed directly to another user. For example:

```
$ uencode lion_in_tree.jpg lion_in_tree.jpg | mail -s "Lion photograph" user@example.org
```
