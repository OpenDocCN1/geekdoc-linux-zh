# Preparing for the Install Process

The basic steps in installing Red Hat Linux are to plan, install, and configure. You'll need to decide on how to boot to an install and how much to remove to Linux. Then will perform the install (a sample step-by-step installation is in Chapter 3) and afterward, configure your system to host new users and specific software services. Much of the initial work will be done during the install process because the Red Hat installer will walk you through partitioning, configuring the desktop, and configuration of any recognized network adapter.

There are many different ways to install Red Hat Linux, and selecting an installation method might depend on the equipment on hand, existing bandwidth, or equipment limitations.

Here are some of the most commonly used Red Hat Linux installation methods:

- *CD-ROM*—Using a compatible CD-ROM drive attached to the computer (laptop users with an external CD-ROM drive will need PCMCIA support).
- *DOS*—By using LOADLIN, you can boot to a Linux install by pointing LOADLIN to use a Red Hat Linux installation kernel and ramdisk. Run the DOS batch file, autoboot.bat, found under the dosutils directory on the first Red Hat CD-ROM.

- *Network File System (NFS)*—You can install Red Hat Linux from a remotely mounted hard drive containing the Red Hat Linux software. To do this installation, you need to have an installed and supported network interface card, along with a boot floppy with network support. (You learn how to make boot floppies later in this section of the chapter).
- *File Transfer Protocol (FTP)*—As with an NFS install, installation via FTP requires that the Red Hat Linux software from CD-ROMs one and two be available on a public FTP server. You also need an installed and supported network interface card, along with a boot floppy with network support.
- *Hypertext Transport Protocol (HTTP)*—As with the FTP and NFS installs, installation via HTTP requires that the Red Hat Linux software from CD-ROM one and two be available on an accessible Web site. You also need an installed and supported network interface card, along with a boot floppy with network support.
- *Installation over the Internet*—If you have the bandwidth, it is also possible to install Red Hat Linux via the Internet; however, this method might not be as reliable as using a Local Area Network (LAN) because of availability and current use of Red Hat or other Red Hat mirrors.
- *Hard drive partition*—By copying the Red Hat Linux installation files from the first and second CD-ROMs, you can boot to an install using a boot disk or the DOS LOADLIN command.

# Preparing for the Install

Partitioning your hard drive for Linux can be done before or during installation.

If you plan to prepare your partitions before installing Linux, you'll need to use commercial partitioning software. Some of the popular commercial software you can use to create Linux partitions include PowerQuest's PartitionMagic or VCOM Products' Partition Commander.

Alternatively, you can prepare partitions before installing Red Hat Linux using the free F.EXE command.

Finally, you can prepare partitions ahead of installation by booting your system using a Linux distribution (such as the LNX Bootable Business Card, available at http://www.lnx-bbc.org/) and using a native utility such as fdisk to partition your drive. For details on using the fdisk partitioning utility and alternative software tools to your hard drive, see the section "How to Access and Manipulate the Partition Table" in Chapter 10, "Managing the Filesystem."

# TIP

You can use the first Red Hat Linux CD-ROM to perform other tasks aside from installing Linux. CD-ROM features a rescue mode and can also be used to partition and prepare a hard drive for Linux. See Chapter 3.
