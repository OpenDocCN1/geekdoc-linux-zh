FIGURE 4 The top command can be used to monitor and control processes.

The top command displays a bit of information about your system. Processes can be sorted by PID, age, CPU or memory usage, time, or user. This command also provides process management, and system administrators can use its k or r keypress commands to kill or reschedule running tasks.

# Displaying Free and Used with memory

Although top includes some memory information, the free utility will display the amount of free and used memory in the system in kilobytes (the -m switch displays in Megabytes). By one, the output looks like this:

```
```
total       used free shared buffers cached
Mem 255452 251132 4320 0 19688 77548
-/ buffers/cache: 138896 101556
Swap 136512 31528 104984
```
```

This output describes a machine with 256MB of RAM memory and a swap partition of 137MB. Note that some swap is used although the machine is not heavily loaded. Linux is very good at memory management and “grabs” all the memory it can in anticipation of future work.
