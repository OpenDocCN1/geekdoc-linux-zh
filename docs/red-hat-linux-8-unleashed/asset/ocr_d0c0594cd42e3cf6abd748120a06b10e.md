# # Reference

http://www.linuxgazette.com/issue70/ghosh.html—A Linux Gazette article on “Bootstrapping Linux,” which includes much detail on the BIOS and MBR aspects.

http://06.ibm.com/developerworks/linux/library/1-slack.html—A link through IBM’s Web site to an article on booting Slack Linux, along with a sidebar about the history of System V versus BSD init scripts.

/usr/src/linux/init/main.c—The best place to learn how linux boots. Fascinating reading,

http://sunsite.dk/linux-newbie/~Home page for the Linux Newbie Administrator Guide—A gentle introduction to Linux System Administration.

The GRUB Manual—The-to-be-completed manual can be found at http://www.gnu.org/manuals/grub-0.92/html_mono/grub.html. On your Red Hat systems, $info grub provides a plethora of information and a sample grub.conf file (named menu.lst) can be found in /usr/doc/grub.

LILO User’s Guide”—Werner Almesberger’s definitive technical tome on the Linux Loader, or LILO, and how it works on Intel-based PCs. Look under the /usr/share/doc/lilo/* directory for the file User_Guide.ps, which can be viewed using the cg client.

http://www.redhat.com/docs/manuals/linux/RHL-8.0-Manual/custom-guide/s1-services-serviceconf.html—Red Hat has to use the serviceconf client.

http://www.redhat.com/support/resources/tips/Boot-Process-Tips/Boot-Process-Tips—Red Hat’se description of the boot process.

http://www.linuxbase.org/spec/refspecs/LSB_1.0.0/gLSB/sysinit.html—The Standard Base description of system initialization. This is the standard.
