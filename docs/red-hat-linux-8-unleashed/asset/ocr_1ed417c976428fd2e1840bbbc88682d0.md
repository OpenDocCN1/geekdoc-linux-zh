http://www.postgresql.org—This is the official Web site of the PostgreSQL database server. You are asked to select a mirror when you arrive at this site. After you select a mirror, you are taken to the main site. From there, you can find information on the latest versions of PostgreSQL and read the online documentation.

http://www.postgresql.org/idocs/index.php?tutorial-start.html—This interactive HTML documentation tree is a great place to get started with learning how to use PostgreSQL..

http://www.pgql.com—This is a commercial company that provides fee-based support contracts for the PostgreSQL database.
