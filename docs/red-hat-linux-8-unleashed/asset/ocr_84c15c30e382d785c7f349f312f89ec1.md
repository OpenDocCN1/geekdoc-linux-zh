The noatum viewer is provided with Red Hat Linux to use as an embedded viewer in the Konqueror browser. noatum is set up as the default association for the video files formats it plays. Open a video file in Konqueror or Nautilus and the video will be shown in the viewer if it's supported. The viewer provides basic Start, Stop, and Fast-Forward VCR-type functions.

You can watch MPEG and DVD video with Xine. Xine is a versatile and popular media player that is not included with Red Hat Linux. You can also use Xine to watch AVI, QuickTime, OGG, and MP3 files.

# Macromedia Flash Plug-In for Mozilla

The Macromedia Flash plug-in for the Mozilla browser is a commercial multimedia application that isn't provided with Red Hat, but many people find it useful. Macromedia Flash enables you to view Flash content at Web sites that it supports. The Mozilla plug-in can be obtained from

http://www.macromedia.com/software/flashplayer/special/beta.

Download the file for Linux and uncompress it with

```
# tar zxvf install_flashplayer_6_linux.targz
```

This produces a directory named flashplayer_installer. Install the plug-in with # ./flashplayer_installer/flashplayer-installer

and follow the prompts to install it and make it available for the Mozilla browser.

Another interesting video player application is MPlayer (not provided by Red Hat), a movie player for Linux. MPlayer can use Win32 codecs and supports a wider range of video formats than Linux, including DivX and some RealMedia files. MPlayer also uses some special display drivers that support Matrox, 3Dfx, and Radeon cards and make use of some hardware MPEG decoder boards for better MPEG encoding. Packages for Red Hat 7.2/7.3 are available and will likely be some for 8.0 when you go to http://www.MPlayerHQ.hu/homepage/ and look for them; a Win32 codec package is also available.
