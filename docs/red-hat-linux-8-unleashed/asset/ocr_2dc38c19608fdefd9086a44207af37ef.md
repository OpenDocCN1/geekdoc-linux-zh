# PAM Explained

Pluggable Authentication Modules (PAM) is a system of libraries that handle the tasks of authentication on your computer. It uses management groups: account management, authentication management, password management, and session management. This allows the system to choose how individual applications will authenticate users. Red Hat has preinstalled and preconfigured all the necessary PAM files for.

The configuration files in Red Hat are found in /etc/pam.d. These files are named for the service they control, and their format is as follows:

```
type module-path arguments
```

The type field is the management group that the rule corresponds to. The control field tells PAM what to do if authentication fails. The two items deal with the PAM module used and arguments it needs. Programs that use PAM typically come with appropriate entries for the /etc/pam.d directory. To achieve greater security, the system administrator can modify the default entries before they modify them. The defaults provided by Red Hat are adequate for home and small office users.

An example of a PAM configuration file with the formatted entries as described previously is shown next. Here are the contents of /etc/pam.d/redhat-config-users:

```
#PAM-1.0
auth sufficient      /lib/security/pam_rootok.so
auth required        /lib/security/pam_stack.so service=system-auth
session required      /lib/security/pam_permit.so
session optional      /lib/security/pam_xauth.so
account required      /lib/security/pam_permit.so
```

Even the PAM documents show that you don't need (or) to know a lot about PAM to use it effectively.

You'll only need the PAM system administrators guide. Look under the /usr/share/doc/pam* for additional documents in PostScript, text, and HTML formats.
