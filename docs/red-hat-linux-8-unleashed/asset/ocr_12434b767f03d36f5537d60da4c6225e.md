# Related Hat and Linux Commands

+   You'll use the following commands to prepare for your installation of Red Hat Linux:
 dd—Convert and copy data
 fdisk—disk partitioning tool
 redhat-config-kickstart—Red Hat's graphical install configuration file generator

# Partitioning Before and During Installation

Partitioning your hard drive for Linux can be done before or during installation.

If you plan to prepare your partitions before installing Linux, you'll need to use comer-
cial partitioning software. Some of the popular commercial software you can use to create
Linux partitions include PowerQuest's PartitionMagic or VCOM Products' Partition
Commander.

Alternatively, you can prepare partitions before installing Red Hat Linux using the free
FIPS.EXE command.

Finally, you can prepare partitions ahead of installation by booting your system using a
Linux distribution (such as the LNX Bootable Business Card, available at
http://www.lnx-bbc.org/) and using a native utility such as fdisk to partition
your drive. For details on using the fdisk partitioning utility and alternative software tools
to your hard drive, see the section "How to Access and Manipulate the Partition
Table" in Chapter 10, "Managing the Filesystem."
