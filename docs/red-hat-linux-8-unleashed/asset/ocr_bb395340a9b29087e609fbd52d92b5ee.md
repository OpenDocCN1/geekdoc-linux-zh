# Evolution

The default graphical email client provided by Red Hat is Jimiian's Evolution. If you have had experience with Microsoft's Outlook mail client, you will resemble. Like MS Outlook, Evolution provides integrated functions: calendar, scheduling, and the ability to receive news and information from Internet sites.

> NOTE
Ximian intends for Evolution to actually act as a replacement for Outlook. Jimiian is also working on a non-free replacement for Microsoft Exchange server so that businesses will have a choice and Linux are targeted to replace the functionality of the UNIX product. As you'll see later, Balsa and Karma are targeted toward the MS Outlook express.

Start Evolution from the Internet menu; it is listed only as “Email.” The first time you start Evolution, the Evolution Setup assistant presents you with a brief and simple configuration, as seen in Figure 19.4.

The next screen permits you to configure Evolution to use your MTA: POP, IMAP, the local spools found in /var/mail in either mailbox or maildir, a local MTA, or “none” if you simply want to use the other features of Evolution. As seen in Figure 19.5, you can also set your password.
