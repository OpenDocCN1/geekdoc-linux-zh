# Increased Productivity with the Personal Desktop

A new installation feature, named Personal Desktop, is available in the latest version of
Red Linux. The Personal Desktop installs pre-selected software suitable for Small Office
Home Office, or SOHO, users. This option, a refinement of the previous Workstation-class
installwhich now is aimed at software developers), will provide a wealth of productivity
tools for document management, printing, communication, and personal productivity.

The Personal Desktop installation requires nearly 2GB of hard drive space, but contains
administration tools, authorizing and publishing clients, a variety of editors, a GNOME-
based X11 desktop, support for sound, graphics editing programs, graphical and text-based
Internet tools, printing support, and office productivity tools. The installation can be
customized to include or sidestep installation of unwanted software.

> Red Hat Linux in Education

In 2002, Red Hat, Inc. announced a “K-12 Red Hat Linux Pilot Program,” an extension of the
company’s “open schools” initiative. Red Hat’s new program aims to provide open source soft-
ware and support, according to Red Hat, “all schools, regardless of size or budget.” Although
candidate schools must provide their own hardware and meet some minimum requirements, Red
Hat has promised software and installation support.

To avoid the expense of software licensing fees, schools around the United States have installed
and Linux. Linux-based computer labs in Portland schools are expected to save the school
system (and Oregon tax payers) nearly one-quarter of a million dollars over the cost of using
mercial software.
