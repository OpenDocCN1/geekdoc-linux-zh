# CHAPTER 26 Multimedia Applications

Other useful documentation can be found in /usr/src/linux-2.4.18-/Documentation/video4linux. After you've identified a driver for a device, it won't hurt to look at the source code for it because so little documentation exists for many drivers; much of it is in the source code comments.

The development of support for TV cards in Linux has coalesced under the Video4Linux project. The Video4Linux software provides support for video capture, radio, and Teletext devices in Red Hat Linux.

## Video Formats

Red Linux recognizes a variety of video formats. The formats created by the MPEG group, Apple, and Microsoft predominate. At the heart of video formats are the codecs—encoders and decoders of the video and audio information. These codecs are typically proprietary, but free codecs do not exist. Here is a list of the most common video formats and their associated file extensions:

- * mpeg—The MPEG video format
- qt—The QuickTime video format from Apple
- .mov—Another QuickTime video format
- .avi—The Windows audio visual format

> An RPM that provides a Divx codec for Linux can be found at http://psyche.freshrmps.net/rpm.html?id=39.

If you need to convert video from one format to another, you use encoder applications, called grabbers. These applications take raw video data from a video device such as a camera or TV card, and convert it to one of the standard MPEG formats or to a still image, such as JPEG or GIF. Red Hat Linux doesn't supply any encoder applications, but you can find them at http://fame.sourceforge.net/ or another online source (see the "References" section at the end of this chapter).

## Viewing Video in Linux

Because of the patent and licensing issues earlier, the ability to play video files has been removed from Red Hat. This functionality can be restored if you install the full version of the applications described in this section from FreshRPMs at http://psyche.freshrmps.net.

You can use Linux software to watch TV, save individual images (take snapshots) from a televised broadcast, save a series of snapshots to build animation sequences, or capture video, audio, or both. The following sections describe the ways in which you can Put Linux multimedia software to work for you.

The noatum viewer is provided with Red Hat Linux to use as an embedded viewer in the Konqueror browser. noatum is set up as the default association for the video files formats it plays. Open a video file in Konqueror or Nautilus and the video will be shown in the viewer if it's supported. The viewer provides basic Start, Stop, and Fast-Forward VCR-type functions.

You can watch MPEG and DVD video with Xine. Xine is a versatile and popular media player that is not included with Red Hat Linux. You can also use Xine to watch AVI, QuickTime, OGG, and MP3 files.

## Macromedia Flash Plug-In for Mozilla

The Macromedia Flash plug-in for the Mozilla browser is a commercial multimedia application that isn't provided with Red Hat, but many people find it useful. Macromedia Flash enables you to view Flash content at Web sites that it supports. The Mozilla plug-in can be obtained from http://www.macromedia.com/software/flashplayer/special/beta.

Download the file for Linux and uncompress it with

```
# tar zxvf install_flashplayer_6_linux.targz
```

This produces a directory named flashplayer_installer. Install the plug-in with # ./flashplayer_installer/flashplayer-installer and follow the prompts to install it and make it available for the Mozilla browser.

Another interesting video player application is MPlayer (not provided by Red Hat), a movie player for Linux. MPlayer can use Win32 codecs and supports a wider range of video formats than http://www.MPlayerHQ/homepage/ and look for them; a Win32 codec is also available.

## Personal Video Records

The best reason to attach a television antenna to your computer, however, is to use the video card and the computer as a personal video recorder.

The commercial personal video recorder, TiVo, uses Linux running on a PowerPC processor to record television programming with a variety of customizations. TiVo has a clearer interface and wonderful features, including a record/playback buffer, programmed recording and, slow motion, and reverse effects. Red Hat doesn't provide any of the many applications that attempt to mimic the TiVo functionality on a desktop PC running Linux. However, several such applications, including DVR, the Linux TV Project, and PVR, are listed at http://www.exploits.org/v41/.
