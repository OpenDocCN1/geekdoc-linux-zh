As Chapter 3, “Installing Red Hat Linux,” demonstrates, installing Red Hat Linux is an easy task in most situations. The installation process includes hardware probing, in which the installer surveys the hardware installed in your system and then configures system settings accordingly. This configuration ensures that when the system boots, all hardware is recognized and ready to operate.

If you're a system administrator (even if you use Red Hat Linux on a standalone workstation), however, you can expect to perform some post-installation configuration of your system. When you add or replace hardware, you will need to configure Linux to recognize and boot the new components. If you have enabled Red Hat’s kudzu service, Red Hat Linux will automatically detect new hardware upon rebooting; Kudzu then enables you to reconfigure information about missing hardware and configure the new device. If you don't use Kudzu, however, you will be required to perform hardware configuration manually without the support of automated hardware detection and configuration.

NOTE

The kudzu service maintains a database of your system’s hardware information in the /etc/sysconfig directory in a file named hwconf. This service can be started, stopped, or restarted (like other Red Hat services) from the command line by using a script under the /etc/rc.init.d directory (named kudzu). You can also use the command-based services client to control kudzu. See Chapter 7, “Managing Services,” for more information on using these commands.
