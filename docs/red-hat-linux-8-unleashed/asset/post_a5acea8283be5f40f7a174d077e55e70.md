## Setting a Password for the MySQL Root User

To set a password for the root MySQL user, you need to connect to the MySQL server as the root MySQL user; you can use the command mysql -u root to do so. This command connects you to the server with the MySQL client (which is discussed later in this chapter, in the section “The MySQL Command-Line Client”). When you have the MySQL command prompt, issue a command like the following to set a password for a root user:

```
mysql> SET PASSWORD FOR root = PASSWORD("secretword")
```

## Creating a Database in MySQL

In MySQL you create a database using the CREATE DATABASE statement. To create a database, you connect to the server by typing mysql -u root -p and pressing Enter. After you do, you are connected to the database as the root user and prompted for a password. After you enter the password, you are placed at the MySQL command prompt. Then you use the CREATE DATABASE command. For example, the following commands create a database called animals:

```
# mysql -u root -p
Enter password:
Welcome to the MySQL monitor. Commands end with or \g.
Your MySQL connection id is 7 to server version: 3.23.51
```

Type 'help' or '\h' for help. Type '\c' to clear the buffer.

```
mysql> CREATE DATABASE animals;
Query OK, 1 row affected (0.00 sec)
mysql>
```

Another way to create a database is to use the mysql command, as the root user, with the create keyword and the name of a new database. For example, to create a new database named reptiles, you use a command like this:

```
# mysql -u root -p create reptiles
```

## Granting and Revoking Privileges in MySQL

You probably want to grant yourself some privileges, and eventually you'll want to grant privileges to other users. Privileges, also known as rights, are granted and revoked on four levels:

- Global-level rights allow access to any database on a server.
- Database-level rights allow access to all tables in a database.
- Table-level rights allow access to all columns within a database.
- Column-level rights allow access to a single column within a database's table.

To add a user account, you connect to the database by typing mysql -u root and pressing Enter. You are then connected as the root user and prompted for a password. (You did set a password for the root user, as instructed in the last section, right?) After you enter the root password, you are placed at the MySQL command prompt.

To grant privileges to a user, you use the GRANT statement, which has the following syntax:

```
grant what_to_grant ON where_to_grant user_name IDENTIFIED BY 'password';
```

The first option, what_to_grant, is the privileges you are granting to the user. These privileges are specified with keywords. For example, the ALL keyword is used to grant global-database-table-, column-level rights for a specified user.

The second option, where_to_grant, is the resources on which the privileges should be granted. The third option, user_name, is the username you want to grant the privileges. The fourth option, password, is a password that should be assigned to this user. If this is an existing user who already has a password and you are modifying permissions, you can omit the IDENTIFIED BY portion of the statement.

For example, to grant all privileges on a database named sampledata to a user named foobar, you could use the following command:

```
GRANT ALL ON animals.* TO foobar IDENTIFIED BY 'secretword';
```

The user foobar can now connect to the database sampledata by using the password secretword, and foobar has all privileges on the database, including the ability to create and destroy tables. For example, the user foobar can now log in the server (by using shuttle2, in this example), and access the database like:

```
$ mysql -h shuttle2 -u foobar -p animals
Enter password:
Welcome to the MySQL monitor. Commands end with or \g.
Your MySQL connection id is 7 to server version: 3.23.51
```

Type 'help' or '\h' for help. Type '\c' to clear the buffer.

```
mysql>
```

> NOTE: See the section "The MySQL Command-Line Client," later in this chapter, for additional options users can use on the command line.

Later on, if you need to revoke privileges from foobar, you can use the REVOKE statement. For example, the following statement revokes all privileges from the user:

```
REVOKE ALL ON animals FROM foobar;
```

## Installing and Configuring PostgreSQL

The latest PostgreSQL binary files and source are available at http://www.postgresql.org. The PostgreSQL RPMs are distributed as several files. At a minimum, you probably want the postgresql, postgresql-server, and postgresql-libs RPMs. You should see the README.rpm-dist file in the FTP directory ftp://postgresql.org/pub/ to determine whether you need any packages.

If you are installing from the Red Linux RPM files, a postgres user account (that is, an account with the name of the user running the server on your system) is created for you automatically:

```
$ fgrep postgres /etc/passwd
postgresql:x:26:26:PostgreSQL Server:/var/lib/postgresql:/bin/bash
```

Otherwise, you need to create a user postgres during the installation. This user shouldn't have login privileges because only root should be able to use su to become this user, and no one will ever log in as the user directly.(See Chapter 9 for more information on how to add users to a Red Hat Linux system). After you have installed each of the PostgreSQL RPMs that you downloaded, use the standard rpm -i command for a default installation.
