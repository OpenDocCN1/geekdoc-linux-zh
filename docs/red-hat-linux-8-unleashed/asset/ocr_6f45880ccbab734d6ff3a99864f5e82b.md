> NOTE

Unfortunately, Microsoft uses an attachment protocol not readily accepted by default attachment settings in a Red Hat Linux (and other Linux) default installation.

The attachment type you might have have trouble with TNEF, known as the Transport Neutral Encapsulation Format. To get around this problem, use the tne filter; the included documentation describes its integration to your MUA. If you'd prefer to use a separate graphical decoding client, you can download from the fentun X client.

The tne filter is available from http://sourceforge.org/projects/tnef/.

The fentun application is available from http://www.fentun.com/

# BinHex

Apple Macintosh users encode binary files in the BinHex 4.0 for attachment to email messages. Recipients need a decoder to view the attachment. Although not included with Red Hat Linux, several decoding tools are listed at Freshmeat.net. See RFC-1741 for details about BinHex encoding.

# yenc

Jürgen Helbing, the author of yenc (the name is a munging of “My Encoder”), this makes encoder available with no copyright restrictions. Although now most used for Usenet messages, yenc can also be used for mail(support for yenc is included in the news reader, see Chapter 2, “News Server Management”). The site, http://www.yenc.org/linux.htm, hosts a page of links for yenc tools for Linux.

> TIP

Frank Philofer offers a handy GPL'd encoding and decoding application for UNIX named UUDecode. It can be found at http://www.fp.de/fp/Software/UUDecode/. Although not included with Red Hat, it is a full-featured tool that makes the encoding and decoding task much easier. It supports Base64, BinHex, uuencoding, xxencoding, and yenc and handles multipart files. Philofer provides a library that you can integrate into your own applications.

# uuencode and uudecode

Red Hat includes a program called uuencode that encodes a binary file as plain text that can be transferred across email with SMTP. At the destination, a companion program called uudecode decodes the text file back into its original binary format. Many times, the uuencoding and decoding of binary files is handled automatically by the email client, but sometimes it isn’t.
