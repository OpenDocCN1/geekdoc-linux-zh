# Creating and Configuring Local Printers

Creating a local printer for your Red Hat Linux system can be accomplished in six easy steps. You must have root permission to use the redhat-config-printer client. The lpd daemon should also be running before you begin (start the daemon as shown earlier in this chapter, or use the ntysrv command to ensure that lpd is started at boot time).

To launch redhat-config-printer, select the Printing menu item from the GNOME or KDE desktop panel's System Settings menu or use the command line of an X terminal like this:

```
# redhat-config-printer &
```
