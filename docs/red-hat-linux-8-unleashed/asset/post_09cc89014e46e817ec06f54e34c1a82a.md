
## Step-by-Step Installation

- Press F1 returns to the initial boot screen.
- Press F2 gives general installation information (described next in this chapter).
- Press F3 describes how to pass kernel video arguments, useful for configuring video hardware to support a graphical install at a specific resolution (such as 800-600 pixels).
- Press F4 describes Red Hat's rescue mode.

The F2 screen lists a number of options you can use at the boot prompt, as follows:

- linux noprobe—Disable probing of the system's hardware.
- linux mediacheck—Verify the integrity of one or more Red Hat Linux install CD-ROMs.
- linux rescue—Boot to single-user mode with a root operator prompt, disabling X, multitasking, and networking; this option can be used if you need to reconfigure your Red Hat boot loader or rescue data from your system.
- linux dd—Use a driver disk (a floppy image) and possibly one or more kernel arguments (such as linux mem=512m expert) to enable certain types of hardware, such as networking cards.
- linux askmethod—Prompt for the type of install to perform, such as over a network.
- linux updates—Start an installation update.
- linux lowres—Install using a graphical display of 640-480 pixels, which can be helpful if your PC has an older or less capable display monitor.

The F3 screen lists options that can be used at the boot prompt to set a specific resolution for the installation. For example, this is done by typing linux resolution= at the boot prompt, along with an option such as "800x600".

> The Hat installer will start automatically. Press the spacebar if you need to halt the install.

After you type linux text and press Enter, the installer's kernel loads, and you're asked if you would like to perform a media check of your CD-ROM, as shown in Figure 3.2.

This check can take some time, but can ensure the integrity of the CD-ROM's contents because Red Hat embeds an md5 value on each CD-ROM. This check can help installation of malicious software from CD-ROMs with tampered contents. This check can also be helpful to make sure the CD-ROM you are using work on your PC and in your CD drive. To perform the check, choose OK; otherwise, use the Tab key to navigate to the Skip button and press Enter to choose it.

## Partitioning Your Drive

You learned how to choose and plan a partitioning scheme in “Planning Partition Strategies,” earlier in this chapter, based on the more specific partitioning information offered in Chapter 2. Here is what the Disk Partitioning Setup screen do:

- The Autopartition button will conveniently partition your hard drive according to the type of installation you selected and configure the partitions for use with Linux.

Choosing the Disk Druid button launches a graphical partition editor. The fdisk button launches a text-based interface.

![](img/446debe023486a07fde575245cf7a3ff_104_0.png)

FIGURE 3.7 Select a partitioning scheme or tool.

For this example, highlight the Disk Druid button and press Enter. If you are using a new hard drive that hasn't been partitioned, you will be asked if you would like to create new partitions on the drive. Click the Yes button to initialize the drive. If you are using a hard drive that has previously partitioned and the partitions are recognized, Disk Druid will present the partitions in the partition dialog. Figure 3.8 shows the graphical interface for a 5GB hard drive that hasn't partitioned.

To use Disk Druid, select any free space, and then press the New button (or F2) to create a new partition. Alternatively,

- To get help, press F1.
- To create free space, scroll to an existing partition and use the Delete button to delete the partition.

After you choose the New button, you see a dialog box as shown in Figure 3.9.

Use the Add Partition box to assign a mount point (such as /boot or /), assign a filesystem (such as ext2, ext3, RAID, swap, or vfat), assign the size of the partition, and assign a filesystem check. Remember that, at a minimum, your Red Hat system should have a root (/) and swap partition. The ext3 filesystem is the best choice for your partitions because it is the default for Red Hat, but you can also use ext2 (convert to ext3 later on—see Chapter 10). The size of the partition can be fixed by entering a number (megabytes), or if you press the spacebar when selecting the Fill All Available Space field, will use all remaining free space.

Use the Check for Bad Blocks item to verify low-level formatting and check the integrity of your hard drive. (This will take a long time on a hard drive with a capacity larger than 10GB.) You can also check your hard drive after installing Red Hat by using various Linux software tools, as shown in Chapter 10. Use the OK button when finished.
