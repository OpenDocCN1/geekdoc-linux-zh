# System Monitoring Tools

![](bbox=[0.158, 0.103, 0.755, 0.477])

FIGURE 8.7 The graph of the System Monitor. It shows CPU usage, Memory/Swap usage and disk usage. To view this, select the System Monitor tab.

These KDE monitoring clients include the following:

+   - ktimemon—A small KDE client or app that docks, or deposits, or an animated graph of CPU activity in your desktop's panel (known as KDE's kicker).
- kdf—A graphical interface to your system's filesystem table that displays free space and enables you to mount and unmount filesystems using a pointing device.
- kisandock—This panel app is used to monitor ISDN connections.
- ksysguard—Another panel app that provides CPU load and memory information in animated graphs.
- kcron—A graphical interface to your system's /etc/crontab file.

# Relevant Red Hat and Linux Commands

Youll use these commands while managing your Red Hat Linux system resources and software packages:

+   - redhat-config-packages—The Red Hat GUI Package Manager.

+   - nice—Run a program at a specified priority.
