The fake C:\ drive is Wine creates the expected Windows file tree and populates it with own .dll files and configuration files; Windows programs behave as if drive is their home. It can be found on your Red Hat system at /usr/share/wine-c.

> CAUTION
You could change the mount point to a real Windows installation, but Wine will break the Windows registry. Alternatively, you can copy the "real" Windows installation to another location like /usr/share/wine-real and Wine there.

+   [Drive C]
"Path" = "/usr/share/wine-c"
"Type" = "hd"
"Label" = "MS-DOS"
"Filesystem" = "win95"

This is the definition for the CD-ROM drive; adjust as appropriate for your system, or duplicate this entry (with a different drive letter) if you have more than one CD-ROM drive.

+   [Drive D]
"Path" = "/mnt/cdrom"
"Type" = "cdrom"
"Label" = "CD-Rom"
"Filesystem" = "win95"
; make sure that device is correct and has proper permissions
"Device" = "/dev/cdrom"

The following entry allows Wine access to /tmp for temporary files and sharing with other users:

+   [Drive E]
"Path" = "/tmp"
"Type" = "hd"
"Label" = "Tmp Drive"
"Filesystem" = "win95"

This entry mounts your /home directory so that you have easy access to it:

+   [Drive F]
"Path" = "$S{HOME}"
