# CHAPTER 20 News and Other Collaborative Communication

The innd program listens for newsfeeds and newsreader requests on the NNTP TCP port. If a remote newsreader establishes a connection, the innd program spawns the active program to authenticate the remote connection and handle the newsreader. If the incoming articles are control articles, they are passed to the controlchan program for processing.

Red Hat has thoughtfully configured the SystemV files that are necessary for starting the news server; you can use (in an appropriate way) ehconfig, ntsysys, service, or redhat-config-services to start the server. (See Chapter 7, “Managing Services,” for details.)

```
# service inn start
```

When the innd program is running, you can control it using the cltinnd program, with the following syntax:

```
cltinnd [ -h ] [ -s ] [ -t timeout ] command [ argument... ]
```

The -s option suppresses any output from the cltinnd command. This is often used in batch programs. The -t option specifies how long to wait for a response from the server (in seconds). If you are connecting to a server across a slow link or to a slow server, you can increase the value of timeout.

The command parameters define what actions the cltinnd program should take with the innd news server. The -h command-line option prints a summary of all the available command parameters that can be used with cltinnd. For now, you can use the newsgroup command to create a new local newsgroup that newsreaders can use to read and post messages:

```
$ cltinnd newgroup local.book.club y rich@ispnet1.net
```

The cltinnd command uses three parameters:

+   - The Name of the new newsgroup
- A flag to define what type of newsgroup to create (y stands for a regular open group and m stands for a moderated group)
- An email address for the maintainer of the new newsgroup

The cltinnd program should be run from the news user ID. If the command is successful, it returns a simple OK message. You can use the getlist command to check whether the new newsgroup has been added to the news server.
