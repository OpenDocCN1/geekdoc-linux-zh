# Backing Up and Restoring the Master Boot Record

The Master Boot Record (MBR) is the first 512 bytes of a hard disk. It contains the boot-loader in the next 446 bytes and the partition table in the next 64 bytes; the last two bytes identify that as the MBR. It can become corrupted, so it makes sense to send back to it as well.

To back it up, this example uses the dd command and will back up the entire MBR. If the bootloader code changes from the time you make this image and restore the old code, the system won't boot; it's easy enough to keep a boot floppy handy and then re-run LILO if that's what you are using.

To copy the entire MBR to a file, use this:

```
# dd if=/dev/hda of=/tmp/hdamber bs=512 count=1
```

To restore the MBR, use this:

```
# dd if=/tmp/hdamber of=/dev/hda bs=512 count=1
```

To restore only the partition table, skipping the bootloader code, use this:

```
# dd if=/tmp/hdamber of=/dev/hda skip=446 count=66
```

Of course, it would be prudent to move the copy of the MBR to a floppy or other storage device. You will need to run dd on the system in order to restore it (which means that you will be using the Red Hat rescue disk as described later, or any equivalent to it).

# Manually Restoring the Partition Table

A different way of approaching the problem is to have a hard copy of the partition table that can be restored by hand using the Red Hat rescue disk and the fdisk program.

We can also make a listing of the partition table with fdisk using the L option, as follows:

```
# fdisk /dev/hda -1 /tmp/hdaconfig.txt
```

We can also copy the file /tmp/hdaconfig.txt to the backup floppy for safekeeping as well.
