The GnomeToaster application is the GNOME CD creator. It is not included in the menus even though it's provided by Red Hat, so you'll have to launch it from the command line, like:

$ gdtoaster &

Shown in Figure 26.8, GnomeToaster starts the first time with default values attempts to set from your system. The application is very powerful, but awkward for beginners because the preferences are more than the command strings for mkisofs, cdrecord, cdparanoia, and other underlying applications. A good knowledge of these applications can help you use GnomeToaster successfully. Fortunately, GnomeToaster provides defaults that are appropriate for your system and you need not modify them to use the application.

Finally, X-CD-Roast is another CD creator provided by Red Hat Linux. It, too, does not have a menu icon and must be launched from the command line, like this:

$ xdroast &

When you first start it, X-CD-Roast is deceptively plain, giving little indication of the true power of this application. The very first time it runs, it begins with a dialog warning to enter the Setup dialog, which will be the only button presented to you in the next other than Exit. The application autodetects your D=CD-RW drive, but you must provide the default HD settings and select the users who are allowed to use the application. The dialogs for setting this information are straightforward and easy to follow. Make certain that you choose a default directory for temporary image storage that offers enough room to store several images.
