# NOTE

One of the by-products encoding binary data is the need to pad each line to a specific number of characters if the data won't fill it because the lines are always a fixed length. Normally these extra characters are random and are always ignored when decoding, but you can deliberately place information instead of the random ASCII text. Placing information in "holes" of other data files is known as steganography. Programs are available to encode and decode information this way (typically in pictures), as well as to scan images for hidden stenographic information. Search http://freshheat.net/steg/ for a listing of interesting applications. Steganography is not limited to uencode.

# Relevant Red Hat and Linux Commands

You'll use the following commands to manage electronic mail in Red Hat Linux:

+   - balsa—A GNOME mail user agent for X
- biff—A console-based mail notification utility
- evolution—A comprehensive and capable Xian GNOME mail PIM for X
- fetchmail—A console-based and daemon-mode mail retrieval command for Linux
- fetchmailconf—A graphical fetchmail configuration client for X
- kmail—A graphical mail user client for KDE and X
- korn—A bird applet for KDE and X
- mail—A console-based mail user agent
- mutt—A console-based mail (and newsreading) user agent
- Sendmail—A comprehensive mail transport agent for UNIX and Linux
- xbf—A mail notification X client
