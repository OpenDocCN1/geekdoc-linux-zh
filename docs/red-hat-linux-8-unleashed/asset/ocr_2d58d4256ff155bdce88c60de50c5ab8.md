Don't forget to address follow-issues on your migration roadmap. You should pay attention to how satisfied or how well new users, especially those new to Linux, adapting if a new desktop is used. However, if Red Hat is deployed in a mixed environment, many users might not know (or need to know) that Linux is being used!

# Planning the Installation

There are many factors in favor of using Red Hat Linux as a computing solution. The current distribution can fill many roles on various tiers and hardware platforms because Red Hat Linux offers preconfigured installation scripts to fit development, workstation, e-commerce, server, and mobile platform—only the required software will be installed.
