# Personal, Professional, and Enterprise-Level Red Hat Linux

Red Hat Linux is a distribution of Linux developed and distributed by Red Hat, Inc. Red Hat, Inc, has developed and marketed its brand of Linux since 1994. Admitted, although all distributions are the same underneath (they all use the Linux kernel) Red Hat continues to hold a market lead. Red Hat is a widely popular distribution, accounting for more than 50 percent of current Linux installs, and according to various market indicators. Red Hat is easy to install and use, provides a host of features, and is backed by extensive bug fixes and security updates.
