# CHAPTER 19 Handling Electronic Mail

# Balsa

Balsa is an email client designed to work with GNOME. Configuring Balsa is similar to configuring Evolution, although most of the configuration is done from the Preferences menu item. Figure 19.8 shows a screenshot of the Balsa interface.

# KMail

If you are using the KDE Desktop Environment rather than the Red Hat default GNOME desktop, you will also have KMail installed. Similar to Balsa, it won't take users of Outlook Express or Mozilla Mail very long to get used to the KMail interface. Some useful features found in KMail are the choice of mbox or maildir formats, improved filter creation, the ability to sort mail into threads, and the ability to apply filters to the MTA. Figure 19.9 shows the KMail email program.
