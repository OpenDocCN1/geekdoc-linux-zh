Software emulators mimic foreign CPUs in order to host
foreign operating systems or computer languages. An emulator
allows us to use an application originally intended for
 Linux. We use an emulator to run, for example,
Microsoft Office on a Linux computer. That's how this book is
written, in fact, the publisher's employees and
production staff use Microsoft products. This cross-platform
approach also enables Linux users to have flexibility in other
areas, as which floppy disk formats. A Linux computer can
even display the desktop of a remote computer running a
non-Linux operating system in a window on the Linux
desktop.

In this chapter, you learn about some of the more popular
emulators available for use with Red Hat Linux. You learn
about Wine, a software product included with Red Hat Linux
that enables you to use software designed for Microsoft platforms- on your Linux system. You also learn how to use
a number of cross-platform tools, including VNC (Virtual
Networking Computing) to access the desktops of other
computers running non-Linux operating systems or software.
The chapter also covers a number of other emulators and
cross-platform tools not included with Red Hat Linux, includ-
ing VMware, Win4Lin, Cygwin, and some popular macOS
emulators.
