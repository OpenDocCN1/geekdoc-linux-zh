The System Monitor menu item is found in the System Tools menu. It can be launched from the command line

# gnome-system-monitor

From the Process List viewing (chosen via the tab in the upper left portion of the screen), select a process and click on More Info at the bottom left of the screen to display details on that process at the bottom of the display. You can select from three views, available in the drop-down View list: All Processes, My Processes (those you alone), or Active Processes (All Processes that are active) to filter the display.

Choose Hidden Processes under the Edit command accessible from the top of the display to show any hidden processes (those that the kernel does not allow the normal monitoring tools to see). Select any process and kill it with End Process.

The processes can be reniced by selecting Edit, Change Priority. The view selection from the menu bar also provides a memory map. In the System Monitor tab, you can view a graph representing CPU and memory usage (see Figure 8.7).
