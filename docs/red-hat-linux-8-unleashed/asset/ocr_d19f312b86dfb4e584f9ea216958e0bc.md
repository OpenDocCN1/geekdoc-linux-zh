# CHAPTER 15 Internet Connectivity

Each networked Red Linux machine on a LAN will use this same IP address for its localhost. If for some reason a Red Linux computer does not have this interface, edit the /etc/hosts file to add the localhost entry, and then use the ifconfig route commands as root to create the interface like this:

```
# ifconfig lo 127.0.0.1
# route add 127.0.0.1 lo
```

These commands will create the localhost interface in memory (all interfaces, such as eth0 or ppp0, are created in memory when using Linux), and then add the IP address 127.0.0.1 to an internal (in-memory) table so that the Linux kernel's networking code can keep track of routes to different addresses.

Use the ifconfig command as shown previously to test the interface.

You should now be able to use the ping command to check that the interface is responding properly like this (using either localhost or its IP address):

```
# /bin/ping -c 3 localhost
PING localhost.localdomain (127.0.0.1) from 127.0.0.1 : 56(84) bytes of data.
64 bytes from localhost.localdomain (127.0.0.1): icmp_seq=0 ttl=255 time=212 use
64 bytes from localhost.localdomain (127.0.0.1): icmp_seq=1 ttl=255 time=80 use
64 bytes from localhost.localdomain (127.0.0.1): icmp_seq=2 ttl=255 time=50 use
```

+   --- localhost.localdomain ping statistics ---
3 packets transmitted, 3 packets received, 0% packet loss
round-trip min/avg/mdev = 0.050/0.114/0.212/0.070 ms

The -c option is used to set the number of pings, and (as it was previously), will return information regarding the round-trip speed of sending a test packet to the specified host.

# Configuring Dial-up Internet Access

Most ISPs provide dial-up connections using PPP because it is a fast and efficient protocol for TCP/IP over serial lines. PPP is designed for two-way networking; TCP/IP provides the transport protocol for data. One hurdle faced by new Red Linux users is how to set up PPP and connect to the network. It isnt' necessary to understand the details of the PPP protocol in order to use it, and setting up a PPP connection is easy. You can configure the PPP connections manually using the command line, or graphically during an X session using Hat's Internet Configuration Wizard. Each approach produces the same results.
