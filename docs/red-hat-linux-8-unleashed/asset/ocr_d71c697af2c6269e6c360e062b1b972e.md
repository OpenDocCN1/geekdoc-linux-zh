# CHAPTER 24 Kernel and Module Management

> NOTE

The stock Red Hat 8.0 kernel included with this book is the 2nd major version, the 4th minor level, the 18th patch level, and an extra version level of 14. The extra version level indicates a Red Hat specific implementation of the 2.4.18 kernel, which generally adds some code in the stock kernel necessary for special applications or hardware support.

The version number for Red Hat 8.0 is 2.4.18-14.

Even-numbered minor versions are stable kernels, whereas odd-numbered minor versions are development releases. Version 2.4.X is the stable production kernel, whereas 2.5.X is the development Linux kernel. When a new version of the stable kernel is started, it may be labeled 2.6.X or possibly 3.0.X.

For production machines, you should always use the kernels with even minor numbers. The odd minor numbers introduce new features, so you might want to use those on a test machine if you need features you provide.

# AC Patches

Alan Cox has produced the "ac" series of Linux patches to include new code being tested by developers. Alan is an accomplished kernel developer and Red Hat employee who became Linux's right-hand man. His job for the 2.4 kernels has been subsumed by Marcelo Tosalti, a four-year veteran of Connectica Linux. AC patch releases are distinguishable by -ac at the end of the kernel version. linux-2.4.9-ac10, is the ninth release of the 2.4 Linux kernel, with the 10th Alan Cox patch. Many of -ac patches have been included in the kernel that Red Hat provides. Some patches, like ACPI, are in the kernel; but they are unselected or marked as experimental, allowing you a wider range of choices.

# Obtaining the Kernel Sources

The Linux kernel has always been freely available to anyone who wants it. If you just want to recompile the existing kernel, install the kernel-sources RPM from the CD using rpm from the command line or the Red Hat graphical tool to get the latest "vanilla" version, open an FTP connection to ftp.kernel.org using your favorite ftp client and log in as anonymous. Because you are interested in the 2.4 kernel, change directories to /pub/linux/kernel/v2.4. The latest stable kernel as of this writing is 2.4.19.

> NOTE

ftp.kernel.org receives more than its share of requests for download. It is considered a courtesy to use a mirror site to reduce the traffic that ftp.kernel.org bears. http://www.kernel.org/mirrors/ has a list of all mirrors around the world. Find one close to your geographic location and substitute address for ftp.kernel.org.
