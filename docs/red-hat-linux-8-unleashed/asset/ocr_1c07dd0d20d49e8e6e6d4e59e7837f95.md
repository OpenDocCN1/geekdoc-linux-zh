# IM in Red Hat Linux with KIT and GAIM

IM has been popularized by America Online (AOL) as well for AOL users to chat directly
with each other rather than speak in chat rooms. As long as the IM clients are running,
alert you to any incoming messages that arrive. They also announce to the server
that you are active and listening for messages, so your friends can be made aware that you
are available to chat with them.

IM can be used in place of IRC for interoffice collaboration, if desired. Red Hat provides
two IM clients, KIT and GAIM, for your use. To use them, you need to be communicating
with a group of “buddies” that are active IM users.

GAIM is the default IM client for Red Hat 8.0. It is a GNOME (GTK-based) IM client that
supports a wide range of protocols. GAIM is a feature-rich message client, and it has
support for plug-ins that extend the functionality of the application.

> NOTE
GAIM supports Jabber, an open XML-based IM protocol that can be used to set up a corporate
IM server. Jabber is not supplied with Red Hat, but you can obtain additional information about
from the Jabber home page, at http://www.jabber.com/. You can obtain the Jabber server,
Jabber, from http://jabber.jabberstudio.org/.

KIT is a simple KDE IM client. When you first launch KIT, offers to go to AOL to create
a new profile. After you choose a screen name and password and have them accepted, you
exit the “registration” process. You receive an email message that you must
return in order to confirm your account, completing the registration.

# Videoconferencing with GnomeMeeting

GnomeMeeting is an Internet videoconferencing application that provides two-way voice
and pictures over the Internet by using the H.323 protocol for IP telephony (also known
as Voice over IP [VoIP]). It is provided with Red Hat Linux.

Before you can take full advantage of the phone and videoconferencing capabilities of
GnomeMeeting, you must configure a full-duplex sound card and video device
(see Chapter 26, “Multimedia Applications”) as well as a camera.

GnomeMeeting is found in the Menu as Video Conferencing; you click on the
icon to launch it. When you start the GnomeMeeting application for the first time, you
ngreeted by the first of four configuration screens. You simply enter your name, email
address, and location and select your connection type. The settings for your audio and
ideo devices are automatically detected; you can view them by selecting the Preferences
item from the Edit menu.
