# Configuring GNOME's galleon Browser

GNOME's galleon Web browser is capable of handling a number of networking and file protocols, including FTP. The first time you launch this browser you're asked to configure various settings, such as the appearance of its toolbar, or which protocols you want galleon to handle (see Figure 18.3).

After enabling gFTP and launching the client, you can use the ftp:// URL form to access remote servers. Settings are saved in a directory named .galeon in your home directory.

Using the ftp:// URL in GNOME and KDE

The K Desktop Environment (KDE) and the GNU Network Object Model Environment (GNOME) graphical clients have integrated FTP functionality built in to window management. You can also use FTP with the Nautilus or konqueror file browsers. Use an ftp:// URL followed by a server name or IP address to start an anonymous FTP session.

The drag-and-drop feature of KDE and the GNOME window manager allow users to select remote files and drag them to the desktop. Figure 18.4 shows an anonymous login to a remote FTP server using Nautilus. These types of features can shield users from the need to know the details of how FTP works or memorizing various commands.

# Related Red Hat and Linux Commands

You'll use these commands to install, configure, and manage FTP services in Red Hat Linux:

- ftp—A text-based interactive FTP command
- ftcopy—Copy directories and files from an FTP server
- ftpcp—Retrieve remote data from FTP server, but do not overwrite existing local files
- ftpd—The FTP server daemon
- gftp—A graphical FTP client for GNOME
- wuftpd—A KDE utility used to edit the wu-ftp ftppass file
- l1ftp—An advanced text-based FTP program
- cftftp—A sophisticated, text-based FTP program
- redhat-config-services—Red Hat's service GUI admin utility
- sftp—Secure file transfer program
- simpleftp—An FTP client written in Perl
- smbclient—Samba FTP client to access SMB/CIFS resources on servers
- vsftpd—The Very Secure FTP daemon
- webcam—A Webcam-oriented FTP client included with xawt

# CHAPTER 19 Handling Mail

## 19.1 A Brief Introduction to Terms

The world is filled with acronyms. This chapter covers some of the most common ones related to email.

- RFC—Request For Comments is as close to a rulebook as one can get.
- SMTP—Simple Mail Transfer Protocol used for sending mail from one network to another.
- IMAP—Internet Message Access Protocol is used by MUAs to receive mail from a remote site.
- POP—Post Office Protocol is used by MUAs to receive mail from a remote site.
- MTA—Mail Transfer Agent works behind the scenes to send and receive email.
- MUA—Mail User Agent is the application used to read and compose email.
- MDA—Mail Delivery Agent handles local deliveries.
- MIME—Multipurpose Internet Mail Extensions addresses the formatting of email messages to include non-ASCII text, encoded binary images, and multimedia content.

## 19.2 How Email is Sent and Received

Email is sent as plain text across networks using SMTP. SMTP is used for sending mail from one network to another. Extensions to the protocol add authentication and error messages to the basic protocol. The mail transfer agent (MTA) works behind the scenes to send and receive email between computers. Some MTAs are Sendmail, Postfix, Exim, or Qmail.
