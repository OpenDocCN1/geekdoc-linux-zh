Proper preparation and planning before beginning a Red Hat Linux installation can pay dividends later. After choosing to deploy Linux and deciding how you want to use Linux, it's time to take a hard look at how to deploy the new operating system.

Installing Red Hat Linux for the first time can seem daunting to inexperienced users or system administrators, but this shows how easy the installation can be if you make some simple preinstallation plans and decisions. Disk partitioning can be one of the most unfamiliar parts of the installation process, but it's an essential step toward configuring a multipatform system. As you learn in this chapter, disk partitioning is also a manageable process when you take the time to plan ahead.

In this chapter, you learn how to prepare for an effective, efficient Red Hat Linux installation. The chapter begins with a checklist of considerations that can help you plan how you will use Red Hat Linux after installation, so you can plan for making the right choices during the installation itself. This chapter also outlines some of the basic hardware requirements for using Red Hat Linux, and it highlights potential hardware problems you can plan for—and avoid. The chapter also walks you through a general overview of the installation process, and it offers in-depth planning advice for partitioning your hard disk to support different configurations.

As you are about to learn, Red Hat Linux is a flexible Linux distribution that can adapt to a variety of hardware configurations and can be installed in a number of ways.
