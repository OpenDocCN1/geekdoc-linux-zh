+   - Xenix

+   - Wyse V/386

In addition, the following binary file formats are supported by Linux so that it can load and run them as if they were the ELF-formatted binaries native to Linux:

+   - COFF (Common Object File Format—UNIX System V)

+   - x.out (Unix 286 and 386)

+   - a.out (BSD and early Linux)

Many of the supported binaries are obsolete, but they might be useful in environments where very old software is still productively used. The home page of this kernel feature can be found at http://www.tat.physik.uni-tuebingen.de/~rguenth/linux/binfmt_misc.html, and the kernel documentation is found at /usr/src/linux-2.4/binfmt_misc.txt. You should always follow the licensing requirements of any software you run on your Linux system.
