# Preparing for Potential Hardware Problems

Red Hat Linux will work "out-of-the-box" with nearly every PC motherboard and laptop. Red Hat Linux also includes drivers for thousands of different types of hardware peripherals. But as you come into problems if Red Hat Linux doesn't recognize a hardware item, if Red Hat Linux doesn't initialize the hardware, or if an initialized item is incorrectly configured. For these reasons, some hardware items are prone to creating problems during Red Hat Linux installation. In the sections that follow, you learn some important pointers for avoiding these problems or resolving those that occur.

# Controllerless Modems

As you read earlier, most Red Hat Linux hardware-related installation problems stem from a lack of technical specifications from the manufacturer or the lack of a driver. In the recent past, one hardware item that triggered both types of difficulties was the controllerless modem, also colloquially known as a WinMod. The good news is that modern chipset manufacturers have been more forthcoming with driver details. Some original equipment manufacturers, such as IBM, have made a concerted effort to provide Linux support. For the ACP Mwave modem, used in ThinkPad 600/Es and 770s, is included in the Linux kernel. Drivers have been developed for many of the controllerless modem chipsets that formally do not work with Linux.

If a driver isn't available for your controller modem, you have a few options. You can download the driver's source code and build the driver. Alternatively, you can download a binary-only software package and install the driver.

Some controllerless modems might also need to be initialized and configured using a rate utility program. The modem, if supported, should work normally after installing and configuring the driver.

You can research Linux support for controllerless modems by browsing to

http://www.linmodems.org/
