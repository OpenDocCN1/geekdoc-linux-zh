# Logging In and Out from a Remote Computer

Although you can happily log in and use Red Hat on your computer, an act known as a local log in, you can also log in to your Red Hat computer via a network connection from a remote computer. Red Hat Linux provides a number of remote access commands you can use to log in to other computers on your Local Area Network (LAN), Wide Area Network (WAN), or the Internet. The point is not only must you have an account on the remote computer, but also the remote computer must be configured to support remote logins—otherwise, you won't be able to log in.

> NOTE
See Chapter 13 to see how to set up network interfaces with Red Hat Linux to support remote network logins and Chapter 7 to see how to start remote services (such as ssh).

The best and most secure way (barring future exploits) to log in to a remote Linux computer is to use the ssh or Secure Shell. Your login and session are encrypted while you work on the remote computer. The ssh client features many different command-line options, but can be simply used with the name of the remote computer, like this:

```
[winky@shuttle winky]$ ssh shuttle2
The authenticity of host 'shuttle2 (192.168.2.70)' can't be established.
RSA key fingerprint is 45:93:1ca:ae:02:32:bd:eb:c6:71:ce:26:97:17:5f:0b.
Are you sure you want to continue connecting (yes/no)? yes
```

The first time you connect with a remote computer using ssh, Linux displays the remote computer's encrypted identity key and asks you to verify the connection. After you type and press Enter, you're warned that the remote computer's identity (key) has been entered in a file named hosts under the .ssh directory in your home directory. You're also prompted to enter your password:

```
Warning: Permanently added 'shuttle2,192.168.2.70' (RSA) \
to the list of known hosts.
winky@shuttle2's password:
/usr/X11R/bin/xauth: creating new authority file /home/winky/.Authority
[winky@shuttle winky]$
```

After entering your password, you can then work on the remote computer. Again, everything you enter on the keyboard in communication with the remote computer is encrypted. Use the exit or logout commands to exit your session and return to the shell of your computer.
