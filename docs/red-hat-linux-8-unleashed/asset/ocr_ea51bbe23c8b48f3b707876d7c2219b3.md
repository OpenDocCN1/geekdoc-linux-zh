# The KNode News Client

The KNode program is part of the KDE networks package, which is included in the Red Hat distribution as kdenetwork RPM package. KNode is installed by default if you select the KDE windows manager option in the Red Hat installation.

The KNode program is an excellent graphical program that allows you to connect to news servers (either the local server or a remote server) and select newsgroups where you can read and post articles. Before you begin, you must configure the address of your news server into KNode. You do this from the Settings menu item on the KNode window. From the Settings drop-down menu, you select the Configure KNode item. The KNode configuration window appears. Under the Accounts item, you can select the News item. A list of configured news servers appears in the window. To add a new news server, you click the New button. # The Mozilla News Client

The Mozilla Web browser supports graphical Usenet newsreading as well as Web browsing. Having numerous newsreading clients installed on a Red Hat system offers users a wealth of choice and opportunities for developing favorites, but in some cases it can complicate an administrator’s task of tracking and fixing client security liabilities. Using Mozilla help simplify this task by offering an all-in-one client that provides Web browsing, email, file transfer, and newsreading capabilities.
