如果您曾经尝试过检查系统漏洞或破解网络中的 Wi-Fi 密码，那么您可能已经熟悉 Kali Linux。它是一个专注于安全的 Linux 版本，提供了许多有助于我们黑客攻击自己网络以发现弱点并防止其他黑客试图进入您系统的工具。

最初，这套系统是出于 Kali 主要开发者 Mati Aharoni 的必要性而创建的。在进行专业安全工作时，这位开发者发现他需要想出许多安全工具，而不必在客户的系统上安装大量软件和其他内容。于是，他转向 Linux，看看他能够一站式做什么来应对这个问题。

这种发行版的理念包含了一堆出于必要性而诞生的安全工具。Aharoni 在与客户进行安全接触时面临着一个困境。他不允许在接触中携带任何硬件，而且通常你只能使用现场电脑，前提是你不能进入硬盘或以任何方式修改它们。

这是一个相当标准的程序。这些公司希望从他们的电脑中获得最大的安全性，并希望确保没有黑客能够入侵。但他们不希望太多东西被更改或修改

他们的系统。你必须保持谨慎，并确保发现所有漏洞。

在 Aharoni 花了一些时间思考这个问题之后，他意识到这些工作条件看似不可能实现，但他只需进行若干调整并添加一些工具即可满足这些条件。所有这些工具都可以添加到现有的可启动 Live Linux CD 中。这使得每个人都能更轻松地按照自己的意愿使用该系统，而不会遇到任何问题。

一旦创建完成，就可以将光盘（在我们的情况下则是可启动 USB 驱动器）带入到作业区域，在你希望工作的任何计算机上启动这些内容，然后直接在 RAM 中操作，这样不会对硬盘或其他部分造成任何影响。完成工作后，你可以选择重新使用该驱动器，或者销毁可启动驱动器，在需要另一种使用场景时再次下载即可。

一旦 Kali Linux 开发人员做出了这些艰难的决定，他们发现下一步需要处理的是引入一些真正懂行的人参与到该系统中。这正是他们引入了一位来自 Debian 的新开发人员，该人员帮助他们从零开始构建新的开发基础设施。这一协助对项目非常有益，确保了 Kali Linux 尽可能成功。

## 第二章：理解 Kali Linux 语言的要求

不过，有一点需要牢记：当我们在这本指南中提到“黑客”时，我们指的是**道德黑客**（ethical hacking）。我们的目标不是闯入他人的计算机并开始制造问题或窃取信息。相反，我们的目标是学习如何利用这些功能来理解我们自己的网络，并阻挡不道德的黑客。

当然，你会很快发现，这两者将使用相同的思想和技术。这是因为我们希望在**我们自己的系统**或被要求保护的系统上使用与不道德黑客相同的流程和技术，以了解不道德黑客是如何入侵我们系统的。这需要我们在一定程度上付出努力，虽然这看起来可能像是在做不该做的事，但总体而言，这是发现系统潜在漏洞并确保我们的系统尽可能安全可靠的最好方式。

基于此，现在该看看 Kali Linux 系统的基础知识，以及我们在命令行中可以使用的一些不同代码了。这些命令行代码非常重要，因为它们告诉系统你希望它如何行为以及你希望它执行什么工作。所以，让我们开始吧：

### Kali Linux 基本命令

对于这种系统，有许多可用的命令。它们帮助我们处理或运行任何类型的文档、创建文档、维护目录，以及在 Linux 平台上编写我们需要的其他脚本。这些命令非常多，我们将花一些时间研究最基础的命令以及如何让它们发挥作用。

这里我们要查看的第一个基本命令是获取日期的命令。这是一个常见且简单的命令，但它有助于我们更多地了解这种语言的工作原理，以及我们如何让它的所有部分按我们的意愿协同工作。这一命令将起作用，因为我们将用它来在 Linux 系统的屏幕上显示带有时间的普通日期。还可以显示一些自定义日期，这通过使用下方的特定命令来处理：

```bash
date-set = '17 Jan 2019 12:16'
```

当我们运行并处理这段代码时，我们将得到 2019 年 1 月 17 日 12:16 东部时间（EDT）的结果。

另一种我们可以操作的命令类型，有助于让我们更熟悉在 Kali Linux 中工作，是显示日历的命令。这是 `cal` 命令，当我们要在终端屏幕上显示一个合适的日历时，它会很有帮助。我们的希望是，我们可以以这种方式使用它，以便其他人可以在该日历上看到本地日期。

在 Kali Linux 命令的情况下，还有许多不同的软件包可供使用，人们可以进来以不同的方式管理他们创建的日历。也许你希望它垂直显示，或者使用这个额外命令具有其他关键功能。可以调用的这个额外添加的命令软件包是 `ncal` 软件包。请确保在你的系统上下载它，以便使其正常工作。

接下来是 `Who` 和 `Whoami` 命令。这些命令真的很有用，也是你在这个平台上可以使用的流行命令。`Whoami` 是一个关键命令，它能立即为我们提供精确的有效用户名，这样你就能看到当某个特定命令被执行时，涉及的是谁。它还可以告诉你哪个命令能提供所有已登录用户的详细信息，这样你就知道他们是在哪里执行的，等等。

在此处可能有用的另一个命令是 `PWD`。这是 Print Working Directory（打印工作目录）的缩写。这是一个用于显示命令执行者当前所属特定目录的命令。有时，当我们谈论该平台上某个用户时，很难理解那个人当时所在的目录。这时我们会使用 `PWD` 命令来找到他们。如果你的目录不安全，黑客就能够利用这一点来帮助他们找到他们想要接触的人。

`Ls` 是初学者需要了解的另一条常见命令。每个用户在应用完他们的逻辑后，都会将其作为执行的最初几个命令之一。`Ls` 命令实际上将提供你所在目录中所有可用文档的完整列表。

当然，当需要以正确方式管理这些文件的显示时，我们还有其他 `Ls` 扩展命令可以使用。这取决于你需要什么信息以及列表的哪部分，例如你希望从那里收集哪些文件。

`Cd` 是另一个命令。这是你准备更改在该平台上当前所在目录时使用的命令。当你在进行此类编码以实现你想完成的渗透测试和编码工作时，从一个目录移动到另一个目录时，这会很有用。

`Mkdir`：这是初学者在 Kali Linux 平台上工作时需要了解的关键命令之一。当需要创建一个全新的目录来与此平台一起工作时，它非常有用。它还可以与 `Cat` 命令一起使用，`Cat` 命令是当需要显示单个文件的全部内容时你可以使用的命令。你可能会调用 `Cat` 命令来在该平台上创建或连接单个或多个文件。

`Cp` 是下一个要处理的命令，当我们希望复制现有文件或目录的映像，然后在 Kali Linux 平台的任何其他地方粘贴相同内容，但在保存时希望使用新文件名时，就会用到它。

最后，在这个编码平台上你可以使用的基本命令中，还有一个有助于你完成正在进行的某些渗透测试工作的命令，那就是 `Mv`。这是一个我们可以用来将目录或我们想要的文件移动到新位置的命令。使用这个命令时，我们可以保持目录或文件相同的内容和名称。

### Kali Linux 中级命令

一旦你有了一些时间处理 Kali Linux 平台附带的一些基本命令，是时候继续学习一些更多的命令，这些命令将帮助我们进行我们想要的一些渗透测试及其他工作。该平台有一些其他流行命令，许多该平台的开发人员都会使用，但对于初学者来说，它们不会像我们期望的那样基础。

尽管这些命令的执行和使用需要付出更多努力，但它们的学习仍然非常重要。以下是一些属于此类类别、需要 Linux 稍加中级工作的不同类型命令的示例，列于下方：

- 1. `Rm`：当需要删除或移除一个或多个文件时，我们将依赖此命令。如果我们以递归方式使用此命令，则用于帮助删除整个目录。
- 2. `Uname`：这是一个很有用的命令，当你想要以合适的方式显示当前系统信息时可以使用。它是程序员在需要显示 Linux 环境中的全部信息以易于理解系统并引导其完成相应配置时，会使用以下命令。
- 3. `Uptime`：该命令将为我们提供更多关于系统已正常运行时长的信息。
- 4. `Users`：该命令将为我们提供更多关于用户的信息。这可能包括该用户的登录信息，甚至包括当前已登录到 Linux 系统的用户详细信息。

当我们准备使用 `Kali Linux` 的双启动时，我们需要查看的第一个选项是如何处理我们的双启动，正如我们之前所说。这将帮助我们确保可以随时调用此操作系统，同时我们仍然能够使用我们的常规操作系统。

我们将开始使用我们的 `Windows` 操作系统来执行此操作。`Windows 7`、`Windows 8` 或 `Windows 8.1` 最适合这些用途。它也可以与较新的版本配合使用，但在这些版本上下载和安装 `Kali Linux` 有点困难，因此我们将从处理起来稍容易一点的东西开始。在我们准备好开始自己的双启动之前，我们首先需要确保我们已设置好一些合适的材料并准备就绪。其中一些包括以下内容：

- 1. 一台笔记本电脑或 PC，能够处理我们想要执行的一些不同的黑客过程。
- 2. 最小 4 GB 的 U 盘
- 3. 系统中至少有一个双核处理器，AMD 或 Intel 都可以很好地配合此用途，且 RAM 最小为 1 GB。
- 4. `Windows 10` 或已安装在你的计算机上的其他版本的 `Windows`。
- 5. 最新版本的 `Kali Linux`
- 6. `Rufus`
- 7. 以及完成这一切所需的耐心。

一旦我们确定拥有所有这些用品，现在是时候学习如何在 `Windows 10` 程序的帮助下启动我们的 `Kali Linux` 双启动了。我们需要做的第一步是确保我们下载了该操作系统的最新 `ISO` 文件。获取它的最佳地点是 `www.kali.org`，因为你知道这是官方网站，你不需要担心附带病毒或其他东西。

你可以选择你想处理哪个版本的下载，然后继续创建一个包含此镜像的可启动 `USB` 驱动器。为此，我们需要引入扩展，特别是我们将使用 `Rufus` 扩展。这是一个非常有用的实用工具，因为它允许我们创建一个可启动的 `USB` 闪存驱动器。你可以从 `www.rufus.ie` 下载此扩展，然后安装到你的系统中。

当你在计算机上拥有以上这两项内容时，现在是时候开始享受创建你自己可启动 `USB` 驱动器的乐趣了。首先，取出你想使用的 `USB` 驱动器，然后将其连接到你的计算机。正如上面所说，确保它至少有 4 GB 的内存来处理，并且有足够的空间来容纳 `Kali Linux` 操作系统和 `Rufus` 扩展。

当你有时间插入你想使用的 `USB` 驱动器后，我们将运行 `Rufus`，并使用我们在这里遵循的步骤来帮助我们创建我们自己的可启动 `USB` 驱动器：

- 1. 首先，你会看到一个关于你正在运行的 `Rufus` 程序的屏幕图像。

# 第 5 章：KALI LINUX 的使用

现在我们可以花些时间看看如何进行渗透测试。这基本上是一个深入的过程，我们可以使用它来找出代码中的一些漏洞。在检查黑客可能尝试入侵我们的位置并确定整体最佳处理方式时，这是最值得使用的工具。

我们需要理解此过程首先要了解的是渗透测试（infiltration testing）是什么。渗透测试是一门发现漏洞并深入挖掘的艺术，旨在弄清楚我们的系统能在多大程度上被攻陷。这是在合法攻击针对您的系统发生之前，提前做好准备并保护自身的一种方式。

渗透测试将涉及多个不同的步骤，以检查系统并确保其按我们想要的方式工作。例如，这种测试将涉及利用网络、服务器、计算机、防火墙等，以找出其中的漏洞，然后突出显示使用此系统会出现的一些实际风险。

在进行这种渗透测试时，我们可以采取很多步骤，我们必须确保以实际发现漏洞并确定下一步正确措施的方式设置好系统，以便在您的网络上保持安全。让我们更仔细地看看渗透测试包含的各个不同部分，以及您可以如何在使用 Kali Linux 系统在适当的时间执行这种测试程序。

## 渗透测试的阶段

渗透测试比许多程序员认为的要深入得多，并且会包含多个阶段以达到成功。您尝试完成的阶段数量将取决于您的具体情况以及每个部分需要发生的事情。让我们看看在关注渗透测试时，您可以处理的所有不同阶段。

第一阶段被称为协议阶段（agreement phase）。在此阶段，各方之间存在某种形式的相互协议。该协议将涵盖我们需要遵循的所有高层细节和方法，以及您将经历的利用级别。即使测试是在非高峰时段进行的，攻击者也不得关停生产服务器。

在进行此渗透测试时，您和客户需要讨论许多事项。您可能需要签署保密协议（non-disclosure agreement），以表明您仅将测试详情与您合作的公司分享，而不与他人分享，这通常还会告知我们还需要进行哪些其他操作。可能会有一些关于您可以访问什么、可以使用什么技术，甚至何时执行测试以免干扰企业需要关注的某些工作的规则。

如果这是您自己的计算机系统，那么这就不会是个大问题。

你不需要走完整个流程才能看到结果。但你会发现，如果你正在与另一家公司或客户合作，通常需要解决一些安全顾虑，才能达到你想要的结果，并确保始终 Everyone 都心往一处想。

一旦双方达成共识并讨论好将要遵循的规则，就该着手进行规划和侦察工作了。在这一阶段，你需要尽可能多地收集关于目标的信息。在此情境下，目标就是客户，但你必须确保自己能够获取尽可能多的信息，并查看哪些信息是公开的、可被获取的。

这是黑客在试图进入你的客户系统时会采取的第一步，因此你也需要采取这一步骤。你需要查看域名详细信息、网络拓扑结构、邮件服务器、IP 地址以及客户在互联网上发布的任何其他信息。希望他们已经对其工作做得不错，这样你就无需为此担心了。但大多数时候，客户都会惊讶于已有大量信息公开存在，且可被黑客利用来对抗他们。

一名经验丰富的黑客在这一阶段往往会花费大量时间。这有助于他们绘制网络地图，并确保他们能发现更多潜在的漏洞位置。作为一名道德黑客，你也希望能浏览这些内容，了解系统的相关信息。

现在我们准备进入本阶段的第三部分。这是攻击者可以与目标进行交互的阶段，他们试图在此识别出一些漏洞。攻击者会向目标发送探针，并记录目标对不同输入的反应。

这是一个很有帮助的环节，因为它会告诉黑客系统的安全程度。如果黑客可以毫无问题地发送大量信息和输入，这可能意味着系统存在大量可利用的空隙。如果这个过程比较困难，你会发现这一阶段中的许多端口都是被封锁的。

这一阶段包括几个步骤，例如使用大量扫描工具扫描网络、识别某些打开的共享驱动器、开放的 FTP 端口、正在运行的服务等，以及更多。当我们处理 Web 应用程序时，扫描部分可以是静态的，也可以是动态的。在静态扫描形式中，应用程序代码将由专业的应用程序漏洞分析师进行扫描。

处理此部分的目标是识别出一些易受攻击的函数、存在的库以及在此过程中实现的一些逻辑。当你处理动态分析类型时，测试人员会向应用程序传递大量不同的输入，然后记录部分响应。各种漏洞，如注入、跨站脚本攻击（XSS）和远程代码执行，都是我们在这个阶段将识别出的内容。

此时，黑客已经花了大量时间查看该系统，并试图弄清楚其中包含哪些信息。他们应该对自己可以在哪里进行利用以及想先攻击哪些区域有清晰的概念。这就是为什么下一阶段是获取系统访问权限。

一旦黑客发现了漏洞，他们需要处理的下一件事就是如何利用这些漏洞以获取对目标的某种访问权限。目标可以是很多东西，包括服务器、安全区域、防火墙或系统，具体取决于黑客最初在哪里发现漏洞。

在此阶段，请注意，并非你发现的所有漏洞都会导致你进入此阶段。你不仅需要发现这些漏洞，还需要找到那些可被利用程度足够高、能让你从中获取所需访问权限的漏洞。

接下来在列表中的是维持访问权限。如果你成功发现了一个能让你进入系统的良好漏洞，那么是时候确保你能维持已获得的访问权限了。你需要以不被发现的方式做到这一点。在某些情况下，这是一个挑战，因为你想在系统中停留并看到你想要的结果，同时不让其他人注意到你的存在。一旦被发现，系统会确保将你踢出，你将无法继续深入。

这就是为什么这一步骤的重点在于确保我们获得的访问权限得以维持。这很重要，以确保即使系统被重置、修改或重启，我们仍能保持对系统的访问。这种持久性是黑客用来在系统中长期驻留，并在一段时间内获取有关其内容、内部信息等知识的工具。然后，当黑客确定环境适合且随时可用时，他们将着手利用在其中发现的内容。

这是黑客获取所需信息并引发其期望混乱的部分。这也是许多企业需要谨慎对待周围发生的事情的部分，因为当黑客到达这一阶段时，他们也会遇到一些问题。最好在到达此点之前阻止黑客，这也是我们为何要配合进行渗透测试（infiltration testing）的原因之一。

这是黑客造成大部分实际破坏的阶段。攻击者会试图获取数据、以某种方式破坏系统或网络、发起攻击等。在渗透测试中，我们会控制这一阶段，以确保你造成的混乱降至最低。但仍然是一个好主意去大致了解如果黑客能够进入系统，他们能够做什么。

这是一个略微修改的阶段。一个哑元标志（dummy flag）被放置在稍后需要知晓的关键区域中。利用阶段的目标是去获取这个标志。揭示该标志的内容通常就足以确保如果不对此过程进行处理，网络可以被利用。

一旦渗透测试全部完成，这里发生的最终目标或目的是让黑客或渗透测试人员收集已利用漏洞的证据，然后向负责客户的相关人员报告。通常，这让他们能够弄清楚如何审查以及采取哪些行动。现在，如何处置风险由管理层决定。无论是接受风险、转移风险、忽视风险，还是采取措施使信息更安全，他们都可以在此时采取正确的行动。

## 渗透测试方法

你可以操作几种不同类型的渗透测试。这些可以根据渗透测试人员的位置以及测试人员对目标的了解程度进行分类。还有一些其他类型的参数可以归入正在进行的渗透测试的分类中：

### 黑盒、灰盒和白盒



这是我们可以操作的第一个渗透测试方法。当测试人员获得关于目标的所有知识时，这被称为白盒渗透测试。攻击者将知道处理问题所需的一切信息，包括代码示例、已实施的控制措施、`IP` 地址等。

有时，攻击者对目标没有任何了解。他们没有任何信息地进入，看看通过一些工作能走到哪里。这被称为黑盒渗透测试。请注意，测试人员仍然可以拥有关于目标的其他公开可获取的所有信息。

然后，当测试人员拥有一些关于目标的部分信息时，然后，他们正在进行一种被称为灰色盒子的渗透类型。在这种情况下，攻击者掌握的目标信息比公众能找到的要多一些，比如 `IP` 地址和 `URL`，但他们绝对不会拥有对系统的完整知识或访问权限。

## 外部和内部渗透测试

如果渗透测试是从网络外部进行的，那么我们就在进行一种外部类型的渗透测试。但如果黑客是网络内部的人员，例如员工或公司聘请进入网络的人员，那么这是一个内部渗透方法的良好示例。

当攻击者或黑客是接入网络的内部人员时，关于系统和目标的知识非常高，这就是为什么这些方法比其他方法更有效的原因。从网络外部发起攻击的人在某些情况下可能会成功，但他们会发现这更加困难，因为他们没有其他人所拥有的同等信息。

## 第三方或内部团队

当测试由内部安全团队完成时，基本上属于内部类型的渗透测试。如果公司聘请第三方组织为其执行这些测试，那么这被称为第三方渗透测试。

## 双重盲测和盲测渗透测试

当我们处理盲测渗透测试时，我们会看到，黑客或参与渗透测试的其他人员除了公司名称外，不会收到关于公司或客户的任何信息。测试者必须完成这里的所有工作，就像一个真正的黑客会尝试做的那样。这需要花费更多的时间，但我们看到的结果与我们观察到的一些实际攻击更加密切相关。

然后，我们可以处理一种称为双重盲测的渗透测试类型。这类似于盲测，但安全专业人员将不知道测试何时开始。只有高级管理层才会有这类信息。这样做是为了测试安全团队的控制措施、意识和流程，看看当人们以与日常相同的方式行事时是否会发生状况，而不是在他们知道攻击即将发生时他们的行为。

## 渗透测试有多重要？

在这里，我们可以花些时间看看渗透测试对您的业务可能有多重要。对于一家公司来说，他们能为其业务做的最重要的事情是业务连续性。他们需要重点处理的第二件事是支持服务，以确保业务尽可能顺畅地运行。

因此，为了确保公司高级管理层参与并能够给予适当的关注，渗透测试可以突出由于此过程中的一些发现而可能导致任何业务面临的风险。让我们讨论一下渗透测试将允许您的业务做的几件事。

首先，它将确保在编码语言架构中显示的任何弱点在黑客发现并利用它们之前得到修复和识别。当这种情况是由黑客而不是由您发现并阻止的弱点发生时，会给您的业务造成大量损失，甚至可能导致您无法向客户提供服务。

在现代世界的组织中，需要遵守许多不同的合规程序和规范。渗透测试是确保修复公司安全漏洞的最佳方式之一，以便该公司能够以应有的方式满足合规要求。一个例子就是 `PCI-DSS`。这是一家处理信用卡信息的公司，并帮助接收此类信息的其他公司。这些公司获得 `PCI-DSS` 认证的方式之一，就是确保他们定期进行渗透测试。

渗透测试是对组织内部安全团队的一大启示或一次检查。团队需要多长时间来识别攻击并采取响应措施？团队是否意识到发生了这些入侵之一，花了多长时间才注意到发生了什么？如果是，团队做了什么，当他们这样做时，是否足以完成工作并保持信息的安全可靠？

此外，这将帮助我们弄清楚如果发生这些攻击之一，对公司造成的实际影响。我们可以使用这种测试来看看能造成多大的损害，然后计算如果什么都没做，这种攻击会给公司带来的潜在损失。当然，这些是一些理论性的数字，很难确切知道，但我们通常可以查看如果例如他们闯入信用卡系统会发生什么，以及那将给业务带来多少成本。

进行这种渗透测试很重要，因为它允许我们看到系统的漏洞在哪里，以及我们可以如何修复它们，以便尽可能保护客户的信息。你不想把一切都交给运气，因为一旦黑客能够进入系统，这不仅可能让你损失大量金钱，还可能让你的客户损失大量的金钱和时间，损害你的声誉，并且如果被发现违反合规规则，情况可能会变得更糟。

许多公司会将部分工作外包，因为他们想确保外部人员看看他们是否可以进入系统并造成一些问题。测试人员可以找出问题所在，然后制作一些必要的报告和公司推荐变更，公司可以选择遵循。

通常这对许多公司来说是一个重大的启示。他们可能没有意识到系统中存在这么多问题。有时，即使你经过了一个旨在保护你系统的安全团队，这些问题也会出现。但是，即使有渗透测试人员的建议，业务仍须决定如何处理信息、采取哪些步骤以及如何应对漏洞并使一切变得更好。

渗透测试人员的工作不是修复计算机系统中的问题，除非这是您试图处理的个人电脑。这是您合作的公司高层管理层的职责，决定他们希望如何处理这些问题，以及他们将采取哪些步骤使其变得稍好一些。然而，渗透测试人员可以向高层管理层提供他们可以遵循的建议和推荐。

# 第 6 章：黑客：如何对抗他们

在这个过程中，我们需要花些时间学习的另一个主题是我们在网络安全期间将遇到的不同类型的黑客。你会发现实际上有相当多种类的黑客，但我们将花些时间看看我们可以处理的三种主要类型的黑客。

在本章中，我们将重点关注黑帽黑客、灰帽黑客和白帽黑客。虽然所有这些个人在利用黑客技术和进入系统进行工作时都会使用一些相同的想法和技术，但他们做的工作背后都有不同的动机。考虑到这一点，让我们来看看关于黑客我们需要知道的一些不同事情，以及这些主要类型中的每一个有何相似之处和不同之处。

## 黑帽黑客

我们要看的黑客的第一种类型是黑帽黑客。当我们听到关于黑客攻击的任何信息时，听到的就是这种类型的黑客。这是我们将从电视、电影、节目，甚至本地媒体中听到的类型的黑客。这给我们听过的所有黑客行为都带来了整体的不良声誉，但重要的是要查看所有不同类型的黑客，以便我们能够理解这个世界是如何运作的。

首先，黑帽黑客是指那些致力于发现计算机安全系统漏洞，并利用这些漏洞谋取个人经济利益或出于其他恶意目的的人。这与我们稍后将介绍的白帽黑客略有不同。黑帽黑客试图将系统用于谋取其个人利益，而白帽黑客则是致力于发现并修补黑帽黑客可能利用来谋取自身利益的安全缺陷的人。

如果你没有使用适当的安全措施，黑帽黑客很可能会对你的系统造成巨大破坏，无论这是一个个人系统还是大型公司系统。这种破坏包括窃取其中的部分个人信息，破坏主要系统中的某些安全性，甚至关闭或篡改网络和网站中发生的某些功能。

黑帽黑客在收集所需信息时会采取许多不同的手段。他们可能会使用击键监视程序来获取你的用户名和密码，甚至发起攻击以禁用我们使用的一些网站的访问权限。在某些情况下，恶意黑客会采用不需要计算机就能获取所需数据的方法，例如致电系统并冒充他人身份以获取该用户的密码。

## 灰帽黑客

现在，是时候让我们深入了解灰帽黑客了。这种黑客处于一种中间状态。他们并没有真正被他们试图进入和获取访问权限的公司所雇佣，但他们进行这种黑客行为也未必抱有恶意。这算是两者之间的一种灰色地带，这也是为什么我们在本节中讨论灰帽黑客的原因。

灰帽黑客可能是那些会违反计算机安全界某些伦理原则和标准的专业人士，但他们这样做时并不具备我们在上述黑帽黑客中看到的那些恶意意图。这些黑客经常从事一些在技术上并不合法的行为，看起来也不合规，但他们往往是为了在这个过程中为公众利益行事。

我们可以将灰帽黑客视为更多的是一种中间立场。他们实际上不被允许进入系统，因此他们的行为是非法的。但他们这样做是为了查明漏洞，让用户更安全并知晓这些信息，而不是在告知其他黑帽黑客这些漏洞之前窃取信息并随意使用。

很多时候，当谈到黑客技术时，人们会将黑客技术和信息安全视为一个非黑即白的世界。当我们在审视安全环境时，这种类型的黑客技术将发挥重要作用。我们将看到的此类黑客最大的例子之一，就是当某人利用网络的漏洞来向客户和其他人传播关于存在此类漏洞的意识。

在这种情况下，专家们认为，灰帽黑客与白帽黑客的区别在于，灰帽黑客会以一种更公开的方式利用漏洞。这仍然可能允许其他黑客利用正在发生的情况并引发问题。但另一方面，当我们与白帽黑客合作时，我们可能会发现他们是以私密的方式进行的，然后在不公开这些结果的情况下向公司发出警报。

## 白帽黑客

最后，但同样重要的是，我们需要看看白帽黑客是什么样的。这是一个经常被人忽视，或者与其他类型的黑客相比很少被考虑到的人。但他们仍然能够执行其他两类黑客能够执行的许多相同类型的流程和黑客攻击。这些人将更侧重于帮助他人，并确保企业和他人保持安全，而不是致力于窃取信息或制造麻烦。

那么，白帽黑客就是计算机安全领域的专家，他们可以突破受保护的或网络，然后测试和评估该类型网络上的安全性。这些黑客可以利用自己的某些技能，通过在恶意黑客（或我们上面提到的黑帽黑客）发现漏洞并利用之前，揭露漏洞来改善公司安全。

尽管白帽黑客使用的方法与我们在黑帽黑客身上看到的类似，但前一组人实际上已经获得了许可，可以使用其中一些战术来对抗最初雇佣他们的组织。这些人可能是以自由职业者的身份工作，或者，在一些经常受到攻击的大型企业中，他们可能会一直雇用这类专家团队。

这类黑客被视为能够以造福社会及周围他人的方式使用其技能的人。他们有时甚至是改过自新的黑帽黑客，尽管在大多数情况下，他们是上过大学，对黑客会使用的某些技术和方法更为精通的个人。任何公司都有可能雇用这些人士，帮助他们确保网络安全，并保持尽可能安全。



白帽黑客帮助其受雇于的业务的方式有很多。根据正在发生的问题，这些个人或专家可以帮助进行测试，同时实施一些最佳实践，以帮助公司和组织在未来降低被恶意黑客攻击及其信息的可能性。

## 其他类型的黑客

除了上面列出的一些黑客类型外，还有几种其他类型，我们将花几分钟时间谈谈这些类型及其能力，以及它们与我们已经看过的其他三种类型的区别。

### 脚本小子（Script Kiddies）

第一个选项是脚本小子。这是一个贬义词，用于描述那些不太关心学习正确编码技能以完成工作的业余黑客。这些黑客是那些下载工具或使用他人已经编写好的现有代码来进行黑客攻击的人。这样做的首要目的是给朋友留下深刻印象，或者顺带获得一些关注。

然而，这些人对了解黑客技术如何运作没有欲望或兴趣。通过使用他人花时间编写和工作的这些代码，这些黑客可以发起攻击，而无需花费时间去审视他们正在进行的攻击质量。这些人发起的最常见的网络攻击包括 `DDoS` 和 `DoS` 等选项。

### 绿帽黑客（Green Hat Hacker）

我们还将看到可能存在绿帽黑客。这些是网络世界的业余黑客。他们可能类似于之前的脚本小子，但有一个关键区别，即他们愿意学习如何成为一名完全的黑客，只是他们目前还没有这些技能。当你刚开始使用这本指南书时，你可能是这样。你准备好开始学习如何入手，但还不完全知道如何操作一切。你可能会发现，这些人非常活跃于他们的黑客社区，并在过程中提出大量问题。

你可以通过学习他们对编码世界的额外兴趣来识别这些人，区别于脚本小子。一旦你回答了他们的问题，他们会倾听，然后带着强烈的学习欲望弄清楚下一步该怎么做，再提出许多其他问题。

### 蓝帽黑客（Blue Hat Hacker）

蓝帽黑客。这是另一种新手黑客，其主要议程是报复那些让他们生气的人。他们想要进行黑客攻击，因为他们认为这是一种报复他们的方式。他们对学习没有欲望，可能会使用简单的网络攻击，例如用大量数据包淹没你的 `IP`，这将导致 `DoS` 攻击。

### 红帽黑客

红帽黑客是列表中的下一个角色。这些人的议程与我们看到的白帽黑客类似，简单来说，他们试图阻止黑帽黑客的行为。然而，在对抗黑帽黑客时，他们的行事手段却极其冷酷无情。

这些人不会仅仅报告他们看到的恶意攻击，而是认为彻底击垮那个黑帽黑客才是更好的做法。他们非常乐意对黑帽黑客实施复仇，手段包括一系列激进的网络安全攻击和恶意软件。在某些情况下，后果如此严重，以至于黑帽黑客不得不一一替换其整个系统，因为他们无法修复已发生的破坏。

### 骇客行动主义（Hacktivist）

如果您曾花时间关注过社会活动家传播社会、宗教或政治议程的行为，那么您迟早也会遇到骇客行动主义。这就是您在网络上看到的活动家行为，尽管两者之间存在一些关键差异。

骇客行动主义者是匿名操作的单个黑客或黑客群体，他们认为通过自己的行动可以带来某种社会变革。通常，他们会入侵组织或政府以引起关注。有时，这样做仅仅是为了表达他们对某些反对其立场的观点的不满。

### 内部恶意人员或吹哨人

最后，我们要探讨内部恶意人员或吹哨人的概念。这通常是某种对公司怀有怨恨的员工，或者是被竞争对手利用或收买的战略性员工，目的是窃取竞争对手的一些重大商业秘密，以助对手保持竞争优势。

这类黑客通常会利用其易于获取信息的特权以及在公司内部的角色，渗透系统并制造他们想要的问题。由于他们已经被视为公司内部人员，获取信息对他们来说更容易，而且他们很可能已经拥有进入此类系统所需的大部分访问权限。

由于存在如此多种您可以经常接触到的黑客类型，您会发现，采取谨慎的态度并警惕那些可能试图入侵您系统的潜在黑客始终是最好的做法。无论您是担心自己的个人系统，还是负责一个需要精心维护的大型系统，请务必留心那些试图在过程中对您造成伤害的人。

在大多数情况下，尽管各类黑客的目标和目的略有不同，但他们都会依赖许多相同的技术甚至更多手段来完成任务。这一点至关重要，因为它能确保我们在过程中取得良好的成果，并且我们能够像坏人一样使用相同的技术来保护我们系统的安全和稳定。

# 第七章：更多网络攻击：知己知彼

我们也需要花时间研究黑客可能用来对付我们的不同攻击类型。黑客获取我们的信息并入侵我们正在使用的系统的方式多种多样，如果我们不小心，最终会导致系统被破坏，大量信息被窃取并被用来对付我们。

由于黑客对抗我们并入侵我们系统的方式非常多，要将黑客拒之门外并预测他们下次从哪里发起攻击是一项艰巨的任务。如果我们能更多地学习这些攻击知识并努力加以防范，我们的处境就会更好。基于此，您会发现有很多类型的攻击，其中一些最常见的包括：

## 中间人攻击

我们要花时间探讨的第一种攻击类型被称为中间人攻击（`Man in the Middle attack`）。在这类攻击中，恶意黑客会采取措施，悄无声息地将自己插入两个通信方之间，而又不被发现。目标是未被检测到，并且让黑客冒充此次交互中的双方。黑客可以截获、发送和接收原本 intended 给任一用户的数据。有时，根据传输信息的性质，交给黑客的信息可能是密码和账号。

典型的通信流发生在服务器和客户端之间。例如，要访问您的银行账户，您需要登录银行网站。您的计算机（即这里的客户端）会将必要的登录信息发送到银行服务器。如果服务器验证信息正确，银行就会返回一个确认，表明您已成功登录，然后您就可以访问该账户。

这一切运行良好，直到黑客能够进入账户并制造一些麻烦。恶意黑客会努力接入网络，并在真实服务器和客户端之间建立通信中继。这使得黑客有机会修改服务器和客户端之间的所有通信。

信息不再按原计划从客户端流向服务器，而是到达了作为黑客的中继点。黑客随后能够修改发送给服务器的信息、修改发送给客户端的信息，或者仅仅读取信息以获取密码和用户名。

例如，假设客户端表示他们想向另一个银行账户汇款。他们填写说另一个银行账户号应为 `222333444`。但黑客使用中间人攻击截获了该通信，他们可能会更改账号。

在这种情况下，银行会收到转账请求的通知，并获取黑客发送的账号。他们不会察觉到有任何欺诈行为，并乐于将钱发送到他们认为您指定的账户。而在任一方意识到盗窃发生之前，一切都已为时已晚。

## 字典攻击

我们要研究的下一类攻击被称为字典攻击。这是一种用于突破计算机、受密码保护的服务器或机器安全的方法或技术。字典攻击试图通过输入字典中的每个单词作为密码的过程，来击败某些认证机制。它还可能利用此方法来确定目标计算机在发送前能够加密的消息或文档的解密密钥。

这些攻击之所以成功，是因为企业和个人倾向于选择普通单词作为密码，而不是设置难以猜测的密码。这些普通单词通常可以在任何字典中找到，黑客会利用这一点满足其自身需求。

如果您没有为自己喜欢访问的系统或网站选择好且安全的密码，那么您将陷入麻烦，因为黑客会试图通过此类攻击之一收集该信息。由于必须使用字典中的所有单词，这需要一些时间，但对于黑客来说非常有效。

用户通过系统进行认证最常见的方法是密码。这种方法还将持续一段时间，因为它被视为最实用和最方便的认证用户想要进入系统的方式。尽管使用简单，但这通常是最弱的认证形式之一，因为用户不擅长选择强密码。

垃圾邮件发送者和黑客非常乐意利用这种弱点，通过我们目前正在讨论的字典攻击手段来实现目的。这些人会尝试输入所有能想到的不同密码，直到找到那个能让他们进入你系统的密码为止。

这里的好消息是，你可以采取一些对策来防范这种类型的攻击。这些对策包括：

- **延迟响应**：服务器稍作延迟响应会很有帮助，因为它可以阻止黑客在较短的时间内检查超过少数几个密码。
- **账户锁定**：即在密码尝试失败几次后锁定账户。这将使垃圾邮件发送者或黑客无法同时检查超过少数几个密码。

当用户对选择的密码类型不够谨慎时，这类攻击最为有效。如果你选择了一个非常强的密码，或者使用需要多个密码的系统，这将使此类攻击难以像黑客期望的那样起作用。

## DOS 和 DDOS

拒绝服务（`Denial of Service`，简称 `DOS`）攻击旨在拒绝某些合法用户对网站或资源的访问。合法用户在访问网络、电子邮件或网站时可能会遇到问题，或者他们发现这些资源运行得非常缓慢。这种类型的攻击是由黑客发起的，他们会在同一时刻向目标资源（如 web 服务器）发送过多的请求。由于这种流量的突然涌入，服务器将无法应对并最终失败。这可能导致服务器变慢，或者所有服务器同时崩溃。

切断某些企业的在线连接会给企业带来客户和资金的损失。我们所有人都高度依赖计算机网络和互联网，它们将支持我们现代世界中的许多公司。一些组织，如电子商务网站和支付网关，完全依赖互联网来开展业务。如果他们无法上线进行工作，在这个过程中将失去大量客户和资金。

在讨论 `DOS` 攻击时，你会发现五种常见的技术。列表中的第一种是“死亡之 Ping”（`Ping of Death`）。`Ping` 命令通常用于测试网络资源是否可用。它能起作用，是因为它可以向网络发送一个小数据包。“死亡之 Ping”随后会利用这一点，发送超过 `IP` 或 `TCP` 允许的最大限制的数据包。

`TCP/IP` 碎片化会将数据包分解成更小的块，以便我们能够将其发送到服务器。由于发送的数据包比服务器能处理的更大，服务器会重启、冻结或崩溃。



另一个需要警惕的攻击是 Smurf 攻击。这是一种使用大量 ICMP（互联网控制消息协议）或 Ping 流量针对目标地址的攻击。回复的 IP 地址被伪造，看起来像是预期受害者的地址。因此，所有回复都会发送给受害者，而不是用于 Ping 的 IP。由于单个 IP 地址最多支持 255 个主机，Smurf 攻击会将其中一个 Ping 放大 255 倍。其结果是网络速度变慢到几乎无法使用。

然后是缓冲区溢出。缓冲区是计算机 RAM 中的一个临时存储位置，用于保存我们需要的一些数据，以便 CPU 有时间对其进行操作，然后再将其写回磁盘。缓冲区会有大小限制。这种攻击可以向缓冲区加载超出其容量的数据。这会导致缓冲区溢出，基本上会损坏其保存的任何数据。

Teardrop（泪滴攻击）是另一种可能发生的数据攻击。这种攻击涉及非常大的数据包。TCP/IP 会将它们分解为片段，然后在接收信息的宿主机上进行组装。攻击者随后可以在发送时操纵这些数据包，使它们相互重叠。这会导致目标系统崩溃，因为它忙于将这些数据包重新排序。

最后，是 SYN 攻击。这是“Synchronize”（同步）的缩写。我们发现这种攻击利用了 TCP 用于在不同系统之间建立通信的一种三方握手机制。它能起作用，是因为它会给受害者发送大量不完整的 SYN 消息。这会导致目标机器从内存中占用从未使用的资源，最终导致它拒绝合法用户访问系统。

## 勒索软件

当我们保护数据免受黑客侵害时，还需要担心几种类型的恶意软件。我们要提防的第一种恶意软件是勒索软件（Ransomware）。这是一种恶意软件，它可以加密你计算机上的某些文件，或者用于完全锁定你对该系统的访问权限。它由黑客传播，他们试图锁定你对文件的访问，然后向你索要赎金或金钱。他们通常声称，如果你支付费用，他们会提供解密密钥，以便你找回文件。

通常，黑客不会完全放手。你也许能也许不能再次访问你的文件，但即使你能，黑客通常也会在系统上留下某些东西，以便他们以后可以访问并随心所欲地操作。当我们深入了解勒索软件时，会看到几种不同的选项，其中包括：

- **加密恶意软件**：这些是我们看到的最常见的恶意软件类型之一，令人惊讶的是它们能造成多大的破坏。除了能从受害者那里获得超过 5 万美元外，其中一种名为 WannaCry 的恶意软件实际上可能在攻击全球各地的医院并导致无法访问患者文件时，使数千人的生命面临风险。
- **锁定程序**：这些会感染你的整个操作系统，导致你被锁定在计算机之外，无法访问你需要的任何文件或应用程序。
- **恐吓软件**：这是一种假冒软件，会出现在你的计算机上并声称电脑存在某些问题。这些软件通常会要求你支付费用来修复问题。某些变体会锁定计算机，而另一些则会在屏幕上充斥着大量弹出窗口和警报。
- **泄密勒索软件**：这种通常也被称为“泄密”，它威胁如果你不付钱，就会在网上发布你的一些被盗信息。每个人的电脑上都有一些敏感类型的文件，所以很容易理解为什么这会让很多人感到恐慌和问题。
- **RaaS**：这被称为“勒索软件即服务”（Ransomware as a Service），是由黑客匿名托管的一些恶意软件，他们可以处理一切，以换取对收到的赎金的分赃。

## 病毒

计算机病毒被设计成可以从一个主机传播到另一个主机，甚至能够自我复制。类似于流感病毒在没有宿主细胞的情况下无法繁殖，这种计算机病毒在没有诸如文件或文档等程序的情况下，无法繁殖或进行传播。

从更技术的角度来看，计算机病毒只是一种恶意程序或代码，被编写出来以改变计算机的运作方式，其设计方式使其可以从一台计算机传播到另一台计算机。病毒之所以能运行，是因为它会插入或附属于合法的程序或文档，然后在适当的时候执行其代码。

一旦病毒有机会攻击文档、文件或程序，病毒就会潜伏在那里并保持休眠状态，直到出现某些情况导致系统执行其代码。为了使病毒真正感染您的计算机，您需要先运行已感染的程序，以便病毒能够看到其代码被执行。

这意味着，这种病毒可能会在您的计算机上保持休眠状态，长时间不采取任何行动，且您的计算机上不会出现任何症状或迹象。但是，一旦病毒能够感染您的计算机，该网络上的任何其他系统也会随之感染。根据黑客编写程序的方式，这些病毒可以执行许多操作，例如接管您的机器、向您的邮件列表中的其他人发送垃圾邮件、破坏文件、记录击键活动以及窃取数据和密码。

在一个始终处于连接状态的世界里，您可以通过多种方式感染计算机病毒，其中一些方式比其他方式更明显。病毒通过各种不同的领域传播，例如社交媒体、互联网文件下载、短信、电子邮件等等。通过您的智能手机和移动设备发生这种情况也是完全可能的。这就是为什么我们通常小心对待我们在网上共享的附件或内容是一个明智的主意，因为病毒也可能隐藏在内部。

## 特洛伊木马

既然我们在这里，我们需要看一看特洛伊木马的概念。这些特洛伊木马是恶意软件传输的一种统称，但我们可以操作的好几种不同类型。根据程序员的意图，特洛伊木马在黑客攻击方面可能像瑞士军刀一样多功能。它可以作为您希望执行的其他一些活动的工具，可以独立工作，还可以做更多事情。

用更简单的话来说，特洛伊木马是黑客的一种传输策略，它可以帮助黑帽黑客传输各种威胁，从立即索要赎金的勒索软件到能够隐藏自己同时从所在系统窃取大量信息的间谍软件。

特洛伊木马看起来像是您可能会信任的其他东西。有时它们看起来像合法的应用程序、关于您浏览器的广告，以及免费的音乐和软件。用户众多不明智的行为都可能导致特洛伊木马感染。您的计算机感染其中一种特洛伊木马的一些最常见方式是通过以下手段：

1. 下载破解的应用程序。这可能是对您想要的一款软件的非法免费副本的承诺。这听起来可能很有吸引力，但通常这些程序会包含您需要担心的特洛伊木马攻击。
2. 下载您不确定是否来自信誉良好公司的免费程序。看起来像很棒的屏幕保护程序或免费游戏的软件，背后很容易隐藏着特洛伊木马，尤其是如果您不确定它来自哪个网站的话。
3. 打开受感染的附件。您可能会在电子邮件中看到这种情况，电子邮件看起来有点奇怪，但有一个看起来重要的附件，比如送货单或发票。但是当您点击附件时，您会发现点击它会启动一个特洛伊木马。
4. 访问一些不太正规的网站。一些网站只需要片刻时间就能感染您的整个系统。另一些网站会像假装流式传输一部热门电影那样欺骗您，但实际上只有当您下载视频编解码器时才会发生，而这实际上是一个特洛伊木马。
5. 我们也可以在任何利用最新趋势进行伪装的社交工程技术中看到这种情况。例如，2017年12月，由于硬件问题，大量安装英特尔处理器的基础架构容易受到攻击。黑客能够利用一些恐慌，伪造补丁，当人们同意使用此补丁时，他们就会安装一个特洛伊木马。

## 欺骗攻击

我们将研究的最后一类恶意软件被称为欺骗攻击。一般来说，我们会发现欺骗攻击是一种欺诈行为，即通信来自未知来源，但伪装成接收者已知的来源。当通信机制缺乏本应具备的高级别安全性时，就会出现欺骗攻击。

电子邮件欺骗攻击是所有这些欺骗手段中最广为人知的之一。由于核心SMTP在过程中无法为我们提供身份验证，黑客很容易伪造以及冒充电子邮件。欺骗的电子邮件可能会向目标索取大量个人信息，有时它们可以很好地伪装成来自您认识的发送者。

这些电子邮件会要求接收者提供一些个人信息，例如账号，用于验证身份。电子邮件欺骗者可以使用此编号接管目标的身份，访问银行帐户，更改联系方式等等。

如果接收者收到一封看起来来自他们认识并信任的来源的欺骗电子邮件，黑客就会知道这一点。这意味着他们更有可能至少打开电子邮件，甚至对其采取行动。因此，欺骗电子邮件还将包含对用户额外的威胁，包括病毒和特洛伊木马。这些程序会通过触发远程访问、意外活动以及删除文件，对计算机造成大量损害。

正如我们所能看到的，黑客可以进入您的系统并造成麻烦的方式有很多。当您不重视系统的安全或保护其中的某些信息时，您最终也会在过程中遇到一些麻烦。采取正确的预防措施，注意在线分享信息的方式等等，对于确保您能挡住黑客并始终保持系统安全至关重要。

# 第8章：保护我们的互联网流量

很少有人拥有一台没有至少允许一些互联网访问的计算机。而且，当我们使用计算机时，我们中的大多数人大部分时间都花在网上。这可能包括工作、查看社交媒体、在线寻找物品、购物，甚至发送和接收电子邮件。由于我们可以通过互联网使用计算机做各种各样的事情，难怪我们会如此努力地寻找保持互联网安全的方法。让我们看看您可以采取的一些措施来维护互联网流量的安全，以便您可以随心所欲地使用计算机，而不会遇到任何风险。

### 什么是网络扫描？

为了保护我们正在处理的互联网流量，我们可以执行的一个过程是完成网络扫描。网络扫描是指我们使用计算机网络来收集与计算系统相关的信息。网络扫描主要用于系统维护、安全评估，也可以帮助黑客执行他们想要的攻击。在网络扫描期间会发生很多事情，一些最常见的目的包括以下内容：

1. 识别所有在我们要目标主机上运行的可用TCP和UDP网络服务。
2. 识别用户和我们想要目标主机之间的过滤系统类型。
3. 通过评估IP响应，确定目标系统正在使用的操作系统。
4. 评估目标主机的TCP序列号可预测性，以确定序列预测攻击和TCP欺骗。

网络扫描将包括网络端口扫描以及一些漏洞扫描。这种端口术语很重要，因为这是一种我们将数据包通过网络发送到指定服务端口的方法。这是为了帮助我们确定该系统有哪些可用的网络服务。当我们试图排查系统问题并帮助保持系统尽可能安全时，这种程序是最有效的。



# 网络安全基础

## 漏洞扫描与网络扫描

漏洞扫描是我们可以用来发现计算系统已知漏洞的另一种方法。它是为了帮助我们检测操作系统或应用软件中发现的薄弱点，如果我们不小心，黑客可能会利用这些薄弱点来崩溃或破坏系统以达到他们的目的。

将网络端口扫描和漏洞扫描结合起来，是一种很好的技术，有助于我们在网络上收集信息。但当由不属于您系统的人执行，且此人选择保持匿名时，这些被视为攻击的前奏。

网络扫描的过程，如Ping扫描和端口扫描，将返回大量关于哪些IP地址直接映射到活动...活动的宿主，以及这些宿主提供的各种服务。另一种被称为反向映射的方法，将收集一些关于那些不会映射到活动宿主的IP地址的详细信息，这将有助于攻击者更集中地关注他们最有利的可行攻击地址。

## 什么是VPN？

保持你的网络尽可能安全和安全的其中一种方法是使用VPN，即虚拟私人网络。这是一个很好的工具，因为它可以确保你在使用互联网时，能够创建一个到可信网络的安全连接。你可以使用这些VPN来访问一些你想要访问的地域限制网站，帮助在上网时屏蔽一些浏览活动免受他人窥探，还有更多功能。

这些VPN现在非常流行，但有时流行原因并非程序员最初开发它们的初衷。最初，这些网络只是商业网络通过互联网连接到另一个网络的方式，或者让你在外旅行或在家时能够访问你的商业网络。

VPN本质上会将你的所有网络流量转发到VPN，而诸如远程访问本地网络资源和绕过互联网审查等好处正是由此而来。好消息是，大多数主要操作系统都内置了某种VPN支持。

VPN将连接到互联网上某处的你的平板电脑、智能手机或PC，并允许你使用该计算机的互联网连接进行一些浏览。因此，如果你与另一个国家的服务器有连接，那么你就能够访问许多在其他情况下无法访问的内容。那么，这将如何帮助你呢？这种VPN可以通过以下方式帮助你，包括：

- 1. 绕过网站或视频和音频流媒体播放时的一些地理限制。
- 2. 观看Hulu和Netflix等可用的流媒体内容。
- 3. 在进行电驴下载时保护你自己不被记录日志。
- 4. 通过隐藏你真正的位置在线获得至少一点匿名性。
- 5. 保护你自己免受一些不可信的Wi-Fi热点进行的窥探。

绝大多数想要保持安全并将信息远离窥探者和黑客的人都将求助于VPN。使用VPN的一种流行方式是绕过许多地理限制以观看其他国家的内容。无论如何，它都可以帮助隐藏你的位置，让你更容易以安全的方式在线完成你想要完成的任务。

当该时候将计算机，或者你想使用的其他设备，连接到VPN时，计算机将表现得好像它可以连接到VPN所在的同一个本地网络。你所有的网络流量都通过一条安全连接发送，直到达到你选择的VPN。

由于计算机表现得好像属于该网络，这将使你能更容易地安全地访问本地网络资源，无论你在世界何处。这意味着你可以像在VPN所在位置一样使用互联网。如果你想使用公共Wi-Fi或访问基于你所在地理位置而被封锁的网站，这将带来一些好处。

当你花时间在连接这些VPN之一时浏览网页，你的计算机可以通过我们加密的VPN连接联系网站。然后，VPN能够为你转发该请求，并将它从网站接收到的响应转发回安全连接。例如，如果你使用基于美国的VPN来帮助你访问Netflix，Netflix将注意到连接来自美国，并为你提供在那里可用的内容。

使用这些VPN有很多很好的理由。它们是隐藏你在线发送的信息的好方法，并将使黑客更难找到你并弄清楚你在网上做什么。对于那些希望能够在进行工作时更少担心黑客如何介入并造成问题的个人和公司来说，使用VPN可能是最佳选择。

启用一个好的防火墙是你需要关注的下一件事。防火墙将充当你所需的网络与互联网之间的屏障。如果你部署了一个好的防火墙，你会发现它有效地关闭了计算机的端口，从而防止外部世界与你的设备通信。这是件好事，因为它通过阻止威胁进入系统并在其他设备之间传播来提供保护；同时，它也是我们防止数据从计算机流出的一种好方法。
