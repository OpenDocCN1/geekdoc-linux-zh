我们必须始终牢记，我们需要在一切时刻保护三类主要实体。我们需要保护某些终端设备，包括路由器、智能设备以及我们的计算机。我们同样需要保护云和我们的网络。保护这些实体可能用到的常见技术将包括防火墙、恶意软件防护、电子邮件安全、DNS 过滤等。

这引出了我们关于为何网络安全如此重要的最后一个问题。在当今互联的世界中，当我们拥有更先进的程序来防御系统时，每个人都能从中受益。如果我们从更个人的层面来看待这一点，此类攻击会导致众多问题，包括勒索企图、对您重要的数据丢失以及身份盗窃。

确保您的系统拥有正确类型的网络安全，并检查任何使其成为现实所需的更新，这对帮助您获得想要的结果至关重要。这不是我们应该搁置或假设完全不需要的事情。即使是个人也有需要保护的东西，而能够保护您的信息和系统的安全是完成这一目标的第一步。

这使我们回到网络安全为何重要以及为何必要的问题。从根本上说，网络安全旨在保护系统及系统中的信息免受网络威胁。这些威胁有许多不同的类型和形式，包括恶意软件、网络钓鱼、勒索软件等。随着我们在技术领域看到的所有进步，新的可能性时刻都在涌现。确保网络安全能够跟上这种步伐，并保护我们、我们的计算机和网络，是我们许多人正在努力应对的一场艰难战役。

借助一种名为自动化的工具，黑客可以以较低的总体成本部署大规模攻击。此外，构成网络犯罪的经济体系使得完成更复杂的攻击变得比以往任何时候都更容易，因此许多人愿意且能够获取这些信息并将其用于对抗我们。

这意味着网络安全及其配套工具需要比黑客发送给我们的内容更加先进。这意味着引入一些机器学习、自动化和一些共享威胁情报是确保组织能保持在这一领域前沿，并打击某些高级威胁的首要事项。而且有大量的高级威胁需要处理，包括：

- 1. DNS 隧道：域名系统（DNS）是现有的协议之一。请将一些人类友好的 URL 转换为更机器友好的 IP 地址。大多数时候，黑客会利用广泛使用且非常受信任但未被监控的 DNS。DNS 隧道将利用客户端服务器模型来传输恶意软件和其他数据。
- 2. 恶意加密货币挖矿：当攻击者找到将 JavaScript 引入网站的方法，然后使用此代码劫持访问该网站者的处理算力时，就有可能发生加密货币挖矿攻击。这是为了挖掘所需的加密货币，如比特币。对于基于恶意软件的此类攻击，用户的整个设备会被接管，CPU 会以更高的级别被使用，以帮助挖掘所需的加密货币。
- 3. 勒索软件：这是犯罪商业模式的重点，它会将一些恶意软件安装到我们的设备上，然后扣留一些信息、数据或文件。由于其进入门槛低且收益潜力高，勒索软件是当前组织面临的重大威胁之一。

在许多情况下，组织和政府会采取被动和点状产品的方法来应对他们在网上遇到的一些威胁。这使他们能够拼凑单个安全技术以保护其数据和网络。然而，这种方法昂贵且复杂，仍然难以应对随之而来的所有不同部分。

我们都听说过，当我们所使用的某些安全未按希望的方式发展时，数据泄露可能有多糟糕。经常登上头条新闻的许多毁灭性泄露事件表明，一些传统的数据安全方法无效且难以操作。

借助我们之前讨论过的某些主题，例如共享威胁情报、机器学习以及公司安全架构中更多的自动化，这将帮助公司跟上更复杂的网络攻击的增长速度。我们还将看到，机器学习有助于我们准确识别已知威胁的一些变异，预测攻击中接下来发生的步骤，识别模式，并通知自动化工具以在组织范围内创建和实施保护。

其中巧妙之处在于，如果我们以适当的方式这样做，我们可以看到上述所有事情几乎实时发生。凭借共享威胁情报，任何用户看到、识别或阻止的内容都可以让共享社区中的其他所有人受益。预防措施越全面，尤其是在快速完成的情况下，我们就越容易降低在线安全的总体风险，管理起来也越容易。

公司需要考虑它们依赖的安全类型，并决定如何处理它。保持这种安全的最新状态，而不是仅仅回避它或假设这不是你需要太担心的事情，对于你看到这一整合带来的成功程度至关重要。
