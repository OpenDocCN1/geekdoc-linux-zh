现在，我们已准备好进入下一步。我们可以通过重启笔记本电脑或 PC 机来实现这一步骤，因为我们希望更改启动时显示的操作系统。重启计算机时，务必直接进入启动管理器。选择您希望计算机从 USB 启动的选项。根据您正在使用的计算机品牌不同，这些选项的外观会有所差异，因此请花点时间寻找该选项。

如果操作正确，您应该会看到计算机显示带有 Kali Linux 的安装窗口。到达这一步时，会出现几个关于如何安装 Kali Linux 的选项。您应该选择显示“Graphical Install”（图形化安装）的选项，以帮助您轻松启动该操作系统。我们甚至可以更进一步，添加一些我们认为效果不错的功能和设置。例如，您可以选择在安装时使用的语言以及应包含的国家/地区。

在依次添加上述的一些自定义偏好设置以及系统弹出的所有其他选项之后，是时候处理我们的主机名了。此时您的安装程序会要求输入此主机名。您可以选择任何想要使用的名称，可以将其视作用户名。然后确保输入您希望 root 用户拥有的密码。输入这两项内容后，您可以点击继续按钮。

现在，我们需要花点时间选择希望在此处使用的分区方法，对于我们的项目，我们将使用“Manual”（手动）方式。

下一步需要谨慎操作，以确保系统能按我们的意愿运行。我们只需选择之前专门为 Kali 安装在 USB 驱动器上创建并添加的那个分区，然后点击“Continue”（继续）按钮。当您确定已选择正确选项后，在继续之前请选择“Delete the partition”（删除该分区）。

如果您选择了正确的选项并正确操作，您会看到 Kali Linux 的分区会提示存在 FREE SPACE（空闲空间）。在决定继续此过程之前，我们需要选择处理这个空闲空间分区。

这是安装程序将询问我们希望如何使用所有空闲空间的部分。在此处我们要做的是点击“Automatically partition the free space”（自动划分空闲空间）部分，然后点击继续按钮。接下来，选择标有“All files in one partition”（所有文件在一个分区）的选项。如果网络上的表述略有不同，这通常是推荐给新用户的选项。然后，我们点击标有“Finish partitioning and writes changes to disk”（完成分区并将更改写入磁盘）的选项以完成此步骤。这里它会授予写入这些更改到磁盘的正确权限。您需要点击“是”然后点击“继续”。

在此部分，我们将看到 Kali Linux 的某些安装过程正在发生。完成此过程可能需要一点时间，因此请等待大约 15 分钟，以确保过程有足够的时间完成。当您的过程进行到一半时，您将看到它会弹出来询问关于网络镜像的问题。选择您要使用的镜像。此设置涉及您想要使用的更新选项类型，因此目前最好选择“否”，如果稍后想要更改这些设置，可以再进行调整。

接下来，安装程序会询问是否安装 GRUB 引导加载程序。在继续之前，您希望点击“是”。接下来，它将询问您想要在哪里安装 Kali GRUB 引导加载程序。具有第二个选项的硬盘是最好的。我们希望 GRUB 安装在您的硬盘上，否则 Kali Linux 的安装程序在计算机启动时将不会显示选择操作系统的选项，而这正是我们在此过程中的一个主要目标。

在完成这些步骤并成功执行 Linux 安装过程后，您将看到询问是否继续或返回的屏幕。点击“继续”，然后弹出 USB 驱动器。此时您需要重启系统。在启动过程中，您可以通过 GRUB 加载器看到 Kali Linux。在这里，您可以选择 Kali GNU/Linux 来使用 Kali Linux 启动计算机。或者，如果您只想使用 Windows 环境，那么可以选择标有“Windows Recovery Environment”（Windows 恢复环境）的选项。

这就是该过程的全部内容。您只需按照上述不同步骤进行操作，然后即可设置完整的 Kali Linux 发行版，使其准备就绪并可供使用。每次您准备重启计算机时，只要已设置好，您可以选择是使用 Kali 操作系统还是使用您的 Windows 系统。您可以根据需要轻松地在两者之间切换。

# 第 5 章：KALI LINUX 的使用

现在我们可以花些时间看看如何进行渗透测试。这基本上是一个深入的过程，我们可以使用它来找出代码中的一些漏洞。在检查黑客可能尝试入侵我们的位置并确定整体最佳处理方式时，这是最值得使用的工具。

我们需要理解此过程首先要了解的是渗透测试（infiltration testing）是什么。渗透测试是一门发现漏洞并深入挖掘的艺术，旨在弄清楚我们的系统能在多大程度上被攻陷。这是在合法攻击针对您的系统发生之前，提前做好准备并保护自身的一种方式。

渗透测试将涉及多个不同的步骤，以检查系统并确保其按我们想要的方式工作。例如，这种测试将涉及利用网络、服务器、计算机、防火墙等，以找出其中的漏洞，然后突出显示使用此系统会出现的一些实际风险。

在进行这种渗透测试时，我们可以采取很多步骤，我们必须确保以实际发现漏洞并确定下一步正确措施的方式设置好系统，以便在您的网络上保持安全。让我们更仔细地看看渗透测试包含的各个不同部分，以及您可以如何在使用 Kali Linux 系统在适当的时间执行这种测试程序。

## 渗透测试的阶段

渗透测试比许多程序员认为的要深入得多，并且会包含多个阶段以达到成功。您尝试完成的阶段数量将取决于您的具体情况以及每个部分需要发生的事情。让我们看看在关注渗透测试时，您可以处理的所有不同阶段。

第一阶段被称为协议阶段（agreement phase）。在此阶段，各方之间存在某种形式的相互协议。该协议将涵盖我们需要遵循的所有高层细节和方法，以及您将经历的利用级别。即使测试是在非高峰时段进行的，攻击者也不得关停生产服务器。

在进行此渗透测试时，您和客户需要讨论许多事项。您可能需要签署保密协议（non-disclosure agreement），以表明您仅将测试详情与您合作的公司分享，而不与他人分享，这通常还会告知我们还需要进行哪些其他操作。可能会有一些关于您可以访问什么、可以使用什么技术，甚至何时执行测试以免干扰企业需要关注的某些工作的规则。

如果这是您自己的计算机系统，那么这就不会是个大问题。
