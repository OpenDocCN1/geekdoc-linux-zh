随着时间推移，情况会发生变化，Linux 带来了新的下载包和更新。Kali Linux 的整体诞生源于一种认知：是时候将过去八年构建 Linux 安全发行版的经验应用到一张全新的画布上，并加以发挥了。原始的 Linux 形式是处理黑客活动及应对随之而来的各种复杂部分的绝佳方式。但随后，Kali Linux 帮助打磨了这一切，并投入时间来深入实践，从而取得了一些优异的成果。

这意味着，针对原始的 Linux 黑客操作，我们需要回顾并拆除此前构建的所有内容，并以全新的起点开始。这一过程对于参与此项目的开发人员来说既令人恐惧又令人解脱，因为他们必须放下某些整体发行版相关的包袱，而这并不容易。但另一方面，这也给了他们重新构建，甚至扩展当前系统以创造更好成果的机会。

一旦 Kali Linux 开发人员做出了这些艰难的决定，他们发现下一步需要处理的是引入一些真正懂行的人参与到该系统中。这正是他们引入了一位来自 Debian 的新开发人员，该人员帮助他们从零开始构建新的开发基础设施。这一协助对项目非常有益，确保了 Kali Linux 尽可能成功。
