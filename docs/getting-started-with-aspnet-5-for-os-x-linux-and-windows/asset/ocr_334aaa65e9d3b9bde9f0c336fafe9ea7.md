# 4.3 Testing

To test our ASP.NET 5, we use code samples from https://github.com/aspnet/Home . We clone this code samples and then restore all required libraries using dnu command.

Type these commands.

```
$ git clone https://github.com/aspnet/Home
$ cd Home
$ dnu restore
```
