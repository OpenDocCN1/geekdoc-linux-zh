# # 5.3 Building ASP.NET 5 MVC Application

The second demo is to build ASP.NET 5 MVC application. We develop a simple entry form and utilize ASP.NET MVC session. The following is our scenario:

+   - User fills a form to create a new project
+   - User clicks Save button to save the data
+   - The data will be stored to a session stack
+   - Then, the data will be shown in another page

Let’s start to develop.

# ## 5.3.1 Creating a Project

Firstly, we create a project by creating a folder, called WebDemo. Then, you create the following folder:

+   - Controllers
+   - Models
+   - Properties
+   - Views
