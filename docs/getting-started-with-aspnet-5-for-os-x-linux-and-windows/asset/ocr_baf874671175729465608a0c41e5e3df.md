To run ASP.NET Console, we can use dnx. Firstly, navigate to ConsoleApp project. Type these commands.

```
$ cd samples/latest/ConsoleApp/
$ dnx . run .
```

If success, you can see a message “Hello World” on Terminal.

# ## 4.3.2 ASP.NET 5

To run ASP.NET 5 app, we can use dnx with kestrel. Firstly, navigate to HelloWeb project. Type these commands.

```
$ cd samples/latest/HelloWeb/
$ dnx . kestrel
```
