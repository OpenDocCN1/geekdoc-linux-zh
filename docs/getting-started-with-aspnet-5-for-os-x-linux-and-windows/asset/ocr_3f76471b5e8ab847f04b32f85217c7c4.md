# ### 2.2 Deploying ASP.NET 5

To install ASP.NET on OS X, you can use brew, [http://brew.sh/](http://brew.sh/). Type these commands to install ASP.NET 5.

```
$ brew tap aspnet/dnx
$ brew update
$ brew install dnvm
```
