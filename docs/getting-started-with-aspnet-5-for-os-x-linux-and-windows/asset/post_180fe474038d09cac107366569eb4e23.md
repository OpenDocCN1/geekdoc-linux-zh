# 6.3.5 AngularJS Program

Firstly, download AngularJS on http://code.angularjs.org/. Put those files into /js/lib folder.

![AngularJS Files](img/2b788c7cc1c2fc37b428b6e7f92dcaed_74_1.png)

The next step is to write AngularJS program. Create a file, called **product.service.js**, and write this script.

```javascript
var myApp = angular.module('ProductService', []);

myApp.service('DataService', function ($http) {
    
    this.read = function (callback) {
        $http({
            method: 'POST',
            url: 'Home/GetAllProducts/',
            headers: {
                'Content-type': 'application/json'
            }
        }).success(function (resp) {
            callback(resp);
        }).error(function () {
            callback(undefined);
        });
    };

});

myApp.controller('MyController', function ($scope, DataService) {
    $scope.products = [];
    $scope.selected = {};

    $scope.getAllData = function () {
        DataService.read(function (data) {
            $scope.products = data;
        });
    };
    $scope.select = function (selected) {
        $scope.selected = selected;
    };
});
```
