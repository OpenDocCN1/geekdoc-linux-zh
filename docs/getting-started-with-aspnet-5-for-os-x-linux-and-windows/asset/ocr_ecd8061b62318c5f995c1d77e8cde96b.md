# 5.2 Building ASP.NET 5 Console Application

In this case, we build a simple program for ASP.NET 5 Console. We implement Math operation using Math class.

# 5.2.1 Creating A Project

To create a project, we can create a folder, called ConsoleDemo. In Linux/OS X, you can type this command on Terminal.

```
```bash
mkdir ConsoleDemo
```
```

Furthermore, we create a file, **project.json**. Type this script.

```
```json
{
"dependencies" : {
},
"commands" : {
"ConsoleApp" : "ConsoleDemo"
},
"frameworks" : {
"dnx451" : { },
"dnxcore50" : {
"dependencies" : {
"System.Console" : "4.0.0-beta- *"
}
}
}
}
```
```

This file is a project configuration which uses ASP.NET 5 DNX.
