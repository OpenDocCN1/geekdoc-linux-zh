## 序言

对于学生、有抱负的 IT 专家以及职场人士来说，“系统管理员 Linux 基础”是学习 Linux 基础的绝佳起点，包括命令行以及管理企业系统所需的所有工具和命令。起初，你将接触 Linux 环境，重点是浏览文件系统、使用基本命令、管理文件和目录以及熟悉 shell。你还将学习软件包管理以及如何高效地处理系统启动和关机。之后，你将学习有关系统配置文件、用于管理系统服务的 `systemd`、用于作业调度的 `crontab`，以及用于自动化处理的 `at` 和 `batch`。你也将学习系统性能监控、日志文件、备份和恢复程序、磁盘分区以及通过 `SSH` 进行远程管理。随后，本书将深入探讨依赖管理、系统硬件配置、内核升级和设备驱动管理等，，使用 `apt` 和 `yum` 进行软件包管理。你还将学习如何创建和管理仓库，并使用 `VirtualBox` 安装和设置虚拟机。最后，本书涵盖了广泛的主题，包括创建和管理用户账户、编辑用户配置、设置文件所有权权限、使用 `ACLs`、管理用户会话、为管理任务配置 `sudo`、实施密码策略、处理 `PAM` 以及管理组成员关系。

在本书中，你将学习如何：
* 精通 Essential Linux 命令，高效地导航和管理系统文件结构。
* 精通用户和组管理，以确保安全的访问控制和权限。
* 学习使用 `systemd` 配置和管理系统服务，实现简化的服务管理。
* 实施并执行强效的密码策略，以增强安全性和用户账户保护。
* 理解并利用软件包管理工具实现无缝软件安装。
* 使用 `VirtualBox` 设置和管理虚拟机，创建隔离、可重复的开发环境。
* 使用访问控制列表 (`ACLs`) 对标准 Unix 模型之外的文件权限进行精调。
* 使用 `cron`、`at` 和 `batch` 调度和自动化任务，提高系统效率和可靠性。
* 监控系统性能和日志，主动识别并解决潜在问题。
* 安全地配置和使用 `SSH` 进行 Linux 系统的远程管理和管理。

读完本书后，你将掌握 Linux 系统管理的基础知识。此外，还有一本名为“系统管理员 Linux 高级”的配套书籍，适合任何想学习更高级 Linux 技术的人，作者同为‘Ryan Juan’。高级数据库管理、安全配置、网络管理、系统监控以及包括部署、负载均衡和与 `Kubernetes` 工作在内的高级操作是这本后续书籍的重点。本书结合起来，为向往和实业的 Linux 系统管理员提供了坚实的基础和高级专业知识。

### 导航文件系统
导航文件系统是高效系统交互和管理的一项基本能力。以斜杠 (/) 表示的根目录开始，Linux 文件系统是层次结构的。从这个根目录出的文件和目录创建了一个类似于树的结构。为了充分利用这个文件系统，让我们进入细节并执行一些命令。

层次结构的顶端是根目录 (/)，包含了几个重要的子目录。一些关键目录包括：
* 包含基本二进制执行文件，如基础命令
* 存储系统配置文件。
* 包含每个用户的个人目录。
* 保存日志和打印文件等变量数据。
* 存放用户安装的软件和库。
* 系统和用户创建的临时文件。

理解这些目录有助于你定位文件并执行管理任务。

在导航文件系统时，某些特殊字符和符号很有用。点 (.) 表示当前目录，而双点 (..) 表示父级目录。例如，如果你在 `/home/user/documents` 并执行 `cd`，你将移动到

打印当前工作目录，使用 `pwd` (print working directory) 命令。此命令显示你在文件系统中的当前位置。例如：

```bash
$ pwd
/home/user/documents
```

切换目录使用 `cd` (change directory) 命令。如果你想移动到不同的目录，可以指定该目录的路径。例如：

```bash
$ cd /etc
```

此命令将你移动到 /etc 目录。如果你想从文件的任何地方返回家目录，只需使用不带参数的 `cd`：

```bash
$ cd
```

或使用波浪号 (~) 作为你家目录的快捷：

```bash
$ cd ~
```

列出目录内容使用 `ls` 命令。添加 -l 将提供详细列表，包括权限、链接数、所有者、组、大小和修改时间：

```bash
$ ls -l
total 12
drwxr-xr-x 2 user user 4096 Jan 1 12:00 documents
-rw-r--r-- 1 user group 88 Jan 1 12:00 file.txt
```

要查看以点 (.) 开头的隐藏文件，使用 -a 选项：

```bash
$ ls -a
.bashrc
..
```

. 和 .. 分别代表当前目录和父级目录。

创建和管理目录使用 `mkdir` (make directory) 和 `rmdir` (remove directory) 命令是直接的。创建一个新目录：

```bash
$ mkdir new_directory
```

删除空目录：

```bash
$ rmdir new_directory
```

如果目录不是空的，你需要使用 `rm` 配合 -r (recursive) 选项来删除其所有内容：

```bash
$ rm -r new_directory
```

在目录之间导航和管理文件可以使用相对路径和绝对路径。相对路径相对于当前目录，而绝对路径从根目录指定。例如，你可以使用相对路径：

```bash
$ cd documents
```

或者绝对路径：

```bash
$ cd /home/user
```

### 基础 Linux 命令
精通一套核心 Linux 命令对于 Linux 系统管理员高效地管理系统和排除故障至关重要。这些命令是每个系统管理员都应该知道的。示例这些用于系统监控、进程管理和网络实用程序。我们将把这些命令结合起来。

#### 网络配置和排除故障
`ip` 和 `ifconfig`
`ip` 命令可以替代旧的 `ifconfig`，提供更多功能和灵活性。查看网络接口、路由表等。要查看网络接口及其 IP 地址，使用：

```bash
$ ip addr
```

启用或禁用接口，使用：

```bash
$ sudo ip link set eth0 up
$ sudo ip link set eth0 down
```

`ifconfig` 命令虽然旧但仍在广泛使用。显示网络接口，使用：

```bash
$ ifconfig
```

在接口上配置 IP 地址，使用：

```bash
$ sudo ifconfig eth0 192.168.1.100 netmask 255.255.255.0
```

`mtr` (My Traceroute) 命令结合了 `ping` 的功能并提供实时网络诊断。它有助于识别数据包丢失和延迟发生的地方。只需使用：

```bash
$ mtr google.com
```

#### 文件和文本处理
`find`
`find` 命令根据各种标准搜索文件和目录。当你不确定某物的所在地时，它特别有用。例如，从根目录查找名为 `file.txt` 的文件：

```bash
$ sudo find / -name file.txt
```

查找过去 7 天内修改的文件：

```bash
$ find /home/user -mtime -7
```

`awk`
`awk` 命令是一个强大的文本处理工具，通常用于数据提取和报告。按行读取输入，将每行分成字段，并根据模式处理。例如，打印每行的第二个字段：

```bash
$ awk -F, '{print $2}' file.txt
```

如果你有一个 CSV 文件并想打印第一和第三列：

```bash
$ awk -F, '{print $1, $3}' file.csv
```

#### 网络监控和诊断
`tcpdump`
`tcpdump` 命令捕获网络包并实时显示，适用于网络故障排除和安全分析。在 eth0 接口上捕获数据包，使用：

```bash
$ sudo tcpdump -i eth0
```

捕获包并保存到文件供以后使用：

```bash
$ sudo tcpdump -i eth0 -w capture.pcap
```

读取保存的捕获文件，使用：

```bash
$ sudo tcpdump -r capture.pcap
```

`netstat`
`netstat` 命令显示网络连接、路由表、接口统计等。列出所有连接和监听端口，使用：

```bash
$ netstat -tuln
```

显示网络统计数据，例如发送和接收的数据包：

```bash
$ netstat -s
```

#### 系统和进程管理
`sudo`
`sudo` 命令允许许可用户以安全策略指定的超级用户或其他用户的身份执行命令。配置 sudo 对于执行管理任务至关重要。以超级权限编辑系统文件：

```bash
$ sudo nano /etc/hosts
```

以另一个用户的身份执行命令，指定 -u 选项：

```bash
$ sudo -u username command
```

`tmux`
`tmux` 命令是一个终端复用器，允许你在单个窗口内运行多个会话。它对于在不打开多个终端窗口的情况下管理多个任务很有用。启动新会话：

```bash
$ tmux
```

在保持会话运行的同时从会话中分离，使用 Ctrl+b 然后按 attach 附加到会话：

```bash
$ tmux attach
```

`lsns`
`lsns` 命令列出系统命名空间的信息，用于 Linux 容器和虚拟环境中的隔离。显示所有命名空间：

```bash
$ lsns
```

此命令显示每个命名空间的 PID、类型和其他详细信息，适用于管理和排除容器化应用程序的故障。

`pkill`
`pkill` 命令根据名称或其他属性向特定用户的所有进程发送信号。它通常用于终止进程。杀死名为 example 的进程：

```bash
$ pkill example
```

发送特定信号，例如 SIGKILL (kill 信号)：

```bash
$ pkill -9 example
```
