With the Samba server up and running, you can verify whether all your shares are available using the smbclient utility. You should see a list of the defined shares similar to the following:

```
Athena:/home/admin # /usr/bin/smbclient -NL localhost
Anonymous login successful
Domain=[TUX-NET] OS=[Unix] Server=[Samba 3.0.4-SUSE]

    Sharename       Type       Comment
    ---------       ----       -------
    junk            Disk
    docs            Disk       On-line documentation
    IPC$            IPC        IPC Service (Samba 3.0.4-SUSE)
    ADMIN$          IPC        IPC Service (Samba 3.0.4-SUSE)
Anonymous login successful
Domain=[TUX-NET] OS=[Unix] Server=[Samba 3.0.4-SUSE]

    Server             Comment
    ------             -------
    MYSAMBASERVER      Samba 3.0.4-SUSE
```
