# SUSE. LINUX. Enterprise Server 9
Administrator's Handbook

Get More Done with SUSE LINUX Enterprise Server 9

Novell's SUSE LINUX Enterprise Server offers a wide range of network services and allows organizations of all sizes to leverage Linux and open-source technologies by delivering a scalable, reliable, high-performance foundation for secure enterprise computing.

This official Novell Press book is the definitive guide to administering, configuring, and securing a SUSE LINUX Enterprise Server and network. Written for all system administrators, consultants, and others who implement and support SUSE LINUX Enterprise Servers, the book is especially useful for experienced NetWare administrators who need to explore SUSE LINUX as an alternative platform or who want to implement SUSE LINUX side by side with NetWare systems.

Topics covered in this book range from the fundamentals of managing users and groups to setting up and configuring essential network services to securing a server against possible hackers.

Whether you need to set up a SUSE LINUX system quickly for a small department or whether you need to lock down the server against unwanted users, SUSE LINUX Enterprise Server 9 Administrator's Handbook is your complete, definitive solution.
