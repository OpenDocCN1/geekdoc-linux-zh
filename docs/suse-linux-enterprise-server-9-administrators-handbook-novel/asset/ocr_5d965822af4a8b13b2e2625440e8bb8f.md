**TABLE 6.3**

**User Group Codes**

| CODE | DESCRIPTION |
|---|---|
| u | User permission triplet |
| g | Group permission triplet |
| o | Others, or world, permission triplet |
| a | A shortcut for all three triplets |

The chmod utility is used to change the access mode of a file or a directory. You can use it with numeric code or alpha code values—whatever works best for you. The general command syntax is

```
chmod access_mode_options target_file_or_directory
```

# NOTE

Within the Linux/Unix world, the term “chmod” has become an almost acceptable English verb, meaning the changing of the access mode.
