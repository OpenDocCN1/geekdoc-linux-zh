# SYS5 PASSWORDS: ENCRYPTED OR HASHED?

Encryption is a method of using a mathematical algorithm and a key to scramble data into gibberish. If you know the key and the algorithm used, you can decrypt the gibberish to arrive back at the original information. S/USE (and indeed all Linux and Unix distributions) converts the (cleartext) password into a scrambled text string through a mathematical algorithm called a cryptographic hash. The resulting string, in a form that is very different from the original string, is called a hash or hash value. The way these hash algorithms work is that one cannot recover the original password from the hash value. Because Linux/Unix passwords cannot be converted back into their original text, the term encrypted Linux/Unix passwords is a misnomer. The more correct term is hashed passwords, and this term is used throughout this book.
