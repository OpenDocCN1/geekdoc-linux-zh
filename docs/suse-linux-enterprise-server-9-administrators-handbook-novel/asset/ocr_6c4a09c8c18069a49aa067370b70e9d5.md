Among the basic tools, a text editor is probably the most important one that a Linux/Unix system administrator uses. Therefore, we start this appendix with a brief review of Linux text editors included with SLES 9 and a short primer about vi. In addition, this appendix provides a list of websites and Internet newsgroups where you can locate additional information about SUSE LINUX and Linux-related security issues.
