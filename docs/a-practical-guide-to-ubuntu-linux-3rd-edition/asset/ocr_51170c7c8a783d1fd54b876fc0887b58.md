# Always test the arguments

> **tip** To keep the examples in this book short and focused on specific concepts, the code to verify arguments is often omitted or abbreviated. It is good practice to test arguments in shell programs that other people will use. Doing so results in scripts that are easier to run and debug.

> [!] is a synonym for test

The following example—another version of chkgargs—checks for arguments in a way that is more traditional for Linux shell scripts. This example uses the bracket ([!]) synonym for test. Rather than using the word test in scripts, you can surround the arguments to test with brackets. The brackets must be surrounded by whitespace (SPACES or TABS).
