Use rpcinfo to make sure the NIS server is up and running (replace plun with the name of the server that ypwhich returned):

```
$ rpcinfo -u plun ypserver
program 100004 version 1 ready and waiting
program 100004 version 2 ready and waiting
```

After starting ypbind, check that it is registered with portmap:

```
$ rpcinfo -u localhost ypbind
program 100007 version 1 ready and waiting
program 100007 version 2 ready and waiting
```

If rpcinfo does not report that ypbind is ready and waiting, check that ypbind is running:

```
$ ps -ef | grep ypbind
root      23144     1  0 18:10 ?          00:00:00 /usr/sbin/ypbind
sam       23670  5553  0 18:31 pts/2      00:00:00 grep ypbind
```
