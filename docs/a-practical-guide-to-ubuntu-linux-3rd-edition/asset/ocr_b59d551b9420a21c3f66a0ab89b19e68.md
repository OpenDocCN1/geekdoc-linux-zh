multiple, sequential, identical lines, you can pipe its output through \textbf{uniq} (page 168) to make the job of finding the right package easier:

```
$ sudo aptitude install apt-file
……
$ sudo apt-file update
……
$ apt-file search X11/Xlib.h | uniq
ivtools-dev: usr/include/IV-X11/Xlib.h
libghe-c-11-dev: usr/lib/X11-1.2.1/ghc-6.6.1/Graphics/X11/Xlib.hi
libbugs-x11-bundled: usr/lib/hugs/packages/X11/Graphics/X11/Xlib.hs
libx11-dev: usr/include/X11/Xlib.h
tendra: usr/lib/TenDRA/lib/Xlib/api/X11/Xlib.h
```

Again, the most generic package (the next-to-last one listed) is probably the one you want. While \textbf{cache} (page 530) searches installed packages only, the \textbf{aptitude search command} (page 529) and \textbf{apt-file search} all packages from the repositories listed in /etc/apt/sources.list, including packages that have not been downloaded. See also \textbf{dpkg—search} (page 538) and \textbf{dpkg—listfiles} (page 538) for other ways of searching for files.

# APT: KEEPS THE SYSTEM UP-TO-DATE

APT (Advanced Package Tool) is a collection of utilities that download, install, remove, upgrade, and report on software packages. APT utilities download packages and call \textbf{dpkg} (page 532) utilities to manipulate the packages once they are on the local system. For more information refer to www.debian.org/doc/manuals/apt-howto.

# REPOSITORIES

\textit{Repositories} hold collections of software packages and related information, including headers that describe each package and provide information on other packages the package depends on. Ubuntu maintains repositories for each of its releases.

Software package categories Software packages from Ubuntu repositories are divided into several categories, including the following:

+   • \textbf{main}—Ubuntu-supported open-source software
+   • \textbf{universe}—Community-maintained open-source software
+   • \textbf{multiverse}—Software restricted by copyright or legal issues
+   • \textbf{restricted}—Proprietary device drivers
+   • \textbf{partner}—Packages that are not part of Ubuntu; offered by other vendors
+   • \textbf{backports}—Packages from later releases of Ubuntu that are not available for an earlier release
