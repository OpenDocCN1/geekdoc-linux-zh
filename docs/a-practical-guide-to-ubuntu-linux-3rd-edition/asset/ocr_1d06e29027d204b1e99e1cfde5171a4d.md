# ## JOBS

Each file in the */etc/init* directory defines a job and usually contains at least an event and a command. When the event is triggered, **init** executes the command. This section describes examples of both administrator-defined jobs and jobs installed with the **upstart** package.

# ### ADMINISTRATOR-DEFINED JOBS

The following administrator-defined job uses the `exec` keyword to execute a shell command. You can also use this keyword to execute a shell script stored in a file or a binary executable file.

> In the first stanza (**start on runlevel 2**), **start on** is a keyword (you can use **stop on** in its place), **runlevel** is an event (page 433), and **2** is an argument to **runlevel**.

```
$ cat /etc/init/mudat.conf
   start on runlevel 2
   task
   exec echo "Entering multiuser mode on " $(date) > /tmp/mudat.out
```

This file defines a task: It runs the `echo` shell command when the system enters multiuser mode (runlevel 2). This command writes a message that includes the time and date to */tmp/mudat.out*. The shell uses command substitution (page 362) to execute the date utility. After this job runs to completion, the **mudat** task stops and enters a wait state.
