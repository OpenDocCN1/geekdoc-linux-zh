The next example uses the ldapmodify modify instruction to replace the mail attribute value and add a title attribute for the employee named Helen Simpson. Because the file specifies Helen's DN, the server knows which entry to modify.

```
$ cat sa4.ldif
dn: cn=Helen Simpson,ou=employees,dc=sobel1,dc=com
changetype: modify
replace: mail
mail: hls@sobel1.com

add: title
title: CTO
$ ldapmodify -xD "cn=admin,dc=sobel1,dc=com" -W -f sa4.ldif
Enter LDAP Password:
modifying entry "cn=Helen Simpson,ou=employees,dc=sobel1,dc=com"
```

You can use slapcat to verify the change. The final example deletes Helen from the LDAP directory:

```
$ cat sa5.ldif
dn: cn=Helen Simpson,ou=employees,dc=sobel1,dc=com
changetype: delete
$ ldapmodify -xD "cn=admin,dc=sobel1,dc=com" -W -f sa5.ldif
Enter LDAP Password:
deleting entry "cn=Helen Simpson,ou=employees,dc=sobel1,dc=com"
```
