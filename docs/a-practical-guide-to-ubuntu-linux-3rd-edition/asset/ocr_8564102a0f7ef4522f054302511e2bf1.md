# You may find pinfo easier to use than info

The pinfo utility is similar to info but is more intuitive if you are not familiar with the emacs editor. This utility runs in a textual environment, as does info. When it is available, pinfo uses color to make its interface easier to use. If pinfo is not installed on the system, use synaptic (page 133) to install the pinfo package. Run pinfo from a terminal emulator or Run Application window (<kbd>ALT</kbd>-<kbd>F2</kbd>) and select <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">Run in terminal</font>.

Now type <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">/</font><kbd>RETURn</kbd> (or <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">/sleeer<kbd>RETUrn</kbd></font>) to search for the next occurrence of <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font> as shown in Figure 4-31. The asterisk at the left end of the line indicates that this entry is a menu item. Following the asterisk is the name of the menu item and a description of the item.

Each menu item is a link to the info page that describes the item. To jump to that page, search for or use the <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">↓</font> <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">↑</font> keys to move the cursor to the line containing the menu item and press <kbd>RETURn</kbd>. With the cursor positioned as it is in Figure 4-31, press <kbd>RETURn</kbd> to display information on <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font>. Alternatively, you can type the name of the menu item in a menu command to view the information: To display information on <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font>, for example, you can give the command <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">m</font> <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font>, followed by <kbd>RETURn</kbd>. When you type <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">m</font> (for menu), the cursor moves to the bottom line of the window (as it did when you typed <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">/</font>) and displays <i>Menu item:</i>: Typing <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleeper</font> displays <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font> on that line, and pressing <kbd>RETURn</kbd> displays information about the menu item you have chosen.

Figure 4-32 (on the next page) shows the <i>top node</i> of information on <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">sleep</font>. A node groups a set of information you can scroll through by pressing the <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;"> </font> bar. To display the next node, press <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">n</font>. Press <font style="font-family: monospace; background-color: #f5f5f5; padding: 0 2px; border-radius: 3px; border: 1px solid #ddd;">p</font> to display the previous node.
