In the preceding example, Zach's home directory, /home/zach, is on the remote system dog. Using NFS, the /home/zach directory hierarchy on dog is mounted on plum; to make it easy to recognize, it is mounted as /dog.home/zach. The /gc1 and /gc5 filesystems on grape are mounted on plum as /grape.gc1 and /grape.gc5, respectively.
