each router along the way and an acknowledgment to get back. You can put this information to good use when you are trying to identify the location of a network bottleneck. The `traceroute` utility has no concept of the path from one host to the next; instead, it simply sends out packets with increasing `TTL` (time to live) values. `TTL` is an IP header field that indicates how many more hops the packet should be allowed to make before being discarded or returned. In the case of a `traceroute` packet, the packet is returned by the host that has the packet when the `TTL` value is zero. The result is a list of hosts that the packet traveled through to get to its destination.

The `traceroute` utility can help you solve routing configuration problems and locate routing path failures. When you cannot reach a host, use `traceroute` to discover what path the packet follows, how far it gets, and what the delay is.
