**db.local** The **db.local** zone file defines the **localhost** zone, the normal server on the local sys-
tem. It starts with a **$TTL** directive and holds four resource records: **SOA**, **NS**, **A**, 
and **AAAA**. The **$TTL** directive in the following file specifies that the default time 
to live for the resource records specified in this file is 604,800 seconds (one week):

```
$ cat /etc/bind/db.local 
; 
; BIND data file for local loopback interface 
;
$TTL 604800 
@ IN SOA localhost. root.localhost. (
2 ; Serial 
604800 ; Refresh 
86400 ; Retry 
2419200 ; Expire 
604800 ) ; Negative Cache TTL 
;
@ IN NS localhost. 
@ IN A 127.0.0.1 
@ IN AAAA ::1
```
