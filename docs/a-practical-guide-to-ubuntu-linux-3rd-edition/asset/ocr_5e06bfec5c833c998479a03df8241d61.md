The fc builtin can take zero, one, or two arguments with the -l option. The arguments specify the part of the history list to be displayed:

```
```
fc -l [first [last]]
```
```

The fc builtin lists commands beginning with the most recent event that matches first. The argument can be an event number, the first few characters of the command line, or a negative number, which is taken to be the nth previous command. Without last, fc displays events through the most recent. If you include last, fc displays commands from the most recent event that matches first through the most recent event that matches last.

The next command displays the history list from event 1030 through event 1035:

```
```
$ fc -l  1030  1035
1030    cd ../memos
1031    ls
1032    rm *@405
1033    fc -l
1034    cd
1035    whereis aspell
```
```
