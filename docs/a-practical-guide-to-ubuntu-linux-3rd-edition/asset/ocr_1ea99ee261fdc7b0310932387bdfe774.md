use feature 'say' The say function is a Perl 6 feature that is available in Perl 5.10. It works the same way as print, except it adds a NEWLINE (\n) at the end of each line it outputs. Some versions of Perl require you to tell Perl explicitly that you want to use say. The use function in the following example tells Perl to enable say. Try running this program without the use line to see if the local version of Perl requires it.

```
```perl
$ cat 5.10.pl
use feature 'say';
say 'Output by say.';
print 'Output by print.';
say 'End.'

$ perl 5.10.pl
Output by say.
Output by print.End.
$```
```

Earlier versions of Perl If you are running an earlier version of Perl, you will need to replace say in the examples in this chapter with print and terminate the print statement with a quoted \n:

```
```perl
$ cat 5.8.pl
print 'Output by print in place of say.', "\n";
print 'Output by print.';
print 'End.', "\n";

$ perl 5.8.pl
Output by print in place of say.
Output by print.End.
```
