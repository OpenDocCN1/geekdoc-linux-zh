# Storage of man pages

man: read man pages
man title formats a specific manual page and sends it to your terminal through more, less, or whatever program is specified in your PAGER environment variable. title is usually a command, device, filename, or name of a library routine. The sections of the manual are searched in roughly numeric order, although sections that describe commands (sections 1, 8, and 6) are usually searched first.

The form section title gets you a man page from a particular section. Then, on most systems, man sync gets you the man page for the sync command, and man d sync gets you the man page for the sync system call.

+   - Under Solaris, you must preface the section number with the -s flag, for example,
man - s 2 sync.

+   - man k word or apropos keyword prints a list of man pages that have keyword in their one-line synopses. For example:

```
$ man -k translate
objcopy (1) - copy and translate object files
dcgettext (3) - translate message
tr (1) - translate or delete characters
snmptranslate (1) - translate SNMP OID values into more useful information
tr (1p) - translate characters
```

The keywords database can be out of date. If you add additional man pages to your system, you may need to rebuild this page with mandb (Ubuntu, SUSE), makeswhat (Red Hat), or catman -w (Solaris, HP-UX, AIX).

# Storage of man pages

nroff input for man pages is usually kept in directories under /usr/share/man. Linux systems compress them with gzip to save space. The man command knows how to uncompress them on the fly. The man command maintains a cache of formatted pages in var/cache/man or /usr/share/man if the appropriate directories are writable, this is a security risk. Most systems preformat man pages at installation time (see catman) or not at all.

Solaris understands man pages formatted with SGML in addition to the traditional nroff. The SGML pages have their own sections underneath /usr/share/man.

The man command can search several man page repositories to find the man pages you request. On Linux systems, you can find the current default search path with the manpath command. This path (from Ubuntu) is:

```
ubuntu$ manpath
/usr/local/man:/usr/local/share/man:/usr/share/man
```
