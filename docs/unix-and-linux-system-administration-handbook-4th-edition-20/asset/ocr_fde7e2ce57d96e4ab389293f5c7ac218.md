# logrotate: manage log files

```
# Logfile rotation definitions and options
/var/log/messages {
    postrotate
    /bin/kill -HUP `/var/run/syslogd.pid`
    endscript
}
/var/log/samba/*.log {
    notifempty
    copydruncate
    sharedscripts
    postrotate
    /bin/kill -HUP `/var/lock/samba*.pid`
    endscript
}
```

This configuration rotates /var/log/messages every week. It keeps free versions of the file and notifies syslog each time the file is reset. Samba log files (of there may be several) are also rotated weekly, but instead of being moved aside and restarted, they are copied and truncated. The Samba daemons are sent HUP signals only after log files have been rotated.

Table 11.7 lists the most useful logrotate.conf options.

| Option | Meaning |
| --- | --- |
| compress | Compresses all nonresident versions of the log file |
| daily, weekly, monthly | Rotates log files on the specified schedule |
| delaycompress | Compresses all versions but current and next-most-recent |
| endscript | Marks the end of a prerorate or postrotate script |
| errors emailaddr | Errors notification to the specified emailaddr |
| missing | Doesn't comply if the log file does not exist |
| notifempty | Does not rotate the log file if it is empty |
| olddir | Specifies that older versions of the log file are placed in dir |
| postrotate | Introduces a script to run after the log has been rotated |
| prerorate | Introduces a script to run before any changes are made |
| rotate n | Includes n versions of the log rotation schedule |
| sharedscripts | Runs scripts only once for the entire log group |
| size | Rotates if log size > size (e.g., 100K, 4M) |

# logrotate options

logrotate is normally run out cron every day. The standard configuration file is /etc/logrotate.conf, but multiple configuration files (or directories configuration files) can appear on logrotate command line. This feature is used to great effect by Linux distributions, which define the /etc/logrotate.d directory as a standard place for logrotate config files. Logrotate- software packages (of which there are many) can drop in log management instructions as part of their installation procedure, greatly simplifying administration.
