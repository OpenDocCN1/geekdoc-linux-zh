# Chapter 21 Network Management and Debugging

Most routers send their ICMP messages from the interface "closest" to the destination. If you use traceroute backward from the destination host, you may see different IP addresses used to identify the state of routers. You may also discover that packets flowing in the reverse direction take a completely different path, a configuration known as asymmetric routing.

Since traceroute sends three packets for each value of the TTL field, you may sometimes observe an interesting artifact. If an intervening gateway multiplexes across several nodes, the packets might be delivered by different hosts; in this case, traceroute simply prints them all.

Let's look at a more interesting example from a host in Switzerland to caida.org at the San Diego Supercomputer Center:

This output shows that packets travel inside Ice Seventh's journey for a name. Sometimes we get the location of the gateways from their names. Ice Seventh's core stretches all the way from Zurich (zur) to Frankfurt (fra), Amsterdam (ams), London (lon), and finally, Los Angeles (lax). Here, the traffic delivers the packets to the caida.org host within the network of the San Diego Supercomputer Center (sdsc) in La Jolla, CA.

At hop 8, we see a star in place of one of the round trips. This notation that no response (error packet) was received in response to the probe. In this case, the cause is probably congestion, but that is not the only possibility. traceroute relies on reliability ICMP packets, which may any routers are smart enough to drop in preference to "real" traffic. A few seconds send you into a panic.

If you see in all the time that no "timeout exceeded" messages arriving from that machine. Perhaps a gateway or firewall is configured to discard packets with early TTLs. In this case, you can see through the silent host to the gateways beyond. Another possibility is that the gateway's errors are slow to return and that traceroute has stopped waiting for the time to make them.

+   We removed a few milliseconds from the longer lines to keep them from forming.
