NfSen is a web front end for NetFlow that sits on top of nfdump and there-
ore combines graphing capabilities with all the features of nfdump. It displays the
three different categories: flows, packets, and bytes. NfSen does more than
create static graphs, though—lets you navigate through the individual flows. You can also
esting peaks in the graphs, and drill down to the individual flows.
apply arbitrary nfdump filters to refine the display. The combination of GUI
browing with the underlying power of nfdump

NfSen lets you save your filter and display settings to create a profile so that you
en easily return to a specific type of analysis in the future. For example, you
mefine profiles that monitor traffic for your DMZ, web reader or
client's network.
