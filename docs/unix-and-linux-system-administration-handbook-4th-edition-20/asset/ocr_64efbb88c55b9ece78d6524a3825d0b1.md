# AIX startup

```
ubuntu$ sudo update-rc.cups start 80 2 3 4 5 . stop 20 S 1 6 .
Adding system startup for /etc/init.d/cups ...
/rc1.d/K20cups -> ../init.d/cups
/rc6.d/K20cups -> ../init.d/cups
/rc5.d/K20cups -> ../init.d/cups
/rc2.d/S80cups -> ../init.d/cups
/rc3.d/S80cups -> ../init.d/cups
/rc4.d/S80cups -> ../init.d/cups
/rc5.d/S80cups -> ../init.d/cups
```

This command adds "start" instances at sequence 80 in run levels 2, 3, 4, and 5, and "stop" at sequence 20 in run levels S, 1, and 6.

The default run level is controlled by two telnet lines in /etc/event.d/rc-default.
Change the run level by editing rc-default with a text editor.

Upstart also controls logins on terminals that you hold tty".

# HP-UX startup scripts

Under HPX, the actual startup scripts are kept in /sbin/init.d. The run-level directories are also in /sbin. Config files related to startup scripts generally live in /etc/rc.config.d. Their names correspond to the names of the startup scripts in /sbin/init.d. For example, the script

+   - /sbin/init.d/SnmpMaster

gets its configuration information from
/etc/rc.config.d/SnmpMaster

and is actually invoked by init by jobs of the links

+   - /rc2.d/S560SnmpMaster
-/rc1.d/K440SnmpMaster

HP-UX saves the output of startup scripts in /etc/rc.log. If one of your startup scripts fails, check /etc/rc.log to see it as to the problem. Saving startup script output is the most useful and excellent feature, and it's simple to implement, too. It is surprising that other vendors haven't caught on it.

The config files in /etc/rc.config.d can be rather confusing, although they are well commented. Table 3.6 on the next page gives an explanation of some of the more commonly modified files.

The default values in these files are usually OK. The most common files you might need to touch are netconf, netdaemons, and perhaps nddcconf.

# AIX startup

AIX takes a cruder approach to the boot process than our other example systems. During startup, AIX runs the /sbin/rc.boot script, which is written in ksh.
