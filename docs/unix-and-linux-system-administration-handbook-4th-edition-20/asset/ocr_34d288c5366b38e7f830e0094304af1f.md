run cfgmgr -l iscsio. The cfgmgr command prints no confirmation messages, but we can see that the new device has appeared by looking in /dev directory (on our example system, the new disk is /dev/hdisk2) or by running smitty devices, navigating to the Fixed Disk category, and listing the entries. The latter option is perhaps safer using smitty shows that hdisk2 is an iSCSI volume.

To disconnect an iSCSI device, you must not only edit the configuration file and reload the configuration with cfgmgr but you must also delete the disk from smitty’s Fixed Disk list.

+   a) A server that will host the home directories of about 200 users
b) A swap area for a site6 primary DNS server
