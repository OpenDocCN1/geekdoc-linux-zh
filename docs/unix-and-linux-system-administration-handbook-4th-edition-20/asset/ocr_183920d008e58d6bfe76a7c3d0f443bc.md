You should do a complete set of level 0 dumps immediately after an upgrade, too. Most vendors' upgrade procedures set the modification dates of system files to the time when they were mastered rather than to the current time. Ergo, incremental dumps made to the pre-upgrade level 0 are not sufficient to restore your system to its post-upgrade state in the event of a crash.

# 10.6 USING OTHER ARCHIVING PROGRAMS

dump is not the only program you can use to archive files to tapes; however, it is the most efficient way to back up an entire system. tar and dd can also move files from one medium to another.

# tar: package files

tar reads multiple files or directories and packages them into one file, often a tape device. tar is a useful way to back up any files whose near-term recovery you anticipate. For instance, if you have a bunch of old files and the system is short of disk space, you can use tar to put the files on a tape and remove them from the disk.

tar is also useful for moving directory trees from place to place, especially if you are copying files as tar. tar preserves ownership and time information, but if you ask it to. For example,

```
sudo tar -cf - fromdir | cd codir ; sudo tar -xpf -
```

creates a copy of the directory fromdir in codir. Avoid using .. in the codir argument since symbolic links and automounters can make it mean something different from what you expect. We've been bitten several times.

Most versions of tar do not follow symbolic links by default

Another problem with non-GNU versions of tar is that parameters are limited by default to 100 characters. This restriction prevents tar from archiving deep hierarchies. If you're creating archives on your Linux systems and exchanging with them, remember that the people with the standard tar may not be able to read the tapes or files you create.¹12

tar -b option lets you specify a "blocking factor" to use when writing a tape. The blocking factor is specified in 512-byte blocks; it determines how much data tar buffers internally before performing a write operation.

> 12. The GNU implementation creates a filename mapping table as one of the files in the archive. Users of the standard tar can extract the contents of the archive and fix it up by hand, but the process is tedious.
