# An example /etc/apt/sources.list file

+   - A "distribution" (really, a release name) that lets you deliver multiple versions of packages. Distributors use this for major releases, but you can use it however for internal distribution systems.

+   - A potential list of components (categories of packages within a release)

Unless you want to set up your own repository or cache, the default configuration generally works fine. Source packages are downloaded from the entries beginning with deb-src.

On Ubuntu systems, you'll almost certainly want to include the "universe" component, which gives access to the larger world of Linux open source software. The "multiverse" packages include non-open source content, such as VMware tools and components.

As you are editing the sources.list file, you should retrieve the individual entries to point to your closest mirror. A full list of Ubuntu mirrors can be found at launchpad.net/ubuntu/+archmirrors. This is a dynamic (and long) list of mirrors that change regularly, so be sure to keep an eye on it releases.

Make sure security.ubuntu.com is listed as a source so that you have access to the latest security packages.

# An example /etc/apt/sources.list file

The following example uses us.archive.ubuntu.com as a package source for the "main" components of Ubuntu (those that are fully supported by the Ubuntu team). In addition, this sources.list includes unsupported open source "universe" packages, and non-free, unsupported packages in the "multiverse" component. There is also a repository for updates, or bug-fixed packages, in each component. Finally, the last six lines are for security updates.

```
# General format: uri distribution [components]
deb us.archive.ubuntu.com/ubuntu/ karmic main restricted
deb-src us.archive.ubuntu.com/ubuntu/ karmic main restricted
deb us.archive.ubuntu.com/ubuntu/ karmic-updates restricted
deb-src us.archive.ubuntu.com/ubuntu/ karmic-updates restricted
deb us.archive.ubuntu.com/ubuntu/ karmic universe
deb-src us.archive.ubuntu.com/ubuntu/ karmic universe
deb us.archive.ubuntu.com/ubuntu/ karmic-updates universe
deb-src us.archive.ubuntu.com/ubuntu/ karmic-updates universe
deb us.archive.ubuntu.com/ubuntu/ karmic multiverse
deb-src us.archive.ubuntu.com/ubuntu/ karmic multiverse
deb us.archive.ubuntu.com/ubuntu/ karmic-updates multiverse
deb-src us.archive.ubuntu.com/ubuntu/ karmic-updates multiverse
deb security.ubuntu.com/ubuntu/ karmic-security restricted
deb-src security.ubuntu.com/ubuntu/ karmic-security restricted
deb security.ubuntu.com/ubuntu/ karmic-security universe
deb-src security.ubuntu.com/ubuntu/ karmic-security universe
deb security.ubuntu.com/ubuntu/ karmic-security multiverse
deb-src security.ubuntu.com/ubuntu/ karmic-security multiverse
```
