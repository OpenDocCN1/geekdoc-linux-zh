# 12.4 INSTALLING AIX WITH THE NETWORK INSTALLATION MANAGER

NIM Installation Manager, or NIM, is AIX’s Kickstart, JumpStart, and Ignite-UX. Versions of NIM AIX 5.3 can also install Linux systems. NIM “master” installs clients from one or more installation images, where a client can be a stand-alone machine, a diskless or dataceless workstation, or a workload partition. Installations over TFTP, NFS, and DHCP or BOOTP, as much as other systems. NIM is included in the standard AIX installation media.

All NIM environments have at least one “resource server” that offers some set of software to be used by clients. The resource server may or not be the same system as the master. Environments that have complex network topologies or geographically separated locations should use localized resource servers to improve installation performance.

There are three ways to configure NIM:

+   * By using the web-based system manager
* By using the smit nim or smit etkin fast paths
* From the command line with the nim tool

We find SMIT to be the fastest and most convenient interface for configuring a NIM environment. The “EZ” version covers most of the common NIM tasks such as quick setup of a master server, updating, backing up, or reinstalling existing clients, and configuring new clients. The full-featured smit nim version adds some complexity over EZ NIM adds more configuration options, such as the ability to use custom software packages and more granular control over the installed clients.

If you insist on command-line operation, (SMIT’s EZ-NIM options for configuring a master server are just call nim_master_setup with the specified options). This initializes filesystems for the NIM software resources, creates the necessary configuration files, and copies in a sample client configuration file that you can edit for your local clients.

The most basic usage is nim_master_setup -a device=/dev/cd0, where /dev/cd0 is the drive that contains the installation media for the AIX release. Unlike most of the other installation systems described in this chapter, a NIM master server can install releases of AIX only on the same revision level or earlier; an AIX 5.2 server cannot install AIX 6.1 releases.
