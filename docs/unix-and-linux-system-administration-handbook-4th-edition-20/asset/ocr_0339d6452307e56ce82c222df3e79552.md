# Table 3.6 Commonly modified HP-UX config files in /etc/rc.config.d

| File(s) | Purpose |
|---|---|
| SNMPMaster | A master switch that turns all SNMP support on or off |
| SNMP* | Hold other SNMP-related options |
| acct | Turns process accounting on or off; is acct(1M) |
| auditing | Configures system auditing; is audsys and audevent |
| cde | Holds CDE (Common Desktop Environment) settings |
| clean* | Controls variable boot-time cleanup operations |
| hnetferconf | Configures Ethernet interfaces; is lanadmind |
| lp | Turns the printer spool on or off |
| mailserv | Starts sendmail or specifies a mail server |
| nameservs | Configures/starts the name server daemon |
| nddconf | Sets tunable kernel parameters at startup using nddconf | Specifies network device configuration (IP address, etc.) netdaemons | Tells networking daemons to start nettl | Configures network tracing and logging |
| nfsconf | Sets NFS configuration options |
| sshd | Configures the SSH daemon |
| vt | Starts daemon; depends on ptydaemon |
| xfs | Turns the Windows font server on or off |

a. See nettl(1M), neticonf(1M), and nettigen.conf(4) for more information.

rc.boot is a poorly commented script that executes in three phases:

+   * Initialization of system hardware
* Mounting of filesystems
* Starting /etc/initabb, which processes entries in the /etc/initabb file

AIX relies heavily on /etc/initabb than to its UNIX relatives, initabb reads each line of the initabb file and executes the lines in order. In some cases, initabb starts a daemon directly. For example, the following line starts or restarts cron on run levels 2 through 9:

```
cron:23456789:respawn:/usr/sbin/cron
```

Other initabb entries run a series of commands. For example, /etc/rc.tcpip (a bsh script), starts daemon:

```
rtcpip:23456789:wait /etc/rc.tcpip > /dev/console 2>&1 # Start TCP/IP daemons
```

Here, output from the script is routed to the system console. it waits for the script to exit before processing the next line in the file.

AIX includes a series of four commands for managing the initabb file: mitab, chitab, lsitab, and rmitab. Predictably, these commands add, change, list, and remove entries from the initabb. We do not see the point and prefer to edit the file directly with a text editor as vi.
