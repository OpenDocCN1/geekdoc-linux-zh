IP routing is "next hop" routing. At any given point, the system handling a packet only needs to determine the next host or router in the packet's journey to its final destination. This is a different approach from that of legacy protocols, which determine the exact path a packet will travel before it leaves its originating host, a scheme known as source routing.\¹
