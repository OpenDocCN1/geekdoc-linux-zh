Win4Lin is a commercial alternative to Wine from NeTraverse. Win4Lin claims to be more stable than Wine and to support a few Microsoft applications. However, it requires kernel modifications, which Wine does not. Win4Lin is available from win4lin.com.

# Dual booting, or why you shouldn't

If you've ever installed Linux on a computer that had a former life as a Windows machine, you have doubtless been offered the option to set up a dual boot configuration. Such configurations function pretty much so. It is possible to mount Windows partitions under Linux and to access Linux filesystems from Windows. Read all about setting up a dual boot configuration on 85.

But wait! If you are doing real work and need access to both Windows and UNIX, be very skeptical of dual booting as a possible solution in the context of a production system. Dual boot setups represent Murphy's Law at worst: they always seem to be booted into the wrong OS, and the slightest chore requires multiple reboots. With the advent of widespread virtualization and cheap hardware, there's usually no reason to put yourself through this torture.

# Microsoft Office alternatives

A few years ago, Sun released an open source version of StarOffice, Microsoft Office-like application suite, under the name OpenOffice. OpenOffice.org includes spreadsheets, a word processor, a presentation package, and a database application similar to Microsoft Access. These tools can read and write files generated by their Microsoft analogs. You can download the suite from openoffice.org.

OpenOffice.org is available on all major platforms, including Windows, Linux, Solaris, Mac OS, and most versions of Unix. If you're looking for a package with a commercial support contract, you can also buy Sun's StarOffice, which is essentially OpenOffice in a box with support and better spell-checking.

Google competes on the application front with Google Apps offering. In addition to its powerful Gmail and Google Calendar offerings, Google also includes word processing and spreadsheets. These free products include collaboration features that let multiple users edit documents simultaneously from several locations. Since all of Google's apps run in a web browser, they can be used on virtually any operating system. You can export and import content in various formats, including those of Microsoft Office.
