# Chapter 17 DNS: The Domain Name System

Use of forwarding

+   - forwarders { in_addr; in_addr; ... }; [empty list]
- forwarder only { first; [first]

Instead having every name server perform its external queries, you can designate one or more servers as forwarders. A run-of-the-mill server can look in its cache and in the records for which it is authoritative. If it doesn't find the answer it's looking for, it can then send the query to a forwarder host. That way, the forwarders build up caches that benefit the entire site. The designation is implicit—not in the configuration file of the forwarder explicitly says “Hey, you're a forwarder.”

The forwarders option lists the IP addresses of the servers you want to use as forwarders. They are queried in turn. The use of forwarder circumvents the normal DNS procedure starting at a root server and following the chain of referrals. Be careful not to create forwarding loops.

A forward-only server caches answers and queries, but it never queries anyone else. If the forwarders do not respond, query fails. A forward-first server prefers to deal with forwarders, but if they do not respond, the forward-first server will complete queries itself.

Since the forwarders option has no default value, forwarding does not occur unless it is specifically configured. You can turn on forwarding globally or within individual zone statements.

Permissions

+   - allow-query { address_match_list }; [all hosts]
- allow-query-cache { address_match_list }; [all hosts]
- allow-transfer { address_match_list }; [all hosts]
- allow-update { address_match_list }; [none]
- blackhole { address_match_list }; [empty]

These options specify which hosts (or networks) can query your name server or its cache, request block transfers of your zone data, or dynamically update your zones. These match lists are a low-rent form of security and are susceptible to IP address spoofing; there's some risk in relying on them. It probably not a day goes if someone tricks your server into answering a DNS query, but using the allow_update and allow_transfer clauses; use cryptographic keys instead.

The blackhole list identifies servers that you never want to talk to: **named** does not accept queries from these servers and will never ask them for answers.

Packet sizes

+   - edns-udp-size number; [4096]
- max-udp-size number; [4096]

All machines on the Internet will be capable of reassembling a fragmented UDP packet of 512 bytes or fewer. Although this conservative requirement made sense in the 1980s, it is laughably small by modern standards. Modern routers and firewalls handle much larger packets, but it only takes one bad link in the IP chain to spoil the whole path.
