# Literal characters

The filename matching and expansion performed by the shell when it interprets command lines like wc *.pl is not a form of regex matching. It's a different system called "shell globbing," and it uses a different and simpler syntax.

Regular expressions are powerful, but they cannot recognize all possible grammars. Their most notable weakness is that they cannot recognize delimiters. For example, it is not possible to write a regular expression that recognizes valid arithmetic expressions when parentheses are allowed for grouping.

Regular expressions reached the peak of their power and performance in Perl. In fact, Perl's pattern matching features are so elaborate that it's not really accurate to call them an implementation of regular expressions. Perl patterns can match nested delimiters, recognize palindromes, and an arbitrary string of As followed by the same number of Bs—all feats beyond the reach of regular expressions. However, Perl can process vanilla regular expressions as well.

Perl's pattern matching language remains the industry benchmark, and it has been widely adopted by other languages and tools. Philip Hazel's PCRE (Perl-compatible regular expression) library makes it relatively easy for developers to incorporate into their projects

Regular expressions are not themselves a scripting language, but they are useful enough to merit featured coverage in any discussion of scripting; hence, this section, we discuss in their basic form with a few of Perl's refinements.

# The matching process

Code that evaluates a regular expression to match a single given text string to a single pattern. The "text string" to match can be very long and can contain embedded newlines. It's convenient to use a regex to match the contents of an entire file or HTML document.

For the matcher to declare success, the entire search pattern must match a contiguous section of the search text. However, the pattern can match at any position. After a successful match, the evaluator returns the text of the match along with a list of matches for any specially delimited subsections of the pattern.

# Literal characters

In general, characters in a regular expression match themselves. So the pattern

I am the walrus

matches the string "I am the walrus" and that string only. Since it can match anywhere in the search text, the pattern can be successfully matched to the string "I am egg man. I am the walrus. Koo koo-cho!" However, the actual match is limited to the "I am the walrus" portion. Matching is sensitive.
