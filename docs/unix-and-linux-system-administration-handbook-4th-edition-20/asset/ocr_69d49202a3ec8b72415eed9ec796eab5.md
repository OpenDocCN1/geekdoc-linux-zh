# Performance issues

BIND 9's performance on multiprocessor architectures is not as speedy as de-
velopers might have hoped, but several root servers use BIND 9 and happily han-
dle of queries per second. But NSD's and Unbound's performance is probably more
adquate for most use. Especially for DNSSEC signed zones.

We've said this multiple times, but it repeats: set your TTLs to
reasonable values—weeks or days, minutes or seconds. The use of short TTL
punishes you (because you must constantly re-serve the same records) and
your web clients (because they must constantly fetch them). It also provides a-
tential attacker with a cache poisoning opportunity. Some name servers select-
ignore TTLs that they don't like (values that seem unreasonably or unpre-
sasonably short).

Paging degrades server performance nonlinearly, so don't be stingy with memory
h hosts that run name servers. You'll need to wait for a week for the memory
footprint to stabilize for recursive servers; see page 571.
