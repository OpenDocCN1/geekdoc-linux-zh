DKIM resource records have not yet been standardized as a DNS record type; TXT records in a special format are used instead. They use a DNS name formed from a "selector" concatenated with the _domainkey. The record's data is the site's DKIM public key. Multiple selectors may exist so that keys can be easily rolled and revoked.

A site using DKIM computes a signature over selected header fields and the body of the message with its DKIM private key. It puts the signature into the outbound message in the form of a header field DKIM-Signature.

The corresponding public key is available through the sending site DNS zone as a TXT record associated with the name _domain.com. The receiving site does a DNS lookup for this key and uses it to validate the message signature. Successful verification authenticates the message as coming from the purported sending domain and verifies that the message has not been modified.

Here is an example of a DKIM-Signature line from a signed message:

```
DKIM-Signature: v=1;rsa=sha256;c=relaxed/relaxed;d=gmail.com;s=gamma;h=domainkey.mime-version:reported-to:date:message-id:subject:from:content-type;bh=24HFUvt1taOA4jRXnBm46JzUpSbkO4dz2pp4ls;b=UtYWupx/UpdiQ7sd1n0H5zfDIkJR7/Ge+HywBxM0ClshlwhRhyRhyHy1ea3S0EnMXEJEY13Jyj3VNEMGAOAOSQlQIMdIdSlPj7avxptY0VFLgYGM9ID4uwB0l4a7ZjuUhoiJHmsEA/Ek48rvj10ZYG+ARDdpbx6/56fSfVt+a+A=
```

The tags in the signature are explained in Table 17.7.

| Table 17.7 Tags in the DKIM-signature header |
| Tag | Example value | What it is |
|---|---|---|n| v | 1 | Version number; must be 1 |
| a | rsa-sha256 | Encryption algorithm: rsa-sha1 or rsa-sha256 |
| c | relaxed/relaxed | Canonicalization algorithm: simple or relaxed |
| d | gmail.com | Domain of the sender |
| s | gamma | Selector or key |
| h | domain... | Header fields to include in the header signature |
| bh | 24HFUvt1... | Cryptographic hash of the body of the message |
| b | UtYWupx... | Cryptographic signature of the whole message |

a. The algorithm specifies how the header and body are merged before encryption.

The selector tag, s=gamma, tells us the name of the public key, and d= gives the parent domain. To get our hands on the public key, we dig for the TXT record for the pseudo-host gamma_domainkey.gmail.com.
