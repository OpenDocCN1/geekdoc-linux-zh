A similar effect can be achieved through Samba's inherit permissions option. If that option is enabled on a, new files and directories inherit their settings from their parent directory:

```
[eng]
comment = Group Share for engineering
path = /home/eng
tnt acl support = no
browable = no
writeable = yes
inherit permissions = yes
```

Because Samba will now propagate settings from the parent directory, it's impor-tant to set the permissions on the root of the share appropriately:

```
$ chmod u-rw,gs+o = /home/eng
$ chgrp eng /home/eng
$ chown eng /home/eng
```

Note that this configuration still requires you to create an eng pseudo-user to as the owner of the shared directory.
