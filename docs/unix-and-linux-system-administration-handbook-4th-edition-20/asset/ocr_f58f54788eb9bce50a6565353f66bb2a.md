| Directory | Contents |

The cf/cf directory contains examples of .mc files. In fact, it contains so many examples that yours may get lost in the cluster. We recommend that you keep your .mc files separate from those in the distributed cf directory. Either create a new directory for your site (sitename) or move the cf directory to cf.examples and create a new cf directory. If you do this, the Makefile and Build script over your new directory to the instructions in the README file still work. Alternatively, you can copy all of your configuration .mc files to a central location rather than leaving them the sendmail distribution. The Build script uses relative pathnames, so you'll have to modify it if you want to build a cf file from an .mc file and are not in the sendmail hierarchy.

The files in the cf/ostype directory configure sendmail for each specific operating system. Many are predefined, but if you have moved things around your system, you might have to modify one or create a new one. Copy one that is close to reality for your system and give it a new name.

The cf/feature directory is where you will shop for all the configuration pieces you might need. There is a feature for just about anything that any site running sendmail has found useful.
