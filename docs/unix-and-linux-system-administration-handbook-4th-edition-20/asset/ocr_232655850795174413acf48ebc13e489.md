# Table 12.3 Important binaries, directories, and configuration files used by Ignite-UX

| Filename | Purpose |
| --- | --- |
| /etc/bootptap | Acts as a plain-text "database" for bootpd |
| /etc/opt/ignite/inst_boottap | Records IP addresses for booting PA-RISC clients |
| /opt/ignite/bin/bootsys | Updates clients that are already running HP-US |
| /opt/ignite/bin/make_config | Creates config file using an installation depot |
| /opt/ignite/bin/make_depots | Creates install depot from some source media |
| /opt/ignite/bin/manager_index | Adds a depot to the Ignite-UX index |
| /opt/ignite/bin/setup_server | Shares /var/opt/ignite/clients over NFS |
| /var/ignite/clients | Stores client configuration files (dir) |
| /var/ignite/data | Traditionally used for installation depots (dir) |
| /var/ignite/INDEX | Indexes all installation depots to Ignite-UX |

The **make_depots** command extracts installation packages and sets up an operating environment for deployment to clients. After you create a depot, run **make_config** to read the depot's contents and create a configuration file that describes them. The configuration becomes known to Ignite-UX by way of the **manager_index**, which adds configurations to an INDEX file. A sample seems for version 11i v3 is shown below.

Before the server can be used by clients, you must enable BOOTP and the clients directory. Individual clients must also be added to the **instal_boottap** or **boottap**, depending on whether they are PA-RISC or Itanium machines.

To share the config directory via NFS, run /opt/ignite/sbin/setup_server. Behind the scenes, this command creates a NFS share in /etc/dfs/sharetab.

You can turn off BOOTP by uncommenting the **bootsys** line in /etc/inetd.conf. Then ask **inetd** to reread its configuration by using /usr/sbin/inetd -c

Before Ignite-UX will offer installation services to a client, it must normally recognize the client by MAC address. However, to lighten your administrative burden, we recommend that you use HP's concept of "anonymous clients," which are not associated with particular MAC addresses.
