# Firewalls: how safe are they?

A firewall should not be your primary (or only!) means of defense against intrud-ers. It's only one component of what should be carefully considered, multil-ered security strategy. The use of firewalls often confers a false sense of security. If a firewall lures you into relaxing other safeguards, it will have a negative effect on the security of your site.

Every host within your organization should be individually patched, hardened, and regularly monitored with one or more tools such as Bro, Snort, Nmap, Map-nus, and OSSEC. Likewise, your entire community needs to be educated about basic security hygiene. Otherwise, you are simply building a structure that has a hard crunchy outside and a soft chewy center.

Ideally, local users should be able to connect to any Internet service they want, but machines on the Internet should only be able to connect to a limited set of local services hosted within your DMZ. For example, you may want to use SFTP ac-cess to a local archive server and allow SMTP connections to a server that receives incoming.

To maximize the value of your Internet connection, we recommend that you emize connectivity and accessibility when deciding how to set up your network. At the end of the day, it is the system administrator's vigilance that makes a net-work secure, not a fancy piece of firewall hardware.

# 22.12 LINUX FIREWALL FEATURES

As stated earlier, we don't really recommend the use of Linux (or UNIX, or Windows) systems as firewalls because the insecurity of running a full-fledged, general-purpose operating system. However, a hardened Linux system is a workable substitute for organizations that don't have the budget for a high-dollar firewall appliance. Likewise, it is a fine option for a security-savvy home user with a penchant for tinkering. In any case, a local filter such as iptables can be an ex-cellent security measure to consider when hardening a system.

If you are set on using a Linux machine as a firewall, make sure that it is up to date with respect to security configuration and patches.
