If you kill the smbd associated with a user, all locks disappear. Applications handle this gracefully and require any locks they need, such as MS Access, freeze and die a horrible death with much clicking required on the Windows side just to be able to close the unhappy application. As this may sound, we have yet to see any file corruption from such a procedure. In any case, be careful when Windows claims that files are locked by another application. Often Windows is right and you should fix the problem on the client side by locking the offending application instead of brute-forcing the locks on.

# 30.9 ACTIVE DIRECTORY AUTHENTICATION

The Windows desktops on your network most likely use Microsoft's Active Directory system for authentication, directory services, and other network services. Active Directory (AD) collects users, groups, computers, and operating systems under a single umbrella, centralizing and simplifying system administration. It is also one of the primary reasons why Windows has gained a permanent foothold in many enterprises. UNIX has assembled some of the pieces of this puzzle, but none of the UNIX solutions are polished or as widely implemented as Active Directory.
