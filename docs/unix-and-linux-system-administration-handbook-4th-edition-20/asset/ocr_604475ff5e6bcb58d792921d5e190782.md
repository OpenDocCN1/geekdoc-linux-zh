# Chapter 19 Sharing System Files

The name “install” is somewhat misleading, since files are copied whether or not an install command is present. Options are specified as they would be on the rdist command line, but when included in the Distfile, they apply only to the set of files handled by that install command.

The optional dest specifies an installation directory on the destination hosts. By default, rdist uses the original pathnames.

The notify command takes a list of email addresses as its argument. rdist sends mail to these addresses whenever a file is updated. Any addresses that do not contain an at @ are suffixed with the name of the destination host. For example, rdist uses “pete” to “pete@anchor” when reporting a list of files up dated host.

See the section starting on page 48 for more information about regular expressions.

The except and except_pat commands remove paths from the list of files to be copied. Arguments to except are matched literally, and those of except_pat are interpreted as regular expressions. These exception commands are useful because rdist, like make, allows macros to be defined at the beginning of its control flow. You might want to use a similar list of files for several statements, specifying only the additions and deletions for each host.

The special command executes a shell command (the string argument) on each remote host. If a pathlist is present, rdist executes the command once copying each of the specified files. Without a pathlist, rdist executes the command after every file. special is similar, but it executes the shell once after all copying is complete. The contents of the pathlist are passed to the shell as an environment variable.

Here’s a example of a Distfile:

```
SYS_FILES = /(etc/passwd /etc/group /etc/mail/aliases)
GET_ALL = (chimchim lollipop bardarkon)
GET_SOME = (whammo piff)

all: ${SYS_FILES} -> ${GET_ALL}
notify barb;
special: /etc/mail/newialases "/usr/bin/newialases";

some: ${SYS_FILES} -> ${GET_SOME}
except /etc/mail/aliases;
notify eddie@spiff;
```

See page 760 for more information about newialases.

This configuration replicates the three listed system files on chimchim, lollipop, and bardarkon sends mail to barb@destination describing any updates or errors that occur. After /etc/mail/aliases is copied, rdist newialases on each destination. Only two files are copied to whammo and piff. newialases is not run, and a mail is reported to eddie@spiff.
