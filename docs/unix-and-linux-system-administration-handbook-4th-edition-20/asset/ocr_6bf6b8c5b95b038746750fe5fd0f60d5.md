# Privacy options

sendmails SafeFileEnvironment option controls where files can be written when email is redirected to a file by aliases or a .forward file. It causes sendmail to execute a chroot system call, making the root of the filesystem no longer / but safe or whatever path you specified in the SafeFileEnvironment option. An alias directed to the /etc/passwd file, for example, would really be written to /safe/etc/passwd.

The SafeFileEnvironment option also protects device files, directories, and other special files by allowing writes only to regular files. Besides increasing security, this option ameliorates the effects of user mistakes. Some sites set the option to /home to allow access to home directories while keeping system files off-limits.

Mailers can also run in a chrooted directory.

# Privacy options

sendmail also has privacy options that control

+   * What external folks can determine about your site through SMTP
* What you require of the host on the other end of an SMTP connection
* Whether your users can see or run the mail queue

Table 20.15 lists the possible values for the privacy options as of this; see the file doc/op.ps in the distribution for current information.

| Value | Meaning |
| --- | --- |
| public | Does no privacy/security checking |
| needhello | Requires SMTP HELO (identifies remote host) |
| noexpn | Disallows the SMTP EXPN command |
| novrry | Disallows the SMTP VRFY command |
| needexpnhello | Does not expand addresses (EXPN) without a HELO |
| needvrfyhelo | Does not verify addresses (VRFY) while at HELO |
| noberv | Disallows verbose mode for EXPN |
| restrictmaq | Allows only mqueue directory's group to see the queue |
| restrictgr | Allows only mqueue directory's owner to run the queue |
| restrictexpand | Restricts info defined by the -bv and -v flags |
| noertrn | Disallows asynchronous queue runs |
| authwarnings | Adds warning if outgoing message merges formed |
| noreceipts | Turns off delivery notification for success receipt receipts |
| nobodyreturn | Does not return body in a DSN |
| goaway | Disables SMTP status queries (EXPN, VRFY, etc.) |

20.15 Values of the PrivacyOption variable

+   a. Verbose mode follows .forward files when an EXPN command is given and reports more information on the whereabouts of a user's mail. Use nober or, better yet, noexpn, on any machine exposed to the outside world.
b. Unless except by root or the TrustedUser.
c. ETRN is an SMTP command intended for use by dial-hosts. It triggers that the queue be just for messages to that.
