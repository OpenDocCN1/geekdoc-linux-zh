hosts: two real hosts—usually at either end of a point-to-point link—and the network and broadcast addresses. To have four values for hosts requires two bits in the host portion, such a network would be a /30 with netmask 255.255.255.252 or 0xFFFFFFFC. However, a /31 network is treated as a special case (RFC 3021) and has no network or broadcast address; both of its addresses are called for hosts, and its netmask is 255.255.255.254.

A handy site called the IP Calculator by Krishan Jodies (it's available at jodies.ie/ipcalc) helps with binary/hex/mask arithmetic. IP Calculator displays everything you need to know about a network address and its netmask, broadcast address, hosts, etc. A tarball for a command-line version of the tool, ipcalc, is also available.

On Ubuntu you can install ipcalc apt-get.
