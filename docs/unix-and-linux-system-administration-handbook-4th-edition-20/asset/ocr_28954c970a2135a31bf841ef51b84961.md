# Network installations with the Automated Installer

At the end of the configuration process, your /jumpstart/config directory should
looking something like this:

```
solaris$ ls -l
-WRF-XR-X 1 root 52152 Aug 23 19:42 check
-WRF-T--R-- 1 root 413 Aug 23 19:29 profile_a
-WRF-T--R-- 1 root 48 Aug 23 19:13 rules
-WRF-T--R-- 1 root 62 Aug 23 19:43 rules.ok
-WRF-T--R-- 1 root 314 Aug 23 17:35 sysidcfg
```

You must add each client to be set up through JumpStart to the install server; this
a two-step process. First, add the MAC address of the client to the server's
/etc/hosts file. Second, run the .add_install_client tool to add the client to the
configuration database, as shown:

```
solaris$ cd /jumpstart/s10sparc/Solaris_10/Tools
solaris$ sudo ./add_install_client -c server/jumpstart sake sun4v
```

In this case, the client called will use the JumpStart NFS share on the host
server for installation. You start the actual network installation on the client from
OB prompt:

```
ok boot install
```

This complicated process allows for highly customized and flexible installations at
of the expense of a few brain cells.

The OpenSolaris developers assessed the complexity of JumpStart and decided to
create a new deployment tool for OpenSolaris. This tool, the Automated Installer,
mirrors the style of JumpStart in several ways but abstracts some of the com-
plexity through a convenient tool called installadm. In its simplest, server
installation can now be achieved with a single command. All the files you need to
get started with AI are contained in the SUNinstall-tools package.

An AI server offers one or more "services," each of which represents
an OS installation option is discovered by clients at boot through multi-
 DNS. Different services serve different installation needs; for example,
one service for site-specific web servers and another for database servers.

Once a client installs an installer, it searches for a configuration, or manifest,
matches its system description. The client performs an installation with data from
the manifest files. No client configuration is required, although custom client-
stallations are available if you need them.

An AI installation bundles all the necessary parts together in a convenient
package, including DHCP and TFTP services. Be sure to check with your network
administrator before adding these to the network.
