Bunch o’ Stuff includes a variety of supplemental information. Some chapters discuss optional features as those that support server virtualization. Others give advice on topics ranging from eco-friendly computing to the politics of running a system administration group.

Each chapter is followed by a set of practice exercises. Items are marked with an estimate of the effort required to complete them, "effort" is an indicator of both the difficulty of the task and the time required. There are four levels:

+   * Easy, to be straightforward
* Harder or longer, may require lab work
* Hardest or longest, requires lab work and digging
* Semester-long projects (in a few chapters)

Some of the exercises require root sudo access to the system; others require the permission of the local sysadmin group. Both requirements are mentioned in the text of the exercise.
