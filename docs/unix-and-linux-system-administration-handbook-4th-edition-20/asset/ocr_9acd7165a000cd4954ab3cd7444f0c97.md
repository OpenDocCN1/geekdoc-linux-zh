# 8.5 ATTACHMENT AND LOW-LEVEL MANAGEMENT OF DRIVES

A disk is attached to the system depends on the interface that is used. The rest is all mounting brackets and cabling. Frequently, SAS and SATA connections are virtually idiot-proof.

For parallel SCSI, double-check that you have terminated both ends of the SCSI bus, but the cable length is less than the maximum appropriate for the SCSI variants you are using, and the new SCSI target number does not conflict with the controller or another device on the bus.

Even on hot-pluggable interfaces, it's conservative to shut the system before making hardware changes. Some older systems as AIX de--vice configuration only at boot, so that the hardware is hot-pluggable may not translate into immediate visibility at the OS level. In the case of SATA interfaces, hot-plugability is an implementation option. Some host adapters don't support it.

# Installation verification at the hardware level

After you install a new disk, check to make sure the system acknowledges its existence at the lowest possible level. On a PC this is easy: the BIOS shows you IDE and SATA disks, and most SCSI cards have their setup screen that you can invoke before the system boots.

On other types of hardware, you may have to let the system boot and check the diagnostic output from the kernel as it probes for devices. For example, one of our tests showed the following messages for an older SCSI disk attached to a BusLogic adapter.

scsi1: 1 host.
Vendor: SEAGATE, Model: T3446452W Rev: 0001
