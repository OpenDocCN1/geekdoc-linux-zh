# 25.3 X SERVER CONFIGURATION

The Xorg server, Xorg was notorious for being difficult to configure for a given hardware environment. However, a tremendous amount of effort has been put into making Xorg ready to right out of the box, and many modern systems run it successfully without any configuration file. However, it is still possible to manually adapt the Xorg server to a wide array of graphics hardware, input devices, video modes, resolutions, and color depths.

If your system is running fine without a Xorg configuration file, great! It may be using the KMS module, which is described later in this chapter. Otherwise, you have two options. Option one is to manually configure the xorg.conf file. True be told, this is your only real option in some situations. Option two is to use the xrrand tool to configure your server; it's covered on page 1025.

The Xorg configuration is normally located in /etc/X11/Xorg.conf, but the X server searches a few of directories to find it. The main page presents a complete list, but one point to note is that some the paths Xorg searches contains the hostname and a global variable, making it easy for you to store configuration files in multiple systems in a central location.

AIX operates without an xorg.conf configuration file and instead to automatically recognize all AIX hardware display types. You can pass configuration hints as arguments to the X server.

Some of the sections that make up the xorg.conf file are relatively fixed. The defaults can often be used straight from an existing example configuration file. Others, such as the Device, Monitor, Screen, InputDevice, and ServerLayout specifications, depend on the hardware setup. We discuss the most interesting of these sections more detail.

# Device sections

A Device section describes a particular video card. You must provide a string to identify the card and a driver appropriate for the device. The driver is loaded only if the device is referenced by a corresponding Screen section. A typical device section might look like this:

| Section "Device" |
| Identifier "Videoocard0" |
| Driver "radeon" |
| option value |

The manual for the driver, radeon in this example, describes the hardware that's driven as well as the options the driver supports. If you are experiencing strange video artifacts, you might try setting options to turn off hardware acceleration (if supported), slowing down video memory access, or modifying interface parameters. It is generally a good idea to check the web to see if other people have experienced similar problems before you start changing values.

# Monitor sections

The Monitor describes the displays attached to your computer. It can specify detailed timing. The information is necessary for older hardware, but most modern monitors can be probed for it. Display specifications can usually be obtained from the manufacturer's web, but nothing beats the original material that you make with the. Either way, you will want to know at least the horizontal sync and vertical refresh frequencies for your model.

A typical Monitor section looks like this:

| Section "Monitor" |
| Identifier "ViewSonic" |
| Option "DPMS" |
| HorizSync 30-65 |
| VertRefresh 50-120 |
