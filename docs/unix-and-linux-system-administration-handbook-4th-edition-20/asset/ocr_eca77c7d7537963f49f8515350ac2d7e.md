# PDF

Adobe's Portable Document Format is produced by Adobe Acrobat and many other non-Adobe applications. OpenOffice, for example, prefers to export documents as PDF.

PDF documents are platform independent, and PDF is routinely used to exchange documents electronically for both on-line and off-line (printed). The first text of this book was delivered to the book printer as a PDF file.

PDF is a document description language, not just a page description language. It describes not only individual pages, but also the overall structure of a document: which pages belong to chapters, which text columns flow to other columns, and so on. It also accommodates a variety of multimedia, hypertext, and scripting features for on-screen use.

Some printers interpret PDF directly. If yours doesn't, a host of PDF viewers and translators (including Ghostview, xpdf, kpdf, Evince, and Acrobat Reader) can convert your PDF documents into something else (such as PostScript) that is more widely understood. Your print system may even hide the conversion requirement from you and automatically convert PDF documents before sending them to the printer.

# XPS

Worth mentioning, too, is Microsoft's XML Paper Specification, aka XPS. OpenXPS is not yet widely used on Windows systems. UNIX and Linux support is currently scant, although Artifex already has an XPS interpreter. Distributions will undoubtedly start to support XPS if it becomes popular.

# PJL

Hewlett-Packard's Printer Job Language, is not a real PDL. It's a meta-language that describes printer jobs. We mention it here because you'll see mentioned in printer descriptions. You'll also need to know about it if you're looking at the internals of print jobs to solve printing problems.

PJL is a job control language that specifies things like a job's PDL, whether the job is duplex or simplex, what paper size to use, and so on. The PJL commands that come at the start of the job, and the PJL statements start with @PJL:

```
@PJL SET COPIES=3
@PJL COMMENT FOO BAR MUMBLE
@PJL SET DUPLEX=ON
@PJL SET PAGEPROTECT=OFF
@PJL ENTER LANGUAGE=PCL
```

Non-HP printers understand (or deliberately ignore) PJL, but if you' having trouble printing something that contains PJL on a non-HP printer, removing the PJL with a text editor and resubmitting the job.
