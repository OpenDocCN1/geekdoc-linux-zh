# Specifics for AIX

# HP recommends

hosts: dns [NOTFOUND=return] nis [NOTFOUND=return] files

we but require

hosts: files [NOTFOUND=continue] dns

to avoid problems with booting. It's important to be able to configure the network in the boot sequence without looking up names in NIS or DNS, inasmuch as services cannot run until the network is up. HP-UX's startup script for name service is in /etc/rc.config/d/namesvr_dns.

HP-UX uses well-commented sample files for just everything in the directory /usr/newconfig, but also, for name service. However, it has a couple of ancient commands related to name service: hosts_named, which transforms a hosts file into a zone file, and sig_named, which sends signals to the running named process to control it. The /etc/hosts file these days contains localhost and the host itself, so the conversion runtime is useless. And since BIND 9, rnd must be used to control named, not signals.

Table 17.20 summarizes the filenames and locations for name service on HP-UX.

# 17.20 BIND files in HP-UX

| File | Directory | Description |
|---|---|---|
| resolv.conf | /etc | Resolver library configuration file |
| named | /usr/sbin | Name server daemon |
| lwresd | /usr/sbin | Lightweight resolver daemon |
| named-checkconf | /usr/sbin | Checks the config file syntax |
| named-checkzone | /usr/sbin | Checks zone file syntax |
| named.conf | /etc/namedb | Configuration file for name server |
| nswitch.conf | /etc | Service switch file |

# Specifics for AIX

AIX ships with BIND 8 and 9, with binaries named8 and named9, respectively. As shipped, named is a link to named8, which is no longer supported by ISC. They ship versions 8.3.3+ and 9.2.1, vintage January 2004. Slightlike performance difference AIX does not include the named-checkconf and named-checkzones commands—perhaps they intend the BIND distribution after 2004. The startup scripts for name service under AIX are in /etc/rc.tcpip.
