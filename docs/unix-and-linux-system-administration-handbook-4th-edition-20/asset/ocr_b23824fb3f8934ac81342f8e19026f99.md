# 21.8 The ICSI NETALYZR

We have looked several tools for network debugging and for reviewing aspects of the network configuration. But even with our best efforts at monitoring, it's useful to have someone take a peek at your network from time to time. The Netalyzr is a service provided by the International Computer Science Institute at Berkeley that provides a useful "second opinion". To use it, point your Java-based browser at netalyzr.icsi.berkeley.edu (note: missing 'é').

The Netalyzr tests your Internet connection in a variety of ways. It has the advantage of being able to access your network both from inside (through the Java program that runs in your browser) and from the perspective of ICSI's servers.

Exhibit C shows the Netalyzr report for a workstation on a private network that is attached to the outside world through a DSL link. The Netalyzr seems to be generally happy with the setup except for a few queries about the Apache web proxy that's in use. (Blocking malformed HTTP requests may actually be a useful feature, however).
