# ServerLayout sections

The ServerLayout is the top-level node of the configuration hierarchy. Each hardware configuration on the server will be run has its own instance of the ServerLayout section. The layout used by a particular X server is usually specified on the server's command line.

This section ties together all the other sections to represent an X display. It starts with the requisite Identifier, which names this particular layout. It associates a set of screens with the layout. If multiple monitors are attached to separate video cards, each screen is specified along with orientation directions to indicate how they are properly arranged. In this example, screen one is on the left and screen is on the right.

Here is an example of a complete ServerLayout section:

| Section "ServerLayout" |
| --- | --- |
| Identifier | "Simple Layout" |
| Screen | "Screen 1 LeftOf "Screen 2" |
| Screen | "Screen 2 RightOf "Screen 1" |
| InputDevice | "Generic Mouse" "CorePointer" |
| InputDevice | "Generic Keyboard" "CoreKeyboard" |
| Option | "BlankTime" "10# Blank the screen in 10 minutes |
| Option | "StandbyTime" "20# Turn off in 60 minutes (DPMS) |
| Option | "SuspendTime" "60# Full hibernation in 60 minutes (DPMS) |
| Option | "OffTime" "120# Turn off DPMS monitor in 2 hours |
| EndSection |

Some video cards can display monitors at once. In this case, only a single Screen is specified in the ServerLayout section. The following list is the list of input devices to associate with the layout. The CorePointer and CoreKeyboard options are passed to the InputDevice section to identify that the devices are active for the configuration. These options can also be set directly in the corresponding InputDevice sections, but it's cleaner to set them in the ServerLayout.

The last few lines configure several layout-specific options. In this example, these all relate to DPMS, which is the interface that tells Energy Star-compliant monitors when to power themselves down. The monitors must also have their DPMS options enabled in the corresponding Monitor sections.

+   - Not all options are supported by Xorg. Some sold separately.
- Recall that screens identify a monitor/video combination at a particular color depth.
