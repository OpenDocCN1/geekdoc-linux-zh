# Constructing rules and persistent names

For matching rules, the assignment_clauses specify the actions udev should take to handle the event. Their format is similar to that for match clauses.

The most important assignment key is NAME, which indicates udev should name the device. The optional SYMLINK assignment key creates a symbolic link to the device through its desired path in /dev.

Let's put these components together with an example: a USB drive. Suppose we want to make the drive's device name persist across insertions and we want the device to be mounted and unmounted automatically.

To start with, insert the flash drive and check to see how the kernel identifies it. There are couple of ways to do this. By running the lsusb command, we can inspect the USB bus:

```
ubuntu$ lsusb
```

```
Bus 001 Device 007: ID: 1307:0163 Transcend, Inc. USB Flash Drive
Bus 001 Device 001: ID: 1d6b:0002 Linux Foundation 2.0 root hub
Bus 002 Device 001: ID: 1d6b:0001 Linux Foundation 1.1 root hub
```
