Similar rules clean up when the device is removed:

```
ACTION+="remove", ATTRS[model]==="USB2FlashStorage", KERNEL="sd[a-z]1"
RUN+="/bin/umount -l /mnt/ate-flash%n"
ACTION+="remove", ATTRS[model]==="USB2FlashStorage", KERNEL="sd[a-z]1"
RUN+="/bin/rmdir /mnt/ate-flash%n```
```

Now that our rules are in place, we must notify **udev** of our changes. **udevadm's control command** is one of the few that require privileges.

```
ubuntu sudo udevadm control --reload-rules
```

Typos are ignored after a reload, even with the **--debug** flag, to be sure to double-check the rules' syntax.

That's it! Now the flash drive is plugged into a USB port, **udev** creates a symbolic link called **/dev/ate-flash1** and mounts the drive as **/mnt/ate-flash1**.

```
ubuntu ls -l /dev/ate*
lrwxwrwx 1 root 4 2020-08-09 21:22 /dev/ate-flash1 -> sdb1

ubuntu mount | grep ate
/dev/sdb1 on /mnt/ate-flash1 type vfat (rw)
```
