# Kernel tuning

AIX has six categories of tunable values and supplies corresponding commands for tweaking them. Most of the values relate to performance optimization. Table 13.6 captures each command and its purpose. Breaking from standard AIX convention, the commands share a common syntax. The parameters can be managed through the SMIT interface with the incantation smit tuning. See the next page for each command for detailed information.

Table 13.6 Commands for setting tunable kernel parameters in AIX
| Command | Domain | Examples of things you can configure |
| :--- | :--- | :--- |
| vmo | Virtual memory Input/Output | Minimum number of free pages Asynchronous I/O behavior JFS2 configuration |
| schedo | Process scheduling | Process time slices and priorities Virtual process forwarding |
| no | Network | IP TCP and UDP socket buffer sizes Packet time-to-live values |
| nfso | NFS | UTF-8 support Delegation support Maximum number of NFS connections |
| raso | Reliability | Only a few tunables, none of which are particularly valuable to administrators |

The commands are simple to use. To enable IP forwarding, for example, run
aix$ sudo no -o ipforwarding=1
To list all available tunables for the I/O subsystem, type
aix$ sudo ioo -a
You can add the -r flag to any of the commands to ensure that your changes persist after a reboot.

# 13.7 LOADABLE KERNEL MODULES

Loadable kernel modules (LKMs) are now common to nearly all flavors of UNIX. Each of our examples systems implement some of dynamic loading facility, although the exact implementations vary.

Loadable kernel module support allows a device driver—or any other kernel service—to be linked into and removed from the kernel while it is running. This facility makes the installation of drivers much easier the kernel binary does not need to be changed. It also allows the kernel to be smaller because drivers are not loaded unless they are needed.
