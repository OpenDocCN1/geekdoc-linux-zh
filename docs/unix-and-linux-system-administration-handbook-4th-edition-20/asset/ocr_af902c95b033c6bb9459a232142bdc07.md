# Captures

When a match succeeds, every set of parentheses becomes a “capture group” that records the actual text that it matched. The exact manner in which these pieces are available to you depends on the implementation and context. In Perl, you can access the results as a list or as a sequence of numbered variables.

Since parentheses can nest, how do you know which match is? Easy—the matches arrive in the same order as the opening parentheses. There are many captures as there are opening parentheses, regardless of the role (or lack of role) that each parent group played in the actual matching. When a parenthesized group is not used, Mu(?ammar when matched against “Muammar”), its corresponding capture is empty.

If a group is matched more than once, only the contents of the last match are returned. For example, with the pattern

```
(I am the (walrus|egg man)\){1,2}
```

matching the text
I am the egg man. I am the walrus.

there are two results, one for each set of parentheses:

I am the walrus.
walrus
