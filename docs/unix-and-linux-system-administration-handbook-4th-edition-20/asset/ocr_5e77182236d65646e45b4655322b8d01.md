# Chapter 31 Serial Devices and Terminals

+   - login prints the message of the day from /etc/motd and runs a shell.
- The shell executes the appropriate startup file.\n- The shell prints a prompt and waits for input.

When the user logs out, control returns to init, which wakes up and spawns a getty on the terminal port.

Files in /etc control the characteristics associated with each terminal. These characteristics include the presence of a login prompt and getty process on the port, the baud rate to expect, and the type of terminal that is assumed to be connected to the port.

Unfortunately, terminal configuration is one area where there is little agreement among vendors. Table 31.4 lists the files used by each system.

# Table 31.4 Terminal configuration files

| System | On/off | Terminal type | Parameters | Monitor |
| --- | --- | --- | --- | --- |
| Ubuntu | /etc/event.d/tty | /etc/ttype | /etc/getdefs | getty |
| SUSE | /etc/inittab | /etc/ttype | /etc/getdefs | getty |
| Red Hat | /etc/inittab | /etc/ttype | /etc/getdefs | getty |
| Solaris* | _sactab | _sact | zsmon/pmtab | ttymon |
| HP-UX | /etc/inittab | | /etc/getdefs | getty |
| AIX* | /etc/inittab | /etc/security/login.cfg | ODM database | getty |

+   a. Ubuntu has moved from init to startup for TTY/getty management; see page 1175.
b. Virtual consoles are defined in /etc/default/console-setup.
c. Solaris configuration files are in /etc/saf and should be managed with sacadm.
d. To ensure consistency, use SMIT to modify TTY parameters on AIX.

# The /etc/ttype file

On many systems, terminal type information is kept in a file called /etc/ttype. The format of an entry in ttype is

```
ttype device
```

where device is the short name of the device file representing the port and the termtype names an entry in the termcap and terminfo database. When you log in, the TERM environment variable is set to the value of this field.

Here is a sample ttype file:

```
wyse console
dialup tty0
dialup tty1
320 tty2
h19 tty3
dialout tty4
```

+   - .profile for sh and ksh; .bash_profile and .bashrc for bash; .shrc for csh/tcsh.
