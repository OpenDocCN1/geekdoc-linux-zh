# Chapter 9 Periodic Processes

A cron configuration file is called a "crontab", short for "cron table." Crontabs individual users are stored under /var/spool/cron. There is (at most) one crontab file per user: for root, for jsmith, and so on. Cron files are named with the login names of the users to whom they belong, cron uses to figure out UID to use when running the commands contained in each file. The cron command transfers crontab files to and from this directory.

Although the exact implementations vary, all versions of cron try to minimize the time spent repairing configuration files and making calculations. The cron command helps maintain cron's efficiency by notifying cron when the crontabs change. Ergo, you shouldn't edit crontab files directly, this may result in cron not notifying your changes. If you get into a situation where cron doesn't seem to acknowledge a modified crontab, a HUP signal will force it to reload on systems.

See Chapter 11 for more information about syslog.

cron normally does itself, but most systems keep a log file (usually /var/cron/log or /var/admin/cron/log) that lists the commands that were executed and the times at they ran. See Table 9.2 on page 287 for logging details.

On some systems, creating the log file enables logging, removing the log file turns logging off. On other systems, the log is turned on or off in a configuration file. Yet another variation is for cron to use syslog. The log file grows quickly and is rarely used; leave logging turned off unless you're debugging a specific problem or have auditing requirements.

# 9.2 THE FORMAT OF CRONTAB FILES

All crontab files on a system share a similar format. Comments are introduced with a pound sign (#) in the first column of a line. Each noncomment line contains six fields and represents one command:

```
minute hour dom month weekday
```

The first five tell cron when to run the command. They are separated by whitespace, but within the command field, whitespace is passed along to the shell. The fields in the time specification are interpreted as shown in Table 9.1.

# Table 9.1 Crontab time specifications

| Field | Description | Range |
| --- | --- | --- |
| minute | Minute of the hour | 0 to 59 |
| hour | Hour of the day | 0 to 23 |
| dom | Day of the month | 1 to 31 |
| month | Month of the year | 1 to 12 |
| weekday | Day of the week | 0 to 6 (0 = Sunday) |
