# Table 26.3 Lpadadmin flags

| Flag | Function |
|---|---|
| -printer | Specifies the printer to which other options apply |
| -dest | Makes the system's default printing destination |
| -xdest | Removes dest from the printing system |
| -class | Adds the printer to class |
| -class | Removes the printer from class |
| -edest | Copies another printer's interface program |
| -interface | Makes the use the interface program for the printer |
| -model | Makes the use the interface program for model |
| -h | Signifies that the printer is hardwired |
| -file | Specifies the full path of the printer device file |
| -D"desc" | Sets the printer description string to desc |
| -L"location" | Sets a textual description of where a printer leaves |

# Lpadadmin examples

The following examples show various uses of Lpadadmin.

```
$ sudo lpadadmin -phowler-lw -v/dev/tty06 -mPostScript -cpr
```

This command tells the printing system that a printer be called howler-lw is connected to /dev/tty06, that the printer should be in the class pr, and that the interface program for PostScript printers should be used. Lpadadmin takes care of creating the spool directory for you.

The command

```
$ sudo lpadadmin -dpr
```

sets the system's default destination to class (or printer) pr, and the command

```
$ sudo lpadadmin -phowler-lw -L"Conference room"
```

sets the description string for howler-lw.

```
$ sudo lpadadmin -phowler-lw -rpr -cfast
```

removes howler-lw from class pr and adds it to class fast;

```
$ sudo lpadadmin -xhowler-lw
```

removes howler-lw completely.
