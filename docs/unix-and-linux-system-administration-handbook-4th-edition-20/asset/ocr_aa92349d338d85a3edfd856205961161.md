# 1.12 Ways TO FIND AND INSTALL SOFTWARE

Chapter 12, Software Installation and Management, for the impatient, here a quick primer on how to find what's installed on your system and how to obtain and install new software.

Modern operating systems divide their contents into packages that can be independently of one another. The default installation includes a range of starter packages that you can expand according to your needs.

Add-software is often provided in the form of precompiled packages as well, although the degree to which this is a mainstream approach varies among systems. Most software is developed by independent groups that release the software in form of source code. Package repositories pick up the source code, compile it appropriately for the conventions in use on the systems they serve, and provide the resulting binaries. It's easier to install a system-specific binary package than to fetch and compile the original source code. However, packages are sometimes a release or before the current version.

The fact that two systems use the same package format does not necessarily mean that packages for the two systems are interchangeable. Red Hat and SUSE use RPM, for example, but their filesystem layouts are somewhat different. It's best to use packages designed for your particular system if they are available.
