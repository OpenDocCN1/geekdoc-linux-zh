# amavisid-new tools tools

The amavisid-nanny distribution includes two handy tools: amavisid-nanny and amavisid-agent. The nanny monitors the health of amavisd, and the agent provides access to lots of SNMP-like counters and gauges in real time. Both require the Berkeley DB library.

amavisd-nanny shows the state of amavisd processes, what messages they are working on, what they are doing, and how long they have been doing it. Running with the -h flag shows a usage message and also a list of that amavisd can be in. Most interesting are S for spam scanning, V for virus scanning, and a dot (period) for being idle. A status is printed every second with a colon every ten to make it easier to count. You should run the amavisd-nanny occasionally to see how the system is doing. Here's an example:

```
$ sudo amavisd-nanny
task-id elapsed in elapsed-bar (dots indicate idle)
process-id or state or busy
PID 01422: 0:09:51 =
PID 26784: 26784-18 0:00:01
PID 01422: 0:09:53
PID 26784: 0:00:03
```

amavisd-agent is an SNMP-like agent that collects statistics from all running daemons and can show the number of messages processed, the time to process each, the percent that contains viruses, the most common viruses, etc. Here is a massively truncated example:

```
$ sudo amavisd-agent
entropy STR ipwvElo5VA
sysSys STR
sysDes amavisd-new-2.6.1 (2008629)
sysLocation STR
sysObjectID OID 1.3.6.4.1.15132.2.1
```
