The use of sudo has the following advantages:

+   * Accountability is much improved because of command logging.
* Operators can do chores without unlimited privileges.
* The real root password can be known to only one or two people.⁷
* It's easier to use sudo than use su or log in as root.
* Privileges can be revoked without the need to change the root password.
* A canonical list of all root privileges is maintained.
* There is less chance of a root shell being left unattended.
* A single file can be used to control access for an entire network.

There are a couple of disadvantages as well. The rest of these is that any breach
in the security of a sudo's personal account can be equivalent to breaching the
root account itself. There is not much you can do to counter this threat other than
caution your sudoers to protect their accounts as would the root-
count. You can also run a password regularly over sudo' passwords to
ensure that they are making good password selections.

sudo command logging can be subverted by tricks such as shell escapes from\within an allowed program or by sudo sh and sudo if you allow them.

If you think of sudo as way of subdividing the privileges of the root account, it is
superior in some ways to the built-in role-based access control systems offered by
many versions of UNIX:

+   * You decide exactly how privileges will be subdivided. Your division may
 coarser or finer than the off-the-shelf privileges defined for you an
RBAC system.
* Simple configurations—by far, the most common—are simple to set up,
maintain, and understand.
* sudo's aliases for groups of hosts, users, and commands are functionally
similar to the roles in an RBAC system.
* sudo runs on all UNIX and Linux systems. You do not need to worry
about using different RBAC systems on different platforms.
* You can share a single configuration file throughout your site.
* You get consistent, high-quality logging for free.

The major drawback of sudo-based access control is the system that remains vul-
nerable to catastrophic compromise if the root account is penetrated.
