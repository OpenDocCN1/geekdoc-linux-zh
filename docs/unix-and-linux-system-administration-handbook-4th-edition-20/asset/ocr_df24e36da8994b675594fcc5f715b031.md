# Perl as a filter

You can use Perl without putting isolated expressions on the command line. This is a great way to do quick transformations and one that largely others filter programs like sed, awk, and tr.

Use the -pe command-line option to loop through STDIN, run a simple expression on each line, and print the result. The example is:

```
ubuntu perl -pe '#/bin/bash$/bin/bash' /etc/passwd
root:x:0:root:/root/bash
daemon:x:1:daemon:/usr/bin/bash
```

replaces /bin/bash at the end of lines in /etc/passwd with /bin/bash, emitting the transformed password file to STDOUT. You may be more accustomed to seeing the text substitution operator with slashes as delimiters (e.g., s/foo/bar/), Perl allows any character. Here, search text and replacement text contain slashes, so it's simpler to use # as the delimiter. If you use paired delimiters, you must use four of them instead of the normal three, e.g., s(foo)(bar).
