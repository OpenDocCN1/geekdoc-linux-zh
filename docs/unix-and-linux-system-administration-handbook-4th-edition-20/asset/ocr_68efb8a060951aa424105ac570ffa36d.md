# EIGRP: Enhanced Interior Gateway Routing Protocol

Although RIP is known for its proligate use of broadcasting, it does a good job when a network is changing often or when the topology of remote networks is not known. However, it can be slow to stabilize after a link goes down.

It was originally thought that the advent of more sophisticated routing protocols such as OSPF would make RIP obsolete. However, RIP continues to feel a need for a simple, easy-to-implement protocol that doesn't require much configuration, and it works well on low-complexity networks. The reports of RIP's death are greatly exaggerated.

RIP is widely implemented on non-UNIX platforms. A variety of common devices, from routers to SNMP-manageable network components, can listen to RIP advertisements to learn about network gateways. In some form of RIP client is available for all versions of UNIX and Linux, so RIP is a de facto-denominator routing protocol. Often, RIP is used for LAN routing, and a more featured protocol is used for wide-area connectivity.

Some sites run RIP daisies (usually routed or Quaggga's rip) for routing updates on the network but do not broadcast any of their own. The actual route computations are performed with a more efficient protocol such as OSPF (see the next section). RIP is used as a distribution mechanism.

# OSPF: Open Shortest Path First

OSPF is the most popular link-state protocol. "Shortest path" refers to the mathematical algorithm used to calculate routes; "open" is used in the sense of "nonproprietary." RFC2328 defines the basic protocol (OSPF version 2), and RFC5340 extends it to include support for IPv6 (OSPF version 3). OSPF version 1 is obsolete and not used.

OSPF is an industrial-strength protocol that works well for large, complicated topologies. It offers several advantages over RIP, including the ability to manage the network into sections ("areas") that share only high-level routing information. The protocol itself is complex and hence worthwhile at sites of significant size, where routing protocol behavior makes a difference. To use OSPF effectively, your's IP addressing scheme should be reasonably hierarchical.

The OSPF protocol specification does not mandate any particular cost metric. Cisco's implementation uses a bandwidth-related value by default.

# EIGRP: Enhanced Interior Gateway Routing Protocol

EIGRP is a proprietary routing protocol that runs only on Cisco routers. Its predecessor IGRP was created to address some of the shortcomings of RIP before bust standards like OSPF existed. IGRP has now been deprecated in favor of EIGRP, which accommodates CIDR masks. IGRP and EIGRP are configured similarly despite being quite different in their underlying protocol design.
