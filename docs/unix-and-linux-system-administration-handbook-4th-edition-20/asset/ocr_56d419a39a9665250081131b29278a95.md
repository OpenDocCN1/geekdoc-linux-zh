- The command family chdev, lsdev, lsattr, mkdev, rmdev, lcscon, and
isparent maps ODM configuration information to specific devices.

One indispensable utility for managing AI devices is the cfgmgr command. Run
it with no roots after adding new hardware to the system; the
hardware will miraculously be recognized and available for use. Well,
usually. If the device drivers haven't already been loaded into the ODM database,
cfgmgr will help suggest a package for you to install from the AI installation
media. See the cfgmgr page for further details.
