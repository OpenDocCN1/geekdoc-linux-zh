# Chapter 31 Serial Devices and Terminals

# 31.10 STTY: SET TERMINAL OPTIONS

tty lets you directly change and query the various settings of the terminal driver. There are about a zillion options, but most can be safely ignored. stty generally uses the same names for driver options as the termios man page does, but occasional discrepancies pop up.

A good combination of options to use for a plain-vanilla terminal is

```
solaris$ stty intr ^C U erase ^H -tabs
```

Here,-tabs prevents the terminal driver from taking advantage of the terminal's built-in tabulation mechanism, a useful practice because emulators are not very smart about tabs. The other options set interrupt, kill, erase characters to <Control-C>, <Control-U>, and <Control-H> (backspace), respectively.

You can use stty to examine the modes of the terminal driver as well as to set it. stty with no arguments produces output like this:

```
solaris$ stty
3840 baud
erase = ^H; col = M-?; eol = M-?; swtch = <undef>;
ixany
tab3
```

For a more verbose output use stty -a - the option:

```
solaris$ -a
3840 baud; rows 24; columns 80;
intr = ^C; quit = ^Q; erase = ^H; kill = ^U; echo = ^D; equal = M-?; eol2 = M-?
swtch = <undef>; start = ^Q; stop = ^S; size = ^Z; dsup = ^Y; rprnt = ^R;
erase = ^W; inext = ^V; flush = ^;
nparenb -parord sd8 huccl -octop cpread -clocal crtsct
jnbrnk -ijnpar -parmark - inpck -istrip -ioctl icnl - ixoff -nixcl iamaxld
opost -ocurl -ocnl onlcr -onorc -refill -ofdel nl0 cr0 tab3 bs0 vto
isig isacan iext iecho echo echok -nonflish -xcase -topocht -echopt
echoctl echo
```

The format of the output is similar but lists more information. The meaning of the output should be intuitively obvious if you've written a terminal driver recently.

stty operates on the file descriptor of its standard input, you can set and query the modes of a terminal other than the current one by using the shell's input redirection (<). You must be the superuser to change the modes on some-one terminal.

# 31.11 TSET: SET OPTIONS AUTOMATICALLY

tset initializes the terminal driver to a mode appropriate for a given terminal type. The type can be specified on the command line; if the type is omitted, tset uses the value of the TERM environment variable.
