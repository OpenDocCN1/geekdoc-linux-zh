## Drivers and the Kernel

The master configuration file for udev is /etc/udev/udev.conf; however, the default behaviors are reasonable. The udev.conf files on some distributions contain only comments, with the exception of one that enables error logging.

Sadly, because of political bickering among distributors and developers, there is little ever synergy among distributions. Many of the filenames in the default rules directory are the same from distribution to distribution, but the contents of the files differ significantly.

Rule files are named according to the pattern mn-description.rules, where mn is usually a two-digit number. Files are processed in lexical order, so lower numbers are processed first. From the rules directories are combined before the udev daemon, udev, parses them. The .rules suffix is mandatory; files without it are ignored.

Rules are of the form

```
match_clause, [match_clause, ...] assignment_clause [,assignment_clause ... ]
```

The match-clauses define the situations in which the rule is to be applied. Each match clause consists of a key, an operator, and a value. For example, the clause ATTR(size=="174271") was referred to above as a potential component of a rule; it selects all devices whose size attribute is 1,974,271.

Most keys refer to properties (which udev obtains from the /sys filesystem), but some refer to context-dependent attributes, as the operation being handled (e.g., device addition or removal). All match clauses must match in order for a rule to be activated.

Table 13.8 shows the match keys understood by udev.

### Table 13.8 Udev match keys

| Match key | Function |
| --- | --- |
| ACTION | Matches the event, e.g., add or remove |
| DEVPATH | Matches a specific device path |
| KERNEL* | Matches the kernel's name for the device |
| SUBSYSTEM* | Matches a specific subsystem |
| DRIVER* | Matches the driver used by a device |
| ATTR(filename)* | Matches a device's sysfs values; the filename is a leaf in the sysfs tree that corresponds to a specific attribute |
| ENV[key] | Matches the value of an environment variable |
| TEST[mask] | Tests if a command; matches if the return code is 0 |
| PROGRAM | Runs an external command; matches if the return |
| RESULT | Matches the output of the last call through PROGRAM |

- a. A plural version is also available. It searches the device path to match the value.

## Constructing rules and persistent names

For matching rules, the assignment_clauses specify the actions udev should take to handle the event. Their format is similar to that for match clauses.

The most important assignment key is NAME, which indicates udev should name the device. The optional SYMLINK assignment key creates a symbolic link to the device through its desired path in /dev.
