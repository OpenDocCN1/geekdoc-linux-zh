The only remaining problem is that instances are not persistent. That is, when this instance terminates, any changes to its disk or memory state are not captured. EBS provisions storage volumes just as new instances are provisioned. Here, we create a volume and attach it to the running host.

```
ubuntu$ create-volume -s 1 -z us-east-1c
VOLUME vol-5de8034 1 us-east-1c creating 2008-12-22T02:02:00
53+0000
ubuntu$ attach-volume vol-5de8034 -i i-1343fb7a -d /dev/sdf
ATTACHMENT vol-5de8034 i-1343fb7a /dev/sdf attaching 2008-12-22T02:04:01+0000
ubuntu$ describe-volumes
VOLUME vol-5de8034 1 us-east-1c in-use 2008-12-22T02:02:00
53+0000
ubuntu$ vol-5de8034 i-1343fb7a /dev/sdf attached 2008-12-22T02:04:01+0000
```

See Adding a Disk chapter for more information about creating filesystems.

These commands create a new EBS volume in the us-east-1c availability zone and attach it as the device /dev/sdf to the instance created. To create a filesystem and begin using, log in to the instance and proceed as if you were creating a filesystem on a physical disk.

Remember that AWS charges for the hour for instances, so unused instances and volumes should be cleaned up. Before terminating an unattended instance, be sure to detach your EBS volumes and gracefully shut down the system, just as you would a physical host.

```
ubuntu$ detach-volume vol-5de8034 /dev/sdf detaching 2008-12-22T02:04:01+0000
ubuntu$ terminate-instances i-1343fb7a
INSTANCE i-1343fb7a running shutting-down
ubuntu$ delete-volume vol-5de8034
VOLUME
```

In addition to the command-line interface, Amazon offers a web management interface that can initiate the same operations as the command-line tools, such as starting and stopping instances, attaching storage volumes, and allocating IP addresses. A Firefox browser plug called ElasticFox provides simple functionality from within your browser.

Amazon regularly introduces new features and products to its web services line. Auto-scaling of EC2 instances automatically spins up new servers to prevent outages when the load is high. The CloudWatch feature monitors metrics such as CPU usage and disk I/O for quick response to changing conditions. Keep an eye on the AWS blog at aws.typepad.com for feature enhancements and product announcements.
