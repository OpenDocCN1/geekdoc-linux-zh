## 17 DNS：域名系统

数以百万计机连接到互联网。当它们属于许多不同的国家、网络和管理组时，我们如何跟踪所有它们呢？两项关键基础设施将一切维系在一起：域名系统 (DNS)，它负责跟踪主机是谁；以及互联网路由系统，它负责跟踪它们是如何连接的。

尽管 DNS 有许多功能，但其核心作用是维护主机名与 IP 地址之间的映射。虽然 DNS 并非完美，但它对网络至关重要。
