# Specific for Linux

The Linux implementation of automount has diverged a bit from that of Sun. The changes mostly have to do with the naming of commands and files.

First, automount is the daemon that actually mounts and unmounts remote-systems. It generally does not need to be run by hand.

The default master map file is /etc/auto.master. Its format and the format of indirect maps are as described previously. The documentation can be hard to find, however. The master map is described in auto.master(5) and the indirect map in autofs(8); be careful, or you'll get the syntax of the autofs command. (As one of the man pages says, "Documentation leaves a lot to be desired.") To cause changes to the master map to take effect, run /init.d/autofs reload, which is equivalent to automount in Sun-land.

The Linux implementation does not support the Solaris-hosts clause for automatic automs.
