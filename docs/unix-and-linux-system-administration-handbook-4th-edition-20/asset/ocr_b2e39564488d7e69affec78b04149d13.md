# 24.8 VMware: AN OPERATING SYSTEM IN ITS OWN RIGHT

VMware is the biggest player in the bleeding edge virtualization industry and was the first vendor to develop techniques to virtualize the fractious x86 platform. VMware developed techniques for handling problematic instructions that previously prevented virtualization from becoming ubiquitous. The release of the VMware Workstation product in 1999 sparked a call to arms for more efficient computing—a call that is still reverberating.

VMware is a third-party product that is worthy of consideration when you are choosing a site-wide virtualization technology. The primary products of interest to UNIX and Linux administrators are ESX and ESXi, which are bare-metal hypervisors for the Intel x86 architecture. ESXi is free, but some useful functionality, like console access, has been removed. ESX targets the enterprise with scriptable installations, features for monitoring through SNMP, and for booting from a storage area (SAN) device.

In addition to the ESX products, VMware offers powerful, advanced products that facilitate deployment and management of virtual machines. They also have the most mature migration technology we've seen. Unfortunately, their client management interface runs only on Windows at your time. Collectively, VMware's products create a next generation IT environment, in-depth coverage which is unfortunately beyond the scope of this chapter.

HP-UX and AIX cannot run as VMware virtual machines because operating systems run on proprietary processor architectures that VMware does not emulate. Linux is of course well supported. Solaris can also run under VMware since its code base powers both the SPARC and x86 platforms.

# 24.9 Amazon Web Services

All the cool kids are getting into cloud computing, and Amazon Web Services (AWS) are the leading pack. Starting in early 2006, Amazon began to produce the infrastructure before its amazon.com site by selling access to a suite of APIs and web services. These services have become an immensely powerful, scalable, and highly available computing and service platform for anyone that needs cheap, instantaneous computing power or storage.

The core suite of AWS offerings of interest to a UNIX administrator include

+   EC2, the Elastic Compute Cloud — a platform for scalable computing. An EC2 "instance" is a server located on the Internet that runs an operating system of your choice and is under your complete control. You add and remove instances at will. EC2 is based on Xen, and many different operating systems are supported.
