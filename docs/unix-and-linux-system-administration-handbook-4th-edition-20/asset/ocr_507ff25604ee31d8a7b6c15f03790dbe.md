# Chapter 20 Electronic Mail

Another simple configuration is a "null client"; that is, a system that doesn't deliver any email locally but rather forwards outbound mail to a designated server. To implement this configuration, we define several parameters, starting with mydomain, which defines the domain part of the hostname, and myorigen, which is the mail domain appended to unqualified emails. If these two parameters are the same, we can write something like this:

```
```
mydomain = cs.colorado.edu
myorigen = $mydomain
```
```

Another parameter we should set is mydestination, which specifies the mail domains of all. If the recipient of a message is mydestination as its mail domain, the message is delivered through the local program to the corresponding user (assuming that no relevant alias or .forward file is found). If more than one mail domain is included in mydestination, these are all considered aliases for the same domain.

For a null client, we want no local delivery, so this parameter should be empty:

```
mydestination =
```

Finally, the relayhost parameter tells Postfix to send all nonlocal messages to a hosted instead of sending them directly to their apparent destinations:

```
relayhost = [mail.cs.colorado.edu]
```

The square brackets tell Postfix to treat the specified string as a hostname (DNS A record) instead of a mail domain (DNS MX record).

Since null clients should not receive mail from other systems, the last thing to do in a null client configuration is to comment out the smtpd line in the master.cf file. This prevents Postfix from running smtpd at all. With these few lines, we've defined a fully functional null client!

For a "real" mail server, you'll need a few more configuration options as well as some mapping tables. We cover these in the next sections.

# Use postfix

postfix is a handy tool that helps you configure Postfix. When run without arguments, it prints all the parameters as they are currently configured. If you name a specific parameter as an argument, postfix prints the value of that. The -d option makes postfix the defaults instead of the currently configured values. For example:

+   * postfix mydestination
mydestination =
* $ postfix -d mydestination
mydestination = $myhostname, localhost.$mydomain, localhost
