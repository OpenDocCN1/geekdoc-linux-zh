# Electronic Mail

Tons of Exim documentation are available on-line, as are a couple of books by the author of the software.

Googling for Exim questions often seems to lead to old, undated, and sometimes inappropriate materials, so check the official documentation first. A 400+-page specification and configuration document (doc/spec.txt) is included in the distribution. This document is also available from exim.org as a PDF file. Its definitive reference work for Exim is updated regularly with each new release.

There are two cultures with respect to Exim configuration: Debian and the world's. Debian adds m4 preprocessing and runs its own set of mailing lists to support users. We do not cover the Debian-specific configuration extensions.

Exim releases 4.70 and later have dropped support for DomainKeys (the precursor to DKIM) and now include DKIM support by default. Both systems can coexist in the real world, but DKIM is on the IETF standards track and will eventually replace DomainKeys.

Exim is like sendmail in that it is implemented as a process that performs all the mail. However, it does not carry all of sendmail's historical baggage (support for ancient address formats, needing to get to hosts on the Internet). When compiled with content scanning, it interfaces with spam and virus scanners via Assassin and ClamAV. Policy is implemented through ACLs (access control lists) that can accept or reject messages or pass them to external scanning software. Per-user filters are available through a special type of entry in users .forward files. Many aspects of Exim's behavior are specified at compile time, the examples being Debian's and message store formats.

The workhorses in the Exim system are all routers and transports. Both are included in the general category of "drivers". Routers decide how messages should be delivered, and transports decide on the mechanics of making deliveries. Routers are an ordered list of things to try, whereas transports are an unordered set of delivery methods.

# Exim installation

You can download the latest distribution from exim.org, or if you are a Linux user, from your favorite package repository. Refer to the top-level README and the file src/EDITME, where you must set locations, user IDs, and other parameters. EDITME is over 1,000 lines long, but it's mostly comments that lead you through the compilation process; required changes are well labeled. After your edits, save the file as ..Local/Makefile or ..Local/Makefile-osname (if you are building configurations for several different operating systems from the distribution) before you run make.
