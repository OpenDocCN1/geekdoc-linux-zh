# Exports in Linux

As AIX, the Linux /etc/exports file enumerates the filesystems exported through NFS and the clients that access each of them. Whitespace separates the filesystem from the list of clients, and each client is followed by a parenthesized list of comma-separated options. Lines can be continued with a backslash.

Here’s what format looks like:

```
/home             harp(rw,no_root_squash) monk(rw)
/usr/share/man    *.atrust.com(ro)
```

There is no way to list client specifications for a single set of options, although some client specifications refer to multiple hosts. Table 18.6 lists the type of specifications that can appear in the exports file:

| Type | Syntax | Meaning |
| --- | --- | --- |
| Hostname | hostname | Individual hosts |
| Netgroup | @groupname | NIS netgroups (not frequently used) |
| Wild cards | * and ? | FDNs with wild cards; " will not match a dot |
| IP networks | ipaddr/mask | CIDR-style specifications (e.g., 128.138.92.128/25) |
