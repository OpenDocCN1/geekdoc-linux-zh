# Chapter 8 Storage

In the /etc/fstab file, copy the line for an existing filesystem and adjust it. The device to be mounted is /dev/vgname/volume. If your existing fstab identifies volumes by UUID, replace the UUID=xxx clause with the device file; UUID identification is not necessary for LVM volumes.

Finally, run sudo mountpoint to mount the filesystem.

See page 224 for more details on Linux device files for disks. See page 236 for partitioning information and page 251 for logical volume management. The ext4 filesystem family is discussed starting on page 255.

# Solaris recipe

![](bbox=[0.168, 0.313, 0.238, 0.353])

Run sudo format and insert the name of known disks to identify the name of the new device. Let's say it c90d0. Type <Control-C> to abort.

Run zpool create poolname c90d0. Choose a poolname as “home” or “extra.” ZFS creates a filesystem and mounts it under /pool.

See page 225 for more details on device disks in Solaris. See page 264 for a general overview.

# HP-UX recipe

![](bbox=[0.178, 0.477, 0.238, 0.517])

Run sudo ioscan -fN -C disk to identify the device for the new disk; let's say they are /dev/disk4 and /dev/rddisk4.

Next, run the following command sequence, selecting appropriate names for the volume group (vgname), logical volume (volume), and mount point. (An example of reasonable choices: homevg, home, and /home).

```
# sudo pvcreate /dev/rddisk4             # Prepare for use w/LVM
# sudo vgcreate vgname/dev/disk4          # Create volume group
# sudo vgdisplay vgname                      # View VG stats
```

```
Free PE                               # Note this value
```

```
$ sudo lvcreate -L freespace -n volume vgname # Create logical volume
# sudo mkfs /dev/vgname/volume             # Create filesystem
# sudo mkdir mountpoint                   # Create mount point dir
# sudo vi /etc/fstab                       # Set mounting options
```

In the /etc/fstab file, copy the line for an existing filesystem and adjust it. The device to be mounted is /dev/vgname/volume.

Finally, run sudo mountpoint to mount the filesystem.

See page 225 for more details on HP-UX device disks. See page 251 for logical volume management information. The VxFS filesystem is discussed starting on page 256.
