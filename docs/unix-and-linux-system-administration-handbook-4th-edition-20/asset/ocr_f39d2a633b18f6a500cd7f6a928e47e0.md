# Chapter 24 Virtualization

The image name typically has a brief description to help you understand its purpose and configuration, but details are available in an on-line directory. To spin up the PHP quick start AMI from the list above, use the following command:

```
ubuntu$ ec2-run-instances ami-ba4eaa3 -k my-keypair
ubuntu$ ec2-describe-instances
RESERVATION r-56a053f default
INSTANCE i-1343fb7b ami-ba4eaa3 pending my-keypair 0
m1.small 2008-12-22T01:43:27+0000 us-east-1c
```

The ec2-describe-instances output reflects that the instance is still booting ("pending") and it's using the key pair set with the name my-keypair.

Import, the output shows that the instance is running in the us-east-1 availability zone. Amazon has segmented its systems into availability zones, so that a user who wants to guarantee that several instances run in physically separate data centers can request this on the main line. This value also be needed to attach an EBS volume.

Finally, the command shows that the instance type is m1.small. This code tells you the amount of resources available to the system. Amazon has defined standard profiles; m1.small is the default and includes a 32-bit EC2 CPU, 1.7GB memory, and 16GB of (nonpersistent) disk. Of course, the actual hardware your server runs probably looks nothing like this; it's just a way of describing your allocation.

Once the instance is running, any network ports you need to access must be authorized through another EC2 command, ec2-authorize:

```
ubuntu$ ec2-authorize default -p 22
```

In this case, port 22 (for SSH) is authorized for all hosts in the default group. (Groups are a mechanism for managing collections of instances. New instances are provisioned in the default group unless otherwise specified.) After you have authorized port 22, you can finally connect to your instance. To do so, find the first hostname, then SSH to it just as if there is another node on the Internet (because it is!)

```
ubuntu$ ec2-describe-instances
RESERVATION r-56a053f default
INSTANCE i-1343fb7b ami-ba4eaa3 ec2-67-202-245-235.compute-
m1.amazonaws.com domU-12-31-39-02-SE-55.compute.internal
runnym-my-keypair 0 m1.small 2008-12-22T01:43:27+0000
us-east-1c
```

```
ubuntu$ ssh -i -ssh/.ec2/id_rsa-my-keypair
root@ec2-67-202-245-235.compute-1.amazonaws.com
```

This command uses the key pair saved above to connect to the new instance's account. For security reasons, we recommend disabling SSH access.
