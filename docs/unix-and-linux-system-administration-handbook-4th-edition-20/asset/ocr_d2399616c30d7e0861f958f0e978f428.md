Set to 1 to forward source-routed packets; set to 0 to disable forwarding. If disabled, ICMP Destination Unreachable message is sent to the sender of source-routed packets being forwarded. [0,1] Default: 1

ndd's output claims that this version of HP-UX allows forwarding of source-routed packets. But that may be the kernel preference, but in fact the file/rc.config/ndddconf on our lab system disables this behavior:

```
TRANSPORT_NAME[2]=ip
dnd_NAME[2]=ip_forward_src_routed
dnd_VALUE[2]=0
```

The 2 here indicates the third of ten possible variables to be set in ndconf. For the next variable you wanted to change, you would add another copy of the same lines with appropriate values and with 3 instead of 2. Unfortunately, only 10 parameters can be set through ndconf.

To view and change the value of the ip_forward_src_routed variable by hand, use ndd-get and ndd-set (the syntax is slightly different from that on Solaris systems):

```
$ ndd -get /dev/ip ip_forward_src_routed
0
$ sudo ndd -set /dev/ip ip_forward_src_routed 1
$ ndd -get /dev/ip ip_forward_src_routed
```

# HP-UX security, firewalls, filtering, and NAT

Table 14.12 shows HP-UX's default behavior with regard to very touch network issues. For a brief description of the implications of these behaviors, see Security issues on page 242. You can modify most of them with ndd.

# Table 14.12 Security-related network behaviors in HP-UX

| Feature | Default | Control through ndd |
|---|---|---|
| IP forwarding | dynamic* | Set ip_forwarding: 0 = off, 1 = on, 2 = dynamic |
| ICMP redirects | obeys** | Set ip_redirect_interval to 0 to disable |
| Source routing | ignores | Set ip_forward_src_routed to 1 to enable |
| Broadcast ping (forward) | blocked | Set ip_forward_directed_broadcasts |
| Broadcast ping (respond) | ignores | Set ip_respond_to_echo_broadcast |

* a. With >1 network interface; otherwise.
** b. The redirect entries are entry preserved for five minutes.
