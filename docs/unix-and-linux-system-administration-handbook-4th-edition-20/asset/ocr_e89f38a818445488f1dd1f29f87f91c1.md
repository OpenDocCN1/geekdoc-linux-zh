# Chapter 14 TCP/IP Networking

The ROUTE_MASK variable is needed for a network in which the netmask differs from the default for the class of addresses used. The ROUTE_COUNT variable should be 0 if the gateway is the local machine and 1 if it is remote. To add more static routes, just enter their parameters to a set of ROUTE_ variables [1], [2], etc. These arguments are passed directly to the route command. For example, the destination parameter can be the word default as not netaddr or host hadaddr.

HP-UX supplies gated but not routed; to use gated, the variable GATED and GATED_ARGS to the arguments you wanted started with. See Chapter 15, Routing, for bit more information about gated. The HP-UX man on routing (man routing) contains a lot of background information.

Many fields in the netconf file contain either a hostname or an IP address. If a hostname is used, it must be defined in /etc/hosts. At boot time, HP-UX looks at /etc/hosts and does not use any other name lookup mechanism. The machines in /etc/hosts should have their fully qualified domain names listed first, followed by their short names and all aliases.

HP uses the ifconfig command to show information about the network interfaces on a machine. ifconfig does not work, or ifconfig does. Network interface names begin with "lan" or "snap": lan for Ethernet link-layer encapsulation and snap for IEEE 802.3 encapsulation. The first interface is lan0, the second is lan1, and so on.

HP-UX has the same sort of "plumbing" concept as Solaris does, but interfaces are automatically plumbed when they are assigned an IP address by ifconfig.

SMH is HP's system administration tool, which is aligned to make UNIX system administration a breeze. It is a menu-based system and can be used to configure network interfaces, as well as to perform many other sysadmin chores.

# HP-UX configuration examples

To bring up an HP-UX network interface and add a default route by hand, you'd use sudo commands as the following:

```
hp-ux$ sudo ifconfig lan 192.108.21.99 netmask 0xffffff0
hp-ux$ sudo route add default 192.108.21.254 1^0
```

HP's lancan command lists the network interfaces in the system and the characteristics of the device driver that controls them. lscan -v shows slightly more information.
