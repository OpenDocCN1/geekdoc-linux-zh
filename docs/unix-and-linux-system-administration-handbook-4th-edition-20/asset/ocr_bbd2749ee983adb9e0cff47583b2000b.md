# DNS configuration

To configure a machine as a DNS client, you need only set the /etc/resolv.conf file. DNS is not, strictly speaking, required (see page 739), but to imagine a situation in which you want to eliminate it.

The resolv.conf file lists the domains that should be resolved names that are incomplete (that is, not fully qualified, as anchor instead of anchor.cs.colorado.edu) and the IP addresses of the name servers to contact for name lookups. A sample is shown here; for more details, see page 561.

```
search cs.colorado.edu
nameserver 128.138.242.1
nameserver 128.138.243.151
nameserver 192.108.21.1
```

/etc/resolv.conf should list the "closest" stable name server first. Servers are contacted in order, and the timeout after the next server in line is tried can be quite long. You can have up to three nameserver entries. If possible, you should always have more one.
