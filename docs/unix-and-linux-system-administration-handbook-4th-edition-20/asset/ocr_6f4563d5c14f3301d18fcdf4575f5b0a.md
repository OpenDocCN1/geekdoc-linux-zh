cron -e checks out a copy of your crontab, invokes your editor on it (as speci-

directory. crontab -l lists the contents of your crontab to standard output,

Root can use a username to edit or view other users' crontabs. For
example, crontab -r jsmith erases the crontab belonging to the user jsmith,
cron -e edits it. Linux allows both a username and a filename argument
the same command, so crontab must be prefixed with -u to disambuate
(e.g., crontab -u jsmith crontab.new).

Without command-line arguments, most versions of crontab will try to read
from standard input. If you enter this by accident, doing so will try to exit
with <Control-D>; instead. Linux requires you to supply a dash as the filename argument if you want
cake pay attention to its standard input. Smart.
