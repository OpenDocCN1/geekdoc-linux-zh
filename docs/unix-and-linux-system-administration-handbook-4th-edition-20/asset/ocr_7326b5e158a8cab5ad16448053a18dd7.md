# 5.13 EXERCISES

+   E5.1 Explain the relationship between a file's UID and effective UID. Before file access control, what is the purpose of a process's effective UID?

+   E5.2 Suppose that a user at your site has started a long-running process that is consuming a significant fraction of your machine's resources.
a) How would you recognize a process that is hogging resources?
b) Assume that the misbehaving process might be legitimate and doesn't deserve to die. Show the commands you would use to suspend the process temporarily while you investigate.
c) Later, you discover that the process belongs to your boss and must continue running. Show the commands you'd use to resume the task.

+   d) Additionally, assume that the process needs to be killed. What signal would you send, and why? What if you needed to guarantee that the process died?

+   E5.3 Find a process with a memory leak (write your program if you don't have one). Use ps or top to monitor the process memory usage as it runs.

+   E5.4 Write a perl script that processes the output of ps to determine the total VSZ and RSS of the processes running on the system. How do these numbers relate to the system's actual amount of physical memory and swap space?
