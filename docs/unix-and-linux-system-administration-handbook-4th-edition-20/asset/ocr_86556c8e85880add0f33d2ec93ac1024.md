# Chapter 8 Storage

See Chapter 18 for more information about NFS.

The first field gives the device name. The fstab file can include mounts from remote systems, in which case the first field contains an NFS path. The notation server:/export indicates the /export directory on the machine server.

The second field specifies the mount point, and the third field names used to identify local filesystems varies among machines.

The fourth field specifies mount options to be applied by default. There are many possibilities; see the man page for mount for the ones that are common to all filesystem type. Individuals usually introduce options of their own. The options shown above are specific to VxFS. For example, the delayog sacrifices some reliability for speed. See the mount_vxfs man page for more information about this and other VxFS mounts.

The fifth and sixth fields are vestigial. They are supposedly a "dump frequency" and a column used to control fsck parameter. Neither is important on contemporary systems.

Below are some additional examples culled from an Ubuntu system fstab. The general format is the same, but Linux systems show some additional flourishes.

| /proc proc defaults 0 0 |
| UUID=a8e3..b8df8 / ext4 errors=remount-ro 0 1 |
| UUID=13e9..b8d2 none swap sw 0 0 |
| /dev/scd0 /media/cdrom0 user.iso9660 user_naauto,exec_utf8 0 0 |
| /dev/scd1 /media/cdrom1 user.iso9660 user_naauto,exec_utf8 0 0 |
| /dev/fd0 /media/floppy auto rw,user_naauto,exec_utf8 0 0 |

![](bbox=[0.19634000000000001, 0.42397, 0.239, 0.46612])

The first line indicates the /proc filesystem, which is in fact presented by a kernel driver and has no active backing store. The proc device listed in the first column is just a placeholder.

The second and third lines use partition ID (UUIDs), which we've truncated to make the excerpt more readable instead of device names to identify values. This alternative is useful on Linux systems where the device names of disk partitions are unstable; adding or removing a dev can cause all the others to change (e.g., from /dev/sd1 to /dev/sdc). The UUID is linked only to the content of the partition, so it allows the partition to be tracked wherever it might be hiding. Note that this convention works for the swap partition as well as the root.

The last three lines configure support for CD-ROM and floppy disk devices. noauto prevents the system from mounting these devices at boot time (If no media were inserted, the mount would fail and prolong the boot process.) The user option makes all the files on removable drives appear to be owned by the user who mounts them.
