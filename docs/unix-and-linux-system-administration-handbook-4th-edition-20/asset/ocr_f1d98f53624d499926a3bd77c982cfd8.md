# Automating installation with the Ubuntu installer

with a database of premoldulated answers, you fully automate the installer. You can either generate the database by hand (it's a text file), or you can perform an interactive installation on an example system and dump out your debconf answers with the following commands:

```
ubuntu$ sudo debconf-get-selections --installer > preseed.cfg
ubuntu$ sudo debconf-get-selections >> preseed.cfg
```

Make the config file available on the net and then pass it to the kernel installation with the following kernel argument:
preseed/url=http://host/path/to/preseed

The syntax of the preseed file, usually called preseed.cfg, is simple and reminiscent of Red Hat's ks.cfg. The sample below has been shortened for simplicity.

+   -d debian-installer/locale string en_US
-d console-setup/ask_detect boolean false
-d console-setup/layoutconfigure string
-d netcfg/choose_interface select auto
-d netcfg/get_hostname string unassigned-hostname
-d netcfg/get_domain string unassigned-domain
-d netcfg/wireless_webp string

+   -d partman-auto/disk string /dev/sda
-d partman-auto/method string lvm
-d partman-auto/choose_recipe select atomic
...

+   -d password/user-filename string Duffy Duck
-d password/username string dduck
d$1$/mk9$G$/it6N.x6670.951VSM/
-d user-setup/enter-home boolean false
tasksel/first/multiselect ubuntu-desktop
d-d grub-installer/only_debian boolean true
d-d grub-installer/with_other_os boolean true
d-d finish-install/reboot_in_progress note
xserver-org xserver-org/autodetect_monitor boolean true

Several options in this list display simple dialogs that would normally require user interaction. For example, the ask_detect disables keymap selection. Similarly, the wireless_webp fetches a question about WEP keys.

This configuration identifies a network interface that's connected to a network (choose_interface select auto) and obtains network information through DHCP. The system hostname and domain values are presumed to be provided by DHCP and are not overridden.

The partman* are evidence that the partman-auto package is used for disk partitioning. You must specify a disk to install unless the system has only one. In this case, /dev/sda is used.
