The AWS site connects the account signup pages and all the necessary downloads. To start using AWS, download the command-line tools and the access identifiers, which consist of a certificate and a private key.

Make a directory ~/.ec2 and move the downloaded certificate file, key, and extracted tools to that directory. All EC2 commands will reside in ~/.ec2/bin, with library dependencies in ~/.ec2/lib. To set up the environment for easy use, add the following to your shell's login script. (For bash, this is ~/.bash_login or ~/.bash_profile).

```
export EC2_HOME=/.ec2
export PATH=$EC2_HOME/bin
export EC2_PRIVATE_KEY=$EC2_HOME/<long string value>.pem
export EC2_CERT=$EC2_HOME/cert-<long string value>.pem
export JAVA_HOME=/path/to/java
```

Finally, choosing an image and starting it, create a key pair that allows you to gain access to the image. The ec2-add-keypair command creates a new key pair. Any images that created will automatically be configured to use the new public key for SSH authentication to the root account.

This will be needed in the future, so save everything the line beginning KEYPAIR to a file in the ~/.ec2 directory and make sure the permissions are 600. Never share the private key file—it contains the keys to the cloud kingdom!

Now it's time to choose an AMI. There is an enormous number of AMIs to choose from, many created by Amazon and many contributed (or) by the community. It's also possible to build a custom AMI for private use, possibly configured with the particulars of your environment or preinstalled with all your needed applications.

After choosing an image, note its identifier. The command below lists the AMIs created by Amazon. Having added the tools directory to the PATH variable, you can execute EC2 commands whenever.

```
ubuntu ec2-describe-images -o amazon
IMAGE ami-ba4aea3 /aws/quickstart/phpquickstart.manifest.xml
amazon available public 1386 machine
IMAGE ami-b4bafdd /aws/quickstart/rubyquickstart.manifest.xml
amazon available public 1386 machine aki-a17cf9c2 ari-a51cf9cc
IMAGE ami-1c54b075 /aws/quickstart/tomcatquickstart.manifest.xml
amazon available public 1386 machine aki-a17cf9c2 ari-a51cf9cc
```
