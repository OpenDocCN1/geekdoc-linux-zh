Let's look at our example shadow line:

```
millert:$md5em5j8hl$aIQ3pXe0sakadRaRFyyt7Ppj::1446:0:180:::
```

In this example, the user millert changed his password on August 13, 2009,
The password must be changed within 180 days, and millert will receive
warnings that the password needs to be changed for the last two weeks of this
period. The account does not have an expiration date.

On Solaris, HP-UX, and Linux you can use the pwconv to reconcile the
contents of the shadow file to the passwd file, picking up any add-
deleting that are no longer listed in passwd. Linux, pwconv
mills of the shadow parameters from defaults defined in /etc/login.defs.

Root on Solaris can use the command -f username to force a user to
change his or password at the next login. This feature is useful if you
regularly run crack to discover poorly-chosen (insecure) passwords. (Under Li-
ux, that -f flag lets users change their finger information.)

AIX does not use the shadow passwords, but it does use the same.
AIX's encrypted passwords are stored in the /etc/security/passwd in a totally
different format from that of the /etc/passwd file. Here's an example from a
AIX install, where the password algorithm defaults to crypt?

trent:

```
password = u10.YaXRx4ql
lastupdate = 1224876639
flags = ADCMCH
```

```
password = Plir2gOPabZ.Q
lastupdate = 1235785246
flags =
```

The format should be self-explanatory. One or more blank lines separates entries.
This same format is used for AIX configuration files in /etc/security,
the username generalized to whatever object is being controlled or logged.

AIX provides a zillion controls to control all aspects of login and passwords. Some
options are user oriented and are port oriented (to control the TTY ports on
by a given user can log in). See the comments in /etc/security/login.cfg and
/etc/security/user for details. One handy command is pwadm, which lets you
force a user to change his or password at next login.

+   Changing to a stronger encryption algorithm should be high on your to-do list for AIX boxes.
