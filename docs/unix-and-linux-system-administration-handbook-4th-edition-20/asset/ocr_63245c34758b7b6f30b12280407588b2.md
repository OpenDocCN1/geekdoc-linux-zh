The most widely used solution to these problems is a program sudo that is currently maintained by Todd Miller. It runs on all of our example systems and is also available in source code form from sudo.ws.

Solaris pfexec command implements a facility similar to sudo that is based on Solaris's own RBAC system.

sudo takes as its argument a command line to be executed as root (or another restricted user). sudo conducts the file /etc/sudoers, which lists the people who are authorized to use sudo and the commands they are allowed to run on each host. If the password is permitted, sudo prompts for the user's password and executes the command.

Additional sudo commands can be executed without the "sudo" having to type a password until a five-minute period (configurable) has elapsed with no sudo activity. This timeout serves as a modest protection against users with privileges who leave terminals unattended.

sudo keeps log of the command lines that were executed, the hosts on which they run, the people who requested them, the directory from which they were run, and the times at they were invoked. This information can be logged by syslog or placed in the file of your. We recommend using syslog to forward the log entries to a secure central host.

A log entry for running executing sudo /bin/cat /etc/sudoers might look like this:

```
Dec 27 10:57:19 sudo TTY=ttyp0 PWD=tigger/users/rand;
USER=root; COMMAND=/bin/cat /etc/sudoers
```

The sudo files are designed so that a single version can be used by many different hosts at once. Here's a typical example:

+   * Define aliases for machines in CS & Physics departments
Host_Alias CS = tigger, anchor, piper, moer, sigi
Host_Alias PHYSICS = eprince, icarus
* Define collections of commands
Cmnnd_Alias DUMP = /sbin/dump, /sbin/restore
Cmnnd_Alias PRINTING = /usr/bin/lpc, /usr/bin/lprm
Cmnnd_Alias SHELLS = /bin/sh, /bin/tcsh, /bin/bash, /bin/ksh, /bin/bash
* # Permissions
mark, ed PHYSICS = ALL
herb CS = /usr/bin/tcpdump PHYSICS = (operator) DUMP
lynda ALL = (ALL), SHELLS
%wheel ALL=(ALL), PHYSICS = NOPASSWORD: PRINTING
