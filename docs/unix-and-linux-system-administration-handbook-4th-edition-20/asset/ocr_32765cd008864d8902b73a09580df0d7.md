# Exim installation

```
BIN_DIRECTORY=/usr/exim/bin          # Where the exim binary lives
SPOOL_DIRECTORY=/var/spool/exim             # Mail spool directory
CONFIGURE_FILE=/usr/exim/configure           # Exim's configuration file
SYSTEM_ALIASES_FILE=/etc/aliases           # Location of aliases file
EXIM_USER=ref:exim                           # User to run as root chores

ROUTER_ACCEPT=yes                          # Router to include
ROUTER_DNSLOOKUP=yes
ROUTER_IPLITERAL=yes
ROUTER_MANUAL_ROUTE=yes
ROUTER_QUERY_PROGRAM=yes
ROUTER_REDIRECT=yes

TRANSPORT_APPENDDEFILE=yes                    # Transport to include
TRANSPORT_AUTOREPLY=yes
TRANSPORT_PIPE=yes
TRANSPORT_SMTP=yes
```

```
SUPPORT_MAILDIR=yes               # Mailbox formats to understand
SUPPORT_MAILSTORE=yes
SUPPORT_MBX=yes
```

```
LOOKUP_DBM=yes                   # Database lookup methods to include
LOOKUP_SEARCH=yes                           # Linear search lookup
LOOKUP_DNSDB=yes                            # Allow arbitrary DNS lookups
LOOKUP_CDB=yes                               # Dan Bernstein's DB lookups
                                              # Use Berkeley DB (from README)
USE_DB=yes                                   # (from README)
DBMLIB=ldap                                 # Include content scanning via ACLs
WITH_CONTENT_SCAN=yes
```

```
EXPERIMENTAL_SPF=yes               # Include SPF support, needs libspf2
CFLAGS=-/usr/local/include                   # From with libspf2
LDFLAGS=-spf2
```

```
LOG_FILE_PATH=/var/log/exim_%slog      # Log files: file, syslog, or both
LOG_FILE_PATH=syslog                          %slog
LOG_FILE_PATH=/var/log/exim_%slog
EXICYCLOG_MAX=10                              # Compress/cycle log files, keep them to
```

Routers must be compiled to include the code that you intend to use. In these days of large memories, you might well as leave them in all. Default paths are certainly nonstandard: for example, the binary in /usr/exim/bin and the PID file in /var/spool/exim. You might want to tweak these values to match other installed software.

About database lookup methods are available, including MySQL, Oracle, CDB,¹ and LDAP. If you include LDAP, you must specify the LDAP_TYPE variable to tell what LDAP library you are using (the options are Netscape, Solaris, and a couple of versions of OpenLDAP). You may also need to specify the path to LDAP include files and libraries.

+   CDB is Dan Bernstein's constant database system; it scales well.
