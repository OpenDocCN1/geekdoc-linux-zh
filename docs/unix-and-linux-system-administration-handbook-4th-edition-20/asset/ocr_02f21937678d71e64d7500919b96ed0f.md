# Red Hat network configuration

Table 14.7 SUSE network configuration files in /etc/sysconfig/network

| File | What's set here |
| --- | --- |
| ifcfg-interface | Hostname, IP address, netmask, and more |
| ifroute-interface | Interface-specific route definitions |
| routes | Default route and static routes for all interfaces |
| config | Lots of less commonly used network variables |

With the exceptions of DNS parameters and the system hostname, SUSE sets most networking options in ifcfg-interface files in the /etc/sysconfig/network directory. One file should be present for each interface on the system.

In addition specifying the IP address, gateway, and broadcast information for an interface, the ifcfg-* file can tune many network details. Take a look at the ifcfg.template for a well-commented rundown of the possible parameters. Here is a simple example with:

```
PROTO='static' # Static is implied but it doesn't hurt to be verbose.
IPADDR='192.168.1.24' # The /24 defines the NETWORK and NETMASK VAR
NAME='AMD PCnet - Fast 79C91' # Used to start and stop the interface.
STARTMODE='auto' # Start at boot
USERCONTROL='no' # Disable control through internet/netminer GUI
```

Global static routing information for a SUSE system (including the default route) is stored in the routes files. Each line in this file is like a route command with the option names omitted and includes stored in the routing table for use by routing daemons. Extra parameters to be stored in the routing table for use by the host configured above, which has only a default route, the routes file contains the line

```
default 192.168.1.254 -
```

Routes to specific interfaces are kept in ifroute-interface files, where the nomenclature of the interface component is the same as for the ifcfg-* files. The contents have the same format as the routes file.

# Red Hat network configuration

Red Hat's network configuration GUI is also system-config-network; it's also accessible from the System->Administration menu under the network Name. This tool provides a UI for configuring individual network interfaces and static routes. It also has panels for setting up IPsec tunnels, configuring DNS, and adding /etc/hosts entries.
