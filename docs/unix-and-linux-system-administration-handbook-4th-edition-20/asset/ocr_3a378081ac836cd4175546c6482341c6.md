# 31.9 SPECIAL CHARACTERS AND THE TERMINAL DRIVER

The terminal driver supports several special functions that you access by typing particular keys (usually control keys) on the keyboard. The exact binding of functions to be set with the set and stty commands. Table 31.6 lists some of these functions, along with their default keys.

# 31.6 Special characters for the terminal driver

| Name | Default? | Function |
|---|---||
| erase | <Control-?> | Erases one character of input |
| werase | <Control-W> | Erases one word of input |
| kill | <Control-U> | Erases the entire line of input |
| eof | <Control-D> | Sends an 'end of file' indication |
| intr | <Control-C> | Interrupts the currently running process |
| quit | <Control-X> | Kills the current process with a core dump |
| stop | <Control-S> | Stops output to the screen |
| start | <Control-Q> | Restarts output to the screen |
| susp | <Control-Z> | Suspends the current process |
| Innext | <Control-V> | Interprets the next character literally |

Depending on what a vendor's keyboards look like, the default for ERASE might be either <Control-H> or the delete character. (The actual key may be labeled "backspace" or "delete", or it may show only a backarrow glyph.) Unfortunately, the existence of two different standards for this function creates multiple problems.

You can use stty erase (the next section) to tell the terminal driver which key you set is actually generating. However, some programs (such as editors and shells with command-editing features) have their own idea of what the backspace character should be, and they don't always pay attention to the driver's setting. In a helpful but confusing twist, some programs obey the backspace and delete characters. You may also find that systems you log in through the network make different assumptions from those of your local system.

Solving these annoying conflicts can be a Sunday project in itself. General, there is no simple, universal solution. Each piece of software must be individually beaten into submission. Two useful resources to help with this are the Linux Backspace/delete mini-HOWTO from tldp and a nifty article by Anne Baretta at ibbt/~anne/keyboard.html. These notes are written from a Linux-perspective, but the problem (and solutions) are not limited to Linux.
