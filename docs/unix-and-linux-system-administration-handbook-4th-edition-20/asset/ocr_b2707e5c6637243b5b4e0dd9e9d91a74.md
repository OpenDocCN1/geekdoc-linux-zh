In addition to CPU information, **sar** can also report on other metrics such as disk and network activity. Use **sar -d** for a summary of this day's disk activity or **sar -n DEV** for network interface statistics. **sar** -reports all available information.

sar has some limitations, but it is a good bet for quick-and-dirty historical information. If you're serious about making a long-term commitment to performance monitoring, we suggest that you set up a data collection and graphing platform like Cacti. Cacti tools us from the network monitoring, but it can actually aggregate system metrics as CPU and memory information. See page 886 for additional comments on Cacti and an example of the graphs it is capable of producing.

# nmon and nmon_analyser: monitor in AIX

![](bbox=[0.173, 0.506, 0.223, 0.545])

On AIX systems, **nmon** is the monitoring tool of choice. It is similar to **sar** in many ways.

Stephen Atkins of IBM developed a super-spreadsheet **nmon_analyser** that processes the data collected by **nmon**. It's great for producing cleaned-up data as well as for creating performance graphs. It analyzes data with more sophistication than **sar**. For example, it can calculate weighted averages for hot-spot-analysis and can integrate IBM and EMC disk performance information. Although **nmon_analyser** is not officially supported by IBM, you can find it at

ibm.com/developerworks/aix/library/au-nmon_analyser

# Choosing a Linux I/O scheduler

![](bbox=[0.203, 0.731, 0.243, 0.771])

Linux systems use an I/O scheduling algorithm to mediate between processes competing for disk I/O. The I/O scheduler massages the order and timing of disk requests to provide the best possible overall I/O performance for a given application or situation.

Four scheduling algorithms are available in the Linux 2.6 kernel. You can pick yours. Unfortunately, the scheduling is set at boot time (with the **elevator=algorithm** kernel argument), so it's not easy to change. The system's scheduling algorithm is usually specified in the GRUB boot loader's file, **grub.conf**.
