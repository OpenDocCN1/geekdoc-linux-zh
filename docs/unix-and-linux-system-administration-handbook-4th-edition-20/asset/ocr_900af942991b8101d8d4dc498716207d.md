To configure a virtual interface, just run ifconfig on one of the virtual names. (The underlying physical interface may already have been "plumbed).\ In most cases, you will want to set up the system so that the ifconfigs for virtual interfaces happen at boot time.

Here is an example in which a Solaris machine has an in address space on an internal virtual private network (VPN) and an external address for the Internet, both associated with the same physical interface, hme0. To have these interfaces configured automatically at boot time, the administrator will have two hostname files: /etc/hostname.hme0 and /etc/hostname.hme0:1.

```
$ ls -l /etc/hosts
-rw-r-r-- 1 root 10 Nov 4:19 /etc/hostname.hme0
-rw-r-r-- 1 root 16 Dec 21 19:34 /etc/hostname.hme0:1
```

Hostname files can contain either hostnames from /etc/hosts file or IP addresses. In this case, the administrator has used one of each:

```
$ cat /etc/hostname.hme0
overkill
$ cat /etc/hostname.hme0:1
206.0.1.133
$ grep overkill /etc/hosts
10.1.2.9 overkill overkill.domain
```

At boot time, addresses are automatically configured (with the loopback address, which we omitted from the output below):

```
$ ifconfig -a
hme0: flags=86<UP,BROADCAST,NOTRAILERS,RUNNING,MULTICAST> mtu
1500 10.1.2.9 netmask fffff0 broadcast 10.1.2.255
hme1: flags=86<UP,BROADCAST,NOTRAILERS,RUNNING,MULTICAST> mtu
1500 206.0.1.133 netmask ffffffe0 broadcast 206.0.1.255
```

# HP-UX virtual interfaces

On HP-UX, you add virtual interfaces with the ifconfig command. The syntax is very similar to that of Solaris. For example, to add the first interface, you would execute the command

```
$ sudo ifconfig lan01 192.168.1.3 up
```

# AIX virtual interfaces

On AIX, you create an "alias" to add additional IP addresses to an interface. For example, to add 192.168.1.3 as a virtual IP address for the en0 interface, you can use ifconfig:

```
$ sudo ifconfig en0 192.168.1.3 netmask 255.255.255.250 alias
```
