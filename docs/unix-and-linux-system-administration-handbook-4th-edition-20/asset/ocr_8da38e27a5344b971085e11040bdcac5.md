# 31.3 HARD AND SOFT CARRIER

UNIX expects to get the DCD signal, carrier detect, go high (positive voltage) when a serial device is attached and turned on. If your serial cable is a DCD line and your computer really pays attention to it, you are using what is known as hard carrier. Most systems also allow soft carrier; that is, the carrier pretends that DCD is always asserted.

For certain devices (such as traditional hardware terminals), soft carrier is a great blessing. You can get away with using only three wires for each serial connection: transmit, receive, and signal ground. However, modern connections really need the DCD signal. If a terminal is connected to a modem and the carrier signal is lost, the modem should hang up (especially on a long distance call).

You can specify soft carrier for a serial port in the configuration file for whatever client you use in conjunction with the port (e.g., gettydefs or initab for a login terminal or printcap for a printer). You can also use stty -clocal to enable soft carrier on the fly.
