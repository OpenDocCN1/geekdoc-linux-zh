# 20.1 MAIL SYSTEMS

In theory, a mail system consists of several distinct components:

+   * A "mail user agent" (MUA or UA) that lets users read and compose mail
* A "mail submission agent" (MSA) that accepts outgoing mail from an MUA, grounds it, and submits it to the transport system
* A "mail transport agent" (MTA) that routes messages among machines local message store
* A "delivery agent" (DA) that places A in a local message store
* An optional "access agent" (AA) that connects the user to the message store (e.g., through the IMAP or POP protocol)

Attached to some user agents are tools for recognizing spam, viruses, and (outbound) internal company secrets. Exhibit A illustrates how the various pieces together as a message winds its way from sender to receiver.

# User agents

Email users employ a user agent (sometimes called an email client) to read and compose messages. Email messages originally consisted only of text, but a standard known as Multipurpose Internet Mail Extensions (MIME) is used to encode text formats (including viruses) into email. It is supported by most user agents. Since MIME generally does not affect the addressing or transport of mail, we do not discuss it further.
