# Chapter 8 Storage

After defining the disk as a physical volume, you add it to a new volume group with the vgcreate command. Two metadata formats exist for volume groups, versions 1.0 and 2.0. You specify which version you want with the -V option when creating a volume group; version 1.0 remains the default. 2.0 has higher size limits, but it is not usable for boot devices or swap volumes. Even version 1.0 metadata has generous limits, which should be fine for most uses. You can see the exact limits with lvsdm. For reference, here are the limits for 1.0:

```
$ lvsdm -t -V 1.0
--- LVM Limits ---
VG Version 1.0
Max VG Size (Tbytes) 510
Max LV Size (Tbytes) 16
Max PV Size (Tbytes) 2
Max VGs 256
Max LVs 255
Max PVs 255
Max Mirrors 2
Max Stripes 255
Max Stripe Size (Kbytes) 32768
Max LXs per LV 65535
Max PXs per PV 65535
Max Extent Size (Mbytes) 256
```

You can add extra disks to a volume group with vgxtend, but this example volume group contains only a single disk.

```
$ vgcreate vg01 /dev/disk/disk4
Increased the number of physical extents per physical volume to 17501.
Volume group "dev/vg01" has been successfully created.
Volume configuration for /dev/vg01 has been saved in
/etc/lvmconf/vg01.conf
```

Once your disks are added to a convenient volume group, you can split the volume group's pool of disk space back into logical volumes. The lvcreate command creates a new logical volume. Specify the size of the volume in megabytes with the -L flag or in logical extents (typically 4MiB) with the -L flag. Sizes specified in MiB are rounded up to the nearest multiple of the logical extent.

To assess the amount of free space remaining in a volume group, run vgdisplay volume as root. The output includes the extent size and the number of unallocated extents.

```
$ lvcreate -L 25000 -n web1 vg01
Logical volume "dev/vg01/web1" has been successfully created with character device "dev/vg01/rwe1".
Logical volume "dev/vg01/web1" has been successfully extended.
Volume Group configuration for /dev/vg01 has been saved in
/etc/lvmconf/vg01.conf
```
