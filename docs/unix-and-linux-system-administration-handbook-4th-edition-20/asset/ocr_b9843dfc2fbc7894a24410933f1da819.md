Note :443 after the IP address and the SSL directives that tell Apache where to find your private key and signed certificate.

When you restart Apache, you will be asked to enter the passphrase for your server.key file. Because of this interaction, httpd can no longer start up automatically when the machine is booted. If you want, you can remove the encryption from your private key to circumvent the need to enter a password:

```
$ cp server.key server.key.org
$ openssl ra -in server.key.org -out server.key
$ chmod 400 server.key server.key.org
```

Of course, anyone who obtains a copy of your unencrypted key can impersonate your site.

For more information about SSL, see the following resources:

```
http://apache.org/docs-2.2/ssl/ssl_faq.html
http://apache.org/docs/2.2/mod/mod_ssl.html
```

# 23.5 CACHING AND PROXY SERVERS

The Internet and the information on it are still growing rapidly. Ergo, the bandwidth and computing resources to support it are growing rapidly as well. How can this state of affairs continue?

The only way to deal with this growth is to use replication. When it's on a national, regional, or site level, Internet content needs to be more readily available from a closer source as the Internet grows. It doesn't make sense to transmit the same popular web page from Australia across a very expensive link to North America millions of times each day. There should be a way to store this information once it's been sent across the link once.

Fortunately, there is—at least at the site level. A proxy lets you cache and manage your outbound requests for web content.

Here's how it works. Web browsers connect the proxy server to request an object from the Internet. The proxy server makes a request on the client's behalf (or provides the object from its cache) and returns the result to the client. Proxy servers of this type are often used to enhance security or to filter content.

In a proxy-based system, only one machine needs access to the Internet through the organization's firewall. At organizations as K–12 schools, a proxy server can also filter content so that inappropriate material doesn't fall into the wrong hands. Many commercial and freely available proxy servers are available today. Some of these systems are purely software based, and others are embedded in a hardware appliance. An extensive list of proxy server technologies can be found at web-caching.com/proxy-caches.html.
