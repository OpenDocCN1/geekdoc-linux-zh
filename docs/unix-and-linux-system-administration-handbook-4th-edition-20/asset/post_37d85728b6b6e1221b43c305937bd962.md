## 14.11 SYSTEM-SPECIFIC NETWORK CONFIGURATION

On early UNIX systems, you configured the network by editing the system startup scripts and directly changing the commands they contained. Modern systems have read-only scripts; they cover a variety of configuration scenarios and choose among them by reusing information from other system files or configuring their own.

Although this separation of configuration and implementation is a good idea, every system does it a bit differently. The format and use of the /etc/hosts and /etc/resolv.conf files are relatively consistent among UNIX and Linux systems, but that’s all you can count on for.

Most systems provide some sort of GUI interface for basic configuration tasks, but the mapping between the visual interface and the configuration behind the scenes is often unclear. In addition, the GUIs tend to ignore advanced configurations, and they are relatively inconvenient for remote and automated administration. ## Ubuntu network configuration

As shown in Table 14.6, Ubuntu configures the network in /etc/hostname and /etc/interfaces, with a bit of help from the file /etc/network/options.

Table 14.6 Ubuntu network configuration files in /etc

| File | What's set here |
| --- | --- |

The hostname is set in /etc/hostname. The name in this file should be qualified; its value is used in a variety of contexts, some of which require qualification.

The IP address, netmask, and default gateway are set in /etc/interfaces. A line starting with the iface keyword introduces each interface. The iface line can be followed by indented lines that specify additional parameters. For example:

```
auto eth0
if lo inet loopback
ace eth0 inet static
    address 192.168.1.10
    netmask 255.255.255.0
    gateway 192.168.1.254
```

The ifup and ifdown command read this file and bring the interfaces up or down by calling lower-level commands (such as ifconfig) with the appropriate parameters. The auto clause specifies the interfaces to be brought up at boot time or when ifup -a is run.

The inet keyword in the iface line is address family a inet. The keyword static is a "method" and specifies that the IP address and netmask for eth0 are directly assigned. The address and netmask lines are required for static configuration; earlier versions of the Linux kernel also required the network address to be specified, but now the kernel is smarter and can figure out the network address from the IP address and mask. The gateway line specifies the address of the default gateway and is used to install a default route.
