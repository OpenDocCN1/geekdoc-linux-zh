Now that we've elaborated the basics of rdist, let's look at how it works. Like make, rdist looks for a control file (Distfile or distfile) in the current directory. rdist -f distfile specifies the control file's name. Within the control file, tabs, spaces, and newlines are used interchangeably as separators. Commands are introduced with a pound sign (#).

The meat of a Distfile consists of statements of the form

```
label: pathnames -> destinations commands
```

The label field associates a name with the statement. From the shell, you can rdist label distribute only the files described in a particular statement.

The pathnames and destinations are lists of files to copy and hosts to copy them, respectively. If a list contains more than one entry, the list must be surrounded with parentheses and the elements separated by whitespace. The pathname can include shell-style globbing characters (e.g., /usr/man/man[123] or /usr/lib/*). The notation -user is also acceptable, but it is evaluated separately by source and destination machines.

By default, rdist copies the files and directories listed in pathnames to the each destination machine. You can modify this behavior by equivalently a sequence of commands and terminating each with a semicolon.

The following commands are understood:

+   - install options [destdir];
otify namelist;
except pathlist;
except_pat patlist;
special [pathlist] string;
cmdspecial [pathlist] string;

The install command options affect the way rdist copies files. Options typically control the treatment of symbolic links, the correctness (vs. efficiency) of rdist's difference-checking algorithm, and the way that deletions are handled. The options, which must be preceded by -o, consist of a comma-separated list of options. For example, the line

```
install -oremove,follow;
```

makes rdist follow symbolic links (instead of just copying them as links) and removes existing files on the destination machine that have no counterpart on the source machine. See the rdist man page for a complete list of options. The defaults are always what you want.
