# Where to Start

Excerpts from configuration files and terminal sessions are shown in a fixed-width font. Sometimes, we annotate sessions with italic text. For example:

```
$ grep Bob /pub/phonelist  # Look up Bob's phone number
Bob Knows 555-2834
Bob Smith 555-2311
```

Outside of these specific cases, we have tried to keep special fonts and formatting conventions to a minimum as long as we could do without compromising intelligibility. For example, we often talk about entities such as the daemon group or the printer-lw with no special formatting at all.

We use the same conventions as the manual pages for command syntax:

+   - Anything between square brackets (““ and ””) is optional.
- Anything followed by an ellipsis (“...”) can be repeated.
- Curly braces (““ and ””) mean that you should select one of the items separated by vertical bars (“|”).

For example, the specification

```
bark -x |on|off| filename ...
```

would match any of the following commands:

```
bark on /etc/passwd
bark -x off /etc/passwd /etc/smartdmarc
bark off /usr/lib/tmac
```

We use shell-style globbing characters for pattern matching or more characters.

+   - A star (*) matches one character.
- A question mark (?) matches the home directory of the current user.
- A tilde (~) means the home directory of the current user.
- ~user means the home directory of.

For example, we refer to the startup script directories /etc/rc0d, and /etc/rc1d, and so on with the shorthand pattern /etc/rc2.

Text within quotation marks often has a precise technical meaning. In these cases, we ignore the normal rules of U.S. English and punctuation outside the quotes so that there be no confusion about what's included and what's not.
