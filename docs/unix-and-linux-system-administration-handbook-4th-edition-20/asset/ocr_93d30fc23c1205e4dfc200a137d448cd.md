# Add-on modules for Perl

Perl's **-a** option on autosplit, which separates input lines into fields that are stored in the array named @F. Whitespace is the default separator, but you can set another separator pattern with the **-F** option.

Autosplit is handy to use in conjunction with **-p** or its nonautoprinting variant, **-n**. For example, the commands below use **perl -ane** to slice and get the output from two variations of df. The third line then runs **join** to combine the two sets of fields on the Filesystem field, producing a composite table that includes fields from both versions of **df** output.

```
suse$ df -h | perl -ane 'print join("", @F[0..4]); "
" > tmp1
suse$ df -i | perl -ane 'print join("", @F[0,1]); "
" > tmp2
suse$ join tmp1 tmp2
```

A script version with no temporary files would look like this:
#!/usr/bin/perl

```
for (split(/\n/, '/df -h/)) {
  @F = split;
  $h_part[$F[0]] = [ @F[0..4] ];
}

for (split(/\n/, '/df -i')) {
  @F = split;
  print join("", @{$h_part[$F[0]]), $F[1], $F[4]], "\n"
}
```

The truly beside is using **-i** in conjunction with **pe** to edit files in place; Perl reads the files, presents their lines for editing, and saves the results out to the original files. You can use a pattern to -i that tells Perl how to get back the original version of each file. For example, **-i=bak** works as password.bak. Beware—if you don't supply a backup pattern, you don't get backups at all. There's no space between the -i and the suffix.

# Add-on modules for Perl

CPAN, the Comprehensive Perl Archive Network at cpan.org, is the warehouse for user-contrib Perl libraries. Installation of new modules is greatly facilitated by the **perl command**, which acts like a yum or APT package manager dedicated to Perl modules. If you're on a Linux system, check to see if your distribution packages the module you're looking for as a standard feature—it's much easier to install the system-level package and then let the system take care of updating itself over time.
