RDP clients for UNIX administrators manage Windows systems from a UNIX- top. They are an indispensable tool for UNIX administrators who have Windows systems in their environments.

# 30.3 RUNNING WINDOWS AND WINDOWS-LIKE APPLICATIONS

As discussed in Chapter 24, the free but proprietary VMware Server from vmware.com lets you run multiple operating systems simultaneously on PC hard- ware. VMware emulate virtual "guest machines" on top of a host operating system, which must be either Linux or Windows. Regardless of the OS, you can install Intel-compatible operating systems into one of VMware's virtual machines. From the guest machine's perspective, the operating system runs ex- act as if on dedicated hardware, and applications install normally. Other virtualization offerings such as KVM and VirtualBox also run Windows and should be candidates for running Windows applications.

A different approach is taken by the Wine system from winehq.org. Wine imple- ments the Windows programming API in the UNIX environment, allowing you to run Windows applications directly on top of X. This free software translates native Windows API calls to their UNIX counterparts and can do so without ing any Microsoft code. Wine supports TCP/IP networking, serial devices, and sound output. It runs on Linux, BSD, Mac OS, and Solaris systems.

A large number of Windows applications run in Wine without problems, and oth- ers can be made to work with a few tricks; see the web site for details. Unfortu- nately, getting an application to run under Wine is not so simple. The tal- folks codewavers.com have written a commercial installer system that can make some of the bulkier Apps work correctly.

If your tool of choice is supported by CodeWeavers, or even if it is not, give the application a try—you might be pleasantly surprised. If an application does work on its own and you find any prewritten hints, be prepared to spend some serious spare time whipping it into shape if you are determined to it on your own. If you have the budget, you can consider contracting CodeWeav- ers to help you.
