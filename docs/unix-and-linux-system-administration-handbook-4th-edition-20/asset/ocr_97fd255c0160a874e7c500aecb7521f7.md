By default, the agent is installed as /usr/sbin/snmpd. It is usually started at boot and reads its configuration information from files in the /etc/snmp directory. The most important of these files is snmpd.conf, which contains most of the configuration information and ships with a bunch of sample collection methods enabled. Although the intention of the authors seems to have been for users to edit only the snmpd.local file, you must use snmpd.conf at least to disable any default data collection methods that you don't plan to use.

The NET-SNMP configure script lets you specify a default log file and a couple of other local settings. You can use snmp -l to specify an alternative log file or -s to log messages to syslog. Table 21.2 lists snmp's most important flags. We recommend that you always use the -a flag. For debugging, you should use the -V, -d, or -D flags, each of which gives more information.

# Table 21.2 Useful flags for NET-SNMP snmpd

| Flag | Function |
| -l | Logs information to logfile |
| -d | Logs the addresses of all SNMP connections |
| -V | Logs the contents of every SNMP packet |
| -D | Enables verbose logging |
| -h | Logs debugging information (lots of it) |
| -H | Displays all arguments to snmpd |
| -A | Appends to the log file instead of overwriting it |
| -s | Logs to syslog (uses the daemon facility) |
