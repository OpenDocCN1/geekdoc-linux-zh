# Dynamic monitoring with top, prstat, and topas

Under Solaris and HP-UX, ps -ef is a good place to start. The e option selects all processes, and the f option selects the output format. (ps -ef also works on AIX and Linux systems; note the dash.)

```
$$ ps -ef
UID PID PPID C STIME TTY TIME COMD
root 0 0 80 Dec 21 ? 0:02 sched
root 1 0 2 Dec 21 ? 4:32 /etc/init-
root 2 0 8 Dec 21 ? 0:00 pageout
root 171 1 80 Dec 21 ? 0:02 /usr/lib/sendmail-bd
trent 8482 8444 35 14:34:10 pts/7 0:00 ps-ef
trent 8444 8442 203 14:32:50 pts/7 0:01 -csh$$
```

The columns in the ps -ef output are explained in Table 5.5.

# Table 5.5 Explanation of ps -ef output

| Field | Content |
|---|---|
| UID | STIME Time the process was started |
| PID | TTY Control terminal |
| PPID | TIME CPU time consumed |
| C | COMD CPU use/scheduling info Command and arguments |

Like ps in the Linux and AIX systems, ps -ef shows additional details over Solaris and HP-UX systems:

```
$% ps -elf
F S UID PID PPID C P NI ADDR SZ WCHAN TIME COMD
19 T root 0 0 80 0 SY f00c2df8 0 0:02 sched
8 S root 1 0 65 1 20 ff2c6a80 88 ff26c3c8 4:32 init-
8 S root 142 1 41 1 20 ff2e8000 176 0:09 syslog
```

The STIME and TTY columns have been omitted to fit this page; they are identical to those described in ps. Nonvious fields are described in Table 5.6 on the next page.

# 5.8 DYNAMIC MONITORING WITH TOP, PRSTAT, AND TOPAS

Since commands like ps offer only a one-time snapshot of your system, it is often difficult to grasp the big picture of what's really happening. top is a free utility that runs on many systems and provides a regularly updated summary of active processes and their use of resources. On AIX, an equivalent utility is tapas, and on Solaris the tool is prstat.
