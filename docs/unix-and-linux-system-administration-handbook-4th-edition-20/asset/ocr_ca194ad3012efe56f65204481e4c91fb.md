# Zone signing

Signed zone files are typically up to ten times the original, and all your nice logical ordering is lost. A line such as

mail-relay A 63.173.189.2

becomes several lines:

```
mail-relay.example.com. 57600 A 63.173.189.2
57600 RRSIG A 5 37600 20090722243636
20090622243636 2301 example.com.
Y7sj9DWYyuU7eGrdFcl+ruZ8cliwoev
012TGFlibhsRizfEFFYRUB77wf2vkRNngEuwyk
d2RSKDJzRQ-w= mail-relay.example.com. A RRSIG NSEC
3600 NSEC SEC 5 33600 20090722243636
20090622243636 2301 example.com.
42QXpVp0ChGSfeProBMZ7wf7eSSWK+40
WNSN8B4ofotynmRizYWlZLIPBAUJ77RR
H0LLFBqDom2YW==
```

In practical terms, a signed zone is no longer human-readable, and it cannot be edited by because of the RRSIG and NSEC records. User-serviceable parts inside!

With the exception of DNSKEY records, each resource record (resource records of the same type for the same name) have one signature from the ZSK. DNS-KEY resources are signed by both the ZSK and the KSK, and they have two RRSIGs. The base-64 representation of a signature ends in however when many equal signs are needed to make the length a multiple of 4.

For clarity in subsequent examples, we assume that the zone file is named for the zone and the zone files and the key files are in the same directory. In real life it's a good idea to identify the key files explicitly, especially when you are rolling over keys and be sure the command uses the right ones.

Once your zones are signed, all remains is to point your name server to the signed versions of the zones. If you are using DNS, look for the zone statement that corresponds to each zone in named.conf and change the file parameter from example.com.signed. For NSD, the configuring file is nsd.conf and you should look for zonefile lines.

Finally, restart the name server daemon, letting it to read its configuration file. For BIND, do sudo rnd reconfig followed by sudo rnd flush. For NSD, sudo nsupdate rebuild by sudo nsdc restart.

We are now serving a DNSSEC zone! To change the original unsigned zone or the signed zone and then re-sign the zone. Editing a signed zone is something of a logistical nightmare, but it is much quicker than re-signing the entire zone. Be sure to remove the RRSIG records that correspond to any records you change. You probably want to make identical changes to the unsigned zone to avoid version skew.
