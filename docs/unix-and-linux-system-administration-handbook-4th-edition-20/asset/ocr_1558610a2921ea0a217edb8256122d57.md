# Chapter 17  DNS: The Domain Name System

Installing RHEL's BIND package puts the binaries in /usr/sbin, puts the man
pages in /usr/share/man, adds a user and group called "named", and creates di-
ories for data files. The "named" user has access to the data files through
group permissions.

Unlike this change in /etc/sysconfig/named, the named.conf file goes in /etc
(as Paul Vissie and God intended), and the zone files go in /var/named. No sample
files are provided, and the bindconf package should have them.

# Specifications for Solaris

Solaris 10 ships with BIND 9.3.4-P1, vintage 2007; you should consider up-
grad. Solaris is more to use with BIND 9.6.1-P1 (2009). Solaris has
always called their network programs in.progname and named was no exception,
so often you couldn't find it for a bug if you was called in.named,
and not named. Happ, this is not true and Solaris comes to
calling the server plain old named, though the in.named name persists as a
link. Link Linux, Solaris uses a service order file /etc/nsswitch.conf to spec-
ify how BIND, NIS, NIS+ (Solaris 10 only), and the /etc/hosts file interact. Modi-
ifying the hosts line in that file

```
hosts: files dns
```

causes name resolution to try /etc/hosts first and then DNS. The short-circuit
clause NOTFOUND=return can modify any entry. Putting crucial servers
routers in the /etc/hosts file eases the chicken-and-egg problems that sometimes
occur at boot time before service is available. Solaris's name service is
started by the SMF service svc/network/dns/server:default. SMF options specify
the command-line arguments.

Table 17.19 BIND 9 files in Solaris summarizes filenames and locations.

| File | Directory | Description |
| --- | --- | --- |
| resolv.conf | /etc | Resolver library configuration file |
| named | /usr/sbin | Name daemon |
| named-checkconf | /usr/sbin | Checks configuration file syntax |
| named-checkpoint | /usr/sbin | Checks zone file syntax |
| named.conf | /etc | Configuration file for name server |
| nsswitch.conf | /etc | Service switch file |

# Specifications for HP-UX

HP-UX includes BIND 9.3.2, vintage 2005; better upgrade! HP-UX provides
several sample nsswitch.conf files for various combinations of databases and ser-
ves. One lists the HP defaults. Copy the one that seems right for your environ-
ment to /etc/nsswitch.conf.
