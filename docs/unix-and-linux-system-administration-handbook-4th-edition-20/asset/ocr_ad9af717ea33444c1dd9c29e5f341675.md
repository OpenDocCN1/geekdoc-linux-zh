# Template Tree 2: cfengine helper

Template Tree 2 was created at the Swiss Federal Institute of Technology (ETH) by Tobias Oetiker. It is a component-based system driven by a two-level approach to defining a site’s configuration and can reduce complexity by dealing with the relocated root directories of diskless machines.

On the lower level, the system consists of a number of "feature packs." A feature pack is a collection of files accompanied by a META file that how these files must be installed on the target system. A feature can be anything from network configuration to the latest version of OpenSSH. Features expose configurable parameters that can be set in the configuration file.

The upper level of configuration is a master site file in which you pull the features together and associate them to machines or groups of machines. At this level, you must specify values for the unbound configuration parameters exposed by each feature. For example, one of the parameters for a mail server feature might be the name of the main domain.

Template Tree 2 combines the information from the master configuration file and the individual features META files to generate cfengine configuration file for the whole site. While each feature must contain documentation about its purpose and usage, Template Tree 2 can also generate documentation.

# DMTF/CIM: the Common Information Model

The Distributed Management Task Force (DMTF), a coalition of "more than 3,000 active participants," has been working since 1992 to develop its Common Information Model (CIM) in an attempt to create standards for an object-oriented, cross-platform management system.

In DMTF’s own words, CIM is "management schema...provided to establish a common conceptual framework at the level of a fundamental topology with respect to classification and association, and with respect to the basic set of classes intended to establish a common framework for a description of the managed environment."
