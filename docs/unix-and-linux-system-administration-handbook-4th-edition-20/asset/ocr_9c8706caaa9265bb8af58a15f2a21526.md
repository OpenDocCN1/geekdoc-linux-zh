# SELinux: security-enhanced Linux

SELinux is an NSA project that has been freely available since late 2000. It has been integrated into the 2.6 series of the Linux kernel and is available on most current distributions. Some distributions ship with it (often in a somewhat dysfunctional state).

The primary focus of SELinux is to enable "mandatory access control," aka MAC, an access control system in which all permissions are assigned by administrators. Under MAC, users cannot delegate their access or access control parameters on the objects they own. As such, it's primarily of interest to sites with specialized requirements.^3

SELinux can also be used to implement a form of role-based access control, although this was not a primary objective of the system.

# POSIX capabilities (Linux)

Linux systems—even those that do not make use of the SELinux extensions—are theoretically capable of subdividing the privileges of the root account according to the POSIX standard for "capabilities." Capability specifications can also be signed to executable programs. The programs then acquire the specified capabilities when they are executed. It's essentially a lower-risk form of setuid.

For various reasons, including problems with the current implementation, the facility is not as helpful or relevant to system administrators as it might initially appear. For more comments on capabilities, see the discussion on page 818.

# PAM: Pluggable Authentication Modules

PAM is an authentication technology rather than an access control technology. That is, rather answering the question "Does user X have permission to perform operation?", it helps answer the precursor question "How do I know this is real user X?" PAM is an important component of the access control chain in systems.

In the past, user passwords were checked against the /etc/shadow file (or network equivalent) at login time so an appropriate UID could be set for the shell or window system. Programs run by the user had to track the UID on faith. In the modern world of networks, cryptography, and biometric identification devices, a more flexible and open system is required. Here, PAM.
