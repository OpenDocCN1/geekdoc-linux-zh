# *It's in the way that you type it*

Don't forget to make a couple of quick setting changes to match the way you like to type. These settings are personal choices; you may hate what we love, and vice versa.

+   1. **Choose Control Center:: Input Devices:: Keyboard.**
+   
+   The Keyboard Configuration screen appears, as seen in Figure 14-10.
+   
+   2. **Click AutoRepeat on or off, according to preference.**
+   
+   AutoRepeat (Keyboard Repeat) determines what happens if you hold down one key for some time. If AutoRepeat is on and you hold down the N key, you see nnnnnnnnnnnn on the screen. If AutoRepeat is off, you can hold the N key down all day and you still only see n.
