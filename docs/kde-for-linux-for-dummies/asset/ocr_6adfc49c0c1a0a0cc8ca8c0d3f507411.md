# Waiter, Where's the Program I Ordered?

If you're new to Linux, you may be befuddled by the KDE menu system. Even if you have installed all the programs in the previous section of this chapter, the programs won't automatically appear in the KDE menu. This can be a shock for folks used to the Windows 95 or 98 installation process, which almost always includes the query "Include program icon in Start Menu?" But fear not -- you can easily get to all the other great programs that you've installed. You even have a couple of choices for starting the programs or a way to avoid the choice altogether.
