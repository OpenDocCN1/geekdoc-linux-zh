+   4. **Select a mouse button configuration.**
+   Left handed? You can reverse the button configuration so that you can use the mouse easily with your left hand, and not have to think about which button to push in order to mimic righty clicks. If you select left-handed configuration, a left-handed left click functions as a right-handed right click, and vice versa.

+   5. **Click OK after you finish.**
+   You probably need to tinker a bit with the acceleration and threshold settings until you're happy with cursor speed. Just reopen the Mouse screen within the Control Center and change the setting.
