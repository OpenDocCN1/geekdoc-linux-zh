# ## Designing desktop color and wallpaper

KDE provides you with many ways to customize your desktop environment. Perhaps the single most striking change you can make is to select a different background for the KDE desktop. You can select a solid color, a two-color gradation or pattern; or you can use an image file to create the computer equivalent of wallpaper. If you choose the wallpaper option, you can use a single large image to cover your desktop, such as a mural (as shown in Figure 6-1), or you can repeat a smaller image many times to create a pattern.

To adjust your desktop background settings, follow these steps:

+   1. Right-click the desktop and choose Display Properties from the pop-up menu that appears.

KDE opens the Display Settings dialog box. Normally, the Background tab is selected by default. If not, click the Background tab to display the options shown in Figure 6-2.
