# *Operating with the Operational Theme*

The Operational theme (shown in Figure 18-8) is a study in simplicity. The light gray color scheme is almost the same as the KDE default color scheme, but a number of small touches set this theme apart from the default. The titlebars on inactive windows are the same light gray as the window surrounds, which makes the subtle monochromatic dot pattern in the active titlebar more than enough of a difference to mark the active window. The titlebar buttons feature simple, clean graphic symbols. The gradation in the panel background is a nice touch. The dark purples and grays of the abstract wallpaper pattern provide a contrasting background for the light gray foreground windows.
