+   
+   The screen shifts to a view of the `kde/stable/1.1.2/distribution` directory. This directory, shown in Figure A-3, holds subdirectories for the major file types, as well as source code. If you prefer software packaged for your particular Linux distribution, open that subdirectory. It contains the same code as the other directories, but is packaged for ease of use with your distribution.
