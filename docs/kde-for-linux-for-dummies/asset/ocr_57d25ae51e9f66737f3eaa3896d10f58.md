+   1. **Open the KDE Control Center dialog box.**
+   Click the KDE Control Center button on the panel or choose KDE Menu->KDE Control Center. The KDE Control Center dialog box appears.

+   2. **Choose Windows->Advanced.**
+   The Advanced tab appears, as shown in Figure 3-6.

![](bbox=[0.06, 0.45, 0.15, 0.6])

![](bbox=[0.19, 0.24, 0.68, 0.6])

+   3. **Adjust the settings on the Advanced tab as needed.**
+   You can adjust the following settings:

+   * **Ctrl+Tab Walks Through Desktops**: Select this option to use the Ctrl+Tab shortcut key to switch desktops.
+   * **Alt+Tab is Limited to Current Desktop**: Select this option to cause the Alt+Tab shortcut key to cycle through windows on the current desktop only. Otherwise, pressing Alt+Tab cycles through all the windows on all your virtual desktops.
+   * **Alt+Tab Mode**: Select KDE or CDE to determine which windows KWM opens if you press the Alt+Tab repeatedly. KDE mode always switches back to the previous window. CDE mode always steps through the available windows sequentially.

![](bbox=[0.05, 0.85, 0.14, 0.88])

If you want to step through all available windows sequentially, press and hold the Alt key as you tap the Tab key repeatedly. This technique works in both KDE and CDE modes.
