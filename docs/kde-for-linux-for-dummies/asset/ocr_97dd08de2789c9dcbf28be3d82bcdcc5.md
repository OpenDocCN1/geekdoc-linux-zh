# The Purple Tech Look of P-Tech

The P-Tech theme sports an unusual purple color scheme and window borders that are composed mostly of thin lines that are set off from the window just enough to allow a bit of background to show through. And what a background it is — mostly black with a large rendering of an evil-looking chrome, cyborg-like skull.
