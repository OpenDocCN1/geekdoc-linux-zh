+   3. Adjust the Visible slider.
+   Drag the slider to the left to decrease the number of desktop buttons visible in the panel. Drag the slider to the right to increase the number of buttons available.

+   4. Adjust the Width slider.
+   Drag the slider left or right to decrease or increase the horizontal size of the desktop buttons on the panel.

+   5. Double-click a desktop name in one of the numbered text boxes and type a new name.
+   You can rename your desktops from the default names (One, Two, and so on) to anything you want. Keep the names short so that they fit on the panel buttons.
+   Try naming your desktops for the kind of work that you do on each desktop. For example, if you normally keep a Web browser open on one desktop and your e-mail program on another, you can name those desktops Web and Mail.

+   6. Repeat Step 5 for each of the desktop names.

+   7. Click the OK button.
+   KDE closes the KPanel Configuration dialog box and redraws the panel using the settings that you specify.
