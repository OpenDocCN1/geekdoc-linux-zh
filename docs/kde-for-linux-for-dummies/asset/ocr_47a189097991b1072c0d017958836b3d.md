# How to Use the CD

To install KDE or the other software on this CD, you will need to mount the CD-ROM drive. The installation process for KDE itself is described in Appendix A. To install the programs on this disk, use the following process and the information in Appendix A as complementary references.

# General installation from source code

+   1.  **Insert the CD-ROM into your computer’s CD-ROM drive.**

+   2.  **Make sure you are logged in as root.**
+   
+   If you are not logged in as root, you may log out of your user account and log back in as root, or use the Kfm superuser method described in Part IV.

+   3.  **As root, issue the command mount -t iso9660 /dev/cdrom /mnt/cdrom.**
+   
+   This command mounts the CD-ROM drive, giving you access to the files on the book’s CD.

+   4.  **Issue the command mkdir /usr/src/KDE.**
+   
+   This command creates a new directory for your source code packages.

+   5.  **Issue the command cp /mnt/cdrom/TGZ/* /usr/src/KDE.**
+   
+   This command copies the files from the CD-ROM drive to the directory you created in Step 4.

+   6.  **Use the procedure in Appendix A to install the packages.**
