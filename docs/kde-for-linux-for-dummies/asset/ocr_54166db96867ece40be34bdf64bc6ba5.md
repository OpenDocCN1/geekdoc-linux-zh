# Kuickshow

Nothing is more frustrating than having a bunch of graphics files on your computer yet not remembering what each file depicts. (Especially if you didn't give them clear names when they were saved) Kuickshow is a handy utility that displays your graphics files. It has some basic graphic editing capabilities, its own file manager, and intelligent resizing for display. You can choose to show the files in a desktop window, or you can view them against a black background in full-screen mode.

Check out the Kuickshow Web page:

http://www.millennix.de/kuickshow.html

# Empath

If you work with Microsoft products at your office or home (as well as at your Linux machine, of course), you may rely on Outlook to handle your e-mail. Empath is a fully configurable KDE program that handles your e-mail in a format just like the Outlook interface. You can change almost everything about Empath's appearance; you can have it run just the way you like.

The Empath home page is here:

http://without.netpedia.net/empath.html
