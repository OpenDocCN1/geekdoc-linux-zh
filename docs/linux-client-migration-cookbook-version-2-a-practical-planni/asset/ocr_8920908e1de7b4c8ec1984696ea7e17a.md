Linux has built-in support for the FAT file system used by DOS and Windows. NTFS, the file system introduced with Windows NT, is currently supported in read-only mode. There is an experimental driver for writing to NTFS, but because this can cause data loss, we do not recommend it for real use.

# 5.2.7 Virtual memory

Both Windows and Linux have a system for virtual memory. The model behind is both different and can change from one version to the next.

One difference between Windows and Linux is the way swapping or paging is done. A Linux system will only paging out memory pages when no physical memory is available for allocation. Paging occurs when memory pages are needed that are no longer in physical memory. Performance can be adversely affected when there is a lot of paging activity especially when there is a lot of paging in and out. This generally means physical memory or certain kernel parameters governing virtual memory might be set incorrectly, or possibly, the parameters of the paging space is not optimal. Windows sometimes perform paging out of certain memory pages even when physical memory is not exhausted. This is called preventive paging. This does speed freeing up memory when the need arises, but it also means that Windows will be paging out more often.

Another difference is that Windows usually uses a swapfile, while Linux uses a swap partition (but can use swapfiles as well). On Windows, the main drive C: usually contains a file named paging.sys, and that file is used for virtual memory. The file can grow if necessary, which can lead to the swapfile becoming fragmented, which significantly hampers performance. On Linux, a swap partition is usually created on installation. This partition is set aside for virtual memory, and is always contiguous. However, because it is a partition, it can never grow larger than the original size to which it was initialized during partitioning, without repartitioning the disk.
