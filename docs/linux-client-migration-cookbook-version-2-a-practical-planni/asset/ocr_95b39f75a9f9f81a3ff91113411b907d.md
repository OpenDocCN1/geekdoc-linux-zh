As with KDE, you can place icons and folders on your desktop and start applications from the GNOME panel. On this panel, you can freely arrange GNOME applets (such as a clock, battery and wireless status, or a virtual desktop chooser). For more fine tuning of the GNOME desktop, GDesklets^5 provides many options to add custom mini-applications (“deskslets”) to the GNOME desktop.

# 4.3.3 Look and feel

After choosing a desktop environment, you might wish to customize the look and feel of the desktop. Choices include choosing the icons that will be used for custom applications or even replacing icons for built-in applications, choosing a theme to make applications consistent across the environment, and using a simple, unified menu structure.

# Custom Icons

You probably want a company logo and other brand graphics to be part of your standardized desktop. You might wish to customize desktop icons, such as replacing the e-mail application icon with one fitting the corporate color scheme. Or, you might wish to change the default menu launcher (the equivalent of the Windows Start Menu) to an icon representing your organization. Also, you need to create or find suitable replacement icons for any custom applications that you have deployed.

Simple bitmap are not really state of the art and should be kept to a minimum to eliminate resolution problems. KDE and GNOME have very good Scalable Vector Graphics (SVG) support in the most current releases. You should use the standard SVG^6 when designing vector graphics
