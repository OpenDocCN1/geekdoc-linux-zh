Figure D-2 illustrates some of the Multi-station topology options discussed so far.
Key components in the figure are described as follows:

+   - A: Managed multi-station disk images support thin clients alongside regular
multi-station desktops.

+   - B: Local workstations connect to the IntelliStation using standard USB/VGA
cables.

+   - C: KVM options allow mice, keyboards, and monitors to be located up to 250
feet from the IntelliStation.

+   - D: Thick clients with minimal CPU, memory, and PCI expansion slots can
serve desktops to local stations, while application processing occurs on the
central IntelliStation computer.

+   - E: PCI expansion bus units allow stations to be deployed into user
environments, while the IntelliStation is managed in a secure environment.
