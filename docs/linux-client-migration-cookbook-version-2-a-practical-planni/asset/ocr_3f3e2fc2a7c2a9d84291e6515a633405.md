+   Which key components of your hardware are currently required by users? For example, machines might have sound cards installed, but drivers are not installed because users are not supposed to use them. Therefore, support on Linux would not be required.

+   What types of attached devices need to be supported? For instance, synchronizing calendaring and other data with PDAs or smartphones might be required. Also, USB sticks, Bluetooth devices, and external FireWire hard drives have become very popular, though organizations disallow such devices due to security reasons. It might be necessary to support such hardware or to not include support for some of these devices. Likewise, many users might be synchronizing their desktops with MP3 player. While supporting these MP3 players in Linux could help users enjoy the Linux experience, it can also increase the complexity of supporting a Linux installation.
