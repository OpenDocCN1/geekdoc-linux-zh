# Scripting languages

Open source scripting languages for Linux as Perl, Python, Ruby, ECMAScript, or Tcl, have been ported to diverse operating systems, including Windows and Mac OS X. The typical Windows scripting language, Visual Basic, and the related project, Visual Basic for Applications (VBA), are not directly available for Linux; although there are similar projects available through commercial offerings (such as RealBasic, "Application porting" on page 329) or through free implementations (such as StarBasic in OpenOffice):

```
http://www.thefreecountry.com/compilers/basic.html
http://documentation.openoffice.org/How_TO/various_topics/VbaBasicXref.pdf
```

All of these Basic dialects are certainly relevant from a compatibility point of view (for example, for Excel migration), but they do not play a central role in the foundation of the GNOME or KDE environments, because there are many other natural choices.

# Shell scripting

The traditional way of scripting on Linux (and UNIX) machines involves shell scripting. Shell dialects include bash, ksh, and tosh. Shell scripts are the equivalent of batch files on Windows, except that they are significantly more powerful. Shell scripts are frequently used for startup routines (such as those found in /etc/init.d) or as wrappers around more complex programs (such as Mozilla or OpenOffice). More information about programming with shell scripts can be found at:

+   - Linux Shell Scripting Tutorial: http://www.frees.org/guides/lsst
- Advanced Bash-Scripting Guide: http://www.tdp.org/LDP/abs/html/

# Perl

Perl (Practical Extraction and Report Language) is a flexible and powerful scripting language. Perl was originally developed for text manipulation, and now can be used for much more. An impressive collection of third-party modules are available at the Comprehensive Perl Archive Network (CPAN). While enthusiasts say that Perl's philosophy of "TMTOWDI" ("More Than One Way To Do It") makes Perl easy to use, others can make a legitimate claim that such philosophy makes code difficult to read and maintain.
