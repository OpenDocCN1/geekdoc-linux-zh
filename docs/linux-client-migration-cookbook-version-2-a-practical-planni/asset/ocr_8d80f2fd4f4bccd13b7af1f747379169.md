Both Red Hat and Novell are providing desktop-oriented products that demonstrate tremendous value, especially focused on business environments: from small business up to enterprise class. At the same time, the explosive popularity of the Ubuntu distribution has aptly demonstrated the increasing interest in Linux as a viable operating system alternative for the mainstream communities of casual home users and home enthusiasts.

Currently, one of the most important challenges facing the development communities that are focused on desktop Linux is compatibility of various application programming interfaces. For instance, how do you manage development of a single code stream for a popular media player, while providing full functionality consistent look and feel when running in both GNOME and KDE environments on Linux? This is possible today, but not without considerable effort on the part of the development teams. And the methods one team uses to accomplish this feat might not be all similar to the same methods another team uses to reach the same goal.

A common set of standards is that allows developers to create applications that seamlessly integrate into various desktop Linux distributions, and the distributions need to support these standards. In support of this goal, there is a significant amount of community collaboration going right now that will lead to further evolution and adoption of standards going forward.

To end, the Open Source Development Labs (OSDL) sponsors a Desktop Linux Working Group. Also, freestanding.org is actively supporting projects that are focused on interoperability and shared technologies between the various Linux environments.
