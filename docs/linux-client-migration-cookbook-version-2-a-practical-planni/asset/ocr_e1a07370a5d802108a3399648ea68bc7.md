# Action restrictions

Using a Kiosk Admin Tool, we have already encountered action restrictions that are configured on a profile level in the kdeglobals file in the KDE Action Restrictions section. For our ITSO profile, look at Example 7-4 to see what actions of entries have been generated.

```
Example 7-4 Action restrictions in /etc/kde-profile/itso/share/config/kdeglobals
KDE Action Restrictions][$i]
action/desktop_rmb=false
action/kicker_rmb=false
action/menuedit=false
editable_desktop_icons=false
editable_system_desktop_icons=false
movable_toolbars=false
run_command=false
user/root=false
```

There are many actions available and a lot will be generated in the future by the applications using the KDE framework. You have actions that refer on a global level to menu and toolbar entries (for example, action/file_new) and general actions for:

+   * Printing (options)
* Screensavers (opengl_screensavers)
* Desktop (lock_screen, movable_toolbars, and start_new_session)

There are also actions related to standard KDE programs such as:

+   * Konqueror (action/openintab) and KDesktop
* KWin (action/kwin_rmb)
* Kicker (action/kicker_rmb)
