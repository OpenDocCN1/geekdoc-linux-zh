# 3.3 Human factors

Because a desktop client migration affects users in a very direct way, considering human factors in the transition management strategy is extremely important.

You can expect that a radical change in the desktop interface from what users are accustomed to will cause different kinds of reactions: From enthusiastic acceptance to outright rejection. Therefore, it is important to keep the users informed about the new developments in a clear and understandable way. A communications plan is key.
