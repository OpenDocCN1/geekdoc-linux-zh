In order to develop a complex mapping from each individual source application to an appropriate destination application, Settings Packages map settings into a common normal format. Progression then automatically translates settings between those with the same in the source and destination packages.

For instance, to migrate personalization settings from Internet Explorer to Konquer, both packages have a named setting "Homepage". Internet Explorer’s case, the "Homepage" setting is defined as coming from the registry at a specific path, while in Konquer the setting points to a path of an INI file and the section and key inside INI. These two paths have been found and named the same, Progression Desktop handles the details of extracting the setting from the registry, storing it inside the PNP, and then inserting the value into an INI on the destination. If the setting had pointed to a file, then Progression Desktop would automatically extract the associated file and insert it in the destination machine.
