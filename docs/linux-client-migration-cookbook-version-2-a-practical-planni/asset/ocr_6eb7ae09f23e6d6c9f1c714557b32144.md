Documents can be chosen by folder or by file, or even by file type. The documents can be copied as they are or sent through a conversion process based on file type to ensure complete compatibility on the target desktop. Progression Desktop also allows files to be excluded based on location or file type; for instance, a corporation might want to migrate the users' directories, but exclude all MP3 files or others that violate corporate policies.

# # How to migrate with Progression Desktop

There are three ways to migrate clients with Progression Desktop:

+   * Using the provided GUI
* Using the command line with templates
* Using a systems management tool to automatically invoke the command line with templates

Each of these methods follows the same basic steps, as shown in the diagram Figure C-1 on page 280. First, the Windows-based executable of Progression Desktop is run on the source desktop. This process retrieves information from each of the selected source applications and stores these settings into a neutral source. This neutral source, called a Platform Neutral Package (NP), must be made available to the destination machine. This step is accompanied by copying the file to a network share, or directly to the destination machine. Finally, the Linux-based executable of Progression Desktop is run on the destination machine. This process gathers information from the PNP and applies the settings to the appropriate location for each of the target applications.
