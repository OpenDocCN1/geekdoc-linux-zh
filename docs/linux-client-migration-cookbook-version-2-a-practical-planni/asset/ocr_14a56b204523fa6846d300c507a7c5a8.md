The main characteristics of the IBM Workplace Managed Client compared to other client technologies can be summarized as:

+   - A centrally managed, policy-based client provisioning system that ensures initial installations as well as maintenance updates can be applied on the server side, and that users can experience new client-side and fully dynamically

+   - A synchronizing secure data store that is locally accessible and centrally manageable (for backups and so forth)

+   - A componentized architecture that allows for gradual extension and that can be distributed on demand

+   - An application development platform that allows users and third-party vendors to extend the framework to their needs

Applications that come with WMC include:

+   - A messaging framework for sending and receiving e-mails and an instant messaging product for real-time chat sessions

+   - An embedded Web browser to access additional portlets on the server side and to directly browse the Web

+   - A document library that is synchronized to the server and can be shared with other team members

IBM Workplace Managed Client includes an office productivity editor for creating, editing, and sharing a variety of document types: word processing, spreadsheet, presentations, project management. The IBM productivity tools are compatible with Open Office applications and support the open OASIS open document format (ODF). The IBM Workplace Managed productivity tools can also be used to create, edit, and save documents in a variety of formats - including Microsoft® Office application formats. By supporting open standards document formats, IBM Workplace Managed Client ensures cross-platform and cross-application document exchange without being locked into proprietary vendor formats.
