default source contains default options that are used for each setting that has not been configured by a user. Finally, the mandatory source overrides users' personal preferences and disallows changes to the associated setting. The settings source is usually stored in $HOME/.gconf. The default source is found in /etc/gconf/gconf.xml.defaults on Red Hat-based systems and /etc/opt/gnome/gconf/gconf.xml.defaults on SUSE-based systems. And, the mandatory source is /etc/gconf/gconf.xml.mandatory on Red Hat-based systems and /etc/opt/gnome/gconf/gconf.xml.mandatory on SUSE-based systems.

For more information about GNOME stores its settings and how to edit them, see “Desktop personalization: GNOME Desktop” on page 317.

# gconftool-2

The GNOME desktop ships with a tool called gconftool-2. You can use it from the command line to edit the GConf database, and you can edit any of the configuration sources. Because the default and mandatory sources apply to all users, they typically only can be edited by the root user. Also, these changes directly edit the GConf databases, and thus, they do not affect any GConf session that is currently running.

If you want to remove the keyboard shortcut for running the Application dialog (which is normally Alt-F2), you run the following command:

```
gconftool-2 --direct --config-source
xml:readwrite:/etc/gconf/gconf.xml.mandatory --type bool --set
/apps/panel/global/run_key false
```

If you want to set the default number of workspaces for new users, but also allow them to change this setting later, you run the following command:

```
gconftool-2 --direct --config-source
xml:readwrite:/etc/gconf/gconf.xml.defaults --type int --set
/apps/metacity/general/num_workspaces 2
```

# Graphical tools

GUI-based tools for locking the GNOME desktop also exist. Similar to the use of gconftool-2, gconf-editor can be used to directly edit the default and mandatory sources. To do so, launch gconf-editor as root, and choose **File → New Defaults Window** or **File → New Mandatory Window**. Just with the command-line tools, changes to the default and mandatory sources do not take effect for any GConf sessions that are already running.

# Pessus

Another available tool is Pessus. Pessus is a graphical tool, which configures the lockdown settings built-in GNOME, which otherwise can only be configured by GConf. Pessus is included in the GNOME admin suite
