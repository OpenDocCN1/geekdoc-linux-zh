# ZENworks Linux Management

The management tasks available in the Linux Management module:

+   - Delivering packages
- Locking down client desktop settings
- Defining preboot activity
- Software and hardware inventory
- Manage remote events
- Generate reports

The system architecture of the ZENworks Linux management server is shown in Figure B-4 on page 266. The server consists of an application running on top of a database and using an http/https interface to communicate.
