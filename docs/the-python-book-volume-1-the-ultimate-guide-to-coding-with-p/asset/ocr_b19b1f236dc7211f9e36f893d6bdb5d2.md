# 22 RSS

Django has a built-in RSS framework. In blog/urls.py add: from django.contrib.syndication.views import Feed class BlogFeed(Feed): title = "Blog Feed" link = "/" def items(self): return Post.objects.order_by("-pub_date") def item_title(self, post): return post.title

# 23 RSS links

We need to define item_link for the feed so that the feed items can link to the right place. We have to give the complete URL and the post ID for it:

```
def item_link(self, post): link = "http://127.0.0.1:8000/myblog/"+str(post.pk) return link
```
