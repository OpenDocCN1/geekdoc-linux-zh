# 04 Excerpt summary

You can replace the excerpt content in the index template with the excerpt, but we can keep it as a backup for if the excerpt is empty:

```python
{% if post.excerpt %} <p>{{ post.excerpt }}</p> {% else %} <p>{{ post.post.truncatewords:3 }}</p> {% endif %}
```

# 05 Database error

If you’ve noticed or tested the changes,

you’ll have noticed our web server has stopped working. This is because there is no excerpt column in our database. Therefore we need to add the excerpt column. To find out how, run:

```bash
$ python manage.py sqlall blog
```

# 06 Database query

The output will show you what the SQL code is to add these models to the database. We want to add the excerpt field specifically, which should look something like this:

```sql
“excerpt” text NOT NULL
```

Make a note of it.

![](bbox=[0.368, 0.716, 0.621, 0.843])

# 07 Alter table

To get into the database shell and add the field, run:

```bash
$ python manage.py dbshell
```

Then we need to use an ALTER TABLE query:

ALTER TABLE “blog_post”;
And then enter the code noted down like so:
ADD “excerpt” text;

# 08 Save the changes

We’ve removed NOT NULL as we already have entries that now have an excerpt, and want to make it so an auto summary can be made. Save the changes with: COMMIT; and then exit the shell with: .quit
