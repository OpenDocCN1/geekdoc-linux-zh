NumPy是用于科学计算的主要Python包。它拥有强大的N维数组对象、用于集成C/C++和Fortran代码的工具、线性代数、傅里叶变换和随机数生成等功能。NumPy还支持广播（broadcasting），这是一种巧妙的方式，让通用函数能够有意义地处理不完全相同形状的输入。

除了功能之外，NumPy的另一个优点是它可以轻松集成到Python程序中。换句话说，你可以从数据库、另一个程序的输出、外部文件或HTML页面获取数据，然后使用NumPy进行处理。

### 02 关于NumPy

尽管名称简单，NumPy却是一个强大的Python包，主要用于处理数组和矩阵。

创建数组的方法有很多种，但最简单的是使用`array()`函数：

```
>>> oneD = array([1,2,3,4])
```

上述命令创建了一个一维数组。如果你想创建一个二维数组，可以按如下方式使用`array()`函数：

```
>>> twoD = array([
    [1,2,3],
    [3,3,3],
    [-1,-0.5,4],
    [0,1,0] ])
```

你也可以创建更多维度的数组。

### 03 使用NumPy进行简单计算

给定一个名为myArray的数组，你可以通过执行以下命令来查找其中的最小值和最大值：

```
>>> myArray.min()
>>> myArray.max()
```

如果你想计算所有数组元素的平均值，可以运行下一条命令：

```
>>> myArray.mean()
```

类似地，你可以通过运行以下命令来查找数组的中位数：

```
>>> median(myArray)
```

一组数据的中位数是将数据集分成两个元素数量相等的子集（左子集和右子集）的元素。如果数据集的元素个数为奇数，那么中位数就是数据集的一部分。另一方面，如果数据集的元素个数为偶数，那么中位数就是排序后数据集两个中间元素的平均值。

### 04 使用NumPy处理数组

NumPy不仅采用了典型Python中用于字符串和列表的索引方法，还对其进行了扩展。如果你想选择数组中的某个元素，可以使用以下表示法：

```
>>> twoD[0,2]
```

你还可以使用以下表示法选择数组的一部分（切片）：

```
>>> twoD[0:1,1:3]
```

最后，你可以使用`tolist()`函数将数组转换为Python列表。

### 05 读取文件

假设你刚刚使用AWK从Apache日志文件中提取了信息，并且想使用NumPy处理这个文本文件。

以下AWK代码统计出每小时的总请求数：

```
$ cat access.log | cut -d ' ' -f2 | cut -d ']' -f1 | awk -F ':' '{print $2}' | sort -n | uniq -c | awk '{print $2, $1}' > timeN.txt
```

带有数据的文本文件（timeN.txt）的格式如下：

```
00 191
01 225
02 122
03 104
```

读取timeN.txt文件并将其赋值给一个新的数组变量可以这样做：

```
aa = np.loadtxt("timeN.txt")
```

### 06 写入文件

将变量写入文件与读取文件在很大程度上类似。如果你有一个名为aa1的数组变量，可以使用以下命令轻松地将其内容保存到名为aa1.txt的文件中：

```
In [17]: np.savetxt("aa1.txt", aa1)
```

正如你很容易想到的那样，之后你可以使用`loadtxt()`函数读取aa1.txt的内容。

### 07 常用函数

NumPy支持许多数值和统计函数。当你对数组应用函数时，该函数会自动应用于所有数组元素。

在处理矩阵时，你可以通过输入"AA.I"来找到矩阵AA的逆矩阵。你还可以通过输入"np.linalg.eigvals(AA)"来找到其特征值，并通过输入"np.linalg.eig(BB)"来找到其特征向量。

### 08 处理矩阵

二维NumPy数组的一个特殊子类型是矩阵。矩阵与数组类似，区别在于矩阵乘法取代了逐元素乘法。矩阵使用`matrix`（或`mat`）函数生成，如下所示：

```
In [2]: AA = np.mat('0 1 1; 1 1 1; 1 1 1')
```

你可以通过输入AA + BB来添加两个名为AA和BB的矩阵。类似地，你可以通过输入AA * BB来将它们相乘。
