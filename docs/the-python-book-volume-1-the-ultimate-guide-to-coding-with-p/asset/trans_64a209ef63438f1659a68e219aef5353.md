## 04 Excerpt summary

你可以用摘要替换索引模板中的摘要内容，但我们可以将其保留作为摘要为空时的备份：

```python
{% if post.excerpt %} <p>{{ post.excerpt }}</p> {% else %} <p>{{ post.post.truncatewords:3 }}</p> {% endif %}
```

![](img/3b256f430f51c98f1315671f6e4eec19_148_2.png)

## 05 Database error

如果你已经注意到或测试了这些更改，

你会注意到我们的 Web 服务器已经停止工作。这是因为数据库中没有 excerpt 列。因此我们需要添加 excerpt 列。要了解如何操作，请运行：

```bash
$ python manage.py sqlall blog
```

## 06 Database query

输出将显示将这些模型添加到数据库的 SQL 代码。我们 specifically 要添加 excerpt 字段，它应该看起来像这样：

```sql
“excerpt” text NOT NULL
```

记下它。

![](img/3b256f430f51c98f1315671f6e4eec19_148_3.png)

## 07 Alter table

要进入数据库 shell 并添加该字段，请运行：

```bash
$ python manage.py dbshell
```

然后我们需要使用 ALTER TABLE 查询：

ALTER TABLE “blog_post”;
然后输入记下的代码，如下：
ADD “excerpt” text;

## 08 Save the changes

我们已移除了 NOT NULL，因为我们已有条目现在具有摘要，并且希望使其能够自动生成摘要。使用以下命令保存更改：COMMIT; 然后使用以下命令退出 shell：.quit

![](img/3b256f430f51c98f1315671f6e4eec19_148_4.png)

## 09 Test it out

现在我们可以测试摘要代码——创建一个新文章或编辑现有文章以添加摘要。如果你已正确按照我们的步骤操作，它应该能正常工作；如果不行，你可能需要做一些错误修复。

# Web development

## 10 Category model

我们可以为博客分类添加一个模型：
class Categories(models.Model): name = models.CharField(unique=True, max_length=200) slug = models.SlugField(unique=True, max_length=100) parent = models.ForeignKey('self', blank=True, null=True, related_names='child') def __unicode__(self): return (self.name)
这允许父分类和子分类。

## 11 Administrate categories

我们可以通过在 admin.py 中创建 Categories 部分将其添加到管理站点：
class CategoriesAdmin(admin.ModelAdmin): list_display = ['name', 'slug', 'parent'] fields = ['name', 'slug', 'parent'] admin.site.register(Categories, CategoriesAdmin)
不过在我们创建分类之前，需要先创建数据库表：
$ python manage.py syncdb

## 12 Categorise the posts

与我们对评论所做的类似，我们希望在 Post 模型中添加一个 ForeignKey，以便将文章归属于某个分类。添加这一行：category = models.ForeignKey(Categories)
并将 Categories 移到 models.py 的顶部

## 13 Database category

像之前一样，我们将找出修改表的所需 SQL： $ python manage.py sqlall blog 对于我们的示例，它返回的代码与之前有些不同： "category_id" integer NOT NULL REFERENCES "blog_categories" ("id") 我们得到的是来自 categories 表的 ID，而不是文本。

## 14 Alter table – part 2

再次进入数据库 shell： python manage.py dbshell 我们将继续像之前一样操作，但使用新的代码： ALTER TABLE "blog_post" ADD "category_id" integer REFERENCES "blog_categories" ("id"); 最后，保存： COMMIT;

## 15 Administrate categories – part 2

现在我们可以返回 admin.py 并将新的分类字段添加到 PostAdmin 模型中： list_display = ['title', 'author', 'pub_date', 'category'] fields = ['title', 'pub_date', 'author', 'post', 'excerpt', 'category'] 我们之前的博客文章如果没有分类就消失了！要修复这个问题，请返回 models.py 并对 Post 模型进行此更改： category = models.ForeignKey(Categories, blank=True, null=True) 这样我们就可以单独创建分类，将它们分配给文章，并查看没有分类的文章。

> 我们现在可以单独创建分类

## 16 Category display

由于 blog 目录中的 urls.py 获取了所有文章字段，我们只需在索引模板中添加： <p>Category: {{ post.category }}</p> 并在文章模板中添加： <p>Category: {{ post_list.category }}</p>

## 17 Category page

首先我们需要在 blog/urls.py 中定义我们的分类。导入 Categories 然后添加： def blog_categories(request, category_id): categories = Categories.objects.get(pk=category_id) 我们需要 category_id 来调用对应的文章。
