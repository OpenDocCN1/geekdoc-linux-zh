# Logical Volume Manager Commands

The following are definitions of some of the more common Logical Volume Manager Commands. Many of these commands are found in the log file that SAM creates when setting up logical volumes for you. I am giving a description of these commands here so that when you see them, you’ll have an idea of each command’s use. Although these are not all of the Logical Volume Manager commands, these are the ones I use most often and are the commands you should have knowledge of when using Logical Volume Manager. The commands are grouped by physical volume (pv) commands, volume group (vg) commands, and logical volume (lv) commands. These commands are found in the manual pages. Some of the commands such as **vgdisplay**, **pvdisplay**, and **lvdisplay**, were issued so that you could see examples of these.
