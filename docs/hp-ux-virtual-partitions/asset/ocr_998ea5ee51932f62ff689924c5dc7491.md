# System Startup and Shutdown Scripts

Startup and shutdown scripts are run based on the directory in which a link to the script appears. Our example script should be started at run level three. Therefore, a link to its script appears in the directory `/sbin/rc3.d`. shown as the third link in the following listing:

```
# ls -l /sbin/rc3.d
\*total
lrwxr-xr-x    1 root     sys        23 Apr 26 14:32 G100nfs.server -> /sbin/init.d/nfs.server
lrwxr-xr-x    1 root     sys        19 Apr 26 14:52 S200tpc.rc -> /sbin/init.d/tps.rc
lrwxrwxrwx    1 root     sys        20 May 16 20:57 S790coldfusion -> ../init.d/coldfusion
lrwxr-xr-x    1 root     sys        23 Apr 26 14:44 S890dologin.rc -> /sbin/init.d/dologin.rc
=
```

We'll get to the significance of the naming of the link shortly. For the time being, it is sufficient to know that a link called `/sbin/rc3.d/S790coldfusion` points to our script `/init.d/coldfusion`.

Applications are shut down in the opposite order from which they were started. This means that a link to the startup and shutdown script will appear in a lower-level directory for shutdown. In our example, the startup link appears in `/sbin/rc3.d` but the shutdown link appears in `/etc/rc1.d`, as shown in the following listing:

```
# ls -l /sbin/rc1.d
lrwxr-xr-x    1 root     sys         17 Apr 26 14:52 K220slod -> /sbin/init.d/slod
lrwxr-xr-x    1 root     sys         18 Apr 26 14:45 K230audio -> /sbin/init.d/audio
lrwxr-xr-x    1 root     sys         21 Apr 26 14:46 K240auditlog -> /sbin/init.d/auditlog
lrwxr-xr-x    1 root     sys         17 Apr 26 14:43 K250envd -> /sbin/init.d/envd
lrwxr-xr-x    1 root     sys         17 Apr 26 14:43 K270cron -> /sbin/init.d/cron
lrwxr-xr-x    1 root     sys         15 Apr 26 14:45 K270pd -> /sbin/init.d/pd
lrwxr-xr-x    1 root     sys         15 Apr 26 14:45 K280lp -> /sbin/init.d/lp
lrwxr-xr-x    1 root     sys         21 Apr 26 14:49 K290ipamgr -> /sbin/init.d/ipamgr
lrwxr-xr-x    1 root     sys         20 Apr 26 14:41 K290pararray -> /sbin/init.d/pararray
lrwxrwxrwx    1 root     sys         20 May 16 20:57 K300coldfusion -> ../init.d/coldfusion
```

The link called `/sbin/rc3.d/K300coldfusion` points to our script `/init.d/coldfusion`. Startup for this application takes place at run level 3, and shutdown takes place at run level 1.
