# Front Panel Animation

Animation for front panel or slide-up subpanel drop zones is created by displaying a progressive series of bitmaps. By convention, the bitmaps are in */usr/dd/appconfig/icons*. The list of bitmaps to display is contained in animation definitions at the end of *dftwm.fp*.
