Figure 9-5 Ten VxFS File Systems on Ten Logical Volumes

Using SAM, we created ten VxFS file systems on all ten tvols. We had to create all ten individually in SAM, so this may have been a good candidate for automating with a shell program.

SAM automatically adds these entries to /etc/fstab because we specified that be mounted both now and at the time of system boot, as shown in the following listing:

```
# System /etc/fstab file. Static information about the file systems
# See fstab(4) and sam(1M) for further details on configuring devices.
/dev/vg00/lvol3 / vxfs delaylog 0 1
/dev/vg00/lvol1 /stand bfs defaults 0 1
/dev/vg00/lvol4 /opt vxfs delaylog 0 2
/dev/vg00/lvol5 /tmp vxfs delaylog 0 2
/dev/vg00/lvol6 /usr vxfs delaylog 0 2
/dev/vg00/lvol7 /var vxfs delaylog 0 2
/dev/vg00/lvol8 /home vxfs delaylog 0 2
/dev/vg00/lvol9 ... swap pri=0 0 0
/dev/vsapp/lvol1 /app vxfs rw, suid, largefiles, delaylog, datainlog 0 2
/dev/vgu01/lvol1 /u01 vxfs rw, suid, largefiles, delaylog, datainlog 0 2
```
