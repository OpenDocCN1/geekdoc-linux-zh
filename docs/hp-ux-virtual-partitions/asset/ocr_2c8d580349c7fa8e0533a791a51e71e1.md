Description

“timezone” specifies the time delay in minutes from Coordinated Universal Time in a westerly direction to the local time zone where the system is located. A negative value is interpreted as minutes east from Coordinated Universal Time. The value is stored in a structure defined in “/usr/include/sys/time.h” as follows:

# ulockable_mem

Specify minimum amount of memory that is to remain reserved for system overhead and virtual memory management use.

Acceptable Values:

Minimum: “0”

Maximum: Available memory indicated at power-up

Default: “0” (system sets to appropriate value)

Specify integer value.

Description

“ulockable_mem” defines the minimum amount of memory that is to always remain available for virtual memory management and system overhead. Increasing the amount of unlockable memory decreases the amount of lockable memory.

Specify “ulockable_mem” in 4-Kbyte pages. Note that current amounts of available and lockable memory are listed along with the physical page size in startup messages, which you can view later by running “/etc/dmesg.”
