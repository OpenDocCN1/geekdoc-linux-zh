# ## uptime

uptime produces information about the time at which the system booted and some load data. Let’s run this command for two different vPar running on the same server as shown below:

```
# hostname
cvhdc03
# uptime
2:32pm up 3:02, 2 users, load average: 2.26, 1.96, 1.60
# hostname
cvhdc04
# uptime
2:31pm up 2:41, 2 users, load average: 0.25, 0.22, 0.23
#
```

The information produced by uptime is vPar-specific. The first output we see in this output is the time at which the first vPar booted, and the second output is the time at which the second vPar booted. The other information in this output is also for the specific vPar on which uptime was run. Like most of the commands you’ll execute when vPar are running, you’ll see vPar-specific information, not system-specific information.
