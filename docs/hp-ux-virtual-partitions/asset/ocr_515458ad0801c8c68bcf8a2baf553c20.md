NIS also calls each of these databases a *map*. These are called maps because NIS allows you to map a key, such as a username, to a value field, such as the user's **passwd** entry from the **passwd** map on the NIS Master Server.

# # How Do I Plan For NIS?

NIS requires one NIS Master Server and typically at least one NIS Slave Server per IP subnet. A NIS Master or Slave Server answers requests from NIS clients typically seeking user password information when a user login occurs. NIS is designed in a "top-down" or hierarchical manner, with all changes being made through the NIS Master Server.
