# # Customizing CDE

I’ll preceede each change with a discussion of what is involved in making the change. I’ll be making some basic, simple changes as well as some more advanced changes to show you how versatile CDE can be.

One thing I need to mention is that all these changes can be made on any system. And knowing how to do these tasks “the hard way” increases your understanding of what these tools are doing for you in the background. So be sure to give each one a try.

# ## Making Changes Using Style Manager

# ### Font Size

When we first log in to CDE and the workspace comes up, as shown in Figure 14-7, one of the first things many users change is the size of the font. Initially set to 4, most users want a bigger font. This change is easy.

![](bbox=[0.05, 0.5, 0.91, 0.58])

Figure 14-7  Style Manager

+   1. Click on the **Style Manager** icon on the front panel. This action brings up the Style Manager.

+   2. Click on **Font**.

+   3. **Highlight 5**.

+   4. Click on **OK**.
