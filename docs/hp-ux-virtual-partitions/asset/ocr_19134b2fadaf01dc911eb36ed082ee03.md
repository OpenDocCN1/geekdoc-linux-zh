# F1 - lvidsplay

View detailed logical volume information with lvidsplay. Note that all of these logical volumes are mirrored and that each has "current" status. Only lv01 and lv02 are shown in the listing. lv03 through lv07 are not shown.

```
# lvidsplay -v /dev/vg00/lvol* 

--- Logical volumes ---
LV Name   /dev/vg00/lvol01
VG Name   /dev/vg00
LV Permission   read/write
LV Status available/syncd
Mirror copies 1
Consistency Recovery MWC
Schedule parallel
LV Size (MBbytes) 92
Current LE 23
Allocated PE 46
Stripes 0
Stripe Size (Kbytes) 0
Bad block off
Allocation strict/contiguous
```
