# netstat

From the earlier description of the subnet mask, you can see that routing from one host to another can be configured in a variety of ways. The path that information takes in getting from one host to another depends on routing.

You can obtain information related to routing with the **netstat** command. The **-r** option to **netstat** shows the routing tables, which you usually want to know, and the **-n** option can be used to print network addresses as numbers rather than as names. With the **-v** option, you get additional information related to routing, such as the subnet mask. In the following examples, **netstat** is issued with the **-r** option (this is used when describing the **netstat** output), the **-n** options, and the **-mv** options, so you can compare the outputs:

```
# netstat -r
Routing tables
Dest/Netsmask             Gateway           Flags  Refs     Use    Interface    Metric
o2                       o2                UH      0  1890555    lo0     4136
o2                       o2                UH      0     343    lanl    4136
10.1.1.0                 o2                U       2       0   lan0    1500
10.1.1.0                 o2                U       2       0   lan1    1500
127.0.0.0                o2                U       2       0    lo0     4136
default          10.1.1.1            UG       0       0   lan1    1500
```
