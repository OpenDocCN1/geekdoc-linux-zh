Figure 1-3 Example of Loading vPars Software

Figure 1-3 shows the three components of which TI355AC is comprised: the kernel, monitor, and run environment. The additional components listed earlier, patches and WINSTALL, will also have to be loaded for vPars to be fully operational.

Please keep in mind that because the vPars software used in this chapter has not yet been released, you may see some different product numbers.

After loading this software, a reboot takes place to build the kernel. This is done for you automatically, however; vPars kernel-related background is covered in both Chapters 2 and 4.

All of the vPars software must be loaded on every HP-UX 11i volume that will be used on your vPars server. The loading of this software will take place for every HP-UX 11i instance that you wish to run simultaneously on your vPars server. There are two ways to load the HP-UX 11i operating system and vPars software on all of the volumes used for vPars. The first, which is the method used throughout this book, is to load HP-UX 11i and vPars software on all vPars volumes prior to creating Virtual Partitions. The second is to load only the volume of the first vPar with all software, create as many vPars as you want, and then use `vparboot -v vp_name -1 ignore_kernel to`
