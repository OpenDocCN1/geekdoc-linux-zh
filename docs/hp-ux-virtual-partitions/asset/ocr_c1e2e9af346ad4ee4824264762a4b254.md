# Disk Reconfiguration Flow Diagram - Part 2

From Part 1.

+   - F10
+   Use vgextend to add 1 GByte disk /dev/dsk/ct1s00 at 10/4/4.0 to vg00
+   for mirroring purposes.
+   # vgextend /dev/vg00 /dev/dsk/ct1s10

+   - F11
+   Create physical volume for new 2 GByte disk /dev/dsk/ct5s00 at 100.5.0.
+   # pvcreate -f /dev/dsk/ct5s00

+   - F12
+   Use vgextend to put 2 GByte disk /dev/dsk/ct5s00 at 100.5.0 in vg00
+   # vgextend /dev/vg00 /dev/dsk/ct5s00

+   - F13
+   Use vgdisplay to verify that three disks are now in /dev/vg00: ct0s60 -
+   original, ct1s00 - will be mirror, ct5s00 - will be dump.
+   # vgdisplay -v /dev/vg00

+   - F14
+   Create logical volume to be used for dump on /dev/vg00 with name dump.
+   # lvcreate -n dump /dev/vg00

+   - F15
+   Extend logical volume used for dump to 2 GBytes:
+   logical extent = 508 x 4 MBytes (except)
+   # lvextend -L 508 /dev/vg00/dump /dev/dsk/ct5s00

+   - F16
+   Use lvdisplay to see dump logical volume.
+   # lvdisplay /dev/vg00/dump

+   - F17
+   Make dump lvol contiguous with lvchange and add dump with lvlnboot
+   # lvchange -cy /dev/vg00/dump
+   # lvlnboot -d /dev/vg00/dump

+   - F18
+   View dump devices: ct0s60 is primary (0), ct5s00 is secondary (1).
+   # lvlnboot -v
+   Partial output: Dump lvol2: on: /dev/dsk/ct0s60, 0
+   Dump dump: on: /dev/dsk/ct5s00, 1
