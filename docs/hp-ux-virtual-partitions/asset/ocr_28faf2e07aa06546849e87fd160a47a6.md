# 9) Boot the Second Virtual Partition

Since we already have the first vPar running, called *cable1*, and the second vPar created, called *cable2*, we can boot the second vPar from the first. There are many options to boot vPars. Since we already have the first vPar running, we’ll simply boot the second from the first with **vparboot** and then run **vparstatus -v** as shown in the following example.
