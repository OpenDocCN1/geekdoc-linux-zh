```
# vparstatus
```

```
# vparstatus -p Celo -v
```

Display Bergen's CPU resources in machine-readable format:

```
# vparstatus -p Bergen -M
Bergen:Up;Dynamic,Manual;/stand/vmunix::2/4;/97,101,93,99;1.4.0.0.5.0 BOOT;1.10
:0x44000000/192,0x40000000/512;768
```

Display the name of the current virtual partition:

```
# vparstatus -w
The current virtual partition is Celo.
```
