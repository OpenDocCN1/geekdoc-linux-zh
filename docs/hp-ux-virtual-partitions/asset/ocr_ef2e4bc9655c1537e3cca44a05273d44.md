Use **arp**

If you did not receive a response using **ping** you may have to use **arp** as shown below for a PC and UNIX system:

PC:  	arp -s 192.0.0.192 00-10-83-fa-3f-11
UNIX:	arp -s 192.0.0.192 00: 10: 83: fa: 3f: 11

I have not had to use the **arp** command in my configurations, however, the document at the URL earlier mentioned recommends the **arp** command if indeed your **ping** fails. Reissue the **ping** command after using **arp** to check your connection. The -s option is for a static arp.

Web Browser

With a successful **ping** you can now access the Secure Web Console through your browser.
