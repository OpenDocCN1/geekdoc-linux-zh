# Description

``vmebpn_sockets'' enables or disables the VME socket domain

# vmebpn_tcp_ip

Maximum number of DLPI PPAa allowed.

Acceptable Values:

Minimum: ``0''
Maximum: ``1''
Default: ``1''

Specify integer value.

# Description

``vmebpn_tcp_ip'' specifies the maximum number of DLPI PPAa
allowed on the system. If set to zero, TCP-IP is disabled.
Otherwise, the maximum value is ``1''.

Refer to VME documentation for further information about setting
kernel parameters for the optional VME subsystem.

# vmebpn_tcp_ip_mtu

``vmebpn_tcp_ip_mtu'' specifies the maximum number of Kbytes allowed
in PPA transmission units.

Acceptable Values:

Minimum: `` 0''
Maximum: `` 64''
Default: `` 8''
