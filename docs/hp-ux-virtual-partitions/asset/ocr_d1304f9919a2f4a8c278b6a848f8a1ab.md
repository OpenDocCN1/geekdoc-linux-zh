aliases: files nis
services: nis [NOTFOUND=return] files

As you can see, the *hosts* line has been modified so that we consult the /etc/hosts file first then continue on to *dns* if the query is unsuccessful. There are many ways to modify the switch order and many other things to mess things up. Use discretion when changing the switch order and consult the man pages on *switch* for more information.

# sig_named restart
# kill -HUP `/var/run/named.pid`
