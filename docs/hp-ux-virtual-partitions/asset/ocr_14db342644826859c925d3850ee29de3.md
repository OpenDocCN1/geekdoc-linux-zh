# Virtual Partition Dump Files

When a Virtual Partition crashes, a dump file is created in /stand/vpmon.dump. When the Virtual Partition boots, files are created in /var/adm/crash/vpar. The files have an extension with a number indicating the number of the dump that occurred. For instance, vpmon.1, vpmon.dump.1, and summary.1 indicate the first set of files that are saved in /var/adm/crash/vpar

An example of what you might see in /stand and /var/adm/crash/vpar related to dumps are shown in the following listing:
