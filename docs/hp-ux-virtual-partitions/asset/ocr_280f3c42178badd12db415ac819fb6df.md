`“semume” specifies the maximum number of semaphores that any given process can have undo’s pending on.

`“semmp” is the value of the maximum number of semaphores you can change with one system call. This value is specified in the file `/usr/include/sys/sem.h`.

A “`semop()”` system call using the `SEM_UNDO` flag returns an `“EINVAU”` error if the `“semume”` limit is exceeded.

# ## semvnx

Specify maximum possible semaphore value.

Acceptable Values:

Minimum: `“1”`
Maximum: `“65535”`
Default: `“32767”`

Specify integer value.

# ### Description

`“semvnx” specifies the maximum value a semaphore can have. This limit must not exceed the largest number that can be stored in a 16-bit unsigned integer or undetectable semaphore overflows can occur.

Any “`semop()”` system call that tries to increment a semaphore value to greater than `“semvnx”` returns an `“ERANGE”` error. If `“semvnx”` is greater than `65&sigmaspace:535`, semaphore values can overflow without being detected.

`“semop”` is the value of the maximum number of semaphores you can change with one system call. This value is specified in the file `/usr/include/sys/sem.h`.

# ## semap

Enable or disable System V IPC semaphores support in kernel at system boot time (Series 700 only).
