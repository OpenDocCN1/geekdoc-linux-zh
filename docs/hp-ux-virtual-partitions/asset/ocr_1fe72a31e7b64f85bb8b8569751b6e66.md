There are some points of interest to cover in this **vgdisplay**. The first is that there is a primary and an alternate path to the same disk because we defined them earlier. For instance, the first disk in the volume group has a primary pathname of *c9t0d0* and an alternate pathname of *c8t8d0*. Next, both the volume group *vgu01* and the only logical volume in it, *lvol1*, consist of a total of 8755 PE or physical extents (the size of the volume group is PE x PE size, or 8755 x 4MB in our case).

We should also check one logical volume on *vgu01*, called *lvol1*. We can check the parameters of this logical volume with the **lvdlsplay** command as shown in the following example:
