
## 2. Instruct the machine to boot to ISL from the tape. This is usually done by specifying `sasi.1` as the boot path.

## 3. Enter the following in response to the ISL prompt:

```
ISL> hpxw restore disk[sasi.1:0]
```

This restores the disk image from the tape to the actual disk at `sasi.1.` Any existing data on the disk will be lost. This command destroys the contents of the device specified by devicefile. The restoration process takes about one hour for a 560 MB drive.

NOTE: There is a 2 GB limit on the amount of data that can be restored. The tape and disk must be on the boot device interface.

Also, this command may be replaced in the future by superior installation and recovery mechanisms. At that time, this command will be removed.
