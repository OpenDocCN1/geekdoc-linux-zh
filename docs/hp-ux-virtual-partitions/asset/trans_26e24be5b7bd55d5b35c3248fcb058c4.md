## 使用 `time` 分析命令

如果您有特定的命令想要深入了解，可以使用 `time`，它会报告在执行您指定的任何命令时花费的经过时间、用户时间和系统时间。

```
marvyp $ time listing

sys     0.02
```

```
marvyp $ time -s listing

real    0.02
```
