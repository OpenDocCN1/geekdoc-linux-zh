After making the selection to load from the CD-ROM, another window appears, which is not shown in our example. Here, we specify the location in which the depot will be loaded. By default the directory is /var/opt/ignite/depos (full path /var/opt/ignite/depos/Rel_B.11.11/core as an example for the 11.11 release of HP-UX); however, we can specify any directory location for the depots. If you have a lot of unused disk space in /localapps, for instance, you could make the full path /localapps/depos/Rel_B.11.11/core.
