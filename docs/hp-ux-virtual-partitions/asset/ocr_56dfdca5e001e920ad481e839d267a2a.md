If you're running Restricted SAM Builder, you will also see a status line with the message "Privileges for user: <username>" As you progress down the hierarchy, the title line will change to reflect your level in the SAM hierarchy. You can move into one of the areas shown, such as Backup and Recovery, by double-clicking the left mouse button on this functional area. You move back up the hierarchy by double-clicking the ..(go up) icon, if available, or by selecting the Actions-Close Level menu commands.

You don't need a graphics display to run SAM. You have access to nearly all the same functionality on a text terminal as you do on a graphics terminal. Figure 11-11 is SAM running in character mode with the same functional areas you have in graphics mode, although the bottom selections are not shown in the figure.
