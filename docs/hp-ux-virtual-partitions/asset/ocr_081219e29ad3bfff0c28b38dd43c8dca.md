**Minimum Size** Specify the smallest size file in bytes that you want to search for. Files smaller than this size will not be reported as part of the search. The minimum size in the example is 500,000 bytes.

**Last Modification** If you select *Large Files*, you can make an entry in this field. You enter the minimum number of days since the file was last modified, and files that have been modified within that time period will be excluded from the search. This is 30 days in the example.
