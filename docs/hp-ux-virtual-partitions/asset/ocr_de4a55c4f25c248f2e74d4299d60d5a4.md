# Managing Cache and RAM

If the information you need is not in cache memory but in RAM, then the access will take longer. The speed of all memory is increasing and RAM speed is increasing at a particularly rapid rate. You have a lot of control over the way in which RAM is used. First, you can decide how much RAM is configured into your system. The entire HP product line, both workstations and server systems, supports more RAM than you will need in the system.
