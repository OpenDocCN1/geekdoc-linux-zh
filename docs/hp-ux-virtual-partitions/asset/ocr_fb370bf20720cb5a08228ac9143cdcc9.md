The *SEArCh* command in the previous listing showed us the bootable devices. There are three possible boot devices. The second two are in the internal disks, one of which would normally be the primary boot device and the other which is normally the alternate boot device. These two disks are on two different SCSI buses internal to the L-Class. The first device was the external DVD-ROM that contains the HP-UX 11i CD-ROM, which is operating system media off of which we want to boot.
