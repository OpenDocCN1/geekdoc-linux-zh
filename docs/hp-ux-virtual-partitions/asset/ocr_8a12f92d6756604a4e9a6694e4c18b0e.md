# **vxs_max_ra_kbytes**

Set the maximum amount of read-ahead data, in kilobytes, that the kernel may have outstanding for a single VxFS filesystem.

Acceptable Values:

Minimum: `` `0` ``
Maximum: `` `65536` ``
Default: `` `1024` ``

Specify integer value or use integer formula expression.

# Description

When data is read from a disk drive, the system may read additional data beyond that requested by the operation. This "read-ahead" speeds up sequential disk accesses, by anticipating that additional data will be read, and having it available in system buffers before it is requested.

This parameter limits the number of read-ahead blocks that the kernel is allowed to have outstanding for any given VxFS filesystem. The limit applies to each individual VxFS filesystem, !not! to the system-wide total.
