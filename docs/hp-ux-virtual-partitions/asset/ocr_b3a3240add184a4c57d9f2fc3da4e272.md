# # Boot Console Handler (BCH) & Processor Dependent Code (PDC)

![](bbox=[0.85, 0.7, 0.95, 0.79])

As mentioned earlier, HP 9000 systems come with firmware installed called Processor Dependent Code (PDC). After the system is powered on or the processor is RESET, the PDC runs self-test operations and initializes the processor. PDC also identifies the console path so it can provide messages and accept input. PDC would then begin the "auto-boot" process, unless you were to interrupt it during the 10-second interval that is supplied. If you interrupt the "autoboot" process, you can issue a variety of commands.
