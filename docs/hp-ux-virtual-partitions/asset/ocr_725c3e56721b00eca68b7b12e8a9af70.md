As mentioned earlier, the *hpx* utility manages loading the HP-UX kernel and gives control to the kernel. ISL can have hpxux run an "autoexecute" file or commands can be given interactively. In most situations you would just want to automatically boot the system. however, in our example so far, we have decided to interact with ISL in the interest of looking at some of the functionality in ISL.
