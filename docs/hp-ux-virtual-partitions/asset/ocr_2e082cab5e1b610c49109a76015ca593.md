# About Virtual Partitions

With Virtual Partitions (vParS) you can take almost any HP 9000 server and turn it into many “virtual” computers. These virtual computers can each be running their own instance of HP-UX and associated applications. The virtual computers are isolated from one another at the software level. Software running on one Virtual Partition will not affect software running in any other Virtual Partition. In the Vir-tual Partitions you can run different revisions of HP-UX, different patch levels of HP-UX, different applications, or any software you want and not affect other par-titions.

+   - Minimum of one CPU,
+   - Sufficient memory to run HP-UX and any other software that will be present in the vPar.
