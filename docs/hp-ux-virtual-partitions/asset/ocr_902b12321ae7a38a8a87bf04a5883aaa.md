```
GSP> ss

Monarch Processor: 0

Processor 0 is : Installed and Configured
Processor 1 is : Not Installed
Processor 2 is : Not Installed
Processor 3 is : Installed and Configured

GSP Host Name: uninitialized
GSP>
```
