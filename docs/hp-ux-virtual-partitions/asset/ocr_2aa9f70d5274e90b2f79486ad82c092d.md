| Command (Function) | Explanation |
| :--- | :--- |
| TC (Session) | System reset through IN FT signal. |
| TE (Admin) | Sends a message to other terminals. |
| TN (Session) | Start a Telnet session on local or remote port. |
| UR (Remote) | Unlock remote support modem access. |
| VSC (Config) | Configure the Virtual Front Panel display |
| VFD (Chassis Codes) | Activates the immediate display of the Virtual Front Panel. |
| WHO (Admin) | Display a list of SAS connected users. |
| XD | SAS Diagnostics and Reset. |
| XU | Upgrade the GSP firmware. |
| ZTO GCCD (Chassis Codes) | DEBUG feature: Change the way the chassis codes are displayed by SL command and VFPD. |
