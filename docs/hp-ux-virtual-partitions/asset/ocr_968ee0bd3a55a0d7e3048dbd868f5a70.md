# Virtual Partition Kernel-Related Work

Because memory is shared among multiple vPar, the kernel must be relocatable in memory. At the time of this writing there are patches that allow the kernel to be built as a relocatable kernel. We won't perform any checks related to patches.

The file `/sbin/vecheck` is a vPar file that is required on the system. The following listing is a portion of `/usr/conf/gen/config.sys` that checks to see if `/sbin/vecheck` has been loaded on the system:

```
#
& if $vparvecheck
"vecheck supports kernel relocation. If it does,"
"enable the relocation options"
then
vrel= : "00 - /92453-07 linker (\\ 
spilt($57, vvers, ":") \
if { vver[1] == "B" && \
     vver[2] == 11 && vver[3] >= 25 } 
    print "${LOADOPTS_6ELOC}"
else print "${LOADOPTS_STATIC}"
fi 
fi
```

The following is a long listing of `/sbin/vecheck` that was loaded with the vPar software:

```
# ll /sbin/vecheck
# -r-xr-xr-x  1 bin    bin    20533 Mar  5 19:01 /sbin/vecheck
```
