# ## 2) Load the Virtual Partitions Application Software

The Virtual Partitions software must also be loaded on the volumes that will be used to host all vPars. At the time of this writing there are *base* and *full* versions of the software. The restrictions of the *base* software is a maximum of two vPars and a maximum of one CPU in one of the vPars.
