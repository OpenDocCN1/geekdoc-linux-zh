If a card you have installed is not included in the list, you can select this to determine the reason.

+   **Zoom**

If you highlight a card and select *Zoom*, you will be provided such information as the hardware path, driver, and description of the card.

+   **Remove**

If you highlight a card and select *Remove*, a window will appear that walks you through removing the card from the system.

+   **Show Device Files**

If you select this, a window will be opened in which the device files associated with the card will be listed.

+   **Create Device Files**

Creates device files for the selected card. This takes place without any user interaction.
