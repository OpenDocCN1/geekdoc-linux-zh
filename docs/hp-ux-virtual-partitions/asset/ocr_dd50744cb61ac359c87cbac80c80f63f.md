Software Distributor Background

| Command | Explanation |
|---|---|
| swlist -l depot | Shows all depots on the local host. |
| swlist -l depot @ sys | Shows all depots on sys. |

I also like to use the -a option with **swlist**. -a specifies that you would like to see a specific attribute associated with the software you are listing. You can look at the sd manual page on your HP-UX system to get a complete list of attributes. One attribute I often look at is size. To get a list of the subproducts in NETWORKING and their size in KBytes, you would issue the following command:

```
$ swlist -l subproduct -a size NETWORKING
```

Another attribute I often view is revision, which you can view with the following command:

```
$ swlist -l subproduct -a revision NETWORKING
```

Sometimes, the brief descriptions of filescts that are given are insufficient to really understand the fileset. The title attribute provides a descriptive title, which you can see with the following command for the fileset level:

```
$ swlist -l fileset -a title NETWORKING
```

Table 1-3 is a list of some attributes that you may find of interest.

# **TABLE 1-3 List of Some Attributes of Interest**

| Attribute | Explanation |
|---|---|
| architecture | Shows the target systems supported by the software. |
| category | Shows the type of software. |
| description | Shows more detailed description of software. |
| title | Shows the official name of the software. |
