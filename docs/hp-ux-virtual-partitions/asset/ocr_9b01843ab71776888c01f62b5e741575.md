Users that are required for specific applications need to be set up on all vParS on which an application is going to run. Since vParS are like individual sys-
tems, you'll put the users, including application users, on the vParS where
you need them and not on others. On a system running Broadvision and Ora-cle, for instance, you would set up the users required for those applications.
