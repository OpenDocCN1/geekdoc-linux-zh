# vpartition - Displays information about the vPars Command Line Interface.

vpartition(5)			vpartition(5)

NAME
vpartition - display information about the Virtual Partition Command Line Interface

SYNOPSIS
vpartition

DESCRIPTION
This manpage gives a listing and brief description of the commands which are used to manage virtual partitions.

| Command | Description |
| :--- | :--- |
| **vparsboot** | Boot (start) a virtual partition. |
| **vparscreate** | Create a new virtual partition. |
| **vparsdump** | Manage monitor dump files. |
| **vparsxtract** | Extract memory images from a running virtual partition system. |
| **vparsmodify** | Modify an existing virtual partition. |
| **vparsreloc** | Relocate the load address of a vmutex file, determine if a vmutex file is relocatable, or promote the scope of symbols in a relocatable vmutex file. |
| **vparsremove** | Remove (delete) an existing virtual partition. |
| **vparsreset** | Send a TOC or hard reset to a virtual partition. |
| **vparsresources** | Description of virtual partition resources and their requirements. |
| **vparsstatus** | Display virtual partition and available resources information. |
| **vparsutil** | Get and set SCSI parameters for disk devices from a virtual partition. |
