Specify integer value.

Description

This parameter is of interest only if process accounting is being used on the system.

“accsuspnd” prevents accounting files from invading file system free space by specifying the minimum amount of available file system space that must be kept available for other uses while process accounting is running. If the available space drops below that value, accounting is suspended until sufficient file space becomes available again so accounting can resume.

Selecting a Value for “accsuspnd”

Related Parameters

“accsuspnd” and “acctresume” are interrelated. To prevent suspend-resume conflicts, the signed, integer value of “accsuspnd” must always be less than the signed, integer value of “acctresume”.
