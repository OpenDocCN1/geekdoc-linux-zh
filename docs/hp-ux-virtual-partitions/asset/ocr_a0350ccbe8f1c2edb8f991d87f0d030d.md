In addition to using the console to switch between vPars, you can also use the $LAN$ cards configured into the respective vPars to open a $TELNET$ or other type of session to the vPar. This is the same technique you would use to connect to any system over the network and is one of the primary reasons you always want to have a $LAN$ card configured as part of every vPar.
