# Graphical Package Tools

Both the Debian-based and Red Hat–based package management systems have graphical tools for making it easier to install software in desktop environments. One tool that is available in both the Ubuntu and Rocky distributions is *gnome-software*.

The *gnome-software* program is a graphical front end to the `PackageKit` tool, which itself is a front end that standardizes the interface to multiple package management tools, including *apt* and *yum*. By including both `PackageKit` and *gnome-software*, Linux distributions can provide a standard graphical interface for users to manage their software packages.
