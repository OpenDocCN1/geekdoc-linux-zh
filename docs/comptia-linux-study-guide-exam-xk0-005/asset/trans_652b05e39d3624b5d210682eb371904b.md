

9. E. 要将特定的服务单元设置为在启动时运行，你需要使用 `systemctl enable` 命令，后跟服务单元名称。因此，选项 E 是正确答案。`restart` 命令会停止并立即重启服务，但无法控制服务单元是否在系统启动时启动。`start` 命令会启动服务，但同样无法控制服务单元是否在系统启动时启动。`isolate` 命令用于 systemd 目标单元，而不是服务单元。选项 D 的 `disable` 命令会将特定的服务单元设置为不在启动时运行（禁用其启动）。

10. B. 要更改系统的默认目标，你需要使用 `systemctl set-default` 命令，将目标名称作为参数传递，并使用超级用户权限。`get-default` 命令会显示系统当前的默认目标。`isolate` 命令用于跳转到新目标，而不是设置默认目标。`is-enabled` 命令对于配置为在系统启动时启动的任何服务显示 enabled，对于未配置为在系统启动时启动的任何服务显示 disabled。它仅涉及服务，因此选项 D 是错误的选择。`is-active` 命令也仅涉及服务。

11. D. `blame` 命令显示每个运行中的单元初始化所花费的时间，单元及其时间从最慢到最快列出。这样，你可以从列表顶部的单元开始进行调查。`time` 命令显示系统初始化在内核和初始 RAM 文件系统上花费的时间，以及正常系统用户空间初始化所花费的时间。然而，它无法帮助你确定哪些单元配置可能导致启动缓慢。`dump` 命令显示有关所有单元的数据，但数据格式并不便于追踪哪个单元在启动时初始化花费的时间最长。因此，选项 B 是错误的选择。选项 C 的 failure 是一种服务状态，表示服务已失败。`verify` 命令非常有用，它会扫描单元文件，如果发现任何错误，会显示警告信息。然而，它不提供配置信息来帮助你找出系统启动缓慢的原因。

12. C, E. 使用 SysV init 的基于 Debian 的 Linux 发行版仅使用 0 到 2 的运行级别。`runlevel` 命令显示上一个运行级别，如果是新启动则显示 N。因此，在较旧的、使用 SysV init 的基于 Debian 的 Linux 发行版系统上，此 `runlevel` 命令只会显示选项 C 和 E。选项 A 是错误的，因为它显示当前运行级别为 5，而基于 Debian 的系统不使用该运行级别。选项 B 也是错误的，因为它也显示当前运行级别为 5。选项 D 是错误的，因为它显示当前运行级别为 3，而基于 Debian 的系统也不使用该运行级别。

13. A. 对于 SysV init 系统，默认运行级别存储在 `/etc/inittab` 文件中的 `initdefault` 记录中。因此，选项 A 是正确答案。`/etc/rc.d` 是一个目录，而不是文件。因此，选项 B 是错误的。rc 文件可以位于 `/etc/init.d/` 或 `/etc/rc.d/` 目录中的脚本。它在切换运行级别或引导系统时运行启动各种系统服务的脚本。然而，此脚本不包含任何有关默认运行级别的信息。因此，选项 C 和 D 是错误的选择。`/etc/rc.local` 文件允许你在系统初始化完成后发出某些命令或运行任何脚本。然而，此脚本也不包含任何有关默认运行级别的信息。

14. C. 存储旧（和新）SysV init 系统服务启动脚本的目录是 `/etc/init.d/` 目录。因此，选项 C 是正确答案。`/etc/rc.d/rcn.d/` 目录在 SysV init 系统上使用，但它们包含指向 `/etc/init.d/` 目录中脚本的符号链接。因此，选项 B 是错误的。选项 A、D 和 E 都是 systemd 目录。因此，它们都是错误的选择。

15. A, B, D, E. 运行级别 1 也称为单用户模式。你可以使用 `/init` 或 `telinit` 命令跳转到该运行级别，并传递以下三个参数之一：1、S 或 s。因此，选项 A、B、D 和 E 是正确答案。你不能使用 `o` 参数来访问运行级别 1，因此选项 C 是唯一错误的选择。

16. B. 最佳使用的命令是 `service status` 命令，将服务名称作为参数传递给它。这将显示服务的当前状态，并允许你快速开始故障排除过程。因此，选项 B 是正确答案。`service start` 命令将启动指定的服务，但你不知道此服务是否已停止。因此，它不是最佳使用的命令，选项 A 是错误的选择。`service --status-all` 命令不是最佳使用的命令，因为它显示所有各种服务的状态。因此，选项 C 是错误的。`service stop` 命令将停止指定的服务，如果服务已经停止，则提供 FAILED 状态。然而，这不是在 SysV init 系统上检查服务状态的最佳方式。`service reload` 命令将加载指定服务的配置文件，如果服务已停止，则提供 FAILED 状态。再次说明，这不是检查服务状态的正确方式。

17. D. 要在基于 Red Hat 的 SysV init 系统上为运行级别 3 和 5 启用 DHCP 服务，正确的命令是使用 `chkconfig --levels 35 dhcp on`。因此，选项 D 是正确答案。选项 A 和 E 是错误的，因为你不能将 `service` 命令用于启用 SysV init 服务。选项 B 是错误的，因为你不能使用分隔符（例如逗号）来分隔运行级别列表。选项 C 是错误的选择，因为此命令中的服务名称和 `on` 参数颠倒了。

18. E. 要在基于 Debian 的 SysV init 系统上为默认运行级别启用 DHCP 服务，正确的命令是使用 `update-rc.d dhcp defaults`。因此，选项 E 是正确答案。选项 A 是错误的，因为最后一个命令参数应该是 `defaults` 而不是 `off`。选项 B 是错误的，因为你不能将 `chkconfig` 命令用于基于 Debian 的发行版。选项 C 是错误的选择，因为此命令中的服务名称和 `default` 参数颠倒了。此外，它还使用了错误的参数——参数应该是 `defaults`。选项 D 中使用的命令是错误的，因为此命令中的服务名称和 `defaults` 参数颠倒了。

19. C. 挂载单元文件名的创建方式是：移除绝对目录引用的前导正斜杠（/），将随后的正斜杠转换为连字符（-），并移除尾随正斜杠。挂载单元文件名还带有 `.mount` 扩展名。因此，`/var/log/` 挂载点的挂载单元文件将是 `var-log.mount`。因此，选项 C 是正确答案。`/var/log.mount` 单元文件名是错误的，因为正斜杠未被移除或替换。此外，`/var/log.unit` 基础文件名是错误的，因为正斜杠未被移除或替换。此外，`var-log.un` 基础文件名是错误的，因为使用了错误的文件扩展名。`var/log.mount` 单元文件名是错误的，因为中间的正斜杠未被连字符替换。

20. A, C, D. 对于 systemd 自动挂载单元文件，`[Automount]` 文件部分中仅包含的指令是 `Where`、`DirectoryMode` 和 `TimeoutIdleSec`。因此，选项 A、C 和 D 是正确答案。`Options` 和 `What` 指令是你在挂载单元文件的 `[Mount]` 部分中会看到的指令。因此，选项 B 和 E 是错误的选择。

## 第 7 章：配置网络连接

1. C, D. `nmtui` 命令提供交互式文本菜单，用于选择网络接口并设置网络参数，而 `ip` 命令提供用于设置网络参数的命令行工具，因此选项 C 和 D 都是正确的。`netstat` 命令显示有关网络连接的信息，但它不设置网络参数，因此选项 A 是错误的。`ping` 命令可以向远程主机发送 ICMP 数据包，但不设置本地网络参数，因此选项 B 是错误的。`route` 命令设置路由网络参数，但不设置 IP 地址或子网掩码，因此选项 E 是错误的。

2. B. 从版本 17.04 开始，Ubuntu 已切换到使用 Netplan 工具来设置网络地址信息，因此选项 B 是正确答案。`netstat` 命令不设置网络信息，而是显示活动的网络连接，因此选项 A 是错误的。`iwconfig` 命令设置无线网络参数，但不设置网络地址信息，因此选项 C 是错误的。`route` 命令设置默认路由器信息，但不设置网络地址信息，因此选项 D 是错误的。`ifconfig` 命令确实设置网络地址信息，但较新版本的 Ubuntu 不使用它，因此选项 E 是错误的。

3. A. `ethtool` 命令显示网卡的功能和参数，因此选项 A 是正确答案。`netstat` 命令显示网络统计信息和连接，因此选项 B 是错误的。`wconfig` 和 `iwlist` 命令用于设置无线网络参数，而不是以太网卡设置，因此选项 C 和 D 是错误的。`route` 命令设置或显示路由信息，而不是以太网卡设置，因此选项 E 是错误的。

4. E. `ss` 命令显示 Linux 系统上打开的端口列表，以及每个端口关联的过程，因此选项 E 是正确的。`iwconfig` 命令设置无线网络信息，而不是打开的端口，因此选项 A 是错误的。`ip` 命令显示或设置网络接口上的网络信息，但不显示打开的端口，因此选项 B 是错误的。`ping` 命令向远程主机发送 ICMP 消息，但不显示任何打开的端口，因此选项 C 是错误的。`nmtui` 命令允许你配置网络接口的网络参数，但不显示系统上打开的端口，因此选项 D 是错误的。
