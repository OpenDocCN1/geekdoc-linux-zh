
## 摘要与分析

**概括分析网络设备状态所需的工具。** `ntm_ui`、`nmcli`、`ifconfig` 和 `ip` 命令显示系统上所有网络接口的当前状态。你还可以使用 `netstat` 或 `ss` 命令来显示所有监听网络端口的统计信息。

**描述 Linux 如何初始化网络接口。** 基于 Debian 的 Linux 系统使用 `/etc/network/interfaces` 文件来配置 IP 地址、子网掩码和默认路由器。基于 Red Hat 的 Linux 系统使用 `/etc/sysconfig/network-scripts` 文件夹中的文件。`ifcfg-ens3` 文件包含 IP 地址和子网掩码设置，而 `network` 文件包含默认路由器设置。系统启动时会检查这些文件以确定网络接口配置。较新版本的 Ubuntu 使用 Netplan 工具，它将在 `/etc/netplan` 文件夹中存储网络配置。

**解释如何测试网络连通性。** `ping` 和 `ping6` 命令允许你向远程主机发送 ICMP 消息并显示接收到的响应。`traceroute` 命令允许你查看用于到达特定远程主机的网络路径。`mtr` 命令提供特定远程主机的实时连通性和响应统计信息。

**描述一个用于在 Linux 中配置网络设置的图形工具。** 网络管理器（Network Manager）工具提供了一个图形界面，用于更改网络接口上的设置。网络管理器显示为桌面系统托盘区域中的图标。如果 Linux 系统使用无线网卡，图标显示为无线电波信号；而对于有线网络连接，它显示为迷你网络。当你点击图标时，它会显示当前网络状态，对于无线接口，它会显示检测到的接入点列表。当你打开网络管理器界面时，它可以让你设置静态 IP 地址信息，或者配置网络使用 DHCP 服务器动态设置网络配置。

图形用户界面（GUI）是一组允许用户通过图标、窗口和其他各种视觉元素与计算机系统进行交互的程序。虽然有些人认为你应该仅通过基于文本的命令行来管理系统，但了解 Linux GUI（发音为“gooey”）仍然很重要。你可能需要使用某些 GUI 实用程序来管理系统及其安全性。

不同的 Linux 发行版带有各种默认的桌面环境，你可能需要为偏好图形用户界面的用户安装和管理这些环境。管理底层软件也是必要的。此外，你需要了解远程桌面及其客户端-服务器模型。通过网络传输的远程桌面交互容易受到隐私问题的影响，因此保护这些 GUI 传输至关重要。

对各种 GUI 桌面的访问应为所有人提供通用访问权限。GUI 桌面环境需要配置得能够适当地适用于视力、听力、手部和手指控制等方面有问题的人。因此，我们很高兴在本章中介绍一个关于无障碍性的部分。

## 关注 GUI

在某些操作系统中，你的 GUI 相当僵化。你可能能够移动或添加几个图标，更改背景图片，或微调一些设置。然而，在 Linux 中，GUI 选择几乎令人不知所措，灵活性巨大。

在 Linux 中，GUI 是一系列协同工作的组件，为用户界面（UI）提供图形设置。其中一个组件是*桌面环境*。桌面环境为 GUI 提供预定的外观和感觉。它通常由以下图形部分和功能组成：

**桌面设置** 桌面设置包括允许你对桌面环境进行配置更改的程序。例如，你可能希望桌面窗口在光标悬停时激活，而不是在点击时激活。

**显示管理器** 桌面环境的登录屏幕是你选择用户名并输入密码以获得系统访问权限的地方。如果系统上安装了多个桌面环境，显示管理器允许你在登录前选择它们。这些登录屏幕通常由公司修改以包含关于系统适当使用的法律声明和/或公司徽标。
