Before you can copy the new time zone file, you'll need to remove the original \texttt{timezone} or \texttt{localtime} file:

```
$ sudo ln -s /usr/share/zoneinfo/America/Chicago /etc/localtime
$ date
Sat Dec 4 07:23:14 CST 2021
$ 
```

The new time zone appears in the output from the \texttt{date} command.

If you just need to change the time zone for a single session or program, instead of changing the system time zone you can set the time zone using the \texttt{TZ} environment variable. That overrides the system time zone for the current session.

# ## Setting the Time and Date

Once you have the correct time zone for your Linux system, you can work on setting the correct time and date values. There are a few different commands available to do that.

# ### Legacy Commands

There are two legacy commands that you should be able to find in all Linux distributions for working with time and date values:

+   - \texttt{hwclock} displays or sets the time as kept on the internal BIOS or UEFI clock on the workstation or server.
+   - \texttt{date} displays or sets the date as kept by the Linux system.

The \texttt{hwclock} command provides access to the hardware clock built into the physical workstation or server that the Linux system runs on. You can use the \texttt{hwclock} command to set the system time and date to the hardware clock on the physical workstation or server. Or, it also allows you to change the hardware clock to match the time and date on the Linux system.

The \texttt{date} command is the Swiss Army knife of time and date commands. It allows you to display the time and date in a multitude of formats in addition to setting the time and/or date. The \texttt{+} option allows you to specify the format used to display the time or date value by defining command sequences:

```
$ date +"%A, %B %d, %Y"
Saturday, December 04, 2021
$ 
```
