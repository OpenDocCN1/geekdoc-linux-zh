
## 第 8 章：比较图形用户界面

5. A、C。`nrc1` 和 `ip` 命令都允许你从命令行设置和更改网络设置，因此选项 A 和 C 都是正确的。`iwconfg` 命令仅设置无线网络信息，因此选项 B 是错误的。`netstat` 命令显示打开的端口，但不更改任何网络设置，因此选项 D 是错误的。`ping` 命令发送 ICMP 数据包到远程主机进行测试，但它也不设置任何网络设置，因此选项 E 是错误的。

6. A。默认路由用于将数据包从本地网络发送到远程网络，因此，要与远程主机通信，你需要定义默认路由地址，这使得选项 A 正确。子网掩码仅定义本地网络；它不定义如何处理发往远程主机的数据包，因此选项 B 是错误的。主机名和 IP 地址仅定义本地主机的特征，因此选项 C 和 D 是错误的。DNS 服务器定义了如何根据域名检索主机的 IP 地址，因此选项 E 是错误的。

7. E。DNS 服务器将主机名映射到 IP 地址，因此，为了在应用程序中使用主机名，你必须在网络配置中定义一个 DNS 服务器。因此，选项 E 是正确的。默认路由仅定义了如何将数据包发送到远程主机；它不将主机名映射到 IP 地址，因此选项 A 是错误的。子网掩码值定义了本地网络，但不定义如何映射主机名到 IP 地址，因此选项 B 是错误的。主机名和 IP 地址定义了本地主机的特征，因此选项 C 和 D 是错误的。

8. B。动态主机配置协议（DHCP）用于为网络上的客户端工作站分配动态 IP 地址，因此选项 B 是正确的。默认路由器不能为设备分配地址，因此选项 A 是错误的。ARP 表将网卡的硬件地址映射到 IP 地址，但不分配 IP 地址，因此选项 C 是错误的。子网掩码值确定了网络地址，但不确定主机的 IP 地址，因此选项 D 是错误的。`i` 命令可以设置主机的静态 IP 地址，但不会自动分配 IP 地址，因此选项 E 是错误的。

9. B。回环地址是分配给回环接口的特殊地址，它允许本地应用程序相互通信，这使得选项 B 成为正确答案。动态和静态 IP 地址被分配给网络接口，这些接口与远程系统交互，而不是本地应用程序，因此选项 A 和 C 是错误的。主机名为远程连接识别本地主机，而不是为本地应用识别，因此选项 D 是错误的。MAC 地址识别网卡的硬件地址，但不被本地应用程序使用，因此选项 E 是错误的。

10. A。`dig` 命令可以显示域名中单个主机的记录，你可以使用它来查找该域名的 MX 邮件主机，因此选项 A 是正确的。`host` 命令仅显示主机 IP 地址信息；它无法根据 DNS 记录确定服务器类型，因此选项 D 是错误的。`netstat` 和 `ss` 命令显示活动的网络连接，但不显示远程主机类型，因此选项 B 和 E 都是错误的。`ping6` 命令发送 IPv6 ICMP 数据包以测试远程主机，但无法判断远程主机是否为邮件服务器，因此选项 C 是错误的。

11. B。`ss` 命令可以显示开放的端口以及拥有这些端口应用程序，因此选项 B 是正确的。`ip` 和 `i` 命令仅显示或设置网络配置，因此选项 A 和 E 是错误的。`host` 和 `dig` 命令仅显示主机名信息，因此选项 C 和 D 也是错误的。

12. A。基于 Red Hat 的系统使用单独的文件来存储 IP 地址和路由器信息。这些文件存储在与 /etc/sysconfig/network-scripts 文件夹中，因此选项 A 正确。选项 B 是 Debian 基系统存储 interfaces 文件的位置，该文件包含网络配置设置。ifcfg-eth0 是用于存储配置的文件，而不是文件夹，因此选项 C 是错误的。ifconfig 和 iwconfig 是命令而不是文件夹，因此选项 D 和 E 是错误的。

13. B。Debian 系统使用 iface 设置来配置接口的功能，并且你必须指定 dhcp 选项以动态获取 IP 地址，这使得选项 B 正确。选项 C 和 E 是错误的，因为它们不使用 iface 设置。选项 A 为接口设置静态 IP 地址而不是动态地址，因此是错误的。选项 D 设置链路本地 IPv6 地址而不是动态 IP 地址，因此是错误的。

14. B。DNS 服务器使用 nameserver 设置列在 /etc/resolv.conf 配置文件中，因此选项 B 是正确的。/etc/dhcpd.conf 文件定义了 DHCP 服务器的配置设置，因此选项 A 是错误的。/etc/nsswitch.conf 文件定义了系统搜索主机名的顺序，而不是使用的 DNS 服务器列表，因此选项 C 是错误的。/etc/network/interfaces 文件定义了基于 Debian 系统的网络接口，而不是 DNS 服务器列表，因此选项 D 也是错误的。/etc/sysctl.conf 文件定义内核网络参数，而不是 DNS 服务器列表，因此选项 E 是错误的。

15. A。ifconfig 命令必须指定网络接口、IP 地址，然后是 netmask 选项，接着是子网掩码地址。你可以使用 up 或 down 选项使网卡默认处于活动或非活动状态，但这不是必需的。选项 A 是唯一以正确顺序使用正确值的选项。选项 C 接近正确但未能指定网络接口。选项 B 格式不正确，选项 D 和 E 未能列出必要的配置设置。

16. A。iwlist 命令显示由无线网卡检测到的可用无线网络接入点，因此选项 A 是正确的。iwconfig 命令配置网卡以连接到特定接入点，但不会列出所有检测到的接入点，因此选项 B 是错误的。选项 C 指定 ifconfig 命令，它用于为无线网卡分配 IP 地址，但不列出接入点。选项 D 中指定的 ip 命令同样可用于设置网卡的 IP 地址，但不列出接入点。选项 E，arp 命令，将硬件地址映射到 IP 地址，以便你可以查找网络中重复的 IP 地址，但它不列出无线接入点。

17. D。SSID 值定义了接入点名称，它通过 iwconfig 命令中的 essid 选项进行设置，这使得选项 D 成为正确答案。key 选项指定连接接入点所需的加密密钥，而不是接入点名称，因此选项 A 是错误的。netmask 和 address 值不由 iwconfig 命令设置，因此选项 B 和 C 是错误的。channel 选项定义了接入点使用的无线电频率，而不是接入点名称，因此选项 E 也是错误的。

18. E。ip 命令允许你同时显示和设置网络接口的 IP 地址、子网掩码和默认路由值，因此选项 E 是正确的。ifconfig 命令可以设置 IP 地址和子网掩码值，但不能设置默认路由。iwconfig 命令用于设置无线接入点设置，router 命令用于设置默认路由，但不设置 IP 地址或子网掩码值。ifup 命令仅激活网络接口；它不能设置地址值。

19. C。ping 命令向指定的远程主机发送 ICMP 数据包并等待响应，这使得选项 C 成为正确答案。netstat 命令显示关于网络接口的统计数据，因此它是错误的。ifconfig 命令显示或设置网络信息，但不发送 ICMP 数据包，因此选项 B 是错误的。iwconfig 命令显示或设置无线网络信息，但不处理 ICMP 数据包，因此选项 D 是错误的。ss 命令显示系统中打开的连接和端口的信息，因此选项 E 也是错误的。

20. B。tcpdump 命令显示通过系统网络接口的网络数据包，因此你可以使用它来监控网络上的应用程序数据包，这使得选项 B 成为正确答案。nc 命令允许你手动在网络中发送数据包，但它不允许你监控应用程序数据包，因此选项 A 是错误的。ping 和 traceroute 命令仅向远程服务器发送 ICMP 数据包；它们不监控数据包，因此选项 C 和 D 是错误的。mtr 命令可以显示到远程服务器的连接状态，但不允许你查看发往服务器的应用程序数据包，因此选项 E 是错误的。

1. C。桌面环境是一系列协同工作的组件，为用户提供图形化设置。因此，选项 C 是正确答案。图形用户界面（GUI）是一组允许用户通过图标、窗口和各种其他视觉元素与系统交互的程序。因此，选项 A 是错误的。显示管理器操作你选择用户名并输入密码以获得系统访问权限的屏幕。因此，选项 B 是错误的选择。文件管理器是允许你以图形方式执行文件维护活动的程序。因此，选项 i 也是错误的选择。窗口管理器是一组确定窗口如何在桌面上呈现的程序。因此，选项 E 也是错误的选择。

2. A、B、C、E。收藏夹栏、文件管理器、图标和系统托盘都是图形用户界面的一部分。因此，选项 A、B、C 和 E 是正确的选择。命令行是输入基于文本命令的位置，虽然你可以使用终端模拟器从 GUI 访问它，但它不被视为图形用户界面的一部分。因此，选项 D 是唯一错误的选择。

3. A。SDDM（Simple Desktop Display Manager）是 KDE Plasma 桌面环境的默认显示管理器。因此，选项 A 是正确答案。Files，也称为 GNOME files，是 GNOME Shell 桌面环境中的文件管理器。因此，选项 B 是错误的。Mutter 是 GNOME shell 窗口管理器，因此选项 C 是错误的。GDM 代表 GNOME Display Manager。因此，选项 D 是错误的选择。Dock 是 GNOME Shell Dash 的另一个名称，它是 GNOME Shell 中的收藏夹栏。因此，选项 E 也是错误的选择。
