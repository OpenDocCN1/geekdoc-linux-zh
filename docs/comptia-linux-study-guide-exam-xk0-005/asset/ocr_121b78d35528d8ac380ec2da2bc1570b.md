Typically the remote repository will demand a username and a password, unless you have set it up to use SSH keys (OpenSSH was covered in Chapter 16, “Looking at Access and Authentication Methods”). When the project is pushed to the remote repository, you should be able to view it. If it is a private repository, you’ll have to log into the remote repository in order to see your work. Figure 27.2 shows the remote repository for this project. Keep in mind that different providers will have different user interfaces for your projects.
