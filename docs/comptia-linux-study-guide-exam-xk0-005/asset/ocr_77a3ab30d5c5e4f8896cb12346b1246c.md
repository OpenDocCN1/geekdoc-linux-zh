# ## Setting Your Locale

As shown in Listing 9.1, there are three components to how Linux handles localization. A locale defines the language, the country, and the character set the system uses. Linux provides a few different ways for you to change each of these localization settings.

# ### Installation Locale Decisions

When you first install the Linux operating system, one of the prompts available during the installation process is for the default system language. Figure 9.1 shows the prompt from a Rocky Linux 8 installation.

When you select a language from the menu, the Linux installation script automatically sets the localization environment variables appropriately for that country and language to include the character set necessary to represent the required characters. Often that's all you need to do to set up your Linux system to operate correctly in your locale.

# ### Changing Your Locale

After you've already installed the Linux operating system, you can still change the localization values that the system uses. There are two methods available to do that. You can manually set the LC\_ environment variables, or you can use the `localectl` command.
