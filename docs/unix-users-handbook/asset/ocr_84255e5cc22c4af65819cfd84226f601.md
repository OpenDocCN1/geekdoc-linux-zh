Figure 16-8 *Exports* Window Showing Exported File Systems

You can use the IP address, as shown in Figure 16-8, or the host name to specify the host on which you wish to view the exported file systems. You can see that this window takes the /etc/exports file and clarifies some of the entries. The entries that have no restrictions now have an "(everyone)" associated with them, and only system nyc_interop may mount the other file systems.

Now we can specify one or more of these exported file systems on the UNIX system that we wish to mount on the Windows system. Using the NFS Network Access from the NFS Maestro menu, we can specify one of these file systems to mount. Figure 16-9 shows mounting /home/hp on the UNIX system on the F: drive of the Windows system. Note that we are UNIX user hp when we mount this file system.
