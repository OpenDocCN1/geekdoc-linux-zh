second. You may recall that ICMP was covered earlier under the net- work, or third layer. **ping** stands for Packet InterNet Groper. **ping** dif- fers somewhat among UNIX variants mostly in the reporting that **ping** produces when no options are provided.

Some systems provide performance information when **ping** is issued with no options; others report that the system “is alive”. The following is an example of checking the connection between the local system and another system on the network called *austin*:

```
martyp $ **ping austin**
austin is alive
martyp $
```
