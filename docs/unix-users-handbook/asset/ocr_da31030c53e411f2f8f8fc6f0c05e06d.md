# ## chmod

![](bbox=[0.03, 0.11, 0.13, 0.19])

**chmod** - Changes permissions of specified files using symbolic or absolute (sometimes called numeric) modes. Symbolic mode is described below.

Symbol of who is affected:

+   - u User is affected.
- g Group is affected.
- o Other is affected.
- a All users are affected.

Operation to perform:

+   - + Add permission.
- - Remove permission.
- = Replace permission.

Permission specified:

+   - r Read permission.
- w Write permission.
- x Execute permission.
- u Copy user permissions.
- g Copy group permissions.
- o Copy other permissions.
