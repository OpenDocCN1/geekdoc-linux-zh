**mput**
Copy multiple files from the local host to the remote host.
Example: **mput \*.c**

**bye/quit**
Close the connection to the remote host.
Example: **bye**

Other **ftp** commands are available in addition to those I have covered here. If you need more information on these commands or wish to review additional **ftp** commands, the UN1X manual pages for **ftp** are helpful.
