Note that the `split` command produced several files from **listing** called xaa, xab, and so on. The -1 option is used to specify the number of lines in files produced by `split`. Here is a summary of the `split` command.

**split** - Split a file into multiple files.

**Options**

+   -l `line_count`       Split the file into files with `line_count` lines per file.

-b n              Split the file into files with n bytes per file.
