# **Block Device File (UNIX example)**

(Described by the **file** command as *block special*.)

```
```
# ls -l /dev/dsk/c0t1d0
brw-r--r--    1 bin     sys       31 0x001000 Apr 17  1999 /dev/
          dsk/c0t1d0
# file /dev/dsk/c0t1d0
/dev/dsk/c0t1d0:        block special (31/4096)
#
