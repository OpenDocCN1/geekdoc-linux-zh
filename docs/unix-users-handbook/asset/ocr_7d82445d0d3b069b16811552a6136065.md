The third component, update expression, is performed after the statements in the body of the loop are executed. It allows the controlling variables to be updated. After the update expression is performed, the looping condition is re-tested to determine whether the loop should continue. The following example illustrates the for loop:

```
int x;          /* control variable used in the for loop */
for ( x = 0; x < 3; x++ ) /* loop exactly 3 times */
{
    printf("%d ", x); /* print the control variable, x */
}
printf("\nThe loop is complete.\n");
```
