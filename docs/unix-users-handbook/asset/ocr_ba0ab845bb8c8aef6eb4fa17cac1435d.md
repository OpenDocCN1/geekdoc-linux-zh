# The Basis of UNIX

Most everything in UNIX comes down to files and directories. If you understand the hierarchical UNIX file system layout and how to manipulate files and directories, then you’re a long way toward UNIX understanding.

A lot goes into working with UNIX files and directories. This chapter covers the basics and background of files and directories in UNIX. The next chapter covers commands related to files and directories. The only command covered in this chapter is the file command, used to determine the type of file.
