I usually run HP MeasureWare Agent for a minimum of a week so that I obtain log information over a long enough period of time to obtain useful data. For some systems, this time period is months. For other systems with a regular load, a week may be enough time.

After having run MeasureWare for a week, I invoked PerfView to see the level of system resource utilization that took place over the week. The graphs we'll review are CPU, Memory, and Disk. Figure 13-9 shows Global CPU Summary for the week.
