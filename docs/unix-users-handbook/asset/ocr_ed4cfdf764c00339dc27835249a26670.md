There are also comparison operators, such as the "<" used in the example, as well as arithmetic, bitwise, and logical operators. As you craft more and more shell scripts, you will want to use all these operators.

There are a set of test conditions related to files that are useful when writing shell scripts that use files. Using the format - operator filename you can use the tests in Table 11-3.

# TABLE 11-3 Operator File Name Tests

| Operator | Meaning |
| :--- | :--- |
| r | read access |
| w | write access |
| x | execute access |
| o | ownership |
| z | zero length |
| f | file, not a directory |
| d | directory, not a file |
