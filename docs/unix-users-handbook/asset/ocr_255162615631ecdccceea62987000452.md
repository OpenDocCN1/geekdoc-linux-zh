```
$ echo $HOME
/root
```

The "$" preceding the environment variable name specifies that the value of the variable be sent to standard output. In this case, the value of the environment variable HOME is /root, which means that the current user has a home directory of /root.

You can define your own environment variables in Bash with the following syntax:

```
export NAME=value
```

You could set your prompt, defined by the PS1 environment variable, with the following command:

```
PS1=[\u@\h \W]\$
```

PS1 has now been set to open bracket, user name, at sign, host name, space, home directory, close bracket, dollar sign. As you can see from the previous listing of environment variables, PS1 has by far the most difficult format.

You can also append to the end of an existing variable with the following format:

```
export NAME="${NAME}:appended_information"
```

To add /root/programs to the existing PATH environment variable, for instance, you would issue the following command:

```
export PATH="${PATH}:/root/programs"
```
