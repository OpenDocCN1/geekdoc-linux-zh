# ## Character Device File (UNIX example)

(Described by the **file** command as *character special*. )

```
# ls -l /dev/rds k/c0t1d0
  c rw-r-----  1 root  sys  188 0x001000 Mar 23  1999 /dev/
  r dsk/c0t1d0
# file /dev/rds k/c0t1d0
  /dev/r dsk/c0t1d0:
  character special (188/4096)
#
```
