# What Should I Look for When Using GlancePlus?

Because GlancePlus provides a graphical representation of the way in which your system resources are being used, the answer is simple: See which bars have a high “Avg” utilization. You can then probe further into the process(es) causing this high utilization. If, for instance, you find that your memory is consistently 99 percent utilized, press the F3 function key and have GlancePlus walk you through an investigation of which of your applications and users are memory hogs.
