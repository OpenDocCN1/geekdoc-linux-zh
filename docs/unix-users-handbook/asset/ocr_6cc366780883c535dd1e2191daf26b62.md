The following example shows issuing the **NET USER** command
with no options:

```
C:\ NET USER
```

Using the second form of the command shown earlier, we can
add a new user to the system:

```
C:\ NET USER amyp \* /ADD
```

```
Type a password for the user:
```

```
Retype the password to confirm:
```

```
The request will be processed at the primary domain controller for domain DEV.
```

```
The command completed successfully.
```

The asterisk in the **NET USER** command means that we want to
be prompted for the password for the new user *amyp*.
