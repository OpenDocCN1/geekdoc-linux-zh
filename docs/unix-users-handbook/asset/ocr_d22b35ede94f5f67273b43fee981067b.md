Although 19 configuration files are still a lot, don't be alarmed by the number. You won't need to modify many of them, and can ignore a couple you modify once and then forget. You need to under-stand in depth for periodic modification only one or two, perhaps a system-wide *.dt file for custom actions and datatypes or maybe dtwm.fp, if you are required to modify the front panel on a regular basis for some reason.

Still, configuring CDE is not something you want to start hack-ing with without a little preparation and a good idea of what you want to accomplish. All CDE configuration files are pretty well com-mented, so a good first step is to print the ones you want to modify.
