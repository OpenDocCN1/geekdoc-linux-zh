# ## touch

**touch** - Changes the modification and/or last access times of a file, or creates a file.

Some commonly used options:

+   - `-c`    Does not create a specified file if it does not exist.
- `-f`    Forces a touch of a file regardless of permissions.

![](bbox=[0.04, 0.43, 0.12, 0.53])

The following example creates **file1** with **touch**:

```
`D:\> ls -l file1`
`ls:file1: No such file or directory`

`D:\> touch file1`

`D:\> ls -l file1`
`-rw-rw-rw-  1 Administ Administ        0 Feb 20 11:45 file1`
```
