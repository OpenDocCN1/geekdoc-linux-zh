This chapter will introduce you to programming basics and three popular languages: C, C++ and Java. The content and structure is tar-geted at beginner programmers, working through basic concepts. The upcoming programming sections are only an introduction. They don't provide enough of information to be used as a reference for a specific programming language. You want to supplement each of these sec-tions with a book dedicated to the language(s) you'll be using.
