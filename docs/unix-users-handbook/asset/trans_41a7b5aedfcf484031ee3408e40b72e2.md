

# ls

![](img/75f39fc91296b889c0653851accdfd46_1340_0.png)

**ls** - 列出目录的内容。

一些常用选项：

- **-a** 列出所有条目。
- **-c** 使用文件的最后修改时间来确定文件列出的顺序。
- **-d** 仅列出目录名，而不列出其内容。
- **-g** 在输出中包含组信息。
- **-i** 在报告的第一列中打印 inode 号。
- **-q** 非打印字符用“?”表示。
- **-r** 反转文件打印的顺序。
- **-s** 以块为单位显示大小，而不是字节。
- **-t** 按保存时间排序列出，最近的排在前面。
- **-u** 使用最后访问时间而不是最后修改时间来确定文件打印的顺序。
- **-A** 与 -a 相同，但不列出当前目录和父目录。
- **-C** 产生多列输出。
- **-F** 目录后跟“/”，可执行文件后跟“*”，符号链接后跟“@”。
- **-L** 列出链接指向的文件或目录。
- **-R** 递归列出子目录。

# mkdir

**mkdir** - 创建指定的目录。

以下是一个常用选项：

- **-p**
  创建中间目录以实现完整路径。如果你想创建多层目录，请使用 **-p**。

![](img/75f39fc91296b889c0653851accdfd46_1344_0.png)

# mv

![](img/75f39fc91296b889c0653851accdfd46_1345_0.png)

**mv** - 重命名文件和目录。

以下是一些常用选项：

- **-i**
  交互式移动，提示确认是否要覆盖现有文件。
- **-f**
  如果发生文件名冲突，强制用正在移动的文件覆盖现有文件。

# rm

**rm** - 删除文件和目录。

以下是一些常用选项：

- **-d**
  删除目录以及其他类型的文件。
- **-i**
  交互式删除，提示确认是否要删除现有文件。
- **-f**
  强制删除文件。
- **-r** (-R)
  递归删除目录的内容，然后删除目录本身。

# touch

**touch** - 更改文件的修改时间和/或最后访问时间，或创建一个文件。

一些常用选项：

- **-c** 如果指定文件不存在，则不创建该文件。
- **-f** 无论权限如何，都强制接触（更新）文件。

![](img/75f39fc91296b889c0653851accdfd46_1347_0.png)

以下示例使用 **touch** 创建 **file1**：

```
D:\> ls -l file1
ls:file1: No such file or directory

D:\> touch file1

D:\> ls -l file1
-rw-rw-rw-  1 Administ Administ        0 Feb 20 11:45 file1
```

# wc

![](img/75f39fc91296b889c0653851accdfd46_1348_0.png)

**wc** - 统计单词、行数和字符数。

以下是一些常用选项：

- **-l**
  打印文件中的行数。
- **-w**
  打印文件中的单词数。
- **-c**
  打印文件中的字符数。

第一个示例列出目录内容，并将输出管道传输到 **wc**。第二个示例提供关于文件 **system.ini** 的 **wc** 信息。

## arp

**arp** 用于显示和编辑地址解析协议 (arp) 缓存，该缓存将 IP 地址映射到物理硬件地址。缓存中包含最近访问的一个或多个系统的地址。以下示例展示了在地址为 113 的 Windows 系统上发出 **arp** 命令，并显示最近访问的地址为 111 的系统及其物理硬件地址。

```
d:\> **arp -a**

Interface: 159.260.112.113 on Interface 2

  Internet Address          Physical Address        Type
  159.260.112.111          08-00-09-f0-bc-40       dynamic
```

**arp** 命令有几个选项，您可以通过发出 **arp /? 命令**来查看。
