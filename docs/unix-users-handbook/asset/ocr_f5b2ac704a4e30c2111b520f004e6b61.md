If you are not sure how many command-line arguments you may get when your program is run, there are two other variables that can help:

+   - $\# The number of command line arguments
- S* A space-separated list of all of the command line arguments (which does not include the command name).

The variable S* is commonly used with a for loop to process shell script command lines with any number of arguments.
