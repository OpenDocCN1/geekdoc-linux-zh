If you decided that you would like to add write permission of the file **sort** for *group* and remove all permissions for *other*, you would simply execute the **chmod** command with the appropriate numeric value. The following set of commands first lists the existing permissions for **sort**, next changes the permissions on **sort**, and finally lists the new permissions on **sort**:

```
```
$ ls -1 sort
-rwxr-x--x   1 marty    users        120 Jul 26 10:20 sort
$ chmod 770 sort
$ ls -1 sort
-rwxrwx---   1 marty    users        120 Jul 26 10:20 sort
