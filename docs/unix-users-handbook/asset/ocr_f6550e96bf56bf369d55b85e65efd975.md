# Check Processes with ps

![](bbox=[0.85, 0.07, 0.99, 0.17])

command. There are a number of options you can use with **ps**. I normally use **e** and **f**, which provide information about every ("e") running process and lists this information in full ("f"). **ps** outputs are almost identical going from system to system. The following three examples are from a Solaris, AIX, and HP-UX system, respectively:
