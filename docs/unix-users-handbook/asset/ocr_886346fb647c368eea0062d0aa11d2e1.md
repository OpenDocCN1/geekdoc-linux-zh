# NET TIME

**NET TIME** - This command is used to display the time for a computer or to synchronize the clock of a computer with the clock on another computer.

The following is a summary of the **NET TIME** command.

```
C:\ NET TIME /?
```

```
NET TIME (\\computername | /DOMAIN[:domainname]) [/SET]
```

Some commonly used options follow:

\\\computername The computer with which you want to synchronize the time or of which you want to display the time.

/DOMAIN[:domainname] The domain name with which you want to synchronize the time.

/SET Sets the computer’s time with the time on the specified computer or domain.
