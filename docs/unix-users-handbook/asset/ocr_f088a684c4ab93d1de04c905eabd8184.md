Notice that the ELSE is associated with the first IF statement. The nested IF statement does not have a corresponding ELSE, because action only needs to be taken if the balance of the account is $0.

A case statement uses the value of an expression to select one of several choices for execution:

```
CASE part number for UNIX software

101: Print Linux
102: Print RedHat Linux
103: Print HP-UX
104: Print Solaris

ELSE Print bad part number
END
```
