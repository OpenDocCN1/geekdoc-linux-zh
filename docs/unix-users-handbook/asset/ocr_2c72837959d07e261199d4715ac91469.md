Some good numbers to record are “Avail Memory” (to see whether you have any free RAM under either condition) and “Total VM” (to see how much virtual memory has been allocated for all your processes). A system that is RAM-rich will have available memory; a system that is RAM-poor will allocate a lot of virtual memory.
