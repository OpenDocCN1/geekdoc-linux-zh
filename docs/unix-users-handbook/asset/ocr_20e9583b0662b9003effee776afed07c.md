# NET USER

**NET USER** - This command creates and modifies accounts on computers. This can also be used without options to list accounts.

The following is a summary of the **NET USER** command.

```
C:\ NET USER /?
NET USER [username [password | *]] [options] [/DOMAIN]
username [password | *] /ADD [options] [/DOMAIN]
username [/DELETE] [/DOMAIN]
```

Some commonly used options follow:

1. /ADD Adds a user account.
2. /DELETE Removes a user account.
3. username The name of the account to manipulate. You can add, delete, modify, or view the account.
4. password Assigns or changes the password of a user account.
5. * Displays the password prompt.
6. /DOMAIN The action is to be performed on the primary domain controller.
