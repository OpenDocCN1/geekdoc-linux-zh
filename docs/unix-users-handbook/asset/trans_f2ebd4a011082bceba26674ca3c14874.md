
## 历史记录列表

```
martyp $ history
125 man fc
126 set | more
127 exit
128 history
129 k
130 env | more
131 set | more
132 more .profile
133 more .profile | grep rof
134 more .profile | grep vi
135 more /etc/profile | grep vi
136 set |grep edit
137 set | grep vi
138 env | grep vi
139 history
140 who
martyp $ history
```

![](img/75f39fc91296b889c0653851accdfd46_335_0.png)

输入 `escape k` 会调出最后一条发出的命令，在本例中即为第 140 行的 `who` 命令。每按一次 `k`，就会获取前一条 `ksh` 命令。这等同于按下 `escape` 键和 `-`（减号）键。你可以使用 `escape nk` 指定要在历史记录列表中回溯的命令数量，其中 `n` 是你希望回溯的命令数。以下示例展示了输入 `escape 5k` 以调取历史记录列表中倒数第五条命令：

```
martyp $ history
125 man fc
126 set | more
127 exit
128 history
129 k
130 env | more
131 set | more
132 more .profile
133 more .profile | grep rof
134 more .profile | grep vi
135 more /etc/profile | grep vi
136 set |grep edit
137 set | grep vi
138 env | grep vi
139 history
140 who
martyp $ set |grep edit
```

![](img/75f39fc91296b889c0653851accdfd46_335_1.png)

输入 `escape 5k` 调出了历史记录列表中倒数第五条，即第 136 行的命令。这等同于输入 `escape 5`。

你还可以在历史记录列表中向前移动，使用 `j` 的方式与我们使用 `k` 向后移动历史记录的方式相同。让我们在历史记录列表中向后移动五条命令至第 136 行，输入 `escape 5k`，然后使用 `escape 3j` 向前移动三条命令至第 139 行，如下例所示：

```
martyp $ history
125 man fc
126 set | more
127 exit
128 history
129 k
130 env | more
131 set | more
132 more .profile
133 more .profile | grep rof
134 more .profile | grep vi
135 more /etc/profile | grep vi
136 set | grep edit
137 set | grep vi
138 env | grep vi
139 history
140 history
martyp $ who
```

输入 `escape 3j` 使我们前进到第 139 行，这与输入 `escape 3` 相同。

我们还可以使用 `escape G` 回到历史记录列表中最旧的命令。你可以使用 `escape nG` 回到历史记录列表中特定的命令编号，其中 `n` 是来自历史记录文件的特定命令编号。以下示例展示了输入 `escape 126G` 从历史记录列表中回到第 126 行：

```
martyp $ history
125 man fc
126 set | more
127 exit
128 history
129 k
130 env | more
131 set | more
132     more .profile
133     more .profile | grep rof
134     more .profile | grep vi
135     more /etc/profile | grep vi
136     set |grep edit
137     set | grep vi
138     env | grep vi
139     history
140     who
martyp $ set | more
```

![](img/75f39fc91296b889c0653851accdfd46_337_0.png)

你还可以基于搜索从历史记录列表中调出行。例如，如果你想从历史记录列表中调出最近包含 **profile** 的命令，你可以输入 `/profile`，即斜杠字符后跟 **profile**，以获得以下示例中显示的结果：

```
martyp $ history
125     man fc
126     set | more
127     exit
128     history
129     k
130     env | more
131     set | more
132     more .profile
133     more .profile | grep rof
134     more .profile | grep vi
135     more /etc/profile | grep vi
136     set |grep edit
137     set | grep vi
138     env | grep vi
139     history
140     who
martyp $ more /etc/profile | grep vi
```

![](img/75f39fc91296b889c0653851accdfd46_337_1.png)

搜索最近出现的 **profile** 产生第 135 行。**vi** 中的许多其他搜索也可以在命令行中使用。**vi** 章节和 **vi** 快速参考卡片中包含更多你可能想在命令行上尝试的搜索信息。

## 使用 vi 指令在命令行上编辑

在你“调取”想要编辑的命令或输入了需要编辑的命令后，你可以使用你的 **vi** 指令在命令行上进行修改。

![](img/75f39fc91296b889c0653851accdfd46_338_0.png)

**ksh** 在从历史记录列表中调取命令后立即将你置于输入模式。这种方法是**vi**程序（用于编辑文件）的相反，后者默认将你置于控制模式。从历史记录列表中调取命令后，若要在 **ksh** 中使用 **vi**，你必须按下 *escape* 才能进入控制模式。

![](img/75f39fc91296b889c0653851accdfd46_338_1.png)

现在让我们对从历史记录列表中调取的一些命令进行简单的修改。我们通过 *escape* **286G** 序列从历史记录列表中调出第 **286** 行。调取此命令后，我们通过 **i cat** 在命令开头插入 *cat*。**i** 表示在当前光标位置左侧插入文本。以下示例展示了调取第 286 行并插入 **cat** 的结果：

```
martyp $ history
285       history
286       more /etc/profile | grep vi
287       who
288       whoami
289       who
290       ls -al
291       alias
292       pwd
293       ls -al /home
294       cat .profile
295       history
296       vi .profile
297       cat /etc/passwd
298       cat /etc/passwd | grep donna
299       pwd
300       history
martyp $ cat more /etc/profile | grep vi
```

可以看到，`i cat` 在行首插入了 `cat`。

我们可以再次调取第 286 行，并使用 A 在行尾追加文本，如下例所示：

```
martyp $ history
285	history
286	more /etc/profile | grep vi
287	who
288	whoami
289	who
290	ls -al
291	alias
292	pwd
293	ls -al /home
294	cat .profile
295	history
296	vi .profile
297	cat /etc/passwd
298	cat /etc/passwd | grep donna
299	pwd
300	history
martyp $ more /etc/profile | grep vieditor
```

![](img/75f39fc91296b889c0653851accdfd46_339_0.png)

在此示例中，我们使用序列 A `editor` 在我们调取的那行命令行末尾插入了单词 `editor`。

![](img/75f39fc91296b889c0653851accdfd46_339_1.png)

我们可以通过发出序列 `cw cat` 调取此行并将行首的 `more` 更改为 `cat`，如下例所示：

```
martyp $ history
285	history
286	more /etc/profile | grep vi
287	who
288	whoami
289	who
290	ls -al
291	alias
292	pwd
293	ls -al /home
294	cat .profile
295	history
296	vi .profile
297  cat /etc/passwd
298  cat /etc/passwd | grep donna
299  pwd
300  history
martyp $ cat /etc/profile | grep vi
```

![](img/75f39fc91296b889c0653851accdfd46_340_0.png)

这将命令行中的 *more* 更改为 **cat**。

若要删除单词 *more* 而不替换它，我们调取第 286 行并发出 **dw**，如下例所示：

![](img/75f39fc91296b889c0653851accdfd46_340_1.png)

```
martyp $ history
285  history
286  more /etc/profile | grep vi
287  who
288  whoami
289  who
290  ls -al
291  alias
292  pwd
293  ls -al /home
294  cat .profile
295  history
296  vi .profile
297  cat /etc/passwd
298  cat /etc/passwd | grep donna
299  pwd
300  history
martyp $ /etc/profile | grep vi
```

如果我们对最近发出的命令不满意，我们可以发出 **u** 来撤销命令，这撤消了我们在命令行上删除 *more* 时使用的 **dw**，如下例所示：

```
martyp $ history
285  history
286  more /etc/profile | grep vi
287  who
288  whoami
289  who
290  ls -al
291  alias
292	pwd
293	ls -al /home
294	cat .profile
295	history
296	vi .profile
297	cat /etc/passwd
298	cat /etc/passwd | grep donna
299	pwd
300	history
martyp $ more /etc/profile | grep vi
```

![](img/75f39fc91296b889c0653851accdfd46_341_0.png)

![](img/75f39fc91296b889c0653851accdfd46_341_1.png)

![](img/75f39fc91296b889c0653851accdfd46_341_2.png)

发出 **u** 恢复了我们用 **dw** 删除的 *more*。

你可能想尝试使用我在本文涵盖的 **vi** 命令，以及其他在命令行上添加、删除、更改、搜索和替换、复制和撤销的命令。

## KornShell 中的别名

别名是你为常用命令或一系列命令选择的名称。许多别名是为你预定义的。

不带任何参数的 **alias** 命令会列出所有别名。此列表既包括预设别名，也包括你设置的别名。以下命令显示了我所在系统上的预设别名：

```
martyp $ alias
autoload='typeset -fu'
command='command'
functions='typeset -f'
history='fc -l'
hyper1='HHLIC='/opt/local/bristol/hyperhelp/licenses/hhptc1;export HHLIC'
hyper36='HHLIC='/opt/local/bristol/hyperhelp/licenses/hhptc36;export HHLIC'
hyper83='HHLIC='/opt/local/bristol/hyperhelp/licenses/hhptc83;export HHLIC'
hyper95='HHLIC='/opt/local/bristol/hyperhelp/licenses/hhptc95;export HHLIC'
integer='typeset -i'
local=typeset
nohup='nohup'
r='fc -e -'
stop='kill -STOP'
suspend='kill -STOP $$'
martyp $
```
