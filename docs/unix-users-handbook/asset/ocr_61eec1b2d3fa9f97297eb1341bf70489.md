```
comm -12 file1 file2
```

Print all lines that appear in file1 but not in file2 (in other words, print column 1):

```
comm -23 file1 file2
```

Print all lines that appear in file2 but not in file1 (in other words, print column 2):

```
comm -13 file1 file2
```
