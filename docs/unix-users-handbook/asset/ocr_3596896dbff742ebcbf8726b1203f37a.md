# Virtual Functions

Polymorphism is accomplished through a combination of inheritance and virtual functions.

A *virtual function* is declared as virtual in the base class and is redefined in one or more derived classes. This definition allows each derived class to have its own version of the virtual function. A virtual function is called through a base class pointer. C++ determines which version of the virtual function to call based upon the type of the object
