# Common Desktop Environment

The Common Desktop Environment (CDE) represents the effort of major UNIX vendors to unify UNIX at the desktop level. CDE is widely used by X terminal and workstation users on many UNIX systems, including IBM's AIX systems, Hewlett Packard's HP-UX systems, and Sun Microsystems' Solaris systems. This chapter provides an introduction to CDE: basics of CDE's look and feel, making changes to the CDE environment, and a bit of background about the X, Motif, and CDE relationships. CDE versions used to write this chapter are: AIX CDE 1.0, HP-UX CDE 2.1.0, and Solaris CDE 1.3. Newer releases will have enhanced features, but in general, they should still work the same.

Several features make it easy to customize CDE. The style manager, which every user has access to, makes it easy to customize CDE on an individual user basis. Sooner or later, however, you may want to provide some common denominator of CDE functionality for your users.
