After you click the Connect button in the window, you have /home/hp mounted as F:. The means by which you specify the system and file system you wish to mount with NFS Maestro is two slashes preceding the IP address or system name, another slash following the IP address or system name, and then the name of the file system you wish to mount. Note that the forward slash is part of the file system name. I used the IP address of the system. To view all the mounted file systems on the Windows system, you can invoke Windows Explorer.
