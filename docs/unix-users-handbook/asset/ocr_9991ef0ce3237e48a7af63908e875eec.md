# Changes Using Style Manager

# Font Size

When we first log in to CDE and the workspace comes up, as shown in Figure 4-4, one of the first things many users change is the size of the font. Initially set to 4, most users want a bigger font. This change is easy.

![](bbox=[0.092, 0.385, 0.955, 0.51])

+   1. Click on the **Style Manager icon** on the front panel. This action brings up the Style Manager.

+   2. Click on **Font**.

+   3. Highlight **5**.

+   4. Click on **OK**.
