**rm** - Remove files and directories.

Options

+   -i		Interactive remove whereby you are prompted to confirm that you wish to remove an existing file.
-f		Force files to be removed.
-r (-R)	Recursively remove the contents of the directory and then the directory itself.

# rmdir

![](bbox=[0.05, 0.79, 0.12, 0.81])

![](bbox=[0.05, 0.83, 0.12, 0.87])

The **rmdir** command removes one or more directories. The directory must be empty in order to be removed. You can also specify more than one directory to be removed. Going back to our earlier discussion on permissions, you must have both *write* and *execute* permissions on the parent of a directory to be removed in order to remove it.
