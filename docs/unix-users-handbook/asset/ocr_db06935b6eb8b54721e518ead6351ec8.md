Pay(). A user could even give a raise to the employee by calling the EMPLOYEE member function GiveARaise(). Both methods, GetPay() and GiveARaise(), are contained in the class EMPLOYEE and are part of EMPLOYEE’s public interface. The interface is a contract that EMPLOYEE makes with its users: it tells the users what the class can do. This is shown in Figure 14-8.
