# # Command-Line History

You can view the history list a variety of different ways. Let’s first view the last 20 commands by simply issuing the **history** command:

```
```
sys1 23: history
        4 whoami
        5 pwd
        6 find / -name login -print &
        7 hostname
        8 who
        9 more /etc/passwd
       10 history
       11 history 5
       12 echo $PATH
       13 more .login
       14 cat .login
       15 exit
       16 exit
       17 history -h
       18 pwd
       19 whoami
       20 cd /tmp
       21 cat database.log
       22 cd
       23 history
sys1 24:
```
```

We can also print the history list without line number, as shown in the following example:

```
```
sys1 24: history -h
pwd
find / -name login -print &
hostname
who
more /etc/passwd
history
history 5
echo $PATH
more .login
cat .login
exit
