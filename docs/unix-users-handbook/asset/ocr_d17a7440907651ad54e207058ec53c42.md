# Search and Replace in vi

You have a lot of search and replace functionality in vi. Table 8-6 summarizes some of the more common search-and-replace functionality in vi.

![](bbox=[0.87, 0.44, 0.94, 0.53])

| Command | Search and Replace Action |
| :--- | :--- |
| *text* | Search for *text* going forward into the file. |
| ?*text* | Search for *text* going backward into the file. |
| **n** | Repeat the search in the same direction as the original search. |
| **N** | Repeat the search in the opposite direction as the original search. |
| f*text* | Search for *text* going forward in the current line. |
| F*text* | Search for *text* going backward in the current line. |
