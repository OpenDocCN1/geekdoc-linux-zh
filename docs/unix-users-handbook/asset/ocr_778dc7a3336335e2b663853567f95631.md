Looking at the 32-bit address in binary form, you can see how to determine the class of an address:

![](bbox=[0.24, 0.41, 0.76, 0.59])

net.host.host.host

A class “A” address has the first bit set to 0. You can see how so many nodes per network can be supported with all the bits devoted to the node or host address. The first bit of a class A address is 0, and the remaining 7 bits of the network portion are used to define the network. There are then a total of 3 bytes devoted to defining the nodes within a network.
