The user's initial group is determined at the time the job is started, not when the job is scheduled. If the user's initial group is not defined, the job runs in the user default group (PRMID=1). See prmconfig(l) for a description of how to configure HP PRM, and prmconf(4) for a description of how the user's initial process resource group is determined.
