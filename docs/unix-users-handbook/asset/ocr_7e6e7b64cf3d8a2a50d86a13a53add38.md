# Macros and Abbreviations

![](bbox=[0.02, 0.5, 0.13, 0.58])

You are not limited to issuing individual **vi** commands. You can define strings of **vi** commands and define a key corresponding to this string that you can recall. When defining the keys for your macros, you can’t use the following: **K V g q v \* =** and function keys. There are also control keys you can’t use, so stay away from control keys in general. Table 8-16 shows macros and abbreviations.

**Table 8-16 Macros and Abbreviations In vi**

| Option | Action |
| :--- | :--- |
| `:map *key* *command_seq*` | Define *key* to run *command_seq*, such as `:map e ea` to append text whenever you use **e** to move to the end of a word. |
| `:map` | Display all defined macros on the status line. |
