If you create a new file (**script2**) for your shell script, you may need to make it executable with the **chmod** command. If a file has permissions of 666 (rw-rw-rw-) and you wish to give the owner execute permission, you would issue the following command:

```
sys1 3: **chmod 766 script2**
```
