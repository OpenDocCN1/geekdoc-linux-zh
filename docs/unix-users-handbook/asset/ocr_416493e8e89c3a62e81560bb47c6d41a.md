**pattern_to_match** is the user input that you are testing, and if it is equal to **pattern1**, then the commands under **pattern1** are exe-cuted. If **pattern_to_match** and **pattern2** are the same, then the com-mands under **pattern2** will be executed, and so on. If no match occurs between **pattern_to_match** and one of the case statement patterns, then the default is executed. The following program allows you to pick from among two scripts through its menu.
