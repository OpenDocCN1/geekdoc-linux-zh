Here are four commonly used forms of **if**:

```
1) if (expression) command
2) if (expression) then
command(s)
endif
3) if (expression) then
command(s)
else
command(s)
endif
4) if (expression) then
command(s)
[else if expression) then
command(s)]
.
.
.
[else
command(s)]
endif
```

There are many operators that can be used in the C shell to compare integer values, such as the < used in the previous example. Here is a list of operators:

+   > greater than
< less than
>= greater than or equal to
<= less than or equal to
== equal to
!= not equal to
