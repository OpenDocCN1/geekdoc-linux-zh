After the installation and configuration are complete, you have **netdemon** running, which is an essential component of Advanced Server/9000, as shown in the following `ps` command:

```
# `ps -ef | grep netdemon`
root 1100 1 0 10:18:38 ? 0:00 /opt/Imu/netbios/bin/netdemon
#
```

In addition to **netdemon**, NetBIOS must also be running.
Advanced Server/9000 starts several processes on your UNIX system in addition to **netdemon**. You can also verify that the Advanced Server/9000 server is running by viewing its processes with the `ps` command:

```
# `ps -ef | grep lm`
root 3285 1 0 10:37:19 ? 0:00 lmx.dmn
root 3200 1 0 10:36:57 ? 0:00 lmx.ctl
root 3262 3200 0 10:37:07 ? 0:00 lmx.srv -s 1
root 3295 1 0 10:37:20 ? 0:00 lmx.sched
root 3289 1 0 10:37:19 ? 0:00 lmx.browser
root 1100 1 0 10:18:38 ? 0:00 /opt/Imu/netbios/bin/netdemon
#
```

Many process are shown here, such as *Imx.dmn*, which is the daemon; *Imx.ctl*, which is the control process; *Imx.sched*, which is the scheduler; *Imx.browser* which is the browser; and *Imx.srv*, which is a client session. If Advanced Server/9000 is not running, you would use the **net start server** command to start the server. Similarly, you stop the server with **net stop server**.
