# Editing Files with vi

vi was the first full-screen text editor written for Unix. It was designed to be
small enough to fit on the old-fashioned, tiny, floppy-based emergency boot sys-
tems. When the GNU Project developed an open source replacement for the vi
editor, they added several improvements to it and called it “vi improved,” or vim.
Though many Linux distributions ship with vim, it is still referred to
as vi editor, vim is upward compatible with the vi editor, and the command
launch vim is typically vi—though some distributions have a vi command
instead. The information presented in this chapter applies to both vi and vim.

Although the vi editor is useful for editing configuration files, it really shines in
editing program files, such as shell scripts. Thus you will benefit from learning the vi
editor, though it is considered by many to be the most complicated text editor to.

# Understanding vi Modes

To use vi, you should first understand the modes in which it operates. Then you
begin to learn the text-editing procedures that vi implements. With any
moment, vi is running in one of three modes:

Command Mode This mode accepts commands, which are usually entered as
single letters. For instance, i and a enter insert mode, although in somewhat
different ways, as described shortly, and o opens a line below the current one.

Ex Mode To manipulate files (including saving your current file and run-
ing outside programs), you use ex mode. You enter ex mode from command
mode by typing a colon (:), typically directly followed by the name of the ex
command that you want to use. After you run the ex mode command, vi
returns automatically to command mode.

Insert Mode You enter text in insert mode. Most keystrokes result in text\appearing on the screen. One important exception is the Esc key, which exits
insert mode and returns to command mode.

Unfortunately, terminology surrounding vi modes is inconsistent as that.
For instance, command mode is sometimes referred to as normal mode, and
insert mode is sometimes called edit mode or entry mode. Ex mode isn't
described as a mode at all, but is referred to as colon commands.
