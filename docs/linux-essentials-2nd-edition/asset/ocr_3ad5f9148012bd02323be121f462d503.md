# Setting Permissions

This example gives ownership of targetfile.edf to bob. You can change the file's principal owner and its group with a single command by separating the owner and group with a colon (:):

```
$ chown bob:users targetfile.edf
```

This example gives ownership of targetfile.edf to bob and associates the file with the users group. To change the group without changing the owner, you can omit the owner, leaving the colon and group name:

```
$ chown:users targetfile.edf
```

Alternatively, you can use the chgrp command, which works in the same way but changes only the group and does not require the colon before the group name:

```
$ chgrp targetfile.edf
```

Note that the commands used to change the group as an ordinary user—but only if you own the file and belong to the target group.
nThe chown and chgrp commands both support a number of options that modify what they do. The most useful of these is -R (or--recursive), which causes a change in ownership of all the files in an existing directory. For instance, suppose that the user has left a company, and an existing employee, bob, must access her files. If mary's home directory is /home/mary, you might type this:

```
$ chown -R bob /home/mary
```

This command gives bob ownership of the /home/mary directory, all the files in the /home/mary directory, including all its subdirectories, the files in the directories, and so on. To make the transition a bit easier for bob, you might also want to move mary's former home directory into bob's home directory.
