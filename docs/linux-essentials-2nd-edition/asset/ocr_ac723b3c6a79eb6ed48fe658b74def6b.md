# Comparing Linux to Unix

If you attempt to draw a "family tree" of OSs, you would end scratching your head at. This is because OS designers often mimic each other's features, and sometimes incorporate each other's ideas into their OS's workings. The result can be a tangled mess of similarities between OSs, with cases ranging from coincidence to code "borrowing." Attempting to map these influences can be difficult. In case of Linux and Unix, though a broad statement is possible: Linux is modeled after Unix.

Unix was created in 1969 at AT&T's Bell Labs. Unix's history is complex and involves multiple forks (that is, splitting of the code into two or more independent projects) and entirely separate code rewrites. Modern Linux systems are, by large, the type of open source projects that clone Unix, or of original open source projects for Unix generally. These projects include the following:

+   The Linux Kernel Linux Torvalds created the Linux kernel as a hobby project in 1991, but it soon grew to be much more than that. The Linux kernel was designed to be compatible with other kernels, in the sense that it used the same software interfaces in source code. This made using open source programs for Unix versions them easy.
The GNU Project GNU's Not Unix (GNU) project is an effort by the Free Software Foundation (FSF) to develop open source replacements for all the core elements of an OS. In 1991, the FSF had already released the most important of such tools, with the notable exception of the kernel. The GNU HURD kernel is now available, but is not as popular as the Linux kernel.
