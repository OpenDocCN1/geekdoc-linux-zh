# User Interfaces

Like OS X, Windows uses its own unique user interface. This
ributes to poor inter-OS portability. (Tools exist to help bridge the gap,
th: Windows System implementations for Windows are available, as are,
tools for running programs in Linux.) Some users prefer the Windows
user interface to any Windows desktop environment, but others prefer a Linux
desktop environment.

# Configurability

Although both OSs provide the means to run specific programs at startup,
change user interfaces, and so on. Linux's source nature means that
you can tweak any detail that you wish. Furthermore, you can pick any Linux
variant that you like to get a head start on setting up the system as you see fit.
