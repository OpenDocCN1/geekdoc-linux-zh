# Understanding Disk Issues

The most common partitioning scheme for .x86 and .x86-64 computers has gone by various names over the years, including master boot record (MBR), MS-DOS, and BIOS partitioning. It supports three types of partitions:

**Primary** This is the simplest type of partition. A disk can have zero to four primary partitions, one of which may be an extended partition.

**Extended** This is a special type of primary partition that serves as a holder for logical partitions. A disk may have at most one extended partition.

**Logical** These partitions are contained within an extended partition. In the theory, a disk can have billions of logical partitions, thus overcoming the limit of four primary partitions, but in practice you're unlikely to see more than a dozen of them.

MBR's use of three partition types is awkward and limiting, but inertia has kept it in place for decades. MBR partitions have a hard limit, though they can't support disks larger than 2 teribytes (TiB), assuming 512-byte sectors, which are nearly universal today.

The Globally Unique Identifier (GUID) Partition Table (GPT) is the successor to MBR. GPT supports disks up to 8 zebibytes (ZiB), which is about 4 billion times large as MBR's. GPT also supports up to 128 partitions by default, with no distinction between primary, extended, and logical partitions. GPT is a superior partitioning system to MBR; however, its support varies between OSs. Linux supports both systems well. Windows can boot only from MBR when the computer uses the Basic Input/Output System (BIOS), and it can boot only from GPT when the computer is based on the Unified Extensible Firmware Interface (UEFI). Thus, if you dual-boot with Windows, you may need to select your partitioning scheme with care.

# MULTIBY UNITS

It is common to use prefixes from the International System of Units (SI units)—kilo (k), mega (M), giga (G), tera (T), and so on—in conjunction with byte (B) to refer to large quantities of storage space, as in KB, MB, GB, TB, and so on. Technically, these units are defined as base-10—kilo means 1000; mega means 1,000,000; and so on. In computers, though, base-2 values, such as $2^{10}$ (1,024) and $2^{20}$ (1,048,576), are even more natural, so the SI units often have (but not always) been used to mean these base-2 values. This practice has led to confusion, since it's not always clear whether base-10 or base-2 units are used.
