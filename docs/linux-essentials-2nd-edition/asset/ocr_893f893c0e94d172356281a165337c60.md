You can make changes in a similar way. Although a GUI version, most of its principles are the same as the ones in GUI text editors and word processors; you just need to know the keystroke to activate the feature that you want.

Ctrl+G displays the nano help documentation, which summarizes the program's features. This can be as handy as you get to know the editor. Some additional features that you might want to use include the following:

**Move to the Start or End of File** You can use the arrows. Page Up. Page Down, Home, and End to move the cursor around in ways that are common to other editors. To move to the start of the file, press M-\; and to move to the end of the file, press M/-.

**Copy or Move Multiple Lines** If you need to copy or move consecutive lines, you can repeat the M-6 or Ctrl+K operation; nano retains all of the lines that you copy or cut, so that when you press Ctrl+U, all of them will be pasted.

**Insert a File** Press Ctrl+R or F5 enables you to insert another file into the current cursor position.

**Search for a String** Press Ctrl+W or F6 activates a search feature. When activated, nano prompts you for a search term.
