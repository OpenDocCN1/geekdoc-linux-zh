# Chapter 4 · Using Common Linux Programs

In theory, most languages can be implemented either in compiled or inter-preted form. In practice, though, most languages are commonly used in just one form or the other.

Some don't fit neatly into either category. See the “Programming in Assembly Language” sidebar for one important exception. Some others fall into an in-between category, such as Java, which is compiled from source code into a platform-independent form that must be interpreted.

# Identifying Common Programming Languages

Linux supports a wide range of programming languages, including the following:

+   Assembly As noted earlier, this low-level language can produce efficient programs, but it is difficult to write and nonportable. In fact, referring to assembly as if it were one language is a bit misleading, since each architecture has its own assembly language.

+   C This language is the most important compiled language for Linux, since most of the Linux kernel, as well as a huge number of Linux applications, are written in C. C can produce efficient code, but it's also easy to write buggy programs in C lacks some error-checking features that come in many other languages. C source code typically have filenames ending in .c or .h—the .c files are the main source code files, while the .h files are header files, which contain short definitions of the functions in the .c files, for reference by other files in a program. A large program can contain dozens of, not hundreds or thousands, of individual source code files. In Linux, C programs are generally compiled with the gcc program, which is part of the GNU Compiler Collection (GCC) package.

+   C++ This language is an extension to C that adds object-oriented features, meaning that greater emphasis is given to data structures and their interactions to the procedures used to control the flow of program. Many complex languages, such as KDE and Apache OpenOffice/LibreOffice, are written largely in C++. C source code files have filenames that end in .cc, .cpp, .cxx, or .c++, with header files ending in .h, .hpp, .hxx, .h+. In Linux, C++ is generally compiled with the g++ program, which is part of GCC.
