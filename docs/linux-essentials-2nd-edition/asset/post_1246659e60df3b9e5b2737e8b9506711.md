## Searching, Extracting, and Archiving Data

An important part of any OS, including Linux, is storage management, and analysis of data. Data is valuable because of the knowledge that can be gleaned from it, so you need to be able to search and extract it properly as well as to protect it. This chapter covers some tools that you can use to search, extract, and archive data. The chapter begins with a look at regular expressions, which are a way to describe patterns you might want to look for in data. You can use regular expressions with many commands, two of which (find and grep) are described in detail. This chapter also covers tools that you use to redirect input and output, which is useful in many situations. Finally, tools for creating backups are described, which can be useful in transferring files over a network.

## Using Regular Expressions

Many Linux programs employ regular expressions, which are tools for expressing patterns in text. Regular expressions are similar to wildcards that can be used to specify filenames. At their simplest, regular expressions can be plain text without adornment. Two forms of regular expression are common: basic and extended. The form that you use depends on the program. Some accept just one form, while others can use either (depending on the options passed to the program). The differences between basic and extended regular expression forms can be complex and subtle, but the fundamental principles of both are the same. The simplest type of regular expression is alphanumeric string, such as addresses. The real strength of regular expressions comes in the use of non-alphanumeric characters, which activate matching rules. The most powerful regular expression features include the following:

Bracket Expressions Characters enclosed in [] constitute bracket expressions, which match any character within the brackets. For instance, [aeiou] matches any of the vowels. Including a caret (^) after the opening square bracket matches any character except the one specified. For instance, [^aeiou] matches consonants but not vowels.

Range Expressions A range is a variant of a bracket expression. Instead of listing every character that matches, range expressions list the start and end points separated by a dash (-), as in [a-z]. This regular expression matches any character from a to z.

Any Character The dot (.) represents any single character except a newline. For instance, a.z matches abc or any other three-character string that begins with a and ends with z.

Start and End of Line The caret ( represents the start of a line, and the dollar sign ($) denotes the end of a line. For instance, ^abc matches only if it is first in a line of characters, while $abc matches only if it is last in a line of characters.

Repetition A full or partial regular expression may be followed by a special symbol to denote repetition of the matched item. Specifically, an asterisk (*) is often used with the dot (.*) to match any substring. For instance, A.*Lincoln matches any string that contains A and Lincoln in any order—Abraham Lincoln and Lincoln are just two possible matches.

Escaping If you want to match one of the special characters, such as a dot, you must escape it—that is, precede it with a backslash (\). For instance, to match a computer hostname (say, www.sybex.com), you must escape the dots, as in www\.sybex\.com.

Extended regular expressions add more features that you can use to match in additional ways:

Additional Repetition Operators These operators work like an asterisk, but they only match certain numbers of matches. Specifically, a plus sign (+) matches one or more occurrences, a question mark (?) specifies zero or one.

Multiple Possible Strings The vertical bar (|) separates two possible matches; for instance, car|truck matches either car or truck.

Parentheses Ordinary parentheses () surround subexpressions. Parentheses are often used to specify which operators are to be applied; for example, you can put parentheses around a group of words that are concatenated with the vertical bar to ensure that the words are treated as a group, any one of which may match, without surrounding parts of the regular expression.

Whether you use basic or extended expressions depends on which form the grep supports. For programs like grep that support both, you can use either; which is mostly a matter of personal preference. Note that a regular expression that includes characters associated with extended regulars will be interpreted differently depending on what type you are using. It is important to know which type of regular expression a program supports, or to select which type to use if the program supports both types.
