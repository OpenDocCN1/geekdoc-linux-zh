# Administrator Skill Requirements

The final column in Table 1.1 provides our personal estimate of the skill level required to administer a distribution. As you can see, we've described most distributions as requiring "intermediate" skill to administer. Some, however, provide less in the way of user-friendly GUI administrative tools, and require more skill. Ubuntu aims to be particularly easy to use and administer.

Most distributions are available for at least two platforms—that is, CPU types: x86 (also known as i32, 386, and several variants) and x86-64 (also known as AMD64, EM64, and x64). Until about 2007, x86 computers had become the standard. If you have an x86-64 computer, you can run either an x86 or an x86-64 distribution on it, although the latter provides a small improvement. More-exotic platforms, such as ARM (for tablets), PowerPC, Apple, and SPARC, are available. Such platforms are mostly restricted to servers and to specialized devices (described shortly).

# Android

Many phones use a Linux-based OS known as Android. Its user interface is similar to that of other smartphones, but underneath lies a kernel and a significant amount of the same Linux infrastructure you'll find on a PC. Such phones don't use X or typical desktop applications; instead, they run specialized applications for mobile phones.
