Packages can, and frequently contain files that will be installed to many directories on the computer. This fact makes tracking package contents critical.

The package software maintains a database of installed packages (the package database). This information includes the names and versions of all installed packages, as well as the locations of all files installed from each package. This information enables the package software to uninstall package software quickly, establishes whether a new package's dependencies have been met, and determines whether a package that you're trying to install has already been installed and, if so, the installed version is older than the one that you're trying to install.
