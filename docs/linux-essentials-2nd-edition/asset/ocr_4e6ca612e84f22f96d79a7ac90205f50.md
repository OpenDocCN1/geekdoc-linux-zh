+   2. A Typically, Linux starts in as the first process, so option A is correct. bash is a Linux text-mode shell program. It's started automatically in the boot process, but it's not the first process the kernel starts, so option C is incorrect. The login process is critical to logging in users in text mode, it's started by init or by another process, so option D is incorrect.
