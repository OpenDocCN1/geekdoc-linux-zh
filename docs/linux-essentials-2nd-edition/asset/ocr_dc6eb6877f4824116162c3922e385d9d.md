# Modifying Accounts from the Shell

One of the most frequent account modifications is to change a user's password, either as part of account creation or because a user has forgotten their password. You can change this with the passwd program. Ordinary users can type passwd to change their own passwords, but not other user accounts' passwords. The super user, however, can pass a username to the command to change any account:

As a security measure, the password that you type does not echo the screen as you type it. If the passwords don't match, the program refuses to accept your change and prompts you again for a fresh pair of passwords. The program also checks the password's strength and may refuse to accept the new password or display a warning message if it deems it to be too weak. Notice in the preceding example that the # prompt is showing, indicating that someone has logged into the root account to obtain super user privileges, which are required to complete this change successfully.

You can handle most other account modifications by using the usermod program. This command works like user, but instead of creating a new account, it modifies an existing one. Table 13.2 summarizes the most important us options.

In addition to setting passwords, the passwd utility enables you to adjust password expiration and aging options.
Consult its man page for details.
