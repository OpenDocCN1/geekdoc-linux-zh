Sometimes command completion will be able to complete a command only partially. For instance, typing gru and then pressing Tab is likely to add a single unique character, b. However, several commands with grub, you must add more characters for yourself. (These commands deal the Grand Unified Bootloader, GRUB, which helps Linux to boot.)

Command completion also works with files. For instance, you can type cat /etc/ser followed by the Tab key to have Bash complete the filename, and therefore complete the command, as cat /etc/ser.Services (This command shows you the contents of a Linux configuration file.)

If command completion is not working for you, the terminal program may have configured to be turned off.

Many of the Bash command-editing features are similar to those used by the emacs text editor.

# Using Command History

Bash remembers the recent commands that you've typed, and you can use this to save yourself if you need to type a command that's similar to one that you've typed recently. In its most basic form, you can use the up-arrow key to enter the previous command; pressing the up-arrow repeatedly moves backward from earlier and earlier commands. Table 6.1 summarizes some other commonly keystrokes you can use in the command history—when editing new commands.

| TABLE 6.1 Bash editing and command history features |
| Keystroke | Effect |
|---|---|
| Up arrow | Retrieves the previous entry from the command history. |
| Down arrow | Retrieves an earlier entry bypassed when using the up arrow. |
| Left arrow | Moves the cursor left one character. |
