Web Searches Web search engines index many Internet resources, including
pages, program documentation sites, web forums, and even IRC channel
discussions. A web search can provide you with an answer from an expert with-
out needing to contact the expert directly.

Careful use of these resources can help you with many Linux problems,
where those are simply a lack of knowledge on your part, a miscon-
figuration, a program bug, or some terrible disaster such as a software update
rendered your computer unboot.

The problem today is that there's often too much information available; sift-
ing through the irrelevant (or just plain bad) information to find the helpful
advice can be difficult. To overcome this challenge, being specific can be help-
ful. You can narrow a web search by adding keywords that you believe are rel-
to the problem but that are uncommon. Words found in error messages
can be helpful in this respect. If you post a problem to a web forum or send
bug report to a program author, be as specific as possible. Include information
t the distribution you are using, the version of the software with
you need help, and specific details about what it is doing. The program displays
er messages, quote them exactly. Such details will help experts zero in
the cause of the problem.

# THE ESSENTIALS AND BEYOND

Command lines are powerful tools in Linux; they're the basis on which many of the friendly
GUI tools are built. They can be accessed without the help of a GUI, and they can be scripted. To
use the text-mode tools described in other chapters of this book, you should be familiar with
the basics of a Linux shell. These include knowing how to start a shell, how to run programs
shell, and how to use a shell's time-saving features.
