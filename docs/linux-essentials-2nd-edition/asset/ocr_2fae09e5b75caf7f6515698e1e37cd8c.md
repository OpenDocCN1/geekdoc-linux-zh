+   2. The open source definition includes 10 points, which is one that users may modify the original code and redistribute the altered version. Thus option C is correct. Although, as a practical matter, all open source software is available at no charge, nothing in the open source definition forbids it. In practice, many organizations and individuals do not sell open source software, either as a convenience (as DVD-ROMs with Linux distributions for those with slow Internet connections) or for value-added arrangements (as Red Hat Enterprise Linux, which bundles open source software with a support contract). Thus option A is correct. The open source definition requires distribution of source code, but does not require distribution of binaries. Thus option B is incorrect. Although some open software, including the Linux kernel, began life in academia, this is not true of all open source software, option D is incorrect. The open source definition does not specify whether an interpreted or compiled language be used, and in fact both have been used to write open source software, so option E is incorrect.
