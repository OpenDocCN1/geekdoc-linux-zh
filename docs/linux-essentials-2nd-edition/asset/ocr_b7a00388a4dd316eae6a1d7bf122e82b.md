# Chapter 8 • Searching, Extracting, and Archiving Data

Two forms of regular expression are common: basic and extended. The form that you use depends on the program. Some accept just one expression form, while others can use either type (depending on the options passed to the program). The differences between basic and extended regular expression forms can be complex and subtle, but the fundamental principles of both are.

The simplest type of regular expression is an alphabetic or alphanumeric string, such as Hwaddr or Linux3. These regular expressions match any string of the same size or longer that contains the regular expression. For instance, the Hwaddr matches Hwaddr, and The Hwaddr is unknown. The real strength of regular expressions comes in the use of nonalphanumeric characters, which activate matching rules.

The most powerful regular expression features include the following:

**Bracket Expressions** Characters enclosed in brackets [] constitute bracket expressions, which match any character within the brackets. For instance, the regular expression b[aeiou] matches the words bag, beg, big, bog, and tug. Including a caret (*) after the opening square bracket matches any character except the one specified. For instance, b[^aeiou]j matches bg or baj but not bag or beg.

**Range Expressions** A range is a variant in a bracket expression. Instead of listing every character that matches, range expressions list the start and end points separated by a dash (–), as in a[2-4]z. This regular expression matches a2, a3, and a4.

**Any Character** The dot (.) represents any single character except a newline. For instance, a.z matches a2, abz, aqz, or any other three-character string that begins with a and ends with z.

**Start and End of Line** The caret (*) represents the start of a line, and the dollar sign ($) denotes the end of a line. For instance, ^bag matches only if it is first in a line of characters, while $bag matches only if it is last in a line of characters.

**Repetition** A full or partial regular expression may be followed by a special symbol to denote repetition of the matched item. Specifically, an asterisk (*) is often used with the dot (.*) to match any substring. For instance, A.*Lincoln matches any string that contains A and Lincoln, and in order—A Lincoln and Abraham Lincoln are just two possible matches.
