# Choosing an Editor

All Linux distributions ship with many text editors. Broadly speaking, text edi-
tors fall into one of two categories: text-mode and GUI. Beginners are generally
more comfortable with GUI editors, which can be more convenient to use evenor experts. But when a GUI is not available, you may have to use a text-mode
editor. Thus it is recommended that you familiarize yourself with at least one
text-mode editor. Some popular text editors include the following:

+   - vi This editor is a Unix staple. It is small and usually installed by default,
y you can be certain that it's present on any Linux computer. It is, however,
strange by modern standards—it uses multiple editing modes, and you must
witch between them to accomplish various tasks. Many lightweight Unix and
Linux administrators like vi for its flexibility, power, and size.

+   - emacs This is another Unix staple. It is a big editor with lots of features,
so it's less likely to be installed by default, particularly on small, lightweight dis-
tributions. Its operating mode is more like those of the text editors with which
ovices are familiar, but its commands can seem rather odd.

+   - pico Some small editors are modeled after emacs, but they omit many of
advanced features in an effort to simplify the editor. One is pico,
which originated as part of the pico email package.

+   - nano This is a clone of pico that adds extra features. Even with the
additional features, nano is small, lightweight, and easy to use.

The nano editor is probably the best place to start, because of its ease of use.
If nano is not already installed, it's typically available in most distributions'
software repositories. If you don't find installed on your distribution, see

package.) For the most part, pico works just like nano, but because nano adds
