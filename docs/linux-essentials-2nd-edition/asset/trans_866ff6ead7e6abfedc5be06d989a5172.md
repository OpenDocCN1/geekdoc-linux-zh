
shell 提示符（prompt）的细节因安装而异，但你可以在 shell 提示符处输入文本模式命令。例如，你可以输入 `ls`（list 的缩写）查看当前目录下的文件列表。删除元音（有时还有辅音）可以缩短最基本的命令，以尽量减少执行命令所需的输入量。但这产生了一个遗憾的影响，使得许多命令变得相当晦涩。

某些命令不显示任何信息，但大多数命令会产生一些输出。例如，`ls` 命令会生成文件列表：

```
$ ls 106792c01.doc f0101.tif
```

此示例显示了当前目录下的两个文件：106792c01.doc 和 f0101.tif。你可以使用额外的命令来操作这些文件，如使用 `cp` 复制它们或使用 `rm` 删除它们。第 6 章和第 7 章（“管理文件”）描述了一些常见的文件操作命令。

## Linux 与 Unix 的比较

如果尝试绘制 Unix 的族谱，你会发现它是复杂的，涉及分支（即将代码拆分为多个独立项目）以及完全独立的重写。Unix 于 1969 年诞生于 AT&T 贝尔实验室。

历史上，Unix 和 Linux 作为服务器非常受欢迎——组织使用它们运行各种服务器程序。

- **Linux 内核**：Linus Torvalds 在 1991 年作为一个兴趣项目创建了 Linux 内核，但它很快就远不止于此。Linux内核的设计与其他内核兼容，因为它使用了相同的软件接口。这使得在 Unix 版本中使用开源程序变得简单。
- **GNU 项目**：GNU（不是 Unix）项目是自由软件基金（FSF）为操作系统的所有核心元素开发开源替代方案的努力。1991 年，FSF 已经发布了大部分工具，唯一的例外是内核。GNU HURD 内核现在可用，但没有 Linux 内核流行。

## Linux 在操作系统世界中的位置

相对于 GNU 工具的替代方案包括专有的商业工具以及为 BSD Unix 变体开发的开源工具。在类 Unix OS 上使用的工具会影响其整体“风格”，但所有这些工具集都足以让任何 Unix 变体在比较时具有相似性。

**Xorg-X11**：窗口系统是大多数 Unix OS 的 GUI 环境。大多数 Linux 发行版今天使用 Xorg-X11 变体正如 GNU 提供的基础文本模式工具一样，选择服务器可能会影响类 Unix OS 的某些功能，例如它支持的字体类型。

**桌面环境**：GNOME、KDE、Xfce 以及其他流行的开源桌面环境已很大程度上取代了商业桌面环境。因此，你不会发现 Linux 与 Unix 在这里的差异。

**服务器程序**：历史上，Unix 和 Linux 作为服务器非常受欢迎——组织使用它们运行 Web 服务器、电子邮件服务器、文件服务器等。Linux 运行的服务器程序与商业 Unix 版本以及开源 BSD 相同。
