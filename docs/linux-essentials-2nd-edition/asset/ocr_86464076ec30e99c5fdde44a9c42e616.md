# Saving Your Changes from vi

To save changes to a file without exiting the editor, type :w in command mode.
This enters mode and runs the we-mode command, which writes the file
using whatever filename you specified when you launched vi. Related-
mands enable other functions:

Edit a New File The :e command edits a new file. For instance, :e /etc/
inittab loads /etc/inittab for editing, vi won't load a new file unless the
existing one has been saved since its last change or unless follow :e with an
exclamation mark (!).

Include an Existing File The :r includes the contents of an old file
in an existing one.

Execute an External Command The ex mode command : executes the
external command that you specify. For instance, typing :ls runs is, enabling
you to see what files are present in the current directory.

Quit The :q command to quit the program. As with :e, this command
won't work unless changes have been saved or you append an exclamation mark
to the command (as in :q!).

You can combine commands such as these to perform multiple actions
in sequence. For instance, as shown previously, typing :wq writes changes and
t quits from vi.
