**Web** This program, originally called Epiphany, is found at https://wiki.gnome.org/Apps/web. It is the web browser for the GNOME desktop. It's designed to be simple and easy to use.

**Konqueror** This KDE program serves a dual function: it's both a web browser and a file manager. Konqueror does a good job with most web pages. It's fairly lightweight, and it is so well worth trying, particularly if you use KDE. You can read more about it at www.konqueror.org.

**Lynx** Most web browsers are GUI programs that display text in multiple fonts, show graphics inline, and so. Lynx (http://lynx.browser.org) is unusual in that it's a text-based browser. As such, it's a useful choice if you run Lynx in text mode or if you don't want to be bothered with graphics. Lynx is also useful as a test browser when you develop your web pages; if a page is readable in Lynx, chances are that visually impaired people who use the Web with speech synthesizers will be able to use your page.

**Opera** An unusual commercial entrant in the Linux web browser sweepsakes. Opera (www.opera.com) claims to be unusually fast. Although Opera is commercial, you can download it at no charge.

Not absent from this list is a Microsoft browser. Unfortunately, some websites won't work with anything but a Microsoft browser. Other sites are somewhat picky but can work with at least one Linux browser. Thus you should probably install at least two Linux browsers.

Web browsers give users easy access to a world of information—literally! The Web has a dark side, too. Problems include the following:

+   Websites can log user data, which can be used in marketing or in other ways that you might not like.

+   Much web-based content is dangerous, meaning that websites download small programs (often written in Java) that your web browser runs. This content might be harmless, but it's increasingly being used to deliver malware.

+   Malicious websites can trick users into giving up sensitive data, such as financial information, by pretending to be a trusted site. This technique is known as phishing.

+   Many websites are not secure. Data transferred can be read on intervening computers. Most sensitive sites, such as Internet banking sites
