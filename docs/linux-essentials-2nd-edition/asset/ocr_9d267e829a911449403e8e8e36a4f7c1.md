# Understanding Disk Issues

If you're planning a new Linux installation, you should consider ext4, Btrfs, ReiserFS, or XFS as your filesystem. Btrfs provides the best overall features and performance, while ReiserFS and XFS are worth considering for volumes that hold particularly small and large files. Btrfs is a good choice for volumes that hold large files, though you could use it for everything and not particularly wrong, especially on a general-purpose computer.

In addition to Linux's native filesystems, the OS supports several other filesystems, some of which are important in certain situations:

**FAT** The File Allocation Table (FAT) filesystem was the standard with DOS and Windows through Windows Me. Just about all OS support it. Its compatibility makes it a good choice for exchanging data between two OSs dual-boot on a single computer. Unlike most filesystems, FAT has two line types: mdos and vfat. Using mdos allows Linux to use the filesystem as DOS, with short filenames of at most eight characters plus a three-character extension (.filename); when you use vfat, Linux supports long filenames on FAT. Most USB drives are preformatted with the vfat filesystem, making it still popular.

**NTFS** Microsoft developed the New Technology Filesystem (NTFS) for Windows NT, and it is the default filesystem for recent versions of Windows. Linux provides a limited read/write NTFS driver, and a full read/write driver is available in the NTFS-3G software (www.tuxera.com). You're most likely to encounter it on a Windows boot partition in a dual-boot configuration or on larger removable or external hard disks. Under Linux, the standard kernel driver is known as ntfs, whereas the NTFS-3G driver is called ntfs-3g.

**HFS** Apple used its Hierarchical File (HFS) in Mac OS version 9.x, and supports it in Mac X. You might encounter HFS on some removable media, and particularly on older disks created under Pre-X versions of Mac OS. Linux provides full read/write support using its hfs driver.

**HFS+** Apple's HFS+, also known as Mac Extended, is the current filesystem for Mac OS; you're likely to encounter it on dual-boot Macs and on some removable media created for use with Macs. Linux provides read/write HFS+ support with its hfs driver; however, write is supported by default on versions of the filesystem that include a journal.

It's possible to use several filesystems in a single Linux installation in order to take advantage of each filesystem for different sets of files.

FAT's simplicity and widespread support make it a popular filesystem on USB drives, smartphones, e-book readers, digital camera media, and so on.

Linux ntfs driver is based in the kernel, which makes it fast. The NTFS-3g driver, unlike most filesystems, is not kernel-based, so it's not as fast.
