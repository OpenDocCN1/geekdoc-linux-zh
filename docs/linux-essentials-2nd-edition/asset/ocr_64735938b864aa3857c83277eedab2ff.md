# Chapter 12 · Understanding Basic Security

To learn who is online, you can use a command known as:

Certification Objective

```
$ who
cristine:0  2016-05-04 17:33 (:0)
kevin      tty2  2016-05-04 17:36
rich       pts/0  2016-05-04 17:33 (192.168.56.101)
cristine   pts/1  2016-05-04 17:34 (:0)
```

This example shows four logins—two by christine, one by Kevin, and one by rich. Information provided in the default output includes the following:

**Username** The first column of who's output shows the username.

**Terminal Identifier** The second column of who's output shows a code associated with the terminal. In this example, christine's first login shows : as this identifier, which means that it's a local login. The remaining logins have terminal identifiers of the form pts/# or tty#, indicating text sessions. A text session can be a terminal launched in a GUI, a text-mode console, or a remote login via SSH or other protocol.

Different distributions have varying details for the who command. However, the major elements are the same.

**Login Date and Time** who displays the date and time of each login. You can see which rich' and christine's sessions began a couple of minutes before Kevin logged.

By default, the who command pulls its data from /var/run/tmp file.

**Remote Host** The final column of who's output, if present, shows the source logins (including both text-mode and GUI-based logins) don't include a source. The source of the form # or #., as in christine's sessions, indicates a terminal opened in a GUI. hostname or IP address, as in rich's session, indicates remote from the computed computer.

You can obtain additional information, which is obscure or specialized, by passing options to who. One's more likely than others to be count (-q), which produces a more compact summary of the data:

The who command, for a little humor, allows you to argue moments you likes in place of the ami arguments.

```
$ -q
cristine kevin rich christine
# users=4
```

This output includes just the usernames and a line specifying the total of sessions. Notice that the users number count one user with multiple logins multiple times.

Similar to the whoami command, but showing more information, passing an i arguments to who to display data only for your current user ID:

```
$ am i
cristine pts/1  2016-05-04 17:34 (:0)
```
