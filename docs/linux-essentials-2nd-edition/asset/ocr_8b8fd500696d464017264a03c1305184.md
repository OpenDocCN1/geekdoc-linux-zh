# Understanding the Process Hierarchy

The Linux kernel is the core of a Linux installation. The kernel manages memory, provides software with a way to access the hard disk, holds out CPU time, and performs other critical low-level tasks. The kernel is loaded early in the boot process, and it's the kernel's responsible for managing every other piece of software on a running Linux computer.

You can change program runs as the first process by adding init=option to your boot loader kernel option line, as init=/bin/bash to run bash.

One of the ways that the kernel operates on the potentially chaotic set of running software is to create a sort of hierarchy—normally /sbin/init. When it boots, the kernel runs one program—init. The init process is then responsible for starting all the other basic programs that Linux must run, such programs, if launched directly by login, are called children. The children of init can in turn launch their children. This happens when you log into Linux. The process that launches a given process is called its parent.
