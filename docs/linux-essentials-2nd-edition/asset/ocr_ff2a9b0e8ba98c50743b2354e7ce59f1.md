# Managing Groups

In many respects, groups are comparable to accounts. They are defined in similar files and managed with similar utilities. Groups are also tied to accounts, in that accounts include group definitions. Until now, it has been assumed that you'll be using standard groups or the groups that are defined as part of account creation. Sometimes, though, need to create, delete, or modify groups for specific purposes, as if you use a project group strategy. With account management, you can do this using either GUI or text-mode tools.

# Managing Groups Using GUI Tools

Many GUI account maintenance tools, such as openSUSE's User and Group Administration utility, provide group management tools that are similar to the user management tools described throughout this chapter.
