**Bookmarks** You can add bookmarks for locations not shown in the Places category. Simply traverse to the files within the desired bookmark location and click the Gear icon on Nautilus' menu bar. From the drop-down menu, select Bookmark This Location. Alternatively, you can press Ctrl+D to mark a location. Newly added bookmarks appear in a new category called Bookmarks.

If you want to modify a bookmark, you do not use the Nautilus window. Instead, you select Files from the top bar in the GNOME desktop and then select Bookmarks from the resulting drop-down menu. The dialog box resembles Figure 4.5. In this window, you can change the bookmark's name and/or location.
