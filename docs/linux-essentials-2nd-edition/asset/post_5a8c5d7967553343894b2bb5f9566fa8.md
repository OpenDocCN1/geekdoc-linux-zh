## Editing Files with vi

As with nano, you can add a new entry to .txt by using vi, either by typing it in entirety or by duplicating an existing line and then modifying the duplicate line. To do it the first way, follow these steps:

- 1. Move the cursor to the beginning of the bird line by the arrow keys.
- 2. Press the O key (letter O, not number 0). This opens a new line immediately below the current line, moves the cursor to that line, and enters insert mode.
- 3. Type in a new entry: reptile.
- 4. Press the Esc key to return from insert mode to command mode.

To practice changes by modifying an existing entry, follow these steps:

- 1. Move the cursor to the beginning of the reptile line that you just created using the arrow keys if necessary. You should see the cursor resting on the r of reptile.
- 2. You will now copy (yank) one line of text. The term yank is used much as copy is used in most text editors—you copy the text to a buffer from which you can later paste it back into the file. To yank text, you use the yy command preceded by the number of lines you want to yank. Therefore, type 1yy (do not press the Enter key, though). It doesn't look like anything happened, but this keystroke copies the line on which the cursor resides in a buffer.

If you want to paste the text into the document starting on the cursor, use an uppercase P command.

- 3. Move the cursor to the third line, which is the line before the one where you want to new a line.
- 4. Type p (again, without pressing the Enter key), vi pastes the contents of the buffer (reptile) starting on the line after the cursor. The file should now have two identical reptile lines. The cursor should be resting at the start of the first one.
- 5. Move the cursor to the r in the word reptile on the line that you just pasted, if it's not there already. You're about to delete this line.
- 6. The dd command works like yy, but it deletes the lines as copying them to a buffer. Type dd to delete the reptile line. The file should have only one reptile line.

Both yy and dd are special cases of the y and d commands, respectively, which yank or delete text in amounts specified by the next character, as in Ow to delete the next word.
- 7. Save the file and quit by typing ZZ. This command is equivalent to :wq.

Many commands are available that you might want to use in some mode. Here are some of the highlights:

Change Case: Suppose that you need to change the character of a word in a file. Instead of entering insert mode and retyping the word, you can use the tilde (~) key in command mode to change the character. Position the cursor on the first character you want to change, and press repeatedly until the task is done.

If you need to change a file's end-line encoding from the Windows method to the Unix/Linux method, open the file in the vi editor and type the command :set ff=unix.

Undo: To undo any change, u in command mode.

Open Text: In command mode, typing o (a lowercase O) opens text—that is, it inserts a new line immediately below the current one and enters insert mode on that.

Search: To search forward for text in a file, / in command mode, followed immediately by the text that you want to locate. ? searches backward rather than forward.

Change Text: The c changes text within command mode. invoke it like the d or y, as in cw to change the next word or cc to change an end line.

Go to a Line: The G key brings you to a line that you specify. The H key moves the cursor—that is, it moves the cursor to the top line of the screen. The L key brings the key to the bottom line of the screen.
