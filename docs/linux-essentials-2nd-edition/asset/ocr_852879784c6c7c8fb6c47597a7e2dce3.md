**FIGURE 9.2** Synaptic enables you to search, select, install, and uninstall software on Debian-based systems.

Debian package files have names that end in .deb. Like RPM packages, names typically include codes for the software version and architecture (such as i386 or amd64). For instance, samba_3.6.1-3_amd64, deb is a package file for the Samba package, version 3.6.1, revision 3, for AMD64 (x86-64) CPUs. You can install such files using dpkg or apt-get, or you can use apt-get to download a package and its dependencies from the Internet, using its install command:

```
# apt-get install samba
```

As with RPM packages, you can remove packages or upgrade your computer's software:

```
# apt-get remove ssh
# apt-get upgrade
```
