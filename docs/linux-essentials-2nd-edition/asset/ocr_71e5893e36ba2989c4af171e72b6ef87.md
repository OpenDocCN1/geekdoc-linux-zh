# SUGESTED EXERCISES

+   - Launch a GUI command, such as firefox, and without a trailing ampersand (&). When you launch it with an ampersand, use Ctrl+2 to put it in the background and see how the program reacts to clicks. Use fg to return to the foreground, and repeat the process but use bg to run the program in the background. See what happens in your terminal when you exit the GUI command.

+   - In a shell, type a single letter, such as m, and press the Tab key. What happens? What happens if you type a less common command, such as z, and then press Tab

+   - Experiment with the command history. Use it to search on strings that are part of both command names and filenames you've used. Use the arrow keys and editing features described in Table 6.1 to edit commands that you've used previously.

+   - Read the man pages for the following items: man, less, whereas, find, and locate. What have you learned about these commands go beyond the descriptions in this book?

+   - Search /usr/doc for documentation on important programs that you use frequently, such as the GIMP, Firefox, or Gnome.

+   - Check your distribution's website, or perform a web search, to find a web forum that supports your distribution. Read some of the discussion to get a feel for some of the topics that come up.
