

# 本书的结构

本书由 15 章加上本引言组成。章节安排如下：

**第 1 章：选择操作系统** 本章对操作系统世界进行了概览介绍。本章将帮助你准确理解 Linux 是什么，以及在什么情况下可能想要使用它。

**第 2 章：理解软件许可** 本章描述了版权法以及 Linux 和非 Linux 操作系统均使用的许可协议，这些协议扩展或限制了用户使用和复制软件的。

**第 3 章：研究 Linux 的原理与哲学** 本章涵盖了 Linux 的历史以及 Linux 以及其他系统的常用用法。

**第 4 章：使用常用的 Linux 程序** 本章涵盖了 Linux 软件的主要类别，并提供了指向最流行程序的提示。

**第 5 章：硬件管理** 本章提供了关于如何在 Linux 中选择和使用硬件的建议。具体主题范围从中央处理器（CPU）到设备驱动程序。

**第 6 章：熟悉命令行** 本章探讨了用于控制 Linux 的输入命令。尽管许多新用户觉得这个话题令人生畏，但对 Linux 的命令行控制是非常重要的。

**第 7 章：文件管理** 本章描述了如何移动、重命名、删除和编辑文件。目录只是特殊类型的文件，因此在这里也涵盖了目录。

**第 8 章：数据的搜索、提取与归档** 本章总结了你可以用于在计算机上查找数据的工具，以及你如何操作归档文件以实现数据传输和备份目的。

**第 9 章：探索进程与进程数据** 本章描述了如何在 Linux 中安装程序，以及如何调整运行中程序的优先级或终止所选程序。

**第 10 章：编辑文件** 本章介绍了编辑文本文件的话题。这包括 pico、nano 和 vi 文本模式编辑器的基本功能，以及一些常见的配置文件和格式化文本文件的约定。

**第 11 章：创建脚本** 本章描述了如何创建简单的脚本，脚本是能够运行其他程序的程序。你可以使用脚本来帮助自动执行原本枯燥的手工任务，从而提高你的工作效率。

**第 12 章：理解基础安全** 本章引入了理解 Linux 多用户本质特性至关重要的概念。它还涵盖了 Linux 用于大多数管理任务的 root 账户。

**第 13 章：创建用户和组** 本章涵盖了你用于创建、修改和删除账户及组的软件和流程，这些组定义了谁可以使用计算机。

**第 14 章：设置所有权与权限** 本章描述了如何控制哪些用户访问文件以及他们可以进行哪些操作。结合用户和组，所有权和权限控制着你计算机的安全性。

**第 15 章：管理网络连接** 本章涵盖了告诉 Linux 如何使用网络的关键主题，包括测试连接和一些基础的网络安全措施。

总的来说，这些章节按照所描述的任务和系统的复杂程度从低到高排列。本书从关于 Linux 的背景信息和驱动其发展的哲学开始。随后的章节描述了基础用户任务，如移动文件。本书以系统管理员最感兴趣的任务结束，例如账户管理和网络配置。

每章的开头都有一个该章涵盖的任务列表。在每章的末尾，你会发现几个元素，它们总结了材料并鼓励你进一步深读：

**核心内容及进阶** 这是对本章涵盖内容的一段式总结。如果你在阅读时发现某些内容听起来很陌生，请返回复习该章节的相关部分！

**建议练习** 每一章都包含两个你应该完成的练习，以便让你自己获得更多 Linux 的实践经验。这些练习并不一定有“正确”答案；相反，它们旨在促进对你自己的计算机和 Linux 的探索与发现。

**复习题** 每一章都以一组 10 道复习题结束。

# 什么是操作系统？

*操作系统*（OS）从软件角度来看提供了计算机最基本的功能。操作系统使你能够使用硬件设备，定义了用户界面标准，并提供了让计算机实用的基本工具。最终，这些许多功能都可以追溯到操作系统的内核，内核将在下一步进行详细介绍。其他操作系统功能归功于运行内核之上的额外程序，如本章后半部分所述。
