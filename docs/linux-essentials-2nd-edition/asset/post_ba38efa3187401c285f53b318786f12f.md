Web browsers give users easy access to a world of information—literally! The Web has a dark side, too. Problems include the following:

- Websites can log user data, which can be used in marketing or in other ways that you might not like.

- Much web-based content is dangerous, meaning that websites download small programs (often written in Java) that your web browser runs. This content might be harmless, but it's increasingly being used to deliver malware.

- Malicious websites can trick users into giving up sensitive data, such as financial information, by pretending to be a trusted site. This technique is known as phishing.

- Many websites are not secure. Data transferred can be read on intervening computers. Most sensitive sites, such as Internet banking sites and online retailers, now encrypt their sensitive data, but you should be cautious when sending such data.

# Using Multimedia

Linux has an excellent reputation as a workhorse server, but until recently its capacity as multimedia has been lacking. In the last decade, however, Linux's multimedia application list has grown. Current offers include the following:

**Audacity** This program, found at http://audacity.sourceforge.net, is an audio editor for Linux, similar to commercial products like Sound Forge. You can use it to cut sections from audio, equalize volume, remove tape hiss or noises, apply artificial effects, and more.

**Blender** You can use this program to create complex 3D images, including both styles and animations.

**The GIMP** GIMP** The GNU Image Manipulation Program (GIMP) (www.gimp.org) is a still-image manipulation program similar in broad strokes to Adobe Photoshop. (The GTK+ toolkit, which is the base of GNOME and many other programs, was originally created for the GIMP.)

**ImageMagick** This is a set of graphics programs with a twist: you typically use ImageMagick programs from the command line. You can use it to convert formats, add frames to images, resize images, and so on. You can read more at www.imagemagick.org.

**Handrake** This program provides an easy way to convert video formats, and particularly into formats that use the efficient H264 encoding. You can learn more at http://handbrake.fr.

**MythTV** You can turn a regular PC into a digital video recorder (DVR) using software, which is best at www.mythtv.org. MythTV uses a client-server model, enabling one recorder to serve multiple players on TVs throughout your home.
