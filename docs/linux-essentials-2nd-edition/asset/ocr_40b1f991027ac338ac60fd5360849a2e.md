In this example, the username has changed from luke to root; the directory has changed from ~ to luke (since for root refers to /root, not /home/luke); and the last character of the prompt has changed from a dollar sign ($) to a hash (#). Because just the last prompt character was used for most examples on their own lines in this book, such examples implicitly specify whether a command requires privileges by the prompt. For instance, consider the /etc/shadow file mentioned earlier:

# # cat /etc/shadow

The use of the hash mark prompt indicates that you must type this using root privileges.
Some of this books describe both GUI and text-mode methods of system administration. How then, you can administer Linux in GUI mode if you must use the sudo (or su) root privileges? One way is to launch a GUI administrative tool from a shell which you've used so. This approach works, but it is a bit inconvenient if you're more comfortable with a GUI than a command line. Most distributions, therefore, provide an alternative: you can launch administrative tools from the computer's desktop menus and the GUI tools will prompt you for the root (administrator) password when super privileges are needed, as shown in Figure 12.3. If you type the password correctly, the program will continue. The result is similar to launching the program from a shell sudo—it runs as root, but without making anything else as root.

+   To use root commands in Ubuntu, you must either precede them with sudo (as sudo cat /etc/shadow) or type sudo to acquire a longer-lasting shell.

What do you do if you have forgotten the root password? Don't worry, because there are many methods for resetting it. Use your favorite web search engine and type in reset Linux root password. It's even better to type in your distribution's name, in place of Linux, for your search:
