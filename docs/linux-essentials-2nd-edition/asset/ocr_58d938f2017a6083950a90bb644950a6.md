# Searching for and Extracting Data

For a simple data list with with only words, you can use sort without any options, as shown here:

```
$ cat pets.txt
fish
dog
cat
bird
$ sort pets.txt
bird
cat
dog
fish
```

Like the cut command, when using sort, no changes are made to the file's data. Only the output is sorted.

You may need to use options when sorting numeric data to achieve the desired results. The example in Figure 8.1 shows what happens when the sort command is used to sort a numeric data list. The numbers are not properly sorted in numerical order until the -n option is used.
