Many user programs take advantage of this feature to keep their configuration from cluttering your display. For instance, ~/.bashrc is a user configuration file, Evolution's configuration files go in the ~/.evolution directory, and ~/.fonts.conf holds user-specific font information.

You can view files in various ways depending on the program in question. Some GUI tools have a check box that you can set in your configuration options to force the program to display such files. At the command line, you can add a -option to the other options in ls:

```bash
$ ls -l
total 0
drwxr-rwt 2 root root 80 Dec 14 18:25 subdir
$ ls -la
total 305
drwxr-xr-x 3 kirk users 104 Dec 14 18:44 ..
drwxr-xr-x 3 kirk users 528 Dec 14 18:21 ..
-rw-r--r-- 1 kirk users 309588 Dec 14 14:44 .f1701.tif
drwxr-xr-x 2 root root 80 Dec 14 18:25 subdir
```

This example shows the hidden file .f1701.tif in the current directory. It also shows two hidden directories. The first refers to the current directory. The second .. refers to the parent directory.

> Note that renaming a file that it begins with a dot will hide it, but this action will also make the file inaccessible to any program that uses the original filename. That is, if you rename f1701.tif to .f1701.tif, and if another program or file refers to the file as f1701.tif, that reference will no longer work. You must include the leading dot in any reference to the hidden file.

# Viewing Directories

Chapter 6 introduced the ls command, including many of its options. One of these deserves elaboration at this point: -d. If you're working in a directory that holds many subdirectories, and if you use a wildcard with * ls that matches one or more subdirectories, you may get an unexpected result: the output will show the files in the matched subdirectories, rather than the information on the subdirectories themselves. For instance, say you start in a directory with two subdir1 and subdir2:

```bash
$ ls -l subdir*
subdir1:
total 304
-rw-r--r-- 1 kirk users 309580 Dec 14 18:54 f1701.tif
```

```bash
subdir2:
total 84
-rw-r--r-- 1 kirk users 86016 Dec 14 18:54 106792c17.doc
```

If instead you want information on the subdirectories rather than the contents of those subdirectories, you can include the -d option:

```bash
$ ls -d subdir*
drwx-xr-xr 2 kirk users 80 Dec 14 18:54 subdir1
drwx-xr-xr 2 kirk users 80 Dec 14 18:54 subdir2
```

# THE ESSENTIALS AND BEYOND

File security is important on a multiuser OS such as Linux, and one of the pieces of security is file ownership. In Linux, every file has one owner and one associated group. The superuser can set the owner with chown and either the superuser or the file's owner can set the file's group with chgrp. By itself, ownership is useless, so Linux supports the concept of file permissions to control which users can access a file and in what ways. You can set permissions with the chmod utility. You can view ownership, permissions, and some additional file features by using the -l option to the ls command.

# IP Address

An Internet Protocol (IP) address is a number that's assigned to a computer for networking purposes. You can think of an IP address as being like a street address or telephone number. Computers communicate with each other via IP addresses. In the past, 4-IPv4 addresses dominated (such as 192.168.1.10), however, the pool of IPv4 addresses has recently been depleted, so many new installations use 6-IPv6 addresses (such as fe80:0000:0023:23fe:6bdc). IP addresses are broken down into two parts: a machine portion and a network portion. The network portion may be used in routing (see router), whereas the machine portion identifies a computer on a given network. This breakdown into machine and network addresses is accomplished via a network mask, as described.

# Network Mask

A network mask (mask or netmask for short) is a way to distinguish between the network and machine portions of an IP address. The netmask defines the individual bits of an IP address that belongs to each part of the address. This can be done by giving each bit of the machine address a binary value of 1 and expressing the result as a number (such as 255.255.255.0 or 255.255.255.250) for IPv4 address or by specifying the number of bits in the machine portion of the address (as in 16 or 24).

Other methods of wired networking exist, but may be obsolete or used in very high-speed, long-distance, or other capacities.
