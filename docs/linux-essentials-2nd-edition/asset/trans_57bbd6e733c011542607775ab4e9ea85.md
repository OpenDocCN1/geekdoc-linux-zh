## 使用常用显示硬件

在处理视频设备时，大部分挑战在于管理涉及的视频芯片组驱动程序。大多数现代计算机使用几种视频驱动程序之一：

- *nv, nouveau 和 nvidia* 适用于 NVIDIA 视频硬件。
- ati 和 fglrx 适用于 AMD/ATI 视频硬件。
- intel 适用于 Intel 视频硬件。
- fbdev 和 vesa 驱动是通用驱动程序，适用于多种硬件，但它们产生的性能并非最优。
- 许多旧款显卡使用更冷门的驱动程序。

nvidia 和 fglrx 是制造商提供的专有驱动程序。请检查制造商网站获取详情。

在过去，大多数显卡通过 15 针视频图形阵列 (VGA) 线缆连接到显示器，29 针数字视觉接口 (DVI) 或较新的 19 针高清多媒体接口 (HDMI) 线缆也很常见。（图 5.4 显示 VGA 和 HDMI 线缆。）DVI 和 HDMI 的优势在于作为数字接口，可以在现代发光二极管 (LED) 显示器上产生更清晰的显示。

显示器分辨率通常以水平和垂直像素数来测量。在过去，640x480 的低分辨率曾很常见，但现在使用最佳分辨率低于 1280x1024 或 1366x768 的显示器已罕见，而 1920x1080 或更高的分辨率已十分常见。你应该咨询你的显示器手册来确定其最佳分辨率。物理尺寸更大的显示器具有更高的分辨率；但并非总是如此。

大多数显示器使用 4:3 或 16:9 的宽高比例；即显示器长度与高度的比例。

在理想情况下，Linux 会在你启动计算机时自动检测显示器的最佳分辨率并设置为该值。遗憾的是，这有时不起作用。键盘/视频/鼠标 (KVM) 切换器和扩展线有时会干扰检测，旧旧显示器可能不支持必要的计算机/显示器之间的通信。你可能需要翻开显示器手册来了解其最佳分辨率。在功能或规格部分查找此类信息；它可能被称为最佳分辨率、最大分辨率或类似的名称。它还可能包含刷新率值，例如 1280x1024 @ 60 Hz。

## 处理 USB 设备

大多数现代计算机使用 USB 端口作为外部外围设备的主要接口。键盘、鼠标、摄像头、闪存存储、硬盘、网络适配器、扫描仪、打印机等都可以通过 USB 连接。在大多数情况下，USB 设备以即插即用的方式工作——你只需插入它们，它们就能工作。某些特定的注意事项包括：

**人机设备 (Human-Interface Devices)** 当你插入键盘、鼠标、平板和类似设备时，X 通常会接管它们。如果你遇到问题，你可能需要通过编辑 `/etc/X11/xorg.conf` 来调整你的 X 配置，但这是一个超出本书范围的高级主题。

**磁盘存储 (Disk Storage)** 我们将 USB 闪盘、外部硬盘和其他存储设备包含在此类。正如之前在“使用可移动磁盘和光盘”中描述的那样，在拔掉 USB 线缆之前卸载磁盘至关重要。不这样做可能会导致数据损坏。

**手机、摄像头、电子书阅读器和音乐播放器** 你通常可以使用这些设备像磁盘驱动器一样来传输照片、音乐或其他文件。不过，你可能需要激活设备上的某个选项使其看起来像一个磁盘驱动器。完成后，卸载设备并停用你的接口模式。

**扫描仪 (Scanners)** Linux 使用 Scanner Access Now Easy 或 SANE 软件 (www.sane-project.org) 处理大多数扫描仪。但少数扫描仪需要冷门或专有的软件。

**打印机 (Printers)** 大多数发行版在你插入 USB 打印机时会自动配置合适的打印机队列。如果你需要调整配置，尝试在相关计算机的浏览器中输入 `http://localhost:631`。这样做会打开一个名为 CUPS（以前称为 Common Unix Printing System）的基于 Web 的打印机配置程序。某些发行版还提供特定发行版的打印机配置工具。

## 管理驱动程序

大多数硬件设备都需要特殊的软件组件才能发挥作用。与硬件“对话”的软件被称为*驱动程序* (driver)，你应该了解驱动程序在 Linux 中是如何工作的。存在几类大类驱动程序，因此我们从描述这些类开始。无论驱动程序的类型如何，你都应该知道如何找到并安装适用于你硬件的驱动程序。

## 理解驱动类型

Linux 需要驱动程序是因为不同的硬件——即使是两个具有相似用途的设备，例如两个网络适配器——工作方式也可能不同。初始化和使用两个网络适配器的方法可能完全不同。为了提供通用接口以便程序可以使用任何网络适配器，内核使用驱动程序作为硬件无关接口与硬件本身之间的桥梁。

广义来说，驱动程序存在于两个位置之一：

- 内核
- 应用程序

大多数驱动程序是内核的，事实上，内核很大一部分由驱动程序组成。内核驱动程序处理大多数设备，例如硬盘、网络接口和 USB 接口。由于驱动程序通常需要硬件的特权访问，这就是内核的目的。

某些驱动程序存在于应用程序中。其中许多是计算机外部的。示例包括以下：

- SANE，它处理扫描仪
- Ghostscript，它将输出转换为打印机可以理解的格式
- X，它直接与设备通信的非内核元素。

X 的特殊之处在于它是非内核元素。相比之下，SANE 和 Ghostscript 都通过内核处理的接口（如 USB 端口）与外部设备通信。也就是说，打印到 USB 打印机至少需要两个驱动程序。理想情况下，大多数用户不会意识到这种复杂性，但在出现问题时，你可能需要理解它。

## 查找和安装驱动程序

大多数驱动程序都随 Linux 内核一起提供，或者随着安装该硬件的应用程序一起提供。例如，大多数 X 安装包含一组适用于你显卡的视频驱动。由于由于原因，很少需要为常见硬件查找并安装额外的驱动程序。也有例外——例如：

新硬件 如果你的硬件非常新（意味着型号是新的，而只是你买的），它可能需要尚未进入你所使用的发行版的驱动程序。

特殊硬件 如果你使用非常奇特的硬件，例如特殊的科学数据采集卡，你可能需要为它查找驱动程序。

专有驱动程序 某些制造商为其硬件提供专有驱动程序。例如，nvidia 和 fgrx 驱动（在前面的“使用常用显示硬件”中提到）可以分别提高基于 NVIDIA 或 ATI/AMD 组的视频显示性能。某些硬件需要专有驱动程序。这在某些特殊硬件上非常常见。

错误修复 驱动程序与其他软件一样可能有 Bug。如果你遇到此类问题，你可能想要查找较新的驱动程序以获取错误修复。

获取新内核驱动程序的一种方法是升级内核。注意内核升级可以为现有驱动程序和提供错误修复。
