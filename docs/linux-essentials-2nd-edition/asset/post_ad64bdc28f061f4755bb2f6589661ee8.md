## An Installer
In order to be used, software must be installed, and most Linux distributions provide unique installation software to help you manage this important task. Thus two distributions may install in different ways, giving you different options for key features, such as disk layouts and initial user account creation.

Typically, Linux distributions are available for download from their websites. You can easily download a CD-R or DVD image file that you can then burn to an optical disc. When you boot the resulting disc, the installer runs, and you can install the OS. You can sometimes download an image that your computer lacks an optical disc. There are also cloud versions of many Linux distributions, which allow you to download a complete Linux system to run in either a private virtual machine or on a commercial cloud such as Amazon or Google services.

The Unbootin tool (http://unetbootin.sourceforge.net) can copy the files from a Linux installation image to a USB flash drive.

Some Linux installers come with all of the software you're likely to install. Others come with only minimal software and expect you to have a working Internet connection so that the installer can download additional software. If your computer is not connected to the Internet, be sure to get the right type of installer.

These features require explanation:
**Availability** Most distributions are entirely open source or free software; however, include proprietary components and are for sale only, typically with a support contract. Red Hat Linux (RHEL) and SUSE Enterprise are the two most prominent examples of this type of distribution. Both have completely free cousins. For RHEL, CentOS is a near-clone that omits the proprietary components, and Fedora is an open source version that serves as a testbed for technologies that may eventually be included in RHEL. For SUSE Enterprise, openSUSE is a free alternative.

**Package Format** Most distributions distribute software in *packages*, which are collections of many files in one. Package software maintains a local database of installed files, making upgrades and uninstalls easy. The RPM Package Manager (RMP) system is the most popular one in the Linux world, but Debian packages are common, too. Other packaging systems work fine, but they are distribution-specific. Slack is unusual when it uses *tarballs* for packages. These are package files created by the standard tar utility, which is used for backing up computers and for distributing source code, among other things. The

**Release Cycle** We describe release cycles in more detail, in "Understanding Release Cycles." ## Administrator Skill Requirements

The final column in Table 1.1 provides our personal estimate of the skill level required to administer a distribution. As you can see, we've described most distributions as requiring "intermediate" skill to administer. Some, however, provide less in the way of user-friendly GUI administrative tools, and require more skill. Ubuntu aims to be particularly easy to use and administer.

Most distributions are available for at least two platforms—that is, CPU types: x86 (also known as i32, 386, and several variants) and x86-64 (also known as AMD64, EM64, and x64). Until about 2007, x86 computers had become the standard. If you have an x86-64 computer, you can run either an x86 or an x86-64 distribution on it, although the latter provides a small improvement. More-exotic platforms, such as ARM (for tablets), PowerPC, Apple, and SPARC, are available. Such platforms are mostly restricted to servers and to specialized devices (described shortly).

## Android

Many phones use a Linux-based OS known as Android. Its user interface is similar to that of other smartphones, but underneath lies a kernel and a significant amount of the same Linux infrastructure you'll find on a PC. Such phones don't use X or typical desktop applications; instead, they run specialized applications for mobile phones.
