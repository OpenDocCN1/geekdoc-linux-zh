**Audacity** This program, found at http://audacity.sourceforge.net, is an audio editor for Linux, similar to commercial products like Sound Forge for other platforms. You can use it to cut sections from audio, equalize volume, remove tape hiss or noises, apply artificial audio effects, and more.

**Blender** You can use this program to create complex 3D images, including both styles and animations. You can learn more about Blender at www.blender.org.

**The GIMP** The GNU Image Manipulation Program (GIMP) (www.gimp.org) is a still-image manipulation program similar in broad strokes to Adobe Photoshop. (The GTR+ toolkit, which is the base of GNOME and many other programs, was originally created for the GIMP.)

**ImageMagick** This is a set of graphics programs with a twist: you typically use ImageMagick programs from the command line. You can use it to convert formats, add frames to images, resize images, and so on. You can learn more at www.imagemagick.org.

**Handrake** This program provides an easy way to convert video formats, and particularly into formats that use the efficient H264 encoding. You can learn more at http://handbrake.fr.

**MythTV** You can turn a regular PC into a digital video recorder (DVR) using software, which is best at www.mythtv.org. MythTV uses a client-server model, enabling one recorder to serve multiple players on TVs throughout your home.

Given this range of multimedia applications, you can use Linux for everything from cropping photos of your two-year-old's birthday party to rendering the effects for major motion pictures. If you have very special needs, digging a bit may turn up something else—this is just the list to start!

# Using Linux for Cloud Computing

Cloud computing is the storage of computer software and/or data over the Internet, rather than storing it on your computer. In this term, cloud represents the Internet and computing represents what you are doing over a web browser. In some cases, users access cloud-computing resources via a web browser. Thus, in theory, Linux function as a cloud-computing client platform—just launch a browser to access the cloud-computing provider and away you go.
