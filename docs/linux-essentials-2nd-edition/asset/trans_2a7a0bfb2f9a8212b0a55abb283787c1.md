

# 第 1 章 • 选择操作系统

## 安装程序
为了使用软件，必须进行安装，大多数 Linux 发行版都提供了独特的安装软件来帮助你管理这项重要任务。因此，不同的发行版的安装方式可能不同，并为关键功能提供不同的选项，例如磁盘布局和初始用户账户创建。

通常，Linux 发行版可以从它们的网站下载。你可以轻松下载 CD-R 或 DVD 镜像文件，然后将其刻录到光盘。当你启动生成的光盘时，安装程序就会运行，你可以安装操作系统。如果你的电脑缺少光驱，有时也可以下载镜像。许多 Linux 发行版还有云版本，允许你下载一个完整的 Linux 系统，运行在私有虚拟机或像 Amazon 或 Google 服务这样的商业云平台上。

Unbootin 工具 (http://unetbootin.sourceforge.net)可以将文件从 Linux 安装镜像复制到 USB 闪存驱动器。

某些 Linux 安装程序带有你可能需要安装的所有软件。另一些则只包含最少软件，并要求你拥有可用的 Internet 连接，以便安装程序可以下载额外的软件。如果你的电脑没有连接互联网，请务必获取正确的安装程序类型。

这些特征需要进一步解释：
**可用性** 大多数发行版是完全开源或免费软件；然而，有些也包含专有组件且仅供出售，通常附带支持合同。Red Hat Linux (RHEL) 和 SUSE Enterprise 是这类发行版的两个最显著的例子。它们都有完全免费的“兄弟版本”。对于 RHEL，CentOS 是一个近乎克隆的版本，删除了专有组件；而 Fedora 是一个开源版本，作为未来可能被包含在 RHEL 中的技术测试基。。对于 SUSE Enterprise，openSUSE 是一个免费的替代方案。

**软件包格式** 大多数发行版通过*软件包*分发软件，软件包是将许多文件集合在一起的整体。软件包维护一个已安装文件的本地数据库，使得升级和卸载变得简单。RPM 软件包管理器 (RMP) 系统是 Linux 世界最流行的系统，但 Debian 软件包也很常见。其他的打包系统也能良好工作，但特定于发行版。Slack 使用 *tarballs*（压缩包）作为软件包，是不寻常的。这些是由标准 tar 工具创建的软件包文件，该工具通常用于备份计算机和分发源代码等。这些

> Tarballs 类似于 Windows 上常见的 zip 文件。第 8 章“搜索、提取和归档数据”中，将介绍如何创建和使用 tarballs。

> Slackware 用于其软件包的 tarballs 包含了 Slackware 特有的信息，以帮助软件包管理。Gentoo 的特殊之处在于，它的软件包系统基于从源代码编译大多数软件。这非常耗时，但它让经验丰富的管理员能够调整编译选项，以针对他们自己的硬件和软件环境优化软件包。

**发布周期** 我们将在“理解发布周期”中更详细地描述发布周期。通常规则是，发布周期短的发行版旨在提供最新的软件，而发布周期较长的发行版则努力提供最稳定的环境。有些发行版试图兼顾两者；例如，Ubuntu 在偶数年的 4 月发布长期支持 (LTS) 版本。它的其他版本则旨在提供最新的软件。

## 管理员技能要求

表 1.1 的最后一列提供了我们对管理发行版所需技能水平的个人估算。如你所见，我们将大多数发行版描述为需要“中级”技能进行管理。然而，某些发行版提供的用户友好 GUI 管理工具较少，因此需要更多技能。Ubuntu 的目标是特别易于使用和管理。

大多数发行版至少支持两个平台——即 CPU 类型：x86（也被称为 i32、386 及其若干变体）和 x86-64（也被称为 AMD64、EM64 和 x64）。直到大约 2007 年，x86 电脑已成为标准。如果你有一台 x86-64 电脑，你可以在上面运行 x86 或 x86-64 发行版，尽管后者提供了小幅改进。此外还有更冷门的平台，如 ARM（用于平板电脑）、PowerPC、Apple 和 SPARC。此类平台大多限制于服务器和专用设备（稍后描述）。
