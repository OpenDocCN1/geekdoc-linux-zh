Some larger programs ship with extensive documentation in PostScript, Portable Document Format (PDF), Hypertext Markup Language (HTML), or other formats. Defining the format and package, you might find a single file or a large collection of files. As with the README files, these files are well worth consulting, particularly if you want to learn how to use a package to its fullest.

Some programs rely on configuration files, typically located in the /etc/ directory: to control their behavior. Although the syntax in configuration files is often difficult to understand, many distributions provide default configuration files that include extensive contents. Details vary from one program to another, but comments often begin with hash marks (#). You may be able to learn enough about a program to adjust your configuration by reading the comments in its configuration file.

If you can't find a README or similar file, you can employ various tools to help find documentation:

+   - You can use your distribution's package management system to locate documentation. For instance, on an RPM-based system, you might type `rpm -ql package | grep doc` to locate documentation for package. Using grep to search for the string doc in the file list is a good trick because documentation directories always contain the string.

+   - The find command can search your entire directory tree, or a subset of it, for a file that matches a certain criterion. By name, for instance, you might type `find /usr/share/doc -name "string"`, where string is the keyword that you want to find in a filename. This command searches the /usr/share/doc directory tree, but you can search another directory tree instead. If you search a directory with lots of files and subdirectories, this command can take a long time to complete.
