As with nano, you can add a new entry to .txt by using vi, either by typing it in entirety or by duplicating an existing line and then modifying the duplicate line. To do it the first way, follow these steps:

+   1. Move the cursor to the beginning of the bird line by the arrow keys.

+   2. Press the O key (letter O, not number 0). This opens a new line immediately below the current line, moves the cursor to that line, and enters insert mode.

+   3. Type in a new entry: reptile.

+   4. Press the Esc key to return from insert mode to command mode.

To practice changes by modifying an existing entry, follow these steps:
