
## Wi-FI SECURITY (Continued)

- An intruder can intercept data passing over the network, possibly gaining access to sensitive files, acquiring credit card numbers, and so on.
- An intruder may be able to launch attacks on your computers from behind any firewall that you maintain to protect yourself from outsiders.
- An intruder can use your network access to attack other computers or to conduct illegal activities such as pirating movies, music, or software. This not only consumes your network bandwidth, but if the activities are detected, you will fall under suspicion!

For these reasons, you should secure any Wi-Fi network that you manage. Three security levels are available (if you count none at all):

- **WEP** Wired Equivalent Protocol (WEP) is a weak encryption protocol. Methods of breaking into a WEP-encrypted network are well known, making this method effortlessly worthless.
- **WPA** Wi-Protected Access (WPA) security provides improved encryption and authentication tools compared to WEP.
- **WPA2** WPA2 is WPA's replacement, and it provides still more improvements in encryption and authentication.

Several variants on each these encryption methods are available. For instance, WPA and WPA2 provide both personal and enterprise options, the latter requiring a more complex setup with a dedicated authentication server. Typically, you set the encryption method in a broadband router or wireless access point (WAP). Clients then detect the method in use and present appropriate options, such as the password prompt earlier in Figure 15.2.

Public Wi-Fi connections might not use any of these protocols. You can use such connections, but be aware that any data that you send or receive might be visible to others.

The GUI method of establishing a Wi-Fi connection is almost always the easiest method to use. If you need to fine-tune the connection, you can use various tools to probe and manage Wi-Fi links. Here are the two most important of these tools:

**iwlist** This command can identify nearby Wi-Fi networks. Type `iwlist scan` or as root to obtain a list of nearby networks. This command produces a great deal of technical data. You're probably most interested in the network names, which appear in the output following the string ESSID, so typing `iwlist scan | grep ESSID` will pare down the output.

![](img/77662199428609b7662c8dc9c0e45c10_312_0.png)

**iwconfig** This utility connects and disconnects you from specific networks. It uses many options, and you may need to study its man page to understand it fully. In many cases, typing something like the following will do the trick:

```
iwconfig wlan0 ssid NoWires channel 1 mode key s:N1mP7mHNw
```

This example connects to the NoWires network running on channel 1 using the password N1mP7mHNw.

## OBTAINING WI-FI DRIVERS

Unfortunately, Linux driver support for Wi-Fi hardware is weak. If you don't see your Wi-Fi hardware when you try to configure it, you may need to track down suitable drivers. You can begin this task with a tool called `lspci`, which is described in Chapter 5, “Managing Hardware.” This command with no options to see a list of available hardware, and search that list for a wireless network adapter. For instance, your laptop's `lspci` outputs the following line:

```
0300.0 Network controller: Realtek Semiconductor Co., Ltd. RTL8191SEVB Wireless LAN Controller (rev 10)
```

This line identifies the Wi-Fi adapter as a Realtek RTL8191SEVB. A search for Realtek's website turns up a driver; however, this driver has to be compiled locally, which is a topic that's beyond the scope of this book. You might not be lucky enough to find a driver in this way.

An alternative to a native Linux driver is to use a Windows driver. This unusual option is possible using a package called ndiswrapper (http://ndiswrapper.sourceforge.net/), which enables you to install Windows drivers in Linux. Unfortunately, not all distributions provide ndiswrapper in their standard package sets, but you can usually find a binary package in an add-on repository.

If all options fail, you may need to buy new networking hardware. Many USB Wi-Fi adapters are available, but you should research them to find one that has good Linux support. You can also replace the built-in adapters on some laptops.

## Using a Network Configuration GUI

If you've configured a Wi-Fi link but it hasn't obtained an IP address, or if you need to set up a wired network connection, you'll have to set up the TCP/IP networking options. You can do this via text-mode tools, as described later in the section "Using Text-Based Tools," or you can use GUI tools. The latter option is easier for new users, the GUI tools vary from one distribution to another. As an example, the procedure for configuring Fedora using GUI tools is as follows:

1. Open the System Settings tools by clicking your name in the upper-right corner of the desktop and selecting System Settings from the resulting menu or by typing `gnome-control-center` at a shell prompt.
2. Click the Network item in the System Settings Hardware section.
3. Select the network device from the list on the left side of the window. The result should resemble Figure 15.3; however, this figure shows a properly configured link that has no obvious problems. If your network is not working, it might read Disconnected rather than Connected, or it might otherwise show significantly different information.

![](img/77662199428609b7662c8dc9c0e45c10_314_0.png)

FIGURE 15.3 Network connections usually set themselves up automatically, but sometimes they don't.

4. For a Wired connection, click the gear icon in the lower-right corner of the window to adjust your network settings. For a Wi-Fi connection, click the gear icon next to the Wi-Fi network name to which you are trying to connect.
5. Select the IPv4 or IPv6 entry in the left side of the window, depending on whether your network uses IPv4 or IPv6. The result resembles Figure 15.4, which shows a partially configured manual IPv4 setup.

![](img/77662199428609b7662c8dc9c0e45c10_315_0.png)

FIGURE 15.4 You can set TCP/IP features after clicking Options in the Network window.

6. Select the connection method by using the Addresses dropdown. Automatic (DHCP) and Manual options are the most common, but a few obscure options are available. You can disable a network connection by selecting Disabled.
7. If you're using DHCP, you can still manually enter the DNS server and default router addresses.
8. To perform manual configuration, select Manual in the Addresses dropdown and enter the address, netmask, and router by clicking the Add button.
9. When you're done making changes, click Save. If all goes well, your Network dialog box should show an IP address, subnet mask, default route, and DNS server.
