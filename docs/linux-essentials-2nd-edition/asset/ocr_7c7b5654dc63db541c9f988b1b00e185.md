Perl This interpreted language is designed for easy manipulation of text, it's a general-purpose language that can be used for many other tasks as well. Perl programs typically have filenames that end in .pl, .pm, or .t.

PHP The PHP: Hypertext Preprocessor, or PHP (a recursive acronym), language was created for use on web servers to generate dynamic content—that is, content varies depending on the user, the time of day, or some other criterion. PHP is an interpreted language, and it requires a PHP-aware web server, as Apache. Given such a server and appropriate configuration, a website can support user logins, shopping carts, different content based on users' locations, and PHP files often have names that end in .php, although several variants are common.

Python This interpreted language makes code readability a major goal. It supports (but does not require) object orientation. It's often used for scripting purposes, but it can be used to write more-complex programs, too. Python programs often use .py filename extensions, although several variants of this are common.

Shell Scripting Most Linux text-mode shells—the programs that enable entirely keyboard-based use of the computer—provide their interpreted languages. Of these, the Bourne Again Shell (Bash) is the most common, so Bash scripting is quite common. Many of the files that control the Linux startup process are in Bash scripts. Scripts frequently have no unique filename extension, although some use a .sh extension.
