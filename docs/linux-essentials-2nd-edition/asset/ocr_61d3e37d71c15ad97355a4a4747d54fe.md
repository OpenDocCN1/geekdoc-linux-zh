Many commands are available that you might want to use in some mode. Here are some of the highlights:

Change Case Suppose that you need to change the character of a word in a file. Instead of entering insert mode and retyping the word, you can use the tilde (~) key in command mode to change the character. Position the cursor on the first character you want to change, and press repeatedly until the task is done.

If you need to change a file's end-line encoding from the Windows method to the Unix/Linux method, open the file in the vi editor and type the command :set ff=unix.

Undo To undo any change, u in command mode.

Open Text In command mode, typing o (a lowercase O) opens text—that is, it inserts a new line immediately below the current one and enters insert mode on that.

Search To search forward for text in a file, / in command mode, followed immediately by the text that you want to locate. ? searches backward rather than forward.

Change Text The c changes text within command mode. invoke it like the d or y, as in cw to change the next word or cc to change an end line.

Go to a Line The G key brings you to a line that you specify. The H key moves the cursor—that is, it moves the cursor to the top line of the screen. The L key brings the key to the bottom line of the screen.
