10.1 The nano editor enables you to edit a text editor in text mode.

gedit The GNOME desktop environment has an associated text editor known as edit. It's a fairly typical text editor, and it's often installed by default.

**KWrite and Kate** Just as edit is associated with GNOME, KWrite and Kate editors are associated with the K Desktop Environment (KDE). KWrite is slightly more sophisticated than edit, and Kate adds some more features, but neither is nearly as powerful as emacs.

Geany This editor is not tied to any particular desktop environment, and it's small, lightweight, and powerful. It also runs under other OSs besides Linux, such as Windows, which is handy if you want to use one editor for multiple platforms.

For a new Linux user, any of these is a good starting GUI editor; all offer the basic features you need for light text editing. Your choice may depend on which is installed by default on your system. In the long term, you should probably try a variety of editors to find the one that you like best.

# Launching an Editor

If you're comfortable with a GUI desktop environment, you can launch a GUI text editor using the desktop environment's menu system or by using a file manager to browse to a file you want to edit and double-clicking that file. This approach works well for files that you own, but if you need to edit system files, you're likely to lack permissions to save changes if you launch a text editor in this way.
