The details of the shell prompt vary from one installation to another, but you can type text-mode commands at the shell prompt. For instance, you could type ls (short for list) to see a list of files in the current directory. Removing vowels, and sometimes consonants, shortens the most basic commands, in order to minimize the amount of typing required to execute a command. This has the unfortunate effect of making many commands rather obscure.

Some commands display no information, but most produce some output. For instance, the ls command produces a list of files:

```
$ ls 106792c01.doc f0101.tif
```

This example shows two files in the current directory: 106792c01.doc and f0101.tif. You can use additional commands to manipulate these files, as cp to copy them or rm to remove (delete) them. Chapter 6 and Chapter 7 (“Managing Files”) describe some common file-manipulation commands.

Some textmodeprograms take over the display to provide constant updates or to enable you to interact with data in a flexible manner. If you use a graphical login, you can use a text-mode shell known as a terminal. Common Linux GUIs provide the ability to launch a terminal program, which delivers a shell prompt and the means to run text-mode programs.
