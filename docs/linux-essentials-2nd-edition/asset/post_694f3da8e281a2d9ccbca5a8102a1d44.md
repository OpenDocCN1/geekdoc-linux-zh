## Checking for Logged-in Users

Be aware that some account changes could be disruptive if the user is logged in the moment that you perform them. Changing the account's username and home directory, in particular, are likely to cause problems. You should make changes only when the user is logged out. Several tools can help you check who's using the computer and avoid problems:

- The `who` utility, described in Chapter 12, produces a list of users who are currently logged into the computer, with some details of their login sessions, such as their terminal identifiers and login dates.

- The `w` command, also described in Chapter 12, is similar to `who` in broad strokes, but provides different details. Most notably, it identifies the program that's currently running in each session.

This program produces a list of recent login sessions, including their starting and ending times, or a notice that the user is logged in:

```
$ last
jennie tty3 Sun Jan 8 12:43 still logged in
jennie tty3 Sun Jan 8 12:43-12:43 (00:00)
jennie tty2 Sun Jan 8 12:36 still logged in
jennie tty2 Sun Jan 8 12:36-12:36 (00:00)
```

One limitation of `last` is that it includes only text-mode logins. It makes its utility for identifying users who are currently using the computer rather limited, since some users are likely to be logged in using a GUI session.

The `last` command displays data that is stored in the /var/log/wtmp file. You should be aware that some distributions do not create this file by default. Consult the `last` command's man pages for more information.

## Modifying Accounts Using GUI Tools

As with adding accounts, the procedure for modifying accounts using GUI tools varies from one to another. Most GUI tools provide similar options, although some are more complete than others. In this section, how to modify accounts using OPENUSE's User and Group Administration utility is shown.

To make changes, after you have the User and Group Administration utility open, you should click the account and then click the Edit button. The result is a dialog box similar to the one shown in Figure 13.3. This dialog box presents account properties. Each of the four tabs accesses to particular types of data:

User Data: As shown in Figure 13.3, you can adjust the account's comment field (identified as User's Full Name), the username, and the password. If you type a weak password, the program warns you of this fact and asks for confirmation before accepting it.

Details: This tab provides several options: you can change the default shell (called the Login Shell in this utility); add the account to additional groups; modify the primary group (called the Default Group in this utility).

## Modifying Accounts Using Command Line

The `usermod` command is the primary tool for modifying existing accounts from the command line. The table below summarizes the most important options for `usermod`.

| Option | abbreviation | Effect |
| :--- | :--- | :--- |
| `--append` | -a | Used with `--groups (-G)`, causes the specified groups to be added, rather than replaced. |
| `--comment` | -c | Specifies the comment field for the user. |
| `--home-dir` | -d | Sets the account's home directory. |
| `--expired-date` | -e | Sets the date on which the account will be disabled, expressed in the format YYYY-MM-DD. The default is an account that does not expire. |
| `--inactive-days` | -f | Sets the number of days after a password expires, after which the account becomes disabled. A value of -1 disables this feature. |
| `--default-group` | -g | Sets the name or GID of the user's group. The default is a new group named after the user. |
| `--groups[,]` | -G | Sets the names or GIDs of groups to which the user belongs—more than one may be specified by commas. |
| `--login` | -l | Changes the account's username to the specified value. |
| `--lock` | -L | Locks the account's password, preventing logins. |
| `--move-home` | -m | When this option is included with `--home-d`, usermod moves the user's existing home directory to the new location. |
| `--shell` | -s | Sets the name of the user's default shell. |
| `--uid` | -u | Changes the account's UID number to the specified value. |
| `--non-unique` | -o | Enables a single UID number to be reused (Use in conjunction with `--uid/-u). |
| `--unlock` | -U | Unlocks a locked account password. |

For example, consider the following use of usermod:

```
# usermod -u 1072 -m -d /home2/kevin kevin
```

This command makes three changes to the key account:

* It changes the UID value to 1072.
* It changes the account's home directory to /home2/kevin.
