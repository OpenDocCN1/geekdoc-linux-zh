# Searching for a man Page

One of the problems with man pages is that it can be hard to help on a topic unless you know the name of the command, system call or file you want to use. Frequently, methods of searching the manual database exist and can help you lead to an appropriate man page:

Details of what man pages are available vary from one distribution to another. This will affect the results of what this is and apropos searches.

**Summary Search** The whatis command searches summary information contained in man pages for the keyword you specify. It returns a one-line summary for every matching man page. (This is the Name section, described shortly, in "Reading Man Pages.") You can then use this information to locate and read the man page you need. This command is most useful for locating all of the man pages on a topic. For instance, typing `whatis password` returns lines confirming the existence of the page entries for password in various sections.

The -k option to man is equivalent to apropos. You can type either apropos or man -k keyword.

**Thorough Search** The apropos command performs a more thorough search, of both of the Name and Description sections of man pages. The result looks like the results of a whatis search, except that it's likely to contain many more results. In fact, doing an apropos search on every common keyword, as the, is likely to return so many hits as make the search useless. A search on a line is likely to be more useful. For instance, typing `apropos password` may return 16 entries on a system, including for gpassword, smpassword, and password—all password utilities or tools installing files.

If you receive a "nothing appropriate" response from either the whatis or apropos command, typically you need to change the keyword that you are using. However, it may indicate that the man database has not been updated. This is particularly true on a fresh Linux installation or after a new program is installed. You can update the man database manually by using superuser privileges and the command `makethis` (on Linux distributions) or `mandb`. (Using superuser privileges is described in Chapter 12.)
