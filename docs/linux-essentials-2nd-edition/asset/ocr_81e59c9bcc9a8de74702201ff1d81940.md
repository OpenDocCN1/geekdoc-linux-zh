+   The locate command searches a database of filenames Linux maintains. It can therefore do its job much quicker than find can, but you cannot control the power of computer that the system searches. Type locate followed by the string you want to find, as in locate xterm to find any files related to the XTerm terminal.

Once you have located documentation files, you must know how to read them. The details of course, depend on the documentation's file format. You can use less to read many files. Most distributions configure in such a way that it can interpret common file formats, such as HTML, and decompress files that are stored in compressed format to save disk space. Table 6.5 summarizes common documentation file formats and the programs that you can use to read them. Which formats are varied from one program to another.

If you want to see a formatted file, such as an HTML file, in a raw form, use the -L option to less, as in less -L file.

Table 6.5 Common documentation file formats
| Filename extension | Description | Programs for reading |
|---|---|---|
| .1 through .9 | Unix man pages | man, info, Less |
| .gz, .xz, or .bz2 | File compressed with gzip, xz, or bzip2 | Use gunzip, unxz, or bun-zip2 to uncompress; use less, which may be able to uncompress the file and read its format |
| .txt | Plain text | less or any text editor |
| .html or .htm | HTML | Any web browser |
| .odt | OpenDocument text | OpenOffice. LibreOffice, or many other word processors |
| .pdf | Portable Document Format (PDF) | Evinc, Adobe Reader, xpdf |
| .tif, .png, .jpg | Graphics file formats | The GIMP, Eye of GNOME (eog) |

Manually uncompressing a file with gunzip, unxz, or bzip2 may require writing the uncompressed version to disk, so may need to copy the file to your home directory. See Chapter 8 for more details.
