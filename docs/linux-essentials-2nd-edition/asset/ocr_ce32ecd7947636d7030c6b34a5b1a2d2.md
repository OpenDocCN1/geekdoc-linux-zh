# Using Open Source Licenses

Apache Like the BSD and MIT licenses, the Apache license is an open source license that permits redistribution under the same or another license. If a text file NOTICE comes with the original work, it must be included in any derived work. This enables the original developer to provide contact or other information, to users of heavily modified versions of the program.

Artistic The Artistic license was originally developed for the Perl programming language, but it has been used with other programs. It's filled with requirements and loopholes for those requirements. Most software that uses the Artistic license is shielded with the stipulation that this license is optional; the user may elect to follow the terms of some other license (usually the GPL) instead.

Many licenses meet the OSI's requirements. You can find a complete list on the Open Source Initiative website at www.opensource.org/licenses/

> Some combinations of open source licenses are incompatible with each other, meaning that you cannot legally combine the code and release the modified version.

The details of various open source licenses are probably not important to system administrators. You may use and redistribute any open source program as you wish. If you modify a program, though, you should be aware of redistribution requirements, particularly if you want to merge two or more programs or distribute a program under a modified license. You should also be aware that some Linux distributions may include software that doesn't qualify as open source. Some of this is commercial software, and some of it falls into a variant category.

One final concern when describing software licenses is the license for Linux as a whole. When you download an image file or buy a Linux package, the software you obtain many licenses—the GPL, the BSD license, the MIT license, and so on. Most of these distributions ship with free shareware or not-open-source packages, such as the XV graphics program. Retail packages sometimes include right own software. For this reason, you shouldn't copy a retail Linux package's disc unless you've researched the issue and found that copying is OK. If the distribution provides free-as-binary download links, copying is probably allowed.

Linux distributions include installation programs, configuration programs, and the like. These tools are usually that a distribution packager can claim to in terms of copyright. Most distribution maintainers have made their installation and configuration routines available under the GPL or some other open source license, but this isn't always the case.
