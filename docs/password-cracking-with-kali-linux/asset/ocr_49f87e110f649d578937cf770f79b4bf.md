You can download Hashcat and run it on a Windows system, or it is already installed on Kali Linux. Though I personally prefer using Hashcat on my Windows Gaming PC for password cracking, I will cover using Hashcat on Kali Linux. The usage for both is identical, so use what operating system you prefer. In Windows, just download the executable from the tool website and run it, usually Hashcat64.exe for most modern Windows system.
