In the Windows 11 settings, Virus & Threat Protection Settings, go to Manage, then turn off Real-Time Protection.

![](bbox=[0.18, 0.3, 0.54, 0.48])

**Turn off Cloud and Sample Detection also.**

![](bbox=[0.19, 0.53, 0.43, 0.76])

If you have a very aggressive Antivirus/ Security software on the host machine, you may need to disable that as well. I have to do this on my system when working with some of the C2 (Command & Control) frameworks. The host AV will catch the payloads, and remove them before they execute.
