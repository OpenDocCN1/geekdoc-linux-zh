Only one hash is shown - an empty password, which is correct for that hash. But where is the second cracked hash? The newer versions of Hashcat will not store the cracked password if it was cracked earlier. It did crack the second hash; it just didn’t store it in the output file. If you look at both sets of hashes above, one hash is repeated, the hash for the password “P@$$word”. The password is stored in Hashcat’s potfile, so it didn’t bother to store it in the output file.
