# 第二章 如何处理大数据

### 大数据及其问题

大数据是指由于规模太大、无组织或非结构化，无法使用目前数据管理中使用的传统技术和手段进行分析的挖掘数据。数据量并没有数据如何使用和分类重要。

大数据分为三个领域：数量（volume）、速度（velocity）和多样性（variety）。公司被海量数据淹没，需要识别和利用这些数据集的方法。

无论管理如何使用，大数据对企业或组织来说仍然非常有价值。大数据让信息变得透明且可用。现在组织正在收集更大规模的数据，以数字格式存储的成本比以前使用磁带存储要低得多。管理层利用性能数据来探索病假和员工迟到的趋势、产品库存、流转，甚至是存储容量。其他企业正在使用数据探索预算和采购决策的预测。

大数据有助于公司细分客户群体，以便他们能够根据客户的需求和愿望定制产品供应。更重要的是，大数据正被研发，以改进下一代服务和产品供应。

### 捕捉与掌握大数据

公司现在必须使用新的存储、计算、收集、分析和技术来捕捉并处理大数据。尽管技术挑战甚至各家公司的优先事项有所不同，但它们面临着相同的问题：旧的计算机系统、不兼容的格式以及数据整合不完整，阻碍了对数据库信息的解读。

现在有新的方法可以处理数据以协助大数据的质量管理。最好的方法是在做出购买决策之前分析数据的数量、多样性和复杂性。

大数据在数据库管理系统方面有开源技术，包括 `Hadoop` 和 `Cassandra`。市场上还有几种商业智能软件产品，可以向所有主报告、展示和分析最终产品。

### 利用大数据进行业务

据估计，企业只使用了其收到的 5% 的信息。这为改进留下了巨大的空间，可以用大数据分析所需的工具堆栈来填充。列表的开头是存储、计算、可视化软件和分析软件。还需要额外的人员可能可能一个 IT 部门。

投资大数据能获得投资回报（ROI）吗？简而言之，是积极的。麦肯锡全球研究院预计，正确利用大数据的企业可以将运营率提高 60% 以上，这是一个巨大的数字。

以下是建议在组织中实施大数据的步骤：

- 盘点所有数据资产
- 推动管理层拥抱数据驱动的世界观
- 开发技术实施
- 解决政策问题，包括数据安全、隐私和产权
- 识别机会和风险

## 第 3 章 数据管理的益处与挑战

在很久以前，企业主会看一眼新产品，听取销商的推销演示，然后根据自己的“直觉”来决定是否购买该产品。就像那种带有邮局和加油站的杂货店，那个时代已经过去了。



这是一个信息时代。企业必须紧跟趋势、市场动态、消费者偏好和经济压力，以便就其在市场中的定位做出相应决策。海量的可用信息需要受过教育的人才，他们才能熟练且准确地解读所提供的数据。

克利夫兰的西储储大学（Western Reserve University）近期宣布，很快将短缺 19 万名分析人员和 150 多万名数据管理人员。这个问题将主要影响中小型企业，因为他们无法在极其有限的预算内聘请专门的数据分析师。

根据《福布斯》杂志，去年具备大数据技能的信息技术项目经理需求增加了 123.6%，而具备大数据技能的计算机系统分析师增加了 89.8%。

> (来源：http://www.forbes.com/sites/louiscolumbus/2014/12/29/where-big-data-jobs-will-be-in-2015/#2caeda004044ga)

即使企业拥有获取数据分析的能力，除了如何使用提供的信息外，企业仍然面临挑战。这些挑战之一就是数据管理。

数据管理是为了安全、限制访问和存储问题，对数据和收集到的信息进行的组织化管理。数据管理的任务包括治理政策、数据库管理系统、数据系统集成、数据安全、来源识别、数据隔离和存储问题。

### 有效数据管理的关键

数据管理问题并不是新困境。只要有收集数据，企业一直在处理保持数据纯净这一棘手问题。现在，随着数据量的增加和营销自动化的发展，数据安全已成为问题的尖端。

如果数据不干净或不相关，对营销和业务首席官来说毫无用处。数据管理需要持续监控，因为黑客正等待着获取并破坏数百万相关信息和资源。在数据安全方面，有些事情应该是自动化的，例如：

- 1. 限制访问

很多时候，材料和信息的访问对所有员工开放以便修改。办公室经理、销售人员和办公室员工不应有进入数据库并更改、访问、删除或添加信息的能力。控制这种情况的最好方法是建立边界，即限制访问。

根据特定功能设置控制，例如，营销人员仅限于查看市场数据，但不能进行编辑。确定组织中的哪位人员将负责所有数据更改，包括添加/删除和操作（如更改客户的联系信息）。建立数据导入和导出规则，确保安全数据不会流出，并确保病毒不会被上传。创建数据主列表，使信息既不重复也不被破坏。

- 2. 创建数据地图

数据地图是一张描述数据路径的流程图，勾勒出输入和输出、部门集成以及每个数据条目的用途。数据映射是一项持续的练习，用于维护控制和数据一致性。

- 3. 分段组织你的数据

数据的关键不在数量，而在于质量。如果你的客户只有几百人，数据库里有数百万个名字也没有用处。如果你没有组织方法进行检索，数据库里有几百个名字也没有帮助。

相反，根据你的需求对数据进行分类。例如可以按性别、年龄、地址人口统计、邮政编码、联系偏好等。纠正数据库可以使数据焕发生机，而无序的数据库看起来和感觉就像一团乱。

从你目前的活跃客户群开始。将他们按人口统计分段，然后按购买习惯分段。定期与客户联系，收集他们对你产品和服务的意见。

### 4. 数据卫生

数据卫生是保持数据清洁和实新的过程。旧数据和损坏的数据只会干扰你的数据库，甚至可能感染你所有的记录。与之前的功能一样，应该定期提供卫生，以确保数据不会腐败或污染。

维护纯净且组织良好的数据库的重要性不容忽视。如果数据本身不好，那么如果发送到错误的联系点，所有的联系和营销项目都将无法成功。为了增强数据库在营销和销售活动中的价值，不要忽视数据库管理。

这些药物名称在手术、手臂骨折或任何需要去医院急诊的情况下都是常见的处方：Percocet, Lotab, OxyContin, Fentanyl, Vicodin, Morphine 和 Xanax 只是几个例子。Xanax 是一种苯二唑类药物，不是止痛药，但各州建立了数据库来监控这些产品的处方。

- 数据源自多个来源，耗时且复杂。
- 数据不完整，因为许多医生没有花时间咨询数据库。虽然 49 个州强制要求安装该系统，但只有 22 个州要求合规，而且不对合规情况进行监控。
- 没有足够的人员对信息进行实时分析。信息被输入数据库，但没有被有效检索。

SAS 学院领先的数据分析专家在《利用数据和分析应对阿片类危机》报告中解决了这个问题。他们的观点是，目前的信息几乎无法使用。

来源：http://www.sas.com/en_us/whitepapers/jia-data-analytics-combat-opioid-epidemic-108369.html/

通过更好的数据分析和解读，医生可以制定改进治疗方案、患者教育和政策边界。例如：

- 医生可以将其治疗方法与同仁进行比较，以确定早期药物成瘾的特定模式。
- 保险和政府支付系统可以记录潜在的滥用或挪用，从而避免支付欺诈的成本。
- 大型医院和公共卫生系统可以开发出更好的教育计划、治疗方案和资源决策。
- 药店可以比较其配药数据，以确定滥用情况的地理重叠等因素。
- 州可以利用数据库根据人口统计信息为治疗中心提供资金支持。

整合和细分数据可以通过拯救生命，从而缓解那些恐怖的新闻报道。

### 有效用法的示例

一位著名的中型企业主通过使用数据分析发现了 400,000 美元。他似乎遗失了 1,000 件库存，这阻碍了他最渴望的现金流。在他开始盘点的第一天，他发现某些产品一直没有离开货架。

他启动了一场仓储销售，并在周末内卖掉了所有库存，增加了 400,000 美元的现金流。这笔钱支付了新数据库和外围设备的实施。通过快速果断地出售新发现的库存，公司以积极的方式利用了他们的数据并取得了即时效果。

此前，这家公司没有 IT 部门，也没有追踪产品老龄化的 POS 系统。钱在货架上腐烂。一旦安装了数据库系统，他能够减少 40% 的旧库存，并更改了过高的价格点、供应商成本和利润率。他还用更新后的信息清理了客户群，节省了大量的邮寄和打印成本。有了新信息，他可以针对产品购买者进行营销以提高销售额，而不是向不感兴趣的家庭群发邮件。这家公司还利用其数据为他们的忠实和顶级客户提供特别折扣，从而通过向上销售产生收入。

## 第 5 章不同类型的数据分析

“大数据”已经是一个非常火热的词汇，以至于人们对它的定义和作用存在某种误解。大数据的用途是巨大的：欺诈检测、竞争分析、消费者偏好分析、流量管理、呼叫中心优化、公用电网管理，以及仓库和库存管理，这只是列举一角。大数据本身是有问题的，因为它是“数据过载”的商业智能代名词。

大数据的有三个 V：

1. 数据量过多，或容量（Volume）
2. 速度过快；数据移动得快到无法进行分析，或速度（Velocity）
3. 来自许多来源的信息过多，或多样性（Variety）。

尽管大数据的收集和同化令人生而畏，但从大数据中衍生出的商业智能对企业产生巨大的帮助。

### 四种大数据商业智能

有四种对企业主特别有帮助的大数据商业智能：

1. 规范性（Prescriptive）
2. 预测性（Predictive）
3. 诊断性（Diagnostic）
4. 描述性（Descriptive）

### 规范性分析



规范性分析是最有价值的分析，因为它告诉企业应该采取哪些步骤来改善状况。使用这些数据可以是组织变革的开始。尽管它被认为是最有价值的，但它的使用率最低，因为只有 3% 的机构报告使用了大数据。公司可以使用规范性分析为孤立的问题提供具体的见解，例如健康行业中的糖尿病和肥胖问题。大数据可以识别出同时患有糖尿病和高胆固醇的肥胖患者，这三个是导致心脏病发展的三个因素。可以立即针对患者，通过饮食、糖尿病教育、鼓励运动和胆固醇监测对风险因素进行四管齐下的攻击。目前，这些由不同的专家处理，如果它们得到了处理的话。结合治疗策略将有效得多，而且可以通过规范性分析汇编信息的组合。

## 预测性分析

预测性分析是从信息分析中得出的可能场景的预测。这通常以业务预测的形式出现。这种形式的分析通过过去预测未来。例如，企业可能会查看之前的圣诞销售情况，以预测特定产品未来的圣诞销售情况。预测性分析在营销和销售部门特别有用，可以模仿以前成功的活动。一些企业正在使用预测性分析来检查销售流程，从客户介绍、与客户沟通、潜在客户开发、向客户销售到完成销售。

## 诊断性分析

诊断性分析关注过去的问题，以找出“谁、什么以及为什么”。这种分析通常以业务仪表板的形式出现，帮助一目了然地看到现状。诊断分析的一个可以是销售活动或社交媒体营销活动。通过这些，可以看到帖子数量、访问量、评论数和页面浏览。使用这些分析将消除数据中的混乱。

## 描述性分析

描述性分析提供关于现状的实时数据。它不是上周甚至昨天的数据，这些信息是正在发生的。描述性分析的一个例子是为购买新车的客户提取信用报告。

文本挖掘。在利用文本技术时，企业通过分析来自全球网、评论、文章和其他文本来源的文本数据，以发现此前未曾的洞察。文本挖掘结合了机器学习和语言处理技术，对博客、信息流、竞争对手情报、电子邮件、评论和调查问等网络文档进行评估和排序，以帮助企业分析海量信息并发现隐藏的关系。

数据集成是将新的信息和数据添加到旧的计算机系统中，同时确保数据在传输过程中保持整洁且不损坏。有效地移动数据已成为以下领域企业面临的挑战：

- 数据需求
  - 以所需的格式提供正确的数据以缓解业务需求是数据集成的首要原因。每一个新的数据源都可能影响之前收集的信息以及其迁入的系统。
- 预判业务需求
  - 如果数据不能及时获取，它将毫无帮助。集成必须能够同时管理批量信息和实时信息。
- 确保所有数据都加盖了相关信息
  - 旧系统没有在服务器上对活动进行时间戳或标记。为了快速识别对数据进行的更改，数据集成需要记录这些信息。
- 对所有输入数据保持怀疑
  - 预期来自其他源的数据是自然的，但要怀疑它们可能被感染或其他发生损坏。扫描所有输入内容以检查其兼容性和集成需求。
- 验证客户信息
  - 将输入数据与主数据库进行比较，以确认客户数据库是正确且实时的。
- 保留每次更改的历史
  - 有时为了法律合规性需要追溯更改，而且当集成结果未达到预期时经常。
- 升级系统并评估流程
  - 不断寻找系统可能无法满足你业务需求的方法。定期升级系统，以确保你拥有针对数据管理和集成需求的最佳解决方案。

`数据仓库`。数据仓库是组织为自身准备的对电子数据进行存储。数据的存储必须确保其可靠、无损、安全、易于检索且易于管理。

我们在书中始终强调了企业中进行数据分析的必要性，但尚未详细解释具体如何收集数据。本章将侧重于基础数据收集，以便你实施进一步促进组织目标的战略。

### 什么是收集数据？

基本上，汇总并收集的数据意味着让你的数据收集配置投入运行。你已经选择了如何获取数据——无论是通过直接感知、访谈、概述、调查和测试，现在你/或不同的观察者需要利用你的安排。收集信息远不止于此，无论情况如何。你需要以有用的方式记录信息，这样数据在理想情况下才是有帮助的。

你收集信息的方式取决于你想要如何分析和利用它。无论你选择使用何种策略，记录工作应尽可能与信息积累同步进行，或尽早进行，以免任何信息丢失或记忆模糊。

有效数据收集所必需的一些功能：

- 从所有来源汇总数据。
- 计算预期的任何数值或定性操作，以获取用于分析的定量数据。例如，这些可能包括将数值感知转换为图表、表格或电子表格，或计算一组数字的平均值（平均）、中（中点）和/或众数（出现次数最多的数）。
- 对信息进行编码（将信息，特别是未以数字表达的主观信息，转换为允许特定编程项目处理的结构）。
- 整理数据，使其更易于处理。

你如何做到这些将取决于你的研究设计和评估问题。独立变量（成就指标）是由人员或成员小组、时间、动作等所识别的。你可能还需要以几种不同的方式对收集的信息进行分组，以便考虑各种变量之间的交互和关系。

数据中有两类变量。独立变量（干预措施）是分析师或小组执行的条件，以检查它是否会改变并改善状况。这可能是一个项目、策略、框架或其他活动。依赖变量是由于独立变量或干预而可能发生的状态。依赖变量可以是行为或结果。

研究数据包括以揭示其内部存在的联系、设计、模式等方式来查看数据。这可能意味着对其进行统计操作，让你知道变量之间存在何种联系，以及你对所需的答案有有多大程度的信任度。它可能意味着将你的数据与不同的数据集（控制组、州数据等）进行比较，以从信息中得出一些推论。对于你的评估而言，重点是提供一个准确的评估，以更好地理解你的工作及其结果。

你使用两种类型的信息，尽管并非所有情况都包含两者。定量数据允许收集的数据以数字呈现或解释为数字，然后可以对数字进行展示和分解。正如你所预期的，定量数据和定性数据应该以不同的方式进行分析。

定量数据是以数字形式收集的。定量数据的示例包括：

- 特定行为或情况的频率（速率和持续时间）
- 调查结果（报告的行为、客户满意度评分等）
- 人口统计中具有某些特征的人的百分比（糖尿病、肥胖、心脏疾病、受教育程度等）

数据也可以通过数值方式收集，并转换为准备分析的定量数据。编译人员可以为特定行为的程度分配数字。例如，编译人员可以统计 Facebook “赞”或“评论”的数量。这种信息是否有用或是否有帮助取决于你的数据要衡量的问题类型。

与数字不同，定性信息被认为是“软”数据，意味着它无法简化为特定的结论。数字可能指示人口统计中的情况，但软数据可能通过消费者的态度和外表告知你压力水平。

网站。

将定性数据转换为定量数据取决于人为因素。即使客户同同使用 1-5 的数字（1 表示非常不满意，5 表示非常满意）来评估客户满意度，评估量表上仍然存在 2、3 和 4 的问题。数字仅提供部分评估；它们没有提供关于客户评分背后的“为什么”的信息。客户不开心是因为货架上的产品库存、产品细节、店内氛围或店内环境的问题、还是商店的地理位置等？

同样，在统计特定行为的特定发生次数时，计数者是否包含了那些只表现出部分行为的人（例如，在 Facebook 上点了“赞”但没有发表评论）？

定性数据可以传达定量数据无法提供的特定知识，例如某次营销活动之所以有效，或者该活动在文化上如何与客户群体产生冲突。1962 年，雪佛兰（Chevrolet）困惑为什么他们的新车型“Nova”在美国非常受欢迎，但在墨西哥几乎没有销量。人员未能将“Nova”一词翻译成西班牙语，而它的意思是“无法启动（no go）”。该汽车名称在西班牙语俗语中是“不运转”。墨西哥的销量因此下降了！该汽车被更名为 Caribe，销量随之增加。

同时评估定性和定量数据集通常是有帮助的。

- 清晰地设计并定义回答问题所需的测量方法。
- 在正确的时间范围内进行所需期限的研究。
- 根据数据的功能组织数据；你将如何使用这些信息？
- 如果可能且合适，将定性数据转换为定量数据。
- 使用图表和视化图表（示例见第 10 章）使数据更容易被吸收。
- 从视觉上检查信息模式以识别趋势和联系。
- 在定性数据中寻找模式，就像寻找定量数据一样。如果人们反复提到某些问题，这些可能对于理解问题和找到可行的解决方案至关重要。

使用以下类别之一来解释结果：

- 你的营销计划执行符合目标，没有明显问题。
- 你的营销计划对销售没有显著影响。
- 你的营销计划对销售产生了负面影响。（可能被消费者认为具有冒犯性或愚蠢。）
- 你的营销计划结果不一。推广的产品卖得很好，但之前受欢迎的产品可能导致了销量下降。例如，Secret 除臭剂提供了一种非常受欢迎的新香型类别，但无味产品的销量大幅下降，因为忠实用户只是更换了偏好。
- 如果分析显示你的营销计划有效，你有一个简单的选择：继续该计划或对其进行微调以期增加销量。
- 如果分析显示计划不起作用，解释就会变得更加复杂。方程式中缺少了什么？什么因素阻止了预期结果产生？

分析和解释结果使整个过程形成闭环；现在你可以利用所得的知识来调整业务并改进服务。持续分析和评估业务目标及结果将使业务保持活力并在市场中保持有效存在。

# 第 8 章 数据分析的组织方法

本章讨论了组织在将大数据纳入企业文化时需要建立的框架。可行的分析治理将使企业能够利用大数据在竞争中获得优势。

为了整合信息技术、商业智能和分析，必须考虑四个主导问题：

1. 分析是业务的核心组成部分吗？与财务、销售、产品开发、研究和营销处于同一类别？
2. 人员是否已到位？
3. 人员是否具备对业务需求的深度知识能力？
4. 是否建立了治理结构？

该框架被称为 CSPG 框架。

- 文化
- 业务是围绕数据分析转，还是分析让位于营销、研发和销售之后？
- 人员配备



## 人员配备是否充足？招聘合格员工是否是首要任务？IT 部门是在极其有限的预算下工作，还是有适当的资源进行大数据分析？

## 流程
如果分析过程正确完成，就可以与类似组织交换数据而无需担心污染，从而允许多条信息流。

## 治理
治理对于最近才接触数据分析的企业来说是一个新概念。治理需要一个涵盖人员、结构和薪资的结构，以确保 IT 部门与其他部门保持一致而不偏。

数据分析功能的布局有三种模式：

1. 将分析部门设在中央单元。这种位置的优点是易于获取数据、更易融入公司文化，且数据检索速度更快。集中部门面临的挑战可能是位置问题（作为一个附加部门，它可能位于决策者中心之外），部门向谁汇报可能会产生困惑，而且数据分析师可能距离公司文化太远，以至于无法预测业务需求。

第二种可能是将分析去中心化，并将分析师部署在公司各个部门。这允许分析师专注于他们所在的业务领域。挑战是在全公司项目上进行工作，这些项目不是碎片化的，需要所有分析师集中在一个问题集上。

2. 第三种方案是前两种方案的混合。这把分析师放在中心位置，同时在整个组织中部署分析师。这需要庞大的分析师团队，这可能是企业面临的最大挑战。

分析由模型、基础设施和运营组成。模型是源自统计数据的统计、预测或数据挖掘模型。分析过程的关键是建立模型，通常由分析师、数据科学家或统计学家执行。

基础设施是用于数据管理、数据处理和决策的软件组件、应用和使用的平台。与分析基础设施连接的流程包括数据管理、模型部署和必须纳入业务运营的多种分析。

运营是创建用于模型的数据和业务用途的操作过程。数据可以通过购买、内部、外部或协作获取。

数据分析团队必须识别内部和外部相关数据、管理数据、构建分析模型并将模型引入内部系统。大多数企业按如下组织这些功能：业务部门请求模型，分析团队构建模型，IT 部门提供原始数据，运营部门发布模型。这引出了分析治理的必要性。

企业在提取大数据时面临的三个挑战是：
1. 识别数据将使用的独特需求
2. 获取所需信息
3. 将分析模型部署到组织中

分析经理必须有足够的权限来消除这些挑战。治理结构需要一种机制，对源于数据分析问题的问题进行识别、沟通和解决。分析经理还需要灵活性来招聘合格且知识丰富的人员。

可视化让数据对读者而言栩生起来。信息列表在尝试将其转换为可用的数据时可能会非常困难；将数据组转换为易于管理的形式，对于帮助读者区分重要信息和无关信息至关重要。

# Linux 历史

20 世纪初 90 年代初，林斯·托瓦尔斯（Linus Torvalds）是芬兰的一名学生。当时的计算机通常运行在 DOS 或 UNIX 上，这两个操作系统在当时都是专有的且难以使用。托瓦尔斯试图作为一个业余项目（基于 UNIX）创建自己的操作系统，但该项目迅速成长并吸引了更多开发者。内核不断演变，直到它变得可移植（可以在各种系统上使用）并且完全可以用于计算。内核并不是操作系统，尽管 Linux 与 GNU 核心实用程序相结合，创建了一个类似于操作系统的计算环境。

然后，第三方组织获取了基础 Linux 产品，并为其添加了他们自己的高级软件和功能，从而创建了 Linux“发行版”。直到今天，Linux 仍然是一个免费的业余项目，因此内核不断收到托瓦尔斯和社区的更新和修订。在整个 2000 年代，许多其他第三方看到了 Linux 环境的实用性，并开始将其整合到他们的生产环境和企业中。今天，Linux 以因其在服务器和商业环境中被广泛使用而闻名，并拥有小规模的专用桌面用户。面向未来，内核已经达到了永远不会消失流行程度。大公司青睐 Linux 的优势和实用性，因此内核和各种发行版将一直作为最好的替代操作系统存在。

# Linux 的好处

为了比较 Linux 作为计算机选择的有多大，我们将将其与更熟悉的现代操作系统进行比较。

首先，Linux 是免费的。GNU 的背景将 Linux 置于一种“免费和开源”的心态中，随 Linux 发送的大部分（不是全部）软件都是免费的。免费和开源（FOSS）指的是两点：软件在资金上是免费的，而且源代码也是透明的。FOSS 与专有软件的区别在于，FOSS 的一切都是开放的，在使用它时不涉及隐藏的间谍软件、费用或陷阱。软件通常更安全，因为任何人都可以对公开的源代码做出贡献并使其变得更好。由于 Linux 以及你可以为它下载的大部分软件，它对于预算有限的小企业或个人来说是一个极佳的操作系统。通过不收费显然没有牺牲质量，因为 Linux 项目及其各种发行版是社区驱动的，并通过捐赠获得资金。与 Windows 的成本相比，光操作系统通常就需要几百美元。Microsoft Office 是一个受欢迎的文档编写套件，但 Linux 中也存在这些程序的替代方案，它们在质量上绝对可以与大品牌产品媲美。

PC 所有者最大的抱怨可能是病毒。Windows 电脑特别容易受到病毒侵害，即使是防病毒软件公司一直在追赶最新的威胁。只需访问一个恶意网站通常就足够感染计算机，许多用户选择 Mac 电脑是因为与恶意软件相关的事件发生频率要低得多。基于 Linux 的操作系统与 Mac 相似之处在于病毒几乎不存在。这种增强的安全性使得任何关心隐私、安全或可靠性的人都必须切换到 Linux。

Linux 在公司和政府机构中非常受欢迎。这就是为什么高功率服务器和关键设备在运行 Linux 操作系统时，运行得明显更好。该操作系统也以可靠性和稳定性闻名。虽然 Windows 电脑需要定期重启和维护来“刷新”并防止其运行变慢，但 Linux 服务器可以运行几个月甚至几年而无需重启。IT 专业人员由于其声誉不可避免地选择 Linux 作为网络的骨干。其闻名的稳定性在桌面平台也适用于消费者，而且对我们来说绝对有用。

也许使用 Linux 最大的好处是速度。低系统要求意味着在 Windows 上通常很慢的电脑将变得敏捷快速。对变慢感到沮丧的用户会更换操作系统以获得更快速的体验。此外，Linux 可以安装在旧电脑上以重焕活力。因此，尽管旧笔记本对于最新版本的 Windows 可能已经过时，但可能有一个 Linux 发行版可以再榨出几年的寿命。

定制化是技术领域中追求的功能。Windows，尤其是 OSX，由于担心普通用户会破坏它，限制了你对操作系统可以做的操作。Linux 并非如此，因为它鼓励编辑和更改操作系统的视觉效果和功能。当然，这并非必须，而且大多数 Linux 发行版的默认配置非常稳定，很难无意破坏。但对于那些热爱越狱、改装和玩弄电脑的人来说，Linux 可以促进创意的一面，并为好奇的黑客提供在其他系统中无法使用的的工具。

最后，Linux 兼容大量的设备。Linux 可以运行在几乎任何架构上，这意味着它可以安装在手机、台式机、笔记本电脑、服务器、游戏机和“智能”设备上。爱好者们仅仅因为他们可以，就乐于在小众、旧或奇特的设备上安装 Linux。

安装 Linux 有多种方式，例如将操作系统镜像刻录到光盘、写入 USB 闪盘、在线订购 Live CD、格式化 SD 卡，以及通过 Virtual Box 尝试运行。尽管如此，你不能仅仅安装“Linux”就获得一个可用的操作系统。因为 Linux 只是一个内核，你还需要其他提供图形界面、互联网访问等的软件。如前所述，Linux 存在不同的“发行版”（distributions）。发行版是包含预装程序并具有独特风格和重点的 Linux 版本。发行版提取了 Linux 核心，并将其转化为一个适合日常使用的完整操作系统。

Linux 发行版的数量多得惊人。某些版本具有特定用途，例如用于黑客的 Kali Linux、用于教育的 Sugar Linux，以及用于自定义的 Arch Linux。另一些则更通用，例如 Ubuntu 和 Debian。要充分发挥安装 Linux 的优势，你需要了解不同的发行版，并选择哪种最适合你。阅读以下章节将了解一些最受欢迎的发行版的用途。



Ubuntu 是本文写作时最广为人知的发行版。在 2000 年间，它因用户友好和直观而广受欢迎。Ubuntu 基于早期的 Debian 发行版，在使用上与 Windows 电脑非常相似，这意味着它是 Linux 新手的极佳选择。正因如此，我们将在书后的部分安装一个 Ubuntu 变体。Canonical 公司是积极开发 Ubuntu 年度更新的公司，这意味着操作系统始终保持最新状态，并能够使用新兴技术。尽管如此，Ubuntu 仍然可以在许多旧设备上以合理的速度速度运行。应用程序可以从某种“商店”安装，这意味着初学者不需要理解通常复杂的命令行。总而言之，Ubuntu 发行版是首次使用 Linux 的用户的绝佳选择，你应该安装它来学习 Linux 是如何运作的，而无需深陷那些更困难的发行版。

## Ubuntu 变体

针对特定的计算场景，Ubuntu 拥有各种子发行版或“变体”（flavors）。这些发行版以 Ubuntu 为基础，但侧重点不同，例如 Lubuntu 强调轻量级应用。以下是几个：

- Ubuntu – 一种设计为在旧硬件或资源有限的计算机上的 Ubuntu 版本。安装文件小于 1GB，硬件要求远低于标准 Ubuntu。使用此发行版可以复活旧电脑，同时保留 Ubuntu 的可用性。
- Ubuntu Studio – 为艺术家设计的 Ubuntu，包括数字画家、音频制作人员和视频编辑师。Ubuntu Studio 是已经预装了编辑工具的 Ubuntu。
- Kubuntu – 使用 KDE 桌面环境重新渲染的 Ubuntu。Kubuntu 的外观和感受与经典的 Ubuntu 感觉不同，它提供了一个更接近其他操作系统的桌面环境。
- Xubuntu – 另一个轻量级发行版，但不像 Ubuntu 那么精简。Xubuntu 牺牲了体积和硬件要求，提供了一个可以在旧但不过时的电脑上运行的操作系统。它显然比其他极简 Linux 发行版更美观，而且同样以 Ubuntu 为基础，具有用户友好熟悉感。
- Ubuntu Server – 一种更适合工业和企业需求的 Ubuntu 变体，Ubuntu Server 可以无头运行，并为网络中的其他 Linux 系统提供功能。
- Mythbuntu – 一种预装了电视流媒体和直播电视节目的变体。这是一个通过 Kodi 将旧电脑转换为“智能电视”设备的绝佳发行版。

结论，广泛的 Ubuntu发行版意味着每个人都有适合初学者的操作系统。强烈建议你利用 Ubuntu 包含的易用特性和通用熟悉性。它作为一个阶石级的操作系统，将引导你逐渐接触 Linux。务必将其作为你的第一个 Linux 体验进行安装。

## Linux Mint

Linux Mint 是 Linux 世界中经常使用的操作系统。“强大且易用”，Mint 包含了自由开源软件（FOSS）和专有软件，旨在为 Linux 初学者提供完整的体验。虽然它并不完全像 Linux，但 Mint 是作为第一个备用操作系统的极佳选择。它一直位列史上最常用的操作系统之列，其默认布局与 Windows 非常相似，有助于平稳地过渡到 Linux 世界。

## Debian

Debian 是最老的发行版之一，创建于 1993 年。结合 Linux 哲学，Debian 将稳定和稳固作为指导开发的原则。无疑，Debian 存在的时间长度是其精炼程度的指标，因此追求自由和无故障体验的人可以转向 Debian。自由开源软件在 Debian 中也有一席之地，因为包含的大部分软件都是 FOSS。这并不意味着你受到了限制，尽管有一个官方非自由（non-free）软件仓库用于存放像 Adobe Flash 这样的专有程序。对于初来说，Debian 是一个不错的选择，但 Ubuntu 仍然是最好的介绍性操作系统。安装 Debian是为了获得稳定性、FOSS 和纯正的 Linux 体验。

## Slackware

Slackware 是比 Debian 更早的操作系统。它保持了接近原始 Linux 的意图，这意味着你必须安装自己的 GUI 和程序依赖。由于这一事实，Slackware 主要面向中级 Linux 用户，因为初学者会被不熟悉的方法搞困惑。然而，如果你想体验一个接近 UNIX 根源的 Linux 发行版，Slackware 可以提供。

## Fedora

Fedora 是一个更倾向于工作站和商业用途的操作系统。 Linus Torvalds 本人也是 Fedora 的用户，这归功于该操作系统的普及和使用。Fedora 更新非常频繁，这意味着它始终是最新的的，并处于 Linux 技术的前沿。安全和 FOSS 也是该操作系统的重点，这就是为什么它经常被小企业的终端电脑使用。Fedora 可能会面临挑战，因此请将其视为中级操作系统。

## Arch Linux

Arch Linux 是另一个发行版，但它是为经验丰富的用户设计的。通过构建你自己的系统，你将理解那些隐藏在你面前的深层概念。因此，Arch 很难设置，但也是有回报的体验。在熟悉基础知识后，请安装这个高级操作系统。

最后，还有许多值得提到的其他发行版。在接下来的列表中，我们将讨论其中几个。请注意，发行版如此众多，整本书都可以用来描述每一个细分领域。

- CrunchBang – 一种基于 Debian 的发行版，旨在减少资源消耗。它简单，且没有某些发行版包含的臃肿软件。CrunchBang 运行快速且高效。
- Android – 这个流行的手机操作系统实际上是一个 Linux 变体。由于许多手机的配置低于台式电脑，该操作系统是笔记本电脑或触摸设备的极佳选择。此外，你可以使用 Play 商店中的许多 Google 应用，这意味着数千个应用程序、游戏和工具可以在手机和电脑上。虽然不建议将其作为第一个 Linux 操作系统，但它无疑是实验旧电脑很有趣的选择。
- Chrome – Google 开发的另一种移动类型操作系统，Chrome OS 本质上是一个用于上网的轻量级 Linux 浏览器。Google 在 Chromebook 上预装了该操作系统，其配置低于笔记本笔记本。但该操作系统实际上只有一个全屏 Chrome 浏览器，因此它对于想要简单体验或专用上网机器的用户非常完美。
- Tiny Core – 以兆字节为单位的操作系统，Tiny Core 适用于旧电脑或嵌入式设备。该操作系统主要面向有爱好项目或特定用途的中级用户。
- Damn Small Linux – 另一个极简 Linux 变体，该操作系统最适合快速访问 Linux 命令行。
- openSUSE – 这是一个面向经验丰富的计算机用户的发行版。拥有许多适用于管理员和程序开发者的工具，openSUSE 是对技能有心的用户的最佳操作系统。

# 启动进入 Linux

如果你已经准备好投入 Linux 发行版，你必须做的第一件事就是备份你的文件。覆盖硬盘上的操作系统将擦除其中包含的所有数据，这意味着你必须在转换后备份任何你想要保留的图片、音乐或文件。请使用外部硬盘或在线数据存储网站（如 `Google Drive`）来临时存放你的文件。我们对你丢失重要信息概负责，请务必备份！

接下来，我们需要选择一个操作系统。本书将使用 Ubuntu 16.04 作为示例，也建议你也这样做。访问 Canonical 的官方网站（`http://www.ubuntu.com`）并获取该操作系统的副本。你将从该网站下载镜像到你的电脑。

接下来，我们需要获取安装介质。这可以是 DVD、USB 驱动器、SD 卡或你的电脑可以读取的任何可写介质。唯一的限制是设备必须能够容纳与下载的镜像等大的文件，因此 4GB 的空间应该足够了。请删除驱动器上的所有内容，因为它也将被格式化。

下载一个用于写入镜像文件的工具。对于 DVD，安装 `Imgburn`；对于闪存介质，下载 `Rufus`（`https://rufus.akeo.io/`）。最常用的操作系统安装方法是使用 4GB USB 驱动器，而且更推荐这样做。插入你的介质，启动相应的程序，选择下载好的操作系统镜像，并开始写入过程。这需要一些时间，因为镜像需要在介质上被制作成可启动状态。完成后，你可以完全关闭电脑。

现在是双重确认你已准备好安装 Linux 的时候了。检查文件是否已备份，理解你将擦除当前的操作系统，并且最好手头留有一个 Windows/OSX 安装光盘，以防你决定切换回来。如果你确实准备好切换了，请继续。

在安装介质仍然插入的情况下，打开电脑。你看到的第一个屏幕是 `BIOS / UEFI POST` 屏幕，它会提示你应该按下哪个键盘按键来进入设置。此屏幕会显示每一个细节，请务必注意。按下指定的键进入 BIOS 设置。如果你操作太慢，屏幕将会消失，你原来的操作系统将开始加载。如果发生这种情况，只需关掉电脑并重试即可。

但如果出现问题，请尝试通过以下提示进行故障排除：

- 启动了主操作系统而非 Linux – 你可能没有保存将备用启动介质置于顶部的设置。PC 仍然默认从内部硬盘启动。
- “未找到启动介质（`No boot media found`）” – 你是否直接将 Linux 镜像“拖放”到介质上，而不是写入它？如果不显式地告诉电脑它是可启动的，它将不知道如何处理介质上的数据文件。或者，可能是下载的文件损坏或写入不完整。尝试重新下载镜像并再次进行安装。



# 安装问题

“内核恐慌（Kernel Panic）” – 启动过程出现问题。请参见上文关于安装损坏的可能性。否则，你尝试安装的镜像可能与你的硬件不兼容。如果你看到任何错误信息，请在互联网上搜索这些信息。对于预装电脑和笔记本电脑，搜索型号名称和 Linux 以查找其他用户的经验。最后，你可能尝试在 32 位的电脑上安装 64 位镜像。在下次下载镜像时，请特意选择 32 位镜像。

“从 CD-ROM 读取数据出现问题（Problem reading data from CD-ROM...）” – 尝试使用不同的安装介质，因为某些发行版不再支持 CD 和 DVD 安装。推荐使用 USB 驱动器。

PC 似乎启动了，但屏幕上空无所有 – 如果你使用的是独立显卡（相对于 CPU 的集成显卡），Linux 可能无法完全识别它。请将显示器直接插在主板而非显卡上。

但大多数此类问题都是罕见的，或者仅仅是用户操作错误。Linux 具有很高的兼容性，且初始安装/使用相对简单。典型用户到此时应该已经成功启动 Ubuntu，并获得一个可用的计算环境。

# Live CD 体验

你看到的桌面被称为“现场光盘（Live CD）”，这基本上是操作系统及其工作方式的演示。你尚未实际将操作系统安装到硬盘上，因为它仍在直接从你的启动介质运行。这是一个在不实际移除主操作系统的情况下测试 Linux 的机会，所以请利用此机会探索 Linux 发行版是如何工作的。

与 Windows 类似，Ubuntu 拥有桌面图形用户界面。应用程序打开的窗口可以通过顶栏进行最大化、最小化、关闭和移动。Ubuntu 也有某种类似于“任务栏”，其功能与 Windows 的对应部分相似——图标代表点击即可启动的程序。任务栏上的“Windows 按钮”（称为 Dash 按钮）用于打开搜索功能，你可以在其中输入电脑上程序或文件的名称来快速启动它们。除了细微的差异，Ubuntu 的运行方式非常熟悉。事实上，许多你可能在其他操作系统使用的程序（如 Firefox）在 Linux 上都是可用的，有时甚至是预装的。通过实验和练习，你能够像专业人士一样操作 Ubuntu 界面。继续探索系统，如果你准备好用它替换主操作系统，请继续。

# 安装 Ubuntu

在桌面上，你会看到“安装 Ubuntu 16.04 LTS”图标。双击它将启动一个让安装变得非常简单的应用程序。如果你没有连接互联网，请现在通过插入以太线或从右上角连接 Wi-Fi。选择你的语言并点击“继续”。下一个提示将询问你是否要在安装操作系统期间下载更新并安装第三方软件。这些选项对初学者来说非常有帮助，请勾选它们并点击“继续”。

在 Ubuntu 安装期间，你可以指定其他选项，例如时区、电脑名称、帐户名称和密码。整个安装过程不会花费太长时间，但长到足以让你的电脑插通电源（如果是笔记本电脑）。完成后，操作系统将需要重启。恭喜，你现在电脑上有了一个可用的 Linux 系统。

# 硬件管理

在 Linux 中，管理硬件实际上比在 Windows 上容易得多。你不需要为每个设备单独下载驱动程序，大多数驱动程序已经内置在操作系统本身中了。这意味着大多数流行设备只需安装，无需进行任何额外步骤即可使用。打印机、网络设备、硬盘和其他常见设备都包含在内；在 Linux 上通常不需要费心调整驱动程序。

然而，强大的显卡和其他特定硬件需要该公司的专有驱动程序才能发挥全部性能。因为尽管你的显卡在 Linux 下默认可以工作，但其内部的秘密且往往被隐藏的技术只有通过该公司的软件才能被充分利用。在 Ubuntu 上，这个过程非常简单——打开“附加驱动”（additional drivers）应用程序，让系统为你搜索。在确定你是否拥有这些设备后，它会询问你想使用哪个版本的驱动。按照屏幕上的提示启用第三方驱动。对于任何未出现的设备，可以在制造商网站上进行互联网搜索，确定他们是否发布了你可以下载的特定 Linux 驱动。

# 软件管理

软件是 Linux 优于 Windows 的另一个方面。类似于苹果电脑，Ubuntu 也有一类应用程序，你可以在其中搜索与你的设备兼容的应用程序库，只需点击几次即可下载并安装。只需搜索“Ubuntu软件中心”（Ubuntu Software Center）图标即可打开该程序。从那里，你可以浏览“游戏”、“办公”或“系统”等单独分类的程序列表，也可以直接通过名称搜索。找到程序后，点击它，然后点击“安装”将下载加入队列。身份验证后，软件将自动下载并安装。之后，可以在启动栏中搜索来找到该应用程序。

安装软件的另一种方法是通过终端，但我们稍后会讨论这一点。Ubuntu 并不完全限于应用商店中的软件，因为从互联网下载的程序也可以安装。同样，我们将在讨论终端后再次提到这个主题。

总的来说，在 Ubuntu 中管理硬件和软件是非常毫不费力的。无论是安装新硬件设备还是下载流行程序，Linux 发行版都让你的计算体验毫无故障。这并不是说 Linux 完全是为初学者设计的，因为正如我们将学的，Linux 绝对是高级用户和经验管理员的绝佳选择。

# 终端基础

在现代计算机出现之前，硬件和软件完全通过键盘进行交互。鼠标引入了图形界面并简化了流程，但许多功能仍然保持纯文本形式，以便向终端用户呈现复杂的选项。在 Linux 中，这一过程延续到了今天。大多数发行版都存在 GUI（图形界面），但每个 Linux 发行版也内置了一个基于文本的界面，可以在其中输入并执行强大的命令。将终端想象成功能得强大的命令行提示符，因为你可以完全仅通过终端来使用你的计算机。拥有足够的知识，用户实际上可以通过文本浏览互联网、安装程序、管理文件系统等。

通过从启动栏（dash）启动或使用 `Ctrl+Alt+T` 快捷键来启动终端。一个紫色窗口将打开并等待你的输入。你可以输入命令并按回车键激活它。对于我们的第一个命令，输入 `ls`。它是 list（列表）的缩写，将显示当前目录下的所有文件。你可以看到 Home（Ubuntu 的主用户文件夹）中的文件和文件夹。如果你迷路了，可以随时输入 `pwd` 来打印工作目录并显示你当前浏览的文件夹名称。在你学习命令时，将它们写下来有助于更好地记忆它们的用法。

目录（文件夹的另一个名称）的工作方式与其他操作系统相同。文件夹存放文件，你必须当前访问某个目录才能与其中的文件进行交互。你可以使用终端命令 `cd` 来更改目录并在文件系统中移动。例如，从 Home 文件夹输入 `cd Desktop` 将带你跳转到该文件夹。现在使用 `ls` 将不会显示任何内容（除非你在桌面添加了文件）。要返回上，输入 `cd ..`。练习这种方式在文件系统中导航；`cd` 进入一个目录并使用 `ls` 查看文件。

由于你输入的是命令，Linux 期望你的输入是精确的。如果你拼错了命令，它将根本无法运行；如果你输入的文件夹或文件名错误，它将尝试引用一个不存在的对象。在使用终端时请仔细检查你的输入。

打开文件使用一个不同的命令——`./`。点用于启动指定的文件，所以如果你尝试打开一张图片，可以这样操作：`./image.png`。点和斜杠都是必要的，因为它们表示你正在当前目录下运行一个文件。当你运行一个文件时，它将用分配给该文件类型的默认应用程序打开，因此对于图片，它可能会在图像查看器中打开。

你还可以通过终端创建和删除目录及文件。在此示例中导航到 Home 目录。作为快捷键，你可以输入 `cd ~` 将目录更改到你的 Home，因为波浪键 `~` 是“当前用户主目录”的缩写。使用 `mkdir` 命令创建一个目录；输入 `mkdir Programming` 创建一个名为该的新文件夹。你可以 `cd` 进入它，也可以进入 GUI 进入它以证明你确实创建了一个新文件夹。现在通过回到 Home 并输入 `rmdir Programming` 删除该目录。Linux 将毫不犹豫删除指定的目录。同样，使用 `rm` 将删除指定的文件。

Linux 有许多用户并不习惯的设计哲学。在 Windows 和 OSX 中，事物通常是被隐藏的，但 Linux 给你完全的控制权。这可能是危险的，但这也是 Linux 强大之处所在。

# Apt 包管理

Apt（高级软件包工具）是与管理 Ubuntu 应用程序相关的命令。其他发行版可能有它们自己的工具，但 apt 因其庞大的存储库和简单的命令而被广泛使用。使用 `apt-get install` 格式安装软件包，你只需指定要安装的程序名称。在示例中，我们通过包名 `chromium-browser` 指定了 Chromium 程序。由于你不知道每个包名，还有另一个命令 `apt-cache search` 可用于定位与所提供字符串匹配的包名。因此，`apt-cache search chromium` 将显示 `chromium-browser`，你可以指定正确的名称进行安装。

apt 的用处远不止于，因为你可以使用几条命令来更新系统中的每一个应用程序。使用 `apt-get update` 刷新存储库，然后使用 `apt-get upgrade` 让每个应用程序本身更新到最新版本。Windows OS 用户应该对这种简单的流程感到羡慕，因为更新 Windows 需要卸载并重新安装最新版本。

随着时间的推移，你可能需要更新 Ubuntu 版本。每年都会有一个新版本，并且可以通过 `apt-get dist-upgrade` 进行安装。保持最新状态可以确保你的 Linux 系统在很一段时间内运行良好。



为了运行我们安装的程序，我们可以从启动栏（dash）中搜索它们，也可以直接在终端中输入包名。输入`chromium-browser`启动它与双击其图标完全相同。某些程序必须通过在命令行输入包名来启动，因为这些包不会出现在启动栏搜索中。总的来说，利用终端可以节省时间，并且是远离缓慢且复杂的图形用户界面的绝佳方法。

软件包的安装和管理是 Linux 的一项特性，它变得非常有用——掌握它能提升你的体验。安装包的第三种方法是涉及从互联网下载并运行`.deb`文件。某些软件是以这种格式打包的，它们的作用类似于`.exe`文件，只需要双击即可开始安装过程。

## 更多终端命令

这里有几个你应该熟记并应用到系统中的更多基础终端命令。完全理解基础知识将为你后续的构建奠下坚实的基础。

- `cp` – `cp image1.jpg image2.jpg` – 将第一个参数复制（并重命名）到提供的第二个参数。使用`-r`选项复制目录。
- `mv` – `mv cat.jpg /home/Pictures` – 将指定的文件移动到指定的目录。
- `shutdown` – `shutdown -h now` – 关闭电脑。`-h`是一个表示“停止(halt)”的标签，但你也可以使用`-r`重启。`now`指执行所需的时间。
- `date` – `date` – 显示当前的日期和时间。
- `free` – `free -g` – 显示程序的当前 RAM 使用情况。
- `du` – `du -h` – 显示硬盘空间使用情况。
- `ps` – `ps` – 显示使用 CPU 时间的活动进程。
- `touch` – `touch memo.txt` – 用于在当前目录下创建一个指定名称的新空文件。
- `ifconfig` – `ifconfig` – Linux 等同于`ipconfig`，它显示网络信息。

某些命令带有相关的“标签”或“开关”。这些是以破折号开头的字母。它们的作用各不相同，学习针对什么目的使用哪些开关，最好的方法是查看该命令的帮助手册（manual pages）。查看高级章节以打开手册。

命令行最实用的程序之一`nano`，是一个简单的文本编辑器，可用于编辑文件并快速更改设置或脚本。通过在命令行输入`nano`即可访问它。你可以根据需要输入文件名，然后按`ctrl+x`保存并退出。在保存时，你会提供与其相关的名称和文件扩展；`notes.txt`将创建一个名为“notes”的文本文件。或者，你可以通过输入`nano notes.txt`编辑文件。在示例中，我们在编辑器中打开`notes`并在可编辑状态下显示其内容。

可能非常简单，但它无疑是强大的，并且是快速更改和创建文件的节省时间的利器。

## 连接到 Windows / Mac 计算机

Windows 和 OSX 具有内置的网络功能，如工作组、域、共享等。将 Linux 计算机集成到由 Windows 服务器计算机主导的网络基础设施中相当容易，尽管正确的设置将允许你看到 Windows 共享并加入公司域。

实现相互通信的第一步是安装`samba`包。可以通过软件中心找到它，或者输入`sudo apt-get install samba`来获取并安装必要的软件。

从你的 Ubuntu 机器向其他电脑共享文件涉及创建`samba`。Samba 运行与其他流行的文件共享方法相同的协议，因此从 Ubuntu 机器共享的文件可以很容易在 Windows 上看到。安装`samba`后，使用`sudo nano /etc/samba/smb.conf`开始编辑配置文件。在文件的最底部添加以下几行：

```
[share]
comment = File Share from Ubuntu
path = /srv/samba/share
browsable = yes
guest ok = yes
read only = no
```

现在，创建`path`指定的文件夹（`sudo mkdir -p /srv/samba/share/`）并设置权限（`sudo chown nobody:nogroup /srv/samba/share/`），以便任何人访问内容。在该目录下放置你想共享的文件，然后重启服务（`sudo restart smbd`）使共享生效。最后，登录你的其他电脑并导航到网络共享。在 Windows 中，它们将出现在资源管理器的左侧。如果共享没有自动出现，在路径框中输入 IP（通过`ifconfig`获取 Ubuntu IP）。现在你可以从其他操作系统访问。

你可能还需要在 Ubuntu 计算机上查看文件。首先，打开 Ubuntu 文件管理器。从菜单栏点击“文件”，然后选择“连接服务器”。在弹出的框中输入你想要访问的共享 URL。可以是`ftp://test.com`地址、`http://test.com`地址或共享地址（`smb://share/Folder`）。无需任何额外的硬件或设置，你就可以这种方式查看文件。

最后，加入如 Active Directory 等域允许你的计算机与网络上的其他操作系统交互并完成其他面向业务的任务。无论你是一个小型家庭网络，还是将 Linux 计算机加入公司域，过程都是相同的。安装一些额外的包（`realmd`, `sssd`, `sssd-tools`, `samba-common`, `samba-common-bin`, `samba-libs`, `krb5-user`, `adcli`, `packagekit`）。在安装它们时，它会询问你的域名。使用全大写字母。输入`kinit -V adminname`替换为实际的管理员账户名称。输入密码后，你已通过域的身份验证。现在可以使用`realm --verbose join -U adminname domainname.loc`加入。

如果失败，意味着你设备上的 DNS 配置错误。输入`echo 'ad_hostname = nix01.domainname.loc' /etc/sssd/sssd.conf`，然后输入`echo 'rdndns_update = True' >> /etc/sssd/sssd.conf`，最后使用`service sssd restart`使用新设置重启。第一行设置了我们计算机的 FQDN，因此该行需要根据我们的域设置进行更改。在使用正确配置设置重启后，终端将声称已加入域。通过`realm list`进行测试。现在连接到 AD 后，你可以从服务器管理 Linux 设备！

如果你正在寻找某种形式的“控制面板”，你可以在“系统设置”（System Settings）应用程序中找到网络、打印、键盘、外观等其他管理工具的快捷方式。某些 Ubuntu 变体使用“设置管理器”或直接称为“设置”来实现相同的目的。

启动后，将会有指向其他默认配置程序的链接；只需点击你需要的程序，即可通过图形界面（GUI）对选项进行设置。但并非所有的管理操作都能通过 GUI 找到。大多数低级设置只能通过命令行进行，因此，你需要确切知道要输入什么来编辑它们。

例如，在 Ubuntu 中添加新用户需要使用`adduser`命令。通过在命令后加上用户名，终端会提示你输入基本信息和密码。将该新用户设置为管理员可以通过`usermod -aG sudo username`完成。此外，可以使用`deluser`删除用户。这些选项在 GUI 中很难找到，但在终端中几秒钟即可完成。

“任务管理器”或对 Ubuntu 内部运行应用程序的管理也是通过终端完成的。`top`程序在所有发行版中（大部分）都是预安装的，启动它将显示类似于任务管理器的、当前正在运行的所有进程列表。但默认情况下，进程列表会更新并移动，导致可能难以阅读我们所需的数据。按`f`调出排序列表，用方向键导航到`PID`并按`s`设置该选项。现在使用`escape`返回`top`，我们现在可以使用向上页（page-up）和向下页（page-down）滚动列表来查看任务。例如，假设我们在“Pidgin”无响应时关闭它。在列表中找到它（或使用上述过滤命令进行搜索）并记住`PID`（进程 ID）数字。按`q`退出，然后输入`kill 4653`，显然要将数字替换为`PID`。在任何时候你都可以按`h`查看各种操作的键盘快捷键列表。如果`top`难以使用，可以考虑安装`htop`，它是该程序的“人类可读”版本。它实际上显示了整洁的 ASCII 图表，详细列出 CPU、RAM 和其他使用统计数据。使用`F3`搜索程序，然后使用`F9`和回车将其杀死。

对于服务，你可能注意到我们使用`service`命令来更改它们的状态。因此，启动 Web 服务器可以使用`service apache2 start`，通过将`start`替换为`restart`来重启，通过将其替换为`stop`来停止。使用`service --status-all`查找服务列表。服务是守护进程，或持续运行的后台任务。它们可以收集数据、运行蓝牙和 Wi-Fi 等服务，或等待用户交互。

Linux 整体关注安全性，这促进了它在企业和服务器环境中的应用。利用安全协议意味着你比其他操作系统更安全，计算机被入侵的概率更低。当然，这需要良好的安全原则，并且始终在网上保持安全。没有密码的计算机几乎没有受到保护。



一个从 UNIX 引入的特性是文件权限。每个文件都有一组权限——所有者、组和权利权限为 `rw-rw-`。`chown` 命令更改文件的所有者，`chgrp` 更改组，`chmod` 更改与文件相关的权限。通过输入 `ls -l filename` 可以发现文件或文件夹的权限。`R` 表示读（read），`W` 代表写（write），第三个是 `X` 表示执行（execute）。这三组分别是所有者、组和其他。所以，我们的示例文件为所有者及其所在组设置了读写权限，但对其他用户只有读取权限。这意味着所有者及其所属的组（最可能是 sudo 用户）有权访问文件并更改其内容，但网络或电脑上的其他用户只能查看内容而不能编辑。脚本文件需要具有 `X` 权限才能执行，没有它将无法运行。

大多数人只需要使用 `chmod` 命令更改他们想要使用的文件的权限。我们使用该命令和一组数字来设置文件的权限。`chmod 777 test.sh` 使该文件对任何地方的所有用户都可读、可写且可执行，因为每个规范（所有者、组、其他）都带有数字 7。数字决定了实体拥有的权限，计算方式如下：

- 从数字 0 开始。
- 加 4 增加可读性。
- 加 2 增加可写性。
- 加 1 增加执行性。
- 剩余的数字决定权限。

6 代表读/写，但 1 仅可执行。5 代表可读和可执行，但不可更改。在我们的 777 示例中，我们将所有者、组和其他都设置为 7。这并不是特别好的安全性，因为这意味着任何地方的任何人都可以弄那个文件。更保守的权限集是 775。充分利用安全权限来实现安全计算。

Linux 内部的安全扩展不仅限于权限。确保你实践良好的安全规范，并在安全方面遵循常识——只安装需要的程序，不要遵循所有的网络建议，不要频繁使用 `sudo`，使用密码，使用加密网络，保持软件更新，加密重要文件，并定期备份。最后的建议是，考虑使用带有 SELinux 的发行版，它是一个支持 AC 和其他安全策略的模块。

# 脚本

Bash 是“编程语言”或终端。当我们输入命令时，我们是在 bash 内执行的。脚本是一系列按顺序执行的 bash 命令列表，这意味着我们可以创建一个命令列表并运行它，以自动化通常需要输入的任务。作为中级和高级 Linux 管理员，可以使用脚本来减少重复任务的工作量。

要启动脚本，在 nano 中创建一个文件 `script.sh`。第一行必须是 `#!/bin/bash` 以将其标记为 bash 脚本。为你的第一个脚本输入以下行：

```
echo “你的名字是什么？”
read name
echo “你好，$name。这是你的当前目录。”
pwd
ls
```

保存脚本。现在我们需要设置权限允许其运行。使用 `sudo chmod 777 script.sh`，然后用 `./script.sh` 运行脚本。只要你完整复制了脚本，它就会询问你的名字并显示目录和文件。在自己的脚本中进一步扩展这一概念。你也可以运行已安装程序的命令，因此你可以编写一个自动加入域或连接到指定网络的脚本。关闭远程计算机也是一个很好的自动化任务。

脚本可以手动运行，也可以设置为在特定时间执行。要在用户每次登录时运行特定脚本，从 dash 打开“启动应用程序”程序并以脚本为源创建一个应用。现在每当该用户登录时脚本都会运行。这对于设置某些选项或启动后台服务而不需要用户自己操作有用。

为特定时间调度任务可以使用 Cron 系统守护进程。它在某些系统中默认安装，但如果没有，可以使用 `sudo apt-get install cron`。使用 `service cron start` 启动服务并通过 `crontab -e` 创建一个新的 crontab 文件。选择 nano 作为你的文本编辑器。在创建的文件底部，添加包含我们调度任务的新行。格式如下：

`分钟，小时，日，月份，星期，命令`

我们通过这些选项对其格式化以指定运行命令的时间。时间数字从 0 开始，所以小时范围是 0 到 23，分钟是 0 到 59。用星号替换任何选项以指定它将在任何值上运行。注意这些示例：

```
0 12 * * * /home/user/script.sh
```

这将在每天中午 12 点运行主目录下的 `script.sh`。

```
30 18 25 12 * /usr/bin/scripts/test.sh
```

这将在每年的圣诞节 6:30 在 `/usr/bin/scripts` 目录下运行 `test.sh`。

总而言之，编写脚本和自动化脚本是接对定期发生的任务进行行政管理控制的绝佳方法。继续编写脚本吧，或者在网上查找示例，查看如何通过 bash 让你的计算体验变得更简单。

## 高级终端概念

精通 Linux 在于对操作系统可用工具的深入理解以及如何利用它们。本章讨论的许多主题将侧重于更多任务以及如何完成它们，或者对操作系统进行一些通用质量（QOL）改进。

文件的压缩和解压缩经常让 Linux 初学者困惑。这些工具通常已经安装，但必须使用命令行。此外，奇怪的 `.tar` 和 `.gz` 文件类型是 Linux 特有的格式，你可能会经常遇到。所有文件都可以使用 gzip 工具进行压缩或压缩。Ubuntu 预装了该工具，在终端中导航到它并输入 `tar -czvf name.tar.gz foldername`。要压缩一个文件夹及其包含的文件，C 代表“create（创建）”，z 表示“compress（gzip压缩）”，v 代表“verbose（详细）”，f 允许指定文件名。（以时间为代价）通过将 `-z` 参数替换为已安装的 `-j` 参数，使用 gzip2 压缩文件夹。

现在可以使用 `tar -xzv name.tar.gz` 来提取同一个归包。你会发现 `-c` 被替换成了 `-x`，这表示提取。再次强调，如果你处理的是 bzip2 文件，请使用已安装的 `-j` 参数。

继续讨论高级终端概念，让我们来聊一些可以在终端中为你节省时间的质量提示和技巧。在输入命令或文件名时，输入到一半按下 tab 键。这项功能——tab 补全会猜测你尝试输入的内容并填充短语的剩余部分。对于文件，它将按照目录所示完成名称，或通过考虑你正在的操作来补全命令。Linux 专家和任何必须经常使用终端的人看起来似乎以极高的准确性和速度输入他们完全想要的内容，但他们实际上只是在使用 tab 补全。

用户（尤其是管理员）会花费大量时间使用 `sudo` 命令，因为他们的指令需要特权权限才能运行。当输入一个长命令并忘记输入 sudo 时，你会因为必须再次输入它而生气。相反，只需输入 `sudo !!`，它是“super user do again（用户再次执行）”的简写。这慷慨地避免了再次输入整个命令。

另一种重复命令的方法是使用向上和向下箭头。按向上键可以循环切换之前输入过的命令。

还可以使用左箭头和右箭头编辑命令以更改其中包含的文本。

最受期待的终端提示涉及复制和粘贴。尝试向终端粘贴一行内容会产生奇怪的字符 `^`。键盘快捷键没有配置为在终端工作，这就是为什么会显示那种奇怪的组合。要实际粘贴，请右键点击并选择该选项；或使用组合键组合 `shift+insert`。以同样的方式复制，使用 `ctrl+insert`。从互联网复制并粘贴终端命令可能没问题（只要你理解风险并知道它们在命令中在做什么），但不要尝试从本出版物中粘贴。通过你阅读的媒介所引入的格式可能会插入终端无法识别的特殊字符，因此最好不要复制和粘贴，而是应该手动输入呈现的任何命令。

Linux 有一个许多用户并不知道隐藏功能。当你访问该目录或执行 `ls` 时，文件会显示给用户，但实际上并非所有文件都能通过这种方式查看。在 Linux 中，如果你用点开头命名文件，它将被标记为隐藏。隐藏文件通常对普通用户不可见，它起到了保护配置文件免受意外编辑/删除等的作用。要查看这些文件，你只需要在 `ls` 后添加 `-a` 标签。在 GUI 中，在目录中按 `ctrl+h` 以显示秘密内容。当你创建脚本和其他配置文件时，请考虑使用点将它们隐藏，作为一种用户保护的形式。

终端中的任何命令都可以通过 `ctrl+d` 组合键中断或退出。使用它来停止长时间运行的进程，或退出你不理解程序/命令。

别名（Aliasing）是在终端内创建你自己的个人快捷键的方法。与其输入长命令或一堆较短命令，可以使用别名将它们合并为单一的用户定义选项。正如名称所暗示，别名是你指定的任何内容的不同名称。每个别名都包含在一个隐藏的配置文件中，使用 `nano ~/.bashrc` 开始编辑它。由于它存在于用户的目录下，每个别名将只对该用户有效。在文件的底部，我们可以按照下面的示例开始创建别名：

```bash
alias gohome='cd ~ && ls'
```

此别名通过输入 `gohome` 将目录更改为家并显示内容。创建别名时，你必须完全遵循上述格式，这意味着命令和等号之间没有空格。多个命令在单引号内通过 `&&` 连接在一起。为了获得更健壮的别名，请改用函数。接下来的示例将 `cd` 和 `ls` 合并为一个单一命令。

```bash
function cdtls () {
  cd "$@" && ls
}
```

编写别名后，保存文件并重启电脑。你的新命令就可以使用了。



我们编辑的那个文件 `.bashrc` 是 Ubuntu 终端的配置文件。除了制作别名，我们还可以使用它来自定义终端设置，例如颜色、大小等……一个快速提示是取消 `force_color_prompt` 的注释，当你打开终端时右键点击并选择偏好设置。通过这些选项卡你可以自定义字体、大小、背景颜色以及更多。如果你打算经常使用，建议进行自定义，因为这有助于熟悉你将使用的工具。

## I/O 重定向

在标准的终端命令执行期间，“标准输入”（由用户输入，或从文件/硬件读取）被输入并由命令解析。有时命令也有“标准输出”，即显示在终端中的文本。在 `ls` 中，标准输入是当前工作目录，标准输出是目录的内容。

输入和输出通常是直接的但但通过 I/O 重定向，我们可以对终端做更多。作为一个示例，`cat` 命令（连接）后跟一个文件会将该文件输出到屏幕。单独运行 `cat` 会打开一个解析器，任何输入都会立即输出（使用 `ctrl+d` 退出）。通过 I/O 重定向热键（`<`, `>`, `>>`），我们可以将输出重定向到另一个源，例如文件。而 `cat > test.txt` 现在会将输出放在该新文件中。双符号表示追加，因此 `cat >> test.txt` 将输出放在文件的末尾，而不是删除开头的内容。

竖线字符，或称为“管道（pipe）”，使用了另一种 I/O 重定向形式，将一个命令的输出直接插入另一个命令的输入中。`ls | sort -r` 将获取 `ls` 的输出并进行反向排序。我们重定向了输出并将其交给另一个命令来完成此操作。

最后，`grep` 命令在 I/O 重定向中被频繁使用。`Grep` 可以在指定文件中搜索特定字符串并将结果返回到标准输出。通过重定向，这可以放入其他命令中。Linux 一个值得注意的有趣特性是对象即文件，甚至是硬件。所以我们的 CPU 实际上是一个存储相关数据的文件，并可以使用 `grep` 和其他工具对其进行搜索。那个例子相当高级，但这里有一个更简单的实例：

```
grep Conclusion report.txt
```

这会在文件中搜索该特定单词。由于有了所有新符号和命令，I/O 重定向可能会变成一个复杂的过程，但它是你可以将其纳入脚本和日常使用的中的功能，它通常允许用单行代码完成 Linux 的某些特性和功能。

Linux 和终端是难以完全掌握的概念。但通过实践和持续的投入，你将能够完成出色的计算工作，并执行在 Windows 或 OSX 中无法完成的有用任务。学习更多命令以及如何使用它们对这非常有帮助，因此请坚持学习新命令及其用法。你唯一真正需要记忆的命令是 `man`，这是一个可以显示指定的任何其他命令的手册页和文档的命令。手册页显示了你系统中每个命令的开关、示例和预期用途。利用这个工具的优势，对你的系统建立深入的了解。

## 更多 Linux 信息

为了继续学习 Linux 及其能提供的可能性，请考虑本节中的示例。它将简要讨论 Linux 的更多用途，以及其他尚未介绍的概念。

`Linux 文件系统`指的是计算机上文件和文件夹的主要布局。如果你在终端中继续执行 `cd ...`，或者在 GUI 上点击返回按钮直到无法再次移动，你将遇到 `root`（根）目录。这里的文件夹，如 `bin`、`boot` 等、`usr` 等是你的硬件和设置的配置方式。每个文件夹都有特定的目的和用途，你可以通过探索其内容来理解它们。例如，用户数据存储在 `home` 中，但用户程序存储在 `usr` 中。由于文件系统实际上非常多样且复杂，这里将不再对其进行讨论，但如果你想了解更多，请进行网络搜索或阅读与你的操作系统相关的文档。

Linux 系统通常用于桌面用途之外的其他目的。专用机器运行 Linux 变体是因为它提供的强大性能和稳定性。甚至我们的汽车也运行着 Linux 内核，用以跟踪错误代码并帮助技师。

服务器通常安装 Linux 是为了它的可靠性以及发行版中内部包含的功能。例如，Linux 机器被用作防火墙，因为 `iptables` 应用程序提供了优秀的端口阻塞和智能过滤。你自己可以使用该应用程序在你的系统上运行防火墙，从而免费获得业务级软件。通过这种方式，Linux 对于网络也非常棒。只需安装相关应用程序，机器就可以充当交换机、路由器、DNS 服务器、DHCP 服务器等。

最后，Linux 系统不仅限于我们目前所看到的界面。每个发行版都有其首选的桌面环境，但界面可以根据个人偏好进行极大的自定义。甚至还有终端的文件和网络浏览器，这对于使用 `SSH` 或远程计算的人来说非常有帮助。总而言之，你应该通过安装并根据你的喜好配置不同的 `DE`（桌面环境）。

你如何继续，取决于你想对你的 Linux 发行版做什么。对于休闲浏览和简单使用，请继续使用 Ubuntu 并安装你需要的程序。对于更具冒险精神的人，考虑安装一个新的发行版来看看每个版本能提供什么。想要更深入地学习 Linux 的人可以安装像 Arch 或 DSL 这样的版本，从零开始构建你独特的操作系统。管理员和高级用户可以安装发行版的服务器版本来构建你自己的 Linux 网络，或者他们可以考虑将环境从其他操作系统切换到完全免费的系统。

总之，Linux 是一套强大且相对易于使用的操作系统。但它们真正的潜力来自于难以掌握的终端和命令行功能。感谢阅读本出版物，我希望它为这个事实上的替代操作系统这一神秘主题提供了一些见解。如果 Linux 让你感到困惑或没有达到预期，我恳请你重新审视它能提供的功能。虽然它可能没有同等水平的游戏或第三方专有软件，但该操作系统简单且足够自定义，可以作为主操作系统，而将 Windows 或 OSX 作为辅助操作系统。几乎每个程序都有替代方案，因此如果可能完全摆脱微软和苹果，强烈建议你这样做。再次感谢，并善用你新的 Linux 知识。
