Getting to Know the Raspberry Pi
The Raspberry Pi device is a small, single-board, but remarkable fully-fledged computer developed to bridge the gap between computer cost and functionality.
Whether you want a normal, work-day pc, write complex programs, or even dabble in engineering, circuitry, and physical devices, the Raspberry Pi has you covered.
A Raspberry Pi device is a single board computer. That means it’s a full computer like any other desktop, only printed on a single circuitry board. The size of the Raspberry pi is not directly proportional to its size. For example, modern versions of the Raspberry Pi can keep up with some desktop computers with the same accuracy and speed.
Since its initial release back in 2012, a wide selection of people, from engineers to company executives, have received the raspberry pi and adapted to using it. The Raspberry Pi has powered great projects like autonomous boats to devices in space. The raspberry is (clearly) a powerful tool.
Since the initial devices, The Raspberry Pi model B, in association with Broadcom, the Raspberry Pi Foundation has released various models of the Raspberry Pi.
Each model adds new features and improved specifications designed for particular use cases. Models such as the Raspberry Pi Zero, a tiny version of the full-size Raspberry Pi, comes with amazing features such as networking and USB ports, all in favor of a smaller size, low power consumption, and compatibility.
Compatibility is a key feature in all Raspberry Pi models. Software developed to run on a specific model will run in other models as well. You can install the latest version of the Raspbian OS in the very first Raspberry Pi model. You will have to sacrifice some performance off course, but it will successfully run.
As we progress and learn about the Raspberry Pi, I will stick to the latest model, the Raspberry PI 4 Model B and Raspberry Pi 400. However, what you will learn in the book is accurate and adaptable to other raspberry pi models. The projects discussed in the book are also compatible with any raspberry pi model, and you can have fun and learn on any Pi device you have.

Hardware Configuration
One of the Raspberry Pi’s key features is its flexibility. You can buy a Raspberry Pi kit equipped with complete hardware components and the Operating system to run it.
NOTE: Like the Raspberry Pi, the hardware components that drive the Pi have advanced exponentially over the years, with each Pi model having features that differ from that of its predecessors.
We shall focus only on the latest model, the Raspberry Pi 4, released in June 2019.
The Raspberry Pi 4 CPU
Although significant changes have happened with each new release of the Raspberry Pi, all models feature a Broadcom System on Chip (Soc) with an ARM-compatible CPU. The Pi has a clock speed range of 700 MHz to 1.5 GHz on the Raspberry Pi 4. 
The Raspberry Pi 4 has a ARM Cortex-A72 quad-core processor, a successor to the Raspberry Pi 3 B+ processor quad-core Broadcom BCM2837BO that featured a clock speed of 1.4GHz.
Modern Raspberry Pi processors support overclocking at boot by running the command sudo raspi-config during the boot process on Raspbian Linux-based distributions. Most of these processors are overclock-able up to 800MHz and 1000 MHz, and 1500 MHz on extreme edges.
Raspberry Pi Memory
The Raspberry Pi Foundation has done a great job of improving the device’s memory. Older models of the device featured 128MB allocated for the GPU, with another 128MB allocated to the CPU. The GPU in Raspberry Pi is the Broadcom Video-core VI. The Raspberry Pi 4 comes in flavors of 1GB, 2GB, and 4GB.
Raspberry Pi Networking
Older Raspberry Pi models have no ethernet connectivity. The only way to connect them to the internet is using external USB ethernet or a USB wireless adapter.
Newer models such as Raspberry pi B and B+ support gigabit ethernet and use it as the primary interface for connectivity. The latest Raspberry models, like the Raspberry Pi 4, also have an 802.11ac wireless interface and a BLE 5.0 Bluetooth. The Pi 4 also has Gigabit ethernet.
Raspberry Pi Storage
The default storage for the Raspberry Pi is a micro SD card. This SD card is what you will use to install the Operating system and as the default storage disk. However, the Pi supports external storage devices via USB ports.
Those are the main features of the general Raspberry Pi. We may have left out some features specific to the Raspberry Pi 4—instead of the entire Raspberry family—let’s cover that now.

A Raspberry Pi 4 motherboard feature
Here are the purposes of each of these features:
  • The 40 Pin General Purpose Input/output (GPIO) header connects projects with electric devices. You can access them directly on the Raspberry Pi.
NOTE: It’s possible to turn some of the Pins on or off while your Pi is still running—or in operation.
  • PoE Header: Power Over Ethernet (PoE) allows the device, once networked, to be automatically turned on/off at specific times. Raspberry Pi 4 features the 4-PIN header that supports the PoE HAT released on the previous model of Raspberry Pi 3B+
  • Gigabit Ethernet: The Gigabit Ethernet hard-built into the Raspberry Pi 4 features a bandwidth speed of over 350Mbps. Although this may not be as powerful as the regular desktop, it is a significant improvement over the Pi 3B+ that featured the gigabit Ethernet over USB 2.0 at 300Mbps. The Ethernet improvements add to the Raspberry Pi 4 feature-rich arsenal.
  • USB: The Raspberry Pi 4 has 4 USB ports. 2 USB 2.o ports, and 2 USB 3.o ports indicated by blue connectors. Since the Raspberry Pi 4 features built-in Wireless and Bluetooth, the possibility of requiring more ports is minimal since the required peripherals are a keyboard, mouse, and should you choose to add one, a webcam.
  • 4-pole stereo audio/video jack: The Raspberry Pi 4 has a 4-pole stereo audio and composite video port used to connect headphones or external speakers.
  • 2-Lane MIPI CSI Camera Port: The Mobile Industry Processor Interface (MIPI) Camera Serial Interface gives you the ability to attach an official Raspberry Pi Camera Module to the motherboard directly.
  • 2-Micro HDMI Ports: The Raspberry Pi 4 also has 2 micro HDMI ports that allow you to connect the Raspberry Pi to Modern Monitors. The ports support both audio and video with 4kp60 or 4K resolution support. These two Micro HDMI ports have replaced the full-sized HDMI port in the previous generations.
  • USB-C Power Port 5V/3A: The Raspberry Pi 4 has a standard USB Power supply that powers the Raspberry Pi. The Raspberry Pi Foundation recommends using the Raspberry Pi’s official power supply to avoid voltage and power issues that may damage the device. Like most single board computers, the Raspberry Pi supports 5v or 3 Amperes power input. The Power supply used by the Raspberry Pi 4 has changed to USB-C from a Micro USB jack available in previous models.
  • 2-Lane MIDI DSI display ports : The MIDI Display Interface port allows you to connect a display directly to the Raspberry Pi.
  • Micro SD Slot: Like older Pis, the Raspberry Pi 4 has an SD Card slot that acts as the hard drive for the board.
  • 2.4/5GHzWireless and Bluetooth 5.0: The Raspberry Pi 4 has dual-band 2.4 and 5.0 GHz IEEE 802.1/* wireless connectivity and a Bluetooth 5.0 and LE. The wireless connectivity update makes the Pi 4 better than older models—in terms of connectivity.
The above are the essential Raspberry Pi 4 features you should know.
Raspberry Pi 400
The Raspberry Pi 400 is an improvement of the Raspberry Pi 4. It features components that are very similar to those on the Raspberry Pi 4. The difference however is that everything is nicely packed inside a keyboard layout. The Raspberry Pi 400 is powerful and developed to protect the internal components and keep the desk tidier and the cables clear.
The Pi 400 has components such as the system-on-chip and n memory inside a closed keyboard casing, which differs from the regular Raspberry Pi 4. At the back of the Raspberry Pi 4, it features all required ports and the GPIO header, which we will discuss in upcoming chapters.
Next to the GPIO header is the microSD card slot. This stores the microSD card that the Raspberry Pi 400 uses to store the operating system, applications, and other data.
The microSD card comes pre-installed in Raspberry Pi 400; you can remove it by pushing gently on the card until it clicks and springs out, then pull it out. When you put the card back in, make sure the shiny metal contacts are facing downwards; the card should slide in with a gentle click.
The next two ports are the micro-HDMI ports used for connection to a monitor, TV, or any other display. Like the Raspberry Pi 4, the Raspberry Pi 400 supports up to two displays. Next to these is the USB Type-C power port used to connect the Raspberry Pi 400 Power Supply or compatible USB power supply.
The two blue ports are USB 3.0 ports, providing a high-speed connection to devices, including solid-state drives (SSDs), memory sticks, printers, and more. The white port to the right of these is a lower-speed USB 2.0 port, to which you can connect the bundled Raspberry Pi Mouse.
The final port is a Gigabit Ethernet network port that allows you to connect the Raspberry Pi 400 to your network using a network cable as an alternative to using the built-in Wi-Fi wireless networking.

Installing and Setting up Raspberry Pi 4 Hardware
To cater to beginners, let’s discuss how to go about installing and configuring the hardware—no soldering things, just basic setup.
Begin by carefully removing the Raspberry Pi device and its components from its box. Although the Raspberry Pi is a durable and robust device, it’s not immortal.
NOTE: Always hold the Raspberry Pi device by its edges, not its flat sides where the internal components are.
Also, ensure to take extra care when handling the Raspberry Pi raised metal pins to avoid a short circuit that may damage the device. Damaged pin pieces can complicate the process of setting up additional hardware such as cameras, sensors, etc.
Assembling the Raspberry Pi case
If you have a case to protect the Raspberry Pi, this should be the first phase of assembling your devices. If you are using a custom-made Raspberry pi case, refer to the specific manual for your case; otherwise, begin by opening up the official case in the middle, which includes a red and white lid.
  • Pick the red base of the Raspberry pi case and turn it such that the lower part faces you or to the right while the raised part faces towards the left.
  • Now ensure you don’t have the microSD card connected to the device. After ensuring that, hold and raise the Raspberry pi by its USB and Ethernet port at a slight angle. Now slide the connectors—USB Type-C, HDMI, and 3.5 mm audio jack—into their respective cutouts, then gently slide it into a lower position until it sits comfortably on the base. Ensure you do not force the port positions or apply force while placing it on the base of the case; as mentioned, this might damage the device.
  • Use the white cover and place the two clips on the left side of the case into the matching set of holes on the left side of the base. These should be above the microSD slot. Once in place, push down the right side above the USB ports until the case closes fully.

Connecting the Keyboard and Mouse

Connecting the display device
To connect the display device to the Raspberry Pi, simply take the micro-HDMI cable and connect the smaller end of the cable to the port next to the USB Type-C connection port on the Raspberry pi.
Next, connect the other end of the cable to your display. If the display has more than one connection port, you will have to select which input number to use manually for the Raspberry pi. If you are not sure how to do this, simply change the port until you locate Raspberry Pi.
Connecting the Network device
Although this an optional decision, you can connect the Raspberry Pi to a network using a wired connection.

Setting Up NOOBS Software on Mac & Windows
If you purchased a microSD card from the official Raspberry Pi store, you should have NOOBS pre-installed on the card, and you can skip this section. However, for a custom SD card, you will need to set it up before using it. Follow the instructions provided to set up NOOBS on Windows and Mac OS.

You can also enter a name that allows you to identify the SD card; however, this is unnecessary for installation.
You can also use other formatting utilities such as the Diskpart in Windows or Disk utility for Mac. If you opt to use any other formatting utility tool, make sure you format your SD card using the FAT32 file system.
Once the SD card formatting process completes, mount the SD card and open it using File Explorer for Windows and Finder for Mac OS.

NOOBS Installation on Linux
For this subsection, we shall discuss how to set up NOOBS on a Linux system. The method discussed here is simple. However, you can use any method you find comfortable, such as using the Balena Etcher tool.
Using the terminal and disk utilities that come pre-installed in Linux systems, we shall partition the SD card and extract the NOOBS software. This method will work with any Linux distribution provided it has the required tools. You may also need to have root permissions to perform this task.
The first step is to launch the terminal and enter the command sudo fdisk -l to list all the connected disks and partitions in the operating system. Ensure you run the command as root or using an account with elevated privileges.
The output will be something close to /dev/sda or /dev/sdb, indicating disk 1 and 2. If you have more than two drives connected, you may get /dev/sd(n), where n is the alphabetical number of the devices connected.
Next, locate your SD card in the listed devices above, copy its identity code, and proceed to the next step.
The next step is to repartition and format the SD card using the FAT32 file system. Enter the command sudo fdisk /dev/sda replacing the /dev/sda with the code representing your SD card.
Once you run the above command, you should see command m for help.  Press enter to view all the commands available in the fdisk utility. We will only use the command d to delete all the partitions currently on the SD card and command n to create a new partition.
Next, enter command d and press enter. Enter 1 for the partition number. If there are other partitions in the SD card, enter command p to print them.
Select each partition and enter command d and followed by their corresponding partition number. Repeat this procedure until you delete all the partitions on your SD card.
Once you have deleted all the partitions, the next step is to create a new one to install NOOBS. While still in fdisk , enter the command n and press Enter.
Next, enter the command p to confirm the partition type as Primary and proceed. Now enter the partition number as 1 and click enter. Next, Enter the First and Last sector or press Enter to confirm the defaults.
You can confirm that the SD Card contains only one partition; enter the command p to list all the available partitions.
Next, we need to change the file system from Linux to FAT32. Enter the command l to list all the codes available. Locate the code corresponding to FAT32 and provide it to the disk utility and click enter.
In this case, select the t and b commands, respectively.  Once the operation completes, a message indicating that the partition has successfully changed to FAT32 will display.
Next, we need to apply the changes to the disk. Ensure that the changes are as specified above before applying. Enter the command w to write and apply the changes to the disk.
Once you have finished creating the partition, format it by entering the command sudo mkfs vfat /dev/sda/ where dev/sda represents the code for your SD card. These commands tell Linux to create a file system on the FAT32 partition of your SD card.
Now we have partitioned and formatted the SD card in the correct format. Next, we need to download and extract the NOOBS software from the official Raspberry Pi repository to the SD card.

Setting Up Static IP
If you are on a cluttered network that has many devices connected to it, it can be challenging to keep track of the Raspberry Pi IP address on each boot, especially if you have connected to a network that is using DHCP. A static IP allows us to set one unique IP address that the Raspberry Pi will use, which helps us find the Pi.
If you are unfamiliar with DHCP and IP addresses, here is an overview of how they work.
An overview of how DHCP and IP addresses work
Once you connect a device to a network, the router/modem automatically assigns it a unique number made up of four blocks of numbers called the Internet Protocol. The Internet Protocol number is usually something similar to 192.168.0._
The first three blocks represent the network, and the third block represents the host—this depends on the network subnet mask. The last digit represents the device number.
When assigning IP addresses, the router takes the first three blocks representing the network and appends a digit to represent the connected host. The router itself is number 1, and you can find it at 192.168.0.1. For example, 192.168.0.2 may represent your desktop, 192.168.0.3 may represent your laptop, 192.168.0.4 may represent your smartphone, etc.
NOTE: You can find the IP address of the Raspberry Pi by Opening the terminal and typing ifconfig .
However, this number may vary based on the number of connected devices and their mode/nature of connection since the router is responsible for assigning this unique number.
To do this, the router uses the Dynamic Host Configuration Protocol (DHCP), which means that it dynamically assigns IP addresses to the connected hosts. For example, if you disconnect the Raspberry Pi and connect other devices before reconnecting the Raspberry Pi, the Pi may get a different IP address once re-connected.
The implication of this is that you cannot memorize one IP address as the Raspberry Pi’s until you configure it to use one unique IP, which is where static IP addresses come in handy. Using DHCP Reservation, we can tell the router to remember this IP address for the Raspberry Pi only.
You can configure DHCP Reservation using the Router administration panel or edit the Raspberry Pi configurations. Since the routers’ administrations may vary, we shall focus on working with the Raspberry Pi network configurations.

Execute the following command:
sudo nano /etc/dhcpcd.conf

static ip_address=192.168.0.4/24

For static IP, set the desired IP address for the Raspberry Pi. The IP should not be an IP assigned to other devices on the same network. Additionally, the IP should be within the subnet range. For example, 192.168.0.2 – 192.168.0.254
Static routers should contain the IP address of the router. By default, this is 192.168.0.1. You can also specify the DNS servers you would like to use. Introducing the GPIO Header

At the top edge of any modern Raspberry Pi or the back of a Raspberry pi 400 are two long rows of metallic pins called the GPIO or General Purpose Input/output header.
In the Raspberry Pi, the GPIO headers allow you to connect additional hardware such as sensors, cameras, LED, switches, etc. You control the hardware connected to the GPIO header using a program you create. You can use the GPIO pins for both input and output.
We will learn how to connect and interact with the GPIO header using python in upcoming sections.
The GPIO header has 40 (male) metallic pins. Some pins are accessible for use in physical computing; some provide power to some hardware; others provide a communication interface with additional hardware such as sensors that collect and send data to the Raspberry Pi.
NOTE: The Raspberry Pi 400 contains similar GPIO header pinouts, but in the Pi 400, the header pinouts have a reverse order alignment compared to other Raspberry Pi models. Although the GPIO header has labeling on the Raspberry Pi, it can be easy to forget. Ensure to double-check before connecting any device.
There are several categories of pin types, each of which has a particular function:
Electronic Components
The Raspberry pi’s GPIO header is half of the items you require to start hardware programming on the Raspberry Pi. The other half features electrical components, which are devices you control from using the GPIO header. There is a wide range of electrical components, but most of them use common parts.
Solderless breadboard
A solderless breadboard, or simply a breadboard, is an electronic component you can use to make physical computing easier. The breadboard allows you to connect various components into the metal tracks hidden underneath its surface. Using this prevents you from connecting all the components to the Raspberry Pi GPIO header using a bunch of random wires. A breadboard also includes sections for power distributions, thus making building electrical circuits substantially easier. Although it is not a requirement when getting into physical computing, the breadboard is an essential add-on.
Breadboards make the process of connecting circuits very easy by making it possible to plug and unplug components with ease. The breadboard is simply a plastic device made up of rows of holes fitted with copper soldering underneath.
The holes in a breadboard connect in a precise method, as shown below:
Despite each hole connecting to the other, they are all electrically secluded from one another.
We call the horizontal rails or bars power rails. Their primary use is to connect the power supply. Like any power source, it has power and ground bars. The blue rails represent the Ground Rails or GND, while the blue rails are what we use to connect to power.
Split rows, also called circuit rails or circuit areas, are in the middle of the top and bottom power rails. Use this area to connect your components.
Jumper Cables
Jumper cables, also called jumper wires or jumper leads, are handy when you want to connect physical components to your Raspberry Pi or breadboard. There are three main versions of jumper wires.
  1. Male to Female: This connects the breadboard to the GPIO header pins.
  2. Female to Female: This connects individual components, especially when not using a breadboard.
  3. Male to Male: We use this to make connections from one point of a breadboard to another.
Depending on your project, you are most likely to require all types of jumper wires. However, if you are not using a breadboard, M2F and M2M will do fine.
Resistors
Resistors are another common type of electrical component, often used to control or regulate the flow of electrical current. Resistors are available in various values measured using ohms (Ω). In a nutshell, the higher the number of ohms in a resistor, the higher the resistance.
In a Raspberry Pi, resistors are mainly useful when devices are drawing too much power, damaging themselves or the Raspberry Pi in the process. Although this may vary depending on your project and device requirements, you will typically use a resistor rated 330 Ω.
Light Emitting Diode
A light-emitting diode (LED) is an output device you can regulate straight from a programmed controller. An LED lights up when it’s on. You will find LED devices all around you: in houses to cars, planes, etc. They are responsible for alerting you when the cooker is on, smoke detectors, toys, and other indicators.
LEDs exist in many shapes, colors, and sizes. Although there is a wide range of LED components, some are entirely unsuitable for the Raspberry Pi. If you intend to use LEDs with the Raspberry Pi,  it is best to avoid using any LED-rated 5V or 12V supplies.
Piezoelectric buzzer
A piezoelectric buzzer, or simply a buzzer, is a common type of output component used with the Raspberry pi. It is very similar to an LED component in that it produces sound instead of light.
The buzzer mainly contains metallic plates enclosed in a plastic casing and vibrates against each other when an electric current passes through them. There are two main types of electric buzzers: active and passive buzzers. For ease of use, stick to active buzzers.
You will also encounter other common electronic components such as motors, push-button switches, infrared sensors, motion sensors, temperature, humidity sensors, and such.
It is good to note that some components may need special boards before connecting them to the Pi. It is therefore advisable to ensure you have all components at hand before undertaking a project.

Working with Analog Signals on Raspberry Pi

sudo make install-groups-users

- This installs and configures permissions on the
