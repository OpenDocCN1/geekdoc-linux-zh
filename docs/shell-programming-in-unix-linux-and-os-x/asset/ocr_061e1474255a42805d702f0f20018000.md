# 204 Chapter 9 Reading and Printing Data

```
$ printf "The unsigned value for %d is %u\n" -1000 -1000
The unsigned value for -1000 is 429496296
```

```
$ printf "This string contains a backslash escape: %s\n" "test\nstring"
This string contains a backslash escape: test\nstring
```

```
$ printf "This string contains an interpreted\nbackslash escape: \b\n" "test\nstring"
This string contains an interpreted backslash escape: test string
```

```
$ printf "%s and a character: %c\n" hello A
A string: hello and a character: A
```

In the last printf, %c is used to display a single character. If the corresponding argument is longer than one character, only the first is displayed:

```
$ printf "Just the first character: %c\n" abc
a $
```

The general format of a conversion specification is

```
%[flags][.precision]type
```

The type is the conversion specification from Table 9.2. As you can see, only the percent sign and type are required; the other parameters are called modifiers and are optional. Valid flags are -, +, #, and the space character

+   - left-just the value being printed, which will make more sense when we discuss the width modifier.

+   + causes printf to precede integers with a or - sign (by default, negative integers are printed with a sign)

+   # causes printf to precede octal and hexadecimal integers with 0x or 0X, specified as %#x or %#X.

The space character printf to precede positive integers with a space and negative integers with a - alignment purposes.

A few examples. Pay attention to the format strings!

```
$ printf "%d\n+%d\n" 10 -20
+10
+20
```

```
$ printf "%d\n%d\n" 10 -10
10
-10
```

```
$ printf "%#o #%x\n" 100 200
0144 0xc8
$
```
