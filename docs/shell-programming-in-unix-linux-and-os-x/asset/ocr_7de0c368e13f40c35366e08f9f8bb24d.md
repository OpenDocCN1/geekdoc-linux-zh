# The true Command

General Format: true

This command returns a zero exit status.

# The type Command

General Format: type commands

This command prints information about the indicated commands.

Examples

```
$ type troff echo
troff is /usr/bin/troff
echo is a shell builtin
$
```

# The umask Command

General Format: umask mask

umask sets the default file creation mask to mask. Files that are subsequently created ANed with this mask to determine the mode of the file.

umask with no arguments presents the current mask. The -s option says to produce symbolic output.

Examples

```
$ umask          Print current mask
0002            No write to others
$ umask 022     No write to group either
$
```

# The unalias Command

General Format: unalias names

The aliases names are removed from the alias list. The -a option says to remove all aliases.
