Now suppose you wanted to extract the usernames from the output of who. You

```
$ who | cut -cl-8
```

Alternatively, you can use sed to delete all the characters from the first space (which marks the
d of the username) through the end of the line using a regular expression:

```
$ who | sed 's/.*//'
root
ruth
steve
pat
$
```

The sed command substitutes a blank space followed by any characters up to the end of\he line ( .*) with nothing (/); that is, it deletes the characters from the first blank to the
d of line for each input.

# # -n Option

de -n flag is: it tells sed that you don't want to print any lines by default. Paired with,
t you use the p command to print whichever lines match your pattern or pattern.
example, to print just the first two lines from a file:

```
$ sed -n '1.2p' intro
Just print the first 2 lines
```
