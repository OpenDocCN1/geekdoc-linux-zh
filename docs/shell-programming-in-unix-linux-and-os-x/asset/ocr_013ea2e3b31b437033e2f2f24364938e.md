# grep 81

There are characters other than * that have a special meaning to the shell and must be quoted when used in a pattern. The whole topic of how quotes are handled by the shell is admittedly tricky; an entire chapter—Chapter 5—is devoted to it.

grep takes its input from standard input if no filename is specified. So you can use grep as part of a pipe to scan the output of a command for lines that match a specific pattern. Suppose that you want to find out the user jim is logged in. You can use grep to search through jim's output:

```
$ who | grep jim
j tty16 Feb 20 10:25
$
```

Note that by not specifying a search, grep automatically scans standard input. Naturally, if the user jim was not logged in, you would get a new command prompt without any preceding output:

```
$ who | grep jim
$
```
