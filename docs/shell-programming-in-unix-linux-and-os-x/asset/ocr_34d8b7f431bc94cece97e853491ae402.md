uucp
asg
steve
other
$

Given that the home directory of each user is in field 6, you can match up each user of the system with their home directory:

```
$ cut -d -f1,6 /etc/passwd
root:
cron:
bin:
uucp:/usr/spool/uucp
as:
steve:/users/steve
other:
$
```

Extract fields 1 and 6

If the cut command is used to extract fields from a file and the -d option is not supplied, cut uses the tab character as the default field delimiter.

The following depicts a common pitfall when using the cut command. Suppose that you have a file called phonebook that has the following contents:

```
$ cat phonebook
Alice Cheeba 733-555-2015
Barbara Swingle 201-555-9257
Jeff Goldberg 201-555-3378
Liz Stachiw 212-555-2298
Susan Goldberg 201-555-7776
Tony Iannino 973-555-1295
$
```

If you want to get the name of the people in your phone book, your first impulse would be to use cut as shown:

```
$ cut -c1-15 phonebook
Alice Cheeba 97
Barbara Swingle 2
Jeff Goldberg
Liz Stachiw 212
Susan Goldberg
Tony Iannino 97
$
```

Not what you want! This happened because the name is separated from the phone number by a tab character, not a set of spaces. As far as cut is concerned, counts can be a single character when using the -c option. Therefore cut extracts the first 15 characters from each line, producing the results shown.
