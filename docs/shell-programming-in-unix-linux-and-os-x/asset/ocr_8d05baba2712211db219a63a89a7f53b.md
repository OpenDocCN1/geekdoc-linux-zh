# Quoting 329

\
Complete pathname of current word; if current word is a directory, append a
/; if current word is a file, append a space.

u
Undo the last text modification command.

U
Restore the current line to its original state.

@letter
Soft function—if an alias of the name _letter is defined, its value will
executed.

[count]v
Executes vi editor on line count; if count is omitted, the current line is used.

Ctrl+l
Linefeed and print current line.

L
Reprint the current line.

Cri+j
Execute the current line.

Cri+m
Execute the current line.

Enter
Execute the current line.

#
Insert a @ at the beginning of the line and enter the line into the command
history (same as I#Enter).

# Quoting

Four different types of quoting mechanisms are recognized, as summarized in Table A.5.

| Quote | Description |
|---|---|
| '...' | Removes special meaning of all enclosed characters. |
| "..." | Removes special meaning of all enclosed characters $, \', and \. |
| \c | Removes special meaning of character c that follows; inside double quotes removes special meaning of $, \', newline, and \ follows, but is otherwise interpreted; used for line continuation if it appears as last character on line (newline is removed). |

'command' or
$ (command)
Executes command and inserts standard output at that point.

# Tilde Substitution

Each word and variable on a line is checked to see whether it begins with an
unquoted -. If it does, the rest of the word or variable to a / is considered a log name and
is looked up in a system file, typically /etc/passwd. If that user exists, their home directory
places the ~ and the name. If that user does not exist, the text is unchanged. A ~ by itself
followed by a / is replaced by the HOME variable.
