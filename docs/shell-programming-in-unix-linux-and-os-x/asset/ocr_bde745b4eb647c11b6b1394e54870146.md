# Command Options

Most Unix commands allow the specification of options at the time a command is executed. These options generally follow the same format:

```
-letter
```

That is, a command option is a minus sign followed immediately by a single letter. For example, to count the number of lines contained in the file, the option -1 (that's the -l) is given by the wc -1 command:

```
$ wc -1 names
```

5 names

```
$
```

To count the number of characters in a file, the -c option is specified:

```
$ wc -c names
```

27 names

```
$
```

Finally, the -w option can be used to count the number of words contained in the file:

```
$ wc -w names
```

24 names

```
$
```

Some commands require that the options be listed before the filename arguments. For example, sort names -r is acceptable, whereas wc names -1 is not. Still, the former is unusual and most Unix commands are designed for you to specify options first, as exemplified by wc -1 names.

# Making a Copy of a File: The cp Command

To make a copy of a file, use the cp command. The first argument to the command is the name of the file to be copied (as the source file), and the second argument is the name of the file to place the copy into known (as the destination file). You can make a copy of the file names and call it saved_names as follows:

```
$ cp names saved_names
```

```
$
```

Execution of this command causes contents of the file names to be copied into a new file named saved_names. With many Unix commands, the fact that no output other than a command prompt was displayed after the cp command proved indicates that the command executed successfully.
