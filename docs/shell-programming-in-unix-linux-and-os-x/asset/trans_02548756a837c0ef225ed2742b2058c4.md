**纪念碑谷**是美国西部的标志符号，也是世界自然奇迹之一。这一红沙漠地区位于亚利桑那州和犹州交界的纳瓦霍霍族范围内，拥有高耸的砂岩岩层，这些岩石随时间推化而成，从谷底高出 400 至 1000 英。山谷中最受摄影拍摄的三座山峰是独特的东手套丘、西手套丘和梅里克山丘。
