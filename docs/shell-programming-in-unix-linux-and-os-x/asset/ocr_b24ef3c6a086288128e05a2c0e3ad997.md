Many modern Unix systems have gone away from using groups, while those permissions are still shown, the group owner for a specific file or directory is omitted in the output of the command.

# Creating a Directory: The mkdir Command

Use mkdir to create directories. The argument to this command is simply the name of the directory you want to create. For example, assume that you are still working with the directory structured in Figure 1.7 and that you want to create a new directory called misc at the same level as the directories documents and programs. If you were currently in your home directory, typing the command mkdir misc would achieve the desired effect:

```
$ mkdir misc
$ 
```

If you run ls, you will have the new directory listed:

```
$ ls
ddocuments
misc
programs
$ 
```
