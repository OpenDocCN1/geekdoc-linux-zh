Parameter Substitution 243

When you write the construct
${variable\pattern}

the shell looks inside *variable* to see whether it ends with the specified *pattern*. If it does, the contents of *variable* are used, with the shortest matching *pattern* removed from the right.

If you use the construct
${variable\pattern}

the shell once again inside *variable* to see whether it ends with *pattern*. This time, however, it removes the *longest* matching pattern from the right. This is relevant only if the * is used in *pattern*. The % and %% behave the same way.

The # is used in a similar way to force the pattern to start from the left rather than the right.
${variable\pattern}

tells the shell to use the value of *variable* on the command line, with *pattern* removed from the left.

Finally, the shell construct
${variable\pattern}

works like the # form, except the longest occurrence of *pattern* is removed from the left.
Remember that in all four cases, no changes are made to the pattern itself. You are affecting only what gets on the command line. Also, remember that the pattern matches are *anchored*. In the case of the % and %% constructs, the variable of match must *end* with the specified pattern; in the case of the # and ## constructs, the variable must *begin* with it.

Here are some simple examples to show how these constructs work:

```
$var-testcase
$echo $var
testcase
$echo ${var%}      Remove e from right
testcas
$echo $var
testcase           Variable unchanged
$echo ${var*e}      Remove smallest match from right
testca
$echo ${var%%e}    Remove longest
te
$echo ${var#?}      Remove smallest match from left
stcase
$echo ${var#*}      Remove smallest match from left	casecase
$echo ${var##}     Remove longest match from left
```
