Finally, in all case of this is not confusing enough, if a * is used in place of a number for
width or precision, the argument preceding the value to be printed must be a number and
be used as the width or precision, respectively. If a * is used in place of both, two integer
arguments must precede the being printed and are used for the width and precision:

```
$ printf("%*.*s\n" 12 "test" 10 2 "test two"
    test one
    te
$ printf("%12s%%10s\n" "test one" "test two"
    test one
    te
$
```

As you can see, the two prints in this example produce the same result. In the first printf,
12 is as the width for the first string, 10 as the width for the second string, and 2 as the
precision for the second string. In the second printf, these numbers are specified as part of the
format specification.
While the format specification for printf is unquestionably complex, its power and capabilities
ties to the relatively unstructured output of echo into exactly what you want from your
own shell programs are darn helpful. It's a command worth studying more closely so you
know how to use it as you develop your more sophisticated programs.

Table 9.3 printf Format Specification Modifiers

| Modifier | Meaning |
|---|---|
| Flags | Left-justify value. |
| + | Precede integer with + or -. |
| (space) | Precede positive integer with space character. |
| # | Precede octal integer with 0, hexadecimal integer with 0x or 0X. |
| width | Minimum width of field; * means next argument as width. Minimum number of digits to display for integers; maximum number of characters to display for strings; * means next argument as precision. |
