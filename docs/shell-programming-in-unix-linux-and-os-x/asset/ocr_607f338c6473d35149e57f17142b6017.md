Add the -1 option to grep and you get instead list of files that contains the specified pattern,
matching the lines from the files:

```
$ grep -1 'Move_history' *.c

$
```

Because grep -1 conveniently lists the files one per line, you can pipe the output from grep -1
to into wc to count the number of files that contain a particular pattern:

```
$ grep -1 'Move_history' *.c | wc -1
3
$
```

The preceding command shows precisely three C program files reference the variable
Move_history. Now, just to make you're paying attention, what are you counting if you
use grep without the -1 option and pipe the output to wc -1?

# ## -n Option

If the -n option is used with grep, each line from the file that matches the specified pattern
is preceded by its corresponding line number. From previous examples, you saw the file
testch.c was one of the three files that referenced the variable Move_history; the following
shows how you can pinpoint the lines in that file reference the variable:

```
$ grep -n 'Move_history' testch.c      Precede matches with line numbers
13:GLOBAL Move_history[100] = {0};
197:     Move_history[Number_half_moves-1].from = move_from;
198:     Move_history[Number_half_moves-1].to = move_to;
$
```

As you can see, Move_history is used on lines 193, 197, and 198 in testch.c.

For Unix experts, grep is one of the most used programs because of its flexibility
and sophistication with pattern matching. It's well worth studying.
