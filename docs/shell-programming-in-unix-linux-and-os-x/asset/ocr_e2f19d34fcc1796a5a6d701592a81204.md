There's a bit more the shell does before individual programs are invoked, so let's talk about those for just a moment too.

# Variable and Filename Substitution

Like a more formal programming language, the shell lets you assign values to variables. Whenever you specify one of these variables on the command line preceded by a dollar sign, the shell substitutes the value assigned to the variable. This topic is covered in much more detail in Chapter 4.

The shell also performs filename substitution on the command line. In fact, the shell scans the command line looking for filename substitution characters *, ?, or [...] before determining the name of the program to execute and its arguments.

Suppose that your current directory contains these files:

```
$ ls
mrs.todd
prog1
shortcut
sweeney
```

Now let's use filename substitution (*) for the echo command:

```
$ echo *
List all files
mrs.todd prog1 shortcut sweeney
```

How many arguments were passed to the echo program, one or four? Because the shell performs the filename substitution, the answer is four. When the shell analyzes the echo *

it recognizes the special character * and substitutes the names of all files in the directory (it) echo mrs.todd prog1 shortcut sweeney

Then the shell determines what arguments to pass to the actual command. So echo never sees the asterisk and as far as it's concerned, four arguments were typed on the command line (see Figure 2.11).
