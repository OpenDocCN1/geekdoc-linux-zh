Hopefully this complex shell programming example offers you some insight into how to develop larger shell programs and how many different programming tools provided by the system can work together.

Other than shell built-ins, rolo relies on tr, grep, an editor, sort, and the standard file system commands such as mv and rm to get the job done.

The simplicity and elegance that enable you to easily tie all these tools together account for the deserved popularity of the Unix system.
