In the case of a shell program invoking another shell program (for example, the rolo program calling the lu program), the process is repeated: the exported variables from the subshell are copied to the new subshell. These exported variables may have been exported from the login shell, or newly exported from within the subshell.

After a variable is exported, it remains to all subshells subsequently executed.

Consider a modified version of vertest4:

```
$ cat vertest4
x=50
y=5
z=1
export z
vertest5
$
```

and vertest5:

```
$ cat vertest4
echo x = $x
echo y = $y
echo z = $z
$
```

When vertest4 gets executed, the exported variable y will be copied into the subshell's environment, vertest4 sets the value of x to 50, changes the value of y to 5, and sets the value of z to 1. Then it exports z which makes the value of z accessible to any subshell.

vertest5 is such a subshell and when it is executed the shell copies into its environment the exported variables from vertest4: y and z.

This explains the following output:

```
$ vertest4
x=
y = 5
z = 1
$
```
