Remember, the ? matches any single character. Since we already have tested the character against digits, lowercase and uppercase letters, and this pattern must be a special character. Finally, if this pattern isn't matched, more than one character have been typed, the catch-all case prints the appropriate error message.

```
$ c u
lowercase letter
$ c ''>'
special character
$ c xx
Please type a single character
$
```

# Back to the case

The symbol | has the effect of a logical OR when used between two patterns. That is, the pattern

```
pat_ | pat_|
```

specifies that either pat_, or pat_ is to be matched. For example,

```
-1 | -list
```

matches either the value -1 or -list, and

```
dmd | 5620 | tty5620
```

matches any of dmd or 5620 or tty5620, there are a number of different programmatic flow structures that can be more neatly and efficiently rewritten with case sequences.

For the example, the greetings program that you saw earlier in this chapter can be rewritten using a case statement rather than the clunkier if-elif. This time, let's take advantage of the fact that date with the +H option writes a two-digit hour to standard output.

```
$ cat greetings
#
# Program to print a greeting -- case version
#
```

```
case "$hour"
in
	0? | [01] ) echo "Good morning";
	1[2-7] ) echo "Good afternoon";
	*) echo "Good evening";
esac
$
```
