# Command History

Regardless of which shell you use, it keeps a history of all your previously entered commands. Each time you press the Enter key to execute a command, that command gets added to the end of your history.

Depending on your settings, your command history could even be saved to a file and restored between sessions, so you can quickly access commands from previous sessions.

By default, the history is kept in a file in your home directory named .sh_history (Bash). You can change this filename to anything you want by setting the HISTORYFILE variable. This variable can be set and exported in .profile.

There is a limit to the number of commands the shell stores. The minimum value is 128 and most modern shells use 500 or more of your commands on the list. Each time you log in, the shell automatically truncates your history file to this length.

You can control the size of your history file by setting the HISTSIZE variable. If the default isn't adequate for your needs, set the HISTSIZE variable to a larger value, such as 500 or 1000. The value you assign to HISTSIZE can be set and exported in .profile file:

```
$ HISTSIZE .profile
HISTSIZE=500
export HISTSIZE
$
```

Don't go crazy with a massive history size, however: the larger the value, the more disk space you will need to store the history file, and the longer it will take the shell to search through the list when you access previous commands.

# The vi Line Edit Mode

After turning on the vi editor feature, you will be typing all subsequent commands in what vi users think of as input mode. You probably won't even notice difference because what you can type in and execute commands exactly the same way that you do with the default shell input prompt:

```
$ set -o vi
$ echo hello
hello
$ pwd
/users/pat
$
```

To make use of the line editor, you must switch to command mode by pressing the ESC key, usually in the upper-left corner of the keyboard. When you enter command mode, the cursor moves to the left one space, to the last character typed in.
