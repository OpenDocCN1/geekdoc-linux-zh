# The Single Quote 107

As soon as the shell encountered the first ' stopped interpreting any special characters until it found the closing '. The space between Susan and Goldberg, which would normally have delimited two separate arguments, was ignored by the shell. The shell then split the command into two arguments, the first Susan Goldberg (which includes the character) and the second phonebook. It invoked grep passing these two arguments (see Figure 5.2).

| grep | arguments | Susan Goldberg |
|---|---||
| | | phonebook |

Figure 5.2 grep 'Susan Goldberg' phonebook

grep interpreted the first argument, Susan Goldberg, as a pattern that included an embedded space and looked for in the file specified by the second argument, phonebook. Note that the shell removes the quotes and does not pass to the program.

No matter how many space characters are enclosed between quotes, they are all preserved by the shell.

```
$ echo one two three four
one two two three four'
$ echo 'one'
two three four
$
```

In the first case, the shell removes the extra whitespace characters from the line (no quotes!) and passes echo the four arguments one, two, three, and four (see Figure 5.3).

| echo | arguments |
|---|---||
| one | two |
| | three |
| | four |

Figure 5.3 echo one two three four

In the second case, the extra spaces are preserved and the shell treats the entire string of characters enclosed in quotes as a single argument when executing echo (see Figure 5.4).

| echo | arguments |
|---|---||
| | one two three four |

Figure 5.4 echo 'one two three four'
