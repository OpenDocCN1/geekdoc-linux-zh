After execution of the set, everything works as expected: $$, $*$, and the for loop without a list all reflect the change in positional parameter values.

set is often used in this fashion to “parse” data read from a file or the terminal. Here's a program called words that counts the number of words typed on a line (using the shell's definition of a “word")

```
$ cat words
#
# Count words on a line
#
```

```
read line
set line
echo $$
$ words Run it
Here's a line for you to count.
7
$
```

The program reads the user input, storing the line read in the shell variable line, then executes the command

This causes each word stored in line to be assigned to the appropriate positional parameter. The variable $$ is also set to the number of words assigned, which is also the number of words on the line.
