For users, the ENV file is read only when Bash is invoked with the name sh, with the --posix command-line option, or after set -o posix is executed (all of force POSIX standard compliance). By default, when a non-interactive Bash shell is started (for example, when you run a shell program), it reads commands from the file specified by the B_ENV environment variable, and when an interactive Bash shell is started (for example, typing bash at the command prompt), it doesn't.

# Command-Line Editing

Line edit mode is a feature of the shell that allows you to edit a command line in a manner that mimics features found in two popular editors. The POSIX standard provides the capability to mimic vi and both Bash and the Korn shell also support emacs line edit mode. We list the complete set of commands in Table A.4 in Appendix A.

If you've used either of these text-based editors, you'll find the built-in line editors in the shell are faithful reproductions from a functional perspective. This capability is one of the most useful features in the shell.

To turn on a line use the set command with the -o mode option, where mode is either vi or emacs:

```
$ set -o vi
Turn on vi mode
```

Put this in your .profile file to automatically start up the shell with one of the edit modes turned on.
