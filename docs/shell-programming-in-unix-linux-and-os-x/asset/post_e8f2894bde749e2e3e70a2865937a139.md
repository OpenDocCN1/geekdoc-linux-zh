# The && and || Constructs

The shell has two special constructs that enable you to execute a command based on whether
the preceding command succeeds or fails. In case you think this sounds similar to the if
command, well it is. Sort of. It's a shorthand form of the if.

If you write
`command, && command;`

anywhere the shell expects to see a command, command, will be executed, and if it returns
an exit status of zero (success), command, will be executed. If command returns a non-zero exit
status (fail), command, is not invoked if ordered.

For example you write
`sort bigdata > /tmp/sortout && mv /tmp/sortout bigdata`

then the mv command will be executed only if the sort is successful. Note that this is
equivalent to writing
`sort bigdata > /tmp/sortout`
then
`mv /tmp/sortout bigdata`

The command
`[ -z "$EDITOR" && EDITOR=/bin/ed`

tests the value of the variable EDITOR. If it's null, /bin/ed is assigned to it.
The construct works similarly, except that the second command gets executed only if the
exit status of the first is nonzero. So if you write
`grep "$name" phonebook || echo "Couldn't find $name in phonebook, or if it can't open the file phonebook"`. In this case, the equivalent if command
would like

```bash
if grep "$name" phonebook
then
:
else
echo "Couldn't find $name"
fi
```

You can use a complex sequence of commands on either or both the left- or right-hand side of these constructs. If the exit status tested is that of the last command in the pipeline; thus

```
who | grep "$name" > /dev/null | echo "$name's not logged on"
```

causes execution of the echo if the grep fails

The && || can also be used on the same command line:

```
who | grep "$name" > /dev/null && echo "$name's not logged on" \
|| echo "$name is logged on"
```

(Recall that when echo is used at the end of the line it uses line continuation to the shell.
The first echo gets executed if the grep succeeds, the second fails if not)

These constructs are also often used in commands, as demonstrated in this snippet for a system program (don't worry if you don't understand every command invoked):

```bash
if validates "$sys" $timeok
then
  sendmail "$user@$sys" < $message
fi
```

If validates returns an exit status of zero, timeok is executed and its exit status is tested for it. If the status is zero, then sendmail is executed. If validates returns a nonzero status, however, timeok is not executed, and the failed exit status is tested by the if, and sendmail ends up not being executed.

The use of the && operator in the preceding case is a logical AND; both programs must return an exit status of zero for the sendmail program to be executed. In fact, you could have the above above if some conditional

```bash
validates "$sys" $timeok && sendmail "$user@$sys" < $message
```

By comparison, the || is used in an if, the exit status is a logical OR:

```bash
if endmonth || specialrequest
then
  sendreports
fi
```

If endmonth returns an exit status, sendreports is executed; otherwise specialrequest is executed and if its exit status is zero, sendreports is executed. The net effect is that sendreports is executed if either endmonth or specialrequest returns an exit status of zero.

# 'Round and 'Round She Goes

In this chapter, you'll learn how to set up program loops. These loops will enable you to execute a set of commands either a specified number of times or until a specific end condition is met.

The three built-in looping commands for shell programming are:

- for
- while
- until

You'll learn about each one of these loops in separate sections of this chapter.

# The for Command

The for command is used to execute one or more commands a specified number of times. Its basic format is as shown:

```bash
for var in word_1, word_2, ... word_n
do
  command
  command
  ...
done
```

The commands enclosed between the do and the done are what's known as the body of the loop and are executed for as many items as listed after the in. When the loop is executed, the first word, word_i, is assigned to the variable var, and the body of the loop is then executed. Next, the second word in the list, word_j, is assigned to var, and the body of the loop is executed again.
