The first tests checks to see whether the -mailopt option was specified. If it was, mailopt is assigned the value TRUE, shift is executed to "shift out" the first argument (moving the name of the user to be monitored to $1 and decrementing $#). If the -m option wasn't specified, mailopt is set to FALSE.

Execution proceeds as in the previous version, except time the main block of code completes, the mailopt variable is tested to determine whether to output the notification via email or an echo statement.
