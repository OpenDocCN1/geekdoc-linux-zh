If you want to run lu, rem, or add standalone, you can do it provided that you first define PHONEBOOK and export it:

```
$ PHONEBOOK=$HOME/phonebook
$ export PHONEBOOK
$ lu Harmon
I couldn't find Harmon in the phone book
$
```

If you do intend to run these programs standalone, you'd better put checks in the individual programs to ensure that PHONEBOOK is set to the correct value.
