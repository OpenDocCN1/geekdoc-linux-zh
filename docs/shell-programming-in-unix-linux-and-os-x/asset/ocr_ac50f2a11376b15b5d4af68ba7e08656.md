# Chapter 7 Decisions, Decisions

The word value is successively compared against the values pattern, pattern, ..., pattern, until a match is found. When a match is found, the commands listed after the matching value are executed, up to the double semicolons, which serve as a “break” statement that shows you've finished specifying commands for that particular conditional. After the double semicolon are reached, the execution of the case is terminated. If a match is not found, none of the commands are executed.

As an example of the use of the case statement, the following program called number takes a single digit and translates it to its English equivalent:

```
$ cat number
#
# Translate a digit to English
#
if [ "$# -ne 1 ]
then
  echo "Usage: number digit"
  exit 1
fi

case "$1"
in
  0) echo zero;
  1) echo one;
  2) echo two;
  3) echo three;
  4) echo four;
  5) echo five;
  6) echo six;
  7) echo seven;
  8) echo eight;
  9) echo nine;
esac $
```

Now to test it:

```
$ number 0
zero
$ number 3
tree
$ number
Usage: number digit
$ number 17
$
```
