This invocation is a specific instance of a global search and replace in ed (and, also in vi): s/old/new/. In this case, we add a range of 1,$ beforehand and the g flag is appended to ensure that multiple substitutions will occur on each line, as appropriate.

A few special cases of this special construct are worth noting. If only one number is enclosed by braces, as in

```
\{10}
```

that number specifies the preceding regular expression must be matched exactly that many times.

```
\[a-zA-Z\]\{7}
```

matches exactly seven alphabetic characters; and

```
\{10}
```

matches exactly 10 characters no matter what they are:

```
$ ed intro
248
1,\$\^/\\{10}\\\ Delete the first 10 chars from each line
1,$p
```
