# Command Summary

# The unset Command

General Format: *unset names*

This causes the shell to erase definitions of the variables or functions listed in names. Read-only variables cannot be unset. The -v option to unset specifies that a variable name follows, whereas the -f option specifies a function name. If neither option is used, it is assumed that variable name(s) follow.

Example

```
unset dblist files    Remove definitions of variables dblist files
```

# The until Command

General Format:

```
until command;
do
    command
    command
..
```

done

command, is executed and its exit status tested. If it is nonzero, it is executed enclosed between the do and done are executed. Then command, is executed again and its status tested. If it is nonzero, the commands between the do and done are once executed. Execution of command, and subsequent execution of the commands between the do and done continues until command, returns a zero exit status, at which point the loop is terminated. Execution then continues with the command that follows the done.

Because command, gets evaluated immediately on entry into the loop, the commands between the do and done may never be executed if the test returns a zero exit the first time.

Example

```
# sleep for 60 seconds until jack logs on
until while | grep jack > /dev/null
do
    sleep 60
done
```

echo jack has logged in

The preceding loop continues until the grep returns a zero exit status (that is, finds jack in who's output). At that point, the loop is terminated, and the echo command that follows is executed.
