# The alias Command

An alias is a shorthand notation provided by the shell to allow command customization. The shell keeps a list of aliases that is searched when a command is entered before any other substitution occurs. If the first word of a command line is an alias, it is replaced by the text of the alias.

An alias is defined using the alias command. The format is

```
alias name=string
```

where name is the name of the alias, and string is any string of characters. For example,
alias ls='ls -l'
assigns ls -l to the alias 11. When the command 11 is entered by the user, the shell replaces it with ls -l. Even better, you can type arguments after the alias name the command line, as in

```
11 *.c
```

which transforms into this alias substitution has performed:

```
ls -l *.c
```

The shell performs its normal command-processing when the alias is set and it is used, so quoting can be tricky. For example, recall the shell keeps track of your current working directory inside a variable called PWD:

```
$ cd /users/steve/letters
$ echo $PWD
/users/steve/letters
$
```

You can create an alias dir that gives you the name of your current working directory by using the PWD variable and one of the parameter substitution constructs:

```
alias dir="echo ${PWD#*/}"
```

This seems reasonable, but let's see how this works in practice:

| $ alias dir="echo ${PWD#*/}" | Define alias |
| $ pwd | Where are we? |
| /users/steve | Execute alias |
| $ dir | |
| steve | |
| $ cd letters | Change directory |
| $ dir | Execute the alias |
| steve | |
| $ cd /usr/spool | One more try |
| $ dir | |
| steve | |
| $ |
