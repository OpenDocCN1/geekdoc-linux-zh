You can save yourself some typing by placing this command sequence into a file—let's call it run—making it executable, and then just typing the name run whenever you want to run a new copy of the proposal:

```
$ cat run
tbl sys.caps | nroff -mmTlp | lp
$ chmod +x run
$ run
```

(The request id message in the example is from the lp command.) For the next example, suppose that you want to write a shell command stats that prints the date and time, the number of users logged in, and your current working directory. The three command sequences you need to get this information are date, who | wc -1, and pwd:

```
$ cat stats
date
who | wc -1
pwd
```

```
$ stats
Wed Jul 10 11:55:02 EDT 2002
13
/users/steve/documents/proposals
$
```

You can add some echo commands to stats to make the output a bit more informative:

```
$ cat stats
echo The current date and time is:
date
echo The number of users on the system:
who | wc -1
echo Echo Your working directory is:
pwd
```

```
$ stats
The current date and time is:
Wed Jul 10 12:00:27 EDT 2002
```
