## The -d and -f Options

The cut command with its -c flag is useful when you need to extract data from a file or command, provided that the file or command has a fixed format.

For example, you could use cut with the who command because you know that the usernames are always displayed in character positions 1–8, the terminal in 10–16, and the login time in 18–29. Unfortunately, not all data will be so well organized!

For instance, take a look at the /etc/passwd file:

```
$ cat /etc/passwd
root:0:0:The User:/usr/bin/ksh
cron*:1:1:Cron Daemon for periodic tasks:
bin*:3:3:The owner of system files:
uucp*:5:5:/usr/sbin:/usr/lib/uucp/uucico
asg*:6:6:The Owner of Assignable Devices:
steve*:20:100:/users/steve:/usr/bin/ksh
other*:4:4:Needed by secure program:
```

$ is the master file that contains the usernames of all users on your system. It also contains other information such as user ID, home directory, and the name of the program to start up when particular user logs in.

Quite clearly, the data in this file does not line up anywhere as neatly as the who’s output does. Extracting a list of all users from your system can be done using the -c option to cut.

Upon inspection of the file, it’s clear that fields are separated by a character. Each field may not be the same length from one line to the next, so you can "count columns" to get the same field from each line.

The -d and -f options are used with cut when you have data that is delimited by a particular character, with -d specifying the field delimiter and -f the fields you want to extract. The invocation of the cut command becomes

```
cut -dchar -fields file
```

where char is the character that delimits each field of the data, and fields specifies the fields to be extracted from file. Fields start at 1, and the same type of formats are used to specify field numbers as used to specify character positions (for example, -f1,2,8, -f1-3, -f-4).

To extract the name of all users from /etc/passwd, you could use the following:

```
$ cut -d -f1 /etc/passwd
Extract field 1
root
cron
bin
uucp
asg
steve
other
$
```

Given that the home directory of each user is in field 6, you can match up each user of the system with their home directory:

```
$ cut -d -f1,6 /etc/passwd
root:
cron:
bin:
uucp:/usr/spool/uucp
as:
steve:/users/steve
other:
$
```

Extract fields 1 and 6

If the cut command is used to extract fields from a file and the -d option is not supplied, cut uses the tab character as the default field delimiter.

The following depicts a common pitfall when using the cut command. Suppose that you have a file called phonebook that has the following contents:

```
$ cat phonebook
Alice Cheeba 733-555-2015
Barbara Swingle 201-555-9257
Jeff Goldberg 201-555-3378
Liz Stachiw 212-555-2298
Susan Goldberg 201-555-7776
Tony Iannino 973-555-1295
$
```

If you want to get the name of the people in your phone book, your first impulse would be to use cut as shown:

```
$ cut -c1-15 phonebook
Alice Cheeba 97
Barbara Swingle 2
Jeff Goldberg
Liz Stachiw 212
Susan Goldberg
Tony Iannino 97
$
```

Not what you want! This happened because the name is separated from the phone number by a tab character, not a set of spaces. As far as cut is concerned, counts can be a single character when using the -c option. Therefore cut extracts the first 15 characters from each line, producing the results shown.

In a situation where the fields are separated by tabs, you should use the -f option to cut instead:

```
$ cut -f1 phonebook
Alice Cheba
Barbara Swingle
Jeff Goldberg
Liz Stachiw
Susan Goldino
Tony Iannino
$
```

Recall that you don't have to specify the delimiter character with the -d option because cut defaults to a tab character delimiter.

How do you know in advance whether fields are delimited by blanks or tabs? One way is by trial and error, as shown previously. Another way is to type the command `sed -n 1 file` at your terminal. If a tab character separates the fields, \t will be displayed instead of the tab:

```
$ sed -n 1 phonebook
Alice Cheba\t973-555-2015
Barbara Swingle\t201-555-9257
Jeff Goldberg\t201-555-3378
Liz Stachiw\t212-555-2298
Susan Goldberg\t201-555-7776
Tony Iannino\t973-555-1295
$
```

The output verifies that each name is separated from each phone number by a tab character. The stream editor sed is covered in more detail later in this chapter.

## paste

The paste command is the inverse of cut: Instead of breaking lines apart, it puts them together. The general format of the paste command is

```
paste files
```

where corresponding lines from each of the specified files are "pasted" or merged together into single lines that are written to standard output. The dash character - can also be used in the files sequence to specify that input is from standard input.

Suppose that you have a list of names in a file called names:

```
$ cat names
Tony
Emanuel
Lucy
Ralph
Fred
```

Suppose that you also have a second file called numbers that contains numbers for each name:

```
$ cat numbers
307-555-5356
212-555-3456
212-555-9959
212-555-7741
212-555-0040
```

You can use paste to print the names and numbers side-by-side:

```
$ paste names numbers
Tony	307-555-5356
Emanuel	212-555-3456
Lucy	212-555-9959
Ralph	212-555-7741
Fred	212-555-0040
$
```

If you want the output fields separated by a colon, you can use the -d option:

```
$ paste -d: names numbers
Tony:307-555-5356
Emanuel:212-555-3456
Lucy:212-555-9959
Ralph:212-555-7741
Fred:212-555-0040
$
```

If there are more files than characters listed, paste "wraps around" the list of characters and starts again at the beginning. For example, if you have three files a, b, and c:

```
$ cat a
1
2
3
$ cat b
4
5
6
$ cat c
7
8
9
```

Then:

```
$ paste -d,: a b c
1,4,7
2,5,8
3,6,9
$
```

## The -s Option

The -s option tells paste to paste together lines from the same file, not alternate files. If just one file is specified, the effect is to merge all the lines from the file together, separated by tabs, or by the delimiter characters with the -d option.

```
$ paste -s names
Tony Emanuel Lucy Ralph Fred
$ ls paste -d' ' - s Paste's output, use space as delimiter
addresses in lotspaces names phonebook
$
```

In the former example, the output from ls is piped to paste which merges the lines (-s option) from standard input (-), separating each field with a space (-d' option). You'll recall from Chapter 1 that the command `echo *` would also have listed all the files in the current directory, perhaps slightly less complicated than ls | paste.

## The -d Option

If you don't want the output fields separated by tabs, you can use the -d option to specify the delimiter. In the simplest form of the -d option, specifying a single delimiter causes that character to be used to separate all fields:

```
$ paste -d'+ names numbers
Tony307-555-5356
Emanuel212-555-3456
Lucy212-555-9959
Ralph212-555-7741
Fred212-555-0040
$
```

## sed

sed is a program for editing data in a pipe or command sequence. It stands for stream editor. Unlike ed, sed cannot be used interactively, though its commands are similar. The general form of the sed command is

```
sed command file
```
