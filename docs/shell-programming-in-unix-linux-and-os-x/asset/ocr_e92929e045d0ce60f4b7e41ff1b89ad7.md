# Chapter 14 Interactive and Nonstandard Shell Features

When you type in the r command, the Korn shell redirects the previous command and then immediately executes it.

If you give the r name of a command as an argument, the Korn shell re-executes the most recent command from your history begins with the specified pattern:

```
$ cat docs/planA
$ pwd
/users/steve
$ r cat  Rerun last cat command
cat docs/planA
$
```

Once again, the Korn shell redisplays the command line from its history before re-executing it.

The final form of the r command allows you to substitute the first occurrence of one string with the. To re-execute the last cat command on the file planB instead of planA you could type:

```
$ r cat planA=planB
cat docs/planB
...
$
```

or even more simply, you could have typed:

```
$ r cat AmB
cat docs/planB
...
$
```

Bash has a similar history shortcut command. !string lets you search your history and !! re-executes the previous command:

```
$ !!
cat docs/planB
...
$ id
date
Thu Oct 24 14:39:40 EST 2002
$
```

No spaces can occur between ! and string.

The fc command can be used with the -s option to do the same with any POSIX compliant shell (the r command is actually an alias to the fc command in the Korn shell—more on that later in this chapter):

```
$ fc -s cat
cat docs/planB
...
```
