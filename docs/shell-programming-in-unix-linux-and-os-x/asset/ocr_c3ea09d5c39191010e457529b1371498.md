# The case Command

The case command allows you to compare a single value against a set of other values or expressions to execute one or more commands when a match is found. The general format of this command is

```
case value in
    command
pattern,)
    command
    ..
    command;
pattern,)
    command
    ..
    command;
pattern_)
    command
    ..
    command;
esac
```
