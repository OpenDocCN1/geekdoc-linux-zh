# Chapter 1 A Quick Review of the Basics

The file directory documents contains the files plan, dact, sys.A, new.hire, no.JSK, and AMG.reply. The directory programs contains the files wb, collect, and mon. At some point, you may decide to further categorize the files in a directory. This can be done by creating subdirectories and placing each file into the appropriate subdirectory. For example, you might want to create subdirectories memos, proposals, and letters inside your documents directory, as shown in Figure 1.2.

documents contains the subdirectories memos, proposals, and letters. Each of these subdirectories in turn contain two files: memos contains plan and dact; proposals contain sys.A and new.hire; letters contain no.JSK and AMG.reply.

Although each file in a given directory must have a unique name, files contained in different directories do not. So you could have a file in your programs directory called dact, even though a file by that name also exists in the memos subdirectory.

Whenever you are "inside" a particular (called your current working directory), the files contained within that directory are immediately accessible, without specifying any path information. If you want to access a file from another directory, you can either issue a command to "change" to the appropriate directory and then access the particular file, or you can specify the particular file by its pathname.
