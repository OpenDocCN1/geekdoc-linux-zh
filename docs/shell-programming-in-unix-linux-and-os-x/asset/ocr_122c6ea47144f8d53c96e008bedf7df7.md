# Working with Directories

Look closely at the second column of the output: The number shown is 1 for collect and mon and 2 for wb and writeback. This is the number of links to a file, normally 1 for nonlinked, nondirectory files. Because wb and writeback are linked, however, this number is 2 for these files (or, more correctly, this file with two names).

You can remove either of the linked files at any time, and the other will not be removed:

```
$ rm writeback
$ ls -l
total 4
-rwwxr-xr-x 1 pat DP3725 358 Jun 25 13:31 collect
-rwwxr-xr-x 1 pat DP3725 1219 Jun 25 13:31 mon
-rwwxr-xr-x 1 pat DP3725  89 Jun 25 23:30 wb
$ 
```

Note that the number of links on wb went 2 to 1 because one of its links was removed.

Most often, ln is used to make a file to appear in more than one directory simultaneously. For example, suppose that pat wanted to access to steve's wb program. Instead of making a copy for himself (subject to the same sync problems described previously) or including steve's programs in his PATH (which has security risks described in Chapter 10, "Your Environment"), can simply link the file from his own directory:

```
$ pwd
/users/pat/bin    pat's program directory
$ ls -l
total 4
-rwwxr-xr-x 1 pat DP3822 1358 Jan 15 11:01 lcat
-rwwxr-xr-x 1 pat DP3822 504 Apr 21 18:30 xtr
$ ln -1 /users/steve/wb    link wb to pat's bin
$ ls -l
total 5
```

```
-rwwxr-xr-x 1 pat DP3822 1358 Jan 15 11:01 lcat
-rwwxr-xr-x 1 pat DP3725  89 Jun 25 23:30 wb
-rwwxr-xr-x 1 pat DP3822 504 Apr 21 18:30 xtr
$
```

Note that steve is total listed as the owner of wb, even when viewing the contents of pat's directory. This makes sense, because there's really one copy of the file and it's owned by steve.

The only stipulation on linking files is for ordinary links the files to be linked together must reside on the same file system. If they don't, you'll get an error ln when you try to link them. (To delete the file systems on your system, execute the df command. The first field on each line of output is the name of a file.)

To create links on different file systems (or on different networked systems), you can use the -s option to the ln command. This creates a symbolic link. Symbolic links behave like regular links, except that the symbolic link points to the original file; if the original file is removed, the symbolic link no longer works.
