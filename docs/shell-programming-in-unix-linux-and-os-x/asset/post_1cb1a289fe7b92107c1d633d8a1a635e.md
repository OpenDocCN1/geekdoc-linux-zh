## Parentheses

You can use parentheses in a test expression to alter the order of evaluation as needed; just make sure that the parentheses themselves are quoted because they have a special meaning to the shell. So to translate the later expression into a test command, you would write

```
[ "$count" -ge 0 -a "$count" -lt 10 ]
```

As is typical, spaces must surround the parentheses because test expects to see every element in the conditional statement as a separate argument.

## The Logical OR Operator -O

The -o operator is similar to the -a operator, it only forms a logical OR of two expressions. That, evaluation of the expression will be true either the first expression is true or the second expression is true or both expressions are true.

```
[ -n "mailopt" -o -r $HOME/mailfile ]
```

This command will be true if the variable mailopt is not null or the file $HOME/mailfile is readable by you.

The -o operator has lower precedence than the -a operator, meaning that the expression

```
"$a" -eq 0 -o "$b" -eq 2 -a "$c" -eq 10
```

gets evaluated by test

```
"$a" -eq 0 -o "$b" -eq 2 -a "$c" -eq 10
```

Naturally, you can use parentheses to change this order if necessary:

```
( "$a" -eq 0 -o "$b" -eq 2 -a "$c" -eq 10 )
```

Since precedence is critically important in complex conditional statements, you'll find a lot of shell programmers have nested if statements to side-step issues, while others use explicit parentheses to clarify order of interpretation. Just assuming things are interpreted left-to-right is dangerous!

You will see many uses of the test command throughout the book because it's almost impossible to write even shell programs without some sort of conditional statements involved. Table A.11 in Appendix A summarizes all available test operators.

## The else Construct

A construct known as else can be added to the if command, with the general format as shown:

```
if command
then
    command
    command
    ..
else
    command
    command
    ..
```

In the above, command, is executed and its exit status evaluated. If it's true (zero), the then code block (all the statements between then and else) is executed and the else block is ignored.
If the exit status is false (non-zero), the then code block is ignored and the else code block (everything else and fi) is executed. In either case, only one set of commands gets executed: the first set if the exit status is executed, and the second set if it's nonzero.

This can be more succinctly expressed:

```
if condition then statements-if-true else statements-if-false fi
```

Let's know a modified version of on. Instead of having no output if the requested user is not logged on, we'll have the program report that fact to the user.

Here is version 3 of the program:

then

If the user specified as the first argument to on is logged on, the grep will succeed and the message user is logged on will be displayed; otherwise, the message user is not logged on will be displayed.

## The exit Command

A built-in shell command exit enables you to immediately terminate shell program. The general format of this command is

```
exit n
```

where n is the status you returned. If none is specified, the exit status is that of the last command executed. Be advised that executing the exit command directly from your terminal will log off the system.
