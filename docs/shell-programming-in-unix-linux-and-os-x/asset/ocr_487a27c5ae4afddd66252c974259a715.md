You can fix this problem by enclosing $1 inside double quotes in the lu program:

$ cat lu

# A Program to Add Someone to the Phone Book

Let's continue with the development of programs that work with the phonebook file. You'll probably want to add someone to the file at some point, particularly because our phonebook file is small, so let's write a program add that takes two arguments: the name of the person to be added and their phone number.

The add program simply amends the name and number, separated by a tab character, onto the end of the phonebook file:

```
$ cat add
# Add someone to the phone book
#
```

```
echo "$2" >> phonebook
$
```

Although you can't tell, there's a tab character that separates the $1 from the $2 in the preceding echo command. This tab must be quoted to make it to echo without getting gobbled by the shell.

Let's try out our program:

```
$ add 'Stromboli Pizza' 973-555-9478
$ lu Pizza
Stromboli Pizza 973-555-9478
```
