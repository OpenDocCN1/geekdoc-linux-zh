```
$ prargs 'a b' c
a b
c
$ prargs *
addresses
intro
lotspaces
names
nu
numbers
phonebook
stat
$ prargs      No arguments
$
```

While the number of arguments is not equal to zero, the value of $1 is displayed and then a shift is invoked to shift variables (that is, $2 to $1, $3 to $2, and so on) and also decrement $#. When the argument has displayed and shifted, $# will equal zero, at which point execution of the while will be terminated.

Note that if no arguments are given to prargs (as was in the last case), the echo and shift are never executed because $# is equal to zero as soon as the loop is entered.

# # The until Command

The while command continues as long as the test expression continues to return a TRUE (zero) exit status. The until command is the opposite: it executing the code block until the test returns a nonzero exit status and stops once a zero status is produced.

Here is the general format of the until:

```
until command_
do
  command
  command
  ...
```

Like the while, the commands between the do and done might never be executed if command, returns a zero status the first time it's executed.

While the two commands are similar, the until command is useful for writing programs that wait for a particular event to occur. For example, suppose that you want to see whether sandy is logged on because you have something to utter. You could send electronic mail, but you know that she usually doesn't get around to reading her mail until late in the day. You could use the on program from Chapter 7 to see whether sandy's logged on:

```
$ sandy is not logged on
$
```
