We could expand on this to consider hyphenated and contracted words (for example, don't), but we'll leave that as an exercise for you. As a point to, if you want to match a dash character inside a bracketed choice of characters, you must put the dash immediately after the left bracket (after the inversion character ^ if present) or immediately before the right bracket for it to be properly understood. That is, either of these expressions

```
[0-9]
```

```
[0-9-]
```

matches a single dash or digit character.

In a similar fashion, if you want to match a right bracket, it must appear after the opening left bracket (and after the ^ if present). So

```
[ a-z]
```

matches a right bracket or a lowercase letter.

# Matching a Precise Number of Subpatterns: \{\{...\}

In the preceding examples, you saw how to use the asterisk to specify that one or more occurrences of the preceding regular expression are to be matched. For instance, the regular expression

```
xx*
```

matches an x followed by zero or more subsequent occurrences of the letter x. Similarly,

```
xxx*
```

matches at two consecutive x's.

Once you get to this point

```
\{min,max\}
```

where min specifies the minimum number of occurrences of the regular expression to be matched, and max specifies the maximum. Notice that you need to escape the curly brackets by preceding each with a backslash.

The regular expression

matches from one to 10 consecutive x's. Whenever there's a choice, the largest pattern is matched, so if the input text contains eight consecutive x's, that is many will be matched by the preceding regular expression.

As another example, the regular expression

```
[A-2a-z]\{4,7\}
```

matches a sequence of alphabetic letters from four to seven characters long.
