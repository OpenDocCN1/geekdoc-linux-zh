# A Quick Review of the Basics

This chapter provides a review of the Unix system, including the file system, basic commands, filename substitution, I/O redirection, and pipes.

## Some Basic Commands

### Displaying the Date and Time: The date Command

The date command tells the system to print the date and time:

```
$ date
Thu Dec 3 11:04:09 MST 2015
$
```

date prints the day of the week, month, day, time (24-hour clock, the system's time zone), and year. Throughout the code examples in this book, we use **boldface type like this**, *italic type like this*, and `monospaced type like this`.

## Finding Out Who's Logged In: The who Command

The `who` command can be used to get information about all users logged in:

```
$ who
pat     tty29 Jul 19 14:40
ruth    tty37 Jul 19 10:54
steve   tty25 Jul 19 15:52
$
```

The who command can also be used to get information about yourself:

```
$ who am i
pat     tty29 Jul 19 14:40
$
```

## Echoing Characters: The echo Command

The echo command prints (or echoes) at the terminal whatever you happen to type on the line (there are some exceptions to this that you'll learn later):

```
$ echo is a test
this is a test
$ echo why not print out a longer line with echo?
why not print out a longer line with echo?
$ echo
```

```
A blank line is displayed
$ echo one two three four five
one two three four five
$
```

You will notice from the preceding example that echo squeezes out blanks between words. That's because on a Unix system, the words are important while the blanks are there to separate the words.

# Working with Files

The Unix system recognizes only three types of files: ordinary files, directory files, and special files. An ordinary file is just that: any file on the system that contains data, text, program instructions, or just anything else. Directories, or folders, are described later in this chapter. Finally, as its name implies, a special file has a special meaning to the Unix system and is typically associated with some form of I/O.

A filename is composed of just any character directly available from the keyboard (and even some that aren't) provided that the total number of characters contained in the name is not greater than 255. If more than 255 characters are specified, the Unix system simply ignores the extra characters.
