listall program lists all entries in the phone book, printing the first and last fields of each entry. The internal field separator characters (IFS) is set to ^, to be used inside the loop. Each line from the file is read and assigned to the variable line. The set command assigns each field to the appropriate positional parameter as shown earlier.

The challenge is to get the value of the first and last positional parameters. The first is easy because it can be directly referenced as $1. To get the last one, the program taps the power of eval as explained in Chapter 12. Specifically, the command

