# Executing a Loop in the Background

An entire loop can be sent to the background for execution simply by placing an ampersand
after after the done statement:

```
$ file in memo[1-4]
do
> run $file
> done & Send it to the background
[1] 9932
$
request id is laser1-85 (standard input)
request id is laser1-87 (standard input)
request id is laser1-88 (standard input)
request id is laser1-92 (standard input)
```

This—and subsequent examples—work because the shell loops as if they were
mini-programs of their own, whatever appears after block closing statements like done, fi
eac can have redirects, be put into background with the ampersand or even part of
a pipeline of commands.

# I/O Redirection on a Loop

You can perform I/O redirection on a loop. Input redirected into the loop applies to all
commands in the loop that read their data from standard input. Output redirected from the
loop to a file applies to all commands in the loop that write to standard output. And it happens
at the loop closing statement done:

```
$ for i in 1 2 3 4
do
> echo $i
> done > loopout Redirect loop's output to loopout
$ cat loopout
1
2
3
4
$
```
