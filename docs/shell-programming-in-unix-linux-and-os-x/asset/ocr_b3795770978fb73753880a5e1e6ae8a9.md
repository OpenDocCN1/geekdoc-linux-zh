# The exit Command

General Format: exit n

Execution of exit causes the shell program to be immediately terminated. The exit status of the program is the value of the integer n, if supplied. If n is not supplied, the exit status is that of the last command executed prior to exit.

An exit status of zero is used to indicate success, and non-zero to indicate failure (such as an error condition). This convention is used by the shell in evaluation of conditions for if, while, and until commands, with the && and || constructs.

Examples

```
who | grep $user > /dev/null
exit
exit 1
if finduser
then...
Exit with status of last grep
Exit with status of 1
If finduser returns an exit status of zero then...
```

fi

Note that executing exit directly from a login shell has the effect of logging you off.

# The export Command

General Format: export variables

The export command tells the shell that the indicated variables are to be marked as exported; that is, their values are to be passed down to subshells.

Examples

```
export PATH PS1
export dbhome xl yi date
```

Variables may be set when using the form

```
export variable=value...
```

So lines such as

```
PATH=$PATH:$HOME/bin; export PATH
CDPATH=$.:HOME:/usr/local/uucpublic; export CDPATH
```

can be rewritten

```
export PATH=$PATH:$HOME/bin CDPATH=$HOME:/usr/local/uucpublic
```

The output of export with a -p argument is a list of the exported variables and their values in the form

```
export variable=value
```
