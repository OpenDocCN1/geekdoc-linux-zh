# More on Commands

# Typing More Than One Command on a Line

You can type more than one command on a line that you separate them with a semicolon. For example, you can find the current time and your current working directory by typing in the date and pwd commands on the same line:

```
$ date; pwd
Sat Jul 20 14:43:25 EDT 2002
/users/pat/bin
$
```

You can string out as many commands as you want on the line, as long as each command is delimited by a semicolon.

# Sending a Command to the Background

Normally, you type in a command and wait for the results of the command to be displayed. For all the examples you have seen so far, this waiting time is typically short—a fraction of a second.

Sometimes, however, you may have to run commands that require a few minutes or longer to complete. In those cases, you will have to wait for the command to finish executing before you proceed, *execute the command in the background*.

It turns out that your Unix or Linux systems seem like it's focused completely on what you're doing, all systems are actually multitasking, running multiple commands simultaneously at any time. If you're on an Ubuntu system, it might have the window manager, a clock, a status monitor and your terminal window running simultaneously. You too run multiple commands simultaneously from the command line. That's the idea of putting a command "into background," letting you work on other tasks while it completes.

The not convention for pushing a command or command sequence into background is to append the ampersand character &. This means that the command will no longer tie up your terminal, and you can proceed with other work. The *standard output* of the command will be directed to your terminal, though in most cases the *standard input* will be dissociated from your terminal. If the command tries to read from standard input, it will stop and wait for you to bring it to the foreground (we'll discuss this in more detail in Chapter 14, "Interactive and Nonstandard Shell Features")

Here's an example:

+   $ sort bigdata > &  Send the command to the background
[1] 1258 Process id
$ date  Your terminal is immediately available to do other work
Sat Jul 20 14:45:09 EDT 2002
$
