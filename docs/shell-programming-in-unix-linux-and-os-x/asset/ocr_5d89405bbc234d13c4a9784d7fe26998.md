# Removing a Directory: The rmdir Command

You can remove a directory with the rmdir command. Rather than let you accidentally remove or hundreds of files, however, rmdir won't let you unless the directory is completely empty of files and subdirectories.

To remove the directory /users/pat, can you use the following:

```
$ rmdir /users/pat
rmdir: pat: Directory not empty
$
```

Phew! That would have been a mistake! Instead, let you remove the misc directory that you created earlier:

```
$ rmdir /users/steve/misc
```

An alternative method for removing a directory and its contents, you can use the -r option to the rm command. The format is simple:

```
rm -r dir
```

where dir is the name of the directory that you want to remove. rm removes the indicated directory and all files (including directories) in it, so be careful with your powerhouse command.
