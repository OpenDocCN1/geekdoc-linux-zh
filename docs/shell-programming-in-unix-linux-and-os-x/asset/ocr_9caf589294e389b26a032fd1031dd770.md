# The $$ Variable and Temporary Files

If or more people on your system use the rolo program at the same time, a potential problem may occur. Look at the rem program and see whether you can spot it. The problem occurs with the temporary file /tmp/phonebook that is used to create a new version of the phone book file.

The specific statements in the rem program look like:

```
grep -v "$Name" phonebook > /tmp/phonebook
m /tmp/phonebook phonebook
```

But here's the problem: If more one person uses rolo at the same time to remove an entry, there's a chance that the phone book file can get messed up because the temporary file will be simultaneously used more than once. To be fair the chance of this happening is rather small, but it's non-zero and means it's a problem.
