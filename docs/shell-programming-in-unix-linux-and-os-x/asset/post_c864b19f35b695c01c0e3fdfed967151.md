## The -v Option

Sometimes you're interested in finding the lines that contain a specified pattern, but those don't. That's what the -v option does for grep: reverse the logic of the matching task. In the example, grep is used to find all the lines in intro that don't contain the pattern UNIX.

```
$ grep -v 'UNIX' intro
Print all lines that do not contain UNIX
Thompson and Dennis Ritchie at Bell Laboratories
in the late 1960s. One of the primary goals in
environment that promoted efficient program
development.
$
```

## The -l Option

At times, you may not want to see the actual lines that match a pattern but just seek the names of the files that contain the pattern. For example, you have a set of C programs in your current directory (by convention, filenames end with the suffix .c), and you want to know which variable a called Move_history. Here is one way of finding the answer:

```
$ grep 'Move_history' *c
Find Move_history in C source files
exec.c:MOVE cpmove(&Move_history[200] = {0});nexec.c:cpmove(&Move_history[Number_half_moves -1],
exec.c:undo_move(&Move_history[Number_half_moves-1],);
exec.c:cpymove(&last_move, &Move_history[Number_half_moves]);
exec.c:convert_move(&Move_history[Number_half_moves-1]),
exec.c:convert_move(&Move_history[i-1]),
exec.c: convert_move(&Move_history[Number_half_moves-1]),
makemove.c:IMPORT Move Move_history[];
makemove.c:     if ( Move_history[j].from != BOOK (i,j,from) OR
makemove.c:         Move_history[j] .to = BOOK (i,j,to)
testch.c:GLOBAL Move_history[100] = {0};
testch.c:     Move_history[Number_half_moves-1].from = move_from;
testch.c:     Move_history[Number_half_moves-1].to = move_to;
$
```

Sifting through the producing output, and you get indeed that three files—exec.c, makemove.c, and testch.c—use the variable.

Add the -l option to grep and you get instead list of files that contains the specified pattern, matching the lines from the files:

```
$ grep -l 'Move_history' *.c
exec.c
makemove.c
testch.c
$
```

Because grep -l conveniently lists the files one per line, you can pipe the output from grep -l into wc to count the number of files that contain a particular pattern:

```
$ grep -l 'Move_history' *.c | wc -l
3
$
```

The preceding command shows precisely three C program reference the variable Move_history. Now, just to make you're paying attention, what are you counting if you use grep without -l option and pipe the output to wc?

## -n Option

If the -n option is used with grep, each line from the file that matches the specified pattern is preceded by its corresponding line number. From previous examples, you saw the file testch.c was one of the three files that referenced the variable; the following shows how you can pinpoint the lines in file reference the variable:

```
$ grep -n 'Move_history' testch.c      Precede with line numbers
13:GLOBAL Move_history[100] = {0};
197:     Move_history[Number_half_moves-1].from = move_from;
198:     Move_history[Number_half_moves-1].to = move_to;
$
```

As you can see, Move_history is used on lines 193, 197, and 198 in testch.c. For Unix experts, grep is one of the most used programs because of its flexibility and sophistication with pattern matching. It's worth studying.

## sort

At its most basic, the `sort` command is really easy to understand: give it lines of input and it'll sort them alphabetically, with the result appearing as output:

```
$ sort names
Charlie
Emanuel
Lucy
Ralph
Tony
$
```

By default, sort takes each line of specified input and sorts it into ascending order. Special characters are sorted according to internal encoding. For example, space is represented internally as the number 32, and the double quote as the number 34. This means that the former would be sorted before the latter. Particularly for other languages and locales the sorting order can vary, although you are assured sort will perform on alphanumeric input, the ordering is not what you might expect. sort has many options that provide more flexibility in performing your sort. We'll just describe a few of options here:

## -u Option

The -u option tells sort to eliminate duplicate lines from output:

```
$ sort -u names
Charlie
Emanuel
Lucy
Ralph
Tony
$
```

Here you see that the duplicate line Tony was eliminated from the output. A lot of old-school Unix people accomplish the same thing by using separate program uniq, so if you read shell scripts you'll often see sequences like sort | uniq. Those can be replaced with sort -u!

## -r Option

Use the -r option to reverse the order of sort:

```
$ sort -r names
Tony
Ralph
Lucy
Emanuel
Charlie
$
```

## -o Option

By default, sort writes the sorted data to standard output. To have it go into a file, you can use redirection:

```
$ sort names > sorted_names
$
```

Alternatively, you can use the -o option to specify the output file. Simply list the name of the output right after -o:

```
$ sort names -o sorted_names
$
```

This sorts names and writes the results to sorted_names. What's the value of -o option? Frequently, you want to sort the names in a file and have the sorted data replace the original. But typing
```
$ sort names > names
```
ends up wiping out the names! However, with the -o option, it is okay to specify the same name for the output as the input file:

```
$ cat names -o names
$ cat names
Charlie
Emanuel
Lucy
Ralph
Tony
$
```

> Tip Be careful if your filter or process is going to replace your input file and make sure that it is all working as you expect prior to having the data overwritten. Unix is good at lot of things, but there is no command to recover lost data or files.

## -n Option

Suppose that you have a file containing pairs of (x, y) data points as shown:

```
$ cat data
5 27
2 12
3 33
-5 11
15 6
14 -9
$
```

And suppose that you want to feed this data into a plotting program called plotdata, but the program requires that the incoming data pairs be sorted in increasing value of x (the first value on each line). The -n option to sort specifies that the first field on the line is to be considered a number, and the data is to be sorted arithmetically. Compare the output of sort used without -n option and then with it:

```
$ sort data
-5 11
14 -9
15 6
2 12
23 33
5 27
$ sort -n data
-5 11
2 12
3 33
5 27
14 -9
15 6
23 2
$
```

## Skipping Fields

If you had to sort your data file by the y value—that is the second number in each line—you could tell sort to start with the second field by using the option instead of -n. The -k says to skip the first field and start the sort analysis with the second field of each line. Similarly, -k5 would mean to start with the fifth field on each line and then sort the data numerically.

```
$ sort -k2n
14 -9
23 2
15 6
-5 11
2
5 27
3 33
$
```

Fields are delimited by space or tab characters by default. If a different delimiter is to be used, the -t option must be used.

## The -t Option

As mentioned, if you skip over fields, sort assumes that the fields are delimited by space or tab characters. The -t option can indicate otherwise. In this case, the character that follows the -t is taken as the delimiter character.
