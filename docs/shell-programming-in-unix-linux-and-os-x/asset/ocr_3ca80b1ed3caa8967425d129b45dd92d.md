# The read Command 197

echo '

Would you like to:

+   1. Look up
2. Add someone to the phone book
3. Remove someone from the phone book

Please select one of the above (1-3): \c'

```
#
# Read and process selection
#
read choice
echo

case "$choice"
in
  1) echo "Enter name to look up: \c"
    read name
    lu "$name"
    validchoice=TRUE;
  2) echo "Enter name to be added: \c"
    read name
    echo "Enter number: \c"
    read number
    add "$name" "$number"
    validchoice=TRUE;
  3) echo "Enter name to be removed: \c"
    read name
    rem "$name"
    validchoice=TRUE;
  *) echo "Bad choice";
done
$
```

If $# is non-zero, lu is called directly with the arguments typed on the command line, then the program exits. Otherwise, the loop is executed until the validchoice is non-null. Remember that the only way it will be assigned a value is if the command
validchoice=TRUE

is executed inside the case of either choice 1, 2, or 3. Otherwise, the program continues to
loop.
