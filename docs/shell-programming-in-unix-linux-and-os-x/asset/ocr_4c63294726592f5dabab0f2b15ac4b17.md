# Tilde Substitution

If a word on the command line begins with the tilde ~ character, the shell performs the follow-
instutions: If the tilde is the only character in the word or if the character following
tilde is a slash /, the value of the HOME variable is substituted:

```
$ echo
/users/pat
$ grep Korn ~/shell/chapter9/ksh
```
