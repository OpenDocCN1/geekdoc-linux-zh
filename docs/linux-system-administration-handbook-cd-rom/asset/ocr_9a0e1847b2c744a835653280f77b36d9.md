# 6.3 Configuring the Printer

Linux uses the BSD style of printing. That is, there is a /etc/printcap file that has to be modified, and the commands are lpr, lpq, lpc, lprm, and so on. I prefer the BSD method, as it makes adding printers and modifying the printer setups very easy. Plus, most magic filters assume you have a BSD-style printcap. Here's a copy of the printcap for a HP LaserJet 4L connected to the parallel port on RedHat 4:

```
lp:
  :sd=/var/spool/lpd/lp:
  :mx#0:
  :lp=/dev/lp1:
  :if=/var/spool/lpd/lp/filter:
  :sh:
```

RedHat has its own filters installed. These filters will pretty much handle ASCII and PostScript into a format your printer can handle. In the case of the HP printer, this is PCL. To print other formats directly from the command line (lp), youll need a magic filter to convert GIF to PS (for example) which then gets sent to the printer.

This printentry is really all one line. You can tell because in the Linux world, a line that ends in \is is automatically added to the next line. Each printentry is one line, but that line can be extremely long. The first line (the lp:) defined the name of the printer. You can add alias names for the printer by adding <alias> to the name definition. Once the name is given, the options can be put in any order. Here are what the options mean:

+   - sd—Spool directory. This is where the files have to be sent to the printer. This is usually /var/spool/lpd/<printername>.
- mx—You can set a maximum file size that can be sent to the printer. The #0 means that there is no maximum file size. The default maximum is 1000 blocks, which equates to just 1 Mb.
- lp—The device name for output. The /dev/lp1 specifies a parallel printer, but you also use a serial device if you wish.
- if—Input filter. Any file going to the printer piped to this command before being put in the queue. This is where the RedHat Print Manager comes and does its work. This is where other magic filters get installed as well.
- sh—Suppress printing of burst pages. Burst pages list the user, the name of the file being printed, and the job number along with other
