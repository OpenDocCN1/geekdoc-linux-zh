# 8
Internet
Agencies

If you're on the Internet, you'll probably have to deal with one of these groups sooner or later.

Even though the Internet appears to be an anarchy, there is a sense of order to it. Various agencies have been set up to give a bit of order to this apparent chaos.

Even if you get your connection via an ISP, you still have things that require outside assistance, like registering your domain and tracking crackers if one should happen to attack your site. How do you keep up with security issues?
