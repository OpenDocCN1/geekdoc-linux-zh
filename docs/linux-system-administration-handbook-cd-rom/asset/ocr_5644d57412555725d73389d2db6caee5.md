# AppleTalk

# Applesaring Your Printer

Making a printer available to your AppleTalk clients is very simple.
The netatalk printer daemon, papd, should be starting automatically when the rest of the atalk daemons start. You need to add an entry to /usr/local/atalk/etc/papd.conf:

```
Denna laserprinter:\n:pr=lp:\n:mx#0:\n:lp=/dev/lpl:\n:if=/var/spool/lpd/lp/filter:\n:sh:
```

Depending on the version of netatalk you have, you may have to reboot the printer to be visible to your clients.

# Printing to a Remote Appletalk

It is also possible to print from your Linux box to a network AppleTalk printer. To do this, follow the instructions below.
Get your Appletalk zone using getzones:

```
/usr/local/atalk/bin/getzones
biology
chemistry
```

If you are not sure which your local zone, use the -m option for zones.
Next you need to determine the name of the printer. You can use nbplkup for:

```
/usr/local/atalk/bin/nbplkup :LaserWriter
galileo:LaserWriter
CANON GP200/215 PS:LaserWriter
LaserWriter 16/600 PS:LaserWriter
```

We gave nbplkup the argument “Laserwriter because we know we are looking for that type of printer. If the argument is left off, you will see everything in your zone.

Check the status of the printer you want to print:

```
/usr/local/atalk/bin/papstatus -p "LaserWriter 16/600 PS*\nstatus: idle
```
