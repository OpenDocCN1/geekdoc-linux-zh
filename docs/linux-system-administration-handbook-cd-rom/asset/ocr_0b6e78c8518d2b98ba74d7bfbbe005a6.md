**doit-file**: The action is performed, but a log entry is written to the speciied log file. If the word is “mail,” then the record is mailed to the
newsmaster. A null string is equivalent to /dev/null, and a pathname
that starts with a slash is taken as the absolute filename as the log.
If there is no prepended slash, then the directory is assumed to be the
log directory defined in the config.data file.

**drop**: The message is completely ignored.

**log**: A one-line notice is sent to the erlog defined in the config.data file.

**log-file**: A one-line notice is written to the “log” as described above in
the doit-file definition.

**mail**: No action is taken except to send mail to the newsmaster.

# 10.6 Newsfeeds

The article will also be fed to the newsfeeds file to determine if it should
sent off-site or run through any local channel feeds. We sends out to
another machine so that the articles posted by users reach the outside world,
you must edit the $INSRC/site/newsfeeds file and add an entry for the
feeding machine. The newsfeeds file leads the newsmaster fine-tune
news will be sent out to which sites and has the potential to be very complex,
be sure to read the man page if anything fancy is being done with one of
t sites. Briefly, each entry in the newsfeeds file has four column-separated
fields: two of the fields may have optional subfields, marked off by a slash.
Fields or subfields that take multiple parameters should be separated by a
comma. Multiple lines may be used to define a site, but each line except the
last must have a “/ continuation character at the end.

The format of each entry is as follows:

```
sitename[/exclude, exclude, ...]
:pattern,pattern...[/(distrib,distrib...]
:flag, flag...
:param
```

send articles to but can also just be a generic unique to the newsfeeds
file. If any of the strings in the “exclude” parameter match a machine in the
