# 16.7 X APPLICATIONS

Depending on the music and the individual, it induces anything from mesmerization to motion sickness. It can be run in an X or full-screen VGA mode. Under X it can run in a window, the root window or as a screen saver. Finally, it can be used in a client/server mode.
