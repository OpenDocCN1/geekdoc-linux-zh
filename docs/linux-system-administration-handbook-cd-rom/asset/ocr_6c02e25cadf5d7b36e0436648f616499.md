# 2.6 System Shutdown

Shutting Linux down is somewhat easier than starting it, since all you need to do is kill off all the available processes and tell the kernel to either stop or reboot the system.

There are a few ways to shut the system down, depending on how and when you want it to happen. The fastest way is the following:

```
sync;sync; /sbin/halt
```

The three sync commands tell the system to sync up the hard drive cache and the hard drive itself. Anything that has to get written to the hard drive gets done at this time. Why three sync commands? There are varying reasons, but simplest one is that by the time the last sync is done, the buffers have had time to clear. Another idea is that the three sync commands make sure that all the buffers are cleared, the hard drive cache may have changed or may not have been completely flushed.

There are a few other methods of telling the machine to halt, including using kill -9 1 and telinit 0. In typical UNIX fashion, more than one command will work.

If you choose to reboot the system, you can replace halt with reboot 6.

All of the commands are for shutting the system right now. If you choose to have a planned shutdown and want to give users time to finish their work and log out in an orderly fashion, you'll want to use the shutdown command.
