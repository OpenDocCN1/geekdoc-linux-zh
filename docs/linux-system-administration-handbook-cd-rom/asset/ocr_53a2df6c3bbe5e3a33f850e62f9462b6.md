29 char Universal frame buffer
0 = /dev/fb00current First frame buffer
1 = /dev/fb00autodetect

16 = /dev/fblcurrent Second frame buffer

block Aztech/Okano/Wearnes CD-ROM
0 = /dev/aztcd Aztech CD-ROM

The universal frame buffer device is currently supported on Linux/68k. The "current" device accesses the fame buffer at current resolution; the "autodetect" at bootup (default) resolution.
Minor numbers 2-15 within each frame assignment are used for specific device-dependent resolutions.
There appears to be no standard naming for these devices.
