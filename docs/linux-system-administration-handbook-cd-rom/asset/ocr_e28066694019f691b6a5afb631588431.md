Table C-8 Creating and marking a swap partition
To create and mark the swap partition

+   a. Enter n (new).
b. Enter p to mark the partition you’re creating as a primary partition
c. Enter the partition number for the partition you’re creating.
d. Enter the cylinder number where you want the partition to start (usually the first one displayed in parentheses).
e. Enter the last cylinder number or the size you want the partition to be. Make this partition between 16 and 64 MB in size. For example, to make the partition 32 MB, enter this: +32M
f. Enter t (type), then enter the number of the partition you’re changing.
g. Enter 82 to mark the partition as type 82, Linux Swap.
