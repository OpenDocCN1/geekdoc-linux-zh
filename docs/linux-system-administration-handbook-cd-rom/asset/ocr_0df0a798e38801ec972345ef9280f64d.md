Some BIOSes will not recognize 64 MB of RAM in your system. Since Linux needs to tell how much memory is installed, systems with more than 64 MB of RAM will be incorrectly reported. The mem= option tells Linux to ignore the BIOS and know how much memory is there. You can use a hex address (mem=0x1000000 which is 16 MB), or use a number followed by k or M (16384k or 16M).

NOTE: If you lie here and tell Linux you have 128 MB when you really have only 64 MB, it will crash at some point. Also, due to paging and some BIOS settings, you may not have the full amount of memory accessible to your system. Check your BIOS or motherboard documentation for how much memory is used.

init specifies what program to boot as the init program. Normally, the kernel looks for /sbin/init, then /etc/init, then gives up and runs /bin/sh. This way, if the init program is corrupted, you can still get into the system.

When (if?) your kernel panics, it normally waits for the administrator to come by and physically press the power or reset switch. This option will allow the kernel to try and reboot 2 seconds after a panic. For example, a setting of panic=60 will have the kernel try and reboot 60 seconds after a panic.

LILO has the ability to change VGA video modes from the standard 80x24 to modes, such as 80x50 or 132x44. A setting of vga=ask provide a list of video modes and allow you to choose when it boots.
