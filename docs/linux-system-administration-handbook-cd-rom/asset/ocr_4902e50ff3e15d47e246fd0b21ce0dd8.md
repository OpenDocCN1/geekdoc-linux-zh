# 3.1 Adding Users

chgrp eng README

Then, set appropriate permissions on the file:

```
chmod 660 README
```

This particular chmod command gives read and write permissions to the owner (you) and anyone else in the eng group. No other users have access to this file.

The chmod command actually uses four octal numbers (0-8) to specify permissions:

| Ownership | User | Group | Others |
|---|---|---|--|\| 0—no setting | 0—no permissions | 0—no permissions | 0—no permissions |
| 1—save text image | 1—execute | 1- execute | 1—execute |
| 2—set GID | 2—write | 2—write | 2—write |
| 4—set UID | 4—read | 4—read |

The ownership settings are rather special, in that they give some extra functionality but are also security holes. The “save text image” means that once the program has finished running, it will save the text portion in memory to decrease the amount of time it takes the program to load later. This can quickly eat up memory if many programs have this, but if you use programs a lot, this may be helpful.

The set GID means that once the program runs, the group ID of the user to be that of the file. If a program is in the sales group and has its GID bit set, when I run that program, I will be in the sales group only within that program it is running. Some E-mail programs use the set GID to lock files in the /var/spool/mail directories. The user becomes part of the “mail” group while the E-mail program is running and can run to /var/mail.

The setUID is the same as setGID but works with user IDs instead. Some programs, like network sniffers, require the use of devices or functions that can run only by root. By setting ping to be UID root, everyday users can run the ping program. If you set a program to be set UID, be careful what you’re doing. If a program creates a new shell process, it will have the UID of the owner of the file. If the owner of the file is root, this can lead to common users getting root access very quickly. All the user would have to do start a shell, and the new shell will be running as root.
