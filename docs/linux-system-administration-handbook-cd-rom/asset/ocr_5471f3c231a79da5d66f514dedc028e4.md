# D.4 Linux Allocated Devices

13 char PC speaker

```
0 = /dev/pcmixer      Emulates /dev/mixer
1 = /dev/pcsp        Emulates /dev/dsp (8-bit)
4 = /dev/pcaudio      Emulates /dev/audio
5 = /dev/pcsp16      Emulates /dev/dsp (16-bit)
```

block 8-bit MFM/RLL/IDE controller

```
0 = /dev/vda          First XT disk whole disk
64 = /dev/vdb         Second XT disk whole disk
```

Partitions are handled in the same way as IDE devices (see major number 3).

16 char Sound card

```
0 = /dev/mixer        Mixer control
1 = /dev/midi          Audio sequencer
2 = /dev/midi100      First MIDI port
3 = /dev/dsp           Digital audio
4 = /dev/audio        Sun-compatible digital audio
6 = /dev/sndstat       Sound card status information
8 = /dev/sequencer2    Sequencer - alternate device
16 = /dev/mixer1      Second soundcard mixer control
17 = /dev/patmgr0      Sequencer patch manager
18 = /dev/midi101      Second MIDI port
19 = /dev/dsp1         Second soundcard Sun digital audio
20 = /dev/audiol       Second soundcard Sun digital audio
33 = /dev/patmgr1      Sequencer patch manager
34 = /dev/midi102      Third MIDI port
56 = /dev/midi103      Fourth MIDI port
```

block BIOS harddrive callback support

```
0 = /dev/dos_hda      First BIOS harddrive whole disk
64 = /dev/dos_dbb      Second BIOS harddrive whole disk
128 = /dev/dos_hdc     Third BIOS harddrive whole disk
192 = /dev/dos_hdd      Fourth BIOS harddrive whole disk
```

Partitions are handled in the same way as IDE devices (see major number 3).

15 char Joystick

```
0 = /dev/js0           First joystick
1 = /dev/js1           Second joystick
```

block Sony CDU-31A/CDU-333A CD-ROM

```
0 = /dev/sonycd       Sony CDU-31A CD-ROM
```

16 char Reserved for scanners

block GoldStar CD-ROM

```
0 = /dev/gscd         GoldStar CD-ROM
```

17 char Chase serial card
