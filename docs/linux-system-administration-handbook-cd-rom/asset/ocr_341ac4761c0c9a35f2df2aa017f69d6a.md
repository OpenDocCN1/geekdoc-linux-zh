# 2. booting and partitioning software from other OSes (e.g., DOS FDISK, OS/2 FDISK)

When you first the drive, there can be any number of strange, possibly nonsensical, partitions on it. Just delete them with the “d” command in fdisk so you can start with a clean slate.

To add a new partition, use the “n” command:

```
Command (m for help): n
Command action
e extended
p primary partition (1-4)
p
Partition number (1-4): 1
First cylinder (1-100): 1
Last cylinder or +size or +sizeM or +sizeK ([1]-100): +50M
```
