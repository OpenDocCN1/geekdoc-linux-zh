# Table C-10 Selecting a source to install from

| If you're installing from this source | Do this |
|---|---|
| CD-ROM | a. Choose “CD-ROM” and press enter. A list of CD-ROM types appears.<br>b. Press enter to choose the default device path; otherwise, choose one from the list.<br>c. Press enter to continue. |

Enter your IP address.<br>e. Enter the network mask.<br>f. Enter the broadcast address.<br>g. If you have a default router/gateway, choose “Yes” and press enter; otherwise, choose “No” and press enter.<br>h. If necessary, enter the default router/gateway.<br>i. Enter the NFS server's IP address.<br>j. Enter the exported directory on the NFS server where the installation data are. |
