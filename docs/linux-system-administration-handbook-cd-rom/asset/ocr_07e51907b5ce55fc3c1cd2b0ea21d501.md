# # Applications 12 for Linux

Linux can be more than just a server—there are a growing number of desktop applications.

This chapter is a survey of the more popular applications for Linux. These applications run the gamut from integrated office suites to symbolic math programs to emulators for running software from other operating systems.

# 12.1 Office Products, Word Processors, and Editors

In this category fall office suites, stand-alone word processors and spreadsheets, editors, and publishing tools.
