# Mapedit

Mapedit is an image map editing program from Boutell.Com, Inc. It can create client-side and server-side image maps. It supports GIF, JPEG, and PNG image formats. It is very easy to use; even Windows users tend to find it easier to use than similar tools for Windows 3.1 or 95. More information can be found at http://www.boutell.com/mapedit.
