# rc.news

After installing INN, create a script that checks the consistency of the last
INN shutdown and then starts the news server back up and performs any
other needed cleanup. This is usually accomplished by calling the script pro-
vided in $INNSRC/samples/rc.news from an /etc/rc2.d/ file or by run-
ing it from /etc/rc2 directly. The rc.news script will read all of the
variables from the INN configuration, set the flags that it will pass to
instart, and check to see if the server was not shut down cleanly.

It will also ensure that if an expire was being run, the newsmaster will be
ified or carries on with the old article removal, as well as verifying
t existing of the active and history files. After it ensures that everything is in a
stable state, it starts the server and a process called “innwatch” to monitor
the machine.

# innwatch

The innwatch program monitors the load average, disk space usage, and
number of used modes on the partitions for news use. The innwatch
program can be customized for site-specific parameters by modifying the
“innwatch.ctl” file located in $INNSRC/site/.

# innd

As described above, rc.news starts the main process, innd, which is the
actual daemon that listens for and handles all incoming connections on port
119.

When started, the innd reads the active, newsfeeds, and hosts.nnpt
files into memory and then opens a socket on port 119 and starts logging article-
cle to the history file and connections to the set of files speci-\ied in the /etc/syslog.conf file.
