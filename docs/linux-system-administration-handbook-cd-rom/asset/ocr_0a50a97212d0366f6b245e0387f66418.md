The Network Extensible Spreadsheet is made by X Engineering Software Systems (http://www.xess.com/). NExS is a fully featured spreadsheet with nearly 250 built-in functions, sheet sizes up to 32,767 rows x 4,096 columns, importing and exporting of tab-separated data or other spreadsheet formats, and C API (see from 12–5).
