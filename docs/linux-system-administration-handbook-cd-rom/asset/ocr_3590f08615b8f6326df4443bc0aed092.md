In this case, the named.boot is doing all three things. The directory statement tells named that any reference to files is going to be in the /var/named directory. Next, it says that the cache file is going to be for all domains and is kept in the named.ca file. The three primary statements say that it is providing DNS information for hosts in the wayga.net and a-muse domains, and the information about those hosts is stored in named.wayga and named.a-muse, respectively. The third primary statement indicates that any reverse DNS requests are on the 127.0.0.0 network (also known as the loopback device) to be done looking at the named.local file.
