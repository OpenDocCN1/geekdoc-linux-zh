# B.3 Key Features of OpenLinux

OpenLinux is a distribution of Linux using the 2.0.29 kernel, the features inherent in Linux are also found in Caldera's OpenLinux. Here's a list of some of the key features found in OpenLinux.

+   - TCP/IP. Uses TCP/IP, the Internet protocol, for high-speed networking.

+   - Menu-based Tools. Installs and configures OpenLinux easily with menu-based tools.

+   - POSIX-based Environment. Uses a POSIX-based multi-user operating environment with complete Connectivity tools, traditional UNIX development environments, and a high-speed, preemptive multitasking architecture that takes full advantage of 32-bit microprocessors. (Caldera includes both ELF and a.out binary formats).

+   - Unlimited Users. Sets up an unrestricted number of user accounts on each Caldera operating system for use on a single computer system.
