# Chapter 10 • NetNews

+   * innd: ME cant renumber ... lo too wide
This error occurs when articles in the news spool have article IDs larger than what will fit in the active file ID field. To fix this, you must shut down the news server and edit the active file by hand, adding another leading zero to the high watermark numbers for each group. To do this safely, do the following:

```
clinnnd throttle 'repairing the active file'
perl -lane 'split';printf "%s ..10d %10d %s\n", @F' active
> active.new
mv active active.old
mv active.new
clinnnd reload "fixed active file"
clinnnd go "repairing the active file'
```

# Non-Fatal Errors When INN is Running

+   * cant read Connection reset by peer
This means that the client closed the NNRP connection ungracefully and usually does not indicate a problem.

+   * Expire had removing articles
Something went wrong when expire tried to remove old articles. To find what happened, take a look in the expire.log in the news log directory. Expires will also report this error if it finds no new articles to remove, depending on the expire times, this message may crop up the first few days that a news server is brought on-line.

+   * Can't replace history files, cross-device link
Expire reports this problem when it runs out of space trying to create two copies of the history file. The news machine should have enough to keep up to three copies of the history file on disk at all times. If the partition that the history file is kept is not big enough for this, you can expire in a different directory by specifying the expdir=<directory> as an argument to news.daily.

+   * Group not matched (removed)?<groupname>—Using default expiration
This merely indicates that the newsgroup <groupname> was removed from the server and it is using the default expiration to remove articles from the spool. These messages should disappear once the default expiration date for the last article has been reached.
