# 3.1 MySQL and mSQL

mysqlql: A GUI for MySQL

An X-based interface to the MySQL client, mysqlql, exists and is available from the MySQL home page. It requires the xforms uwm library for compilation. xforms can be found at http://bragg.phys.uwemu.edu/xforms. It allows the user to choose tables and columns by pointing and clicking, doing a good part of the query building on its own. Of course its likely that the user will have to enter some in the WHERE clause.
