## D Allocated Devices

Maintained by Peter Anvin <anvin@linux.org>. Last visited: May 29, 1995. This is the successor to Rick Miller's Linux List which stopped maintaining network access in 1993. It is a registry of allocated major numbers, as well as the recommended nodes for these devices. This list is available via ftp.yggdrasil.com in the directory /pub/device-list; where format is ASCII (txt), LaTeX, or PostScript. In cases of discrepancy, the LaTeX version has priority. This document is included by reference to the Linux Filesystem (FSSTND). The FSSTND is available via FTP from tsx-11.edu in the directory /pub/linux/docs/fssnd/. To have a major number, or a minor number in situations that applies (e.g. bus), please contact me. Also, if you have additional information regarding any of the devices listed below, I would like to know. Allocations marked (68k) apply to Linux/68k.

Unnamed devices:
- 0 = /dev/loop0 (loopback device)
- loopback devices (NFS mounts)
- 0 = /dev/null (reserved device)
- 1 = /dev/mem (physical memory)
- 2 = /dev/kmem (virtual memory)
- 3 = /dev/null
- 4 = /dev/I/O port
- 5 = /dev/zero (source)
- 6 = /dev/core (replaced by /proc/core)
- 7 = /dev/full

To specify format, add to the autodetect number:
- 0 = /dev/fd0 First disk
- 1 = /dev/fd1 Second disk
- 2 = /dev/fd2 Third disk
- 3 = /dev/fd3 Fourth disk
- 4 = /dev/fd4 Fifth disk (360K)
- 5 = /dev/fd5 First logical partition
- 6 = /dev/fd6 Second logical partition
- 7 = /dev/fd7 Third logical partition
- 63 = /dev/fd63 59th logical partition

For partitions, add to the whole disk device number:
- 0 = /dev/hd0 Whole disk
- 1 = /dev/hd1 First primary partition
- 2 = /dev/hd2 Second primary partition
- 3 = /dev/hd3 Third primary partition
- 4 = /dev/hd4 Fourth primary partition
- 5 = /dev/hd5 First logical partition
- 6 = /dev/hd6 Second logical partition
- 7 = /dev/hd7 Third logical partition
- 63 = /dev/hd63 59th logical partition
