# Executor

ARDI (http://www.ardi.com/) makes a Macintosh emulator for Linux and a number of other platforms. A free, crippled demo is available. The list of completely and mostly usable software is quite long.

There is also an upcoming NEXTSTEP emulation version. Finally, students and educators can get discounts.

Executor is available in a fairly crippled demo version. It is just enough to let what is possible with it.
