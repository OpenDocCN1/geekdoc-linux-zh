# ### Creating Install and Modules Diskettes

If you don't have a bootable CD-ROM, you will need diskettes to install OpenLinux. You can use the Caldera CD-ROM to create these diskettes.

+   1. Insert the Caldera CD-ROM.
2. To create an Install diskette, use this table:

# ### Table C-3 Creating an Install diskette

| To copy the files from DOS/Windows | To copy the files from Linux |
|---|---|n| Insert a blank 3-1/2" diskette. | Insert a blank 3-1/2" diskette. |
| Access this file on your CD-ROM: /COL/LAUNCH/FLOPPY/WRITE3.COM | Mount your CD-ROM drive. |
| Enter drive letter and this file: /COL/LAUNCH/FLOPPY/INSTALL.IMG (for example, D:/COL/LAUNCH/FLOPPY/INSTALL.img) | Access the directory you mounted the CD-ROM to. |
| Enter the drive letter for the floppy diskette. | From a command line, enter dd if=/col/launch/floppy/install.img of=/dev/fd0. |
