# 10.2 Setup, Obtaining, and Unpacking INN

The first step to installing a news server is to format all the partitions that will be used and mount them. Next, create the news user and news group or verify that they already exist. The news user and news group should own all directories that the INN software resides in for a secure installation. The news user should have a locked password and the home directory where-ever news binaries will be installed.

Verify that PGP is installed, or see the chapter on security for instructions on PGP installation and, make a PGP key for the news user so that may do secure control message authentication. Also, if the news machine has an FTP daemon, make sure that the news user is in the /etc/ftpusers file no ftp access is allowed.

Once that's set, confirm that you're using the source code for the latest version of INN. The Slack news package comes with the Reference Implementation of NNTP as well as INN. However, if you select "INN" for installation, it does not remove the NNTP entry in the /etc/inetd.conf and must be removed manually. It's generally safer to install the INN implementation that comes with the Linux distribution and to obtain the latest INN version, 1.6 at the time of this writing, from ISC'S Web at http://www.isc.com/inn.html. Also retrieve any patches released for the same version of INN. Once the partitions are set up and the INN distribution are downloaded, move everything to the news source directory, such as /usr/local/src/inn. Become the news user (su news) to unpack and press the source archive by doing the following:

```
$su news
(make sure the path is set correctly)
>tar xf inn-1.5sec3.tar.gz
>cd inn-1.5sec3
>ls -a
```

This is the source tree for the INN distribution, which contains several Makefiles, README instructional files, and directories broken down into the following topics:

+   **frontends:** Programs that control the central server and feed articles to **innd:** The NNTP server itself

+   **backends:** Programs to transmit articles to other sites

+   **expire:** Programs to purge article files and databases
**nnpd:** The NNTP server for client readers
