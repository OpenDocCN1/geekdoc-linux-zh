# 5.6 Summary

Now edit /var/yp/securenets and /etc/ypserv.conf. They are well commented and fairly self-explanatory. If you need more information, read the ypserv(8) and ypserv.conf(5) man pages.

Then start the portmapper if needed and then start ypserv. Verify that it is running:

```
[root:/home/cary]# rpcinfo -u localhost ypserv
program 100004 version 1 ready and waiting
```

Now run ypinit to generate the maps in /var/yp from the files in /etc:

```
ypinit -m
```

If you are setting up a slave server, run

```
ypinit -s master
```

And you're done!
