The following are the components that are freely distributable:

+   * Linux operating system kernel
* The utilities accompanying the Linux operating system

Though you can freely change and redistribute these programs, you should review the license agreements to find out about any exclusions. For example, some freely available software can't be redistributed without writ-ten permission from the copyright owner.
