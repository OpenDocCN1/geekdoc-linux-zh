# 6.7 Summary

+   - disable { all|printer }—Disable the named printer. New jobs cannot be added, but printing will continue.
- down { all|printer }—Disable the named printer completely. No new jobs can be added, and printing stops.
- enable { all|printer }—New jobs can be added to the queue (reverse of disabled)
- restart { all|printer }—Try to restart a print daemon. The lpd process will die or get stuck, and this will try to restart a new daemon.
- status { all|printer }—Get a status of the printers. List whether or not queues are awake, whether printing is enabled.
- topq printer [job..]—Print the jobs listed at the top of the queue

The lpc man page has more on the commands available, but these get you started with the queue administration.

In the worst case scenario where the lpc commands do not work, you can use the /etc/rc.d/init.lpd.init stop command to stop the lpd program altogether. The /etc/rc.d/init.d/lpd.init command will start lpd up.

For more information or help on how the print services work, check out the Printing HOWTO and the Printing Usage HOWTO.
