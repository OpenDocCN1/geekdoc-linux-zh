# Chapter 23 • Connecting to the Internet

# Diald

Diald, written by Eric Schenk, is available from http://www.dna.lth.se/~erics/diald.html. Diald is a utility used to automatically connect your machine via a modem or ISDN to your ISP when external data is requested. It will also disconnect you when the connection has been idle for a specified period of time. If your PPP connection dies then diald will automatically try to reconnect. If you have a static IP and you are in the middle of downloading the latest Linux kernel, this feature can be a real stress reliever. Ever downloaded 10 M over a 28.8 and had the modem die on the last 5 percent?

Diald's only system requirements are that the kernel be compiled with SLIP enabled, and whatever connection protocol you are using is configured and working correctly (PPP in these examples). Diald uses SLIP to monitor the network traffic and if a non-local IP is requested, diald tells the modem to dial out and connect to your ISP.

Installation is as simple as obtaining the source code, unpacking it, performing a “make depend,” followed by “make,” and then “make install” at root. In the three versions I have installed on two different machines, I have never had an error message. After installing the latest version (at the time of writing, it was version 0.16), there are three files that you will need to check. The first is /usr/lib/diald/diald.defs. This file is a list of internal rules for diald and does not usually need to be touched. If you need to make any changes, refer to the dial man pages on the format of this file.

The second file to examine is /usr/lib/standard.filters. You may wish to copy this file to a different location and I suggest /etc/diald.conf. While leaving it in /usr/lib would work, I had some problems that were solved by moving it to /etc/diald.conf, the location of the config from previous versions of diald. This file is a list of services from /etc/services, and how many seconds that service will get of “up-time.” This doesn't mean that if you are telnetting somewhere dial will automatically kick you off of your typing. What it means is after so many seconds of idle dial, diald will shut the modem link down. The default file is very well documented and easy to understand.

The third and last file is a script to start diald. I suggest starting from it rc.local by adding the line “/etc/rc.d/diald” to the end of your /etc/rc.local file. You may even add the lines to your rc.local file, but it is more convenient to keep things separate so it can run as a stand-alone program. Notice that we are using the same chat file used in the PPP section, but we are not using the ppp-on program.
