# 23.2 Software Versions

The configurations in this chapter use Linux kernel 2.0.30, PPP 2.2.0f, dial 0.16, and ipfwadm if you are not planning to do IP masquerading, but still use dial, then kernel 1.2.X (X > 0), and PPP version 2.2.0x work fine. Dial is constantly undergoing changes, and from the version released over a year ago (0.14) to the current version, many improvements and enhancements have been made.

Links to the current version of the kernel, PPP, and ipfwadm can be found at http://www.linuxhq.com/.

# 23.3 Networking

The local network should be a private network and should not advertise its IP addresses beyond the firewall. RFC #1597 (Address Allocation for Private Internets) specifies the address blocks which are reserved for internal use only. While not necessary, using these blocks of addresses is suggested. You can alternatively use a class of addresses assigned to you by the InterNIC, if any mistakes happen, and one of your local networks IPs ends up outside the firewall, it will be ignored by the rest of the world as an invalid IP if it belongs to one of the following address blocks:

| ADDRESS RANGE | TYPE | # of machines |
| --- | --- | --- |
| 10.0.0.0 -> 10.255.255.255 | single class A | 1 x 16777214 |
| 172.16.0.0 -> 172.31.255.255 | class B | 16 x 65534 |
| 192.168.0.0 -> 192.168.255.255 | class C | 255 x 254 |
