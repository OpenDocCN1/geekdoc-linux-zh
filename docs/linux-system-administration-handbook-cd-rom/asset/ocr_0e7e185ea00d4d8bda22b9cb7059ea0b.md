# Web Serving 15

# Various Web servers and extensions for Linux.

How to install and configure Apache-derived Web servers under Linux as well as popular modules, extensions, and key configuration directives are explained and some examples of their use are given.

With the phenomenal rise in popularity of the World Wide Web (WWW), everyone wants a Web page, be it a small personal home page where you can pull out your soapbox or a large corporate Web site where a company can distribute information (everything from press releases to hardware driver updates to troubleshooting guides), market themselves, or sell their products on-line. Linux has proven itself to be a robust, high-performance Web server on everything from a 386 to a DEC Alpha. Still, with nearly any application, there are hardware and software issues to be considered.
