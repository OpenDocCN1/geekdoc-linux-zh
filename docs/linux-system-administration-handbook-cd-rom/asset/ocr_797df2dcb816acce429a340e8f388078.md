# MWM

![](bbox=[0.163, 0.142, 0.836, 0.526])

Figure 16–1 The Motif Window Manager

Motif is really a group of widgets that make for a common look and feel for programs. The Motif Window Manager (MWM) is one of the programs behind the Common Desktop Environment (CDE) which is trying to give a standard interface to all UNIX workstations. The downside to Motif is that it's commercial. The upside is that you don't need to purchase Motif to use programs that were built using it. Programs compiled using Motif libraries can be copied freely.

# FVWM

The Feeble (Fine?)—no one knows what the F stands for anymore) Virtual Window Manager (FVWM) is one of the most popular window managers around. The program itself is relatively small; it comes with a lot of features from virtual windows to menu buttons. You can also set it up so specific programs start only on a certain virtual window.
