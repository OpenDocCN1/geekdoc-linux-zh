# 7.5 Mailing Lists

Mailing lists allow larger groups of people to communicate via E-mail. In many cases, it is preferable to using USENET since

+   - Mailing lists do not need approval to be created.

Anyone with a machine connected to the Internet can create a mailing list on any subject. Getting members to subscribe to it is a different issue, ever.

+   - Mailing lists can control who subscribes.

The mailing list administrator can make it so that anyone can subscribe, or can make it so that the administrator is the only one who can add new members to the mailing list. The administrator can also remove offending members if a problem arises

+   - Mailing lists can control content.

This isn't as bad as it sounds, since it is the alternative to the anarchy that is USENET. The administrator can set the list up to be open and provide a healthy discussion area (such as for developers working on a piece of software) or can set the list up such that the administrator has to approve each piece of E-mail that gets into the list (like the moderated USENET groups). The moderated lists are good for news releases, humor lists, or any other list where the amount of discussion should be low.
