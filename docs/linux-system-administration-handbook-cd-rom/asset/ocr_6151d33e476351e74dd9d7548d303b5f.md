designed for laptops, which may not always be connected to a network. In POP, all the E-mail is downloaded at once, which is a bit of a problem for large messages over slow links. IMAP supports a mode where only portions of an E-mail (the headers) are downloaded. IMAP is also for more than just E-mail, since the protocol allows for transmission of other kinds of data, such as NetNews articles. Only a few programs (pine and Netscape) currently handle IMAP because the protocol is a bit newer than POP. A large list of available IMAP clients and servers is available at the IMAP Web site http://www.imap.org.
