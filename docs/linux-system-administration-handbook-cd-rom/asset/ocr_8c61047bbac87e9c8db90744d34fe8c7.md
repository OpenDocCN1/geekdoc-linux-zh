# D.4 Linux Allocated Devices

To have a major number allocated, or a minor number in situations where that applies (e.g. busmice), please contact me. Also, if you have additional information regarding any of the devices listed below, I would like to know. Allocations marked (68k) apply to Linux/68k.

+   0 Unnamed devices (NFS mounts, loopback devices)
  0 = reserved as null device number

+   1 char Memory devices
  1 = /dev/mem Physical memory access
  2 = /dev/kmem Kernel virtual memory access
  3 = /dev/null Null device
  4 = /dev/port I/O port access
  5 = /dev/zero Null byte source
  6 = /dev/core OBSOLETE - replaced by /proc/kcore
  7 = /dev/full Returns ENOSPC on write

+   RAM disk
  1 = /dev/randisk RAM

+   2 char Reserved for PTY's <ltytso@athena.mit.edu>

+   block FIFO disks
  0 = /dev/fd0 First disk autodetect
  1 = /dev/fd1 Second disk autodetect
  2 = /dev/fd2 Third disk autodetect
  3 = /dev/fd3 Fourth disk autodetect
