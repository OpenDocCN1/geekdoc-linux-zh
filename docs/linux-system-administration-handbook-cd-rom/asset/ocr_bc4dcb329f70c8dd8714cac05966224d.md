# When you use the “p” command to display the partition table, you see a
sequence of error messages:

| Device Boot | Begin | Start | End | Blocks | Id System |
|---|---|---|---|---|---|-|
| /dev/sda | | 1 | 754 | 771088+ | 6 | DOS 16-bit-32M |
| /dev/sdb | * | 97 | 1954 | 122892+ | 82 | Linux swap |
| /dev/s3 | | 1274 | 1954 | 2456 | 514080 | a5 | BSD/386 |
| /dev/s4 | | 2362 | 2456 | 4095 | 167872+ | | Extended |
| /dev/s5 | | 2362 | 2456 | 2707 | 257008+ | 83 | Linux |
| /dev/s6 | | 2394 | 2707 | 2770 | 64228+ | 83 | Linux native |
| /dev/s7 | | 2402 | 2770 | 3436 | 682731 | 6 | DOS 16-bit-32M |
| /dev/s8 | | 2487 | 3436 | 4095 | 674698+ | 6 | DOS 16-bit-32M |

Partition 1 does not end on cylinder boundary:
phys=(95, 254, 63) should be (95, 63, 32)
Partition 2 does not end on cylinder boundary:
phys=(248, 254, 63) should be (248, 63, 32)
Partition 3 does not end on cylinder boundary:
phys=(312, 254, 63) should be (312, 63, 32)
Partition 4 does not end on cylinder boundary:
phys=(521, 254, 63) should be (521, 63, 32) 

To correct these errors, new values must be entered by “fdisk” to the
partition boundaries match the values returned by the hard disk and control-
ler. In this example, the 4-GB hard disk shown has 64 heads, 32 sec-
tors, and 4095 cylinders, for a total capacity of 64*32*4095 bytes = 4095 MB. 

If you set the number of heads to 255, and number of sectors to 63 (a
hint that this value is correct in the error messages shown above), the
partition must still have 4095 MB. So if 255*63*cylinders = 4095 MB, then
the number of cylinders will be 522.

These new values must be entered into “fdisk.” First, you must change to the
expert mode with the “x” command; and then enter the new parameters for
the heads, sectors, and cylinders. In expert mode the commands “c” (cylin-
ders), “h” (heads), and “s” (sectors) can be used. Using the calculation
above, these values should be 255 heads and 63 sectors.

NOTE: If you are using DOS on your system, never enter a head count of
256. This value will cause DOS to crash without without.

Below is how the screen might look like as you enter the new values in
“fdisk.”

```
Expert command (m for help): h Number of heads (1-256): 255
Expert command (m for help): s Number of sectors (1-63): 63
Warning: Setting sector offset for DOS compatibility
Expert command (m for help): c Number of cylinders (1-65535): 822
```
