# ### Introduction

The Linux operating system is starting to get attention which will increase its popularity past what has been seen for the past few years. The explosive growth and need for Web servers, Internet servers, File and Print servers is sending more administrators to see a UNIX-like system that is relatively low cost compared to other solutions. About ten percent of the web today are running Linux as base. The Red Hat distribution of Linux was named InfoWorld's "Product of the Year" in 1996, and regularly has announcements and articles from contributors seeing the best of Linux.

Technical journals and magazines are becoming filled with advertisements and articles related to Linux development, administration, distributions, and use. SysAdmin magazine has recently had an issue dedicated to Linux.

The need for an in-depth book for system administrators is clear.
