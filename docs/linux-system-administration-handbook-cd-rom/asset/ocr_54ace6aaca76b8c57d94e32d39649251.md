You will need to add a line or lines similar to /etc/ftpaccess:

```
virtual 10.10.10.200 /ftp/ftp-virtualall/ /ftp/ftp-virtualall/etc/
banner.msg
```

The first argument to the virtual directive is the IP of the virtual host;
thecond is the root of the ftp area for that host; and the third is the location of
the file containing the welcome message.

# tftp

Trivial tftp is a very simplistic FTP service. It has no user validation and no
ability to change directories or to list the contents of the directories. It can
get or put files in binary or ASCII mode. That's it.

Some devices may require a tftp host for part of their booting pro-
cess, but in general, tftp is used fairly rarely and you will likely want to dis-
able it in /etc/services unless you need it.

# 11.5 FTP Clients

There are two types of ftp clients: those which support user-based FTP
dhose which support only anonymous FTP.

Today, probably the most common way to access anonymous FTP sites is
with a Web browser. These are typically the only clients that only support
anonymous FTP.

There are also a number of other FTP clients ranging from the simple
command line like the ftp program to full-screen clients like NcFTP to
graphical clients like XFTP.
