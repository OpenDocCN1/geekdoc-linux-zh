# KDE

In case you ever wanted the functionality that Windows 98 is supposed to
have without all the excess Microsoft baggage, there's KDE. The beta we're
using to write this section (Beta3) seems to be more stable and a magnifi-
ent for first-time users. Like Windows 98, many of the func-
tions of the desktop are integrated, with drag and drop capabilities, and there
a a heavy dependence on browsers. KDE comes with its own HTML
browser that, while not as full featured as something like Netscape, does the
quit quite well. The only drawback is that for applications to take full adv-
tage, they have to be written to work with KDE. However, there are a
number of applications already written in KDE from CD players to editors
games. More are being written and should quickly have enough components
to equal what Windows 98 took three years to develop. Another downside is
that some of the applications you expect to be connected to the Internet. For
example, the CD player (kscd) will talk to the CDDB database
cdbb.cdbb.com to get information about the CD you're playing. If you're not
connected to the Internet, this feature is somewhat wasted. However, if you
have a dial up connection, you can get the CD information and save it
locally so you'll have it next time.

The file manager (called KFM) allows for seamless use of FTP, HTTP,
tZIP Files as or Web pages are selected, they get opened and
displayed (or an appropriate application that can handle the file is started).
KDE is similar to CDE in that there is an application and virtual window
manager on the bottom of the screen. This can be configured to autohide,
much like the Windows95 taskbar. Each window in KDE has a thumbnail
attached to it to make that window "sticky" and show that window in each
virtual screen. This makes it handy for clocks or other applications to always
be seen. KDE also remembers what applications you were running last
t and starts them up the next time you start KDE. Much of the config-
ation, from virtual windows, autohiding, and background, autoraise of win-
dows, and so on, can be done in KDE itself all without restarting the
window manager. Unlike other window managers, KDE does not
require you to edit configuration files.

For the large numbers of applications and amount of configurability that
KDE gives, it's well worth the drive space, especially if you have fans of Win-
dows 95 who don't like the normal X interface. Their web page is http://
