It is also possible to override sections of the information in the passwd
map or add users that don't exist in the NIS at all. For example, to give
paul shell /bin/tcsh and change Rachel's home directory (and allow
only them access) and add a user surya, use entries like:

```
++:::
+paul::::/bin/tcsh
+rachel::::/local/home/rachel:
+*:/bin/false
surya:UGj6khgT:506:100:/home/surya:/bin/bash
```

Finally, you will need to set up the ypcient programs and set the NIS
domain name. It's likely that your distribution came with the NIS client (and
server) programs. If not, you should be able to get them from any Linux dis-
tistribution site.

Setting the NIS domainname is accomplished by running /bin/domain-
name nis. You will also need to make sure the portmap program is
running. Using the rpcinfo command for this:

```
[root:/home/cary]# rpcinfo -p localhost
program vers proto port
100000 2 tcp 111 portmapper
100000 2 udp 111 portmapper
```

If it's not in the list, run /usr/sbin/portmap, then /usr/sbin/ypbind.
rpcinfo should show something like

```
[root:/home/cary]# rpcinfo -p localhost
program vers proto port
100000 2 tcp 111 portmapper
100000 2 udp 111 portmapper
100007 2 udp 637 ybind
100007 2 tcp 639 ybind
```

At this point, your NIS client setup should be complete.
