# Gimp

The GNU Image Manipulation Program (http://www.XCF.Berkeley.EDU/~gimp/) is an image composition, authoring, and photo retouching tool. It is the closest thing to packages like Adobe Photoshop that are available for Linux.

It is very extensible and relies on an active user community to write plugins to extend GIMP’s functionality.

# Xfig

Xfig is a freeway drawing tool for X. It supports the drawing of interpolated lines, various polygons, grouping of objects, scaling, copying, and embedding text using PostScript fonts. It ships with most distributions of Linux.

# Xpaint

Xpaint is similar to xfig, but more oriented toward painting rather than drawing. It is free as well and ships with most Linux distributions.
