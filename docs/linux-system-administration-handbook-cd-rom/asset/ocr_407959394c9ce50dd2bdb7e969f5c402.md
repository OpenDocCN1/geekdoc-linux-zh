To tell Apache to parse .html files with the embedded PHP parser, add a line like this to your srm.conf:

```
AddType application/x-httpd-php .php
```

Start up your server. With the above setup, you would enter http -f /etc/httpd/conf/httpd.conf -d /home/http. Make or edit (if it already exists) an index.html in the document root. Somewhere in the document, add a line like <?php phpinfo(); ?>

The phpinfo function should spit out a few screenshots of CGI environment variables and configuration information. If it doesn't, check to make sure you added the correct line to your srm.conf or httpd.conf to tell Apache to parse .php or html files, make sure you have the right extension over your file and mod_php enabled in your Apache source Configuration file.
