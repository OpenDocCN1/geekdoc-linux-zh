# 系统要求

您的计算机系统必须满足以下要求才能安装 OpenLinux。

- 32 位 Intel 个人电脑或兼容设备，例如这些处理器：386、486、Pentium, Pentium Pro。此版本不支持其他处理器。
- 至少 8MB RAM（使用图形化组件需要 16MB RAM）
- 推荐安装需要 266MB 空闲硬盘空间（根据您选择的安装选项，需要的更多或更少的磁盘空间。）
- 支持的鼠标和显卡（用于图形化组件）。
