As you can guess, question 1 is the best, as it requires the least amount of effort on everyone's part.⁵ Here's a copy of a sample .procmailrc file:

```
PATH=/bin:/usr/bin:/bin
MAILDIR=$HOME/Mail  #you'd better make sure it exists
DEFAULT=$MAILDIR/mbox  #completely optional
LOGFILE=$MAILDIR/from  #recommended
```

:0

+   * ^From.*mark

from_me

:0

+   * ^Subject::.*Flame

/dev/null

There are three sections to matching a line and performing some action on it, also called recipes. A recipe starts with a line that has at a :0 starting. After the :0, you can include some flags (for example, H will scan only the headers). Pattern matching is done for lines that start with an *. The rest of the line is sent to egrep⁶ literally. If all of the lines match (the lines ANDed together) then the appropriate action is taken. If not, it moves to the next recipe.

There can be only one action line, and this is the one that does not start with an * or :. An action starting with ! will forward the program to the specified user. Anything else will be assumed to be a filename to append (or if it doesn't already exist).

These two examples show that all mail has a From line and ends in mark (which will be your E-mail sent by me) will be put in the ~/Mail/from mailbox. The second example shows that all E-mail that starts with the word “Subject” and ends in “Flame” will be sent to /dev/null (the bucket).

The thing to know if you want to delete mail out of hand is you have to be absolutely sure that your logic is correct. For, if you delete all mail that has the word “Flame” in it, then you can potentially lose messages with a subject such as “Flame broiled burgers free until 10 AM.”
