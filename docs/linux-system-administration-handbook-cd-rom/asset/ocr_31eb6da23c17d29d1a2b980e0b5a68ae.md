# Chapter 12 • Applications for Linux

# WordPerfect

Corel's WordPerfect 7 (and previous versions) has been ported to Linux by the Software Development Corporations (http://www.sdcorp.com/) and WordPerfect 8 should be ported soon. WordPerfect is probably the most feature-rich word processor available for Linux.

The downside of using WordPerfect is that the rest of Corel's office products have not been ported with it, so it does not have a nice, well-integrated office suite to interact with. That said, Corel itself is portant its entire office suite to Java. This course will let any machine with a Java virtual machine run it. For more information on Corel Office for Java, see http://www.corel.com/javastrast/index.htm.
