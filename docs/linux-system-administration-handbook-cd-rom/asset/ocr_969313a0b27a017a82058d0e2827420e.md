guage. Its popularity has given birth to large numbers of contributed exten-
sions (classes) and a great deal of support on the Net.

Java is different than the other languages here in that it is meant to be
completely platform-neutral. Java code is compiled into platform-indepen-
byte-code files that can be run on a virtual machine. Once a virtual
machine (VM) has been implemented on a machine, it will (in theory) run
any "pure" Java program or applet. Sun has a program for certifying applic-
tions as "100 percent Pure Java."

Java support can be compiled into the Linux kernel, allowing programs to
be executed directly from the command line. Applets can be invoked this way
as well, as long as Java support has been compiled directly into the
kernel and not as a loadable module by setting the execute bit on the HTML
file that references the applet class.

The feature that originally won Java much of its popularity is that the VM
could be implemented in a Web browser and applets could be executed in the
client VM served by a Web server. At first the applets were mainly
"ge whiz" things as simple animations or moving text, clocks, and sim-
ple like tic tac toe.

However, because of the enormous amount of contributed code and add-
tional tools such as Java DBC (Database Connectivity),
"real" applets (and applications) are much more easily realized.

Information on Java for Linux, including where to download the latest
develop's kit, can be found at the URL listed above. It should be noted that
a native (as opposed to running in the Solaris OS in emulation) Java Develop-
Kit (JDK) for Linux/SPARC is so also available.

APIs for interfacing Java to virtually everything imaginable exist. A search
through your favorite application's contributed software list will likely turn up
a Java API.

# Tcl/Tk

The Tool Command Language and Tk toolkit are the inventions of John
Osterhout. Tcl is both a scripting language and a C library. Tk is not a separa-
rate language but an extension to Tcl for interfacing with X; it is also available as
a C library. Tcl and Tk have been ported to MacOS and Windows, making
them a good choice for cross-platform application development. However,
interfaces for it exist for other languages as well, most notably the Tkinter
module for Python.
