# /etc/services

The /etc/services file contains information about a TCP/IP port number, and a name for the specified port which is later used in the /etc/inetd.conf file. It is not often that you'll need to add entries to this, but some programs may have you here. Here's a portion of /etc/services file:

```
chargen      19/tcp          ttytst source
chargen      19/udp          ttytst source
ftp-data      20/tcp
ftp           21/tcp
telnet        23/tcp
smtp          25/tcp          mail
time          37/tcp          timserver
time          37/udp          timserver
lrip           39/udp          resource        # resource location
name          42/udp          nameserver
whois         43/tcp          nickname       # usually to sri-nic
domain        53/tcp
domain        53/udp          # deprecated
mtp           57/tcp
bootps        67/udp          # bootp server
bootpc        68/udp          # bootp client
tftp           69/udp
gopher        70/tcp          # gopher server
```

The first entry in the line is the service name. This is followed by the number, and the protocol (usually TCP or UDP) and it is then followed by any aliases. As you can see above, the port E-mail calls is in called the smtp port and it is located on port 25. Its alias is mail, so I could run a command like:

```
[mark@wayga-$] telnet localhost smtp
Trying 127.0.0.1...
Connected to localhost.
Escape character is '^'
220 wayga.ratatosk.org SMTP Sendmail 8.8.5/8.8.5; Mon, 1 Sep 1997
18:54:30 -040
```

and that telnet command would connect me to TCP/IP port 25 (where send-mail is currently running).
