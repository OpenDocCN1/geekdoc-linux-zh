# 14.9 Other Languages

There are literally scores of programming languages, certainly more than we have space to cover in any detail here. Those languages described above are among the most popular on Linux and many other platforms, but many other bear mentioning as well.

Many readers have surely noticed we left out some old standbys.

# Oldies but Goodies

# FORTRAN

```
http://www.fortran.com/fortran/
```

FORTRAN is a venerable language designed mainly for numerical calculations. Its most common incarnation on Linux is in the form of g77, FORTRAN 77 compiler. The latest specification is FORTRAN 90, which is not common as FORTRAN 77. Few compilers for FORTRAN 90 exist and no free ones exist for Linux.

# BASIC

```
http://www.Uni-Mainz.DE/~ihm/basic.html
```

Not as old as FORTRAN, but still popular for its simplicity; Microsoft's Visual Basic and' played a large part in keeping it popular. It has had and continues to have many different incarnations both interpreted and compiled. Only recently has a BASIC compiler available for Linux.
