## 16.2 Setting Up X

Next is the monitor configuration section. This is where you need to know the horizontal sync range. There are nine predefined monitors you can choose from, and a tenth allows you to define your own range.

**WARNING:** Be sure that the numbers entered here are correct, because a wrong monitor and video card pair can damage your monitor, video card, or both. Don't say I didn't warn you.

Next is the vertical sync. Here you have a choice of about four monitor types, plus one to let you define your own. Once the vertical is set, you can enter information about your monitor. This section isn't necessary, as it allows XFree86 to use multiple monitors at the same time. You can either press enter and use the default for each, or enter a unique identifier for your monitor, along with a vendor name and model name.

Once this is completed, you set up the video card. It's important to select the correct video card because two video cards from the same vendor can have very hardware internally. Selecting the wrong card can damage your card or monitor.

Now you get to select the type of video to run. If you selected a video card that has an accelerator chip supported by XFree86, you'll be able to select that X server.

The options are as follows:

- 1. The XF86_Mono server, which is a 640x480 resolution with two colors, black and white. This should work for all VGA cards. If you suspect a problem with your video card or are unsure of the type of video card you have, this may be a good starting point.
- 2. XF86_VGA16 server, which is also 640x480, but with 16 colors. This should also work with all VGA-compatible cards.
- 3. XF86_SVGA server, which provides Super VGA (SVGA) resolutions with 256 colors. This is an accelerated server, so most ISA SVGA cards will probably work with it.
- 4. Accelerated server, which is for accelerated cards. This gives more than 256 colors for most servers, and higher resolutions. These servers also utilize any of the fastest chipsets in most modern video cards.
- 5. The server for the video card you selected earlier.

If you select 5, the best server for your card is set up for installation. Now you must get information about your video card. First you'll be asked about the amount of video memory on your card. You'll get five selections from 256K to 4096K (4 Mb) and a sixth selection that allows you to enter your own amount.

Once that is completed, you'll be allowed to enter a description for your video card similar to the monitor descriptions above. You can either enter through the entries, or type in the description, vendor, and model of your video card.

If you have an S3- or AGX-based video card, you may need to know the type of random access memory digital to analog converter (RAMDAC) the card has. The RAMDAC is used to get high color (greater than 32K colors) from the server. Enter the appropriate entry if you have those cards and know the RAMDAC type, or else you just press enter.

Some video cards also have a programmable clock. Some clocks are programmable, but if yours is (some Diamond cards and S3 cards are), enter the type of clockchip you have. It should be found in your owner's manual, or on the card itself. If you don't have a clockchip, just press enter.

At this point, the x86config program will attempt to find the clocks your card supports by using the X -probe command. This command doesn't start X itself, but asks the video card to return what clocks it knows about. These clocks are important to determine the correct resolutions you use.

Now you should be ready to start X. Doing this is simply getting to a command prompt and typing

```bash
> startx
```

This will start the X server in the lowest color depth and resolution you selected. If you configured your server to use 8-bit color (256 colors) and also for 16-bit (65K colors), just typing startxs will start the X server in 8-bit mode. To start it up in 16-bit mode, use the following:

```
> startx --bbpp 16
```

For the sake of extra memory, you may want to log out of other virtual consoles (VCs) before starting X, since you can start multiple shells (xterms) from within X. You can switch to a virtual console while in X by pressing CTRL-ALT-Fn where n is a number between 1 and 6. The first X usually uses virtual console 7. You can see what VC is being used when X starts up, or by going through the virtual consoles.
