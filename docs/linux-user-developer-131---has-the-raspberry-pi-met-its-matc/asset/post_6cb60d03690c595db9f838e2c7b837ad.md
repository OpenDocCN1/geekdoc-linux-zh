
## Tutorial: Make a Python Twitter client

Create your own app details by using the Twitter Developer account tools, either for personal use or for an app you intend to release. Access the entire dataset of Twitter via the Python wrapper, allowing you to grab timelines, lists and user profiles among others. Create your authentication keys for user and OAuth, letting you tap into the Twitter API. Write your own tweets in Python using the Twython module to access components from the Twitter API.

Learn the basics of the Twitter API using Python libraries and create a simple Twitter client to make and monitor tweets.

Python has many strengths, and one of them is the way you can use it to create lightweight desktop software and packages for the Internet of Things. One of the services used for this is Twitter, which has a few Python APIs you can make use of in a Python script to check and post the tweets from a specified user.

With this you can create a standard Twitter client in the command line, or make a UI for it with Tkinter (from previous issues of LUD). You can also specify the login details you'd normally ask for from a client and then use it to check for specific words on Twitter, retweets, messages received, or if a specific person is sending tweets.

For this tutorial we'll be using Twython, which provides a pure Twitter interface for Python, and show you how to get your own unique API key to use it with Twitter itself.

### 02 New beginnings
Go to 'My applications' and click 'Create a new application'. Here you'll need to enter the app's name, a short description and a website where more details about yourself and/or the app can be found. Names of apps are not allowed to use the word Twitter in them.

### 03 Privileges
After this has been created, you'll be brought to the details page of the app. Before we go any further, click on Settings and select Read, Write and Access Direct Messages under Application Type so that we can use it properly as a Twitter client.

### 04 Access token
We can now create an access token for the application to work with your Twitter account. Go back to the details once the read and write permissions have been changed, and scroll down to the bottom. Click 'Create my access token' to retrieve it.

### 05 Install Pip
We'll install the latest version of python-twitter from our website. To do this, first install pip, as we're using Python, available in repos as python-pip. As we're using Debian, this looks like:

```bash
sudo apt-get install python-pip
```

...which allows us to set up Python modules.

![](img/dd9251551a61a36067892b1cc68615b0_66_5.png)

### 06 Install Twython
Now that we have Pip installed, we can go ahead and install Twython. To do this, continue in your terminal and put:

```bash
sudo pip install twython
```

This will get the Twython module, and all the OAuth packages you need to log into your account with tokens we created.

![](img/dd9251551a61a36067892b1cc68615b0_66_6.png)

### 07 Authentication file
We need to create a Python file to hold all our authentication details. Start up IDLE, or a text editor of your choice, and start by importing Twython with:

```python
from twython import Twython
```

Make sure you have the keys we created earlier handy to add in the next parts. If the output is long, type it to go to the next screen.

![](img/dd9251551a61a36067892b1cc68615b0_66_7.png)

### 08 App keys
Add the following to your code:

```python
APP_KEY = 'YOUR_CONSUMER_KEY'
APP_SECRET = 'YOUR_CONSUMER_SECRET'
```

...replacing YOUR_APP_KEY and YOUR_APP_SECRET with your own consumer key and consumer secret respectively.

### 09 Access keys
Now we can add the access tokens that we created to the script with:

```python
OAUTH_TOKEN = 'YOUR_ACCESS_TOKEN'
OAUTH_TOKEN_SECRET = 'YOUR_ACCESS_TOKEN_SECRET'
```

…where again you’ll need to replace YOUR_ACCESS_TOKEN and YOUR_ACCESS_SECRET with the relevant numbers.

### 10 Verification
Now’s a good time to verify if what you’ve done so far actually works. Enter the following at the bottom of the script:

```python
twitter = Twython(APP_KEY, APP_SECRET, OAUTH_TOKEN, OAUTH_TOKEN_SECRET)
twitter.verify_credentials()
```

And run. If it doesn’t come up with any errors, it’s all working fine.

### 11 Test post
As it all seems to be working, you could try making a test post straight to Twitter. At the bottom of our code, enter:

```python
twitter.update_status(status="Test")
```

And then run it again. If it’s successful, there will be no errors and it will show up on your timeline.

### 12 Write a post
Let’s create a simple way to post tweets to your timeline via our script. We’ll use human input like so:

```python
post = raw_input("Write your tweet: ")
```

…which will store our tweet as a string in `post`.

To post this, we use the `update_status` bit from before, only now it uses the string from `post` to update our timeline. Add:

```python
twitter.update_status(status=post)
```

And then save the file. Run it, and test the code again.

### 13 Update
The complete script structure for writing posts looks like this:

```python
APP_KEY = 'YOUR_CONSUMER_KEY'
APP_SECRET = 'YOUR_CONSUMER_SECRET'
OAUTH_TOKEN = 'YOUR_ACCESS_TOKEN'
OAUTH_TOKEN_SECRET = 'YOUR_ACCESS_TOKEN_SECRET'

from twython import Twython
twitter = Twython(APP_KEY, APP_SECRET, OAUTH_TOKEN, OAUTH_TOKEN_SECRET)

post = raw_input("Write your tweet: ")
if twitter.update_status(status=post):
    print("Tweet sent!")
```

### 14 Timeline
To access the timeline of our account tweets, we use the following:

```python
twitter.get_user_timeline()
```

This accesses the past 20 posts our account has made. You can specify which timeline to check as well by adding the `screen_name` option:

```python
twitter.get_user_timeline(screen_name='username')
```

### 15 Full timeline
We can access the account’s full timeline by using the `get_home_timeline` function like so:

```python
twitter.get_home_timeline()
```

If you printed this out, it would display all the unfiltered data from the last 20 tweets on your timeline. You can modify the amount of tweets by adding the `count` parameter to the `get_home_timeline`.

```python
twitter.get_home_timeline(count = 5)
```

We’ll need to parse the data to make sure we get something coherent and recognisable as a timeline.

### 16 Search tweets
We can search Twitter for specific keywords using the following:

```python
twitter.search(q="linux")
```

This will return a mixed result of tweets relating to the word Linux. You can filter them with the `result_type` parameter, by setting it as mixed, recent or popular.

### 17 Follow
To follow someone on Twitter, we use the `create_friendship` function. We need either the screen name or numerical ID of the Twitter user you want to follow – you’ll most likely be using the screen name, so we’ll write it like so:

```python
twitter.create_friendship(screen_name = "LinuxUserMag")
```

### 18 Retweeting
As retweets are an integral part of Twitter, the function for this is simply `retweet`. We require the tweet ID for this, the numerical string used for each tweet and displayed in the URL for a tweet. We use it with:

```python
twitter.retweet(id = '12345')
```

### 19 Favouriting
This works very similar to retweets, using the unique ID for the tweet used in the URL to determine which tweet to favourite. The function for this is `create_favorite`, and is written as:

```python
twitter.create_favorite(id = '12345')
```

Make sure to use the American spelling (favourite) when doing this.

### 20 Retrieve favourites
All of a user’s favourites are stored by Twitter so that you can recover them at any time. You can either get your own, or specify a user to get the favourites from. The basic code is:

```python
twitter.get_favorites()
```

…which will get you your own favourites. As before, you can specify the user ID number or screen name with `user_id` and `screen_name` respectively to get a specific list.

### 21 Mentions
You can also access the list of mentions for your authenticated account. To do this, use the `get_mentions_timeline` function. This works like the other timelines, allowing you to limit the amount of posts you get from the selection. Limit it to five like before with:

```python
twitter.get_mentions_timeline(count='5')
```

### 22 Trending topics
Everyone knows what everyone else is talking about thanks to Twitter’s trending topics, whether it’s a young Canadian musician or important world events. You access the trends with:

```python
twitter.get_place_trends(id = '1')
```

An ID of 1 returns global trends. You can specify different IDs for different locales.

### 23 Retrieve list
If you prefer to use Twitter by curating lists of people, you can get the contents of any list using the `get_list_statuses` function:

```python
twitter.get_list_statuses(id = '12345')
```

Each list has a unique ID, or a slug, that you can use. You can also call members of any list, or anyone that subscribes to it.
