# 01 Installation

The first step is to get LyX installed on your system. Most distributors should have a package available. For your non-Linux friends, there are binaries available for Windows, Mac OS X, and even OS/2 and Haiku. As always, you can download the source code and build from scratch in the worst-case scenario.

![](bbox=[0.07, 0.44, 0.33, 0.54])

# 02 Opening a new document

When you first start up LyX, the main window opens up with a splash screen image displayed. You actually have to tell LyX that you want to start a new document before you can start writing. You can start a new document by clicking the menu item **File->New**.

![](bbox=[0.07, 0.67, 0.33, 0.81])

# 03 Setting the document class

Many of the layout properties for your document are set to defaults based on the class of your document. You can set this by clicking the menu item **Document->Settings**. This will pop up a dialog window that will use for the next few steps. The drop-down list will give you a very full list of possible document classes.

![](bbox=[0.37, 0.67, 0.65, 0.87])

# 04 Text layout

While the document class sets the defaults for your document, you still have full control to change anything in the document. The Text Layout option lets you change the indentation size to a custom increment. The vertical spacing and line spacing can also be customised. You also have the option to make your document two-column here.

# 05 Page layout

LaTeX figures out the actual rendering of your document based on a page layout. You can select one of a number of standard page formats, or set a custom page size. You can set whether the page is oriented as either portrait or landscape mode.

# 06 Numbering and the TOC

Documents are broken down into several nested subregions. How these regions are handled in the layout is decided by the document class. You can also set whether these regions are numbered or not, and whether they show up in the generated table of contents.

# 07 View source

Now that your document is set up, you can start typing. LyX gives you a pseudo-WYSIWYG view of the text. But LaTeX is a purely text-based markup language, so you can always see the actual source code to verify what LyX is putting into your document. To see the source, just click on the menu item **View->View Source**.
