
# Tutorial

## Browse privately with Onion Pi

### 09 Incoming Wi-Fi

We need to set up the Wi-Fi adaptor to be both static and accept incoming signals. First:

```bash
$ sudo nano /etc/network/interfaces
```

Put a # in front of iface wlan0 and following lines with wpa roam, iface default and any other affecting wlan0.

![](img/dd9251551a61a36067892b1cc68615b0_47_0.png)

### 10 Static IP

Now give the wireless interface a static IP – after the line allow-hotplug wlan0, enter the following:

```bash
iface wlan0 inet static

address 192.168.42.1
netmask 255.255.255.0
```

Save and exit, and then set wlan0's address with:

```bash
$ sudo ifconfig wlan0 192.168.42.1
```

![](img/dd9251551a61a36067892b1cc68615b0_47_1.png)

### 11 WLAN creation

We need to create a new file that holds all the information for our wireless network. We are going to make it password protected so that only the people we want to can access it. To create the file, start with:

```bash
$ sudo nano /etc/hostapd/hostapd.conf
```

And then enter the text from the next step.

![](img/dd9251551a61a36067892b1cc68615b0_47_2.png)

### 12 WLAN configuration

```ini
interface=wlan0
driver=rtl8171xdrv
ssid=[access point name]
hw_mode=g
channel=1
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpa_passphrase=[password]
wpa_key_mgmt=WPA-PSK
wpa_pairwise=TKIP
rsn_pairwise=CCMP
```

### 13 Hostapd

After saving and exiting, we need to edit hostapd to point it to this new file. Open it with:

```bash
$ sudo nano /etc/default/hostapd
```

And then find the line #DAEMON_CONF="". Remove the #, and change it to:

```ini
DAEMON_CONF="/etc/hostapd/hostapd.conf"
```

![](img/dd9251551a61a36067892b1cc68615b0_47_3.png)

### 14 Network addressing

Setting up a NAT will allow multiple clients to connect. To do this, run:

```bash
$ sudo nano /etc/sysctl.conf
```

And add to the bottom of the file:

```ini
net.ipv4.ip_forward=1
```

Save this, and then finish by running:

```bash
$ sudo sh -c "echo 1 > /proc/sys/net/ipv4/ip_forward"
```

![](img/dd9251551a61a36067892b1cc68615b0_47_4.png)

### 15 IP tables

Run the following three commands to make sure the internet connection is forwarded correctly:

```bash
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT
```

### 16 Apply configuration

So that this still works after a reboot, type:

```bash
$ sudo sh -c "iptables-save > /etc/iptables.ipv4.nat"
```

Then add to the end of /etc/network/interfaces:

```bash
up iptables-restore < /etc/iptables.ipv4.nat
```

![](img/dd9251551a61a36067892b1cc68615b0_47_5.png)

### 17 Wi-Fi final

Finally, set it up as a daemon so it runs at boot with the following commands:

```bash
$ sudo service hostapd start
$ sudo service isc-dhcp-server start
$ sudo update-rc.d hostapd enable
$ sudo update-rc.d isc-dhcp-server enable
```

And the wireless access point part will be finished.

### 18 Install Tor

After a reboot, we now need to install Tor. Do this simply with:

```bash
$ sudo apt-get install tor
```

Once it’s installed, you’ll need to edit the Tor config file with:

```bash
$ sudo nano /etc/tor/torrc
```

Follow the next step to add all the necessary information to it.

### 19 Tor configure

Put this below the FAQ comment:

```ini
Log notice file /var/log/tor/notices.log
VirtualAddrNetwork 10.192.0.0/10
AutoMapHostsSuffixes .onion, .exit
AutomapHostsOnResolve 1

TransPort 9040

ListenAddr 192.168.42.1
DNSPort 53
DNSListenAddress 192.168.42.1
```

![](img/dd9251551a61a36067892b1cc68615b0_48_1.png)

### 20 Table flush

We now need to flush the current IP tables so that we can get the routing to go through Tor. First of all, do:

```bash
$ sudo iptables -F
$ sudo iptables -t nat -F
```

![](img/dd9251551a61a36067892b1cc68615b0_48_2.png)

If you want to keep SSH open to connect remotely, you’ll need to make an exception for that with:

```bash
$ sudo iptables -t nat -A PREROUTING -i wlan0 -p tcp -dport 22 -j REDIRECT --to-ports 22
```

### 21 Reroute

Route all DNS traffic first, using:

```bash
$ sudo iptables -t nat -A PREROUTING -i wlan0 -p udp -dport 53 -j REDIRECT --to-ports 53
```

And then route any TCP traffic with:

```bash
$ sudo iptables -t nat -A PREROUTING -i wlan0 -p tcp --syn -j REDIRECT --to-ports 9040
```

![](img/dd9251551a61a36067892b1cc68615b0_48_3.png)

### 22 Check and save

You can check the table setup with:

```bash
$ sudo iptables -t nat -L
```

If you’re happy with it, save it to the NAT file like before with:

```bash
$ sudo sh -c "iptables-save > /etc/iptables.ipv4.nat"
```

### 23 Logging

We should create a log file in case you need to debug later. To do this, use these three commands:

```bash
$ sudo touch /var/log/tor/notices.log
$ sudo chown debian-tor /var/log/tor/notices.log
$ sudo chmod 644 /var/log/tor/notices.log
```

You can also check it with:

```bash
$ ls -l /var/log/tor
```

### 24 Secure the router

Finally, we can activate the Tor service so that we can start using the access point securely with:

```bash
$ sudo service tor start
```

You can check this if you wish with:

```bash
$ sudo service tor status
```

To make it turn on at boot, you simply add it to rcd with:

```bash
$ sudo update-rc.d tor enable
```

## The other half of WordPress

With ten years under its belt, WordPress has firmly cemented its place in the hearts of bloggers. But what next for its co-founder Mike Little? David Crookes finds out...

We are on a tram to Manchester, tapping away on our phone as we update one of our blogs, engrossed in the words and thinking little about the underlying code which is making all of this possible. Just as the last few words are written, the tram stops and we make our way to the escalator to Piccadilly Station about to meet the man who created the behemoth that is WordPress, the very blogging platform we had been using throughout the journey.

Our meeting is being held at a railway station because Mike Little, who is from Stockport, is a busy man. He has already had one meeting before we shake hands and he is due to have another. We decide to sit in a coffee shop and he grabs a sandwich before telling us about his latest venture, which is – unsurprisingly given the software is used by 18.9 per cent of the top 10 million websites – very much related to WordPress.

Little is currently working on a series of screencasts which showcase how WordPress can be used, explaining the fundamentals of it to encourage more people to get involved with blogging using the platform. My screencasts won’t be like that and people will certainly get value for money.”

After all, if he cannot produce a killer website for companies and organisations using the software, then nobody can. It is fitting, then, that he has worked with Downing Street on government sites.
