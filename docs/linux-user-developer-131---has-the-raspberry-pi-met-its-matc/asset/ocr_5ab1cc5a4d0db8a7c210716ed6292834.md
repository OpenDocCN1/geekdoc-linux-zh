One method we'd recommend using on Linux would be wget, the standard downloading tool for the command line. You can download the contents of a web directory with something like:

```
$ wget --mirror -p --convert-links -P /destination/folder/ http://www.website.com/directory/
```

# ## Assault on battery

I want to have a notification show up in the event that my laptop battery charge falls below 10%, as I regularly move around when working on it. I guess that most desktop environments provide a notification of this sort, and I use GNOME with a few other programs, so I just need something like a notification daemon and front-end. I've had a few close calls while working so far, and I'd really rather not go back to a desktop environment I don't have to.

Can you suggest any notification tools? I would prefer a lightweight package that I can extend with other notifications, but any suggestions are welcome. If there are any GNOME notification tools that work well outside of their environments, that would also do.

Chris Dodd

![](bbox=[0.07, 0.69, 0.13, 0.75])

There's actually a couple of great tools you can use on GNOME to get this type of functionality. You can use 13, which is a tiling window manager, which can be used on its own or in conjunction with TWM. Both offering notification windows, and 13 is specifically designed to work with the xmobar as well. 13 is also very extensible, and it can be used for a lot more than just battery notifications. Hope this helps.

# ## Oracle of Java

So I have the OpenJDK installed on my system, and it turns out I need to use the official Oracle JDK for a project I'm working on. Only, it seems like I can't just install it and expect it to work —

how do I go about setting up my system to use the Oracle JDK? I'm currently running Ubuntu. Thanks.

![](bbox=[0.35, 0.71, 0.41, 0.77])

Peter Chan

Okay, so the process for doing this is a two-step one. Firstly, you need to download the JDK files from the Oracle website, which come in a tarball. Extract these and this will create a *jdk1.7.0_0x* directory in the location of your choosing.

Now create a new directory for it and move into it with:

```
$ sudo mkdir -p /usr/lib/jvm $ sudo mv ./jdk1.7.0[Current Version] /usr/lib/jvm/jdk1.7.0
```

Now you need to run some specific commands to update the system Java info, allowing you to then switch to it. First of all do:

```
$ sudo update-alternatives --install "/usr/bin/java" "java" "/usr/lib/jvm/jdk1.7.0/bin/java" 1
```

```
$ sudo update-alternatives --install "/usr/bin/javac" "javac" "/usr/lib/jvm/jdk1.7.0/bin/javac" 1
```

```
$ sudo update-alternatives --install "/usr/bin/javaws" "javaws" "/usr/lib/jvm/jdk1.7.0/bin/javaws" 1
```

Now, correct the file ownership and the permissions of the executables with:

```
$ sudo chmod a+x /usr/bin/java
```
