# 3.7.2 Solaris 2.5.1 and 2.6 Turnstiles

Figure 3.13 illustrates the turnstile structures and links in Solaris 2.5.1 and 2.6.

![](bbox=[0.239, 0.178, 0.881, 0.684])

The tstile_mod structure is where it all begins. There is one tstile_mod systemwide, and it maintains the links to the turnstiles. It also maintains various fields required to support the implementation, such as the number of turnstiles in the pool (pool_size), number of active rows in the tsm_chunk array (active), a link to the pool of turnstiles, and an array of pointers to turnstiles (tsm_chunk[]—these are the active turnstiles).

The tsm_mutex lock is used to protect tstile_mod only when more turnstiles need to be allocated. Other turnstile support functions do not need to acquire tsm_mutex.
