# 13.5.5.1 DNLC Operation

Each time we open a file, we call the open() system call with a path name. That path name must be translated to a vnode by the process of reading the directory and finding the corresponding name that matches the requested name. No place in the vnode stores the name of the file; so, to prevent us from having to reread the directory every time we translate the path name, we cache pathname-to-vnode mappings in the directory name lookup cache.
