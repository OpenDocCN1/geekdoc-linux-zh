# Table 13-7 *Solaris 7 vfs Support Functions*

| Method | Description |
|---|---|
| `vfs_make_fsid()` | Called by a file system to generate the file system ID from the device. |
| `getvfs()` | Gets a pointer to the vfs that matches the supplied fsid. Used only by the nfs server. |
| `vf_to_stf()` | Maps vfs flags to statfs flags. |
