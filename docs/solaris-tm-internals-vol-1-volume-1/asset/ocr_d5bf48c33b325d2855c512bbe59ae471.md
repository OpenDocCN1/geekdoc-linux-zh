# ### 7.3.1 Free Memory

Our vmstat example shows that we have 2,096 Kbytes of memory free, which seems low for a system with 128 Mbytes. Recall from the introduction that free memory is low because the VM system has used all of it for file system caching, which means that free memory has fallen to approximately the value of lots-of-free. (See “The Page Scanner” on page 178 for the meaning of lotsfree.) Although free memory is almost zero, plenty of memory is still available for applications. We will look at how to observe how much of our memory is being used for file system caching when we later discuss MemTool in detail.
