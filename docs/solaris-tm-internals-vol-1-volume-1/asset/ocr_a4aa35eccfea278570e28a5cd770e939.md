We alluded earlier to a default partition, created at system initialization (boot) time. All installed processors are placed in this default partition during the initialization process, and if no other partitions (processor sets) are explicitly created by psrset(1M) or psrset_create(2), the system simply maintains the internal default set, which is not made visible to users. psrset(1M) will show all processors on the system as managed by a default partition. The default partition is a processor set. The kernel defines three possible levels for partitions (cp_level): CP_DEFAULT, CP_SYSTEM, CP_PRIVATE. The default partition created at boot time is, of course, CP_DEFAULT, and will be the only default partition systemwide (only one such partition is allowed). Additional partitions created on the system are set to CP_PRIVATE. The CP_PRIVATE level is not currently used but will likely be implemented in the future as a means of creating internal kernel (only) partitions.
