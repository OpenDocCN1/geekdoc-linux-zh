# 15.7.2 VxFS Inode Cache

The Veritas file system uses a similar parameter, `vxfs_ninode`, to control the size of the inode cache. It also attempts to keep one-fourth of the `vxfs_ninode` parameter number of inodes on the inode idle queue.

```
```
* Set number of inodes stored in VxFS inode cache
*
set vxfs:vxfs_ninode = new_value
