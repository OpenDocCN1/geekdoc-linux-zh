# INTRUSION DETECTION SYSTEMS

**Objective 4.7** An Intrusion Detection System (IDS) inspects all inbound and outbound network activity and identifies suspicious patterns that may indicate a network or system attack. The difference between a firewall and an IDS is that a firewall prevents access between networks to prevent intrusion, whereas an IDS identifies action to be taken once an intrusion has been detected. There are several categories of IDS; misuse detection, anomaly detection, network-based system, host-based system, passive system, and reactive system.

+   * **Misuse detection** This category of IDS compares network traffic to a database of attack signatures. This is similar to the way virus detection works and is only as good as the database of signatures.
* **Anomaly detection** This category of IDS compares the current state of the network to a baseline or normal state.
* **Network-based system** This category of IDS analyzes network traffic to detect suspicious packets.
* **Host-based system** This category of IDS is similar to a network-based system, but it analyzes only the traffic on a single host.
* **Passive system** This category of IDS will detect a security breach, log the occurrence, and send an alert.
* **Reactive system** This category of IDS will detect a security breach and take action against it. This action could be to log off a user or to block traffic from a specific source.

# LIDS

Several types of IDS are available for Linux, including an enhancement to the Linux kernel called LIDS (Linux Intrusion Detection System). LIDS implements several security features, including mandatory access controls (MAC), a port scan detector, file protection, and process protection. You can download LIDS from www.lids.org.

# Snort

Snort is an open-source network intrusion detection system. It performs real-time network traffic analysis and packet logging. It can perform protocol analysis, content searching, and matching, and can detect several types of attacks. You can download Snort from www.snort.org.

# PortSentry

PortSentry is part of the Abacus security tools. It detects and responds to port scans against a target host in real time. It runs on TCP or UDP, detects several attack signatures, can react to a port scan by blocking the host, and provides alerts to report the attempt. PortSentry can be downloaded from www.insecure.org.
