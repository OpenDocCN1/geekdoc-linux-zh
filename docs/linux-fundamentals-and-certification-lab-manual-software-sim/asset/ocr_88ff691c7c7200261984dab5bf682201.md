Software developers will enjoy the sophisticated development tools available in Linux. There are toolkits for C, C++, Java, and many other languages. Almost all Linux distributions include development packages for C. (The C development software is often used to compile packages and the Linux kernel.) There are IDEs (Integrated Development Environments), libraries, and other tools that make development on Linux systems desirable. A comparable C compiler for Windows can cost hundreds of dollars.

The Linux operating system is endowed with a comprehensive set of networking tools. Not only basic network services, but other services such as ftp, telnet, smtp, snmp, finger, DNS, DHCP, and others are available. Linux provides a fast, reliable, and secure networking environment for many uses. Linux can also share devices, such as modems, a feature not available on most other operating systems.

Linux is an ideal environment for running servers. One of the best features for a Linux server is that the GUI can be eliminated, freeing up resources for other tools.

# ## LINUX DISTRIBUTIONS

Initially, Linux consisted of the operating system and a few GNU tools, but as time goes on more tools and applications are being added. The concept of a Linux distribution came into being and today is a multimillion dollar industry.

The development cycle of Linux follows a development phase denoted by the version number. Linux kernel versions are identified by three numbers: the major version, the minor version, and the patch version. The minor version number indicates the version type. For example, with 1.2.3, the 2 is the version type. Odd-numbered versions, 1.1, 2.1, and so on, denote the period in which kernel features are being added and developed, the development phase. Even-numbered versions denote the stabilization phase where smaller modifications to the kernel are made. The current development release is 2.5.75 and the current production release is 2.4.22. Linux is maturing into a professional, enterprise-ready operating system. The latest stable release, 2.4.x, provides an improved scheduler and a Logical Volume Manager (LVM, a method of allocating hard drive space into logical volumes that can be easily resized instead of partitions), and support is evolving for 64-bit architecture.

Doing a basic search on the Internet for Linux distributions, filtering only those that are available for Intel-compatible hardware, returned more than 150 different distributions. The version you use will be determined by your individual needs.

This book uses the most generic commands available, so it won't matter which distribution you choose to use. However, some features are proprietary to each distribution. Many different versions are illustrated throughout this book, but Red Hat Linux is used for most examples. Red Hat is one of the most popular distributions available. It has an easy-to-use GUI installer program, the RPM (Red Hat Package Manager) program developed by Red Hat to manage add-on software packages, and an easy way to upgrade your system when new versions of programs and applications are available.
