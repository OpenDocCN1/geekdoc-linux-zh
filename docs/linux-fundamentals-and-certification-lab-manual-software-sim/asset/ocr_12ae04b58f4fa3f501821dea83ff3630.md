# Boot Disk Creation

Not all new systems have a floppy disk drive; however, if your system does, it is highly recommended that you create a boot disk. The boot disk can boot your system properly using GRUB, LILO, or a third-party boot loader. If your system’s boot sector was damaged for some reason, the boot disk will allow you to start the system anyway.

The boot disk can be created after installation, or at any time, from the command line. To create a boot disk during installation, select Yes when prompted and then insert a new formatted disk in your floppy drive, as seen in Figure 3–27. All data on the disk will be erased. Some installations will prompt you for more than one disk.
