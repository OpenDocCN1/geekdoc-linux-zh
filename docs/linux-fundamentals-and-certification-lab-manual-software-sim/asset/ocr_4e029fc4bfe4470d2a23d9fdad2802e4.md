# ■ INSTALLATION VALIDATION

Objective 1.15

![](bbox=[0.22, 0.79, 0.27, 0.81])

The first time you start the Red Hat Linux system, the Setup Agent is displayed, as shown in Figure 3-32. The Setup Agent guides you through the configuration of Red Hat Linux. (Some distributions will automatically run a setup; others will not.) The Setup Agent is used to set system time and date, add users, install software, register with Red Hat, and more. If the values need to be changed later you can use configuration tools in the GUI and in the text environment to do so. These tools will be covered in Chapter 4.

The first Setup Agent screen allows creation of user accounts, shown in Figure 3-33. The root account you created during installation is the super user account. This account is too risky to use for normal login. The root account can change any values within Linux, and for that reason a user account should be created. The Setup Agent lets you enter a user name, an optional full name, and a password. Each character of the entered password will display as an asterisk.
