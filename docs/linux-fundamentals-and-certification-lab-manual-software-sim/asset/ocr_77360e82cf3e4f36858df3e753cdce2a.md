Usually the *value 7* is reserved for the host adapter. If this is the only drive or the last drive there may be a setting for terminations. Many of today's SCSI drives are terminated by attaching the drive to the end of the cable.

Install the drive into the system case. There are several specifications for SCSI cables. The cable is keyed to allow installation in only one direction. A common SCSI-3 cable is shown in Figure 2-8.

Setting the BIOS for the system is not necessary with SCSI drives. The SCSI adapter handles the I/O for the drive. It may be necessary to enter the SCSI board setup program on startup and set parameters for the drive. Instructions are different for every board, but there will be a prompt indicating how to enter the SCSI setup. After entering setup, you can follow onscreen prompts or the instructions that accompany the adapter.
