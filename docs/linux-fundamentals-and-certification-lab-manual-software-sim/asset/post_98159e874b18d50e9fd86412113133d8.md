
## FTP

File Transfer Protocol (FTP) is used to transfer files from one machine to another on a network. An FTP server can be a small machine in terms of processing power, but is usually larger in terms of disk space. Its purpose is to store files and make them available for transfer when requested. Often an FTP server allows anonymous access for anyone who wants to “download” a file. The size of an FTP server will depend on the number of users accessing files and the size of the files provided. More users connected translates to more processing power needed, and more files to more disk space. So, an FTP server can be any size from an older 486 to the largest available today.

## Database Servers

A database server provides access to a database for one or many clients. Typically the RDBMS, Relational Database Management System, is managed on the server and accessed by clients remotely. With larger database systems, the server’s sole purpose is to provide the database services. Database servers tend to be larger, more powerful machines with large data stores. The data store in these servers often consists of multiple disk drives configured as a Redundant Array of Inexpensive Disks (RAID). RAID is discussed later in this chapter.

A database server is often accessed through a firewall (Figure 2-1). If it is used to service Web clients, the Web client accesses a Web server via the Internet and the Web server accesses the database through the firewall. The database processes the request and returns a data set to the Web server, which in turn returns a response to the client.

## Web Servers

A web server provides access to Web content. Specifically, it is a server process running on a Linux server that responds to requests for Web pages by transferring files to the requester. A Web site is a directory located on a Web server that sends out Web pages in response to HTTP requests from remote clients. Some of the terms used with Web servers are:

- Web site: A set of interconnected Web pages, usually including a homepage, generally located on the same server, and prepared and maintained as a collection of information by a person, group, or organization.
- Hyper Text Transfer Protocol (HTTP): A protocol used to request and transmit files, especially Web pages and Web page components, over the Internet or other computer networks.
- Hyper Text Markup Language (HTML): A language used to generate Web content. A markup language consists of tags placed before and after text that indicate how the text is to be displayed. For example, the tag `<B>` placed before text indicates that it should be displayed in bold.
- Web page: A document on the World Wide Web, consisting of an HTML file and any related files for scripts and graphics, and often hyperlinked to other documents on the Web.
- Hyperlink: A section of text on a Web page that, when selected, retrieves another Web document from the Web server.

Apache HTTP server is a popular Web server, used in more than 60 percent of Web sites on the Internet, and can be used by Linux and other operating systems. The Apache HTTP Server Project develops and maintains the open-source HTTP server for most operating systems.

### Note

A recent survey of over 44 million Web sites conducted by news.netcraft.com determined that Apache HTTP server has over 67% market share with an increasing trend over the last few years. Microsoft IIS has 21% market share with a decreasing trend since February 2002, and all other HTTP servers have less than 3% market share with decreasing trends.

A Web server can be run on almost any size machine. The level of service determines what size machine to use. If you are running a personal Web server you can manage the content on a personal desktop machine with access to the Internet or intranet. But if you are managing a Web server for a corporation with hundreds or thousands of pages you will need a larger server. Large Web servers often are run on multiple machines to provide high availability. The software requires little in the way of resources, but with larger sites, the increased number of users requires more RAM and faster network connections.

## File Servers

A file server is a computer that controls a central repository of data that can be downloaded or manipulated in some manner by a client. A file server is often used to provide additional disk space for individual users. By using a central location to store files, administrators can easily back up user content without having to manage multiple machines.

A popular file server application for Linux is Samba, an open-source/free software suite that provides seamless file and print services to SMB/CIFS clients. Server Message Block (SMB) is a protocol that provides file and printer sharing between computers. Common Internet File System (CIFS) is an Internet file system protocol based on Microsoft’s SMB.

With Samba a server can provide file and print services to Windows-based clients using TCP/IP as the underlying transport protocol. It allows you to use Linux and Windows machines together without requiring a separate Windows server.

Another file sharing system, Network File System (NFS), was developed by Sun Microsystems as a standard for sharing files over a network. This service allows integrating a file system into a remote system where it is used seamlessly with other local file systems. NFS is available by every Unix and Linux system.

A file server’s size is determined by its usage. Again, if you have one user with limited needs a personal desktop will suffice; but if you have hundreds of users you will need a larger server and a much larger data store.

## Messaging Servers

A messaging server provides access to e-mail by clients. It quickly delivers e-mail with content that could include embedded sound, graphics, video files, HTML forms, Java applets, and desktop applications. Message servers use several protocols, as shown in Figure 2–2. Some of the protocols are Simple Mail Transfer Protocol (SMTP), Internet Message Access Protocol version 4 (IMAP4), Post Office Protocol 3 (POP3), and Hyper Text Transfer Protocol (HTTP).

SMTP is used to communicate client to server and server to server and uses port 25 to communicate. Information about SMTP can be found in RFC-821. RFCs, requests for comments, are managed by the Internet Engineering Task Force (IETF) and can be found at http://www.ietf.org.

![](img/37f079cee226b270f2e09b37a2e4a05d_35_0.png)

POP3 provides client access to retrieve queued e-mail from the messaging server. Normally e-mail is downloaded and then deleted from the message store. Information about POP3 can be found in RFC 1939.

IMAP4 is a protocol that enables a client to connect with a messaging server and download queued e-mail to the local workstation. IMAP4 is much more robust than POP3 and provides the ability to manage folders and mailboxes on the server. IMAP4 gives you the flexibility to store messages locally or on the server, or both. Information about IMAP4 can be found in RFC 2060.

HTTP is used by messaging servers to provide access to e-mail via any standard Web browser. In most cases, WebMail, using HTML and JavaScript, provides an interface to a messaging backend. Message data is translated into HTML pages for viewing through a browser. HTML forms are used to create messages, which are then sent using SMTP. Messaging servers provide a message store to hold e-mail until it is retrieved by the client. With POP3 the client retrieves e-mail and then the e-mail is deleted from the store. With IMAP4 the client retrieves e-mail and then has the option to leave it on the server or delete the message from the store.

A messaging server, sendmail, is included with Linux. Many e-mail servers are available, both open source and commercial. A quick search of the Internet will show several dozen open-source e-mail servers and clients, including SquirrelMail and Open WebMail. Commercial servers include Sun/One’s Application Server 7 and Zeus Web Server.

As with other servers, the size of the server depends on its usage. If you are managing a personal mail server you can use a personal desktop machine. But if you are providing a messaging solution for a business you will need a dedicated server to manage the system and sufficient disk space to contain the e-mail.

In a corporate environment, one or more mail servers would be positioned outside a firewall and at least two mail servers would be within the firewall. The systems outside the firewall serve to restrict access to the intranet. The inside systems are typically for performance issues. Depending on the number of users accessing e-mail, one group of intranet mail servers will provide message storage for users to read mail from, and another group for outgoing e-mail, providing enhanced performance for overall messaging.

## Enterprise Server

An enterprise server provides server services while maintaining high availability. Enterprise servers are usually high-end machines with redundant components that are hot-swappable (replaceable while powered). Typically, an enterprise server is a group of servers that are operated in a cluster. A cluster provides:

- Shared storage: All cluster members have access to the same storage.
- Service failover: Services provided by the enterprise server are always available. The cluster detects failures and recovers from them automatically.
- IP load balancing: Provides the capability to load-balance incoming IP network requests across a farm of servers. An IP load balancing cluster appears as one server.

An enterprise server is usually a group of high-end machines attached to a common RAID. The Linux distribution that provides this type of service is not usually available for free download.
