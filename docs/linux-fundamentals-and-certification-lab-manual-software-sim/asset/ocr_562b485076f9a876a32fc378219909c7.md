# GLOSSARY



Switch.  A device that routes network information based on the physical MAC address. It works at the OSI model data-link layer.

SysV.  A Linux operating system startup process derived from an old Unix version, System V. It is the most commonly used startup process on a Linux system.

TAR.  Short for Tape ARChive. TAR is a Linux utility that combines a group of files into a single file. The tar command does not compress files.

Tar Balls.  A repository for program files, universally accepted by Linux and Unix systems.

TCP.  Transmission Control Protocol, a connection-oriented, reliable protocol that is used on TCP/IP networks.

TCP Wrappers.  TCP wrappers are a form of basic access control. They provide an authentication request, banners, and other services before allowing a connection.

TCP/IP.  Short for Transmission Control Protocol/Internet Protocol. TCP/IP is a protocol suite used to communicate over the Internet and most local area networks.

Telnet.  A program used on TCP/IP networks to connect to other hosts. Telnet sessions provide a command-line interface to the remote computer. Telnet is not a secure program and uses port 23.

TGZ.  Files ending in .tar.gz or .tgz are tar files that are compressed with the gzip program, making them smaller and quicker to transfer over a network.

Traceroute.  A program that attempts to trace the route an IP packet follows to a remote host. traceroute uses the Internet Control Message Protocol (ICMP) defined in RFC 792.

TurboLinux.  A distribution of the Linux operating system.

UDP.  User Datagram Protocol, a connectionless and unreliable transport protocol that is used on TCP/IP networks.

UID.  A unique identification number, called the userid, that is assigned to each user.

Unix.  A multiuser, multitasking operating system developed at Bell Labs in the early 1970s.

USB.  Universal Serial Bus, a port type on a computer system that allows up to 127 devices to be connected.

Usenet.  A bulletin board system, called newsgroups, that can be accessed through the Internet.

Username.  An alphanumeric string entered by the user that identifies one and only one account. No two users can have the same username.

vi.  A command-line text editor that allows only the adding, changing, and deleting of text.

Virtual Consoles.  Additional consoles provided by the Linux operating system that can display different types of information.

VPN.  An acronym for Virtual Private Network. A VPN uses a public connection to provide the same network connectivity for remote users as that provided over a private connection.

Web Server.  A computer that provides access to Web content using the HTTP protocol.

Workstation.  A type of Linux installation that is similar to the Personal Desktop Linux installation, but typically includes graphic software development tools, and sometimes network management tools. Workstations are computers designed for the work environment.

X.  A windowing system that serves as the core of a GUI operating system.

X Windowing System.  A specification for device-independent windowing operations. It is also called X.

XFree86.  An open-source client/server interface between the display hardware and the desktop environment.

Xterm.  A program that can provide a text-based command line interface from within an X windowing system.
