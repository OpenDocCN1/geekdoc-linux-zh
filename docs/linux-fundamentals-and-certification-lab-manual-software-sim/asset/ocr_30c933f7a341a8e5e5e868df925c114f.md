# ## Managing Quotas

After quotas are configured, you have to turn the quotas on, set user/group limits, and set a grace period. The command to start or restart using quotas is **quotaon**. The quotaon command has the same options available as quotacheck.

```
# quotaon -auv
/dev/hda3: user quotas turned on
```

Setting limits is accomplished with the **edquota** command. This brings up an editor, vi by default, with values for the user selected. Use the **edquota -u jsmith** command to edit the values for jsmith. Figure 11-11 shows jsmith's entry in the quota table.
