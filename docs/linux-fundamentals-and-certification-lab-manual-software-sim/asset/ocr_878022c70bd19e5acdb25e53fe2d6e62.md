Compiling your own kernel also can ensure that the most standard features are used. Many distributions provide newly updated drivers and custom features that make using them attractive; however, these features can sometimes cause problems with some computer systems.

Another advantage of compiling your own kernel is ease of upgrading. As new or updated devices are introduced to a computer new drivers must also be used. Compiling the kernel is a way to ensure that the new drivers are included.

Most Linux installations use the kernel developed for the distribution set installed. In most cases the kernel will not have to be compiled. The details of compiling a Linux kernel are beyond the scope of this book. If you are interested in compiling the kernel, there are many sources to research the topic, including Web sites, books, and magazine articles.

# INSTALLATION METHODS

The Linux installer program for your distribution set runs within the Linux operating system. Any method you choose to install Linux requires that Linux be running in order to load the installer. Typically, the Linux boot system can be run from one or two floppies or it can be run from a bootable CD-ROM.

All personal computer systems can be configured to boot from a small range of sources. To configure the boot source, you must enter the setup program when the computer starts. To enter the setup program you press a key when the initial computer screen displays the prompt to do so. Typical choices are Diskette Drive, Internal Hard Disk Drive, CD-ROM, Network Interface Card (NIC), and USB Storage Device. Some distributions include a DOS or Windows program that can launch the installer.

Depending on the system and your distribution set, you may need a floppy disk to start the install. Some distributions come with a floppy disk, but others do not. If you need a boot floppy disk, you can make one from the distribution set or you can download the tools to create one. Most Linux distributions come with a program called rawrite.exe to perform this task. Rawrite is a Windows/DOS program used to create a floppy disk from an image file. +   1. Change drives to your CD-ROM. If you have only one hard disk drive or partition, your CD-ROM is probably drive D:. To change to this drive, type **D:** and press Enter.
