# FTP

FTP is part of the TCP/IP suite of protocols. FTP uses ports 20 and 21. FTP client software allows transfer of files between client and server. For example, if you produce Web pages for a Web site you could use FTP to transfer the Web page files to the hard drive on the remote server. Copying from the client to the server is called uploading, and copying from the server to the client is called downloading.

Client software that is used to connect to remote servers is vulnerable to interception by others. Many users do not realize that when they use their password over a network, it is often sent in clear text, making it easy for others to read. Programs such as FTP Telnet and others send passwords in clear text. Often, with FTP, the connection is anonymous and a password is not sent. Anonymous connection is often used when the files to be transferred are public; however, some data is confidential and should be protected as it is being transferred across the network. One way to protect data is to use programs that offer secure data transfer.

Many Linux distributions use an open-source set of programs called OpenSSH. OpenSSH uses strong authentication, RSA keys, and programs that work enough like the insecure versions to make retraining unnecessary.

The OpenSSH suite includes the following programs:

+   - **sshd**	Server program that is run on the server machine. This listens for connections from client machines, performs authentication, and starts serving the client.
- **ssh**	Secure Shell client program is used to log into another machine.
- **scp**	Secure Copy is used to copy files from one machine to another.
- **sftp**	Secure File Transfer Protocol is used to transfer files securely from one computer to another.

The program ftp is an insecure program that is vulnerable to hostile attack. The sftp program should be used instead. The basic syntax of sftp is sftp *servername* where servername is the remote computer’s FQDN or IP address. For example, to connect to a program called myserver with the IP address 192.168.0.21 using sftp (Figure 7–33), type sftp 192.168.0.21.

The first time a connection is made, an encryption key is exchanged between the server and client. This key is very secure, allowing the computers to transfer data between them without compromising the information.
