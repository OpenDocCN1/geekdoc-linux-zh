To begin the installation, insert disk 1 of the distribution set and power up the system. If it is set to boot from the CD-ROM, just wait for the welcome screen. If not, enter the setup program and change the device boot order to start from the CD-ROM. The Red Hat install screen, Figure 3–1, will be displayed, prompting you to install or upgrade using the graphical mode or the text mode. **Type linux text** and press **Enter**.

The Red Hat installation will prompt you to begin the installation, Figure 3–2, or to check the media first. Selecting the **OK** button will check the installation media to ensure that it is a valid disk. You can insert each disk of your distribution set to check all the disks. Selecting **SKIP** will continue the installation without taking the time to check the disk set. Performing a media check will take a considerable amount of time, and is not a required step.
