**cdrom.img** or **boot.img** is used to install from a local IDE or SCSI CD-ROM.

**network.img** is used to install from a NFS, FTP, or HTTP repository.

NFS is Network File System, a client/server application from Sun Microsystems that allows network users to access shared files on network computers.

FTP is File Transfer Protocol. It is used on the Internet to exchange files between remote computers.

HTTP is Hyper Text Transfer Protocol. This is the protocol used by content on the Internet.

**pcmcia.img** is used to install from a PCMCIA card. PCMCIA devices are small, credit-card size cards, usually connected to laptop computers. They can be network cards, CD-ROMS, and other devices.

**hd.img** is used to install the Linux image from a hard drive.

**usb.img** is used to install from a USB device such as an external CD-ROM.

**other.img** is used to install from less common devices. Use this img file if others do not work.

Different distributions may have different names and types of images. For example, Red Hat has an image called bootdisk.img for all types of installation methods.

# CD Installation

If you have a CD-ROM distribution and your system will boot from CD, you can start the Linux installation by inserting CD and starting the computer. You will see an installation screen start menu similar to Figure 3-1. The start menu asks what method of interaction you want to use during installation. The installation choices on this menu are graphical interface or text interface. With the graphical interface option, Linux must have an available graphics driver for the installed graphics adapter. Choosing the text mode option does not require a graphics driver and will work in all installations. The only real difference between the two interfaces is how the screen looks and how you select options, mouse or keyboard. Even in the cases where the screens are slightly different between the two, all the same options are available.

The graphical user interface allows you to navigate the installation screens using the mouse and GUI tools, such as buttons and drop-down lists. You can also navigate through the installation using the Tab and Enter keys.
