A typical file would contain the following entries:

order hosts,bind

multi on

/etc/hosts The /etc/hosts file contains the name and IP address of local hosts. If a host’s name is in this file, the system does not need to query the DNS server to get its IP address. The disadvantage to using the /etc/hosts file is that a change to the list of hosts on a network requires manually changing the entries in the file. You can specify more than one hostname per line.

An /etc/hosts file will minimally contain one entry for the **localhost** loopback. localhost is a special hostname with a special IP address. It always references your own machine. The IP address associated with localhost is 127.0.0.1.

The remainder of the /etc/hosts file contains entries identifying IP addresses with hostnames. Typically, each line identifies at least two hostnames, one fully qualified domain name (FQDN) and one with just the hostname. Typical entries are described as:

```
127.0.0.1 localhost loopback
192.168.0.20 myserver.linuxplus.com myserver
192.168.0.24 myclient1.linuxplus.com myclient1
```
