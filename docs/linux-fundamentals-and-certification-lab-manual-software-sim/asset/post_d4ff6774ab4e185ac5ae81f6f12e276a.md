
Both the symbolic and octal modes of manipulating file permissions will achieve the same results. Use whichever method you are comfortable with.

### Creating, Removing, Changing, and Viewing Directories

The file system structure, as seen in Figure 4–20 and used by Linux, is a hierarchical list of directories called a directory tree. The top of the tree is the root directory, indicated by a /. The upper directories are called parent directories, and the directories beneath them are called child directories.

#### Pathnames
A pathname is used to identify where a file or directory is in the file system. A pathname identifies a specific file or directory by using the names of the directory tree folders as reference points. For example, the path to the directory init.d is /etc/init.d, which says follow from the root directory (/) to the child directory etc to etc’s child init.d.

The first slash (/) in a pathname indicates the root directory. Subsequent slashes are used as delimiters between directory names, as shown in Figure 4–21.

![](img/37f079cee226b270f2e09b37a2e4a05d_111_2.png)

![](img/37f079cee226b270f2e09b37a2e4a05d_111_3.png)

Pathnames can be absolute or relative. An absolute pathname identifies a full path-name, beginning with the root directory. In Figure 4–21 the full pathname of the file smb is /etc/init.d/smb. A relative pathname identifies where a file or directory is relative to the current directory. For example, if the current directory is /etc then the path to smb is init.d/smb. (Notice that there is no leading /. That would indicate the root directory as the start of the path.)

### Changing and Viewing Directories

To list the contents of each directory, the tree structure must be navigated with a change directory (`cd`) command, and then the files can be listed with the `ls` command. There are shortcut symbols that can be used in pathnames. To refer to the current directory, use a period (`.`). To refer to the parent directory, use two periods (`..`). To refer to the current user’s home directory, use the tilde + slash (`~/`). To refer to the previous directory, use the hyphen (`-`).

When jsmith logs in to the system, he will be in his home directory, /home/jsmith. The default directory location for any user is the user’s home directory. Using the example directory tree in Figure 4-22 as a reference, look at the commands to navigate through the tree.

To change to jsmith’s documents directory, type `cd documents`.

The documents directory is directly below the jsmith directory, so the relative path is just the directory name.

The absolute pathname, `cd /home/jsmith/documents`, could also be used.

The shortcut symbol for current directory, `cd ./documents`, could also be used.

To change directories to the etc directory, type `cd /etc`.

The / is needed because the etc directory is off the root directory. This is an example of an absolute pathname.

There are two choices in changing from the /etc directory to the jsmith directory. You can use the absolute path `cd /home/jsmith`. You can also use the shortcut symbol for the user’s home directory, the tilde (~), `cd ~`. Either command will change directories to the jsmith directory.

From the jsmith directory, to change to the home directory, use an absolute or a relative pathname.

The absolute pathname to home is /home, such as `cd /home`.

The relative path from jsmith is the shortcut parent (`..`), such as `cd ..`.

To return to the previous directory, use the - shortcut, such as `cd -`.

![](img/37f079cee226b270f2e09b37a2e4a05d_112_0.png)

It’s easy to lose files along the way. Some file systems can have tens of thousands of files in hundreds of directories. Use the `pwd` command to display the current pathname:

```bash
pwd
/home/jsmith
```

To view the current directory, use the `ls` command. The `ls`, list directory, command lists information about the files in a directory. The command will display files in the current directory by default, but can be used to display any directory by supplying the pathname. For example, `ls /home` displays the files in the /home directory. The syntax of the `ls` command is `ls [option] [file]`, where option is from the following list and file is either a file-name or a pathname.

- **a, --all** Do not hide entries starting with .
- **A, --almost-all** Do not list implied . and ..
- **--author** Print the author of each file
- **-d, --directory** List directory entries instead of contents
- **-l** Use a long listing format
- **-n** Like -l, but list numeric UIDs and GIDs
- **-S** Sort by file size
- **-t** Sort by modification time
- **-x** List entries by lines instead of by columns
- **-X** Sort alphabetically by entry extension
- **--help** Display all the options. Same as the `man ls` command, which displays the man pages for the `ls` command. Use the `more` command with this command to view page by page. (Example: `ls --help | more`)

> **NOTE**
>
> A man page is a selected group of pages from the Unix Programmers Manual. Each man page describes one command. To view the information about a command, use `man command`, where *command* is one of the Unix commands.

These options are just a small subset of all the options available. To view all the options, use the `man ls` command.

A long file listing (`ls -l`) displays the columns shown in Figure 4–23.

**FIGURE 4–23**
`ls -l`.

![](img/37f079cee226b270f2e09b37a2e4a05d_113_0.png)

To display a directory that is not the current directory, include the directory name at the end of the `ls` command. To list the contents of the *usr* directory, type `ls usr`.

There are two wildcard symbols that can be used with file names. The asterisk (`*`) represents any group of characters, and the question mark (`?`) represents any single character.

The `*` symbol can represent any number of characters. For example, to list all files that begin with the letter v, type `ls v*` or `ls -l v*` to get a long listing.

The `*` can be used anywhere in the filename to replace the characters. For example, to list all files that contain the letters ftp, type `ls *ftp*`.

The `?` can be used to replace any single character. For example, to list all files with the letters rcXd, where X is any character, type `ls rc?.d`.

File types can include those for directories, executable files, text files, and symbolic links. To view the different file types, use the `-F` option with the `ls` command. Figure 4–24 is the result of using the `ls -F` command in the */bin* directory.

Various file types are displayed with the following symbols:

- / Directory
- \* Executable file (a command or script file)
- @ Symbolic link (a file that points to another file)
- No symbol (indicates a plain file)

### Creating Directories

Creating directories is a common task. Users typically create directories to organize their personal files within their home directories. To create a directory, use the `mkdir` command. There are a few options that can be used with the `mkdir` command and they can be discovered by using the `man mkdir` command.

To create a directory, use the `mkdir` command with a directory name. Use an absolute or relative pathname when creating a directory. For example, if the current directory is /home/jsmith and jsmith wants to create a directory to contain downloaded files, use the `mkdir downloads` (relative pathname) or the `mkdir /home/jsmith/downloads` (absolute pathname) command.

### Removing Directories

To remove a directory, use the remove (`rm`) command. The `rm` command can be used to remove files or directories. Even an empty directory has two hidden entries. The . and .. symbols that are used as shortcuts are actual entries in the directory. (Use `ls -a` to see hidden files.) To remove a directory, the files in the directory must be removed as well. This can be accomplished with the recursive (-r) option. The recursive option removes the contents of a directory before the directory is removed. The current directory cannot be the directory to be removed.

If the current directory is /home/jsmith and the directory /home/jsmith/downloads is to be removed, type either `rm -r downloads` (relative pathname) or `rm -r /home/jsmith/downloads` (absolute pathname).

## MOUNTING FILE SYSTEMS

![](img/37f079cee226b270f2e09b37a2e4a05d_114_1.png)

Before you can use any file system, it must be mounted to a directory. For example, the root file system is mounted to the / directory at startup. All storage devices must be mounted before use. The floppy drive must be mounted, usually to the /mnt/floppy directory, before it can be accessed. The system automatically mounts file systems on your hard drive at boot time.

The `mount` command is used to mount file systems. At boot time the command `mount -av` is executed. The -a option causes all file systems mentioned in the `/etc/fstab` file, shown in Figure 4-25, to be mounted. File systems can be mounted at boot time by entering the information into the fstab file. File systems can also be mounted using the `mount` command after login.
