## X WINDOWING SYSTEM

The X system is the GUI system for Linux and Unix. The current version is 11 release 6.6. It is most commonly called X11 or just X. You may also see it written as XWindows, which is incorrect, but gets the meaning across.

X is the foundation software for GUI interfaces. It provides functionality for the mouse cursor, drawing windows, and moving windows. X does not provide any other functionality, such as buttons, menus, or title bars. These windowing features are provided by other software.

X is based on a client/server model. The X server displays information on a graphical display and sends back user input from a keyboard or mouse. An X client is a program that relies on an X server for interaction. These programs usually run on the same computer, but they do not have to. An X client can connect to a remote X server relatively easily.

### The Video Adapter

Video cards basically accomplish the same task on any machine. They provide the hardware link from software that wants to communicate to a display device. Many different video adapters are available, and the type you have installed is not always easy to determine.

Video adapter manufacturers use a video chipset as the core of a video adapter. The chipset must be identified to the Linux kernel before a GUI can work. The video chipset can be discovered in a number of ways.

Linux will auto-detect the video card during installation in most cases. In some cases the video card cannot be detected. For example, if you have a new machine with the latest video chipset, Linux may not detect it.

If you are installing a new video card, you may have the manufacturer’s documentation. Or, if the card is a popular model, you will probably be able to find documentation online. If you have to search online for the video documentation, you need to know what chipset your card uses. Figure 9–1 shows a video chipset from nVIDIA. The information on the chip can be used when searching www.nvidia.com for a driver.

During video configuration you may be presented with a list of choices. The driver you select should match your chipset. If you are not sure, power off the computer and remove the video card for a visual inspection. If the video is built in, visual inspection of the main board is required. Many different chipsets are on the board, but the video chipset is usually one of the largest. If you are unsure of the chipset, you can try the generic video drivers.

A simple way to identify the video device type is to observe the BIOS messages displayed following a system reset. Often the video card will display its manufacturer and model along with additional details.

One last way to determine the video driver is to inspect it on a machine where it is already installed and running. For example, on a Linux installation you can view the /usr/X11/lib/X11/XF86Config file (Figure 9–2) for the Section “Device”, which will list the video adapter driver, vendor name, and board name.

**NOTE**
Some high-end video adapters generate a lot of heat. If this is the case, your video card will probably have a heat sink on top of it. A heat sink is a metal device with a fan that dissipates heat from the chip.

## X Servers for Linux

Most Linux distributions ship with XFree86, an open-source implementation of the X window system (http://www.xfree86.org). The XFree86.org Web site has documentation with information about installing, updating, driver status, and other matters that will be helpful once you have determined your chipset.

Most Linux installations ship with XFree86 version 4.3.0. The next planned release is version 4.4.0. If you have a video adapter that is not supported by the version of XFree86 you are using, you may want to download the latest version.

If XFree86 does not fulfill your needs, you may want to try a commercial X server. Two companies that provide an X server product are Accelerated-X (www.xig.com) and Metro Link (www.metrolink.com).

## Configuring X

One method of configuring X is through its configuration files. The main file is XF86Config in the /usr/X11R6/lib/X11 directory. This file contains information about the mouse, keyboard, and video adapter. If you change this file, make sure you make a copy of it first.

Another method is to let the Linux installation automatically configure video. This will work in most cases; however, not all video adapter information is programmed into the Linux distribution.

Similar to the automatic Linux installation, you may also run a separate configuration program. Some systems use the command `/usr/X11R6/bin/XF86Config -configure`; others have a custom program, such as Red Hat's `/usr/bin/redhat-config-xfree86` program. This method will work if Linux automatically identified your video adapter.

**Configuring X Manually**
Configuring XFree86 manually is basically a trial-and-error process. The following is a summary of a manual configuration.

1. Determine your video chipset, memory, and monitor. One tool to do this is `/usr/sbin/ddcprobe`. This program will probe the hardware for monitor and video card.

   ```
   # ddcprobe

   Videocard DDC probe results
   Description: Intel Corporation Brookdale-G Graphics Controller
   Memory (MB): 7

   Monitor DDC probe results
   ID: DEL300e
   Name: Dell M992
   Horizontal Sync (kHz): 30-96
   Vertical Sync (HZ): 50-160
   Width (mm): 350
   Height (mm): 260
   ```

2. Configure XFree86Config. Start by generating a configuration file. The **XFree86** program will generate the file with the -configure option. Before running this program, change to runlevel 3 with the `telinit` program. Runlevel 3 will allow you to configure X in a mode that does not automatically start it.

   ```
   telinit 3
   XFree86 -configure
   ```

   This command will generate a skeleton XFree86 configuration file called XF86Config.new. The XFree86 program will attempt to probe the hardware and place entries in the file for the mouse, video card, and monitor.

3. Check the configuration to verify that XFree86 will work. The XFree86 program has an option, -xf86config, to accomplish this task.

   ```
   XFree86 -xf86config XF86Config.new
   ```

   If a black and gray grid and an X mouse cursor appear, the configuration was successful. To exit the test, press the Ctrl+Alt+Backspace key combination. If the configuration was not successful, or if you want to configure other parameters, you can edit the XF86Config.new file and make adjustments. Use the `man XF86Config` command to set options in the file. If you make changes, test the configuration again.

4. Copy the new configuration file to the XFree86 configuration directory, /etc/X11.

   ```
   cp XF86Config.new /etc/X11/XFree86Config
   ```

   After the configuration file is in place, the configuration is complete. To start X, use the `startx` program. This will start the GUI normally, that is, from runlevel 3. If the configuration is still correct, use the `telinit` command to enter runlevel 5 and restore the X login screen.

   ```
   telinit 5
   ```
