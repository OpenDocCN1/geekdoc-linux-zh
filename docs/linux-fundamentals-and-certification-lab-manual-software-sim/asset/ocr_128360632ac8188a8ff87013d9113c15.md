The boot loader can be password protected. This allows you to require a password before attempting to boot an operating system other than the default one, or to make boot-time configuration changes. This password is only for the boot loader; you will be asked to enter a password for the Linux operating system authentication once you pass this level.
If physical access to your Linux system is available you should use a boot loader password. Without a password anyone can interrupt your Linux startup and pass boot options to the kernel. This can compromise your system security. With the boot loader in place, the user must enter a password before being given the opportunity to enter options.
To use a boot loader password (Figure 3–14) tab to the Use a GRUB Password option and press the space bar to select it. Then tab to Boot Loader Password and enter the pass-word you want to use. Tab one more time to Confirm and enter the same password again.
