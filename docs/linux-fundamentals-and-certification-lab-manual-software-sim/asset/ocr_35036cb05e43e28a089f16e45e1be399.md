# Starting X

There are several ways to start X. One that you are probably already using is to have it start when you first start Linux. This option was set during installation; if you are staring in run-level 3, however, you may want to start X to run a GUI program.

There is a script in /usr/X11R6/bin/startx that can be used to start X. It looks for startup information in the .xinitrc and .xserverrc files in the user's home directory. If those files cannot be found, it lets xinit start with its default values. This file may be customized for individual Linux systems.

Another way to start X is to use the telinit command to change the runlevel. The telinit command sends a signal to init, telling it which runlevel to change to. If you are in runlevel 3 and want to change to runlevel 5, type telinit 5.
