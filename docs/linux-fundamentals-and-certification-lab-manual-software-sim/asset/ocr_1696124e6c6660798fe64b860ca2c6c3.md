# PERSONAL FIREWALLS

A personal firewall is a single point of defense that all network traffic must go through in order to communicate with applications on a computer. It’s also a program running on a workstation computer that prevents unauthorized access to the computer via the network connection. A personal firewall is a pain to use, but necessary in many cases.
