The video card configuration dialog box allows you to enter the amount of video memory installed on your video card. The documentation that came with the card or the computer system will indicate the amount of video memory.

If you choose to configure your video later, you can use the \_redhat\-config\-xfree86 program from a command prompt. You will need to be the root user in order to make changes.

As part of the video configuration you will be asked to select a monitor (Figure 3\-29). Again, Red Hat Linux installation will attempt to auto\-select the monitor. If it does not select the correct monitor, you can select **Change** and then select the correct monitor from a list.

If your monitor is not on the list you can pick a **Generic** model. The Generic monitors will indicate the size, the horizontal and vertical sync ranges, and other properties for the monitor.

If you are performing a custom or server installation, you can choose to boot your Linux system into either the text or the GUI interface. The GUI is recommended for most users. The GUI closely resembles the Windows GUI and is easy to administer and use, especially for the novice user.

Some systems require a text\-only environment. By using text only, you free up a lot of the computer's resources for other applications. The only disadvantage to using the text interface is that you must know the commands needed to administer the Linux operating system. Many of the commands discussed in future chapters of this book will use the text environment.

The X Customization screen, shown in Figure 3\-30, allows you to select the color depth, the number of colors displayed, and the resolution, the number of pixels that are used to form the images on the screen. This screen also gives you two options to select how you will boot into the system, graphical or text. Select the **Graphical** option.

For purposes of this installation, log into Red Hat Linux with the graphical interface. The text environment is easily entered from the GUI to explore the text commands.

The Complete prompt, seen in Figure 3\-31, indicates that your Red Hat Linux installation has finished all its tasks. Remove any installation media, diskette or CD, and select **OK** to automatically reboot your computer. If you did not install a boot loader you will need your boot disk to start Linux on your computer.
