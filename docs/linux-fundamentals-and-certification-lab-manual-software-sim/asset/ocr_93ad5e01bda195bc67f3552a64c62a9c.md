# FIGURE 4-2
/etc/inittab.

```
# inittab
#		This file describes how the INIT process should set up
#		the system in a certain run-level.
#
# Author:	Miquel van Smoorenburg, <miquels@drinkel.nl.mugnet.org>
#		Modified for RHS Linux by Marc Ewing and Donnie Barnes
#
#
# Default runlevel. The runlevels used by Mandrake Linux are:
#	0 - halt (Do NOT set initdefault to this)
#	1 - Single user mode
#	2 - Multiuser, without NFS (The same as 3, if you do not have networking)
#	3 - Full multiuser mode
#	4 - unused
#	5 - X11
#	6 - reboot (Do NOT set initdefault to this)
#
id:5:initdefault:	*

#	System initialization.
s1:sysinit:/etc/rc.d/rc.sysinit
10:0:wait:/etc/rc.d/rc 0
```

> **NOTE**
Be careful when editing the /etc/inittab file. A mistake can cause your system to be unbootable without using a boot disk or reinstalling the system.

Runlevels 2 and 4 are available to configure in whatever way makes sense for your system. By using runlevels 2 and 4 for custom configuration, runlevels 3 and 5 remain undisturbed.

> **NOTE**
If the system does not boot due to a bad /etc/inittab or if the password is corrupted or forgotten, perform the following steps to boot into single-user mode:

	If you are using boot loader LILO, type **linux single** at the boot: prompt and press Enter.

	If you are using GRUB as the boot loader, enter single-user mode with the following steps:

1.  In the graphical GRUB boot loader screen, select the Linux boot label and press **e** to edit.
2.  Arrow down to the kernel line and press **e** to edit.
3.  At the prompt, type **single** and press Enter.
4.  After the GRUB screen with the kernel information is displayed, press **b** to boot the system into single-user mode.

	A bare system will boot with a command shell, allowing changes to be made to the operating system.
