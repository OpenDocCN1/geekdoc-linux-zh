Depending on the Linux version and whether or not the prompt has been changed, the prompt will usually display in the following format: **username@hostname current_directory $**. For example, if jsmith logged in to the CLI on host linux1 the prompt would be [jsmith@linux1 jsmith]$

# NOTE

> Linux distributions can have slightly different properties for the CLI prompt, but, generally, all work the same.

One useful feature of CLI is command-line completion. All current shells have this feature. The command-line completion feature uses the Tab key to complete a command.

To illustrate the command, suppose that jsmith wants to view the contents of the file *my_summer_vacation_in_south_beach_journal*. The filename is very long and cumbersome to type. However, you can type **view my[tab]** (press the Tab key where indicated by [tab]), and the CLI will display **view my_summer_vacation_in_south_beach_journal**. You can then just press Enter.

If the characters that you enter are not unique to the file you want, the CLI will display a list of all files that meet the current criteria and you can type enough characters to make the file unique, then press Tab again.

Auto-completion is also available for usernames, machine names, or environment variables. The characters for each of these are \~, @, and $. Type each of these characters in the CLI and then press Tab.
