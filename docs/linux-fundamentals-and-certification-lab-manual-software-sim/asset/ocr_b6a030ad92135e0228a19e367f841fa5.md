# ## /etc/samba/smb.conf

The /etc/samba/smb.conf file is a configuration file for the Samba suite. It contains the runtime configuration for the Samba programs. The file contains name/value pairs of information within sections.

A section name is the name of the shared resource. A section can be named almost anything, but usually it is named something that describes what it is meant to share. For example, if the directory to be shared is the /opt/oracle directory, the section name might be **oracle**.

Some special section names are used in Samba, **global**, **homes**, and **printers**. Not all special names have to be used.

+   - The **global** section provides default values for all Samba shares. These are parameters that apply to the Samba service, not just individual shares.
- The **homes** section provides shares for individual clients on the network. This is often called *home space*.
- The **printers** section provides information for clients to connect to a printer. Shares in Samba are either a file directory or a printer.

The following listing is a sample smb.conf file listing. This file has only two sections—**[global]** and **[tmp]**. **[global]** contains information about general Samba share properties, and **[tmp]** contains information about a directory to share.

```
[global]
  workgroup=linuxplus.com
  security=user
  encrypt passwords=yes
  guest account=guest
  wins server=192.168.0.21
  local master=yes
  os level=99
  hosts allow=192.168.0. 127.
  interfaces=eth0
[tmp]
  path=/tmp
  writeable=yes
```

The **[global]** section contains the following properties:
* **workgroup** Windows machines participate on a network within a workgroup. Windows machines can participate in a peer-to-peer network with a workgroup, or in a network with a dedicated server providing a domain. The workgroup can be in either of these.
If you are using a Windows client, the computer's workgroup can be found by right-clicking the My Computer icon and selecting Properties. The computer name and workgroup or domain are under the Computer Name tab (Figure 8-10).
* **security** This tells Samba to run in user-level security mode and to challenge any user that is connecting for a user ID and password. From a Windows client, a connection dialog box asking for the ID and password of an account on the Linux Samba server will be displayed. If the user is connecting from a Linux client, the Linux server will ask for the password of the account the client is using. In both cases you must have an account on the Linux server to access the Samba share.
* **encrypt** This tells Samba to exchange passwords in encrypted mode. Encryption should always be used for security, unless the share is an anonymous share that all can use.
