
## HARDWARE REQUIREMENTS

- Objective 1.1
- Objective 6.1

Linux is versatile and works on most existing hardware configurations. Most Linux distributions have a hardware compatibility list that you can browse through. These hardware compatibility lists are usually arranged by type of hardware and whether or not they’ve been tested with the distribution in question. Of course, purchasing new hardware from the compatibility list is most desirable. However, the type of system you use is controlled by the size of your budget for the installation.

Your first step in determining your hardware requirements is to determine the type of installation you need. A server, for example, depending on its usage, can require a more powerful CPU, bigger file system, and faster network connection than those of most personal desktop machines.

After you determine the type of installation you require, you need to determine the type of hardware needed. Hardware needs include CPUs, memory, video cards, hard drives, network cards, modems, and other devices.

### CPU

![](img/37f079cee226b270f2e09b37a2e4a05d_36_0.png)

Most Linux distributions support just about any i386 CPU. Some distributions also support IBM, Sparc, PowerPC, and other CPUs, as well as SMP (Symmetric Multi-Processor) systems. Most CPUs use 32-bit internal registers; however, 64-bit versions of the Linux operating system are available for some 64-bit CPUs. Linux has more installations on i386-based CPUs and was initially developed for that platform, so it is most mature on i386-based system. The i386-based hardware tends to be less expensive than other hardware and is often the best buy. An Intel Pentium processor is shown in Figure 2–3.

> Intel processor.

When deciding which type of CPU you need, you first look at the speed of the CPU. This measure is useful when looking at one manufacturer’s brand; however, when you compare across different models, there are other considerations. Some models can do more work during a CPU cycle than others, making comparisons very difficult. Also, the type of computing being done can make a difference in the way the processor responds.

The Linux operating system will run adequately, depending on the installation type, on some of the oldest i386-based processors. Generally, you want the fastest Linux-compatible CPU available. However, a workstation installation with office productivity, Internet, and e-mail software will run well on a PII-400 with 256 MB of RAM.

### Memory

The type of random access memory (RAM) used in a computer has changed over the last several years. The types used most recently are single-in-line memory modules (SIMM), dual in-line memory modules (DIMM), and small outline dual in-line memory modules (SODIMM). The older SIMM is used by older systems. More current computer systems use DIMM. DIMMs range in capacity from 32 MB to 512 MB per module. SODIMM is used in most notebook computers. SODIMMs also range in capacity from 32 MB to 512 MB. The types of RAM are illustrated in Figure 2–4.

Some distributions of Linux run on as little as 4 MB of RAM. However, the amount of RAM on the system has a great deal to do with how well the system performs. The operating system and its applications run in RAM. If enough RAM is available for the applications the programs will run faster than if they have to page in and out of swap space (disk area used to store currently running applications that won’t fit in RAM).

The good news about RAM is that today it’s inexpensive. Most new systems come with a minimum of 128 MB and many with 512 MB of RAM.

### Video

Linux works in text mode with any video adapter. This is adequate for a system that will be used only as a server for most applications; however, most systems will require a GUI, and this requires a video adapter that will support it.

Most drivers for Linux are part of the kernel, but video drivers to operate bitmapped graphics modes are not. Bitmapped drivers are part of the X server. X support is provided through XFree86 (www.xfree86.org) or a commercial X window system. XFree86 is open source and provides a client/server interface between display hardware and the desktop environment. Most video adapters will work with Linux. Some video drivers for newer cards can take weeks or months before being available.

The video adapter should have sufficient RAM to support the types of video you want to display. The RAM is used to store an image on the card before it is displayed on the display device. Most video cards have at least 8 MB of RAM and many have much more. 8 MB can handle screen resolution of 1600/1200 with a 32-bit color depth. Cards with more memory typically use it for rendering 3D images. This is useful for high-resolution graphics packages used for CAD, computer aided design, and games. Configuring video is discussed in Chapter 3.

### Hard Drives

There is a wide variety of hard drives and hard drive manufacturers. Most hard drives fall into two categories—Enhanced Integrated Drive Electronics/Advanced Technology Architecture (EIDE/ATA) and Small Computer System Interface (SCSI). EIDE and SCSI are standard interfaces for connecting hard drives to a computer system.

> **NOTE**
> Serial Advanced Technology Architecture (ATA) is a new interface used to connect hard drives and other peripherals to a PC. It is a replacement for parallel ATA storage interface. Serial ATA is compatible with today's ATA, but has smaller connectors (7 pins) and cables can be longer (up to a meter in length). The initial Serial ATA offers 150 MBps and is expected to double about every three years.

**Hard Drive Controllers**  
Small Computer System Interface (SCSI, pronounced “skuzzy”) is a parallel interface standard used by computer systems for attaching peripheral devices to computers. SCSI interfaces provide for very fast data transmission rates, up to 80 MBps. It also allows for the connection of many devices to a single SCSI port.

Although SCSI is an American National Standards Institute (ANSI) standard, there are many variations of it. These variations are not always compatible and may even use different types of connectors.

- **SCSI-1** Uses an 8-bit bus, and supports data rates of 4 MBps.
- **SCSI-2** Same as SCSI-1, but uses a 50-pin connector instead of a 25-pin connector, and supports multiple devices. This is what most people mean when they refer to plain *SCSI*.
- **Wide SCSI** Uses a wider cable (68 cable lines to 68 pins) to support 16-bit transfers.
- **Fast SCSI** Uses an 8-bit bus, but doubles the clock rate to support data rates of 10 MBps.
- **Fast Wide SCSI** Uses a 16-bit bus and supports data rates of 20 MBps.
- **Ultra SCSI** Uses an 8-bit bus, and supports data rates of 20 MBps.
- **SCSI-3** Uses a 16-bit bus and supports data rates of 40 MBps. Also called Ultra Wide SCSI.
- **Ultra2 SCSI** Uses an 8-bit bus and supports data rates of 40 MBps.
- **Wide Ultra2 SCSI** Uses a 16-bit bus and supports data rates of 80 MBps.

EIDE refers to ATA, Advanced Technology Attachment, a disk drive implementation that integrates the controller on the disk drive. Like SCSI, EIDE/ATA has several versions.

- **ATA** Known also as IDE, ATA supports one or two hard drives, a 16-bit interface and PIO modes 0, 1, and 2.
- **ATA-2** Supports faster PIO modes (3 and 4) and multiword DMA modes (1 and 2). Also supports logical block addressing (LBA) and block transfers. ATA-2 is marketed as Fast ATA IDE (EIDE).
- **ATA-3** Minor revision to ATA-2.
- **Ultra-ATA** Also called Ultra-DMA, ATA-33, and DMA-33, supports multiword DMA mode 3 running at 33 MBps.
- **ATA/66** A version of ATA proposed by Quantum Corporation, and supported by Intel, that doubles ATA's throughput to 66 MBps.
- **ATA/100** An updated version of ATA/66 that increases data transfer rates to 100 MBps.

Most home personal computers use the EIDE/ATA standard. EIDE is relatively inexpensive, and for a single hard drive attached to a single adapter there is very little difference in the performance of EIDE when compared to SCSI. But when using multiple drives, SCSI has some advantages over EIDE:

- Only two devices can be attached using EIDE/ATA, whereas many devices can be attached to a SCSI controller.
- SCSI provides for higher bandwidth than EIDE/ATA devices.
- SCSI devices support hot-swapping in RAID systems. Hot-swapping allows removing a drive without powering off the RAID, providing a high-availability scenario.

SCSI is a natural choice for more demanding server installations.

Redundant Array of Inexpensive Disks (RAID) is a way of using two or more drives to provide high availability. This is accomplished through data striping and disk mirroring. Data striping allows spreading out blocks of data across multiple disks to improve performance. Disk mirroring allows data to be written to two duplicate disks at the same time so that if one disk fails, the other can take over with no data loss. There are several RAID levels. The most commonly used are:

- **Level 0** Provides data striping
- **Level 1** Provides disk mirroring
- **Level 3** Provides data striping with error correction
- **Level 5** Stripes both data and parity information across three or more drives

The most common implementations of RAID are Level 0 + 1 and Level 5. RAID 0 + 1 is striping and mirroring combined, without parity. The advantage of RAID 0 + 1 is fast data access, as well as the ability to lose one drive and have a complete duplicate surviving drive or set of drives.

**Hard Drive Characteristics**  
The characteristics of hard drives vary widely and greatly affect performance. Hard drives can be installed internally or externally and have different rotational spins, varied seek times, and wide ranging capacities.
