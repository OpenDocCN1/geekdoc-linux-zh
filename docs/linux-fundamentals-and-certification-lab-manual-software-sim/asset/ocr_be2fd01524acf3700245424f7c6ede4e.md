The pathnames are not necessary because the file is moved within the same directory.

+   cp: Copy a file. cp has the same syntax as mv: `cp [options] source destination`. The difference in mv and cp is that cp leaves the source file in the current location whereas mv removes it from the current location.

Suppose that root wants to copy the file **data1** to jsmith's home directory. The current location of data1 is /root. The command to copy the file is

```
`cp /root/data1 /home/jsmith`
```

If the new copy of the file needs to be renamed, append the new name to the destination path. For example, to copy the data1 file to jsmith's directory with the name jsmithdata, type the following:

```
`cp /root/data1 /home/jsmith/jsmithdata`
```

+   in: Linked files can be symbolic or hard links. Symbolic links are pointers to programs, files, or directories located elsewhere. The linked file can be manipulated in the same way as the actual file. Symbolic links provide a way to easily reach files even though they are not in the current directory.

The rcX.d directories that contain the files to start or kill during startup and shutdown of Linux contain symbolically linked files. Using linked files enables the system to provide the correct files for each runlevel without having to duplicate the files.

To create a symbolic link to the /etc/hosts file from the /root home directory, type the following:

```
`ln -s /etc/hosts`
```

To display a list of linked files use the command `ls -F`. Linked files are displayed with the at (@) symbol after them.

Deleting a symbolically linked file removes the link, but not the original file. Deleting the target of a symbolically linked file breaks the link.

Hard linked files are pointers to programs and files, but not to directories. Like symbolic links, hard links provide access to files located in other locations. Unlike symbolic links, hard links must be on the same disk drive. Hard linked files point to the same disk address as the original file.

To create a hard link from a file called /home/jsmith/myfile.txt to a file in the /root directory called /root/myfilehardlink.txt, type the following:

```
`ln /home/jsmith/myfile.txt /root/myfilehardlink.txt`
```

Deleting a hard linked file removes the link, but not the original file. Deleting the target of a hard linked file does not break the link.

+   cat: Print the contents of a text file to standard output. The syntax is `cat [options] filename`. To view the contents of a text file named data1, type the following:

```
`cat data1`
```

+   more: View files on the screen through the more filter. more is a filter for paging through text. The text can be in a file or piped from another program. The basic syntax is `more filename`. more will display text to the screen one full screen at a time, pausing at the end of each screen for the user to continue to the next screen. To view a file named data1, type the following:

```
`more data1`
```

To view the results of the ls command one screen at a time, pipe the results to the more command:

```
`ls | more`
```

+   less: The less command, like more, is used to view a file, but also allows backward movement through the file. The basic syntax for less is `less [options] filename`. To view the file /etc/inittab with the less command, type the following:

```
`less /etc/inittab`
```
