# Virtual Consoles

The Red Hat Linux installation program gives you several virtual consoles to monitor your installation. A virtual console is another console that you can display with different types of information, as shown in Table 3–1. These virtual consoles are helpful if you encounter a problem during installation. The messages displayed on the different consoles can help narrow a problem so that it can be corrected. Usually, you need only the default console. If you have a problem, you may want to change to investigate the options. You may want to explore the virtual consoles while you are installing Linux. Use Table 3–1 to choose the console you want.

**Table 3–1**  
Virtual consoles.

| Console | Keystrokes | Contents |
| :---: | :---: | :---: |
| 1 | Ctrl+Alt+F1 | Installation dialog |
| 2 | Ctrl+Alt+F2 | Shell prompt |
| 3 | Ctrl+Alt+F3 | Installation log |
| 4 | Ctrl+Alt+F4 | System-related messages |
| 5 | Ctrl+Alt+F5 | Other messages |
| 7 | Ctrl+Alt+F7 | GUI display |

# Parameters

The first parameter that you will provide a value for, shown in Figure 3–4, is the language you want to use. Use the up and down arrow keys to highlight the correct option and then press Tab to the OK button. Press the space bar to select the OK button. If you accidentally tab past the OK button, just keep on tabbing. The tab will circle through all the options available.

Language selection here will help provide default answers for future questions. For example, the language will help target your time zone configuration later. Most screens have a Back button. Tabbing to the Back button and pressing the space- bar will “go back” a screen. Use this option if you answered a question wrong, or you just want to check the options you have already selected.
