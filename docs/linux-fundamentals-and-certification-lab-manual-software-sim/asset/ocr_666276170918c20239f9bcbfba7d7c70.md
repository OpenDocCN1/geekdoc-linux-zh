To solve boot loader problems you may want to use a boot disk. An emergency boot disk is just what the name implies, a boot disk to use in case of emergency. What constitutes an emergency? Usually, your system won't boot up. This problem can be caused by a number of things. The boot loader could have been damaged, the MBR could be damaged, or there could be other serious problems preventing the system from starting.

You may have created a boot disk during initial installation. One of the last options of the install is to create a boot disk. You probably did this the first time you installed, but if you have installed more than once, you probably skipped over this step because it takes too much time. It really doesn't take too much time, it just seems like it when you want to get the installation completed. You should create an emergency boot disk, otherwise you may not be able to boot your system.

If you did not create an emergency boot disk and find that you need one, you can still create it, even if your system won't start. The distribution CD has a boot disk image file that can be used to create a boot disk. You can also download the boot disk image from several Web sites, such as **http://ftp.redhat.com/pub/redhat/linux/9/en/os/i386/images/**. This boot disk image creates a boot disk using an image writing program, such as **rawrite**. rawrite is a DOS program that can be run from a Windows command prompt.

To create an emergency boot disk from the distribution CD (Figure 13-5), do the following:

+   1. From a DOS prompt, change to the CD drive by typing the drive letter of the CD, such as **E:**. The **E:\>** is displayed.  
2. Change to the **dosutils** directory by typing **cd \dosutils** from the command prompt.  
3. Run the **rawrite** utility program. The utility will ask where the image is located. The bootdisk.img file is located on the CD in the images directory.  
4. When asked for the image source filename, enter **e:\images\bootdisk.img**.  
5. When asked for a target diskette drive location, put a blank disk in drive **A:** and then enter **A:**. The diskette is created.

An emergency boot disk needs to have a few more tools to be really useful. For example, if your system uses a non-standard hard drive, you may need drivers to access the drive in an emergency. Consider including the following programs on a floppy disk:

+   - **vi**  Having access to a text editor will prove invaluable if you need to change a configuration file. vi takes a lot of space on a floppy, but it may be worth it.  
- **fdisk, mkfs, fsck**  Disk utilities may be needed if a file system needs to be restored or replaced.  
- **tar**  The tar program may be needed to restore data from tape or other storage media.

To use the emergency boot disk, put the disk in the floppy disk drive and restart the system. (Be sure to remove the CD if it is in the CD drive.)
