The **rpm** program can be used from the command line. **rpm** allows a user to query the packages available. The **-q** option tells rpm that this is a query and the **-s** option says to include the state of the application. The possible states are normal, not installed, or replaced. A normal state indicates that the package is installed. Figure 12-22 shows the result of a query. To remove a program after it is identified, use the **rpm** command with the erase option (-e). To remove the ftp-0.17-17 program, use the **rpm -e ftp** command.
