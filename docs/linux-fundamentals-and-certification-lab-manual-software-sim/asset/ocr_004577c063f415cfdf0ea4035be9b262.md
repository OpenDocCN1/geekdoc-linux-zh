**Configuring X Manually** Configuring XFree86 manually is basically a trial-and-error process. The following is a summary of a manual configuration.

+   1.  Determine your video chipset, memory, and monitor. One tool to do this is `/usr/sbin/ddcprobe`. This program will probe the hardware for monitor and video card.

```
```
# ddcprobe

Videocard DDC probe results
Description: Intel Corporation Brookdale-G Graphics Controller
Memory (MB): 7

Monitor DDC probe results
ID: DEL300e
Name: Dell M992
Horizontal Sync (kHz): 30-96
Vertical Sync (HZ): 50-160
Width (mm): 350
Height (mm): 260
# ```

```

+   2.  Configure XFree86Config. Start by generating a configuration file. The **XFree86** program will generate the file with the -configure option. Before running this program, change to runlevel 3 with the `telinit` program. Runlevel 3 will allow you to configure X in a mode that does not automatically start it.

```
```
telinit 3
XFree86 -configure
```

```

This command will generate a skeleton XFree86 configuration file called XF86Config.new. The XFree86 program will attempt to probe the hardware and place entries in the file for the mouse, video card, and monitor.

+   3.  Check the configuration to verify that XFree86 will work. The XFree86 program has an option, -xf86config, to accomplish this task.

```
```XFree86 -xf86config XF86Config.new```
```

If a black and gray grid and an X mouse cursor appear, the configuration was successful. To exit the test, press the Ctrl+Alt+Backspace key combination.
If the configuration was not successful, or if you want to configure other parameters, you can edit the XF86Config.new file and make adjustments. Use the `man XF86Config` command to set options in the file. If you make changes, test the configuration again.

+   4.  Copy the new configuration file to the XFree86 configuration directory, /etc/X11.

```
```cp XF86Config.new /etc/X11/XFree86Config```
```

After the configuration file is in place, the configuration is complete. To start X, use the `startx` program. This will start the GUI normally, that is, from runlevel 3. If the configuration is still correct, use the `telinit` command to enter runlevel 5 and restore the X login screen.

```
```telinit 5```
```
