# **Support for Linux**

Many question the availability of support for Linux. You may ask yourself, "What kind of support do I have for Windows?" Sure, you can call Microsoft, but if you want support you will have to pay for it. The same, however, does not hold for the Linux version you are using.

Support for Linux can be found for free on news groups. (You can find many groups that support Windows, as well.) Both Linux and Windows provide on-line access to documentation.

There are more trained technicians and administrators for Windows than for Linux. However, there are more training courses and certifications for Linux available today and the number is growing every month.

At least with Linux you get the source code. If you don't like the way something works, you can change it.

As with any operating system, Linux is not perfect. You can experience problems with running hardware and software in Linux, just as with Windows and Unix. Many administrators report that they run their Linux systems for months without having to restart, not something many Windows installations can boast. Over all, we think you will find that Linux is a good operating system and worth the time and effort you will need to get acquainted with it.

# ## THE FUTURE OF LINUX

The future looks good for Linux. To users, the only purpose of an operating system is to provide a platform to run applications. Linux has a huge base of applications, many of which have the source code available. A growing number of software companies, such as Oracle and Sun Microsystems, are porting their applications to Linux.

Over the next few years, Linux will have an increasing role in business. Reducing the cost of software licensing and providing more secure networks will increase the demand in both private and public areas.

Using the material provided in this book is a good way to start preparing for the Linux+ exam. To complement this information, you must also install and administer the Linux operating system.

The Linux kernel is always in development. While other operating systems offer updates a few times a year, Linux is, at times, updated weekly. The entire operating system need not be reinstalled to use the latest version of the Linux kernel. Patches are available to upgrade the kernel to provide access to newer device drivers and security updates. Kernel patching is discussed in Chapter 12.

# ## SUMMARY

Linux is the kernel of the operating system. When used along with GNU software it forms the GNU/Linux operating system. GNU is a recursive acronym for "GNU's Not Unix". The source code for Linux is free and available for anyone to revise and implement to meet their individual needs.

The copyright for GNU products is basically a "copyleft." Copyleft uses copyright law, but flips it over to serve the opposite of its usual purpose. Instead of serving as a means of protecting private software, it, instead, keeps software free.

Linux can be run on machines that have outlived their usefulness as Windows machines. Linux can provide usefulness without implementing a GUI with the operating system. It can be used in a number of ways including as a software development platform, firewall, DNS server, DHCP server, and many others.

There are more than a hundred distributions of Linux. A distribution contains the Linux kernel and a host of GNU applications for networking, development, and office productivity. The kernel development cycle is denoted by the version number. Odd-numbered versions denote periods when kernel features are being added and developed. Even-numbered versions denote smaller modifications made in the stabilization phase to the kernel.
