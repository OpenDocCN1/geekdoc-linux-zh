# Mandrake Linux

Mandrake Linux was created with the goal of making Linux easier to use for everyone. Since its inception Mandrake has grown and currently offers Mandrake Linux in varying distributions depending on customer needs.

Mandrake offers a clustering product for high-end processing. A clustering solution allows you to link several systems together and use their combined processing to reach performance equivalent to supercomputers. The cost is considerably lower than that of a supercomputer. Additionally, clustering allows you to access, manage, and program a cluster of machines as if it were only one machine.

The current version is Mandrake 9.1 and is available for download from http://www.mandrakelinux.com/.

# FreeBSD

FreeBSD is a Unix-like operating system distribution based on UC Berkeley’s “4.4BSD-Lite” release with some enhancements. FreeBSD is used by a wide range of users world wide.

Although FreeBSD is similar to Linux it is not an implementation of the Linux kernel. Instead, it uses the 4.4BSD Lite as a core for its operating system. One major difference in Linux and FreeBSD is in the way changes are included into the kernel. In Linux, Linus Torvalds is the final decision maker for changes in the official kernel; in FreeBSD a group of 200 individual programmers called Committers have the ability to make any change needed to the official FreeBSD source base at any time. The selection of Committers and dispute resolution are handled by the FreeBSD Core Team. The Core Team acts similar to a board of directors. Currently, the Core Team members are an elected body, with candidates and voters coming from the Committers.

Like most Linux distributions, FreeBSD is free. It offers networking, security, and compatibility modules to enable programs for other operating systems to run on FreeBSD. The current release of FreeBSD is 5.1 and is available for download from http://www.freebsd.org/.

# TurboLinux

TurboLinux is the leading supplier of Linux in Asia Pacific. TurboLinux was one of the first distributions to offer its software in multiple languages. The Japanese version includes an English-Japanese/Japanese-English dictionary on CD-ROM. The current version of TurboLinux is 8 and is available from http://cc.turbolinux.com/support/download/.

# Other Versions

You’ve got the idea. There are lots of versions. The preceding list is only a few of those available. Most distributions provide software for a wide range of platforms, such as Intel, Sun, Power PC, and Macintosh to name a few. Many provide their software in multiple languages as well.

Still don’t know which version to try? Do some research to find the distribution that will fit your needs. One of the best places to start is public newsgroups. They contain a wealth of information on almost any Linux topic. You can also post your own questions and receive answers that fit your specific needs.
