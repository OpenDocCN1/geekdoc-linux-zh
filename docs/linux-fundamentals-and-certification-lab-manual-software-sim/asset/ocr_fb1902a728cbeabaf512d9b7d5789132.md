**FTP**  File Transfer Protocol (FTP) is used to transfer files from one machine to another on a network. An FTP server can be a small machine in terms of processing power, but is usually larger in terms of disk space. Its purpose is to store files and make them available for transfer when requested. Often an FTP server allows anonymous access for anyone who wants to “download” a file. The size of an FTP server will depend on the number of users accessing files and the size of the files provided. More users connected translates to more processing power needed, and more files to more disk space. So, an FTP server can be any size from an older 486 to the largest available today.

**Database Servers**  A database server provides access to a database for one or many clients. Typically the RDBMS, Relational Database Management System, is managed on the server and accessed by clients remotely. With larger database systems, the server’s sole purpose is to provide the database services. Database servers tend to be larger, more powerful machines with large data stores. The data store in these servers often consists of multiple disk drives configured as a Redundant Array of Inexpensive Disks (RAID). RAID is discussed later in this chapter.

A database server is often accessed through a firewall (Figure 2-1). If it is used to service Web clients, the Web client accesses a Web server via the Internet and the Web server accesses the database through the firewall. The database processes the request and returns a data set to the Web server, which in turn returns a response to the client.

**Web Servers**  A web server provides access to Web content. Specifically, it is a server process running on a Linux server that responds to requests for Web pages by transferring files to the requester. A Web site is a directory located on a Web server that sends out Web pages in response to HTTP requests from remote clients. Some of the terms used with Web servers are:

+   * Web site A set of interconnected Web pages, usually including a homepage, generally located on the same server, and prepared and maintained as a collection of information by a person, group, or organization.

* Hyper Text Transfer Protocol (HTTP) A protocol used to request and transmit files, especially Web pages and Web page components, over the Internet or other computer networks.

* Hyper Text Markup Language (HTML) A language used to generate Web content. A markup language consists of tags placed before and after text that indicate how the text is to be displayed. For example, the tag <B> placed before text indicates that it should be displayed in bold.

* Web page A document on the World Wide Web, consisting of an HTML file and any related files for scripts and graphics, and often hyperlinked to other documents on the Web.
