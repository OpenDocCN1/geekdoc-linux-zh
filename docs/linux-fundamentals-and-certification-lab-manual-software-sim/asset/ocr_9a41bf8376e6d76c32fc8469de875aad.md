# NOTE

> To discover the options and arguments available for most commands, use the man com-
mand. Use the **man man** command to display the manual pages for the man command.

Commands and scripts are similar in the way they function, but are different in the
way they are designed. A command is a compiled program in binary format. A script is a
text file that contains commands and logic syntax to execute a group of commands in a par-
ticular sequence.

Commands start as source code, typically in the C programming language. The source
code is processed by a compiler that translates each statement into symbolic code, which is
then linked to the system. The result is a machine language program that performs a specific
task. Commands contain binary information, and their contents are unreadable if displayed.

Scripts, as shown in Figure 5-3, are strictly text files. Besides containing commands,
a script can also contain comments (preceded by the # symbol) and logic structures, such
as case statements, if statements, and other programming constructs. Scripts save time by
combining system and shell commands that are executed often into a single package. Oth-
erwise, running a complex list of commands can be time consuming and, with a larger
number of statements, increase the chances of making a mistake. Scripts can be interactive
or automatic, providing greater flexibility in managing Linux.

# FIGURE 5-3
Script.

```
#
# $Header: dbshut.sh.dp 03-apr-2001.13:38:20 jboyce Exp $
# dbshut.sh.dp Copyr (c) 1991 Oracle
#
##############################################
#
# usage: dbshut
#
# This script is used to shutdown ORACLE from /etc/rc
(.local).
# It should ONLY be executed as part of the system boot
procedure.
#
##############################################

ORATAB = /etc/oratab

trap 'exit' 1 2 3
case $ORACLE_TRACE in
T) set -x ;;
esc
```
