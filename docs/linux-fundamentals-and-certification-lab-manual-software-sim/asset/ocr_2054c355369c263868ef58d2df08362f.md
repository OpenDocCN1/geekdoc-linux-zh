Parameters also include the number of days before the user account expires, and an expiration date for the account.

The Privileges tab (Figure 4-8) is used to apply permissions and other select properties. Permissions can be denied, granted, or granted/silent. Denied prevents the user from accessing the specified resource. Granted allows access to the resource after the user supplies his password. Granted/silent allows access to the resource without further question.
