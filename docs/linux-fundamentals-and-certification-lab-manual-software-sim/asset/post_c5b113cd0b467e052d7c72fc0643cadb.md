Windows Device Manager is available from the Control Panel. To access the Device Manager, do the following steps in Windows:

- Select **Start** from the Taskbar.
- Select **Settings** from the menu.
- Select **Control Panel** from the submenu.
- Select **System** from the icon list.
- Select the **Hardware** tab.
- Select the Device Manager button.

> **NOTE**
> Different Windows versions may have a slightly different list of options.

Hardware devices can be viewed by type (the default), by connection (USB, IDE, etc.), or by resource (DMA, IRQ, I/O, memory). By drilling down into the device list, you can select properties on individual devices and examine the resources used by each.

If you are assembling a new machine, most settings will be assigned automatically. The only settings you will likely set are those for the IDE or SCSI devices you install and, possibly, the system board.

An IDE device, such as a hard drive or CD-ROM, has a set of jumpers that must be set to indicate whether the device is the master or the slave of the IDE interface. Designation of a drive as either master or slave is generally performed by the jumper configuration, not by the order in which the drive is attached to the IDE cable. But if the drive is set for cable select, master or slave is determined by the position on the data ribbon cable. Jumper settings are available for single, master, slave, or cable select. With two drives, one is set for master and the other set for slave. With one drive the single jumper setting is used.

## INSTALLING AN EIDE/ATA HARD DRIVE

![img/37f079cee226b270f2e09b37a2e4a05d_43_0.png](img/37f079cee226b270f2e09b37a2e4a05d_43_0.png)

Installing a hard drive in the computer case is relatively simple. Most system cases today have ready-to-use hard drive bays. Some hard drives require the use of rails, which are not usually shipped with the drive, but are available from the case manufacturer.

> **NOTE**
> Before you disconnect any cables or change jumpers, you should record their original positions.

![img/37f079cee226b270f2e09b37a2e4a05d_44_0.png](img/37f079cee226b270f2e09b37a2e4a05d_44_0.png)

Set the jumpers on the drive for your installation. If this is a second drive and you intend to use the same cable as the first drive, you may have to change the jumper settings on the existing drive for master and on the new drive for slave. Many CDs and DVDs use ATA technology as well and may be connected to the same cable. If this is the case, you may need to change the jumper settings on the CD or DVD also.

After completing the physical installation, you then need to connect the power and data cables, as shown in Figure 2-6. Cables are usually keyed so they can be plugged in only one way. This doesn't mean that the cables can't be forced in, so be careful. The data cable may already have one device attached to it. Use the empty connector for the hard drive.

> **NOTE**
> If the cable is not keyed, ensure that pin 1 of the cable is connected to pin 1 of the connector. Pin 1 on the cable is indicated by a red stripe on the pin 1 side of the cable.

If more than two devices are attached, you must have a second cable. One end goes to the hard drive and the other to the EIDE port on the motherboard. These cable connections are usually identified as IDE 0 and IDE 1 on the board and are usually right next to the existing port.

Now you must set BIOS to find the drive. Actually, BIOS is usually set automatically on a current machine. But if you have an older computer, you may have to enter setup on startup of the computer (most computers will display the word Setup and indicate which key to press to enter setup mode) and manually set values for the hard drive. The installation manual for the hard drive will have details for the setup.

Linux should find the new drive automatically. You can check this by typing the command:

```bash
# ls /proc/ide
```

The result will be similar to the following:

```text
drivers hda@ hdc@ ide0/ ide1/ pix
```

You are now ready to partition the drive. This can be done with the `fdisk` utility. (In Chapter 3 the Disk Druid utility will be used to partition the hard drive. This utility is available on many Linux distributions.) `fdisk` is used to view and manage partitions. To view a partition, type:

```bash
# fdisk -l /dev/hda
```

where `/dev/hda` will show the partitions on the first IDE hard disk drive. To create a partition, type:

```bash
# fdisk /dev/hdc
```

Then type **m** for the menu and the following is displayed:

```text
Command (m for help): m
Command action
a toggle a bootable flag
b edit bsd disklabel
c toggle the dos compatibility flag
d delete a partition
l list known partition types
m print this menu
n add a new partition
o create a new empty DOS partition table
p print the partition table
q quit without saving changes
s create a new empty Sun disklabel
t change a partition's system id
u change display/entry units
v verify the partition table
w write table to disk and exit
x extra functionality (experts only)
```

The commands you need to know are d, n, p, q, and w. If this is a new installation and there are any existing partitions (option p shows existing partitions), you need to delete an existing partition (option d deletes existing partitions). After the existing partitions are deleted you must create a new partition (option n creates a new partition). A new partition can be primary or extended. Remember that you can have four primary partitions, or three primary partitions and one extended partition. After you select p for primary you are asked for the partition number (1–4), then the first cylinder. If you are using the entire disk, the first cylinder is 1. You then enter the last cylinder (a maximum value range is displayed). If you do not want to use the remainder of the disk for this partition, you must enter a value for the last cylinder that is something less than the maximum. You have told Linux what you want, but it won't create or delete partitions until you save the results (option w writes the new partition table to disk and exits). You can abort the process by quitting without saving (option q quits without saving changes). Remember that logical partitions are always numbered 5 and up.

Some versions of Linux require a reboot after partitioning a drive (pre-2.2 kernels). Linux will report that it needs to reboot. After rebooting, you are ready to format the disk drive. Formatting is accomplished through the `mkfs` command. If you added a second drive to IDE 1 (second master) and created one partition, the following command:

```bash
# mkfs -t ext3 -j /dev/hdc1
```

will format the drive.

After `mkfs` has finished formatting, it is time to mount the drive. This is easily done and is covered in Chapter 4.

## INSTALLING A SCSI HARD DRIVE

SCSI devices are identified by an identification (ID) number that is configured by jumper settings selected to assign a value of 0 to 15. Other jumper settings are usually available to set SCSI termination. SCSI controllers and drives have different sets of instructions for installation. You should contact the manufacturer for detailed instructions on configuring these devices. Installing a SCSI driver in Linux is the same as with an IDE drive, except the device name will be `/dev/sd*` instead of `/dev/hd*`.

The first thing you do is set the drive SCSI ID and other operating options. The SCSI ID is generally set with a jumper and is an identity value of 0 to 15, as shown in Figure 2–7.
