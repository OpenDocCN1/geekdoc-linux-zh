+   * The third field describes the type of file system. File systems supported by Linux include ext2, ext3, vfat, tmpfs, and others. An entry of swap indicates a partition used for swap.

+   * The fourth field is used to describe mount options of the associated file system. For most entries the option will be defaults. Use the man mount command to display options for non-NFS file systems. Use the man nfs command for NFS file system options.

+   * The fifth field is used by the dump command to determine which file systems need to be dumped. A value of zero or blank indicates that dump is not needed.

+   * The sixth field is used by the fsck program to determine the order file system checks are done at reboot time. File systems on the same drive will be checked sequentially, but file systems on different drives will be checked at the same time. A value of zero indicates that the file system does not need to be checked.

**/etc/modules.conf**  The Linux kernel contains drivers for hardware and file systems. Some drivers can be compiled into the kernel, while other drivers are installed as modules. Modules, or driver files, provide information to Linux about how to control the devices they are designed to run.

Modules can be loaded and unloaded dynamically as needed by Linux. This allows the operating system to “free up” system resources that are not required at the moment. For example, a floppy drive may not be used most of the time and so Linux could load its driver as needed.

modprobe is a high-level program for handling loadable modules. This program makes the Linux modular kernel more manageable for all users. It can load a single module, a group of modules, or all modules. The behavior of modprobe can be modified by the configuration file /etc/modules.conf.

The /etc/modules.conf file (Figure 8–4) contains information about modules. This configuration file contains a list of drivers and the devices they are associated with. Linux usually writes the appropriate lines to the file when it detects a new device.
