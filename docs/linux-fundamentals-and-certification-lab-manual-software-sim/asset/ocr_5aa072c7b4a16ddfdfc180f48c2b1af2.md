**Session Manager** Sets properties for a user’s logon session.

**Information** Lists the properties of devices attached to the Linux system.

**LookNFeel** Allows a user to change the properties of the background, screensaver, taskbar, and others.

**Network** Allows you to set properties for e-mail, file sharing, and others.

**Peripherals** Enables you to set properties for digital cameras, printers, keyboard, and mouse.

**PowerControl** For battery-powered laptop machines. It enables you to change the period of time the system will wait before entering standby mode, whether or not to display the battery information, and other options.

**Security** Used to set the crypto settings and password properties.

**Sound** Contains settings for the sound card.

**System** Contains settings for boot loader, date and time, and other options.

**WebBrowsing** Allows changes to Web browser properties.

# **xterm**

Even on a GUI screen you will need a terminal window. xterm terminal emulator programs provide a text-based command-line interface within an X window system. The shell doesn’t know how to deal directly with the X window system, so an xterm program is used to allow the communication. The xterm program will load a bash shell by default on a Linux system.

One of the oldest xterm programs is called **xterm** (Figure 10–27). It provides DEC VT102/VT220 and Tektronix 4014 compatible terminals.
