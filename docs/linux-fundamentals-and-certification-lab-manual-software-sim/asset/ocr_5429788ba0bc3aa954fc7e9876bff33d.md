# Editing a File with vi

vi has two modes of operation, command mode and input mode. When you first start vi you are in command mode. From command mode you can move around the screen, enter commands to save the file, search the content of the file, or edit the text in the file. To type text into the file you enter input mode. To exit input mode, press the Esc key.

To start vim you can just type vi and press Enter. If you are creating a new file, this will open the editor and provide a blank window to start. To edit an existing file or to create a new file, type vi *filename*. For basic editing, a few commands are needed.

**Display Help** with the F1 key or type **:help** and then press Enter. The colon (:) is used to enter command mode.

**Move around** the screen with the following keys:

+   - **k** moves up one line
- **J** moves down one line
- **l** moves right one character
