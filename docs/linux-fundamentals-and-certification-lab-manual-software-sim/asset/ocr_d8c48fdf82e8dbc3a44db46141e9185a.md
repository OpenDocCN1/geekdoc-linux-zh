# NOTE

> The mount -av command actually mounts all file systems other than the root file system. The root file system is mounted by the kernel at boot time.

The fstab file contains static information about the file systems. Each file system is described on a separate line with fields separated by tabs or spaces. The order of the records in fstab is important because the file systems are mounted in the order presented in the file. The fstab file contains six columns of information.

+   - The first column of the fstab file is the device name or remote file system to be mounted. Typically, device names are names like `/dev/cdrom` or `/dev/hda2`. This field may also have an entry for listing the host and directory, for example, **cs.ua.edu/home**.

+   - The second column contains the mount point for the file system. This is a directory where the file system will be mounted.

+   - The third column describes the file system type. As discussed previously, Linux can use many file system types, including ext3, vfat, tmpfs, and others.

+   - The fourth column describes the mount options associated with the file system.

+   - The fifth column is used by the dump command to determine which file systems need to be dumped. If the fifth column is not present, a value of zero is returned and dump will assume that the file system does not need to be dumped.

+   - The sixth column is used by the fsck program to determine the order in which file system checks are done at reboot time.

The fstab file contains one entry for **/proc**. This pseudo-file system contains information about system processes, available memory, and other system information the kernel knows about. /proc is a pseudo-file system in that it does not actually use disk space on the hard drive. The typical command to mount a file system manually is **mount -t [type] [device] [directory]**. For example, to mount an ext3 file system on device **/dev/hda2** to the directory **/home**, use the **mount -t ext3 /dev/hda2 /home** command.

Mounting file systems manually is not a common occurrence, but if a temporary mount is needed, the command is available. Most mounts occur during startup with the mount -av command.
