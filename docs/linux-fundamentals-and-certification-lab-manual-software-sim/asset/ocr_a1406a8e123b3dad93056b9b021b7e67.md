# THE SYSCONFIG DIRECTORY

The /etc/sysconfig directory (Figure 8–6) contains files that control what happens when
a Linux system is booted up and shut down. This section outlines some of the files
found in this directory. A more complete list that includes options can be found in
/usr/share/doc/initscripts-version-number/sysconfig.txt.

![](bbox=[0.02, 0.56, 0.85, 0.82])

+   * apmd This file contains various parameters used in Advanced Power Management
(APM). It contains information for what power settings to start, stop, or change on
suspend or resume. The apm daemon is a monitoring program that works with power
management code within the Linux kernel. It will alert users of low battery power on
laptops and other power settings.
