
## Using GEdit

The GEdit program is a simple GUI text editor. A text editor provides a way to edit text, but it does not provide any formatting of the document. In other words, GEdit does not support boldface, italics, page formatting, and other formatting options.

To start GEdit from Mandrake Linux, select the **main menu**, **Accessories**, then **Text Editor**. From the command line, type `gedit`. The GUI GEdit window displays (Figure 5–7).

![](img/37f079cee226b270f2e09b37a2e4a05d_134_0.png)

**GEdit Screen** The window items for GEdit are as follows:

The **menu bar** contains all the commands needed to work with files. The menu bar contains the options File, Edit, View, Search, Tools, Documents, and Help. The underlined character of each menu bar item indicates the key that, when pressed together with Alt, selects that menu. The File menu is displayed in Figure 5–6.

The **toolbar** contains shortcut items that are a subset of the commands available from the menu bar.

The **display area** is the area of the GEdit window in which text is entered or edited.

The **status bar** displays information about the current edited file. For example, the status bar can contain the GEdit action being done, the line and column number of the current cursor location, and other items.

### Editing a File with GEdit
Figure 5–8 shows an open file menu. The menu allows the user to open, close, save, and perform other actions for a file. Also notice that most menu commands have a shortcut key to the right.

**Moving** around in GEdit. Use the up, down, right, and left arrow keys to place the cursor where you want. Use the Page Up and Page Down keys to go up and down a screen of text at a time.

**Open** a file by selecting **Open** from the File menu. A dialog box, shown in Figure 5–9, is displayed with existing folders in the left pane and files within the selected folder in the right pane. Navigate to the folder you want by double-clicking the folder name, select the file you want, and click the **OK** button. Alternatively, if you know the pathname of the file you want to open, just type it in the selection text box.

![](img/37f079cee226b270f2e09b37a2e4a05d_135_1.png)

**FIGURE 5-9**  
Open File dialog box.

The Open File dialog box also contains buttons to create a new folder, delete a file, or rename a file.

Save a file with the File Save menu item or the File Save As (Figure 5-10) menu item. Use the Save item if you are working on an existing file and you want to write the changes to the same file. Use the Save As item if you want to save the file with a name different from that of the current file. It is often a good idea to have multiple versions of a file saved to the disk just in case the edit didn’t go as expected.

![](img/37f079cee226b270f2e09b37a2e4a05d_136_0.png)

**FIGURE 5-10**

The Save As dialog box works the same as the File Open dialog. Use the same point-and-click options to select where the file should go, type a file name for the file, and click OK.

- **Editing** includes inserting, deleting, and modifying text.
  - You can type in new text from the keyboard. The default is to insert text at the cursor position.
  - Use the **Delete** key to delete text to the right of the cursor.
- Use the **Cut, Copy, Paste**, and **Delete** menu items on the **Edit** menu. To use these options the text must be selected. To select text, either drag the mouse across the text or place the cursor before or after the text and, while holding down the **Shift** key, use the direction keys to point to the other end of the text.

### Searching text
**Searching text** is done from the **Search** menu. The Search menu contains options to Find, Find Next, and Replace text.

- The Find dialog box (Figure 5–11) allows entry of the text to be found in the edited file.

![](img/37f079cee226b270f2e09b37a2e4a05d_136_1.png)

**FIGURE 5-11**  
GEdit Find dialog box.

- Find Next isn't a dialog box. Find Next just finds the next entry in the text file based on the value in the Find dialog box.
- The Replace dialog box (Figure 5–12) allows entry of text to be found and a second text box for entering text to replace the found text. The Replace dialog box has a Replace All option to replace all occurrences of the found text in the file.

Using a GUI is easier for novice users. Its point-and-click methods are very intuitive and easy to learn. A plus is that most GUI applications use the same keystrokes, menu bar, and toolbar entries. After you learn one program, it is much easier to learn others.

## SUMMARY

Commands are used to control all aspects of the Linux operating system. Commands allow a user to manage directories, mount and unmount file systems, manage users and groups, and manage files. The command-line shell used by default in Linux is **bash**. A command line is typically used by administrators for Linux maintenance and administration. The command-line environment is controlled by environment variables. Common environment variables identify the default path, the pathname of specific directories, and others.

All applications within the Linux operating system are executed from programs or scripts. A script is a list of commands that are executed through the control of the script.

A commonly used text editor for command-line interfaces is vi. The vi program allows a user to edit any Linux file, including binary files. Learning the vi program is essential to Linux administration. GUI interfaces for Linux abound. These offer all the features of a GUI operating system. Using the mouse for point-and-click operations is easier for novice users than using the more traditional command-line vi program.
