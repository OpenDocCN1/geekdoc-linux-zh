### Hard Disk Installation

Linux can be installed from the hard disk. To install Linux from the hard drive, the Linux ISO files must be extracted to a DOS or Windows partition and then installed on another partition on the same system. This method can be used with a high-capacity external hard drive to easily carry files from machine to machine for installation. With the availability of CD-ROMs, this option is rarely used.

### Network Installation

Installing Linux from a network provides a way to complete installation without having to carry the distribution disk from machine to machine. The disk can be stored on a network hard drive, in the same method as a hard disk installation, and accessed through NFS, FTP, or HTTP. An administrator either can boot from a floppy disk and answer the network setup questions or, on some systems, can set the computer to boot from the network drive. The network option is useful if you have many machines that must be installed because network installations can be started on several machines at once. The only disadvantage to network installation is that installing over network connections tends to be slower than installing from local media. However, with today’s fast, reliable networks, it is a viable option.

## STARTING THE INSTALLATION

You can install Linux using a GUI-based or a text-based method. Most systems work easily with a GUI-based installation, but all will work with a text-based installation. This chapter presents a text-based installation. For either type of installation, the parameters are the same. You complete a sample installation using Red Hat 9.0 using a CD-ROM distribution set. If you are using a different distribution set, the questions may be slightly different, but the details of the Linux installation are the same. The Mandrake Linux installation screens are presented here to show the similarities.

To begin the installation, insert disk 1 of the distribution set and power up the system. If it is set to boot from the CD-ROM, just wait for the welcome screen. If not, enter the setup program and change the device boot order to start from the CD-ROM. The Red Hat install screen, Figure 3–1, will be displayed, prompting you to install or upgrade using the graphical mode or the text mode. **Type linux text** and press **Enter**.

The Red Hat installation will prompt you to begin the installation, Figure 3–2, or to check the media first. Selecting the **OK** button will check the installation media to ensure that it is a valid disk. You can insert each disk of your distribution set to check all the disks. Selecting **SKIP** will continue the installation without taking the time to check the disk set. Performing a media check will take a considerable amount of time, and is not a required step.

### Virtual Consoles

The Red Hat Linux installation program gives you several virtual consoles to monitor your installation. A virtual console is another console that you can display with different types of information, as shown in Table 3–1. These virtual consoles are helpful if you encounter a problem during installation. The messages displayed on the different consoles can help narrow a problem so that it can be corrected. Usually, you need only the default console. If you have a problem, you may want to change to investigate the options. You may want to explore the virtual consoles while you are installing Linux. Use Table 3–1 to choose the console you want.

The mouse types are grouped into sections based on their hardware interfaces. Table 3–2 shows the different mouse ports. Choose the correct mouse type for your system. If you cannot find an exact match to your mouse, select a generic mouse from the list. Try to find a mouse type that is as close to your mouse as possible. Take into account the number of mouse buttons, whether you have a wheel mouse or not, and the type of port it uses.

The **Emulate 3 buttons** checkbox allows you to use a two-button mouse as if it had three buttons. The graphical interface is easier to use with a three-button mouse. If you select this checkbox, you can emulate a third, “middle” button by pressing both mouse buttons simultaneously.

Red Hat will give you an opportunity to check your mouse setup by moving the mouse on the screen and clicking buttons. If your choice does not work, you can still use the Tab and arrow keys to navigate the screen controls.

If you already have a Linux installation, you will be offered the option to upgrade. An upgrade will check the installation and then offer to let you make changes or additions. For example, if you want to include the ftp server that wasn’t installed the first time, you can load that package now. There are other ways to load a package without having to perform an upgrade. Installing packages is covered later in the text.

Selecting **Perform a new Red Hat Linux installation** will overwrite an existing installation.
