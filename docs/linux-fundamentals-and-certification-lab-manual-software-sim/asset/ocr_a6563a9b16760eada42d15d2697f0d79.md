Web browsers use HTTP, Hyper Text Transfer Protocol. HTTP is part of the TCP/IP suite of protocols, and it uses port 80 by default.

Web browsers are designed to transfer a document from a server and then translate command directives from the source code it finds. The directives are in the form of tags embedded within the code. For example, to display text in bold you could use the following: <b>text</b>. The <b> tag says to start bold and the </b> to end it.

As a Web page is downloaded from a remote server, the tags are interpreted and the commands contained within them are executed. If a command says to retrieve another document, the browser requests the new document and places it where directed by the first document.

# ## E-mail Clients

The first application available on the Internet was an e-mail program. E-mail is one of the most widely used services on the Internet. It is used to communicate business, personal, and commercial information.

E-mail most commonly uses three protocols—SMTP, POP3, and IMAP. E-mail is delivered from client to server and from server to server using SMTP. A user retrieves e-mail using POP3 or IMAP.

**SMTP** is used to send and relay e-mail. A client will connect to an e-mail server using SMTP on port 25, then send an e-mail. The e-mail server determines if the mail is local or remote delivery. If the mail is local delivery, it is stored on a local data store until the intended recipient retrieves it. If the mail is meant for remote delivery, the server passes it on to another mail server. Basic SMTP requirements are outlined in RFC 821, available from http://www.ietf.org.

**POP3** is used to retrieve e-mail from a server. A client opens a TCP connection on port 110 and then sends a request to retrieve e-mail. The server authenticates the user, then sends the stored e-mail to the client and removes the e-mail from the data store. RFC 1939 defines the basic POP3 properties.

**IMAP** is used to retrieve e-mail from a server. A client opens a TCP connection on port 143 and sends a request to retrieve e-mail. The server authenticates the user and then sends the stored e-mail to the client. The e-mail stays in the data store until the client explicitly removes it. IMAP is typically used when e-mail is accessed from more than one client; for example, if you have an e-mail program at work where you typically read e-mail, but you also read e-mail at home on a different computer. Using POP3, the e-mail would be read and then removed from the server; IMAP allows storing e-mail on the server. IMAP also allows multiple folders within the data store. RFC 2060 outlines the characteristics of IMAP.

E-mail can be retrieved from the command line; however, most users use a GUI application. The more common programs are Netscape’s Mail and Newsgroups Reader, Eudora, Mutt, and others.

All e-mail clients require the same information to read e-mail. You must have a username, password, SMTP server address, and POP3/IMAP server address.
