+   - The local X window system display for remote X clients
- The X Font server port

If you want to allow some resources while still blocking access to normal system services, choose Medium.

The **No Firewall** setting provides complete access to your system. This should be selected only if you are running on a trusted network or have a firewall on another device.

Selecting **Customize**, shown in Figure 3–19, allows you to add trusted devices or to allow incoming services. If you want most ports secured but still need certain services made available, then choose this setting.

The **Trusted Devices** options allow access to your system for all traffic from a specified device. If you have a network device to connect to your local network and a modem connection to the Internet, you can trust your local network while still disabling connections from the Internet.

The **Allow Incoming** options allow specified services to pass through the firewall. Some services are listed explicitly, but other ports can be entered. The services listed are:

+   - DHCP, Dynamic Host Configuration Protocol, is a protocol for assigning dynamic IP addresses to devices on a network.
- SSH, Secure SHell, is a suite of tools for logging into and executing commands on a remote machine. With SSH the entire session, including transmission of password, is encrypted.
- Telnet is a protocol for logging into remote machines. Telnet communications are unencrypted and provide no security.
- WWW (HTTP), Hyper Text Transfer Protocol, is used by Apache and other Web servers to send Web pages.
- Mail (SMTP), Simple Mail Transfer Protocol, allows the transmission of e-mail through the firewall. You need this protocol only if you are running a messaging server.
- FTP, File Transfer Protocol, is used to transfer files between machines on a network.
- Other Ports is a field to enter ports that you want to allow incoming services to your computer.

Red Hat Linux supports multiple languages. You must select a default language to use as shown in Figure 3–20. You can select multiple languages. If you are going to use only one language, selecting only that language will save disk space.
