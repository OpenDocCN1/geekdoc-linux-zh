Firewall.  A software package or network appliance (such as a PIX firewall from Cisco) that restricts access to specific ports, thus making the Linux operating system a more secure environment.

Foomatic.  A printer driver database used by most current Linux versions. It supplies common printer drivers, generating Adobe-compliant PPD files that allow easy setup of print queues with access to all driver options. Foomatic is an XML-based system that integrates the free software drivers with all common print spoolers.

Format.  The term that describes the preparation of a storage device for use on a computer system.

Free Software Foundation.  The principal organizational sponsor of the GNU project.

FreeBSD.  A free version of the Unix operating system, similar to Linux.

Freeware.  Software that can be freely distributed, but retains the author's copyright.

FTP.  Short for File Transfer Protocol, FTP is the protocol used to transfer files over a TCP/IP network. FTP uses port 21 for file transfer control and port 20 for file transfer data.

Gateway.  The IP address to which data can be routed to communicate with networks outside the local network.

GID.  An acronym for groupid, a unique number assigned to each group.

GNOME.  GNU Network Object Model Environment, a GUI desktop environment with a panel, a desktop, system icons, and a graphical file manager.

GNU.  Recursive acronym for GNU's Not Unix. GNU is a Unix-compatible software system developed by the Free Software Foundation (FSF). GNU software can be modified and freely redistributed.

GPG.  GnuPG is a free replacement for, and based on, PGP. It provides public-key encryption for exchanging files or messages with confidentiality and authentication.

GPL.  Acronym for General Public License. This license usually accompanies open-source software and allows the software to be copied, distributed, and modified.

Group.  A logical grouping of users and resources.

GRUB.  Acronym for GRand Unified Boot loader.

GUI.  Acronym for Graphical User Interface.

Hardware.  The physical portion of a computer system.

Hostname.  The common name of the local host.

Hosts.  Devices that are connected to a network and are identified by a unique value that allows communication over the network.

HTTP.  HyperText Transfer Protocol, a protocol used to request and transmit files over TCP/IP networks. It uses port 80.

Hub.  An OSI model physical layer device that is used to connect multiple hosts to a network.

IETF.  Internet Engineering Task Force.

IMAP.  Internet Message Access Protocol, a protocol used to receive e-mail. IMAP is similar to POP3, but supports additional features. It uses port 143.

IP Address.  An address assigned to every host on a TCP/IP network, consisting of a 32- bit number expressed as four decimal numbers separated by decimals. For example, 192.168.0.1 is an IP address.

iptables.  A Linux program used to enable packet filtering, network address translation (NAT), and other packet manipulations.

IPsec.  Strong cryptography that provides both authentication and encryption services.

IRQ.  Short for Interrupt ReQuest, an IRQ sends an interrupt signal to the CPU to indicate that a device needs to execute a task.
