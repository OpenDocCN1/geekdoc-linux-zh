The if Statement &nbsp;&nbsp;&nbsp;&nbsp;The syntax of an *if* statement is **if [***expression***]; then *statement* [***else statement***] ***fi*** where *expression* is a *Boolean* expression and *statement* is the shell command to perform. Notice the end of the command is *fi*. Some command structures end with the same word they start with, spelled backward.

The *bash* shell has several conditional expressions that can be used. Conditional expressions can be used to compare strings (words), numbers, or files. Some of the most commonly used are:

+   * `=` &nbsp;&nbsp;&nbsp;&nbsp;Are two strings equal?
* `<` &nbsp;&nbsp;&nbsp;&nbsp;Is the first string less than the second string?
* `>` &nbsp;&nbsp;&nbsp;&nbsp;Is the first string greater than the second string?
* `!=` &nbsp;&nbsp;&nbsp;Is the first string not equal to the second string?
* `-eq` &nbsp;Is the first arithmetic value equal to the second arithmetic value?
* `-ne` &nbsp;Is the first arithmetic value not equal to the second arithmetic value?
* `-lt` &nbsp;Is the first arithmetic value less than the second arithmetic value?
* `-le` &nbsp;Is the first arithmetic value less than or equal to the second arithmetic value?
* `-gt` &nbsp;Is the first arithmetic value greater than the second arithmetic value?
* `-ge` &nbsp;Is the first arithmetic value greater than or equal to the second arithmetic value?

The simplest *if* command compares two values and then does an action. For example, if you wanted to accept a name from the command line and display either Good Morning or Good Afternoon and the name, you could use the following script:

```
```bash
#!/bin/bash
if [ $(date + %H) -lt 12 ]; then
    echo Good Morning $1
else
    echo Good Afternoon $1
fi
```
```
