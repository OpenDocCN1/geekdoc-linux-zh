# ## Network Problem Isolation

To identify network problems, you follow the network layers, identifying what is expected at each layer. The first check should be of the physical layer. This is the hardware and signaling component of the network.

You need some special equipment to help isolate physical layer components. The first is a cable tester (Figure 13-9). A cable tester will check that the cable is assembled correctly and check the length of the cable. Some network testers will even draw a diagram of the network.

A second piece of equipment that will often prove invaluable is a crossover cable. Most patch cables used with an Ethernet network are wired straight through. In other words, the wire connected to pin 1 on one end is connected to pin 1 on the other end, and so on. A crossover cable reverses the transmit and receive wires so that two computers can be connected directly together.

A few standards must be adhered to. The first has to do with the length of 10BASE- T UTP cables and is called the **5-4-3 rule**. A signal traversing a length of cable is delayed before it reaches the other end. A 100 m trip delays the signal about 0.55 microseconds. What this means is that a signal on an Ethernet 10BASE-T UTP cable is rated to work at 100 m. Anything past that length is too attenuated to work reliably. However, the cable run can be lengthened by using a repeater. A repeater boosts the signal and sends it down the next network segment of up to 100 m. Besides the delay of sending a signal down a line, there is also some repeater delay. Because of this the 5-4-3 rule says that no more than 500 m total length can be used, with a maximum of 4 repeaters, and that no more than 3 of the segments should have hosts on them.

If everything is correct at the physical layer, then the data-link layer, layer 2, can be checked next. The data-link layer uses the host device's MAC address to communicate within a network segment. Switches work at the data-link layer. They pass along connections based on the destination of the packets coming in to the system. Without MAC addressing, hosts on the network could not be uniquely identified.

Protocols, such as DHCP, use the layer 2 MAC address to communicate. Layer 2 connections are used within a single network segment. In other words, if you are on network 192.168.0.0 and another machine is on network 192.168.1.0, the two machines cannot communicate directly because they are on two different segments.

The network layer, layer 3, is a routable layer. This means that data at the network layer can be sent to other network segments. The network layer uses IP addresses to communicate. Information is sent from one network segment to another through a router. A router is a layer 3 device. Routing problems can prevent network information from reaching the destination host.

The transport layer, layer 4, is the layer that TCP works at. TCP establishes a connection with a remote host to transfer information. Problems at this layer can cause connections to be unsuccessful.

The session (layer 5), presentation (layer 6), and application (layer 7) layers are maintained within applications. Problems at these layers are within the applications and can usually be resolved by reinstalling or reconfiguring the programs.
