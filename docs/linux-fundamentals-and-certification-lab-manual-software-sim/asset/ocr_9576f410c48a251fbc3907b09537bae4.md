+   - Use the **Delete** key to delete text to the right of the cursor.
- Use the **Cut, Copy, Paste**, and **Delete** menu items on the **Edit** menu. To use these options the text must be selected. To select text, either drag the mouse across the text or place the cursor before or after the text and, while holding down the **Shift** key, use the direction keys to point to the other end of the text.

**Searching text** is done from the **Search** menu. The Search menu contains options to Find, Find Next, and Replace text.

+   - The Find dialog box (Figure 5–11) allows entry of the text to be found in the edited file.

+   - Find Next isn't a dialog box. Find Next just finds the next entry in the text file based on the value in the Find dialog box.
- The Replace dialog box (Figure 5–12) allows entry of text to be found and a second text box for entering text to replace the found text. The Replace dialog box has a Replace All option to replace all occurrences of the found text in the file.
