# Desktop Environments

Desktop environments provide an environment similar to Windows or Mac OS. A GUI interface makes using a computer for productivity much easier and much more feature-rich. The command-line interface is great for a Linux installation that is used as a server. Many, if not all, of the server functions are configured and run from the command line. Using a GUI for the same work unnecessarily uses additional resources on the system just to provide a more user-friendly environment. Using the GUI interface on a server can cause poor performance of any server software.

A GUI is a great tool for any user of the Linux operating system. Its point-and-click environment makes selecting tasks for the operating system easy. There are two predominant desktop environments for Linux—GNOME and KDE.
