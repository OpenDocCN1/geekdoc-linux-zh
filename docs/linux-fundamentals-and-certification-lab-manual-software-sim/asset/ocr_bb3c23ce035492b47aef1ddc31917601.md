With the file manager (Figure 10–14), you can view and manage files and folders. You can run scripts from the file manager by double-clicking the script’s filename. The file manager window contains the following:

+   * **Side pane** enables you to navigate through your files. It displays information about the current file or folder.
* **View pane** displays the contents of files and folders.

To open files from the file manager, navigate to the folder that contains the file. Double-click the file to open it. Right-click the file manager to open the shortcut menu (Figure 10–15) with Open, Copy File, and other options.

If you want to copy a file, navigate to the folder that contains the file, right-click the file to display the shortcut menu, and select **Copy File**. Navigate to the folder to which you want to copy the file and right-click an empty spot on the file manager to display the shortcut menu. Select **Paste Files** from the shortcut menu.

You can move a file by navigating to the folder that contains the file. Right-click the file to display the shortcut menu and select **Cut File**. Navigate to the folder to which you want to move the file. Right-click an empty spot on the file manager to display the shortcut menu and select **Paste Files**.
