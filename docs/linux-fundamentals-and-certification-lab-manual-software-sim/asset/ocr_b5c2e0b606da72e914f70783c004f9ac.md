# ADMINISTRATIVE TASKS

**The case Statement** Another type of conditional statement is the case statement. The syntax of the case statement is **case word in <pattern | pattern | ...> statement ;; ... esac** where word is a value to be matched in the list of patterns, pattern is a list of values to be matched against, and statement is the list of shell commands to be executed.

The case statement performs a series of commands based on a value match in a list. For example, if you wanted to display the number of days in a month, you could use a case statement as follows:

```
```bash
#!/bin/bash
case $1 in
January|March|May|July|August|October|December)
    echo $1 has 31 days;;
April|June|September|November)
    echo $1 has 30 days;;
February)
    # The let statement starts an arithmetic expression
    let VAL1=$(date + %Y)%4
    if [$VAL1 -eq 0]; then
        echo $1 has 29 days
    else
        echo $1 has 28 days
    fi;;
esac
```

```

This is the most complicated script yet and deserves a more detailed explanation. The overall case structure begins with the keyword **case** and ends with **esac** (case spelled backwards).

Commands within the case structure are indented. This is the convention and should be followed. Indenting commands within structures makes the script much more readable and easier to follow. The same indentation was applied to the if structure as well.

The second line, case $1 in, tells the case conditional that the value to be evaluated is taken from the first command line argument and is evaluated in the list that follows.

The third, fifth, and seventh lines provide the values to be evaluated for each set of shell statements to be executed. In this case, if the value of $1 is found in a list line, then the statement(s) following the list are executed. Each list terminates with a closing parenthesis.

The statements following the list lines are shell command lines. The last command to be executed is terminated with two semicolons. The semicolons indicate that this is the end of the list/command entry.

The line **# The let statement starts an arithmetic expression** is a comment line. Comment lines begin with a pound sign (#). These statements are ignored by the shell script. Comments should be used to document what is happening in a script. Comments should be concise and meaningful.

The line **let VAL1=$(date + %Y)%4** is an arithmetic statement. The $(date + %Y) should be familiar; it returns the year in the format yyyy. The % before the 4 is an arithmetic operator that says to do remainder division. This statement says to take the year and divide it by 4, giving the remainder. If you divide the year by 4 and get 0 as a reminder, that year is a leap year.

Conditional statements are necessary to control the flow of logic through a script. Another useful thing that a script does is to allow code to be repeated. To repeat code you need a loop construct.
