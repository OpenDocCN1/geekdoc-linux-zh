Partition sizes vary depending on the system use. The most common partitions include:

+   - /home  Contains individual user files. The size of /home depends on how many users you have and the type of data that they store.
- /usr  Contains Linux program and data files. This is typically the largest partition on a multipartition system.
- /usr/local  Contains Linux programs and data that is unique to the installation.
- /opt  Contains Linux program and data files associated with third-party applications. These are usually commercial applications.
- /var  Contains files that are often transient in nature. A mail queue, for example, would be stored here. Mail queues change in size depending on daily mail usage.
- /tmp  Holds temporary files. These are usually removed during system restart, or periodically via a routine automated task.
- /mnt  Used as mount points for removable media, such as CD-ROM and floppy drives.

Some directories contain Linux configuration files and should not be placed on separate partitions. These directories are */etc/, */bin, */sbin, */lib, and */dev. The */etc directory, for example, contains the initab configuration file, which contains startup and shutdown information, the password database, and most software configuration files.

# SUMMARY

Your installation budget should provide for the cost of hardware, software, support, personnel, training, and communications. In many cases you can use pre-existing hardware to reduce the overall cost.

There are four types of installations:

+   - Embedded Linux is used for proprietary systems that are employed to do a limited number of tasks.
- Personal desktop installations are designed for the home user and provide personal productivity, games, and GUI desktop environments.
- Workstations are the business end of personal desktops and generally would include development and graphic software as well as applications found on personal desktops.
- Servers provide services for clients. This relationship is called client/server. Services include:

+   - Network services  such as DNS, DHCP, routing, firewall, ipchains, squid, and ftp.
- Database services  with software such as Oracle or MySQL.
- Web services  with software such as Apache Web server to provide Web content to clients on an intranet or the Internet.
- File services  to provide a central repository of data.
- Messaging services  to provide e-mail access.

Enterprise servers provide the same services as a server while maintaining high availability. Enterprise servers typically support:

+   - Shared storage  for all machines participating in the server cluster.
- Service failover  that allows restarting an application that has failed.
- IP load balancing  to allow a request to be serviced across many servers.

Linux installations are flexible when it comes to hardware. All Linux distribution sets have a list of tested hardware that will ensure the success of the installation. These lists include CPUs, memory, video adapters, hard drives, network cards, modems, and other commonly used hardware.
