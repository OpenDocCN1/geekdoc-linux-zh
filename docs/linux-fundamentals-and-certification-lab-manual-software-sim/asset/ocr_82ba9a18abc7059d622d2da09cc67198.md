# Konqueror File Manager

The KDE Konqueror File Manager is more than just a file manager. It is also a Web browser and a universal viewing application.

As a file manager, Konqueror provides all the features of any file manager program. It supports cut, copy, and paste; local file browsing, remote file browsing, and file launching.

As a Web browser, it compiles with HTML 4.0. It supports Java applets, JavaScript, CSS1, CSS2, and Netscape plugins.

As a viewing application, Konqueror will display the contents of many types of files: Clicking on an image will display an image; clicking on a text file will display its contents.

To start Konqueror (Figure 10–23), you can double-click the Home icon on the desktop, or click the Home icon from the icon bar.

To copy and paste a file, simply navigate to the folder that contains the file you want to copy. Right-click the file to display the shortcut menu (Figure 10–24) and then select **Copy**. Navigate to the folder that you want to copy the file to, right-click an empty spot on the file manager to display the shortcut menu, and select **Paste Files** from the shortcut menu.
