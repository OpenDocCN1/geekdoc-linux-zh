The download files are often identified as i386, i586, PPC, Alpha, or Sparc. This is because each Linux distribution set has to be designed for a particular hardware platform.

+   * i586 and i386 refer to systems with Intel processors. These are commonly known as personal computers (PCs) and often are already equipped with the Windows operating system.
* PPC refers to Power PC systems from Apple Computer Corporation.
* Alpha refers to Digital Equipment Computer (DEC) systems.
* Sparc refers to systems from Sun Microsystems.

Using an Internet browser you can click the link with the ISO image name you want to start the download. Even though you click a HTTP link, the download is done using the FTP protocol. Most browsers support both protocols. Some browsers, such as Mozilla, will allow you to resume a download if it is interrupted. Being able to resume a download is a huge time saver, especially if you are using a slower connection. You will be prompted for a download location within your local file system. Usually, you can navigate with a GUI interface to find a directory to store your download. Make sure you have enough space to store the downloaded files.

If you have a CD-ROM burner you can write the disk images to a CD. You can then use the CD to install the Linux operating system on your system. There are iso extracting programs that allow you to extract the contents of the ISO to a Windows directory on the hard disk. After the ISO is extracted, you can do the install from the disk.

+   * You can copy or borrow a distribution set from someone. Remember, one of the great things about using Linux is that the software is free to copy and distribute. If you borrow a disk you should make a copy of it in case you need the disk again. Your system could be damaged by a power surge, an accidentally deleted file, or some other unforeseen catastrophe, requiring re-installation or updating of the operating system.

# THE LINUX KERNEL

The Linux kernel can be upgraded similar to any other program in the Linux distribution. (Refer to Chapter 2 to review Linux kernel features.) The kernel is constantly being upgraded by a team of hundreds of developers. When a new kernel is introduced the Linux installation can use it to access newly introduced features. Upgrading a Linux kernel is often done through automatic installation scripts. Some administrators prefer to compile their own kernels from the source code. This should be done only by the most experienced Linux users. Official kernel sources can be obtained from http://www.kernel.org.

There are some advantages to compiling your kernel. If you compile your own kernel you can optimize it for your particular CPU. If your system requires custom drivers, these drivers can be compiled within the kernel; unnecessary drivers can be removed. This will further optimize the system and promote better performance. Patching the Linux kernel is discussed in Chapter 12.

> **NOTE**

A driver is a program that controls a device. Every device used by the operating system must have a driver. Devices include keyboards, mice, video cards, and other input, output, or storage devices. A driver acts as a translator between the device and the programs that use it. In Linux operating systems device drivers are either part of the kernel or loaded as separate programs.
