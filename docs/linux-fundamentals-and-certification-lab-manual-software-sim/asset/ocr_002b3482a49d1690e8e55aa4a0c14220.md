# ## Appendix B
## Discussion Questions

Throughout this book, you've learned about the various flavors of Linux. You've also learned all the tasks that you can do with the Linux operating system. The following discussion questions will help you further your knowledge and understanding of Linux.

# ■ DISCUSSION, CHAPTER 1

+   1. Discuss the GNU/GPL software license.
2. Compare and contrast three different package management systems.
3. List and explain three different Linux system features.
4. Discuss support options available for the Linux operating system.

# ■ DISCUSSION, CHAPTER 2

+   1. Discuss common partitions and why you would use them.
2. Discuss hard drive controllers, the types of controllers available, and the characteristics of those most commonly used.
3. Discuss network services; select five.
4. Contrast and discuss the different Linux installation types.
5. Suppose that you wish to install Linux for personal use at home. What types of budgetary concerns should be addressed? Take into account both hardware and software.

# ■ DISCUSSION, CHAPTER 3

+   1. List the values that should be documented from a Linux installation.
2. Identify three different sources to obtain a Linux distribution.
3. Explain what it means to compile your own kernel. Explain why you would compile the Linux kernel.

# ■ DISCUSSION, CHAPTER 4

2. Discuss runlevels in the Linux operating system. How do you change the default runlevel?
3. Discuss the properties of a strong password.
