One environment value that users often change is **PROMPT_COMMAND**. Just before bash prints each primary prompt PROMPT_COMMAND is checked for a non-null value. If it has an assigned value it is executed the same as if it had been typed on the command line. For example, to display the date and time before each prompt, enter the **export PROMPT_COMMAND=date** command, and the date and time will display before each prompt:

```
[jsmith@Styx jsmith]$ export PROMPT_COMMAND=date
Thu Sep 18 22:25:55 CDT 2003
[jsmith@Styx jsmith]$
```

The primary can be changed by changing the value of **PS1**. PS1 is an environment variable that stores the value of the shell prompt. It does not appear in the output of the env command. In the Red Hat Linux implementation of bash the default prompt displays as follows:

```
[jsmith@Styx jsmith]$
```

The PS1 value for this prompt is
$PS1 = "\u@\h\W\$"$

Special characters such as **\u** or **\h** are used to display environment variables within the prompt. In the prompt, **\u** represents the user and **\h** represents the hostname. Some of the available prompt variables include:

+   \d The date in “day month date” format
\h The hostname, up to the first ‘.’
\H The hostname
\l The base name of the shell’s terminal device name
\n A new line
\r A carriage return
\t The time in 24-hour format
\T The time in 12-hour format
\@ The time in 12-hour am/pm format
\u The username of the current user
\w The working directory
\W The basename of $PWD
\$ If the UID is 0, display #, otherwise display $

The PROMPT_COMMAND and the PS1 value assignment can be included in the .bash_profile to set the values when the user logs in.

# ## Execution of Scripts and Programs

All programs and scripts that run from the command line have a similar command syntax: First the command (program) name, followed by options and then arguments. For example, to list all the files that end with **.conf** type `ls -1 *.conf` where `ls` is the command, `-1` is an option, and `*.conf` is an argument.
