The access permissions are arranged in three groups of three permissions each. For example, the previous listing shows that the file newfile has permissions `-rw-rw-r--` indicating that the owner has read/write permissions, the group has read/write permissions, and others have read permissions. The script may have permissions of `-rwxr-xr-x`, indicating that the owner has read/write/execute permissions, and the group and others have read/execute permissions.

The three values, rw x, form an octal value for each permission group. A one in a permission position indicates that it is active and a zero indicates that it is not. For example, a file with read and write permissions would have the value `rw`. The values can be replaced with ones and zeroes as **110**. This forms an octal value of 6. Every combination of read/write/execute values can be replaced with an octal value (Figure 12–18).

The permission value of a file is changed with the `chmod` command. To set permissions for the owner to read/write/execute, the group to read/execute, and others to read/execute use the value 755. The command to set newfile to 755 is `chmod 755 newfile`.

Listing the new file, as shown in the following, shows that the permissions have changed.

```
$ ls -l newfile
 -rwxr-xr-x 1 jsmith jsmith 30 Nov 16 15:00 newfile
 $
```

The default value of a file can be set with the `umask` command. The umask, or user mask, is an octal value that is used as a bit mask for values of 777 for directories and 666 for files. The value 777 gives the permission set of rwxrwxrwx for directories and rw-rw-rw for files. As a binary value, directories are 111-111-111 and files are 110-110-110. The umask value is used to replace any bit positions that have a value of one with a value of zero. The default umask is 002. Expressed as a binary value, this is 000-000-010.
