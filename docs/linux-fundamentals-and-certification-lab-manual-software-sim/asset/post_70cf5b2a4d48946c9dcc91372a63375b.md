
## Linux Overview

Linux users are not your run-of-the-mill computer nerds. With new versions of the **graphical user interface** (GUI), a way to interact with the operating system by pointing-and-clicking graphical representations of programs or commands with a mouse, many home users are opting for Linux over the more popular Windows operating system. The biggest reason is the cost. Linux can be obtained free. Since its creation by Linus Torvalds in 1991, its source code has been made available free of charge to anyone that wants to use it. The only restriction is that revisions be made available to all users.

To say that Linux is free does not necessarily mean without charge. As the **Free Software Foundation** (FSF), the principal organizational sponsor of the GNU Project, puts it, “You should think of ‘free’ as in ‘free speech’, not as in ‘free beer.’” Many businesses using Linux today are running a distribution that was purchased and comes with some level of support. Free Linux software affords you the right to freely make changes to the software to suit your needs and a copy of the source code to accomplish the task. Companies and developers may charge for their products as long as the source code remains available. Many companies are developing and distributing versions of Linux for a wide range of markets. The Red Hat Linux version, for example, not only provides a version for home users and SOHO (small office/home office) users, but for enterprise-wide servers as well. Red Hat Linux is discussed in more detail later in this chapter.

### Note

> Red Hat Linux Project merged with Fedora Linux to form the Fedora Linux Project. The new organization will be responsible for development of a completely open-source version of Linux with support and sponsorship from Red Hat Linux. Red Hat Linux will concentrate on their enterprise version of Linux.

Home versions of Linux can be downloaded from many sites and the only charge is your time. To obtain technical support, you can register your distribution, pay a small fee, and have access to support resources from the distribution provider.

### Note

> Many Linux installations do not have formal support; however, that does not mean support is not available. The Linux operating system community is an unusual group, providing not only free software, but also free support. For example, there are many free usenet groups (a worldwide bulletin board system that can be accessed through the Internet), document Web sites, Linux groups, and other forums where questions can be posed and responded to by professionals in the industry. Many of these support features are discussed in Chapter 12.

Linux is **open-source software** using the **GNU/GPL** (General Public License), the license that accompanies some open-source software that details how the software and its accompanying source code can be freely copied, distributed, and modified. More information about open-source software can be found by visiting www.opensource.org/docs/definition.php. Open-source software complies with the following criteria:

- **Free redistribution.** The license does not restrict anyone from selling or giving away the software. The license shall not require a royalty or other fee for such sale.
- **Source code.** The program must include source code and must allow distribution in source code as well as compiled form.
- **Derived works.** The license must allow modifications to the software and allow the modifications to be distributed under the same license as the original software.
- **Integrity of the author's source code.** The license can restrict distribution only if “patch files” will be made available.
- **No discrimination against persons or groups.** The license may not discriminate against any person or group of persons.
- **No discrimination against fields of endeavor.** The license must not restrict anyone from making use of the program in a specified field of endeavor.
- **Distribution of license.** The license must apply the same to all persons automatically, without the need of signing or otherwise acknowledging the license.
- **License must not be specific to a product.** The license terms may not be contingent upon the program being part of another product.
- **No contamination.** The license must not contaminate other software licenses by placing restrictions on other software distributed with the product.

In contrast, a closed-source license is designed to protect the source code and distribute only the binary version of the program.

Other software licenses fall somewhere between open- and closed-source licenses. Some examples include:

- **Public domain.** Public domain software is given freely by the author without copyright or license. As such, there are no restrictions on its use.
- **Freeware.** Freeware is software that is free to use, but not necessarily free to modify and not necessarily open source.
- **Shareware.** Shareware is software that is distributed freely, but the author requests payment for its use. Usually, shareware is available to use for free but with some restrictions in functionality unless the full version is purchased.
- **Artistic license.** An artistic license allows the author to maintain some semblance of artistic control over the development of the package, while giving the users of the package the right to use and distribute the package in the customary fashion and to make reasonable modifications.

> Another license, **FreeBSD**, is also commonly used within the Linux community. BSD is short for Berkeley Software Distribution and FreeBSD is a version of Unix developed by BSD. FreeBSD does not use the Linux kernel as a basis of its operating system, but most applications developed to work under FreeBSD will also work under Linux. The FreeBSD license is more versatile for developers when compared to the GNU/GPL. For example, FreeBSD does not require that the source code be distributed with the software.

Linux has become popular over a relatively short period of time. Literally thousands of programmers have an active role in developing Linux. As of today, there are hundreds of ongoing projects with Linux and various hardware and purposes.

### Unix Background

As mentioned earlier in this chapter, Linux is similar to the Unix operating system. The Unix operating system, originally Unics for UNiplexed INformation and COmputing System, was initially designed for DEC’s PDP-11 computer system. For the first 10 years Unix was solely in Bell Labs domain until it was ported to the VAX (Virtual Address eXtension, which is DEC’s successor to the PDP-11 minicomputer). Many improvements have been made to Unix, making it one of the most widely used operating systems for servers. Unix, similar to the newer Linux, requires very little in the way of resources while providing much in the way of services. Later versions of Unix provide many of the same capabilities as the current Windows operating system.

Most Linux commands are exactly the same as their Unix counterparts, so if you want experience with Unix, Linux is a good, inexpensive solution. Many colleges and universities teaching Unix are actually using Linux to do so.

### Linux for Windows Users

If you are a Microsoft Windows user you can use Linux with ease using the GUI. There are several GUIs for Linux, most of which provide the look and feel of a Windows desktop. Linux can read and write to Windows formatted disks, and many programs in Linux emulate their counterparts in Windows applications. You can, for example, read a Microsoft Word document in OpenOffice.org for Linux, make changes, and save it back to a Word format for use on a Windows system. (Not all Word features are supported.)

Of course, the Linux GUI is much more versatile than its Windows counterpart. For example, the Linux GUI is provided through an implementation of the X windowing system, which provides multi-user access, multiple virtual desktops, and other features. The X window system is discussed in Chapter 8.

Linux has its own set of applications, and more and more vendors are porting their applications to the Linux platform. You can find evidence of this from software vendors such as Oracle, Sun Microsystems, and IBM. IBM is especially vocal in their support for the Linux operating system and has contributed significantly to Linux development and support. IBM has many software solutions designed for Linux, including accounting, commerce, finance, and retail applications. The IBM Web site lists over 3,000 independent software vendors that deliver a wide range of Linux applications to many industries. To see what kind of support some of these software and hardware giants are providing, check out the following Web sites:

Linux means freedom for the user. You are free to choose your own Web browser. You are free to report errors whenever you want, not automatically by the operating system. You are free from applications making changes to your Internet protocols. You are free from running a GUI if you don't need it. You are free to make changes to your operating system to fit your needs.

## Reasons to Use Linux

Linux provides many advantages over other operating systems. For example, suppose you have a 486 or older Pentium system. If you are using Windows, you probably will find the system useless for most of today's applications. However, Linux can breathe life into the old system by giving it useful work in a number of ways. You can use Linux on an old system to provide basic services, such as DHCP, packet routing, ftp, and other applications that are a nightmare to establish on other operating systems.

The current version of Windows can cost over $150. Linux will only cost the time and effort spent downloading, then installing the software. You can also buy versions of Linux. The cost is still minimal when compared to other operating systems. The advantage of purchasing Linux is the provided technical support and the printed documentation. The Linux distribution from SuSE (covered later in this chapter) is especially well known for the excellent printed material supplied with the distribution.

Most Linux distributions include not only the operating system, but a comprehensive set of applications for personal and professional uses. Applications usually include word processing, spreadsheet, calendar, presentation, database, and many others. Office applications for a comparable Mac OS or Windows-based system can cost hundreds of dollars.
