# KDE Control Center

The KDE Control Center (Figure 10−25) is a GUI program that enables a user to change properties of the desktop. It allows a user to change the colors, screensaver, and other properties.

![](bbox=[0.08, 0.15, 0.88, 0.46])

To start the KDE Control Center, select the **Application Starter**, the **Configuration** menu item, and the **Control Center** entry (Figure 10−26). The Control Center is displayed.

![](bbox=[0.08, 0.53, 0.87, 0.85])

From the Control Center, you can change properties for most KDE programs.

+   *   **Accessibility** Includes properties for seeing- or hearing-impaired users, country settings, keyboard layout, and keyboard shortcuts.
*   **Components** Properties for several items, including:
    *   **File Associations** This enables you to determine which files work with which extensions.
    *   **Service Manager** Allows starting and stopping services.
