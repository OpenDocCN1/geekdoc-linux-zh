more information may be saved to disk. A soft limit allows users to exceed their limits with only a warning. The soft limit should be less than the hard limit so that a user receives a warning before completely running out of space.

The Linux operating system on most distributions will automatically install the quota application and its utilities. The quota tool displays a user's disk usage and limits. The quota application uses the /etc/fstab, /home/quota.user (created if needed), and /home/quota.group (created if needed) files as configuration and data files for the quota system.

# Configuring for Quotas

Configuring the Linux operating system to use quotas involves several steps. The first step is to change the mount options for the file system that will have quotas applied. In order to set quotas for users, you must add the option usrquota to the file system to be configured. To set quotas for a group, add the grpquota option to the file system.

The /etc/fstab file, discussed in Chapter 8, contains the file system mount information. The following display of this file shows the change made to the /dev/hda3 file system. The usrquota option is added. To add the option for group quotas, just add the grpquota option to the line.

```
# cat /etc/fstab
LABEL=/              /                 ext3    defaults              1 1
LABEL=/boot           /boot             ext3    defaults              1 2
none                  /dev/pts          devpts  gid=5,mode=620        0 0
/dev/hda3             /newDrive         ext3    defaults,usrquota     1 2
none                  /proc             proc    defaults              0 0
none                  /dev/shm          tmpfs   defaults              0 0
/dev/hda5             swap              swap    defaults              0 0
/dev/cdrom            /mnt/cdrom        udf,iso9660 noauto,owner,kudzu,ro 0 0
/dev/fd0              /mnt/floppy       auto    noauto,owner,kudzu    0 0
/dev/cdrom1           /mnt/cdrom1       udf,iso9660 noauto,owner,kudzu,ro 0 0
#
```

After the file system is prepared you must have a quota database in the file system's root (/) directory. After the database is used by the quota system, it is not in a human-readable format. All you have to do is create an empty file to be used. Create the empty file with the touch command. The database name for user quotas is **quota.user**, and the name for group quotas is **quota.group**. The `touch /newDrive/quota.user` command creates the quota.user file in the /newDrive (/dev/hda3) root directory.

To add entries to the quota.user file just created, use the **quotacheck** command. The quotacheck command examines each file system, builds a table of current disk usage, and compares the table against that recorded in the disk quota file for the file system. If there is a discrepancy, the quota file is updated. By default user quotas are checked. Use the `man quotacheck` command for a complete list of options. Some of the more common options include the following:

+   - **-v**   Causes a verbose output of the command.
- **-a**   Says to check all mounted non-NFS file systems.
- **-u**   Causes quotacheck to explicitly check user quotas.
- **-g**   Causes quotacheck to explicitly check group quotas.

To have quotacheck check all file systems' user quotas (the default) and give a verbose listing, use the following command:

```
# quotacheck -av
quotacheck: Scanning /dev/hda3 [/newDrive] done
quotacheck: Checked 6 directories and 18 files
#
```
