+   * ping  This command determines whether an IP address is accessible and the network is functioning properly. ping uses the Internet Control Message Protocol (ICMP) defined in RFC 792 (http://www.ietf.org/rfc/rfc0792.txt#number=792, Internet Control Message Protocol RFC 792).

One of the first things a cracker will do in order to plan for an attack is map a network. Recall from Chapter 12 that the Echo Reply can be disallowed by a firewall. Many organizations block the ping command to keep unauthorized users from gaining information about their network.

ping can be used to ping an IP address or a host name. When using ping for troubleshooting, you should use the localhost address, 127.0.0.1, to determine that the network interface is up and running. Several options are available. Some of the more interesting are listed as follows:

+   -a  An audible ping.
-  Allows pinging a broadcast address.
-c <count>  Allows sending count number of ECHO_REQUEST packets.
-v  Verbose response.
-q  Quiet output. Only the summary lines are displayed.

+   * traceroute  The traceroute program attempts to trace the route an IP packet follows to a remote host. traceroute uses the Internet Control Message Protocol (ICMP) defined in RFC 792.

traceroute depends on the common router practice of sending an ICMP time exceeded message back to the sender. It uses a small TTL (time to live) value, which quickly expires. traceroute causes routers along the packet's path to generate ICMP messages that identify the router. Again, a firewall can block an ICMP response.
