Within the **/var/log** directory you see several files and corresponding numbered files. The files that have descriptive names, such as **messages**, are current log files. As events occur, these files will be updated immediately. The numbered files are log rotation files. Log rotation is necessary to ensure that log files do not continually use more and more disk space. Log files, if left unchecked, will grow until there is no more disk space. Most files are set to rotate four times. A log file with a .4 after its name is the oldest log file of that type on the system. The **/etc/logrotate.conf** file is used to configure when log files are rotated. A cron job bash script, **logrotate**, is used to start the log rotation.

> NOTE
Log information is listed in date/time order. The most recent entries are at the end of the file.

> NOTE
The daily cron jobs are located in the /etc/cron.daily directory. Use the `file *` command to see what type of files are located in the directory. Most are bash script files and can be edited with any text editor.
