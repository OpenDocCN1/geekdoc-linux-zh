+   5. Enter the **User Name** provided by the ISP or e-mail administrator. Click **Next> **to display the Account Name dialog box (Figure 7-29).
6. Account Name is a title for this mail configuration. You can have multiple mail configurations. Type in the text you want to use to identify this configuration and then click **Next**. The Congratulations dialog box is displayed (Figure 7-30). You are not finished yet. The outgoing SMTP server still has to be configured.
7. After reviewing the options you selected click **Finish**. The e-mail client program should be displayed (Figure 7-31).
8. To configure the outgoing SMTP server, select the **Edit** menu and then **Mail & Newsgroups Account Settings**. Select the account you just configured and the account settings will be displayed to the right (Figure 7-32).
9. Fill in the outgoing Server Name, Port, and **User Name**. The port, by default, is **25** for SMTP services. Click **OK**. Now you’re done.
