Service configuration from GNOME.

The GUI screen, from GNOME on Red Hat Linux, is displayed from the main menu by selecting **System Settings, Server Settings, Services**.

To stop unwanted services you can use the service _<service_name>_ stop command where _service_name_ is the name of a service, such as sshd or cupsd. However, this command works only for this session, and after the system is rebooted, the service will restart. A better method is to use a configuration tool that comes with your Linux distribution. Most systems use **linuxconf**, whereas some have their own proprietary tool. Whatever tool you use, the same information is displayed: a list of services and an indicator to enable or disable the service. Figure 12–11 shows the use of the setup tool from Red Hat Linux, invoked with the **setup** command.

On the Services screen (Figure 12–12), use the arrow keys to move up and down the services list and use the space bar to select/deselect services. When finished, use the Tab key to select the OK button and press the space bar. You may need to research what the services are and what they do.
