The next prompt, shown in Figure 3–5, asks what type of keyboard to use. Red Hat will auto-detect your keyboard type and leave it to you to confirm its choice. Almost all keyboards will work as US keyboard. Select your keyboard type, and again tab to the OK button to select it.

> **NOTE**

You can change your keyboard layout after the installation by selecting the Keyboard Configuration Tool. From a shell prompt you can type **redhat-config-keyboard** to launch the tool. You must be root (the name of the super user account) to run any configuration tool. If you are not logged in as root you will be prompted for the root password.

You will be prompted for the mouse configuration next, shown in Figure 3–6. Again, Red Hat will auto-detect your mouse.
