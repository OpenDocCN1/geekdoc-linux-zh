Linux supports most of the features found in Unix installations. It’s a multitasking, multiuser, and multiprocessor operating system. Linux also supports many file systems including its own ext3, which offers sizes up to 4 TB. It also supports a wide variety of networking protocols.

Package management programs are used by all Linux distributions to install, uninstall, and update software packages. The most popular package programs are RPM, DEB, TAR, and SLP.

Support is available from Internet news groups, online documentation, and private companies.
