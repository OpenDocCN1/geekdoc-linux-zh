The third set of three characters represents the permissions assigned to everyone else, that is, anyone that is not the owner and that does not belong to the group.

# ## Types of Permissions

Every file or directory has a set of permissions that determines who can access and what they can do to the file. Permissions are represented by the characters r, w, and x, which represent read, write, and execute, as seen in Table 4–1. The permissions are slightly different when assigned to a file or a directory.

Table 4–1

Permissions.

| Permission | Symbol | File Usage | Directory Usage |
| :--- | :--- | :--- | :--- |
| Read | r | File can be displayed or copied. | Directory can be listed with the ls command. |
| Write | w | File can be changed. | Directory files can be created or deleted. |
| Execute | x | Files can be executed if they are scripts or executables. | Directory files can be copied. A directory must have execute permission to allow files to be copied or moved. |

For example:

+   * -rwx----- indicates a file that has read, write, and execute permissions for the owner only.
* -r-xr-xr-x indicates a file that has read and execute permissions for the owner, group, or anyone else.
* drwxr-x---x indicates a directory that allows read, write, and execute permissions for the owner, read and execute for the group, and execute only for everyone else.

# ## Changing Permissions

The command to change permissions is **chmod**. Permissions can be changed using symbolic mode or octal mode. The chmod syntax is `chmod mode filename/directory` where mode is either a symbolic value or an octal value and filename/directory is the name of the affected file or directory.

+   * Symbolic mode uses letters and symbols to assign permissions to files or directories.
* Octal mode uses octal numbers to assign permissions to a file or directory.

Symbolic modes are composed of symbols for who, the operation, and the permission to be applied. Table 4–2 describes each symbolic value.

Table 4–2

| | o | Others, not owner or group |
| | a | All of the above |
| Operation | | |
| | = | Set permissions |
| | - | Remove access |
| | + | Give access |
| Permissions | | |
| | r | Read |
