After the command is entered, a new SMB password is requested. You must type the password a second time to ensure it is correct. If the user does not exist in the Linux system, an error is displayed. The following is a sample listing of the command adding the user jsmith. Figure 8--12 shows the resulting /etc/samba/smbpasswd file.

```
# smbpasswd -a jsmith
New SMB password:
Retype new password:
Added user jsmith.
#
```

# ### Starting Samba

Only two processes need to be started to use Samba---**smbd** and **nmbd**. smbd provides the SMB/CIFS services to clients. This provides file and print sharing services to Windows clients.

nmbd provides the NetBIOS over IP naming service to clients. The NetBIOS over IP naming service allows the Linux Samba server to participate in the Windows *Network Neighborhood* view.

The following entries perform two tasks. The command *ps -ef | grep search\_name* determines whether smbd and nmbd are running. The second line of each entry starts the service.

```
# ps -ef | grep smbd
root 14592 14535 0 08:16 pts/1 00:00:00 grep smbd
# ps -ef | grep nmbd
root 14594 14535 0 08:16 pts/1 00:00:00 grep nmbd
# smbd
# nmbd
```

```
# ps -ef | grep smbd
```
