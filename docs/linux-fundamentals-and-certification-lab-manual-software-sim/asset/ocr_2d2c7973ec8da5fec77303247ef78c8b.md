+   Runlevel. This is a setting used by the Linux operating system to specify which programs will start and stop.

+   Samba. This is Linux's answer to Windows NT Server. Windows uses the SMB protocol to share resources between computers on a network. Linux provides the SMB protocol with Samba, a suite of programs that provide the same functionality as an NT server.

+   SCSI. An acronym for Small Computer System Interface, a parallel interface standard used by computer systems to attach peripheral devices to computers. It is usually used to connect hard drives.

+   Security Update. A minor change that is made to an operating system to prevent security breaches.

+   Server. A type of Linux installation that is used to service client computer systems. It can provide Web services, file services, messaging services, database services, and network services.

+   Service. A program running on a server that provides resources for client computers.

+   Shadow Passwords. A suite of programs that moves and encrypts the system passwords to a secure file that only root can read.

+   Shareware. Software that can be freely distributed, but retains the author's copyright. If you decide to keep the software, you're expected to register and pay a small fee.

+   Shell Script. A collection of commands stored in a file that can be executed under the shell environment.

+   Shortcut Menu. A pop-up menu displaying options for an object that has been right-clicked.

+   Signed Packages. These are packages that support PGP or GPG electronic signatures to verify who created them.

+   SIMM. Single inline memory module, a type of RAM.

+   SLP. An acronym for Stampede Linux Package. The SLP format, from the Stampede Linux distribution, uses tar and the compression tool, bzip2, as its foundation.

+   SMB/CIFS. Short for Server Message Block/Common Internet File System. SMB/CIFS was developed by Microsoft and uses port 139.

+   SMTP. An acronym for Simple Mail Transfer Protocol, a protocol on TCP/IP networks that is used for sending e-mail messages between servers and from client to server. It uses port 25.

+   SNMP. Short for Simple Network Management Protocol, a protocol used to manage TCP/IP networks. It uses ports 161 and 162.

+   SODIMM. Small outline dual inline memory module, a type of RAM usually used in laptop computers.

+   Software. The programs that are executed on computer hardware. These can include system software, such as operating systems, or application software, such as word processors.

+   SOHO. Acronym for Small Office/Home Office.

+   Spooler. A program that controls printer jobs in a queue. The spooler takes the print jobs one at a time and sends them to the printer in sequence.

+   SQUID. A high-performance proxy caching server for Web clients.

+   SSH. Secure Shell, a program used to log into another computer over a network in order to execute commands on a remote machine. SSH provides strong authentication and secure communication.

+   Subnet Mask. A 32-bit value divided into four 8-bit octets. This mask enables you to divide your network into segments with fewer computers, making the network more manageable than one with large numbers of computers on very large segments.

+   SUSE. A distribution of the Linux operating system.

+   Swap. This term refers to storage capacity that is used by the computer to page information in and out of main memory. This enables you to run programs that otherwise would not have room in memory to run.
