**Routing**  A Linux server can be used as a router. A router's job is to provide switching and path determination for packets of network information. In other words, a router accepts a packet of information from a host, reads the destination IP address, and then determines the best path to use to forward the information. Often an older machine can be equipped with two or more network interface cards (NICs) to provide this service. A packet will come into one NIC, be examined and found to be addressed to a network available on the other NIC, and then routed out the second NIC. This same machine can provide DHCP and DNS as well. As part of its routing duties, a Linux router can filter out unwanted packets to provide a source of security to the internal network.

**Firewall**  When a packet is sent from one machine to another over a network, it is addressed with not only the IP address, but also the port to use for communication. When the packet is received by the remote host, it determines what type of packet is being received and routes the information to the designated port number. There are many common ports that are used for file transfer, telnet, mail, and others. A firewall is a software package that restricts access to specific ports, thus making the Linux operating system a more secure environment. This system can also be minimal in size. An older system will usually work nicely as a firewall. Firewalls and networking are discussed in Chapters 6 and 11.

**ipchains**  ipchains is a program used to enable packet filtering, network address translation (NAT), and other packet manipulation. The major use of ipchains is to turn your Linux computer into a gateway between a private network and the Internet. A packet is a unit of information sent from computer to computer across intranets or the Internet. It basically has a header with routing information, where it's coming from and where it's going, and a body with all the other information. NAT is a way for a private network to communicate with other networks. It takes the private network address and translates it to a public network address that other networks recognize. When packets arrive from other networks, NAT translates to the appropriate address within the private network. ipchains also provides a way to work as a firewall (a way to block unwanted packets to or from the internal network). ipchains is discussed in Chapter 11.

**Squid**  Squid is a high-performance proxy caching server for Web clients, supporting FTP, and HTTP data objects. Internet object caching is a way to store requested Internet objects on a system closer to the requesting site than to the source. Web browsers can then use the local Squid cache as a proxy HTTP server, reducing access time as well as bandwidth

Without going into too much detail, an IP address consists of a 32-bit value. Usually, for convenience, it is presented in decimal dot notation, four octets (bytes) separated by a dot and shown as decimal values. For example, 192.168.0.1 is an IP address. Each physical network has its own unique network address. Each host has its own unique address. Each host is assigned a gateway, or router's address, to which it can send information to be routed to other networks. There are five classes of IP addresses, denoted as Class A through Class E. Each class has a specific range of IP addresses to use. Each IP address is divided into network and host identification. The host identification can be further divided by using a subnet mask, which makes part of the host address valid for network addresses and part available for hosts (individual machines).
