Many options can be configured for the Linux kernel. An explanation of all available options is beyond the scope of this book. One way to find out about an option is to use the help facility. Help is available using the CLI or the GUI and, in most cases, it is very helpful.

After you have configured the kernel, exit the system. You are asked to save the configuration to a file. If you save to a file, you can choose to recall the configuration you saved if you ever have to recompile.

# Compiling the Kernel

After you have configured the kernel it is time to compile it. Several steps are involved. You must identify kernel dependencies, compile the kernel, compile the modules that the kernel will need, move the modules to the correct directory, move the kernel to the correct directory on the system, and, finally, modify your boot loader to recognize the new kernel.

**make** The make utility is a group of shell scripts that evaluate a set of dependencies, and then execute commands. make is one of the original Unix tools for software development. Other tools for software development include language compilers and shell programming tools.

Invoking make usually involves typing **make** and waiting for the command to finish. Sometimes, however, the process is a little more involved.

Usually, make looks for a file called Makefile. Makefile has instructions for a specific project and describes the relationships among files in your program. Typically, the executable file is updated from object files, which in turn are made by compiling source files. Most source programs you will download will have a Makefile provided.

The make program uses the Makefile database and the last-modification times of the files to decide which files need to be updated. For each of those files it issues the commands recorded in the database.

**Makefile** The Makefile has instructions for the project to be compiled and installed on the operating system. Makefile is composed of the following components: comments, dependency lines, rules, and shell lines.

![](bbox=[0.24, 0.59, 0.96, 0.72])

+   • **Comments** These are the simplest Makefile statements. A # sign indicates that any text following it is user comments and is not to be read by the compiler.
• **Rules** A rule tells the make utility when and how to make a file. The syntax of a rule is as follows:

```
target : prerequisite
command
```

+   • *target* is usually the name of a file that is generated by a program. This is most often an executable or an object file. The target can also be the name of an action.
• *prerequisite* is a file that is used as input to create the target.
• *command* is an action that make carries out. This can consist of several commands. Each command is typed on a different line.

The rule **main.obj : main.c bcc -ms -c main.c** says to compile mail.c with the bcc compiler.
