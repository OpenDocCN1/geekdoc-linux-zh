# PATCHING THE KERNEL

Patching the kernel is not really a troubleshooting exercise, but it may prevent you from having to troubleshoot the system. Patching the kernel requires updating the source files and then recompiling the kernel.

Linux kernel version numbers consist of three numbers separated by periods. The first number is the major version number, the second is the minor revision number, and the third is the patch level version. Stable releases of the Linux kernel are identified by an even number as the second number of the release. Development releases are identified by an odd number as the second number of the release. For example, the current stable release is 2.4.22 (the second number 4 is even), and the current development release is 2.5.75.

Kernel patches are released to offer new functionality and to address security issues. New functionality could include new drivers for recently released devices. Security patches are released when a program exploit is detected. Patches are not immediately available; they can often take weeks (or longer) before being available.

Updating the kernel does not always go smoothly. Before actually applying the newly compiled kernel, you should make a backup of the system.

# Finding Kernel Patches

Patching an existing kernel allows you to retain your configuration from previous kernel compilations. Patching a kernel is a good choice if you are patching to the next consecutive level. For example, if you are currently using version 2.4.20 and want to go to 2.4.21, a patch is a good choice. However, if you are using version 2.4.3 and want to go to 2.4.21, you would be better off downloading the 2.4.21 kernel because patching would require applying each patch from 2.4.3 to 2.4.21.

Kernel versions and kernel patch versions can be found in several places on the Internet. One of the most popular sites is the Linux Kernel Archives at www.kernel.org or ftp.kernel.org. This FTP site has almost every Linux kernel ever created. You can download the current patch version, current stable version, current development version, and current test version of Linux. From this site, download the current patch for your Linux update. For purposes of discussion, the patch downloaded will be patch-2.4.21.bz2.

To apply the patch, do the following:

+   Move the downloaded patch to the /usr/src/linux directory.
