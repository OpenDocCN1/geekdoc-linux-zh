To move a file, navigate to the folder that contains the file you want to move. Right-click the file to display the shortcut menu. Select **Cut**. Navigate to the folder that you want to move the file to and then right-click an empty spot on the file manager to display the shortcut menu. Select **Paste** from the shortcut menu.

To move a file to trash, navigate to the folder that contains the file you want to remove. Right-click the file to display the shortcut menu. Select **Move to Trash**.

# NOTE

Moving a file to trash removes it from the directory it is in, but keeps it in a temporary storage area. If you are sure the file needs to be removed, the trash can be emptied. If the file should be kept, it can be removed from trash and placed back in the folder.
