## Adding Hardware

Available devices that can be added to a computer system are too numerous to list here. Typical devices that will be added are printers, scanners, modems, Ethernet adapters, sound adapters, video adapters, RAM, and storage devices. The only thing that these devices have in common is the sequence of events used to add them:

1. Configure the new device.
2. Physically install or connect the device to the computer system.
3. Install the driver for the device and configure it for use.
4. Test the device.
5. Make the device available.

### External Hardware Connections

Some devices only require connections to existing ports on a computer system, whereas others must be installed inside the system case. The connections (ports) available on most computer systems are shown in Figure 9-28.

![](img/37f079cee226b270f2e09b37a2e4a05d_272_0.png)

- **PS2 Mouse/Keyboard** Some keyboards and mice use other connectors. The older keyboards have a much larger connector, and the newer models may connect to a USB port.
- **Ethernet** This connection is used to connect to the Internet. It is a standard Ethernet connector and usually 100BASE-T type (100 Mbps). The speed range can be from 10 to 1000 Mbps.
- **Parallel** The parallel port is usually used for a printer connection, but other devices can use it to connect as well. Parallel devices can receive more than one bit at a time.
- **Game** The game port is used to connect a joystick or other game-type device. Game devices can connect to other ports as well.
- **USB** Universal Serial Bus. These connections are a relatively new standard that supports transfer speeds up to 12 Mbps to and from devices. Devices connected to a USB can be daisy-chained. Up to 127 devices can be connected to a single USB port.
- **Serial** Serial ports are used to connect a mouse, an external modem, and many other devices. Serial ports communicate one bit at a time.
- **Video** Typically a VGA monitor will be connected to this port. This port could also connect to an overhead projector.
- **Sound** The sound connections provide connections for the microphone, speaker, and other devices.

USB and other serial devices can be connected and disconnected with the system powered. Other connections should be attached only while the power is off. A power surge on the system can cause system components to be damaged. If you are unsure whether a component is safe to connect or disconnect, turn the power off first.

### Internal Hardware Connections

Internal components are connected to slots directly on the mainboard (Figure 9-29). Most systems have slots for PCI, AGP, DIMM, and others. The system should be powered off before installing internal components.

![](img/37f079cee226b270f2e09b37a2e4a05d_273_0.png)

- **PCI** Peripheral Component Interconnect slots are the slots most commonly used for internal components today. Several other slots have been used on older systems, including ISA, VESA, and EISA. Most have been replaced with the newer PCI because it is a 64-bit bus implemented as a 32-bit bus and it runs at a faster clock speed than the older technologies.
- **AGP** Accelerated Graphics Port is an interface developed for the high demands of 3-D graphics.
- **DIMM** Dual In-line Memory Module. This provides a 64-bit path to memory.

When working inside a computer system, take great care to prevent static discharge. If your body accumulates a static charge it can dissipate when you touch the computer, causing damage to the system. Always use a grounding wrist strap when working on a computer system.

## Hardware Drivers

After you have connected a new device, you must tell Linux how to use it. This is done through modules (drivers). There are several places you can look for a driver:

- **Built-in Kernel Modules** Many drivers are compiled with the kernel and provided when you need them. If you have an older kernel, you may have to get a newer version.
- **Manufacturer** Your device probably came with documentation, including a CD containing some device drivers. Some manufacturers ship only the most standard drivers and you may have to contact them for specific drivers. Many manufacturers have Web sites with drivers available for download.
- **Nonprofit Organizations** Some nonprofit organizations provide device drivers from their Web sites. Linuxprinting.org, for example, provides hundreds of printer drivers, and the group spends its time working on providing even more. A large community of Linux developers contributes to different projects, including development of device drivers. ## SUMMARY

X is a windowing system for Linux GUI desktops. The current version is 11 release 6.6. X provides functionality for the mouse cursor, drawing windows, and moving windows. X does not provide a GUI desktop, just the basic tools for its use and development. X is a client/server application: The X server provides the back-end interaction with the graphical display, and the X client is the user interaction front-end.

Most Linux systems ship with XFree86, an open-source implementation of the X windowing system. Commercial versions of X are available as well.

A desktop environment provides a Windows-like environment for Linux. The two major implementations of desktop environments are GNOME and KDE.

Before you purchase a printer, you should make sure that it will work with Linux. One place to check for Linux compatibility is www.linuxprinting.org.

Linux uses spoolers and queues to communicate with printers. A spooler is a program that manages the printing system and controls all printing jobs. A print queue is the program/data area where print jobs are queued. The queue releases jobs to the printer in sequence. The most commonly used print spoolers are LP/LPD, PPR, PDQ, and CUPS.

Linux printers can be local, networked with CUPS, networked with Unix, networked with Windows, networked with Novell, or connected directly to the network with JetDirect.

Storage devices on Linux must be configured and mounted. Hard disk devices must be partitioned, usually by using fdisk, and formatted using mkfs or mkswap before they can be mounted.

Swap space is created when Linux is initially installed. Occasionally, additional swap space is needed and can be added on a new hard drive, configured on an existing hard drive if there is space, or configured with a swap file. The df command can be used to determine the amount of swap space.

Kernel modules are device drivers for Linux resources. A module can be compiled with the Linux kernel, or it can be loaded as needed. Modules that are loaded as needed are called Loadable Kernel Modules (LKM). The /etc/modules.conf file is used to control how modules are loaded and unloaded within Linux.

Hardware can be added after the Linux operating system is installed. Before loading the module that identifies the hardware and how it works for Linux, the hardware must be connected to existing ports or installed internally in the computer.

When installing devices, take care to ensure no static discharges occur. A grounding wrist strap is the best way to do this, but simply discharging a charge by touching grounded metal will be sufficient.
