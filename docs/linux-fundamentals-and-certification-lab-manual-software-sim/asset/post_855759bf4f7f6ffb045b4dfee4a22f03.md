The user account called *root* has complete access to the entire system and is used for system maintenance and administration. Setting up a root account and password, as seen in Figure 3-22, is one of the most important steps during installation. The password should follow your password policy.

The root user is also known as the super user. This account should be used only for system administration and not for day-to-day use. You can create a non-root account for your general use later in the installation. The password you enter will display as a string of asterisks (*) to prevent others from reading it.

System security is enhanced in Linux by allowing different methods of authentication. Authentication is the process of identifying an individual. This is not the same as authorization, which gives an individual access to the system. Authentication only ensures that the individual is who he or she claims to be.

Passwords are used by Red Hat Linux to verify a user’s identity. For this reason, password security is very important. To protect passwords Red Hat Linux provides shadow passwords and MD5 hashing. These technologies provide strong encryption, which forces those attempting unauthorized access to use a brute-force attack. A brute-force attack means that unauthorized access is gained through repeated attempts to break the password, which is very slow and leaves an obvious trail.

To protect your network from intrusion, it is a good idea to have a strong password policy. A password policy is a document that outlines the policies of an organization. Points to include are the size of passwords, how long a password may be used, the characters a password must contain, and other policies to ensure that all users maintain secure passwords. To create a strong password you should first avoid the following:

- Do not use just letters or numbers.
- Do not use dictionary words.
- Do not use foreign language words.
- Do not use personal information, such as your birth date or your name.
- Do not invert recognizable words.
- Do not write down your password.
- Do not use the same password for all machines.

You should, however, do the following:

- Make the password at least eight characters in length; the longer, the better.
- Mix upper- and lowercase letters. Your password is case sensitive.
- Mix letters and numbers. The mix of letters and numbers should be within the password, not just at the beginning or the end.
- Include special characters, such as ! or #.
- Change your password regularly.

Use a password creation methodology. Think of a memorable phrase such as “Way down upon the Suwanee river, Far, far away.” Next, turn it into an acronym including the punctuation. For example, **WdutSr.Fa**. Increase the complexity by substituting numbers for some letters. Be consistent, replacing certain letters with the same numbers; for example, replace d with 6, F with 7, and so on, giving you a finished password of **W6ut5r.7.fa**.

One good password protection policy is password aging. Password aging means that a password will remain valid for a set amount of time, then the user will be prompted to change the password. Aging also can ensure that the same password cannot be reused and require that it be active for a number of days before it can be changed.
