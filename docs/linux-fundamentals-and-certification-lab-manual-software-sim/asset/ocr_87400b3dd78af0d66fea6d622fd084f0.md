# MORE ADMINISTRATIVE TASKS

Another program that can be used to manage processes is the **killall** command. This command uses the same signals as the **kill** command, but allows you to use the process name rather than just the PID. Again, the default signal is SIGTERM.

Figure 11-8 shows a GNOME screen with four terminal windows displayed. Three of the terminal windows have **vim** (an updated version of the **vi** command) running and the fourth has a command line available. With the **kill** command you would list the processes running and then **kill** each individual PID listed as **vim**. With **killall** all you have to do is execute the command with the name of the processes you want to terminate. For example, to terminate all instances of vim you could use the **killall -15 vim** command.

![](bbox=[0.0, 0.257, 0.809, 0.564])

This command will terminate vi running in all terminal sessions. In Figure 11-9, the killall -1 vim command was used to do the same action. Remember that the -1 (SIGHUP) is used to stop the program, reload the configuration file, and restart the command. Not all programs can be restarted with this signal, as is the case with vim.
