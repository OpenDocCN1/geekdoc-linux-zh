**Network Installation.** Installing Linux from a network enables you to complete installation without having to carry the distribution disk from machine to machine. The disk can be stored on a network hard drive, in the same method as a hard disk installation, and accessed through NFS, FTP, or HTTP.

**NFS.** Short for Network File System, a standard for sharing files over a network developed by Sun Microsystems.

**NIC.** An acronym for Network Interface Card.

**NIS.** The Network Information Service, or NIS, enables you to run a group of computers in a domain with a common password and group file.

**NTP.** NTP, or Network Time Protocol, allows computers to synchronize with a remote network time server.

**Open Source.** A term that describes a program that is distributed together with its source code.

**Operating System.** A software platform on top of which application programs run.

**OSI Model.** The OSI, or Open System Interconnection, model identifies seven layers of network function. Each layer specifies particular network functions, such as addressing, flow control, error control, encapsulation, and reliable message transfer. The highest layer manages the flow of information from the application to the network, whereas the lowest layer identifies the methods of physical data flow between devices. The seven layers from 1 to 7 respectively are: physical, data-link, network, transport, session, presentation, and application.

**Package.** A software bundle for a program on an operating system.

**Packet.** A portion of a message sent over a packet switching network. Each packet has, among other things, the data to be sent and the source and destination IP addresses of the network hosts.

**Panel.** A work area on the GNOME or KDE desktop that can contain a wide range of shortcut options. Panels can be corner, edge, floating, menu, or sliding panels.

**PAP.** Short for Password Authentication Protocol, PAP is a simple method for a host to establish its identity to the server. The remote client and the server establish a connection using PPP, and then the remote client sends a username/password pair until the server acknowledges authentication or the connection is terminated.

**Parameter.** A value or group of values that is passed to a program on startup.

**Partition.** A logical segment of a disk drive that acts as a separate drive.

**Password.** An alphanumeric string entered by a user that verifies that the associated user is the one in question.

**Patch.** Object code that is inserted into an executable program. Patching is a temporary measure that is used until a new version of the software is made available.

**PATH.** An environment variable that points the operating system to the most commonly used file locations.

**Permissions.** Settings that control the kinds of access allowed to resources. Three different permissions are used: read (r), write (w), and execute (x).

**Personal Desktop.** A type of Linux installation designed for the home user. It typically includes personal productivity software and the GUI interface.

**Personal Firewall.** A single point of defense that all network traffic must go through in order to communicate with applications on a computer.

**Personal Productivity Software.** Software designed for personal productivity, such as word processing, calendar, e-mail, and so on.

**PGP.** An acronym for Pretty Good Privacy, a public-key encryption application that is used for exchanging files or messages with confidentiality and authentication.

**PID.** Short for Process ID, a number that is assigned to a process when it is started.
