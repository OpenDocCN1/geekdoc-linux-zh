You can also add an object to the desktop by dragging an object from a file manager window to the desktop.
The desktop has several preferences that can be changed. Changes can be made to the default properties for background color or image, mouse, keyboard, screen saver, sound, and others. To change desktop properties, select the **Start** menu and then choose **Configuration**, **GNOME**, and **GNOME Control Center**. Figure 10-9 shows the cascading menu.

You can also change the background preferences. From the **Desktop Preferences** dialog box, double-click the **Background** icon to display the Background Preferences dialog box (Figure 10-11). Select the preferences desired and then select **Close**.
