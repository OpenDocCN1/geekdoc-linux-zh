A hardware firewall is a dedicated computer between clients on the inside of a network and clients on the outside of a network. Often, a firewall is placed at the Internet entry point of an organization. The dedicated firewall can be configured to allow or deny the movement of specific protocols into and out of a network. There are several vendors of dedicated firewalls. One of the most popular is Cisco's PIX firewall.

A software firewall, or server firewall, is a software program running on a server that accomplishes the same functions as a dedicated hardware firewall. Often, the software firewall is run on a server that has other duties besides that of firewall. This means that the software firewall will often be unresponsive during heavy loads in a large network. Often a software firewall is used on a server to restrict access to its resources only.

One method of firewall technology is IP packet filtering. Recall that the TCP/IP protocol is made up of many services that are identified by port numbers. The FTP application, for example, uses ports 20 and 21. IP packet filters inspect network datagrams and decide whether or not to allow packets to pass. Packet filtering can look at the protocol, the IP addresses, the port numbers, and other TCP/IP values to make access decisions.

The programs used by the Linux operating system to configure the software firewall are ipfwadm, ipchains, and iptables. The Linux firewall can be configured from the command line or with a GUI tool. At the most basic level, the firewall can be configured through linuxconf, setup, or during installation to restrict the protocols that will be accepted.
