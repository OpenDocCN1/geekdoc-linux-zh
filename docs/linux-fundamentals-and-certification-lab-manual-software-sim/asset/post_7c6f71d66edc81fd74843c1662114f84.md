
Besides the interface a hard drive will connect to, a few geometry values should be examined. For example, the capacity of the drive is important. All hard drive capacities today are measured in gigabytes (GB). Drive capacities range from about 20 GB to over 200 GB. The size of the drive you need will be determined by the intended usage of the drive. The number of revolutions per minute (RPM) a drive platter spins is important to determine how fast the drive will retrieve information. On a hard drive, the read/write head moves in and out between platters of the hard drive while the platters spin. The faster a platter spins, the faster data can be read from or written to the hard drive. The typical RPM of hard drives ranges from 5400 to 15,000.

Seek time refers to how fast information can be read to or written from a hard disk on average. Seek times range from about 13 ms to less than 4 ms.

Hard drives are typically installed internally using SCSI or EIDE/ATA technology. However, there are external drives that use proprietary ports, parallel ports, universal serial bus (USB) ports, or FireWire ports. The newest FireWire drives provide high performance while also providing portability. A FireWire drive can be moved quickly from one machine to another.

## Network Cards

A lot of networking hardware is available, but most systems use Ethernet. There are also several different Ethernet specifications including 10BASE2, 10BASE5, 10BASE-T, 100BASE-TX, 100BASE-FX, 1000BASE-T, 1000BASE-SX, and 1000BASE-LX. Ethernet uses a logical bus topology, although most installations use a physical star or extended star topology. Ethernet is a shared media broadcast technology. The access method Carrier Sense Multiple Access with Collision Detect (CSMA/CD) is used in Ethernet technology. In the CSMA/CD access method, networking devices that have data to transmit over the networking media work in a listen-before-transmit mode. This means that the device checks to see if the media is busy, and if not it transmits. If a collision is detected, the device waits a random amount of time and tries again. Collisions are common when using Ethernet because of the shared media segment. Some of the more common Ethernet types are described in Table 2–1.

|---|---|---|---|
| 10BASE5 | Thick coax | 10 Mbps (megabits per second) | 500 meters |
| 10BASE-T | Category 5 UTP (Unshielded Twisted Pair) | 10 Mbps | 100 meters |
| 10BASE-FL | Multimode Optical Fiber | 10 Mbps | 2000 meters |
| 100BASE-TX | Category 5 UTP | 100 Mbps | 100 meters |

The Ethernet adapter has to match the type of medium you are using. The most common medium today is 100BASE-T.

Linux will find most any Ethernet adapter in use today. There are some newer devices that Linux won’t find during installation. For example, many of the 1000BASE-T and 802.11 (wireless) adapters are not included in most Linux distributions. However, Broadcom and Intel GigE network interface cards (NICs) are supported by Red Hat. If the NIC installed is not supported, the manufacturer will often provide Linux drivers. Linux supports other networking standards, such as Token Ring, Fiber Distributed Data Interface (FDDI), Local Talk, and 802.11 wireless. If you are using one of these, you need to search your Linux distribution’s support and find the recommended adapters.

## Modems

Linux distributions support almost any older internal or external modem. The most compatible modems are those that are Hayes compatible. Some of the newer modems are software modems that rely on the CPU to do some of the work that once was the modem's job. These software modems may not work with your Linux distribution. For those you can check http://www.linmodem.org for help on what's currently supported.

## Miscellaneous Hardware

Linux supports a wide range of commonly used hardware. Although some of these devices may have features that are not supported by Linux, all standard versions are supported without additional hardware drivers.

**Floppy Drives** All standard floppy drives work with Linux operating systems. There are a few drives, usually high-capacity, that may or may not work with Linux. These usually can be configured as hard disks or removable devices.

**CD-ROMs** Most CD-ROM drives are very standardized and will work within Linux. Often you will install Linux from a CD-ROM that will be booted on the system. Most recordable CD-ROMs and many recordable DVD-ROMs will be recognized by the Linux distribution as well.

**Tape Drives** Most tape drives use a standard EIDE/ATA or SCSI interface. These drives usually work with Linux without any special configuration.

**Keyboards** Standard PC keyboards work with any distribution of Linux. Some keyboards that have special keys will usually work, but the special keys may not be recognized on some distributions. USB keyboard support is available in the 2.2.x and 2.4.x kernels.

**Mice** Mice are standard devices and work with Linux easily. Most serial, USB, or PS/2 interfaces are supported.

**Monitors** A Linux driver is not required to use a monitor. Some features may not be supported if the monitor isn't recognized by the XFree86 configuration program, but it will still work. Full functionality can usually be achieved by inputting the vertical and horizontal refresh rates into the appropriate configuration files.

**Serial/Parallel Ports** Linux installation should find any serial or parallel port installed in the system. On later distributions, if you add a new port, the system should find it on startup and automatically configure it.

**PCMCIA** Personal Computer Memory Card International Association (PCMCIA) is an organization of about 500 companies that have developed a standard for small, credit-card-size devices called PC cards. PC cards are typically used in portable computers to add network cards, modems, and other devices. Linux will find these devices on installation and support most devices that are installed. PCMCIA is designed to allow replacement of cards without having to reboot the system.

**USB** Universal Serial Bus (USB) devices can support up to 127 devices on one port. USB devices include mice, modems, multimedia hardware, storage devices, and keyboards. The newer releases of Linux support USB and will work with most devices attached to the USB port.

**Sound Cards** Linux supports most sound cards. Many cards are Sound Blaster-compatible and work easily in Linux. There are commercial implementations of Open Sound System (OSS) and freeware versions, OSS/Free and ALSA, that support almost all sound cards designed with the OSS standard.

## IDENTIFYING HARDWARE CONFIGURATION

The configurable values for hardware include Interrupt Requests (IRQ), DMA, and I/O addresses. Some of these values are designed into the hardware, and some have to be configured when the device is installed. Current hardware devices generally configure themselves to the correct values without user intervention.

Many devices use jumpers and dip switches (see Figure 2–5) to indicate hardware configuration values. A bank of pins on a hardware device can be shorted by placing a jumper across a pair of pins. The jumper indicates an on or off condition to the computer system, which translates it to a value. A dip switch achieves the same result as a jumper, but uses a small switch to indicate an on or off condition.

### IRQ

IRQs are hardware lines that devices use to send interrupt signals to the CPU. After a device gets the attention of the CPU, data is transferred between the device and the CPU to accomplish the device’s tasks. IRQ conflicts used to be common, but with today’s plug-and-play architecture, devices will automatically use an available IRQ. If you are using an older system you need to know the assigned IRQs for devices. (Some motherboards allow mapping of IRQs outside the standard range. This is a function of the board.) ### DMA

Direct memory access (DMA) is a technique of transferring data from main memory to a device without passing it through the CPU. This results in much faster transferal of information to and from devices than when routing it through the CPU.

When installing a device that is capable of accessing the computer’s DMA channel you must set the channel to be used either with software or manually by setting a jumper or dip switch.

### I/O Address

I/O addresses are not the same as memory addresses. When an I/O address is put onto the computer’s address bus, another wire is energized. This both tells main memory to ignore the address and tells all devices that have I/O addresses to listen to the address to see if it matches. If the address matches, then the I/O device reads the data on the data bus. Table 2–3 shows the I/O addresses most commonly used in computer systems.

A good reason to purchase a new, preconfigured computer system is that you don’t have to manage the IRQs, DMA, or I/O addresses of the devices; they are set by the assembler. It’s likely that a new system will come with a pre-installed operating system as well. If Windows is available you can use Windows Device Manager to determine the configuration settings of the installed devices.
