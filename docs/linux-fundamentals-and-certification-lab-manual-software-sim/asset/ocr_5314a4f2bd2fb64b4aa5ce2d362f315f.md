By disabling root login you prevent users from accidentally damaging the system by executing the wrong program. root access should be gained through the use of su or sudo.

A personal firewall is a way to restrict network traffic to the local host. The firewall tests packets when they arrive. If the packets meet certain criteria, they are processed; otherwise, the packets are dropped.

Server security is much the same as workstation security. On a server the services should be secured as well. Services include Web servers, FTP servers, and other network services. TCP wrappers are used to further secure network connections with access control, login banners, and other features. Ports should be monitored to ensure that unused ports are not open and that ports have not been opened by unauthorized users.

A Virtual Private Network (VPN) enables a remote user or LAN to access a local LAN as if they were directly connected. Crypto IP Encapsulation (CIEPE) is one method used to configure a VPN. Other solutions are available, such as FreeS/WAN, which is a free VPN implementation.

A firewall secures the network or the local host from unauthorized network traffic. iptables is one type of firewall on a Linux system. It contains a chain of rules that packets are evaluated against before they are forwarded, processed, or outputted.

File system security is achieved primarily through file permissions. A file is secured by read/write/execute permissions and group and user ownership. The umask command can set default permissions used when creating files and directories.

Unused packages installed on the Linux operating system should be removed. Unused packages take up disk space, and they offer unauthorized users access through the applications' security holes.

Physical security is also a concern. Lock the door to the computer center, secure the computer with a locking case, remove external storage devices, and use a security system. Fire and water damage can be as serious as unauthorized access. Keep fire extinguishers nearby, and let users that have physical access to the computer know where they are and how to use them.
