A file would have the value of 664 or `rw-rw-r--` (664). To see the results, use the `mkdir` command to create a directory or the `touch` command to create a file. The following command sequence shows the results:

```
$ mkdir mydir
$ touch myfile
$ ls -l
total 4
drwxrwxr-x 2 rbrown rbrown 4096 Nov 16 15:52 mydir
-rw-rw-r-- 1 rbrown rbrown 0 Nov 16 15:52 myfile
$
```

The umask value can be changed by using the umask command. For example, to make the default umask value for the group read permission only and others no permissions, use a umask value of 037. The binary value of 037 is 111011111, making the corresponding permission values for directories and files 111100000 or `rwxr-----` for directories and 110100000 or `rw-r-----` for files. The following command sequence shows the result:

```
$ umask 037
$ mkdir mydir
$ touch myfile
$ ls -l
total 4
drwxr----- 2 rbrown rbrown 4096 Nov 16 16:02 mydir
-rw-r----- 1 rbrown rbrown 0 Nov 16 16:02 myfile
$
```

## Removing Unnecessary Programs

Unnecessary programs on your Linux system pose a security risk, and they use disk space as well. An unauthorized user can run programs on the Linux system that may not be running, which poses security issues. For example, an FTP program may be installed but not used. An unauthorized user can run the program and then take advantage of known exploits in your system with it.

There are many ways to view which packages are installed on the Linux operating system. The best ways are with GUI tools.

Figure 12-20 shows the GUI `urpmq` screen from Mandrake Linux. There are instances of the program to view packages to be installed, updated, or removed. To remove a package, select **Configuration**, **Packaging**, then **Remove Software** from the main menu. On the removal screen, select the program to be removed and click the **Remove** button.

To remove a package from Red Hat Linux, select **System Settings** from the main menu and then **Add/Remove Applications**. On the Add or Remove Packages screen (Figure 12-21), select the program to be removed and then click the **Update** button.

## PHYSICAL ACCESS SECURITY

Keeping your data secured with permissions, cryptography, or security updates is a good idea. But what do you do if someone steals your hard drive? What do you do if someone gains physical access and steals a backup tape? Don't spend all your resources on soft security and leave all the hard security undone.

There is no way to be completely sure that the physical security of your computer system will not be breached. So, what reasonable steps can you take to physically secure a computer system?

- **Make sure the door is locked.** If you lived in a city with a high crime rate, you wouldn't leave your door unlocked. So, don't leave your computer center unlocked. Secure the door and consider using a security center. The measures you take will be determined by how important the data center is. Some organizations post guards, use keycards, and even scan thumbprints to verify who has access to the computer center.
- **Secure the computer.** Most computer systems have a key that ensures that the computer can't be turned off or disassembled. Some systems even have special screw heads on the covers that require special tools to remove the cases.
- **Remove any external storage devices.** Don't keep an external floppy disk or CD-ROM drive attached to the computer. If such devices are needed, removable devices are available that can be connected in seconds.
- **Consider using video cameras to record access.** Many video cameras, often using the Linux operating system, will FTP captured images to an FTP server. These images can be used to record unauthorized access and can be copied to a remote location.

Physical security includes security from fire or water damage, too. At the very least have fire extinguishers in close proximity and ensure that all users with access know where they are. Fire extinguishers should be inspected regularly.

## SUMMARY

Security is an ongoing process comprised of four phases—secure, monitor, test, and improve. Securing the computer is a first step. This step includes strong passwords, enabling firewalls, applying file system permissions, establishing VPNs, and running software updates. Monitoring includes checking logs, monitoring open ports, and tracking who has logged on to the system. Testing includes running programs like John the Ripper to check that security measures are running properly. After monitoring and testing are completed, the information gained is used to secure the system again and the process starts over.

A software program is often under its own cycle of development, testing, deployment, and changes. Programs are not perfect and require constant monitoring. After a problem is found, developers make necessary changes and distribute them in the form of updates. Keeping software up-to-date is one of the best ways to ensure that unauthorized access is denied.

Updates are secured over the network with encryption. Asymmetric encryption provides a way to exchange encryption keys to ensure that data is not tampered with during download. Encryption keys and electronic certificates are used to sign software packages to ensure that the packages are valid and have not been tampered with.

Workstation security involves securing the boot loader, choosing strong passwords, disabling root login, and setting up a personal firewall. Securing the boot loader prevents unauthorized users from gaining access by power-cycling the system.

Strong passwords include using uppercase and lowercase letters, numbers, special characters, and a length of at least eight characters. Passwords consisting of birth dates or proper names are easily cracked, often in seconds. Passwords should be used for a limited time and then changed.

By disabling root login you prevent users from accidentally damaging the system by executing the wrong program. root access should be gained through the use of `su` or `sudo`.

A personal firewall is a way to restrict network traffic to the local host. The firewall tests packets when they arrive. If the packets meet certain criteria, they are processed; otherwise, the packets are dropped.

Server security is much the same as workstation security. On a server the services should be secured as well. Services include Web servers, FTP servers, and other network services. TCP wrappers are used to further secure network connections with access control, login banners, and other features. Ports should be monitored to ensure that unused ports are not open and that ports have not been opened by unauthorized users.

A Virtual Private Network (VPN) enables a remote user or LAN to access a local LAN as if they were directly connected. Crypto IP Encapsulation (CIEPE) is one method used to configure a VPN. Other solutions are available, such as FreeS/WAN, which is a free VPN implementation.

A firewall secures the network or the local host from unauthorized network traffic. iptables is one type of firewall on a Linux system. It contains a chain of rules that packets are evaluated against before they are forwarded, processed, or outputted.

File system security is achieved primarily through file permissions. A file is secured by read/write/execute permissions and group and user ownership. The umask command can set default permissions used when creating files and directories.

Unused packages installed on the Linux operating system should be removed. Unused packages take up disk space, and they offer unauthorized users access through the applications' security holes.

Physical security is also a concern. Lock the door to the computer center, secure the computer with a locking case, remove external storage devices, and use a security system. Fire and water damage can be as serious as unauthorized access. Keep fire extinguishers nearby, and let users that have physical access to the computer know where they are and how to use them.
