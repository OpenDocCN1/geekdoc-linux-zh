To install additional Red Hat Linux RPM packages that were not installed during the initial installation, use the **Additional CDs** screen (Figure 3-36). This can be software from third-party providers, or documentation from the Red Hat Linux Documentation CD. After the Setup Agent is completed the login prompt is displayed, as seen in Figure 3-36. If you selected the text login, enter the account username you created or the root account name, then press Enter. Enter the password of the account and press Enter, and the default prompt is displayed. The password will not be displayed.

# NOTE

The prompt displays as white letters on black background. To make the screens easy to read, the remaining screens display as black letters on white background.
