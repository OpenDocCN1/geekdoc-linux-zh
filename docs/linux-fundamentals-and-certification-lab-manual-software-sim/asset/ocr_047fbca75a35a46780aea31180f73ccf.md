# ## Changing and Viewing Directories

To list the contents of each directory, the tree structure must be navigated with a change directory (cd) command, and then the files can be listed with the ls command. There are shortcut symbols that can be used in pathnames. To refer to the current directory, use a period (.). To refer to the parent directory, use two periods (..). To refer to the current user’s home directory, use the tilde + slash (~/). To refer to the previous directory, use the hyphen (-).

When jsmith logs in to the system, he will be in his home directory, /home/jsmith. The default directory location for any user is the user’s home directory. Using the example directory tree in Figure 4-22 as a reference, look at the commands to navigate through the tree.

To change to jsmith’s documents directory, type **cd documents**.

The documents directory is directly below the jsmith directory, so the relative path is just the directory name.

The absolute pathname, **cd /home/jsmith/documents**, could also be used.

The shortcut symbol for current directory, **cd ./documents**, could also be used.

To change directories to the etc directory, type **cd /etc**.

The / is needed because the etc directory is off the root directory. This is an example of an absolute pathname.

There are two choices in changing from the /etc directory to the jsmith directory. You can use the absolute path **cd /home/jsmith**. You can also use the shortcut symbol for the user’s home directory, the tilde (~), **cd ~**. Either command will change directories to the jsmith directory.

From the jsmith directory, to change to the home directory, use an absolute or a relative pathname.

The absolute pathname to home is /home, such as **cd /home**.

The relative path from jsmith is the shortcut parent (..), such as **cd ..**

To return to the previous directory, use the - shortcut, such as **cd -**.

It’s easy to lose files along the way. Some file systems can have tens of thousands of files in hundreds of directories. Use the pwd command to display the current pathname:

```
pwd
/home/jsmith
```

To view the current directory, use the ls command. The ls, list directory, command lists information about the files in a directory. The command will display files in the current directory by default, but can be used to display any directory by supplying the pathname. For example, **ls /home** displays the files in the /home directory. The syntax of the ls command is **ls [option] [file]**, where option is from the following list and file is either a file-name or a pathname.

+   - **a, --all** Do not hide entries starting with .
- **A, --almost-all** Do not list implied . and ..
- **--author** Print the author of each file
