# Checking the Signature of an RPM Package

Red Hat uses Pretty Good Privacy (PGP) for identifying files. PGP is a technique for encrypting messages so that they can be read only by using a specific key. PGP is based on the public-key method, which uses two keys, a public and a private key. Information encrypted with the private key can be read only with the public key. This public key is distributed freely and is used only to read a digital signature, or byte sequence, within a file. If the signature matches, the file assigned to it is the original and unchanged file.

GNU publishes the GNU Privacy Handbook, which outlines the GNU Privacy Guard (GnuPG or GPG) project, an implementation of PGP. GnuPG includes tools for key pair generation, exchanging and verifying keys, encrypting and decrypting documents, and authenticating documents with digital signatures. Information about GnuPG can be found at http://www.gnupg.org.

The syntax of the command used to check the digital signature of a package is **rpm --checksig package name**, where *package name* is the name of the installed package. To check the digital signature of the package tftp-server, type the command **rpm --checksig tftp-server**.

This command requires that GnuPG be configured to run on the Linux system and be able to find a key ring with the appropriate keys. This command should be run before installing a new RPM package. An imported public key is carried in a header, and key ring management is performed exactly like package management. For example, all currently imported public keys can be displayed by typing the command **rpm -qa gpg-pubkey \***.

# RPM Package GUI

Package management requires root access. The root user has unfettered access to the system and should be used with care. As mentioned in Chapter 4, the su command login is a better choice.

Red Hat Linux has a package management system that can be accessed through the GUI (Figure 6–9). This system allows you to add or delete packages provided with the Red Hat Linux distribution. It looks similar to the package management tool that is displayed during installation. All available packages are displayed, arranged in groups. Each group can be expanded and individual packages selected. If a package is unselected, the package is removed. Dependencies are maintained. If a package is selected for installation or removal, the operation is allowed only if dependencies are met.

The GUI package manager can be started from the command line by typing the command **redhat-config-packages**.
