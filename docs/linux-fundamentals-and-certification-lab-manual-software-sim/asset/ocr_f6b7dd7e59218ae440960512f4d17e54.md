**Server Availability** can be checked by issuing the *ping* command. If WINS is properly configured, you should be able to type *ping server\_name*, where *server\_name* is the name of the Linux Samba server. If you can’t ping by server name, try the IP address of the server. If the IP address works but the server name does not, check the WINS server setup.

**Workgroup membership** was checked in the “/etc/samba/smb.conf” section earlier in this chapter. To change the workgroup, click the *Change* button on System Properties, Computer Name tab.

# ## Test Samba Configuration

If you are using a Linux client, use the procedure from Chapter 7 to check the Samba share setup. If you are using a Windows client, select Network Neighborhood (My Network Places on some Windows versions) and browse for Workgroups. Your Samba server should show up on the list. Double-click it and make sure you can see your */tmp* folder.

# ## SUMMARY

Linux configuration files are either system related or user related. System-related configuration files are used to configure what services Linux executes when it starts, properties for the services, and general properties that are available. User-related configuration files provide properties for users either individually or globally.
