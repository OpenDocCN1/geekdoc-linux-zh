### File Manager

A file manager is a graphical shell for GNOME that makes it easy to manage your files and directories. GNOME uses the Nautilus File Manager as an access point to your files, applications, FTP sites, and URLs.

FIGURE 10-12

![](img/37f079cee226b270f2e09b37a2e4a05d_288_0.png)

To open the file manager window for your personal login account, from the desktop, double-click the *username*’s **Home** icon (Figure 10-13).

FIGURE 10-13
Starting file manager.

![](img/37f079cee226b270f2e09b37a2e4a05d_288_1.png)

With the file manager (Figure 10-14), you can view and manage files and folders. You can run scripts from the file manager by double-clicking the script’s filename. The file manager window contains the following:

- **Side pane** enables you to navigate through your files. It displays information about the current file or folder.
- **View pane** displays the contents of files and folders.

To open files from the file manager, navigate to the folder that contains the file. Double-click the file to open it. Right-click the file manager to open the shortcut menu (Figure 10-15) with Open, Copy File, and other options.

If you want to copy a file, navigate to the folder that contains the file, right-click the file to display the shortcut menu, and select **Copy File**. Navigate to the folder to which you want to copy the file and right-click an empty spot on the file manager to display the shortcut menu. Select **Paste Files** from the shortcut menu.

You can move a file by navigating to the folder that contains the file. Right-click the file to display the shortcut menu and select **Cut File**. Navigate to the folder to which you want to move the file. Right-click an empty spot on the file manager to display the shortcut menu and select **Paste Files**.

Moving a file to trash removes it from the directory, but keeps it in a temporary storage area. If you are sure the file can be removed, the trash can be emptied. If the file should be kept, it can be removed from trash and placed back into the folder.

### KDE

As with GNOME, K Desktop Environment (KDE) is a powerful desktop application designed to work with Unix/Linux. KDE, shown in Figure 10-16, is a suite of applications working together to provide not only a desktop, but also a working environment for system administration, file management, and user productivity.

KDE was developed by a group of several hundred software engineers from all over the world. The KDE project is a free software project under the GNU LGPL/GPL licenses.

![](img/37f079cee226b270f2e09b37a2e4a05d_290_0.png)

KDE is easy to use and very stable. It provides not only a desktop, but an application development environment as well. It also provides a lot of packages for everything from entertainment to an integrated office suite.

#### Desktop Components

The KDE desktop is similar to GNOME or Windows—most of the characteristics of KDE are derived from other GUI desktops. The main visible parts of KDE are the desktop and the panel.

**KDE Panel** The panel (Figure 10-17), called Kicker, is the bar across the bottom of the desktop screen by default. From the panel, you can start programs, switch between virtual desktops, and switch between programs.

![](img/37f079cee226b270f2e09b37a2e4a05d_290_1.png)

The main panel component is the Application Starter icon. The icon button provides access to all KDE-installed applications (Figure 10-18). The menu, as with all KDE components, is completely configurable. When selected, the icon button will display the main menu. The menu is a hierarchical design. As the mouse is moved over any entry with an arrow to the right, the next menu in the structure is displayed. Once you find the program you want to run, just left-click the entry.

The Virtual Desktop buttons represent the four desktops available within KDE. Selecting one of the Virtual Desktop buttons will display a new desktop screen. The Task List still displays any programs open in KDE, regardless of which Virtual Desktop you are viewing. This allows you to have several applications open without having to overlay other windows.

The Icon bar is an area where quick-launch icons can be placed. Applications that run often can be added to this area, allowing them to be run with a single click, rather than having to be found through the menu first.

The Task List displays a list of applications that are currently running. If an application is minimized, it can be restored by clicking its Task List button. If the application is open on the screen, it can be minimized by clicking its Task List button. You can also right-click the Task List button for the application to control its properties. To change virtual desktops, click the number icon of the Virtual Desktop desired.

You can also use the Ctrl+F1 through F4 keys to change to a desktop. Pressing Ctrl+Tab will cycle through the desktops.

To move an application to another Virtual Desktop (Figure 10-19), right-click the application’s Task List button to open a shortcut menu. Select **To Desktop** and then select the numbered desktop to which you want to move the application.

**Desktop Workspace** The workspace is the largest component of the desktop. It displays windows and icons that are currently being used. The default components displayed include icons for the CD-ROM, floppy drive, Home, and Trash.

The CD-ROM and floppy icons give quick access to those devices. A CD or floppy disk will be mounted automatically when inserted in the device. Right-clicking either icon will display a shortcut menu to mount, open, or copy the device.

The Home icon is a link to the user's home directory. Double-clicking this icon will display the file manager view of the directory.

The Trash icon contains items that are to be deleted from the system. You can drag items to the Trash container from the desktop or a file manager window. Items in the Trash container are held until the Trash Bin is emptied. Before Trash is emptied, items may be retrieved. After Trash is emptied, the items that were in it are completely removed from the system.

To add an item to the desktop (Figure 10-21), right-click an empty area of the desktop to display the shortcut menu. Select **Create New** and then the type of item to add.
