## Konqueror File Manager

The KDE Konqueror File Manager is more than just a file manager. It is also a Web browser and a universal viewing application.

As a file manager, Konqueror provides all the features of any file manager program. It supports cut, copy, and paste; local file browsing, remote file browsing, and file launching.

As a Web browser, it compiles with HTML 4.0. It supports Java applets, JavaScript, CSS1, CSS2, and Netscape plugins.

As a viewing application, Konqueror will display the contents of many types of files: Clicking on an image will display an image; clicking on a text file will display its contents.

To start Konqueror (Figure 10–23), you can double-click the Home icon on the desktop, or click the Home icon from the icon bar.

To copy and paste a file, simply navigate to the folder that contains the file you want to copy. Right-click the file to display the shortcut menu (Figure 10–24) and then select **Copy**. Navigate to the folder that you want to copy the file to, right-click an empty spot on the file manager to display the shortcut menu, and select **Paste Files** from the shortcut menu.

## xterm

Even on a GUI screen you will need a terminal window. xterm terminal emulator programs provide a text-based command-line interface within an X window system. The shell doesn’t know how to deal directly with the X window system, so an xterm program is used to allow the communication. The xterm program will load a bash shell by default on a Linux system.

One of the oldest xterm programs is called **xterm** (Figure 10–27). It provides DEC VT102/VT220 and Tektronix 4014 compatible terminals.

![](img/37f079cee226b270f2e09b37a2e4a05d_296_0.png)

![](img/37f079cee226b270f2e09b37a2e4a05d_296_1.png)

rxvt (Figure 10–28) is a color VT102 terminal emulator. It is a replacement for xterm. rxvt doesn’t support Tektronix 4014 emulation; however, rxvt requires much less memory than xterm.

![](img/37f079cee226b270f2e09b37a2e4a05d_296_2.png)

![](img/37f079cee226b270f2e09b37a2e4a05d_296_3.png)

Konsole (Figure 10–29) is another implementation of a terminal emulator program. Konsole is also available as kpart, a tool in the development library, and can be embedded within another application. Konsole has a menu system that allows opening multiple terminal sessions and changing the terminal settings.

![](img/37f079cee226b270f2e09b37a2e4a05d_297_0.png)

GNOME Terminal (Figure 10–30) is a terminal emulation application similar to Konsole. It starts the default shell that is specified in the user’s system account. GNOME Terminal emulates the xterm program.

![](img/37f079cee226b270f2e09b37a2e4a05d_297_1.png)

To start an X terminal emulation program from a GUI desktop, choose **Application Starter**, Terminals, and select the terminal you want.

## SUMMARY

The Linux desktop is an X window system client program that displays GUI components. Most servers do not require the use of a GUI. Most non-servers have GUI desktop applications for user applications.

The desktop is the workspace of a GUI environment. Its basic components are windows, menus, and icons. Most desktop environments have panels, which are non-workspace areas on the screen for menus and other shortcut applications.

GNU Object Model Environment (GNOME) is a popular desktop application for Linux. GNOME is also an application development environment that provides libraries to allow programmers to create applications with standard menus and dialog boxes.

K Desktop Environment (KDE) provides GUI applications for file management, network access, system configuration, and Internet browsing. It is also an application development platform.

xterm is the name not only of a terminal emulation program, but also of a class of terminal emulation programs. xterm has been improved with new applications, rxvt, GNOME Terminal, and Konsole. All these applications offer access to DEC VT102/VT220 terminal emulation. Most offer access to Tektronix 4014 compatible terminal emulation.
