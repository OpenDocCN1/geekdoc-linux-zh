Each user and group has a unique identification number. That for the user is called the userid (UID) and for the group, the groupid (GID). The default value of UIDs is typically greater than 99 and one greater than any other user. UID values between 0 and 99 are typically reserved for system accounts. GIDs are typically 100 or greater and by default greater than any other group. GID values between 0 and 100 are reserved for system accounts.

A UID and GID of 0 are used to identify the root account. Linux grants all access to the root user account regardless of file permissions.

When a file is created, it is assigned to a user and a group owner. It is also assigned separate read, write, and execute permissions for the owner, the group, and everyone else. The user and group that own the file can be changed by the root user.

# Adding a User

Users can be added through the command line or the GUI. Most user and group properties have default values that will be used during account creation.

Before adding a user you should be logged in as root. You can connect quickly as the root user by using the **su** command. The su, substitute user, command changes the effective userid and group id to those of a user identified in the command. The syntax of the su command is `su [-options] [-] [user]`. The default user is root if the user is not identified. The hyphen (-) logs in with a new login shell in the designated user’s home directory as if the user had logged in originally. For example, to log in as the root user type **su - root**.

For a user, all that must be identified is the username and password. To create a user from the command line, use the command **useradd username**.

For example, **useradd jsmith** creates an account called jsmith. The following properties were not explicitly defined. Some have a default value; others have no value unless explicitly created.

- `-c comment`: The new user’s password file comment field.
- `-d home directory`: This creates a user’s login directory. The default is to append the user’s name to the home directory.
- `-e expire date`: The date this account will automatically be disabled.
- `-f inactive days`: The number of days after a password expires until the account is permanently disabled. This can have a value of 0 to disable the account as soon as the password has expired, and a -1 to disable this feature.
- `-g initial group`: The group name or number of the initial group for this account. The default group number is 1 or whatever is specified in /etc/default/useradd.
- `-G group[,...]`: A list of supplementary groups that the user is a member of. Each group is separated by a comma.
- `-m`: Create the home directory if it doesn't exist. The default is to create the directory when the user first logs in to the system.
- `-M`: Create a user account without a home directory.
- `-n`: A group having the same name as the user is added to the system.
- `-o`: Allow creation of a user with a non-unique UID.
- `-P`: Include the encrypted password.
- `-r`: Used to create a system account (an account with a UID lower than 500).
- `-s shell`: The default shell that the user will use. Shells are discussed later in this chapter.
- `-u uid`: The numerical value of the user ID. The default is greater than 99 and greater than every other user.

# Deleting a User

Users can be deleted with the command-line interface or the GUI. The **userdel** command deletes a user and optionally removes the user’s home directory. Before deleting a user you must be logged in as root. (Use the **su - root** command to log in as root.)

To remove a user, the user cannot be currently logged in. You must kill any running processes that belong to the user. You cannot remove any NIS attributes on an NIS client; this must be done on the NIS server.

To delete a user named jsmith and the user's home space, use the command **userdel -r jsmith**. The -r option indicates that the home directory and the user's mail spool will be deleted. Other files will not be removed. You must look for files owned by the user and remove them manually.

# Adding a Group

A new user, by default, is assigned to a private group with the same name as the user. The user private group (UPG) makes it easier to assign file permissions for new users; however, new users are often grouped by function, department, or some other criteria. To assign rights and permissions to resources for users, groups are created and given rights and permissions, and then users are added to the groups.

To add a group from the command line, type **groupadd mygroup** where *mygroup* is the name of the new group. The available options are:

- `-g GID`: Where GID is the numerical value of the group's ID. This is a unique value, typically 500 or greater.
- `-r`: Used to add a system group account. Automatically uses the first available GID lower than 499.

To add a group from GNOME, perform the following steps.

1. Start by selecting the **main menu**. This is usually the first icon on the task bar at the bottom of the screen. Look for a configuration menu and then find a Group entry. In Mandrake Linux, select the **main menu**, **Configuration**, **Other**, and **Userconf** (refer back to Figure 4-4).
2. Select **Group definitions** from User account configurator (Figure 4-11). The User groups dialog box is displayed. Click the **Add** button to add a group. The **Group specification** dialog box is displayed.

![](img/37f079cee226b270f2e09b37a2e4a05d_102_0.png)

Enter the **Group name** in the **Base info** tab and click **Accept**. Members of the group can be defined in the **Alternate members(opt)** box (Figure 4-12) by typing the username of each member separated by a space.
