An environment variable can be changed or modified after it is defined. For example, to change the PATH variable, adding /opt/oracle to the path, use the following commands:

```
# echo $PATH
/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/usr/X11R6/bin:/root/bin
# export PATH=$PATH:/opt/oracle
# echo $PATH
/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:/usr/X11R6/bin:/root/bin:/opt/oracle
#
```

**NOTE**
The PATH environment variable lists the directories for the system to check when executing a program. Paths are separated using the colon ( : ).

# ### Configuration Files

Configuration files give an administrator an easy way to change how a program works. After values in a configuration file have been changed, the program that uses it will behave differently. For example, if the value **id:5:initdefault:** in the inittab configuration file is changed to **id:3:initdefault:** , the user will automatically be in the command-line interface instead of the GUI interface the next time the Linux operating system starts.

Before you make any changes to a configuration file, you should back it up. For example, before changing the **/etc/inittab** file, you may want to copy it to **/inittab.backup** . You should also know what the configuration file is used for and the possible values of its variables. Values and fields for common configuration files, in many cases, can be discovered in the man files. For example, to get information about the /etc/inittab file, you can enter the command **man inittab** .
