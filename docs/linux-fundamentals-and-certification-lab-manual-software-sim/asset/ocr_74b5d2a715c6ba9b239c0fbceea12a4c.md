**Desktop Workspace** The workspace is the largest component of the desktop. It displays windows and icons that are currently being used. The default components displayed include icons for the CD-ROM, floppy drive, Home, and Trash.

The CD-ROM and floppy icons give quick access to those devices. A CD or floppy disk will be mounted automatically when inserted in the device. Right-clicking either icon will display a shortcut menu to mount, open, or copy the device.

The Home icon is a link to the user's home directory. Double-clicking this icon will display the file manager view of the directory.

The Trash icon contains items that are to be deleted from the system. You can drag items to the Trash container from the desktop or a file manager window. Items in the Trash container are held until the Trash Bin is emptied. Before Trash is emptied, items may be retrieved. After Trash is emptied, the items that were in it are completely removed from the system.

To add an item to the desktop (Figure 10-21), right-click an empty area of the desktop to display the shortcut menu. Select **Create New** and then the type of item to add.
