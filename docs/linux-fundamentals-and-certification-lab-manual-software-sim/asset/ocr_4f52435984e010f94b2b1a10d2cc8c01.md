# ■ INSTALLING AN EIDE/ATA HARD DRIVE

![](bbox=[0.22, 0.79, 0.28, 0.82])

Installing a hard drive in the computer case is relatively simple. Most system cases today have ready-to-use hard drive bays. Some hard drives require the use of rails, which are not usually shipped with the drive, but are available from the case manufacturer.
