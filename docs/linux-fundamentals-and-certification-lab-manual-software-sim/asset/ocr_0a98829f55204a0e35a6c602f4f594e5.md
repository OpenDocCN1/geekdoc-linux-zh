# SUMMARY

Commands are used to control all aspects of the Linux operating system. Commands allow a user to manage directories, mount and unmount file systems, manage users and groups, and manage files. The command-line shell used by default in Linux is **bash**. A command line is typically used by administrators for Linux maintenance and administration. The command-line environment is controlled by environment variables. Common environment variables identify the default path, the pathname of specific directories, and others.
