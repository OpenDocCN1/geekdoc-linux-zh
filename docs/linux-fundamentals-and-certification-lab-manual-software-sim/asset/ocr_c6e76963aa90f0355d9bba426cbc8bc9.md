When creating a new partition you also indicate the type of file system to use. The most commonly used file systems are the Linux Native ext2 and ext3, but you may select a FAT type partition if you want to share information with a DOS or Windows installation. A swap partition is a special file system type. You must have at least one swap partition. The types of file systems were discussed in Chapter 2. Table 3–3 lists the available file systems for this installation.
