# ## MONITORING YOUR NETWORK

**Objective 4.9** After a network is configured, it should be monitored. Networks change over time. Hosts are added and removed, new services are added, and many other things occur that can affect how a network reacts.

Several network tools are available to check how a network is functioning. For example, the **who** command will tell you who is logged on at any given time. Some of the commands to monitor your system are listed below.

**who [option]**  The who command with no options shows who is logged on. Options can be viewed with the *man who* command.

```
# who
root pts/1 Oct 15 19:13
(pcp03396479pcs.tsclos01.al.comcast.net)
#
```

**w [user]**  The w command gives a more detailed list of information about who is logged on. Additionally, you can provide a username to get detailed information about a single user.

```
# w root
19:26:29 up  7:38,  1 user,  load average: 0.00, 0.00, 0.00
USER  TTY  FROM  LOGIN@  IDLE  JCPU   PCPU  WHAT
root pts/1 pcp03396479pcs.t 7:13pm 0.00s  2.03s 0.03s w root
```

**finger [user@host]**  finger entered by itself will display a list of the users that are logged on. finger with a username and hostname will return information about users on a remote system.

```
# finger
Login Name Tty Idle Login Time Office Office Phone
root root pts/1 Oct 15 19:13
(pcp03396479pcs.tsclos01.al.comcast.net)
```

**last [username]**  To track login information to the Linux system, the **wtmp** file is used. The wtmp file, in the /var/log directory, is rotated based on the information in the /etc/logrotate.conf file. The last command will use this file to display a listing of every login since the last time the log file was rotated. Including a username with the last command will display information about a single user.

```
# last dangle
dangle pts/1 pcp03396479pcs.t Fri Oct 10 01:30 - 01:31
(00:00)
dangle pts/0 engle-ee102.dave Wed Oct 1 08:18 - 08:22
(00:03)
wtmp begins Wed Oct 1 08:18:10 2003
```

**netstat**  The netstat command can be used to print a list of current network connections, routing information, and interface statistics.
