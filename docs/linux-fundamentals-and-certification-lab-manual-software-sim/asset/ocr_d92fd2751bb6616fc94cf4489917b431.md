# **Objective 2.9 Using a CD-ROM**

Using a CD-ROM is similar to using a floppy drive. The CD-ROM must be mounted before use and unmounted after use. A CD-R or CD-RW can also be written with data using the **cdrrecord** command.

To mount a CD you must first find the device. View the *etc/fstab* file to see the available devices. Typically, the first CD-ROM will have the following entry:

/dev/cdrom       /mnt/cdrom        udaf, iso9660     noauto, owner, kudzu, ro  0 0

Similar to the floppy device, this CD-ROM is located at /dev/cdrom and uses the mount point /mnt/cdrom. To mount the CD-ROM, use the command **mount /dev/cdrom /mnt/cdrom**.

After the CD is mounted you can read it using the **ls** or **cp** command. CD-ROMs are mounted as read-only devices.

To change the CD you can **unmount** the drive or use the **eject** command. You can use the eject command to eject the CD-ROM by typing **eject cdrom**. After the drive ejects the CD, insert the next CD and start over.

CD-Rs and CD-RWs can be written with data. The **cdrrecord** command is available and will work on almost all Linux systems. If the cdrrecord command is not loaded on your system you can download the package from the official site *ftp://ftp.berlios.de/pub/cdrrecord/.*

To find your CD writer, use the **-scdbus** option. Typing **cdrrecord -scdbus** will display drives that are installed and recognized. For example:

```
# cdrrecord -scdbus

cdrrecord 2.0 (1686-pc-linux-gnu) Copyright (C) 1995-2002 Jörg Schilling
Linux sg driver version:  3.1.24
Using libscg version 'schily-0.7'

scsibus0:
  0,0,0  0) '  ' '48X12X50 CD-RW' '1.00' Removable CD-ROM
  0,1,0  1) *
```

The above display shows that the device is 0,0,0.

To burn an ISO image, use the following cdrrecord command:
**cdrrecord -v dev=0,0,0 speed=0 driveropts=burnfree -eject -data myfile.iso**
where:

+   * -v
				* Verbose
	* dev=0,0,0
				* Sets the SCSI target for the CD recorder
	* speed=0
				* Set the speed factor of the writing process
	* driveropts=burnfree
				* Driver options burnfree turns on Buffer Underrun Free
	* -eject
				* Ejects the CD when the process is completed
	* -data
				* Uses CD-ROM mode 1
	* myfile.iso
				* Use the ISO file myfile.iso

The options for cdrrecord can be found using the **man cdrrecord** command.

# **SUMMARY**

During startup, the Linux operating system performs a power-on self-test (POST), loads the BIOS from ROM, then displays boot options via the boot loader, usually GRUB or LILO.

The Linux kernel is loaded into memory from the boot device and control is passed to it. The init program is then executed and controls the remainder of the boot process.

Init uses several scripts during startup:

+   * */etc/rc.d/rc.sysinit* sets environment values such as path, starting swap, and checking file systems. rc.sysinit uses *etc/sysconfig* configuration files and scripts.
* */etc/initab* describes how the system should be set in each runlevel.
