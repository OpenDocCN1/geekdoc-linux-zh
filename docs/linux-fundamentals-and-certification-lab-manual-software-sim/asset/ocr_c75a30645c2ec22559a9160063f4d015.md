# ### Disk Configuration

As discussed in Chapter 2, disk partitioning allows you to divide your hard drive into dif-ferent sections. Each physical hard drive can have four partitions. You can have either four primary partitions or three primary partitions and one extended partition. An extended par-tition can be divided into multiple logical partitions.

Each disk partition is attached to the system as a directory. As you navigate from directory to directory, you can connect to separate disk drives or partitions on disk drives. Partitions are designed to physically separate information on a hard disk for disk perfor-mance, security, and backup considerations.

You can allow Red Hat installation to automatically partition your disk, or you can manually partition the disk using Disk Druid. There are several ways to partition your hard disk, but you will find that Disk Druid is easy to use and is somewhat intuitive to your needs.

For purposes of this installation, indicate automatic disk partitioning by selecting Autopartition, shown in Figure 3–8. This option will create a swap partition, a /boot partition, and a / (root) partition. These are the partitions most commonly used for an installation.
