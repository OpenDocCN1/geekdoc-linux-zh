To extract a single file or group of files from a tar, use the following syntax: **tar -xvf tar_filename.tar filename**, where *tar_filename.tar* is the name of the tar file and *filename* is the name of the file to be extracted. For example, to extract the file *adomfaq.txt* from the archive *adom_11-01-2003.tar*, use the following command:

```
tar -xvf adom_11-01-2003.tar home/jsmith/adom/adomfaq.txt
```

# **NOTE**

Files extracted from a tar will be placed in the same directory structure that they were archived from, starting in the current directory. For example, extracting the tar file *adom_11-01-2003.tar* while in the `/home/jsmith` directory will extract the files to `/home/jsmith/home/jsmith/adom`.

Be careful not to accidentally overwrite existing files. When you extract a file from a tar, if a file with the same name exists you will be prompted to replace the file or not. It is possible to have files on the system that have the same name, but are used for different purposes. For example, it is very common to have a file named *readme.txt* that describes the usage of a program in an archive. This same name can be used in many different files. When you extract a new program to a pre-existing directory that has other files, you risk overwriting an existing file with the same name.

# ## Updating an RPM Package

Most good programs are continually changing. As computer hardware improves, the programs it runs are updated to exploit the new features. Programs also evolve over time to meet the needs of program users. As new programs are released, existing programs can be updated.

Because RPM keeps a database of characteristics and storage locations, it can easily update existing programs. The syntax is similar to that of an RPM install (Figure 6-4), **rpm -options rpm_filename.rpm**, where *rpm_filename.rpm* is the name of the new RPM package. To upgrade an RPM package called *tftp-server* with the new package *tftp-server-0.32-4.i386.rpm* (Figure 6-5), use the following command:

```
rpm -Uvh tftp-server-0.32-4.i386.rpm
```
