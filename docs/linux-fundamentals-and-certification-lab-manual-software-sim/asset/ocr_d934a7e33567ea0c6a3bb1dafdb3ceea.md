All applications within the Linux operating system are executed from programs or scripts. A script is a list of commands that are executed through the control of the script.

A commonly used text editor for command-line interfaces is vi. The vi program allows a user to edit any Linux file, including binary files. Learning the vi program is essential to Linux administration. GUI interfaces for Linux abound. These offer all the features of a GUI operating system. Using the mouse for point-and-click operations is easier for novice users than using the more traditional command-line vi program.
