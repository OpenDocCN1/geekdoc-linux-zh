**Using awk**   The awk command looks for a pattern and does an action for every match. The syntax of awk is *awk '/pattern_to_find/action/' file_to_use*, where *pattern_to_find* is the string to match in the file, action is the command to execute when the pattern is matched, and *file_to_use* is the file awk will be working with.

For example, to list every line from the *sed_test* script that contains a capital J, use the *awk '/J/{print}' /root/sed_test* command.

The awk command looks through the *sed_test* file and lists the lines that match the pattern. Figure 6–18 shows a sample run of this command.

**Using sort**   The *sort* command (Figure 6–19) will arrange a file in sequence. Use the *-r* option to arrange the file in reverse order. For example, to sort the file *data1* in alphabetical order, use the *sort data1* command.

To arrange the file in reverse order, use the *sort -r data1* command.
