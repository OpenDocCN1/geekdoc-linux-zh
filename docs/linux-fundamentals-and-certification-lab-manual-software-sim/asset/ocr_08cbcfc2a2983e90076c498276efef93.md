**local master**  The Windows network requires a central location that keeps track of what machines and workgroups exist on the local subnet. This is called a local master. Any Windows machine can be the local master browser. Setting the local master to *yes* indicates that Samba can be that machine.

**os level**  A machine on a Windows network becomes the local master by broadcasting its presence. The os level of Windows machines is hard coded to cause the most advanced version of the operating system to be the local master. By setting the os level to 99, you beat every Windows machine, which allows the Linux Samba server to become the local master.

**hosts allow**  The hosts allow entry sets which IP networks are allowed to access the network share. In this case the networks are **192.168.0.** and **127.**. The network portion of the IP address is listed, not the host portion. The 127 network is localhost.

**interfaces**  If your Linux server has more than one Ethernet adapter, you can specify which adapter will be used for Samba.

The next section, **[tmp]**, is the name of a share. On Windows this share will display as a directory on the Linux server. Figure 8--11 shows the Linux server Styx with its tmp directory displayed. If any printers are available on the Linux Samba server, they will be displayed as well.

Your very basic smb.conf file is configured. You can test the content of the file by using the Samba-provided utility **testparm**. Any errors to the configuration file will be displayed. Follow the instructions from the displayed list to correct any errors.

# Creating Samba Users

Before a client can access our share, there must be a valid user ID and password in the Samba password file. In this Samba installation the password file is /etc/samba/smbpasswd. This file contains the user ID and an encrypted password string for each authorized user. Entries in the smbpasswd file must have corresponding entries in the Linux main /etc/passwd file.

To add a user to the smbpasswd file, use the *smbpasswd* command. To add the user jsmith to the Samba password file, use the **smbpasswd -a jsmith** command.
