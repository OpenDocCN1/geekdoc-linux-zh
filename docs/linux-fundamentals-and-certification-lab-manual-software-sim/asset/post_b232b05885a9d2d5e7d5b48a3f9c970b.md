
The ps line shows the pid, or process ID, assigned to the service. If any changes are made to the smb.conf file, the services must reread the configuration file. The `kill -HUP pid` command is used to reread the configuration file. The kill command kills a process. The -HUP is a signal that kill should have the process reread the configuration file. The pid is the process ID. This can be found with the ps command shown previously.

You can send several signals to the kill process. Signals for kill have a number and an assigned name. A 9 (SIGKILL), for example, indicates that kill should immediately destroy the process. A normal kill sends signal 15 (SIGTERM), which gives the process a chance to do housekeeping and then terminate gracefully. The 1 (SIGHUP), or HUP, indicates that kill should have the processes reread the configuration file.

To have the smbd and nmbd processes reread the configuration file, find the pid of each process and then issue the kill -HUP command.

```bash
# ps -ef | grep smbd
root         14596     1  0 08:16 ?        00:00:00 smbd
root         14600  14535  0 08:16 pts/1  00:00:00 grep smbd
# ps -ef | grep nmbd
root         14598     1  0 08:16 ?        00:00:00 nmbd
root         14602  14535  0 08:16 pts/1  00:00:00 grep nmbd
# kill -HUP 14596
# kill -HUP 14598
#
```

## SUMMARY

Linux configuration files are either system related or user related. System-related configuration files are used to configure what services Linux executes when it starts, properties for the services, and general properties that are available. User-related configuration files provide properties for users either individually or globally.

Configuration files can be edited and changes made that affect the system or users. Every configuration file is a standard text file that can be easily manipulated. Most entries are in the form of a name/value pair, where an entry such as path is assigned a value such as /tmp as in PATH=/tmp.

After configuration files are changed, the services to which they apply must be restarted. In the case of a system file, you may need to restart the server. For user-related entries, logging off and then logging back on will reread the configuration information.

Services can be restarted with the `service service_name restart` command. GUI programs are available that make restarting services easier for novice users.

Two methods of sharing resources on Linux machines are Network File System (NFS) and Samba. NFS is the oldest method and the one most widely used in purely Linux environments. Samba uses the Microsoft Windows protocol SMB. Samba-shared resources can be used by Linux and Windows clients.
