# PRINTERS

Printing is a task that is available on every computer system. Setting up a printer would seem to be a simple task, and in some cases it is; depending on the printer, however, it is not always so simple. New tools for Linux have changed printer administration for the better.

One caution when picking a printer for your Linux system: Be sure to ask the dealer whether the printer will work with Linux. Some printers are especially designed to work with Windows and are difficult, if not impossible, to use with Linux. Chances are that the printer dealer will not know whether the printer works with Linux, but almost every printer manufacturer has an online presence with the information you need. You can also check with www.linuxprinting.org for their Linux printer compatibility list. This can save you a lot of time and trouble.

There are several different types of printers. The two most prevalent types today are ink-jet and laser printers. An ink-jet printer sprays the ink on the paper to form the characters to be printed. A laser printer uses a modified copier engine. Images are formed in the laser printer's RAM, then transferred to the copier.
