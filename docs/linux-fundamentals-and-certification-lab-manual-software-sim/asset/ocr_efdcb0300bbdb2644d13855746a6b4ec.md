The /var/log directory contains several log files. Most of the files are simple text files and can be browsed using Linux tools, such as vi, cat, more, or less. Some of the more interesting log files include the following:

+   * /var/log/boot.log Contains messages from the boot sequence.

+   * /var/log/cron Contains a list of cron jobs which shows which tasks were started and when.

+   * /var/log/dmesg Contains messages from devices. This log file should be viewed to help track hardware problems.

+   * /var/log/maillog Contains messages about e-mail.

+   * /var/log/messages Contains all error messages. This is the main system log and should be viewed to help resolve any problems.
