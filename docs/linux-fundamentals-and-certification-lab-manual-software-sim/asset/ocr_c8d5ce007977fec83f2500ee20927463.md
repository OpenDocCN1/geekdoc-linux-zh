To delete a print job, use the `lprm` command. To delete the print job listed above, use the following command:

```
lprm 3
```

If you are root, you can use lprm with no options to delete all print jobs. If you are a normal user, only the print files you own are removed from the print spool. The lprm utility reports on the tasks it kills.
The root user can kill all the print tasks issued by any user, by specifying a username.
To remove all print jobs of jsmith use the following command:

```
lprm jsmith
```

# LPRng Permissions and Authentication

There are several security issues when printing. Most printers in today's work environment are TCP/IP printers. If a printer is on the public network then anyone on the Internet can print to the printer. Networked printers should be configured so that only certain host IP addresses will be accepted.

Different print queue types use different methods for securing the printer. On LPRng, an extended and enhanced version of Berkeley LPR print spooler, the /etc/lpd.perm file is used to specify permissions and authentication before printing. An incoming request is tested against a list of rules (/etc/lpd.perm), and the first match found determines the action to be taken. The action is either ACCEPT or REJECT. An ACCEPT accepts the incoming print request and sends the file to be printed to the print spooler. A REJECT will block printing, and will not send the file to be printed to the print spooler.

The following simple permission file first specifies that lpc commands from user root will be accepted. Any other lpc requests are then rejected. The third, fourth, and fifth command lines accept requests from the host and user that submitted the job to remove the print job from the queue. Finally, all other types of commands are allowed by default.

```
# allow root on server to control jobs
ACCEPT SERVICE_C SERVER REMOTEUSER_root
REJECT SERVICE_C
#
# allow same user on originating host to remove a job
ACCEPT SERVICE_M SAMEHOST SAMEUSER
# allow root on server to remove a job
ACCEPT SERVICE_M SERVER REMOTEUSER_root
REJECT SERVICE_M
# all other operations allowed
DEFAULT ACCEPT
```

A service can specify the following request types.

| Key | Request |
| :-- | :-- |
| C | LPC Control Request |
| M | LPRM Removal Request |
| P | Job Printing |
| Q | LPQ Status Request |
| R | LPR Job Transfer |
| S | LPC Status Request |
| X | Connection Request |

Other entries in the file specify the following:

+   *   **DEFAULT**    The rule to follow if no other rules match
*   **REMOTEUSER** Information taken from the remote user that sent the service request
*   **SAMEHOST**   Indicates that the REMOTEHOST, retrieved by doing a reverse IP name lookup, and HOST, taken from the H information in the print job control file, must match.
