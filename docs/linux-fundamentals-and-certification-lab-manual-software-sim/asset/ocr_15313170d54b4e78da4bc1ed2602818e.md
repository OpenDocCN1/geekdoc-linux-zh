+   - h moves left one character  
- 0 moves to the beginning of the line  
- $ moves to the end of a line  
- G moves to the end of the file  
- w moves forward one word  
- b moves back one word  
- <ctrl>f moves down one screen  
- <ctrl>b moves up one screen

**Exit vi** with the :q or :q! command. The :q command exits the current file, and :q! forces exit of the current file, whether or not the file has been saved.

**Input mode** commands are used to enter text in a file.

+   - a appends text to the right of the cursor  
- A appends text at the end of the line  
- i inserts text at the current cursor position  
- I inserts text at the beginning of the line  
- o inserts text starting on a blank line below the current cursor position  
- O inserts text starting on a blank line above the current cursor position

**Save file** with :w or :w!. The :w command saves the file, whereas :w! saves the file even if the file is read only. If the text you’ve typed is not yet associated with a file-name, type :w *newfilename* where *newfilename* is the name of the file to be created on disk.

**Delete text** with x or X.

+   - x deletes text under the cursor  
- X deletes text to the left of the cursor

To start typing in a new file, type i to enter input mode and start typing. Anything you type after you are in input mode is displayed on the screen and can be saved with the file. While in input mode press Enter to type text on the next line. Before moving around the screen in input mode, you should first type esc to exit input mode.

# Searching Through a File with vi

If you want to find a specific string of text in the file you are editing, you can type /pattern where pattern is the string you are looking for. /pattern looks forward in the file, and ?pattern looks backward in the file. To repeat the search forward through the file, type the letter n, and to repeat the search backward through the file, type the letter N.

# Moving Lines of Text in a File with vi

To move a single line, position the cursor on the line to be moved and type dd to delete the line. Position the cursor where you want the line to be and type P. You can move more than one line by prefixing the dd command with the number of lines to be deleted.

# Copying Lines of Text in a File with vi

To copy a single line of text, position the cursor on the line to be copied and press the letter Y. Y copies the current line to the working buffer of vi. Position the cursor where you want the line to be and type the letter P. To copy multiple lines, prefix the Y command with the number of lines from the cursor to be copied.

**Settings** Settings allow you to change the way vi works. For example, by default vi does not display line numbers. To set vi to display line numbers, type :set number. To view other set commands, type :help set from vi command mode.
