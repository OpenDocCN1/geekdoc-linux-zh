+   * **df** This command will tell you how much disk space is available on all of your file systems. Files, especially log files, can grow in size until all available disk space is used. If this happens your system may fail. Some computer viruses will write information to the disk until all disk space is used. The df command should be run often to track the amount of disk space used.
