**/etc/inittab** The inittab file describes which processes are started at bootup and during normal operation. Entries within the file have the following format:
*id:runlevels:action:process*

+   • **id** Identifies an entry in inittab. This is a unique sequence of one to four characters.
• **runlevels** Lists the runlevels for which the action should be taken.
• **action** Describes how init handles the process. Some common values are:
    • **respawn** The process will be restarted if it terminates.
    • **wait** Linux will start the process and then wait for its termination. This is typical for initialization scripts. Often, one process must complete before another process can start.
    • **initdefault** This specifies which runlevel should be entered after the system boots. If no initdefault entry exists, init will ask for a runlevel.
    • **ctrlaltdel** This process will be executed when someone presses the CTRL+ALT+DEL key combination.
• **process** The name of the process to be executed.

The /etc/inittab contains getty programs. A getty program opens a tty port, prompts for a login name, and runs the /bin/login command. The getty program may be getty, agetty, mingetty, and others. (mingetty is a minimal getty used on virtual consoles.)

**/etc/fstab** The **/etc/fstab** file contains information about the various file systems. When you create file systems during the Linux installation the entries are automatically entered in /etc/fstab. It is up to the Linux administrator to create and maintain the /etc/fstab file thereafter. This file is read during startup or shutdown to mount and unmount the file systems listed. File systems are mounted and unmounted in the order that they are found on the list.

+   • The first field contains the block special device or *remote* file system to be mounted. For ordinary mounts it will hold a block special device for the device to be mounted, for example, /dev/fd0 for the first floppy drive. For NFS mounts, the entry name will be *host:directory*, for example, *myserver.linuxplus.com:/opt/oracle*.
• The second field describes the mount point for the file system. For example, root is described as / and the boot partition is described as */boot*. A swap partition will have the word “swap” in this field.
