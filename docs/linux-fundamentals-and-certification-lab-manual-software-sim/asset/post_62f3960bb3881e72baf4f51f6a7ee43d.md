
## The Desktop

The term *desktop* refers to the workspace used in a GUI environment. It provides a space similar to that of your office desk. Your papers and other material can be spread around your desk and organized to meet your needs. The same is true of a GUI desktop. The different documents you are working with can be organized and arranged to make them easy to find and view with desktop tools.

The basic components of a desktop are windows, menus, and icons (Figure 10–1). The desktop is accessed using the mouse.

![](img/37f079cee226b270f2e09b37a2e4a05d_281_0.png)

A window is the workspace for a single application or document within an application. The term *window* comes from the similarity between how a desktop window works and how a window in a building works. From a window in a building you can see only a portion of what is outside the structure. The same is true of a window on a GUI desktop. You may use a window to view a 1,000-page document, but can only see a portion of one page at a time. The GUI desktop can display many windows at a time. The windows can be sized and moved to organize the desktop, allowing the desktop to be customized to the user’s preference.

An icon is a picture that represents a program or document. You are already familiar with icons. The door of a public restroom often has an icon that represents what it is for; a *parking* space in front of a building may have an icon representing handicapped parking; and even a computer keyboard uses an icon for the Enter key. An icon on the desktop can be moved to suit the user. Icons are used to launch applications from the desktop. A menu displays a list of command options on the desktop. A menu has a list of available features that a user can browse through to select the application they want to use. Menus provide a way to run programs without cluttering the desktop with icons.

## Using the Mouse

The mouse is used to manipulate and manage the desktop. Several types of mouse-type products are available (Figure 10–2). They are all used to point-and-click on the desktop. A mouse usually operates in one of two ways. The mouse may have a ball on the bottom that rolls when the mouse is moved. This is translated into mouse pointer movement on the desktop. The other way a mouse works is with an optical device. The optical mouse has a light underneath, which is reflected off the surface. As with the ball-type mouse, when movement is sensed, it is translated to mouse pointer movement on the desktop.

![](img/37f079cee226b270f2e09b37a2e4a05d_282_0.png)

Several actions can be performed with the mouse. A simple mouse typically has two buttons, identified as the right and left mouse buttons. The following actions are available.

- Clicking an object with the left button selects that object. If the object is an icon, the icon is highlighted to indicate that it is selected. If you left-click a menu, the menu is immediately displayed, offering options that can be selected (Figure 10–3). If text is left-clicked, the insertion point is moved to the new position. Multiple objects can be selected by holding down the Ctrl or Shift keys while left-clicking.

### FIGURE 10–3

Menu selection.

![](img/37f079cee226b270f2e09b37a2e4a05d_282_1.png)

- Clicking an object with the right button displays a shortcut menu for that object. For example, right-clicking the desktop displays a shortcut (or pop-up) menu (Figure 10–4) with options for the desktop.

- Double-clicking the left button executes an action. (A double-click is two quick clicks of a button.) For example, double-clicking an icon on the desktop launches the application it represents. Double-clicking text selects a single word within the text.

- Clicking an object and holding down the button without releasing allows moving or resizing an object. If you press and hold down the left button on an icon and then move the mouse across the screen, the icon will be moved. Pressing and holding down the left button on the corner of a window and then dragging across the screen resizes the window. Pressing and holding down the left button on the title bar of a window and then dragging across the screen moves the window.

Using the mouse is easy and with a little practice, you will be proficient in its use.

## Windows

A window is the basic structure of the GUI desktop. A window can contain almost any information. For example, Figure 10-5 shows a window from a word processing application. Windows can display file folders, configuration items, and a host of other things.

Regardless of what the window displays, all windows have standard components. All the components can be displayed or hidden programmatically. This means that some components can be turned off or on if the developer of the windowed object desires it. The following list describes some of the more commonly used window components that are shown in Figure 10-5.

- **Title Bar**: The title bar displays information about the window. The title bar can be used to move the window.
- **Minimize Button**: The minimize button removes the window from the screen, and displays a button on the desktop bottom panel. Clicking the button on the bottom panel restores the window to its original screen location.
- **Maximize Button**: The maximize button causes the window to grow, using all available desktop workspace. If a window is maximized, the maximize button becomes a restore button. Left-clicking the restore button on a maximized window restores the window to its original size and position on the desktop.
- **Close Button**: The close button is used to terminate the window.
- **Control Menu**: The control menu button displays a menu of available window actions. Minimize, maximize, and close are included on the menu. (In a GUI environment there is a lot of duplication.)
- **ToolBar**: A toolbar is a group of icons that act as shortcut commands for the windowed application. For example, there may be a picture of a printer that, when left-clicked, will print the contents of the window.
- **Borders**: Borders can be used to resize a window.

Minimizing an application does not close the application. Programs are often run minimized so other work can be done using the desktop.

## GNOME

GNU Object Model Environment (GNOME) is one of the more popular desktop environments. GNOME is free and part of the GNU project.

GNOME is an application framework. This consists of a style guide for applications along with a set of libraries that enforce the style requirements. The libraries allow programmers to create applications with standard menus and dialog boxes.

GNOME is a file manager (Figure 10-6). The GNOME file manager is an application for browsing a file system with a GUI display. Directories are displayed as folders, and files as dog-eared pages.

![](img/37f079cee226b270f2e09b37a2e4a05d_284_0.png)

GNOME uses panels in the desktop environment. These allow access to all of the system applications and menus. The main panel is located across the bottom of the screen and is responsible for launching other applications and embedding small applets within itself.

GNOME provides session management, which means that GNOME tracks connections to the desktop and notifies applications so they can save state information when a user logs out. When the user logs back in, the applications can have the same values as when they were last used.

GNOME is a suite of applications. GNOME includes applications to configure the operating system, start and stop services, play games, and perform many other tasks. GNOME applications have a consistent look and feel.

## Panels

Panels (Figure 10–7) can be added or deleted from the desktop. The default GNOME desktop has one panel across the bottom of the desktop. Panels can be corner, edge, floating, menu, or sliding panels.

![](img/37f079cee226b270f2e09b37a2e4a05d_285_0.png)

To add a new panel, right-click an empty space on an existing panel to open a shortcut menu. Select **New Panel** and then click on the panel type you want.

To delete a panel, right-click an empty space on the panel you want to delete. Select **Delete This Panel** to open the **Delete Panel** dialog box. Click the **Delete** button on the displayed dialog box.

A panel can have many different types of objects embedded within it. Panels can have applets, menus, a window list, or a workspace switcher.

An applet is a program that resides within a panel. Any of the programs from the main menu can be added.

To add an applet, right-click an empty space on the panel where you want to add an application. Select **Add to Panel** to select an application from the application list. The selected application is displayed on the panel.

## Desktop

The GNOME desktop has all the basic desktop features of any GUI application. It allows a user to start an application, open files and folders, and use the desktop menu.

To open a desktop object, double-click the object. Preferences can be set in the file manager window to allow a single click to open an object.

Use the desktop menu to add a launcher (Figure 10–8) and right-click an empty area on the desktop to open a shortcut menu. Select **New Launcher** to open the Create Launcher dialog box. Add a name and select the command of the application to launch. Click the **OK** button.
