## DEFINING THE LINUX INSTALLATION

When installing the Linux operating system, you need to determine who will use the system and what the system’s main purpose will be. If you are going to use the system for personal use, you need to decide what your needs are. Will you use the system for personal productivity? If so, you need personal productivity software with word processing, spreadsheet, database, calendar, e-mail, and other applications. If you want to play games or do graphic design, you need higher-end video and sound hardware. Every use of the system will have certain requirements for hardware and software that must be met.

It’s important to document your installation. In a nutshell, you cannot keep enough information written down. Every system you install should have a written record listing the type of hardware, software, and other installation particulars. Use the installation checklist at the end of this chapter or create your own documentation.

Installing a Linux operating system is not too difficult, but you need to answer a few questions before you get started. For example:

- Who is going to use the Linux system?
- What are the budgetary constraints?
- What role will this Linux installation take?
- Do you have enough disk space for the installed role of your computer?
- Is your hardware compatible?
- Do you have enough memory?
- How much swap space do you need?
- What software will you need to accomplish your tasks?
- Are you going to install from a CD-ROM or by some other method?
- How is your system going to boot?
- What level of firewall protection do you need?
- What is the skill level of your users?

These questions and others will be answered in this chapter.

## YOUR LINUX INSTALLATION BUDGET

![](img/37f079cee226b270f2e09b37a2e4a05d_28_0.png)

No matter what type of installation you are going to do, you need to set a budget for the project. Whether for a personal system or a corporate installation, it is a good idea to have and follow a budget. It is easy to nickel and dime your system into hundreds or even thousands of dollars over your intended cost, so when setting your budget make sure you provide for unexpected costs. For example, after installation you may find that the backup device you are using is too slow for your purposes and needs to be replaced with a faster model.

The hardware is not the only budget item you will need to consider. Take into account software, maintenance, support, personnel, training, and communications as well.

### Hardware

You will probably find that your hardware budget is inadequate. The cost of a computer system is dropping, but can still be quite expensive for the right system that fits your needs. If you have to cut cost, consider a smaller hard drive. Hard drives today are measured in tens or hundreds of gigabytes, which is more than enough for most personal desktops and many servers. Consider using a smaller monitor. Flat LCD monitors are nice, but not really necessary. Hardware is discussed in more detail later in this chapter.

### Software

There is a lot of open-source and freeware software (as mentioned in Chapter 1), but you may find that the software you need is a commercially available package. The cost of some software includes not only the initial purchase, but annual upgrades, too. For example, if you are running a personal tax business filing tax returns for individuals, you will probably have to purchase tax program updates to reflect changes in tax laws from the previous year. Various software packages are discussed later in this chapter.

### Maintenance

Computer systems require maintenance items. These items can be small, such as floppy disk cleaning kits and blank CDs, or large, such as a replacement hard drive. Peripheral devices need maintenance as well. A laser printer, for example, will need replacement toner cartridges, drums, and other components.

### Support

If you maintain a business, support cost may be required. Support is provided for hardware and software. If you purchase an enterprise system, support becomes important to ensure you have the “up-time” required for your system. Software support provides updates and answers to technical questions that may be very difficult to answer from other sources.

### Personnel

A business may need additional personnel to operate and administer the new Linux installation. A computer operator may be needed to perform daily tasks such as starting backups or loading forms into printers. A Linux administrator may be needed to make necessary changes in configuration, schedule jobs, add users, and install new software. Smaller organizations may have one person that handles all the jobs; larger installations may require a staff of several people.

### Training

It is likely that most existing personnel have not used Linux before. Linux is growing, but still has a small market share when compared to other operating systems. Your budget may include training for all users for basic tasks and for a few users that will be doing administration tasks.

### Communication

Communication cost is ongoing. If you are going to maintain a connection for a server, you have to purchase equipment and communication lines to provide intranet and Internet access. Communication is a complicated topic and you may want to consider including a consultant in your budget to accomplish this task.

### Other Budgetary Items

When budgeting for a larger system, consider purchasing one large machine rather than several smaller machines. Linux is a multitasking, multiuser system. One system can provide resources for many users. For example, rather than providing larger hard drives for multiple machines, you can include one large hard drive for the server and provide home space for the users.

If your budget is very tight, you may consider using existing resources. Even an older 486 machine can be used as a workstation connected to a server. It is not necessary for a user to be running a Linux installation to connect to a Linux server. If users are more comfortable with Windows, they can continue to use it and still access resources on the Linux server. This could reduce the training cost as well as the hardware cost.

## INSTALLATION TYPES

![](img/37f079cee226b270f2e09b37a2e4a05d_29_0.png)

Linux can be used for anything from a personal desktop machine to a high-end server. The purpose of the installation will determine the hardware and software needs of the operating system. Linux is divided into four types of installations:

- Embedded
- Personal Desktop
- Workstation
- Server

### Embedded Linux

Embedded Linux installation refers to the functionality of the application, not that of Linux. What is different are the resources employed by Linux to achieve the application. Embedded Linux is a feature-rich subset of Linux, stripped down to include only those elements of Linux that are useful on an embedded system. The smaller size of the embedded Linux operating system allows devices to use flash RAM to hold the operating system instead of a hard drive.

Embedded Linux can be employed to control high-tech gadgets including security video cameras, PDAs, mobile phones, audio/video, routers, and wireless access points. Linux is lightweight when compared to other operating systems such as Windows, yet Linux is versatile and robust, and can be used to accomplish a wide range of tasks. It can also be easily upgraded. Manufacturers of products that need an embedded operating system are opting for Linux rather than designing their own operating system from scratch.
