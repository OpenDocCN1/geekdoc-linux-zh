The next step manually sets the machine date and time, as shown in Figure 3-34, and will also adjust the clock on the computer’s Basic Input/Output System (BIOS). To set the day, month, and year on your system, click the date, and then use the controls for the time.

The computer can automatically synchronize the date and time automatically with a network time server using the Network Time Protocol (NTP). A network time server is a computer that sends accurate date and time settings to other computers through a network connection. Check the box labeled **Enable Network Time Protocol** and then use the drop-down menu to select the time server to use.

If you purchased a *boxed* distribution set, register your system with Red Hat Network (Figure 3-35). Selecting **Yes, I would like to register my system with Red Hat Network** allows you to receive automatic updates of Red Hat Linux. To skip this step, select **No, I do not want to register my system**. Should you change your mind and want to register later, you can go to http://www.redhat.com.
