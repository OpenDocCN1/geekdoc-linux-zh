If you want to move a file to trash, navigate to the folder that contains the file. Right-click the file to display the shortcut menu and then select **Move to Trash**.

# NOTE

> Moving a file to trash removes it from the directory, but keeps it in a temporary storage area. If you are sure the file can be removed, the trash can be emptied. If the file should be kept, it can be removed from trash and placed back into the folder.

# KDE

As with GNOME, K Desktop Environment (KDE) is a powerful desktop application designed to work with Unix/Linux. KDE, shown in Figure 10–16, is a suite of applications working together to provide not only a desktop, but also a working environment for system administration, file management, and user productivity.

KDE was developed by a group of several hundred software engineers from all over the world. The KDE project is a free software project under the GNU LGPL/GPL licenses.
