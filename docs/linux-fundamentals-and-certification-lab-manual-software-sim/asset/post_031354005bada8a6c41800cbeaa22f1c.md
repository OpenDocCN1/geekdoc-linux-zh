To complete installation of your new SCSI drive, follow the instructions for an IDE drive mentioned in the previous section. Replace the hd in the instructions with sd. For example, to partition an IDE drive, you type:

```
# fdisk /dev/hdc
```

To partition a SCSI drive, you would type:

```
# fdisk /dev/sdc
```

Formatting is accomplished through the mkfs command:

```
# mkfs -t ext3 /dev/sdc1
```

## OTHER HARDWARE CONSIDERATIONS

![](img/37f079cee226b270f2e09b37a2e4a05d_47_0.png)

IEEE 1394 is a very fast external bus standard that supports data transfer rates of up to 800 Mbps. The newer Linux distributions support this standard. A single 1394 port can support up to 63 external devices. IEEE 1394 is not only for hard disks. IEEE 1394 devices can include video, keyboards, CD-ROMs, and others. IEEE 1394 also supports plug-and-play (the ability to readily recognize attached devices) and hot plugging (the ability to remove and attach devices without restarting the machine); it also provides power to peripheral devices.

System boards have settings to configure built-in ports and other settings. Most new boards have these settings configured in CMOS, Complementary Metal Oxide Semiconductor. CMOS chips require very little power and are usually powered by a small battery, and they hold information such as date, time, peripheral settings, and other settings. A built-in program of the system board lets a user enter and save the CMOS settings on startup. Some system boards have jumper settings that are used to set many of the settings controlled by CMOS in other systems.

### Peripheral Devices

A peripheral device is defined as any device that is attached to a computer system. For example, a printer is a peripheral device. Properly connecting peripheral devices and configuring them is an administrative task. Peripheral devices are connected to standard ports, which should be configured before installing Linux.

Peripheral devices are connected to ports built into the system unit. Most of the system unit ports are configured from CMOS. The two most commonly configured ports are parallel and serial ports. These are typically used to connect printers and external modems.

Usually the built-in ports do not need any configuration changes, but if you add a port or need to change a setting, specific values are typically assigned to ports. These values include the I/O address and the Interrupt Request (IRQ). The I/O address is the memory address the system uses to communicate with the device. An Interrupt Request is a signal the system uses to indicate when time will be spent by the system accessing the device. Some of these values are listed in Table 2-4.

Many settings for ports seem to conflict with each other, but that is generally not a concern. For example, a system may have two serial devices, one using IRQ 3 and the other using IRQ 4, but using more than two serial ports is generally not necessary. The additional settings are typically used when a conflict arises.

Common peripheral port settings.

## SOFTWARE AND SERVICES

**Objective 1.5**

The software and services that are available on a Linux system reflect the function of the installation. A personal desktop would usually need the GUI and personal productivity software, but not server services, such as Dynamic Host Configuration Protocol (DHCP) or Domain Name System (DNS). Software can always be added if enough resources are available, but you should plan your software and services implementation before installation to ensure that the resources available are sufficient.

Table 2-5 is taken from a Red Hat Linux distribution. Not all distributions have the same software, but it is a good example of the software and services you can expect to find.

You may intend to install commercial software on your system. You should contact the software vendor and make sure the Linux distribution you choose is supported. There may be a version of the software you can run “out-of-the-box,” or it may need to be compiled for your specific installation.

Some commercial software packages require a lot of disk space to install, and even more to run. The amount of disk space needed can be calculated by the software vendor.

## ALLOCATING STORAGE SPACE

Nearly every computer system today uses disk partitions. Partitions are a standard in the computer industry. However, with so many preconfigured computer systems, many users don’t understand how disk partitions work or even what they are.

Hard disk drives are relatively simple devices, or at least they’ve been around so long that the approach to using them is very standard. Their purpose is to store data and reliably retrieve it.

A hard disk is designed to be “formatted” for the specific operating system that will be controlling it. By formatting a drive you are creating a file system on the drive. A file system uses a small percentage of the drive space to accomplish its task of organizing the storage structure of the data. It divides the remainder of the drive into small segments called blocks. There are several file systems that are not necessarily standard between different operating systems. For example, a Linux ext3 file system is not readable by a Windows NT system, and the Windows NT NTFS file system is not fully available to a Linux system.
