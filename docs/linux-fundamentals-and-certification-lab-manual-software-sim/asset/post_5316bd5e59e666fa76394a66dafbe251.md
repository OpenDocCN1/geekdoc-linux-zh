## INTRUSION DETECTION SYSTEMS

**Objective 4.7** An Intrusion Detection System (IDS) inspects all inbound and outbound network activity and identifies suspicious patterns that may indicate a network or system attack. The difference between a firewall and an IDS is that a firewall prevents access between networks to prevent intrusion, whereas an IDS identifies action to be taken once an intrusion has been detected. There are several categories of IDS; misuse detection, anomaly detection, network-based system, host-based system, passive system, and reactive system.

- **Misuse detection** This category of IDS compares network traffic to a database of attack signatures. This is similar to the way virus detection works and is only as good as the database of signatures.
- **Anomaly detection** This category of IDS compares the current state of the network to a baseline or normal state.
- **Network-based system** This category of IDS analyzes network traffic to detect suspicious packets.
- **Host-based system** This category of IDS is similar to a network-based system, but it analyzes only the traffic on a single host.
- **Passive system** This category of IDS will detect a security breach, log the occurrence, and send an alert.
- **Reactive system** This category of IDS will detect a security breach and take action against it. This action could be to log off a user or to block traffic from a specific source.

## LIDS

Several types of IDS are available for Linux, including an enhancement to the Linux kernel called LIDS (Linux Intrusion Detection System). LIDS implements several security features, including mandatory access controls (MAC), a port scan detector, file protection, and process protection. You can download LIDS from www.lids.org.

## Snort

Snort is an open-source network intrusion detection system. It performs real-time network traffic analysis and packet logging. It can perform protocol analysis, content searching, and matching, and can detect several types of attacks. You can download Snort from www.snort.org.

## PortSentry

PortSentry is part of the Abacus security tools. It detects and responds to port scans against a target host in real time. It runs on TCP or UDP, detects several attack signatures, can react to a port scan by blocking the host, and provides alerts to report the attempt. PortSentry can be downloaded from www.insecure.org.

## Security Appliance

Several network IDS tools are available. These are typically called stand-alone security appliances. Security appliances are basically stand-alone, special-purpose computers that detect intrusions and manage blocking and alerts from a network site. Cisco provides several security appliances to fit almost any size network. For more information about Cisco IDS, view the company's site www.cisco.com.

## MONITORING YOUR NETWORK

**Objective 4.9** After a network is configured, it should be monitored. Networks change over time. Hosts are added and removed, new services are added, and many other things occur that can affect how a network reacts.

Several network tools are available to check how a network is functioning. For example, the **who** command will tell you who is logged on at any given time. Some of the commands to monitor your system are listed below.

**who [option]**  The who command with no options shows who is logged on. Options can be viewed with the *man who* command.

```
# who
root pts/1 Oct 15 19:13
(pcp03396479pcs.tsclos01.al.comcast.net)
#
```

**w [user]**  The w command gives a more detailed list of information about who is logged on. Additionally, you can provide a username to get detailed information about a single user.

```
# w root
19:26:29 up  7:38,  1 user,  load average: 0.00, 0.00, 0.00
USER  TTY  FROM  LOGIN@  IDLE  JCPU   PCPU  WHAT
root pts/1 pcp03396479pcs.t 7:13pm 0.00s  2.03s 0.03s w root
```

**finger [user@host]**  finger entered by itself will display a list of the users that are logged on. finger with a username and hostname will return information about users on a remote system.

```
# finger
Login Name Tty Idle Login Time Office Office Phone
root root pts/1 Oct 15 19:13
(pcp03396479pcs.tsclos01.al.comcast.net)
```

**last [username]**  To track login information to the Linux system, the **wtmp** file is used. The wtmp file, in the /var/log directory, is rotated based on the information in the /etc/logrotate.conf file. The last command will use this file to display a listing of every login since the last time the log file was rotated. Including a username with the last command will display information about a single user.

```
# last dangle
dangle pts/1 pcp03396479pcs.t Fri Oct 10 01:30 - 01:31
(00:00)
dangle pts/0 engle-ee102.dave Wed Oct 1 08:18 - 08:22
(00:03)
wtmp begins Wed Oct 1 08:18:10 2003
```

**netstat**  The netstat command can be used to print a list of current network connections, routing information, and interface statistics.

## SUMMARY

In the early days of networks, there were many different and proprietary network topologies and protocols. Today, the primary network topology is Ethernet with TCP/IP protocols.

## CHAPTER 7

Network design is based on the Open System Interconnection (OSI) model. The OSI model identifies seven layers of network function; application, presentation, session, transport, network, data link, and physical.

Network components include hosts, hub, switches, and routers. Hosts communicate using all seven layers of the OSI model. Hosts include computers, routers, and other TCP/IP devices. A hub is a physical layer device that connects multiple computers together in a network segment. A switch is a data-link layer device that connects multiple computers together in single or multiple network segments. A router is a network layer device that determines path determination and switching.

Networks are designed using ring, star, and bus topologies. The most common topology is Ethernet bus topology. Ethernet topology is also a broadcast topology, meaning that it broadcasts information to all hosts on the same network segment. Ethernet uses CSMA/CD.

The most commonly used protocol for network connection is Transmission Control Protocol/Internet Protocol (TCP/IP). TCP/IP is a suite of protocols for file transfer, remote login, e-mail, and other network functions.

Every host on a network must have an address associated with it. The IP addressing scheme defines three classes of IP addresses: A, B, and C. Class A addresses are in the range of 0 to 127, class B addresses from 128 to 191, and class C addresses from 192 to 223 in the first octet.

Configuring a computer on the network requires not only the IP address of the hosts, but also the address of the gateway, the DNS server, and other information. Addresses are configured on a host statically or dynamically. Dynamic addresses are obtained using the DHCP protocol.

Common applications for the network include Web browsers, e-mail clients, FTP clients, and others. Network applications that use passwords should use encryption to secure data transfer. One set of programs that offer secure communications is OpenSSH. OpenSSH has tools to transfer files, establish remote connections, and perform other tasks.

Resources on remote devices can be shared over a network with SMB and NFS protocols. SMB is a protocol that is used in Microsoft Windows applications for sharing resources. NFS is a protocol from Sun Microsystems that is used for sharing resources. Both protocols allow for mounting remote file systems locally.

Simple Network Management Protocol (SNMP) is designed to integrate management of different types of networks. An SNMP server application is an agent and an SNMP client is a manager.

Network Information Service (NIS) is a protocol that is designed to simplify user authentication. NIS allows users to authenticate across multiple hosts.

Remote access to a server is used to remotely manage computer systems. Non-secure programs such as Telnet and rsh are not recommended. The OpenSSH program, ssh, is a better choice because it uses RSA keys for secure communication.

Firewalls are used to restrict access to network resources. Typically, a router acts as a gate to an internal network, restricting access from untrusted networks. Firewalls can be hardware or software. Hardware firewalls are dedicated devices that offer better utilization of bandwidth than software firewalls.

After a network is configured, it should be monitored. Tools for monitoring a network are who, w, finger, and last. The wtmp log file is used to track login information.
