If you selected a graphical startup, the GUI login screen will be displayed (Figure 3-37). Enter the login account you created during the Setup Agent or root. At the password prompt enter the password; it will not be displayed.

Most Linux distributions have a log file of the installation options. This file contains a list of what files were installed and any failures. The Red Hat install log is **root/install.log**. To view this file from text mode, type **less /root/install.log** and then press Enter.

> **NOTE**
>
> The less command provides options to move forward and backward through a file. Use F to go forward a screen, B to go back a screen, H for help, and Q to quit viewing. There are many other commands for less. To view the commands and options for less, type **man less** from the text prompt.

The GUI has a shell prompt, an application similar to text mode that allows you to type commands. Many users prefer the shell prompt over the GUI for entering commands. The shell prompt is faster to use than the GUI for many commands.

To open a shell prompt, right-click an open space on the desktop and select **New Terminal** from the resulting menu. To exit a shell prompt, type the word **exit** and press Enter.

To shut down the system from the text environment type **shutdown -h now**. This tells Linux to halt the system immediately.

To shut down Linux from the GUI prompt, click the bottom left icon on the GNOME desktop and then select **Log Out** from the menu. A confirmation dialog box displays with actions to **Log Out**, **Shut Down**, or **Restart** the computer. Select **Shut Down** and then click **OK**. After Linux shuts down, it is safe to power down the computer.

## DOCUMENT YOUR CONFIGURATION

The most important part of any installation is documentation. Documentation is the installation task that is the most talked about, and the least performed. Good documentation is necessary if you have to troubleshoot your system or perform another installation. Documentation should include all of the parameters entered during the installation as well as any changes made to the configuration.

Documentation should include boot configuration, keyboard and mouse parameters, video parameters, disk configuration, network setup, firewall settings, and the software installed. Use the installation checklist (see Appendix A) to guide your documentation efforts. The more information recorded, the better.

- Boot configuration should include the boot loader program, the default operating system, the boot loader location, and the boot loader password. Passwords are the first line of defense against unauthorized access to the Linux system and should be guarded accordingly. Server passwords, unlike user passwords, should be recorded and placed in a secure location. Otherwise, if something should happen to the administrator, parts of the Linux system may be rendered unusable.
- Keyboard and mouse configuration should include the language used and the mouse type.
- Video parameters should include the model, amount of RAM, resolution, and colors. Monitor parameters should be included.
- Disk configuration should include the type of hard disk and partition information. The file system and partition mount points should be included.
- Network settings should include whether the network parameters are entered manually or with DHCP/BOOTP. If these parameters are entered manually the IP addresses of the host, gateway, and DNS should be recorded.
- Firewall settings should include the ports permitted and denied.
- Installed software should be identified.

## SUMMARY

A Linux distribution set can be purchased from a retailer, downloaded from a vendor, or borrowed from someone. Purchasing a distribution set provides access to online or phone support and access to updates. Distribution sets are available for Intel, Intel-compatible, Alpha, Power PC, and Sparc computer platforms.

Installation can be achieved from a CD-ROM, hard disk, or network. Most systems will boot from a CD-ROM, providing an easily transported distribution set that can be used on multiple systems. A boot floppy may be required to start Linux. Linux distributions come with a utility to create a boot floppy from a provided image file.

Linux provides multiple virtual consoles to use during installation. Virtual consoles provide a way to view installation dialog, installation log, and other information that can be invaluable if a problem arises.

Many parameters are entered during installation and should be documented. Parameters include the language, input devices, output devices, disk configuration, network configuration, initial security settings, and packages installed.

After installation is complete, the system should be tested. Basic testing includes logon via text or GUI, viewing the installation log file, configuring basic parameters, and shutting down the system.
