# ## SECURITY OVERVIEW

Security is one topic that everyone with a computer connected to the Internet must know. Some think that security is only to protect critical data, such as national defense information or weekly payroll data. Actually, computer and network security is for everyone.

Some demented people seem to want only to cause mischief. These individuals work diligently to find ways to *crack* or disrupt computer systems. Attacks on your computer system from these individuals may be harmless and done just to prove that they can; but others will attack your system for malicious purposes, that is, not only crack into your system, but also cause severe damage. Still others may attack your system not to cause problems, but for the purpose of using your computer as a platform to launch attacks against others. Often a compromised computer is used to launch denial-of-service attacks against other computers. With today's technology providing *“always connected”* Internet access, computers are more vulnerable than ever to security breaches.

Security has one purpose—to protect assets. For most of history, security meant having strong walls and well-guarded doors to keep bad guys out. This strategy worked well for centralized computer systems, where only a few were given access and no outside connections were available. However, because today's business is conducted over large, easily accessible networks, the computers connected are much more vulnerable.

The only way to make your computer completely secure is to only use it in a locked room with no means of external communications. In most cases, this is not a viable option, so other means must be used to secure your system.

Security is an ongoing process composed of four phases—secure, monitor, test, and improve. These phases are implemented as a continuous process.

+   - **Secure** Securing the computer system involves assigning strong passwords, enabling firewalls, applying file system permissions, establishing VPNs, and patching systems.
- **Monitor** Monitoring involves checking logs to determine who has logged on to the system, and to see if there have been any unauthorized accesses.
- **Test** Testing of the system is done to determine whether the security measures are working and that they can be monitored properly.
- **Improve** After information is gathered through monitoring and testing, improvements can be made.
