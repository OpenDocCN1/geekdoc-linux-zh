> **NOTE**

Some high-end video adapters generate a lot of heat. If this is the case, your video card will probably have a heat sink on top of it. A heat sink is a metal device with a fan that dissipates heat from the chip.

# X Servers for Linux

Most Linux distributions ship with XFree86, an open-source implementation of the X window system (http://www.xfree86.org). The XFree86.org Web site has documentation with information about installing, updating, driver status, and other matters that will be helpful once you have determined your chipset.

Most Linux installations ship with XFree86 version 4.3.0. The next planned release is version 4.4.0. If you have a video adapter that is not supported by the version of XFree86 you are using, you may want to download the latest version.

If XFree86 does not fulfill your needs, you may want to try a commercial X server. Two companies that provide an X server product are Accelerated-X (www.xig.com) and Metro Link (www.metrolink.com).

# Configuring X

One method of configuring X is through its configuration files. The main file is XF86Config in the /usr/X11R6/lib/X11 directory. This file contains information about the mouse, keyboard, and video adapter. If you change this file, make sure you make a copy of it first.

Another method is to let the Linux installation automatically configure video. This will work in most cases; however, not all video adapter information is programmed into the Linux distribution.
