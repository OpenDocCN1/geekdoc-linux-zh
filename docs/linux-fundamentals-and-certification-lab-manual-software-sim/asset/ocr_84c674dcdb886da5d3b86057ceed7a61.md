# NOTE

> You should have a password policy. Typically, a password should be at least eight characters in length and should contain upper- and lowercase letters, numbers, and special characters. You should not use any dictionary words in your password. A password should be distinctive enough to prevent someone from guessing it, but should be something you will remember.

If you have more than one operating system on your computer, you can select which will boot by default. When the Linux operating system starts, it will delay on the list of operating systems. If there is no user interaction the default operating system will be started. Tab to the operating system you want to be automatically selected on startup (Figure 3-15) and press the space bar to select it.
