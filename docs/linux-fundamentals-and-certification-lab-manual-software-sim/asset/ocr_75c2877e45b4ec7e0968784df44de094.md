# # Modems

Linux distributions support almost any older internal or external modem. The most compatible modems are those that are Hayes compatible. Some of the newer modems are software modems that rely on the CPU to do some of the work that once was the modem's job. These software modems may not work with your Linux distribution. For those you can check http://www.linmodem.org for help on what's currently supported.

# ## Miscellaneous Hardware

Linux supports a wide range of commonly used hardware. Although some of these devices may have features that are not supported by Linux, all standard versions are supported without additional hardware drivers.

**Floppy Drives** All standard floppy drives work with Linux operating systems. There are a few drives, usually high-capacity, that may or may not work with Linux. These usually can be configured as hard disks or removable devices.

**CD-ROMs** Most CD-ROM drives are very standardized and will work within Linux. Often you will install Linux from a CD-ROM that will be booted on the system. Most recordable CD-ROMs and many recordable DVD-ROMs will be recognized by the Linux distribution as well.

**Tape Drives** Most tape drives use a standard EIDE/ATA or SCSI interface. These drives usually work with Linux without any special configuration.

**Keyboards** Standard PC keyboards work with any distribution of Linux. Some keyboards that have special keys will usually work, but the special keys may not be recognized on some distributions. USB keyboard support is available in the 2.2.x and 2.4.x kernels.

**Mice** Mice are standard devices and work with Linux easily. Most serial, USB, or PS/2 interfaces are supported.

**Monitors** A Linux driver is not required to use a monitor. Some features may not be supported if the monitor isn't recognized by the XFree86 configuration program, but it will still work. Full functionality can usually be achieved by inputting the vertical and horizontal refresh rates into the appropriate configuration files.

**Serial/Parallel Ports** Linux installation should find any serial or parallel port installed in the system. On later distributions, if you add a new port, the system should find it on startup and automatically configure it.

**PCMCIA** Personal Computer Memory Card International Association (PCMCIA) is an organization of about 500 companies that have developed a standard for small, credit-card-size devices called PC cards. PC cards are typically used in portable computers to add network cards, modems, and other devices. Linux will find these devices on installation and support most devices that are installed. PCMCIA is designed to allow replacement of cards without having to reboot the system.

**USB** Universal Serial Bus (USB) devices can support up to 127 devices on one port. USB devices include mice, modems, multimedia hardware, storage devices, and keyboards. The newer releases of Linux support USB and will work with most devices attached to the USB port.

**Sound Cards** Linux supports most sound cards. Many cards are Sound Blaster-compatible and work easily in Linux. There are commercial implementations of Open Sound System (OSS) and freeware versions, OSS/Free and ALSA, that support almost all sound cards designed with the OSS standard.
