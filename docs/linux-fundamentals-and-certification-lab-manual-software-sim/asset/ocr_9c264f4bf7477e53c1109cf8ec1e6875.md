+   • **xF86Config** This program is strictly a text mode tool (Figure 9–4). It asks a series of questions about your hardware and configuration preferences. It does not offer a lot of features; if you make a mistake, you will have to start over again from the beginning.

![](bbox=[0.04, 0.15, 0.85, 0.38])

+   • **Xconfigurator** This program provides a text interface and a GUI interface on some Linux distributions. It uses menus similar to xf86config. Xconfigurator and xf86config are both good for configuring systems from runlevel 3.

+   • **XF86Setup** This program runs only in GUI mode. It only runs after X has been configured. Although XF86Setup is not always good for initial configurations, it will facilitate changes to your display settings and other hardware after it is running.

Linux distributions often provide a custom configuration program. For example, Mandrake Linux provides the **Mandrake Control Center** (Figure 9–5), which allows configuration of the display as well as a lot of other hardware and software.

![](bbox=[0.04, 0.59, 0.85, 0.88])

Red Hat Linux provides the **redhat-config-xfree86** program (Figure 9–6) to configure display settings. This is a GUI tool that is good for configuring the display after X has been configured. The Display tab allows you to set the resolution and color depth of the display.
