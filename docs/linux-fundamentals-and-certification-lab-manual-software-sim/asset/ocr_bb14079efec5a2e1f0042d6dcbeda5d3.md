# ## LINUX BACKUP

Even the most reliable computer system can fail. Doing a backup is one way to plan for computer disasters. Disasters in this case can mean the computer center was severely damaged by flood or fire, but more likely it means that the hardware has failed or someone accidentally erased a directory or a hard drive.

Computer failures can include hardware failure, software failure, environmental failure, and human error. Failures can be minimized in effect, but not eliminated altogether. For example, one method of configuring multiple hard disks is to use RAID. If a system is using RAID 0+1, the failure of a single hard drive is minimal and probably not even noticed by users of the system. The RAID of many systems supports hot-swapping of hard drives, making repair of a failed drive just a matter of replacing the damaged drive without even stopping the computer system.

Hardware failure of a computer system will happen. Even electronic parts with no moving parts have wear from heat. To keep the effects of hardware failures to a minimum you could:

+   - Set up a second system to take over if the primary system fails
- Have redundant technologies, such as RAID, so that failures can be repaired easily and quickly
- Have replacement parts readily available as well as someone with the skills needed to replace them
- Have automated monitoring and notifications in place so that issues can be resolved before a hard failure occurs

No software is immune from failure. Some programs are not likely to fail, especially those that have limited functions to perform. Many programs are very complex and often have many developers working on them. In more complex programs failures are much more likely. Some software failures can be minimal with almost no effect, whereas others can cause the operating system to fail completely. To keep the effects of software failures to a minimum you could:

+   - Set up a second system to take over processing if the primary system fails
- Test the software on a test system before installing it on a production system
- Make a backup of all data and programs before installing the software

Environmental failures include losing electricity, leaky roofs, and others. Minimizing the effects of environmental failures can be costly and, depending on the problem, it can be difficult if not impossible to prevent them. For example, protecting against the effects of an earthquake can be accomplished by having a second facility in another location take over, a very expensive solution; however, barring extreme circumstances like an earthquake, there are solutions to environmental problems. For example:

+   - Protect against power outages by employing a battery backup or power generator.
- Protect against extreme temperatures by providing an air conditioned environment.
- Protect against lightning by using proper grounding and lightning rods.

Human error can take many forms. It can include anything from someone accidentally turning off power to the computer system to just typing in the wrong command. One term that applies to human error is Garbage In Garbage Out (GIGO), meaning that if bad data is entered into the computer system, bad information will be the result. Human failures can be protected against by providing proper training of personnel and backing up the data and programs on a regular basis.

The term backup has a specific meaning when it refers to an operating system: copying data and programs from the computer to another medium. Backups can be performed several different ways and with several different programs.

The typical backup hardware is a tape drive; however, smaller installations also use removable hard drives, optical disks, and high-capacity floppy disk devices. Tape drives are the slowest backup devices; however, tape media is the least expensive per megabyte.
