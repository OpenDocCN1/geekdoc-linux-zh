**Copyleft.** A general method for making the software for a program free and requiring all modified and extended versions of the program to be free software as well.

**Core Dump.** A dump of memory contents to a file, usually used to track a software error.

**cron.** An acronym for “command run on,” a daemon that can be used to execute scheduled tasks.

**CSMA/CD.** Short for Carrier Sense Multiple Access/Collision Detection, a set of rules that determine how network devices respond when two devices attempt to transmit a packet at the same time (collision). Standard Ethernet networks use CSMA/CD.

**Daemon.** A process that runs in the background and performs specific tasks. The term is used in Unix systems and comes from Greek mythology, where daemons were guardian spirits.

**DEB.** A packaging management system designed for the Debian Linux distribution. It is used to install, uninstall, verify, query, and update packages on a Linux operating system.

**Debian.** A distribution of the Linux operating system.

**DHCP.** An acronym for Dynamic Host Configuration Protocol, a protocol on TCP/IP networks used to assign network addressing to hosts requesting the service. Requests are sent on port 68 and replies are sent on port 67.

**Digital Certificate.** An electronic message that is attached to another message for security purposes. Digital certificates are used to verify that a user sending the message is who they claim to be.

**DIMM.** Dual inline memory module, a type of RAM.

**DMA.** Direct memory access, a technique used for transferring data from main memory to a device without passing it through the CPU.

**DNS.** Short for Domain Name System. It is a network service that translates domain names into IP addresses.

**Domain Name.** A name that identifies an IP address.

**DSL.** Digital Subscriber Line. Its two main categories are ADSL and SDSL. DSL offers much faster connection times than do dial-up connections.

**EIDE/ATA.** Enhanced Integrated Drive Electronics/Advanced Technology Architecture, a standard interface used on most computer systems to connect hard drives.

**Embedded Linux.** Embedded Linux is a feature-rich subset of Linux, stripped down to include only those elements of Linux that are useful on an embedded system. The smaller size of the embedded Linux operating system allows devices to use flash RAM instead of a hard drive to hold the operating system.

**Enterprise Server.** A type of Linux installation that incorporates server services while maintaining high availability.

**Environment Variable.** A variable that provides named information to support programs.

**Ethernet.** A local area network architecture that uses a physical bus topology and, usually, a logical star topology. Ethernet networks support data transfer rates up to 1 gigabit per second.

**Extract.** To remove files from an archive.

**FAQ.** Acronym for Frequently Asked Questions. An FAQ is an online document that provides a group of questions about a specific subject with corresponding answers.

**Fedora.** A distribution of the Linux operating system, formerly Red Hat Linux.

**File System.** Data structures placed on a logical disk or partition that allow the operating system to record information about files stored there.

**Finger.** A Unix/Linux program that accepts an e-mail address as input and returns information about the user who owns the address. It uses port 79.

**FireWire.** Also called IEEE 1394, FireWire is a very fast external bus standard that supports data transfer rates up to 800 Mbs. It can be used to connect up to 63 external devices.
