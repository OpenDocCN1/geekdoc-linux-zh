
Cable characteristics change with the technology. Cable lengths can be from 1.5 to 25 meters, depending on the type of SCSI technology used. A cable length for SCSI 1 could be up to 6 meters, Fast SCSI could be up to 3 meters, and Ultra SCSI up to 1.5 meters. As technologies have changed, the cable length has mostly decreased; however, with the latest Ultra2 SCSI and later technologies, the cable length could be increased to as much as 25 meters. The latest standard, Ultra 160 SCSI and Ultra 320, has a maximum cable length of 12 meters.

SCSI cable is one of the largest contributors to SCSI problems. The cable should be the best quality and of the proper length for the technology used. The SCSI drive documentation will include specifics for installation.

## NETWORK PROBLEMS

Networking problems can usually be isolated by using the OSI model. As you learned in Chapter 6, each of the seven layers of the OSI model encapsulates data and sends it to the next layer. The model layers are described in Table 13–2.

**Table 13–2 Model layers.**

| Layer | Common Name | Responsibility |
| :---- | :---------- | :------------- |
| 1 | Physical | This layer defines the physical link between devices. Voltage levels, timing of voltage changes, physical connectors, and other characteristics are defined. The physical layer delivers the bits, 1s and 0s, across the transmission media. |
| 2 | Data Link | The data-link layer is responsible for the physical addressing, network topology, error notification, and flow control. The computer’s MAC address is defined at this layer. (*A MAC, Media Access Control, address is provided by the manufacturer of the network interface card (NIC) and consists of six bytes, of which three identify the manufacturer and three identify the device. Each device has a unique MAC address.*) The data-link layer assembles the frames of information to be sent across a network. |
| 3 | Network | The network layer is responsible for path selection, routing, and logical addressing. The computer’s logical network address, such as IP or IPX, is used to perform the network functions. The network layer assembles packets of information to be transmitted over the network. |
| 4 | Transport | The transport layer is the boundary between application issues and data flow issues. This layer provides connection protocols between computers. The transport layer segments the data from the upper layers for transmission over the network. |
| 5 | Session | The session layer establishes, manages, and terminates sessions between two computers. This layer provides exception reporting for session, presentation, and application layer problems. |
| 6 | Presentation | The presentation layer ensures that information from the application layer of one computer can be understood by the application layer of another. This layer ensures that there is a common data format. |
| 7 | Application | The application layer is closest to the user. It provides network services to applications. |

Data must traverse the OSI model layers to travel from one computer to another. For example, suppose you open the Mozilla Web browser to connect to a Web site. The first thing you do is type in the Uniform Resource Locator (URL) of the Web site you want. The URL is sent to the presentation layer, which ensures that it is in standard format and then sends it to the session layer. The session layer establishes session information for the data, then sends it to the transport layer. The transport layer segments the data stream from the upper layers into manageable segments that can be transmitted over a communication line, then sends the segments to the network layer. The network layer applies the computer’s logical addressing information to the segments, forming packets that are then sent to the data-link layer. The data-link layer applies the MAC address information to the packet information, forming frames that are then sent to the physical layer. The physical layer sends the frames one bit at a time over the transmission media. After the bits are received by another computer the whole process is done in reverse order.

### Network Problem Isolation

To identify network problems, you follow the network layers, identifying what is expected at each layer. The first check should be of the physical layer. This is the hardware and signaling component of the network.

You need some special equipment to help isolate physical layer components. The first is a cable tester (Figure 13-9). A cable tester will check that the cable is assembled correctly and check the length of the cable. Some network testers will even draw a diagram of the network.

A second piece of equipment that will often prove invaluable is a crossover cable. Most patch cables used with an Ethernet network are wired straight through. In other words, the wire connected to pin 1 on one end is connected to pin 1 on the other end, and so on. A crossover cable reverses the transmit and receive wires so that two computers can be connected directly together.

A few standards must be adhered to. The first has to do with the length of 10BASE-T UTP cables and is called the **5-4-3 rule**. A signal traversing a length of cable is delayed before it reaches the other end. A 100 m trip delays the signal about 0.55 microseconds. What this means is that a signal on an Ethernet 10BASE-T UTP cable is rated to work at 100 m. Anything past that length is too attenuated to work reliably. However, the cable run can be lengthened by using a repeater. A repeater boosts the signal and sends it down the next network segment of up to 100 m. Besides the delay of sending a signal down a line, there is also some repeater delay. Because of this the 5-4-3 rule says that no more than 500 m total length can be used, with a maximum of 4 repeaters, and that no more than 3 of the segments should have hosts on them.

If everything is correct at the physical layer, then the data-link layer, layer 2, can be checked next. The data-link layer uses the host device's MAC address to communicate within a network segment. Switches work at the data-link layer. They pass along connections based on the destination of the packets coming in to the system. Without MAC addressing, hosts on the network could not be uniquely identified.

Protocols, such as DHCP, use the layer 2 MAC address to communicate. Layer 2 connections are used within a single network segment. In other words, if you are on network 192.168.0.0 and another machine is on network 192.168.1.0, the two machines cannot communicate directly because they are on two different segments.

The network layer, layer 3, is a routable layer. This means that data at the network layer can be sent to other network segments. The network layer uses IP addresses to communicate. Information is sent from one network segment to another through a router. A router is a layer 3 device. Routing problems can prevent network information from reaching the destination host.

The transport layer, layer 4, is the layer that TCP works at. TCP establishes a connection with a remote host to transfer information. Problems at this layer can cause connections to be unsuccessful.

The session (layer 5), presentation (layer 6), and application (layer 7) layers are maintained within applications. Problems at these layers are within the applications and can usually be resolved by reinstalling or reconfiguring the programs.

### Network Troubleshooting Utilities

Several commands are used to check network connectivity. These commands are ping, tracerte, telnet, nslookup, and netstat. Each is described on the following pages.

- **ping** This command determines whether an IP address is accessible and the network is functioning properly. ping uses the Internet Control Message Protocol (ICMP) defined in RFC 792 (http://www.ietf.org/rfc/rfc0792.txt#number=792, Internet Control Message Protocol RFC 792).

One of the first things a cracker will do in order to plan for an attack is map a network. Recall from Chapter 12 that the Echo Reply can be disallowed by a firewall. Many organizations block the ping command to keep unauthorized users from gaining information about their network.

ping can be used to ping an IP address or a host name. When using ping for troubleshooting, you should use the localhost address, 127.0.0.1, to determine that the network interface is up and running. Several options are available. Some of the more interesting are listed as follows:

- `-a` An audible ping.
- `-b` Allows pinging a broadcast address.
- `-c <count>` Allows sending count number of ECHO_REQUEST packets.
- `-v` Verbose response.
- `-q` Quiet output. Only the summary lines are displayed.
