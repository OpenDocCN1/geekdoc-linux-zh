# Querying an RPM Package

To determine if an RPM package is installed on the Linux operating system, use the query option (-q). The syntax is **rpm -options rpm_package_name**, where rpm_package_name is the name of the RPM package to be installed. To query the RPM system, asking if the tftp-server package is installed (Figure 6-6), use the **rpm -q tftp-server** command:

![](bbox=[0.06, 0.515, 0.15, 0.565])

```
[root@Styx root]# rpm -q tftp-server
tftp-server-0.32-4
[root@Styx root]#
```

The RPM system responds with the package name, version, and release number of the package. Use the query option to verify that a package is installed on the system.
If you aren't sure of the exact name of the installed RPM try the following:

```
[root@www engie005]# rpm -qa | grep -i ftp
1ftp-2.6.3-3
gftp-2.0.14-2
ftp-0.17-17
vsftpd-1.1.3-8
[root@www engie005]#
```
