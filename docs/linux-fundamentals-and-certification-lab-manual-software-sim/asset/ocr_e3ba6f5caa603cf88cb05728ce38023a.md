# NOTE

The **tty** is an abbreviation for teletype. A teletype is a type of terminal where a modified typewriter is designed to accept input from a communication line that operates it from a remote location.

Other device names can be used as well. For example, for the HSF modem found in Figure 7-21, the device name is /dev/ttySHSF0. To check device settings you can use the command `setserial -a <devicename>`. For example, to view the information for /etc/tySHSF0 (Figure 7-22), use the command `setserial -a /dev/ttySHSF0`.

Set up PPP with the following steps:

+   1. Add a ppp group with a unique gid number. For example, to add the group ppp use the command **groupadd ppp**.
2. Add users that will be connecting to the remote server to the ppp group. For example, to add jsmith to the ppp group use the command **usermod -G ppp jsmith**.
3. Make sure that the /usr/sbin/pppd command is owned by root (Figure 7-23). For example, **chown root /usr/sbin/pppd**.
