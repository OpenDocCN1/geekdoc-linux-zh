# Suidid Programs Two methods are used to provide users root access to programs—su and sudo. Both commands allow a user access to limited or all root programs.

# Using su The su command allows a user to log in as another user. By default, su will log in as root. The su command sets environment variables HOME and SHELL from the pass-word entry for USER. If the dash (-) option is used, a login shell is presented. To log in as root, use the su - command (you will be asked for the root password).

Figure 12–3 shows a normal login session. jsmith logs as a normal user. He wants to create a directory off the root directory, but receives a message that he does not have permission to create it. jsmith then logs in as root with the su - command and retries the command. jsmith is effectively the root user once the login is complete. To exit the root user, just type exit and press Enter.

# Using sudo If allowing a user full access to a machine makes you squeamish, you may want to use the sudo command instead. Each user that is to be given access to a restricted program must be configured to do so.

To configure a user for access to restricted resources, the /etc/sudoers file (Figure 12–4) must be updated. User entries in the /etc/sudoers file allow users to use the sudo command to execute restricted programs using their own passwords. sudo doesn't log in as root, but rather allows a user to run a program with root privileges from the user account. To add jsmith as a user with root administrative rights, add the following line to the file:

```
jsmith ALL=(ALL) ALL
```
