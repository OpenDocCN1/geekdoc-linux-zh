**Ping.** A command used to determine if an IP address is accessible and the network is functioning properly.

**Pipe.** A command used to send the output of one command to the input of another program.

**PKG.** A package management system used by FreeBSD and many other Unix operating systems.

**POP3.** Short for Post Office Protocol 3, a protocol used to receive e-mail. It uses port 110.

**Port Number.** Port numbers keep track of the different sessions that are active on a network host. Port numbers 0 to 255 are called well-known port numbers and are used to assign TCP/IP standard protocols; port numbers 256 to 1023 are commercially assigned port numbers for marketable applications; and port numbers above 1023 are unregulated.

**POST.** An acronym for Power-On Self-Test, a program in computer ROM that runs on computer startup to check that all hardware on the computer is functioning.

**PostScript.** The PostScript language is used for printing documents on laser printers, but its technology can be adapted to produce images on other types of devices. Printer drivers developed using PostScript technology are referred to as PPD files.

**PPP.** Point-to-Point Protocol, a protocol that encapsulates IP traffic over point-to-point links, which is a method that connects one computer to another computer that then puts the TCP/IP packets onto the Internet.

**PRI.** Primary Rate Interface, an ISDN service offering 23 B channels and one D channel. This provides a total bandwidth of 1.544 Mbps. The D channel provides 64 Kbps with PRI.

**Process.** An executing program.

**Public Domain.** Software that has all rights released to the public.

**Public-Key Encryption.** A cryptographic scheme that uses two keys, a public key known to everyone and a private key known only to the owner of the key. Messages sent with the public key are readable by the private key, and messages sent with the private key are readable by the public key.

**Queue.** This term refers to the process of lining up jobs for a computer or device. A print spooler is a queue that sends documents to the printer one at a time in a process called print spooling.

**Quota.** A method of restricting user access to disk space or printer services.

**RAID.** Short for Redundant Array of Inexpensive Disks. RAID provides for hot-swapping drives, data striping, and disk mirroring. There are six different levels of RAID: RAID 0 through RAID 5. The most commonly used are RAID 3, RAID 5, and RAID 0+1, a combination of RAID 0 and RAID 1.

**RAM.** Random Access Memory, the volatile main memory of a computer system.

**Red Hat Linux.** A distribution of the Linux operating system.

**Redirection.** The sending of the output of a command to somewhere other than its configured output.

**Right-Click.** Clicking an object on a desktop with the right mouse button. Typically, right-clicking displays a shortcut menu.

**ROM.** Read Only Memory, a chip on the computer’s main board that stores the BIOS (Basic Input Output System).

**Router.** An OSI model network layer device. Its purpose is path determination and the switching of packets on a network.

**Routing.** The service performed by a server or network appliance (router) that provides switching and path determination for packets on a network.

**RPM.** RPM, or Red Hat Package Manager, is a package management system used to install, uninstall, verify, query, and update packages on a Linux operating system.

**RSA.** Rivest-Shamir-Adleman, an algorithm used to generate digital certificates.
