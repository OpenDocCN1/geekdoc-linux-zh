+   *   **grep**: Search a file or standard input for lines containing a match to a given pattern. Even though grep expects to search text files, it can search binary files as well. The basic syntax of grep is `grep "expression" file` where expression is the text to be found, and file is the text file to be searched.

For example, if a user wanted to know what the default login runlevel is, the user could view the initab file. After using one of the view commands to display the file, the user would then have to search the file to find the right line. (The runlevel in the initab file is found in the line `id:X:initdefault:`, where X is the runlevel.) A faster method to find the line and what the runlevel is would be to search the file for the text using grep. For example, to find what the runlevel is, a user could search for any line that starts with id.

```
```
[jsmith@Styx jsmith]$ grep "id" /etc/inittab
id:5:initdefault:
[jsmith@Styx jsmith]$
```
```

The grep command can use input piped from another command as well. For example, a user could use the following command to find all commands with the word “restore” in them:

```
```
[jsmith@Styx sbin]$ ls | grep "restore"
iptables-restore
restore
restore.static
rrestore
xrestore.static
vgcfgrestore
[jsmith@Styx sbin]$
```
```

Notice, all lines that contain the word “restore” are returned, regardless of where it is contained in the line.

If the user wanted to know how many entries would be returned by the above command, the output could be piped to the wc command. For example:

```
```
[jsmith@Styx sbin]$ ls | grep "restore" | wc -w 6
[jsmith@Styx sbin]$
```
```

The ls command sends its results to grep, which filters out only those lines that have “restore”. It then sends its results to the wc command, which counts how many words are returned.

Some of the options available are as follows:

+   *   **-a, --text**: This option allows grep to process a binary file (a command or program) as if it were a text file.
*   **-c, --count**: Suppress the normal output and just print the number of matches found.
*   **-h, --no-filename**: Suppress the prefixing of filenames on output when multiple files are searched.
*   **-i, --ignore-case**: Ignore the case of the characters in the pattern.
*   **-l, --files-with-matches**: Suppress normal output and point to the name of each in-put file that would have normally been printed. Scanning stops on the first match.

The grep command supports regular expressions. A regular expression is a pattern that describes a set of strings. Regular expressions are constructed analogously to arith-metic expressions, by using various operators to combine smaller expressions. Think of regular expressions as being wildcards on steroids.
