Some of these package tools, such as RPM, Red Hat Package Manager, and DEB, Debian's package tool, are tightly integrated with the Linux distribution and provide a centralized mechanism for program updates.

Package management programs have several features that should be compared when deciding on a system to use. These have to do with security, usability by standard Linux tools, scalability, and metadata.

Security features include values that can be examined to ensure the package is valid and has not been modified. These include:

+   - **Signed packages** Support for PGP or GPG electronic signature to verify who created the package.
- **Checksums** A checksum ensures the package is complete and unmodified.

Standard Linux tools include tools that can be used to view packages without having a special tool for each package. Some package systems use tools that are included with every Linux distribution. These include:

+   - **Standard package tools** Can the package be manipulated by standard Linux tools, such as tar, gzip, bzip2, and others?
- **Package creation** Are standard Linux tools available to create the package?

Scalability features include how well the package format is able to grow to meet future needs. These include:

+   - **Version format** Can the version be determined by examining the package?
- **Hard programmed limits** Are limits designed into the package format?

Limits may prevent the package from expanding to meet future needs.

Metadata features include embedded information about a package. This information includes values such as package name, description, and other properties that may be changed within the package. Some of these properties are:

+   - **Name** The name of the package can be determined by data within the package.
- **Version** A version number within the package or the name of the package indicates the package version.
- **Dependencies** A dependency indicates what packages need to be installed before the package in question is installed.
