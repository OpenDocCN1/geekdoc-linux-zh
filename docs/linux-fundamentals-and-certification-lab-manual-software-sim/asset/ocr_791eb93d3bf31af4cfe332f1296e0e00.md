User cron jobs are defined within the user's home directory with a text editor. The user then uses the crontab command to tell the system that the user has cron jobs to be executed. User cron jobs are in the /var/spool/cron directory.

Core dumps are listings of everything in memory when a program fails. These files can be viewed by a programmer to determine what caused a program to fail. Core dump sizes can be limited with the ulimit command. Core dumps can take a lot of disk space and should be backed up and removed.

Processes are programs that run on the Linux operating system. Processes should be monitored for running time and CPU usage. They can be viewed with the ps command. Tools are available to prioritize, kill, suspend, and restart processes.

Processes can also be viewed with the top program. top provides an interactive view of running processes, CPU usage, memory usage, and swap usage. GUI programs are available to view and manage processes. GUI applications are also available to show charts and graphs of memory and CPU usage.

The Linux operating system allows the configuration of file system quotas. Quotas let Linux restrict file system usage based on soft and hard limits. Soft limits are values that, when reached, only display a message warning that the soft limit has been reached. After hard limits are reached, no further writes by the user are allowed.

Linux provides logging with the syslog daemon. Log files are written in the /var/log directory and can be used by applications, drivers, and other daemons.
