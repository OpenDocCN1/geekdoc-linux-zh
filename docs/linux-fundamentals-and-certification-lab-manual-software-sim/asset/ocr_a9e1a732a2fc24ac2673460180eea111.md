# NOTE

“Lightweight” can have several meanings. For example, when you install the Windows operating system you install the graphical interface and all that it includes, making for a large (heavyweight) installation. In many cases Linux can accomplish the same functionality as a similar Windows installation but without the overhead. The GUI (graphical user interface) is not required, and many other tools can be removed from a standard installation, thus making Linux a lightweight yet powerful operating system.

Embedded Linux is a great implementation, but typically most users will not be involved with installing it. The amount of resources needed to run Linux as an embedded system varies widely. For more information about embedded Linux, connect to http://www.embedded-linux.org.

# Personal Desktop

A personal desktop installation of Linux is designed for the home user and is good for personal productivity. Typically, the installation includes a GUI environment such as GNOME or KDE, personal productivity software such as OpenOffice.org, and games, and may or may not include network connectivity.

Users may experiment with server software, but the personal desktop is the most widely used installation type. The personal desktop installation of Linux gives users basically the same functionality they get from a Windows installation. As already mentioned, a typical installation includes the GUI as well as text editors, tools to manage the desktop, a folder manager similar to Windows Explorer, an Internet browser, and additional features, such as remote access to the desktop, not found in most Windows systems. Most distributions of Linux provide productivity software such as OpenOffice.org. OpenOffice.org, as its name implies, is open-source software and can be downloaded free from http://www.openoffice.org. OpenOffice.org, a suite of productivity tools, contains:

+   - **WRITER** A powerful word processing application, similar to Microsoft Word, for creating documents, reports, newsletters, and brochures. It integrates charts, graphs, and images within documents.
- **CALC** A spreadsheet application that functions similar to Microsoft’s Excel application. CALC provides advanced spreadsheet functions, decision-making tools, and 2D and 3D charts.
- **IMPRESS** A multimedia presentation package that provides basic text formatting, special effects animation, and drawing tools.
- **DRAW** A simple drawing application to design everything from simple diagrams to 3D illustrations.
- **DATABASE USER TOOLS** OpenOffice.org doesn’t have a database as part of the suite; however, it does provide some tools to let you manage existing databases, such as MySQL or ODBC-compliant databases.

StarOffice, a product from Sun Microsystems, uses the same source code as OpenOffice.org and the core suites are the same. StarOffice is commercial software, not open source. StarOffice has additional features and capabilities, such as:

+   - a more sophisticated spell-checker
- a clip-art collection
- additional macros and filters
- the Adabas database
