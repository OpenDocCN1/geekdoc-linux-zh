The following options indicate how to handle existing partitions for this Linux installation:

+   - **Remove all Linux partitions on this system:** Select this option to remove only Linux partitions (partitions created from a previous Linux installation). This will not remove other partitions you may have on your hard drive.
- **Remove all partitions on this system:** Select this option to remove all partitions on your hard drive, regardless of the file system type.
- **Keep all partitions and use existing free space:** Select this option to keep your current data and partitions and use the available existing free space.

# NOTE

> You can learn more about disk partitions in Chapter 2.

A list of available hard disks will be displayed. You can select which hard disk to use for the installation. EIDE/ATA hard drives are indicated with hd and a letter. For example, the first hard disk would be hda, the second hdb, and so on. SCSI drives are identified with sd and a letter. The first SCSI drive, for example, would be sda.

Select the drive you want to use for the installation by tabbing to the drive and pressing the space bar. The selected option will have an asterisk beside it.

The automatic partitions will be created. The /boot partition requires about 100 MB. The swap partition, depending on available disk space, will be one to two times the size of RAM. It is generally recommended to create a swap partition no smaller than two times the amount of physical RAM in the computer. The / or root partition will be allocated the remaining disk space. The partition name is the mount point for the partition. You can create your own mount point, or select one from a list of the more common names.

The partitioning screen, seen in Figure 3–10, will allow you to adjust partitions to meet your needs.
