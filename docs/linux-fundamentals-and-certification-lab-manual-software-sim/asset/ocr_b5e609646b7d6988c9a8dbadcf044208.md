First tell Linux to add the NIS domain you will be using. Edit the /etc/sysconfig/network file and add the NIS domain name to be used. For this example we will use the name NIS-LINUX-NETWORK.

```
# cat /etc/sysconfig/network
NETWORKING=yes
HOSTNAME=localhost.localdomain
NISDOMAIN="NIS-LINUX-NETWORK"
```

NIS servers have to be NIS clients as well. Next we’ll edit the NIS client configuration file /etc/yp.conf to list the domain’s NIS server as the localhost.

```
# cat /etc/yp.conf
# /etc/yp.conf - ypbind configuration file
# Valid entries are
#
#domain NISDOMAIN server HOSTNAME
#    Use server HOSTNAME for the domain NISDOMAIN.
#
#domain NISDOMAIN broadcast
#    Use broadcast on the local net for domain NISDOMAIN
#
#ypserver HOSTNAME
#    Use server HOSTNAME for the local domain. The
#    IP-address of server must be listed in /etc/hosts.
#
ypserver 127.0.0.1
```

Start the necessary NIS daemons in the /etc/init.d directory. Use the chkconfig command to ensure that the daemons start after the next reboot and then initialize the NIS domain. Six commands will be used to start NIS: portmap, yppasswd, ypserv, ypbind, and ypxfrd.

+   *   **portmap** The RPC daemon that NIS runs under.
*   **yppasswd** Lets NIS users change their passwords on the NIS server from NIS clients.
*   **ypinit** The ypinit command builds the domain subdirectory of /var/yp for the current default domain and builds a complete set of administrative maps for your system.
*   **ypserv** The main NIS server process.
*   **ypbind** The main NIS client process.
*   **ypxfrd** The program used to speed up transfer of very large NIS maps.

```
# /etc/init.d/yppasswd start
Starting YP passwd service:    [ OK ]
# /etc/init.d/ypserv start
Setting NIS domain name NIS-LINUX-NETWORK: [ OK ]
Starting YP server services: [ OK ]
# chkconfig yppasswd on
# chkconfig ypserv on
#
```

Use the **ypinit** command to initialize the NIS domain. This program will make normal user accounts available to NIS clients.

```
# /usr/lib/yp/ypinit -m
```
