Every network device that uses TCP/IP has a unique network address called an IP address. IP addresses are 32-bit values identified in four 8-bit values called octets. The values are written in decimal notation for easy use. For example, 10001011.10000000.00000000.00000000 translates to 139.128.0.0, a class B IP address.

There are three classes of IP addresses, class A, B, and C. Each class of IP addresses is made up of a network portion and a host portion. Class A addresses are divided at the first octet, class B at the second, and class C at the third. The host portion can be subdivided to provide subnets by using a subnet mask. A subnet mask is similar to an IP address in that it is 32 bits and divided into four octets. The default subnet mask for a class A network is 255.0.0.0, for a class B network is 255.255.0.0, and for a class C network is 255.255.255.0. Each octet can provide 256 values.

Subnets allow you to divide your network into segments with fewer computers, which are more manageable than large numbers of computers on very large segments. Computers on the same network segment can talk to each other, but must have a device, called a router, that will pass the information to another segment in order to communicate across large networks. The Internet, for example, has millions of computers communicating across vast distances continually. If every computer were on the same network segment, communication would not be possible.

For a computer to communicate across the Internet, it must have an IP address, a subnet mask, an address of the router that it will pass through, and an IP address of a domain name server (DNS). A DNS server looks up a named address, such as www.yahoo.com, that is easy to remember and converts it to an IP address.

The values required for a computer to communicate can be provided statically or dynamically. A static configuration requires an administrator to explicitly enter the IP address, subnet mask, and other values. Dynamic values can be entered through a service called DHCP (Dynamic Host Configuration Protocol) or BOOTP. A DHCP server is configured with a range of values that it will assign to network devices when queried. BOOTP is an older version of the DHCP service.

The network can be configured during install time by entering the static values or indicating that Linux should use DHCP. A system can have more than one NIC. Each NIC must be configured.
