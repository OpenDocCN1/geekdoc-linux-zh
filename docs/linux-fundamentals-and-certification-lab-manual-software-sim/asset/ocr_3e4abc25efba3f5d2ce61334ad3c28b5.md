Konsole (Figure 10–29) is another implementation of a terminal emulator program. Konsole is also available as kpart, a tool in the development library, and can be embedded within another application. Konsole has a menu system that allows opening multiple terminal sessions and changing the terminal settings.

![](bbox=[0.06, 0.18, 0.86, 0.43])

GNOME Terminal (Figure 10–30) is a terminal emulation application similar to Konsole. It starts the default shell that is specified in the user’s system account. GNOME Terminal emulates the xterm program.

![](bbox=[0.06, 0.57, 0.86, 0.88])

To start an X terminal emulation program from a GUI desktop, choose **Application Starter**, Terminals, and select the terminal you want.
