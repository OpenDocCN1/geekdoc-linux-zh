Changing the screensaver is easy. To do so, follow these steps:

From the Desktop Preferences dialog box, double-click the Screensaver icon to display the Screensaver Preferences dialog box (Figure 10-12).

Select the screen saver desired from the list box. When you select a screensaver, it will be previewed in the window to the right.

The Lock Screen After check box will lock the screen after the number of minutes selected. This option will require the user to enter ID and password to continue.

Select Close when finished.

# ## File Manager

A file manager is a graphical shell for GNOME that makes it easy to manage your files and directories. GNOME uses the Nautilus File Manager as an access point to your files, applications, FTP sites, and URLs.
