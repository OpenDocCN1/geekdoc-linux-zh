# # Advanced Power Management—Advanced Configuration and Power Interface

Advanced Power Management (APM) is an Application Program Interface (API). An API is a set of routines, protocols, and tools for building applications that access services provided by some lower-level modules, such as the operating system or JVM. APM is an API developed by Intel and Microsoft that enables developers to include power management in BIOS. APM defines a layer between the hardware and the operating system that effectively shields the programmer from hardware details.

Advanced Configuration and Power Interface (ACPI) is an open industry power management specification developed by Hewlett-Packard, Intel, Microsoft, Phoenix, and Toshiba. ACPI enables the operating system to control the amount of power given to each device attached to the computer. This enables the operating system to turn off peripheral devices when they are not in use. ACPI is meant to supersede the older APM standard and to provide a generic interface for recognition and configuration of hardware devices.

The ACPI specification was released in 1996. The latest version is 2.0c, with the 3.0 specification under development (see www.acpi.info). The latest version extends to computer platforms with 64-bit and 36-bit addressing.

# **Using APM**

For APM to work, the system BIOS in the machine must support the APM standard. For APM to work with the Linux operating system, the system BIOS must support at least APM version 1.0. You can get information about APM version or support using the **dmesg** command. Excerpts of the dmesg output of two different machines are shown below. These indicate that APM is not supported in the BIOS on the first machine and APM BIOS version 1.2 is supported on the second machine.

The apm command tells the Linux operating system how to use the power management features. The syntax is **apm -options** where the options are one or more of those listed below.

+   * `-V, --version` Print the apm program version and exit immediately.
* `-v, --verbose` Print information about the APM BIOS version and Linux APM driver version.
* `-m, --minutes` Print the total minutes remaining instead of using the hh:mm format.
* `-s, --suspend` Put the machine in suspend mode.
* `-S, --standby` Put the machine in standby mode.
* `-i, --ignore` Ignore APM suspend and standby events when on AC power.
* `-n, --noignore` Do not ignore APM suspend and standby events when on AC power.
