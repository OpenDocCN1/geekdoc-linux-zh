# Remote Access to a Server

Several programs allow a remote client to access and run programs on a server. Some of these programs are insecure and can cause security issues with use. One of the oldest programs to allow remote access is Telnet. Telnet clients can be found on almost any host, including Linux systems, Windows systems, Unix systems, and even proprietary systems like Cisco routers.
