
## Glossary

- **Ping.** A command used to determine if an IP address is accessible and the network is functioning properly.
- **Pipe.** A command used to send the output of one command to the input of another program.
- **PKG.** A package management system used by FreeBSD and many other Unix operating systems.
- **POP3.** Short for Post Office Protocol 3, a protocol used to receive e-mail. It uses port 110.
- **Port Number.** Port numbers keep track of the different sessions that are active on a network host. Port numbers 0 to 255 are called well-known port numbers and are used to assign TCP/IP standard protocols; port numbers 256 to 1023 are commercially assigned port numbers for marketable applications; and port numbers above 1023 are unregulated.
- **POST.** An acronym for Power-On Self-Test, a program in computer ROM that runs on computer startup to check that all hardware on the computer is functioning.
- **PostScript.** The PostScript language is used for printing documents on laser printers, but its technology can be adapted to produce images on other types of devices. Printer drivers developed using PostScript technology are referred to as PPD files.
- **PPP.** Point-to-Point Protocol, a protocol that encapsulates IP traffic over point-to-point links, which is a method that connects one computer to another computer that then puts the TCP/IP packets onto the Internet.
- **PRI.** Primary Rate Interface, an ISDN service offering 23 B channels and one D channel. This provides a total bandwidth of 1.544 Mbps. The D channel provides 64 Kbps with PRI.
- **Process.** An executing program.
- **Public Domain.** Software that has all rights released to the public.
- **Public-Key Encryption.** A cryptographic scheme that uses two keys, a public key known to everyone and a private key known only to the owner of the key. Messages sent with the public key are readable by the private key, and messages sent with the private key are readable by the public key.
- **Queue.** This term refers to the process of lining up jobs for a computer or device. A print spooler is a queue that sends documents to the printer one at a time in a process called print spooling.
- **Quota.** A method of restricting user access to disk space or printer services.
- **RAID.** Short for Redundant Array of Inexpensive Disks. RAID provides for hot-swapping drives, data striping, and disk mirroring. There are six different levels of RAID: RAID 0 through RAID 5. The most commonly used are RAID 3, RAID 5, and RAID 0+1, a combination of RAID 0 and RAID 1.
- **RAM.** Random Access Memory, the volatile main memory of a computer system.
- **Red Hat Linux.** A distribution of the Linux operating system.
- **Redirection.** The sending of the output of a command to somewhere other than its configured output.
- **Right-Click.** Clicking an object on a desktop with the right mouse button. Typically, right-clicking displays a shortcut menu.
- **ROM.** Read Only Memory, a chip on the computer’s main board that stores the BIOS (Basic Input Output System).
- **Router.** An OSI model network layer device. Its purpose is path determination and the switching of packets on a network.
- **Routing.** The service performed by a server or network appliance (router) that provides switching and path determination for packets on a network.
- **RPM.** RPM, or Red Hat Package Manager, is a package management system used to install, uninstall, verify, query, and update packages on a Linux operating system.
- **RSA.** Rivest-Shamir-Adleman, an algorithm used to generate digital certificates.
- **Runlevel.** This is a setting used by the Linux operating system to specify which programs will start and stop.
- **Samba.** This is Linux's answer to Windows NT Server. Windows uses the SMB protocol to share resources between computers on a network. Linux provides the SMB protocol with Samba, a suite of programs that provide the same functionality as an NT server.
- **SCSI.** An acronym for Small Computer System Interface, a parallel interface standard used by computer systems to attach peripheral devices to computers. It is usually used to connect hard drives.
- **Security Update.** A minor change that is made to an operating system to prevent security breaches.
- **Server.** A type of Linux installation that is used to service client computer systems. It can provide Web services, file services, messaging services, database services, and network services.
- **Service.** A program running on a server that provides resources for client computers.
- **Shadow Passwords.** A suite of programs that moves and encrypts the system passwords to a secure file that only root can read.
- **Shareware.** Software that can be freely distributed, but retains the author's copyright. If you decide to keep the software, you're expected to register and pay a small fee.
- **Shell Script.** A collection of commands stored in a file that can be executed under the shell environment.
- **Shortcut Menu.** A pop-up menu displaying options for an object that has been right-clicked.
- **Signed Packages.** These are packages that support PGP or GPG electronic signatures to verify who created them.
- **SIMM.** Single inline memory module, a type of RAM.
- **SLP.** An acronym for Stampede Linux Package. The SLP format, from the Stampede Linux distribution, uses tar and the compression tool, bzip2, as its foundation.
- **SMB/CIFS.** Short for Server Message Block/Common Internet File System. SMB/CIFS was developed by Microsoft and uses port 139.
- **SMTP.** An acronym for Simple Mail Transfer Protocol, a protocol on TCP/IP networks that is used for sending e-mail messages between servers and from client to server. It uses port 25.
- **SNMP.** Short for Simple Network Management Protocol, a protocol used to manage TCP/IP networks. It uses ports 161 and 162.
- **SODIMM.** Small outline dual inline memory module, a type of RAM usually used in laptop computers.
- **Software.** The programs that are executed on computer hardware. These can include system software, such as operating systems, or application software, such as word processors.
- **SOHO.** Acronym for Small Office/Home Office.
- **Spooler.** A program that controls printer jobs in a queue. The spooler takes the print jobs one at a time and sends them to the printer in sequence.
- **SQUID.** A high-performance proxy caching server for Web clients.
- **SSH.** Secure Shell, a program used to log into another computer over a network in order to execute commands on a remote machine. SSH provides strong authentication and secure communication.
- **Subnet Mask.** A 32-bit value divided into four 8-bit octets. This mask enables you to divide your network into segments with fewer computers, making the network more manageable than one with large numbers of computers on very large segments.
- **SUSE.** A distribution of the Linux operating system.
- **Swap.** This term refers to storage capacity that is used by the computer to page information in and out of main memory. This enables you to run programs that otherwise would not have room in memory to run.
- **Switch.** A device that routes network information based on the physical MAC address. It works at the OSI model data-link layer.
- **SysV.** A Linux operating system startup process derived from an old Unix version, System V. It is the most commonly used startup process on a Linux system.
- **TAR.** Short for Tape ARChive. TAR is a Linux utility that combines a group of files into a single file. The tar command does not compress files.
- **Tar Balls.** A repository for program files, universally accepted by Linux and Unix systems.
- **TCP.** Transmission Control Protocol, a connection-oriented, reliable protocol that is used on TCP/IP networks.
- **TCP Wrappers.** TCP wrappers are a form of basic access control. They provide an authentication request, banners, and other services before allowing a connection.
- **TCP/IP.** Short for Transmission Control Protocol/Internet Protocol. TCP/IP is a protocol suite used to communicate over the Internet and most local area networks.
- **Telnet.** A program used on TCP/IP networks to connect to other hosts. Telnet sessions provide a command-line interface to the remote computer. Telnet is not a secure program and uses port 23.
- **TGZ.** Files ending in .tar.gz or .tgz are tar files that are compressed with the gzip program, making them smaller and quicker to transfer over a network.
- **Traceroute.** A program that attempts to trace the route an IP packet follows to a remote host. traceroute uses the Internet Control Message Protocol (ICMP) defined in RFC 792.
- **TurboLinux.** A distribution of the Linux operating system.
- **UDP.** User Datagram Protocol, a connectionless and unreliable transport protocol that is used on TCP/IP networks.
- **UID.** A unique identification number, called the userid, that is assigned to each user.
- **Unix.** A multiuser, multitasking operating system developed at Bell Labs in the early 1970s.
- **USB.** Universal Serial Bus, a port type on a computer system that allows up to 127 devices to be connected.
- **Usenet.** A bulletin board system, called newsgroups, that can be accessed through the Internet.
- **Username.** An alphanumeric string entered by the user that identifies one and only one account. No two users can have the same username.
- **vi.** A command-line text editor that allows only the adding, changing, and deleting of text.
- **Virtual Consoles.** Additional consoles provided by the Linux operating system that can display different types of information.
- **VPN.** An acronym for Virtual Private Network. A VPN uses a public connection to provide the same network connectivity for remote users as that provided over a private connection.
- **Web Server.** A computer that provides access to Web content using the HTTP protocol.
- **Workstation.** A type of Linux installation that is similar to the Personal Desktop Linux installation, but typically includes graphic software development tools, and sometimes network management tools. Workstations are computers designed for the work environment.
- **X.** A windowing system that serves as the core of a GUI operating system.
- **X Windowing System.** A specification for device-independent windowing operations. It is also called X.
- **XFree86.** An open-source client/server interface between the display hardware and the desktop environment.
- **Xterm.** A program that can provide a text-based command line interface from within an X windowing system.
