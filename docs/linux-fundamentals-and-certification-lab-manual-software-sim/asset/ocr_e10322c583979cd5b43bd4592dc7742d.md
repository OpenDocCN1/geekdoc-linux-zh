# Windows

A window is the basic structure of the GUI desktop. A window can contain almost any in- formation. For example, Figure 10-5 shows a window from a word processing application. Windows can display file folders, configuration items, and a host of other things.

Regardless of what the window displays, all windows have standard components. All the components can be displayed or hidden programmatically. This means that some com- ponents can be turned off or on if the developer of the windowed object desires it. The fol- lowing list describes some of the more commonly used window components that are shown in Figure 10-5.

+   **Title Bar** The title bar displays information about the window. The title bar can be used to move the window.

+   **Minimize Button** The minimize button removes the window from the screen, and displays a button on the desktop bottom panel. Clicking the button on the bottom panel restores the window to its original screen location.
