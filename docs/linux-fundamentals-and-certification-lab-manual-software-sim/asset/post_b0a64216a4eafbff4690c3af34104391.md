
## THE LINUX KERNEL

The download files are often identified as i386, i586, PPC, Alpha, or Sparc. This is because each Linux distribution set has to be designed for a particular hardware platform.

- i586 and i386 refer to systems with Intel processors. These are commonly known as personal computers (PCs) and often are already equipped with the Windows operating system.
- PPC refers to Power PC systems from Apple Computer Corporation.
- Alpha refers to Digital Equipment Computer (DEC) systems.
- Sparc refers to systems from Sun Microsystems.

Using an Internet browser you can click the link with the ISO image name you want to start the download. Even though you click a HTTP link, the download is done using the FTP protocol. Most browsers support both protocols. Some browsers, such as Mozilla, will allow you to resume a download if it is interrupted. Being able to resume a download is a huge time saver, especially if you are using a slower connection. You will be prompted for a download location within your local file system. Usually, you can navigate with a GUI interface to find a directory to store your download. Make sure you have enough space to store the downloaded files.

If you have a CD-ROM burner you can write the disk images to a CD. You can then use the CD to install the Linux operating system on your system. There are iso extracting programs that allow you to extract the contents of the ISO to a Windows directory on the hard disk. After the ISO is extracted, you can do the install from the disk.

- You can copy or borrow a distribution set from someone. Remember, one of the great things about using Linux is that the software is free to copy and distribute. If you borrow a disk you should make a copy of it in case you need the disk again. Your system could be damaged by a power surge, an accidentally deleted file, or some other unforeseen catastrophe, requiring re-installation or updating of the operating system.

The Linux kernel can be upgraded similar to any other program in the Linux distribution. (Refer to Chapter 2 to review Linux kernel features.) The kernel is constantly being upgraded by a team of hundreds of developers. When a new kernel is introduced the Linux installation can use it to access newly introduced features. Upgrading a Linux kernel is often done through automatic installation scripts. Some administrators prefer to compile their own kernels from the source code. This should be done only by the most experienced Linux users. Official kernel sources can be obtained from http://www.kernel.org.

There are some advantages to compiling your kernel. If you compile your own kernel you can optimize it for your particular CPU. If your system requires custom drivers, these drivers can be compiled within the kernel; unnecessary drivers can be removed. This will further optimize the system and promote better performance. Patching the Linux kernel is discussed in Chapter 12.

> **NOTE**
> A driver is a program that controls a device. Every device used by the operating system must have a driver. Devices include keyboards, mice, video cards, and other input, output, or storage devices. A driver acts as a translator between the device and the programs that use it. In Linux operating systems device drivers are either part of the kernel or loaded as separate programs.

Compiling your own kernel also can ensure that the most standard features are used. Many distributions provide newly updated drivers and custom features that make using them attractive; however, these features can sometimes cause problems with some computer systems.

Another advantage of compiling your own kernel is ease of upgrading. As new or updated devices are introduced to a computer new drivers must also be used. Compiling the kernel is a way to ensure that the new drivers are included.

Most Linux installations use the kernel developed for the distribution set installed. In most cases the kernel will not have to be compiled. The details of compiling a Linux kernel are beyond the scope of this book. If you are interested in compiling the kernel, there are many sources to research the topic, including Web sites, books, and magazine articles.

## INSTALLATION METHODS

The Linux installer program for your distribution set runs within the Linux operating system. Any method you choose to install Linux requires that Linux be running in order to load the installer. Typically, the Linux boot system can be run from one or two floppies or it can be run from a bootable CD-ROM.

All personal computer systems can be configured to boot from a small range of sources. To configure the boot source, you must enter the setup program when the computer starts. To enter the setup program you press a key when the initial computer screen displays the prompt to do so. Typical choices are Diskette Drive, Internal Hard Disk Drive, CD-ROM, Network Interface Card (NIC), and USB Storage Device. Some distributions include a DOS or Windows program that can launch the installer.

Depending on the system and your distribution set, you may need a floppy disk to start the install. Some distributions come with a floppy disk, but others do not. If you need a boot floppy disk, you can make one from the distribution set or you can download the tools to create one. Most Linux distributions come with a program called rawrite.exe to perform this task. Rawrite is a Windows/DOS program used to create a floppy disk from an image file. To create a floppy disk image using rawrite.exe from most distribution disks, follow these steps:

1. Change drives to your CD-ROM. If you have only one hard disk drive or partition, your CD-ROM is probably drive D:. To change to this drive, type **D:** and press Enter.
2. Change to the dosutils directory. To change to this directory, type `cd \dosutils` and press Enter. A directory list should look similar to the following:

3. Create the boot disk. The boot disk you create depends on the type of installation you are going to do. The Mandrake Linux distribution set includes the following images stored on the CD-ROM's images directory:
   - **cdrom.img** or **boot.img** is used to install from a local IDE or SCSI CD-ROM.
   - **network.img** is used to install from a NFS, FTP, or HTTP repository. NFS is Network File System, a client/server application from Sun Microsystems that allows network users to access shared files on network computers. FTP is File Transfer Protocol. It is used on the Internet to exchange files between remote computers. HTTP is Hyper Text Transfer Protocol. This is the protocol used by content on the Internet.
   - **pcmcia.img** is used to install from a PCMCIA card. PCMCIA devices are small, credit-card size cards, usually connected to laptop computers. They can be network cards, CD-ROMS, and other devices.
   - **hd.img** is used to install the Linux image from a hard drive.
   - **usb.img** is used to install from a USB device such as an external CD-ROM.
   - **other.img** is used to install from less common devices. Use this img file if others do not work.
   Different distributions may have different names and types of images. For example, Red Hat has an image called bootdisk.img for all types of installation methods.
4. Have one or two formatted 3.5-inch high-density 1.44 MB diskettes available and then enter the command **rawrite**. Press Enter.
5. Enter the disk image source file name: **d:\images\cdrom.img**
6. Enter the target diskette drive: **a:**
7. Insert a formatted diskette into drive A and press Enter.
8. Boot with the disk. After you have boot a boot floppy, if needed, you only have to start your computer with the newly created floppy disk in drive A. Depending on the type of boot disk created, you will be asked for options. For example, if you boot from an image for network connection, you will be asked for your computer connection information and the type, address, and directory of the remote site.

## CD Installation

If you have a CD-ROM distribution and your system will boot from CD, you can start the Linux installation by inserting CD and starting the computer. You will see an installation screen start menu similar to Figure 3-1. The start menu asks what method of interaction you want to use during installation. The installation choices on this menu are graphical interface or text interface. With the graphical interface option, Linux must have an available graphics driver for the installed graphics adapter. Choosing the text mode option does not require a graphics driver and will work in all installations. The only real difference between the two interfaces is how the screen looks and how you select options, mouse or keyboard. Even in the cases where the screens are slightly different between the two, all the same options are available.

The graphical user interface allows you to navigate the installation screens using the mouse and GUI tools, such as buttons and drop-down lists. You can also navigate through the installation using the Tab and Enter keys.
