### PKG Packages
PKG packages do not provide for signing, but do provide for checksums and dependency checking. PKG files cannot be viewed or manipulated by standard Linux tools.

Some Linux distributions provide for automatic updates to packages. For example, Red Hat Linux offers the Red Hat Network. The Red Hat Network is a complete systems management platform for Unix. It provides updates to software, increased management capabilities, and monitoring of the entire infrastructure. Automatic updating of RPM packages on Red Hat Linux is done with the up2date program.

### SYSTEM FEATURES

Linux supports most of the features found in Unix installations. It's a multitasking, multi-user operating system, meaning that it can run more than one program at a time and supports multiple users connected at the same time.

Linux is mostly compatible with Unix. Linux was developed with portability in mind. Most of the free software available online can be compiled under Linux and runs easily.

Linux supports multiprocessors on Intel, AMD, IBM, Sun, and other platforms (depending on the distribution). Symmetric Multi-Processor (SMP) support was introduced with kernel version 2.0. With SMP, processes and kernel-threads are distributed among processors. This means that while you are multitasking, each program can be controlled by its own processor. Using more than one processor is almost like having more than one computer to do the jobs you are running.

Linux supports multiple virtual consoles. A console is used by the user to enter commands. Up to 63 consoles can be used at one time.

Linux supports several file systems including minix, Xenix, and all the common System V file systems. It also has an advanced file system of its own, ext3, which offers file systems of up to 4 TB and names up to 255 characters long. The ext3 file system is a journalizing file system. Journalizing file systems can be checked for consistency far more quickly than non-journalizing file systems. Today's file system sizes often exceed several hundred gigabytes, and so the difference in recovery time after an ungraceful shutdown can run into several hours.

Linux also supports MS-DOS partitions. You don't need any special commands to use the MS-DOS partition, since it looks similar to a normal Unix file system.

Most Linux distributions provide support for TCP/IP, AppleTalk, NetWare, and LAN Manager/Windows Native (SMB or Server Message Block) client and server. These are protocols for sharing files, printers, serial ports, and communications between computers.

### Support for Linux

Many question the availability of support for Linux. You may ask yourself, "What kind of support do I have for Windows?" Sure, you can call Microsoft, but if you want support you will have to pay for it. The same, however, does not hold for the Linux version you are using.

Support for Linux can be found for free on newsgroups. (You can find many groups that support Windows, as well.) Both Linux and Windows provide on-line access to documentation.

There are more trained technicians and administrators for Windows than for Linux. However, there are more training courses and certifications for Linux available today and the number is growing every month.

At least with Linux you get the source code. If you don't like the way something works, you can change it.

As with any operating system, Linux is not perfect. You can experience problems with running hardware and software in Linux, just as with Windows and Unix. Many administrators report that they run their Linux systems for months without having to restart, not something many Windows installations can boast. Overall, we think you will find that Linux is a good operating system and worth the time and effort you will need to get acquainted with it.

### THE FUTURE OF LINUX

The future looks good for Linux. To users, the only purpose of an operating system is to provide a platform to run applications. Linux has a huge base of applications, many of which have the source code available. A growing number of software companies, such as Oracle and Sun Microsystems, are porting their applications to Linux.

Over the next few years, Linux will have an increasing role in business. Reducing the cost of software licensing and providing more secure networks will increase the demand in both private and public areas.

Using the material provided in this book is a good way to start preparing for the Linux+ exam. To complement this information, you must also install and administer the Linux operating system.

The Linux kernel is always in development. While other operating systems offer updates a few times a year, Linux is, at times, updated weekly. The entire operating system need not be reinstalled to use the latest version of the Linux kernel. Patches are available to upgrade the kernel to provide access to newer device drivers and security updates. Kernel patching is discussed in Chapter 12.

### SUMMARY

Linux is the kernel of the operating system. When used along with GNU software it forms the GNU/Linux operating system. GNU is a recursive acronym for "GNU's Not Unix". The source code for Linux is free and available for anyone to revise and implement to meet their individual needs.

The copyright for GNU products is basically a "copyleft." Copyleft uses copyright law, but flips it over to serve the opposite of its usual purpose. Instead of serving as a means of protecting private software, it, instead, keeps software free.

Linux can be run on machines that have outlived their usefulness as Windows machines. Linux can provide usefulness without implementing a GUI with the operating system. It can be used in a number of ways including as a software development platform, firewall, DNS server, DHCP server, and many others.

There are more than a hundred distributions of Linux. A distribution contains the Linux kernel and a host of GNU applications for networking, development, and office productivity. The kernel development cycle is denoted by the version number. Odd-numbered versions denote periods when kernel features are being added and developed. Even-numbered versions denote smaller modifications made in the stabilization phase to the kernel.

Linux supports most of the features found in Unix installations. It’s a multitasking, multiuser, and multiprocessor operating system. Linux also supports many file systems including its own ext3, which offers sizes up to 4 TB. It also supports a wide variety of networking protocols.

Package management programs are used by all Linux distributions to install, uninstall, and update software packages. The most popular package programs are RPM, DEB, TAR, and SLP.

Support is available from Internet news groups, online documentation, and private companies.
