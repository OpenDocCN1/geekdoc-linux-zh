# Formatting a Partition

After a partition is created, it must be formatted. Many Linux versions use the **mkfs** program. Several options are available for the **mkfs** program. The *-t* option allows you to select the type of file system, and the *-v* option is for verbose.

**mkfs -t ext3 -v /dev/hda3**

This command will format the newly created partition using the partition's default file system type. The file system type for this partition is **ext3**.
