A useful command when dealing with file systems is the **du** command. The du command displays the estimated amount of space being used by files in a directory. If you type **du** at a shell prompt, the disk usage for each of the subdirectories will be displayed in a list with the grand total of file usage as the last line. To see only the total file usage, type **du -hs**.

Another command used with file systems is **df**. The df command displays the amount of disk space available on the file system. If no filename is given in the command, then the space available for all currently mounted file systems is shown. To show available disk space in 1K blocks, use the -k option. The syntax of the df command is **df [ -options] [file]**. To see available space on all file systems, type **df -k**.

# # FILE PERMISSIONS

The primary function of file permissions is to deny access to unauthorized users. Permissions are used in conjunction with the UID and GID, or in other words, depending on the username and group assigned.

Linux provides two default levels of security. A user must supply a username and password for authentication. After the user is determined to have valid access to the Linux system, the second security level, file permissions, determines if the user is authorized to access the resource.

File type is indicated by the first character. A file is represented by a hyphen (-) and a directory is represented by the letter d. Sockets are indicated by the letter s, symbolic links with l, and block and character devices with b and c respectively. The next nine characters represent the permissions for the owner, group, and other users.

The owner is represented by the next three characters. The letter r represents read permission, w represents write permission, and x represents execute permission.

The second set of three characters represents group permissions. These are the permissions assigned to the group identified by this file. In this case the group is dengle, but could be any group assigned by the system administrator. Users in the same group can access each other’s files based on the group permissions.
