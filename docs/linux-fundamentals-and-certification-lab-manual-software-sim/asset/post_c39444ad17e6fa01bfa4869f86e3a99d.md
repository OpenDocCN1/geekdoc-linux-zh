
## NOTE

“Lightweight” can have several meanings. For example, when you install the Windows operating system you install the graphical interface and all that it includes, making for a large (heavyweight) installation. In many cases Linux can accomplish the same functionality as a similar Windows installation but without the overhead. The GUI (graphical user interface) is not required, and many other tools can be removed from a standard installation, thus making Linux a lightweight yet powerful operating system.

Embedded Linux is a great implementation, but typically most users will not be involved with installing it. The amount of resources needed to run Linux as an embedded system varies widely. For more information about embedded Linux, connect to http://www.embedded-linux.org.

## Personal Desktop

A personal desktop installation of Linux is designed for the home user and is good for personal productivity. Typically, the installation includes a GUI environment such as GNOME or KDE, personal productivity software such as OpenOffice.org, and games, and may or may not include network connectivity.

Users may experiment with server software, but the personal desktop is the most widely used installation type. The personal desktop installation of Linux gives users basically the same functionality they get from a Windows installation. As already mentioned, a typical installation includes the GUI as well as text editors, tools to manage the desktop, a folder manager similar to Windows Explorer, an Internet browser, and additional features, such as remote access to the desktop, not found in most Windows systems. Most distributions of Linux provide productivity software such as OpenOffice.org. OpenOffice.org, as its name implies, is open-source software and can be downloaded free from http://www.openoffice.org. OpenOffice.org, a suite of productivity tools, contains:

- **WRITER** A powerful word processing application, similar to Microsoft Word, for creating documents, reports, newsletters, and brochures. It integrates charts, graphs, and images within documents.
- **CALC** A spreadsheet application that functions similar to Microsoft’s Excel application. CALC provides advanced spreadsheet functions, decision-making tools, and 2D and 3D charts.
- **IMPRESS** A multimedia presentation package that provides basic text formatting, special effects animation, and drawing tools.
- **DRAW** A simple drawing application to design everything from simple diagrams to 3D illustrations.
- **DATABASE USER TOOLS** OpenOffice.org doesn’t have a database as part of the suite; however, it does provide some tools to let you manage existing databases, such as MySQL or ODBC-compliant databases.

StarOffice, a product from Sun Microsystems, uses the same source code as OpenOffice.org and the core suites are the same. StarOffice is commercial software, not open source. StarOffice has additional features and capabilities, such as:

- a more sophisticated spell-checker
- a clip-art collection
- additional macros and filters
- the Adabas database

The software available for personal productivity with different distributions of Linux varies. Some applications are available free as open-source software, others are available for purchase. If your distribution does not include software, you can download it from a wide range of sources. A personal desktop Linux installation requires between 1 and 2 GB of hard disk space. The amount of memory required will depend on the software chosen; however, most systems will run with as little as 32 MB of RAM and will run well with as little as 128 MB of RAM.

## Workstation

A workstation installation of Linux is similar to a personal desktop with inclusion of graphic, software development tools, and, sometimes, network management tools. Workstation implementations are designed for the work environment. Typically, network options, development tools, and high-end output devices are included.

The software used is typically productivity software, but is usually purchased software that provides for e-mail or telephone support and possibly formal training. An example of purchased productivity software is StarOffice from Sun Microsystems. StarOffice is the close cousin of OpenOffice.org but is licensed through Sun.

A workstation typically provides access to corporate databases, high-end printers, high-end graphic applications, and other business software packages. Because workstation applications are so demanding of resources, a workstation tends to be more powerful than a basic personal desktop machine.

A typical workstation requires between 2 and 2.5 GB of disk space and, minimally, 128 MB of RAM. Many workstations have higher video demand and, therefore, have larger, high-definition monitors and more powerful graphic adapters.

## Server

A server installation is used to service other computer systems. The computers using the server are called clients. This setup of clients and servers is called a client/server environment.

It is a server's job to provide services to other computers. These services could be network services, database services, Web services, file services, or messaging services. The server can have one to hundreds of users requesting services at any one time. Because of this, servers tend to be larger in capacity than personal desktop or workstation computers. However, the services that a server provides can be small to large in nature and can vary the requirements of a server greatly. A look at the services provided by the server will make the requirements of the server clear.

### Network Services

The network services that are provided depend on what type of network protocol (the communication rules used between network devices) is used, of which there are many. The most commonly used network protocol today is Transmission Control Protocol/Internet Protocol (TCP/IP), the protocol of the Internet. The following sections contain a brief description of some of the more common network services for TCP/IP.

### DNS

There are a wide range of network services that a server can provide. For example, a server is needed to provide DNS information to a network. Domain Name System (DNS) provides an Internet Protocol (IP) address for a domain name. Domain names are registered with their associated IP addresses and, when requested, the domain name is looked up and the IP address returned. When using the TCP/IP suite of network protocols, every machine must have an IP address assigned to it. DNS can be run on a minimal server configuration, often smaller than a personal desktop machine.

### DHCP

Dynamic Host Configuration Protocol (DHCP) is used to automatically configure host computers for the network. When a computer starts, it broadcasts a packet of information requesting DHCP. When another computer, running DHCP, sees the broadcast it responds with network information. Network information contains the IP address for the host, subnet mask, and gateway IP address, and can contain the IP address of the DNS server that it uses. The purpose of DHCP is to relieve the administrative burden of assigning static IP addresses to each host on a network. DHCP can be run on a minimal server. A good Pentium-class machine can serve this purpose. (Older distributions of Linux will work on Intel-based 386 or 486 machines; however, many current distributions of Linux have outgrown the older machines.)

### Routing

A Linux server can be used as a router. A router's job is to provide switching and path determination for packets of network information. In other words, a router accepts a packet of information from a host, reads the destination IP address, and then determines the best path to use to forward the information. Often an older machine can be equipped with two or more network interface cards (NICs) to provide this service. A packet will come into one NIC, be examined and found to be addressed to a network available on the other NIC, and then routed out the second NIC. This same machine can provide DHCP and DNS as well. As part of its routing duties, a Linux router can filter out unwanted packets to provide a source of security to the internal network.

### Firewall

When a packet is sent from one machine to another over a network, it is addressed with not only the IP address, but also the port to use for communication. When the packet is received by the remote host, it determines what type of packet is being received and routes the information to the designated port number. There are many common ports that are used for file transfer, telnet, mail, and others. A firewall is a software package that restricts access to specific ports, thus making the Linux operating system a more secure environment. This system can also be minimal in size. An older system will usually work nicely as a firewall. Firewalls and networking are discussed in Chapters 6 and 11.

### ipchains

ipchains is a program used to enable packet filtering, network address translation (NAT), and other packet manipulation. The major use of ipchains is to turn your Linux computer into a gateway between a private network and the Internet. A packet is a unit of information sent from computer to computer across intranets or the Internet. It basically has a header with routing information, where it's coming from and where it's going, and a body with all the other information. NAT is a way for a private network to communicate with other networks. It takes the private network address and translates it to a public network address that other networks recognize. When packets arrive from other networks, NAT translates to the appropriate address within the private network. ipchains also provides a way to work as a firewall (a way to block unwanted packets to or from the internal network). ipchains is discussed in Chapter 11.

### Squid

Squid is a high-performance proxy caching server for Web clients, supporting FTP, and HTTP data objects. Internet object caching is a way to store requested Internet objects on a system closer to the requesting site than to the source. Web browsers can then use the local Squid cache as a proxy HTTP server, reducing access time as well as bandwidth.

Without going into too much detail, an IP address consists of a 32-bit value. Usually, for convenience, it is presented in decimal dot notation, four octets (bytes) separated by a dot and shown as decimal values. For example, 192.168.0.1 is an IP address. Each physical network has its own unique network address. Each host has its own unique address. Each host is assigned a gateway, or router's address, to which it can send information to be routed to other networks. There are five classes of IP addresses, denoted as Class A through Class E. Each class has a specific range of IP addresses to use. Each IP address is divided into network and host identification. The host identification can be further divided by using a subnet mask, which makes part of the host address valid for network addresses and part available for hosts (individual machines).
