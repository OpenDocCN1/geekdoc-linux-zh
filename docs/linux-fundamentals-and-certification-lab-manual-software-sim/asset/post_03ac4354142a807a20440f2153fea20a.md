
## Firewall.
A software package or network appliance (such as a PIX firewall from Cisco) that restricts access to specific ports, thus making the Linux operating system a more secure environment.

## Foomatic.
A printer driver database used by most current Linux versions. It supplies common printer drivers, generating Adobe-compliant PPD files that allow easy setup of print queues with access to all driver options. Foomatic is an XML-based system that integrates the free software drivers with all common print spoolers.

## Format.
The term that describes the preparation of a storage device for use on a computer system.

## Free Software Foundation.
The principal organizational sponsor of the GNU project.

## FreeBSD.
A free version of the Unix operating system, similar to Linux.

## Freeware.
Software that can be freely distributed, but retains the author's copyright.

## FTP.
Short for File Transfer Protocol, FTP is the protocol used to transfer files over a TCP/IP network. FTP uses port 21 for file transfer control and port 20 for file transfer data.

## Gateway.
The IP address to which data can be routed to communicate with networks outside the local network.

## GID.
An acronym for groupid, a unique number assigned to each group.

## GNOME.
GNU Network Object Model Environment, a GUI desktop environment with a panel, a desktop, system icons, and a graphical file manager.

## GNU.
Recursive acronym for GNU's Not Unix. GNU is a Unix-compatible software system developed by the Free Software Foundation (FSF). GNU software can be modified and freely redistributed.

## GPG.
GnuPG is a free replacement for, and based on, PGP. It provides public-key encryption for exchanging files or messages with confidentiality and authentication.

## GPL.
Acronym for General Public License. This license usually accompanies open-source software and allows the software to be copied, distributed, and modified.

## Group.
A logical grouping of users and resources.

## GRUB.
Acronym for GRand Unified Boot loader.

## GUI.
Acronym for Graphical User Interface.

## Hardware.
The physical portion of a computer system.

## Hostname.
The common name of the local host.

## Hosts.
Devices that are connected to a network and are identified by a unique value that allows communication over the network.

## HTTP.
HyperText Transfer Protocol, a protocol used to request and transmit files over TCP/IP networks. It uses port 80.

## Hub.
An OSI model physical layer device that is used to connect multiple hosts to a network.

## IETF.
Internet Engineering Task Force.

## IMAP.
Internet Message Access Protocol, a protocol used to receive e-mail. IMAP is similar to POP3, but supports additional features. It uses port 143.

## IP Address.
An address assigned to every host on a TCP/IP network, consisting of a 32-bit number expressed as four decimal numbers separated by decimals. For example, 192.168.0.1 is an IP address.

## iptables.
A Linux program used to enable packet filtering, network address translation (NAT), and other packet manipulations.

## IPsec.
Strong cryptography that provides both authentication and encryption services.

## IRQ.
Short for Interrupt ReQuest, an IRQ sends an interrupt signal to the CPU to indicate that a device needs to execute a task.

## ISDN.
Integrated Services Digital Network, an international communications standard used for sending voice, video, and data over digital telephone lines.

## ISO.
Short for International Organization for Standardization. ISO is not an acronym, but is derived from the Greek word "iso," which means equal. ISO is composed of national standards bodies from over 75 countries. ISO defined the Open Systems Interconnection (OSI) model for network design.

## ISO 9660.
A file system standard for CD-ROMs that allows you to read the same CD-ROM on most major operating system platforms. It is also called High Sierra.

## KDE.
A GUI desktop environment with a panel, a desktop, system icons, and a graphical file manager.

## Kerberos.
A secure system used for providing network authentication services.

## Kernel.
The core of an operating system. The kernel is the part of the operating system that loads first and remains in memory during operation. It is typically responsible for memory management, process management, and disk management.

## Kernel Module.
Provides for functionality in the Linux kernel. This gives it basic functionality for using the keyboard, the mouse, and other devices.

## LDAP.
Short for Lightweight Directory Access Protocol, a centralized hierarchical database used for authentication.

## Left-Click.
Clicking an object on a desktop with the left mouse button. Typically, left-clicking an object selects the object.

## LILO.
The Linux Loader boot loader.

## Linus Torvalds.
The main developer of the Linux kernel.

## Linux.
A free operating system kernel, the core of the Linux operating system.

## Linux Distribution.
An operating system based on the Linux kernel.

## LKM.
Loadable Kernel Module, loaded dynamically by the Linux kernel.

## Log.
A chronological listing of events stored by programs in a file. Logs are used to track system and program problems within the operating system.

## LVM.
Logical Volume Management is a partitioning method available to the Linux 2.4 kernel that enables you to create logical volumes out of the physical storage while the system is still running.

## MAC.
MAC, Media Access Control, is a 48-bit value, divided into two 24-bit values, that identifies a host's adapter. The first 24 bits define the manufacturer of the adapter, and the second 24 bits identify the local host.

## man.
A Linux command that formats and displays the online manual pages.

## Mandrake.
A distribution of the Linux operating system.

## Master boot record.
The first sector on a hard disk. It contains the partition table for the disk.

## MD5.
A one-way hashing function that creates a unique number and associates it with a message. This number can be generated on the receiving end to ensure that the message has not been changed.

## Mouse.
A pointing device used in a GUI environment to control the movement of a pointer on a screen.

## Multiprocessing.
This term describes an operating system that supports more than one process at the same time.

## Multiuser.
This term refers to an operating system that supports two or more simultaneous users.

## NAT.
Short for Network Address Translation, an Internet standard that enables a local area network (LAN) to use one set of IP addresses for internal traffic and a second set of addresses for external traffic.

## Network Installation.
Installing Linux from a network enables you to complete installation without having to carry the distribution disk from machine to machine. The disk can be stored on a network hard drive, in the same method as a hard disk installation, and accessed through NFS, FTP, or HTTP.

## NFS.
Short for Network File System, a standard for sharing files over a network developed by Sun Microsystems.

## NIC.
An acronym for Network Interface Card.

## NIS.
The Network Information Service, or NIS, enables you to run a group of computers in a domain with a common password and group file.

## NTP.
NTP, or Network Time Protocol, allows computers to synchronize with a remote network time server.

## Open Source.
A term that describes a program that is distributed together with its source code.

## Operating System.
A software platform on top of which application programs run.

## OSI Model.
The OSI, or Open System Interconnection, model identifies seven layers of network function. Each layer specifies particular network functions, such as addressing, flow control, error control, encapsulation, and reliable message transfer. The highest layer manages the flow of information from the application to the network, whereas the lowest layer identifies the methods of physical data flow between devices. The seven layers from 1 to 7 respectively are: physical, data-link, network, transport, session, presentation, and application.

## Package.
A software bundle for a program on an operating system.

## Packet.
A portion of a message sent over a packet switching network. Each packet has, among other things, the data to be sent and the source and destination IP addresses of the network hosts.

## Panel.
A work area on the GNOME or KDE desktop that can contain a wide range of shortcut options. Panels can be corner, edge, floating, menu, or sliding panels.

## PAP.
Short for Password Authentication Protocol, PAP is a simple method for a host to establish its identity to the server. The remote client and the server establish a connection using PPP, and then the remote client sends a username/password pair until the server acknowledges authentication or the connection is terminated.

## Parameter.
A value or group of values that is passed to a program on startup.

## Partition.
A logical segment of a disk drive that acts as a separate drive.

## Password.
An alphanumeric string entered by a user that verifies that the associated user is the one in question.

## Patch.
Object code that is inserted into an executable program. Patching is a temporary measure that is used until a new version of the software is made available.

## PATH.
An environment variable that points the operating system to the most commonly used file locations.

## Permissions.
Settings that control the kinds of access allowed to resources. Three different permissions are used: read (r), write (w), and execute (x).

## Personal Desktop.
A type of Linux installation designed for the home user. It typically includes personal productivity software and the GUI interface.

## Personal Firewall.
A single point of defense that all network traffic must go through in order to communicate with applications on a computer.

## Personal Productivity Software.
Software designed for personal productivity, such as word processing, calendar, e-mail, and so on.

## PGP.
An acronym for Pretty Good Privacy, a public-key encryption application that is used for exchanging files or messages with confidentiality and authentication.

## PID.
Short for Process ID, a number that is assigned to a process when it is started.
