# CHAPTER 7

Network design is based on the Open System Interconnection (OSI) model. The OSI model identifies seven layers of network function; application, presentation, session, transport, network, data link, and physical.

Network components include hosts, hub, switches, and routers. Hosts communicate using all seven layers of the OSI model. Hosts include computers, routers, and other TCP/IP devices. A hub is a physical layer device that connects multiple computers together in a network segment. A switch is a data-link layer device that connects multiple computers together in single or multiple network segments. A router is a network layer device that determines path determination and switching.

Networks are designed using ring, star, and bus topologies. The most common topology is Ethernet bus topology. Ethernet topology is also a broadcast topology, meaning that it broadcasts information to all hosts on the same network segment. Ethernet uses CSMA/CD.

The most commonly used protocol for network connection is Transmission Control Protocol/Internet Protocol (TCP/IP). TCP/IP is a suite of protocols for file transfer, remote login, e-mail, and other network functions.

Every host on a network must have an address associated with it. The IP addressing scheme defines three classes of IP addresses: A, B, and C. Class A addresses are in the range of 0 to 127, class B addresses from 128 to 191, and class C addresses from 192 to 223 in the first octet.

Configuring a computer on the network requires not only the IP address of the hosts, but also the address of the gateway, the DNS server, and other information. Addresses are configured on a host statically or dynamically. Dynamic addresses are obtained using the DHCP protocol.

Common applications for the network include Web browsers, e-mail clients, FTP clients, and others. Network applications that use passwords should use encryption to secure data transfer. One set of programs that offer secure communications is OpenSSH. OpenSSH has tools to transfer files, establish remote connections, and perform other tasks.

Resources on remote devices can be shared over a network with SMB and NFS protocols. SMB is a protocol that is used in Microsoft Windows applications for sharing resources. NFS is a protocol from Sun Microsystems that is used for sharing resources. Both protocols allow for mounting remote file systems locally.

Simple Network Management Protocol (SNMP) is designed to integrate management of different types of networks. An SNMP server application is an agent and an SNMP client is a manager.

Network Information Service (NIS) is a protocol that is designed to simplify user authentication. NIS allows users to authenticate across multiple hosts.

Remote access to a server is used to remotely manage computer systems. Non-secure programs such as Telnet and rsh are not recommended. The OpenSSH program, ssh, is a better choice because it uses RSA keys for secure communication.

Firewalls are used to restrict access to network resources. Typically, a router acts as a gate to an internal network, restricting access from untrusted networks. Firewalls can be hardware or software. Hardware firewalls are dedicated devices that offer better utilization of bandwidth than software firewalls.

After a network is configured, it should be monitored. Tools for monitoring a network are who, w, finger, and last. The wtmp log file is used to track login information.
