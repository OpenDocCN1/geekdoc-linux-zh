# ## SUMMARY

The Linux desktop is an X window system client program that displays GUI components. Most servers do not require the use of a GUI. Most non-servers have GUI desktop applications for user applications.

The desktop is the workspace of a GUI environment. Its basic components are windows, menus, and icons. Most desktop environments have panels, which are non-workspace areas on the screen for menus and other shortcut applications.

GNU Object Model Environment (GNOME) is a popular desktop application for Linux. GNOME is also an application development environment that provides libraries to allow programmers to create applications with standard menus and dialog boxes.

K Desktop Environment (KDE) provides GUI applications for file management, network access, system configuration, and Internet browsing. It is also an application development platform.

xterm is the name not only of a terminal emulation program, but also of a class of terminal emulation programs. xterm has been improved with new applications, rxvt, GNOME Terminal, and Konsole. All these applications offer access to DEC VT102/VT220 terminal emulation. Most offer access to Tektronix 4014 compatible terminal emulation.
