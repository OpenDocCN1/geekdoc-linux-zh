# PHYSICAL ACCESS SECURITY

Keeping your data secured with permissions, cryptography, or security updates is a good idea. But what do you do if someone steals your hard drive? What do you do if someone gains physical access and steals a backup tape? Don't spend all your resources on soft security and leave all the hard security undone.

There is no way to be completely sure that the physical security of your computer system will not be breached. So, what reasonable steps can you take to physically secure a computer system?

+   *   **Make sure the door is locked.** If you lived in a city with a high crime rate, you wouldn't leave your door unlocked. So, don't leave your computer center unlocked. Secure the door and consider using a security center. The measures you take will be determined by how important the data center is. Some organizations post guards, use keycards, and even scan thumbprints to verify who has access to the computer center.
*   **Secure the computer.** Most computer systems have a key that ensures that the computer can't be turned off or disassembled. Some systems even have special screw heads on the covers that require special tools to remove the cases.
*   **Remove any external storage devices.** Don't keep an external floppy disk or CD-ROM drive attached to the computer. If such devices are needed, removable devices are available that can be connected in seconds.
*   **Consider using video cameras to record access.** Many video cameras, often using the Linux operating system, will FTP captured images to an FTP server. These images can be used to record unauthorized access and can be copied to a remote location.

Physical security includes security from fire or water damage, too. At the very least have fire extinguishers in close proximity and ensure that all users with access know where they are. Fire extinguishers should be inspected regularly.

# SUMMARY

Security is an ongoing process comprised of four phases—secure, monitor, test, and improve. Securing the computer is a first step. This step includes strong passwords, enabling firewalls, applying file system permissions, establishing VPNs, and running software updates. Monitoring includes checking logs, monitoring open ports, and tracking who has logged on to the system. Testing includes running programs like John the Ripper to check that security measures are running properly. After monitoring and testing are completed, the information gained is used to secure the system again and the process starts over.

A software program is often under its own cycle of development, testing, deployment, and changes. Programs are not perfect and require constant monitoring. After a problem is found, developers make necessary changes and distribute them in the form of updates. Keeping software up-to-date is one of the best ways to ensure that unauthorized access is denied.

Updates are secured over the network with encryption. Asymmetric encryption provides a way to exchange encryption keys to ensure that data is not tampered with during download. Encryption keys and electronic certificates are used to sign software packages to ensure that the packages are valid and have not been tampered with.

Workstation security involves securing the boot loader, choosing strong passwords, disabling root login, and setting up a personal firewall. Securing the boot loader prevents unauthorized users from gaining access by power-cycling the system.

Strong passwords include using uppercase and lowercase letters, numbers, special characters, and a length of at least eight characters. Passwords consisting of birth dates or proper names are easily cracked, often in seconds. Passwords should be used for a limited time and then changed.
