When a packet comes in, the kernel looks at the destination and determines the routing. If the routing is to localhost, the packet is sent to the INPUT chain. If the INPUT chain rules are met, the packet is passed to the internal processes.

If the routing is to another host, the packet is sent to the FORWARD chain. If the FORWARD chain rules are met, the packet is forwarded to the destination host.

A process running on the local host will send packets to the OUTPUT chain. If the OUTPUT chain rules are met, the packets are sent out.

To start the iptables service, use the **service iptables start** command.

Using ipchains is complicated and requires expertise and trial-and-error to get it right. For a complete list of ipchains options and actions, look at the man ipchains command. Some of the ipchains options are as follows:

+   - **-N** Create a new chain.
- **-X** Delete an empty chain.
- **-L** List the rules in a chain.
- **-F** Flush the rules out of a chain.
- **-Z** Reset the packet and byte counters on all rules in a chain.
- **-A** Append a new rule to a chain.
- **-D** Delete the first rule that matches in a chain or a chain rule number.
- **-j** Indicates the target. This can be another chain or one of the special values ACCEPT, DROP, QUEUE, or RETURN. ACCEPT lets the packet pass through to its destination. DROP terminates the packet, not allowing it to pass. QUEUE sends the packet to userspace. RETURN means to stop using this chain and to return the packet to the next rule in the previous chain.
- **-s** The source IP address or DNS name of the packet.
- **-p** The protocol to check against the packet. The specified protocol can be tcp, udp, icmp, all, or a numeric value representing a protocol.
- **-v** Verbose listing.

To add a rule to a chain, use the -A option. One way an unauthorized user gains access to a computer is by first determining that the computer is on the network. A computer can be found on the network by pinging its IP address. The following command pings the Linux server at address 192.168.0.21 from the local host IP address 192.168.0.3.
