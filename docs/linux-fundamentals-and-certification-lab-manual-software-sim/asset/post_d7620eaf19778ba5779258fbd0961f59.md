### WHAT IS LINUX?

Before you jump into Linux, you need to know something about **GNU** (a recursive acronym for “GNU’s Not Unix”). The GNU project was started in 1984 with the goal of developing a Unix-like operating system and distributing it for *free*. The GNU Project developed some of the programs, but instead of doing all the development work it incorporated many existing, “free” programs.

> **NOTE**
> You can learn more about GNU by visiting www.gnu.org.

The GNU software license is a *copyleft* license. Copyleft is a general method of making a program free software and requiring all modified and extended versions of the program to be free software as well. This means that anyone may redistribute GNU software, with or without changes, but you must pass along the freedom to further copy and change it.

Linux is an **operating system**, similar to Unix, and designed to be used on a wide range of hardware platforms. More accurately, Linux is the kernel of the operating system. Linux is used in combination with the GNU operating system. It is currently being used to control everything from security cameras to high-end enterprise servers.

The kernel of an operating system is its most basic component part. An operating system is built in layers, with each layer providing new capabilities such as access to a keyboard, or a screen. The kernel provides low-level services such as memory management, basic input/output, security, scheduling tasks, and routing data for the operating system.

Most distributions of the Linux operating system can be installed in about thirty minutes without a lot of technical knowledge. The installation parameters are discussed in Chapter 3.
