# SECURITY

A file would have the value of 664 or **rw-rw-r--** (664). To see the results, use the `mkdir` command to create a directory or the `touch` command to create a file. The following command sequence shows the results:

```
$ mkdir mydir
$ touch myfile
$ ls -l
total 4
drwxrwxr-x 2 rbrown rbrown 4096 Nov 16 15:52 mydir
-rw-rw-r-- 1 rbrown rbrown 0 Nov 16 15:52 myfile
$
```

The umask value can be changed by using the umask command. For example, to make the default umask value for the group read permission only and others no permissions, use a umask value of 037. The binary value of 037 is 111011111, making the corresponding permission values for directories and files 111100000 or rwxr----- for directories and 110100000 or rw-r----- for files. The following command sequence shows the result:

```
$ umask 037
$ mkdir mydir
$ touch myfile
$ ls -l
total 4
drwxr----- 2 rbrown rbrown 4096 Nov 16 16:02 mydir
-rw-r----- 1 rbrown rbrown 0 Nov 16 16:02 myfile
$
```

# Removing Unnecessary Programs

Unnecessary programs on your Linux system pose a security risk, and they use disk space as well. An unauthorized user can run programs on the Linux system that may not be running, which poses security issues. For example, an FTP program may be installed but not used. An unauthorized user can run the program and then take advantage of known exploits in your system with it.

There are many ways to view which packages are installed on the Linux operating system. The best ways are with GUI tools.
