# NETWORK BASICS

Networking computer systems encompass many different technologies. This brief introduction to networking is only the tip of the iceberg. To become proficient with networking technologies, consider taking a Network+ or CCNA course. Network+ is a set of objectives suggested and tested by Comptia. CCNA is a course of study and testing sponsored by Cisco Systems.

Networking has undergone a lot of changes over the last 20 years. In the late 1970s, networks were accomplished in many proprietary ways. It was not uncommon to find computers networked through serial cables and parallel cables. The main advantage to networking at that time was the ability to share a printer, and many did that with whatever means were available.

By the 1980s, the development of LANs was eclectic. From business to business you could find any number of proprietary network solutions. Standardization of network hardware or software was nonexistent. As organizations grew, it became more difficult to assimilate the different networks into one usable LAN. The need for a standard was realized.

To help bring order to networking solutions, the International Organization for Standardization (ISO) started research on network schemes to find a set of rules that could be applied universally. The result of this research was a network model called Open System Interconnection (OSI) that any vendor could apply to the creation of network hardware.

# OSI Model

The OSI model identified seven layers of network function. Each layer specifies particular network functions, such as addressing, flow control, error control, encapsulation, and reliable message transfer. The highest layer manages the flow of information from the application to the network, whereas the lowest layer identifies the methods of physical data flow between devices. Layering responsibilities helps to show how communication occurs from an application to the transmission media and from computer to computer. The seven layers of the OSI model are shown in Table 7–1.

| Layer | Common Name | Responsibility |
|---|---|---|
| 1 | Physical | This layer defines the physical link between devices. Voltage levels, voltage changes, physical connectors, and other characteristics are defined. The physical layer delivers the bits, 1s and 0s, across the transmission media. |
| 2 | Data Link | The data-link layer is responsible for the physical addressing, network topology, error notification, and flow control. The computer's MAC address is defined at this layer. (A *MAC, Media Access Control*, address is provided by the manufacturer of the network interface card (*NIC*) and consists of six bytes, three that identify the manufacturer and three that identify the device. *Each device has a unique MAC address*.) Data link assembles the frames of information to be sent across a network. |
| 3 | Network | The network layer is responsible for path selection, routing, and logic addressing. The computer's logical network address, such as IP or IPX, is used to perform the network functions. The network layer assembles packets of information to be transmitted over the network. |
| 4 | Transport | The transport layer is the boundary between application issues and data flow issues. This layer provides connection protocols between computers. The transport layer segments the data from the upper layers for transmission over the network. |
| 5 | Session | The session layer establishes, manages, and terminates sessions between two computers. This layer provides exception reporting for session, presentation, and application layer problems. |
| 6 | Presentation | The presentation layer ensures that information from the application layer of one computer can be understood by the application layer of another. This layer ensures that there is a common data format. |
| 7 | Application | The application layer is closest to the user. It provides network service applications. |

For data to travel from one computer to another, the OSI model layers must be traversed. For example, suppose that you open the Mozilla Web browser to connect to a Web site. The first thing you do is type in the Uniform Resource Locator (URL) of the Web site you want. The URL is sent to the presentation layer, which ensures that it is in standard format, then sends it to the session layer. The session layer establishes session information for the data, then sends it to the transport layer. The transport layer segments the data stream from the upper layers into manageable segments that can be transmitted over a communication line and then sends the segments to the network layer. The network layer applies the computer's logical addressing information to the segments, forming packets that are then sent to the data-link layer. The data-link layer applies the MAC address information to the packet information, forming frames that are then sent to the physical layer. The physical layer sends the frames one bit at a time over the transmission media. After the bits are received by another computer the steps of the whole process just described are performed in reverse order.

# Network Components

Networks today have a lot of different components. There are the computers, called **hosts**, that connect to the network, hubs, switches, routers, and other devices that are too numerous to list here. In most cases, a Linux administrator will deal with hosts, hubs, switches, and routers. Other components are beyond the scope of this course.

Components include:

- **hosts**: A host is any computer connected to the network and assigned a logical address. In most cases a logical address is the IP address, although there are other addressing schemes.
- **hub**: A connection point to a network. Hubs (Figure 7-1) are layer 1 devices, meaning that they don't care about logical or physical addressing schemes, they just transmit the data received out all connection points. A hub is just an extension to the network cable. When a PC connected to a hub transmits information all connected devices see the information. Before hubs were used, a cable was run from machine to machine to make the connection.

![](img/37f079cee226b270f2e09b37a2e4a05d_177_0.png)

**Figure 7-1** Hubs and hosts.

- **switch**: A switch (Figure 7-2) routes information based on the physical (MAC) address provided in a frame of data. Each NIC of a network has a unique MAC address. A switch will use the MAC address to route transmissions only to the host referenced. In other words, if pc1 sends a transmission intended for pc4, only pc4 will see the transmission. Switches are layer 2 devices.

![](img/37f079cee226b270f2e09b37a2e4a05d_177_1.png)

**Figure 7-2** Switched network.

- **router**: A router's (Figure 7-3) job is path determination and switching. Routers look at the packets coming in and use the logical addressing embedded within the packets to determine where the information needs to go. Without routers, large networks would not be possible. Consider that the Internet has millions of devices connected. If all these devices were to broadcast information at the same time, the network would become overwhelmed with transmissions and the data would be unusable. Routers act as stop points for broadcast data, allowing only packets that are addressed to outside locations to pass through.

# Network Topology

Topology is the structure of a network. The physical topology is how the devices are physically connected. The logical topology is how data flows from host to host within the network. The most commonly used physical topologies are bus, ring, and star (Figure 7-4).

- **Ring topology** connects the machines host-to-host, with the last machine connecting to the first.
- **Star topology** connects hosts through a central hub or switch.
- **Bus topology** connects hosts through a single cable.

![](img/37f079cee226b270f2e09b37a2e4a05d_178_0.png)

The logical topology is how communication is accomplished across the medium. The most commonly used logical topologies are broadcast and token passing.

Broadcast topology means that all data sent from one host can be received by all the other hosts on the network. Imagine being in the same room with lots of people; if everyone talks at once, it is very difficult to understand what was said. The same is true of broadcast topology; if one computer communicates at the same time as all other computers, a signal collision occurs and the computer has to rebroadcast.

Token passing topology controls the information on the medium by transmitting a token. The token is received by only one machine, which may use it to send a message or pass it to the next machine, which repeats the process. Token passing has no signal collisions.

Within a LAN, the most common logical topology is broadcast. The most common implementation of broadcast topology is on Ethernet networks. Ethernet uses carrier sense multiple access/collision detection (CSMA/CD). CSMA/CD listens for a signal on the medium, and if none is present, broadcasts the information. If a collision occurs, the system will wait a random amount of time and rebroadcast. CSMA/CD works so well that Ethernet is the most widely used of all network types.

# TCP/IP

To send information from one computer to another, protocols are needed to ensure that all participants are communicating the same. The U.S. Department of Defense (DoD) started a project in the 1960s to create a network that would work under the most precarious circumstances. The result of the DoD’s project was the TCP/IP protocol suite.

TCP/IP protocol suite encompasses all the protocols used over public networks for e-mail, file transfer, remote login, and other applications. Other protocols exist, such as IPX and Appletalk, but TCP/IP is the most widely used. TCP/IP is the protocol for the Internet.

In the application layer, TCP/IP supports protocols for network management, name management, e-mail, remote login, file transfer, and troubleshooting.
