The packages you select to install should be chosen carefully, especially if you have limited resources. Every package you install uses disk space and, once installed and running, uses RAM and CPU processing time.

Unless you chose a custom installation, the installation program will automatically choose most packages for you. If you chose a Personal Desktop installation, the installation process will select the packages that would be most useful, based on that type of installation.

You can customize the packages you use by selecting the **Select Individual Packages** option, shown in Figure 3–24. This option will allow you to select or deselect packages within a group. For example, if Games were selected, you could choose only the games you want from a list of all games.

You can also select the **Everything** option to install all packages included with the Red Hat distribution.

Some packages have dependencies on other packages. In other words, in order to install some packages, you must have the dependent packages as well. Red Hat Linux installation will check dependencies and warn you before completing the installation process. If you have any unresolved dependencies, you select the **Install packages to satisfy dependencies** option. This will install the programs to resolve dependencies automatically by adding all required packages to the list of selected packages.

Packages that you do not install during installation can be added later by running the **redhat-config-packages** command. This command will launch the Package Management Tool. This tool and packages will be discussed in more detail in Chapter 5.

You begin installation by selecting **OK** on the *Installation to Begin* dialog box (see Figure 3-25). After the packages have been selected, they will be installed on the file system. Your installation will in all likelihood complete with no problems. However, if there is a problem the details will be stored in the installation log file. This file has a copy of all messages generated during installation and may prove invaluable if you have to re-install Linux. The log file can be found in the /root/install.log directory.

A progress indicator, shown in Figure 3-26, will be displayed indicating the percentage of completion. This gives you an indication that everything is progressing correctly and not “hanging” the system.

### Boot Disk Creation

Not all new systems have a floppy disk drive; however, if your system does, it is highly recommended that you create a boot disk. The boot disk can boot your system properly using GRUB, LILO, or a third-party boot loader. If your system’s boot sector was damaged for some reason, the boot disk will allow you to start the system anyway.

The boot disk can be created after installation, or at any time, from the command line. To create a boot disk during installation, select Yes when prompted and then insert a new formatted disk in your floppy drive, as seen in Figure 3–27. All data on the disk will be erased. Some installations will prompt you for more than one disk.

### Video Card Support

Even though you are doing a text installation, you may want to run the X window system. The GUI desktop allows you to use the mouse to point-and-click the options you want. To use the GUI interface you must configure your video card.

Red Hat Linux will attempt to auto-select the video card on your system. If it does not find the correct card, you can select the Change option and then select your video card from a list, as shown in Figure 3–28.

![](img/37f079cee226b270f2e09b37a2e4a05d_81_1.png)

# FIGURE 3-28
Video card selection.

If your video card does not appear on the list, it may not be supported. If you have technical knowledge about your card, you can choose Unlisted Card and attempt to configure it by matching the card’s chipset. Most video cards are included in the list of supported cards and so you should not have any problems.

The video card configuration dialog box allows you to enter the amount of video memory installed on your video card. The documentation that came with the card or the computer system will indicate the amount of video memory.

If you choose to configure your video later, you can use the `redhat-config-xfree86` program from a command prompt. You will need to be the root user in order to make changes.

As part of the video configuration you will be asked to select a monitor (Figure 3-29). Again, Red Hat Linux installation will attempt to auto-select the monitor. If it does not select the correct monitor, you can select **Change** and then select the correct monitor from a list.

![](img/37f079cee226b270f2e09b37a2e4a05d_82_0.png)

# FIGURE 3-29
Monitor selection.

If your monitor is not on the list you can pick a **Generic** model. The Generic monitors will indicate the size, the horizontal and vertical sync ranges, and other properties for the monitor.

If you are performing a custom or server installation, you can choose to boot your Linux system into either the text or the GUI interface. The GUI is recommended for most users. The GUI closely resembles the Windows GUI and is easy to administer and use, especially for the novice user.

Some systems require a text-only environment. By using text only, you free up a lot of the computer's resources for other applications. The only disadvantage to using the text interface is that you must know the commands needed to administer the Linux operating system. Many of the commands discussed in future chapters of this book will use the text environment.

The X Customization screen, shown in Figure 3-30, allows you to select the color depth, the number of colors displayed, and the resolution, the number of pixels that are used to form the images on the screen. This screen also gives you two options to select how you will boot into the system, graphical or text. Select the **Graphical** option.

For purposes of this installation, log into Red Hat Linux with the graphical interface. The text environment is easily entered from the GUI to explore the text commands.

The Complete prompt, seen in Figure 3-31, indicates that your Red Hat Linux installation has finished all its tasks. Remove any installation media, diskette or CD, and select **OK** to automatically reboot your computer. If you did not install a boot loader you will need your boot disk to start Linux on your computer.

### Installation Validation

**Objective 1.15**

![](img/37f079cee226b270f2e09b37a2e4a05d_83_2.png)

The first time you start the Red Hat Linux system, the Setup Agent is displayed, as shown in Figure 3-32. The Setup Agent guides you through the configuration of Red Hat Linux. (Some distributions will automatically run a setup; others will not.) The Setup Agent is used to set system time and date, add users, install software, register with Red Hat, and more. If the values need to be changed later you can use configuration tools in the GUI and in the text environment to do so. These tools will be covered in Chapter 4.

The first Setup Agent screen allows creation of user accounts, shown in Figure 3-33. The root account you created during installation is the super user account. This account is too risky to use for normal login. The root account can change any values within Linux, and for that reason a user account should be created. The Setup Agent lets you enter a user name, an optional full name, and a password. Each character of the entered password will display as an asterisk.
