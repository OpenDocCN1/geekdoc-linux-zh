Before continuing with the discussion on variables, look at the syntax of the bash command `date`. The date command is used to display the date and time. For example, to see the current date and time from the command prompt, type the date and press Enter. The following is displayed:

```
[root@localhost root]# date
Tue Oct 7 00:26:38 CDT 2003
[root@localhost root]#
```

The `date` command has several options and a format entry. The syntax for date is `date [options] [+format]`, where `options` is one of the available options and `format` is a series of format symbols that control what part of a date is displayed and how. Some of the available format values are:

- `%a` Abbreviated weekday name (Sat, Sun, ...)
- `%A` Full weekday name (Saturday, Sunday, ...)
- `%b` Abbreviated month name (Jan, Feb, ...)
- `%B` Full month name (January, February, ...)
- `%d` Day of the month (01..31)
- `%D` Date (mm/dd/yy)
- `%F` Date (yyyy-mm-dd)
- `%H` Hour (00..23)
- `%I` Hour (01..12)
- `%m` Month (01..12)
- `%M` Minute (00..59)
- `%p` Upper case AM or PM
- `%Y` Year (2003...)

To display the date as 2003October07 use the format `+%Y%m%d`. Try typing the date command with the format described:

```
date +Y+B+d
```

Now that the date command is explained, use it in a backup script. For example, to back up the /home directory to a file whose name includes the date and time of the backup, try the following script:

```bash
#!/bin/bash
TODAY=$(date + %Y%m%d%H%M)
BKFILE=/var/backup-$TODAY.tgz
tar -czvf $BKFILE /home
```

The variable **TODAY** is assigned the results of the `date +%Y%m%d%H%M` command. The `$(command)` format runs the command inside the parentheses and sends the results as output, in this case as the value of the **TODAY**= assignment. The value of **TODAY** should look similar to 200310080113.

The variable **BKFILE** will have a value of `/var/backup-200310080113.tgz`.

The `tar` command will archive the `/home` directory to the file `/var/backup-200310080113.tgz` in a compressed format.

# Conditions

Scripts can control the flow of processing in a number of ways. One of the most commonly used methods is conditional statements. A conditional statement takes the form of an `if` or a `case` statement, and asks a question that can be answered yes (true) or no (false). Conditional statements give shell scripts a powerful tool to accomplish tasks.

### The if Statement

The syntax of an *if* statement is **if [***expression***]; then *statement* [***else statement***] ***fi*** where *expression* is a *Boolean* expression and *statement* is the shell command to perform. Notice the end of the command is *fi*. Some command structures end with the same word they start with, spelled backward.

The *bash* shell has several conditional expressions that can be used. Conditional expressions can be used to compare strings (words), numbers, or files. Some of the most commonly used are:

- `=` Are two strings equal?
- `<` Is the first string less than the second string?
- `>` Is the first string greater than the second string?
- `!=` Is the first string not equal to the second string?
- `-eq` Is the first arithmetic value equal to the second arithmetic value?
- `-ne` Is the first arithmetic value not equal to the second arithmetic value?
- `-lt` Is the first arithmetic value less than the second arithmetic value?
- `-le` Is the first arithmetic value less than or equal to the second arithmetic value?
- `-gt` Is the first arithmetic value greater than the second arithmetic value?
- `-ge` Is the first arithmetic value greater than or equal to the second arithmetic value?

The simplest *if* command compares two values and then does an action. For example, if you wanted to accept a name from the command line and display either Good Morning or Good Afternoon and the name, you could use the following script:

```bash
#!/bin/bash
if [ $(date + %H) -lt 12 ]; then
    echo Good Morning $1
else
    echo Good Afternoon $1
fi
```

The *if* expression is enclosed in brackets [ ] and followed by a semicolon. This statement says if the current hour, according to the computer, is less than 12 then display Good Morning. If the expression is not true, then display Good Afternoon. The sample run is displayed in Figure 6–16.

```bash

[root@Styx root]# cat if_test

    echo Good Morning $1
else
    echo Good Afternoon $1

[root@Styx root]# ./if_test Jeff
Good Morning Jeff
[root@Styx root]#
```

# ADMINISTRATIVE TASKS

### The case Statement

Another type of conditional statement is the case statement. The syntax of the case statement is **case word in <pattern | pattern | ...> statement ;; ... esac** where word is a value to be matched in the list of patterns, pattern is a list of values to be matched against, and statement is the list of shell commands to be executed.

The case statement performs a series of commands based on a value match in a list. For example, if you wanted to display the number of days in a month, you could use a case statement as follows:

```bash
#!/bin/bash
case $1 in
January|March|May|July|August|October|December)
    echo $1 has 31 days;;
April|June|September|November)
    echo $1 has 30 days;;
February)
    # The let statement starts an arithmetic expression
    let VAL1=$(date + %Y)%4
    if [ $VAL1 -eq 0 ]; then
        echo $1 has 29 days
    else
        echo $1 has 28 days
    fi;;
esac
```

This is the most complicated script yet and deserves a more detailed explanation. The overall case structure begins with the keyword **case** and ends with **esac** (case spelled backwards).

Commands within the case structure are indented. This is the convention and should be followed. Indenting commands within structures makes the script much more readable and easier to follow. The same indentation was applied to the if structure as well.

The second line, `case $1 in`, tells the case conditional that the value to be evaluated is taken from the first command line argument and is evaluated in the list that follows.

The third, fifth, and seventh lines provide the values to be evaluated for each set of shell statements to be executed. In this case, if the value of $1 is found in a list line, then the statement(s) following the list are executed. Each list terminates with a closing parenthesis.

The statements following the list lines are shell command lines. The last command to be executed is terminated with two semicolons. The semicolons indicate that this is the end of the list/command entry.

The line `# The let statement starts an arithmetic expression` is a comment line. Comment lines begin with a pound sign (#). These statements are ignored by the shell script. Comments should be used to document what is happening in a script. Comments should be concise and meaningful.

The line `let VAL1=$(date + %Y)%4` is an arithmetic statement. The `$(date + %Y)` should be familiar; it returns the year in the format yyyy. The % before the 4 is an arithmetic operator that says to do remainder division. This statement says to take the year and divide it by 4, giving the remainder. If you divide the year by 4 and get 0 as a reminder, that year is a leap year.

Conditional statements are necessary to control the flow of logic through a script. Another useful thing that a script does is to allow code to be repeated. To repeat code you need a loop construct.

# Using Loops

If you had a list of one thousand names and your job was to assign an account for all the names on the list, this would get tedious in a hurry. So what's the solution? Loops! A loop is a structure in a script or program that allows conditional repeating of code. The structures supported by the bash scripting language are for, while, and until. Each structure has a different purpose.

# The for Loop

A `for` loop lets you execute a specific group of script statements a set number of times. The bash script for is a little different from that in other programming languages in that it lets you iterate a series of words within a string.

Consider the following for loop example.

```bash
for I in $(ls); do
    echo "$item;" $I
done
```

This for loop uses the variable `I` to contain each value of the list provided. The list provided is identified after the `in` statement and is a command to list the directory, `$(ls)`. The variable takes on the value of each value in the list and the next line, `echo "$item;" $I`, prints each filename in the directory.

For loops can be very useful. Take the "days in a month" case example from The case Statement section earlier in this chapter and use a for loop instead of a command-line argument to provide a value for the case. For example:

```bash
#!/bin/bash

for MONTH in January February March April May June July August September October November December;
do
    case $MONTH in
        January|March|May|July|August|October|December)
            echo "$MONTH has 31 days;;
        April|June|September|November)
            echo "$MONTH has 30 days;;
        February)
            let VAL1=$(date +%Y)%4
            if [ $VAL1 -eq 0 ]; then
                echo "$MONTH has 29 days
            else
                echo "$MONTH has 28 days
            fi;;
    esac
done
```

This is a case statement inside a for loop. Based on the value of `MONTH`, different numbers of days will be displayed on the screen. The resulting output would be:

```
January has 31 days
February has 28 days
March has 31 days
April has 30 days
May has 31 days
June has 30 days
July has 31 days
```
