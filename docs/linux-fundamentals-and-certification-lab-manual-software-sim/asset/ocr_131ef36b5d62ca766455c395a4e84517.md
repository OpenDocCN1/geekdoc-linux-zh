# Table 11-1  
Schedule fields.

MAILTO to send results of tasks, the home directory of the cron owner, and the schedule of when jobs are to be accomplished.

The schedule lines are space- or tab-separated fields of time-related information and the programs to run. Table 11-1 describes the schedule fields.

| Field | Value | Description |
| :--- | :--- | :--- |
| Minute | 0-59 | The minute of the hour that the command will be executed. |
| Hour | 0-23 | The hour of the day the command will be executed. |
| Day | 1-31 | The day of the month the command will be executed. |
| Month | 1-12 | The month of the year the command will be executed. |
| Weekday | 0-6 | The day of the week the command will be executed. Sunday = 0, Monday = 1, ... |

In the crontab file, the first line under run-parts defines the hourly cron jobs to be run at one minute after the hour. The line is interpreted as:

| Minute | Hour | Day | Month | Weekday |
| :--- | :--- | :--- | :--- | :--- |
| 01 | * | * | * | * |
| One minute after the hour | Any hour | Any day | Any month | Any weekday |

The programs to be run hourly are contained in the /etc/cron.hourly directory.

The third line is interpreted as:

| Minute | Hour | Day | Month | Weekday |
| :--- | :--- | :--- | :--- | :--- |
| 22 | 4 | * | * | * |
| Twenty-two minutes after the hour | Four a.m. (24 hour clock) | Any day | Any month | Only on Sunday |

The programs to be run are contained in the /etc/cron.weekly directory.

The remaining lines are interpreted in the same way. Programs to be executed are located in the /etc/cron.X directories, where X is hourly, daily, weekly, or monthly. Any of the time/date values can contain an asterisk indicating any or all, or a comma-delimited list. For example, if a cron job needed to be done at five minutes after two on Monday, Wednesday, and Friday, the line would be

*05 2 * * 1,3,5 command*
