ISDN. Integrated Services Digital Network, an international communications standard used for sending voice, video, and data over digital telephone lines.

ISO. Short for International Organization for Standardization. ISO is not an acronym, but is derived from the Greek word "iso," which means equal. ISO is composed of national standards bodies from over 75 countries. ISO defined the Open Systems Interconnection (OSI) model for network design.

ISO 9660. A file system standard for CD-ROMs that allows you to read the same CD-ROM on most major operating system platforms. It is also called High Sierra.

KDE. A GUI desktop environment with a panel, a desktop, system icons, and a graphical file manager.

Kerberos. A secure system used for providing network authentication services.

Kernel. The core of an operating system. The kernel is the part of the operating system that loads first and remains in memory during operation. It is typically responsible for memory management, process management, and disk management.

Kernel Module. Provides for functionality in the Linux kernel. This gives it basic functionality for using the keyboard, the mouse, and other devices.

LDAP. Short for Lightweight Directory Access Protocol, a centralized hierarchical database used for authentication.

Left-Click. Clicking an object on a desktop with the left mouse button. Typically, left-clicking an object selects the object.

LILO. The Linux Loader boot loader.

Linus Torvalds. The main developer of the Linux kernel.

Linux. A free operating system kernel, the core of the Linux operating system.

Linux Distribution. An operating system based on the Linux kernel.

LKM. Loadable Kernel Module, loaded dynamically by the Linux kernel.

Log. A chronological listing of events stored by programs in a file. Logs are used to track system and program problems within the operating system.

LVM. Logical Volume Management is a partitioning method available to the Linux 2.4 kernel that enables you to create logical volumes out of the physical storage while the system is still running.

MAC. MAC, Media Access Control, is a 48-bit value, divided into two 24-bit values, that identifies a host's adapter. The first 24 bits define the manufacturer of the adapter, and the second 24 bits identify the local host.

man. A Linux command that formats and displays the online manual pages.

Mandrake. A distribution of the Linux operating system.

Master boot record. The first sector on a hard disk. It contains the partition table for the disk.

MD5. A one-way hashing function that creates a unique number and associates it with a message. This number can be generated on the receiving end to ensure that the message has not been changed.

Mouse. A pointing device used in a GUI environment to control the movement of a pointer on a screen.

Multiprocessing. This term describes an operating system that supports more than one process at the same time.

Multiuser. This term refers to an operating system that supports two or more simultaneous users.

NAT. Short for Network Address Translation, an Internet standard that enables a local area network (LAN) to use one set of IP addresses for internal traffic and a second set of addresses for external traffic.
