Every bootable partition is listed, including partitions used by other operating systems. If you used GRUB for your boot loader, the label will be **Red Hat Linux**. If you used LILO as your boot loader, the label will be **linux**. To change the label displayed, select the label and then select the **Edit** button.

After you select the boot loader you want to use, you must decide where you want to install it (Figure 3-16). You can install the boot loader in one of two places—the master boot record (MBR) or the first sector of your boot partition.

MBR is the recommended install location for the boot loader. The MBR is a special area on your hard disk that is automatically loaded by your computer's BIOS.

The first sector of your boot partition is recommended if you already have another boot loader on your system. In that case, the other boot loader will take control first. You can configure that boot loader to start GRUB or LILO, which will then boot Linux.

Alternative boot loaders are available. You can use a boot diskette, LOADLIN, SYSLINUX, or a commercial boot loader. You will be prompted to create a boot diskette at the end of the installation program. LOADLIN is a simple DOS-based utility that loads the Linux kernel into memory from DOS. SYSLINUX is a boot loader that runs under DOS. A SYSLINUX floppy disk can be manipulated using standard DOS tools. Commercial programs include System Commander and Partition Magic. These are able to boot Linux, but still require that GRUB or LILO be installed in your Linux partition.

# Basic Networking

If you have a network device installed on your system, you will see the Network Configuration screen. Networking must be configured to access network resources.

By far the most common network interface card (NIC) you will encounter is the Ethernet card. Today's Ethernet devices provide access speeds of 10, 100, or 1000 Mbps (megabits per second).

To use a NIC, the operating system must have a protocol that allows other network devices to converse with it. The most common network protocol is Transmission Control Protocol/Internet Protocol (TCP/IP). TCP/IP is a suite of protocols used to do a variety of jobs. It includes protocols such as Domain Name Service (DNS), File Transmission Protocol (FTP), Telnet, and others.
