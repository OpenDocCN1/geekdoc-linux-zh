# ### INSTALLING LINUX

By now you should know much about the Linux operating system installation, including which distribution set, which kernel version, which installation type, what type of hardware you are going to use, and what software packages will be installed. In this chapter you will install the Linux operating system.

# ### OBTAIN A LINUX DISTRIBUTION

Regardless of what type of boot source you use, you have to have a Linux distribution set. You have three choices on how to obtain your distribution set.

+   *   You can purchase a boxed set from a retailer. The advantages of purchasing your Linux distribution include the following:
    *   **Installation support.** If you need help during the installation process, you can e-mail or call a technical support line and ask questions. The vendor will often supply you with updates, news, and other useful services concerning their distribution if you also register with them.
    *   **Source disk.** The boxed set will include CDs, an installation guide, and often boot floppies. These are tested and ready to use on your system.
*   You can download a distribution from a vendor. Before you attempt this, be aware that the distribution files are very large. Each of up to six installation disk files will be from 400 to over 600 MB. This is usually too large to download with a dial-up connection. If you have a fast broadband connection, such as DSL or a cable modem, you can download the files.
