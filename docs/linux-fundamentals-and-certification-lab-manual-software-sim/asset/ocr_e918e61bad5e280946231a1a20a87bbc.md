# # LINUX INSTALLATION REQUIREMENTS

| IRQ Number | Typical Use | Description |
| :--- | :--- | :--- |
| 0 | System timer | Used for the internal system timer. Not available for other devices. |
| 1 | Keyboard | Used for the keyboard. Not available for other devices. |
| 2 | Cascade interrupt for IRQs 8–15 | Cascades the second interrupt controller to the first. |
| 3 | Serial port 2 (COM2) | Used for the second and fourth serial ports. PCs have four serial ports available. The first and third share an IRQ, as do the second and fourth. |
| 4 | Serial port 1 (COM1) | Used for the first and third serial ports. |
| 5 | Sound card | Usually used by the sound card. Some adapters can be configured to use selected IRQs via jumpers or dip switches. See Figure 2–5. |
| 6 | Floppy disk controller | Used for the floppy disk controller. |
| 7 | First parallel port (PAR1) | Usually used for the printer port if a printer is attached. |
| 8 | Real-time clock | Reserved for the real-time clock. Not available for other devices. |
| 9 | Open interrupt | Available for devices that do not have a reserved IRQ. |
| 10 | Open interrupt | Available for devices that do not have a reserved IRQ. |
| 11 | Open interrupt | Available for devices that do not have a reserved IRQ. |
| 12 | PS/2 mouse | Used for the PS/2 mouse if attached. |
| 13 | Math coprocessor | Use exclusively for the internal signaling for the floating point unit. |
| 14 | Primary IDE channel | Used by the primary IDE controller if an IDE device is attached. |
| 15 | Secondary IDE channel | Used by the secondary IDE controller if an IDE device is attached. |

Windows Device Manager is available from the Control Panel. To access the Device Manager, do the following steps in Windows:

+   1.  Select **Start** from the Taskbar.
2.  Select **Settings** from the menu.
3.  Select **Control Panel** from the submenu.
4.  Select **System** from the icon list.
5.  Select the **Hardware** tab.
6.  Select the Device Manager button.

> **NOTE**
Different Windows versions may have a slightly different list of options.

Hardware devices can be viewed by type (the default), by connection (USB, IDE, etc.), or by resource (DMA, IRP, I/O, memory). By drilling down into the device list, you can select properties on individual devices and examine the resources used by each.

If you are assembling a new machine, most settings will be assigned automatically. The only settings you will likely set are those for the IDE or SCSI devices you install and, possibly, the system board.
