+   • **Make sure that any static charge you have is dissipated.** Use a wrist strap and make sure it is grounded properly. Always touch the metal on the power supply to bleed off any residual charge.
• **Never force a connection.** Many of the connectors on a computer are designed as a group of small metal pins. These pins are very easy to bend or break, often without realizing it.
• **Never disconnect a cable by pulling the wire.** Most computer connectors are delicate and will separate easily. Pulling the wires can separate them from the connector.
• **Label everything.** Until you feel proficient in computer repair, label everything. Connectors are usually keyed to allow connections in only the proper direction, but a determined individual can force them to connect anyway. Hard cables in a computer system look the same. Labeling will save you time later on.
• **Read the manual.** Most systems have a service manual available. Read the directions and follow them.

# ### Hard Drive Problems

On most Linux systems the hard disk will generally run flawlessly beyond its rated life. However, errors can always occur. The fsck program will take care of most problems.
If a catastrophic failure occurs with the hard drive, the hard drive should be replaced and the data restored from backup. Replacing a hard drive is the same procedure as installing a second hard drive, covered in Chapter 2.

**EIDE/ATA Hard Drive Problems** Most personal computers use EIDE/ATA hard drives. After a hard drive is installed and functioning, the major problem encountered is a performance problem. If you have a new system that is designed to work with the Linux operating system, your hard drive may be optimized for the system. However, not all systems are designed for Linux and not all Linux distributions are optimized for all hard drives. Moreover, Linux distributors usually opt for stability over performance, so the hard disk may not be performing near its optimum performance.
The Linux operating system provides the hdparm tool to both test and to improve the performance of hard drives; however, **hdparm can cause unexpected data corruption. Use it at your own risk.** Make sure you back up your system before attempting any hard disk changes. The syntax of the hdparm command is **hdparm [flags] [device]**, where device is a hard drive device name, such as /dev/had, and flags are from zero to many options. Some of the most common include:

+   • **no flags** If no flags are given, the -acdgmrrrw flags are assumed. Running the hdparm command with no flags shows that the hard drive is set to safe values. These values help ensure that the Linux operating system runs with the widest range of hard drives.
