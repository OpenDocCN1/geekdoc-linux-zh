
To display the next page, type the letter **f**. To display the previous page, type the letter **b**. To exit the listing, type the letter **q**.

- **grep**: Search a file or standard input for lines containing a match to a given pattern. Even though grep expects to search text files, it can search binary files as well. The basic syntax of grep is `grep "expression" file` where expression is the text to be found, and file is the text file to be searched.

For example, if a user wanted to know what the default login runlevel is, the user could view the inittab file. After using one of the view commands to display the file, the user would then have to search the file to find the right line. (The runlevel in the inittab file is found in the line `id:X:initdefault:`, where X is the runlevel.) A faster method to find the line and what the runlevel is would be to search the file for the text using grep. For example, to find what the runlevel is, a user could search for any line that starts with id.

```
[jsmith@Styx jsmith]$ grep "id" /etc/inittab
id:5:initdefault:
[jsmith@Styx jsmith]$
```

The grep command can use input piped from another command as well. For example, a user could use the following command to find all commands with the word “restore” in them:

```
[jsmith@Styx sbin]$ ls | grep "restore"
iptables-restore
restore
restore.static
rrestore
xrestore.static
vgcfgrestore
[jsmith@Styx sbin]$
```

Notice, all lines that contain the word “restore” are returned, regardless of where it is contained in the line.

If the user wanted to know how many entries would be returned by the above command, the output could be piped to the wc command. For example:

```
[jsmith@Styx sbin]$ ls | grep "restore" | wc -w
6
[jsmith@Styx sbin]$
```

The ls command sends its results to grep, which filters out only those lines that have “restore”. It then sends its results to the wc command, which counts how many words are returned.

Some of the options available are as follows:

- **-a, --text**: This option allows grep to process a binary file (a command or program) as if it were a text file.
- **-c, --count**: Suppress the normal output and just print the number of matches found.
- **-h, --no-filename**: Suppress the prefixing of filenames on output when multiple files are searched.
- **-i, --ignore-case**: Ignore the case of the characters in the pattern.
- **-l, --files-with-matches**: Suppress normal output and point to the name of each input file that would have normally been printed. Scanning stops on the first match.

The grep command supports regular expressions. A regular expression is a pattern that describes a set of strings. Regular expressions are constructed analogously to arithmetic expressions, by using various operators to combine smaller expressions. Think of regular expressions as being wildcards on steroids. For more information on grep, read the man pages. Some of the special characters used in grep are described as follows:

- `^` Match the expression at the start of a line. For example:
  `[jsmith@Styx etc]$ ls | grep "^ns"`
  nsd.conf
  nsswitch.conf
- `$` Match the expression at the end of the line. For example:
  `[jsmith@Styx etc]$ ls | grep "conf$"`
  aep.conf
  aeplog.conf
  cdrecord.conf
- `[]` Match any of the enclosed characters. Use a hyphen for a range, as in `[a-z]`. For example:
  `[jsmith@Styx etc]$ ls | grep "[0-9]"`
  a2ps.cfg
  a2ps-site.cfg
  gnome-vfs-2.0
  gtk-2.0
  iproute2
  krb5.conf
  pbm2ppa.conf
  pnm2ppa.conf
  rc0.d
  rc1.d
  rc2.d
  rc3.d
  rc4.d
  rc5.d
  rc6.d
  w3m
  X11

The special characters may need to be included as search items. For example, a user may need to look for a `^` within a file. Using the caret is difficult because the caret is a special character that tells grep to search the start of the line for the expression. To allow the expression to contain a caret, use the escape character (`\`). The expression to find a `^` within an expression would be `\\^`.

## USING VI AND OTHER EDITORS

**Objective 2.15** If you are using the CLI, you have to learn to use a text editor to edit text files. Most Linux and Unix operating systems use a program called vi (pronounced “vee-eye,” as two separate letters). The vi program has been around nearly as long as Unix and continues to be the most widely used text editor. vi is short for visual editor. In Linux, vi shows a window of 24 lines of text from a file. The vi text editor lets you add, change, and delete text only. vi does not have any formatting capabilities such as bold, underline, or line centering. There are other text editors, but mostly they emulate vi and usually offer a few improvements. The Red Hat Linux distribution uses vim (Vi Improved), which is open source and an improvement over vi (Figure 5–5).

GUI editors are similar to any other GUI-based program. They have a menu to select major options, a toolbar for shortcut commands, and support for keyboard and mouse input. GUI editors work within a window in the GUI environment. Figure 5–6 shows the GEdit program for the Gnome GUI environment.

## Editing a File with vi

vi has two modes of operation, command mode and input mode. When you first start vi you are in command mode. From command mode you can move around the screen, enter commands to save the file, search the content of the file, or edit the text in the file. To type text into the file you enter input mode. To exit input mode, press the Esc key.

To start vim you can just type vi and press Enter. If you are creating a new file, this will open the editor and provide a blank window to start. To edit an existing file or to create a new file, type vi *filename*. For basic editing, a few commands are needed.

**Display Help** with the F1 key or type **:help** and then press Enter. The colon (:) is used to enter command mode.

**Move around** the screen with the following keys:

- **k** moves up one line
- **j** moves down one line
- **l** moves right one character
- **h** moves left one character
- **0** moves to the beginning of the line
- **$** moves to the end of a line
- **G** moves to the end of the file
- **w** moves forward one word
- **b** moves back one word
- **<ctrl>f** moves down one screen
- **<ctrl>b** moves up one screen

**Exit vi** with the :q or :q! command. The :q command exits the current file, and :q! forces exit of the current file, whether or not the file has been saved.

**Input mode** commands are used to enter text in a file.

- **a** appends text to the right of the cursor
- **A** appends text at the end of the line
- **i** inserts text at the current cursor position
- **I** inserts text at the beginning of the line
- **o** inserts text starting on a blank line below the current cursor position
- **O** inserts text starting on a blank line above the current cursor position

**Save file** with :w or :w!. The :w command saves the file, whereas :w! saves the file even if the file is read only. If the text you’ve typed is not yet associated with a file-name, type :w *newfilename* where *newfilename* is the name of the file to be created on disk.

**Delete text** with x or X.

- **x** deletes text under the cursor
- **X** deletes text to the left of the cursor

To start typing in a new file, type i to enter input mode and start typing. Anything you type after you are in input mode is displayed on the screen and can be saved with the file. While in input mode press Enter to type text on the next line. Before moving around the screen in input mode, you should first type esc to exit input mode.

## Searching Through a File with vi

If you want to find a specific string of text in the file you are editing, you can type /pattern where pattern is the string you are looking for. /pattern looks forward in the file, and ?pattern looks backward in the file. To repeat the search forward through the file, type the letter n, and to repeat the search backward through the file, type the letter N.

## Moving Lines of Text in a File with vi

To move a single line, position the cursor on the line to be moved and type dd to delete the line. Position the cursor where you want the line to be and type P. You can move more than one line by prefixing the dd command with the number of lines to be deleted.

## Copying Lines of Text in a File with vi

To copy a single line of text, position the cursor on the line to be copied and press the letter Y. Y copies the current line to the working buffer of vi. Position the cursor where you want the line to be and type the letter P. To copy multiple lines, prefix the Y command with the number of lines from the cursor to be copied.

**Settings** Settings allow you to change the way vi works. For example, by default vi does not display line numbers. To set vi to display line numbers, type :set number. To view other set commands, type :help set from vi command mode.
