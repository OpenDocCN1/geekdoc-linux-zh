# FIREWALLS

A firewall is a core component of network security. A firewall provides packet filtering, and can also provide a circuit-level gateway and an application-level gateway. Firewalls are typically located at the boundary of a network. All incoming and outgoing traffic should be routed through the firewall.

All traffic through a network is sent in the form of packets. Each packet contains a body and a header. The header has the source IP address, destination IP address, and other information. Packet filtering looks at the header, then decides if the packet is denied or allowed to pass through based on the IP address, port, or protocol.

A circuit-level gateway validates connections before allowing data to be exchanged. This determines if the connection is valid based on the destination, source, time of day, and other values. This enhances packet filtering.

An application-level gateway acts as a proxy for applications. All data exchange with the remote system is done by proxy, rendering the local computer invisible to the remote computer. The gateway performs detailed logging of traffic and monitoring of events on the host system. Application-level gateways are regarded as the most secure type of firewall.

All firewalls, regardless of type, provide inspection of incoming and outgoing data before it is sent on to the destination. Besides filtering content, firewalls can also provide Network Address Translation (NAT). NAT hides the internal IP addresses behind the firewall and provides IP addresses to the outside network.

Firewall technology is built into the Linux kernel. It is provided through netfilter (see www.netfilter.org) and iptables. The netfilter subsystem provides stateful or stateless packet filtering as well as NAT and IP masquerading services.

# IPTABLES

![](bbox=[0.18, 0.53, 0.26, 0.55])

The iptables tool inserts and deletes rules from the kernel’s packet filtering table. A computer with a single network connection can use iptables to configure packet filtering as a personal firewall. A computer with two connections, one connected to the outside (Internet) and one connected to the inside (intranet), can use iptables to configure a network firewall (Figure 12–16).

![](bbox=[0.27, 0.65, 0.86, 0.83])

iptables is initially configured with three lists of rules called chains. These are INPUT, OUTPUT, and FORWARD (Figure 12–17). A chain is a list of packet rules. If a packet matches a rule, the action indicated by the rule is performed. Packets that don’t match a rule are dropped.
