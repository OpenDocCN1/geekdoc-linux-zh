+   - **\-o or \-all**    Loads all matching modules.
- **\-c or \-showconfig**    Shows the current configuration.
- **\-k or \-autoclean**    Sets the autoclean flag. This causes the Linux operating system to automatically remove the module if it is not being used.
- **\-n or \-show**    Shows what would be done with the command, but does not actually execute the command.
- **\-r or \-remove**    Removes module stacks or does an autoclean. Which action is performed, remove or autoclean, depends on whether a module name was supplied. No module name indicates an autoclean.
- **\-v or \-verbose**    Prints a verbose listing of commands as they are executed.

To insert the module e100 with the autoclean option you would execute the command:

```
modprobe --autoclean eth0
```

+   - **insmod**    This command is used to insert modules. Using this command alone will require you to determine the dependencies of the module you want and load them first. The modprobe command does this automatically. A few common options are listed below. For a complete list of options, use the **man insmod** command.
  - **\-f or \-force**    This option attempts to load the module even if it was compiled for another version of the kernel. The \-f option only overrides the kernel check. This is useful when you are attempting to load a commercial binary module.
  - **\-k or \-autoclean**    Sets the autoclean flag. This works the same as in modprobe.
  - **\-p or \-probe**    Tests to see if the module could be successfully loaded.
- **rmmod**    This command removes modules. The modprobe \-\-remove command can also be used. The most commonly used options are listed below. For a complete list, use the man rmmod command.
  - **\-a or \-all**    This causes an autoclean. This removes unused modules.
  - **\-r or \-stacks**    Removes a module stack. This removes a group of modules.
- **lsmod**    The lsmod (Figure 9\-27) command is used to list all loaded modules. It lists the loaded module name, the size, and the number of times used.
