To add a print queue to a CUPS printer, use the following procedure:

+   1. From the command line, type **printconf** or **redhat-config-printer** and press **Enter**. If you are using a GUI screen, the GUI program will be displayed. The **Printer Configuration** (Figure 9-19) screen is displayed.

# FIGURE 9-19

![](bbox=[0.31, 0.45, 0.87, 0.67])

+   2. The **Add a new print queue** welcome (Figure 9-20) screen is displayed. The welcome screen includes a message reminding you to click **Apply** on the last screen to save your settings.
