# ■ INTRODUCTION TO THE DESKTOP

As a Linux administrator, you will probably find that the command-line interface (CLI) is where you spend most of your time working. The command line is fast and offers the most control over the operating system.

So, why do you need a graphical user interface (GUI)? In most cases, a server doesn’t need a GUI. After all, a GUI is a way for a user to interact with the operating system, and most users do not log onto a server locally. On a server, a GUI is a program that requires resources, RAM, and disk space that could be better utilized by other services the server provides.

Non-server implementations of Linux usually offer, and often require, a GUI environment. Some programs are designed to work only with a GUI. A drawing program, for example, by its very nature is designed to work only with a GUI.

An administrator can usually accomplish all their work from the CLI, but other users generally accomplish their tasks through the GUI. A GUI application’s workspace is called the *desktop*.

The desktop provides organization to GUI applications. Desktops are organized through the use of windows, icons, and menus. The two most prevalent desktop environments for Linux are GNOME and KDE.

# CLI vs. GUI

Linux users fit into two categories, administrators and non-administrators. As you can see, non-administrator defines a very large group of users. Non-administrator users can be anyone from a video game player to a payroll clerk in a business. Most administrators use the CLI and most non-administrators use the GUI. Both environments are needed.

Several characteristics can be compared between the two environments. This chapter looks at the interface, speed, overhead, availability, learning curve, and usefulness.

**Interface** The CLI is a very dull interface. It offers only text output, usually white text on a black background. It requires the user to memorize lots of commands as well as to know the location of applications and configuration files in the hierarchical file structure.

The GUI interface is a colorful, pleasant display. It offers a point-and-click environment that enables a user to point with a mouse and then click menu options, program icons, and other tools displayed on the desktop. It requires almost no memorization of individual commands; rather the entries can be found through menu entries. GUI tools, called file managers, enable a user to graphically view the hierarchical file structure to find files within the system instead of having to know where files are located.
