A suspended process can be either continued or killed. To continue a suspended process, use the **fg** or **bg** command. The fg command continues a process in the foreground. > To explicitly start a process in the background, add an ampersand (&) to the end of the command line. For example, to start a program called parse_names in the background, use the **parse_names &** command.

In the example above, instead of continuing the **forever_loop** process, you will probably terminate it instead. You can usually interrupt a process running in the foreground using the Ctrl+C (break) key combination, but that doesn’t work with a process running in the background. A background process must be terminated with the **kill** command.

The kill command sends a signal to a process. The syntax of the kill command is **kill [signal] pid**, where **signal** is a number or name indicating what to do with the process and **pid** is the process ID.

The signal can tell the process to terminate, terminate immediately, reread the configuration files, or perform other actions. To see a complete list of signal options use the **man 7 signal** command. The most commonly used signals are 1 (SIGHUP), 9 (SIGKILL), and 15 (SIGTERM).

**SIGHUP** tells the process to hang up, reread its associated configuration files, and restart. This signal is usually used with services that are running as daemons. Most other applications will ignore this signal. For example, to send the SIGHUP signal to the 10841 PID, use the **kill -HUP or kill -1 10841** command.

**SIGKILL** sends an immediate termination signal. This tells the process to immediately terminate, without closing files or performing any other normal housekeeping routines. SIGKILL should only be used if absolutely necessary. The **forever_loop** script can easily be killed with the **SIGKILL** signal because it does not have any associated data files that need to be maintained. To kill the **forever_loop** use the **kill -kill 15205 or kill -9 15205** command. (The PID number is from the previous listing.)

**SIGTERM** sends a signal for a normal program termination. This is the default action of the **kill** command. If the program has any open files it has the chance to close them before terminating the process. To kill the **forever_loop** gracefully, use the **kill -term 15205 or kill -15 15205** command.
