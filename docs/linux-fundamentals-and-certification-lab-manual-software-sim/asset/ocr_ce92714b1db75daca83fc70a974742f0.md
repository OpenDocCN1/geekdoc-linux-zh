# Creating Directories

Creating directories is a common task. Users typically create directories to organize their personal files within their home directories. To create a directory, use the **mkdir** command. There are a few options that can be used with the **mkdir** command and they can be discovered by using the **man mkdir** command.

To create a directory, use the mkdir command with a directory name. Use an absolute or relative pathname when creating a directory. For example, if the current directory is /home/jsmith and jsmith wants to create a directory to contain downloaded files, use the *mkdir downloads* (relative pathname) or the **mkdir /home/jsmith/downloads** (absolute pathname) command.

# Removing Directories

To remove a directory, use the remove (**rm**) command. The rm command can be used to remove files or directories. Even an empty directory has two hidden entries. The . and .. symbols that are used as shortcuts are actual entries in the directory. (Use **ls -a** to see hidden files.) To remove a directory, the files in the directory must be removed as well. This can be accomplished with the recursive (-r) option. The recursive option removes the contents of a directory before the directory is removed. The current directory cannot be the directory to be removed.

If the current directory is /home/jsmith and the directory /home/jsmith/downloads is to be removed, type either **rm -r downloads** (relative pathname) or **rm -r /home/jsmith/downloads** (absolute pathname).

# MOUNTING FILE SYSTEMS

![](bbox=[0.06, 0.8, 0.27, 0.92])

Before you can use any file system, it must be mounted to a directory. For example, the root file system is mounted to the / directory at startup. All storage devices must be mounted before use. The floppy drive must be mounted, usually to the /mnt/floppy directory, before it can be accessed. The system automatically mounts file systems on your hard drive at boot time.

The **mount** command is used to mount file systems. At boot time the command **mount -av** is executed. The -a option causes all file systems mentioned in the */etc/fstab* file, shown in Figure 4-25, to be mounted. File systems can be mounted at boot time by entering the information into the fstab file. File systems can also be mounted using the mount command after login.
