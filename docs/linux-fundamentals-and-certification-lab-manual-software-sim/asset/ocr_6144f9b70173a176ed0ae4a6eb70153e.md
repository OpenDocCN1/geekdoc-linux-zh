having. The Linux community is founded on free and open access and discussion. Several sources for finding help are available.

+   - **Linux Documentation Project (LDP)** LDP is a group of volunteers who provide documentation for Linux. Documentation includes man pages, guides, HOWTOs, and FAQs.
	- **Guides** A guide is a longer document on a broader topic, not just a set of instructions on how to perform one task. For example, the Network Administration Guide contains information on the very broad subject of networking.
	- **HOWTO** A HOWTO contains information about how to accomplish a single task. For example, a HOWTO may cover how to set up NFS.
	- **man page** A manual page is a standard form of the help that is available on most Linux distributions. The man page contains information about a single command. For example, if you want to know what the ls command is, you can type `man ls` to view information about the command.
	- **FAQs** An FAQ (Frequently Asked Questions) is a list of questions and answers about a wide range of subjects. An FAQ could deal with simple questions such as "How do you pronounce Linux?" or much broader questions such as "How do you print from Linux?" The answers can be anything from a simple definition to a mini-howto on the subject in question.

+   - **Web resources** Hundreds of Web sites are devoted to Linux. These sites have an abundance of information; all you have to do is find it. To find information on any Linux subject, get proficient with a Web search engine. For example, take time to learn how to use google.com’s search criteria. All Web search engines have instructions on their use. Too many search engines are available to list them all; however, a brief list of Web search engines includes:

+   * www.google.com
* www.yahoo.com
* www.lycos.com
* www.altavista.com
* www.ask.com
* www.about.com

Here is a nice google.com search tip: You can search a subject on a specific Web site using the format “<subject>” site:<web_site>. For example, to find out about using NFS on Red Hat Linux use the search criteria “using nfs” site:redhat.com.

Many programs used within Linux have their own Web sites. Most of these are found at the Web site <program_name>.org where program_name is the name of the program you are looking for. For example, to find information about using Samba, try www.samba.org.

+   - **User groups** Hundreds of user groups are available. User groups usually hold monthly meetings locally or online. These are a great source of information. You will find that Linux users give help freely and enthusiastically. Linux users often treat using Linux as a hobby, not a job.
- **News groups** You will find that if you have a question, you can post it and get many useful responses. You may also get responses challenging the possibility of you ever becoming a Linux administrator, but just consider it a “hazing” for the *Linux newbie*. Don’t feel that any question is too simple to post. There are many more newbies on the news groups than experts. News groups can be searched, enabling you to find postings from others with the same problem. Expect to be chastised if your question to a group indicates that you have not done your homework.
- **Printed documentation** Many commercially available programs come with user manuals. These manuals contain information about installing and using the product. You can also find books in your local bookstore on a wide range of Linux subjects.
