You use only a few commands with environment variables, but lots of possibilities exist for values and uses. The three most commonly used commands are set, export, and echo.

+   * **set**   Set is used to set shell attributes. Several options can be used; use the man set page to view them. Using set by itself will display all values used by the shell.

```
# set
PATH=/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr
/bin:/usr/X11R6/bin:/root/bin
PIPESTATUS=( [0]='0' )
PPID=3954

PROMPT_COMMAND='echo -ne
\033]0;${USER}@${HOSTNAME%.*}:${PWD/#$HOME/~}\007'

```

+   * **export [-fn] [name = word]**   The supplied name is marked for automatic export to the environment. The -f option refers to the name of a function, and -n removes the named variable. To export an environment variable called ORACLE_HOME with a value of /opt/oracle/product/9.2.0/, use the following command:

```
# export ORACLE_HOME=/opt/oracle/product/9.2.0/
# echo $ORACLE_HOME
/opt/oracle/product/9.2.0/
#
```

+   * **echo [name]**   The echo command displays information to standard output. The echo command can display anything, and is often used from a script to display onscreen instructions. To display environment variables, you use the dollar sign ($) in front of the variable name. By convention, environment variables are capitalized. To view the PATH variable, use the following command:

```
# echo $PATH
/usr/local/bin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin:
/usr/X11R6/bin:/root/bin
#
```

Variables are used with shell programming. In Chapter 6, the variables $1, $2, and so on were used to identify the command-line position of a parameter passed to a script. Variables were also used with the let statement to assign values that were to be used later in the script. Environment variables can be used by all scripts.
