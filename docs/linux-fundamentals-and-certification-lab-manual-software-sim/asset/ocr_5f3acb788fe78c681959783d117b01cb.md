+   3. Load the initrd command to set RAM disk space. For example, **initrd /initrd-2.4.20-8smp.img.**

4. Run the **boot** command to load the operating system.

# ## Using LILO

LILO is a little different than GRUB. It has no interactive command interface, it stores in-formation about the location of the kernel on the MBR, and it cannot read ext2 partitions.  LIL0 allows only one command with arguments. Changes to the LIL0 configuration file require rewriting the stage 1 LIL0 boot loader to the MBR using the command */sbin/lilo -v -v*.

**Configuring LIL0** The LIL0 configuration file is */etc/lilo.conf* (Figure 6–12). The /sbin/lilo command uses this file when writing information to the MBR.

![](bbox=[0.04, 0.33, 0.84, 0.65])

Figure 6-12 shows a sample LIL0 configuration file. The following commands are commonly used in the */etc/lilo.conf* file:

+   **boot=<device_name>** Indicates where LIL0 will be installed. In Figure 6-12, LIL0 will be installed on the first SCSI hard disk.

**default=<"label_name">** The default operating system for LIL0 to boot. The <label_name> refers to the label entry described below the image name of the operating system.

**prompt** Displays the contents of the message line.

**message=<filename>** The message screen that LIL0 displays to let you select the operating system.

**image=<kernel_name>** Indicates the Linux kernel to boot.

**root=<partition_name>** Indicates which disk partition to use as the root partition.

**label=<"title_name">** The name that is displayed by LIL0 and the name re-ferred to by the default line.

**initrd=<ram_disk_name>** The name of the initial RAM disk that will be used at boot time.
