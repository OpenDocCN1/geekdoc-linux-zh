# Table 2-5
Common packages available.

| Element Name | Description | Hard Disk Space Required (MB) |
| :--- | :--- | :--- |
| **Desktops** | | |
| X Window System | XFree86 basic fonts, programs, and docs for an X workstation and custom configuration utilities. These utilities require very little disk space. | <1 MB |
| Gnome Desktop Environment | GNOME desktop environment GUI with panel, desktop, system icons, and a graphical file manager. GUI interface programs require about 200 MB of disk space. | ~200 MB |
| KDE Desktop Environment | KDE desktop environment GUI with panel, desktop, system icons, and a graphical file manager. GUI interface programs require about 200 MB of disk space. | ~200 MB |
| **Applications** | | |
| Editors | Text editors that allow you to create and edit files. These applications usually require very little disk space. But some editors for the X window system can exceed 100 MB. | 20-100 MB |
| Engineering and Scientific | Packages for performing mathematical and scientific computations and plotting. | ~50 MB |
| Graphical Internet | Graphical e-mail, Web, and chat clients. | 50-100 MB |
| Text-based Internet | Text-based e-mail, Web, and chat clients. These do not require the X window system. | <10 MB |
| Office/Productivity | Office suites and other programs for personal productivity. These include programs such as Open Office, PDF viewer xpdf, and others. An office suite program can easily require 400 MB or more of disk space. | 100-500 MB |
| Sound and Video | Applications that play CDs, record CDs, play multimedia files, and include tools to work with sound and video on the system. | 10-50 MB |
| Authoring and Publishing | Tools to create documentation in HTML, PDF, PostScript, and text. | 50-150 MB |
| Games and Entertainment | Games and other files to entertain you. | 10-100 MB |
| **Servers** | | |
| Server Configuration Tools | A set of custom server configuration tools for Samba, Web server, printer, and other services. | ~30 MB |
| Web Server | Tools that allow you to run and maintain a Web server. | ~40 MB |
| Mail Server | Tools to configure a mail server. | ~40 MB |
| Windows File Server | Samba SMB server that allows the sharing of files between Linux and Windows systems. | 5 MB |
| DNS Name Server | Allows you to run a DNS name server on the system. | <1 MB |
| FTP Server | Allows you to run an FTP (File Transfer Protocol) server on the system. | <1 MB |
| SQL Database Server | Allows you to run a relational database that uses SQL as its management language. Some commercial RDBMS (Relational Database Management Systems) can take several 100 MB to run. | ~20 MB |
| News Server | Allows you to configure a news server. | ~5 MB |
| Network Server | Includes network-based servers such as DHCP, DNS, telnet, remote access, and more. | <5 MB |
