# The while Loop

Whereas for loops a set number of times, the **while** loop loops through a set of script commands and terminates when a condition is true. This can be especially useful when you need to loop through a set of calculations.

Consider the following **while** loop:

```
```bash
#!/bin/bash
I=0
J=10
while [ $I -lt $J ]; do
    echo The value of I is $I
    let I=$I + 1;
done
```
```

In the example, the value of I is less than the value of J, so the while loop continues to do the script commands within the while structure. The first command within the script echos the value of I to the screen. The let statement increments the value of I by one. The while loop will continue looping until the value of I is no longer less than the value of J.

# The until Loop

The **until** loop is the opposite of the while loop. It loops through a set of script commands and terminates when the condition is false. You use **while** to loop while a condition is true, and **until** to loop until a condition is false.

To convert the loop in the while example to an until loop, only two changes are required. The while is replaced with until and the condition is changed to represent a true value until the value of I has reached a value greater than or equal to that of J.

```
```bash
#!/bin/bash
I=0
J=10
until [ $I -ge $J ]; do
    echo The value of I is $I
    let I=$I + 1;
done
```

# Using sed

The **sed** (stream editor) command is a non-interactive text editor. Instead of changing a file by moving across a screen and making changes as you do in vi, you can use the sed command to make changes from command level. The syntax of sed is **sed options file_to_change**, where file_to_change is the file that will be altered. The following example uses sed to make a change to a file:

```
sed 's/I/X/g'root/sed_test
```
