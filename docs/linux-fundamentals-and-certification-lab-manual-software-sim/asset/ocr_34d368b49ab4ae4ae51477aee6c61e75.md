# HARDWARE CONFIGURATION

v verify the partition table

w write table to disk and exit

x extra functionality (experts only)

To create a new partition:

+   1. Define the type of partition, either extended logical (l) or primary (p). For this example, the p for a primary partition is used.
2. After you select the partition type, you are asked for beginning and ending cylinders. In this case, the first cylinder is 828 (the next cylinder after the previous partition) and the last cylinder is 1224.

```
Command (m for help): n
Command action
l logical (5 or over)
p primary partition (1-4)
```
