
## The while Loop

Whereas for loops a set number of times, the **while** loop loops through a set of script commands and terminates when a condition is true. This can be especially useful when you need to loop through a set of calculations.

Consider the following **while** loop:

```bash
#!/bin/bash
I=0
J=10
while [ $I -lt $J ]; do
    echo The value of I is $I
    let I=$I + 1;
done
```

In the example, the value of I is less than the value of J, so the while loop continues to do the script commands within the while structure. The first command within the script echos the value of I to the screen. The let statement increments the value of I by one. The while loop will continue looping until the value of I is no longer less than the value of J.

## The until Loop

The **until** loop is the opposite of the while loop. It loops through a set of script commands and terminates when the condition is false. You use **while** to loop while a condition is true, and **until** to loop until a condition is false.

To convert the loop in the while example to an until loop, only two changes are required. The while is replaced with until and the condition is changed to represent a true value until the value of I has reached a value greater than or equal to that of J.

```bash
#!/bin/bash
I=0
J=10
until [ $I -ge $J ]; do
    echo The value of I is $I
    let I=$I + 1;
done
```

## Useful Utilities

Several commands are almost programming languages within themselves. These special utility commands can really expand the usefulness of a script. For more information concerning these commands, refer to their man pages.

### Using sed

The **sed** (stream editor) command is a non-interactive text editor. Instead of changing a file by moving across a screen and making changes as you do in vi, you can use the sed command to make changes from command level. The syntax of sed is **sed options file_to_change**, where file_to_change is the file that will be altered. The following example uses sed to make a change to a file:

```bash
sed 's/I/X/g' /root/sed_test
```

sed looks through the file sed_test and replaces all I's with X's. The results of this command are illustrated in Figure 6–17.

### Using awk

The awk command looks for a pattern and does an action for every match. The syntax of awk is *awk '/pattern_to_find/action/' file_to_use*, where *pattern_to_find* is the string to match in the file, action is the command to execute when the pattern is matched, and *file_to_use* is the file awk will be working with.

For example, to list every line from the *sed_test* script that contains a capital J, use the *awk '/J/{print}' /root/sed_test* command.

The awk command looks through the *sed_test* file and lists the lines that match the pattern. Figure 6–18 shows a sample run of this command.

### Using sort

The *sort* command (Figure 6–19) will arrange a file in sequence. Use the *-r* option to arrange the file in reverse order. For example, to sort the file *data1* in alphabetical order, use the *sort data1* command.

To arrange the file in reverse order, use the *sort -r data1* command.

## SUMMARY

Packages are archives that contain program files for use with the operating system. The tar and cpio programs are provided with all Linux distributions. Two of the more commonly used package management systems are Red Hat Package Manager (RPM) and Debian GNU/Linux Package Manager (DEB). The package management programs keep track of program dependencies when installing programs.

After a program is installed on the Linux operating system, the program should be tested. Ideally, a test system is used to execute and test programs before they are run in a production environment. The test system should be as close in quality as possible to the production machine.

The two most commonly used boot loaders on Linux are Linux Loader (LILO) and Grand Unified Bootloader (GRUB). Boot loaders can be customized to start Linux on specific partitions and with differing parameters.

Backups are a necessary administration task for most Linux installations. Linux computer systems can fail due to failures in hardware, software, environment, and human error. In the case of failure, machines can be restored from backup. Backup can be accomplished through tar, cpio, or third-party programs.

Backup devices include tape drives, hard drives, optical drives, and high-capacity floppy drives. The most commonly used backup device is the tape drive.

Shell scripts are a way to combine many different shell commands together into a single executable command. Shell scripts can use any command available from the shell prompt and can be controlled with conditional and looping command structures. Many of the Linux startup scripts are shell scripts.
