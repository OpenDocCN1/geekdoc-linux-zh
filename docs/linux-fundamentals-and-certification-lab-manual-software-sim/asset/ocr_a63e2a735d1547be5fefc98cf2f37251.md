# LINUX INSTALLATION REQUIREMENTS

Hardware, especially on older systems, must be configured and identified for Linux to be installed correctly. Configuring hardware includes setting IRQs, DMA addresses, I/O addresses, and jumper settings.

Regardless of the type of installation you do, you will install software and services. The Linux operating system provides access to the computer’s hardware through a user interface or through software. Software includes a wide range of applications for personal productivity, games, audio and video, and many other uses. Services include programs for clients to provide network support, database access, and so on.

Data is stored on your computer system in disk drive partitions. Each hard drive may have one to four primary partitions, or one to three primary partitions and one extended partition. An extended partition may have any number of logical partitions. Typical partitions include swap, / (root), and /boot. Each partition can have a different file system. File systems are responsible for how data is stored on the partition. Common file system types are FAT, Linux native, and Novell NetWare. In Linux, a partition is “mounted” into the overall file system hierarchy. In other words, each partition is shown in Linux as a subdirectory of the file system.
