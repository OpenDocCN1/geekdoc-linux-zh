# # About the Author

**Roderick W. Smith** has been using computers since high school, including systems using operating systems as diverse as AppleDOS, MacOS, TOS, MS-DOS, Windows 95 and 98, Windows NT, OS/2, VMS, Ultrix, and, of course, Linux. He has been building and upgrading x86 PCs since 1992, and has experience with Linux running on both x86 and PowerPC hardware. Rod has used Linux since 1994, and has used it as his primary OS since 1996. This is Rod’s fourth book, the first three being Que’s *Special Edition Using Corel WordPerfect 8 for Linux, Sams’ Linux: Networking for Your Office*, and Que’s *Multi-Boot Configuration Handbook*. He holds a BA from Oberlin College, an MA from the University of Michigan, and a PhD from Tufts University. He currently resides in Malden, Massachusetts.
