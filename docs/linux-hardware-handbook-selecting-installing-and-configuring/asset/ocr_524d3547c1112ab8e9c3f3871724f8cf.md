# NOTE

*PC Card used to be named after the organization that originated the standard, the Personal Computer Memory Card International Association (PCMCIA). Most Linux documentation continues to use this name for the technology. Most manufacturers, however, now use the term PC Card instead. I follow this convention in this book.*

# ## PC Card Hardware

PC Card slots typically reside on one side of the computer. You slide the PC Card device into the computer much as you would a floppy disk. If all goes well, when the device locks in place, Linux detects it and loads the appropriate drivers. You can then use the device without further ado.
