# NOTE

> X-CD-Roast uses the .raw filename extension for CD image files. .iso is a more common extension, but you shouldn’t use this if you expect X-CD-Roast to be able to write the image file you create. If you’ve downloaded an image file that uses an .iso extension, you can rename the file to let X-CD-Roast see it and burn it to CD without re-creating the filesystem.
