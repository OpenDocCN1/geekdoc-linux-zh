You should ask the vendor whether it uses the full commercial version of a distribution or a freely-available version. If the former, you should get a set of installation CDs, a manual, and support from the publisher. If the latter, be sure that the vendor at least gives you a Linux installation CD. Some might include extra printed documentation—either a printout of some set of documents that come in electronic form with Linux or a Linux book that covers a distribution.
