# ## Summary

In many cases, Linux installs itself to a computer and works with the computer’s hardware without any special effort on your part. In some cases, however, you must track down unusual drivers in order to get some component to work. Doing this can take some effort and perhaps even ingenuity, because many small driver projects lurk in out-of-the-way locations on the Web. The first step, however, is usually to identify the device’s chipset. With that information, you can at least search for the driver in an intelligent way. Web sites, including search engines such as `http://www.yahoo.com` and `http://www.deja.com/usenew/`, can be powerful tools when you want to locate a driver. So can some commands included with Linux, used in conjunction with the Linux kernel source code.
