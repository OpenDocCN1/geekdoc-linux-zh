本附录列出了许多较大的计算机硬件组件制造商。由于销售硬件的公司数量相当庞大，本附录的列表必然是不完整的。在适用的情况下，我列出了芯片组和完整主板制造商。

本附录的结构大致反映了本书的结构，从 CPU 到完整系统逐步推进。这里有一些例外。例如，我没有列出内存供应商，因为许多人认为内存是一种商品，事实上，它通常是以通用品牌销售的，不附带品牌名称。我在附录末尾加入了一个关于 Linux 零售商的部分。
