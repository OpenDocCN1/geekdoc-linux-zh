# Keyboards and Mice

Many manufacturers sell both keyboards and mice, but a few sell only one type of device. Most manufacturers of mice also produce mouse substitutes, such as trackballs. There are a huge number of manufacturers of very low-cost keyboards and mice; this section lists only some of the best-known or highest-quality manufacturers of these devices.
