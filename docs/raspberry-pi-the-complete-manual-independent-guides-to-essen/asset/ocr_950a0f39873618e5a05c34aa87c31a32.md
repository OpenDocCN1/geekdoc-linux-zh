Make shooting time-lapse video with your DSLR camera a cinch with our expert advice

You'd be forgiven for thinking that creating mesmerising time-lapse videos like those of Vincent Laforet ([www.laforetvisuals.com](http://www.laforetvisuals.com)) or John Elkind ([www.theartoftime lapse.com](http://www.theartoftime%20lapse.com)) might be out of reach of the Average Joe. With the help of the Raspberry Pi and a sprinkling of Python code, though, that's no longer the case. In this guide we're going to trigger our DSLR camera to create pixel-perfect time-lapse imagery...

# What you'll need...

+   - Latest Raspberry Image www.raspberrypi.org/downloads  
+   - Breadboard  
+   - Connectors  
+   - Jumper wire  
+   - DSLR camera  
+   - Compatible shutter cable

# Set up the Raspberry Pi

**01** For this tutorial we're assuming you're using a recent build of Ras pi on, with the Raspberry Pi set up with a keyboard, mouse and monitor. Open the terminal and type:

```
sudo apt-get update
```

# Install the RPi.GPIO library

**02** Next we want to make sure your development environment is set up. Follow these steps to make sure you've all set in the terminal, type:

```
sudo apt-get install python-dev
sudo apt-get install python-rpi-gpio
```

# Set up the Pi Cobbler

**03** For this tutorial we've used a cheap prototyping breadboard and an Adafruit Pi Cobbler to give us easy access to the Raspberry Pi's GPIO pins. As you can see from the picture, the Cobbler straddles the centre-point of the breadboard and a ribbon cable connects the two.
