### Create a portable wireless access point

#### What you'll need…

- Raspbian
  - www.raspberrypi.org/downloads
- Wi-Fi adaptor

#### Create a portable wireless access point

With the help of a Wi-Fi adaptor, you can turn your Raspberry Pi into a wireless access point for other devices.

The Raspberry Pi's portability makes it ideal for carrying around as an emergency wireless router or access point. Perfect if you're visiting a hotel without the service, or less tech-adept friends and family. Here's how to get it set up…

#### Did you know…

Aside from XBMC, setting up your Pi as a Wi-Fi access point is one of the most common projects to undertake.

![](img/59caadfa348382a5c408c25137901e27_111_0.png)

#### Install Raspbian

**01** For this project, we recommend using Raspbian to power our access point. To do this, install the image on an SD card and go through the basic setup process, making sure to enable SSH during installation. You can also turn off the desktop during setup as well if you don't plan to use it, though you might want to keep it for other projects.

#### Connect through SSH

**02** Find the IP address of your Raspberry Pi by typing `ifconfig` into the command line, and make a note of it. Unplug your Raspberry Pi, then plug your wireless adaptor in, and then plug the power back in. In a networked computer's terminal, type:

```bash
ssh [user]@[IP address]
```

#### Install DHCP

**03** Install a DHCP server with:
`sudo apt-get install hostapd isc-dhcp-server`

Now we need to set it up. Edit the configuration file with:
`sudo nano /etc/dhcp/dhcpd.conf`

And start by putting a # in front of the two `option domain-name` entries, then remove the `fi` in front of `‘authoritative;’` seven lines down.

![](img/59caadfa348382a5c408c25137901e27_112_0.png)

#### Server address

**04** At the end of the configuration file, add these lines:

- `sudo nano /etc/network/interfaces`
- 保存并退出，然后输入以下命令：
  - `sudo ifconfig wlan0`

#### Disable Wi-Fi

**05** Edit the server name with `sudo nano /etc/default/dhcpd-server` and set `INTERFACES` to `wlan0` and save.

#### Enable access

**06** After the line `#lo-hotplug` in `/etc/network/interfaces`, add the following:

- `iface wlan0 inet static`
- `address 192.168.42.1`
- `netmask 255.255.255.0`

Save and exit. Set `wlan0`'s address with `sudo ifconfig wlan0 192.168.42.1`

Now create a new file to use to start creating the wireless network:

- `sudo nano /etc/hostapd/hostapd.conf`

#### Wireless networking

**07** Create your wireless network with the following code:

```text
interface=wlan0
driver=rtl871xdrv
ssid=CissCiss point me
channel=1
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpapassphrase=[Password]
wpa_key_mgmt=WPA-PSK
wpa_pairwise=TKIP
eap_identity=%copp
wpa_rsn_pairwise=TKIP
```

Save and exit. Now edit `hostapd` to point to the new file with `sudo nano /etc/default/hostapd`.

#### Network addressing

**08** Run `sudo nano /etc/sysctl.conf`

Add this, `ipv4_ip_forward=1`, to the bottom of the file.

Save this, then run `sudo sh -c "echo 1 > /proc/sys/net/ipv4/ip_forward"`

Run the following three commands to make sure the internet is forwarded correctly.

- `sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE`
- `sudo iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT`
- `sudo iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT`

#### Finish up

**09** So that this works after a reboot, type:

`sudo sh -c 'iptables-save > /etc/iptables.ipv4nat'`

Then add `up iptables-restore < /etc/iptables.ipv4nat` to the end of `eth` in `/etc/network/interfaces`.

Finally, set it up as a daemon with:

- `sudo service hostapd start`
- `sudo service isc-dhcp-server start`
- `sudo update-rc.d hostapd enable`
- `sudo update-rc.d isc-dhcp-server enable`

### Build a security camera

#### What you'll need...

- A router or switch
- A Linux-compatible webcam
- Raspbian [www.raspberrypi.org/downloads](http://www.raspberrypi.org/downloads)
- Powered USB hub

#### Build a security camera

Want to keep an eye on something from the comfort of your web browser? All you need is a Pi and a webcam!

This article will teach you how to use the MJPG-streamer software to stream video straight from a webcam to your web browser. You could record the stream, and also display multiple streams from multiple Raspberry Pis on one page. The streams can also be viewed from mobile devices and tablets.

#### Did you know...

> Most modern webcams are compatible with the Raspberry Pi, but check in a [support forum](https://forum.raspberrypi.com) before you buy.

#### Check compatibility

Most USB cameras should work with your Pi out of the box, but it’s worth checking compatibility first.

![](img/59caadfa348382a5c408c25137901e27_113_0.png)

#### Extra power

Depending on your webcam, you may need a powered USB hub to get it working.

#### Network investigation

The first job we need to do is investigate the network your Raspberry Pi is on, so we can assign it a static IP address. That way, we’ll always know where it is on the network so we can access with ease.

```bash
pi@raspberrypi ~ $ ip addr show dev eth0 | grep inet
        inet 172.17.173.94/24 brd 172.17.173.255 scope global eth0
pi@raspberrypi ~ $ ip route | grep default
default via 172.17.173.1 dev eth0
pi@raspberrypi ~ $ cat /etc/resolv.conf
nameserver 172.17.173.1
```

#### Assign a static IP address

Now that we have the network configuration, we can assign a static IP address. Open `/etc/network/interfaces` in an editor such as nano, and change the line:

`iface eth0 inet dhcp`

to a configuration similar to our expert's. Reboot to load the new configuration.

```text
iface eth0 inet static
address   172.17.173.94
netmask   255.255.255.0
network   172.17.173.0
broadcast 172.17.173.255
```

![](img/59caadfa348382a5c408c25137901e27_114_0.png)

#### Installing the software

**03** Log into the Raspberry Pi system with the username 'pi' and the password 'raspberry'. The MJPG-streamer software isn't packaged for the Raspberry Pi, so we'll need to compile it ourselves. Update the package index with `sudo apt-get update`. We need to install Subversion, which we'll use to download source code. We'll also need libpng and imagemagick, both of which are required by MJPG-streamer. Install these with:

`sudo apt-get install subversion libjpeg-dev imagemagick`

#### Compile MJPG-streamer

**04** Download and compile MJPG-streamer as shown below:

```bash
pi@raspberrypi ~ $ svn checkout svn://svn.code-sf.net/mjpg-streamer-code /code/mjpg-streamer-code
pi@raspberrypi ~ $ cd mjpg-streamer-code/mjpg-streamer
pi@raspberrypi ~ $ make clean all
```

#### Testing it out

**05** To start MJPG-streamer, export `LD_LIBRARY_PATH=:/mjpg_streamer-* "input_uvc.so" "output_file.so -w /www/`

You have to export the library path variable to the current directory so that the various input and output plug-ins can be used. Type your Raspberry Pi's IP address followed by :8000 into a browser and click the Stream tab. If the Stream tab doesn't work, try the example that uses JavaScript, that should work on most browsers, including Android.

#### Start MJPG-streamer at boot

**06** Edit the `/etc/rc.local` file (you'll need to use sudo) to include the following lines, ensuring that it still ends with `exit 0`.

```bash
export STREAMER_PATH=/home/pi/mjpg-streamer-code/mjpg-streamer
export LD_LIBRARY=STREAMER_PATH
$STREAMER_PATH/mjpg_streamer -i "input_uvc.so" -o "output_file.so -w $STREAMER_PATH/www/ &"
```

Reboot the Pi to check that it comes back up happily and starts the stream.

#### Extensions and improvements

**09** This example setup is very basic and has a few flaws. There is no authentication or SSL encryption, which means the streams are insecure and should not be shared over the internet. The HTTP module that comes with MJPG-streamer is quite simple, so you could get SSL by using a reverse proxy, such as Pound. You'd be able to SSL for each Pi you have with a single Pound instance and access the different Pis by having something like `/stream, stream2` in the URL.

#### Recording the stream

**07** You can easily download a motion JPEG stream and convert it to a useful format using VLC:

`cvlc stream://172.17.173.94:8000 0/actions?stream=1-sout #file=/m4:stream.mp4`

Alternatively, you can just download the stream URL with wget like so:

`wget stream://172.17.173.94:8000/0/actions?stream`

#### Multiple streams at once

**08** Here is an example of how to put multiple streams on a single webpage. These streams could come from a number of different Raspberry Pis all over the house.

```html
<HTML>
<TABLE BORDER="1">
<TR>
<TD><IMG SRC="172.17.173.94/8000/actions?stream=2/">
</TD>
<TD><IMG SRC="172.17.173.94:8000/actions?stream=1/">
</TD>
</TR>
</TABLE>
</HTML>
```
