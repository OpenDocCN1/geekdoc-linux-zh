# ## Server address

04 At the end of the configuration file, add these lines:

+   *   `sudo nano /etc/network/interfaces`
+   *   保存并退出，然后输入以下命令：
+       *   `sudo ifconfig wlan0`

# ### Disable Wi-Fi

05 Edit the server name with `sudo nano /etc/default/dhcpd-server` and set `INTERFACES` to `wlan0` and save.

# ## Enable access

06 After the line `#lo-hotplug` in `/etc/network/interfaces`, add the following:

+   *   `iface wlan0 inet static`
+   *   `address 192.168.42.1`
+   *   `netmask 255.255.255.0`

Save and exit. Set `wlan0`'s address with `sudo ifconfig wlan0 192.168.42.1`

Now create a new file to use to start creating the wireless network:

+   *   `sudo nano /etc/hostapd/hostapd.conf`

# ## Wireless networking

07 Create your wireless network with the following code:

```
```text
interface=wlan0
driver=rtl871xdrv
ssid=CissCiss point me
ho, medium
channel=1
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wp=2
wpapassphrase=[Password]
wpakey_mgmt=WPA-PSK
wpa_pairwise=TKIP
eap_identity=%copp
wpa_rsn_pairwise=TKIP
```

Save and exit. Now edit `hostapd` to point to the new file with `sudo nano /etc/default/hostapd`.
```

# ## Network addressing

08 Run `sudo nano /etc/sysctl.conf`

Add this, `ipv4_ip_forward=1`, to the bottom of the file.

Save this, then run `sudo sh -c "echo 1 > /proc/sys/net/ipv4/ip_forward"`

Run the following three commands to make sure the internet is forwarded correctly.

+   *   `sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE`
+   *   `sudo iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT`
+   *   `sudo iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT`

# ### Finish up

09 So that this works after a reboot, type:

`sudo sh -c 'iptables-save > /etc/iptables.ip4v4nat'`

Then add `up ip4tables-restore < /etc/iptables.ip4v4nat` to the end of `eth` in `/etc/network/interfaces`.

Finally, set it up as a daemon with:

+   *   `sudo service hostapd start`
+   *   `sudo service isc-dhcp-server start`
+   *   `sudo update-rc.d hostapd enable`
+   *   `sudo update-rc.d isc-dhcp-server enable`
