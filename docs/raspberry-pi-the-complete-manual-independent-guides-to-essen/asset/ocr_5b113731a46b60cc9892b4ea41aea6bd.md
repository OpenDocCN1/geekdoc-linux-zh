# Build a portable internet radio

Turn your Raspberry Pi into a portable Wi-Fi streaming radio

There are thousands of free radio stations on the internet, and with this project you can listen to all of them from one tiny little box. So let's build our streaming radio using a Raspberry Pi, a speaker and a few odds and ends ...

![](bbox=[0.06, 0.44, 0.94, 0.75])

# Let's get set up

+   1.  Firstly, we need to prepare our Pi. Using Raspbian, and a Pi connected to the internet, open a terminal and switch to the root user.
+   
+   ```
+   sudo su
+   ```
+   
+   And update your list of packages, then upgrade your Pi to the latest software:
+   
+   ```
+   apt-get update && apt-get upgrade -y
+   ```

# Install some extra packages

+   2.  We need to install the Python packages to access the GPIO. In a terminal, logged in as root, enter the following
+   
+   ```
+   apt-get install python-rpi.
+   gpio
+   ```
+   
+   Now install MPiayer, which is what will be playing our audio.
+   
+   ```
+   apt-get install mp
+   ```

# Make the files executable and Install

+   3.  To install the tools, we need to navigate to the 3.5mm sound jack on the Pi master/Install We now need to make installIAUITSuite.sh executable for all users, so use:
+   
+   ```
+   chmod 777 InstallIAUITSuite.sh
+   ```
+   
+   Now that the file is executable, let's install:
+   
+   ```
+   sudo ./ InstallIAUITSuite.sh
+   ```
