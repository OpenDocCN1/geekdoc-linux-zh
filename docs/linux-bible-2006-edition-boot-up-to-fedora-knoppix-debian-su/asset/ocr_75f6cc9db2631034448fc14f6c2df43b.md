You can execute the backtrace (or bt back) command to generate the function
tree that led to the segmentation fault. The backtrace doesn't usually show you
what the problem is, but does show you more precisely where the problem
occurr. Here is the function trace for the examples on your system:

```
(gdb) backtrace

#1 0x080048a6 in main (arg=0x704, arg=0x69) at debugme.c:15
```
