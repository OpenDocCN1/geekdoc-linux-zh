
# Booting KNOOPPIX

If you have a PC in front of you that meets the requirements, you can get started by following these steps:

- 1. Insert your KNOOPPIX DVD or CD into the appropriate drive.
2. Reboot the computer. After a few moments, you will see the boot screen.
Although the boot screens look different for the Linux Bible DVD and a regular KNOOPPIX CD, you can proceed with the boot process the same way.
3. Press Enter. If all goes well, you should see the KNOOPPIX desktop, and you can proceed to the “Using KNOOPPIX” section. If KNOOPPIX doesn't boot properly or if you want to tune it further before it, continue on to the next section.

# Correcting Boot Problems

By understanding all the boot process you will, in most cases, be able to overcome any problems you might have installing KNOOPPIX. Here are some things you should know:

- **Boot order**— Your computer's BIOS has a particular order in which it looks for boot operating systems. A typical order would be floppy, CD or DVD, and hard disk. If your computer skips over the KNOOPPIX boot disk and boots right from hard disk, make sure that the boot order in the BIOS is set to CD or DVD. To change the BIOS, restart the computer and as it first boots the hardware enter Setup (quickly) as instructed (usually by pressing F1, F2, or DEL). Look for a selection to choose the boot order so that your CD or DVD boots before the hard disk.
- **Make floppy disks**—If your computer still can't boot from CD or DVD, you can create two floppy disks from a running KNOOPPIX system, run the mkbootfloppy command that is on the KNOOPPIX disk (it automatically formats the floppy images and tells you when to put in the floppy disks). To create for other operating systems, refer to the KNOOPPIX wiki (www.knoppix.net/wiki/MainPage).
- **Add boot options**—Instead of letting the boot process autodetect and configure everything about your hardware, you can add options to the boot prompt that will override your KNOOPPIX autoconfiguration date. Press F2 from the boot prompt to see additional boot options.

Some boot options are available with which you can overcome different issues at boot time. KNOOPPIX refers to these options as cheat codes. For a more complete list, refer to the file knoppix-cheatcodes.txt, which you will find in the KNOPPIX directory when you mount the CD or the DVD that comes with this book on any operating system.

Many options can be used with different Linux systems. If you are having trouble installing or booting a different Linux distribution, you can try any of the options to use instead. Instead the word "knoppix," you will probably use a different word to launch the install or boot process for other distributions (such as "Linux" for Red Hat Linux systems or "morphix" for Morphix Live-CD, depending on the distribution).

# Part III Choosing and Installing a Linux Distribution

### Testing the CD

If you suspect that you have a bad KNOOPPIX CD, I recommend you run this from the boot prompt:

```
knoppix testcd
```
If you are still not able to boot KNOOPPIX at this point, it might be that your hardware is either not supported or is broken in some way. To further pursue the problem, check out an appropriate forum at www.knoppix.net.

### Running KNOOPPIX from RAM

To improve performance, KNOOPPIX offers a way to run the KNOOPPIX distribution from RAM (provided you have enough available) or install it on hard disk and run it from there. Provided that you have more than 1GB of RAM, you can run KNOOPPIX entirely from RAM (so you can remove the KNOOPPIX DVD and CD and use drive while you run KNOOPPIX) by typing from the boot prompt:

```
knoppix toram
```

### Installing KNOOPPIX to Hard Disk

You can run KNOOPPIX entirely from hard disk if your hard disk is either a FAT or EXT2 file system type and contains at least 800MB of space. To do this, you must know the name of the hard partition you are installing on. For example, to the first partition on the first IDE drive you would use /dev/hda. In that case, to copy KNOOPPIX to that partition, you would type this at the boot prompt:

```
knoppix tohd=/dev/hda
```
You can watch as KNOOPPIX is copied to your hard partition and boots automatically from there. The next time you want to boot KNOOPPIX, you can boot it from hard disk by inserting the KNOOPPIX medium and typing the following:

```
knoppix fromhd=/dev/hda
```
With KNOOPPIX running from your hard disk, you can safely eject your CD or DVD and use the drive for other things (type eject /dev/cdrom). Refer to the knoppix-cheatcodes.txt file for information on other things you can do from the KNOOPPIX boot prompt.
