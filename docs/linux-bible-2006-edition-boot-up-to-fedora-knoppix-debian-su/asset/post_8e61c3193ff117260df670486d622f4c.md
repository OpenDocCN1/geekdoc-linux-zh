## Creating Playlists with Xine

Click the Playlist button on the left side of the xine control window. A Playlist Editor appears, showing the files on your current playlist. You can add and delete content and then save the list to call later.

Xine content is identified as resource locators (MRLs). Each MRL is identified as a file, DVD, or VCD. Files are in the regular file path (/path/file) or preceded by file://, fifo:/ or stdin:/. DVDs and VCDs are preceded by dvd and vcd, respectively (for example, vcd:/01).

Table 20-2 shows what the xine Playlist Editor buttons.

| Button | Description |
|---|---|
n| CDA, DVD, or VCD | All content from that CD or DVD is added to the playlist. |
| Add | See the MRL Browser window. From there, click File to choose a file from your Linux system, and then Click to Select add that file to the Playlist Editor. (MRL stands for Resource Locator, which defines the form in which remote and local content are identified.) |
| Move Up Selected MRL Move Down Selected MRL | Move up and down the playlist. |
| Play | Play the contents of the playlist. |
| Delete Selected MRL | Remove the current selection. |
| Delete All Entries | Clear the whole playlist. |
| Save | Save the playlist to your home directory ($HOME/.xine/playlist). |
| Load | Read in (saved) playlist. |

## Xine Tips

Getting audio and video to work properly can sometimes be a tricky business. Here are a few quick tips if you are having trouble getting xine to work correctly (or at all):

- *Xine won't start—To work best, xine needs an X driver that supports xvid. If there is no xvid support for your video card in X, xine shuts down immediately when it tries to use the default driver. If this happens to you, try xine with the X11 video driver (which is slower, but should work) as follows:
  * xine -VXSHM

- *playback choppy—If playback of files from your hard disk is choppy, there are a couple of settings you can check: 32-bit IO and DMA, features, that are supported by your hard disk, generally improve hard disk performance. Here's how to check:

![](img/a2d958d7eab32ca5b89b2b8af808aa70_568_0.png)

Improper disk settings can result in destroyed data on your hard disk. This procedure is at your own risk. for IDE hard drives (no SCSI)! Also, be sure to have a current backup and no activity on your hard disk if you change DMA or IO settings in this section.

- 1. Test the speed of hard disk reads. To test the first IDE drive (/dev/hda), type:

```
# hdparm -t /dev/hda
buffered disk reads: 64 MB
19.31 seconds = 3.33 MB/sec
```

- 2. Set your current DMA and IO settings, as root user:

```
# hdparm -c /dev/hda
/dev/hda:
/O support = 0 (default 16-bit)
using_dma = 0 (off)
```

- 3. This result shows that 32-bit IO and DMA are off. To turn them, type:

```
# hdparm -c 1 -d 1 /dev/hda
/dev/hda:
/O support = 1 (32-bit)
using_dma = 1 (on)
```

- 4. With both settings, test the disk again:

```
# hdparm -t /dev/hda
Timing disk reads: 64 MB
2.2 seconds = 28.83 MB/sec
```

In this example, buffered disk reads of 64MB went from 19.31 seconds to 2.2 seconds after changing the parameters described. Playback would be much better now.

- *Wine not play popular media — Messages as no input plug-in mean that the file format you are trying to play is not supported or it requires an additional plug-in (as is the case with playing DVDs). If the message says xy a broken file, the file may be a proprietary version of an otherwise supported format. For example, I had a QuickTime video fail that required an SVQ3 codec (which is currently not supported by Linux), although other QuickTime files played fine.

## Using Helix Player and RealPlayer 10

A tremendous amount of content is available on the Internet in the RealMedia and RealAudio formats. You can see and hear video clips of popular musicians and comics; view live events such as conferences, news stories, and concerts; and listen to your favorite radio stations when you are out of town.

To play RealMedia and RealAudio content, you may have guessed, RealPlayer. Real Networks (www.real.com) is a leader in streaming media on the Internet. More than 50 million unique users have registered with Real Networks and its Web site, downloading more than 175,000 files per day. And that's not even the good news. The news is that RealPlayer is available to run in Fedora Core.

RealPlayer 10 for Linux is available via the Linux area of www.download.com and www.tucows.com and at http://proforma.com/real/player/unix/html. This player is not supported by Real Networks directly. In addition, Real opened the source code to the RealPlayer under the name Helix Player. Fedora Core 4 (on the DVD included with this) includes a preleased version of the Helix Player that you can try out.

The instructions for configuring RealPlayer are delivered in HTML format, so you can read them in Mozilla or some other browser. If any patches or workarounds are required, you can find them by querying for the word “Linux” in the Real Networks Knowledge Base. To get there, click Support (from most Real Networks pages), and then click Knowledge Base.

When you install RealPlayer, you are asked if you want to configure it to be used as a Netscape plugin (which I recommend so that you can play real content in Mozilla). After, when you open any Real content in your browser, RealPlayer opens to handle it. Alternatively, you can start RealPlayer from a Terminal window on your desktop by typing the following:

```
$ realplayer &
```

## Using a Digital Camera with gPhoto

Using a Digital Camera with gPhoto2 allows you to manage your photos and videos directly from your Linux system. With gPhoto2, you can import images, download video files, and even control camera settings.

To get started, connect your camera to your computer via USB or a card reader. Once connected, use the following command to list the available cameras:

```bash
gphoto2 --list-cameras
```

This will show a list of connected cameras and their supported features. To import images from your camera, use the following command:

```bash
gphoto2 --camera [CAMERA_ID] --dump-all [destination_directory]
```

Replace `[CAMERA_ID]` with the ID found in the previous step. gPhoto2 also supports many other operations such as renaming files, clearing the camera memory, and extracting metadata.
