If you are unable to use some feature of the mouse, such as a middle wheel, you might be able to get it working with an entry that looks more like the following:

```
Section "InputDevice"
Identifier "Mouse0"
Driver "mouse"
Option "Protocol" "IMPS/2"
Option "Device" "/dev/psaux"
Option "ZAxisMapping" "4 5"
EndSection
```

Don't change the mouse identifier, unless you change the protocol and the ZAxisMapping line to enable your wheel. Try restarting X and trying your mouse wheel on something like a Web page to see if you can scroll up and down with it.

Your mouse might be connected in a different way (such as a bus or serial mouse) or may have different buttons to enable. Tools for configuring your mouse are distribution-specific. Try mouseconfig, mouseadmin, or system-config to reconfigure your mouse from the command line.

+   ♦ Monitor—The section defines attributes of your monitor. There are generic settings you can use if you don't know the model of your monitor. Changing the Horizontal Sync and Vertical Refresh rates without checking your monitor's technical specifications is not recommended; you could damage the monitor. Here's an example of an entry that will work on many LCD panels:

```
Section "Monitor"
Identifier "Monitor0"
VendorName "Monitor Vendor"
Name "LCD Panel 1024x768"
HorSync 31.5 - 48.5
VertRefresh 40.0 - 70.0
EndSection
```

Here is an entry for a generic CRT monitor that will work on many CRTs:

```
Section "Monitor"
Identifier "Monitor0"
VendorName "Monitor Vendor"
Name "Generic Monitor, 1280x1024 @ 74 Hz"
HorSync 31.5 - 79.0
VertRefresh 50.0 - 90.0
EndSection
```

If a tool is available to select your monitor directly, that would be the best way to go. For example, in Red Hat systems, you would run system-config-xfree86 to change monitor settings.
