Mounting Removable Media
If want to mount a file system manually, the /etc/fstab file helps it simple to mount a floppy disk or a CD. In some cases, you can use the mount command with a single option to indicate what you want to mount, and information is taken from the /etc/fstab file to fill in the other options. There are probably entries in your /etc/fstab file to let you do these quick mounts in the following cases:

+   * CD—If you are mounting a CD that is in the standard ISO 9960 format (as most software CD-ROMs are), you can mount that CD by placing it in your CD-ROM drive and typing one of the following:

```
# mount /media/cd*
# mount /mnt/cdrom
```

By default, a CD is usually mounted on the /mnt/cdrom directory (Linux 2.4 kernels) or a subdirectory of /media (Linux 2.6 kernels). The file type, device name, and other options are filled in automatically). To see the contents, use cd /mnt/cdrom or cd /media/cd*, and then type ls. Files from the CD's root directory will be displayed.

+   * Floppy disk—If you want to mount a floppy in the Linux ext3 file system (ext3), or in some cases a format that is autodetected, mount floppy disk by inserting it into your floppy drive and typing one of the following:

```
# mount /media/floppy*
# mount /mnt/floppy
```

The file type (ext3), device (/dev/fd0), and mount options are filled in the /etc/fstab file. You should be able to change the floppy disk directory (cd /mnt/floppy or cd /media/floppy*) and list the contents of the floppy's top directory (ls).

> In both of cases, you could give the device name (which is something like /dev/hdc, /dev/cdrom or /dev/fd0) instead of the mount point directory to get the results.

Of course, it is possible that you get floppy disks you want to mount that are in all formats. Some may be (MS-DOS format). Or you may get a floppy containing files from an old Microsoft operating system or from another UNIX system. In those cases, you can fill in your options instead of relying on options from the /etc/fstab file. In some cases, Linux autodetects the floppy disk contains an MS-DOS (or Windows vfat) file system and mounts it properly without additional arguments. If it doesn't, here's an example of how to mount a floppy containing MS-DOS files:

```
# -t msdos /dev/fd0 /mnt/floppy
```
