# ## Getting into Slackware

Although full graphical installs and GUI administration tools can make installing and configuring Linux easy, those tools carry them with some overhead. They also hide some of the details of how Linux is being configured.

As Slackware devoting the value of Slackware and they might recite their mantra, the “45 Rule”: Stable, Solid, Simple, and Sensible. By keeping things basic, Slackware offers the following-advantages:

+   * **Basic comprehension**—Because you use commands and configuration files with Slackware, you learn more about how Linux works on the inside. Most graphical installers and GUI tools hide the actual configuration that is going on and often limit the features you can use.
