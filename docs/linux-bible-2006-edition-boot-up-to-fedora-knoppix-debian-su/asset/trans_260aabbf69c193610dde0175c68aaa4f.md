

# 寻找通用安全资源

现在许多计算机网络资源都提供了对 Linux 系统管理员特别有用的信息。你可以查看以下几个网站：

- *CERT (www.cert.org)*——CERT 协调中心关注计算机安全问题。访问其主页以获取最新的漏洞信息。该网站有关于安全实践的文章（www.cert.org/nav/articles_reports.html）。它还提供了当你的计算机被攻破时应该采取措施的建议（www.cert.org/tech_tips/win-UNIX-system-compromise.html）。
- *SecurityFocus (www.securityfocus.com)*——除了提供通用计算机安全主题的新闻和信息外，SecurityFocus 还提供了若干 Linux 资源。特别是，你可以订阅接收每周的《安全新闻》通讯报。
- *LinuxSecurity (www.linuxsecurity.com)*——该网站包含许多与 Linux 相关的文章和专题。它还跟踪了十多个发行版的安全公告。

# 安全地使用 Linux

获取并保持 Linux 系统的安全不仅意味着对如何设置系统做出明智决策，还意味着如何使用它。本节描述了与密码、使用应用程序、通过查看日志监控系统活动以及使用安全 shell (ssh) 与其他系统通信相关的良好实践。设置防火墙（如第 8 节所述）对于拥有安全系统至关重要。

# 密码保护

密码是任何现代操作系统的基础安全工具，因此也是最受攻击的功能。选择一个容易记忆的密码是自然而然的，但通常意味着选择了一个同样容易被猜到的密码。破解者会针对任何超过几个用户的系统进行工作，至少可能有一个人拥有易猜的密码。显然，选择良好的密码是拥有安全系统的第一也是最重要的一步。在选择密码时，请避免以下情况：

- 不要使用你的登录名或全名的任何变体，即使使用了不同的大小写、添加了数字或标点符号，或者倒过来输入。
- 不要使用字典单词，即使你对其添加了数字。
- 不要使用键盘上连续的字母（例如 "qwerty" 或 "asdf"）。

# 良好的密码

选择强密码的一种好方法是取一个易记句子的每个单词的首字母。通过添加数字、标点符号和变化的大小写，密码可以变得更好。你选择的句子只对你有意义，且不应公开（在你的个人页面上选择句子是一个坏主意）。表 6-1 列出了强密码的示例以及用于记忆它们的技巧。

| 密码 | 如何记忆 |
| :--- | :--- |
| Mrcy! | My rusty car is years old! |
| emBpib | elephant pets is better |
| ItGib | Is that coat? Give it back |

这些密码看起来像乱码，但实际上很容易记忆。如你所见，我可以对密码中代表大写字母的单词进行强调。你使用 `passwd` 命令输入密码。shell 中的 `passwd` 命令将允许你更改密码。首先，它会提示你输入旧密码。为了防止他人“窥视肩膀”并获知你的密码，密码在你输入时不会显示出来。

# 加固 Linux

假设你正确输入了旧密码，`passwd` 命令将提示你输入新密码。当你输入密码时，系统会根据 crack 标准对密码进行检查，以确定它是好密码还是坏密码。如果选择的密码不是好密码，非 root 用户将被要求尝试不同的密码。root 用户是唯一允许分配坏密码的用户。一旦密码被 crack 接受，`passwd` 命令会要求你再次输入密码，以确保没有输入错误（当你看不见输入的内容时，错误很难被发现）。以 root 身份运行时，可以通过提供 `password` 命令更改用户的密码。例如：

```
# password joe
Changing password for user joe.
New UNIX password: ********
Retype new UNIX password: ********
password: tokens updated successfully.
```

`password` 命令提示为 joe 输入新密码。在这种情况下，它不会提示你输入他的旧密码。这允许 root 在用户忘记密码时重置其密码（这种情况经常发生）。

# 使用影子密码文件 (Shadow Password File)

在 UNIX 版本中，所有用户账户和密码信息都存储在所有用户都可以读取的文件中（尽管只有 root 可以写入）。这通常不是问题，因为密码经过了加密。密码使用陷门算法（trapdoor algorithm）进行加密，这意味着明文密码可以加密成一个杂乱的字符字符串，但该字符串无法翻译回明文密码。换句话说，陷门意味着加密是单向的，加密后的密码无法用来还原明文密码。

在这种情况下，系统如何检查你的密码呢？当你登录时，系统会检查你输入的密码，将其与密码文件中存储的杂乱字符串进行比较，只有当两者匹配时才授予访问权限。你是否问过系统管理员你的账户密码是什么，结果得到的回答是“我不知道”？如果是，这就是原因：管理员实际上没有密码，只有加密版本。明文密码只在你输入它的那一刻存在。

# 破解加密密码

然而，人们能够看到加密密码这存在一个问题。虽然反转陷门算法的加密可能是困难的（甚至是不可能的），但加密大量的密码猜测是非常容易的。
