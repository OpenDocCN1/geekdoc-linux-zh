If you don't like your default shell, simply type the name of the shell you want to try out temporarily. To change your shell permanently, use the usermod command. For example, to change your shell to the csh shell for the user named chris, type the following as root user from a shell:

```
# usermod -s /bin/csh chris
```

# Checking Your Login Session

When you log in to a Linux system, Linux views you as having a particular identity, which includes your username, group name, user ID, and group ID. Linux also track of your login session: it knows when you logged in, how long you have been idle, and where you logged in from.

To find out about your identity, use the id command as follows:

```
$ id
uid=501(chris) gid=105(sales) groups=105(sales),4(adm),7(lpd)
```

In this example, the username is chris, which is represented by the numeric user ID (uid) 501. The primary group for chris is sales, which has a group ID (gid) of 105. The user chris also belongs to other groups adm (gid 4) and lpd (gid 7). These names and numbers represent the permissions that chris has to access computer resources. (Permissions are described in the “Understanding File Permissions” section later in this chapter.)

You can see information about your current login session using the who command. the -u option says to add information about idle time and the process -H has a header that is printed:

```
$ -UH
NAME TIME IDLE PID COMMENT
chris tty Jan 13 20:57 2013
```

The output from who shows that the user is logged in on tty (which the monitor connects to), and his login session began at 20:57 on January 13. The idle time shows how long the shell has been open without any command being typed (the dot indicates that it is currently active). PID shows the process ID of the user's login shell. COMMENT shows the name of the remote computer the user had logged in, if that user logged in from another computer on the network, or the name of the local X if you are using a Terminal window (such as :0).
