# Puppy Linux

The other heavyweight contender for lightweight Linux bootables is Puppy Linux (www.goose.com/puppy). The Puppy Linux image is about 61MB. So, for example, you can install and boot Puppy Linux on a 128MB flash drive and still have another 60+MB of space for data.

Puppy Linux is built for small, size, and ease of use. To emphasize the ease-of-use aspects, Puppy Linux tends to lean more toward open and closed than secure. Here are some examples:

+   **Writes to your hard disk**—Before you start using Puppy Linux on someone's computer, know that if it finds a hard disk when it boots up, you must mount that disk read/write and make pup001 file to the root of the free usable partition. It will then find partition on /mnt/home and leave it writable during your Linux session. Changes you make during your Linux session are stored in that pup001 file. So, if you don't need to enter keyboard, mouse, or video card information again when you boot from that. Most bootable Linux systems do not automatically write to a hard partition if it finds. You should decide how secure you feel with that.

+   **Loads to RAM**—When you load Puppy Linux, by default, run in RAM. So you should get excellent performance, provided your machine has at least 128MB of RAM available. With Puppy Linux in RAM, that also frees up your CD/DVD drive. So you can pop in a CD or DVD and play it without disturbing the Puppy Linux system

+   **Set no firewall rules**—Because Puppy Linux uses a Linux 2.4 kernel, iptables firewall is built in. However, no firewall rules are set by default. So, if you are thinking of using Linux to offer some services (Web server, mail server, and so on), keep in mind that it is intended for a desktop system and not to securely offer services.

Every major category of applications is represented in Puppy Linux. For word processing, you have abiword. You can play music with GPlayer and video with Gxine. The Mozilla suite is included for Web browsing, mail, news, and HTML editing. For internet client applications, you have GAIM (instant messaging), FTP, and Sylpheed mail/news client, as well as remote login tools (secure and telnet).

Other personal productivity tools that come with Puppy Linux include calendar (Xcalendar and Mozilla Calendar), spreadsheet (Planmaker), contacts (Gabby and Mozilla Addressbook), finance manager (Xfinans), and personal information DidiWiki). Most of these applications are lightweight, but serviceable, applications.
