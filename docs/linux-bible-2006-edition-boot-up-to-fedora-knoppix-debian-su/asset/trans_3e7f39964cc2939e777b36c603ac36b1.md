## 理解 Linux

那些不知道 Linux 是什么的人有时把它当成一个运行在 Microsoft Windows 上的程序。当我告诉他们 Linux 本身就是一个像 Windows 一样的操作系统，他们可以替换（或删除）Windows 时，我有时会得到惊讶的反应：“电脑可以在没有任何微软的程序的情况下运行吗？”
