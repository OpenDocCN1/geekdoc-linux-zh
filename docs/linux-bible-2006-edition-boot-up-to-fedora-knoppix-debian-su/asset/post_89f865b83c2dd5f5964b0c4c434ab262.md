The vi editor was originally based on the ex editor, which didn't let you work in full-screen mode. ### Using Numbers with Commands

You can precede vi with numbers to have the command repeated number of times. This is a handy way to deal with several lines, words, or characters at a time. Here are some examples:

-   ◆ 3dw — Deletes the next three words.
-   ◆ 5cl — Changes the five letters (that is, removes the letters and enters input mode).
-   ◆ 12j — Moves down 12 lines.

Putting a number in front of most commands just repeats those commands. At this point, you should be fairly proficient using the vi.

Most desktop Linux systems that are installed on your hard disk boot to a graphical login screen. So chances are that you will see the login screen associated with KDE or GNOME depending on which is the default on your Linux system.

When Linux starts up, it enters into what is referred as a run level or system state. Typically, a system set to run level 5 boots to a graphical login.
