# # Recording and Ripping Music

Writable CD-ROM drives are a standard device on computers. Once you had had to settle for a floppy disk (14.4MB) or a Zip disk (100MB) to store personal data, a CD-ROM burner lets you hold more than 600MB of data in a format that can be exchanged with most computers. On top of that, you can create CD music disks!

Both graphical and command-line tools exist for creating CDs on Linux. cdrecord command enables you to create audio and data CDs from the command line, writing to CD-recordable (CD-H) and CD-rewritable (CD-RW) drives. This command is discussed in the following section.

# # Creating an Audio CD with cdrecord

You can use cdrecord command to create either data or music CDs. You can create a data CD by setting up a separate file system and copying the image of that file to system. Creating an audio CD consists of selecting the audio tracks you want to copy and copying them all once to the CD.

This section focuses on cdrecord to create audio CDs. cdrecord can use audio files in .au, .wav, and .cdr formats, automatically translating them when necessary. If you use audio files in other formats, you can convert them to one of the supported formats by using the sox command (described previously in this chapter).

One way to create an audio CD is to use cdda2wav to extract (copy) music tracks to a directory and then use cdrecord to write them from the directory to the CD. Here's an example:
