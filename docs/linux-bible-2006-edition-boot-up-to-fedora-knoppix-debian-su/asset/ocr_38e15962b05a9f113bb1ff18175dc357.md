# Trying Out the Desktop

With the latest GNOME interface, menus are available from the top panel. By default, you won't have as many applications to choose from as you get with the default Fedora Core install, which should be expected since Ubuntu comes on one rather than four CDs.

However, the selection of desktop applications that you get with Ubuntu is good. The following list explains the categories of software you get on the Applications menu (and some what you don't get):

+   * Accessories—From this menu, select some basic desktop utilities that are part of the GNOME project. Choose Archive Manager to launch the File Roller application. File Roller provides a simple GUI interface that is useful for backing up personal files in a variety of archive and compression types. Text Editor starts the default text editor (so you don't have to use the unintuitive vi to edit plain text documents). Browser starts the Nautilus manager, which is the most common GNOME tool for navigating around the Linux system. Other Accessories include a Calculator, a Character Map (for mapping special characters), and Dictionary (for checking definitions of words).

+   * Games—Under the Games, you get a selection of about 17 GNOME games. Games are similar to those you would find on a Windows desktop (Mines, AisleRolitaire Solitaire, and FreeCell Solitaire are examples). There are also Tetris-like games (Gnometris) and board games (Mahjongg). One of the more demanding open sources (such as Tux Racer) or networked games (such as the BZFlag networked tank battle game).

+   * Graphics—The Ubuntu desktop includes the GIMP open source graphics manipulation application. It also includes the Thumb and Eye of GNOME image viewers. To import images from a scanner, Ubuntu includes the XImage scanning application. No document viewers are included here, such as Evince (which can be used to view PostScript and PDF files).

+   * Internet—Popular, standard open source Internet clients can be launched from this menu. Evolution (resource-intensive but full-featured Outlook-like email client) can be used for messaging and emailing your mail. Firefox is the web browser and GAIM is for instant messaging. The GNOME Torrent client can be used to download files (and share what you download with them). GnomeMeeting lets you do video conferencing over a network. The Terminal Server Client provides a free remote terminal and viewer desktop applications. XChat lets you use Internet Relay Chat (text-based) messaging.

+   * Office—A full set of OpenOffice office productivity applications are included with Ubuntu. Selections include OpenOffice Calc (spreadsheet), Draw (drawing and flowcharts), Impress (presentations), Math (formulas and equations), and Writer (word processing). OpenOffice.org Base lets you create and access a database.
