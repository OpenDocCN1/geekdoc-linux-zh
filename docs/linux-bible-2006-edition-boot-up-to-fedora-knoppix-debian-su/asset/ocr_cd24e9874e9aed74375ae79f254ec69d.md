# Using the KDE desktop in KNOOPPIX

KDE is the best desktop environment that comes with KNOOPPIX. You can change that at the boot prompt to use one of several window managers, or get a Gnopp disk instead to use the GNOME environments. But, as delivered, the desktop looks quite similar to what you see in Figure 11-1.

The KNOOPPIX version of KDE pretty matches the descriptions in Chapter 3, although there are a few items related to the KNOOPPIX KDE desktop that are worth noting:

+   * **Desktop icons** —To get information about KNOOPPIX, click the KNOOPPIX icon (choose a language, and then links to FAQs, Knoper.Net, and general KNOOPPIX information) or the LinuxTag icon (to read the licenses). There is also the requisite Trash icon.

+   * **Disk icons** — Any CD, DVD, floppy, or other removable media is displayed as an icon on the desktop. Of course, this includes the drive holding the KNOOPPIX disk, which you can get to get directly to such things as find boot images or KNOOPPIX documentation.
