# What’s So Great About Linux?

Leveraging work on UNIX and GNU projects helped get Linux up and running quickly. The culture of sharing in the open source community and adoption of a wide array of tools for communicating on the Internet has helped Linux to move quickly through infancy and adolescence to become a single operating system.

The simple commitment to code is probably the most powerful contributor to the growth of the open source software movement in general, and Linux in particular. That commitment has also encouraged from the kind of people who are willing to contribute to that community in all kinds of ways. The willingness of Linus to incorporate code from others in the Linux kernel has also been critical to the success of Linux.

# Features in Linux

If you have not used Linux, you should expect a few things to be different from using other operating systems. Here is a brief list of some Linux features that you might find:

+   **No constant rebooting**—Uptime is valued as a matter of pride (remember, Linux and other UNIX systems are most often used as servers, which are expected to stay 24/7). After the original installation, you can install or remove software without having to reboot your computer.

+   **Start/stop without interrupting others**—You can start and stop individual services (such as Web, file, and e-mail services) without rebooting or interrupting the work of any other users or features of the computer. In other words, you should not have to reboot your computer every time someone sneizes.
