# 444 Part III ♦ Choosing and Installing a Linux Distribution

+   Totem video player — As for multimedia support, GNOME continues to improve its Totem video player, which is based on the GStreamer multimedia framework. Playlists are not integrated into the Totem sidebar and DVD menus and subtitles are supported.

+   Application installation tool — After Ubuntu is installed, you can use the Add/Remove Programs from the System Administration menu to install new applications or rid of existing ones you don't want anymore.

Beyond these features, Ubuntu contains a broad range of open source applications suitable for the desktop. The leading one are OpenOffice.org (popular productivity suite), the GIMP (image manipulation software), Evolution (e-mail client), and Firefox (Web browser).

Many of the tools for configuring and setting preferences for the desktop that with the GNOME project fit well into the Ubuntu goals of accessibility and ease-of-use. GNOME's Removable Drives and Media Preferences window is set to automatically launch applications when you insert a CD or DVD or plug in a camera, printer, or scanner. The Assistive Technology enables users who is visually or physically impaired to use magnifiers and onscreen keyboards.

The GNOME Configuration Editor provides a graphical means of changing settings for the applications you launch from the desktop. In earlier versions of GNOME, you needed to edit text-based configuration files to change how desktop applications behave. Figure-17-1 shows an example of the GNOME tools just described.
