# 348 Part III ♦ Choosing and Installing a Linux Distribution

+   * Your whole, portable operating system — You don't have to carry a laptop or PC to make sure you have the software you need. Instead, you can use any PC that is available (with the exception of some unsupported hardware) and boot your own computing environment with a single CD or floppy. By customizing your own KNOOPPIX, you can add your data and pick choose applications as well.

+   * A tool for managing data on any PC — You can bypass the operating system and other software on any computer and the applications on KNOOPPIX disk to manage the data on that computer.

Of course, concepts are not exclusive to KNOOPPIX because you could conceptually doing the same with any boot floppy since the days of DOS (as well as any other bootable Linux). The difference is that KNOOPPIX does those things so well. It lets you over a computer, not with a tiny rescue disk capable of running a few obtuse commands, but with at full-scale desktop, server, and administrative tool operating system. With that in mind, here are some ways people are using KNOOPPIX.

+   * Showing off Linux — A demo can look poor when you have to spend an hour installing before you can make your point. With KNOOPPIX, it can take about 5 minutes from the time you tell your friend about Linux to the time you have a complete desktop system running on his PC. And in the process, you don't have to worry about anything on his computer because you don't even need to touch his hard disk.

+   * Testing a computer for Linux — If is capable of running Linux, you can boot KNOOPPIX. If it works, you can see what drivers were dealt with by your hardware (type Ismod from a shell) and then go add and install any Linux to the hard disk.

+   * Rescuing a computer or network — Many tools for tracking and fixing problems on Linux and Windows systems are included in KNOOPPIX. There is also a KNOOPPIX-STD edition that includes dozens tools for rescuing broken systems and tracking network problems (see www.knoppix-std.org).

+   * Taking over a broken server — If a Web server, file, or firewall has been hacked or otherwise broken, you might be able to use KNOOPPIX to safely save the data from a KNOOPPIX boot disk while you fix the problem.

+   * Doing anything want — For those of us who have gotten to using Linux, it's a pain to go somewhere and have to work or make a presentation on a computer that doesn't have the tools you need. By bringing the whole operating system, all your software tools and sometimes your data (with a customized CD, separate floppy, pen drive, or downloaded files), your computing environment can be the same wherever you go.

Now that you have some idea of what to do with KNOOPPIX, let's get started.
