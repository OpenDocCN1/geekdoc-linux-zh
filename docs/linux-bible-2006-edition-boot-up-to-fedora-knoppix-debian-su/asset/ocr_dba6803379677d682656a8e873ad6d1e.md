To format a page for typesetting, you can specify PostScript or HP LaserJet output. Direct the output to a file or to a printer. Here are a couple of examples:

```
$ groff -Tps /tmp/chown.1 > /tmp/chown.ps
$ groff -Tlj4 -man -1 /tmp/chown.1
```

The first example creates PostScript output (-Tps) and directs to a file called /tmp/chown.ps. That file can be read by a PostScript viewer (such as Ghostscript) or sent to a printer (pr /tmp/chown.ps). The next example creates HP LaserJet output (-Tlj4) and directs it to the default printer (-1 option).

# Creating a Man Page with Groff

Before HOWTOs and info files, man pages were the foundation for information about UNIX and UNIX-like systems. Each command, file, device, or other component had its own man page or was grouped on a man page with similar components. To create your own man page requires that you learn a few macros (in particular, macros). Figure 21-3 shows the source for a fictitious man page for a command called waycool.

```
# waycool.1 - the dwarf document source for the waycool command
# TH1 "1 May, 2002, GNU "Linux's Manual"
# NAME
 my cool command
# SYNOPSIS
# waycool [options]
# VF [FVagcoolVR | VR-abcf-VR] [ VR file ... VR ]
# SECTION
# This page describes the GNU manual source X,XX
# DESCRIPTION
# The |FVagcoolVR|
# waycool| is a cool command.
# NOTES
# This version of |FVagcoolVR| is better than the last one.
# OPTIONS
# All options with it.
# Run some options.
# LINKS
# waycool provides linksed to any referenced file
# only options that can change the content
# of a man page.
# PRINT
# Print the version number with the command.
# COMMENT
# If you don't like it, don't tell me. It will just hurt my feelings.
# ENVIRONMENT
# These environment variables are used by |FVagcoolVR|
# This sets the X display.
# PROLOGUE
# This contains the content of the manual database.
# FILES
# /usr/local/waycool - Directory containing waycool source.
# AUTHOR
# John Doe <john@example.com>
# REPORTING
# Report bugs to-example.com.
# COPYRIGHT
# Copyright (c) 2002 Free Software Foundation, Inc.
# This is free software: source for copying conditions. There is NO
# WARRANTY WITHOUT ANY FOR MERCHANTABILITY OR FITNESS FOR A PARTICULAR PURPOSE.
# ACKNOWLEDGEMENTS
# I'd like to thank all my friends.
```
