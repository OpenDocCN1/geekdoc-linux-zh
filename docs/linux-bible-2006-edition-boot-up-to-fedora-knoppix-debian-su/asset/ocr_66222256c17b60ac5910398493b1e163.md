# Playing Commercial Linux Games

To get your commercial games running in Linux, you should start from a site like the Linux Game Time (www.happypepenguin.org) or Linux Games' FAQ (http://icculus.org/igfqaf), which both provide information on commercial games that run in Linux and help in getting them to run. In most cases, you need to:

+   Purchase a legal copy of the game.

+   Go to a site that describes how to install, get patches for, and work around any issues related to playing the game in Linux.

Here are examples of a few commercial games that run in Linux:

+   **Duke 3D Atomic Edition for Linux (3D Realms)** — Multiplayer death match set in the future, where warriors face each other with awesome weapons and stuff. Includes a Linux installer. Got to Epic Games (www.epicgames.com) or Unreal Tournament site (www.unrealtournament.com) for the official information. See the Icculus.org site (http://icculus.org/duke3d/) for tips on getting it running.

+   **Unreal Tournament 2004 (Epic Games)** — Adds new maps, characters, vehicles, weapons, and modes of play to the 2003 edition.
