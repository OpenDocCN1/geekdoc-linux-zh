# # Special Purpose Bootables

As people learning about and playing with customizing bootable Linux distributions, I believe more special-purpose distributions will begin to emerge. The eMoviX distribution (part of the MoViX project) is an example of a distribution geared specifically towards a particular function (in that case, playing video content that you package with the distribution).

Here are examples:

+   **Gaming distributions**—More than 100 open source games are included on the Linux Live Game Project (http://tuxamers.altervista.org/ll1gp.php) In addition to games, the distribution offers other features of interest to gamers, such as NVIDIA drivers, an app for choosing random games, and music players.

Another distribution focusing on games is the GamesKNOOPPIX distribution (http://games-knopix.unix-ag.uni-kl.de). While the current version fits on a CD (around 700MB), a new updated version will fit on a DVD.

Refer to Chapter 23 for descriptions of many open source games available today.

+   **Windows applications**—The SLAX project (www.slax.org) is based on Slackware, offers some good examples of special-purpose bootable Linuxes. By including WINE, DoBox, and QEMU software, with an easy-to-use KDE interface, SLAX KillBill offers a special Linux system designed particularly to get Windows applications running in a bootable Linux. Figure 19-4 shows an example of the SLAX KillBill desktop with the Windows WINAMP application running under WINE.

The SLAX KillBill image is included on the CD with this book. Refer to Appendix A for information on copying and burning image to CD.

Using the features mentioned above, many Windows applications can run natively, without any modification. This distribution offers a great way to try different kinds of Windows compatibility and emulation software to see if you can move your application to Linux.
