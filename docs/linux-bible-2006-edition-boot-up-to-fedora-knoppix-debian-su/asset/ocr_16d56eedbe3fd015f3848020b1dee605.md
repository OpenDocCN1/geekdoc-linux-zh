+   * Improve tab browsing (Tabbrowser Preferences) — Although Firefox already gives you some nice features for using tabs to keep multiple Web pages open in the same Firefox window, Tabbrowser Preferences takes those features a step further. Select Edit ✎ Tabbed Browsing. The Tabbed Browsing lets you refine your work in Firefox. You can set how motion selects tabs (such as mouse-over as opposed to clicking), puts tabs on the bottom of the tab, or choose whether or not to load the home page in a new tab.

+   * Watch your weather (ForecastFox) — With Firefox, the latest for any region you select can be just a click in Firefox. After you install ForecastFox and restart Firefox, a pop-up window tells you configure Firefox options. Select at least Find Code, to choose the area you want to keep up on weather. Save your options and a weather icon appears in the lower-right corner of Firefox. Move your mouse over that icon to see a view of the current weather. Double-click the icon to have a more detailed weather report displayed from www.weather.com.

+   * Check internet speed (Bandwidth Test) — The Bandwidth Tester gives you a sense of how fast you are able to download over your Internet connection. The tester downloads five files, based on the type of connection you indicate, and tells you the speed at which data was downloaded.

# Changing Firefox Themes

There are several themes available for changing the look and feel of your Firefox window. From the Mozilla update site (http://addons.mozilla.org), select Firefox Themes. When you download a theme for Firefox, it knows that it is a Firefox theme and, on the download window, gives you the option to install the theme by clicking the Use button.

To change a theme later or get more Themes, select Tools ✎ Themes. After you have installed a new theme and selected it as your current theme, you need to restart Firefox for the new theme to take effect.
