To create a table in a Groff document, use the .TS and .TE macros of the tbl preprocessor. The following is an example of the markup used to produce a simple table:

```
.TS
center, box, tab(:);
cs s s
c | c | c
| 1 | 1.
Mergers and Acquisitions Team
=
Employee:Title:Location
Jones, James:Manager:New York Office
Smith, Charles:Sales Manager:Los Angeles Office
Taylor, Sarah:R&D Manager:New York Office
Walters, Mark:Information Systems Manager:Salt City Office
Zuk, Mike:Distribution Manager:Portland Office
.TE
```

The .TS macro starts the table, and the line indicates that the table should be centered on the page (center) and surrounded by a line box and a colon will be used to separate the data cells (Tab(:)). The third line shows that the header should be centered in the box (|) and span across the two cells (s). The fourth line shows that the header of each cell should be centered (| c | c) and the fifth line indicates that the data cells that follow should be justified (| l | l |).

> There must be a period at the end of the table definition line. In this example, after the | | | . line. If the period is not there, tbl tries to interpret the text as of table definition, fails, and stops the table; the does not print.

The rest of the information in the table is the data. Note that the table separators are colon characters (:). End the table with a .TE macro. If the table were a memo called memotbl.mm, tbl could process the memo and send it to the printer using the following:

```
$ groff -Tps -1 -mm -t memotbl.mm
```

Data between .TS and .TE macros are interpreted as tables. Figure 21-8 displays the output from this example.
