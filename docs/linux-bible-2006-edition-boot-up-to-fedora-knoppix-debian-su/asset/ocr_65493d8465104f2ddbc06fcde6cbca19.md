# Chapter 17 \ Running Ubuntu Linux 443

Don't expect the Ubuntu installer to look like installers for Red Hat or SUSE systems. There are no pretty graphics and no point-and-click with the mouse. The Ubuntu installer is text-based, although it does lead you through fairly simple configuration questions. It also makes some choices for you, so novice users not have to wreck their brains for answers they may not have.(For example, a server or desktop installer gives you all packages for those install types, without giving you the option to customize the install further.)

While there are many changes compared to the Ubuntu installer, the ability to create file systems based on Logical Volume Management (LVM) is the most significant feature in the latest version of Ubuntu. By creating LVM file systems, you are able to add or subtract disk space to each LVM partition. So, for example, if you have a /var partition that runs out of disk space, you can add a physical hard disk to your computer. You can then add the additional space from that disk to /var partition (without having to copy data off, the partition, creates a larger partition, and copy the data back).

Other neat ease-of-use features are built into the Ubuntu installer. For example, if you are not sure which keyboard you have, you have the option to type a few keys (prompted by the installer) and have to try to figure out the type of keyboard you. You also have the option to resize a partition during installation (a very handy feature if you have a hard disk with one big Windows partition that you't want to completely delete).

# Ubuntu as a Desktop

As promised, Ubuntu 5.1 contains the latest desktop features available at the time it was released. Along with the latest desktop components you would expect (GNOME, OpenOffice, and so on), Ubuntu 5.1 also includes improved features for installing applications. Here are some of the features in Ubuntu 5.1:

+   GNOME Desktop—GNOME 2.12 provides the desktop environment for release of Ubuntu. End users will find a new theme called ClearLooks, which provides a very clean, professional look.

+   If you used earlier versions of GNOME, you'll notice that there are two panels (one top, one bottom) instead of one that at the bottom of the screen. This gives you more room for menus, application launchers, and applets without taking any more screen space. With this release, rotated menus have been added, so you can have vertical panels (along the sides) instead of panels on the top and bottom.

+   Nautilus file manager—The Nautilus file manager, which comes with GNOME, is constantly being enhanced. For this release, look for changes to drag-and-drop (drag text from a document to Nautilus and it creates a new text document). Also, when you view files in List View, you can now see files as well as folders (by clicking a down arrow to a folder).
