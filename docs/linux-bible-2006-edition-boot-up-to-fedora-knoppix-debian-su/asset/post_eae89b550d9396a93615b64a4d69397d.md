## Managing Files with the Konqueror File Manager

The Konqueror file manager helps elevate the KDE environment from just another window manager to an integrated desktop that competes with GUIs from Apple Computing or Microsoft. The features of Konqueror rival those offered by their user-friendly desktop systems. Figure 3-4 shows an example of the Konqueror file manager in Fedora Core.

Konqueror's greatest strengths over earlier file managers include the:

- Network desktop——If your computer is connected to the Internet or a LAN, features built into Konqueror enable you to create links to files (using FTP) and Web pages (using HTTP) on the network and open them in the Konqueror window. Those links can appear as file icons in a Konqueror window or on the desktop. also supports WebDAV, which can be configured to allow local read and write access to remote folders (which is a great tool if you are maintaining a Web server).

- Web browser interface — The Konqueror interface works with Mozilla, Internet Explorer, or other Web browsers when you select files, directories, and Web content. Konqueror is based on a browser model, a single click opens a file, a link to a network resource, or an application program. You can also enable Java by typing Web-style addresses in the Location box. The rendering engine used by Konqueror, called KHTML, is also used by Safari (the popular Web browser for Apple Mac OS systems).

Web pages contain Java and JavaScript content run by default in Konqueror. To check that Java and JavaScript are turned on, choose Settings ⮕ Configure Konqueror. From the Settings window, click Java & JavaScript and select the Java tab. To enable Java, choose Enable Java globally and click Apply. Repeat for JavaScript.

- File types and MIME types — If you want a particular type of file to always be launched by a particular application, you can choose that yourself. Konqueror already has dozens of MIME types defined so that particular file and data types can be automatically detected and opened in the correct application. There are MIME types defined for audio, image, text, video, and a variety of other content.

Of course, you can also perform standard file manager functions with Konqueror. For example, you can manipulate files by using features such as select, move, cut, paste, and delete; search directories for files; create new items, folders, and links, to name a few; view histories of the files and Web sites you have opened; and create bookmarks.

## Working with Files

Because most of the ways of working with files in Konqueror are quite intuitive (by intention), Table 3-3 provides a quick rundown of how to do basic file manipulation.

| Task | Action |
| --- | --- |
| Open file | Double-click the file. It will open right in the Konqueror window, if possible, or in the default application set for the file type. |
| Open file with a specific application | Right-click a data file, choose With from the pop-menu, and then select one of the available applications to open the file. The applications listed are those that are set up for the file. |
| Delete a file | Right-click the file and select Delete. Are asked if you really want to delete it. Click Yes to permanently delete it. |
| Copy a file | Right-click the file and select Copy. This copies the file to your clipboard. After that, you can paste it to another folder. Click the Klipper (clipboard) icon in the panel to see a list of copied files. Klipper holds the seven most recently copied files, by default. Click the Klipper icon and select Configure Klipper to change the number of copied files. |
| Paste a file | Right-click the file and select Copy. (Wait, context implies Paste) Right-click the file and select Paste. |
| Link a file | Drag-and-drop from one folder to create a link. |
| Move a file | Right-click the file and select Move. |

There are also several features for viewing information about the files in Konqueror:

- View quick information — Positioning the mouse over the file displays its filename, size, and type.
- View hidden files — Selecting Show Hidden Files enables you to see files that begin with a dot. Dot files tend to be used for configuration and don't need to be viewed in your daily work.

- View system tree — Selecting View Mode provides a tree view of folders above the current folder. You can click a folder in the tree to jump directly to that folder. Multicolumn, Detailed List, and Text views are all available.
- Change icon view — Select View Icon Size, and then choose Large, Medium, or Small to select the size of the icons that are displayed in the window. You can also choose Default Size to return to the default icon size (which is medium, unless you have changed it through Configure Konqueror).

To act on a group of files at the same time, there are four actions you can take. Choose Edit Selection ❧ Select. A pop-up window lets you match all or any group of documents by typing letters, numbers, and wildcard characters. Or, you can select a group of files by clicking in an open area of the folder and dragging the pointer across the files you want to select. All files within the box will be highlighted. When files are highlighted, you can move, copy, or delete the files as described earlier.

## Searching for Files

If you are looking for a particular file or folder, you can use the Konqueror find feature. To open a window to search for a file, open a folder (such as /home/chris) and choose Tools ❧ Find File; The find box appears in your Konqueror window. You can also start the kfind window by typing kfind from a Terminal.
