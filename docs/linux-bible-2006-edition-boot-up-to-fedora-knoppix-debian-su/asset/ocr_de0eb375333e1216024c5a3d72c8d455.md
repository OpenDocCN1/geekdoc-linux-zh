# Using Tabbed Browsing

If you switch back and forth among several Web pages, you can use the tabbed browsing feature to hold multiple pages in your browser window at once. You can open a new tab for browsing by simply selecting File: Navigator Tab or by pressing Ctrl+T. You can also tailor how tabbed browsing works from a Web page or from the Location box. Here's:

+   1. Click Edit: Preferences. The Preferences window appears.
2. Click Tabbed Browsing under the Navigator category.
3. Select one or both of these boxes, depending on how you want to use tabbed browsing:

+   * Middle-click, Ctrl+click or Ctrl+Enter on a link — Selecting this box lets you open a link to another Web page in a new tab. For this work, click the middle button on a link, hold the Ctrl key while you click the left mouse button on a link, or (with the highlighted) hold the Ctrl key and press Enter.
* Ctrl+Enter in the Location bar — After you type a Web address (URL) into the Location box, hold the Ctrl key and press Enter to open the new page in a tab.

+   4. Click OK. You can begin using the tabbed browser feature.

A tab for each tagged page appears at the top of the Navigator pane. To close a tab, create a new tab, bookmark a group of tabs, or reload tabs, right-click one of the tabs and choose the function you want from the drop-down menu.

One of the easiest ways to open a link in a tab is to right-click over a link on HTML page. Select the Open Link in New Tab choice.
