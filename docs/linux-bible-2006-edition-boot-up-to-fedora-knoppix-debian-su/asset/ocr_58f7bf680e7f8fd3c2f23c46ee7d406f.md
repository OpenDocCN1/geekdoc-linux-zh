# Chapter 7 + Installing Linux 265

```
@  kernel /vmlinuz-version root=/dev/hda6
@ initrd /initrd-version.img
@boot=/dev/hda
default=0
timeout=10
splashimage=(hd0,4)/grub/splash.xpm.gz
title Fedora Linux (2.6.13-1.1526_FC4)
troot (hd0,4)
kernel /vmlinuz-2.6.13-1.1526_FC4 root=LABEL=
initrd /initrd-2.6.13-1.1526_FC4.img
```

```
title Windows XP
rootnotify (hd0,0)
chainloader +1
```

The default=0 line indicates the first partition in this list (in this case Fedora Linux) will be the one that is booted by default. The timeout=10 causes GRUB to pause for 10 seconds before booting the partition. (How much time you have left to edit the boot line, or press arrow keys to select a different operating system to boot.)

The splashimage line looks the fifth partition on the first disk (in this case /dev/hd5, which is the /boot partition). GRUB loads splash.xpm.gz as the image on the splash screen (/boot/grub/splash.xpm.gz). The splash screen appears as the background of the boot screen.

> GRUB indicates disk partitions using the following notation: (hd0,0), the first number represents the disk, and the second is the partition on that disk. hd0,4 (hd0,1) is the second partition on the first disk (O).

The two bootable partitions in this example are Fedora and Windows XP. The title lines for each of those partitions are followed by the name that appears on the boot screen to represent each partition.

For the Fedora Linux system, the root line indicates the location of the boot partition as the second partition on the first disk. So, to find the bootable kernel (vmlinuz-2.6.13-1.1526_FC4) and the initrd RAM boot image that is loaded (initrd-2.6.13-1.1526_FC4.img), GRUB looks in the root of hd0,4 (which is represented by /dev/hd5 and is mounted as /boot). Other options on the kernel line set the read-only initially (ro) and set the root file system to /dev/hd6.

For the Windows XP partition, the rootnotify line indicates that GRUB should try to mount the partition. In this case, Windows XP is on the first partition of the first disk (hd0,0) or /dev/hd1. Instead of mounting the partition and passing options to the new operating system, the chainloader +1 indicates to handle control the boot of the operating system to another boot loader. The +1 indicates that the first sector of the partition is used as the boot loader.
