There are many text-based mail programs for reading, sending, and working with your mail. Many of these programs have been around for a long time, so they are full of features and been well debugged. As a group, however, they are not very intuitive.

![](bbox=[0.168, 0.212, 0.831, 0.613])

Most of these programs use the value of $MAIL environment for your local mailbox. Usually, that location is /var/spool/mail/user, where user is your username. If you use Mozilla Mail but want to try out of the text-based e-clients, you can set your MAIL so that it points to your Mozilla mailbox. This will enable you to use either Mozilla Mail or a text-based mail program. Add the following line to your startup files:

```
export MAIL=$HOME/.mozilla/default/*/Mail/hostname/Inbox
```

If you use Mozilla Mail for text, set this variable temporarily to try out of these mail programs.
