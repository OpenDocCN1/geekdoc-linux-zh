# 486 Part III ♦ Choosing and Installing a Linux Distribution

A bootable Linux distribution can offer you some amazing opportunities. On a removable medium, you can take with you:

+   * Your favorite operating system
* As many of your favorite applications as fit on your medium
* As much of your music, video, documents or other data as will fit on your medium
* A fully customized set of features and configuration settings

In other words, if you are willing to build your own custom bootable distribution, the concept of bootable Linux distributions can be extended any way you like. Your bootable business card (mini-CD) or CD can carry all the applications you are used to having, so you can use them anywhere from a handy PC. It can also hold your presentations, documents, mail-server, address book, favorite backgrounds and screensavers, personal photos, and any other kind of data you want

Most bootable Linux systems are based on established Linux distributions that are typically installed to hard disk. For example, KNOPIX is based on Debian, as is Damn Small Linux. SLAX is based on Slackware. The System Rescue CD is based on Gentoo. So it, for example, you want to choose a bootable Linux to customize as a personal desktop or server, you might choose one based a Linux system that you are familiar.

More than that distribution it comes from, however, you will choose a bootable Linux system because it contains a specialized set of tools (such as a security toolkit) or is built to provide a specific function (such as playing multimedia-dia). For example, tools that are included with the Auditor CD are focused on securing, checking, and recovering computers and networks. Auditor’s menus are organized by the security tools it provides. Components in MovIX include those geared toward playing movies, music, and images.
