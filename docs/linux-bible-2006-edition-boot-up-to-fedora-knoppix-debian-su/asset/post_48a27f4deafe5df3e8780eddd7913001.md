## Receiving, Composing, and Sending E-Mail

Evolution offers a full set of features for sending, receiving, and managing your e-mail. Here's a quick rundown of these tasks:

- Read e-mail — Click Inbox in the left column. Your messages appear to the right. Message headers are in the upper right; double-click a message to display it in a separate window.

- Delete e-mail — After you have read a message, select it and press the Delete key. View ⇩ Hide Messages to toggle whether you can see deleted messages. Check Actions ↷ Expunge to permanently remove all marked for deletion in the current folder.

- Send and receive — Click the Send/Receive button to send any e-mail waiting for you at your mail. You may not need to do this if Evolution is configured to download your messages every few minutes. Check Tools ✎ Settings, and then double-click on your mail account. The Receiving Options tab identifies if automatic mail checking is being done.

- Compose e-mail — Click New ↣ Compose a Message window appears. Type your recipient's e-mail address, enter a subject line, and fill in the body of the message. Click Send when you are finished. Buttons on the Compose window enable you to add attachments, copy and paste text, choose a format (HTML or plain text), and send the message (if you have set appropriate keys).

- Use address books — Click the Contacts button to see a list of addresses, and other contact information for the people in your address book. When you compose a message, click the To or CC buttons to select addresses from the book to add recipients for your message.

- Create folders — If you like to keep old messages, you may want to save them outside your Inbox (so it won't get too junked). Create a folder to keep them, right-click on the Inbox and select New Folder. You can choose to store the new folder as a subfolder to any existing folder. Type a folder name and click OK.

- Move messages—With new folders created, you can easily move messages from your Inbox to another folder. The easiest way is to simply drag-and-drop each message (or a set of selected messages) from the message page to the new folder.

- Search messages—Type a keyword in the search box over your e-mail page and select whether to search your message subject lines, sender, recipient, or message body. Click Find Now to search for the keyword. After viewing the messages, click Clear to have the other messages reappear.

## Managing E-Mail with Virtual Folders

Managing amounts of e-mail can become difficult when the messages you want to refer to several folders, dates, or senders. With virtual folders (vFolders), you can identify criteria to group together messages from all mail folders so you can deal with them in one vFolder. Here's a procedure for creating a vFolder:

1. With Evolution to open read mail (click Inbox to get there), select File > New Folder. Create New Folder pop-up appears.
2. Select vFolders, type a folder name (like FromJohn), and select OK. A New vFolder pop-up appears.
3. Click Add and select criteria for including a message in your vFolder. You can search to see if it is the sender, recipient, message body, or other part of the message contains or doesn't contain the string you type in the next box. Click Add if you want to add more criteria. own4. If you want to search only specific folders, click Add in the vFolder Sources and select the folder you want to search. You can repeat this to more than one. Otherwise, you can select to search all local folders, all active remote folders, or all local and active remote folders. Then click OK.
5. Make sure your folder is visible (View > Folder). The folder you just created is listed under the vFolders heading. Click that folder to see the messages gathered with this action.

At this point, you can work with the messages you gathered in the vFolder. Although it appears that there are multiple versions of each message across your mail folders, there is only one copy of each message.

## Getting Thunderbird

One source e-mail client got a lot of attention before it reached version. Thunderbird, from Mozilla.org, is being touted as next generation. With version available, Thunderbird has quickly become one of the most popular.

Because Thunderbird is not delivered with every Linux distribution yet, you may download to try it—go to www.mozilla.org/products/thunderbird. Or, you can find out if there is a package available for your distribution (for example, there's a package included with Fedora Core).

After Thunderbird is installed, look for a Thunderbird menu on your panel (usually under an Internet submenu). As an alternative, you can just run the thunderbird command from a terminal window. Figure 22-4 shows an example of Mozilla Thunderbird.

## Working with Text-Based E-Mail Readers

There are many text-based mail programs for reading, sending, and working with your mail. Many of these programs have been around for a long time, so they are full of features and been well debugged. As a group, however, they are not very intuitive.

The first text-based mail clients could be configured quite simply. Mail clients such as mut, or pine were often run with the user logged in to the computer acting as the mail server. instead of downloading the messages, using POP3 or IMAP, the mail client would simply open the mailbox (often under the user's name in /var/spool/mail) and begin working with mail.

Most of these programs use the value of $MAIL environment for your local mailbox. Usually, that location is /var/spool/mail/user, where user is your username. If you use Mozilla Mail but want to try out of the text-based e-clients, you can set your MAIL so that it points to your Mozilla mailbox. This will enable you to use either Mozilla Mail or a text-based mail program. Add the following line to your startup files:

```
export MAIL=$HOME/.mozilla/default/*/Mail/hostname/Inbox
```

If you use Mozilla Mail for text, set this variable temporarily to try out of these mail programs.
