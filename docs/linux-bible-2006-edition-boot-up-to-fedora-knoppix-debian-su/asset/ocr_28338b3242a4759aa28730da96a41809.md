# 250 Part III ♦ Choosing and Installing a Linux Distribution

+   * RAM You should have at least 64MB of RAM to install most Linux distributions and run it in text mode. Slackware might run on 8MB of RAM, 16MB is considered the minimum. If you are running in graphical mode, you will probably need at least 192MB. The recommended RAM for graphical mode is Fedora 256MB. A GNOME environment generally requires a bit less memory to run a KDE environment. If you are using a more streamlined graphical system (that runs X with a small window manager, such as Blackbox), you might get by as little as 32MB. In that case, you might try Dny Small Linux or Slackware.

+   * CD and drive — You need to be able to boot up the installation process from a DVD or CD. If you can't boot from a DVD or CD, there are ways to start the installation from a hard disk or using a PXE install. Some distributions, such as Slackware or SUSE use floppy disks to boot. Once the installation is booted, the software sometimes be retrieved from different locations (over the network or from hard disk, for example).

+   * Network card — If you are installing one of the distributions with which we have a scaled-down boot disk, you might need to have an Ethernet card to install the software you need over the network. A dialup connection won't work for network installs. You don't have to be connected to the Ethernet necessarily to do a network install. Some people will download the necessary software packages to a computer on their LAN, and then use that as an installer.

If you're not sure about computer hardware, there are a few ways to check what you have. If you are running Windows, the System Properties window can show you the processor you have, as well as the amount of RAM that's installed. As an alternative, you can use KNOPPIX and let it detect and report to you the hardware. run lspci, lsmod, and dmseg commands in Linux to view information about your computer hardware.

# Upgrading or Installing from Scratch

If you already have a version of Linux you are installing on your computer, many Linux distributions offer an upgrade option. This lets you upgrade packages, for example, from version 1 to version 2. Here are a few general rules before performing an upgrade:

+   * There is a possibility that after you finish your upgrade, the operating system won't boot. It's always a good idea to back up any critical data and configuration files (in /etc) before doing any major changes to your operating system.

+   * Remove extra packages — If there are software packages you don't need, remove them before you do an upgrade. Upgrade processes typically upgrade only those packages that are on your system. Upgrades generally do more checking and comparing than clean installs do, so any package you can remove saves time during the upgrade process.
