## Puppy Linux

The other heavyweight contender for lightweight Linux bootables is Puppy Linux (www.goose.com/puppy). The Puppy Linux image is about 61MB. So, for example, you can install and boot Puppy Linux on a 128MB flash drive and still have another 60+MB of space for data.

Puppy Linux is built for small, size, and ease of use. To emphasize the ease-of-use aspects, Puppy Linux tends to lean more toward open and closed than secure. Here are some examples:

- **Writes to your hard disk**—Before you start using Puppy Linux on someone's computer, know that if it finds a hard disk when it boots up, you must mount that disk read/write and make pup001 file to the root of the free usable partition. It will then find partition on /mnt/home and leave it writable during your Linux session. Changes you make during your Linux session are stored in that pup001 file. So, if you don't need to enter keyboard, mouse, or video card information again when you boot from that. Most bootable Linux systems do not automatically write to a hard partition if it finds. You should decide how secure you feel with that.

- **Loads to RAM**—When you load Puppy Linux, by default, run in RAM. So you should get excellent performance, provided your machine has at least 128MB of RAM available. With Puppy Linux in RAM, that also frees up your CD/DVD drive. So you can pop in a CD or DVD and play it without disturbing the Puppy Linux system.

- **Set no firewall rules**—Because Puppy Linux uses a Linux 2.4 kernel, iptables firewall is built in. However, no firewall rules are set by default. So, if you are thinking of using Linux to offer some services (Web server, mail server, and so on), keep in mind that it is intended for a desktop system and not to securely offer services.

Every major category of applications is represented in Puppy Linux. For word processing, you have abiword. You can play music with GPlayer and video with Gxine. The Mozilla suite is included for Web browsing, mail, news, and HTML editing. For internet client applications, you have GAIM (instant messaging), FTP, and Sylpheed mail/news client, as well as remote login tools (secure and telnet).

Other personal productivity tools that come with Puppy Linux include calendar (Xcalendar and Mozilla Calendar), spreadsheet (Planmaker), contacts (Gabby and Mozilla Addressbook), finance manager (Xfinans), and personal information (DidiWiki). Most of these applications are lightweight, but serviceable, applications.

Puppy Linux is a relative newcomer to bootable Linuxes, but it seems to have a good following and fairly active forums and development effort. Tools for configuring your network and detecting devices seem to work better in KNOOPPIX derivatives, such as Damn Small Linux, at the moment. But for these areas to improve as Puppy Linux develops.

## Special Purpose Bootables

As people learning about and playing with customizing bootable Linux distributions, I believe more special-purpose distributions will begin to emerge. The eMoviX distribution (part of the MoViX project) is an example of a distribution geared specifically towards a particular function (in that case, playing video content that you package with the distribution).

Here are examples:

- **Gaming distributions**—More than 100 open source games are included on the Linux Live Game Project (http://tuxamers.altervista.org/ll1gp.php). In addition to games, the distribution offers other features of interest to gamers, such as NVIDIA drivers, an app for choosing random games, and music players.

Another distribution focusing on games is the GamesKNOOPPIX distribution (http://games-knopix.unix-ag.uni-kl.de). While the current version fits on a CD (around 700MB), a new updated version will fit on a DVD.

Refer to Chapter 23 for descriptions of many open source games available today.

- **Windows applications**—The SLAX project (www.slax.org) is based on Slackware, offers some good examples of special-purpose bootable Linuxes. By including WINE, DoBox, and QEMU software, with an easy-to-use KDE interface, SLAX KillBill offers a special Linux system designed particularly to get Windows applications running in a bootable Linux. Figure 19-4 shows an example of the SLAX KillBill desktop with the Windows WINAMP application running under WINE.

The SLAX KillBill image is included on the CD with this book. Refer to Appendix A for information on copying and burning image to CD.

Using the features mentioned above, many Windows applications can run natively, without any modification. This distribution offers a great way to try different kinds of Windows compatibility and emulation software to see if you can move your application to Linux.

- **Firewall distributions**—A firewall is a very good application for a bootable Linux distribution. Using most any PC and a CD (or a floppy disk) Linux distributions, you can protect your PC from LAN intruders and provide a route for multiple computers to the Internet. Popular firewall distributions include Devil-Linux (www.devil-linux.org) and Sentry Firewall CD (www.sentryfirewall.com).

There are also Linux distributions that are suited for education. There are many Linux distributions that are suited to run as server.

- **Damn Linux (DSL)**—This is the distribution I have used the most. In fact, the CD that is a remastered of DSL includes software.
