# 488 Part III ♦ Choosing and Installing a Linux Distribution

a wide range of tools for monitoring Linux or Windows systems, scanning for viruses, debugging networks, and doing forensics.

Most Linux systems will boot up on your network if a DHCP server is on the line. (If there isn't one, many include the netconfig utility to you set up a wired Ethernet card manually) So, with your computer booted and connected to a network with a bootable Linux, you could proceed to check, fix, back up, and over-control the local computer as well as other computers on your network.

Here are suggestions of the ways you can use most Linux security/rescue CDs, based on open source software that many of these distributions contain:

+   **Assessing vulnerabilities** — Tools for assessing vulnerabilities of your computer include those let you scan Windows SMB folders (nbt), CGI scripts (nikto and screamingCobra), and the computer's ports (nmap), as well as scan for viruses (clamAV). You can also check if someone has used a rootkit to replace critical system files (chkroot), or you can use a scanner dispatch (wscan) to test any exploit you like across lots of machines.

+   **Running forensics on Windows machines** — If you believe a Windows system has been compromised, there are many tools you can use to find and correct it. Boot a security CD, such as KNOPPIX-STD, and you can recover Internet cookies (galletta), check Outlook Express dbx files to mbox (readbx and reread), check system integrity (ftimes), and check the Windows recycle bin (riflu).

+   **Recovering data** — If a Windows or other operating system won't boot or is otherwise impaired, you can get data off. You can copy files over the network (using rsync, scp, or others) or back up to local CD or tape (cpio, or others). You can selectively recover file types from disk images (foremost) or recover lost partitions (testdisk)

+   **Dealing with intruders** — Tools such as Snort (www.snort.org) let you analyze traffic in real time, as well as log and analyze data as attacks happen. Honepots let you watch intruders moves as honeypots let intruders believe they've compromised your system. Honepots-related Linux tools include honeyd (http://honeyd.org), thp and thwart (www.alinista.org/thp). Kill zombies from DDoS attacks with zz.

+   **Using analyzing encryption techniques** — Many tools enable you to use encryption techniques to protect your data and find when others have tried to compromise it. GNP privacy guard (gpg) is used for verifying the authenticity of computers and people. For setting up virtual private networks, there are tunnel and super-freeSWAN VPNs (giftshuffle, stegbrak, and stegdetect) and using (mp3stego) that contain hidden messages from a technique called steganography.
