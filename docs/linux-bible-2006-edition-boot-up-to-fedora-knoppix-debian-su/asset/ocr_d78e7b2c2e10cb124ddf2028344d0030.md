# Other Installation Options

While the Click-N-Run application is the quickest means of managing software on your Linspired, it may not meet every user's needs. With this in mind, there are a couple of other options for managing software on your Linspired:

+   - DEB packages can be used to manually install software. Open a Terminal window and run the command `dpkg -i filename`.

For more information on using the dpkg installation utility, check the Debian FAQ at http://debian.org/doc/FAQ/ch-pkgtools.html.

+   - RPM packages can be used if you make use of an installation package verter as Alien (http://kitten.net/programs/alien/). This method should be employed only if you have no more convenient options. Package conversion is not a sure thing and unexpected consequences can arise from using converted packages.

+   - Apt-get, a tool for managing software packages, can be used, as its graphical derivative Synaptic. It offers the same functionality as CNR, but without the ease of use.

See Chapter 9 for a thorough description of Debian's apt-get utility and related software management tools.

+   - Software not available in .DEB or RPM formats can be installed from installer scripts (.sh) or by compiling source code from tarball. A tarball is an archive of files with a special utility (named tar) and commonly pressed using utility, gzip. Source code distributions are often packaged as gzipped tarballs. Compiling from source enables you to do the things the old way if needed and to exercise granular control of unpacked software. This functionality helps keep Linspired a flexible platform for running a variety of software.

# Linspired Support and Software

Support is one of the nicest benefits of being a Linspired consumer. The level of support from Linspired is not particularly expensive, especially when compared to other Linux communities. It is, however, very easy to find information on the support site, and contact with users willing to help you out should you have any questions or need help using Linspired or most of the Click-N-Run applications (although most application support is unofficial).
