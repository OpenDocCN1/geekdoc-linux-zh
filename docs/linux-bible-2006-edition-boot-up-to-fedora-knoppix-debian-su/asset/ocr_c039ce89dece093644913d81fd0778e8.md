# Return to Castle Wolfenstein

You battle with the Allies to destroy the Third Reich in Return to Castle Wolfenstein, which mixes World War II with creatures conjured up by Nazi scientists. It's based on the Quake III Arena engine and offers single-player mode as well as team-based multiplayer mode.

If you purchase Castle Wolfenstein for Linux, you actually get the Windows version with an extra Linux installer. If you already have the Windows version, you can download the Linux installer and follow some instructions to get it running. I downloaded the installed called wolf-linux-1.31.x86.run from www.idsoftware.com/games/wolfenstein/rtw/index.php?game_section=updates. The INSTALL file (in /usr/local/games/wolfenstein) describes which files you need to copy from the Windows CD.

To get a demo of Return to Castle Wolfenstein, go to www.idsoftware.com/games/wolfenstein/rtw/index.php?game_section=overview. Both single-player and multiplayer demos are available.

> You need an NVIDIA card to run Return to Castle Wolfenstein.

# Playing TransGaming and Cdega Games

TransGaming Technologies brings to Linux some of the most popular games that currently run on the Windows platforms. Working with WINE developers, TransGaming is developing Cdega, which enables you to run many different games on Linux that were originally developed for Windows.
