# 694 Part V ♦ Running Servers

If CUPS is already running on your computer, you can immediately use CUPS Web-based administration from your Web browser. To see if CUPS is running and start up your printers, open a Web browser on the local computer and type the following into its location box:

```
http://localhost:631/admin
```

You are prompted for a valid login name and password. Type the root login name and the root user's password, then click OK. A screen similar to the one shown in Figure 26-1.

![](bbox=[0.17, 0.318, 0.722, 0.603])

**Figure 26-1:** CUPS provides a Web-based administration tool.

By default, Web-based CUPS administration is available only from the local host. To access Web-based CUPS administration from another computer, you must change the /etc/cups/cupsd.conf file. As recommended in the text of this file, you should limit access to CUPS administration from the Web. The following example includes an Allow line to permit access from a host IP address 10.0.0.5 (you must also add the Listen 127.0.0.1:631 line to listen outside your local host, as described a bit later).

```
<Location>
AuthType Basic
AuthClass System
Order Deny, Allow
Deny From All
Allow From 127.0.0.1
Allow From 10.0.0.5
</Location>
```
