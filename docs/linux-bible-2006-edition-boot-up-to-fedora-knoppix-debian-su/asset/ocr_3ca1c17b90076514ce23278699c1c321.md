# 204 Part II  Run the Show

Linux systems make use of log-viewing tools, which come with the desktop environment (such as GNOME) or as a command you can execute from a Terminal window. Red Hat Linux comes with a System Logs window (systemlogviewer command) that you can use to view and search critical system log files from the GUI. To open the System Logs window from the main desktop menu in RHEL, select System Logs. Figure 6-1 shows an example of the System Logs.

![](bbox=[0.181, 0.273, 0.658, 0.553])

Figure 6-1: Display log files in the System Logs window.

For a particular log file, click the log name in the left column. If you are looking for a particular message or problem, type a keyword into the Filter Box and click Filter. Cases matters, only lines containing that keyword are displayed. Searching for Mem will not find mem when you use the filter. Click Reset to display the whole file again.

Table 6-2 contains a listing of log files displayed in the System Logs window, with other files in the /var/log directory that may interest you. Many of these files are included with most Linux systems and are only viewable by root. Also, some Linux systems may use different file or directory names (for example, /etc/apache on some Linux systems).

Because these logs are stored in plain text files you can view them using any text editor (such as vi or edit) or paging command (such as the less command).
