# # Media

The DVD and CD that accompany Linux Bible 2006 Edition contain 12 Linux distributions. Two of those distributions can be booted directly from the DVD and run live (KNOPPIX) or installed to your hard disk (Fedora Core). Two can be booted and run live from the CD (Damn Small Linux) or installed to your hard disk (Debian). The others can be burned to a CD-ROM from one of those media and installed separately.

General information on installing or booting the various distributions on the DVD is in Chapter 7. Specific instructions for using and installing each Linux distribution are contained in the other chapters in Part III (see Chapters 8 through 19).
