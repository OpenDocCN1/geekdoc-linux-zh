# Loading Modules

You can load any module that has been compiled and installed (to the /lib/modules directory) into your running kernel using the modprobe command. A reason for loading a module is to use it temporarily (such as loading a module to support a special file system on a floppy you want to access). Another reason is to identify a module that is used by a particular piece of hardware that could not be autodetected.

Here is an example of the modprobe command used to load the parport module, which provides the core functions to share parallel ports with multiple devices:

```
# modprobe parport
```
