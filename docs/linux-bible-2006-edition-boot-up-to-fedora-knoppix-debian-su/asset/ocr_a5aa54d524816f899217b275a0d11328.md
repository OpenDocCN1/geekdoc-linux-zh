# Mounting a Disk Image in Loopback

Another valuable way to use the mount command has to do with disk images. If you download a CD or floppy image from the Internet and want to see what it contains, you can do without burning it to CD or floppy. With the image on your hard disk, you create a mount point and use the -o loop to mount it locally. Here's an example:

```
# mkdir /mnt/mycdimage
# mount -o loop whatever-i386-discl.iso /mnt/mycdimage
```

In this example, /mnt/mycdimage directory is created, and then the disk image file (whatever-i386-discl.iso) is residing in the current directory is mounted on it. It can now cd to that, view the contents of it, and copy or any of its contents. This is useful for downloaded CD images from which you want to install software without having to burn the CD. When you are done, just unmount /mnt/cdimage to unmount it.

Other options to mount are available only for specific file system types. The mount manual page for those and other useful options.

# Using the mount Command

When you are done using a temporary file system, or if you want to unmount a permanent file system temporarily, use the mount command. This command detaches the file system from its mount point in your Linux file. To use unmount, you can give it either a directory name or a device name. For example:

```
# unmount /mnt/floppy
```
