# # Code Cader

Code Crusader is a commercially available and supported IDE developer in C++ and specifically targeted at a Linux developer; it is not available for Windows. You can use Code Crusader to write Java, FORTRAN, C++, and, of course, C programs. Unlike the IDEs discussed so far, Code Crusader does not include a built-in debugger. Rather, New Planet Software, developer of Code Crusader, makes its application, Medic, available separately (although you can buy the two together as an IDE bundle). Figure 28-4 shows Code Crusader for the forkexec program from Listing 28-1 in an open editor.

As you can see in Figure 28-4, Code Crusader has a simpler, cleaner interface than the other IDEs mentioned so far. Another significant difference between Code Crusader and the larger IDEs like Eclipse and KDev is that development components, such as the project browser, the class browser, editor windows, and the log viewer, appear in their own, independent windows rather than being part of a single-document interface (MDI).

Having multiple windows is more consistent with traditional Linux and UNIX conventions, but developers coming from a Windows background might find Crusader's multiple-document interface (MDI) a little jarring at first. On the other hand, programmers who prefer a leaner, cleaner interface might prefer Code Crusader to the over-stuffed interfaces like Eclipse and KDev offer.
