

# 第一部分 ♦ Linux 入门步骤

不同类型的 Linux 系统。如果调整得当，最重要的进程将从处理器处获得最快的响应。例如，桌面系统上的 Linux 调度器会对某些任务赋予更高的优先级，比如在桌面上移动窗口，优于后台文件传输。

- Linux 尝试将有即时需求的进程保留在内存（RAM）中，同时管理超出可用内存的进程如何被移动到交换空间（swap space）。交换空间是硬盘上的一个定义区域，用于处理运行中的进程和数据的溢出。当内存满时，进程会被放置在交换空间中。当交换空间也满时（这是你不希望发生的情况），进程将无法启动。

- Linux 支持各种硬件设备，通过在活动内核中仅包含一小部分设备来保持内核的可管理性。使用加载模块（load modules），内核可以根据硬件的添加和移除按需加载和卸载。（内核将在稍后文中进行详细描述，它是 Linux 操作系统的核心。）

- 文件系统提供了文件在硬盘、CD、DVD 或其他介质上存储的结构。Linux 了解不同的文件类型（如 Linux 的 ext3 和 reiserfs 文件系统，以及 Windows 的 VFAT 或 NTFS）以及如何管理它们。

- Linux 从底层开始构建，以允许多个用户同时访问系统。为了保护每个用户的资源，每个目录和文件都分配了一组读、写、执行权限，这些权限定义了谁可以访问它们。在标准 Linux 系统中，root 用户拥有访问整个系统的权限，特殊登录用户拥有特定服务的权限（例如用于 Web 服务的 Apache），而用户则按个人或按组分配权限。最近的功能安全增强型 Linux（Security-Enhanced Linux）允许在高度安全的计算环境中进行更精细的调优和保护。

我描述了构成了所谓“Linux 内核”的组成部分。事实上，Linux 内核（由林斯·托瓦尔斯 Lin Torvalds 创建并维护）是 Linux 命名的来源。内核是你启动计算机时运行的软件，它管理你用于与计算机硬件进行有效且简单通信的程序。

其他组件（如管理命令和应用程序）从自由开源项目中添加到内核中，使 Linux 成为一个完整的操作系统。特别是 GNU 项目贡献了许多现在位于 Linux 中的组件（GNU、Apache、KDE、GNOME 以及 Linux 中的其他关键源码项目将在稍后讨论）。那些其他项目添加了诸如下内容：

- 图形用户界面（GUIs）——由图形框架（通常是 X 系统）、窗口管理器、面板、图标和菜单组成。GUI 让你能够通过键盘和鼠标组合来使用 Linux，而不仅仅是输入命令（像过去那样）。

- 管理工具——包括数百（也许数千）个命令和图形窗口，用于执行诸如添加用户、管理磁盘、监控网络、安装软件以及通常的安全和管理你的计算机的任务。

- 应用程序——虽然没有 Linux 发行版包含所有程序，但 Linux 确实有数千个游戏、办公生产力工具、Web 浏览器、窗口、多媒体播放器和其他应用程序。

- 编程工具——包括用于创建应用程序和实现系统接口库的实用。

- 服务器功能——允许你从 Linux 计算机向网络上的另一台计算机提供服务。换句话说，虽然 Linux 包含了查看 Web 页面的浏览器，但它也可以向他人提供 Web 页面的计算机。流行的服务器功能包括 Web、数据库、打印机、文件、DNS 和 DHCP 服务器。

一旦林斯·托瓦尔斯（Linus Torvalds）和朋友们有了一个可以运行的 Linux 内核，汇集出一个完整的开源操作系统就变得可能的，因为有许多可用的“免费”软件：

- 受 GNU 公共许可证（GPL）或类似许可的保护。这允许整个系统被自由分发，前提是提供有关未来软件源代码如何提供的准则（参见 http://www.gnu.org/licenses/gpl.html）。

- 基于类 UNIX 系统。UNIX 系统所有其他用户级组件的克隆版本都已创建。这些和其他应用程序被设计为运行在 UNIX 或类 UNIX 系统上。

Linux 是开源软件运动的结晶。但共享代码和建立社区的传统在 Linux 诞生几年前就让 Linux 成为可能。你可以认为它始于被称为“实验室”（Laboratories）的舒适思考。

# 第 1 章 从 Linux 开始

- UNIX 文件系统——创建文件系统允许目录层级结构（对于今天的用户来说，这就像是文件夹中的文件夹），UNIX 可以以直观的方式组织文件。

- 输入输出重定向——早期 UNIX 系统还包含了输入重定向和管道。通过命令行，UNIX 可以使用右箭头 (>) 将命令的输出重定向到文件。后来，管道的概念是将一个命令的输出重定向到另一个命令的输入。例如，命令行：

```
$ cat file1 | sort | pr
```

(cat) 文件2，sort (sort) 按字母顺序排序，pr 生成打印文本（pr）到默认打印机。这种重定向输入输出的方法让开发者能够创建与现有工具结合的专用工具。这种模块化使得许多人开发代码成为可能。

- 可移植性——简化 UNIX 使用体验的大量工作使其在不同计算机上具有极强的移植性。通过在文件系统中表示设备驱动程序，UNIX 为应用程序提供了一种接口，使程序无需了解底层细节。要将 UNIX 移植到另一个系统，开发者只需要更改驱动程序。应用程序不需要为了硬件而改变！

为了让可移植性概念变为现实，需要一种高级编程语言来实现所需的软件。为此，布莱恩·柯尼汉（Brian Kernighan）和丹尼斯·里奇（Dennis Ritchie）创造了 C 语言。1973 年，UNIX 被重写为 C。。今天，C 仍然是创建 UNIX（以及 Linux）操作系统内核的主要语言。

正如里奇在他 1980 年的演讲中所说：

今天，唯一用汇编语言编写的重要 UNIX 程序是汇编器本身；几乎所有的实用程序都是用 C 语言写的，大多数应用程序也是如此（尽管有些站点是用 Fortran、Pascal 和 Alg 68 编写的）。似乎 UNIX 的成功很大源于其软件的可读性、可修改性和移植性，而这些特性又源于它们对高级语言的表达。

如果你是 Linux 爱好者，并且对 Linux 早期的某些功能保留至今感兴趣，一份有趣的读物是丹尼斯·里奇重印的第一份 UNIX 程序员手册（日期为 1971 年 11 月 3 日）。你可以在里奇的网站找到它：http://cm.bell-labs.com/cm/cs/who/dmr/lstEd.html。
