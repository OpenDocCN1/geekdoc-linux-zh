# 500 Part III ♦ Choosing and Installing a Linux Distribution

To remaster a KNOKPIX CD, you should have at least 3GB of disk space on a Linux (ext2, ext3, xfs, or other) file system with at least 1GB of available memory (computing RAM and swap space). It's also a good idea to have an active Internet connection during any remastering there is almost surely what you will do in the process.

+   **Damn Linux (DSL)** — This is the Linux distribution I have used the most to customize your own Linux distributions. DSL does good hardware detection and good selection of working desktop applications. I can start with the 48MB ISO image, add lots of software that comes with the book Linux Toys II by Christopher Negros (Wiley, 2006). In fact, the CD that is a remastered version of DSL that includes software for building Linux Toys projects as well. For information about remastering DSL, visit the following:
www.damslinux.org/talk/node/160

If you want to install DSL to a pen drive or other media, DSL offers an automated way for doing that. Once DSL is on a rewritable pen drive, you can easily add applications (using the MyDSL feature) and custom desktop features that persists across reboots.

+   **Puppy Linux** — The project uses its own package management system (PuppGet) that offers more than 300 packages you can add to Puppy Linux. By adding and deleting these packages, you can create a customized version of Puppy Linux. For information on adding packages and saving your configuration to a custom Puppy Linux distribution, refer to Puppy Unleashed:nwww.goosee.com/puppy/puppy-unleased.html

+   **Gentoo** — Tools for building a more finely tuned LiveCD are available through the livecd tool, while creating a Gentoo LiveCD is supported there no complete document describing a simple way to use this, or other tools, to create a custom Gentoo LiveCD. Here is a link, that can get started:

+   **Fedora/Red Hat Enterprise Linux** — Although there is not any official, completed Fedora RHEL LiveCD, there is a project on that path called Fedora. If you are a Fedora or RHEL enthusiast, keep an eye on this project. Its goal is to create tools for generating LiveCD from Fedora installations. If you are using RPM packages on Fedora, this project could help you get a custom Fedora LiveCD you can take on the road. Check it out here:://fedoraproject.org/wiki/Kadisci
