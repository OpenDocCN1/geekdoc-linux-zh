# 392 Part III ♦ Choosing and Installing a Linux Distribution

If you have a slow processor, consider getting precompiled packages because the full compilation process can take a long time.

Obtain the Gentoo CD image from the CD that comes with this book, as described in Appendix A. With the install CD in hand, here's how to install Gentoo on your computer:

+   1. **Insert CD.** Insert the CD (minimal or universal) into your computer's CD or DVD drive.

+   2. **Reboot.** Reboot your computer.

+   3. **Boot CD.** From the boot prompt, press Enter. (If you are not able to boot the install medium, press F1 or F2 to see other install options that might help you getting.)

Gentoo should detect your hardware, start the install process, and display a boot prompt.

+   4. **Set date.** Use the `date` command to make the date and time are correct. If it needs to be changed, use the `date` command (with options) to change them. to set the date to 8:15 a.m. June 15, 2006, type:

```
$ date 061508152006
```

+   5. **Load modules.** If some piece of hardware was auto-detected, you may have to load the module to access that hardware. Use the `modprobe` command with the name of the module you want to load. For example, to load the module for Orinoco LAN card, you can type:

```
$ modprobe orinoco
```

> Do a search for "Linux" and the name of the hardware not being detected to find out module to load.

+   6. **Configure network.** Use `ifconfigeth0` to see if the Internet connection to your first Ethernet is up and running. Then try to ping a computer on the Internet to make sure you can get out (for example, `ping gentoo.org`). If you are not able to pick up a DHCP server to automatically connect to the Internet, set your Internet connection manually, by typing:

```
$ net setup eth0
```

Refer to the network configuration information in the installation procedure in Chapter 8 to help you answer questions about setting your Internet connection.

+   7. **Partition disk.** Partition your hard disk to prepare it for your Gentoo installation. You can use the `fdisk` utility to do this. Gentoo recommends a 64MB boot volume (ext2 file system), swap partition that doubles the size of your RAM, and a large root (/) partition (ReiserFS file system). Start `fdisk` by following the command with the name of your hard disk (such as `/dev/hda` or `/dev/sda` for your first IDE or SCSI hard disk, respectively):
