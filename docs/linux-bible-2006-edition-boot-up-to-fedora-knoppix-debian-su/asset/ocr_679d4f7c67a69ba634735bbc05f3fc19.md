# Running Ubuntu Linux

Ubuntu Linux (www.ubuntu.com) has experienced a meteoric rise in popularity since its first release at 2004. Relying on a handful of developers from the Debian, Arch Linux, GNOME, and other open source projects, Ubuntu has become one of the leading Linux distributions in the world.

> “Ubuntu” is an African word that means “humanity to others.
The Project pursues the meaning of its name by:

+   - Making the distribution freely available; in fact, the project will even mail you you pressed CDs without charge (http://shipit.ubuntu.com).

+   - Providing support for many languages.
- Offering features to make it usable by people with disabilities.

Ubuntu is based on Debian GNU/Linux but offers more focused goals than Debian. A primary goal is to fit an easy-to-use desktop Linux on one installation CD. Because Ubuntu is based on Debian (in fact, it's based on the latest, unstable Debian software packages available), an Ubuntu user has hundreds of software packages available that can be installed using APT management tools.

This chapter describes some of the major features of Ubuntu.
It also describes how to install it on your computer or run the LiveCD version of Ubuntu.
