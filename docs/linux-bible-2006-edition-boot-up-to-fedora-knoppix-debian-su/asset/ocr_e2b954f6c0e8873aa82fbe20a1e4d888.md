If you are setting your prompt temporarily by typing at the shell, you should put the value of PS1 in quotes. For example, you could type **export PS1="\t \w\$** to see a prompt that looks like this: `[20:26:32 /var/pool]`.

To change your prompt permanent, add the value of PS1 to your .bashrc file in your directory (assuming that you are using the bash shell). There may already be a PS1 value in that file that you can modify.

# Adding Environment Variables

You may adding a few environment variables to your .bashrc file. These can help make working with the shell more efficient and effective:

+   * TMOUT—Sets how long the shell can be inactive before bash automatically exits. The value is the number of seconds for which the shell has not received input. This is a nice security feature, in case you leave your desk while you are still logged in to Linux. As so not to be logged off while you are working, you may want to set the value to something TMOUT=1800 (to allow 30 minutes of idle time).

+   * PATH—As described earlier, the PATH variable sets the directories that are searched for commands. If you often use directories of commands that are not in your PATH, you can permanently add them. To do this, add a PATH variable to your .bashrc file, to add a directory called /getstuff/bin, add the following:

```
PATH=$PATH:/getstuff/bin ; export PATH
```

This example first reads all current directories into the new PATH ($PATH), adds the /getstuff/bin directory, and exports them to the PATH.

Some people add the current directory to your PATH by adding a directory simply as a dot (.), as follows:

```
PATH=:$PATH ; export PATH
```

This lets you runs commands in your current directory (which may be used to you if they have used DOS). The security risk with this procedure is that you could be in a directory that contains a command that you don't intend to run from that directory. For example, a hacker could put an in listing of the content of your directory, does something vicious.

+   * WHEVER—You can create your own environment variables to provide shortcuts in your work. Choose any name that is not being used and assign a useful value to it. For example, if you do a lot of work with files in the /work/time/files/info/memos directory, you could set the following variable:

```
M=/work/time/files/info/memos ; export M
```
