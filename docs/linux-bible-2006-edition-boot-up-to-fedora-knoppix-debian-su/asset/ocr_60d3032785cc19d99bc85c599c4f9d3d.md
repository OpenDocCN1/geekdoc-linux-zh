If you are going to change any of the lines related to the boot process, you would probably change only the second line to add or remove boot options. Here is how you do that:

+   1. Position the cursor on the kernel line and type e.

+   2. Add or remove options after the name of the boot image. You can use a minimal set of bash shell command-line editing features to edit the line. You can use even command completion (type of a filename and press Tab to complete). Here are a few options you may want to add or:

+   * Boot to a shell—If you forget your root password or if your boot changes, you can boot directly to a shell using init=/bin/sh to the boot line. (The file system is mounted read-only, so you can copy files out. You need to remove the file system with read/write permission to be able to change files.)

+   * Select a run level—If you want to boot to a particular run level, you can add the word by the number of the run level you want. For example, have Fedora Linux boot to level 3 (multiuser networking mode), add linux 3 to the end of the boot line. You can also boot to single-user mode (1), multi-user mode (2), or X GUI mode (5). Level 3 is a good choice if your GUI is temporarily broken.

# Permanently Changing Boot Options

You can change the options that affect each time you boot your computer by changing the GRUB configuration file. In Fedora and other Linux systems, GRUB configuration centers on the /boot/grub/grub.conf.

The /boot/grub/grub.conf file is created when you install Linux. Here's an example of that for Fedora Core:

```
# grub.conf generated by anaconda

# Note that you do not have to rerun grub after making
# changes to this file
# NOTICE: You have a boot partition. This means that
# all kernel and initrd paths are relative to /boot/, eg.
root (hd0,0)
```
