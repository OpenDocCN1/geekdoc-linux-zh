# Choosing a Linux Distribution

Hundreds of Linux distributions are available today. Some are generalized distributions that you can use as a desktop, server, workstation system; others are specialized for business or computer enthusiasts. Part of the intention of this book is to help you choose which (or ones) will suit you best.

Using the DVD that comes with this book, you can boot directly to KNOPPIX (to try out Linux without installing it on your hard disk) or to Fedora Core 4 (to install Linux on your computer's hard disk). Because the Fedora Core 4 included with the book is the complete PC4, you can install a full range of desktop interfaces and applications, programming tools, and server features. After you've tried KNOPPIX and are ready to install Linux on your hard disk, I recommend you Fedora.

Using the CD that comes with this book, you can boot to Damn Small Linux (a smaller Linux system) or Debian (to do a network install of Debian to your hard disk). These two distributions can be set up to work on computers that are older and less powerful, or have a CD drive but no DVD drive. For Debian, the book also provides descriptions for setting up as a Mobile and Web server.

Other Linux distributions included in the DVD and CD are stored in those images that fit on CDs, or in some cases, mini-CDs or bootable bushel size CDs (shaped like business cards, but can be read by most CD drives). Because of space limitations on the DVD, some of the distributions contained there are intended for network installs, which means you need an Internet connection to get some of the software to complete a full install.

# Linux at Work

Because I know a lot of people who use Linux, informally and at work, I want to share my general impressions of how different Linux distributions are being used in the United States. Most consultants who set up small office servers use Red Hat Linux, but now have mostly moved to Fedora Core, Ubuntu, or Debian. Mandriva Linux (formerly Mandrakelinux) has been popular with people wanting a friendly Linux desktop, and Fedora and SUSE are also wellliked. The more technically inclined like to Gentoo (highly tunable) or Slackware (in a basic form).

For people are transitioning to a PowerPC and Macintosh hardware, Yellow Dog Linux lets them learn skills that are useful to expand on Red Hat Linux systems (Yellow Dog is based on Red Hat). As for the bootable Linux, everyone thinks they are great to try out and a good way to learn about Linux. For a bootable containing desktop software that fits on a full CD (or DVD), KNOPPIX is a good choice; for a bootable mini-CD size Linux, Damn Small Linux works well.
