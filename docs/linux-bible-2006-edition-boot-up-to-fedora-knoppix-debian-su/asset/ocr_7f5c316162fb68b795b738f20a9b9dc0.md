The pppconfig will ask a number of questions during the connection process. Start by selecting "Create a connection," and then enter the following information as prompted:

+   1. **Provider name**—Enter any name you like to identify this connection. For the dial-up entry to your primary ISP, you can simply leave the `provider` as the Provider name.
2. **DNS server configuration method**—Here you can configure the connection to static DNS servers if needed. This is probably not necessary unless your service provider included the DNS server information in the information that it about the connection. If you're not certain, select Dynamic DNS and change it if needed.
3. **Authentication method**—This is the method that your computer will use to identify itself to the dial-up server. PAP is the most commonly used protocol, and some systems also support CHAP. The Chat option should be used if the dial-up server uses prompt for the username and password. In doubt, select PAP.
4. **User name and password**—Enter the username and password that will be recognized by the dial-up server.
5. **Speed**—This is the speed that your computer and your modem communicate. In most cases, this should be set to 115200.
6. **Dialing method**—If your telephone system requires pulse dialing, you can configure that here.
7. **Phone number**—Enter the number that you need to dial in order to reach the dial-up server, including any area codes and other codes that may be needed. For instance, if you have to dial 9 in order to reach an outside line, use `9_number` to dial. The comma tells your modem to pause before continuing the dialing process. You may also enter the appropriate numbers for disabling features such as your telephone service.
8. **Modem configuration method**—Here, you can pppconfig attach to automatically find the port that your modem is on. If a modem is not found, you will then get the chance to enter the path to the modem device. More information about what to enter can be found in the "Identifying and Configuring Your Modem" sidebar later in this chapter.

Save your settings by selecting Finished from the menu, and then exit the pppconfig utility.

Dial a connection by using the `pon` command, replacing `peer` with the name you assigned to your connection, or leaving it out if your connection is named `provider:`

```
# pon peer
```
