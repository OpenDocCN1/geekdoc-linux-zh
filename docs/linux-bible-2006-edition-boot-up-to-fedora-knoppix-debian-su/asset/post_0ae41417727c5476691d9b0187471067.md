# Summary

Mandriva may not be as widely known as other Linux distributions, it is arguably one of the most accessible version for desktop users. It is especially useful to those who want Linux installations to exist alongside Windows installations that do not have free partitions for a dedicated Mandriva installation.

This chapter explores some of the defining features of Mandriva, including the installer, which incorporates the capability to resize Windows partitions destructively; an RPM package management (RPMDrake); and system configuration tools.
