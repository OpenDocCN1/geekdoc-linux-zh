If you find yourself with icons all over the desktop, you can also organize them from the desktop menu. Right-click the desktop, then select Icons ⇅ Sort Icon. From the menu that appears, select icons by name, size, or type. You can also choose to simply line up all icons vertically or horizontally.

# Moving Windows

The easiest way to move a window from one location to another is to place the cursor on your window's title bar, hold the mouse button and drag the window to a new location, and release the mouse button to drop the window. Another way to do it is to click the window menu button (top-left corner of the title bar), select Move, move the window to relocate it, and then again to place it.

If some window gets stuck in a location where the title bar is off the screen, you can move it back to where you want by holding the Alt key and clicking the left mouse button in the inner window. Then move the window you want and release it.

# Resizing Windows

To resize a window, grab anywhere on the outer edge of the window border, and move the window until the window is the size you want. Grab a corner to resize vertically and horizontally at the same time. Grab a side to resize in one direction.

You can also resize a window by clicking the window menu button (top-left corner of the title bar) and selecting Resizing. Move the window until the window is resized and click to leave it.

# Pinning Windows on Top or Bottom

You can set a window to always stay on top of all other windows or stay under them. Keeping a window on top can be useful for a small window that you (such as a clock or a small TV viewing). To pin a window on top of the desktop, click the window title bar. From the menu that appears, select Advanced▸ Keep Above Others. Likewise, to keep the window on the bottom, select Advanced▸ Keep Below Others.

# Using Virtual Desktops

To give you space to run applications that will fit on your physical screen, KDE gives you access to several virtual desktops at the same time. Using the 1, 2, 3, and 4 buttons on the panel, you can easily move between the different desktops. Just click the one you want.

If you want to move an application from one desktop to another, you can do so from the window menu. Click the window menu the window you want to move, click To Desktop, and then select Desktop 1, 2, 3, or 4. The window will disappear from the current desktop and move to the one you selected.
