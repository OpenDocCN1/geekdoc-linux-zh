# # Running KNOPPIX

A computer's operating system usually resides on the hard disk—but it doesn't have to. When a computer boots up, it typically checks if there is a CD, floppy disk, or DVD in a drive and tries to boot from (depending on BIOS settings). So, with up to 700MB (CD) or 4.7GB (DVD) of space on these media, why not use them for whole operating systems?

Well, that's exactly what bootable Linux distributions (also live CDs) do as KNOPPIX do. In the case of KNOPPIX, one CD holds up to 2GB of compressed software for you to run that uncompresses on-the-fly. Start it up and you can try out all the features of a well-stocked Linux system, without touching the contents of your hard disk.

KNOPPIX is included on the DVD that comes with this book. In fact, it is the default option. Insert the DVD into your PC's DVD drive, and when you see the boot screen, press Enter. KNOPPIX should start up, and you can begin using it as described in this chapter.

Each year you have never used Linux before, KNOPPIX gives you the chance to do so in a very safe way. If you are experienced with Linux, troubleshoot a computer, or check whether a computer will run Linux. In any case, you can use this to take a little tour of some great Linux features that you can try out with KNOPPIX.
