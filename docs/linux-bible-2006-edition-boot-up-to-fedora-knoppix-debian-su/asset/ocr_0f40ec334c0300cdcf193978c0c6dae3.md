+   * Firewall distributions—A firewall is a very good application for a bootable Linux distribution. Using most any PC and a CD (or a floppy disk) Linux distributions, you can protect your PC from LAN intruders and provide a route for multiple computers to the Internet. Popular firewall distributions include Devil-Linux (www.devil-linux.org) and Sentry Firewall CD (www.sentryfirewall.com). Firewall/router distributions are described in Chapter 17.

There are also bootable Linux distributions that are suited for education and for the visually impaired. There are bootable Linux distributions that are suited to run as a server or to centrale management of clusters. The cool thing is that if there is not the exact kind of bootable Linux available for you to use, you can start with existing bootable Linux and customize it.
