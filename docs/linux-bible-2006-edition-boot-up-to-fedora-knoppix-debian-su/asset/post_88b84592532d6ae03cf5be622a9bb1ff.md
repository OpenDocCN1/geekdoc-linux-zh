
## Getting Into Linspire

Linspire is a Debian-based Linux distribution that is being developed with a focus on ease of use. The key features of Linspire include:

- An almost entirely automated installation process that enables beginning users to install Linspire without being intimidated by lengthy screens of output.
- Easy software management using the Click-N-Run utility.
- Support that incorporates online and offline resources designed to be accessible to novice users.
- An intuitive user interface based on the KDE environment.

What really sets Linspire apart, however, from other Linux desktop systems is that Linspire, Inc. has found a way to include software that other Linux distributions wouldnt because there is no open source equivalent available or because royalties would be required by patent holders. In particular, the ability to play MP3 audio and commercial audio is something that no major Linux distribution does out of the box.

Besides selling Linspire in boxed sets, Linspire Inc. also has partnerships with companies such as Tiger Direct, to offer PCs with Linspire preinstalled. Computers that are preloaded with Linspire are also available from Wal-Mart, CompUSA, Best Buy, Fry's Electronics, and Micro Center.

## Installing Software with Click-N-Run

One of the biggest complaints from Linux neophytes is the difficulty installing additional software. It has become very clear that in order to make serious inroads into the desktop PCs of Joe and Jane Q. Linux needs to keep improving ease of use.

Continuing with the “it’s so easy” theme, Linspire has developed one of the most trouble-free software installation processes in use on a desktop Linux system: Click-N-Run (CNR). This process connects users with tons of applications and requires almost no effort to install at.

Click-N-Run has been described, accurately, as apt-get taken to new, graphical heights. Apt-get is a tool to manage software packages. The beginnings of apt-get are most closely associated with Debian and .DEB packages, apt-get have been adapted to handle RPMs and is widely available for platforms other than Debian.

Apt-get is complemented by detailed man pages, although it lacks a graphical interface. The CNR process enables you to select the desired application, click a little green button, and wait until the package downloads and installs. You need only an existing Linux installation and click the green globe with a running man in the middle to get started. Here are some of the CNR's features:

- Login/Logout — Use this button to configure your login information for CNR. To use the CNR Warehouse, you need a valid user account.
- Configure Click-N-Run — This option enables you to specify where CNR will look for files when you are installing applications. If you do not have your own repository, leave this setting alone.
- The capability to select your source location is relevant only if you choose to install packages not in the CNR Warehouse, such as an application network administrator has made available for installation by users on the local network. For most users, this is not a selling point because the real return for buying Linux comes from accessing applications in the CNR Warehouse.
- Install — After you've selected a software package to install from your source location (local files, CD-based, on the network, or from the CNR Warehouse), you can initiate the installation process. Items in the warehouse can be installed by clicking the green globe icon next to the product name in lieu of using CNR's install button.
- Update — Select an application and then use the Update feature to check for newer versions of the software.
- Run — After you have installed an application you can use this to run the program immediately. You can also run the program from the launch menu or a shortcut.
- Pause — You can pause your download of online installation files. This makes working with large installation files slower or shared network connections easier.
- Add to Desktop — Creates a desktop shortcut for any of your applications addition to the launch menu icons.
- Uninstall — When you run the uninstall option on a selected application, all of the files, icons, and folders for that application are automatically removed.

CNR is a great tool for getting software from the warehouse, and Click-N-Run Express is a CNR version that can be used to install applications from any location. It enables you to designate local or remote repositories and install the products.

If you configure the download option, CNR Express stores a local copy of the installed applications for later, enabling you to install, remove, and reinstall when you want without having to download the installation package all over again. When your installation is complete, the application waits for you to use it by browsing to the application title in your K menu.

One of a truly handy, proprietary applications available in the CNR Warehouse Win4Lin, which can be used to get many Win32 applications and running on your Linspired system.

## Other Installation Options

While the Click-N-Run application is the quickest means of managing software on your Linspired, it may not meet every user's needs. With this in mind, there are a couple of other options for managing software on your Linspired:

- DEB packages can be used to manually install software. Open a Terminal window and run the command `dpkg -i filename`.

For more information on using the dpkg installation utility, check the Debian FAQ at http://debian.org/doc/FAQ/ch-pkgtools.html.

- RPM packages can be used if you make use of an installation package verter as Alien (http://kitten.net/programs/alien/). This method should be employed only if you have no more convenient options. Package conversion is not a sure thing and unexpected consequences can arise from using converted packages.

- Apt-get, a tool for managing packages, can be used as Synaptic. It offers the same functionality as CNR, but without ease of use.

- Software not available in .DEB or RPM formats can be installed by compiling source. See Chapter 9 for thorough description of apt-get.

## Linspired Support and Software

Support is one of the nicest benefits of being Linspired, especially when compared to other communities. Many of the online Lin5 support options are available by clicking the Help icon (it looks like a life jacket) in the panel. The menu that appears not only connects you to official Lin5 support and community forums, but also lets you view demos.

## Lin5 Forums and Information

If you should encounter any problems or simply want to ask some questions about Lin5, you can start by checking out the Lin5 support pages. By taking your Web browser to http://support.lin5.com, you can access forums, FAQs, and (if you have a product login) personalized support.

While the FAQs and personalized support are very useful, you will get the most out of forums. Most of the forums allow posts by registered users, but there are guest areas as well. These forums are frequented by other users and product developers are a great resource for getting future product information and providing feedback on how Lin5 works for you.

## Audio Assistant

What good new software be without a product tour peppered with a touch of evangelism? Lin5 offers both with the Audio Assistant. This animated tour of the Lin5 OS runs after your initial installation. The Assistant walks you through Click-N-Run, configuring your desktop, and a lot more.

> You can check out the online version of the Audio Assistant at http://media.lin5.com/howto/kiosk.swf.

Should you install Lin5 and bypass the Audio Assistant tutorial, have no fear. You can re-launch the tutorials by clicking the life jacket in the lower-left corner of your desktop.

## Installing Lin5 Five-0

If you plan ahead, a Lin5 installation is one of the most straightforward installations. This includes Apple and Microsoft as well as other Linux distributions. There are very few configuration options and no disk partitioning options other than selecting an installation partition or wiping the entire hard. For maximum joy, make sure you have no data on the computer/partition/drive where Lin5 will be installed. The target location for the installation will be wiped out.

Make sure that you check the supported hardware list (www.lin5.com/windows_hwsw_compatibility.php) before you begin your installation to make sure there are no surprises there.
