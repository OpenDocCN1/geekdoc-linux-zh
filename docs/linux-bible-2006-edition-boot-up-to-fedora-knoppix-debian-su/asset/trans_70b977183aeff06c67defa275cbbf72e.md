**9. 选择根分区。** 在显示的 Linux 分区中，高亮你想要作为根目录 `/` 分区的分区并选择 Choose。`/` 分区是 Linux 和你所有数据默认将去的地方。（稍后可以添加其他分区）

选择快速格式化（Format）或包含坏块检查的慢格式化（Check）。你也可以选择 No 不对该分区进行格式化。

通常情况下，你会覆盖你的 `/` 分区，尽管你可能会保留另一个分区的数据。我经常维护一个独立的数据分区，并将其挂载到文件系统的 `/mnt/data`。通过这种技术，我可以在保留数据的同时仍然安装新的操作系统。

为根系统选择文件系统类型。如今，大多数人使用 `ext3` 或 `reiserfs` 文件系统作为你的 Linux 根分区。这两种文件系统都带有日志记录，因此当系统非正常关闭时（例如有人拔掉电源线），它们可以恢复。

选择 Inode 密度。选择 4096（大多数情况下的默认值）、2048 或 1024 字节。（较小的数字允许文件系统拥有更多的 inodes，这仅在你有许多小文件时有用，例如在网络服务器上那样。）

**10. 选择其他分区。** 如果你创建了其他分区，可以为它们分配文件系统类型并对其进行格式化。识别你的其他分区在文件系统中的连接位置。（再次检查第 7 部分有关你可能想将分区挂载到 Linux 文件系统的位置信息。）

**11. 选择你的源媒体。** 选择 1，以便从 CD 安装 Slack。你也可以从硬盘上的某个分区、NFS 共享文件系统或预挂的目录安装 Slack。

你可以让 Setup 扫描你的 Slack CD，或告诉它使用特定的设备（如果你有多个驱动器并想让它使用某一个）。

**12. 选择你想安装的软件包系列并按 OK。** 普通软件包系列包括：

- Base Linux 系统（操作系统的核心和基本实用程序）
- 不需要 X 的应用程序（非图形化命令）
- 程序开发（C, C++, Lisp, Perl 等）
- GNU Emacs（一个文本编辑器）
- FAQ 列表、HOWTO 文档
- Linux 内核源码
- 用于 X 的 Qt 和 K Desktop 环境
- KDE 的国际化支持
- 系统库（X, KDE 等其他程序需要）
- 网络（TCP/IP, UUCP, 邮件、新闻等）
- TeX 排版
- Tcl/Tk 脚本语言
- X Window 系统
- X 应用程序
- 游戏

如果你是从单张 CD 镜像安装的，请取消选择 KDE 和 KDEI，因为它们已经在 CD 上了。在安装过程中，你有机会选择一个简单的窗口管理器，如 XFCE、Blackbox、Fluxbox 或 ftwm2。

**14. 选择一个 Linux 内核。** 在大多数拥有 IDE 控制器的情况下，你可以选择 Slackware CD 作为获取内核的路径，你安装的 Slackware 系统最终将使用该内核。移除 Slackware CD #2 并重新插入 Slackware CD #1 然后按回车。大多数情况下，你应该选择默认的 `bare` 内核。如果你有 SCSI 控制器，选择一个以 `s` 结尾的内核。如果你的 RAM 非常小，尝试 `lowmem` 内核。如果你想使用较新的 2.6 内核而不是 2.4 内核，请选择 `test26s`。其他专用内核在 Slackware-HOWTO 文档中描述。
