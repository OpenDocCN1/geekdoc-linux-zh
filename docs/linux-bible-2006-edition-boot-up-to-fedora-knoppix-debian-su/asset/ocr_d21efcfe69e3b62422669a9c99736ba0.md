# 456 Part III ♦ Choosing and Installing a Linux Distribution

> Caution

As with any Linux distribution, any time you aspire to use repositories that are outside of the official repositories supported by that distribution, you should carefully scrutinize that repository. Unofficial repositories can break software compatibility, can contain software that you cannot use legally, and might even contain software. Although it is still no guarantee of safety, check Ubuntu forums and mailing lists to find outside repositories others have found to be reliable before using them yourself. Also, look for repositories that are specific to your version of Ubuntu because software from earlier Ubuntu releases or Debian-specific releases may not work.

To add a custom repository to Ubuntu, do the following from the Synaptic Package Manager:

+   1. Select Settings: The Software Preferences window appears.
2. Select Add. The Edit Repository window appears.
3. Click Custom. You are asked to add a complete APT line, identifying the repository.
4. Type the line identifying the APT repository that contains the outside software you want to install. (The following is an example of a line identifying a fictitious repository.)
deb http://ubuntu.example.com/ubuntu breezy main
5. Click Add Repository to have the line you just created added to your list of Ubuntu software repositories.
6. Click OK from the Software Preferences list. You are warned that your repository information changed and that you can now reload your package list.
7. Click Yes to reload your package list.

At this point, you can install any packages that appear in your new package list. (Click Not Installed in the left column to see any packages that have not yet been installed from any of the repositories identified in your repository list.)

# Getting More Information About Ubuntu

Ubuntu's rapidly growing popularity has led to many online resources for support-it. One of the best places to start learning about Ubuntu or finding answers to specific questions is the Ubuntu Forums site (www.ubuntuforums.org). To begin participating in that site, I suggest you read the Ubuntu Forums FAQ at www.ubuntuforums.org/faq.php.
