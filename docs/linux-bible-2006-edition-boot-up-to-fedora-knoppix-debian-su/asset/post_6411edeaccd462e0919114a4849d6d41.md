
# Chapter 1 ♦ Starting with Linux

In the open source community we have learned that this rapid evolutionary process produces better software than the traditional closed model, in which only a very few programmers can see the source and everybody must blindly use an opaque block of bits.

The primary goal of open source software is to make source code available, other goals are also defined by OSI in its Open Source Definition. Most of the following rules for acceptable open source licenses are to protect the freedom and integrity of the open source code:

- ◆ Free distribution—An open source license can't require a fee from anyone who resells the software.
- ◆ Source code—The source code has to be included with the software and not restricted from being redistributed.
- ◆ Derived works—The license must allow modification and redistribution of the code under the same terms.
- ◆ Integrity of the author's source code—The license may require that those who use the source remove the original project's name or version if they change the source code.
- ◆ No discrimination against persons or groups—The license must allow all people to be equally eligible to use the source code.
- ◆ Distribution of license—No additional license should be needed to use and redistribute the software.
- ◆ License must not be specific to a product—The license can't restrict the source code to a particular software distribution.
- ◆ License must not restrict other software—The license can't prevent someone from including the open source software on the same medium as non-open source software.
- ◆ License must be technology-neutral—The license can't restrict methods in which the source code can be redistributed.

Open licenses used by software development projects must meet these criteria to be accepted as open source software by OSI. More than 40 licenses are accepted by OSI to label software as "OSI Certified Open Source Software." In addition to the GPL, other popular OSI-approved licenses include:

- ◆ LGPL—The GNU Lesser General Public License (LGPL) allows people to redistribute certain software, but not change its contents. This license is often used for distributing libraries that other application programs depend upon.
- BSD — The Berkeley Software Distribution License allows redistribution of source code, with the requirement that the source code keep the BSD copy-right notice and not use the names of contributors to endorse or promote developed software without permission.
- MIT — The MIT license is like the BSD license, except that it doesn't include the endorsement and promotion requirement.
- Mozilla — The Mozilla license covers use and redistribution of source code associated with the Web browser and related software. It is a much longer license than the others just mentioned because it contains definitions of how contributors and those reusing the source code should behave. This includes submitting a file of changes when submitting modifications and that making their own additions to the code for redistribution should be aware of patent issues or other restrictions associated with their code.

# Vibrant Communities

Communities of people and enthusiasts have grown around Linux and its open source projects. Many have shown themselves to devote their time, knowledge, and skills on public mailing lists, forums, Wikis, and Internet venues (you could ask politely and not too annoying).

Linux User Groups (LUGs) have sprung up all over the world. Many Linux installs (where members help you install the Linux of your choice or on computer) or non-profit groups and schools use Linux on older computers that will no longer support the latest Windows software. The LUG is a member who holds monthly meetings with talks on Linux topics and has an active Web site, mailing list, and chat server where members can help each other with Linux questions that come up.

Free online board services have sprung up to get information on Linux topics. Popular Linux forums are available from www.LinuxOrgs.org, www.LinuxForums.org, and www.LinuxHelp.net. Most of these sites are built with open source software (see www.e107.org and www.php88.org for examples of open source software framework).

Communities also gather around specific software projects and Linux distributions. www.sourceforge.net is the home to thousands of open source software projects. Go to the SourceForge.net site and try keywords for topics that interest you (for example, image gallery or video editing). Each project links to project pages, forums, and software download sites. There are always projects looking for people to help write code or documentation or participate in discussions.

You'll find that major Linux distributions have associated mailing lists and forums. You can go directly to the Web sites for Red Hat Fedora Linux (www.redhat.com/fedora), Debian (www.debian.com), SUSE (www.novell.com/linux/suse), Gentoo (www.gentoo.org), and others to learn how to participate in forums and contribute to those projects.

# Major Software Projects

Some software projects have grown beyond the status of being simply a component of Linux or some other UNIX derivative. Some of these projects are sponsored and maintained by organizations that oversee multiple open source projects and organizations. This section introduces some of the most popular open source projects and organizations.

- The Apache Software Foundation (www.apache.org) is not only the world's most popular open source Web software, it's the most popular of all server software. Most Linux distributions that contain server include Apache. The Apache Software Foundation maintains the Apache Web (HTTP) server and about a dozen others, including SpamAssassin(for blocking and filtering e-mail), Apache Portals (to provide portal soft-, and a bunch) for producing projects to use with your Apache Web.
- The Internet Systems Consortium (www.isc.org) supports critical Internet infrastructure projects under open-source licenses. These projects include Bind (DNS server), DHCP (to assign IP addresses and other information to Internet clients), ISC (for creating Internet servers) and OpenReg (a tool for managing delegation of domains in a shared registry).
- The Free Software Foundation (www.fsf.org) is the principal sponsor of the GNU Project. Most of the UNIX commands and utilities used in Linux that were not closely associated with the kernel were produced under the umbrella of the GNU project.
- The Mozilla project's (www.mozilla.org) most well-known product is the very popular open source Web browser Navigator, which was originally based on code released to the open source community from Netscape Communicator. Most other open source projects incorporate Mozilla's engine. The Mozilla project also offers e-mail, composer, IRC Chat, and address book software. New projects include the Thunderbird e-mail and news clients and Firefox browser, which have seen enormous success over Linux, Windows and Mac OS platforms in the past year.
- The Sendmail Consortium (www.sendmail.org) maintains the sendmail transport agent, which is the world's most popular software for transporting mail across the Internet.

There are, of course, many open source projects and organizations that provide software in various Linux distributions, but the ones discussed here give you a good feel for the kind of projects that produce open source software.

# Can You Stop Worrying About Viruses?

Well, you can (and should) always worry about the security of any computer connected to the Internet. At the moment, however, you are less likely to get a virus from infected e-mail or untrusted sites with standard e-mail clients and browsers that come with Linux than you would with the average Windows system.

The most commonly cited warnings to back up that statement come from the United States Emergency Readiness Team (CERT) regarding a vulnerability in Microsoft Internet Explorer:

> There are Vulnerability Note: There are a number of significant vulnerabilities in technologies relating to the IE domain/zone security mode, the HTML object model, MIME type determination, and ActiveX. It is possible to reduce exposure to these vulnerabilities by using a different browser, especially when browsing untrusted sites. Such a decision may, however, reduce the functionality of sites that require IE-specific features such as HTML, VBScript, and ActiveX. Note that using a different browser will not remove IE from a Windows system, and other programs may invoke IE, the webbrowser control, or the HTML rendering engine (MSHTML).

While the note also recommends keeping up with patches from Microsoft to reduce your risks, it thinks the only real solutions are to disable scripting and ActiveX, use plain text e-mail, and don't visit sites you don't trust with Internet Explorer.

This announcement apparently quite a run on the Mozilla.org site to download Mozilla or Firefox browser and related e-mail client (described in Chapter 22 of this book). Versions of those software projects run on Windows and Mac OS X, as well as on Linux. Many believe that browsers such as Mozilla are inherently more secure because they allow non-standard Web features that might do things as automatically download unsolicited software without your knowledge.
