# KNOPPIX Features

KNOPPIX has many features that it's hard to find a place to start. The latest official version of KNOPPIX at the time of this writing (KNOPPIX 4.0.2), features OpenOffice.2.0, KDE 3.4.1, GIMP 2, linux kernel 2.6.12, and as well as multimedia applications. More information can be found on the KNOPPIX homepage (http://www.knoptix.com).

One of the best features of the most recent versions of KNOPPIX is the ease with which you can create your own, personalized KNOPPIX disk. The available options are so vast that there is not enough room to cover them in this book. For more information on how to create your own version of KNOPPIX, see http://www.knoper.net.

# Understanding KNOPPIX

If you are impatient to get started, you don't have to read any further. In most cases, you can just insert your DVD into your PC, reboot the computer and start using KNOPPIX. If you have the time, however, read on a bit more.

KNOPPIX is a bootable Linux that includes a nice selection of open source software. Originally, there was a CD version of Gnoix (about 700MB image). Now, there is also a DVD version (about 3.1GB image). It is the KNOPPIX CD image that is included on the DVD that comes with this book.

KNOPPIX is considered to be the best bootable Linux available. In fact, KNOPPIX is used as the base for many specialized Linux distros, including GnoppPPIX (featuring GNOME instead of KDE), KNOPPIX STD (security), KnopMyth (MythTV media player), and KnopixMAME (console game player), to name a few. To try out the latest features, however, you should start with the most recent version of KNOPPIX, as described in the rest of this chapter.
