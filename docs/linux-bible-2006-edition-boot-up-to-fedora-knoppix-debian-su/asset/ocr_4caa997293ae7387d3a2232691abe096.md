Computers are great for collecting and recording music, playing games, and communicating with far-off lands. While these functions are popular and exciting, one tool has been considered essential since the earliest days of personal computers:document-creating applications. With ultrasimple text-only editors to feature-rich groupware systems, you'll be hard-pressed to find a PC without this basic functionality. Such software is so important that Microsoft makes billions of dollars each year productivity tools for the Windows OS.

Linux users are, on levels, different from any other PC user. They need to write letters, make presentations, write books, and sort information in spreadsheets. For the Linux user, a copy of Microsoft Office is not simply in the cards yet, but there are many powerful tools to choose from.

OpenOffice.org is a powerful open source tool available as a download and part of many Linux distributions. On Sun Microsystem's StarOffice productivity suite, OpenOffice.org includes a word processor, spreadsheet program, and other productivity tools. In most cases, OpenOffice.org can be used as a drop-in replacement for Microsoft Office.

The first document editors were mostly built on old, text-based tools. Recently, more sophisticated tools for writing, formatting pages, and integrating graphics have been added. Despite their age, many of the older publishing tools (such as Groff and LaTeX) are still used by people in the technical community.
