# RPM Package Management with RPMDrake

Adding software and removing software from your Linux installation should be a time-consuming chore. RPMDrake provides an intuitive graphical interface for managing installed software. You can easily see what is installed and add or remove packages. Once you use RPMDrake, there are a few things you should know:

- You configure your list of sources by invoking the Definition Sources. This enables you to specify the location of installation packages, which could be local network locations, CD-ROM media, or HTTP/FTP archives of installation packages. There is a List of Mirrors that you can refresh to make sure you're ready to get access to the latest security and system updates.
- Using the Mandriva Update button is perhaps the easiest way to maintain your system because it automatically downloads and installs updates for your system when you initiate the updates.

- You need the root password when installing packages. RPMDrake prompts you for it as needed.
- RPMDrake offers improved upgrade support. You can use it to scan for software updates, download them, and offer them in list of installable programs for the user to select.

RPMDrake supports a search feature that enables you to search for a variety of criteria to search for desired software within configured sources. You can search by package name, or you search based on a description. Either way, you find the package you want, simply select the target package and use the Install/Remove button to get going.

# Mandriva Control Center

The Mandriva Control Center (MCC), also called DrakConf, provides an intuitive and accessible means of configuring various system resources. You can use this tool to add new hardware, configure installed applications, or remove applications (by invoking RPMDrake), and change the configuration of your existing hardware.

You can also use it to adjust your default system security levels, change your display options, schedule events, manage user accounts, and even change the system time/date setting. The MCC uses a number of installation and configuration wizards to help you get rolling. For example, a wizard for Apache Web server setup enables to get your HTTP server online in just a few minutes. Some of the improvements and MCC of Mandriva 10 are:

- Secure, remote system configuration from any network.
- Automatic detection of hot swappable devices without restarting the system.
- Large icons that are easy to see and appropriately related to the functions they invoke.

# The Mandriva Community

Like many distributions of Linux, Mandriva has developed a split personality of sorts. Mandriva distributes value-added versions of Mandriva complete with numerous utilities, applications, and support. The core Mandriva development effort produces an unsupported, but just useful, version of the core Mandriva build. With "free" copy, you get the OS and the basic utilities and applications no access to the Mandrivacl.

Mandrivacl allows folks with a paid membership to access early builds, the full set of downloadable one-click applications, forums, support, and downloads of current releases using club-member-only bit torrent. It also gives you access to Commercial software (such as Flash-pins and NVIDIA drivers) that cannot be freely distributed. For someone trying to make Linux a desktop system for use by folks coming from Apple and Microsoft GUI operating systems, the added features are extremely useful.

# RPM Repository on Mandrivacl

# The Right Hardware for Mandriva

As with software packages, look before you leave. It is important to make sure your hardware is up to the task before you install Mandriva. Fear not, users of less-than-stellar hardware; the hardware requirements are far from onerous. Use Mandriva you need:

- Intel Pentium-IV, AMD K6/II/III, Duron, or Athlon.
- **RAM** — For text installation, the minimum is 32MB. If you plan to use the GUI, the minimum is 64MB, but 128MB is recommended.
- **Hard disk** — 500MB of SCSI, IDE, or Serial ATA hard disk is the bare minimum. 1GB is recommended, and if you decide to install additional packages, you should have at least 2GB of free disk space.
- **RAID controllers** — There is wide support for SCSI RAID controllers. In addition, Wide IDE and Serial ATA controllers are also supported.
- **DVD or CD drive** — To run the installation from a CD/DVD source disk, you need the appropriate drive. This drive will need to support bootable CD/DVD media.
- **Input/Output** — Of course, if you want to interact with your Mandriva install, you'll need least a keyboard and a monitor. A mouse is not needed for the installation, but it is handy and recommended.

> For those who live on the bleeding edge, there is a distribution of Mandriva that supports the AMD Athlon64 processor. This distribution is available currently as a commercial product from the right side of Mandriva. mandriva.com.
