# Chapter 28 ♦ Programming Environments and Interfaces 781

| API | Category | Description |
| libpng | Graphics | The Portable Network Graphics (PNG) standard is an extensible file format for the lossless, portable, compressed storage of images. PNGs provide a patent-replacement for GIF. |
| libtermcap | Hardware | libtermcap implements the GNU termcap library API, a library of functions that enable programs to control strings to terminals in a way independent of the terminal. |
| libtiff | 2-D Graphics | The TIFF library provides an API for working with images stored in Tag Image File Format (TIFF), a widely used format for storing high-quality, high-resolution images. |
| libungif | 2-D Graphics | libungif provides an API unencumbered by patents for loading and saving images in GIF format. |
| libusb | Hardware | libusb allows user space application access to USB devices. |
| libvorbis | Audio | This library supports the Vorbis General Audio Compression Code, commonly known as Ogg Vorbis. Ogg Vorbis is an open, patent-royalty-free, general-purpose compressed format for audio and music. |
| libdwm | Graphics | libdwm provides an API for interpreting, displaying, and converting metadata to standard image formats such as PNG, JPEG, PS, EPS, and SVG. |
| libxml2 | XML | libxml2 is the XML parser used by GNOME and KDE. |
| libxslt | XML | libxslt provides XSLT support for libxml2. XSLT is a language used to transform XML documents into other formats. |
| orbit | CORBA | ORBIT is a high-performance Common Object Request Broker Architecture (CORBA). ORBIT allows programs to send requests and receive replies from other programs, regardless of the locations of the two programs. GNOME uses ORBIT heavily. |
| pango | Text layout | Pango is a library for layout and rendering of text, with an emphasis on internationalization. Pango forms the core of text and font handling in GTK+2.0. |
| pcre | Regular expressions | The Perl-compatible regular expression (PCRE) library implements an API for regular expression pattern matching that uses the same syntax and semantics as Perl 5. The PCRE library is used by many programs.
