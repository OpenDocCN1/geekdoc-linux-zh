### Using the fdisk partitions to Define Mountable File Systems
The hard disks on your local computer and the remote file systems you use every day are probably set up in fstab to automatically mount when you boot Linux. The /etc/fstab file contains definitions for each partition, with options describing how the partition is mounted. Here's an example of /etc/fstab file:

```
LABEL=/boot      ext3            defaults        11
LABEL=/boot      ext3            defaults        12
/dev/devpts     /dev/pts       devpts          gid=5,mode=620  0
/dev/shm        /dev/shm       tmpfs           0
/dev/proc       proc            defaults        0
/dev/sys        sys             sysfs           0
/dev/hda5       swap            defaults        0
/dev/hdc        media/cdrom    udf,iso9660     exec,auto,managed 0
/dev/sda1       /mnt/win       vfat            noauto          0
/dev/fd0        /mnt/floppy    auto            noauto,owner   0
```

All partitions listed in this file are mounted at boot time, except for those set to noauto in the field. For example, the root (/) and boot (/boot) hard partitions are mounted at boot time, along with the /dev/pts,/dev/shm,/dev/sys,/proc file systems (which are not associated with particular storage devices).
