8. **创建文件系统。** 要在你的磁盘分区上创建适当的文件系统，请使用 `mkfs` 和 `mkswap` 命令。例如，对于一个 IDE 驱动器，第一个分区是启动分区 (/dev/hda1)，第二个分区是交换分区 (/dev/hda2)，第三个是根分区 (/dev/hda3)，你可以输入以下内容：

```
# mkfs /dev/hda1
# mkswap /dev/hda2
# mkextfs /dev/hda3
```

9. **开启交换分区。** 使用 `swapon` 命令开启你的交换分区。对于我们的示例（hda2 为交换分区），输入：

```
# swapon /dev/hda2
```

10. **挂载根目录 (/)。** 你需要临时挂载根 (/) 分区以开始安装 Gentoo。在本示例中（根文件系统为 /dev/hda3），输入：

```
# mount /dev/hda3 /mnt/gentoo
```

11. **挂载 /boot 分区。** 接下来，挂载启动分区，以便将启动文件安装到该分区：

```
# mkdir /mnt/gentoo/boot
# mount /dev/hda1 /mnt/gentoo
```

12. **获取 stage1 压缩包。** 假设你拥有最小化 Gentoo 安装 CD，你需要下载 stage1 压缩包。找到你附近的镜像站点（如前文所述）。在硬盘上创建一个目录来存放它，并使用 `wget` 等工具下载压缩包。例如：

> 如果你使用的是通用 CD，那里已经提供了 stage1 压缩包。无需下载，直接跳到下一步并从 /mnt/cdrom/stages/stage1\*.tar.bz2 解压压缩包即可。

```
# mkdir /mnt/gentoo/tmp2
# cd /mnt/gentoo
# wget -c http://gentoo.osu.org/releases/x86/2005.1/stages/stage1-x86-2005.1.tar.bz2
```

此处显示的多行 `wget` 命令应该在一行内输入。（第一行末尾的斜杠与下一行开头的单词 之间没有空格。）如果下载中途停止，你可以在相同目录下运行相同的命令来重启。

## 13. 解压 stage 1 压缩包。使用以下命令：

```
# cd /mnt/gentoo
# tar -xvjpf /mnt/gentoo/tmp2/stage1-*.tar.bz2
```

解压完成后，你就可以删除 stage1 压缩包。

14. **选择镜像站点。** 使用 `mirrorselect` 命令搜索 Gentoo 镜像，你可以从那里高效地下载安装所需的文件。运行以下命令选择一个高效镜像并将其添加到你的 `make.conf` 文件中（从 150 多个服务器下载速度可能需要一些时间）：

```
# mirrorselect -a s4 -o | grep Gentoo_MIRrors >> /mnt/gentoo/etc/make.conf
```

当在此过程中执行 `emerge` 命令时，可能会看到在任何其他站点未找到文件的消息，你可能需要从其他站点获取。

15. **挂载 /proc 文件系统。** 挂载 `/proc` 文件系统：

```
# mount -t proc /mnt/gentoo/proc
```

16. **切换根目录。** 使用 `chroot` 命令切换到根目录，以便进入新的 Gentoo 环境：

```
# chroot /mnt/gentoo /bin/bash
```

17. **更新环境变量。** 使用以下命令更新环境变量：

```
# source /etc/profile
```

18. **更新 Portage。** 更新 `make.conf` 文件：

```
# emerge --update-config
```

19. **更新 Portage 树。** 运行以下命令同步 Portage 树：

```
# emerge --sync
```

20. **修改 make.conf。** 使用 `nano` 编辑器 `make.conf`：

```
# nano /etc/make.conf
```

如果你不确定需要更改哪些设置，请参考 Gentoo 手册。

21. **编译内核。** 运行以下命令编译内核：

```
# genkernel
```

在完成更改后，使用以下命令进行内核配置：

```bash
# genkernel --menuconfig
```

22. **设置时区。** 使用符号链接设置时区：

```bash
# ln -sf /usr/share/zoneinfo/UTC /etc/localtime
```

23. **创建 fstab 表。** 编辑 `/etc/fstab`：

| 设备 | 挂载点 | 文件类型 | 选项 | 倾储 | 检查 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| /dev/hda1 | /boot | ext3 | defaults | 0 | 1 |
| /dev/hda2 | swap | swap | | 0 | 0 |
| /dev/hda3 | / | ext3 | defaults | 0 | 1 |
| /proc | /proc | proc | defaults | 0 | 0 |

24. **安装引导程序。** 安装 GRUB 引导程序：

```
# grub install
```

25. **添加冷启动。** 输入以下命令启用硬件检测：

```bash
# emerge coldplug
# rc-update add coldplug default
```

26. **配置系统服务。** 安装你的系统服务 —— 日志、定时任务、热插拔和 reiser 服务 —— 并设置域名。然后开启这些服务：

```
# emerge syslog-ng
# rc-update add syslog-ng default
# emerge vixie-cron
# rc-update add vixie-cron default
# emerge hotplug
# rc-update add hotplug default
# emerge reisersprogs
# rc-update add domainname default
```

27. **添加驱动支持。** 你的电脑可能需要特定的内核模块。例如，如果你有特殊的以太网适配器或类型的显卡，使用 `emerge` 安装内核模块：

```
# emerge nvidia-kernel
# emerge nforce-audio
# emerge e100
# emerge e1000
# emerge iau10k
# emerge ati-drivers
```

这些命令行仅在你拥有与内核驱动相关的特殊硬件时使用。分别，这些命令用于加速的 Nvidia 显卡、Nvidia Nforce 主板的音频、Intel e100 千兆网卡、Intel e1000 千兆网卡、2.4 内核的 Sound Blast/Audichemy 以及 ATI Radeon+/FireGL 显卡。

28. **添加用户信息。** 为 root 用户添加密码，创建一个你喜欢的普通账户（示例中为 chris），机器名和域名。如果你喜欢，还可以编辑 `/etc/hosts` 和 `/etc/rc.conf` 文件来添加 IP 地址或更改基础启动脚本。

```
# passwd
# useradd chris -G users,wheel,audio -s /bin/bash
# echo myname > /etc/hostname
# echo mydomain.com > /etc/dnsdomainname
# nano -w /etc/hosts
# nano -w /etc/rc.conf
```

29. **设置网络。** 编辑 net 文件，然后运行 `rc-update` 将 eth0 接口设为默认（取消 `interface eth0="dhcp"` 行以让网络使用 DHCP 自动启动）。

```bash
# nano -w /etc/config.d/net
# rc-update add net.eth0 default
```
