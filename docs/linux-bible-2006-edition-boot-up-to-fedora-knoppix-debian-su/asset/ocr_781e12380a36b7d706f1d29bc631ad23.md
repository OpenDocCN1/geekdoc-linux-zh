# Part III ✦ Choosing and Installing a Linux Distribution

Setting a firewall can be serious business. A misconfigured firewall can reject legitimate requests, forward packets to the wrong places, or even make your computer completely inaccessible from the network. Be cautious if you are trying the following procedure on a computer that you rely on to be safe and accessible from a network.

+   1. From a Terminal window, become root user:

```
$ su
Password: ********
#
```

+   2. Type the following to see what firewall rules are set on your system:

```
$ iptables -L
Chain INPUT (policy ACCEPT)     prot opt source      destination
Chain FORWARD (policy ACCEPT)
  target     prot opt source      destination
Chain OUTPUT (policy ACCEPT)
  target     prot opt source      destination
```

The example output shows that no filtering rules are currently set for this Linux system, meaning that all packets are accepted (policy ACCEPT) by default. If you make a complex set of firewall rules, you might consider using a different machine to try this.

+   3. These three commands change the default behavior of how packets are filtered for your computer:
$ iptables -P INPUT DROP
$ iptables -P OUTPUT DROP
$ iptables -P FORWARD DROP

In this example, the default behavior is changed such that all packets that come into your network interfaces (INPUT), or request to travel through them (FORWARD) are dropped. In this point, points should be allowed to come in or out of any network interfaces. You can run iptables -L to see that all policies have changed from ACCEPT to DROP. (If this concerns you, don't worry. You can run the commands again, changing DROP to ACCEPT, to make your firewall wide open once. Likewise, a reboot gets you back to your original state.)

+   4. This step configures your firewall will accept or reject ICMP packets. ICMP (Internet Control Message Protocol) messages are for reporting error conditions and controlling connections to your server. Your server receives ICMP packets from computers that want to find out the state of your machine, such as if the machine is currently accessible.
