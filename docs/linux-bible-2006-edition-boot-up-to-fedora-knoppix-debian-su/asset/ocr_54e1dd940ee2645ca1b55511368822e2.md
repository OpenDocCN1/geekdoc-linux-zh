+   * /midi100—Provides access to MIDI ports. Under Udev, access to MIDI ports is handled by symbolic links to device-special files in /dev/snd named midiC[0-9]. For example, /dev/midi100 would be a symbolic link to /dev/midiCD.

# Choosing an Audio CD Player

The GNOME CD player (gnome-cd) is the default CD player for GNOME desktop systems. In fact, if the HAL (halid) is enabled, as it is with Fedora systems, gnome-cd pops up automatically on the GNOME desktop when you insert a CD. It has standard play buttons and lets you track information automatically from a CD database, such as freeped.org (if your CD isn't found in the database, you can enter your own track information.)

A variety of CD players come with Linux distributions or be downloaded and installed. Here is a cross-section of your choices for playing CDs with Linux:

+   * Rhythmbox (rhythmbox)—Import and manage your CD collection with Rhythmbox music management and playback software for GNOME. It uses GStreamer on the audio backend and compresses music using Ogg Vorbis audio format. In addition to enabling you create playlists of your music library, Rhythmbox also has features for playing Internet radio stations.

+   * KcSD player (ksc)—The CD player comes with the KDE desktop. To use it, themimedia package must be installed. From the main menu of the KDE desktop, select Multimedia: KcSD (or type ksc in a Terminal window). Like gnome-cd, this player lets you view, track, and artist information from the CD database. KcSD, however, also lets you submit information to a CD database (if your CD isn't found)
