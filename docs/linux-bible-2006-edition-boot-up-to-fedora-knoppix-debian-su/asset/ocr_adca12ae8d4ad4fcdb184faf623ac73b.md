# Table 23-1
GNOME Games

| Game | Description |
|---|---|
| AisleRiot (solitaire) | Lets you select from among 28 different solitaire card games. |
| Chess | Gnuchess game in X. (Runs the chessboard and gnuche commands). |
| Chromium Configuration | Set options such as level, screen size, and sound for Chromium. |
| Chromium | Deliver supplies to troops in this action game. |
| FreeCell | A popular solitaire card game. |
| Freeciv (Isometric tileset) | In this strategy game, you try to lead your civilization to extinguish all others. (Uses Isometric tile to represent cities, oceans, and other terrain). |
| Freeciv Server (new game) | Server program needed to play Freeciv. |
| Ataxck | Board game where you flip over circles to consume enemy pieces. |
| Lines | Match five colored balls in a row to score points. |
| Four-In-A-Row | Drop balls to beat the game at making four in a row. |
| Nibbles | Steer a worm around the screen while avoiding walls. |
| Robots | Later version of Gnobots, which includes movable junk heaps. |
| Mines | Minesweeper clone. Click on safe places and avoid the bombs. |
| Stones | Move around a cave, collect diamonds, and avoid rocks. |
| Tetravex | A clone of Tetrax from the GNOME project. Move blocks so that numbers on each side align. |
| Klotski | Move pieces to allow one piece to escape. |
| Tali | Yahtzee clone. Roll dice to fill in categories. |
| lagno | Flip black and white chips to maneuver past the opponent. |
| Maelstrom | Navigate a spaceship through an asteroid field. |
| Mahjong | Classic Asian tile game. |
| Same GNOME | Eliminate clusters of balls for high score. |
| PenguinPlanet Racer | Steer a penguin as he races down a hill on his belly. |
