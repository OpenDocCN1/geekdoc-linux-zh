Packets from the Internet that are accepted for ICMP protocol requests in the following example are for ICMP types 8 and 11. Type 8 service allows your computer to accept reply messages, making it possible for people to ping your computer to see if it is available. Type 11 service returns packets with a time to live (TTL) that was exceeded in transit, and for which you are accepting a Time Exceeded message that is being returned to you. (You need to accept Type 11 messages to use the traceroute command to find broken routes to hosts you want to reach.)

```
# iptables -A INPUT -p ICMP -i eth0 -s 0/0 --icmp-type 8 -j ACCEPT
# iptables -A INPUT -p ICMP -i eth0 -s 0/0 --icmp-type 11 -j ACCEPT
```

These two lines define rules for ICMP packets that come into the first Ethernet interface (eth0) from any source (-s 0/0). The first line says to ACCEPT type 11 service, and the second says to ACCEPT type 11 service.

+   5. The following are examples of commands that define the packets that will be allowed to come in and go out of the local computer or the private LAN that the firewall is protecting:

```
# iptables -A INPUT -p ALL -i lo -s 127.0.0.1/3 -j ACCEPT
# iptables -A INPUT -p ALL -i lo -s 10.0.0.1/8 -j ACCEPT
# iptables -A INPUT -p ALL -i lo -s 323.45.67.89 -j ACCEPT
# iptables -A INPUT -p ALL -i eth1 -s 10.0.0.0/24 -j ACCEPT
# iptables -A INPUT -p ALL -i eth1 -d 10.0.0.255 -j ACCEPT
```

The result of these commands is that packets are sent from the local host itself (-s 127.0.0.1/8), an interface to the local LAN (-s 10.0.0.1/8), or the Internet (-s 323.45.67.89). The IP addresses 10.0.0.1 and 123.45.67.89 are examples of local interfaces to those networks (your addresses will be different). The last two lines indicate that the firewall should accept incoming packets that are from the private LAN (-s 10.0.0.0/24) or destined for any address on that LAN (-d 10.0.0.255), network requests.

> 323.45.67.89 is not a real IP address. You will replace it with the IP address assigned from your ISP for your external interface. No valid IP address can include a port higher than 255.

The following commands define accepting outgoing packets from the firewall:

```
# iptables -A OUTPUT -p ALL -s 127.0.0.1/8 -j ACCEPT
# iptables -A OUTPUT -p ALL -s 10.0.0.1/8 -j ACCEPT
# iptables -A OUTPUT -p ALL -s 323.45.67.89 -j ACCEPT
# iptables -A OUTPUT -p ALL -s 10.0.0.0/24 -j ACCEPT
# iptables -A OUTPUT -p ALL -d 10.0.0.255 -j ACCEPT
```
