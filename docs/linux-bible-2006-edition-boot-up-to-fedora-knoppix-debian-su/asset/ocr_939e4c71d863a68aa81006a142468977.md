# Chapter 8 ✦ Running Fedora Core and Red Hat Enterprise Linux 281

The Fedora Extras repositories are automatically added to your yum and update facilities. So, for example, if you know that you want to install the abiword package, you can do so by simply typing yum install abiword as root user. Yum grabs it and installs it from a Fedora Extras repository.

Packages in Fedora Extras are still expected to meet Red Hat's stringent guidelines. This means that you won't find proprietary software drivers (as those used with NVIDIA video cards or wireless cords intended for Windows systems) or with questionable patent issues (such as MP3 or video players).

Another effect of the Fedora Core/Fedora Extras approach, however, is that thirdparty, RPM-based software repositories have a wider base of common software libraries and utilities to rely upon. The rpm.livna.org repository (which includes many useful software packages that Red Hat will not distribute), depends on the Fedora Core and Fedora Extras repositories.

# Fedora Legacy Project

In April 2004, Red Hat, Inc. officially ended support for Red Hat 9, the last release of Red Hat Linux systems. That meant that Red Hat would no longer provide errata packages or gather bug reports for any Red Hat Linux systems. From RedHat's perspective, you either had to upgrade to RHEL or to a recent Fedora release. The Fedora Legacy Project (www.legacy.org) came with a third possibility: extend the lives of select Red Hat Linux systems.

Fedora Legacy Project's charter is to offer software patches for select Red Hat Linux and Fedora cores beyond the end of life set by Red Hat, Inc. These critical fixes and security patches are necessary for an operating system to remain stable for up to two or three years. Without this, companies and consultants who want to use Fedora Core with their hardware or software products can't expect to have a stable OS to rely on for more than a few months.

As of writing, Red Hat Linux 7.3 and 9 releases have both Fedora Legacy Project software repositories from which you can download available critical software updates and continuing to be maintained. Fedora Legacy support for Red Hat 7.2 and 8 has been suspended because of lack of community support. Those who are using 7.2 and 8 are urged to upgrade to 7.3 or 9. (Of course, upgrades to legacy releases may be the better way to go.) Fedora Legacy has also taken over support of Fedora Core 1 and 2.

By following a few simple steps from the Fedora Legacy download page (www.fedoralacy.org/download), you can use yum or apt tools to configure your system to automatically download and install selected packages.

Fedora Legacy Project's site provides a lot of information, from a mailing list and IRC channel you can join to overview material you can read about the project.
