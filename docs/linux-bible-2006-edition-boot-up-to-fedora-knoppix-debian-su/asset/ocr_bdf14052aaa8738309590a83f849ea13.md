# 608 Part IV ♦ Running Applications

After you install the CrossOver Plugin, you see a nice Plugin setup that lets you selectively install plug-ins for QuickTime 6.5, Windows Media Player 6.4, Shockwave 8.5, Flash 6, iTunes, and Lotus Notes, as well as Microsoft Word, Excel, and PowerPoint views. (Support for later versions of these content formats may be available by the time you read this.) You can install other multimedia plug-ins, as well as a variety of fonts to use those plugins.

Follow the installation instructions with the plug-in you downloaded. The plug-ins in RPM file, it is not unless any other software package if you are using an RPM-based Linux distribution (rpm -Uvh command). The plug-doesn't come with instructions, just copy the plug-in file (the .so file) to the system plug-directory (such as /usr/lib/mozilla/plugins) or your personal plug-directory (probably HOME/.mozilla/plugins), if you are not instructed. When you restart Mozilla, the plug-ins are automatically picked up from those locations.

Most plug-ins work for Firefox as well. To have the plug-in for all users who run Firefox on the system, put the plug-in in /usr/lib/firefox~/plugins directory.

# Using Mozilla Navigator Controls

If you have used a Web browser, the Mozilla Navigator controls are probably as you might expect: location box, forward and back buttons, file and edit menus and so on. There are a few controls with Mozilla, that you might not need to use, see as these:

+   **Sidebar** - Press the F9 function key to toggle the sidebar on and off.
The sidebar is a left column on your Mozilla screen for quick access to Searches, Bookmarks, and History. Use the Search tab to search for Web content; the Bookmark tab to add your own bookmarks; and the History tab to return to pages in your history list. The What's Related tab shows a list of links available from the current Web page.

+   **Send Web Content** - You can send an e-mail containing the current Web page (File:- Send Page) or the URL of the current Web page (File:- Send Link) to selected recipients.

+   **Search the Internet** - You can search the Internet for a keyword phrase in many different ways. Choose Tools:- Search Web to open a Netscape Web site lets you search the Internet, or one or more keywords in the Location box and click Search. And of course you can use the sidebar's Search tab described earlier.
