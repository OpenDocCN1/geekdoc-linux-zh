# KNOPPIX Security Tools Distribution

The Knopix-STD is lightweight on the window manager to go heavyweight on the diagnostic tools. The distribution contains hundreds of tools that can be used for repairing and assessing computer and network security (http://knoppix-std.org).

Instead of a GNOME desktop, Knopix-STD uses the Fluxbox window manager. It will run on lesser machines, but any Pentium-class machine with at least 64MB of RAM. With 640MB of RAM, you can run the entire distribution from RAM (type knoppix toram to boot it entirely from RAM). With Knopix-STD running, the system operates faster and your CD or DVD drive is available for other purposes.

Go to the project's Tools page (www.knoppix-std.org/tools.html) to find out more features about the project. Or go to the download page (www.knoppix-std.org/download.html) to download and try it yourself.
