If you want to specify a particular printer (other than the default), add the -Pprinter option. For example, to print to the lp0 printer, type the following:

```
$ lpr -Llp0 file.ps
```

If you want to print more than one copy of a document, use the -num option, where num is replaced by the number of copies you want. For example, to print five copies of a file, use:

```
$ lpr -#5 file.ps
```

The lpr command can accept standard output for printing. For example, you can print the output of a groff command by piping that output to lpr as follows:

```
$ groff -Tps -man /tmp/chown.1 | lpr -Llp0
```

# Checking the Print Queues

To check the status of print jobs that have been queued, use the lpq command. By itself, lpq prints a listing of jobs that are in the queue for the default printer. For example:

```
$ lpq
hpy is ready and printing
Rank Owner Job Files Total Size
active root 3 hosts 1024 bytes
1st root 7 (stdin) 625 bytes
2nd root 8 memo.ps 12273 bytes
3rd chuck 9 bikes.ps 10880 bytes
```

The output from lpq shows the printer status and the jobs waiting to be printed. Rank lists the order in which they are in the queue. Owner is the user who queued the job. Job shows the job number. The Files column shows the name of the file or standard output (if the file was piped or directed to lpr). Total Size shows how large each file is in bytes.

You can add options to lpq to print different kinds of information. By adding -P, you can see the queue for any available printer. You can also add the job number (to see the status of a particular print job) or a username (to see all queued jobs for a user).

# Removing Print Jobs

If you have printed a large document by mistake, you understand the value of being able to remove a print job from the queue. Likewise, if a printer is going to down for a while and everyone has already printed their jobs to another printer, it's sometimes nice to clear all the print jobs when the printer comes back. Remove print jobs using lprm. For example, to remove all jobs for the user bill (assuming you are either bill or the root user), type the following:

```
$ lprm
```

The root user can remove all jobs from the queue. To do this, add a dash (-) to the lprm command line, as follows:

```
$ lprm -
```

You can also remove jobs for a particular printer (-Pprinter) or for a particular job by adding the job number to the lprm command line.

# Checking Printer Status

Sometimes nothing comes out of a printer, and you need a clue about what's going on. The status command is intended for administrators, so it may not be in your default PATH. To stop the status command, type the following:

```
$ status
```

When the command returns to the prompt, type:

```
status
printer is on device
queuing is enabled
printing is enabled
no entries
```

This example shows the status of printer: queuing and printing are enabled, the printer shows no print jobs waiting. To quit, type exit.

# Displaying Documents with ghostscript and Acrobat

Document publishing can be very page-intensive if you send a Groff or LaTeX document to the printer each time you want to make a change to the document's content or formatting. To save time, use print preview to display your document on the screen as it will appear on the printed page. The following sections describe ghostscript command for displaying PostScript files and Adobe Acrobat Reader for displaying Portable Document Format (PDF) files.

# Using ghostscript and gv Commands

To display PostScript or PDF documents in Linux, you can use the ghostscript command. It is a fairly crude interface, intended to let you step through documents and interpret them one at a time. You can display any PS or PDF file you happen to have on your computer. For example, if the gv package is installed, you can use the following to display your own PDF file:

```
$ ghostscript /usr/share/doc/samba/HOWTO-Collection.pdf
```

The gv command (GNOME ghostview) is another friendly way of viewing PostScript files. To use gv to open a named file bash.ps, type the following:

```
$ gv
```

When the ghostview window opens, you can see the document. Left-click on the page and move the mouse up and down to scroll the document. Use the Page Up and Page Down keys to page through the document. You can click a page number in the left column to jump to a particular page or click the Print All button to print the entire document.

# Using Acrobat Reader

The Portable Document Format (PDF) provides a way of storing documents as they would appear in print. With Adobe Acrobat Reader, you can view PDF files in a friendly way. Adobe Acrobat makes it easy to move around within a PDF file. A PDF file may include hyperlinks, a table of contents, graphics, and a variety of type fonts.

# Working with Graphics

Tools for creating and manipulating graphics are becoming both more plentiful and more powerful in Linux systems as a whole. Leading the list is the GNU Image Manipulation Program (GIMP). GIMP lets you compose and author images as well as retouch photographs. Other tools for creating graphics include knsnapshot (a program for taking screen captures) and kpaint (for working with bitmap images).

# Manipulating Images With the GIMP

The GIMP is a free software for manipulating photographs and graphical images. To create images with GIMP, you can either import a drawing, photograph, or 3D image, or you can create one from scratch. You can start GIMP from the system menu by selecting Graphics< GIMP or by typing gimp from a Terminal window.
