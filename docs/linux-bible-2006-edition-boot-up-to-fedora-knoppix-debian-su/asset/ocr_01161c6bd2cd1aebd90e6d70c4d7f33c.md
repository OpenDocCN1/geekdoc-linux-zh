# Summary

Ubuntu is certainly the past year's rising star of Linux distributions. Ubuntu started with Debian (one of the most respected but challenging distributions for beginners) and simplified the packaging and installation. Using a single installation CD, a user can install a set of useful desktop software or a streamlined server system.

While the installation process is text-based (no fancy graphics or mouse during installs), the process is greatly simplified in comparison to the Debian systems need to be installed. The user is offered limited choices during installation, making the installation process simple if not as customizable as want. (Of, you can change the system you want after it is installed.)

Along with the growth in popularity of Ubuntu has come an active community of developers and users. To become involved with Ubuntu, a good place to start is with community forums and the Ubuntu Wiki.
