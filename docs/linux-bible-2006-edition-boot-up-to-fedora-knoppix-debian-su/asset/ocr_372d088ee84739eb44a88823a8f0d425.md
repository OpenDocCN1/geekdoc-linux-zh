# Removing Print Jobs

If you have printed a large document by mistake, you understand the value of being able to remove a print job from the queue. Likewise, if a printer is going to be down for a while and everyone has already printed their jobs to another printer, it's sometimes nice to be clear all the print jobs when the printer comes back.

Remove print jobs using 1prm. For example, to remove all jobs for the user named bill (assuming you are either bill or the root user), type the following:

```
$ 1prm bill
```

The root user can remove all print jobs from the queue. To do this, you add a dash (-) to the 1prm command line, as follows:

```
$ 1prm -
```

You can also requeue print jobs for a particular printer (-Pprinter) or for a particular job by just adding the job number to the 1prm command line.

# Checking Printer Status

Sometimes nothing comes out of a printer, and you have no why. lpc is a status command that might give you a clue about what's going on with your printer. It is intended for administrators, so it may not be in your default PATH. To stop the lpc command, type the following:

```
: "# /usr/sbin/lpc"
```

When the command returns the lpc> prompt, type the word status:

```
lpc status
h:
printer is on device 'lpd' speed -1
queuing is enabled
printing is enabled
no entries
daemon present
lpc>
```

This example shows the status of printer hp: queuing and printing are enabled, the printer shows no problems, and no print jobs are waiting. To quit the lpc-command, type exit at the lpc> prompt.
