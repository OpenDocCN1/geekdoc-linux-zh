# Adding More Software

While Ubuntu manages to install 1.7GB of applications from a single Ubuntu CD, it's only 1.7GB. By contrast, the Fedora Core four-cd system can install up to 7GB of applications. To add more software to Ubuntu, you can use the common Debian packages (apt-get and dpkg). However, you can also use the Synaptic Package Manager for adding and removing software packages.

To open the Synaptic Package Manager, select System ⟷ Synaptic Package Manager. Figure 17-3 shows the Synaptic Package Manager window.

Using Synaptic Package Manager, you can install more software by selecting the Not Installed entry in the next column, and then selecting the package you want to install to the left. With one or more packages selected, select Apply and the software packages you selected will be downloaded from an Internet repository and installed.

As Ubuntu is installed, it will check only Ubuntu software repositories to find and download the software you add to Ubuntu. There are, however, when you want to add community-build software that is outside the official distribution, in referred to as Universe and Multiverse:

- **Universe** — Packages stored in Universe repositories include software that is not yet stable enough to be included in the project. Although the software has been built against Ubuntu libraries by the Ubuntu community, and will work well in most cases, it comes without guarantee of support or security fixes.

- **Multiverse** — Packages in Multiverse repositories contain software that is not free. This means the software licensing might not meet Ubuntu requirements, that the software may be encumbered by patent issues, or that only binary versions are available. Users are encouraged to research licensing and other legal issues themselves before using software from these repositories.

Follow these steps to add the Universe and Multiverse repositories to Synaptic Package Manager so you can use them to get additional Ubuntu software that might not be stable enough to be part of the Ubuntu release:

- 1. From the Synaptic Package Manager main window, select Settings ⟷ Repositories. The Software Preferences window appears, displaying the software that are active for your system.
- 2. Select Settings. A setting pop-up window appears, as shown in Figure 17-4.

- 3. Select Show disabled software sources and click Close. Additional community-maintained software repositories are displayed on the Software Preferences window.

> Caution

> As with any Linux distribution, any time you aspire to use repositories that are outside of the official repositories supported by that distribution, you should carefully scrutinize that repository. Unofficial repositories can break software compatibility, can contain software that you cannot use legally, and might even contain malicious software. Although it is still no guarantee of safety, check Ubuntu forums and mailing lists to find outside repositories others have found to be reliable before using them yourself. Also, look for repositories that are specific to your version of Ubuntu because software from earlier Ubuntu releases or Debian-specific releases may not work.

To add a custom repository to Ubuntu, do the following from the Synaptic Package Manager:

- 1. Select Settings: The Software Preferences window appears.
- 2. Select Add: The Edit Repository window appears.
- 3. Select Custom: You are asked to add a line.
- 4. Type the line identifying the repository, for example:
deb http://example.com/ubuntu main
- 5. Click OK: The repository list is updated.
- 6. Click OK: You are warned that your repository list has changed.
- 7. Click Reload: The package information is downloaded.

At this point, you can install any of the software that was added to your software list. (Click Not Installed in the left to see any packages you want.)

# Summary

Ubuntu is certainly the past year's rising star of Linux distributions. Ubuntu started with Debian (one of the most respected but challenging distributions for beginners) and simplified the packaging and installation. Using a single installation CD, a user can install a set of useful desktop software or a streamlined server system.

While the installation process is text-based (no fancy graphics or mouse during installs), the process is greatly simplified in comparison to the Debian systems. The user is offered limited choices during installation, making the installation process simple if not as customizable as want. (Of, you can change the system you want after it is installed.)

Along with the growth in popularity of Ubuntu has come an active community of developers and users. To become involved with Ubuntu, a good place to start is with community forums and the Ubuntu Wiki.
