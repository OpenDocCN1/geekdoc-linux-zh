# Part III ♦ Choosing and Installing a Linux Distribution

Because the Debian CD image included with this book is the network install image, the CD itself will provide software for installing only a minimal Debian system. You will need a network connection or other Debian software CDs to install, for example, a full desktop system or the LAMP and mail servers described in Chapter 24 and 25.

+   - You have the option of adding another APT source. If you have an Internet connection and want to have the installer check for updated packages, choose either the HTTP or FTP methods (HTTP is recommended), and then select a country and a mirror server from the list. You are prompted for any HTTP proxy configuration, which may be necessary on some corporate or school networks. If you're not sure, check with your support desk. If it does not apply, leave it empty. APT retrieves a list of packages from the site that you selected.

+   - The installer attempts to retrieve a list of security updates from the Debian security archive. This step will fail if you do not have an Internet connection, but you can still finish the installation.

+   - You are presented with a list of predefined package sets (as tasks) that you can select for installation. Package installation is covered in greater detail later, so I recommend that you do not select any tasks from this list now. Use the tab to get to the OK box.

+   - APT downloads any updated packages (this could take quite a while, depending on available updates and your connection speed), and deconf you to configure any packages that are in the half-installed state. If at any time you are uncertain about which option to select, you can proceed stick with the default.

+   - Assuming that you not select any tasks, the only package needing configuration is the Exim mail agent. The configuration questions asked during this stage may vary. When in doubt, use the default settings.

When the Configuring Exim screen appears, choose from a list of default configurations; here are the most likely options:

+   - internet site; mail sent and received directly via SMTP — This option configures your server to accept incoming mail and deliver outgoing mail directly to the servers for the recipient domain. This configuration is useful if you are running a simple mail server or if you are mut or pipe to check your mail locally.

+   - mail sent by smarthost; received via SMTP or fetchmail — This option is almost identical to the previous option, you will be prompted to enter a server for all outgoing mail will be sent through. This option may be necessary if the ability to connect directly to outside mail servers is provided on your network.
