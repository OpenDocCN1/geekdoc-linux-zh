# 496 Part III ♦ Choosing and Installing a Linux Distribution

Dann Small's default desktop is pretty simple. The window manager is the powerful, yet efficient, FluxBox window manager (based on BlackBox). Right-click the desktop to see a menu of features you can select. Here are a few things you want to do when you first boot up Dunn Small:

+   * Enhance your desktop—Right-click to see the Dunn Small menu, and then select Desktop Full Enhanced Desktop. This adds some icons to your desktop applications, some apples in the lower right corner to display system information, and a workspace editor. Select Desktop again if you want to change the Styles (colors and window borders), or Configuration to change desktop behavior.

+   * Get a network connection—If you don't automatically get the Internet at boot time, select System Net Setup from the Dunn Small menu. Then you can configure to your Ethernet card, DSL connection, dial-up modem, or wireless card.

+   * Browse the web—Dann Small comes with the Dillo web browser. The browser is simple, fast, and can run on any X window manager because it doesn't require GNOME libraries.

+   * Configure and read email—The Spyeed client is very close to perfect and runs fast. Select Apps Net Spyeed to open it. Configure it and you can be up and reading your e-mail within a few minutes.

+   * Try other applications—Right-click and look through the menu for applications that interest you. See descriptions of those applications, visit http://damnsmallinux.org/applications.html.

+   * Get other applications—Select the MySQL on the desktop to select of applications you can choose from. If you are connected to the Internet, you can see lists of applications in each category to choose for downloading and installing.

> Note You can get other DSL files that let you download other applications from your desktop as well. Visit www.damnsmallinux.org and select the link to packages to my MySQL repository.

Dann Small Linux has recently added some excellent customization features. For example, packages you download, desktop settings, and configuration information can be saved across reboots. By creating a list of packages and files you want to save, these files and packages can be saved to a backup file that is stored on your hard disk or any removable medium. The next time you reboot, you can tell Dunn Small Linux to find that backup file and all settings and applications will be inserted into your current Dunn Small session.

More information about using Dunn Small Linux is available at the project FAQ page, www.damnsmall.org/faq.html.
