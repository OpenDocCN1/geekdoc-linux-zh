+   Downloadable applications—If the applications you are not delivered with your version of Linux, you can download and install them with a single command, using tools such as apt and yum.

+   Freedom—Linux, in its most basic form, has no corporate agenda or bottom line to meet. You are free to choose the Linux distribution that suits you, at the code that you write the system, and remove any software you like, and make your computer do what you want it to.

There are some aspects of Linux that make it hard for some new users to get started. One is that Linux is typically up to be secure by default, so you need to adjust using an administrative login (root) to make changes that affect the whole computer system. Although this can be a bit inconvenient, trust me, it makes your computer safer than just letting anyone do anything.

For the same reason, many services are off by default, so you need to turn them on and at least minimal configuration to get them going. For someone who is used to Windows, Linux can be difficult because it is different from Windows. But you're reading this book, I assume you want to learn about those differences.

# OSI Open Source Definition

For developers, Linux provides a platform that lets them change the operating system as they like and get a wide range of help creating the applications they need. One of the watchdogs of the open source movement is the Open Source Initiative (www.opensource.org). This is how the OSI website describes open source:

The basic idea behind open source is very simple: When programmers can read, redistribute, and modify the source code for a piece of software, the software evolves. People improve it, people adapt it, people fix bugs. And this can happen at a speed that, if one is to use the slow pace of conventional software development, seems astonishing.
