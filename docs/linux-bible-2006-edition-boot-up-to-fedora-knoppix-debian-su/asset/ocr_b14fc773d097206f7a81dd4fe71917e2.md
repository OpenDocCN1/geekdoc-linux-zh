# Creating Text-Mode User Interfaces with S-Lang

S-Lang, created by John Davis, is an alternative to creating TUIs. In addition to providing screen manipulation and cursor control routines, S-Lang also consists of an embeddable S-Lang interpreter, a large library of built-in (intrinsic) routines that simplify parts of programming, and a variety of data types and data structures.
