## Tips for Using Firefox

There are so many features in Firefox, it's hard to cover all of them. Just to point you toward a more fun and useful features, here are some tips for using Firefox:

- **Add smart keywords**— Many Websites include their search boxes to allow you to look for information on their sites. With Firefox, you can assign a smart keyword to any search box on the Web, and then use that keyword from the location bar in the browser to search for that.

For example, go to the Linux Documentation Project select (http://tdp.org). Right-click in the Search/Resources search box. Select Add Keyword for the Search from the menu that appears. Add a name (Linux Documentation) and a keyword (tdp) and select Add the keyword to your Bookmarks.

After you have added the keyword, you can use it by simply entering the keyword or one more terms to the Firefox location box (on the navigation toolbar). For example, I entered Lego Mindstorms and can come up with a list of HOWs using Lego Mindstorms in Linux

- **Check config**—Firefox has hundreds of configurations available to set as you use. You can see these options by typing config into the location box. For true/false options, you can simply click on the preference name to toggle between the two values. For other preferences, click the preference to enter a value into a pop-up box. Many of these values can be changed through the Preferences menu (Edit: Preferences), some people prefer to look at settings in a list like the one shown on about:config

- **Multiple home pages**— Instead of using one home page, you can have a whole set of home pages. When you start Firefox, a separate tab will open in the Firefox window for each address you identify in your home page list. To do this, create multiple tabs (Edit: New Tab) and enter the address for each page you want in your list of home pages. Select Edit Preferences General and click the Use Current Pages button. The next time you open Firefox, it will start with the selected tabs open to the home pages you chose. (Clicking the icon will open new tabs for all the home pages.)

## Summary

You have a lot of high-quality applications available to fulfill your needs for a Web browser and e-mail client in Linux. Most Web browsers are based on the Mozilla gecko engine (which came originally from Netscape Navigator). Firefox is being slated as the next generation replacement for Mozilla Navigator. ## Gaming with Linux

There are literally hundreds of games that run in Linux. Freely distributed games include popular card games, board games, strategy games, and first person shooters. The list of commercial games that will run in Linux has also grown steadily in recent years.

These days, many native Linux games are also network-enabled. You can battle tanks (BZFlag), create civilizations (freeciv) or play standard board games (gnutches) against others on the Internet. In most cases, the clients (playing the games) and the game servers (managing dozens or hundreds of players) will all run natively in Linux.

This chapter provides an overview of the state of Linux gaming today. It describes games that were created specifically to run in Linux, and explains how to find commercial games that run in Linux (either with a Linux version or running a Windows version along with Windows compatibility software, such as Cedega).

## Tips for Using Firefox

There are so many features in Firefox, it's hard to cover all of them. Just to point you toward a more fun and useful features, here are some tips for using Firefox:

- **Add smart keywords**— Many Websites include their search boxes to allow you to look for information on their sites. With Firefox, you can assign a smart keyword to any search box on the Web, and then use that keyword from the location bar in the browser to search for that.

For example, go to the Linux Documentation Project select (http://tdp.org). Right-click in the Search/Resources search box. Select Add Keyword for the Search from the menu that appears. Add a name (Linux Documentation) and a keyword (tdp) and select Add the keyword to your Bookmarks.

After you have added the keyword, you can use it by simply entering the keyword or one more terms to the Firefox location box (on the navigation toolbar). For example, I entered Lego Mindstorms and can come up with a list of HOWs using Lego Mindstorms in Linux

- **Check config**—Firefox has hundreds of configurations available to set as you use. You can see these options by typing config into the location box. For true/false options, you can simply click on the preference name to toggle between the two values. For other preferences, click the preference to enter a value into a pop-up box. Many of these values can be changed through the Preferences menu (Edit: Preferences), some people prefer to look at settings in a list like the one shown on about:config

- **Multiple home pages**— Instead of using one home page, you can have a whole set of home pages. When you start Firefox, a separate tab will open in the Firefox window for each address you identify in your home page list. To do this, create multiple tabs (Edit: New Tab) and enter the address for each page you want in your list of home pages. Select Edit Preferences General and click the Use Current Pages button. The next time you open Firefox, it will start with the selected tabs open to the home pages you chose. (Clicking the icon will open new tabs for all the home pages.)

## Gaming with Linux

There are literally hundreds of games that run in Linux. Freely distributed games include popular card games, board games, strategy games, and first person shooters. The list of commercial games that will run in Linux has also grown steadily in recent years.

These days, many native Linux games are also network-enabled. You can battle tanks (BZFlag), create civilizations (freeciv) or play standard board games (gnutches) against others on the Internet. In most cases, the clients (playing the games) and the game servers (managing dozens or hundreds of players) will all run natively in Linux.

This chapter provides an overview of the state of Linux gaming today. It describes games that were created specifically to run in Linux, and explains how to find commercial games that run in Linux (either with a Linux version or running a Windows version along with Windows compatibility software, such as Cedega).
