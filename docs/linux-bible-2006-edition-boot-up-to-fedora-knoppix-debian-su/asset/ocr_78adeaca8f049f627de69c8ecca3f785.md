# Installing Mac OS 9 or Below and Yellow Dog Linux on One Hard Drive

If you want to install Mac OS 9 or below in addition to Yellow Dog Linux on one hard
drive, you can perform the following for a dual-booted machine:

+   1. Boot the Mac OS CD by holding down the C with the Mac OS CD-ROM
inserted.

+   2. Double-click the Utilities or Disk Tools folder. Double-click the Drive Setup
application.

+   3. Select your hard drive in the List of Drives in the Drive Setup window.

+   4. Click the Initialize button, and then click the Custom Pop-up window

+   5. Choose how many partitions you want in the Custom Setup pop-up window
(3 is a good selection for both Mac OS and Yellow Dog Linux, or 4
partitions for Mac OS, Mac OS X, and Yellow Dog Linux). You can use the
sider to change the size of the partitions here.

+   6. Choose the top partition and select Unallocated in the menu by default
displays Mac OS Extended. The extended partition should be Mac OS Standard
for Mac OS, and if you are loading Mac OS X as well, the third partition should
be Mac OS Extended (available only if you chose 3 partitions). Make sure to
label the partitions appropriately.

+   7. Select OK and then Initialize.

Resume your installation of Mac OS as normal.
