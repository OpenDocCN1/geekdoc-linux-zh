Video device — The Device section is where you identify the driver to use with your video driver and any options to use with it. It's important to get this section right. The Xorg command described earlier usually does a good job detecting the. If you want to change to a different one, this is where to do so. Here is an example of the Device section after I added a video driver from NVIDIA (driver name nv):

```
Section "Device"
  Identifier "Card0"
  Driver "nv"
  VendorName "nVIDIA Corporation"
  BoardName "Unknown Board"
  BusID "PCI:1:0:0"
EndSection
```

Screen resolution — The last piece of information you may want to add is the screen resolution and color depth. There will be a screen section associated with each video card installed on your computer. The section defines color depths (such as 8, 16 or 24) and modes (such as 1024 × 768 × 600, or 640 × 480). Set the DefaultDepth to the number of bits representing color depth for your system, and then add a Modes line to set the screen resolution.

Read more about how to set your options in xorg.conf file, type man xorg.conf. If your server is XFree86, type man XF86Config.
