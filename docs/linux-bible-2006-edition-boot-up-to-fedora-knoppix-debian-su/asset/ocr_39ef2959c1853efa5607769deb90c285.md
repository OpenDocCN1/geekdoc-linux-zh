# Chapter 17 ♦ Running Ubuntu Linux 453

Sound & Video — Like other commercial Linux distributions, Ubuntu doesn't include the software needed to play commercial DVD movies or MP3 music. However, it comes with a simple CD player, the Rhythm Music Player, Sound Juicer CD ripper, and Serpent audio recording application. There are also controls for volume and recording levels.

System Tools — Useful tools are installed on the System Tools menu. The Network Tools utility lets you run a variety of tools for checking your network (viewing your interfaces, peering a remote system, or running a scan to check for unprotected ports). To get to shell, you can launch the Terminal application. Other tools on this menu let floppy disks, re-login to your desktop, monitor system activity, and check log files.

The menus keep track of places you went to, lets you connect to remote servers, and you see (and, if you connect) to recently opened documents. There is also an option available to search your system for files.

# Adding More Software

While manages to install 1.7GB of applications from a single Ubuntu CD, it's only 1.7GB. By contrast, the Fedora Core four-cd system can install up to 7GB of applications. To add more software to Ubuntu, you can use the common Debian packages (apt-get and dpkg). However, you can also use the Synaptic Package Manager for adding and removing software packages.

To open the Synaptic Package Manager, select System ⟷ Synaptic Package Manager. Figure 17-3 shows the Synaptic Package Manager window.

Using Synaptic Package Manager, you can install more software by selecting the Not Installed entry in the next column, and then selecting the package you want to install to the left. With one or more packages selected, select Apply and the software packages you selected will be downloaded from an Internet repository and installed.
