## Table 28-1
Common Linux APIs

| API | Category | Description |
| :--- | :--- | :--- |
| aalib | ASCII art | AA-lib is an ASCII graphics library output as ASCII art. |
| arts | Sound | The analog realtime synthesizer (aRTs) of KDE's core system, designed to create and process sound using small specialized modules. These modules might create a waveform, play samples, filter data, adds signals, perform effects (such as delay, flanger, or chorus), or output the data to the soundcard. |
| atk | Accessibility | atk is a library of accessibility functions used by GNOME. |
| audiofile | Audio | audiofile, used by the sound daemon (Berkeley Sound Daemon), is a library for processing audio file formats. You can use it to develop your own audio file-based applications. |
| db4 | Database | The Berkeley Database (DB) library for parsing SQL allows developers to create applications with database support. |
| expat | XML | Expat is a stream-oriented XML parser used by Python, GNOME, Xf2, and other applications. |
| gdbm | Database | The GNU Database Manager (GDBM) is a set of database routines that work similarly to the standard UNIX dbm. |
| gdk-pixbuf | 2-D Graphics | GdkPixbuf is an API for scaling, composing, and animating images. GdkPixbuf is required by many GTK+ programs. |
| glib | General | GLib is a general purpose API of C language routines. The library includes support for features such as lists, trees, hashes, memory allocation, and many other things. GLib is required by almost every GTK+ application. |
| glut | 3-D Graphics | The GL Utility (GLUT) is a 3D graphics library based on the OpenGL API. It provides a higher-level interface for creation of OpenGL-based graphics. |
| gmp | Mathematics | The GNU Multiple Precision (GMP) API implements a library for arbitrary precision arithmetic, such as operations on signed integers, rational numbers, and floating-point numbers. |
| gnet | Network | GNet is an object-oriented library of network routines. Written in C and based on the GLib library, GNet is used by gnomeicu and Pan. |

| libusb | Hardware | libusb allows user space application access to USB devices. |
| libvorbis | Audio | This library supports the Vorbis General Audio Compression Code, commonly known as Ogg Vorbis. Ogg Vorbis is an open, royalty-free, general-purpose compressed format for audio. |

As you can see, a wide variety of APIs exist for performing an equally wide variety of programming tasks. Tasks are pretty good that if you need to perform some sort of programming task, someone has written a library that you can use to do.

## Summary

The phrase “Linux programming environments and interfaces” is shorthand that masks a rich set of features, which, taken together, only partially characterize the activity of programming on a Linux system.
