## Improving Mozilla Browsing

Not every site you visit with Mozilla is going to play well. Some sites don't follow standards, use unbearable fonts, choose colors that make it hard to see, or demand that you use a particular type of browser to view their content. To improve your browsing experience, there are several things you can add to Mozilla.

> If you encounter a problem with Mozilla that you cannot overcome, I recommend that you refer to the Mozilla Bugzilla database (https://bugzilla.mozilla.org). This site is an excellent place to search for others who have found (many times you can get around your problems) or enter a bug report about difficult-to-read pages.

## Adding a Preferences Toolbar

Did you ever enter a Web page that required you to use a particular type of browser or have fonts or colors that make a page unreadable? The Mozilla preferences toolbar called PrefBar3 enables you to spoof Web sites into thinking you are running a different browser. It also lets you choose settings that might improve colors, fonts, and other attributes on difficult-to-read pages.

You can install the neat toolbar from the Mozilladev site (http://prefmozdev.org). Click the Install link, and after it is installed, restart Mozilla.

## Adding Java Support

If you want to display Java content, but you only see a broken puzzle piece and a failure message that says you need a plug-in to view application/x-java-whatevercontent, you can install the software from the Sun Microsystems Web site (www.sun.com). Look for the Java 2 Runtime Environment package at java.sun.com/download. It should say like Java 2 Platform, Standard Edition. Be sure to select the one that runs on Linux.

## Doing Cool Things with Mozilla

Some neats and whistles are built into Mozilla that can make your browsing more pleasant. The following sections explore a few of those features.

## Blocking Pop-ups

You can block annoying pop-up windows using the Mozilla Preferences window. Here's:

1. Click Edit -> Preferences. The Preferences window appears.
2. Click Popup Windows under the Privacy & Security category.
3. Click the Block Unrequested Popup Windows.
4. Click OK. You won't get any more pop-up windows from this point.

As the Preferences window notes, de-facto-o by blocking all pop-ups might keep some Web sites from working properly. The Allowed Sites button to allow pop-ups on certain sites that you choose.

## Using the DOM

If you are debugging a page, the Document Object Model (DOM) can be useful for checking the structure of the page. To use the DOM inspector, go to Edit -> Preferences and click on the Advanced tab. The inspector window will open and show you a list of all the elements on the page. You can click on any element to see its attributes and properties.

## Resizing the Web Page

There is a nice keyboard shortcut that lets you quickly resize the text on most pages. Hold the Ctrl key and press the (+) or (-) keys. In most cases, text on the page gets larger or smaller.

## Using Text-Based Browsers

If you become a Linux administrator or power user, you will inevitably find yourself working on a computer where there is no GUI. At some point while you are in that state, you will want to check an HTML file. To solve the, many Linux distributions include several text-based browsers.

With text-based browsers, any HTML file from the Web, your local file system, or a computer where you are remotely located can be accessed from your shell. There is no need to fire up a GUI or read pages of HTML markup if you want to take a peek at the contents of a Web page. In addition enabling you to call up Web pages, move around those pages, and follow links to other pages, some of browsers display graphics in a terminal window!
