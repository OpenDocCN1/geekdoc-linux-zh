# 822 Appendix A + Media

+   **DVD or CD drive:** You need a drive from which to copy the ISO image of the CD you want from the DVD or CD that come with this book, depending on which medium contains the image you want. If you don't have a DVD drive, download and verify Linux installation CD images yourself, as described in Chapter 7. Then those images to CD, as explained later in this appendix.

+   **Linux Bible 2006 Edition DVD or CD:** The DVD contains several CD images that you can burn to CD and install to use with Linux. The CD contains several live CD images and several install images you can burn to CD.

+   **Blank CDs:** You need blank CDs to burn the CD images to.

+   **CD burner:** You can use a different drive from your DVD/CD to burn CDs. Or you can copy a CD to hard disk, remove the DVD/CD, and burn the new CD to a CD in the same drive.

Unless you have two DVD/CD drives, you must copy the CD image to your hard disk before you can burn it. (If you have two drives, simply skip the steps for copying the CD image to hard disk).

Here is how to create bootable Linux CDs from a running Linux system (such as Fedora Core:

+   1. With a Linux desktop system running, insert the disk into the Linux Bible 2006 Edition disk that contains the ISO you want to burn.

+   2. If an icon appears on the desktop, open it (double-click). (If an icon doesn't appear, mount the disk by manually typing like the following root user: **mount /dev/cdrom** or **/dev/hdc**, depending on the location of your DVD or CD drive. Then browse to where that image is located from your desktop window manager. It's probably mounted to **/mnt/cdrom** or something like **/media/recorder/.)

+   3. Open the *directory* and select the Linux ISO image you want to burn to CD. Your choices are:

+   dams-1.5.iso: Contains the complete Damn Small Linux distribution. You can burn to a regular CD, mini-CD, or bootable disk card-size CD.

+   slax-killbill-5.0.6.iso: Contains the Slack KillBill image that can be used to test Windows applications in Linux.

+   Gentoo-install-x86-minimal-2005.1.iso: Contains the network install CD image for starting a Gentoo installation. It requires 633MB of space.

+   INSERT-1.3.5_en.iso: Contains the Inside Safety Rescue Tools CD image. This is a bootable Linux CD image that requires only about 50MB of disk space. It can be burned to a regular CD, mini-CD, or bootable business card-size CD.
