# umount /dev/fd0

In general, it's better to use the directory name (/mnt/floppy) because the umount
command will fail if the device is mounted in one location. (Device
names begin with /dev.)

If you get the message device is busy, the umount request has failed either
a process has a file open on the device or you have a shell open with a directory on
the device as a current directory. Stop the processes or change to a directory outside
the device you are trying to unmount the umount request to succeed.

An alternative for unmounting a busy device is the -l option. With ummount -l (a
lazy unmount), the unmount happens as soon as the device is no longer busy. You
mount remote NFS file system that is no longer available (for example, the
device went down), you can use the -f option to forcibly unmount the NFS
file system.

A very useful tool for discovering what's holding on a device you want to
unmount is the lsof command. Type lsof with the name of the partition you
want to unmount (such as lsof/mnt/floppy). The output shows what
commands are holding open files on partition.

# Using the mkfs Command to Create a File System

You can create a file system for any supported file type on a disk or partition-
that you choose. You do so with the mkfs command. While this is most useful
for creating file systems on hard-disk partitions, you can create file systems on
floppy disks as well.

Here is an example of using mkfs to create a file system on a floppy disk:

```
# mkfs -t ext3 /dev/fd0

```
