# Chapter 13 ♦ Running Gentoo Linux 397

**30. Add kernel modules.** Add any extra kernel modules that you need to add at boot time. You usually need to do this only if some piece of hardware isn't detected and the module needed to use isn't automatically loaded. Edit either the kernel-2.4 or kernel-2.6 file, depending on which kernel you are using.

```
# nano -w /etc/modules.autoload/kernel-<version>
```

You can type uname -a to see what your kernel version is.

**31. Configure the boot loader.** You need to install a boot loader (grub in this example) and configure it. It makes the following assumptions about your setup:

+   - Gentoo is installed on your first IDE hard disk (/dev/hda).
- You have a separate boot partition on /dev/hd1.
- Your initrd file in the /boot directory is initrd-2.4.26-r9.
- Your kernel file in the /boot directory is kernel-2.4.26-r9.

If any of information is different for your setup, you need to adapt the following step appropriately. To configure grub, install it with emerge, run the grub command, and create the grub.conf file as follows:

```
# emerge grub
# grub
gub> root (hd0,0)
gub> setup (hd0)
gub> quit
# nano -w /boot/grub/grub.conf
default 0
timeout 15
splashimage=(hd0,0)/grub/splash.gmz
```

```
title=Gentoo Linux
root (hd0,0)
kernel /kernel-2.6.13-gentoo-r3 root=/dev/hd0
initrd /initrd-2.6.13-gentoo-r3
```

**32. Reboot.** Exit your root partition by running umount to unmount partitions and rebooting as follows:

```
# exit; cd /
# umount /mnt/gentoo/proc /mnt/gentoo
# reboot
```

Remove the installation disk and allow the computer to boot from hard disk. After a few minutes, you should see the GRUB screen. Select Gentoo Linux (Press Enter).

From here on you be booting from the hard disk and working directly from the operating system. If you installed you will see error messages, as missing kernel drivers, I recommend that you go to http://forums.gentoo.com and search for the driver that's causing problems. Chances are that someone else had the same problem and can offer you a solution.
