
# Running the Installer

The Debian installation process consists of two stages. The first stage is used to establish the Debian installation on your hard drive. The second stage boots the newly installed Debian system and performs additional installation and configuration tasks.

Before you begin installing Debian to your hard disk, be sure to back up any data that is important to you. A simple mistake partitioning can result in losing some or all of your data. Refer to Chapter 7 for information on disk partitioning. It can help you decide how to use your hard disk or ever resize disk partitions to make room for the new Debian installation.

# Stage 1

The first stage boots from the installation medium (generally a CD); configures hardware drivers, disk partitions, and file systems; and copies a set of essential packages known as the base system. Here's the procedure:

- Boot the CD that comes with this book and type linux from the boot prompt to begin the Debian installer.
- After the installation has finished, you are presented with the series of menus that make up the installation process. Use the arrow keys to navigate through the menus and select your language, region, and keyboard mapping.
- The next step is to configure the network connection. This step is skipped automatically if no network card is detected in your system.

If a network card is detected in your system, the installer will attempt to automatically detect the network using the DHCP protocol. This involves the computer sending requests on the network for configuration details from a DHCP server. Most networks and broadband routers support this service.

If the DHCP configuration fails, you will be presented with four options:

- retry — Select this option if you suspect that there was a temporary problem that prevented your computer from communicating with the DHCP server.
- retry with hostname — Select this option if your network provider requires you to enter a DHCP hostname. This used to be common on cable modem networks, but is rarely seen anymore.
- manual configuration — Select this option if you have static IP address information that must be entered for your Internet connection.

See Chapter 7 for information about IP addresses, network masks, and other material related to setting up a network connection.

- do not configure at this time — Select this option if you do not have an Internet connection, using a dial-up connection, or have a broadband connection that requires the use of PPPoE. In the latter two cases, you'll want to establish the connection at the point it is noted during stage 2 of the installation.
- 4. Provide a hostname (a single-word name that you give to your system, as *debian*, *laptop*, or *linux*) and a domain name. If you do not have your own domain name, you can make one up, as *myhouse.local*.
- 5. You will next be asked to configure your partitions for Debian. If you haven't done so, read Chapter 7 for more information about partitioning.

If you have partitions on your drive and room for more, you are given the option to use this space for your Debian system. Another option is to erase the entire disk and use the whole thing for Debian. Either of these two options takes you through the guided partitioning, which is covered in this section.

A third option, manually editing the partition, enables you to be more exact about your partition setup, but you should not try this without at least reading Chapter 7.

The guided partitioning section presents three partitioning schemes. Each of the options includes a suitable amount of swap space but has different benefits based on your situation. You must select one from the list before you proceed. See "Selecting a Partition Scheme" sidebar for more information.

> When installing to small drives (under a few gigabytes in size), you should use ext file systems instead of ext3. The journaling in ext3 requires that a portion of the disk be set aside for the journal, but the feature is of limited usefulness on small file systems. You can change file system types by going into the partition properties. To do this, highlight the arrow keys and press Enter.

The next step will modify the contents of your hard disk. Check your partition settings before proceeding.

- 6. With your partition configuration complete, select Finishing Partition and Write Changes to Disk. This is your last chance to cancel changes that could cause damage to any other operating systems you may have on the disk, so check the screen before proceeding!

The installer writes the partitions to disk and creates the necessary file systems. After they have been prepared and mounted, the Debian base system is extracted from the CD and installed into the target partitions.

- 7. The final step is to install GRUB, the boot loader. The default setting is to install the master boot record (MBR), which is generally the best option. Accept the defaults and continue. The installer extracts the CD and prompts you to proceed with stage 2.
- 8. Remove the CD and press Enter to continue.

# Selecting a Partition Scheme

The guided partitioning feature allows you to select one of three templates to create your partitions. Use these guidelines to select the template that is correct for you.

- **All files in one partition** – Makes a single Linux partition for files. This is the easiest option to manage because you don't have to worry about balancing the sizes of your partitions. This can be dangerous because users have the capability to fill the entire disk, which can cause problems for the operating system. Do not use this option unless you are prepared to monitor disk space.
- **Desktop machine** – Gives the operating system its own space and gives home directories their own. This is a good trade-off between the convenience of a single partition and the increased safety of the multiuser scheme. However, the `/tmp` directory is still part of the operating system partition, meaning that it is still easy for people who habitually use that directory to fill up the operating system.
- **Multi-user system** – Creates separate partitions for the root file system, `/usr/var/`, `/tmp/`. You can choose this option when you use this system as a server. It may also be a good choice for systems that will be used by more than just you, your relatives, and your close friends. The trade-off is that you may run out of space on a given partition even the others have plenty of space, which means you will need to plan carefully.

In some situations, you may need to adjust the partition sizes selected by the multiuser partitioning scheme to put more room where you are likely to need it:

- If you plan to compile a large lot of software packages, you'll need to have plenty of space in the `/usr/` partition. even- Active servers (especially Web and mail servers) may need extra room in `/var/` for log files. Mail servers also use this space for the mail queue, and the default mail system also storing mail here (you may also want to consider making `/var/mail/` a separate partition in cases).
- Web browsers using Mozilla as `/tmp/` for storing files while they are downloaded. This system must be big enough to hold any large files that you want to download through, plus any other files that may be at the same time.

Note that with the multiserver partitioning scheme, the `/home/` generally ends up receiving most of the space. This makes it a good place to “borrow” space when you want to make other partitions larger. However, because partman (the partitioning tool used by the Debian installer) has already mapped the partitions, you actually need to delete `/home/` and then re-add it if you increase the size of the other partition. If there are other partitions between `/home/` and the one that you are increasing in size, you also need to delete them, and then add them back in an appropriate order.
