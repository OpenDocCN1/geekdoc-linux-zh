# Protecting Denial of Service Attacks

As explained earlier, a denial of service attack attempts to crash your computer or at least degrade its performance to an unusable level. There are a variety of service exploits. Most try to overload system resource, such as your available disk space or your internet connection. Some common attacks and defenses are discussed in the following sections.

# Mailbombing

Mailbombing is the practice of sending so much e-mail to a particular user or system that the computer's hard drive becomes full. There are several ways to protect yourself from mailbombing. You can use the Procmail e-filtering tool, or if using sendmail as your mail transport agent, configure your sendmail daemon.

# Blocking With Procmail

The Procmail e-filtering tool, installed by default with Fedora, RHEL, and many other Linux systems, is tightly integrated with the sendmail daemon; thus, it can be used to selectively block or filter specific types of e-mail. You can learn more about the Procmail Web site: www.procmail.org.

To enable Procmail for your user account, create a .procmail file in your home directory. The file should be mode 0600 (readable by you nobody else). Type the following, replacing emailmailer with the actual e-mail address that is mailbombing you.

```
# Delete mail from emailmailer
:0
* ^.*emailmailer
/dev/null
```

The Procmail recipe looks for the From line at the start of each e-mail to see if it includes the string emailmailer. If it does, the message is sent to /dev/null (effectively throwing it away).
