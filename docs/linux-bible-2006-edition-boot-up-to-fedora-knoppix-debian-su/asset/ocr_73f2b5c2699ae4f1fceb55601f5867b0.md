# 640 Part IV ♦ Running Applications

Other features in the new Point2Play window include the ability to select among different versions of Cedega for running applications and tools for individually configuring each game runs under Cedega. (If a game won't run from the GUI, launching it from a Terminal window).

To get binary copies (ones that are already compiled to run) of Cedega and Point2Play, you need to subscribe to TransGaming. For details on how to become a “TransGamer,” click the Subscribe Here link on the TransGaming home page (www.transgaming.com). Benefits currently include:

+   - Downloads of the latest version of Cedega
- Access to Cedega support forums
- Ability to vote on games you want TransGaming to support next
- Subscription to the Cedega newsletter

Cedega used to be WineX. The source code for WineX may become available in the future if you want to build your own WineX/Cedega package. To check availability, try the SourceForge project site for WineX (sourceforge.net/projects/wine).

# Loki Software Game Demos

To encourage people to get its games, Loki Software, Inc. offered a demo program that let you choose from more than a dozen of its games to download and run them. You can still find some of its games for sale. For example, a recent search for Loki at Amazon.com returned 16 different Loki games (including the ones described here), many selling for $9.99.

> If you try to download any of the demos in the following sections, make sure you have plenty of disk space available. It is common for one of these demos to require several hundred megabytes of disk space.

The Loki Demo Launcher page (www.lokigames.com/products/demos.php) still offers links to FTP sites from which you can download the Demo Launcher. The file that you want to save is lok_demos-full-1.0e-x86.run. Save it to a directory and do the following:

+   1. Change the directory to which you downloaded the demo. For example:

```
# cd /tmp/loki
```
