Guest account — If Guest OK is selected, the username that is defined here is assigned to users accessing the file system. No password will be required to access the share. The nobody user account (used only by users who access your computer remotely) is the default name. (The FTP user is also a recommended)

Read only — If Yes, files can only be read from this file system, but no remote user can save or modify files on the file system. Select No if you want users to be allowed to save files to this directory over the network.

Guest ok — Select Yes to enable any access to this directory without requiring a password.

Hosts allow — Add the names of the computers that will be allowed to access this file system. Separate host names by commas, spaces, or tabs. Here are some valid ways of entering hosts:

+   - localhost — Allows access to the local host.
- 192.168.12.125 — IP address. Enter an individual IP address.
- 192.168.12 — Enter a network address to include all hosts on a network. (Be sure to put a dot at the end of the network number or it won't work!)
- pcren, pcstimsy — Enables access to individual hosts by name.
- EXCEPT host — If you are allowing access to groups of hosts (such as by entering an address), use EXCEPT to specifically deny access from one host from that group.

Hosts deny — Denies access to specific computers by placing their names here. By default, no particular computers are excluded. Enter host names in the forms you use for Hosts Allow.

Browseable — Indicates whether you can view this directory on the list of shared directories. This is on if (Yes) by default.

Available — Enables you to leave this entry intact but turns off the service. This is useful if you want to close access to a directory temporarily. Select No to turn it off.
