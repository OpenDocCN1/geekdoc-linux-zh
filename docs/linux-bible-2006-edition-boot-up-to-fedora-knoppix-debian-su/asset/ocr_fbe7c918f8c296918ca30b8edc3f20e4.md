While KNOPPIX is probably the best-known bootable distribution, it is by no means the only one. The past few years, bootable Linux systems have gone from little to more, shell-command rescue floppies to fully-blown desktop, server, and security operating systems.

This chapter describes some popular and interesting bootable Linux distributions. It also explores ways that you can customize some of these bootable Linux systems to suit the way you want to use them.

> If you haven't already done so, I recommend you try the KNOPPIX distribution included with this book and described in Chapter 11. It will help you get a good hands-view of a bootable Linux system describing how KNOPPIX works, how to use different boot options to start it, and ways of saving changes across reboots. # Overview of Bootable Linux Distributions

There are now dozens, and probably soon will hundreds, of bootable Linux distributions (also sometimes called LiveCDs). By stuffing removable media (CDs, DVDs, floppies, and even USB drives) with a select mix of open source software, bootable Linuxes enable you to bypass the hard disk completely and have a special Linux distribution running (if you like) on almost any computer within minutes.
