# Adding Plug-ins

There are not many plug-ins available for use in most Linux versions of Mozilla. To see a list of plug-ins associated with the browser, choose Help About Plug-ins.

Check PluginDoc (http://plugindoc.mozzdev.org/linux.html) for a list of plug-ins for Mozilla. Here are descriptions of a few of plug-ins:

+   * Acrobat Plug-in — Displays files in Adobe Systems' PDF (Portable Document Format) format.
* Cult3D Plug-in (http://www.cult3.com/download/download.asp) — Displays high-quality, interactive, real-3D images on the Web. This plug-in is part of the Cult3D product from Lycore Inc. (Click Download from the Cult3D home page to find the plug-in. There is a cult3d RPM that requires tailoring to working in Mozilla).
* DvLibra Plug-in (djvu.sourceforge.org) — Displays image compression technology. This plug-in is from AT&T.
* RealOne Player (www.real.com/) — Real Audio and Video content, Networks and its open source Helix have made RealVideo 10 codecs available to the Linux community.
* Macromedia Flash Player (www.macromedia.com) — Displays multimedia graphics and animation. This plug-in is from Macromedia, Macromedia's Shockwave plug-in is not available for Linux.
* Crossover PlugIn (www.codewavers.com) — Linux plug-ins are not available for some of the more interesting and popular plug-ins. QuickTime 5 movies, Shockwave Desktop media content, and many Microsoft file, and data formats will not play natively in Firefox. Using software built under WINE for Linux on x86-based processors, CodeWeavers created the Crossover Plug-in. Although no longer offered as a separate product (you must buy the Crossover Office product for $39.95 US), the Crossover Plug-in lets you play some content that you could not otherwise use in Linux (Download a demo from codewavers.com/site/products/download_trial/).
