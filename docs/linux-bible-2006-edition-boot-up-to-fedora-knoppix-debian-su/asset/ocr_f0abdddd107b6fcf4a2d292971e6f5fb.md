| Table 21-2 |
| Document and Graphics Conversion Utilities |
| Utility | Converts | To |
| dosunix | DOS text file | UNIX (Linux) text file |
| fax2ps | TIFF facsimile image files | Compressed output PostScript (The PostScript output is optimized to send to a printer on a low-speed line. This format is less efficient for images with a lot of black or continuous tones, which tif2ps might be more effective.) |
| fax2tiff | Fax data (Group 3 or Group 4) | TIFF format (The output is either low-resolution or medium-resolution TIFF format.) |
| g3pbbm | Group 3 fax file (either digraf or raw) | Portable bitmap |
| gif2tiff | GIF (87) file | TIFF format |
| man2html | Man page | HTML format |
| pal2rgb | TIFF image (palette color) | Full-color RGB image |
