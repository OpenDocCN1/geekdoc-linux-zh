Another Metacity feature of interest is the workspace switcher. Four virtual workspaces appear in the workspace switcher on the GNOME panel. You can do the following with the workspace switcher:

+   - **Choose current workspace** — Four virtual workspaces appear in the workspace switcher. Click any of the four virtual workspaces to make your current workspace.
- **Move windows to other workspaces** — Click any window, each represented by a tiny rectangle in a workspace, drag-and-drop to another workspace.
- **Add more workspaces** — Right-click the workspace switcher, select Preferences. You can add workspaces (up to 32).
- **Name workspaces** — Right-click the workspace switcher and select Preferences. Click in the Preferences pane to change names of workspaces to any names you choose.

You can view and change information about Metacity controls and settings using the gconfeditor (from a Terminal). As the window shows, it is not the recommended way of changing preferences, when possible, change the desktop through GNOME preferences. However, gconfeditor is the only way to see descriptions of each Metacity feature.

From the gconfeditor window, select apps ⊞ metacity, and then choose from generic, global_keybindings, keybindings_commands, window_keybindings, and workspace_names. Click each key to see its value, along with short and long descriptions of the key.

# Using the GNOME panels

The GNOME panels are placed on the top and bottom of the GNOME desktop. From those panels you can start applications (from buttons or menus), see what programs are active, and monitor how your system is running. There are many ways to change the top and bottom panels — by adding applications or monitors by changing the placement or behavior of the panel, for example.

Right-click any open panel on either panel to see the Panel menu. Figure 3-8 shows the Panel menu on the panel.
