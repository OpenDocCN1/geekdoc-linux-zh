请记住，任何分区命令都可能轻易擦除您的磁盘或使其无法访问。在使用任何工具更改分区之前，请务必备份关键数据！然后，对您所做的更改要非常小心。准备一个应急启动盘也是一个好主意。

fdisk 命令在许多不同的操作系统均可用（尽管它们的界面和行为各不相同）。在 Linux 中，fdisk 是一个基于菜单的命令。使用 fdisk 列出所有分区，以 root 用户身份输入以下内容：

```
# fdisk -l
Disk /dev/hda: 40.0 GB, 40020664320 bytes
255 heads, 63 sectors/track, 4865 cylinders
Units = cylinders of 16065 * 512 = 8225280
```

要查看当前系统是否正在使用每个分区，请输入以下内容：

| Device | Boot | Start | End | Blocks | Id | System |
| /dev/hda | | 1 | 13 | 104391 | 83 | Linux |
| /dev/hda2 | | 14 | | 38716650 | 83 | Linux |
| /dev/hda3 | | 4834 | | 257040 | 82 | Linux swap |

从 `df` 的输出中，可以看到您的 Linux 系统根目录 (/)位于 /dev/hda2 分区，且 /dev/hda 分区被用于 /boot。

```
# df -h
Filesystem Used | Avail | Use | Mounted on |
/dev/hda2 | 37G | 5.4G | 30G | 16% | / |
/dev/hda1 | 99M | 8.6M | 86M | /boot |
none | 61M | | 61% | /dev/sh |
```

如果这是一个双启动系统（带有 Windows 98），你可能会在 fdisk 中看到类似这样的 Windows 分区：

```
/dev/hda1 * | 83 | 66666+ | b Win95 FAT32
```

你可以在 Linux 中挂载分区（以便在 Windows 启动时访问您的 Windows 文件）：

```
# mkdir /mnt/win
# mount vfat /dev/hda1 /mnt/win
```

在使用 fdisk 更改分区之前，我强烈建议使用 `df -h` 命令查看您的分区是如何定义的。这有助于降低更改或删除分区的风险。

要使用 fdisk 更改分区，您需要识别出正在分区的硬盘。例如，第一块 IDE 硬盘被识别为 /dev/hda。因此，要对您的第一个 IDE 硬盘进行分区，可以以 root 用户身份开始输入：

```
# fdisk /dev/hda
```

对于不同的驱动器类型或数量，/dev/hda 被替换为想要操作的设备名称。表 7-1 显示了您的一些选择。

### 表 7-1 磁盘设备名称

| Device | Description |
| --- | --- |
| /dev/hda | 用于第一个 IDE 硬盘；其他 IDE 硬盘为 hdb、hdc 等。 |
| /dev/sda | 用于第一个 SCSI 硬盘；其他 SCSI 硬盘为 sdb、sdc 等。 |
| /dev/tdd0 | 用于 RAID 设备。 |
| /dev/idc0 | 也用于 RAID 设备。 |

启动 fdisk 后，输入 m 查看选项。以下是你可以用 fdisk 做的操作：

- *删除分区*——输入 d 和分区号，然后按 Enter。例如，/dev/sda2 将是分区号 2。（删除操作不会等待您确认更改——您可以回退到那一点。）
- *创建分区*——如果您有空闲空间，可以添加新分区。输入 n 创建本地分区（5 或以上）或输入 p 创建主分区（1–4）；并从可用范围选择一个分区号。从可用的磁道数中选择第一个磁道数。（早之前 `fdisk -l` 的输出会在 Start 和 End 列下显示正在使用的磁道数。）
接下来，磁道数将以您想要的特定兆字节或字节数结束：例如 `+50M 或 +104K`。您可以创建一个 ext3 Linux 分区。再次强调，在您写入更改之前，这不是永久的。
- *更改分区类型*——按 l 选择文件系统类型。输入您想要更改的分区号。输入代表您想要使用的文件系统类型的十六进制代码。（此时输入 L 可查看文件系统类型和代码列表。）对于 Linux 文件系统，使用数字 83；对于 Linux 交换分区，使用 82；对于 Windows FAT32 文件系统，使用字母 b。
- **显示分区表**——在整个过程中，可以随时输入 p 来显示（打印在屏幕上）当前的分区表。
- **退出或保存**——在写入您的更改之前，确保它们是您所想要的。如果您不喜欢所做的某个更改，按 Q 退出且不保存。如果您的更改正确，则将它们写入分区表。

### 防御攻击

拒绝服务攻击（DoS）有时尝试填满您的硬盘。如果 /var 位于单独的分区，攻击可能会填满您的硬盘。

### 772 将分区分配给特定目录

表 7-2 列出了您可能考虑设置为独立的目录：

| Directory | Explanation |
| --- | --- |
| /boot | 有时旧式 PC 的 BIOS 只能访问硬盘的前 1024 个磁道。为了确保 /boot 目录中的信息可被 BIOS 访问，请为 /boot 创建一个单独的分区（约100MB），并确保它位于1024磁道之内。您的 Linux 系统其他部分可以在1024磁道边界之外存在。有了更好的镜像，/boot 很少需要超过 100MB。 |
| /usr | 该目录包含了 Fedora Linux 用户使用的许多应用程序和实用程序。将 /usr 独立分区允许您在安装操作系统后将文件系统挂载为只读。这可以防止攻击者替换或……如果您有无磁盘工作站，单独分区也是用的。通过 NFS，您可以在网络上共享 /usr。 |
| /var | 您的 FTP (/var/ftp) 和 Web 服务器 (/var/www) 目录在许多 Linux 系统中默认存储在 /var 下。拥有 /var 分区可以防止这些设施的攻击损坏或填满您的硬盘。 |
| /home | 因为用户账户位于此目录下，拥有独立的 /home 账户可以防止鲁莽的用户填满硬盘。 |
| /tmp | 通过将 /tmp 放在单独的分区来使其不受硬盘其他部分的影响，可以确保需要 /tmp 中临时文件的应用程序即使磁盘其他部分已满也能完成其处理。 |
