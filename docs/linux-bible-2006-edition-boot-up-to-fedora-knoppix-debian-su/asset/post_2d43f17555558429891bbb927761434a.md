
One of the easiest ways to become familiar with GIMP is to crop, trim, an image file already on your computer. To crop a file, follow these steps:

1. Start GIMP and open an image file.
2. Right-click on the image. From the contextual menu that appears, select Tools -> Transform Crop and Resize. The crop cursor appears (two overlapping L shapes), as does the Crop and Resize Information window.
3. Position the cursor at the upper-left corner of the area of the image that you want to crop. Click and drag the cursor to the lower-right corner of the image to be cropped. A selection rectangle appears around the selected area as you do so.
4. Release the mouse button. Four handles appear in the corners of the border around the selected area. Click and drag the handles to resize the border.
5. When the border is in the right place, click the Crop button in the Information window. The image is cropped to the border.

If you make a mistake, select Edit -> Undo from the GIMP menu, or press the Ctrl+Z key combination.

## Using Scanners Driven by SANE

Software using a scanner with Linux is driven by an effort Scanner Access Now Easy (SANE). This effort hopes to standardize how device drivers for equipment such as scanners, digital cameras, and digital video cameras are created, as well simplify the interfaces for applications that use those devices. SANE is now included with a variety of Linux distributions.

Some wanting to use Linux as a publishing platform is generally interested in two issues about scanners: which scanners are supported and what applications are available to use the scanners. In general, more SCSI scanners are supported over parallel scanners.

Because of the ongoing development effort, new scanners are being supported all the time. You can find a current list of supported scanners at www.sane-project.org/sane-supported-devices.html with USB scanners listed at www.buzzard.me.uk/jonathan/scanner-usb.html. For applications, more widely used today include:

- xsane - An X-based graphical front for end SANE scanners, xsane can work as a GIMP-plug or as a separate application (from most KDE desktops, select Graphics ->). It supports 8-bit output in JPG, TIFF, PNG, PostScript, and PNM formats. There is experimental 16-bit support for PNM (ASCII), PNG, and raw formats.

- scanimage - Use this command-line interface to obtain images. The command acquires the scanned image, and then directs the data to standard output (so you can send it to a file or pipe it to another program). It supports the same formats as xsane.

In addition to these applications, the OpenOffice.org supports SANE.

Because of the architecture of SANE scanner drivers, it is possible to separate scanner drivers from scanner applications. This makes it possible to share scanners across a network.

## Choosing an E-Mail Client

Choices of e-mail clients range from those that look like clones of popular Windows e-mail programs to those that run in plain text from the shell, and interfaces vary widely with the e-mail clients that are available with Linux. Here are some different ways in which e-mail clients are integrated into Linux:

- With a Web browser— Many popular Web browsers include an integrated e-mail client. By configuring the e-mail client that comes with your browser, you are ready to launch a new e-mail message by clicking on a mailto link from a browser window. You can also easily open the e-mail client from your Web browser's toolbar.

Feature-rich Mozilla mail (www.mozilla.org) is the most popular e-mail client for Linux to use with a Web browser. Netscape Communicator (www.netscape.com) is another Web browser that has its own mail client (although it has been dropped from many Linux distributions because of licensing issues).

The Opera (www.opera.com) Web browser also includes an integrated e-mail client. It is the most elegant of the e-mail clients that comes with a Web browser.

- With groupby— Some e-mail clients have been bundled with other productivity applications to form integrated applications. The most popular of these in Linux is Evolution, which is bundled as the default e-mail client with different Linux distributions. A company named Ximan originally produced Evolution. Novell, Inc. purchased Ximan then renamed and rebranded Ximan as Evolution.

- From the shell— Many old UNIX and Linux users prefer to use an e-mail client that runs without a graphical desktop. Although intuitive to use, text-based e-mail readers run much faster than their counterparts. The `mail` command dates back to the earliest UNIX systems (where there was no GUI). The mut e-mail client is popular among power users because of its capability to manage large mailboxes and attachments.

Features inside each e-mail client help you distinguish between them. Most e-mail clients you get, compose, send, and manage e-mail messages, here are a few extra features you might look for:

- Filters and spam catchers— Mozilla, and other mail clients offer message filters and junk detectors. You can use filters to sort incoming mail into different folders, delete certain messages, or otherwise respond to incoming mail. Some e-mail clients also have features to automatically detect when junk has arrived. If you get a lot of e-mail, these can be invaluable tools for managing your e-mail. (Select the Tools menu from your e-mail client, and look for Filters or Junk selection.)

- Security features— E-mail clients such as Thunderbird (www.mozilla.org) enable you to use message encryption, digital signatures, and other security features to keep your e-mail private.

- Sorting, searching, marking, and displaying— If you managing lots of e-mail messages at once (some people manages thousands of messages), the capability to refer back to the one you want be critical. Some clients lets you sort by date, priority, subject, and other items.
