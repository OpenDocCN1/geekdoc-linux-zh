To see what SoC is doing, use the -V option. For example:

```
$ soc -V file.wav file1.voc
```

size bytes, style unsigned, 1 channel
soc: Input file1.wav: comment "file1.wav"

```
$ soc: Output file1.voc: using sample rate 44100
size shorts, encoding signed (2's complement), 2 channels
soc: Output file: comment "file1.wav"
```

You can apply effects during the SoC conversion process. The following example shows how to change the sample rate (using the -r option) from 10,000 KHz to 5,000 KHz:

```
$ soc -r 10000 file1.wav -r 5000 file1.voc
```

To reduce noise, you can send the file through a low-pass filter. Here's an example:

```
$ soc file1.wav file2.voc lowp 2200
```

For more information on SoC and to get the latest download, go to the SoC—Sound Exchange—home page (www.sourceforge.net/projects/soc/).

# Compressing Music Files with ogg

the ogg command takes music or other audio data and converts it from uncompressed formats (such as WAV, RAW, or AIFF) to the compressed Ogg Vorbis format. Using Ogg Vorbis, audio can be significantly reduced in size without a noticeable loss of quality. (Use the default settings in ogg and reduced a 48MB WAV music file to 4MB).

In its most basic form, you can use oggenc with one or more WAV or AIFF files it. For example:

```
$ oggenc *.wav
```

This command would result in all files ending with .wav in the current directory to be converted to Ogg format. An OGG file is produced for each WAV file, with oggenc substituting, .ogg for .wav as the suffix for the compressed file. Ogg Vorbis files can be played in many different audio players in Linux, including the XMMS player (described earlier).

> If you want to rip music files from CD and compress them, you can use the Grip window (described later in this chapter). Grip enables you to use oggenc as the tool to do the file compression.
