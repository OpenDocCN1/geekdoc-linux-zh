KNOPPIX directory when you mount the CD or the DVD that comes with this book on any operating system.

Many options can be used with different Linux systems. If you are having trouble installing or booting a different Linux distribution, you can try any of the options to use instead. Instead the word "knoppix," you will probably use a different word to launch the install or boot process for other distributions (such as "Linux" for Red Hat Linux systems or "morphix" for Morphix Live-CD, depending on the distribution).

When KNOPPIX begins the process, you see the screen, with the boot: prompt provides boot options that can help you get KNOPPIX running the way you like. Table 11-1 shows options to use when you want specific features turned on that may not be turned on by default when you boot.

# ### Table 11-1
Boot Options to Select Features

| Option | Feature |
| knoppix lang=?? | Choose a specific language/keyboard. Replace ?? with one of the following: cn, de, da, es, fr, it, nl, pl, ru, sk, tr, tw, uk, or us. |
| knoppix desktop=?? | Instead of the KDE desktop (kde), replace ?? with one of the following window managers: fluxbox, cewm, larswm, wmaker, or xfce. |
| knoppix blind | Start BrailleTerminal (running without X). |
| knoppix brittle=type,port,table | Add parameters to use for the Braille device. |
| knoppix wheelmouse | For a wheel mouse, enable IMPS/2 protocol. |
| knoppix nowmouse | For a regular PS/2 mouse, use PS/2 protocol. |
| knoppix keyboard-us xkeyboard-us | Assign different keyboard drivers to use with text (shell) and graphical (X). |
| knoppix dma | Turn on DMA acceleration for all IDE drives. |
| knoppix alsa knoppix alsa-es1938 | Select either of these two notations to use the ALSA driver (do at your own risk). |
