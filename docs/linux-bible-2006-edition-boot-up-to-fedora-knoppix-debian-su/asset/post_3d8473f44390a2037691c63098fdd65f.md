Conditional breakpoints are usually more useful. They enable you to temporarily halt execution if or a particular condition is met. The correct syntax for setting conditional breakpoints is as follows:

```
(gdb) break linenum if expr
(gdb) break funcname if expr
```

In the preceding code, expr can be any expression that evaluates to true (non-zero). For example, the following break commands stop execution at line 24 of debug when the variable i equals 15:

```
(gdb) break 24 if i == 15
Breakpoint 1 at 0x0843cb: file debugme.c, line 24.
(gdb) run
Starting: /home/kwill/code/debug
```

Breakpoint 1, index_to_mon (ary=0xffff4fb0) at debugme.c:24
ary[1] = i;

Stopping when i equals 15 is an arbitrary choice to demonstrate conditional breaks. As you can see, gdb stopped on line 24. A quick print command confirms that it stopped when the value of i reached the requested value:

```
(gdb) print i
$1 = 15
```

To resume execution after hitting a breakpoint, type continue. If you have set breakpoints and have lost track of what has been set and which ones have been triggered, use the infobreakpoints command to refresh your memory.

## Working with Source Code

Locating a specific variable or function in a multi-file project is a breeze with GDB, provided you use the -d switch to tell it where to find additional source code files. This is particularly helpful option when not all of your source code is located in your current working directory or in the program's compilation directory (which GCC recorded in its symbol table).

To specify one or more additional directories containing source code, start GDB using one or more -d options, as this illustrates:

```
$ gdb -d /source/project1 -d /oldsource/project1 -d /home/bba/src
```

To locate the next occurrence of a particular string in the current file, use the search command. If you want to find the previous occurrence of the word "return" in debugme.c (see Listing 29-5), use the reverse-search command:

```
(gdb) reverse-search return
```

The search and reverse-search commands are especially helpful in large source files that have dozens or hundreds of lines. One common use of the reverse-search command is to find the location in which a variable, macro, or function is first used or perhaps to find the place where it is called when it shouldn't be.

## Fedora Core 4 Linux

The DVD includes the entire Fedora Core 4 distribution that normally comes on CDs. This is the recommended Linux distribution for trying out most of the procedures in this book. You can install Fedora Core 4 directly from the DVD without having to create CDs from the DVD to install separately.

Because the complete Fedora Core 4 Linux distribution is included, you have access to a broad range of software packages (more than 1,600), allowing you to get a feel for using Linux as a desktop, server, or programmer's workstation. Details on installing and using Fedora Core 4 are in Chapter 8. If you find that you like Fedora Core 4, consider getting Red Hat Enterprise Linux to learn more about that distribution. ## SUSE Linux

The complete SUSE 10.0 OS installation set (also referred to as OpenSUSE 10.0) included on the DVD lets you install the OpenSUSE operating system.
