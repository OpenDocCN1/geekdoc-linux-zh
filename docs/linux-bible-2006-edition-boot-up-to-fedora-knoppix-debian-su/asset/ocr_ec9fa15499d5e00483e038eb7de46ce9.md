**14. Choose a Linux kernel.** In most cases where you have an IDE controller, you can choose the Slackware CD as the location for getting the kernel you installed Slackware system will ultimately use. Remove Slackware CD #2 and reinsert the Slackware CD #1 and press Enter. In most cases, you should choose the default `bare`,i kernel. If you have a SCSI controller, choose one of the kernels with `s` at the end. If you have very little RAM, try `lowmem`,i kernel. If you want to use the newer 2.6 kernel instead of a 2.4 kernel, select `test26s`. Other specialized kernels are described in the Slackware-HOWTO document.
