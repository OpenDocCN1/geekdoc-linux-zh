# Playing Commercial Linux Games

To get your commercial games running in Linux, you should start from a site like the Linux Game Time (www.happypepenguin.org) or Linux Games' FAQ (http://icculus.org/igfqaf), which both provide information on commercial games that run in Linux and help in getting them to run. In most cases, you need to:

- Purchase a legal copy of the game.

- Go to a site that describes how to install, get patches for, and work around any issues related to playing the game in Linux.

Here are examples of a few commercial games that run in Linux:

- **Duke 3D Atomic Edition for Linux (3D Realms)** — Multiplayer death match set in the future, where warriors face each other with awesome weapons and stuff. Includes a Linux installer. Got to Epic Games (www.epicgames.com) or Unreal Tournament site (www.unrealtournament.com) for the official information. See the Icculus.org site (http://icculus.org/duke3d/) for tips on getting it running.

# id Software Games

Among the most popular games running natively in Linux are Quake II, Quake III Arena and Return to Castle Wolfenstein from id Software, Inc. You can purchase Linux versions of these games or download demos of each game before you buy.

> Note If you have trouble getting any id Software games running in Linux, refer to the Linux FAQs available from id Software at: http://zerowing.idsoftware.com/linux.

# Quake III Arena

Quake III Arena is a first-person, shooter-type game where you can choose from lots of weapons (lightning guns, shotguns, grenade launchers, and so on) and pass through scenes with highly detailed 3D surfaces. You can play alone or against your friends. Standalone are multiplayer death-match and capture-the-flag competitions. Standalone play allows you to advance through a tournament structure of skilled opponents. This version of the game has a selectable difficulty level, from fairly easy to downright impossible.

A version of Quake III Arena for Linux is available from the id Software Web site (click the demo link at www.idsoftware.com/quake/quake3-gold/ and then look for the Linux demo). Figure 23-5 shows a screenshot from Quake III Arena.

# Return to Castle Wolfenstein

You battle with the Allies to destroy the Third Reich in Return to Castle Wolfenstein, which mixes World War II with creatures conjured up by Nazi scientists. It's based on the Quake III Arena engine and offers single-player mode as well as team-based multiplayer mode.

If you purchase Castle Wolfenstein for Linux, you actually get the Windows version with an extra Linux installer. If you already have the Windows version, you can download the Linux installer and follow some instructions to get it running. I downloaded the installed called wolf-linux-1.31.x86.run from www.idsoftware.com/games/wolfenstein/rtw/index.php?game_section=updates. The INSTALL file (in /usr/local/games/wolfenstein) describes which files you need to copy from the Windows CD.

To get a demo of Return to Castle Wolfenstein, go to www.idsoftware.com/games/wolfenstein/rtw/index.php?game_section=overview. Both single-player and multiplayer demos are available.

> You need an NVIDIA card to run Return to Castle Wolfenstein.

Working with WINE developers, TransGaming is developing Cedega, which enables you to run many different games on Linux that were originally developed for Windows.
