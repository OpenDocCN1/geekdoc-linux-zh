## Configuring X

Before 2004, most Linux distributions used the X server from the XFree86 project (www.free86.org). Because of licensing issues, many of the major Linux vendors (including Red Hat, SUSE, and Slack) changed to the X server from Xorg (www.x.org). The descriptions of how to get going on your system assume you are using the Xorg server.

> To determine which X is installed on your system, from a Terminal window type man Xorg or XFree86. If you have only one X installed on computer (which probably do) only the one will show. While you are, press the spacebar to page through the features of your X.

It is possible that you already did some configuration when you installed. If you are able to start desktop and your mouse, keyboard, and screen seem to be behaving, you may not have to do anything to configure X. However, if you can't start the desktop or want to adjust some basic features (as screen resolution or number of colors), the following sections offer some ideas on how to go about.

## Creating a Working Configuration File

If your desktop crashes immediately or shows only garbled text, try to create a new configuration file. With the Xorg server, the configuration file to use is /etc/X11/xorg.conf.

> In XFree86, the configuration file has basically the same format, /etc/X11/XF86. To have X try to create a sane xorg.conf file for you to use, do the following from a Terminal window as root user:

1. If Linux boots to a command prompt, go to next. However, if X tried to start automatically, press these keys together: Ctrl-Alt-Backspace. This should kill your X server and get you back to a command prompt. If X tries to restart (and is still messed up), press Ctrl-Alt-F2. When you see the command prompt, log in as root and type:

2. To have X probe your video hardware and create a new configuration file, type: xconfigure

3. The file xorg.conf.new should appear in your home directory. To test if this new configuration file works, type the following to start the X server:

4. If that succeeds, you have a working xorg.conf file. Press Ctrl+Alt-Backspace to exit.

5. Copy the new configuration file to where it is picked up the next time X starts:
cp /root/xorg.conf.new /etc/X11/xorg.conf

Chances are that you have a very basic configuration that you may want to tune further.

## Getting New Drivers

Working video drivers are available with most video cards you purchase today. However, to get some advanced features from your video cards (such as 3D acceleration) you may need to get proprietary drivers directly from the manufacturers. In particular, you may want to get drivers from NVIDIA and ATI.

To get new drivers for video cards or chipsets from NVIDIA, go to the NVIDIA site (www.nvidia.com) and select the Downloads button. Follow the link to Linux drivers. Links from the page that appears will take you to a Linux page from which you can download the driver and get instructions for installing.

For ATI drivers and chipsets, go to www.ati.com and select Drivers & Software. Follow the links to Linux drivers and related installation instructions.

## Tuning Up Your Configuration File

The xorg.conf file might look a bit complicated when you first work with it. However, chances are that you will need to change only a few elements in it. As root user, open the /etc/X11/xorg.conf file in any text editor. Here are some things you can look for:

- Look for an InputDevice section with a Mouse identifier. That section for a simple PS2 mouse might look like:

```
Section "InputDevice"
  Identifier "Mouse0"
  Driver "mouse"
  Option "Protocol" "PS/2"
  Option "Device" "/dev/psaux"
EndSection
```

If you are unable to use some feature of the mouse, such as a middle wheel, you might be able to get it working with an entry that looks more like the following:

```
Section "InputDevice"
  Identifier "Mouse0"
  Driver "mouse"
  Option "Protocol" "PS/2"
  Option "Device" "/dev/psaux"
  Option "ZAxisMapping" "4 5"
EndSection
```

Don't change the mouse identifier, unless you change the protocol and the ZAxisMapping line to enable your wheel. Try restarting X and trying your mouse wheel on something like a Web page to see if you can scroll up and down with it.

Your mouse might be connected in a different way (such as a bus or serial mouse) or may have different buttons to enable. Tools for configuring your mouse are distribution-specific. Try mouseconfig, mouseadmin, or system-config to reconfigure your mouse from the command line.

Monitor—The section defines attributes of your monitor. There are generic settings you can use if you don't know the model of your monitor. Changing the Horizontal Sync and Vertical Refresh rates without checking your monitor's technical specifications is not recommended; you could damage the monitor. Here's an example of an entry that will work on many LCD panels:

```
Section "Monitor"
  Identifier "Monitor0"
  VendorName "Monitor Vendor"
  Name "LCD Panel 1024x768"
  HorSync 31.5 - 48.5
  VertRefresh 40.0 - 70.0
EndSection
```

Here is an entry for a generic CRT monitor that will work on many CRTs:

```
Section "Monitor"
  Identifier "Monitor0"
  VendorName "Monitor Vendor"
  Name "Generic Monitor, 1280x1024 @ 74 Hz"
  HorSync 31.5 - 79.0
  VertRefresh 50.0 - 90.0
EndSection
```

If a tool is available to select monitor settings, for example, in Red Hat systems, you would run system-config-free86.

Video device — The Device section is where you identify the driver to use with your video card and any options to use with it. It's important to get this section right. The Xorg command described earlier usually does a good job detecting the. If you want to change to a different one, this is where to do so. Here is an example of the Device section after I added a video driver (nv):

```
Section "Device"
  Identifier "Card0"
  Driver "nv"
  VendorName "NVIDIA Corporation"

EndSection
```
