As noted earlier, you can play several audio file formats. Supported formats include:

+   * MP3 (with added plugin-in)
* Ogg Vorbis
* WAV
* AU
* CD Audio
* Cin Movies

> Note If MMMS is not able to find a configured sound, it redirects its output to the
Disk Writer plugin-in. This causes the files you play to be written to hard disk as WAV
files.

You can get more audio plug-ins from www.xmms.org. The MMMS audio player
be used in the following way:

+   1. Obtain music files by ripping songs from a CD or copying them from the Web
so that they are in an accessible directory, or by inserting a CD into your
CD-ROM drive (MMMS expects the CD to be accessible from /dev/cdrom.).
2. From the applications menu, select Sound & Video ♫ Audio Player. The X
Mimedia System player appears.
3. Click the Eject button. Load windows appears.
4. If you have inserted a CD, the contents of /mnt/cdrom appear in the Files
pane. Select the files you want to add to your Playlist and click the Add
Selected Files or the Add All Files in Directory button to add all songs
