# Extending Firefox

Firefox can handle most standard Web content (HTML, JPEG, text files) without trouble. With any browser, some content requires additions of plug-ins or helper applications to be able to play or display that content. Firefox also allows you to add extensions that let enhance the features in Firefox.

Most plug-ins can be used for Mozilla Navigator will for Firefox as well. See the description of Mozilla plug-ins earlier in this chapter for information on adding plug-ins for both Mozilla and Firefox browsers.

Besides plug-ins, Firefox also allows you to add extensions and themes, start from the Mozilla. Firefox product page (www.mozilla.org/products/firefox). From there, follow the "Get Extensions and Themes". The following sections describe some popular Firefox extensions and themes.

# Adding Firefox Extensions

Here are some of the most popular extensions to Firefox that are available from Mozilla.org:

+   **Downloading tool (FlashGot)** — If you like to download groups of files from your browser, FlashGot can be a very useful tool. With FlashGot installed, you can select an individual file, files identified by highlighting links on a web page, or all files linked from the current web page. There is a Build Gallery feature that lets you identify a range of filenames at once.

+   When FlashGot is installed, you can access it from Firefox by selecting Tools > FlashGot, and then choosing a feature for the menu. In Fedora Core, Firefox passes requests to KGet to complete the download. You can get other-tools to use instead of KGet.

+   **Selectively block ads (Adblock)** — Using Adblock, you can selectively prevent ads from displayed on the Web pages. With Adblock installed, an Adblock button appears on the lower-right corner of Firefox. Click that to see a window containing items on the current page you want to block. Right-click on an image and select Adblock image to block from a particular site (for example, www.example.com/*). Open the Adblock preferences from Firefox (Tools > Adblock > Preferences) to see, edit, or remove blocked sites.
