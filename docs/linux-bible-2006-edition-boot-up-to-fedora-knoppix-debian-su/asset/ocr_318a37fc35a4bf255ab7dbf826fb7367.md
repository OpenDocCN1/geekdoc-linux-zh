# 422 Part III ♦ Choosing and Installing a Linux Distribution

Both basic and advanced installations wipe out all data on the target drive/parti tion. Back up anything you think you might want to keep before proceeding.

+   1. Start the computer and boot the CD. You'll see the first is to install and the second is for running diagnostics. Select option 1 and press Enter, or wait until the installation proceeds after a few moments.

+   2. On the Install Type screen, you can select a basic or advanced installation. A basic installation is useful when you have only one hard disk or partition. An advanced installation enables you to select the hard disk and/or partition to you want to install. Make your selection, and click Next.

+   3. The Select Computer Name and Password screen appears. You need to the PC and provide an admin (root) password if you opt to provide one. For a home configuration replaying a Windows installation, for example, leaving the password blank be acceptable. In any working environment or if the PC is not going to be shielded from the Internet, providing a strong root pass word is essential. When you have made your selection, click Next.

+   4. You're asked to confirm your name and the installation method you selected. If you are happy with your selections, click Next.

+   5. A warning window asks to make absolutely certain that you want to proceed. You are again warned that all data on the target drive/partition will be lost. You are given the options "Yes, I am sure" and "Let me make changes." to go to the next step. Select "Let me make changes" and return to the installation type screen.

At any point up to and including Step 5, you can use the Back button to review and/or change your previous configuration decisions.

+   6. The next screen indicates the progress of the installation process. Scrolling messages fill the space, and in a few minutes you see the message:

```
Linspin setup complete
press OK to restart your computer.
```

Click OK.

+   7. A final message appears, instructing you to remove your drive and press any key. Grab the CD tray and your installation is complete.

+   8. When Linspin starts up, you can specify which startup path you would like to take. The startup options are called boot options, and there are three options in your startup screen (called the Linux Loader or LILO): Linspin, Redetect, and Diagnostics.
