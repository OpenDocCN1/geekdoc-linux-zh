**31. Configure the boot loader.** You need to install a boot loader (grub in this example) and configure it. It makes the following assumptions about your setup:

- Gentoo is installed on your first IDE hard disk (/dev/hda).
- You have a separate boot partition on /dev/hd1.
- Your initrd file in the /boot directory is initrd-2.4.26-r9.
- Your kernel file in the /boot directory is kernel-2.4.26-r9.

If any of information is different for your setup, you need to adapt the following step appropriately. To configure grub, install it with emerge, run the grub command, and create the grub.conf file as follows:

```bash
# emerge grub
# grub
gub> root (hd0,0)
gub> setup (hd0)
gub> quit
# nano -w /boot/grub/grub.conf
default 0
timeout 15
splashimage=(hd0,0)/grub/splash.gmz
```

**33. Install a Desktop.** For most of us, it's not much just working from the command line. The following command installs a basic set of desktop packages, including the X Window System (xfree), KDE desktop (kde), Mozilla browser (mozilla), and Openoffice office suite (openoffice-bin). This takes a long time to install over the network!

```bash
# emerge xfree kde mozilla openoffice-bin
```

As an alternative, if you have these packages available on CD-ROM, you can use the following commands to identify the location of the packages and install them from that location:

```bash
# export PKGD1="* /mt/cdrom/packages"
# emerge -k kde mozilla openoffice-bin
```

You can also save some time by installing only GNOME or KDE (not both). If you don't plan to create documents or spreadsheets, you probably don't need to install openoffice-bin either.

**34. Configure the X.** Now that your desktop software is installed, you need to configure the X Window System to work properly with your video card and monitor. Type the type of configuration for your video card and monitor:

```bash
# /usr/X11R6/bin/xf86_config
```

At this point you should have a Gentoo system. For further documentation, check out www.gentoo.org/doc/en/index.xml.

# Summary

In a few years, Gentoo has distinguished itself as a premier distribution for Linux enthusiasts who are interested in complete control of the components and settings of their Linux systems.

The jewel of Portage is the Portage package management system. Using the Portage emerge command, you can install thousands of Gentoo software packages which can be downloaded and built from scratch, using settings you choose for how you use your Linux system.

If you don't want to learn about the inner-workings of a Linux system (and spend lots of time getting it to work), Gentoo may not be for you. An experienced Linux person usually takes several trials to get Gentoo going, while someone may not get it installed and running at all without lots of help. However, if you want to tune and tweak your operating system, Gentoo is a great way to go.
