# Chapter 11 ♦ Running KNOPPIX 345

Configuration tools—Some hardware cannot be perfectly detected or requires some extra setup. You can access KNOPPIX-specific configuration tools for configuring your printer, TV card, sound card, network connections, and other features by clicking the desktop icon that looks like a squished penguin.

Save setup—You don't have to lose the configuration you have done for KNOPPIX every time you reboot. Recl the configuration to save your configuration—including your personal desktop configuration, files on the desktop, network settings, and graphics setup (X)—to floppy disk or USB memory stick.

Persistent desktop—You can use the configuration icon to create a persistent KNOPPIX home directory on your hard disk or other medium so you can store and reuse your desktop setup information and any data from session to session. (See the "Creating a Persistent Home Directory" section in this chapter for details on setting up a persistent desktop.)

Add swap—If you use KNOPPIX from a computer with Linux installed, it automatically uses a swap partition that is set up. On DOS and Windows systems KNOPPIX enables you to create an extra swap area if you have space on an available partition. The *mddosswapfile* command is used for this

Work with Windows files—KNOPPIX includes experimental drivers for using Windows NTFS files. The drivers enable you to read and write files from your hard disk if you are booting KNOPPIX from a PC with Windows installed. (Writing to NTFS partitions from KNOPPIX is still experimental, so consider using an NTFS partition in read-only mode if the partition contains critical data.)

For example, if you have your entire music collection, images-loaded from your digital camera, and personal Web pages on a computer that was set to be booted by Microsoft Windows XP. You boot KNOPPIX instead (notice that Microsoft Windows is not running at all)
Suddenly your hard disk is just a place that holds a lot of files. You can use all applications that come with KNOPPIX to open the files on your hard disk to play the music, view images, and change Web pages.

A testament to how well KNOPPIX is respected is how many other Linux distributions are based on. The KNOPPIX project provides a KNOPPIX-customize package that lets anyone make own customized KNOPPIX derivatives that can be used to rescue a broken computer, play a range of multimedia content, or run a specific application.
