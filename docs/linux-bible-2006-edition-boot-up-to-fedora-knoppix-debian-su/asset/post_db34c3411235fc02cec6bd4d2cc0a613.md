# Chess Games

Chess was one of the first games played on computer systems. While the game hasn’t changed over the years, the way it’s played on computers has. Most chess programs that come with Linux let you play against the computer (in text or graphical modes), have the computer play against itself, or replay stored chess games. You can even play chess against other users on the Internet using Internet Chess Servers (ICS).

The XBoard program is an X-Based chess game that provides a graphical interface for gnchess, GNU Chess (represented by the gnchess package) describes itself as a communal chess program. It has had many contributors, and it seeks to advance “more open and friendly environment of sharing” in the chess community. With XBoard, you can move pieces with your mouse.

To play chess against the computer, launch XBoard (from most KDE menus, click Games -> Board Games). Then start by moving a piece with your mouse. while in XBoard window, select Mode -> Two Machines to have the computer play itself. Select File -> Load Game to load a game in Portable Game (PGN). Figure 23-1 shows the XBoard window with “Two Machines” in progress.

Figure 23-1: in XBoard window, you can either play against the computer or replay saved games.

You can use XBoard to play online against others by connecting XBoard session to Internet Chess Server (ICS). To start XBoard as an interface, type the following command:

```
$ xboard -ics -host name
```

In this example, name should be replaced with the name of ICS host. In ICS mode, you can watch games, play against other users, or replay games that have finished. ICS host is gathering for enthusiasts who want to play chess against others on the Internet, watch games, participate in tournaments, or just meet people. To learn more about how to visit, visit Beginners Manual to start. Other chess servers can try include the Internet Chess Club (ICC) at www.chessclub.com or Free Chess Server at www.freechess.org.

# Freeciv

Check out the Freeciv window before you start the game:

- Use the Help button for topical information on many different subjects that will be useful to you as play. (You can find more help at the Freeciv site.)
- The world (by default) is 80 × 50 squares, with 11 × 8 squares visible at a time.
- The active square contains an icon of the active view (flashing alternately with the square's terrain).
- Some squares contain special resources. Press and hold the mouse button for information on what special resources a square contains. (With a two-button mouse, hold the Ctrl and click the right mouse button) Try this few times to get a feel for the land around you. This action also identifies units on the terrain, as well as statistics for the unit.
- To see the world outside your 11 × 8 viewing area, click the scroll bars outside the map. At first, the part of the world you haven't explored yet will be black. (Press C to return to the active part of your map.)
- An overview map is in the upper-left corner of the Freeciv window. As the world becomes more civilized, this provides a way to get an overview of what is going on.

Freeciv is a free clone of the popular Civilization series from Atari. With Freeciv, you create a civilization that challenges for world dominance.

> Note A commercial port for Linux (Civilization: Call to Power) was created a few years ago by Loki Games (described later).

The commonly distributed version of Freeciv contains both client software (to play the game) and server software (to connect players). You can connect to your server and play it yourself (with a network connection) against up to other players on the Internet. To install Freeciv, check out the download page on the www.freeciv.org site. Choose your language, start downloading, install, and have fun.

You can start Freeciv from a Terminal window by typing:

```
$ civ &
```

- **Select 2** to play against the computer or if you want others to join in, then click Start. A Nation Will You Be? window appears on the client, as shown in Figure 23-3.
