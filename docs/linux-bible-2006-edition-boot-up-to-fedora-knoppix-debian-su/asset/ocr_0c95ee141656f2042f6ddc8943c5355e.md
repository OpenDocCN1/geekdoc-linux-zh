# 198 Part II ♦ Running the Show

+   **Monitor your system.** You can log almost every type of activity on your Linux system. System log files, using the syslog and klogd facilities, can be configured to track as much or as little of your system activity as you choose. Utilities like logwatch provide easy ways to handle the potential messages forwarded to your administrative e-mail account. Logging features are described later in this chapter.

+   **Use SELinux.** SELinux is an extraordinarily rich (and complex) facility for managing the access to nearly every aspect of a Linux system. It addresses the if-get-root-access-login-own-box shortcuts of Linux and UNIX systems for highly secure environments. Red Hat systems use a default set of SELinux policies that are turned on by default. Other Linux distributions are using SELinux implementations as well.

# Finding Distribution-Specific Security Resources

Most Linux distributions have developed resources to help you secure Linux and keep up with security information that is specific to the version of Linux. Here are a few online that focus on security for several Linux distributions:

+   **Red Hat Enterprise Linux and Fedora Core security** — Check the Red Hat Security site (www.redhat.com/security) for RHEL security issues (that typically relate to Fedora cores systems as well). From here you can look and read available updates. You can also get information on security training and consulting from Red Hat, Inc. Refer to the Red Hat Enterprise Linux 4 Security Guide for an in-depth look at Linux security for Red Hat systems. You can access this guide from the following address:

```
www.redhat.com/docs/manuals/RHEL-4-Manual/security-guide/
```

+   **Debian security** — The Debian Security Information page (www.debian.org/security) provides a central point for finding security advisories, answers to common Debian questions, and links to security documents. You can find the Debian security manual here:

```
www.debian.org/doc/manual/securing-debian-how
```

+   **Gentoo security** — Included on the Gentoo Security page (www.gentoo.org/security) are tools, announcements, and links to security policy and project documents secured with Gentoo systems. The Gentoo security handbook here:

```
www.gentoo.org/doc/en/security
```

+   **Slackware security** — To keep up with Slackware security issues, refer to the Slackware Advisories (www.slackware.org/security). You can also join the security mailing list (www.slackware.org/lists) for Slackware.

+   **SUSE security** — Online security support for SUSE is provided by SUSE's parent company, Novell. Find links to a variety of SUSE security topics from this site:

```
www.novell.com/linux/security/securityupport.html
```
