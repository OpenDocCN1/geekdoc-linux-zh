# PlanetPenguin Racer (TuxRacer)

With PlanetPenguin Racer, you guide Tux the penguin (the Linux mascot) down a snow-covered hill as fast as you can. PlanetPenguin Racer (ppracer command) is an open source (GPL) version of TuxRacer, which was once freeware, but was made into a commercial game by Sunspire Studios.

To advance in PlanetPenguin Racer, you need to complete courses in the allotted time while overcoming whatever obstacle is presented (gathering herring or negotiating flags). You may try up to different courses and achieve higher-level cups.
