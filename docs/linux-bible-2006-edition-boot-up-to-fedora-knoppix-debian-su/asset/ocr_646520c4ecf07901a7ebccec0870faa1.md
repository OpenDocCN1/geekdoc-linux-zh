+   —Linux tries to keep processes with the immediate need in RAM, while managing how processes exceed the available memory are moved to swap space. Swap space is a defined area on your hard disk's to handle the overflow of running processes and data. When RAM is full, processes are placed in swap space. When swap space is full (something you don't want to happen), processes can't start.

+   Linux supports various hardware devices, which keeps the kernel manageable by including only a small set of devices in the active kernel. Using load modules, the kernel can be loaded and unloaded on demand, as hardware is added and removed. (The kernel, described in detail a later on, is the heart of the Linux operating system.)

+   File systems provide the structure in which files are stored on hard disk, CD, DVD disks, or other media. Linux knows about different file types (such as Linux ext3 and reiserfs file systems, VFAT or NTFS from Windows) and how to manage them.

+   Linux was built from the ground up to enable multiple users to access the system simultaneously. To protect each user's resources, every directory, and file is assigned sets of read, write, and execute permissions that define who can access them. In a standard Linux system, the root user has access to the entire system, special logins have access to particular services (such as Apache for Web services), and users are assigned permission individually or in groups. Recent features Security-Enhanced Linux enable more refined tuning and protection in highly securing computing environments.

I have described components that make up what is referred as the Linux kernel. In fact, the Linux kernel (which was created and is still maintained by Lin Torvalds) is what gives Linux its name. The kernel is the software starts up when you boot your computer and manages the programs you use to communicate effectively and simply with your computer hardware.

Other components, such as administrative commands and applications, are added to the kernel from free and open source projects to make Linux a complete operating system. The GNU project, in particular, contributed many components that are now in Linux. (GNU, Apache, KDE, GNOME, and other key source projects in Linux are discussed a bit later).
