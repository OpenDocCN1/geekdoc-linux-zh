

## 加固 Linux

自从互联网络诞生以来，就一直有用户试图入侵其他用户的系统。随着互联网的增长和宽带网络接入的普及，这个问题变得更加严峻。一台配置不当的家庭计算机可能被用作强大的邮件中继站，或者导致用户的个人信息泄露，甚至引发无数其他可怕的后果。几何时，网络攻击需要攻击者付出一些精力和技巧。而现在，自动化工具可以让最新手的用户在惊人的短时间内运行起来，尝试攻破网络连接系统。此外，攻击者还有能力将大量不安全的系统变成“僵尸”大军，用于大规模的、协调的分布式拒绝服务（DDoS）攻击。

你为什么应该关注安全？根据 [互联网风暴中心](http://isc.sans.org/) 的数据，一台连接到互联网的计算机平均在连接后 16 分钟内就会受到某种形式的攻击。加固任何计算机系统并不困难；它需要一些常识以及对良好安全实践的仔细应用。

在许多情况下，保护和安全系统的良好实践、监控日志文件以及创建良好的防火墙可以挡住许多潜在的入侵者。有时，需要更主动的方法来应对入侵。

与加固 Linux 系统相关的许多任务在桌面和服务器系统中是通用的。然而，由于服务器允许外部客户端进行某种程度的访问，因此保护服务器有特殊的考虑。

本章描述了加固 Linux 系统的通用任务以及加固桌面和服务器系统的技术。随后，它描述了一些你可以从可引导 Linux 系统尝试使用的工具，用于排除计算机和网络故障。

## Linux 安全清单

虽然大多数 Linux 系统都提供了加固计算机所需的所有工具，但如果你粗心，某人（而且可能）会损害你的系统、接管它或盗取你的数据。请记住，没有任何安全措施是 100% 可靠的；通过提供计算机的物理访问权限或无限的破解时间，熟练且意志坚定的破解者可以进入任何计算机。

尽管如此，你可以采取许多保护措施来增加保持 Linux 系统安全的几率。以下清单涵盖了保护 Linux 桌面或服务器的一系列安全功能。

- **控制物理访问。** 将计算机锁在锁门后面是一个好主意，特别是当它包含关键数据时。你可以通过在 BIOS（防止计算机启动）以及 GRUB 或 LILO 启动加载器中启用密码，来限制拥有物理访问权限的人对你计算机的操作。你还可以在 BIOS 中限制哪些设备可以启动。

- **添加用户和权限。** 创建用户账户（每个账户都有密码）是你保护数据安全的第一道防线。账户之间相互保护，也能防止接管了某个用户账户的外部人员进一步渗透。设置组账户可以将所有权概念扩展到多个用户。设置用户账户请参阅第 4 章，“使用密码保护”请参阅本章后部分。

- **读、写和执行权限。** 系统中的每个项目（包括文件、目录、应用程序和设备）都可以根据该项的所有者、组以及所有其他人的读、写和执行权限进行限制。例如，你可以允许他人运行命令或文件并允许他们进行更改。有关设置文件和目录权限的信息，请参阅第 2 章。

- **保护 root 用户。** 在标准 Linux 系统中，root 用户（以及 apache 等其他用户账户）具有更改和使用你 Linux 系统的特殊能力。保护好 root 账户的密码，并在不需要时不要 root 账户。由 root 用户拥有的开放 shell 或桌面可能成为攻击目标。使用 sudo 以普通用户身份运行图形化管理命令（在提示时输入 root 密码）可以减少 root 账户受到攻击的风险。有关处理 root 用户账户的信息，请参阅第 4 章。

- **使用可信软件。** 虽然没有任何开源软件是可以保证的，但通过使用成熟的 Linux 发行版（如 Fedora、Debian 或 SUSE），你更有机会避开受损的软件。你获取附加包或更新的软件仓库应该经过审慎检查。使用有效的 GPG 公钥可以帮助确保你安装的软件来自有效的供应商。当然，在 Linux 应用程序中安装收到的数据文件之前，务必确认其来源是否可靠。如果你下载了发行版的完整 ISO 镜像，请使用创建者提供的 MD5 或 SHA1 校验和来检查其完整性。

- **获取安全更新。** 随着软件包中不断发现漏洞和错误，每个主要的 Linux 发行版（Debian、SUSE 和 Red Hat 发行版）都提供了获取和安装这些更新的工具。务必获取这些更新，特别是当你将 Linux 作为服务器时。这些工具包括 apt、yum 和 emerge。

- **使用安全应用程序。** 即使软件是有效且运行的，某些应用程序也能提供更好的防攻击或防入侵保护。例如，如果你想通过互联网登录计算机，安全外壳服务（ssh）被认为比 login 或 telnet 服务更安全。此外，某些被认为暴露在互联网上是不安全的服务（如 Samba 和 NFS）可以通过 VPN 在互联网上进行更安全地使用。

- **使用限制性防火墙。** 防火墙的主要目的是控制进出你网络的访问。你可以使用规则来确定哪些流量是被允许的，哪些是被拦截的。有关如何配置防火墙的信息，请参阅第 12 章。

- **仅启用所需的项。** <a href="http://www.w3.org/TR/html41/inter.html#h400">最小权限原则</a>规定用户或程序应只拥有执行其任务所需的最小权限。通过禁用你不使用的服务和端口，可以减少系统的攻击面。

- **监控日志文件。** 日志文件包含了你系统中发生事件的记录。通过定期查看这些文件，你可以检测可疑活动或系统问题。有关如何监控日志的信息，请参阅第 10 章。

- **检查漏洞。** 新漏洞不断被发现。保持软件更新以防止这些威胁至关重要。你可以使用各种工具扫描系统的漏洞。
