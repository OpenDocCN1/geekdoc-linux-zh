**Desktop area**— The windows and icons you use are arranged on the desktop area, which supports drag-and-drop between applications, a desktop menu (right-click to see it), and icons for launching applications. There is a Computer that consolidates CD drives, floppy drives, the file system and shared network resources in one place.

GNOME also includes a set of Preferences that enable you to configure aspects of your desktop. You can change backgrounds, colors, fonts, keyboard shortcuts, and other features related to the look and behavior of the desktop.
