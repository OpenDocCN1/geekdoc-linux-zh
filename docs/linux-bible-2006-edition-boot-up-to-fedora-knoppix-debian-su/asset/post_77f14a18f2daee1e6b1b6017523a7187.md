# Understanding KNOPPIX

If you are impatient to get started, you don't have to read any further. In most cases, you can just insert your DVD into your PC, reboot the computer and start using KNOPPIX. If you have the time, however, read on a bit more.

KNOPPIX is a bootable Linux that includes a nice selection of open source software. Originally, there was a CD version of Gnoix (about 700MB image). Now, there is also a DVD version (about 3.1GB image). It is the KNOPPIX CD image that is included on the DVD that comes with this book.

KNOPPIX is considered to be the best bootable Linux available. In fact, KNOPPIX is used as the base for many specialized Linux distros, including GnoppPPIX (featuring GNOME instead of KDE), KNOPPIX STD (security), KnopMyth (MythTV media player), and KnopixMAME (console game player), to name a few. To try out the latest features, however, you should start with the most recent version of KNOPPIX, as described in the rest of this chapter.

# Looking Inside KNOPPIX

KNOPPIX boots right up to a full-featured desktop system complete with hundreds of desktop applications. It includes some powerful server and power user features.

# Chapter 11 ♦ Running KNOPPIX

In fact, there are many features, I won't even to mention them all here, but take a look at the following list of KNOPPIX's major components:

- KDE—A full-featured KDE desktop (which runs on the X Window System) that includes tools for configuring the desktop and a bunch of applications tailored for the KDE environment. (See Chapter 3 for descriptions of KDE.)

If you prefer the GNOME desktop environment, there are several customized versions of KNOPPIX that include GNOME. Most notable is the Gnoppix (www.knoppix.org) distribution, which uses GNOME as its default desktop. 

- OpenOffice.org—The OpenOffice suite of productivity tools that you can create documents, graphics, presentations, spreadsheets, and most anything you expect to able with office applications. With KNOPPIX, I can give a presentation created in OpenOffice.org using OpenOffice software anywhere where I have access to a PC. (See Chapter 21 for descriptions of OpenOffice.org productivity applications.)

- Internet tools—Web browsers (Firefox, Conqueror, and Lynx), e-mail clients (Thunderbird, Kmail, Mozilla mail, and mutt), a chat client (XChat IRC), a news reader (KNode), an instant messaging client (Gaim), and many more applications using the Internet. (See Chapter 22 for descriptions of popular browsers and mail clients.)

- Multimedia software—Applications for playing music (xmms and Juk), editing music (Audacity), watching TV (xawt), playing movies (kv), working with graphics (GIMP and ImageMagick), using Webcams (gcam), and displaying images (KV and Kickshow). (Chapter 20 covers music and video players.)

- Games—A few dozen diverting board games, card games, strategy games, and puzzles to play. There are Potato Guy to keep the young ones busy, and Kasteroids for the older kids. (Chapter 23 talks about KDE games and other games you can run with KNOPPIX.)

- Administrative tools—A nice set of system and network administration tools that enables you to do some pretty advanced setup, monitoring, and debugging of your computer and network. (The Knoppix-STD distribution is configured specifically as a CD to do almost anything you can imagine to check and fix your computer and network.)

- Servers—A few of the powerful servers available for Linux, many of which don't require a local disk space: A Web server (Apache), file server (NFS), Window file/print server (Samba), proxy server (Squid), DNS server (bind9), login server (sshd), and DHCP server (dhcpd).

Using KNOPPIX (or any other bootable Linux systems described in Chapter 19) as a server offers some amazing possibilities for serving the data from a Windows or other operating system to a network, while completely bypassing that operating system's hard disk.

- Programming tools—a good set of tools for developing software across a variety of programming environments.

KNOPPIX is based on Debian, so a Debian user will be particularly comfortable with the selection and organization of features. KNOPPIX software packages are also in deb format, so you can use apt, dpkg, and related tools to list and manage the packages. A graphical tool for working with software packages that comes with KNOPPIX is KPackage.

> Note Refer to Chapter 9 for information on using apt and dpkg tools for managing software in Debian. Even if you don't install any new software, those tools provide an excellent way to search, list, or even upgrade software packages that are running in KNOPPIX.

# What’s Cool About KNOPPIX

The features just described are ones that come with many Linux distributions. What makes them special with KNOPPIX is that you can be up and using those features within a few minutes — without having to repartion your disk, install software, or do any configuration. For trying out Linux or using it for some special, task such as playing or displaying music, documents, or spreadsheets from a computer's hard disk, KNOPPIX is quite awesome.

Some features, however, are specific to KNOPPIX (as compared to a Linux system you would run from a hard disk). Many of those features are there to help you through issues that relate to the fact that you are not working in a permanent setup. In particular, KNOPPIX includes the following:

- Extraordinary hardware detection —The capability to properly detect and configure hardware is one of the best features. During the boot-up procedure, KNOPPIX finds most common PC components and loads the proper modules so it can use them. Its chipset tool relies on the Red Hat libkduzu to identify hardware, load appropriate modules, and create device files.

For hardware that cannot be detected, there are many boot options you can add to properly identify (or skip) over hardware devices. Some of them deal with particularly sticky issues related to video cards and running on laptop computers. (See Tables 11-1 through 11-3).

- Automatic desktop startup —Instead of dropping you to a command line, KNOPPIX does its best to start up a complete KDE desktop environment. Along the way, it adds some nice features, such as desktop icons giving access to features.

- Configuration tools—Some hardware cannot be detected or requires some extra setup. You can access KNOPPIX-specific tools for configuring your printer, TV card, sound card, network connections, and other features by clicking the desktop icon that looks like a squished.

- Save setup—You don't have to lose the configuration you have done every time you reboot. Save the configuration—including your personal desktop, files, network settings, and graphics setup—to floppy disk or USB memory stick.

- Persistent desktop—You can use the configuration icon to create a persistent home directory on your hard disk or other medium so you can store and reuse your desktop information and any data from session to session. (See the "Creating a Persistent Home Directory" section in this chapter for.)

- Add swap—If you use KNOPPIX from a computer with Linux installed, it automatically uses a swap partition that is setup. On DOS and Windows systems KNOPPIX enables you to create an extra swap area if you have space on an available partition. The dosswapfile command is used for this

- Work with Windows files—KNOPPIX includes experimental drivers for using Windows files. The drivers enable you to read and write files from your hard disk if you are booting KNOPPIX from a PC with Windows installed. (Writing to NTFS partitions from KNOPPIX is still experimental, so consider using an NTFS partition in read-only mode if the partition contains critical data.)

For example, if you have your entire music collection, images-loaded from your digital camera, and personal Web pages on a computer that was set to be booted by Microsoft Windows XP. You boot KNOPPIX instead (notice that Microsoft Windows is not running at all)
Suddenly your hard disk is just a place that holds a lot of files. You can use all applications that come with KNOPPIX to open the files on your hard disk to play the music, view images, and change Web pages.

A testament to how well KNOPPIX is respected is how many other Linux distributions are based on it. The KNOPPIX project provides a KNOPPIX-customize package that lets anyone make customized KNOPPIX derivatives that can be used to rescue a broken computer, play a range of multimedia content, or run a specific application.
