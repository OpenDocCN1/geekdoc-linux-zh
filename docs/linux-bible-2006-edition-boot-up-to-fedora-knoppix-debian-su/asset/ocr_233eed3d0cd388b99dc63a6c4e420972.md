Given an archive created with the ar command, you can speed up access to the archive by creating an index to the archive. ranlib does precisely this, storing the index in the archive. ranlib's syntax is:
ranlib [-v|-V] file
This generates a symbol map in file. It is equivalent to ar -file.

# The ldd Command

While nm lists the symbols defined in an object file, unless you know what library defines functions, it is not terribly helpful. That is ldd's job. It lists the shared libraries that a program requires to run. Its syntax is:

```
ldd [options]
```

ldd prints the names of the shared library files. Two of ldd's most-useful options are -d, which reports any missing functions, and -r, which reports functioning and missing data objects. For example, the following ldd reports that the client maint (which may or not be installed on your system) requires eight shared libraries.

```
$ ldd /usr/bin/mutn
libcurses.so.5 -> /lib/libcurses.so.5 (0x40020000)
ssl.so.0 -> /usr/libssl.so.0 (0x40066000)
crypto.so.0 -> /usr/libcrypto.so.0 (0x40097000)
libc.so.6 -> /lib/libc.so.6 (0x40195000)
libpgm.so.1 -> /lib/libpgm.so.1 (0x402c5000)
ldl.so.2 -> /lib/ldl.so.2 (0x402cb000)
/ld-linux.so.2 -> /lib/ld-linux.so.2 (0x40000000)
libcurses.so.5 -> /lib/libcurses.so.5 (0x402ce000)
```
