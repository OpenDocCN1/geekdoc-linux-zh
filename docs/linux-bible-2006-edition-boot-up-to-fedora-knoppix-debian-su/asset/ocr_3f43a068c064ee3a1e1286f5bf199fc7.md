# Exploring Administrative Commands, Configuration Files, and Log Files

You can expect to find many commands, configuration files, and log files in the same places in the file system, regardless of Linux distribution you are using. The following sections give you some pointers on where to look for these important elements.

# Administrative Commands

Only the root is intended to use many administrative commands. When you log in as root (or use su - from the shell to become root), your PATH variable is set to include some directories that contain commands for the root. These include the following:

+   * /sbin—Commands for managing your disk partitions (such as fdisk), checking file systems (fsck), and changing system states (init).
* /usr/sbin—Commands for managing user accounts (such as useradd) and adding mount points for automounting file systems (automount). Commands that run daemon processes are also contained in this directory. (Look for commands that end in d, sshd, pppd, and cupsd.)

Some administrative commands are contained in regular user directories (such as bin and /usr/bin). This is especially true of commands that have options available to everyone. An example is the /bin/mount command, which anyone can use to list mount files systems, but only root can use to mount file systems (Desktops, however, are configured to let regular users mount CDs, DVDs, or removable media.)

To find commands intended primarily for the system administrator, check the section 8 manual pages (usually in /usr/share/man/man8). They contain descriptions and options for many Linux administrative commands.

Some-party applications will add administrative commands to directories that are not in your PATH. For example, an application may put commands in /usr/local/bin, /opt/bin, or /usr/local/sbin. Some Linux distributions automatically add those directories to your PATH, usually before your standard bin and sbin directories. In that way, commands installed to those directories are not only accessible, but can also override commands of the same name in other directories.
