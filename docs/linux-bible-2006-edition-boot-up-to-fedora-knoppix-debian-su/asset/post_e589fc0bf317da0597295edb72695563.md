## Adding an Application Launcher

Icons on your panel represent a Web browser and several office productivity applications. You can add your own icons to launch applications from the panel as well. To add a new application launcher to the panel, do the following:

1. Right-click in an open space on the panel.
2. Select Add to Panel ⏎ Application Launcher from the menu. All application categories from your main desktop menu (the one under the red hat or foot-) appear.
3. Select the next arrow to the category of application you want, and select Add. An icon representing the application appears.

To launch the application you just added, simply click the icon on the panel.

If the application you want to launch is not one of your menus, you can build a launcher yourself as follows:

1. Right-click in an open space on the panel.
2. Select Add to Panel ⏎ Custom Application Launcher ⏎ Add. The Create launcher appears.
3. Provide the following information for the application that you want to add:
* **Name** — A name to identify the application (this appears in the tooltip when your mouse is over it).
* **Generic Name** — A name to identify the type of application.
* **Comment** — A comment describing the application. It also appears when you later move your mouse over the launcher.
* **Command** — The command line that is run when the application is launched. Use the full path, plus any required options.
* **Type** — Select Application (to launch an application). (Other selections include Link, to open a Web address in a browser, or FSDevice, to open a file system)
* **Run in Terminal** — Click this box if the application is a character-based or curses application. (Applications using curses library in a Terminal window without off-screen mouse and keyboard controls.)
4. Click the icon box (if it may say No). Select one of the icons shown and click OK. Alternatively, you can browse the Linux file system to choose an icon.

![](img/a2d958d7eab32ca5b89b2b8af808aa70_137_0.png)

Icons available to represent your application are contained in the `/usr/share/pixmaps` directory. These icons are either in `.png` or `.xpm` formats. If there isn't an icon in the directory you want to use, create your own (in one of those two formats-) and assign it to the application.

5. Click OK.

The application should now appear in the panel. Click it to start the application.

## Adding a Drawer

A drawer is an icon that you can click to display other icons representing menus, applets, and launchers; it behaves just like a panel. Essentially, any item you can add to a panel you can add to a drawer. By adding a drawer to your GNOME panel, you can include several applets and launchers that take up the space of only one icon. Click on the drawer to show the applets and launchers as they were being pulled out of a drawer icon on the panel.

To add a drawer to your panel, right-click the panel and select Add to Panel Drawer. A drawer appears on the panel. Right-click it, and add applets or launchers as it would want to a panel. Click the icon to retract the drawer.

## Changing Panel Properties

Those properties you can change are limited to the orientation, size, hiding policy, and bargain. To open the Panel Properties window that applies to a specific panel, right-click on an open space on the panel and choose Properties. The Panel Properties window that appears includes the following values:

* **Name** — Contains a name by which you identify this panel.
* **Orientation** — Move the panel to different locations on the screen by clicking on a new position.
* **Size** — Select the size of your panel by choosing its height in pixels (48 pixels by default).
* **Expand** — Select this check box to have the panel expand to fill the entire side, or clear the check box to make the panel only as wide as the applets it contains.

**AutoHide**— Select whether a panel is automatically hidden (appearing only when the mouse pointer is in the area).

**Show Hide buttons**— Choose the Hide/Unhide buttons (with pixmap arrows on) appear on the edges of the panel.

**Arrows on hide buttons**— If you select Show Hide Buttons, you can choose to have arrows on those buttons.

**Background**— From the Background tab, you can assign a color to the background, the panel, assign an image, or just leave the default (which is based on the current system). Click the Background Image checkbox if you want to select an image for the background, and select an image, such as a file from `/usr/share/backgrounds/tiles` or other directory.

![](img/a2d958d7eab32ca5b89b2b8af808aa70_139_0.png)

I usually turn on the AutoHide feature and turn off the Hide buttons. Using AutoHide gives you more desktop space to work with. When you move your mouse to the edge of the panel, the panel pops up—so you don't need Hide buttons.

## The Nautilus File Manager

At one time, file managers did more than let run applications, create data files, and open folders. These days, as the information a user needs expands beyond the local system, file managers are expected to display web pages, access FTP sites, and play multimedia content. The Nautilus file manager, which is the default GNOME file manager, is an example of just such a file manager.

When you open the Nautilus file manager (from the GNOME main menu or by opening the Home icon or folder on your desktop), you see the name of the location you are viewing (such as the folder name) and what location contains (files, folders, and applications). Figure 3-1 is an example of the file manager window displaying the home directory of a user named chris (`home/chris`).

In GNOME 2.10, the default Nautilus has been simplified to show fewer controls and provide more space for file and directory icons. Double-click a folder to open in a new window. Select your folder name in the lower-left corner of the window to see the file hierarchy around the current folder (as shown in Figure 3-11). GNOME remembers whatever size, location, and other thing you had for the folder last time you closed it and returns to that state next time you open.

To see more, right-click a folder and select Browse Folder to open it. Icons on the toolbar of the Nautilus window let you move forward and back among the directories and visit sites. To move to the view of the folder or Web page, click the Reload button. The Home button takes you to your home page, and the Computer button lets you see the same type of information you would see from a My Computer icon on a Windows system (CD drive, Floppy drive, hard disk file systems, and network folders).

Icons in Nautilus indicate the type of data that particular file contains. The contents or file extension of each file can determine which application is used to work with the file, or you can right-click an icon to open the file it represents with particular application or viewer.

Here are some of the most interesting features of Nautilus:

* **Sidebar** — From the Browse Folder view described previously, select View Side Pane to have a sidebar appear in the left column of the screen. You can click a pull-down menu that represents different types of information you can select at one time.

The Tree tab, for example, shows a tree view of the directory structure, so you can easily traverse your directories. The Notes tab lets you add notes that become associated with the current Directory or Web page, and the History tab displays a history of directories and Web sites you have visited, enabling you to click those items to return to the sites they represent. There is also Emblems tab that indicate something about the file or folder (emblems include icons representing drafts, urgent, bad, and multimedia).

* **Windows printer sharing** — If your computer is connected to a LAN on which Windows computers are sharing files and printers, you can find those resources from Nautilus. Type **smb:** in the Open Location box (select File> Open Location) to see available workgroups. Click a workgroup to see computers from that workgroup that are sharing files and printers.
