# Major Software Projects

Some software projects have grown beyond the status of being simply a component of Linux or some other UNIX derivative. Some of these projects are sponsored and maintained by organizations that oversee multiple open source projects and organizations. This section introduces some of the most popular open source projects and organizations.

+   * The Apache Software Foundation (www.apache.org) is not only the world's most popular open source Web software, it's the most popular of all server software. Most Linux distributions that contain server include Apache. The Apache Software Foundation maintains the Apache Web (HTTP) server and about a dozen others, including SpamAssassin(for blocking and filtering e-mail), Apache Portals (to provide portal soft-, and a bunch) for producing projects to use with your Apache Web.

+   * The Internet Systems Consortium (www.isc.org) supports critical Internet infrastructure projects under open-source licenses. These projects include Bind (DNS server), DHCP (to assign IP addresses and other informa-to Internet clients), IBN (for creating Internet servers) and OpenReg (a tool for managing delegation of domains in a shared registry).

+   * The Free Software Foundation (www.fsf.org) is the principal sponsor of the GNU Project. Most of the UNIX commands and utilities used in Linux that were not closely associated with the kernel were produced under the umbrella of the GNU project

+   * The Mozilla project's (www.mozilla.org) most well-known product is the very popular open source Web browser Navigator, which was orig-inally based on code released to the open source community from Netscape Communicator. Most other open source projects incorporate Mozilla's engine. The Mozilla project also offers e-mail, composer, IRC Chat, and address book software. New projects include the Thunderbird e-mail and news clients and Firefox browser, which have seen enormous success over Linux, Windows and Mac OS platforms in the past year.

+   * The Sendmail Consortium (www.sendmail.org) maintains the sendmail transport agent, which is the world's most popular software for transporting mail across the Internet.

There are, of course, many open source projects and organizations that pro-vide software in various Linux distributions, but the ones discussed here give you a good feel for the kind of projects that produce open source software.
