# Will You Be Sued for Using Linux?

In the United States, anyone can try to sue anyone for anything. That doesn't mean the people who bring lawsuits will win, but they can try. So far, the threat to individuals has not been substantial, but there have been some well-founded lawsuits against Linux providers. With litigation against Linux have gone primarily after big companies, such as IBM, Novell, and Red Hat, Inc., and have made only vague threats regarding end users of Linux. Linux Torvalds himself is the rare individual who has been named in lawsuits.

# The SCO

The lawsuits getting the most press are the ones involving Santa Cruz Operation (SCO). SCO is the current owner of the UNIX source code that from AT&T Labs to UNIX System Laboratories to Univel (a lot of people who know that) to Novell and the company formed by joining SCO and Caldera Systems.

Although the particulars of the claim seem to change daily, SCO's basic assertion in lawsuits against IBM and others that Linux contains Unix V source code that is owned by SCO, so those who use Linux owe licensing fees to SCO. To a layman (I am not a lawyer), the assertions seem weak based on the facts that:

+   * There seems no original UNIX code in Linux. And, if even a small amount of code could be proved to be owned by SCO had made it in theirs, that could be easily dropped and rewritten

+   * Concepts that created UNIX all to be in the public domain, with public specifications of UNIX interfaces blessed by AT&T in the form of POSIX and System V Interface standards.

+   * AT&T dropped a lawsuit in 1994 against BSD, which had actually started with UNIX source code, but rewritten it completely over the years.

+   * Exactly what SCO owns has brought into question because Novell still claims rights to the UNIX code sold to SCO. (In fact, SCO doesn't even own the UNIX trademark, which Novell gave away to the Open Group before it sold the source code to SCO. Attempts were underway in 2004 by SCO to trademark the name Unix System Laboratories.)
