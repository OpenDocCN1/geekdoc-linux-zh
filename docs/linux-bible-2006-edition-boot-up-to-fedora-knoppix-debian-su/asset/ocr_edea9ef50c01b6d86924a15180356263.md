These distributions are based on open source technology, they rely on many of the same components in their basic technology. SYSLINUX Project (http://syslinux.zytor.com) is responsible for the boot-loader technology used in most Linux distributions. Hardware detection is based on Kudzu libraries created by Red Hat, Inc., and enhanced by the KNOPPIX project. A graphical interface is included, but the most compact distributions use the X Window System (www.x.org or www.free8.org), with space requirements dictating the exact window manager used with it.

If you trouble running any bootable Linux distributions, adding options to the boot prompt, because so many of the distributions are based on KNOPPIX, refer to the KNOPPIX boot options (also called cheat codes) described in Chapter 11 to help your Linux distribution to start up with what you like. View these codes online at www.knoppix.net/wiki/CheatCodes.

This book comes with several bootable Linux distributions, and are noted as you read through the descriptions later in this chapter. You can get more recent versions of distributions that interest you (some are updated quite often) by following links from the sites mentioned.

> Caution

Most bootable Linux distributions are created by individuals and should still be considered as exemplary in nature. The quality can vary widely and sometimes the controls are not as stringent as they would for commercial Linux systems, such as Red Hat Enterprise Linux or SUSE. You can limit your risks by doing things as making all hard disk partitions read-only (as is usually, but not always, done by default), remember that this software is distributed with no warranty.
