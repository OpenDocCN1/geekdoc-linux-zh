
## Choosing a Text Editor

Hardcore UNIX or Linux users tend to edit files with either the vi or emacs text editor. These editors have been around a long time and are hard to learn but efficient to use because your fingers never leave the keyboard. The emacs editor has some GUI support, although it runs in a Terminal window. There are also GUI versions of vi and emacs that add menu and mouse features to the editors. These are GVim (vim command in the vim-X11 package) and Emacs (emacs command).

The following are some of other, simpler text editors that can run on your graphical desktop.

| Text Editor | Command | Description |
|---|---|---|
| gedit | gedit | Lightweight text editor that comes with the GNOME desktop environment. It has simple edit functions (cut, copy, paste, and select all), and can indentations and word wrap. Special functions, such as a spellchecker and a diff feature, are included. Start by typing gedit from a Terminal window. Go to http://gedit.sourceforge.net for more information. |
| Advanced Editor | kwrite | Includes a menu to create, open, and save files, and simple edit functions (cut, copy, paste, undo, and help). Other features enable you to indent, find and replace text, and select all. This tool comes with the KDE desktop; access it by Accessories > More > Kwrite |
| Text Editor | kedit | A simple text editor that comes with the KDE desktop. Features let you open files from your file system or a URL. It also includes a convenient toolbar and a spellchecker. Access it by Accessories > More > Text Editor |
| nedit | nedit | A plain-looking, but very advanced, X-based editor. It provides all the editing functions, syntax-highlighting modes for a plethora of programming languages, and despite its advanced features, its easy for beginners to use. |

## Chapter 21: Working with Words and Images

Here are the general steps for creating documents in Groff or LaTeX:

1. Create a document with any text editor. The document will contain text and markup.
2. Format the document using a formatting command that matches the style of the document you created. During this step, you may need to indicate that the document contains special content, such as equations (eqn command), tables (tbl command), or line drawings (pic command).
3. Send the document to an output device (a printer or display program).

If you are accustomed to a word processor with a GUI, you may find tools difficult to learn. In general, Groff is useful for creating pages for Linux. LaTeX is useful if you need to produce mathematical documents, perhaps for publication.

## Text Processing with Groff

The nroff and troff commands were the first interfaces available for producing typeset documents with the UNIX system. They aren't editors, but commands through which you send your text, with the result being formatted pages. The nroff command produces plain text and includes the capability to do paging, indents, and text justification, as well as other features. The troff command produces typeset text, including everything nroff can do, plus the capability to produce different fonts and spacing. The troff command also supports kernels.

The troff command is the front end for producing nroff/troff documentation. Because Linux pages are formatted and output in Groff, most of the examples here you can create and print pages with Groff. People rarely use primitive nroff/troff macros. There are many common packages that simplify creating nroff/troff-formatted documents, which include:

- man — These macros are used to create Linux pages. You can format a page using the -man option to the groff command.
- mm — The mm macros (memorandum macros) were created to produce memos, letters, and technical papers. This package includes macros for creating tables of contents, lists of figures, references, and other document-style features. You can format an mm document using the -mm option to the groff command.
- me — These macros are popular for producing memos and technical papers on Berkeley UNIX systems. You format a document using -me.

Groff macro packages are stored in /usr/share/groff/. The man macros are called from the man.tmac file, mm macros from m.tmac, and me from e.tmac. The naming convention for each macro package is xxx.tmac, where xxx represents the macro package. In each case, you can deduce the name of the macro package by adding an m to the beginning of the file prefix.

Instead of noticing a specific macro package, you can use mandoc to choose one. When you run the groff formatting command, you can indicate on the command line which packages you are using. You can also indicate that the command should run through any of the following commands that preprocess text for special formats:

- eqn — Formats macros that produce equations in groff.
- pic — Formats macros that create line drawings in groff.
- tbl — Formats macros that produce tables within groff.

The formatted Groff document is output for a particular device type. The device can be a printer, a window, or (for plain text) your shell. Here are the output formats:

- ps — PostScript for PostScript printer or a PostScript viewer
- lj4 — Output for an HP LaserJet or other PCL5-compatible printer.
- ascii — Plain-text output that can be viewed from a Terminal window.
- dvi — Output in TeX dvi, to output to a variety of devices described later.
- X75 — Output for an X11 70 dots/inch preview.
- X100 — Output for an X11 100 dots/inch preview.
- latin1 — Typewriter-like output using the ISO Latin-1 character set.

## Formatting and Documents with Groff

Try formatting and printing an existing Groff document using many pages from your system. You'll find some in /usr/share/man/*; they're compressed, so copy them to a temporary directory and unzip them to try out Groff.

The following commands copy the man page to the /tmp directory, unzip it, and format it in plain text so you can page through it on your screen:

```
$ cp /usr/share/man/1 /tmp
$ gunzip /tmp/1.gz
$ groff -man < /tmp/1 | less
```
