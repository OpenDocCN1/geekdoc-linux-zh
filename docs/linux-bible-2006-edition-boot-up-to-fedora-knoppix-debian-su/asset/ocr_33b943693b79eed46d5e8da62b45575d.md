# KDevelop: KDE's IDE

KDevelop, another open source IDE licensed under the GPL, was originally created to provide an IDE that operated seamlessly with KDE and the Qt framework (a large C++ application framework) on which KDE is based. Over the years, KDevelop has evolved into an attractive, feature-rich development environment supporting a number of languages other than C++. Today, KDevelop is a general-purpose IDE, although it works best when to create Qt-based applications written in C++. Figure 28-3 shows a representative screenshot of KDevelop.

If you compare KDevelop's appearance to Eclipse's, you will see that both have the same type of components. In Figure 28-3, the class browser is located on the left side of the screen, the project window is located in the upper right portion of the screen, and KDevelop's version of the Declaration view is displayed in the lower right portion of the screen.

The log view that occupies the bottom of the KDevelop interface in Figure 28-3 shows the compilation process. As Eclipse, KDevelop's toolbars and menus are stuffed with buttons and menu items that cater to the needs of developers, just as a word processor is customized with buttons and menu items to the task of writing and formatting documents.

For more information about KDevelop, including download information, visit the KDevelop home page at http://kdevelop.kde.org/. The language support page (www.kdevelop.org/HEAD/doc/api/html/LangSupportStatus.html) shows the current list of supported programming languages.
