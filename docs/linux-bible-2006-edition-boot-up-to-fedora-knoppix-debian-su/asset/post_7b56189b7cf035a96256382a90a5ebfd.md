# Monitoring Partitions for Writing

Provided your partitions are properly detected, Windows partitions is no different than Linux partitions. For Windows file system types FAT and VFAT, there is no problem mounting and writing to those file systems. For NTFS partitions, there are a few things you should consider before writing to them.

Earlier versions of KNOPPIX allowed you to download a feature Captive NTFS. With NTFS, you could use Windows drivers to access NTFS partitions from KNOPPIX. This was considered to be reliable enough that you could write to NTFS without much fear of corruption.

The current version of KNOPPIX uses drivers from the Linux-FS (http://linux-fs.sourceforge.net) to provide support for accessing NTFS file systems from Linux. The advantage of using Linux-FS is that NTFS partitions can be mounted and used like any other Linux file system. You don't need Windows drivers. The downside is that writing to NTFS partitions using LinuxFS is considered unreliable and could cause corruption to your NTFS partition. So, I recommend not try to write to an NTFS file system from KNOPPIX, but feel free to read from NTFS during a KNOPPIX session.

# Creating a Persistent Home Directory

If you are going to use the computer more than once with KNOPPIX (or if you just want more storage space for files than your computer has available in RAM) you assign your KNOPPIX home directory (/home/knoppix) to use some of the available space on your hard drive. That can be done in two ways:

- Assigning an entire partition to be used for your home directory.
- Assigning a part of that for your home directory, in the form of an image file.

You can also put your persistent home directory on rewritable, removable media, such as a memory stick. Once you create that area to use as your home directory, you can tell KNOPPIX it every time you restart KNOPPIX. Here's what you do:

- 1. Click the squished penguin in the panel, and then Select Create Persistent KNOPPIX disk image. A window appears, asking if you are ready to create a persistent home directory.
- 2. Click Yes to continue. You are asked which partition you want to use for your persistent home directory.
- 3. Select the partition you want to store your persistent desktop and click OK. You are asked if you want to save the home directory in an encrypted format.
- 4. Select No, to have the directory encrypted (if you choose Yes, you'll have to specify a password that you will need to access the persistent home directory at boot time). You are asked to enter the size of your home directory.
- 5. Type the number of megabytes to assign to your home directory and click OK. Be sure that much space is available on the partition. (When the partition is mounted, you can use df -h to see how much space is available on it.) The partition or image file should be created.

When I ran this procedure to create a 100MB image over the hd5 partition, the file /mnt/hd5/knoppix.img, which had 97MB of available space. To see how to use that, see the "Restarting KNOPPIX" section later in this chapter.

# Restarting KNOPPIX

You can start KNOPPIX anytime by inserting your KNOPPIX CD or DVD and restarting your computer. However, if you want to take advantage of the persistent desktop you use, you need to add some options to the KNOPPIX boot. Here's how:

- 1. Insert your KNOPPIX CD or DVD into the computer and reboot. You should see the KNOPPIX boot prompt.
- 2. Press F3 (before KNOPPIX boots) to see if any additional options are required.
- 3. If you have a configuration floppy (or other removable media), insert that disk.
- 4. At the boot prompt, type one of the following command lines, which are different ways to load your configuration:

```
boot: knoppix floppyconfig
boot: knoppix myconfig=/dev/hda
boot: knoppix myconfig=/dev/sda
boot: knoppix myconfig-scan
```

These KNOPPIX boot commands, respectively, get configuration information from the first IDE partition from the floppy disk, look for information on the first SCSI drive (/dev/sda), or scan all available drives to find the information. To boot to a persistent desktop (assuming you set up one), you can instead type:

```
boot: knoppix home=/dev/hda1/knoppix.img
boot: knoppix home=/dev/sda1/knoppix.img
boot: knoppix home=scan
```

The previous boot commands, respectively, assign the KNOPPIX home directory (/home/knoppix) to the /dev/hda/knoppix.img file, to the /dev/sda/knoppix.img file, or to the image file found by scanning available directories. You can also combine one from each of the two preceding commands to read your configuration files and assign a persistent desktop, as follows:

```
boot: knoppix floppyconfig home=/dev/hda/knoppix.img
```

Now you are ready to continue your KNOPPIX session where you left last time, with the same configuration and data files available.

# Summary

KNOPPIX offers what many feel is the best bootable Linux today. It gives you a fully configured Linux desktop system available anywhere you can find a bootable PC.

Besides its desktop features, KNOPPIX contains software needed to use many server, programming, and troubleshooting features of Linux as well. The fact that KNOPPIX runs as a bootable system in RAM, by default, there are ways to configure it to save data and configuration information across multiple boot sessions.

KNOPPIX is particularly valuable as a tool for accessing a damaged computer that you can troubleshoot it. With a KNOPPIX disk booted on a computer that was installed to use Microsoft Windows or other operating system, you can use KNOPPIX to access and work with data on that computer's hard disk.
