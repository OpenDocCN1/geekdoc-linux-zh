# Auditor Security Collection

A wide-range of well-organized security tools are on the Auditor Security LiveCD (http://new.remote-exploit.org/index.php/Main_Page). Auditor is based on KNOPIXX, the boot process and basic desktop environment (KDE, by default) will be familiar if you have used KNOPIXX.

Auditor offers a good combination of GUI and command-line security tools. The Auditor menus (shown in Figure 19-1) organize all of those tools together. This lets you find in one place for all security tools. When you select a command from the menu, the command runs with the (-h) option so you can see how it works. It's up to you to type the command and the options you want.
