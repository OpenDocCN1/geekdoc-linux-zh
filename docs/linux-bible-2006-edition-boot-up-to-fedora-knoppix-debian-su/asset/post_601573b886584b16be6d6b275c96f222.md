
The images that are burned onto CDs are typically stored on the Internet with what are called software repositories. You can download the images and burn them to CDs yourself. Alternatively, the software packages are usually included separately in directories. Those separate software directories allow you to start an install process with a minimal boot disk that can grab packages over the network during the installation process. (Some of the installations we recommend with this book are that way.)

When you follow links to Linux software repositories, here's what you look for:

- **Download directory** — You often have to step down a few directories from the link that gets you to a repository. Look for subdirectories that describe the distribution, architecture, release, and medium format. For example- /fora/linux/core/4/i386/iso.

- **ISO images** — The images you are going to be burned to CD are typically stored in ISO format. Some repositories include a README file to tell you what images you need (just adjust as you know). To install a distribution, you want the ISO containing the Linux distribution's binary files. For example, the set of four Fedora Core 4 installations for i386 platforms are FC4-i386-disc1.iso (with the others disc2, disc3, and disc4).

Note

An ISO image appears as one file, it's actually a snapshot of a file system. You can mount the image to see all the files in the image by using the loop feature of the mount command. For an example with abc.iso in the current directory, create a directory (mkdir myiso) and as a root, run the mount command: mount -o loop abc.iso myiso. Change to myiso directory and you can view the files and directory the ISO image contains. When you are viewing the contents, leave the directory and unmount the ISO image (cd .. : mount myiso).

- **MD5SUM** — To verify that you got the right CDs completely, after you download them look for a file named MD5SUM or ending in .md5 in the ISO directory. You can use that file to verify the content of each CD (as described later).

## Downloading the Distribution

You can download each ISO by simply clicking the link and downloading it to a directory in your computer when prompted. You can do this on a Windows or Linux system.

If you know the location of the image you want, with a running Linux system, the get command is a better way to download than just clicking a link in your browser. The advantage of using wget is that you can restart a download that stops in the middle for some reason. A wget command to download a KNOPPIX CD image (starting from the directory you want to download) might look like this:

```
$ wget -c ftp.tux.org/pub/linux/knopPIX_V4.0.2CD-2005-09-23-EN.iso
```

If the download slows down before it is finished, the -c option allows wget to begin where the download left off, so if you are 640MB into when it stopped, it adds back the last 10MB.

You might also want to look into a facility called BitTorrent (http://bittrent.com). BitTorrent lets you download a file to your computer by grabbing bits of that from multiple computers on the network that are downloading the file at the same time. For the privilege, you use your upload capacity to share the file with others as you are downloading.

During times of high demand with a Linux distribution, BitTorrent can be the best way to go. Recent articles have portrayed BitTorrent as a tool for illegal activities, such as downloading copyrighted materials (movies, music, and so on). Because Linux distributions contain only software covered under various open source licenses, there is no legal problem with using BitTorrent to distribute distributions. Check out www.linuxtracker.org for a list of Linux distributions that can be downloaded with BitTorrent.

If you are on a dial-up modem, you should strongly consider purchasing Linux CDs (or getting them from a friend) if we don't have what you want on the CD or DVD with this book. You might be able to download the 700MB CD in a couple of hours on a DSL or cable connection. On a dial-up line, you might be waiting the whole day or more per CD. For a large, multi-CD distribution, available disk space can also become a problem (although, with today's large hard disks, it's not as much of a problem as it used to be).

## Burning the Distribution to CD

With the CDs copied to your computer, you can proceed to verify their contents and burn them to CD. All you need is a CD burner on your computer.

With Linux, you can use the md5sum command to verify the.

If you are using Windows to validate the contents of the Linux CD, you can get the MD5Summer utility (www.md5summer.org) to verify each CD image.

Assuming you downloaded the MD5 file associated with each CD image, in the same directory as your CD images, run the md5sum command to verify the image. For example, to verify the KNOPPIX CD shown previously in the wget example, you would type:

```
$ md5sum KNOPPIX_V4.0.2CD-2005-09-23-EN.iso
1188f6d48c9f1af837297ef4c5 KNOPPIX_V4.0.2CD-2005-09-23-EN.iso
```

## Knowing Your Computer

If you're not sure about computer hardware, there are a few ways to check what you have. If you are running Windows, the System Properties window can show you the processor you have, as well as the amount of RAM that's installed. As an alternative, you can use KNOPPIX and let it detect and report to you the hardware. run lspci, lsmod, and dmesg commands in Linux to view information about your hardware.

- **Processor** — If you are using Windows to validate the contents of the Linux CD, you can get the MD5Summer utility (www.md5summer.org) to verify each CD image.

- **RAM** — Assuming you downloaded the MD5 file associated with each CD image, in the same directory as your CD images, run the md5sum command to verify the image.

- **CD and drive** — You need to be able to boot up the installation process from a DVD or CD. If you can't boot from a DVD or CD, there are ways to start the installation from a hard disk using PXE.

- **Network card** — If you are installing one of the distributions with which we have a scaled-down boot disk, you might need to have an Ethernet card to install the software need over the network.
