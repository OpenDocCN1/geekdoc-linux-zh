# Dual Booting with Windows or Just Linux?

It is possible to have multiple, bootable operating systems on the same computer (using multiple partitions on a hard disk and/or multiple hard disks). Setting up to boot more than one operating system, however, requires some thought. It also assumes some risks.

> Caution While resizing Windows partitions and setting up multi-boot systems have improved in recent years, there is still considerable risk of losing data on Windows/Linux dual-boot systems. Different operating systems often have different views of partition tables and master records that can cause your machine to become unstable (at least temporarily) or lose permanently. Always back up your data before you try to resize a Windows (NTFS or FAT) system to make space for Linux. If you have a choice, install Linux on a machine of your own or at least on a separate hard disk.

If you are already using a Windows system on it, it's quite possible that the hard disk is devoted to Windows. While you can run a bootable Linux, using KNOPPIX or Damn Small Linux, without touching the hard disk, to do a permanent installation you'll want to find disk space out of the Windows installation. There are a few ways to do this:

+   ◆ Add a hard disk — Instead of messing with your Windows partition, you can simply add a hard disk and devote it to Linux.

+   ◆ Resize your partition — If you have available space on your Windows partition, you can shrink that partition so there is free space on the disk to devote to Linux. Commercial tools such as Partition Magic (www.powerquest.com/partitionmagic) or Acronis Disk Director (www.acronis.com) are available to resize your disk partitions and set up a workable boot manager. Some Linux distributions (particularly Ubuntu Linuxes used as rescue CDs) include a tool called QTParted that is an open source clone of Partition Magic (which includes software from the Linux-NTFS project for resizing Windows NTFS partitions).
