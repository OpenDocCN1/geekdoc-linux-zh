+   7. With a file selected and playing, there are a few actions you can take:

* **Control play** — Buttons for playing are what you would expect to see on a standalone CD player. From left to right, the buttons you go to a previous track, play, pause, stop, go to the next track, and eject the CD. The eject button opens, enabling you to load the next file.
* **Adjust sound** — Use the left slider to adjust the volume. Use the right slider to change the right-to-left balance.
* **Display time** — Click in the elapsed time area to toggle elapsed time and remaining.
* **View file information** — Click the button in the upper-corner of the screen to see the XMMS menu. Select View File Info. You can often find out lot of information about the file: title, artist, album, comments, and genre. For an Ogg Vorbis file, you can see specific information about the file itself, such as the format, bitrate, sample rate, frames, file, and more. You can change or add to the tag information and click Save to keep it.

+   * If you have the settings for a particular song, you can save them as a Preset. Set each frequency as you like and click the Preset button. Then choose Save�: Preset. Type a name for the preset and click OK.

+   * To reload a preset you created earlier, click the Preset button and select Load�: Preset. Select the preset you want and click OK.
