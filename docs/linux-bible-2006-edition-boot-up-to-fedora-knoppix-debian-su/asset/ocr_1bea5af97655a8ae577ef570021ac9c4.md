# 84 Part I ♦ Linux First Steps

+   **Conqueror file manager** — Conqueror is the file manager window used with KDE desktops. It can be used not only to manage files but also to display Web pages. Conqueror is described later in this chapter.

+   **Desktop menu** — Right-click the desktop to see a menu of common tasks. The menu provides a quick way to access your bookmarks; create new folders, files, or devices (with devices, you're actually choosing to mount a device on a particular part of the file system); straighten your windows or icons; configure the desktop; and log out of your KDE session.

To navigate the KDE desktop, you can use the mouse or key combinations. The responses from the desktop will depend on which button you click and where the mouse pointer is located.

# Table 3-1
Single-Click Mouse Actions

| Pointer Position | Mouse Button | Result |
| --- | --- | --- |
| Window bar or frame (current active) | Left | Raises current window |
| Window bar or frame (current active) | Middle | Lowers current window |
| Window bar or frame (current active) | Right | Opens operations menu |
| Window bar or frame (current not active) | Left | Activates current window and raises it to the top |
| Window bar or frame (current not active) | Middle | Activates current window and lowers it |
| Window bar or frame (current not active) | Right | Opens operations menu without changing position |
| Inner window (current not active) | Left | Activates current window, raises it to the top, and passes the click to the window |
| Inner window (current not active) | Middle or Right | Activates current window and passes the click to the window |
| Any part of a window | Middle (plus Alt key) | Toggles between raising and lowering the window |
| Any part of a window | Right (plus Alt key) | Resizes the window |
