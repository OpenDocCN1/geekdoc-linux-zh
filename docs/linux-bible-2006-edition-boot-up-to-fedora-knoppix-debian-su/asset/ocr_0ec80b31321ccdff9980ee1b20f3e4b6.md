Fortunately Linux and all modern UNIX systems support a shadow password file by default. The shadow file is a special version of `passwd` file that only root can read. It contains the encrypted password information, so passwords can be left out of the `passwd` file, which any user on the system can read. Linux supports the older, single password file method as well the newer shadow password file. You should always use the shadow password file (it is used by default).

# Checking for the Shadow Password File

The password file is named `passwd` and is found in the `/etc` directory. The shadow password file is named `shadow` and is also located in `/etc`. If `/etc/shadow` file is missing, it is likely that your Linux system is storing the password information in the `/etc/passwd` file instead. Verify this by displaying the file with the `less` command.

```
# /etc/passwd
```

Something like the following should be displayed:

```
root:Dkk6Uke79fYq:0:0:root:/root:/bin/bash
bin*:1:1:bin:/bin
daemon*:2:2:daemon:/sbin/bin
```

```
mary:KRPUp20zmY5:500:100:Mary Smith:/home/mary:/bin/sh
joe:O5xrZvnKnAOI:501:100:Joe Johnson:/home/joe:/bin/sh
jane:ptnoOIeEJWXk.:502:100:Jane Anderson:/home/jane:/bin/sh
bob:JuV2Y7A0KXZW5:503:100:Bob Reynolds:/home/bob:/bin/bash
```

Each line in this list corresponds to a user account on the Linux system. Each line is made up of seven fields separated by colons (:). Characters from left to right are the login name, the encrypted password, the user ID, the group ID, the description, the home directory, and the default shell. Looking at the first line, you see that it is for root account and has an encrypted password of `Dkk6Uke79YQ`. You can also see that root has a user ID of zero, a group ID of zero, and a home directory of `/root`, and root default shell is `/bin/sh`.

All these values are normal for a root account, but seeing that encrypted password file set off all bells in your head. It confirms that your system is not using the shadow password file. At this point, you should immediately convert your password file so that it uses `/etc/shadow` to store the password information.
