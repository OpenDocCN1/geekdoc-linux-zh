To Linux, the USB mass storage camera appears as a SCSI drive containing a VFAT file system with image files on it. Here's a procedure for using your digital camera as a USB storage device:

+   1. Use the cable provided with your digital camera to connect your camera to a USB port on your computer, and turn the camera so it is ready to send and receive data.
2. Boot your computer.
3. Open the /etc/fstab file as root user and see if an entry was created for your digital camera. If you have no other SCSI devices on your computer, the camera is probably detected as a /dev/sda device. Here's what the entry might look like:
/dev/sda mnt/camera auto defaults.user,noatime 0 0

If no such entry appears, create the entry. Create the mount point directory (as root user), type the command to mount the camera: mkdir /mnt/camera).

+   4. As root user, type the command to mount the camera: mount /mnt/camera.
5. Open the /mnt/camera directory as you would any other directory from the shell or from a file manager. Copy, delete, move, and rename files as you would have any files on your hard disk.

+   6. When you are done, unmount the camera (as root user from a Terminal window):

```
# umount /mnt/camera
```

If you unplug your camera without unmounting the file system, it can damage the files on your camera.

You can follow this procedure to use other USB mass storage devices (CD drives, chains, and so on) in Linux. Use different directories (such as /mnt/keychain) and check which SCSI device is assigned to the USB storage device.

To see if your USB storage device can be seen by Linux, check the /var/log/dmesg or run the usbview command. Either will tell you if the device is detected properly by Linux.
