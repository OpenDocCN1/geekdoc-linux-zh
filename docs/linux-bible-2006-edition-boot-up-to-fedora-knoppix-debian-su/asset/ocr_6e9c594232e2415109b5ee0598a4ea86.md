# Configuring X

Before 2004, most Linux distributions used the X server from the XFree86 project (www.free86.org). Because of licensing issues, many of the major Linux vendors (including Red Hat, SUSE, and Slack) changed to the X server from Xorg (www.x.org). The descriptions of how to get going on your system assume you are using the Xorg server.

> To determine which X is installed on your system, from a Terminal window type man Xorg or XFree86. If you have only one X installed on computer (which probably do) only the one will show a page. While you are, press the spacebar to page through the features of your X Server.

It is possible that you already did some configuration when you installed Linux. If you are able to start a desktop successfully and your mouse, keyboard, and screen seem to be behaving, you may not have to do anything more to configure X.

However, if you can't start the desktop or want to adjust some basic features (as as screen resolution or number of colors supported), the following sections offer some ideas on how to go about doing things.

# Creating a Working Configuration File

If your desktop crashes immediately or shows only garbled text, try to create a new X configuration file. With the Xorg server, file is /etc/X11/xorg.conf.

> In XFree86, the configuration file, which has basically the same format, /etc/X11/XF86Config.

To have X try to create a sane xorg.conf file for you to use, do the following from a Terminal window as root user:

+   1. If Linux boots to a command prompt, go to the next. However, if it tried to start X automatically, you might have an illegal screen. In that case, press these keys together: Ctrl-Alt-Backspace. It should kill your X server and get you back to a command prompt. If X tries to restart (and if is still messed up), press Ctrl-Alt-F2. When you see the command prompt, log in as root and type init 3. This will temporarily bring you to a nongraphic state.

+   2. To have X probe your video hardware and create a new configuration file, type: # Xorg -configure
