
# Ubuntu as a Server

Many features are not useful for a desktop Linux system, although they are important to servers, have been built into the Ubuntu default server install. By their natures, servers tend to grow. So features such as the ability to create LVM partitions during installation make it easier for you to add disk space to your server on the fly in the places it is needed.

Added to the default server install is support for more RAM on regular PCs (32-bit architecture) up to 4GB of RAM can be used. Also, support is added to the Ubuntu server's kernel for the GFS and OCSF2 cluster system. While GFS and OCSF2 are still quite new, they may not be ready for you to use on your production systems, they are available for you to try out in Ubuntu.

To use Ubuntu as a thin-client server, Linux Terminal Server Project software is included in the Ubuntu server. You can read about how to use LTSP on the Ubuntu Thin Client HOWTO (http://wiki.ubuntu.com/ThinClientHowto).

The default server install takes only about 400MB of disk space, it is a very bare-bones system. Besides base software packages and core utilities, which you use software for managing your network connections and file systems, but not much else. Luckily, however, if you get application management utilities (such as apt-get), then any open source software you want to add to your server is just apt-get with an Internet connection.

# Ubuntu Spin-Offs

Because no single CD of software is going to please everyone, some spin-off projects have already been created from Ubuntu. The following are two partner projects associated with Ubuntu Linux:

- **Kubuntu** (www.ubuntu.org) — This project combines the latest version of the KDE desktop with each Ubuntu release. KDE replaces the GNOME desktop, which is used by default with Ubuntu. The first version of Kubuntu combined the KDE 2.6 kernel with KDE 3.4.

- **Edubuntu** (www.ubuntu.org) — This project aims at producing a version of Ubuntu that is suitable for classrooms. Edubuntu combines Ubuntu with software geared toward education (such as KDE Eduainment software) and software used for creating inexpensive computer clusters (such as the Linux Terminal Server Project). As a result, Edubuntu can be used to fill a school's whole computer lab with working, educational workstations at very little cost.

Because of Ubuntu's commitment to help people of different cultures, with support for many different languages and keyboard types, there are Ubuntu communities to support users from all over the world. There's Ubuntu China (www.ubuntu.org.cn), Ubuntu Germany (www.ubuntu-forum.de), Ubuntu Sweden (www.ubuntlinux.se), Ubuntu Indonesia (www.ubuntlinux.or.id), Ubuntu Portugal (www.ubuntu-pt-org), and more than 20 international Ubuntu sites.

# Challenges Facing Ubuntu

Despite its rise to stardom, Ubuntu is bound to suffer some growing pains. Some possible challenges Ubuntu faces include:

- **Debian's goodwill**— While Debian relies on thousands of developers worldwide, Ubuntu has a handful (ten was the last number I) of full-time developers. This means that going forward, they have a great deal on the goodwill of the Debian community. There are some in the Debian community who have spoken out, saying that the good work of the Debian project has been hijacked by a rich guy and a few developers have taken credit from the Debian project. To continue, Ubuntu needs to find a comfortable way to coexist with the Debian project.

- **Fast release cycles**— Ubuntu set itself a place of six-month release cycles. In terms of Linux distributions, only Red Hat (and its community-driven Fedora) has consistently stayed close to a six-month release cycle. Debian has not been known to release new versions. Breezy (the third release of Ubuntu) came in October, 2005. So the two releases of Ubuntu following the original in October 2004 have bit the six-month schedule. The challenge is to see if they can keep up.

- **Business model**— While the Ubuntu project offers shirts, hats, teddy bears, and other products you can purchase that carry the Ubuntu logo (www.cafepress.com/ubuntushop), proceeds from that and are not clearly going to be enough to support a long-term development effort. The project has made clear that it intends to be committed to software that is "100% free of charge". How will Ubuntu be paid in the future if the costs become too much for its benefactor to bear?

- **Freedom and responsibility**— Endeavors with goals such as freedom and equality guiding lights sometimes suffer from a lack of control. As Ubuntu becomes more popular, technical discussions have sometimes spun out of control to become almost religious discussions. This problem is not unique to Ubuntu. However, Ubuntu seems to resist the response that some profit-oriented projects ultimately resolve: "Because we say so."

So far, I believe, Ubuntu leadership has done a good job setting up a structure to make decisions in a free environment. For example, Ubuntu now has a Community Council (to create teams and projects, as well as leaders for each team) and a Technical Board (to guide the technical direction of Ubuntu). There is also now a Code of Conduct (www.ubuntu.com/community/conduct) presented to keep everyone participating in the project on the same path.

# Installing Ubuntu

Installing Ubuntu to hard disk requires a computer with at least 24MB of RAM. As for hard disk space, you will need at least 1.8GB of space to install a desktop system or 400MB of disk space for a minimal server system. For the minimal server, you need to be able to work from the command line (no GUI is installed).

![](img/a2d958d7eab32ca5b89b2b8af808aa70_478_0.png)

The Ubuntu 5.10 installation CD image is included on the DVD that comes with this book. Refer to Appendix A for information on copying and burning that image to CD.

If you are setting Ubuntu to dual-boot on a computer with a Windows system currently installed, first you need to make sure the free disk space exists outside of the Windows partition. See Chapter 7 for information on resizing hard partitions to make space for a Linux installation. Of course, you should also back up any important data before this process.

![](img/a2d958d7eab32ca5b89b2b8af808aa70_478_1.png)

If you have an Ubuntu LiveCD, I recommend you boot first, before trying a hard disk install. The LiveCD gives you an opportunity to see if your computer can boot Ubuntu, and it gives you an indication of whether or not your hardware can be easily detected and configured, before you change the contents of your hard disk.

The following procedure describes how to install Ubuntu:

- 1. Insert the Ubuntu installation CD and reboot your computer. You will see the Ubuntu boot prompt. (If you don't see the boot prompt, make sure your computer is capable of booting from a CD, as described in Chapter 7).
- 2. From the boot prompt, there are several screens you can view for information that might help you if you have special requirements during the install. The following is a list of function keys you can press and descriptions of each resulting page:
    * **Help index (F1)** — Lists what is available on the boot screens.
    * **Prerequisites (F2)** — Describes RAM and disk space needed to install Ubuntu.
    * **Boot methods (F3)** — Notes which word to type at the boot prompt.
- 3. To start the installation process, either press Enter (start a default desktop), **type linux** (followed by any boot parameters, for a desktop install), or **type server** (followed by any boot parameters, for a server install). The installer starts, some initial hardware detection, and asks you what language you would like to use.
- 4. Select the language you want to use for Ubuntu and press Enter. The default is English. You are asked to select your location.
- 5. Choose your location. Your location will refine the language used (in other words, US English might be different from Canadian English). You are asked to select your keyboard.
- 6. Select your keyboard type. The Ubuntu installer tries to further your computer hardware. If it loads the drivers needed to get those components to work, you are asked to configure your network.
- 7. If a network interface card is detected (such as an Ethernet card, not a modem), you can select it. You are asked to select a name for your computer.
- 8. Select a name for your computer (Ubuntu is used by default, but you can choose any name that doesn't conflict with other computers on your network). You are asked to begin partitioning your hard disk.

> Caution Changing or removing existing partitions can result in data being lost. Consider your options carefully before selecting a partitioning method.

- **Erase entire disk** — Erases your entire hard disk, repartitions automatically. Choose this method if you are prepared to remove all the data on your hard disk. Ubuntu installer will repartition using Linux file system types.
