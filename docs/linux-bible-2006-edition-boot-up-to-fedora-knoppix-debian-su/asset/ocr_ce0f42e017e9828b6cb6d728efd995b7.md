Now you're ready to begin installing (or booting) the Linux distribution you just have burned. Then go to the chapter that covers your particular distribution to find its specific installation procedure.

If you don't have Linux installed or K3b available at the moment, you can burn CDs from any CD-burning application you have available. There's a nice overview of CD installation tools and how to use them to burn CDs at the Gentoo Web site (www.gentoo.org/doc/en/faq.xml). It describes disk-burning tools that are available on Windows, Mac OS, and Linux systems.

If you have no GUI, or dont working from the shell, you can use the cdrecord command to burn the ISOs. With a blank CD inserted and the ISO image you want to burn in the current directory, here's a simple command line for burning a CD image using cdrecord:

```
# cdrecord -v whatever.iso
```

See the cdrecord man page (man cdrecord) to see other options available with the cdrecord command.
