3. Select Show disabled software sources and click Close. Additional community-maintained software repositories are displayed on the Software Preferences window.

4. Select one of the Binary Community maintained repositories so that a check mark appears in the box next to it. Select OK. You are warned that your repository list has changed and a backup of the original list is contained in the `/etc/apt/sources.list.save`.

5. Select Reload and the new package information is downloaded to your computer.

6. Select Reload from the main Synaptic window. Software from the added repositories now appears in the list of software you can install in your system.

At this point, you can install any of the software that was added to your software list. Keep in mind, that because this software is not fully supported by Ubuntu, it will not receive official patches or security updates from the Ubuntu development team. In others, you are on your own.

If you want to stray from the officially supported Ubuntu software, you can add custom repositories to your Ubuntu repository list. Here is where you need to be particularly careful, be sure to read the caution before proceeding.
