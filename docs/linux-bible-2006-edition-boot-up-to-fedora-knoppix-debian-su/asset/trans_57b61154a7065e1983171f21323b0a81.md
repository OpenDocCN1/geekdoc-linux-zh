

## 第三部分 ♦ 选择和安装 Linux 发行版

虽然人们在随意使用 Linux 系统时很少觉得需要很多分区，但对于那些需要维护并偶尔必须恢复大型系统的人来说，当系统需要修复到几个分区时，他们会感激不尽。多个分区可以将蓄意的破坏（例如拒绝服务攻击）、误操作用户引起的问题以及意外的文件系统损坏隔离开。

## 使用 LILO 或 GRUB 引导程序

引导程序（boot loader）允许您选择以及如何启动安装在计算机硬盘上的可启动操作系统。大多数 Linux 系统都为您提供了使用 GRUB 或 LILO 引导程序的机会。以下章节将同时介绍 GRUB 和 LILO 引导程序。

## 使用 GRUB 启动您的计算机

在安装了多个操作系统并设置了几个分区的情况下，您的计算机是如何知道启动哪一个操作系统的呢？为了选择和管理启动哪个分区以及如何启动它，您需要一个引导程序。Fedora 默认安装的引导程序是全统一引导程序（GRUB）。

GRUB 是一个 GNU 引导程序（www.gnu.org/grub），它取代了许多 Linux 系统（包括 Fedora）的默认引导程序。GRUB 提供了以下功能：

- 支持多种可执行格式。
- 支持多引导操作系统（如 Fedora、FreeBSD、NetBSD、OpenBSD 以及其他 Linux 系统）。
- 通过链加载（chain-loading）功能支持非多引导操作系统（如 Windows 95、Windows 98、Windows NT、Windows ME、Windows XP 和 OS/2）。链加载是指从 GRUB 加载另一个引导程序（假设是特定专有系统的引导程序）来启动选定的操作系统。
- 支持多种文件系统类型。
- 支持引导镜像的自动解压。
- 支持从网络下载引导镜像。

有关 GRUB 如何工作的更多信息，请输入 `man grub` 或 `info grub`。`info` 包含更多关于 GRUB 的详细信息。

## 使用 GRUB 启动

当您安装 Linux 时，通常会有将启动计算机（带有一个或多个操作系统）所需的信息配置到默认引导程序的选项。配置好 GRUB 后，当您启动计算机时，在 BIOS 加载 GRUB 启动屏幕（顶部显示 GRUB，下方列出可启动分区）之后，您首先看到的是执行以下操作之一：

- **默认（Default）** —— 如果您什么都不做，默认操作系统将在几秒后自动启动。
- **选择操作系统（Select an operating system）** —— 使用上下方向键选择屏幕上显示的任何操作系统。然后按回车键（Enter）启动该系统。
- **编辑启动过程（Edit the boot process）** —— 如果您想更改启动过程中使用的任何选项，请使用方向键选择您想要的操作系统并输入 `e` 进行选择。接下来的步骤将用于临时更改您的启动选项。

如果您想更改启动选项使其在每次启动计算机时都生效，请查看关于“永久更改启动选项”的章节。更改选项涉及编辑 `/boot/grub/grub.conf` 文件。

## 临时更改启动选项

从 GRUB 启动屏幕开始，您可以选择为当前会话更改或添加启动选项。首先，选择您运行的操作系统（使用方向键）并输入 `e`（如前所述）。您将看到一个图形化界面，其中包含如下信息：

```
GRUB version 0.94 (639K lower / 12876K memory)
root(hd0,0)
kernel/vmlinuz-2.6.13-11526_FC4 root=LABEL=/initrd-2.6.13-11526_FC4.img
```

使用方向键选择高亮显示的条目。按 'b' 在启动序列中执行选定的命令，按 'c' 进入命令行，按 'o' 在选定行之后打开新行（在 '0' 之后），按 'd' 删除选定行，或按退出键（escape）返回主菜单。

在 GRUB 编辑屏幕的示例中有三行，用于标识您所选操作系统的启动过程。第一行（以 `root` 开头）显示 GRUB 引导程序的条目是第一块磁盘 `hd0,0` 的第一个分区。GRUB 将硬盘表示为 `hd`，无论其是 SCSI、IDE 还是其他类型的磁盘。您只需从零（0）开始计算硬盘编号和分区编号即可。

示例的第二行（以 `kernel` 开头）标识了引导镜像（`/boot/vmlinuz-2.6.13-11526_FC4`）以及几个选项。这些选项标识了分区最初加载为 `ro`（只读）以及根目录 `LABEL=/` 的位置。第三行（以 `initrd` 开头）标识了初始 RAM 磁盘的位置，它包含了启动过程中所需的最小文件和目录。

如果您要更改任何与启动过程相关的行，您可能只会更改第二行来添加或删除选项。以下是操作方法：

1. 将光标置于 `kernel` 行上并输入 `e`。
2. 在引导镜像名称之后添加或删除选项。您可以使用 bash 命令行编辑功能来编辑文件名。以下是您可以执行的编辑示例：
   - **进入 Shell（Boot to shell）** —— 如果您想在启动后进入 Shell，请在行尾添加选项（在旧版 Linux 启动中，这通常通过删除 `ro` 和 `initrd` 部分来实现）。
   - **选择运行级别（Select a run level）** —— 如果您想进入特定的运行级别，请在行尾添加数字（例如 `3`）。
3. 修改完成后，按 `b` 启动启动序列中的选定命令。
4. 或者按退出键返回主菜单。

## 永久更改启动选项

如果您想更改启动选项使其在每次启动计算机时都生效，请查看关于“永久更改启动选项”的章节。更改选项涉及编辑 `/boot/grub/grub.conf` 文件（或者在较新版本的 Fedora 中，该文件可能位于 `/boot/grub2/grub.cfg`）。

在 `/boot/grub/grub.conf` 中可以看到 GRUB 引导程序的配置：

```
# grub.conf generated by anaconda
# Note: DO NOT EDIT THIS FILE MANUALLY. It will be overwritten by anaconda.
# ...
#
#
#
#
#
#
#
#
# /boot/splash...
root(hd0,0)
kernel/vmlinuz-2.6.13-11526_FC4 root=LABEL=/initrd-2.6.13-11526_FC4.img
initrd=/initrd-2.6.13-11526_FC4.img
ro splash
timeout=5
default=0
```

要永久更改这些选项，通常的方法是使用 `grub-mkconfig` 命令来重新生成配置文件。
