In this example, the equipment you need includes:

+   * An Ethernet port on each computer plus an extra port for the firewall/router
* A LAN cable for each computer
* A hub or a switch
* A low-end PC (a PC with as little power as 486 might do) running as a Linux firewall/router
* The DSL or cable modem

An alternative to this wired configuration is to replace the hub or switch with a wireless access point. Then each computer equipped with a wireless LAN card can get on the network with wires.
