# 
There are various ways to store and manage the e-mail messages in Mozilla Mail. There's a quick rundown of how to manage incoming mail:

+   * Mail folders — Mail messages are stored in the left column. There should be a separate heading for each mail account you have. For each mail account, incoming messages are stored (by default) in your inbox folder. You can create additional folders to keep track of your mail (right-click on Inbox, and select New Folder to add a folder). Other folders contain drafts of messages set aside for a time (Drafts), templates for creating messages (Templates), messages you have sent (Sent), and messages that you have discarded (Trash).
