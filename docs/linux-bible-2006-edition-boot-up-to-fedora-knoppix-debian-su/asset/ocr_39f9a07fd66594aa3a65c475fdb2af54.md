# Understanding Linux

People who don't know what Linux is sometimes as if it's a program that runs on Microsoft Windows. When I tell them Linux is, itself, an operating system like Windows and that they can replace (or remove) Windows, I sometimes get a surprised reaction: “A PC can run with nothing from Microsoft on?”

Yes, Linux is a full-blown operating system that is a free clone of the UNIX operating system. Start your computer with Linux, and Linux takes over the operation of your PC and manages the aspects of your computer:

+   * Processor**—Because Linux can run many processes from many different users at the same time (even with multiple CPUs on the same machine), Linux needs to be able to manage those processes.
