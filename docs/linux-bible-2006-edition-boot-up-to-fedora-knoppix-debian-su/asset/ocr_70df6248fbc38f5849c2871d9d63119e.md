# Mandriva Features

Unlike Linux distributions that are community-driven, Mandriva is a company that sells Linux products. Community-like activities are available through the Mandriviclub, where there is more than a customer support type of activity than a Linux development center.

Besides the merger with Conectiva, Mandriva also acquired the desktop-oriented Lycoris Linux distribution in June 2005. Therefore, the product offerings changed significantly in the past year (expect changes to continue for a while as dust settles). Actual Mandriva products are delivered along the lines of Mandriva and home office servers.

On the business side, products focus on corporate desktops and servers, as well as some specially firewall and clustering products. To support those products, Mandriva offers a variety of consulting, support and training options. For the home, Linux products range from beginner desktop products to products aimed toward home and small office servers. With the acquisition of Lycoris, Mandriva is also offering a Lycoris desktop product. Lycor was always respected for its ease-of-use.

The latest version of Mandriva Linux as of this writing is Mandriva 10.2. Version numbers for business-oriented products follow a different scheme, with the latest business server product called Linux Corporate Server 3.0. Here is a brief overview of the Mandriva products:

+   **Mandriva Discovery**—Designed with the entry-level desktop user in mind. The package includes basic productivity software such as OpenOffice, Kdeprint, and planning/finance software. Also included the requisite networking tools for e-mail, FTP, and Web browsing. Several media components are also including audio and video playback, image editing, and scanning documents as well as recording.

+   **Mandriva Powerpack**—Includes all the features that Mandriva Discovery Edition has and adds a set of development tools that includes the Kdevel integrated development environment, GCC GNU compiler, GDB debugger, and others. Some non-free, commercial software is also included with this product, including Flash and Java plugins, Java Runtime Environment, and NVIDIA video cards.

+   **Mandriva Powerpack+**—Includes eight CDs and one DVD of software (more than 3,000 software packages in all) and two manuals. Along with the Mandriva complete desktop software, Mandriva Powerpack+ includes a range of server software, including Samba, MySQL, PostgreSQL (e-mail), LDAP, and Apache, which are ready to use after the default installation, making this product well-suited to a network environment where a cost-effective, multipurpose server is needed.
