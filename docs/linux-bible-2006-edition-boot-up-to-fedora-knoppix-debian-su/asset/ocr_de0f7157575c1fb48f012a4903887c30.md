# Chapter 5 ♦ Getting on the Internet

# Configuring Ethernet from the Desktop

Most Linux distributions offer graphical tools for configuring network interfaces. These tools step you through the information you need to enter, and then start up the network interface (if you choose) to begin browsing the Web.

Here is a list of tools for configuring network interfaces in a few Linux distributions. Some of these are graphical tools, and some are menu-based:

+   **Red Hot Ethernet/Fedora Linux** — The Network Configuration window lets you configure network connection using Ethernet, ISDN, modem, Token Ring, Wireless, and xDSL hardware. The Network Configuration window shows the red hat by selecting System Settings or by picking **system-config** and entering the root password when prompted. (On Red Hat systems, the command is `redhat-config-network`.)

+   **SUSE Linux** — The YaST Control Center with SUSE contains features for configuring your network. From the SUSE menu on the panel, select System, then choose Network Devices. The YaST Control Center lets you configure a DSL, ISDN, Modem, or Network Card interface to the network. Select Network Card to configure your wired Ethernet to the Internet.

+   **Gentoo Linux** — From a shell (as root user), type **netsetup eth0** to start the menu-driven interface to configure the network connection from your first Ethernet card (eth0). The tool lets you have try to start using DHCP or static address information that you provide.

+   **KNOPPIX** — Select the penguin icon in the Knoppix desktop, choose Networking/Internet from the menu. Select the Network card menu entry to configure your network card. Or select from several other network types (ADSL, GPRS, ISDN, Modem, or Weaveln).

# Using Network Configuration GUI

An example of a graphical tool for configuring your interface is the Network Configuration GUI that comes with Fedora and Red Hat Linux. If you did not configure your LAN connection during installation of Fedora or RHEL, you can do so at any time using the Network Configuration window. The IP address and host names can be assigned statically to an Ethernet interface or retrieved dynamically from a DHCP server.

> A computer can have more than one IP address because it has multiple network interfaces. Each network interface must have an IP address to connect to a network (if the address is assigned temporarily). So, if you have two Ethernet cards (eth0 and eth1), each needs its own IP address. Also, the address 127.0.0.1 represents the local host that users on the local computer can access services in loopback.
