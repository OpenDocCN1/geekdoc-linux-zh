# 328 Part III ♦ Choosing and Installing a Linux Distribution

YaST (which stands for Yet Another Setup Tool) was, until recently, proprietary code that was not available as open source. However, to gain wider acceptance for YaST among major computing clients as a framework for managing a range of computing services, Novel released YaST under the GNU Public License in March 2004.

YaST makes obvious what you need to install Linux. Hardware detection is done before your eyes. You can set up your disk partitions graphically (highly no need to remember options with the `fdisk` command). Setting up the GRUB boot loader is done for you, with the option to modify it.

One of the nice features of YaST install is that you can scan the configuration process without stepping through every feature. If you scan through the mouse, keyboard, installation mode, partitioning, and other information they look okay, you can click Accept and keep going. You can change any of those settings you choose ("Installing OpenSUSE" section later in this chapter details the installation process with YaST)

YaST offers both graphical (QT) and text-based (ncurses) interfaces, you can use YaST as a configuration tool for the desktop or the shell.
