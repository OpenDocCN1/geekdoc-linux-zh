# 476 Part III ◆ Choosing and Installing a Linux Distribution

The computer with which you create the floppy disk and the computer on which you run it may be the same computer.

You need to know the Linux driver name for your Ethernet cards before you run the procedure to create your firewall floppy. If you don't know it, I recommend starting with KNOPPIX on your machine and using `lsmod` and `lspci` commands to determine the driver names for your Ethernet cards (which should have been autodetected). Use `modinfo` if you are not sure if the driver name is the right one (for example, `modinfo 8139xtoo`).

If possible, it's better to use a broadband or other Ethernet interface to connect to the Internet because dial-up modems can require extra configuration to work, provide slower connections, and you manage bringing dial-up connections up and down the time. This section is meant to illustrate how to use minimal hardware with an extraordinarily compact Linux, which shows how to use an inexpensive connection type as well.
