# Booting KNOOPPIX

If you have a PC in front of you that meets the requirements, you can get started by following these steps:

+   1. Insert your KNOOPPIX DVD or CD into the appropriate drive.
2. Reboot the computer. After a few moments, you will see the boot screen.
Although the boot screens look different for the Linux Bible DVD and a regular KNOOPPIX CD, you can proceed with the boot process the same way.
3. Press Enter. If all goes well, you should see the KNOOPPIX desktop, and you can proceed to the “Using KNOOPPIX” section. If KNOOPPIX doesn't boot properly or if you want to tune it further before it, continue on to the next section.

# Correcting Boot Problems

By understanding all the boot process you will, in most cases, be able to overcome any problems you might have installing KNOOPPIX. Here are some things you should know:

+   **Boot order**— Your computer's BIOS has a particular order in which it looks for boot operating systems. A typical order would be floppy, CD or DVD, and hard disk. If your computer skips over the KNOOPPIX boot disk and boots right from hard disk, make sure that the boot order in the BIOS is set to CD or DVD. To change the BIOS, restart the computer and as it first boots the hardware enter Setup (quickly) as instructed (usually by pressing F1, F2, or DEL). Look for a selection to choose the boot order so that your CD or DVD boots before the hard disk.
**Make floppy disks**—If your computer still can't boot from CD or DVD, you can create two floppy disks from a running KNOOPPIX system, run the mkbootfloppy command that is on the KNOOPPIX disk (it automatically formats the floppy images and tells you when to put in the floppy disks). To create for other operating systems, refer to the KNOOPPIX wiki (www.knoppix.net/wiki/MainPage).
**Add boot options**—Instead of letting the boot process autodetect and configure everything about your hardware, you can add options to the boot prompt that will override your KNOOPPIX autoconfiguration date. Press F2 from the boot prompt to see additional boot options.
