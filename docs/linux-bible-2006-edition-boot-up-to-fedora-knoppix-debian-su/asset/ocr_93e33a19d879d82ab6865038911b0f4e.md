Simple layouts work well with Linux documentation tools. For example, a technical book with a few charts and images can be easily produced and maintained using Geoff or TeX documentation tools. Letters and memos are also easy to do with these tools. And, of course, Linux maps are created with text-based tools.

Additionally, Linux likes PostScript. Although people think of PostScript as a printing language, it is really more of a programming language (you could write PostScript directly). Most Linux document-processing software includes print drivers for PostScript. Some documents on the Web are distributed in PostScript (.ps).

The drawback to the traditional Linux documentation tools is that they are not intuitive. Although there are some easier front ends to LaTeX (see the description of LyX later in this chapter), if you are creating documents in a text editor, you need to learn how macros type into your documents and what formatting to use.

> Note

For many years, the UNIX system documentation distributed by AT&T was created in troff/nroff formats, which precede Geoff. The documents used separate macro packages for man pages and guide material. Using a source code control system (SCCS), AT&T ported thousands of pages of documentation to different UNIX systems.

# Creating Documents in Geoff or LaTeX

You can use any text editor to create documents for both Linux’s Geoff (troff/nroff) and LaTeX styles of publishing. Most Linux distributions come with several text editors. You also have the option to download others from the Internet. (See the “Choosing a Text Editor” sidebar for information.)
