The modprobe command loads modules temporarily—they disappear at the next reboot. To permanently add the module to your system, add the modprobe command to one of the startup scripts run at boot time.

An alternative to modprobe is the insmod command. The advantage of using modprobe, however, is that insmod loads only the module you requested, whereas modprobe tries to load other modules that the one you requested depends on.

# Removing Modules

Use the rmod command to remove a module from a running kernel. For example, to remove the module parport_pc from the current kernel, type the following:

```
rmmod parport_pc
```

If it is not busy, the parport_pc module is removed from the running kernel. If it is busy, try killing any process that might be using the device. Then run rmmod again.

# Managing File Systems and Disk Space

File systems in Linux are organized in a hierarchy, beginning from root (/) and continuing down a structure of directories and subdirectories. As an administrator of a Linux system, it is your duty to make sure all the drives that represent your file system are available to the users of the computer. It is also your job to make sure there is enough disk space in the right places in the file system for users to store what they need.

File systems are organized differently in Linux than they are in Windows operating systems. Instead of drive letters (for example, A:, B:, C:) for each local disk, network file system, CD-ROM, or other type of storage medium, everything fits neatly into the directory structure. It is up to an administrator to create a mount point in the file system and connect the device to that point.

The organization of your file system begins when you install Linux. Part of the installation process is to divide your hard disk (or disks) into partitions. These partitions can be assigned to:

+   ◆ A part of the Linux file system

+   ◆ Swap space for Linux, or

+   ◆ Other file system (perhaps containing other bootable operating systems)

+   ◆ Free space (you can leave space unassigned so you can format it later as you need it).
