+   21. **Select startup services.** For server software that you installed, you need to tell Slackware whether to start that service at boot time. In general, you should turn on only services you want to have (you can always turn any others on). Among the services that will be on default (assuming you installed the packages) are the ssh service, to enable remote login using ssh; system.logging (rc.syslog), to log system activity; and Sendmail, to receive email. To share your printer, you may need to enable CUPS; to be a Web server, you should install Apache (rc.httpd).

+   22. **Configure fonts.** You can try some custom screen fonts. If you find one particular like, you can choose to use it instead of the default.

+   23. **Set hardware clock.** The clock on your computer can be set to local time or to UTC time (Greenwich Mean Time). Most often will set it to local time.

+   24. **Choose a time zone.** Use your current time zone from the list.

+   25. **Select a default window manager.** Choices the KDE and XFC4 desktop environments or any of a smaller window managers, such as Blackbox, Fluxbox, fwm2 (selections look like Windows systems), and TWM (lightweight for most people). If you installed only from the first Slackware CD, KDE is not among your choices if it is installed from the second installation CD.

+   26. **Set root password.** Select a root password when prompted to do so.

+   27. **Select EXIT** to leave the setup screen. The install CD should eject.

+   28. **Press Ctrl+Alt+Delete** to reboot your computer.

# Starting with Slackware

The LILO Boot menu appears when you first boot Slackware. It should contain at least a listing for your Linux partition and possibly for a Windows partition (if there is one on your computer).

Press Enter at the boot prompt to start Slackware. Log in as the root user when you see the login prompt. You are going to be at a Linux command prompt; if you don't know what that is, refer to Chapter 2.

Here are a few things you might want to get started with Slackware:

+   Get mail — Type the command line prompt. You should have a couple of mail messages there for the root user, including one from Patrick Volerkding. Type the number of that message and page through it (using the Enter key) to read some additional steps that may interest you. (Type q to exit the message and x to exit mail).
