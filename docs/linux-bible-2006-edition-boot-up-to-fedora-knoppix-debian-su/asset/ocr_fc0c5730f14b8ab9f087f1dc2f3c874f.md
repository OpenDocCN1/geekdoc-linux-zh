**MIME types and file types** — To handle different types of content that may be encountered in the Nautilus window, you can set applications to respond to MIME type and file type. With a folder displayed, right-click a file for which you want to assign an application. Click either Open With an Application or Open With a Viewer. If no application or viewer has been assigned for the file type, click Associate Application to be able to select an application. From the Add Files window, you can add an application based on the file extension and MIME type representing the file.

**Drag-and-drop** — You can drag-and-drop within the Nautilus window, between Nautilus and the desktop, or multiple Nautilus windows. As other GNOME-compliant applications become available, they are expected to also support the drag-and-drop feature.

If you would like more information on the Nautilus file manager, visit the GNOME Web site (www.gnome.org/nautilus).
