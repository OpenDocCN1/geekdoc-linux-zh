# Using the KDE desktop in KNOOPPIX

KDE is the best desktop environment that comes with KNOOPPIX. You can change that at the boot prompt to use one of several window managers, or get a Gnopp disk instead to use the GNOME environments. But, as delivered, the desktop looks quite similar to what you see in Figure 11-1.

The KNOOPPIX version of KDE pretty matches the descriptions in Chapter 3, although there are a few items related to the KNOOPPIX KDE desktop that are worth noting:

- **Desktop icons** — To get information about KNOOPPIX, click the KNOOPPIX icon (choose a language, and then links to FAQs, Knoper.Net, and general KNOOPPIX information) or the LinuxTag icon (to read the licenses). There is also the requisite Trash icon.

- **Disk icons** — Any CD, DVD, floppy, or other removable media is displayed as an icon on the desktop. Of course, this includes the drive holding the KNOOPPIX disk, which you can get to get directly to such things as find boot images or KNOOPPIX documentation.

Hard disk partitions are also represented by icons on your KNOPPIX desktop. Click one of those icons and you can access (read-only) the files on that hard disk partition. This is a great feature for getting the information you need without default, letting you change or otherwise manage the data on the computer. To make a disk writable, right-click on the disk icon and select Changes read/write mode. If you are not able to write to the disk, refer to the section on making disks writable in this chapter.

- **KDE Panel** — KNOPPIX loads the KDE Panel with applets and launchers for a few applications. Click the K button to display the menu containing most KDE applications for you to select. The Web Browser launches the Konqueror, which is the KDE file manager.

- **KNOPPIX configuration** — Click the squished penguin to see a menu of configuration tools specific to KNOPPIX. This is where you can tune up your TV card, configure printers, get your network connection going, and start a few servers. I describe some of these subjects — in particular how to save data and configuration information across sessions with these other settings — later in this chapter.

- **Launching games, players, and other stuff** — From the KDE menu, you can launch applications as you would from any desktop operating system. Just to illustrate that, I launched a simple game (Frozen Bubble), Konqueror web, and a music player (juk) for Figure 11-1.

Running KNOPPIX, at this point, is like running any other Linux system with a KDE desktop, with one major exception. By default, you can't save any permanently. There are a few ways around this issue, especially if you expect to use KNOOPPIX on a regular basis. Refer to sections on creating persistent desktops and opening disks for writing later in this chapter.

# Getting on the Network

If you have an Ethernet card and a connection to a network that has a DHCP server, your KNOOPPIX system should start up and offer immediate access to that network(work) and possibly the Internet if it offers such connection). If not, KNOOPPIX offers several tools for configuring your network connection, including:

- **Dial-up modem** — From the squished penguin, select Network/Internet/dev modem setup. The menus that appear help you create a dial-connection to the Internet, or other TCP/IP network, using a serial modem, USB modem, IRDA cell phone/PDA, or Bluetooth cell phone/PDA.

- **ADSL router** — From the squished penguin, select Network/Internet/ADSL/PPPOE configuration. It will help you connect your broadband ADSL router to connect the Internet.

- **GPRS connection** — From the squished penguin, select Network/Internet/GPRS/UMTS connection to set up a connection via your cellphone provider.

- **Network card** — From the squished penguin, select Network/Internet ❧ Network card configuration to configure your Ethernet card (assuming you don't just want to use DHCP to get your network address).

- **ISDN** — From the squished penguin, select Network/Internet ❧ ISDN to use ISDN to connect to the network.

- **Wireless Card** — From the squished penguin, select Network/Internet ❧ Wavelun to use a wireless Ethernet card to connect to the network. You can instead select ndiswrapper configuration if there is no Linux driver for your card, but you have a Windows driver you can.

In addition to the interfaces available here, you can use the wdialconf command to create your dial-out connection as described in Chapter 5.

# Installing Software in KNOPPIX

Despite the fact that KNOPPIX includes a wide range of software applications, there may be some software package you want to use with that isn't included. For installing while you are running KNOOPPIX from the DVD, you can use KPackage.

To start KPackage, click the squished penguin on the KNOPPIX panel and select Utilities ❧ raManage Software in KNOPPIX (kpackage). The KNOOPPIX window opens displaying lists of installed and available packages. If there is a package you want to install, type its name into the search box and press Enter. If the package is available, it will be listed, with a notation of whether or not the package is already installed.

If the software package you want to install is available, but not yet installed, select it then click the Install button. KPackage will use the Debian installer to download the package, and all dependent packages, and install them on your computer. Remember that the software being installed in the version of KNOOPPIX that is running in RAM. So, the software will disappear the next time you reboot, unless you do something to preserve your data (such as creating a persistent desktop before installing the software you want to).

# Saving Files in KNOOPPIX

When you reboot your computer with KNOOPPIX, you not only lose KNOOPPIX itself but any data and configuration you may have created along the way. That is because, by default, KNOOPPIX runs from your system's RAM and non-writable. KNOPPIX happily gives you a login name (knoix) and a home directory (/home/knoix), each time you boot. The problem is that those directories are in RAM, so they disappear when you reboot. The following sections give you some ideas about how to save what you do in your session to use in future sessions.

# Writing to Hard Disk

Although hard disk partitions are mounted read-only by default, you can make them read/write if you like. You can store any data you want to save on those partitions. (You can simply drag and drop files to those partitions.)

> Up to this point, there's not risk of damaging any data on your hard disk. Once you make your disks writable, you have the potential for deleting or changing that data. Keep in mind if the computer doesn't belong to you or if you are not using Linux. Regardless of which user you are logged in, KNOPPIX does not prevent you from changing any file in a writable hard disk partition.

# Mounting Linux Partitions for Writing

KNOPPIX usually identifies hard disk partitions and adds entries for each one in /etc/fstab file. If you click the icon representing that partition, the partition is automatically mounted and a folder opens to the root of that directory.

The name of each partition (hda1, hda2, and so forth for IDE partitions: sda1, sda2, and so on for SCSI disk partitions) is shown on the desktop icon representing each partition. Hover the pointer over the icon to see information about the partition's mount point and device. With that information, you can make any of those partitions writable by following these steps:

1. Click the hard disk partition you want to write to on the KNOOPPIX desktop. A folder opens, displaying the top directory in that.

2. When you know which partition you want to write to, close all folders or shells that have that partition. (With the partition open, you can't remnant it.)

3. Open a Terminal from the panel, and use the sudo utility, become root user by typing the following:

```
$ cd
$ sudo su -
#
```

4. Make sure the partition you want to mount as writable is unmounted. For example, to unmount the second IDE hard disk partition (hda2), type the following:

```
# umount /dev/hda2
```
