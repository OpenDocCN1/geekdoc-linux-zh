## Playing Music with Rhythmbox Audio Player

Rhythmbox provides the GNOME music player that lets you do everything, at least according to the Rhythmbox documentation. You can play music files, import from CDs, and play internet radio stations, from one interface.

The first time you run Rhythmbox, the program displays a setup wizard (see Figure 20-2). You can tell Rhythmbox where you store your music files, and Rhythmbox will index, store, and help you maintain a music library.

After you have gone through the setup wizard, you will see the main music library interface (see Figure 20-3). Rhythmbox makes it easy to organize large collections of music files.

## Playing Music with XMMS Multimedia Player

The XMMS (X Multimedia System) multimedia player provides a graphical interface for playing music files in MP3, Ogg Vorbis, WAV, and other audio formats. XMMS has some nice extras too, including an equalizer, a playlist editor, and the capability to add more audio plug-ins. One of its greatest attributes is that it is easy to use. If the player looks familiar to you, that's because it is styled after the Windows Winamp program.

Red Hat removed all software that does MP3 encoding or decoding because of patent concerns related to MP3 format. Although the XMMS player was designed to play MP3 files, the XMMS plug-in required to actually decode MP3 is not included. To add MP3 support to your Red Hat/Fedora Core, you can get and install an MP3 plug-in. One place to get RPM packages that support MP3 decoding is http://rpm.livna.org. They are also available from other sources, including www.xmms.org and www.gurabs.com/downloads.html. This issue does not necessarily apply to other Red Hat-derived distributions, such as Mandrake 10.

Start the MMMS audio player by selecting Sound & Video ♫ Audio Player or by typing kmms from a Terminal window. Figure 20-5 shows the MMMS audio player with an equalizer (below) and the Playlist Editor (to the right).

![](img/a2d958d7eab32ca5b89b2b8af808aa70_549_0.png)

Figure 20-5: Play Ogg Vorbis and other audio files from the MMMS playlist.

As noted earlier, you can play several audio file formats. Supported formats include:

- MP3 (with added plugin-in)
- Ogg Vorbis
- WAV
- AU
- CD Audio
- Quick Movies

> Note: If MMMS is not able to find a configured sound, it redirects its output to the Disk Writer plugin-in. This causes the files you play to be written to hard disk as WAV files.

You can get more audio plug-ins from www.xmms.org. The MMMS audio player can be used in the following way:

1. Obtain music files by ripping songs from a CD or copying them from the Web so that they are in an accessible directory, or by inserting a CD into your CD-ROM drive (MMMS expects the CD to be accessible from /dev/cdrom.).
2. From the applications menu, select Sound & Video ♫ Audio Player. The Multimedia System player appears.
3. Click the Eject button. Load windows appears.
4. If you have inserted a CD, the contents of /mnt/cdrom appear in the Files pane. Select the files you want to add to your Playlist and click the Add Selected Files or the Add All Files in Directory button to add all songs to the current directory. To add audio files from your system folder, browse your files and directories and click the same buttons to add the audio files you want. Select Close.
5. Click the Play List (the tiny button marked PL) on the console. A Playlist editor appears.
6. Double-click the music file, and it starts to.
7. With a file selected and playing, there are a few actions you can take:
    - **Control play** — Buttons for playing are what you would expect to see on a standalone CD player. From left to right, the buttons you go to a previous track, play, pause, stop, go to the next track, and eject the CD. The eject button opens, enabling you to load the next file.
    - **Adjust sound** — Use the left slider to adjust the volume. Use the right slider to change the right-to-left balance.
    - **Display time** — Click in the elapsed time area to toggle elapsed time and remaining.
    - **View file information** — Click the button in the upper-corner of the screen to see the XMMS menu. Select View File Info. You can often find out lot of information about the file: title, artist, album, comments, and genre. For an Ogg Vorbis file, you can see specific information about the file.
8. When you are playing, click the Stop button.

Special features the equalizer let:
- If you have the settings, save them as a preset. Hold the right mouse button down on the List button and then select Playlist Save from the pop-up menu. Browse to the directory you want, and type the name you want to assign to the preset and click OK.
- To a saved playlist, click the List button. Select a playlist from the directory in you saved it and click OK.

## Playlist Editor

The Playlist Editor lets you put together a list of audio files that you want to play. You can add and delete files from this list, save them to a file, and them again. Click the PL button in the XMMS window to open the Playlist Editor.

The Playlist Editor enables you to:

- Add files to the playlist: Click the Add button. Load Files window appears. Select the directory containing your audio files (it's useful to keep them all in one) from the left column. Then select a file from the right column and Click Selected Files or Add All in the Directory. Click OK. The selected file appear(s) in the playlist. You can also add music files by dragging them from the Nautilus manager onto the playlist window.
- Select files to play: To select from the files in the playlist, use the previous track and next tracks in the main XMMS window. The selected file is highlighted. Click the Play button to play that file. Alternatively, you can double-click any file in the playlist to start playing it.
- Delete files from the playlist: To remove files from the playlist, select the files you want to remove (use the next track and previous tracks), right-click the playlist window, and click Remove.
- Save the playlist: To save the current playlist, hold the right mouse button down on the List button and then select Playlist Save from the pop-up menu. Browse to the directory you want, and type the name you want to assign to the playlist and click OK. The filename should end with .m3u extension.
- Load the playlist: To reload a saved playlist, click the List button. Select a playlist from the directory in you saved it and click OK.

There is also a tiny set of buttons at the bottom of the Playlist Editor screen. These are the same buttons as those on the main screen for selecting different tracks or playing, pausing, stopping, or ejecting the current track.
