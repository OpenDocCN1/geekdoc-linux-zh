✦ playback choppy—If playback of files from your hard disk is choppy, there are a couple of settings you can check: 32-bit IO and DMA, features, that are supported by your hard disk, generally improve hard disk performance. Here's how to check:

![](bbox=[0.133, 0.198, 0.193, 0.243])

Improper disk settings can result in destroyed data on your hard disk. This procedure is at your own risk. for IDE hard drives (no SCSI)! Also, be sure to have a current backup and no activity on your hard disk if you change DMA or IO settings in this section.

+   1. Test the speed of hard disk reads. To test the first IDE drive (/dev/hda), type:

```
# hdparm -t /dev/hda
buffered disk reads: 64 MB
19.31 seconds = 3.33 MB/sec
```

+   2. Set your current DMA and IO settings, as root user:

```
# hdparm -c /dev/hda
/dev/hda:
/O support = 0 (default 16-bit)
using_dma = 0 (off)
```

+   3. This result shows that 32-bit IO and DMA are off. To turn them, type:

```
# hdparm -c 1 -d 1 /dev/hda
/dev/hda:
/O support = 1 (32-bit)
using_dma = 1 (on)
```

+   4. With both settings, test the disk again:

```
# hdparm -t /dev/hda
Timing disk reads: 64 MB
2.2 seconds = 28.83 MB/sec
```

In this example, buffered disk reads of 64MB went from 19.31 seconds to 2.2 seconds after changing the parameters described. Playback would be much better now.

✦ Wine not play popular media — Messages as no input plug-in mean that the file format you are trying to play is not supported or it requires an additional plug-in (as is the case with playing DVDs). If the message says xy a broken file, the file may be a proprietary version of an otherwise supported format. For example, I had a QuickTime video fail that required an SVQ3 codec (which is currently not supported by Linux), although other QuickTime files played fine.
