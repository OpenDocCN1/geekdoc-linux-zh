# Ubuntu Releases

Coming into 2006, the Ubuntu project has produced three releases, which, so far have stuck to Ubuntu's promised six-month release cycle. Each release carries a version number and is named after a fury creature:

+   * Warty Warth—Released in October 2004 under Ubuntu version number 4.10.
* Hoary Hedgehog—Released in April 2000 under Ubuntu version number 5.04.
* Breezy Badger—Released in 2005 under Ubuntu version number 5.1

If you are new to Linux, Ubuntu is designed with you in mind. While there are many choices for configuration when you install Ubuntu, defaults work well in most cases. If you are transitioning from Debian (or a Debian derivative, as KNOPPX), you will find it easy to work with Ubuntu. Install and remove packages and manage services with Ubuntu using the same methods as with Debian.

The Ubuntu project offers each release as a single installation CD and a LiveCD. Getting started with Ubuntu is easy because the LiveCD boots to a fully functioning desktop system. The Ubuntu LiveCD takes a bit longer than most LiveCDs to boot up, but it does a great job at detecting hardware, setting up your video environment (mouse, keyboard, and video card), and rebooting to a GNOME desktop.

The installation is also intended (by default) to help you install a fully functioning system. However, the installation CD also gives you the option of installing a minimal server system. The following sections describe the desktop and server features in Ubuntu 5.1 (Breezy Badger).

# Ubuntu Installer

The Ubuntu installer is one of the features that has made Debian-based Linux systems more acceptable to less experienced Linux users. The install process leads you through some fairly simple questions, and then does a very good job of detecting your hardware and installing its whole set of software packages to your hard drive.
