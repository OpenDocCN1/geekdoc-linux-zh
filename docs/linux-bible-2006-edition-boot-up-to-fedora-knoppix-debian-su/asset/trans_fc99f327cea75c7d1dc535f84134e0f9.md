# 配置设置

SUSE 现在已安装，当 SUSE 第一次从硬盘启动时，你会立即看到一个要求你进行基本配置的屏幕。在 YaST Root 密码界面面前，请执行以下操作继续下一步：

- 16. Root 密码。输入 root 密码（两次）。最多输入 8 个字符。DES 是用于保护你密码的默认加密类型。（你可以选择“选项”（Options）来选择 MDS 或 Blowfish。）请参考第 6 章关于选择良好密码的建议。

- 17. 网络配置。YaST 会探测连接到你计算机的任何网络、DSL 连接、ISDN 适配器或调制解调器。根据需要选择屏幕上显示的任何这些项目进行配置。例如，选择“网络接口”（Network Interfaces）以查看任何已安装的网卡。你可以通过 DHCP（如果可用）或你的网络设置配置任何网络地址以连接局域网和/或互联网。（查看第 5 章有关配置互联网连接的信息。）

完成后，点击“下一步”（Next）。SUSE 将设置并告知你的网络连接。

- **18. 用户身份验证方法。** 通常，在用户账户方面，你将在独立模式下使用家用计算机。但在商业环境中，你可能使用 NIS、LDAP 或 Samba 获取用户账户列表，从而访问局域网内的你的和其他计算机。如果是后一种，请选择“客户端”（Client），并不选择 NIS（UNIX 系统共享配置文件的常用设施）或 LDAP（一种标准目录服务，用于共享网络上的地址簿和其他类型的信息），取决于你公司支持哪种。选择 Samba 可以让你使用 Windows SMB 文件和打印共享功能进行身份验证。点击“下一步”。

- **19. 添加新用户** 你将需要按照提示为你的计算机添加至少一个用户账户。现在你已经为单机设备设置了 root 用户账户。使用该账户处理电子邮件、Web 浏览或其他常见任务被认为是不安全的做法：你应该为计算机的非管理性使用添加至少一个用户账户。添加你的全名、单单词登录名以及保护该账户的密码。点击“下一步”。

完成后，YaST 将系统配置信息写入你的计算机。它会显示你当前 SUSE 版本的发行说明（Release Notes）。点击“下一步”继续。

- **20. 硬件配置。** 你现在有机会配置与系统一起使用的其他硬件设备。选择配置你的显卡、打印机、声卡或电视卡。在显卡配置后，你应该按照提示测试你的显示器。如果设置无效，选择 Ctrl-Alt-Backspace 退出并尝试重新配置。

完成硬件配置后，点击“接受”（Accept）。设置将写入硬盘。出现一个“安装完成”（Installation Completed）屏幕。

- **21. 完成。** 点击“完成”（Finish）。系统重启并准备好供你登录。

# 从 SUSE 开始

如果你在之前的安装过程中创建了用户账户，SUSE 应该自动以该用户的身份登录并向你展示 KDE 桌面。（如果你看到的是图形登录界面，请现在现在以该用户身份登录）。以下是一些帮助你开始使用 SUSE 的事项：

- **桌面应用程序** 默认的 SUSE 10.0 安装为桌面系统，包含一组易于访问的桌面应用程序。在桌面上，尝试点击 Office 图标打开 OpenOffice.org 来处理文档、电子表格、演示文稿、图纸、网页或其他各种其他类型的内容。从面板上的 SUSE 图标，从数十个应用程序中选择进行尝试。

- **支持**——点击 SUSE 桌面图标将带你进入一个页面，让你可以检查软件更新或获取免费的 Novell Linux 通讯内容。订阅通讯内容还为你提供了订阅其他 Novell Linux 服务的机会。

如果你想配置桌面（更改背景、屏幕保护程序或主题），请像使用任何 KDE 桌面一样使用 KDE 控制中心。你可以从 SUSE 菜单启动控制中心（选择“控制中心”）。

# 总结

SUSE 通常被认为是企业级 Linux 系统的最佳选择之一，类似于 Red Hat Enterprise Linux。它的图形和管理工具（在名为 YaST 的设施中实现）使其与面向技术用户的其他 Linux 发行版区分开来。

自从 SUSE 在 2003 年被 Novell 收以来，SUSE Linux 已成为更大、企业级产品线的一部分。提供 SUSE Linux 盒装版。提供多个水平的支持服务。凭借 Novell 全球销售和培训组织，SUSE Linux 拥有了竞争成为全球最受欢迎的商业 Linux 系统所需的支持。

由于在 YaST 安装程序和管理界面上投入了大量工作，即使是毫无经验的用户也可以在一个小时内在新安装的系统上运行。从 SUSE 桌面可以轻松开始使用各种桌面应用程序。
