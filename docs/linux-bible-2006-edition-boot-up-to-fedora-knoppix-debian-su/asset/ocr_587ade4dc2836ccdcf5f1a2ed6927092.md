# The Right Hardware for Mandriva

As with software packages, look before you leave. It is important to make sure your hardware is up to the task before you install Mandriva. Fear not, users of less-than-stellar hardware; the hardware requirements are far from onerous. Use Mandriva you need (or you can use):

+   * **x86 class processor or above** — The Intel Pentium-IV, AMD K6/II/III, Duron, or Athlon/XP.
* **RAM** — For text installation, the minimum is 32MB of memory. If you plan to use the GUI, the minimum is 64MB, but 128MB is recommended.
* **Hard disk** — 500MB of SCSI, IDE, or Serial ATA hard disk is the bare minimum. 1GB is recommended, and if you decide to install additional packages, you should have at least 2GB of free disk space available.
* **RAID controllers** — There is wide support for SCSI RAID controllers. In addition, Wide IDE and Serial ATA controllers are also supported.
* **DVD or CD drive** — To run the installation from a CD/DVD source disk, you need the appropriate drive. This drive will need to support bootable CD/DVD media.
* **Input/Output** — Of course, if you want to interact with your Mandriva install, you'll need least a keyboard and a monitor. A mouse is not needed for the installation, but it is handy and recommended.

> For those who live on the bleeding edge, there is a distribution of Mandriva that supports the AMD Athlon64 processor. This distribution is available currently only as a commercial product from the right side of Mandriva. mandriva.com.

As you can from the system specifications, you can use a wide range of hardware to run your Mandriva installation. If you have an old P233 with 64MB of RAM, a CD-ROM, and a blank 540MB hard disk? No problem. How about a "gaming machine" sporting a 3.2 GHz P4, 1GB of RAM, DVD-R, and an ocean of hard disk space? Bring it on!
