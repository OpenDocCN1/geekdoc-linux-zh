# 400 Part III Choosing and Installing a Linux Distribution

If something goes wrong, it can be hard to debug a problem with most graphical interfaces. The Slack installer is menu-based, very flexible, and quite intuitive.

+   **Less bleak**—In general, graphical interfaces consume more resources than their command-line counterparts. GUIs require more room on the distribution, plus more hard disk space and more RAM. Slack relies primarily on basic Linux commands, text-based configuration files, and some simple menu-driven administration tools. With a Slack 10.2 system, you can install a basic functional command-line version on a 100MB hard disk.

+   **Better for low-end computers**—Slack is the first distribution recommend to run on low-end machines. A special ZipSlack (www.slack.com/zipslack) can be installed from a 100MB Zip drive or floppy disks. Slack can run on a 386 PC with as little as 4MB of RAM. Even with the latest distribution, if you want a GUI, the installation procedure for Slack lets you choose some efficient window managers, Web browsers, mail clients, and other graphical tools.

+   **Packages as intended**—Slack does not mold the software it includes into one look-and-feel. The Apache Web server, KDE desktop, or Samba/file sharing projects work pretty much as they are delivered from those projects. So, the knowledge you gain from those projects will transfer easily to those projects on other Linux systems.

Instead of providing a unified look-and-feel, Slack gives you the maximum amount of control. It allows the desktop environment or window manager you choose to dictate the desktop presentation. You can change your desktop as you like, using the menus or preference windows that come with those environments. A full desktop environment is included with Slack (contained mostly on the second of two Slack installation CDs). Or you can opt for a lighter, more efficient window manager, such as XFCE, fwm2, or more.

> The GNOME desktop environment was dropped from Slack 10.2. Patrick Volkerding, Slack's creator/maintainer, cited demands of keeping up with GNOME development changes and some GNOME features don't match Slack objectives (such including RAM and replacing some system packages, such as X11). Volkerding suggests two projects if you want to add GNOME yourself to your own installation of Slack: http://gsb.sf.net/gware.sf.net.

For system administration, Slack offers some tools based on the ncurses textmode windowing library. Ncurses allows an application to provide a screen-oriented interface on a character terminal, so you can use forms, from any menu and sometimes even a mouse to configure some basic Linux features from any (no X-based GUI required).
