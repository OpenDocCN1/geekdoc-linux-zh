The DVD that comes with this book contains CD images of OpenSUSE Linux 10.0. You can run those images to CD as described in Appendix A and install them as described later in this chapter.

Like Red Hat, SUSE is an excellent first Linux for people who work from a graphical desktop rather than from the command line. Novell's product line is geared toward enterprise computing, the skills you gain using SUSE on your home Linux system will be useful in a business environment.

SUSE has a slick graphical installer that leads you through installation and intuitive administrative tools, consolidated under a facility called YaST. SUSE and its parent company Novell offers a range of Linux products and support plans that scale up to enterprise computing, as well as free, binary versions of SUSE that can be used with limited.

In 2005, Novell refused its development efforts to do as Red Hat does with its Red Enterprise Linux product and Fedora project: Novell formed the OpenSUSE project, like the Fedora project, produces a free community-driven Linux system that feeds into Novell's for-profit Linux systems. Unlike Fedora and RHEL, however, OpenSUSE and SUSE are, so far, following the same release numbers. They are differentiated by the fact that OpenSUSE offers no official Novell support and SUSE may contain some non-open source software.
