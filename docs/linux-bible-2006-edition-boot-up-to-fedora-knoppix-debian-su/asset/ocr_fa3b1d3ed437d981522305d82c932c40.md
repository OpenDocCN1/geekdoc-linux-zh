+   4. Provide a hostname (a single-word name that you give to your system, as *debian*, *lebiteigobox*, or *yoda*) and a domain name. If you do not have your own domain name, you can make one up, as *myhouse.local*.

+   5. You will next be asked to configure your partitions for Debian. If you haven't done so, read Chapter 7 for more information about partitioning.

If you have partitions on your drive and room for more, you are given the option to use this space for your Debian system. Another option is to erase the entire disk and use the whole thing for Debian. Either of these two options takes you through the guided partitioning, which is covered in this section.

A third option, manually editing the partition, enables you to be more exact about your partition setup, but you should not try this without at least reading Chapter 7.

The guided partitioning section presents three partitioning schemes. Each of the options includes a suitable amount of swap space but has different benefits based on your situation. You must select one from the list before you proceed. See "Selecting a Partition Scheme" sidebar for more information.

> When installing to small drives (under a few gigabytes in size), you should use ext file systems instead of ext3. The journaling in ext3 requires that a portion of the disk be set aside for the journal, but the feature is of limited usefulness on small file systems. You can change file system types by going into the partition properties. To do this, highlight the arrow keys and press Enter.

The next step will modify the contents of your hard disk. Check your partition settings before proceeding.

+   6. With your partition configuration complete, select Finishing Partition and Write Changes to Disk. This is your last chance to cancel changes that could cause damage to any other operating systems you may have on the disk, so check the screen before proceeding!

The installer writes the partitions to disk and creates the necessary file systems. After they have been prepared and mounted, the Debian base system is extracted from the CD and installed into the target partitions.

+   7. The final step is to install GRUB, the boot loader. The default setting is to install the master boot record (MBR), which is generally the best option. Accept the defaults and continue. The installer extracts the CD and prompts you to proceed with stage 2.

+   8. Remove the CD and press Enter to continue.
