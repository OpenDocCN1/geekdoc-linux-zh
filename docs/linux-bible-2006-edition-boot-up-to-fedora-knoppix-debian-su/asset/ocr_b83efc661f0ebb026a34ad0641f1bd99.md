Table 6-3 describes each of the netstat parameters used here.

# Table 6-3
netstat Parameters

| Parameter | Description |
| --- | --- |
| -t, --tcp | Show TCP socket connections |
| -u, --udp | Show UDP socket connections |
| -p, --program | Show the PID and name of the program to which each socket belongs |
| -n, --numeric | Show numerical address instead of trying to determine symbolic host, port, or user names. |

The output is organized into columns defined as:

+   * Protocol—used by the socket.
* Recv-Q—the number of bytes not copied by the user program attached to this socket.
* Send-Q—the number of bytes not acknowledged by the host.
* Local Address—Address and port number of the local end of the socket.
* Foreign Address—Address and port number of the remote end of the socket.
