## Begin the DrakX Installation

You have a PC that can handle Mandriva, and you have your installation CDs; it is time to begin. Installation time varies based on how fast your hardware is and how big a partition you choose to resize. On a system with a PII800, 512MB of RAM, 30GB IDE hard disk, 40X CD-ROM, and an existing NTFS partition with Microsoft Windows (2000 Server SP4), the installation takes approximately 30 to 40 minutes. Here's what to do:

- 1. Back up all your virtual information.
- 2. With all your CDs ready to go (from the retail box set or your downloaded images), insert CD and start your computer. If the BIOS didn't catch the CD and boot from it, press Ctrl+Alt+Delete to restart. If it does not boot to the DrakX installation, make sure that your BIOS is configured to boot the CD first, and then restart.

If you don't see the installation screen, your CD-ROM drive may not be bootable. You may be able to make the drive bootable, Here's how: Restart the computer, immediately when you see a message to go into setup, by pressing the F1, F2, or Del key. Enter and look for an option as Boot Options or Boot From. If the value is A: First, Then C:, change it to CD-ROM First, Then C: or something similar. Save the changes and try to install again.

- 6. Setting your security level is critical if you plan to use your installation to provide services to other computers. This screen presents four security options from which you can choose a security level:

- **Standard** — Designed for a typical desktop client that will connect to the Internet.
- **High** — Implements some access restrictions and performs daily checks of the system for signs of unwanted activity.
- **Higher** — Enough security to reasonably allow inbound server services (Web, FTP, and so) on your server.
- **Paranoid** — “Lock down.” The maximum local security available, this allows you to tighten everything and open ports and access as you see fit. Not for the faint of heart.

**Erase** — Wipes the existing hard disk in preparation for your install. This is a great option for critical server systems or if there is no data on the disk you need.

**Use free space on Microsoft Windows partition** — Exactly what it sounds like. You can use free disk space on the FAT, FAT32, or NTFS partition that houses your Windows installation to house your Mandriva install. Pretty nifty if you want both systems to be able to access all of the files on the system.

**Custom** — Here’s where the real magic happens: You can create custom volumes, resizing volumes, and in general torture your hard drives as much as you like.

Selecting the Custom option opens a new window that shows all the hard drives and configured partitions. If your system has only an Windows installation on an NTFS partition, all that will be visible the markers indicating a Mandriva partition.

Once you click on the partition that you want to use for your Mandriva installation, a new option appears in the left portion of the configuration window. By clicking the Resize button, you can change the size (with limitations) of the existing NTFS partition.

Give it a shot if you have the opportunity. Click the Resize button, and a new window appears. It has a slider that goes all the way to the right by default. As you slide the slider to the left, the corresponding value displayed gets smaller. This number the NTFS partition will be after you’ve completed the resizing operation. For example, if you have a 30GB partition and want to free up 10GB of space for the creation of native Linux partitions, simply slide the slider from the maximum value of 30000MB to 20000MB, and you will have freed 10000MB.

The amount of space you can create depends on the size of the disk, how much data is stored, and whether the partition has been defragmented. To find out the degree you can resize the partition, move the slider to the left. That displays the smallest size you can make the existing Mandriva partition.

There is a catch to resizing partitions. The 2.6 Linux kernel misreports hard disk geometries, and the incorrect information can cause a flawed partition to be written to the end of the resize. See www.mlf.linux.org/efaz/ntfsresize.html#troubleshoot for more details.

When you’ve selected the size you want, click the Next button. You are shown a warning to make sure you have backed up any information you depend on before performing the partitioning resizing. If you’re ready to commit, click OK.
