# Filtering Mail and Catching Spam

Mozilla Mail can do more than just place them in your Inbox. You can set up filters to check each message and then have Mozilla Mail take an action when a message matches the rule you set up.

For example, you can filter a rule that checks the subject, sender, text body, date, recipients, or age in days of the message for a particular word, name, or date, as appropriate. If there is a match, you have Mozilla Mail put that message in a particular folder, label it with a selected phrase, change its priority, or set its junk mail status. You can add as many rules as you like. For example, you:

+   - Have all messages sent from a particular address sorted into a separate mail folder. For example, I do so that important mail doesn't get lost when there's a lot of activity on the mailing lists to which I subscribe.

+   - Have incoming messages from people or places that are being mistakenly marked as spam change junk status to Not Junk

To set up filters in Mozilla Mail, click Tools ✦ Message Filters. The Message Filters pop-up appears. If you have multiple mail accounts, select the account you want to filter. Click New. From the Filters pop-up window, choose the following:

+   - For incoming messages—that are different ways to check parts of a message. For example, you can check whether the Sender is in the address body. You can check whether the Priority is: low, medium, or high. You can create multiple rules for a filter (click More to add another rule), and then choose if you want to match all or any of the rules to continue to the action.
