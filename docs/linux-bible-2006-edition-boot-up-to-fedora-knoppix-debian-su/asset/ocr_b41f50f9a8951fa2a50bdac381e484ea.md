# Summary

You have a lot of high-quality applications available to fulfill your needs for a Web browser and e-mail client in Linux. Most Web browsers are based on the Mozilla gecko engine (which came originally from Netscape Navigator). Firefox is being slated as the next generation replacement for Mozilla Navigator. The combination of security, ease-of-use features, and extensions has made Firefox an extremely popular Web browser for both Linux and Windows users.

Graphical and text-based e-mail clients include Ximian Evolution, Mozilla Mail, and KMail. Thunderbird is set to become the next generation e-mail client to replace Mozilla Mail.
