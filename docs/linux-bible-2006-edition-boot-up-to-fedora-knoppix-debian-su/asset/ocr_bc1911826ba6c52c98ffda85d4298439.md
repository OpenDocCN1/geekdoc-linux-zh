YaST has some useful tools in its Hardware section that enable you to probe your computer hardware.

On my system, for example, I could see that the CD-ROM drive that YaST detected was available through device /dev/hdc and that it supported CD-R, CD-RW, and DVD media. I could also see detailed information about my CPU, network card, PCI devices, sound card, and various storage media.

YaST offers interfaces for configuring and starting network devices, as well as a variety of services to run on those devices. In addition, you can use YaST to configure your computer as a client for file sharing (Samba and NFS), e-mail (sendmail), and a variety of network services.

SUSE Linux Enterprise Server comes with a wider range of configuration tools that are specifically geared toward server setup, including tools for configuring a mail server, VPN tunnels, and full Samba 3.

# Using the root login

Every Linux system starts out with at least one administrative user account (the root user) and one or more regular user accounts (given a name that you choose, or a name assigned by Linux). In most cases, you log in as a regular user and become the root user to do an administrative task.

The root user has complete control of the operation of your Linux system. You can open any file or run any program. The root user also install software packages and accounts for others who use the system.

When you first install Linux systems, you add a password for the root user. You must remember and protect this password—you will need it to log in as root or obtain root permission while you are logged in as some other user. Other systems (such as KNOPIXX) start with a blank root password, so you might want to add one when you first start by typing the following from a Terminal window or shell:

```
# password root
Changing password for user root.
New UNIX password: ********
Retype UNIX password: ********
```

Some Linux distributions give you (as a regular user) the power to run commands as root. You simply have to ask for the privilege using the sudo command. For example, from a Terminal window, to open a shell as root, type the following:

```
$ sudo su -
#
```

You'll find out more about the sudo command later in this chapter.
