# Chapter 14 Running Slack Linux

15. Make a boot disk. If you have a floppy drive, make a boot disk. It will enable you to reboot your computer if your hard disk ever becomes unbootable. You don't have a floppy drive, you can use the Slackware install CD as a boot disk in an emergency.

16. Configure modem. Select No Modem if you don't plan to use a modem with your computer. If you have an external, serial modem, choose the COM port it is connected to (represented by /dev/tty?, COM1 associated with ttyS0). For PCI modems (slots directly in the motherboard), device names usually begin at /dev/ttyS4.

17. Enable hotplug subsystem. Select Yes to enable the hotplug subsystem at boot time. Lets Slackware try to activate devices that are plugged into the computer while it is running (such as Card and USB devices). By enabling the system at boot, it can also detect other hardware, including PCI cards.

18. Install LILO boot loader. Choose Simple to have the setup process try to automatically install the LILO boot loader, or Expert if you want to configure the boot loader to something else. If you want to add kernel parameters and set framebuffer console features, you can use either method, but certain tasks require Expert mode:

+   - Adding other bootable Linux partitions
- Adding a bootable Windows partition
- Installing an existing.conf file, instead of creating a new one

You can have graphics on the boot screen by enabling the frame buffer console. Choose the resolution and number of colors (such as 1024 × 768 × 256) to use with the frame buffer console.

When prompted, add any parameters you want to fed when you boot. In particular, you might add kernel parameters if you want to turn off autopdetect on certain devices (for example, nousb noacpi). Chapter 11 describes some kernel parameters that might be useful to you.

LILO is usually placed in the root of the Linux partition or in the master boot record for the hard disk. It is safest to put LILO in the super block (Root) of the Linux partition or on a formatted floppy disk. For the former, you need to indicate that the partition is booting (using the fdisk command when return to a shell prompt). It can unsafe to put LILO in the master boot record. However for a system on which only one operating system is installed (in this case, Slackware), the master boot record is a common place to put LILO.

19. Configure the mouse. Select the type of mouse connected to your system. You are also given the opportunity to configure gim, which lets you to select mouse, copy, and paste in virtual consoles (text windows).

20. Configure the network. Select Yes to configure your network (that is, your LAN connection from your Ethernet card). Refer to Chapter 7 for information on configuring your network connection.
