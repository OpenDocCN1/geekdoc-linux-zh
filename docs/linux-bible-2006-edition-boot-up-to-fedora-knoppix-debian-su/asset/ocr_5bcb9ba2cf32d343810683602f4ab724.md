# Examining Challenges with KNOOPPIX

For most people, KNOOPPIX is a special-use Linux system. It's a great way to try Linux or access a computer that isn't set up the way you like. However, there are a few challenges with using KNOOPPIX that you should keep in mind:

+   * Reboot each KNOOPPIX—Unless you save your data to some other media (which you can, as I describe later in this chapter), the entire KNOOPPIX system goes away when you reboot. This means files on the desktop, installed software, system configuration, and anything else you do during your KNOOPPIX session will be gone unless you explicitly save that information to a hard disk or remove removable media (floppy, CD, and so on).

+   * Memory limitations—KNOOPPIX is made to be able to run without your hard disk, when you save files to KNOOPPIX, they are (by default) stored in your computer's memory (RAM). On my desktop system, which has 512MB of RAM, KNOOPPIX assigned about 3MB to the root (/) partition and 396MB to ramdisk (to provide space in the /var andhome directories, where data is normally stored). So there is only 100MB left to hold all the running applications.

+   * Performance hits—Even with today's CD and DVD drives, it's still slower getting data from CDs and DVDs than it is getting them from a local hard disk. Almost every component needed to run KNOOPPIX (commands, libraries, and so on) is grabbed from the CD or DVD and decompressed onthe fly. So would have to run them commands from hard disk. Watch the blinking light on your CD or DVD drive to see if it is going there to get data.

+   * Uses your CD/DVD drive—Because KNOOPPIX relies heavily on data from the CD or DVD, you cannot remove it while you are using the system. So, if you have only one drive for removable media, you can't use it to access a music CD, install from another software disk, or burn data while you are using KNOOPPIX.

If you have more than 1GB of RAM on your computer, you can use the boot option to KNOOPPIX. This will not only allow you to remove the KNOOPPIX disk, since everything is running from RAM, but will also cause KNOOPPIX to run faster than a Linux installed on a hard disk would run.

I must admit that the challenges described here are more of an explanation of how KNOOPPIX works than they are problems with KNOOPPIX itself. The idea that you can run a full-blown desktop and server operating system from a CD (with nearly 2GB of available applications) is an awesome concept for someone who remembers DOS and character terminals.
