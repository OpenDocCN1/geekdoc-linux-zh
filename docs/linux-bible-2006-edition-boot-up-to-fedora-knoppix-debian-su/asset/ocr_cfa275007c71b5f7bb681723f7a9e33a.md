# 568 Part IV Running Applications

To start your first document, I recommend that you select one of the templates provided in `/usr/share/lyx/templates` which come with LyX. To open a template, click File->New from Template. A list of available templates appears. You can use them to create letters, slides, and articles, for example.

Besides offering standard editing functions, such as cut, copy, and the paste, the Layout menu enables you to perform a variety of markup functions. As for mathematical functions, the Math menu enables you to insert fractions, square root, exponent, and integral functions into your document. When you are done, one:

+   * Print the file to a PostScript printer or output a PostScript (.ps) file. (Click File-> select the method, and then click OK).
* Export the file to LaTeX, DVI, PostScript, or ASCII Text. (Click File-> Export and choose from the list of formats).

LyX calls it WYSIWYM editor—What You Say Is What You Mean. As a result, what you see on the screen is not exactly as the printed document will look. For example, no extra white space appears between lines by pressing Enter multiple times.

Because LyX supports styles file, it enables you to create documents that meet different standards. For example, LyX supports typesetting for the American Mathematics Society (AMS) journals using the article text class. Other classes supported:

+   * article—One-sided paper with no chapters.
* report—Two-sided report that tends to be longer than an article.
* book—Same as report, with additional front and back matter.
* slides—For producing transparencies.
* letter—Includes special features for addresses, signatures, and elements.

# Printing LaTeX Files

Whether you create your LaTeX file, export from the LyX LaTeX editor, or download one from the Internet, several utilities are available to print, or display the output. Here are some of your choices:

+   * To format a LaTeX file (filename.tex), run the following command:
  $ latex filename.tex
* To print a DVI file (filename.dvi), send it to your default PostScript printer, and type the following:
  $ dvips filename.dvi
