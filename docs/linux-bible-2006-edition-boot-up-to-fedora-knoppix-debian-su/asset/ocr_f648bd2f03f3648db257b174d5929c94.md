This chapter focuses on partitions that are used for the Linux file system. To see what partitions are currently set up on your hard disk, use the fdisk command:

```
# /sbin/fdisk -l
```

```
Disk /dev/hda: 40.0 GB 4002066432 bytes
255 heads, 66 sectors/track, 4825 cylinders
Units = cylinders of 16065 * 512 bytes = 8225280 bytes
Device Boot Start  End Blocks Id System
/dev/hda1 *      1    13 104  b Win95 FAT32
/dev/hda2         84    89 48195 83 Linux
/dev/hda3        90   522 347082+ 83 Linux
/dev/hda4        523   554 257040  5 Extended
/dev/hda5        523   554 257008+ 82 Linux swap
```

This output shows the partition for a computer running both Linux and Microsoft Windows. You can see that the Linux partition on /dev/hda3 and a Linux swap partition (/dev/hda5). There is also a small /boot partition (46MB) on /dev/hda2. In this case, the root partition for Linux is 3.3GB of space and resides on /dev/hda3.

Next use the mount command (with no options) to see what partitions are actually being used for your Linux system (which available partitions are actually mounted and where they are mounted):

```
# mount
/dev/hda3 / ext3 (rw)
/dev/hda2 /boot type ext3 (rw)
/dev/hda1 on /mnt/win type vfat (rw)
/dev/proc on /proc type proc (rw)
/dev/sys /sys type sysfs (rw)
/dev/devpts on /dev/pts devpts (rw,gid=5,mode=620)
/dev/shm on /dev/shm type tmpfs (rw)
none on /proc/sys/fs/binfmt_misc binfmt_misc (rw)
/dev/hdc on /media/cdrecorder type iso9660 (ro,noisid,nodev)
```

Although some of the file systems shown as mounted are for special purposes (/sys,/proc, and others.), our concern is here with partition (/dev/hda*, /dev/sd*). The mounted partitions in this case are /dev/hda2, which provides space for the /boot directory (data booting for Linux), and /dev/hda3, which provides space for the rest of the Linux file system beginning from the root directory/).

This particular system also contains a Windows partition that was mounted in the /mnt/win directory and a CD that was mounted in /media/cdrecorder. (With most GUI interfaces, the CD is typically mounted automatically when you insert it.
