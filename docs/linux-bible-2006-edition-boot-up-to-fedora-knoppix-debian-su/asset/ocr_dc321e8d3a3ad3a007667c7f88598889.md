# Chapter 3 Getting into the Desktop

GNOME login manager — The GNOME display manager (gdm) comes with a Login Setup utility (from the desktop run the gdmconfig command as root user). From the Login Setup window, you can select the Graphical Greeter tab and choose a different theme for the login manager. On the Security tab, you may notice that all TCP connections to the X server are allowed. Don't change this selection, because no processes other than those handled directly by your display manager should be allowed to connect to the login screen.

After your login and password have been accepted, the desktop environment configured for your user account starts up. Users can modify their desktop environments to suit their tastes (even to the point of changing the entire desktop environment).

# Boot to a Text Prompt

Instead of a graphical screen with pictures and colors, you might see a login prompt that looks like this:

> Welcome to XYZ Linuxnyourcomputer login:

This is the way UNIX and Linux systems used to appear on the screen when they were booted up. Now this login prompt is typical for a system that is installed as a server or, for some reason, was configured not to start an X display manager for you to log in. Run level 3 boots to a plain-text login prompt in multiuser mode.

Just because you have a text prompt doesn't necessarily mean you can start a desktop environment. Many Linux experts boot to a text prompt because they want to use the GUI occasionally. However, if X and the necessary desktop components are installed on your computer, you can typically start the desktop after log in by typing the following command:

+   * startx

The default desktop environment starts up, and you should be ready to go. What you need depends on whether you have a KDE, GNOME, or some sort of homespun environment.

In most cases, the GUI configuration you set up during installation for your video card and monitor gets you to a working desktop environment. If for some reason the screen is unusable the “Configuring Your Own Desktop” section later in this chapter describes some tools you can use to get your working desktop.
