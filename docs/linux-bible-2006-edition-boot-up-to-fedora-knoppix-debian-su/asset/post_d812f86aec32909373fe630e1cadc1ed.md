The PIC macros (.PS and .PE) let you create simple diagrams and flow charts to use in Groff. PIC is really qualified to create only simple boxes, circles, ellipses, lines, arcs, splines, and some text. The following is some PIC code that could be in a Groff document:

```
.PS
box "Start" "Here"; arrow
box "Step 1"; arrow
circle "Step 2"; arrow
ellipse "Step 3"; arrow
box "Step 4"; arrow
box "End"
.PE
```

The first line after the .PS includes an invisible box (invis) that contains the words Start Here, followed by an arrow. This connects to the next box, containing the Step 1. The next elements (connected by arrows) are a circle (Step 2), an ellipse (Step 3), another box (Step 4), and another invisible box (End). The .PE indicates the end of the pic drawing.

If these lines appear in a document called memopic.mm, you can preprocess the PIC code and print the file using the following command:

```
$ groff -Tps -l -mm -p memopic.mm
```

## Text Processing with TeX/LaTeX

TeX (pronounced *tech*) is a collection of commands used primarily to produce scientific and mathematical typeset documents. The most common way to use TeX is by calling a macro package. The most popular macro package for TeX is LaTeX, which takes a higher-level approach to formatting TeX documents. TeX and LaTeX tools are contained in the tex-latex package.

## 566 Part IV Running Applications

TeX interprets the LaTeX macros from the LaTeX format file (latex.fmt). By default, the latex.fmt and plain.fmt format files are the only ones that are automatically built when the TeX package is installed. Other macro files that you can use with TeX include:

- **amtex**— Mathematical publications, including the American Mathematical Society, use this as their official typesetting system.
- **epain**— Includes macros for indexing and table of contents.
- **texinfo**— Macros used by the Free Software Foundation to produce software manuals. Text output from these macros can be used with the info command.

You can create a TeX/LaTeX file using any text editor. After the text and macros are created, you can run the tex command (or one of several related utilities) to format the file. The input file is in the form filename.tex. The output is generally three different files:

- **filename.dvi**—Device-independent output which can be translated for several different types of output devices (such as PostScript).
- **filename.aux**— An auxiliary file used by LaTeX.

The .dvi file can be formatted for a particular device. For example, you can use the dvips command to output the resulting .dvi file to your PostScript printer (dvips filename.dvi). Or you can use the xvi command to preview the .dvi file in X.

## Creating and Formatting a LaTeX Document

Because LaTeX is the most common way of using TeX, this section describes how to create and format a LaTeX document. A LaTeX macro (often referred to as a command) appears in a document in one of the following ways:

- **\[required]**— a backslash (\ followed by a command. (Replace with the name of the command). Optional arguments are contained in brackets ([]), and required arguments are contained in brackets ([]).
- **?[required]**— a backslash (?) followed by a single character (not a letter) command. (Replace ? with the command character). Optional arguments are contained in braces ({}), and required arguments are contained in brackets ([]).

Each command defines some action to be taken. The action can control page layout, the font used, spacing, paragraph layout, or a variety of other actions on the document.

The minimum amount of formatting that a LaTeX document can contain is the following:

```
\documentclass{name}
\begin{document}
TEXT GOES HERE!
\end{document}
```

Replace [name] with the class of document you are creating. The text for the file, along with your formatting commands, goes between the begin and end document commands.

## Printing Files

Whether you create a LaTeX file (.tex) or a DVI file, several utilities are available to print. To print a LaTeX file (.tex), run the following:

```
$ latex filename.tex
```

To print a DVI file (.dvi), send it to your default PostScript printer:

```
$ dvips filename.dvi own```

To view a DVI file on your screen, use:

```
$ xvi filename.dvi
```

## WYSIWYG (What You See Is What You Get)

WYSIWYG stands for "What You See Is What You Get." This means that what you see on the screen is exactly what you will get when printed. LyX is a WYSIWYG editor for LaTeX. LaTeX itself is not a WYSIWYG editor, because you write code and then compile it to see the output. In LyX, you type and format your document, and LyX generates the LaTeX code for you.

## What is LyX?

LyX is a WYSIWYG editor for LaTeX. It allows you to write documents without worrying about the underlying code. It uses a graphical interface that is similar to a word processor. This makes it much more accessible for beginners who find LaTeX intimidating. However, you can still see and edit the generated LaTeX code if you want.

## Creating a Document in LyX

To create a new document:

1.  Click **File** > **New**.
2.  Select the document type (e.g., Article, Report, Book).
3.  Click **OK**.

Now you have a blank document. You can start typing. To format text, use the toolbar at the top. To insert elements like tables or images, use the **Insert** menu.

## Inserting Tables and Images

To insert an element:

1.  Click **Insert**.
2.  Select the type of element you want to insert (e.g., Table, Image, Equation).
3.  Follow the prompts to configure the element.

To insert a table:

1.  Click **Insert** > **Table**.
2.  Choose the number of rows and columns.
3.  Click **OK**.

To insert an image:

1.  Click **Insert** > **Image**.
2.  Select the image file from your computer.
3.  Click **OK**.
