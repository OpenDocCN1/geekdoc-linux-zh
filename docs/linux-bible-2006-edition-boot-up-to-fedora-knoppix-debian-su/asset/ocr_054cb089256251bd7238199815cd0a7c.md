# Checking Directories and Permissions

Associated with each shell is a location in the Linux file system known as the cur- or working directory. Each user has a directory that is identified as the user's home directory. When you first log in to Linux, you begin with your home directory as the current directory.

When you want to open or save a file, your shell uses the current directory as the point of reference. Simply provide a filename when you save a file, and it is placed in the current directory (relative path). Alternatively, you can identify a file by its relation to the current directory (relative path), or you can ignore the current directory and identify a file by the full directory hierarchy that locates (absolute path). The structure and use of the file system is described in detail later in this chapter.

To find out your current directory is, type the *pwd* command:

```
$pwd
/usr/bin
```

In this example, the current/working directory is /usr/bin. To find the name of your home directory, use the echo command, followed by the $HOME variable:

```
$ echo $HOME
/home/chris
```

Here the home directory is /home/chris. To get back to your home directory, just type the change directory (cd) command. (Although *cd* followed by a directory name changes the current directory to the directory you choose, typing *cd* with no directory name takes you to your home directory):

```
$ cd
```

> Note Instead of typing $HOME, you can use the tilde (~) to refer to your home directory. So, to return to your home directory, you could simply type: cd ~

To list the contents of your home directory, either use the full path to your home directory, or the ls command without a directory name. Using the -a option enables you to see the hidden files (dot files) as well as all other files. With the -l option you can see a long, detailed list of each file. (You can combine multiple single-letter options after a single dash, for example, -la).

```
$ ls -la /home/chris
total 158
dr-xr-x 2 chris 4096 May 12 13:55
-rw-r--r-- 1 root 4096 May 10 01:49 -
-rw-r--r-- 1 chris 2204 May 18 21:30 .bash_history
-rw-r--r-- 1 chris 24 May 10 01:50 .bash_logout
-rw-r--r-- 1 chris 230 May 10 01:50 .bash_profile
-rw-r--r-- 1 chris 124 May 10 01:50 .bashrc
```
