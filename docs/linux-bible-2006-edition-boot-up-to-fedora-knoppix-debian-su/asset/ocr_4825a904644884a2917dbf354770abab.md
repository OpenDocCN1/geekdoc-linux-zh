The output shows the disk space used in each directory under the home directory of the user jake (/home/jake). Disk space consumed is shown in kilobytes (k) and megabytes (M). The total space consumed by /home/jake is shown on the last line.

# Finding Disk Consumption with find

The find command is a great way to find file consumption of your hard disk using a variety of criteria. You can get a good idea of where disk space can be recovered by finding files that are over a certain size or were created by a particular person.

You must be root to run this command effectively, unless you are just checking your personal files. If you are not root, there will be many places in the file system that you will not have permission to check. Regular users can usually check their home directories but not those of others.

In the following example, the find command searches the root file system (/) any files owned by the user name jake (-user jake) and prints the filenames. The output of the find command is organized in size order (ls -lds). Finally, that output is sent to the file /tmp/jake. When you view the file /tmp/jake (for example, less /tmp/jake), you will find all of the files that are owned by the user jake listed in size here. This is the command line:

```
# find / -user jake -print -xdev | xargs -ls -dS > /tmp/jake
```

```
-xdev options prevents systems other than the selected file system from being searched. This is a good way to cut out a lot of junk that may output from the /proc file system. It can also keep large remotely mounted file systems from being searched.
```

Here's another example, except that instead of looking for a user's files, we're looking for files larger than 100 kilobytes (-size 100k):

```
# find / -size 100k -print -xdev | xargs -ls -dS > /tmp/jake
```

You can save yourself a lot of disk space by removing some of the largest files that are no longer needed. In this example, you can see large files sorted by size in the /tmp/size file.
