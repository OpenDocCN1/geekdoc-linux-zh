# Freecivic

Freecivic is a free clone of the popular Civilization game series from Atari. With Freecivic, you create a civilization that challenges competing civilizations for world dominance.

> Note A commercial port for Linux (Civilization: Call to Power) was created a few years ago by Loki Games (described later in this chapter).

The commonly distributed version of Freeciv contains both client software (to play the game) and server software (to connect players). You can connect to your server and play it yourself (with a network connection) play against up to 14 other players on the Internet. To install Freecivic, check out the download page on the www.freeciv.org Web site. Choose your language, start downloading, install, and have fun.

You can start Freecivic from a Terminal window by typing:

```
$ civilent &
```
