# # The Nautilus File Manager

At one time, file managers did more than let run applications, create data files, and open folders. These days, as the information a user needs expands beyond the local system, file managers are expected to display web pages, access FTP sites, and play multimedia content. The Nautilus file manager, which is the default GNOME file manager, is an example of just such a file manager.

When you open the Nautilus file manager (from the GNOME main menu or by opening the Home icon or folder on your desktop), you see the name of the location you are viewing (such as the folder name) and what location contains (files, folders, and applications). Figure 3-1 is an example of the file manager window displaying the home directory of a user named chris (`home/chris`).

In GNOME 2.10, the default Nautilus has been simplified to show fewer controls and provide more space for file and directory icons. Double-click a folder to open in a new window. Select your folder name in the lower-left corner of the window to see the file hierarchy around the current folder (as shown in Figure 3-11). GNOME remembers whatever size, location, and other thing you had for the folder last time you closed it and returns to that state next time you open.

To see more, right-click a folder and select Browse Folder to open it. Icons on the toolbar of the Nautilus window let you move forward and back among the directories and visit sites. To move to the view of the folder or Web page, click the Reload button. The Home button takes you to your home page, and the Computer button lets you see the same type of information you would see from a My Computer icon on a Windows system (CD drive. Floppy drive, hard disk file systems, and network folders).
