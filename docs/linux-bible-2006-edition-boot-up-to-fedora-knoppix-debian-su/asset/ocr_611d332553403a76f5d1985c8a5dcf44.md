4. From the output, look for an indication that the new disk was found. For example, if it's a second IDE disk, you should see hdb: in the output. For a second SCSI disk, you should see sdb: instead. Be sure you identify the correct disk, or you will erase all the data from disks you probably want to keep!

5. Use the fdisk command to create partitions on the new disk. For example, if you are formatting the second IDE disk (hdb), you can type the following:

```
# fdisk /dev/hdb
```

Now you are in fdisk command mode, where you can use the fdisk singleletter command set to work with your partitions. If the disk had existing partitions on, you can change or delete those partitions now. Or, you can simply reformat the whole disk to blow away everything. Use p to view all partitions and d to delete a partition.

6. To create a new partition, type the following:

```
n
```

```
p
```

8. Type in the partition number. If you are creating the first partition (or for only partition), type the number one:

```
1
```

Enter the first cylinder number (1 is the default). A range of cylinder numbers is displayed (for example, 1-4865 is the number of cylinders that appears for my 40GB hard drive).

9. To assign the new partition to begin on the new hard disk, type the number 1.

10. Enter the cylinder number. If you are using the entire hard disk, use the last cylinder number or indicate how many megabytes the partition should have.

11. To create more partitions on the hard disk, repeat Steps 6 through 10 for each partition.

12. Type w to write changes to the hard disk and exit from the fdisk command. At this point, you will be back at the shell.

13. To create a file system on the new partition, use the mkfs command. By default, this creates an ext2 file system, which is usual by Linux. In most cases you will want to use a journaling file system (such as ext3 or refs). To create an ext3 file system on the first partition of the hard disk, type the following:

```
# mkfs -t ext3 /dev/hdb1
```

If you created multiple partitions, repeat this step for each partition (such as /dev/hdb2, /dev/hdb3, and so on).
