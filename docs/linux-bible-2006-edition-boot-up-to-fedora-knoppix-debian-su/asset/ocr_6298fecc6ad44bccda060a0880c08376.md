# # Exiting GNOME

When you are done with your work, you can either log out from your current session or shut down your computer completely. To exit from GNOME, do the following:

+   1. Click the Desktop menu button.
2. Select the Log Out from the menu. A pop-up window appears, asking if you want to Log Out. Some versions will also ask you if you want to Shut Down or Restart the computer.
   At this point, you can also choose to save your session by clicking Save Current Setup. This is a great way to have the applications that you use all the time you restart the next time you log in. Make sure you save your data before you exit, however. Most applications do not support the data-saving feature.
3. Select OK from the pop-up menu. This logs you out and returns you to either the graphical login screen or your shell login prompt. (If you select Shut Down, the system shuts down, and if you select Reboot, the system restarts.)
4. Select OK to finish exiting from GNOME.
