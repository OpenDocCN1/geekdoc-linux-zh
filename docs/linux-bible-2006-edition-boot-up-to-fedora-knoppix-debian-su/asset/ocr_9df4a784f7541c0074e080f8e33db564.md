Linspire, the default option, boots into the Linspire operating system; you can select it or just wait for Linspire to load. Unless you have installed hardware since the time you started Linspire or you are having some serious startup issues, always select the default option to launch Linspire.

Redect identifies installed hardware, which is useful if you have added new items from your last installation. This is roughly equivalent to the plug-and-play functionality most Windows users enjoy.

Diagnostics is an option used when you are experiencing some kind of server system issues, such as failed or improperly configured hardware. A results of the detection and diagnosis are displayed. This screen can be very intimidating and difficult to interpret if you are not familiar with the Linspire startup process.

Select Linspire and the operating system finishes loading.

The First Time Setup window provides a button for setting the system time, a check box for agreeing to the Linspire license agreement, and an Advanced button that allows you to set or change the administrator (root) password; set the desktop (display) resolution that you prefer and that hardware supports; invoke the Linspire tool User Manager, with which you can create users, assign them capabilities, and delete them as needed. You also get opportunity to rename your PC. You set the computer name and administrator password during startup, so there is likely not to be a reason to change them here, but you if you like.

With Linspire installed, with the exception of the few special Linspire applications (mostly associated with playing multimedia content and getting help), Linspire behaves like most KDE desktop systems, so you can learn how to get around the Linspire desktop using descriptions from Chapter 3.

# Linspire

Linspire may not excite the battle-hardened Linux-using community, but it serves as a positive example of a user-oriented Linux system. Linspire is by far the most accessible version of Linux for new users. With a computer that has supported hardware, anyone can install Linspire and get up and running with new applications, Web surfing, and e-mail in a couple of hours.

The Click-Run application takes ease of installation to a new level, making Linspire hopeful proof of the concept that a desktop version of Linux can succeed in the home and office. The installation walk-through at the end of the chapter demonstrates that there are some trade-offs for this ease of use.
