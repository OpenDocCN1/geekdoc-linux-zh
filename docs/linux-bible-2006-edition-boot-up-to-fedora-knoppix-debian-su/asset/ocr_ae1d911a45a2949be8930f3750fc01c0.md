8. The next screen gives you the option of selecting packages to install on your Linux system. Mandriva offers a set of general package groups that you can use to meet general configuration goals. These prefab package groups are:

Make sure you have selected the Higher or Paranoid security level if you plan to expose this to inbound connections from the Internet or other public network. If you fail to do so, increase your risk of unauthorized intrusion to your server and any other devices to which it has access.

+   * Workstation options — You can choose to install productivity, multimedia, and some more advanced user tools. Each subgroup is individually selectable. Productivity software (in the Office workstation group) is comprised of OpenOffice and a collection of time, financial, and document tools. Your entertainment options (in the Game Station and Multimedia Station groups) include multimedia applications and a set of arcade-style games. A number of network-related package groups (Network Computer and Internet Station groups) are available for Web browsers, e-mail clients, and network client (NFS) utilities.

For configuring your system, you have the option to install console tools (Console group) and graphical configuration (Configuration group) utilities. You should plan to use the computer for scientific analysis and study, you can install some applications by selecting the Scientific Workstation group. The Office Station, Multimedia, Internet Station, Configuration, and Console Tool groups are selected by default.

+   * Server options — Package groups for server services fall into Web/FTP, Mail, Database, Firewall/Router, and Network Computer Server groups. If you want to experiment with these services, feel free to check all the server boxes, and install all of them. If you already know which package you want to use (mail service, for example), install only the package you need.

+   * Other options — In addition to the server/workstation options, you can select the desktop environments that you would like installed (KDE, GNOME, Other). You can also elect to install comprehensive documentation and development applications. Also, if you need them for a development effort or testing, you can install the Linux Standard Base (LSB group)
