The touch command creates empty files. The next few commands show how you to use shell metacharacters with the ls command to match filenames. Try the following-commands to see if you can get the responses:

```
$ ls a*
apple
$ ls g*
grape
grapefruit
$ ls g*t
grapefruit
$ ls *e*
apple grape watermelon
$ ls *n*
ana watermelon
```

The first example matches any files that begins with an a (apple). The next example matches any files that begin with g (grape, grapefruit). Next, files beginning with g and ending in t are matched (grapefruit). Next, any file that contains an e in the name is matched (apple, grape, watermelon). Finally, any file that contains an n is matched (banana, watermelon).

Here are a few examples of pattern matching with the question mark (?):

```
$ ls ???e
apple grape
$ ls ???*
grape grapefruit
```

The first example matches any five-character file that ends in e (apple, grape). The second matches matches any file that begins with g and has e as its fifth character (grape, grapefruit).

Here are a couple of examples using brackets to pattern matching:

```
$ ls [abw]*
apple banana watermelon
$ ls [agw]*[ne]
apple watermelon
```

In the first example, any file beginning with a, b, or w also is matched. In the second, any file that begins with a, g, or w also ends with either n or e is matched. You can also include range within brackets. For example:

```
$ ls [a-g]*
apple banana grape grapefruit
```

Here, any filenames beginning with a letter from a through g is matched.
