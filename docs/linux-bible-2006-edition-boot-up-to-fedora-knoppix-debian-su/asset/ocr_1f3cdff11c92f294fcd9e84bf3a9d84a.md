# Resizing the Web Page

There is a nice keyboard shortcut that lets you quickly resize the text on most Web pages in Mozilla. Hold the Ctrl key and press the plus (+) or minus (-) keys. In most cases, text on the Web page gets larger or smaller, respectively. That page with the insanely small type font is suddenly readable.

# Using Text-Based Web Browsers

If you become a Linux administrator or power user, you will inevitably find yourself working on a computer from a remote location or where there is no desktop GUI. At some point while you are in that state, you will want to check an HTML file or a Web page. To solve the problem, many Linux distributions include several text-based browsers.

With text-based browsers, any HTML file from the Web, your local file system, or a computer where you are remotely located in can be accessed from your shell. There is no need to fire up a GUI or read pages of HTML markup if you want to take a peek at the contents of a Web page. In addition enabling you to call up Web pages, move around those pages, and follow links to other pages, some of browsers display graphics in a terminal window!

Which browser use is a matter of which you are comfortable with. Browsers that are available include:

+   - lyn — You can open a file or a URL, and then traverse links from the pages you open. Use search forward (/string) and back (?string) features to find text strings in pages. Use up and down arrows to go forward and back among pages. Press Enter to go to the current link. Use the right and left arrow keys to go forward and back among pages you have visited. Press Esc to see a menu of features which to select.

+   - lynx The lynx browser has a set of help files (? key). Go through pages using the spacebar. Although lynx can display pages containing frames, it cannot display them in the intended positioning. Use the arrow keys to display the selected link (right arrow), go back to the previous document (left arrow), select the previous link (up arrow), and select the next link (down arrow).

+   - w3m This browser can display HTML pages containing text, links, frames, and tables. It even tries to display images (although it is a bit shaky).
