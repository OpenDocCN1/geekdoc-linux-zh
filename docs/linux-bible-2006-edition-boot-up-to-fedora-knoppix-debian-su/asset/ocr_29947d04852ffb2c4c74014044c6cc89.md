# Samba Passwords Working?

Try accessing a shared Samba directory as a particular user (from the local host or
other Linux system on your LAN). You can use the smclient command to do this.
Here is an example:

```
# smclient //localhost/tmp -U chris
 interface ip=10.0.0.1 bcast=10.0.0.255
nmask=255.255.255.0
Password: ********
Domain=[ESTREET] OS=[Unix] Server=[Samba 2.2.7a]
smb:\
```

In this example, smclient connects to the shared directory name tmp as the
samba user named chris. If the password is accepted, you should see information
about the server and a smb\> prompt. If you cannot access the shared direc-
tory from a Windows client, it's possible that the client is using an improper
username and password. Of the problem may be that the Windows client is not
providing encrypted passwords.

For certain Windows clients, using encrypted passwords requires that you
a Windows registry for the machine. One way to change the registry is with the
Windows regedit command. Registry changes required for different Windows
systems are contained within the /usr/share/doc/samba-*/Registry
directory.

The smclient command, used here to list server information and test pass-
words, can also be used to browse the shared directory and copy files after you
after. Use the smb\> prompt, type help to see the available com-
mands. The interface is similar to any ftp client, such as sftp.
