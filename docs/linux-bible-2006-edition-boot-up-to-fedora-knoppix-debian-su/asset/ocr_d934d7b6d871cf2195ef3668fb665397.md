# Appendix A ◆ Media 823

+   - ubuntu-5.10-install-i386.iso: Contains the CD image to install a nicely stocked Ubuntu desktop system.

+   - systemrescuecd-x86-0.2.15.iso: Contains the System Rescue CD image. This bootable Linux CD can be used to help recover a damaged system or network.

+   - slackware-10.1-install-d2.iso: Represents the two Slack CDs contained on the DVD (replace with 1 or 2). The images can be used to install Slackware with a basic X desktop, server packages, and programming tools.

+   - SUSE-10.0-CD-i386-GM-?.iso: Represents the five-CD SUSE Linux 10.0 (replace the ? with a number from 1 to 5). You can use this CD to install a workable desktop SUSE and server Linux system with KDE desktop and a set of desktop applications.

+   4. Open a folder on your hard disk (as your home directory from a desktop icon) and browse or create a folder to copy the CD image to. (You'll need between 50MB and 700MB of hard disk space, depending on the disk image you choose.)

+   5. Drag-and-drop the image to your hard disk.

+   6. Close all files and shells that are open on the DVD or CD, and unmount and eject the media (right-click the DVD or CD icon and select Eject).

+   7. Open a CD/DVD burning application. For this procedure, I recommend K3B/DVD Burning Facility (http://www.k3b.org). In Fedora, select the Applications menu and choose Sound & Video K3b (or use k3b from a terminal). The K3B-CD Creator window appears.

+   8. From the K3B window, select Tools⮮CD⮮ Burn CD image. You are asked to choose an image file.

+   9. Browse to the image you just copied for hard disk and select. Once the image is selected, the Burn CD image appears and does a check on the image. (You can check the checksum number that appears against the number in the MDSSUM file on the DVD for this image, to be sure that the CD is not corrupted.) Figure A-1 shows the Burn CD image ready to read on an image of Damn Small Linux.

+   10. Insert a blank CD into the CD burner drive, which may be a combination with your drive. (If a CD/DVD Creator window pops up, you can just close it.)

+   11. Check the settings in the Burn CD image window (often the defaults are fine, but you may want to slow down the speed if you get some bad burns) and click Start.

+   12. When the CD is done burning, eject it (or it may eject automatically) and appropriately such as the distribution name, version number, and date).
