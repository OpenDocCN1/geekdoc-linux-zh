# 258 Part III ♦ Choosing and Installing a Linux Distribution

The following procedures are performed from the command line as root user.

Remember that any partition commands can easily erase your disk or make it inaccessible. Back up critical data before using any tool to change partitions! Then be very careful about the changes you make. Keeping an emergency boot disk handy is a good idea, too.

The fdisk command is that is available on many different operating systems (although it looks and behaves differently (each). In Linux, fdisk is a menu-based command. Use fdisk to list all your partitions, type the following (at root user):

```
# fdisk -l
Disk /dev/hda: 40.0 GB, 40020664320 bytes
255 heads, 63 sectors/track, 4865 cylinders
Units = cylinders of 16065 * 512 = 8225280
```

To see each partition is being used on your current system, type the following:

| Device Boot | Start | End | Blocks Id System |
| /dev/hda | | 1 | 13 | 104391 | 83 Linux |
| /dev/hda2 | | 14 | | 38716650 | 83 Linux |
| /dev/hda3 | | 4834 | | 257040 | 82 Linux swap |

From the output of df, you can see that the root of your Linux system (/) is on the /dev/hda2 partition and that the /dev/hda partition is used for /boot.

```
# df -h
Filesystem Used Avail Mounted on |
/dev/hda2 | 37G | 5.4G | 30G | 16% / |
/dev/hda1 | 99M | 8.6M | 86M | /boot |
none | 61M | | 61% | /dev/sh |
```

If this had a dual-boot system (with Windows 98), you might have seen a Windows partition from fdisk that looked like this:

```
/dev/hda1 * | 83 | 66666+ | b Win95 FAT32
```

You could mount partition in Linux (to get to your Windows files when it is booting):

```
# mkdir /mnt/win
# mount vfat /dev/hda1 /mnt/win
```

Before using fdisk to change your partitions, I strongly recommend using the df -h command to see how your partitions are being defined. This will help reduce the risk of changing or deleting the partition.
