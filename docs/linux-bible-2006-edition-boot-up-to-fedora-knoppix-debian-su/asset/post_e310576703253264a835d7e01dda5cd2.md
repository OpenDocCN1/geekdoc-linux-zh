# Running the Coyote Floppy

To start your firewall, simply insert the floppy disk into your computer and reboot. The firewall should come up as you configured it. There is no direct interface from the firewall's console onto it and running. In fact, you don't have to monitor the firewall because you won't see a login prompt. Any administration of the firewall should be done over your LAN. If you configured it, your firewall is now:

- Offering addresses to the computers on your LAN using DHCP.
- Launching a dial-up connection from your firewall to your ISP as soon as anyone from your LAN tries to access the Internet.
- Allowing traffic from your LAN to the Internet.
- Offering login (sshd) and Web administration service to you from your LAN.

If the firewall is not behaving as you would like it, go to the next section to further tune it.

# Managing the Coyote Linux Floppy

With the firewall up and running, you will surely want to manage it further. There are a couple of ways to access your firewall so that you can change its configuration with a Web interface or a remote login. Before you use the remote login, however, you must change the system (root user) password, and that can be done only through the Web interface.

# Using a Web Interface

The Coyote Web Administrator can be run from any browser on your LAN to view and change your firewall configuration. It is available from that machine on port 8180. To access the site configured in the preceding example, type the following location in your browser: http://192.168.0.1:8180.

The first thing you want to do is click the System Password button in the main menu and add a password for the root user. Figure 18-3 shows the Internet connection that was set up to dial out in the previous section.

# Using a Remote Login

The firewall floppy was configured to run under the ssh daemon, enabling you to log in over your LAN (using the ssh command) to manage your Coyote Linux firewall from the shell. In example, you can type:

```
# ssh -l root 192.168.0.1
root@192.168.0.1's password: ********
```

Enter the password (that you added from your Web interface as just described) and you are taken to the following Configuration menu:

Coyote Linux Gateway -- Configuration Menu

3) Edit rc.local script file 4) Custom firewall rules
5) Edit firewall configuration 6) Edit port forward configuration
c) Show running configuration f) Write configuration to disk

Select the letter of the configuration item you want to change. Type q when you are done and you are left at a regular Linux prompt. At that point, you can use Coyote Linux as your (somewhat limited) Linux system from a shell.
(Type menu if you want to return to the menu interface.)

As previously, the first time you open the interface to Coyote Linux, change the root password. For basic administrative tasks, you want to read the system log on occasion and back your configuration changes (which you have in RAM) so they are copied back to the floppy.

> To use ssh from a Windows machine to get to your firewall, or to get any other Linux system for that matter, many people use the putty utility. You can get it from its development page at http://chiark.greenend.org/uk/~sgtatham/putty/

# Using Other Firewall Distributions

Coyote Linux was chosen for this to illustrate how well, yet still really useful a Linux distribution can be. It also uses the iptables facility, which, once you learn how to use it, is useful in all recent Linux distributions.

There are, however, many other bootable firewalls available today. I strongly recommend that you check some of these other distributions if you want more or different features than those offered by Coyote Linux.

The Sentry Firewall CD (www.sentryfirewall.com) is a very nice bootable CD firewall CD takes advantage of the additional space on its CD to provide many extra tools for managing and watching your network. You can create a private network connection using FreeS/WAN, manage SNMP services with net-snmp, and set up a variety of servers (using Apache, sendmail, bind, and others).
