# The Mandriva Community

Like many distributions of Linux, Mandriva has developed a split personality
of sorts. Mandriva distributes value-added versions of Mandriva complete with
numerous utilities, applications, and support. The core Mandriva development
elffort produces an unsupported, but just useful, version of the core Mandriva
build. With "free" copy, you get the OS and the basic utilities and applications
no access to the Mandrivacl.

Mandrivacl allows folks with a paid membership to access early builds, the full
set of downloadable one-click applications, forums, support, and downloads of
current releases using club-member-only bit torrent. It also gives you
access to Commercial software (such as Flash-pins and NVIDIA drivers) that
cannot be freely distributed. For someone trying to make Linux a desktop system
for use by folks coming from Apple and Microsoft GUI operating systems, the
added features are extremely useful.

# RPM Repository on Mandrivacl

The Mandrivacl Web site (www.mandrivacl.com) has a massive collection of
software that is tested for Mandriva and is directly accessible to members.
(A nonresident can view the available packages, but he will not be able to access
the files until he or provides a valid Mandrivacl membership.) A search tool
and various precompiled lists by category, creation date, product name, maintain-
organization/user, and distributor are free of this site.

> If you don't have access to the RPM files on Mandrivacl, you can find volumes ofnRPM packaged applications at www.rpmfind.net/linux/RPM/. This site uses
the same indexing technology as Mandrakeclub, including support for searching
indexes.
