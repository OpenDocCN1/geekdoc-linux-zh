As Ubuntu is installed, it will check only Ubuntu software repositories to find and download the software you add to Ubuntu. There are, however, when you want to add community-build software that is outside the official distribution, in referred to as Universe and Multiverse:

+   **Universe** — Packages stored in Universe repositories include software that is not yet stable enough to be included in the project. Although the software has been built against Ubuntu libraries by the Ubuntu community, and will well in most cases, it comes without guarantee of support or security fixes.

+   **Multiverse** — Packages in Multiverse repositories contain software that is not free. This means the software licensing might not meet Ubuntu requirements, that the software may be encumbered by patent issues, or that only binary versions are available. Users are encouraged to research licensing and other legal issues themselves before using software from these repositories.

Follow these steps to add the Universe and Multiverse repositories to Synaptic Package Manager so you can use them to get additional Ubuntu software that might not be stable enough to be part of the Ubuntu release:

+   1. From the Synaptic Package Manager main window, select Settings \ Repositories. The Software Preferences window appears, displaying the softwarewares that are active for your system.
2. Select Settings. A setting pop-up window appears, as shown in Figure 17-4.
