# Chapter 4 ✦ Learning Basic Administration 151

The following settings are available from the Removable Drives and Media Preferences window on the Storage tab:

+   **Removable Storage**—When a removable drive (such as a USB pen drive) is hot-plugged into the computer, it is automatically mounted, based on the "Mount removable drives when hot-plugged" option, CDs, DVDs, and other removable media are automatically mounted when inserted, based on the "Mount removable media when inserted" option

You can choose "Browse removable media when inserted" to have the contents of removable media displayed in a Nautilus file manager window when it's inserted. "Auto-run programs on new devices and media" to have an autorun program if it exists on the media.

+   **Blank CD and DVD Dis**—When a blank CD or DVD is inserted, by default the Nautilus media window opens with the burn: options set. You can drag and drop files to back up files to the blank media.

The following settings are available from the Removable Drives and Media Preferences window on the Multimedia tab:

+   **Audio CD**—When an audio CD is inserted, the gnome-cd audio player opens and starts playing the music on the disk. You can change to a different audio player by changing the command, or select the checkbox to "Play audio CD disks when inserted" to not have audio play automatically.

+   **Video DVD Disc**—No player is started, by default, when you insert a media DVD disk into the DVD drive. By selecting "Play video DVD disks when inserted" the Totem media player will open to try to play the DVD.

The Totem media player will not play movie DVDs unless you add extra software to decrypt the DVD. There are legal issues and other movie player options you should look into if you want to play DVD movies from Linux. See Chapter 20 for more information about video players in Linux.

+   **Digital Camera**—Connect a digital camera and the gThumb Image Viewer (gthumb-import) will open, ready to import digital images from your camera. You can have other commands open the folder of digital images from your camera by replacing the `gthumb-import` command with an image viewer or import application you prefer.
