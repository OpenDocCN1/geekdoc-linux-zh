Increase this value if you believe that timeouts are occurring because of slow response from the server or slow network.

+   - retrans=#Sets the number of minions and retransmissions that need to happen before a major timeout.

+   - retry=#Sets how many minutes to continue to retry failed mount requests, where # is replaced by the number of minutes to retry. The default is 10000 minutes (which is about one week).

+   - bg—If the first mount attempt times out, all subsequent mounts in the background. This option is variable if you are mounting a slow or radically available NFS file system. By placing mount requests in the background, your system can continue to mount other file systems instead waiting for the current one to complete.

If a nested mount fails, a timeout allows for the needed mount point to be added. For example, if you mount /usr/trip and /usr/trip as NFS file systems and /usr/trip is not yet when /usr/trip/extra will time out. If you're lucky, /usr/trip comes up and /usr/trip/extra mounts on the next retry.

+   - fg—If the mount attempt times out, subsequent mounts in the foreground. This is the default behavior. Use this option if it is imperative that the mount be successful before continuing (for example, if you were mounting /usr).

Any of the options that don't have a value can have no appended to it to have the opposite effect. For example, nobg indicates that the mount should not be done in the background.

# Using autofs to Mount NFS File Systems on Demand

With the autofs facility configured and turned on, you can use any NFS shared directories to mount mount. To use the autofs facility, you need to have the autofs package installed. (For Fedora, you can type install autofs or for Debian type apt-get install to install the package from the network.)

With autofs enabled, if you know the host name and directory being shared by another computer, simply change (cd) to the autofs mount directory (/net by default). This causes the shared resource to be automatically mounted and accessible to you.
