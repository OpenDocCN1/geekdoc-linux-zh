## Mandriva Features

Unlike Linux distributions that are community-driven, Mandriva is a company that sells Linux products. Community-like activities are available through the Mandriviclub, where there is more than a customer support type of activity than a Linux development center.

Besides the merger with Conectiva, Mandriva also acquired the desktop-oriented Lycoris Linux distribution in June 2005. Therefore, the product offerings changed significantly in the past year (expect changes to continue for a while as dust settles). Actual Mandriva products are delivered along the lines of Mandriva and home office servers.

On the business side, products focus on corporate desktops and servers, as well as some specially firewall and clustering products. To support those products, Mandriva offers a variety of consulting, support and training options. For the home, Linux products range from beginner desktop products to products aimed toward home and small office servers. With the acquisition of Lycoris, Mandriva is also offering a Lycoris desktop product. Lycor was always respected for its ease-of-use.

The latest version of Mandriva Linux as of this writing is Mandriva 10.2. Version numbers for business-oriented products follow a different scheme, with the latest business server product called Linux Corporate Server 3.0. Here is a brief overview of the Mandriva products:

- **Mandriva Discovery**—Designed with the entry-level desktop user in mind. The package includes basic productivity software such as OpenOffice, Kdeprint, and planning/finance software. Also included the requisite networking tools for e-mail, FTP, and Web browsing. Several media components are also including audio and video playback, image editing, and scanning documents as well as recording.

- **Mandriva Powerpack**—Includes all the features that Mandriva Discovery Edition has and adds a set of development tools that includes the Kdevel integrated development environment, GCC GNU compiler, GDB debugger, and others. Some non-free, commercial software is also included with this product, including Flash and Java plugins, Java Runtime Environment, and NVIDIA video cards.

- **Mandriva Powerpack+**—Includes eight CDs and one DVD of software (more than 3,000 software packages in all) and two manuals. Along with the Mandriva complete desktop software, Mandriva Powerpack+ includes a range of server software, including Samba, MySQL, PostgreSQL (e-mail), LDAP, and Apache, which are ready to use after the default installation, making this product well-suited to a network environment where a cost-effective, multipurpose server is needed.

- **Mandriva Corporate Server** — Along with popular server software (Apache, MySQL, Samba, and so on), business-oriented Mandriva products come with more extensive product support. Both the Corporate and Premium Corporate Server products come with 24/7 Web support, with a Web response time of two business days. Both offer unlimited phone support as well, with the premium package offering quicker response time and extended options.

If you just want to try out Mandriva, the Mandriva Linux Limited Edition is available for download from the Mandriva download page mentioned earlier. ## Exploring Mandriva

The Linux distribution that has evolved into Mandriva has long held on the concept of "ease of use," the idea that its distributions would be readily accessible to a large pool of users. Mandrelinus was heralded early on its exceptional use of a graphical installer and configuration tools. Its quality support for hardware, video acceleration, and audio playback also tends to be top-notch.

When coupled with the fact that Mandlinux installer frequently detected and configured hardware that other distributions' installation routines mystified, you can see why Mandriva has been, and will probably continue, under the name Mandriva to be, a popular distribution.

Mandriva Limited Edition comes with a number of attractive features, including the following:

- highly automated installation process has new features such as the capability to resolve NTFS partitions.

- Hardware detection and configuration have been improved over previous Mandrelinus releases. In particular, the security, printing, and configuration tools have been completely overhauled to provide additional functionality and ease of use.

- Updated versions of the RPM Package Manager and the Internet update software have improved the ease of installing new software as well as system patches.

- Security maintenance is comprehensive. The Mandriva Limited Edition distribution includes easy-to-use configuration tools for setting general system security and setting up a firewall. Mandriva Limited Edition also supports a range of security protocols such as SSH, SSL, LDAP, and NIS.

- The user interface is consistent across all desktop environments.

In addition, there are a few tools that make a particularly big impact on the usability and consistency of Mandriva. These utilities are Drakx, RPMDrake, and Control Center.

### Mandriva Installer (Drakx)

DrakX is a highly acclaimed and user-friendly installer that has been one of Mandriva's key differentiators. Included since version Mandlinux 7.0, this installer was one of the first attempts at automated installers that most Linux users could easily use.

Although the installer is almost "newbie-proof," it is still possible to invoke advanced installation options enabling detailed control of the install at any point during the installation process. With most versions of Linux, you can install from a boot CD, another drive, or a network. Here are the key features of the Drakx installer included in the current version of Mandriva:

- Convenient configuration options using predefined packages, rather than requiring you to choose individual packages from the selection that is available. You can select individual packages if you do not want to use one of the predefined package options. Workstation and Server Package are available for various roles and, for example.
- The ability to format hard disks, configure RAID, and resize partitions of many types, including NTFS, FAT32, EXT3, ReiserFS, and XFS.
- Support for a wide range of network file systems.
- Improved upgrade.
- Automated installation tools.
- Rescue mode for failed/problematic installation.

In addition to the straightforward boot CD, the Drakx installer supports a number of other installation methods, including:

- Network installs -- If needed, you can start the Drakx installation process and connect to a variety of network servers to access the installation files. This includes NFS, HTTP, SMB, SSH, Web Proxy, and FTP servers.
- Kickstart installs -- In environments where customer support call centers, school computer labs, and large offices, you might find yourself needing to install and configure large number of computers in a short period of time. Kickstart installations use an answer file to automate most of the installation process. Mandriva's installation routine enables you to create floppies to use when performing kickstart installations.
