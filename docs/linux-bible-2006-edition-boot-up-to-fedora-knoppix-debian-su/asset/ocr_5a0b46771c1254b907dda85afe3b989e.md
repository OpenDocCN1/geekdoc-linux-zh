# Displaying Documents with ghostscript and Acrobat

Document publishing can be very page-intensive if you send a Groff or LaTeX document to the printer each time you want to make a change to the document's content or formatting. To save time and spent around, use a print preview program to display your document on the screen as it will appear on the printed page. The following sections describe the ghostscript command for displaying PostScript files and the Adobe Acrobat Reader for displaying Portable Document Format (PDF) files.

# Using the ghostscript and gv Commands

To display PostScript or PDF documents in Linux, you can use the ghostscript command. It is a fairly crude interface, intended to let you step through documents and interpret them one at a time.

You can display any PS or PDF file you happen to have on your computer. For example, if the samba package is installed, you can use the following to display a PDF (otherwise, use gv to view your own PDF file to try it);

```
$ ghostscript /usr/share/doc/samba /*doc/samba-HOWTO-Collection.pdf
>>showpage, press <return> to continue<<
```

At the prompt, press Enter (or Return) to go through the file one at a time. When you have reached the end of the document, you can type the name of PostScript or PDF file and page through that file. When you are done, quit.

# Using Adobe Acrobat Reader

The Portable Document Format (PDF) provides a way of storing documents as they would appear in print. With Adobe Acrobat Reader, you can view PDF files in a friendly way. Adobe Acrobat makes it easy to move around within a PDF file. A PDF file may include hyperlinks, a table of contents, graphics, and a variety of type fonts.
