## Identifying Other Computers (Hosts and DNS)

Each time you need to identify a computer, such as when browsing the Web or using an e-mail address, the computer name must be translated into an IP address. To resolve names to IP addresses, Linux goes through a search order (usually based on the contents of files in `/etc/resolve.conf`, `nsswitch.conf`, and `host.conf`). By default, checks host names (which end up in the `/etc/hosts` file), hosts available via NIS, and host names available via DNS.

Again, for RHEL and Fedora systems, you can use the Network Configuration window to add:

- **Host names**—You might need to identify hosts on your LAN that are not configured on a DNS server.
- **DNS search path**—By adding domain names to a search path (such as `linuxtoys.net`), you can browse to a site by its host name (such as `jukebox`), and have Linux search the domains you added to the search path to find the host you are looking for (such as `jukebox.linuxtoys.net`).
- **DNS name servers**—A DNS server can resolve addresses for the domains it serves and contact other DNS servers to get addresses for all other domains.

If you are configuring a DNS server, you can use that server to centrally store names and IP addresses for your LAN. This saves you the trouble of updating every computer's /etc/hosts file time you add or change a computer on your LAN.

To add hosts, IP addresses, search paths, and DNS servers:

- 1. Start the Network Configuration. As root user from a Terminal window, system-config-network or from the red hat menu, click System Settings Network. The Network Configuration window appears.
- 2. Click the Hosts tab. For IP addresses, host name, and aliases appears.
- 3. Click New. A pop-up window (see Figure 5-6) appears.

- 4. Type in the IP address number, host name, and, optionally, the host alias.
- 5. Click OK.
- 6. Repeat this process until you have added every computer on your LAN that cannot be reached by DNS.
- 7. Click the DNS tab.
- 8. Type the IP address of the computers that serve as your Primary and Secondary DNS servers. (You get these IP addresses from your ISP, or if you created your own DNS server, you enter that server's IP address.)
- 9. Type the name of the domain (probably the name of your local domain) to be searched for host names into the DNS Search Path box.
- 10. Click File->Save to save the changes.
- 11. Click File->Quit to exit.

Now, when you use programs such as ftp, ssh, or other TCP/IP utilities, you can use any host name that your local computer exists in your search path, or can resolved from public DNS servers. Strictly speaking, you don't have to set up your /etc/hosts file. You could use IP addresses as arguments. But names are easier to work with.

## Understanding Your Internet Connection

If your Ethernet interface to the Internet is not working, there are ways to check out what's happening. Use the following procedure:

- 1. Open a shell (if you are using a graphical interface, open a Terminal window).
- 2. Type the following after boot to verify whether your Ethernet card was found and installed properly: `dmesg | grep eth`. The dmesg command lists all the messages that were output by boot. The grep command shows those lines that contain the word eth. Here are a couple of examples:

```
eth0: Intel PRO/1000 Gigabit Ethernet Controller at port 0x300, hw_addr 00:10:25:8C:8E:49 irq3
eth0: Intel PRO/1000 Gigabit Ethernet Controller at port 0x300, hw_addr 00:90:27:46:35 irq17
```
The first message appears on my laptop with port 0x300 and an Ethernet address of 00:10:25:8C:8E:49. The second example is from my computer with port 0x300, and the Ethernet address of 00:90:27:46:35. If the eth interface is not found, type `lspci | grep eth` to see if your Ethernet card is properly seated in its slot.

- 3. To view how network interfaces are up, run the following: `ifconfig`

```
eth0: inet=10.0.0.5  netmask=255.255.255.0  broadcast=10.0.0.255  multipicast=1
        ether=00:10:25:8C:8E:49  mtu=1500  txlen=1000
        packet,RX,packets,RUNNING
        errors=0  dropped=0  collisions=0
```
The output shows a loopback interface (lo) and one Ethernet card (eth0). The Ethernet interface (eth0) is assigned the IP address of 10.0.0.5. In this example, eth0 has an IP address of 10.0.0.5.

- 4. Communicate with another computer on the LAN. The ping command can be used to send a packet to another computer and ask for a packet in return. You can give ping a host name (ping) or an IP address (10.0.0.10). For example, to ping a computer on the network called pine, type the following command: `ping ping`.
