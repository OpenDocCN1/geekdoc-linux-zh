The images that are burned onto CDs are typically stored on the Internet
with what are called software repositories. You can download the images and burn them
to CDs yourself. Alternatively, the software packages are usually included separa-
rately in directories. Those separate software directories allow you to start an
install process with a minimal boot disk that can grab packages over the network
during the installation process. (Some of the installations we recommend with this
bone are that way.)

When you follow links to Linux software repositories, here's what you look for:

+   - **Download directory** — You often have to step down a few directories from
the link that gets you to a repository. Look for subdirectories
describe the distribution, architecture, release, and medium format. For example-
fora/linux/core/4/i386/iso.

+   - **ISO images** — The images you are going to be burned to CD are typically\stored in ISO format. Some repositories include a README file to tell you what
images you need (just adjust you know). To install a distribution, you
want the ISO containing the Linux distribution's binary files. For example,
t set of four Fedora Core 4 installations for i386 platforms are
FC4-i386-disc1.iso (with the others disc2, disc3, and disc4).

Note

An ISO image appears as one file, it's actually a snapshot of a file system
You can mount the image to see all the files in the image by using the
loop feature of the mount command. For an example with
abc.iso in the current directory, create a directory (mkdir myiso) and
as as root, run the mount command: mount -o loop abc.iso myiso. Change to
myiso directory and you can view the files and directory the ISO image-
tains. When you are viewing the contents, leave the directory and unmount
t ISO image (cd .. : mount myiso).

+   - **MD5SUM** — To verify that you got the right CDs completely, after you
down download them look for a file named MD5SUM or ending in .md5 in the ISO
directory. You can use that file to verify the content of each CD (as described
later).
