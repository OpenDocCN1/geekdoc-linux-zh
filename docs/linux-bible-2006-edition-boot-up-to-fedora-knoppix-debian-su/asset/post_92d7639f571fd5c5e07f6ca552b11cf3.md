
# Chapter 3 ◆ Getting into the Desktop

- Web Behavior—Click the Behavior (Browser) button to open a window to configure the Web browser features of Konqueror. By enabling Form Completion, Konqueror can save data you type in, at a later time, fill information into other forms. If your computer has limited resources, you can speed up page display by clearing the Automatically Load Images check or by disabling animations.

- Java and JavaScript—Enable or disable Java and JavaScript content contained in Web pages in your Konqueror window.

- Fonts—Choose which fonts to use, by default, for various fonts needed on Web pages (standard font, fixed font, serif, sans serif, cursive, and fantasy). The serif fonts are typically used in body text, while sans serif fonts are often used in headlines. You can also set the Minimum and Medium size fonts.

- Web Shortcuts—Display a list of keyboard shortcuts you can use to go to different Internet sites. For example, follow the word "ask" with a search string to search the Jeeves (www.ask.com) Web site.

- History Sidebar—Modify the behavior of the list of sites you have visited (the history). By most recent 500 URLs are stored, and after 500 days (KNOPPX) or 90 days (Fedora), a URL is dropped from the list. There is also a button to clear your history list in Konqueror, open the left side panel, and then click the tiny scroll icon.

- Cookies—Choose which cookies are enabled in Konqueror. By default, you are asked to confirm if it is okay time to create a Web site or modify a cookie. You can change this to either accept or reject all cookies. You can also set policies for acceptance or rejection of cookies based on host and domain names.

- Cache—Indicate how much space on your hard disk can be used to store the sites you visited (based on the value in the Disk Cache size field).

- Proxy—Configure Konqueror to access the Internet through a proxy server (by default, Konqueror tries to connect directly). You need to enter the address and port of the providing HTTP and/or FTP proxy servers. Alternatively, you can have Konqueror automatically detect proxy configuration.

- Stylesheets—Choose whether to use the default stylesheets, a user-defined stylesheet, or a custom stylesheet. The stylesheet sets the font family, font sizes, and colors that are applied to Web pages. (This won't change particular font requests made by the Web page). If you select a custom stylesheet, use the Customize tab to customize your fonts and colors.

- Crypto—Display a list of secure certificates that can be accepted by the Konqueror browser. By default, Secure Socket Layer (SSL) versions 2 and 3 certificates are accepted, as is TLS support (if supported by the server). You can also choose to be notified when you are entering or leaving a Web site.

- Browser Identification—Set how Konqueror identifies itself when it accesses a Web site. By default, Konqueror tells the Web site that it is the Mozilla Web browser.

## Creating an Image Gallery with Konqueror

There's a feature in Konqueror that lets you create a quick image gallery. The feature takes a directory of images, creates thumbnails for each one, and generates an HTML (Web) page. The HTML page includes a title you choose, all image thumbnails arranged on a page, and links to the larger images. Here's how you do it:

- 1. Add images in your gallery to any folder (for example, `/home/knoppix/Images`). Make sure they are sized, rotated, and cropped the way you like before beginning. Try The Gimp for manipulating your images.

- 2. Open the folder in Konqueror (for example, type `/home/knoppix/images`).

- 3. Click Tools -> Create Gallery.

- 4. Type a title for the image gallery into the Title box. You can also select other attributes of the gallery, such as the number of rows, information about the image to appear on the page (name, size), the fonts, and the colors to use.

- 5. Click OK.

Konqueror generates the thumbnails and adds them to the directory. The image page opens itself and is saved to `Images.html`. Select the button to save the gallery under a different name. You can also have Konqueror create galleries in subfolders to a depth you choose. You can now copy the entire contents of this directory and publish your pictures on the Internet. ## Managing Windows

If you have a lot of icons on the desktop and windows open at the same time, organizing those items can make it easier to manage your desktop. KDE helps you out by maintaining window lists with shortcuts for keeping the windows in order.

- Plugins—Display a list of directories that Konqueror will search to find plugins. Konqueror can also scan your computer to find plugins that are installed for other locations.

- Performance—Display configuration settings that can be used to improve performance. You can preload an instance from startup or minimize memory usage.

## Using the Taskbar

When you open a window, a button representing the window appears in the taskbar at the bottom of the screen. Here is how you can manage windows from the taskbar:

- Toggle windows—Left-click any running task in the taskbar to toggle opening and minimizing the window.

- Move windows—Move a window from the current desktop to any other virtual desktop. Right-click any task in the taskbar, select To Desktop, and select any desktop. The window moves to that desktop. All the windows that are running, regardless of which desktop you are on, appear in the taskbar. If there are multiple windows of the same type as a single task, you can right-click that task; then, select All Desktop to move all windows to the desktop you pick.

## Uncluttering the Desktop

If your windows are scattered wildly over the desktop, here are a couple of ways you can make your desktop's appearance little nicer:

- Unclutter windows—Right-click the desktop, and then click Windows -> Unclutter windows on the menu. All windows that are currently displayed on the desktop are aligned along the left side of the screen (or aligned with other windows), from the top down.

- Cascade windows—Right-click the desktop, and then click Windows -> Cascade windows on the menu. The windows are aligned diagonally, except that the windows are each indented starting from the upper-left corner.

If you find yourself with icons all over the desktop, you can also organize them from the desktop menu. Right-click the desktop, then select Icons -> Sort. From the menu that appears, select icons by name, size, or type. You can also choose to simply line up all icons vertically or horizontally.

## Moving Windows

The easiest way to move a window from one location to another is to place the cursor on your window's title bar, hold the mouse button and drag the window to a new location, and release the mouse button to drop the window. Another way to do it is to click the window menu button (top-left corner of the title bar), select Move, move the window to relocate it, and then again to place it. ![](img/a2d958d7eab32ca5b89b2baf80aa70_127_0.png)

If some window gets stuck in a location where the title bar is off the screen, you can move it back to where you want by holding the Alt key and clicking the left mouse button in the inner window. Then move the window you want and release it.

## Resizing Windows

To resize a window, grab anywhere on the outer edge of the window border, and move the window until the window is the size you want. Grab a corner to resize vertically and horizontally at the same time. Grab a side to resize in one direction.

You can also resize a window by clicking the window menu button (top-left corner of the title bar) and selecting Resizing. Move the window until the window is resized and click to leave it.

## Pinning Windows on Top or Bottom

You can set a window to always stay on top of all other windows or stay under them. Keeping a window on top can be useful for a small window that you (such as a clock or a small TV viewing). To pin a window on top of the desktop, click the window title bar. From the menu that appears, select Advanced -> Keep Above Others. Likewise, to keep the window on the bottom, select Advanced -> Keep Below Others.
