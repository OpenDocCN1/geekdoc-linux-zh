# Linux Distributions

Every major Linux distribution has a Web site that provides information about how to get it and use it. If you haven't chosen a distribution yet, here are some sites that can help you evaluate, find, and get a Linux distribution that interests you:

+   **Distrowatch (www.distrowatch.com)** Contains information about a few hundred different Linux distributions. The site provides an easy way to find out different distributions, and then simply connect to the distribution's home page, download site, or related forums.

+   **LinuxISO (www.linuxiso.org)** Provides information about Linux distributions and how to get them. Also tells you about downloading, verifying, and burning your own CDs from ISO images.

+   **LWN net Distributions (lwn.net/Distributions)**—If you want to read succinct descriptions of more than 400 Linux distributions on one page, this is the place to go.

Here are sites associated with Linux distributions covered in this book:

+   **Fedora (fedora.redhat.com)**—Community-driven Linux, supported by Red Hat. In the past year, Red Hat Inc, has designated FedoraForum as the official site for Fedora. The project itself is transitioning from the Red Hat Web site to http://fedoralegacy.org. Check the Legacy Project (http://fedoralegacy.org) for long-term support. Look to Fedora Extras (fedora.us) and Livna (rpm.livna.org) for downloads of Extra Fedora software.

+   **Red Enterprise Linux (www.redhat.com)**—Check the main Red Hat site for information on commercial Linux products.

+   **Debian GNU/Linux (www.debian.org)**—Get news, documentation, and download information about Debian. Try the Debian news site at http://us.debian.org/News for the latest news on Debian.

+   **SUSE (www.novell.com/linux/suse)**—Get product support information from this site. The Novell also provides information about Novell's Linux offerings. The community supported version of SUSE (called openSUSE) also has a Web site (http://www.opensuse.org).

+   **Knoppix (www.knoper.net/knoppix/index-en.html)**—The official KNOPPI page on its creator's (Klaus Knupper's) Web site. An English forum is at www.knoppix.net, and a German forum at www.linuxuag.org/forum.
