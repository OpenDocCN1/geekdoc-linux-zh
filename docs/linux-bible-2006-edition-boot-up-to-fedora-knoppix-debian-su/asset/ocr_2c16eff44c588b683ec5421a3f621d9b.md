# Chapter 22 ♦ E-Mailing and Web Browsing 605

+   * **Smart Browsing** — Choose to do keyword searches when you type partial addresses in the Location box. Smart browsing is off by default, typing netscape would cause Mozilla to look for www.netscape.com instead of searching for netscape links.

+   * **Internet Search** — Select which search engine to use for Internet searches. You can also change how the Search tab is used with searches.

+   * **Tabbed Browsing** — Use these selections to have search results appear in tabs on the Mozilla Navigator instead of appearing in the full screen.

+   * **Download** — Choose what you see during downloads from the Internet (a download manager, a progress dialog box, or nothing).

Set Advanced Preferences to fine-tune your Web browsing experience. That includes choosing how data is cached on your computer and which proxies are used. On the main Advanced preferences panel, you choose whether to enable Java content to be displayed in your browser. Here are some preferences that may interest you:

+   * **Scripts & Plug-ins** — The Web content you choose try to open, move, resize, raise, and lower windows. You can restrict to change your images, status bar text, or bits of information stored are called cookies. These preferences let you restrict the content you want do.

+   * **Keyboard Navigation** — If you like to move around Web pages using keystrokes, these preferences let you choose Mozilla's behavior when you press the Tab or just typing Shift-Tab will always move to the next box, however you can also select to have Shift-Tab go to the next link or button/check box on the page as well. You can also select when you begin typing, Mozilla will go to anywhere it appears on the page or only to a link containing that word.

+   *Cache** — By default, the most recent 4MB of Web pages you visit are stored in RAM and the most recent 50MB of pages you visit are on your hard disk. If a page is not out-of-date, caching makes possible to return to a page quickly, without needing to reload from the original Web server. Cache preferences let you how much information is cached, and where the hard disk cache is located. Other preferences let you all memory and disk cache immediately.

+   * **Proxies** — If you have direct access to the Internet, you don't need to change any proxy settings. If you need to access the Internet via a proxy server, you can identify the location of that server (or servers) here. To access the Web proxy servers, you must explicitly identify the proxy server to use for each type of content you request (HTTP, SSL, FTP, GOP, and SOCKS).

+   * **HTTP Networking** — If you are using a proxy server, that proxy server may require you make HTTP requests using either HTTP/1.0 or HTTP/1.1 standards (1.1 is the default). You can set which version of HTTP requests you should use.
