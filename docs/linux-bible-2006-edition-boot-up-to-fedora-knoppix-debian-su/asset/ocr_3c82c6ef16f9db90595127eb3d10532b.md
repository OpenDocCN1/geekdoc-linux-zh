# Managing E-Mail with Virtual Folders

Managing amounts of e-mail can become difficult when the messages you want to refer to several folders, dates, or senders. With virtual folders (vFolders), you can identify criteria to group together messages from all mail folders so you can deal with them in one vFolder. Here's a procedure for creating a vFolder:

+   1. With Evolution to open read mail (click Inbox to get there), select File > New Folder. Create New Folder pop-up appears.
2. Select vFolders, type a folder name (like FromJohn), and select OK. A New vFolder pop-up appears.
3. Click Add and select criteria for including a message in your vFolder. You can search to see if it is the sender, recipient, message body, or other part of the message contains or doesn't contain the string you type in the next box. Click Add if you want to add more criteria.
4. If you want to search only specific folders, click Add in the vFolder Sources and select the folder you want to search. You can repeat this to more than one. Otherwise, you can select to search all local folders, all active remote folders, or all local and active remote folders. Then click OK.
5. Make sure your folder is visible (View > Folder). The folder you just created is listed under the vFolders heading. Click that folder to see the messages gathered with this action.

At this point, you can work with the messages you gathered in the vFolder. Although it appears that there are multiple versions of each message across your mail folders, there is only one copy of each. So deleting or moving the message from a vFolder actually causes it to be deleted or moved from the original folder in which the real message resides.

# Filtering E-Mail Messages

You can take action on an e-mail message before it lands in your Inbox. Click Tools > Filters, and a Filters window opens to let you add folders to deal with incoming or outgoing messages. Click Add to create criteria and set actions.
