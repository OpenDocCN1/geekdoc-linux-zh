# Working with Files

Because most of the ways of working with files in Konqueror are quite intuitive (by intention), Table 3-3 provides a quick rundown of how do basic file manipulation.

| Task | Action |
| --- | --- |
| Open file | Double-click the file. It will open right in the Konqueror window, if possible, or in the default application set for the file type. You can also open directories, applications, and links by double-clicking them. |
| Open file with a specific application | Right-click a data file, choose With from the pop-menu, and then select one of the available applications to open the file. The applications listed are those that are set up to the file. |
| Delete a file | Right-click the file and select Delete. Are asked if you really want to delete it. Click Yes to permanently delete it. |
| Copy a file | Right-click the file and select Copy. This copies the file to your clipboard. After that, you can paste it to another folder. Click the Klipper (clipboard) icon in the panel to see a list of copied files. Klipper holds the seven most recently copied files, by default. Click the Klipper icon and select Configure Klipper to change the number of copied files Klipper will remember. |
| Paste a file | Right-click (an area of a folder) and select Paste. A copy of the file copied previously from one folder is pasted in the current folder. |
| Link a file | Drag-and-drop from one folder to another. When the new appears, click Link Here. (A linked file allows you to access a file from a new location without having to make a copy of the original. When you open the link, a pointer to the original file causes it to open.) |
| Move a file Create a link to file | With the original folder and target folder both on the desktop, click and hold the mouse button on the file you want to move, drag the file to an open area of the new folder, and release the mouse button. From the menu that appears, click Move. (You also use this to copy or create a link to the file.)

There are also several features for viewing information about the files and folders in your Konqueror windows:

+   * **View quick file information** — Positioning the mouse pointer over the file displays information as its filename, size, and type in the window footer.
* **View hidden files** — Selecting View < Show Hidden Files Enables you to see files that begin with a dot (.). Dot files tend to be used for configuration and don't generally need to be viewed in your daily work.
