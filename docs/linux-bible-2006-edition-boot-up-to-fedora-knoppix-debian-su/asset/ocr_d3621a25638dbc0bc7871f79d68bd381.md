# Exploring Mandriva

The Linux distribution that has evolved into Mandriva has long held on the concept of "ease of use," the idea that its distributions would be readily accessible to a large pool of users. Mandrelinus was heralded early on its exceptional use of a graphical installer and configuration tools. Its quality support for hardware, video acceleration, and audio playback also tends to be top-notch.

When coupled with the fact that Mandlinux installer frequently detected and configured hardware that other distributions' installation routines mystified, you can see why Mandriva has been, and will probably continue, under the name Mandriva to be, a popular distribution.

Mandriva Limited Edition comes with a number of attractive features, including the following:

+   - highly automated installation process has new features such as the capability to resolve NTFS partitions.

+   - Hardware detection and configuration have been improved over previous Mandrelinus releases. In particular, the security, printing, and configuration tools have been completely overhauled to provide additional functionality and ease of use.

+   - Updated versions of the RPM Package Manager and the Internet update software have improved the ease of installing new software as well as system patches.

+   - Security maintenance is comprehensive. The Mandriva Limited Edition distribution includes easy-to-use configuration tools for setting general system security and setting up a firewall. Mandriva Limited Edition also supports a range of security protocols such as SSH, SSL, LDAP, and NIS.

+   - The user interface is consistent across all desktop environments.
