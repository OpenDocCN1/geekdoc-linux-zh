# Running Ubuntu Linux

Ubuntu Linux (www.ubuntu.com) has experienced a meteoric rise in popularity since its first release at 2004. Relying on a handful of developers from the Debian, Arch Linux, GNOME, and other open source projects, Ubuntu has become one of the leading Linux distributions in the world.

> “Ubuntu” is an African word that means “humanity to others.
The Project pursues the meaning of its name by:

- Making the distribution freely available; in fact, the project will even mail you requested CDs without charge (http://shipit.ubuntu.com).
- Providing support for many languages.
- Offering features to make it usable by people with disabilities.

Ubuntu is based on Debian GNU/Linux but offers more focused goals than Debian. A primary goal is to fit an easy-to-use desktop Linux on one installation CD. Because Ubuntu is based on Debian (in fact, it's based on the latest, unstable Debian software packages available), an Ubuntu user has hundreds of software packages available that can be installed using APT management tools.

This chapter describes some of the major features of Ubuntu.

Because Ubuntu is primarily a Debian distribution on the inside, which of what makes Ubuntu different from Debian are the specific packages chosen, the simplified installation process, and the settings that shield new users from complex choices. # Ubuntu Installer

The Ubuntu installer is one of the features that has made Debian-based Linux systems more acceptable to less experienced Linux users. The install process leads you through some fairly simple questions, and then does a very good job of detecting your hardware and installing its whole set of software packages to your hard drive.

Don't expect the Ubuntu installer to look like installers for Red Hat or SUSE systems. There are no pretty graphics and no point-and-click with the mouse. The Ubuntu installer is text-based, although it does lead you through fairly simple configuration questions. It also makes some choices for you, so novice users not have to wreck their brains for answers they may not have. (For example, a server or desktop installer gives you all packages for those install types, without giving you the option to customize the install further.)

While there are many changes compared to the Ubuntu installer, the ability to create file systems based on Logical Volume Management (LVM) is the most significant feature in the latest version of Ubuntu. By creating LVM file systems, you are able to add or subtract disk space to each LVM partition. So, for example, if you have a /var partition that runs out of disk space, you can add a physical hard disk to your computer. You can then add the additional space from that disk to /var partition (without having to copy data off, the partition, creates a larger partition, and copy the data back).

Other neat ease-of-use features are built into the Ubuntu installer. For example, if you are not sure which keyboard you have, you have the option to type a few keys (prompted by the installer) and have to try to figure out the type of keyboard you you. You also have the option to resize a partition during installation (a very handy feature if you have a hard disk with one big Windows partition that you't want to completely delete).

# Ubuntu as a Desktop

As promised, Ubuntu 5.1 contains the latest desktop features available at the time it was released. Along with the latest desktop components you would expect (GNOME, OpenOffice, and so on), Ubuntu 5.1 also includes improved features for installing applications. Here are some of the features in Ubuntu 5.1:

- GNOME Desktop—GNOME 2.12 provides the desktop environment for release of Ubuntu. End users will find a new theme called ClearLooks, which provides a very clean, professional look.
- If you used earlier versions of GNOME, you'll notice that there are two panels (one top, one bottom) instead of one that at the bottom of the screen. This gives you more room for menus, application launchers, and applets without taking any screen space. With this release, rotated menus have been added, so you can have vertical panels (along the sides) instead of panels on the top and bottom.
- Nautilus file manager—The Nautilus file manager, which comes with GNOME, is constantly being enhanced. For this release, look for changes to drag-and-drop (drag text from a document to Nautilus and it creates a new document). Also, when you view files in List View, you can now see files as well as folders (by clicking a down arrow to folder).
- Totem video player—As for multimedia support, GNOME continues to improve its Totem video player, which is based on the GStreamer multimedia framework. Playlists are not integrated into the Totem sidebar and DVD menus and subtitles are supported.
- Application installation tool—After Ubuntu is installed, you can use the Add/Remove Programs from the System Administration menu to install new applications or rid of existing ones you don't want anymore.

Beyond these features, Ubuntu contains a broad range of open source applications suitable for the desktop. The leading one are OpenOffice.org (popular productivity suite), the GIMP (image manipulation software), Evolution (e-mail client), and Firefox (Web browser).

Many of the tools for configuring and setting preferences for the desktop that with the GNOME project fit well into the Ubuntu goals of accessibility and ease-of-use. GNOME's Removable Drives and Media Preferences window is set to automatically launch applications when you insert a CD or DVD or plug in a camera, printer, or scanner. The Assistive Technology enables users who is visually or physically impaired to use magnifiers and onscreen keyboards.
