# 414 Part III ◆ Choosing and Installing a Linux Distribution

Enter the root user name and your root password when prompted. Then select the Add printer button to begin adding your printer to the CUPS printing over your Slackware system.

+   * Configure networking—If you do not configure your Ethernet cards at installation time, you can do it now. Type the following command:

```
# netconfig
```

The menu system enables you to configure your network interface using the same screens at installation.

+   * Install additional software packages—You can use the pkgtool to install Slackware packages. Download any packages you want to install to a directory. Change to that directory and run the pkgtool command. Choose Current, to install packages from the current directory. A screen appears, displaying the first software package available for you install. Select Yes to install the package.

![](bbox=[0.103, 0.388, 0.173, 0.435])

One place to find Slackware packages is LinuxPackages.net. Likewise, when you install Slackware packages from any open source project (as sourceforge.net) that are either identified as being created for Slackware or simply tar.gz packages that you can build from scratch.

The pkgtool utility also enables you to list the contents of installed packages, install new packages, and remove existing packages.

If you are used to other Linux systems, you should familiarize yourself with things you might find different in Slackware. For example, system startup scripts are contained in /etc/rc.d, rather than a series of links to /etc/rc?.d directories.

# Summary

Slackware is the oldest Linux distribution. It is run by Patrick Volkerding, as it has been for more than a decade, and keeps its goals stability and security. Slackware has a loyal following, but the project is not geared for wide deployment in enterprise computing situations. Slackware is a great distribution to learn Linux on because it keeps its configuration simple and near to the command line and configuration files.

Look for Slackware to continue to be the most efficient Linux distributions. There are currently no plans to add a graphical installer or fancy software package management system. You can expect Slackware to remain true and true to its roots, making it one of the best Linux distributions to run on older hardware.
