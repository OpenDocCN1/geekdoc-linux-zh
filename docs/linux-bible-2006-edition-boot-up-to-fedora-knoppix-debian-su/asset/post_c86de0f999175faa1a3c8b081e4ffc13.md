- Start the desktop—If you installed X and either a window manager or whole desktop environment (KDE or XFCE), you can start it by:
```bash
# startx
```

If X and your desktop doesn't start properly (the screen may be unresponsive or may simply crash), press Ctrl-Alt-Backspace to exit and return to the shell. Instructions for solving X problems, choosing different window managers, and configuring X are included in Chapter 3's "Configuring Your Own Desktop" section.

- Configure sound—When you first boot Slackware, the ALSA sound should be set up to, but the volume is muted. Configure ALSA so that your sound card is ready to go, as root user run the alsaconf command. For installed sound cards, and when it finds one, it adds any modules you need to use the card, raises the volume, and tests the card.

Once your sound card is configured, use the alsmixer to adjust volume levels for your sound card.

- Add modules—If any of your hardware was not properly detected and configured, you can add the modules after Slackware is running. In addition to the standard /etc/modules.conf file for 2.4 kernels or /etc/modprobe.conf for 2.6 kernels, Slackware provides its own file where you can load extra drivers: /etc/rc.modules.

The rc.modules file is useful because it contains the commands to load many useful modules. The lines are commented out, so you simply have to remove the comment character to have the modules on the next reboot.

If some of your hardware was not detected properly, and you don't know what module is required for it to, try booting KNOOPPIX (from the DVD included with this book). If the hardware works in KNOOPPIX, run the lsmod command to see what modules are loaded. From that list, you will be able to add the necessary modules as described.

# Summary

Slackware is the oldest Linux distribution. It is run by Patrick Volkerding, as it has been for more than a decade, and keeps its goals stability and security. Slackware has a loyal following, but the project is not geared for wide deployment in enterprise computing situations. Slackware is a great distribution to learn Linux on because it keeps its configuration simple and near to the command line and configuration files.

Look for Slackware to continue to be the most efficient Linux distributions. There are currently no plans to add a graphical installer or fancy software package management system. You can expect Slackware to remain true and true to its roots, making it one of the best Linux distributions to run on older hardware.

# Overview of Lininspire

Lininspire began as Lindows, founded by Michael Robertson in 2001, after his tenure with MP33.com. His goal was to bring Linux to the desktop once and for all.

The general concept was to develop an operating system that would be inexpensive, easy to install and use, and a competitive alternative to Microsoft Windows on the desktop PC. To accomplish that, Lindois needed to be simple enough for a non-technical user (even someone who has never really used a PC before) to install, configure, and use. While this is, indeed, a laudable goal, most of this product’s press as the result of its tension with Microsoft Corporation.
