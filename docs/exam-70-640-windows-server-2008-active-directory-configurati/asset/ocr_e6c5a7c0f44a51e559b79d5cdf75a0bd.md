Lucerne Publishing is a global publishing firm with offices in North America, Europe, and India. Over the past several weeks, the IT staff at Lucerne Publishing has designed and implemented a Windows Server 2008 Active Directory network containing multiple sites, OUs, and GPOs. To maintain the Active Directory network, Lucerne Publishing needs to develop a backup and recovery plan for Active Directory to protect against the loss of a single domain controller, object, or container. Additionally, the IT staff at Lucerne Publishing needs to implement an ongoing monitoring scheme to ensure that the new Active Directory environment remains available for all users, workstations, and member servers.
