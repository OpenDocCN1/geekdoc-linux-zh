## 使用 Repadmin 查询域控制器

Active Directory 中用于 Microsoft Windows 系统的域管理器。
1. 在命令提示符下，输入以下命令以列出 Active Directory 中的所有域控制器：
   ```
   ntdsutil quads show dcs
   ```
2. 注意以下命令如何列出域中的所有域控制器：
   ```
   repadmin /showrepl
   ```
3. 运行以下命令以查询特定域控制器：
   ```
   repadmin /showrepl <DNS hostname of DC>
   ```
