### 教学特性

《Microsoft Windows Server 2008 Active Directory》MOAC 教材旨在覆盖该 MCTS 考试的所有学习目标，即其“目标域”。教材中处处突出显示 Microsoft Certified Technology Specialist (MCTS) 考试目标。许多教学特性是专门为*Microsoft 官方学术课程*（MOAC）项目开发的。

教材中穿插了大量程序性信息和技术概念，这对学生和讲师都构成了挑战。接下来的图示化章节导览为*Microsoft 官方学术课程*项目教学计划中的丰富特性提供了指南。以下是每课中旨在帮助学生为认证考试和职场取得成功所做的准备的关键特性列表：

- 每课都以**目标域矩阵**开始。目标域矩阵不仅仅是标准的学习目标列表，它将课程中涵盖的每项软件技能与特定的 MCTS“*目标域*”进行对应。
- 简明扼要且频繁出现的**逐步**指导教学生掌握新功能，并提供动手实践的机会。编号步骤提供详细的逐步指导，帮助学生学习软件技能。步骤还展示了结果和屏幕图像，以匹配学生电脑屏幕上应看到的内容。
- **插图**：屏幕图像为学生在练习过程中提供视觉反馈。这些图像强化了关键概念，提供了步骤的视觉提示，并允许学生检查其进度。
- **关键术语**：重要的技术词汇列在课程开始处。当这些术语在课程后续部分使用时，它们以**粗斜体**显示并进行定义。词汇表包含所有关键术语及其定义。
- 引人入胜的**读者辅助**功能位于课程各处，告知学生为何此主题相关（*要点*），为学生提供有用的提示（*请注意*），或展示完成任务的其他方法（*另一种方法*）。读者辅助功能还提供额外的相关或背景信息，以增加课程的价值。
- 贯穿全文的**认证就绪？**功能向学生指出特定认证目标被覆盖的位置。它们为学生提供检查对该特定 MCTS 目标理解的机会，并在必要时复习课程中涵盖该目标的章节。MOAC 提供 MCTS 认证的完整准备。
- **知识评估**提供三个难度递增的结束课程活动。
