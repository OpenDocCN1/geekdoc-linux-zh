# PERFORMING A STAGED INSTALLATION OF AN RDC

In addition to doing a full installation of the Active Directory service, Windows also supports a **staged installation**. A staged installation installs the Active Directory service and the Active Directory database on a domain controller, but does not create the Active Directory forest or domain.
