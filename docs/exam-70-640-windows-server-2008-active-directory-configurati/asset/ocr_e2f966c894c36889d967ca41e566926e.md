# Part D – Enable Secure Connections to the CA IIS Server

+   1.  In the left pane of IIS Manager, expand the **Sites** node.
+   2.  Right-click **Default Web site** and click **Edit Bindings**. The Site Bindings screen is displayed.

+   4.  In the **Type** dropdown box, select **https**. In the **SSL Certificate** dropdown box, select **ca.lucernepublishing.com**, as shown in Figure 13-10.
