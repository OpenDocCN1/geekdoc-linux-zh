## 使用 Mac OS X 或 Linux 终端连接

打开一个新的终端窗口并输入以下命令：

```bash
$ ssh -i jeffskeys.pem root@ec2-nnn-nnn-nn-nnn.compute-1.amazonaws.com
```

将 **jeffskeys.pem** 替换为您自己的密钥对文件，并将 *ec2-nnn-nnn-nn-nnn* 替换为您的实例的公共 DNS 名称。您将收到以下响应：

```text
The authenticity of host 'ec2-nnn-nnn-nnn-nnn.compute-1.amazonaws.com (nnn.nnn.nnn.nnn)' can’t be established.
RSA key fingerprint is cd:79:eb:e3:e9:2e:d6:d2:9c:79:65:2a:27:c5:__1b:ba.
Are you sure you want to continue connecting (yes/no)?
```

当然，主机信息和 RSA 密钥指纹细节将与上述不同。如果您对上面的问题回答 **yes**（是），您将登录成功并收到以下输出：

## 现在我们已经连接上了

恭喜，您现在完全掌控了您自己的 EC2 实例！如果您计划启动不止一个 EC2 实例，您应该确保通过使 shell 提示符更具区分度来区分它们。以下是如何将 shell 提示符设置为字符串 `<dev>:` 以表明 shell 位于开发（而非生产）服务器上：

```bash
[root@domU-12-31-38-00-2E-18 ~]# export PS1="<dev>: "
```

运行以下命令以查看哪些软件包已经安装：

```bash
<dev>: yum list | grep installed
```

您应该看到一个很长的列表。请随意花些时间探索您的新 EC2 实例。尝试您最喜爱的 Linux 命令，并验证它们是否按预期工作。您可以使用 yum 命令安装新的软件包。如果您更喜欢 emacs 而不是 vim，请像这样安装它：

```bash
<dev>: yum -y install emacs
```

如果您决定在此处暂停，请记住您的实例现在正在运行，并且您正在按小时支付费用。如果没有必要保持其运行状态，请返回 AWS 管理控制台，选择该实例，并从 *实例操作* 菜单中选择 **终止**。这样做时，实例上存储的所有数据都将丢失。

如果您启动的是基于 EBS 的 AMI，您有一个额外的选项。您可以从 **实例操作** 菜单中选择 **停止**。操作系统将干净地关闭，实例的状态将变为 *stopped*（已停止）。稍后，您可以选择再次启动实例，它将启动且根文件系统上的所有文件保持完好。这种额外的灵活性是偏好基于 EBS 的 AMI 而非其较旧的基于 S3 的 AMI 的众多原因之一。

## 分配 IP 地址

让我们给这个实例分配一个永久的专属 IP 地址。使用 `exit` 命令关闭您的 SSH 会话，然后返回 AWS 管理控制台。在 *导航* 窗格中点击 **弹性 IP**，然后按下 **分配新地址** 按钮。在对话框中按下 **是，分配** 按钮以确认您希望分配一个新的 IP 地址。经过非常短暂的停顿后，您新分配的地址将列在 **地址** 列表中。

此时该地址属于您，但尚未与任何特定的 EC2 实例关联。让我们来解决这个问题。点击列表中的地址以选中它，然后按下 **关联** 按钮，这将弹出如图 5.14 所示的对话框。

![](img/4a5ba0dd041e08e6a67fa31d52309995_148_0.png)

在菜单中选择适当的实例 ID，然后按对话框中的 **关联** 按钮。现在使用弹性 IP 地址而不是主机名创建一个新的 SSH 会话。如果您碰巧有一个空闲的域名和一个 DNS 提供商，您可以将该域名映射到公共 IP 地址。

请记住，您会被收取已分配但未映射的 IP 地址的费用。如果您决定终止您的实例且不再需要该 IP 地址，请务必使用 AWS 管理控制台释放它。

## 创建 EBS 卷

既然您已经有了一个实例和一个 IP 地址，让我们创建、附加并格式化一个存储卷。

创建完成后，您可以将 EBS 卷附加到与该卷位于同一可用区中的任何实例。由于我们的实例已经在运行，让我们看看它运行在哪个区域。返回 AWS 管理控制台，并选择 **实例** 视图。点击您的实例所在行，并检查底部显示的详细实例属性，如图 5.15 所示。

![](img/4a5ba0dd041e08e6a67fa31d52309995_149_0.png)

我的实例在区域 `us-east-1a` 中。在 **导航** 窗格中点击 **卷**，按下 **创建卷** 按钮，您将看到如图 5.16 所示的对话框。

![](img/4a5ba0dd041e08e6a67fa31d52309995_149_1.png)

该对话框表单接受以 **GiB**（吉字节）和 **TiB**（太字节）为单位的值。这些是更常见的十进制单位吉字节（GB）和太字节（TB）的对应二进制单位，后者代表 10 的幂。1 GiB 是 1,073,741,824 字节，而 1 GB 是 1,000,000,000 字节。

输入所需的卷大小（10GiB 是一个很好的值）并选择您的实例的可用区。保持其他字段不变，按下 **创建** 按钮。新卷将出现在 EBS 卷列表中，状态为 **creating**（创建中）。等待几秒钟，按下 **刷新** 按钮，状态应变为 **available**（可用）。

现在选择该卷并按下 **附加** 按钮（或右键点击并选择 **附加卷**），以显示如图 5.17 所示的附加卷对话框。

![](img/4a5ba0dd041e08e6a67fa31d52309995_150_0.png)

图 5.17. 将 EBS 卷附加到 Amazon EC2 实例

选择您的实例，记录 **设备** 字段中的值，然后按下 **附加** 按钮。刷新 EBS 卷列表，直到 **附加信息** 列中包含单词“attached”（已附加）。

此时，新的 EBS 卷已附加到您的实例，但尚未准备好存储文件。转到您的 SSH 会话，并为新附加的卷建立文件系统：

```bash
<dev>: mkfs -F /dev/sdf
```
