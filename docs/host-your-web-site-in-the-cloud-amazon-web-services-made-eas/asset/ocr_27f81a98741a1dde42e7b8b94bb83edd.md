Let’s create a Single-AZ DB Instance using the Launch DB Instance Wizard. Click on **DB Instances** in the **Navigation** area, and then click on the **Launch DB Instance** button. Fill in the first page of the wizard as shown in Figure 9.3.

![](bbox=[0.16, 0.2, 0.8, 0.58])

Leave the **DB Instance Class** and the **Multi-AZ Deployment** values as they are. Enter 5GB for the **Allocated Storage**, set the **DB Instance Identifier** to mydb, set the **Master User Name** to dbuser, and set the **Master User Password** to dbpass. Press the **Continue** button, and fill in the second page of the wizard as in Figure 9.4.
