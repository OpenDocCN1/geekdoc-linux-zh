# Installing and Running JMeter

JMeter 9 is a free, open source program. Download the binary file and choose a di- rectory so that the resulting path will exclude any spaces. 10

Now go into the **bin** subdirectory of the installation directory and run `jmeter` if you’re on Mac OS X or Linux; **jmeter.bat** if you’re on Windows. On Windows it’s best to run the batch file from a command because some of JMeter’s reports (also known as listeners) will produce their output there.
