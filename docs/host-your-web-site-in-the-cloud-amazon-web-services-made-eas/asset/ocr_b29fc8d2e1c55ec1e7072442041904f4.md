```
$minimums[$i] = (int) ($minimums[$i] * $scale);
$maximums[$i] = (int) ($maximums[$i] * $scale);
$sums[$i]	= (int) ($sums[$i]		* $scale);
}
```

The chart API accepts the data values for each line in the chart as a comma-separated string. The values for the lines are separated by the pipe or vertical bar character. Here’s the code to set this up:

```
chapter_07/statistics_chart_page.php (excerpt)

$average = implode(',', $averages);
$minimum = implode(',', $minimums);
$maximum = implode(',', $maximums);
$sum	= implode(',', $sums);

// Combine arrays for use in chart
$series = $average . '|' .
		$minimum . '|' .
		$maximum . '|' .
		$sum;
```
