```
$ as-update-auto-scaling-group AutoScale --min-size 0 --max-size 0
```

Now, watch for a scaling activity that actually terminates the instances. Run this command:

```
$ as-describe-scaling-activities AutoScale
```

Run it a couple of times over the course of a minute or two, until you see an entry like this:

```
ACTIVITY fb0aa624-6480-4da8-99d0-40c9135c20be 2009-07-25T05:47:14Z
➡ Successful "At 2009-07-25 05:45:32Z a user request update of AutoScalingGroup constraints to min: 0, max: 0 changing the desired capacity from 1 to 0. At 2009-07-25 05:45:33Z an instance was terminated in response to a difference between desired and actual capacity, shrinking the capacity from 1 to 0. At 2009-07-25 05:45:33Z instance i-9f9f9fff6 was selected for termination."
```

Now you can go ahead and delete the group (as usual, you'll be asked to confirm):

```
$ as-delete-auto-scaling-group AutoScale
```

Finally, delete the load balancer:

```
$ elb-delete-lb LoadBal
```

And we're done!
