+   There’s no charge for the zone-to-zone data transfer that occurs as part of a Multi-AZ deployment.

+   There’s no charge for data transfer between an EC2 Instance and a DB Instance in the same Availability Zone.

+   Data transferred into Amazon RDS that *isn’t* coming from an EC2 Instance is charged at $0.10 per GB.

+   Data transferred *out* of Amazon RDS that isn’t going to an EC2 Instance is charged on a sliding scale that starts at $0.15 per GB.
