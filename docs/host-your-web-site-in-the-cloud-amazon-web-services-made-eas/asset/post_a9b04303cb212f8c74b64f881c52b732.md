
## 程序化弹性负载平衡

与所有Amazon Web服务一样，您可以通过编程接口访问弹性负载平衡功能。

然而，不幸的是，CloudFuse目前（截至2.5版）并不支持弹性负载平衡。

话虽如此，您可以通过创建一个基于EC2类的新类来添加支持。关于如何执行此操作的详细信息超出了本书的范围，但如果您想尝试这项任务，您需要一些基本信息：`DEFAULT_URL` 是 elasticloadbalancing.amazonaws.com，API版本是 2009-05-15。

有九个弹性负载平衡 API 调用：

- `CreateLoadBalancer` 创建新的负载均衡器，`DeleteLoadBalancer` 删除旧的。
- `ConfigureHealthCheck` 设置一个非默认的健康检查，该检查将用于所有实例。
- `RegisterInstancesWithLoadBalancer` 将一组EC2实例附加到负载均衡器，而 `DeregisterInstancesFromLoadBalancer` 则执行相反操作。
- `DescribeLoadBalancers` 返回有关每个现有负载均衡器的详细信息，而 `DescribeInstanceHealth` 返回所有或选定的EC2实例的健康状况。
- `EnableAvailabilityZonesForLoadBalancer` 允许负载均衡器访问其他可用区中的实例，而 `DisableAvailabilityZonesForLoadBalancer` 则实现相反功能。

现在您已经知道如何使用一些简单的命令来创建、监视和销毁弹性负载均衡器，您离创建高度可扩展和高可用性的应用程序就更近一步了。

## 自动扩展

在本节中，您将了解Amazon EC2的自动扩展功能。我们将回顾关键术语和概念，讨论定价，然后使用命令行工具对其进行测试。我们将再次回顾编程模型，而将实际代码留给您完成。

## 自动扩展概念

您可以使用EC2的自动扩展功能在任何EC2区域中创建自动扩展组。每个自动扩展组都有一个引用名称，可以跨越一个或多个可用区。自动扩展组依赖于启动配置来提供启动EC2实例所需的信息。附加到组的触发器提供启动扩展活动所需的信息。每次自动扩展组启动或终止EC2实例时，都会生成一个**扩展活动**。实例作为**扩展事件**的一部分添加，作为**缩减事件**的一部分终止。每个组还有一个最小大小和一个最大大小。

**自动扩展启动配置**包括AMI ID、EC2密钥对的名称、一组EC2安全组、EC2实例类型以及启动EC2实例所需的其他信息。

自动扩展触发器引用CloudWatch指标，例如EC2 CPUPutilization或弹性负载平衡 HealthyHostCount。触发器还包括上下阈值和扩展增量。扩展增量可以是绝对的（“添加1个实例”）或相对的（“添加50%的实例”）。触发器的违约持续时间指定了评估触发器阈值与指标之间的时间段。

## 自动扩展处理模型

尽管自动扩展独立于弹性负载平衡，但这两个功能被设计为相辅相成，以便您轻松地将大量请求负载平衡到自动扩展的EC2实例集群上。一旦设置好一切，您可以将所有流量路由到负载均衡器，AWS将处理其余部分。

自动扩展处理模型清晰易懂。首先，创建以下内容：

1. 为一个或多个可用区创建一个弹性负载均衡器
2. 创建启动配置，指定要启动的AMI ID、实例类型和其他所需参数
3. 为所需的可用区组创建一个自动扩展组，提供负载均衡器和启动配置的名称、每个组所需的最大和最小尺寸，以及组的引用名称
4. 为组创建一个触发器

然后坐下来放松，让自动扩展过程确保您拥有满足应用程序需求（如组大小和触发器所示）的足够数量的EC2实例。

一旦自动扩展组正常运行，其工作原理如下：

1. 使用触发器中的参数（Namespace, Dimension, Measure, Statistic, 和 Unit）获取组触发器中指定的CloudWatch指标，时间范围回溯到触发器的BreachDuration值。
2. 将指标与触发器的阈值进行检查。如果指标大于UpperThreshold，且组中的EC2实例数量小于MaxSize，则启动扩展事件。使用组的启动配置参数启动一个或多个EC2实例。启动实例的数量取决于触发器的UpperBreachScaleIncrement。如果此参数的值以百分号（“%”）结尾，则启动足够的实例以提高组中实例总数的该百分比。否则，该值用作要启动的实际实例数量。新实例自动添加到与组相关的负载均衡器（如果有）。

类似地，如果指标小于LowerThreshold，且组中的实例数量大于MinSize，则启动缩减事件。使用组的启动配置参数终止一个或多个EC2实例。终止实例的数量取决于触发器的LowerBreachScaleIncrement，它可以是百分比值或数字。在这两种情况下，数值都应为负数。多余的实例在终止前从负载均衡器（如果有）中移除。

在扩展或缩减事件之后，在组的冷却期过去之前，不会触发进一步的自动扩展操作。所有扩展和缩减事件都会记录在案，并可供后续分析。
