There’s a couple of interesting points in the code above:

+   1. This template iterates over the $fileList array, adding a table row for each element of the array, and a table cell for the thumbnail image, the filename, and file size.
+   2. The contents of the thumbnail table cell are only added if there’s a thumbnail URL specified for that file, otherwise the cell is left empty.
