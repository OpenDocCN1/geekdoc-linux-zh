# Asynchronous Messaging Patterns

In this section, we'll take a look at some effective ways to decompose a complex processing system by using a series of processes connected to each other with message queues.

The first pattern is the linear processing pipeline. The first process passes work onto the second using a single queue, as depicted in Figure 6.1.

![](bbox=[0.42, 0.28, 0.56, 0.48])

Figure 6.1. A linear processing pipeline

This pattern decouples Process 1 and Process 2, so that they can make progress independently. If Process 1 produces more results than Process 2 can absorb, they simple accumulate in Queue 1. If Process 2 has no work to do it simply idles, checking the queue for new work from time to time. This is a good starting point, but what if there is so much work to do that Process 2 is unable to keep up, and the size of the queue keeps on growing? The easiest solution is to simply start an additional copy of Process 2, as shown in Figure 6.2.
