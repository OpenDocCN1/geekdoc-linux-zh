# ## Listing Domains

The next step is to list the domains. Here's how to do that:

```
chapter_08/list_domains.php (excerpt)
# !/usr/bin/php
<?php
error_reporting(E_ALL);
require_once('cloudfusion.class.php');
$db = new AmazonSDB();
$res = $db->list_domains();
if (!$res->isOk())
{
exit("List domain operation failed\n");
}
foreach ($res->body->ListDomainsResult->DomainName as $domainName)
{
print($domainName . "\n");
}
exit(0);
?>
```

The `list_domains` method returns an array of domain names. The code iterates through the list and prints each one.

Here's the output from the command:

```
$ php list_domains.php
feed_items
feeds
files
```
