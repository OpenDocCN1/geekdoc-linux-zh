Next, we have to assemble an array of items ($itemCat) that match the city and state specified. If no city or state are specified, the array will be empty. We also reorganize the array so that the items are categorized by their category value:

```
```php
$itemCat = array();
if ($CurrentCity != '' && $CurrentState != '')
{
    $items = getItems($Sdb, $City, $state);
    foreach ($items as $Key => $attrs)
    {
        $Category = $attrs['Category'];
        if (!IsSet($itemCat[$Category]))
        {
            $itemCat[$Category] = array();
        }
        $itemCat[$Category][$Key] = $attrs;
    }
}
