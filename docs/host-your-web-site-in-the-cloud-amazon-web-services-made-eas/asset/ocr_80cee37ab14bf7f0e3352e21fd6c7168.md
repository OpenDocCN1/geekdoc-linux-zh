# ## EC2 Regions in CloudFusion

At the time of writing, the current version of CloudFusion (2.5) has limited support for EC2 Regions other than the default (us-east-1). Should you experience problems running any of the code in the book, it's worth trying it again using instances in the us-east-1 Region. CloudFusion 2.6 is expected to fix many of these issues, and it should be released in the near future. If it's already available by the time you read this, then some of the code may require modification to take advantage of these new features; this should be easy to do with a quick pass through the documentation pertaining to the methods in question.
