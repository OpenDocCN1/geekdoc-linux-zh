Let's take a closer look:

+   First, we check to see if there are any arguments supplied; if there are none we display a helpful usage message and exit the script.

+   This program expects the first argument to be a bucket name. If the bucket name is a dash character (-), the default bucket (BOOK_BUCKET) is used instead.

+   The remaining arguments are considered to be the files to upload. We then loop through all the inputted filenames.

+   Within each loop we call our uploadObject function. I chose to use the path name to each object exactly as supplied, to enable usage of key names with embedded slash characters.
