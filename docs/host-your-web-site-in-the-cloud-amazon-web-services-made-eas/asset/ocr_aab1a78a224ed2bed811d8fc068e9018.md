This script accepts queue names on the command line, creates a new AmazonSQS object, calls the create_queue method for each queue name, and prints some helpful messages. Here’s an example of the output:

```
$ php create_queues.php A B C
Created queue 'A'
Created queue 'B'
Created queue 'C'
```

If the queue is unable to be created, the error message is extracted from the returned data and then printed.

Creating a queue that already exists does not raise an error and will have no effect on the queue in any way.

require_once('cloudfusion.class.php');

$res = $sqs->list_queues();
