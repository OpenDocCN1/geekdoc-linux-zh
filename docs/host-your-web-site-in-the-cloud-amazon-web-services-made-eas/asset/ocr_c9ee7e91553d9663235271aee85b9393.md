```
    }
    print("\n");
}
```

The $s3ImageKeys array stores all the keys to our thumbnails, so we test that the number of thumbnail keys matches the number of images we’re processing. If they match it means we’ve successfully processed all the images, and the message for this site can be sent to the next queue. If the message is successfully sent to the next queue, the message in the image-fetching queue can be deleted.

Our crawler is now three-quarters complete; there’s just one more stage left.
