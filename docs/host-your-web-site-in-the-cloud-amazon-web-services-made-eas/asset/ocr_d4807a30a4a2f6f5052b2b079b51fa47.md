# # Creating a Test Plan

The next step is to create a JMeter test plan. The test plan specifies the number of parallel threads to run, the HTTP requests to make in each thread, and a disposition for the results.

Here's how to create a simple test plan:

+   1. Right-click on the **Test Plan** node and choose **Add > Threads (Users) > Thread Group**.
+   2. Configure the thread group with four threads, a ramp-up period of ten seconds, and a loop count of 16.
+   3. Right-click on the new Thread Group node and choose **Add > Sampler > HTTP Request**.
+   4. Enter your server host name or IP address (mine is www.captaincloud.com—omit the http:// protocol prefix) and port (80 should be fine).
+   5. Enter “/” for the path to retrieve the home page from the site.
+   6. Repeat the previous step for other pages on the same server. And enter a different name for each one.
+   7. Right-click on the **Test Plan** node once again. Add the following listener nodes: **Generate Summary Results**, **Aggregate Report**, and **Graph Results**.
