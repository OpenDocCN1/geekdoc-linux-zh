For a more complete list of ways to spell <commit>, see “SPECIFYING REVISIONS” section in (7). However, “diff” is about comparing two *endpoints*, not ranges, and the range notations (“<commit>..<commit>” and “<commit>...<commit>”) do not mean a range as defined in the “SPECIFYING RANGES” section in (7).

```
git diff [options] <blob> <blob>
```

This form is to view the differences between the raw contents of two blob objects.
