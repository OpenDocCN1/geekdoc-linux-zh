properly terminated with a new line, just as the “oneline” format does. For example:

```
$ git log -2 --pretty=format:%h 4da45bef \ | perl -pe '$_ .= "—NO\n' unless /^\n/' 4da45be 7134973—NO NEWLINE $ git log -2 --\n pretty=tformat:%h 4da45bef \ | perl -pe '$_ .= "—NO NEWLINE\n' unless\n/^\n/' 4da45be 7134973
```

In addition, any unrecognized string that has a % in it is interpreted as if it has format: in front of it. For example, these two are equivalent:

```
$ git log -2 --pretty=tformat:%h 4da45bef $ git log -2 --pretty=%h\n4da45bef
```
