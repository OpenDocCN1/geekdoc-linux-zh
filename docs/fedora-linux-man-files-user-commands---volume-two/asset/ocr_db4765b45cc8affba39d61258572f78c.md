# ## CONFIGURATION

You may specify configuration in your .git/config

```
```
[instaweb] local = true httpd = apache2 -f port = 4321 browser =
konqueror modulePath = /usr/lib/apache2/modules
```
```

If the configuration variable *instaweb.browser* is not set, *web.browser* will be used instead if it is defined. See (1) for more information about this.
