# NON-BUGS

```
$ find . -name *.c -print
find: paths must precede expression Usage: find
[-H] [-L] [-P] [ -01evel] [-D help|tree|search|stat|rates|opt|exec] [path...]
[expression]
```

This happens because `*.c` has been expanded by the shell resulting in **find** actually receiving a command line like this: `find . -name bigram.c code.c frcode.c locate.c -print` That command is of course not going to work. Instead of doing things this way, you should enclose the pattern in quotes or escape the wildcard: `find . -name '*.c' -print` `find . -name \*.c -print`
