# SYNOPSIS

General Options:

```
foomatic-rip [-v] [-q] <mode-specific options>
```

Spooler-less printing filter:

```
foomatic-rip [-P <printer> | --ppd <ppdfile>] [-J <jobtitle>] [-o <option>=<value> [...]] [<files>]
```

CUPS filter:

```
foomatic-rip <jobid> <user> <jobtitle> <numcopies> <options> [<file>]
```
