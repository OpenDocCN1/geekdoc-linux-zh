### 22.5.3 后利用模块

### 22.5.4 使用 Metasploit Framework 进行路由扩展

在攻陷目标之后，我们可以从该系统路由到其他目标。我们可以从 MSF 内部进行路由，这很方便，但缺乏手动路由技术的灵活性。

例如，让我们利用现有的 Meterpreter 会话枚举内部网络的 Active Directory 基础设施并路由到其他机器。
