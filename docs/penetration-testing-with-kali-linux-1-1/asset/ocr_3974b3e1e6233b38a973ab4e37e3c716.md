One good place to start in WordPress is the *Info* tab under the *Tools > Site Health* section.

![](bbox=[0.12, 0.14, 0.86, 0.73])

*Figure 333. Viewing the WordPress Info Page*

On this page, we can determine that the server is running WordPress using PHP version 7.0.33-OubuntuUo.16.04.7. We also find that the database is running on the 10.5.5.11 IP address, which is different than the one we are currently targeting. This is not unusual as databases and web applications are often run on separate servers.
