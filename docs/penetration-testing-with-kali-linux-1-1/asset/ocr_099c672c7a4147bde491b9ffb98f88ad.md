# 3.6  Managing Processes

The Linux kernel manages multitasking through the use of processes. The kernel maintains information about each process to help keep things organized, and each process is assigned a number called a process ID (PID).

The Linux shell also introduces the concept of *jobs*<sup>69</sup> to ease the user's workflow during a terminal session. As an example, `cat error.txt | wc -m` is a pipeline of two processes, which the shell considers a single job. Job control refers to the ability to selectively suspend the execution of jobs
