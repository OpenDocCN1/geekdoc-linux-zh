### 6.6 Recon-ng

**recon-ng**[149] 是一个基于模块的 Web 信息收集框架。Recon-ng 将模块的结果显示在终端，但它也将其存储在数据库中。Recon-ng 的大部分威力在于将一个模块的结果输入到另一个模块中，使我们能够快速扩大信息收集的范围。

让我们使用 recon-ng 来编译关于 MegaCorp One 的有趣数据。为了开始，让我们简单地运行 **recon-ng**。
