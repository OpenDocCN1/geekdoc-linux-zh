# 3.5.3 vimdiff

**vimdiff** opens vim^[^68] with multiple files, one in each window. The differences between files are highlighted, which makes it easier to visually inspect them. There are a few shortcuts that may be useful. For example:

+   * **do**: gets changes from the other window into the current one
+   * **dp**: puts the changes from the current window into the other one
+   * **]c**: jumps to the next change
+   * **[c**: jumps to the previous change
+   * **<kbd>Ctrl</kbd> <kbd>W</kbd>**: switches to the other split window.
