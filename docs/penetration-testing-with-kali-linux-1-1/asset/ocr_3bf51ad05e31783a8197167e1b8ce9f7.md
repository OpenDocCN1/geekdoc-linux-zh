# 10.1.1.1 The Stack

When a thread is running, it executes code from within the Program Image or from various Dynamic Link Libraries (DLLs). $^{292}$ The thread requires a short-term data area for functions, local variables, and program control information, which is known as the stack. $^{293}$ To facilitate independent execution of multiple threads, each thread in a running application has its own stack.

Stack memory is “viewed” by the CPU as a Last-In-First-Out (LIFO) structure. This essentially means that while accessing the stack, items put (“pushed”) on the top of the stack are removed (“popped”) first. The x86 architecture implements dedicated PUSH and POP assembly instructions in order to add or remove data to the stack respectively.
