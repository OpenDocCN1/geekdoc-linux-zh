This manual approach will work best on small repos. For larger repos, we can use several tools to help automate some of the searching, such as Gitrob$^{159}$ and GitLeaks$^{160}$. Recon-ng also has several modules for searching GitHub. Most of these tools require an access token$^{161}$ to use the source code hosting provider's API.
