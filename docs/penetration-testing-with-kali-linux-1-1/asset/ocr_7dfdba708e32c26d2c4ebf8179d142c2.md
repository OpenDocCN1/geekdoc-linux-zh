*Listing 956 - authorized_keys file entry*

The "from" IP does not have to change since the traffic is still coming from the external firewall as far as our Kali system is concerned. The ssh command we use does have to change a bit though. This time, we don't need multiple remote port forwarding options. We will only need one port forwarding option, which is **–R 1080**. By not including a host after the port, ssh is instructed to create a SOCKS proxy on our Kali server. 759 We also need to change the location of the private key.

```

```
