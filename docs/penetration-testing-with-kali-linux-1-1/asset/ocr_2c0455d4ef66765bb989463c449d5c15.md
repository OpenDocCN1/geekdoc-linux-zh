# ### 18.2.6 Windows Kernel Vulnerabilities: USBPcap Case Study

In the previous **helper.exe** example, we leveraged an application-based vulnerability to bypass UAC. When attempting to exploit system-level software (such as drivers or the kernel itself), we must pay careful attention to several factors including the target’s operating system, version, and architecture.
