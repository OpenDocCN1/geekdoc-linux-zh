# 14.2.2.4 The Metasploit Framework

Metasploit376 is an excellent framework built to assist in the development and execution of exploits. This framework is available in Kali Linux by default and can be started with the `msfconsole` command:

```
kali@kali:-$ sudo msfconsole -q

msf >
```

Listing 417 - Starting the Metasploit framework

Usage of this framework is covered in-depth in a different module so we will simply focus on listing the exploits available within the framework with the `search` command.

To demonstrate, consider this search for the popular MS08_067377 vulnerability:

```
msf > search ms08_067

================
```
