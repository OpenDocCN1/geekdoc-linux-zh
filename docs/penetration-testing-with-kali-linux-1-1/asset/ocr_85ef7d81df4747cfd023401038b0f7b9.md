# 4.5 Tcpdump

Tcpdump [106] is a text-based network sniffer that is streamlined, powerful, and flexible despite the lack of a graphical interface. It is by far the most commonly-used command-line packet analyzer and can be found on most Unix and Linux operating systems, but local user permissions determine the ability to capture network traffic.

Tcpdump can both capture traffic from the network and read existing capture files. Let’s look at what happened in the password_cracking_filtered.pcap file,[107] which was captured on a firewall.
