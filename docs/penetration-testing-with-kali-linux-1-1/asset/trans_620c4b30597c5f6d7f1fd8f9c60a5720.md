**列表 179 - 从 searchsploit 的输出中提取 URL**

这看起来好一些了。现在我们已经有了每个利用工具的 URL，我们可以使用 Bash 循环来下载文件并将其保存为本地文件。然而，在此之前，我们注意到每个页面都有一个链接可以下载“原始”利用工具代码，而这正是我们真正想要的：
