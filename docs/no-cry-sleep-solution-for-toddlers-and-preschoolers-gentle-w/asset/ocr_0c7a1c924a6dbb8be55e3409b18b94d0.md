# Network Talk and Messenger Clients: ICQ, IRC, AIM, and Talk

You may, at times, want to communicate directly with other users on your network. You can do so with Talk, ICQ, instant messenger, and IRC utilities, provided the other user is also logged into a connected system at the same time (see Table 15-2). The Talk utility operates like a telephone, enabling you to have a direct two-way conversation with another user. Talk is designed for users on the same system or connected on a local network. ICQ (I Seek You) is an Internet tool that notifies you when other users are online and enables you to communicate with them. ICQ works much like an instant messenger. With an Internet Relay Chat utility (IRC), you can connect to a remote server where other users are also connected
