<IfDefine HAVE_SSL>

# Server Certificate:

SSLCertificateKeyFile /etc/httpd/conf/ssl.key/server.key

#SSLCAcertificatePath /etc/httpd/conf/ssl.crt

In the /etc/httpd/conf directory, mod_ssl will set up several SSL directories that will contain SSL authentication and encryption keys and data. The ssl.crt directory will hold certificates for the server. The ssl.key directory holds the public and private keys used in authentication encryption. Revocation lists for revoking expired certificates are kept in ssl.crl. The ssl.csr directory holds the certificate signing request used to request an official certificate from a certificate authority. ssl.pfm holds parameter files used by the DSA key encryption method. Check the README files in each directory for details on the SSL files they contain.

The mod_ssl installation will provide you with a demonstration certificate called snakeoil that you can use to test your SSL configuration. When you have an official certificate, you can install it with the make certificate command within the ssl.crt directory. This will overwrite the server.crt server certificate file.
