

你可以使用CTRL-Z键挂起并停止一个作业。这会将作业放到一边，直到重新启动它。作业并未终止；它只是保持挂起状态，直到你想继续。当你准备好后，可以使用`fg`或`bg`命令在前台或后台继续该作业。`fg`命令在前台重新启动挂起的作业。`bg`命令将挂起的作业放到后台。

有时，你可能需要将当前在前台运行的作业放入后台。但是，你不能直接将正在运行的作业移动到后台。你首先需要用CTRL-Z挂起它，然后用`bg`命令将其放入后台。在下一个示例中，当前用于列出并重定向`.c`文件的命令首先用CTRL-Z挂起，然后将该作业放入后台。

```
$ cat *.c > myprogs
^Z
$ bg
```

## Shell 变量

前面描述的Bash、Korn和Z shell实际上是不同类型的shell。根据定义，shell是一种解释性环境，你可以在其中执行命令。你可以同时运行多个环境，这些环境可以是相同类型的shell，也可以是不同类型的shell。这些解释性环境被称为shell。因此，你可以同时运行多个Bash类型的shell。

在每个shell中，你可以输入并执行命令。你可以使用shell变量进一步增强shell的能力。使用shell变量，你可以保存数据，以便在给定shell中执行不同命令时反复引用。例如，你可以定义一个shell变量来保存复杂文件名。与其在不同命令中重新输入文件名，不如用shell变量引用它。

你在shell中定义变量，这些变量称为shell变量。存在许多不同的shell。某些实用程序（如Mail实用程序）有自己的shell和相应的shell变量。你也可以使用所谓的shell脚本创建自己的shell。你有一个用户shell，一旦登录它就会激活。这通常称为登录shell。在此登录shell中定义了特殊的系统变量。shell变量还可以用于定义shell的环境，如第9章所述。

> 注意：只要你的shell处于活动状态，shell变量就存在——也就是说，直到你退出shell。例如，注销将退出登录shell。当你再次登录时，你可能需要在登录shell中使用的任何变量都必须重新定义。

## 变量的定义与求值：=、$、set、unset

当你在shell中首次使用变量名时，就定义了一个变量。变量名可以是任意一组字母字符，包括下划线。名称也可以包含数字，但数字不能是名称中的第一个字符。名称不能包含任何其他类型的字符，例如感叹号、与号（&）甚至空格。这些符号被shell保留供其自身使用。此外，变量名不能包含多个单词。shell使用命令行上的空格来区分命令的不同组成部分，如选项、参数和命令名称。

使用赋值运算符`=`为变量赋值。你输入变量名、赋值运算符，然后输入要赋的值。不要在赋值运算符周围放置任何空格。例如，赋值操作`poet = Virgil`将失败。（C shell的赋值操作类型略有不同。）你可以将任意字符集赋给变量。在下一个示例中，变量`poet`被赋值为字符串`Virgil`：

```
$ poet=Virgil
```

一旦你为变量赋值，就可以使用变量名来引用该值。你通常会将变量的值用作命令的参数。你可以使用变量名前加`$`运算符来引用变量的值。美元符号是一个特殊运算符，它使用变量名来引用变量的值，实际上就是求变量的值。求值会获取变量的值，通常是一组字符。这组字符随后替换命令行上的变量名。只要在变量名前加上`$`，变量名就会被替换为变量的值。在下一个示例中，shell变量`poet`被求值，其内容`Virgil`随后用作`echo`命令的参数。`echo`命令只是在屏幕上回显或打印一组字符。

```
$ echo $poet
Virgil
```

你必须仔细区分变量的求值结果与仅使用其名称（不求解）的区别。如果你省略变量名前的`$`运算符，那么你得到的只是变量名本身。在下一个示例中，变量名上没有`$`运算符。在这种情况下，`echo`命令的参数是单词“poet”，因此输出“poet”：

```
$ echo poet
poet
```

变量的内容通常用作命令参数。常见的命令参数是目录路径名。重复输入一个反复使用的目录路径可能会很繁琐。如果你将目录路径名赋给变量，就可以直接使用对该变量求值的结果来替代它。当使用`$`运算符对变量求值时，会检索你赋给该变量的目录路径。下一个示例将目录路径名赋给变量，然后在复制命令中使用求值后的变量。对`ldir`（即`$ldir`）求值得到路径名`/home/chris/letters`。复制命令将求值为`cp myletter /home/chris/letters`。

```
$ ldir=/home/chris/letters
$ cp myletter $ldir
```

你可以使用`set`命令获取所有已定义变量的列表。如果你决定不再需要某个变量，可以使用`unset`命令将其移除。`unset`命令会取消定义变量。
