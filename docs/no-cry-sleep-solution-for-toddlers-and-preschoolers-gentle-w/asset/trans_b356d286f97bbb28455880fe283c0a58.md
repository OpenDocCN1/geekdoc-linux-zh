## usermod

usermod命令使您能够更改这些特性中的任意值。您可以更改主目录或用户ID，甚至可以更改账户的用户名。usermod命令使用与useradd相同的选项，如表28-3所列。

## userdel

当您想从系统中移除用户时，可以使用userdel命令删除该用户的登录。使用-r选项，用户的主目录也会被删除。在下一个示例中，用户chris将从系统中被移除：

```
# userdel -r chris
```

## 管理组

您可以使用shell命令或窗口工具（如Red Hat用户管理器）来管理组。

## /etc/group和/etc/gshadow

保存组条目的系统文件称为/etc/group。该文件由组记录组成，每行一条记录，字段用冒号分隔。组记录有四个字段：组名、密码、组ID以及属于该组的用户。密码字段可以为空。组记录的字段如下：

- 组名 组的名称，必须唯一
- 密码 在实现shadow安全机制后，此字段为x，密码在/etc/gshadow文件中指明。
- 组ID 系统分配用于标识该组的数字
- 用户 属于该组的用户列表，用逗号分隔

以下是/etc/group文件中条目的示例。组名为engines，密码由shadow安全机制管理，组ID为100，属于该组的用户为chris、robert、valerie和aleina。

```
engines:x:100:chris,robert,valerie,aleina
```

与/etc/passwd文件一样，最好使用组管理工具（如groupmod、groupadd或Red Hat用户管理器）来更改组条目。所有用户对/etc/group文件都有读权限。在shadow安全机制下，密码等安全组数据保存在/etc/gshadow文件中，只有root用户才能访问。

## 用户私有组

可以将新用户分配到仅为该用户设置的、并使用该用户名称的特殊组中。因此，新用户dylan会获得一个同样名为dylan的默认组。组dylan也会出现在组列表中。这种分配默认用户组的方法称为用户私有组（UPG）方案。UPG目前用于Red Hat系统。附加组是用户可能希望加入的其他组。传统上，所有用户都被分配到一个名为users的组，这将使所有用户受到users组的组权限控制。使用UPG后，每个用户都有自己的组，并有自己的组权限。

## 组目录

与用户一样，您可以为组创建主目录。为此，只需在/home目录中为组创建一个目录，并将其组更改为该组，同时允许该组的任何成员访问。以下示例创建了一个名为engines的目录，并将其组更改为engines组：

```
mkdir /home/engines
chgrp engines /home/engines
```
