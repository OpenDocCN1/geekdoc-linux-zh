## 虚拟FTP服务器

ProFTPD守护进程可以同时管理多个FTP站点。通过proftpd.conf文件中的VirtualHost指令，您可以创建一组独立的指令来配置单独的FTP服务器。VirtualHost指令通常用于将虚拟服务器配置为FTP站点。您可以配置系统以支持多个IP地址。额外的IP地址可用于虚拟服务器，而不是独立的机器。您可以使用这样一个额外的IP地址来设置虚拟FTP服务器，从而在同一系统上获得另一个FTP站点。这个新增的服务器会将额外的IP地址作为自己的地址。远程用户可以使用该IP地址（而不是系统的主IP地址）访问它。由于这样的FTP服务器不是独立运行在单独机器上，而是位于同一台机器上，因此被称为虚拟FTP服务器或虚拟主机。此功能让您可以在一台机器上运行多个对外呈现为不同FTP服务器的服务。当远程用户使用虚拟FTP服务器的IP地址访问它时，ProFTPD守护进程会检测到该请求并作为该站点的FTP服务运行。ProFTPD可以在一台机器上同时处理大量的虚拟FTP站点。

> 注意：凭借其配置功能，您还可以将任何虚拟FTP站点定制为特定角色，例如访客站点、针对特定组的匿名站点或针对特定用户的匿名站点。

您可以通过在proftpd.conf文件中输入<VirtualHost>指令来配置虚拟FTP服务器。此类条目以VirtualHost指令和IP地址开头，以终止的VirtualHost指令</VirtualHost>结尾。放在这两者之间的任何指令都应用于该虚拟主机。对于匿名或访客站点，请添加Anonymous和Guest指令。您甚至可以为特定目录添加Directory指令。在独立配置中使用Port指令，您可以创建一个在同一系统上运行但连接不同端口的虚拟主机。

```
<VirtualHost 10.0.0.1>
    ServerName "My virtual FTP server"
</VirtualHost>
```

Xinetd和独立配置处理虚拟主机的方式有所不同。Xinetd检测到对虚拟主机的请求，然后将其转交给FTP守护进程。FTP守护进程随后检查请求中指定的地址和端口，并为相应的虚拟主机处理请求。在独立配置中，FTP守护进程持续监听所有指定端口上的请求，并在不同虚拟主机的请求进来时生成子进程来处理它们。在独立配置中，ProFTPD可以同时支持大量虚拟主机。

以下示例展示了虚拟FTP主机的示例配置。VirtualHost指令使用域名地址作为其参数。使用域名地址时，该地址必须与网络域名服务器中的IP地址关联。该IP地址又必须指向运行ProFTPD守护进程的机器。在ftp.mypics.com虚拟FTP服务器上，配置了一个名为robpics的匿名访客账户，该账户需要密码才能登录。同时还配置了一个匿名FTP账户，使用主目录/var/ftp/virtual/pics。

```
<VirtualHost ftp.mypics.com>
    ServerName      "Mypics FTP Server"
    MaxClients      10
    MaxLoginAttempts 1
    DeferWelcome    on
    <Anonymous ~robpics>
        User            robpics
        Group           robpics
        AnonRequirePassword on
    </Anonymous>
    <Anonymous /var/ftp/virtual/pics>
        User            ftp
        Group           ftp
        UserAlias       anonymous ftp
    </Anonymous>
</VirtualHost>
```
