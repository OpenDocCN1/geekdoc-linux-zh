mkdir to create a remote directory, and rmdir to remove one. Use the delete command to erase a remote file. With the rename command, you can change the names of files. You close your connection to a system with the close command. You can then open another connection if you want. To end the ftp session, use the quit or bye command.

```
ftp> close
ftp> bye
Good-bye
$
```

To transfer files to and from the remote system, use the get and put commands. The get command receives files from the remote system to your local system, and the put command sends files from your local system to the remote system.
