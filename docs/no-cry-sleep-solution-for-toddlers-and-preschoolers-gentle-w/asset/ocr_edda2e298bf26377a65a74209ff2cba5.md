# File and Directory Properties

With the Properties dialog box, you can view detailed information on a file and set options and permissions (see Figure 6-3). A Properties box has four panels: Basic, Emblems, Permissions, and Notes. The Basic panel shows detailed information such as type, size, location, and date modified. The type is a MIME type, indicating the type of application associated with it. The file's icon is displayed at the top with a text box showing the file's name. You can edit the filename in this text box, changing that name. A button at the bottom labeled Select Custom Icon will open a dialog box showing available icons you can use. You can select the one you want from that window. The Remove Custom Icon button will restore the default icon image. The Emblems panel enables you to set the emblem you want displayed for this file, displaying all the emblems available.
