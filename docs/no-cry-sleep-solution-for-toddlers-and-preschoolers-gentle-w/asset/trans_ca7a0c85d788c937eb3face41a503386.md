- **ATA/IDE/MFM/RLL 支持（设备驱动程序）** 在 ATA/IDE/MFM/RLL 支持窗口中，你可以点击“IDE、ATA 和 ATAPI 块设备”按钮打开一个窗口，在此窗口中可以选择对 IDE ATA 硬盘和 ATAPI CD-ROM 的支持。
- **SCSI 支持（设备驱动程序）** 如果你的系统上有任何 SCSI 设备，请确保 SCSI 支持窗口中的条目设置为 Yes。在此你可以启用对 SCSI 磁盘、磁带驱动器和 CD-ROM 的支持。SCSI 低级驱动程序窗口列出了 Linux 当前支持的广泛 SCSI 设备列表。请确保你拥有的设备已被选中。
- **网络设备支持（设备驱动程序/网络支持）** 网络设备支持窗口列出了网络设备支持的多个通用功能。这里有条目可打开列出特定类型网络设备支持的窗口，包括以太网（10 或 100MB）设备、令牌环设备、WAN 接口和 AppleTalk 设备。其中许多设备作为模块创建，可根据需要加载。你可以选择重建内核，将其中任何设备的支持直接内置到内核中。
- **多媒体设备（设备驱动程序）** 多媒体设备提供对各种多媒体卡以及 Video4Linux 的支持。
- **文件系统（文件系统）** 文件系统窗口列出了 Linux 可支持的不同类型文件系统。这些包括 Windows 文件系统，如 DOS、VFAT（Windows 95/98）和 NTFS，以及 CD-ROM 文件系统，如 ISO 和 UDF。网络文件系统如 NFS、SMB（Samba）和 NCP（NetWare）也包含在内，以及其他杂项文件系统如 HFS（Macintosh）。
- **字符设备（设备驱动程序）** 字符设备窗口列出了键盘、鼠标和串口等设备的特性。存在对串行和总线鼠标的支持。
- **声音（设备驱动程序）** 对于 2.4 内核，声音窗口列出了内核支持的不同声卡。选择你系统上的那一个。对于旧系统，你可能需要提供声卡使用的 IRQ、DMA 和 Base I/O。这些被编译为单独的模块，其中一些你可以选择直接包含在内核中。对于 2.6 内核，你可以选择高级 Linux 声音架构声音支持，并将其展开到特定声音设备的驱动程序（还包括已弃用的开放声音系统）。
- **蓝牙设备（设备驱动程序/网络）** 此处提供对蓝牙外设的支持，列出了 USB、串行和 PC 卡接口的驱动程序。
- **内核黑客（内核黑客）** 内核黑客窗口列出了对在内核级别工作并需要修改内核代码的开发人员感兴趣的功能。你可以让内核包含调试信息，并在崩溃时提供一定程度的控制。

设置好选项后，保存你的配置。Save And Exit 选项会覆盖你的 .config 配置文件。Store To Configuration File 选项允许你将配置保存到特定文件。

> Tip Red Hat Linux 整合了对 Native POSIX Thread Library（NPTL）的支持，NPTL 是 Linux POSIX 线程的更新版本，可更高效地使用高端处理器。尽管该功能设计为向后兼容，但某些旧模块可能不兼容，可能需要使用新内核重新编译。

# 编译和安装内核

现在配置已准备就绪，你可以编译内核。首先需要生成一个依赖树，以根据你的配置确定要编译的源代码部分。在 /usr/src/linux-2.4 中使用以下命令：

```
make dep
```

你还必须清理可能残留的上一次编译的对象文件和依赖文件。使用以下命令删除此类文件：

```
make clean
```

你可以使用多个选项编译内核（参见表 33-1）。bzImage 选项仅生成名为 bzImage 的内核文件并将其放置在 arch 目录中。对于 Intel 和 AMD 系统，你可以在 i386/boot 子目录中找到 bzImage，arch/i386/boot。对于内核源码，这将位于 /usr/src/linux-2.4/arch/i386/boot。

```
make bzImage
```

表 33-1 中的选项会创建内核，但不会创建模块——即要编译为单独模块的内核特性。要编译模块，请使用带有 modules 参数的 make 命令。

```
make modules
```

表 33-1
内核 make 命令的编译选项

| 选项 | 描述 |
|---|---|
| zImage | 创建名为 zImage 的内核文件，位于 /usr/src/linux/arch 或 arch/i386/boot 目录中。 |
| install | 创建内核并将其安装到你的系统上。 |
| zdisk | 创建内核文件并将其安装到软盘上（创建启动盘）。 |
| bzImage | 创建压缩的内核文件并命名为 bzImage。 |
| bzdisk | 创建内核并将其安装到软盘上（创建启动盘）。 |
