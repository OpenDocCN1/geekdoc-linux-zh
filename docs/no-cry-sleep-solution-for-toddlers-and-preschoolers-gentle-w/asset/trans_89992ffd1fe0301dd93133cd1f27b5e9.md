
NIS服务器。NIS服务器将其信息维护在称为映射的特殊数据库文件中。Linux版本同时支持NIS客户端和服务器。Linux NIS客户端可以通过NIS轻松连接到任何网络。

NIS客户端在大多数Linux发行版的初始安装过程中就已安装。NIS客户端程序包括ypbind（NIS客户端守护进程）、ypwhich、ypcat、yppoll、ypmatch、yppasswd和ypset。每个程序都有各自的手册页，详细说明其用法。NIS服务器程序包括ypserv（NIS服务器）、ypinit、yppasswdd、yppush、ypxfr和netgroup，同样每个程序都有自己的手册页。你可以使用service命令启动和停止ypbind客户端守护进程和ypserv NIS服务器。或者，也可以使用redhat-config-services来启动和停止NIS客户端和服务器守护进程。

```
service ypbind start
service ypserv start
```

> 注意 你可以使用Red Hat的authconfig-gtk来指定你网络上的远程NIS服务器。

## NIS服务器

在设置NIS服务器时，你有很大的灵活性。如果网络很小，可能只需要一个NIS域，为此只需一个NIS服务器。对于较大的网络，你可以将网络划分为多个NIS域，每个域都有自己的服务器。即使只有一个域，也可能需要多个NIS从服务器。对于一个NIS域，可以有一个NIS主服务器和多个NIS从服务器。从服务器可以作为备份，以防主服务器出现故障。从服务器只包含NIS主服务器上配置文件的副本。配置NIS服务器涉及以下几个步骤：

- 1. 定义NIS服务器将服务的NIS域名。
- 2. 启动ypserv守护进程。
- 3. 在/var/yp/Makefile文件中，设置任何NIS服务器选项，并指定要管理的配置文件。
- 4. 使用ypinit创建配置文件的NIS版本。

## 定义NIS域

首先必须定义NIS域名。你可以通过在/etc/sysconfig/network文件中定义NIS_DOMAIN变量，在系统每次启动时自动定义NIS域。为该变量指定你想要赋予NIS域的名称。以下示例定义名为myturtles.nis的NIS域：

```
NIS_DOMAIN=myturtles.nis
```

在首次设置服务器时，你可能希望在无需重启系统的情况下定义NIS域名。可以使用domainname命令来完成，如下所示：

```
domainname myturtles.nis
```

可以使用ypserv启动脚本启动NIS服务器：

```
service ypserv start
```

## 设置NIS服务器选项

然后编辑/var/yp/Makefile文件，选择NIS服务器将维护的配置文件，并设置任何NIS服务器选项。标准选项以及最常用的配置文件通常已经设置好了。

NIS服务器选项列在最前面。NOPUSH选项将被设置为true，表示没有NIS从服务器。如果你要为该域设置任何NIS从服务器，则必须将此选项设置为no：

```
NOPUSH = true
```

最小用户ID和组ID设置为500。这些通过MINUID和MINGID变量设置：

```
MINUID=500
MINGID=500
```

大多数发行版使用影子密码和影子组文件来加密密码和组。MERGE_PASSWD和MERGE_GROUP设置将被设置为true。NIS会将影子密码信息合并到其密码文件中：

```
MERGE_PASSWD=true
MERGE_GROUP=true
```

然后使用YPSRCDIR和YPPWDDIR变量定义NIS查找密码和其他配置文件的目录。通常，/etc目录保存你的配置文件：

```
YPSRCDIR = /etc
YPPWDDIR = /etc
```

然后列出NIS可以管理的配置文件。在这里，你会看到诸如PASSWD（用于密码）、GROUP（用于用户组）和PRINTCAP（用于打印机）之类的条目。以下展示了部分条目示例：

```
GROUP     = $(YPPWDDIR)/group
PASSWD    = $(YPPWDDIR)/passwd
SHADOW    = $(YPPWDDIR)/shadow
GSHADOW   = $(YPPWDDIR)/gshadow
ALIASES   = /etc/aliases
ETHERS    = $(YPSRCDIR)/ethers   # ethernet addresses (for rarpd)
BOOTPARAMS = $(YPSRCDIR)/bootparams # for booting Sun boxes (bootparamd)
HOSTS     = $(YPSRCDIR)/hosts
NETWORKS  = $(YPSRCDIR)/networks
PRINTCAP  = $(YPSRCDIR)/printcap
PROTOCOLS = $(YPSRCDIR)/protocols
```
