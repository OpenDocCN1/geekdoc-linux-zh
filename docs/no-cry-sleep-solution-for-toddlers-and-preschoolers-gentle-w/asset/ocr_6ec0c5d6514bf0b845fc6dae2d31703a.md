# Red Hat Documentation

Red Hat maintains an extensive library of Linux documentation that is freely accessible online (see Table 1-1). From its home page, you can link to its support page, which lists the complete set of Red Hat manuals, all in Web page format for easy viewing with any Web browser. These include the Reference Guide, the Getting Started Guide, and the Installation Guide. Tip, HOW-TO, and FAQ documents are also provided. Of particular note are the Hardware Compatibility Lists. This documentation lists all the hardware compatible with Red Hat Linux. For PC users, this includes most hardware, with few exceptions. All the Red Hat documentation is freely available under the GNU General Public License. Before installing Red Hat Linux on your system, you may want to check the online Installation guide.
