EXTRAVERSION = -2.48lean

The -2.48 corresponds to the package number (the last part of the kernel identifier: 2.4.20-2.48) and lean is what we've added to distinguish this configuration of the kernel from other configurations. Therefore, our kernel will be installed as 2.4.20-2.48lean.

7. Next, we need to create a couple of empty files and an empty modules directory associated with our kernel, as the Makefile assumes that these files will be in place. Otherwise, we will see compile-time errors.

```
# touch drivers/pci/classlist.h drivers/pci/devlist.h
# mkdir /lib/modules/2.4.20-2.48lean
```
