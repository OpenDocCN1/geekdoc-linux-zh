# ## Logging In

In the login screen, you'll be prompted for a username. Type the username you created earlier on. Here, I'll use the **sandipb** account I created a few pages back:

![](bbox=[0.35, 0.17, 0.64, 0.28])

Then you'll be prompted for the password for your user account – enter that too. This will start up the desktop. The default desktop in Red Hat Linux 9 is the **GNOME** desktop. You'll see a user interface like the one shown below, with icons in the top-left corner, and a panel at the bottom:

![](bbox=[0.19, 0.38, 0.82, 0.74])

That's it! The installation is complete, and you're ready to start using the graphical user interface to start making the most out of your Red Hat Linux 9 operating system. We'll begin to explore it in the next chapter.
