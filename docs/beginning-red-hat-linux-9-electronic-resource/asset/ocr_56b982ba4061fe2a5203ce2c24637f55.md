# ## Creating a Group

Groups are useful when we need to treat a number of different users the same way. For example, if we want to grant a group of users access to a particular file or directory, we add the users to a group and grant the permission to the group (instead of to the individual user accounts). We'll see more of this later, but first we need to see how to create a group.

We have some user accounts for some of the authors on this book. Let's create a group called authors, and then we'll add these accounts to that group.
