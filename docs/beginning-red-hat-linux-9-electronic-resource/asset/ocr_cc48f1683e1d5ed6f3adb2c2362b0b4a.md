# ### Using a Program

Once you have understood how to use a program, you can execute it from the terminal. In time, you might find it more convenient to use the terminal rather than the **Main Menu**. In that case, you might need to know the program names that correspond to the menu items – so here’s a trick that allows you to do that easily:

+   1. Find the menu item by clicking the **Main Menu** button and then navigate to the item in question.
+   
+   2. Don’t select the item, but right-click on it instead. In the resulting submenu, select the **Put in run dialog** option. This opens up a **Run program...** dialog with the corresponding command name in it:

![](bbox=[0.14, 0.42, 0.87, 0.7])

The screenshot above shows how this happens when we use this technique on the **Volume Control** menu option. The corresponding **Run Program** dialog shows that the CLI command to invoke this program is actually `gnome-volume-control`.
