# # Software and Configuration

So, now we’ve got our Internet connection set up, we’re ready to fire up our browser and go places! Let’s look at the tools that Red Hat Linux 9 makes available for you to do this.

# ## Web Browsers

Obviously, the most common and popular way of accessing the Internet is by using a web browser. Red Hat Linux 9 comes with the highly functional Mozilla browser installed by default. You can start it from the Panel at the bottom of your screen, by clicking on the ‘globe and mouse’ icon. Alternatively, you can type `mozilla` at the command prompt. For those of us who connect directly to the Internet, that’s it. Up pops Mozilla, helpfully set to a Welcome to Red Hat page, and you’re ready to go:

> Notice it’s actually browsing HTML pages on your local file system at the moment, rather than the web – just type `file:///` to explore your machine.
