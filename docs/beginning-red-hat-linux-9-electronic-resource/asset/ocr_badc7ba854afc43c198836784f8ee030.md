Then locate and select the service called **xinetd**, and click **Restart**. You’ll get a dialog to confirm that the restart was successful; then you can exit the tool by clicking on **Quit**.

# ## Using SWAT for the First Time

Now we can test SWAT. Open a browser on the Linux server and type in the URL http://localhost:901. You’ll be prompted for a username and password – use the system’s root username and password. Then you should see the SWAT HOME page:

Note that this page contains the index of Samba’s very comprehensive online documentation (as shown above), where you can find out much more about Samba and SWAT. There are also eight buttons listed across the top of this page, which provide access to SWAT’s various utilities:
