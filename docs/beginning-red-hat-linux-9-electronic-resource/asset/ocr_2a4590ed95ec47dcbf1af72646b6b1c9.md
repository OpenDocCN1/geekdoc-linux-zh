# ## Viewing Logs

Log files are plain text files, much like the configuration files that we have seen earlier in this chapter. You can find most of the system log files in one directory, `/var/log`, so keeping track of them is rather easy. Here are some of the more important files that you will find in this directory:

| File | Description |
| :--- | :--- |
| boot.log | Boot messages |
| cron | crond messages |
| maillog | All email-related messages |
| messages | All informational messages except for cron, mail and secure |
| secure | Secure, authentication messages |

We can use either the `cat`, `more`, or `less` utilities from the command line or the **System Logs** GUI application (by selecting **Main menu** | **System Tools** | **System Logs**) to view the contents of these plain text log files. Here is an example:
