# ## Webmin

GWCC and our sysadmin tool are definitely nice and useful applications. But now, we are about to look at the king of them all – **Webmin**. Before we even discuss what Webmin can do, you should take a look at this screenshot:

![](bbox=[0.11, 0.16, 0.88, 0.71])

Look at all of those features! Webmin, like our sysadmin application, provides a web interface to a variety of system administration tasks. For example, we can use Webmin to:

+   - Configure the Apache Web server
+   - Manipulate MySQL databases
+   - Modify Sendmail configuration
+   - Install RPM packages
+   - Set DNS client information
+   - Edit user information
