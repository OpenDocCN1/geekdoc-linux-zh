You can view the processes sorted by any of the columns on display – to do this you just click the respective column header. Here, you can see that we've sorted the processes according to their memory usage.

At the terminal, you can use the `ps` program to view the processes running in the machine in a non-dynamic way. This program can be invoked in a variety of ways, which you can learn from its man page. However, we will mention some commonly used arguments of this program.
