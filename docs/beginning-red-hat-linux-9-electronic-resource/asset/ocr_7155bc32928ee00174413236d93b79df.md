# ### Information about the Sound Card

The sound card configuration tool is `redhat-config-soundcard` (again, you can run this from the command line, or from the menu shortcut **Main Menu | System Settings | Soundcard Detection**). This program displays a simple dialog box showing the sound card detected on the system and the kernel sound driver loaded:

![](bbox=[0.32, 0.17, 0.7, 0.39])

You can test the sound configuration by using the **Play test sound** button.
