# # Chapter 1

The problem with working as root all the time is that these privileges make it very easy to accidentally delete important files that you don’t mean to delete. For this reason, it’s recommended that you create a “normal” (non-administrative) account for your personal use, and use that most of the time.

The following screen allows you to do that – you just need to choose a username and password, and (if you like) type your full name too:

![](bbox=[0.18, 0.22, 0.8, 0.48])

When you’ve done that, click **Forward** to continue.
