Sometimes, you will see code in a mixture of gray and white backgrounds, like this:

```
echo -n Deleting temporary files...
rm -f *.tmp
echo Done.
```

In cases like this, we use the gray shading to draw attention to a particular section of the code – perhps because it is new code, or it is particularly important to this part of the discussion. We also use this style to show output that is displayed in the console window.

We show commands typed at the command line, and their output, like this:

```
$ cat bookdetail.txt
Title: Beginning Red Hat Linux
ISBN: 1861-00847-3
Authors: Bhattacharya, Gundavaram, Mamone, de Mauro, Sharma, Thomas, Whiting
```

Commands that must be executed as root are shown with a # prompt, like this:

# make install
