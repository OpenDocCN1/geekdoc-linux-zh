> This application uses its own httpd web server. This is started automatically as part of the install, but for security reasons isn’t configured to run all the time (it runs only until your machine is shut down). So, before browsing to the program, you’ll need to start the server, by issuing the command /etc/init.d/httpd start from the command line.
