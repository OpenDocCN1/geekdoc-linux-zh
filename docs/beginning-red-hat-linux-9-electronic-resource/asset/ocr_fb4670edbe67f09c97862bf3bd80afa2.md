# Support for Various Audio and Video Formats

So, the xmms application can be used to play audio CDs in the same way as Gnome-CD. The real benefits come from using the application to play other audio and video formats, such as MP3s, which may exist on media other than a CD. For example, you may keep your MP3 collection on your hard disk, in which case you may use the Play Directory feature of XMMS.

> NOTE: By default Red Hat has disabled the ability for XMMS to play MP3 files; however, this capability can be reinstated and is discussed later on in this section.

You can extend the capabilities of the xmms application using plug-ins, which can be enabled and configured using the Preferences dialog. To get to the Preferences dialog, right-click on the main xmms window and select Options | Preferences:
