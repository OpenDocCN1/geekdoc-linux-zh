# Technical Operation

High-bandwidth connections typically layer the TCP/IP protocol over one of the two hardware protocols: Ethernet or PPPoE (PPP over Ethernet). In fact most of the Cable modem providers use Ethernet as the hardware protocol while DSL providers use PPPoE:
