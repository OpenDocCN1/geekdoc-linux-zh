As you can see, the folder bar makes it much easier to find your way around your local mail folders. In addition, you can use the folder bar to manage your folders – creating, deleting, moving, copying, renaming folders and so on. For example, to create a new subfolder you simply select the parent folder in the folder bar and *either* select **File | New | Folder** or right-click and select **Create New Folder**.

Evolution also provides the usual search facilities, which are very similar to those in Microsoft's Outlook. You can apply search criteria against fields held in e-mails, such as the subject or body.
