- `nmap` 是一个用于网络探索或安全审计的工具。它支持端口扫描（确定哪些主机在线）、端口技术（哪些服务可用）以及 TCP/IP 指纹（远程主机识别）。`Nmap` 还提供了灵活的目标和端口规格、诱骗扫描、TCP 序列预测、反向扫描等。来自 Redhat 8.0 RPM 的 Network Mapper 是一个扫描大型网络的实用程序，尽管它也适用于单个主机。创建 `nmap` 的口号是 TOWDI (There's More Way To It)。它是 Perl 写的，但适用于扫描器。你可能需要速度，有时你需要隐蔽。在某些情况下，可能需要绕过防火墙。不用提到由于不稳定的硬件可能会产生伪噪声，你无法用一个命令完成所有操作（UDP, TCP, ICMP 等）。你可能不同的接口。`nmap` 支持：原生 TCP（连接）扫描、TCP SYN（半开）扫描、TCP FIN（隐蔽）扫描、TCP 探测（弹回）攻击扫描、SYN/FIN（使用分片）扫描、UDP 不可达扫描、ICMP 扫描以及反向扫描。`nmap` 支持许多性能和可靠性功能，如动态时间计算、数据超时和重传、并行端口扫描、通过并行路径检测主机以及灵活的目标和端口规格。来自 Debian 3.0.0

- `nmh` 一组电子邮件处理程序。这是 `nmh` 邮件代理（读取器/发送者），一个基于命令行、强大且可扩展的邮件读取器。`nmh` 是接收和处理大量邮件的人的选择。与大多数邮件代理不同，`nmh` 不是单一程序，而是从 shell 运行的一组程序。这允许用户配合 `nmh` 协作利用 Unix shell 的全部功能。有多种前端，例如 `mh-e` (enacs 模式)、`xmh` 和 `exmh` (X11 客户端)。`nmh` 起初基于 MH 版本 6.8.3，旨在作为 MH 的（大部分）直接替换。来自 Debian 3.0.0
