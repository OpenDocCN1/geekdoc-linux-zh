
`set` 用于设置 shell 选项、设置位置参数以及声明数组。可以使用 `-o` 选项指定选项。使用 `-A` 选项可以使用输入的参数定义数组。`-A` 将显示所有数组。`-o` 或 `-A` 选项都不用于设置位置参数。在不带参数的情况下，所有 shell 变量的名称和值将打印到标准输出。如果仅带 `+` 参数，将打印所有变量的名称。

## `setopt` [+options] [name ...]

`setopt` 用于设置 Z shell 选项。你可以使用选项名称或选项缩写进行设置。不带参数时，`setopt` 列出当前设置的选项。选项名称的大小写敏感，但忽略下划线。使用 `-m` 选项，你可以指定一个模式，设置匹配该模式的所有选项。

## `shift` [n] [name ...]

如果提供了参数 `n`，`shift $1` 会重命名位置参数，使得参数 `n+1` 变为 `$2`，以此类推。参数 `n` 及之前的将被取消。如果 `n` 为 0，则不更改任何参数。如果没有参数，假设 `n` 为 1。参数必须是非负数。如果你指定 shell 数组的名称，则该数组的元素将被移动。

## `suspend`

`suspend` [-f]

此命令暂停 shell 的执行，直到接收到 `SIGTST` 信号。如果你在登录 shell 中执行此命令，应该使用 `-f` 选项来抑制 shell 的抱怨；直接挂起即可。

## `test`

```
test value -option value
test string = string
```

`test` 命令包含在 Z shell 中是为了兼容。通常使用 `[[` 命令来求值表达式。两者可以使用相同的操作符。`[[ ]]` 命令处理表达式的方式与 `test` 命令非常相似。`test` 命令将比较两个值，如果比较成功，则返回退出状态 `0`。通过 `test` 命令，你可以比较整数、字符串，甚至进行逻辑操作。该命令由 `test` 后面跟随要比较的值组成，并由一个指定比较类型的选项隔开。该选项可以被视为运算符，但与其他选项一样，它是带有减号和字母代码的。例如，`-eq` 是表示相等比较的选项。然而，有两个字符串操作实际上使用的是操作符而不是选项。当你比较两个字符串是否相等时，使用等号 `=`。对于不相等，使用 `!=`。有关不同选项的列表，请参见第 1 章中的 `test` 命令。

## 144 Z Shell 命令

在下面的示例中，用户比较两个整数值以查看它们是否相等。在这种情况下，你需要使用相等选项 `-eq`。通过检查 `test` 命令的退出状态来找到测试操作的结果。shell 特殊变量 `$?` 保存了最近执行的 Linux 命令的退出状态。

```
$ num=5
$ test $num -eq 10
$ echo $?
```

你可以使用中括号而不是使用关键字 `test` 来执行 `test` 命令。命令 `test $greeting = "hi"` 可以写为：

`[[ $greeting = "hi" ]]`

同样，测试命令 `test $num -eq 10` 可以写为：

`[[ $num -eq 10 ]]`

括号本身必须被空白字符包围：一个空格、制表符或硬回车。如果没有空格，它将是非法的。

## `trap`

```
trap [argument] [sigspec]
```

`trap` 指定当 shell 接收到由 `sigspec` 指定的系统信号时，读取并执行此处列出的作为参数的特定命令。信号可以是 `<signal.h>` 中定义的信号名称，也可以是信号数字。如果 `sigspec` 为 `EXIT` (0)，则在退出 shell 时执行命令参数。如果为该信号没有列出命令参数，则该信号被重置。

`trap` 命令本身在不带参数的情况下，会显示与每个信号号关联的命令列表。带有参数和信号号时，它指定了在该信号发生时执行的命令。信号可以是数字也可以是名称。`-` 参数将所有信号重置为它们的默认值。如果参数为空字符串，shell 将忽略信号参数中指定的信号。

如果信号参数为 `ZERR`，则在每个退出状态为非零的命令后执行命令参数。如果是 `DEBUGL`，则在每个命令后执行。如果信号参数为 `0` 或 `EXIT` 且在函数内部执行，则在函数结束时执行该命令。如果在函数外部为 `0` 或 `EXIT`，则在 shell 终止时执行该命令。

## `type`

`type` 显示详细报告，说明如果将每个参数作为命令名称使用，它将如何被解释。

## `typeset`

```
typeset [+LRZ] [name=value] ...
```

`typeset` 用于设置变量的属性。不带参数时，`typeset` 列出所有定义的变量。带有选项，它可以更改变量的行为。带有名称和值，它可以设置变量的值。`-p` 选项显示变量定义。`-v` 选项仅显示名称。`-n` 选项仅显示值。`-a` 选项显示变量的属性。

## `while`

```
while Linux command
  do
    commands

```

`while` 循环重复命令。`while` 循环以关键字 `while` 开始，后跟一个 Linux 命令。关键字 `do` 紧随下一行。循环的结束由关键字 `done` 指定。

在 `while` 结构中使用的 Linux 命令通常是用括号括起来测试命令。在接下来的示例 `myname` 脚本中，你被要求输入一个名称。然后会打印出该名称。通过使用测试命令的括号形式再次测试变量的值来控制循环。

## `myname`

```
again=yes
while [ "$again" = yes ]
  do
```

## ZSH-Shell 配置

Z shell 有多种初始化文件、许多配置变量以及各种 shell 选项。初始化文件与 `BASH` 和 `TCSH` shell 中的文件相似，其中一个被称为 `.zshenv`。shell 配置变量也与 `BASH` 和 `TCSH` shell 中的非常相似。Z shell 有一系列广泛的选项来配置你 shell 的许多方面。

## ZSH 初始化文件

系统首先读取系统 `/etc/zshenv` Z-shell 初始化文件中的命令（带有 `-f` 或 `NO_RCS` 选项时将跳过所有其他初始化文件）。然后读取用户的 `.zshenv` 文件。此文件和其他用户初始化文件（见下列表）可以位于用户的家目录，也可以位于分配给 `ZDOTDIR` 的目录。如果启动的 shell 是登录 shell，则读取 `/etc/zprofile` 文件，然后是用户的 `.profile` 文件。如果该 shell 还是交互式的，则会读取 `/etc/zshrc` 文件以及用户的 `.zshrc` 文件。如果该 shell 随后是登录 shell，则读取 `/etc/zlogin` 和用户的 `.zlogin` 文件。

```
$ZDOTDIR/.zshenv
$ZDOTDIR/.zprofile
$ZDOTDIR/.zshrc
$ZDOTDIR/.zlogin
$ZDOTDIR/.zlogout
/tmp/zsh*
/etc/zshenv
/etc/zprofile
/etc/zshrc
/etc/zlogin
```
