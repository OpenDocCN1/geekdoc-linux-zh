## DMZ

非军事化区（Demilitarized zone）。局域网和互联网之间的中立区域主机或小型网络。它可以向互联网提供 Web 页面和其他数据，允许本地系统访问互联网，同时防止未经授权的互联网用户访问局域网。即使 DMZ 被攻破，它也不包含私密且无法轻易复制的数据。

## DNS

域名服务（Domain Name Service）。一种管理完整主机名（包含域名的名称）与 IP 地址和其他系统特征之间关系的分布式服务。
