### Java

一种由 SUN 开发的计算机语言，它允许你编写可在各种计算机上运行的软件。Java 是目前互联网的编程语言，它允许在网络上创建并设置微型程序。更多信息请参阅 `http://www.sun.com/`。摘自《距离教育与互联网术语表》`http://www.tldp.org/LDP/Linux-Dictionary/index.html`

一种由 Sun Microsystems 于 1996 年开发的基于 C 语言的语言。它曾被称为“Oak”（橡树），意图成为 C++ 的继任者（但项目最初被卖给了 S 公司，作为机顶盒的嵌入式语言）。在互联网大爆发运动（1993–1994）之后，Java 被“黑”成了一种字节解释型语言，并成为 Sun 公司持续攻势营销的焦点。Java 确实比 C++ 更强大、更致密，并被黑客社区所接受——但对许多人来说，它是巨大的挫败来源，原因在于对不同 Web 浏览器平台的支持不均、性能问题以及某些标准工具（特别是 Kinds）一些臭名的缺陷。微软试图腐败这种语言（它正确地认为这是对其操作系统垄断的威胁），这并无任何帮助。截至 1999 年，这些问题仍在解决过程中。尽管有许多特性和良好的设计，但很难找到那些尝试用它实现复杂现实世界系统的人来赞美 Java（但公平地说，现在还处于早期阶段，没有其他语言曾像 Java 那样在聚光灯下被迫脱掉“童年”）。另一方面，Java 在学术界已经取得了成功，它已经取代了 Pascal，成为成为向下一代黑客教授良好编程基础的首选工具。摘自《黑术语词典》`http://www.tldp.org/LDP/Linux-Dictionary/index.html`

一种由 Sun Microsystems 开发的面向对象的编程语言。它是独立于操作系统的。Java 常用于 Web 服务器。Java 应用程序有时以下载形式提供以便在用户系统上运行。Java 编程可以产生应用程序或更小的 Java Applet（小程序）。Java 是 C++ 语言的某种简化版本，通常是解释执行而非编译的。（另见 JIT 编译器。）摘自 I-gloss `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# Java

Java 是一种由 Sun Microsystems 发明的网络友好型编程语言。Java 常用于构建涉及多个不同计算机跨网络交互的大型系统，例如事务处理系统。Java 也在创建运行在小型电子设备（如手机）上的程序方面变得流行。Java 的一种用途是创建可以通过互联网下载到你的计算机并进行调程序的程序，无需担心病毒或其他对你的计算机或文件造成伤害。使用小型 Java 程序（称为“Applets”），网页可以包含动画、计算器和其他花哨的功能。摘自 Matisse `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# Java Applets

小型 Java 程序嵌入在 Web 页面并在浏览器中运行，而不是作为独立应用程序运行。Applets 无法访问本地计算机上的资源，如文件和序列设备（媒体、打印机等），并且通常无法跨网络与其他计算机通信。摘自 I-gloss `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
