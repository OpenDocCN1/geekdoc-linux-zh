
# 常用 UNIX 命令

## mv

```
mv <old> <new>
```

其中 `<old>` 是现有文件，`<new>` 是新位置或新文件名。

## ps

`ps` 命令用于列出所有当前进程。输出包含显示每个进程运行时间以及每个进程所用系统资源的数据。`ps` 的语法如下：

```
ps [options]
```

`ps` 选项包括：

- `-a`：列出计算机上运行的所有进程，而不仅仅是用户自己的进程
- `-x`：包含后台进程
- `-u`：按用户 ID (userid) 对所有进程进行排序

## pwd

`pwd` 命令返回当前目录的完整路径名。通过执行以下命令来学习你在文件系统中的当前位置：

```
pwd
```

## read

`read` 命令用于 shell 编程。它告诉计算机从键盘或其他标准输入设备获取输入，并将其赋值给变量 `$VAR`。`read` 的语法如下：

```
read $VAR
```

## rm

`rm` 命令删除指定名称的文件。单独使用或配合有限的选项时，它是一个安全的命令。然而，某些选项组合具有破坏性；在组合参数时，应谨慎使用 `rm`。`rm` 的语法如下：

```
rm [options] <filename>
```

`rm` 选项包括：

- `-i`：交互模式：`rm` 在每次删除时都需要确认。许多系统将配置为 `rm` 自动使用 `-i` 标志。
- `-R`：递归模式：`rm` 将删除当前目录中存储的子目录以及子目录包含的文件
- `-f`：强制模式：`rm` 将忽略所有消息和警告

`-r` 和 `-f` 经常组合作为快捷键，特别是在删除文件系统或嵌套目录时。使用此组合时要极其小心，因为如果不经思考地使用可能会是毁灭性的。命令 `rm -rf` 将完全擦除文件系统；如果你以用户身份登录，它将删除你的主目录；如果你以 root 身份登录，它将擦除整个硬盘。不多说，除非你确清楚自己在做什么，否则不要使用此命令。

### rmdir

`rmdir` 命令用于删除指定名称的目录。如果指定的目录中有文件，`rmdir` 将给出错误信息并退出。`rmdir` 的语法如下：

```
rmdir <directory name>
```

## route

`route` 命令提供有关 IP 路由表的信息。它也可以用于更改该表。`route` 使用的语法：

```
route [options] <target>
```

`route` 选项包括：

- `-v`：详细模式
- `-n`：显示数值 IP 地址（主机名是路由默认）
- `-add`：添加路由
- `-del`：删除路由
- `-net`：目标是网络
- `-host`：目标是主机
- `-netmask`：网子掩码（如果目标是网络）
- `-default`：将指定的路由定义为默认，在没有其他路由匹配时使用
- `-gw`：定义数据包必须路由通过的网关

## rsync

`rsync` 命令同步网络上的文件和目录。它的语法如下：

```
rsync [options] <source> <destination>
```

`rsync` 有多个选项，包括：

- `-e`：定义 `rsh` 或 `ssh` 为传输方法（`rsh` 是默认值）
- `-a`：归档模式：保留所有文件属性
- `-r`：递归模式：复制所有子目录中的所有文件
- `-u`：更新模式：仅复制时间戳新于目标文件拷贝的文件
- `-R`：允许使用相对路径名
- `-v`：详细模式
- `-b`：备份模式：在替换文件之前对其备份
- `-n`：试运行：报告将会发生的情况，但不传输任何文件
- `-z`：在传输前压缩数据
- `--delete`：如果目标文件系统上的文件在发送文件系统中不存在，则将其删除
- `--exclude`：与 `-R` 标志配合使用：从传输中排除指定的子目录

## set

`set` 命令显示环境变量列表及其当前值。在 shell 提示符处执行命令：

```
set
```

以查看输出。

## setenv

`setenv` 命令用于在 shell 下更改环境变量。它使用的语法如下：

```
setenv VAR=<value>
```

## sh

`sh` 命令启动一个 Bourne shell 会话。如果提供命令作为参数，则该命令将在新的 Bourne shell 会话中运行。`sh` 的语法如下：

```
sh [<command>]
```

## shutdown

`shutdown` 命令用于停止所有当前进程，然后关闭机器。此命令具有复杂的语法：

```
shutdown [options] <time> [<warning message>]
```

时间组件定义了到机器关机的时钟时间。它有三个选项：

- `now`：现在
- `+<m>`：关机前等待的分钟数
- `<hh>:<mm>`：关机过程开始的时钟小时和分钟

其他 `shutdown` 选项包括：

- `<warning message>`：打印到所有登录用户标准输出的，用于宣布即将到来的关机
- `-h`：停止或关闭机器
- `-r`：重启机器

此命令通常以以下形式发布：

```
shutdown -h now
```

## sort

`sort` 命令对指定文件中的条目进行排序。排序是数值或字母取决于每个条目的第一个字符。排序后的输出打印到标准输出。`sort` 的语法如下：

```
sort <filename>
```

## ssh

`ssh` 命令用于使用 SSH 程序打开安全的 shell 会话。`ssh` 的语法如下：

```
ssh [-l <login name>] [hostname] [command]
```

## startx

`startx` 命令启动 X Window 系统会话。虽然可以在命令行使用参数，但这样更具一致性且不易失败。

```
startx
```

## su

`su` 命令允许你切换到另一个用户。它的语法如下：

```
su [options] [username]
```

你将被提示输入要切换的用户密码。

## test

`test` 命令用于 shell 编程以评估定义的条件。`test` 的语法如下：

```
test <condition>
```

或

```
[ <condition> ] （括号是可选的。）
```

`test` 选项包括：

- `-e`：文件存在
- `-f`：文件存在且是普通文件
- `-d`：目标存在且是目录
- `-s`：文件存在且不为空

## top

`top` 命令显示进程表。`top` 的语法如下：

```
top [options]
```

`top` 选项包括：

- `-d`：定义 PID 之间的间隔
- `-p`：仅显示指定 PID 的进程——单个命令最多可以使用 20 次
- `-q`：无延迟不断刷新
- `-i`：忽略所有僵尸进程和空闲进程

## touch

`touch` 命令用于更新命名文件的时间戳。也可以带有一个属于现有文件的文件名，在这种情况下 `touch` 将创建一个指定名称的新空文件。`touch` 的语法如下：

```
touch <filename>
```

## traceroute

`traceroute` 命令列出数据包从你的主机到另一个指定远程网络的路由。它的语法如下：

```
traceroute [options] <remote machine>
```

`traceroute` 选项包括：

- `-n`：显示机器的数值 IP 号（默认是文本主机名）
- `-w`：`traceroute` 等待响应的时间（秒）

## ulimit

`ulimit` 命令定义了 shell 进程可用的资源，限制了任何进程可以使用的系统资源。对于频繁使用的系统特别有用。`ulimit` 的语法如下：

```
ulimit [options [limit]]
```

`ulimit` 选项包括：

- `-S`：设置软资源限制（如果进程超过软限制，将向进程所有者发出警告）
- `-H`：设置硬资源限制（不允许进程超过硬限制）
- `-a`：将当前限制打印到标准输出
- `-c`：定义核心转储文件的最大大小
- `-d`：定义进程数据段的最大大小
- `-t`：定义任何给定进程可用的 CPU 时间最大值，单位为秒
- `-f`：定义 shell 进程创建的文件的最大大小
- `-p`：定义管道缓冲区
- `-n`：定义打开文件描述符的最大数量
- `-u`：定义用户进程的最大数量
- `-v`：定义虚拟内存的大小

## umask

`umask` 命令使用之前定义的掩码为新文件设置默认权限。`umask` 的语法为：

```
umask [-S] [<mode>]
```

`-S` 选项将当前掩码打印到标准输出。模式由 `chmod` 使用的字母或八进制数字组成。

## umount

`umount` 命令卸载指定文件系统，使其不再可使用。`umount` 的语法为：

```
umount [options] <filesystem>
```

`<filesystem>` 元素可以是设备或目录名。也可以使用 `-a` 选项卸载 `/etc/mtab` 文件中描述的所有文件系统，例如：

```
umount -a
```

## useradd

`useradd` 命令用于创建新用户账户。在某些系统中，`useradd` 可能会被一个几乎相同的程序 `adduser` 替代。`useradd` 的语法为：

```
useradd [options] <username>
```

该选项包括：

- `-c`：包含注释
- `-d`：定义主目录
- `-e`：定义账户到期日期
- `-p`：定义初始密码
- `-s`：定义默认 shell
- `-u`：定义用户 ID

文件 `/etc/default/useradd` 包含了在您的系统上创建的账户的标准选项。

## userdel

`userdel` 命令删除指定的用户账户。在某些系统中，`userdel` 可能会被一个几乎相同的程序 `deluser` 替代。`userdel` 的语法为：

```
userdel [-r] <username>
```

`userdel` 经常带有 `-r` 标志使用。该标志会删除与用户主目录相关的所有文件，并删除用户账户。

## w

`w` 命令显示登录系统的用户列表。它使用以下语法：

```
w [options]
```

常用的 `w` 选项包括：

- `-h`：打印不带头部信息的输出
- `-s`：以缩短格式显示输出
- `<user>`：显示指定用户的所有信息，忽略其他登录用户

## wc

`wc` 命令用于统计命名文件中的单词数。单词被定义为两端都有空格的字符字符串（行开头和结尾的字符串除外）。`wc` 的语法为：

```
wc [options] <filename>
```

`wc` 选项包括：

- `-c`：统计字符而不是单词
- `-l`：统计行数而不是单词
- `-L`：打印最长行的长度

## whereis

`whereis` 命令用于在磁盘上定位指定的程序或文件。`whereis` 的语法为：

```
whereis [options] <filename>
```

`whereis` 选项包括：

- `-b`：仅识别指定名称的二进制文件
- `-m`：仅识别指定名称的手册
- `-s`：仅识别指定名称的源码

## which

`which` 命令用于在磁盘上定位指定的可执行程序。`which` 的语法为：

```
which [options] <programname>
```

使用 `-a` 标志查看来自 `PATH` 环境变量定义目录的所有匹配的可执行文件。使用 `which -a` 标志将搜索所有目录，而不仅仅是 `PATH` 中的目录。

# 附录 B 术语表

## 目录

文件类型作为其他文件的容器。目录是 Unix 系统的核心，单个文件的目录是以该文件嵌套的目录列表的形式提供的。

## 控制流

有两种类型的流控制：条件流和迭代。条件流是程序的一个特定片段，只有在满足指定条件时才会执行。在迭代控制下，特定片段将保持运行，直到满足指定条件。

## 显示器管理器

图形用户界面的一部分。显示器管理器控制登录和注销，并管理显示在屏幕上的各种进程。

## 以太网

一种网络构建方法，以太网涉及使用专门用于数据传输的电缆。

## 自由软件

由自由软件基金会制作软件。自由软件通常被认为是允许任何人出于任何原因使用该程序：

1. 允许任何人出于任何原因使用程序；
2. 允许任何人修改程序；
3. 允许任何人重新分发程序；
4. 要求任何衍生版本都携带相同的许可证。

## 发行版

发行版是 Linux 的特定版本。有一百多个发行版，每个发行版都有相同的内核，但提供了与其他不同的方法。

## 退出状态

每个进程都会返回一个值，指示进程成功还是失败。这些值通常被视为 0 表示成功，其他值表示失败的各种原因。

## 点文件

名称以点开头的文件。配置和其他系统文件通常存储为点文件。

## 函数调用

一种将现成函数调入程序中的编程结构。函数允许少量的不同程序，使得程序员不需要在每个新程序中重新书写。

## 环境变量

定义运行在系统上的各种程序的外观和活动。环境变量是程序特定的，但大多数用作 shell 的一部分。环境变量几乎总是可配置的。

## 文件权限

可能会授予所有者、组或其他人员。读、写、执行。无论特定文件设置了什么种权限，超级用户都可以访问系统上的文件。

## GPL (GNU 公共许可证)

该许可证包含了自由软件定义的所有元素。Linux 软件在 GPL 下发布，其他变体也是如此。

## 转义序列

一种指示正在运行的进程将被修改的字符串或按键组合。

## 图形用户界面

图形用户界面提供了一套用于与 GUI 配合工作的软件。流行的桌面包括 KDE 和 GNOME。虽然 GUI 在技术上比文本环境更复杂，但可以在 GUI 桌面的窗口内运行文本会话。

## 接口

用户与操作系统交互的方法。Unix 接口可以是文本的，也可以是图形的。

## 行编辑器

一种一次只处理一行的文本编辑器。行编辑器已被 `vi` 等可视编辑器和图形编辑器取代。

## 互联网

一种将多个网络连接在一起的网络。例如，互联网是连接许多局域网（LAN）或广域网（WAN）的网络。

## 链接

文件的别名。有两种链接：符号链接和硬链接。符号链接指向另一个实际文件。硬链接涉及一个具有不同名称的独立节点；此节点指向文件节点。

## 异构网络

网络类型。异构网络拥有多种操作系统的机器。例如，一台 Linux 机器和一台 Macintosh 就是异构的。这些网络由相互理解的软件操作系统进行管理。

## 同构网络

网络类型。在同构网络上，所有机器都运行相同的操作系统。

## 任务号

由特定用户启动的唯一标识数字。

## 宏

宏有两种定义：

1. 在选定的数据部分上执行的一系列命令或操作，通过按键或单个命令调用。这种定义通常用于应用程序的语境下。
2. 长度函数的替换。这定义在编程中，宏可以节省大量的按键次数。

## 节点

描述哪个磁盘块被特定文件占用。该信息存储在节点中，用于为新文件分配磁盘空间。

## 内核

操作系统的最低层次组件。

## 手册页

描述指定程序或命令功能的文本文件。通过 `man` 命令访问手册页。

## 整数

任何整数：正数、负数或零。整数不能包含分数或小数。

## 键绑定

函数通过按键组合或具有分配函数的特定键唤起。这些绑定通常在文本编辑器（特别是 Emacs）中找到，也可以在系统的其他元素中找到。

## 日消息

登录时显示的消息。此消息文本通常存储在文件 `/etc/motd` 中，只有 root 用户可以更改。

## 库

编程函数的集合。通过库，程序可以进行调用。

## 元字符

通常与其他字母组合按下的键盘键。常见的元字符包括 `Ctrl`、`Alt` 和 `Windows` 键或连字符。

## 模块化

一种将简单元素组合成更大型系统的结构。然而，模块化可能会限制原始源代码，因为我们可以分发补丁或微小更改。

## 多任务处理

操作系统可以同时执行多个任务。多任务处理可以通过任务切换和时间片来实现。

## 操作系统

位于用户和硬件之间的软件。操作系统包括 Unix、Windows 和 macOS。

## 操作符

一个可以执行一些操作（包括数学、比较和其他操作）的项目。

## 选项

命令的可选元素。选项通常由 `-` 或 `--` 开头。

## 密码

用户提供以访问系统的文本字符串。密码应该是短的，包含大写和小写字母。字典单词是安全风险。我们不应共享密码。

## 外围设备

任何可以从主计算机连接或移除的设备。外围设备包括打印机、指向设备。

## 权限

参见文件权限。

## 管道

将一个程序的输出数据传输到作为另一个程序的输入的方法。

## 重写

为不同的平台或操作系统重写软件。
