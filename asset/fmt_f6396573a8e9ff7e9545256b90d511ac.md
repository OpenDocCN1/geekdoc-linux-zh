# 共享磁盘资源设置

执行以下步骤来设置共享磁盘资源：

1. 检查两个节点的网络接口上是否配置了 IP 地址。
2. 检查 `/etc/hosts` 文件是否包含所有 IP 地址条目，且这些标签被 `HACMP` 使用。
3. 使用 `host` 命令验证名称解析是否正常。如果有问题，请检查并修改 `/etc/hosts` 文件。
4. 检查串口网络连接。建议为 `HACMP` 存活检测提供辅助网络。

配置共享磁盘的：

- 卷组（`VG`）
- 逻辑卷（`LV`）
- 日志文件系统（`JFS`）
- 文件系统（`FS`）
