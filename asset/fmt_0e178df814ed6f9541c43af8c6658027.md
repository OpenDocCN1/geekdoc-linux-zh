
## 通过引用 URL 保存状态

保存状态信息的简单方法是使用 `self_url()` 方法，它返回一个重定向 URL，该 URL 会带有所有状态信息重新调用程序。语法如下：

`$my_url = $cgi->self_url;`

你可以通过 `url()` 方法获取未附加所有查询字符串的 URL：

`$my_url = $cgi->url;`

另一种保存状态的方法是使用 cookie。我将在本章后面介绍如何使用它们。

## 接受多个参数的 CGI 函数

尽管我已经提供过类似的示例，但它非常值得强调。例如，如果你想创建一个文本输入字段，可以这样做：

```
$field = $cgi->textfield(-name => 'foo',
 -default => 'bar');
```

能够向函数传递这些指定参数的一个很棒的副作用是，即使 CGI 模块不认识它们，你也可以给标签传递参数。例如，如果 HTML 的某个未来版本识别了 `align` 参数，你可以简单地使用它：

```
$file = $cgi->textfield(-name => 'foo',
 -default => 'bar',
 -align => 'right');
```

## HTTP Header

如下所示，`header()` 方法会打印相应的 HTTP 头部和空行（用于将头部与正文分离）。如果未提供参数，则返回默认 MIME 类型：

`print $cgi->header('text/html');`

如果你想指定状态码，可以这样做：

```
print $cgi->header('text/html',
 -status => '200 OK');
```

如果你想设置过期时间，可以这样做：

```
print $cgi->header('text/html',
 -expires => 3600);
```

如果你想设置 cookie，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value']);
```

如果你想设置多个 cookie，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name1' => 'value1', 'name2' => 'value2']);
```

如果你想设置路径路径，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'path' => '/']);
```

如果你想设置 cookie 域，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'domain' => 'example.com']);
```

如果你想设置安全 标志，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'secure' => true]);
```

如果你想设置 HttpOnly ，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'httponly' => true]);
```

如果你想设置过期时间，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'expires' => time() + 3600]);
```

如果你想设置最大年龄，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'max-age' => 3600]);
```

如果你想设置 SameSite，可以这样做：

```
print $cgi->header('text/html',
 -cookie => ['name' => 'value', 'samesite' => 'Strict']);
```

## HTTP 变量

大多数用于创建 CGI 的环境变量（包括本章开头提到的）都可以通过此接口使用。以下是每个方法的简要描述：

- `accept()`: 该方法返回浏览器接受的 MIME 类型。如果你给该方法传递一个 MIME 类型（例如 `$cgi->accept('image/gif')`），它将返回一个布尔值。
- `auth_type()`: 如果页面受保护，则返回验证类型。在 HTTP/1.0 中，可能的类型是 "basic"。在 HTTP/1.1 中，可以是 "basic" 或 "digest"。其他特定的服务器方案可能是可能的，请咨询你的 HTTP 服务器。
- `raw_cookie()`: 该方法返回原始状态的 Netscape Cookie。通常情况下，你可能想通过 `cookie()` 方法执行任何 cookie 操作。
- `path_info()`: 该方法返回附加到你程序的任何路径信息。例如，如果你的程序执行重定向，并且通过路径 `/cgi-bin/programname/some/other_path` 调用，那么 `path_info()` 返回 `/some/other_path`。
- `path_translated()`: 该方法与 `path_info()` ，但路径信息被转换为物理路径，例如 `/var/www/cgi-bin/programname/some/other_path`。
- `query_string()`: 该方法返回附加到你程序的路径信息。这些信息可能包含用于维护状态信息的选项和参数。
- `referer()`: 该方法返回用户链接到你程序的 URL。
- `remote_addr()`: 该方法以点分十格式返回远程主机（即客户端）的 IP 地址。
- `remote_ident()`: 该方法返回执行请求的远程主机上的身份。此方法仅当远程系统运行 `identd` 服务时有效。
- `remote_host()`: 该方法返回远程主机的名称（如果已知）。否则，它返回 IP 地址。
- `remote_user()`: 该方法返回执行请求的用户的用户名。

此方法返回在你的服务器上经过身份验证的用户名称。

`request_method()`

此方法返回请求你的程序 URL 时使用的 HTTP 方法（例如，`GET`、`POST` 或 `HEAD`）。

`script_name()`

此方法返回作为部分 URL 的程序名。此方法对于会引用自身的程序非常有用。

`server_name()`

此方法返回运行程序的服务器名称。

`server_port()`

此方法返回本地 Web 服务器正在使用的端口号。

`user_agent()`

此方法返回远程用户的客户端软件标识。你可能对查看此响应结果感兴趣，以看看有多少浏览器声称自己是 Mozilla（Netscape Navigator 导航器）。

`user_name()`

此方法返回远程用户的名称。此方法通常不起作用，尽管它在某些旧版浏览器（如早期版本的 NCSA Mosaic）中可以工作。

## 来自 `CGI.pm` 的 HTML

现在你准备好查看一些用于创建 HTML 头部和 HTML 文档本身的有用参数了：

- `-title`

此参数指示文档的标题。（此参数的参数最终位于 `<TITLE>` 和 `</TITLE>` 标签之间。）

- `-author`

此参数指示作者的电子邮件地址。

- `-script`

你使用此参数将 JavaScript 整合到你的 HTML 中。在这里，你需要定义所有打算在事件发生时（如提交表单、更改字段内容等）要使用的 JavaScript 方法。你将在 JavaScript 节中学习如何调用在此处定义的方法。

`CGI.pm` 不会为你编写 JavaScript；它只是为你提供了一种将 JavaScript 整合到你动态生成的 HTML 中的方法。要使用它，你需要知道如何使用 JavaScript。考虑这个示例：

```perl
$cgi = new CGI;
print $cgi->header;
$JAVASCRIPT=<<END;
// 这是一个在动态生成的
// HTML 页面中整合
// JavaScript 的超简单示例。
window.alert("Click on OK!");
END
print $cgi->start_html( -title => 'Some sort of silliness',
-script => $JAVASCRIPT);
```
