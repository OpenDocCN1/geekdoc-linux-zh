# 相相器

一种能够改变信号相位为 180° 的电路。相相器最常用作推挽放大器的移相。因此，相相器必须提供两个幅度相等且相位相差为 180° 的电压。

推挽放大器的整体保真度可能会受到相相器设计的不利影响。在相位设计中，推挽放大器的一个输入的频率响应与另一个输入的频率响应相同至关重要。

相相变压器的简单形式是一种假设二次电压相等的电路。当系统必须为推挽放大器供电时，变压器的设计形成良好的相相器。变压器可能会产生不等的电压，占用空间更大，大于晶体管。此外，还需要某些手段来补偿频率响应。

# 1652 相锁环

相锁环：用于用输入信号锁定振荡器的电子电路。PLL 有两种根本不同的使用方式：(1) 作为解调器，用于跟踪（并解调）频率；(2) 跟踪频率可能变化的信号。也可以用于计时。

相锁环的基本组件如图所示。输入信号是正弦波或任意波形。电压控制振荡器（VCO）产生与输入频率相同的正弦波或方波，但两者之间的相位角是变化的。相位检测器提取相位差以及输入频率及其谐波的分量。低通滤波器移除所有交流（ac）分量，留下直流分量，直流是相位差的函数。如果输入信号发生变化，信号之间的相位角会导致直流控制的变化，从而改变 VCO 的频率以跟踪输入信号。

# 相调制

一种用于通信系统的技术，其中载波的周期随输入信号（称为调制信号）特征而改变。相位调制是幅度调制的一种形式，其中调制信号是数字的，使用术语“相移键”（PSK）。参见调制。在相位调制或相移键的应用中，载波是恒定幅的正弦波，数学表示为方程 (1)，其中常数 `A` 为

```
$c(t) = A\sin(\omega t + m(t))$ (1)
```

其幅度 `m(t)` 是恒定的，随相位线性增加，其中 `ω = 2π f` 和 `f` 是使载波信号线性响应频率的常数。

相位调制根据调制信号 `m(t)` 直接改变载波相位，见方程 (2)：

```
$\theta(t) = \omega t + km(t)$ (2)
```
