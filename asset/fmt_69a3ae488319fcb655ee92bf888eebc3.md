# C 程序中的数据

在 `C` 程序中操作的两类数据是字面值和变量。字面值是特定的、实际数字或字符，例如 1、4.35 或 a。变量是与内存中可以存储数据的名称关联。`C` 中的每个变量都有类型；也就是说，它只能持有一种值。基本数据类型包括整数、浮点数、字符和数组。数组是相同类型数据元素的序列；元素通过它们出现的顺序来标识。

你也可以定义复杂的数据结构。复杂数据结构用于将许多相关数据项汇到一个名称下。例如，一个终端通信程序可能会为每个登录的用户关联一个终端控制块（TCB）。TCB 通常包含标识通信端口、活动应用程序进程以及其他与该终端会话相关的信息。

在 `C` 程序中所有的变量在使用之前都必须显式定义。
