# docbook-website

# docbook-xml

用于 DocBook 的 XML DTD，也称为 DocBk XML。它是 DocBook DTD 的 XML 表示形式，有时被称为 DocBk XML。这是一种用于记录软件和其他技术主题的 DTD。此包分发了新的 DocBook XML DTD，以及一组用于旧文档的特定遗留 DTD。来自 Debian 3.0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# docbook-xsl

用于将 DocBook XML 文件转换为 HTML 和 FO 的样式表。这些是用于处理使用 DocBook XML DTD 及其衍生版本（“简化”DocBook XML、JReferenceDTD 等）编写的文档的模块化样式表。包中包含了文档。样式表为 HTML 和格式化对象（Formatting Object）输出提供了 XSLT 转换。后者可以使用 FOOP 或基于 Tex 的工具进一步处理成多种格式。样式表具有模块化特征，这意味着你可以对它们进行扩展，并在某种程度上进行自定义。还存在为 Saxon 和 Xalan2 处理器提供的扩展类。此包中包含了文档。如需快速上手，请使用 `/usr/share/docbook-xsl/README.Debian`。作者：Norman Walsh <ndw@nwalsh.com>: 主页：`http://sourceforge.net/projects/docbook` 来自 Debian 3.0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
