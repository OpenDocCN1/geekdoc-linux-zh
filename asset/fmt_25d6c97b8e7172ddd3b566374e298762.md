## 设置和使用你的打印机和扫描仪

### 打印机

除非你电脑的唯一用途是玩游戏、听 MP3，或者在炎热多风的日子里用来顶门，否则你无疑想将你的机器连接到打印机。尽管个人电脑本应开启一个无纸办公的时代，但计算机作为桌面出版和通用工作工具的优势，使得高质量打印文档比以往任何时候都更具有吸引力。

#### 确认你的打印机是否受支持

让打印机与新系统配合是一项相当轻松的任务，但你必须确保你的打印机受 Linux 支持。幸运的是，Linux 世界的支持情况似乎比以前好得多。通常情况下，对爱普生（Epson）、兄弟（Brother）、三星和惠普（Hewlett-Packard）打印机的支持非常好，而其他制造商和其他打印机类型支持则有些不稳定，尽管正在改进。

如果你真的想确保你的打印机受支持（为什么不呢？），最好的方法是去 www.linuxprinting.org。在该网站上，你可以检查在线数据库，查看你的打印机是否受到支持，以及支持的程度。支持的打印机列表还包括哪些驱动程序最适合你的需求。如果你正考虑购买打印机，那里还有一个建议的品牌和型号页面。你可能还想参考 Ubuntu 的列表：https://wiki.ubuntu.com/HardwareSupport-Components

#### 设置你的打印机

如果你有一个 USB 打印机，从将其连接到电脑并开启打印机开始。如果你的打印机连接到电脑的并行口，你首先必须关闭电脑，将打印机连接到电脑，打开打印机并启动电脑。当然，如果你的打印机在安装期间已连接并开启，你可以跳过这一步。无论如何，你的打印机都会被检测到，你不会收到像 Windows 中那样的立即发现新硬件的提醒。

系统重启后，你需要执行以下操作：

1. 进入系统（System）菜单，选择打印管理（Administration Printing）。此时将出现一个打印机窗口，显示一个名为“New Printer”（新打印机）的打印机。双击该图标，随后将出现设置向导（图 10-1）。

由于即插即用的奇妙（这意味着你的打印机、扫描仪和其他设备可以告诉计算机它们是什么），你的打印机名称应该出现在“使用检测到的打印机”（Use a detected printer）字下方的面板中。遗憾的是，仅仅因为系统在硬件上知道你连接了哪台打印机，并不意味着它真的能在打印方面与之进行通信（Windows 和 Mac OS X 也是如此）。这就是驱动程序的作用。

![](img/ba6b82a7869bba748202d57c97336dca_196_0.png)

图 10-1：打印机设置向导

2. 点击**向前**（Forward）按钮继续，这将带你进入向导的第二页，如图 10-2 所示。向导的第二页会自动打开，并选中你的打印机品牌、型号以及该打印机的推荐驱动程序。如果选择的型号不正确，向下滚动列表直到找到正确的型号。如果你的型号未列出，请尝试默认选中的那个。

![](img/ba6b82a7869bba748202d57c97336dca_196_1.png)

图 10-2：在打印机设置向导中选择打印机的品牌和型号

3. 选中打印机后，点击“向前”按钮，这将带你进入向导的最后一页。

4. 在此页上，为你的打印机输入名称，并如果需要，提供描述和位置。完成后，你的窗口应该看起来像图 10-3 中我的那里一样。你可以点击“应用”（Apply）。

![](img/ba6b82a7869bba748202d57c97336dca_197_0.png)

向导应该会关闭，让你回到开始此任务的“打印机”窗口。你的打印机图标现在应该出现在该窗口中，在你最初发现的“New Printer”图标旁边。如果你设置了多台打印机，可以通过右键点击打印机并在出现的菜单中选择“设为默认”（Make Default）来选择哪一台作为默认。该打印机的图标上将会有一个蓝色的复选框（图 10-4），表示它是你系统的默认打印机。

![](img/ba6b82a7869bba748202d57c97336dca_197_1.png)

图 10-4：完成打印机设置向导后打印机窗口中的 New Printer 图标

你的打印机现在已设置好并可以使用。不过，为了确保万无一失，打印测试页总是好主意。

1. 在打印机窗口中右键点击打印机图标，并在弹出菜单中选择“属性”（Properties）。

2. 在出现的属性窗口中，点击“打印测试页”（Print Test Page）按钮。

你的系统将向打印机发送一个文档并在一个小窗口中通知你它已完成，你可以关闭该窗口。如果测试页没有出来，请检查你的设置。

### 将网页打印为 PDF

将网页打印为 PDF 也是一种非常方便的方法，可以以原始图形格式保存所需的网页，以备后参考。目前，Firefox 不支持此功能，尽管它允许你将页面打印为 PostScript。只要你严格在自己的系统中使用该文件，或者将其发送给其他使用 Linux 系统的人，你可能察觉不到 PS 和 PDF 文件之间的任何区别，它们的显示和行为几乎完全相同。

要将网页打印为 PostScript，进入 Firefox 的**文件**（File）菜单，并选择**打印**（Print）。打印对话框出现时，选择“打印到文件”（Print to file），然后为你的页面命名，确保保留 .ps 文件扩展名。点击“打印”（Print），几秒钟后，文件就会出现在你的硬盘上。

这完全没问题，但如果你想将文档分给更广泛的受众，PostScript 替代方案就不行，因为大多数 Windows 用户没有方法查看该文件。你能做什么？嗯，一种方法是创建 PS 文档并使用 `ps2pdf` 命令将其转换为 PDF。这很容易，尽管它并不总是有效。例如，你可能会发现 PS 文档中的文本在输出的 PDF 文件中消失了，或者文本出现了但图形消失了。尝试一下无害，以下是操作方法：只需在终端（Terminal）中输入 `ps2pdf filename.ps filename.pdf`，然后按回车键。是的，就这么。

### 项目 10：创建一个虚拟 PDF 打印机

如果你对 `ps2pdf` 转换的结果不满意，但仍然想要将网页打印为 PDF，有一个相当简单的解决方案——创建一个虚拟 PDF 打印机。通过这样做，你将能够在允许打印的任何应用程序打印到 PDF（抱歉，游戏玩家们）。

#### 10-1：准备所需的文件

在开始之前，运行 Synaptic，搜索 `cups-pdf` 并安装它。安装完成后，打开终端窗口，输入 `sudo chmod +s /usr/lib/cups/backend/cups-pdf` 并按回车键。当提示输入密码时，输入密码并按回车键。

#### 10-2：设置你的虚拟 PDF 打印机

在完成 `cups-PDF` 安装和准备后，你可以继续设置打印机。要进行此操作，进入系统菜单，选择管理（Administration）▸打印（Printing）。在提示时提供密码，然后当打印机出现时，双击“新建打印机”图标。在添加打印机向导中，选择“本地打印机”（Local Printer）和“使用检测到的打印机”（Use a detected printer），然后点击 PDF 进行选择。完成后，点击“下一步”。

在向导的第二页，在制造商（Manufacturer）菜单中选择“Generic”，并在型号（Model）部分选择“postscript color printer rev3b”。你的窗口应该看起来像图 10-6 所示。如果是，点击“下一步”。

![](img/ba6b82a7869bba748202d57c97336dca_201_0.png)

图 10-6：创建一个虚拟 PDF 打印机

最后，在向导的最后一页，根据你的喜好填写文本框并点击“应用”（Apply）完成操作。如果你想要将打印机名称缩短为更容易管理的名称，例如 My PDF Printer。

#### 10-3：使用你的虚拟打印机

一旦设置好虚拟 PDF 打印机，你就可以很容易地使用它了。事实上，由于系统将其视为真实的打印机，你只需要按照打印任何文档的常规步骤操作，只需确保在打印窗口出现时选择你的虚拟 PDF 打印机作为任务打印机即可。

一旦使用虚拟 PDF 打印机打印了文档，当你第一次使用时，你可以在主目录下 `cups-PDF` 为你创建的 PDF 文件夹中找到你的文档。

### 取消打印任务

这种情况发生在我们每个人身上。你想打印 57 页文档中的 1 页，但你不小心开始打印了整个文档。你能做些什么来节省墨水和 56 张纸？幸运的是，解决方案很简单。

一旦你点击“打印”按钮并将任务发送到打印机，顶部 GNOME 面板的右侧（通常在上方其他项目的左侧）会出现一个小小的打印机图标，如图 10-7 所示。
