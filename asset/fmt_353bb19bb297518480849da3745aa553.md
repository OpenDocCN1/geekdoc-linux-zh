
大多数 Linux 命令会读取输入（如文件或其他命令的属性）并写入输出。默认情况下，输入由键盘提供，输出显示在屏幕上。键盘是你的标准输入（`stdin`）设备，屏幕或特定的终端窗口是标准输出（`stdout`）设备。

然而，由于 Linux 是一个灵活的系统，这些默认设置并不一定需要应用。例如，在大型环境中受严格监控的服务器上，标准输出可能是一个打印机。

### 重定向运算符

#### 使用 `>` 进行输出重定向

有时你想将命令的输出放入文件中，或者可能想在一个命令的输出上执行另一个命令。这被称为输出重定向。重定向通过 `>`（大于号）或 `|`（管道）运算符来实现，后者将一个命令的标准输出发送到另一个命令的标准输入。

正如我们之前看到的，`cat` 命令合并文件并将它们全部输出到标准输出。通过将此输出重定向到文件，将创建一个文件——如果文件已存在则会被覆盖，所以请小心。

```
nancy-> cat test1
some words
```

```
nancy->> cat test2
some other words
```

```
nancy->> cat test1 test2 > test3
```

```
nancy->> cat test3
some words
some other words
```

#### 不要覆盖！

在重定向输出时，小心不要覆盖已有的（重要）文件。许多 shell（包括 Bash）都有一个内置功能来保护你免受这种风险：`noclobber`。更多信息参见 Info 页面。在 Bash 中，你可能需要在 `.bashrc` 配置文件中添加 `set -o noclobber` 命令以防止意外覆盖文件。

将“无”重定向到已存在的文件等于清空文件：

```
nancy->> ls -l list
-rw-rw-r-- 1 nancy nancy 117 Apr 2 18:09 list
```

```
nancy->> ls list
```

```
nancy->> ls -l list
-rw-rw-r-- 1 nancy nancy 0 Apr 4 12:01 list
```

这个过程被称为截断（truncating）。

将相同的重定向到一个不存在的文件将创建一个给定名称的新空文件：

```
nancy->> ls newlist
: No such file or directory
```

```
nancy->> newlist
```

```
nancy->> ls -l newlist
-rw-rw-r-- 1 nancy nancy 0 Apr 4 12:05 newlist
```

## 输入重定向

在另一种情况下，你可能想让一个文件作为命令通常不会作为的输入。在以下示例中，如果省略了重定向数字且重定向运算符的第一个字符是 `<`，则重定向指向标准输入（文件描述符 0）。如果重定向运算符的第一个字符是 `>`，则重定向指向标准输出（文件描述符 1）。

一些实际示例将使其更清晰：

```
ls dirlist 2>&&
```

d会将标准输出和标准错误重定向到文件 `dirlist`，而命令

```
s 2>&1 dirlist
```

只会将标准输出重定向到 `dirlist`。这对于程序员来说是一个非常有用的选项。

## 组合重定向

下面的示例组合了输入和输出：

```
ls dirlist 2>&&
```

## `>>` 运算符

除了覆盖文件数据，你还可以使用两个大于号向现有文件追加文本：

示例：

```
nancy->> cat wishlist
more money
less work

nancy->> date >> wishlist
more money
less work
Thu Feb 28 20:23:07 CET 2002
```

## 高级重定向功能

### 使用文件描述符

有三种类型的 I/O，它们各有一个标识，称为文件描述符：

- 标准输入：0
- 标准输出：1
- 标准错误：2

```bash
[nancy@asus /var/tmp]$ ls 2> tmp
```

```bash
[nancy@asus /var/tmp]$ ls -l tmp
-rw-rw-r-- 1 nancy 0 Sept 7 12:58 tmp
```

```bash
[nancy@asus /var/tmp]$ ls 2 > tmp
ls: 2: No such file or directory
```

Nancy 执行的第一条命令是正确的（尽管没有生成错误，且标准错误没有重定向到文件）。第二条命令期望 2 是一个文件名，但在这种情况下该文件不存在，因此显示了错误。

所有这些功能在 Bash Info 页面中都有详细解释。

## 分析错误

如果你的进程产生了大量错误，这是一种彻底检查它们的方法：

```bash
command 2>&1 | less
```

这在使用 `make` 命令创建新软件时使用，例如：

```bash
andy:~/newsoft make all 2>&1 | less
--output omitted--
```

## 将标准输出与标准错误分离

程序员使用此类结构，以便将输出显示在一个终端窗口中，而错误显示在其他窗口中。首先使用 `tty` 命令找到你正在使用的哪个伪终端：

```bash
andy:~/newsoft make all 2> /dev/pts/7
```

## 同时写入输出和文件

你可以使用 `tee` 命令将输入复制到标准输出以及一个或多个输出文件。使用 `tee` 的 `-a` 选项可以将结果追加到文件（们）中。如果你想查看又要保存输出，此命令非常有用。`>` 和 `>>` 操作不支持同时执行这两个操作。

此工具通常通过管道（`|`）调用，如下例所示：

```bash
mireille ~/test> date | tee file2
Thu Jun 10 11:10:34 CEST 2004
```

```bash
mireille ~/test> cat file1
Thu Jun 10 11:10:34 CEST 2004
```

```bash
mireille ~/test> cat file2
Thu Jun 10 11:10:34 CEST 2004
```

## 过滤器

```bash
mireille ~~/test> uptime | tee -a file2
11:10:51 up 21 days, 21:21, 57 users, load average: 0.04, 0.16, 0.26

mireille ~~/test> cat file2
Thu Jun 10 11:10:34 CEST 2004
11:10:51 up 21 days, 21:21, 57 users, load average: 0.04, 0.16, 0.26
```

当程序对输入进行操作并将结果写入标准输出时，它被称为过滤器。过滤器最常用的用途之一是重构输出。我们将在下面讨论几个最重要的过滤器。

## 更多关于 `grep`

正如我们在“`grep` 命令”节中所看到的，`grep` 逐行扫描输出并搜索匹配模式。所有包含该模式的行将打印到标准输出。可以使用 `-v` 选项反转这种行为。

一些示例：假设我们想知道某个目录下的哪些文件在二月被修改过：

```bash
jenny:-> ls -la | grep Feb
```

`grep` 命令像大多数命令一样对大小写敏感。使用 `-i` 选项可以忽略大小写。此外，还有许多 GNU 扩展可用，例如 `--color`，有助于在长行中高亮搜索词，以及 `--after-context`，它可以打印最后一条匹配行之后的行数。你可以使用 `-r` 选项使用递归 `grep`，它会扫描遇到目录的所有子目录。像常一样，选项可以组合。

可以使用正则表达式进一步详细说明你想要从所有输入行中选择的精确匹配。使用正则表达式的最佳方法是阅读 `grep` 文档。`grep` info 中包含了一个非常出色的章节。由于这会使我们在讨论正则表达式的细节方面走太远，如果你想了解更多关于它的信息，强烈建议从这里开始。

尝试玩玩 `grep` 吧，花些时间研究这个最基础但也最强大的过滤命令是值得的。本章末尾的练习将帮助你入门，请参“练习”节。
