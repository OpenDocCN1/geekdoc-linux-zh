
## man whatis
`whatis(1)`

### NAME
`whatis` - 在 whatis 数据库中搜索完整单词。

### SYNOPSIS
`whatis keyword ...`

### DESCRIPTION
`whatis` 在包含系统命令简短描述的数据库文件中搜索关键字，并将结果输出到标准输出。仅显示完整单词匹配。
`whatis` 数据库是使用命令 `/usr/sbin/makewhatis` 创建的。

### SEE ALSO
`apro(1)`, `man(1)`.

`whatis` 类似于 `man -k`，但只搜索完整的关键词。

```
whatis keyword
```

```
$ whatis less (3) perl pragma 指示在编译时请求更少的内容
```

```
$ alias

alias l1l='/bin/ls -A'
alias l1l='ls -la'
alias mv='mv -i'
alias rm='rm -i'
## alias j='jobs -1'
## alias j
alias j='jobs -1'
## unalias j
```

## 管理文件/目录

`cd` 工作目录。

```
cd [path]

$ cd
$ pwd
/home/miss_scarlet
$ cd ~candace
$pwd
/home/candace
```

`chmod` 设置文件/目录权限。

```
chmod [option]... mode[,mode]... file
$ ls -l dead.letter
-rw-r--r-- 1 miss_sca bad-guys 1357 Feb 21 18:03
dead.letter
$ chmod +rx dead.letter
$ ls -l dead.letter
-rwxr-xr-x 1 miss_sca bad-guys 1357 Feb 21 18:03
dead.letter
```

`chown` 修改文件所有权。

```
chown [OWNER][[GROUP]] FILE
## chown candace dead.letter
$ ls -l dead.letter
-rwxr-xr-x 1 miss_sca bad-guys 1357 Feb 21 18:03
dead.letter
```
