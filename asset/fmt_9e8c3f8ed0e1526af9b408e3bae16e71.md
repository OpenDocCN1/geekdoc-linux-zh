# 学习 USB

工程师们找到了 Jan Axelson 编写的《USB Complete》，该书声称可以告诉你“开发 USB 外设设备所需的一切知识”。书的前半部分解释了 USB、数据传输和设备识别（称为枚举）。后半部分讨论了使用芯片组的设备硬件设计。书的内容与开发 Linux USB 驱动程序并不完全匹配，但它为 USB 通信提供了极好的介绍。以下是工程师们学到的知识：

- USB 总线是异步串口，采用差分信号。
- USB 是即插用的；用户不需要配置内存地址、I/O 地址、中断或直接内存访问（DMA）。
- USB v1.1 支持 12Mbps 的数据传输率。
- USB v2.0 相对较新，支持 480Mbps 的数据传输率。
- 总线支持最多 127 个设备，使用集线器和设备的分层拓扑结构。
- USB 设备是自描述的。
- USB 支持四种传输模式，满足不同设备的带宽需求：
  - 中断传输支持周期性带宽。
  - 同步传输支持保证带宽。
  - 控制传输支持保证总线访问。
  - 批量传输支持低优先级的大数据传输。
- USB 控制器通过使用这四种传输模式来优化总线通信，从而优先考虑通信。

除了提供电气和通信协议规范外，USB 还为常见外设定义了若干设备类，如音频设备、鼠标设备、键盘、打印机和大容量存储设备。实现设备类的外设设备可以利用现有的主机设备驱动程序代码。设备类促进了互操作性。

许多 USB 外设设备不属于定义的设备类，例如视频设备、以太网设备、MP3 播放器以及串/并行转换器。这些设备的制造商必须开发设备驱动代码。

USB 主控制器分为两类：通用主机控制器接口（UHCI）和开放主机控制器接口（OHCI）。这些控制器在功能上相互不同；UHCI 控制器从硬件角度来看更简单，并将部分处理交给主机 CPU 和驱动程序，增加了驱动程序的复杂度。许多供应商提供 UHCI 和 OHCI 主控制器。

工程师们继续研究，发现了 Linux USB 项目官网（www.linux-usb.org）和《Linux 设备驱动程序编程指南》。通过浏览这些，他们发现了 Linux USB 驱动程序的复杂性。《USB Complete》的前半部分明确了 USB 通信并不简单。《USB 编程指南》证实了这一点。工程师决定 Project Trailblazer 不开发任何 USB 驱动程序代码，因为陡峭的学习曲线会影响开发进度。

Linux USB 项目官网提供了丰富的 USB 信息。Linux 对 USB 的支持始于 1996 年，名为通用 USB 驱动程序（UUSB）。1999 年，Linus Torvalds 开发了 Alternate USB 驱动程序并根据 GPL 许可证发布。在其他 Linux 内核的基础上，一组开发和测试人员修复并增强了 Alternate USB 驱动程序。随后，一个完整的 USB 驱动程序重写版本成熟并整合到内核版本 2.4.x 的配置过程中，并已回传到内核版本 2.2.18。对于设备类（音频设备、鼠标设备、键盘和大容量存储设备）以及许多特定厂商的驱动程序（扫描仪、视频设备、以太网设备、MP3 播放器和串/并行转换器），已经开发完成。若干特定厂商的驱动程序被纳入内核进程，而其他的则作为可加载模块单独编译。

Project Trailblazer 的工程师通过阅读《Linux USB 子系统》继续学习。这份早期草稿为内核修订版本 2.4.0-test9 的 USB 提供了极好的介绍和使用指南。当工程师们为 Linux 研究 USB 时，内核版本 2.4.10 发布了。他们理解 USB 驱动程序的开发在不断演进。这引导他们访问 Linux-USB 设备概览网站，该网站作为当前 Linux USB 驱动程序信息的库，并将驱动程序分类为：音频、通信、人机接口、集线器、图像、键盘、大容量存储、多功能、网络、打印机、扫描仪、厂商和视频。该网站提供了设备和驱动概览、可搜索索引以及添加和编辑设备信息的功能。这个 USB 信息中心使工程师能够选择具有可用 Linux USB 驱动程序的硬件。
