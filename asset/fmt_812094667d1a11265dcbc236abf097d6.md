## 项目 9A：安装 Ubuntu 存储库未提供的 DEB 软件包：Automatix

你可能记得，你通过 Synaptic 或 Add/Remove Programs（添加/删除程序）从各种 Ubuntu 存储库安装的应用程序都是 DEB 包——而存储库中充满了此类软件包。遗憾的是，尽管这些存储库似乎包含了市上的每一个软件，但由于各种原因，并不是每个包都能进入存储库，即使它以 DEB 格式可用。目前，Automatix 应用程序就是其中之一。

有趣的是，Automatix 是强大的 APT 包管理软件的另一个前端，而 APT 是所有基于 Debian 的系统的结构核心。与 Synaptic 类似，Automatix 为你提供了选择、下载和安装包的图形化方法。但不同的是，Automatix 提供了一种相当自动的方法，让你填补由于许可和版权问题在你的发行版中留下的所有空白。我不知道我在说什么，我指的是 MP3 播放和编码、解密 DVD 播放，以及允许你向硬盘上的 NTFS 分区写入数据。你可以不使用 Automatix 就完成这一切，但使用它会让这个过程变得毫不费脑。

### 9A-1：获取并安装 Automatix

获取和安装 Automatix 是一个简单的过程。开始之前，访问`www.automatix.com`，然后点击 Install 按钮。在下一页，点击图 9-1 所示的 URL。之后，点击 Install 按钮。一旦窗口出现，点击 OK 按钮。在下一个屏幕中，按一次 TAB 键然后按 ENTER 选择 Yes。在白色文字滚动一两秒后，你将回到常规 Automatix 窗口，Skype 已经安装完成。

### 9A-2：运行 Automatix

一旦安装 Automatix，你可以转到 Applications（应用程序）菜单并选择 Internet Skype 来运行它。在设置好 Skype 用户账户后，我建议你重启电脑。Skype 在初始重启后音质似乎会更好。

### 9A-3：使用 Skype 安装软件

## 项目 9B: 使用 Alien 将 RPM 转换为 DEB 包

虽然并不是所有的 DEB 软件包都能进入 Ubuntu 仓库，这是事实，但确实有少数应用程序根本没有 DEB 软件包的形式提供。然而，有些程序是以 RPM 格式提供的，RPM 是 Red Hat、Fedora、Mandriva 以及其他少数 Linux 发行版使用的软件包。虽然这对于 Ubuntu 用户来说听起来可能并不乐观，但一个名为 Alien 的方便实用程序带来了一丝希望。

如果你还没猜到的话，Alien 的作用是将 RPM 软件包转换为 DEB 软件包，这样你就可以在基于 DEB 的系统中安装并运行它们。它不能 100% 保证成功，也不如从源码正确编译的 Deb 软件包那样理想，但如果你需要某个特定的应用程序，它可能就能完成任务。所以尝试一下 Alien 吧，我们将转换并安装一个名为 TuxCards 的应用程序（如图 9-5 所示），它自称为*层级笔记本*。

![](img/ba6b82a7869bba748202d57c97336dca_177_0.png)

#### 图 9-5: TuxCards–一个层级笔记本

### 9B-1: 安装 Alien

在下载、转换和安装 TuxCards RPM 之前，你必须先安装 Alien。幸运的是，可以通过 Synaptic 获取 Alien，你只需要搜索 `alien`，然后按照标准的安装程序操作即可。如果你愿意，可以使用上一章学过的 `apt-get` 命令来下载并安装。如果你选择这条路线，先输入 `sudo apt-get update` 并按回车。在仓库数据库更新完成后，输入 `sudo apt-get install alien` 并按回车来安装 Alien。

### 9B-2: 获取 TuxCards RPM

安装 Alien 后，你需要下载 TuxCards RPM。你可以从`www.tuxcards.de/requirements.html`获取。在该页面上，右键点击 `tuxcards-1.2.imdk.i586.rpm`，然后在弹出菜单中选择 **Save Link As**（另存链接）。页面上还有其他可用版本，但为了本项目的考虑，请坚持我提到的那个。

下载完成后，确保将 RPM 文件放在你的主目录中（如果它不在那里的话）。

### 9B-3: 转换 TuxCards RPM

现在 TuxCards RPM 已经在你的主目录中了，你可以通过输入以下命令并按回车，使用 Alien 将其转换为 Ubuntu 的 DEB 包：

```bash
sudo alien --scripts tuxcards*.rpm
```

在你输入密码后，似乎并没有发生什么变化。但是，你会在终端看到生成 `tuxcards_3.2.2._i386.deb`（或类似名称）的消息。

### 9B-4: 安装新生成的 DEB 包

一旦生成了 DEB 包，你就可以使用在本章学过的 `dpkg` 命令来安装它：

```bash
sudo dpkg -i tuxcards_3.2.2._i386.deb
```

### 9B-5: 运行 TuxCards

应用程序安装完成后，你就可以从应用程序菜单或终端运行它了。

# Tarballs：源码的容器

几乎所有的软件包都以 tarballs 的形式出现（tarballs、DEBs 甚至 RPMs，例如用于基于 Red Hat 系统的程序，统称为软件包，这就是为什么此类文件的图标看起来像一个包裹盒）。正如你在第 6 章和第 8 章中所学到的，tarballs 由一组被归档到单个文件中的文件组成，为了节省磁盘空间，这些文件通常会被压缩，类似于 Windows 上的 Zip 文件或 Mac 上的 SIT 文件。在 Linux 中，创建存档的最常用方法是通过 `tar` 程序，tarball 正也由此得名，其压缩通常通过 `bzip` 程序完成。因此，压缩后的 tarballs（或 tarballs）可以通过其文件后缀名识别，即 `.tar.gz`，或者使用 `bzip` 程序压缩后的 `.tar.bz2`。

正如你在第 8 章中所学到的，归档在 tarballs 中的文件可以使用命令行进行提取，但为了让本章内容保持简单，如果你愿意，也可以直接使用你在第 6 章中使用过的简单双击方法。
