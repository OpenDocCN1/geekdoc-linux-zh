## 指定图像大小

`<img>` 标签的两个额外属性 `WIDTH` 和 `HEIGHT` 可以帮助提高连接缓慢客户端的性能。这些设置允许你以像素指定图像的大小。它们还让像 Netscape Navigator 这样的浏览器在页面到达浏览器时显示，无需等待下载图像即可渲染文本。没有这些设置，渲染会被延迟，因为客户端必须检索图像以计算其在页面上的大小。这些设置允许你在不修改图像的情况下对其缩放；你只需要为实际的大小指定不同的 `HEIGHT` 和 `WIDTH` 设置，浏览器就会将图像缩放到这些尺寸。

- 不建议指定比实际图像大或提供不同宽高比例（即高度与宽度的比例）的值。如果这样做，GIF 和 JPEG 格式的图像可能无法正确缩放导致失真。我们将在本章稍后讨论更多关于 GIF 和 JPEG 图像格式的知识。

要使用这些设置，你需要知道图像的尺寸。如果你不知道尺寸，可以使用多种工具中的任何一个获取这些信息。（请参阅本章后文“查看图像”和“操作颜色映射与转换图像格式”章节。）当你知道图像的尺寸后，可以如下所示将它们添加到 `<IMG>` 标签中：

```html
<IMG SRC="earth.gif" ALT=" HEIGHT=125 WIDTH=125>
```

## 链接与边框

在使用纯文本指定 HTML 链接时，默认情况下，文本将显示为与屏幕上其他文本不同的颜色。用作链接的图像可以设置为另一种颜色，因此为它们提供了一个与文本链接相同色的边框。这允许用户识别出图像是可以点击的链接。用于设置边框宽度的 `<IMG>` 属性是 `BORDER`。你提供的值是边框的厚度（像素）：

```html
<IMG SRC="earth.gif" ALT=" BORDER=4>
```

虽然很少有人使用 `BORDER` 为普通的内联元素添加边框，但此设置通常赋值为 0，以移除作为按钮的超链接内联元素周围的边框，或者父级内联图像映射周围的边框（参见本章后文的“将图像作为网页内容”）。

## 低分辨率代理

Netscape Navigator 还允许你通过 `<IMG>` 标签的 `LOWSRC` 设置为内联图像指定低分辨率版本。你可以如下所示使用此设置：

```html
<IMG LOWSRC="lowres.jpg" SRC="hires.gif">
```
