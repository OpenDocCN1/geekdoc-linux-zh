
| 权限 | 八进制数 |
| :--- | :--- |
| 用户 ID。 | 4 |
| 组 ID。 | 2 |
| 设置粘滞位。 | 1 |

> **注意**
>
> 绝对模式下的第四位数字是可选的。

## 更改其他文件属性

除了所有者、组和权限之外，你还可以在本地 Linux (`ext2`) 文件系统上设置其他文件属性。

*输入：*`chattr OPTIONS ACTIONS ATTRIBUTES FILES`。

每个部分的可能条目在下面某个表格中有解释。

不要在操作参数和属性参数之间留有空格。

### `chattr` 命令（更改属性）：选项

| 选项 | 操作 | 注释 |
| :--- | :--- | :--- |
| `-R` | 更改子目录及其内容的属性。 |  |
| `-V` | 在屏幕上显示操作。 |  |

### `chattr` 命令（更改属性）：操作

| 操作 | 参数 |
| :--- | :--- |
| 添加属性。 | `+` |
| 移除属性。 | `-` |
| 仅设置指定的属性并移除所有其他属性。 | `=` |

### `chattr` 命令（更改属性）：属性

| 属性 | 参数 |
| :--- | :--- |
| 当文件被修改时，日期和时间不会更新。 | `A` |
| 材料只能添加到文件末尾。现有内容不能更改。 | `a` |
| 文件只能由 root 用户修改。 | `i` |
| 文件删除后无法恢复。 | `S` |
| 文件不能被删除。 | `u` |
| 不包括在使用 dump 进行备份中。 | `d` |

## 查看由 `chattr` 命令设置的属性

文件按每行一个的方式显示。

### `lsattr` 命令（列出属性）的选项

| :--- | :--- | :--- |
| `-a` | 列出所列目录中的所有文件。 |  |

# 10 读取系统信息

Linux 是由具有实践精神的计算机用户构建的。因此，你的系统包含许多用于显示信息的命令行工具。

你可以查看以下信息：

- 操作系统和硬件。
- 系统上正在运行的进程。
- 正在使用的内存和可用内存。
- 用户。

你可以通过以下方式收集信息：

- 使用命令行工具。
- 查看 `/proc` 目录中的文件。
- 读取日志文件。

虽然为某些命令行工具制作了对应的图形化工具，但它们通常不如命令行工具完整和灵活。
