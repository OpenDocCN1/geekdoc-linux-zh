## 薛定谔方程

一种随时间演变的波函数的线性齐次偏微分方程。

量子力学在20世纪沿着两条不同的路线发展，分别由海森堡（W. Heisenberg）和薛定谔（E. Schrödinger）。薛定谔无法解释爱因斯坦关于粒子能量（光子）断言中发现的波粒二象性，光被称为电磁辐射，具有确定能量的波性。例如，`$h = 6.626 \times 10^{-34}$` 焦秒是自然界的常数，由普朗克（M. Planck）引入。他的电磁频率与黑体辐射光谱相。这种波的概念在1923年被布罗意（B. Broglie）证实，他假设了与电子等粒子相关的波状现象的存在。参见粒子（PARTICLE）。

经典动力学与几何光学在材料中电磁信号传播之间存在某些纯数学上的相似性。对于在势 `$V$` 中运动的粒子，这种类比导致了波函数 `$\psi$` 的运动，它遵循方程 (1)：

```
$i\hbar \frac{\partial\psi}{\partial t} + V\psi = E\psi$
```

这里 `$m$` 是粒子的质量，`$E$` 是它的能量，`$E = h\nu$`；`$\psi^2$` 是概率的平方。参见计算：几何光学（CALCULATORS OF: GEOMETRICAL OPTICS）；拉普拉斯（LAPLACIAN）。

可以提出一个更一般的方程，因为依赖于空间的波函数 `$\psi_t$` 可能遵循方程 (2)，现在被称为薛定谔方程。

```
$i\hbar \frac{\partial\psi_t}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\psi_t + V\psi_t$
```

波函数可以推广到包含多个粒子的系统 `$\psi$`。每个粒子并没有分配单独的波函数。只有一个波函数 `$\psi_1, \psi_2, ..., \psi_n$`，它依赖于所有的位置坐标以及时间。这个位置变量空间称为构型空间。广义薛定谔方程是方程 (3)，其中势 `$V$` 可能依赖于所有位置。

```
$i\hbar \frac{\partial\Psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2\Psi + V\Psi$
```

该方程的显著特征如下：

1. 方程中出现了复数（负1的平方根）。`$\psi$` 通常是如此。参见复数（COMPLEX NUMBERS）；变分理论（VARIATION THEORY）。

2. 时间导数是一阶的。因此，如果已知任意时刻波函数作为位置函数，则它对所有后续时间都有定义。

3. 薛定谔方程对于 `$\psi$` 是线性且齐次的，这意味着如果 `$\psi$` 是一个解，那么 `$c\psi$` 也是解，`$c$` 是任意常数。通常，如果 `$\psi_1$` 和 `$\psi_2$` 是解，那么它们的线性组合 `$c_1\psi_1 + c_2\psi_2$` 也是解。参见叠加原理（SUPERPOSITION PRINCIPLE）。

薛定谔方程对概率给出了解释。只要波函数在构型空间上是平方的，根据方程 (3)，关于时间的 `$\Psi$` 由方程 (4) 定义：

```
$\Psi = |\psi_1|^2, |\psi_2|^2, ..., |\psi_n|^2$
```

可以通过归一化 `$\psi$`（通过使其成为合适的解）来确保该波等于1。根据这一规则，薛定谔方程显示表达式 (5) 是在 `$t$` 时在体积元 `$dx_2$` 和 `$dx_n$` 中找到 `$p$` 的概率密度。[S.T.]
