# USB 图像捕捉：Kensington VideoCAM

Kensington VideoCAM 是一种廉价 USB 摄像头，提供高达 800x600 像素的图像分辨率。该摄像头以每秒 24 帧的速度传输视频。Project Trailblazer 不需要视频流——只需要捕捉。摄像头的高分辨率为 guest 和 Silverjack 使用提供了高质量的图像。

在内核配置程序 `make menuconfig` 的 USB 支持中，没有 Kensington 摄像头选项。工程师不知道从哪里开始。他们只是插上摄像头，控制台就产生了几百行文本。查看日志文件，工程师发现了这些行：

```
Oct 7 19:54:16 tbdev1 kernel: hub.c: USB new device connect on bus/2, assigned device number 4
Oct 7 19:54:16 tbdev1 kernel: Product: VideoCAM
Oct 7 19:54:16 tbdev1 kernel: usb.c: USB device 4 (vend/prod 0x47d/0x5003) is not claimed by any active driver
```

`vend/prod` 信息提供了关键。工程师在 Linux-USB 设备概览查询了 `0x047D` 和 `0x5003`，发现是 Kensington 摄像头使用 `se401` 驱动。在 USB 支持菜单下有一个针对 `se401` 的内核配置选项。在本节中，你将在 `tbdev1` 上执行以下步骤：

1. 为视频操作和 `se401` 使用配置内核。编译并安装内核，然后重启 `tbdev1`。
2. 连接 Kensington 摄像头。
3. 下载并编译一个名为 `vgrabb` 的控制台视频帧捕获程序，然后捕获视频图像。

### 提示

厂商和产品信息对可以识别唯一的 USB 设备。设计通常会授权给几家公司进行生产和销售。例如，两家公司可能基于相同的硬件设计提供 USB 摄像头。这些摄像头从电气角度来看是相同的，并且可以使用相同的 USB 驱动程序。如果你找不到 USB 设备的驱动程序信息，请使用厂商和产品信息对。
