## 目录

Sysvinit 软件包包含 `pidof`, `last`, `lastb`, `mesg`, `utmpdump`, `wall`, `halt`, `init`, `killall5`, `poweroff`, `reboot`, `runlevel`, `shutdown`, `sulogin` 和 `telinit` 程序。

### 描述

### pidof

`Pidof` 查找命名程序的进程 ID (pids)，并将这些 ID 输出到标准输出。

### last

`last` 搜索 `/var/log/wtmp` 文件（或由 `-f` 标志指定的文件），显示自该文件创建以来所有登录（并注销）的用户列表。

### lastb

`lastb` 与 `last` 相同，但它默认显示 `/var/log/btmp` 文件的日志，该文件包含了所有失败的登录尝试。

### mesg

`Mesg` 控制其他对你终端的访问。它通常用于允许或禁止其他用户写入你的终端。

安装 Sysvinit 168

### utmpdump

`utmpdump` 以用户友好的格式将文件（通常是 `/var/run/utmp`）的内容打印到标准输出。

### wall

`Wall` 向所有 `mesg` 权限设置为 yes 的登录用户发送消息。

### halt

`Halt` 在 `/var/log/wtmp` 文件中记录系统正在关闭，然后告诉内核停止、重启或关机系统。如果当系统不在运行级别 0 或 6 时调用了 `halt` 或 `reboot`，则将代调用 `shutdown`（带有 `-h` 或 `-r` 标志）。

### init

`Init` 是所有进程的父进程。它的主要作用是根据存储在 `/etc/initab` 文件中的脚本创建进程。该文件通常包含条目，导致 `init` 在用户登录时在每行上生成 `get {`。它还控制任何特定系统所需的自主进程。

### killall5

`killall5` 是 SystemV 的 `kill` 命令。它向其所在会话进程之外的所有进程发送信号，因此它不会杀死运行该脚本的 shell。

### poweroff

`poweroff` 等同于 `shutdown -h -p now`。它停止电脑并关闭电脑（当使用兼容 APM 的 BIOS 且内核中启用 APM 时）。

### reboot

`reboot` 等同于 `shutdown -r now`。它重启电脑。

### runlevel

`Runlevel` 读取系统 utmp 文件（通常为 `/var/run/utmp`）以定位运行级别记录，然后在标准输出上打印之前的和当前的系统运行级别，之间用单个空格隔开。

### shutdown

`shutdown` 以安全的方式关闭系统。所有登录的用户都会收到系统即将关闭的通知，登录会被阻止。

### sulogin

系统进入单用户模式时，`init` 调用 `sulogin`（这是通过 `/etc/initab` 中的条目实现的）。当从启动监视器（例如 LILO）传递 `-b` 标志时，`init` 也会尝试执行 `sulogin`。

### telinit

`telinit` 向 `init` 发送适当信号，告诉它切换到哪个运行级别。
