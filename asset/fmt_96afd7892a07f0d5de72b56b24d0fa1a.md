## 创建倒计时指示器

有时你可能希望某些操作超时。如果我们知道允许任务完成的大致时间，我们就可以显示一个倒计时指示器；那么，当时间到时，我们就可以采取行动。在这一点上发挥你的想象力。我们将使用的过程将取决于当前倒计时的数字位数，例如 0 到 9，10 到 99，100 到 99。

```bash
#!/bin/ksh
# AUTHOR: Michael Kelly
# DATE: 2005-05-12
# DESCRIPTION: 倒计时指示器
# PURPOSE: 此脚本在屏幕上显示倒计时。
# PLATFORM: Solaris
# VERSION: 1.0

####################################
# Begin of Main #
####################################

function test_string
{
    # 此函数检查输入是否为正整数。
    if [[ $1 == +([0-9])* ]]; then
        return 0
    else
        return 1
    fi
}

function usage
{
    echo "Usage: $0 [seconds]"
    exit 1
}

# 检查是否提供了参数
if [ $# -ne 1 ]; then
    usage
fi

# 检查参数是否为正整数
if ! test_string "$1"; then
    echo "Error: $1 is not a positive integer."
    exit 1
fi

SECONDS=$1

while [ $SECONDS -gt 0 ]; do
    echo -n "Time remaining: $SECONDS seconds "
    sleep 1
    SECONDS=$((SECONDS - 1))
done

echo
echo "Time's up!"
```

**Listing 4.5** 倒计时指示器。

该脚本使用 `while` 循环对提供的秒数进行倒计时。在每次迭代中，它使用 `echo -n` 让输出保持在同一行，使用 `sleep 1` 等待一秒，并递减计数。当循环结束后，它打印 "Time's up!"。

# 进度指示

函数的输出将是用法说明（`usage`）而不是倒计时。这种在使用 `basename` 命令时的这种细微区别是一个常见的错误。

接下来我们有 `trap_exit` 函数，它将在退出信号 1、2、3 和 15 上执行（其中我们无法捕获 -9）。这个 `trap_exit` 函数将向用户显示 `...EXITING` 作为一个信息性消息。

`test_string` 函数用于测试是否为整数值或大于 0。为了测试整数，我们在 `case` 语句中使用正则表达式 `+([0-9]+)`。如果值是大于或等于 0 的整数，则该正则表达式为真。在第 1 章中，有一个非常详尽的 `test_string.ksh` 脚本，其中包含了小写字母、大写字母、混合大小字符串、数字和字母字符。正则表达式对于测试字符串非常有用，且使用灵活。

我们通过设置 `trap` 来捕获退出信号 1、2、3 和 15 来开始脚本部分。在这些信号触发时，我们执行之前介绍过的 `trap_exit` 函数。

设置陷阱后，我们检查是否恰好有一个命令参数；如果参数多于或少于一个，我们就运行 `usage` 函数并以返回码 1 退出。

接下来是命令行参数的整数检查。为了实现这一点，我们使用 `test_string` 函数并将输出赋值给变量 `INT_STRING`。`test_string` 将返回 `POS_INT`，否则我们将通知用户无效，运行 `usage` 函数并以返回码 1 退出。

如果执行到这一步，我们知道得到了一个正数，因此需要确保该整数在该 脚本的范围内。范围是 1 到 9999 秒，即 2.78 小时。如果值超出范围，我们将通知用户该值超出范围，运行 `usage` 函数并以返回码 1 退出。在这个 脚本中，所有的用法错误都以返回码 1 退出。

现在我们准备好开始倒计时了。倒计时在一个 `while` 循环中进行。在这个 `while` 循环中，注意 `if.then.elif.elif..` 控制结构和光标控制。此光标依赖于倒计时值的位数。我们需要通过这种方法进行控制，以便在 1000 和 999、100 到 99 以及 10 到 9 之间获得平滑过渡。如果你不用光标处理过渡，数字集将在转换过程中跨屏幕移动。对于光标，我们使用带有反斜杠 `\b` 的 `echo` 命令将光标后退一个空格。对于三个空格，我们使用 `\b\b\c`，最后的 `\` 让光标保持在同一行而不产生新的换行。因此，在每次循环迭代中，光标都会根据倒计时值的当前位数进行控制。

当倒计时到达 0 时，脚本将输出一个新行和回车，并以返回码 0 退出。
