# iraf

图像归算与分析设施 (天文学/成像) IRAF 是“图像归算与分析设施”。主要的 IRAF 分发版包含了用于通用图像处理和图形的优秀程序，以及大量用于光学和红外天文学归算与分析的程序（"noir" 软件包）。外部或分层软件包可用于数据采集或处理来自其他天文台和不同波段的数据，例如哈勃空间望远镜（光学）、EUVE（极紫外线）、ROSAT 和 AXAF（X射线）。这些外部软件包与主 IRAF 分发版单独分发，但可以轻松安装。IRAF 系统还包含一个用于科学应用的完整编程环境，包括一个可编程的命令语言脚本设施，以及编写可移植 IRAF 系统及其所有应用程序的 IMPORT Fortran/C 编程环境。来自 Debian 3.0r APT
