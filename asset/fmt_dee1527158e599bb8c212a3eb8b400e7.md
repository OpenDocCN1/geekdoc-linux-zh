core

当程序意外终止、由于 bug 或违反操作系统或硬件保护而终止时，会创建一个 core 文件。操作系统杀死程序并创建一个 core 文件，程序员可以使用它来确定发生了什么。它包含了程序死亡时的详细描述。如果你想确定是哪个程序产生了 core dump，使用 `file` 命令，例如：`$ file core` 将告诉你你产生 core dump 的程序名称。你可能想要启用或禁用 core dumps，使用 bash 中的 `limit` 命令， ksh 中的 `limit` 命令。查看相应的手册页获取详细信息。此设置直接或间接地影响 shell 程序而不是整个系统。在 `/usr/include/linux/sched.h` 中引用 `INIT_TASK` 的定义。在 `/usr/include/linux/resource.h` 中优化 PAM 环境，包括允许的内存。某些发行版中，此参数在 `/etc/security/limits.conf` 中配置。源自 Linux 管理指南

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

core

n. 主存储或 RAM。来自铁氧时代；现在位于 IBM 之外，但在 Unix 社区和老派黑客在使用。某些派生词是非常当前的；“in core”意味着“在内存中”（相对于“在磁盘上”），以及 core dump 和“core image”或“core file”。源自 Jargon 字典

http://www.p.org/LDP/Linux-Dictionary/index.html

core dump

当进程因某些内部错误中断时产生的 core 内容副本。对于确定程序崩溃的很有用。源自 Linux 指南 @FirstLinux

http://www.p.org/LDP/Linux-Dictionary/index.html

Core dump

在计算中，一种打印计算机核心（内存）内容的调试技术。在俚语中，该术语指一个人在被提问时，背诵关于某人的记忆。源自 QUEDIC

http://www.p.org/LDP/Linux-Dictionary/index.html

core dump

n. Unix 常见的产生。1. [技术书籍] 当进程因某些内部错误中断时产生的内容副本。2. 扩展地，用于人类昏倒或极端方案。“他崩溃了一地（dumped core）。到处都是一团糟。“他听说了并崩溃了。”3. 偶尔用于人类的胡言乱语，至少很棒；特别适用于：“抱歉，我对你崩溃了（dumped core）。”4. 知识的回顾（比较位，感知）。因此，每个人都知道关于某个主题的一切（同步，脑 dump），特别是在讲座或回答问题时。“简单简洁的回答比 core dump 更好”（来自哥伦比亚大学考试的说明）。源自 Jargon 字典

http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

这些是 GNU 工具。此包是旧的 GNU 工具、sh-utils 和 textutils 的结合。这些工具是常用的实用且流行的文本工具的 GNU 版本，用于文件管理——shell 修改文件（拆分、合并、比较……）。大多数程序与其对应版本相比具有显著优势，具有更高的速度、额外的选项和更少的限制。包含的工具有：basename cat chgrp chmod downown ck chmp chmv cp splat split date col dd dircolamos dirame du echo esprit factor falt fmt findst group head hostid id kill link logname me msud mknod etkki mkvc mi ni al nohop at us path paithk prink pr prinv prvint pft pwd md rmdir esq sha read sleep sleep sort flat stat sun su yac tam tac tee test touch tr test tru try when we need unique users vdr we with whom yomami yes 源自 Mandrake 9.0 RPM
