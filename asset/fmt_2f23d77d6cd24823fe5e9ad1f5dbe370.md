
Foomatic 是一个全面的、与打印程序无关的打印机、驱动程序和描述数据库。它包含用于使用数据库生成 `CUPS`、`LPD`、`PRNG` 和 `PDQ` 的驱动描述文件和打印队列的实用程序。还可以从支持 `PJL` 的打印机中读取 `PJL` 选项并在生成驱动文件时考虑它们。此外还有与打印程序无关的命令行接口用于管理队列（`foomatic-config`）和打印文件/处理作业（`foomatic jobprint`）。该网站 http://www.linuxprinting.org/ 是基于此的。

- 前台 (foreground)。[Unix; 常用] 将任务移动到栈的顶端以便立即处理，在非计算机任务中也经常用于此意义。“如果你的演示稿下周就要交，我最好把写设计文档的任务放在前台。”从技术上讲，在分时系统中，在前台执行的任务是能够接受用户输入和输出的任务；与后台相对立。现在这主要与 Unix 关联在一起，但似乎最早在 OS/360 上被这样使用。通常情况下有一个前台进程（或终端窗口）；多个进程同时读取键盘是导致失败的好方法。来自术语字典 (Jargon Dictionary) http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- 在多任务操作系统（如 UNIX）中，前台是用户当前正在交互的进程（例如，数据输入）。随着用户在不同程序之间切换，不同的程序可以在不同时间处于前台。在分层窗口环境中，它是最底层的。来自 I-log http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- 图形化浏览器 (Graphical Browser) 是一个为 Python 设计的新型图形化浏览器。它将让你浏览网络空间并处理各种类型的媒体，包括 HTML 和视频。来自 Debian 3.0r0 API http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- 分叉 (fork)。一种由进程（“父进程”）调用的 Linux 系统调用，用于创建自身的副本（“子进程”）。子进程与父进程相同，但它有不同的进程标识，且 `fork` 调用的返回值为0。假设它没有资源。来自 Linux Guide @FirstLinux http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- 分叉 (fork)。在开源社区中，分叉是指当两个（或多个）版本的软件包源代码并行开发时发生，这些版本共享共同的代码库，且这些多个版本的源码之间存在不可替代的差异。这不应与开发分支混淆，开发分支可能会被合并回原始代码库。它也不会与创建新的 Linux 发行版或其他发行版时发生的情况相混淆，因为那些大型组合部分可以且会在其他发行版中使用而不产生冲突。分叉并不常见；事实上，由于它是如此罕见，以至于实例在“锁柜跟随者（locker follower）”中挂起。值得注意的是 http://www.emacs.org/About/EMacsGNUmacros.html、`GCC/EGCS` 分叉（后通过合并愈合）以及来自 FreeBSD、NetBSD 和 OpenBSD 操作系统系统的分叉。来自术语字典 (Jargon Dictionary) http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- 分叉 (forking)。形容词；动词。1. [1997年后常见，尤其在 Linux 中] 指一个开源项目发生分叉或被分叉，将项目组分成两个或多个部分，导致开发路线的分离（或者较少见，作为与项目组无关的第三方）。分叉被认为是一件坏事——不仅是因为这意味着未来将浪费大量精力，还因为分叉往往伴随着继任小组之间在合法性、继承和方向设计问题上的激烈斗争和缩写词冲突。分叉面临着严重的社会压力。因此，主要的分叉（如 GNU-Emacs/XEm 分裂、36BSD 组分裂为三个子项目，以及寿命很短的 GCC/ECGS 分裂）非常罕见，以至于它们在民间传说中被单独记住。2. [独特的；不寻常；可能受到主流脏话的影响] 终极了，或死掉了。当一个系统被一个无意的分叉炸弹（fork bomb）慢到蜗牛速度时。来自 Jonathan 字典 (Jonathan Dictionary) http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

一个由程序员将输入作为 `printf(1)`（一种常用的 C 语言函数）的格式字符串而创建的常见漏洞。通常，`printf` 使用一个“字符串”来指定数据的格式化方式。在打印时间时，可以使用以下命令：`printf("%02d:%02d:%02d", hours, minutes, seconds);`。这将以类似于“09:15:00（一小时一刻）”的格式打印时间。格式字符串 `"%0d"` 表示一个 2 位的十进制，如果数字位数不够，它会在前面加一个 0。字符串也可以以类似的方式打印：`printf("%s", "hello");`，这会打印该字符串。`printf("%s", Hello);` 到此为止，一切正常。问题出现在当从输入读取格式字符串时：`g = read_input();` 程序员期望输出为 "Hi"。然而，由于格式字符串 `"%s"`，这可能导致程序崩溃。正确的方法是：`g = read_input(); printf("%s");`。由于使用了格式字符串，这可能导致程序崩溃。如果 `printf` 使用了格式字符串，系统可能存在漏洞。`printf("%x");` 这里的 `x`。由于系统可能存在格式化漏洞。
