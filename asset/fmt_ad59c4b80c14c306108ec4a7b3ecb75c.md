
定理 4.4 中的级数由 `$e^{-1}$` 无穷级数的前 `n + 1` 项组成，因此一组 `n` 个对象的错排数约为 `n e^{-1}`，且当 `n >= 6` 时，这个近似值非常精确。

### 4.3 斯特林数的公式

斯特林数 `S(n,k)` 在第 3 章中引入。它们给出了将 `n` 个不同的球放入 `k` 个相同的盒子中且没有空盒的方法数。定理 3.4 给出了这些数满足的递推关系*。我们现在可以利用问题 4.3 的论证来得到一个显式公式。

* 关于“递推关系”的含义，参见第 7 章 7.3 节。

#### 定理 4.5

对于所有满足 `1 <= k <= n` 的整数 `n, k`，

$$S(n, k) = \frac{1}{k!} \sum_{s=0}^{k-1} (-1)^s C(k, s)(k - s)^n. \quad (4.7)$$

### 证明

我们在第 3 章中指出，`k! S(n, k)` 是将 `n` 个不同的球放入 `k` 个不同的盒子中且没有空盒的不同方法数，这也等同于从具有 `n` 个元素的集合到具有 `k` 个元素的集合的满射函数（surjective functions）的数量。因此，我们可以通过计算这个数量然后除以 `k!` 来得到 `S(n, k)` 的公式。我们可以取 `A = {1, ..., n}` 作为我们的 `n` 元素集合，并设 `B = {1, ..., k}` 为我们的 `k` 元素集合。从 `A` 到 `B` 总共有 `k^n` 个不同的映射。我们计算这些映射中不是满射的数量。对于 `1 <= i <= k`，设 `X_i` 为那些不取值为 `i` 的映射 `f: A -> B` 的集合。因此，我们的目标是计算 `#(union_{i=1}^k X_i)` 的值。自然地，我们通过使用容斥原理来完成，该原理告诉我们：

$$\# \left( \bigcup_{i=1}^k X_i \right) = \sum_{i=1}^k (-1)^{i+1} \sum_{1 \leq i_1 < \dots < i_j \leq k} \#(X_{i_1} \cap \dots \cap X_{i_j}). \quad (4.8)$$

我们现在使用的论证是我们以前见过的一种。从 1 到 `k` 的范围中选择数字 `i_1, ..., i_s` 有 `C(k, s)` 种方法。对于每一种选择，`X_{i_1} \cap ... \cap X_{i_s}` 是那些不取任何值 `i_1, ..., i_s` 的函数 `f: A -> B` 的集合。因此，对于这个集合中的每个函数 `f`，对于每个满足 `1 <= j <= n` 的整数 `j`，`f(j)` 有 `(k - s)` 种选择。因此 `#(X_{i_1} \cap ... \cap X_{i_s}) = (k - s)^n`。因此，根据公式 4.8，

$$\# \left( \bigcup_{i=1}^k X_i \right) = \sum_{i=1}^k (-1)^{i+1} C(k, s)(k - s)^n,$$

因此，满射函数 `f: A -> B` 的数量是

$$k^n - \sum_{i=1}^k (-1)^{i+1} C(k, s)(k - s)^n = \sum_{s=0}^k (-1)^s C(k, s)(k - s)^n.$$

因此可得

$$S(n, k) = \frac{1}{k!} \sum_{s=0}^k (-1)^s C(k, s)(k - s)^n. \quad (4.9)$$

当 `s = k` 时，`(k - s)^n = 0`，公式 4.9 中求和的最后一项为 0，因此公式 4.9 等价于我们旨在证明的公式 4.7。由此证明完毕。

# 斯特林数与卡特兰数

### 5.1 斯特林数

学习数学的乐趣之一，在于发现相同的思想、数字等如何在不同的场景中不断出现。特别是对于（集合形式的）数字而言，许多数字都以著名数学家的名字命名，通常是它们的创始人或主要研究者。除了众所周知的斐波那契数列外，还有以费马、伯努利、欧拉、梅森、卢卡斯、卡迈克尔、拉姆齐（我们将在第 16 章中遇到他）以及更多人名命名的数字。*

在本章中，我们仅考虑两类数字，一类以苏格兰数学家斯特林的名字命名，另一类以法国/比利时数学家卡特兰的名字命名。前者确实是由斯特林引入的，而后者基本上是由欧拉引入的，不过在卡特兰之前，其他数学家也研究过它们。那么，是哪些问题促成了这些数字的产生？

在他的著作《微积分方法》（*Methodus Differentialis*，1730 年；紧随其同名论文 1719 年发表）中，詹姆斯·斯特林† 引入了方法，通过这些方法，他可以快速且精确到许多小数位地确定各种缓慢收敛级数的近似值。例如，他能够计算 `sum_{n=1}^{infty}(1/n^2)` 到小数点后 17 位。（如果天真地直接计算，大约需要添加前 1,000,000,000 项！）为了做到这一点，斯特林需要确定当所谓的*下降阶乘多项式* `x(x-1)(x-2)...(x-[n-1])` 被写成形式 `a_{n,n} x^n - a_{n,n-1} x^{n-1}+...+(-1)^{n-1} a_{n,1} x`（负号的选择使得所有项 `a_{n,k}` 均为正数）时产生的系数 `a_{n,k}`，以及反之，当 `x^n` 用下降阶乘多项式表示时产生的系数 `b_{n,k}`，即：

$$ x^{n}=b_{n,n} x(x-1)\cdots (x-[n-1])+b_{n,n-1} x(x-1) \cdots (x-[n-2])+... +b_{n,2} x(x-1)+b_{n,1} x. $$
