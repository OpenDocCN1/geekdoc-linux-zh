
`result = line.split(delimiter)`

## 第 6 章 函数与函数式编程

在本例中，我们像之前一样使用协程。然而，现在调用 `send()` 也会产生结果。例如：

```
>>> s = line_splitter(",*")
>>> s.next()
Ready to split
>>> s.send('A,B,C')
['A', 'B', 'C']
>>> s.send('100,200,300')
['100', '200', '300']
>>>
```

理解这个示例的执行顺序至关重要。第一次 `next()` 调用将协程推进到 `yield result`，它返回 `None`，即 `result` 的初始值。在随后的 `send()` 调用中，接收到的值被放入 `line` 并分割为 `result`。`send()` 返回的值是传递给下一个 `yield` 语句的值；换句话说，`send()` 返回的是下一个 `yield` 表达式，而不是接收 `send()` 传递的值的地方。

如果协程返回值，那么在处理通过 `throw()` 抛出的异常时需要注意。如果你在协程中使用 `throw()` 抛出异常，传递给协程中 `yield` 的值将作为 `throw()` 的结果返回。如果你需要这个值却忘记保存它，它就会丢失。

## 使用生成器和协程

初看，并不清楚如何用生成器和协程解决实际问题。然而，当生成器和协程应用于系统、网络和分布式计算中的某些编程问题时，它们特别有效。例如，如果你想建立一个处理流水线，生成器函数非常有用，这在本质上类似于使用 UNIX Shell 中的管道。引言中出现过一个示例。这里是另一个涉及一组打开、读取和处理文件的生成器示例：

```python
import os
import fnmatch
```

```python
def find_files(topdir, pattern):
    for path, dirname, filelist in os.walk(topdir):
        for name in filelist:
            if fnmatch.fnmatch(name, pattern):
                yield os.path.join(path,name)
```

```python
import gzip, bz2
def opener(filenames):
    for name in filenames:
        if name.endswith(".gz"): f = gzip.open(name)
        elif name.endswith(".bz2"): f = bz2.BZ2File(name)
        else:
            f = open(name)
        yield f
```

```python
def cat(filelist):
    for f in filelist:
        for line in f:
            yield line
```

```python
def grep(pattern, lines):
    for line in lines:
        if pattern in line:
            yield line
```

这里是一个使用这些函数建立处理流水线的示例：

```python
wwwlogs = find_files("www","access-log")
files = opener(wwwlogs)
lines = cat(files)
pylines = grep("python", lines)
for line in pylines:
    sys.stdout.write(line)
```

在这个示例中，处理的是在顶层目录 `"www"` 的子目录下找到的所有文件。每个 `"access-log"` 都会经过文件压缩测试，并使用适当的文件打开器打开。行被连接并通过一个查找子字符串 `"python"` 的过滤器进行处理。整个程序由最后的 `for` 语句驱动。循环的每次迭代都会通过流水线提取一个值并消耗它。此外，该实现是高度内存高效的，因为没有创建列表或大型数据结构。

协程可以编写基于数据流的程序。这种方式组织的程序看起来像倒置的流水线。你不是通过一系列生成器函数传递值，而是通过一组链接的协程发送值。这里是一个模拟之前所示生成器函数编写的协程函数示例：

```python
import os
import fnmatch
@coroutine
def find_files(target):
    while True:
        topdir, pattern = (yield)
        for path, dirname, filelist in os.walk(topdir):
            for name in filelist:
                if fnmatch.match(name, pattern):
                    target.send(os.path.join(path, name))
```

```python
import gzip, bz2
@coroutine
def opener(target):
    while True:
        name = (yield)
        if name.endswith(".gz"): f = gzip.open(name)
        elif name.endswith(".bz2"): f = bz2.BZ2File(name)
        else: f = open(name)
        target.send(f)
```

```python
@coroutine
def cat(target):
    while True:
        f = (yield)
        for line in f:
            target.send(f)
```

```python
@coroutine
def grep(pattern, target):
    while True:
        line = (yield)
        if pattern in line:
            target.send(line)
```

```python
@coroutine
def printer():
    while True:
        line = (yield)
        sys.stdout.write(line)
```

以下是你如何链接这些协程以创建一个数据流处理流水线：

```python
finder = find_files(opener(grep("python",printer())))
```

## 现在，发送一个值

```python
finder.send("www","access-log")
finder.send("otherwww","access-log")
```

在这个示例中，每个协程都将数据发送到指定的另一个协程以执行。与生成器示例不同，执行完全由将数据推入第一个协程 `find_files()` 驱动。在这个协程中，数据被推送到下一个阶段。这种方法的一个关键方面是，协程在显式调用 `close()` 之前保持活动状态。因此，程序可以根据需要持续向协程输入数据——例如上面所示的重复调用 `send()`。

协程可以用于实现并发功能。一个中心化的任务管理器或事件循环可以向成百上千个协程发送数据，以执行各种处理任务。输入数据被“发送”到协程的特性意味着协程可以轻松与使用队列和消息传递进行通信的程序混合。关于这方面的更多信息可以在第 20 章“线程”。

## 列表推导式

涉及函数的常用操作之一是对列表中的所有元素应用函数，创建一个包含结果的新列表。例如：

```python
nums = [1, 2, 3, 4, 5]
squares = [n*n for n in nums]
```

列表推导式的语法如下：

```python
[expression for item1 in iterable1 if condition1
    for item2 in iterable2 if condition2
    ...
    for itemN in iterableN if conditionN]
```

## 生成器表达式

生成器表达式是一个与列表推导式执行相同计算的对象，但它是迭代地产生结果。其语法与列表推导式相同，只是使用圆括号而不是方括号。这是一个示例：

```python
(expression for item1 in iterable if condition
```
