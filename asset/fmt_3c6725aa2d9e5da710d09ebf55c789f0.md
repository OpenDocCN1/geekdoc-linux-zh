# 属性: border-bottom

描述: 用于设置元素底部边框宽度、样式和颜色的复合属性

媒体类型(s): 视觉

示例:

```css
#sidebar {
  border-bottom: 2px dashed green;
}
```

> 提示：你不需要使用所有三个值。例如，如果你只想设置宽度，可以这样做并使用 `border-style` 和 `border-color` 属性来设置这些值。
