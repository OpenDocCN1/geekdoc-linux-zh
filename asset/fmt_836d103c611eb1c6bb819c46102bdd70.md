
# 周期运动

```
x(t+T)=x(t)
```

在该参数的某些范围内，可以增加振荡频率，直到观察到运动是周期性的。在参数的某个值之后，运动变得更加复杂（发生了分叉）；然而，在时间 `T` 内（即运动在分叉之前重复自身的时间后），运动仍然无法循环，尽管是重复的，但在7个周期后变为14个周期。这意味着周期从7倍增加到14倍。在新周期循环的前半部分后同步。

参数的进一步增加产生另一个分叉，导致周期的倍增；在两个周期之后，运动仍然无法重复，随着参数的增加，会出现连续的倍增，次数越来越多，直到在无限次之后出现一个临界值，使得运动不再具有周期性，并且具有比以前更复杂的特征。

然而，存在一个可能的定量值，在不知道系统 `s` 方程的情况下，通过预测参数值的所有数学模型，将无法给出产生该值的物理系统。因此，类似于热力学，问题可以用通用的方式提出和回答，即

任何运动都在规则间隔内识别自身。

如果 `x(t)` 代表任何时间 `t` 的循环状态，那么如果对于变量 `t` 的每一个值，由方程定义的属性都成立，则运动是周期性的。

```
x(t+T)=x(t)
```
