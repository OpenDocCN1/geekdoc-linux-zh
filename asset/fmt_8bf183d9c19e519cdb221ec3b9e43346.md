
`alias lm 'ls -*' | more`

调用时，将 `ls(1)` 的输出通过管道交给 `more(1)`。除了第一个单词外，别名的名称不能出现在其定义中，或其定义所引用的任何别名中。系统会检测此类循环并显示错误信息。

## I/O 重定向 (I/O Redirection)

以下元字符指示后续单词是文件名，命令的标准输入、标准输出或标准错误指向此处；此单词是变量、命令和文件名，与命令的其余部分分开扩展的。

`>` `<` 重定向标准输入。读取标准输入，直到遇到与单词相同的行，并将结果行放置在临时文件中。除非单词被转义或引用，否则将在这些行上执行变量和命令替换。然后，使用临时文件作为其标准输入调用管道。单词本身不经过变量、文件名或命令替换，在 shell 执行任何替换之前，每行都会与它进行比较。

`>` `>>` `&>` `>!` 重定向标准输出到文件。如果文件不存在，则创建它。如果存在，则覆盖；其原有内容将丢失。

当设置了变量 `noclobber` 时，它会防止现有文件被破坏。它还防止重定向到终端和 `/dev/null`，除非你使用了 `!` 形式的之一。`&` 将标准输出和标准错误（诊断输出）都重定向到该文件。

```
>> >>> >>!
```

追加标准输出。类似于 `>`，但将输出置于文件末尾而不是覆盖。如果设置了 `noclobber`，文件不存在将视为一个错误，除非你使用了 `!` 形式的之一。`&` 将标准错误和标准输出都追加到文件中。

注意 — 进程启动后对终端输出的控制是原始的；如果你需要更好的输出控制，请使用 Sun 窗口系统。

单独重定向标准输出和标准错误的唯一方法是调用子 shell，如下所示：

```
castle% (command > outfile) > errorfile
```

## 变量替换 (Variable Substitution)

`shell` 维护了一组变量，每个变量由一个名称和一个值组成。变量名由最多 20 个字母和数字组成，并以字母开头（下划线被视为字母）。变量的值是零或多个单词的空格分隔列表。

要引用变量的值，请在它的名称前加美元符号 (`$`)。你可以使用某些引用（下文描述）从显示内容中选择特定的单词或其他关于变量的其它信息。你可以使用大括号将引用与输入行单词中的其他字符隔离开。

变量替换发生在从命令行扩展的单词之后，但在命令名本身执行之前。然而，对于命令和文件名替换，命令和文件名替换会被选择性地应用于内置命令的参数。 (注：此处原文存在大量重复和乱码，已根据上下文逻辑处理)

## 命令替换

由反引号（``...``）括的命令由子 shell 执行。其标准输出在每个空格字符、Tab 键和换行符处拆分成单独单词；空单词会被丢弃。这段文本将替换当前行中的引号字符串。在双引号内，只有换行符会强制产生新单词；空格和 Tab 字符会被保留。然而，最后的换行符会被忽略。因此，命令替换可能会产生一个部分单词。

## 文件名替换

包含任何字符 `*`、`[`、`(` 或以此开头的未引号单词将被扩展（也称为通配符匹配）为按字母排序的文件列表，如下：

- `*` 匹配任意（0 个或多个）字符。
- `?` 匹配任意单个字符。
- `[...]` 匹配闭括号内列表或范围内的任意单个字符。列表是字符字符串。范围是由两个连字符 (`--`) 分隔的两个字符，并包括 ASCII 排序序列中间的所有字符。
- `{ str, str, ... }` 扩展为逗号分隔列表中的每个字符串（或文件名匹配模式）。与上述模式匹配表达式不同，此结构的扩展不是排序的。例如，`{b, a}` 扩展为 `ba`（而不是 `a b`）。作为特殊情况，字符 `{ }` 和 `,` 以及字符串 `( )` 将原样传递。
- `~[user]` 你的主目录（由变量 `home` 指定），或用户的主目录（由用户对应的密码条目指定）。

## 表达式与运算符

许多 shell 内置命令接受表达式，其运算符与 C 语言的运算符且具有相同的优先级。这些表达式通常出现在 `@`、`exit`、`if`、`set` 和 `while` 命令中，用于调节执行命令的流。表达式组件由空格分隔。

空值或缺失值被视为 0。所有表达式的结果都是字符串，可以表示十进制数字。

### csh

以下 C shell 运算符按优先级分组：

- `(...)` 分组。
- `~` 补反。
- `!` 逻辑取反。
- `*` `/` 乘法、除、取余。（这些运算符是右结合的，可能会导致意外结果。请用括号显式地组合）。
- `+` `-` 加法、减法（也是右结合的）。
- `<<` `>>` 位右移。
- `<` `>` `<=` `>=` 小于、大于、小于等于、大于等于。
- `==` `!=` `=~` 等于、不等于、文件名替换模式匹配（下文描述）以及 `!` 文件名替换模式匹配。
- `&` 位与。
- `^` 位异或（互斥或）。
- `|` 位或。
- `&&` 逻辑与。
- `|` 逻辑或。

运算符 `!=`、`=`、`~` 和 `!` 将其参数作为字符串进行比较；其他运算符使用数字。运算符 `~` 和 `!` 分检查左侧字符串是否匹配右侧的文件名替换模式。当只需要进行字符串之间的模式匹配时，这种检查减少了对 `switch` 语句的需求。

其他可用文件查询：

```
-r filename
```

如果用户具有读取权限，返回 true 或 1。否则，返回 false 或 0。

```
-w filename
```

如果用户具有写入权限，则返回 true。

```
-x filename
```

如果用户具有执行权限（或目录的搜索权限），则返回 true。

```
-e filename
```

如果文件名存在，则返回 true。

```
-o filename
```

如果用户拥有文件名，则返回 true。

```
-z filename
```

如果文件名长度为 0（空），则返回 true。
