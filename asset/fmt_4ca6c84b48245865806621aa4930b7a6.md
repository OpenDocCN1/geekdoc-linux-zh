# 导入二层

下一步是将你的工作导入到 `VIZ`：

1. 返回 `VIZ` 并选择 文件（`File`） ▷ 重置（`Reset`）。由于你已经保存了工作，可以直接重置场景了。

2. 选择 文件（`File`） ▷ 导入（`Import`）。然后，在“选择导入的文件”对话框中，找到并打开你从 `AutoCAD` 保存的 `savoye-second.dwg` 文件。如果你没有 `AutoCAD`，请打开 `savoye-second-outline.dwg` 文件。

3. 在 `AutoCAD DWG/DXF` 导入选项对话框中，调整设置以匹配图 17.25 所示。

4. 点击 `AutoCAD DWG/DXF` 导入选项对话框中的层（`Layers`）选项卡。默认选中“跳过冻结层”（`Skip Frozen Layers`）按钮。此设置会自动跳过你在 `AutoCAD` 中冻结的层。

当你点击 `AutoCAD DWG/DXF` 导入选项对话框中层选项卡上的“从列表选择”（`Select from List`）按钮时，你可以通过取消列表边缘的勾选来手动检查导入哪些层。列表中显示的层（开启/关闭，冻结/解冻，锁定/解锁）代表 `DWG` 或 `DXF` 文件的当前状态，并非功能性的；

![](img/7e143440dd5a0ed9683d4f26f3c074f8_845_0.png)

5. 点击确定（`OK`）导入图形并关闭 `AutoCAD DWG/DXF` 导入选项框。

你现在可以看到你在 `AutoCAD` 中创建的二层轮廓了。

## 探索文件链接管理器

通过文件链接设置，你可以像在 `AutoCAD` 中那样控制层，使用 `VIZ` 中保留的 `AutoCAD` 层名称。你还可以通过文件链接管理器的“预设”（`Presets`）选项卡为特殊情况创建自己的集合，并根据需要调整自定义预设。

要确认你对链接图纸具有完全控制权，请尝试以下步骤：

1. 打开“选择对象”（`Select Objects`）对话框；然后选择 `Layer:Wall-viz-int` 和 `Layer:Wall-viz-ext` 对象。

2. 点击面板中的“修改”（`Modify`）选项卡；然后从“修改器列表”（`Modifier List`）下拉列表中选择“拉伸”（`Extrude`）。

3. 将“数量”（`Amount`）参数设置为 `9'6"` 或 `114`。场景中的内墙和外墙将被拉伸。

如你所见，导入的 `AutoCAD` 文件拉伸墙体的方法完全相同。你现在可以像之前导入的 `savoye-ground.dwg` 文件一样选择并拉伸对象。与链接文件的区别在于，`AutoCAD` 文件中进行的更改可以在 `VIZ` 中重新加载，就像 `XRefs`（外部引用）的工作方式一样。

1. 返回 `AutoCAD` 并打开 `savoye-second-viz.dwg` 文件。

2. 开启并解冻所有层，并使用“拉伸”（`Stretch`）命令如图 17.27 所示拉伸墙体。

3. 选择 文件（`File`） ➤ 保存更改。

## 无需 AutoCAD 的继续练习

如果你没有 `AutoCAD`，重命名现有的 `savoye-second-viz.dwg` 文件，然后使用 `Windows` 资源管理器创建 `savoye-second-viz.dwg` 副本以替换现有文件。`savoye-second-viz-mod.dwg` 包含了前面步骤描述的修改。

`VIZ` 场景根据 `AutoCAD` 文件中进行的更改进行更新。

## 理解块层级

你已经看到当一个链接到 `AutoCAD` 对象时，如何更新 `VIZ` 场景。如果你在 `AutoCAD` 中添加对象，这些对象也会添加到 `VIZ` 场景中。新对象被添加到已存在的层，与该层关联的对象也被修改器控制。例如，如果你在 `AutoCAD` 图纸的 `Wall-viz-ext` 层上添加一个矩形，该矩形将被拉伸到 `114` 高，就像 `Wall-viz-ext` 层上的其他对象一样。该层上在 `AutoCAD` 中被拉伸的新对象将被 `VIZ` 忽略，除非它们被放置在新创建的层上。

在 `VIZ 2005` 之前，`AutoCAD` 块转换为 `VIZ` 块，它们被视为单个对象的实体集合（工作方式类似于复合对象）。

## 遇到 VIZ 块

如果你选择按层、实体、颜色或单个对象派生 `AutoCAD` 原，在 `VIZ 2008` 中仍然可以遇到 `VIZ` 块。

从 `VIZ 2007` 开始，当你选择按层、实体层级或块作为层级派生 `AutoCAD` 原时，块按层级结构链接。为了理解其工作原理，让我们做一个短教程：

1. 选择 文件（`File`） ➤ 重置（`Reset`），不要保存你之前对场景做的更改。

2. 选择 文件（`File`） ➤ 链接管理器（`File Link Manager`）并点击“附加”（`Attach`）选项卡。

3. 点击文件按钮选择 `Blocks.dwg` 文件；然后打开。

4. 点击“预设”（`Presets`）选项卡并点击“新建”（`New`）。为新预设命名为 `Entity Blocks` 并点击“确定”（`OK`）。

5. 在预设列表中选择 `Entity Blocks` 并点击“修改”（`Modify`）。

6. 点击 文件链接设置 `DWG` 文件对话框中的“高级”（`Advanced`）选项卡。在这里的“派生依据”（`Derive By`）下拉列表中选择“实体层级”（`Entity as Node Hierarchy`）。在这个例子中，按实体（而不是层）组合是合理的，因为只有几个简单的对象。

7. 点击 文件链接设置 `DWG` 文件对话框中的“保存”（`Save`）。
