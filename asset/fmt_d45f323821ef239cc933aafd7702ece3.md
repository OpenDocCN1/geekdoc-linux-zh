
# dbx 调试命令参考

`trace <var>` - 跟踪变量的变化

`trace <exp> at <line#>` - 在到达 `<line>` 时打印 `<exp>`

`status` - 打印生效的跟踪和停止编号列表

`delete # [< ...]` - 取消每个给定的跟踪或停止

`cont` - 继续执行源码，进入函数

`step` - 执行一行源码，跳过调用

`return` - 直到当前函数返回

`call <func(<params>)>` - 执行给定的函数调用

`print <exp[, <exp ...>]>` - 打印表达式的值

`where` - 打印当前激活的过程

`whatis <name>` - 打印名称的声明

`assign <var> = <exp>` - 将 `<exp>` 的值赋予程序变量

## 为调试准备程序

要调试程序，它必须使用 `cc` 的 `-g` 选项进行编译，该选项将调试信息放入对象模块。

## 运行程序

要运行你的程序，输入 `run` 命令，它将运行程序直到结束：

```
(dbx) run ...运行程序。
palindrome "cat" = 0
palindrome "noon" = 0
program exited
(dbx)
```
