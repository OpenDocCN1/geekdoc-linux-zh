
以下示例展示了如何使用 `xml.dom.minidom` 解析并提取 XML 文件信息：

```python
from xml.dom import minidom
doc = minidom.parse("recipe.xml")

ingredients = doc.getElementsByTagName("ingredients")[0]
items = ingredients.getElementsByTagName("item")

for item in items:
    num = item.getAttribute("num")
    units = item.getAttribute("units")
    text = item.firstChild.data.strip()
    quantity = "%s %%s" % (num,units)
    print(\-10s %%s" % (quantity,text))
```

> 注意
> `xml.dom.minidom` 模块具有更多更改解析树和处理不同类型 XML 节点的功能。更多信息可以在在线文档找到。

## `xml.etree.ElementTree`

`xml.etree.ElementTree` 模块定义了一个灵活的容器对象 `ElementTree`，用于存储和操作层次结构数据。虽然此对象通常用于 XML 处理，但它是通用的——充当了类似于列表和字典的角色。

### `ElementTree` 对象

以下类用于定义一个新的 `ElementTree` 对象，并代表层次结构的顶层。

`ElementTree([element [, file]])`

创建一个新的 `ElementTree` 对象。`element` 是表示根节点的实例。该实例支持接下来描述的元素接口。`file` 是文件名或文件对象，将从其中读取 XML 数据以填充树。

`ElementTree` 的实例树具有以下方法：

```
tree._setroot(element)
```

将根元素设置为 `element`。

```
tree.find(path)
```

查找并返回树中标签与给定 `path` 匹配的第一个顶层元素。`path` 是描述元素类型及其相对于其他元素的位置字符串。以下列表描述了语法：

| 路径 (Path) | 描述 |
| :--- | :--- |
| `'tag'` | 仅匹配给定标签的顶层元素——例如，`<tag>...</tag>`。不匹配在较低层级定义的元素。不会匹配嵌入在另一个元素中的元素，如 `<foo><tag>...</tag></footer>`。 |
| `'parent/tag'` | 如果一个元素是标签为 `'parent'` 的元素的子元素，则匹配标签为 `'tag'` 的该元素。可以指定任意数量的路径组件。 |
| `'*'` | 选择所有子元素。例如，`*/tag` 会匹配所有标签名为 `'tag'` 的孙子元素。 |
| `','` | 从当前节点开始搜索。 |
| `'//'` | 选择元素下方所有层级的所有子元素。例如，`.//tag` 会匹配所有子层级标签为 `'tag'` 的元素。 |

如果你正在处理涉及 XML 命名空间的文档，路径中的标签字符串格式为 `{uri}tag`，其中 `uri` 是如 `http://www.w3.org/TR/html4/` 类的字符串。

```
tree.findall(path)
```

查找树中所有匹配 `path` 的顶层元素，并按文档顺序作为列表或迭代器返回它们。

```
tree.findtext(path [, {default}]])
```

返回树中匹配 `path` 的第一个顶层元素的文本。如果找不到匹配的元素，则 `default` 为字符串。

```
tree.iter([tag])
```

创建一个迭代器，按顺序产生树中的所有元素，其中 `tag` 匹配指定的 `tag`。如果省略了 `tag`，则按顺序返回树中的每个元素。

```
tree.getroot()
```

返回树的根元素。

```
tree.parse(source [, parser])
```

解析外部 XML 数据并用结果替换根元素。`source` 是文件名或代表 XML 文件的对象。`parser` 是 `TreeBuilder` 的可选实例，稍后会描述。

```
tree.write(file [, encoding])
```

将树的所有内容写入文件。`file` 是文件名或为写入打开的文件对象。`encoding` 是要使用的输出编码，如果没有指定，默认使用解释器的默认编码（大多数情况下为 `'utf-8'` 或 `'ascii'`）。

### 创建元素

`ElementTree` 中持有的元素类型由不同类型的实例表示，这些实例通过解析文件或以下构造函数创建：

```
Comment([text])
```

创建一个新注释。`text` 是一个包含元素文本的字符串。在解析或写入输出时，该元素会被映射为 XML 注释。

```
Element(tag, attrib [, extra])
```

创建一个新元素。`tag` 是元素的名称。例如，如果你正在创建一个元素 `'<foo/>'`，`tag` 将为 `'foo'`。`attrib` 是一个指定为字符串的元素属性字典。`extra` 中提供的任何关键字也用于设置元素属性。

```
fromstring(text)
```

从 XML 文本片段创建元素——与后面描述的 `XML()` 相同。

```
ProcessingInstruction(target [, text])
```

创建一个对应于处理指令的新元素。`target` 和 `text` 都是字符串。映射到 XML 时，此元素对应于 `'?target'`。

```
SubElement(parent, tag, attrib [, extra])
```

与 `Element()` 相同，但会自动将新元素作为父元素的子添加。

```
XML(text)
```

通过解析 XML 代码片段创建元素。例如，如果将 `text` 设置为 `'<foo/>'`，这将创建一个标签为 `'foo'` 的标准元素。

```
XMLID(text)
```

与 `XML(text)` 相同，不同之处 `'id'` 属性会被收集并用于构建一个映射值到元素的字典。返回一个元组 `(elem, idmap)`，其中 `elem` 是元素，`idmap` 是 ID 字典。例如，`XMLID('<foo id="123"><bar id="456">Hello</bar></foo>')` 返回 `(<Element foo, {'123': <Element foo, '456': <Element bar>})`。

### 元素接口

虽然 `ElementTree` 中存储的元素可能有不同的类型，但它们都支持共同的接口。如果 `elem` 是任何元素，则定义了以下运算符：

| 运算符 (Operator) | 描述 |
| :--- | :--- |
| `elem[n]` | 返回 `elem` 的第 `n` 个子元素。 |
| `elem[n] = elem` | 将 `elem` 的第 `n` 个子元素更改不同的元素。 |
| `del elem[n]` | 删除 `elem` 的第 `n` 个子元素。 |
| `len(elem)` | `elem` 的子元素数量。 |

所有元素都有以下基本属性：

| 属性 (Attribute) | 描述 |
| :--- | :--- |
| `elem.tag` | 标识元素类型的字符串。例如，`<foo></foo>` 的标签为 `'foo'`。 |
| `elem.text` | 与元素相关的数据。通常是包含 XML 元素开始和结束标签之间的文本的字符串。 |
| `elem.tail` | 属性的附加数据。对于 XML，这通常是包含元素结束标签之后、下一个标签开始之前的空白字符的字符串。 |
| `elem.attrib` | 元素属性的字典。 |

元素支持以下方法：

```
elem.append(subelement)
```

将子元素添加到列表末尾。

```
elem.clear()
```

清除所有子元素。

```
elem.find(path)
```

查找匹配 `path` 的第一个元素。

```
elem.findall(path)
```

查找所有匹配 `path` 的元素。

```
elem.findtext(path, default='')
```

返回匹配 `path` 的第一个元素的文本。

```
elem.get(key)
```

获取 `key` 属性值。

```
elem.iter([tag])
```

产生所有匹配 `tag` 的元素的迭代器。

```
elem.insert(index, subelement)
```

在 `index` 处插入子元素。

```
elem.remove(subelement)
```

移除子元素。

```
elem.set(key, value)
```

设置 `key` 值为 `value`。

```
elem.items()
```

返回属性键值对。

```
elem.keys()
```

返回属性的键。
