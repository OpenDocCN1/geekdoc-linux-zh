Unix C 编程语言编译器。该编译器通过预处理、编译、汇编和链接四个阶段处理源代码文件。本条目描述了 SVR4 编译器，并对 Solaris 和 SCO 实现提供了说明。BSD 包含了 GNU C 编译器 `gcc`，它用于包括 Linux 在内的许多系统；请参见 `gcc`。

## 语法

你可以使用以下命令调用 C 编译器：

```
cc [options][filename...]
```

此命令运行 ANSI C 编译器；若要使用该编译器处理 Kernighan 和 Ritchie 的 C 语言，请使用：

```
/usr/bin/cc
```
