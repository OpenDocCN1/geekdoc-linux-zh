## 从命令行调试

运行调试器的另一种方法是在命令行中调用它。示例如下：

```
$ python -m pdb someprogram.py
```

## 配置调试器

如果在用户主目录或当前目录下存在 `.pdbre` 文件，当在调试器提示符下输入该文件名时，它将被读取并执行。这对于指定你每次启动调试器时想要执行的调试命令非常有用（而无需每次都交互式输入命令）。

## 程序性能分析

`profile` 和 `cProfile` 模块用于收集性能分析信息。这两个模块的工作方式相同，但 `cProfile` 是作为 C 扩展实现的，速度快得多且更现代。每个模块都用于收集覆盖信息（即执行的函数）以及性能统计数据。对程序进行性能分析简单的方法是从命令行执行它：

```
% python -m cProfile someprogram.py
```

或者，可以使用 `profile` 模块中的 `run` 函数：

```
run(command, filename)
```

使用 `exec` 语句配合性能分析器执行 `command` 的内容。`filename` 是保存原始数据的文件名。如果省略该参数，会将报告打印到标准输出。

## 内存测量

`sys` 模块有一个 `sizeof()` 函数，可用于调查 Python 对象的内存占用（字节字节）。例如：

```
>>> sys
>>> sys.getsizeof(1)
28
>>> sys.getsizeof("Hello World")
52
>>> sys.getsizeof((1,2,3,4))
72
>>> sum(sys.getsizeof(x) for x in [1,2,3,4])
56
```
