
## ROBDoc

一种文档工具。其核心思想是为每个函数或过程包含一个包含该过程或函数各种信息的标准头文件。`ROBDoc` 从源代码中提取这些头文件并放入服务器自动文档 `autodocs` 中——`ROBodoc` 允许你将文档包含在源代码中，从而避免维护独立的文档。或者正如 Petri 所说：“robodoc 非常有用——对于那些想要用 Word 或其他工具编写文档的程序员来说。” `RoboDoc` 可以以不同的格式化头文件：HTML、ASCII、Amiga、LaTeX 或 RTI。在 HTML 格式中，它可以生成头文件之间的交叉链接。你甚至可以包含源代码的一部分：`ROBDoc` 支持许多编程语言：对于 `C`、`Pascal`、`Shell` 脚本、`COBOL`、`Occam`、`PostScript`、`TeX`、`C++`，基本上任何你可以使用注释的程序，源自 Debian 3.0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## root

- n. [Unix] 超用户（用户名为 '`root`'），忽略权限位，Unix 系统上的用户编号为 0。使用了 avatar（化身）一词。2. 系统目录结构的顶层节点；在历史上，它是 root 用户的家目录，但准确的名称是（倒置）树的根（root）。3. 通过选举产生的，任何操作系统上具有特权的系统维护登录账户。参见 `root mode`（root 模式），`go root`，另见 well。源自 Jargon Dictionary

`http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html`

## root (超级用户)

在 UNIX 上，`root` 是超级用户或管理员，对机器中的一切拥有完全控制权。一旦作为动词：`root` 是为了获取系统及其本身管理（即完全）控制权的操作。关键点：该词可以作为动词使用。“`root`” 一台机器是指入侵并获取该机器及其系统的 root 权限。源自 Hacking-Lexicon

`http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html`

## root window (root 窗口)

你屏幕的背景。它仅在名称上被称为窗口，其行为与其他任何窗口都不同，但可以在 root 窗口上运行应用程序，或在其上放置图片，或仅仅是一种纯色。源自 Linux Guide @FirstLinux
