### `/dev/null` 的用途

将 `/dev/null` 视为黑洞。它本质上等同于一个只写文件。所有写入它的内容都会消失。尝试从中读取或输出将导致无结果。尽管如此，`/dev/null` 在命令行和脚本中都非常有用。

抑制标准输出 (`stdout`)。

```bash
cat $filename >/dev/null
# 文件内容不会列到标准输出。
```

抑制标准错误 (`stderr`)（来自示例 16-3）。

```bash
rm $badname 2>/dev/null
# 这样错误信息 [stderr] 就会消失。
```

同时抑制标准输出和标准错误。
