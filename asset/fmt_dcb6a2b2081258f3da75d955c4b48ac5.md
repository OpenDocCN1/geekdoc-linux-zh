
`is` 提供的细节比另一个程序提供的更多。`ls` 显示的列（从左到右）：

* 文件的 inode 号（在其文件系统中唯一标识每个文件的数字）
* 文件消耗的 IK 块数
* 文件类型和权限
* 指向文件的硬链接数
* 文件的所有者
* 文件的大小（以字节计）
* 最近修改的日期和时间
* 文件名

通过 `-printf`，你可以自定义 `find` 命令的输出，以符合你正在运行的程序的需求。列表 12-2 显示了一个总结磁盘使用情况的脚本。

### 使用 `-printf` 显示特定信息

在大多数情况下，`-ls` 操作提供的信息比你真正需要的要多。你可以使用 `-printf` 操作只查看你想要的信息节点。要使用 `-printf`，你必须在操作后跟上指定要显示信息的指令。例如，请看以下内容：

#### 列表 12-2：磁盘使用情况

```bash
# /bin/bash

# 文件名: diskusage

# 创建三个数组，每个数组索引为

# 数字用户 ID

# sizes[$uid] 将累积每个用户消耗的磁盘空间

# uids[$uid] 将存储每个用户的数字

# uid

# users[$uid] 将存储每个用户的用户名

# 调用者将发送如下格式的行

# 数字-用户-id 文件名

while read user size; do
  # 查找此 uid 使用的当前空间
  size=${size:-0}

  # 加上该文件消耗的空间并存储
  # $size[$uid]+=$size
  sizes[$uid]]+=$size

  # 同时存储数字用户 ID 和用户名
  uids[$uid]=$uid
  users[$uid]=$user
done

# 我们现在累积了所有的磁盘空间使用情况
# 为调用者显示结果
for uid in ${uids[@]}; do
  printf "%15d\t%s\n" "${size[$uid]}" "${users[$uid]}"
done
```
