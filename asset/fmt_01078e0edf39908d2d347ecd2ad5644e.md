`telnet` 命令启动 `telnet` 程序，提示符会发生变化，以告知你正在使用 `telnet` 控制台。向 `open` 命令提供主机名或其 IP 地址，然后在要求连接到该系统时输入有效的登录用户名。通常远程计算机将使用基于 Unix 的操作系统（如 `Linux`），因此它能够识别用于导航的 `bash` 命令——`cd`、`ls`、`pwd` 等。

退出远程计算机可能涉及某些操作，这取决于 `logoff` 命令——尝试 `quit`、`end`、`stop`、`logout` 和 `logoff`。

| 命令 | 说明 |
| :--- | :--- |
| `telnet` | 打开 `telnet` 控制台程序 |
| `ssh` | 安全地连接到远程计算机 |

`telnet` 是一个非常老的程序，遗憾的是 `telnet` 传输的数据仅以明文格式发送——容易被窃取密码和信息。更安全的替代方案是 `ssh` 命令![](img/0494b8ec9ddc4515587e9808d73902e_202_0.png) 尽可能使用 `ssh` 而不是 `telnet` 以获得更好的安全性。`ssh` 命令加密跨网络传输的所有数据，包括你的用户名和密码。它还可以使用公钥进行复杂的身份验证。简单的登录如下：

```

mike@example.com's password: ******
Last login: Sun Oct 9 14:10:00
Your Operating System is Linux
Welcome to... the domain
Checking your file quota... OK
mike@example.com->
```

## 通过网络传输文件

你可以使用文件传输协议通过网络发送文件。`ftp` 命令启动 `ftp` 程序，提示符告知你正在使用 `ftp` 控制台。向 `open` 命令提供主机名或其 IP 地址，然后在要求连接到该系统时输入有效的用户名。如果主机运行基于 Unix 的操作系统，它将识别用于导航的 `bash` 命令——`cd`、`ls`、`pwd` 等。使用 `put` 命令后接文件名，将文件从本地系统传输到远程主机![](img/0494b8ec9ddc4515587e9808d73902e_203_0.png)

![](img/0494b8ec9ddc4515587e9808d73902e_203_1.png)

`ftp` 服务器上的文本可以在不下载到本地系统的情况下进行读取——例如，你可以发出 `page otherbooks.txt` 命令来读取示例上传的文件![](img/0494b8ec9ddc4515587e9808d73902e_204_0.png)。`ftp` 服务器识别的 `page` 命令是一个 Unix 命令，工作类似于 `Linux` 的 `less` 命令。

| 命令 | 说明 |
| :--- | :--- |
| `ftp` | 打开 `ftp` 控制台程序 |
| `open` | 连接到 `ftp` 服务器 |
| `put` | 将文件复制到远程系统 |
| `mput` | 将多个文件复制到远程系统 |
| `get` | 将远程文件复制到本地系统 |
| `mget` | 将多个远程文件复制到本地系统 |
| `exit` | 退出 `ftp` 控制台 |

可以使用 `mput` 命令配合通配符字符 `*` 将多个文件传输到远程系统。`input *` 命令可以简单地将当前本地目录中的所有文件复制到当前远程工作目录。同样，`get` 和 `mget` 命令可以用于反向复制文件——从远程系统到你的计算机。

当你完成所有文件传输后，`exit` 或 `quit` 关闭 `ftp` 控制台并返回 shell 提示符。

## 浏览互联网

`lynx` 命令在 shell 窗口中启动 `Lynx` 文本浏览器，并在屏幕底部显示其命令选项。按下 `G` 键，输入字段将邀请你输入 URL。输入地址后按回车键在 `Lynx` 中打开网页：
