
`r = "Hello {0}, your age is {1}".format('Elwood',age=47)`

`r = "Use {{0}} and {{1}} to output single braces".format()`

对于每个占位符，你还可以额外执行索引和属性查找。例如，在 `{name[n]}` 中（其中 `n` 是整数），会形成一个序列查找；在 `{name[key]}` 中，会执行字典查找。如果 `key` 是非数字字符串，则执行字典查找。在 `{name.attr}` 中，会执行属性查找。这里是一些示例：

```
stock = {

  'name' : 'GOOG',

  'shares' : 100,

  'price' : 490.10 

}

r = "{0[name]} {0[price]}".format(stock)
```

```
x = 3 + 4j

r = "{0.real} {0.imag}j".format(x)
```

在这些情况下，你只允许使用名称。不支持任意表达式、方法调用等。你可以选择性地指定一个指定符，以便对输出、小数位和对齐进行更多控制。这通过在冒号后添加可选的格式指定符来实现：`{value:spec}`。这里是一个示例：

```
r = "{name:8} {shares:d} {price:.2f}".format(name='GOOG',shares=100,price=490.10)
```

### 高级字符串格式化

指定符的通用格式为 `[fill][align][width][precision][type]`，其中每个部分都是可选的。宽度指定符标识要使用的最小字段宽度，对齐指定符是 `<`、`>` 或 `^` 之一，分别用于左对齐、右对齐和居中对齐。填充字符用于填充空间。例如：

```
name = 'Elwood'

r = ":0<10".format(name) # r = 'Elwood   '

r = ":0>10".format(name) # r = '     Elwood'

r = ":0^10".format(name) # r = '  Elwood  '
```

### 集合操作

`set` 和 `frozenset` 类型支持许多常用操作：

| 操作 | 描述 |
| --- | --- |
| s | t | s 和 t 的并集 |
| s & t | s 和 t 的交集 |
| s - t | 差集 |
| s ^ t | 对称差 |
| len(s) | 集合中的元素个数 |
| max(s) | 最大值 |
| min(s) | 最小值 |

并集、交集和差操作的结果与最左侧操作数的类型相同。例如，如果 `s` 是 `frozenset`，而 `t` 是 `set`，那么结果将是 `frozenset`。

### 复合赋值

Python 提供了以下一组复合赋值运算符：

| 操作 | 描述 |
| --- | --- |
| x += y | x = x + y |
| x -= y | x = x - y |
| x *= y | x = x * y |
| x /= y | x = x / y |
| x //= y | x = x // y |
| x **= y | x = x ** y |
| x %= y | x = x % y |
| x &= y | x = x & y |
| x |= y | x = x | y |
| x ^= y | x = x ^ y |
| x >= y | x = x >> y |
| x <= y | x = x << y |

这些运算符可以用任何使用普通赋值的地方。这里是一个示例：

```
a = 3

b = [1,2]

c = "Hello %s"

a += 1 # a = 4

b[1] += 10 # b = [1,12]

c = ("Monty","Python") # c = "Hello Monty Python"
```

复合赋值并不违反易变性，也不会对对象进行就地修改。因此，编写 `+=` 会创建一个值为 `x + y` 的完全新对象。用户定义的类可以使用第 3 章“类型和对象”中描述的特殊方法来重新定义复合赋值运算符。

### 属性运算符 (.)

点运算符 (`.`)运算符用于访问对象的属性。这里是一个示例：

```
foo.x = 3

print foo.y

a = foo.bar(3,4)
```

单个表达式中可以出现多个点运算符，例如 `foo.y.a.b`。
点运算符也可以应用于函数的中间结果，例如 `a = foo.bar(3,5).spam`。
用户定义的类可以重新定义或自定义 ( `.` ) 的行为。更多细节请参阅第 3 章和第 7 章“类和面向对象编程”。

### 函数调用 () 运算符

`f(args)` 运算符用于对 `f` 进行函数调用。每个参数都是一个函数。在调用函数之前，所有的参数表达式都会从左到右完全求值。这被称为*结合律求值*。

可以使用 `partial()` 函数来评估参数：

```python

def foo(x,y,z):

    return x + y + z

from functools import partial

f = partial(foo,1,2) # 为 foo 的参数 x 和 y 提供值

f(3) # 调用 foo(1,2,3)，结果为 6
```
