
这些被称为软件包的程序，其多样性如同最初设计它们的开发人员一样广泛。在 Linux 中，如果需要对某个特定程序的需求，就会有人开发它。然后将其发布到全世界，并免费公开源代码，因此称为“开源”。一旦程序经过测试，最终会进入该特定 Linux 发行版的一个远程服务器。

这些被称为软件源（或 `repos`）的远程服务器包含软件包的所有元素，以便将其下载并安装到你的系统上。一旦你知道如何操作，这个过程非常快速且简单...

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_31_0.png)

## 更新和升级

### 01 获取软件包

通过桌面上的 `LXTerminal` 图标进入命令行终端，并输入几个命令。但在这样做之前，我们需要确保系统是最新的。在终端中输入以下内容：

```
sudo apt-get update
sudo apt-get upgrade
sudo apt-get update && sudo apt-get upgrade
```

## 搜索软件包

### 02 `apt-get` 命令

`apt-get` 命令（高级包工具）是在树莓派上下载和安装软件包的关键。在之前的示例中，我们更新了现有软件包和系统，升级了需要升级的部分，并更新了当前软件包列表。现在，让我们在服务器软件包列表中搜索可用的游戏。

```
apt-cache search game | less
```

## Apt 搜索

### 03

你当前所在的列表是所有标记为“游戏”的可用服务器软件包名称。在列表中，连字符前面的部分告诉你软件包的名称，这是你安装它所需要知道的。使用上下箭头键导航，按 `Q` 退出。

## 安装软件包

### 04

使用上下箭头键导航列表。如果你找到喜欢的东西，例如 Angry Drunken Dwarves，记住软件包的名称，在此例中为 `angryd2`，然后按 `Q` 退出列表。要安装该软件包，在终端中输入以下内容：

```
sudo apt-get install angryd2
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_32_0.png)

## 执行软件包

### 05

上一个命令的结果应该是游戏 Angry Drunken Dwarves 的成功下载和安装。要执行新安装的软件包，你可以从 LXDE 菜单中的 游戏 -> Angry Drunken Dwarves 运行它，或者在终端中输入以下内容：

```
angryd2
```

## 删除软件包

### 06

安装软件包是完全正常的，你可以看到 Apt 命令有多强大。但是，如果你想删除软件包怎么办？

再次使用 Apt 命令，假设我们要从树莓派中完全删除 Angry Drunken Dwarves 的所有痕迹。

```
sudo apt-get --purge remove angryd2
```

输入 `Y` 接受删除。

## Apt 彩蛋

### 07

`Apt` 命令是 `Aptitude` 命令的更短、非菜单驱动变体。这个命令在 Linux 中有着悠久的历史，因此拥有一些相当特殊的功能，也被称为彩蛋。纯粹为了好玩，输入以下命令并查看结果：

```
aptitude moo
aptitude -v moo
aptitude -vv moo
aptitude -vvv moo
aptitude -vvvv moo
aptitude -vvvvv moo
aptitude -vvvvvv moo
sudo apt-get moo
```

## 查阅 Apt 命令手册

### 08

如你所见，简单的 Apt 命令比表面看起来更复杂。你可以运行许多不同的子命令，以及运行它们的不同变体。

如果你想查看 Apt 命令还能做什么，请输入以下内容：

```
man apt
```

## 使用图形化安装

*你更喜欢使用图形界面来安装新程序吗？如果是，请继续阅读...*

如果你是 Linux 新手，可能会觉得使用其内置的 Apt 包管理工具有点令人生畏和困惑。`apt-get` 命令用于通过互联网安装应用程序，连接到被称为软件源（`repos`）的远程服务器，这些服务器将程序作为软件包进行存储。但它通过终端命令提示符使用，这可能令人望而生畏，因此我们需要一种替代方案：一种通过桌面环境界面获取软件包的方法。

这就是 Synaptic 发挥作用的地方。Synaptic 是一个外观友好的图形界面，用于 `apt-get` 终端命令，它允许你通过熟悉的桌面环境管理应用程序的安装和删除。把它想象成一种在线商店，你可以挑选想要的程序，并将它们下载和安装到你的树莓派上，而无需进入终端。

### 你知道吗...

树莓派运行最新版本的 Debian Linux，并包含适用于所有不同桌面环境的最新软件包，如 Cinnamon、XFCE、LXDE 和 GNOME。

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_33_0.png)

- **升级整个系统**

  Synaptic 能够升级和更新每个程序或软件包，并可以将整个系统升级到最新版本

- **安装及其他**

  Synaptic 是一个功能强大的工具。你可以使用它安装、删除、升级和降级单个或多个软件包和程序

- **浏览所有文档**

  在 Synaptic 内部，你可以浏览和阅读与软件包或程序相关的所有可用在线文档

- **轻松查找程序**

  Synaptic 使你可以轻松通过名称、描述、版本甚至程序开发人员来定位软件包和程序

## 更新系统

### 1.

不幸的是，如果您已有一个现有的 Synaptic 系统，显示在第一步的命令可能会卡住。在安装任何内容之前，我们需要确保树莓派是最新的，并且现有的软件包也是最新的。只需将以下内容输入到 `LXTerminal` 中：

```
sudo apt-get update
sudo apt-get upgrade
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_34_0.png)

## 安装 Synaptic

### 2.

既然系统已是最新的，我们终于准备好安装 Synaptic 了。转到 `LXTerminal` 并运行下面的命令。别忘了在提示接受安装时输入 `Y`。

```
sudo apt-get install synaptic
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_34_1.png)

## 运行 Synaptic – 第一部分

### 3.

本质上，这就是你需要做的全部。Synaptic 现在已安装并准备就绪。然而，由于其复杂性，可能有一些 bug 需要先解决，因此最好遵循这些步骤。要测试 Synaptic 是否工作正常，首先在终端中输入以下命令：

```
sudo synaptic
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_34_2.png)

## 运行 Synaptic – 第二部分

### 4.

你现在应该正在查看 Synaptic 程序窗口，你可以在其中浏览可用程序列表并点击下载和安装。现在我们需要测试它是否能从 LXDE 菜单中运行。点击左下角的图标，然后转到 Preferences, Synaptic Package Manager。

## 运行 Synaptic – 第三部分

### 5.

从 LXDE 菜单运行 Synaptic 会导致错误。然而，不要惊慌，它只是要求输入密码。输入用户名/密码以便我们可以访问系统。这是你最初更改时设置的默认密码，如果你没有更改它，可以使用默认值。

## 修复 Synaptic – 选项 1

### 6.

这将临时修复该问题。要永久解决它，请执行以下任一操作：首先，右键点击菜单中的 `synaptic` 图标，然后左键点击属性。在命令文本框中，更改文本以添加 `sudo` 命令。因此，而不是“`synaptic-pkexec`”，它将读取为：

```
sudo synaptic-pkexec
```

![](img/fd3f4a582cf5250916d8b8e1d4ccd045_34_3.png)

## 修复 Synaptic – 选项 2

### 7.

第二种，也是最好的选择，是拉回到终端并重复从菜单中执行程序的方式。只需将一行更改为另一行，以便再次使用命令类型而不是普通的 `synaptic-pkexec`。从终端输入：

```
sudo nano /usr/share/applications/synaptic.desktop
```

```
将“Exec=synaptic-pkexec”更改为“Exec=gksu /usr/bin/synaptic-pkexec”
```

## Synaptic 完全正常工作

### 8.

输入这些更改后，通过 `Ctrl+X` 退出 `nano`，接着按 `Y` 接受更改，然后按 Enter。几行操作后即可回到命令提示符。现在你可以从菜单启动 Synaptic，或者在终端中输入以下命令：

```
sudo synaptic
```
