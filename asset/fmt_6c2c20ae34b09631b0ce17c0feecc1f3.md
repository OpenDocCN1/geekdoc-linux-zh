## Wiki

`Wiki` 是一种服务器软件，允许用户使用任何浏览器自由创建和编辑 Web 内容。`Wiki` 支持超链接，并具有简单的文本语法，用于创建新页面以及内部页面之间的交叉链接。在小组通信机制中，`Wiki` 的与众之处在于它不仅允许编辑内容本身，还允许组织贡献组织。与许多简单概念一样，“开放编辑”对 `Wiki` 的使用产生了深远而微妙的影响。用户创建和编辑 Web 中的任何页面是如此令人兴奋的，这鼓励了 Web 的民主化使用并促进了非技术用户的内容定位。历史说明：第一个 wiki 网站是 1995 年为 Portland Pattern 库创建的。该网站现在托管了数十页。来自 Wiki
