
#!/bin/bash

### 首先刷新所有规则集

`ipfwadam -I`

`ipfwadam -f -O`

`ipfwadam -F`

### 允许两个网络之间的转发，出于安全考虑其他拒绝

```bash
ipfwadam -F -a accept -P all -S 10.0.0.0/24 -i eth0 -D 192.168.0/24
ipfwadam -F -a accept -P all -S 192.168.0/24 -i eth1 -D 10.0.0.0/24
ipfwadam -F -P deny
```

### 当然，我们必须允许这些数据包进入

```bash
ipfwadam -I -a accept -P tcp -S 10.0.0.0/24 -i eth0 -D 192.168.0/24
ipfwadam -I -a accept -P tcp -S 192.168.0/24 -i eth1 -D 10.0.0.0/24
ipfwadam -I -P deny
```

### 让他们访问服务器上的邮件服务器，但什么都不能访问

```bash
ipfwadam -I -a accept -P tcp -S 10.0.0.0/24 -i eth0 -D 192.168.0/24
ipfwadam -I -a accept -P tcp -S 192.168.0/24 -i eth1 -D 10.0.0.0/24
ipfwadam -I -P deny
```

## IPchains

`ipchains` 有一些新功能，你可以创建规则链（因此得名）并将它们链接起来，使得防火墙的管理更加简单。`ipchains` 支持比 `iptables` 更多的目标，你可以规则指向 `ACCEPT`、`DENY`、`REJECT` 或 `RETURN`。这种方式非常强大，你可以重定向 80 端口的数据包，并结合服务质量（QoS）路由，`ipchains` 给出的示例中流量优先级高于 ftp，这减少了由拥塞链路引起的延迟问题。以下脚本适用于具有 2 个接口的网关，我使用 `DENY` 而不是 `REJECT` 的原因是数据包会被直接丢弃且不予响应，这会减慢扫描。`ipchains` 适用于具有 2 个接口的服务器，如果你计划使用它，需要设置防火墙规则。我们假设所有机器都与网关通信。

```bash
#!/bin/bash

PATH=/sbin

### FLUSH ALL

## 变量

### ETH0 是 IP 地址（外部接口）

### ETHONET 是网络

### ETHET 是掩码

### TRUSTEDHOST1 是一个信任主机（用于 web）

### TRUSTEDHOST2 是一个信任主机（用于 ssh）

### ETH1 是 IP 地址（内部接口）

### ETHONET 是网络

### ETHET 是掩码

ETHIP=1.1.1
ETHONET=1.1.0
ETHET=24
TRUSTEDHOST1=1.5.1
TRUSTEDHOST2=1.5.2
ETH1=10.0.0.1
ETHONET=10.0.0
ETHET=24

iptables -F input
iptables -F output
iptables -F forward

## 伪造 (SPOOFING)

iptables -A input -p all -j DENY -s 10.0.0.0/8 -i eth0 -d 0.0.0/0
iptables -A input -p all -j DENY -s 127.0.0.0/8 -i eth0 -d 0.0.0/0
iptables -A input -p all -j DENY -s 192.168.0.0/16 -i eth0 -d 0.0.0/0
iptables -A input -p all -j DENY -s 172.16.0.0/16 -i eth0 -d 0.0.0/0
iptables -A input -p all -j DENY -s $ETHIP -i eth0 -d 0.0.0/0

## ICMP

iptables -A input -p icmp -j ACCEPT -s $ETHONET/$ETHET -i eth0 -d 0.0.0/0
iptables -A input -p icmp -j DENY -s 0.0.0.0 -i eth0 -d 0.0.0/0

## SSH

iptables -A input -p tcp -j ACCEPT -s $TRUSTEDHOST1 -i eth0 -d 0.0.0/0 22
iptables -A input -p tcp -j DENY -s $TRUSTEDHOST2 -i eth0 -d 0.0.0/0 22

# 阻断 11023

iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 11023
iptables -A input -p udp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 11023

# 阻断其他

iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 11039
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 1524
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 1600
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 2003
iptables -A input -p udp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 2045
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 2049
iptables -A input -p udp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 2045
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 2105
iptables -A input -p tcp -j DENY -s 0.0.0.0/0 -i eth0 -d 0.0.0/0 3001
iptables -A input -p udp -j DENY -s 0.0.0.0/ -i eth0 -d 0.0.0/0 3128
```
