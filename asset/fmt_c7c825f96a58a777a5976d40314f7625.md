### WAD 应用设计器概述

在 WAD 中，BI 源通过数据提供者（Data Providers）链接到 Web 框架。数据提供者为 BI 源提供的数据创建逻辑连接。BI 源与数据提供者之间通常是一对一的关系。如有必要，数据提供者可以进行配置。通常情况下，Web 项目负责格式化从数据提供者接收的数据。例如，图表 Web 项目（在第 13 章中解释）将以图表的形式显示数据，其中导航窗会将数据提供者的组件列到 Web 项目中，这被称为数据绑定。

并不是每个 Web 项目都会为 Web 应用程序的用户进行格式化。XML 数据提供者信息项为 JavaScript 方案以 XML 格式提供了 Web 应用程序的数据和元数据。还有其他 Web 项目，例如容器和右键菜单，它们不提供数据而是用于格式化。由于 Web 项目能够以许多不同的格式表示数据提供者数据，它们是 Web 模板的构建模块。模板是定义 Web 页面的 Web 项目、格式对象、文本、图像和参数的集合。Web 模板可以非常基础，也可以根据客户的需求进行定制。这取决于它们在整个报告过程中的用途。因此，在创建和维护 Web 模板的过程中，WAD 的主要项目需要注意每个 Web 项目在过程中的应用和用途。当 Web 模板在企业门户（Enterprise Portal）中执行时，它们被称为 Web 应用程序。Web 应用程序可以是任何链接在一起的 Web 模板组合。Web 应用设计器包含了各种基于 Web 的业务智能，你可以使用标准的 Web 技术根据个人需求进行调整。图 15-7 显示了 Web 应用设计器如何集成到功能布局和 Business Explorer 布局中。

### Web 应用设计器组件

Web 应用设计器是一个用于创建具有 BW 特定内容的 Web 应用程序的桌面应用程序。Web 应用设计器允许通过标准标记语言和 Web 设计 API 创建具有用户定义界面元素的高度个性化场景。你可以单独地调整和增强 Web 模板（决定 Web 应用程序结构的 XHTML 页面）。这些 XHTML 页面不仅是交互 Web 应用程序的基础，也是 BW 驾驶舱和视图的基础。
