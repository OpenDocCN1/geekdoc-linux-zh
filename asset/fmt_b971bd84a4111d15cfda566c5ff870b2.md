# getopt — 解析命令行选项

### 概要

```
set -- getopt optstring $*
```

## 描述

`/usr/bin/getopt` 命令被 `getopts` 命令取代。

> 注意 — 下一个主要版本将不再支持 `getopt`。本版本提供了一个 `getoptcvt` 转换工具。有关关于 `getopts` 和 `getoptcvt` 的更多信息，请参见 `getopts(1)`

使用 `getopt` 拆分命令行中的选项以供 shell 程序解析并检查合法选项；在 shell 循环中使用 `getopts` 以确保命令行选项符合标准语法。`optstring` 是由识别的选项字母组成的字符串；使用 `getopt(3C)`。如果在字母后跟着一个冒号，则预计该选项有一个参数，该参数可能与选项被空格分隔，也可能。特殊选项 `--` 用于分隔选项的结束。如果你显式使用它，`getopt` 都会将其放在选项的末尾。shell 的位置参数（`$1 $2 ...`）会被重置，使得每个选项前面都有一个 `-` 并且位于其自己的位置参数中；每个选项参数也被解析到其自己的位置参数中。

在重新扫描选项时，将 `getopt` 重置为 `1`。
`getopt` 不支持命令语法规则 8 的部分（参见 `intro(1)`），该规则允许跟随选项后的选项-参数组通过空格分隔并加引号引用。例如，

```
cmd - a - b - o "xxx z yy" filename
```

无法被正确处理。为了纠正这一缺陷，请使用 `getopts` 命令代替 `getopt`。

## 示例

以下代码段显示了如何处理可以接受选项 `a` 或 `b` 以及需要一个参数的选项 `o` 的命令参数。

```
set `getopt abo: $*`

if [ $? -ne 0 ];

then

  echo $USAGE

  exit 2

fi

for i in "$@";

do

  case $i in

    -a -b) FLAG=$i; shift;

    -o) OARG=$2; shift 2;

    --) shift; break;

  esac

done
```

此代码接受以下任何一种等效形式。

```
cmd - aoarg filename1 filename2

cmd - a - o arg filename1 filename2

cmd - oarg - a filename1 filename2

cmd - a - oarg - filename1 filename2
```

> 注意 — 如果带有选项-参数的选项后面跟着的值与 `optstring` 中列出的选项之一相同，

```

```

`opt` 总是将 `- a` 视为 `o` 的选项-参数；它绝不会将 `- a` 识别为选项。对于这种情况，示例中的 `for` 循环将跳过文件名。

每次调用它时，`getopts` 将下一个选项放在 shell 变量 `name` 中，并将下一个处理的参数索引放在 shell 变量 `OPTIND` 中。每当你调用 shell 或 shell 脚本时，`OPTIND` 初始化为 `1`。
