
- `display` 指定与 X 服务器的连接。
- `list` 指定一个空终止字符字符串列表。
- `count` 指定指定的字符串数量。
- `style` 指定属性的编码方式。
- `text_prop_return` 返回 `XTextProperty` 结构。

`XmbTextToListTextProperty` 和 `XwcTextListToTextProperty` 函数将指定的 `XTextPropertyValue` 设置为一组空分隔元素，这些元素表示指定的空终止字符串列表的拼接结果。一个终止空字符存储在 `text_prop_return` 值的末尾，但不包含在 `n` 个成员中。

这些函数将 `text_prop_return` 的 `encoding` 字段设置为指定显示器的 `Atom`，该编码名称由指定的样式决定，并将指定的文本列表转换为该文本属性返回值中的此编码。如果指定了样式 `Xstring` 或 `XCompoundTextStyle`，则编码分别为 `STRING` 或 `COMPO_TEXT`。如果指定了样式 `XTextStyle`，则编码为当前本地化的编码。如果指定了样式 `XstdCcTextStyle`，如果文本可以完全转换为 `STRING`，则编码为 `STRING`，否则为 `COMPO_TEXT`。

如果没有足够的内存用于新值，函数将返回 `XNoMemory`。如果不支持当前本地化，函数将返回 `XLocaleNotSupported`。在这两种错误情况下，函数都不会设置 `text_prop_return`。

要确定函数是否保证会返回 `XLocaleNotSupported`，请使用 `XSupportsLocale`。

如果提供的文本无法完全转换为指定的编码，函数返回不可转换字符的数量。每个不可接受的字符都会转换为由实现定义且特定于编码的默认字符串。否则，函数返回 `Success`。注意，除 `XTextStyle` 外，保证可以向所有样式完全转换。

要释放该值，请使用 `XFree`。

要从 `XTextProperty` 结构获取文本字符串列表，请使用 `XmbTextPropertyToListList` 或 `XwcTextPropertyToTextList`。

```c
int XmbTextPropertyToListList(display, text_prop, list_return, count_return);

int XwcTextPropertyToTextList(display, text_prop, list_return, count_return);
```

- `display` 指定与 X 服务器的连接。
- `text_prop` 指定要使用的 `XTextProperty` 结构。
- `list_return` 返回空终止字符字符串列表。
- `count_return` 返回字符串的数量。

`XmbTextPropertyToList` 和 `XwcTextPropertyToList` 函数返回当前本地化环境下的文本字符串列表，表示指定的 `XTextProperty` 结构的空分隔元素。`text_prop` 中的数据格式必须为 `8`。

属性的多个元素（例如不连续文本选择中的字符串）由空字节分隔。属性的内容不需要以空终止；任何终止空都不应包含在 `text_prop.nitems` 中。

如果列表及其元素没有足够的内存，`XmbPropertyToToList` 和 `XwcPropertyToToList` 返回 `XNoMemory`。如果不支持当前本地化，或者如果 `text_prop` 的 `encoding` 字段无法转换为当前本地化，函数返回 `XwcNonSupported`。对于支持的本地化，从 `COMPOUND TEXT`、`STRING` 或当前本地化编码的转换器的存在性由 `SupportedLocale` 对当前本地化返回 `True` 保证（但实际文本可能包含不可转换字符）。其他编码的转换取决于实现。在所有错误情况下，函数不返回结果。

否则，`XmbPropertyToToList` 和 `XwcPropertyToToList` 将空终止字符串列表返回给 `list return`，并将文本字符串的数量返回给 `count`。

## 设置和读取文本属性

Xlib 提供了两个函数，用于设置和读取给定窗口的文本属性。你可以使用这些函数设置和读取类型为 `TEXT` 的属性（`WM_NAME`, `WM_ICON_NAME`, `WM COMMAND` 和 `WM_CLIENT_MACHINE`）。此外，Xlib 还提供了方便函数，你可以使用它们来设置这些属性中的每一个一个。有关这些方便函数的更多信息，请分别参见 14.1.4、14.1.5、14.2.1 和 14.2.2。

要设置窗口的文本属性之一，请使用 `XSetTextProperty`。

```c
void XSetTextProperty(display, w, text_prop, property);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop` 指定 `XTextProperty` 结构。
- `property` 指定属性名称。

`XSetTextProperty` 用数据替换指定窗口的现有属性，其数据、类型、格式和项目数量分别由指定的 `XTextProperty` 结构中的 `value` 字段、`encoding` 字段、`format` 字段和 `nitems` 字段决定。如果该属性不存在，`XSetTextProperty` 将为窗口设置它。

`XSetTextProperty` 可能会产生 `BadAlloc`、`BadAtom`、`BadValue` 和 `BadWindow` 错误。

要读取窗口的文本属性之一，请使用 `XGetTextProperty`。

```c
Status XGetTextProperty(display, w, text_prop_return, property);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop_return` 返回 `XTextProperty` 结构。
- `property` 指定属性名称。

`XGetTextProperty` 从窗口读取指定的属性并将数据存储在返回的 `XTextProperty` 结构中。它将数据存储在 `value` 字段，数据类型存储在 `encoding` 字段，格式存储在 `format` 字段，项目数量存储在 `nitems` 字段中。`text_prop_return` 的 `value` 字段末尾存储了一个包含空值的额外字节（不包含在 `nitems` 字段中）。属性编码和数据的特定解释由调用应用程序决定。如果窗口不存在该属性，`XGetTextProperty` 将 `value` 字段设为 `NULL`，`encoding` 字段设为 `None`，`nitems` 字段设为零。

如果能够读取并将数据存储在 `XTextProperty` 结构中，`XGetTextProperty` 返回非零状态；否则返回零状态。

`XGetTextProperty` 可能会产生 `BadAtom` 和 `BadWindow` 错误。

## 设置和读取 `WM_NAME` 属性

Xlib 提供了方便函数，你可以使用它们设置和读取给定窗口的 `WM_NAME` 属性。

使用提供的方便函数设置 `WM_NAME` 属性，请使用 `XSetWMName`。

```c
void XSetWMName(display, w, text_prop);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `text_prop` 指定要使用的 `XText` 结构。

方便函数 `XSetWMName` 调用 `XSetTextProperty` 来设置 `WM_NAME` 属性。

使用提供的方便函数读取窗口的 `WM_NAME` 属性，请使用 `XGetWMName`。

```c
Status XGetWMName(display, w, text_prop_return);
```
