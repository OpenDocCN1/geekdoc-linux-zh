
- `XcmmsSuccess` 表示函数执行成功。此外，如果函数执行了任何颜色转换，则颜色不需要被压缩。
- `XcmmsSuccessWithCompression` 表示函数执行了颜色转换，且至少有一种颜色需要被压缩。色域压缩方法由 `CCC` 中的色域压缩程序决定，该程序直接作为函数参数指定，或者通过颜色表参数间接指定的 `CCC` 指定。

## 复制与销毁颜色表

要为屏幕创建颜色表，请使用 `XCreateCol`。

### 颜色管理函数

```c
Colormap XCreateColormap(display, w, visual, alloc);
```

- `display`: 指定到 X 服务器的连接。
- `w`: 指定你想要在其创建颜色表的窗口。
- `visual`: 指定屏幕上支持的视觉类型（`visual`）。如果屏幕不支持该视觉类型，则会导致 `BadMatch` 错误。
- `alloc`: 指定要分配的颜色表条目。你可以传递 `AllocNone` 或 `AllocAll`。

`XCreateColormap` 函数为指定窗口所在的屏幕创建一个指定视觉类型的颜色表，并返回与其关联的颜色表。请注意，指定的窗口仅用于确定屏幕。

对于 `GrayScale`、`PseudoColor` 和 `DirectColor` 视觉类，颜色表条目的初始值是未定义的。对于 `StaticGray`、`StaticColor` 和 `TrueColor`，条目有定义值，但这些值是特定于视觉类型的，且不由 X 定义。对于 `StaticGray`、`StaticColor` 和 `TrueColor`，所有条目必须为 `AllocNone`，否则将产生 `BadMatch` 错误。对于其他视觉类型，如果 `AllocNone` 初始已分配了条目，则客户端可以分配它们。关于此点的信息，请参阅第 3.1 节。

如果你使用 `AllocAll`，则会分配颜色表。已分配条目的初始值未定义。对于 `GrayScale` 和 `PseudoColor`，其效果等同于 `XallocColorCells` 返回了从零到 N-1 的所有像素值，其中 N 为。对于 `DirectColor`，其效果等同于 `XallocColorPlanes` 返回了像素值为零的红掩码、绿掩码和蓝掩码包含指定窗口中对应掩码相同的位。然而，在所有情况下，这些内容都无法使用 `XFreeColors` 释放。

`XCreateColormap` 可能会产生 `BadAlloc`、`BadMatch`、`BadValue` 和 `BadWindow` 错误。

当由于资源耗尽导致之前共享颜色表的分配失败时，使用 `XCopyColormapAndFree` 创建一个新的颜色表。

```c
Colormap XCopyColormapAndFree(display, colormap);
```

- `display`: 指定到 X 服务器的连接。
- `colormap`: 指定颜色表。

`XCopyColormapAndFree` 函数创建一个与指定颜色表视觉类型相同且位于相同屏幕的颜色表，并返回新的颜色表 ID。它将客户端的所有分配从指定的颜色表移动到新颜色表，保持其颜色值以及只读或可写特性不变。新颜色表中其他条目的颜色值未定义。如果指定的颜色表是客户端使用 `alloc AllocAll` 创建的，则新颜色表也以 `AllocAll` 创建，所有条目的颜色值都从指定的颜色表复制，然后释放指定颜色表中的条目。如果指定的颜色表不是客户端用 `AllocAll` 创建的，则要移动的分配是客户端使用 `XAllocColor`、`XAllocNamedColor` 或 `XAllocColorPlanes` 分配且自分配以来未释放的像素和平面。

`XCopymapAndFree` 可能会产生 `BadAlloc` 和 `BadColor` 错误。

要销毁颜色表，请使用 `XFreeColormap`。

```c
XFreeColormap(display, colormap);
```

- `display` 指定到服务器的连接。
- `colormap` 指定你想销毁的颜色表。

`XFreeColormap` 删除了颜色表与屏幕之间的关联。`XFreeColormap` 可能会产生 `BadColor`。

## 将颜色名称映射到值

将颜色名称映射到值，请使用 `XLookupColor`。

```c
Status XLookupColor(display, colormap, color_name, exact_return, screen_return);
```

- `display`: 指定到 X 服务器的连接。
- `colormap`: 指定颜色表。
- `color_name`: 指定想要返回的颜色字符串（例如红色）。
- `exact_return`: 返回 RGB 值。
- `screen_return`: 返回硬件提供的 RGB 值。

`XLookupColor` 函数根据与颜色表关联的屏幕查找字符串名称。它返回相对于指定视觉类型的精确值和屏幕提供的最接近的值。如果名称不在主机通用编码中，则结果取决于实现。大小写不影响结果。`XLookupColor` 在名称解析成功返回非零值，否则返回零。

## 颜色管理函数（续）

将颜色名称映射到精确 RGB 值，请使用 `XParseColor`。

```c
Status XParseColor(display, colormap, spec, exact_return);
```

- `display`: 指定到 X 服务器的连接。
- `colormap`: 指定颜色表。
- `spec`: 指定颜色名称字符串；忽略大小写。
- `exact_return`: 返回精确值并设置 `DoRed`、`DoGreen` 和 `DoBlue` 标志。

`XParseColor` 函数根据与颜色表关联的屏幕查找字符串名称。它返回精确值。如果名称不在主机通用编码中，则结果取决于实现。大小写不影响结果。`XParseColor` 在名称解析成功返回非零值，否则返回零。

`XParseColor` 产生 `BadColor`。

将颜色名称映射到任意颜色空间，请使用 `XcmsLookupColor`。

```c
Status XcmsLookupColor(display, color_string, color_screen_return, result_format);
```

- `display`: 指定到 X 服务器的连接。
- `colormap`: 指定颜色表。
- `color_string`: 指定颜色字符串。
- `color_exact_return`: 返回从颜色字符串解析出的或从颜色名称数据库找到的对应字符串解析出的颜色规格。
- `color_screen_return`: 返回可以在屏幕上还原的颜色。
- `result_format`: 指定返回颜色规格的颜色格式（屏幕返回参数）。如果格式为 `XcmsUndefinedFormat` 且颜色字符串包含数值颜色规格，则按数值颜色规格的格式返回。如果格式为 `XcmsUndefinedFormat` 且颜色字符串包含颜色名称，则按数据库中存储颜色的格式返回。

`XcmsLookupColor` 函数根据与颜色表关联的屏幕查找字符串名称。它返回相对于指定视觉类型的精确值和屏幕提供的最接近的值。值按 `result_format` 指定的格式返回。

或者如果名称已解析，则返回 `XcmsSuccessWithCompression`；否则返回 `XcmsFailure`。如果返回了 `XcmsSuccessWithCompression`，则颜色屏幕返回的颜色规格将返回色域压缩的值。

## 分配和释放颜色单元

分配颜色单元有两种方式：显式地作为只读单元分配，或者一次分配一个像素，或者读/写单元，在这些情况下，你可以同时分配多个颜色单元和平面。只读单元的 RGB 值由服务器设置；读/写单元最初没有定义的颜色；下一节中指定的单元必须用于将值存储到它们中。任何客户端都可能将值存储在另一个客户端分配的读/写单元中，但通常情况下，读/写单元应该被视为分配它们的客户端的私有单元。

只读颜色单元在客户端之间共享。服务器会统计客户端对单元的每次分配和释放操作。当最后一个客户端释放共享单元时，该单元最终会被释放。如果单个客户端多次分配同一个只读单元，服务器会计算每一次此类分配，而不是只第一次。

要分配一个具有 RGB 值的只读颜色单元，请使用 `XallocColor`。

```c
Status XallocColor(display, colormap, screen_in_out);
```

- `display`
指定到 X 服务器的连接。
- `colormap`
指定颜色表。
- `screen_in_out`
指定并返回在颜色表中实际使用的值。

`XallocColor` 函数分配一个与硬件支持的最接近的 RGB 值相对应的只读颜色表。`XallocColor` 返回硬件支持的、与指定的 RGB 元素最接近的颜色像素值，并返回对应的只读颜色表单元。此外，`XallocColor` 在成功时返回非零值，在失败时返回零。多个请求相同有效 RGB 值的客户端可以分配相同的只读条目，从而允许条目共享。当最后一个客户端释放共享单元时，它会被释放。`XallocColor` 不使用或影响 `Xstructure` 中的标志位。

`XallocColor` 可能会产生 `BadColor` 错误：

要分配一个具有任意格式颜色的只读颜色单元，请使用 `XcmsAllocColor`。
