## 系统管理指南

# db — 通用调试器

## 概要

```
/usr/bin/db [-k] [-w] [-I dir] [-P prompt] [-V mode] [objectfile [corefile [swapfile]]]
```

## 描述

`db` 工具适用于 Solaris 5。它们提供了与 SunOS 4x 工具相同的功能。`db` 经过增强以识别多个处理器。处理器 ID 在 `db` 提示符中显示。`db` 命令是一个交互式的通用调试器。你可以使用它来检查文件。程序执行的控制环境。在 Solaris 2 下进行调试变得更容易：

- 通过取消 `/etc/init.d/syset` 中的 `dbcore` 行来启用 `dbcore`。
- 通过输入 `$c` 在系统崩溃时启动 `dbcore`。

`db` 命令取决于平台和发布版本。

### 缺陷

由于没有调用 shell 来解释 `db` 的参数，通配符和变量展开不会发生。

## 选项

- `-k` 执行内存映射；使用 core dump 或 `/dev/mem` 或 `swapfile`。
- `-w` 如果必要，创建 `objectfile` 和 `corefile` 并打开它们读写以便使用 `db` 进行修改。
- `-I dir` 指定以冒号分隔的目录列表（见下文）；默认是 `/usr/lib/db`，其中 `db` 是文件名。
- `-P prompt` 指定 `db` 提示符字符串。
- `-V mode` 指定反汇编和寄存器显示模式。`mode` 值为 `1` (`v8`)，`2` (通用)，`4` (`v9 PlusARC` 特定指令)。默认模式由所检查的 `corefile` 类型决定（仅 SPARC）。

## 操作数

- `objectfile` 通常是可执行程序文件，包含符号表。如果文件不包含符号表，你仍然可以检查，但无法使用 `db` 的功能。`objectfile` 的默认是 `out`。
- `corefile` 假设是 `objectfile` 执行后产生的核心映像。`corefile` 的默认是 `core`。
- `swapfile` 使用的交换设备映像。仅在使用 `-k` 选项时有效。

## 使用

`db` 命令从标准输入读取命令并在标准输出显示响应。默认情况下它不提供提示符。忽略 `QUIT` 信号。`INTERRUPT` 调用下一个 `db` 命令。`db` 通常识别如下形式的命令输入：

```
[address], [count] [command]
```

`address` 和 `count`（如果提供）是当前位置和重复计数的表达式。`command` 由动词加上修饰符或修饰符列表组成。

符号 `(`.)` 表示当前位置；初始为 `0`。默认计数为 `1`。

### 表达式

- `.` `dot` 的值。
- `+` 增加的 `dot` 值。
- `^` 减少的 `dot` 值。
- `&` 最后输入的地址。在旧版本的 `db` 中，使用了双引号（`"`）。
- `integer` 一个数字。前缀 `0o` 和 `00` 表示八进制；`0t` 和 `0T` 表示十进制；`0x` 和 `0X` 表示十六进制（默认）。
- `int.frac` 浮点数。
- `'cccc'` 最多 4 个字符的 ASCII 值。
- `<name>` `name` 的值，可以是变量名或寄存器名。
- `symbol` 符号表中的符号。
- `(exp)` `exp` 的值。

### 一元运算符

- `* exp` `corefile` 中位置 `exp` 的内容。
- `% exp` `objectfile` 中位置 `exp` 的内容（在旧版本的 `db` 中，使用了 `@db`）。
- `- exp` 整数取反。
- `~ exp` 位取反。
- `# exp` 逻辑取反。

### 二元运算符

二进制运算符是左关联的，优先级低于一元运算符。

- `+` 整数加法。
- `-` 整数减法。
- `*` 整数乘法。
- `%` 整数除法。
- `&` 位与（AND）。
- `|` 位或（OR）。
- `#` 左侧结果向上取整到右侧的倍数。

### 变量

命名变量最初由 `db` 设置，但随后不再使用。

- `0` 最后打印的值。
- `1` 指令源最后的偏移部分。
- `2` 变量 `1` 的上一个值。
- `9` 上一次 `$$` 或 `$$` 命令的计数。

进入时，将从 `corefile` 或 `objectfile` 中的系统头适当地设置以下变量：

- `b` 数据段的基地址。
- `d` 数据段的大小。
- `e` 入口点。
- `m` 魔数。
- `t` 代码段的大小。

### 命令动词

`db` 的命令由动词加上修饰符或修饰符列表组成。

- `?` 打印 `objectfile` 中从地址开始的位置。
- `/` 打印 `corefile` 中从地址开始的位置。
- 打印地址本身的值。
- 管理子进程。
- 给变量或寄存器赋值。
