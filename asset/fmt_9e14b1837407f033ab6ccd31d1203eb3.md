
# 颜色管理函数

`XcmsQueryGreen` 函数返回全强度绿色的格式。

为了获取红色（全强度红色，而绿色和蓝色为零）的颜色规范，我们使用 `XcmsQueryRed`。

```
Status XcmsQueryRed(ccc, target_format, color_return);
```

`ccc` 指定 CCC。CCC 的客户端白点和白点调整程序被忽略。

`target_format` 指定目标颜色规范格式。

`color_return` 返回全强度红色的格式。返回的规范白点假设为屏幕白点。`pixel` 成员未定义。

`XcmsQueryRed` 函数返回全强度红色的格式。

为了获取白色（全强度红、绿、蓝）的颜色规范，我们使用 `XcmsQueryWhite`。

```
Status XcmsQueryWhite(ccc, target_format, color_return);
```

`ccc` 指定 CCC。CCC 的客户端白点和白点调整程序被忽略。

`target_format` 指定目标颜色规范格式。

`color_return` 返回全强度红、绿、蓝的格式。

与返回的颜色规范相关的白点是屏幕白点。`pixel` 成员中返回的值是未定义的。

`XcmsQueryWhite` 函数返回在全强度红、绿、蓝的指定目标格式格式的颜色规范。

## CIELab 查询

以下方程在描述 CIELab 查询函数时非常有用：

```
%CIELab-Psychometric-Chroma ~= sqrt(a_star^2 +- b_star^2 )
%CIELab-Psychometric-Hue ~= tan^-1 [ b_star / a_star ]
```

对于给定的心理色角和 CI 亮度亮度 (L*)，获取最大心理色度的 CI L*a*b* 坐标，请使用 `XcmsCIELabQueryMax`。

```
Status XcmsCIELabQueryMax(ccc, hue_angle, L_star, color_return):
```

- `ccc`: 指定 CCC。忽略 CCC 的客户端白点和白点调整程序。
- `hue_angle`: 指定用于寻找最大色度的色角（单位：度）。
- `L_star`: 指定用于寻找最大色度的亮度 (L*)。
- `color_return`: 返回在给定色角和亮度下，屏幕可显示的最大色度 CIE L*a*b* 坐标。与返回的颜色规范相关的白点是屏幕白点。`pixel` 成员中返回的值是未定义的。

`XcmsCIELabQueryMax` 函数在色角和亮度的情况下，寻找屏幕可显示的最大色度点。它以 CI L*a*b* 坐标返回此点。

对于给定的心理色角和心理色度，获取最大 CI 亮度亮度 (L*) 的 CI L*a*b* 坐标，请使用 `XcmsCIELabQueryMaxL`。

```
Status XcmsCIELabQueryMaxL(ccc, hue_angle, chroma, color_return):
```

- `ccc`: 指定 CCC。忽略 CCC 的客户端白点和白点调整程序。
- `hue_angle`: 指定用于寻找最大亮度的色角（单位：度）。
- `chroma`: 指定用于寻找最大亮度的色度。
- `color_return`: 返回在给定角度和色度下，屏幕可显示的最大亮度 CIE L*a*b* 坐标。与返回的颜色规范相关的白点是屏幕白点。`pixel` 成员中返回的值是未定义的。

`XcmsCIELabQueryMaxL` 函数在色调和色度的情况下，寻找 CIE L*a*b* 颜色空间中屏幕可显示的最大亮度 (L*) 点。它以 CIE L*a*b* 坐标返回此点。`XcmsFailure` 返回值通常表示色度超过了给定色角的最大值。

对于给定的心理色角，获取最大心理色度的 CIE L*a*b* 坐标，请使用 `XcmsCIELabQueryMaxLC`。

```
Status XcmsCIELabQueryMaxLC (ccc, hue_angle, color_return):
```

- `ccc`: 忽略 CCC 的客户端白点和白点调整程序。
- `hue_angle`: 指定用于寻找最大色度的色调（单位：度）。
- `color_return`: 返回在给定角度下，屏幕可显示的最大色度 CIE L*a*b* 坐标。与返回的颜色规范相关的白点是屏幕白点。`pixel` 成员中返回的值是未定义的。

`XcmsCIELabQueryMaxLC` 函数在色调和色度的情况下，寻找屏幕可显示的最大色度点。它以 CIE L*a*b* 坐标返回此点。

对于给定的心理色角和心理色度，获取最小 CI 亮度亮度 (L*) 的 CIE L*a*b* 坐标，请使用 `XcmsCIELabQueryMinL`。

```
Status XcmsCIELabQueryMinL (ccc, hue_angle, chroma, color_return):
```

- `ccc`: 指定 CCC。忽略 CCC 的客户端白点和白点调整程序。
- `hue_angle`: 指定用于寻找最小亮度的色角（单位：度）。
- `chroma`: 指定用于寻找最小亮度的色度。
- `color_return`: 返回在给定角度和色度下，屏幕可显示的最小亮度 CIE L*a*b* 坐标。与返回的颜色规范相关的白点是屏幕白点。`pixel` 成员中返回的值是未定义的。

`XcmsCIELabQueryMin` 函数在色角和色度的情况下，寻找屏幕可显示的最小亮度 (L*) 点。它以 CIE L*a*b* 坐标返回。`XcmsFailure` 返回值通常表示给定的色度超过了给定色角的最大值。

## CIELuv 查询

```

%CIELuv-Psychometric-Hue ~= tan^-1 [ v_star / u_star ]
```


`XmsCIELuvQueryMaxC` 在色角和亮度的情况下，寻找屏幕可显示的最大色度点。它以 CIE L*u*v* 坐标返回。
