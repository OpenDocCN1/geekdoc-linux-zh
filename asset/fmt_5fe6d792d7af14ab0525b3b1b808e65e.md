```
--*Emacs: dickens.note (Fundamental)---Bot----
保存文件 `/users/taylor/dickens.note`? (y 或 n)
```

输入 `y` 保存更改；`n` 退出但不保存更改；如果你决定返回编辑会话，`Escape` 将完全取消操作。输入 `n` 会再次提醒你，如果不保存，更改将会丢失。
