
`XCopyArea` 函数将源的指定矩形与目的的指定矩形合并。绘图对象必须具有根和深度，否则会产生错误。如果源矩形的区域被遮挡且未缓存，或者指定了绘图对象边界外的区域，这些区域将不会被复制。相反，将在可见或缓存的目标区域上执行操作。如果目标是具有除 `None` 背景的窗口，目标区域将使用背景进行平铺（全1 位掩码和 GC 函数）。无论是否平铺或目标是窗口或 pixmap，如果所有目标区域的图形暴露事件为 True，如果图形暴露事件为 True 但没有生成 `GraphicsExpose` 事件，则会生成 `NoExposure` 事件。默认情况下，新 GC 的 `graphics-plane-mask` 为 True。

此函数使用这些 GC 组件：`function`、`plane-mask`、`subdivision-mode`、`graphics-exposes`、`clip-x`、`clip-y` 和 `clip-mask`。

`XCopyArea` 可能会产生 `BadDrawable`、`BadGC` 和 `BadMatch` 错误。

若要复制给定绘图对象的单位平面，使用 `XCopyPlane`。

```
XCopyPlane(display, src, dest, gc, src_x, src_y, width, height, dest_x, dest_y, plane);
```

- `display` 指定与 X 服务器的连接。
- `src` 指定源和目标矩形。
- `gc` 指定指定的 GC。
- `src_x` `src_y` 指定 x 和 y 坐标，相对于源矩形的起点，指定其左上角。
- `width` `height` 指定宽度和高度，即源和目标矩形的尺寸。
- `dest_x` `dest_y` 指定 x 和 y 坐标，相对于目标矩形的起点，指定其左上角。
- `plane` 指定要复制的位平面。

# 图形函数

## XCopyPlane

`plane` 指定位平面。你必须将恰一个位设置为 1。

`XCopyPlane` 函数使用指定的源矩形的单个位平面，配合指定的 GC 来修改目标（`dest`）的矩形。绘制对象（drawables）必须具有相同的根窗口，但深度不需要相同。如果绘制对象没有相同的根窗口，则将导致 `BadMatch` 错误。如果 `plane` 没有恰好有一个位被设置为 1，且 `plane` 的值不小于 `$2^n$`（其中 `$n$` 是 `src` 的深度），则会导致 `BadValue` 错误。

实质上，`XCopyPlane` 为目的的指定矩形形成一个映射，其大小由源区域指定。它通过 GC 中的前景色/背景像素（当 `src` 中的位平面包含设置为 0 的位时处处使用前景色）和背景，执行了等同于 `CopyArea` 协议的操作，并具有所有相同的曝光语义。这也可以被理解为使用源位平面的指定区域作为 `FillOpaqueStippled` 的填充样式，用于填充目的的矩形区域。

此函数使用了这些 GC 组件：`function`、`plane-mask`、`foreground`、`background`、`subwindow-mode`、`graphics-exposures`、`clip-x-origin`、`clip-y-origin` 和 `clip-mask`。

`XCopyPlane` 可以产生 `BadDrawable`、`BadGC`、`BadMatch` 和 `BadValue` 错误。

## 绘制单点和多点

要在指定的绘制对象中绘制一个点，使用 `XDrawPoint`。

```c
XDrawPoint(display, d, gc, x, y);
```

- `display` 指定到 X 服务器的连接。
- `d` 指定绘制对象。
- `gc` 指定 GC。
- `x` 和 `y` 指定想要绘制点的 x 和 y 坐标。

要在指定的绘制对象中绘制多个点，使用 `XDrawPoints`。

```c
XDrawPoints(display, d, gc, points, npoints, mode);
```

- `display` 指定到 X 服务器的连接。
- `d` 指定绘制对象。
- `gc` 指定 GC。
- `points` 指定一个点数组。
- `npoints` 指定数组中点的数量。

`mode` 指定坐标模式。你可以传递 `CoordModeOrigin` 或 `CoordModePrevious`。

`DrawPoint` 函数使用 GC 的前景色像素和函数组件在绘制对象中绘制单个点；`XDrawPoints` 则以这种方式绘制多个点。`CoordModeOrigin` 将所有坐标视为相对于原点，`CoordModePrevious` 将第一个点之后的所有坐标视为相对于上一个点。`XDrawPoints` 按照数组列出的顺序绘制点。

这两个函数都使用了这些 GC 组件：`function`、`plane-mask`、`foreground`、`subwindow-mode`、`clip-x`、`clip-y` 和 `clip-mask`。

`XDrawPoint` 可以产生 `BadDrawable`、`BadGC` 和 `BadMatch` 错误。

`XDrawPoints` 可以产生 `BadDrawable`、`BadGC`、`BadMatch` 和 `BadValue` 错误。
