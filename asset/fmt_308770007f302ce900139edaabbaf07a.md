- `RPN`: 来自 VERA 的逆波兰尔表示法 http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `RPN` (逆波兰尔表示法)：一种描述数学运算的方法，便于计算机处理。在 `RPN` 中，表达式 `"a b +'"` 表示加 `a` 和 `b`，在标准符号中写为 `"a + b"`。与波兰尔符号同义。QUEDIC http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `rpcalc`: 模拟 `HP285` 的 `RPN` 计算器。`rpcalc` 是一个类似于 `dc(1)` 的计算器，但它使用 `readline` 并视觉化栈。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

- `RPP`: 来自 VERA 的相对处理器性能 (`CPU`, `Cray`) http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

- `rproxy`: 使用差异加速检索的缓存。代理存储检索页面的哈希值，当你下次访问同一页面时，它计算当前页面与最近存储页面之间的差异。`rproxy` 的 HTTP 扩展允许服务器针对缓存实例生成 `hsync`，这种方式是完全通用的，并传输到服务器和用户代理。实现 `hsync` 的 `rproxy`、客户端和服务器计算文件的块签名，计算连续块（如 1024 字节）的校验和。然后将此校验和添加到请求头中并照常传输。要有用在于，客户端和服务器之间应至少有两个代理实例。代理之间的传输是增量编码的，而浏览器和服务器看到的只是标准的 HTTP。在每个现代调制解调器上运行一个实例是非常有用的，这样跨越链路的数据流将是增量编码的。更多信息请参阅 http://linuxcare.com.au/proxy/ 来源于 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- `rrdtool`

时间序列数据和显示系统（`prods`）`RRD` 是轮询队列数据库（`Round Robin Database`）的缩写。`RRD` 是一个用于存储和显示时间序列数据的系统（例如网络带宽、机房温度、服务器平均负载）。它以非常紧凑的方式存储数据，不会随时间推移而膨，并通过处理数据以确保特定的密度来呈现有用的图表。可以使用简单的封装脚本（来自 `shell` 或 `Perl`）或通过轮询网络设备并操作 `RRD` 的前端来使用。此包包含了用于访问和操作 `RRD` 的命令行程序。来源于 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

- `rrdtool-tcl`

时间序列数据和显示系统（`tcl`）`RRD` 是轮询队列数据库的缩写。`RRD` 是一个用于存储和显示时间序列数据的系统（例如网络带宽、机房温度、服务器平均负载）。它以非常紧凑的方式存储数据，不会随时间推移而膨胀，并通过处理数据以确保特定的密度来呈现有用的图表。可以使用简单的封装脚本（来自 `shell` 或 `Perl`）或通过轮询网络设备的前端来使用。此包包含了指向 `RRD` 的 `tcl` 接口。来源于 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
