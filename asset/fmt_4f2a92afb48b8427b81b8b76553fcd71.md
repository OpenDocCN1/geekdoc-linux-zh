
`WHEN`关键字求值为逻辑1时，其后`THEN`关键字后面的方程将被激活。如果表达式求值为逻辑0，则其后`ELSE`关键字后面的方程处于活动状态。在本例中，所有写线`W0–W3`通常处于逻辑0。然而，在第38行，如果输入地址等于0 (`A==0`) 且写输入为低 (`WEB`)，则`W0`线变为逻辑1。如果激活`W0`的条件不满足，而`A==1`且`WEB==0`，则`W1`线变为逻辑1 (第39行)。控制`W2`和`W3`写线的逻辑类似，描述于第40行和第41行。如果没有任何布尔表达式求值为逻辑1，则没有任何方程被激活，写线全部保持在逻辑0。

第45–48行将写控制线连接到各自寄存器的时钟输入。请注意，时钟输入被反相，因此它们在寄存器被写入时除外通常为高。因此，在写操作结束时，时钟输入上会出现上升沿，导致`D`触发器被加载新值。这会将输入总线上的值锁存到所选寄存器中。存储器是异步的，因为每个寄存器都接收到自己的独立时钟，该时钟源自RAM的主写控制输入。

第52–55行使用`WHEN…THEN…ELSE`结构来描述一个多路复用器电路。多路复用器只是检查输入地址并将其中一个寄存器的输出门控到输出总线上。第58行将`OE`输出连接到输出数据总线缓冲器的输出使能控制。因此，如果`OE`为低，缓冲器将处于高阻抗状态。只有当`OE`为逻辑1时，存储器位置的值才能被读出。

存储器的输出驱动一个LED解码电路，该电路由第61–77行的真值表描述。

4×4存储器的VHDL版本显示在Listing 8.2中。第1–7行的`ENTITY`块声明了存储器的接口。以下`ARCHITECTURE`声明以四个4位信号数组的声明开始，这些数组将存储寄存器内容 (第21–24行)。随后是寄存器写使能控制的声明 (第26和27行)。

存储器地址解码器描述于第33至41行。如果其地址与地址输入匹配且主写使能输入为低，则寄存器的写控制线将被拉低。如果写使能输入不为低或没有任何地址匹配，则所有写控制线都保持在逻辑1。

每个写控制线作为第43–48行、第50–55行、第57–62行或第64–69行的其中一个独立寄存器进程的时钟。在这些进程中，输入数据总线上的值会在写控制信号的上升沿写入寄存器。

第71至74行的输出多路复用器使用输入地址选择其中一个寄存器并将其内容传递到中间输出总线`outbus`。然后，如果输出使能为高，则中间输出总线上的值会被传递到主输出总线 (第75行)。如果输出使能为低，则输出总线将被置于高阻抗状态。

#### Listing 8.2 由4个寄存器模块构成的4位宽异步存储器的VHDL版本。(续)

```
041- w3 <= w(3);

042-

043- PROCESS (w0, inp)        -- register a
044- BEGIN
045-   IF(w0’event AND w0='1') THEN
046-      rga <= inp;           -- write register a with inp bus on
047-   END IF;                  -- a rising edge of the w0 write-enable
048- END PROCESS;

049-

050- PROCESS (w1, inp)        -- register b
051- BEGIN
052-   IF(w1’event AND w1='1') THEN
053-      rgb <= inp;           -- write register b with inp bus on
054-   END IF;                  -- a rising edge of the w1 write-enable
055- END PROCESS;

056-

057- PROCESS (w2, inp)        -- register c
058- BEGIN
059-   IF(w2’event AND w2='1') THEN
060-      rgc <= inp;           -- write register c with inp bus on
061-   END IF;                  -- a rising edge of the w2 write-enable
062- END PROCESS;

063-

064- PROCESS (w3, inp)        -- register d
065- BEGIN
066-   IF(w3’event AND w3='1') THEN
067-      rgd <= inp;           -- write register d with inp bus on
068-   END IF;                  -- a rising edge of the w3 write-enable
069- END PROCESS;

070-

071- outbus <=                 rga WHEN a="00" ELSE -- output addressed
072-                            rgb WHEN a="01" ELSE -- register value
073-                            rgc WHEN a="10" ELSE -- onto intermediate
074-                            rgd;
075- outp <= outbus WHEN oe='1' ELSE "ZZZZ"; -- tristate bus when oe=0
076-
077- u0: led4dc PORT MAP (d=>outp,s=>s); -- display digit on LEDs
078-
079- END mem1_arch;
080-
```

最后，输出总线上的值在第77行被传递给LED解码器模块。这使得4位输出值能够以十六进制数字的形式显示在LED显示器上。
