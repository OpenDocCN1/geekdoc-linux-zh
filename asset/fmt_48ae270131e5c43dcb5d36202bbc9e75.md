
这就是为了用 `Vim` 程序打开想要编辑的文件而需要执行的所有操作。但你也可以使用这种语法来完成其他事情。当你使用上述完全相同的语法时，你可以创建一些新文件。要查看它是如何运作的，你需要打开命令提示符，然后将上面的命令放在里面。你可以为你想要创建的文件命名，然后它就会打开供你使用。如果你对打开一个新文件供你尝试进行一些新更改感到困惑，请记住这一点。

对于某些使用过 Linux 变体的人，你可能知道在执行 `vim` 命令时可以根据需要去掉 `sudo` 命令。这确实可行，但对于 Ubuntu 发行版，你会发现无论你是否带有 `sudo` 命令，这都可能导致你想打开的文件出现一些问题。其他时候，如果缺少 `sudo` 命令，你会发现程序无法打开。至少对于 Ubuntu 发行版，你应该始终确保 `sudo` 命令就绪。

### 修改文件所有权

在该系统内部你可以执行的另一个任务是更改所有权。为了理解它是如何运作的，让我们考虑计算机上的程序。当你在 Linux 系统上安装新软件时，所有权对于大多数将 Linux 作为个人操作系统使用的人来说并不是大问题，但可能会引发一些问题。

当你在 Linux 内部工作时，除非你是文件的所有者，否则你无法对文件进行更改。当你处理你拥有的程序时，这会导致一些问题。例如，如果你向系统下载了 PHP 或 MySQL，你会发现所有者不是你。如果你想对这些程序进行一些编辑，这是可能的，因为你不是所有者。

所以，如果你想对配置文件进行一些编辑，你首先需要将所有权更改为你自己，以便更方便。实现这一点的语法包括：

```
$ sudo chown <username> <filename>
```

要以正确的方式实现这一目标，你需要输入以下语法：

```
$ sudo chown reader notes
```

一旦此操作进入系统，你会发现你现在是该特定文件的所有者，并且你能够按照你喜欢的方式使用它。这与你在 Windows 上使用的某些其他程序有所不同，但它之所以能运行，是因为 Linux 系统是开源的，因此它是免费的，任何人都可以按照你想要的方式使用该程序。只需要这种简单的语法就能确保你能够获得想要的结果。

### 编辑

现在，我们已经花了一些时间打开你想用 Vim 使用的文件，现在是时候学习如何对你想修改的文件进行一些修改了。当你尝试编辑文件时，你应该注意到的第一点是使用方向键移动光标并输入内容来编辑文件。对于不习惯这种系统的人来说，这可能看起来很令人沮丧，但你只需要进入“插入模式”`Insert mode`。

要进入插入模式，你只需要输入字母“`i`”。完成后，你就可以对文件进行任何你想要的修改。当你觉得修改已完成，你需要退出插入模式。只需按下 `ESC` 键即可。

你想要更改的大多数文档通常都很长。如果你想进行更改，可以使用命令来让这一切变得更简单。首先，你需要确认你已经退出了插入模式。现在调出写入代码的命令。此命令用于查看你想要更改的所有地方，直到到达文档末尾。这将帮助你获取你正在寻找的信息。

一些使用这种语言的人发现，以不同的方式处理此效果更好。与其编写上述代码，你不如输入 `:filename`。这个命令很好用，因为它显示了你想查找任何前面带有特殊字符的内容。现在，通过我们在语法中使用使用的正斜杠 `/`，你会发现光标从你的当前位置开始向下移动。

但如果你在搜索文档时已经到达底部，却仍然找不到想要的内容，会发生什么？使用该语法对你没太大帮助。更好的解决方案是使用命令：

```
/:filename
```

使用这个命令，光标将从你的当前位置开始向文档上方移动，这样你就可以反复来回查找你想要找到的不同关键词，无论你当前的位置在何处。

### 退出并保存更改

一旦你完成了浏览并进行了你所需要的编辑，现在是时候打开文件并保存你在 Vim 系统中使用的文件了。我们已经花了一些时间从命令行打开了文件，现在我们将讨论当你已经在 Vim 内部时如何打开更多文件。

所以，当你在 Vim 程序内部需要打开文件时，只需要输入以下命令切换到另一个文件：

```
:filename
```

当然，你需要确保在执行此操作时不要处于插入模式，否则 Vim 程序将仅仅把该新命令输入到文档中，而不会被视为打开文件的命令。只需确保退出插入模式，然后输入命令为你设置新文件即可。在 Vim 程序内部处理多个文件时，这就是你需要做的全部事情。

现在是时候学习如何退出文件了。如果你打开一个文件发现它不是你想操作的文件，或者你看到文档中的更改已经完成，你可能想关闭文件。在不进行任何更改的情况下关闭文档，只需输入：

```
:q
```

输入此内容并按回车键让系统执行。此外，在你想要关闭程序时，有时 Vim 程序会停止工作，或者它无法按预期通过退出命令工作，而你仍然想退出程序。在这种情况下，你可能想要强制关闭 Vim 程序。为了强制关闭程序，你只需要输入以下语法：

```
:q!
```

当你想要退出程序且程序不允许你执行你想操作的操作时，这就是你应该使用的命令。请记住，如果你使用了这些选项，在编辑时你的任何工作都不会被保存，除非你之前已经保存了它们。你应该始终确保在继续之前保存你正在工作的信息，否则你将丢失所有工作。

所以，有时你可能想对文件进行更改，然后希望它为你保存，以便更改能够存在且不会丢失。为了保存你想要的文档更改，只需输入以下命令：

```
:wq
```

此命令的第一部分保存你对文件所做的更改，第二部分关闭你正在使用的程序。这使得当你只想进行更改并在完成后退出程序时，这是一个完美选择。

在某些情况下，你可能想对文件进行一些更改但不想保存它们。这就是你想要了解如何使用正斜杠的时候。当你想要学会保存文件时，只需输入以下命令：

```
:w!
```

## 显示和列出你的文件

一旦你进入了想要使用的目录，你就应该花些时间确定该目录里有什么。幸运的是，这是一个你能够完成的简单过程。为了列出 Linux 系统中的文件，你只需要使用以下命令：

```bash
$ ls
```

在列出文件时，你有几个可以使用的参数，它们将取决于你想要系统做什么。例如，如果你执行了以下操作：

```bash
$ ls -l
```

你将能够获得系统上列出的所有文件夹和文件。除了列出这些内容外，你还可以看到所有这些文件夹和文件的权限、最后修改的日期、这些项目的所属组所有权，以及在你的系统中谁拥有这些项目的个人所有权。这有时会变成一个非常大的文件，因为它包含了很多信息。如果你想学习某些信息，而不想列出这么多内容并占用这么多空间，你可以使用这种语法：

```bash
$ ls -m
```

使用这种语法，你将获得以块形式输入的所有内容，而不是使用之前的语法显示的冗长列表。它将以更整洁的格式将它们放在一起，比之前占用更空间，但仍然会为你提供了解文件夹所需的信息。

现在，你可以用此做的另一件事是当你想要编辑其中一个文件，但又难以确定它位于何处。Linux 确实有选项可以帮助你，帮助那些不知道想要处理的文件位于哪里的人。如果你想搜索该文件以便找到它所在的目录，你只需要输入以下语法：

```bash
$ sudo find -iname <file/folder>
```

在 Linux 上工作时，使用 `-iname` 函数真的非常重要。在大多数情况下，Linux 系统对你使用的大小写非常敏感。你必须区分你使用的大写字母和小写字母。但当你使用 `-iname` 函数时，你使用的大小写就没了。

这可以帮助你遍历所有可用目录，无论它们内部使用的是大写还是小写字母。如果你不确定要搜索的文件名称，这将为你节省大量的时间和麻烦。

此外，在使用此选项时，你需要确保在该语法中使用了 `sudo` 命令。如果你不把它放进去，你甚至看不到命令失败的消息，它只会保持一个空白屏幕，你可以将其解释为系统根本没有该文件。确保你添加了 `sudo` 命令，以便你能够找到文件是否存在。

现在，会有某些时候你想寻找一个文件，但不确定它叫什么，并且你想要查找你想要的文件的某些变体。假设你想调出以 `.conf` 为后缀的文件；你可以输入以下语法来使其工作。

```bash
$ sudo find -iname *.conf
```

当使用此命令时，你能够查找任何以 `.conf` 部分开头或以 `.conf` 部分结尾的文件夹或文件，所有这些都会显示出来，让你查看所有选项。现在，假设你需要知道文件名对应的后缀，而你已经知道了文件名。对于这些文件，你需要输入以下代码：

```bash
$ sudo find -name php*
```
