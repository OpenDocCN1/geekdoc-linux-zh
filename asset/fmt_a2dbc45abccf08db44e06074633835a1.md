
# operator

`operator` 模块提供了许多函数，用于访问第 3 章“类型与对象”中描述的内置内置运算符和特殊方法。例如，`add(3, 4)` 等同于 `3 + 4`。对于具有原地值的操作，可以使用函数如 `iadd(x,y)`，它等同于 `x += y`。以下展示了 `operator` 模块定义的函数以及它们如何映射到变量上：

| 函数 | 说明 |
|---|---|
| `add(a, b)` | 数字返回 `a + b` |
| `sub(a, b)` | 返回 `a - b` |
| `mul(a, b)` | 数字返回 `a * b` |
| `div(a, b)` | 返回 `a / b`（旧除） |
| `floordiv(a, b)` | 返回 `a // b` |
| `truediv(a, b)` | 返回 `a / b`（新除） |
| `mod(a, b)` | 返回 `a % b` |
| `neg(a)` | 返回 `-a` |
| `pos(a)` | 返回 `+a` |
| `abs(a)` | 返回 `a` 的绝对值 |
| `inv(a)`, `invert(a)` | 返回其倒数 |

| 函数 | 说明 |
| --- | --- |
| `lshift(a, b)` | 返回 `a << b` |
| `rshift(a, b)` | 返回 `a >> b` |
| `and_(a, b)` | 返回 `a & b`（按位与） |
| `or_(a, b)` | 返回 `a | b`（按位或） |
| `xor(a, b)` | 返回 `a ^ b`（按位异异） |
| `not_(a)` | 返回 `not a` |
| `lt(a, b)` | 返回 `a < b` |
| `le(a, b)` | 返回 `a <= b` |
| `eq(a, b)` | 返回 `a == b` |
| `ne(a, b)` | 返回 `a != b` |
| `gt(a, b)` | 返回 `a > b` |
| `ge(a, b)` | 返回 `a >= b` |
| `truth(a)` | 如果 `a` 为真则返回 `True`，否则返回 `False` |
| `concat(a, b)` | 序列返回 `a + b` |
| `repeat(a, b)` | 序列和整数 `b` 返回 `a * b` |
| `contains(a, b)` | 返回 `b` 在 `a` 中的结果 |
| `countOf(a, b)` | 返回 `b` 在 `a` 中出现的次数 |
| `indexOf(a, b)` | 返回 `b` 在 `a` 中第一次出现的索引 |
| `getitem(a, b)` | 返回 `a[b]` |
| `setitem(a, b, c)` | `a[b] = c` |
| `delitem(a, b)` | `del a` |
| `getslice(a, b, c)` | 返回 `a[b:c]` |
| `setslice(a, b, c, v)` | 设置 `a[b:c] = v` |
| `delslice(a, b, c)` | `del a[b:c]` |
| `is_(a, b)` | `a is b` |
| `is_not_(a, b)` | `a is not b` |

初看之下，可能并不看出为什么有人想使用这些函数，因为它们执行的操作可以通过简单输入普通语法来完成。这些函数在处理使用回调函数的代码时，以及你可能使用 `lambda` 定义匿名函数时非常有用。例如，考虑以下使用 `functools.reduce()` 的基准测试：

```python
>>> from functools import reduce

>>> import operator

>>> a = range(100)

>>> reduce(operator.add, a)

4950

>>> reduce(lambda x,y: x+y, a)

4950
```
（注：示例块中的 OCR 文本包含了损坏的数字和语法，已根据 Python `reduce` 的逻辑流在此处进行了修正。）

在这个示例中，注意到使用 `operator.add` 作为回调函数的运行速度比使用 `lambda x,y: x+y` 的版本快了一倍。

`operator` 模块还定义了以下函数，它们是对属性访问、查找和方法调用的封装：

- `attrgetter(name[, name...])`: 创建一个可调用对象 `f`，调用 `f(obj)` 返回 `obj.name`。如果提供了更多参数，则返回结果的元组。
- `itemgetter(item[, item2, ...])`: 创建一个可调用对象 `f`，调用 `f(obj)` 返回 `obj[item]`。如果提供了更多参数，则返回结果的元组。
- `method(name[, args[, kwargs]])`: 创建一个可调用对象 `f`，调用 `f(obj)` 返回 `obj.name(*args, **kwargs)`。如果没有提供参数，则返回该方法。

这些函数对于优化排序等操作的性能也有用。例如，如果你想对一个元组列表进行排序，可以使用 `sorted(rows, key=itemgetter(2))`。第二种版本运行速度更快，因为它避免了 `lambda`。

# 字符串与文本处理

本章描述了与基础字符串和文本处理最常用的 Python 模块。本章的重点是最常见的字符串操作，如正则表达式匹配和文本格式化。

## codecs

`codecs` 模块用于处理不同的编码。它用于处理文本 I/O，如 UTF-8、UTF-16 等。`codecs` 模块用于处理编码数据。

### 低级 codecs 接口

每个编码都有以下方法：

```python
lookup(encoding)
```
查找请求的编码。如果未知，将抛出 `LookupError`。否则，返回一个 `CodeInfo` 实例。`CodeInfo` 实例具有以下方法：

```python
encode(s, errors)
```
编码字符串 `s` 并返回字节字符串。

### StreamReader

返回一个 `StreamReader` 实例，用于读取编码数据。`bytestream` 是以二进制模式打开的文件对象。`errors` 是错误处理策略，默认为 `'strict'`。请查看详细信息：

```python
streamreader(bytestream [, errors])
```
用于方法。

| 方法 | 说明 |
|---|---|
| `r.read([size [, chars [, firstline]]])` | 返回最多 `chars` 个解码后的字符。`size` 是从底层字节流中读取的最大字节数，用于控制缓冲。`firstline` 是一个标志，如果设置，则即使稍后发生解码也会返回第一行。 |
| `r.readline([size [, keepsends])` | 返回单行解码文本。`keepsends` 是控制是否保留行结束符的标志。 |
| `r.readlines([size [, keepsends])` | 将所有行读入列表。 |
| `r.reset()` | 重置内部缓冲区和状态。 |

### StreamWriter

返回一个 `StreamWriter` 实例，用于写入编码数据。`bytestream` 是以二进制模式打开的文件对象。`errors` 是错误处理策略，默认为 `'strict'`。`StreamWriter` 实例支持以下低级 I/O 操作：

```python
decode(bytes, errors)
```

| 方法 | 说明 |
|---|---|
| `w.write(s)` | 写入字符串 `s` 的编码表示 |
| `w.writelines(lines)` | 将字符串列表写入文件 |
| `w.reset()` | 重置内部缓冲区和状态。 |

```python
incrementalencoder([errors])
```
返回一个 `IncrementalEncoder` 实例，可分步编码字符串。`errors` 默认为 `'strict'`。

| 方法 | 说明 |
|---|---|

| `e.encode(s [, [final])` | 返回字符串 `s` 的编码表示，作为字节字符串。`final` 是一个标志，在最后一次调用 `encode()` 时设置为 True。 |

| `e.reset()` | 重置内部缓冲区和状态。 |

## codecs 279

```python
c.incrementaldecoder([errors])
```

```
codecs
```

返回一个 `IncrementalDecoder` 实例，可分多个步骤解码字节字符串。`errors` 默认为 `'strict'`。`IncrementalDecoder` 实例具有以下方法：

| 方法 | 说明 |
| --- | --- |
| `d.decode(bytes [,final])` | 从 `bytes` 中的编码字节返回解码后的字符串。`final` 是一个标志，在最后一次调用 `decode()` 时设置为 `True`。 |
| `d.reset()` | 重置内部缓冲区和状态。 |

### I/O 相关函数

`codecs` 模块提供了一系列高级函数，用于模拟文本的 I/O 编码和解码。大多数程序员将这些函数之一，而不是第一节描述的低级 codecs 接口。
