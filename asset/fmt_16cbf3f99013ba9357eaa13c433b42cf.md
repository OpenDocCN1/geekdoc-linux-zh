### 指令清单54.11 `Month2.java` (月份2)

```java
class Month2
{
    public static String[] months = {
        "January",
        "February",
        "March",
        "April",
        "May",
        "June",
        "July",
        "August",
        "September",
        "October",

        "December"

    public static String get_month(int i) throws IncorrectMonthException
    {
        if (i<0 || i>11)
            throw new IncorrectMonthException(i);

    }

    public static void main(String[] args)
    {
        try {

        }

}
```
