
# 医疗控制系统

医疗控制系统可以分为两组：（1）在正常或病理条件下的生理控制系统（例如，电解质、动脉压、呼吸、体温、血糖、内分泌功能、神经肌肉和运动活动以及感觉功能），以及（2）与生理系统接口的外部（人工）控制系统（例如，用于人工肾或血液透析器，在开胸手术中使用的血液氧合器或心肺机，外部假体和矫形器具，心脏起搏器，呼吸机，可植入式除颤器，以及用于药物输送的可植入泵）。为了开发并让医疗设备正常运行，必须充分理解与外部设备接口的正常及功能障碍生理系统的基础控制机制。因此，在最广义上，医疗控制系统领域涵盖了工程、数学、生物学、心理学、生理学以及医学的所有分支。参见[生物力学](https://example.org/biomechanics)；[生物医学化学工程](https://example.org/biomedical_chemical_engineering)；[生物医学工程](https://example.org/biomedical_engineering)；[控制系统](https://example.org/control_systems)；[数学生物学](https://example.org/mathematical_biology)。

医疗应用中控制系统工程的重要性日益增长，这是因为医疗控制系统固有的复杂性。H. A. Simon 的复杂性概念非常适用于医疗控制系统：复杂系统由子系统组成，而这些子系统又拥有自己的子系统，以此类推；大量部件以复杂的方式相互作用，使得有时无法从部件及其相互作用定律推断出整体的性质。事实上，使用系统工程开发的医疗系统组件的分析模型在预测整体系统行为方面取得了有限的成功。

医疗控制系统的例子包括肌电假肢，它是失去肢体的替代装置；外部矫形器具，用于康复获得性残疾患者；以及可植入设备，如除颤器和用于药物输送的泵。许多其他设备，如心脏起搏器、人工肾、心肺机和人工呼吸机，多年来一直在临床常规使用。（G.C.A.）

## 医学影像

一个利用 X 射线、伽马射线、高频声波和磁场来产生器官和身体其他内部结构图像的医学专科。

在诊断放射学中，目的是检测和诊断疾病，而在介入放射学中，影像程序与其他技术结合以治疗某些疾病和异常。参见[放射学](https://example.org/radiology)。

胶片 X 射线检查是最常见的放射学程序，由身体各种器官和组织的静态图片组成。在这些检查中，X 射线穿过身体以暴露放置在身体另一侧的感光胶片。曝光导致的胶片密度变化使放射科医生能够区分正常和异常组织，并诊断许多不同的疾病类型。参见[X 射线](https://example.org/x-rays)。

荧光透视是一种动态 X 射线成像技术，随时间产生移动图像。对于评估器官运动（如心脏跳动或膈肌运动）至关重要。胃肠道系列检查和钡剂灌肠检查是最常见的荧光透视检查。这些程序始于通过摄入或灌肠方式给予钡剂混合物，以充满胃或大肠。钡剂混合物，一种被称为对比剂的物质，像致密的软组织一样阻挡 X 射线束。荧光透视揭示了涂有钡剂的胃和肠内膜的位置，并使放射科医生能够观察它们收缩和扩张的过程。

血管造影是对血管的放射学研究。由于动脉和静脉在常规 X 射线检查中通常不可见，必须将含碘化合物（对 X 射线不透明）注入血流中。动脉造影图是动脉的 X 射线检查；静脉造影图是静脉的 X 射线检查。动脉造影最常用来显示动脉因动脉粥样硬化而堵塞和狭窄的存在及程度，这可能导致中风和心脏病发作。

计算机断层扫描（CT），也称为计算机轴向断层扫描（CAT），是一种结合了计算机和 X 射线技术的扫描技术。计算机构建一个二维解剖图像，代表身体的横截面切片。使用特殊计算机软件可以生成三维图像。这些在规划重建性骨科或整形手术时特别有用。参见[计算机断层扫描](https://example.org/computed_tomography)。

超声成像，或称超声诊断，是一种使用高频声波而非电离辐射的诊断成像程序。在超声检查期间，一个轻量级换能器放置在患者待成像部位的皮肤上。换能器产生声波，这些声波穿透皮肤到达组织和器官。当声波撞击特定组织表面时，会产生回声。回声被换能器检测到，然后电子转换为显示在视频屏幕上的解剖图像。图像也可以记录在胶片或录像带上。超声成像常用于产科，以监测胎儿的位置和发育，并检测任何胎儿异常或妊娠问题。超声还用于显示其他内部结构的问题，包括胆囊、肾脏和心脏。多普勒超声可以监测静脉和动脉中的血流。它常用于研究肾移植和流向大脑的血流，以及诊断动脉阻塞。参见[医学超声断层扫描](https://example.org/medical_ultrasonic_tomography)。

磁共振成像（MRI）是一种利用大型高强度磁铁、射频信号和计算机产生图像的诊断为程序。MRI 技术在评估脑部和脊柱疾病方面极其有用。它也用于评估关节、骨骼和软组织异常，以及胸部、腹部和盆腔异常。参见[核磁共振（NMR）](https://example.org/nuclear_magnetic_resonance)。

核医学影像研究使用放射性化合物，称为放射性碘化物或放射性药物，它们发射伽马射线，有些发射 beta 粒子。这些化学制剂被配制为暂时聚集在需要研究的身体部位。对于大多数核医学影像研究，放射性核素注射入患者体内，图像由悬挂在平躺在检查台上的患者上方的伽马相机拍摄。相机检测患者体内放射性核素发射的伽马射线，并使用这些信息产生显示放射性核素在体内分布的图像。图像记录在胶片上，称为闪烁图或扫描图。心脏和骨骼的闪烁图是最常见的两种核医学检查。

单光子发射计算机断层扫描（SPECT）检查使用计算机获取二维图像，这些图像是心脏、大脑等内部器官的薄片切面，以及肝脏。SPECT 影像能够比传统 X 光片显示更多细节的器官组织。

正电子发射断层成像（PET）是一种更为精密的放射学技术，用于研究器官内部的代谢活动。该技术已被证明在研究脑部相关疾病（如癫痫和阿尔茨海默病）以及心脏组织活力方面具有实用性。

介入放射学将影像程序与各种注射和导管技术相结合，用于治疗肿瘤、阻塞、出血性血管以及体腔内的其他异常。其中较为常见的介入手术是血管成形术，用于治疗阻塞或狭窄的动脉。

参见 RADIOGRAPHY。[M.L.G.; R.D.E]⁴

## 对人类致病真菌（霉菌和酵母菌）的研究

根据感染部位在身体上的位置，或者是否需要机会性条件才能致病，将真菌感染进行分类。由于导致宿主防御机制受损（尤其是细胞介导的免疫力）的条件增多，在机会性条件下发生的真菌感染变得更加常见。此类条件包括获得性免疫缺陷综合征（AIDS）、癌症以及用于防止移植排斥或控制炎症综合征的免疫抑制疗法。此外，随着现代医学的进步，严重体弱的个体寿命延长，机会性真菌感染变得更加重要，而院内（医院获得性）真菌感染也成为一个日益严重的问题。早期诊断并治疗真菌感染以及控制诱因至关重要。参见 OPPORTUNISTIC INFECTIONS。

抗真菌药物治疗极具挑战性，因为真菌与其人类宿主都是真核生物，这导致了药物毒性或与宿主分子发生交叉反应的问题。大多数抗真菌药物靶向真菌的细胞膜或细胞壁。治疗大多数严重真菌感染的“黄金标准”是两性霉素 B，它结合了大多数真菌和其他某些生物（但不在哺乳动物中）中的膜脂——麦角固醇。不幸的是，两性霉素 B 与哺乳动物细胞膜中胆固醇的轻微交叉结合可能导致严重的毒性，尤其是在药物浓缩的肾脏中。

近年来抗真菌治疗的进展包括使用脂质体两性霉素 B 以及更新的唑类药物，如氟康唑和伏立康唑，这些药物显示出较少的毒性副作用。相反，致病真菌的药物耐药性正如细菌一样成为一个日益严重的问题。

念珠菌病是最常见的机会性真菌感染，它也成为住院患者的主要院内感染之一。*白色念珠菌（Candida albicans）* 是一种双相真菌，其酵母形态是黏膜表面正常菌群的一部分。在机会性环境下，该真菌可能会增殖并转化为菌丝形态，侵入组织、血液和其他器官。在患有严重潜在疾病或免疫功能低下的患者中，疾病可能会从各种感染部位蔓延至血液或其他器官。其他重要的机会性真菌疾病包括曲霉菌病、毛霉菌病和隐球菌病。

健康人通过吸入某些致病真菌的孢子形式可能会患病。所谓的深部或系统性真菌病均由不同的土壤霉菌物种引起；大多数感染未被察觉且无症状或症状轻微。然而，在某些个体中，感染可能会从肺部蔓延至全身，使用两性霉素 B 或抗真菌唑类药物进行治疗至关重要。

当特定种类的土壤霉菌被深部接种到皮下组织时（例如被深刺或受其他创伤），也会发生其他真菌感染。随着每种真菌在组织中生长，会形成特定类型的病灶。适当的伤口卫生可以预防这些感染。

癣，也称为皮肤癣菌病或 tinea（癣病），是所有的真菌感染中最常见的一种。某些种类的致病霉菌可以在皮肤最外层的死亡角质层中生长。疾病是由宿主对感染霉菌代谢产物以及实际真菌入侵产生的超敏反应所致。体癣（tinea corporis），即身体部位的癣，表现为光滑皮肤上的病灶，具有含有水疱的红色圆形边缘。随着边缘的推进，病灶中心会显示清澈。在厚实的皮肤上，如脚部的趾间，这些红色的愈合病灶（已知为脚气或足癣 tinea pedis）如果继发细菌感染，情况会变得更加严重。癣菌还可能侵入发干（头癣 tinea capitis）或指甲（甲癣 onychomycosis）。有许多药物可用于治疗或抑制此类感染，但控制向他人的传播至关重要。参见 FUNGAL INFECTIONS；FUNGI；YEAST。[C.H.T.; J.PW]⁵
