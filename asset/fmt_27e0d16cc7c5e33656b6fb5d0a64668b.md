
```python
class Stack(Stackable):
    def __init__(self):
        self.items = []
    def push(self,item):
        self.items.append(item)
    def pop(self):
        return self.items.pop()
```

当你尝试创建一个 `Stack` 时，会得到如下错误信息：

```
>>> s = Stack()
Traceback (most recent call last):
File "<stdin>", line 1, in <module>
TypeError: Can't instantiate abstract class Stack with abstract methods
>>>
```

这可以通过向 `Stack` 添加 `size()` 属性来修复。你可以通过修改 `Stack` 的定义来实现，也可以通过继承它并添加所需的方法或属性来实现：

```python
class CompleteStack(Stack):
    @property
    def size(self):
        return len(self.items)
```

这是一个完整堆栈对象的示例：

```python
>>> s = CompleteStack()
>>> s.push("foo")
>>> s.size
1
>>>
```

## bisect

`bisect` 模块提供了对保持列表排序的支持。它使用二分查找算法来完成大部分工作。

```
bisect(list, item, low [, [high])
```

返回 `item` 插入 `list` 的位置点索引，以保持列表的升序状态。`low` 和 `high` 是指定要检查列表子集的索引。如果 `item` 已经在列表中，插入点将始终位于列表中现有条目的右侧。

```
bisect_left(list, item, low [, [high])
```

返回 `item` 插入 `list` 的位置点索引，以保持列表的升序状态。`low` 和 `high` 是指定要检查列表子集的索引。如果 `item` 已经在列表中，插入点将始终位于列表中现有条目的左侧。

```
bisect_right(list, item, low [, [high])
```

与 `bisect()` 相同。

```
insert(list, item, low [, [high])
```

按排序将 `item` 插入列表。如果 `item` 已经在列表中，新条目将插入到任何现有条目的右侧。

```
insert_left(list, item, low [, [high])
```

按排序将 `item` 插入列表。如果 `item` 已经在列表中，新条目将插入到任何现有条目的左侧。

```
insert_right(list, item, low [, [high])
```

与 `insert()` 相同。

## deque and defaultdict

`collections` 模块定义了两个新容器：`deque` 和 `defaultdict`。

```
deque(iterable [, maxlen])
```

代表双端队列（deque，发音为 "deck"）对象的类型。`iterable` 是一个用于填充 `deque` 的可迭代对象。`deque` 允许从 `deque` 的两端插入或删除项。该实现已过优化，使得这些操作的性能大致相同（O(1)）。这与列表略有不同，列表在头部的操作可能需要移动后续的所有元素。如果提供了可选的 `maxlen` 参数，生成的 `deque` 对象将成为该大小的循环缓冲区。也就是说，如果添加项但没有更多空间，将从对端删除项以腾出空间。

`deque` 的实例 `d` 有以下方法：

```
d.append(x)
```

在 `d` 的右侧添加 `x`。

```
d.appendleft(x)
```

在 `d` 的左侧添加 `x`。

```
d.clear()
```

移除 `d` 中的所有项。

```
d.extend(iterable)
```

通过在右侧添加 `iterable` 中的所有项来扩展 `d`。

```
d.extendleft(iterable)
```

通过在左侧添加 `iterable` 中的所有项来扩展 `d`。由于发生了左侧追加序列，`iterable` 中的项在 `d` 中将反序出现。

```
d.pop()
```

返回并移除 `d` 的右侧的一个项。如果 `d` 为空，则抛出 `IndexError`。

```
d.popleft()
```

返回并移除 `d` 的左侧的一个项。如果 `d` 为空，则抛出 `IndexError`。

```
d.remove(item)
```

移除 `item` 的首次出现。如果没有找到匹配项，则抛出 `ValueError`。

```
d.rotate(n)
```

将所有项向右旋转 `n` 步。如果 `n` 为负数，项将向左旋转。许多 Python 程序员经常忽略 `deque`。然而，这种类型具有许多优势。首先，其实现非常高效——甚至达到了使用提供良好处理器缓存行为的内部数据结构的程度。在末尾添加项仅比内置 `list` 类型略慢，而在头部插入则要快得多。向 `deque` 添加新项的操作也是线程安全的，这使得该类型适用于实现 `deque`。`deque` 还可以使用 `pickle` 模块进行序列化。

```
defaultdict(default_factory, ...)
```

一种与字典完全相同的类型，但在处理缺失键方面不同。当对不存在的键进行查找时，会调用作为 `default_factory` 提供的函数来提供默认值，该值随后被保存为关联键的值。`defaultdict` 的其余参数与内置 `dict()` 完全相同。`defaultdict` 实例具有与字典相同的操作。`default_factory` 属性包含作为参数传递的函数，可以根据需要进行修改。

如果你尝试使用字典作为跟踪数据的容器，那么 `defaultdict` 对象非常有用。例如，假设你想跟踪每个单词的位置。
