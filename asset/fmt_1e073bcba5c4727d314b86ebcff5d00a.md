## `ucspi-proxy`
UCSPI 工具的连接代理。此包包含一个代理程序，可以在由 UC 服务器和 UCSPI 客户端建立的两个连接之间传输数据。有关 UCSPI 的更多信息，请参阅 `http://er.yt.po/proto/ucspi.txt`。有关最新信息请参阅 `http://em.ca/~bruge/ucspi-proxy/`。来自 Debian 3.0r0 APT

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## `ucspi-unix`
UNIX 域客户端-服务器命令行工具。`unixserver` 是用于构建 UNIX 域客户端-服务器的命令行工具；`unixclient` 连接到 UNIX 域套接字并运行你选择的程序；`unixserver` 创建一个 UNIX 域套接字，等待传入的连接，并为每个连接运行你选择的程序。`unix server` 符合 UCSPI 标准（即使用 UNIX 域套接字的 UCSPI 客户端-服务器接口）。UCSPI 工具适用于多种不同的网络。有关 UCSPI 的更多信息，请参阅 `http://cr.yt.po/proto/ucspi-unix/`。来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## `udftools`
用于 UDF 文件系统和 DVD/CD-R(W) 驱动器的工具。此包包含许多与创建 UDF（通用光盘格式）文件系统相关的用户空间工具，UDF 主要用于视频，但也可用作 CD-ROM：

- `mkuddfs` – 格式化设备，创建一个空的 UDF 文件系统
- `cdrow` – 低级设备管理（例如设置写入速度、格式）
- `pockets` – 为驱动器设置数据包写入设备 (`/dev/pktcdv`)；你需要 Linux 2.4 或更高版本来挂载 UDF 文件系统。随这些工具一起的内核补丁目前尚未为 Debian 封装，但正在合并到 2.4 内核树中。来自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html.index.html`

## `UDP`
虽然 TCP 会自动重传数据，但 UDP 并不关心。这对于音频/视频实际上是一个优势，但在传输文件时是一个致命的缺点。

UDP 格式：

| 源端口 | 目的端口 | 长度 | 校验和 |
| :--- | :--- | :--- | :--- |
| | | | |

UDP 并没有什么特别令人兴奋的。源端口识别发送机器上的应用程序。目的端口识别数据由接收者。长度表示数据包中有多少数据；校验和用于验证数据在传输过程中没有被意外篡改（尽管它无法防止蓄意的篡改）。来自 Hacking-Linux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
