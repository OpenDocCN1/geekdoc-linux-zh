
# 下面显示了 vfs 接口以及来自 `sys/vfs.h` 的相关结构

- 每个挂载的文件系统结构包含一个操作数组和一个实例记录。
- 文件系统存储在一个单向链表中，以 `rootvfs` 为头，以 `NULL` 结尾。文件系统的实现程序不应访问此列表；该列表仅在内核的 vfs 层使用。

```c
typedef struct vfs {
    struct vfs             *vfs_next;
    struct vfs_op          *vfs_op;
    struct vnode          *vfs_nodecovered;
    uint_t               vfs_flags;
    uint_t               vfs_fstype;
    int                  vfs_file_type_index;
    int                  vfs_system_id;
    cadd_t               vfs_data;
    dev_t                vfs_dev;
    ulong_t              vfs_count;
    short_t              vfs_mounts;
    struct vfs           *vfs_list;
    struct vfs           *vfs_hash;
    ksema_t              vfs_reflock;
} vfs_t;
```
