
`strace` 命令对不同参数类型有不同的输出模式，例如，对于 C 风格字符串，我们将根据其参数获得不同的输出。这有助于我们使用 `strace` 实用工具动态地监控数据。

默认最大输出长度为 32 字节，过长的 `strace` 将用 "..." 省略。

例如，`ls -l` 命令将读取 `/etc/passwd` 文件：

```
root@server : $ strace -read(4, "root: x: 0: root:root:/bin/bash \n" ..., 4096) = 2342.
```

需要注意的是，文件名不被 `strace` 视为 C 风格字符串。对于结构体，`strace` 将用 "{}" 输出结构体的每个字段，并用 "," 分隔每个字段。对于字段较多的结构，`strace` 将用 "..." 省略部分输出。

例如：

```
root@server : $ strace /dev/null lstat64 ("/dev/null",{mode = S_IFCHR|0666, rdev = makedev(1,3),...) = 0
```

上面的 `strace` 输出显示 `trace` 的第一个参数是 `stat` 结构类型的输出参数（指针）。`strace` 只显示了结构参数的两个字段：`mode` 和 `rdev`。应该指出，当系统调用失败时，输出参数将显示为传入之前的值。

对于位参数（例如信号类型 `sigset`），`strace` 将把集合中所有置为 1 的位输出在 "[ ]" 中，并用空格分隔每个项目。

假设程序中有以下代码：

```c
sigaddset(&set,SIGUSR1);sigprocmask(SIGBLOCK, &set,NULL);
```

那么针对该程序的 `strace` 命令将输出以下内容：

```
rt sigprocmask (SIGBLOCK, [SIGUSR1], NULL, 8) = 0.
```

关于其他参数类型的输出模式，请参考 `strace` 的手动页，我们在此不再重复。

对于程序接收到的信号，`strace` 将输出信号的值及其描述。例如，我们在一个终端上运行 "`sleep 100`" 命令，然后在另一个终端使用 `strace` 命令跟踪该进程，然后使用 "`Ctrl+C`" 终止 "`sleep 100`" 进程以观察 `strace` 的输出。

具体操作如下：

```
root@server : $ sleep 100 $ ps -EF | grep sleep
```

操作如下：

```
root@server : $ ./websrv 127.0.0.1 13579 $ ps -EF | grep websrv
```

接下来，使用该方法发起对服务器的连接并发送 HTTP 请求。因此，此事件表示客户端连接正在到来，所以 `websrv` 服务器对监听的 `socket` 执行了 `accept` 调用，`accept` 返回一个新的值为 5 的连接 `socket`。

然后，服务器清除新 `socket` 上的错误，设置其 `REUSEADDR` 属性，然后在 `epoll` 事件表中的 `socket` 上注册注册 `EPOLLRDHUP` 和 `EPOLET` 事件，最后将新 `socket` 设置为非阻塞。

`wait` 调用检测到文件描述符上的事件，这表明工作线程正确处理了客户端请求并准备好了发送的数据，因此主线程开始执行 `write` 系统调用并响应客户端。

最后，服务器从 `epoll` 事件表中移除文件描述符 5 的所有注册事件并关闭文件描述符。因此，`trace` 命令使我们能够清晰地看到每个系统调用的时机和相关参数的值，这比使用 `gdb` 调试要方便。

到此，我们已经对 `strace` 命令 `string` 了简短而复杂的介绍。我们建议你仔细阅读。虽然理解网络包在 `strace` 中重要性的方法有多种，但我们还应该使用如 `netstat` 等其他工具来进一步提升我们作为黑客对网络监控工具的影响力。

## NETSTAT

`Netstat` 是一个强大的网络信息统计工具。它可以打印本地网卡接口上的所有连接、路由表信息和网卡接口信息。对于本书，我们主要使用上述功能中的第一种，即显示 TCP 连接及其状态信息。

毕竟，对于路由表信息和网卡（NIC）接口信息，我们可以使用 `route` 和 `ifconfig` 命令获取更丰富的输出内容。

接下来，我们运行 `websrv` 服务器并执行 `telnet` 命令向其发起连接请求。

```bash
root@server : $./websrv 127.0.0.1 13579 & $ telnet 127.0.0.1 13579
```

然后执行命令来检查连接状态。

```bash
netstat -nat | grep 127.0.0.1:13579
```

结果如下：

```
proto recv-q send-q local address foreign address state
TCP 0 0 127.0.0.1:13579 0.0.0.0:
```

在上述输出中，第1行表示本地 `socket` 地址 `127.0.0.1:13579` 处于 `LISTEN` 监听状态，等待任何远程 `socket`（由 `0.0.0.0:` 表示）向其发起连接。第2行表示服务器与远程地址 `127.0.0.1:48220` 建立了连接。

第三行仅从客户端的角度反复输出由第二行信息所指示的连接，因为我们正在同一台机器上运行服务器程序 (`websrv`) 和客户端程序 (`telnet`)。在服务器端程序的开发过程中，我们必须确保每个连接在任何时刻都处于我们期望的状态。因此，我们应该学会使用 `netstat` 命令。

我们可以使用 `netstat` 命令显示关于不同网络服务器、其流量包和其他重要的大量信息。在下一节中，我们将讨论另一种名为 `vmstat` 的基础网络工具。请继续！

## VMSTAT

`Vmstat` 是 `virtual memory statistics`（虚拟内存统计）的缩写，它可以实时输出系统各种资源的使用情况，例如进程信息、内存使用、CPU 使用率和 I/O 使用率。

默认情况下，`vmstat` 的输出非常丰富。

看示例：

```bash
root@server : $vmstat 5 3
#### 每5秒输出一次结果。
```

注意，第一行的输出是自系统启动以来的平均结果，而下一行的输出是采样间隔内的平均结果。

如果这两个值变化频繁，说明内存不足。`io` 是块设备的使用信息，单位是 `block/s`；`bi` 表示从块设备读取块的速率；`bo` 表示向块设备写入块的速率；`in` 表示每秒中断数，`cs` 表示每秒上下文切换（进程切换）的次数次。

然而，我们可以使用 `iostat` 命令获取更多关于磁盘使用情况的信息，也可以使用 `mpstat` 获取更多关于 CPU 使用率的信息。`vmstat` 命令主要用于检查系统内存的使用情况。

许多黑客利用此工具了解内存资源，并临时停止那些消耗高内存的程序。在执行暴力破解等任务时，我们需要理解这些可以减轻系统负载的工具的重要性。在下一节中，我们将详细介绍 `ifstat` 网络工具。请继续！

## IFSTAT

`Ifstat` 是 `interface statistics`（接口统计）的缩写，是一个简单的流量监控工具。

例如，我们在测试机上执行以下命令：

```bash
root@server : $ifstat-a 2 5
#### 每2秒输出一次结果。
```

`ifstat` 的输出显示了每个 NIC 接口接收和发送数据的速率（单位为 KB/s）。因此，使用 `ifstat` 命令可以粗略估计服务器在每个阶段的总入出流量。

在本章的后续节，我们将讨论 `mpstat`，这是一种黑客分析不同处理器统计数据的常用网络工具。请继续！

## MPSTAT

`Mpstat` 是 `multi-processor statistics`（多处理器统计）的缩写，它可以实时监控多处理器系统中每个 CPU 的使用情况。`mpstat` 命令和 `iostat` 命令通常集成在 `sysstat` 软件包中，可以通过安装 `sysstat` 获取。

`mpstat` 命令的典型用法如下（`mpstat` 的选项并不多，此处不做专门介绍）：

```bash
mpstat [-p { all }] [interval [count]]
```

选项 `p` 指定要监控的 CPU 编号（0 ~ CPU 数量 -1），其值 "all" 表示监控所有 CPU。

`interval` 参数是采样间隔（单位为秒），即每隔一个间隔输出一次统计信息。`count` 参数是采样次数，即 `mpstat` 总共输出 `count` 次统计信息，并最终输出这 `count` 次采样结果的平均值。

与 `vmstat` 命令类似，`mpstat` 命令的第一个输出结果是自系统启动以来的平均结果，而接下来的（第 `count` 次）输出结果是采样间隔内的平均结果。

例如，我们在测试机上执行以下命令：

```bash
root@server : $mpstat -P ALL 5 2
#### 每5秒输出一次结果。
```

每次采样的输出包含三部分信息，每部分包含以下字段：CPU，“0”表示第一个 CPU 的数据，“1”表示第二个 CPU 的数据，“all”表示两个 CPU 的平均值。

`%usr` 表示除了具有 `nice` 值的进程外，系统其他进程在用户空间运行的时间占比例。

`%nice` 表示具有负 `nice` 值的进程在用户空间运行的时间占比例。

`%sys` 表示系统所有进程在内核空间运行的时间占比例，但不包括由硬件和软件中断消耗的 CPU 时间。

`%iowait` 表示 CPU 等待磁盘操作的时间占比例。`%ir` 表示处理硬件中断的 CPU 时间占比例。

`%soft` 表示处理软件中断的 CPU 时间占总 CPU 时间的比例。

`%steal` 表示一个物理 CPU 可能包含一对虚拟机 CPU，它们由虚拟机管理器管理。当虚拟机管理器处理一个虚拟机 CPU 时，另一个虚拟机 CPU 必须等待其处理完成后才能运行。这种等待时间被称为窃时。该字段表示窃时占总 CPU 时间的比例。

`%guest` 表示运行虚拟机 CPU 的时间占总 CPU 时间的比例。

`%idle` 表示系统空闲时间占总 CPU 时间的比例。在所有输出字段中，我们最关注 `%user`、`%sys` 和 `%idle`。

它们基本上反映了代码中业务逻辑代码和系统调用的比例，以及系统能够承受的负载。显然，在上面的输出中，执行系统调用消耗的 CPU 时间比执行用户业务逻辑更多。这是因为我们运行了此机器上介绍的压力测试工具，它不断执行 `recv/send` 系统调用来收发数据。

## 阶段 1 - 侦察工具

如前所述，在破解和攻击系统之前，你首先需要获取关于目标的大量信息。例如，了解目标使用的服务器架构可以帮助你发现该特定服务器架构的漏洞。

但是，你到底是如何获取目标信息的呢？

为了解释这一点，我们首先需要解释黑客的工作原理。黑客不仅是聪明的极客，还是出色的交际者，他们试图从使用目标的用户的普通对话中获取信息。

如果一个黑客想要攻击银行服务器，他会说服几名银行员工并试图收集有关服务器的信息。虽然这看起来很有风险，但只需安装监控软件就能帮助他们获得所需的所有资源和信息。

出于这个原因，我们将这一黑客分支分为两类：一种是社交工程攻击，另一类是挖掘价值信息。

### A) 社交工程攻击

这些是黑客针对目标用户、员工和系统管理员的攻击。一种著名的攻击手段是创建一个钓鱼页面，让目标输入其用户名和密码。在获取凭据后，他们利用这些权限访问 `root` 级别。

这类攻击有许多工具可用。有不同的命令行程序可以创建社交网络网站的虚假钓鱼页面。

### B) 挖掘价值信息

关于目标的大量信息通常可以在开放世界中找到。几次智能 Google 搜索就能为你提供大量关于目标的信息。通过电子邮件联系系统管理员也是获取某些敏感信息的好方法。

然而，黑客在这一黑客步骤中使用的最重要的工具是 `nmap`。`nmap` 是一个开源工具，用于扫描可用的开放端口并输出与目标相关的大量信息。

如果操作得当，你可以通过不同的自动化命令找到服务器架构和目标使用的操作系统。然而，请记住，网络安全研究人员多年积累了大量经验，并开发了多样的入侵检测系统，以应对来自试图扫描开放端口的新手的请求。

如果你是一个经验丰富的黑客，你唯一做的就是不要引起系统管理员的注意，以免你的 IP 地址或 MAC 地址被永久封禁。

这里有一些命令：

```
root@sample : nmap
// 这显示菜单
root@ sample : nmap www.google.com
// 这扫描此地址的开放端口
root@sample : nmap -V 192.32.222.12
// 这对输入地址发送开放端口检测请求
```

`Nmap` 在了解其他高级内容（如 `ping` 时间和防火墙的存在）方面也非常高效。如果存在防火墙，你可以找到开放的漏洞并利用它们。

在扫描并发现潜在漏洞后，你可以进入黑客攻击的下一个阶段。即利用（Exploitation）。

## 2) 利用工具

如果你不知道如何攻击和利用系统，攻击系统还有什么乐趣呢？

在发现漏洞后，黑客通常会插入木马或蠕虫来为他们完成肮脏工作。现在许多黑客在不同系统中实施比特币货币挖矿来赚快钱。但他们是如何做到的呢？

经验丰富的黑客会编写自己的利用软件，而中级黑客则使用 `Metasploit` 等 Kali Linux 工具。

### 什么是 Metasploit？

`Metasploit` 是最流行的利用工具，可以用于跟踪用户或将木马绑定到图像或 PDF 文件中。当目标点击被 `metas-loot` 修改的文件时，我们就可以跟踪并利用他们。

这里有一些命令：

```
root@server : metasploit
// 这将启动 msf 控制台
root@server : metasf bind.jpg
// 使用图片文件绑定木马
```

`Metasploit` 还可以用于生成安卓文件进行利用。你还可以使用 `metasploit` 破解服务器。然而，请记住，在没有硬件访问的情况下你无法破解安卓设备。

## 阶段 3 - 监控工具

在之前的阶段中，我们使用了 Kali Linux 工具进行扫描和利用。在本节中，我们将学习如 `Wireshark` 等监控工具，以理解可能发生的黑客攻击。

### 什么是监控？

网络数据以包的形式传输。数据包如果没有加密，就可以被伪造，并被黑客用于窃取信息。`Wireshark` 是一种用于分析异常流量的工具。它提供一个显示每个数据包的面板。

像 `Wireshark` 这样的工具可以帮助黑客通过伪造数据包进行监控。`Wireshark` 是最受欢迎的包分析软件之一。它提供一个显示每个数据包头部信息的面板。

- 以下是使用 `Wireshark` 的一些技巧：

1) 始终确保你了解尝试监控的目标主机地址。

2) 使用 `net stat` 和 `ping` 等工具分析网络流量，并有效地捕捉数据包。

3) 理解加密和非加密网络包的区别。如果你强制解密加密包，请确保你理解 `HTTP` 协议等复杂内容。

`Wireshark` 为网络管理员提供付费功能。在专业版中你可以使用捕获的信息自动报告，而在社区版中你需要手动制作。

### 字典攻击工具

黑客需要处理许多复杂的问题，他们最感兴趣的是窃取密码和电子邮件地址等敏感信息。获取大量密码和账户唯一方法是使用字典攻击，技术上称为暴力破解。

Kali Linux 提供了 `Hydra` 和 `Jack the Ripper` 等工具来破解网站和数据库。一些破解者还利用 SQL 注入破解数据库以获取敏感信息。

#### A) Hydra

`Hydra` 是 Kali Linux 中的字典攻击工具。使用 `Hydra`，你只需要提供 URL 页面和一个由冒号分隔用户名和密码的文本文件。

所有成功的登录都将打印在日志文件中，并用于登录网站。

这里有一些命令：

```
root@server : hydra www.google.com/login user.txt
// 这将使用文本中的信息攻击登录页面
```

#### B) Jack the Ripper

`Jack the Ripper` 是同类型的工具，可用于破解登录页面。虽然 `Hydra` 只能暴力破解静态登录页面，但此工具可以帮助你动态破解登录页面。

也就是说，你可以根据正在的结果自定义暴力破解。例如，如果登录页面出现“未找到服务器”错误，`Jack the Ripper` 将自动更换代理服务器，以缓解入侵检测系统执行的代理封禁。

这是一条命令：

```
root@server : jtr -w pass.txt www.sampleurl.com -p proxy.txt
```

这里的 `w` 代表携带用户名和密码的字典列表，而 `proxy.txt` 包含不同代理服务器的信息，如果它们是存活的，会被引擎随机使用。

我们将最后讨论的一组工具是关于无线工具的。我们都知道，世界正在发生快速变化，网络以太网现在不再是网络中传输信息的唯一方式。无线网络包括 `wifi` 热点、手机手机、笔记本电脑甚至智能手表。

这里涉及到大量的隐私问题，即使网络协议中一个微小的漏洞也可能被窃取大量敏感信息。这就是为什么你需要定期更新系统的原因。

以下是一些重要的工具：

#### A) aircrack-ng

这是一个著名的网络工具，可用于暴力破解所有可用的 `Wpa/wp2` 网络。它还可以自动发现 `WPS` 网络中的漏洞。你们只需要使用 `net stat` 命令找到无线网络的地址，并将其插入到工具中进行自动破解即可。

以下是相关命令：

```
root@server : aircrack-ng 192.23.11.234 text.txt
```

#### B) Airdump
