# 2.1 我应该为 Linux 购买什么样的网卡？

这个问题的答案很大取决于你打算用网络连接具体做什么，以及它将承担多大的流量。

如果你只预期单个用户偶尔进行 ftp 会话或 WWW 连接，那么即使是一块旧的 8 位网卡可能也能让你满意。

如果你打算建立服务器，并且要求将网络数据传输的 CPU 开销降至最低，你可能想看一个使用具有总线主控能力（bus-mastering）芯片的 PCI 卡，例如 DEC tpl（21xxxx）芯片或 AMD PCnet-PCI 芯片。

如果你处于上述两者之间，那么任何带有稳定驱动的低 PCI 或 16 位 ISA 网卡都能胜任工作。
