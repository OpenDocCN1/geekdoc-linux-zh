# wminet

为 Window Maker 设计的 inet 监控 dock 应用。WMiNET 有一些很棒且有趣的监控功能；

- 监控进程数、用户、http、nfs 挂载
- LPD 监控
- 监控指定的指定的 tcp 端口
- 可选 LED 或 LCD GUI
- 启用/禁用

## wml

## wmload

用于 Window WM 的系统负载监控器。`wmload` 在 64x64 的窗口中显示内核/系统统计的图形化表示。其中有三个影子：较浅的对应用户统计、nice 时间统计，最深的是系统统计。对于其他窗口管理器，该程序中没有任何内容要求它必须使用窗口管理器，除非是为了外观考虑。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## wmmail

## wmmon

监控 CPU 负载和平均负载。WMMon 将 CPU 负载作为平均系统负载，如果你添加一些额外功能……WMMon 目前提供：

- 实时 CPU“压力”计
- 平均负载，类似于 `xload` & `vmagload`
- 自动缩放的平均系统图
- 实时内存磁盘 I/o 交换计
- 实时磁盘 I/o 图（自动缩放）
- 实时内存与交换使用系统显示
- 通过 `~wmmonrc` 实时循环所有管理器命令

可以启动多次。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
