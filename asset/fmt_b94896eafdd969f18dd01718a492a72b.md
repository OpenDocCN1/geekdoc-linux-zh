
# Pine 全局默认文件

根据需要进行自定义。此文件设置了 Pine 使用的系统级配置默认。如果你对特定设置有疑问，请查看 Pine 笔记中关于配置选项的章节。运行 `pine -conf` 查看设置了哪些系统默认值。对于接受多个值的变量，列表元素之间用逗号分隔。以空格或制表符开头的行被视为上一行的延续。若要取消设置某个变量，其值必须留空。若要将变量设置为空字符串，其值应为 `""`。切换变量被设置为 `"yes"` 或 `"no"`，默认为 `"no"`。以 `#` 开头的行是注释，会被 Pine 忽略。

## 文件夹与路径设置

（本地或远程）收件箱的路径，例如 `={mail@somewhere.edu}inbox`。Unix 默认值是本地收件箱（通常位于 `usr/spool/mail/$USER`）。

`inbox-path=`

除了 INBOX 之外的输入文件夹列表，例如 `={host2}inbox, {host3}inbox`。语法：`optnl-label (optnl-imap-host-namefolder-path)`。

`incoming-folders=`

保存消息文件夹可能所在的目录列表。第一个是保存（Saves）的默认值。示例：`Main[host1]/. Desktop mail[]`。语法：`optnl-label (optnl-imap-hostname)nntp-directory-path[]`。

`folder-collections=`

列表，仅当未设置 nntp 服务器或新闻位于不同的 NNTP 发布主机时才需要。示例：`News [* 或 News {host3/nntp]`。语法：`optnl-label *news-host/protocol[]`。

`news-collections=`

文件夹对列表；第一个表示要归档的文件夹，第二个表示读取第一个文件夹后应移动到的文件夹。

`incoming-archive-folders=`

上下文和文件夹对列表，用空格分隔，为每个月提供。例如：`{host1}/`。

`pruned-folders=`

覆盖发送邮件（sent-mail）文件夹的默认路径，例如 `=old-mail`（使用第一个目录或 `={host2}sent-mail=""` 来取消）。默认值：Unix 中的 `sent-mail` 或 PC 中的 `SENTMAIL`。

`default-cc=`

覆盖保存消息（saved-msg）文件夹的默认路径，例如 `=saved-messages`（使用第一个目录或 `={host2}saved-mail=""` 来取消）。默认值：Unix 中的 `saved-messages` 或 PC 中的 `SAVEMAIL`。

`default-saved-msg=`

覆盖标记（postmarked）文件夹的默认路径，例如 `=pm`（使用第一个目录或 `={host4}pm` 在 host4）。默认值：Unix 中的 `postponed` 或 PC 中的 `POSTOND`。

`postponed-folder=`

如果设置，已读消息将在退出时移动。

`read-message-folder=`

如果设置，字母应存储在这里。

`form-folder=`

覆盖签名文件的默认路径。默认是 `~/.signature`。

`signature-file=`

## 保存与排序规则

保存（Saves）的默认文件夹... 选项：`default-folder, by-sender, from, by-recipient, last-folder-used`。默认值：`"default-folder"`，即 Unix 中的 `saved-messages` 或 PC 中的 `SAVEMAIL`。

`saved-msg-name-rule=`

确定密抄（Fcc）的默认文件夹名... 选项：`default-fcc, by-recipient, last-fcc-used`。默认值：`"default-fcc"`另变量 `"default-fcc="`。

`fcc-name-rule=`

设置索引中消息的显示顺序。选项：`subject, from, arrival, date, size`。默认值：`"arrival"`。

`sort-key=`

设置地址簿条目的显示顺序。选项：`dont-sort, fullname-with-lists-last, fullname, nickname-with-lists-last, nickname`。默认值：`"fullname-with-lists-last"`。

`addrbook-sort-rule=`

设置文件夹列表条目的显示顺序。选项：，默认值：`"alpha-with-directories-last"`。

`folder-sort-rule=`

设置跳转（Goto）命令提示符提供的默认文件夹和集。

`goto-default-rule=`

设置光标开始的消息。选项：`first-unseen, first-recent, first, last`。默认值：`"first-unseen"`。

`incoming-startup-rule=`

## 网络与超时设置

此项指定了用户在读取和写入文件夹和文件时被限制的树根目录。例如，在 Unix 上，`~/work` 将用户限制在以其工作子目录开始的子树中。（注意：仅靠此项不足以防止访问。你还需要限制 shell 访问等，请参阅 Pine 技术备注）。默认值：未设置（无限制）。

`operating-dir-`

`news-active-file=`

`news-spool-directory=`

用于从你的终端模拟器上传文本到 Pine 编辑器的程序。

`upload-command=`

在调用由 `upload-command` 变量定义的程序之前发送到终端模拟器的文本。注意：`FILE_` 将替换为上传时使用的临时文件。

`upload-command-prefix=`

用于通过你的终端模拟器从 Pine 的导出和保存命令下载文本的程序路径和文件名。

`download-command=`

在调用由 `download-command` 变量定义的程序之前发送到终端模拟器的文本。注意：`FILE_` 将替换为下载时使用的临时文件。

`download-command-prefix=`

设置 mailcap 配置文件的路径。注意：在 UNIX 下使用冒号分隔，在 DOS/Windows/OS2 下使用分号分隔。

`mailcap-search-path=`

设置 mimetypes 配置文件的路径。注意：在 UNIX 下使用冒号分隔，在 DOS/Windows/OS2 下使用分号分隔。

`mimetype-search-path=`

如果若干小时内没有用户输入，Pine 将在等待新命令的空循环中退出。如果设置为零（默认），则无超时。

`user-input-timeout=`

Pine 尝试打开网络连接的秒数。默认30，最小5，最大由系统定义（通常为75）。

`tcp-open-timeout=`

Pine 尝试打开 Unix 远程壳连接的秒数。默认15，最小5，无限制。零完全禁用 rsh。

`rsh-open-timeout=0`

用于打开 Unix 远程壳连接的命令名称。

`rsh-path=`

`rsh-command=`

## 系统启动脚本片段

读取配置数据。

```bash
if [ -f /etc/sysconfig/network ]; then
  /etc/sysconfig/network
else
  NETWORKING=no
fi
```

```bash
if [ -z "$HOSTNAME" -o "$HOSTNAME" = "(none)" ]; then
  HOSTNAME=localhost
fi
```

加载函数库。

```bash
. /etc/init.d/functions
```

打印横幅。

```bash
# Print a banner.
echo -e "$\t\\\tWelcome to"
[ "$BOOTUP" != "serial" ] && echo -en "\033[1:31m"
echo -en "Red Hat"
[ "$BOOTUP" != "serial" ] && echo -en "\033[0:39m"
echo "Linux"
if [ "$PROMPT" != "no" ]; then
  echo -en "\tPress 'I' to enter interactive startup."
  echo
  sleep 1
fi
```

修复控制台日志级别。

```bash
/bin/dmesg -n LOGLEVEL
```

挂载 /proc（在此处完成，以便卷标签可以与 fsck 配合工作）。

```bash
action "$Mounting proc filesystem: " mount -n -t proc /proc /proc
```

配置内核参数。

```bash
action "$Configuring kernel parameters: " sysctl -e -p /etc/sysctl.conf
```

设置系统时钟。

```bash
ARC=0
SRM=0
UTC=0

if [ -f /etc/sysconfig/clock ]; then
  /etc/sysconfig/clock
fi
```
