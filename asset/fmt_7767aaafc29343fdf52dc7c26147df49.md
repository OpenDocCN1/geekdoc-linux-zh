
## gkrecover
用于恢复的 GUI；`gtkrecover` 是一个程序的 GUI，用于对 ext2 分区上的被删除文件进行恢复。你可以通过以下方式搜索删除的文件：
- 硬盘名称
- 删除年份
- 删除月份
- 删除星期几
- 月份的第一/最后一天
- 最小/最大可能的文件大小
- 删除最小/最大可能小时
- 最小/最大可能分钟
- 删除文件的用户 ID
- 文件包含的文本字符串来自 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtsee
基于 GTK 的 ACDSee（一种图像查看器）副本；`GTSee` 是一个图像查看器/浏览器。浏览器显示缩略图，你可以通过回车键快速大图或全屏查看图片。它具有幻灯片功能。非常棒，但你也可以试试“`ggview`”。来自 Debian 3.0r0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtksql
postgresql 数据库的 GTK 前端。`GtkSQL` 是一个 PostgreSQL 的图形化工具。作者表示它还在开发阶段，缺少计划添加的功能，但它是稳定且实用的。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtktalog
磁盘目录。`Gtkalog` 是一个 GTK 目录程序。这意味着你可以为 CD 或其他内容创建数据库，并浏览或搜索特定的文件或文件夹。当你有很多 CD 并想知道某个内容在某张 CD 中时，它非常有用。来自 Debian 3.0r0 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtktiemu
文本仪器计算器；`GtkTemu` 仿真德州仪器计算器 TI-92/98+。它基于 XTiger（原始的 Linux TI 模拟器），后者使用了 UAE（Ultimate Amiga Emulator）的 68k 仿真内核。它是一个共享库，名为 `libti68k`。你需要转储你计算器的 ROM（你可以使用 `TilP` 完成），或者从德州仪器获取 ROM（进入有关你计算器的软件部分，然后下载压缩包并提取文件以使用此模拟器）。此包中*没有*提供 ROM，因为它们受德州仪器公司的版权保护。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtktrain
带有 GTK 接口的火车路线计算器；`gtktrain` 是一个考虑时间和距离计算从一个站点到另一个站点的最短路线的程序。它告诉你应该乘坐哪条线路以及在何处换。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtkwave
VCD（值变化转储）文件查看器；`gtkwave` 是 VCD 文件（通常由数字电路创建的文件）的查看器。（这些文件与视频 CD 无关！）。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtm
多文件管理器。`GTransferManager` 允许用户从网络检索多个文件。这些文件分部分检索，每个部分在用户连接互联网的独立会话中检索。这在用户对话时最有用。该程序使用 `gtm` 作为其后端执行这些任务。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## gtml
HTML 处理器；`gtml` 是一个用于维护多个网页的 HTML 处理器。由 GTM 生成的 HTML 文件与其他文件一样。因为 GTM 不尝试以任何方式解释 HTML，与所有版本的 HTML 兼容，并且不需要特定的浏览器或服务器。更多信息请访问 http://www.liffr/~beaufis/gtml/。 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
