
相当直接。传递给 `echo` 的任何参数都会获取。让我们尝试另一个例子。

```
@me@linuxbox ~]$ echo *
Desktop ls-output.txt Pictures Public Videos
```

发生了什么？为什么 `echo` 没有打印 `*`？正如我们回想起通配符的操作，`*` 字符匹配文件名中的任何字符，但我们在最初的讨论中没有看到 Shell 是如何做的。简单的答案是，Shell 在命令执行之前将 `*` 扩展成了其他内容（在此例中为当前目录下的文件名），因此 `echo` 命令从未见过它的扩展结果。

## 路径名扩展 (Pathname Expansion)

通配符工作的机制被称为“路径名扩展”。如果我们尝试在前面的章节中使用过的一些技术，就会发现它们实际上是扩展。给定一个主目录看起来如下：

```
@me@linuxbox ~]$ ls
Desktop ls-output.txt Pictures Templates
Documents Music Videos
```

我们可以执行以下扩展：

```
@me@linuxbox ~]$ echo*
Desktop Documents
```

以及这个：

```
@me@linuxbox ~]$ echo *s
Documents Pictures Templates Videos
```

甚至是这个：

```
@me@linuxbox ~]$ echo [:upper:]]*
Desktop Documents Music Public Templates Videos*
```

并且在我们的主目录之外，我们可以这样做：

```
melinuxbox ~$ echo /usr/*/share
/usr/kerberos/share /usr/local/share
```

### 隐藏文件的路径名扩展

众所周知，以点字符开头的文件名是隐藏的。路径名扩展（Pathname expansion）会遵循这一行为。如下所示扩展不会显示隐藏文件：

```
echo *
```

乍一看，我们似乎可以通过在模式开头加点来将隐藏文件包含在扩展中，例如：

```
echo ..*
```

这几乎奏效。但是，如果我们仔细观察结果，会发现名称 `.` 和 `..` 也会出现在结果中。由于这些名称指向当前工作目录和其父目录，使用这种模式可能会产生错误的结果。我们可以尝试运行以下命令来看这一点：

```
ls -d ..* | less
```

为了在这种情况下获得更好的路径名扩展效果，我们必须使用更具特定的模式。

```
echo .[!!]*
```

这会扩展为每一个以一个点开头、后跟任何其他字符的文件名。这对于大多数隐藏文件都能正常工作（尽管它不会包含开头有多个点的文件名）。带有 `-A` 选项（“几乎所有”）的 `ls` 命令将提供正确的隐藏文件列表。

```
ls -A
```

### 波浪号扩展

我们在介绍 `cd` 命令时可能记得，波浪号字符（`~`）具有特殊含义。当它位于单词开头时，它会扩展为指定用户的家目录名称；如果没有指定用户，则扩展为当前用户的家目录。

```
me@linuxbox ~]$ echo ~
/home/me
```

如果“foo”有一个账户，那么它会扩展为：

```
me@linuxbox ~]$ echo ~foo
/home/foo
```

### 算术扩展

允许 通过扩展执行算术运算。这允许我们将 shell 提示符作为计算器。

```
me@linuxbox ~]$ echo $(((2 + 2))
4
```

算术扩展使用以下格式：

```
$((expression))
```

其中 `expression` 是由数值和算术运算符组成的算术表达式。

算术扩展仅支持整数（整数字，不带小数），但可以执行许多不同的操作。表 7-1 描述了一些支持的运算符。

#### 表 7-1：算术运算符

| 运算符 |  |

| :--- | :--- |

| + | 加法 |

| - | 减法 |

| * | 乘法 |

| / | 除法（但记住，由于扩展仅支持整数运算，结果为整数） |

| % | 取模，简单意味着“余数” |

| ** | 幂 |

空格在算术表达式中是不重要的，表达式可以嵌套。例如，为了将 5 的平方乘以 3，我们可以使用：

```
me@linuxbox ~]$ echo $((5**2) * 3)
75
```

单圆括号可以用于分组多个子表达式。通过这种技术，我们可以重写之前的示例，并使用单个扩展而不是两次来得到相同的结果。

```
me@linuxbox ~]$ echo $((**2) * 3))
75
```

这是一个使用除法和取余运算符的示例。注意整数除法的效果。

```
me@linuxbox ~]$ echo Five divided by two equals $((5/2))
Five divided by two equals 2
me@linuxbox ~]$ echo with $((5%%2)) left over.
with 1 left over.
```

### 大括号扩展

也许奇怪的扩展被称为大括号扩展（brace expansion）。通过它，你可以从包含大括号的模式创建多个文本字符串。这里是一个示例：

```
me@linuxbox ~]$ echo Front-{A,B,C}-Back
Front-A-Back Front-B-Back Front-C-Back
```

大括号扩展的模式可以包含一个前导（preamble）和一个后缀（postfix）。大括号表达式可以包含逗号分隔的字符串列表、整数范围或单个字符。模式可以包含空格。这里有一个使用整数范围的示例：

```
me@linuxbox ~]$ echo Number (1..5)
Number_1 Number_2 Number_3 Number_4 Number_5
```

在 `bash` 4.0 及更高版本中，整数也可以这样进行零填充：

```
me@linuxbox ~]$ echo (01..15)
01 02 03 04 05 06 07 08 09 10 11 12 13 14 15
me@linuxbox ~]$ echo (001..15)
001 002 003 004 005 006 007 008 009 010 011 012 013 014 015
```

这是一个倒序的字母范围：

```
me@linuxbox ~]$ echo (Z..A)
Z Y X W V U T R Q P O N L K J I H G F E D C A
```

大括号扩展可以嵌套。

```
me@linuxbox ~]$ echo a{1,2},B{3,4}}
1 a3 a4
```

那么，这有什么用？最常见的应用是创建文件或目录列表。例如，我们不仅限于简单的命令。可以使用整行（仅显示部分输出）。

```
$ file -d /usr/bin/* | grep zip
/usr/bin/binzip symbolic link to 'bzip'
/usr/bin/bzip2 ELF 32-bit executable, Intel 8036, version 1
(SYSV), dynamically linked (shared libs), GNU/Linux 2.6.9, stripped
/usr/bin/funzip ELF 32-bit executable, Intel 8036, version 1
(SYSV), dynamically linked (shared libs), GNU/Linux 2.6.9, stripped
/usr/bin/gpg-zip Bourne shell script executable
/usr/bin/gunzip symbolic link to '../bin/gunzip'
/usr/bin/gzip symbolic link to '../bin/gzip'
/usr/bin/mzip symbolic link to '../tools'
```

现在我们已经看到了 shell 有多少方式进行扩展，是时候学习如何控制它了。例如以下所示：

```
$me@linuxbox ~$ echo this is a test
th is a test
```

或者使用这个：

```
[me@linuxbox ~]$ echo The total is $100.00
The total is 00.00
```

在第一个示例中，shell 的单词拆分（word splitting）删除了 `echo` 命令参数列表中额外的空格格。在第二个示例中，参数扩展（parameter-expansion）将 `$1` 的值替换为空字符串，因为它是一个未定义的变量。shell 提供了一种名为“引用”（quoting）的机制，用于选择性地抑制不需要的扩展。
