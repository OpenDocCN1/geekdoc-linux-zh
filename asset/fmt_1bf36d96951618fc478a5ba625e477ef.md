
如果 IP 消息的发送速度快于目标设备的处理速度，它们会被丢弃。当这种情况发生时，IP 层负责向原始源发送消息，告知其传输负载。此消息增加了网络上发送的数据量。

## 传输层
传输层描述了用于在网络内部发送 IP 数据报的协议。这些协议是 `TCP` 和 `UDP`。`TCP` 在网络中两个通信设备之间提供面向连接、可靠的全双工字节流服务。`UDP` 协议提供不可靠的无连接数据报服务。更多信息见第 4.3 节。

## 应用层
OSI 模型的会话和表示层未包含在 TCP/IP 通信协议中。应用层包含了用户使用 TCP/IP 通信访问网络的应用程序。TCP/IP 通信的一个优势是这些应用程序可以在各种平台（包括 UNIX 和 Windows NT）上运行。一些标准应用程序如下：

### 文件传输协议 (FTP)
FTP 是用于从一个系统发送文件到另一个系统的应用程序。它提供了用户验证、目录列表、更改目录以及以 ASCII 和二进制格式传输数据等功能。FTP 使用 `TCP` 传输协议将数据从一个应用程序传输到另一个。由于使用了 `TCP`，数据是可靠的。

# TCP/IP 简介

### 远程进程执行 (REXEC)
REXEC 是一种允许用户在连接到网络的主机上远程执行进程的应用程序。REXEC 使用 `TCP` 传输层协议进行通信。当用户尝试使用 REXEC 在远程机器上执行进程时，系统会对用户的用户名和密码进行身份验证。如果无法启动请求的进程，系统将会通知用户；否则，进程将打开两个 `TCP` 通信通道。其中一个通道用于在远程应用程序之间传输数据，另一个通道则用于向远程应用程序发送信号。目前，仅 UNIX 支持 REXEC 连接，尽管这两个操作系统都包含可以连接到已启用 REXEC 的 UNIX 工作站的客户端。可以使用第三方的 Windows NT 软件来实现 REXEC 连接时的进程启动。

# 互联网地址

互联网地址（即 IP 地址）由 32 位组成，包含了网络地址和主机地址。IP 地址的格式为：网络地址 + 主机地址。TCP/IP 互联网上的每一个每个主机都必须有一个 32 位的 IP 地址。主机地址并不一定用于标识主机本身，而是标识主机与网络的连接情况。因此，如果主机移动到不同的网络，它必须获取不同的 IP 地址。

IP 地址有四种格式，称为 A 类、B 类、C 类和 D 类。图 4.2 展示了 32 位 IP 地址的四种格式。

## 图 4.2 IP 地址格式

| 类型 | 值 | 说明 |
| :--- | :--- | :--- |
| A 类 | 0 | 网络地址 (7 位) + 主机地址 (24 位) |
| B 类 | 10 | 网络地址 (14 位) + 主机地址 (16 位) |
| C 类 | 110 | 网络地址 (21 位) + 主机地址 (8 位) |
| D 类 | 1110 | 多组播地址 (28 位) |
| 未来备用 | 11110 | 未来备用 |

# 第 4 章：跨平台通信

地址的前几位指定格式类型。地址的剩余部分指定网络地址和主机地址。主机地址称为本地地址或 `HOST` 字段。

A 类地址用于具有大量主机的网络。主机 `ID` 字段长度为 24 位。因此，每个网络可以标识 $2^{24}$ 个主机。网络 `ID` 分配了 7 位。这意味着在指定的互联网中最多可以 127 个网络。

B 类地址用于需要中等数量主机和大量网络的网络。在这种配置中，16 位被分配给主机 `ID`，14 位分配给网络 `ID`。

C 类地址允许最大数量的网络 `ID`（21 位）和最少的主机 `ID`（仅 8 位，即每个网络 256 个主机）。

D 类地址用于多组播（multicasting），这是有限区域内广播的一种形式。本书未涵盖 D 类地址。

指定每个互联网类别的 IP 地址范围范围如表 4.1 所示。

## 表 4.1 类标识网络值

| TCP/IP 分类 | 网络地址值 |
| :--- | :--- |
| A 类 | 0–127（0 和 127 被预留） |
| B 类 | 128–191 |
| C 类 | 192–223 |
| D 类 | 224–254 |

互联网地址写作四个十进制数字，每个数字用点隔开。每个十进制数字编码 32 位互联网地址中的一个。指定为 `1.5.10.1` 的互联网地址是一个 A 类互联网地址，网络 `ID` 为 `1`，主机 `ID` 为 `5.10.1`。B 类地址的示例是 `128.3.19.1`，其中 `128` 是网络 `ID`，`19.1` 是网络内的主机 `ID`。C 类互联网地址 `192.3.2.200` 指定网络 `ID` 为 `192.3.2`，主机 `ID` 为 `200`。最后，D 类互联网地址 `230.191.2.3` 指定了位于一个或多个物理网络上的多组播组。表 4.2 显示了使用点点表示法的四种分类格式。

## 表 4.2 IP 地址格式

| TCP/IP 分类 | IP 地址格式 |
| :--- | :--- |
| A 类 | `网络_ID.主机_ID.主机_ID.主机_ID` |
| B 类 | `网络_ID.网络_ID.主机_ID.主机_ID` |
| C 类 | `网络_ID.网络_ID.网络_ID.主机_ID` |
| D 类 | 不适用（多组播组） |

网络中传输的每个 IP 数据报文包含一个由两个 32 位地址组成的头部。其中一个指定源主机，另一个指定目的主机。整个 IP 数据报文头部为 20 字节。由于每个 IP 地址都包含网络 `ID` 和主机 `ID`，路由器仅提取网络 `ID` 来确定主机所连接的网络。通过使用分层寻址法，路由器不需要知道网络上每个主机的位置。当 IP 消息跨不同网络传输时，定义为网关的系统会连接这两个网络并传递 IP 数据报文。网关不负责消息的完全翻译。
