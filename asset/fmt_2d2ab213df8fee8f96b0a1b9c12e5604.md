## DBI 与 Perl

`DBI` 是一个数据库访问模块。它定义了一组与所用数据库无关的方法和变量。`DBI` 将调用发送给驱动程序，驱动程序随后发送到数据库。数据库模块被称为 `DBD`（数据库驱动）。这些驱动是用 Perl 实现的。

### 表 13-2 文档注释

| `DBD` | 含义 |
| --- | --- |
| `DBI` | 静态类 |
| `$dbh` | 数据库句柄 |
| `$sth` | 语句句柄 |

## 第13 章 接口

| `DBD` | 含义 |

| `$h` | 任何 `$dbh`、`$sth` 或 `$drh` 句柄 |
| `$rc` | 返回代码（布尔值：true 表示成功，false 表示错误） |
| `$rv` | 返回值 |
| `@ary` | 从数据库返回的值，通常为行 |

| `\attr` | 传递给方法的属性值引用 |
