## 设置获取窗口尺寸提示

Xlib 提供了你可以用于设置或获取窗口尺寸提示的函数。本节讨论的函数使用了 `<X11/XUtil.h>` 头文件中定义的标志和 `XSizeHints` 结构以及 `WM_NORMAL_HINTS` 属性。

要设置给定窗口在正常状态下的尺寸，请使用 `XSetNormalHints`。此函数已被 `XSetWMNormalHints` 取代。

- **`XSetNormalHints` (*display, w, hints);**
    - *display**: 指定与 X 服务的连接。
    - *w**: 指定窗口。
    - *hints**: 指定指向窗口在正常状态下尺寸提示的指针。

`XSetNormalHints` 为指定的窗口设置尺寸提示结构。应用程序使用 `XSetNormalHints` 告知窗口管理器该窗口所需的尺寸或位置。此外，想要移动或调整自身大小的应用程序应该调用 `XSetNormalHints` 并指定其新位置和大小，以及直接调用 Xlib 函数来移动或调整大小。这是因为窗口管理器可能会忽略重定向配置（redirect configure），但它们会关注属性的变化。

要设置尺寸，应用程序不仅必须为结构中的成员赋值，还必须设置结构的标志以指示存在哪些信息以及这些信息的来源。除非设置标志以指示结构中的哪些成员已分配值，否则对 `XSetNormalHints` 的调用是没有意义的。

`XSetNormalHints` 可以产生 `BadAlloc` 和 `BadWindow` 错误。

要返回窗口在正常状态下的尺寸，请使用 `XGetNormalHints`。此函数已被 `XGetWMNormalHints` 取代。

- **Status `XGetNormalHints` (*display, w, hints_return*);**
    - *display**: 指定与 X 服务的连接。
    - *w**: 指定窗口。
    - *hints_return**: 返回窗口在正常状态下的尺寸提示。

`XGetNormalHints` 函数返回窗口在正常状态下的尺寸提示。如果成功，它返回非零状态；如果应用程序对该窗口没有正常尺寸提示，则返回零。

## 兼容函数

`XGetNormalHints` 可以产生 `BadWindow` 错误。

接下来两个函数设置并读取 `WM_ZOOM_HINTS` 属性。

要设置窗口的缩放提示，请使用 `XSetZoomHints`。此函数不再被《通信规范手册》（Inter-Communication Conventions Manual）支持。

- **`XSetZoomHints`(display, w, zhints);**
    - * display 指定与 X 服务的连接。
    - * w 指定窗口。
    - * zhints 指定指向缩放提示的指针。

许多窗口管理器将窗口视为三种状态之一：图标化（iconic）、正常（normal）或缩放（zoomed）。`XSetZoomHints` 为窗口管理器提供了窗口在缩放状态下的信息。

`XSetZoomHints` 可以产生 `BadAlloc`。

`XGetZoomHints`。此函数不再被《通信规范手册》支持。

- **Status `XGetZoomHints`(display, w, zhints_return);**
    - * display 指定与 X 服务的连接。
    - * w 指定窗口。
    - * zhints 返回缩放提示。

`XGetZoomHints` 返回窗口在缩放状态下的尺寸提示。如果成功或应用程序未为该窗口指定尺寸提示，则返回非零值。

`XGetZoomHints` 可以产生 `BadWindow` 错误。

要读取 `WM_SIZE_HINTS` 任何属性的值，请使用 `XGetSizeHints`。此函数已被 `XGetWMSizeHints` 取代。

    - * display 指定与 X 服务的连接。

`Status XGetNormalHints(display, w, colormap_return);`
    - * display 窗口
         * w 指定窗口

- * colormap_return 返回窗口在正常状态下的调色板。

`XGetNormalHints` 函数返回窗口在正常状态下的调色板。如果成功，它返回非零状态；如果应用程序对该窗口没有正常调色板，则返回零。

`XGetSizeHints` 可以产生 `BadAlloc` 和 `BadWindow` 错误。

**w**
指定窗口。

**colormap**

**property**

`XSetSizeHints` 为指定的窗口设置调色板结构。应用程序使用 `XSetNormalHints` 告知窗口管理器该窗口所需的尺寸或位置。此外，想要移动或调整自身大小的应用程序应该调用 `XSetNormalHints` 并指定其新位置和大小，以及直接调用 Xlib 函数来移动或调整大小。这是因为窗口管理器可能会忽略重定向配置，但它们会关注属性的变化。

## 解析窗口几何

要根据用户指定的位置和默认位置解析窗口几何，请使用 `XGeometry`。此函数已被 `XWMGeometry` 取代。

```
int XGeometry(display, screen, position, default_position, bwidth,

width, fheight, xadder, yaadder, x_return, y_return, width_return,

height_return);
```

## 兼容性函数

返回的宽度和高度将是 `default_position`指定的宽度和高度，但会被任何用户指定的区域覆盖。它们不受 `width`、`height`、`xadder` 或 `yadder` 的影响。x 和 y 坐标通过边框宽度、屏幕宽高、由 `xadder` 和 `yadder`指定的填充，以及几何规格中的高度和宽度乘以宽度和高度计算得出。
