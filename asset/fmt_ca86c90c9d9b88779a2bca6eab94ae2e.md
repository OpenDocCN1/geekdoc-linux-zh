## 执行 RDC 的分阶段安装

除了执行 Active Directory 服务的全局安装外，Windows 还支持 **分阶段安装**。分阶段安装会在域控制器上安装 Active Directory 服务和 Active Directory 数据库，但不会创建 Active Directory 林或域。
