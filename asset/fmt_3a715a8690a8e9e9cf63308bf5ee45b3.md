## 配置 sudo

配置 sudo 是很多人会卡住的地方。如果你采取小步运行并在构建配置时测试每个部分，配置其实并不困难。如果你在安装完成后查看 `/etc` 目录，你会看到一个名为 `sudoers` 的文件。`sudoers` 文件用于配置 sudo 程序的命令和用户。**千万不要直接编辑 `sudoers` 文件！** 系统提供了一个带有编辑器包装器的特殊程序，称为 `visudo`（或使用 `vi sudo`）。`visudo` 程序位于 `/usr/local/bin`，它会在保存文件之前检查任何错误。如果检测到错误，`visudo` 程序会准确告诉你错误是什么，在大多数情况下还会指出错误所在的行。如果你直接编辑 `/etc/sudoers` 文件并出错，编辑器将直接带错误保存文件，这可能很难找到错误。`visudo` 程序会检查文件格式是否正确，并确保命令/用户引用的一致性。如果你用户名写了错误，`visudo` 编辑器不会捕获，但这类错误在首次运行后应该很容易发现。

我提供了两个 `/etc/sudoers` 文件的示例，供你在列表 14.5 和 14.6 中作为模板使用。

> 注意：列表 14.5 中的 `sudoers` 文件在 www.courtesan.com 的 Todd Miller 许可下使用，并作为示例包含在 sudo 分发中。感谢你，Todd！

```
# 示例 /etc/sudoers 文件。
#
# 此文件必须以 root 身份使用 'visudo' 命令编辑。

User_Alias WEBMASTERS = will, wendy, vim

```
