# 从源码构建 Gentoo

从源码开始编译你自己的自定义发行版教程

## 16 编译内核

真理时刻——是时候编译你的内核了。使用以下命令执行：

```bash
make && make modules_install
```

取决于你激活的模块和选项，这需要一段时间时间。安装完成后，重启内核：

```bash
cp /arch/x86/bzimage /boot/kernel-$(uname -r)-gentoo
```

然后重启进入最后一步。

## 17 启动模块

你需要设置你想要加载的模块。要找到可用模块，请使用：

```bash
find /lib/modules/*/ -type f -name '*o*' -or -name '*ko*' | less
```

...其中 X 是内核版本。你需要将模块添加到你的文件中：

```bash
nano -w /etc/conf.d/modules
```

## 18 fstab 文件

我们需要正确设置要挂载的分区。使用以下打开 `fstab`：

```bash
nano -w /etc/fstab
```

然后按照示例操作以确保系统正常工作：

| 设备 | 类型 | 选项 |
| :--- | :--- | :--- |
| `/dev/sda` | `ext4` | `defaults,noatime` |
| `/dev/sdb` | `swap` | |
| `/dev/sda3` | `ext4` | |

## 19 网络

在重启之前，我们需要配置网络。首先编辑文件：

```bash
nano /etc/network/interfaces
```

添加此行：

```bash
eth0="dhcp"
```

如果你使用静态 IP，可以将其替换为：

```bash
eth0="192.168.1.10 255.255.255.0 192.168.1.1"
```

双重授权后，重启：

## 20 Root 设置

设置 `root` 密码。双重授权后：

```bash
passwd
```

## 21 语言包

你需要设置需要的语言包。要可用的语言：

```bash
locale-gen
```

设置 `locale`：

```bash
LC_ALL="en_US.UTF-8"
```

## 22 启动

安装 `GRUB`。使用以下命令安装：

```bash
grub-install /dev/sda
```

并更新 `GRUB` 配置：

```bash
update-grub
```

## 23 引导程序

安装 `GRUB` 引导程序以启动：

```bash
grub-install /dev/sda
```

## 24 引导程序

安装 `GRUB` 引导程序以：

```bash
grub-install /dev/sda
```

## 25 完成

现在可以重启进入 `Gentoo`：

```bash
reboot
```
