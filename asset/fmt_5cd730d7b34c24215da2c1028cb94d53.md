```bash
function twirl
{
  TCOUNT="0"

  while
  do
    TCOUNT=$((expr TCOUNT + 1))

    case $TCOUNT in
      "1")
        echo '\*\*c'
        sleep 1
        ;;
      "2")
        echo '\*\*c'
        sleep 1
        ;;
      "3")
        echo '\*\*c'
        sleep 1
        ;;
      "4")
        echo '\*\*c'
        sleep 1
        ;;
      *)
        TCOUNT="0"
    esac
  done
  # End of twirl function
}
```

## 开启/关闭 SSA 标识灯

为了控制此列表中 pdisks 的标识灯，我们使用 `for` 循环和我们的 `lsdev` 命令，通过命令替换来创建 pdisk 列表。这些步骤在列表 20.6 中。

```bash
function all_defined_pdisks {
  # 开启/关闭所有灯：
  # 使用带有 "Cc" 选项的 "lsdev" 命令遍历系统的每个 pdisk，
  # 同时使用 "awk" 提取出 
  # 实际的 pdisk 编号。
  
  # 我们将根据 $SWITCH 变量开启或关闭指定的标识灯：
  # -y: 开启灯
  # -n: 关闭灯
  
  # ... 将 $SWITCH 的值传递给 "ssaidentity" 命令，如下文所示...

  echo "\nTurning $STATE ALL of the system's pdisks...Please Wait...\n"

  for PDISK in $(lsdev -Cc pdisk -s ssar -H | awk '{print $1}' | grep pdisk)
  do
    echo "\nTurning $STATE $PDISK "
    ssaidentity -l $PDISK "$SWITCH"
    echo "\nTurning $STATE $PDISK Failed"
  done
  echo "\n...TASK COMPLETE...\n"
}
```

**列表 20.6** `all_defined_pdisks` 函数列表

在列表 20.6 中，注意 `for` 循环中使用的命令替换。命令替换的列表参数在每次迭代中都被分配给 `$PDISK` 变量。每当分配一个磁盘，`ssaidentity` 命令就会使用 `$PDISK` 定义作为目标执行，并使用 `$SWITCH` 作为要执行的操作，该操作可以是 `-y`（开启灯）或 `-n`（关闭灯）。这些值在脚本的主体中定义。每个灯的开启或关闭都会通知用户。

## 第 20 章

最后一个函数 `list_of_disks` 作用于执行 shell 脚本时命令行指定的一个或多个 `hdisk` 或 `pdisk`。在 shell 脚本主体中，我们完成了所有命令行参数的解析，因为如果你尝试在函数内部解析命令行，它将作用于函数的参数，而不是脚本的参数。因此，这是一个短函数。

在 shell 脚本的主体中，变量 `PDISKLIST` 被填充为 `pdisk` 列表。由于用户可以在命令行上指定 `hdisk` 或 `pdisk` 或两者都有，我们唯一能做的验证是在 `hdisk` 翻译为 `pdisk` 时进行的检查。我们需要进行合理性检查，以确保我们操作的每个 `pdisk` 在 `/dev` 文件系统中都有一个特殊文件。这是通过使用 `if...then` 测试中的 `-c` 开关实现的。如果列出的 `pdisk` 关联有一个特殊文件，则尝试开启/关闭 SSA 标识灯，否则将通知用户系统上未定义该 `pdisk`。`list_of_disks` 函数如列表 20.8 所示。
