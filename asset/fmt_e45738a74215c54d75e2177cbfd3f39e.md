## 第 2 步：确定 DHCP 租约池

此时，向导要求管理员为每个请求 IP 地址的客户端确定地址租约的长度。租约表示客户端在分配到 IP 地址后，可以使用该地址多长时间。一旦租约到期，该 IP 地址将失效，客户端将需要请求另一个 IP 地址。
