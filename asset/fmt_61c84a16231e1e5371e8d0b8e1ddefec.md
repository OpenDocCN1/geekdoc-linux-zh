### e) b 和 d 的答案中的基地址是否一致？如果不一致，在此停止并 Determine原因。

答案：在示例中，答案是一致的。实际上，通过两种方法找到基地址可能会差 10（例如，你可能从一个命令得到 `0x280`，从另一个命令得到 `0x290`）。在这种情况下，不要担心值的差异。如果你的网卡没有启动，你可能以后需要回顾。否则，所有其他值都是一致的。差异在于网卡探测的方式。

### 表 2.2 网卡设备加载信息

| 描述 | 值 | 注释 |
|---|---|---|
| 基地址 | `0x280` | |
| 中断或 IRQ | `5` | |

| 协议设备名称 | `eth0` | 因为它是可加载的 |
