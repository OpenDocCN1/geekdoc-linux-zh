## 更完整的应用

在长时间停顿后，我们将恢复对 `sys_info_page` 程序的工作，该程序上次出现在第 27 章中。我们接下来的添加将为程序增加以下几个命令行选项：

- * 输出：我们将添加一个选项来指定包含程序输出的文件名。它将被指定为 `-f file` 或 `--file file`。
- * 交互模式：此选项将提示用户输入输出文件名，并确定指定的文件是否已经存在。如果存在，在覆盖现有文件之前会提示用户。此选项将通过 `-i` 或 `--interactive` 指定。
- * 帮助：可以指定 `-h` 或 `--help` 来导致程序输出一条信息丰富的用法消息。

以下是实现命令行处理所需的代码：

```bash
usage() {
  echo "$PROGNAME: usage: $PROGNAME [-f file | -i]"
  return
}
# process command line options
interactive=
filename=
while [[ -n "$1" ]]; do
  case "$1" in
    -f | --file)
      shift
      filename="$1"
      ;;
    -i | --interactive)
      interactive=1
      ;;
    -h | --help)
      usage
      exit
      ;;
    *)
      usage >&2
      exit 1
      ;;
  esac
  shift
done
```

首先，我们添加了一个 shell 函数，用于在调用帮助选项或尝试使用未知选项时显示消息。

接下来，我们开始处理循环。只要位置参数 `$1` 不为空，循环就会继续。在循环结束时，我们有一个 `shift` 命令来移动位置参数，以确保循环最终终止。

在循环内部，我们有一个 `case` 语句来检查当前的位置参数，看它是否匹配任何支持的选择。如果找到支持的参数，则执行相应的操作。如果发现未知选项，则显示用法消息，脚本将带错误终止。

`-f` 参数的处理方式很有意思。当检测到它时，它会触发额外的 `shift`，从而将位置参数 `$1` 移动到 `-f` 选项提供的文件名参数。

### 交互模式

if [[ -n "$interactive" ]]; then

        read -p "Enter name of output file: " filename

如果 `interactive` 变量不为空，将启动一个无限循环，循环中包含文件名提示和后续的文件处理代码。如果所需的输出文件已存在，将提示用户覆盖、选择另一个文件名或退出程序。如果用户选择覆盖现有文件，将执行 `break` 来终止循环。注意 `case` 语句是如何检测用户是选择覆盖还是退出的。任何其他选择会导致循环继续并再次提示用户。
