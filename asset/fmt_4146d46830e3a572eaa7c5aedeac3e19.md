## 多任务

在 Linux 中进行多任务处理，你可以同时运行多个程序。当你希望在等待另一个程序完成的同时运行程序时，这非常有用。例如，你可以在输入文档时打开一个网页浏览器。

在 Linux 中在后台运行程序，你可以在命令末尾使用 `&` 符号：

```bash
command &
```

这将在后台运行该程序，你可以继续使用终端。要查看后台运行的程序，你可以使用 `jobs` 命令：

```bash
jobs
```

要停止后台程序，你可以使用 `kill` 命令：

```bash
kill pid
```
