调制解调器是一种通过电话线传输数字信号的设备。如果电话线全是数字信号，你就不需要调制解调器了。它允许你的电脑与外部世界连接并通信。PC 的调制解调器有两种基本类型：外部和内部。外部位于电脑外部，内部位于电脑内部。外部调制解调器插入电脑上称为“串口”的接口。内部调制解调器是一块插入电脑内部的卡。

串口不应与“通用串行总线”（`USB`）混淆，后者使用特殊的接口，未来可能用于调制解调器。有关调制解调器和串口的细节请参见“调制解调器与串口基础”。

使用直连线或调制线将调制解调器连接到 PC 上空闲的串口。确保你知道串口名称：`COM1` 是 `ttyS0`，`COM2` 是 `ttyS1`。你可能需要检查 BIOS 来确定这一点。插上电源线为调制解调器供电。进一步说明请参见“所有调制解调器”。

内部调制解调器（在 ISA 总线上）

（PCI 总线请参阅 PCI 调制解调器）如果调制解调器说它只能在 MS Windows 下工作，那么你就没戏了。如果你已经有两个串口，请将此设置为第三个串口（`ttyS2 = COM`）。找到一个可以使用的空闲 IRQ 编号。通常，一个空闲的编号是用于第二个并行端口或声卡的 `IRQ5`（你可能没有这些）。然后将内部调制解调器上的跳线帽（或类似设置）设置为空闲的 IRQ 和 I/O 地址 `3E8` (`ttyS2`)。

# 2 调制解调器将数字转换为模拟信号（反之亦然）

大多数电话主线是数字信号的，但通往你家（或公司）的线路通常是模拟的，这意味着它们的设计是为了传输电压波，这种电压波与你口中发出的声波特性相同。电压波被称为“模拟信号”。在示波器上查看，它看起来像频率和幅度变化的正弦波。数字信号则像方波。例如，`3 v`（伏特）可能代表 1 位，而 `0 v` 可能代表 0 位。对于大多数串口（外部调制解调器使用），`+12 v` 是 0 位，`-12 v` 是 1 位（有些是 `+` 或 `- 5 v`）。

# 调制解调器 调制解调器指南（适用于 Linux）

要通过电话线从你的电脑发送数据，调制解调器接收电脑的数字信号并将其转换为“模拟信号”。它通过创建一个模拟正弦波并对其进行“调制（Modulating）来实现。由于结果仍然代表数字数据，它也可以被称为数字信号而非模拟信号。它看起来像模拟信号，几乎每个人都称其为模拟信号。在电话线的另一端，另一个调制解调器对该信号进行“解调（DEModulating）”，从而恢复出纯数字信号。将上述两个词的“mod”和“dem”部分结合起来就得到了“modem”（如果你去掉了两个 d 中的一个）。因此，“modem”就是一个调制器-解调器（MODulator-DEModulator）。关于什么是调制，请参见“调制细节”章节。

## 2.2 什么是串口？

## 引言

由于调制解调器与电脑之间有一个串口，因此有理解串口以及调制解调器是很有的。串口是一个 I/O（输入/输出）设备。大多数 PC 都有两个串口。每个串口在电脑后面有一个 9 针连接器。电脑程序可以将数据（字节）发送到发送引脚（输出），从接收引脚（输入）接收字节。其他引脚用于控制和接地。

串口不仅仅是一个连接器。它将数据从并行转换为串行并改变数据的电气表示。在电脑内部，数据位是并行流动的（同时使用许多电线）。串行流是单根电线上的位流（例如串口连接器的发送或接收引脚）。为了让串口创建这样的流，它必须在发送引脚上将数据从并行（电脑内部）转换为串行（反之亦然）。

串口的大部分元件位于一个名为 `UART` 的电脑芯片（或芯片区域）中。有关 `UART` 的更多详细信息，请参见“什么是 UART？它们如何影响性能？”章节。但你可能想先看这一节，以便你希望能够理解 `UART` 是如何融入整体方案之中的。
