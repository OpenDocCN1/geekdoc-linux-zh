
这会将以下发送到

```
===================================

Here is the text I want to display.

===================================
```

标准输出文件。`$` 是 Perl 使用的特殊标量变量；它告诉 Perl 使用哪种打印格式。

## 在打印格式中显示值

若要在你的打印格式中指定要打印的值，请在打印格式中添加一个值字段。这是一个使用值字段的打印格式示例：

```
VOWELFORMAT =

==========================================

Number of vowels found in text: a: @<<< e: @<<< i: @<<< o: @<<< u: @<<< a, e, i, o, u

==========================================
```

该行包含五个值字段。每个值字段都包含特殊字符，提供了值如何显示的信息（这些特殊字符在后续章节“选择值格式”中进行了描述）。任何包含值字段的行后面必须紧跟一行，列出要在这些值字段中显示的标量：值字段的数量必须与标量值的数量相等。

## 选择值格式

支持以下值字段格式：

- `@<<<<` 左对齐输出：宽度等于所提供的字符数。
- `@>>>>` 右对齐输出：宽度等于所提供的字符数。
- `@||` 居中齐输出：宽度等于所提供的字符数。
- `@####` 固定精度数值：`.` 表示小数点的位置。
- `@*` 多行文本。

在所有情况下，在计算字段中的字符数时，都会包含 `@` 字符。例如，字段 `@>>>>` 的宽度为五个字符。同样，字段 `@#####` 的宽度为七个字符：小数点前四位，小数点后二位，以及小数点本身。

## 写入其他输出文件

你还可以使用打印格式和 `write()` 写入其他文件。例如，要使用打印格式 `MYFORMAT` 写入由文件变量 `MYFILE` 代表的文件，请使用以下语句：

```
select(MYFILE);

$~ = "MYFORMAT";

write(MYFILE);
```

`select()` 语句指示要写入哪个文件，而 `$~ = "MYFORMAT"` 语句选择了要使用的打印格式。在用 `select()` 选择了输出文件后，它将一直保持选中状态，直到看到另一个 `select()`。这意味着如果你选择了一个标准输出文件以外的输出文件（如 `select(MYFILE)`），在 Perl 看到 `select(STDOUT)` 语句之前，`write()` 的输出不会进入标准输出文件。有两种方法可以确保你不会因此困扰：

- 始终使用 `STDOUT` 作为默认输出文件。如果你更改了输出文件，在完成后将其改回：
```
select(MYFILE);

$~ = "MYFORMAT";

write(MYFILE);

select(STDOUT);
```
- 在调用 `write()` 之前始终用 `select()` 指定输出文件：
```
select(STDOUT);

$~ = "MYFORMAT";

write(); # 假设为 STDOUT
```

使用哪种方案并不重要，只要你保持一致即可。如果你正在编写一个写入特定输出文件的子程序，可以将当前选中的输出文件保存在临时变量中并在稍后恢复：

```
$temp = select(MYFILE); # 选择输出文件

$~ = "MYFORMAT";

write(MYFILE);

select($temp); # 恢复原始选中的输出文件
```

这种方法在你处一个大型程序中间且不记得当前选了哪个输出文件时也非常有用。

## 指定页眉

你可以指定在开始新页时打印的页眉。要实现这一点，定义一个名为 `filename_TOP` 的打印格式，其中 `filename` 是与你要写入的文件对应的文件变量名。例如，要为写入标准输出定义页眉，请定义一个名为 `STDOUT_TOP` 的打印格式：

```
STDOUT_TOP =

page @$%
```

系统变量 `$%` 包含当前页码（从 1 开始）。

## 设置页长度

如果为特定的输出文件定义了页眉，`write()` 会自动对该文件的输出进行分页。当打印行数大于页长度时，它将开始新页。

默认情况下，页长度为 60 行。要指定不同的页长度，请更改存储在系统变量 `$=` 中的值：

```
$= = 66; # 将页设置为66行
```

此赋值必须出现在第一个 `write()` 语句之前。

## 格式化长字符串

包含长字符字符串的标量变量可以使用多个值字段打印：

```
QUOTATION =

Quotation for the day:

-----------------------------

^<<<<<<<<<<<<<<<<
```
