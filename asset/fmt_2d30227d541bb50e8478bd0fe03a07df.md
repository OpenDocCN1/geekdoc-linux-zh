
编译器工具，对 `lex` 和 `yacc` 的补充。`Kimwitu`（读作 ‘kewreetoo’）是一个支持构建使用树或项作为主要数据结构的程序的系统。它是工具开发中的一种“元工具”。它可以与 `Yacc` 和 `Lex` 建立接口——其核心思想是 `yacc` 和 `Lex` 用于解析，而 `Kimwitu` 程序则用于构建和操作解析树。还有 `Kimwitu++`（也为 Debian 提供的），它以从 C 的方式与 C 接口。来自 Debian 3.0r0

# kimwitu++

一个（语法树处理（项处理器））`Kimwitu` 是一个支持构建使用树或项作为主要数据结构的程序的系统。它允许你定义、存储和操作类型节点。树的每个节点都有特定数量的节点，并扩展这些节点以具有特定功能。此类树最流行的例子是语法树。节点以类似于 `Yacc` 的方式定义。项可以被剥离（例如 `treewealk`）和重写（例如 `item substitution`）。`Kimwitu++` 为解析唯一规则和重写规则提供了强大的匹配功能。`Kimwitu++` 是 `C++` 的扩展。它引入了类 `Yacc` 的定义以及重写规则，并将输入文件翻译为 `C++`。使用它时，可以使用 `Bison` 生成的解析器，你也可以自由使用其他工具。此外存在 `Kimwitu`（也为 Debian 提供的），它与 C 而不是 `C++` 接口，也可以用于 `C++` 项目，但 `Kimwitu++` 具有一些人们可能认为有用的扩展。来自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
