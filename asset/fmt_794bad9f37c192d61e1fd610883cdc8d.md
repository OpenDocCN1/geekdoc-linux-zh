
我们已经看到，每个图和每个有向图都关联一个有限群。我们现在考虑反向问题，即为给定的有限群关联一个有向图和一个图。

如果非平凡群 `Γ` 可以由非单位元 `h_1, h_2, …, h_k` **生成**（这些元素称为 `Γ` 的**生成元**），即 `Γ` 的每个元素都可以表示为这些生成元的（有限）乘积，则称该群由这些元素生成。每个非平凡的有限群都有一个有限的**生成集**（通常有多个这样的集合），因为该群所有非单位元元素的集合总是 `Γ` 的一个生成集。

设 `Γ` 是一个给定的具有生成集 `Δ = {h_1, h_2, …, h_k}` 的非平凡有限群。我们将 `Γ` 与 `Δ` 关联为一个有向图，通常称为 `Γ` **关于** `Δ` 的**凯莱色图**（Cayley color graph），记为 `D_Δ(Γ)`。`D_Δ(Γ)` 的顶点集是 `Γ` 的群元素集合，因此 `D_Δ(Γ)` 的阶为 `|Γ|`。此时，每个生成元 `h_i` 被视为一种颜色。对于 `g_1, g_2 ∈ Γ`，若 `g_2 = g_1 h_i`，则在 `D_Δ(Γ)` 中存在一条标有颜色 `h_i` 的弧 `(g_1, g_2)`。如果 `h_i` 是一个 2 阶群元素（因此是自逆的）且 `g_2 = g_1 h_i`，那么必然有 `g_1 = g_2 h_i`。当凯莱色图 `D_Δ(Γ)` 同时包含弧 `(g_1, g_2)` 和 `(g_2, g_1)`，且两者都标有颜色 `h_i` 时，为了简便起见，惯例上用单条标有颜色 `h_i` 的边 `g_1 g_2` 来表示这对对称弧。正如我们现在所见，凯莱色图实际上是一个有向图，其中的每条弧都分配了一种颜色，这种颜色是 `Δ` 中的一个生成元。该有向图以数学家亚瑟·凯莱（Arthur Cayley）命名，因为他有一条群论中的著名定理：*每个有限群都同构于一个置换群*。

在进一步探讨之前，让我们通过示例来说明刚刚引入的概念。设 `Γ` 表示集合 `{1, 2, 3}` 上所有置换的对称群 `S_3`，令 `Δ = {a, b}`，其中 `a = (123)` 且 `b = (12)`。则 `Γ` 的六个元素可以表示为 `Γ` 中元素 `a` 和 `b` 的乘积，如下所示：

如果给定的具有 `n` 个元素的非平凡有限群 `Γ` 的生成集 `Δ` 被选为所有非单位元群元素的集合，那么对于 `D_Δ(Γ)` 中的任意两个顶点 `g_1, g_2`，`(g_1, g_2)` 和 `(g_2, g_1)` 都是弧（尽管不一定颜色相同），在这种情况下，`D_Δ(Γ)` 是 `n` 阶完全对称有向图 `K_n^s`。

### 保色自同构

设 `Γ` 是具有生成集 `Δ` 的非平凡有限群。凯莱色图 `D_Δ(Γ)` 的自同构群 `Aut(D_Δ(Γ))` 中的每个元素 `α` 都具有这样的性质：如果 `(g_1, g_2)` 是 `D_Δ(Γ)` 的一条弧，那么 `(α(g_1), α(g_2))` 也是 `D_Δ(Γ)` 的一条弧。如果对于 `D_Δ(Γ)` 的每一条弧 `(g_1, g_2)`，弧 `(g_1, g_2)` 和 `(α(g_1), α(g_2))` 具有相同的颜色，则称 `α` 为**保色**的。对于给定的具有生成集 `Δ` 的非平凡有限群 `Γ`，`D_Δ(Γ)` 的所有保色自同构的集合构成 `Aut(D_Δ(Γ))` 的一个子群。

例如，设 `Γ = Z_4` 是由元素 `a` 生成的 4 阶循环群。那么我们可以将 `Γ` 写为 `{g_1, g_2, g_3, g_4}`，其中对于 `i = 1,2,3,4`，有 `g_i = a^{i-1}`。因此，`g_1 = a^0 = e` 是 `Γ` 的单位元。

`Δ = {g_2, g_3, g_4} = {a, a^2, a^3}`

是 `Γ` 的非单位元元素的集合，它是 `Γ` 的一个生成集。对于这个群 `Γ` 和这个生成集 `Δ`，凯莱色图 `D_Δ(Γ)` 展示在图 9.11(a) 中。由于存在同色的对称弧对连接着顶点对 `g_1, g_3` 和 `g_2, g_4`，因此这个凯莱色图绘制如所示于图 9.11(b)。

在这种情况下，`D_Δ(Γ)` 是完全对称有向图 `K_n^*`，因此 `Aut(D_Δ(Γ))` 是**对称群 `S_n`**。由于 `Γ` 中元素的任意置换都是 `D_Δ(Γ)` 的自同构，所以置换 `α = ⟨g_1 g_2 g_4⟩` 是一个自同构。因此，`α` 将有向边 `⟨g_1, g_2⟩` 映射到有向边 `⟨g_2, g_4⟩`。由于 `⟨g_1, g_2⟩` 的颜色是 `a`，而 `⟨g_2, g_4⟩` 的颜色是 `a^2`，由此可知 `α` 不是保持颜色的。在这种情况下，`D_Δ(Γ)` 的保持颜色的自同构子群由 `ε, ⟨g_1 g_2 g_3 g_4⟩, ⟨g_1 g_3⟩⟨g_2 g_4⟩, ⟨g_1 g_4 g_3 g_2⟩` 组成，这是一个**阶为 4 的循环群**，因此与群 `Γ` 同构。我们即将看到这绝非巧合。

下一个结果（见练习 14）给出了保持颜色的自同构的一个有用特征化。

> **定理 9.4** *设* `Γ` *为非平凡有限群，其生成集为* `Δ`，*且* `α` *为* `V(D_Δ(Γ))` *的一个置换。则* `α` *是* `D_Δ(Γ)` *的保持颜色的自同构，当且仅当对每个* `g ∈ Γ` *和* `h ∈ Δ` *，有* `α(gh) = (α(g))h` *。*

借助定理 9.4，我们现在可以证明以下结果。

> **定理 9.5** *设* `Γ` *为非平凡有限群，其生成集为* `Δ`。*则* `D_Δ(Γ)` *的保持颜色的自同构群与* `Γ` *同构。*

**证明** 设 `Γ = ⟨g_1, g_2, …, g_n⟩`。对于 `i = 1, 2, …, n`，定义 `α_i : V(D_Δ(Γ)) → V(D_Δ(Γ))` 为 `α_i(g_s) = g_i g_s`，其中 `1 ≤ s ≤ n`。由于 `Γ` 是一个群，映射 `α_i` 是一一对应的且满射。设 `h ∈ Δ`。则对于每个 `i` (`1 ≤ i ≤ n`) 和每个 `s` (`1 ≤ s ≤ n`)，`α_i(g_i h) = g_i (g_i h) = (g_i g_i)h = (α_i(g_i))h`。因此，根据定理 9.4，`α_i` 是 `D_Δ(Γ)` 的保持颜色的自同构。
