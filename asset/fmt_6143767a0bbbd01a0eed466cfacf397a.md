## 通过 Synaptic 移除应用程序

要通过 Synaptic、GNOME App Install 或任何其他方法从 DEB 包安装的应用程序，可以通过以下方式之一搜索想要移除的程序：点击“搜索（Search）”按钮并输入程序名称；或者点击 Synaptic 窗口左下角的“状态（Status）”按钮，在上方窗格中点击“已安装（Installed）”，然后在右上窗格中出现的已安装软件包列表中滚动查找。一旦在列表中找到该程序，右键点击其名称，并选择“标记为完全删除（Mark for Complete Removal）”，以移除该程序及其任何设置或配置文件。当窗口提示该程序将要删除时，请仔细检查以确保你没有无意中卸载任何你感到遗憾的内容——例如你的桌面环境。假设一切看起来无误，点击“应用（Apply）”按钮，之后的流程将与安装应用程序相同。

# 通过 Synaptic 升级应用程序

如所述，你还可以使用 Synaptic 升级系统中已安装的应用程序。要执行此操作，点击 Synaptic 窗口右下角的“状态（Status）”按钮。在上方窗格中点击“已安装（可升级）[Installed (Upgradable)]”，随后右上窗格将出现有可用更新的已安装程序列表。右键点击列表中任何你想升级的程序，在弹出的菜单中选择“标记为升级（Mark for Upgrade）”。对任何其他想要升级的程序重复此右键操作，然后点击“应用（Apply）”按钮。此后的步骤将与安装软件包相同。

无论你使用哪种操作系统，你都必须处理文件。有些人非常有条理，在文件第一次被保存时，就会将其放置于一个命名符合逻辑的文件夹中。但也有一些像我这样的人，会将所有东西都保存到桌面上，直到桌面堆满了垃圾，让你再也看不清壁纸，只有在那时他们才开始认真整理（如果把所有这些文件放在一个名为“3月17日清理”的文件夹里可以叫整理的话）。唉。

当然，文件不仅存储在你的硬盘上，还会在 CD、DVD、外部硬盘、优 盘以及其他存储介质和设备之间进行复制。它们还经常被保存在压缩包中，然后通过压缩来减小空间占用，使其更易通过电子邮件发送，或者放入存储空间受限的可移动存储介质中。

有了这些介绍，你可能已经猜到在本章中，我将处理 Ubuntu 中的文件操作，特别是与 Nautilus 文件管理器相关的内容， Nautilus 是 GNOME 文件处理能力的核心。

## Nautilus：你的文件管理器

正如我提到的，在系统中创建文件查看和组织界面的程序被称为 Nautilus，它是作为 GNOME 桌面环境的一部分提供的。你以前可能没有想过操作系统的文件管理器也是一个程序，但事实上，它就是这样一个程序。（Windows 的文件管理器被称为 Windows 资源管理器。）要查看 Nautilus，只需进入“位置”（Places）菜单，并选择“主文件夹”（Home Folder）。

当 Nautilus 打开你的主文件夹时，你第一次看到应该会发现除了一个名为“桌面”（Desktop）的文件夹（如图 6-1 所示）外无其他，双击该文件夹将显示你存储在那的所有内容（对我来说有很多；很可能你也是如此）。另一个名为“示例”（Examples）的文件夹，它与 Ubuntu 从离线光盘启动时出现的那个相同。它包含了一些示例文件，让你了解 Ubuntu 为你提供了什么，以及我在第 3 章提到的尼尔森·曼德拉的视频。

你可以创建额外的文件夹，而且可以随心所欲，这样当你真正开始使用系统时，那种极其简陋的状态就会改变。事实上，你将在第 7 章中创建许多文件夹，这会让一切变得更有生活气息。

### 侧边栏

Nautilus 有许多值得提及的功能，其中最明显的是侧边栏，它出现在窗口的左侧。侧边栏允许你通过可选的视图查看各种信息。你可以通过点击侧边栏顶部的下拉菜单做出选择（图 6-2）。

![](img/ba6b82a7869bba748202d57c97336dca_100_0.png)

图 6-2：为 Nautilus 侧边栏选择视图

Ubuntu 的默认视图是“位置”（Places），是一种快速导航工具。在“位置”中，你会找到代表系统可用各种数据存储位置的图标，例如你的主文件夹、桌面、整个文件系统、你连接的任何网络共享（稍后会介绍），以及你系统中或连接到系统的任何移除介质或设备。双击这些图标中的任何一个会在 Nautilus 窗口的右面板显示该位置的内容。

当然，还有其他视图，例如“树”（Tree），它为你提供了一个可扩展的文件系统分级视图；以及“历史”（History），它显示了你最近在文件系统中的位置，就像网络浏览器中的历史功能一样。仍然有其他视图供你选择，其中几个将在第 7 章中用到。
