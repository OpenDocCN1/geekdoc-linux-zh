> 注意 — 在 `test` 中，`-a` 的优先级高于 `-o`，`&&` 和 `||` 在 `shell` 中优先级相等。

你可以在 `shell` 命令语言中使用括号或大括号进行分组。在使用 `sh` 时，必须转义括号；例如：

```
test \( expr1 - expr2 \) -o expr3
```

此命令在所有系统中总是移植的。相反，你可以使用以下形式：

```
( test expr1 && expr2 ) || expr3
```

以下命令在某些系统中无法可靠地使用：

```
test "$1"
test "$1"
```

如果使用了字符串条件且 `$1` 扩展为已知原始操作，会发生未定义的结果。更好的构造是：

```
test -n "$1"
test -z "$1"
```

历史系统在常用的 `test "$response" = "expected string"` 构造上不可靠。以下是更可靠的格式：

```
test "$response" = "expected string"
```

注意 `"expected string"` 可能与任何原始操作混淆。如果 `"expected string"` 以 `(` 或甚至 `=` 开头，则使用第一个原始操作。在字符串比较中， `=` 和 `!=` 的优先级高于任何原始操作。在参数情况下，如果 `$1` 评估为一个可能的目录名，遇到第二个 `-d` 时将显示语法错误。

```
test -d $1 -o -d
```

以下格式之一可以防止此问题；优选第二个：

```
test "$1" -o -d test "$1" || test -d
```
