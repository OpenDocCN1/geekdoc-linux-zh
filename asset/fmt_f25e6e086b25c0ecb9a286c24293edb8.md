4.6 程序如下：

```java
// 计算 1 到 10 的整数之和
public class Calculate {
    public static void main(String[] args) {
        int sum;
        int x;
        x = 1; // 为了计数初始化 x 为 1
        sum = 0; // 为了求和初始化 sum 为 0
        while (x <= 10) // 当 x 小于等于 10 时
            sum += x; // 将 x 加到 sum
            x++; // x 加 1
        }
        System.out.printf("The sum is: %d\n", sum);
    }
}
// 结束类 Calculate
```
The sum is: 55
