## 06 404 未找到
对于任何服务器，都会有人点错或人们迷路。如果是这样，我们该如何处理？通过定义路由（`route`），我们可以定义一个处理获取请求的处理器。

```python
@app.route('/404')
def four_oh_four():
    return render_template('fourfour.html')
```

如果请求了一个端点且存在 404，我们的函数将被触发。在这种情况下，我们将生成一个告诉用户的模板，但也可以重定向到另一个页面或输出错误消息。
