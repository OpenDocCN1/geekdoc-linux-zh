# 步骤 2
当你回答问题时，`wp_sap` 会被赋予一个值。使用 `cookie` 管理器并将其更改为如下所示载荷：
```
["1650149780") OR=1 UNION SELECT 1,2,3,4,5,6,7,8,9@version,11#"]
```

"OR" 语句必须是 `1=2`，这一点很重要。因为应用程序会反映查询结果结果。当你设置为 `1=1` 时，你应该看到来自来自 记录的问题。因此，OR 语句必须返回 False。
