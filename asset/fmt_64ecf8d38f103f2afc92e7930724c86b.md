
# 3.1 扩展样条与NURBS

除了 Shapes 工具创建的 `Splines` 组外，还有 `NURBS` 和一个名为扩展样条（Extended Splines）的新库，它们由常见的截面组成。当 `Shapes` 按钮激活时，可以从下拉列表中访问 `NURBS` 和扩展样条。`NURBS` 在附录 C 中略有介绍，而扩展样条类型和选项在表 3.3 中讨论。

## 表 3.3: 扩展样条的创建方法

| 样条名称和功能 | 创建方法 | 创建选项* | 参数* |
| :--- | :--- | :--- | :--- |
| `Star`—绘制星形 | 点击中心并拖动第一个半径；再次点击第二个半径。 | `Radius 1`, `Radius 2`, [number of] `Points`, [distortion], `Fillet Radius 1`, 2. |
| `Helix`—绘制三螺旋线 | 点击第一个圆周，拖动第二个圆周，点击高度，点击第二个半径。或点击中心，拖动第一个半径，点击高度，点击第二个半径。 | `Radius 1`, `Height`, `Turns`, `CW` [顺时针]/ `CCW` [逆时针]。 |
| `Rectangle`—绘制带或无圆角的矩形样条 | 点击第一个角并拖动另一个角；点击内偏移 [Edge]。点击中心并拖动角，点击内偏移 [Center]。 | `Edge`/`Center` | `Length`, `Width`, `Thickness`, `Sync Corner Fillets`, `Corner Radius 1`, 2. |
| `Angle`—绘制“L”形 | 点击第一个角并拖动另一个角；点击内偏移 [Edge]。点击中心并拖动角，点击内偏移 [Center]。 | `Edge`/`Center` | `Length`, `Width`, `Thickness`, `Sync Corner Fillets`, `Corner Radius 1`, 2, `Edge Radii`. |
| `Wide Flange`—绘制“I”形 | 点击第一个角并拖动另一个角；点击内偏移 [Edge]。点击中心并拖动角；点击内偏移 [Center]。 | `Edge`/`Center` | `Length`, `Width`, `Thickness`, `Radius`. |
| `Channel`—绘制“C”形 | 点击第一个角并拖动另一个角；点击内偏移 [Edge]。点击中心并拖动角，点击内偏移 [Center]。 | `Edge`/`Center` | `Length`, `Width`, `Thickness`, `Fillets`, `Corner Radius 1`, 2. |
| `Tee`—绘制“T”形 | 点击第一个角并拖动另一个角；点击内偏移 [Edge]。点击中心并拖动角，点击内偏移 [Center]。 | `Edge`/`Center` | `Length`, `Width`, `Thickness`, `Radius`. |

## 3.2 编辑样条

你已经可以通过命令面板的修改（`Modify`）选项卡编辑矩形和直线。在大多数情况下，你需要通过修改器列表（`Modifier List`）下拉列表选择样条编辑（`Edit Spline`）修改器，以访问样条的子对象级，那里通常显示参数化控制。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_185_0.png)

此处的例外是直线（`Line`）样条，一旦选择修改选项卡，它就会显示其子对象级选项。

一旦你选择了样条编辑（`Edit Spline`），你就可以在修改器对应的对象级别，对顶点、段或样条进行更改。你甚至可以附加或分离样条的组件来创建新形状，正如你接下来将看到的。

访问样条子对象级的另一种方法将其转换为可编辑样条（`editable spline`）。这可以通过右键点击修改器堆中的对象名称并从快捷菜单中选择“转换为：编辑样条（`Convert To: Edit Spline`）”，或者右键点击视口并在四角菜单（`quad menu`）中选择“转换为 > 编辑样条（`Convert To > Edit Spline`）”。

![](img/7e143440dd5a0ed9683d4f26f3c07f8_186_0.png)

这种方法以类似于样条编辑修改器的方式暴露所选样条的子对象级，但它是通过永久将样条转换为可编辑样条来实现的。样条随后会失去参数化功能。

在使用样条编辑修改器修改样条对象后（特别是添加或删除了顶点后），在顶层级编辑样条可能会产生不可预测的结果。因此，转换为可编辑样条是有益的。

### 转换为可编辑样条节省内存

折叠为编辑样条可以节省内存。当你将样条转换为可编辑样条时，你获得了自由移动顶点的自由，这在编辑修改器中实现。但这对于创建复杂的形状来说非常耗时，因此最好保持样条为参数化。

## 3.3 放置和倒角文本

文本具有文字处理软件中的许多功能。文本可以对齐、加粗和斜体；字间距可以调整（`kerning`）；行间距可以调整（`leading`）。

你可能注意到在创建对象时，它们是相对于网格分布的。这种网格功能通过勾选对象类型（`Object Type`）中的网格框来实现。

1. 选择文件（`File`）> 打开 `Signage.max` 文件。该文件由一个带圆边的矩形组成，如图3.45所示。
2. 点击命令面板中的创建（`Create`）> 形状（`Shapes`）> 样条（`Splines`）。
3. 点击对象类型按钮，然后勾选网格（`AutoGrid`）框。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_187_0.png)

4. 将光标悬在标志牌上，注意轴会相对于光标所在的面，如图3.46所示。
5. 在标志牌中心部分点击鼠标，在场景和标志子上放置默认的“`VIZ Text`”文本。文本已创建，但尺寸太大（见图3.47）。取消勾选网格。
6. 在参数（`Parameters`）滚动栏中，从下拉列表中选择字体，然后调整尺寸（`Size`）值将文本更改为合适的大小。选择文本字段中的内容并替换为你希望出现在标志牌上的文字。

### 新形状选项

你可能注意到样条对象类型顶部的新形状（`New Shape`）选项。当取消勾选此选项时，每个创建形状将成为更大样条对象的样条子对象，而不是独立的参数化样条对象。该选项的默认状态是勾选的。

当对字体应用修改器时，不同的字体会产生不同的结果。这通常是因为使用了转角紧凑或区域狭窄的字体，在对文本进行倒角处理时，使其强制相互交叉。在其他情况下，由于字体设计不佳，在挤出（`Extrude`）或倒角时效果不佳。本练习使用了 `Book Antiqua Bold` 字体，并将 `Size` 参数设置为 `23.0"`。

### 熟悉字体选项

在 `Parameters`（参数）面板中高亮字体，使用向上和向下方向键循环字体，并观察每个字体在视口中的显示。如果你使用数字键盘上的箭头键，请确保没有开启数字锁定（`Num Lock`）。

文本假设了你分配的特征，但它在标牌上的位置太低了。要移动它，必须正确使用 `Local`（局部）引用坐标系，该系统使用所选对象的 `X`、`Y` 和 `Z` 方向，而不是 `World` 坐标系。

1. 点击主工具栏中的 `Select and Move`（选择并移动）按钮。在变换工具的右侧，展开 `Reference coordinate System`（引用坐标系）下拉列表并选择 `Local`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_190_0.png)

2. 选择文本，注意 `Move` 变换手柄（`gizmo`）已对齐文本。将光标置于 `Y` 轴上，并将文本移动到合适位置。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_190_1.png)
