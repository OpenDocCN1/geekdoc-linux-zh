
# 使用安全增强型 Linux（真正实用）
虽然 `SELinux` 已包含在 Fedora Core 2 中，但直到 Fedora Core 3，`SELinux` 才对大多数人变得有用。默认情况下，Fedora Core 3 提供配置好的 `SELinux`，旨在以保护整个 Linux 系统的方式对几个关键服务（Web 服务、DNS 服务和其他）进行隔离。有关 Fedora Core 3 中 `SELinux` 的描述，请参见第 28 章。

# 从其他媒体安装 Fedora
当 2.6 内核的体积大到你无法从软盘引导 Fedora 安装过程时，Fedora 项目添加了可用于 mini-boot CD 或 USB 闪存盘引导的镜像。在第 1 章中，我描述了如何从这些媒体启动 Fedora Core 3 安装，以及如何执行 `VNC` 安装（这样你可以从另一台计算机的桌面安装 FC3）。

# 调整大小以腾出 Fedora 空间
在本版本中，我删除了对名为 `FIPS` 的工具的描述（我将其移至我们的网站 `www.wiley.com/go/fedora3bible`），该工具用于调整硬盘大小。它主要适用于具有 FAT 或 VFAT 文件系统的旧版 Windows 操作系统，如 Windows 95 或 98。由于 Fedora 最近弃用了 `FIPS`，并且大多数人拥有具有 NTFS 文件系统的 Windows XP 操作系统，我描述了如何使用一些第三方工具调整一个 NTFS 分区的大小（Fedora 不包含我描述的 `oparted` 工具）。在继续之前，请阅读第 1 章中的说明（包括注意事项）。

# 管理可移动介质
当你插入可移动介质（CD、DVD 或软盘）或连接热插拔设备（闪存盘、USB 硬盘或数码相机）时，Fedora 现在设置为自动将它们挂载到 `/media` 目录下。在 Fedora Core 3 之前，可移动介质主要挂载在 `/mnt` 目录下（例如 `/mnt/cdrom`）。第 3 章描述了如何使用 `GNOME` 卷管理器设置可移动介质的挂载方式，以及可选地与选定的应用程序一起打开它们。

# 使用新的 GNOME 面板
第 3 章展示并描述了默认 `GNOME` 桌面的新布局。`GNOME` 桌面不再是一个底部面板，而是有细的顶部和底部面板。此外，面板上不再是单一的红帽菜单，应用程序列在顶部面板的应用程序和操作按钮下。

# 运行桌面工具
为了让你不必使用太多命令，`GNOME` 和 `KDE` 继续提供更多图形工具来执行常见任务。第 3 章中描述的一个此类工具的示例是 `GNOME` 网络工具窗口，它允许你以图形方式运行 `ping`、`traceroute`、`DNS` 查找以及通常用 shell 命令完成的其他常见网络操作。

# 本书的组织结构

本书分为五个部分。

# 第一部分：Fedora 入门

第一部分包含第 1 章至第 4 章。第 1 章和第 2 章简要介绍了 Linux 技术，并告知您安装操作系统所需的内容。第 1 章作为 Linux 操作系统及 Fedora 的入门介绍。我还特别关注 Red Hat, Inc. 公司在 Fedora 项目和 Red Hat Enterprise Linux 之间的划分。第 2 章讨论安装 Fedora 所需的内容，以及您在安装过程中将面临哪些决策。其中包括通过 DVD、CD-ROM、硬盘或网络连接（NFS、FTP 或 HTTP 服务器）进行安装的操作步骤。

在第 3 章中，您将了解 `GNOME` 桌面环境、`KDE` 桌面环境以及 X 窗口系统。这些图形用户界面提供了使用 Fedora 的图形化方式。第 4 章描述了探索和理解 Fedora 的方法，主要通过 Linux Shell 命令解释器进行。您将学习如何使用 `bash` shell、`vi` 文本编辑器以及用于在 Linux 文件系统中移动的的命令。

# 第二部分：使用 Fedora

第二部分包含第 5 章至第 9 章，内容为希望使用 Linux 运行应用程序和访问互联网的普通用户提供信息。

第 5 章包含有关获取、安装和运行 Linux 应用程序的信息。它还帮助您在 Linux 中运行来自其他操作系统的应用程序。第 6 章既描述了传统的出版工具，也描述了随 Fedora 提供的新图形化文字处理器。旧工具包括 `troff` 和 `TeX` 文本处理工具，而较新的出版软件包括 `OpenOffice.org` 实用程序（包含在 DVD 上）和 `StarOffice`（商业版本）。

第 7 章描述了在 Fedora 中运行的图形和字符类游戏。本章还描述了如何使用 `Cedega` 运行商业 Windows 游戏，以及商业 Linux 游戏，例如《文明：权力呼唤》（Civilization: Call to Power）和《神话 II》（Myth II），其中一些游戏有演示版本可用。第 8 章描述了如何使用音频和视频播放器，以及如何配置声卡和 CD 刻录机。第 9 章描述了浏览网页的工具（如 Mozilla 浏览器）及相关工具（如电子邮件客户端和新闻阅读器）。
