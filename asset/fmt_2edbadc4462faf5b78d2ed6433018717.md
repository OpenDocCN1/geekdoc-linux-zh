# LINUX 网页管理员指南，版本 0.201

# LINUX 快捷键与命令

* `zgv my_picture`
  在 `vga` 屏幕上显示图片（无需 `X` 窗口）。

* `giftopnm my_file.gif > my_file.png`
  `pntopnm my_file.png > my_file.jpg`
  将专有图形格式转换为原始的、移植的 `pnm` 文件。然后将 `pnm` 转换为 `png` 文件。从技术上讲，`png` 是更新、更好的互联网图片标准（而且不用担心被 `gif` 专利所有者起诉）。

* `xwd my_capture_screen.file.xdw`
  （在终端中）将 `X` 窗口的内容转换为图形 `X` “转储”文件（`*.xdw`）。你可以使用 `KDE` 的 `kwide` 工具将 `xdw` 文件转换为你喜欢的格式。你也可以使用快捷键 `Alt+PrintScreen` 或 `<ctrl><Alt>PrintScreen` 将当前窗口或桌面复制到剪贴板。

* `convert my_capture_screen.file.xdw my_capture_screen.jpg`
  将 `X` 窗口转储文件（`*.xdw`）转换为 `*.jpg` 文件格式。该工具可以将根图形转换为许多不同的格式。

* 将 `X` 的根内容捕获到 `192.105.2.100` 显示 `0` 的图形 `X` 根上。输出文件为 `my_file.jpg`（通过提供适当的文件扩展名来更改文件名）。你需要拥有写入屏幕的权限才能捕获其内容（通过在 `X` 终端运行 `root +` 来获得权限）。请参见 `man import` 选项。

* `snapshot`
  （在终端中）基于 `GUI` 的捕获屏幕内容的工具。

* `ine frankensteinstein.avi &`
  （在终端中）观看文件 `frankenstein.avi` 中的电影。看起来比在电视上更好看：))

## 7.2 OpenOffice / 套件

这包含了文字处理器、电子表格、演示文稿、绘图程序和数学公式。它是由一家公司专门读取的数据格式。这种文件格式可以使用第三方工具解析。

**描述：** `OpenOffice` 看起来和操作就像 `Windows` 上的 `MS Office`。这功能丰富、体积大（需要大量的...）。`OpenOffice` 不像某些替代方案那样“漂亮”。它是一个真正的生产力工具，而且改进迅速。简而言之，我们推荐 `StarOffice/OpenOffice` 来满足所有严苛的需求。功能上，它涵盖了 `MS Word` 的内容（尽管有对应的 `Excel`），并增加了一些 `MS Office` 没有的额外功能。

**安装：** `OpenOffice/StarOffice` 的安装很复杂。步骤如下：

* 确保你有足够的磁盘空间。使用命令检查空间：

```bash
df -h
```

这将以人类可读的形式报告已用和可用磁盘空间（选项 `-h`）。至少需要 350 MB 的磁盘空间（安装后可以释放其中 100 MB）。

* 解压下载的文件。我在 `/usr/local` 目录下进行了“本地服务器”安装，但你也可以选择 `/home/your_login` 进行“个人”安装：

```bash
cd /usr/local
tar -xvf StarOffice5.2.tgz
```

# 重要的 LINUX 应用程序

* 将文件名 `StarOffice5.2.tgz` 替换为你下载的文件。
  以 `root` 身份，使用 DOS 风格的 `/net` 选项运行本地“服务器”设置：

```bash
cd /usr/local/OpenOffice64
./setup /net
```

使用 `/net` 或 `-net` 选项，`OpenOffice` 将执行个人安装（到你的主目录中！），这样只有一个用户能够运行它，而且你的主目录会被塞满。

* 在此“网络”安装之后，每个用户必须执行自己的安装，将文件夹放入他们的“家”目录。这是通过运行以下命令实现的（以用户身份，不带 `/net` 选项）：

```bash
cd /usr/local/OpenOffice64
./setup
```
