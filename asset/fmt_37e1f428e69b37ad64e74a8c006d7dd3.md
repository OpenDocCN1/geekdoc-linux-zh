
你可以尝试许多其他设置。有一项你不应该触碰的设置是 HTML 邮件设置。默认情况下，`KMail`表现良好并发送纯文本电子邮件。我们喜欢纯文本电子邮件，因为它能包含文字。你可以配置`KMail`发送 HTML 邮件，但它会带来 HTML 邮件固有的问题。直接去那里看看吧！

`KMail`的工具栏起初可能会让人困惑。只需将鼠标悬停在按钮上，你就能看到该功能的实际描述。例如，那个看起来像折角的纸、前面有一个信封的按钮就是“新消息”按钮。除此之外，使用`KMail`与任何其他邮件程序大无异。

# 使用 Evolution 邮件

将`Evolution`作为邮件客户端而不使用它的任何其他功能可能可能是愚蠢的。它非常惊人。它无所不能。它可能还有一个隐藏的“带来世界和平”菜单项。它能处理日历；它无所不能。但如果你无法在里面读取邮件，谁会在乎呢？等你的邮件运行起来后，你就可以从容探索其他功能。

按照以下步骤在`Evolution`中设置邮件：

- 1. 选择`Tools`:`Settings`。

打开“设置”窗口。

- 2. 点击左侧的“`Mail Accounts`”按钮。

- 3. 点击窗口右侧的“`Add`”按钮。

启动一个向导，它与`Mozilla`用于向你提问所需问题的向导相似。

- 4. 点击“`Next`”。

- 5. 输入你的姓名和电子邮件，然后点击“`Next`”。

“`Reply-To`”和“`Organization`”字段是可选的。组织通常是指你所属的机构——如果是工作邮件，则是你的雇主。“回复至”是一个特殊的表头，用于告诉人们向哪里回复你的邮件。只有当你想要将回复发送到输入电子邮件地址以外的地址时才设置它，而你可能没有理由这样做。

- 6. 从服务器类型的弹出列表中选择`POP`选项。

出现新字段。

- 7. 输入你的主机名和账户名，然后点击“`Next`”。

一如既往，主机名是你的 ISP 提供的，是入站邮件服务器。如果你的 ISP 要求或支持 SSL 连接，你可以更改“`Secure Connection`”选项，但大多数 ISP 不支持。一如既往，我们不建议让程序记住你的密码。习惯输入它。`Evolution`支持多种身份验证类型。你可能不需要了解这些：大多数适用于密码。如果似乎有问题，尝试点击“`Check for Supported Types`”按钮。（此按钮在你输入主机名后才可用）。

- 8. 如果需要，可以更改设置，然后点击“`Next`”。

这些设置最好保持原样。自动检查邮件可能会非常烦人。只有当你使用多个邮件客户端并想多次阅读邮件时，将邮件留在服务器上才有用。

- 9. 输入你的发件邮件服务器名称，然后点击“`Next`”。

这和之前的步骤是一样的。同样，`Evolution`有许多选项。如果你的 ISP 要求在 SMTP 之前使用 POP；这是在此面板输入的地方；请勾选“`Server Requires Authentication`”选项，并在弹出列表中选择“`POP before SMTP`”。

- 10. 为此账户命名，将其设为默认账户，并点击“`Next`”。

这类似于`Mozilla`中的账户名称——任何你喜欢的名称都可以。很多人喜欢像“工作”或“家里”这样的创意名称。如果这是你唯一的账户，你可以勾选“`Make My Default Account`”复选框。

- 11. 点击“`Finish`”。

好了！你完成了。

你可以关闭“设置”窗口并开始检查和阅读邮件。`Evolution`有一个按钮用于发送发件邮件和获取收件邮件。此功能允许你在撰写回复并在尝试发送它们时立即获取新邮件。如果你和足够的人往来邮件，你可能再也不用工作了！
