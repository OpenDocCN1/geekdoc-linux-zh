FIFO 调度器：

- 1. 启动 `timidity`

2. 打开一个 root 控制台话。

3. 使用 `pidof timidity` 找到 `timidity` 的进程 ID (PID)。

4. 使用命令 `setpriority <processID> fifo 10` 修改调度器。

你可以在 root shell 中使用以下命令来加速此过程：

```bash
for i in $(pidof timidity); do setpriority $i fifo 10; done
```

以 root 模式运行程序始终是有风险的，因为程序被允许执行任何操作。如果计算机连接到互联网，这种安全风险将是不可接受的。程序中的安全漏洞可能会被用于获取系统的访问权限。

## 注意

后续段落中描述的命令绝不应在可以通过互联网访问的机器上执行，或者在系统崩溃或数据丢失将导致严重后果的系统中执行。

以 root 模式运行程序应使用 `sudo` 机制。这种机制通过 `timidity++` 应用得到了演示。要让你系统上的所有用户都能以 root 权限执行 `timidity++`，请修改 `/etc/sudoers` 文件。具体步骤请参见手册。如果你不熟悉 `vi`，可以通过导出所需的编辑器来选择不同的编辑器（例如 `joe`），例如使用 `export EDITOR=joe`。然后以 root 身份执行 `visudo`，并将以下行附加到 `/etc/sudoers` 文件的末尾：

```
ALL ALL=(ALL)/usr/bin/timidity
```

现在，所有系统用户都被允许通过命令 `sudo timidity` 以 root 模式运行 `timidity++`。如果距离上一次 `sudo` 命令已超过五分钟，则会要求输入用户的密码。

## 19.5 JACK 音频连接套件

使用 JACK Audio Connection Kit（软件包名为 `jack` 和 `qjackconnect`），应用程序可以相互以及与声卡交换音频数据。只有当应用程序具有 JACK 接口时，这种交换才是可能的。JACK 支持已成为一项标准功能，因此有许多需要该接口的应用程序。

要使用 JACK，首先通过 `jackd -d alsa -d hw:0` 启动引擎。JACK 设计旨在实现具有实时优先级的低延迟。欲更多信息，请阅读文件 `/usr/share/doc/jack/README`。

接线器软件 QJackConnect 帮助跟踪系统中运行的所有客户端。在启动 `qjackconnect` 程序后，具有可读端口的客户端列在左侧，具有可写端口的客户端列在右侧。如果没有启动 JACK 客户端，列表将仅显示声卡的输入和输出。通过从列表中选择端口来连接单个端口，或通过选择客户端来同时连接多个端口。

## 19.6 使用 Audacity 进行硬盘录制

使用 `audacity`（软件包 `audacity`）录制和编辑音频文件。这被称为硬盘录制。当你第一次启动程序时，选择接口。在其他时候，可以在“文件 (File)”->“偏好 (Preferences)”下更改设置。更改将在下一次启动程序时生效。（img/705a076b108ea96be0c695efb556ce_330.png）

图 19.10：音频数据的频谱视图

### 19.6.1 录制文件和导入文件

点击红色按钮生成一个空的立体声轨道并开始录制。若要更改标准参数，请在“文件 (File)”->“偏好 (Preferences)”下指定设置。“音频 (Audio/O)”和“质量 (Quality)”对录制非常重要。即使轨道已经存在，按下录制按钮也会创建新轨道。起这可能会令人困惑，因为这些轨道在标准窗口中是可见的。

要导入音频文件，选择“项目 (Project)”->“导入音频 (Import Audio)”。程序支持 WAV 格式以及压缩的 MP3 和 Ogg Vorbis 格式。关于这些格式的更多信息，请参见第 314 页的第 19.8 节。

### 19.6.2 编辑音频文件

每个轨道左侧可以打开“轨道 (Track)”菜单并提供多种视图。其中一种是“波形 DB (Waveform DB)”，它不适合检查调试，因为在此视图中数据始终调整为轨道的最大幅度。

根据应用程序的不同，“选择格式 (Selection Format)”下提供了用于片段选择的各种视图格式。通过“对齐模式 (Snap-To Mode)”，边界可以自动适应所选视图格式。例如，如果你选择“帧 (frames)”作为视图格式并选择“对齐 (Snap-To)”，边界将始终以帧的倍数选取。

许多编辑工具都配备了工具提示，应该非常容易使用。通过“视图 (View)”->“历史 (History)”可以访问“撤销 (Undo)”功能，这是一个用于查看最近编辑步骤并通过点击列表中的相应项目来撤销操作的有用功能。请谨慎使用“丢弃 (Discard)”，因为它会删除列表中的编辑步骤。此后，这些步骤将无法撤销。

内置的频谱分析仪有助于快速跟踪任何噪声。通过“视图 (View)”->“绘制频谱 (Plot Spectrum)”查看所选片段。使用“对数频率 (Log frequency)”选择以八度为单位的对数频率刻。如果你在频谱内移动鼠标指针，频率将自动显示相应的音符。

不需要的频率最好通过“效果 (Effect)”->“FFT 过滤器 (FFT Filter)”删除。在过滤过程中，可能需要使用“放大 (Amplify)”重新调整信号幅度。此外，“放大”可以检查幅度。默认，“新峰值 (New Peak Amplitude)”设置为 0.0 dB。此值代表所选音频格式中可能的最高幅度。“放大 (Amplification)”显示了放大所选片段所需的值。负值表示放大过度。
