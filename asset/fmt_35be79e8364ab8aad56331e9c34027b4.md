# 5 Linux 新手管理员常见问题解答

## 5.1 启动问题 (LILO 和 GRUB)

### 5.1.1 LILO 和 GRUB

`GRUB`和另一个都是引导加载程序。它们让你能够在引导启动时选择操作系统。本节中描述的大多数（或所有？）启动过程都可以通过安装最新的 Linux 内核和最新版本的`GRUB`引导加载程序来解决。`GRUB`与`LILO`不同。`LILO`依赖于绝对硬盘地址来查找启动镜像，而`GRUB`理解文件系统并查找包含启动镜像的文件。我们建议在安装过程中有选择选择时使用`GRUB`。

主要的`GRUB`配置文件是`/boot/grub.conf`（或`/boot/`，在我的系统上有一个指向它的符号链接）。以下是对该文件中包含的项目的一些注释：

- # 以 # 标记开头的都是注释。
`timeout 5`
- # 上述设置将在按下按键之前在 5 秒后启动默认操作系统
`default 0`
- # 上述设置使默认操作系统成为菜单列表的第一项。

可以使用`Default "3"`让第 4 个项目成为默认项。

```
title linux
kernel(hd0,2)/vmlinuz-root=/dev/sda1 root=64 hdc=ide-scsi
# 上述行定义了一个启动菜单项，并为该项设置了启动动作。
# 第一行将菜单项命名为 "linux"。
# 第二行指定内核位于第一块物理硬盘 (hd0)，第三个分区 (2)，启动镜像是文件 /boot/vmlinuz
```

同样在第二行中，以下选项被传递给内核：

- `/root=/dev/hda` (即将根分区设置为第一块硬盘 (hda) 上的第 3 个分区)
- `mem=64m` (即强制使用 64 兆物理内存)。
- `hd-ide-scsi` (即在我的 CD-ROM 上使用 SCSI 模拟，因为是一台 CD 刻录机)。

```
/root=/dev/disk
initrd/boot/initrd-2.4.17-custom.img
# 定义启动时包含模块的文件，因为模块加载到根目录
# 我必须重新创建我的（因为我重新编译了内核），使用 mkinitrd /boot/initrd-2.4-10-custom.img 2.4.7-custom
```

可以使用`info grub`获取关于`GRUB`的良性文档。

### 5.1.2 LILO 显示 LI (或 LIL) 并挂起

我引用自我那本非常好的手册《RedHat Unleashed》，由 Kamran Hussain, Timothy Parker 等人编写，SAMS 出版：

“当 LILO 加载时，它会显示 LILO。每个字母在执行某些操作之前或之后打印。如果 LILO 在某处失败，到为止打印的字母可以识别问题。”

- `LI [...]` 这可能是由于几何结构不匹配，或者是由于在没有运行 map 安装程序的情况下移动了`/etc/lilo/boot.b`。
- `LIL [...]` 这通常是由介质故障或几何结构不匹配引起的。几何结构意味着你的 BIOS 硬盘配置中使用的扇区/磁头/柱面数。祝你好好运！

拥有一本 LILO 手册或至少有一本优秀的 UNIX 手册是非常明智的主意。Windows 的手册是没用的，但它们很很棒！《RedHat Unleashed》是一本非常好的手册，但我确定有同样优秀的手册。

遇到像上面的 LILO 错误，你可以使用 Linux 或 DOS 启动软盘启动你的机器。

修正 LILO 错误似乎有几种通用可能，取决于具体情况：

1. 如果 LILO 损坏了（看起来并不常见），你可以删除并重新安装它。

可以使用 Linux 移除 LILO：

```
lilo -u /dev/sda
```

或者在 DOS 下：

```
fdisk /mbr
```

这会重写主引导记录 (MBR)，LILO 所在的磁盘，从 DOS 启动。

在删除 LILO 后重启系统，可以运行`lilo`重新安装 LILO。

2. 指定选项

在`/etc/lilo.conf`顶部指定。对于大硬盘 (>8 GB)，这特别有用。

`lilo.conf="linear"` 是安全的——不会影响正常系统，默认启动`/etc/lilo.conf`中出现的第一个 label。

你可能还想对 BIOS 硬盘的方式进行尝试。例如，对于 LBA（linear 或 large 块访问）模式。

3. 查看你的 BIOS 设置，找出指定的几何结构不匹配的原因。在 Linux 下，可以使用以下命令显示的几何结构（对于第一个 IDE 硬盘）：

```
hdparm -g /dev/hda
```

4. 将 LILO 放在另一个分区（硬盘），并使该分区可引导（如果你的系统支持）。

5. 你可能更喜欢使用`loadlin`而不是 lieu。在 DOS 下，定位 CDROM 并查看程序`dosutils/loadlin`。从 DOS 启动。

6. 移除 LILO 并使用 GRUB 作为默认。

### 5.1.3 如何更改 LILO 启动的操作系统？

这可以在 lilo 配置文件`/etc/lilo.conf`中设置。我的（lilo 版本 0.21.5-4M）看起来如下：

```
boot=/dev/hda
map=/boot
install=/boot/boot.b
vga=normal
default=linux
keytable=/boot/us.klt
lba32
prom
timeout=50
message=/boot/message
menu-scheme=bw:bw:bw
image=/vmlinuz
label=linux
root=/dev/hda3
append="mem=96M"
read-only
image=/vmlinuz
label=failsafe
root=/dev/hd3
append="mem=96M failsafe"
read-only
image=/dev/hd1
label=windows
table=/dev/hda
other=/dev/fd0
label=loppy
```

四个 "label=" 条定义了启动选项的名称。默认启动操作系统由文件顶部的 "default=" 指定。如果没有 "default"，则启动 `/etc/lilo.conf` 中第一个 label。
