## 在内存和寄存器中递增/递减数字

在伪代码中，它看起来很简单，意味着递增（递减）存储在位置（地址）“`a`”的数字：

+ `[a] <- [a] + 1`

`[a] < [a] - 1`

在 C 或 C++ 语言中，我们可以三种可能的方式编写它：

```
a = a + 1;
++a;
a++;
b = b - 1;
--b;
b--;
```

在汇编语言中，我们使用指令 `ADD` 和 `SUB`，并写道：

```
add x0, x0, #1
sub x0, x0, #1
adr x0, a

add w1, w1, #1
str w1, [x0]
adr x0, b
ldr w1, [x0]
sub w1, w1, #1
str w1, [x0]
```

## 数字乘法

在伪代码中，它看起来很简单，意味着乘以存储在位置（地址）“`b`”的数字：

+ `[b] <- [b] * [a]`

在 C 或 C++ 语言中，我们可以这样写：

```
b = b * a;
```

在汇编语言中，我们使用 `MUL` 指令并写道：

```
adr x0, b
ldr w1, [x0]
adr x0, a
ldr w0, [x0]
mul w1, w1, w0
adr x0, b
str w1, [x0]
```

在 GDB 反汇编输出中，我们可能会看到以下代码：

```

add x0, x0, #0xb00
ldr w1, [x0]
adrp x0, 0x4b2000
add x0, x0, #0xb04
ldr w0, [x0]
mul w1, w1, w0
adrp x0, 0x4b2000
add x0, x0, #0xb04
str w1, [x0]
```
