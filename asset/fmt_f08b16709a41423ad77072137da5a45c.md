## echo

> 注意 — 提供 `-n` 选项是为了 BSD 应用的过渡，可能在未来的版本中不再支持。

Korn shell 的 `echo` 命令没有 `-n` 选项来抑制显示末尾换行。`/usr/bin/echo` 和 Bourne shell `echo` 命令仅在设置了 `SYS` 环境变量时才具有 `-n` 选项。如果设置了，则所有反斜杠字符均不可用。另一方面，`/usr/ucb/echo` 和 C shell 的 `echo` 命令具有 `-n` 选项，但不理解反斜杠转义字符。

### 操作数

`string`

要写入标准输出的字符串。对于 `/usr/bin/echo`，如果任何操作数为 `-n`，它将被视为字符串而不是选项。

## `/usr/bin/echo`

在任何参数中都会识别以下字符序列：

- `\a` 警报字符。
- `\b` 退格符。
- `\c` 不换行打印行。
- `\f` 换页符。
- `\n` 换行。
- `\r` 回车。
- `\t` 制表符。
- `\v` 垂直制表符。
- `\\` 反斜杠。

其中 `n` 是 8 位字符，其 ASCII 码是表示该字符的 1、2 或 3 位八进制数。

> 注意 — `/usr/bin/echo` 以及 Korn 和 Bourne shell 的内置 `echo` 命令都理解反斜杠转义字符，但 Bourne shell `echo` 命令不识别 `\a` 为警报字符。

当使用转义约定 `\0n` 表示 8 位字符时，`n` 之前必须有一个数字零 `0`。

例如，以下命令会打印短语 `WARNING:` 并在你的终端上发出响铃。

```
$ 'WARNING: \07'
WARNING:
$
```

需要单引号（或双引号）（或两个反斜杠）来保护位于 `07` 之前的反斜杠。

## echo 279

在 `\0` 之后，你可以使用最多三个数字来构造输出字符。如果在 `\0n` 之后，你想 `echo` 不属于八进制表示的其他额外数字，必须使用完整的 3 位 `n`。例如，如果你想 `echo` `ESC 7`，必须使用三个数字 `033`，而不是仅在 `\0` 之后使用数字 `33`。

以下示例显示了仅使用两个数字是错误的。

```
$ echo "01337" | od -xc
000000 337 df0a \n000002 $
```

以下示例显示了 3 位数字语法产生了正确的结果。

```
$ echo "\00337" | od -xc
000000 033 7 a0a \n0000003 $
```

有关每个字符的八进制等效值，请参见 `ascii(5)`。

## 使用

可移植应用程序不应使用 `-n`（作为第一个参数）或转义序列。可以使用 `printf(1)` 命令可移植地模拟 `echo` 命令的任何传统行为，如下：

Solaris 2.x `/usr/bin/echo` 等同于：

```
printf "%b\n" "*"
```

`/usr/ucb/echo` 等同于：

```bash
if ["$X1" = "X-n"]
then
  shift
printf "%s" "*"
else
printf "%s\n" "*"
fi
```

鼓励新应用程序使用 `printf` 代替 `echo`。

## 示例

你可以通过在变量名前前加上美元符号 `$` 使用 `echo` 命令显示变量的值。以下示例显示了 `PATH` 环境变量的值。

```
castle% echo $PATH
/usr/openwin/bin:/usr/dt/bin:/bin:/usr/bin:/usr/sbin:/ucb/etc:/usr
/proc/bin:/opt/hnpn:bin:/local/games::
castle%
```

以下示例显示了如何结合 `echo` 命令与 `tr` 和 `wc` 命令来确定根目录 `/` 和当前目录之间有多少个子目录。该示例包含以下部分：

- `echo` 当前工作目录的全路径。
- 将输出通过 `tr` 将路径中嵌入的斜杠字符转换为空格。
- 将该输出通过 `wc -w` 对路径中的名称进行计数。
