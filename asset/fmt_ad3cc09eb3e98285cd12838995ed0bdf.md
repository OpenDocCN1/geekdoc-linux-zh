# BIND（伯克利命名域守护进程）

`BIND` 是互联网上提供 DNS 服务最流行的软件。你的 ISP（互联网服务提供商）可能运行 `BIND`。`BIND` 是开源的。关键点：`BIND` 涵盖了 80% 的 DNS 服务。结果，发现的 `BIND` 漏洞对互联网产生了巨大影响。截至 1999 年 11 月，8.2.2 之前的所有 `BIND` 版本都存在可利用的漏洞。很可能这些较新版本也存在未发现的漏洞。关键点：`BIND` 有两个版本，4.x 和 8，这在很大程度上是为了向下兼容性：人们运行许多旧服务器，而不愿将其升级到新版本。此外，8.x 代码经过了审查，被认为更安全。更新：`BIND` v9 现在可用，尽管大多数用户仍在使用 v8。另见：`dig`。来自 黑客词汇表 http://www.tldp.org/LDP/Linux-Dictionary/index.html

# binfmts

`binfmt` 内核模块包含在 Linux 2.1.43 及之后的版本中，它允许系统管理员根据魔数或文件扩展名为二进制格式注册解释器，每当执行匹配的文件时，就会调用相应的解释器。将其视为一种灵活的解释器机制。该包提供了 `binfmts` 脚本，包维护者可以使用它们注册解释器而无需编写自己的 init 脚本，系统管理员可以使用它来实现稍微高级别的接口。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/index.html
