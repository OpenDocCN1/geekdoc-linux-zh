首次支持于：Navigator 2, IE 3

支持从一组或多个选项中恰好选择一个的表单字段。单选按钮是 `TYPE` 属性设置为 `RADIO` 的 `INPUT`。通过将它们的 `NAME` 属性设置为相同的值对单选按钮分组。基础 Radio 对象引入 JavaScript 1.0，并在 JavaScript 1.1 和 1.2 中进行了更新。
