# 脚本：命令与注释

符号引用 `u+x` 设置文件的执行权限。`chmod u+x hello` 命令将设置 `hello` 文件的执行权限。现在你可以像使用任何 Linux 命令一样使用脚本文件名了。你只需要设置一次执行权限。一旦设置，它就会一直有效，直到你显式更改它。

```
hello

echo "Hello, how are you"
```

```
$ chmod u+x hello
$ hello
Hello, how are you
$
```

绝对引用会在设置执行权限的同时设置读写权限。简而言之，`700` 将为用户设置执行读写权限；`600` 将设置读写权限，`500` 将设置执行读取权限；`400` 将设置读取权限，`300` 将设置执行写入权限，`200` 将设置写入权限。用户通常设置 `700` 或 `500`。在下一个示例中，用户使用绝对引用设置读、写和执行权限。

```
$ chmod 700 hello
$ hello
Hello, how are you
$
```

# Shell 脚本：命令与注释 3

当你在一个 Linux shell 中工作时，你可能需要执行为另一个 Linux shell 编写的脚本。假设你正处于 `TCSH` shell 中，想要执行一个你在 `BASH` shell 中编写的包含 `BASH` shell 命令的脚本。首先，你必须使用 `sh` 命令切换到 `BASH` shell，执行该脚本，然后切换回 `TCSH` shell。然而，你可以通过在脚本开头放置两个字符 `#!`，后面跟上系统上 shell 程序的路径名称，来实现这一过程的自动化。

你的 shell 总是会检查脚本的第一个字符以确定它是什么类型的脚本——`BASH`、`ZSH` 还是 `TCSH` shell 脚本。如果第一个字符是空格，则认为该脚本是 `BASH` 或 `ZSH` shell 脚本。如果只有一个 `#`，则该脚本是 `TCSH` shell 脚本。如果 `#` 后面紧跟 `!` 字符，你的 shell 就会读取其后的 shell 程序的路径名称。`#!` 后面应该始终跟随标识脚本运行类型的 shell 程序路径名称。如果你当前处于不同的 shell 中，该 shell 将读取 shell 程序的路径名称，切换到该 shell 并执行你的脚本。如果你在不同的 shell 中，仅凭空格或单独的 `#` 不足以识别 `BASH` 或 `TCSH` 脚本。这种识别仅在各自的 shell 中有效。要识别来自不同 shell 的脚本，你需要包含 `#` 字符以及路径名称。

例如，如果你在 `hello` 脚本的第一行开头放入 `#!/bin/sh`，你就可以从 `TCSH` shell 直接执行它。该脚本会先切换到 `BASH` shell，执行其命令，然后返回 `TCSH` shell（或执行它时的任何 shell 类型）。在下一个示例中，`hello` 脚本包含了 `#!/bin/sh` 命令。用户随后在 `TCSH` shell 中执行该脚本。

# hello

```
#!/bin/sh
### The hello script says hello
echo "Hello, how are you"
```

$ hello

Hello, how are you

## 控制结构

你可以通过控制结构在 shell 程序中控制 Linux 命令的执行。控制结构允许你重复命令并在某些命令之间进行选择。一个控制结构由两个主要部分组成：测试和命令。如果测试成功，则执行这些命令。通过这种方式，你可以使用控制结构来决定是否执行某些命令。

控制结构有两种类型：循环和条件。循环重复命令，而条件结构在满足特定条件时执行命令。`BASH` shell 有三种循环控制结构：`while`、`for` 和 `for-in`。有两种条件结构：`if` 和 `case`。

`if` 和 `while` 控制结构适用于通用目的，例如执行迭代和使用各种不同的测试做出决策。`case` 和 `for` 控制结构更加专门。`case` 结构是 `if` 条件的限制形式，通常用于实现菜单。`for` 结构是一种特殊循环。它遍历值列表，并在迭代时为变量分配新值。

`if` 和 `while` 结构的测试是执行 Linux 命令。所有 Linux 命令在执行完成后都会返回一个退出状态。如果命令执行成功，其退出状态将为 `0`。如果命令由于任何原因失败，其退出状态将是一个引用发生故障类型的正值。`if` 和 `while` 结构会检查 Linux 命令的退出状态是否为 `0` 或其他某个值。在 `if` 和 `while` 结构中，如果退出状态为零，则命令执行成功，结构继续。

## 控制结构：AND, OR, &&

### 函数

逻辑与（`AND`）条件在两个命令都返回真值（`0`）时返回真值 `0`；如果其中一个返回非零值，则 `AND` 条件为假并同样返回非零值。

```
command && command
```

### 控制结构：AND, OR 和 NOT

### 函数

```
command | command
```

逻辑或（`OR`）条件在两个命令中任一返回真值（`0`）时返回真值 `0`；如果两个命令都返回非零值，则 `OR` 条件为假并同样返回非零值。

```
! command
```

逻辑非（`NOT`）条件反转命令的返回值。

### 循环控制结构：while, until, for, in, select


  `select` 根据 item-list 中的项创建一个菜单；然后执行命令；该命令通常是一个 `case` 语句。

### 函数

赋值运算符。任何字符集都可以赋值给变量。在下一个示例中，变量 `greeting` 被赋值为字符串 "Hello"。

一旦你为变量分配了值，你就可以使用该变量来引用该值。通常情况下，你会将变量的值作为命令的参数。你可以通过在变量名前加上 `$` 运算符来引用变量的值。美元符号 `$` 是一个特殊的运算符，它使用变量名来引用变量的值，实际上是对变量进行求值。求值会获取变量的值——一组字符。该字符集将替换命令行上的变量名。因此，在变量名前任何放置 `$` 的地方，变量名都会替换为变量的值。
