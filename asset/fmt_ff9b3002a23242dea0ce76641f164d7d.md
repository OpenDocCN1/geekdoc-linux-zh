# 狄利克雷鸽巢原理

## 15.1 原理的起源

在本章中，我们描述了一种计数技术，它有不同的名称：*鸽巢原理*、*盒子原理*，以及*抽屉原理*，最后一个是德语术语 *Schubfachprinzip* 的翻译。它由 P. G. L. 狄利克雷* 在 1834 年引入，并在其关于数论的著名著作中用于处理无理数的有理逼近。我们在第 1 章中提到了这一应用，并陈述了以下问题。

# 问题 15A

**无理数的有理逼近**

证明对于每个无理数 `a`，存在一个有理数 `p/q`，使得

$$\left|a - \frac{p}{q}\right| < \frac{1}{q^{2}}.$$

即使在其最复杂的形式下，该原理看起来如此明显，你甚至可能怀疑它没有价值。然而，我们将看到一些真正巧妙且漂亮的证明，往往带有令人惊讶的结果，这表明这样的评估是完全错误的！

> * 彼得·格斯塔夫·莱让·狄利克雷（Peter Gustav Lejeune Dirichlet）出生于 1805 年 2 月 13 日的德国迪伦。他 27 岁时被任命为柏林大学数学教授，并于 1855 年迁往哥廷根，1859 年在那里去世。狄利克雷对数学做出了许多贡献。他因在解析数论方面的工作而受人铭记，特别是他的定理：当 `a` 和 `b` 是互质整数时，序列 `⟨an+b⟩` 包含无穷多个质数。

## 15.2 鸽巢原理

我们首先陈述该原理的一个版本：

# 定理 15.1

鸽巢原理（版本 1）

如果 `n+1` 只鸽子被放入 `n` 个鸽巢中，那么至少有一个鸽巢包含至少两只鸽子。

这看起来如此显然，以至于似乎不需要证明。一个微不足道的应用是：在任何 13 个人中，必然至少有两个人出生在同一个月（当然，不一定在同一年）。如果对此提出质疑，我们可以这样论证：“取其中任意 12 个人（即鸽子！）。如果这 12 个人中没有两个人出生在同一月份，那么，他们合起来（‘占据’）了全年 12 个月（即鸽巢！）的所有月份。由于只有 12 个不同的月份，第 13 个人必然与原 12 个人中的某人生在同一个月。” 显然，如果需要证明定理 15.1，这种论证可以被推广。

作为定理 15.1 的第一个应用，我们提供以下可能令人惊讶的定理。

# 定理 15.2

在每一个简单图中，都有两个顶点具有相同的度数。*

**证明**

设 `G` 为一个简单图，并假设 `G` 有 `n` 个顶点。每个顶点的度数是集合 `{0, 1, 2,..., n-1}` 中的一个整数；乍一看，顶点度数有 `n` 个可能的值，因此 `n` 个顶点可能具有不同的度数。然而，事实上，在一个具有 `n` 个顶点的图中，不可能同时存在度数为 0 的顶点和度数为 `n-1` 的顶点（为什么？）。因此，由于顶点数多于可能的度数值，根据鸽巢原理，必然至少有 2 个顶点具有相同的度数。

一个有趣的解释是，在聚会中，如果有部分客对行握手，那么在任一时刻，必然至少有两个人与其他客人握手的数量相同。

我们已经注意到，在确保至少有两个月份相同之前，我们需要至少有 13 个人。我们可以轻松推广这个例子。必须有多少个人才能确保至少有四个人出生在同一月份？你可以这样论证（这次更关注鸽巢而不是鸽子）。

如果没有任何一个月有多于 3 个人出生，那么最多可以有 `12 × 3 = 36` 个人。因此，如果我们至少有 37 个人，我们将确保至少有 4 个人出生在同一月份。

这一论证背后的原理可以陈述如下（回忆一下，如果 `x` 是一个实数，我们使用 `⌊x⌋` 表示 `x` 的*整数部分*，即不超过 `x` 的最大整数）。

# 定理 15.3

**鸽巢原理（版本 2）**

假设 `n + 1` 个物体被放入 `k` 个盒子中。那么必然至少有一个盒子包含至少 `⌊n/k⌋ + 1` 个物体。

**证明**

如果没有任何盒子包含多于 `⌊n/k⌋` 个物体，那么总共最多有 `k×⌊n/k⌋` 个物体。现在，`⌊n/k⌋ ≤ (n/k)`，因此 `k×⌊n/k⌋ ≤ n`，这与有 `n + 1` 个物体的事实相矛盾。所以，至少有一个盒子必须包含至少 `⌊n/k⌋ +1` 个物体。

# 问题 15.1

一百张卡片，编号从 1 到 100，分发给六个人。证明必然至少有一个人持有的卡片上出现了至少四个 3。

**解答**

在一百张卡片中，总共有二十个 3（即，卡片 3, 13, 23, 30, 31, 32, 34, 35, 36, 37, 38, 39, 43, 53, 63, 73, 83, 和 93 上各有一个，卡片 33 上有两个）。所以这里 `n = 20` 且 `k = 6`，`⌊n/k⌋ +1 = ⌊20/6⌋ +1 = 4`。因此，根据鸽巢原理的版本 2，必然有某个人持有至少四个 3。

# 定理 15.4

设 `n` 为一个正整数。则每个由 `n² + 1` 个不同数字组成的序列，从左到右读取，要么包含一个长度至少为 `n + 1` 的递增子序列，要么包含一个长度至少为 `n + 1` 的递减子序列。

**证明**

设 `a1, a2, ..., a_{n²+1}` 为一个由 `n² + 1` 个不同数字组成的序列。我们将假设不存在长度大于 `n` 的递增子序列，并展示如何推导出必然存在一个长度至少为 `n + 1` 的递减子序列。

对于每个 `i`，其中 `1 ≤ i ≤ n² + 1`，设 `si` 为以 `ai` 开始的最长递增子序列的长度。根据我们的假设，对于每个 `i`，`si ≤ n`。因此，我们可以将 `n² + 1` 个数字 `ai` 放入 `n` 个编号的盒子中，如果 `si = k`，则 `ai` 放入盒子 `k`。根据鸽巢原理的第二个版本，必然至少有一个盒子包含至少 `n + 1` 项。因此，对于某个 `k`，序列中至少有 `n + 1` 个数字，例如 `a_{i1}, a_{i2}, ..., a_{i_{n+1}}`
