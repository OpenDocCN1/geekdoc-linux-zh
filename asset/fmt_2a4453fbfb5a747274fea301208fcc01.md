## 基于角色的访问控制 (RBAC)

AppArmor 支持 RBAC，允许你定义角色并为用户和应用程序分配权限。使用 AppArmor 配置文件定义角色并分配权限。例如，为 Web 服务器角色创建一个配置文件：

```
/etc/apparmor.d/usr.bin.apache2
```

```bash
#  apache2 的常用包含
#include /usr/sbin/apache2 {
  # 强制对 目录执行只读访问
  /var/www/html/ r,
  # 允许 apache 读取配置文件
  /etc/apache2/** r,
  # 允许 apache 写入日志文件
  /var/log/apache2/** rw,
  # 拒绝访问任何其他文件或目录
  deny /home/** rw,
  deny /etc/** rw,
}
```

应用并强制执行角色：

```
$ sudo aa-enforce /etc/apparmor.d/usr.sbin.apache
```

## 示例程序：在 AlphaProject 中实现 AppArmor

我们将通过为不同的组件创建并强制执行配置文件为 AlphaProject 实现 AppArmor。

首先，为 Apache Web 服务器创建配置文件：

```bash
$ sudo aa-genprof /usr/sbin/apache2
```

运行 Apache 服务器生成日志条目：

```bash
$ sudo systemctl restart apache2
```

完成配置文件的生成：

```bash
$ sudo aa-logprof
```

编辑配置文件以定义权限：

```bash
# apache2 的常用包含
#include /usr/sbin/apache2 {
  # 强制对 目录执行只读访问
  /var/www/html/ r,
  # 允许 apache 读取配置文件
  /etc/apache2/** r,
  # 允许 apache 写入日志文件
  /var/log/apache2/** rw,
  # 拒绝访问任何其他文件或目录
  deny /home/** rw,
  deny /etc/** rw,
}
```

强制执行配置文件：

```
$ sudo aa-enforce /etc/apparmor.d/usr.sbin.apache2
```

编辑 SSH 的 PAM 配置文件：

```
$ sudo nano /etc/pam.d/sshd
```

添加以下行：

```
auth required pam_apparmor.so
```

为 SSH 守护进程创建配置文件：

```
/etc/apparmor.d/usr.sbin.sshd
```

编辑配置文件：

```bash
# sshd 的常用包含
#include /usr/sbin/sshd {
  # 允许对 SSH 配置文件的读取访问
  /etc/ssh/sshd_config r,
  # 允许 sshd 执行二进制文件
  /usr/sbin/sshd ix,
  # 拒绝访问敏感文件
  deny /etc/passwd rw,
  deny /etc/shadow rw,
}
```

强制执行配置文件：

```
$ sudo aa-enforce /etc/apparmor.d/usr.sbin.sshd
```
