## 为复杂的纹理创建凹凸图

你已经看到如何混合扩散图和不透明图来创建树的错觉，或者使用 `Alpha` 通道像不透明图一样剪切出扩散图。但扩散图、剪切图和不透明图不是 `VIZ` 中唯一用的组合。例如，你可以将凹凸图与扩散图结合，快速地创建复杂的形状。例如，假设你想创建一个由石头或劈脸块组成的墙。试图通过逐块或逐块石头地建模来创建这样一个细节物品会让你疯掉。通过结合扩散凹凸图，你可以快速完成此类项目。

- 尝试以下教程，它结合了 `Photoshop`、`AutoCAD` 和 `VIZ` 来帮助创建块墙。

## 使用 `AutoCAD` 画轮廓

首先使用 `AutoCAD` 创建块墙的基本轮廓。如果你使用的是不同的 CAD 程序，尝试按照要求创建此处描述的 `96"x48"`块墙。

- 1. 打开 `AutoCAD`；然后在“绘制”工具栏上点击矩形工具，或在命令行提示符输入 `rec`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_749_1.png)

- 2. 输入 `0,0`，从绘图原点开始绘制矩形。

- 3. 输入 `96,48`；放置矩形角。这创建了一个宽 `96"`、高 `48"` 的矩形。这些尺寸可以容纳六个垂直块。

- 4. 点击“实时缩放”（`Zoom Realtime`）工具。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_750_0.png)

- 5. 右键并选择“全显示”（`Zoom Extents`）查看整个矩形。使用“实时缩放”工具向下拖动以获得更好的视图。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_750_1.png)

你现在有了基本轮廓。下一步是添加块图案。

- 1. 点击“填充”（`Hatch`）工具或在命令行提示符输入 `H`。

![](img/77e143440dd5a0ed9683d4f26f3c074f8_750_2.png)

## 为复杂纹理创建凹凸贴

2. 在“填充和渐变”（`Hatch and Gradient`）对话框中，点击采样色块。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_751_0.png)

3. 在“填充图案”（`Hatch Pattern`）调板上，点击“其他预定义”（`Other Predefined`）选项卡。

4. 点击对话框中显示的 `AR-B816c` 图案；然后点击确定。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_751_1.png)

5. 回到“填充和渐变”对话框，点击“添加选择对象”（`Add: Select Objects`）按钮。对话框会临时消失，以便你选择对象。

6. 选择矩形；然后按 `J` 键。返回“填充和渐变”对话框。

- 7. 点击确定。填充图案将出现在绘图中。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_752_0.png)

你现在有了一个基础区块图案，可以在此基础上为劈裂面块墙构建图像映射。`AutoCAD` 非常适合这项特定任务。在非 CAD 图形程序中准确地创建这种图案将花费更多时间。

接下来，你需要将 `AutoCAD` 图像传输到 `Photoshop`。有几种方法可以实现。`AutoCAD` 可以设置为打印一个能够被 `Photoshop` 读取的位图文件；但是，对于块墙，我们将使用一种更简单的方法。

- 1. 如果你在屏幕左下角看到 `UCS` 图标，输入 `ucsicon Off` 将其关闭。你不希望 `UCS` 图标出现在复制到剪贴板的图像中。

- 2. 在 `AutoCAD` 窗口为全屏显示且光标位于区块区域之外的情况下，按 `Print Screen` 键。这会将屏幕的所有内容复制到剪贴板。

- 3. 返回 `Photoshop`；然后点击“文件”->“新建”。记住，`Photoshop` 中的新文件尺寸将根据剪贴板的内容进行调整，因此你会看到“新建”对话框显示新文件的尺寸为你的显示器大小。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_752_1.png)

- 4. 点击确定。当“无标题”窗口显示时，选择“编辑”▷“粘贴”或按 `Ctrl+V`。你的屏幕图像显示在窗口中。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_753_0.png)

- 5. 一旦你成功将 `AutoCAD` 屏幕复制到 `Photoshop`，就可以关闭 `AutoCAD`。你不需要保存区块绘图。通过剪贴板传输 `AutoCAD` 图像对于你这里的操作已经足够。你不需要极其精确的 `AutoCAD` 图像来创建区块图案，因为你将通过将其用于 `VIZ` 材质中来增强绘图。

## 使用 `Windows` 剪贴板

剪贴板仅以屏幕分辨率在应用程序之间传输图像，这对于直接进行高分辨率打印是不够的。

## 在 `Photoshop` 中构建纹理

下一步是开始构建一个 `VIZ` 可以用于创建纹理的图案。记住，`VIZ` 在使用位图作为凹凸贴图时，使用灰度来营造凹凸感。劈裂面区块具有粗糙表面，可以用随机灰点图案进行模拟。`Photoshop` 提供了一个名为“噪声”（`Noise`）的过滤器，它引入了与你在第8章中使用的噪声图类似的随机性，为别墅设计的地面产生波动效果。在下一个练习中，你将使用“噪声”作为背景。

## 消失的线条

你可能会在移动或放大时发现图像中的某些线条消失。线条仍然在那里，这是由 `Photoshop` 处理行或列的方式引起的。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_755_1.png)

现在你准备好添加一些噪声了。首先，查看 `Photoshop` 窗口右下部分的图面板。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_756_0.png)

你会看到两个层：背景和图 `1`。背景是你将 `AutoCAD` 屏幕粘贴到图像之前的内容。图 `1` 包含粘贴的图像。当粘贴文件时，`Photoshop` 会创建一个新层。在下一个练习中，你将在背景上添加噪声；噪声将用于 `VIZ` 来创建劈裂面区块的粗糙纹理。

- 1. 在图面板中，点击“背景”标签使其成为当前层。标签显示为蓝色表示它处于激活状态。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_756_1.png)

- 2. 点击图面板上图 `1` 列表左侧的眼睛图标临时关闭图 `1`。这是层可见性按钮。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_756_2.png)

眼睛消失了，无标题窗口中的区块图案也消失了。

- 3. 选择“滤镜”>“噪声”>“添加噪声”。添加噪声”对话框显示，噪声图案出现在图像窗口中。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_757_0.png)

- 4. 勾选“单色”复选框；然后将“量”滑块调整到 `400%`。注意在你这样做时，对话框中的样本图像和无标题窗口都会发生变化。

- 5. 点击确定接受添加噪声设置。

- 6. 在图面板中，点击图 `1` 的层可见性框将其开启。噪声在图像窗口中消失了，因为图 `1` 完全覆盖了它。

你已经在背景上添加了噪声，但你需要对图 `1` 进行一些调整，以便让噪声出现在图像中。你还需要填充图 `1` 图像中的缝隙。从缝隙开始：
