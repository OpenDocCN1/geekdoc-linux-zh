# 总结

在本章中，你学习了在 Web 上使用图像。需要记住的一些具体细节如下：

- 只有 `GIF`、`JPEG` 和 `PNG` 图形格式在网页页面上是有效的。

- `PNG` 文件只能在 4.0 或更高版本的 Web 浏览器中查看。

- 图像在互联网上通常效果更好。它们不仅下载速度更快，而且更容易放置在你的文档中。

- `GIF` 和 `PNG` 图像是唯一允许透明部分的格式。

- 图形会自动将所有 `GIF-89` 导出保存为交错图像。
