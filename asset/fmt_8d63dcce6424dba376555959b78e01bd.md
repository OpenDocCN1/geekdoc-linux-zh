
`class` `exec` `in` `print`

`continue` `finally` `is` `raise`

`def` `lambda` `return`

以下划线开头或结尾的标识符具有特殊含义。例如，以单下划线开头的标识符如 `_foo` 不会被模块 `import` 语句导入。结尾都有下划线的标识符如 `__init__` 留给特殊方法，而以双下划线开头的标识符如 `__bar` 用于实现私有类成员，如第 7 章“类与面向对象编程”所述。应避免对标识符进行通用用途。

## 数字字面量

有四种内置数字字面量：

- 布尔值
- 整数
- 浮点数
- 复数

标识符 `True` 和 `False` 分别解释为整数值 `1` 和 `0`。类似 `1234` 的数字被解释为十进制整数。要使用八进制、十六进制或二进制表示指定整数，请分别在值前面加上 `0`、`0x` 或 `0b`（例如，`0644`、`0x100fea8` 或 `0b11011010`）。

Python 中的整数具有任意数的位数，如果你想写一个巨大的整数，只需写出所有数字，如 `12345678901234567890`。在检查值和查看旧 Python 代码时，你可能会看到带有尾随 `1`（小写 l）或 `L` 字符的数字，如 `1234567890123456789L`。这个尾随的 `L` 与 Python 将整数表示为固定精度的机器整数或任意精度长整数类型有关。在旧版本的 Python 中，你可以显式选择使用其中一种类型并为其添加 `L`。这种区分是没有必要的，并且是被积极反对的。如果你想要一个大整数，直接写不带 `L` 的即可。

类似 `13.4` 和 `1.234e+02` 的数字被解释为浮点数。

## 字符串字面量

| 字符 | 描述 |
|---|---|
| \n | 换行 |
| \v | 垂直制表符 |
| \t | 水平制表符 |
| \r | 回车 |
| \f | 换页 |
| \a | 响铃 |
| \b | 退格 |
| \e | 转义 |
| \0 | 空字符 |
| \' | 单引号 |
| \" | 双引号 |
| \000 | 八进制值 |
| \uxxxx | Unicode 字符 |
| \Uxxxxxxxx | Unicode 字符 |
| \N(charname) | Unicode 名称 |
| \xhh | 十六进制值 |

`\000` 和 `\x` 转义用于在字符串字面量嵌入难以输入的字符（即控制代码、不可打印字符、国际字符）。例如，如果你想为“Japeño”写字符串字面量，你可能会写成 `"Jape\xf1"`。

Python 2 字符串有一个严重的局限，它们不支持国际字符和 Unicode。为了解决这个问题，Python 3 使用单独的 Unicode 类型。编写 Unicode 字符串，在第一个引号前加上字母 `u`。例如：

```python
s = "jalape\u00f1"
```

在 Python 3 中，这个前缀是没有必要的（实际上是语法错误）。如果你使用 `-u` 选项运行 Python 2，它将模拟这种行为（在这种情况下所有字符串字面量将被视为 Unicode，可以省略 `u`）。

无论你使用哪种版本的 Python，使用 `\u`、`\U` 和 `\n` 转义符都可以向 Unicode 字面量插入任意字符。每个字符都有分配的代码点，通常在 Unicode 中表示为 `U+XXXX`，其中 `XXXX` 是四个或多个十六进制数字。（注意，这不是 Python 语法，而是作者在描述 Unicode 时使用的）。字符 `ñ` 的代码点是 `U+00F`。`\u` 转义用于插入代码点范围在 `U+0000` 到 `U+FFFF` 及以上的字符（例如，`\U00012345`）。

Unicode 字符还有描述性名称。如果你知道名称，可以使用 `\N(character name)` 转义序列。例如：

```python
s = "Jalape\NLATIN SMALL LETTER N WITH TILDE\o"
```

有关代码点和字符名称的权威参考，请参阅 http://www.unicode.org/charts。

可选情况下，你可以在字符串字面量前加上 `r` 或 `R`，例如 `r'd'`。这些字符串被称为“原始字符串”（raw strings），因为所有的反斜杠都保持原样——也就是说，字符串字面量包含了包含的文本，包括反斜杠。原始字符串的主要用途是指定反斜杠字符具有某些意义的字面量。示例可能使用 `re` 模块定义正则表达式模式，或者在 Windows 上为文件名加上缀（例如 `r'c:\newdata\tests\'`）。

原始字符串不能被编码为 `r=""`。此外，只要前置字符的数量正确，`\xxxx` 转义序列仍然会被解释为 Unicode 字符。例如，`ur\u1234` 或 `ur\\u1234` 定义了一个包含单个字符 U+1234 的 Unicode 字符串，或者是一个包含七个字符的字符串，其中前两个字符是反斜杠，其余字符是字面量 `\u1234`。在 Python 2.2 中，原始字符串中的 `r` 必须出现在引号之后，如所示。在 Python 3.0 中，该前缀是不必要的。

字符串字面量不应使用对应于 UTF-8 或 UTF-16 数据编码的字节序列来定义。例如，直接将 UTF-8 编码的字符串写入 `'Jape\xc3\xb1'` 会产生一个多字符字符串 U+00A4, U+006C, U+0066, U+0070, U+0065, U+00C3, U+00B1 和 U+00E6，这并不是你预期的。这是因为代表单个字符 U+00F1 的字节序列 `\xc3\xb1` 被解释为了前两个字符 U+00C3 和 U+00B1。若要将字节字符串指定为字面量，请在第一个引号前加上加上 `a`，如 `b'Jape\xc3\xb1'`。定义后，它会字面量地创建一个单字节字符串。通过这种表示法，可以使用其 `decode()` 方法解码字节字面量创建一个普通字符串。关于这方面的更多细节请见第 3 章和第 4 章“运算符与表达式”。

字节字面量在程序中的用法非常罕见，因为这种语法直到 Python 2.6 才出现，在该版本中，字节字面量和普通字符串之间没有区别。但在 Python 3 中，字节字面量被映射到一个新的 `bytes` 数据类型，其行为与普通字符串不同（见附录 A，“Python 3”）。

## 容器

在方括号 `[...]`、圆括号 `(...)` 和大括号 `{...}` 中的值分别表示包含在列表、元组和字典中的对象集合，如下所示的示例所示：

```
a = [ 1, 3, 'hello' ]      # 一个列表

b = ( 10, 20, 30 )         # 一个元组

c = { 'a': 3, 'b': 42 }      # 一个字典
```

## 运算符、分隔符和特殊符号

以下运算符是可以识别的：

```
+ * / // & & 
- * = = <= >= = < > ^
- *= /= //= &= &== <= > >= <<=
```

以下标记（tokens）作为表达式、列表、字典和语句各个部分的分隔符：

```
( ) [ ] { } = ; ,
```

例如，等号（`=`）字符作为赋值名和值之间的分隔符，而逗号（`,`）字符用于分隔函数的参数、列表和元组中的元素，句号（`.`）用于浮点数，而省略号（`...`）用于扩展切片操作。
最后，还使用了特殊符号：

```
' $ @
```

字符 `$` 和 `?` 在 Python 中没有意义，除了在引号内的字面量内部，否则不能出现在程序中。

## 文档字符串

如果模块、类或函数定义的第一条语句是字符串，那么该字符串将成为关联对象的文档字符串，如在例例所示：

```python
def fact(n):
    """此函数计算阶乘!""
    if (n <= 1):
        return 1
    else:
        return n * fact(n - 1)
```

代码浏览器和文档生成工具有时会使用文档字符串。可以通过对象的 `__doc__` 属性访问这些字符串，如下所示：

```python
>>> fact.__doc__
此函数计算阶乘
>>>
```
