
```text
@me@linuxbox ~$ ls -l
total 56
drwxr-xr-x 2 root 2017-10-26 20 Desktop
drwxr-xr-x 2 root 2017-10-26 20 Documents
drwxr-xr-x 2 root 2017-10-26 20 Music
drwxr-xr-x 2 root 2017-10-26 20 Pictures
drwxr-xr-x 2 root 2017-10-26 20 Templates
drwxr-xr-x 2 root 2017-10-26 20 Videos
```

通过在命令中添加 `-l`，我们将输出更改为长格式。

## 选项和参数

这引出了大多数命令工作的一个重要点。命令后面通常跟着一个或多个选项来修改其行为，以及一个或多个参数（命令作用的对象）。因此，大多数命令看起来像：

```text
command -options arguments
```

大多数命令使用由单个连字符开头的选项，例如 `-l`。然而，许多命令（包括来自 GNU 项目的命令）也支持长选项。许多命令允许多个短选项组合在一起。在下面的示例中，`ls` 命令给了两个选项：`-l` 生成长格式，`-t` 按文件的修改时间排序结果。

```text
[me@linuxbox ~$ ls -lt
```

我们将添加长选项 `--reverse` 来反转排序顺序。

```text
[me@linuxbox ~$ ls -lt --reverse
```

命令选项和文件名一样区分大小写。`ls` 命令有很多可能的选项，最常用的列在表 3-1 中。

## 3-1：常用 `ls` 选项

| 选项 | 长选项 | 描述 |
|---|---|---|
| `-a` | `--all` | 列出所有文件，甚至是以点开头的文件（这些通常不列出，即隐藏文件）。 |
| `-A` | `--almost-all` | 类似于 `-a` 选项，但不列出 `.`（当前目录）和 `..`（父目录）。 |
| `-d` | `--directory` | 通常，如果指定一个目录，`ls` 将列出目录的内容而非目录本身。将此选项与 `-l` 结合使用可以查看目录详情而非其内容。 |
| `-F` | `--classify` | 此选项将在每个列出的名称末尾添加指示字符。例如，如果是目录，它将添加一个斜杠（`/`）。 |
| `-h` | `--human-readable` | 在长格式列表中，以人类可读的格式显示文件大小。 |
| `-l` | | 以长格式显示结果。 |
| `-r` | `--reverse` | 反序显示结果。通常，`ls` 按字母升序显示结果。 |
| `-s` | | 按文件大小排序结果。 |
| `-t` | | 按修改时间排序。 |

## 使用 `file` 确定文件类型

当我们探索系统时，了解文件中包含什么内容将很有帮助。为了做到这一点，我们将使用 `file` 命令来确定文件的类型。正如之前讨论的，Linux 中的文件名并不要求反映文件的内容。虽然通常会认为像 `picture.jpg` 这样的文件名会包含一个 JPEG 压缩的图像，但在 Linux 中这并不是强制的。我们可以这样调用 `file` 命令：

```text
file filename
```

当调用时，`file` 命令将打印文件内容的简要描述。例如：

```text
[me@linuxbox ~]$ file picture.jpg
picture.jpg: JPEG image data, JFIF standard 1.01
```

文件有很多种。事实上，Linux 等类 Unix 操作系统的共同理念之一就是“万物皆文件”。随着课程的进行，我们将看到这句话在多程度上是真的。

虽然我们系统中的许多文件是熟悉的（例如 MP3 和 JPEG 文件），但还有许多类型并不那么明显，还有几种类型非常奇怪。

## 使用 `less` 查看文件内容

`less` 命令是一个查看文本文件的程序。在整个 Linux 系统中，有许多包含人类可读文本的文件。`less` 程序提供了一种检查这些文件的方便方法。

为什么要检查文本文件？因为许多包含系统设置（称为*配置文件*）的文件是以这种格式存储的，能够读取它们可以让我们了解系统是如何运行的。此外，系统使用的一些实际程序（称为*脚本*）也以这种格式存储。在随后的章节中，我们将学习如何编辑文本文件以编写自己的脚本，但现在我们只需查看它们的内容。

`less` 命令的用法如下：

```text
less filename
```

## 什么是“文本”？

在计算机上表示信息有许多方法。所有方法都涉及定义信息与用于表示它的某些数字之间的关系。毕竟，计算机只理解数字，所有数据都会转换为数值表示。

这些表示系统中的某些非常复杂（例如压缩的视频文件），而另一些则很简单。最早且最简单的之一是 ASCII 文本。ASCII（读作 "as-key"）是美国标准信息交换代码的缩写。这是一种简单的编码方案，最初用于电传字机，将键盘字符映射到数字。

文本是字符到数字的一一对应映射。它非常复杂。文本的加密被翻译为数据字节。重要的是要理解文本只包含字符到数字的简单映射。它与由 Microsoft Word 或 LibreOffice 创建的文字处理器文档不同。相比之下，这些文件与简单的 ASCII 不同，包含了许多非文本元素，用于描述其结构和格式。纯 ASCII 文本文件只包含字符本身以及一些基本的控制代码，如制表符、回车和换行符。

在整个 Linux 系统中，许多文件以文本格式存储，并且有许多处理文本文件的 Linux 工具。即使是 Windows 也认识到了这种格式的重要性。著名的 `NOTEPAD.EXE` 程序就是纯 ASCII 文本文件的编辑器。

一旦启动，`less` 程序允许我们向前和向后滚动文本文件。例如，要检查定义系统用户账户的文件，输入以下命令：

```text
[me@linuxbox ~]$ less /etc/passwd
```

一旦 `less` 程序启动，我们就可以查看文件的内容。如果文件超过一页，我们可以向上和向下滚动。按 `q` 退出。表 3-3 列出了 `less` 最常用的键盘命令。

## 表 3-3: `less` 命令

| 命令 | 动作 |

| PAGE up or b | 向上翻页 |
| PAGE DOWN or space | 向下翻页 |
| Up arrow | 向上滚动 |
| Down arrow | 向下滚动 |
| G | 移动到文件末尾 |
| 1G or g | 移动到文件开头 |
| /characters | 向前搜索字符 |
| n | 向后搜索下一个匹配项 |
