
# GtkStyle 结构定义

```c
typedef struct _GtkStyle GtkStyle;
struct _GtkStyle {
  GtkStyleClass *class;

  GdkColor fg[5];
  GdkColor bg[5];
  GdkColor light[5];
  GdkColor dark[5];
  GdkColor mid[5];
  GdkColor text[5];
  GdkColor base[5];

  GdkColor black;
  GdkColor white;
  GdkFont *font;

  GdkGC *fg_gc[5];
  GdkGC *bg_gc[5];
  GdkGC *light_gc[5];
  GdkGC *dark_gc[5];
  GdkGC *mid_gc[5];
  GdkGC *text_gc[5];
  GdkGC *base_gc[5];
  GdkGC *black_gc;
  GdkGC *white_gc;

  GdkPixmap *bg_pixmap[5];
};
```

## 绘制函数

`gtk/gtkstyle.h` 包含了绘制函数，这些函数使用样式的虚表来绘制各种 GUI 元素。每个绘制函数有两个变体：一个以 `gtk_draw_` 前缀的变体渲染到任何可绘制对象 `drawable`；另一个以 `gtk_paint_` 前缀的变体渲染到一个 `widget` 的部分。例如，`gtk_draw_shadow()` 如下：

```c
void gtk_draw_shadow(GtkStyle *style,

                               GdkWindow *window,

                               GtkStateType state_type,

                               GtkShadowType shadow_type,

                               int x,

                               int width,

                               int height);
```

而 `gtk_paint_shadow()` 增加了 `area`、`widget` 和 `detail` 参数：

```c
void gtk_paint_shadow(GtkStyle *style,

                               GdkWindow *window,

                               GtkStateType state_type,

                               GtkShadowType shadow_type,

                               GdkRectangle *area,

                               GtkWidget *widget,

                               gchar *detail,

                               int x,

                               int y,

                               int width,

                               int height);
```

这些函数中的每一个都对应 `GtkStyleClass` 中的 `draw_member`。
所有的 `gtk_paint_functions` 都会与其对应的 `gtk_draw` 函数相比增加相同的参数：`area` 参数是一个裁剪矩形，`widget` 参数是正在绘制的 `widget`，而 `detail` 参数是主题引擎使用的提示信息。这里有一个调用 `gtk_paint_shadow()` 的示例源码：

```c
gtk_paint_shadow(widget->style, widget->window,

                  GTK_STATE_NORMAL, GTK_SHADOW_IN,

                  NULL, widget, "entry",

                  x, y, width, height);
```
