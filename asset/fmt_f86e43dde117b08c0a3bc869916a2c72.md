
```
make modules_install
```

阅读 `/usr/doc/KERNEL-HOWTO` 了解如何安装新内核。配置和编译也会发现，如果你不知道自己在做什么，`CAN` 可能会导致问题。编译内核是测试硬件的好方法，因为它涉及大量的计算。如果硬件有“故障”，你可能会收到“`error`”（错误）信号。详情请参见 `/usr/doc/KERNEL-HOWTO`。

- `depmod -a`

（作为 `root`）为内核构建依赖表。这非常有用，例如，在安装并启动新内核之后。使用 `depmod -a` 加载模块。

- `ldconfig`

（作为 `root`）重新为加载器（`ids`）创建缓存和缓存。在启动系统后运行它也很有用，或者如果你不需要手动运行它。更改 `fstab` 文件的时间戳为当前时间。如果文件不存在则创建一个空文件。

- `touch`

（作为 `root`）创建一个设备文件。此示例显示了如何创建一个与你的驱动器关联的设备文件，意外删除时很有用。选项有：块设备、字符设备、`FIFO` 设备。两个整数指定主从设备号。

```
mkfs /dev/fd0
```

- `fdformat`

```
/dev/fd0 mkfs -t ext2
```

- `badblocks`

（作为 `root`）检查高密度软盘的坏块并对第一个软盘（`/dev/fd0`）进行低级格式化。

```
/dev/fd0
```

- `fsck -t ext2`

系统检查，检查并修复文件系统。示例使用了分区 `hda`，系统级格式。
