## `jserv`
带有可选 Apache Servlet 的 Java Servlet 2.0 是一个100% 纯 Java servlet 引擎，符合 JavaSoft Servlet APIs 2.0 标准。它可以在任何符合 1.1 标准的 JVM 上运行，并通过动态加载模块（`mod_jserv`）来激活对 Apache 1.3 支持。Servlet 2.0（`servlet-2.0 jar`）包含在一个免费（LGPL）实现中，地址位于 `http://www.euronet.net/~paulis/java/servlet/`。更多信息请参考 servlet 引擎项目主页 `http://java.apache.org/`。来自 Debian 3.0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## `jslaunch`
摇杆按钮命令执行/关闭。`jslaunch` 是一个非常小的守护进程/程序，当按下摇杆按钮组合时它会启动一个特殊命令。它的用途之一是备份，当你的控制台被 X11 或 SVGalib 搞乱，且你桌面上没有终端可以登录并关闭时，可以使用它进行安全关闭；你也可以将其作为远程控制来执行任何事情（包括启动连接到你的实验装置上的测量）。你不需要任何摇杆。来自 Debian 3.0r APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
