
通用网络文件系统 (CIFS)
通用网络文件系统是一种基于服务器消息块 (`SMB`) 协议规范的文件共享解决方案，该规范最初由 `IBM` 为其 `OS/2` 操作系统开发，后由微软开发，并于 `1995` 年发布。在 Linux 上，`CIFS` 在 `Samba` 服务器中实现，通常用于企业环境中共享文件。`CIFS` 也是 `NAS` 设备的常用解决方案。

命令提交（command submission）
这是脚本编写中的一种技术，它使用脚本中命令的结果。通过使用命令提交，可以创建一个灵活的脚本来执行特定命令的结果，这些结果可能根据执行条件的不同而而异。

完全公平队列 (CFQ)
在内核调度器优化中，`CFQ` 是一种让读请求与写请求具有相同优先级的方法。`CFQ` 是默认的调度器设置，对待读、写请求具有同等优先级。由于这些请求之间的对等对待，对于专注于读请求或写请求的服务器来说，这可能不是实现最佳性能的方法。

Conga
在 Red Hat 高可用性扩展组件包中，`Conga` 是一个基于 Web 的管理平台的名称，它由 `ricci` 代理（agents）和 `luci` 管理界面组成。

上下文（context）
在 `LDAP` 中，上下文是 `LDAP` 目录中的一个位置。`LDAP` 客户端通常配置有一个默认上下文，该上下文是客户端在 `LDAP` 目录中查找对象的默认位置。

控制器（controllers）
在 `cgroups` 中，可以控制不同类型的系统资源。`cgroups` 使用控制器来定义提供的系统资源访问类型。例如，有针对内存、`CPU` 周期和 `I/O` 的不同控制器可供。

左向拷贝许可（copyleft license）
一种对版权许可的开源替代方案。在版权许可中，权利由组织主张。在左向拷贝许可中，权利并不被主张，而是留给普通公众。

Corosync
这是 Red Hat 高可用性扩展的一部分，负责集群的低层工作。`Corosync` 使用 `Totem` 协议来验证集群中的其他节点是否仍然可用。

cron 守护进程（cron daemon）
`Cron` 是用于调度任务的守护进程（进程）。`cron` 守护进程根据 `/etc/crontab` 文件中定义的设置执行此操作。

# D

**守护进程 (daemons)**
守护进程是 Linux 上的服务进程。要启动它们，通常会使用 `service` 命令。

**截止日期调度器 (deadline scheduler)**
这是一种调度器设置，会在向数据写入磁盘之前尽可能等待。通过这样做，它确保写入操作能够以最高效的方式执行。对于写多于读的服务器，建议使用截止日期调度器。

**默认网关 (default gateway)**
在 `IP` 网络上，默认网关是连接此网络到外部世界的路由器。每台计算机都需要配置默认网关；否则，数据包无法发送到外部网络。

**目录项缓存 (dentry cache)**
这是内核内存中的一个区域，用于缓存目录项。这些项用于查找磁盘上频繁读取的文件和目录，此时目录项缓存的比例会较高。

**dig**
`dig` 是一个可以查询 `DNS` 名称服务器的实用。

**域名系统 (DNS)**
`DNS` 允许网络用户使用易记的名字代替难以记忆的 `IP` 地址。每台计算机都需要至少配置一个 `DNS` 服务器。

**动态主机配置协议 (DHCP)**
`DHCP` 是一种用于自动为网络上的计算机提供 `IP` 地址和其他 `IP` 相关信息的协议。使用此协议来替代繁琐的手动分配 `IP` 地址，可以使 `IP` 网络中主机的网络配置变得相对简单。

**动态链接器 (dynamic linker)**
库文件需要连接到使用它们的程序文件。这可以通过静态或动态方式完成。在后一种情况下，则使用动态链接器来完成此操作。它是一个跟踪所需库的软件组件，如果调用了库中的函数，它就会被加载。

# E

**熵 (entropy)**
熵是随机数据。在生成加密密钥时，你需要大量的随机数据，特别是当你使用大型加密密钥（如 `4096` 位密钥）时。熵通常由计算机上的随机动作产生，例如移动鼠标或显示大型目录列表。

**条目 (entry)**
在 `LDAP` 中，条目是 `LDAP` 数据库中的对象。`LDAP` 模式定义了不同的条目。典型的条目是创建在 `LDAP` 中用于身份验证的用户和组。

**环境变量 (environment variables)**
环境变量是 shell 环境中的变量。像 `Bash` 这样的 shell 使用本地变量（仅在当前 shell 中可用）和环境变量（在当前 shell 及其所有子 shell 中均可用）。许多环境变量在服务器启动时会自动设置。

**转义 (escaping)**
在 shell 环境中

**以太网绑定 (Ethernet bond)**
以太网绑定是一组被捆绑在一起的网卡。以太网用于服务器，用于增加可用带宽或为网络连接增加冗余。

**执行权限 (execute permission)**
执行权限用于 Linux 上的程序文件。没有执行权限，就无法运行程序文件或进入目录。

**区区/范围区 (extent)**
传统上，文件系统使用 `4KB` 的块作为分配文件的最小单位。这对于大文件会占用许多块，增加了此类类型文件的开销。为了让大文件处理更高效，现代文件系统使用范围区（extents）。一个范围区的大小为 `2MB`。

**fdisk 工具**

**for 循环 (for loop)**

# G

**全局文件系统 2 (GFS2)**
`GFS2` 是集群文件系统。`GFS2` 的优点是多个节点可以同时对其写入。在非集群系统（如 `ext4`）上，如果多个节点尝试写入同一个文件系统，会导致文件系统损坏。

**GNU Privacy Guard (GPG)**
`GPG` 是一种基于私钥的加密解决方案。示例包括加密加密或 `RPM` 校验和。通过对 `RPM` 包创建校验和，下载包的用户可以验证其是否未被篡改。

**组所有者 (group owner)**
Linux 中的每个文件和目录都有一个组所有者，权限分配给该组。该组的所有用户都可以访问该文件或目录。

# H

**硬链接 (hard link)**
硬链接是引用文件的方式。基本上，它是为文件创建的第二个名称。

**硬件隔离 (hardware fencing)**
在高可用集群中，使用硬件来隔离节点，例如管理板或可管理的电源开关。

**启发式 (heuristics)**
在高可用集群中，可以使用仲裁磁盘来验证节点是否仲裁权。为了定义仲裁磁盘，对其分配某些测试。

**隐藏文件 (hidden file)**
隐藏文件是在普通目录列表中不可见的文件。要创建隐藏文件，用户应该创建一个以点开头的文件名。

# I

**非活跃内存 (inactive memory)**
非活跃内存是最近未使用的内存。非活跃内存中的页面会在活跃内存中的页面之前移动到交换分区（swap）。

词汇表 61

**inode**
`inode` 包含文件的完整管理信息。事实上，文件就是一个 `inode`。实际上，它们被分配给文件。为了方便，使用 `ls -i` 查看 `inode` 号。

**插入模式 (insert mode)**
在 `vi` 编辑器中，插入模式是可以输入文本的。与命令模式相反，在该模式下可以执行命令。

**进程间通信 (Inter-Process Communication, IPC)**
进程间通信是发生在进程之间的通信。内核分配套接字（sockets）和管道（pipes）来实现 `IPC`。

**内部命令 (internal command)**
内部命令是 shell 的一部分。它不在磁盘上查找，而是在 shell 中执行。

**IP 伪装 (IP masquerading)**
`IP` 伪装是网络公共侧的一种技术，使用了注册的 `IP` 地址；而在网络私有侧，可路由的 `IP` 地址被使用。`IP` 伪装允许所有地址（地址）连接到互联网。

**iSCSI**
`iSCSI` 是一种通过 `IP` 发送 `SCSI` 命令的协议。它通常用于高可用集群，实现共享存储。

## K

**Kdump**
`Kdump` 是内核的一个特殊版本，当内核崩溃时发生内存转储。`Kdump` 获取内存转储并写入磁盘。

**密钥发行中心 (key distribution center, KDC)**
`KDC` 是 `Kerberos` 中用于分发票据。

**密钥传输 (key transfer)**
密钥传输是将共享密钥传输给合作伙伴的过程。

**基于密钥的认证 (key-based authentication)**
基于密钥的认证是使用密码来验证身份的解决方案。在 `SSH` 环境中，基于密钥的认证被频繁使用。

**密钥环 (keyring)**
在 `GPG` 加密中，密钥环是用户收集的所有密钥的集合。它包含了属于用户的密钥。
