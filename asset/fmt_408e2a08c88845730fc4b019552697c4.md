struct timer_list {
    struct timer_list *next;
    struct timer_list *prev;

# `tq_struct`

每个任务队列（`tq_struct`）数据结构持有已队列工作的信息。这通常是一个设备驱动程序需要的任务，但不需要立即完成。

```c
struct tq_struct {
    struct tq_struct *next;   /* 活跃 bh 的链表 */
    int sync;                   /* 必须初始化为零 */
    void (*routine)(void *);   /* 要调用的函数 */
    void *data;                 /* 函数的参数 */
};
```
