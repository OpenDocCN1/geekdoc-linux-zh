
- 3. 使用我们在第 140 页 Project 8A 中使用的 Pico 编辑器，通过输入 `pico briscola.tk` 来编辑 `briscola.tk` 文件。该文件将出现在终端的 Pico 编辑器中。
- 4. 将 `briscola.tk` 文件的第一行改为 `#usr/local/wish`。
- 5. 在第二行，将 `/usr/local/games/briscola` 更改为 `/usr/share/games/briscola`，这是 `briscola` 放置的地方。
- 6. 按下键盘上的 CTRL 键。
- 7. 输入 Y 并按回车键保存更改。
- 8. 输入 `cd` 并按回车键返回终端主目录。

### 8C-4: 将 Briscola 文件夹移动到全局位置

我们可以将 `briscola` 文件夹移动到 `LocalApps` 文件夹并在那里运行，就像我们对 `PyGames` 做的那样，但这次是通过将整个内容移动到全局区域。这不仅让它免受我们清理倾向的影响，还让所有用户都能在这些文件夹中玩游戏。为了做到这一点，请在终端窗口中输入以下命令：

```
sudo mv briscola /usr/share/games
```

当提示输入密码时，输入密码并按回车键。

### 8C-5: 为 Briscola 创建链接

尽管我们已经将 `briscola` 移动到了全局位置，但仍然无法简单地运行它，因为 `briscola.tk` 文件本身不在系统路径下。正如我们为 `PyGames` 做的那样，我们将为 Briscola 创建一个链接，步骤如下：

- 1. 在终端中输入 `cd /usr/share/games` 并按回车键。
- 2. 现在通过输入 `sudo ln -s /usr/share/games/briscola.tk briscola` 创建链接，并按回车键。
- 3. 输入 `cd` 并按回车键返回终端主目录。你可以通过在终端输入它轻松运行 `briscola`。

## 我可以对 `pyWings` 执行同样的操作吗？

可以。如果你想移动 `pyWings` 到全局位置，只需按照移动文件夹和创建链接的方法即可。当然，你需要通过以下命令删除之前创建的链接：

```
sudo rm /usr/share/games/pywings
```

之后，通过输入 `sudo mv LocalApps/pywings /usr/share/games/` 将 `pyWings` 文件夹移动到全局区域。当提示输入密码时，输入并按回车键。然后通过输入 `cd /usr/share/games; sudo ln -s pywings pywings` 并按回车键创建链接。

## 玩 Briscola

正如我提到的，Briscola 很容易——就像吃花游戏一样，这意味着你出一张牌，然后你的对手也出一张牌，出牌值更高的人赢得该回合。得分根据该回合涉及的牌发放。回合的获胜者将领先下一个回合。当所有的牌都打完后，计算每个玩家的得分，分高者获胜。这描述起来非常简单。

### 扑牌及其排名

与许多意大利和西班牙游戏一样，Briscola 使用 40 张牌的牌组，由以下牌组成：K、Q、J、7、6、5、4、3、2 和 A（王牌）。传统上，它使用花色牌（红桃、方片、梅花和黑桃）或意大利花色牌（金币、权杖、杯），取决于玩游戏的地区。在你刚刚安装的软件版本中，你将在斯卡纳地区使用花色牌。

与你熟悉的大多数牌游戏不同，Briscola 中牌的排名和分值有些不同，如下表所示。

| 牌的排名 | 分值 |
| :--- | :--- |
| Ace | 11 |
| 3 | 10 |
| King | 4 |
| Queen | 3 |
| Jack | 2 |
| 7, 6, 5, 4, 2 | 0 |

### Briscola 的玩法

一旦 Briscola 开始，它将向每个玩家发三张牌。然后它会产生第七张牌，并将其放在朝下的未发牌堆下，称为牌堆（stock 或 talon）。第七张牌被称为 Briscola（游戏也由此命名），它决定了该场游戏的将牌色。这意味着任何与 Briscola 同花色的牌将击败任何其他花色的牌，即使是排名更高的牌。当然，当你用将牌牌对抗另一张牌时，牌的普通排名将重新生效。

需要注意的是，与其他吃花游戏不同，你既不需要跟随 Briscola 牌的花色，也不需要在有能力时击败它。这意味着如果你的对手出出一张梅花牌，你可以出任何你喜欢的花色的牌，即使你有可以击败它的牌，这完全取决于最终赢得游戏的策略。

在开始之前，在游戏过程中选择“显示分数”（Show Score）来了解自己的情况是一个好主意。一旦完成，你就可以行动了，由于你的电脑对手总是让你先出，你可以点击你想出的牌开始。你的电脑对手随后会出一张牌。

一旦你评估了形势，点击手中的任意空白处，该回合的分数将显示在“你”（You，如果你赢得回合）或“我”（Me，如果电脑赢得回合）框中。当然，如果该回合只涉及 7、6、5、4 或 2 等，则不会出现分数，因为这些牌没有分值。

## 定义终端

如你现在所知，终端在外观上是一个非常简单的应用程序。然而，事实如此，如果你愿意，可以对其进行一些装饰。你不仅可以在终端中更改背景和文字颜色，还可以将你喜欢的照片之一作为背景（如图 8-13 所示），或者让背景透明 . . . 嗯，至少是透明。

![](img/ba6b82a7869bba748202d57c97336dca_170_0.png)

图 8-13：自定义背景颜色和字体颜色的终端窗口

要更改终端背景，请转到终端编辑菜单，并选择 **Current Profile**（当前配置）。当编辑窗口出现时，选择 **Effects**（效果）选项卡下的 **Background image**（背景图像），然后点击 **Browse**（浏览）按钮并导航到你想使用的图像（见图 8-14）。根据图像在终端中的显示情况，你可能会发现很难看清上面的文本。如果是这样，请尝试移动配置窗口中 *Shade transparent*（阴影透明）或 *image background*（图像背景）文字下的滑块。如果仍然不起作用，点击 **Colors**（颜色）选项卡，取消勾选 **Colors from system theme**（来自系统主题的颜色），然后尝试 Built-in schemes（内置方案）旁菜单中的某些预设前景和背景颜色组合（图 8-13 中使用的是黑底白字）。

![](img/ba6b82a7869bba748202d57c97336dca_170_1.png)

图 8-14：自定义终端窗口

如果你只想让背景透明，请选择 **Transparent background**（透明背景），并将编辑配置窗口底部的滑块拖到最左侧。如果你选择这种方法，也可以使用滑块来调整背景图像的阴影。

注意：终端中使用的透明效果是“伪透明”的，因为它只是桌面图像的镜像。因此，你会发现，如果桌面上上有任何图标，当你将透明终端穿过这些充满图标的区域时，这些图标不会出现在看似透明的终端窗口中——你只会看到桌面壁纸或背景颜色。

根据你的背景图像或桌面壁纸（如果你选择了透明方案）中存在的颜色，你可能还想更改终端的字体颜色以便于观察。要执行此操作，请点击 Colors（颜色）选项卡，取消勾选 Use colors from system theme（使用来自主题的颜色），然后选择合适的字体颜色。
