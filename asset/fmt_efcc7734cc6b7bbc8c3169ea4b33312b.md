# 7.1 快速启动器

首次从主菜单（“应用程序”->“辅助工具”->“更多”->“OpenOffice.org 快速启动器”）启动时，系统会询问你是否应该启用程序的快速启动功能。如果你打算频繁使用 OpenOffice.org 并且有足够的可用内存，它将很有用。

![](img/705a076b108ea96be0c0695efb5556ce_205_0.png)

图 7.1：OpenOffice.org 快速启动器

快速启动器图标出现在屏幕右下角的桌面面板中。右键点击它会显示如图 7.1 所示的菜单，提供了多种可能性：直接启动各个 OpenOffice.org 应用程序模块、快速重新打开最近使用的文件、从模板创建新文档。选择“配置 OpenOffice.org 快速启动器...”来自定义快速启动器设置。

一旦启用，每次登录桌面时快速启动器都会自动启动。为了以后不再发生这种情况，请点击图 7.1 所示的快速启动器菜单中的“退出(Quit)”。

# 7.2 模块概述

OpenOffice.org 由几个应用程序模块（子程序）组成，它们旨在相互交互。

表 7.1：OpenOffice.org 应用程序模块

| 模块 | 说明 |
| --- | --- |
| Writer | 强大的文字处理应用程序 |
| Calc | 包含图表实用程序的电子表格应用程序 |
| Draw | 用于创建矢量图形的绘应用程序 |

本章的讨论专注于 Writer 和 Calc。其他模块仅作要说明。每个模块的完整描述可以在第 7.3 节的在线帮助中找到。

## 7.3 获取帮助

可以随时从“帮助(Help)”菜单获取 OpenOffice.org 的帮助。根据你的选择，提供的帮助深度和类型各异。要彻底熟悉某个主题，选择“帮助(Help)”->“内容(Contents)”。帮助系统提供有关 OpenOffice.org 每个模块（Writer、Calc、Impress 等）的信息。

如果你发现这些信息太广泛或难以处理，请尝试使用“帮助助手(Help Agent)”，它会在对 OpenOffice.org 执行不同操作时提供帮助和提示。选择“帮助(Help)”->“帮助助手(Help Agent)”来启用。如果较少的信息足够，请尝试“提示(Tips)”和“扩展提示(Extended Tips)”。它们会启用程序的工具提示——关于鼠标指向的元素的简短信息。当你更熟悉程序后，可以轻松禁用这些项目。

> 注意
> 如果你不确定功能是否已激活，请打开“帮助(Help)”菜单。选中的菜单项表示相应的帮助功能当前处于激活状态。

# 7.4 转换 Microsoft Office 文档

OpenOffice.org 能够处理 Microsoft Office 文档。要转换此类文档，选择“文件(File)”->“自动驾驶(AutoPilot)”->“文档转换...(Document Converter...)”。选择要转换的文件格式。会有多种 StarOffice 和 Microsoft Office 格式。选择格式后，点击“下一步(Next)”然后指定 OpenOffice.org 应在何处查找以及转换后的文件放在哪个目录。在继续之前，确保所有其他设置都是恰当的。

> 注意
> 来自 Windows 分区的文档通常位于 `/windows/` 子目录下。

点击“下一步(Next)”查看要执行的操作摘要，这提供了再次检查所有设置是否正确的机会。最后，通过“转换(Convert)”开始转换。

## 7.5 修改全局设置

可以通过选择“工具(Tools)”->“选项...(Options)”来修改全局设置。这将打开图 7.2 所示的窗口。使用树结构显示设置类别。

OpenOffice.org 此项涵盖了各种基本设置。包括你的用户数据（如地址和电子邮件）、导入路径，以及打印机和外部程序的设置。

![](img/705a076b108ea96be0c0695efb5556ce_208_0.png)

图 7.2：选项对话框

“加载/保存(Load/Save)”此项包含与多种文件类型加载和保存相关的设置。有一个用于通用设置的对话框以及定义如何处理外部格式的特殊对话框。

“语言设置(Language Settings)”此项涵盖了与语言和写作辅助相关的各种设置，即你的区域设置和拼写检查设置。这也是启用亚洲语言支持的地方。

“互联网(Internet)”此项包含配置任何代理和更改与搜索引擎相关设置的对话框。

“文本文档(Text Document)”在此项下配置全局文字处理选项，例如 Writer 应使用的基本功能和布局。

“HTML 文档(HTML Document)”在此项下更改与 OpenOffice.org HTMLset功能相关的设置。

“电子表格(Spreadsheet)”使用此项更改 Calc 的设置，例如与排序列表和网格相关的设置。

“演示文稿(Presentation)”在此项下更改适用于所有演示文稿的设置。例如，指定用于排列元素的网格的测量单位。

‘绘图’ 此条目涵盖了与矢量绘制模块相关的设置，如绘图比例、网格属性以及某些打印选项。

‘公式’ 此条目提供了一个单一对话框，用于设置公式的一些特殊打印选项。

‘图表’ 这定义了新创建图表时使用的默认颜色。

‘数据源’ 使用此项来定义如何访问外部数据源。

> 注意上述列出的所有设置均为全局应用——它们将作为你创建的每个新文档的默认设置。

## 7.6 使用 OpenOffice.org Writer 进行文字处理

### 7.6.1 使用 AutoPilot 创建文本

若要为自己的文档使用标准格式和预定义元素，请尝试使用 AutoPilot。这是一个小型实用程序，让让你做出一些基本决策，然后从模板生成一个准备就绪文档。例如，要创建一封商务信，选择‘文件’->‘AutoPilot’，然后选择‘信...’。这将打开下一页图 7.3 所示的对话框。

点击每页中的‘下一步’继续下一页。如需修改任何之前的条目，请使用‘上退’。完成后，点击‘创建’以根据你的规格生成信件。使用‘取消’退出对话框。使用‘帮助’访问帮助文档。

完成后，点击‘创建’。OpenOffice.org 根据你的规格生成一封信。现在，编写信件本身的文本（正文）。AutoPilot 不限于信件，还可以协助创建议程、备忘录和演示文稿。

![](img/705a076b108ea96be0c0695efb5556ce_210_0.png)

图 7.3：OpenOffice.org 的 AutoPilot

### 7.6.2 不使用 AutoPilot 创建文本

通过选择‘文件’->‘新建’->‘文本文档’创建一个新文档。在编辑文档时，标准功能栏正下方有一个名为对象栏的第二个工具栏。将鼠标指针悬停在图标上可以获取简短的帮助文本。文档也可以使用样式表（Stylist）进行格式设置，该内容将在后续页的第 7.6.4 节中描述。

### 7.6.3 选择文本

要进行选择，点击所需的选择起始位置，并按住鼠标将光标移向范围末尾（可以是字符、行或整个段落）。在所需的选择结束处释放按钮。在选中时，文本将以反转颜色显示。通过右键点击选择内容打开上下文菜单。使用上下文菜单更改字体、字体样式和其他文本属性。导航器显示有关文档内容的信息。它还允许你快速跳转到包含的各种元素。例如，使用导航器快速概览所有章节，或者查看文档中包含的图像列表。下一页的图 7.4 显示了导航器的操作。导航器中列出的元素根据 Writer 中加载的文档而异。通过选择‘编辑’->‘导航器’打开导航器。

![](img/705a076b108ea96be0c0695efb5556ce_211_0.png)

图 7.4：Writer 中的导航器

### 7.6.4 使用样式表

样式表可以通过多种方式帮助你格式化文本。你可以通过切换‘格式’->‘样式表’或按下 `(F11)` 随时打开或关闭。样式表的对话框显示在对应页的图 7.5 中。

如果你将样式表底部的下拉列表设置为‘自动’，OpenOffice.org 会尝试提供适应于当前任务的样式选择。另一方面，如果你选择‘所有’，样式表将提供来自当前活动组的所有样式。通过顶部的按钮选择组组。文本可以进行硬格式化，也可以进行软格式化：

| 方法 | 说明 |
| :--- | :--- |
| **硬格式化** | 将格式属性直接分配给文本范围，且每个属性必须应用于每个范围，它是静态的，且只能手动更改。这仅建议用于短文档。 |
