# vc — 版本控制

### 摘要
`/usr/ccs/bin/vc [-a] [-t] [-cchar] [-s] [keyword=value... keyword=value]`

## 描述

> 注意 — 此命令已过时，将在下版本中删除。

`vc` 命令从标准输入复制行到标准输出，使用标准输入中的参数和控制语句。在复制操作中，用户声明的关键字出现在纯文本和/或控制语句中时，可以替换为它们的字符串值。
从标准输入到标准输出的行复制是有条件的，基于控制语句中指定的或作为 `vc` 参数的关键字值的测试（在控制语句中）。
控制语句为单行。

## 选项

- `-a` 强制替换所有行中的关键字。
- `-c` 指定一个用于代替冒号的字符。
- `-s` 静默通常打印的消息。
- `-t` 忽略所有字符。

`vc` 识别以下控制语句：

- `asg keyword=value` 为关键字赋值。`asg` 语句会覆盖关键字的赋值。
- `dcl keyword[, keyword]` 声明关键字。所有关键字必须先声明。
- `if condition` 跳过标准输入行。如果条件为真，则将该语句到结束语句之间的行复制到标准输出。如果条件为假，则丢弃中间行，包括控制语句。

## 条件的语法为：

```
cond  ::= "not" <or>

or    ::= <and> <and> <or>

and   ::= <exp> <exp> "&" <and>

exp   ::= "<" |
```

可用运算符及其含义为：

+ 等于。
!= 不等于。
& 与。
| 逻辑。
> 大于。
< 小于。
() 用于逻辑分组。

`not` 只能跟在 `if` 后面。当存在 `not` 时，它反转整个条件的值。
`>` 和 `<` 仅对无符号整数值操作（例如：012 > 12 为假）。所有其他运算符接受字符串作为参数（例如：012 != 12 为真）。

运算符的优先级（从高到低）为：

+ != >= > 所有优先级。
* &
* |

可以使用括号来改变优先级。
值与运算符或括号之间至少分隔一个空格或制表符。

```
::text 替换复制到标准输出行中的关键字。移除行首两个控制字符，并将文本中被控制字符包围的关键字替换为其值，然后复制行到输出文件。此操作与 -a 字母无关。
```

```
:on 开启或关闭所有行的关键字替换。
```

```
:ctl char 将控制字符改为 char。
```

```
:msg message 在诊断输出上打印消息。
:err message 在诊断输出上打印消息以及 ERROR: err 语句位于行 ... (915)。停止执行并返回退出代码 1。
```
