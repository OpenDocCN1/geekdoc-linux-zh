## barrendero

根据年龄删除堆积目录中的消息。`Barrendero` 旨在限制堆积目录浪费的空间。它根据年龄删除消息，并能够向用户发送警告和报告，进行完整和部分备份，并根据每个用户允许不同的年龄。警告和报告消息是可自定义的，并且可以轻松翻译，以便此包在任何环境中都用。这种处理邮件的方法比传统的“配额”(`quota`)系统更有优势：配额可能会导致最终用户丢失新邮件，而 `barrendero` 删除旧邮件，因此新邮件可用。来自 Debian 3.0r APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## BASIC

`/bay-sic/` n. 一种编程语言，为 20 世纪 60 年代的期的实验分时系统设计，多年来它是黑客的大脑损伤的主因。Edsger W. Dijkstra《计算选集：个人观点》“对于接触过 BASIC 的学生教授良好的编程几乎是不可能的。”这是另一种情况（如 Pascal），当一种语言作为教育工具变得太严肃时。非常短的 BASIC 程序（10-20 行）非常容易；编写任何 (a) 是痛苦的，并且 (b) 养成使用更强大语言的习惯。如果历史事故让 80 年代的低端机器得到慰藉，这可能会破坏数千个潜在的魔法师。有些被称为“BASIC”的并不糟糕，像 Pascal 和 C 那样的过程和控制结构并放弃了行号。此外：名字通常是 Beginner's All-purpose Symbolic Code，这是一个倒缩写。BASIC 最初命名为 Basic 是因为它是一种简单基础的编程语言。因为名称是缩写，BASIC 往往只是为了安静。最初不存在 BASIC 的缩写或刻意设计的（可以通过阅读 70 年代初的文本来验证）。后来，在 70 年代中期，人们开始为 BASIC 制作倒缩写，因为他们不确定。Beginner's All-purpose Symbolic Code 是那个被称为 Dictionary `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
