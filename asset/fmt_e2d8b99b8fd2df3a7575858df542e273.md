
### 表 8.2 匹配修饰符

| 修饰符 | 含义 |
| :--- | :--- |
| i | 关闭大小写敏感性。 |
| m | 将字符串视为多行。 |
| o | 仅编译模式一次。用于优化搜索。 |
| s | 当嵌入换行符时，将字符串视为单行。 |
| x | 允许在正则表达式中使用注释并忽略空白字符。 |
| g | 全局匹配；即找到所有出现的位置。如果在数组上下文中使用，则返回一个列表；如果在标量上下文中使用，则返回 true 或 false。 |

## 示例 8.7

```text
1 m/Good morning/ 
2 /Good evening/ 
3 \\/usr\\/var\\/adm/ 
4 m#/usr/var/adm# 
5 m(Good evening) 
6 m('$name')
```

### 解释

1. 在这个例子中，由于前向斜杠限制了正则表达式，因此不需要 `m` 运算符。
2. 前向斜杠是分隔符；因此，`m` 运算符是可选的。
3. 搜索路径中的每个前向斜杠都用反斜杠引用，以免与用作模式分隔符的前向斜杠混淆——这是一种混乱的方法。
4. 因为使用井号 `#` 作为前向斜杠的替代，所以 `m` 运算符是必需的。井号分隔符澄清并简化了前面的例子。
5. 如果起始分隔符是圆括号、方括号、尖括号或花括号，则结束分隔符必须是对应的结束字符：`m`(`expression`)、`m`[`expression`]、`m`<`expression`> 或 `m`{`expression`}。
6. 如果分隔符是单引号，则关闭变量插值；换句话说，`$name` 被视为字面值。

## 示例 8.8

```perl
# (The Script)
use warnings;
while (<DATA>) {
    print if /Betty/;   # Print the line if it matches Betty
}
__DATA__
Steve Blenheim
Betty Boop
Igor Chevesky
Norma Cord
Jon Deloach
Karen Evich
# (Output)
Betty Boop
```

### 解释

1. 所有匹配模式 `Betty` 的行都会被打印。
2. `DATA` 文件句柄从跟随 `__DATA__` 标记的那些行获取其数据。

## 示例 8.9

```perl
# (The Script)
use warnings;
while (<DATA>) {
    print unless /Evich/;   # Print line unless it matches Evich
}
__DATA__
Steve Blenheim
Betty Boop
Igor Chevesky
Norma Cord
Jon Deloach
Karen Evich
# (Output)
Steve Blenheim
Betty Boop
Igor Chevesky
Norma Cord
Jon Deloach
```

### 解释

1. 所有不匹配模式 `Evich` 的行都会被打印。
2. `DATA` 文件句柄从跟随 `__DATA__` 标记的那些行获取其数据。

## 示例 8.10

```perl
# (The Script)
use warnings;
while (<DATA>) {
    print if m@Jon@;   # Print the line if it matches Jon
}
__DATA__
Steve Blenheim
Betty Boop
Igor Chevesky
Norma Cord
Jon DeLoach
Karen Evich
# (Output)
Jon DeLoach
```

### 解释

1. 由于分隔符从默认的前向斜杠更改为 at 符号 `@`，因此 `m` `match` 运算符是必需的。如果该行匹配 `Jon`，则该行会被打印。
2. `DATA` 文件句柄从跟随 `__DATA__` 标记的那些行获取其数据。

## 示例 8.11

```perl
# (The Script)
use warnings;
while (<DATA>) {
    print if m(Karen E);  # Print the line if it matches Karen E
}
$name = "Jon";
$_ = "$name is a good sport.\n";
print if m'$name';
print if m"$name";
__DATA__
Steve Blenheim
Betty Boop
Igor Chevesky
Norma Cord
Jon DeLoach
Karen Evich
# (Output)
Karen Evich
<No output>
Jon is a good sport.
```

### 解释

1. 由于分隔符从默认的前向斜杠更改为一对开始和结束圆括号，因此 `m` `match` 运算符是必需的。其他可用的对包括方括号、花括号、尖括号和单引号。如果使用单引号，且正则表达式包含变量，则变量不会被插值。如果该行匹配 `Karen E`，则该行会被打印。
2. 标量 `$name` 被赋值为 `Jon`。
3. `$_` 被赋值为一个包含标量 `$name` 的字符串。
4. 当匹配分隔符是一组单引号时，正则表达式中的变量不会被插值。在 `$_` 中未找到字面值 `$name`；因此，什么也不会打印。
5. 如果表达式由双引号包围，则变量 `$name` 将被插值。如果分配给 `$_` 的字符串包含 `Jon`，则该字符串会被打印。
6. `DATA` 文件句柄从跟随 `__DATA__` 标记的那些行获取其数据。

**`g` 修饰符——全局匹配。** `g` 修饰符用于执行全局匹配；换句话说，匹配该行中模式的所有出现位置。如果没有 `g`，则只匹配模式的第一次出现。`m` 运算符将返回匹配的模式列表。

### 格式

```perl
m/search pattern/g
```

## 示例 8.12

```perl
# (The Script)
use warnings;
$_ = "I lost my gloves in the clover, Love.";
my @list = /love/gi;
print "@list.\n";
# (Output)
love Love.
```

### 解释

1. `$_` 标量变量被赋值为一段文本字符串。
2. 如果使用 `g` 修饰符进行搜索，在数组上下文中，每个匹配项都存储在 `@list` 数组中。正则表达式 `love` 在字符串中被找到两次，一次在 `gloves` 中，一次在 `clover` 中。`Love` 未匹配，因为 `L` 是大写的。
3. 匹配的项列表被打印。

## i 修饰符——忽略大小写

Perl 在执行匹配时，对字符的大小写敏感。若要关闭大小写敏感性，需在匹配运算符的最后一个定界符后追加 `i` `insensitive`，不敏感。

### 格式

```
m/搜索模式/i
```

### 示例 8.13

```perl
(脚本)
use warnings;
$_ = "I lost my gloves in the clover, Love.";
my @list=/love/gi;
print "@list.\n";
(输出)
love love Love.
```
