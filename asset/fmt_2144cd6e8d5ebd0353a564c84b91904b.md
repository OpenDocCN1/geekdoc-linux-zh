```
get_count()
```

返回一个元组 `(count0, count1, count2)`，包含每代中当前存在的对象数量。

```
get_debug()
```

返回当前设置的调试标志位。

```

```

返回一个由垃圾回收器跟踪的所有对象的列表。不包含所返回的列表本身。

```
get_referr(obj1, obj2, ...)
```

返回一个所有直接引用 `obj1`、`obj2` 等对象的列表。返回的列表可能包含未被垃圾回收的对象以及部分构造的对象。

```
get_referents(obj1, obj2, ...)
```

返回一个 `obj1`、`obj2` 等所指向的对象列表。例如，如果 `obj1` 是一个容器，这将返回容器内部元素的列表。

```
get_threshold()
```

以元组形式返回当前的阈值。

```
isEnabled()
```

如果启用了垃圾回收，则返回 `True`。

```
set_debug(flags)
```

设置垃圾回收调试标志，可用于调试垃圾回收器的行为。`flags` 是常量 `DEBUG_STATS`、`DEBUG_COLLECTABLE`、`DEBUG_UNCOLLECTABLE`、`DEBUG_INSTANCES`、`DEBUG_OBJECTS`、`DEBUG_SAVEALL` 和 `DEBUG_LEAK` 的按位或结果。`LEAK` 标志可能是最有用的，因为它会让收集器打印用于调试具有内存泄漏的程序信息。

```
set_threshold(threshold0, threshold1, threshold2)
```

设置垃圾回收的频率。对象被分为三代，第 0 代包含年轻的对象，第 2 代包含最旧的对象。在垃圾回收步骤中存活的对象会被移动到老一代。`threshold0` 是在第 0 代发生垃圾回收之前必须达到的分配数与释放数之差。`threshold1` 是在扫描第 1 代之前发生的第 0 代收集次数。`threshold2` 是在收集第 2 代之前在第 1 代必须发生的收集次数。目前的默认阈值设置为 `(700, 10, 10)`。将 `threshold0` 设置为 0 将禁用垃圾回收。

## 第 13 章 Python 运行时服务

### 注意事项

- 涉及带有 `__del__()` 方法对象的循环引用不会被垃圾回收，并被放入 `gc.garbage` 列表（不可回收对象）。由于与对象终结相关的困难，这些对象不会被收集。
- `get_referrers()` 和 `get_referents()` 函数仅适用于支持垃圾回收的对象。此外，这些函数仅用于调试，不应用于其他用途。

## inspect

`inspect` 模块用于收集有关存活 Python 对象的信息，例如属性、文档来源、源代码、堆栈帧等。

`cleandoc(doc)`

清理文档字符串 `doc`，通过将所有制表符转换为空格，并移除为了使 docstring 与函数或方法内部其他语句对齐而插入的缩进。

`currentframe()`

返回与调用者堆栈帧对应的对应的帧（frame）。

`formatargspec(args [, varags [, varkw [, defaults]]])`

产生一个格式化正确的字符串，表示 `getargspec()` 返回的值。

`formatargvalues(args [, varags [, varkw [, locals]]])`

产生一个格式化正确的字符串，表示 `getargvalues()` 返回的值。

`getargspec()`

给定一个函数 `func`，返回一个元组 `ArgSpec(args, varags, warkw, defaults)`。`args` 是参数名称列表，`varags` 是 `*`（如果有）的名称，`warkw` 是 `**`（如果有）的名称，`defaults` 是默认值的元组，如果没有默认值则为 `None`。如果存在默认值，`defaults` 代表 `args` 中最后 `n` 个参数的值，其中 `n` 等于 `len(defaults)`。

`getargvalues(frame)`

返回传递给带有执行帧的函数的参数值。返回一个元组 `ArgInfo(args, varags, warkw, locals)`。`args` 是参数名称列表，`varags` 是 `*`（如果有）的名称，`locals` 是帧的字典。

`getmro(class1, base2, ..., unique=True)`

给定一个类列表，此函数根据继承关系将类组织成层次结构。该层次结构表示为嵌套列表的集合，列表中的每个项目都是继承自前一个列表的类列表。列表中的每个项目是一个二元组 `(cls, bases)`，其中 `cls` 是类对象，`bases` 是基类的元组。如果 `unique` 为 `True`，则每个类在返回列表中只出现一次。否则，如果使用了多重继承，一个类可能会出现多次。

```

```

返回一个由 Python 源代码中紧邻 `object` 定义之前的注释组成的字符串。如果 `object` 是模块，则返回在模块顶部的注释。如果没有找到注释，则返回 `None`。

```

```

```

```

```

返回一个命名元组 `Traceback(filename, lineno, function, code_context, index)`，包含有关对象帧的信息。`filename` 和 `line` 指定了源位置。`context` 参数指定了上下文。

```

```

返回 `traceback` 及其所有内部帧的列表。此列表表示调用序列，第一个项目包含帧的信息。每个记录是一个六元组 `(frame, filename, line, fullname, contextlist, index)`，其字段含义与 `getframeinfo()` 相同。

```
