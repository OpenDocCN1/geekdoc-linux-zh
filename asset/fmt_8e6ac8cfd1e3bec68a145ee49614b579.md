
为了让你的 iPod 达到 Linux 下的舒适可用状态，请点击 iTunes 窗口右侧格中的“恢复”（Restore）按钮。会出现一个警告窗口，提示你 iPod 上的所有内容都将被删除（这就是我之前警告先备份所有内容的原因）。点击“恢复并更新”（Restore and Update）按钮，然后按照简短的向导操作。向导完成后，静静等待 iPod 恢复（到 Windows 格式）。这需要几分钟时间，请享受这段短暂的休息。

进程完成后，会出现一个新窗口要求你为 iPod 命名，并询问你是否希望 iTunes 自动将 iPod 与你的照片和音乐收藏同步（图 16-2）。给 iPod 起什么名字随你决定（短名称在 GNOME 桌面显示效果更好），但我强烈建议勾选两个自动同步复选框；否则以后可能会导致意想不到的异常。完成后，点击`OK`。

一旦整个过程完成，你将拥有一个配置正确、FAT32 格式且完全空的 iPod，它已准备好在 Linux、Windows 和 Mac OS 上使用。你现在甚至可以在所有系统上交替查看你的 iPod，尽管我只会在禁用自动更新功能的情况下才会这样做。

## 从 iPod 拷贝文件到硬盘

虽然 `iTunes` 允许你向 iPod 添加文件，但不允许你从 iPod 拷贝文件。自动更新功能是严格的单行道。这意味着每当你将开启了自动更新的 iPod 连接到支持 `iTunes` 的电脑时，`iTunes` 都会自动将其库中的曲目添加到你的 iPod 中，更可怕的是，它会移除 iPod 上任何库中不存在的曲目。我是通过一次惨痛的经历学到这一点的：我把妻子装满歌曲的 iPod 带到公司，插入了我 `iTunes` 库完全空的办公室 Windows 电脑上。当我把那个空空如也的小 Podster 带回给她时，场面可真难看。

### 使用 Rhythbox 管理 iPod 文件

虽然最新版本的 `Rhythbox` 应该能满足你的 iPod 需求，但其他应用也可以完成工作。例如，音频播放器 `Songbird` 和 `Amarok`（在第 15 章中简要提到）也支持 iPod。还有一些专门针对 iPod 的应用程序，其中一个 `gtkpod`。如图 16-4 所示，`gtkpod` 是一个非常直观的程序，用户群很大，这意味着可以在 Ubuntu 和其他 Linux 在线论坛找到很多答案。它还处理了处理 iPod 时常用的许多功能，包括专辑封面（但不是照片）。不过，`gtkpod` 并不是音频播放器；相反，它是 `XMMS`，如果你有其他喜欢的播放器，可以更改设置。

### 在 gtkpod 中管理 iPod 音频文件

`iTunes` 没有提供的功能（至少在没有特殊插件的情况下）之一是从 iPod 拷贝歌曲到硬盘。幸运的是，事实上所有支持 iPod 的音频播放器都可以轻松地做到这一点。

### 弹出你的 iPod

当你在 `Rhythbox` 中操作 iPod 时，可以通过以下方式弹出：在 `Rhythbox` 窗口左侧格中点击该项目并点击窗口顶部的“弹出”（Eject）按钮，或者在左侧格中右键点击它，并在弹出菜单中选择“弹出”。

## 使用 gtkpod 管理你的 iPod

### 下载、安装和运行 gtkpod

在课程中，为了使用 `gtkpod`，你首先需要下载并安装它。你可以通过 `Synaptic` 搜索 `gtkpod`，然后按照第 68 页项目 5A 中的安装步骤安装 `gtkpod-aac`。如果你之前在第 246 页的项目 15A 中没有安装多媒体解码器包，现在是安装它们的好时机。之后，如果你还没有连接 iPod，请将其插入电脑的 USB 端口。一旦你的 iPod 挂载（一旦桌面图标出现且 Rhythmbox 打开），请转到“应用程序”菜单并选择“音频与视频” > “gtkpod”。你可以根据需要关闭 `Rhythmbox`。

#### 使用 gtkpod

当 `gtkpod` 窗口打开时，你应该会在左窗格看到三个项目：本地（Local）、播客（Podcasts）和 iPod。要显示 iPod 的内容，点击左侧窗格中的 iPod 条目，然后点击“加载 iPod(s)”按钮。你的 iPod 内容将显示在右窗格中。如果你在 iPod 上有任何播放列表，点击窗口左窗格中 iPod 名称左侧的小箭头以显示你的列表。

要添加新歌曲或歌曲文件夹，点击菜单栏上的“文件”（Files）或“目录”（Dirs），并导航到你想要添加的项目。你也可以通过点击“播放列表”（Playlist）来创建特定文件夹内容的播放列表，或者通过点击“新建播放列表”（New PL）来构建自己的播放列表。

当你点击“New PL”时，窗口左侧的“播放列表”窗格会出现一个新列表。将你想要的歌曲从右窗格拖到左侧窗格的新列表中，以构建你的列表。（只需确保直接将文件拖到播放列表图标上，因为 `gtkpod` 在这方面可能有点挑剔。）你也可以以同样的方法将歌曲添加到现有列表中。

说到拖放，值得注意的是，你只需简单地将歌曲从你的“音乐”文件夹（或其他任何文件夹）拖出来，然后将其到 `gtkpod` 窗口的右窗格中，即可添加到你的 iPod。要将歌曲同时添加到 iPod 库和特定的播放列表，请将“音乐”文件夹中的文件或目录拖到相应播放列表的图标上。这非常酷炫。

## 使用 gtkpod 设置专辑封面和编辑标签

标签编辑（包括专辑封面图像）是 `gtkpod` 可以证明非常有用的另一个领域。要进行编辑，点击播放列表中的任何曲目并选择`编辑歌曲详情（Edit Track Details）`：该歌曲的窗口将会出现（图 16-5）。在该窗口中，你可以编辑所有的标签条目（艺术家、专辑、曲名、流等），并为歌曲设置专辑封面。一旦完成修改，点击`应用按钮（Apply button）`，然后点击 `OK`。

图 16-5：在 `gtkpod` 中编辑标签

## 使用 gtkpod 将文件从 iPod 复制到硬盘

与 `Rhythmbox` 类似，`gtkpod` 可以将歌曲从 iPod 复制到硬盘。要执行此操作，选择你想导出的歌曲或播放列表（按住 `CTRL` 键进行多选，或使用标签页选择特定艺术家或特定流的所有歌曲）。然后点击“文件”（File）菜单、`从数据库导出歌曲”（Export Tracks from Database）`，并从子菜单 *选定播放列表、选定条目或选定歌曲* 中选择一个目标。

与 `Rhythmbox` 一样，从 `gtkpod` 导出的 AAC 文件不会保留原始的文件名。解决方法与之前一样：只需手动更改文件名。无论你是否更改文件名，任何播放器窗口中都会显示正确的曲目标题和艺术家信息。

## 使用 gtkpod 在 iPod 上播放歌曲

你可以使用 `gtkpod` 播放 iPod 上的歌曲，但 `gtkpod` 必须使用辅助应用程序来实现，因为它本身不具备播放能力。为此目的的默认辅助程序是 `XMMS`，这并不是一个糟糕的选择，特别是当你希望获得无头疼的 AAC 文件支持时。

当然，如果你还没有安装 `XMMS`，将需要安装它或选择不同的辅助程序，例如 `Rhythmbox` 或 `amaraK`。要安装 `XMMS`，运行 `Synaptic` 并搜索 `xmms`（如果你想要 AAC 播放支持，请搜索 `xmms-mp3`）。要更改 `gtkpod` 的音频辅助程序，请转到“编辑”（Edit）菜单并选择`编辑偏好（Edit Preferences）`。进入偏好窗口后，点击“工具”（Tools）选项卡，然后将最上方框中的命令从 `xmms` 改为 `rhythbox` 或你任何喜欢的应用程序。做出选择后，点击应用，然后记录你的歌曲并关闭偏好窗口。

## 使用 gtkpod 完成工作

一旦你完成了所有想通过 `gtkpod` 做的操作，点击“加载 iPod(s)”按钮以保存你对 iPod 文件所做的任何更改。右键点击 `gtkpod` 窗口左窗格中的 iPod 图标并选择“弹出 iPod”（Eject iPod）。如果之后没有出现桌面桌面图标，右键点击它并选择“弹出”。当桌面图标消失时，你就可以断开 iPod 连接了。

## Floola 和 YamiPod

还有一对 iPod 管理应用可能让你感兴趣，可以作为 `gtkpod` 的替代方案：`Floola` 和 `YamiPod`。两者都是 iPod 文件管理领域的较新成员，但它们是很有吸引力且功能强大的替代方案。除了界面简洁外，两者都允许音频直接和无辅助程序的播放（`gtkpod` 不支持），而且它们的播放列表创建和处理更加精细。

### 下载、安装和运行 Floola

截至本文为止，`Floola` 和 `YamiPod` 无法通过 Automatik 或 `Synaptic` 获取，因此你可能需要从每个项目的网站下载它们。要获取 `Floola`，访问 floola.com 并下载 linux (GTK) 版本。当 Firefox 询问如何处理该文件时，点击 OK 接受默认的“归档管理器打开”，并将 `Floola-linux` 文件夹提取到你的主目录。你可以通过打开 `Floola-linux` 文件夹并双击二进制文件来运行 `Floola`。如 16-6 所示，`Floola` 将出现。
