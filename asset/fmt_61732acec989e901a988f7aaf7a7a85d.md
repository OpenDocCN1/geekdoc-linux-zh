# gfontview
Type 1 和 TrueType 字字体查看器。`gfontview` 是一个用于轮廓、PostScript(ctm) Type 1 和 TrueType 的字体查看器。`gfontview` 允许你在一个窗口中显示某个字体的字符或字符串，从而允许使用特定的字符串样本对多种字体进行比较。该字符或字符串可以进行别名处理（平滑）。如果在 AFM 或 TTF 文件中，字符串还可以考虑字间距对。显示的字符或字符串可以保存为 GIF 格式。还可以创建一个包含字体中所有字形的工具（PostScript Type 1 字体也包含多种编码）。该工具将为文件生成一个自定义编码，以允许你查看 Type 1 字体中的所有字符（而不仅仅是已编码的），这些被称为“自定义”编码。你还可以打印字体样本。程序生成带有各种尺寸示例字符串的 PostScript 代码，可以下载到任何 Postscript 或 ghostscript。TrueType 字体可以保存为 Type4 字体。来自 Debian 3.00 APT
