# 自动化、编程与源码修改

在每次拷贝操作之前，都会显示相关消息。如果你想在多个子目录的文件中搜索字符串（使用`grep`命令），这也会非常方便。许多版本的`grep`命令在不使用通配符（或在命令行中指定文件名）的情况下，无法找到所搜索文件的信息。以下示例使用`find`搜索C源文件，使用`awk`创建用于查找错误消息的`grep`命令，并使用shell的`echo`命令显示被搜索的文件：

```
$ find -name "*.c" -print |
awk '{print "echo " $1; grep error-message " $1}'
ksh
```

同样的技术可以用于对系列子目录中的源代码进行`lint`检查。它可以定期在shell脚本中运行以检查所有C代码：

```
$ find -name "*.c" -print |
awk '{print "lint " $1 > "$1.lint"}'
nksh
```

某个系统上的`lint`版本会将代码作为标题行打印，然后将问题的代码部分作为列表列在下方。`grep`只显示标题而不显示详情。`awk`脚本会打印从标题开始到第一个空行（`lint`部分的结束）的所有行。

如果有疑问，可以将输出通过管道交给`more`或`less`以查看生成的命令，或者将它们管道到shell中执行。
