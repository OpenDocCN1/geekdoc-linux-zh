
# combinations(iterable, r)
创建一个迭代器，返回从 `iterable` 中提取的所有长度为 `r` 的子序列。返回的子序列中项的顺序与它们在输入可迭代对象中的顺序相同。例如，如果 `iterable` 是列表 `[1,2,3,4]`，则 `combinations([1,2,3,4], 2)` 产生的序列为 `[[1,2], [1,3], [1,4], [2,3], [3,4]]`。

# count([n])
创建一个从 `n` 开始产生连续整数的迭代器。如果省略 `n`，计数将从 `0` 开始。（注意，此迭代器不支持长整数。如果超过了 `sys.maxint`，计数器将溢出并继续计数为 `-sys.maxint - 1`）。

# cycle(iterable)
创建一个反复循环 `iterable` 中元素的迭代器。在内部，会为 `iterable` 中的元素创建一个副本。该副本用于返回循环中重复的项。

# dropwhile(predicate, iterable)
创建一个迭代器，只要函数 `predicate(item)` 为 `True`，它就会丢弃 `iterable` 中的项。一旦 `predicate` 返回 `False`，该项以及 `iterable` 中的后续所有项都将被产生。

# groupby(iterable, {key})
创建一个对 `iterable` 产生的项进行分组的迭代器。分组通过识别具有相同键的连续项来工作。如果提供了 `key` 函数，则使用它来确定键；否则，使用项本身。

# filtertrue(predicate, iterable)
创建一个迭代器，只产生 `iterable` 中 `predicate(item)` 为 `True` 的项。如果 `predicate` 为 `None`，则使用真值。

# filterfalse(predicate, iterable)
创建一个迭代器，只产生 `iterable` 中 `predicate(item)` 为 `False` 的项。如果 `predicate` 为 `None`，则使用假值。

# imap(function, iter1, iter2, ..., iterN)
创建一个产生 `function(i1, i2, ...iN)` 的迭代器，其中 `i1, i2, ...iN` 分别来自迭代器 `iter1, iter2, ...iterN`。如果 `function` 为 `None`，则返回形式为 `(i1, i2, ...iN)` 的元组。当一个迭代器不再产生值时，迭代停止。

# islice(iterable, [start], stop, [step])
创建一个迭代器，产生产生的方式类似于切片 `iterable[start:stop:step]` 返回的结果。前 `start` 个项被跳过，并在 `stop` 处停止。每个 `step` 指定使用的步长。如果省略 `start`，迭代从 `0` 开始。如果省略 `step`，使用步长 `1`。

# zip(iter1, iter2, ..., iterN)
创建一个产生元组 `(i1, i2, ...iN)` 的迭代器，其中 `i1, i2, ...iN` 来自迭代器 `iter1, iter2, ...iterN`。当一个迭代器不再产生值时，迭代停止。

# zip_longest(iter1, iter2, ... iterN, fillvalue=None)
与 `zip()` 相同但迭代持续直到所有输入 `iter1, iter2` 等耗尽。除非使用 `fillvalue` 关键字指定了默认值，否则使用 `None` 填充已耗尽的可迭代对象的值。

# permutations(iterable, r)
创建一个返回 `iterable` 所有长度为 `r` 的排列的迭代器。如果省略 `r`，长度与 `iterable` 中项的数量相同。

# product(iter1, iter2, ... iterN, [repeat=1])
创建一个产生 `iter1, iter2` 等项的笛卡尔积元组的迭代器。`repeat` 是一个关键字参数，指定重复的次数。

# starmap(func, iterable)
创建一个产生 `func(*item)` 值的迭代器，其中 `item` 来自 `iterable`。这仅当 `iterable` 产生适用于这种方式调用函数的项时才有效。

# takewhile(predicate [, iterable])
创建一个迭代器，只要 `predicate(item)` 为 `True`，它就会产生 `iterable` 中的项。一旦 `predicate` 结果为 `False`，迭代立即停止。

# tee(iterable [, n])
从可迭代对象中创建 `n` 个独立的迭代器。创建的迭代器将以 `n` 元元组的形式返回。`n` 的默认值为 `2`。此函数适用于任何可迭代对象。然而，为了克隆原始迭代器，产生的项会被缓存并并在所有新创建的迭代器中使用。请务必不要在调用 `tee()` 之后使用原始迭代器，否则缓存机制可能无法正常工作。

# 示例

以下示例说明了 `itertools` 模块中某些函数的工作原理：

```python
from itertools import *

# 在无限循环中遍历数字 0,1,...,10,9,8,...,1

for i in cycle(chain(range(10), range(10,0,-1))):
    print i
```

```python
# 创建一个包含唯一元素的列表

a = [1,4,5,9,1,2,3,4,5,1]
a.sort()
b = [k for k in groupby(a)]  # b = [1,2,3,4,5,9]
```

```python
# 遍历来自 x 和 y 的值的所有可能的组合

x = [1,2,3,4,5]
y = [10,11,12]

for r in product(x,y):
    print r

# 输出 (1,10), (1,11), (1,12) ... (5,10), (5,11), (5,12)
```
