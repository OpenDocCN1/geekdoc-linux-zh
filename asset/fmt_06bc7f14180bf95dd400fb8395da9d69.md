
# 选择 Linux 发行版

## Linux 内核与 Linux 发行版

在谈论 Linux 发行版时，操作系统是 Linux。Linux 是`内核`，也是每个 Linux 发行版的核心。Linux 内核的软件由一组个人维护，林纳·托瓦尔斯领导。托瓦尔斯受一家名为 Linux 基金会的行业联盟聘用从事 Linux 内核。

> Linux 内核最早由芬兰的学生林纳·托瓦尔斯于 1991 年开发。1992 年，在 GNU 通用公共许可证第 2 版 `GPLv2` 下发布的第一个内核版本是 0.12 版本。

### Linux 内核

正如我们所提到的，所有 Linux 发行版运行的都是同一个操作系统 Linux。

### Linux 发行版

当人们谈论红帽 Linux 或 Ubuntu Linux 时，他们指的是`Linux 发行版`。Linux 发行版将带有一个 Linux 内核和一个环境，该环境以我们能够交互的方式使内核有用。至少我们需要一个像 `Bash` 这样的命令行 shell 以及一组允许我们访问和管理系统的基本命令。当然，开源的 Linux 发行版将具有完整的桌面环境，如 `Gnome` 或 `KDE`。

开发者们决定他们认为 Linux 应该是什么样的。因此，我们有数百种发行版。要查看更多 Linux 发行版，你可以访问 `Distro Watch` 网站，该网站的维护者列出了下载量前行的 Linux 发行版，允许你比较并查看当前哪些流行的。

### Linux 支持生命周期

正如你所期的，企业级 Linux 发行版的支持寿命比消费者版或社区版长。例如，红帽企业级 Linux `Red Hat Enterprise Linux` 提供 10 年的支持。`Red Hat Enterprise 8` 于 2019 年 5 月发布，软件更新和支持将持续到 2029 年 5 月。

消费者版仅通过论坛获得社区支持。软件更新通常提供 3 个版本。以 Ubuntu 为例，在编写时，19.04 是最新版本，更新一直持续到 19.10 发布，并在 2020 年 1 月停止。Ubuntu 还提供长期支持版本，即 LTS 版本，它们从原始发布起提供 5 年的支持。目前的 LTS 版本是 18.04，其软件更新将持续到 2023 年。这些 LTS 版本使得 Ubuntu 成为企业的选择，可以从 `Canonical`（Ubuntu 品牌后的公司）或独立咨询公司获得商业支持。

> 注意 Ubuntu 发行版使用基于日期的版本格式 `YY.MM`：例如，19.04 版本于 2019 年 4 月发布。

### Linux 作为你的桌面

在桌面支持侧重于商业操作系统提供的企业中，将 Linux 作为桌面系统可能更具挑战性。然而，不仅是支持可能证明具有挑战性。企业客户可能在软件解决方案上投入了大量资金，这使他们与特定的桌面操作系统绑定在一起。尽管如此，有许多 Linux 桌面集成到大型组织中的例子，像亚马逊这样的公司甚至有自己的 Linux 发行版 `Amazon Linux 2`。它被内部用于他们的 `AWS` 云平台，并同时用于服务器和桌面。

在较小的企业或在家使用 Linux 会变得简单得多，并且是一次有回报的体验，它消除了对许可的需求，并让你开眼界看到 Linux 丰富的免费和开源软件。你还会发现有许多不同的桌面环境。最常见的是 `Gnome` 和 `KDE`，但还有许多其他。决定取决于个人喜好。

### 在服务器上使用 Linux

在企业领域，使用 Linux 作为你的操作系统是常见做法。服务器由专门负责 Linux 的工程师维护。因此，即使有数千个用户，用户也可以对他们连接的服务器一无所知。服务器操作系统对他们并不重要，通常后端客户端应用程序在 Linux 和其他操作系统之间没有区别。同样，随着越来越多的应用程序在本地和远程云中被虚拟化或容器化，操作系统被掩盖得更多，而嵌入式操作系统可能是 Linux。

### 云端中的 Linux

熟悉 Linux 的另一个机会是在许多可用的公共云中部署 Linux。在许多其他提供商之一创建账户，将让你能够快速、方便地部署许多不同的 Linux 发行版。

### 非 Linux 操作系统

是的，尽管听起来不可置信，但存在不基于 Linux 内核的操作系统。当然，多年年来有很多此类系统并已被淘汰，但你仍然有其他选择可用，无论是在家里还是在办公室。

### Unix

在我们拥有 Linux 操作系统之前，有了 Unix。Unix 曾与硬件一起销售，直到今天，市场上仍有商业级 Unix，如 `AIX` 和 `HP-UX`。虽然 Linux 深受 Unix 的启发（以及它在某些硬件上的不可用），但 BSD 操作系统族直接基于 Unix。今天，`FreeBSD`、`NetBSD` 和 `OpenBSD` 以及其他一些相关的 BSD 系统作为免费软件可用。

Unix 在企业中被广泛使用，但随着 Linux 的增长，我们看到了 Unix 命运的衰落。随着 Linux 的增长和企业支持服务的随之增长，我们看到 Unix 慢慢消失。`Solaris`（源自 Sun 公司，后转至 Oracle）近期已经消失。这是电信公司使用的较大的操作系统之一，被称为电信电信级（Telco Grade）Unix。

### Unix 操作系统包括：

- `AIX`
- `FreeBSD`, `NetBSD`, `OpenBSD`
- `HP-UX`
- `Irix`
- `Solaris`

### Apple 的 macOS

`Apple` 的 `macOS`（此前称为 `OS X`）可以追溯到 2001 年。它非常基于 BSD Unix，并利用 `Bash` 命令行 shell，如果你习惯使用 Unix 或 Linux 操作系统，这是一个非常易于使用的系统。如果你正在使用 macOS，可以打开终端应用程序来访问命令行。再次运行相同的 `uname` 命令，我们可以检查报告的操作系统：

```
$ uname -s
Darwin
```

> 注意 这种情况下我们使用了 `-s` 参数来返回 OS 名称。我们之前使用 `-r` 来返回内核版本号。

### 微软 Windows

我们可以说，世界上大多数的桌面和笔记本电脑都是基于 Windows 的。该操作系统取得了巨大的成功，并主导了桌面市场多年。尽管它是专有软件且不免费，但通常在购买硬件时会包含操作系统许可证，因此它成了一个简单的选择。当然，整个硬件和软件供应商都为 Windows 提供支持，许多开源应用程序也适用于 Windows。Windows 的未来似乎没有像以前那样光明。随着现在销售的桌面和笔记本电脑减少，焦点已转向平板电脑和手机市场。这一市场一直被 Apple 和 Android 主导，微软很难立足。

作为一个服务器平台，微软现在允许其客户在 GUI（图形用户界面）和纯命令行版本之间选择。GUI 和命令行的分离是非常重要的。大多数时候，旧版微软服务器的 GUI 会加载，但没有人会使用它。考虑一个 `Active Directory` 域控制器……用户一直使用它进行域验证，但它从管理员的桌面远程管理，而不是在服务器上。
