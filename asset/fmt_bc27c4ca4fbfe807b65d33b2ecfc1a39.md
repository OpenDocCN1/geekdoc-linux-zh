
## 术语表 527

### 中断栈 (interrupt stack)
一种用于响应中断和异常的调用程序的运行时栈。在许多架构中，会提供一个系统级的中断栈，它与每个进程用户存储中的内核运行时栈相互独立。

### 反转页表 (inverted page table / 反向映射页表)
一种硬件内存驻留表，每个物理页有一个条目，并由物理地址而非虚拟地址进行索引。条目包含当前映射到物理页的虚拟地址；条目还包括保护和状态属性。硬件通过对虚拟地址计算哈希函数来选择表中的条目，处理虚拟到物理地址的转换。硬件通过链接条目来处理冲突，并在链中进行线性搜索，直到找到匹配的虚拟地址。另参见*正向映射页表 (forward-mapped page table)*。

### I/O
参见 input/output（输入输出）。

### I/O 重定向
将 I/O 流从默认分配重定向。例如，所有的标准 shell 都允许用户将标准输出流重定向到文件或进程。

### I/O 流
指向进程或从进程产生的数据流。UNIX 中的大多数 I/O 流都具有单一的通用数据格式，允许用户以工具为导向的方式编写程序，并通过重定向一个程序的标准输出流到另一个程序，将这些程序组合在管道中。

### ioctl
一种向内核指定 I/O 请求的数据结构。每个结构体持有数据缓冲区的地址以及要读取或写入的数据字节数。此类结构的数组通过 `readv` 和 `write` 系统调用传递给内核。

### I/O 向量
参见 *Internet Protocol*（网协议）。

### IP
参见 *Interprocess communication*（进程间通信）。

### IPC
参见 UNIX 进程间通信。

### job
在 UNIX 中，一组具有相同进程组标识符的进程。具有多个进程的作业通常通过管道创建。作业是使用作业控制操作的基本对象。

### 作业控制
一种管理作业的机制。通过作业控制，可以启动、停止、杀死作业，以及在前台和后台之间移动作业。终端处理程序提供了相关功能，用于自动停止尝试访问控制终端的后台作业，并在事件发生时通知作业的控制进程。

### 心跳包（keepalive packet）
TCP 用于维护有关目标主机是否在线信息的一种类型的数据包。心跳包被发送到远程主机，如果该主机在线，则必须做出响应。如果在合理时间内没有收到多个心跳包中的任何一个响应，则连接将被终止。心跳包仅用于那些为设置了 `SO_KEEPALIVE` 选项的套接字创建的 TCP 连接。

### 心跳定时器（keepalive timer）
TCP 协议结合心跳包使用的定时器。在发送心跳包时设置该定时器。如果在定时器过期多次后未收到对数据包的响应，则关闭连接。

### 内核（kernel）
提供基本系统设施的中央控制程序。4.4BSD 内核创建并管理进程，提供访问文件系统的函数，并提供通信设施。4.4BSD 内核是 4.4BSD 中用户无法替换的部分。

### 内核态（kernel mode）
处理器访问权限权限的模式。4.4BSD 内核在内核态下运行。

## 术语表 528

### 内核进程（kernel process）
以处理器内核模式执行的进程。`pagedemon` 和 `swapper` 进程都是内核进程的示例。

### 内核状态（kernel state）
内核的运行时执行状态。该状态包括程序计数器、通用寄存器和运行时栈，必须在每次上下文切换时进行保存和恢复。

### 删除字符（kill character）
终端处理程序在规范模式下识别的字符，用于“删除自最近一个行尾字符之后在该终端上输入的所有内容”。每个终端会话可以有不同的字符，用户可以随时通过 `tctattr` 系统调用更改该删除字符。终端处理程序在非规范模式的终端上不识别删除字符。另参见清除字符（erase character）；单词字符（word character）。

### 租约（lease）
一种允许活动的许可，有效期直到过期时间。在 NGFS 协议中，客户端从服务器获取租约以读取、写入和写入文件。只要客户端持有有效的租约，它就知道如果文件状态发生变化，服务器将通知它。一旦租约过期，客户端必须使用其已缓存的文件的任何数据联系服务器请求新租约。另参见回调（callback）；驱逐通知（eviction notice）。

### 最近最少使用（LRU）
一种重用策略，其中最久未使用的项会被重用。例如，在文件系统中，有固定数量的可用缓冲区用于 I/O。持有有效数据的缓冲区会在 LRU 缓冲区列表中按 LRU 顺序重新分配，希望缓冲区中持的数据可以被随后的读取请求重用。另参见 AGE 缓冲区列表；缓冲区缓存（buffer cache）。

### 行规律（line discipline）
内核中的一个处理模块，为异步串行接口或此类接口的软件仿真提供语义。行规律由一个过程化接口描述，其入口点存储在 `linews` 结构中。

### 行模式（line mode）
参见规范模式（canonical mode）。

### 链路（link）
ISO 开放系统互连模型中的第二层。在该模型中，链路层负责在单个物理网络内进行（可能是不可靠的）消息传递。链路层与 4.4BSD 网络子系统的网络接口层最为对应。

### 监听请求（listen request）
进程在套接字上执行系统调用后，向通信协议的用户例发出的请求。该请求指示系统应该监听建立到套接字连接的请求。否则，系统将拒绝收到的该套接字的任何连接请求。

### 平均负载（load average）
衡量系统 CPU 负载的指标。4.4BSD 中的平均负载定义为：就绪运行或等待磁盘 I/O 完成的进程数的平均值，是在之前的 1 分钟运行间隔内采样的。

## 术语表 529

### 本地域（local domain）
进程间通信设施中的通信域，支持单机进程之间流面向和数据报面向风格的通信。

### 引用局部性（locality of reference）
运行程序的内存引用在短时间内局限于虚拟地址空间内的现象。大多数程序倾向于表现出某种程度的引用局部性。这种局部性使得系统预取与缺页页面相邻的页面是有价值的，以降低运行程序的缺页率。

### 本地页面替换算法（local page-replacement algorithm）
一种页面替换算法，它首先选择一个要替换页面的进程，然后根据进程标准在该进程内选择一个页面。通常，进程会被赋予固定数量的页面，当它需要新页面时，必须从自己的页面中选择。

### 日志（log）
一种仅追加的文件。文件中现有数据不会被覆盖；因此，内核通过追加新数据来扩展文件。日志结构文件系统（Log-Structured Filesystem）实现了磁盘上日志的抽象。另参见非覆盖策略（no-overwrite policy）。

### 逻辑块（logical block）
通过将文件长度跨度除以底层块大小而定义的块。这种额外的映射层允许物理块被放置在磁盘上，而不必担心文件中逻辑块的线性组织。

### 逻辑驱动器分区（logical drive partitions）
一种将磁盘驱动器划分为一个或多个线性条目或区的软件方案。

### 逻辑单元（logical unit）
指定硬件设备单元数的整数。硬件设备和单元是以系统在引导序列的自动配置阶段发现的逻辑设备和单元的形式指定的。例如，对“磁盘驱动器 2 上的 1”的引用通常指向启动时识别的第三个驱动器的分区 1（设备从 0 开始编号）。逻辑单元与物理设备之间的实际映射是由构建内核的配置文件定义的。为了灵活性，大多数系统配置为支持物理与逻辑设备之间相当动态的映射。这种动态映射允许系统管理员例如将磁盘驱动器从一个控制器移动到另一个控制器，而无需重新配置新内核或重建设备相关的特殊文件。

### 长期调度算法（long-term–scheduling algorithm）
参见短期调度算法（short–scheduling algorithm）。

### 低水位（low watermark）
一种规定在采取操作前必须存在最小数据量的下限。在进程间通信设施中，每个套接字的数据缓冲区都有一个低水位，指定在满足接收请求之前数据缓冲区中必须存在的最小数据量。另参见高水位（high watermark）。

# 术语表

### LRU
参见最近未未使用（least recently used）。

### 机器检查 machine check
一种异常的机器状态，表示 CPU 检测到其操作发生错误。例如，如果在缓存内存中检测到校验错误，就会产生机器检查。

### 魔数 magic number
位于可执行文件前几个字节中的一个数字，用于指定可执行文件的类型。

### 主内存 main memory
机器上的首级内存系统。

### 主设备号 major-device-number
一个唯一标识设备类型的整数。它被定义为设备驱动程序入口点数组的索引。例如，当用户使用 `knod` 系统调用创建设备文件时就会使用它。

### 强制锁 mandatory lock
一种无法被忽略或避免的锁。强制锁与建议锁相对，后者在进程显式请求强制时才生效。另参见建议锁（advisory lock）。

### 映射对象 mapped object
一个其内存页被映射到进程地址空间的对象。进程使用 `mmap` 系统调用将对象映射到其虚拟地址空间。
