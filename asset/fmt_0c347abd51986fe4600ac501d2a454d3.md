
# 文件操作

| 命令 | 说明 |
| --- | --- |
| `print <file-handle> text ;` | 向文件写入内容。（如果未指定 `<file-handle>`，则写入到标准输出。如果未指定 `text`，则写入 `$_` 的内容） |
| `printf <file-handle> "format-str", values ;` | 向文件写入格式化字符串 `format-str`。使用转换说明符格式化值。（如果未指定 `<file-handle>`，则写入到标准输出。如果未指定值，则使用 `$_` 的内容） |
| `sprintf str-variable "format-str", values ;` | 将格式化后的值写入字符串 `str-variable`。使用转换说明符格式化值。（如果未指定值，则使用 `$_` 的内容） |

# 数组操作

| 操作 | 功能 |
| --- | --- |
| `push(array, value-list)` | 向数组末尾添加元素。 |
| `pop(array)` | 从数组末尾移除元素。 |
| `shift(array, value-list)` | 向数组开头添加元素。 |
| `unshift(array)` | 从数组开头移除元素。 |
| `sort(array)` | 按升序排序数组。 |
| `reverse(array)` | 按降序排序数组。 |
| `split(delim, str)` | 将字符串 `str` 拆分为元素数组。（`delim` 可以是模式或字符串。用于分隔字符串。） |
| `join(delim, array)` | 将 `array` 元素合并为一个字符串。 |
| `grep(array, pattern)` | 在数组元素中搜索模式。 |
| `splice(array, index)` | 使用 `splice` 从数组中删除元素。`index` 从 0 开始。 |
| `splice(array, index, num)` | 使用 `splice` 从数组中删除连续的 `num` 个元素。 |
| `splice(array, num,0, str)` | 使用 `splice` 在数组中插入值为 `str` 的元素。 |
| `splice(array, $#argv, str)` | 使用 `splice` 在数组末尾添加新元素。 |

# 逻辑运算符

| 运算符 | 功能 |
| --- | --- |
| `expression && expression` | 逻辑与条件在两个表达式都返回真 0 值时返回一个真 0 值；如果其中一个返回非零值，则 AND 条件为假并返回非零值。执行在第一个假表达式处停止。`and` 运算与 `&&` 相同，但优先级较低。 |
| `expression \|\| expression` | 逻辑或条件在其中一个表达式返回真 0 值时返回一个真 0 值；如果两个表达式都返回非零值，则 OR 条件为假并返回非零值。求值在第一个真表达式处停止。`or` 运算与 `\|\|` 相同，但优先级较低。 |
| `! command` | 逻辑非条件反转表达式的真假值。`not` 运算与 `!` 相同，但优先级较低。 |

# 条件控制

结构: `if`, `else`, `elsif`, `case`

| 结构 | 功能 |
| --- | --- |
| `LABEL: { statements; }` | 块是语句的集合，可以被标记 (`LABEL`) 并包含在左大大括号之间。语句按顺序执行。 |
| `if(expression) { statements; }` | 如果其测试表达式为真，则 `if` 执行语句。语句必须包含在块中。 |

## 控制结构

| 结构 | 功能 |
| --- | --- |
| `if(expression) { statements; } else(expression) { statements; }` | `if-else` 在测试表达式为真时执行语句；如果为假，则执行 `else` 语句。 |
| `if(expression) { statements; } elseif(expression) { statements; } else(expression) { statements; }` | `elsif` 允许你嵌套 `if` 结构，以便在多个备方案之间进行选择；在第一个真表达式处，执行其语句并跳出整个 `elsif` 结构。 |
| `unless(expression) { statements; }` | 如果测试表达式为假，则 `unless` 执行语句。 |
| `test ? stat1 : stat2` | 条件表达式，如果为真则执行 `stat1`，否则执行 `stat2`。通过使用列出的语句并让块中的最后一个语句引用该块的 `LABEL` 来模拟 `switch` 结构。 |

```
LABEL: { if(expr){ last LABEL); }
```

# 循环控制结构

结构: `while`, `until`, `for`, `foreach`

| 结构 | 功能 |
| --- | --- |
| `LABEL: while(expression) { statements; }` | 只要测试表达式为真，`while` 就执行语句。`LABEL` 是可选的。 |
| `do{ statements; } until(expression)` | 只要测试表达式为假，`until` 就执行语句。 |
