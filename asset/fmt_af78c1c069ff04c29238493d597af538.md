## 21.2 刻录 CD

检测到的刻录机显示在刻录对话框的“设备”下。刻录速度在“刻录速度”中。此处提供以下选项：

- “模式”此选项决定激光如何写入 CD。DAO（一次性刻录）模式下，在写入 CD 时激光不会禁用。该模式适用于创建音频 CD。然而，并不是所有的 CD 刻录机都支持它。在 TA 模式（逐轨道刻录）下，对每个单独的轨道应用单独的写入过程。RAW 模式并不常用，因为刻录机不执行任何数据纠正。最佳设置是“自动”，因为它允许 K3b 使用最合适的设置。

- “模拟”此功能可检查您的系统是否支持所选的写入速度。在禁用激光的情况下执行写入以测试系统。

- “即时刻录 (On the fly)”在不先创建镜像文件的情况下直接刻录所需数据（请勿在低性能机器上使用此功能）。镜像文件——也称为 ISO 镜像——是一个包含整个 CD 内容的文件，随后将原样写入 CD。

- “防欠写刻录 (Burnfree)”此选项以前被称为防刻录。它有助于避免 CD 产生欠写（underruns）。如果选择了 burnfree，CD 刻录机将标记当前位置，并在缓冲区欠写时返回此处。然而，这会导致音频 CD 中出现可听的数据间隙。最好是选择一个合适的速度以避免欠写。

- “仅创建镜像文件”此选项在“临时文件”下为该文件创建一个镜像文件。镜像文件可以在稍后写入 CD。要执行此，使用“工具” -> “写入 ISO 镜像”。如果使用此选项，本部分中的所有其他选项都将被禁用。

“设置”选项卡提供了创建具有多个数据或音频轨道的 CD（多扇刻录 CD）所需的选项。在“介质名称”选项卡中，为 CD 指定名称、描述、发行者和其他详细信息。

在“文件系统”下，指定 CD 上文件系统的设置（Rock-Ridge, Joliet, UDF）。还决定如何处理符号链接、文件权限和空白区域。在“高级”选项卡中，资深用户可以指定额外的设置。
