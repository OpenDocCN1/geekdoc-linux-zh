
`$ awk '{ printf "%03d %s\n", NR, $1 }' books`

`printf` 几乎原封不动地从 C 语言中引入，它提供了丰富的选项用于在任何可以想象的布局中格式化数字和字符串。`printf` 接受一个格式字符串，后面跟着要打印的参数。双引号内的格式字符串包含一组格式化规范，每个规范都以 `%` 开头，每个对应一个要打印的参数。在上面的示例中，`%03d` 格式化 `NR`，`%s` 格式化字段 `$1`。`d` 表示十进制数；`%03` 表示补导前零直到宽度为 3。`s` 表示格式字符串。最后的 `\n` 应该很熟悉：它提供换行符。与 `print` 不同，`printf` 不会在每次显示结束时自动生成新行，因此你必须像显示的那样提供一个，否则布局会变得混乱。你还可以在格式字符串中插入 `\t` 来生成制表符：

```awk
$ awk '{ printf "%03d %s\n", NR, $1 }'
```

- 001 Author
- 002 Smith
- 003 Jones
- 004 Brown

预定义变量 `OFMT` 在没有显式 `%` 规范的情况下决定数字的输出格式。默认格式为 `%.6g`，它处理的是一个精度为 6 位的十进制浮点数（`awk` 在内部始终以浮点格式处理所有数字）。

## -F 选项

`-F` 选项允许你更改字段分隔符字符。你只需要在 `-F` 后面跟随单个字符或正则表达式即可。一个典型的应用是 `-F:`，将分隔符设置为冒号。例如，`/etc/passwd` 文件使用冒号来分隔字段：

```bash
$ cat /etc/passwd
root:gf54JxxZ2Fd:0:1:::/bin/sh
stan:Ig65rsRdfdnn28:12:Stan Kelly-Bootle:/usr/stan/:/bin/bin
fred:qgs3324Fc22:512:Frederick Lemaitre:/usr/fred:/bin/csh
joe::27:14:Joseph Lussac:/usr/joe:
```

![](img/0aad0e0ec0359d5e535f4b2e4c2df9e9_330_0.png)

> 注意
> 出于安全考虑，许多现代 Unix 实现不再在 `/etc/passwd` 中存储加密密码。如果用户有密码，则会出现一个 `":"`；否则字段为空，`":"` 表示未分配密码。某些系统无论用户是否有密码，都会显示 `":"`。

`awk` 可用于调查你系统密码文件的重要属性。考虑以下内容：

```awk
$ awk -F: $2 == "" /etc/passwd # 注意：隐含了 print 命令
joe::27:14:Joseph Lussac:/usr/joe:
```

这个示例提供了一种发现那些未设置密码保护用户的快速方法！要了解它是如何工作的，首先注意 `-F` 告诉 `awk` 以冒号作为分隔符定义哪些字段。`$2` 指 `/etc/passwd` 中的第二个字段，即加密密码字段。模式匹配表达式 `$2 == ""` 测试该字段是否为空，或者说，测试第二个和第三个冒号之间是否有任何内容。记住，一旦 `FS` 定义为 `:`，冒号之间的任何空格都将“属于”该字段。我强调这一点，是因为初学者经常混淆空格、空值和字段分隔符。`==` 运算符同样从 C 语言引入，被称为关系运算符，因为它测试两个表达式之间的关系；在我们的案例中，它测试 `$2` 与空字符串 `""` 之间的相等性。

> 警告
> 请仔细区分 `==` 等价性测试和 `=` 赋值。混淆它们是 `awk` 和 C 编程错误的另一个常见来源。

![](img/0aad0e0ec0359d5e535f4b2e4c2df9e9_330_1.png)

`==` 运算符为你提供了一种选择行号范围的简洁方法：
`$ awk 'NR >= 5, NR <= 20' myfile`
将打印从第 5 行到第 20 行，包含边界。记得两个由逗号隔开的模式建立了一个范围。你可以列出除 33 行以外的所有行：
`$ awk 'NR != 33' myfile`
“不等于”运算符是 `!=`。在 C 语言中一样，`!` 在几种语文中带有否定的含义提示。让我们来看 `awk` 的关系运算符。

## awk 关系运算符

`awk` 允许表 14.5 所示的测试。这些运算符可以用于模式部分和动作部分。在模式部分，条件测试是隐含的：你只需要写下它，例如 `$2 == ""`，`awk` 就会寻找匹配。然而在动作部分，你需要显式的条件和流控制运算符，如 `if`、`else` 和 `while`，我稍后会解释它们。

表 14.5：`awk` 允许的测试

| 关系运算符 | 含义 |
| --- | --- |
| x = y | x 等于 y？ |
| x != y | x 不等于 y？ |
| x > y | x 大于 y？ |
| x >= y | x 大于等于 y？ |
| x < y | x 小于 y？ |
| x <= y | x 小于等于 y？ |
| x ~ re | 正则表达式？ |
| x != re | 不匹配正则表达式？ |

关系运算符的精确含义取决于所比较的变量或表达式的数据类型。对于数字和字符串，相等和不等的测试遵循明显的规则。你可以测试 `x == 33`，也可以测试 `str == "stan"`。对于数字，`>=` 等比较遵循通常的算术规则：`2 > 1`、`-1 > -2` 等。对于字符串，比较是按字典顺序进行的，因此 `"b" > "a"`、`"aa" > "a"` 等。

## 多重测试

通过提供三个逻辑运算符 `!` 非、`||` 或和 `&&` 与，`awk` 的模式检查能力得到了显著增强。这些运算符允许你测试复杂的组合：

```awk
$ awk '($1*$2) > 0) || ($6 == "Late")'
```

在这里，我们匹配任何数量乘以价格字段 1 和 2 为正，或者状态字段 6 为“Late”的行。注意使用括号对模式进行分组。即使它们对于控制优先级不是必需的，我建议使用它们来增加可读性。

### 表 14.6：awk 运算符优先级递增

| 分组 | 运算符 |
| --- | --- |
| 1 | += /= %= |
| 2 | \|\| |
| 3 | && |
| 4 | > >= <= != ~ |
| 5 | 字符串拼接："x" "y" 变成 "xy" |
| 6 | + - |
| 7 | * / % |
| 8 | ++ |

你已经以多种形式见过 NOT 反转运算符。在 `sed` 中，相同的符号 `!` 用于反转匹配的意思，但它被放在模式和动作之间。在 `awk` 中，`!` 总是放在要否定的表达式之前：`! x` 读作“NOT-x”。任何复杂的模式都可以通过在前面加感叹号 `!` 来否定。

## 开始与结束

两个特殊的表达式 `BEGIN` 和 `END` 可以用于模式参数。在 `BEGIN` 之后列出的任何操作在花括号内都将在 `awk` 扫描输入之前执行，而在 `END` 之后列出的任何操作都将在所有输入都扫描完毕后执行。`BEGIN` 用于显示标题和预设初始化变量。`END` 用于显示任何最终结果，例如字段总和。考虑：

```
$ awk
> BEGIN { FS = ":"; print "Security Check" }
> $2 == " " {count++}
 END { print count, "User(s) not password." } /etc/passwd
Security Check
joe:27:14:Joseph Lussac:/usr/joe:
1 User(s) not password.
```
