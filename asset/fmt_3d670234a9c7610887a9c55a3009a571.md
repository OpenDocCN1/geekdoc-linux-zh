## 编译程序

在本章中，我们将介绍如何通过编译源代码来构建程序。源代码的可用性是使 Linux 可能的核心自由。Linux 的整个开发生态系统依赖于开发者之间的自由交流。对于许多桌面用户来说，编译是一门失传的艺术。它曾经非常常见，但今天，发行版提供者维护着巨大的预编译二进制文件仓库，供下载和使用。在出版时，Debian 仓库（所有发行版中最大的仓库之一）包含了超过 68,000 个软件包。

那么为什么要编译软件呢？原因有两个：

- **可用性。** 尽管发行版仓库中有大量的预编译程序，但某些发行版可能不包含所有所需的应用程序。在这种情况下，获取所需程序的唯一方法就是从源代码进行编译。

- **及时性。** 虽然某些发行版专注于提供前沿版本的程序，但许多发行版并非如此。这意味着对于程序的最新版本，编译是必须的。

从源代码编译软件可能会变得复杂且具有技术性，并远超许多用户的能力范围。然而，许多编译任务是简单的，仅涉及几个步骤。这取决于软件包。我们将通过一个非常简单的案例来提供该过程的概述，并作为那些想要进一步学习的人的起点。

```
make Utility to maintain programs
```

### 什么是编译？

简单来说，编译是将源代码（程序员编写的人类可读的程序描述）翻译成计算机处理器的原生语言的过程。

计算机处理器（或 CPU）在元素级上工作，以所谓的“机器语言”执行程序。这是一种描述极小操作的数字代码，例如“加此字节”、“指向内存中的此位置”或“复制此字节”。每条指令都用二进制（0 和 1）表示。最早的计算机程序是使用这种数字代码编写的，这可能解释了为什么编写它们的程序员不得不抽很多烟、喝很多加咖啡，并且需要眼镜。

这个问题随着汇编语言的出现得到了解决，汇编语言将数字代码替换为（略微更容易使用的字符助记符，如 `CPY`（复制）和 `MOV`（移动）。汇编语言程序由一个名为汇编器的程序处理成机器语言。汇编语言在今天仍用于专门的编程任务，如设备驱动程序和嵌入式系统。

接下来我们来看所谓的高级编程语言，它们允许程序较少关注处理器正在做什么的细节，更多地通过手动解决问题。早期语言（开发于 20 世纪 50 年代）包括 FORTRAN（为科学技术任务设计）和 COBOL（为业务应用设计）。两者今天仍处于有限使用状态。

虽然有很多流行的编程语言，但有两种占据主导地位。大多数现代系统程序都是用 C 或 C++ 编写的。在接下来的示例中，我们将编译一个 C 程序。

用高级编程语言编写的程序通过另一个名为“编译器”的程序处理，转换为机器语言。某些编译器将高级指令翻译成汇编语言，然后使用汇编器执行到机器语言的最终阶段翻译。

通常与编译配合使用的过程是链接。程序执行许多常用任务，例如打开文件。许多程序都执行此任务，但如果让每个程序都实现自己的打开文件例程将是浪费的。更好的做法是让一段程序代码知道如何打开文件，并允许所有需要它的程序共享它。对常用任务的支持通过所谓的“库”来实现。这些库可以包含多个例程，每个例程执行某些多个程序可以共享的常用任务。如果我们查看 `/lib` 和 `/usr/lib` 目录，就可以看到许多库所在的位置。一个名为链接器的程序被用于在编译器的输出与编译程序所需的库之间建立连接。这一过程的最终结果是可执行程序文件，可以随时使用。

### 所有程序都编译了吗？

不是。正如我们所看到的，像 shell 脚本这样的程序不需要编译。它们被直接执行。这些程序是用被称为脚本语言或解释型语言编写的。这些语言在近年来变得流行，包括 Perl、Python、PHP、Ruby 等许多其他语言。

脚本语言由一个名为“解释器”的特殊程序执行。解释器输入程序文件并执行其中包含每条指令。通常，解释型程序的执行速度比编译程序慢。这是因为解释型程序中的每条源代码指令在每次执行时都会被翻译，而在编译程序中，源代码指令只被翻译一次，且这种翻译被永久记录在最终的可执行文件中。

为什么解释型语言如此流行？对于许多编程任务，结果是“足够快”，但真正的优势是开发解释型程序通常比开发编译型程序更快。程序通常在“代码-编译-测试”的循环中开发。随着程序规模增大，循环中的编译阶段可能会变得非常长。解释型语言消除了编译步骤并加快了程序的开发。

### 编译 C 程序

让我们编译点东西。但在在此之前，我们需要一些工具，如编译器、链接器和 `make`。Linux 环境中几乎通用的 C 编译器是 `gcc`（GNU C Compiler），它最初由 Richard Stallman 编写。大多数发行版默认不安装 `gcc`。我们可以像这样检查编译器是否存在：

```text
[me@linuxbox ~]$ which gcc

/usr/bin/gcc
```

此示例中的结果表明编译器已安装。

你的发行版可能包含一个用于软件开发的元软件包（软件包集合）。如果是的话，如果你打算在系统上编译程序，请考虑安装它。如果你的系统没有提供元软件包，尝试安装 `gcc` 和 `make` 软件包。在许多发行版中，这足以完成后续练习。
