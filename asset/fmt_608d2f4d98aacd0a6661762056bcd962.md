### 列表 18.12. C shell--计数器示例。

```csh
#!/bin/csh
#
# count1.csh
#
echo "Content-type: text/html"
echo ""
echo "<<html>"
echo "<head>"
#
# 处理选项
#
if ( $QUERY_STRING =~ "up" ) then
  set ADDER=1
else
  if ( $QUERY_STRING =~ "down" ) then
    set ADDER=-1
  else
    if ( $QUERY_STRING =~ "recall" ) then
      set ADDER=0
    else
      echo "<title> An error occurred </title>"
      echo "<body <p> someone goofed with this counter query is $QUERY_STRING"
      echo "</p> </body> </html>"
      exit 0
    endif
  endif
  endif
echo "<title>Counter</title>"
echo "</head> <body>"
#
# 读取计数器文件
#
set value_is='cat counter_file'
@ value_is = $value_is + $ADDER
echo $value_is > counter_file
echo $value_is
echo "</p> </body> </html>"
exit 0
```

`counter_file` 以值 `00000` 开始。应该被设置为所有者对它具有读写权限，否则它无法被修改。

该脚本在以下三行存在危险：

```bash
read value_is < counter_file
let value_is=value_is+ADDER
echo $value_is > counter_file
```

多个用户可能并发执行此操作，并且没有考虑到文件锁定机制。多个用户可能会看到相同的计数，因为第一个人在下一个人读取它之前没有写入新值。
