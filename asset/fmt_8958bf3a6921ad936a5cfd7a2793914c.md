## Linux 字典

### 奇偶位
在异步通信和主存储中，在字中增加的额外位，用于奇偶性检查。源自 QUEDIC `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### 奇偶性校验
用于检测内存或数据错误的技术。计算机累加一个字节项目中的位数数量，如果奇偶位与其它位之和不符，计算机就会报告错误。奇偶校验方案的原理是存储一个位（0 或 1），指示数据项中位之和是奇数还是偶数。当从内存读取数据项或由另一台计算机接收时，会发生奇偶性检查。如果检查发现奇偶位错误，计算机将显示错误信息。源自 QUEDIC `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### 奇偶错误
在奇偶性校验期间发生的错误，当一个或多个奇偶位错误时，表明数据处理或数据传输可能出错。源自 QUEDIC `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## Linux 字典

### parted–b
GNU 分区工具允许你创建、删除和移动硬盘。它适用于为新的操作系统创建空间、重新组织磁盘以及拷贝数据到新硬盘。源自 Debian 3.0r0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### partimage
Linux/Unix 工具，将分区以压缩镜像的形式保存。分区是一种 Linux/Unix 分区工具；它以 GZIP/BZIP2 格式保存 Ext2（标准）、原始 NTFS（NT 文件系统）或 FAT16/32（DOS 文件系统）。镜像可以压缩并拆分成多个文件，拷贝到移动介质（例如 ZIP）但在 CD-R。这使得通过单一操作保存 Linux/Windows 系统成为可能。出现问题（病毒、崩溃、错误）时，它是完全工作的。这在许多机器上安装相同软件时非常有用：只需安装一台，创建镜像，将其还原到所有其他机器上。第一台之后，安装是自动的，只需几分钟。源自 Debian 3.0r0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### partimage–server
用于网络上使用 part 的服务器。Partition Image 是一种 Linux/Unix 工具，它将你的分区备份到服务器。所有数据将使用 SSL 传输。源自 Debian 3.0r0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### 分区 (Partition)
由操作系统创建的磁盘驱动器的连续部分，大多数操作系统将其视为独立的物理驱动器。因此，一个磁盘可以分配多个驱动器号。源自 I–gloss `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### 分区 (partition)
硬盘内存的划分，在大多数操作系统中是完全独立的磁盘。源自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### 分区 (Partition)
为了组织目的或区分不同操作系统而创建的硬盘区域。分区在硬盘初始准备期间创建，随后对磁盘进行格式化。源自 MS–DOS，每个硬盘至少有一个 DOS 分区（MS–DOS 4.0 版本要求每个磁盘空间都有单独的分区）。每个分区由 DOS 创建，就像独立的驱动器一样。用户可以分区硬盘创建另一个操作系统，但可以使用 MultiDisk 等工具来创建系统分区。见目录和子目录。源自 QUEDIC `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# Pascal

一种高级过程化编程语言，利用了现代控制结构并避免了“面条代码”的产生。Pascal 作为一种教学和应用开发语言已获得广泛认可，尽管专业程序员更倾向于使用 C 或 C++。Pascal 既有解释版也有编译版。Pascal 的主要缺点是其标准版本（Standard Pascal）存在许多缺陷。该语言的发明者尼古拉斯·沃特（Nicholas Wirth）开发了新语言 Modula-2 作为 Pascal 的继任者，修复了该语言的一些问题，而 Borland International 的 Turbo Pascal 则让个人电脑用户能够更易地使用 Pascal。参阅来自 QUEDIC 的 BASIC 和 FORTRAN `http://www.tdlp.org/LDP/Linux-Dictionary/html/index`

# Pascal

一种由尼古拉斯·沃特于 1967 年左右在 CDC 6600 上开发的基于算法（Algo-descended）的语言——作为基础编程教学工具。这种语言的设计初衷是防止学生自乱阵脚，因此从通用编程的角度来看极其严格，但它后来被作为一种通用工具推广，并实际上成为了包括 Modula-2 和 Ada 在内的一大语言族的祖先。源自 Linux Guide@FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index`
