## 数据库

引擎最重要的工具是一个基于字符的应用程序，允许你查看引擎、数据库和表。它允许对特定实例的所有数据库进行查询和维护。请阅读数据库的文档。当你运行数据库时，你会得到以下显示：

```
DBACCESS: 查询语言 数据库 会话

使用 SQL 语言

--------------------------------按 W 帮助
```

`Dbaccess` 易于使用，并在 VT-100 窗口中运行良好。它为你的工作提供了一个很好的草稿。Informix 正在开发 GUI 工具，并将作为引擎发行的一部分提供。

## Onmonitor

我们没有使用的工具是 `onmonitor`。`onmonitor` 用于引擎监控和维护，但没有提供足够的活性或指导。你可以运行 `onmonitor` 并更改或查看许多许多设置；然而，大多数 Informix DBA 倾向于命令行控制。在生产环境中，你拥有的控制越多，情况就越好，因为一个错误的命令就会删除数据。只需运行 `onmonitor`，出现的以下输出是一个与 `dbaccess` 类似的字符用户界面：
