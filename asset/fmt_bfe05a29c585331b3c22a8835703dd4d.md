
`/mak/rob.` [技术术语] 一个名称（后跟一个正式列表参数），等同于一个文本或符号表达式，该表达式将被展开（通过替换参数），这被称为宏。这是在任何技术词典中使用的定义；它不会告诉你是如何工作的，也不会告诉该术语的黑客内涵是如何随时间变化的。“macro”一词起源于早期的汇编器，它鼓励将宏作为一种结构和信息隐藏的设备。在 20 世纪 70 年代初期，宏无处不在，有时甚至与昂贵的编译器技术一样强大；被边缘化的宏开始被用于与 `C` 预处理器相关联，或者用于围绕宏扩展机制构建的几种特殊用途语言之一（例如 `TeX` 或 `Unix` 的 `[nsoft]`）。事实上，它的含义已经发生了足够大的偏移，以至于“macros”这个复数现在被用于任何特殊应用程序语言中的代码（无论该语言实际上是否通过文本扩展翻译），以及用于类宏实体，例如某些文本编辑器支持的“键盘宏”（以及 `PC` `TSR` 或 `Macintosh` `INIT`/`CDEV` 键盘增强器）。源自 Jargon Dictionary

## M

一个包含某些其他命令的命令。你从现有命令自定义设计一个命令，称为宏。`vi` 编辑器以及 `nroff` 和 `troff` 都使用宏。书中描述的 `mm` 宏包是 `nroff` 和 `troff` 宏的大构集合的一个示例。源自 Linux First Guide `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## 宏 (Macro)

一个由重排的按键和应用程序命令组成的程序，应用程序执行这些按键以完成任务。宏可以自动化枯燥且经常重复的任务（例如将文件保存并备份到软盘）或用于保存数据输入的特殊菜单。某些程序提供宏录制模式，程序会记录你的按键，并将录制保存为宏。另一些程序提供内置的宏编辑器，你可以在其中输入并编辑宏以创建 `IF/THEN/ELSE` 语句和 `DO WHILE` 循环。源自 QUEDIC `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## 宏 (Macro)

一组以执行形式存储的指令。宏可以是特定应用程序（例如在该程序内执行特定步骤的电子表格或文字处理器），也可以是通用的（例如，当按下键盘上的 `Ctrl-U` 时输入用户 ID 的键盘宏）。源自 I-gloss `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## magic number

n. [`Unix`/`C`] 常见的。1. 在源代码中，某些非显式的常量，其值对程序的运行非常重要，并以内联方式（硬编码）插入，而不是通过注释的 `#define` 展开。这种意义上的魔法数是糟糕的。2. 一种以加密方式在算法中使用的关键数字。这些经典示例是用于哈希函数或 `CRC` 函数的数字，或者是伪随机数线性线性生成器的系数。这种意义特别 3. 位于文件开头的用于向工具指示其类型的特殊数据。`Unix` 系统和各种应用程序程序（特别是链接器）通过查找魔法数来区分可执行文件的类型。源自 Linux Guide @FirstLinux
