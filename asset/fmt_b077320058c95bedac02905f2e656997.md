# grub

通用统一引导程序 (`GRUB`) 是一个跨 x86 操作系统的 GPL 引导程序。它可以加载 Linux 内核，除了加载内核外，它启用了 Multiboot 标准，允许灵活加载多个启动镜像（GNU Hurd 等模块化内核所需）。来自 Debian 3.0 APT

# Linux 词典

`GRUB` 是一种基于 GPL 的启动引导加载程序，旨在统一 x86 操作系统的启动过程。除了加载 Linux 和 *BSD* 内核外，它还实现了 Multiboot 标准，该标准允许灵活地加载多个启动镜像（如 GNUHull 等模块化内核所需）。Mandrake 9.0 RPM `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

参阅通用统一引导加载程序 (`GRUB`)。源自 Redhat–9–Glossary `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

### grub-client

一个开源、分布式协作的数据提交客户端。这是 Grub 爬虫，用于向分布式开源项目提供网页内容的实时通知，该项目维护在 `<http://grub.org>`。你需要一个 `client-id` 才能加入其中。这是向数据库进行身份验证提交所必需的。此外，目前你只有在拥有静态 IP 地址时才能加入。Grub 反过来会向任何索引或搜索项目返回更新。对于公共消费，通知是免费的，但通过集中化和组织爬取，对其数据库的查询将收取某种费用。Grub 希望提高互联网的爬取速度，同时减少想要定期索引其内容的网站**所需的爬虫流量。不要将此软件包与同名的引导加载程序混淆。它与后者别无任何关系。该项目目前正在寻找更好的名字。源自 Debian 3.0o APT `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

### grun

基于 GTK 的对话框 `grub` 是一个基于 GTK 的对话框，类似于 Windows 的“运行”对话框，如 `xexec`。它是一个智能的历史机制，以及一种在独立进程中启动应用程序的双级（派生 fork）机制。`grub` 支持在 XTerm 中启动控制台应用程序以及文件类型。`grub` 比 `xexec` 更强大，外观好得多，并且有一个巨大的优势：你无需移动到文本框即可启动命令。如果你没有使用内置运行命令的 GNOME 桌面，或者使用窗口管理器（例如 iWeCm），那么 `grub` 特别好用。源自 Debian 3.0o APT `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

### gs

Ghostscript (PostScript 和 PDF 语言解释器和查看器) 源自 Whatis `http://www.tdlp.org/LDP/Linux-Dictionary/index.html`

Ghostscript 解释器 Ghostscript 用于 postscript 打印。将其作为 `ghostview` 等程序的后端使用，可以在 X11 环境中显示 postscript 文档。此外，它可以渲染 postscript 文件以便在非 postscript 打印机上打印。支持的打印机包括常见的针式打印机、喷墨打印机和激光型号。`gsfonts` 软件包包含一组用于 `ghostscript` 的标准字体。Ghostscript 宽网首页位于 `http://www.ghostscript.com/` 源自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

不同 Ghostscript 版本的常用文件有两种不同许可证发布的 Ghostscript postscript 解释器：

- GNU Ghostscript: 根据 GPL发布的自由软件。包含在 Debian 的 "`gs`" 软件包中。
- AFPL Ghostscript: 这种版本更常见且更新，在非自由许可下发布。如果你想使用该软件包，请确保你已同意相关条款。Ghostscript 的 AFPL 变体不是 Debian 官方发行版的一部分，但作为对用户的服务，我们在非免费（non-free）部分提供了该软件包。该软件包包含了用于管理字体安装和软件脚本的常用文件。源自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

### gs-pdfenc

提供使用 Ghostscript 查看加密 PDF 的支持。此软件包提供了使用 `gs` 和 `gs-aladdin` 插件查看加密 PDF 文件所需的修改。当你给 PDF 文档设置所有者密码时，Adobe Acrobat 会对其进行加密，导致你无法从文件中移除密码。遗憾的是，由于加密无法添加到从美国分发源码的 Ghostscript 等程序中，你必须遵守美国出口条例安装此软件包才能查看加密的 PDF 文件。源自 Debian 3.0r0
