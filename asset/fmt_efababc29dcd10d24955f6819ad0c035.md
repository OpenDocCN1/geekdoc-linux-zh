## 无线通信

- 原则：小型、端口、自定义、更糟
- 核心概念：廉价、高效、便携的通信将成为下一个“杀手级应用”。

与固定电话相比，手机的效率并不高。它们的扬声器很糟糕。当你正在高速公路上飞驰驰时，它们会在重要的对话中掉线。与家里的带线式无线电话相比，它们的电池似乎需要频繁充电。但我们都知道自己为什么喜欢它们：便携性。

手机也许是便携性优于效率这一价值的最好例子。手机的保真度并非最高，但人们发现他们越来越多地使用手机而不是座机。那些编写微波炉有问题的人知道在手机上按哪些按钮可以让它们屈服。这并不是因为手机比微波炉更容易理解。它们并没有。只是由于交流的需求是如此巨大，显然已经超过了进东西的需求。

手机还将 Unix 哲学中“小即是美”的格调推向了。我的第一部手机是个笨家伙。它重得像块砖一样。在主要覆盖区域外信号平平。话费是一笔巨款。但我付出的每一分钱都值。如今，纤薄的超智能手机的价格比在城里玩一晚上还便宜，而且许多手机是无线运营商的授权代理免费提供的。

## Web 服务

手机和其他无线通信设备更具趣味的是融合问题。仅仅用手机互相通话是不够的。我们希望能够用手机完成家电脑能做的一切事情。这意味着发送和接收实时视频、玩游戏、将语音信息转换为电子邮件、即时翻译外语、阅读邮件、访问互联网、观看流媒体视频等。

不，手机无法像桌面电脑那样很好地完成这些事情。但它们将足够好用。又是那种“越糟越好”的天才。廉价且有效的东西比大而贵的东西更有用。人们不会意意手机上的小屏幕没有笔记本电脑上的屏幕大。他们想要足够好用且便携的东西。

你怀疑手机能胜任这项任务吗？如果你只是看看……请原谅，我有一个电话打进来。

每个人意识到戈登·贝尔（Gordon Bell）的说法“网络变成了系统”是绝对正确的，只是时间问题。4. 太阳系统公司（Sun Microsystems）后来通过“网络即计算机”营销活动推广了这一理念。尽管在实现这一愿景的道路上有很多兴趣（例如 CORBA、DCOM），但到目前为止，尚未展现将网络转化为像 Web 服务目前所实现的整体计算机（gestalt computer）的潜力。5.

Web 服务使用一种由一组小型、基于网络的组件或工具组成的模型。简单来说，这项技术是作为传输协议的 HTTP 以及在该传输之上的简单对象访问协议（SOAP）作为消息语言的总和。

正如你可能怀疑的那样，它的架构与 Unix 哲学有许多共同点。在理想的实现中，每个 Web 服务：

- 很好地做好一件事
- 作为客户端与服务器之间双向消息的过滤器
- 使用 XML 形式的扁平文本作为消息
- 使用可重用组件的可便携语言编写

Web 服务以大浪潮席兴起这奇怪吗？拥有 DotGNU 项目的开源社区和拥有 .NET 倡议的微软都在围绕这项技术实现框架。Web 服务对业务应用的潜力是巨大的，它可能是计算世界下一次地构造运动的开始。

尽管 Web 服务技术正在万维网联盟（W3C）作为标准缓慢推进，但实施该标准的对立派正准备好一场长而血腥的战斗。如果 Linux 和 Windows 之间的竞争是计算机末日战（Aggageddon），那么 Web 服务领域主权的斗争将是游击战。双方都理解战斗规则，并表现出可能愿意颠覆这些规则的迹象。

## 人工智能

- 原则：协议、层次
- 核心概念：如果你足够早地构建原型，你就可以从机器告诉你的中学习。

在读了本章的其他讨论后，你可能会怀疑我们为什么要拿起人工智能（AI）这个主题。毕竟，在那些终身教授和极客对此如此痴迷之前，AI 不是很枯燥的吗？关于 AI 的好科幻小说不是都写完了吗？AI 长期以来一直告诉我们计算机将比我们更聪明。这大部分内容一直被嘲笑为技术梦想。总有一天还是未来的某个时候。AI 社区除了 IBM 的 Deep Blue 和其他象棋类奇迹外，从未交付过任何价值。

首先，大部分 AI 理论集中在寻找遍历巨大决策树的方法上。这就是象棋程序背后的思想。象棋游戏的决策树是一个有限的、巨大的树。旧的象棋计算机只能搜索，Deep Blue 使用了一台 IBM SP32-CPU RS6000 并行机器，配备了 256 个象棋加速芯片，每秒检查 1 亿个位置，并能执行深达 30 步的选择性搜索。

还记得下一台机器的主意吗？对，有一天我们将在手腕上拥有 Deep Blue 的力量。我们等不及待了。那时卡斯帕罗夫就能随身携带 Deep Blue，并真正弄清楚它为什么击败他。

其次，开发者发现在早期原型 AI 程序时，他们偶尔会发现程序本身教给了他们一些新知识。开发 AI 软件变成了一个迭代过程，涉及的不再是终端用户，而是计算机本身。显然，随着机器越来越快、程序越来越智能，人们越频繁地进行这样做，这些程序就会变得越聪明。

当然，AI 的这种增长并非没有危险，科幻小说作家们长期以来一直在提醒我们这一点。要看到这项技术如何用于良良的生生例子（至少从商业角度来看），请查看 Amazon.com 网站。注意 Amazon 尝试用各种方式说服你购买与你买过的任何书相关的书、你看过的任何书、你想要拥有的书、你母亲购买的任何书、你前女友烧掉的任何书、你配偶在你公包里发现的任何书、你狗咬过的任何书、你在浴室里读过的任何书、你弟弟借了从未还的任何书等等。

这种 AI——即通过匹配两个或多个数据库之间的键来观察人类行为的模式——是一个相对较新的趋势。由于其巨大的商业潜力，随着公司寻求利润最大化，它可能会在未来几年内作为热门技术占据之地。因此，像 Amazon 这样的公司正在探索数据库之间显而易见的联系。然而，当 AI 启发式开始指出不那么明显的联系时，情况会变得更有趣。Amazon 为你提供一本关于 Linux 音乐作曲的酷书时，这很有趣；但当超市算出了你最喜欢的咖啡涨价的确切日期，这可能就不好玩了。

在本章中，我们查看了 Unix 哲学思想如何渗透到其他技术的几个例子。讨论绝不是全面的，如果我漏掉了你喜欢的技术，我深表歉意。今天有这么多迷人的技术，要讨论它们可能还需要再写一书。即便如此，那部巨著也将是不完整的，因为每天都有新技术的涌现。

我希望你现在能够在任何事务中识别出那些本质上类 Unix 的思想。当你看到模式显现时，你将能够引导它们迈向开放和社区的方向，而不是孤立和排他。分享一个想法等同于脑中两个。当人们分享自己的想法并对他人的想法保持开放时，所有人都将受益。
