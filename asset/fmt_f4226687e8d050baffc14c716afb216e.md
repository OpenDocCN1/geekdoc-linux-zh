
对于 `$V(G)$` 的非空子集 `S`，**诱导的**子图 `G[S]` 的顶点集为 `S`，且 `G[S]` 中顶点 `u` 和 `v` 相邻当且仅当它们在 `G` 中相邻。如果图 `G` 的子图 `H` 存在 `V(G)` 的非空子集 `S` 使得 `H = G[S]`，则称 `H` 为**诱导子图**。因此 `G[V(G)] = G`。对于图 `G` 的边的非空集合 `X`，由 `X` **诱导的**子图 `G[X]` 以 `X` 为边集，且如果顶点 `v` 与 `X` 中至少一条边相关联，则 `v` 属于 `G[X]`。如果存在 `E(G)` 的非空子集 `X` 使得 `H = G[X]`，则 `G` 的子图 `H` 是**边诱导的**。因此，`G[E(G)] = G` 当且仅当 `G` 没有孤立顶点。

再次考虑图 1.11 中显示的图。由于 `xy ∈ E(G)` 但 `xy ∉ E(G_4)`，子图 `G_4` 不是 `G` 的诱导子图。另一方面，子图 `G_2` 和 `G_5` 都是 `G` 的诱导子图。确实，对于 `S_1 = {v, x, y, z}` 和 `S_2 = {u, v, y, z}`，有 `G_2 = G[S_1]` 且 `G_5 = G[S_2]`。`G` 的子图 `G_4` 是边诱导的；事实上，`G_4 = G[X]`，其中 `X = {uw, wx, wy, xz, yz}`。

对于非空图 `G = (V, E)` 中的顶点 `v` 和边 `e`，通过从 `G` 中删除 `v` 得到的子图 `G - v` 是 `G` 的诱导子图 `G[V - {v}]`；通过从 `G` 中删除 `e` 得到的子图 `G - e` 是 `G` 的生成子图，其边集为 `E - {e}`。更一般地，对于 `V` 的真子集 `U`，图 `G - U` 是 `G` 的诱导子图 `G[V - U]`。对于 `E` 的子集 `X`，图 `G - X` 是 `G` 的生成子图，其边集为 `E - X`。如果 `u` 和 `v` 是 `G` 中两个不相邻的不同顶点，则 `G + uv` 是指满足 `V(G + uv) = V(G)` 且 `E(G + uv) = E(G) ∪ {uv}` 的图。因此，`G` 是 `G + uv` 的生成子图。对于图 1.12 中的图 `G`，顶点集 `U = {t, x}` 和边集 `X = {tw, wx, vx}`，该图中还显示了 `G` 的子图 `G - u`，`G - ux`，`G - U` 和 `G - X`，以及图 `G + uv`。

如果图 `G` 的任意两条边 `e_1` 和 `e_2` 都具有性质 `G - e_1 ≅ G - e_2`，那么我们写 `G - e` 表示从 `G` 中删除任意一条边。因此，对于 `n ≥ 2`，`K_n - e` 表示通过从 `K_n` 中删除任意一条边得到的图。如果对于 `G` 中任意两对不相邻顶点 `{u, v}` 和 `{x, y}`，都有 `G + uv ≅ G + xy`，那么我们写 `G + e` 表示向 `G` 中添加任意一条边。特别地，`C_4 + e = K_4 - e`。

## 1.4 正则图

存在某些类的图出现频率很高，值得特别提及，在某些情况下甚至有专门的记号。我们现在介绍其中一些最著名的类。

如果图 `G` 的所有顶点具有相同的度，则称该图为**正则图**；如果这个度为 `r`，则称其为**度为 `r` 的正则图**。这类图也被称为 **`r`-正则图**。因此，阶数为 `n` 的完全图是度为 `n - 1` 的正则图，每个圈都是 2-正则的。图 1.13 显示了所有（非同构的）阶数为 4 和 5 的正则图，包括圈 `C_4` 和 `C_5` 以及完全图 `K_4` 和 `K_5`。由于没有图拥有奇数个奇度顶点，因此不存在阶数为 5 的 1-正则图或 3-正则图。确实，对于存在阶数为 `n` 的 `r`-正则图的整数对 `r, n` 是可预测的。

> **定理 1.7** 对于整数 `r` 和 `n`，存在阶数为 `n` 的 `r`-正则图当且仅当 `0 ≤ r ≤ n - 1` 且 `r` 和 `n` 不同时为奇数。

**证明。** 这些条件是必要的，这是推论 1.5 以及图 1.5 中阶数为 `n` 的每个顶点 `v` 都满足 `0 ≤ r ≤ n - 1` 这一事实的直接推论。对于逆命题，假设 `r` 和 `n` 是满足 `0 ≤ r ≤ n - 1` 且 `r` 和 `n` 不同时为奇数的整数。首先假设 `r` 是偶数。如果 `r = 0`，则由 `n` 个孤立顶点组成的阶数为 `n` 的图是 `r`-正则的。因此我们可以假设 `r = 2k`，其中 `k ≥ 1` 且 `n ≥ 2k + 1` 是某个整数。设 `G` 为具有顶点集 `V(G) = {v_1, v_2, …, v_n}` 的图，使得 `v_i` ` (1 ≤ i ≤ n)` 与...

到 `v_{i+1}, v_{i+2}, …, v_{i+k}`（下标按模 `n` 计算）。由此得到的图 `G` 是一个 `n` 阶的 `r`-正则图。如果 `r` 是奇数，则 `n = 2ℓ` 为偶数。因此，对于某个整数 `k`（满足 `0 ≤ k ≤ ℓ - 1`），`r = 2k + 1`。对于此情况下的图 `G`，顶点 `v_i` 与上述 `2k` 个顶点相邻，同时也与 `v_{i+ℓ}` 相邻。同样，`G` 是一个 `n` 阶的 `r`-正则图。

## 1.5 二分图

我们经常遇到的另一类图是二分图。如果图 `G` 的顶点集 `V(G)` 可以被划分为两个集合 `U` 和 `W`（称为**部集**），使得 `G` 的每条*边*都连接 `U` 中的一个*顶点*和 `W` 中的一个*顶点*，那么图 `G` 是**二分图**。图 1.16(a) 中的图 `G` 是二分图，其*部集*为 {`v_1`，`v_3`，`v_7`} 和 {`v_2`，`v_4`，`v_6`}。该图在图 1.16(b) 中重新绘制，以便更清楚地看出它是二分图。如果 `G` 是一个 `r`-正则的*二分*图，`r ≥ 1`，其*部集*为 `U` 和 `W`，那么 `|U| = |W|`。这是因为 `G` 的边数（size）为 `r|U| = r|W|`。对于图 `G` 中两个非空的*顶点*集合 `X` 和 `Y`，集合 `[X, Y] = {xy : x ∈ X, y ∈ Y}` 由那些连接 `X` 中*顶点*和 `Y` 中*顶点*的*边*组成。因此，如果 `G` 是一个具有*部集* `U` 和 `W` 的*二分*图，那么 `[U, W] = E(G)`。

![](img/598a6ae3fd44120830ada34717906f29_26_0.png)

图 1.16：一个*二分*图

如果 `V(G)` 可以被划分为两个集合 `U` 和 `W`（再次称为*部集*），使得 `uw` 是 `G` 的*边*当且仅当 `u ∈ U` 且 `w ∈ W`，那么图 `G` 是一个**完全二分图**。如果 `|U| = s` 且 `|W| = t`，那么这个完全*二分*图的阶为 `s + t`，边数为 `st`，记为 `K_{s,t}`（或 `K_{t,s}`）。完全*二分*图 `K_{1,1}` 被称为**星形图**。完全*二分*图 `K_{1,3}`、`K_{2,2}`、`K_{2,3}` 和 `K_{3,3}` 如图 1.17 所示。注意到 `K_{2,2} = C_4`。*星形*图 `K_{1,3}` 有时被称为**爪形图**（claw）。

![](img/598a6ae3fd44120830ada34717906f29_26_1.png)

图 1.17：完全*二分*图

由于完全*二分*图 `K_{[n/2], [n/2]}` 的边数为 `[n/2] · [n/2] = [n²/4]`，因此存在阶为 `n`、边数为 `[n²/4]` 的*二分*图。然而，阶为 `n` 的任何*二分*图的边数都不会更大。

**定理 1.8** *任何阶为 n 的二分图的边数至多为*[n²/4]。
