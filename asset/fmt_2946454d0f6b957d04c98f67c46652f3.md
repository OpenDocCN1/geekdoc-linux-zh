
# 项目 14D：通过 Automatrix 安装 Picasa

如果在介绍 Linux 图形化能力时不提到 Linux 应用程序领域最新的成员之一——Picasa，将是不恰妥的。来自 Windows 世界的你们无疑熟悉这款由 Google 出出的、非常流行的图片查看、整理和编辑应用程序，而且你们一定会发现它现在已经有了 Linux 版本。Picasa 并不是一个开源应用程序，这可能会让一些 Linux 原生主义者望而却步，但它是免费、功能丰富且外观良好的（图 14-16）。它还能让你轻松访问各种在线相博客、照片网站以及产品供应商，如 PhotoStamps、Shutterfly、Kodak 和 Evergreen。

## 14-1: 下载并安装 Picasa 软件包

获取 Picasa 最简单的方法是通过 Automatrix，这是你在第 9 章中安装并学会使用的工具。打开 Automatrix（应用程序 ► 系统工具 ► Automatrix），一旦它运行，点击左侧窗格中的 Office。在 Automatrix 窗口的右侧窗格中，勾选 Google Picasa 旁的方框，然后点击窗口顶部的 Start 按钮。下载和安装过程就会开始。

会弹出一个小窗口，提示你需要权限才能继续。点击 Grant（授权），系统会提示输入密码。输入密码并点击 OK 开始安装。Automatrix 会显示下载和安装的进度，并在完成后通知你。

![](img/ba6b82a7869bba748202d57c97336dca_259_0.png)

## 14D-2: 运行和设置 Picasa

一旦安装了 Picasa，你就可以进入 **Applications** 菜单并选择 **Graphics > Picasa** 来运行。第一次执行此操作时，你会看到一个 Picasa 许可协议窗口。点击 **I Agree**（我同意）按照要求操作。

随后，另一个窗口会询问你（同样仅限第一次），你是想让它扫描整个计算机的图像（默认选项），还是只扫描桌面。不要重复操作，不要接受默认设置（Scan my computer and all network directories for pictures）。

之所以这样做是因为，尽管你可能只想扫描计算机中的单张图像，但你的系统已经堆满了这些图像。如果你接受了默认设置，Picasa 将被各种你并不真正想要的东西填充。毕竟，它本应该是用于**你的**照片的整理工具。考虑到这一点，选择 **Only scan the Desktop**（仅扫描桌面），然后点击 **Continue**（继续）按钮。Picasa 将扫描你桌面的图像并将其找到的任何图像添加到其库中。

使用 Picasa 应该非常简单直接，但如果你想了解更多信息，可以查看 http://picasa.google.com/linux。在该页面上，你将找到基础概述、指向更多特定 Linux 信息的链接（包括 FAQ 和论坛页面）以及 Picasa 导览。

# 其他一些值得考虑的图形应用

除了本章涵盖的图形应用程序外，还有更多可用程序。其中一个是随系统预装的，而其他的可以通过 Synaptic 获取（或者为了方便浏览，通过 Add Applications 工具）。虽然你可以尝试各种可用的程序，但我将指出其他几个值得注意的程序。即使没有别的，这些程序也能让你了解到那里等待着你的丰富资源。

除了 gThumb 图像查看器外，你的系统还提供了另一个用于图像查看和管理需求的应用程序 F-Spot Manager（图 14-17）。

## Blender

也许今天可用最令人印象深刻的开源应用程序之一是 Blender。Blender（图 14-18）是一个专业的 3D 建模、动画和渲染程序。它相当复杂，但这正是它强大且受欢迎的源泉（它几乎几乎每个操作系统都有版本）。如果你在花时间（以及磁盘空间）安装它之前想了解一下 Blender，请前往 www.blender3d.org。在 Synaptic 中搜索 blender 找到它；程序安装后，你可以通过 Applications > Graphics > Blender 3D modeller 运行它。

# 音频格式

在我们继续之前，有必要讨论一直以来使用的各种格式。在很长一段时间里，标准一直是 WAV、AU（来自 Sun）和 AIFF（来自 Apple）。所有这些都是未压缩格式，这意味着它们非常大。具体来说：

- WAV: Windows 标准。

- AU: Sun/Unix 标准。

- AIFF: Apple 标准。

由于这些格式未经过压缩，它们占据了大量的空间。这就是为什么许多人使用压缩格式。

## 音频压缩

在这些压缩格式中，最为人知且被接受的是 MP3。MP3 格式的文件切除了人耳朵听不到的部分，从而使文件只有原始大小十分分之一，且没有可见的质量损失。

另一种压缩格式是 Ogg Vorbis。Ogg Vorbis 是开源社区的产物，与一直处于专利权阴影下的 MP3 不同，它是免费且没有许可忧虑的。由于这一点，加上它在质量上与 MP3 平等（许多人认为更好），Ogg Vorbis 成为了 Linux 社区的宠儿。

另一个选项是 FLAC。无损音频压缩（FLAC）是一种编码格式，与 MP3 或 Ogg Vorbis 不同，它在编码过程中不会从文件中删除任何数据。这种方法的缺点是 FLAC 只能节省 30% 到 50% 的空间，远少于 MP3 实现的 80%。当然，优点是 FLAC 在质量上应该等同于 CD。考虑到音频质量的保留，如果你对 Ogg Vorbis 或 MP3 文件提供的质量不满意，FLAC 是一个理想的选择。如果你可能需要创建 Ogg Vorbis 和 MP3 文件……或者你只是不知道想用哪一个，它也是一个很好的选择。在这种情况下，你可以直接抓取文件并编码为 FLAC 格式。当你知道想要或需要什么时，再进行转换。

撇开这些 Ogg Vorbis 和 FLAC 不谈，很多人喜欢或需要处理 MP3 文件。例如，你可能已经从音乐收藏中提取了大量的 MP3，或者你可能喜欢收听许多以某种格式广播的网络电台，

MP3 格式。遗憾的是，由于许可考虑，Ubuntu 并不包含 MP3 播放和编码支持。如果你计划在未来的数字刻录和编码工作中使用 Ogg Vorbis，那么安装 MP3 支持是一个好主意，以涵盖你所有的音频需求。这也是一个非常简单的过程。

安装任何格式播放和编码支持的最简单方法（也适用于本章及整本书将讨论的大多数应用）是通过 Automix（应用程序 ➡ 系统工具 ➡ Automix）。打开打开 Automix 后，点击窗口左侧窗格中的 Codecs and Plugins（解码器和插件），然后勾选右侧窗格中的 DVD-DVD Codecs 和 Multimedia Codecs（多媒体解码器）。完成后，点击窗口顶部的 Start（开始）按钮，下载和安装过程将开始。请注意，这是一个相当大的下载包，如果你的网络连接较慢，请耐心等待。

## 音频抓取器和编码器

你用于从 CD 中提取（rip）音频文件并将其编码为节省空间的 MP3 或 Ogg Vorbis 格式的应用程序通常被称为“抓取器”（ripper）。长期以来，最常用的非命令行抓取器是 Grip，它仍然有一群忠实粉丝。然而，最近也出现了一些更简单的抓取器，例如 XPX、Goobox 以及与 Ubuntu 自带的 Sound Juicer。
