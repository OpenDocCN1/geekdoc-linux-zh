### 通用的什么是 Shell（壳）？

Linux 使用硬件设备等系统资源与软件内核进行交互，以确保所有功能都能完美运行。Linux 内核是复杂的，并为几乎每个创建的驱动程序提供用例。用户与内核之间的所有通信都在称为 shell 的命令行环境中进行。

在 Linux 中，shell 就像是用户和操作系统之间的一座交叉桥。你输入的任何内容都会被发送到 Linux 内核。然而，请记住，Linux 内核只对它认为正确的 shell 命令做出响应。它不会执行任何可能关闭系统或完全抹除系统的恶意破坏性命令。如果你拥有 root 权限并在 shell 环境下执行命令，请务必小心，因为任何错误的命令都可能严重搞乱你的系统。

### Shell 的优势是什么？

你可能经常听过 shell，并应该困惑为什么它们在 Linux 系统中如此特殊。它们在系统管理员（Sysadmins）和黑客之间的流行，是因为它们不像占用大量资源的 GUI 应用程序和安装程序那样产生非常少的杂乱。你可能觉得在日常普通 PC 时这并不重要，因为维护服务器和数据库并不断监控它们不崩溃是一项微不足道的任务。

这正是 shell 以其极低的系统占用大显身手的地方。它用非常少的代码和时间执行复杂的任务。此外，应该记住 shell 可以同时运行在 Linux 和 UNIX 操作系统上。由于 macOS 是基于 UNIX 构建的，因此你可以在上面运行所有的 Linux shell 代码。对于 Windows，还有其他沙箱替代方案可以在 Windows 内部创建 shell 环境。

shell 的一些著名示例包括 Korn shell、C shell 和 Bourne-again shell (`Bash`)。在本章的下一节中，我们将通过几个示例讨论 bash shell 的基础。

### 如何编写一个简单的 Bash 脚本？

这里，提供了 `/bin/bash` 作为解释器位置。所以现在 Linux 知道上述文本文件需要作为 Bourne-again shell 运行。

### 如何运行 Bash 脚本

Linux 尊重用户隐私，并对运行可能损害系统的程序（如 bash 脚本）有严格限制。即使你是文件的所有者，如果没有某些调整，你被允许运行 bash 程序，这些调整将确认你已经意识到如果搞乱任何系统文件可能发生的风险。但这正是我们这些黑客要做的，不是吗？承担风险，搞乱系统并修复它们。

## 内置 Bash 命令

在之前的章节中，我们通过一些示例程序和详细的解释讨论了 bash 脚本语言的构建模块。在这一奖励章节中，我们将讨论 Linux 中 Bash 为我们提供的一些内置命令。你可能会感到惊讶，因为其中许多命令对于刚开始学习 Linux 奇之处的初学者来说也是为人知的。不要浪费时间，让我们现在开始探索吧。

### 什么是内置命令？

内置命令是在安装软件或 shell 接口时自带的命令。例如，当我们安装一个 Python 解释器时，可以在 shell 中运行 `py` 命令。换句话说，`py` 是因为安装了 Python 而自带的内置命令。

同样，bash 也带有这些命令，由于它们在与内核资源通信方面的效率很高，其中一些命令被 Linux 操作系统广泛使用。

一些著名的命令：

### I) echo

我们已经讨论过这个命令，并在我们的某些程序中也使用了它。Echo 命令就像编程语言中的 `print` 命令。它所做的只是在屏幕上显示输出。它可以通过 `$` 符号获取变量或函数实例。

这是一个示例：

```
Echo “This can display output on computer screen"
```

# 输出:

This can display output on computer screen

#### ii) cd

这是由 bash 开发的著名 Linux 命令之一。它的作用是更改用户在终端中的目录。在执行操作时，你可能需要更改目录，因为某些程序只会在当前目录中运行。

这是一个示例：

```
Cd /bin/home
```

在 shell 接口中执行上述命令后，你将进入该特定目录。你现在可以使用 `ls` 来检查当前目录下的所有文件。

#### iii) pwd

请记住你也可以使用 `pwd` 命令查找你所在当前目录的信息。

这是一个命令：

```

```

这将提供关于你所处目录的一系列信息，以及文件数量和目录位置。

#### iv) 进程管理命令

我们都知道在 Linux 中一切都作为进程运行。有后台进程和前台进程，它们可以提高可用系统配置的准确性。Bash 有一些内置命令可以帮助用户更好地组织可用进程或刚创建的进程。

#### A) bg

这个内置命令让你尝试启动的软件或进程在后台运行，而不是在前台并消耗系统资源。

这是一个示例：

```
root@server : bg vmware
// This starts the software in background
```

作为一名黑客，你需要意识到哪些软件正在后台运行，因为防病毒软件是以后台进程运行的。此外，当你向目标系统植入漏洞时，你需要确保它不会被系统管理员发现。

#### B) exec

这是一个内置的 bash 命令，将软件作为新进程启动。有时即使在软件或工具已经打开的情况下，你也可以使用此命令打开该软件的新实例。

这是一个命令：

```
root@server : exec vmware config
// This starts the config file of Vmware software as a new process
```

你可以通过以下命令确认是否创建了新进程：

```
root@server : pid
```

使用 `grep` 命令在此处检查 `vmware`，查看是否有两个进程同时运行。

#### C) wait

通常情况下，进程会自动启动，并在系统资源允许时结束。有时进程甚至会卡住，并在它们需要之前就结束。有时，你可以使用 `wait` 命令强制让软件等待进程完成。

这是一个示例：

```
root@server : wait vmware
```

这个内置命令用于更改已存在的默认权限。我们通常可以使用 `chmod` 来赋予可执行权限，但 `umask` 要复杂得多，可以在需要时执行复杂的更改。

这是一个命令：

```
root@server : umask 777 bash.sh
// This makes the files as executable even though by default it has just read and write permissions.
```
