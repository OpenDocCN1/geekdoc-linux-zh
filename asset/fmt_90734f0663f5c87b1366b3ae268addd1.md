### snace

一个将 ASN.1 C 或 C++ 或 IDL 的编译器 `snack` 意为“示例 ASN.1 到 C 编译器”，ASN.1 代表抽象语法表示法一 (Abstract Syntax Notation One, ITU-T X.208/ISO 8824)。`snack` 支持 ASN 1998 的子集。如果你需要 ASN 1992 或更高版本的功能，`snack` 并不适合你。给定一个 ASN.1 源文件，它会生成：

1. 用于 BER 编码和释放的程序。
2. 用于 BER 编码、解码和打印的 C++ 程序。
3. 一个可以与 C 驱动程序配合用于 BER 编码、解码和打印的类型表。如果你想构建 `snack` 应用，你需要安装 `libacc-dev` 包。你的你的应用程序将依赖于 `snack` 库，可以在 `libsnace0` 包中找到它们。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
