
映射中未找到键。`LookupError` 的子类。

### `KeyboardInterrupt`

当用户按下中断键（通常是 `Ctrl+C`）时抛出。

### `MemoryError`

可恢复的内存不足错误。

### `NameError`

在本地或全局命名空间中未找到名称。

### `NotImplementedError`

未实现的功能。可以由要求派生类实现方法的基类抛出。`RuntimeError` 的子类。

### `OSError`

操作系统错误主要由 `os` 模块中的函数抛出。值与 `OSError` 相同。`Environment` 的子类。

### `OverflowError`

整数值太大而无法表示的结果。此异常通常在将大整数值传递给内部实现依赖于固定精度整数的对象时出现。例如，当在 `range` 或 `xrange` 对象中指定的起始或结束值超过 32 位时，可能会出现此错误。`ArithmeticError` 的子类。

### `ReferenceError`

在底层对象被销毁后访问弱引用的结果。`weakref` 模块。

### `RuntimeError`

未被其他任何类别涵盖的通用错误。

## 内置警告

Python 拥有一个 `warnings` 模块，通常用于通知程序员某些已已用。通过包含如下代码来发布警告：

```python
import warnings
warnings.warn("The MONDO flag is no longer supported", DeprecationWarning)
```

虽然警告是由库模块发出的，但各种警告名称是内置的。警告与异常有些相似。存在一个内置警告的层次结构，它们都继承自 `Exception`。

### `Warning`

所有警告的基类。它是 `Exception` 的子类。

### `UserWarning`

通用的用户定义警告。它是 `Warning` 的子类。

### `DeprecationWarning`

针对已弃用特性的警告。它是它是 `Warning` 的子类。

### `SyntaxWarning`

针对已弃用 Python 语法的警告。它是 `Warning` 的子类。

### `RuntimeWarning`

针对潜在运行时问题的警告。它是 `Warning` 的子类。

### `FutureWarning`

警告特性行为未来将发生变化。它是 `Warning` 的子类。

警告与异常的不同之处在于，使用 `warn()` 函数发布警告可能也可能不会导致程序停止。例如，警告可能只是向输出打印某些内容，也可能抛出异常。实际行为可以通过 `warnings` 模块或解释器的 `-W` 选项进行配置。如果你正在使用生成警告的他人的代码，但你想通过 `try` 和 `except` 捕获已转换为异常的警告。例如：

```python
import md5
except DeprecationWarning:
    pass
```

应该强调的是，这种捕获代码是罕见的。虽然它可以捕获转换为异常的警告，但它不会抑制警告消息（你必须使用 `warnings` 模块来控制）。此外，忽略警告是编写在新的 Python 版本发布时无法正常工作代码的好方法。

## future_buildins

`future_buildins` 模块仅在 Python 2 中可用，提供了在 Python 3 中行为发生变化的内置函数的实现。以下是这些函数：

```python
ascii(object)
```

产生与 `repr()` 相同的输出。请参考本章“内置函数”部分的描述。

```python
filter(function, iterable)
```

创建一个迭代器而不是列表。与 `itertools.ifilter()` 相同。

```python
hex(object)
```

创建一个十六进制字符串，但使用 `__index__()` 特殊方法获取整数值，而不是调用 `__hex__()`...

```python
map(function, iterable, ...)
```

创建一个迭代器而不是列表。与 `itertools.imap()` 相同。

```python
oct(object)
```

创建一个八进制字符串，但使用 `__index__()` 特殊方法获取整数值，而不是调用 `__oct__()`..

```python
zip(iterable, iterable, ...)
```

创建一个迭代器而不是列表。与 `itertools.izip()` 相同。

注意，该模块列出的函数并不是内置模块更改的完整列表。例如，Python 3 还将 `raw_input()` 重命名为 `input()`，将 `xrange()` 重命名为 `range()`。

## Python 运行时服务

本章介绍了与 Python 解释器运行时相关的模块。主题包括垃圾收集、对象的基本管理（拷贝、序列化等）、弱引用和解释器环境。

### atexit

`atexit` 模块用于注册在 Python 解释器退出时执行的函数。提供了一个单一函数 `func(*args, [kwargs])`：

```python
register(func, {args, [kwargs]})
```

将 `func` 添加到解释器退出时执行的函数列表中。`args` 是传递给函数的参数元组，`kwargs` 是关键字参数字典。该函数以 `func(*args, **kwargs)` 被调用。在退出时，函数按照注册的反序顺序调用（最近添加的函数首先调用）。

### copy

`copy` 模块提供了对复合对象进行浅拷贝和深拷贝的函数，包括列表、字典和实例。

```python
copy(x)
```

通过新对象并复制 x 的成员制作 x 的浅拷贝。

```python
deepcopy(x, [visit])
```

通过创建新对象并递归复制 x 的所有成员制作 x 的深拷贝。`visit` 是用于跟踪已遇到对象的可选字典。

### gc

`gc` 模块提供了控制垃圾收集器的接口，该收集器用于收集列表、元组、字典和实例。当创建各种容器对象时，它们被放置在解释器内部的列表中。当容器对象被释放时，它们会从列表中移除。如果分配次数超过用户定义的阈值值，就会调用收集器。垃圾收集器通过扫描此列表并识别不再使用但由于循环依赖而被释放的对象。此外，垃圾收集器使用三级方案，在初始垃圾收集步骤中生存的对象放在检查频率较低的对象列表中。

```python
collect([generation])
```

运行完全垃圾收集。此函数检查所有代并返回不可对象的数量。`generation` 是 0 -2 范围内的可选整数，指定要收集的代。

```python
disable()
```

禁用垃圾收集。

```python
enable()
```

启用垃圾收集。

```python
garbage
```

一个包含只读列表的，，由于引用循环且定义了 `__del__()` 方法而无法被垃圾收集。此类对象无法被垃圾收集，因为为了打破引用循环，解释器必须任意销毁
