所有这些文件都通过用于用户和组管理的命令行工具进行更新，我们将在本节稍后讨论它们。它们也可以通过图形化应用程序进行管理，这些程序提供了更简单、更直观的管理界面。

**警告** 尽管这些文件是纯文本，但请不要直接编辑它们。请务始终使用您发行版提供的工具来实现此目的。

### /etc/passwd 文件

`/etc/passwd` 是一个全局可读的文件，包含一个用户列表，每个用户占一行：

```
frank:x:1001:1001::home/frank:/bin/bash
```

每行由七个由冒号分隔的字段组成：

- **用户名 (Username)**：用户登录系统时使用的名称。
- **密码 (Password)**：加密的密码（如果使用 shadow 密码则显示为 x）。
- **用户 ID (UID)**：系统中分配给用户的 ID 号。
- **组 ID (GID)**：用户在系统中的主组编号。
- **GECOS**：一个可选的注释，用于添加有关该用户的额外信息（如全名）。该字段可以包含多个用逗号分隔的条目。
- **家目录 (Home directory)**：用户家目录的绝对路径。
- **Shell**：当用户登录系统时自动启动的程序的绝对路径（通常是交互式 shell，如 `/bin/bash`）。

### /etc/group 文件

`/etc/group` 是一个全局可读的文件，包含一个组的列表，每个组占一行：

```
developer:x:1002:
```

每行由四个由冒号分隔的字段组成：

- **组名 (Group Name)**：组的名称。
- **组密码 (Group Password)**：组的加密密码（如果使用 shadow 密码则显示为 x）。
- **组 ID (GID)**：系统中分配给组的 ID 号。
- **成员列表 (Member list)**：属于该组的用户的逗号分隔列表，但以该组作为主组的用户除外。

### /etc/shadow 文件

`/etc/shadow` 是一个仅限 root 和具有 root 权限的用户可读的文件，包含用户的加密密码，每个用户占一行：

```
frank:$6$i9gjJM4dMueZ2Cd$7JJa8Cd2bbADDFH4dwftvJLOYCCBf./ybKb1IMy7WhWh4fXRcc2xQUVU2N1gb97yIYaiq.mJJammof2Jfr::1829:0:9999:7::
```

每行由九个由冒号分隔的字段组成：

- **用户名 (Username)**：用户登录系统时使用的名称。
- **加密密码 (Encrypted password)**：用户的加密密码（如果值为 !，则账户锁定）。
- **上次修改密码日期 (Date of last password change)**：上次修改密码的日期，自 1970/01/01 以来的天数。值 `!` 表示用户在下次访问时必须更改密码。
- **密码最小年龄 (Minimum password age)**：密码密码后必须经过的最小天数，用户才允许再次更改密码。
- **密码最大年龄 (Maximum password age)**：在需要更改密码之前必须经过的最大天数。
- **密码警告 (Password warning)**：在密码过期前的天数内，用户会收到必须更改密码的警告。
- **密码不活动期 (Password inactivity period)**：密码过期后用户应更新密码的天数。在此期限之后，如果用户未更改密码，账户将被禁用。
- **账户过期日期 (Account expiration date)**：用户账户过期的日期，自 1970/01/01 以来的天数。空字段意味着用户账户永不过期。
- **一个预留字段 (A reserved field)**：为以后使用保留的字段。

### 添加和删除用户

在 Linux 中，你使用 `useradd` 命令添加用户，使用 `userdel` 删除用户。如果你想创建一个名为 `frank` 的用户，可以使用 `useradd`：

```bash
useradd frank
```

创建用户后，你可以使用 `passwd` 设置密码：

```bash
passwd frank
```
更改密码：
```bash
passwd frank
```
密码已成功更新。当你想要创建一个名为 `frank` 的用户并创建其家目录时，你可以使用以下命令来查看新的用户信息：

```bash
cat /etc/passwd | grep frank
```

`useradd` 命令最重要的选项包括：

- `-c`：带有自定义注释的用户（如全名）。
- `-d`：带有自定义家目录的用户。
- `-e`：设置账户过期的特定日期。
- `-f`：设置密码过期后用户应更新的天数。
- `-g`：指定特定的 GID。
- `-G`：将用户添加到多个辅助组。
- `-m`：创建用户的家目录。
- `-M`：不创建家目录。
- `-s`：指定特定的登录 shell。
- `-u`：指定特定的 UID。

创建用户账户后，你可以使用 `id` 和 `groups` 命令查看其 UID、GID 以及其所属的组：

```bash
# id frank
uid=1000(frank) gid=1000(frank) groups=1000(frank)
# groups frank
frank : frank
```

记得检查并最终编辑 `/etc/login.defs` 文件，它定义了创建用户和组的配置参数。例如，你可以设置分配给新用户和组的 UID 和 GID 范围，指定系统是否为每个用户创建一个新组。

**提示**

如果你想删除一个用户账户，可以使用 `userdel` 命令。特别地，它会更新账户数据库，删除所有引用该用户的条目。`-r` 选项还会删除用户的家目录及其所有内容，以及该用户的邮件池。位于其他位置的文件必须手动查找并删除。

```bash
# userdel -r frank
```

### 骨架目录 (Skeleton Directory)

当你添加新用户账户时，即使是创建家目录，该目录也会从骨架目录（默认为 `/etc/skeleton`）填充内容。这种设计的理念很简单：系统管理员希望新用户使用相同的家目录文件和文件夹。因此，如果你想自定义在新用户家目录中自动创建的文件和文件夹，必须将这些新文件和文件夹添加到骨架目录。

> 注意，通常位于骨架目录中的配置文件是隐藏文件。因此，如果你想列出骨架目录中的所有文件和文件夹（它们将被复制到新用户的家目录），你必须使用 `ls -A` 命令。

## 添加和删除组

在组管理方面，你可以使用 `groupadd` 和 `groupdel` 命令添加或删除组。

如果你想创建一个名为 `developer` 的新组，可以在 root 用户权限下运行以下命令：

```
# groupadd -g 1090 developer
```

该命令的 `-g` 选项创建一个具有特定 GID 的组。

如果你想删除 `developer` 组，可以运行以下命令：

```
# groupdel developer
```
