`ln source destination`

为名为 "source" 的文件创建一个硬链接 "destination"。该链接看起来像是原始文件的副本，但实际上只保留了一份文件副本，只是有两个（或多个）目录目指向它。对文件的任何更改都会处处可见。当其中一个目录目被删除时，其他的将保持完好。硬链接的局限性是：文件必须在同一个文件系统中，无法对目录或特殊文件创建硬链接。

```
ln -s source destination
```

为名为 "source" 的文件创建一个符号（软）链接 "destination"。符号链接指定了查找“真实”文件的路径。与硬链接不同，源和目标不需要在同一个文件系统中。符号链接的缺点是：如果原始文件被删除，链接就会“损坏”——它指向了虚无之处；符号链接可能会创建循环引用（类似于电子表格或数据库中的循环引用，例如 "a" 指向 "b" 而 "b" 指向 "a"）。简而言之，符号链接是一个非常棒工具且被频繁使用（比硬链接多），但它们可能会增加额外的复杂性。
