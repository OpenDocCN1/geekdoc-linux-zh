
以下变量是内部变量。你可以从环境中导入它们，或随时使用 `set` 命令设置它们。你可以使用 `unset` 命令删除变量。

> 注意 — 你无法取消从环境中导入的内部变量。

`+allnet` 将最后一个部分（登录名）匹配的网络名称视为相同的。`message-list` 规范的行为类似。默认如此。另请参阅 `alternates` 命令和 `metoo` 变量。

`+alwaysignore` 在到处忽略头部，而不仅仅是在打印或类型期间。影响 `save`、`copy`、`top`、`pipe` 和 `write` 命令以及 `-m` 和 `-f` 转义。默认启用。

`+append` 在终止时，将消息追加到 `mbox` 的末尾而不是开头。虽然默认禁用，但 `append` 在系统启动文件中设置（你可以使用 `-n` 命令选项将其抑制）。

`+appenddeadletter` 追加到死信件文件而不是覆盖它。虽然默认禁用，但 `appenddeadletter` 经常在系统启动文件中设置。参见第 766 页的“发送邮件”。

`+askbcc` 在你输入主题后，如果没有在命令行中指定 `-b` 选项，则提示 Bcc 列表。已禁用。

`+askcc` 在你输入主题后，如果没有在命令行中指定 `-c` 选项，则提示 Cc 列表。默认禁用。

`+asksub` 如果没有在命令行中指定 `-s` 选项，则提示主题。默认启用。

# mailx, mail, Mail

`autoinc`

当新消息到达时，自动将其纳入当前会话中。此变量的效果与每次显示命令提示符时执行 `inc` 命令类似。默认禁用，`autoinc` 在 `mailx` 的默认系统启动文件中设置；在 `/usr/ucb/mail` 或 `/usr/ucb/Mail` 命令中未设置。

`autoprint`

在执行删除（`delete`）和撤销（`undo`）命令后自动打印消息。默认禁用。

`bang`

允许像 `vi(1)` 一样对 shell 转义命令行中的转义点（`!`）进行特殊处理。默认禁用。

`bsdcompat`

如果作为 `mailx` 或 `Mail` 被调用，则自动此设置。使用 `/etc/mail/Mail.rc` 作为系统启动文件。将默认分页器更改为 `more(1)`。

`cmd=shell-command`

设置管道（`pipe`）命令的默认命令。以下均无默认值：

`conv=conversion`

将 `uucp` 地址转换为指定的地址样式，可以是：

`internet`: 需要一个符合 RFC8222 电子邮件地址标准的邮件投递程序。

`optimize`: 移除 `uucp(IC)` 地址路径中的循环（通常由 `reply` 命令生成）。不执行重路由；`mail` 不感知 UUCP 路由或连接。

转换默认禁用。另请参见 `sendmail(1M)` 和 `-U` 命令行选项。

`crtnumber`

默认将超过 `number` 行的消息通过 `PAGER` 变量指定的值（`pg(1)` 或 `more(1)`）指定的命令进行处理。如果没有指定 `number`，则使用当前窗口大小。默认禁用。

`debug`

启用用于调试的详细诊断。不投递消息。默认禁用。

`dot`

将单独成行的点（`.`）视为文件结束。默认禁用，`dot` 在系统启动文件中设置（你可以通过 `-n` 命令行选项指定它）。

`escape=c`

用 `c` 替换转义字符 `~`。在发送下一条消息时生效。

`flipr`

反转 `followup/Followup` 和 `reply/Reply` 组合的效果。如果 `flipr` 和 `replyall` 均设置，则效果等于均未设置。

# mailx, mail, Mail

`folder=directory` 保存标准邮件文件的目录。对于以加号 (`+`) 开头的指定文件名，通过在文件名前加上目录名来获取真实文件名。如果目录不以斜杠 (`/`) 开头，则在其前面加上 `$HOME`。`folder` 变量没有默认值。另请参见 `outfile`。

`header` 在进入 `mailx` 时启用打印头信息。默认启用。

`hold` 保留信箱中已读的所有消息，而不是将它们放入标准信箱文件中。默认禁用。

`ignore` 在输入消息时忽略中断。这对于嘈杂的拨号线路非常管用。默认禁用。

`ignoreof` 在消息输入期间忽略文件结束符（EOF）。输入可能由单独成行的点（`.`）或 `~` 命令终止。另请参见上文。默认禁用。

`indentprefix=string` 使用字符串标记来自 `~m` 包含的消息的缩进行。默认是制表符（Tab）。

`iprompt=string` 在发送消息时，在输入的每行之前之前指定的指定的提示符字符串。

`keep` 当信箱为空时，将其截断为长度 0 而不是将其删除。默认禁用。

`keeps` 保留信箱中已保存到其他文件的消息，而不是删除它们。默认禁用。

`makeremote` 在回复消息的所有收件者时，如果地址不包含机器名，则假设它相对于消息的发送者。在处理支持 RFC822 的主机时，通常不需要此设置。

`metoo` 如果你的登录显示为收件者，则不要从列表中删除它。默认禁用。

`mustbang` 强制所有邮件地址采用 bang 格式。

`onehop` 禁用收件者地址的分配，在所有机器均可直接发送到所有其他机器（即单跳距离）的网络中，这可以提高效率。在回复原始发送给多个收件者的消息时，其他收件者地址通常被强制设置为相对于原始作者机器的。默认禁用。

`outfile` 在 `folder` 变量指定的目录查找用于记录发送消息的文件，除非路径是绝对路径。默认禁用。另请参见 `folder` 以及 `Save`、`Copy`、`followup` 和 `Followup` 命令。

# mailx, mail, Mail

`page`

配合管道命令使用，在通过管道发送的每条消息后插入分页符（formfeed）。默认禁用。

`pipeignore` 在输出到管道命令时省略被忽略的头信息。虽然默认禁用，但 `pipeignore` 经常在系统启动文件中设置。参见第 766 页的“Starting Mail”。

`postmark` 在你发送的消息的 `From` 行中包含你的真实。默认情况下，此值源自你 `passwd(4)` 文件中的注释字段。

`prompt=string`

将命令提示符设置为字符串。除非设置了 `bsdcommand` 变量，否则默认值为 `?`；否则默认值为 `&`。

`quiet` 在进入 `mailx` 时停止打印启动消息和版本。默认禁用。

`record-file` 将所有输出记录在文件中。默认禁用。另请参见 `outfolder`。注意 `mailx` 不锁定你的文件。因此，如果你使用记录文件并发送两条或多条消息，消息的行可能会在文件中交织。

`replyall` 反转 `reply` 和 `follow-up` 命令的效果。虽然默认设置，但 `replyall` 经常在系统启动文件中使用。参见 `flipp` 和第 766 页的“Starting Mail”。

`save` 在中断或投递错误时将消息保存到 deadletter（死信箱）中。请参见第 783 页“Environment Variables”中的 `DEAD` 以获取该文件的描述。默认启用。

`screen=number`

设置 `top` 命令中头信息的行数。`number` 必须是正数。根据波特率或窗口大小设置。如果波特小于 1200，默认值为 5；如果正好为 1200，默认值为 10；否则默认值为 20。

`sendmail=shell-command`

投递消息的替代命令。注意，除了收件人列表外，`mailx` 会将 `-i` 和 `-m` 选项传递给命令。由于这些选项不适用于其他命令，你可能需要使用一个脚本。默认值为 `/usr/bin/mailx`。

`sendwait` 等邮件器完成后返回。默认禁用。

`showname` 在邮件头中显示发送者的真实姓名（如果已知）而不是地址。默认禁用，但 `showname` 在 `/etc/mail/mailx.rc` 中设置。

`showto` 当显示头摘要且消息来自你时，打印收件者的姓名而不是作者姓名。

`sign=string` 使用 `-a` 命令时将变量插入消息文本中。没有默认值（另请参见第 777 页的“Tilde Escapes）。

`Sign=string` 使用 `-A` 命令时将变量插入消息文本中。没有默认值（另请参见第 777 页的“Tilde Escapes）。

`verbose` 带 `-v` 标志调用 `sendmail(1M)`。

`translate` 使用翻译程序翻译地址。程序接收地址作为参数。它在标准输出上产生以下数据，顺序如下：

* 发送者的标记（参见 `postmark` 变量）。

* 翻译后的地址，每行一个，对应程序的参数。每个翻译地址替换发送邮件中的相应地址。

* 只包含 `y` 或 `n` 的行。如果行包含 `y`，则要求确认是否发送消息。

为每条发送的消息调用翻译程序。如果程序以非零状态退出或未能产生足够的输出，则不发送消息。
