当 switch 定义后面有一个冒号 (`:`) 意味着 switch 后面必须紧跟一个参数。如果 switch 定义中没有冒号，则 switch 没有参数。例如，`getopts` 获取了 `-f` 和 `-t` 作为需要参数的命令行开关，而 `-a` 则没有关联的参数。

```bash
while getopts ":f:t:" ARGUMENT
do
  case $ARGUMENT in
    f) START_BASE="$OPTARG" ;;
    t) END_BASE="$OPTARG" ;;
    \?) usage; exit 1 ;;
  esac
done
```

`getopts` 定义包含两个部分。第一部分是 `getopts` 语句的 `while` 循环，第二部分是在发现有效或无效 switch 时执行操作的 `case` 语句。在 `while` 循环中我们定义了两个有效 switch `-f` 和 `-t`。当你定义这些时，不需要在 `case` 语句中添加连字符 (`-`)，但在 `getopts` 定义中是要求的。冒号开头的定义指定了当发现未定义的 switch 时——例如 `-?`——该无效 switch 与 `case` 语句中的问号 (`?`) 匹配。在我们的情况下，我们总是运行 `usage` 函数并以错误代码 1 退出。此外请注意我们对 `?` 进行了转义 (`\?`)。通过转义 `?` (`\?`)，我们可以将 `?` 用作普通字符，而不具有特殊含义或功能。

+([0-9])) : # 什么都不做 - 冒号是无操作。

## 主程序开始

在此时，我们已经确认了命令行输入的数据是有效的，所以让我们进行进制转换吧。因为我们在命令行上有了所有的命令行开关和开关参数，我们实际上需要找到在进制之间需要转换的“数字”。要找到我们的数字，请扫描所有的命令行参数，从参数 `$1` 开始一直扫描，直到找到数字，或者到达最后一个参数（由 shell 变量 `$#` 指向）。

扫描命令行参数并尝试寻找“数字”有点棘手。首先，“数字”可能处于系统支持的任何有效进制中，或者我们可能包含字母数字。但我们有一个优势：我们拥有 `$START_BASE` 和 `$END_BASE` 变量。我们仍然需要考虑命令行开关和开关参数之间可能也可能不存在空格。让我们思考一下。如果一个命令行参数在开关和开关参数之间放置了单个空格。另一方面，如果一个命令行参数同时是一个命令行开关及其开关参数，那么我们就知道用户没有在开关和开关参数之间放置空格。通过这种逻辑，我们可以使用一个简单的 `case` 语句来测试这些条件。当我们遇到不符合这种逻辑的命令行参数时，我们就找到了正在寻找的“数字”。

查看列表 23.6 中的代码段，我们将在最后进入更详细的内容。

```bash
# 从 1 计数到最大命令行参数数量
while ((COUNT < MAX_COUNT))
do
  ((COUNT = COUNT + 1))
  TOKEN=$1
  case $TOKEN in
    -f) shift;
      ((COUNT == COUNT + 1))
      :;
    -s($START_BASE)) shift
      :;
dn;
```

记住在 shell 的开头，我们定义了变量 `COUNT=0` 和 `MAX_COUNT=$#`。现在我们有机会使用它们了。如果我们想引入 `shift` 命令。这个 Korn shell 内置命令允许我们始终引用 `$1` 命令行参数以接受命令行上的任何参数。要进入下一个命令行参数，我们使用 `shift` 命令将下一个参数（即 `$2`）移动到 `$1` 的位置。如果我们想移动一个位置，可以执行多次 `shift` 命令，或者只需向 `shift` 命令添加一个整数，以指示我们想要移动到 `$1` 位置的多少个位置。以下两个命令都将位置参数移动两个到 `$1` 参数。

```bash
shift; shift
shift 2
```
