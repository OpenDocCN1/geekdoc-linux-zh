# 7.2 Star Office 套件

`Star Office` 是一个完整的办公套件：包含文字处理器、电子表格和演示文稿。个人使用免费，尝试：`http://www.stardivision.com/free/` (较大，60-80 MB)。

`Star Office` 看起来和操作非常像 `MS Office`（尽管很大且运行缓慢），在没有至少 32 MB 内存的情况下可能并不实用。它与 `MS Office` 有良好的兼容性（可以读写 `MS Word`、`Excel` 和 `PowerPoint` 格式）。旧版本的 `Star Office` 在你获得“密钥”后需要注册。注册密钥基于你给 `Star Office` 的邮箱，调调器。

## 7.8 Netscape 和 Lynx（网络浏览器）

你可能在安装 `RedHat` 期间安装了 4.xx 版本的 `Netscape`。要运行它，尝试（在 `X` 终端中）：

```
netscape
```

如果你没有安装 `Netscape`，你可能想将 `RedHat` CD 插入 CD-ROM，使用以下方式（例如作为 `root`）进行挂载：

```bash
mount -t auto /dev/cdrom /mnt/cdrom
```

然后，从命令行使用 `glint`（针对 `RH5.2`）或 `gnorpm`（针对 `RH6.0`）来浏览可用软件包，并可能从你的 `RedHat` CD 中安装 `netscape`。如果你倾向于从命令行进行安装，在挂载 CD-ROM 后：

```bash
cd /mnt/cdrom
cd RedHat/RPMS
rpm -i netsca
```

`Netscape` 是一个非常好的浏览器，与 `MS Windows` 版的 `Netscape` 具有相同的外观、感受和功能，你在浏览时不会遇到任何问题。缺点是，`Netscape` 有时会崩溃（它会从屏幕上消失，没有损坏，你必须重启它）。此外，在某些配置下，`Netscape` 不喜欢在没有连接互联网的情况下运行（取决于你的配置，对我来说，`Netscape` 可能需要几分钟时间才能发现问题所在）。任何 `Netscape 4.xx` 版本似乎都有类似的问题，升级到稍高的版本似乎没有帮助。放宽心，经过调优的 `Netscape` 运行得相当好，而且绝对可用（我一直使用它）。`Gecko`（`Netscape` 已经闻名的、革命性的后代）正在路上，所以你可以抬头挺胸了 :)

现在，如果你的 `Netscape` Bug 太多无法使用，你可能想清空邮件“垃圾”箱并定期压缩文件夹，同时禁用 `Java`（在菜单 `Edit-Preferences-Advanced` 中）。这似乎能让 `Netscape` 更加稳定。如果你在工作时 `Netscape` “冻结”，禁用邮件自动检查可以解决你的问题。

如果 `Netscape` 崩溃并在后的启动中抱怨存在锁文件，它可能在你的主目录下留了一个锁文件。只需退出任何正在运行的 `Netscape` 实例，并删除主目录下的 `.netscape` 目录中的 "lock" 文件：

```
rm ~/.netscape/lockfile
```

如果你的 ISP 连接非常慢，你可能更倾向于基于文本的浏览器：

```
lynx
```

这真的是件艺术品，而且没有任何问题。

另一个浏览器的选择是你的 `KDE` 帮助程序（点击 `K-bar` 上的“带灯箱的书”按钮）。这是一个真正的 `html` 浏览器，所以如果你连接了互联网（例如使用你的 `kpppp`），你可以使用这个简单的工具浏览任何内容。

要编写 `html` 页面，请使用 `Netscape`（所见即所得视图）和 `WebMaker`（代码视图）。
