
在没有指定值列表的情况下，`foreach` 结构将命令行参数作为其值列表。在调用 `shell` 文件时在命令行上指定的参数将成为 `foreach` 结构引用的值列表。`foreach` 结构中使用的变量会自动按顺序设置为每个参数值。循环第一次执行时，变量被设置为第一个参数的值。第二次执行时，被设置为第二个参数的值，以此类推。

### `function`

```
function name {commands}
```

`function` 用于定义函数。使用关键字 `function` 后跟想要给函数命名的名称，然后是花括号括起来的组成函数的命令。每当函数名指定为命令名时，这些命令就会执行。函数的退出状态是最后一个命令的退出状态。

或者，你可以使用一组闭合括号而不是 `function` 关键字来定义函数，使其风格类似于 C 语言程序。

```
func_name () {
    commands
}
```

Z shell 有几个特殊的函数名，你可以用它们定义函数，`shell` 会在某些时刻自动执行。例如，如果你定义了一个名为 `chpwd` 的函数，那么每当当前目录改变时，你在该函数定义的命令就会被执行。

## Z-Shell 命令

| 函数名 | 执行时间 |
|---|---|
| `chpwd` | 每当当前工作目录改变时执行。 |
| `precmd` | 在每个提示符出现之前执行。如果设置了 `PERIOD` 选项，此函数将每隔 `PERIOD` 秒执行一次，紧在提示符出现之前。 |
| `TRAPxxx` | 每当 `shell` 接收到 `SIGXXX` 时执行，其中 `xxx` 是为 `kill` 内置命令指定的信号名称。该信号值将作为第一个参数传递给函数。 |
| `TRAPZERR` | 每当命令具有非零退出状态时执行。 |
| `TRAPDEBUG` | 在每个命令之后执行。 |
| `TRAPEXIT` | 当 `shell` 退出时，或者如果定义了函数，则在该函数结束时执行。 |

### `functions`

```
functions [±tum] [name ...]
```

`functions` 用于为 `shell` 函数设置属性。它等同于 `typeset -f` 命令。在没有选项或参数的情况下，`functions` 列出所有定义的函数。使用 `-m` 选项，参数被视为模式，选择任何匹配模式的函数。`-t` 选项开启该函数的跟踪，`-u` 选项将该函数标记为自动加载（`autoload`）。

### `getopts`

```
getopts
```

`getopts` 用于解析命令行选项。虽然原文 OCR 存在混淆，但根据上下文及 Z-Shell 标准行为，此处应保留 `getopts` 的基本定义。
