
然后，你的邮件程序会获取所有入站邮件并显示供你阅读。如果你不删除它们，它们会被存放在你的邮箱文件（`mailbox file`）中。这与你的入站邮件不同——邮箱文件存储了你所有的旧邮件。许多用户会觉得 `sendmail` 邮箱箱不够用，并为不同的主题创建多个信箱，但当你运行邮件程序时，总有一个默认的信箱，这被称为你的“邮箱”。

如果你向他人发送邮件，邮件将直接发送到你所在站点的邮件计算机，该计算机可以随心所欲地处理邮件——要么立即发送，要么保存邮件以稍后发送。

## 使用邮件程序

如前所述，有很多邮件程序，每个程序都有自己的特点。但它们都尝试完成任务，并倾向于以类似的格式呈现消息。学习一个邮件程序将让你掌握使用任何现有程序所需的概念。

### 消息摘要

几乎每个邮件程序都会这样汇总你的消息：

| 标记 | 序号 | 主题 |
|---|---|---|
| FA | 1) From | Re: Congratulations! (245 chars) |
| F | 2) From | requirements. (1744 chars) |
| F | 3) From | Re: Sign (2576 chars) |
| D | 4) From | Re: Overnight (1378 chars) |
| FA | 5) From | Re: thank you (1451 chars) |
| U | 6) From | noise (2653 chars) |
| | 7) From | |

每条消息占一行。每条消息的信息呈现格式可能不完全相同，但内容应该是类似的。从左到右，程序提供以下信息：

- 消息标记（Message flags）：每条消息都关联有几个变量。在这种情况下，标记表示消息是否未被使用（U）、你是否已回复（A）、消息是否已删除，以及你是否标记了该消息以备后续关注。程序允许你为每个标记设置优先级。
- 消息编号（Message number）：这有助于通过唯一标识符来引用消息，以便打印、读取和删除。通常，邮件程序会从你邮箱中的第一条消息开始向上计数。
- 日期（Date）：这告诉你是消息发送的时间。
- 姓名（Name）：这是发送邮件的人员。如果没有提供姓名，则使用该人的互联网地址。
- 主题（Subject）：当发送者输入消息时，邮件程序会请求主题。如果空间不足，主题会被截断。
- 长度（Length）：这显示消息的大小。在这里以行数给出。

### 读取新消息

所有邮件程序都有读取邮件的命令。通常，在字符界面中你使用 `r` 或按回车键，在图形界面中则为“点击”。这会一次性向你显示所有的新消息。当你阅读每条消息时，你有几个选项，例如回复或删除消息。

### 操作旧消息

当你在读取消息时可用的功能，通常在你没有读取任何特定消息时也可用，并且可以应用于单条旧消息或一组消息。例如，当你正在阅读某条消息时，你可以告诉邮件程序将其删除。消息通常通过编号给出，但如果你使用的是使用鼠标的邮件程序，你可能可以通过点击消息来选择它们。

## 常用邮件函数

以下是你应该在程序中学习使用的标准邮件函数列表：

- 读取消息（Read message(s)）：显然，如果你不能做到这一点，其他什么都不重要了。
- 删除消息（Delete message(s)）：邮箱可能会被旧邮件弄得非常混乱，你甚至可能因为它们深埋在垃圾邮件中而丢失重要邮件。你需要能够丢弃你不关心的邮件。
- 标记消息（Flag message(s)）：你应该能够将消息标记为重要。邮件程序应该以某种方式让它们脱颖出来，以便你记得处理它们。
- 发送消息（Send message）：你应该能够向其他人发送邮件。
- 回复消息（Reply to message）：你应该能够轻松地向给你发邮件的人回复，并包含部分发送者的消息正文供参考。
- 将消息保存到文件（Save message to file）：你可能会收到包含你想在另一个程序使用的重要信息的邮件。你应该能够将消息正文保存到文件中，你可以对文件任意处理。
- 切换到其他邮箱（Switch to other mailbox）：如果你开始收到足够的邮件，你可能会发现创建其他邮箱很方便。也许可以为邮件列表专门创建一个邮箱。你的邮件程序应该能够处理多个邮箱。
- 将消息移动到其他邮箱（Move message(s) to other mailbox）：如果你有多个邮箱，应该可以将邮件移动到另一个邮箱。

### 邮件配置文件

由于处理邮件涉及很多个人偏好，几乎所有的邮件程序都有许多可以设置的选项。为了让你不需要每次运行邮件程序时都设置这些选项，大多数邮件程序都有一个每次启动程序时读取的配置文件。

你应该仔细研究如何设置你的邮件程序——在此过程中，你会发现许多你甚至不知道的选项。例如，许多程序允许你设置别名；例如，你可以只输入 `bill` 而不是 `bill@longname.deep.stuff.edu`。邮件会将别名转换为全名。

## 常见的 UNIX 邮件程序

UNIX 系统有很多邮件程序。本章介绍最流行的程序，包括 `mail`、`milx`、`elm` 和 `pine`。

### mail (Berkeley Mail)

`mail` 程序是一个简单的邮件代理，源于 BSD（Berkeley 软件发行）版本的 UNIX。它有时被称为 Berkeley Mail。该程序在功能和演示上都很简单，但仍有一些站点在使用。

要发送消息，输入 `mail`，后跟一个或多个用户地址（本地或远程）。例如，以下命令将邮件发送给不同的用户：

```
mail carter@example
```

在下一行开始输入消息内容。完成后，单独输入一个 `.` 或 `control-d` 表示你已完成。邮件传输代理将递送消息。为了方便，你可以将消息文本放在一个文件中，并通过以下单条命令发送：

```
mail carter@example < file
```

当你在登录时，有邮件到达将收到通知。例如，`cshrc` 文件中的以下语句每隔 60 秒检查一次邮件，并在邮件到达时打印消息“You have new mail”。如果你没有使用 C shell，某些 UNIX 平台存在一个名为 `notify` 的实用程序，可以提供类似的功能。

`mail` 命令是 Berkeley mail 命令的扩展版本。要发送邮件消息，请输入 `mailx` 后跟一个本地和/或远程用户列表。例如：

```
mailx ccarter jrandle
```

在输入消息正文之前，系统会提示你输入主题。你可以为主题输入单行的描述，或者直接按回车继续。之后，你就像使用 `mail` 命令一样输入消息正文。你也可以通过从文件重定向输入来发送邮件，就像之前的 mail 示例一样。

`mail` 命令为输入消息提供了扩展功能。例如，在某行输入 `~v` 将打开编辑器。当你在 `vi` 编写消息时，输入 `ESC` 和 `ZZ` 即可退出编辑器，并直接返回 `mail` 命令。此功能在 Berkeley Mail 中可用。

另一个实用功能是将文件内容导入到消息体中。输入 `~r filename` 会出现一行显示文件名以及文件中的行数和字符数。下面的示例显示了如何使用此选项将命令（uencode）的结果导入到邮件消息中。此功能在 Berkeley Mail 中同样可用。

```
$ mail trimble
Subject: tif file

Here is the tif file that I promised you.

~r !uencode picture.tif picture.tif
"uencode picture.tif picture.tif" 368/22606
.
EOT
$
```

接下来的命令集显示了收件人如何保存并 udecode 文件内容：

```
$ mailx
mailx Revision: 70.7      Date: 92/04/16 15:39:44 Type ? for help.
/usr/mail/trimble": 1 message new
> N 1 trimblef             Sun Apr 27 14:36 376/22723 tif file
> ?8 file.tif
"file.tif" [New file] 376/22768
> q
$ uencode file.tif
$ ls -l
total 260
-rw-rw-rw- 1 trimblef users      22733 Apr 27 14:38 file.tif
-rw-xr-rwx 1 trimblef users      16384 Apr 27 14:40 picture.tif
$
```

在提示提示符处，使用了 `file.tif` 命令来保存消息内容，即 uencoded 后的文件。运行 `uencode` 程序后，将创建 `picture.tif`。

前面的示例还说明了如何读取邮件。只需输入 `mailx`，即可显示信箱中每条消息的消息头。第一个字段标识消息状态（N 代表新消息，U 代表未读消息）。第二个字段是队列中的数字。第三个字段是发件人地址。下一个字段是接收消息的日期。最后一个字段表示消息的行数/字符数。在问号提示符处，你可以输入 `p` 读取下一条消息，输入 `s filename` 发送文件，或输入 `n` 读取下一条消息。如果你想在邮件程序中回复发件人，请输入 `r`。

> 注意：在 Utrix、HP-UX 和 AIX 系统上，`r` 命令用于回复头部中“To:”和“CC:”部分的所有人员，而 `R` 仅回复发件人。然而，在 SunOS 上，情况相反。请阅读手册页以明确你系统上的行为。

完整的命令列表请参见 `mailx` 的手册页。

环境也可以进行自定义。当调用 `mailx` 命令时，它首先执行名为 `/usr/lib/mailx/mailx.rc` 的全局配置文件中的命令。以下是一个典型的 `mailx.rc` 文件内容：

```
+ set assub
set dot
set crt=23
set PAGER=more
```

`set` 选项允许 mailx 在发送邮件时未指定 `-s` 选项的情况下提示用户输入主题行。`dot` 选项允许你通过单独占一行输入 `.` 来发送消息，就像 `mail` 命令一样。`cr` 选项指定了从消息到 `PAGER` 设置中指定的管道显示的行数。例如，每次将 23 行输出发送到 `more` 命令。在读取全局配置文件后，mailx 会读取 `$HOME/.mailrc` 中的用户本地配置文件。本地配置文件中最常见的项目类型是显示选项和定义用户别名。完整的配置选项集记录在 `mailx` 的手册页中。

> 提示：某些 UNIX 系统有一个非常有用的程序叫做 `vacation`，它允许你用预定义的消息自动回复邮件。当你不打算在长时间回复邮件时，这非常有用，因此该程序会向你在 `vacation` 命令中指定的每人发送邮件。`vacation` 命令旨在放在你转发到另一个电子邮件地址的设置中，同时向发件人发回消息，告知你的新电子邮件地址。可以使用以下命令来设置 `vacation` 命令以响应你的邮件：
```
$ cd $HOME
$ rm .forward
$ vacation -I
vi .forward
username, "vacation message"
I'll be out of the office until 5/20/97
```

当你能够回复邮件并想禁用转发时，只需删除 `.forward` 文件。测试这个 `vacation` 命令是一个好主意，以确保它正常工作。详情请参 `vacation` 命令的手册。

与 `mailx` 程序相比，`elm` 提供了一个全屏菜单驱动的界面。它被设计为一个易用的 UNIX 程序，但具有相当的配置和功能。随附的辅助程序值得关注。它附带了多页 PostScript 格式的文档。`elm` 程序在你的系统中可能不是标准的，所以你需要自己获取。坦率地说，它可以通过 http://ftp.archive.wisc.uci.edu/packages/mail/elm 获取。打包好的源代码有几兆字节。为了安装，你需要编译并安装一些系统配置。

`elm` 显示的菜单如下：

```
Mailbox is /usr/mail/trimble with 3 message(s) [Elm revision: 70.8]
1   Apr 27 trimble (9) status
2   Apr 27 trimble (10) tickets
3   Apr 27 trimble (10) Going away
```

你可以通过按下以下字符使用命令：`D` 删除或取消删除邮件，`M` 邮件，`R` 回复或转发，`Q` 退出。要读取消息，按 `j` 向下，`k` 向上，`?` 帮助。消息显示的格式与 `mailx` 类似。为了访问帮助，随时按 `?`。

> 提示：从菜单按 `o` 获取选项。`elm` 创建了一个名为 `.elmrc` 的文件，你可以用 `vi` 或 `emacs` 编辑。这些选项大部分在 `elm` 内部设置。阅读指南获取关于这些选项的信息。

> 提示：`elm` 可以作为命令行邮件程序——就像 Berkeley mail 一样使用相同的语法：
```
elm -s "subject" recipient < messagefile
```

> 提示：不要忽略随 `elm` 附的辅助程序。其中最有用的几个：
- `autoreply` 用自动回复回答你的所有入站邮件。如果你的信箱积压，或者你要度假或想让人们知道你不在读邮件，这很有用。
- `filter` 根据邮件内容将邮件保存到不同的信箱、删除它、转发它等。如果你订阅了邮件列表或收到大量主题邮件，这很有用。
- `lists` 为每条消息列出 From 和 Subject 头部。这对于快速检查入站邮件很有用。
- `messages` 提供信箱中消息的计数。
- `newmail` 和 `winmail` 是在新邮件到达时立即通知你的程序。`winmail` 在窗口中运行。
- `readmsg` 从信箱获取消息并将其发送到标准输出。这对于以奇异的方式提取和处理邮件消息。

甚至有一个 USENET 组：`comp.mail.elm`。

PINE 是另一个适用于 UNIX 系统的邮件程序。PINE 代表 Program for Internet News and E-mail（在历史上，有人将 PINE 称为 Pine Is Not Elm，`elm` 的原始代码被用作起点！）。它在华盛顿大学开发，考虑了新手用户。这些用户可以使用程序而不会出错。由于宽容的用户界面，它也为高级用户提供了许多选项。

PINE 的用户界面与 `elm` 非常相似。然而，它的功能数量并不那么令人应从，并且努力保持相同的按键来执行相同的功能。PINE 甚至附带了自己的文本编辑器 `Pico`，可以作为通用文本编辑器。从核心上来说，它是 `emacs` 或 `vi` 的改进。

Unix 平台提供了预编译的 PINE 版本。你可以访问 ftp/ftp.cac.washington.edu 并查看 `/mail` 目录。AIX3.2、HP/UX 9.1、Linux、NextStep、Solaris 2 (SPARC) 和 SunOS 4.1.3 (SPARC) 的预编译版本位于 `pine` 目录下的 `unix-bin` 子目录下。如果你需要编译自己的版本，源代码可在 `pine` 文件中找到。

要自定义 PINE 的行为，请编辑家目录下的 `.profile`。配置项解释得相当清楚。这里不需要做什么，但请确保使用 `personal-name`、`smtp-server`（如果你使用 SMTP）和 `inbox-path` (/usr/spool/mail/your`)。

“常用 Unix 邮件程序”通常假设你在连接互联网的计算机上运行邮件程序。然而，在许多情况下，你希望在自己的电脑上读取所有邮件，因为登录邮件账户的时间可能会收费，而且 Mac 和 PC 上的程序比 Unix 系统上的友好得多。

你需要的是一个能够接收邮件（或连接到任何必要的手段）、获取所有新邮件并断开连接的程序。然后你可以随时阅读邮件并输入新消息。如果有任何新消息，程序应该调用你的邮件服务器并交付新消息进行递送。正如你可能猜到的，这些程序存在并被称为邮件客户端（mail clients）。

这种方法与“在你的互联网计算机上读邮件”的方法之间的主要区别在于，你的邮箱箱被保存在你的个人计算机上，而不是互联网计算机上。

显然，必须有一种方法让你的邮件客户端能够与你的互联网计算机通信并传输消息。关于这方面，有几种标准。

## SMTP（简单邮件传输协议）

简单邮件传输协议（SMTP）或其变体（如扩展 SMTP）被互联网上处理邮件的计算机用于将邮件从一机器机器传输到另一台机器上。它是一种单向协议——SMTP 客户端连接 SMTP 服务器并向其递交邮件。

大多数邮件客户端都支持使用 SMTP 发送出的邮件，这仅仅是因为它很容易实现。事实上，大多数邮件客户端支持 SMTP 是因为你的邮件客户端无法联系你的个人计算机来递交邮件。例如，你的个人计算机可能恰好通过以太网永久连接到邮件计算机，或者你的邮件客户端知道如何使用调制解调器拨打你的个人计算机，但在大多数情况下，这一点是不容疑问的。

## POP3（邮局协议第3 版）

大多数邮件客户端用于从远程系统检索邮件的标准协议是邮局协议 POP3。这使得你的邮件客户端能够获取新邮件、删除邮件以及读取收件箱邮件所需的其他操作。POP 只需要系统中的一个“愚笨”邮件服务器，而你的邮件客户端需要具备大多数管理邮件的智能。它是一个简单的协议，大多数邮件客户端都提供该协议。

POP3 有些不安全的地方，因为你的邮件客户端每次调用时都需要发送你的账户和密码。你执行此操作越频繁，使用网络嗅探器的人同时获取这二者的概率就越大。（我们正试图恐唬你，但这是可能的）。一种名为 APOP 的扩展使用类似 MD5 的安全算法来为每个会话对你的密码进行加密。

最后，请注意 POP3 没有方法将邮件发回邮件服务器。POP3 有一个名为 XNDIM 的可选扩展可以实现此功能，但客户端和服务器都必须支持它。通常，邮件客户端使用 SMTP 发送邮件，并使用 POP3 检索邮件。

## 邮件客户端的理想功能

以下是在购买邮件客户端时可以参考的一些实用功能：
