
BASH shell 有一组用于配置你的 shell 的配置变量。你可以通过修改这些变量来根据你自己的需求配置 shell。某些变量由系统设置且不可更改。另一些变量带有初始值，你可以将其更改为你想要的值。还有一些变量需要用户自行定义。

## BASH Shell 配置

### 系统确定

| Shell 特殊变量 | 变量内容 |
|---|---|
| `HOME` | 用户主目录的路径名。 |
| `LOGNAME` | 登录名。 |
| `TZ` | 系统使用的时区。 |

### 可重定义的特殊变量

| Shell 特殊变量 | 变量内容 |
|---|---|
| `SHELL` | 你正在使用的 shell 类型程序的路径名。 |
| `PATH` | 用于搜索可执行命令的目录路径列表。 |
| `PS1` | 主提示符。 |
| `PS2` | 次提示符。 |
| `PS3` | `select` 命令的提示符。 |
| `PS4` | 此提示符的值会被展开，并在 BASH 在执行跟踪期间显示的每个命令之前进行显示。`PS4` 的第一个字符会根据需要复制多次，以指示多层间接。默认值是 `+`。 |
| `IFS` | 字段分隔符符号。 |
| `MAIL` | `mail` 实用程序检查接收消息的文件名。 |
| `MAILCHECK` | 检查接收邮件的间隔。 |
| `CDPATH` | `cd` 命令搜索子目录的目录路径名。 |
| `PWD` | 当前工作目录。 |
| `OLDPWD` | 由 `cd` 命令设置的上一个工作目录。 |
| `REPLY` | 当未提供任何参数时，设置为 `read` 内置命令读取的输入行。 |
| `UID` | 展开为当前用户的用户 ID，在 shell 启动时初始化。 |
| `EUID` | 展开为当前用户的有效用户 ID，在 shell 启动时初始化。 |
| `BASH` | BASH 的完整路径名。 |
| `BASHVERSION` | BASH 的版本号。 |
| `SHLVL` | 每启动一次 BASH 实例加 1。 |
| `RANDOM` | 被引用时生成一个随机整数。随机数序列可以通过给 `RANDOM` 赋值来初始化。 |
| `HISTCMD` | 当前命令在历史列表中的索引。 |
| `HISTSIZE` | 历史命令记住的命令数。默认值为 500。 |
| `OPTARG` | `getopts` 内置命令处理的最后一个选项参数的值。 |
| `OPTIND` | `getopts` 内置命令将处理的下一个参数的索引。 |
| `HOSTTYPE` | 自动设置为唯一描述执行 BASH 的机器类型的字符串。 |
| `HOSTFILE` | 系统的完整完整机名。格式与 `/etc/hosts` 相同。 |

### 用户定义的特殊变量

| Shell 特殊变量 | 变量内容 |
|---|---|
| `MAILPATH` | `mail` 检查接收消息的检查邮件文件列表。 |
| `TERM` | 终端名称。 |
| `MAILWARNING` | 如果设置，且 BASH 正在检查邮件的文件自上次检查后被访问过，则显示消息“The mail in mailfile has been read”。 |
| `EXINIT` | Ex/V1 编辑器的初始化命令。 |
| `OSTYPE` | 执行 BASH 的操作系统的描述。 |
| `ENV` | 包含初始化 shell 命令的文件名，如 `.bashrc` 或 `.tcshrc`。`ENV` 的值在解释为路径名之前会经过参数展开、命令替换和算术展开。 |
| `HISTFILESIZE` | 历史文件中包含的最大行数。当给此变量赋值时，历史文件将根据需要截断，使其包含行数不超过该数量。默认值为 500。 |
| `OPTERR` | 如果设置为 1，BASH 会显示由 `getopts` 内置命令生成的错误消息。每次调用 shell 或执行 shell 脚本时，`OPTERR` 均初始化为 1。 |
| `PROMPTCOMMAND` | 显示主提示符之前执行的命令。 |
| `TEOUT` | 等待输入的秒数。 |
| `FCEDIT` | `fc` 命令的默认编辑器。 |
| `IGNORE` | 要忽略的后缀冒号分隔列表。 |
| `INPUTRC` | `readline` 启动的文件名，覆盖 `~/.inputrc`。 |

### BASH Shell 功能

| BASH Shell 功能 | 功能 |
|---|---|
| `set -o` | 使用 `set` 命令开启或关闭功能。 |
| `notify` | 立即报告后台作业，而不是等到显示下一个提示符。 |
| `dotfilenames` | 在路径展开结果中包含以点 (.) 开头的文件名。 |
| `commandoriented` | 保存所有历史记录。 |
| `nolinks` | 执行更改目录的命令时不跟随符号链接；而是使用物理目录。（默认情况下，BASH 逻辑目录。） |
| `noexitonfailed` | 当 `exec` 失败时不允许交互式 shell 退出。 |
| `cdvars` | 假设 `cd` 命令的非目录参数是变量名，该变量的值要切换的目录。 |
| `ignoreeof` | 禁用 `CTRL-D` 退出。不要通过重定向重写文件。 |
| `noglob` | 禁用用于文件名展开的特殊字符：`*`、`?`、`[` 和 `]`。 |

## 脚本输入与输出：`$<`

你可以轻松地在 shell 脚本中定义和使用变量。如例所示，你可以使用文本编辑器将 Linux 命令（例如赋值操作和 `echo`）放入文件中。然后你可以让该文件具有执行权限，并在命令行中作为另一个命令调用它。记得添加执行权限，你可以使用 `chmod` 命令配合 `u+x` 权限或 `700` 绝对权限。在脚本中，你可以使用 `echo` 命令输出数据。然而，必须通过重定向标准输入将输入读入变量。TCSH shell 中没有类似的 Linux `read` 命令。

TCSH shell 通过检查文件的第一个字符来确定其是否为 TCSH shell 脚本。记住，所有 TCSH shell 脚本的第一行第一个字符必须是 `#`。这会将该文件识别为 TCSH shell 脚本。注意 `greet` 脚本开头的 `#` 字符。位于第一行第一个字符以外任何地方的 `#` 字符都被视为普通字符。

`greet`

```bash
#
# 输出问候候的脚本
set greeting = "hello"
echo The value of greeting is $greeting
```

```bash
> chmod u+x greet
> greet
The value of greeting is hello
```

`set` 命令结合重定向操作 `<$`，会读取用户输入到标准输入的任何内容。下一个示例将输入读入 `greeting` 变量。

```bash
> set greeting = $<
```

你可以使用 `echo` 命令将提示符与输入放在同一行。TCSH shell 为 `echo` 使用了一个特殊选项 `-n`，它会消除输出字符串末尾的换行符。在输出字符串结束时，光标仍留在同一行：

```bash
> echo -n Please enter a greeting:
```

如果你想在双引号内的提示符末尾包含一个空格，你需要将输出字符串放在双引号内，包括空格：

```bash
> echo -n "Please enter a greeting: "
```

接下来显示的 `greptspt` 脚本包含一个 TCSH shell版本的提示符，它与输入保持同一行。

```bash
greetpt
#
echo -n "Please enter a greeting:"
set greeting = $/
echo "The greeting you entered was $greeting"
```

```bash
> greetspt
Please enter a greeting: hello
The greeting you entered was hello
>
```

TCSH shell 拥有一标准的赋值、算术和关系运算符（见下表），这在大多数编程环境中都是常见的，此外还有 shell 函数的运算符，例如重定向和后台操作。

| 赋值运算符 | 功能/描述 |
|---|---|
| `=` | 赋值。 |
| `+=` | 加到表达式并赋值。 |
| `-=` | 从表达式减去并赋值。 |
| `*=` | 与表达式相乘并赋值。 |
| `/=` | 除以表达式并赋值。 |
| `%=` | 对表达式取模并赋值。 |

| 算术运算符 | 描述 |
|---|---|
| `-` | 一元减法运算符 |
| `+` | 加法 |
