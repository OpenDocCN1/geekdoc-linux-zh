# sed

`sed` 是 `stream editor`（流编辑器）的缩写。虽然这个名字意味着编辑，但它并不是一个真正的编辑器；它逐行扫描输入文件，并对每行应用一组指令。脚本通常位于文件中，但也可以在命令行输入。

`sed` 有三个有用的选项：
- `-n`：抑制自动输出。
- `-f`：指定脚本文件。
- `-e`：指示脚本跟在命令行后面。

脚本由地址和命令组成。地址选择要处理的行，如果省略地址，则处理所有行。

## 脚本格式

地址可以是行号、行范围（例如 `2,14`）或正则表达式。命令可以是替换（`s`）、删除（`d`）或打印（`p`）。

## sed 示例

为了理解 `sed` 如何与输入文件交互，让我们看看 `11.6` 中的示例。该脚本使用了替换命令。在第一行中，将范围 `1,3` 的“Greetings”替换为“Hello”。第二条指令在第 2 和 3 行将“buddies”替换为“friends”。注意这两个范围有重叠。

## 注释

注释是解释脚本的行。`sed` 会忽略注释。注释以 `#` 开头。

## 11.1 示例脚本

```
# 这是一个注释
2,14 s/A/B
30d
42d
```
