# latex2html

LaTeX 到 HTML 翻译器。`LaTeX2HTML` 是一种将 LaTeX 编写的文档转换为 HTML 格式的转换工具。它为使用文字处理功能创建超媒体文档提供了一条便捷的迁移路径。`LaTeX2HTML` 将 LaTeX 文档的结构复制为一组相互连接的 HTML 文件，可以使用自动生成的导航页面进行浏览。交叉引用、引用、脚注、目录和表格列表也被转换为超链接。在 HTML 中具有等效 `tags` 的格式（列表、引用、段落断行、字体等）也得到了适当转换。重度格式的项目（如数学方程、图片或表格）被重名为图像，并自动放在最终 HTML 文档的正确位置。`LaTeX2HTML` 通过支持不断变化的远程文档之间的超链接和符号交叉引用扩展了 LaTeX。它还允许包含原始 HTML 命令。这些 LaTeX 的超链接作为 LaTeX 文档中的新命令和环境可用。`Pstoimg`（处理 LaTeX 源的部分）可以支持 GIF 和 PNG 格式。由于对 GIF 图像格式某些法律限制，此包禁用了 GIF 支持。来自 Debian 3.0r

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
