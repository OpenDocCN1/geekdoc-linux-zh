# fwlog

防火墙日志分析器。`fwlog` 使用 `iptables` 过滤器生成防火墙日志（包括每日统计等），并以 HTML 和文本格式化。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`。

# g++

GNU C++ 编译器。这是由 `gcc` 支持的平台的 C++ 编译器。它使用 `gcc` 后端生成优化代码。它是 Debian 默认的 `g++` 依赖包（版本 95.4，针对 i386 架构）。

# g-wrap

`g-wrap` 是创建 C 库的工具。目前它主要关注 C 库的访问，但它支持 Scheme。

# g3data

从扫描中提取数据。`g3data` 用于从图表中提取数据。例如，图表通常在科学期刊上发表；`g3data` 使提取这些数据变得简单。来自 Debian 3.0r0 APT `http://www.helsinki.fi/~frantz/g3data.html`

# g5

基于 GTK 的 5 游戏。目前其核心游戏仍在那里，但它支持声音。它是 Debian 独有的（至少目前）。来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

# g77

GNU Fortran 77 编译器。这是由 `gcc` 支持的平台的 Fortran 77 编译器。它使用 `gcc` 后端生成优化代码。它是 Debian 默认的 `g77` 依赖包。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/index.html`

# gabber

GNOME Jabber 客户端。`Gabber` 是一个名为 Jabber 的即时系统的免费开源 GNOME 客户端。Jabber 不依赖单一服务器，且协议有良好的文档。`Gabber` 允许与许多不同的即时系统通信，包括 ICQ 和 Aim。来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

# gaby

小型个人数据库管理器。`Gary` 是基于 GTK+ 和 Gnome 的 Linux 程序。它旨在为普通用户提供直接的数据库访问（地址、书籍……），同时保留轻松创建其他数据库的能力。在技术上，它的设计考虑了简单性并使用了插件的规则。来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

# GAC

ICANN 政府顾问委员会。来自 Vera `http://www.tld.org/LDP/Linux-Dictionary/index.html`

# gacc

个人账户管理器。`prace` 是一个旨在管理个人银行账户的程序。它提供了基本功能，如下：

- 在钱包中拥有多个账户
- 用户可读的文件和钱包
- 从文件中添加/删除任何账户（开心地）
- 从任何账户中添加/删除任何操作（幂）
- 修改分类列表
- 点对点操作
- 显示每次操作的中间余额
- 重新编辑操作
- 重新编辑操作
- 国际化（尚未完成。需要志愿者？）以及定位格式等……为了更好地使用，还需要实现其他功能。查看 TODO 文件了解它们是什么。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# gadfly

基于 Python 的 SQL 数据库和解析器生成器 `Gadfly` 使用非常标准 SQL 的大部分子集作为查询语言，并使用 Python 模块以及可选的 C 扩展模块作为底层引擎。`Gadfly` 将活动数据库存储在内存中，并带有到文件系统的恢复日志。它支持可选的 TCP/IP 客户端/服务器以及基于日志的软件恢复（但不支持硬件故障恢复）。作为 `Gadfly` 包的一部分的 `kwParser` 是一个 Python 的解析器生成器。它将语言语法的抽象表示（带有定义语言语义的“解释函数”）转换为编译器或解释器。来自 Debian 3.0r3 APT-Debian 3.0r3

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# gaim

`Gaim` 允许你与各种即时通讯通信，包括 AIM (Oscar 和 TCQ)、ICQ、Yahoo!、MSN Messenger、Jabber、Gadu-Gadu、Napster 和 Zephyr。这些协议的实现采用了模块化且易于使用的设计。要使用某种协议，只需加载 Gail 的插件即可。它支持许多与其他软件共同功能以及许多独特功能，如 perl 脚本和 C 插件。`Gaim` 与 AOL 无关。来自 Mandrake 9.0 RPM
