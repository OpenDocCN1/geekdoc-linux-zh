# texinfo

Textinfo 是一个可以从单个文件同时生成信息性输出和打印输出的文档系统。通常情况下，你必须编写两份文档：一份用于在线帮助或其他信息，另一份用于排版手册或打印字作品。使用 Textinfo，你只需要编写一个源文档。当作品需要修订时，你只需要修改一个源文档。GNU 项目在其大部分文档中使用 Textinfo 格式。如果你需要一个能够从同一个源文件生成在线和打印文档的文档系统，或者你正准备为 GNU 项目编写文档，请安装 `texinfo`。Mandrake 9.0 RPM

# texmacs

WSIWYG 所见即所得 emacs 类数学文本编辑器，使用字体。GNU TeX 是一个免费的文本编辑器，由 TeX 和 GNU Macs 构建。该编辑器允许你通过 WYSIWYG（所见即所得）和友好的界面编写结构化文档。作者可以创建新的样式。该程序实现了高质量的排版算法和 TeX 字体，这有助于你生成看起来专业的文档。高水平的排版仍然适用于自动生成的文档，这使得 TexMacs 适合作为计算机代数系统的接口。TexMacs 还支持 Guide/scheme 扩展语言，因此你可以自定义界面并为编辑器编写自己的扩展。未来，TexMacs 计划演变为一个完整的科学软件，TexMacs 主页见：`http://www.tldp.org//imux-Dictionary/html/index.html`

# text

这个词有多种含义。从历史角度看，它源自标准的英语单词，指印刷或书写作品的主文。例如，某人发出的信件正文将信件内容与信封或问候区分开来。在密码学中，单词 TEXT 指任何你想加密的内容，其中单词 plaintext（明文）表示加密前的消息，而 ciphertext（密文）表示你加密后的消息。在科学的其他领域，有文本数据（text data）和二进制数据（binary data）。“text”一词通常指可读数据（如英语），而二进制数据表示只能由计算机读取。误解：我们有时会加密二进制数据，在这种情况下，二进制数据构成了消息的明文。运行的二进制程序的主体通常被称为程序的 TEXT。在这些特定领域，单词“TEXT”表示的是与通常用法相反的含义。源自 黑客术语表（Hacking-Lexicon）

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
