
`display` 指定与 X server 的连接。

`discard` 一个布尔值，指示 XSync 是否丢弃事件队列上的所有事件。

`XSync` 函数刷新输出缓冲区，并等待所有请求都由 X server 接收并处理。错误必须由错误处理器处理。对于 Xlib 接收到的每个协议事件，`XSync` 会调用应用程序的错误处理程序（见第 11.8.2 节）。服务器生成的任何事件都会被入库到事件队列中。

最后，如果你传递 `False`，`XSync` 不会丢弃队列中的事件。如果传递 `True`，`XSync` 会丢弃队列中的所有事件，包括在调用 `XSync` 之前队列上的事件。客户端应用程序很少需要调用 `XSync`。

## 事件队列管理

Xlib 维护一个事件队列。然而，操作系统也可能在其网络连接中缓冲数据，这些数据尚未读入事件队列。

要检查事件队列中的事件数量，请使用 `XEventsQueued`。

```
int XEventsQueued(display, mode);
```

指定与 X server 的连接。

指定模式。你可以传递 `QueuedAlready`、`QueuedAfterFlush` 或 `QueuedAfterReading`。

如果 `Mode` 为 `QueuedAlready`，`XEventsQueued` 返回事件队列中已事件的数量（从不执行系统调用）。如果 `Mode` 为 `QueuedAfterFlush`，如果队列中的事件不零，则 `XEventsQueued` 返回队列中的事件数量。如果队列中没有事件，`XEventsQueued` 会刷新连接的输出并返回读取的数量。如果 `Mode` 为 `QueuedAfterReading`，如果队列中的事件不零，则 `XEventsQueued` 返回队列中已事件的数量。如果队列中没有事件，`XEventsQueued` 会从应用程序读取更多事件而不刷新输出缓冲区，并返回读取的数量。

如果队列中已经有事件，`XEventsQueued` 始终会立即读取且不进行 I/O。模式为 `QueuedAfterFlush` 的 `XEventsQueued` 行为与 `XPending` 相同。

要返回待处理的事件数量，请使用 `XPending`。

```
int XPending(display);
```

指定与 X server 的连接。

`XPending` 与模式为 `QueuedAlready` 的 `XEventsQueued` 相同。

## 操作事件队列

Xlib 提供了让你操作事件队列的函数。本节讨论了如何：

- 按顺序获取事件并从队列中移除
- 查看事件而不移除它们

### 返回下一个事件

要获取下一个事件并从队列中移除它，请使用 `XNextEvent`。

```
XNextEvent(display, event_return);
```

指定与 X server 的连接。

返回队列中的下一个事件。

`XNextEvent` 函数将队列中的第一个事件复制到指定的 `XEvent` 结构中并移除。如果队列为空，`XNextEvent` 会刷新输出缓冲区并等待事件接收。

要查看事件队列，请使用 `XPeekEvent`。

```
XPeekEvent(display, event_return);
```

指定与 X server 的连接。

返回事件关联结构的副本。

`XPeekEvent` 函数返回队列中的第一个事件，但不将其从移除。如果队列为空，`XPeekEvent` 会刷新输出缓冲区并等待事件接收。

## 使用谓词程序选择事件

本节讨论的每个函数都要求你传递一个谓词程序，用于判断事件是否符合你的要求。谓词必须在不调用任何 Xlib 函数的情况下判断事件是否有用。如果谓词直接或间接地导致了事件队列状态的变化，结果是不定义的。如果 Xlib 已为线程初始化，则调用谓词时会锁定显示，且谓词对任何锁定显示函数的调用结果是不定义的，除非调用者先调用了 `XDisplay`。

谓词及其关联参数为：

```
Bool(display, event, arg);
```

指定与 X server 的连接。

指定 `XEvent` 结构。

指定从 `XEvent` 或 `XPeekEvent` 传递的参数。

谓词程序会对队列中的每个事件调用一次，直到找到匹配项。谓词程序必须返回 `True`。如果没有找到匹配，它必须返回 `False`。

要检查事件队列是否存在匹配事件，并在找到后将其从队列中移除，请使用 `XNextEvent`。

```
XNextEvent(display, event_return, (*predicate)(arg), arg);
```

指定与 X server 的连接。

返回匹配事件的关联结构。

指定要调用的谓词，以确定队列中的下一个事件是否符合你的要求。

指定用户提供的参数，该参数将传递给谓词程序。

`XIfEvent` 函数仅当指定的谓词程序对某个事件返回 `True` 时才完成，这表示队列中的某个事件与条件匹配。如果 `XIfEvent` 在等待额外的事件时发生阻塞，它将刷新输出缓冲区。`XIfEvent` 会从队列中移除匹配的事件，并将该结构复制到客户端提供的结构中。

若要在非阻塞的情况下检查事件队列以查找匹配的事件，请使用 `XCheckIfEvent`。

```
Bool XCheckIfEvent(display, event_return, (*predicate)(), arg);
```

- `display`
  指定与 X 服务器的连接。

- `event_return`
  返回匹配事件的关联的拷贝。

- `predicate`
  指定要调用的程序，用以确定队列中的下一个事件是否符合你的需求。

- `arg`
  指定用户提供的参数，该参数将传递给谓词程序。

当谓词程序找到匹配项时，`XCheckIfEvent` 会将事件拷贝到客户端提供的 `XEvent` 结构中并返回 `True`。`True` 事件已从队列中移除。如果谓词程序没有找到匹配项，`XCheckIfEvent` 将返回 `False`，且输出缓冲区将被刷新。存储在队列中的所有早期事件都不会被丢弃。

若要在不移除事件的情况下检查事件队列以查找匹配事件，请使用 `XPeekIfEvent`。

```
XPeekIfEvent(display, event_return, (*predicate)(), arg);
```

- `display`
  指定与 X 服务器的连接。

- `event_return`
  返回匹配事件的关联的拷贝。

- `predicate`
  指定要调用的程序，用以确定队列中的下一个事件是否符合你的需求。

- `arg`
  指定用户提供的参数，该参数将传递给谓词程序。

`XPeekIfEvent` 函数仅当指定的谓词程序对某个事件返回 `True` 时才返回。在谓词程序找到匹配项后，`XPeekIfEvent` 将匹配的事件拷贝到客户端提供的 `XEvent` 结构中，而不会从队列中移除。如果 `XPeekIfEvent` 在等待额外的事件时发生阻塞，它将刷新输出缓冲区。

# 使用窗口或事件掩码选择事件

本节讨论的函数允许通过窗口或事件类型选择事件，允许你无序处理事件。

## 事件处理函数

若要移除同时匹配窗口和事件掩码的下一个事件，请使用 `XWindowEvent`。

```
XWindowEvent(display, w, event_mask, event_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定你感兴趣的窗口事件。

`event_mask` 指定事件掩码。

`event_return` 返回匹配事件的关联结构。

`XWindowEvent` 在事件队列中搜索匹配指定窗口和事件掩码的事件。当它找到匹配项时，`XWindowEvent` 会从队列中移除该事件并将其拷贝到 `XEvent` 结构中。存储在队列中的其他事件不会被丢弃。如果队列中没有事件，`XWindowEvent` 将刷新输出缓冲区并阻塞直到接收到事件为止。

若要移除同时匹配窗口和掩码（if）的下一个事件，请使用 `XCheckWindowEvent`。此函数与 `XWindowEvent` 类似，但它永远不会阻塞，并返回一个指示事件是否已返回的 `Bool`。

```
Bool XCheckWindowEvent(display, w, event_mask, event_return);
```

`display` 指定与 X 服务器的连接。

`w` 指定你感兴趣的窗口事件。

`event_mask` 指定事件掩码。

`event_return` 返回匹配事件的关联结构。

`XCheckWindowEvent` 函数在事件队列以及服务器连接上可用的事件中搜索第一个匹配指定窗口和事件掩码的事件。如果找到匹配项，`XCheckWindowEvent` 会移除该事件，将其拷贝到指定的 `XEvent` 结构中并返回 `True`。存储在队列中的其他事件不会被丢弃。如果请求的事件不可用，`XCheckWindowEvent` 返回 `False`，且输出缓冲区将被刷新。

若要移除匹配事件掩码的下一个事件，请使用 `XMaskEvent`。

```
XMaskEvent(display, event_mask, event_return);
```
