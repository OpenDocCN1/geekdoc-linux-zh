
![](img/7e143440dd5a0ed9683d4f26f3c074f8_49_0.png)

这可以防止由于鼠标点击意外丢失选择。它还允许你在无需将光标置于所选对象的情况下使用变换工具。你也可以在选择模式下点击它或按下空格键来开启或关闭它。

如你所见，在 `VIZ` 中移动对象非常简单。但如果你想将对象移动到特定距离或已知位置呢？接下来的练习演示了如何进行操作。

- 1. 在选中盒子并激活“选择并移动”工具的情况下，点击 `VIZ` 窗口底部的“绝对/偏移模式变换类型输入”（`Absolute/Offset Mode Transform Type-In`）按钮。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_50_0.png)

工具变为显示“偏移”（`Offset`）模式已激活状态。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_50_1.png)

当“绝对/偏移模式变换类型输入”处于“向上”或“绝对”模式时，你可以输入想要移动对象的点的特定坐标。当它处于“向下”或“偏移”模式时，你可以输入相对于对象当前位置的相对距离。

- 2. 点击坐标读取中的 `X` 输入框并输入 `10`。盒子在正 `X` 方向上移动 `10` 英寸。
- 3. 点击并拖动 `Z` 轴旋转器。盒子垂直移动。
- 4. 点击“绝对/偏移模式变换类型输入”按钮切换到绝对模式。然后点击 `Z` 坐标输入框并输入 `1`。盒子移动，使其基底的 `Z` 坐标恰好为 `1` 英寸。
- 5. 右键点击 `X` 坐标读取旋转器。记住，右键点击旋转器会将与旋转器关联的值转换为最低值，在这种情况下为 `0`。注意到盒子的 `X` 坐标移动到了 `0`。
- 6. 右键点击 `Y` 和 `Z` 坐标的旋转器。盒子移动到屏幕中心的原点 `(0,0,0)`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_50_2.png)

`就像命令面板中的旋转器一样，变换类型输入允许你通过点击和拖拽来设置值。你也可以通过右键点击旋转器返回默认零值。在偏移模式下，旋转器会自动重置为零，因为这些值代表距离基准线的数值。当你打开“选择移动”、“选择旋转”或“选择缩放”工具时，坐标读取中的旋转器会出现。`

### 旋转和缩放对象

除了移动工具外，变换工具还包括“旋转”（`Rotate`）和“缩放”（`Scale`）工具。尝试以下练习以查看这些工具如何工作。

## 从右键菜单使用变换

你也可以通过右键点击对象来激活“移动”、“旋转”和“缩放”工具。右键点击对象，从变换列表中选择“移动”、“旋转”或“缩放”。通过点击右侧的图标来访问变换输入框。

- 1. 选中对象后，点击主工具栏中的旋转工具。变换手柄显示出 `X`、`Y`、`Z` 轴。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_51_0.png)

- 2. 点击旋转手柄上的 `X` 轴。注意旋转轴被黄色高亮。拖动旋转轴。会出现一个箭头显示旋转方向，以及一个透明的提示框显示旋转量。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_51_1.png)

确保“绝对/偏移模式变换类型输入”按钮处于绝对模式。查看坐标读取。

- 3. 右键点击坐标读取中的旋转器，将 `X` 值恢复为 `0`。

旋转工具的操作方法与移动工具相同。变换输入允许你通过点击和拖拽来设置值。你也可以通过右键点击旋转器返回默认零值。在偏移模式下，你可以相对于当前方向来旋转对象。

现在尝试使用缩放：

- 1. 选中对象后，点击主工具栏中的缩放工具。变换手柄显示出 `X`、`Y`、`Z` 轴。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_52_0.png)

- 2. 点击缩放手柄的中心或对象本身并拖动。盒子均匀放大。
- 3. 点击并按住均匀缩放工具。然后从弹出菜单中选择中间工具，即“非均匀缩放”工具。此步并不是绝对必要的，在这里展示是为了说明概念。仅使用轴柄即可进行非均匀缩放。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_52_1.png)

- 4. 拖动缩放手柄上的 `XY` 平柄（黄色高亮），在 `XY` 平面内非均匀缩放盒子。同样，可以拖动轴柄将对象的缩放限制在单个轴上。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_52_2.png)

现在查看坐标读取。你看到的数值是缩放百分比。当“绝对/偏移模式变换输入”按钮处于绝对（向上）位置时，数值是原始大小的百分比。当它处于偏移位置时，数值是相对于当前大小的缩放，并在松开鼠标按钮时立即重置为 `100%`。

- 1. 在绝对/偏移模式变换输入处于绝对位置的情况下，点击并拖动 `Z` 旋转器。注意盒子在 `Z` 轴上增大。
- 2. 右键点击 `Y` 轴旋转器。盒子在 `Y` 轴上扭变为 `0` 值。
- 3. 点击 `X` 值输入框并输入 `100`。盒子的 `X` 值恢复到原始大小。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_52_3.png)

# VIZ 如何处理缩放变换

查看命令面板中参数（`Parameters`）展开列表中的盒体长度（`Length`）、宽度（`Width`）和高度（`Height`）值。尽管盒子已经缩放，但它们仍然显示为 `50.0"`。这是 `VIZ` 处理对象数据的一个重要指标。例如，如果你有一个每边长为 `1` 单位的盒子，然后将其缩放为尺寸的两倍，`VIZ` 不会将其视为边长为 `2` 单位的盒子，而是将其视为应用了 `200%` 缩放系数的 `1` 单位盒子。

- 4. 按 `Tab` 键移动到 `Y` 值输入框并输入 `100`。
- 5. 再次按 `Tab` 移动到 `Z` 输入框并输入 `75`。现在盒子比宽和长短。

选择和缩放（`Select and Scale`）工具的工作方式与其他工具略有不同。首先，坐标显示中的零值不会将选定对象恢复原始形状。这是因为坐标显示中的值代表百分比，其中 `100%` 是原始尺寸。

缩放轴（`Scale gizmo`）允许你通过自动在缩放模式之间切换，对对象进行均匀和非均匀缩放。你执行的操作取决于你拖动缩放轴的哪个部分。

- 1. 尝试拖动缩放轴的中心。当你向上或向下拖动时，你会看到对象均匀地变大或变小。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_53_0.png)

- 2. 这次将鼠标放在缩放轴的一个边缘上。当你拖过一个平面柄时，你正在同时进行两个方向的非均匀缩放。仔细观察缩放轴，你可以看到标记的轴。尝试在 `YZ` 平面上对盒子进行非均匀缩放。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_53_1.png)

- 3. 使用缩放变换轴可以执行的最后一种操作是单方向的非均匀缩放。要实现此操作，将鼠标直接悬放在轴末端的轴柄上。例如，将鼠标悬放在 `Y` 轴末端的绿色圆点上，并拖动以仅在该方向上缩放。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_54_0.png)

一旦你掌握了新变换轴的机制，你会发现与 `VIZ` 的早期版本相比，你对对象有了更精确、更直观的控制。

### 复制对象

你已经涵盖了在透视视图中移动、旋转和缩放对象的所有方法。如果你想复制对象，可以使用与移动、旋转或缩放对象相同的方法——只需额外按住 `Shift` 键。尝试以下步骤来查看复制（在 `VIZ` 中称为克隆 `cloning`）是如何工作的。（复制是更通用的克隆功能功能的一种形式。）

- 1. 从文件（`File`）菜单中选择打开（`Open`）。出现打开文件对话框。导航到 `Syex` 网站上的第 1 章文件。选择 `Chair.max` 文件，然后点击打开（`Open`）按钮。
- 2. 点击主工具栏上的选择对象（`Select Object`）按钮，然后选择椅子。
- 3. 点击选择并移动（`Select and Move`）按钮。
- 4. 按住 `Shift` 键，将椅子向左拖动。出现第二把椅子。
- 5. Release 鼠标按钮。显示克隆选项（`Clone Options`）对话框。此对话框允许你控制创建副本的数量和类型，以及新对象的名称。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_54_1.png)

- 6. 在克隆选项对话框的对象（`Object`）组中，选择复制（`Copy`）。
- 7. 点击确定（`OK`）。新椅子被添加到你的模型中。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_54_2.png)

# 在原对象的相同位置创建副本

你可能会遇到想要在与原始对象完全相同的位置创建对象副本的情况。要实现这一点，首先选择想要复制的对象，然后从菜单栏选择编辑（`Edit`） ➤ 克隆（`Clone`），或者在键盘上按 `Ctrl+V`。你会看到一个与上一个练习中类似的克隆选项对话框。选择你的选项并点击确定。注意，新副本最初不会出现，因为它占据了与原始相同的空间。你可以通过使用选择并移动工具对对象进行 `Shift`-点击，或者通过右键点击对象访问变换菜单并选择克隆（`Clone`）来完成。
