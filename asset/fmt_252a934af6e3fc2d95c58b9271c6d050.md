
# 丝囊菌类

与其他无性型真菌类群一样，丝囊菌类也是一个人为的类群，几乎完全由具有子囊菌亲和性的无性型真菌组成。大多数是已知的子囊菌无性型，尽管一些具有担子菌的亲缘关系。其中一些是水生或气-水两栖的。分类单元被称为型属和型种，因为缺乏有性或完全型 (teleomorph) 状态，迫使分类和鉴定采用人为而非系统发生学的方法。该类群的一个统一特征是产生分生孢子，分生孢子梗细胞是从分化的营养菌丝或细胞（非担子菌型）单独产生，或者是结合在分生孢子梗上，这些分生孢子梗可能完全分离，或者聚集在垫状孢子座或柄状座果体 (synnemata) 中。分生孢子梗细胞和分生孢子梗的插入方式和排列传统的上被用来区分三个目。在丝囊菌目 (Hyphomycetales) 中，它们是单生的或至多呈束状和簇状；在团囊菌目 (Tuberculariales) 中，它们产生在垫状至扁平的分生孢子（孢子座）的外表面；在柄囊菌目 (Stillediales) 中，它们连接成具柄的分生孢子（座果体）。一种替代的丝囊菌分类方法基于分生孢子产生方式以及分生孢子梗细胞在分生孢子形成前、中和后的生长方式上的差异。参见 `ASCOMYCOTA`、`BASIDIOMYCOTA`、`COELOMYCETES`。

用肉眼观察，丝囊菌菌落在基物上表现为显眼的黑色、棕色、绿色、灰色和白色生长物。在大小上，丝囊菌分生孢子从微小到极长或极宽不等。形状在属内和属间变化显著。许多丝囊菌在胶状基质中产生分生孢子。与腔囊菌类似，基质在环境压力期间抑制或延缓发芽。其他属在非常轻盈的团块中产生分生孢子，这类丝囊菌分生孢子更适合空气传播。在分生孢子梗或分生孢子座中常见简单的或分枝的刚毛等耐久元素，由于它们在落叶层真菌中特别常见，被认为是一种防御捕食者的形式。

丝囊菌从活体或死亡生物中获取营养，许多适应于在广泛的生态环境中生长、繁殖和生存。它们也可以是耐胁迫或竞争性的。一些物种生长在垃圾中，由于其薄壁的透明营养和生殖结构更容易受到攻击和腐烂，它们是短暂的。它们定植、分解和利用基物以及与其它生物相互作用或寄生的能力，是它们产生的酶、抗生素、毒素和其他代谢产物，加上广泛的生态多样性的结果。它们在各种类型的土壤、落叶层以及天然和制造的人工有机碎屑中极其常见。它们还可能导致食物腐败的严重问题，并出现在咸水、停滞水和小水中。(B.C.S.)

一些丝囊菌被发现于或与真菌（包括致病菌，如 `Verticillium`、`Mycogone` 和 `Cladosporium`）以及地衣有关。几个在医学上具有重要意义，与表面、皮肤、皮下和系统性感染有关。它们往往是机会性病原体，在免疫功能受损的患者中引起感染。许多丝囊菌形成有毒代谢物，即真菌毒素，尤其是 `Aspergillus`、`Fusarium` 和 `Penicillium`。其他的是线虫食性的，食肉性的，消耗线虫和其他微型动物。例如，`Beauveria`、`Metarhizium`、`Hirsutella` 和 `Entomophthora` 已被用于昆虫控制。许多也导致所有类型维管植物上具有重要经济价值的病害，特别是农业和林业作物。丝囊菌是植物和杂草的主要病原体，引起腐烂、茎腐和叶腐病；病害；溃疡；萎蔫；和枯萎。通过感染或污染种子，它们可以随种子传播缺陷或降低种子活力。参见 `MEDICAL MYCOLOGY`、`MYCOTOXIN`、`PLANT PATHOLOGY`。

丝囊菌产生多种主要和次要代谢物，并有能力引起许多不同的化学和生物化学变化。通过利用这种能力在工业过程中，可以生产和储存有机酸、酶、抗生素、生长物质、酒精和许多其他产品，并发生转化。参见 `DEUTEROMYCOTA`；`FUNGI`。(B.C.S.)

## 藓类 (Hypnales)

藓类是真藓 (subclass Bryidae) 中的一个目。也被称为 Hypnophyllales，这个目由 14 个科和大约 135 个属组成，主要将它们归为一类是因为它们共享下唇边 (hyponoid peristome)。各科在孢子体结构上表现出相当大的统一性；配子体结构决定了科成员资格。

藓类通常被称为皮藓，因其自由分枝的茎，侧枝规则或不规则地排成两行。植物形成垫状，特别是在林地中。叶片最常见的是急尖或渐尖，中肋通常较短或双肋。锯齿或圆齿边缘大多缺乏。孢子体侧生，具有延长的、光滑的蒴柄，蒴果通常倾斜且不对称，具有发达的双边蒴齿。参见 `BRYIDA`、`BRYOPHYTA`、`BRYOPSIDA`。(H.C.L.)

## 催眠术 (Hypnosis)

一种假设的意识改变状态，处于该状态的个体通常比在正常状态下对暗示更敏感。在此背景下，暗示被理解为一种想法或携带想法的交流，它能引发一种不受高级批判能力（即自愿装置）中介的隐秘或公开的反应。

从生理学上无法将催眠状态与个体的正常清醒状态区分开来，因此它的

催眠的存在已受到一些研究者的质疑。实际上，与催眠状态相关的独特现象很少，如果有的话，也极为罕见。大多数现象都是由建议（暗示）直接或间接产生的。通过对受催眠者的建议，可以引起记忆、感知、感觉、情绪、情感、态度、信念和肌肉状态的变化。这些变化可以且通常会被整合到个体的复杂行为中，从而导致遗忘症、错构症、类似失忆的状态、瘫痪、感觉功能丧失、注意力变化、人格改变、幻觉和妄想行为，甚至生理变化。有时候也可能增强记忆力。尽管有时效果显著，但对大多数人而言，通过催眠产生的效果远不如大众普遍认为的那么惊人。

[A.M.W.]

## 皮层下（植物）

植物皮层的最外层细胞层，也称为外皮层。在许多（但并非所有）植物中，它形成表皮下方明显的一层。与内皮层一样，它发育出凯氏带、亚油素沉积物以及浸渍有酚类或醌类物质的纤维素沉积物。皮层下组织可能产生作为病原菌进入屏障的物质，并且在一些植物中，它可能参与水分吸收和进入植物离子的选择。参见 皮层（植物）；内皮层。

## 次卤酸

卤素（氟（F）、氯（Cl）、溴（Br）、碘（I）或砹（At））含氧酸，具有通用化学公式 `HOX`，其中 X 是卤素原子。次卤酸的化学行为与较重的卤代含氧酸（作为一组表现出相似性质）截然不同。这些差异主要归因于氟原子的高电负性和小尺寸，这使得 `HOF`（次氟酸）成为极强的氧化剂，且 O-F 键异常弱。因此，该分子具有高反应性和相对不稳定性。（气态 `HOF` 在室温下分解为 `HF` 和 `O₂`，半衰期约为 1 小时，液态时则有爆炸倾向。）由于 `HOF` 中电负性最强的元素是氟，而其他卤素原子的电负性小于氧，因此 `HOF` 与较重的同系物中 O-X 键的极性相反。因此，`HOF` 主要起氧化和羟基化试剂的作用，而其他次卤酸则是电正性卤化试剂。例如，`HOF` 将芳香族化合物羟基化生成酚，并与水瞬时反应生成过氧化氢（`H₂O₂`），而次氯酸（`HOCl`）则将芳香族化合物氯化，且对水无反应。参见 砹；卤素元素。

次氯酸、次溴酸和次碘酸的溶液通过相应卤素的歧化反应生成，如下列反应所示。

`X₂ + H₂O ⇌ H⁺ + X⁻ + HOX`

次卤酸是弱酸，即 `HOX ⇌ H⁺ + OX⁻`，其解离常数按 `HOCl < HOBr < HOI` 的顺序增加。相对酸强度的结果是复杂混合速率不同，并按 `X = Cl⁻ < Br⁻ < I⁻` 的顺序增加。次卤酸溶液（例如商业漂白剂）在室温及以下可稳定数月，但在高温下分解；次溴酸溶液仅在低温下稳定；而次碘酸通常在其形成后几分钟内衰变。

`HOCl` 和 `HOBr` 是强氧化剂，能迅速与广泛的有机和无机还原剂反应。此外，这两种酸都能卤化芳香族化合物，与不饱和有机化合物形成卤代水合物，并与含氮碱形成 N-氯化合物。通常，`HOCl` 比 `OCl⁻` 反应更快。

`HOCl` 和 `HOBr` 是强细胞毒素。次氯酸盐在二十世纪初开始被用作消毒剂，随后广泛应用于公共卫生问题。针对细菌的最新研究表明，死亡伴随着与质膜相关的代谢功能紊乱，包括腺苷三磷酸合成酶失活和参与代谢物主动转运的蛋白质，以及（在厌氧菌中）呼吸作用的抑制。这种反应模式表明，毒性源于细胞能量转换能力的破坏。

[J.K.Hu.]

## 低体温

（人体）内部温度低于 98.6°F（37°C）至少 3.6°F（2.0°C）的状态。低体温代表了一系列随寒冷对生理系统严重程度而异的连续效应。人体需要特定的内部温度，并且需要每分钟进行调节以维持所有正常身体功能。维持内部温度恒定的许多生理和行为过程被称为体温调节。参见 体温调节。

各种环境状况容易使人患低体温症，即使在没有寒冷的情况下也可能发生。事实上，低体温症在温带地区比在更冷的气候中更常见。由于低体温症发生情境的独特性，低体温症被分为各种类型，所有这些类型都可能是致命的。

### 原发性低体温症

原发性低体温症是指因环境因素导致内部温度下降，此时身体的生理过程正常，但体温调节能力被环境压力压倒。

空气（ formerly 暴露）低体温症被认为是最常见的形式。暴露在冷空气中的人经历与处于冷水中的人相同的过程，但空气低体温症发生得较慢。空气低体温症的诱导更微妙，因此更具危险性，因为它可能在数周内发生。个人对冷空气压力的反应程度取决于年龄、体力耐力、冷压力的强度以及体温调节系统的响应能力等因素。确定某人是否患有低体温症的最简便方法之一是监测个性变化。易怒、疲劳、言语迟钝和混乱很常见，在某些情况下，行为类似于醉酒。
