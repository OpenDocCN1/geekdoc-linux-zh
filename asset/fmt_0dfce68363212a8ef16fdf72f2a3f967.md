## 23.1.6 DCOM

在本节中，我们将检查一种相当新的横向移动技术，该技术利用了分布式组件对象模型 (DCOM)¹¹⁵² 并学习如何将其用于横向移动。¹¹⁵³

微软组件对象模型 (COM)¹¹⁵⁴ 是一种用于创建相互交互软件程序的系统。虽然 COM 是为了同进程或跨进程交互而创建，但它被扩展为分布式组件对象模型 (DCOM)，用于网络上多台计算机之间的交互。

COM 和 DCOM 都是追溯到 Windows 最早版本的旧技术，¹¹⁵⁵ 与 DCOM 的交互通过 TCP 端口 135 RPC 执行，并且需要本地管理员权限来调用 DCOM 服务控制管理器，该管理器本质上是一个 API。

`Cyberdemond`¹¹⁵⁶ 是各种 DCOM 横向移动技术的集合，其中一种由 `Matt Nelson`¹¹⁵⁷ 发现，我们将在本节中介绍它。

发现的 DCOM 横向移动技术基于微软管理控制台 (MMC)¹¹⁵⁸ COM 应用程序，它用于 Windows 系统的脚本化自动化。

`MMC Application` 类允许创建应用程序对象，¹¹⁵⁹ 这些对象通过 `Document` ActiveX 属性暴露 `ExecuteCommand` 方法。正如名称所示，只要经过验证的用户具有权限（这是本地管理员的默认权限），该方法允许执行任何 shell 命令。

我们将以从已攻破的 Windows 11 `CLIENT` 主机登录的 `jen` 身份演示这种横向移动攻击。

从具有提升权限的 PowerShell 脚本，我们可以通过将 `FILES04` 的目标 IP 指定为 `GetTypeFromProgID` 方法的第二个参数，实例化远程 MMC 2.0。

```powershell
$dcom = [System.Activator]::CreateInstance([type]):GetTypeFromProgID("MMC20.Application.1","19.168.50.73")
```
