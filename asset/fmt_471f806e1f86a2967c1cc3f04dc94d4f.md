
`ping` 命令将持续 ping 目标，直到你按下 `CTRL-C` 取消命令。

该命令还有几个可以使用来更改其性能的选项。`-c` 选项告诉 `ping` 发送指定数量的数据包然后停止。例如，如果你只想 ping `192.168.1.2` 六次，可以使用此命令：

```
ping -c 6 192.168.1.2
```

注意，`ping` 命令并不总是奏效，即使远程目标具有活跃的网络连接。这是因为某些操作系统默认会阻止 ICMP 流量。然而，有足够的设备允许 ICMP 流量，这使得 PING 成为一个实用的诊断工具。

## 追踪路径

有时你的网络连接是激活的，但你却无法访问特定的目标。在这种情况下，`traceroute` 命令就变得很有用。`traceroute` 命令会映射从你的电脑到目的地的网络路由，并向路径中的每个设备发送 ICMP 数据包。你随后可以看到路径中哪些设备没有响应，并希望借此确定解决方案。例如，要追踪到 `10.10.11.254` 的路径，你可以这样使用 `traceroute`：

```
traceroute 10.10.11.254
```

输出结果类似于所示，每一行代表通往目的地的每一跳（hop，即链中的另一个设备）：

![](img/12fa978ca0d488232e696056d63d8bb6_45_0.png)

`traceroute` 命令默认运行三十跳。

# 第 6 章 启动与关机

## 概述

本章涵盖了用于启动和关机 Unix、Linux 和 BSD 系统的命令。它还提供了流行平台特定服务控制命令的概述。

- `shutdown`：关机系统。
- `poweroff`：关闭系统电源。
- `reboot`：重启系统。

- `telinit`：更改运行级别（runlevel）。

- `sysv-rc-conf`：显示并编辑 Linux 运行级别配置。

## 本节使用的术语表

**Init (INITialization，初始化)**
一个控制 Unix、Linux 和 BSD 系统启动（又初始化）的程序。

**Runlevel（运行级别）**
一组在系统启动期间（或由 init 命令调用时）加载的程序。

**Service（服务）**
一个提供 Web 服务器、DNS 服务器、电子邮件服务器等服务的系统程序。

## shutdown（关机）

**用途**：关机系统。

**语法**：`shutdown [OPTIONS] [TIME] [MESSAGE]`

```
# shutdown now

系统正在立即关机！
* 停止服务 [ OK ]
* 终止进程 [ OK ]

系统现在将停止。
```

`shutdown` 命令的输出

`shutdown` 命令用于关机本地系统。有几种不同的关机类型：halt、poweroff 和 reboot。

注意：`shutdown` 命令的用法在各种 Unix、Linux 和 BSD 平台之间有所不同。本页示例适用于 Linux 系统。

当执行 `shutdown` 命令时，会向所有登录系统的用户发送警告。可以在时间参数之后指定可选消息，如下例所示。

```
保存你的工作并退出！
```

`shutdown` 命令的广播消息

常用用法：

- `shutdown now`：立即关机。
- `shutdown [MIN]`：等待指定的分钟数后关机。
- `shutdown [HH:MM]`：在指定时间关机（24小时制）。
- `shutdown -r now`：重启系统。
- `shutdown -H now`：停止系统。
- `shutdown -P now`：关闭系统电源。
