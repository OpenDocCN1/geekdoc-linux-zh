
Unix 文件按层次结构排列，类似于 DOS 文件的存储方式。路径名是在目录树中移动的工具。目录树以 `/` 开始（称为根目录）。

如果我想绝对引用 `c123456` 子目录下的一个文件，它看起来像这样：

```
/home/c123456/files/assign1.c
```

总路径长度不能超过 1024 个字符。

你的主目录将是：`/home/userid`。如果你是用户 ID `c123456`，那么你的主目录将是：`/home/c123456`。

|  |  |
|---|---|
|  | 当前目录。 |
| `..` | 当前目录的上级目录。 |
| `-c987654` | 用户 ID `c987654` 的主目录 |
| `~` | 你自己的主目录。 |

# 目录管理和文件管理

| `cat files` | 合并：将文件复制到标准输出：合并输出为一个文件。 |
| `cd directory` | 切换工作目录。 |
| `chgrp group files` | 更改文件的组 ID。 |
| `chmod wholelevel files` | 更改文件的模式：设置安全访问。 |
|  | 权限可以是： |
| `u` | 用户 |
| `g` | 组 |
| `a` | 所有 |
|  | 符号可以是： |
| `+` | 添加此权限级别。 |
| `-` | 移除此权限级别。 |
| `x` | 文件的可执行权限，目录的可搜索权限 |
| `X` | 扩展执行权限（目录） |
| `r` | 读取权限 |
| `w` | 写入权限 |
| `cp infile outline` | 复制文件。另见 `mv` 和 `tar`。 |
| `cp [options] files directory` | 将多个文件复制到不同的目录。 |
| `-p` | 保留原始权限、日期。 |
| `-i` | 交互式确认是否覆盖旧文件。 |
| `-r` | 递归复制目录中的所有文件。 |
| `compress [filename]` | 压缩文件以节省空间。 |
| `uncompress [filename].Z` | 解压缩文件。 |
| `diff file1 file2` | 显示文件或目录之间的差异 |
| `-b` | 忽略空白符。 |
| `-c` | 显示更多内容。 |
| `df` | 显示磁盘可用空间总额。 |
| `du [files]` | 显示磁盘使用情况 [默认：当前目录下的所有目录] |
| `-s` | 显示每个文件的和。 |
| `find [start-directories] [characteristics]` | 搜索具有各种特征的文件。 |
| `-name **` | 查找名称中包含特定内容的文件。 |
| `-mtime +5` | 查找 5 天前修改的文件。 |
| `-mtime -5` | 查找 5 天内修改的文件。 |
| `-size +1024c` | 查找大于 1K 字节的文件。 |
| `-print` | 打印符合之前条件的完整文件名。 |
| `-ls` | 查找文件名和其他其他信息。 |
| `-exec rm {} \;` | 删除符合之前条件的文件。 |
| `flip [files]` | 转换回车符/换行符和其他格式。 |
| `-u` | 从 DOS 格式转换为 Unix 格式。 |
| `-m` | 从 Unix 格式转换为 MS-DOS 格式。 |
| `head [files]` | 显示文件的前几行。[默认：前 10 行] |
| `ln oldfile newfile` | 为文件创建别名。 |
| `ln -s filespec` | 符号链接：名称将指向 `filespec`。 |
| `ls [files]` | 列出目录中的所有文件。 |
| `-a` | 所有文件 [以 * 开头的普通文件不显示。] |
| `-l` | 详细格式。 |
| `-t` | 时间排序 - 最近的文件。 |
| `-R` | 递归查看目录。 |
| `mkdir [files]` | 创建目录。 |
| `more [files]` | 显示文件，当屏幕满时停止。[默认：标准输入。] |
| `mv oldfile newname` | 重命名或移动文件。如果新名称存在，则进行交互式确认。 |
| `pwd` | 打印工作目录。 |
| `rm files` | 删除文件。 |
| `-i` | 交互式确认每一个。 |
| `-r` | 递归删除目录内容。 |
| `rmdir` | 删除空目录。 |
| `tail [file]` | 显示文件的最后几行。[默认：最后 10 行。 |
| `tar [op] [file]` | 磁带存档和恢复。用于将整个目录结构卸载到一个简单文件中以便存储或发送。 |

```
15794 d rwx --- 2 student 512 Apr 1 16:03 mail/
```

| I-Node 用户 组  日期/时间 文件名 |
|---|---|---|---|---|

| I-Node | 磁盘位置。 |
| --- | 类型以及谁可以访问。 |
| Type | `d` 目录 |
| `l` 符号链接 |
| `-` 普通文件 |
| Access | `r` 读取权限 |
| `w` 写入权限 |
| `x` 文件执行或目录搜索 |
| Links | 文件的硬链接（同义词）数量。 |
| Group | 与文件相关的组。 |
| Size | 字节数。目录取 1024 的倍数。对于超过六个月的文件切换到年份。 |
| File Name | 后面可以附加： |
| `/` 目录 |
| `*` 可执行文件 |
