### `typeset [LRzfiltrt[n]] [name=value]...`

为 shell 变量和函数设置属性和值。在函数内部调用 `typeset` 时，会为变量名创建一个新实例。在函数完成时恢复变量的值和类型。你可以指定以下属性：

- `-H` 在非 UNIX 机器上提供 UNIX 到主机文件的映射。
- `-L` 左对齐并删除值开头的空格。如果 `n` 不为零，则定义字段的宽度；否则，通过赋值值的宽度来确定。当变量赋值时，它会在右侧填充空格，或在需要时进行截断以适应字段。如果同时设置了 `-Z` 选项，则会移除开头的 0。`-R` 选项会被关闭。
- `-R` 右对齐并用开头的空格填充。如果 `n` 不为零，则定义字段的宽度；否则，通过第一次赋值值的宽度来确定。如果变量被重新赋值，字段将在左侧填充空格，或从末尾进行截断。`-L` 选项会被关闭。
- `-Z` 如果非空字符是数字且你没有使用 `-L` 选项，则右对齐并在开头填充 0。如果 `n` 不为零，则定义字段的宽度；否则，通过第一次赋值值的宽度来确定。
- `-f` 名称指向函数名而非变量名。无法进行赋值，其他有效选项仅为 `-t`、`-u` 和 `-x`。

- `-i` 参数是一个整数。这可以加快算术运算。`n` 不为零时定义输出算术基数；否则，由第一次赋值决定输出基数。

使用 `+` 代替 `-` 可以关闭这些选项。如果你没有指定名称但指定了选项，则打印设置了这些选项的变量列表（以及可选的值）。（使用 `+` 代替 `-` 则可以不打印值）。如果你没有指定任何名称或给出了选项，则打印所有变量的名称和属性。

设置或显示资源限制。可用的资源列在下面。许多系统不包含其中一个或多个限制。当你为特定资源指定限制时，它会被设置。`limit` 的值在每个资源下可以是无限的（`unlimited`），或者值为 `unlimited`。`H` 和 `S` 选项指定设置该资源的硬限制还是软限制。一旦设置了硬限制，你就无法增加它。你可以将软限制增加到硬限制的值。如果你既没有指定 `H` 也没有指定 `S`，则限制适用于两者。省略 `limit` 时打印当前限制。在这种情况下，除非你指定了 `H`，否则打印软限制。当你指定了多个资源时，在值之前打印限制名称和单位。

## 错误

shell 检测到的错误（如语法错误）返回非零状态。否则，shell 返回最后一个命令的状态。对于非交互式 shell，不报告错误。

## 636 ksh, rksh

特殊内置命令或其他类型的命令遇到错误时，向标准错误写入诊断信息并如表所示退出。

| 错误 | 特殊内置命令 | 其他工具 |
|---|---|---|
| Shell 语言语法错误 | 退出 | 退出 |
| 工具语法错误（操作数） | 退出 | 不退出 |
| 重定向错误 | 退出 | 不退出 |
| 变量赋值错误 | 退出 | 不退出 |
| 扩展错误 | 退出 | 退出 |
| 未找到命令 | N/A | 可能退出 |
| 未找到点脚本 | 退出 | N/A |

扩展错误是在扩展时发生的（例如 `$(xy)`，因为 `!` 不是运算符）；如果实现在分词阶段就能检测到这些错误，可能会将其视为语法错误。
如果表中显示的任何错误在子 shell 中发生，子 shell 将以非零状态退出，但包含子 shell 的脚本不会因为该错误退出。
在表中所示的所有情况下，交互式 shell 都会向标准错误写入诊断信息而不退出。

注意
某些旧 shell 脚本包含 `^` 作为管道字符 `|` 的同词。内置命令 `.file` 在执行任何命令之前读取整个文件。因此，文件中的 `alias` 和 `unalias` 命令不适用于文件中定义的任何函数。
当 shell 执行一个尝试执行不存在的命令解释器的 shell 脚本时，shell 会返回一个 shell 文件不存在的错误诊断信息
