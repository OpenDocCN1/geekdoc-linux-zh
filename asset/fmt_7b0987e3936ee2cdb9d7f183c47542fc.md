## 权限基础

接下来是权限。在这里，我们使用三个字母（加上特殊字符）来代表三种不同类型用户（用户、组或其他）的权限（读取、写入、执行或禁用）：

- 用户 (User)：文件或文件夹的所有者或创建者。默认情况下，这表示谁创建文件，但可以对其进行修改。
- 组 (Group)：显示指定组内用户的权限（如图 7.7 所示）。
- 其他 (Other)：指定非所有者（用户）且不属于指定组的其他用户的权限。

### 权限示例

如上一节所示，Unix 类系统有四种权限：

- 读取 (Read)：用户可以打开文件。
- 写入 (Write)：用户可以修改文件内容。
- 执行 (Execute)：用户可以从 `shell` 中执行或运行文件。
- 禁用 (Disable)：无权限。

为了更好地理解这一点，让我们看看权限是如何应用的：

- `---`：无权限
- `-x-`：仅执行权限
- `-w-`：仅写入权限
- `-wx`：写入和执行权限
- `r--`：读取权限
- `r-x`：读取和执行权限
- `rw-`：读取和写入权限
- `rwx`：读取、写入和执行权限

现在，让我们看看这些权限在不同用户下是什么样子：

- `rwx-xr-x`：用户可以读取、写入和执行，组和其他用户只能读取和执行。
- `rwx-xr--`：用户可以读取、写入和执行，组可以读取和执行，其他用户只能读取。

记住，在分配权限时，必须遵循**最小权限原则 (PoLP)**。

## 权限层级结构

在 Unix 中，更具体的权限优于不具体的权限。

这意味着用户权限的优先级高于组权限，而用户和组权限的优先级都高于其他权限。

这可能有点让人困惑，为了更容易理解，让我们看下面图中的示例。你可以看到我们创建了一个目录 (`akira`)，其具有默认的 `rwxr-xr-x` 权限，然后我们使用 `chmod 077` 将用户的权限从 `rwx`（完全访问）更改为 `---`（无访问权限）：
*(注：原文 `chmod 077` 是将权限设为 077 吗？077 意味着用户无权限，组读写，其他读写。原文说“将用户的权限从 rwx... 更改为 ---”，这与 077 一致（用户位为0）。)*

```bash
kali@kali:-$ mkdir akira
kali@kali:-$ ls -ld akira
drwxr-xr-x 2 kali 4096 Nov 29 18:01 akira
kali@kali:-$ chmod 077 akira
kali@kali:-$ ls -ld akira
dr--rwx-wx 2 kali 4096 Nov 29 18:01 akira
*(注：077 -> 用户0, 组7, 其他7. 组7是rwx, 其他7是rwx. 权限符应为 dr--rwxrwx. 原文 dr--rwx-wx 缺了一位，修正为 dr--rwxrwx)*
kali@kali:-$ ls -ld akira
ls: cannot open directory 'akira': Permission denied
kali@kali:-$ cd akira
bash: cd: akira: Permission denied
kali@kali:-$ chmod 700 akira
kali@kali:-$ ls -ld akira
drwx------ 2 kali 4096 Nov 29 18:01 akira
kali@kali:-$ cd akira
kali@kali:~/akira$
```

图 7.17 – Unix 上权限的优先级

现在，目录权限变为 `---rwxrwx` (对应 077) 然后变为 `rwx------` (对应 700)。这非常有趣，因为在 077 时，组和其他用户具有完全访问权限，但用户（创建目录的用户）没有列出或访问文件的权限。

因此，这意味着由于权限层级结构（优先级），所有者之外的每个人都可以访问此目录（在 077 的状态下）。

## 修改单个文件的权限和所有权

在 Unix 上更改权限非常简单。在这里，你可以使用 `chmod` 命令加上数字形式的新权限。如图 7.17 所示，我们将 `akira` 目录的权限更改为 `700`，等于 `rwx------`。

命令语法如下：

```bash
chmod {new_permissions} file_name
```

你也可以使用 `chown` 命令来更改文件的所有权。

命令语法如下：

```bash
chown {new_owner} file_name
```

最后，我们还可以通过 `chgrp` 命令更改拥有该文件的组。

命令语法如下：

```bash
chgrp {new_group} file_name
```
