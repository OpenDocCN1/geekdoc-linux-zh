## 全局解释器锁 (GIL)

Python 解释器受一个锁的保护，即使在有多个处理器的情况下，一次也允许一个线程执行。这严重限制了线程在计算密集型程序中的实用性——事实上，使用线程会导致 CPU 密集型程序的运行性能比顺序执行工作更差。线程应该只保留给主要关注 I/O 或网络服务器的程序。对于计算密集型任务，考虑使用 C 扩展或 `multiprocessing` 模块。C 扩展具有释放解释器锁并并行运行的选择，前提是它们在锁释放时不与解释器交互。`multiprocessing` 模块通过变为独立的子进程来工作，不受锁的限制。

## 使用线程进行编程

尽管可以使用各种锁和同步原语的组合在 Python 中编写非常传统的多线程程序，但有一种优于其他所有类型的编程风格——那就是将多线程程序组织和管理为一组通过消息队列通信的独立线程。这将在下一节（`queue` 模块）中结合示例进行详细描述。

## queue, Queue

`queue` 模块（在 Python 2 中命名为 *Queue*）实现了各种生产者、多消费者队列，可以在多个执行线程之间安全地交换信息。

`queue` 模块定义了不同的队列类：

```python
Queue([maxsize])
```
创建一个 FIFO（先进先出）队列。`*maxsize*` 是可以放入队列的项数。如果省略 `*maxsize*` 或为 0，则队列大小为无限大。

```python
LifoQueue([maxsize])
```
创建一个 LIFO（后进先出）队列（也称为*栈*）

## PriorityQueue ([maxsize])

创建一个优先级队列，其中项按优先级从低到高排序。在使用此队列时，项应该是格式为 `(priority, data)` 的元组，其中 `priority` 是一个数字。

队列类的一个实例具有以下方法：

```python
q.size()
```
返回队列的大致大小。由于其他线程可能会更新队列，这并不完全可靠。

```python
q.empty()
```
如果队列为空则返回 True，否则返回 False。

```python
q.full()
```
如果队列已满则返回 True，否则返回 False。

```python
q.put(item, block [, timeout=])
```
将 `item` 放入队列。如果可选参数 `block` 为 True（默认值），调用者将阻塞直到有空位可用。否则 `block` 为 False，如果队列已满，将抛出 `Full` 异常。`timeout` 提供了一个可选的以秒为单位的超时值。如果发生超时，将抛出 `Full` 异常。

```python
q.put_nowait(item)
```
等于 `q.put(item, False)`。

```python
q.get([block [, timeout]])
```
从队列中移除并返回一个项。如果可选参数 `block` 为 True（默认值），调用者将阻塞直到有项可用。否则 `block` 为 False，如果队列为空，将抛出 `Empty` 异常。`timeout` 提供了一个可选的以秒为单位的超时值。如果发生超时，将抛出 `Empty` 异常。

```python
q.get_nowait()
```
等于 `get(0)`。

```python
q.task_done()
```
被 `deque` 数据的消费者使用，表示对某个项的处理已完成。如果使用了此方法，则应该对从队列中移除的每一个项调用它。

```python
q.join()
```
阻塞直到队列上的所有项都被移除并处理。一旦对放置在队列上的每个项都调用了 `q.task_done()`，该方法将返回。

## 协程与微线程

在某些应用程序中，可以使用调度器实现协作用户空间多线程。这有时被称为微线程，尽管该术语是在任务（greenlets）的背景下描述的。这种技术的常见用途是需要管理大量文件或套接字的程序。例如，一个想要同时管理 1000 个连接的网络服务器。与其创建 1000 个线程来这样做，不如结合调度器使用异步 I/O 或轮询（使用 `select` 模块）。

驱动这种协程编程技术的核心是：生成器或协程函数中的 `yield` 语句挂挂函数的执行，直到通过 `next()` 或 `send()` 操作恢复。这使得可以使用调度器循环对生成器函数进行协作多任务处理。这里有一个说明该思想的示例：

```python
def foo():
    for n in range(5):
        print("I'm foo %d" % n)
        yield
```

```python
def bar():
    for n in range(10):
        print("I'm bar %d" % n)
        yield
```

```python
def spam():

```
