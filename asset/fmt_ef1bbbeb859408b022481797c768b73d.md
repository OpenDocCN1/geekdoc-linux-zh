
- **情况 1.** 某个颜色出现在列表 `L(v_1)`、`L(v_2)`、`L(v_3)` 中的两个或更多，或者出现在列表 `L(v_4)`、`L(v_5)`、`L(v_6)` 中的两个或更多，例如颜色 `a` 出现在 `L(v_1)` 和 `L(v_2)` 中。则将颜色 `a` 分配给 `v_1` 和 `v_2`，并将 `L(v_5)` 中的任意颜色分配给 `v_5`。然后对于 `v_i`（`i = 4, 5, 6`）在 `L(v_i)` 中有可用颜色。（注：此处原文逻辑似乎有误，分配 `v_5` 后，`v_4, v_6` 的约束未完全阐述，但遵循原文翻译）

- **情况 2.** 列表 `L(v_1)`、`L(v_2)`、`L(v_3)` 两两不相交，且列表 `L(v_4)`、`L(v_5)`、`L(v_6)` 也两两不相交。设 `a_1 ∈ L(v_1)` 且 `a_2 ∈ L(v_2)`。如果列表 `L(v_4)`、`L(v_5)`、`L(v_6)` 中没有同时包含 `a_1` 和 `a_2` 的，那么设 `a_3` 为 `L(v_3)` 中的任意颜色。然后对于 `v_4`、`v_5`、`v_6` 中的每一个都有可用颜色，以构造 `K_{3,3}` 的正规着色。如果列表 `L(v_4)`、`L(v_5)`、`L(v_6)` 中恰好有一个同时包含 `a_1` 和 `a_2`，那么选择一个颜色 `a_3 ∈ L(v_3)`，使得 `L(v_4)`、`L(v_5)`、`L(v_6)` 中的任何一个都不包含 `a_1`、`a_2`、`a_3` 的全部。通过给 `v_3` 分配颜色 `a_3`，我们看到对于 `v_4`、`v_5` 和 `v_6` 中的每一个都有可用颜色。

因此，如前所述，`χ_ℓ(K_{3,3}) ≤ 3`。事实上，我们证明 `χ_ℓ(K_{3,3}) = 3`。考虑如图 15.10(b) 所示的集合 `L(v_i)`，`1 ≤ i ≤ 6`。不失一般性，假设 `v_1` 被着色为 1。那么 `v_4` 必须被着色为 2，且 `v_5` 必须被着色为 3。无论 `v_3` 选择什么颜色，其颜色都与 `v_4` 或 `v_5` 的颜色相同。这产生了一个矛盾。因此，`K_{3,3}` 不是 2-可选的，所以 `χ_ℓ(K_{3,3}) = 3`。图 `G = K_{3,3}` 表明 `χ(G) > χ_ℓ(G)` 是可能的。事实上，`χ_ℓ(G)` 可以远大于 `χ(G)`。

### 定理 15.18

如果 `r` 和 `k` 是满足 `r ≥ {2k-1 \choose k}` 的正整数，则

$$\chi_\ell(K_{r,r}) \ge k + 1.$$

## 15.3. 列表着色

![](img/598a6ae3fd44120830ada34717906f29_421_0.png)

图 15.10: 图 `K_{3,3}` 是 3-可选择的

**证明。** 反设 `χ_l(K_{r,r}) ≤ k`。则 `K_{r,r}` 是 `k`-可选择的。设 `U` 和 `W` 是 `K_{r,r}` 的 partite 集合，其中

`U = {u_1, u_2, …, u_r}` 且 `W = {w_1, w_2, …, w_r}`。

设 `S = {1, 2, …, 2k - 1}`。`S` 有 `\binom{2k-1}{k}` 个不同的 `k`-元素子集。将这些颜色列表分配给 `U` 中的 `\binom{2k-1}{k}` 个顶点和 `W` 中的 `\binom{2k-1}{k}` 个顶点。`U` 和 `W` 中剩余的顶点分配 `S` 的任意 `k`-元素子集。对于 `i = 1, 2, …, r`，选择一个颜色 `a_i ∈ L(u_i)`，并设 `T = {a_i: 1 ≤ i ≤ r}`。我们考虑两种情况。

*情况 1。* `|T| ≤ k-1`。那么存在 `S` 的一个 `k`-元素子集 `S'` 与 `T` 不相交。然而，对于某个满足 `1 ≤ j ≤ r` 的 `j`，有 `L(w_j) = S'`。这是矛盾的。

*情况 2。* `|T| ≥ k`。因此，存在 `T` 的一个 `k`-元素子集 `T'`。从而，对于某个满足 `1 ≤ j ≤ r` 的 `j`，有 `L(w_j) = T'`。无论从 `L(w_j)` 中分配哪个颜色给 `w_j`，该颜色已分配给某个顶点 `u_i`。因此，`u_i` 和 `w_j` 被分配了相同的颜色，且 `u_i w_j` 是 `K_{r,r}` 的一条边。这是矛盾的。$\blacksquare$

对于满足 `r ≥ \binom{2k-1}{k}` 的正整数 `r` 和 `k`，定理 15.18 提供了 `χ_l(K_{r,r})` 的下界，其中 `r` 相对于 `k` 足够大。以下 Noga Alon [3] 1992 年的结果给出了对于所有 `r ≥ 3` 的 `χ_l(K_{r,r})` 的上界。

**定理 15.19** 对于每个整数 `r ≥ 3`，

`χ_l(K_{r,r}) ≤ \left\lceil 2 \log_2 r \right\rceil`。

定理 15.19 将在第 21 章中再次讨论，并给出证明。
