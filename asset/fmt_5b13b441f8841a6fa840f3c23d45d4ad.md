当与 X 服务器的最后一个连接关闭时，会发生额外的处理。X 服务器会在“无连接”和“有连接”的状态之间循环。当由于 `close_mode` 为 `DestroyAll` 的连接关闭导致与 X 服务器的最后一个连接关闭时，X 服务器将执行以下操作：

- 将状态重置为刚启动时的状态。X 服务器首先销毁在 `RetainPermanent` 或 `Temporary` 模式下终止的客户端的所有残留资源。
- 删除所有预定义的原子（atom）标识符。
- 删除根窗口（第 4.3 节）上的所有属性。
- 重置所有设备映射和属性（例如：键击、铃音量和加速度）以及访问控制列表。
- 恢复标准的根瓦（tiles）和光标。
- 恢复默认字体路径。
- 将输入焦点恢复到 `PointerRoot` 状态。

然而，如果你使用设置了 `RetainPermanent` 或 `RetainTemporary` 的关闭模式关闭连接，则 X 服务器将不会进行重置。

# 在多线程中使用 Xlib

在支持线程的系统中，可能会提供支持以允许多个线程并发使用 Xlib。

要为并发线程进行初始化，请使用 `XInitThreads()`。

```
Status XInitThreads();
```

`XInitThreads` 函数用于初始化 Xlib 对并发线程的支持。此函数必须是多线程调用的第一个 Xlib 函数，并且在调用任何其他 Xlib 函数之前完成。如果初始化成功，该函数返回非零状态；否则返回 0。在不支持线程的系统中，此函数始终返回 0。

只有当多个线程可能并发使用 Xlib 时，才有必要调用此函数。如果所有对 Xlib 函数的调用都受到其他访问机制的保护（例如，工具包中的互斥锁或通过显式客户端编程），则不需要 Xlib 线程初始化。建议单线程程序不要调用此函数。

要跨多个 Xlib 调用锁定显示器，请使用 `XLockDisplay`。

```
XLockDisplay(display);
```

指定到 X 服务器的连接。

`display`

`XLockDisplay` 函数锁定所有使用指定显示器的线程。其他尝试使用该显示器的线程将阻塞，直到通过此操作解锁该显示器。对 `XLockDisplay` 的嵌套调用可以正常工作；在调用 `XUnlockDisplay` 的次数与 `XLockDisplay` 相同之前，显示器不会被解锁。除非使用 `XThreads` 成功初始化了 Xlib，否则此函数不起作用。

要解锁显示器，请使用 `XUnlockDisplay`。

```
XUnlockDisplay(display);
```

指定到 X 服务器的连接。

`display`

`XUnlockDisplay` 函数允许其他线程再次使用指定的显示器。任何在显示器上阻塞的线程都被允许继续。嵌套锁工作正常；如果一个线程多次调用了 `XLockDisplay`，那么在显示器实际解锁之前，必须调用相同次数的 `XUnlockDisplay`。除非使用 `XThreads` 为线程成功初始化了 Xlib，否则此函数不起作用。

# 内部连接

除了连接到 X 服务器外，Xlib 实现可能还需要连接到其他类型的服务器（例如，第 13 节描述的输入方法服务器）。使用多个显示器或将显示器与其他显示器结合使用的工具包和客户端需要阻塞直到输入可用，并在输入可用时处理该输入。使用单个显示器并在 Xlib 事件函数中阻塞等待输入的简单客户端不需要使用这些功能。

要跟踪显示器的连接情况，请使用 `XConnectionWatch`。

```
typedef void (*XConnectionWatchProc)(display, client_data, fd, opening, watch_data);
```

```
Status XConnectionWatch(display, procedure, client_data);
```

`display`

指定到 X 服务器的连接。

`procedure`

指定要调用的过程。

`client_data`

指定额外的客户端数据数据。

`XAddConnectionWatch` 注册一个过程，每当 Xlib 打开或关闭指定显示器的内部连接时都会调用该过程。该过程接收显示器、客户端数据、连接的文件描述符、一个指示连接正在打开还是关闭的布尔值，以及指向私有数据位置的指针。如果 `opening` 为 `True`，该过程可以在 `watch data` 指向的位置存储指向私有数据的指针；当稍后为同一连接调用该过程且 `opening` 为 `False` 时，由 `watch data` 指向的过程将持有相同的私有数据指针。

在显示器打开后的任何时间都可以调用此函数。如果已存在内部连接，则在 `XAddConnectionWatch` 返回之前，会立即为每个现有连接调用注册的过程。如果过程注册成功，`XAddConnectionWatch` 返回非零状态；否则返回 0。

注册的过程不应调用任何 Xlib 函数。如果过程直接或间接地导致内部连接或过程的状态发生变化，则结果未定义。除非使用 `XThreads` 成功初始化了 Xlib，否则此函数不起作用。

要解锁显示器，请使用 `XUnlockDisplay`。

```
XUnlockDisplay(display);
```
