# 根（数学）

根（数学）。如果函数 `$f(x)$` 在 `$x$` 处的值为0，则 `$a$` 是 `$f(x)$` 的一个根。代数基本定理指出，任何形式为 `$ax^n + a_{n-1}x^{n-1} + ... + a_1x + a_0 = 0$` 的代数方程（其中 `$a_i$` 为实数）都有根。由此得出，这类方程具有实根或复根，其数量等于方程次数。

此外，如果 `$a = (b + ic)$` 是方程的一个复数根，那么它的共轭根 `$b - ic$` 也是一个根。这是因为根可以表示为系数的有理函数，涉及加法、乘法、幂和除法等基本运算。

阿贝尔（Abel）和伽罗瓦（Galais）证明了无法通过代数法求解次数大于四的通用代数方程。然而，可以找到任意次数代数方程的实根。

特殊情况：方程，代数分析理论。

## 均方根

一组数算术平均值的平方根称为它们的均方根。如果这些数字为 `$x_1, x_2, ..., x_n$`，则均方根等于：

$$\sqrt{\frac{x_1^2 + x_2^2 + ... + x_n^2}{n}}$$

它是幅值的平均值，不受数值正负号的影响。在均方根的应用中，最重要的是算术平均值的标准差。如果 `$X$` 是

$$\frac{x_1 + x_2 + ... + x_n}{n}$$

那么标准差就是偏离平均值值的均方根。参见：统计学。

$$\sqrt{\frac{(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + ... + (x_n - \bar{x})^2}{n}}$$

因此，标准差是离散值的均方根。

## 迷迭香

Officinalis，该科成员，用作芳香草和观赏。它可以生长多年，并在各种条件下生存。`$R. officinalis$` 是一个品种。大多数品种适用于烹饪，尽管某些品种（如松香）含有高水平的萜类和类似松节的味道。
