
`=` 字符用作转义字符。当后面跟着两个十六进制数字时，它表示具有该值的字符（例如，`'=0C'`）。等号表示为 `'=3D'`。如果 `=` 出现在行尾，它表示软换行（soft break）。这只在长输入行必须拆分为多个输出行时才会发生。

空格和制表符原样保留，但可能出现在行尾。

## xml.dom.minidom

`xml.dom.minidom` 模块为解析 XML 文档提供基本支持，并根据 DOM 规范将其作为树结构存储在内存中。有两个解析函数：

## 节点 (Nodes)

由解析函数返回的文档由一组连接在一起的节点组成。每个节点都有以下属性，这些属性可以提取信息并在树形结构中进行导航：

| 节点属性 | 说明 |
| --- | --- |
| `n.attributes` | 存储属性值（如果有）的映射对象。 |
| `n.childNodes` | `n` 的所有子节点的列表。 |
| `n.firstChild` | `n` 的第一个子节点。 |
| `n.lastChild` | `n` 的最后一个子节点。 |
| `n.localName` | 元素的本地标签。如果标签中出现冒号（例如 'foo:bar ...'），则只包含冒号后的部分。 |
| `n.namespaceURI` | `n` 的命名空间（如果有）。 |
| `n.nextSibling` | 树中出现在 `n` 之后且具有相同父节点的节点。如果 `n` 是最后一个兄弟节点，则为 `None`。 |
| `n.Name` | 节点的名称。 |
| `n.type` | 描述节点类型的整数。它被设置为以下来自 `Node` 类的类变量之一：`ATTRIBUTE_NODE`, `CDATA_SECTION_NODE`, `COMMENT_NODE`, `DOCUMENT_FRAGMENT_NODE`, `DOCUMENT_NODE`, `DOCUMENT_TYPE_NODE`, `ELEMENT_NODE`, `ENTITY_NODE`, `ENTITY_REFERENCE_NODE`, `NOTATION_NODE`, `PROCESSING_INSTRUCTION_NODE` 或 `TEXT_NODE`。 |
| `n.value` | 节点的值。取决于节点类型。 |
| `n.parentNode` | 指父节点的引用。 |
| `n.prefix` | 标签中出现在冒号之前的部分。例如，元素 '<foo:bar ...>' 的前缀为 'foo'。 |
| `n.previousSibling` | 树中出现在 `n` 之前且具有相同父节点的节点。 |

除了这些属性外，所有节点都有以下方法。通常，这些方法用于操作树结构。

`n.appendChild(child)`

将新节点 `child` 添加到 `n` 中。新子节点被添加到任何其他子节点的末尾。

`n.cloneNode(deep)`

制作节点 `n` 的副本。如果 `deep` 为 `True`，则所有子节点也会被复制。

`n.hasAttributes()`

如果节点具有任何属性，则返回 `True`。

`n.hasNodes()`

如果节点具有任何子节点，则返回 `True`。（注：通常为 `hasChildren`）。

`n.insertBefore(newchild, ichild)`

在另一个子节点 `ichild` 之前插入新子节点 `newchild`。`ichild` 必须是 `n` 的子节点。

`n.isSameNode(other)`

如果节点 `other` 指向与 `n` 相同的 DOM 节点，返回 `True`。

`n.normalize()`

将相邻的文本节点合并为一个文本节点。

`n.removeChild(child)`

从 `n` 中移除子节点 `child`。

`n.replaceChild(newchild, oldchild)`

用 `newchild` 替换子节点 `oldchild`。`oldchild` 必须是 `n` 的子节点。虽然树中出现了许多类型的节点，但最常见的是处理 `Document`、`Element` 和 `Text` 节点。每个节点都有简要描述。

### 文档节点 (Document Nodes)

节点 `d` 出现在整个文档树的顶部，代表整个文档。它有以下方法和属性：

`d.documentElement`

包含整个文档的根元素。

`d.getElementsByTagName(tagname)`

搜索所有子节点并返回具有给定标签 `tagname` 的元素列表。

`d.getElementsByTagNameNS(namespaceURI, localname)`

搜索所有子节点并返回具有给定命名空间 URI 和本地名称的元素列表。返回列表是 `NodeList` 类型的对象。

### 元素节点 (Element Nodes)

元素节点 `e` 代表单个 XML 元素，如 '<foo>...</foo>'。要从元素获取文本，你需要寻找作为子节点的 `Text` 节点。定义了以下属性和方法来获取其他信息：

- `e.tagName`

元素的标签名。例如，如果元素是由 '<foo ...>' 定义的，名称为 'foo'。

- `e.getElementsByTagName(tagname)`

返回所有具有给定名称的子节点列表。

- `e.getElementsByTagNameNS(namespaceuri, localname)`

返回命名空间中具有给定标签名的子节点列表。`namespaceuri` 和 `localname` 是指定命名空间和标签名的字符串。如果使用声明 '<foo xmlns:foo=http://www.spam.com/foo>' 声明了命名空间，则 `namespaceuri` 被设置为 'http://www.spam.com/foo'。如果搜索后续元素 '<foo:bar>'，`localname` 被设置为 'bar'。返回的对象类型为 `NodeList`。

- `e.hasAttribute(name)`

如果元素具有名为 `name` 的属性，返回 `True`。

- `e.hasAttributeNS(namespaceURI, localname)`

如果元素在命名空间中具有名为 `name` 的属性，返回 `True`。

- `e.getAttribute(name)`

获取属性的值。返回值为字符串。如果属性不存在，则返回空字符串。

- `e.getAttributeNS(namespaceURI, localname)`

获取命名空间中属性的值。返回值为字符串。如果属性不存在，则返回空字符串。

### 文本节点 (Text Nodes)

文本节点用于表示文本数据。`Text` 存储在 `t.data` 属性中。

## 工具函数

在节点上定义了以下工具方法。不是 DOM 标准的一部分，但是 Python 为了方便调试而提供的。

```
n.toJSON([indent, newline])
```

创建一个格式化良好的包含 `n` 及其子节点的字符串。`indent` 指定缩进，默认为 `'\t'`。`newline` 指定换行符，默认为 `'\n'`。

```
n.toxml([encoding])
```

创建一个包含 `n` 及其子节点的字符串。`encoding` 指定编码（例如 'utf-8'）。如果没有给出编码，则在输出中不指定。
