# 第 8 章 | 使用角色（Roles）简化 Playbook

根据角色中每个文件的用途进行命名，例如任务（`tasks`）和处理器（`handlers`）。文件和模板子目录包含在其他 YAML 文件中引用的文件。

以下命令显示了 `user.example` 角色的目录结构。

```
[user@host roles]$ tree user.example
```

```
user.example/

├── defaults
│   └── main.yml
├── handlers
│   └── main.yml
├── meta
│   └── main.yml
├── README.md
├── tasks
│   └── main.yml
├── templates
├── tests
│   ├── inventory
│   └── test.yml
└── vars
    └── main.yml
```
