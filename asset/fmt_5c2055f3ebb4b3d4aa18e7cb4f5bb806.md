# pdnsd

代理 DNS 服务器。`pdnsd` 是一个具有永久缓存的代理 dns 服务器（缓存内容会被写入硬盘），设计用于处理无法访问或已宕机的服务器（例如在拨号网络中）。`pdnsd` 可用于那些不进行查询的应用程序（例如在启动时），并可以配置为更改行为，以防止因 dns 查询停滞导致的几分钟的卡顿（甚至崩溃）。例如，某些 Unix 版本的 Netscape Navigator 就暴露了这种行为。

# pdq

用于工作站的简单打印系统。工作站安装的无队列打印系统，支持将打印作业发送到 BSD `lpr` 队列、通过 Applelet（使用 `netatalk`）或 TCP 连接，以及通过传真程序通过传真传输。它包含一个打印到基于 Novell NetWare 服务器的贡献接口。Linux Printing HOWTO 的维护者建议独立使用此系统，或作为 LPrng 的前端。主页：`http://pdq.sourceforge.net/`。来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
