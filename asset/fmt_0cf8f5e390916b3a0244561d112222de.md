## 我如何在 `/usr` 上运行 `fsck`？

每当你对文件系统运行 `fsck` 时，必须先卸载它。遗憾的是，你无法卸载 `/usr`，因为 `/bin` 是 `/usr/bin` 的符号链接。此外，`/etc/fsck` 是 `/usr/sbin/fsck` 的符号链接。

解决此问题的办法是从启动盘或维护磁盘启动进入维护模式。此时，你应该输入 `getrootfs hdisk0 sh` 而不是 `getrootfs hdisk0`。然后你可以运行 "`fsck /dev/hd2`”。

## 我如何在根文件系统上运行 `fsck`？

与 `/usr` 文件系统一样，你必须从维护或启动磁盘启动进入维护模式。然而，在提示符处，你必须输入 `/etc/continue hdisk0 exit`（如果 `hdisk0` 不相同，应替换为启动磁盘）。然后你可以运行 `fsck /dev/hd4`。

## 你能将软盘挂载为文件系统吗？

可以。但是，它只允许对磁盘进行读取访问。这是因为从 3.1.5 版本开始，AIX 无法在磁盘上创建日志记录，因为 IBM 仅打算将此策略用于只读数据的临时访问。

如果你构建了一个文件系统并将其挂载到软盘上，在用后以及系统备份过程中必须始终将其卸载，否则可能会出错。

要在软盘上创建文件系统：

1. 在另一个文件系统上创建一个子目录，并将所有打算放入该文件系统的文件放在那里。

2. 你必须创建一个原型文件，该文件将包含新文件系统的信息。

`proto /(directory) > (filename)`

3. 将格式化过的软盘插入驱动器，然后编辑原型文件，并将第一行更改为 `<noboot> 0 0`。

4. 输入以下命令在软盘上创建文件系统：

`mkfs -p (filename) -V jfs /dev/fd0`

5. 创建用于挂载基于软盘的文件系统的目录，通常称为 `/mnt`。要挂载文件系统：

`mount -r -V jfs /dev/fd0 /mnt`

6. 若要卸载文件系统，只需像往常一样使用 `umount` 命令即可。

`umount /dev/fd0`

这种方法几乎唯一的用途是你打算将其用于实用程序或其他保持静态的数据。遗憾的是，对该文件系统进行任何更改的唯一方法是将软盘中的目录复制到另一个目录，进行更改并使用前面的步骤重新创建文件系统。

## 我如何减小 `hd6` 上的默认分页空间大小？

要做到这一点，你应该遵循以下步骤：

1. 创建一个临时分页空间。

`mkps -s 20 -a rootvg`

2. 更改默认分页空间，使其在下次启动时不被使用。

`chps -a n hd6`

3. 编辑 `/etc/rc.boot`，将 `swapon /dev/hd6`（在 AIX 3.1 中，编辑 `/etc/rc.boot4` 文件）更改为 `swapon /dev/paging00`。

4. 你必须更新 3.1 启动逻辑卷的信息。

`bosboot -a for 3.2: bosboot -a -s hdisk0`

5. 现在你应该关闭并重启系统。

6. 当系统重新启动后，你应该移除当前的 `hd6` 并创建一个较小的。

`rmps hd6 mklv -y hd6 -t paging rootvg <paging space size in 4 blocks>`

7. 再次编辑 `/etc/rc.boot`（或 `/etc/rc.boot4`）文件，将 swapon 值改回。

`swapon /dev/hd6`

8. 你还需要再次更新启动逻辑卷。

`3.1: bosboot -a 3.2: bosboot -a -d hdisk0`

9. 现在你将当前的分页设备（`paging00`）更改为下次启动时的非活动状态。

`chps -a n /dev/paging00`

10. 最后，关闭并再次重启，并在启动后移除 `paging00`。

`rmps paging00`

你可以随时使用命令 `lsps -a` 显示你的分页空间。

## 如何为 AIX 3.2 制作启动磁盘？

这将要求你已经格式化了四块磁盘。要创建相应的磁盘，你必须执行以下操作：

1. 对于启动磁盘，运行 `bosboot -d /dev/fd0 -a`。

2. 对于显示磁盘，运行 `mkdispdskt`。

3. 对于显示扩展磁盘，运行 `mkextdskt`。

4. 对于安装/维护磁盘，运行 `mkinstdskt`。

## 是否可以将 FTP 访问信息记录到日志文件中？

你可以通过以下方法简单地实现：

1. 在 `/etc/syslog.conf` 中添加以下行。

`daemon.debug /tmp/daemon.log`

2. 创建日志文件并重启 `syslog` 守护进程。

`touch /tmp/daemon.log refresh -s`

3. 现在你必须通过 SMIT 修改 `inetd.conf`。使用 `smit inetd` 将添加 `-l` 和 `-d` 选项。现在所有来自 `ftpd` 和其他 `daemons` 的 syslog 消息将出现在 `/tmp/daemon.log` 中。

## 如何强制 `mksysb` 保留时间戳（timestamps）？

从 3.2.5 版本开始，`bosrest` 命令保留了时间戳和权限。`pax` 命令也会这样做。

在 AIX 3.2.2 中，`/usr/lpp/bosinst/bosnet`（网络安装）以及 `bosrest`、`pax c` 命令都带有可用选项 `-pmop`，其中 `m` 告诉它不要保留修改时间。你只需要将所有的 `-pmop` 选项更改为 `-pop` 并重新制作你的 `mksysb` 磁带。
