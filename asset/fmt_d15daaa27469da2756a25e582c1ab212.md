
用于轻松编写 Web 应用程序的库（稳定版）。该库将帮助你编写中大型数据驱动 Web 应用程序。“中大型应用”是指包含多个数据库查询、必须从数据库数据生成表、并由用户界面处理 SQL 查询或以一种舒适且易于用户的方式保护页面功能的应用程序。“数据驱动”应用是指利用支持的 SQL 创建 HTML 内容，并使用 HTML 表单驱动数据库事务的应用程序。这是官方稳定版本。更多信息可以在 phpplib 网站找到

`http://phpplib.sourceforge.net/` 来自 Debian 3.0r0 APT

## phpmyadmin

一组用于通过 WWW 管理 MySQL 的 PHP 脚本。phpMyAdmin 旨在通过 WWW 处理 MySQL 的管理。目前它可以：

- 创建和删除数据库
- 创建、复制、删除和修改表
- 删除、编辑和添加字段
- 执行任何 SQL 语句，甚至是批量查询
- 管理字段上的查询
- 将文本字段加载到表中
- 创建和读取表转储（dumps）
- 导入/导出 CSV 数据
- 管理一个数据库 来自 Debian 3.0r0 APT

`http://www.tld.org/LDP/Linux-Dictionary/html/index`

## phpsgadmin

一组用于通过 WWW 管理 PostgreSQL 的 PHP 脚本。phpPgAdmin 旨在通过 WWW 处理 PostgreSQL 的管理。目前它可以：

- 创建和删除数据库
- 创建、复制、删除和修改表/视图/序列/函数
- 编辑和添加字段（在 Postgres 范围内）
- 执行任何 SQL 语句，甚至是批量查询
- 管理字段上的查询
- 将文本字段加载到表中
- 创建和读取表转储
- 管理一个数据库
- 管理所有 posts 来自 Debian 3.0r0 APT
