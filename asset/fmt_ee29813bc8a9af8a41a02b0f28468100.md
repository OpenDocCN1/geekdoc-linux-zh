
# 系统工具

系统工具本质上是旨在辅助管理和优化计算机系统或应用程序的软件程序，在支持计算机基础设施方面起着至关重要的作用。与直接辅助用户任务的应用程序不同，实用程序通常在后台运行——无论是备份数据、压缩磁盘还是管理文件。它们可以是操作系统的一部分，也可以单独安装，从而提供增强的功能或替换默认工具。对于通过防病毒程序确保安全以及通过磁盘碎片整理优化性能，系统工具对于普通用户和 IT 专业人员来说都是不可缺的。根据其对系统的影响，它们需要不同级别的用户权限，并包括调试器、诊断程序和网络工具等大量工具，以保持计算机运行流畅高效。

`QDirStat` 是一款帮助用户可视化和管理磁盘空间的图形化工具。作为其前身 `KDirStat` 的升级版，此 `Qt 5` 不需要 `KDE` 库，使其能够在各种 Unix 类系统甚至 `Docker` 容器中运行。它提供了目录和文件的双重视图：传统的树形结构和彩色的树状，便于根据类型轻松识别和管理大小文件。`QDirStat` 以其功能增强著称，引入了多选、自定义清理操作和详细的错误报告，并提供了用于包管理、文件类型和磁盘使用统计的可配置类别和视图。它是优化磁盘空间的友好型解决方案。

`Psensor` 是一款基于 `GTK+` 的友好软件，旨在实时监控硬件温度，包括主板、`CPU`、`GPU` 和硬盘，以及 `CPU` 风扇转速。它将其功能扩展到监控远程服务器，并显示 `Linux` `CPU` 使用率。凭借自动检测支持的硬件的能力，`Psensor` 将温度和风扇速度以文本和详细图表的形式呈现，将所有数据整合到一个综合图中以便于分析。它还具有可配置的警报和提醒功能，通知用户关键温度和风扇速度问题，确保系统健康始终得到高效监控。

`Stacer` 是一款适用于 `Linux` 的全开源系统优化器和应用程序监控器，为用户提供对系统各个方面的控制。它通过管理启动应用、清理系统不必要文件、处理系统服务和进程，甚至卸载应用程序等功能简化了管理。“启动应用”选项卡简化了开机时应用程序的设置，而系统清理器有助于整理您的系统。`Stacer` 还让启动或停止系统服务变得简单易行，提供了运行进程的详细视图，并展示了 `CPU`、内存和网络活动的实时使用情况。此外，它的 `APT` 存储管理器允许轻松编辑软件包仓库，使其成为优化和监控 `Linux` 系统的多功能工具。

`BleachBit` 是一款强大的开源工具，旨在为 `Linux` 和 `Windows` 用户高效地释放磁盘空间并保护隐私。它可以清理不必要的文件，包括缓存、`Cookie`、上网历史和临时文件，并通过粉碎文件防止恢复、擦除磁盘空间以删除其他应用程序删除的文件痕迹，超越了简单的删除。`BleachBit` 简单易用，支持 `Firefox`、`Google Chrome` 等多种应用程序，确保不包含广告软件或恶意软件。它不仅免费而且完全可定制，支持多种语言和如清理 `Firefox` 以提高速度等高级功能，使其成为维护系统性能和安全的必备工具。

`SoundConverter` 是 `GNOME` 桌面环境常用的音频文件转换器，以其简洁的界面和快速的多线程转换能力而闻名。得于 `GStreamer`，它支持多种格式，包括 `Ogg Vorbis`、`AAC`、`MP3` 和 `FLAC`。通过 `SoundConverter`，用户可以根据标签轻松重命名文件并组织文件夹，简化了本可能是枯燥的任务。它设计简单快速，利用可用的多个核心来加速处理，甚至可以从视频文件中提取音频。无论转换为 `Opus`、`Ogg Vorbis` 还是 `MP3`，`SoundConverter` 都能为您的转换需求提供无缝且高效的体验。

相反，这种多功能免费图像处理器支持包括 `Windows`、`Linux`、`macOS` 和 `FreeBSD` 在多个平台上的各种任务。凭借 `ImageMagick` 的强大功能，它可以轻松管理 100 多种格式，允许轻松对无数图像进行转换、调整大小、旋转和翻转。用户可以将 `PDF` 文档转换为图像，为网络使用进行压缩并批量重命名文件，从而提高管理视觉内容的效率。它的易用性结合自定义尺寸、分辨率和文件名的能力，使其成为任何图像处理需求的实用工具。它可以通过多种安装方法获取，体现了为所有人提供的易于使用、快速且实用的图像处理能力。

`GParted`（又称 `GNOME` 分区编辑器）是一款基于 `GTK` 的免费应用程序，用于 `GNU Parted` 管理磁盘分区。它简化了创建、调整大小、移动和复制分区等任务，对于设置新操作系统、重新组织磁盘空间或数据镜像而言具有极高价值。`GParted` 兼容包括硬盘、`SSD` 和 `RAID` 系统在内的多种存储设备，支持多种文件系统以进行全面的磁盘管理。其用户友好界面允许分区对齐、数据救援和设置分区标志，满足了在 `Linux` 和其他操作系统上寻找高效分区管理工具的初级和高级用户的需求。

`HardInfo` 是一款 `Linux` 的全面系统分析器和基准测试工具，通过易于导航的图形界面提供硬件和软件组件的详细见解。它提供 `HTML` 或纯文本格式的详尽报告，允许基准测试对比，

并且可以访问远程计算机上的信息。`HardInfo` 涵盖了从 `CPU`、`GPU`、主板到内存、存储和网络的广泛系统方面，它通过以易访问的格式组织数据而脱颖而出，比类似的工具更易理解。用户可以直接从图形界面或命令行生成详细报告，增强了其在诊断和分析系统性能以及硬件规格方面的实用性。

`gpustat` 是一个简单的命令行实用程序，专为监控 `NVIDIA` 图形显卡设计，不支持 `AMD GPU`。作为免费开源软件，它为用户提供了一套强大的实时查询 `GPU` 状态的功能。这些功能包括用于持续监控的内置监听模式（`watch mode`）、显示全面 `GPU` 属性、运行进程名称、完整命令、`CPU` 统计、用户名、进程 `ID`、`GPU` 风扇速度、编码器/解码器利用率以及功率使用或功耗的选项。该工具对于需要深入了解其 `NVIDIA GPU` 性能和运行进程的人来说是无价的，而这一切都可以通过简单的命令行实现。

`Czkawka` 的名字源自波兰语中的“打嗝”词，是一个简单、快速且免费的应用程序，旨在通过删除不需要的文件来清理电脑。它使用内存安全的 `Rust` 语言编写，因速度快、利用先进算法和多线程高效执行任务而脱颖而出。这款开源工具无广告，适用于 `Linux`、`Windows`、`macOS` 和 `FreeBSD` 在内的多个平台。它同时具有 `CLI` 和 `GUI` 前端，后者利用 `GTK 4` 或 `Slint` 框架以满足不同的用户偏好。此外，`Czkawka` 确保隐私，不访问互联网或收集数据。它支持多种语言，并配备了大量工具来识别重复文件、空文件夹、大文件等，包括对相似图像、视频和音乐的特殊搜索，以及识别无效符号链接、损坏文件以及内容与扩展名不匹配。

## QDirStat

访问 `QDirStat` 官方网站 `https://github.com/shundhammer/qdirstat` 了解有关 `QDirStat` 的一切。

通过软件管理器安装 `DEB/FLATPAK` 软件包：打开软件管理器并搜索 `QDirStat`。

点击 `QDirStat`，然后点击源选择框。选择系统包或 `Flatpak` 并点击安装。

在终端中通过 `APT` 安装 `QDirStat`：
输入以下命令：

```
sudo apt update
sudo apt install qdirstat
```
