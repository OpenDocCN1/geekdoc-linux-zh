## 04 传感器入门

启动传感器会稍微复杂一点，因为我们需要准备传感器以确保 `Sensly` 的读数是稳定的。为了做到这一点，我们在代码中使用了一个循环，等待预热完成。如果你刚刚开启 `Sensly`，这需要二到三分钟。

- `import os`
- `from sensly import Sensly`
- `sensly = Sensly()`

```python
# 等待预热完成
# 这样我们就可以获得稳定的读数
while(preheat == False):
    print("preparing...")
    time.sleep(1)
```

## 02 获取代码
