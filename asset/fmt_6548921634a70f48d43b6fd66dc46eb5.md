# 限制器/调节器 (Limiter)

一种用于限制振幅的设备（如信号），在规定范围内有效。这种限制器是理想的限制信号。信号放大器。该术语有时用于调频（FM）接收机。这种限制器是理想的限制值。如果输入大于限制器，输出小于限制器。在系统中，上界和下界是不相等的。这种限制器是理想的。

## 公差与配合

尺寸的极值称为公差（limits）。两个相邻部件之间的紧密程度或松散程度称为配合（fit）。配合的特性取决于部件的使用。因此，轴承中相互运动的部件之间的配合，与设计用于防止部件之间发生任何相对运动的配合（如安装在轴上的轮子）被认为是不同的。

在为各种应用设计和规定公差与配合时，互换性制造的利益要求：(1) 使用与公差和配合相关的标准定义；(2) 优选基准尺寸和公差工具；(3) 公差应基于优选的公差和隙量；(4) 使用统一的公差应用系统（双边或单边）。参见：设计标准；工程设计；机械。

## 褐石

天然铁氧化物的化石或通用术语，是矿物针铁矿 α-Fe(OH) 中的常见相。褐石包括砂质沼铁矿。它是特征性的褐色岩石，在沼泽、湖或海洋沉积物中有机沉淀形成的矿石风化带中，含有黄铁矿和赤铁等氧化物。

## 帽螺

水生腹足软体动物的名称，具有锥形壳和吸盘状足。帽螺（如帽螺）非常适应生活在受波浪影响的岩石表面，在潮间带，它们能够抵抗脱水和空气干燥。帽螺在岩石或硬表面上缓慢移动，通过收缩肌肉保护自己免受波浪冲击。足没有壳盖，帽螺一旦脱离就无能为力。

*Diodera*，北美太平洋岸的粗顶帽螺，从侧面和顶部的视图。

帽螺通过机械刮擦岩石表面的藻类和硅藻缓慢而持续地进食。帽螺的结构和功能适应性出现在许多不同的腹足纲动物中。参见：腹足纲；软体动物门。

## 亚麻目

开花植物的一个目，属于锦形植物门（被子植物）中的蔷形目亚目。该目包含约 5 个科和约 550 种。它们大多是草本植物或木本植物，具有许多对称的花朵，拥有许多基部愈合的雄蕊。花粉为四分体。*Linum usitatissimum*（亚麻，纤维的来源）和*Erythroxylon*（古柯因的来源）是亚麻目的著名成员。参见：线轴；锦形植物门；木兰目；真序目。

## 线积分

向量函数 $F$ 沿路径 $C$ 的线积分表示为 $\int_C F_x dx + F_y dy + F_z dz$

```
F \cdot d\mathbf{r} = \int_C (F_x(x,y,z) dx + F_y(x,y,z) dy + F_z(x,y,z) dz)
```

是 $F$ 沿坐标轴的分量。路径 $C$ 应该是平滑的，至少部分可以通过形式如 (2) 的方程轻松参数化，对于每个平滑

```
x = x(t) \quad y = y(t) \quad z = z(t)
```

函数 $F_x(x,y,z)$ 必须在 $C$ 的所有点定义。

当 $C$ 是闭合曲线时，线积分称为环，记为 (3)

```
\oint F \cdot d\mathbf{r}
```

参见：积分。

## 线谱

低压气态下激发原子、离子和化学分子的特征不连续谱。

具有良好生物生长条件和高营养水平的水生生态系统显示出富营养化的迹象。富营养湖泊通常通过大量的浮游植物和藻类以及深层区低氧浓度来识别。参见：生态学；富营养化；淡水生态系统；水文学；湖泊；河流。
