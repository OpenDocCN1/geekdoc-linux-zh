
大多数错误都源于没有仔细阅读安装过程中提供的信息。仔细阅读安装信息是通往成功的第一步。

- 这个发行版能在我的硬件上运行吗？
- 当对硬件能力有疑问时，请查看 [http://www.tldp.org/HOWTO/Hardware-HOWTO/index.html](http://www.tldp.org/HOWTO/Hardware-HOWTO/index.html)。
- 我用的是什么种键盘（按键数量、布局）？什么种鼠标（串口/并行、按键数量）？有多少 MB 的内存内存？
- 我是从基础工作站还是服务器安装，还是需要自己选择软件包？
- 我是从硬盘、CD-ROM 还是通过网络安装？我需要为其中任何一种调整 BIOS 吗？安装方法需要启动盘吗？
- Linux 会是这台电脑上唯一的系统，还是双系统安装？我是否应该创建一个大分区以便以后安装虚拟系统，或者这本身就是一个虚拟安装？
- 这台电脑在网络中吗？它的主机名、IP 地址是什么？是否有网关服务器或其他我的机箱需要通信的重要网络设备？

不使用网络或配置不当可能会导致启动缓慢。

- 这台电脑是网关/路由器/防火墙吗？（如果你在想这个问题，它可能不是。）

## 登录、激活用户界面和注销

### 引言

为了直接在 Linux 系统上工作，你需要提供用户名和密码。你始终需要对系统进行验证。正如我们在第 1 章的练习“什么是 Linux?”中提到的，大多数基于 PC 的 Linux 系统有两种供运行的运行模式：要么是在文本控制台模式下（既快速且清爽，看起来像带有鼠标、多任务和多用户特性的 DOS），或者是在图形模式下（外观更漂亮，但消耗更多系统资源）。

### 图形模式

这是目前大多数桌面电脑的默认设置。当你第一次被要求输入用户名，然后在新窗口中输入密码时，你就知道可以使用图形模式连接到系统了。

要进行登录，在登录窗口中使用鼠标指针，向系统提供用户名和密码，然后点击 OK 或按 `Enter` 键。

#### 注意 root 账户！

使用 root 用户名（系统管理员账户）进行（图形）连接通常被认为是一个坏主意，因为图形界面包含了许多额外的程序，而对于 root 来说还拥有大量的额外权限。为了将风险降至最低，请使用普通用户进行图形连接。但有足够的理由将此作为通用建议，适用于所有 root 账户的使用：只有在需要 root 权限时才登录 root。

在输入用户名/密码组合后，图形环境启动可能需要一些时间，这取决于你电脑的速度、使用的软件以及你的个人设置。

要继续，你需要打开一个终端窗口或简称为 `xterm`（X 是支持图形环境的底层软件名称）。根据你正在使用的窗口管理器，可以在应用程序（Applications）-> 实用（Utilities）、系统工具（System Tools）或菜单（Menu）中找到此程序。可能会有可以作为快捷获取 `xterm` 窗口的图标，在桌面背景上点击鼠标右键通常会弹出一个包含终端窗口的菜单。

在浏览菜单时，你会发现很多事情不需要通过键盘输入命令就可以完成。然而，处理计算机的老旧点点（point-'n'-click）方法仍然可行。但这是为未来的网络和系统管理员准备的，他们需要处理系统的核心。他们需要比鼠标更强大的工具来处理将面对的所有任务。这个工具就是 shell（壳），在图形模式下，我们通过打开终端窗口来激活 shell。

终端窗口是你 shell 的控制面板。接下来的几乎一切都是使用这个简单但强大的文本工具完成的。

**图 2.1 终端窗口**

| 文本 | 描述 |
| :--- | :--- |
| RedHat Linux Release 8.0 (Psyche) | 登录界面示例 |
| login: | 用户名提示符 |
| user@host: | 登录后的提示 |
| $ | Shell 提示符 |

你不会看到任何你正在输入的指示，甚至没有一个星号，你也不会看到光标移动。但这在 Linux 上是正常的。

当系统接受你为有效用户时，可能会收到一些信息，被称为“每日消息”（message of the day），它可以是任何内容。此外，在 UNIX 系统上流行给出一个幸运签饼，其中包含一些明智或不明智（取决于你）的想法。之后，你将获得一个 shell，具有与你在图形模式下得到的相同的提示符。

### 文本模式

当你看到整个屏幕是黑色的，大多数情况下显示字符时，你就知道处于文本模式。

```
RedHat Linux Release 8.0 (Psyche)
login: 
```

登录方式与图形登录不同，不同在于提供用户名后必须按下回车键。你不会看到任何你正在输入的指示，甚至没有一个星号，你也不会看到光标移动。但这在 Linux 上是正常的。

当系统接受你为有效用户时，你可能会收到一些信息，被称为“每日消息”，它可以是任何内容。

注销是通过输入注销命令并按回车键完成的。当你再次看到登录界面时，你就成功断开了系统连接。

### 电源按钮

虽然 Linux 设计初衷并非在不执行适当停机程序的情况下关闭，但在新系统中，按下电源按钮等同于启动这些程序。然而，在不经过停机过程的情况下关闭旧系统可能会导致严重的损坏！如果你想确保万无，请在图形界面注销时始终使用“关机”（Shut down）选项，或者在登录界面（你需要提供用户名和密码的地方）寻找关机按钮。
