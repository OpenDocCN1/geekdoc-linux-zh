
# 术语表

### 阶段 (Phases)
阶段是 Apache API 三个关键组件之一。Apache 的操作流经过八个阶段：Apache 接收请求，请求从阶段 1 流向阶段 8。

### PHP
一种主要用于 Linux 服务器的脚本语言和解释器。为生成动态内容提供了灵活性。

### 端口 (Port)
用于识别主机上网络服务的 16 位数字。此外，端口也是一个指令，当与 `Bind-Address` 使用时可以指定地址和端口，允许运行同一机器上的不同 Apache 实例在不同的地址或端口监听请求。

### 端口 80
最用于 Web 服务器或超文本传输协议流量的端口。

### 基于端口的虚拟主机 (Port-based virtual hosting)
如果没有其他 IP 地址或别名，可以使用这些主机。

### 极好隐私 (PGP)
一种用于加密通信、验证文件未被篡改以及验证人员身份真实性的程序。

### 代理 (Proxy)
作为 Web 请求和服务的网关，根据客户端的 IP 地址允许或限制网络访问，缓存以帮助系统运行更高效，并控制（或帮助防火墙控制）网络访问。

### 红帽软件包管理器 (RPM)
一个提供软件包灵活性的程序，用于许多 Unix 和 Linux 发行版。

### 请求 (Request)
此日志文件包含客户端发送的实际 HTTP 请求，用引号括起。

### 重写 (Rewrite)
通常与 `mod_rewrite` 使用，此指令有助于执行内部文件子请求。`Rewrite` 可以使用多次。

### 重写条件 (RewriteCond)
与 `mod_rewrite` 使用的指令，`RewriteCond` 定义了 `RewriteRule` 的条件。在在其之前有一个或多个条件的情况下，只有当这些条件适用时才会使用 `RewriteRule`。

### 重写规则 (Rewrite rule)
此指令可以运行多次。它定义了一个简单的重写规则。

### 安全套接层 (SSL)
该协议层为客户端和服务器之间提供安全通信，通过允许双向身份验证、使用数字签名确保完整性以及使用加密保护隐私。

### ServerName
如果主机要与其 IP 地址关联的自己的域名，则必须在此处定义该主机。

### Server Side Includes (SSI)
此指令可在 HTML 文档中使用，用于回显任何环境变量的信息。

### ServerSignature
此指令会在日志中添加一行，包含服务器版本号以及生成该行的虚拟主机的名称。

### ServerType
`ServerType` 指令中的独立模式（Stand-alone Mode），在此模式下 `httpd` 进程监听连接。

### Setcookie
此指令将使用 PHP 在 Web 浏览器中设置 cookie，避免使用 JavaScript 方法。

### Spoofing
欺骗。一种攻击手段，数据包被伪装成看起来来自另一个源（通常是防火墙后的内部网络）。

### Squid caching proxy
一种用于缓存 HTTP 信息的程序，不需要高端硬件即可显著提升性能。

### srm.conf
用于指定哪些类型的文档可以被保护。

### Standalone
独立。该选项是 Apache 的默认方法。在独立模式下，服务器处于就绪并等待连接状态。对于繁忙的网站特别有效。

### Static Web page
静态网页。不改变的网页。

### Style sheets
样式表。描述文档在屏幕上或打印时的呈现方式。

### Sudo
允许系统管理员赋予特定用户或用户组以 root 或其他用户的身份运行特定命令，同时记录命令及其参数。

### Superuser
超用户。唯一可以请求某些系统服务的账户，例如更改日期/时间、添加新用户账户和增加进程优先级。

### TCP/IP
传输控制协议/网际协议 (`TCP/IP`) 是允许互联网上所有计算机通信的主要协议。每台计算机都获得一个唯一的 IP 地址。

### TCP wrappers
TCP 封装。它们有一组通配符，允许匹配服务和客户端。

### Thundering herd
群群效应。所有一个线程都把自己放回等待队列等待下一个连接的问题。

### Trojan horse
木马。一种看似为用户执行某些任务的程序，但其主要功能是执行另一个可能是恶意的任务。

### Trusted networks
可信网络。采用以下一项或多项 Apache 安全网络：Apache+SSL、`mod_ssl`、密码认证、`.htaccess` 文件认证和匿名访问。

### Uniform Resource Identifier (URI)
统一资源标识符。URL 的子集，用于标识网页的路径。

### Uniform Resource Location (URL)
统一资源定位。客户端与服务器之间使用 HTTP 通信的一部分。

### Uniform Resource Name (URN)
统一资源名称。客户端与服务器之间使用 HTTP 通信的一部分。

### User
用户。任何使用系统上进程的实体。

### UserDir
该指令分配目录名称，该目录被用作个人的根文档目录。

### Virtual hosts
虚拟主机。允许在一个 IP 地址下托管多个域名，或者在具有不同域名的多个地址下进行托管。

### Webuser/Webgroup
Web用户/Web组。Apache 将用于读取文件、执行 CGI 和创建子进程的用户和组。

### Worms
虫。一种攻击形式，作为独立程序进入计算机系统，不附着于其他代码，可能会导致无意损坏或资源耗尽。
