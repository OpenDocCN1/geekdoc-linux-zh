
## 销毁内存描述符

当与特定地址相关的进程退出时，会调用定义在`kernel/exit.c`中的`exit_mm()`函数。该函数执行一些清理工作并更新统计信息。然后它调用`mmput()`，该函数会减少内存描述符的`mm_users`计数器。如果用户计数达到零，则调用`mmdrop()`来减少`mm_count`使用量。如果该计数器最终为零，则调用`free_mm()`宏通过`kmem_cache_free()`将`mm_struct`返回到`mm_cache`slab中，因为该内存描述符已经没有用户了。

## `mm_struct`与内核线程

内核线程没有进程地址空间，因此没有关联的内存描述符。内核线程进程描述符中的`mm`字段为`NULL`。这就是内核线程的定义——没有上下文的进程。

这种地址空间的缺失并没有问题，因为内核线程不会访问任何用户空间内存。由于内核线程在用户空间中没有任何页，它们不需要自己的内存描述符和页表。尽管如此，内核线程仍需要某些数据（例如页表）来访问内核内存。为了获取内核线程所需的数据，同时避免在内存描述符和页表上浪费内存，或在每次内核线程开始运行时切换到新地址空间时浪费周期，内核线程会使用上一个运行的任务的内存描述符。

每当进程被调度时，进程的`mm`所引用的地址空间会被加载。进程描述符中的`active_mm`字段被更新为指向新的地址空间。内核线程没有地址空间，且`mm`为`NULL`。当内核线程被调度时，内核发现`mm`为`NULL`并保留上一个进程的地址空间加载。内核更新内核线程进程描述符的`active_mm`字段，指向上一个进程的内存描述符。内核线程就可以根据需要使用上一个进程的页表。由于内核线程不访问用户内存，它们可以使用包含内核内存的地址空间中的信息，这对于所有进程都是相同的。

## 虚拟内存区域

内存区域结构`vm_area_struct`代表内存区域。它定义在`<linux/mm_types.h>`中。在 Linux 内核中，内存区域通常被称为虚拟内存区域（简称 VMA）。

# 第 15 章 进程地址空间

`vm_area_struct`结构描述了给定地址中连续区间上的单个内存区域。内核将每个内存区域视为唯一的内存对象。每个内存区域都拥有属性，例如权限和一组关联的操作。通过这种方式，每个VMA可以表示不同类型的内存区域——例如内存映射文件或进程的用户空间栈。这类似于VFS层采用的面向对象的方法（见第 13 章）。以下是该结构，带有描述每个字段的注释：

```c
struct vm_area_struct {
    struct mm_struct        *vm_mm;          /* 关联的 mm_struct */
    unsigned long          vm_start;       /* VMA 起始，包含 */
    unsigned long          vm_end;         /* VMA 结束，不包含 */
    struct vm_area_struct *vm_next;      /* VMA 列表 */
    pgprot_t               *vm_page_prot;   /* 访问权限 */
    unsigned long          vm_flags;       /* 标志 */
    struct rb_node         *vm_rb;          /* 树中的 VMA 节点 */
    union {
        struct {
            struct list_head      list;
            void                  *parent;
            struct vm_area_struct *head;
        } vm_set;
        struct prio_tree_node pririo_tree_node;
    } shared;
    struct list_head        anon_vma_node;  /* 匿名_vma 条目 */
    struct vm_area_struct  *anon_vma;       /* 匿名 VMA 对象 */
    struct vm_operations   *vm_ops;         /* 关联的操作 */
    unsigned long          vm_goff;        /* 文件内的偏移 */
    struct file            *vm_file;       /* 映射文件，如果有的话 */
    void                   *vm_private;    /* 私有数据 */
};
```
