## 第六章 LINUX 中的分区

分区是在计算机上执行 Linux 安装时必须的非常基础的步骤。即使您安装 Windows 系统也需要分区。虽然 Windows 提供图形化界面，但 Linux 的分区机制可能不同，某些 Linux 发行版甚至不提供 Gparted 这样的图形化安装程序。跟随操作详细了解分区方案和安装步骤。

## 分区命名方案

这些数字分区命名方案。

- `/dev`: 这是存储所有设备文件的目录。

- `hd` 和 `sd`: 它们是分区名的前两个字母，代表分区所在的设备类型，其中 `hd` 代表 IDE 硬盘，`sd` 代表 SCSI 硬盘。

- `a`: 它是分区名的第三个字母，表示分区位于哪个设备。

例如，`/dev/hda` 代表第一块 IDE 硬盘，`/dev/sdb` 代表第二块 SCSI 硬盘，`/dev/sdd` 代表第四块 SCSI 硬盘，以此类推。

- `+ 2`: 这些数字分区。

Linux 下的前 4 个分区（主分区或扩展分区）用数字 1 ~ 4 表示，逻辑分区从 5 开始，以此类推。

例如，`/dev/hda2` 代表第一块 IDE 硬盘的第二个主分区或扩展分区，`/dev/sdb3` 代表第二块 SCSI 硬盘的第三个主分区或扩展分区，`/dev/sdc6` 代表第三块 SCSI 硬盘的第二个逻辑分区。

### 双系统 Windows + LINUX 硬盘分区方案

很多从 Windows 切换过来的初学者喜欢在电脑上安装双系统。这在技术术语中也称为双启动。这种方法对于 Linux 初学者来说更加危险，可能会导致硬盘数据丢失。因此，有必要讨论如何安全、有效地安装 Linux + Windows 共存的双系统。

首先，应该理解 Linux 和 Windows 是两个完全不同的系统，因此 Linux 和 Windows 的文件系统之间也是不兼容的。如果你想安装 Linux，必须从硬盘中“专用”出一个分区给 Linux，这种专用并不是清空某个盘器符下的数据，而是从 Windows 中完全删除磁盘。

例如，如果我想给 Linux 系统分配 G 盘空间，我需要在 Windows 的磁盘管理中完全删除 D 盘。空间取决于安装包的大小。通常，10GB 的空间就能满足需求。

整理好 Linux 所需的空间后，下一步是重启系统，将 BIOS 设置为光驱启动，将 Linux CD 放入光驱，然后进入系统安装界面。

注意：

安装双系统时，最好先安装 Windows 系统，然后再安装 Linux，因为每次安装 Windows 时，系统启动文件都会被修改。如果你反过来安装双系统，Linux 可能无法启动，你可能需要修复系统启动文件。

此外，在安装 GRUB 引导加载程序时，引导将从 Windows 切换到 Linux。在将来情况下，如果由于某种原因你选择了删除 Linux，那么 Grub 将损坏，你可能无法进入你的 Windows 系统。

这是初学者在处理双启动系统时遇到的最常见的问题之一。要排除引导加载器问题，我们建议检查制造商的论坛。
