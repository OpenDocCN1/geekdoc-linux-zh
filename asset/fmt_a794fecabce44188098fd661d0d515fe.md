
《贝奥夫》是一首古英语史诗，也是已知的日耳曼文学中最老的作品之一。《贝奥夫》是英语唯一幸存的史诗，讲述了一个力量巨大的英雄击败怪物格林德尔的故事。请参见“历史”以了解详情。可能有很多关于贝奥夫的定义。有些人声称，只有当系统是按照原始机器相同的方式构建时，才能称其为贝奥夫。其他人则走向极端，将任何运行并行贝奥夫的工作站系统都称为此类系统。我对贝奥夫的定义介于这两种观点之间，并基于许多计算点。它是一个贝奥夫：一种可以使用通过以太网或其他网络连接的一个或多个节点进行并行计算的架构。这是一个使用通用组件、任何可运行的 PC、标准以太网适配器和交换机构建的系统。它不包含任何自定义软件，并且可以很容易复制。贝奥夫还使用通用软件，如 Linux 操作系统、并行虚拟机 `PVM` 和消息传递接口 `MPI`。服务器节点控制集群并向节点提供文件。大型贝奥夫机器有多个节点，可能还有其他专门用于特定任务的节点，例如案例或监控站。在大多数情况下，贝奥夫系统是基于节点数量的。在无盘集群配置中，客户端节点在服务器告知它们之前并不知道自己的 IP 地址或名称。贝奥夫与工作站集群 `COW` 的主要区别之一是 `COW` 可以处理更多工作站。在大多数情况下，客户端节点没有键盘和显示器，通过远程登录或串口终端访问。贝奥夫节点可以被视为一个 CPU + 内存包，放置在集群中，就像将 CPU 或内存模块插入主板上一样。贝奥夫不是一个特殊的软件包、新的网络拓扑结构或最新的内核头。贝奥夫是将 Linux 节点聚集成并行虚拟超级计算机的技术。尽管通过努力，人们可以使用标准 Linux 发行版在不使用额外软件的情况下构建贝奥夫类机器。如果你有两个通过 NFS 共享 `/home` 文件系统的 Linux 集群，并可以使用彼此执行远程 shell `rsh`，那么可以认为你拥有一个简单的双节点贝奥夫机器。来自 Beowulf-HOWTO
