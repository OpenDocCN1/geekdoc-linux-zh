
在特殊格式字符串中，`{item}` 还可以包含索引和属性查找。占位符 `{item[n]}`（`n` 为数字）对 `item[key]` 执行序列查找（其中 `key` 是非数字字符串），则返回 `item["key"]` 的字典查找。占位符 `{item.attr}` 指向 `item` 的属性。关于 `format()` 的更多细节可以可以在第 4 章的“字符串格式化”部分。

## range() 对象

内置函数 `xrange([i],j[, [stride])` 创建一个表示整数范围 `k` 的对象，使得 `i <= k`。第一个索引，`i`，和 `stride` 是可选的，默认值分别为 0 和 1。`xrange` 对象在每次访问时计算其值，虽然 `xrange` 对象看起来像序列，但实际上不支持切片操作。这限制了 `xrange` 的用处。在 Python 3 中，`xrange()` 被 `range()` 取代，其行为类似于 Python 2 中的 `xrange`。`range()` 对象是惰性的，意味着它只在需要时生成数字，这对于大范围非常节省内存。`range()` 函数可以接受三个参数：
- `start`: 序列的起始值（包含）。
- `stop`: 序列的结束值（不包含）。这是唯一的强制参数。
- `step`: 序列中每个数字之间的增量。默认为1。

例如：

```python
>>> list(range(5))
[0, 1, 2, 3, 4]
>>> list(range(2, 7))
[2, 3, 4, 5, 6]
>>> list(range(0, 10, 2))
[0, 2, 4, 6, 8]
```

`range()` 对象通常用于循环以迭代特定的次数。

```python
>>> for i in range(3):
...     print(i)
0
1
2
```

`range()` 对象也可以用于切片：

```python
>>> r = range(10)
>>> r[2:5]
range(2, 5, 1)
```
