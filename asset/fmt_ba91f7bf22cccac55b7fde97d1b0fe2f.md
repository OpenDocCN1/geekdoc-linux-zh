
除了通过多个节点外，流量还会被加密，事实上是多次加密。它在每个节点失去一层加密，但在离开出口节点到达目的地之前，永远不会被完全解密。

每个节点都有一个标识性的 IP 地址，这也是经过加密的。目的地网站看到的唯一 IP 地址是最终节点，即出口节点的 IP 地址。

目前，Tor 网络总共由大约 7,000 个中继（节点）和 800 个桥组成。桥与中继类似，但它们未列在 Tor 目录中。当网站或应用程序阻止来自已检测到的 Tor 节点的流量时，也可以使用桥。

## Tor 会隐藏 IP 地址吗？

当连接到 Tor 网络时，活动永远无法追溯回你的 IP 地址。同样，你的互联网服务提供商（ISP）将无法查看关于你流量内容的信息，包括你正在访问哪个网站。

你的 ISP 会看到你在连接到 Tor 入口节点，而你访问的网站将知道 Tor 出口节点的 IP 地址。

## 如何使用 Tor：入门指南

使用 Tor 最简单的方法是通过 Tor 浏览器。这些是基于 Firefox 的应用程序，可以下载并安装到你的电脑上。

提供适用于 macOS、Windows 和 Linux 的版本。一旦你下载并安装完毕，你就可以通过浏览器访问明网和 .onion 网站。

在某些情况下，使用 Tor 浏览器可能会被阻止。如前所述，使用桥应该可以解决这个问题。在过去，这相当复杂，但在最新版本中要容易得多。你首先需要找到一个桥，然后将其配置到 Tor 浏览器中。

## Tor 能让你匿名吗？

要在网上实现真正的匿名是复杂的，甚至是不可能的，但 Tor 无疑可以帮助你接近这一目标。所有到达目的地的流量看起来都来自一个 Tor 出口节点，因此会被分配该节点的 IP 地址。由于流量在加密状态下经过了多个额外节点，因此无法追溯回你。

然而，其中一个问题在于信任出口节点的运营商。如果你访问的是一个未加密（非 HTTPS）的网站，节点运营商可能会跟踪你的活动并查看你的信息。他们可以收集诸如你正在浏览哪些网页、你的登录信息、你的消息或帖子内容以及你执行的搜索等数据。虽然，没有办法将这些信息追溯回你，甚至追溯回入口节点。

值得注意的是，使用 Tor 浏览器仅保护通过该连接的流量，不会匿名化你电脑上的其他应用程序（尽管许多应用程序可以通过其他方式配置为通过 Tor 网络）。此外，你的 ISP 仍然可以看到你正在使用 Tor。为了提高隐私，你可以同时使用 VPN 和 Tor 浏览器。

## 什么是暗网，Tor 与它有什么关系？

如果你熟悉“明网”这个词，你会知道它指的是可以免费访问的互联网部分，也就是说，不需要 Tor 或替代浏览器。另一方面，你有深网。这些内容包括未被搜索引擎索引的内容，包括过时内容、私人文件和禁止搜索引擎爬取的网页。

此外，深网中包含暗网。这些内容通常只能使用像 Tor 这样的特殊工具访问。暗网包含一些合法的网站，但它更以充斥非法活动的地方而闻名。

你可以用 Tor 访问明网，但你也可以访问暗网站点，特别是 .onion 网站。这些网站只有使用 Tor 浏览器的人才能访问，并且它们的 URL 中包含 .onion。它们也被称为“Tor 隐藏服务”。

它们未被搜索引擎索引，如果你不知道去哪里查找，很难找到它们。Tor 保护 .onion 网站运营商的匿名性，因此很难查明是谁在运营它们。当然，运营商和用户匿名性的结合正是暗网成为犯罪活动理想场所的原因。

臭名昭著的 AlphaBay 市场网站（现已查封）就是一个 .onion 网站。（来源：美国司法部通过 Wikipedia）

话虽如此，有很多合法网站都有 .onion 版本。例如，VPN 面向注重隐私的用户，有些提供其网站的 .onion 版本，ExpressVPN 就是一个例子。你甚至可以通过 Tor 浏览器设置自己的 .onion 网站。

### 为什么有人想使用 Tor？

如上所述，Tor 通常与非法活动以及想要访问暗网的用户联系在一起。因此，通常假设任何使用 Tor 的人都不怀好意。相反，注重隐私的用户可以使用 Tor 在明网站点进行日常浏览，以帮助维持在线用户匿名性和隐私。

普通互联网用户希望获得更高匿名性的原因非常多。这些包括阻止 ISP 和第三方收集有关在线活动的数据、绕过审查、保护儿童隐私，或研究禁忌话题，例如避孕或宗教。

在许多职业中，保持匿名的在线个人资料也是必要或有帮助的。合法使用 Tor 的人群包括：

- 记者
- 执法人员
- 活动人士
- 吹哨人
- 企业高管
- 博客作者
- 军事人员
- IT 专业人员

虽然 Tor 不跟踪用户在线做什么，但它确实提供聚合统计数据，告诉你用户位于哪里。你可以看到按国家划分的图表，并阅读关于可能导致用户数量剧烈变化的事件的说明。

## 使用 Tor 合法吗？

Tor 的性质确实使其成为犯罪分子访问暗网某些更阴暗部分并进行犯罪活动的热门选择。这些包括买卖非法产品或服务，或参与传播仇恨言论和鼓励极端主义的论坛。

然而，如上所述，有很多非犯罪分子想要使用 Tor 的理由。事实上，使用 Tor 是完全合法的，尽管它在某些国家被封锁或正被封锁。此外，使用 Tor 仍然带有一定的污名，因此你可能不应该假设可以毫无麻烦地使用它。

据报道，互联网服务提供商（ISPs）已对 Tor 用户的带宽进行节流，甚至已联系客户告知他们停止使用 Tor 浏览器。用户可能会受到 ISP 的询问，了解他们通过 Tor 连接到哪些网站。

当局本身可能会对 Tor 用户产生怀疑，并仅基于此对他们在 Tor 上的活动进行调查，尽管目前没有关于对使用 Tor 进行罚款或指控的报道。

### 使用 Tor 有任何缺点吗？

Tor 在许多用户中很受欢迎——目前，在任何给定时间都有大约 200 万用户连接到中继节点。

但它确实存在一些缺点。以下是使用 Tor 的主要缺点：

- 速度缓慢
- 可被 ISP 检测
- 被网络管理员封锁
- 易受攻击

让我们更详细地看看这些问题。

### 速度缓慢

使用 Tor 的主要缺点是它相当安静（流量分散）。流量不会直接到达其目的地，因此这会减慢速度。此外，节点之间流动的流量速度可能比你的常规互联网连接更慢，这进一步削弱了整体势头。

更重要的是，与通过网络流动的流量相比，可用的志愿者节点数量很少。由此产生的拥塞将减慢流量，尤其是在高峰时段。

由于这些问题，Tor 的主要用途是一般浏览。它不适合流媒体或种子下载，也不适合任何其他需要大量带宽的活动。

### 可被 ISP 检测

另一个缺点是你的 ISP 能够看到你正在使用 Tor。它无法读取你的流量内容，但检测到你在这一点可能会产生一些后果。如前所述，仅仅使用 Tor 就足以引起 ISP 和当局的怀疑。绕过此问题的一种方法是使用带有 Tor 的 VPN（下文将有更多介绍）。

### 被网络管理员封锁

单个网络的管理员通常会封锁 Tor。绕过此问题的一种方法是使用桥接（bridges），它们不应该被检测为 Tor 节点。如果封锁更加复杂并使用了深度包检查，你可能需要使用额外的工具，例如可插拔传输协议（Pluggable Transports，见下文）。这些工具会将你的 Tor 流量伪装成常规流量，以绕过封锁。

### 易受攻击

虽然尚未得到证实，但有报道称，针对 Tor 的流量分析已成功用于寻找有罪证据。其中一个引人注目的案例是 2013 年的“丝绸之路”行动。丝绸之路是通过 Tor 网络运营的 marketplace，涉及估计价值 10 亿美元的毒品交易，以及其他非法商品和服务。

此外，也要注意上面提到的关于出口节点监控的传闻。请记住，这些报告似乎尚未得到证实，因此可以持怀疑态度看待它们。

## 如何使用 Tor Browser 在线保护你的隐私

如果你想保持网络浏览的私密性，你可以使用 Chrome 的无痕模式、Firefox 的隐私浏览、Microsoft Edge 的 InPrivate 模式等。虽然这会阻止使用你电脑的其他人查看你的浏览历史，但它并不能限制你的 ISP 监控你访问的网站。你可能由于各种原因希望完全匿名地浏览互联网，而这正是 Tor Browser 所提供的。

Tor 代表 The Onion Router（洋葱路由器），它提供多层次的保护，以确保你的在线活动、位置和身份完全私密。以下是安装和使用 Tor Browser 所需遵循的步骤。

### 1. 安装和配置 Tor Browser

首先下载并安装 Tor Browser。安装完成后，点击“完成”，Tor 将首次启动。你会看到一个用于控制如何连接到 Tor 网络的设置对话框。

在大多数情况下，你应该可以点击“连接”按钮，但如果你通过代理连接互联网，则需要点击“配置”按钮以输入你的设置。

### 2. 使用 Tor 上网

在 Tor 通过中继节点建立与网络的连接时会有轻微的延迟——程序警告初始连接可能需要几分钟——但一旦建立连接，Tor 浏览器将启动并准备好使用。
