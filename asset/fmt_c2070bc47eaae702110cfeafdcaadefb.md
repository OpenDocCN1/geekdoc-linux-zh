
## 管理用户账户

在 Linux 系统中，系统管理员的主要职责之一是管理用户账户和组。组是相互相关的账户集合，例如人力资源部门的一组用户。管理用户账户包括添加、修改和删除用户账户等任务。管理组包括创建新组、向组添加账户以及为组设置权限等任务。`Fedora 11` 提供了“用户管理器”（`User Manager`）工具来管理所有相关的账户和组的操作。

让我们学习如何添加用户账户。

### 添加用户账户

在 Linux 系统中你必须有一个用户账户。默认情况下，在 Linux 安装期间会创建 `root`（也称为超级用户），它为你提供了在系统上的所有管理权限，例如添加账户和创建组。你可以通过限制你用户账户的密码来保护你的文件和目录。

执行以下步骤在 Linux 中添加用户账户：

1. 点击 GNOME 网络对象模型环境（`GNOME`）桌面的“系统”（`System`）菜单项（图 Linux-9.1）。会出现一个下拉菜单（图 Linux-9.1）。
2. 将鼠标指针悬停在下拉菜单的“管理”（`Administration`）选项上（图 Linux-9.1）。会出现一个子菜单（图 Linux-9.1）。
3. 从子菜单中选择“用户和组”（`Users and Groups`）选项，如图 Linux-9.1 所示。

![](img/12ecf7a0767a6080881fb04f59162115_181_0.png)

图 Linux-9.1

出现“查询”（`Query`）对话框（图 Linux-9.2），其中你需要输入密码以授予用户管理权限。

4. 在密码（`Password`）文本框中输入 `root` 密码（图 Linux-9.2）。
5. 点击“确定”按钮（图 Linux-9.2）。

一旦你点击查询对话框中的 `OK` 按钮，用户管理器窗口就会出现。该窗口显示了安装 `Fedora 11` 时创建的用户账户（图 Linux-9.3）。

![](img/12ecf7a0767a6080881fb04f59162115_182_0.png)

图 Linux-9.2

用户账户在用户管理器窗口中按字母顺序排列。它显示了以下列：用户名、用户 ID、主要组、登录 Shell 和主目录。以下是这些列的简要描述：

*   **用户（`Users`）**：显示创建账户时输入的用户名称。
*   **用户 ID（`User ID`）**：指 Linux 操作系统在创建账户时分配给用户的唯一标识符（称为 `User ID` 或 `UID`）。系统在用户登录系统时使用该唯一数字来识别用户，并确定允许该用户的访问级别。
*   **主要组（`Primary Group`）**：指用户账户可能所属的组类别。组用于组织相关的账户。
*   **全名（`Full name`）**：显示创建账户时输入的用户全名。
*   **登录 Shell（`Login Shell`）**：指 `shell`，它是一个允许用户登录并与操作系统进行交互的程序。
*   **主目录（`Home Directory`）**：指用户的顶层目录。它包含特定用户账户的所有子目录和文件。主目录的名称以图标形式显示在桌面上，并在前面带有用户名。例如，用户 `kogent` 的主目录名称将是 `kogenthome`。

6. 从工具栏点击“添加用户”（`Add User`）按钮（图 Linux-9.4）。

出现“创建新用户”（`Create New User`）对话框（图 Linux-9.5）。

![](img/12ecf7a0767a6080881fb04f59162115_182_1.png)

图 Linux-9.4

![](img/12ecf7a0767a6080881fb04f59162115_182_2.png)

图 Linux-9.5

你可以在此对话框中输入新用户账户的详细信息：

*   在用户名（`Name`）框中输入用户名（图 Linux-9.6）。
*   在主目录（`Home Directory`）框中输入主目录路径。默认情况下，该路径以用户名作为前缀。
*   在全名（`Full name`）框中输入用户全名（图 Linux-9.6）。
*   在密码（`Password`）框中输入密码。密码字符将以星号 (`*`) 显示。
*   在确认密码（`Confirm`）框中输入相同的密码（图 Linux-9.6）。
*   在用户 ID（`User ID`）框中输入用户 ID（通常由系统自动生成）。
*   在主要组（`Primary Group`）框中选择组（默认为同名的组）。
*   点击“确定”（`OK`）按钮。

用户管理器窗口将显示已添加的用户（图 Linux-9.7）。

### 显示用户账户

学习如何创建用户账户后，现在让我们学习如何使用用户管理器工具显示用户账户。

Linux 安装期间创建的主要账户称为 `root`。该账户由管理员使用，拥有系统的所有权限。Linux 安装期间，安装程序提示你创建其他账户。如果你输入了额外账户，它们将包含在账户列表中。用户管理器显示用户账户。例如，用户管理器显示了 `kogent`、`Nisha` 和 `Kapoor`。通过选择“系统-管理-用户和组”菜单可以查看用户管理器窗口。

### 修改用户账户属性

执行以下步骤更改用户的属性：

1. 选择要更改的用户账户（图 Linux-9.9）。例如，我们选择了 `Nisha`。
2. 从工具栏点击“属性”（`Properties`）按钮（图 Linux-9.9）。
3. 出现“用户属性”对话框（图 Linux-9.10）。
4. 双击文本框中的密码。该框中的星号将被高亮显示（图 Linux-9.10）。

![](img/12ecf7a0767a6080881fb04f59162115_184_0.png)

5. 在密码（`Password`）文本框中输入新密码（图 Linux-9.11）。
6. 在确认密码（`Confirm`）框中输入相同的密码以进行确认（图 Linux-9.11）。
7. 点击“确定”（`OK`）按钮（图 Linux-9.11）。

账户属性现在已更改，用户属性对话框关闭。我们再次返回用户管理器窗口（图 Linux-9.12）。

## 管理组

组是相关用户账户的集合。例如，一个名为 `wages`（工资）的组可能包含公司中所有按日薪领取的用户账户。当创建一个新的用户账户时，Linux 会自动将其分配到一个与该用户账户同名的组。这意味着每个用户账户都属于一个组，而该组可能有一个或多个用户账户。这种自动分配的组被称为账户的主组（`primary group`）。不过，你可以创建更多组并将不同的用户账户包含其中。

让我们学习管理组。

### 创建新组

你可以根据需求创建新组。Linux 会自动为每个新组分配组 ID（`group ID`）。不过，在创建组时也可以手动为组应用 ID。让我们先学习创建用户组。

执行以下步骤创建组：

1. 从用户管理器窗口中选择“组”（`Groups`）选项卡（图 Linux-9.16）。组的详细信息显示在用户管理器窗口（图 Linux-9.17）。
2. 点击工具栏上的“添加组”（`Add Group`）按钮（图 Linux-9.17）。

![](img/12ecf7a0767a6080881fb04f59162115_186_1.png)

图 Linux-9.16

图 Linux-9.17

出现“创建新组”（`Create New Group`）对话框（图 Linux-9.18）。

3. 在“组名”（`Group Name`）文本中输入组名。在我们的案例中，我们输入 `Sales` 作为组名（图 Linux-9.19）。
4. 勾选“手动指定组”（`Specify group manually`）复选框以手动输入 ID。在我们的案例中，我们使用默认值 `504`（图 Linux-9.19）。
