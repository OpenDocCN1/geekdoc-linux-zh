## enable, disable — 启用/禁用打印机

### 概要

```
/usr/bin/enable printer ...
/usr/bin/disable [-c | -W] [-r [reason]] printer
```

## 描述

`enable` 命令激活由 `lp` 提交的打印机。`disable` 命令停用由 `lp` 提交的打印机。使用 `lpstat` 查看打印机状态。`enable` 和 `disable` 命令仅影响系统。

## 选项

- `-c` 取消正在打印的请求。如果是远程的，`-c` 选项将被忽略。
- `-i` 忽略从 shell 继承的环境。将环境限制为参数指定的的环境。如果是远程的，`-c` 选项将被忽略。
- `-r [reason]` 指定停用的原因。
- `-W` 等待已打印的请求完成后再禁用。如果是远程的，`-W` 选项将被忽略。

### 操作数

- `printer` 要启用或禁用的打印机名称。使用 atomic 名称指定。

## env — 设置调用环境

### 概要

```
/usr/bin/env [-i] [name=value] ... [command]]
/usr/xpg/bin/env [-i] [name=value] ...
```

## 描述

不带参数的 `env` 命令显示当前环境变量。带有选项的 `env` 命令获取当前环境，根据参数进行修改，然后调用指定的命令。如果你没有指定命令参数，则结果将写入标准输出，以 `name=value` 对的形式。

```
/usr/bin/env
```

如果 `env` 执行命令，它使用默认 shell `/sh` (参见 `sh(1)`)。

## `/usr/xpg/bin/env`

`usr/xpg/bin/env` 是 POSIX 标准的 `/usr/bin/env` 版本。参见 `standards(5)`。

如果 `env` 执行命令，它使用 `/usr/xpg/bin/sh`，这等同于 `ksh` (参见 `ksh(1)`).

## 选项

- `-i` 忽略从 shell 继承的环境。将环境限制为参数指定的。

### 操作数

- `command` 要调用的命令名称。如果命令是任何内置命令，结果是未定义的。
- `arg` 传递给调用命令的字符串。

## 示例

以下示例使用不带任何参数的 `env` 命令显示环境变量的当前值。为了节省空间列表已被截断。

```
castle% env
PATH=/usr/openwin/bin:/usr/dt/bin:/bin:/usr/bin/sbin:/usr/ucb:/etc
usr/proc/bin:/opt/hpnp/bin:/usr/local/games::
castle%
```

以下示例将 `env` 命令的输出通过管道传递 `grep`，搜索 `MANPATH` 环境变量的值。

```
castle% env | grep MANPATH
MANPATH=/usr/openwin/share/man:/usr/openwin/man:/usr/share/man:/usr/dt/
share/man:/usr/dt/man:/usr/opt:/usr/SUNWrtvc/man:/usr/opt/hnpman
castle%
```

# eqn, neqn, checkeq — 排版数学测试

### 概要

`/usr/bin/eqn [-dxy] [-fn] [-pn] [-sn] [file] ...`
`/usr/bin/neqn [file] ...`
`/usr/bin/checkeq [file] ...`

## 描述

`eqn` 和 `neqn` 是辅助描述方程的语言处理器。`eqn` 是 `troff(1)` 的预处理器，用于可以打印 `troff` 输出的设备。`neqn` 是 `nroff(1)` 的预处理器，用于终端。用法几乎总是是：

```
castle% eqn file ... | troff
castle% neqn file | nroff
```
