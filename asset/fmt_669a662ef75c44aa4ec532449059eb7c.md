## whatis 和 appropos 命令

可以使用 `whatis` 命令获取命令说明的简短索引，如下所示：

```
[your_prompt] whatis ls
ls (1) - list directory contents
```

这显示了命令的简短信息，man 集合中的第一个章节包含一个相应的页面。

如果你不知道从何开始以及要制作哪个页面，`appropos` 会提供更多信息。假设你不知道如何启动浏览器，可以输入以下命令：

```
another_prompt> appropos browser
Galeon (galeon) (1) - gecko-GNOME web browser
lynx (1) - 一个用于万维网的通用分布式浏览器
cftp (1) - 用于文件传输协议的浏览器程序
opera (1) - 图形化 浏览器
pilot (1) - Pine Composer 风格的简单文件系统浏览器
pinfo (1) - 基于 curses 的 lynx 风格 info 浏览器
primpo (1) - 基于 curses 的 lynx 风格 info 浏览器
views (1x) - Xt 的图形化类浏览器
```

输入后，你会发现你的机器上有许多相关内容：不仅有浏览器，还有用于文档的 FTP 浏览器。如果你有相应的处理编写浏览器程序的 man 页。通常情况下，一个在某个章节中有 man 且带有“(1)”的命令适合用户尝试的。执行上述 `appropos` 的用户随后可能会尝试启动 `galeon`、`lynx` 或 `opera` 命令，这些命令显然与浏览万维网有关。

## --help 选项

大多数 GNU 命令支持 `--help`，它会提供关于如何使用该命令的简短说明以及可用选项列表。以下是 `cat` 命令使用此选项的输出：

```
userprompt@host: cat --help
Usage: cat [OPTION] [FILE]...
Concatenate FILE(s), or standard input, to standard output.

-A, --show-all             equivalent to -VET
-b, --number-nonblank      显示非空输出行
-e, --show-ends             equivalent to $ at end of each line
-n, --number               显示所有输出行
-s, --squeeze-blank         连续空行多于一个空行
-t, --vt                    equivalent to -vt
-T, --show-tabs            显示 TAB 字符为 ^I (忽略)
-v, --show-LFD               use ^ and M- notation,
  --help                      显示帮助并退出
  --version                   输出版本信息并退出
```

在无 FILE 或当 FILE 为 - 时，读取标准输入。

## 练习题

| 命令 | 含义 |
|---|---|
| `man` | 读取命令的帮助页。 |
| `passwd` | 更改你的密码。 |
| `pwd` | 显示当前工作目录。 |

我们学习的大部分内容是通过犯错和观察事物是如何出错的获得的。这些练习是为了让你阅读一些错误信息。你完成这些练习的顺序很重要。

不要忘记在命令行中使用 Bash 特性：尝试通过输入尽可能少的字符来完成练习！

## 新密码

除非你将密码再次改回练习之前的样子，否则它将始终是 "P6p3.aa!"。在完成此练习后更改你的密码！

请注意，某些系统可能不允许循环使用密码，即在一定时间内或经过一定次数的密码更改后不允许恢复原始密码，或者两者兼有。
