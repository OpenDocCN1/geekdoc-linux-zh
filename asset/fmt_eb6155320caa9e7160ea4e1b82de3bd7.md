## 使用点串指示进度

最简单的进度指示形式是每 5 到 20 秒在屏幕上打印一个点。它简单、干净且非常容易实现。和每个脚本一样，我们从开始：

```bash
echo "\c"
```

为了制作一系列点，我们将此单独命令放在循环中，并在每个点之间加入一些睡眠。我们将使用无限循环的 `while` 循环，每个点之间睡眠 10 秒。

```bash
while true
do
    echo "\c"
    sleep 10
done
```

## 使用点串、旋转线或倒计时零的进度指示

给用户提供程序正在运行的反馈。例如，如果我们正在运行备份脚本并想使用这种方法指示进度，我们将此循环放在后台运行并保存进程 ID (`PID`)，以便在备份脚本完成后杀死后台进程。首先，我们将只把这个 `while` 循环放在后台运行，或者我们可以创建一个带有此循环的函数。方法包括：

- 一系列点
- 旋转线
- 倒计时到零计数器

列表 4.1 在后台运行循环。

为了实现后台循环，注意我们在 `while` 循环的结束处（`done` 之后）只放了一个 `&`。下一行使用 `$!` 运算符保存上一个后台进程的 PID，`BG_PID=$!`。后台循环开始让点跳动，然后在前台启动备份脚本 `/usr/local/bin/my_backup.ksh`。当备份脚本完成后，我们使用 `kill` 命令通过指定的 `$BG_PID` 杀死后台作业以停止点。

```bash
while true
do
    echo "\c"
done &

BG_PID=$$

/usr/local/bin/my_backup.ksh

kill $BG_PID
```

```bash
function dots
{
    while true
    do
        echo ".*c"
    done
}

######################################
###### Begin of Main #######
######################################

dots &=$!

BG_PID=$!

/usr/local/bin/my_backup.ksh

kill $BG_PID
```

**Listing 4.2** 使用后台函数。

列表 4.2 中的脚本和函数实现了相同的任务，但它们使用的是后台函数，而不是将 `while` 循环放在后台。我们仍然通过 `$!` 捕获 `dots` 函数的 PID（进程 ID），因此我们可以在像上一个示例中所做的那样，在备份脚本完成后 `kill`（杀掉）该函数。我们也可以将循环放在一个独立的 shell 脚本中并在后台运行外部脚本，但对于三行代码来说，这样做太大材小用了。

## 使用旋转线指示进度

如果一系列点太无聊了，那么我们就可以使用旋转线作为进度指示器。为了旋转线条，我们将再次使用 `echo` 命令，但这次我们需要稍微更多的光标控制。这种方法要求我们按顺序显示正斜杠 `/`、连字符 `-`、反斜杠 `\`、以及管道符 `|`，然后重复该过程。为了让这一字符序列无缝地出现，我们需要退格到最后一个字符并将其删除，或者用新字符覆盖它，使线条看起来像在旋转。我们将在 `while` 循环内部使用 `case` 语句，如列表 4.3 所示。

```bash
function rotate
{
# PURPOSE: 此函数用于向用户提供一些反馈，说明
# "某些东西"正在运行。它提供了一个圆圈旋转的线条。
# 此函数作为后台进程启动。将它的 PID
# 赋值给变量：
#
    rotate & # 启动
    ROTATE_PID=$! # 获取上一个后台作业的 PID
#
    # 在执行结束时，只需杀死 $ROTATE_PID
    # 进程即可。我们还需要对留下的 rotate 输出行进行快速的“清理”。
#
    # FROM THE SCRIPT:
    kill -9 $ROTATE_PID
    echo "*\b\c"

INTERVAL=1
# “旋转”之间的睡眠时间
TCOUNT="*0"
# 对于每个 TCOUNT，线条旋转一个增量

while
# 无限循环...直到此函数被杀死

    TCOUNT=$(expr $TCOUNT + '1') # 增加 TCOUNT

    case $TCOUNT in
        "1") echo "-*'\b\c"
            sleep $INTERVAL
            ;;
        "2") echo "\\"*\b\c"
            sleep $INTERVAL
            ;;
        "3") echo "*|\b\c"
            sleep $INTERVAL
            ;;
        "4") echo "*/\b\c"
            sleep $INTERVAL
            ;;
        *) TCOUNT="0"; # 将 TCOUNT 重置为 "0"。
esac
done
# End of Function - rotate
```

列表 4.3 旋转函数。

在列表 4.3 中，我们首先定义了一个更新之间的睡眠间隔。如果我们没有一些睡眠时间，系统的负载将会变得明显。我们只是想给最终用户提供一些反馈，而不是增加系统负担。屏幕更新之间至少需要一秒。我们启动了一个无限 `while` 循环，并使用 `TCOUNT` 变量来控制在间隔期间显示旋转线条的哪部分。注意，每当我们 `echo` 旋转线条的一部分时，我们还会用 `\b` 将光标后退，并用 `\c` 在同一行继续；这两者都是必要的。这样下一次迭代就会用新字符覆盖之前的字符，然后我们再次后退光标并在同一行继续。这一系列字符产生了旋转线条的视觉效果。

我们使用该函数的方式与 4.2 中使用 `dots` 函数的之前的示例相同。我们在后台运行该函数，使用 `$` 操作符保存后台函数的 PID，启动我们的耗时任务，并在任务完成后杀死后台的 `rotate` 函数。我们可以直接将 `while` 循环放在后台而不使用函数。无论在何种情况下，当旋转线被杀死时，我们都需要清理屏幕上的最后一个字符。为了进行清理，我们只需后退光标并用空格覆盖最后一个字符。（参见列表 4.4）。
