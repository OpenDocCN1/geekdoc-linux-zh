## 6.61. Less-551

Less 软件包包含一个文本查看器。

预计编译时间：少于 0.1 SBU
所需磁盘空间：4.1 MB

### 6.61.1. 安装 Less

为编译准备 Less：

```
./configure --prefix=/usr --sysconfdir=/etc
```

配置选项的含义：

`--sysconfdir=/etc`
该选项告诉由该包创建的程序去 `/etc` 查找配置文件。

编译软件包：

```
make
```

此软件包不附带测试套件。

安装软件包：

```
make install
```

### 6.61.2. Less 的内容

已安装程序：
`less`, `lessecho` 和 `lesskey`

### 简要说明

- `less` | 文件查看器或分页器；它显示给定文件的内容，允许用户滚动滚动、查找字符串并跳转到标记
- `lessecho` | 在 Unix 系统上需要扩展文件名中的元字符（如 `*` 和 `?`）
- `lesskey` | 用于指定 less 的按键绑定

## 6.62. Gzip-1.10

Gzip 软件包包含用于压缩和解压缩文件的程序。

预计编译时间：0.1 SBU
所需磁盘空间：20 MB

### 6.62.1. 安装 Gzip

为编译准备 Gzip：

```
./configure --prefix=/usr
```

编译软件包：

```
make
```

要测试结果，执行：

```
make check
```

在 LFS 环境中已知两个测试会失败：`help-version` 和 `zmore`。

安装软件包：

```
make install
```

移动一个需要位于根文件系统上的程序：

```
mv -v /usr/bin/gzip /bin
```
