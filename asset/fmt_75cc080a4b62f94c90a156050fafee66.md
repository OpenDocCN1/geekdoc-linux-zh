### exdbm
`Xcode` 数据库管理器。`Xcode` 数据库管理器是一个基于 ASCII 的结构化库。`Exdbm` 还可以管理 `Exode` 编辑器的配置文件。库用户使用存储在内存中的表树，优先考虑速度而非内存消耗。它的效率基于所管理的数据库可以包含数千条目这一事实。注意，`Exdbm` 是一个专用的配置库，可以用于许多与 `Exode` 项目无关的应用程序中。有关 `exode` 的信息请访问 http://simplicity/exode。来自 Debian 3.0. apt。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### EXE
`/exe/` 或 `/EXE/`。可执行文件。某些操作系统（特别是 MS-DOS, VM 和 TWENEX）使用该扩展名来标记文件。这种用法在程序员中也是正式的。来自术语词典。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### executable
任何可以在计算机上“运行”的程序。要使一个程序可执行，它首先必须通过（通常是编译器）翻译成特定计算机的机器语言。来自 QEDIC。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### Executable program
准备在给定计算机上运行的程序。要使一个程序可执行，它必须拥有更改目录权限，或者能够将该目录名称包含在命令行路径中。Linux Guide |FirstLinux。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### execute
运行程序。在命令行上，你可以使用 `x` 添加或删除文件的执行权限。执行算法或程序中的指令。来自 QECUID。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### Execute
`'execute'` 的同义词，名词。1. 操作系统系统的命令解释器（参见 `shell`）；这里用于大型主机，源自 UNIVAC 的古老 `EXEC`。在 IBM 和 VM/CMS 中，不使用等同于 shell 命令 `'exec'` 的函数缩写。对于黑客来说，`'exec'` 永远是一个动作，而不是人。来自术语词典。

### exim
MTA（邮件传输代理）比 `sendmail` 更容易配置。它是 `sendmail/smtp` 的无缝替代品。功能包括拒绝已知垃圾邮件连接以及极其高效的队列处理。来自 Debian 3.0 APT。

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### exim-ls
支持 TLS (SSL) 的 Exim 邮件，比 `sendmail` 更容易配置。它是 `sendmail/smtp` 的无缝替代品。功能包括拒绝已知垃圾邮件连接以及极其高效的队列处理。此版本的 Exim 使用 OpenSSL 编译，通过 SSL 进行安全的 SMTP。来自 Debian 3.0 APT。
