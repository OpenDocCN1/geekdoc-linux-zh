`SloppyFocus`

```
#
# 现在，我们配置一些窗口。所有窗口的

#
```

`Style "*" NoIcon`

# 在此处定义了若干函数。每个函数都会有注释。
# 此函数要么调整窗口大小（拖动时），要么置顶/置底
#（点击时）。

```
Function "Resize-or-RaiseLower"
RaiseLower "Click"
Resize     "Motion"
EndFunction
```

# 此函数要么最大化并置顶（点击时），要么
# 最大化并置底（双击时）。

```
Function "Maximize-and-Raise-or-Lower"
Maximize    "Click"
Raise      "Click"
Maximize    "DoubleClick"
Lower      "DoubleClick"
EndFunction
```

# 此函数要么水平方向最大化并置顶（点击时），
# 或者水平方向最大化并置底（双击
# 点击时）。

```
Function "Maximize-Horizontal-and-Raise-or-Lower"
Maximize    "Click" 100 0
Raise      "Click"
Maximize    "DoubleClick" 100 0
Lower      "DoubleClick"
EndFunction
```

# 此函数的功能与上一个函数相同，但
# 是垂直方向而非水平方向。

```
Function "Maximize-Vertical-and-Raise-or-Lower"
Maximize    "Click" 0 100
Raise      "Click"
Maximize    "DoubleClick" 0 100
Lower      "DoubleClick"
EndFunction
```

# 此函数在拖动时移动，点击时置顶/置底，
# 或双击时置底。
