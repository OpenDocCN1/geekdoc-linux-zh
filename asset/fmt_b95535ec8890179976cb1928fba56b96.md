## 安装 Linux 内核二进制文件

按照以下步骤安装新的Linux内核二进制文件。当你需要配置并重建内核时，请参考第1031页的“Rebuilding the Linux Kernel”，而不是安装一个新的预发布内核二进制文件。重建内核比安装新内核要复杂。

- 1. 使用`-i`选项运行`rpm`来安装新内核。不要使用`-U`选项，因为你正在安装一个与旧内核名称不同的内核：你不是在升级现有内核。
- 2. 将新内核信息添加到`/etc/lilo.conf`（并运行`lilo`）或`/etc/grub.conf`。修改`grub.conf`后不需要运行`grub`。

> 16. 虽然你可以作为非特权用户运行`rpm`，但在安装或卸载期间你将没有权限写入必要的目录，导致安装/卸载失败。在查询期间，你不需要这种权限，因此你可以（也应该）作为非特权用户工作。

- 3. 在移除旧内核之前，确保新内核工作正常。要验证新内核是否可用，请使用新内核重启系统。
- 4. 通过删除包含发行号（如果适用，还包括`EXTRAVERSION [number [1036]`）的`/boot`或`(root)`下对应文件来移除旧内核。从`lilo.conf`或`grub.conf`中删除关于旧内核的信息。记住如果你修改了`lilo.conf`，请运行`lilo`。你可能想在移除旧内核之前等一会儿，以确保新内核没有问题。

## 非 rpm 软件

大多数不以`rpm`格式提供的软件都带有关于如何配置、构建（如有必要）和安装它们的详细说明。某些二进制发行版（那些包含可在Red Hat上运行的预编译可执行文件）要求你从系统的根目录解包软件。某些较新的应用程序包包含了将自身自动安装到`/opt`下方层级结构中的脚本，其中在`/opt`子目录下有以软件包命名的文件夹，以及在`/opt/bin`或`/opt/package/bin`中的可执行文件。这些脚本是Red Hat较新的新增，但对Solaris用户来说很熟悉。

其他软件包允许你选择解包的位置。由于适用于GNU/Linux的软件由许多不同的人开发，因此安装方法没有统一的标准。当你获取本地软件时，应以尽可能一致且可预测的方式将其安装到你的系统中。Red Hat的默认文件结构在`/usr/local`下有一个目录树，用于存放二进制可执行文件（`/usr/local/bin`）、手册页（`/usr/local/man`）等。为了防止以后产生混淆，并避免在将来安装标准软件升级时覆盖或丢失软件，请避免在标准系统目录（如`/usr/bin`）中安装非标准软件。确保你系统上的用户知道在哪里可以找到本地软件，并记住在每次安装、更改或移除本地工具时都发布公告。

## GNU Configure 和构建系统

GNU Configure和构建系统可以轻松地构建以源码形式分发的程序（见developer.gnome.org/tools/build.html中的`autoconf`）。这个二步过程除了shell、`make`和`gcc`（GNU C编译器）之外不需要特殊工具。这两个步骤中你都不需要root特权权限。

第17章 Red Hat Linux管理

以下示例假设你已经在工作目录中下载了GNU chess (www.gnu.org/software/chess/chess.html)。首先，你需要解包并解压缩它，进入新目录：

```bash
$ tar -xvzf chess*
gnuchess-5.03/
gnuchess-5.03/book/
gnuchess-5.03/book/README
...
$ cd gnuchess-
```

在阅读`README`和`INSTALL`文件后，执行两个步骤的第一步：运行`configure`脚本，它会获取系统信息并生成`Makefile`：

```bash
$ ./configure
checking for a BSD compatible install... /usr/bin/install -c
checking whether build environment is sane... yes
checking for mawk... make
checking whether make sets ${MAKE}... yes
checking for gcc... gcc
checking for C compiler default output... aout
checking whether
```
