# DoS (拒绝服务)

一种目的是拒绝使用系统的漏洞利用：使程序或整个系统崩溃或挂起。例如：某些类别的 DoS：流量洪水淹没了互联网连接。因为被攻击的是互联网本身，因此没有受害者可以停止攻击。防火墙可能会阻止洪泛进一步扩散，但防火墙前的互联网连接仍然处于过载状态。应用程序洪水或“炸弹”通过大量事件淹没程序。允许攻击的防火墙不能简单地阻塞洪水，而是允许所有其他流量。受攻击的常见服务有 IRC、HTTP 和电子邮件 (SMTP)。远程系统/崩溃：历史上，有很多可以被远程崩溃的机器。这种攻击导致系统内的 TCP/IP 栈导致崩溃或挂起。这会影响运行在系统上的所有软件。例如：著名的 DoS 包括：死亡之 ping (Ping of Death)，该漏洞利用通过向受害者发送非法分片的包在 1995 年导致了大多数机器崩溃。从 2000 年以来，系统受到 DoS 变体的影响，例如 Windows 系统的 Jol2 攻击、SYN 洪水、受害者重叠 ping。跨 TCP 连接的 OOB/UR 数据。重叠的 IP 分片不应该发生。这意味着没有经过测试的代码来处理它们——因此存在许多漏洞。Land (literra) 可以伪造从受害者机器发送到受害者的包，导致其产生无限循环回复。`tarda` 一个包含许多流行 DoS 攻击的工具。DoS 的常用术语是 "`nuke`“（核），”`nukes`“ 是聊天室里的小子互相使用的那些 DoS 漏洞利用。如今，“`nukes`”是指来自 Hacking-Lexicon 的 DoS 漏洞利用 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
