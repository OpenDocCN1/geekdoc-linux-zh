
虽然我们刻意避免使用已有的命令来给别名起名，但这样做并不罕见。这通常是为了对每个常用命令的每次调用应用一个常用的选项。例如，我们之前看到过`ls`命令经常被别名为以添加颜色支持。

```
@me@linux~$ type ls
ls is aliased to 'ls --color=tty'
```

要查看环境变量中定义的所有别名，请不带参数使用`alias`命令。这里是 Fedora 系统上默认定义的一些别名。尝试弄清楚它们都是做什么的。

```
@me@linux~$ alias
alias 1.='ls -d .* --color=tty'
alias 1l='ls --color=tty'
alias 1s='ls --color=tty'
```

在命令行上定义别名有一个小问题：它们会在你的 shell 会话结束时消失。在第 11 章中，我们将看到如何将自己的别名添加到每次登录时都建立环境的文件中，但现在，请享受我们已经在 shell 编程世界中迈出的虽然微小的一步的事实吧！

## 总结

既然我们已经学会了如何查找命令的文档，请查阅我们目前为止遇到的所有命令的文档。研究可以使用哪些额外选项并尝试它们吧！

# 第6章 重定向

![](img/0cf46e6370424e4fc9bc72ba090b1e02_80_0.png)

在本节中，我们将释放可能是命令行中最酷的功能之一。它被称为 I/O 重定向。“I/O”代表输入/输出，通过此功能，你可以重定向命令的输入和输出到或从文件，还可以将多个命令连接成强大的流水线。为了展示这项功能，我们将引入以下命令：

- `cat` 合并文件
- `sort` 排序文本行
- `uniq` 报告或忽略重复行
- `grep` 打印匹配模式的行
- `wc` 打印每个文件的换行符、单词和字节数
- `head` 输出文件的第一部分
- `tail` 输出文件的最后部分
- `tee` 从标准输入读取并写入标准输出和文件

## 标准输入、输出和错误

我们使用过的许多程序都会产生某种输出。这种输出通常包含两种类型。

- 程序的结果；即程序设计用于产生的数据
- 状态和错误消息，告诉我们程序运行得如何

如果我们看像`ls`这样的命令，可以看到它显示了它的输出。这种输出通常包含两种类型。
