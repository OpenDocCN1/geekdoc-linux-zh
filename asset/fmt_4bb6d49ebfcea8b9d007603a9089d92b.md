
## 创建大文件用于计时测试

在介绍每种解析文件的方法之前，我想向你展示一个小脚本，你可以用它创建一个具有你想要处理精确行数的文件。每行创建的字符数可以通过修改 shell 脚本中的 `LINE_LENGTH` 变量来更改，默认值为 80。该脚本也使用了 `while` 循环，但这次是为了构建文件。要创建一个具有 7,500 行的文件，将行数作为参数传递给 shell 脚本名。使用列表 2.1 中的 shell 脚本，你可以通过以下语法创建一个 7,500 行的文件：

```
## mk_large_file.ksh 7500
```

完整的 shell 脚本显示在列表 2.1 中。

```bash
#!/bin/ksh
#
# SCRIPT: mk_large_file.ksh
## AUTHOR: Randy Michael
## DATE: 03/15/2002
## REV: 1.2
## PURPOSE: 此脚本用于创建一个
#具有指定行数的文本文件
# set -n 注释以检查语法
# set -x 注释以调试此脚本
################################################
## 在此处定义函数
################################################

function usage {
    echo "用法..."
    echo "用法: $SCRIPT_NAME <lines_to_create>"
}
################################################
## 检查参数数量
################################################

if (( $# != 1 )) #
then
    usage 
    exit 1
fi

################################################
## 在此处定义文件和变量
################################################

LINE_LENGTH=80 # 每行的字符数

OUT_FILE=/scripts/bigfile # 要创建的文件
```

列表 **2.1** `mk_large_file.ksh` shell listing。（续）

```bash
>OUT_FILE                              # 初始化为空大小文件
SCRIPT_NAME=$(basename $0)             # 提取脚本名称
TOTAL_LINES=$1                        # 创建的总行数
LINE_COUNT=0                          # 行计数
CHAR=$                                # 写入文件的字符

######################################
## 主程序开始
######################################

while ((LINE_COUNT < TOTAL_LINES )) # 由指定的
do
    CHAR_COUNT=0                      # 每新行初始化计数器为零

    while ((CHAR_COUNT < LINE_LENGTH )) # 每行固定长度
    do
        echo "$CHAR" >> $OUT_FILE    # 输出单个字符
        ((CHAR_COUNT = CHAR_COUNT + 1)) # 计数器加1
    done
    ((LINE_COUNT = LINE_COUNT + 1)) # 行计数加1
    echo >>$OUT_FILE                 # 输出换行符
done
```

列表 **2.1** `mk_large_file.ksh` shell listing。（继续）

`mk_large_file.ksh` 脚本产生的每行长度都相同。用户将总行数作为参数传递给 shell 脚本。

## 逐行解析文件的 12 种方法

以下段落描述了多年来我常见的 12 种解析技术。我将它们全部整合在一个 shell 脚本中，以函数的形式分离。在定义函数之后，我执行每个方法（或函数），同时使用 `time` 命令对执行进行计时。为了获得准确的结果，我使用了一个包含 7,500 行每行长度相同的文件（我们使用 `mk_large_file.ksh` 脚本构建了这个文件）。对于 shell 逐行解析一个 7,500 行的文件是一个巨大的文件，我的 Linux 机器快到需要一个大文件才能得到大于零的时间！

现在是来看这 12 种逐行解析文件的方法了。每个方法都使用 `while` 语句创建一个循环。循环中的两个命令是 `cat SLINE`（输出读取的每一行）和一个空操作（由 `:`（冒号）字符表示）。每种方法的不同之处在于 `while` 循环的使用。

## 逐行处理文件的十二方法

### 方法 1：`cat $FILENAME | while read LINE`

让我们从我看到的常用方法开始，即使用 `cat` 读取文件并将输出通过管道交给 `while read` 循环。在每次循环迭代中，单行文本会被读取到变量 `LINE` 中。这个连续循环将一直运行，直到文件的所有行都逐一处理完毕。

管道是这种方法受欢迎的原因。直观上显易见，管道中 `process` 命令的输出被用作管道中下一个命令的输入。例如，如果我执行 `df` 命令来列出文件系统统计信息，而它滚出了屏幕范围，我可以使用管道将输出发送给 `more` 命令，如下：

```
df | more
```

当执行 `df` 命令时，管道会将输出存储在一个临时系统文件中。然后这个临时系统文件被用作 `more` 命令的输入，允许我逐页/逐行地查看 `df` 命令的输出。我们将管道到 `while` 循环的方式也是类似的；`cat` 命令的输出被用作 `while` 循环的输入，并在每次循环迭代中读取到 `LINE` 变量中。查看列表 2.2 中的完整函数。

```
function while_read_LINE
{
  cat $FILENAME | while read LINE
do
    echo "$LINE"
  done
}
```

列表 2.2 `while_read_LINE` 函数列表。

这些测试每一个都被创建为一个函数，以便我们使用 shell 脚本对每个方法进行计时。如果你愿意，也可以使用 `()` 类型的函数定义，如列表 2.3 所示。

```
while_read_LINE ()
{
  cat $FILENAME | while read LINE
do
    echo "$LINE"
  done
}
```

## 第二章

无论你是否使用函数 `()` 技术，结果都是相同的。我倾向于更多使用函数方法，这样当有人编辑脚本时，他们知道哪个代码块是函数。对于初学者来说，`function` 这个词有助于理解 shell 脚本。循环变量 `$FILENAME` 位于 shell 脚本的主体。我在 `echo` 语句之后添加了空操作 `:`。空操作 (`:`) 什么都不做，但它总是返回 0 退出码。我使用空操作作为占位符，这样你可以将函数提取并粘贴到你的一个脚本中。如果你删除 `echo` 语句并留下空操作，`while` 循环不会失败；然而，循环将什么都不做。

### 方法 2：从底部 read $FILENAME

你现在进入我最喜欢的解析文件的方法之一。我们仍然使用 `while read LINE` 语法，但这次我们从底部向循环提供数据，而不是使用管道。你会发现这是处理文件每一行最快的方法之一。第一次使用它时看起来有点奇怪，但它运行得非常好。查看列表 2.4，我们将在最后介绍该函数。

```
function while_read_LINE_bottom
{
while read LINE
do
    echo "$LINE"
:
done < $FILENAME
}
```

**列表 2.4** `while_read_LINE_bottom` 函数列表。

我们对列表 2.3 中的函数进行了一些修改。删除了到管道的 `cat $FILENAME`。然后我们使用输入重定向从循环的底部读取文件。通过在 `done` 循环终止符之后使用 `< $FILENAME` 符号，我们从底部向循环提供数据，这极大地增加了循环的输入吞吐量。当我们使用这种技术时，这种方法将处于列表的前列。

### 方法 3：`while_line_LINE_Bottom`

与 `read` 命令一样，你可以使用相同的循环技术在 `while` 循环中直接使用 `line` 命令。在这个函数中，我们使用以下语法：

```
while line LINE
```
