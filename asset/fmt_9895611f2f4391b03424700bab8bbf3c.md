
现在当 shell 执行 `break` 命令时，外层循环停止了。

## continue 命令

`continue` 命令是一种提前停止循环内部处理的方法，但不会完全终止循环。这允许你在循环内部设置条件，使 shell 不执行该条件后的命令。这里有一个在循环中使用 `continue` 命令的简单示例：

```bash
$ cat test21

#!/bin/bash

# using the continue command

for (( varl = 1; varl < 15; varl++ ));
do
  if [ $varl -gt 5 ] && [ $varl -lt 10 ];
  then
    continue
  fi
  echo "Iteration number: $varl"
done
./test21
Iteration number: 1
Iteration number: 2
Iteration number: 3
Iteration number: 4
Iteration number: 5
Iteration number: 10
Iteration number: 11
Iteration number: 12
Iteration number: 13
Iteration number: 14
```

当满足 `if-then` 语句条件时（值大于 5 且小于 10），shell 执行 `continue` 命令，跳过循环中剩余的命令，但保持循环继续。当 `if-then` 条件不再满足时，情况就会恢复正常。

你可以在 `while` 和 `until` 循环中使用 `continue` 命令，但要务必非常小心你的操作。记住，shell 执行 `continue` 命令时会跳过剩余的命令。如果你在这些条件之一中递增测试变量，就会发生糟糕的事情：

```bash
$ cat badtest3

#!/bin/bash

# improperly using the continue command in a while loop

varl=0
while echo "while iteration: $varl";
[ $varl -lt 15 ]
do
  if [ $varl -gt 5 ] && [ $varl -lt 10 ]
  then
    continue
  fi
  echo " Inside iteration number: $varl"
  varl=$[$varl + 1]
done
$ ./badtest3 | more
while iteration: 0
  Inside iteration number: 0
while iteration: 1
  Inside iteration number: 1
while iteration: 2
  Inside iteration number: 2
while iteration: 3
  Inside iteration number: 3
while iteration: 4
  Inside iteration number: 4
while iteration: 5
  Inside iteration number: 5
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
while iteration: 6
$
```

你可能需要确保将此脚本的输出重定向到 `more` 命令以便停止操作。一切看起来运行良好，直到满足 `if-then` 条件，shell 执行 `continue` 命令。当 shell 执行 `continue` 命令时，它跳过了 `while` 循环中剩余的命令。不幸的是，那正是你在 `while` 测试命令中递增 `$var` 计数变量的地方。这意味着变量没有被递增，正如你从持续显示的输出中看到的。

与 `break` 命令一样，`continue` 命令允许你通过命令行参数指定要继续执行的哪一层循环：

```
continue n
```

其中 `n` 定义了继续的循环级别。这里是一个继续外层 `for` 循环的示例：

```bash
$ cat test22

#!/bin/bash

# continuing an outer loop

for (( a = 1; a <= 5; a++ ))
do
  echo "Iteration $a:"
  for (( b = 1; b < 3; b++ ))
    do
      if [ $a -gt 2 ] && [ $a -lt 4 ]
      then
        continue 2
      fi
      var3=$[$a * $b]
      echo "The result of $a * $b is $var3"
    done
done
./test22
Iteration 1:
The result of 1 * 1 is 1
The result of 1 * 2 is 2
Iteration 2:
The result of 2 * 1 is 2
The result of 2 * 2 is 4
Iteration 3:
Iteration 4:
The result of 4 * 1 is 4
The result of 4 * 2 is 8
Iteration 5:
The result of 5 * 1 is 5
The result of 5 * 2 is 10
```

该 `if-then` 语句：

```bash
if [ $a -gt 2 ] && [ $a -lt 4 ]
then
  continue 2
fi
```

使用了 `continue` 命令来停止处理循环内部的命令，但继续外层循环。注意脚本输出中，值为 3 的迭代没有处理任何内层循环语句，因为 `continue` 命令停止了处理过程，但它继续了外层循环的执行。

## 处理循环的输出

最后，你可以对 shell 脚本中管道 `pipe` 或重定向循环的输出。你可以通过在 `done` 命令的末尾添加处理命令来实现：

```bash
for file in /home/rich/*
do
  if [ -d "$file" ]
  then
    echo "$file is a directory"
  elif
    echo "$file is a file"
  fi
done > output.txt
```

不是在显示器上重定向结果，而是 shell 将 `for` 命令的结果重定向到文件 `output.txt`。

考虑以下将 `for` 命令的输出重定向到文件的示例：

```bash
$ cat test23

#!/bin/bash

# redirecting the output to a file

for (( a = 1; a < 10; a++ ))
do
  echo "The number is $a"
done > test23.txt

echo "The command is finished."
./test23
The command is finished.
$ The number is 1
The number is 2
The number is 3
The number is 4
The number is 5
The number 6
The number is 7
The number is 8
The number is 9
$
```

shell 创建了文件 `test23.txt` 并仅将 `for` 命令的输出重定向到文件。shell 像往常一样在 `for` 命令之后显示 `echo` 语句。

这种技术同样适用于将循环的输出管道到另一个命令：

```bash
$ cat test24

#!/bin/bash
```
