# fnlist — 显示 FNS 上下文中绑定的名称和引用

### 概要

`/usr/bin/fnlist [-Alv][composite-name]`

## 描述

`fnlist` 显示在 `composite-name` 上下文中定义的联邦命名服务 `FNS` 名称和引用。
如果没有指定 `composite-name`，则显示默认的初始上下文，如下例所示。

```
castle%

_myorgunit

_orgunit

...

_x500

_thisens

myens

thisens

org

orgunit

dns

myorgunit

thisorgunit

_thisorgunit

_myens

castle%
```

## 选项

`-A` 咨询权威源获取信息。
`-l` 显示在 `composite-name` 上下文中绑定的引用以及名称。如果没有此选项，则仅显示名称。
`-V` 详细显示引用。对于 `_onc_fn*` 引用，此选项用于推导出 NIS+ 表的名称，该表存储了 `composite-name` 上下文中绑定的每个名称引用。

## 参数

`composite-name`

一个联邦命名服务命名对象。复合名称类似于 UNIX 文件名，取决于创建的子上下文。

带有有效 `composite-name` 参数的命令示例：

```
castle% fnlist thisorgunit

castle% fnlist thisorgunit/service

castle% fnlist thisorgunit/service/printer
```

当 FNS 部署时，复合名称特定于部署的站点。

## 示例

在以下示例中，不带参数的命令提供了初始上下文的引用和地址类型列表。

```
castle% fnlist -1

name: _myorgunit

Reference type: onc_fn_nsid

Address type: onc_fn_files

  context type: namespace id
```

```
name: ...

Reference type: fn_global

Address type: initial
```

```
name: _orgunit

Reference type: onc_fn_organization

Address type: onc_fn_files

  context type: organization
```

```
name: _x500

Reference type: fn_global

Address type: x500

Warning: empty X.500 reference address

length: 0

data:
```

```
name: _thisens

Reference type: onc_fn_enterprise

Address type: onc_fn_files

  context type: enterprise root
```

...

`castle%` 在接下来的示例中，如果你指定了用户上下文（即 `composite-name = user/`），FNS 必须先使用 `fncreate(1M)` 进行部署，并使用 NIS、NIS+ 或 files 命名服务之一。如果 FNS 未经部署，则没有用户上下文，命令将以 "Name not found" 错误消息失败。

以下命令显示了 `user/` 上下文中绑定的名称。

```
castle% fnlist user/
```

以下命令显示了 `user/` 上下文中绑定的名称和引用。

```
castle% fnlist -1 user/
```

# fnlookup — 显示 FNS 中绑定的引用

### 概要

`/usr/bin/fnlookup [-ALV] composite-name`

## 描述

`fnlookup` 显示 `composite-name` 的联邦命名服务 `FNS` 绑定。

## 选项

`-A` 咨询权威源获取信息。
`-L` 如果复合名称绑定到 XFN 链接，则显示该链接。如果没有 `-L` 选项，则显示引用。
`-v` 详细显示绑定。对于 `onc_*` 引用，此选项用于推导出存储引用的 NIS+ 表名称。

## 参数

`composite-name`

一个联邦命名服务命名对象。

## 示例

以下示例显示了 `jsmith/service/calendar` 绑定的引用。

```
castle@ fnlookup user/jsmith/calendar

castle@ fnlookup user/jsmith/service
```

以下示例显示了 `jsmith/service` 绑定的引用。

```
castle@ fnlookup user/jsmith/service
```
