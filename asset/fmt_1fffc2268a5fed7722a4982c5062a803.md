# bluefish

Gtk+ 编辑器是一个面向经验丰富的网页设计师的 HTML 编辑器。它目前处于 alpha 阶段，但仍然有用。它包含了良好的启动、表格和框架向导；功能全图像插入对话框；缩略图创建以及缩略图与原图自动链接；以及可配置的 HTML 语法高亮。验证需要网络预览。你需要一个可以查看本地文件或到命令行的浏览器。来自 Debian 3.0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

`bluefish` 是一个可以放在两个软盘上的发行版，包含一个图形 Web 浏览器（使用 glibc 1.4.3 的 linux 2.1pre9）和一个流行的 IRC 客户端（BitchX 1.0c19）。内核为 24.2-0，大多数以太网驱动程序作为模块绑定。C 语言库是 uClib 0.9.16，`busybox` 是 0.61.pre 的稍微修改版本。"links' 和 'BitchX' 是静态链接并用 UPX 1.9 压缩的。`bluefish` 的特点是它的配置程序。所有脚本都使用一个 '`setup`' 脚本，它们都有一个很好的 '`dialog`' 前端。版本 1.0.0 于 2003 年 4 月 15 日发布。软盘发行版。来自 LWN 分发列表 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# bmconf

# Linux 词典

轻量级高性能的 Web 服务器 Boa 是一个单任务 HTTP 服务器。这意味着与传统的 Web 服务器不同，它不会为每个连接创建分进程（fork），也不会通过创建自身的副本来处理多个连接。它对所有进行中的 HTTP 连接进行复用，仅为 CGI 程序（必须是独立的）创建分进程。初步测试显示，boa 在 100 MHz 的 Pentium 处理器上每秒可以处理数百次访问。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`
