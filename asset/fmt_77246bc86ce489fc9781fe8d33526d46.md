
事实如此。Xmahjongg 现在已安装在你的系统中，你会在 Xmahjongg 文件夹中找到 Xmahjongg DEB 包。你应该将 DEB 包移动到安全的地方，例如 Tarballs 或 Software 文件夹（或你喜欢的任何名称），这样在你需要重装系统时可以再次使用。一旦移动了 DEB 包，假设它在你的主目录下，通过输入 `cd; sudo rm -r xmahjongg*` 并按 ENTER 键来删除 Xmahjongg 文件夹。

> 注意：两边带有空格的分号用于分隔单行上的命令。按照上述说明操作，你实际上是在单行中执行了两个操作：`cd; sudo rm -ir xmahjongogg*`

## 9C-4: 运行 Xmahjongg

通常情况下，从源码编译的程序不会自动为你安装启动器，你必须通过命令行运行它们。虽然你可以在“运行应用程序”（Run Application）组件中输入命令来首次运行程序，但在你的终端窗口中输入命令首次运行程序更好。如果安装过程中出现任何问题，终端会告诉你问题所在，而“运行程序”方法会让你纳闷发生了什么。

要运行 Xmahjongg，只需在终端窗口中输入 `xmahjongogg` 然后按 ENTER。如果一切正常，你可以在应用程序菜单、GNOME 面板或面板抽屉中为 Xmahjongg 创建程序启动器。

## 在 Wine 下运行 Windows 应用程序

现在你已经学习了向系统添加应用程序的各种方法，我也可以顺便再介绍一种——运行应用程序。尽管大多数人们使用或需要的 Windows 程序在 Linux 中都有对应的替代品，但你可能仍然怀念一两个程序。对我来说，长期以来一直是奥利利的纸牌游戏 Schnapsen。幸运的是，通过名为 Wine 的程序，可以在 Linux 内部运行某些 Windows 应用程序。

Wine 的开发者似乎非常强调 Wine 并不是 Windows 模拟器，而是倾向于将其称为 Windows 兼容性层。事实上，这个名字本身就说明了这一点，因为 Wine 是 *Wine Not an Emulator*（Wine 不是模拟器）的递归缩写。无论你如何看待，它的功能都是让你在不安装 Windows 的情况下运行 Windows 应用程序。

值得指出的是，Wine 仍在开发中。它在某些程序上运行得良好，但在另一些程序上完全无法运行。不过，情况已经有所改善，Wine 现在似乎能更好地支持更多应用程序。例如，在最新版本发布之前，我一直无法让我喜欢的 Schnapsen 游戏运行。现在它可以运行了，而且运行得相当不错（图 9-11）。

## 安装和检查 Wine

你可以通过 Automix 获取 Wine：点击窗口左侧面板中的 Virtualization（虚拟化），并勾选右面板中 Wine 旁的复选框。之后，点击 Start（开始）即可。安装完成后，退出 Automix。

在安装之前，Wine 安装脚本会自动尝试通过运行 Wine Configuration（Wine 配置）在你的用户文件夹内创建一个伪 Windows C: 盘。Automix 会向你提示，一旦出现 Wine 配置窗口，你只需要点击 OK，Wine 配置窗口就会关闭，Wine 本身就准备就绪了。

如果安装完成时没有出现 Wine 配置窗口，你可以通过运行 Wine File 来实现相同的操作，Wine File 是一个类似于 资源管理器的文件浏览器（图 9-12）。你可以通过进入 Applications > Accessories > Wine File 或打开 Run Application 窗口并输入 `winefile` 来运行 Wine File。一旦打开了 Wine File，你不需要做任何事情，因为工作已经在后台完成了。你可以立即关闭 Wine File。
