
## NAME（名称）
命令、子程序、文件等的名称及其功能的简要描述。

## SYNOPSIS（概要）
Synopsis 是指在调用命令、子程序或文件时使用的语法。Synopsis 是 Linux 和 UNIX 世界中常用的术语，意为语法。通常，语法遵循我们在本章中介绍的格式，但你也会看到针对你所使用的特定 Linux 版本的该命令所有选项和参数的完整列表。在示例 3.3 中，我们对 Synopsis 部分做了进一步的注释。

## INTRODUCTION（介绍） 或 DESCRIPTION（描述）
对命令功能的更深入的定义或描述。本节还可以列出或讨论选项和参数，或者列出在执行命令之前、期间或之后需要遵循的分步说明。

## OPTIONS（选项）
可用的选项和参数。

## FILES（文件）
文件列表及其与命令的关系。例如，你可能需要查阅某个文件才能找到命令的参数。

## ENVIRONMENT（环境）
在执行命令之前检查特定参数的配置文件列表。

## EXAMPLES（示例）
虽然示例通常出现在介绍或描述部分，但作者可能会在这个示例部分列出使用该命令、子程序或文件的一些常见示例。

## SEE ALSO（另见）
此部分包含相关命令或文件的名称，或者可能产生相同效果的命令的名称。

## HISTORY（历史）
该命令首次出现的 Linux 或 UNIX 版本、原始开发者以及其他历史信息。

## BUGS（错误/提示）
关于如何、何时、何地以及为何应使用此命令、文件或子程序的额外提示或注意事项。你可能还会找到关于何时*不要*执行该命令的指导。

## SUMMARY（摘要）
另一个用于展示选项、描述、用途等的章节。

## AUTHOR（作者）
开发该命令、子程序或文件的个人或组织的名称，或提供此信息页面的人或组织的名称。你通常还可以找到直接联系作者的地址。通常，本节指示该命令是否源自其他版本的 UNIX，或是专为 Linux 开发的。

## DERIVATION（来源）
在 man 手册页底部，你可能会找到关于命令来源的额外信息，来源如 AT&T 或 Berkeley，或版本号或日期。

## DATE（日期）
man 手册页的最后更新日期。这个日期并不指示命令的实用程序、选项或参数的最后更新时间。当有人修改命令/程序或文件的某个元素时，man 手册页本身并不总是随之更新。

### 浏览 man 手册页

打开 man 手册页后，按以下按键在其中移动：

- 空格键每次翻动一屏向下导航。
- `b` 每次翻动一屏向上导航。
- `d` 每次翻动半屏向下导航。
- `u` 每次翻动半屏向上导航。
- Enter 键或向下箭头键每次下行一行导航。
- `h` 显示包含许多其他导航命令的帮助屏幕。
- `q` 退出帮助屏幕并返回 man 手册页。
- 输入 `/*` 后跟字母数字字符串并回车，可搜索该字符串。
- `n` 查找上一次搜索结果的下一个出现位置。
- `q` 退出 man 手册页。

退出 man 手册页后，这些按键不再用于导航，直到你再次调用 `man` 命令或如前所述输入 `fg`。

### 打印 man 信息

如果你想打印特定命令的 man 手册页的硬拷贝，请输入：

```
$ man commandname | lpr<Enter>
```

或者，如果你使用的是 PostScript 打印机，请输入：

```
$ man -t commandname | lpr<Enter>
```

当然，使用这些选项和管道命令需要事先设置好打印机。如果你打算现在这样做，请翻到第 5 章“在 Linux 中使用文件”，那里我们讨论了打印。

### 示例 3.4 man 命令

很快，我们将看到 Sancho 使用 `who` 命令。但如果他想事先或在任何时间了解有关 `who` 命令的信息，他可以按以下方式访问其 man 手册页：

```
$ man who<Enter>
```

系统响应的第一页将类似于：

```
WHO(1)          FSF                     WHO(1)
NAME
   who - show who is logged on

SYNOPSIS
   who [ OPTION ] [ FILE | ARG1 ARG2 ]

DESCRIPTION
   -H, --heading
           print line of column headings
```

- `-i, -u, -idle`
  将用户空闲时间作为小时:分钟，或以 old 形式显示
- `-l, -lookup`
  尝试通过 DNS 规范化主机名
- `-m`
  仅显示与标准输入关联的主机名和用户
- `-g, -count`
  显示所有登录名以及已登录用户的数量
- （等等）

“Synopsis”概要部分中的代码使用以下排版约定。

可选字段显示在方括号中，`[` 和 `]`。它们表示你无需输入某个选项或参数。如果存在强制字段，它们将显示在花括号中：`{` 和 `}`。如果存在强制字段，则你必须在命令名称后为该对应的选项或参数输入一个值。当看到管道符 `|` 分隔两个强制选项或参数时，则你必须输入其中一个来配合命令使用。不过，对于 `who` 命令而言，尽管参数由管道符分隔，但它们都是可选的。因此，除非你选择提供参数，否则无需提供任何内容。

你可能会注意到 `who` 的手册页中包含 `FILE` 选项。当用户登录时，其登录记录会保存在文件 `/var/run/utmp` 中。默认情况下，`who` 命令会在此处查找信息。如果系统管理员已配置系统使用其他文件来记录登录信息，则你必须在 `who` 命令后指定该文件名。

## info 页面

`info` 页面使用与 `man` 相同的数据库，但以不同的格式呈现信息。有些人认为 `info` 功能更强大，因为它允许你将信息分解为更小的块进行检查，并显示你所搜索的信息与其他相关信息之间的关系。

`info` 的另一个重要特性，尤其对于新用户而言，是它会在第一个屏幕上提供自身的操作说明，并允许你在调用 `info` 后立即进入入门指导。这种引导式方法大大提高了搜索成功的可能性。

其语法再简单不过了：

```
$ info<Enter>
```

调用该命令后，会出现第一个基于 ASCII 字符的 *info* 屏幕，并声明你位于 *info* 目录树的顶部。随后是基本说明，以及启动 *info* 入门指导的机会。

如果你不需要入门指导，请按下 Tab 键或上、下箭头键，在可用的众多用户命令、系统调用、子例程、设备、文件格式、游戏、系统管理功能等之间移动。示例 3.5 列出了基本类别，但未列出你可以从此屏幕访问的所有功能。当你选择一个类别后，按下 Enter 键。随后会显示一个包含你所选信息内容的屏幕。

然而，当用户退出 *info* 后，并没有类似 `fg` 我们在 *man* 中使用过的那样命令可以将用户返回到他们离开 *info* 时的位置。他们必须从头开始重新进入，并再次执行整个流程。

用户还可以从 `xterm` 窗口调用 `info`，并且可以从 X Window 系统桌面调用其他类似 `info` 或 `man` 的程序。这些程序的名称和类型因每个 X 窗口管理器而异。例如，从 KDE 中，你可以调用 KDE Help。KDE Help 允许你使用鼠标通过超链接进行导航，而不是我们用来通过面向 ASCII 的 *info* 页面的键盘导航。有关 X Window 系统和 X 窗口管理器的更多信息，请参阅第 14 章，“Linux X Window 系统”。

> **注意** 请检查本章提到的所有命令的 *man* 页面及其他信息源中的选项和参数。
