启动界面 (a splash screen)，来自 Whatis `http://www.tdq.org/LDP/Linux-Dictionary/index.html`
- `splain`

用于执行相同功能的独立程序 (standalone program to do the same thing) `http://www.tdq.org/LDP/Linux-Dictionary/index.html`
- `splash`

启动界面 (a splash screen)，来自 Whatis `http://www.tdq.org/LDP/Linux-Dictionary/index.html`
- `splay`

`MPEG-1,2,3` 播放器，基于`sqcup`，它可以解码层 I、II 和 III 流并从 CD 级播放。它比商业设备消耗的计算资源少得多。来自 Linux Guide `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
- `spline`

Akima 样条插值。`spline` (1) 通过一系列通用点插值出 Akima 样条。Akima 样条比样条能更好地拟合手动绘制的曲线，但后者不是连续的。
- `splint`

用于 C 代码和不良风格的 Splint。来自 Redhat 8.0 RPM
- `Slack`

`Slack` 是一个继续对已停止的端口进行工作的志愿者项目。`Slackware` 基于 KISS（简单而不愚蠢）原则，这使得任何有一点 Unix 经验的人都能轻松维护。于 2001 年 9 月 30 日发布。来自 LWN List `http://www.tdq.org/LDP/Linux-Dictionary/html/index.html`
- `split`

创建一个或多个输出文件（按需要），包含输入的内容，如果给出标准输入则名为 "-"。默认情况下，`split` 将输入文件的每 1000 行（如果不足则为剩余所有行）放入每个输出文件。来自 Linux Guide @FirstLinux `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
- `splitdigest`

一个拆分邮件数字的程序。它从命令行指定或 STDIN 读取文件，并为每个摘要写入一个 mbox 格式（Email, Pine, Vim, mailx）。它已为 Debian-User 和 Debian–Changes 预配置，但可以轻松配置为任何类型的摘要。
- `splitvrt`

在屏幕上运行两个程序。一种工具，可以将具有 vt100 能力的屏幕分为两部分（上下部分），并在每个部分同时运行不同的程序。
- `SPM`

会话协议机 (OSI, ISO 8327) 来自 VERA
