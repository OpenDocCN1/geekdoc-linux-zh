
- `display` 指定到 X 服务器的连接。
- `bytes` 指定字节流，不一定是 ASCII 或以 null 终止。
- `nbytes` 指定要存储的字节数。

数据可以包含嵌入的 null 字符且不需要 null 终止。任何客户端以后都可以通过 `XFetchBytes` 获取剪贴板缓冲区的内容。

`XStoreBytes` 可能会产生 `BadAlloc` 错误。

要在剪贴板缓冲区中存储数据，请使用 `XStoreBuffer`。

```c
XStoreBuffer(display, bytes, nbytes, buffer);
```

- `display` 指定到 X 服务器的连接。
- `bytes` 指定字节流，不一定是 ASCII 或以 null 终止。
- `nbytes` 指定要存储的字节数。
- `buffer` 指定想要存储字节的缓冲区。

如果指定了无效缓冲区，调用将不起作用。数据可以包含嵌入的 null 字符且不需要 null 终止。

`XStoreBuffer` 可能会产生 `BadAlloc` 错误。

要从剪贴板缓冲区 0 返回数据，请使用 `XFetchBytes`。

```c
char *XFetchBytes(display, nbytes_return);
```

- `display` 指定到 X 服务器的连接。
- `nbytes_return` 返回 `nbytes_return` 中的字节数。

如果缓冲区包含数据，`XFetchBytes` 函数返回 `nbytes_return` 参数中的字节数。否则，函数返回 `NULL` 并将字节置为 0。系统将分配适当的存储空间并返回指针。客户端在使用后必须调用 `XFree` 释放该存储空间。

从指定的剪贴板缓冲区返回数据，请使用 `XFetchBuffer`。

```c
char *XFetchBuffer(display, nbytes_return, buffer);
```

- 指定到 X 服务器的连接。
- 返回缓冲区中的字节数。
- 指定想要返回存储数据的缓冲区。

如果缓冲区中没有数据或指定了无效缓冲区，`XFetchBuffer` 函数将向 `nbytes_return` 参数返回零。

要要旋转剪贴板缓冲区，请使用 `XRotateBuffers`。

```c
XRotateBuffers(display, rotate);
```

- `display` 指定到 X 服务器的连接。
- 指定旋转剪贴板缓冲区的程度。

`XRotateBuffers` 函数旋转剪贴板缓冲区，使得缓冲区 0 变为 n，缓冲区 1 变为 n+1，依此类推。此缓冲区编号对于显示器是全局的。注意，如果八个缓冲区中的任何一个未创建，`XRotateBuffers` 会产生 `BadMatch` 错误。

## 确定适当的视觉类型

单个显示器可以支持多个屏幕。每个屏幕可以在不同的深度下支持多种不同的视觉类型。你可以使用本节中的函数来确定应用程序使用哪种视觉。

本节中的函数使用视觉信息掩码和 `XVisual` 结构，该结构定义在 `<X11/Util.h>` 中并包含：

```c
/* Visual信息掩码位 */
#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMask 0x10
```

```c
/* Visual信息掩码位 */
#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMask 0x10
#define VisualGreenMask 0x20
#define VisualBlueMask 0x40
#define VisualColormap 0x80
#define VisualBitsPerRGB 0x100
#define VisualAllMask 0x200
```

# 应用实用函数

`bitmap_pad` 指定了扫描线的位（8、16 或 32）。换句话说，在客户端内存中，一条扫描线的起始点与下一条扫描线的起始点之间的间隔是许多比特的整数倍。

`bytes_per_line` 指定了客户端图像中从一条扫描线的起始到到下一条扫描线的起始之间的字节数。

`XCreateImage` 函数为指定的显示器分配 `Ximage` 结构体所需的内存，但不会为图像本身分配空间。它从显示器初始化结构体的字节序、位序和位图单位值，并返回一个指向 `Ximage` 的指针。红、绿、蓝掩码值是为 Z 格式图像定义的，并从传入的 `Visual` 结构体得出。其他值也会被传入。偏移量允许快速显示图像，而无需将其移动到指定位置。如果你传递每行 0 字节，Xlib 会假设扫描线在内存中是连续的，并计算 `bytes_per_line` 的值。

请注意，当使用 `XCreateImage`、`XGetImage` 或 `XSubImage` 创建图像时，`XDestroyImage` 函数调用的销毁过程会释放图像结构体和图像指向的数据。

用于获取像素、设置像素、创建子图像以及向图像添加常数的基本函数定义在图像对象中。本节中的函数实际上是图像对象的宏调用，定义在 `<X11/Util.h>` 中。

要获取图像中的像素，请使用 `XGetPixel`。

```c
unsigned long XGetPixel(image, x, y);
```

`image` 指定图像。

`x`

`y` 指定 x 和 y 坐标。

`XGetPixel` 函数返回从命名图像中采样的像素。像素值以归一化格式返回（即 `long` 类型的最低有效位是像素的最低有效位）。图像必须包含 x 和 y 坐标。

要在图像中设置像素，请使用 `XPutPixel`。

```c
XPutPixel(image, x, y, pixel);
```

`image` 指定图像。

`x`

`y` 指定 x 和 y 坐标。

`pixel`

指定新的像素值。

`XPutPixel` 函数用指定的像素值覆盖命名图像中的像素。输入的像素值必须是归一化格式（即 `long` 类型的最低有效字节是像素的最低有效字节）。图像必须包含 x 和 y 坐标。

要创建一个子图像，请使用 `XSubImage`。

```c
XImage *XSubImage(ximage, x, y, subimage_width, subimage_height);
```

`ximage` 指定 x 和 y 坐标。

`x` 指定 x 和 y 坐标。

`subimage_width` 指定新子图像的宽度（单位为像素）。

`subimage_height` 指定新子图像的高度（单位为像素）。

`XSubImage` 函数创建一个现有图像的子图像。它为新的 `XImage` 结构体分配必要的内存并返回指向新对象的指针。数据从源图像复制，且图像必须包含由 x、y、subimage_width 和 subimage_height 定义的矩形。

要用常数增加图像中每个像素的值，请使用 `XAddPixel`。

```c
XAddPixel(ximage, value);
```

`ximage` 指定图像。

`value` 指定要加的常数。

`XAddPixel` 函数为图像中的每个像素加上一个常数。当你通过分配颜色资源获得基础像素值，并需要处理图像以形成时，该函数非常有用。

要释放之前调用 `XCreateImage` 分配的内存，请使用 `XDestroyImage`。

```c
XDestroyImage(ximage);
```

`ximage` 指定图像。

`XDestroyImage` 函数释放与 `XImage` 结构体相关的内存。

请注意，当使用 `XCreateImage`、`XGetImage` 或 `XSubImage` 创建图像时，宏调用的销毁过程会释放图像结构体和图像结构体指向的数据。

# 操作位图

Xlib 提供了可以从文件读取位图、将位图保存到文件或创建位图的函数。本节描述了在客户端文件系统中传输位图的函数，允许它们在后续连接中重用（例如，来自完全不同的客户端或到不同的显示器或服务器）。

X 版本 11 位图格式为：

```c
#define name_width width
#define name_height height
#define name_x_hot x
#define name_y_hot y
```
