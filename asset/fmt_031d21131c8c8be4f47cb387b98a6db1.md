
`fdisk`提供了一种简单的方法，可以检查系统中所有挂载并正在使用的磁盘分区及关联文件系统。遗憾的是，`df`等命令无法提供新连接到系统的设备信息（因此这些设备可能尚未包含分区，或者虽然已连接系统但其文件系统尚未挂载）。幸运的是，Linux提供了简单的方法来查找系统中所有的存储设备，无论它们是否已格式化或挂载。你必须忍受一点晦涩的命令行“魔法”，这至少已经算是个Linux魔法师徒了，对吧？你只需要向系统中插入一个新驱动器即可！

确定与系统中存储设备相关的设备节点的方法，是查看内核启动消息，寻找与本章标题“故障排除自动设备检测”（Troubleshooting Automatic Device Detection）部分讨论的字符串匹配的模式。该部分建议查看`dmesg`文件中与热插事件（hotplug events）相关的消息，这些事件是内核在系统运行时处理的设备检测和移除过程。幸运的是，你也可以使用`dmesg`命令查看此消息日志的信息。由于你知道以`hd`开头后跟其他字母的IDE设备，以及SATA和SCSI设备以

![](img/e88880e40d650bfe19d5b6927bd86568_724_0.png)

以`sd`开头后跟某些字母，你可以使用如`[hs]d[a-z]:`的模式。如果你不熟悉Linux正则表达式，`[hs]d[a-z]:`的意思是：“匹配任何以‘h’或‘s’开头的字符序列，随后是跟任意单个字母‘d’，然后是‘a’到‘z’之间的任何任意字符（包含在内），最后是冒号，然后是空格。”这很简单，不是吗？

在示例Ubuntu系统上在`dmesg`命令的输出中搜索此字符串正符合你所希望的，如下例所示：

`dmesg | grep ‘[hs]d[a-z]:’`

终于让它派上用场了。接下来的示例将在磁盘上创建两个分区（实际上，你将创建的分区布局与图 23.17 所示相同）。

使用`fdisk`对磁盘分区，请执行以下操作：

使用`sudo`命令启动`fdisk`命令，并将你想要分区的磁盘名称作为参数提供，如下例所示：

```bash
sudo fdisk /dev/sda
```

此磁盘的磁道数设置为 14593。这没有任何问题，但它大于 1024，在某些设置下可能会导致以下设备出现问题：

- 在启动时运行的软件（例如，旧版本的 LILO）
- 来自其他操作系统的启动和分区软件（例如 DOS FDISK、OS/2 FDISK）

`command (m for help):`

示例输出的最后一行行行是`fdisk`的命令提示符，显示它正在等待命令。

使用`p`（打印）命令来显示磁盘上可能已经存在的任何分区列表。毕竟，你不想意外地在错误的磁盘上尝试创建分区或破坏任何现有的数据。该命令及其输出如下：

```text
command (m for help): p
Disk /dev/sda: 120.0 GB, 120034123776 bytes
55 heads, 63 sectors/track, 14593 cylinders
Units = cylinders of 16065 * 512 = 8225280 bytes

| Device Boot Start End Blocks Id System |
| :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | |

```

`command (m for help):`

如完全缺少分区所示，此磁盘目前不包含任何分区。使用`n`（新建）命令来定义新分区：

```text

command (m for help): n

command action

e extended

p primary partition (1-4)

```

输入此命令会提示你想要创建的分区类型，扩展分区（e）或物理分区（p）。使用`p`命令创建物理分区：

```text

partition number (1-4):

```

指定要创建物理分区会提示你想要创建的分区编号。Linux磁盘只能包含四个物理分区，其中一个可以是扩展分区。输入`1`创建1号分区：

```text

first cylinder (1-14593, default 1):

```

标识你想要创建的物理分区编号会提示你分区开始的物理磁盘块，并显示可能值的范围（在此情况下为1-14593）。按回车键接受默认值1：

```text

using default value 1

last cylinder or +size or +sizeM or +sizeK (1-14593, default 14593):

```

在创建分区时，你可以根据分区开始或结束的磁盘块来定义它们，也可以根据开始的块和分区的大小来定义它们。输入`+30G`表示你想创建一个30GB的分区：

```text

Last cylinder or +size or +sizeM or +sizeK (1-14593, default 14593):

30G

```

```text

Command (m for help):

```

这完成了创建分区所需的信息，但并没有告诉你关于这是否真的成功了。再次使用`p`命令列出当前定义的任何分区：

```text

command (m for help): p

Disk /dev/sda: 120.0 GB, 120034123776 bytes

55 heads, 63 sectors/track, 14593 cylinders

Units = cylinders of 16065 * 512 = 8225280 bytes

| Device Boot Start End Blocks Id System |

| :--- | :--- | :--- | :--- | :--- | :--- |

| dev/sda1 | 1 | 3648 | 29302528 | 83 | Linux |

```

足够了，一个30GB的分区已经定义为分区`/dev/sda1`，这是你磁盘上的第一个分区。

在此处，你的磁盘分区尚未尚未进行任何物理更改。任何建议的更改目前仅在内存中，除非你在退出`fdisk`命令之前将其写入磁盘，否则它们将被丢弃。
