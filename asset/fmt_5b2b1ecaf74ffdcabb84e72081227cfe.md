# 动力学（经典力学）

经典力学的一部分处理物体运动与作用在物体上的力之间的关系。它与物体动力学是同义词。见动力学（DYNAMICS）。

运动涉及可以用可测量量描述的概念。用于规定这些概念的本质概念和可测量量如下：

- 1. 运动指的是观察者观测的参考系中物体的坐标和位置。通过一组坐标和极角定量地表示。
- 2. 持续时间通过时间定量地表示并用时钟测量。
- 3. 运动指的是形状随时间的变化，通过速度率和称为加速度的速度的变化来表示。
- 4. 惯性是物体的属性，意味着它们改变静止或运动的能力。物体的惯性相对于线性力。
- 5. 动量与总质量和速度正比。线性动量表示为质量与速度的乘积。

功是运动对特定物体施加力的积分，由牛顿第二定律表示（文中已讨论）。经典动力学的主要目标是在坐标和动量初始值可用时预测物体的行为。距离、时间和质量通常被认为是基本要素，艾萨克·牛顿提出的基本定律——第二定律规定，粒子的变化率与作用于它身上的力成正比且方向一致。静态地，牛顿第二定律变为微分方程方程 (1)，其中 $m$ 代表粒子的质量，$v$ 是，

```

```

$F$ 是作用于它的力。$ma = F$ (2)

多个相互作用的系统的动量遵循牛顿第三定律，规定当物体相互作用时，作用在物体上的力相等且相反。动量能量守恒定律源于此。见加速度（Acceleration）；质量（Mass）；速度（Velocity）。

# 考拉

考拉物，学名为 *Phascolos cinereus*，是袋鼠目（有袋类动物）中袋幼目科的一的一员。它们是一种小型动物，成年后体重在 11 至 17 磅之间（5 至 8 公斤）。它们仅限于澳大利亚东部。它们的食物并非桉树叶，树叶必须是特定年龄或特定物种的树叶，且树木必须生长在特定的土壤上。考拉每季节繁殖一次，通常后代只有一个。幼崽在育囊中停留 6 个月；它会紧贴着母亲的背，并在母亲怀里被抱着几个月。参见考拉（KOALA）。

Kohairi 是一种叶用甘蓝植物。*Brassica cauliflower-rapo oleracea caule-rapo*，起源于北欧，属于攀援植物。Kohairi 的用途是作为食用芜萝卜，通常作为煮熟的蔬菜食用（见插图）。它是欧洲、中非和热带南美洲常见的蔬菜。它也会导致鼻炎（臭鼻），这是一种鼻粘膜的破坏性萎缩，且极见由尿路感染和细菌引起。

Kifwruit 是一种落叶藤本果实（猕科），被引入中国中部，通常生长在东部的山区和森林地区。该果实由雌株和雄株产生，通过交叉授粉实现成功的结实。

该品种果实具有奶油白色中心、黑褐色种子以及带有灰色皮肤的明亮透明绿色果实，非常适应温带气候，冬季温度范围在 32 至 45 °F（或 0 至 7 °C）之间，以确保萌芽。Kifwruit 适合运输，并能承受低至 -29 °F（-15 °C）的温度。

Kifwruit（*Actinidiaiculata*）于1904年从中国种子引入新西兰，现在新西兰、日本、中国、法国、德国、美国（加利福尼亚州）和澳大利亚广泛栽培。现在新西兰通过一雄一母植物生产。

Kystron 是一种真空电子束管，通过电子的密度调制引入电子。Kystron 用于微波区域的放大器或作为振荡器。

作为放大器，kystron 需要一个通过电子束的输入信号。输入能量调制束中电子的速度，随后使其开始产生密度调制。较快的电子超过其他电子形成团聚。在这种机制中，电子电流变为交流电。具有显著交流电成分的 kystron 束随后产生一个输出，束可以将能量传输到该输出上。

Kystron 通过将部分输出反馈到输入来作为振荡器工作。电子束中的振荡器更多为电子束的调制提供了必要的反馈，正如在放大器中一样。空腔通常需要在一个空间内产生电场，以便该电场能与低速电子束相互作用。每个电子的速度随后通过其运动进行调制，这种运动是由一个相对于阴极处于负电位运行的反射电极产生的。电子不会被空腔偏转，而是被空腔进行调制的。

克雷伯菌（*Klebsiella*）是一种革兰氏阴性运动性细菌。由于大量的荚膜物质，会产生特征性的粘性菌落。克雷伯菌常见于人类胃肠道、土壤和水中，以及动物和人类。克雷伯菌感染通常是由于它们在尿路感染和细菌中固定氮引起的。

克雷伯菌导致很大比例的医院感染、败血症感染（特别是在免疫功能低下的患者中）和尿路感染。它是静脉感染常见的类型，如葡萄糖相关感染和肺炎。它们通过医疗护理治疗。

克雷伯菌可能产生大肠杆菌类毒素，并导致婴儿和年幼儿童的急性胃肠炎。克雷伯菌发现于更常见且敏感性较低的人群中。

### 医学背景

物种包括肺炎雷伯菌（*K. pneumoniae*）。臭鼻，如肺炎雷伯菌和肠杆克雷伯菌（*K.oxytoca*），会导致肺炎。肺炎雷伯菌是免疫功能低下的患者中常见的病原体。克雷伯菌在人群中更常见且敏感性较低。

一种多年生藤本植物，能够在温暖的亚热带气候中快速生长。本土葛藤原产于日本。葛藤（*Pueraria*）于1876年引入美国，曾被用作遮荫植物，直到1906年，美国东南部的一股热潮开始将其作为作物种植，这种做法一直持续到现在。此后它被广泛认为是一种入侵植物。然而，由于其蔓延到森林边缘以及其他后果，引发了许多针对它的应对措施。
