
# diff

`-b` 忽略空格。

`-C` 显示上下文。

`-d` 仅报告不同的行。

`-e` 忽略变化。

`-f` 使用脚本文件。

`-m` 输出统一格式差异。

`-y` 显示并排比较。

`-Y` 忽略共同行。

`-W` 设置宽度。

`-Z` 忽略制表符。

描述 `diff` 命令比较文件并报告差异。默认情况下，它显示差异周围的三行。使用 `-U` 参数更改上下文数。

# du

## 目的

显示目录的磁盘占用情况

## 语法

`du [options] [file]`

`-a` 显示所有文件。

`-b` 以字节为单位显示。

`-c` 显示总计。

`-d` 指定深度。

`-h` 以人类可读格式显示（K, M, G）。

`-l` 列出目录。

`-m` 以兆字节为单位显示。

`-s` 显示摘要。

`-x` 排除其他文件系统。

## 描述

`du` 命令显示目录的磁盘占用情况。默认情况下，它显示目录及其子目录的总量。

# expand

将制表符转换为相应数量的空格后将文件写入标准输出

## 语法

`expand [options] [file]`

`-n` (`n` 是数字) 设置制表符间隔为 `n`。

`-n1 [n2,...]`（其中 `n1`, `n2`, ... 是数字）指定制表位。

`-i` 仅将起始制表符转换为空格。

## 目的

## 选项

该命令读取文件（如果没有指定文件则从标准输入读取）并将其写入标准输出，每个制表符转换为相应数量的空格。默认情况下，`expand` 假设制表符间隔为（相当于 `-8`）。

## 目的

## 选项

# fdisk

分区磁盘或显示现有分区信息

## 语法

`fdisk [device_name]`

`-l` 显示分区表并退出。

`-s` 显示指定分区的大小。

`-v` 显示 `fdisk` 程序版本。

## 目的

## 选项

描述 `fdisk` 命令对硬盘进行分区（磁盘命名约定参见附录 B）。你也可以使用 `fdisk` 显示现有分区的信息。你不应该在一个或多个分区挂载到 Linux 文件系统时运行 `fdisk` 并更改分区。相反，你应该从安装磁盘（或启动磁盘）引导并执行分区。记住，分区通常会破坏硬盘上的所有现有数据。

# find

用途：显示匹配一组特定标准的文件列表。

## 语法

`find [path] [options]`

## 选项

`-depth` 先处理当前目录，再处理子目录。

`-maxdepth n` 将搜索限制在 `n` 层目录内。

`-follow` 通过符号链接处理目录。

`-name pattern` 查找名称匹配模式的文件。

`-ctime n` 恰好在 `n` 天前修改过的。

`-user uname` 查找指定用户拥有的文件。

`-group name` 查找指定组拥有的文件。

`-path pattern` 查找路径匹配模式的文件。

`-perm mode` 查找具有特定权限设置的文件。

`-size +nk` 查找大于 `n` 千字节的文件。

`-type x` 查找指定类型的文件，其中 `x` 为以下之一：

`f` 匹配文件。

`d` 匹配目录。

`l` 匹配符号链接。

`-print` 显示找到的文件名。

`-exec command [options] (;)` 通过将找到的文件名作为参数来执行指定的命令。

## 描述

`find` 命令用于查找所有匹配一组特定标准的文件。如果你在不带任何参数的情况下输入 `find`，输出将是当前目录下所有子目录每个文件的列表。要查看所有以 `.gz` 结尾的文件，请输入 `find -name "*.gz"`。

# fold

用途：将文本行折叠到指定的宽度（默认为 80 个字符）。

## 语法

`fold [options] [files]`

## 选项

`-b` 统计字节而非列，因此退格键和制表符会被计入内。

`-s` 在单词边界处折行。

## 描述

`fold` 命令将每个输入行折叠为指定的字符数，并将结果显示在屏幕上（标准输出）。如果你不指定任何文件名，它将从标准输入读取行。

# free

用途：显示系统中的可用和已用内存。

## 语法

`free [options]`

## 选项

`-b` 以字节数显示内存。

`-k` 以千字节为单位显示内存（默认）。

`-m` 以兆字节为单位显示内存。

`-s` 每隔 `n` 秒重复一次命令。

`-t` 显示包含包含总计摘要的行。

## 描述

`free` 命令显示关于物理内存（RAM）和交换区（磁盘上）的信息。输出显示内存的总量、使用量和可用量。

# fsck

用途：检查并修复 Linux 文件系统。

## 语法

`fsck [options] device_name`

## 选项

`-A` 检查 `/etc/fstab` 文件列出的所有文件系统。

`-R` 跳过根文件系统（在检查所有文件系统时）。

`-T` 启动时不显示标题。

`-N` 显示可能执行的操作但并不实际执行。

`-V` 产生详细输出。

`-f ftype` 指定文件系统类型（如 `ext2`）。

`-n` 对所有确认请求均回答为“no”（仅用于 `ext2` 文件系统）。

`-p` 执行所有修复并请求确认（用于 `ext2`）。

`-y` 对所有确认请求均回答为“yes”（仅用于 `ext2` 文件系统）。

## 描述

`fsck` 命令检查文件系统的完整性并执行任何必要的修复。根据文件系统的类型，`fsck` 会运行适当的命令来检查和修复文件系统。例如，要检查 `ext2` 文件系统，`fsck` 会运行 `e2fsck` 程序。你在没有运行 `shutdown` 命令的情况下直接关机系统时，你必须运行 `fsck`。通常情况下，`fsck` 在系统启动期间自动运行。

# grep

用途：在一个或多个文件中搜索匹配正则表达式（搜索模式）的行。

## 语法

`grep [options] pattern files`

`-N`（`N` 为数字）显示包含模式的行周围的 `N` 行。

`-c` 显示包含搜索模式的行数。

`-f file` 从指定文件读取选项。

`-i` 忽略大小写。

`-l` 显示包含模式的文件名。

`-n` 为包含模式的行显示行号。

`-q` 返回状态码但不显示任何输出。

`-w` 仅匹配整个单词。

## 描述

`grep` 命令在文件中搜索模式。模式是一个具有自身规则的正则表达式。通常，你使用 `grep` 是为了在一个或多个文件中文件中搜索特定的字符序列。
