## 方法 2：在 PV 级别监控过期的 PP

在 PV 级别检查过期的磁盘分区可以让你知道一个或多个 LV 是否有过期的 PP。为了更清楚地了解未同步镜像的位置，我们需要查看 `hdisk` 级别。在本节中，我们将搜索物理分区（Physical Partitions，简称 PPs）的查询点从逻辑卷（Logical Volume）更改为物理卷（Physical Volume）。这两种方法在执行时间节省上，直接操作磁盘快三倍。在我的测试机器 H80 上，LV 查询实际耗时时 40.7 秒，系统时间 0.36 秒，用户时间 0.02 秒。使用 PV 查询方法将执行时间缩短到实际时间 12.7 秒，系统时间 0.17 秒，用户时间仍为 0.02 秒。为了理解 LV 配置，我有 18 块磁盘，总共 32 个 LV。由于 PV 查询的执行时间比 LV 查询长，可以理解 PV 查询的优势并不总是适用。

监控方法仍然关注当前活动（varied）的卷组（Volume Groups），正如我们在 LV 方法中使用 `lsvg -o` 命令所做。通过使用这些活动 VG，我们可以查询每个 VG 并提取所有磁盘。我们拥有所有 PV 的完整列表，可以启动循环并独立地查询每一个。PV 查询的输出与列表 11.2 中的 LV 统计相似。查看列表 11.5 中使用 `lspv -l hdisk5` 对 `hdisk5` 进行 PV 查询。

```bash
# set -x # 取消注释以调试此 shell 脚本
# set -n # 取消注释以检查命令语法而不执行

THIS_HOST=$(hostname)      # 本地机器的主机
HDISK_LIST=""               # 初始化为空
STALE_PP_COUNT=0           # 初始化为零

# 在每一步通知用户
echo "\n正在收集查询的 hdisks 列表\n"

# 遍历每个活动的 VG

for VG in $(lsvg -o) 
do
    # 构建一个属于当前活动 VG 的 hdisk 列表
    echo "正在查询 $VG 的磁盘列表"
    HDISK_LIST="$HDISK_LIST $(lsvg -p $VG | grep disk | \
        awk '{print $1}')"
done

echo "\n开始对单个磁盘进行 hdisk 查询\n"

# 遍历上一个循环找到的每个 hdisk

for HDISK in $(echo $HDISK_LIST) 
do
    # 每次迭代查询一个新的 hdisk
    echo "正在查询 $HDISK 的过期分区"
    NUM_STALE_PP=$(lspv -l $HDISK | grep "STALE_PARTITIONS:" | \
        awk '{print $3}')
    # 检查过期分区数是否大于零
    if ((($NUM_STALE_PP > 0) ));
    then
        # 此 hdisk 至少有一个过期分区 - 进行报告
        echo "\n${THIS_HOST}: $HDISK 有 $NUM_STALE_PP 个过期分区"
        # 添加到 HDISK_LIST
        HDISK_LIST="$HDISK_LIST $HDISK"
    fi
done
```

## 方法 3：通过重同步进行 VG、LV 和 PV 监控

我们已经从两个角度查看了过期的磁盘镜像（stale disk mirrors），但我们可以在更高的层面（VG 级别）查找过期的磁盘分区。通过使用 `lvg` 命令，我们可以找到哪些 VG 具有过期的 PP（物理分区）。通过 `lvg <VG_name>` 命令，我们可以将查询缩小到有限数量的磁盘，尽管根据墨菲定律，它很有可能恰好是地球上最大的 VG！

我们遵循的策略是：首先使用 `lvg <VG_name>` 命令查询每个活动 VG 的 PV。然后，对于每个 `STALE PV` 大于 0 的 VG，我们在循环中查询当前的 VG 以获取关联的 PV 或磁盘列表。使用找到的所有 PV 列表，我们对每个磁盘进行查询，以找到与该 PV 关联的 LV（逻辑卷）以及 STALE 分区的值：由于每个 PV 必须至少有一个过期分区，我们会查询位于当前 PV 上的 LV 列表。请现在不要困惑！涉及的步骤是沿着食物链的自然演进——所有这些查询的最终结果是，我们知道了哪个 VG 和 LV 具有不同镜像，这正是我们想要的完整视图。

我们在本节中遵循的流程执行速度更快且易于理解，所以让我们开始吧。我们将使用的命令如列表 11.7 所示。

```
lsvg -o               生成活动 VG 列表
lsvg VG_NAME          查询目标 VG 的状态信息
lsvg -p $VG_NAME       生成该 VG 的 hdisk（硬件磁盘）列表
lspv $PV_NAME         查询由 $PV_NAME 指定 hdisk
lsp -l $PV_NAME      生成目标 hdisk 上的 LV 列表
lslv -l $LV_NAME       查询目标 LV 的状态信息
syncg HDISK_LIST     在 hdisk 级别同步镜像
sync -l $LV_LIST      在 LV 级别同步镜像
varyonly             仅同步过期分区
```
