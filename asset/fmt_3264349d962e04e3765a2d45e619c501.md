# 高级主题

`mysql` 程序实现的一种常用 SQL 命令是 `SHOW`。使用此命令可以提取有关 `MySQL` 服务器的信息，例如创建的数据库和表：

```
mysql> SHOW DATABASES;
+----------------------+
| Database             |
+----------------------+
| Information_schema   |
| mysql                 |
+----------------------+
2 rows in set (0.04 sec)
mysql> USE mysql;
Database changed
mysql> SHOW TABLES;
+----------------------+
| Tables_in_mysql     |
+----------------------+
| columns_priv         |
| db                   |
| help_category        |
| help_keyword         |
| help_relation        |
| help_topic          |
| host                 |
| proc                 |
| procs_priv           |
| tables_priv          |
| time_zone            |
| time_zone_leap_second|
| time_zone_name       |
| time_zone_transition |
| time_zone_transition_type|
| user                 |
+----------------------+
17 rows in set (0.00 sec)
```

在这个例例中，我使用了 `SHOW` SQL 命令显示在 `MySQL` 服务器上配置的数据库，然后使用 `USE` SQL 命令连接到单个数据库。你的 `mysql` 会话一次只能连接到一个数据库。

你会注意到在每个命令后我都添加了分号。分号表示向 `mysql` 程序发送的结束。如果你不使用分号，它会提示更多数据：

```
mysql> SHOW
  -> DATABASES;
```
