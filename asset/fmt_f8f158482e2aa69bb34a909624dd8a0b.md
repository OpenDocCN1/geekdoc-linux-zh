
## 时间测量与性能优化

我们使用 `time` 命令来测量程序运行的时间。`TIMEFORMAT` 变量用于指定 Linux 输出的时间格式，默认情况下为 POSIX 格式，该格式包含 CPU 使用率信息。

我们可以观察到，1MB 的输入文件 `file.in` 成功复制到了 `file.out`，后者仅具有所有者读权限（`S_IRUSR`）。然而，复制过程花费了大约 4.77 秒，并消耗了 95% 的 CPU 时间。这速度较慢，因为程序执行了数百万次系统调用。近年来，Linux 在系统调用和文件系统性能方面取得了巨大进步。

```bash
$ TIMEFORMAT="time " copy_system
1.07user 3.50system 4.77elapsed 95%CPU
```

通过改用大块复制可以改进这一性能。查看修改后的程序 `copy_block.c`，它再次使用系统调用，但按 1KB 块复制文件：

```c
#include <unistd.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <stdlib.h>

int main()
{
    char block[1024];
    int in, out;
    int nread;

    in = open("file.in", O_RDONLY);
    out = open("file.out", O_WRONLY|O_CREAT, S_IRUSR);

    while((nread = read(in, block, sizeof(block))) > 0)
        write(out, block, nread);
}
```

现在尝试运行该程序，首先移除输出文件：

```bash
$ rm file.out
$ TIMEFORMAT="" time copy_block
0.00user 0.01sys 0:00.01elapsed 62%CPU
```

现在程序只需约百分之一秒，因为它仅需约 2000 次系统调用。当然，具体数值取决于系统，但结果表明系统调用存在明显的开销，因此优化其使用频率是值得的。

## 管理文件的其他系统调用

还有许多其他针对低级文件描述符的系统调用。它们允许程序控制文件的使用方式并返回状态信息。

### lseek

`lseek` 调用用于设置文件描述符 `fildes` 的读写指针；也就是说，可以使用它来设定下一次读或写操作在文件中的位置。可以将指针设置为文件中的绝对位置，也可以相对于当前位置或文件结束的位置。

```c
#include <unistd.h>
#include <sys/types.h>

off_t lseek(int fildes, off_t offset, int whence);
```

`offset` 参数用于指定位置，而 `whence` 参数指定如何使用 `offset`。`whence` 可以是以下常量之一：

- `SEEK_SET`：`offset` 是绝对位置
- `SEEK_CUR`：`offset` 相对于当前位置
- `SEEK_END`：`offset` 相对于文件结束

`lseek` 返回从文件开头计算的新文件指针偏移量（以字节为单位），失败时返回 `-1`。用于表示寻址偏移量的 `off_t` 类型是在 `sys/types.h` 中定义的实现相关类型。

### fstat, stat 和 lstat

`fstat` 调用返回与打开的文件描述符关联的文件状态信息。信息被写入结构体 `buf` 中，其地址作为参数传递。

以下是相关头文件：

```c
#include <unistd.h>
#include <sys/stat.h>
#include <sys/types.h>
```

#### 函数原型

```c
int fstat(int fd, struct stat *buf);
int stat(const char *path, struct stat *buf);
int lstat(const char *path, struct stat *buf);
```

请注意，包含 `sys/types.h` 是可选的，但在调用系统调用时建议包含它，因为其中某些定义是标准类型的别名，未来可能会发生变化。

相关函数 `stat` 和 `lstat` 返回命名文件的状态信息。它们产生相同的结果，除非该文件是符号链接。`lstat` 返回关于链接本身的信息，而 `stat` 返回关于链接所指向的文件的信息。

`stat` 结构体的成员在不同的类 Unix 系统之间可能有所不同，但通常包含下表中的成员：

| `stat` 成员 | 说明 |
|---|---|
| `st_mode` | 文件权限和文件类型信息 |
| `st_ino` | 与文件关联的 inode 编号 |
| `st_dev` | 文件所在的设备 |
| `st_uid` | 文件所有者的用户 ID |
| `st_gid` | 文件所有者的组 ID |
| `st_atime` | 最后访问时间 |
| `st_ctime` | 权限、所有者、组或内容修改时间 |
| `st_mtime` | 内容最后修改时间 |
| `st_nlink` | 指向文件的硬链接数 |

`stat` 结构体返回的 `st_mode` 字段在头文件 `sys/stat.h` 中定义了一些关联宏。这些宏包含了权限和文件类型标志的名称，以及一些有助于测试特定类型和权限的掩码。

权限标志与此前的 `open` 系统调用相同。文件类型标志包括：

- `S_IFBLK`: 条目是块特殊设备
- `S_IFDIR`: 条目是目录
- `S_IFCHR`: 条目是字符特殊设备
- `S_IFIFO`: 条目是 FIFO（命名管道）
- `S_IFREG`: 条目是普通文件
- `S_IFLNK`: 条目是符号链接

其他模式标志包括：

- `S_ISUID`: 条目在执行时设置了 UID
- `S_ISGID`: 条目在执行时设置了 GID

用于解释 `st_mode` 标志的掩码包括：

- `S_IFMT`: 文件类型
- `S_IRWXU`: 用户读/写/执行权限
- `S_IRWXG`: 组读/写/执行权限
- `S_IRWXO`: 其他人的读/写/执行权限

还定义了一些确定文件类型的宏。这些宏只需将经过适当掩码的模式标志与合适的设备类型标志进行比较。它们包括：

- `S_ISBLK()`: 测试是否为块特殊文件
- `S_ISCHR()`: 测试是否为字符特殊文件
- `S_ISDIR()`: 测试是否为目录
- `S_ISIFO()`: 测试是否为 FIFO
- `S_ISREG()`: 测试是否为普通文件
- `S_ISLNK()`: 测试是否为符号链接

例如，要测试文件不是目录，且所有者具有执行权限但没有其他模式，可以使用以下测试：

```c
struct stat statbuf;
mode_t modes;

stat("filename", &statbuf);
modes = statbuf.st_mode;

if(!S_ISDIR(modes) && (modes & S_IRWXU) == S_IXUSR) {
    // ...
}
```

## 文件描述符复制：dup 和 dup2

`dup` 系统调用提供了一种复制文件描述符的方法，为我们提供两个或多个访问相同文件的不同描述符。这些描述符可以用于在文件的不同位置进行读写。`dup` 系统调用复制文件描述符 `fd`，返回一个新的描述符。`dup2` 系统调用通过指定用于复制的目标描述符，有效地将一个文件描述符复制到另一个。

### 函数原型

```c
#include <unistd.h>

int dup(int fd);
int dup2(int oldfd, int newfd);
```

## 标准 I/O 库

标准 I/O 库提供了一个通用的输入输出接口。它通过 `stdio.h` 头文件提供了许多用于格式化、扫描和引用数据的函数。

### fopen

`fopen` 函数打开由文件名指定的文件并与其关联流。`mode` 参数指定了打开文件的方式。注意与 MS-DOS 不同，UNIX 和 Linux 中处理的是所有类型的文件。

```c
#include <stdio.h>

FILE *fopen(const char *filename, const char *mode);
```

如果成功，`fopen` 返回一个非空指针。如果失败，则返回 `NULL`。`mode` 可以是以下字符串之一：

- `"r"`: 只读
- `"w"`: 只写（截空现有文件）
- `"a"`: 只写（追加到文件末尾）
- `"r+"`: 读写
- `"w+"`: 读写（截空现有文件）
- `"a+"`: 读写（追加到文件末尾）

### fclose

`fclose` 函数关闭指定的流，导致任何未写入的数据被写入。使用 `fclose` 是重要的，因为 `stdio` 库会缓存数据。

```c
#include <stdio.h>

int fclose(FILE *stream);
```

### fflush

`fflush` 函数清除文件流上的所有待写数据并立即写入。

```c
#include <stdio.h>

int fflush(FILE *stream);
```
