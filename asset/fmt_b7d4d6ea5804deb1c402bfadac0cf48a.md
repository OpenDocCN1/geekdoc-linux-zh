
# 天文学中的武士

天文学中的武士，无疑是天空中最精美的星座之一。猎户座是靠近天赤道的冬季星群。四颗最明亮的恒星，α、γ、β 和 κ，组成一个巨大的矩形（见图）。该星群被描绘成一个武士的形象，左手持盾，高举右臂挥舞球棒，准备击打冲锋的公牛。参宿四（意为腋窝），已知最大的恒星之一，是右肩上的红色恒星。参宿七位于左肩，而蓝白色恒星参宿三位于左腿。矩形中心附近直线排列的三颗亮星代表武士的腰带。中间的恒星是参宿二。参见星座；猎户座星云；金牛座。[C.S.V.]

## 猎户座星云

天空中明亮的发射星云，在梅西耶星表中被指定为 `M42`。猎户座大星云由电离氢和其他轻元素组成（见图）。该星云属于一类被称为 H II 区的天体（罗马数字 II 表示氢处于电离状态），这些区域标志着近期大质量恒星形成的地点。位于猎户座之剑，距离为 460 秒差距或 1500 光年（8.8 × 10¹⁵ 英里或 1.4 × 10¹⁶ 公里），猎户座星云由稠密的等离子体组成，由一组已知为梯形星团的年龄不超过 100,000 年的热星的紫外辐射电离。星云覆盖的面积略小于满月，借助双筒望远镜或小望远镜即可看到。参见猎户座。

通过亚利桑那州基特峰的直径 4 米（158 英寸）望远镜在照相底片上进行长时间曝光获得的猎户座星云可见光波段视图（国家光学天文台）。

除了梯形星团的大质量恒星外，猎户座星云还包含约 700 颗质量较小的恒星，它们挤在一个异常小的空间体积内。随着猎户座星云的演化，预计该星团将扩张，并可能消散到银河系平滑的背景恒星中。

哈勃太空望远镜的观察表明，猎户座星云中的许多小质量恒星被稠密气体和尘埃组成的盘所环绕。这些所谓的原行星盘（源自“原行星星盘”一词）似乎正在迅速失去质量给周围的星云。这些盘中的气体可能会凝结成行星。

## 鸟臀目

鸟臀目是众所周知的恐龙两大目之一（另一目为蜥臀目）。这两个目通过多种解剖学差异加以区分，但骨盆的形状是主要区别：鸟臀目为四生椎或表面呈“鸟类样”，而蜥臀目为三出椎。目级名称即指这些独特特征：“鸟臀型”和“蜥臀型”。与蜥臀类一样，鸟臀类可能起源于三叠纪早期或中期的鳍龙类（`Thecodontia`）。鸟臀类的化石记录见于从中三叠世到晚白垩世的岩层中，并在除南极洲以外的所有大洲均有发现。根据牙齿形状判断，所有鸟臀类都被认为是植食性动物。大多数种类具有特殊的喙或嘴，其下颌前端具有一块独特的 `predentary` 骨（前齿骨），用于啄食植物。许多种类拥有高度特化的牙齿列，用于压碎、研磨或切割植物组织。参见：蜥臀目。[J.H.J]

传统分类承认四个亚目：鸟脚亚目（`Ome-topoda`）、剑龙亚目（`Stegosauria`）、甲龙亚目（`Angylosauria`）和角龙亚目（`Ceratopsia`）。第五个亚目——厚头龙亚目（`Pachycephalosauria`）——是根据在蒙古的新发现而提出的。参见：恐龙。[J.H.J]

## 造山作用

造山作用是指山脉形成的过程。传统上，造山作用一词指大陆上形成的长条状山地的发育，这些山地被称为造山带或造山脊。其中包括北美洲的阿巴拉契亚造山带和科迪勒拉造山带，南美洲西部的阿尔卑斯式造山带（`Alpidic orogen`），欧洲北部和格陵兰东部的加里东造山带，以及从中欧延伸至中国东部的阿尔卑斯-喜马拉雅造山带。重要的是要认识到，这些构造体系仅代表那些仍保留山地高相对高程特征的最近几代造山带。事实上，大陆可以被视为由古老的造山带拼合而成的拼贴画，其中大多数因侵蚀过深，已完全不留其原始山地地形的痕迹。通过比较较新造山带中典型的岩石组合与其深度侵蚀后的对应物，地质学家推测，今天负责造山作用的过程在几乎整个（如果并非全部）地质历史时期都起作用，并在大陆的生长过程中发挥了主要作用。参见：大陆，演化。

在板块构造理论的背景下最能理解造山带的构造。造山带形成于汇聚型板块边界，即岩石圈板块发生碰撞之处。参见：岩石圈；板块构造。

汇聚型板块边界有两种基本类型，由此导致两类端元造山带的发育。大洋俯冲边界是指大洋岩石圈被推挤（俯冲）到大陆或大洋岩石圈之下的边界。俯冲过程导致深部板块边界附近的局部熔融，这表现为上覆板块上的火山和侵入岩浆活动。如果上覆板块由大洋岩石圈组成，结果就是形成洋内岛弧，例如日本列岛。如果上覆板块是大陆板块，则形成大陆弧。南美洲西部的安第斯山脉就是一个例子。参见：海洋地质；大洋岛屿；俯冲带。

第二类汇聚型板块边界形成于两个大陆之间的大洋盆地完全在海陆俯冲边界处消亡，且大陆发生碰撞之时。大陆碰撞造山作用形成了地球上一些最壮观的山脉；一个很好的例子是喜马拉雅造山带，它大约始于5000万年前，当时印度板块与亚洲大陆发生碰撞。由于在俯冲边界处破坏大洋岩石圈是大陆碰撞的先决条件，因此大陆碰撞造山带通常既包含在弧形成期间形成的变形特征和岩石组合，也包含由大陆碰撞产生的特征。[K.Ho]

## 雄黄

雄黄是一种矿物，化学成分为 $\mathrm{As_2S_3}$。晶体较小，呈板状，很少发育完善；该矿物更常见于片状或柱状集合体中。硬度为1.5-2（莫氏硬度），比重为3.49。光泽为树脂光泽至珍珠光泽，解理面上尤为明显；颜色为柠檬黄色。雄黄产于罗马尼亚、秘鲁、日本和俄罗斯。在美国，它产于犹他州的`Mercer`、内华达州的`Manhattan`，以及黄石国家公园中来自间歇泉水的沉积中。参见：砷。[C.S.Hu]

## 直壳纲

直壳纲是一类瓣鳃动物的目，包括该类最早已知的代表。它们最早出现于早寒武纪，并在奥陶纪时期变得特别繁盛和多样。随后，该群在志留纪和古生代晚期相对丰度下降，最终在二叠纪灭绝。该目大多数属于直壳亚纲（`Orthoidina`）。典型特征为双凸壳，壳面有细肋，铰线平直，两瓣均有发达的间区。参见：腕足动物。[J.R]

## 正长石

正长石是钾长石（$\mathrm{Or} \equiv \mathrm{KAlSi_3O_8}$），通常含高达30摩尔%的高岭石（`Ab ≡ NaAlSi_3O_8`）固溶体。其硬度为6；比重为2.57-2.5，取决于高岭石含量；平均折射率为1.52；颜色为白色至暗淡的粉色或橙褐色。某些正长石可能与相对纯净的高岭石共生，该高岭石在花岗岩、伟晶岩或花岗闪长岩从高温冷却过程中析出。这通常是有序的低温高岭石，但在罕见情况下，它可能显示出一定程度的铝/硅无序性，需要将其分类为文石或高温高岭石。如果肉眼可观察到析出相，则这种`Or-Ab`组成矿物称为纹长石（`orthopyre`）；如果需要显微镜检查才能区分相，则称为微纹长石（`microperthite`）；如果只有通过X射线衍射或电子光学方法才能检测到析出相，则称为隐纹长石（`crypto-perthite`）。正长石在光学上是斜方的。其在数百纳米尺度上平均的结构可能是斜方的，但其真正的对称性是三方的。参见：高岭石；晶体结构；纹长石。[P.R]

## 正交多项式

正交多项式是正交函数的一个特殊类别，出现在许多物理问题中（常作为微分方程的解）、分布函数的研究以及某些其他情形中，在这些情形中可以用多项式近似相当一般的函数。参见：概率论。每组正交多项式都是相对于特定的平均过程定义的。适当函数 `f` 的平均值表示为 `E(f)`。示例显示在公式(1)中。一般地，平均过程具有公式(2)所示的形式

$$E(f) \equiv \frac{1}{2} \int_{-1}^{1} f(x) dx \tag{1}$$

$$E(f) \equiv \int_{-\infty}^{\infty} f(x) \, d\sigma(x) \tag{2}$$

以及斯蒂尔杰斯积分，其中 `σ` 是一个分布函数，即一个递增函数，满足 `σ(-∞) = 0` 和 `σ(+∞) = 1`。

若 `E(f \bar{g}) = 0`（其中上划线表示复共轭），则两个函数 `f` 和 `g` 相对于给定的平均过程被称为正交的。与平均过程相关的正交多项式系指的是一系列多项式 `P_{0}, P_{1}, P_{2}, \ldots`，其中多项式 `P_{n}` 具有精确次数 `n`，且彼此正交，即对于 `m ≠ n`，有 `E(P_{m} \bar{P}_{n}) = 0`。最后一个条件等价于陈述每个 `P_{n}` 与所有次数低于 `n` 的多项式正交。因此 `P_{n}(x) = a_{0} + a_{1}x + a_{2}x^{2} + \ldots + a_{n}x^{n}`，其中 `a_{n} ≠ 0`，并受限于 `n` 个条件 `E(P_{n} \bar{P}_{k}) = 0`（对于 `k = 0, 1, \ldots, n - 1`），这给出了 `P_{n}` 的 `n + 1` 个系数中的 `n` 个线性方程，从而还留下一个称为归一化的条件需要施加。归一化方法在不同参考文献中有所不同。参见：多项式方程组。[C.S.He]
