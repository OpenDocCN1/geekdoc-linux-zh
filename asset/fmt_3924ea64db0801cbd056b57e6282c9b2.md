## 描述 (Description)

`as` 命令从汇编源文件创建对象。

> 注意 — 如果你使用 `-m`（调用 `m4(1)` 宏处理器）选项，你无法将关键字用作为 `m4(1)` 的符号（变量、函数、标签），因为 `m4(1)` 无法确定哪些关键字是汇器符号，哪些是真实的 `m4(1)` 宏。

尽可能通过编译接口（如 `cc(1)`）访问汇器。

所有未定义符号均被视为全局符号。

## 56. as

- `-n` 在汇编时抑制所有警告。

- `-o outfile` 将汇编输出输出到 `outfile` 中。默认情况下，输出文件名是通过移除输入文件名中的 `.s` 后缀（如果有的话）并添加 `.o` 后缀形成的。

- `-P` 在正在汇编的文件上运行 `cpp(1)`（C 语言预处理器）。预处理器会分别在每个输入文件上运行，而不是在它们它们合并后的文件上运行。将处理器的输出传递给汇编器。

- `-q | n` 如果你指定 `n` 选项，则在输出对象文件的注释部分生成汇编器版本信息。如果你指定 `y` 选项，则抑制该信息。

- `-s` 将所有 stabs 放在 `.abs` 段中。默认情况下，将 stabs 放在 `.abs.excl` 段中，这些段在最终执行期间会被静态链接器 `ld(1)` 剥离。当你使用 `-s` 选项时，stabs 将留在最终的可执行文件中，因为 `.stab` 段不会被静态链接器剥离。

- 新选项 `-S [a | b | c | 1 | A | B | C | L]` 将发射的代码反汇编到标准输出。在 `-S` 选项后添加以下每个字符之一可以产生：

    + `a` 带地址的反汇编。

    + `b` 带 `.bof` 反汇编。

    + `c` 带注释的反汇编。

    + `l1` 带行号的反汇编。

    大写字母关闭相应的选项。

- 新选项 `-T` 将 4.x 汇编文件中的符号名解释为 5.x 符号名。此选项用于在 5.x 系统上汇编 4.x 汇编文件。

- `-U` 当 `-P` 选项生效时，将此选项传递给 `cpp(1)` 预处理器而不经过解释；否则忽略它。

- 新选项 `-V` 向标准错误输出写入正在运行的汇编器版本。

- `-xF` 使用 Sun Workshop 分析器为可执行文件的性能分析生成额外信息。如果输入文件不包含任何 stabs（调试指令），则汇编器将生成 Sun Workshop 分析器所需的默认 stabs。另请参考 Sun Workshop 提供的 dbx 手册页。

以下选项仅适用于 SPARC：

- `-q` 执行快速汇编。当你使用 `-q` 选项时，不会进行许多错误检查。注意：此选项禁用了许多错误检查。建议不要使用此选项汇编手写的汇编语言。

## 57. as

- `-xarch=v7` 指示汇编器接受 SPARC 版本 7 (V7) 架构中定义的指令。生成的对象代码为 ELF 格式。

- `-xarch=v8` 指示汇编器接受 SPARC-V8 架构中定义的指令，但不包括双精度浮点指令。生成的对象代码为 ELF 格式。

- `-xarch=v8a` 指示汇编器接受 SPARC-V8 架构中定义的指令，但不包括双精度浮点指令和 `fsmuld` 指令。生成的对象代码为 ELF 格式。此选择是 `-xarch=options` 的默认值。

- `-xarch=v8plus` 指示汇编器接受 SPARC-V9 架构中定义的指令，但不包括双精度浮点指令。生成的对象代码为 ELF 格式。它不在 Solaris V8 系统（带有 V8 处理器的机器）上执行。它在 Solaris V8+ 系统上执行。

- `-xarch=v9` 限制指令集到 SPARC-V9 架构。生成的 `.o` 对象文件为 64 位 ELF 格式，且只能与相同格式的对象文件链接。生成的可执行文件只能在运行 64 位内核的 64 位 Solaris 的 64 位 SPARC 处理器上运行。

- `-xarch=v9a` 限制指令集到 SPARC-V9 架构，增加了视觉指令集 (VIS) 以及 UltraSPARC 处理器的特定扩展。生成的 `.o` 对象文件为 64 位 ELF 格式，且只能与相同格式的对象文件链接。生成的可执行文件只能在运行 64 位内核的 64 位 Solaris 的 64 位 SPARC 处理器上运行。

## at, batch

`batch` 命令读取要在稍后执行的命令。它等同于命令 `at -q b -m now`，其中队列 `b` 是专门为批处理作业设计的特殊队列。批处理作业提交到批处理队列以便立即执行。

## 选项

如果不使用 `-c`、`-k` 或 `-s` 选项，将由 `SHELL` 环境变量决定使用哪种 shell。

- `-c` 使用 C shell (`csh(1)`) 执行 at 任务。

- `-k` 使用 Korn shell (`ksh(1)`) 执行 at 任务。

- `-s` 使用 Bourne shell (`sh(1)`) 执行 at 任务。

- `-f` 指定文件路径作为 at 任务的源，而不是标准输入。
