
与 Bourne shell 不同，C shell 区分环境变量和 shell 变量之间的区别。环境变量会自动导出到 shell 调用的进程中。shell 变量则不会。在变量替换下，这两类变量的处理方式类似。shell 在初始化时设置 `argv`、`cwd`、`home`、`path`、`prompt`、`shell` 和 `status` 变量。shell 将环境变量 `USER` 复制给 shell 用户，`TERM` 复制给 `term`，`HOME` 复制给 `home`，并在每次 shell 变量重置时将它们复制回相应的环境变量。`PATH` 和 `path` 的处理方式类似。你需要在 `.cshrc` 或登录文件中设置一次。每当 `cwd` 变化时，环境变量 `PWD` 就会被设置。下面显示的 shell 变量具有预定义的含义。

- `argv`: 提供给当前 shell 调用 的命令行参数列表。此变量决定了位置参数 `$1`、`$2` 等的值。
- `cdpath`: `cd`、`chdir` 和 `popd` 命令搜索的目录列表，如果目录参数不是当前目录的子目录。
- `cwd`: 当前目录的全路径名。
- `echo`: 在执行前回显（替换后）`echo` 命令。
- `ignoreore`: 在尝试文件名补全时要忽略的文件后缀列表。通常是单个单词 `.o.`。
- `file`: 启用文件名补全，在这种情况下，在终端输入行末尾输入 `Control-D` (EOT) 和 `ESC` 字符具有特殊意义。
- `EOT`: 打印所有以先前的字符串开头的文件列表。
- `ESC`: 将替换为最长无歧义扩展。
- `hardpaths`: 解析目录栈中的路径名，使其不包含符号链接组件。注意符号链接可以找到 shell。设置 `hardpaths` 变量可以缓解这个问题。
- `histchars`: 两个字符的字符串。第一个字符替换 `!` 作为历史替换字符。第二个字符替换脱字符（`^`）以进行快速替换。
- `history`: 保存在在历史列表中的行数。非常大的数字会占用 C shell 的所有内存。如果不设置，C shell 只保存最近的一条命令。
- `home`: 用户的家目录。`~` 的文件名扩展引用的是此变量的值。
- `ignoreof`: 忽略终端的 EOF（文件结束符）。此变量防止通过输入 `Control-D` 意外杀掉 C shell。
- `mail`: C shell 检查邮件的文件列表。如果值的第一个单词是数字，则指定以秒为单位的邮件检查间隔（默认 5 分钟）。
- `nobeep`: 当请求 C shell 扩展歧义的文件名时，命令完成期间抑制铃声。
- `noclobber`: 限制输出重定向，以免现有文件被意外破坏。`>>` 重定向只能指向新文件。
- `noglob`: 抑制文件名替换。一旦获取了文件名（如果有的话）且不再需要进一步扩展，此变量在 shell 中最为有用。
- `non-match`: 如果模式未匹配，则返回文件名替换模式而不是错误。格式不正确的模式会导致错误。
- `notify`: 在作业完成后立即通知你，而不是等到在发布提示符之前。
- `path`: 搜索命令的目录列表。`path` 从环境变量 `PATH` 初始化，C shell 每当 `path` 变化时更新它。空单词指定默认路径（通常是 `/usr/bin`）。如果 `path` 被取消设置，则只执行全路径。交互式 C shell 在读取 `.shrc` 后以及每次 `path` 重置时，会对列目录的内容进行哈希处理。如果添加了新命令，使用 `hash` 命令更新。
- `prompt`: 交互式 shell 的字符串。非交互式 shell 不设置提示符。默认显示输出来自 `%U`、`%S`、`%E`、`%P` 等标签。
- `savehist`: 保存在历史列表中的行数。`savehist` 值过大会减慢 shell。
- `shell`: C shell 所在的文件。此变量在派生的 shell 中是可执行的。
- `status`: 最近一个命令返回的状态。如果该命令异常终止，则状态加 200。失败的内置命令返回 1；所有其他内置命令设置为 0。
- `time`: 控制命令的自动计时。可以提供一个或两个值。第一个是以秒为单位的报告阈值。第二个是指示报告哪些标签字符串。标签是一个百分号跟一个大写字母（无法识别的标签将作为文本打印）：
  - `%D` 未共享数据的平均量，单位为 KB。
  - `%E` 命令执行的经过时间（墙钟时间）。
  - `%F` 页面错误数。
  - `%I` 块输入操作次数。
  - `%K` 未共享栈空间的平均量，单位为 KB。
  - `%M` 进程执行期间使用的最大内存。
  - `%O` 块输出操作次数。
  - `%P` 总 CPU 时间（用户 U 加上系统 S）占经过时间 E 的百分比。
  - `%S` 内核代表用户进程消耗的 CPU 秒数。
  - `%U` 投入用户进程的 CPU 秒数。
  - `%W` 交换次数。
  - `%X` 共享内存的平均量，单位为 KB。

## csh 文件

- `~/.cshrc` 在每个 shell 执行开始时读取。
- `~/.login`: 登录 shell 在登录时读取 `.cshrc` 后读取。
- `~/.logout`: 登录 shell 在注销时读取。
- `~/.history`: 供下次登录使用的保存历史。

# csplit — 基于上下文拆分文件

### 概要

```
/usr/bin/csplit [-ks] [-f prefix] [-n number] file arg1 argn
```

### 描述

使用 `csplit` 命令将文件拆分为部分。`csplit` 命令读取由文件操作数命的文件，根据 `arg` 操作数的指示将该文件的全部或部分写入其他文件，并写入文件的大小。

### 选项

- `-k` 保留之前创建的文件。默认情况下，如果发生错误，`csplit` 会删除已创建的文件。
- `-s` 抑制文件大小消息的输出。
- `-f prefix` 创建的文件命名为 `prefix0,prefix01,prefixn`。默认是 `xx00...xxn`。如果 `prefix` 参数创建的文件名超过 14 字节，则发生错误；`csplit` 将带诊断消息退出且不创建任何文件。
- `-n number` 指定用于形成分段文件名的位数。默认从 00 开始。例如，如果你指定 `-n 4`，输出文件将从 `xx0000` 开始编号。

### 操作数

- `file` 待拆分文本文件的路径。如果 `file` 为 `-`，则使用标准输入。
- `arg1...arg` 操作数 `arg1...arg` 可以是以下内容的组合：
  - `/reexp/[offset]`
    使用从当前行到应用了偏移量（如果有）的正则表达式评估结果的行（但不包含该行）之间的内容创建一个文件。正则表达式 `reexp` 必须遵循基本正则表达式的规则。可选的 `offset` 必须是一个正整数或负整数值，表示行数。该整数值前必须有 `+` 或 `-`。如果从这种类型的 `offset` 表达式中选择行会创建一个行数为零的文件，或大于输入文件中剩余行数的文件，则结果未定义。在创建部分后，当前行被设置为应用了任何偏移量的正则表达式评估结果的行。`reexp` 的模式匹配始终从当前行应用到文件末尾。
  - `%reexp%[offset]` 此操作数与 `/reexp/[offset]` 相同，但不会为输入文件的选定部分创建文件。
  - `line-no` 从当前行到但不包含行号 `line-no` 所在的行创建一个文件。文件中的行从 1 开始编号。当前行变为 `line-no`。例如，内联参数 `100` 会在每个文件中放置 99 行。
  - `"(num)"` 重复操作数。此操作数可以跟在之前描述的任何操作之后。如果它跟随 `rex` 类型操作数，如果操作数未引用当前位置到文件末尾之间的行，`csplit` 将报告错误。
