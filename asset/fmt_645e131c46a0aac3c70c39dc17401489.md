X 支持字节/字符、双字节/字符矩阵以及 16 字符文本操作。这些形式中的任何一种都不能与字体配合，但单字节/字符文本请求只能指定单个字节（即 2 字节字体的第一行）。你应该将 2 字节字体视为一个定义字符的二维矩阵：字体指定了行的范围，`byte2` 定义了字体中定义列的范围。单字节/字符字体定义了一行，结构体中指定的 `byte2` 范围定义了一个字符范围。

字符的边界框由该字符的 `XCharStruct` 定义。当字体中缺少字符时，使用 `default_char`。当字体所有字符大小相同时，则仅使用 `XFontStruct` 中 `min` `max` 边界中的信息。

`XFontStruct` 的成员具有以下语义：

- `direction` 成员可以是 `FontLeftToSort` 或 `FontRightToSort`。它只是一个提示，说明大多数 `XStruct` 元素的字符宽度为正（`FontLeftToRight`）或为负（`FontRightToLeft`）。该度量标准不支持垂直文本。
- 如果 `min byte1` 和 `max byte1` 成员均为 0，则 `min_char_or_byte2` 指定对应于 `per char` 数组第一个元素的线性索引，`max_char_or_byte2` 指定最后一个元素的线性索引。
- 如果 `min byte1` 或 `max byte1` 任一不为零，则 `min_char_or_byte2` 和 `max_byte2` 均小于 256，且对应于 `per char` 数组元素 $N$（从 0 开始计数）的 2 字节字符值为：
  - `byte1 = N/D + min byte1`
  - `byte2 = N%D + min char_or_byte2`
  - 其中：
    - $D = max\_char\_or\_byte2 - min\_char\_or\_byte2 + 1$ / 整数除法 \ 整数取模
- 如果字符指针为 `NULL`，则第一个和最后一个字符索引之间的字形具有相同的信息，由 `min bounds` 和 `max bounds` 提供。
- 如果 `all_chars_exists` 为 `True`，则 `per_char` 数组中的所有字符都有非零的边界框。
- `default_char` 成员指定在打印未定义或不存在的字符时使用的字符。默认字符是一个 16 位字符（不是 2 字节字符）。对于使用 2 字节矩阵格式的字体，默认字符的 `byte1` 位于最高字节，`byte2` 位于低位字节。如果 `default_char` 指定的是未定义或不存在的字符，则对该字符不进行打印。

## 加载和释放字体

Xlib 提供了你用于加载字体、获取字体信息、卸载字体的函数，某些字体使用 GContext 资源 ID 或字体 ID。

要加载给定的字体，请使用 `XLoadFont`。

```c
Font XLoadFont(display, name);
```

指定到 X 服务器的连接。

指定字体的名称，这是一个空终止字符串。

`XLoadFont` 函数加载指定的字体并返回其关联的字体 ID。如果字体不在主机可移植字符编码中，结果取决于实现。大小写不敏感。当在字体中使用 `?` 和 `*` 时，将执行模式匹配并使用任何匹配的字体。在模式中，`?` 字符将匹配任何

单字符，且 `*` 字符将匹配任意数量的字符。字体名的结构化格式在 X 联盟逻辑字体描述规范（Logical Font Description Conventions）中指定。如果 `XLoadFont` 未能加载指定的字体，会发生 `BadName` 错误。字体不与特定屏幕关联，可以作为任何 GC（图形上下文）的组件存储。当不再需要时，调用 `XUnFont`。

`XLoadFont` 可能会产生 `BadAlloc` 和 `BadName` 错误。

要返回可用字体的信息，请使用 `XQueryFont`。

```c
XFontStruct *XQueryFont(display, font_ID);
```

- `display` 指定与 X 服务的器的连接。
- `font_ID` 指定字体 ID 或 GContext ID。

`XQueryFont` 函数返回一个指向 `XFontStruct` 实例的指针，该结构包含与字体相关的信息。你可以对字体进行查询，或将其存储在 GC 中。存储在 `XFontStruct` 中的字体 ID 将是 GContext ID，在其他函数中使用此 ID 时需要小心（参见 `XGetFontFrom`）。如果字体不存在，`XQueryFont` 返回 `NULL`。要使用数据，请使用 `XFreeInfo`。

要在单个操作中执行 `XLoadFont` 和 `XQueryFont`，请使用 `XLoadQueryFont`。

```c
XFontStruct *XLoadQueryFont(display, name);
```

- `display` 指定与 X 服务的器的连接。
- `name` 指定字体名称，这是一个以空 结尾的字符串。

`XLoadQueryFont` 函数提供了访问字体的最常用方法，`XLoadQueryFont` 同时打开（加载）字体并返回指向相应 `XFontStruct` 的指针。如果字体不在主机可移植字符编码（Host Portable Character Encoding）中，结果取决于实现。如果字体不存在，`XLoadQueryFont` 返回 `NULL`。

`XLoadQueryFont` 产生 `BadAlloc` 错误。

要卸载字体并释放由 `XQueryFont` 或 `XLoadQueryFont` 分配的字体结构存储空间，请使用 `XFreeFont`。

```c
XFreeFont(display, font_struct);
```

- `display` 指定与 X 服务的器的连接。
- `font_struct` 指定与字体关联的存储。

`XFreeFont` 删除字体资源 ID 与指定字体之间的关联，并释放 `XFontStruct` 结构。当没有其他资源引用它时，字体本身将被释放。之后不应再次引用该数据和字体。

`XFreeFont` 可能会产生 `BadFont` 错误。

要返回指定的字体属性，请使用 `XGetFontProperty`。

```c
Bool XGetFontProperty(font_struct, atom, value_return);
```
