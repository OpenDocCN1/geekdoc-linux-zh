
# 舟足总

**舟足总。** 虾和磷虾中最大且多样性最多的群体。第一腹节覆盖在第二腹节上；第三对不是足；没有腹节或尾节。雌性通常通过雄性体内第二对腹足内侧分支上的两个小刺来区分。十足足类分布于海洋的所有部分，通常与其他海洋动物单独生活。长脚科和古虾科两个科的成员也广泛分布于淡水。北欧和北美西北部的食用虾类（属于舟足总中的 `Cragon` 属和 `Pandalus` 属）是热带大虾属 `Macrobrachium`。大多数蟹是喜欢的食物。某些节壳动物维持“服务站”，在那里它们清除鱼外皮、口和鳃上的寄生虫。已知超过 1500 种蟹。

## 跳科

跳科是一类小虾，其第二对腹足在表象上可识别为尾节。第三对腹足比第一对大得多也更粗壮；第二对不与第一对重叠，且没有步足或尾节。在 20 或多个活物种中是海洋性的；某些与海绵等其他动物紧密相关。

### 海虾科（Eonidae）

海虾科（Eonidae）是皮肤薄的深海居民。甲壳扁平并显著缩小。第一对步足是螯足，第一对明显伸长。在约 400 种活物种中，大多数是海洋性的；某些具有重要意义。约有 85 种。

### 泥足虾科（Thachycaridae）

泥足虾科（Thachycaridae）通常是皮肤薄的穴居节壳动物，第一对具有螯，第三对步足没有螯。超过 250 种活物种分布于全球浅海和深海，特别是热带和温带地区。这一中间且潜在不确定的群体位于异足亚和短足目之间。它包括蟹、岩蟹、仙蟹、王蟹和泥蟹。几乎所有这些多样的节壳动物，有时第一组和最后一组步足是螯足。腹部通常不对称，且柔软或坚硬。已知约 1300 种。

# 分贝

一种用于表示功率、电压、电流或声音变化幅度的单位。分贝（dB）等于10贝耳（bel）。在声学中，10分贝对我们大多数人来说太大了。它通常用于用分贝表示强度。相对于参考值 `I0`，声音强度 `I` 的分贝级由公式(1)给出。因为声强

```
10 log10(I/I0) (1)
```

与声压 P 的平方成正比。参考压力为：

```
10 log10(P/P0) = 20 log10(P/Pr) (2)
```

取值为 0.0002 $cm^2/dyn$ 或微巴（microbar）。海平面处的大气压力约为1巴（bar）。参见 SEE：声音；压力。

奈珀（neper）是分贝的比例单位，但基于自然对数（奈尔数）。1奈珀等于8.68 dB。参见 NEPER：音量单位（VU）。[K.D.]

## 问题分类

决策理论的努力可以分为：

- 1. 问题通过识别可行方案来结构化，这些方案可能是采取或可能的，其中一些会发生，另一些不发生；结果取决于决策和事件问题的组合。
- 2. 决策不确定性问题是指在给定自然状态下，事件发生无法被完美预测。在给定情况下，对事件发生的确定程度由事件的概率来衡量。
- 3. 决策概率不精确问题是指在给定自然状态下，可能产生多种结果，且这些状态发生的概率规定不当。与不确定性参数相关的概率不精确。
- 4. 决策信息不完全问题是指在给定自然状态下，可能产生多种结果，且这些状态发生的概率不完全。存在相关的结果，且未知的信息是已知的。
- 5. 决策冲突与协作问题涉及多一个决策者，且一个决策者的目标和活动并非所有决策者所知。
