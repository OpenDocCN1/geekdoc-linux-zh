
# `sort` 命令

`sort` 命令用于使用第二个字段作为排序键对 `file.txt` 的行进行排序（`-k 2` 表示排序键是文件的第二列）。默认情况下，`sort` 按升序对行进行排序。

以下是该命令每个元素的更详细解释：

`sort`：这是要执行的命令名称。

`-k 2`：这是排序键选项，指示应使用第二列作为排序键。如果文件的列是用空格以外的字符分隔的，你可以使用 `-t` 选项来指定列分隔符字符。

`file.txt`：这是要排序的文件名。

当你运行此命令时，`sort` 将使用第二个字段作为排序键对 `file.txt` 中的行进行排序，并将排序后的行打印到标准输出。

```
sort -t ',' -k 2 file.txt
```

`sort` 命令用于使用逗号作为字段分隔符，使用第二列作为排序键对文件 `file.txt` 的行进行排序。

以下是该命令每个元素的详细解释：

- `sort`：这是要执行的命令名称。
- `-t ','`：这是字段分隔符选项，指示应使用逗号作为字段分隔符。
- `-k 2`：这是排序键选项，指示应使用第二列作为排序键。
- `file.txt`：这是要排序的文件名。

```
cat sales.txt
```

```
John,Jan,1000,200
Jane,Feb,1500,100
Michael,Mar,2000,300
Alex,Apr,1000,150
```

该命令使用逗号作为字段分隔符，根据第三列（收入）对条目进行排序。

```
sort -t "," -k 3 sales.txt
```

```
Alex,Apr,1000,150
John,Jan,1000,200
Jane,Feb,1500,100
Michael,Mar,2000,300
```

该命令使用相同的字段分隔符，根据第四列（利润）对条目进行排序，并按升序排序。

```
sort -t "," -k 4 -n sales.txt
```

```
Jane,Feb,1500,100
Alex,Apr,1000,150
John,Jan,1000,200
Michael,Mar,2000,300
```

# `uniq` 命令

`uniq` 命令用于过滤文本文件中的重复输入或管道的输出。它可以消除在合并多个文件或运行某些命令时可能出现在文件中重复条目。

以下是 `uniq` 命令使用的选项：

- `-c`：显示每个唯一条目在文件中出现的次数。
- `-d`：仅显示重复条目。
- `-u`：仅显示唯一条目。
- `-i`：比较输入时忽略大小写。

`uniq file.txt`

从 `file.txt` 中的重复行并显示结果。重复行必须连续出现。`uniq` 命令设计用于删除连续的重复。如果你想使用 `uniq` 命令删除文件中的重复，必须先对文件进行排序。

```
cat names.txt
```

```
jane
John
Alex
Alex
Michael
jane
```

```
uniq names.txt
```

```
jane
John
Alex
Michael
```

```
sort file.txt | uniq
```

首先对 `file.txt` 中的行进行排序，然后使用管道 `|` 连接两个命令来移除重复行。

```
uniq -c file.txt
```

`uniq -c file.txt` 命令读取文本文件 `file.txt` 的内容，并显示文件中存在的唯一行列表，并带上每行出现的次数。

如果文本文件 `file.txt` 的内容如下：

```
Good morning
Good morning
Hi
Hello
Hello
Hello
```

当你运行命令 `uniq -c file.txt` 时，它将显示以下输出：

```
2 Hello
1 Hi
3 Hello
```

```
uniq -i file.txt
```

`uniq -i file.txt` 命令与 `uniq file.txt` 命令相似，不同之处增加了 `-i` 选项，以便在比较连续行时忽略大小写区别。

所以，当你运行命令 `uniq -i file.txt` 时，它读取文本文件 `file.txt` 的内容，并显示文件中唯一的行列表，忽略大小写区别。如果文本文件 `file.txt` 的内容如下：

```
Good morning
Good morning
Hi
Hello
Hello
Hello
```

当你运行命令 `uniq -i file.txt` 时，它将显示以下输出：

```
2 Good morning
1 Hi
3 Hello
```

```
uniq -u file.txt
```

该命令允许仅显示文件中出现一次的行，即唯一的行。此命令对于从文件中提取单行非常有用。

以下是该命令每个元素的更详细解释：

`uniq`：这是要执行的命令名称。

`-u`：这是允许仅显示唯一行的选项，即文件中只出现一次的行。

`file.txt`：这是要处理的文件名。

```
uniq -d data.txt
```

`uniq -d data.txt` 命令显示文件中重复或重复的行。`-d` 选项意味着只显示重复行。

它允许你读取标准输入（通常来自键盘），并同时将其重定向到标准输出（通常是屏幕）以及一个或多个文件。

这在许多情况下都非常有用。如果你正在运行产生大量输出的命令，可以使用 `tee` 命令将输出重定向到文件以供以后访问，同时让输出在屏幕上显示。

`tee` 的语法非常简单。只需在 `tee` 命令后面指定你想将输出重定向到的文件名，用空格分隔。例如，要将输出重定向到文件 `myfile.txt` 同时同时在屏幕上显示，可以使用以下命令：

```
command | tee myfile.txt
```

这将命令输出重定向到 `myfile.txt`，同时在屏幕上显示。

通过在 `tee` 命令中使用 `a` 选项，可以将输出追加到现有文件的末尾，而不是覆盖它。例如：

```
command | tee -a myfile.txt
```

这将命令输出追加到 `myfile.txt` 文件的末尾，而不是覆盖它。

## 将命令输出重定向到文件

假设你运行了一个命令来生成输出，例如使用 `ls` 命令列出目录中的文件。你可以使用 `tee` 命令将命令输出重定向到文件，如下：

```
ls | tee file.txt
```

这会运行 `ls` 命令并将输出重定向到屏幕和 `file.txt` 文件。你将能够在屏幕上看到输出，它也会被保存到 `file.txt` 文件中。如果文件不存在，它将自动创建。

## 将命令输出追加到现有文件的末尾

如果你想将命令的输出追加到现有文件的末尾，而不是覆盖其内容，可以使用 `tee` 命令的 `-a` 选项。例如：

```
ps aux | tee -a process.txt
```

这会运行 `ps aux` 命令显示正在运行的进程并将输出追加到 `process.txt` 文件的末尾。

## 将输出重定向到多个文件

`tee` 命令还允许将输出重定向到多个文件。如果你想将命令的输出重定向到两个不同的文件，可以使用带有多个文件名的 `tee` 命令。这是一个示例：

```
ping google.com | tee result1.txt result2.txt
```

这会运行 `ping google.com` 命令测试与 Google 的连接，并将输出重定向到 `result1.txt` 和 `result2.txt` 文件。

# `sed` 流编辑器命令

`sed` (Stream EDitor) 命令是一个流编辑器，可用于对文件的输入或管道的输出进行转换。它是处理大量数据的强大工具，可以用于执行字符串替换、删除行、插入行等任务。

```
sed 's/old/new/g' file.txt
```

将 `file.txt` 中所有的 `old` 替换为 `new` 并显示结果。

表达式 `s/old/new/g` 被用于执行替换。

在下面的示例中，`sed` 命令将 `names.txt` 文件中每行出现的第一个 `Jane` 替换为 `Sarah`。

```
cat names.txt
```

```
jane
John
Alex
Michael
```

```
sed 's/Jane/Sarah/' names.txt
```

```
Sarah
John
Alex
Michael
```

`sed 's/^#/#/' file.txt` 命令在 `file.txt` 文件的每一行开头添加一个 `#` 字符。

```
sed 's/^#/#/' file.txt
```

以下是对命令中每个元素的更详细解释：

- `sed`：这是将执行的命令名称。
- `s/^#/#/`：这是用于替换文件中每行开头的正则表达式。
- `s` 表示 `substitution`。
- `^` 是匹配每行开头的正则表达式。
- `#` 是将添加到每行开头的字符。
- `file.txt`：这是要处理的文件名。

当你运行此命令时，`sed` 会在 `file.txt` 文件的每一行开头附加 `#` 字符，并将结果打印到标准输出。因此，原始文件的每一行开头都用 `#` 字符进行了注释。

请注意，此命令不会修改原始文件，它只将结果打印到标准输出。如果你想将结果保存到一个新文件中，可以使用重定向命令 `sed 's/^#/#/' file.txt > new_file.txt`。

```
sed '4,$ d' file.txt
```

`sed '4,$ d' file.txt` 命令会删除 `file.txt` 文件从第 4 行到行尾的所有行。

以下是对命令中每个元素的更详细解释：

- `sed`：这是将执行的命令名称。
- `4,$ d`：这是用于删除文件行的表达式。
- `4` 是开始删除的行号。
- `$` 代表文件的最后一行。
- `d` 表示 `delete`。
- `file.txt`：这是要处理的文件名。

当你运行此命令时，`sed` 会删除 `file.txt` 从第 4 行到行尾的所有行并将结果打印到标准输出。

请注意，此命令不会修改原始文件，它只将结果打印到标准输出。如果你想将结果保存到一个新文件中，可以使用重定向命令 `sed '4,$ d' file.txt > new_file.txt`。

```
sed -n '5p' file.txt
```

`sed -n '5p' file.txt` 命令显示 `file.txt` 的第 5 行。

以下是对命令中每个元素的更详细解释：

- `sed`：这是将执行的命令名称。
- `-n`：该选项阻止显示文件中除指定命令以外的所有行。
- `5p`：这是显示第 5 行的命令。
- `5` 是要显示的行号。
- `p` 代表 `print`。
- `file.txt`：这是要处理的文件名。

当你运行此命令时，`sed` 将 `file.txt` 的第 5 行打印到标准输出。

如果你想将结果保存到一个新文件中，可以使用重定向命令 `sed -n '5p' file.txt > new_file.txt`。

```
sed '/^[ \t]*/' file.txt
```

`s/[ \t]*// file.txt` 命令删除 `file.txt` 每一行开头的空格和制表符。

以下是对命令中每个元素的更详细解释：

- `sed`：这是将执行的命令名称。
- `s/[ \t]*//`：这是用于删除每行开头空格和制表符的正则表达式。
- `s` 表示 `substitution`。
- `^` 是匹配每行开头的正则表达式。
- `[ \t]*` 是匹配零或多个空格和/或制表符的正则表达式。
- ``（空字符串）用于替换匹配的空格和制表符。
- `file.txt`：这是要处理的文件名。

当你运行此命令时，`sed` 会删除 `file.txt` 每一行开头的空格和制表符并将结果打印到标准输出。

# `df` 命令

Linux 中的 `df` 命令用于显示文件系统磁盘空间的使用情况。以下是该命令的详细说明：

语法：`df [options] [挂载点或目录]`

当不带任何选项或参数运行时，`df` 命令会显示系统中所有挂载文件的磁盘空间使用情况。

常用选项：

- `-h` 或 `--human-readable`：使用人类可读的格式显示大小（例如用 `1K`、`1M`、`1G` 而不是字节数字）。
- `-T` 或 `--print-type`：显示文件系统类型（例如 `ext4`、`ntfs` 等）。
- `-t` 或 `--type`：只显示指定类型的文件系统（例如 `ext4`、`ntfs` 等）。
- `-x` 或 `--exclude-type`：排除指定类型的文件系统（例如 `tmpfs`、`devtmpfs` 等）。
- `-i` 或 `--inodes`：显示 inode 使用信息（而不是磁盘空间使用情况）。

挂载点或目录：

如果你指定一个挂载点或目录作为参数，该命令将仅显示包含该挂载点或目录的文件系统信息。

用法示例：

- `df -h`：使用人类可读的格式显示磁盘空间使用情况。
- `df -T`：显示每个文件系统的磁盘空间使用情况和文件系统类型。
- `df -t ext4`：只显示 `ext4` 类型文件系统的磁盘空间使用情况。
- `df /home`：显示包含 `/home` 挂载点的系统磁盘空间使用情况。

要找到满硬盘上占据最多磁盘空间的目录，你可以运行以下命令：

```
du -h / | sort -rh | head -n 20
```

命令 `du -h / | sort -rh | head -n 20` 用于查找文件系统根分区 `/` 分区上占据最多磁盘空间的目录。以下是该命令链中每个命令的作用：

- `du -h /`：该命令计算文件系统根 `/` 分区上每个目录和文件的大小，采用“人类可读” `-h` 格式。结果显示在标准输出上。
- `sort -rh`：该命令根据大小 `-h` 降序 `-r` 对 `du` 命令的结果进行排序。
- `head -n 20`：该命令显示排序后结果的前 20 行（即占据最多磁盘空间的 20 个目录）。

`du` (Disk Usage) 命令用于查找文件系统中文件和目录所在的大小。它对于识别哪些文件或目录占据了最多的磁盘空间以及优化存储使用非常有用。

默认情况下，`du` 命令显示指定目录内每个目录和子目录的大小。如果没有指定目录，`du` 命令将显示当前目录目录下所有文件和目录的大小。

`du` 的语法如下：

```
du [options] [文件或目录]
```

常用选项：

- `-h` 或 `--human-readable`：以人类可读的格式显示大小（例如 1K, 2M, 3G 等），而不是字节。
- `-s` 或 `--summarize`：仅显示每个参数的总和。
- `-c` 或 `--total`：在输出末尾生成一个总计。
- `-a` --all：包含文件，而不只是目录。
- `-b` 或 `--bytes`：以字节输出大小。

使用人类可读的格式显示磁盘空间使用：

```
df -h
```

```
du -h -s /* | sort -h | tail -n 5
```


此命令显示文件系统中最大的五个目录，按大小从大到小排序。在这个示例中，最大的目录是 `/home`，总大小为 11 GB。

`uname` 命令集成在 Unix 和 Linux 操作系统中，允许获取有关操作系统内核的信息。它通常用于显示基本系统信息，例如操作系统名称、主机名、机器类型和内核版本。它也可以用于显示其他信息，例如处理器架构、操作系统版本、内核版本日期和系统类型。
