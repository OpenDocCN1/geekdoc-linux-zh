# 停止更改浮动的 uptime 字段

在 **`uptime`** CPU 负载监控 shell 脚本中，我们确实需要追溯最新 CPU 统计信息的位置。另一种方法是使用我们所知的事实。具体来说，我们知道感兴趣的字段位于 **`uptime`** 命令输出末尾倒数第三个位置。使用这个小函数 `get_max` 来查找输出中的字段总数。如果从总位置数中减去 2，我们就始终拥有正确的字段。下一个代码段是使用此技术的示例。

```bash
function get_max
{
  (($# == 0)) && return -1
  echo $#
}

########## MAIN #######

MAX=$(get_max $(uptime)) # 获取 uptime 中的字段总数
```

# 监控系统负载 213

```bash
output
(( MAX == -1)) && echo "ERROR: Function Error..EXITING.." && exit 2
TARGET_FIELD=$((MAX - 2)) # 从总数减去 2
CPU_LOAD=$(uptime | sed s/,//g | awk '{print \$TARGET_FIELD}')
echo $CPU_LOAD
```

在前面的代码段中，`get_max` 函数接收 `uptime` 命令的输出。使用此输入函数返回 `uptime` 命令包含的位置参数总数。在 MAIN 部分，我们将 `get_max` 函数接收的结果赋值给 `MAX` 变量。如果返回值为 -1，则发生了脚本错误，脚本将向用户显示错误并以代码 2 退出。否则，从 `MAX` 变量中减去其值，并赋值给 `TARGET_FIELD` 变量。最后步骤将最近的队列统计信息赋值给变量 `CPU_LOAD`。

这种技术消除了跟踪字段位置的需求。
