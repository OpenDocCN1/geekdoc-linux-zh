
大多数实验室仪器由一个高压发生器组成，它为 X 射线管提供稳定的电压，使得 X 射线源强度的变化小于 1%。衍射仪测角仪安装在 X 射线管窗口前的桌子上。电子电路使用 X 射线探测器将衍射的 X 射线光子转换为可测量的电压脉冲，并记录衍射数据。[R.Me]

## X 射线光谱学

一种快速且经济的定量分析样品元素组成的技术。它不同于 X 射线衍射，后者的目的是鉴定结晶化合物。它也不同于可见光区域的光谱学，X 射线光子的能量为数千电子伏特，来自原子中紧密结合的内层电子，而可见光子来自外层电子，能量仅为几个电子伏特。

在 X 射线光谱学中，高能电子、质子或光子照射样品会使一些原子电离，然后这些原子发射特征 X 射线，其波长取决于元素的原子序数，其强度与该元素的浓度相关。一般来说，特征 X 射线线与元素的物理状态（固态或液态）和元素存在的化合物类型（价态）无关，因为 X 射线发射来自原子中屏蔽良好的内层电子。插图显示高能光子移除了最内层 K 壳层中的一个电子。光子能量必须大于电子的结合能；能量差表现为被射出电子的动能。K 电离的原子是不稳定的，L 或 M 壳层中的一个电子落入 K 壳层空位。当发生这种跃迁时，发射一个特征 X 射线光子，其能量等于 K 壳层和 L（或 M）壳层之间的能量差，或者一个称为俄歇电子（Auger electron）的额外电子从原子中射出。X 射线或俄歇电子都可以用于分析。参见：俄歇效应。

X 射线光谱学通常不需要在测量前分离元素，因为 X 射线线容易分辨。然而，预浓缩方法有时作为提高检测限的手段是有用的。X 射线光谱学的一个限制是原子序数低于 11 时的测量难度逐渐增加。参见：光谱学。[L.S.B]

## X 射线望远镜

一种旨在收集并检测来自地球大气层外源的 X 射线的仪器，以便将 X 射线转化为图像。由于大气层对 X 射线的吸收，X 射线望远镜必须被带到高空。气球用于设计用于高能（硬）X 射线观测的检测系统，而火箭和卫星则用于较软 X 射线探测器。参见：X 射线天体物理；X 射线。

成像。X 射线波长的成像望远镜镜头可以基于折射率变化处的表面全外反射现象（掠入射望远镜），或基于建设性干涉原理（多层膜望远镜）。

对于 X 射线，物质中的折射率略小于 1。根据斯涅尔定律的应用，全外反射的条件是辐射以小于约 1° 临界角的小掠射角入射到反射面上。基于这些特性，已经制造了可在两个维度上聚焦图像的 X 射线镜面。

### X射线望远镜结构

曲面可以有多种构型。参见`电磁辐射的反射`；`反射波`。

第二种X射线望远镜基于在沉积于镜面材料极薄层中发生`相长干涉`的原理。与掠入射望远镜不同，多层望远镜并不要求X射线以浅角度撞击才能被反射。相反，这些镜子类似于普通的光学望远镜镜面，入射辐射以正入射角度撞击镜面后被反射和聚焦。参见`波的干涉`。

多层镜面的优点在于其全部镜面面积都可用于收集X射线辐射，而掠入射望远镜只有实际镜面的一小部分投影面积用于收集辐射。存在一个相对的缺点，即多层镜面仅能在非常狭窄的能量范围内反射X射线，而掠入射镜面能在较宽的能量范围内反射。其效果类似于在光学望远镜上使用窄带滤光片，在某些情况下这非常有用。多层正入射X射线望远镜首次在天文学上的应用是拍摄太阳。

#### 图像探测

掠入射望远镜的高角分辨率要求摄像机具有相应的良好空间分辨率。一种探测器使用微通道板，并对软能段（约100–10,000 eV）的X射线产生约20微米的分辨率。微通道板是由许多小空心管或通道（直径约10–15 µm）组成的阵列，经过处理后其内壁具有很高的二次电子产率。

`电荷耦合器件（CCD）`已开发用于X射线成像应用。这种固态探测器由微小的硅像素组成，X射线光子通过时产生的电子电荷在此处被收集。典型的电荷耦合器件的像素边长为15–25 µm，单个此类器件上最多可有4096 × 4096个像素。电荷耦合器件不仅记录事件的位置，还提供光子能量的信息。参见`电荷耦合器件`。

位置敏感比例计数器是一种充有气体的计数器，X射线在其中被光电吸收，产生由其在气体中产生的电离所检测到的电子。通过以比例模式操作计数器并利用线平面来定位电信号，可以记录每个事件的位置和幅度。这些探测器的空间分辨率通常较低（约200 µm），低于微通道板或电荷耦合器件探测器，但它们的尺寸可以做得更大，并且比微通道板探测器具有更好的能量分辨率。参见`电离室`。

另一类探测器由极低温度设备组成，当X射线被阻止时，这些设备检测沉积在吸收器中的热量。这些设备承诺在广泛的能量范围内提供改进的能量分辨率和效率。参见`望远镜`。 [S.S.M]

## X射线管

用于产生X射线的电子设备。X射线在X射线管中产生，通过静电场将电子加速到高速度，然后通过与路径中所谓的`靶`（固体物体）的碰撞突然停止它们。X射线从靶上发生碰撞的斑点向所有方向辐射。X射线是由于快速移动的电子与构成靶原子的电子和带正电的原子核之间相互作用而产生的。根据产生电子的方法，X射线管可以分为两大类：气体管和高真空管。参见`X射线`。

在气体管中，电子通过正离子轰击从阴极释放出来。正离子的存在要求管内有一定的气体压力，在该压力范围内管内不会让电流通过。将铂和钨等金属放置在电子束的路径中作为靶。使用凹形金属阴极将电子聚焦在金属靶的一小块区域上，以增加在荧光屏或胶片上形成的阴影的清晰度。许多设计的气管已为实用应用而构建，特别是在医学领域。

气体X射线管的操作困难和异常行为与气体本身以及在操作过程中发生的正离子轰击固有地相关。高真空X射线管通过使用其他方式从阴极发射电子消除了这些困难。原始类型的高真空X射线管具有热钨灯丝阴极和固态钨靶。该管允许在相对高电压和大质量金属下稳定且可重复地操作。现代商用热阴极高真空X射线管由液体冷却、铜背衬的钨靶制成。 [E.E.C]

## X射线

X射线，或`伦琴射线`，是电磁波，其中周期性变化的电场和磁场相互垂直，并且垂直于传播方向。因此，它们在性质上与可见光以及构成电磁波谱的所有其他类型的辐射相同。通常，X射线是由高能电子轰击高原子重量的材料引起原子电子能级跃迁而产生的。参见`电磁辐射`。

在W. R. 伦琴于1895年发现“一种新型射线”之后，一些科学家找到了证明X射线可以被偏振、被晶体衍射、在棱镜和晶体中折射、被镜面反射以及被刻线光栅衍射的基本实验条件。参见`X射线晶体`。

X射线在电磁波谱中的范围，由阴极电子在高加速电势下轰击阳极靶产生，在长波一侧与约100纳米的紫外范围重叠，并且随着电压增加，最短波长极限向下移动。10⁶伏特的加速电势，现在很容易产生，产生10⁻¹² m（10⁻² nm）的波长。研究中使用的平均波长为0.1 nm，或约为黄光波长的1/6000。参见`X射线管`。

在衍射、折射、偏振和干涉现象中，X射线与所有其他相关辐射一起表现出波的行为。在其他现象中——例如线谱线的出现、连续“白光”谱的明确光电阈值限制、被原子中电子散射的X射线波长偏移（`康普顿效应`）以及`光电效应`——能量似乎以称为`光子`的量子形式传播和传递。参见`康普顿效应`；`电子衍射`；`中子衍射`；`光电效应`；`量子力学`。

X射线在许多科学领域的重要用途已经找到，例如，`伦琴 spectroscopy`和`伦琴衍射`，X射线发射线系列（K，L，M等）的X射线分析以及所谓的特征于化学元素的吸收边，提供用于化学分析的必要信息，正如光学发射光谱的情况，以及用于开发解释光谱起源的原子结构理论。参见`历史放射照相术`；`微放射照相术`；`辐射生物学`；`放射照相术`；`放射学`；`X射线晶体学`；`X射线衍射`；`X射线荧光分析`；`X射线显微镜`；`X射线功率法`。 [G.L.C]

## 异养藻纲

一类植物，包括黄绿色藻类，属于叶绿素a-c系统发育谱系（Chromophyta）。替代名称是`Trichophyceae`，源自该纲的一个丝状成员 *Trichonema*，以及`Heterokontae`，指每个运动细胞上存在两种鞭毛。

## 黄藻门

细胞。缺乏淀粉是区分黄藻与绿藻（它们在形态和颜色上可能表面相似）的一个重要特征。参见：藻类；色藻纲。

游动细胞具有两条不等长的鞭毛，顶端或侧生。其中一条（通常较长）向前指向，具毛状（pleuronematic）结构；另一条向后指向，为光滑无毛状（achronematic）结构。*瓦鱼虫*（*Vaucheria*）的复合游动孢子（syncyzoospore）具有众多对略不等的 smooth 鞭毛，这是例外的。每个游动细胞通常有两个叶绿体，腹面叶体在前方有一个红色反光的眼点。游动细胞的前端有一个或两个收缩泡。大多数黄藻细胞的细胞器是单室（unilocular）的，但在一些属中它们是多室的（multilocular）。线粒体可能具有管状嵴。每个营养细胞含有一至多个黄色绿色、层状或盘状、平行的叶绿体。

大多数黄藻生活于淡水环境，尤其是软水。它们常作为附着生物生长在水生植物上。主要的例外是*瓦鱼虫*（*Vaucheria*），其包含淡水、咸水和海水物种。黄藻也发生或在土壤和泥中、在冰雪中以及在树干和潮湿墙壁上。[P.C.S.; R.L.Mo.]
