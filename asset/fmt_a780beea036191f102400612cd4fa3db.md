
- **密钥认证**：基于密钥的认证更安全、更方便。它使用一对加密密钥：私钥（保留在本地机器上）和公钥（添加到远程服务器的 `authorized_keys` 文件中）。当你连接到服务器时，将使用密钥来验证你的身份，而无需密码。

### 生成 SSH 密钥对

要生成 SSH 密钥对，可以使用 `ssh-keygen` 命令。默认情况下，该命令会创建一个带有以下文件的密钥对：`id_rsa`（私钥）和 `id_rsa.pub`（公钥）。

```
$ ssh-keygen
```

### 将公钥复制到远程服务器

生成 SSH 密钥对后，你需要将公钥复制到远程服务器。你可以通过将公钥追加到远程服务器上的 `~/.ssh/authorized_keys` 文件手动完成，或者使用 `ssh-copy-id` 命令：

```
$ ssh-copy-id username@hostname_or_IP
```

### 使用 SSH 密钥登录

一旦你的公钥位于远程服务器上，你只需运行 `ssh` 命令即可无密码登录：

```
$ ssh username@hostname_or_IP
```

SSH 将使用你的私钥进行身份验证，你将获得远程服务器的访问。

### 禁用密码认证

为了增加安全性，你可以在 SSH 服务器上禁用密码认证并仅允许基于密钥的认证。要做到这一点，编辑 SSH 服务器配置文件（通常位于 `/etc/ssh/sshd_config`）并将 `PasswordAuthentication` 选项设置为 `no`。完成更改后，重启 SSH 服务器：

```
$ sudo systemctl restart sshd
```

### SSH Agent

可以使用 SSH agent 进一步保护 SSH 密钥，agent 是一个在后台运行并管理你的 SSH 密钥的程序。agent 可以持有你解密后的私钥，允许你在每次连接时无需输入密码短语。

要启动 SSH agent 并添加你的私钥：

```
$ eval "$(ssh-agent -s)"
```

```
$ ssh-add /path/to/private_key
```

### 结论

SSH 是安全远程访问 Linux 系统的强有力工具。通过理解 SSH 基础知识、生成 SSH 密钥对并配置安全认证，你可以增强远程连接的安全性，并确保数据在传输过程中保持保护。SSH 健壮的加密和认证机制使其成为 Linux 以及其他 Unix 类操作系统远程访问和安全文件传输的标准选择。

## 4.4. 数据共享：NFS 和 Samba

跨网络共享数据和资源是许多 Linux 环境中的共同需求。在 Linux 和其他系统（包括 Windows）之间共享数据的两种流行解决方案是 NFS（网络文件系统）和 Samba。在本节中，我们将探索 NFS 和 Samba，以及如何使用这些技术设置文件共享。

### NFS (网络文件系统)

NFS 是一种网络协议，允许远程服务器上的文件系统被挂载并访问，就像本地一样。它被广泛应用于 Unix 和 Linux 环境中共享文件和目录。

### NFS 服务器设置

要在 Linux 系统上设置 NFS 服务器，需要遵循以下步骤：

1. 如果尚未安装 NFS 服务器软件包。包名可能根据你的发行版而异：

   - Ubuntu/Debian:

     ```
     $ sudo apt-get install nfs-kernel-server
     ```

   - CentOS/RHEL:

     ```
     $ sudo yum install nfs-utils
     ```

2. 创建你想与远程客户端共享的目录：

   ```
   $ sudo mkdir /shared_data
   ```

3. 编辑 `exports` 文件（`/etc/exports`）并定义共享目录的访问权限：

   ```
   /shared_data *(rw,sync,no_root_squash,subtree_check)
   ```

4. 导出共享目录并重启 NFS 服务器：

   ```
   $ sudo exportfs -ra
   ```

   ```
   $ sudo systemctl restart nfs-server
   ```

### NFS 客户端设置

在客户端系统中，可以使用 `mount` 命令挂载远程共享：

```
$ sudo mount -t nfs server_ip:/shared_data /mnt/mount_point
```

将 `server_ip` 替换为 NFS 服务器的 IP 地址，将 `/mnt/mount_point` 替换为想要挂载的本地目录。

### Samba

Samba 是一组实现 Linux/Unix 服务器与 Windows 系统之间互操作的程序。它允许 Linux 系统与 Windows 客户端共享文件和打印机。

### Samba 服务器设置

要在 Linux 上设置 Samba 服务器，请遵循以下步骤：

1. 如果尚未安装 Samba 软件包：

   - Ubuntu/Debian:

     ```
     $ sudo apt-get install samba
     ```

   - CentOS/RHEL:

     ```
     $ sudo yum install samba
     ```

2. 创建你想与 Windows 客户端共享的目录：

   ```
   $ sudo mkdir /shared_data
   ```

3. 编辑 Samba 配置文件（`/etc/samba/smb.conf`）并定义共享目录的访问权限：

   ```
   [shared_folder]
   path = /shared_data
   writable = yes
   guest ok = yes
   ```

4. 创建 Samba 用户并设置密码：

   ```
   $ sudo smbpasswd -a username
   ```

5. 重启 Samba 服务：

   ```
   $ sudo systemctl restart smbd
   ```

### Samba 客户端设置 (Windows)

在 Windows 系统上，你可以访问共享 Samba 文件夹：

1. 打开文件管理器。

2. 在地址栏输入 `\\server_ip`（将 `server_ip` 替换为 Linux Samba 服务器的 IP 地址）。

3. 系统将提示输入你在 Samba 服务器上创建的用户名和密码。

## 4.5 高级网络工具与技术

在 Linux 网络世界中，有许多系统管理员和网络专业人士可以利用高级工具和技术来管理和优化网络基础设施。本节将探索其中一些工具和技术。

### 1. Wireshark

Wireshark 是一款强大的网络协议分析器，允许你捕获并检查在网络上往返的数据。它可以用于排查网络故障、分析网络流量以及理解网络应用程序的行为。

在 Linux 上安装 Wireshark：

```
# For Ubuntu/Debian

$ sudo apt-get install wireshark
```

```
# For CentOS/RHEL

$ sudo yum install wireshark
```

```
# netstat example

$ netstat -tln
```

在 Linux 上安装 Nmap：

```
# For Ubuntu/Debian

$ sudo apt-get install nmap
```

```
# For CentOS/RHEL

$ sudo yum install nmap
```

在 Linux 上安装 TCPdump：

```
# For Ubuntu/Debian

$ sudo apt-get install tcpdump
```

```
# For CentOS/RHEL
```
