### mailman

强大的基于 Web 的邮件列表管理器。GNU 邮件列表管理器管理类似于 `Majordomo` 和 `Smartmail` 的讨论列表。与大多数类似的模型不同，`Mailman` 为每个邮件列表提供一个页面，并允许用户通过网络进行订阅、取消订阅等。即使列表管理员也可以从网页管理其列表。`Mailman` 还整合了许多人们希望在邮件列表中实现的功能，包括归档、<-> 网关等。它具备你对这类产品预期的所有功能，以及对 Web 的集成支持（包括基于 Web 的归档）、自动退信邮件和集成反垃圾邮件保护。更多信息请参阅 http://www.list.org/。源自 Debian 3.0r0 APT

简单但强大的 WWW 邮件阅读器。`Mailreader` 是一个用 Perl 编写的轻量且简单的基于 Web 的邮件代理。它的配置非常简单，且运行良好。`Mailreader` 目前支持 POP3 服务器。现在它支持日语（需要 `libcodype–pop-mail`——否则请忽略此建议）。尽管 `mailreader` 的依赖项不包含 POP3 服务器，但它的运行需要在网络上有一个适当的 POP3 服务器。出于安全考虑（`强烈建议！`），你需要 ssl 的帮助（你可以尝试 `apache–ssl`）。源自 Debian 3.0r0 APT

### mailscanner

一个邮件扫描器和反垃圾邮件标记器。`Mailscanner` 是一个免费分发的 A-邮件网关病毒扫描器守护进程。它以 `Sendmail` 或 `Exim` 为基础，并在 7 个商业扫描引擎到实际的病毒扫描器中。它可以解码并扫描仅供 Microsoft Outlook 用户使用的附件（MS-TNE）。如果可能，它将剖析受感染的文档并自动删除。它还具有防止拒绝服务攻击的功能。默认禁用病毒检查，默认启用反垃圾邮件检查。安装后，你可以启用病毒检查、编写自己的病毒扫描器或安装其中一个支持的商业反病毒包。源自 Debian 3.0r0 APT
