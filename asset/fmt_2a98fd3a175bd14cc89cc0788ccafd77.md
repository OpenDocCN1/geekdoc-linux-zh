
在函数执行期间，`EBP`寄存器不受运行的影响它是函数访问局部变量和函数参数的基准值。我们也可使用`EBP`寄存器存储局部变量和运行参数，但是`EBP`寄存器的值总是会变化，使用起来并不方便。

函数在退出时，要做退出过程的反操作，释放栈中申请的内存，还原`EBP`寄存器的值，将代码控制权还原给调用者函数（callee）。

```
mov     esp, ebp
pop     ebp
ret     0
```

# 第5章 栈

栈是计算机科学里最重要且基础的数据结构之一。[1]

从技术上说，栈就是CPU寄存器里的某个指针所指向的一片内存区域。这里所说的“某个指针”通常指x86平台的`ESP`/x64平台的`ESP`寄存器/`RSP`寄存器，以及ARM平台的`SP`寄存器。

操作的最常见的指令是`PUSH`和`POP`，在x86和ARM Thumb模式的指令里都有两条指令。`PUSH`指令会对`ESP/RSP/SP`寄存器的值进行减法运算，使得减4（32位）或8（64位），然后将操作数上述寄存器的指针指向的内存中。

`POP`指令是`PUSH`指令的逆操作，从栈指针（Stack Pointer，三个寄存器之一）的内存中读取，用操作（通常是写到其他寄存器），然后将指针的值增加4或8。

在分配的空间中，找指针，即Stack Pointer指向的地址就是栈的底部。`PUSH`会减少指针的值，而`POP`会增加指针的值。栈的“底”并不是整个栈的最低地址，而是整个栈的初始地址。虽然听起来很奇怪，但是确实如此。

虽然x86/x64的栈已经很好理解了，但是ARM的栈更为复杂的。ARM的栈分为增栈和减栈。减栈（descending stack）的起始地址就是栈的最高处，向低地址增长，指针的值随栈的增长而减少，如`STMFD/LMFD`、`STMED/LDMED`等指令都是减栈的操作。ARM的增栈（ascending stack）的起始地址则是栈的最低地址，向高地址增长，指针的值随增长而增加，如`STMFA/LMFA`、`STMEA/LDMEA`等指令都是增栈的操作指令。[2]
