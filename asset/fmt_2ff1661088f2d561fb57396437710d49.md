# 使用 test

到目前为止，与`if`配合最常用的命令是`test`。`test`命令执行各种检查和比较。它有两种等价的形式。第一种形式所示：

`test expression`

第二种更流行的形式，如下所示：

`[ expression ]`

其中`expression`是一个被评估为真或假的表达式。当表达式为真时，`test`命令返回退出状态 0，当表达式为假时，返回状态 1。

值得注意的是，`test`和`[`实际上都是命令。在`bash`中，它们也作为程序存在于`/usr/bin`中，以供其他 shell 使用。表达式实际上就是它的参数，而`{`命令要求将`}`字符作为其最后一个参数。

`test`和`[`命令支持广泛的实用表达式。

这是一个演示这些表达式的脚本：

```bash
#!/bin/bash

# test-file: 评估文件的状态

FILE=bashrc

if [ -e "$FILE" ]; then
    if [ -f "$FILE" ]; then
        echo "$FILE is a regular file."
    fi

    if [ -d "$FILE" ]; then
        echo "$FILE is a directory."
    fi

    if [ -r "$FILE" ]; then
        echo "$FILE is readable."
    fi

    if [ -w "$FILE" ]; then
        echo "$FILE is writable."
    fi

    if [ -x "$FILE" ]; then
        echo "$FILE is executable."
    fi
else
    echo "$FILE does not exist"
    exit 1
fi
```

上面的脚本评估了`FILE`。关于这个脚本有两个值得注意的地方。首先，虽然`bash`文档说明排序顺序符合当前区域设置（`locale`），但实际上并非如此。ASCII (POSIX) 顺序用于 4.0 之前的版本。这个问题在 4.1 版本中得到了解决。同样，shell 函数可以通过`return`来返回退出状态。我们将之前的脚本转换为函数：

        fi

        fi

### 表 27-3：测试整数表达式

| 表达式 | 为真的条件： |

#!/bin/bash

    exit 1

    echo "INT is zero."
else
