
# 网络与系统术语表

## 网络设备与协议

**network switch (网络交换机)**：连接网络中的设备。为了增加带宽，交换机正日益取代共享媒体集线器。例如，16 端口的 BaseT 集线器与 16 个连接节点共享总 10 Mbps 的带宽。通过用交换机取代集线器，发送方和接收方都可以利用全部 10 Mbps 的容量。交换机上的每个端口都可以为单个服务器、客户端站或带有多个站点的集线器提供全带宽。网络交换机指的是具有智能的设备。与**集线器**对比。

**Network Time Protocol (网络时间协议)** 见 **NTP**。

**NFS (Network Filesystem，网络文件系统)**：由太阳微系统设计的远程文件系统，可在 Unix 供应商的计算机上使用。

**NIC (Network interface card，网卡或控制器)**：安装在计算机中的适配器板，用于提供到网络的物理连接。

**NIS (Network Information Service，网络信息服务)**：基于共享数据库的分布式服务，用于管理与系统无关的信息（如用户名和密码）。

**NIS domain (NIS 域)**：一个描述一组拥有特定 NIS 文件的系统的名称。与**域名**不同。

**NNTP (Network News Transfer Protocol，网络新闻传输协议)**：参考“Usenet”。

**node (节点)**：在树形结构中，支持其他分支的分支末端。当 Linux 文件系统层次结构被构想为树时，目录就是节点。见**叶**。

## 词汇表 1051

**nonprinting character (非打印字符)** 见**字符**。见 **nonprintable（不可打印）**。

**nonvolatile storage (非易失性存储)**：一种掉电后内容仍能保留的存储设备。也称为 NVS 和持久化存储。示例包括 CD-ROM、打孔带、硬盘、**ROM**、**PROM**、**EPROM** 和 **EEPROM**。与 **RAM** 对比。

**NTP (Network Time Protocol)**：构建在 **TCP/IP** 之上；通过参考时钟保持时钟准确。

**null (空值)**：一个不包含任何字符的字符串。见**零**。

**octal number (八进制数)**：由 0–7 组成的八进制数。

**one-way function (单向函数)**：一种接受变长输入并产生固定长度哈希的函数；从哈希反推消息在计算上是不可行的。也见**哈希**。

**operating system (操作系统)**：计算机分配资源、调度任务并为用户提供访问的控制程序。

**option (选项)**：一种修改命令效果的命令行参数。选项通常以连字符（-）开头。

**output (输出)**：发送到终端的信息。见**标准输出**。

**P2P (Peer-to-Peer，点对网络)**：将节点分为客户端和服务器的网络。

**packet (数据包)**：跨网络发送的数据单元。*Packet* 是 OSI 栈中任何层的通用术语。见**帧**和**数据报**。

**packet filtering (数据包过滤)**：一种根据特定标准（如数据包的源、目的或类型）阻塞网络流量的技术。另见**防火墙**。

**packet sniffer (包嗅探器)**：监控网络数据包的程序或设备。见**嗅探**。

**pager (分页器)**：允许你一次查看一个文件的工具（例如 `less` 和 `more`）。

**paging (分页)**：由操作系统维护虚拟内存的过程。为了给其他进程腾出空间，进程内存会被交换到**交换空间**。

**PAM (Linux-PAM 或 Linux-Pluggable Authentication Modules，Linux 可插件认证模块)**：这些模块允许系统管理员确定应用程序如何验证用户。参考“PAM”。

**parent process (父进程)**：派生（fork）其他进程的进程。见**进程**和**子进程**。

**partition (分区)**：磁盘的一个部分，具有可以单独指定的名称。磁盘分区可以包含文件系统或其他结构，如交换区。

**passive FTP (被动 FTP)**：通过允许数据流由客户端 FTP 程序而非服务器启动和控制，使 FTP 能够穿越墙。也称为 **PASV FTP**，因为它使用了 `PASV` 命令。

**passphrase (口令)**：你输入以验证身份的单词和字符字符串。口令与密码的区别在于长度。密码通常很短——6 到 10 个字符。口令通常长得多——可达 100 个字符或更多。更大的长度使得口令难以猜测或复制。

**password (密码)**：为了防止未经授权访问用户账户，由用户或系统管理员选择的任意字符串，并在尝试登录时验证用户。另见 **passphrase**。

**PASV FTP** 见 **passive FTP**。

**pathname (路径)**：由斜杠（/）分隔的目录列表，并以文件名（可以是目录）结尾。路径用于跟踪文件结构的路径以定位或识别文件。

**pathname, last element of (路径的最后一个元素)**：路径中 / 之后的部分，或者如果没有 / 则为整个文件名。一个简单的文件名。也见**基名**。

**pathname element (路径元素)**：构成路径的路径之一。

**peripheral device (外围设备)** 见**设备**。

## 词汇表 1053

### persistent（持久）
存储在非易失性介质上的数据，例如硬盘。

### phish（钓鱼）
一种欺骗用户披露或共享私人信息的尝试，特别是密码或财务信息。最常见的形式是伪装成银行或供应商的电子邮件，要求用户填写表格以在手机网站上“更新”账户，使其看似合法。通常作为**垃圾邮件**发送。

### physical device（物理设备）
一种有形的设备，例如磁盘驱动器，在物理上与其他类似的设备隔离开。

### PID
进程标识符，通常后面跟着单词 *number*（编号）。Linux 在每个进程启动时都会为其分配一个唯一的 PID 号。

### pipe（管道）
程序之间的连接，将一个程序的标准输出连接到下一个程序的标准输入。也称为 *pipeline*（流水线）。

### pixel（像素）
图像中最小元素，通常是显示屏幕上的单个点。

### plaintext（明文）
未加密的文本。也称为 *cleartext*（明文）。与 *ciphertext*（密文）相对。另参见“加密”。

### Pluggable Authentication Modules（可插身份模块）
参见 **PAM**。

### point-to-point link（点点链路）
仅限于两个端点的连接，例如一对调制器之间的连接。

### port（端口）
通信系统中的逻辑通道或通道端点。用于以太网的 **TCP** 和 **UDP** 传输层协议使用端口号来区分同一台计算机上同一网络接口的不同逻辑通道。

`/etc/services` 文件（更多信息请参见此文件的开头）或 **NIS** 服务数据库为每个应用程序指定了唯一的端口号。该端口号将入站数据链接到正确的服务（程序）。标准端口、众皆知的端口供所有人使用。端口 80 用于 HTTP（Web）流量。某些协议（如 TELNET 和 HTTP，其后者是 TELNET 的特殊形式）具有上述所示的默认端口，但也可以使用其他端口。

### port forwarding（端口转发）
将一台计算机上的网络端口连接到另一台计算机上的端口的过程。如果端口 X 从系统 A 转发到系统 B，则发送到端口 X 的任何数据将自动发送到系统 B。连接可以是两个系统的不同端口。另参见 *tunneling*（隧道技术）。

### portmapper（端口映射）
将 TCP/IP 端口号转换为 **RPC** 程序号服务器。参见“RPC 网络服务”。

## 1054 词汇表

### printable character（打印字符）
图形字符之一：字母、数字或标点符号。与不可打印字符或 CONTROL 字符相对。也称为打印字符。

### private address space（私有地址空间）
IANA 为私有网络或局域网（LAN）预留了三个 IP 地址块：

| 范围 |
| :--- |
| 10.0.0.0 - 10.255.255.255 |
| 172.16.0.0 - 172.31.255.255 |
| 192.168.0.0 - 192.168.255.255 |

你可以使用这些地址而无需与局域网之外的任何人协调（你不需要注册系统名称或地址）。使用这些 IP 地址的系统无法与使用全局地址空间的主机通信，必须通过网关。由于私有地址没有全局含义，DNS 不存储路由信息，且大多数 ISP 拒绝带有私有地址的数据包。确保你的路由器已设置好将这些数据包转发到互联网。

### privileged port（特权端口）
数字小于 1024 的**端口**。在 Linux 和其他类 Unix 系统中，以 root 权限运行的进程才能绑定到特权端口。Windows 98 及更早的 Windows 系统中的任何用户都可以绑定到任何保留端口。

### procedure（过程）
执行特定任务的指令序列。大多数编程语言（包括机器语言）都允许程序员定义过程，允许代码从多个地方被调用。也称为 **subroutine**（子程序）。

### process（进程）
Linux 对命令的执行。参见“进程”。

### .profile 文件
用户主目录下的启动文件，当你登录时 Bourne Shell 或 Z Shell 会执行该文件。TC Shell 则执行 Login 文件。你可以使用 `.profile` 文件运行命令、设置变量并定义函数。

### program（程序）
包含在文件中的一系列可执行指令。Linux 工具程序、应用程序和 shell 脚本都是程序。每当你运行一个不是 shell 内置的命令时，你都是在执行一个程序。

### PROM
可编程只读存储器。一种非易失性存储器。可以使用 PROM 编程器写入的 **ROM**。

### prompt（提示符）
程序提供的提示信号，通常显示在屏幕上，表示它正在等待输入。shell 会显示提示符，某些交互式工具（如 mail）也是如此。默认情况下，Bourne Again 和 Z Shell 使用美元符号 ($) 作为提示符，TC Shell 使用百分号 (%)。

### protocol（协议）
一组描述如何传输数据（特别是跨网络传输数据）的正式规则。低层协议定义了电气和物理标准，以及位顺序、位流的传输、错误检测和纠正。高层协议处理数据格式，包括消息语法、终端到计算机的对话、字符集和消息排序。

## 1055 词汇表

### proxy（代理）
获得授权代操作的服务。另参见**代理网关**和**代理服务器**。

### proxy gateway（代理网关）
将客户端（如浏览器）与互联网隔离开的计算机，作为代理将数据请求（如 HTTP）传递给远程服务器。服务器返回通过代理网关返回。代理网关对用户透明。代理网关通常运行在**防火墙**系统中，作为恶意用户的屏障。你可以配置浏览器（如 Mozilla/Firefox 和 Netscape）为每个访问方法（包括 FTP、网络 和 HTTP）使用不同的代理网关或不使用代理。

### proxy server（代理服务器）
通常包含**缓存**的网关，缓存常用页面以便下次本地访问。代理服务器和代理网关术语经常混用。

### Python
一种简单、高级、解释型、面向对象的交互式语言，弥补了 C 和 shell 编程之间的差距。适用于快速原型或作为 C 应用程序的扩展语言，Python 支持包、模块、类、用户自定义异常、良好的 C 接口以及模块的动态加载。它没有任意限制。更多信息请参见 www.python.org。

### quote（引用）
当你对一个字符进行引用时，会取消其在当前上下文中的特殊含义。你可以通过在字符前加反斜杠来对其引用。当你与 shell 交互时，还可以用单引号引用字符。例如，命令 `echo \*` 或 `echo '*'` 会输出 *。`echo` 命令显示工作目录下的文件列表。参见**模糊文件引用**、**元字符**、**正则表达式**、**特殊字符**。另见 **escape**。

### radio button
在 GUI 中，一组按钮按钮之一，类似于收音机选择电台的按钮。组内的单选按钮是互斥的；一次只能选择一个。

### RAID
冗余独立磁盘阵列。将两个或多个硬盘组合在一起，以提供容错能力和性能。RAID 可以通过硬件或软件实现。

### RAM
随机存取存储器。一种易失性存储器。对不同位置的访问顺序不影响访问速度的数据存储设备。与硬盘或磁带驱动器相比，后者在顺序访问上更快，因为访问非顺序位置需要存储介质和/或读写头的物理移动，而不仅仅是电子切换。与**非易失性存储**相比。也指内存。

### RAM 磁盘 (RAM disk)
模拟软磁盘或硬盘的 RAM。RAM 磁盘经常用作**启动**过程的一部分。

### RAS
远程访问。在网络中，通过模拟调制解调器或 ISDN 连接为远程用户提供访问的计算机。RAS 包含拨号协议和访问控制（身份验证）。它可以是一个带有远程访问软件的普通**过滤器**，也可以是一个专有系统，例如 Shiva 的 LANRouter。调制调器位于设备内部或外部。

### RDF
资源描述框架。由 W3C（万网主要标准机构）开发，是一种规定了编码和传输**元数据**机制的标准。RDF 没有规定元数据应该是什么或具有什么。它可以作为交换语法集成许多种应用程序和数据。可以集成到库目录和全球目录中的数据示例：新闻、软件和内容的发布与聚合；音乐和照片的集合。访问 URL 获取更多信息。

### 重定向 (redirection)
将程序的标准输入重指向文件而非键盘的过程。也指将标准输出或错误重指向文件而非屏幕的过程。

### 可重入 (reentrant)
指可以有多次同时、交替或嵌套调用，且这些调用互不干扰的代码。非干扰性对于并行处理、递归编程和中断处理至关重要。

通常很容易安排多次调用（即对子程序的调用）来共享一份代码副本和任何随手可用的数据。然而，为了使代码具有重入性，调用必须使用其自有的任何可修改数据（或共享数据）的副本。这一目标通常通过使用栈并在每次调用时在新栈中分配局部变量来实现。或者，调用者可以传递一个指向内存块的指针，调用可以使用该内存（通常用于输出），或者代码可以在堆上分配一些内存，特别是当数据必须在例程返回后仍然存在时。

可重入代码常见于系统软件，如操作系统和远程处理监控器。它也是多线程程序的关键组件，在多线程中，通常使用“线程安全” 一词代替“可重入”。

### 普通字符 (regular character)
在歧义的文件引用或其他类型的正则表达式中表示其自身的字符。与**特殊字符**相比。

### 表达式 (expression)
一个由字母、数字和特殊符号组成的字符串，用于定义一个或多个字符串。参见附录 A。

## 术语表 1057

### 相对路径 (relative pathname)
从工作目录开始的路径路径。与**绝对路径**相比。

### 远程访问服务器 (remote access server)
见 **RAS**。

### 远程文件系统 (remote filesystem)
远程计算机上的文件系统，其设置使得你可以（通常通过网络）访问它的文件，就像它们存储在你本地计算机的磁盘上一样。远程文件系统的示例是 **NFS**。

### 远程过程调用 (remote procedure call)
见 **RPC**。

### 解析器 (resolver)
TCP/IP 库软件，用于格式化发送到 **DNS** 的请求，以便进行主机到 Internet 地址的转换。

### 资源描述框架 (Resource Description Framework)
见 **RDF**。

### 恢复返回码 (restore return code)
将图标转换为窗口的过程。与**图标化**相比。

见**退出状态**。

### RFC
意见征集。始于 1969 年，是一系列带有编号的 Internet 信息文档和标准之一，被商业软件、互联网自由社区以及 UNIX/Linux 社区广泛遵循。少数 RFC 是标准，但所有 Internet 标准都记录在 RFC 中。也许最有影响力的 RFC 是 RFC 822，即 Internet 电子邮件格式标准。

RFC 通常处于这种状态：由技术专家根据自己的意愿发起浮动，并由整个互联网进行审查，而不是由 ANSI 等机构正式颁布的。由于这个原因，即使在被采纳为标准后，它们仍被称为 RFC。这种由个人或小小组进行的务实、经验驱动的、事后编写的标准的 RFC 传统，相比于 ANSI 或 ISO 那种更正式、委员会驱动的流程具有重要优势。如需 RFC 的完整列表，请访问 URL。

### 漫游 (roam)
在无线网络上于无线接入点之间移动，而用户或应用程序感知不到这种转换。在接入点之间移动通常会导致一些数据丢失，尽管对于使用 **TCP** 的程序来说是透明的。

### ROM
只读存储器。一种非易失性存储。一种带有固定内容制造的数据存储器。通常情况下，ROM 描述任何内容无法被更改的系统，例如唱片唱片或印刷书籍。在引用电子和计算机时，ROM 指的是半导体集成电路内存（存在多种类型）以及 CD-ROM。
