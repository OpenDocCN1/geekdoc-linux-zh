
红帽 6.1 现在内置了对 `xfs` 的支持，并开箱即提供了吸引人的字体支持。因此，如果你正在使用这个版本的 Linux，你可以对现状感到满意。不过，你仍然可以采取一些措施来进一步改进，如果你有 TrueType 字体，也可以使用它们。

要启用 TrueType 字体支持，创建一个目录（例如 `"/usr/local/share/ttfonts"`），并从你的 Windows 系统（可以在 `"c:\windows\fonts"` 目录中找到）复制任何或所有字体文件到新目录。

> 提示：如果你没有可用的 TrueType 字体，可以直接从微软官网下载：http://www.microsoft.com/typography/fontpack/default.htm。

要使用这些字体，在新的 `ttfonts` 目录中，输入以下命令（作为 root）：

```
ttmkfdir -o fonts.scale
mkfontdir
```

接下来，编辑 `"/etc/X11/fs/config"` 文件，将你的新字体目录添加到现有目录列表中。此外，将默认点大小（`point-size`）从 120 改为 140，这将为你提供更大、更易读的字体。

最后，退出 X（如果你还没有退出），并按照如下方式重启你的 `xfs` 服务：

`/etc/rc/init.d/xfs restart`

最后，重启 X 并享受你光丽的新字体！

关于改进 X 下字体支持的更多详细信息，有一个非常优秀的资源名为 "XFree86 Font Deugification Mini HOW-TO"，地址为：http://www.frii.com/~meldroc/Font-Deugification.html。

## 5.6. KDE 安装与配置

K 桌面环境 (`KDE`) 是另一种流行的窗口管理器，在写作时比 `GNOME` 更加成熟。然而，它似乎比 `GNOME` 需要更多的内存资源，因此请考虑你的内存量（如果你小于 64 Mb 且没有交换内存，你可能更好使用 `GNOME`）。

安装 `KDE` 的第一步是下载该包的最新 RPM 发行版。为了完成此，请在 http://www.kde.org/mirrors.html 找到一个镜像站点。选择一个距离你地理位置较的镜像，确保你选择的更新频繁（这可以通过查看镜像列表判断）。

当你找到合适的镜像后，下载适用于你的红帽版本和平台的 RPM 文件。例如，如果你在 Intel 平台上使用红帽 5.2（或更高版本），你可能想从 `/pub/mirrors/kde/stable/latest/distribution/rpm/RedHat-5.2/i386/` 目录下载包。

在你所有必要的文件后，可以使用以下简单命令安装 `KDE` 包，以 `"root"` 输入（确保你在 `KDE` rpm 文件所在的目录）：

```
rpm -Uvh *.rpm
install-kde-1.1-base
```

上述命令将先安装 Qt 库，然后安装 `KDE` 基础包。一旦完成，你应该注销并重新登录（如果你是 `su as root`，只需退出并再次 `su`），以便正确设置你的路径环境变量，然后输入：

```
install-kde-1.1-apps
```

上述命令将安装应用程序。

此安装过程在随你下载的 `KDE` 文件一起包含的 `"readme-redhat-rpms.txt"` 文件中有更详细的讨论。

如果一切顺利，`KDE` 在没有出现任何错误消息的情况下安装完成，如果你愿意，可以将 `KDE` 配置为你的任何用户的默认窗口管理器（即他们在输入 `"startx"` 后立即看到的），再次作为 root 输入以下：

```
/opt/kde/bin/usekde userid
```

（请确保将 `userid` 替换为实际的用户 ID！）

关于 `KDE` 桌面环境的更多信息，可以在 `KDE` 网页 http://www.kde.org/ 上找到。不要忘记查看截图，位于 http://www.kde.org/kde2shots.html。
