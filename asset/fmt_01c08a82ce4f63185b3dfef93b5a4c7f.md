
## ed 命令

命令可能需要零、一个或两个地址。不需要地址的命令会将地址的存在视为错误。接受一个或两个地址的命令在指定的地址数量不足时会使用默认地址；如果 `ed` 使用最后一个地址。

- 通常，你用逗号 `,` 或分号 `;` 将地址彼此隔开。如果你使用分号分隔符，则会计算第一个地址，将当前行 `.` 设置为该值，然后相对计算第二个地址。你可以使用此功能来确定向前和向后搜索的起始行。任何两个地址序列的第二个地址必须对应缓冲区中位于第一个地址对应行之后的行。

在下面的 `ed` 命令列表中，命令前显示的括号不是地址的一部分；相反，它们显示了命令的默认地址。

你可以在每个地址组件前加上零或多个空白字符。你可以在命令字母前加上零或多个空白字符。如果你使用后缀字母 `l`、`n` 或 `p`，它必须紧跟命令之后。

### 284 ed

`e`、`E`、`f`、`v` 和 `w` 命令接受一个可选的文件参数，该参数与命令字母之间用一个或多个空白字符隔开。

自上次写入整个缓冲区的 `w` 命令以来缓冲区发生了更改，当你使用 `e` 或 `q` 命令时 `ed` 会警告你，因为这将会破坏缓冲区。`ed` 命令向标准输出写入字符串：`?n`（如果你使用 `H` 命令启用帮助模式，则后跟解释性消息），并在命令模式下继续，当前行号不变。如果你在没有其他中间命令的情况下重复 `e` 或 `q` 命令，缓冲区将被清空，`ed` 将退出。

如果在期望命令时在标准输入中检测到文件结束 `EOF`，`ed` 命令的行为就像输入了命令一样。

一行中出现多一个命令通常是非合法的。但你可以为任何命令（`e`、`f`、`r` 或 `w` 除外）加上后缀 `l`、`n` 或 `p`，在这种情况下，当前行将被列出、编号或写入。

`ed` 命令列在下方。

- `(a) text` 在缓冲区中选定行之后追加零或多行文本。将当前行 `.` 留在最后插入的行，或者如果没有插入行，则留在选定行。地址 `0` 对此命令是合法的，将追加的文本放在缓冲区开头。每行的最大字符数为 `256`，包括换行符。
- `(c) text` 用零或多行文本更改缓冲区中的选定行。将当前行 `.` 留在最后输入的行，或者如果没有输入，则留在未被删除的第一行；如果被删除的行原本位于缓冲区末尾，则将当前行号设置为新最后一行的地址；如果缓冲区中不再剩余行，则将当前行号设置为 `0`。
- `c` 假设为 `e` 和 `r` 命令读取的所有文本都是加密的，除非输入了空键。
- `(d)` 删除缓冲区中的选定行。最后被删除的行成为当前行；如果被删除的行原本位于缓冲区末尾，则新的最后一行成为当前行。如果缓冲区中不再剩余行，则将当前行号设置为 `0`。
- `e file` 删除缓冲区的所有内容并将文件内容读入缓冲区。将当前行 `.` 设置为缓冲区的最后一行。如果你没有指定文件，则使用当前记忆的文件名（如果有，参见 `f` 命令）。除非你指定 `-s` 选项，否则按以下格式将读取的字节数写入标准输出：

```
\n 读取的字节数
```

记忆文件供后续 `e`、`E`、`r` 和 `w` 命令作为默认文件名使用。如果你将文件替换为 `!`，则将行的剩余视为 shell 命令（参见 `sh(1)`），其输出将被读取。此类 shell 命令不会被记录为当前文件名。完成后丢弃所有标记

### 2, red

- `P` 使用星号 `*`（或字符串，如果你指定了 `-p` 选项）作为后续所有命令的提示符 `prompt`。再次再次输入 `P` 命令可退出此模式。默认情况下，提示模式是关闭的，除非你指定了 `-p` 选项。当前行保持不变。
- `q` 退出编辑。如果缓冲区自上次写出整个缓冲区以来发生了变化，则显示警告消息。
- `Q` 退出编辑，不检查缓冲区自上次 `w` 以来是否发生了更改。
- `($)r file` 将文件内容读入缓冲区。如果未指定文件，则使用当前记住的文件名（如果有，通过 `e` 和 `w` 命令）。除非它是自 `ed` 被调用以来提到的第一个文件名，否则保持当前记住的文件名不变。`0` 对于 `r` 来说是合法的，它会在缓冲区开头读取文件。如果读取成功且你没有指定 `-s` 选项，则按以下格式向标准输出写入读取的字符数：

```
dn,<number of bytes>
```

- `.` 将当前行 `.` 设为最后一行。如果将 `file` 替换为 `!`，则将该行的剩余部分视为 shell 命令（见 `sh(1)`），其输出将被读取。例如，`$ ls` 将当前目录追加到正在编辑文件的末尾。此类 shell 不会被记录为当前文件名。

将选定的行写入标准输出，采用一种视觉上无歧的格式。将字符 `\a`、`\b`、`\f`、`\l`、`\r`、`\t`、`\v` 写入相应的转义序列；将不在表格中的不可打印字符写入为字符中每个字节的三位八进制（带前置的反斜杠），高有效字节在前。
