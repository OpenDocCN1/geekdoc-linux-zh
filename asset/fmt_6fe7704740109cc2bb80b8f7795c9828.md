
`font_struct`

指定 `XFontStruct` 结构体。

`string`

指定字符字符串。

`nchars`

指定字符串中的字符数量。

`direction_return`

返回方向提示（从左到右或从右到左）。

`font_ascent_return`

返回字体升型部（ascent）。

`font_descent_return`

返回字体下降部（descent）。

`overall_return`

返回指定的 `XCharStruct` 结构体中的总体尺寸。

`QTextExtents` 和 `QTextExtents16` 在本地进行尺寸计算，从而避免了 `XQueryTextExtents` 和 `XQueryTextExtents16` 的往返开销。这两个函数都返回一个 `XCharStruct`，其成员的设置值如下：

`ascent` 成员设置为字符串中所有字符升型部指标的最大值。`descent` 成员设置为所有下降部指标的最小值。`width` 成员设置为字符串中所有字符的宽度指标的总和。对于字符串中的每个字符，令 $W$ 为字符串中该字符之前的所有字符的宽度指标之和。令 $L$ 为字符的左侧边缘（left-side-bearing）指标加上 $R$ 字符的右侧边缘（right-side-bearing）指标加上 $W$。`bearing` 成员设置为字符串中所有字符的 $L$。`bearing` 成员设置为最大 $R$。

对于线性索引大于 2 字节矩阵索引的字体，每个 `XChar2b` 结构体被解释为 16 位值，其中字节作为最高有效字节。如果字体没有定义默认字符，则字符串中未定义的字符的指标必须为零。

## 查询字符字符串大小

要向服务器查询给定字体中 8 字节字符字符串的边界框，请使用 `XQueryTextExtents`。

```
XQueryTextExtents(display, font_ID, string, nchars, direction_return, font_ascent_return, font_descent_return, overall_return);
```

`display`: 指定与 X 服务器的连接。

`font_ID`: 指定字体 ID 或包含该字体的 GContext ID。

### 图形函数

`string`: 指定字符字符串。

`nchars`: 指定字符串中的字符数量。

`direction_return`: 返回方向提示（从左到右或从右到左）。

`font_ascent_return`: 返回字体升型部。

`font_descent_return`: 返回字体下降部。

`overall_return`: 返回指定的 `XStruct` 结构体中的总体尺寸。

要向服务器查询给定字体中 2 字节字符字符串的边界框，请使用 `XQueryTextExtents16`。

```
XQueryTextExtents16(display, font_ID, string, nchars, direction_return, font_ascent_return, font_descent_return, overall_return);
```

`display`: 指定与 X 服务器的连接。

`font_ID`: 指定字体 ID 或包含该字体的 GContext ID。

`string`: 指定字符字符串。

`nchars`: 指定字符串中的字符数量。

`direction_return`: 返回方向提示（从左到右或从右到左）。

`font_ascent_return`: 返回字体升型部。

`font_descent_return`: 返回字体下降部。

`overall_return`: 返回指定的 `XStruct` 结构体中的总体尺寸。

`XQueryTextExtents` 和 `XQueryTextExtents16` 函数返回指定字体或 GC 中字体的指定 8 字节和 16 字节字符字符串的边界框。这些函数查询 X 服务器，因此避免了 `XTextExtents` 和 `XTextExtents16` 提供的往返开销。两个函数都返回一个 `XStruct` 结构体，其成员设置值如下：

`ascent` 成员设置为字符串中所有字符升型部指标的最大值。`descent` 成员设置为所有下降部指标的最大值。`width` 成员设置为字符串中所有字符的宽度指标的总和。对于字符串中的每个字符，令 $W$ 为字符串中该字符之前的所有字符的宽度指标之和。令 $L$ 为字符的左侧边缘指标加上 $R$ 字符的右侧边缘指标加上 $W$。`bearing` 成员设置为字符串中所有字符的 $L$。`bearing` 成员设置为最大 $R$。

对于线性索引大于 2 字节矩阵索引的字体，每个 `XChar2b` 结构体被解释为 16 位值，其中字节作为最高有效字节。如果字体没有定义默认字符，则字符串中未定义的字符的指标必须为零。

每个字符图像（由 GC（图形上下文）中的字体定义）被视为对可绘制对象（drawable）填充操作的额外掩码。只有当字体字符的位设置为 1 时，可绘制对象才会被修改。对于使用 2 字节索引定义并配合 `XDrawString16` 使用的字体，每个字节都被用作 `byte2`，`byte1` 为零。

这两个函数都使用了这些 GC 组件：`function`、`plane-mask`、`fill-style`、`font`、`subwindow-mode`、`clip-x`、`clip-origin` 和 `clip-mask`。它们还使用了这些取决于 GC 模式的组件：`foreground`、`background`、`tile`、`stipple`、`stipple-x-origin` 和 `stipple-y-origin`。

`XDrawString` 和 `XDrawString16` 会产生 `BadDrawable`、`BadGC` 和 `BadMatch` 错误。

## 绘制图像文本字符

某些应用程序（特别是模拟器）需要打印图像文本，其中每个字符的前景和背景位都会被绘制。这可以防止显示器上出现烦人的闪烁。

要在给定的可绘制对象中绘制 8 位图像文本字符，请使用 `XDrawImageString`。

```
XDrawImageString(display, d, gc, x, y, string, length);
```

- `display`: 指定与 X 服务器的连接。
- `d`: 指定可绘制对象。
- `gc`: 指定 GC。
- `x`: 指定 x 和 y 坐标，它们相对于指定的可绘制对象的原点，并定义了第一个字符的起点。
- `string`: 指定字符字符串。
- `length`: 指定字符串参数中的字符数。

要在给定的可绘制对象中绘制 2 位图像文本字符，请使用 `XDrawImageString16`。

```
XDrawImageString16(display, d, gc, x, y, string, length);
```
