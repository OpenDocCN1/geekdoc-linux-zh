这里没有显示所有输出，但如您所见，`chkconfig`可以显示每个服务和每个运行级别的`off`或`on`值。示例输出仅显示在运行级别5中启动的那些服务。`chkconfig`命令可用于重新分配每个运行级别和每个服务的启动或停止值。例如，要在运行级别5使用Fedora时启动电源管理（由`/etc/rc.d/init.d`下的`apmd`脚本控制），请像这样使用`chkconfig`：

```
# chkconfig --level 5 apmd on
```

然后，您可以再次使用`grep`对`chkconfig`的输出进行过滤来验证此操作，如下所示：

```
# chkconfig --list | grep apmd
apmd 0:off 1:off 2:on 3:on 4:on 5:on 6:off
```

`chkconfig`命令不会启动或停止服务；相反，它更改启动或停止服务的脚本，或者它可以报告服务的状态。默认情况下，它仅影响当前运行级别；您可以使用`--level`选项修改其他运行级别。您需要使用`ntsysv`或`service`命令，或者直接运行守护进程来实际启动或停止服务（在本章后面有描述）。所有这些工具都有有用的手册页，可以帮助您回忆所有可用选项。

### 通过 xinetd 运行服务

`xinetd`守护进程是`inetd`的替代品；它在特定端口上监听服务请求，并根据需要启动这些服务。`xinetd`被称为超级服务器，因为它控制其他服务器。其目的是在不需要服务时不运行服务，从而节省资源。`xinetd`守护进程比旧的`inetd`更安全，提供比`inetd`更好的日志记录功能，并且可以将服务请求重定向到另一台机器。它不需要`root`用户来启动任何服务。

`xinetd`的配置文件位于`/etc/xinetd.conf`；单个服务的配置文件位于`/etc/xinetd.d/`；其格式的详细信息在`xinetd.conf`的手册页中有所介绍，其中还提供了一个示例文件列表。如果可能，Fedora提供已配置为使用`xinetd`的相应服务器RPM软件包。如果您正在从源代码手动安装服务器，随附的文档描述了适当的`xinetd`配置。在`xinetd`下运行的服务不能以与`/etc/rc.d/init.d`中通过脚本运行的服务相同的方式启动和停止；您必须重新启动`xinetd`服务本身，并让它控制那些服务。

## 更改运行级别

在对系统服务和运行级别进行更改后，你可以使用`telinit`命令在正在运行的Fedora系统上即时更改运行级别。通过这种方式更改运行级别，使得系统管理员能够修改正在运行的系统的特定部分，以更改服务或使已经做出的更改生效（例如，重新分配网络接口的网络地址）。

例如，系统管理员可以使用带有`S`选项的`telinit`命令快速将系统切换到维护模式或单用户模式，如下所示：

```
# telinit S
```

`telinit`命令使用`init`命令来更改运行级别并关闭当前正在运行的服务。然后，该命令会启动指定运行级别的服务；在本例中，单用户运行级别等同于运行级别2。`init`命令只能从控制台运行，而不能从X会话中运行的`xterm`运行。

在启动到单用户模式后，你可以像这样返回到无X的多用户模式：

```
# telinit 3
```

如果你修改了系统初始化表本身`/etc/inittab`，请使用`telinit`命令的`q`命令行选项强制`init`重新检查该表。

> **提示**
>
> Linux充满了快捷键：如果你在提示符处输入`exit`退出单用户shell，你将回到默认的运行级别，而无需担心使用`telinit`。

## 故障排除运行级别问题

除非发生某些灾难性事件，否则在使用Fedora时，在特定运行级别中重新排序或更改系统服务很少是必要的。但系统管理员应该对Linux如何启动以及服务如何受控以执行故障排除或诊断问题有基本的了解。通过使用诸如`dmesg | less`命令（在启动后读取内核输出）或使用`cat /var/log/messages | less`检查系统日志等额外实用工具，可以在面对问题驱动程序或服务故障时获取更多关于正在发生什么的详细信息。

为了更好地理解如何在Fedora中排查服务问题，请查看典型服务相关问题的诊断和解决方法。在这个例子中，X无法启动：你看不到桌面显示，计算机似乎也没有响应键盘输入。X服务器可能卡在循环中，反复失败，或者可能退出到shell提示符，无论是否带有错误消息。

X服务器仅在运行级别5中尝试重新启动自己，因此为了确定X服务器是否卡在循环中，请尝试切换到运行级别3。

> **提示**
>
> 如果你正在多用户系统上工作，并可能无意中打断其他用户的工作，请让他们保存当前工作；然后切换到更安全的运行级别，例如单用户模式。

通过切换到另一个虚拟控制台（使用`Ctrl+Alt+F2`），以`root`身份登录并运行命令`telinit 3`来切换到运行级别3。这种切换到运行级别3的操作会阻止X服务器尝试重新启动。现在你可以轻松检查错误并尝试修复它。
