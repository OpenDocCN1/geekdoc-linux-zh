## 启动 Linux 安装程序

Linux 安装程序由一系列对话框组成，有时也称为屏幕或窗口。这些对话框向您提供信息，并向您请求信息和决定。启动安装程序最常用的两种方法如下：

- 将 Linux CD-ROM 插入 CD 驱动器并启动系统。系统的 CMOS 必须设置为支持从 CD-ROM 驱动器引导（参见本章前面提到的“启动 Linux 安装”）。
