
`cd [arg]`

在第一种形式中，将当前目录更改为`arg`。如果`arg`是`-`，则切换到上一个目录。`shell`变量`HOME`是默认`arg`。变量`PWD`设置为当前目录。`shell`变量`CDPATH`定义包含`arg`的目录的搜索路径。备目录名称用冒号（`:`）隔开。默认路径为空（即指定当前目录）。注意，当前目录是由空名称指定的，该名称可以紧跟等号出现，或出现在路径列表任何地方冒号分隔符之间。如果`arg`以`/`开头，不使用搜索路径。否则，在路径中的每个目录搜索`arg`。第二种形式在当前目录名`PWD`中将字符串`old`替换为`new`，并尝试切换到此新目录。`rksh`可能不执行`cd`命令。

```bash
cd old new
```


该命令将参数视为简单命令，抑制`shell`函数查找。`-p`选项执行命令搜索，使用`PATH`的默认值，该值保证能找到所有标准命令。`-v`选项向标准输出写入一个字符串，指示`shell`在当前执行环境中中使用路径名或命令调用`command-name`的方式。`-V`选项向标准输出写入一个字符串，指示`command-name`操作数在当前`shell`环境中被解释。

```bash
echo [arg...]
```

用法和描述请参见`echo(1)`。

* `eval [arg...]`
我们将参数作为`shell`的输入并执行结果产生的命令。

* `exec [arg...]`
如果指定了`arg`，则执行参数指定的命令以替换此`shell`，而不创建新进程。输入/输出参数可能会出现并影响当前进程。如果你未指定任何参数，则按照输入/输出重定向列表修改文件描述符。在这种情况下，当调用另一个程序时，任何大于2 的文件描述符都会通过此机制打开。

## ksh, rksh

* `exit [n]`
以`n`指定退出状态退出调用的`shell`或`shell`脚本。该值是指定状态的低有效 8 位。如果省略`n`，则退出状态为上一个执行的命令的状态。当在执行`trap`（陷阱）时发生`exit`，上一个命令指的是在调用`trap`之前执行的命令。`EOF`会退出`shell`，开启了`ignoreof`选项的`shell`除外。

* `export [name=value]...`
标记给定的名称以便自动导出到后续执行命令的环境中。
