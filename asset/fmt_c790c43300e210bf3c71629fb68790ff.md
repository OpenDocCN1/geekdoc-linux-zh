
## 定制 GNOME 和 KDE

无论你使用哪个发行版，GNOME 和 KDE 的默认设置都提供了一个吸引且易于使用的界面，但让我们面对现实吧：在一个你自己设计的桌面上工作要有趣得多。GNOME 和 KDE 都可以以多种方式进行定制和调整，这可以为你提供符合你工作方式的独特用户体验。你可以更改背景图片，或者完全删除它，移动面板和图标，向你的面板添加启动器，自定义菜单，更改窗口的外观和行为——以此类推。

在本章中，我将向你展示如何定制桌面环境的基础知识。选项太多了，我无法涵盖所有内容，但我涵盖了重点并给你一个起点。定制桌面的的一半工作是发现新设置。

### 定制 KDE

## 定义你的桌面

桌面背景是最简单的定制功能之一。有些人喜欢纯色背景，而另一些人喜欢漂亮的图片或疯狂的设计。Fedora Core 的默认背景是一个深蓝色图像，带有抽象设计和右下角的 Fedora Logo。如果你喜欢这个图像并想保留它，可以什么都不做。然而，如果你想更改它，选择 `Desktop -> Preferences -> Desktop Background` 或 `GNOME Control Center` 中的 `Desktop`，桌面背景偏好窗口就会打开，如图 10-3 所示。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_169_0.png)

**图 10-3**：桌面背景偏好窗口。

该窗口的主面板显示了适用于桌面的壁纸。只需点击你想使用的壁纸，它将立即应用到你的桌面。如果你喜欢，可以选择另一个看看效果；当你对选择满意时，点击 `Close` 关闭桌面背景窗口。

### 添加壁纸

如果现有的壁纸没有让你兴奋，你可能想寻找一些新壁纸或添加你自己的照片。要这样做，你需要计算机上已经有一张你想要使用的图片。你可以从网上下载一张，或者从 CD 或其他介质导入你的照片。一旦你将文件复制到计算机，它可能可以在任何地方访问，例如你的主目录。在本例中，我们假设你将一张图像复制到主目录并命名为 `wallpaper.jpg`。

接下来，在桌面背景偏好窗口中，点击 `Add Wallpaper` 按钮。这将打开 `Add Wallpaper` 窗口，如图 10-4 所示。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_170_0.png)

图 10-4：添加壁纸窗口。

在左侧面板中，双击标记为 `Home` 的选项。在右侧面板中，你将看到主目录下的文件列表。选择 `wallpaper.jpg` 文件并点击打开。添加壁纸窗口关闭，现在你可以看到你从可选的壁纸图像中选择了一个。它应该已经被选中了，但如果没有被选中，点击它，你就能在桌面上看到该图片。

## 无壁纸的桌面

当然，桌面上并不要求使用图像。`Desktop Background Preferences` 中的第一个项目是 `No Wallpaper`。如果你选择此项，你需要决定如何处理你的背景。你有三个选择：纯色、垂直渐变或水平渐变。渐变是一组颜色，第一种颜色在整个桌面范围内混合成第二种颜色：垂直渐变是从上到下混合，而水平渐变是从左到右混合。

当你选择 `No Wallpaper` 时，`Desktop Background Preferences` 中的桌面部分将变为激活。如果你之前的桌面图像不足以覆盖整个屏幕，桌面部分可能已经是激活状态，此时你可以选择用于桌面边框的颜色。可以点击显示 `Solid Color` 的区域，这将打开一个菜单，供你选择纯色、垂直渐变或水平渐变。如果你选择了纯色，会在你的选择旁边看到一个方框。点击此方框将打开 `Pick color` 窗口，如图 10-5 所示。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_171_0.png)

图 10-5：选取颜色窗口。

此窗口允许你选择显示在桌面上的颜色。你的选择由一个小圆表示。你可以将此颜色移动到三角形内的任何位置。如果你点击外环，将改变三角形的位置，从而改变其内部的颜色范围。稍微练习一下就会发现这实际上有多简单。一旦你选择了颜色，点击 `OK`。窗口退出，新颜色将出现在桌面上。

如果选择了垂直或水平渐变，如图 10-6 所示，你将在选择旁边看到两个颜色框。这些色框代表形成渐变两端的两种颜色。点击每个色框以调出 `Pick color` 窗口。当你做出选择后，生成的渐变将是两个所选颜色之间的颜色范围。警告：并不是所有的颜色组合都能产生良好的渐变。例如，松石绿和深青柠绿色不会吸引大多数人。

一旦你按照自己的意愿安排好桌面，点击 `Desktop Preferences` 窗口上的 `Close`。你的新桌面现在已保存，并且每次你登录时都会以此配置出现，直到你更改它为止。

## 桌面主题

自定义桌面外观最简单的方法可能就是使用主题。主题是一组视觉元素，标题栏、窗口角、图标、边框等，它们组合在一起，使桌面上的所有内容具有一致的外观。

要访问主题控制选项，请从桌面菜单中选择 `Preferences -> Theme`。这将打开 `Theme Preferences` 窗口，如图 10-7 所示。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_172_0.png)

图 10-6：桌面上的水平渐变。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_172_1.png)

此主题没有建议任何特定的字体或背景。

图 10-7：主题偏好窗口。

在主面板中，你可以看到列出的多个主题。与 `Desktop Background Preferences` 窗口一样，你只需点击它即可选择主题。当你这样做时，你桌面的视觉元素会随之发生改变。这可能需要几秒钟。如果你喜欢这个主题并决定保留它，只需点击 `Close` 退出 `Theme Preferences` 窗口。如果你想做其他操作，请点击相应的按钮。每当你点击一个新主题时，你的主题就会发生变化。

## 安装新主题

默认安装的 Fedora Core 仅带有几个主题，在大部分情况下，它们都相当简陋。这些主题的设计初衷是简单易用。然而，实际上有成百上千的主题可用；其范围从简陋实用到极具趣味性应都有。

`GNOME` 主题的中心区域位于 `GNOME` 网站的 Art 部分，地址为 `http://art.gnome.org`。这些主题分为若干几种类型：

- `Application`：这些是控制按钮和复选框外观、窗口和面板样式等的主题。
- `Window Border`：这些主题控制窗口的轮廓。
- `Icons`：在这里你可以找到一组图标。
- `Login Manager`：登录管理器主题决定登录界面。
- `Splash Screen`：启动屏幕控制 `GNOME` 会话启动期间你看到的内容。
- `GTK+ Engines`：这些主题主要用于开发其他主题。

还有第六大类：`GTK+ Engines`。这些主题主要用于开发其他主题。

要安装应用程序主题，首先下载主题。它需要是压缩格式。打开 `Preferences` 窗口并点击 `Themes`。这将打开 `Theme Details`，如图 10-7 所示。

`Theme Details` 窗口应打开 `Controls` 选项卡。如果选择了不同的主题，请点击 `Controls`。接下来，找到你下载的主题图标。如果你没有下载到桌面，请打开 `Nautilus` 窗口并导航那里。点击图标并将其拖到主题窗口。你的主题安装已确认。点击 `OK` 确认窗口。你现在可以在 `Theme Details` 窗口的左侧看到你下载的主题名称。它可能已经被选中。如果没有，点击它进行高亮。一旦选中，你应用程序的控件将显示新主题的艺术。

![](img/65ef52f6e9fc73ddc3051990377c4f5b_174_0.png)

图 10-8：主题详情窗口。

安装窗口边框的方法与安装应用程序完全相同，只是当你打开 `Theme Details` 窗口时，需要点击 `Window Border`，然后将图标拖入。安装图标主题稍微有点复杂。在 Fedora Core 4 使用的 `Preferences` 程序版本存在一个 Bug，不会将主题文件安装到正确位置。因此，你必须使用终端手动完成。
