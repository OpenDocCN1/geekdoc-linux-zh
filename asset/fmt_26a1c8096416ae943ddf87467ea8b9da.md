## 8.2.7 Assembler

`as`
`ndisam`

（3 个命令）。汇编器，一种替代原生汇编器和反汇编器。发送你的新手示例说明如何使用这些：例如 `ndisam /bin/sh |` 会产生来自系统二进制文件的长段输出（在本示例中为 `/bin/sh`），我无法理解。要了解更多关于 `as` 的信息，你可能想查看：`file:/usr/share/doc/nasm-doc-0.98/nasmdoc0.html`

适用于 Linux 2.2.17 或更高版本的 Intel 示例：

```asm
;; hello.asm: 版所有 (C) 2001 Brian Raxter, the GNU
;; General Public License (版本 2 或更高)。不提供担保。

BITS 32
org 0x600000
db 0x7F,"ELF"
d dd 1
d dd 0
d dd 2
d dd 3

start:   inc eax      ; de系统调用号
mov dl, 13      ; 设置消息长度
mp al, _start  $
pusha           ; 保存 eax 和 ebx
xch eax, ebx    ; 将 ebx 设置为 1 (stdout)
```

```assembly
add eax, dword 4    ; 4 = 写系统调用号
```

谁会使用汇编语言？通过汇编构建，在我的系统上执行文件仅有 56 字节。具有相同功能的“C”语言（见上一页）则是 13.7 KB。

以下是简要说明，帮助我理解上述程序：

`;` 用于注释到行尾。

`msg:` 是标签的一个示例（类似于 FORTRAN 中的标签）。

`org(\origin")` 声明程序在内存中的起始位置（在加载到内存执行之后）。

`db`, `dw` 是作为“伪指令”用于向输出文件插入初始化的数据。

`$` 求值为包含该表达式的行开头的汇编位置；因此你可以使用 `JMP $` 创建无限循环。`$` 的求值为当前节段的开头。

通用 32 位处理器有 `EAX`, `EBX`, `ECX`, `EDX`, `ESI`, `EDI`, 和 `EBP`。`"E"` 代表扩展（extended）。这是因为处理器可以“叠加”寄存器，并将它们视为命名为 16 位寄存器：`AX`, `BX`, `CX`, `SI`, `DI`, `BP`, 和 `SP`。使用它们，还有 8 位寄存器：`AL`, `AH`, `BL`, `BH`, `CL`, `DH`。这里的 `"L"` 和 `"H"` 分别代表“高”（high）和“低”（low）。

## 8.2.8 Scheme

`guile`
`"Scheme"` 编程语言的一种实现。Scheme 是 LISP 语言的一种现代方言（在过去的 40 年中一直有望应用于人工智能的语言）。

用于 `guile` 解释器的愚蠢示例。

```guile
(+ 1 1)
(define a 2)
(/ a 3)
(= a 7)
(display "hello\n")
(system "ls")
(exit)
```
