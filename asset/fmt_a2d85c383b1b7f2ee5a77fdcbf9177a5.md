
# GNOME 概述

GNOME（GNU 网络对象模型环境）是一组易于使用的应用程序和桌面工具，可与 X 窗口系统的窗口管理器配合使用。GNOME 的目的与 C 和 KDE 类似，但 GNOME（与 KDE 一样）完全基于开源软件。GNOME 的强大之处在于视觉上漂亮、易于配置和使用。此软件包将安装如 GNOME CD 播放器等功能。如果你想开发 GNOME 应用程序，还需要安装 `gnome-print` 软件包。源自 Mandrake 9.0 RPM http://www.tldp.org/LDP/Linux-Dictionary/index.html

## `gnome-utils`

Gnome 工具 (itt, gsearch 等)。Gnome 是“GNU 网络对象模型环境”。这是一个完全基于自由软件构建的完整、用户友好桌面的项目。此包包含了一些附带 Gnome 的杂项工具：

- `gelorsel` – 颜色选择器

- `gfontsel` – 字体选择器 – 'less' 分页器的 Gtk 版本
- `gsearchtool` – 用于查找文件和 grep 文件的工具
- `gs` 重启或关机你的机器
- `gtt` – 任务列表/跟踪器
- `gnome` – 显示关于你系统的信息
- `gw` – 显示系统上的用户，'like'
- `ideol` – 一个 IDE 磁盘工具查看
- 日志查看应用程序
- splash/space – 启动屏渲染器
- clipart – 绘制系统测量（包括应用版本）来自 Debian 3.0.0 http://www.ldp.org/LDP/Linux-Dictionary/index.html
