
确保你的硬盘上有足够的可用空间。如果你有双系统，可以使用 `DOS` 分区上的空间。

-   要将音频文件写入 `CD-R(RW)`，我可以使用：

```bash
cdrecord -speed=8 dev=0,0 -pad -audio track*
```

某些音频 CD 在各个音频音轨之间没有间隙。制作此类 CD 最简单的方法是使用工具 `cdraw`。
要将磁盘复制到硬盘上的文件 `data.bin`，并将目录复制到文件 `toc-file.toc`，可以使用此命令：

```bash
cdraw -device dev=0,0 --buffers 64 --driver generic-mmc-raw --read toc-file.toc
```

要从我创建的文件中刻录 CD，可以使用：

```bash
cdraw -device 0,0 --buffers 64 --driver generic-mmc-raw --speed 12 toc-file.toc
```

关于可重写 CD 的说明。某些音响系统因为 CD 上凹槽（pits）的大小问题无法播放可重写 CD。例如，我的家用立体音响（JVC）完全无法读取可重写 CD (`CD-RW`)，尽管它可以读取只写一次 CD (`CD-RS`)。因此，可重写 CD 更适合存储数据而非适合音频（我计划仅在电脑上播放它们）。

## 7.7.5 创建混合模式 CD

混合模式 CD（使用同时包含数据和音频的 CD，甚至是游戏 CD）并不是问题，例如：

-   挂载混合模式 CD 的数据部分

```bash
mount -t iso9660 /dev/cdrom /mnt/cdrom
```

-   从 CD 数据创建 ISO 文件系统

```bash
mkisofs -r -o cd_image /mnt/cdrom
```

-   卸载 CD

```bash
umount /mnt/cdrom
```

-   刻录 CD 上所有音频音轨的内容，第一个音轨除外，因为它是数据

```bash
cdparanoia -B "2-"
```

-   逐个写入数据和音频文件

```bash
cdrecord -speed=2dev=0,0 -data track*
```

## 7.7 复制整个 CD

大多数 CD 可以通过先将所有数据（对于数据 CD）或所有音轨（对于音频 CD）复制到硬盘来实现，但某些 CD 不行。
例如，这些数据（而非音频）CD 需要不同的处理方式：可启动 CD（如 Linux 安装盘）、带有错误的磁盘等。对于 CD，我使用这些命令制作精确复制：

```bash
cdrecord -v speed=2dev=1,0 -data cd_image
```

`dd` 命令将输入文件（`if`，在本例中是 `/dev/cdrom`）复制到输出文件（`of`，在本例中是硬盘上的 `cd_image`）。第二个命令将由该命令创建的 `cd_image` 写入空 CD。

对于带有错误的数据，你可能想尝试：

```bash
cdrecord conv=noerror,notrunc=/dev/cdrom of=cd_image

cdrecord -v speed=2dev=1,0 -data cd_image
```

选项 `conv=noerror,notrunc` 指定忽略读取错误且不截断文件。对于音频 CD，我使用此命令制作复制：将 CD 上所有音频音轨逐个刻录。音轨保存到当前目录下的文件中并命名为 `track1.cda.wav,track2.cda.wav, etc.`。
