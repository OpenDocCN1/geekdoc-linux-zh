- 6. 如果前一条语句中的表达式评估为`false`，则评估此语句。该表达式读取为*如果* `$hour` *等于* 12...

#### *switch*特性 (*given*/*when*/*say*)

从Perl 5.10.1及更高版本开始，你可以使用实验性的`switch`特性，该特性启用了Perl 6的*given*/*when*结构，`use feature qw(switch);`

只要声明你的代码偏好在Perl 5.10.1或更高版本下运行，你就可以获得`switch`特性。例如：

```perl
use v5.10.1;
```

Perl 5版本18.0的文档说明：

在"`switch`"特性下，Perl获得了实验性的关键字*given*、*when*、*default*、*continue*和*break*。从Perl 5.18开始，你可以使用`CORE::`作为前缀来访问这些特性，而无需包含`use feature`。在下面的示例中，每个特性都带有`CORE::`标签：

```perl
CORE::given ( $some_variable) {   
CORE::when( /abc/ ) { statements }
```

（`CORE`命名空间提供了访问Perl原始内置函数的功能。有关`CORE`的更多信息，请参阅http://perldoc.perl.org/CORE.html。）

示例7.33中的代码可以重写为示例7.34所示的形式。

### 示例 7.33

```perl
use v5.10.1;  
for (1..24) {  
 when([1..11]) { say "Morning" }  
 when(12) { say "Lunch" }  
 when([13..17]) { say "Afternoon"}  
 default {say "Night"}  
}
```

### 示例 7.34

```perl
use feature qw(switch say);
my @weeks=("Sunday",
           "Monday",
           "Tuesday",
           "Wednesday",
           "Thursday",
           "Friday",
           "Saturday");
foreach $wday (0..6){
	$today=$weeks[$wday];
	given ($wday) {
		when([1..5]) { say "$today is Work, work, work" }
		when (6) {say "$today is Play!"}
		default { say "$today is Rest" }
	}
}
```
