## 如何获得 Linux 认证

### 我为什么要获得 Linux 认证？

嗯，你可能有的第一个问题是为什么要获得 Linux 认证？这个问题的答案与获得一般的认证类似。它通过测试并通过最低标准的知识测试，帮助证明你对 Linux 操作系统的了解。它还能帮助你获得行业内的工作。许多工作都要求 Linux 认证，例如管理员或服务器管理员。它还能够充实你现有的 Linux 知识，你可以将其应用于工作中。

### 我应该获得哪种 Linux 认证？

这本身可以单独成一篇文章——但我将所有信息都包含在这里这个方便的地方。有四家主要的 Linux 认证供应商，他们都为不同的级别提供系列不同的认证。

#### Novell（诺维尔）

他们提供一系列认证，标签为工程师 (`Engineer`)、专业人士 (`Professional`) 和桌面管理员 (`Desktop Administrator`)。

- 认证 Linux 工程师 (`CLE`) - 为管理基于 `SUSE Linux Enterprise` 的大型系统的经理和架构师提供工程师级技能。你需要通过认证 Linux 专业人士考试才有资格获得此项认证。
- 认证 Linux 管理员 (`CLA`) - 一种关注 `SUSE Linux Enterprise Server` 网络日常运行的新认证。
- 认证 Linux 桌面管理员 (`CLDA`) - 针对那些有 Windows 桌面经验并希望学习 `SUSE Linux Enterprise Desktop` 的人员。
- 认证 Linux 专业人士 (`CLP`) - 提供管理 `SUSE Linux Enterprise Server` 所需的。

#### CompTIA

CompTIA 只提供一种 Linux 认证，即 `Linux+`。

- `Linux+` - 针对想要进入 Linux 领域的人的入门级认证。厂商无关。

## Linux Professional Institute（Linux 专业协会）

Linux Professional Institute，又称为 `LPI`，提供几项 Linux 认证。

- Linux Professional Institute 认证级 级 (`LPIC-1`) - 一种初级 Linux 认证，测试主要 Linux 发行版的基础技能。
- Linux Professional Institute 认证 2 级 (`LPIC-2`) - 一种高级 Linux 认证，涵盖管理技能。需要通过 `LPIC-1` 获得此认证。
- Linux Professional Institute 认证 3 级 (`LPIC-3`) - 一种针对主要 Linux 发行版的高级 Linux 认证，提供多个专业方向。需要通过 `LPIC-2`。

#### Red Hat（红帽）

Red Hat 为他们的 Linux 版本提供若干认证。

- 红帽认证系统管理员 (`RHCSA`) - 一种涵盖管理基础的低级 Linux 认证。
- 红帽认证工程师 (`RHCE`) - 针对经验丰富的 Linux 专业人士的高级 Linux 认证。`RHCSA` 是此认证的要求。
- 红帽认证虚拟化管理员 (`RHCVA`) - 关注在 Linux 环境中部署虚拟机。
- 红帽认证安全专家 (`RHCSS`) - 关注 Linux 安全功能和领域。
- 红帽认证数据中心专家 (`RHCDS`) - 关注管理和支持数据中心环境的要求。
- 红帽认证架构师 (`RHCA`) - 红帽认证最高级别，关注 Linux 管理和使用的专家主题。

所以，关于应该获得哪种 Linux 认证的答案是？

这取决于你的经验和需求。对于初级 Linux 认证（`Linux+`、`RHCSA`、`LPIC`、`CLE`）对于入门很有用。更高级认证如 `RHCE`、`LPIC-2`、`CLA` 和 `CLP` 对于有经验的人非常有益。

## 在新计算机系统上安装 Linux 的 7 个步骤

### 1. 记录你的 Linux 安装设置

在 Linux 安装过程中，你需要指定一些系统设置。这些包括：你想安装的 Linux 软件程序和桌面、网络设置以及磁盘分区大小。

### 2. 使用 Linux CD 或 DVD 启动并开始 Linux 安装程序

设置系统从 CD 或 DVD 驱动器启动的步骤。

关闭你的系统，并在驱动器中插入第一个 Linux CD / DVD 启动系统，开始 Linux 安装程序。

### 3. 指定你的 Linux 安装设置

按照屏幕提示，输入你在第 1 步中记录的安装设置。

### 4. 创建普通（“非 root”）用户

你以 Linux “用户”的身份登录并在 Linux 系统上工作，拥有用户名和密码。你可以以“root”用户身份，也可以以“非 root”用户身份登录。

当你需要执行 Linux 系统管理任务时，以 `root` 用户身份登录并在 Linux OS 上工作。例如，你以 `root` 用户身份运行 Linux 命令来创建新用户，或执行安装 Linux 服务器的步骤。

当你安装 Linux 时，系统总是会自动创建 `root` 用户用于执行 Linux 系统管理任务。然而，出于安全考虑，你永远不要以 `root` 用户身份登录 Linux 桌面。

在安装过程的某个时刻，系统会询问你是否想再创建一个“普通”（非 `root`）Linux 用户。请务必至少创建一个普通 Linux 用户，并使用该用户处理日常任务。

### 5. 让 Linux OS 安装在硬盘上

在指定 Linux 安装设置并创建一个或多个新 Linux 用户后，安装程序会将 Linux OS 和 Linux 软件程序复制到系统的硬盘上，然后重启。

### 6. 登录并测试系统

系统重启后，以“普通”（非 `root`）Linux 用户身份登录，测试你是否可以以此用户身份工作。此时，Linux 桌面会出现，你可以运行 Linux 程序来测试系统。
