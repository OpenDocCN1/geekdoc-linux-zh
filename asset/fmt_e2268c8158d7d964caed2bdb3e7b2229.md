
## 在 CENTOS 中创建 RAID 1

RAID 0 虽然不具备容错能力，但它有一些优势：

- 它具有高性能
- 不会浪费空间
- 读写速度会很快

在虚拟机中设置 RAID 0：

- 要求：
  - 虚拟机
  - 两个磁盘
  - 互联网连接
  - 一个静态 IP 地址（如果你想 ssh 连接服务器）

### 第 1 步

在 centos7 虚拟机中添加两个 20GB 的磁盘。

### 第 1 步：在虚拟机中添加三块 20GB 磁盘

必须关闭虚拟机以减少内存占用。

### 第 2 步：启动机器

### 第 3 步：打开终端（或直接 ssh 到服务器）

### 第 4 步：应用 `lsblk` 命令查看块设备

=>`lsblk`

```

有三个额外的设备 `sdb`、`sdc` 和 `sdd`，我们使用这三块硬盘来创建一个 raid 5。

### 第 5 步：安装 mdadm 包

```
=>yum update
=>yum install mdadm -y
```

### 第 6 步：检查软件包的版本

```
=>mdadm -version
```

### 第 7 步：使用 mdadm 检查硬盘

=>`mdadm --examine /dev/sd[b-d]`

  └─sdd1 8:49 0  20G 0 part

```

### 第 12 步：创建 RAID 设备

=>`mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb /dev/sdc /dev/sdd`

### 第 13 步：查看 RAID 详情

=>`mdadm --detail /dev/md0`

### 第 14 步：格式化卷

=>`mkfs.ext4 /dev/md0`

### 第 15 步：挂载卷

=>`mkdir /mnt/raid`
=>`mount /dev/md0 /mnt/raid`

### 第 16 步：检查挂载的卷

=>`df -h`
