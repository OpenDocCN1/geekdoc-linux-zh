# 海王星

通过望远镜观察，海王星呈现出一个蓝色的圆盘。它与地球的距离（307.7亿公里（2055 AU））与天王星非常相似。海王星的质量是天王星的17倍，平均密度为1.62，大约是其姐妹行星的两倍。

我们对海王星的大部分认知源于1989年旅行者2号探测器的飞掠。该任务包括了对海王星的卫星海卫进行近距离研究，揭示了海王星比天王星活跃得多。

通过对探测器进行数周的追踪，科学家推断出某些纬度存在电流，其速度远高于天王星。这种循环模式表明两个行星的轴倾角不同（海王星的角度不同）。

海王星的大气与其他巨行星一样，由氢和氦组成。甲烷的相对含量比太阳中元素的丰度高出约30倍。

海王星磁场的方向相对于旋转轴倾斜了47°。这在行星磁层中形成了由电离和中性气体组成的等离子体。

在旅行者号接触之前，仅已知海王星有颗卫星，它们都具有倾斜轨道。海卫一绕海王星进行逆行轨道，周期为5.9天，轨道近乎圆形。大约100年后，加勒（G. P. Galle）在搜索中发现了它。它是已知离心率最高的卫星。旅行者号发现的另外两个卫星具有规则且近圆形的轨道。海卫一的大气由氮、甲烷、一氧化碳和水蒸气组成，这些物质也同样存在。这些气态在卫星表面凝结成冰。

旅行者号相机显示海王星周围有三个定义的环，每个环都由一片构成环体的物质组成。最外层的清晰环是亚当斯环、加勒环和拉法叶环，它们包含了物质团。

这些窄环的发现通常归因于小卫星的存在。伽拉忒（Galatea）和德斯皮娜（Despina）在外环之外轨道运行，但尚未发现相应的守护者卫星。环内弧状结构的持续性尚不确定。

# 神经系统（无脊椎动物）

无脊椎动物拥有神经系统，可以定义为根据形状和功能组织的细胞集合，作为神经体的主要协调者。神经组织使生物具备感知环境、运动反应以及控制生物功能的能力。

与脊椎动物相比，无脊椎动物的神经系统更简单，复杂性较低；更容易接触且组织性较低；难以采用实验方法。

无脊椎动物神经系统具有独特的特征和智力，尽管人类和脊椎动物在进化发育上存在巨大差异。

无脊椎动物和脊椎动物神经系统在复杂性、大小和数量上存在差异，这是最显著的特征。显著的区别在于无脊椎神经具有单极神经元，而脊椎神经元是多极的。

无脊椎和脊椎神经系统的另一个对比是，无脊椎神经系统倾向于向外周（身体外侧）迁移，并与中枢神经系统进行更多整合。

无脊椎动物神经系统在神经细胞受损后具有更大的生长、再生或修复潜力。无脊椎动物神经细胞随年龄增长继续向神经节中添加新细胞；脊椎动物通常不如此。只有无脊椎神经元具有髓鞘（环绕轴突的特殊胶质膜），并连接到脊髓。无脊椎动物通过巨轴增强某些反应的传导速度。

神经系统（脊椎动物）——一种在生物适应环境方面发挥协调和整合系统。环境刺激通过特化结构（受体）引起生物产生反应。兴奋通过神经传导，以适应环境的变化。
