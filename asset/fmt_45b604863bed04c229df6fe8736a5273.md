## 在哪里寻找驱动程序

一个很好的起点是 Linux 发行版的官方网站；例如，`www.redhat.com`（RedHat 网站的一个小部分）或 `www.debian.org/distrib/wptlist`（Debian 网站的一个小部分）。你也可以从任何网络浏览器中使用你最喜欢的搜索引擎，并输入关键词“Linux”和“你的硬件名称”。这通常会提供几个（甚至数百个）指向带有驱动程序的网站的链接。大多数网站还会包含他们最新的硬件兼容性 HOWTO 作为额外提示。

此外，选择你喜喜欢的搜索引擎，输入关键词“Linux”和`{你的硬件}`。你应该得到许多指向驱动程序网站的链接，可能会列出一些收藏品，如显卡、网卡和 SCSI 卡。最新的硬件兼容性 HOWTO 应该提供一些提示。

## 迁移到桌面工作站

你一定记得上一次更改操作系统是什么时候，从 DOS 改到 Win3.x / Novell 或者 Win95 / NT / Novell？这种向 Linux 的转变将不会那么痛苦。在某些情况下，你可能需要对某些用户进行重新培训。然而，基本的界面技能将保持不变，但某些应用程序可能会有所不同，例如你的办公套件。但如果这是一个特定的数据库客户端桌面，其外观和感觉应该非常相似，甚至完全相同，而且可靠性很高。想想，普通用户根本不知道如何从软盘中存或取文件！这难道不值得吗？不仅如此，一个像 StarOffice 这样提供界面和文档兼容性的免费办公套件又如何？你可能想检查一下 Sun Microsystems 免费提供的 StarOffice 生产力套件，地址为 `www.sun.com/products/starOffice`，它包含在许多版本的 Linux 中（包括 RedHat 6.1 和 TurboLinux 4.0）中。你可以通过访问 `www.slashdot.org` 和 `www.freshmeat.net` 等网站找到这些以及其他产品，如新的 GNU Office 套件，这些网站提供 Linux 社区新闻以及在大多数情况下所有不同 Linux 版本的游戏、应用程序、补丁和升级的最新软件下载。
