- `-o options` 指定以逗号分隔的可导出文件系统。`exportfs` 选项转换为 share- 等效选项。

# exstr — 从源文件中提取字符串

### 概要

```
/usr/bin/exstr filename...
/usr/bin/exstr -e filename...
/usr/bin/exstr -r [-d] filename...
```

## 描述

使用 `exstr` 命令从 C 语言源代码提取字符串，并将其替换为消息检索函数的调用（参见 `gettext(3)`）。此命令提取所有由双引号包围字符字符串，而不仅仅是作为 `printf` 命令或 `printf` 例程参数的字符串。在第一种形式下，`exstr` 在所有源文件中查找字符串并将其写入标准输出。使用以下步骤从源文件中提取字符串：

+ 1. 使用 `exstr -e` 提取字符串列表并将其保存到文件中。
2. 检查行并确定哪些字符串可以被翻译并随后由消息检索函数检索。
3. 修改文件，删除无法翻译的行；对于可以翻译的行，将消息文件名和消息编号作为行的第四项 (`msgfile`) 和第五项 (`msgnum`) 目。命名的消息文件必须由 `mkmsgs(1)` 创建并存在于 `/usr/lib/locale/locale_LC_MAGES`。目录 `locale` 对应于编写文本字符串的语言；参见 `setlocale(3)`。使用与消息文件中字符串顺序对应的消息编号。
4. 使用此修改后的文件通过 `-r` 提取，以生成原始 C 语言源代码的新版本，其中字符串已被替换为对消息检索函数 `gettext()` 的调用。`msgfile` 和 `msgnum` 字段用于构造 `gettext()` 的第一个参数。如果在运行时消息检索失败，则打印 `gettext()` 的第二个参数。除非你使用 `-d` 选项，否则该参数为空字符串。

`exstr` 命令无法替换所有实例中的字符串。例如，静态初始字符字符串无法被替换为函数调用。第二个例子是可能是转义序列形式且无法翻译的字符串。为了不破坏现有代码，你必须检查调用 `exstr -e` 创建的文件，并删除包含无法用函数替换的字符串的行。在某些情况下，代码可能需要修改，以便字符串可以被提取并替换为消息检索函数的调用。

## 选项

+ `-e` 从命名的 C 语言源文件中提取字符串列表，并带有位置信息。此列表按以下格式在标准输出生成：
`file:line:position:msgfile:msgnum:string`
`file` C 语言源文件的名称。
`line` 文件中的行号。
`position` 行中的字符位置。
`msgfile` 空值。
`msgnum` 空值。
`string` 提取的字符串。通常，你将此输出重定向到文件中。然后，编辑此文件添加你用于 `msgfile` 和 `msgnum` 的值。
`msgfile` 包含替换字符串的文本字符串的文件。该文件必须由 `mkmsgs(1)` 命令创建并安装在适当的位置。
`msgnum` 字符串在 `msgfile` 中的序号。

+ `-r` 将 C 语言源文件中的字符串替换为消息检索函数 `gettext()` 的函数调用。

## 示例

与 `-r` 选项结合使用。当运行时调用 `gettext()` 失败时，将打印提取的字符串。你可以在需要在国际环境中运行并需要以多种语言打印消息的应用程序上使用 `exstr` 提供的功能。`exstr` 将文本字符串替换为指向消息数据库中字符串的函数调用。所使用的数据库取决于环境变量 `LC_MESSAGES` 的运行时值（参见 `environ(0)`）。

以下示例显示了 `exstr` 的用法。
假设文件 `example.c` 包含两个字符串。

```
main()
{
    printf("This is an example\n");
    printf("Hello world!\n");
}
```

以下示例使用参数 `example.c` 调用 `exstr` 命令，从命名文件提取字符串并将其打印到标准输出。

```
castle$ exstr example.c
example.c:This is an example\n
example.c:Hello world!\n
cast$
```

接下来，使用 `-e` 选项提取字符串并将输出重定向到命名的 `example.string`。

```
castle$ exstr -e example.c > example.string
castle$ more example.string
example.c:3:22:::This is an example\n
example.c:4:22::UX:Hello world!\n
cast$
```

你必须编辑 `example.string` 添加你想要用于 `msgfile` 和 `msgnum` 字段的值，然后这些字符串才能被替换为检索函数的调用。以下示例使用 `UX` 作为消息文件名，并将数字 1 和 2 作为文件中字符串的序号，生成如下所示的文件。

```
castle$ more example.string
example.c:3:22:UX:1:This is an example\n
example.c:4:22:UX:2:Hello world!\n
```

接下来，使用 `-r` 选项提取字符串以生成原始 C 语言源代码的新版本，其中字符串已被替换为消息检索函数 `gettext()` 的调用。`msgfile` 和 `msgnum` 字段用于构造 `gettext()` 的第一个参数。如果在运行时消息检索失败，则打印 `gettext()` 的第二个参数。除非你使用 `-d` 选项，否则该参数为空字符串。
