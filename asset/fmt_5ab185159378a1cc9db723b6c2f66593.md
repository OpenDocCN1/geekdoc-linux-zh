## 2.5.5 使用 YaST 进行专家级分区

使用下一页图 2.8 所示的专家对话框，手动修改您硬盘的分区。可以添加、删除或编辑分区。

专家对话框的列表中显示了所有连接硬盘上的所有现有或建议的分区。整个硬盘被列为不带数字的设备，例如 `/dev/hda` 或 `/dev/sda`。分区列为这些设备的部分，例如 `/dev/hd1` 或 `/dev/sda1`。硬盘及其分区的尺寸、类型、文件系统和挂载点也会被显示。挂载点描述了分区在 Linux 文件系统树中的挂载位置。

## 创建分区

1. 选择“新建”。如果连接了多个硬盘，将出现一个选择对话框，在其中选择新分区的硬盘。然后，指定分区类型（主分区或扩展）。可以创建最多四个主分区，或最多三个主分区和一个扩展分区。在扩展分区内，您可以创建多个逻辑分区（参见第 19 页的第 2.5.4 节）。
2. 选择格式化分区的文件系统和挂载点。YaST 会为每个分区建议挂载点。
3. 选择“确定”应用更改。

## 分区参数

如果您创建新分区或修改现有，YaST 将提供各种的建议。如果需要进行手动设置，请按照以下步骤操作：

1. 选择分区。
2. “编辑”分区并设置：
   - 文件系统 ID：即使您不想使用 LVM，也可以指定以下文件系统：`Linux`、`Linux swap` 或 `RAID`。参考 LVM 指南。
   - 文件系统：要立即格式化分区，请指定以下内容：`Ext2`、`Ext3` 等。
   - 文件系统选项：在此处可以指定关于的参数。
   - fstab 选项：此处可以指定管理文件 `/etc/fstab` 的各种参数。高级用户可以修改许多选项。在更改任何内容之前，请参考指南中的相关章节。
   - 挂载点：指定在 Linux 文件系统树中的挂载位置。YaST 的建议可以展开。
3. 选择“下一步”激活分区。

## 调整 Windows 分区大小

如果选择了包含 FAT 或 NTFS 分区的硬盘作为安装目标，YaST 将提供删除或缩小此分区。通过这种方式，即使硬盘上目前没有空间，也可以安装 SUSE LINUX。硬盘包含一个覆盖整个硬盘的 Windows分区，这在预装计算机中很常见。YaST 发现所选硬盘空间不足，但通过删除或缩小 Windows 分区可以获得空间，它将显示一个对话框供在这两个选项中进行选择。

如果您选择“完全删除 Windows”，Windows 分区将被标记为删除，空间将用于安装 SUSE LINUX。

## 注意事项

一旦开始格式化，如果你删除了 Windows，所有数据都将面临无法恢复的丢失。

要收缩 Windows 分区，请中断安装并启动 Windows，以便从该处对分区进行准备。虽然此步骤对于 FAT 分区并非强制性，但它可以加速调整过程并使操作更安全。这些步骤对于 NTFS 分区至关重要。

FAT 文件系统：在 Windows 中，首先运行 `scandisk` 以确保 FAT 分区没有丢失的文件碎片和交叉链接。之后运行 `defrag` 将文件移动到分区开头。这将加速 Linux 下的调整程序。

## 2 自定义安装

注意：如果你为 Windows 优化了虚拟内存设置，使其具有相同初始（最小）和最大大小限制的连续交换文件，请考虑采取其他步骤。在这些 Windows 设置下，调整大小可能会导致交换文件被分成许多分散在整个 FAT 分区上的细小部分。此外，在调整大小期间需要移动整个交换文件，这会导致过程变得非常缓慢。因此，建议暂时取消这些 Windows 优化，并在调整大小完成后重新启用它们。

NTFS 文件系统：在 Windows 中，运行 `scandisk` 和 `defrag` 将文件移动到硬盘开头。与 FAT 文件系统不同，在 NTFS 中必须执行此操作才能调整大小。

注意：如果你在 NTFS 文件系统上使用永久交换文件运行系统，该文件可能位于硬盘末尾，并且在碎片整理后依然存在。因此，可能无法充分收缩分区。在这种情况下，请禁用交换文件（Windows 中的虚拟内存）。分区调整大小后，重新配置虚拟内存。

完成这些准备后，返回 Linux 分区设置并选择“收缩 Windows 分区”。对分区进行快速检查后，YaST 将打开一个对话框，建议收缩 Windows 分区。

第一个图显示了 Windows 目前占用了多少磁盘空间以及仍可用空间。第二个图显示了根据 YaST 当前建议（见下页 2.10）调整大小后空间如何分布。接受建议的设置或使用滑动块更改分区大小（在一定范围内）。

如果你通过选择“下一步”离开此对话框，设置将被存储并将你带回之前的对话框。实际调整将在格式化硬盘之前进行。
