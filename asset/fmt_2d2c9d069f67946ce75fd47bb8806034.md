
基于 X 的系统监控器，其他是 `procmonter` 的旧版本。你可能想安装 `procmeter` 而不是这个，因为它包含了此旧版本不具备的功能——记录到文件或 syslog 的能力，以及从命名管道读取的能力。`Procmeter` 显示持续更新的系统信息图。支持许多不同的图表，包括：总 CPU、用户进程、内核或系统进程使用的 CPU。交换量、换入、换出、交换入、页出、再次页出。进程数量、上下文切换次数、CPU 空闲时间、读取、写入或中断。空闲、已用或缓存内存的大小（MB）。已使用的交换分区大小。通过本地接口、以太网或 slip/ppp 接口接收或传输的数据包数量。以太网上的冲突次数、电池寿命统计数据。如果这些还不够，`procmeter` 还允许你编写与 `procmeter` 通信的程序并在显示中添加新图表。`Procmeter` 还可以将统计数据记录到文件并回放。源自 Debian 3.0r APT

# procs

`/proc` 文件系统工具。这些是用于浏览 `/proc` 文件系统的工具，该文件系统并非内核用于使用的真实文件系统，而是用于提供有关其进程表中的条目状态的信息（例如：运行、停止或“僵尸”状态）。提供了命令行和全屏工具。全屏模式需要 Nurses。源自 Debian 3.0r APT

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# props

`props` 包包含一组提供系统信息的系统工具。`Props` 包含 `ps`, `free`, `kill`, `load`, `loadtop`, `uptime`, `vmstat` 和 `watch`。`ps` 命令显示运行中进程的快照。`free` 命令重复更新运行中进程的状态。`free` 命令显示系统上空闲和已用内存的。`kill` 命令可以向进程集终止一个命令（或另一个指定的信号）。

# Linux 词典

`snice` 命令用于更改指定进程的调度优先级。`load` 命令向指定的终端打印当前系统负载平均负载的图表。`uptime` 命令显示当前时间、系统运行了多久、登录了多少用户，以及过去五分钟和十五分钟的系统平均值。`w` 命令显示当前登录的用户列表以及他们正在运行的内容。`watch` 命令显示正在运行的程序。`vmstat` 命令显示关于进程、内存、分页、块 I/O、陷阱（trap）和 CPU 活动的虚拟内存统计。

# 专业工作站

一种高性能个人电脑，针对数字设计、建筑和技术制图等领域的专业应用进行了优化。专业工作站通常提供卓越的屏幕分辨率、强大的处理器以及大量的内存。例如 Sun Micros 和 Next, Inc. 制造的工作站。专业工作站比个人电脑昂贵，通常使用 UNIX 操作系统。然而，随着个人电脑变得越来越强大，高端个人电脑和专业工作站之间的界限正在消失。源自 QUEDIC

# proftpd

多功能托管 FTP 守护进程。作为 `wuftpd` 的强大替代品，该文件传输协议（FTP）支持隐藏目录、虚拟主机和每个目录的“ftaccess”文件。它使用类似于 Apache 语法的配置文件。由于其先进的设计，匿名 FTP 目录具有内部结构（bin, lib 等以及不需要的特殊文件）。高级功能包括多个密码文件，并支持上传/下载比例。此包仅包含 `proftpd` 的基本功能和认证。如果你需要 SQL 或 LDAP，更多信息可以在 http://www.proftpd.net/ 找到。源自 Debian 3.0r APT
