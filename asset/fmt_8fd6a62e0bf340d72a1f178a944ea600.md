
# 空洞与洞穴形成

空洞可能发生在地下、山坡或悬崖侧，而洞穴出现在各种类型的岩石和地形状况中。它们可能由许多侵蚀过程形成。最重要的例子是水溶性岩石，如石灰岩、白云岩和石膏。盐洞最常见且持续时间最长。由波浪作用形成的洞穴、水下通道管流引起的洞穴以及此类洞穴的形成被称为洞穴形成（speleogenesis）。参见白云岩（DOLOMITE）；石膏（GYPSUM）；石灰岩（LIMEST）。

# 空化

当液体受到足够强烈的声音（或超声波，频率为20 kHz至10 MHz的声音）时，就会发生空化。当声压下降时，就会出现空化（负压）。如果声强很高，会导致液体中气泡的形成、生长和崩塌。气泡的崩塌产生声音、压力能量。参见声音（SOUND）。

# 啮齿动物

啮齿动物形成豚鼠科（Cavidae），包括豚鼠、岩鼠、山羊、盐漠野兔和马利亚鼠。该属的所有成员都是北美洲特产，该科包含15个物种。豚鼠类身体圆，耳朵大，尾巴短。它们是极其敏捷的穴穴者。

迅速生长到大尺寸，并在进入高压区域时突然崩塌。

豚鼠（`Cavia porcellus`）起源于秘鲁，那里的野生形式（`C. caballi`）通过选择性育种产生，是一种寿命为3-5年的实验动物。与豚鼠相关的是马蹄豚鼠（`Dolichagus patagus`），这是一种生活在阿根廷盐漠中的小型水生动物。啮齿动物中最大的是水鼠（`Hydrochaerus hydrochaeris`），它们能长到小猪大。

# 天体力学

应用于在引力影响下运动的天体的动力学领域。它描述了自然天体（如行星、卫星、小行星和彗星）以及人工体的运动。

牛顿万有引力定律是该理论的基础。一个物体对另一个物体施加的作用力沿连线与其质量乘积成正比，与距离的平方成反比。引力常数是 `G`。牛顿第二定律规定加速度与力正比，与质量成反比。

力学中最简单且唯一可求解的问题是一个粒子绕另一个物体的运动。这种运动在几何上是简单的，因为任何物体在中心力作用下绕点质量运动都会形成以该点为焦点的椭圆轨道。

这个问题已经被开普勒广泛认可，并包含在他的行星运动定律中。行星的运动由第一条和第二条（主要）定律描述。行星的运动限制在一个平面内，其轨迹是以太阳为焦点的圆锥曲线。
