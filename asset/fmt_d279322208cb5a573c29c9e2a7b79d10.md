## 均方根

一组数算术平均值的平方根称为它们的均方根。如果这些数字为 $x_1, x_2, ..., x_n$，则均方根等于：

$$\sqrt{\frac{x_1^2 + x_2^2 + ... + x_n^2}{n}}$$

它是幅值的平均值，不受数值正负号的影响。在均方根的应用中，最重要的是算术平均值的标准差。如果 $X$ 是

$$\frac{x_1 + x_2 + ... + x_n}{n}$$

那么标准差就是偏离平均值的均方根。参见：统计学。

$$\sqrt{\frac{(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + ... + (x_n - \bar{x})^2}{n}}$$

因此，标准差是离散值的均方根。

罗斯卡（Rouscara）是首次发现的引起鸡肿瘤的病毒（virus）。它由P. F. Rous于1911年发现，他因这一发现于1967年获得诺贝尔奖。它是一种核糖酸病毒，属于引起肿瘤的鸟类病毒。该物种以对热、氧气、臭氧和其他分解剂的抗性而闻名。其硫化物的机械性能相当于SBR（丁橡胶）。

工业上最早使用的合成橡胶之一是氯橡胶，它是氯丁-1.3-丁二烯的聚合物。氯橡胶具有卓越的耐候、耐晒、耐氧和耐磨性。它们在耐性、不渗透性以及耐热、耐油和耐酸方面表现良好。它们的机械性能使其适用于许多需要耐油、耐候、耐磨或耐电性或这些属性组合的场合，例如电缆、软管和皮带。

天然橡胶是异戊烯单元的碳烃聚合物。合成橡胶的发展使得某些橡胶在结构上与天然橡胶相似，但更通用的术语同时包含了天然橡胶和合成橡胶。橡胶（rubber）一词是指聚合物，定义为在室温下可以拉伸至至少原始长度两倍，并在恢复时不受损坏或永久变形的物质。

天然橡胶和合成橡胶要具有橡胶特性，必须满足三个条件：长链分子、允许流动和拉伸的分子柔活性。

天然橡胶和合成橡胶通常以乳胶的形式存在，乳胶是水介质中聚合物的胶体。天然橡胶以这种形式来自树；某些合成聚合物也分散在水中。

乳胶用于各种产品，如手套、避孕套和粘剂。

腈橡胶是丁二烯和丙烯的共聚物。腈橡胶可以与天然橡胶、聚丁二烯和各种橡胶混合，产生诸如增强强度、更好的溶剂抗性和提高耐候性等特性。

丁基橡胶是乙烯亚和己戊烯的共聚物。由于含有氟，它们是所有弹性体中化学性质最稳定的，在极端温度范围内也表现良好。

它们在航空、汽车和工业领域非常有用。

聚氨酯弹性体也因其属性的多样性和功能性而受到关注。它们可以用作粘剂、涂层和制品的零件。最大的用途是用于家具装饰和床上材料的泡沫。
