# csh 内置

`nice [-increment | +increment] [command]`

## Description

使用 `nice` 命令提高或降低命令的优先级。当你不带参数使用 `nice` 命令时，默认增加十 单位。

`iontl(1)` 命令是调度函数的通用接口。

如果你使用 C shell `csh(1)`，必须指定 `nice` 命令的完整路径；否则将调用 `csh` 内置版本的 `nice`。参见 Shell 内置。

# /usr/bin/nice

如果 `nice` 带参数执行命令，它使用默认的 `/usr/bin/sh` (`sh sh(1)`)。

# /usr/xpg4/bin/nice

如果 `nice` 带参数执行命令，它使用 `/usr/xpg4/bin/sh`，等同于 `/usr/bin/ksh`（参见 `ksh(1)`）。

# Shell 内置

`nice` 也是 `csh` 内置命令，其行为与命令版本不同。请参见 `csh(1)`。

## 选项

- `-increment | -n increment` 增量必须在 1-19 范围内；如果没有指定，假设增量为 10。大于 19 的增量等同于 19。

超级用户可以使用负增量如 `--10` 运行高于正常的命令。无权限用户指定的负增量将被忽略。

### 操作数

- `command` 要调用的命令名称。如果命令命名为任何特殊内置命令（参见 `shell_builtins(1)`），结果未定义。
- `argument` 调用命令时作为参数提供的任何字符串。

不错

## 示例

以下示例将命令的优先级降低4 个单位（默认值）。

```
castle@ /usr/bin/nice command
```

以下示例通过将 `nice` 值增加 10 个单位来降低命令的优先级。

```
castle@ /usr/bin/nice +10 command
```

注意 — 对于正数，加号是可选的。对于负数，必须使用减号。

以下示例通过将 `nice` 值减少 10 个单位来提高命令的优先级。第一个减号是选项符号，第二个减号表示负数。

```
# /usr/bin/nice -10 command
```

## 环境变量

请参阅 `environ(5)` 以了解影响 `nice` 执行的以下环境变量的描述：`LC_TYPE`、`LC_MESSAGES`、`PATH` 和 `NLPATH`。

## 退出状态

如果调用了命令，`nice` 的退出状态为该命令的退出状态；否则，`nice` 以以下值之一退出。

- 1-125 发生错误。
- 1-126 找到了命令但无法调用。
- 1-127 找不到命令。
