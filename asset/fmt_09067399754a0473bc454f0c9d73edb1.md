## 8.28.1. ncurses 的安装

为编译准备`ncurses`：

```
./configure --prefix=/usr \
    --mandir=/usr/share/man \
    --with-shared \
    --without-debug \
    --without-normal \
    --with-cxx-shared \
    --enable-pc-files \
    --enable-wide \
    --with-pkgconfig-libdir=/usr/lib/pkgconfig
```

新配置选项的含义：

- `--with-shared`

编译并安装共享 C 库。

- `--without-normal`

阻止编译和安装静态 C 库。

- `--without-debug`

阻止编译和安装调试库。

- `--with-cxx-shared`

编译并安装共享 C++ 绑定。同时也阻止编译和安装静态 C 绑定。

- `--enable-pc-files`

为`pkg-config`生成并安装`.pc`文件。

- `--enable-wide`

导致构建宽字符库（例如`libncurses.so.6.4`）而不是普通库（例如`libcurses.so.6.4`）。

编译包：

```
make
```
