# ipcp-accept-remote

`192.168.10.10:192.168.10.11`

此文件中的内容仅特定于此连接。您可以设置其他连接，甚至可以激活它们（只要您有足够的数据端口）。全局配置项显示在 `/etc/ppp/options` 文件中：

```
asyncmap 0

modem

crtscts
```

`/etc/ppp/options` 文件中的大多数选项现在（或应该）已经很熟悉了。最后一个文件是 `/etc/ppp/chatscripts/isp` 文件。这是用于连接到您的互联网服务提供商的聊天脚本：

```
ABORT BUSY

ABORT "NO CARRIER"

ABORT VOICE

ABORT "NO DIALTONE"

ABORT "NO ANSWER"

"" ATZ

OK ATM0

OK ATDT7756575

#OK ATDT2651155

#OK ATDT2271155

#ATDT2130400

CONNECT ''

ogin: \d\davidb

ssword: \qmypassword

"" \d\c
```
