
`salt`是从`[a-zA-Z0-9./]`集合中选取的两字符字符串。该字符串用于以4,096种不同方式之一影响加密算法。`salt`值存储在加密密码的前两个字符中。例如，`XoAlxlaie wp8s`中的`Xo`是`umbrella`的加密密码，使用的`salt`值为`Xo`。没有已知方法能从加密版本中恢复原始密码，因为加密算法是单向的。然而，如果已知加密密码，则可以编写程序利用两字符的`salt`值，用该`salt`加密大量字典单词。如果密码恰好是字典中的单词（如本例），它将被加`salt`并找到匹配项。换句话说，当您知道`bob`密码的`salt`值为`Xo`时，可以使用该`salt`编写程序执行以下操作：

```
加密密码 = crypt(每个单词, "Xo")
```

当该程序选中单词"`umbrella`"时，加密密码将与`/etc/passwd`中存储的相同。糟糕，`bob`的密码刚被破解！现在程序知道创建密码使用的是哪个单词。这是破解软件工作原理的简化解释。但请记住，现在的破解软件先进得多，随着计算机硬件越来越强大，破解密码变得更容易、更快。

## 安装 Crack 以破解您自己的密码

要破解系统的密码，您需要一个密码破解程序。`Crack`就是一个这种广泛使用的免费软件包。您可以从许多保存用户贡献软件的Red Hat镜像站点下载`Crack`的RPM包版本。其中一个站点是`http://ftp.digital.com/pub/linux/redhat/contrib/`。

您必须进入与您系统架构对应的目录，例如`i386`（x86或Intel）、`SPARC`（Sun Microsystems）、`alpha`（Digital Alpha）等，并下载`crack-X.xx-x-(architecture).rpm`，其中`X.xx-x`是版本号，`(architecture)`是您系统的架构。例如，对于基于x86或Intel的系统，下载`crack-4.1f-1.i386.rpm`。版本号可能会有所不同，因为较新的版本会随着时间的推移被上传。

上传RPM包后，按如下方式安装它：

```
rpm -ivh crack_package_name.rpm
```

然后您可以通过运行以下命令来查看安装了哪些文件：

```
rpm -qi crack_package_name
```

通常，`Crack`安装在`/root/crack-X.xx/`目录中。

### 运行 Crack

要从安装目录运行`Crack`程序，请使用以下命令：

```
crack /etc/passwd
```

> **提示**
>
> 如果您使用影子密码并想运行`Crack`，则需要使用一个名为`shadowmgr`的支持脚本（位于`Scripts`目录中）来合并`/etc/passwd`和`/etc/shadow`文件。合并后的输出通常发送到STDOUT，因此您必须将其重定向到一个文件，然后将该文件作为输入密码文件供`Crack`使用。

`Crack`将开始破解您的密码。如果您的密码文件中有大量用户帐户，`Crack`可能需要很长时间才能完成工作。这就是为什么`Crack`会自动在后台运行。您还可以为`Crack`指定一些命令行选项来控制其部分行为。不带任何参数运行`Crack`可查看命令行选项列表。

密码并不是系统中唯一的弱点。要发现许多其他潜在的安全漏洞，您需要`COPS`。

## 使用 COPS

`COPS`是一组工具，旨在定位系统中潜在的安全漏洞。除其他功能外，这些工具专注于检测可能源于文件/目录/设备权限、密码、`/etc/rc.d`目录中的`init`文件、`cron`配置和匿名`FTP`设置的潜在安全问题。一般来说，`COPS`的目的是检测潜在的安全问题并警告您。它不会修复检测到的任何问题。

### 安装 COPS

我还没有见过`COPS`的RPM打包版本。您可以从以下`FTP`站点获取通用的`COPS`发行版：`ftp://ftp.eart.org/pub/tools/cops/`。

下载最新的`COPS`发行版，并将文件解压缩并提取到系统上的适当目录中。

`COPS`发行版包含同一软件的两个版本。一个版本主要用`C`编写，另一个主要用`Perl`编写。只要您有`Perl`或`C`编译器（这两者在Red Hat Linux中几乎都是标准配置），就可以运行其中一个版本。本讨论解释了如何使用`C`版本。如果您有兴趣运行该软件的`Perl`版本，请阅读随附的`Perl`版本`README`文件。您还将在安装目录的`perl`子目录中找到该软件的`Perl`版本。

要配置`COPS`的`C`版本，请执行以下操作：

1. 从安装目录运行以下脚本：

   ```
   . ./reconfig
   ```

   这会调整某些脚本中二进制文件（如`awk`）的几个路径以匹配您的系统。

2. 修改`docs`目录中的`Makefile`，从`ROFFLAGS=-ms`行中移除`-ms`。如果您已为`troff`安装了`-ms`包，则无需执行此操作。然后，从安装目录运行以下命令：

   ```
   ./make all
   ```

3. 编辑`cops` shell脚本并修改以下行：

   ```
   SECURE=/usr/foobar
   SECURE_USERS="foo@bar.edu"
   ```

4. 更改第一行，使该目录成为您安装路径的全限定目录名。例如，如果您将`COPS`安装在`/usr/local/security/cops`目录中，则将`SECURE`设置为该目录。将第二行设置为接收`COPS`输出的电子邮件地址。如果您不想以`e-mail`格式接收报告，请修改`MAIL=NO`；否则，将该行更改为`MAIL=YES`以通过电子邮件接收报告。
