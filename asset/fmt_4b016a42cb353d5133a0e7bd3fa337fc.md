使用 IP 地址而非人类可读的名称来路由互联网数据。每当我们想要通过名称访问域名时，我们首先需要获取其 IP 地址。为了检索（或解析）人类可读地址的 IP 地址，我们需要询问 DNS 服务器。让我们逐步解析 "www.example.com" 的 IPv4 地址的过程。
