
`urllib.robotparser` 模块（Python 2 中为 `robotparser`）用于获取和解析用于指示网络爬虫的 `robots.txt` 文件内容。请参考在线文档获取更多用法信息。

`urllib` 包的高级用户可以自定义其行为。

## xmlrpc

### 将 URL 解析为组件的示例

```python
url = "http://www.somehost.com/cgi-bin/view.py?" + form_data

r = urlparse(url)

print(r.scheme) # 'http'

print(r.netloc)  # 'www.somehost.com'

print(r.path)    # '/cgi-bin/view.py'

print(r.params)   # ''

print(r.query)    # 'uid=12345&name=Dave&email=dave%40dabeaz.com'

print(r.fragment) # ''
```
