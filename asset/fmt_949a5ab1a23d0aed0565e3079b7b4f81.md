# 面向对象

一种软件开发方法，允许程序员使用标准的重用模块（组件），而不是要求开发者为每段代码编写自定义程序。使用标准组件可以缩短开发时间（这些组件的编写和测试由其他程序员完成），并确保使用相同组件的程序具有标准的界面。来自 I-gloss `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# obscurity (隐蔽性)

关于“通过隐蔽性实现安全”的哲学辩论，人们希望通过隐藏而非防御来防止黑客。争议性：这是一个有争议的话题。非安全领域人士会声称，常见的安全措施并非必要，因为黑客不太可能发现隐蔽的漏洞。安全专业人士认为这令人不安，因为他们与黑客社区接触的经验表明，隐蔽性会变得暴露。例如，缓冲区溢出漏洞是隐蔽且难以利用的，但一旦黑客运行了自动利用脚本或蠕虫，一个隐蔽漏洞就会广为人知。源自《黑客词典》(Hacking–Lexicon)

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

# ocaml

带有基于类的对象系统的 ML 语言实现。Caml 是 ML 语言的一种实现，在 Caml 方言的基础上扩展了基于类的对象和一种类似于 Standard ML 风格的强大系统。Objective 编译为两个编译器：一个可以快速生成代码且内存需求中等，并可以扩展到任何 32 或 64 位的 Unix 平台；生成程序的性能对于字节码实现来说很好：速度是 Caml 0.7 的两倍。此编译器既可以作为一个独立的、面向后端的编译器产生独立程序，也可以作为一个交互式的、基于令牌的系统。另一个编译器为许多处理器生成高性能原生代码。性能卓越，保留了字节码编译器的中等内存需求。尽管在所有架构上并不可用。源自 Debian 3.0r0 APT

# ocamelweb

用于 Caml 的文学编程工具，根据 Knuth 定义的文学编程，将程序代码和文档合并成一个文档，并从中提取代码和文档。ocamelweb 的方法是将文档作为特殊内容包含在程序代码中。ocamelweb 从带文档的程序代码中提取出 LaTeX 文档，但编译源文件需要特殊的预处理。见 `http://www.irfi/~filarrat/ocamelweb/index.en.html`。源自 Debian 3.0 OPT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
