
## 使用 cpio 工具进行备份与恢复

`cpio` 是一种用于归档和备份文件的标准工具。你可以使用管道将其与其他命令结合，以执行各种操作，例如提取、列出或复制文件。

### 提取归档文件

要从 `cpio` 归档中提取文件，请使用以下命令：

```bash
cat maggie.cpio | (cd /tmp ; cpio -i)
```

### 列出归档内容

你可以使用以下命令列出 `cpio` 归档中的文件：

```bash
cat maggie.cpio | cpio -it
```

### 通过模式（Copy-Pass）复制文件

`cpio` 还具有将文件从一个目录复制到另一个目录的能力。这种能力被称为通过模式（copy-pass），它结合了输入和输出复制的功能，但不会创建 `cpio` 归档。以下命令将 `/home/maggie` 中的文件复制到 `/tmp`：

```bash
find /home/maggie -print | cpio -p /tmp
```

### 操作模式概述

`cpio` 的操作模式有输入、输出和通过模式。它们允许你创建、删除、列出或修改 `cpio` 归档。归档可以存储到文件、管道或设备（如磁带）。请参阅 `cpio` 手页（man page）获取更多详情。

## 使用 TAR 工具进行低容量备份

如果你有一个简单的网络——例如家庭办公室或小微企业——那么你可能不需要专门的备份系统。在我的家庭网络中，我并没有足够的兆字节级文字处理文件、一些电子表格、几个 HTML 文件以及我的 Linux 配置文件。由于我将所有数据存储在我的 Linux 服务器上，我的 Microsoft Windows 工作站除了配置文件和应用程序软件外，在它们上没有存储任何数据。我在 Linux 上保留了它们一些配置文件和应用程序软件的备份，使用 `tar` 应用程序备份关键目录，使用 `gzip` 应用程序压缩 `tar` 文件，然后将生成的文件备份到软盘和我的 ISP 账户。这个系统既不优雅也不复杂，但它是——最重要的是——有效且廉价的。

# 第四部分：运行真实业务

### 创建全量备份

下面的示例说明了我用于制作个人备份的简单命令：

```bash
/bin/tar cvf - /etc/home > /tmp/backup.tar
# 后续步骤：
# 1. 复制到软盘
# 2. 复制到 ISP
```

Linux `tar` 命令具有在不将数据显式管道到工具的情况下压缩数据的选项；`-z` 或 `--gzip` 参数调用 `gzip` 工具；`--gunzip` 调用 `gzip`；`-Z` 或 `--compress` 调用 `compress` 命令，而 `--uncompress` 则要求调用 `uncompress` 选项。

### 创建增量备份

这种方式进行备份是简单且有效的。为了节省时间以及有限的带宽，我还进行增量备份。在像写这本书这样的关键时期，我会在白天频繁地向磁盘进行全量备份，然后在一天结束时向我的 ISP 账户进行增量备份。以下是我用于增量备份的命令，使用了较新的 `--N` 日期参数：

```bash
tar -czvf /tmp/incr.tgz -N 1 /etc/home
```
