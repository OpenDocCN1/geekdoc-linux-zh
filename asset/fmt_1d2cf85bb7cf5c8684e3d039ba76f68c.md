目标通常是你想要创建的文件，而依赖项是目标所依赖的文件。命令是从依赖项生成目标的 Shell 命令。

## Makefiles

`Makefile` 是一个包含项目规则的文本文件。它通常命名为 `Makefile` 或 `makefile`。`make` 工具默认查找这些名称。然而，你可以使用 `-f` 选项指定不同的 Makefile 名称。

## Target Lines

`Target lines`（目标行）告诉 `make` 什么是可以构建的。规则由一个目标、一个冒号以及依赖列表组成。目标和依赖项之后是一个或多个用于构建目标的命令。每条命令都必须缩进。

依赖列表由比当前目标旧的目标组成。换句话，目标必须比它的任何依赖项新。如果任何依赖目标比当前目标新，或者依赖目标不存在，则必须构建依赖目标。如果依赖列表为空，则始终构建目标。

文件名模式匹配可用于自动生成目标的依赖列表。可以使用 Shell 元字符星号（`*`）、问号（`?`）和括号（`[]`）。例如，如果 `parse.cc`、`main.cc` 和 `io.cc` 是包含 Makefile 的目录中所有以 `.cc` 结尾的文件，那么以下两个目标行将是相同的：

```
main: parse.cc main.cc io.cc # 手动列出所有依赖文件

main: *.cc # 使用 Shell 元字符生成列表
```

通常，列表包含了构建目标使用的依赖项。例如，依赖列表可能由构成可执行文件的对象文件组成：

```
program: part.o component.o module.o
```

或者对象文件依赖的头文件和源代码：

```
module.o: module.cc module.hh part.hh
```
