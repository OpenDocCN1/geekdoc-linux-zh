
MySQL 正在不断开发，从发行版的成熟程度就可以看出。稳定发行版因其稳定性和经过测试的功能而受到推荐。前沿发行版用于测试正在数据库中完善的新功能。除非你是之前的用户，否则过时的版本没有必要。保持最新的稳定发行版（即 `3.22`）将提供应用程序所需的所有功能和稳定性。

你很快就会觉得自己像个数据库魔法师。

# 常见问题

**Q**: 我如何在我的机器上运行多个 MySQL 服务器？

**A**: 这可以通过两种方式实现：

使用源码发行版，你可以传递特定的标志来配置数据库指向不同的位置并使用不同的端口：

```
shell$ ./configure --with-tcp-port=port_number \
--with-unix-socket=file_name \
--prefix=/usr/local/mysql-3.22.9
```

如果你没有源码发行版，也可以对 `mysqld` 使用运行时标志：

```
shell$ /my/path/bin/safe_mysqld --socket=file_name \
port=port_number
```

你不你不应该让两个不同的守护进程修改同一个数据库路径。

可以通过 `-datadir` 指定不同的路径。

**Q**: 我如何复制我的数据库？

**A**: 目前，MySQL 还没有自动完成此操作的功能。一个简单的变通方法是每天对数据库进行转储并将其导入到另一个数据库中。此操作的频率取决于数据的新鲜度。

**Q**: 我如何备份我的数据库？

**A**: `mysqldump` 命令允许你保存数据库中的所有表。

```
shell mysqldump --tab=/save/path --opt --full
```

你也可以关闭服务器并 `tar` 压缩数据库目录。要将表重新加载回数据库，你可以将文件 `untar` 到数据库目录或恢复转储文件。

**Q**: 如果我已经安装了 MySQL，我该如何升级到最新版本？

**A**: 你可以停止当前的数据库并将目录重命名为其他名称。然后像以前一样安装发行发行版。之后，将你的数据库目录移回新目录并启动你的数据库。

**Q**: 如果我忘记了密码怎么办？

**A**: 你必须首先关闭服务器。然后使用 `--skip-grant-tables` 选项启动服务器，以*不*使用权限表。重新连接到数据库，使用 `GRANT` 重置密码，或直接使用 SQL 命令在用户表中重置密码。

**Q**: 我如何启用事务？

**A**: 与更大规模的数据库不同，MySQL 还没有启用事务的能力。这将在后续版本中包含。

## 简介

Progress 数据库嵌入在如今数以千计流行的中型软件包中（例如，quad Inc. 的 MFG/Pro、Symix、FiServ 的 Unifi 和 NxTrend 的 Trend）。事实上，Progress 是嵌入式数据库市场的领先产品（详情请参见 http://www.progress.com/services/pressm/releases/pr_gartner_04199.htm），并且嵌入式 ASP（软件专业人员协会）市场的主要参与者。基于 Progress 关系数据库管理系统（RDBMS）的软件包被 60% 的财富500强公司使用，每年为 Progress Partners 带来超过 25 亿美元的收入。然而，Progress Software 公司 (PSC) 并没有一家年销售额 3 亿美元、在 100 个国家拥有 80,000 个安装量的公司应有的即时知名度。

这种现象归因于 PSC 主要通过分销商渠道进行销售的“隐形营销”策略。Progress 的销售计划一直围绕向软件开发人员销售，而不是直接销售给大型 IT 组织。这在他们 15 年的历史中被证明是极其成功的，因为他们现在有一系列基于数据库和 4GL 开发的 4000 多个应用程序。然而，由于 PSC 本身必须避免与其自己的所有者竞争产生冲突，Progress 合作伙伴的名称比 Progress 本身更具知名度。

无论营销策略如何，Progress 作为一个平台提供了很多东西。数据库具有大型 OLTP（在线事务处理）解决方案的所有功能，但不需要全职数据库管理员 (DBA) 即可运行。Progress 乐于从具有 32MB 内存的独立 PC 扩展到规模最大的 IBM、HP、Sun 和 Compaq/DEC 多处理器服务器。4GL 是一门完整的语言，在构建全方位应用程序时不需要任何 3GL 代码。超过 90% 的应用程序仅包含 4GL 代码，并且通过运行时应用程序执行环境，可以在包括 Linux 在内的主要 UNIX 平台之间完全可迁移。

在撰写本文时的时间点（2000 年第一季度），PSC 已发布了适用于 Linux 的 Progress `8.3` 版本。`8.3` 版本是大多数已安装 Progress 软件包使用的成熟部署平台。当版本 `9.1` 在 2000 年第一季度后期发布时，最新的 Progress 版本 `9` 将在 Linux 上可用。v8.3 的发布虽然不是，但通过使用 iBCS 软件包和 Progress for SCO Open 在 Linux 上运行。各方已通过这种方式在 Linux 上成功运行了 `6.2` 到 `8.2` 版本。然而，这些版本超出了本书的范围，可以通过互联网资源研究，例如 http://market-man.com/pl/Progress-Linux-FAQ.html 上的以及 Progress 邮件组 (PEG—peg.com)。本章将重点关注 V8.3 版本及其安装、配置和管理。

## 安装

安装是一个相当直接的三步过程。首先，从介质安装可执行文件，然后更改任何内核参数，然后设置环境。安装完成后，你就可以准备创建你的第一个数据库了。

## 从介质安装

从介质安装是一个简单的任务，即从 Progress 提供的光盘或磁带中拷贝可执行文件。每个平台的安装脚本工作方式略有不同。Linux 与大多数 UNIX 平台一样拥有磁带版本，每个磁带部分包含一个独立的产品。磁带安装脚本是 cpio 提取文件和 dd 跳过未使用节点的简单组合。CD 版本略有不同，因为文件就在那里，不需要提取。在这种情况下，Progress 使用自己的存档方案将每个产品合并到 CD 上的单个存档文件中。在我们开始实际安装过程之前，我们需要确保我们。

## 前提条件

安装 Progress 介质是一个在 CD 上运行脚本的简单过程。在开始之前，请确保你有大约 100MB 的空闲空间。取决于你购买的产品，可能需要更少的磁盘。还要确保拥有随产品附带的“Progress 许可附录”。这被俗称为“绿页”，因为打印它的纸是绿色。

假设有一台已经安装了 Linux 的运行良好的计算机，并且具有工作良好的光驱驱动器。如果你将在客户端/服务器模式下访问数据库，那么你需要安装 TCP/IP。哑终端不需要这个。Progress 正式在 RedHat Linux `6.1` 版本上进行了测试，但应该可以在大多数具有 `2.2.13` 内核的发行版上运行。这里描述的具体过程是在 Mandrake 版本的 `6.1` 上测试的。

## 安装

通过将 CD 放入驱动器并通过 Linux 挂载它开始过程。具体的命令在你的自定义发行版中可能有所不同，但通常形式如下：

```
mount /dev/cdrom /mnt/cdrom
```

请确保将当前目录设置为 CD 盘以外的地方。如果你忘记了，安装脚本将提醒你无法直接从 CD 运行。然后运行 proinstall 安装工具：

```
/mnt/cdrom/proinst
```
