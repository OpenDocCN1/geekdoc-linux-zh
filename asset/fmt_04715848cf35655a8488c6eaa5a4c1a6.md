### FORMAT

```
        statements

    ;;

    ;;

case "$color" in
    blue )
        statement
        statement
    ;;
    red | orange )
        statements
    ;;
    *)
        statements
    ;;
```


## Looping Errors.

循环错误发生在 `for`、`foreach`、`while` 或 `until` 循环的语法不正确时，最常见的是用于终止循环块的关键字被遗漏，例如 `do`、`done` 或 `end`。

### FORMAT

# Bourne shell：

```
while [ $n -lt 10 ]    <-- Missing do keyword
echo $n
n= `expr $n + 1`
done

while [ $n -lt 10 ]
do
echo $n
n= `expr $n + 1`

                        <-- Missing done keyword
```

## 操作符错误。

各 shell 在处理字符串和数字时使用不同的操作符。Bourne shell 使用 `test` 命令（参见 `man test`）及其操作符来比较数字和字符串。虽然这些操作符在 Korn 和 Bash shell 中也能工作，但通常不使用。相反，Korn 和 Bash shell 提供了一套类似 C 的操作符来使用 `let` 命令 `(( ))` 处理算术运算，以及用于新 `test` 命令 `[[ ]]` 的字符串操作符。但 Korn shell 不使用双 `==` 号表示相等，而 Bash shell 使用。

C 和 TC shell 也提供了一套类似 C 的操作符来比较数字和字符串，并且对数字和字符串都使用 `==`。令人困惑？如果你正在移植 shell 脚本，最好检查一下每个 shell 的操作符。本书中为每个 shell 提供了表格。（参见附录 B。）以下示例说明了每个 shell 的一些操作符。

### FORMAT

### Bourne shell:

```
Numeric testing
if [ $n -lt 10 ]
if [ $n -gt 5y ]
if [ $n -eq 6 ]
if [ $n -ne 6 ]

String testing
if [ "$name" = "John" ]
if [ "$name" != "John" ]
```

### Korn shell:

```
Numeric testing
if (( n < 10 ))
if (( n > y ))
if (( n == 6 ))
if (( n != 6 ))

String testing
if [[ $name = "John" ]]
if [[ $name != "John" ]]
```

### Bash shell:

```
Numeric testing
if (( n < 10 ))
if (( n > y ))
if (( n == 6 ))
if (( n != 6 ))

String testing
if [[ $n == "John" ]]
if [[ $n != "John" ]]
```

## FORMAT (CONTINUED)

C and TC shells:

```
Numeric testing
if ( $n < 10 )
if ( $n > $y )
if ( n == 6 ))
if ( n != 6 )

String testing
if ( "$name" == "John" )
if ( "$name" != "John" )
```
