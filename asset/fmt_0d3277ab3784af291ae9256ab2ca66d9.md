### 01 安装 MRTG

大多数Linux发行版都有现成的MRTG软件包可供安装使用。MRTG是一个Perl脚本，因此如果你想修改某些内容，可以轻松地对其进行更改。

如果你打算以Apache用户的身份运行MRTG（这是推荐的），你需要首先以root身份执行以下操作，假设Apache进程的所有者是`www-data`用户（根据你的Linux系统调整命令）：

```bash
$ chown www-data:root /var/lock/mrtg
```

![](img/c7d3278283754436651c50a2e9c72912_30_2.png)

### 02 关于 SNMP

SNMP是一种众所周知的TCP/IP协议，适用于大多数“智能”设备，包括Linux和其他UNIX机器、路由器、网络交换机、Windows机器以及许多其他设备。

它提供关于网络接口状态、传入和传出流量、丢弃的数据报和错误消息的统计数据，并允许客户端轻松且远程地访问这些统计数据。

![](img/c7d3278283754436651c50a2e9c72912_30_3.png)

### 03 有用的 SNMP 命令

SNMP附带许多命令，包括`snmpbulkget`、`snmpd`、`snmptrap`、`snmpbulkwalk`、`snmpget`、`snmpstatus`和`snmpwalk`。其中最有用的是`snmpwalk`命令，它使用SNMP GETNEXT请求获取值子树。

如果团体字符串名称错误或者设备当前不支持SNMP，`snmpwalk`命令的输出将类似于以下内容：

```bash
$ snmpwalk -v 1 -c LUD cwfi
Timeout: No Response from cwfi
```

### 04 配置 MRTG

配置MRTG可能是整个过程中最困难的部分 - 特别是当你处理非标准网络设备时，因为你可能会难以找到要查询的正确对象标识符。Cisco路由器是很流行的设备，因此在Cisco网络上设置SNMP是一个众所周知的过程，但找到正确的对象标识符总是很棘手。

![](img/c7d3278283754436651c50a2e9c72912_30_4.png)

### 05 Cisco IOS

在Cisco 877W ADSL路由器上要做的第一件事是开启SNMP并创建一个SNMP团体字符串，这将帮助你获取所需信息。Cisco IOS有很多晦涩的命令，所以请仔细输入。

RO（只读）团体字符串（`LUD`）仅允许Get请求，而RW（读写）团体字符串 - 这里不需要 - 允许Get和Set请求。

以下命令会产生许多行输出，用于验证名为`cisco`的路由器上的SNMP设置是否正常工作：

```bash
$ snmpwalk -v 1 -c LUD cisco
```

![](img/c7d3278283754436651c50a2e9c72912_30_5.png)

### 06 配置 Apache

你应该设置Apache，以便你不仅可以本地看到MRTG的静态HTML输出，还可以从你的网络或互联网上看到。你可以通过使用子域名来实现这一点。这里将使用`mrtg.mtsoukaloos.eu`作为子域名 - 你的可能会不同 - 这需要添加一个新的DNS条目。配置Apache后，别忘了启用新站点并让Apache使用新配置：

```bash
#### a2ensite mrtg.mtsoukaloos.eu
#### /etc/init.d/apache2 reload
```

![](img/c7d3278283754436651c50a2e9c72912_30_6.png)

### 07 MRTG 文件和目录

你应该仔细考虑的一件事是，MRTG存放文件的目录必须具有必要的UNIX权限，以便运行MRTG Cron任务的用户能够读写。

MRTG存放文件的目录结构非常简单：它只有一个目录，里面有对应于受支持接口和设备的众多文件。

### 08 cfgmaker 工具

`cfgmaker` MRTG工具用于轻松创建配置文件。它可能会添加一些你稍后需要清理的无用数据，但它所创建的是一个很好的起点。通常你按如下方式运行它：

```bash
#### cfgmaker --global "WorkDir=/srv/www/mrtg.mtsoukalos.eu/public_html" LUD:2.86.5.103 > mrtg.cfg
```

此命令在当前工作目录中创建`mrtg.cfg`，使用`/srv/www/mrtg.mtsoukalos.eu/public_html`目录来写入输出，并使用"LUD"团体字符串查询IP地址为`2.86.5.103`的机器。

由`cfgmaker`自动生成的`mrtg.cfg`文件非常繁杂，因此你将不得不花些时间清理它，只保留真正让你感兴趣的接口。

### 09 indexmaker 工具

在使用`cfgmaker`生成MRTG配置文件后，你应该创建一个索引HTML页面，以便你可以访问MRTG的输出。这项任务可以使用随mrtg软件包提供的`indexmaker`工具来完成，如下所示：

```bash
$ indexmaker mrtg.cfg > index.html
```

现在，你可以将浏览器指向Apache中定义的正确URL或本地文件（取决于你把MRTG的`index.html`文件放在哪里），以查看MRTG的信息。由于图像文件尚未创建，因此输出将看起来不太美观。
