# gcore — 获取运行进程的 Core 映像

## 语法

`/usr/bin/gcore [-o filename] process-id ...`

## 描述

`gcore` 在当前工作目录下为每个指定的进程创建一个 core 映像。默认情况下，进程的 core 映像文件名为 `core.process-id`。

## 选项

`-o filename` 用 `filename` 代替 `core` 作为 core 映像文件名的第一部分。

### 操作数

`process-id` 进程 ID。

## 示例

下面的示例为进程 ID 450 的进程创建一个 core 映像。

```
castle% gcore 450

gcore: core.450 dumped

castle% ls -l core*

-rw-rw-rw- 1 winsor staff 66216 Jan 16 14:16 core.450

castle% file core.450

core.450: ELF 32-bit MSB core file SPARC Version 1, from 'cat'

castle%
```

下面的示例尝试为不存在的进程 ID 461 创建 core 映像。请注意，`gcore` 创建了一个名为 `core.o` 的输出文件，但它是一个空文件。

```
castle% gcore 461

castle% ls -l core*

-rw-rw-rw- 1 winsor staff 0 Jan 14 15:50 core.o

castle%
```

## 退出状态

```
0
```

非零    发生失败时，例如不存在的进程 ID。

## 文件

```
core.process-id
```

Core 映像。

| --- | --- |
| 可用性 | SUNwtoo (32-bit)<br>SUNwtoox (64-bit) |

## 参见

`kill(1)`, `core(4)`, `proc(4)`, `attributes(5)`

# gencat — 生成格式化消息目录

## 语法

`/usr/bin/gencat catfile msgfile...`

## 描述

使用 `gencat` 命令将消息文本源文件 `msgfile` 合并到格式化的消息数据库 `catfile` 中。如果数据库 `catfile` 不存在，则会创建它。如果 `catfile` 已经存在，其消息将包含在新的 `catfile` 中。如果设置了且消息编号冲突，则使用当前包含在 `catfile` 中的新消息文本定义新文本。你输入到 `gencat` 的消息文本源文件（或文件集）可以是设置了消息编号的，也可以仅是消息编号，在这种情况下假设使用默认消息集 `NL_SETD`（参见 `nl_types(5)`）。

## 消息文本源格式

消息文本源行的格式描述如下。

> 注意 — 消息文本源行的字段由单个 ASCII 空格或 Tab 制符分隔。任何其他 ASCII 空格或 Tab 制符都被视为后续字段的一部分。

`$set n comment`
指定一个集标识符，其中 `n` 指定直到下一个 `$set,$delset,$end-of-file` 之前的消息集标识符。`n` 必须是 (1–NL_SETMAX) 范围内的数字。单个源文件内的集标识符不需要连续。将集标识符后的任何字符串 true视为注释。如果你在消息文本源文件中没有指定 `$set` 指令，则在默认消息集 `NL_SETD` 中查找所有消息。

`$delset n comment`
从现有目录中删除消息集 `n`。将集编号后的任何字符串视为注释。（注意：如果 `n` 不是有效集，则被忽略。）

`$ comment`
将以美元符号开头后跟 ASCII 空格或 Tab 制符的行视为注释。

`$m message-text`
表示消息标识符，范围 (1–NL_MSGMAX) 范围内的数字。将 `message-text` 存储在由最后一个 `$set` 指令定义的集标识符和标识符 `m` 的消息目录中。如果 `message-text` 为空且存在 ASCII 空格或 Tab 分隔符，则在消息目录中存储空字符串。如果消息源行有消息编号但既没有字段分隔符也没有消息文本，则从目录中删除该编号的现有消息（如果有）。消息标识符不需要连续。

`$quote c` 指定一个可选的引号字符 `c`，可用于包围 `message-text`，以便消息源行中的尾随空格或空（空值）消息是可见的。默认情况下或如果你指定了 `$quote` 指令，则不识别 `message-text` 的引号。消息源文件中的空行会被忽略。文本字符串可以包含下方的特殊字符和转义序列。

| 描述 | 符号 | 序列 |
| --- | --- | --- |
| 新行 | NL (LF) | \n |
| 水平制表符 | HT | \t |
| 垂直制表符 | VT | \v |
| 退格 | BS | \b |
| 回车 | CR | \r |
| 分页符 | FF | \f |
| 反斜线 | \ | \\ |
| 位进制 | ddd | \ddd |
