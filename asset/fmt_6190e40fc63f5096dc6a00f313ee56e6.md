我们在上一章中简要提到了 PostScript，将在下一章再次提到。PostScript 是一种页面描述语言，用于向类排字机设备描述打印页的内容。如果我们获取命令的输出并将其存储文件中（假设我们正在使用带有 Desktop 目录的图形桌面），那么输出文件的任何图标都应该出现在桌面上。

```
[me@linuxbox ~$ ps2pdf ~/Desktop/ls.ps ~/ls.pdf
```

对于 `groff` 的最后一个练习，我们将回到老朋友 `distros`。这次我们将使用 `tbl` 程序将 Linux 发行版格式化为列表。为了实现这一点，我们将使用之前的脚本向输入 `groff` 的文本流添加标记。首先，我们需要修改 `sed` 脚本以添加 `tbl` 所需的标记元素（称为 groff 请求）。使用文本编辑器，我们将 `distros.sed` 修改为如下：

```bash
# sed script to produce Linux distributions report

1 i

\TS\

center;\ncb s\ncb cb\n1 c.\

Linux Distributions Report\n
```

注意，为了脚本正常工作，必须注意到 `Name Version Released` 之间是用制表符而不是空格分隔的。我们将结果保存为 `distros-tbl.sed`，`tbl` 使用 `.ts` 和 `.te` 请求来开始和结束表格。`.ts` 请求定义全局属性并被框起来。剩余的行定义表格的布局。现在，如果我们使用新的 `sed` 脚本再次运行生成报告的管道，将得到：

```
[me@linuxbox ~]$ sort -k 1,1 -k 2 distros.txt | sed -f distros-tbl.sed | groff -T ascii
```
