
这些对象的行为模仿了 `threading` 模块中同名定义的同步原语。详情请参阅 `threading` 文档。

需要注意的是，在使用 `multiprocessing` 时，不需要像线程那样程度地担心锁、信号量或类似结构的低级同步。在某种，管道（pipes）上的 `send()` 和 `receive()` 操作以及队列上的 `put()` 和 `get()` 操作已经提供了同步。然而，共享值和锁可以在某些特殊设置中使用。这里是一个使用共享数组而不是管道将 Python 浮点数列表发送到另一个进程的的示例：

```python
import multiprocessing

class FloatChannel(object):
    def __init__(self, maxsize):
        self.buffer = multiprocessing.RawArray('d',maxsize)
        self.len = multiprocessing.Value('i')
        self.empty = multiprocessing.Semaphore(1)
        self.full = multiprocessing.Semaphore(0)
    def send(self, values):
        self.empty.acquire() # 只有当缓冲区为空时继续
        items = len(values)
        self.len.value = items # 设置缓冲区大小
        self.buffer[:items] = values # 将值拷贝到缓冲区
        self.full.release() # 信号缓冲区已满
    def recv(self):
        self.full.acquire() # 只有当缓冲区满时继续
        values = self.buffer[:self.len.value] # 拷贝值
        self.empty.release() # 信号缓冲区为空
```
