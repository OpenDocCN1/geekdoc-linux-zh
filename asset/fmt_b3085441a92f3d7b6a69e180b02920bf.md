在 `echo` 语句中使用数学表达式并将输出管道到 `bc`。另一种选项是使用带有命令替换的 *here* 文档（在此文档/here-document）。对于这个练习，我们将使用第二种选项来查看在此文档的使用。

要计算已用交换空间的百分比，我们将交换空间总量除以以 MB 为单位的已用交换空间，并乘以 100，如下语句所示：

```
($SW_USED / $SW_TOTAL) * 100
```

这看起来足够简单，但在 shell 脚本中如何获得浮点输出呢？这就是 `bc` 工具大显身场的地方。在 `bc` 的一个名为 `scale` 的选项中，`scale` 指明了我们在计算中想要右侧保留多少位小数。在我们的情况下，我们需要设置 `scale=4`。现在问题是，为什么要用四位？因为我们将除法结果乘以 100，得到的数据将只有两位小数，而最后两位将是零。让我们看看下面的示例以消除任何疑问：

```
PERCENT_USED=$(bc <<EOF
scale=4
($SW_USED / $SW_TOTAL) * 100
EOF
)
```

根据之前的值，此计算结果为已用交换空间的 7.100%，因为 `$SW_USED` 是 15MB 而 `$SW_TOTAL` 是 211MB。现在让我们更仔细地观察 `bc` 工具的使用。我们正在使用带有封闭文档的命令替换。文档具有以下格式：

```
command
<<LABEL
...
到命令的输入
...
LABEL
```

这是一种为通常需要输入的 `here` 命令提供输入的整洁方法，这就是为什么它被称为 *here* 文档，因为输入就在*这里*（here），而不是由用户在命令行输入。

在我们的情况下，我们在命令替换内部使用文档，它由 `$(commands)` 变量指定。结果被赋值给 `PERCENT_USED` 变量。空闲百分比的计算以相同的方式进行，只是除以 MB 为单位的空闲交换空间，如下：

```
PERCENT_FREE=$(bc <<EOF
scale=4
($SW_FREE / $SW_TOTAL) * 100
EOF
)
```

在我们的情况下，使用之前获取的数据，我们得到了 92.410% 的结果。通过这两个计算，我们拥有了标准输出所需的所有数据。我们将介绍 `bc` 命令，并在下一节处理 Solaris 交换空间监控时再次使用它。请查看列表 6.10 中的整个 shell 脚本，特别注意粗体字体。
