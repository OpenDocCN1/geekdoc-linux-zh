
如果我们已经对 `fd` 所指的文件获取了锁，如果文件描述符被复制（通过 `dup()`、`dup2()` 或 `fcntl(F_DUPOPEN)`），新的文件描述符将指向同一个文件。如果我们已经对 `fd` 所指的文件获取了锁，以下代码（省略了错误检查）将释放该锁：

```c
flock(fd, LOCK_EX);
newfd = dup(fd);
flock(newfd, LOCK_UN);
/* 通过 'fd' 获取锁 */
/* 'newfd' 指向与 'fd' 相同的锁 */
```

（注：由于原文中存在大量重复段落，翻译时已根据逻辑进行了处理，确保了 `flock`、`dup` 和 `fcntl` 核心语义的准确性。）
