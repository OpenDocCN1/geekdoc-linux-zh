
`print('Content-type: text/html\r')`    # HTTP 输出

`print('\r')`                             # 空行（强制性）

剩余的原始输出内容。例如：

```python
print('<TITLE>My CGI Script</TITLE>')
print('<Hello World: %s>')
print('You are %s (%s)' % (name, email))
```

HTTP 头部使用 Windows 换行符 `\r\n` 结束是标准做法。这就是为什么在示例中出现了 `\r`。如果你需要发送一个错误信号，请在头部中包含一个特殊的 `'Status:'`。例如：

```python
print('Status: 401 Forbidden!')    # HTTP 错误代码
print('Content-type: text/plain\r')     # 空行（强制性）
print('\r')
print('You\'re not worthy of accessing this page!')
```

如果你需要将客户端重定向到另一个页面，请创建如下输出：

```python
print('Status: 302 Moved')
print('Location: http://www.foo.com/orderconfirm.html')
print('\r')
```

### `cgi` 模块与 `FieldStorage`

`cgi` 模块中的大部分工作通过创建 `FieldStorage` 类的实例完成。

```python
FieldStorage([input, headers, outerboundary, environ, keep_blank_values, {strict_parsing:}])
```

通过读取和解析通过环境变量或标准输入的查询字符串来读取表单内容。`input` 是一个文件类对象，在 POST 请求中从从中读取表单数据。默认使用 `sys.stdin`。`headers` 和 `outerboundary` 在内部使用，不应由用户提供。`environ` 是一个包含 CGI 环境变量的字典。`keep_blank_values` 是一个布尔标志，用于控制是否保留空值。默认为 `False`。`strict_parsing` 是一个布尔标志，如果发生任何类型的解析问题，将抛出异常。默认为 `False`。

`FieldStorage` 实例的工作方式类似于字典。例如，`f = form[key]` 将提取给定参数键的条目。以这种方式提取的实例 `f` 要是另一个 `FieldStorage` 实例或 `MiniFieldStorage` 实例。`f` 上定义了以下属性：

| 属性 | 描述 |
| --- | --- |
| `f.name` | 指定的字段名 |
| `f.filename` | 上传时使用的客户端文件名 |
| `f.value` | 字符串格式 |
| `f.file` | 可以从中读取数据的文件对象 |
| `f.type` | 内容类型 |
| `f.type_options` | HTTP 请求中 `content-type` 行上指定的选项字典 |
| `f.disposition` | 'content-disposition' 字段；若未指定则为 `None` |
| `f.disposition_options` | 处置选项字典 |
| `f.headers` | 包含所有 HTTP 头部内容的类字典对象 |

可以使用以下方法从表单中提取值：

```python
form.getvalue(filename, [default])
```

返回名为 `filename` 的给定字段的值。如果一个字段被定义了两次，此函数将返回所有定义值的列表。如果提供了 `default`，则指定当字段不存在时返回的值。使用此方法的一个注意点是，如果请求中包含了两次相同的字段名，返回的值将是一个包含这两个值的列表。为了简化编程，你可以使用 `form.getfirst()`，它只返回第一个值。

```python
form.getfirst([field, [default]])
```

返回为名为 `filename` 的字段所定义的第一个值。如果提供了 `default`，则指定当字段不存在时返回的值。

```python
form.getlist(filename)
```

返回为 `filename` 定义的所有值的列表。它总是返回列表，即使只定义了一个值，若无值存在则返回空列表。

此外，`cgi` 模块定义了一个类 `MiniFieldStorage`，它只包含属性名和值。该类用于表示通过查询字符串传递的表单的单个字段，而 `FieldStorage` 用于包含多个字段。`MiniFieldStorage` 包含了的属性名和值。该类用于表示的。以这种方式提取的实例 `f` 要是另一个 `FieldStorage` 实例或 `MiniFieldStorage` 实例。`f` 上定义了以下属性：
