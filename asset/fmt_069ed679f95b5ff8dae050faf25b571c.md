
下表列出了本节中讨论的所有 Emacs 键盘快捷键。若要查看当前所有 Emacs 键位绑定列表，请打开 Emacs，并依次按下 `Ctrl + h` 和 `b`。

## 选定的键盘快捷键

| 使用此键盘快捷键 | 功能 |
|---|---|
| Alt + S | 检查所选单词的拼写 |
| Alt + / | 插入当前单词最近似的补全内容 |
| Alt + a | 移动到句首 |
| Alt + d | 删除下一个单词 |
| Alt + Delete 或 Ctrl + Delete | 删除前一个单词 |
| Alt + e | 移动到句尾 |
| Alt + g | 显示字体样式菜单 |
| Alt + g, b | 将字体样式设为粗体 |
| Alt + g, d | 将字体样式设为默认字体 |
| Alt + g, i | 将字体样式设为斜体 |
| Alt + g, l | 将字体样式设为粗斜体 |
| Alt + g, o | 使用您指定的字体样式 |
| Alt + g, u | 将字体样式设为下划线 |
| Alt + j, c | 居中显示所选区域（仅限富文本模式） |
