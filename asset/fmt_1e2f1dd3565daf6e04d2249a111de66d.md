
# X射线显微术

一种利用X射线辐射进行化学分析和放大100–1000倍的技术、仪器或仪器组合。可能的分辨率约为0.25微米。X射线显微图像中的对比度是由样品中变化的X射线衰减引起的。X射线显微镜的优势在于，除了结构信息外，它还提供了关于物体的定量化学信息，包括那些对光不透明的物体。它是一种可靠的超微量化学分析技术，可以分析小至10⁻¹²到10⁻¹⁴ g的元素量和样品重量，误差仅为几个百分点。参见[显微摄影术](MICROSCOPGRAPHY)。

X射线显微镜成像有四个一般原理：

- (1) **接触微摄影**（插图 a, b）；
- (2) **投影X射线显微镜**（插图 b）；
- (3) **反射X射线显微镜**（插图 c）；以及
- (4) X射线图像光谱学（插图 d）。

在接触微摄影中，薄样品与具有超过25,000 lines/in. (1000 lines/mm) 分辨率的极细颗粒感光乳剂紧密接触，并用适当波长的X射线进行放射摄影。因此，获得1:1比例的吸收图像，随后通过光学显微镜观察该图像。最大分辨率是光学显微镜的分辨率（0.25 μm），但该图像包含更多信息，可以通过在电子显微镜中检查微分图来获得。参见[电子显微镜](ELECTRON MICROSCOPE)。

投影X射线显微镜，或X射线阴影显微镜，基于产生极细X射线焦斑的可能性。这是通过类似电子显微镜中的电子透镜系统实现的。精细的焦斑产生在一个非常薄的金属箔上，该箔用作透射靶。X射线由电子撞击靶材在靶材上产生。样品放置在靶材附近，初级放大倍数取决于焦斑到样品距离与样品到胶片距离之比。分辨率c与焦斑大小处于同一数量级；在有利对象中，最佳值约为0.1 μm。

反射X射线显微镜法基于固体中X射线的折射率略小于1这一事实。因此，在掠入射（即入射角非常小角度时，X射线会被全反射，如果反射面制成圆柱形，则会在一个维度上产生聚焦作用。通过交叉两个这样的表面，可以获得真正的成像，尽管会产生一些像差，但可以通过赋予表面复杂的光学形状来校正。

此过程的分辨率约为 0.5–1 µm。X射线成像光谱术利用圆柱弯曲晶体中的布拉格反射，产生略微放大的发射图像；这项技术最好被归类为微成像分析。分辨率约为 50 µm。参见：X射线衍射；X射线荧光分析。

在生物学领域，X射线显微术已被用于量化多种组织的干重、含水量和元素组成，尤其是矿化组织。(A.E.)

## X 射线光学

类比光学科学，这是 X 射线表现出类似光线特性的光物理的那些方面。X 射线光学也可以定义为使用类似于可见光光学中使用的仪器来操控 X 射线的科学。这些仪器使用如镜面等光学元件来聚焦或偏转 X 射线，使用 zone plates（环形光栅）来成像，并使用衍射光栅来分析 X 射线的谱分量。X 射线光学在许多领域都很重要，包括 X 射线天文学、生物学、医学研究、热核聚变以及 X 射线显微术。对于建造用于同步辐射研究的操控和分析来自同步加速器和粒子储存环的 X 射线的仪器来说，它是必不可少的。参见：几何光学；光学；物理光学；X 射线。

1895 年，当 W. C. 伦琴发现 X 射线时，他试图用各种材料的镜子、棱镜和透镜来反射、折射和聚焦 X 射线，但均未成功。这种不成功的原因在后来得出 X 射线是波长极短的电磁波这一结论后变得明显，所有材料对 X 射线的折射率都小于 1，且差值很小。此外，X 射线会被材料吸收。

折射率可以写成一个复数量，如方程 (1) 所示，其中 $1 - \delta$ 代表折射率 $n$ 的实部，$\beta$ 是吸收指数。这些量强烈依赖于 X 射线的波长和材料。波长小于或等于 0.1 纳米的 X 射线被称为硬 X 射线，具有较强的穿透力；而波长在 1–10 纳米范围内的 X 射线穿透力较弱，被称为软 X 射线。波长在 10–50 纳米范围内的辐射被称为极紫外 (EUV) 区域，会被大多数材料强烈吸收。$\beta$ 值在 X 射线和极紫外区域都保持非常小，结果是辐射在任何材料中都被非常微弱地折射。因此，X 射线透镜必须具有非常强的曲率且非常厚，才能产生显著的聚焦效果。然而，由于相比之下吸收指数 $\beta$ 非常高，这样的透镜会吸收大部分入射辐射，使得这类透镜不切实际。参见：电磁辐射的吸收；波的折射；紫外辐射。

$\hat{n} = 1 - \delta - i\beta$ (1)

如果辐射垂直（即成直角）入射到两种折射率不同的介质之间的界面上，反射能量分数为 $(n_{1}^{2}(n_{1}^{2} + n_{2}^{2})^{2})$。显然，对于 X 射线的正入射镜面，这个值在实践上非常小。然而，利用全反射原理可以构建有用的镜面。当电磁波入射到折射率为 $n_{1}$ 的材料与折射率较低（$n_{2}$）的材料之间的边界时，存在一个入射角 $I_{c}$，称为临界角，由方程 (2) 给出。如果入射角（入射辐射相对于法线的角度）大于这个临界角，所有波能量都会反射回第一种介质。当向上看水族箱时可以看到这种现象：箱中的物体反射在水面上，水面充当了完美的镜子。X 射线发生类似的情况。由于所有材料的折射率都略小于 1，从真空（或空气）入射到例如金属抛光表面的 X 射线会遇到较低的折射率，并存在由 $\sin I_{c} = 1 - \delta$ 给出的临界角。由于 $\delta$ 非常小，$I_{c}$ 非常接近 $90^{\circ}$。在这种情况下，入射角通常从表面切线而不是法线测量，角度 $\theta_{c} = 90^{\circ} - I_{c}$ 被称为掠入射角。这个角度通常在 $0.1^{\circ}$–$1.0^{\circ}$ 范围内。参见：电磁辐射的反射。

$\sin I_{c} = \frac{n_{2}}{n_{1}}$ (2)

尽管表面在大于临界角的掠射角下的反射率非常小，但这种反射率可以通过在表面沉积交替具有高低 $\delta$ 值的超薄膜层堆栈来增强。这些薄膜的单个厚度经过调整，使得来自每个界面的反射在堆栈顶部同相叠加，完全类似于用于可见光的多层膜镜面。然而，与需要数百纳米膜厚度的可见光多层膜不同，在 X 射线区域，每层膜的厚度必须在 1 到 100 纳米之间。新的超薄膜可以通过多种真空沉积技术制造，通常包括溅射和蒸发。这些人造多层膜具有强烈的波长选择性。参见：X 射线衍射。

作为掠入射光学的涂层，多层膜使得镜面可以在给定的掠射角下用于更短的波长（更高的 X 射线能量），从而增加投影面积并提高镜面的收集效率。在波长长于 3 或 4 纳米时，多层膜镜面可用于制造相对较高反射率的正入射镜面。例如，由钼和硅交替层组成的堆栈在 13 纳米及更长的波长处，反射率可高达 $65\%$。这些镜面已被用于构建与可见光镜面光学完全类似的光学系统。例如，正入射 X 射线望远镜已经在约 18 纳米的波长下拍摄了太阳的炽热外层大气。波长为 13.5 纳米的多层膜光学可用于通过投影法进行 X 射线微成像，以打印尺寸小于 100 纳米的特征。

晶体是天然的多层结构，因此可以反射 X 射线。许多晶体（如云母、石英、硅）或塑料（氟化锂）可以用作 X 射线聚焦反射器。这些用于 X 射线显微镜、电子束显微镜和衍射相机等设备中，将来自小光源或样品的辐射聚焦到胶片或探测器上。在基于镜面和环形光栅的成像光学的出现之前，晶体对 X 射线衍射的主题被称为 X 射线光学。参见：X 射线晶体学；X 射线光谱学。

Zone plates（环形光栅）是聚焦 X 射线并形成图像的衍射装置。它们是由面积相等的同心圆环组成的衍射掩模，对 X 射线交替透明和不透明。与通过调整波前每一点的相位来聚焦辐射的镜面和透镜不同，环形光栅通过阻挡波前中相位比板中心相差超过半周的区域来起作用。因此，环形光栅起到一种 X 射线透镜的作用。环形光栅显微术是 X 射线生物样品显微术中最有前途的候选方法。参见：衍射。[J.H.U]

## X 射线粉末法

用于物质鉴定及其他类型分析的物理技术，主要用于固态结晶材料。在这些技术中，单色 X 射线光束被照射到多晶（粉末）样品上，产生记录在胶片上或通过衍射仪记录的衍射图样。这种 X 射线图样是由衍射物质的原子排列决定的基本且唯一的性质。不同物质具有不同的原子排列或晶体结构，因此没有两种化学性质不同的物质会产生相同的衍射图样。可以通过将未知物质的图样与已知物质的图样进行比较来进行鉴定，这类似于通过指纹识别人。分析信息与通过化学或光谱分析获得的信息不同。X 射线鉴定化学化合物可以指示组成元素并展示它们的结合方式。

X 射线粉末法广泛应用于基础和应用研究；例如，它用于原料和成品的分析、相图研究、固态化学反应过程的追踪，以及矿物、矿石、岩石、金属、化学品和许多其他类型材料的研究。使用 X 射线粉末衍射法确定实际原子排列的方法在研究化学键、晶体物理和晶体化学方面具有重要意义，相关方法在相关文章中描述。参见：X 射线晶体学；X 射线衍射。

市面上有许多类型的粉末衍射仪，从简单的实验室仪器到使用同步辐射源的复杂多功能仪器都有。专用仪器允许在非环境条件（包括可变温度、压力和气氛）下记录衍射图样。也有用于 X 射线分析的全自动设备。
