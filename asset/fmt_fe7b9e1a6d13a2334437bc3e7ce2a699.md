
### XkbOptions
用于将普通键盘的 Caps Lock 键与 Ctrl 键互换（即 Caps Lock 变为 Ctrl），以适应偏好 Sun Microsystems 键盘布局的用户。例如，`XkbOptions "ctrl:swapcaps"` 将 Caps Lock 与 Ctrl 互换。默认保持键位不变。

### XkbRules
用于指定规则文件。默认规则文件是 `xfree86`。

## Pointer 节

用于设置指针设备，通常是鼠标。此节的示例如下：

```text
Section "Pointer"

Protocol   "Microsoft"
Device     "/dev/mouse"

EndSection
```

以下是此节中的选项：

### Protocol
设置指针设备的协议。协议可以是 Auto、BusMouse、GlidePoint、GlidePointPS/2、IntelliMouse、IMPS/2、LogiTech、Microsoft、MMhiTab、NMSeries、Mouseman、MouseManPlusPS/2、MouseSystems、NetMousePS/2、NetScrollPS/2、OSiMouse、PS/2、SysMouse、ThinkingMouse、ThinkingMousePS/2 或 Xqueue。如果您不知道哪种协议适合您的新型指针设备，请尝试将协议设置为 Auto。

### Device
指定设备路径。如果您使用鼠标作为指针设备并将其连接到串口 1 (`cua0`) 或串口 2 (`cua1`)，则可以分别指定 `/dev/cua0` 或 `/dev/cua1`。然而，最好的方法是创建一个名为 `/dev/mouse` 的符号链接指向您的串口设备 (`cua0` 或 `cua1`)，并将设备设置为 `/dev/mouse`。这样，如果您更换端口，只需重新调整链接，而无需修改配置文件。

您可以在此节中添加的其他常用选项列在表 14-3 中。

### 表 14-3：XF86Config Pointer 节的选项

| 选项 | 说明 |
| :--- | :--- |
| `BaudRate` | 用于设置指针设备的波特率。 |
| `Port` | 用法与前面列表中描述的 `Device` 选项相同。 |
| `Button` | 用于设置按钮数量。 |
| `Emulate3Buttons` | 用于用两键鼠标模拟三键鼠标。当您同时按下两个按钮时，将模拟第三个按钮。 |

## 表 14-3 续

| 选项 | 说明 |
|---|---|
| `Emulate3Timeout` | 用于设置三键模拟的超时时间（以毫秒为单位）。X 服务器将等待指定的毫秒数，以判断当你同时按住两个按钮时是否按下了第三个按钮。 |
