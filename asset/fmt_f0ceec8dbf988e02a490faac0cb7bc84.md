# Linux 系统管理

系统管理既是一门计算机科学，也是一门计算机艺术。这就是为什么 `M Carling`、`Stephen Degler` 和 `Jim Dennis` 编写了这本书，书中提供了大量的技术细节，并探讨了管理 `Linux` 及其他系统环境背后的哲学。

作者对开源软件的价值深表赞同，对网络系统的的需求具有敏锐的洞察力，帮助你设计、安装和管理 `IT` 环境。你将学习制定有效的安全和数据恢复策略的技术。你将看到关于脚本工具及其使用原因的广泛涵盖，以及关于如何为特定任务选择正确命令的讨论。

在编写这本书时，作者借鉴了数十年来在开发和管理世界上规模最大、最复杂的网络系统方面的丰富经验，以说明如何构建一个能够随系统软件共同进化的环境。

如果你管理着 `Linux` 网络，本书将提供坚实的专业知识，帮助你：

- 学习管理网络的最有效手段
- 理解安全理论以及如何执行该理论
- 在考虑到扩展性的前提下设计你的环境
- 通过自动化操作确保可靠性
- 迁移到 `IPv6`
- 维护数百个 `NIS` 域的一致性
