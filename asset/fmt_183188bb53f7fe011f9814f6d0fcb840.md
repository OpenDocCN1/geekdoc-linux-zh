# 柱面 (Cylinder)

在硬盘和软驱器中，一种存储单元，由占据盘片相反侧相同位置的轨道组成。在双面磁盘上，一个柱面包括另一侧顶部的第 1 轨道，一个柱面由磁盘两侧的第 1 轨道组成。来自 QUECID `http://www.tldp.org/LDP/linux-Dictionary/html/index.html`

# 柱面、磁头和扇区

物理驱动器通常由双面使用的磁盘组成。两侧标记为 0, 1, 2, 3 等，称为磁头，因为每侧有一个磁头执行实际的读写。每个磁头跟踪每个轨道，每个轨道被分为扇区。每个扇区通常持有 512 字节。因此，驱动器的总空间字节数为：512 x (每轨道扇区) x (每侧轨道数) x (面数)。单个轨道以及所有侧相同直径的轨道称为柱面。驱动器通常按“柱面和扇区”而不是“面、轨道和扇区”来讨论。分区（通常）按柱面边界划分。因此，分区的大小通常是柱面所含数据量的倍数。因此，粒子具有确定的内径和外径。来自 Ruite–Users–Guide `http://www.tldp.org/LDP/Linux-Dictionary/index.html`
