
# crontab 文件的格式

每个与时间相关的字段可能包含：

- `*` 号，匹配所有内容
- 单个整数，精确匹配
- 两个用连字符分隔的整数，匹配一个值范围
- 范围后跟一个斜杠和步长值，例如 `1-10/2`（仅限 Linux）
- 逗号分隔的整数或范围列表，匹配任何值

## 示例

```
0-59 * * *
```

```
0-17 * * *
```

```
0 0,12 * * *
```

```
0 0 * 1-5
```

```
0 0 * * 1,3,5
```

```
0 0 * 1-15 * *
```

```
0 0 1-31/2 * *
```

```
0 0 * * 0-6
```

```
0 0 * 1,2,5 0-6
```

```
0 0 1-15 * 0-6
```

```
0 0 1-31 1-12 0-6
```

```
0 0 * * 0,2,4,
```
