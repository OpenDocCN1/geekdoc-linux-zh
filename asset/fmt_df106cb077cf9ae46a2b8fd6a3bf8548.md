
# 对称定律（物理学）

基本物理定律在时间平移下具有对称性的陈述，等价于陈述这些定律不发生变化或演化。时间平移对称性在根本上应该适用于简单的孤立系统。大型复杂系统，特别是整个宇宙，当然会老化和演化。因此，在构建宇宙学的大爆炸模型时，假设单个电子或质子的性质不随时间变化，尽管当然根据模型，整个宇宙的状态已经发生了巨大变化。

基本定律在空间平移下具有对称性的陈述，是空间均质性的另一种表述方式。这意味着定律在整个宇宙中是相同的。它指出，前例中的宇航员无法通过其太空舱内的局部实验推断其位置。这种对称性的威力在于，它使得我们有可能根据地球实验室中的观测推断宇宙中任何地方的物质行为。

上述提到的物理定律在旋转下的对称性体现了空间的各向同性。

在动力学的数学表述中，对称性与守恒定律之间存在密切联系。时间平移对称性意味着能量守恒；空间平移对称性意味着动量守恒；旋转对称性意味着角动量守恒。参见 `角动量`；`能量守恒`；`动量守恒`。

狭义相对论的基本公设，即物理定律对于以固定速度相对运动的观测者具有相同形式，显然是关于物理定律对称性的另一个陈述。伽利略讨论过物理定律在此类变换下应保持不变的观念，并通过在平静海面上封闭舱室中的观测者无法推断运动这一例子来说明。爱因斯坦理论的新颖之处在于将此速度对称性与从实验推导出的第二个公设结合，即光速是一个普适常数，对于静止和匀速运动的观测者必须取相同的值。参见 `伽利略变换`；`洛伦兹变换`；`相对论`。

## 离散对称性

在 1956 年之前，人们认为所有物理定律都遵守一组额外的基本对称性，分别称为 `P`、`C` 和 `T`，即宇称、电荷共轭和时间反转。涉及被称为 `K 介子` 的粒子的实验提出了 `P` 可能在弱相互作用中被破坏的建议，并且确实观测到了破坏。这一发现导致了对其他珍视的对称性原则的质疑——在某些情况下甚至被推翻。

宇称，`P`，大致上将物体变换为其镜像形状。如果 `P` 是对称性，物体在镜中反射图像的表观行为也将是相应真实物体的实际行为。参见 `宇称`（`量子力学`）。

电荷共轭，`C`，将粒子变换为其反粒子。这是一种纯粹的内在变换；即，它不涉及空间和时间。如果物理定律在电荷共轭下具有对称性，涉及反粒子的实验结果可以从涉及粒子的相应实验推断出来。

值得注意的是，通过组合变换 `P` 和 `C`，得到一个结果 `CP`，它比其任一单独组分更接近有效的对称性。然而，1964 年的实验发现即使 `CP` 也并不是完全有效的对称性。

尽管上述讨论强调了 `P`、`C` 和 `CP` 未能成为物理定律精确对称性的失败，但负责核结构和反应的强相互作用力以及负责原子结构和化学的电磁力确实遵守这些对称性。只有负责 β 衰变和一些相对缓慢

物理定律中体现对称性的那些定律。术语“对称性”在数学和精确科学中使用时，指的是物体或物理定律的一种特殊性质，即它们在通常可能会改变它们的变换下保持不变。例如，球体的几何形状不会因球体绕其中心的任何旋转而改变，因此可以说球体在旋转下是对称的。对称性在约束形状方面可以非常强大。确实，参考同一个例子，唯一在任意旋转下对称的表面是球体。

物理定律展现对称性的概念更加微妙。一种朴素的表述是：如果存在某种可能改变定律形式但实际上并未改变的宇宙变换，那么该物理定律就展现对称性。然而，不同宇宙的比较通常不可行或不可取。物理定律对称性的一个更有成效的定义利用了局域性，即给定系统的行为仅受空间或时间上遥远物体行为的微弱影响这一原则。由于局域性，可以使用不涉及整个宇宙但仅涉及适当孤立部分的变换来定义对称性。因此，陈述物理定律在旋转下对称意味着（例如）太空中的宇航员无法通过其空间站内部的实验来定向——确定首选方向。他们只能通过参考遥远物体的微弱效应来做到这一点，例如遥远恒星的光或地球的小残存重力。

### 时空对称性

物理定律最基本和深远的对称性可能是时间平移对称性和空间平移对称性。

奇异基本粒子的衰变现象违背了这些对称性。因此，这些相互作用虽然是近似的，但在核物理和原子物理中仍非常有用且强大。参见[电弱相互作用](https://example.org/electroweak_interaction)；[基本相互作用](https://example.org/fundamental_interactions)；[弱核相互作用](https://example.org/weak_nuclear_interactions)。

时间反演对称性 `T` 的操作涉及改变所有粒子的运动方向。例如，它将 `A + B → C + D` 类型的反应与其逆反应 `C + D → A + B` 联系起来。目前没有检测到对 `T` 的直接违反。参见[时间反演不变性](https://example.org/time_reversal_invariance)。

即使时间反演对称性有效，它也以直接的方式仅适用于基本过程。例如，它并不违背热力学第二定律的单向性特征，该定律指出熵只能随时间增加。参见[热力学原理](https://example.org/thermodynamic_principles)；[时间之箭](https://example.org/arrow_of_time)。

量子场论的基本原理表明，联合操作 `PCT`——即同时反射空间、将粒子变为反粒子并反转时间方向——必须是物理定律的一种对称性。现有的证据与这一预测相符。参见[CPT 定理](https://example.org/cpt_theorem)。

## 内部对称性

内部对称性，如 `C` 对称性，不涉及时空变换，而是将一种粒子转变为另一种粒子。例如，尽管是近似的，这种类型的对称性是同位旋或 `I-旋` 对称性。实验观察到质子和中子的强相互作用基本上是相同的。参见[I-旋](https://example.org/i-spin)。

基于内部对称性的假设，对新粒子的存在和性质做出了若干成功的预测。其中最著名的可能是基于将同位旋对称群 `SU(2)` 扩展为一个更大的近似 `SU(3)` 对称性（该对称性也作用于奇异粒子），从而预测了 `Ω⁻` 重子的质量和性质。这些对称性是一个重要线索，表明基本强相互作用在某种程度上是普适的，即对所有夸克的作用方式相同，从而为现代量子色动力学奠定了基础，该理论确实实现了某种普适性。参见[重子](https://example.org/baryon)；[群论](https://example.org/group_theory)；[量子色动力学](https://example.org/quantum_chromodynamics)；[幺正对称性](https://example.org/unitary_symmetry)。

比 `SU(2)` 内部对称性在数学上简单得多的 `U(1)` 内部对称性，在物理上却相当深刻。我们将考虑电荷量子数的一个重要情况。带有参数 `λ` 的 `U(1)` 内部对称性变换的作用是使带电量为 `q` 的状态的波函数乘以因子 `$e^{iλ q}$`。因此，两个带电量分别为 `q1` 和 `q2` 的状态之间的振幅将被乘以因子 `$e^{iλ(q1-q2)}$`。由于量子力学的物理预测依赖于这些振幅，只有当乘以所有非零振幅的相位因子为平凡（即等于 1）时，这些预测才保持不变。反过来，这只有在不同电荷状态之间的振幅为零时才成立；也就是说，改变电荷的振幅是被禁止的，这恰恰是用一种迂回的方式表达电荷守恒。参见[非相对论量子理论](https://example.org/nonrelativistic_quantum_theory)；[量子力学](https://example.org/quantum_mechanics)；[量子数](https://example.org/quantum_numbers)。

## 对称性的局域化

局域规范不变性这一概念是基本粒子相互作用标准模型的核心，并以略微不同的形式存在于广义相对论中。它可以被看作是对 `U(1)` 内部对称性变换的推广，其中出现了一个独立于空间和时间的参数 `λ`。这种参数违背了局域性的精神，局域性认为时空中每个点都具有一定的独立性。因此，有理由考虑一种更一般的对称性，涉及依赖于时空的变换，其中波函数被乘以 `$e^{iα(x,t)}$`，其中 `α(x,t)` 是时空点 `(x,t)` 处的电荷密度。这些变换比上面讨论的变换更加一般，而在它们不变性下会导致更强大且具体的后果。

对于电磁学，物质与电磁场之间所需的相互作用被精确预测。因此，可以说电磁场理论——麦克斯韦方程组和量子电动力学——是依赖于时空的对称性，即局域规范对称性这一抽象概念的唯一理想体现。参见[麦克斯韦方程组](https://example.org/maxwells_equations)；[量子电动力学](https://example.org/quantum_electrodynamics)。

# 超适应结构

一种关于生物有机体结构设计的理论，该理论假设结构是定量匹配功能需求的，这是生长和维持过程中受调控形态发生的结果。超适应结构是一种经济设计理论。在生物有机体中，所有功能都依赖于结构设计，特别是器官的形态计量特征。一般而言，结构越大，功能容量越大。作为经济设计理论，超适应结构的一个核心要求是，器官上功能需求的差异需要对其结构设计参数进行定量调整，以将功能容量（最大）功能需求相匹配。
