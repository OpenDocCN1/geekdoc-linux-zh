## ERRNO

上一个失败的命令的非零退出代码。此变量被设置为 `?`，但它与其他变量不同之处在于，它的值只在命令失败时发生变化。成功执行的命令不会改变 `$ERRNO` 的值。这个变量对于使用它的用户是一个诊断辅助工具；或者用于 shell 脚本。

## LINENO

此变量仅在脚本中有意义。它的值是你为你赋值的赋值行的行号。`LINENO` 将由你调用的下一个脚本改变。或者，如果是 shell 脚本，它将在下一次执行时改变。

## OLPWD

此变量的值始终是上一次 `cd` 命令之前当前目录的完整路径。换句话说，重复执行 `$OLPWD` 会在你当前目录和目录之间切换。`$OLPWD` 的一个示例是方便 `cp` 和许多命令的使用；`cp someplace` 后面跟着 `cp filesize $OLPWD` 可以将文件复制到原始目录，而无需输入完整路径。然后你使用 `cd $OLPWD` 切换回原始目录。（在 Korn shell 中，简写 `cd -` 的含义与 `cd $OLPWD` 相同。）

## OPTARG

此值由 Korn shell 的内置命令 `getopts -a` 设置。（欲了解更多信息，请参阅本章的“Shell 编程”。）

## OPTIND

此值是你当前进程的进程 ID。如果 `$$` 是当前进程 ID，那么 `$PPID` 就是产生你的进程的 ID。`$PPID` 对于 shell 编写者特别有用。它在键盘操作上作用不大。

## PPID

指定你当前目录的完整路径。由于符号链接的存在，`$PWD` 的值并不与 `pwd` 命令打印的值相同。假设存在目录 `/usr/bin` 以及存在一个名为 `.after` 的指向 `/usr/bin` 的符号链接。执行 `cd` 之后，`pwd` 命令打印 `usr/bin`——目录的真实路径——而语句 `print $PWD` 打印的是 `/bin`——你到达该目录的路径。（链接在第 4 章“Unix 文件系统”中解释。）

## RANDOM

此值是一个 0 到 32767 之间的整数。每当你执行它时，该值都是随机的。这个变量在键盘操作上用处不大；但在 shell 脚本中，它对于生成临时变量很有用。

## REPLY

在 Korn shell 中，`select` 命令会将 `$REPLY` 的值设置为用户输入的文本。如果你在 `read` 命令中没有提供任何变量名，该内置命令将存储用户输入的文本。（欲了解更多信息，请参阅本章的“使用 select 语句”。）

## SECONDS

自你调用 Korn shell 以来的秒数整数值——通常是你登录时，或通过 `ksh` 命令显式地调用 Korn shell 时。此变量简单地记录了 shell 运行到你终端为止的挂钟时间。
