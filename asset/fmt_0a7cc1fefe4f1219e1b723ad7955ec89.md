## konvert

文件或终端 IO 的字符转换 `'konvert'` 是另一种字符转换器。某些特殊功能：

- 一对多转换
- 上下文转换
- 对不可用字符的近似
- （作为结果）转换俄语语音等效转换
- `'filter'` 应用过滤器将字符串转换为 I/O，获取实时字符转换器并自定义输入方法。来自 Debian 3.0r0 APT

## korganizer

基于 QI 和 KDE 的个人组织器。一个完整的日历和调度程序。`Organizer` 支持通过行业标准 `vCalendar` 格式从其他应用程序导入信息。`KOrganizer` 的目标是成为管理预约、联系人、项目等的完整程序。它与常见的 Microsoft Windows 等各种程序精神一致。最棒的是它 `原生` 读写 `vCalendar` 格式（请参阅 `http://www.imc.org/pdi` 了解更多信息，`http://www.imc.org/pdi` 了解更多信息），由于这一点，你应该能够轻松地从其他现代 PIM 迁移到 `KOrganizer`。当前用户可以比较功能。如果你安装了 `kpilot`，`KOrganizer` 提供与你的 Palm Pilot 完全同步。来自 Debian 3.0r0 APT
