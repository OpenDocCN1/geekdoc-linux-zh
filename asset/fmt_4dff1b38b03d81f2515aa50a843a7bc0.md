## Shell 设置文件

当你输入 `ls -al` 命令来获取主目录下所有文件的详细列表（包括以点开头的文件）时，你会看到一个或多个以 `.` 开头并以 `_rc` 结尾的文件。对于 bash 来说，这就是 `.bashrc`。它是系统级配置文件 `/etc/bashrc` 的对应项。

当登录交互式登录 shell 时，`login` 将定义身份验证、环境并启动你的 shell。对于 `.bashrc`，下一步是读取 `/etc` 下的通用配置（如果该文件存在）。bash 然后会按顺序查找 `~/.bash_profile`、`~/.bash_login` 和 `~/.profile`，并读取且执行第一个存在且可读的文件中的命令。如果都不，则应用 `/etc/bashrc`。

当登录 shell 退出时，如果存在 `~/.bash_logout` 文件，bash 会读取并执行其中的命令。

此过程在 `login` 和 `bash` 页面中有详细解释。

## Bash 提示符

### 序言

Bash 提示符的功能远不止显示用户名、机器名以及当前工作目录的指示。我们还可以添加其他信息，例如当前日期和时间、连接的用户数等。

然而，在开始之前，我们将当前的提示符保存到另一个环境变量中：

```bash
[jerry@nowhere jerry]$$ MYPROMPT=$PS1
```

```bash
[jerry@nowhere jerry]$ echo $MYPROMPT
\u@\h \W\$
```

```bash
[jerry@nowhere jerry]$$
```

当我们更改提示符时（例如通过执行命令 `PS1="->"`），我们始终可以使用 `PS1=$MYPROMPT` 命令找回原始的提示符。当然，当你重新连接时，提示符也会恢复，只要你是在是在命令行上调整提示符，而不是将其放入 shell 配置文件中即可。

#### 示例

为了理解这些提示符和使用的序列，我们参考 Bash Info 或 man 页面（帮助手册）。

- `export PS1="\t \j"` 显示当天时间和运行中的作业数
- `export PS1="\d \u@\h \w"` 显示日期、用户名、主机名和工作目录。注意 `\W` 仅显示当前工作目录的基名。
- `export PS1="\j"` 显示每个命令的历史记录。
- `export PS1="\033[1;35m\u@\h\033[0m\j"` 以粉色显示 user@host。
- `export PS1="\033[1;34m\j \w\033[0m"` 将当前工作目录中的用户名设置为蓝色。
- `export PS1="\033[1;44m$USER is in \w\033[0m]"` 为那些难以区分提示符与输入内容差异的人设计的。
- `export PS1="\033[4;34m\u@\h \w \033[0m]"` 下划线提示符。
- `export PS1="\033[7;34m\u@\h \w \033[0m]"` 蓝色背景上的白色字符。
- `export PS1="\033[3;35m\u@\h \w \033[0m]\a"` 较浅字色的粉色提示符，在命令完成时提醒你。
- `export PS1=\=` 变量被导出到后续执行的命令，这些命令也能感知环境。提示符配置行最好放在你的 shell 配置文件 `~/.bashrc` 中。

如果你愿意的话，提示符可以执行脚本并在不同的条件下表现出不同的行为。你甚至可以让提示符在你每次执行命令时等待，尽管这很快就会变得无聊。更多信息可以在 Bash-Prompt HOWTO [http://www.tdp.org/HOWTO/Bash-Prompt-HOWTO] 中找到。

## Shell 脚本

### 什么是脚本？

正如 shell 配置示例所示，脚本是一个包含 shell 命令的文本文件。当该文件在调用 Bash 时作为第一个非选项参数使用，且没有使用 `-c` 或 `-s` 选项时，Bash 会读取并执行文件中的命令，此时的操作模式创建一个非交互式 shell。当 Bash 运行脚本时，它会将特殊参数 `$0` 设置为文件名而非 shell 的名称；如果提供了后续参数，则位置参数（脚本名称之后的所有内容）被设置为剩余参数。如果没有提供额外的参数，则位置参数将被清除。
