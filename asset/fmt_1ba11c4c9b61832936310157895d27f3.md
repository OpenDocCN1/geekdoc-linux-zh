## 历史

### UNIX

为了理解 Linux 的流行，我们需要回到过去，回到大约 30 年前……

想象一下计算机像房子甚至是体育场一样大。虽然这些计算机的尺寸构了巨大的问题，但有一件事让情况变得更糟：每台计算机都拥有不同的操作系统。软件是为了特定目的而定制的，为某个特定系统的软件无法在另一个系统上运行。能够操作某一个系统并不意味着你就能自动操作另一个系统。对于用户和系统管理员来说，这都是困难的。

计算机极其昂贵，即使在最初购买后，必须做出牺牲才能让用户理解它们是如何工作的。单位计算能力的总成本是巨大的。

从技术上说，世界还没有那么先进，因此必须再忍受十年的体积。1969 年，贝尔实验室（Bell Labs）的一组开发者开始研究解决软件问题的方案，以应对这些兼容性问题。他们开发了一种全新的操作系统，特点是：

1. 简单优雅。
2. 使用 C 语言编写而非汇编代码。
3. 能够复用代码。

贝尔实验室的开发者将他们的项目命名为“UNIX”。

## 什么是 Linux？

代码复用特性非常重要。在此之前，所有市售计算机系统都是用专门为某个系统开发的代码编写的。相反，UNIX 只需要这些代码的一小部分，通常被称为内核（kernel）。内核是唯一需要为每个特定系统进行适配的代码，它形成了 UNIX 系统的基础。操作系统和其他所有其他功能都是围绕这个内核构建，并用高级编程语言 C 编写的。C 是专门为创建 UNIX 系统而开发的。使用这种新技术，开发一个可以在不同类型硬件上运行的操作系统变得容易得多。

软件供应商迅速了了，因为他们发现可以几乎毫不费力地提供十倍的软件。奇怪的情况出现了：例如，同一网络中来自不同供应商的计算机，或者用户在不同的系统上工作而无需额外学习使用另一台计算机。UNIX 在帮助用户兼容不同系统方面出了巨大努力。

在接后的几十年里，UNIX 的持续持续。更多事情变得可行，更多的硬件和软件供应商在其产品中支持 UNIX。

UNIX 最初仅出现在带有大型机和微机的大型环境中（注意 PC 是“微型”计算机）。你必须在大学、政府或大型金融机构工作才能接触到 UNIX 系统。

但更小的计算机正在开发中，到 80 年代末，许多人拥有了计算机。那时，PC 架构已经有多个版本的 UNIX 可用，但没有一个是真正免费且重要的；它们运行得非常慢，以至于许多人在家庭 PC 上运行 MS DOS 或 Windows 3.1。

## Linux 和 Linux

到 90 年代初，家用 PC 终于足够强大，可以运行完整的 UNIX。在赫尔辛基大学学习科学的年轻人林斯·托瓦尔斯（Linux Torvalds）认为，拥有某种免费的学术版 UNIX 是个好主意，并受此开始编写代码。

在那个时代，即插即用（plug-and-play）从未被发明，但由于许多人渴望拥有自己的 UNIX 系统，这只是一个微小的障碍。新驱动以不断提高的速度出现在各种新硬件上。几乎只要新硬件出现，有人购买并提交到 Linux 测试，随着系统的逐渐发布，为更广泛的硬件释放了免费代码。这些拷贝不仅限于他们的 PC；他们拥有的每件硬件对 Linux 都是有用的。

## 针对无经验用户的 Linux

如 RedHat、SuSE 和 Mandriva 等公司应运而生，提供了适合大批量消费的定制化 Linux 发行版。它们整合了大量由社区开发的图形用户界面（GUI），以简化程序和服务的管理。如今的 Linux 用户拥有了各种方法从外部了解你的系统，但为了让系统满足你的需求，并不非要这样做。

现在，你可以通过图形界面登录并启动所有所需的应用程序，甚至不需要输入单个字符，而在需要时，你仍然可以访问系统的核心。由于其结构，Linux 允许用户在系统中成长：它能够轻松适应新手和老手。新用户不会被迫去做困难的事情，而老手也不会被迫像他们初次接触 Linux 时那样操作。

在服务领域持续发展的同时，人们正在为用户做出努力，这些用户通常被认为是最不了解系统工作原理的群体。桌面应用程序的开发者正在巨大的努力，打造你见过的最美丽的桌面，或者让你的 Linux 机器看起来就像你的 Windows 操作系统或某个应用程序。最新进展还包括 3D 加速对 USB 设备的支持、系统和软件包的单击更新等。Linux 尝试以普通人能理解的逻辑格式呈现所有可用服务。下面是一份包含了一些优秀示例的短列表；这些网站有许多截图，可以让你领略 Linux 桌面可以变成的样子：

## 开源

开源软件背后的理念非常简单：当程序员可以阅读、分发和更改代码时，代码就会成熟。人们可以对其进行适配、修复、调试，而且其速度远超传统公司软件开发者的性能。这种软件将比使用传统方法开发的软件更具活性、质量更好，因为在不同条件下测试它的人数比闭源软件开发者所能测试的要得多。

开源倡议（Open Initiative）开始向商业界阐明这一点，而供应商也非常缓慢地意识到其中的意义。虽然许多学者和技术人员已经信服了 20 年这是正确的道路，但商业供应商需要互联网应用来让他们意识到可以从开源中获利。现在，Linux 已经过了那个几乎完全是学术系统的阶段（当时仅对少数具有技术背景的人有用）。

## 什么是 Linux？

现在 Linux 提供的不仅仅是一个操作系统：它还有一整套基础设施，支持着创建操作系统、为其制作和测试程序、将一切交付给用户、提供维护、更新和定制等系列工作。Linux 已经准备好接受瞬息万变世界的挑战。

## 十年经验为您服务

虽然 Linux 可能是最广为人知的开源倡议，但还有另一个项目对 Linux 操作系统的普及做出了巨大贡献。这个项目是 SAMBA，它的成就是救活了服务器消息块（SMB)/通用互联网文件系统（CIFS）协议，该协议用于 PC 相关机器的文件和打印，并被 MS Windows NT 和 OS/2 原生支持。现在几乎每个系统都有相应的软件包，并在混合环境中使用 MS Windows 协议提供互连解决方案：兼容 Windows（最高到 WinXP）的文件和打印。
