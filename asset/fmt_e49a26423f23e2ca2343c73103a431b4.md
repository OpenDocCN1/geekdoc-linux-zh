## 1.3 必要知识

### 1.3.1 知识点 1 核心版本与发行版本

#### 1. Linux 基本结构

市面上 Linux 的种类非常多，从华为手机到太湖之光都是 Linux 操作系统，区别却是巨大的。为何会有如此不同的系统？首先需要了解 Linux 的基本结构才能回答这个问题。一个完善的 Linux 操作系统往往由 4 部分组成，即内核（`kernel`）、外壳（`shell`）、实用程序（`utility`）和应用程序（`application`），如图 1-22 所示。内核是 Linux 的心脏，实现操作系统的基本功能，包括管理硬件设备、管理内存、提供硬件接口、处理基本 I/O、文件系统以及内核分配 CPU 时间；外壳是交互窗口，提供用户与内核交互的操作；实用程序是工具，是用户用于 Linux 系统日常维护和管理程序；应用程序是给用户执行各种功能的第三方程序，如各种服务器、文档管理器套件、各种媒体播放和处理组件。

![](img/a95c6704e7d3618800a5dd1f2c0aafd0_25_0.png)

![](img/a95c6704e7d3618800a5dd1f2c0aafd0_25_1.png)

> ① 华为手机所用的 EMUI 是一种 Android 操作系统，采用的内核是 Linux 内核，所以从意义上也是 Linux。
>
> ② “太湖之光”是中国计算研究中心研发的超级计算机，算力性能数值为 125 FLOPS。2016 年 6 月 20 日在 LINPACK 性能测试中取得了测试结果，荣冠天号（LINPACK 成为第 34 位），是世界上最强大的超级计算机，2018 年 6 月 8 日由美国开发的超级计算机神富取代。神威、太湖之光用的是 Linux 内核的系统（RaiseOS 2.0.5），主要面临问题和通用需求限制。

显然，内核执行的是整个操作系统关键、基础但对用户不可见的功能，而主要由外壳、实用程序和应用程序提供交互和其他功能。华为手机上的 EMUI 操作系统与太湖之光的内核 RaiseOS 操作系统是基于 Linux 的，恰恰是它们之间唯一的共同点。

#### 2. Linux 内核

Linux 内核诞生于 1991 年。90 年代初，赫尔辛基大学的学生 Lin Torvalds 以 Andrew Tanenbaum 教学类 Unix 系统 Minix 为蓝本，开发了一套新的内核，源代码托管在芬兰最大的 FTP 站点上，这也是 Linux 0.0 版。内核的发展到现在已经非常成熟，它是一个自由软件（`free software`），目前在通用许可证下发布。从桌面领域逐渐从移动到服务器的其他领域。截至 2018 年 12 月，世界顶级超级计算机全部使用 Linux 内核，内核版本是 5.x。

#### 3. Linux 发行

当用户想要一个操作系统，为了让操作系统工作，还需要编译器（`Compiler`）、库（`Libraries`）、各种程序和应用程序。GNU Project 是自由软件的精神，著名维护员 Richard Stallman 在 1983 年发起，致力于一个自由且完整的 Unix 操作系统。到 1991 年内核发布之前，GNU 已经完成了内核开发。

- Lin Torvalds 是 Linux 的创始人。
- 诞生于世界上最大的开发者社区之一。
- 根据自由软件定义，自由是一类不受限制的使用、复制、发行、修改。自由不是免费，开源软件（`open source`），相反对应的是专有软件（`proprietary software`），其定义就是限制或禁止任何使用。
- 通用许可证（`General Public License, GPL`）发表的所有权利，让用户能够发行、修改、自己的权利。GPL 最新版本共享、修改、优化程序带来巨大的利益。
- GNU 是一系列关于 Linux 的实现，内核能够充分引起开发者，直接导致 GNU 世界的完成，两者结合产生了操作系统。Linux 操作系统的正式名称为 `GNU/Linux`，标志如图 1-23 所示。

![](img/a95c6704e7d3618800a5dd1f2c0aafd0_27_0.png)

当然，对于少数 Linux 专家之外，大多数人没有选择。发行版本之间会有很大差异，这些差异主要体现在各自的安装上。例如，有的版本提供了更好的桌面环境，有的适用于工作站，有的版本具有良好的稳定性，作为服务器。目前 Linux 的主流发行版有 Red Enterprise Linux (RHEL)、CentOS、Fedora、Ubuntu 和 Debian。对于初学者来说，使用哪个版本的练习无区别，但最好的是 CentOS 7，建议这些读者使用和我一样的发行版本。

### 1.3.2 知识点 2 Linux 硬盘分区基础知识

在学习 Linux 的过程中，每一个分区表。硬盘有一个简单的功能：保存数据并随时访问。对硬盘进行分区的目的非常明确：将操作系统与用户数据分离；可以使用不同的文件系统。

#### 1. 分区表

分区表记录分区信息，支持两种类型：MS-DOS（MBR）和 GPT（GUID Partition Table）。

#### 2. 分区类型

在 Linux 中，分区表记录分区，支持两种类型：MS-DOS（MBR）和 GPT（GUID Partition Table）。

- **MS-DOS (MBR) 分区表**：传统的格式，最多支持 4 个主分区。
- **GPT 分区表**：现代分区格式，支持更大的磁盘和更多的分区数量，并支持 UEFI 启动。

#### 3. 逻辑卷 (LVM)

LVM（Logical Volume Management）是一种管理技术，可以将多个物理磁盘或分区合并成一个逻辑卷，使得分区能够灵活扩展和缩小。

#### 4. 交换分区

`swap` 分区负责虚拟内存，当物理内存不足以处理数据时，会将数据写入 `swap` 分区，`swap` 不需要挂载到目录上。

### 2.2.1 子任务 1 与 Linux 进行交互

在所有的问题中，首要解决的就是如何让 Linux 做出用户想做的事情。

可以用多种方式做到这一点。例如，Linux 程序员可以用编程语言操作系统的编程接口与 Linux 进行交互，甚至可以不使用编程接口，直接与 Linux 内核交互。但是，作为一名 Linux 的系统管理员，还是通过现成的命令行接口（`user command interface`）与 Linux 进行交互。用户命令行接口被形象地称为“shell”。

简单来说，就是一种能让用户与 Linux 之间进行“对话”的软件。`shell` 接收用户输入，由 Linux 解释输入，并且处理各种系统输出结果，把这些结果展示给用户。交互可以是即时交互（从键盘输入，并且可以立即得到响应），也可以是非即时交互（`shell` 脚本①）。

在本任务中所使用的 CentOS 系统的默认 `shell` 叫做 `bash`（GNU's bourne shell），它也是大部分 Linux 平台上的默认。

> **注意**
>
> - 事实上，Linux 为用户提供了截然不同的“壳”：一种是命令行（`command line interface, CLI`），用户利用这些命令或 `shell` 脚本来组织和控制操作的执行；另一种是图形界面（`graph user interface, GUI`），用户通过点击、拖动图标完成所有的事情。

① `shell` 脚本是在文件中的一系列命令和操作命令，它们可以被重复使用。简单来说，`shell` 脚本将命令组合到一个文件里。

![](img/a95c6704e7d3618800a5dd1f2c0aafd0_33_0.png)

对 CLI 应该抱着开放的态度，它们只是解决不同问题的工具，完全不存在优劣之分。例如，运维人员可能会觉得 CLI 比较好，而美工则认为 GUI 更好。在 10 个任务中基本没有用到 GUI 只是因为在这些任务中，CLI 更加简单。

> **注意**
