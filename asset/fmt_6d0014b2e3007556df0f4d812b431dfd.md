## 运行级别 0 和 6

在 Slackware Linux 中，运行级别 0 关闭系统，而运行级别 6 重启。在运行级别 0 或 6 时，所有文件系统都会被卸载，进程会被终止，并且交换空间会关闭。如果发生在运行级别 0，系统停止。如果发生在运行级别 6，系统重启。运行级别 0 或 6 的进程位于 `/etc/rc.d/rc.0` 中。

要在任何运行级别运行 Slackware Linux，只需使用命令 `telinit`，如下所示：

```
# telinit 1
```
