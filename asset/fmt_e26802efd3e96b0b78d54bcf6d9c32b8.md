## 2220 固体中的热传导（Thermal conduction in solids）

差示热分析监测样品与惰性参考之间的温度差 `T_p`。大多数基础物理可以被精确测量。需要理论来从实验中诱导出。参见 基本（FUNDAMENTAL）；

样品与惰性参考之间的温度差。固体中，热导率受温度影响。热导率可以写为 `k = Sv`，其中 `S` 是单位面积的热通量，`v` 是平均速度。从气体的动力学来看，热导率可以表示为 `k = 1/3 Cvλ`，其中 `C` 是热容，`λ` 是自由程。固体中，自由程决定了热导率。

固体的热导率还受到缺陷、杂质和晶界的影响。晶体中的热导率很高，而在非晶固体中较低。气体的热导率可以表示为：

`k = 1/3 n k_B T λ` (3) 其中 `k_B` 是玻尔兹常数，`T` 是温度，`n` 是数密度，`λ` 是自由程。

金属的热导率由自由电子的运动主导。维德曼定律将热导率 `κ` 与电导率 `σ` 联系起来：

`κ / σ = L T` 其中 `L` 是伦兹数。

传导传热遵循傅里叶定律：

`q = -k dT/dx` 其中 `q` 是热通量，`k` 是热系数，`dT/dx` 是温度梯度。

材料的热导率取决于其温度、结构和化学组成。对于气体，热导率随温度升高而增加。对于液体，通常随温度升高而降低。对于固体，差异很大。在金属中，它通常随温度升高而降低，而在绝缘体中，它可能随温度升高而增加。
