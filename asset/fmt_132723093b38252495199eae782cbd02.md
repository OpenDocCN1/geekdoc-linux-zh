
`print "The Updated String: $String";`

当应用 `"e"` 修饰符时，正则表达式会将右侧（RHS）视为要进行评估的替换内容；在这种情况下，右侧是 `$1`，它保留了 `$var` 但没有保留其值。因此，应用 `"ee"` 修饰符将重新评估包含已求值值 `$var` 的右侧。

## 进行数学计算时，使用 "ee" 修饰符

如果字符串中包含数学表达式，该表达式的值将不会被评估，而是按原样显示。这是因为它被同时视为一个字符串和一个待评估的表达式。

# Perl 中的正则表达式

## 示例：

```perl
#!/usr/bin/perl

# 存储为字符串的数学表达式
$String = "1 + 2";

# 用于求和的正则表达式
$String =~ s/(\d+ [+*\-]) (\d+)/$1/ee;

print "Sum is $String";
```

上述代码中的表达式是用正则表达式编写的，使用 `"\d+"` 操作符表示一个或多个数字，使用 `"[++-]"` 字符类表示运算符，然后另一个 `"\d"` 表示数字。`"ee"` 修饰符评估了表达式的总和，并通过 `$1` 运算符显示出来。

上述正则表达式也可以保留在子程序中，用于评估不同的表达式，而无需重复编写正则表达式。

## 示例：

```perl
#!/usr/bin/perl

# 计算正则表达式的子程序
sub Regex {
  $var = shift;

  # 用于求和的正则表达式
  $var =~ s/(\d+ [+*\-]) (\d+)/$1/ee;
  return $var;
}

# 存储为字符串的数学表达式
$String1 = "1 + 2";

$String1 = Regex($String1);

print "Sum is $String1\n";
```

### 计算积

```perl
$String2 = "10 * 3";

$String2 = Regex($String2);

print "Product is $String2";
```

在给定的代码中，可以使用单个正则表达式利用子程序执行四次数学计算。

## 正则表达式中的 `pos()` 函数

Perl 中的 `pos()` 函数返回使用 `"m"` 修饰符的正则表达式中最后一次匹配的位置。

正则表达式中的 `pos()` 函数可以与字符类结合使用，返回字符串中所有所需子字符串的位置列表。对于整个文本中的子字符串，请使用全局操作符 `"g"` 配合 `"m"` 修饰符。

- **语法**：`pos(String)`
- **参数**：应用正则表达式后的字符串
- **返回值**：匹配的子字符串的位置

### 第一个示例：利用子字符串字符

```perl
#!/usr/bin/perl

# 打印子字符串位置的程序
$String = "Peeks For Peeks";

print "Position of 'P' in string:\n";

# 使用 m 修饰符搜索子字符串
while($String ~ m/G/g)
{
    # 使用 pos() 查找子字符串的位置
    $position = pos($String);
    print "$position\n";
}
```

### 第二个示例：利用字符类

```perl
#!/usr/bin/perl

# 打印子字符串位置的程序
$String = "Peeks For Peeks";

print "Position of all the Uppercase characters:\n";

# 使用字符类搜索
# 所有大写字母
while($String ~ m/[A-Z]/g)
{
    # 使用 pos() 函数查找子字符串的位置
    $position = pos($String);
    print "$position, ";
}

print "\nThe Position of all Lowercase characters:\n";

# 使用字符类搜索
# 所有小写字母
while($String ~ m/[a-z]/g)
{
    # 使用 pos() 函数查找子字符串的位置
    $position = pos($String);
    print "$position, ";
}
```

### 第三个示例：空格的位置

```perl
#!/usr/bin/perl

# 打印子字符串位置的程序
$String = "Peeks For Peeks";

# 搜索
# 所有空格
while($String ~ m/\s/g) {
}

# 使用 pos() 函数查找子字符串的位置
$position = pos($String);
print "$position\n";
```

要进行匹配，使用 `pos()` 函数：

```perl
$position = pos($String);

print "$position\n";
```

## 元字符

元字符在 Perl 正则表达式中用于匹配模式。必须避免所有的元字符。

| 字符 | 解释 |
| :--- | :--- |

| `*` | 匹配 0 次或多次。 |

| `?` | 匹配 0 次或 1 次。 |
| `()` | 用于分组。 |

| `{}` | 用于重复修饰符。 |

## 量词

这些用于检测特殊字符。量词分为三类：

- `?` 它匹配 0 次或 1 次字符出现。
- `+` 它对应字符出现 1 次或多次。
- `*` 当字符出现 0 次或多次时匹配。

| 使用量词 | 解释 |
| :--- | :--- |
| `a?` | 检查 `"a"` 是否出现 0 次或 1 次。 |
| `a+` | 检查 `"a"` 是否出现 1 次或多次。 |
| `a*` | 检查 `"a"` 是否出现 0 次或多次。 |
| `a[2,6]` | 检查 `"a"` 是否出现 2 到 6 次。 |
| `a[2, ]` | 检查 `"a"` 是否出现 2 次到无限次。 |
| `a[2]` | 检查 `"a"` 是否出现 2 次。 |

### 示例：

```perl
# 程序演示
# 正则中量词的使用
# 实际字符串

$str = "color";

# 如果在 $str 中找到匹配项，
# 则打印找到匹配
# 使用了量词?
if ($str ~ /colou?r/)
{
    print "Match is Found\n"
}
else
{
    # 如果在 $str 中未找到，
    # 则打印未找到匹配
    print "Match is Not Found\n"
}
```

## 分组与捕获

在正则表达式内部，这些组由“`1`”表示，而在正则表达式外部，它们由`"$1"`表示。这被称为捕获。这些组可以在列表上下文中获取变量。`(...)` 生成缓冲区和捕获组。

- `(...)` 用于分组和捕获。
- `\1`, `\2` 在正则匹配时，这些用于捕获。
- `$1`, `$2`, `$3` 在成功匹配时，这些用于捕获变量。
- `(?...)` 用于不捕获项目（这些 `$1` 或 `1`）。
