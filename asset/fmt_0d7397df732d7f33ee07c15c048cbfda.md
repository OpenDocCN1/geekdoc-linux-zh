# 用户错误

用户输入往往是代码中一个瘫痪性的错误。例如，当用户应该输入年龄数字时他们输入了字母。用户经常会输入此类内容导致缓冲区溢出，从而崩溃。观察那些用户输入并清晰说明需要什么。

```
输入一个整数

你输入了错误

你输入了错误

sdf22123123

2232n223

你输入了错误

数字是：12

返回 (0x0) 执行时间：2.49 s

按任意键继续。
```

# 安全数据

如果你正在编写处理或其他敏感数据的代码，请确保数据不是明文。在将敏感数据输入程序之前，学习创建一个加密敏感数据的函数，任何人都可以查看它。
