#### 24.3.2 尝试利用数据库

虽然单独的命令没有引起我们的担忧，但我们不知道 `shellcode` 在做什么。相反，我们将使用我们自己可控的内容替换 `shellcode`。漏洞利用中的参考指出使用了 `raptor.udf.c`。快速谷歌搜索发现了一个相关的 Exploit Database 条目 $^{\text{733}}$，且评论底部的一个注释提到了一个看起来非常有前途的 GitHub 项目 $^{\text{734}}$。
