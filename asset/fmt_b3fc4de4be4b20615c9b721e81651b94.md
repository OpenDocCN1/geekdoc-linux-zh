# 重复

对于几乎每个命令，都可以给出一个重复因子，指定执行的频率。

例如，`5dw` 删除五个单词，`3fe` 将光标移动到字符 `e` 的第三次出现处。

甚至插入操作也可以通过这种方式重复，例如，插入 50 次相同的行。

# 使用区域 (Regions)

在命令行模式下，你可以对大多数命令使用区域，这会将命令限制在相应的行上。

例如，`:3,7d` 删除第 3 到第 7 行。

区域通常配合替换命令 `:s` 使用；例如，`::$/old/new/g` 执行从当前行到行尾的替换。
