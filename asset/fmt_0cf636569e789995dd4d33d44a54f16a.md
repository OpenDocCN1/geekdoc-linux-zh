
## Linux 提供出色的投资回报率（ROI）

按座位计几乎没有或没有成本。与商业操作系统不同，`Linux`没有版税或许可费用，单个`Linux`发行版在`CD-ROM`或网络共享文件夹上即可成为企业范围软件分发的基石，包含应用程序和生产力软件。可以轻松制作定制的企业`CD-ROM`，或创建网络共享以在企业范围硬件上提供特定安装。仅此一项功能就能节省数十万甚至数百万美元的`IS/IT`成本——而且无需担心来自商业软件垄断的软件审计，或对基础操作系统安装进行许可核算和控制的需要。

## Linux 可用于桌面

`Linux`结合其支持的图形网络协议和界面（`X Window System`），自1990年代中期以来一直作为消费级类`UNIX`桌面操作系统运行良好。`UNIX`已准备好用于消费桌面这一事实，现在随着`Apple Computer`基于`BSD UNIX`的`Mac OS X`的推出、采用和快速成熟而得到证实——据`Apple`称，已有超过3,000个被称为原生应用程序的`Mac OS X`特定程序得到支持。本书光盘包含超过800个软件包，包括`Internet`连接实用程序、游戏、完整的办公套件、许多不同字体和数百个图形应用程序。

## Linux 可作为服务器平台使用

`Linux`速度快、安全、稳定、可扩展且健壮。`Linux`内核的最新版本可轻松支持多处理器计算机、大量的系统内存（最高达64`GB RAM`）、单个文件大小超过数百`GB`、多种现代日志文件系统、数百个进程监控和控制实用程序，以及（理论上）同时支持超过四十亿用户的能力。`IBM`、`Oracle`和其他主要数据库厂商都为`Linux`提供了其企业软件版本。

## Linux 具有低进入和部署成本门槛

维护成本也可以降低，因为`Linux`在各种`PC`上运行良好，包括一些基于`Intel`的`486`和早期`Pentium CPU`等旧硬件。虽然最佳程序性能将通过更新的硬件实现，但由于客户端可以为`Pentium`级`CPU`重新编译和优化，因此即使在仅有8`MB RAM`的低端计算机或嵌入式设备上也可以进行基础安装。此功能可提供更广泛的用户群；延长旧工作硬件的使用寿命；并可帮助家庭、小型企业和企业用户节省资金。

## Linux 在硬件和软件行业吸引了广泛的受众

几乎所有`CPU`都有`Linux`版本。嵌入式系统开发人员现在在利用`ARM`、`MIPS`和其他低功耗处理器构建定制解决方案时转向`Linux`。`Linux`是英特尔`Itanium CPU`可用的第一个完整操作系统，也是`AMD64`系列`CPU`的操作系统；`HP/Compaq`的`Alpha`和`Sun Microsystems SPARC CPU`的移植也已提供一段时间。`PowerPC`用户定期在`IBM`和`Apple`硬件上使用`Linux`的`PPC`端口。

## Linux 为跨平台开发提供免版税的开发平台

由于开源开发模式和免费高质量开发工具的可用性，`Linux`为有抱负的开发人员和科技行业初创企业提供了低成本的切入点。

## 来自 IBM 等计算机硬件行业巨头的强力支持

现在使`Linux`作为可行平台更具可信度——`IBM`已在其整条计算机产品线上启用`Linux`，从低端笔记本电脑到“大型机”大型主机。新的企业客户正在排队并将`Linux`用作企业级计算解决方案的一部分。它已用于世界上一些最快的计算机，包括`IBM`的`Blue Gene/L`。`HP`也在其大量硬件产品中认证了`Linux`。

随着使用范围在全球范围内向所有层级企业传播以寻求更低成本、更好性能以及稳定和安全的实现，期待获得更多支持。

## 什么是 Ubuntu？

`Ubuntu`是一个基于`Linux`内核的操作系统；由`Ubuntu`社区在`http://www.ubuntu.com/`上创建、改进、完善和分发。`Ubuntu`由`Canonical Software`赞助，是一个由全球软件开发人员社区支持的开源项目。

## Ubuntu 的根源

`Ubuntu`是目前可用的较新的`Linux`发行版之一，于2004年10月发布了第一个版本。它迅速获得了安装和使用简便的声誉，同时每个版本都带有略显古怪的代号。然而，`Ubuntu`本身是基于`Debian`的，而`Debian`是一款历史悠久的发行版，在更广泛的`Linux`社区中享有极高的尊重。`Ubuntu`建立在`Debian`之上，它所建立的基础之上，这是一种很好的描述方式来描述两者之间的关系。还值得注意的是，`Debian`因发布不频繁而闻名。从`Debian 3.0`到`3.1`的迁移几乎花了三年时间，在此期间，许多其他`Linux`发行版已远远领先于`Debian`。

## Ubuntu 版本

如前所述，自2004年10月首次发布以来，`Ubuntu`为其发行版选择了一些奇特的代码名称。摒弃了其他地方常见的典型版本号，`Ubuntu`决定采用发布月份和年份并将其倒序排列。因此，2004年10月的首个发布版成为`4.10`，随后很快推出`5.04`（2005年4月）、`5.10`、`6.06LTS`、`6.10`、`7.04`和`7.10`。

本书所涵盖的版本于2008年4月发布，因此版本号为`8.04`。更特别的是，此次发布还带有`LTS`（长期支持）标签，这意味着`Canonical`将在发布后为桌面版提供三年支持，服务器版总共支持五年。

代码名称甚至更好：`4.10`被命名为`Warty Warthog`，以承认这是首个发布版，瑕疵俱全。第二个发布版`5.04`被称为`Hoary Hedgehog`。`5.10`的情况稍有好转，代号为`Breezy Badger`。`6.06`被宣布为`Dapper Drake`，也是首个带有`LTS`徽章的`Ubuntu`发行版。`Dapper`之后是`Edgy Eft`（`6.10`），随后是`Feisty Fawn`（`7.04`）、`Gutsy Gibbon`，以及现在我们要介绍的`Hardy Heron`（`8.04`），本书即涵盖此版本。

## Ubuntu 用于企业

`Linux`多年来不断成熟，被认为在企业级环境中必不可少的特性，例如`CPU`架构支持、文件系统和内存处理，已被添加并改进。虚拟内存（将部分`RAM`交换到磁盘的能力）的加入是首批必要的要素之一，同时还有`TCP/IP`栈的免版权实现（主要由于当时`BSD UNIX`陷入法律纠纷）。其他特性也迅速跟进，例如对多种网络协议的支持。

`Ubuntu`包含可使用多处理器的`Linux`内核，这使你能够在对`CPU`性能要求更高的高级计算环境中使用`Ubuntu`。该内核至少支持16个`CPU`；实际上，小型企业服务器通常仅使用双`CPU`工作站或服务器。然而，`Ubuntu`可以在更强大的硬件上运行`Linux`。

`Ubuntu`将自动支持你的多`CPU`英特尔主板，你将能够利用对称多处理器（`SMPs`）的优势进行软件开发和其他操作。`Ubuntu`包含的`Linux`内核可使用高达64`GB`的系统`RAM`，允许单个文件大小超过2`GB`，并可承载——理论上——数十亿用户的需求。

依赖高可用性、大规模系统的企业也可以由`Ubuntu`服务，同时还能获得来自全球数百家支持合作伙伴提供的专业商业支持。

然而，`Ubuntu`可以在许多这些环境中使用，满足客户截然不同的计算需求。`Ubuntu`的一些应用包括桌面支持；小型文件、打印或邮件服务器；局域网`Web`服务器；以及部署在公司局域网内部和外部战略位置的安全防火墙。

商业客户还将受益于`Debian`与多家顶级系统制造商的联盟，包括惠普。

`Debian`本身也适用于多种架构，并且直到最近一直并行在11种不同架构上开发，从`x86`到较旧的摩托罗拉`680x0`芯片（如`Commodore Amiga`所用），以及其他几种架构。

小型企业主可以通过摆脱软件许可和升级的循环，采用基于`Linux`的解决方案获得丰厚回报。使用`Ubuntu`不仅避免了许可核算和软件审计的威胁，还为许多类型的商业生产力软件提供了可行的替代方案。

在小型企业环境中使用`Ubuntu`还有其他诸多好处，例如无需投资尖端硬件即可建立高效的工作环境。`Ubuntu`轻松支持旧的或遗留硬件，随着时间的推移，避免不必要的硬件升级可带来累积的节省。此外还会实现额外节省，因为软件和升级都是免费的。应用程序的新版本可以以零或极低成本下载和安装，办公套件软件也是免费的。
