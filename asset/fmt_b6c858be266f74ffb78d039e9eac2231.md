# 50 第3章 类型与对象

## 作为可调用对象的类和实例

类对象和实例也可以作为可调用对象操作。类对象是由 `class` 语句创建的，并作为一个函数存在，用于创建新实例。在这种情况下，传递函数的参数会被传递给类的 `__init__` 方法，以初始化新创建的实例。如果实例定义了特殊方法 `__call__`，则实例可以模拟函数。如果实例 `x` 定义了该方法，那么 `x(args)` 就会调用方法 `x.__call__(args)`。

## 类、类型与实例

当你定义一个类时，定义通常会产生一个类型为 `type` 的对象。这是一个示例：

```python
>>> Foo(object):
    pass
...
>>> type(Foo)
<class 'type'>
```

下表显示了类型 `t` 的常用属性：

| 属性 | 描述 |
| --- | --- |
| `t.__doc__` | 文档字符串 |
| `t.__name__` | 类名 |
| `t.__bases__` | 基类元组 |
| `t.__dict__` | 存储方法和变量的字典 |
| `t.__module__` | 定义类所在的模块名 |
| `t.__abstractmethods__` | 抽象方法名称集合（如果没有抽象方法，则可能未定义） |

当创建一个实例时，该实例的类型就是定义它的类。这是一个示例：

```python
>>> f = Foo()
>>> type(f)
<class '__main__.Foo'>
```
