
```
earth:~ # fuser -k /dev/lp0
```

对 USB 打印机实现相同操作，输入：

```
earth:~ # fuser -k /dev/usb/lp0
```

- 4. 通过关闭电源对打印机进行完全重置。在将纸回托盘并开启设备之前等待几秒。打印机应该准备好接受新任务。
