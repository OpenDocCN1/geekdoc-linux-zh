## 冻伤

在冻伤中，身体内部温度降低，但同时也发生了结冰。在冻伤中，如果手指或肢体发生结冰，局部组织会受到冷却损伤。在预冻阶段，皮肤温度处于 37–54°F（2.8–4°C），冰晶在细胞外形成，循环受限，随着细胞膜破裂发生细胞死亡。一旦它们冻结并融化，可能会受到寒冷引起的不可逆的损伤，并更容易发生冻伤。身体的任何部分都可能冻伤，但手指、脚趾、耳朵和鼻子往往受影响最大。

# 同自旋 (I-spin)

这是一个量子力学变量或量子数，应用于夸克和流子（强相互作用的基本粒子）、强子以及强子的组成部分（如核子），以便考虑强相互作用的电荷无关性。例如，在负电电子的量级上，形成一个三个同位素、同自旋和同自旋的状态。

观测到强相互作用粒子（强子）和粒子组成部分（如核子）形成组或多重态，这些多重态的成员在电荷、磁矩以及自旋等其他属性上存在差异。例如，电子、质子和中子的电荷分别为0和1（以电子电荷量级为单位），形成了一个两个状态的集合。介子其中一个自旋为零，两个自旋为一，形成了一个三个状态的集合。

似乎，如果电磁力和与其密切相关的力小于强相互作用，则多重态的不同成员是等价的，在相互作用中无法区分。相互作用独立于相互作用粒子所带电荷对于；它们具有电荷无关性。基本基本相互作用；强核相互作用。

一组或一个多重态粒子的同自旋定义为满足方程 $I = N/2$，其中 $N$ 是状态数：

$N = 2I+1$

状态。另一个量子数 $I_3$，也称为同自旋的第一分量，通过以电荷为单位从 $+I$ 到 $-I$ 的 $I_3$ 值来区分多重态的成员。电荷 $Q$ 和 $I$ 的值通过盖曼-奥库波关系联系起来；方程 (2)，其中：

$Q = I_3 + Y/2$

该电荷被称为超电荷。对于核子来说，$I_3$ 只是中子的数量。电荷在相互作用中是守恒的。观测到，在粒子之间的强相互作用作用中，同自旋 $I_3$ 是守恒的。

这种对同自旋粒子的描述与具有角动量 $J$（以普朗常数为单位）的粒子的量子力学描述相似，它取决于所选择的量子化轴。在一个各向同性或自旋 $J$ 复合的状态集中，$M_J$ 的值以1为单位从 $-J$ 到 $+J$ 变化。这表明局部宇宙是各向同性的（或给定方向的角动量轴是守恒的），并且不同的 $J$ 值在动力学上守恒。

具有不同 $I$ 值和不同 $J$ 值的粒子多重态描述 (1) 与关于方向无关力的具有确定自旋和 $J$ 的粒子多重态描述 (2) 之间存在逻辑或数学上的等价性。在多重态的每个成员中，相应成分的值不同。例如，一方面的守恒量 $I_3$ 和另一的 $I_0$ 在动力学上是等的；也就是说，通过对所述力的任何应用无法区分它们。角动量；自旋；对称。

## 板足鱼

*Ichthyostega* 是四足脊椎动物（基部四足类），起源于晚期泥盆纪（4亿至3.5亿年前）的肉鳍鱼祖先[参见图示]。板足鱼是泥盆纪的第一种四足类动物，发现于格陵兰东部。在几十年里，它是科学界已知“鱼类到四足类”过渡阶段的唯一代表。随后，在同一地层中发现了第二个属——*角足鱼*（*Acanthostega*），并在20世纪90年代在世界其他地区发现了泥盆纪的四足类动物。

![](img/b16805e6127c92641547ee45e5728f7f_1134_0.png)

与极早期脊椎动物不同，板足鱼具有一个较小的复合外壳（颅骨），带有包含大脑的顶盖（脑壳）。它表现出极不寻常的特征，尤其是在耳朵区域，这些特征难以解释，且与任何其他分类群都不相似。

后体骨骼显示出一些原始且非常详细的特征。尾部带有一排鳍状射线，这些射线在除角足鱼以外的其它早期四足类动物中也可见。每根肋骨都与一个发育良好的关节相；肋骨是许多重叠的叶片，在身体周围形成了一个笼，并为其提供了刚性。

骨带足够大，能够支撑与身体成直角关节的后肢。骨带很宽，髋窝深陷，表明其参与了四足类动物的运动。股骨很大，约占股骨长度的一半，后肢呈桨状，带有指、趾和踝骨，且宽且扁平。脚趾也发育良好。

## 火成岩

是由熔融物质冷却形成的岩石。它们根据形成条件，可能由晶体或颗粒组成。熔融岩被称为岩浆；当它从其来源的地球喷发时，被称为岩浆。液态岩石的流动发生在地下孔隙中。在深处，岩浆穿过地壳上升，并在地球表面或海底以火山岩或喷出岩的形式喷发。在表面冷却速度很快。

在地下，它由于上覆岩石的隔离而缓慢冷却；形成较粗的构造。在深处形成的火成岩（浅成岩）表现出处于火山岩和深成岩之间的中间特征。构造取决于均匀聚集体内部岩石成分的相互关系。它取决于晶体与无定形（玻璃态）物质的相对含量，以及成分的大小、形状和排列：岩石构造具有高度意义；它们揭示了岩石的问题，反映了大量岩石形成的条件和环境。

火成岩的分类方案众多。主要使用三种分类方法：(1) 宏观分类法，基于放大镜观察到的岩石外观。此类方案在野外研究中非常有用。(2) 微观分类法（通常是矿物学的），用于实验室提供详细信息。(3) 使用化学分类法，但提供的信息少得多。岩石的矿物含量和构造通常比整体化学分析能提供更多关于岩石起源的信息。

深成岩形成于大型侵入体（岩基、岩脉和其他形式）。它们通常被称为深成岩。它们由缓慢冷却的大量岩浆产生。

火山岩以火屑岩（火山灰和颗粒物质的异质堆积）的形式形成。它们形成迅速，逸离水分的膨胀气泡经常产生高压结构。

浅成岩表现出介于火山岩和深成岩之间的特征。它们与火山岩的区别在于自由晶体和气孔较少。它们与深成岩的区别在于它们形成于较小的物体（岩脉和岩席）或层状。它们的密度较低，并具有由更快速冷却形成的特征。

火成岩可分为初级或次生级。原生矿物通过岩浆的直接化学变化形成。原生矿物可能较少，可能是浅色（长石质）或深色（镁铁质）。长石质矿物富含长石。

次生矿物通过向岩石添加物质或在水存在的情况下改变现有成分形成。这是常见且普遍的。原生矿物如下：

| 原生矿物 | 次生矿物 |
| :--- | :--- |
| 石英 | 未改变 |
| 长石 | 高岭石 |
| 钾长石 | 紫苏石（副长石）、绿帘石、沸石 |
| 辉钠石 | 钙钠矿、斜长石 |
| 锂辉 | 辉钠石和钾长石 |
| 钠钠 | 分析石、钙铁钠 |
| 黑云母 | 绿泥石、闪石、金钛 |
| 角闪石 | 闪石、黑云母、绿泥石、绿帘石 |
| 钙钠 | 紫苏石、反钙石、滑石 |
| 斜辉 | 蛇纹石、铁矿石、滑石 |
