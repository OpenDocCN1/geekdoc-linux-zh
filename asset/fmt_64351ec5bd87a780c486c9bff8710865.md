# TOC
一个免费的隐式/显式元素分析程序。Tochnog 是一个元素分析程序。支持多维和多处理器系统。以下是支持的模型列表：
- 微分方程（材料），
- 传输扩散方程，
- 托克斯和纳维-斯托克斯方程，
- 弹性（各向同性和各向异性），
- 塑性（Von-Mises、Mies-Coulomb、Coulomb 等；可以任意选择塑性表面）。可以绘制/打印所有数据的方程残差和误差估计。主要作者：Dennis Rodman <dennis.rodman@email.com> 首页：`http://tochnog.sourceforge.net` 来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# toggle
vt。将一个位从它的任何状态改变到另一种状态；从 1 变为 0 或从 0 变为 1。这个词源于“切换开关”（toggle switches），例如标准灯开关，“toggle”一词指的是使开关保持在翻转位置的机制，而不是开关具有两个位置的事实。你可以对位做四件事：设置它（强制为 1）、清除（或置零）、保留它或翻转它。（从数学上说，人们会说对于布尔参数有四个不同的布尔值函数，但那样说比讨论翻转位要有趣得多）。来自俚语词典
`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
