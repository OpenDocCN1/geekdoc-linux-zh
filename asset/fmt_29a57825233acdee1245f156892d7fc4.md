
# Linux 词典

## Fortran 90
`FORTRAN 77` 的广泛更新。`Fortran 90` 拥有所需的类型、数组段、返回数组、语句、模块和子程序、递归以及动态分配。来自 Linux Guide@First `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## 幸运文件 (fortunes)
此包包含了超过 1500 个“幸运”信息。你需要 `fortune-mod` 包来显示这些信息。来自 Debian 3.0r `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## FORWI

## 工具集 (forutil)
`FORTRAN 77` 工具集。`ForUtil-0.6` 是一个分析 `FORTRAN` 代码的实用工具。`ForUtil` 中每个程序的简要描述如下：`flow`，一个 `FORTRAN` 生成器——参数检查器；`scan`，一个子程序计数器；`tags`，一个用于 `vi` 的 `FORTRAN` 文件生成器。这些三个工具允许对常见的 `FORTRAN` 文件的数据库进行检查和搜索。它们是：`scan_commons`，用于创建数据库；`list_commons`，数据库的内容或存储在数据库中的所有文件；`get_common`，快速搜索数据库查看哪些文件是常见的。来自 Debian 3.0r `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

## fp-compiler
Free Pascal 编译器。Free Pascal 编译器（Free Pascal 编译器）是一个 Turbo Pascal 7.0 和 Delphi 32位 Pascal 编译器。它附带了完全与 FP 7.0 兼容的运行时库。该语言还增加了一些扩展，如函数重载。可以链接并创建共享库。已经实现了基础的 Delphi 支持（类、异常、ansstring）。此包包含命令行编译器。在开始任何操作之前，你至少需要 RTL 运行包。来自 Debian 3.0.0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

## fping
向网络主机发送 ICMP ECHO_REQUEST 数据包。`ping` 是一个使用互联网控制消息协议 (`ICMP`) 回请求来确定目标主机是否有响应的程序。`fping` 与 `ping` 的区别在于你可以在命令行上指定任意数量的目标，或一个包含 ping 目标列表的文件。`fping` 不是向一个目标发送直到超时或响应，而是会发送数据包并以轮询方式处理下一个目标。来自 Debian 3.0.0 APT `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`
