
4. 点击主工具栏上的“快速渲染”（`Quick Render`）工具查看目前模型的效果。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_549_2.png)

你已经学习过辐射光度（`radiosity`）是一种在计算机中模拟光行为的方法。更具体地说，它是模拟模型中材料反射特性的方法。为了实现这一点，模型中的表面被划分为称为“元素”的小区域。`VIZ` 使用这些元素来计算光从一个表面到另一个表面的反射。图 11.6 为你展示了模型中的元素是如何模拟反射光行为的。

### 图 11.6

辐射光度渲染使用网格元素来帮助确定模型内的光反射。从一个元素反射的光会照亮其他元素。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_551_0.png)

`VIZ` 创建元素网格；然后计算每个元素的反射特性。在创建最终渲染图时，会考虑网格元素的反射特性，从而在你的模型表面创建出细微的光照效果。

在辐射光度解决方案中，这些元素的网格被称为辐射光度网格（`radiosity mesh`）。创建辐射光度网格时，可以在线框视图中看到一系列三角形面的结果。这些不要与构成物体几何结构的实际面混淆；它们仅作为辐射光度的一部分存在模型中。

网格元素的大小是可以控制的，稍后你将会看到。你希望控制网格大小，是因为如果元素过于密集，辐射光度解决方案的计算将花费太长时间。如果元素太大，辐射光度解决方案将不够精确，无法生成良好的渲染。你需要确定元素的大小，在生成辐射光度解决方案的时间与解决方案质量之间取得良好平衡。1 米（约 3 英寸）的默认尺寸是一个通用尺寸。

辐射光度网格的另一个特性是，你可以决定模型中的哪些对象被分配网格。你不需要为整个模型分配辐射光度网格；事实上，你不想对所有内容应用网格，那会减慢辐射光度解决方案的处理。根据经验，你应该对场景中反射光影响最大的对象应用辐射光度网格。地板和墙壁无疑是网格的理想选择，而扶手、窗棂和小物体则不是。

## 选择网格对象

要确定哪些对象被应用于辐射光度解决方案，你需要使用图层管理器（`Layer Manager`）对话框。你可能记得第 6 章中提到，可以通过图层管理器对话框控制对象的组织、颜色和可见性。这里也是你控制对象被用于辐射光度解决方案的地方。下面的练习将展示如何操作。为了获得场景中反射光更真实的模拟，你将应用全局网格（`global mesh`）。首先，你将排除对场景中反射光影响最小的较小对象。从网格中排除这些较小对象可以节省辐射光度处理时间。

1. 点击主工具栏上的图层管理器按钮。

2. 在图层对话框中，点击图层 0 左侧的 (+) 号。列表展开，显示场景中所有对象的名称。

3. 选择四个 `MULLION` 对象。这些对象在列表中应以黄色高亮。

## 组织图层

点击图层工具栏正下方的图层列标题，按名称字母顺序组织图层。对象的顺序是数字，接着是大写字母，然后是小写字母。

4. 对于任何 `MULLION` 图层，在 `Radiosity`（辐射光度）列中双击相应的图标。图标在第一次点击时变为圆点，第二次点击时变为灰色图标。这将从辐射光度解决方案中移除选中的对象。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_552_0.png)

## 选择正确的辐射光度图标

点击两次图标以出现灰色的辐射光度图标是非常重要的。如果你让它保持为点，列表顶部的主层设置将控制缩进对象的行为。

5. 向上滚动列表并选择 `Ground`；然后像处理 `MULLION` 对象一样关闭 `Ground` 对象的辐射光度设置。这是一个从辐射光度解决方案中移除的重要对象，因为由于其尺寸，它会大大增加导出解决方案的时间。

6. 最后，关闭三个 `STAIR.0x` 对象以及列表底部附近的窗棂框的辐射光度设置。

7. 关闭图层对话框。

## 使用网格选项获取辐射光度解决方案

你刚刚关闭了几个对象的辐射光度设置。下一步是生成另一个辐射光度解决方案，但这次你将开启全局网格（`global mesh`）选项：

1. 回到渲染场景（`Render Scene`）对话框的高级（`Advanced`）选项卡；然后打开辐射光度网格参数（`Radiosity Meshing Parameters`）展开节。

2. 点击 `Enabled`（启用）框以启用辐射光度网格。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_553_0.png)

3. 点击辐射光度处理参数（`Radiosity Processing Parameters`）展开节顶部的 `Reset All`（重置所有）按钮。

4. 将 `Initial Quality`（初始质量）更改为 `65%`。这将减少时间。

5. 点击 `Start`（开始）按钮。

这将需要一些时间。在生成解决方案时，你会看到 `Radiosity` 条。在第 4 步中你降低了初始质量。处理完成后，你会发现主视口没有变化。如果你仔细观察，你会看到建筑上的辐射光度。

### 图 11.7 开启网格后生成辐射光度解决方案的主视口

![](img/7e143440dd5a0ed9683d4f26f3c074f8_553_1.png)

主视口看起来好了一些，但图像中仍有一些扭变。尝试以下操作获得更好的效果：

1. 选中主视口后，点击 `Maximize Viewport`（最大化视口）将其放大。柱子和窗棂看起来扭曲了，天花板呈现斑点。

2. 点击主工具栏上的快速渲染（`Quick Render`）工具。渲染也有类似的扭变，如图 11.8 所示。

## 改进辐射光度解决方案

你看到的扭变是质量设置过低的结果。还注意到渲染视图比视口暗一点。在下一个练习中，你将完善辐射光度解决方案以获得改进的渲染。顺便，你可以调亮场景以显示更多的室内空间。

1. 如果必要，打开环境和效果（`Environment and Effects`）对话框（按下键盘上的数字 8），在对数曝光参数（`Logarithmic Exposure Parameters`）展开节中，将 `Brightness`（亮度）设置更改为 `30`。

2. 在渲染场景对话框的辐射光度展开节中，将 `Initial Quality` 更改为 `80%`，然后点击 `Update & Start` 按钮。你不应该更改任何内容，因为模型的几何结构或光线都没有变化，而且你还没有渲染场景。如果弹出对话框指示需要重置，点击 `Yes`。处理完成后，你会发现主视口没有变化。

3. 再次渲染视图。这次天花板开始变得均匀，但柱子仍然不对。

4. 回到渲染场景对话框，将 `Refine Iterations`（所有对象）更改为 `1` 以增加渲染过程的视觉质量；然后点击 `Update & Start` 按钮，并在重置辐射光度解决方案对话框中点击 `Yes`。

这一次，示例图像有了明显的改进。

5. 再次渲染视图。现在场景看起来更真实了，柱子看起来很平滑。然而，天花板看起来仍然有些斑驳。

6. 在“渲染场景”（`Render Scene`）对话框的“交互工具”（`Interactive Tools`）组中，将两个光线过滤（`Light Filtering`）选项都改为 `1`。这些选项会取消表面的光照处理。

| 交互工具 | |
|---|---|
| 间接光过滤 | 1 |
| 直接光过滤 | 1 |
| 对数曝光控制: | 设置 |
| 在视口中显示辐射辐射度 | |

请注意，你可以在 `My camera` 视口中立即看到此设置的结果。

7. 第三次渲染视图。现在渲染包含的畸变更少，如图 11.9 所示。

### 图 11.9

设置细化迭代（所有对象）（`Refine Iterations (All Objects)`）和过滤（`Filtering`）参数为 `1` 的渲染视图

![](img/7e143440dd5a0ed9683d4f26f3c074f8_555_0.png)

这一次，你在“渲染场景”对话框的辐射部分使用了一些新设置。首先，你将初始质量（`Initial Quality`）设置改为 `80`。对于大多数渲染来说，这是一个很好的设置；除非是为了最高要求的演示，否则你不需要将其设置得太高。

接下来，你将细化迭代（所有对象）（`Refine Iterations (All Objects)`）设置改为 `1`。此选项通过考虑周围环境的光能来提高表面光照的平滑度。细化迭代（所有对象）下方的选项是细化迭代（选定对象）（`Refine Iterations (Selected Objects)`）。如名所示，此选项作用于选定对象而不是整个场景。要使用它，选择场景中你想要细化迭代的对象，然后设置细化迭代（选定对象）选项。在复杂场景中，这可以帮助节省时间，因为你只需要细化需要的对象。

你做的第三个设置是增加“交互工具”组中的过滤（`Filtering`）设置。该设置对元素之间的光照水平进行平均处理，以减少辐射的斑驳效果。你可以将此值增加到 `3` 或 `4`，但不建议使用更高的值。
