## dsniff

各种嗅探网络流量以寻找明文不安全的工具。此包包含几个用于监听和创建网络流量的工具：
- arspoof – 发送未请求的（可能是伪造的）ARP 复。
- dnsnoop – 伪造回答局域网内的 DNS 属性/查询。
- dsniff – 针对多种协议的密码嗅探器。
- filesize 从 NFS 流量中选择选择的文件。
- macof – 使用随机 MAC 地址泛洪局域网。
- mailsnarf – 嗅探局域网流量并以 mbox 格式存储。
- msgranaf – 记录选定的消息从

# Linux 词典

不同的即时通讯工具。
* sshmit – SSH 中间人攻击（monkey-in-the-middle）。代理并嗅探 SSH 流量。
* show – SSH 流量分析器。
* tcpkill – 杀死正在进行中的 TCP 连接。
* tprice – 通过“流量”整形减慢 TCP 连接。
* urlsonar – 从 CLF 格式的 HTTP 流量中输出选定的 URL。
* webmit – HTTP / HTTPS 中间人攻击。透明化操作。
* webspy – 将客户端内的 URL 发送到你的本地浏览器中。请勿滥用此软件。此文源于 Debian 3.0r3
