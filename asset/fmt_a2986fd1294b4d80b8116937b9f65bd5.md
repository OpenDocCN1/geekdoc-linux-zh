
一个经常需要将数据作为 URL 的一部分发送。因此，URL 包含了将二进制信息“编码”为文本字段一部分的能力。关键点：这种编码机制可以用于通过 Web 协议更改黑客攻击的签名。此类编码可用于规避无法“规范化” URL 的入侵检测系统的检测：微软在其 ASP 服务端脚本的 Web 服务器中，黑客可以丢弃 URL 的末尾以读取脚本内容而不是执行脚本。微软创建了一个补丁，但黑客很快就能通过对点进行 URL 编码来规避补丁（在丢弃部分的末尾修改 `%2e` 而不是点）。示例：`http://www.roberthams.com/sample.asp` 正常 URL `http://www.roberthams.com/sample.asp` 这种编码可以规避检测。

### USENET
一个全球范围内的讨论组系统，在数以万的机器之间传递评论。并非所有 USENET 机器都连接到互联网。USENET 是完全去中心化的，拥有超过10000个讨论区域，称为新闻组（newsgroups）。源自 Matisse

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### USENET
点：传输 USENET 消息的协议称为 `NNTP`；键：USENET 死亡协议 (`http://www.spam.org/usenet/faqs.html`) 经常应用于 `NNTP` 服务器以停止垃圾邮件泛滥。对于 ISP 允许用户发送大量垃圾邮件或允许其服务器被劫持是开放。由于这些原因，许多 ISP（尤其是高速电缆调制解调器和 DSL 提供）会禁止寻找未经授权 `NNTP` 服务器的客户。争议：USENET 因其分布式特性对互联网构成了挑战。它允许匿名发布无法追溯到源头的材料。这挑战了知识产权的历史性概念以及如何保护这些产权。例如，当 RC2 和 RC4 发布到 USENET 时，它们停止了商业机密。源自 黑客词典 (`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`)

### UseNet
这是一种分布式公告板，广泛存在基于 UNIX 的计算机系统中，并通过互联网和其他计算机网络连接。UseNet 每天有超过 1500 万人在 100 多个国家访问。UseNet 内部包含每个可以想象到的主题（以及你未想到的主题）的讨论组（新闻组）。每个新闻组专注于一个特定主题，例如跑车、火器、美国历史、模型飞机、政治或爵士乐。代表性强的主题是政治、科学学科和当前辩论的话题。UseNet 用户可以阅读并回复已发布的消息。源自 QUEDIC

`http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
