
Linux 操作系统内的所有应用程序都通过程序或脚本执行。脚本是一组通过脚本控制执行的命令列表。

在命令行接口中常用的文本编辑器是`vi`。`vi`程序允许用户编辑任何Linux文件，包括二进制文件。学习`vi`程序对Linux管理至关重要。Linux的图形用户界面abound（丰富多样）。这些提供了图形用户界面操作系统的所有功能。对于初学者来说，使用鼠标进行点击操作比使用更传统的命令行`vi`程序更容易。

### 软件包

Linux操作系统得名于Linux内核。整个操作系统由许多其他程序组成，这些程序的功能从提供用户界面到从远程时间服务器获取时间不等。这些程序以软件包的形式呈现，以便安装到你正在使用的特定Linux发行版上。

在Linux操作系统中，`软件包`一词指的是打包成归档文件并准备好安装的应用程序。本节从一般意义上讨论软件包，但详细讨论了`Red Hat Package Manager (RPM)`。许多Linux安装使用`RPM`，包括`Red Hat`、`SuSE`、`Mandrake`等。

#### 软件包概念

软件包是文件的归档。Windows中归档文件通常使用`zip`格式。Linux软件包在功能上与此类似，但在实现上略有不同。例如，`RPM`文件在安装时会首先检查以确保依赖项已就位。换句话说，`RPM`软件包会先检查其依赖的所有文件是否已安装。

软件包含有预编译的软件，可在Linux操作系统上随时安装；然而，一些Linux应用程序是以源代码形式分发的。源代码在能在Linux系统上运行之前，必须编译为二进制代码。软件包是针对不同的Linux发行版版本编译的，并准备好安装。预编译的程序通常比源代码小，使其更容易通过网络传输。

如果没有针对你的特定计算机和操作系统配置的软件包，你就必须编译程序，然后将它们安装到正确的位置。如果你后来决定更新程序，则取决于你自己确保所有文件都已更新、位于正确位置且未重复。

二进制文件编译用于与特定的计算机资源配合工作。资源包括处理器和系统库。处理器采用独特的微码设计，控制计算机系统的功能。每种处理器类型都必须使用专为该处理器设计的系统库来编译源代码。

管理员日常工作中最重要的一项任务之一就是管理软件包。当发布新的程序更新时，管理员必须找到该程序，确定版本，并在需要时安装更新。软件包和软件包管理程序使管理软件的工作变得更加容易。

### 软件包格式

大多数程序由许多文件组成，包括文档文件、支持文件和程序文件。当只有少数文件时，在传输过程中将所有文件保持在一起是容易的，但随着使操作系统能够提供更多服务的新型计算机资源出现，程序变得非常大。为了减轻管理员“跟上”变化的负担，所有这些文件都被合并到一个单一容器内，其工作原理类似于文件系统上的子目录。合并的文件通常会被压缩，以减少所需的磁盘空间并使其更容易通过网络传输。

这些压缩容器被称为软件包。单个软件包可以包含一个甚至数百个文件。你的Linux安装可能包含上百个软件包。

有几种软件包格式。一些软件包是Linux发行版专有的，如`RPM`和`DEB`（`Debian GNU/Linux Package Manager`）。另一些则适用于所有发行版，如`TAR`、`GZ`和`TAR.GZ`。

常见的软件包格式更难管理。基本上，所有这些打包工具所做的只是对应用程序进行打包和压缩。当应用程序从`TAR`、`GZ`或其他通用软件包中安装后，用户仍需要做大量工作才能使应用程序正常工作。关于软件包的信息，如版本号和编译日期，必须由管理员手动维护。
