
# 质量控制

质量控制确保制造的产品、单个组件和组件组件符合其预期用途。检查和测试是质量控制的执行部分，也是生存中最重要的因素。

质量检查可以分为两类：接触式和非接触式。检查方法使用使用表或其他设备来检查项目是否符合对象的设计或目的。这些方法主要用于制造业。坐标测量、柔性检查系统和非接触式检查是最广泛使用的。

检查和测试在生产前、期间和后进行，以确保产品质量在可的设计标准范围内。

检查是检查产品的活动或测试是一个程序，以确定观察到的项目是否符合设计标准，或是否能为特定目的正常运行。参见控制（CONTROL）。

质量控制直接支持成本、生产力、交付和市场份额的其他因素。因此，生产产品组件并确保其组装的所有质量标准必须以满足客户预期的方式进行，并包括以客户为中心的服务。质量竞争压力迫使制造公司交付更高质量的产品和服务。

在统计控制中，使用从项目群体中提取的样本来管理质量。项目样本从群体中随机选择。每个项目预计都能代表群体的特征。圆柱的直径是在车加工完成后对生成的零件进行的测量。

## 仪表着陆系统 (ILS)

一组离散无线辅助设备，用于所有类型的飞机在能见度的情况下接近繁忙机场跑道。通常，这些组件构成了仪表着陆系统：提供侧向引导的定位器；提供垂直引导的滑道器；以及沿滑道延伸的标志物（见插图）。距离测量设备（DME）读数或非方向频率无线电标（NDB）取代了其他标志物。定位器和滑道标志通常分别位于跑道末端。距离测量设备（`DISTANCE-MEASURING EQUIPMENT`）。

定位器、滑道器和标志物通过向空气辐射能量发挥作用。定位器和滑道标志物分别在 `108 MHz` 和 `75 MHz` 的频率上工作。例如，每个工作在 `109.5 MHz` 的定位器都有一个工作在 `32.9 MHz` 的滑道器。如果存在 DME，也会配对。只需要对接收器中的定位器进行调。

美国有1000个仪表着陆系统，世界上还有额外的300个系统。仪表着陆系统的主要替代者似乎是全球导航卫星系统（`GNSS`），其中 `GPS` 将发挥主要作用。参见卫星导航系统（SATELLITE NAVIGATION SYSTEMS）。

### 仪表放大器

一种特殊用途放大器，用于精确放大来自高共模电压（通常为高阻抗）输入端的两个（通常很小）电压之间的差值，具有一对指向 `$V_1$` 和 `$V_2$` 的差分输入，并满足下方方程中的线性关系。它与运算放大器（op-amp）不同，后者在结合闭环传输函数时具有无限开路增益。

```
V_out = A_v(V_1 - V_2)
```

设置仪表变压器界面的主要要求是提供从 `480 V` 到 `765-1000 V` 的适当电压范围。在网络电路中双用运算放大器时，仪表放大器作为便宜的集成电路使用。典型的商业放大器为 `10 mV` 至 `100 mV` 的电压范围提供良好的性能。

### 工具性学习

建立了行为的后果。例如，老鼠可能会学会按杠杆获取食物。工具性行为是生物改变环境的行为。行为的环境提供了后果，行为的不同后果被称为操作类，开放类中的响应（动作）作用于环境。例如，鼠按杠杆可能通过按左杠杆或右杠杆、杠杆或其他来响应，但所有这些共同构成了操作类学习。

仪器化浮标用于测量洋流，记录水流通过浮标的位置（欧洲流）。漂浮浮标随流移动，其去（拉格朗日框架）。这些浮标对于测量风暴和波浪形成很有用。

响应的后果增加或减少行为。例如，如果动物最近没有获得奖励，行为将减少。特定事件是否强化某种响应取决于后果的密度。惩罚或强化减少了行为的减少。

表面出现许多形状和大小，取决于许多因素，例如运筹学研究的发展、部署阶段、电流测量和天气状况。

行为的后果是生物可以学习的最重要的属性。行为的后果决定了哪些行为被学习。当组织的响应在一种环境中有一种后果而在另一种环境中具有不同后果时，组织就会学习。

为了长时间运行，浮标需要高可靠性，包括坚固的结构以防止在大海况下失效。浮标必须承受气压作用并持续多年。

当响应具有不同后果的设定时，它们被称为辨别。如果它们没有引起，其功能与仅通过其他刺激简化的功能不同。当生物学习到在海洋表面而非表面的情况下响应会在水下漂浮时。水下体验体验与水下漂浮。水下锚定比硬表面环境经历更少的疲劳。性能更好，硬件更便宜。更重要的是，没有波浪运动导致了平静得多的环境，从而提高了性能。水下锚定还减少了海盗和与渔网缠绕的风险。这些锚定需要贵的表面构造，因为它们必须能够承受高静水压力。大型钢球用于近表面应用，玻璃棒用于更大的压力。由嵌入环氧树脂的玻璃纤维基质组成的合成泡沫已在应用中证明非常有效，然而浮标有特殊的形状来支撑它们，以尽量减少水流中的阻力。
