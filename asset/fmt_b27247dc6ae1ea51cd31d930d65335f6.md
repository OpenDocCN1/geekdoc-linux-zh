#### 字符串开头匹配子字符串长度

`expr match "String" "$substring"`：`$substring` 是一个正则表达式。
`expr "String" : "$substring"`：`$substring` 是一个正则表达式。

```bash
stringZ=ABC123ABCabc

#-------

# 12345678

echo expr match "$stringZ" 'abc[A-Z].*2' # 8

echo expr "$stringZ" : 'abc[A-Z].*2' # 8
```

#### 索引

`expr index $string $substring`：`$string` 中与 `$substring` 中第一个字符匹配的的数字位置。

```bash
stringZ=ABC123ABCabc

# 123456...

echo expr index "$stringZ" C12 # 6

  # C 的位置。
```

```bash
echo expr index "$stringZ" 1c # 3

  # 'c'（在第 3 位置）在 '1' 之前匹配。

这等同于 C 语言中的 strchr。
```

#### 子字符串提取

`${string:position]}`：从 `$string` 的 `$position` 处提取子字符串。
如果参数 `$string` 为 `"*"` 或 `"@"`，则从 `$position` 开始提取这些位置参数。
`${string:length]}`：从 `$string` 的 `$position` 处提取 `$length` 个字符的子字符串。

```bash
stringZ=ABC123ABCabc

# 0123456789...

# 从 0 开始索引。

echo ${stringZ:0} # ABC123ABCabc

echo ${stringZ:1} # BCABC123ABCabc

echo ${stringZ:7} # 23ABCabc

echo ${stringZ:7:3} # 23A

  # 子字符串的三个字符。
```

#### 从字符串右端索引

```bash
# 是否可以从字符串的右端进行索引？

echo $(stringZ:-4)                                # abcABC123ABCabc

# 默认为整个字符串，类似于 $(parameter:-default)。

# 但是 . . .

# 现在可以了。

# 括号或添加空格可以“转义”位置参数。
```

位置和长度参数可以是“参数化”的，即表示为变量而不是数值常量。

# 生成一个 8 位的“随机”字符串。

if [ -n "$1" ]                                # 如果存在命令行参数

then

    str0="$1"

#### 删除子字符串

`${[substring]}`：从 `$string` 开头删除 `$substring` 的匹配项。
`${string##substring}`：从 `$string` 开头删除 `$substring` 的最长匹配项。

```bash
stringZ=ABC123ABCabc

# 最短

# ----|

# 最长

echo ${stringZ#*C} # 123ABCabc

# 删除 'a' 和 'C' 之间最短的匹配项。

echo ${stringZ##*a} # abc

# 删除 'a' 和 'C' 之间最长的项。

# 你可以对子字符串进行参数化。

X='a*C'

echo ${stringZ#$X} # 123ABCabc

echo ${stringZ##$X} # abc

# 同上。
```

`${string%substring}`：从 `$string` 末尾删除 `$substring` 的最短匹配项。

例如：

```bash
stringZ=ABC123ABCabc

# 最短

# ----|

# 最长

echo ${stringZ#*C} # 123ABCabc

# 删除 'a' 和 'C' 之间最短的匹配项。
```

#### 使用子串提取结构的 `getopt` 简单示例

`getopt` 是一个简单的示例，展示了如何使用子串提取结构。

##### 示例 10-5. 模拟 `getopt`

```bash
#!/bin/bash

## getopt-simple.sh

# 作者：Chris Morgan

# 经许可用于 ABS Guide。

getopt_simple() {

	echo "getopt_simple()"

	echo "Parameters are '$*'"

	while [ -n "$1" ]

	do

		echo "Processing parameter of: '$1"

		if [ "${1:0:1}" = "-" ]; then

			tmp=${1#*/}      # 去除开头的 '/' 和 .

			parameter=${tmp#*=}      # 提取名称。

			value=${tmp#*=}          # 提取值。

			echo "Parameter: '$parameter', value: '$value'"

			eval parameter=$value

		fi

		shift

	done

}
```

```bash
# 将所有选项传递给 getopt_simple()。

getopt_simple "$@"

echo test is '$test'

echo test2 is '$test2'

exit 0 # 另参见 UseGetOpt.sh，该脚本的修改版本。
```

```bash
sh getopt_example.sh /test=value1 /test2=value2

Processing parameter of: '/test=value1'
Parameter: 'test', value: 'value1'
Processing parameter of: '/test2=value2'
Parameter: 'test2', value: 'value2'
test is 'value1'
test2 is 'value2'
```

#### 子串替换

`${string/substring/replacement}`：将 `$substring` 的第一个匹配替换为 `$replacement`。

`${string//substring/replacement}`：将 `$substring` 的所有匹配替换为 `$replacement`。

```bash
stringZ=abc123ABCabc      # xyz123ABCabc
echo ${stringZ/abc}       # 将第一个匹配的'abc'替换为 'xyz'。

echo ${stringZ//abc}       # xyz123ABCxyz
# 将所有匹配的 'abc'替换为 'xyz'。

echo
echo "$stringZ"         # abc123ABCabc
echo                      # 字符串本身没有被修改！

# 匹配和替换字符串可以参数化吗？
match=abc
repl=000
echo ${string}/$match/${repl} # 000ABC123ABCabc
echo ${string//$match/${repl} # 000ABC123ABC000
# 可以！
echo
# 如果不提供替换字符串会怎样？
echo ${string/abc}         # 123ABC
echo ${string//abc}        # 123ABC
```

`${string/substring/replacement}`：如果 `$substring` 匹配 `$string` 的开头，则用 `$replacement` 替换 `$substring`。

`${string%substring/replacement}`：如果 `$substring` 匹配 `$string` 的结尾，则用 `$replacement` 替换 `$substring`。

| 代码 | 说明 |
| :--- | :--- |
| `stringZ=abcABC23abc` | |
| | |
| `echo ${stringZ#*abc}` | `# ABC23abc` 替换 `'abc'` 的开头匹配。 |
| `echo ${stringZ%*abc}` | `# abcABC23` 替换 `'abc'` 的结尾匹配。 |
