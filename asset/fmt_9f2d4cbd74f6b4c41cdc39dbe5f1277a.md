## 第 12 章：数组

### 第 12.1 节：数组赋值

#### 列表赋值

```bash
myarray=(1 2 3 4 5)
```

如果你想给特定的数组元素赋值，请使用以下语法：

```bash
myarray[0]=6
myarray[1]=7
```

使用新值创建数组：

```bash
myarray+=(6 7 8)
```

#### 下标赋值

要给现有索引赋值，使用：

```bash
myarray[2]="value"
```

#### 通过索引赋值

```bash
myarray[1]="new value"
```

#### 删除

```bash
unset myarray[1]
```

要删除数组中的所有元素，执行：

```bash
unset myarray
```

## 第 21 章：引用

### 第 21.1 节：用于变量和命令替换的双引号

变量替换应该只在双引号内发生。

双引号允许变量扩展，但会保留 `$` 和反引号（backticks）之外大多数特殊字符的字面值。

```bash
name="John Doe"
echo "$name"
```

双引号还允许命令替换。

```bash
echo "$(date)"
```

双引号不会防止单词分割和通配（globbing）。

```bash
echo "$@"
"#"
```

### 第 21.2 节：双引号和单引号的区别

**双引号**

- 允许变量扩展
- 允许命令替换
- 允许单词分割和通配

**单引号**

- 防止所有变量扩展
- 防止命令替换
- 防止单词分割和通配
