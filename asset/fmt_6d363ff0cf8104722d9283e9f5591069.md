
## 生成自签名证书

```bash
ps > /tmp/ssl-rand; date >> /tmp/ssl-rand
/usr/local/ssl/bin/openssl req -config RANDFILE=../tmp/ssl-rand ../SSLconf/conf/ssleay.conf -new x509 -nout ../SSLconf/conf/httpd.pem -keyout ../SSLconf/conf/httpd.pem
ln -sf htttpd.pem ../SSLconf/conf/
/usr/local/ssl/bin/openssl x509 -noout -hash < ../SSLconf/conf/httpd.pem.0; rm /tmp/ssl-rand
```

名为 `httpsd` 的证书创建在 `SSL/conf` 子目录中。例如，如果包含 Apache 源码分发的的目录路径为 `/usr/src/redhat/SOURCES/apache_x.xx`，那么完全路径（即你在下一节中用于配置 Apache 的路径）如下：

```
/usr/src/redhat/SOURCES/apache_x.xx/SSL/conf/httpsd.pem
```

现在你可以配置 Apache 了。

## 为 SSL 配置 Apache

当你在“编译和安装 Apache-SSL 补丁”中运行 `make install` 时，你在 Apache 安装目录的 `conf` 子目录中创建了一个 `httpsd.conf` 文件。例如，如果你使用 `--prefix=/usr/local/apache` 来配置 Apache，你会在 `/usr/local/apache/conf` 中找到 `httpsd.conf` 文件。使用以下命令将其重命名为 `httpd.conf`：

```bash
mv /usr/local/apache/conf/httpsd.conf /usr/local/apache/conf/httpd.conf
```

> 注意：如果你将 Apache 安装在不同的目录，请确保将 `/usr/local/apache/conf` 替换为相应的路径。

在 Apache 中使用 SSL 时，你有两个选择。你可以为主服务器启用 SSL，也可以为虚拟网站启用 SSL。在这里我演示如何为你的主 Apache 服务器启用 SSL。按如下方式修改 `httpd.conf` 文件：

### 1. 修改端口
默认情况下，Web 浏览器向 Web 服务器的 443 端口发送 SSL 请求，因此如果你想将主 Apache 服务器转换为启用 SSL 的服务器，请将 `Port` 指令改为：

```apache
Port 443
```

### 2. 设置随机数文件
添加以下行以告诉 Apache 如何生成加密 SSL 连接所需的随机数据：

```apache
SSLRandomFile /dev/urandom 1024
SSLRandomFileConnection file /dev/urandom 1024
```

### 3. 强制 SSL
如果你想拒绝除安全请求以外的所有请求，插入以下指令：

```apache
SSLRequireSSL
```

### 4. 启用 SSL 服务
要启用 SSL 服务，添加以下指令：

```apache
SSLEnable
```

### 5. 设置缓存路径
默认情况下，启用 SSL 的 Apache 所使用的缓存服务器创建在 Apache 的 `src/modules/` 目录下。设置：

```apache
SSLCachePath /src/modules/
```

### 6. 启用缓存
添加以下指令以启用缓存：

```apache
SSLCacheTimeout 300
```

### 7. 指定证书文件
告诉 Apache 你的证书位置。如果你使用自签名证书，浏览器将显示警告：

```apache
SSLCertificateFile /usr/src/redhat/SOURCES/apache_x.xx/SSL/conf/httpsd.pem
```

### 8. 其他指令
按照所示设置以下指令：

```apache
SSLBasicAuth on
SSLVerifyDepth 1
```
