## 治理
治理对于最近才接触数据分析的企业来说是一个新概念。治理需要一个涵盖人员、结构和薪资的结构，以确保 IT 部门与其他部门保持一致而不偏。

数据分析功能的布局有三种模式：

1. 将分析部门设在中央单元。这种位置的优点是易于获取数据、更易融入公司文化，且数据检索速度更快。集中部门面临的挑战可能是位置问题（作为一个附加部门，它可能位于决策者中心之外），部门向谁汇报可能会产生困惑，而且数据分析师可能距离公司文化太远，以至于无法预测业务需求。

第二种可能是将分析去中心化，并将分析师部署在公司各个部门。这允许分析师专注于他们所在的业务领域。挑战是在全公司项目上进行工作，这些项目不是碎片化的，需要所有分析师集中在一个问题集上。

2. 第三种方案是前两种方案的混合。这把分析师放在中心位置，同时在整个组织中部署分析师。这需要庞大的分析师团队，这可能是企业面临的最大挑战。

分析由模型、基础设施和运营组成。模型是源自统计数据的统计、预测或数据挖掘模型。分析过程的关键是建立模型，通常由分析师、数据科学家或统计学家执行。

基础设施是用于数据管理、数据处理和决策的软件组件、应用和使用的平台。与分析基础设施连接的流程包括数据管理、模型部署和必须纳入业务运营的多种分析。

运营是创建用于模型的数据和业务用途的操作过程。数据可以通过购买、内部、外部或协作获取。

数据分析团队必须识别内部和外部相关数据、管理数据、构建分析模型并将模型引入内部系统。大多数企业按如下组织这些功能：业务部门请求模型，分析团队构建模型，IT 部门提供原始数据，运营部门发布模型。这引出了分析治理的必要性。

企业在提取大数据时面临的三个挑战是：
1. 识别数据将使用的独特需求
2. 获取所需信息
3. 将分析模型部署到组织中

分析经理必须有足够的权限来消除这些挑战。治理结构需要一种机制，对源于数据分析问题的问题进行识别、沟通和解决。分析经理还需要灵活性来招聘合格且知识丰富的人员。

可视化让数据对读者而言栩生起来。信息列表在尝试将其转换为可用的数据时可能会非常困难；将数据组转换为易于管理的形式，对于帮助读者区分重要信息和无关信息至关重要。

使用图形设计软件可以吸引人们对关键数据的关注，通过使用视觉图像，可以发现其他情况下无法检测到的隐藏模式和联系。

### Chart.js
`http://www.chartjs.org/`
该程序提供了 6 种不同的 HTML5 图形，它是最流行的小型图表程序之一。

### Dygraphs
`dygraphs.com/`
这是一个可自定义的 JavaScript 图表工具，适用于几乎所有的浏览器，用于处理密集数据集。它对移动设备和平板友好。

### FusionCharts
`www.fusioncharts.com/`
FusionCharts Suite XT 提供了 90 多种图表、965 种数据地图以及可自定义的交互式业务仪表板。FusionCharts 适用于 AJAX 应用程序并可以使用 JavaScript API 使用。

### Instant Atlas
`[www.instantatlas.com/]`
Instant Atlas 将统计数据与地图数据相结合，这在人口统计信息方面非常有用。

### Raw
`[raw.densitydesign.org/]`
Raw 是可自定义且可修改的，可以从应用程序上传到计算机，导出为 SVG 或 PNG，可以嵌入网页中，并提供基于向量的图像。

### Tableau
`[www.tableau.com/]`

### Timeline
`https://timeline.knightlab.com/`

### Visual.ly
`[visual.ly/]`

`https://www.zingchart.com/`

社交媒体分析是使用从博客和社交媒体网站收集的信息，使业务更成功、更具可见性。拥有网络存在是吸引年轻一代客户的关键。30 岁以下的购买者中有81% 使用互联网来影响他们的购买。与这些购买者的连接点对于业务的增长和发展至关重要。

社交媒体分析涉及数据挖掘、网站信息分析、数据收集以及利用信息进行业务预测和产品塑造的实践。社交媒体分析的主要用途是评估客户反应，以支持营销进展和客户服务决策。社交分析的第二个主要用途是通过维护网络上的存在感来获得竞争优势。社交媒体分析的第三种用途是衡量客户对产品或服务的态度。社交媒体分析的第四种用途是通过提供仅限网络资源和折扣来增强产品。社交媒体分析的第五种用途是生产违背逻辑（例如跑步者拉出跑步鞋的内里，因为这会让他们的脚太热）但消费者想要的产品。

### 形成假设
社交媒体分析更多是关于为什么发生了什么，而不是报告事件本身。从一种情况甚至从一个关于“为什么”的问题开始分析。为什么读者参与了这个问题，但没有回应 Facebook 或 Twitter 上的类似调查？检查你的发布频率和时间。它们对你的品牌或产品是最优的吗？例如，如果分析师参与数据挖掘，YouTube 可能会有作为解决方案的答案。

数据分析时代已经到来，水瓶时代已经过去。那些收集、解释并根据原始数据采取行动能够适应快速变化的市场，并保持领先竞争对手的状态。

为了正确且快速地使用数据，利用这些工具分析数据将带来清晰的思路和创新建议。

从**衡量**(Measuring）开始，确定了哪些分析对公司内部决策最有帮助。

**诊断**(Diagnose）客户满意度或产品布局出现的问题。为什么事情会以不利的方式发生？数据分析可以帮助你定位特定问题，以获得满意的解决方案。

**预测与优化**(Predict and Optimize）以预测变化以及变化可能带来的潜在后果。使用“如果……那么……”的提问法。（如果我对客户服务做出此改变，我随后将如何预判反应？）这种分析技术有助于确定组织的方向以及维持持续增长的最佳路线。

**运营化**(Operationalize），亦或将信息投入一线员工、销售人员、工程师、营销人员、经理以及其余决策者的使用中。这是从分析到实用的转变，离开实验室进入真实世界的体验。

**自动化**(Automation）是指业务经理利用实时信息对组织做出更改。例如，在杂货行业，优惠券对客户和杂货店来说都是巨大的利润来源。杂货店销售产品，但通过优惠券机构获得补偿（基于优惠券价值的手续费）。客户以折扣获得产品，而该产品通常是新引入的物品，在经济低迷时期会被视为奢侈品。然而，当客户通过购买该产品的所有架货来利用零售商，导致其他客户无货可用并营造出客户不满的环境时，会发生什么？店经理立即评估情况并应用“每笔交易最多3张优惠券”的规则。现在很少有人愿意在结算处进行多次交易。零售商已利用自动化分析了问题并创建了时解决方案。
