# 第 5 章：Nessus 安装实用指南

Tenable 是安全网络领域广誉盛名的名称，它推出了一款名为 Nessus 的卓越漏洞过滤应用程序。该应用程序有两个版本，在实用性和支持程度上有所不同。分别是 Nessus Professional（专业版）和 Home（家庭版）。专业版为合规性检查、SCADA 和配置检查提供了丰富多得多的模块，非常适合团队使用。对于本书，我们将使用家庭版数据来建立 Nessus 漏洞扫描器。Nessus 将在后续过滤部分进行进一步介绍，现在介绍 Nessus 将巩固本节的信息。

## 在安装 Nessus 之前刷新并清理系统

在 windows 终端中输入以下指令：`sudo apt update && sudo apt upgrade && sudo apt dist-upgrade && sudo apt autoremove && sudo apt autoclean`

## 引入并配置 Nessus

从 `http://www.nessus.org/download` 下载 Nessus 5.0 或更高版本。

根据 32 位或 64 位工作框架选择基于 Debian 的包。仔细阅读会员协议并点击 Agree（同意）按钮。如果不确认协议，Nessus 将无法工作。请注意文档下载的位置，因为完成安装时需要它。

从终端窗口输入以下内容：

```
dpkg -I B/{Download_Location}/Nessus-{version}.deb
```
