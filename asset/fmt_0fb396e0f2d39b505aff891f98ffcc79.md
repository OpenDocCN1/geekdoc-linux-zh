# 游戏论

策略游戏论可以表述为将数学分析应用于抽象的情境概念。第一个此类模型了一个……

游戏分类。如果每个可能的 $n$ 元策略 $s_1, s_2, ..., s_n$ 的所有玩家收益之和为零，则该游戏被称为零和游戏，即公式 (1) 成立：

$P_1(s_1, ..., s_n) + P_2(s_1, ..., s_n) + ... + P_n(s_1, ..., s_n) = 0$

对于某些纯策略游戏，其和不为零，被称为非零和游戏。如果每个玩家在每个动作做出时都知道，则游戏在极端情况下具有完美信息。如果每个玩家知道对方做了什么（但不知道自己做了什么），由于玩家的记忆在两个……之间划分，具有完美记忆。游戏论在经济学、社会学和政治科学等领域的应用导致了许多零和游戏。

**非零和游戏。** 游戏论的大部分处理一个玩家的收益恰等于另一个玩家损失的游戏。当两个或多个玩家参与冲突局面时，游戏的……特征是联盟在一起以最大化总收益。具有联盟的游戏被称为合作游戏。在非合作游戏中，每个玩家只关心自己的收益。在这样的游戏的平衡点，一组混合策略 $s_1, ..., s_n$，使得公式 (2) 成立：

$P(s_1, ..., s_n) = P_i(s_1, ..., s_n)$

对于 $i = 1, \dots, n$，这意味着没有玩家可以通过改变策略来保持自己的收益。如果任何玩家改变策略而其他人保持固定，收益将得到提高。

**简单游戏。** 零和游戏的一个重要类别是简单游戏。在这些游戏中，每个玩家都可以赢得、输掉或阻止。联盟可能是一个阻止联盟形成的玩家集合。如果联盟中的玩家不强制他们的策略，则联盟是阻止的。

**连续游戏。** 在游戏的正式术语中，如果允许玩家从策略范围内选择，且收益允许是两个变量的函数，结果被称为连续游戏。

**玩游戏的机器。** 电子计算机最早的应用之一是解决大型矩阵游戏。设计了一些方法来寻找此类游戏的平衡。因此，方法可以扩展到具有数千或数百万变量的某些问题。计算机被编程玩象棋和跳棋等游戏。严格来说，它们完全没有使用游戏论，而是使用了与……代码相同的意义。决策论；信息论；随机过程。[G.L.T.]
