
# Linux 词典

- `xkobo` 一个战斗空间。摧毁所有堡垒并避开许多敌舰，以进入战斗空间的下一关。源自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlaby` 使用鼠标移动并在迷宫中收集四个物品。`xlaby` 将你的鼠标光标困在由 "`maze`" 生成的迷宫中，你必须移动直到收集到四个物体——隐形墙也是一种选择！源自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlander` 一个针对 X 对象的月球模拟，用于将飞天器成功降在月球或其他行星表面。该程序具有“窗外” 3-d 线框图形和对锚的定向控制。更多指令请参阅 `man` 手。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlassic` 可停靠邮件通知器，带有消息计数和 POP3/POP/IMAP 增强待处理邮件通知器。显示等待消息的数量。支持本地邮件池和邮件服务器。点击时可以运行。使用纯 `xlib`，因此内存占用极小。你可以将其创建一个应用程序或 WindowMaker/KDE docklet。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlbff` X Litetiff。显示并对你的新 Xlibff 主题。它潜伏在后台，监控你的信箱文件（通常为 `~/spool/mail/username`）。当有邮件出现时，它会调用 `MH scan(1)` 命令并在窗口中显示输出。如果有更多邮件，它会再次并快速地扫描。如果在窗口中点击鼠标左键，它就会消失。它在 `xconsole` 之后也会消失——它的工作是隐形地坐并在事情需要你注意时弹出。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlc` 用于 `linesrv` 的 Gtk 是用于 `linesery` 的 Gtk。允许用户在伪装服务器上启动或停止互联网连接。它监控连接并关闭运行服务器的盒子。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xless` X 系统文件浏览器。`xless` 允许你在 X 窗口中通过文件名或 STDIN 查看信息。它可以打印当前缓冲区和正则表达式搜索。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xletters` 在故障落点处打字。一个用于 X 的打字练习游戏，用于打字速度和字体类型。单词从系统词汇表中从屏幕顶部选择，必须正确输入才能得分。在挑战阶段，随机字符序列将代替单词出现。可以通过 `xletters–duel` 进行网络对战。源自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

- `xlhtml` `http://www.tldp.org/LDP/Linux-Dictionary/html.index`

## Linux 词典

一个转换 Microsoft Excel 文件的程序。`xlhtml` 程序可以创建 Excel、95 或 97 文件并将其转换为高度优化的 html。输出通过 `stdout` 进行，因此可以重定向文件或管道到过滤器，或作为互联网网关使用。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- `xli` 在 X11 下查看图像。可以查看 X11 下的图像类型：FBM Image、Rasterfile、CMU WM Raster、可能的位图 (`PBM`, `PGM`, `PPM`)、便携网络图形 (`PNG`)、Faces Project、GIF Image、JPEG图像类型、Utah R Image、Windows、OS/2 Image、CD 图像、X Window Dump、Large Image、MICDAS archive、G3 Face、Paintbrush Image、GEM Bit Image、MacPaint Image、X Pixmap、X Bitmap。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- `xlib` 由 `libc` X 客户端共享库。X 库是 X 客户端与面向硬件的 X 服务器之间的交汇，它们由以抽象方式从键盘和指针、屏幕上读取输入的程序组成，这种方式独立于特定的硬件特性。X 通过协议与 X 服务器通信。`Xlib` 本身提供了低级功能；在 X 中，Toolkit Introspection 通常用作 `Xlib` 或 Athena 等小部件库的基础。`Xaw`，Athena 小部件提供了一组基础的图形用户界面元素（按钮、滚动条、文本框等）。提供了几个库来实现 `get X` 客户端的功能。针对 `libc` 编译的 X 客户端称为 `lib5`，具有此类向后兼容性。为了避免冗余，此包依赖于 X 服务器使用的非二进制文件（位图、位置数据等）的当前 X 库版本。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- `xlibmesa` XFree86 渲染库 Mesa 3D 图形库。`Mesa` 是一个 3D 图形库，提供了一个与 `OpenGL` 兼容的 API。XFree86 维护它自己的 Mesa 服务器（定期与官方版本同步），以便开发 XFree86 服务器的直接渲染基础设施 (`DRI`)，使得现代显卡的 3D 加速功能对 X 程序员可用。如果机器架构支持，此包提供了无芯片模块（与 `xserver-xfree86` package 中的模块不同，DRI 模块由 Mesa 加载而非 X 服务器）。源自 Debian 3.0r `http://www.tld.org/LDP/Linux-Dictionary/index.html`

- `xlibmesa3g` Mesa/XFree86 离屏渲染库。`Mesa` 是一个 3D 图形库，提供了一个与 `OpenGL` 兼容的 API。XFree86 维护它自己的 Mesa 服务器（定期与官方版本同步），以便开发 XFree86 服务器的直接渲染基础设施 (`DRI`)，使得现代显卡的 3D 加速功能对 X 程序员可用。如果机器架构支持，此包提供了无芯片模块（与 `xserver-xfree86` package 中的模块不同，DRI 模块由 Mesa 加载而非 X 服务器）。源自 Debian 3.0r `http://www.tld.org/LDP/Linux-Dictionary/index.html`
