
```bash
thomas:-> cat people-I-like | sort
Auntie Emmy
Boyfriend
Dad
Grandma
Mum
My boss
```

但 `sort` 还可以做很多事情。例如查看文件大小。通过此命令，

目录内容将按从小到最大的文件进行排序：

```bash
ls -la | sort -nk 5
```

## 旧的 sort 语法

你可以通过 `ls -la | sort +4n` 相同的结果，但这是一个旧格式，不符合当前标准。

`sort` 命令还结合 `uniq` 程序（或 `sort -u`）用于对输出进行排序并过滤条目：

```bash
thomas:> cat itemlist

2
5
34
567
432
567
34
555
```

```bash
thomas:> sort itemlist | uniq
1
2
34
4
432
555
```

### 我应该使用什么编辑器？

我们的重点是文本编辑器，它们也可以在没有图形的环境和终端窗口中使用。掌握编辑器的额外优势是在远程机器上使用它。由于不需要通过网络传输整个图形环境，使用文本编辑器极大地提高了网络速度。有多种方法处理此问题。让我们看看常用的编辑器：

#### GNU Emacs

`Emacs` 是一种可扩展、可定制、自文档的实时显示编辑器，在许多 UNIX 和其他系统中已知。它是一种实时编辑器，显示会在屏幕上更新，并随着你输入命令而自动更新。它更新频繁，通常在你输入每个字符或字符对后更新。这减少了你在编辑时必须在大脑记忆的信息量。`Emacs` 被称为高级，是因为它提供了超出简单插入和删除的功能：控制程序的自动缩进；同时查看两个或多个文件；编辑格式文本；以单词、行、句子、段落和页为单位，以及处理不同编程语言的表达式和注释。自文档意味着你可以在任何时候通过一个特殊字符 `Ctrl+H` 来查找你的选项。你也可以用它来查找任何命令的作用，或者查找与特定主题相关的所有命令。

可扩展（Extensible）意味着你可以超越简单的自定义，编写完全新的命令——即使用 Lisp 语言编写的、作为 `Emacs` 自身解释器的扩展程序。`Emacs` 是一个在线系统，这意味着它被分为许多相互调用的函数，其中几乎任何函数都可以在编辑过程中进行定义。`Emacs` 的几乎任何部分都可以替换，而无需制作 `Emacs` 的独立副本。`Emacs` 的大部分命令是用 Lisp 编写的；少数例外本可以用 Lisp 编写，但为了效率使用了 C 语言。只有程序员才能编写扩展，但任何人都可以使用它。

#### Vi(m)

`Vim` 是 "Vi Improved（改进版 Vi）" 的缩写。它曾经是 "Vi Imitation（Vi 模仿者）"，但由于改进非常多，更改名称是很恰当的。`Vim` 是文本编辑器，包含了 UNIX `vi` 的几乎所有命令以及许多新命令。

编辑器中的命令仅通过键盘输入，其优势是你可以让手指停留在键盘上，眼睛盯着屏幕，而不需要反复移动手臂去操作鼠标。对于你需要的每个键，都可以激活鼠标支持以及带有工具栏和菜单的 GUI。

在编辑文件时，我们会统称为 `vi` 或 `vim`，你可以自由使用你选择的编辑器。我们建议至少在指尖上掌握基础操作，因为它是几乎所有 UNIX 系统上的标准文本编辑器，而 `emacs` 可以作为一个可选软件包。不同的计算机和终端之间可能有很多差异，但关键点是，如果你会用 `vi`，你可以在任何 UNIX 系统上生存。

除了 `vi` 命令外，`vim` 软件包可能还提供 `gvim`，即 Gnome 版本的 `vim`。初学者可能会发现它更容易使用，因为当你不知道如何使用标准 `vim` 命令执行特定的编辑任务时，菜单可以提供帮助。

## 使用 Vim 编辑器

### 两种模式

`vi` 编辑器是非常强大的工具，具有非常丰富的内置功能，你可以在程序启动时使用帮助命令激活它们（而不是使用包含信息不多的 `man` 或 `info`）。在我们开始之前，这里只讨论基础知识。

让初学者感到困惑的是 `vi` 它在两种模式下运行：命令模式（command mode）和插入模式（insert mode）。编辑器始终从命令模式开始。命令让你在文本中移动、搜索、替换、块标记并执行其他编辑任务，某些命令会将编辑器切换到插入模式。

这意味着每个键不仅有一个含义，而是两个：它既可以代表命令模式下的编辑器命令，也可以代表插入模式下你想在文本中需要的字符。

### 发音

读音为 "vee-eye"。

### 命令

#### 在文本中移动

通常可以使用方向键在文本中移动。如果不行，尝试：

- `h` 将光标向左移动
- `l` 将光标向右移动
- `k` 向上移动
- `j` 向下移动
- `SHIFT-G` 将提示符置于文档末尾。

#### 基础操作

这些是常用的 `vi` 命令：

- `dd` 删除从当前光标位置开始的 n 行。
- `nw` 删除光标右侧的 n 个单词。
- `x` 删除光标所在的字符。
- `:in` 移动到文件的第 n 行。
- `:w` 保存（写入）文件。
- `:q` 退出编辑器。
- `:q!` 当你想退出包含未保存更改的文件时强制退出。
- `:wq` 保存并退出。
- `wnewfile` 将文本保存到新文件中。
- `:wq` 覆盖只读权限（如果你有覆盖权限的权限，例如你正在使用 `root` 账户）。
- `/astring` 在文件中搜索字符串，并将光标置于位置下方的第一个匹配项。
- `/` 再次执行相同的搜索，将光标移动到下一个匹配项。
- `:1,$s/anotherword/anotherword/g` 在整个文件中将 word 替换为 anotherword。
- `yy` 复制一段文本。
- `np` 粘贴它 n 次。
- `recover` 在意外中断后恢复文件。

#### 将编辑器切换到插入模式的命令

- `a` append（追加）：它在切换到插入模式之前将光标位置移到右侧。
- `i` 插入。
- `o` 在当前光标位置下方插入一个空行并将光标移动到该行。

按下 `Esc` 键切换回命令模式。如果你不确定处于哪种模式（因为你使用的是不显示 "INSERT" 信息的旧版本 `vi`），输入 `Esc` 即可返回命令模式。当你已经在命令模式并按下 `Esc` 时，蜂鸣可能会发出轻微的警报，或者提供视觉铃（屏幕上的闪烁）。这是正常行为。
