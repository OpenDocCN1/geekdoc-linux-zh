# 第七章

## 通过语调实现效率

村里的钟声是多么轻柔，

间歇地落在耳边，

带着甜美的韵律；如今渐渐远去，

如今再次响亮，愈发响亮，

清脆悦耳，随着狂风袭来！

它以轻松的力量开启了

记忆睡眠的细胞。

--威廉·考沃，《任务》。

赫伯特·斯宾曾评论道，“韵律”（Cadence，他指的是说话时语调的调制）“是情感对智力命题的动态评论”。这句话有多真实，当我们反思声音微小的起升起伏比我们的词汇更真实地表达了我们的意图时，就会显出来。语言的表达力通过这种改变声调阴影的微妙力量而倍增，而这种声音——我们称之为“语调”（inflection）。

单词内部音调的变化甚至比短语之间音调的变化更为重要，因为它更细腻。事实上，两者不可不可缺。单调的词仅仅是许多砖块——语调会将它们变成铺设好的道路、车库或大教堂。正是语调改变词义的力量产生了那句老话：“重要的不是你说了什么，而在于你怎么说。”

莎士比亚评论家詹姆森夫人为我们提供了一个关于语调效果的深刻例子；西德斯夫人在扮演麦克白夫人的角色时，在说出‘我们失败了’这两个词时连续采用了三种不同的语调。起初是快速且轻蔑的询问——‘我们失败了？’随后，带着钦佩的语气——‘我们失败了’，带着愤怒的惊讶将重音放在‘我们’字上——我们失败了。最后，她固定在我深信是正确的读法——‘我们失败了’，语气平稳，将声音调制为深沉、坚定的语调，立刻定下了结局，仿佛她在说：“如果我们失败了，那我们为什么要失败呢，一切都结束了。’”

我们语言中最具表现力的元素是我们在学习外语自然表达时最后被掌握的元素，而它的正确使用是我们的母语自然、灵活表达的主要要素。没有了多样的语调，说话就会变得生硬而单调。

语调只有两种：升调和降调，这两种语调可以处理成不同程度的阴影或组合，从而产生如一条或两条直线、曲线那样的变化，如下：

| 语调类型 |
| :--- |
| 快速升调 |
| 长升调 |
| 平调 |
| 长降调 |
| 快速降调 |
| 快速升降调切换 |
| 犹豫调 |

这些可以无限变化，仅用于说明这两种简单语调的组合可以产生多广泛的变化。

列出表达各种思想和情感色彩的各种语调是不可能的。这里提供了一些建议，并附有大量的练习，但掌握语调的唯一真正方法是观察、实验和练习。

例如，取常用的句子：“噢，他很好。”注意升调如何被用来表达微弱的赞美、礼貌的怀疑或意见的不确定。然后看同样的词，以通常的降调说话时，如何表示确定性、好意的赞同或热忱等等。

总而言之，我们发现声音的向上扬扬会暗示怀疑和不确定，而坚定的降调则暗示你对立场是肯定的。

--克兰奇

必须非常明确的是，语调主要处理单个单词内部微妙、细腻的阴影，绝不是通过在说话句子时音调的普遍升高或降低来实现的。然而，某些句子完全可以通过这样的语调来有效地传达。尝试用几种方法读这个句子，在达到指示的最后两个音节之前，不要进行任何调制，

| 句子 | 语调 |
| :--- | :--- |
| 然而我告诉过他这—— | (高音)地。 |
| 然而我告诉过他这—— | (低音)(高音)地。 |

现在尝试通过改变重点词的语调来读这个句子，以表现出意义的细微差别。上面说明的第一形式展示了*单个单词内部*的音调变化；你自己练习出来的形式应该在整个句子中显示出许多这样的语调。

获得强调的主要手段之一是在强调词上使用长长的下降语调——即让声音在单词的*内部*音上下降到较低的音调。尝试对“every”（每一个）、“eleemosynary”（慈善的）和“destroy”（摧毁）这些词。

对节选中的斜体词使用长长的下降语调，注意它们的强调力量。这里还有其他词通过长长的下降语调会有表现力吗？

达特茅斯学院案中的演讲 先生，这是我的诉求。这不仅仅是一个小机构的诉求；它是我们国家每所大学的诉求。它*不仅如此*；它是我们全国*每一个**慈善*机构的诉求——由我们祖先的虔诚创立的所有伟大慈善，旨在减轻人类苦难，并在生命的道路上播下福泽。先生，您可以*摧毁*这个小机构——它是*虚弱的*，它在您的手中。我知道它是我国文学地平线上较微弱的光芒之一。您可以熄灭它。但如果您这样做，就必须完成您的工作；您必须一个接一个地熄灭那些一个多世纪以来在我们片土地上投射光芒的伟大科学之光！

先生，正如我所说的，这是一所小学院，但是——依然有人爱它！

先生，我不知道别人感受如何，但对我来说，当我看到我的母校被凯撒在元老院中包围，被那些一次又一次捅刺的人包围时，我不愿看到这右手转向我说：*你也是*，我的儿子！

--丹尼尔·韦伯斯特

注意不要过度语调。过多的调制会产生一种不悦的的人造感，就像一个成熟的贵妇试图装稚态。真正的表达与刻意的技巧之间只有一步之遥。用不同的方式读这个句子，观察音调。取一个像“噢，不！”或“确实”这样的表达，观察通过语调可以表达多少意义。这种感觉的练习比看书更有用。*但不要忘记倾听你的声音。*
