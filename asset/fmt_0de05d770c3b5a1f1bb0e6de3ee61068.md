
ROM 是非易失性存储——即使在断电后也会保留其内容。ROM 经常用于存储嵌入系统的程序，因为这些系统通常有固定用途。相比之下，ROM 也用于存储 BIOS（第 1025 页）。与 RAM（第 1055 页）相比。

# 根目录 (root directory)

所有目录的祖先以及所有绝对路径的起点。根目录的名字为 `/`。

# 根文件系统 (root filesystem)

当系统在恢复模式下启动时，文件系统可用。此文件系统的名称始终为 `/`。你不能卸载或挂载根文件系统。

# root 登录 (login)

超级用户（Superuser）的用户名。

# root 用户 (user)

超级用户（第 63 页）的别名。

# root 窗口 (window)

根所在的任何地方，例如桌面。

# 路由器 (router)

连接不同网络的设备。见第 38 页的 router。

# RPC

远程过程调用。一种允许程序在另一台计算机上执行过程的机制，就像本地调用一样。

# RSA

基于大数分解困难性的公钥加密（第 93 页）。RSA 是 Internet 标准。

# 运行 (run)

执行程序。

# 运行级别 (runlevel)

系统的状态，包括单用户和多用户。见 runlevel。

# 术语表

## 架构 (schema)

一种帮助你查看和解释信息的模式。

## 滚动 (scroll)

在窗口中上下移动行。

## 滚动条 (scrollbar)

图形界面中的一种控件（第 68 页），用于控制文档的可见部分。

## 服务器 (server)

一种强大的中心化计算机或程序，旨在根据请求向客户端提供信息。

## 会话 (session)

进程的生命周期。对于桌面，它是桌面管理器；对于字符终端，它是用户的登录进程。在 KDE 中，它由 `kdeinit` 启动。

## setgid

当你执行一个具有 `setgid`（组 ID）权限的文件时，执行该程序将获得该文件所属组的权限。`ls` 工具在组位置显示 `s` 以表示设置了 `setgid`。

## setuid

当你执行一个具有 `setuid`（用户 ID）权限的文件时，执行该程序将获得该文件所有者的权限。例如，如果你运行一个删除某个目录中所有文件的 `setuid` 程序，你可以删除文件所有者的任何目录，即使你没有权限这样做。当程序由 root 拥有时，你可以使用 root 权限处理任何目录。`ls` 工具在所有者位置显示 `s` 以表示设置了 `setuid`。

## sexillion

在英国体系中为 10⁶；在美国体系中，这个数字被称为 undecillion。

## SHA1

安全哈希算法 1。SHA 家族是由国家安全局（NSA）设计的一系列加密哈希（第 139 页）算法。该家族的第二个成员是 SHA1，是 MD5（第 147 页）的继者。

## share

通过 SMB（第 60 页）与其他系统共享的文件系统层次结构。也指 Windows 共享（第 69 页）。

## 共享网络拓扑

一种网络（如以太网），每个数据包都可以被目标系统以外的系统看到。共享意味着网络带宽由所有用户共享。

## Shell

一种 Linux 系统命令行处理器。三个主要的 shell 有 Bourne Again Shell（第 1026 页）、TC Shell（第 164 页）和 Z Shell（第 1070 页）。

## shell 函数

shell 存储以供以后执行的一系列命令。shell 函数类似于 shell 脚本，但运行速度更快，因为它们存储在计算机的主内存中而不是文件中。此外，shell 函数在调用它的 shell 环境中运行（与 shell 脚本不同，脚本通常在子 shell 中运行）。

## shell 脚本

一个包含 shell 命令的 ASCII 文件。也称为 shell 程序。

## 信号 (signal)

UNIX 系统可以发送的非常短的消息，除了进程的标准输入外。参阅第 451 页的“trap：捕获信号（Catches a Signal）”。

## 简单文件名

不包含斜杠（`/`）的单个文件名。简单文件名是路径名最简单的形式。路径名的最后一个元素。basename（第 1025 页）。

## 单用户系统

同一时间只能由一个人使用的计算机系统。与多用户系统对比（第 1049 页）。

## 滑块 (slider)

一种小部件（第 1068 页），允许用户通过沿线移动指示器来设置一个值。许多滑块还允许用户点击线条来移动指示器。与工具栏（第 1059 页）的区别在于，移动指示器不会改变显示的其他部分。

## SMB

服务器消息块（Server Message Block）。由 Intel、Microsoft 和 IBM 在 20 世纪 80 年代早期开发，是 Windows 文件和打印服务的客户端协议。此外，SMB 还可以共享串口和通信抽象，例如命名管道和邮件套接字。SMB 类似于远程调用（RPC，第 1058 页），针对文件系统访问进行了定制。也称为微软网络（Microsoft Networking）。

## 笑脸 (smiley)

一种基于字符的符号（第 1038 页），通常用于电子邮件，用来传达情感。消息中的字符 `:-)` 描绘了一个笑脸（侧着看）。由于很难判断电子消息的编写者是在开玩笑还是严肃，用户经常使用 `:-)` 来表示幽默。由 Scott Fahlman 设计的两个原始笑脸是 `:-)` 和 `:(`。也称为表情符号。关于互联网上笑脸的更多信息。

## 多个笑脸符号 (smilies)

见 smiley。

## SMTP

简单邮件传输协议（Simple Mail Transfer Protocol）。一种用于在计算机之间传输电子邮件的协议。它是一种服务器到服务器的协议，因此使用其他协议访问消息。SMTP 对话通常在后台由消息传输系统（如 exim）控制。

## 贴靠 (snap windows)

当你将窗口拖向另一个窗口或工作区的边缘时，它可能会突然移动，使其与另一个窗口/边缘相邻。因此，窗口吸附到位置。

## 间鼠网络 (sneakernet)

使用手提磁介质在机器之间传输文件。

## 嗅探 (sniff)

监控网络上的数据包。系统管理员可以合法地嗅探数据包，恶意用户可以嗅探数据包以获取用户名和密码等信息。另见数据包嗅探器（第 1052 页）。

## SOCKS

一种封装在 SOCKS 服务器中的网络协议，其功能与代理网关（第 1055 页）或代理服务器（第 1055 页）相同。SOCKS 工作在应用层，需要修改应用程序以适配 SOCKS 协议，而代理（第 1055 页）对应用程序没有要求。

SOCKSv4 不支持身份验证或 UDP 代理。SOCKSv5 支持多种身份验证方法和 UDP 代理。

## 排序 (sort)

按顺序放置，除非是字母或数字。

## 空格字符 (SPACE character)

一种显示为可见字符缺失的字符。尽管你看不见它，但空格是一个可打印字符。它由 ASCII 代码 32（十进制）表示。空格字符被认为是一个空白或空白字符（第 1068 页）。

## 垃圾邮件 (spam)

故意或无意地违反网络礼仪（第 1049 页），向一个或多个 Usenet 组或邮件列表发布无关或不当的消息。此外，大量发送未经请求的电子邮件通常是为了推销某种产品或服务。垃圾邮件的另一个常见目的是钓鱼（第 1053 页）。垃圾邮件是电子垃圾的等价物。源自蒙提 Python 的歌曲《Spam》。

## 稀疏文件 (sparse file)

一种很大但占用磁盘空间很少的文件。稀疏文件中的数据不是连续的（其名称由来）。稀疏文件的示例是核心文件和 dbm 文件。

## 创建 (spawn)

见第 1037 页的 fork。

## 特殊字符 (special character)

当出现在模糊文件或另一种类型的正则表达式中时具有特殊含义的字符，除非用引号括起来。shell 中常用的特殊字符有 `*` 和 `?`。也称为元字符（第 1047 页）和通配符。

## 特殊文件 (special file)

见第 1033 页的设备文件。

## 数字调节框 (spin box)

在 GUI 中，一种文本框（第 1064 页），你可以通过对其输入或使用框末尾的上下箭头来更改数字。也称为旋转器。

## 旋转器 (spinner)

见 spin box。

## 欺骗 (spoofing)

见第 1043 页的 IP 欺骗。

## 池 (pool)

将项目放入队列中，每个项目都在等待某些操作。通常用于讨论打印机池。也用于描述队列。

## SQL

结构化查询语言（Structured Query Language）。一种为关系型数据库管理系统（RDBMS）提供用户界面的语言，事实标准，也是 ISO 和 ANSI 标准，并且经常嵌入其他编程语言中。

## 方括号 (square bracket)

左方括号（`[`）或右方括号（`]`）。这些特殊字符在模糊文件引用和其他正则表达式中定义了类。

## SSH

创建原始 SSH（secure shell）协议套的公司（www.ssh.com）。Linux 使用 OpenSSH（第 1055 页）。

## 标准错误 (standard error)

程序可以向其发送错误的文件。通常是屏幕。除非你重定向它。

## 标准输入 (standard input)

程序从其接收输入的文件。通常是键盘。除非你重定向它。

## 标准输出 (standard output)

程序向其发送输出的文件。通常是屏幕。除非你重定向它。

## 启动 (startup)

shell 运行。

## 状态行 (status line)

显示正在发生什么的行。编辑器使用它显示关于行的信息。

## 粘滞位 (sticky bit)

目录访问权限。只有具有 root 权限的用户才能设置。

## 流媒体 (streaming)

以恒速移动的网络。

## 流 (streams)

见第 30 页的面向连接协议。

## 字符串 (string)

字符序列。

## 样式表 (stylesheet)

见第 31 页的 CSS。

## 子目录 (subdirectory)

位于另一个目录中的目录。

## 子网 (subnet)

子网络。网络的一部分。子网之于网络，段之于互联网。

## 子网地址

IP 地址的子网部分。在分子网的网络中，主机部分分为子网部分和主机部分。另见子网数。

## 子网掩码

用于标识 IP 地址中哪些位对应网络的掩码。掩码在对应网络位为 1，主机位为 0。也称为地址掩码。

## 子网数

IP 地址的子网部分。在分子网的网络中，主机部分分为子网部分和主机部分。另见子网地址。

## 亚像素提示 (subpixel hinting)

与抗锯齿（第 1023 页）类似，但利用颜色来实现锯齿。

## 子程序 (subroutine)

见第 54 页。

## 子 shell (subshell)

作为父 shell 的副本生成的 shell。当你通过命令行运行一个包含 shell 脚本的可执行文件时，shell 分派一个子 shell 来运行脚本。此外，括号括起的命令在子 shell 中运行。

## 超级块 (superblock)

包含文件系统信息的块。超级块包含管理信息，例如文件系统的 inode 数量和空闲列表信息。

## 超级服务器 (superserver)

扩展 Internet 服务守护进程。参阅第 386 页的 xinetd。

## 超级用户 (Superuser)

使用 root 权限的用户。该用户拥有任何其他系统用户的权限以及更多。系统管理员必须成为超级用户（具有 root 权限）以建立帐户、更改密码并执行其他管理任务。超级用户的用户名是 root。也称为 root 或 root 用户。

## 交换 (swap)

操作系统将进程从主内存移动到磁盘，反之亦然。交换进程允许另一个进程开始或继续执行。参阅第 564 页。

## 交换空间 (swap space)

用于存储进程内存部分的磁盘区域（即交换）。在虚拟内存系统中，交换空间的大小而不是物理内存的大小决定了单个进程的最大以及所有活动进程的总大小。也称为交换区域或交换区。

## 交换机 (switch)

见第 1050 页的网络交换机。

## 符号链接

指向另一个文件路径的目录条目。在大多数情况下，指向文件的符号链接的使用方式与硬链接相同。与硬链接不同，符号链接可以跨越文件系统并连接到目录。

## 系统管理员

负责系统维护的人员。系统管理员能够以 root 身份登录或使用 `sudo` 以 root 权限进行工作。参见超级用户。

## 系统控制台

主终端，通常直接连接到计算机，并接收系统错误信息。也称为控制台或控制台终端。

## 系统模式

系统在执行系统工作时的状态标识。一些示例包括：进行系统调用、运行 NFS 和 autofs、处理网络流量以及代表系统执行内核操作。与用户模式（第 1067 页）对比。

## System V

UNIX 系统的两个主要版本之一。

## TC Shell

`tcsh`。BSD Unix shell 的增强型但完全兼容的版本。

## TCP

传输控制协议（Transmission Control Protocol）。互联网上常用的传输协议。这种面向连接的协议构建在 IP（第 1042 页）之上，几乎总是以 TCP/IP（TCP over IP）的形式出现。TCP 增加了通信、排序和流控制，提供了全双工的进程间连接。UDP（第 1066 页）虽然是无连接的，但它是运行在 IP 之上的另一种协议。

## tera-

在二进制系统中，前缀 tera- 乘以 2⁴⁰（1,099,511,627,776）。Terabyte（字节）是该前缀的常见用法。缩写为 T。另见第 1044 页的大数。

## termcap

终端能力（Terminal capability）。`/etc/termcap` 文件包含各种类型终端及其特性列表。System V 用 terminfo 系统取代了该文件的功能。

## 终端

与工作站（第 1069 页）的区别在于其缺乏智能性，终端连接到运行 Linux 的计算机。工作站则在本地运行 Linux。

## terminfo

终端信息（Terminal information）。`/usr/lib/terminfo` 目录包含许多子目录，其中包含若干文件。这些中的每个文件都以特定的终端命名，并持有该终端功能特征的摘要。视觉导向的文本程序（如 vim）使用这些文件。它是 termcap 文件的替代方案。

## 文本框

一种 GUI 控件（第 1068 页），允许用户输入文本。

## 主题

定义为一种隐性或循环的理念，主题在 GUI 中用于描述桌面所有元素保持一致的外观。示例见 themes.fresh.net。

## thicknet（粗缆网）

一种用于以太网的同轴电缆（粗型）。设备通过在固定点打接连接到粗缆网。

## thinnet（细缆网）

一种用于以太网的同轴电缆（细型）。细网电缆比粗缆电缆直径更小、更灵活。每个设备通常通过 T 型连接器连接到两个独立的电缆段；一段连接到网络中前一个设备，另一段连接到后续设备。

## thread-safe（线程安全）

参见第 1056 页的 `reentrant`（重入）。

## thumb（滑块）

滚动条（第 1059 页）中的活动按钮，用于确定图像在窗口中的位置。滑块的大小反映了缓冲区中的信息量。也称为 bubble（泡）。

## tick（标记）

一种标记，通常在复选框（第 1028 页）中，表示肯定响应。该标记可以是勾（✓）或 x。也称为 `checkmark`（钩号）或 check。

## TIFF

标记图像文件格式。一种用于静态图像位图的文件格式，存储在标记的字段中。应用程序曾可以根据其能力使用标记来忽略某些字段。

## tiled windows（平铺窗口）

一种窗口排列方式，没有任何窗口重叠另一个。它是层叠窗口（第 1027 页）的相反。

## time to live（生存时间）

参见 TTL。

## toggle（切换）

在不同位置之间切换。例如，`ftp glob` 命令切换 `glob`（通配符）功能：输入命令即可开启或关闭；再次输入命令即可将功能恢复到原始状态。

## token（令牌）

语言中基本的、语法上不可分割的单元，例如关键字、操作符或标识符。

## token ring（令牌环）

一种局域网（LAN，第 1044 页），计算机连接到环形电缆上。令牌数据包在环上持续循环。计算机只有在持有令牌时才能传输信息。

## tooltip（工具提示）

一种微上下文帮助，用户通过鼠标指针悬停在对象（如面板上的对象）上激活。

## transient window（瞬态窗口）

一种仅显示很短时间的对话框或其他窗口。

## Transmission Protocol（传输协议）

参见第 1064 页的 TCP。

## Trojan horse（特洛伊木马）

一词由 MIT 黑客转变为 NSA 特工的 Dan Edwards 创造。它指的是一种伪装成无害内容的恶意安全破坏程序，例如目录列表、归档工具、游戏或（在 1990 年一个著名的 Mac 案例中）用于查找并破坏病毒的程序。与 back door（后门，第 1024 页）相似。

## TTL

生存时间（Time to live）。

1. 所有 DNS 记录都指定了有效期——通常最长一周。这个时间被称为记录的生存时间。当 DNS 服务器或客户端缓存记录时，它会递减 `TTL` 值。当 `TTL` 达到零时，记录被丢弃。在 IP 中，`TTL` 是一个指示数据包可以经过多少跳数的字段。
2. `TTL` 也用于 DNS 来指定记录应缓存多久。

## TTY

打字机（Teletypewriter）。终端设备。今天，TTY 指屏幕。

## tunneling（隧道技术）

在协议内部封装协议。隧道用于在不支持该协议的网络上传输数据。

## UDP

用户数据报协议。一种不可靠的无连接协议。
