## 调整墙体参数

墙体整齐地位于提供的空间内，但它比所需的要短得多。与`VIZ`中的大多数对象一样，你可以调整墙体的参数和子对象以获得你想要的结果。

- 1. 选中墙体后，点击命令面板的`修改（Modify）`选项卡。

- 2. 点击墙体旁边的加号展开`修改器栈（modifier stack）`中的`墙体`列表，然后高亮`段（Segment）`子对象级。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_273_2.png)

- 3. 在视图中，选择所有三个`墙段`。可以自由使用`选择区域`快速拾取所有段；在`子对象`模式下，你无法选择任何额外对象。

- 4. 在`编辑段（Edit Segment）`部分中，将`高度（Height）`参数增加到`19' 8"`。选中的段向上延伸，现在与套件中的其他墙体高度匹配。

- 5. 点击`修改器栈`中的`墙体（Wall）`以退出`子对象`级。

- 6. 右键点击`Wall`视图标签，选择`视图（Views）➤ 透视（Perspective）`。

## 理解墙对象的高度和底部偏移参数

`编辑段（Edit Segment）`展开列表中的`底部偏移（Bottom Offset）`控制`墙底部`相对于`初始高度`的位置。`高度（Height）`值是从`墙底部`到`顶部`的距离。例如，`正值`会将墙抬高离开地面，并同样抬高`墙顶部`。

## 添加门窗

门窗不仅需要在墙体中正确定位和对齐，还需要一个`开口`。如果没有`开口`，只能看到穿过墙体的`门框`或`窗框`，而不是`门窗`。如果`墙`是简单的`几何体（primitive）`或`网格（mesh）`，可以使用上一章讨论的`布尔技术`形成`开口`。当`墙`是参数化`VIZ`对象时，可以同时创建`门窗对象`及其`开口`。使用后一种方法，当移动`门`或`窗`时，`开口`会自动调整。

- 1. 右键点击墙体，从`选择（Selection）`菜单隐藏场景中的其他对象。

- 2. 右键点击`透视`视图的标签切换为`线框（Wireframe）`，或按下`F3`。在`线框模式`下更容易看到`门`的创建过程。

- 3. 平移、放大并`圆弧旋转`透视视图，直到看到`墙顶部`，类似于`图 5.2`。

- 4. 右键点击主工具栏上的`捕捉（Snap）`以打开`网格和捕捉对话框`。清除所有`捕捉`选项，仅激活`边缘/段（Edge/Segment）`。`边缘/段`选项将`门`或`窗`捕捉到相对于`墙`的正确位置和朝向。关闭`网格和捕捉对话框`。

## 修改门参数

你可以更改`门`的许多参数，包括`门框`和`门扇`的大小及复杂度，以满足设计要求。方法如下：

- 1. 选中`门`后，点击`修改（Modify）`选项卡，并在`参数`展开列表中增加`开启（Open）`值以查看`门`的`摆动方向`，如`图 5.3`所示。

- 2. 勾选`翻转摆向（Flip Swing）`和`翻转合页（Flip Hinge）`选项以反转`摆向`并将`合页`移动到`门框`的`对侧`。

| 双开门 (Double Doors) |
| :--- |
| 翻转摆向 (Flip Swing) |
| 翻转合页 (Flip Hinge) |
| 开启 72.5 度 (Open 72.5 deg) |

大多数人认为`门`是推时会摆动的大矩形物体，但在`VIZ`中并非如此。在`VIZ`中，这被称为`扇（leaf）`，`门对象`由`门框`和`扇`组成。`扇`本身拥有一套控制其外观和复杂度的参数。

### 图 5.3

`Open（开启）`参数决定了`门`跟随的`摆动角度数`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_277_0.png)

- 3. 在`Leaf Parameters（叶子参数）`展开面板中，将`# Panels Horiz（水平面板数）`改为`2`，将`# Panels Vert（垂直面板数）`改为`5`。`门`会立即反映变化。

## 开启边缘面模式

你可以按下`F4`键，或者从`视口标签`的右键菜单中选择`Edged Faces（边缘面）`，进入`边缘面模式`，以便更好地查看`门`参数更改的结果。

- 4. 在`Leaf Parameters`展开面板的`Panels（面板）`区域中，选择`Beveled radius（倒角半径）`按钮。如你所见，只需调整参数`门`就可以变得非常详细。

- 5. 点击`Exit Isolation（退出隔离模式）`以显示当`墙体`被隔离时被隐藏的所有对象。

- 6. 调整你的`Perspective（透视）`视口，再次清晰地看到`门`。

## 创建窗户

也许你的`墙`需要一个`窗户`让光线进入房间。按照以下步骤添加一个：

- 1. 重复创建过程，但这次点击`Create Geometry（创建几何体）`，然后在下拉菜单中选择`Windows（窗户）`。

- 2. 点击`Object type（对象类型）`展开面板中的`Sliding（滑动）`按钮，并使用`Edge/Segment snap（边缘/段吸附）`将`窗户`放置在`绿色墙`上，靠近`透视视口`中看到的`灰色墙`。

- 3. 将`窗户`沿`墙`上移动，然后根据你的喜好调整`参数`。在`Open Window（开启窗户）`区域使用`Open 文件`打开`窗户`。注意，如果你移动`窗户`，`墙`上的`洞`也会随之移动。你的`窗户`看起来应该类似于`图 5.4`中的那个。

## 使用楼梯改变高度
