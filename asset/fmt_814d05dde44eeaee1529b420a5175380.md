
# chown 命令

用法：`chown [选项]... [所有者][:组]`

功能：`chown` 将文件的所有者改为指定的用户或组，可以使用用户名或用户 ID，组可以是组名或组 ID。只有 root 用户才有权限修改文件的所有者。

`chown` 命令的常用选项及说明见表 4-9。

## 表 4-9 chown 命令的常用选项

| 选项 | 说明 |
| :--- | :--- |
| `-R`, `--recursive` | 以递归方式更改所有的文件及子目录 |
| `--reference=<参考文件>` | 将文件的所有者设置为与 `<参考文件>` 相同 |

### 示例 1：设置文件所有者

修改 `sample1` 的所有者为 `alice`，如清单 4-44 所示。

```
$ ls -l ~jack/sample1
总量 9216
-rw-r---- 1 jack jack 10476 12月 03 sample1
$ su root
# chown alice ~jack/sample1
# ls -l ~jack/sample1
-rw-r---- 1 alice jack 10476 12月 09
```

> **注意**：修改文件的所有者和组，一般来说只有 root 才有权限。该用户/组必须存在，否则出错。

### 示例 2：设置组

修改 `sample2` 的组为 `group`，如清单 4-45 所示。

```
# chown :group ~jack/sample2
# ls -l ~jack/sample2
-rw-r---- 1 jack group 304 12月 09
```

### 示例 3：设置所有者和组

修改 `sample03` 的所有者为 `alice`，组为 `group`，如清单 4-46 所示。

```
# chown alice:group ~jack/sample03
# ls -l ~jack/sample03
-rw-r---- 1 alice group 1943 12月 09
```

### 示例 4：递归设置目录及其内容的所有者和组

修改当前目录和文件的所有者为 `alice`，组为 `group`，如清单 4-47 所示。

```
# chown -R alice:group ~jack/sampledir
# ls -ld ~jack/sampledir
drwxr-xr-x 2 alice group 4096 12月 24
```

# chmod 命令

下面首先介绍 `chmod` 命令的语法格式，然后用实例来演示和说明。

用法：`chmod [选项] 模式... 文件...`

其中，模式有两种写法：一种是字符方法，另一种是数字方法。常用选项如表 4-10 所示。

## 表 4-10 chmod 命令的常用选项

| 选项 | 说明 |
| :--- | :--- |
| `-R`, `--recursive` | 以递归方式更改所有的文件及目录 |
| `--dereference` | 修改指向的文件而非符号链接本身 |
| `--reference=<参考文件>` | 将权限设置为与 `<参考文件>` 相同 |

### 示例 1：使用字符方法

将 `hello.sh` 修改为所有者可读可写可执行，组用户可读可执行，其他用户无权限，如清单 4-48 所示。

```
$ ls -l ~/hello.sh
-rw-r---- 1 stu stu 23 12月 19:23 hello.sh
$ chmod u+rwx,g=rx,o-rwx ~/hello.sh
$ ls -l ~/hello.sh
-rwxr-x--- 1 stu stu 23 12月 19:23 hello.sh
```

> **注意**：字符模式中 `u` 表示所有者，`g` 表示所属组，`o` 表示其他用户，`a` 表示所有用户；`+` 增加权限，`-` 移除权限，`=` 设置权限。

### 示例 2：使用八进制数字方法

将 `sampledir` 目录修改为所有者可读写执行，所属组可读执行，其他用户可读执行，如清单 4-49 所示。

```
$ ls -ld ~/sampledir
drwxr-xr-x 2 stu stu 4096 12月 30 sampledir
$ chmod 755 ~/sampledir/
$ ls -ld ~/sampledir
drwxr-xr-x 2 stu stu 4096 12月 30 sampledir
```

在 `chmod` 命令中，八进制权限模式下一般用八进制数字表示一个文件的访问权限。每个数字代表三位二进制位，对应读、写、执行权限。八进制数字与访问符号对照表如表 4-11 所示。

## 表 4-11 八进制数字和文件访问符号对照表

| 符号 | 二进制 | 八进制 | 说明 |
| :--- | :---: | :---: | :--- |
| `rwx` | `111` | `7` | 读、写、执行 |
| `rw-` | `110` | `6` | 读、写 |
| `r-x` | `101` | `5` | 读、执行 |
| `r--` | `100` | `4` | 只读 |
| `-wx` | `011` | `3` | 写、执行 |
| `-w-` | `010` | `2` | 只写 |
| `--x` | `001` | `1` | 只执行 |
| `---` | `000` | `0` | 无权限 |

> **注意**：`umask` 的第一位与文件特殊访问权限有关，这里不进行讨论。

### 示例 3：修改 `umask` 设置默认权限

也可以更改创建前用户的 `umask`，使得新创建的文件或目录默认拥有特定权限。例如，将 `umask` 设为 `0077`，使新文件仅所有者有权限，如清单 4-51 所示。

```
$ umask 0077
$ umask
0077
$ touch newfile
$ mkdir newdir
$ ls -ld newfile newdir
-rw------- 1 dev01 dev01 0 10月 8 15:30 newfile
drwx------ 1 dev01 dev01 0 10月 8 15:30 newdir
```

> **注意**：用 `umask` 命令修改的 `umask` 值是临时的，如果要永久生效，就需要修改文件 `/etc/bashrc` 或者 `/etc/profile`。一般来说，没有必要去修改用户的默认 `umask` 值。

## 1. touch 命令

下面首先介绍 `touch` 命令的语法格式，然后用例子来进行展示和说明。

> **命令**：`touch`
>
> **用法**：`touch [选项]... 文件...`
>
> **功能**：将每个文件的访问时间和修改时间改为当前时间。不存在的文件会被创建为空文件，除非使用 `-c` 或 `-h` 选项。如果文件名为 `-` 则特殊处理，更改与标准输出相关的文件的访问时间。

`touch` 命令的常用选项及说明如表 4-13 所示。

## 表 4-13 touch 命令的常用选项及说明

| 选项 | 说明 |
| :--- | :--- |
| `-a` | 只更改访问时间 |
| `-c`, `--no-create` | 不创建空文件 |
| `-d`, `--date=<字符串>` | 使用字符串表示的时间而非当前时间 |
| `-m` | 只更改修改时间 |
| `-r`, `--reference=<文件>` | 使用指定文件的时间属性而非当前时间 |
| `-t <时间戳>` | 使用 `[[CC]YY]MMDDhhmm[.ss]` 格式而非当前时间 |

### 示例 1：创建空文件

如清单 4-52 所示。

```
$ touch file2
$ ls -l
总用量 0
-rw-rw-r-- 1 stu stu 0 2月 3 08:38 file1
-rw-rw-r-- 1 stu stu 0 2月 3 08:38 file2
# 可以使用通配符
$ touch file{a..d}
$ ls -l
总用量 0
-rw-rw-r-- 1 stu stu 0 2月 3 08:38 file1
-rw-rw-r-- 1 stu stu 0 2月 3 08:38 file2
-rw-rw-r-- 1 stu stu 0 2月 3 08:40 filea
-rw-rw-r-- 1 stu stu 0 2月 3 08:40 fileb
-rw-rw-r-- 1 stu stu 0 2月 3 08:40 filec
-rw-rw-r-- 1 stu stu 0 2月 3 08:40 filed
```

### 示例 2：修改文件时间（最后访问时间）

如清单 4-53 所示。

```
# 不添加选项，将时间戳改为当前时间
$ ls -l
-rw-rw-r-- 1 stu stu 0 2月 3 08:49 file1
$ touch file1
$ ls -l
-rw-rw-r-- 1 stu stu 0 2月 3 08:52 file1
# -d 选项指定时间，将时间戳修改为2019年03月06日
$ touch -d 20190306 file1
$ ls -l
总用量 0
-rw-rw-r-- 1 stu stu 0 2月 3 08:49 file1
-rw-rw-r-- 1 stu stu 0 3月 6 2019 file2
# -r 选项指定文件，将时间戳改为和该文件相同
$ touch -r /etc/centos-release file1
$ ls -l /etc/centos-release
-rw-r--r-- 1 root root 359 8月 29 2018 /etc/centos-release
$ ls -l file1
-rw-rw-r-- 1 stu stu 0 8月 29 2018 file1
```

## 2. cp 命令

介绍 `cp` 命令的语法格式，然后用多个用例来进行展示和说明。

> **命令**：`cp`
>
> **用法**：`cp [选项]... [-T] 源文件 目标文件` 或 `cp [选项]... 源文件... 目标目录`
>
> **功能**：将源文件复制到目标文件，或将多个源文件复制到目标目录。如果最后一个参数是一个已经存在的目录，`cp` 会将每个文件复制到该目录（维持原文件名）。

`cp` 命令的常用选项及说明如表 4-14 所示。

## 表 4-14 cp 命令的常用选项

| 选项 | 说明 |
| :--- | :--- |
| `-f`, `--force` | 如果目标文件无法打开，则将其移除并重试 |
| `-i`, `--interactive` | 覆盖前询问 |
| `-l`, `--link` | 创建硬链接文件而不复制文件 |
| `-n`, `--no-clobber` | 不覆盖已存在的文件（使 `-i` 选项失效） |
| `-p`, `--preserve` | 复制时保留文件的访问权限、所有者、组和时间 |
| `-R`, `-r`, `--recursive` | 递归复制目录及其子目录 |
| `-s`, `--symbolic-link` | 创建符号链接而不是复制 |
| `-u`, `--update` | 在源文件比目标新，或目标文件不存在时复制 |
| `-d` | 复制符号链接本身而非指向的文件，且保护副本 |

### 示例 1：复制单个文件到目标目录

如清单 4-54 所示。

```
$ cp myfile.txt /home/stu/office/
```

> **注意**：
> * 如果目标是一个目录，那么文件就会复制到目录中保持原名。
> * 如果目标是文件名，那么文件就会复制到目录中并重命名。

### 示例 2：复制多个文件到目标目录

如清单 4-55 所示。

```
$ cp file1.txt file2.txt file3.txt /home/stu/
```

> **注意**：复制多个文件时，目标必须是目录。

### 示例 3：使用 `-r` 或者 `-R` 选项复制目录

无论源目录为空，这个选项都是必要的，如清单 4-56 所示。

```
$ cp -r mydir /home/stu/
```

> **注意**：复制目录时使用 `-l` 是无效的。

### 示例 4：使用 `-p` 选项，复制文件时保留属性

在复制文件时，默认文件的访问权限由 `umask` 值重新定义，文件的所有者和组变为当前用户。对于 `cp` 命令添加 `-p` 选项，保留上述属性，如清单 4-57 所示。

```
$ cp -p file01 /home/stu/
$ ls -l file01
-rw-rw-r-- 1 stu stu 0 12月 3 file01
```

> **注意**：
> 切换到 root，`cp ~stu/file01` 复制到当前工作目录。
> ```
> $ su root
> # cp ~stu/file01 .
> # 发现文件所有者和组变为 root
> # ls -l file01
> -rw-rw-r-- 1 root root 0 12月 3 file01
> # 复制以保护属性
> # cp -p ~stu/file01 ./file01_bak
> # ls -l *
> -rw-rw-r-- 1 root root 0 12月 3 file01
> -rw-rw-r-- 1 stu stu 0 12月 3 file01_bak
> ```

### 示例 5：使用 `-i` 选项添加交互提示

在复制时出现同名文件，询问是否覆盖，如清单 4-58 所示。

```
$ ls /home/stu/sampledir/
file01
$ cp -i /tmp/file01 ~/sampledir/
cp: 是否覆盖 '/home/stu/sampledir/file01'? y
```

### 示例 6：root 用户的影响

对于 root 用户，系统用 `cp -i` 命令创建一个别名。因此，root 用户在使用 `cp` 命令时，实际上是在使用 `cp -i`。不想使用这个别名，需要在 `cp` 前加上反斜杠 `\`，表示使用 `cp` 命令本身，如清单 4-59 所示。

```
$ alias cp
alias cp='cp -i'
$ cp /tmp/file01 ~/sampledir/
cp: 是否覆盖 '/home/stu/sampledir/file01'? y
$ \cp /tmp/file01 ~/sampledir/
```

> **注意**：只有 root 用户在复制文件时出现提示，这是因为 root 用户权限太大，系统担心误覆盖文件，所以为 root 用户创建了别名并自动添加了 `-i` 选项。

### 示例 7：用 `-l` 选项实现创建硬链接替代文件

有时由于某些原因（例如为了节省空间或控制版本），希望在目标目录创建硬链接来替换文件，如清单 4-60 所示。

```
$ ls -il /usr/share/myfile
1246 -rw-r--r-- 1 root root 0 12月 3 /usr/share/myfile
# 在当前用户目录下建立一个硬链接，两个文件的索引号指向同一数据块
$ cp -l /usr/share/myfile ~/myfile
$ ls -il ~/myfile
1246 -rw-r--r-- 1 root root 0 12月 3 ./myfile
```

> **注意**：操作不是将 `/usr/share/myfile` 复制到当前工作目录中，而是建立了一个链接。这两个文件有着相同的索引号 (1246)。复制目录时使用 `-l` 选项是无效的，`cp` 会忽略该选项。

### 示例 8：用 `-s` 选项创建符号链接

与示例 7 相同，希望在目标中建立符号链接而非复制内容，如清单 4-61 所示。

```
$ cp -s /usr/share/file01 /home/stu/file01
$ ls -l /home/stu/file01
lrwxrwxrwx 1 stu stu 20 12月 3 /home/stu/file01 -> /usr/share/file01
```

> **注意**：选择选项 `-R` 时，`cp` 命令复制目录中的所有层级目录，但不复制其他文件，而是创建链接。

## 3. mv 命令

下面介绍 `mv` 命令的语法，然后用例子来进行演示和说明。`mv` 和 `cp` 的用法相当，这里只展示不同之处。

> **命令**：`mv`
>
> **用法**：`mv [选项]... 源文件 目标文件` 或 `mv [选项]... 源文件... 目标目录`
>
> **功能**：将源文件重命名为新文件名，或将源文件移动到指定目录。

`mv` 命令常用选项及说明见表 4-15。

## 表 4-15 mv 命令的常用选项

| 选项 | 说明 |
| :--- | :--- |
| `-f`, `--force` | 强制覆盖不询问 |
| `-i`, `--interactive` | 覆盖前询问 |
| `-u`, `--update` | 只在源文件较新或目标文件不存在时移动 |

### 示例 1：用 `mv` 移动目录

`mv` 命令可以直接移动目录，如清单 4-62 所示。

```
$ ls -ld /tmp/sampledir
drwxr-xr-x 2 root root 4096 1月 1 00:00 /tmp/sampledir
$ mv /tmp/sampledir /home/stu/
```

### 示例 2：用 `mv` 重命名文件

如果目标是文件名，则相当于重命名，如清单 4-63 所示。

```
$ mv file1 file2
```

> **注意**：如果目标是一个目录，那么文件就会移动到目录中。

## 4. rm 命令

下面首先介绍 `rm` 命令的语法，然后用例子来进行展示和说明。

> **命令**：`rm`
>
> **用法**：`rm [选项]... 文件...`
>
> **功能**：删除文件或目录。

`rm` 命令的常用选项及说明见表 4-16。

## 表 4-16 rm 命令的常用选项

| 选项 | 说明 |
| :--- | :--- |
| `-f`, `--force` | 强制删除不提示 |
| `-i`, `--interactive` | 删除前询问 |
| `-R`, `-r`, `--recursive` | 递归删除目录及其内容 |

### 示例 1：删除普通文件

```
$ rm file1
```

### 示例 2：使用 `-i` 选项确认删除

```
$ rm -i file1
rm: 是否删除普通文件 'file1'? y
```

### 示例 3：使用 `-f` 强制删除不存在的文件

```
$ rm -f nonfile
```

### 示例 4：使用 `-R` 递归删除目录

```
$ rm -R mydir
```

### 示例 5：使用 `-rf` 强制递归删除目录

```
$ rm -rf mydir
```

## 5. find 命令

`find` 命令的常用表达式及说明见表 4-19。

## 表 4-19 find 命令的常用表达式及说明

| 表达式 | 说明 |
| :--- | :--- |
| `-print` | `find` 命令的默认操作，将找到的文件名输出 |
| `-fprint <filename>` | 将找到的文件输出到指定文件 |
| `-ls` | 使用 `ls` 格式输出文件 |
| `-exec command {} +` | 对找到的文件执行命令，用 `{}` 代替找到的文件 |
| `-ok` | 与 `-exec` 相似，只不过在对文件执行之前会询问是否执行 |

### 示例：按文件名查找

在 `/tmp` 目录下查找名为 `sample` 的文件。

```
$ find /tmp -name sample
```
