# tput — 初始化终端或查询 terminfo 数据库

### 概要
`/usr/bin/tput [-Ttype] capname [parm...]`
`/usr/bin/tput -S <<`

## 描述
`tput` 命令使用 `terminfo` 数据库使 shell 可用终端相关的特性和信息（参见 `sh(1)`）；用于清除、初始化或重置终端；或返回请求的终端类型的名称。如果能力属性 `capname` 类型为字符串，`tput` 输出字符串；如果属性类型为布尔值，`tput` 仅设置退出状态（如果终端具有该能力则为 0，否则为 1）且不产生输出。在从标准输出使用返回值之前，你应该测试退出状态以确认其是否为 0 (?, 参见 `sh(1)`））。

## 选项
`-Ttype` 指示终端类型。通常你不需要使用此选项，因为默认值来自环境变量 `LINES` 和 `COLUMNS`，如果你指定了 `-T`，则不引用 shell 变量和层大小。
`-S` 允许每次调用 `tput` 时多个能力。你必须从标准输入将能力传递给 `tput`，而不是从命令行。每行只允许一个 `capname`。`-S` 选项更改了 0 和 1 布尔及字符串退出状态的含义。

### 操作数
`capname` 指示来自 `terminfo` 数据库的能力属性。参见 `terminfo(4)` 获取能力的完整列表以及每个能力关联的 `capname`。C 语言环境实现支持以下字符串作为操作数：
`clear` 显示清屏序列。
`init` 如果 `terminfo` 数据库存在且存在你的终端的条目（参见 `-Ttype`），将发生以下情况：

* 如果存在，输出终端的初始化字符串 `is1, is2, is3, if, iprog`。
* 设置 tty 驱动程序条目中指定的任何延迟（例如，换行）。

# tr — 翻译字符

```
/usr/bin/tr [-cs] string1 string2

/usr/bin/tr -s|-d [-c] string1

/usr/bin/tr -ds [-c] string1 string2

/usr/bin/xpg4/tr [-cs] string1 string2

/usr/bin/xpg4/tr -s|-d [-c] string1

/usr/bin/xpg4/tr -ds [-c] string1 string2
```

### 概要

使用 `tr` (translate) 命令将文件中一组字符串替换为另一组或从文件中删除指定的字符。`tr` 命令是常用的 UNIX 命令之一，它不允许你指定文件名作为参数。相反，你必须使用 `<` 重定向符号。

`tr` 命令可以翻译任意数量的字符。通常，你提供一个输入字符列表（指定为 `string1`），后面跟着输出字符列表（指定为 `string2`），用 `string1` 中的每个字符实例替换为 `string2` 中对应的字符。

指定的选项以及 `string1` 和 `string2` 操作数控制着在复制字符和单字符排序元素时发生的操作。

## 描述

注意 — 与之前的版本不同，`tr` 命令可以正确处理输入流中的空字符（null characters）。你可以通过 `tr -d '\0000'` 来剔除空字符。

## 选项

`-c`
对 `string1` 指定的字符集取补集。

`-d`
删除 `string1` 指定的所有输入字符的出现。

`-s`
将重复字符的实例替换为单个字符。

当你不指定 `-d` 选项时：

- 在 `string1` 指定数组中找到的每个字符都被替换为 `string2` 指定数组中相同位置的字符。如果 `string2` 指定的数组比 `string1` 指定的数组短，则结果未定义。

- 如果你指定了 `-c` 选项，`string1` 指定字符的补集（当前 `LC_TYPE` 设置定义的当前字符集中所有字符，但数组操作数中实际指定的字符外）将按照当前 `LC_COLLATE` 设置定义的升序排序排列。

- 因为由类表达式或等价类表达式指定的字符的顺序是未定义的，因此只有当你打算将多个字符映射到一个字符时，才使用此类表达式。一个例外是下文描述的大小写转换。

当你指定了 `-d` 选项时：

- `string1` 指定数组中找到的输入字符将被删除。

- 当你结合 `-d` 使用 `-c` 时，除 `string2` 指定字符外的所有字符都被忽略，除非你也指定了 `-s` 选项。

- 你不能对 `-d` 和 `-s` 选项使用相同的字符串；当你同时指定这两个选项时，需要指定 `string1`（用于删除）和 `string2`（用于压缩/squeeze）。

- 当你指定了 `-s` 选项时，在执行任何删除或翻译之后，如果该字符出现在最后一个操作数指定的数组中，则相同字符的重复序列将被替换为一次该字符。如果最后一个操作数包含字符类（例如 `tr -s '[:space:]'`），则最后一个操作数的数组包含该类中的所有字符。然而，在下文描述的大小写转换中，如 `tr -s '[:upper:]' '[:lower:]'`，最后一个操作数的数组仅包含在每个 `toupper` 或 `tolower` 对中被定义的第二个字符（视情况情况，参见 `toupper(3)` 和 `tolower(3)`）。

- `string1` 或 `string2` 为空字符串会导致未定义的结果。

### 操作数

`string1`

翻译控制字符串。每个字符串代表一组字符，这些字符将被转换为用于翻译的字符数组。

`string2`

操作数 `string1` 和 `string2`（如果指定）定义了两个字符数组。你可以使用列表中的构造来指定字符或单字符排序元素。如果任何构造导致了多字符排序元素，`tr` 将在不提供诊断的情况下排除结果数组下方未描述的多字符元素。

`character`

任何未由约定描述的字符都代表其自身。

`\octal`

你可以使用八进制序列来表示具有特定编码值的字符。八进制序列由一个反斜杠后跟最长的一个、二或三位八进制数字序列（0123457）组成。该序列将由一、二或三位整数表示编码的字符放入数组。多字节字符需要多个此类类型的连接序列，每个字节都需要一个反斜杠。

`\character`

支持反斜杠转义序列 `\a`, `\b`, `\f`, `\n`, `\r`, `\c` 和 `\v`。在反斜杠后使用八进制数字以外的任何字符的结果都是未定义的。

```
c-c (/usr/xpg4/bin/tr)

[c-c] (/usr/bin/tr)
```
