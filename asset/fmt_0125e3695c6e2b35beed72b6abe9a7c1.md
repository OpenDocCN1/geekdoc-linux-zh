
`Status XcmsAllocColor(display, colormap, color_in_out, result_format);`

- `display` 指定到 X 服务器的连接。
- `colormap` 指定颜色表。
- `color_in_out` 指定要分配的颜色，并返回在颜色表中实际使用的像素。
- `result_format` 指定返回颜色规格的颜色格式。

# 颜色管理函数

`XcmsAllocColor` 函数与 `XallocColor` 类似，但颜色可以用任何格式指定。`XcmsAllocColor` 函数最终调用 `XallocColor` 来分配具有指定颜色的只读颜色（颜色表）。`XcmsAllocColor` 首先将指定的颜色转换为 RGB 值，然后将其传递给 `XallocColor`。`XcmsAllocColor` 返回颜色单元的值及其分配的颜色规格。此返回的颜色是将 `XallocColor` 返回的 RGB 值转换为 `result` 参数中指定的格式的结果。如果对结果颜色规格感兴趣，当 `result` 设置为 `XmsRGBFormat` 时，可以跳过不必要的拷贝。相应的颜色表是只读的。如果你的函数返回 `XmsFree`，则颜色或颜色规格将保持不变。

`XcmsAllocColor` 可能会产生 `BadError`。

要使用名称分配只读颜色，并以 RGB 格式返回硬件支持的最接近的颜色，请使用 `XallocNamedColor`。

| `Status XallocNamedColor(display, colormap, color_name, screen_def_return, exact_def_return);` |  |
| :--- | :--- |
| `display` | 指定到 X 服务器的连接。 |
| `colormap` | 指定颜色表。 |
| `color_name` | 指定颜色字符串名称（例如，red），即你所需的颜色定义结构。 |
| `screen_def_return` | 返回硬件提供的最接近的 RGB 值。 |
| `exact_def_return` | 返回精确的 RGB 值。 |

`XallocNamedColor` 函数根据与指定颜色表相关的屏幕查找命名颜色。它同时返回精确的数据库定义和屏幕支持的最接近的颜色。分配的颜色是只读的。像素值在 `screen` 中返回。如果颜色名称不在主机可用的字符编码（Hostable Character Encoding）中，结果取决于实现。使用大写或小写均可。如果 `screen_def_return` 和 `exact_def_return` 指向同一个结构，则像素字段将正确设置，但颜色值是未定义的。如果分配了颜色，`XallocNamedColor` 返回非零值；否则返回零。

`XallocNamedColor` 可能会产生 `BadError`。

要使用名称分配只读颜色，并以任意格式返回硬件支持的最接近的颜色，请使用 `XcmsAllocNamedColor`。

| `Status XcmsAllocNamedColor(display, colormap, color_string, color_screen_return, color_exact_return, result_format);` |  |
| :--- | :--- |
| `display` | 指定到 X 服务器的连接。 |
| `colormap` | 指定颜色表。 |
| `color_string` | 指定要返回颜色定义结构的颜色字符串。 |
| `color_screen_return` | 返回实际存储在该单元的颜色单元像素值和颜色规格。 |
| `color_exact_return` | 返回从颜色字符串解析出或从颜色名称数据库中找到的对应字符串解析出的颜色规格。 |
| `result_format` | 指定返回的颜色规格的颜色格式（`color_screen` 和 `color_exact_return` 参数）。如果格式是 `XmsRGBFormat`，则可以跳过不必要的拷贝。相应的颜色表是只读的。如果你的函数返回 `XmsFree`，则颜色或颜色规格将保持不变。 |

`XcmsAllocColor` 可能会产生 `BadError`。

或者如果名称已解析，则返回 `XcmsSuccessWithCompression`；否则返回 `XcmsFailure`。如果返回了 `XcmsSuccessWithCompression`，则颜色屏幕返回的颜色规格将返回色域压缩的值。

## 分配和释放颜色单元

分配颜色单元有两种方式：显式地作为只读单元分配，或者一次分配一个像素，或者读/写单元，在这些情况下，你可以同时分配多个颜色单元和平面。只读单元的 RGB 值由服务器设置；读/写单元最初没有定义的颜色；下一节中指定的单元必须用于将值存储到它们中。任何客户端都可能将值存储在另一个客户端分配的读/写单元中，但通常情况下，读/写单元应该被视为分配它们的客户端的私有单元。

只读颜色单元在客户端之间共享。服务器会统计客户端对单元的每次分配和释放操作。当最后一个客户端释放共享单元时，该单元最终会被释放。如果单个客户端多次分配同一个只读单元，服务器会计算每一次此类分配，而不是只第一次。

要分配一个具有 RGB 值的只读单元，请使用 `XallocColor`。

`Status XallocColor(display, colormap, screen_in_out);`

- `display` 指定到 X 服务器的连接。
- `colormap` 指定颜色表。
- `screen_in_out` 指定并返回在颜色表中实际使用的值。

`XallocColor` 函数分配一个与硬件支持的最接近的 RGB 值相对应的只读颜色表。`XallocColor` 返回硬件支持的、与指定的 RGB 元素最接近的颜色像素值，并返回对应的只读颜色表单元。此外，`XallocColor` 在成功时返回非零值，在失败时返回零。多个请求相同有效 RGB 值的客户端可以分配相同的只读条目，从而允许条目共享。当最后一个客户端释放共享单元时，它会被释放。`XallocColor` 不使用或影响 `Xstructure` 中的标志位。

要分配一个具有任意格式颜色的只读颜色单元，请使用 `XcmsAllocColor`。

`Status XcmsAllocColor(display, colormap, color_in_out, result_format);`

- `display` 指定到 X 服务器的连接。
- `colormap` 指定颜色表。
- `color_in_out` 指定要分配的颜色，并返回在颜色表中实际使用的像素。
- `result_format` 指定返回颜色规格的颜色格式。
