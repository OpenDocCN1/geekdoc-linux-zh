## 第 5 章。处理文件

```assembly
movl ST_BUFFER_LEN(%ebp), %ebx
```

将函数参数移动到相应的寄存器中以便使用。然后，我们将 `%edi` 设置为 0。我们要执行的是通过从 `%eax + %edi` 位置加载来遍历缓冲区的每个字节，递增 `%edi`，并重复此操作直到 `%edi` 等于存储在 `%ebx` 中的缓冲区长度。以下几行代码

```assembly
cmpl $0, %ebx
je end_convert_loop
```

仅仅是一个简单的完整性检查（sanity check），以确保没有给我们提供大小为 0 的缓冲区。如果有的话，我们只需清理并退出。防止潜在的用户和编程错误是程序员的一项重要任务。你始终可以指定你的函数不接受大小为零的缓冲区，但更好的做法是让函数在发生这种情况时进行检查，并准备一个可靠的退出计划。

现在我们开始循环。它将一个字节移动到 `%cl`。对应的代码是：

```assembly
movb (%eax,%edi), %cl
```
