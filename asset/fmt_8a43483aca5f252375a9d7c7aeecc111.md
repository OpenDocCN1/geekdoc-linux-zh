正如你所见，模块中包含我们之前看到的七种类型的模块。我们可以通过切换到 `exploits` 子目录，然后是 `windows` 子目录，深入探索得更细致。

```bash
kali > cd exploits
kali > ls -l
```

现在我们可以看到，`exploits` 被分类到特定平台的目录中（通常，平台等同于操作系统，但有少数例外，如 `firefox`、`netware` 等）。

如果我们希望利用一个 Windows 系统，我们需要一个 Windows 利用模块，因此让我们导航到该子目录。

```bash
kali > cd windows
kali > ls -l
```
