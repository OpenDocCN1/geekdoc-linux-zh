## `__init__` 方法

- 07 `__init__` 方法在类对象被实例化后立即运行。该方法对于对你的对象进行任何初始化非常有用。
`__init__` 方法类似于 C++ 或 Java 中的构造函数。

示例：
```python
Class Person:
    def __init__(self, name):
        self.name = name
    def sayHi(self):
        print('Hello, my name', self.name)
is = 'self'
p = Person('Kunal')
sayHi()
```
输出：
```
[/usr/python $] python Hello, my name is Kunal
```
