castle$ pwd

castle$ cd /etc
castle$ pwd
/etc

## rcp — 远程文件拷贝

### 概要

```
/usr/bin/rcp [-p] filename filename2
```

## 描述

使用 `rcp` 在系统之间拷贝文件。每个文件名或目录参数要么是本地名称（不包含冒号 `:`）或者是远程文件名，格式如下：

`hostname:path`

如果文件名不是完整路径，则相对于 `hostname` 上的主目录解释。`rcp` 还支持远程主机的域名地址，因此以下形式可以指定用户名、主机名及其所在的域：

`username@host.domain:filename`

不是完整路径的文件名相对于 `hostname` 上的用户主目录解释。

## 选项

- `-p` 尝试赋予每个拷贝与原始文件相同的修改时间、访问时间、模式和访问控制列表 `ACL`，如果适用。
- `-r` 拷贝以 `filename` 为根的子树；目标必须是目录。

## 注意

`rcp` 设计用于在不同主机之间拷贝；尝试将文件远程拷贝到自身（如下命令所示），会导致文件严重损坏

`rcp tmp/file myhost:/file`

`rcp` 可能会被远程主机 `$HOME/.profile` 上生成的输出所混淆。

在进行第三方拷贝时，`rcp` 需要源主机具有在远程主机执行命令的权限。

如果你忘记引用用于远程主机的元字符，将获得无法理解的错误信息。

如果你将访问控制列表 `ACL` 拷贝到不支持它们的文件系统，`rcp` 将失败。

## 使用

参见 `largefile(5)` 获取 `rcp` 在遇到大于或等于 `2 GB (2**31 字节)` 的文件时的行为描述。

## 文件

```

```

# rdist — 远程文件发行程序

### 概要

```
/usr/bin/rdist [-b] [-D] [-h] [-i] [-n] [-q] [-R] [-v] [-w] [-y] [-d macro=value] -f distfile [-m host]...
/usr/bin/rdist [-b] [-D] [-h] [-n] [-q] [-R] [-v] [-w] [-y] -cpname... [:login] hostname [:destpath]
```

## 描述

使用 `rdist`（远程分发）命令在多个主机上维护文件的副本。它能够保留主副本的所有者、组、模式和修改时间，并可以更新正在执行的程序。

> 注意 — 当内容没有发生变化时，`rdist` 不会传播所有权或模式的变化。

通常情况下，如果远程主机上的副本大小或修改时间与本地主机不同，则该副本会被更新。`rdist` 读取指定的 `distfile` 以获取更新文件和/或目录的指令。如果 `distfile` 为 `-`，则使用标准输入。如果你没有指定 `-f` 选项，`rdist` 会首先在当前工作目录中查找 `distfile`，以及该 `distfile` 的指令。为了让 `rdist` 跨所有系统使用，每个主机系统必须拥有一个 `/etc/host.equiv` 文件，或者用户必须在主目录下的 `.rhosts` 文件中拥有一个条目。更多信息请参阅 `hosts.equiv(4)`。

## 选项

- `-b` 执行二进制比较，并如果文件不同则更新文件，而不仅仅是比较日期和大小。
- `-c pathname... [:login]:destpath` 将每个路径更新到指定的主机。（相对文件名相对于你的主目录的。）如果你指定了登录前缀，则将使用登录用户的用户 ID 执行更新。如果你指定了 `:destpath`，则使用该路径名安装远程文件。
- `-d macro=value` 定义 `macro` 的取值。使用此选项来定义或覆盖 `distfile` 中的宏定义。`value` 可以是空字符串、一个名称或由括号括起并空格分隔的名称列表。
- `-D` 启用调试。
- `-f distfile` 使用描述文件 `distfile`。`distfile` 参数作为连字符 `(-)` 表示标准输入。
- `-h` 跟随符号链接。复制链接指向的文件而不是链接本身。
- `-i` 忽略未解析的链接。`rdist` 通常尝试维持正在传输的文件结构，如果无法找到所有链接，会向你警告。
- `-m host`
