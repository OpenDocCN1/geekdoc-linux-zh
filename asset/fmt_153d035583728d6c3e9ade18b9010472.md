
以下列表显示了 JSON 值与 Python 值的映射。括号中列出的 Python 类型在编码时被接受，但在解码时不会返回（返回第一个列出的类型）。

| JSON 类型 | Python 类型 |
|---|---|
| object | dict |
| array | list (tuple) |
| string | unicode (str, bytes) |
| number | int, float |
| true | True |
| false | False |
| null | None |

对于字符串数据，你应该假设使用 Unicode。如果在编码过程中遇到字节字符串，它们将默认使用 `'utf-8'` 解码为 Unicode 字符串（尽管可以控制这一点）。解码时，JSON 数组返回为 Unicode。

使用以下函数来编码/解码 JSON 文档：

```python
dump(obj, f, **opts)
```

将 `obj` 序列化到类文件 `f`。`opts` 代表一组关键字参数，这些参数可以在序列化过程中指定：

|  | 说明 |
|---|---|
| `skipkeys` | 布尔标志，用于控制当字典键（其值）不是字符串或数字等基本类型时执行的操作。如果为 `True`，则跳过它们。如果为 `False`（默认值），将抛出 `TypeError`。 |
| `ensure_ascii` | 布尔标志，决定 Unicode 字符串是否可以写入文件 `f`。默认情况下为 `False`。只有当将其设置为 `True` 时，才能正确处理 Unicode，例如由 `codecs` 模块创建的文件或使用特定编码打开的文件。 |
| `check_circular` | 布尔标志，决定是否检查循环引用。默认是 `True`。如果为 `False` 且遇到循环引用，将抛出 `Overflow`。 |
| `allow_nan` | 布尔标志，决定是否允许超出范围的值。 |
| `cls` | 要使用的 `JSONEncoder` 子类。仅在你通过继承 `JSONEncoder` 创建了自定义类时使用。 |
| `indent` | 设置缩进量的非负整数。默认是 `None`。 |
| `separators` | 元组 `(item_separator, dict_separator)`，其中 `item_separator` 是字符串。默认是 `(',', ':')`。 |
| `encoding` | 用于 Unicode 字符串的编码。默认是 `'utf-8'`。 |

```python
dumps(obj, **opts)
```

与 `dump` 相同，但返回的是字符串。

# json

`load(f, **opts)`

反序列化文件 `f` 中的 JSON 对象。`opts` 代表一组关键字参数，下文所示。

| 关键字参数 | 说明 |
|---|---|
| `encoding` | 解析任何字符串值的编码。默认是 `utf-8`。 |
| `strict` | 布尔标志，决定 JSON 字符串中是否允许出现未转义的换行符。默认是 `True`，意味着出现此类字符串将生成异常。 |
| `cls` | 用于解码的 `JSONDecoder` 子类。`load()` 的额外关键字参数将传递给构造函数。 |
| `object_hook` | 在解码每个 JSON 对象时都会调用的函数。默认是内置的 `dict()` 函数。 |
| `parse_float` | 用于解码 JSON 浮点值的函数。默认是内置的 `float()` 函数。 |
| `parse_int` | 用于解码 JSON 整数值的函数。默认是内置的 `int()` 函数。 |
| `parse_constant` | 用于解码 JSON 常数（如 `'NaN'`、`'true'`、`'false'` 等）的函数。 |

```python
loads(s, **opts)
```

与 `load()` 相同，但返回的是字符串。

`JSONDecoder(**opts)`

解码 JSON 数据的类。`opts` 代表与 `load()` 函数相同的关键字参数。`JSONDecoder` 的实例 `d` 有以下两个方法：

`d.decode(s)`

返回 `s` 中 JSON 对象的 Python 表示。`s` 是一个字符串。

`d.raw_decode(s)`

返回一个元组 `(pyobj, index)`，其中 `pyobj` 是 `s` 中 JSON 对象的 Python 表示形式，`index` 是 `s` 中 JSON 结束结束的位置。当你尝试从一个末尾带有额外数据的输入流中解析出一个对象时，可以使用此方法。

`JSONEncoder(**opts)`

一个将 Python 对象编码为 JSON 的类。`opts` 代表一组关键字参数，这些参数与 `dump()` 函数中使用的参数完全相同。`JSONEncoder` 的实例 `e` 具有以下方法：

`e.default(obj)`

当 Python 对象 `obj` 无法按照任何标准规则进行编码时调用的方法。该方法应该返回一个结果，其类型可以是编码的类型之一（例如，字符串、列表或字典）。

`e.encode(obj)`

用于创建 Python 对象 `obj` 的 JSON 表示形式的方法。

`e.iterencode(obj)`

创建一个迭代器，该迭代器在计算时产生组成 Python 对象 `obj` 的 JSON 表示形式的字符串。创建 JSON 字符串的过程是高度递归的；例如，遍历字典的键，并向下遍历找到的字典和列表。如果你使用此方法，可以以分批的方式生成输出，而不是将所有内容收集到一个内存字符串中。

如果你定义了 `JSONDecoder` 或 `JSONEncoder` 的派类，如果你的类定义了带有所有关键字参数的 `__init__()`，你需要小心，以下是定义方式：

```python
class MyJSONEncoder(JSONEncoder):
    def __init__(self,**kwargs):
        # 获取所有参数
        foo = kwargs.pop('foo',None)
        bar = kwargs.pop('bar',None)
        # 使用剩余参数初始化父类
        JSONEncoder.__init__(self,**kwargs)
```

# mimetypes

`mimetypes` 用于根据文件名扩展名猜测文件相关的 MIME 类型。它还将类型转换为其标准扩展名。MIME 类型由类型/子类型对组成——例如 `'text/html'`, `'image/png'` 或 `'audio/mpeg'`。

`guess_type(filename, strict)`

根据文件名或 URL 猜测文件的 MIME 类型。返回一个元组 `(type, encoding)`，其中 `type` 是 `"type/subtype"` 字符串，`encoding` 是用于传输数据编码的程序（for, compress 或 gzip）。如果无法猜测类型，则返回 `(None, None)`。如果 `strict` 为 `True`（默认值），则只识别在 IANA 注册的官方 MIME 类型（参见 http://www.iana.org/assignments/media-types）。否则，也会识别一些常见的非官方 MIME 类型。

```python
guess_extension(type [, strict])
```

根据文件的 MIME 类型猜测文件的标准文件扩展名。返回一个以点（`.`）开头的文件扩展名字符串。对于未知类型返回 `None`。如果 `strict` 为 `True`（默认值），则只识别官方 MIME 类型。

```python
guess_all_extensions(type [, strict])
```

与 `guess_extension()` 相同，返回所有可能的文件名扩展名列表：

```python
init([files])
```

初始化模块。`files` 是读取以提取类型信息的文件名序列。这些文件包含将 MIME 类型映射到接受的文件后缀列表的行，如下：

```
image/jpeg: jpe jpg jpg
text/html: htm html
```

```python
read_mime_types(filename)
```

从文件名加载类型映射。返回一个映射文件名扩展名到 MIME 类型的字典。如果文件名不存在或无法读取，则返回 `None`。

```python
add_type(type, ext [, strict])
```

向映射添加新的 MIME 类型。`type` 是如 `'text/plain'` 的 MIME 类型，`ext` 是如 `'.txt'` 的文件扩展名，`strict` 是指示是否为官方注册 MIME 类型的布尔值。默认情况下，`strict` 为 `True`。

- 任何非空格 ASCII 字符（`=`' 除外）原样表示。
