
# 第 4 天：switch 语句与无限循环

## switch 语句基础

在第 4 天，你学习了如何编写 `if/else` 语句。这些嵌套时会变得非常复杂，`switch` 提供了一种替代方案。`if` 语句只能处理一个值，`switch` 允许对多个值进行分支。`switch` 语句的一般形式如下：

```cpp
switch (expression)
  case valueOne: statement;
  case valueTwo: statement;
  ...
  case valueN: statement;
  default: statement;
```

`expression` 是任何 C++ 表达式，而 `statements` 是任何语句。然而，`switch` 仅用于相等判断；不能使用关系运算符。

如果某个 `case` 值匹配，执行将跳转到这些语句。除非遇到 `break` 语句，否则执行将结束 `switch` 块。如果没有任何匹配项，执行将跳转到 `default`。

在 `switch` 语句中包含 `default case` 几乎是一个好主意。如果你没有匹配项，执行将结束 `switch` 语句。使用 `default`，这对调试有巨大的帮助。

注意，如果 `case` 末尾没有 `break` 语句，执行将穿透到下一个 `case`。这有时是必要的，但通常是因为你忘记了 `break`。

## 列表 7.16：switch 语句演示

```cpp
// Listing 7.16
// 展示 switch 语句

#include <iostream.h>

int main() {
    int number;
    cout << "Enter a number between 1 and 5: ";
    cin >> number;
    switch (number)
    {
        case 0: cout << "Too small, sorry!";
            break;
        case 5: cout << "Good job!\n"; // 穿透
        case 4: cout << "Nice Pick!\n"; // 穿透
        case 3: cout << "Excellent!\n"; // 穿透
        case 2: cout << "Masterful!\n"; // 穿透
        case 1: cout << "Incredible!\n";
            break;
        default: cout << "Too large!\n";
            break;
    }
    cout << "\n\n";
    return 0;
}
```

### 运行示例

**输入 1**
```
Enter a number between 1 and 5: 3
```
**输出 1**
```
Excellent!
Masterful!
Incredible!
```

**输入 2**
```
Enter a number between 1 and 5: 8
```
**输出 2**
```
Too large!
```

用户被要求输入一个数字。该数字交给 `switch` 语句。如果数字是 0，第 13 行的 `case` 语句匹配，打印 "Too small, sorry!"，`break` 语句结束 `switch`。如果值是 5，执行跳转到第 15 行打印一条消息，然后穿透到第 16 行打印另一条消息，以此类推直到遇到第 20 行。

这些语句的最终效果是对于 1 到 5 之间的数字，会打印相应数量的消息。如果数字的值不在 0 到 5 之间，假设它太大，并调用第 21 行的 `default` 语句。

## switch 语句语法详解

### 基本语法

```cpp
switch (expression)
{
    case valueOne: statement;
    case valueTwo: statement;
    ...
    case valueN: statement;
    default: statement;
}
```

### 示例 1：基本用法

```cpp
switch (choice)
{
    case 0:
        cout << "Zero!" << endl;
        break;
    case 1:
        cout << "One!" << endl;
        break;
    case 2:
        cout << "Two!" << endl;
    default:
        cout << "Default!" << endl;
}
```

### 示例 2：多 case 共享逻辑

```cpp
switch (choice)
{
    case 0:
    case 1:
    case 2:
        cout << "Less than 3!";
        break;
    case 3:
        cout << "Equals 3!";
        break;
    default:
        cout << "greater 3!";
}
```

## 在菜单中使用 switch 语句

列表 7.17 回到了之前讨论的 `for(;;)` 循环。这些循环也被称为无限循环，如果没有遇到 `break`，它们将一直循环下去。无限循环用于显示菜单、向用户请求选择、根据选择执行操作并返回菜单。此过程将一直持续，直到用户选择退出。

>

> ```cpp

>     // 语句...
> }
> ```

## 更多程序流控制

无限循环是一种没有退出条件的循环。若要退出循环，必须使用 `break` 语句。无限循环也称为持久循环。

## 列表 7.17：无限循环演示

```cpp
// Listing 7.17
// 使用无限循环管理用户交互

#include <iostream>

// 原型声明
int menu();
void DoTaskOne();
void DoTaskMany(int);

int main()
{
    bool exit = false;
    for (;;)
    {
        int choice = menu();
        switch(choice)
        {
            case 1:
                DoTaskOne();
                break;
            case 2:
                DoTaskMany(2);
                break;
            case 3:
                DoTaskMany(3);
                break;
            case 4:
                continue; // 多余的！
                break;
            case 5:
                exit = true;
                break;
            default:
                cout << " Please select again!\n";
                break;
        } // switch 结束

        if (exit)
            break;
    } // 无限循环结束
    return 0;
}
```

无限循环从第 15 行开始。调用 `menu()` 函数，该函数在屏幕上打印消息并返回用户的选择。从第 18 行开始到第 38 行结束的 `switch` 语句根据 `choice` 进行切换。如果用户输入 1，执行将跳转到 `DoTaskOne()`，该函数打印一条消息并返回。返回后，执行在第 22 行继续，此处 `break` 结束 `switch` 语句，执行跳转到第 39 行。在第 40 行，评估变量 `exit`。如果评估结果为 `true`，则将执行第 41 行的 `break`。

    GetPerim, ChangeDimensions, Quit };

// Rectangle class declaration
class Rectangle
{
public:
    // constructors
    Rectangle(int width, int height);
    ~Rectangle();

    // accessors
    int getHeight() const { return itsHeight; }
    int getWidth() const { return itsWidth; }
    int getArea() const { return itsWidth * itsHeight; }
    int GetPerim() const { return 2*itsHeight + 2*itsWidth; }
    void SetSize(int newWidth, int newHeight);

private:
    int itsWidth;
    int itsHeight;
};
