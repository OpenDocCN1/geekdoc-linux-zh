
# 描摹墙壁

要描摹位图，你将使用上一章中介绍的`Line`（线条）工具。你不会描摹所有的墙。

从草图外部的`U`型墙开始描摹：

1. 继续之前的练习或打开`Background`（背景）。如果你使用`MyWalls04`文件，可能需要在`Viewport`对话框中重新定位背景图像。
2. 在视口中，使用`Zoom`（缩放）工具放大`U`型墙区域，使你的视图看起来类似于图 4.20。不要选择太小的区域。

**图 4.20**

**描摹墙**

![](img/7e143440dd5a0ed9683d4f26f3c074f8_210_0.png)

可能会收到关于内存使用的警告消息。在这种情况下，`VIZ`警告将使用`16MB`内存。如果你选择了较小的区域，此警告可能会增加到`85MB`内存或更多。在警告对话框中点击`Yes`（是）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_210_1.png)

3. 点击命令面板的`Create`（创建）选项卡，然后点击`Shapes`（形状）。
4. 点击命令面板中`Object Type`（对象类型）下的`Line`按钮。
5. 以逆时针方式描摹图 4.20 所示的点。
6. 对于最后一点，点击`spline`（样条）。在`Spline`对话框中点击`Yes`关闭`spline`。

# 恢复背景图像

如果你在步骤 1 中不小心在警告对话框中选择了`No`（否），图像可能会消失。如果发生这种情况，可以选择`Views ➤ Viewport Background`（视口背景），并确保`Viewport Background`对话框中勾选了`Display Background`（显示背景）。

线条需要弯曲，因此使用`Bezier`（贝塞尔）选项来形成墙的曲线：

1. 点击命令面板的`Modify`（修改）选项卡，并在视口中右键点击弹出菜单。
2. 在`tools-quad`中点击`Vertex`（顶点）选项以访问`spline`的子对象级。你也可以点击`modifier stack`（修改器堆）中`Line`旁边的号，然后在展开列表或`Modify Tab`的`Selection`（选择）布局中点击`Vertex`按钮。
