### 微分几何
一门研究曲面空间内在性质的数学分支。该学科研究几何曲线和曲面，在直角坐标系 $(x,y)$ 中具有广泛优势。空间可以通过一对依赖方程 $f(x,y) = 0$ 和 $g(x,y) = 0$ 定义，或者有意义地通过参数方程 $\mathbf{x} = (x(t), y(t))$ 定义，其中 $t$ 是该类中的参数。两点 $t$ 和 $s$ 之间的线由给出：

```
$s = \int \sqrt{(\frac{dx}{dt})^2+(\frac{dy}{dt})^2+(\frac{dz}{dt})^2} dt$ (1)
```

显然，如果选择 $s$ 为参数，见方程 (2)。在这里：

```
$s = \int \sqrt{(\frac{dx}{dt})^2+(\frac{dy}{dt})^2} dt$ (2)
```

考虑三个相邻的点 $P_1, P_2, P_3$。通过它们可以构造一个。P_1$ 和 $P_2$ 的极限位置是曲面 $S$ 的切平面。当 $P_1, P_2$ 和 $P_3$ 接近 $P$ 时，曲率及其半径是曲率半径 $\kappa$；其值如 (3) 所示。曲线上 $P$ 处的垂直面是法平面，$P$ 处的垂直面是切法面。双曲

```
$$\kappa = \frac{\left(\frac{dx}{dt})^2+(\frac{dy}{dt})^2+(\frac{dz}{dt})^2\right)\left(\frac{d^2x}{dt^2})^2+(\frac{d^2y}{dt^2})^2+(\frac{d^2z}{dt^2})^2-\left(\frac{dx}{dt}\right)\frac{d^2y}{dt^2}-\left(\frac{dy}{dt}\right)\frac{d^2x}{dt^2}\right)}{\left(\frac{dx}{dt})^2+(\frac{dy}{dt})^2\right)^{3/2}} \quad (3)
```

在三维欧几里得空间中，可以通过 $f(x,y,z) = 0$ 定义，或者局部通过方程 (4)。对于：

```
$x=x(u) \ y=y(u) \ z=z(u)$
```

描述曲面上的曲线，固定 $u$ 值的线。这些是点的 $(u,v)$ 曲线坐标。曲面上最重要的问题是曲线的弧长。由 (5) 给出，$E, F, G$ 是 $(x,y)$ 的导数。

```
$ds^2 = E^2 du^2 + 2F dudv + G^2 dv^2 \quad (5)$
```

在实际情况下，$E, F, G$ 是非负的，仅在曲面的奇异点或 $(x,y)$ 导数矩阵秩小于2的地方可能为零。方程 (5) 的右侧称为曲面的第一形式，其中包含 $F$。所有曲面都有第一基本形式。因此，任何可展开的（适用于平面的）圆柱或锥体都有基本坐标。在坐标 $(u,v)$ 的任意变换下，基本量 $E, F, G$ 线性变换，使得许多存在存在坐标系的曲面上点，其 $E, F, G$ 满足要求。坐标系；黎曼几何。[M.S.K]
