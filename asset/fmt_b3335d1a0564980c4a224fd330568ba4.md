系统会提示你输入你的域名，是否使用单用户模式（用于测试目的很有用），是否正在使用 `Docker`（这次不是），`PostgreSQL` 详细信息（除非你更改了某些设置，否则默认值是正确的 – 数据库用户故意没有密码）。`Mastodon` 可以发送邮件（用于账户验证和恢复目的），可以使用本地服务器或通过 `Mailgun` 等外部服务。也可以运行一个不发送邮件的实例。你会被提示设置一个管理员用户，你应该这样做，因为你需要管理你的实例。会为你生成一个密码：请记下来并在登录时更改。

### 设置服务

我们的工作即将完成，我们只需要设置三个 `Systemd` 服务：`mastodon-web`、`mastodon-sidekiq` 和 `mastodon-streaming`，它们应放置在 `/etc/systemd/system/` 中。同样，你可以从之前链接的设置指南中找到并复制粘贴它们的内容。我们可以使用 `sudo systemctl enable --now /etc/systemd/system/mastodon-*.service` 一次性启动并启用这三个服务。

### SOLID 与去中心化 Web

蒂姆·伯纳斯-李教授（Professor Tim Berners-Lee）发明了万维网，所以当他宣布他的发明“已经演变成不公和分裂的引擎”时（参见 `https://medium.com/@timberners_lee/one-small-step-for-the-web-87f92217d085`），人们往往会倾听。该教授及其在 `MIT` 的团队提出了一个重新发明它的计划。建立在现有 Web 之上的 `Solid` 平台旨在赋予用户选择数据存储位置、谁可以查看数据以及如何使用数据的能力。`Solid` 是“Social Linked Data”（社会关联数据）的合成词，而关联数据的理念并不新鲜 - 伯纳斯-李在 2006 年引入了它，同时也引入了语义 Web 的理念。它使发布的数据能够根据上下文进行链接，并源自外部来源，使其不再受制于特定的提供商或应用程序。如果出现新的、更好的应用程序，它可以访问并重新使用与其较差的前任相同的数据。

这是一项雄心勃勃的努力，但 `Solid` 并不是唯一旨在实现对 Web 的去中心化重构的项目。`ZeroNet`、`SAFE`（Secure Access For Everyone）网络和 `PiperNet` 都希望通过各自的方式实现这一目标。

最后再提一点，以防你的关注变得流行起来。`Mastodon` 会缓存来自其他实例（你的用户的关注所在）的数据，并且这个缓存可能会迅速增长。通过将以下内容添加到 `Mastodon` 用户的 `crontab` 中，可以避免任何问题：

```
RAILS_ENV=production
daily cd /home/mastodon/live && /home/mastodon/rbenv/shims/bundle exec rake mastodon:media:remove_remote
```

自 2005 年雅虎收购 `Flickr` 以及 2006 年 `YouTube` 并入谷歌帝国以来，聪明的人们一直对其图片和视频的使用方式表示担忧。在我们独家 [LF222](https://lfx.lf222.com) 采访中，科里·多克托罗谈到了他对 `Flickr` 被“雅虎化”后强加给用户的苛刻新条款的恐惧。用户被迫将他们的 `Flickr` 账户与雅虎账户关联，否则将无法访问他们的图像。此外，内容受美国联邦法律管辖而非加拿大法律管辖也是一个主要担忧。再加上雅虎在 2013 年泄露了大约三十亿个账户（基本上是所有拥有 `@yahoo.*` 电子邮件地址的人）的个人数据。雅虎被 `Verizyn` 收购，随后卖掉了 `Flickr`：更不用说他们的大多数其他资产了。但担忧依然持续。

### 还有另一件事……

现在让我们转向谷歌，特别是其 2012 年统一隐私政策的修改。最初，它简化了其服务的使用（当时约有 60 种服务，大多数人至少使用过其中一种），同时也为它们提供了大量的数据洞察力。在此之前，与每项服务相关的数据都是孤立的，因此虽然它仍然通过扫描电子邮件（不再这样做）、跟踪搜索以及在 `YouTube` 上传内容上运行各种模糊算法来收集大量数据，但没有尝试跨这些服务进行关联。事后，用户有了选择：要么让谷歌将所有这些数据与单一身份关联，要么完全停止使用谷歌的服务。如今，随着约二十亿人使用安卓手机，所有这些都关联到谷歌账户并愉快地传输位置数据，问题变得显而易见（这就是为什么我使用 [LineageOS – 编辑注]。虽然打击大型跨国企业很容易，但真正有错的是整个集中化模型。一家抱有良好初衷的开创性公司（这正是当时的 `Flickr`）可能在任何时刻发现自己被某个可怕的怪物吞噬。数据随后实际上成为人质，直到用户屈从于该怪物提出的任何糟糕政策为止。在去中心化模型中，如果一个实例变得失控，或被一个失控者接管，那么该失控实例可以被列入黑名单。如果一个整个项目转向黑暗面，那么分叉软件并重建网络将是轻而易举的。ES
