## `break`

```
break [n]
```

### 第 28 个 BASH 命令

`break` 强制从 `for`、`while` 或 `until` 循环内部退出。如果存在 `n` 参数，则指定要跳出的嵌套层数。如果 `n` 大于外层循环的数量，则退出所有外层循环。`break` 返回值为 0，除非在执行 `break` 时 shell 并没有在执行一个循环体。

## `builtin`（内置命令）

`builtin shell-builtin [arguments]`

`builtin` 命令执行指定的 shell 内置命令，传递其参数并返回其退出状态。当你希望定义一个名称与 shell 内置命令同名的函数，但又在函数内部需要该内置命令的功能时，这种方法非常有用。`cd` 内置命令通常通过这种方式重新定义。如果 `shell-builtin` 不是 shell 内置命令，则返回状态为假。

## `case`

```bash
case variable in
  pattern)
    commands
    ;
  pattern)
    commands
    ;
  *) default commands
  esac
```

`case` 结构在多个可能的替代方案中进行选择。通过将值与多个可能的模式进行比较来做出选择。每个模式都与一组操作相关。如果找到匹配项，则执行相关的操作。`case` 结构以关键字 `case`、变量的求值以及关键字 `in` 开头。紧接着是一组模式。每个正则表达式都以右括号结束。在右括号之后，列出与该模式相关的命令，随后在另起一行处跟一个双分号（`；`），表示这些命令的结束。在所有列出的模式之后，用关键字 `esac` 结束 `case` 命令。

### 第 29 个 BASH 命令

模式可以包含任何 shell 特殊字符。shell 特殊字符有 `*`、`[`、`]`、`?` 和 `|`。你可以使用单个 `*` 特殊字符来指定默认模式。`*` 特殊字符匹配任何模式；因此如果所有模式都不匹配，`*` 将会匹配。这样，如果没有选择其他选项，就会执行默认选项。默认选项是可选的；你不需要必须包含它。

`case` 结构通常用于实现菜单。在接下来的示例程序 `lschoice` 中，用户被要求输入一个以不同方式列出文件的选择。注意警告输入无效的默认选项。

## `lschoice`

# 列出文件

## `cd`

`cd [dir]`

将当前目录更改为 `dir`。变量 `HOME` 的值是默认目录。变量 `CDPATH` 定义了包含 `dir` 的目录的搜索路径。备用目录之间用冒号（`:`）分隔。空目录名为（`.`）。`CDPATH` 等同于当前目录（即 `..`）。如果 `dir` 以斜杠（`/`）开头，则不使用 `CDPATH`。参数 `-` 等同于 `$OLDPWD`。如果目录成功更改，则返回真；否则为假。

## `continue`

```bash
continue [n]
```

跳过当前循环体的剩余部分并重新开始下一次迭代。适用于 `for`、`while` 和 `until` 循环。带有 `n` 参数，`continue` 将从第 `n` 个外层循环开始。如果 `n` 大于外层循环的数量，则恢复最后一个外层循环（“顶层”循环）。`continue` 返回 0，除非在执行 `continue` 时 shell 并没有在执行一个循环体。

`declare` 声明一个变量，指定变量名和用等号（`=`）分隔的其初始值。如果没有参数，则显示变量的值。可以使用以下选项设置变量属性：

## `elif`

```bash
if Linux command
  then
    commands
elif Linux command
  then
    commands
else
  commands
fi
```

`elif` 结构允许你嵌套 `if-then-else` 操作。通过 `elif`，你可以在多个替代方案之间进行选择。第一个替代方案由 `if` 结构指定，随后是其他替代方案，每个替代方案由其自己的 `elif` 指定。最后一个 `elif` 结构的替代方案由 `else` 指定。如果第一个 `if` 结构的测试（一个 Linux 命令）失败，控制将传递到下一个 `elif` 结构，并执行其测试。如果失败，控制传递到下一个 `elif` 并检查其测试。此过程持续直到测试为真。此时，该 `elif` 执行其命令，并跳出 `if` 结构，进入 `fi` 关键字之后的命令。
