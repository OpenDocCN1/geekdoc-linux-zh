## talk (对话)

如果另一个用户已登录，你可以使用 `talk` 命令与该用户实时交谈。使用 `talk` 命令，你可以与本地主机或远程主机上的用户交谈。

`talk` 命令接受一个强制性参数——用户名或用户主机名。你可以可选地提供第二个参数，指定用户登录的 TTY。

远程主机上的用户可以使用以下格式之一：

- `-username@host`
- `host!username`
- `host.username`
- `host:username`

当你执行 `talk` 命令时，它会打开两个窗口——一个用于发送消息，另一个用于接收消息，并且它将等待对方的响应。

示例：如果你执行以下命令与用户 `friend` 交谈：

```
talk friend
```

你将得到以下屏幕：

[等待你的对方响应]

其中一半部分用于发送消息，另一半用于接收消息。如果指定的用户未登录，你将收到消息“你的对方未登录（Your party is not logged on）”。

而用户 `friend` 将收到以下消息：

```
Message from Talk_Daemon@host at 0:46...

talk: connection requested by testuser@host1.

talk: respond with: talk testuser@host1

Waiting for your party to respond]
```

用户 `friend` 必须使用以下命令进行响应：

```
talk testuser@host1
```

以开始对话。

退出会话请使用 `Ctrl-c`。

## vacation (休假)

如果你想通知邮件发送者你正处于休假，可以使用 `vacation` 命令。如果你在 `.vacation.msg` 文件中创建了消息，发送的消息可以是自定义的。如果文件不存在，则发送系统默认消息。默认情况下，系统每周会向向你发送邮件的用户发送一次系统消息。

`vacation` 命令可以结合你家目录下的 `.forward` 文件将你在休假期间收到的邮件转发给其他用户。包含所有你希望转发消息的处的用户名称。`.forward` 文件中的条目格式如下：

```
testuser, "/usr/bin/vacation testuser"
```

`vacation` 命令还允许你存储休假期间向你发送消息的用户名。这些用户名存储在家目录下的 `.vacation.dir` 和 `.vacation.pag` 文件中。

`vacation` 命令有一个选项标志，用法如下：

- `-I` 在你休假开始前初始化 `.vacation.dir` 和 `.vacation.pag` 文件。

系统通过识别家目录中 `.forward` 文件的存在来判断你正在休假。因此，一旦你回来，你应该删除或重命名 `.forward` 文件。

在去休假之前，使用以下命令初始化你目录中的 `.vacation.dir` 和 `.vacation.pag` 文件：

```
vacation -I
```

随后应是创建 `.forward` 和 `.vacation.msg` 文件。

### line 9 diff

你可以使用 `diff` 命令比较文本文件，但无法比较不存在的文件。你可以使用 `diff` 比较单独的文件，或位于不同目录下具有相同名的多个文件。对于比较单独的文件，使用 `-`（连字符）表示其中一个文件是从标准输入接受的。

`diff` 命令的输出行组之前有一行包含以下信息的标识行：

- 第一个文件中不同的行。这可能表示一个单独行号，或两个用逗号分隔的行号（表示该范围内的所有行）。
- 操作代码，其有效值为 `a`（表示添加的行）、`c`（表示修改的行）和 `d`（表示删除的行）。
- 第二文件中不同的行。这可能表示一个的行号，或两个用逗号分隔的行号（表示该范围内的所有行）。

`diff` 命令会生成 `ed` 命令。这些 `ed` 命令可以应用于第一个文件，这样做将使第二个文件与第一个文件完全相同。

`diff` 命令生成三种形式的输出，如下：

- `Number1Number2,3`，表示第二个文件中 `Number2` 到 `Number3` 的行必须在第一个文件的第 `Number1` 行之后添加，以使它们相同。这种形式后面是带有 `>`（大于号）前缀的第二个文件的行。
- `Number1Number2,`，表示必须从第一个文件中删除 `Number1` 到 `Number2` 的行，以使它们相同。这种形式后面是带有 `<`（小于号）前缀的第一个文件的行。
- `Number1Number2cN3,Number4,`，表示第一个文件的 `Number1` 到 `Number2` 行必须通过 `Number3` 到 `Number4` 行进行修改，以使它们相同。这种形式后面是带有 `<`（小于号）前缀的第一个文件的行，然后是带有 `>`（大于号）前缀的第二个文件的行。

以下是可以在 `diff` 命令中使用的标志列表：

- `-b` 确保多个空格或制表符字符被视为一个。然而，开头的空格或制表符字符将原样处理。
- `-c LINE` 产生与默认格式不同的输出。输出首先识别被比较的文件及其创建日期时间。每组修改的行之间由一行带有 `*`（星号）的行分隔，随后是第一个文件和第二个文件的行。从第一个文件中删除的行用 `-`（连字符）标记。添加到第一个文件的行用 `+`（加号）标记。位于两个文件指定上下文行内但用 `!`（感叹号）标记的更改将分组输出。
- `-c LINE` 产生与默认格式不同的输出。`LINE` 参数是可选的。输出首先识别正在比较的文件及其创建日期时间。每组修改的行之间由一行带有 `*`（星号）的行分隔，随后是第一个文件和第二个文件的行。从第一个文件中删除的行用 `-`（连字符）标记。添加到第二个文件的行用 `+`（加号）标记。两个文件中都存在的行用 `!`（感叹号）标记。位于彼此指定上下文中的更改将分组输出。
- `-D` 在标准输出上创建第一个文件和第二个文件的合并版本。包含了 C 预处理器控制选项，使得在不定义 `String` 的情况下编译结果等同于编译第一个文件，而定义 `String` 则会编译第二个文件。
- `-e` 生成可以输入到 `ed` 中的输出，以便从第一个文件生成第二个文件。
- `-f` 创建与 `-e` 标志产生相反的输出。
- `-i` 在忽略字母大小写的情况下比较两个文件。
- `-l1` 生成格式化输出。它在末尾还会生成摘要。
- `-n` 按 `-e` 标志的反向顺序生成输出。此外，它还会生成添加和删除的行数。
- `-r` 在指定目录的所有同名子目录下执行 `diff` 命令。
- `-s` 生成输出以获取相同文件的列表以及同名文件之间的差异。这将生成仅存在于一个目录的文件列表。
- `-S FILE` 忽略文件。在比较目录时可以使用此选项忽略排序小于指定 `FILE` 的。
- `-w` 保留行的原始缩进。输出中的行缩进可以通过使用 `>`（大于号）或 `<`（输出中的小于号）进行修改。
- `-w` 忽略所有空格和制表符字符。在比较时将它们视为相同。

示例 假设有两个名为 `file1` 和 `file2` 的文件。文件内容使用 `more` 命令显示如下：

```
file1

This is the first line

This is the second line

This is the fourth line

This is the fifth line

This is the sixth line

This is the seventh line

This is the eighth line

This is the NINTH line

file2

This is the first line

This is the second line

This is the third line

This is the fourth line

This is the fifth line

This is the sixth line

This is the seventh line
```

这是第三行

要更新 file1 并查看结果，你现在使用以下命令：

```
ed - file1 < diffout

more file1

这是第一行

这是第二行

这是第三行

这是第四行

这是第六行

这是第七行

这是第八行

这是第九行
```

如果你不想更新原始文件，请使用 `1, $` 代替 `w`。这会将输出生成到标准输出。你也可以按照如下所示将输出重定向到文件：

```
ed - file1 < diffout > file1.new
```

若要生成与 `-e` 指定的顺序相反的输出，请使用 `-f` 标志执行以下命令：

```
a2

这是第三行

d4

c6 8

这是第七行

这是第八行

这是第九行
```

如果你不在乎文件中是否包含大写或小写字母，可以使用 `-i` 标志在以下命令中执行不区分大小写的 diff：

```
diff -i file1 file2

a23

> 这是第三行

d4d

< 这是第五行

6,7c6,7

< 这是第七行

< 这是第八行

---

> 这是第七行

> 这是第八行
```

注意，由于使用了 `-i` 标志，`file1` 中的第九行和 `file2` 中的“这是第九行”被评估为相等。

如果你想知道每次插入或删除影响的行数，请在以下命令中使用 `-n` 标志：

```
diff -n file1 file2

a2 1

这是第三行

d4 1

d6 3

a8 3

这是第七行

这是第八行

这是第九行
```

上述行信息是关于 `file1` 的。它告诉你在 2 行之后要插入一行，随后是待插入的行；在第 4 行删除一行；在第 6 行删除三行；在第 8 行之后要插入三行，随后是待插入的内容。

若要忽略所有的制表符和空格字符，请使用 `-w` 标志。`-b` 和 `-w` 标志的区别在于 `-b` 忽略领先空格以外的所有空格和制表符，而 `-w` 忽略所有字符。以下是 `-w` 标志的示例：

```
diff -w file1 file2

a2a3

> 这是第三行

d4d

< 这是第五行

8c

< 这是第第九行

----

> 这是第九行
```

`testdir1` 和 `testdir2`

此外，让我们看看这些目录下存在什么内容：

```
ls -R test*

testdir1/testdir3:

filea fileb filec filed file

testdir2:

file2 file4 file5 file7 testdir3

testdir2/testdir3:

fileb filed file lief fileg
```

不带任何标志比较两个目录的 diff 命令的最简单形式将产生如下输出：

```
diff testdir1 testdir2

仅在 testdir1 中:file1

仅在 testdir1 中:file3
```

```
仅在 testdir1 中: file6

仅在 testdir2 中:file7

仅在 testdir2 中: file8

公共子目录: testdir1/testdir3 和 testdir2/testdir3
```

在示例中，diff 命令没有遍历 testdir1 和 testdir2 下的子目录 testdir3。如果你让 diff 命令遍历目录下的子目录，请在命令中使用 `-r` 标志：

```
diff -r testdir1 testdir2

仅在 testdir1 中: file1

仅在 testdir1 中: file3

仅在 testdir1 中: file6

仅在 testdir2 中: file7

仅在 testdir2 中: file8

仅在 testdir1/testdir3 中: filea

仅在 testdir1/testdir3 中: filec

仅在 testdir2/testdir3 中: filef

仅在 testdir2/testdir3 中: fileg
```

如果你想知道目录中所有相同文件的列表，请在命令中使用 `-s` 命令：

```
diff -rs testdir1 testdir2

仅在 testdir1 中: file1

文件 testdir1/file2 和 testdir2/file2 是相同的

仅在 testdir1 中: file3

文件 testdir1/file4 和 testdir2/file4 是相同的
```
