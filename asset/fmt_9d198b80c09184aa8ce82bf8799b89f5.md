# alevt
X11 电视节目 `alevt` 是一个用于搜索和搜索文本页面的 X11 程序。电视节目页面通过兼容的解码器 `btv` 查看。功能包括：多窗口、页面缓存、正则表达式搜索、内置帮助。命令行单元可以从电视节目接收它们、捕捉页面并写入磁盘。电视节目用于电视频道传输文本页面（通过不可见的空白传输）。它是使用 Bi848 系列视频解码器芯片的采集器驱动程序。包含在 2.2 版本的 Linux 内核中，或单独从 `http://byteshex.org/bt/` 获取。首页：`http://www.goron.de/~froese/` 来自 Debian 3.0r0 APT

# ALT Linux
2002年5月3日创建的 LWN 发行版。旨在作为一个通用发行版，适用于服务器组织、用户工作站和软件开发。ALT Linux 已偏离其根源并分裂为几个项目，所有项目共享相同的代码库。例如，Castle 是一个基于 RSBAC 的服务器发行版；ALT Linux Junior 是一个用于家庭电脑的单磁盘发行版，设计易于安装和稳定。不稳定的 Sisyphus 分支会不断变化。ALT Linux Master 2.2 于 2003年3月7日 发布。ALT Linux 2.2 (Plum) 于 2003年3月26日 发布。来自 LWN 分发列表 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
