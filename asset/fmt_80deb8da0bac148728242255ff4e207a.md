## 使用客户端自定义桌面

你可以使用 X11R5 发行版带的一些客户端软件来自你的桌面。本章涵盖了以下应用：

- `xsetroot`
- `xset`
- `xdpyinfo`
- `xmodmap`

在 `/usr/bin/X11` 目录下还有更多工具供你尝试：`bitmap`、`xmag`、`xcalc`。检查每一个来自定义你的桌面。本章描述了那些并非直观易见的工具。

### xsetroot

该客户端自定义根窗口的特性。可用选项包括：

- `-cursor cursorfile maskfile`。将光标更改为显示的掩码值。参见侧栏使用 `bitmap` 创建自己的光标。
- `-cursor_name name`。这是 X11 协议中标准光标的名称。
- `-bitmap filename`。在根窗口上创建一个位位的平铺表面。检查 `/usr/lib/X11/bitmaps` 目录获取标准位图列表。
- `-fg color foreground`。根显示器位图的前颜色。
- `-bg color background`。根显示器位图的背景色。
- `-gray` 或 `-grey`。将背景设置为对某些人来说舒适的灰色。
- `-rv`。反转前景和背景颜色。
- `-solid color`。将根窗口设置为纯色。

查看 `/usr/lib/X11` 目录下的 `rgb.txt` 文件获取列表，并查看本章中的“Colors”部分获取更多信息。

查看 `xsetroot` 的帮助页获取更多功能。

### 创建 Cursorfile

光标文件是一个带有字符数组的 ASCII 文件。你使用 `bitmap` 工具创建一个位图。然后通过 `bmtoa` 运行该位图以将位图转换为数组。有一个名为 `atobm` 的反向工具，可以将预存数组转换为位图，以便用于位图编辑器。

### 使用 xset

`xset` 命令设置你环境中的某些基本选项。这些选项中的某些可能在你特定的系统上不起作用。值得检查一下。

你可以设置蜂声音量：

```
xset b volume frequency durationInMilliseconds.
```

例如，命令行

```
xset b 70 4000 60
```

将键盘蜂声设置为最大值的约 70%，频率为 4000 Hz，持续 60 毫秒。

要打开扬声器，使用 `xset s`。要关闭它，使用 `xset nois`。要设置蜂声，使用 `xset b`。

这会在另一个节点上启动一个远程会话。`displayname` 和 `ScreenName` 是可选的，如果不输入，则默认为零。

当你想在远程机器 `alma` 上打开一个 `xterm` 时，运行以下命令：

```
xterm -display alma:0.0 &
```

输入显示参数的选项格式如下：

```
\[host\]:\[server\]\[:screen\]
```

如果你被允许打开显示，你将登录到远程机器。你可以使用 `uname` 命令来验证这一点。使用 `echo $DISPLAY` 命令检查 `DISPLAY`。

当你使用 `exit` 命令退出时，远程会话和 `xterm` 将被终止。

**提示：** 无法打开远程终端的最常见原因之一是远程主机允许你在那里打开窗口。请请求远程用户在登录时在远程机器上使用 `xhost` 命令。

由于红、绿、蓝各有 256 个值，可能颜色的数量为 16,777,216 个。没有多少工作站能同时显示这么多颜色。因此，X 使用了一种将这些颜色映射到显示器上的机制，称为调色板（`colormap`）。颜色显示器使用若干位来显示此映射中的条目。`xdpyinfo` 程序可以提供显示器的位数。这是一个帧缓冲区。1 位帧表示黑白显示。8 位帧缓冲区表示 2⁸ 个条目，即 256 种可能的颜色。

遗憾的是，由于不同屏幕上使用的荧光粉不同，你在一个显示器上的颜色规格在另一个显示器上可能完全不同。Tektronix 提供了一个名为 `xtici` 的工具和文档，通过使用国际颜色标准来解决此类问题。这被称为颜色管理系统（CMS），使用一种 HVC（色调-值-色度）模型。X11R5 或更高版本查看 `Xcms` 更多详情，或者联系 Tektronix。

## 字体

X Windows 系统中的字体是为了提供最大的灵活性而设计的。有两个很好的工具可以帮助你筛选基本系统中的字体类型：

- `xlsfonts`：列出系统中的字体。
- `xfontsel`：允许你交互式查看系统中有哪些字体并查看它们在屏幕上的样子。
