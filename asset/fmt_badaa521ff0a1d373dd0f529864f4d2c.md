
## 日志配置选项

根据 HTTP RFC，日志文件中存储的信息具有非常特定的格式。你可能不需要更改这些。图 8-9 是来自 `/home/httpd/manual/mod/mod_log_config` 的节选。

### 图 8-9
日志格式选项

| Token | 描述 |
| :--- | :--- |
| `%h` | 远程主机 |
| `%l` | 远程用户名 (ident) |
| `%u` | 远程用户 |
| | 请求时间 |
| `%r` | 请求行 |
| `%s` | HTTP 状态码 |
| `%b` | 响应大小（字节） |
| `%{Referer}i` | Referer 请求头 |
| `%{User-Agent}i` | User-agent 请求头 |
| `%t` | 响应的第一行 |
| `%D` | 服务请求所需的时间（微秒） |
| `%T` | 服务请求所需的时间（秒） |
| `%C` | Cookie 字符串 |
| `%q` | 查询字符串 |
| `%O` | 开始主体前发送的字节 |
| `%m` | HTTP 方法 |
| `%U` | URL 路径 |
| `%V` | 协议版本 |
| `%H` | HTTP 版本 |
| `%B` | 发送的字节 |
| `%S` | 状态码 |
| `%t` | 请求时间 |
| `%L` | 响应时间 |
| `%r` | Referer |
| `%a` | 用户代理 |
| `%C` | Cookie 字符串 |
| `%q` | 查询字符串 |
| `%u` | 远程用户 |
| ...（大量重复的 Token 已省略）...

## 启动 Apache 服务器

实际的二进制文件是 `/usr/sbin/httpd`。你也可以使用 `httpd` 控制服务的停止和启动。在不带参数的情况下，会打印出用法语句，如图 8-10 所示。该输出表示服务器正在运行。
