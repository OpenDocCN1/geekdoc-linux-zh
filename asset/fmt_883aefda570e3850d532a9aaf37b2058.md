### 双引号

双引号告诉 Shell 将引号内（`"..."`）文本视为普通字符。除了 `$`（美元符号）、`\`（反斜杠）和 `` ` ``（反引号）之外，所有的特殊字符都将失去它们的含义。这意味着变量、命令替换和算术函数仍然可以使用。

例如，变量 `$USER` 的替换不会受到双引号的影响：

```bash
$ echo I am $USER
I am tom

$ echo "I am $USER"
I am tom
```

另一方面，空格字符（space character）失去了其作为参数分隔符的含义：

```bash
$ touch new file
$ ls -l
-rw-r--r-- 1 tom students 0 Oct 8 15:18 file
-rw-r--r-- 1 tom students 0 Oct 8 15:18 new
```

```bash
$ touch "new file"
$ ls -l
-rw-rw--r-- 1 tom students 0 Oct 8 15:19 new file
```

如你所见，在第一个示例中，`touch` 命令了两个独立的文件，命令将这两个字符串视为独立的参数。在第二个示例中，命令将两个字符串解释为一个参数，因此它只创建了一个文件。然而，最佳实践是避免在文件名中使用空格字符。相反，可以使用下划线（`_`）或点（`.`）。

### 单引号

单引号没有双引号的那些例外。它们会取消每个字符的任何特殊含义。让我们看看上面的第一个例子之一：

```bash
echo I am $USER
I tom
```

当应用单引号时，你会看到一个不同的结果：

```bash
echo 'I am $USER'
I am USER
```

命令现在显示精确的字符串，而不替换变量。

### 转义字符

我们可以使用转义字符来移除 Bash 中字符的特殊含义。回到 `$USER` 环境变量：

```bash
echo $USER
carol
```

我们看到默认情况下，变量的内容会在终端中显示。但是，如果我们在美元符号前面加上一个反斜杠字符（`\`），那么美元符号的特殊含义就会被否定。相反，这会让 Bash 不扩展变量的值为运行命令的用户名，而是以字面量来解释变量名：

如果你还记得，我们可以使用单引号获得类似的结果，它会打印单引号内任何内容的字面内容。然而，转义字符的工作方式不同，它指示 Bash 忽略其其前的字符可能拥有的任何特殊含义。

```bash
$ echo $greeting
hello
```

可见，变量已经创建。现在打开另一个 shell 并尝试显示所创建的变量的内容。

```bash
$ echo $greeting
```

什么都没有显示。这说明它实际上是一个局部变量，尝试启动一个新进程并检查该进程是否可以访问该变量。我们可以通过启动另一个 shell 并让该 shell 运行 `echo` 命令来实现。由于新 shell 在新进程中运行，它不会继承父进程的局部变量：

```bash
$ echo $greeting world
hello world

$ bash -c 'echo $greeting'
world
```

> 注意：请确保在上面的示例中使用单引号。

要删除变量，你需要使用 `unset` 命令：

```bash
$ echo $greeting
hey

$ unset greeting

$ echo $greeting
```

> 注意：`unset` 需要将变量名作为参数。因此，你不能在名称中添加 `$`，因为这会解析变量并将变量的值传递给 `unset`，而不是变量名。

## 使用全局变量

要让变量对子进程可用，请将其从局部变量转换为环境变量。这是通过 `export` 命令完成的。当在使用变量名调用该命令时，该变量会被添加到 shell 的环境中：

## Linux 基础 (版本 1.6) | 主题 2：在 Linux 系统中导航

```bash
$ greeting=hello
$ export greeting
```

注意：再次确保在运行 `export` 时不要使用 `$`，因为你想传递的是变量名而不是它的内容。

创建环境变量的另一种简单方法是结合上述两种方法，通过在命令参数中赋值值。

```bash
$ export greeting=hey
```

让我们再次检查子进程是否可以访问该变量：

```bash
$ export greeting=hey
$ echo $greeting world
hey world

$ bash -c 'echo $greeting world'
hey world
```

使用环境变量另一种方法是在命令前使用它们。我们可以使用持有时区的环境变量 `TZ` 来进行测试。该变量被 `date` 命令使用，以确定要显示的时区时间：

```bash
$ TZ=EST date
```
