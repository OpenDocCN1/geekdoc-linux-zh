
# 第 14 章：函数

## 第 14.3 节：处理标志和可选参数

`getopts` 可以在函数内部用于编写处理标志和可选参数的函数。这并没有特别困难，但必须正确处理由 `getopts` 触及的相应值。在一个示例中，我们定义了一个 `failwith` 函数，它在标准错误（`stderr`）上输出消息，并根据 `-x` 选项提供的任意代码或代码 `1` 退出：

```bash
# failwith [-x STATUS] PRINTINT-LIKE-ARGV
# Fail with the given diagnostic message
# The -x flag can be used to convey a custom exit status, instead of
# the value 1. A newline is automatically added to the output.

failwith() {
  local OPTIND OPTARG status
  status=1
  OPTIND=1
  while getopts 'x:' OPTION; do
    case $OPTION in
      x) status="${OPTARG}";
      *) 1>&2 printf 'failwith:%s: Unsupported option.\n' "${OPTION}";
    esac
  done
  shift $((OPTIND - 1))
  {
    printf 'Failure: '
    printf "$@"
    printf '\n'
    1>&2
    exit "${status}"
  }
}
```

该函数可以如下所示使用：

`failwith %s: File not found. "${filename}"`  
`failwith -x 70 'General internal error.'`

以此类推。

注意对于 `printf`，不应将变量作为第一个参数。如果要打印的消息包含变量值的内容，应该使用 `%s` 标识符来打印它，例如：

`failwith '%s' "${message}"`

## 第 14.4 节：打印函数定义

```bash
getfunc() {
  declare -f "$@"
}

function func() {
  echo "I am a sample function"
}

funcd=$(getfunc func)

getfunc func # or echo "$funcd"
```

输出：

```bash
func() {
{
  echo "I am a sample function"
}
}
```

## 第 14.5 节：接受命名参数的函数

```bash
foo() {
  while [[ $# -gt 0 ]]; do
    case $1 in
      -f|--follow)
        local FOLLOW="following"
        ;;
      -t|--tail)
        local TAIL="tail=$2"
        ;;
    esac
    shift
  done
  echo "FOLLOW: $FOLLOW"
  echo "TAIL: $TAIL"
}
```

示例用法：

```bash
foo -f
foo -t 10
foo -f --tail 10
foo --follow --tail 10
```

## 第 14.6 节：函数的返回值

Bash 中的 `return` 语句并不像 C 语言函数那样返回一个值，而是以返回状态退出函数。你可以将其视为该函数的退出状态。

如果你想从函数返回一个值，可以像这样将值发送到标准输出（`stdout`）：

```bash
fun() {
  local var="Sample value to be returned"
  echo "$var"
  printf "%s\n" "$var"
}
```

现在，如果你执行：

```bash
var=$(fun)
```

`fun` 的输出将存储在 `$var` 中。

## 第 14.7 节：函数的退出码是其最后一个命令的退出码

考虑这个检查主机是否在线的函数：

```bash
is_alive() {
  ping -c "$1" & /dev/null
}
```

该函数向第一个函数参数指定的主机发送单个 `ping`。`ping` 的输出和错误输出被重定向到 `/dev/null`，因此函数永远不会输出任何内容。但 `ping` 命令成功时退出码为 `0`，失败时为非零。这是函数的最后一个（在本例中也是唯一的）命令，`ping` 的退出码将复用作为函数本身的退出码。

这一事实在条件语句中非常有用。

例如，如果主机 `graucho` 是在线的，则通过 `ssh:` 连接到它：

```bash
if is_alive graucho; then
  ssh graucho
fi
```

另一个示例：反复检查直到主机 `graucho` 在线，然后通过 `ssh:` 连接到它：

```bash
while ! is_alive graucho; do
  sleep 5
done

ssh graucho
```

# 第 15 章：Bash 参数扩展 (Parameter Expansion)

`$` 字符引入了参数扩展、命令替换或算术扩展。参数名称或扩展符号可以括在大括号中，大括号是可选的，但它可以保护变量不被紧随其后的字符意外扩展，因为那些字符可能会被解释为名称的一部分。

请在 [Bash 用户手册]() 中阅读更多内容。

## 第 15.1 节：修改字母的大小写

### 转为大写

```bash
$ v='hello'

# 仅转换第一个字符
$ printf '%s\n' "${v^^}"
Hello

# 所有字符
$ printf '%s\n' "${v^^}"
HELLO

# 另一种方法
$ v='hello world'
$ declare -u string="$v"
$ echo "$string"
HELLO WORLD
```

### 转为小写

```bash
$ v='BYE'

# 仅转换第一个字符
$ printf '%s\n' "${v,,}"
byE

# 所有字符
$ printf '%s\n' "${v,,}"
bye

# 另一种方法
$ v='HELLO WORLD'
$ declare -l string="$v"
$ echo "$string"
hello world
```

### 切换大小写 (Toggle Case)

```bash
$ v='Hello World'

# 所有字符
$ echo "${v~}"
HELLO WORLD

$ echo "${v^}"

# 仅转换第一个字符
hello World
```

## 第 15.2 节：参数长度

```bash
# 字符串长度
$ var='12345'
$ echo "${#var}"
```

注意，它是字符数量的长度，不一定等同于字节数（例如在 `UTF-8` 中，大多数字符被编码为多个字节），也不等同于字形/字素数（某些字符是字符的组合），更不等同于显示宽度。

```bash
# 字符数量
$ var='12345'
$ echo "${#var}"
```

## 第 15.3 节：替换 (Pattern Substitution)

```bash
# 替换
$ var='hello world'

# 替换第一个匹配
$ printf '%s\n' "${var/hello/hi}"
hi world

# 替换所有匹配
$ printf '%s\n' "${var//hello/hi}"
```

## 第 15.4 节：删除 (Deletion)

```bash
$ var='hello world'

# 删除结尾的匹配
$ printf '%s\n' "${var%world}"
hello

# 删除结尾的所有匹配
$ printf '%s\n' "${var%%world}"
hello
```

## 第 15.5 节：从字符串开头删除模式

```bash
$ var='hello world'

# 删除开头的最短匹配
$ printf '%s\n' "${var#hello}"
world

# 删除开头的最长匹配
$ printf '%s\n' "${var##hello}"
world
```

## 第 15.6 节：间接引用 (Indirection)

Bash 间接引用允许获取包含另一个变量名的变量的值。变量示例：

```bash
$ red="the color red"
$ green="the color green"
$ color=red
$ echo ${$color}
# the color red
$ color=green
$ echo ${$color}
```
