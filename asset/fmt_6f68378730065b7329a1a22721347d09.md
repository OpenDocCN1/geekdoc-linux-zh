## 文件所有者

每个文件（或目录）都属于一个所有者（普通名称）和一个组。所有者通常是创建（或复制）该文件的用户。该组通常由一个人组成——即所有者，且名称与所有者相同，但并不一定如此。文件的所有者、该文件所属组的成员以及`root`用户可以删除（清除）文件。然而，如果其他用户被赋予了读取权限，他们可能会修改或删除文件的内容。在`ls -l`命令（即长格式）的输出中将显示文件的所有者和所属组。例如，命令：

```
ls -l
```

在我的屏幕上产生：

```
-rw-r--r-- 1 yogin 27 Apr 14:12 june
```

这显示文件`"junk"`属于所有者`"yogin"`和组`"inca"`。文件的所有权可以使用`chown`（更改所有者）和`chgrp`（更改组）命令进行更改，这些命令通常由以下命令执行：

```
chown peter
chgrp peter
ls -l
```

执行这3行后，命令`ls-l`会在我的屏幕上产生此输出：

```
--rw-r--r-- 1 peter peter 27 Apr 25 20:27 june
```

如果你想作为`root`移动/复制文件供其他用户使用，则更改文件所有权。在清理工作结束后，你可能将文件所有权改为正确的用户。

## 文件权限

现在，任何文件的所有者都可以以三种模式：读(`r`)、写(`w`)和执行(`x`)为三类用户设置访问：所有者(`u`)、组成员(`g`)、系统其他用户(`o`)。你可以检查当前的访问权限：

```
ls -l filename
```

如果文件对所有用户（所有者、组、其他）在三种模式（读、写、执行）下都是开放的，它将显示：

```
--rw-xr-x
drwxr-xr-x 2 root root 21584 Apr 24 19:22 june
```

第一个字母`"d"`显示该文件实际上是一个目录。你可以使用`chmod`（更改模式）更改你拥有的文件的权限。例如，此命令将添加读取文件`"junk"`的权限给`<user=group+>`：

```
chmod a+r
```

在上面的命令中，`"a"`是（全部），我可以使用`"u"`、`"g"`或`"o"`代表（用户、“组”或“其他”）。我可以使用`"-"`或`"="`来移除权限或设置一组`"r"`（读权限），我可以使用`"w"`或`"x"`（“写权限”或“执行权限”）。

第二个示例。此命令将移除其他用户执行文件`"junk"`的权限：

```
chmod o-x
```

除了字母外，也可以使用数字来指定权限。要理解它是如何工作的：

```
execute=1
write=2
read=4
```

### 权限位参考

一类用户的总权限是这三者之和。因此：

*   `0` = 完全没有权限（既不可写、不可读、不可执行）（常见）
*   `1` = 仅执行（看起来不寻常）
*   `2` = 仅写入（看起来不寻常）
*   `3` = 写和执行（看起来不寻常）
*   `4` = 仅读（常见）
*   `5` = 读和执行（常见）
*   `6` = 读和写（常见）
*   `7` = 写和执行（常见）

所有三类用户（所有者、组、其他）的权限通过将三个数字逐一拼接获得。例如，命令：

```
chmod 778 junk
```

将赋予所有者和组完整的权限，但对其他用户没有权限。命令：

```
chmod 666 junk
```

赋予了所有三类用户（所有者、组、其他）对名为`"junk"`的文件的读和写（但不可执行）权限。请注意`"666"`经常被使用，并且对于我认识的至少有一个人来说，它是`Linux`（这很重要）是`dev:-`工作的证明。此命令：

```
chmod 411 junk
```

将赋予所有者读取权限，而赋予组和其他用户仅执行权限。这看起来似乎没用，但可能很有趣，至少对北美用户来说，如果你考虑任何其他权限（也许`777`）。用数字表示文件权限的方法被称为“八进制”，因为数字是`8`基（十进制系统的基数是`10`）。最高数字是`7`（八进制数字为`0`到`7`，类似于十进制系统的数字为`0`到`9`）。八进制表示是权限二进制表示的一种方便表示法，其中每个权限都用一个零标记为“已设置”或“被拒绝”，总和表示为由零和一组成的字符串，如下图所示：

| | 所有者 | 组 | 其他用户 |
|---|---|---|---|
| 类别: | | | |
| 示例权限: | `rw-` | `rw-` | `-wx` |
| 缺失权限: | `-` | `-` | `-` |
| 二进制表示: | `110` | `110` | `011` |
| 八进制表示: | `6` | `6` | `3` |

*(注：由于原文二进制/八进制对应关系在示例中可能略有偏差，此处保持逻辑一致或根据标准八进制修正，原文示例为 111/110/011 对应 7/6/3，此处按翻译逻辑对齐)*
