
示例表单头部的另一个元素`METHOD`告诉客户端如何将输入的数据发送到服务器。该元素是可选的；如果你遗漏了它，浏览器将使用默认值`GET`。`GET`告诉客户端将表单数据嵌入URL中。事实上，你可以创建直接运行使用`METHOD=GET`的CGI程序的超链接。

`<FORM>`标签中可以出现的可选元素`ENCRYPT`告诉浏览器如何构建发送到服务器的信息。如果省略了`ENCRYPT`，编码类型为"text/x-form-encoded"，这意味着普通的表单数据将被发送到服务器。目前`ENCRYPT`除了默认值外的唯一值是"multipart/form-data"，这意味着浏览器将组织其返回的内容，以便发送多种文件类型。除了任何数量的表单数据（文本字段、选择菜单等，后文讨论），此选项意味着表单可能包含整个文件，使用下面讨论的文件上传功能。除非允许用户使用表单上传文件，否则请在`<FORM>`标签中省略`ENCRYPT`属性。

你可以在表单的开始和结束元素之间放置任何文本或标记，另一个`<FORM>`标签除外；你不能嵌套表单。除了普通标记外，几个特殊的HTML标签在表单内部是合法的；在其他地方添加它们甚至会导致某些（编写得非常糟糕）客户端崩溃。浏览器将这些特殊标签渲染为用户交互和输入的区域。

在上一个示例中，表单包含一个需要回答的问题，后面是两个标签`<INPUT>`和`<BR>`。如图10-4所示，客户端的渲染包括文本，随后跟一个嵌入的文本输入框，用户已经在其中输入了他的回答。要完成表单，用户按下回车键，这告诉浏览器表单已完成。浏览器将输入的文本分配给标签的`NAME`元素（即"home"），并将此数据发送到服务器。

另一方面，`MAXLENGTH`元素确实限制了输入。例如，用户在"州"（State）字段中输入的字符不能超过两个。虽然它阻止了用户添加更多输入，但`MAXLENGTH`并不决定输入框在页面上的长度。`SIZE`属性影响框的物理尺寸，而`MAXLENGTH`属性只影响可以输入的最大字符数。

在文本输入控件中有效的可选元素中，最后一个是`VALUE`，它允许你为字段提供默认响应。你可以在上述图10-5所示示例的"国家"（Country）字段中看到该元素的示例。当客户端渲染此内容时，文本区域内会有"USA"文本。如果用户想要不同的响应，他或她必须先删除此默认文本。`VALUE`元素对于提供你所需的输入类型示例，以及节省用户输入典型响应的麻烦非常有用。

与复选框不同，单选按钮不是独立的实体。多个单选按钮通常被分组在一起，共享相同的名称。在任何时候，一组只能选择一个单选按钮，因为它们的行为就像老式汽车上的预设档位。当用户按下一个按钮时，上一个选择就会弹出。单选按钮用于从几个互斥的选项中选择一个：

```
你的性别是什么？
<P>
<INPUT TYPE=radio VALUE="male" NAME="sex">男性<BR>
<INPUT TYPE=radio VALUE="female" NAME="sex">女性<BR>
```

此示例创建了两个互斥的选项，每个选项都有自己的按钮。虽然单选按钮共享相同的`NAME`，但由于它们是一组的，它们就像老式汽车上的预设设置。

## 文件上传

浏览器引入的一个较新功能是允许使用表单上传文件。HTML语法本身非常直观。在章节开头提到的`<FORM>`标签中放入`ENTYPE`属性后，你可以使用以下标签提示用户选择本地机器的文件：

```
<INPUT TYPE=FILE NAME="UPLOAD">
```

使用表单上传文件比向服务器发送文本需要更复杂的处理。在第11章"CGI：面向程序员的高级表单"中详细介绍了如何使用CGI处理。

## 隐藏字段

虽然隐藏字段对于简单表单并不重要，但它允许高级表单作者解决编写交互式应用程序的主要障碍之一：无状态性。由于Web服务器不保留之前的连接信息，表单所需的任何信息必须由客户端保留。你可以通过数据本身或数据的密钥嵌入表单的隐藏字段中来保留此类信息，除非用户查看页面，否则它是不可见的。这些字段并不具有交互性。（用户甚至看不到它们，更不用与之交互了！）相反，它们更像编程语言中的变量赋值；它们允许将`NAME`等于`VALUE`：

```
<INPUT type=hidden NAME="gamestate" VALUE="o--x----">
```

这个示例可能来自虚拟井棋游戏。它声明了一个名为"gamestate"的变量，并为其分配了一个代表九个格子的状态值。在这个假设的应用中，用户最初会拉取一个包含三行三个单字符文本输入字段的表单（尽管使用`<SELECT>`标签可能是更好的选择——参见下一节）。用户会在中心格子中输入X，并按下提交按钮。

服务器上的表单处理程序会找到用户的移动并将其据为己有，可能会写出一个新表单，如图10-7所示，带有上一个示例所示的隐藏字段。通过在隐藏字段中跟踪游戏进度，程序可以记住轮到谁了。它还可以确保用户在游戏后期更改他或她的移动，或者尝试在单回合内移动两次。
