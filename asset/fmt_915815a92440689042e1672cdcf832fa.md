
如果脚本需要 `temp` 目录但它不存在，则脚本将以退出状态 1 终止。

## 总结

我们从一个问题开始本章：我们如何让自己的 `sys_info_page` 检测用户是否有权限读取所有主目录？根据我们掌握的知识，我们可以通过向 `report_home_space` 函数添加以下代码来解决这个问题：

```bash
report_home_space () {
if [[ "$(id -u)" -eq 0 ]]; then
  cat << _EOF
    <h2>Home Space Utilization (All Users)</h2>
    <pre>$(du -sh /home/*)</pre>
  _EOF
else
  cat << _EOF
    <h2>Home Space Utilization ($USER)</h2>
    <pre>$(du -sh $HOME)</pre>
  _EOF
  fi
  return
}
```

我们评估了 `id` 命令的输出。通过 `-u` 选项，`id` 输出有效用户的数字用户 ID。超级用户 ID始终为零，其他所有用户都是大于零的数字。通过这一点，我们可以构建两个不同的文档：一个利用超级权限，另一个限制在用户自己的主目录中。

我们将暂停编写 `sys_info_page` 程序，但不用担心，它会回来的。在此期间，我们将涵盖在恢复工作时需要的一些主题。

## read – 从标准输入读取值

`read` 内置命令用于读取单行标准输入。该命令可以用于读取键盘输入，或者在采用重定向时从文件中读取数据行。该命令具有以下语法：

```
read [-options] [variable...]
```

其中 `options` 是表 28-1 后列出的可用选项的一个或多个，`variable` 是用于存储输入值的一个或多个变量名。如果没有提供变量名，壳变量 `REPLY` 将包含该行数据。

基本上，`read` 将标准输入中的字段赋值给指定的变量。如果我们将整数评估脚本修改为使用 `read`，它可能看起来这样：

```bash
#!/bin/bash

echo -n "Please enter an integer -> "
read int
if [[ ! "$int" =~ ^-?[0-9]+$ ]]; then
    if [ "$int" -eq 0 ]; then
        echo "$int is zero."
    else
        if [ "$int" -lt 0 ]; then
            echo "$int is negative."
```

```bash
else
  echo "$int is positive."
fi
if [ $((int % 2)) -eq 0 ]; then
  echo "$int is even."
else
  echo "$int is odd."
fi
```

```bash

  echo "Input value is not an integer." >&2
exit 1
```

我们使用带有 `-n` 选项的 `echo`（抑制输出结尾的换行符）来显示提示，然后使用 `read` 为变量 `int` 输入一个值。运行此脚本的结果如下：
