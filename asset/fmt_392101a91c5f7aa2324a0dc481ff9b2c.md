### 安装 WordPerfect 8

术语 Linux 有两层含义。首先，它指的是 Linux 操作系统的内核或核心。其次，它指的是围绕 Linux 内核构建的软件程序发行版。

最新的 Linux 发行版都包含了 Linux 内核的 2 版本。在这种意义上，发行版的核心是相同的。然而，构成发行版的程序可能会有很大差异。例如，Red Hat 发行版与 Caldera 发行版不同，尽管两者都基于相同的 Linux 内核。

发行版不同的一个方面是它们包含的桌面环境的风格和外观。Linux 桌面环境加载在 Linux 之上，就像 Microsoft Windows 加载在 DOS 之上一样。换句话说，您 Linux 窗口的风格和外观取决于您使用的桌面环境。

您可能有兴趣知道，一些 Linux 发行版——例如 Red Hat 6——随附多个桌面环境。选择使用哪一个由您决定。

目前最常见的桌面环境是 Gnome 和 KDE。Red Hat——Linux 最畅销的发行版——将其 Gnome 桌面作为默认安装。Caldera——第二畅销的发行版——默认使用 KDE。从 WordPerfect for Linux 用户的角度来看，您使用哪一个并不重要，因为 WordPerfect 在任一桌面环境中都工作相同。

如果你想了解更多关于 Red Hat Linux 6 和 Gnome 桌面的信息，请查阅《Red Hat Linux 6：Visual QuickPro Guide》（Peachpit Press）。

### 什么是 Linux X11 Windows Server？

从技术上讲，WordPerfect 8 for Linux 可以在任何能够显示 X11 Windows 的 Linux 系统上运行。X11 Windows 是在 Unix 系统（如 Linux）中幕后工作的机制，用于显示 Gnome 等窗口环境。它是过去所称 X Windows 的增强版本。因此，你的系统是否能够运行 WordPerfect 8 for Linux 的关键在于它是否具有 X11 Windows 服务器。

### WordPerfect 版本之间的区别

WordPerfect 8 for Linux 有三个版本可供选择：可免费下载的版本、本书所基于的个人版，以及服务器版。

可下载版本是一款功能完整的文字处理器，可让你导入和导出 Microsoft Office 97 文档文件格式。它包含在线帮助系统、90 多个内置电子表格函数，并可将文档以 HTML 格式导出为可上网的文档。

个人版包含可下载版本中的所有功能，外加绘制图片和创建图表的能力、使用 ExpressDocs 功能创建文档套件，以及安装随程序提供的 130 种字体。此外，CD-ROM 包含超过 5000 张剪贴画、200 张照片和 180 种纹理，可用于创建动态报告和文档。

服务器版包含个人版中的所有功能，外加对 Oracle 数据库引擎的支持、高级应用程序定制程序，以及让使用非 GUI 终端版 Linux 的用户访问 WordPerfect 8 的能力。

### WordPerfect 与 Linux 许可

与 Linux 操作系统不同，WordPerfect 是一款商业产品；它既不是免费软件也不是开源软件。你有法律义务遵守 Corel Corporation 的许可条款。对于免费的可下载版本，这意味着每个用户必须在 90 天内向 Corel 注册，否则免费版本将过期且无法再使用。此外，免费版本仅用于个人用途，而非商业用途。

个人版附带单用户许可。有关许可服务器版的信息，请联系 Corel Corporation。

### 安装个人版

本节描述如何安装随 CD-ROM 发行的 WordPerfect 8 个人版。如果你想了解如何下载和安装免费版本，请翻到第 29 页。

要在你的计算机上安装 WordPerfect 8 个人版，你需要挂载 CD-ROM 驱动器，然后使用终端窗口进入命令行。要执行这两项操作，你必须以 `root` 身份登录或 `su` 到 `root`。如果你无法访问 `root`，请联系你的系统管理员。

#### 挂载 CD-ROM 驱动器：

1. 将 WordPerfect CD-ROM 插入计算机的 CD-ROM 驱动器。

2. 在 Gnome 主菜单的 System 弹出菜单中选择 Disk Management（图 1）。User Mount Tool 对话框将打开（图 2）。

3. 点击位于计算机 CD-ROM 位置右侧的 Mount 按钮。在图 2 中，该位置为 `/mnt/cdrom`。CD-ROM 驱动器将被挂载，你刚刚点击的按钮将显示为“Unmount”。

4. 点击 Exit 关闭 User Mount Tool 对话框。
