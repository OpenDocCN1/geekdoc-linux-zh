## 使用 `:map` 命令创建宏

`:map` 命令的用法与缩写（abbreviation）类似。`:map` 命令允许我们将命令模式下的多个按键序列分配给单个（或多个）按键序列（或者反之）。

这类命令通常被称为键盘宏（keyboard macros）。

*通常，`:map` 命令用于将键盘上可用的按键（如光标控制方向键）映射到所需的 `vi` 命令（`h`、`j`、`k` 和 `l`）。*

`:map` 命令的输入方式与缩写完全相同。例如，要将命令序列 `dwelp`（它将反转两个相邻单词的顺序）映射到字母 "v"：

`:map v dwelp`

在映射中使用控制字符时，必须在输入该控制字符之前输入 `^V`。否则，`vi` 将立即尝试解释你正在输入的控制字符。`^V` 实际上告诉 `vi`：“不要解释下一个字符，直接将其输入文本中。”当你输入 `^V` 时，屏幕只显示 `^`（脱字符符号）。例如，当你想在映射中插入一个 Esc 字符时，你需要输入 `^V` 然后紧按 Esc 键。假设你想将 "v" 键映射到 Esc 键。输入 `^V` 后，你在屏幕上看到的将：

`:map v ^`

然后当你按下 Esc 键时，屏幕看起来像这样：

`:map v ^\[`

最后按下回车键（Return）后，你的映射就会生效。

要将键盘上某些某些键重新映射到 `vi` 中的等效功能，你甚至不需要知道键盘被分配了什么字符序列。只需使用 `^V` 键，然后输入你想要分配的键即可。（这可能有效也可能无效，取决于你终端所生效的终端映射。如果在设置键盘映射时遇到困难，请咨询你的系统管理员。）

查看哪些键尚未被 `vi` 占用是非常有用的，因此这些键可以用于映射而不会丢失任何功能（事实上，还有几个键是未使用的）。它们如下：`g`、`K`、`q`、`V`、`v`、`^A`、`^K`、`^O`、`^T`、`^W`、`^X`、`\_`、`\*`、`\\`、`\=`。（如果生效了 lisp 设置，则 `\=` 键不可用。）

要移除映射，请使用 `:unmap` 命令。要查看所有生效的所有映射，请使用不带参数的 `:map` 命令。

## 修改 `vi` 设置

在本节之前，我一直在描述 `vi` 在各种情况下的默认行为。你可以通过更改 `vi` 设置来修改这些默认行为。理解这些设置的最简单方法是通过示例。其中一种默认行为是当你插入文本并到达行尾时 `vi` 的操作。默认行为是继续向该行添加文本；但显示上会产生换行到下一行的视觉效果。（你可以通过使用命令模式下的 `0` 和 `$` 命令来检查 `vi` 认为的行开始和结束位置。）你可以根据需要更改这种默认行为。

**提示：** 除了使用 `0` 和 `$` 命令查看行的开始和结束位置外，你还可以使用 `:set nu` 设置行号，来查看 `vi` 是如何分配行号的。另一种可能有帮助的技巧是使用 `:set list`，它将分别用 `^I` 和 `$` 显示制表符和行尾。

例如，如果你正在输入备忘录的文本，你可能希望 `vi` 自动换行。通过使用 `wrapmargin` 设置（缩写为 `wm`），你可以让 `vi` 在你接近行尾时自动插入换行符。（`wm` 设置的具体行为将在后文中描述。）另一方面，如果你正在编辑源代码文件，你很可能不希望有这种换行，因此默认行为就是你需要的。

**其他高级编辑技巧**

尽管我们显然已经触及了 `vi` 强大的边缘，但仍有更多可用功能。本节简要提到的功能是为了让您知道它们的存在。只有您亲自使用它们时，才能从中获得最大的收益。

**@ 函数** `@` 函数将名为命名缓冲区的内容作为 `vi` 命令执行。因此，构建宏命令的另一种方法是输入您想要反复使用的命令文本，用 `^V` 转义每个控制字符，然后将该文本删除到命名缓冲区中。然后您可以使用 `@*x*` 命令执行该缓冲区中的命令，其中 *x* 是命名的缓冲区。

**使用自动缩进** 在编辑源代码文件时，`autoindent` 命令和设置是不可缺的。当启用 `autoindent` 设置时，每个新行的缩进距离与上一行相同，这使得源代码的结构更容易构建。您有几个命令可以配合 `autoindent` 使用使用。

- **^D--反制表（带自动缩进）** 回到上一个 `autoindent` 停止位，由 `shiftwidth` 设置指定。为了最有效地使用，您应该将 `shiftwidth` 设置与 `tabstop` 设置配合。
- **^^D--结束自动缩进，仅限一行** 此命令是脱字符符后跟 Ctrl-D。它会导致当前行暂停 `autoindent`。光标移动到左。在下一行，`autoindent` 将恢复。
- **^D--光标到左** 回到左边距。
- **使用标签** 在使用此命令之前，必须先创建 `tags` 文件。`Emacs` 允许跳转到文件。此命令对程序员有利。此命令消除了您跟踪函数在哪个文件的需要。

要删除光标所在的行，使用 `C-k` 命令。该命令的操作方式很特殊。第一次按下 `C-k` 时，光标所在的行会被删除，留下一个空行。再次按下 `C-k` 会删除该空行。

要删除不是单词、句子或行等文本元素的特定部分，你可以使用标记（mark）来标记要操作的文本区域。标记命令 `C-@`（或者 `C- SPACE`）用法如下：首先将光标移动到要标记区域的一端。按下标记命令。然后将光标移动到区域的另一端。从现在起，任何操作区域的命令将作用于标记点和当前光标之间的所有文本。例如，要删除标记区域中的文本，可以使用 `C-w` 命令。

`C-@` - 设置标记命令，标记区域的一端
`C-SPACE` - 设置标记命令，标记区域的一端（与 `C-@` 相同）
`C-w` - 杀死标记区域
`SHIFT-DEL` - 杀死标记区域（与 `C-w` 相同）

**恢复删除的文本：剪切与粘贴** 有两种方法可以找回删除的文本：(1) 从环（kill ring）中 yank；(2) 使用 `Emacs` 的 undo 函数。

**注意：** `Emacs` 和 `vi` 之间存在术语差异。`vi` 将存储删除内容的缓冲区称为撤销缓冲区（undo buffers）。`Emacs` 将对应的称为杀死缓冲区（kill buffers）。

在 `Emacs` 中，yank（贴回）的概念与 `vi` 相反。在 `vi` 中，yank 会将文本复制到撤销缓冲区；而在 `Emacs` 中，yank 是从杀死缓冲区复制回文本的反向操作。

`Emacs` 将所有被杀死文本存储在称为杀死环（kill ring）的内部缓冲区中。被删除但未被杀死的文本不会保存在杀死环中。例如，通过 `DEL` 或 `C-d` 删除的单个字符不会保存在那里。

要从杀死环中恢复最近删除的文本，你需要结合使用两个命令。首先，你必须使用 `C-y` 命令执行 yank（`SHIFT-INS` 是其同义词）。该命令将贴回最近一次的删除。如果这并不是你想要的删除文本，连续使用 `ESC y` 命令将按顺序恢复之前的删除内容，类似于 `vi` 中 `"`np` 命令接 `repeat`(`.)` 命令的序列。第一次使用 `ESC y` 时，会插入第一个之前被杀死的文本。下一次 `ESC y` 将将 yank 的文本替换为下一个最近的删除内容。（当你回到已保存删除次数的限制后，最近一次的删除内容会被贴回。这就是“环（ring）”一词的由来。杀死环的初始默认大小为 20。）一旦你习惯了这些命令的操作，通过一系列杀死命令后接 yank 命令来重新排列文本就会变得简单。

**另一种删除和粘贴方法** 正如你从删除和 yank 命令的讨论所示，在 `Emacs` 中移动文本的最简单方法之一是通过选择和粘贴的菜单命令。当你使用此命令时，会显示一个窗口，其中最近几次删除内容的每行内容。你可以将显示选项中的任何一个粘贴到你的文本中。

**撤销编辑** `Emacs` 的 undo 函数非常强大。重复应用 undo 函数 `C-x u`（或者 `C-\` 或 `C\\`，除非你重新映射了该绑定）将按顺序撤销你所做的每一次编辑，最终带你回到编辑会话的开始！undo 函数将撤销每一次编辑更改，而不仅仅是删除。

**搜索与替换** `Emacs` 拥有许多不同方法来搜索和替换文本。在后续对各种搜索类型的讨论中，我将使用“目标（target）”来指代你查找的文本，也指代 `Emacs` 找到的匹配文本。我使用“替换（replacement）”来指代你希望替换目标的字符串。以下是你可以使用的五种不同搜索方法：

1. **简单搜索。** 这种搜索最容易理解。`Emacs` 会查找一个固定的字符串，在找到第一个匹配字符串后将光标放在后面。执行简单搜索使用命令 `C-s target`。只需输入 `C-s` 即可重复搜索。要向后搜索，使用命令 `C-r target`。再次向后搜索，只需输入 `C-r.`。要使用简单搜索并将找到的所有文本替换为替换字符串，使用命令 `ESC x replace-string *target* *replacement*，其中 `replace-string` 文本需要字面输入，因为它是命令的名字。在许多情况下，使用简单搜索替换方法替换文本并不是好主意，因为对任何大量文本执行此类操作不可避免地会导致许多不需要的替换。

## 3. *增量搜索*。增量搜索是文本编辑器中一项独有的功能，尽管它经常实现在提供某种列表框处理或表格查找功能的应用程序中。增量搜索是在输入目标字符串时实时发生的。其工作原理如下：调用增量搜索命令后，你开始输入搜索字符串的字符。你输入第一个字母，`Emacs` 会搜索与该字母匹配的第一个。你输入下一个字母，`Emacs` 会进一步搜索与你目前输入的两个字母匹配的第一个。这个过程一直持续，直到 `Emacs` 找到你正在寻找的目标，或者不存在这样的匹配。

要执行增量搜索，请使用 `C-s` 命令。然后开始输入目标字符串的字符。如果你找到了正在寻找的目标字符串，按下 `RETURN` 搜索将停止。你可以通过再次输入 `C-s` 命令继续搜索更多匹配目标，而无需再次输入搜索字符串。

**注意：** 无论原始搜索是简单搜索还是增量搜索，再次搜索同一个目标都是通过 `C-s` 命令完成的。一旦 `Emacs` 定位目标，重复搜索的操作不再取决于原始搜索是如何执行的。

如果上一个动作是搜索，那么 `C-s`（或反向搜索的 `C-r`）将立即跳转到下一个目标。如果中间插入了命令（如光标定位），则必须输入两次 `C-s`（或 `C-r`）：第一次用于开始搜索，第二次用于告诉 `Emacs` 使用与上次搜索相同的目标。

## 4. *单词搜索*。单词搜索是另一种特殊类型的搜索。单词搜索只会匹配完整的单词或短语，忽略空格、标点符号和换行符。你可以使用它来避免之前描述的简单搜索所存在的问题。单词搜索是唯一可以跨行的搜索类型，因为它忽略了换行符。因为其他搜索类型局限于单行，如果目标是一个短语，它们通常会错过目标，因为目标可能跨越两行分布。要执行单词搜索，输入命令 `C-s RETURN C-w ``target*`` RETURN`，其中 *target* 是一个单词或短语。

当你的 Emacs 编辑屏幕上显示多个窗口时，每个窗口都有某些特定的属性。在一个 Emacs 会话中只有一个光标；它一次只能在一个窗口。包含光标的窗口被称为活动窗口。然而，每个缓冲区都维护自己的点（point）。因此，当不同窗口之间切换时，光标将出现在该缓冲区上次工作的位置。

` 若智，指挥官能够洞察形势的变化并采取机机行动。若诚，他的部下将对赏罚的确定性毫无疑虑。若仁，他热爱人类，同情他人，并赞赏他们的辛勤劳动。若勇，他能毫不犹豫地抓住机会赢得胜利。若严，他的军队纪律严明，因为他们敬畏他并害怕惩罚。`

` 包拯 ... 说：“将者无勇，则不能克服疑虑，不能制定大计划。”`

## 用于标记位置的书签

Emacs 提供了一个书签功能，其功能远超 vi 的文本标记能力。当你设置书签时，Emacs 会在你的主目录下创建一个文件，记录所有书签的永久记录。每个书签都会跟踪被标记文件的完整路径和名称，以及在该文件中被标记的位置。此后，每次启动 Emacs 会话，该书签文件都会加载。你可以使用一组特殊的命令找到你处理过的任何文件中的任何点。当你正在一个大型项目或处理多个缓冲区时，这种功能完备的书签能力可以极大地节省时间。

Emacs 允许你使用与处理缓冲区类似的界面来处理书签列表：你可以在窗口中显示书签列表，然后发出专门命令来直接操作书签。再次，你可以使用 Emacs 的补全功能来选择书签（输入名称的几个字符并按 TAB；Emacs 将会补全书签名称或给你提供一个选择菜单）。表 3.40 显示了处理书签和书签列表最重要的命令。

## 各语言的格式化

Emacs 为编写代码提供了帮助。针对许多常用语言的主模式（major modes）。每种语言提供的功能各不相同。通常，Emacs 以非常基础的方式“理解”语言的语法。当 Emacs 处于文本模式时，它会识别单词、句子和段落等文本结构的边界，以便执行移动命令等。同样，当处于其中一种语言模式时，Emacs 被设置为执行相应的操作，例如插入换行符或指定的缩进。

每种语言的主要功能之一是设置缩进。例如，在 C 模式下，有多种格式化选项（即 GNU、K&R、BSD、Stroustrup、Whitespacemith）。或者如果你精通 LISP 语言（Emacs 是用这种语言实现的），你可以修改并扩展这些模式来实现自己的样式。

## 作为集成环境的 Emacs

为了帮助程序员，Emacs 以集成环境的形式提供了额外的支持。这些支持的主要组件包括 `make` 设施的接口、在窗口中执行编译器、操作编译错误输出以跳转到源码中的错误点，以及在窗口中执行 shell 以进行测试和通用用途。有几个命令与这些功能的每一个都配合工作。

对于 C 和 C++ 程序员来说，一个特殊的功能是 `etags` 功能。该功能类似于 vi 的 `tags` 函数（在 vi 章节中已描述）。该功能的目的是使用由独立的 etags 程序创建源代码文件名和程序函数名的数据库。一如既往，Emacs 版本的功能比 vi 内部使用的对应函数更强大——有更多命令可以用于处理标签。

## 使用 `Emacs` 作为文件管理器

dired（“目录编辑器”）模式在表 3.24 中被列为 `Emacs` 的主要模式之一。这种模式可以通过多种方式启动。一种方法是在启动 `Emacs` 时，输入一个目录名称而不是文件名。另一种方法是使用常规的 `find-file` 命令，但提供目录名称而不是文件名。第三种方法是通过输入 `C-x d` 直接发布 `dired` 命令，然后提供目录名称。

当你处于 dired 模式时，缓冲区的内容看起来类似于 `ls` 命令的输出。从这个缓冲区，你可以执行许多与文件相关的操作。你可以对单个文件进行复制、移动、删除、重命名、压缩、查看和编辑。你可以创建目录。你可以在文件上执行其他的 UNIX 命令。你还可以标记一组文件以进行这些相同的操作。你可以使用正则表达式选择文件进行操作。通常在操作此类文件集时，会获得最大的生产力提升。例如，你可以一次性对一组文件执行 `query-replace`（查询替换）。

虽然确实如此，在 dired 模式下无法完成任何你通过单独执行 shell 命令就能完成的事情，但作为一名对 shell 操作和使用 dired 类文件管理器方法都有长期经验的人，我完全可以认为，取决于你的工作风格，生产力可能会获得极大提高。我经常遇到这样的情况：原本需要几小时的操作缩短到了几分钟。

## 在 `Emacs` 中使用 Shell 

`Emacs` 中的 shell 模式可以非常简单地解释。在输入命令 `ESC x shell` 启动 shell 缓冲区后，`Emacs` 会打开一个可以在其中执行普通 UNIX shell 命令的缓冲区。然而，`Emacs` 提供了在你输入的文本使用其许多编辑功能的能力，包括补全功能和类似屏幕历史的功能（能够回溯 shell 会话的“转录”以检查命令输出，甚至可以无需重新输入即可重新执行缓冲区中的命令）。

Shell 模式最出色的隐藏宝藏之一是能够同时运行多个可见的 shell 会话，同时保持每个会话的输出互不干扰。事实上，在 X-windows 流行之前，许多 `Emacs` 用户仅通过 `Emacs` shell 模式就拥有类似的功能。

## 像文字处理器一样使用 `Emacs`

除了是一个很好的文本编辑器之外，当你需要时，`Emacs` 还可以对你的文档进行某种装扮。虽然不自诩为真正的文字处理器，但你可以执行一组有限简单格式化任务。这些任务包括处理屏幕上的字体和颜色、文本对齐、文本缩进、添加分页符、处理列以及处理大纲。

## 使用 `Emacs` 对文本进行标记

随着世界维网的广泛采用，标记语言的概念已变得广为人知。Web 语言是 HTML，全称为超文本标记语言（HyperText Markup Language）。HTML 是文本的一种，包含 ASCII 字符以及特殊标签，浏览器会解释这些标签并根据浏览器的能力产生非常精细的效果。特殊标签具有相当简单的结构。你可以使用任何标准编辑器创建 HTML 文档；然而，当编辑器被扩展以理解 HTML 标签时，它可以帮你更轻松地完成工作。

有实现 HTML 和其他类型标记语言的主要模式和包。`Emacs` 提供的常用模式用于 `troff`（标准的 UNIX 文本格式化器）、`nroff`（字符终端的 `troff` 版本）、TEX 和 LATEX。

## 使用 `Emacs` 互联网

有几项互联网活动 `Emacs` 提供了直接支持。你可以将 `Emacs` 作为操作环境，其具有直接与电子邮件交互的功能，包括发送、接收和管理你的通信。你可以在 `Emacs` 内部使用 Telnet 登录另一个系统，并在 `Emacs` 缓冲区中保留会话的转录；你可以通过 Ange-ftp 模式扩展 `find-file` 命令来处理 FTP 以查找和下载文件。你还可以通过内置接口直接在 `Emacs` 内部使用 Gnus 阅读器（一个独立的程序）。

## 缩写模式 (Abbreviation Mode)

正如在次要模式章节暗示的那样，`Emacs` 中有一个可以启缩写功能。该模式的用法在 `vi` 中介绍过，所以我只需简要提到 `Emacs` 具有这种模式，并且功能比 `vi` 多一些。

要启用缩写模式，使用命令 `ESC x abbrev-mode RETURN`。要设置一个缩写，首先在文本中输入你想要使用的缩写，然后输入命令 `C-xaig`。当 `Emacs` 询问你扩展内容时，输入你希望在输入缩写时插入的完整文本，然后按 `RETURN`。你刚刚输入的缩写会被展开。每当你输入它并后跟空格或标点符号时，它都会展开。

## 使用宏 (Macros)

正如你现在可能已经猜到的那样，宏是一系列记录留以后使用的按键。通过回放按键，你可以轻松地完成重复性任务。许多编辑器都提供宏功能。`Emacs` 的功能特别强大，因为可以通过在命令前加一个倍数来执行任何系列命令，例如使用 `C-u` 重复宏四次，以此类推。

执行宏有两种方法。你可以执行最近记录的（当前宏），或者你可以给它命名并在稍后执行。当前宏仅在会话期间有效。要使宏持久化，必须将它们保存到文件中。用于宏的命令见表 41。

| `C-x e` | 调用当前宏 |

## 配置 `Emacs` 以你的喜好

正如你现在可能猜到的，`Emacs` 是高度可定制的。主要的自定义类型有 (1) 为你经常使用的没有标准绑定的函数创建自己的绑定；或者 (2) 重映射提供的函数。另一种超出本章范围的自定义类型是通过编写 `Emacs LISP` 实际上添加函数（通过后这种方法，你真的可以说 `Emacs` 是无限灵活的）。

例如，为了将帮助功能绑定到 `C-x ?`并将退格功能绑定到 `C-h`，你可以在你的 `.emacs` 文件中输入以下：

`(global-set-key "\\C-x?" 'help-command)`

`(global-set-key "\\C-h" 'backward-char)`

（只有最基础的部分是用 C 编写的；其余部分是用 `Emacs LISP` 编写的）。通过这种方法你真的可以说它是无限灵活的。

## 字段

输入或输出文件中的一组字符被称为*字段*（field）。字段在 awk 中预定义：`$1` 是第一个字段，`$2` 是第二个字段，`$3` 是第三个字段，以此此类推。`$0` 表示整行。字段由分隔符（包括 `Tab` 在内的任何字符）分隔，存储变量 `FS` 中。除非你更改它，`FS` 的值为空格。

脚本包含两个部分：`BEGIN` 块和处理每个输入的主行块。此外，大部分工作都是自动完成的。

## 程序格式

除了少数例外外，awk 程序是自由格式的。解释器会忽略程序文件（也称为 awk 脚本）中的任何空行。添加空行可以提高程序的可读性。操作符与程序部分之间的制表符和空格也是如此。因此，awk 解释器对这两行代码的处理方式是等同的：

`$4 == 2 {print "Two"}`

`$4 == 2 { print "Two" }`

如果一行中出现多个动作，你需要用分号隔开这些动作，正如之前在 `/etc/passwd` 文件翻译器的 `BEGIN` 块中显示的那样。如果你坚持每行一个命令，就不需要太担心分号了。然而，在某些地方必须使用分号：在 `else` 语句之前，或者当包含在语句的语法中时。（参见本章的“循环”或“条件语句”章节。）

在语句末尾加上分号对于当你具有 C 语言背景或将 awk 代码转换为编译后的 C 程序时非常有用。

awk 程序的另一个格式限制是，动作（模式动作语句）的起始大括号必须与相应的模式在同一行内。因此，以下示例的作用都是相同的。

第一个示例将所有语句放在同一行内：

`$2==0 {print ""; print ""; print "";}`

第二个示例将第一个语句与匹配模式放在同一行，将其余语句放在随后的几行中：

`$2==0 { print ""`
` print ""`
` print ""}`

你还可以通过将第一个语句移动到单独的一行来进一步分散语句。只有初始的（起始）大括号必须与模式在同一行上：

`$2==0 {`
` print ""`
` print ""`
` print ""`
` }`

当输入文件的第二个字段等于 `0` 时，awk 会向输出文件打印三个空行。

**注意：** 请注意 `print ""` 会向输出文件打印一个空行，而单独的 `print` 语句会打印当前的输入行。

awk 程序文件中可能包含注释。从 `#` 到行尾的任何输入内容都被视为注释并被 awk 忽略。注释是使用自然语言解释正在发生的情况的说明，而不是计算机语言。

`$ awk -F, '{print $1,$5}' sales`
`John Anderson 42`
`Joe Turner 50`
`Susan Greco 46`
`Bob Burmeister 46`

字段变量之间的逗号（`,`）表示我在输出字段之间应用 `OFS`，正如之前的示例所示。记住，如果没有逗号，字段将在一起。

`awk '{print($1,$1)}'`

## 模式

*模式* 是 awk 程序语句的第一部分。在 awk 中，有六种接受的模式类型。你已经见过其中几种，包括 `BEGIN` 和指定的斜杠分隔模式。awk 具有许多源模式的字符串匹配能力，并在模式中使用正则表达式。范围模式定位一个序列。除了范围模式外的所有模式都可以组合成复合模式。

本节将详细探讨模式匹配的具体含义。你可以匹配什么种模式取决于你具体如何使用模式表示法。

### BEGIN 和 END

两个特殊模式 `BEGIN` 和 `END` 分别用于在读取第一个输入记录之前或读取最后一个输入记录之后指示匹配。某些版本的 awk 要求，如果使用 `BEGIN`，它必须是程序的第一个模式；如果使用 `END`，它必须是程序的最后一个模式。即使你使用的版本不要求，这也是良好的做法。本章中的示例将遵循这一做法。使用 `BEGIN` 模式初始化变量是很常见的（变量也可以从命令行传递给程序；参见“命令行参数”章节）。`END` 模式用于依赖输入的项，例如总计。

如果我想知道一个程序中有多少行，我会输入以下行：

`$ awk 'END {print "Total lines: " NR}' myprogram`

我在显示器上看到 `Total lines: 256`，因此知道文件 `myprogram` 有 256 行。在 awk 处理文件的任何时刻，变量 `NR` 计数到目前读取的记录数。文件末尾的 `NR` 值等于文件中的行数。

你可能会在什么地方看到 `BEGIN` 块？你的想法可能是初始化变量，但如果某个值是数值，它在第一次使用之前会自动初始化为 `0`。相反，你可能正在构建一个数据表并希望有一些列标题。考虑到这一点，这里有一个简单的 awk 脚本可以向你显示计算机上名为 Dave 的人的所有账户：

`BEGIN {`
` FS=":" #记得 passwd 文件使用冒号`
` OFS=" " #我们正在将输出设置为制表符
` print "Account", "Username"`
` }`
`/Dav/ {print $1, $5}`

这是它运行的样子（我将此文件命名为 `daves.awk`，尽管程序匹配 `Dave` 和 `David`）：

`$ awk -f daves.awk /etc/passwd`
`Account Username`
`andrews Dave Andrews`
`d3 David Douglas Dunlap`
`daves Dave Smith`
`taylor Dave Taylor`

注意你还可以通过增加一个每次匹配时增加的变量来轻松获得匹配账户的总数，然后以某种方式在 `END` 块中输出它。这是一种方法：

`BEGIN { FS=":" ; OFS=" " # 输入冒号分隔，输出制表符分隔
` print "Account", "Username"`
` }`
`/Dav/ {print $1, $5 ; matches++ }`
`END {print "A total of " matches " matches."}`

在这里，你可以看到 awk 通过将多个项目放在同一行来缩短程序的长度，这对于初始化特别有用。此外，注意 C 递增符号：`matches++` 功能上

这与 `matches = matches + 1` 和 `matches += 1` 相同。最后，请注意我没有将变量 

`matches` 初始化为 `0`，因为这是 awk 系统自动完成的。

## 表达式

awk 中的任何表达式都可以与任何操作符一起使用。*表达式*由 awk 中的任何操作符及其
对应的以模式匹配语句形式呈现的操作数组成。类型转换——变量在某一点被解释为数字，在另一点被解释为字符串——是自动的，但从不是显式的。所需的操作数类型由运算符类型决定。如果给数值运算符一个字符串操作数，它会被转换，反之亦然。

**提示：** 若要强制转换，如果所需的更改是从字符串到数字，请添加 `(+) 0`。如果你想
显式地将数字转换为字符串，请向变量拼接 `""`（空字符串）。

以下是两个快速示例：`num=3; num=num ""` 创建了一个新的数值变量并将其设置为数字三；通过向其附加空字符串，它被翻译成字符串（包含字符 `3` 的字符串）。对创建的字符串 `str="3"; str=str + 0` 加 `0` 会强制将其变回数值。

任何表达式都可以是模式。如果模式（在此例中为表达式）的值为非零或非空值，则
模式匹配该输入记录。模式通常涉及比较。表 4.1 显示了有效的 awk 比较运算符。

### 表 4.1. awk 中的比较运算符。

| 运算符 | 含义 |
| :--- | :--- |
| `==` | 等于 |
| `<` | 小于 |
| `>` | 大于 |
| `<=` | 小于等于 |
| `>=` | 大于等于 |
| `!=` | 不等于 |
| `~` | 匹配 |
| `!~` | 不匹配 |

在 awk 中，像 C 语言中一样，逻辑相等运算符是 `==` 而不是 `=`。单个 `=` 用于赋值，
而 `==` 用于比较值。当模式是一个比较表达式时，如果比较为真（非空或非零），则模式匹配。这里有一个
例子。如果你只想打印第一字段数值值小于 20 的行呢？方法如下：

`$1 < 20 {print $0}`

如果表达式是算术表达式，则当其求值为非零数字时会被匹配。例如，这里有一个小型
程序，将打印恰好有7个单词的前10行：

`BEGIN {i=0}`
`NF==7 { print $0 ; i++ }`
`i==10 {exit}`

你也可以另一种使用这些比较的方法，因为 awk 理解排序顺序（即单词在标准字典排序中是
比其他单词大还是小）。考虑这样做的情况：你在文件中有一个电话目录（一个经过排序的名称列表），
并且你想打印出所有在公司电话簿中出现在某个人（例如 D. Hughes）之前的名称。你可以通过以下
非常简洁地做到这一点：

`$1 >= "Hughes,D" { exit }`

当模式是字符串时，如果表达式非空，则发生匹配。在之前模式为 `/Ann/` 的例子中，
它被假设为字符串，因为它被斜杠包围。在比较表达式中，如果两个操作数都有数值，则比较是基于数值的。
否则，则将使用字符串排序进行比较，这就是为什么这个简单的例子是有效的。

**提示：** 你可以在 awk 的一行中编写两个以上的比较。

模式 `$2 <= $1` 可能涉及数值比较或字符串比较。无论是哪种，它都会根据文件不同，甚至
根据同一个文件内的不同记录而异。

**提示：** 使用此类模式时要充分熟悉你的输入文件，特别是因为 awk 经常会静地假设变量的类型
并对其处理，而没有错误信息或其他警告。

## 字符串匹配

字符串匹配有三种形式。最简单的是用斜杠（`/`）包围字符串。不使用引号。因此 `/"Ann"/` 
实际上是字符串 `' "Ann" '`，而不是字符串 Ann——且 `/"Ann"/` 不返回任何输入。
如果斜杠内的表达式出现在记录的任何位置，则返回整个输入记录。另外两个匹配运算符具有
更具体的范围。运算符 `~` 意味着“被匹配”，当被测试匹配的输入字段包含右侧的子字符串时，模式匹配。

`$2 ~ /mm/`

此示例匹配第二个字段中任何地方包含 `mm` 的输入记录。它也可以写成 `$2 ~ "mm"`。

另一个运算符 `!~` 意味着“不被匹配”。

`$2 !~ /mm/`

此示例匹配第二个字段中任何地方不包含 `mm` 的输入记录。

掌握了这一解释，你现在可以看到 `/Ann/` 实际上只是更复杂的语句 `$0 ~ /Ann/` 的简写。

正则表达式在 UNIX 中很常见，它们有两种主要形式。你可能已经在命令行中无意识地将它们作为
通配符使用，其中 `\*` 匹配零或多个字符，`?` 匹配任意单个字符。例如，输入下面的第一行
结果会导致命令解释器匹配所有后缀为 `abc` 的文件。正则表达式与 `grep`、`sed` 和其他
编辑器类似，但与 shell 中的通配符有细微不同。`.` 匹配字符，`\*` 匹配零或多个
之前的字符（如果要强制让 `x` 也出现，则需要使用表达式 `xx\*y`）。默认情况下，模式可以出现在
行的任何位置，所以使用 `^` 表示单词的开头，`$` 表示结尾。如果你想匹配所有以 `abc` 结尾的行，例如，可以使用 `$1 ~ /abc$/`。

## Nawk内置变量 (Built-In Variables for Nawk)

当 awk 在 1985 年扩展时，扩展的一部分包括添加更多内置变量。

## Gawk 中的内置变量

GNU 组通过向 gawk 中添加四个新变量进一步增强了 awk（gawk 是 awk 的公开重新实现）。幸运的是，gawk 不同 UNIX 版本之间的差异不像 awk 和 nawk 那么大。这些内置变量是在上一节所述 POSIX 规范之外的额外。变量 `CONVFMT` 包含数字的转换格式。`CONVFMT` 的默认值为 `"%.6g"`，且仅供内部使用。变量 `FIELDWIDTHS` 允许程序员选择固定字段宽度，而不是单个字符字段分隔符。`FIELDWIDTHS` 的值是由空格或制表符 (\t) 分隔的数字，因此字段不需要相同的宽度。当设置了 `FIELDWIDTHS` 变量时，每个字段预期具有固定宽度。Gawk 使用 `FIELDWIDTHS` 值作为字段宽度分隔输入记录。如果设置了 `FIELDWIDTHS`，则忽略 `FS` 的值。为 `FS` 赋值新值将覆盖对 `FIELDWIDTHS` 的使用；恢复默认行为。

为了了解用途，想象你刚刚从财务部门收到一个数据文件，列出了你小组中不同的员工及其年龄。它可能像这样：

`$ cat gawk.datasample`

`1Swensen, Tim 24`
`1Trinkle, Dan 22`
`0Mitchel, Carl 27`

你发现，第一个字符指示员工是时薪还是月薪。值 `1` 表示他们是月薪，值 `0` 指的是时薪。你如何从其余数据字段中分离出该字符？你可以使用 `FIELDWIDTHS` 语句。这里有一个可以美化列出数据的 gawk 脚本：

`BEGIN {FIELDWIDTHS = 1 8 1 4 1 2}`
`{ if ($1 == 1) print "Salaried employee "$2,$4" is "$6" years old.";`
` else print "Hourly employee "$2,$4" is "$6" years old."`
`}`

输出将如下：

`Salaried employee Swensen, Tim is 24 years old.`
`Salaried employee Trinkle, Dan is 22 years old.`

## 循环

人们经常编写程序来执行重复任务或若干个重复任务。这些重复被称为*循环*。循环是本节的主题。awk 的循环结构与 C 语言中发现非常相似。首先，让我们看看逐一计数的快捷方法。然后，我将向你展示在 awk 中编写循环的方法。awk 的循环结构是 `do ` (nawk)、`for,` 和 `while` 语句。与 `if` 语句中的多动作组一样，大括号(`{}`) 包围了循环相关的一组动作语句。如果没有大括号，只有紧跟在关键字后面的语句被视为循环的一部分。

**提示：** 忘记大括号是常见的循环错误。

## 递增和递减

如前所述，赋值语句的形式为 `x = y`，值 `y` 被赋值给 `x`。Aw 有一些这种写法的简写方法。例如，为了将每月销售总额添加到销售文件中，你需要一个变量来保存销售额的运行总和。称之为 `total`。你需要将 `total` 初始化为零并加上销售额。读取时，将 `total` 从零开始并加上 `$(NF-1)`。标准做法写成 `total = total + $(NF-1)`。然而，简写格式 `total += $(NF-1)` 也是接受的。有两种方式来指示 `line+=1` 和 `line -=1`（在 awk 中为 `line-1`）。它们分别被称为递增和递减，并可以进一步简写为 `++line` 和 `line--`。在任何引用变量处，只能使用这种表示法，但取决于在语句在使用之前还是之后操作。这被称为前置和后置表示法，由 `++line` 和 `line++` 表示。先关注递增。递减以相同的方式运行。使用 `++line` 表示法告诉 awk 在行指示的操作之前执行加法。后置形式表示在行执行操作后再加法。有时，选择并不重要；保持人数计数（为了在月底计算平均值）需要一个计数器。但假设我想打印人数、姓名和销售额。根据 `totalpeople=1` 添加下面的行会产生不同的结果：

`$ cat awkscript.v1`

`BEGIN { totalpeople = 1 }`

`{print ++totalpeople, $(NF-1) }`

`$ cat awkscript.v2`

`BEGIN { totalpeople = 1 }`

`{print totalpeople++, $(NF-1) }`

第一个示例实际上会列出第一个员工为2，因为 totalpeople变量在 print 语句中使用之前增加了。相比之下，第二个版本是我们想要的，因为它会使用变量值并在之后增加。awk 提供了 `while` 语句用于通用循环。其格式如下：

`while(E1) S1`

在这里，`E1` 是表达式（条件），`S1` 是单条语句或大括号包围的一组动作语句。当 awk 遇到 `while` 语句时，会评估 `E1`。如果 `E1` 为真，`S1` 从头到尾执行，再次评估 `E1`。如果 `E1` 为真，`S1` 再次执行。该过程持续到 `E1` 被评估为假。此时，执行循环后的下一个动作语句。考虑这个程序：

`{ while ($0~/M/) print }`

通常，条件 (`E1`) 测试一个变量，并在 while 循环中改变该变量。

`{ i=1`
`while (i<20)`
` { print i`
` i++`
` }`

这段第二个代码片段将打印 1 到 19 的数字；在 while 循环测试 i=20 后，`i<20` 的条件变为假，循环结束。

## do 语句

Nawk++ 除了 `while` 语句外还提供了循环的 `do` 语句。`do` 语句采用以下格式：

`do S while E`

在这里，`S` 是单条语句或大括号包围的一组动作语句，`E` 是测试条件。当 awk 到达 `do` 语句时，执行一次 `S` 然后测试条件 `E`。如果 `E` 非零或非空，`S` 再次执行，以此此类推，直到条件 `E` 假。`do` 和 `while` 语句之间的区别在于评估顺序。`while` 语句首先检查条件，如果条件为真则执行循环体。使用 `while` 语句检查可能初始为假的条件。例如，`while (not end-of-file(input))` 是一个常见的示例。`do` 语句首先执行循环然后检查条件。当测试取决于第一次执行满足条件时使用 `do` 语句。你可以使用 `while` 语句启动 `do` 语句。将循环中的代码放在条件之前，也放在循环体中。

## for 语句

`for` 语句是为计数设计的紧凑型 `while` 循环。当你提前知道 `S` 是一个重复任务，且其执行次数可以表示为单个变量时，请使用它。`for` 循环具有以下格式：

`for(pre-loop-statements; TEST; post-loop-statements)`

在这里，`pre-loop-statements` 通常初始化计数变量，`TEST` 是测试条件，`post-loop-statements` 表示任何循环变量的递增。

例如：

`{ for(i=1; i<=30; i++) print i }`

这是一种简洁的写法，表示初始化 `i` 为 1，当 `i<=30` 时继续循环，并且每次将 `i` 增加一个。每次执行的语句只需打印 `i` 的值。该语句的结果是 1 到 30 的数字列表。

**提示：** 条件测试应该是 `< 21` 或 `<=` 20` 以执行循环 20 次。相等运算符 `==` 不是一个好的测试条件。它在第一次检查时为假（或者如果 `i` 初始化为 20，则在不久后为）。

`{ for (i=1; i==20; i++) print i }`

`for` 循环也可以用于处理未知大小的循环：

`for (i=1; i<=NF; i++)`

` print $i`

这会将每个字段打印在单独的一行上。你不知道字段的数量将会是多少，但你知道 `NF` 将包含该数字。

`for` 循环并不非要递增；它也可以是递减：

`awk -F: '{ for (i = NF; i > 0; --i) print $i }' sales.data`

这会按反序打印字段，每行一个。

## 字符串

awk 可以处理两种类型的数据：数值或组成单词、短语或句子的字符数字序列。后者在 awk 以及大多数其他编程语言中被称为*字符串*（strings）。字符串始终包含在双引号（`""`）中。字符串操作之一是*拼接*（concatenation），意思是组合。当你拼接两个字符串时，你会创建第三个字符串，它是第一个字符串紧随第二个字符串的组合。在 awk 中执行拼接，只需在两个字符串之间留一个空格即可，它们几乎可以是任何长度；具体长度取决于版本。

`print "Her name is" "Ann"` 输出：`Her name isAnn.`。（作为一条规则，awk 返回最左侧的最长字符串。为了确保包含空格，请在 `print` 语句中使用逗号，或者简单地在字符串中添加空格：`print "Her name is " "Ann"`）。

## 内置字符串函数

原始 awk `length` 函数返回字符串的长度。如果你使用参数，它必须跟在关键字后面并括在括号内：`length(string)`。如果没有参数，很难从编辑器中确定某行文本是否在 80 个字符处停止。以下 awk 调用通过列出超过 80 个字符的行来帮助：

`awk '{ if (length > 80) { print NR ": " $0}} file-with-long-lines`

原始 awk 可用的另一个字符串函数是 `substr`，格式为 `substr(string, position, len)`，返回从 `position` 开始的 `len` 长度。

## nawk

当 awk 扩展到 nawk 时，增加了许多用于字符串处理的内置函数。`gsub(r, s, t)` 函数在每次出现正则表达式 `r` 时将字符串 `s` 替换到目标字符串 `t` 中并返回替换次数。如果没有给出 `t`，`gsub()` 使用 `$0`。例如，`gsub(//, "Randall")` 将所有内容变为 `Randall`。

`sub(r, s, t)` 函数的作用类似于 `gsub()`，但替换只发生一次。因此，`sub(//, "Randall")` 返回 `Randall`。字符串 `t` 在字符串 `s` 中出现的位置通过函数 `index(s, t)` 返回：`index("i", "Chris")` 返回 `4`。正如你预期的那样，如果没有找到字符串 `t`，返回值为 `0`。

`match(s, r)` 函数返回 `s` 中正则表达式 `r` 出现的位置。它返回子字符串开始的索引，如果没有子字符串则返回 `0`。`split` 函数将字符串分开。例如，如果你的程序读取的日期为 `5-10-94`，而之后你想将其写为 `May 10, 1994`，第一步是适当分割日期。内置函数 `split` 这样做：`split("5-10-94", store, "-")` 分割日期并设置 `store["1"] = "5"`、`store["2"] = "10"` 和 `store["3"] = 94.`。注意这里的下标是从 `"1"`不是 `"0"`。

*数组*是一种在计算机中存储相似数据片段以备以后使用的方法。假设你的老板要求编写程序，读取姓名、社会安全号码等人人员数据以打印支票存根和可拆卸支票。对于三或四个员工，保留 `name1`、`name2` 等可能是行的，但在 20 名员工那里就很繁琐，对于 200 名员工来说是不可能的。这是数组的用途！查看 CD-ROM 上的文件 `LIST15_4` 以了解如何处理此问题的示例。

使用数组比为每个使用的元素列出单独的变量要容易得多、整洁且快速得多。这意味着当元素数量（例如员工）发生变化时，你不需要更改代码。awk 仅支持单维数组。（请参见“高级概念”章节了解如何模拟多维数组。）这一点以及其他几点使得 awk 数组区别于其他编程语言的数组。本节关注数组及其用途、特殊属性，以及帮助你处理数组的 awk 三种特性（一个内置函数、一个内置变量和一个运算符）。

awk 中的数组像变量一样，不需要声明。此外，不需要预先给出大小标示；从编程术语来说说，你可以说 awk 中的数组是动态的。要创建一个数组，给它起一个名称并在名字后的方括号（`[]`）中放入下标，例如不是使用 `name2`，而是使用 `name[2]`。数组下标也称为数组的索引；在 `name[2]` 中，`2` 是数组名称的索引，它访问存储在位置 `2` 的那个名称。

**注意：** awk 的一个特殊之处是元素并不是按照它们输入的顺序存储的。这个 bug 在较新版本中已修复。

awk 数组与其他编程语言的数组不同，因为在 awk 中，数组下标是以字符串存储的，而不是数字。从技术上讲，这个术语是*关联数组*（associative arrays），这在编程语言中是不寻常的。注意，如果你纯从数值角度考虑，使用字符串作为下标可能会让你感到困惑。因为 `"3" > "15"`，下标为 `15` 的数组元素将存储在下标为 `"3"` 的元素之前，尽管在数值上 `3 > 15`。

由于下标是字符串，下标可以是一个字段值。`grade[$1]=$2` 是一个合法的语句，`salary["John"]` 也是。
