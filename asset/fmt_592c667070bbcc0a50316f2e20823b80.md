## 使用 getops 解析命令行参数

`getops` 命令是 Korn shell 内置的。它验证由减号（`-`）或加号（`+`）前的单个字符指定的命令行选项。我们指定命令的开关需要一个参数；如果开关不需要任何参数，则 `:` 应该是空的。所有放入的选项被称为 `OptionString`，其后面跟着一个变量名。每个开关的参数存储在变量 `$OPTARG` 中。如果整个 `OptionString` 前面有一个冒号（即 `::`），那么任何未匹配的开关都会导致 `:` 加载到 `VARIABLE` 中。命令的形式为：

```
getops OptionString VARIABLE { Argument ... }
```

解释此内容的简单方法是使用示例。对于我们的脚本，我们需要秒、分、小时、天和一个要监控的进程。对于这些每一项，我们都希望提供参数——例如 `-s 5 -m10 -p pybackup`。在此处，我们指定了 5 秒、10 分钟，且进程是 `my_backup`。

```bash
SECS=0          # 初始化所有为零
MINUTES=0
HOURS=0
DAYS=0
PROCESS=      # 初始化为空

while getops :s:m:h:d:p TIMED 2>/dev/null
do
  case $TIMED in
    s) SECS=$OPTARG
      ;
    m) (( MINUTES = $OPTARG * 60 ))
      ;
    h) (( HOURS = $OPTARG * 3600 ))
      ;
    d) (( DAYS = $OPTARG * 86400 ))
      ;
    p) PROCESS=$OPTARG
      ;
    \?) usage
      exit 1
      ;
  esac
done
```

## 逐行处理文件的最快方法

大多数 shell 脚本都处理文件，有些使用文件作为数据输入。本节展示了逐行处理文件的两种最快技术。第一种技术是从底部向 **while** 循环提供数据。第二种技术使用文件描述符。

```
function while_read_LINE_bottom
{
while read LINE
do
  echo "$LINE"

done < $FILENAME
}
```

上一个代码中的函数使用了来自 `done` 底部的 **while** 循环。

```
function while_read_LINE_FD
{
exec 3< $FILENAME
while read LINE <&3
do
  echo "$LINE"
done
exec 3-
}
```
