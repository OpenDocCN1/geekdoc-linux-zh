## 4.10 文本模式下的 YaST2 (ncurses)

YaST 也可以通过文本终端进行控制。这对于无法运行 X Window 系统或不需要 X 的系统（如专用服务器或防火墙机器）特别有用。它对于管理员远程访问系统也很有帮助。

### 4.10.1 控制

使用方法可能很陌生，但非常简单。基本上，整个程序可以通过 `Tab`、`Alt` + `Tab`、`Space`、方向键 (`↑`) 和 (`↓`) 以及快捷键来控制。首先出现的是 YaST 控制中心，如图 4.32 所示。

![](img/705a076b108ea96be0c0695efb5556ce_148_0.png)

图 4.32：YaST2 ncurses 的主窗口

左侧框架由粗白色边框包围，显示了各种模块所属的类别。活动类别由彩色背景指示。右侧框架由细白色边框包围，提供了活动类别中包含的模块概览。底部框架包含“帮助”和“退出”按钮。

当启动 YaST 控制中心时，系统会自动选择“软件”类别。使用 (`↓`) 和 (`↑`) 更改类别。要从所选类别启动模块，请按 (`→`)。然后会出现带有粗边框的模块选择。使用 (`↓`) 和 (`↑`) 选择所需的模块。按住方向键可滚动可用模块列表。当选中某个模块时，模块标题将带有彩色背景，并在底部框架中显示简要描述。

按回车键启动所需的模块。模块中的各种按钮或选择字段包含一个不同颜色的字母（默认认为黄色）。按 `Alt`+黄色字母可以直接选择相应的按钮，而无需通过 `Tab` 导航。通过按“退出”或在类别概览中选择“退出”并按回车键退出 YaST 控制中心。

### 4.10.2 键组合的限制

如果您在 X 服务运行时具有系统范围的 Alt 键组合，则 YaST 中的 Alt 组合可能无法工作。此外，Alt 或 Shift 等键可能被终端设置占用。

将 Alt 替换为 Esc：Alt 快捷键可以使用 Esc 代替 Alt 执行。例如，`Esc-H` 替换 `Alt-H`。

将后退和向前导航替换为：可以使用 `Ctrl+F` 和 `Ctrl+B` 替换 Alt 组合。

限制键组合：如果您在 X 服务运行时具有系统范围的 Alt 键组合，则 YaST 中的 Alt 组合可能无法工作。此外，Alt 或 Shift 等键可能被终端设置占用。

## 5.1.2 垃圾箱

垃圾箱是标记为删除的文件的目录。按住鼠标左键将图标从文件管理器或桌面拖到垃圾箱图标上，然后松手即可释放。或者，右键点击图标并选择“移动到垃圾箱”。点击垃圾箱图标可查看其内容。如果需要，您可以从垃圾箱中恢复项目。

使用“删除”键移除的文件不会完全移动到垃圾箱。要完全删除垃圾箱中的文件，请右键点击垃圾箱图标并选择“清空垃圾箱”。

## 5.1.3 CD-ROM、DVD-ROM 和软盘

插入软盘时点击软盘图标，文件管理器将启动并显示软盘的内容。通过右键点击软盘上的单个图标，可以显示包含各种选项的上下文菜单。也可以通过简单按住鼠标左键并拖动到相应位置（如桌面或主目录），将图标移动到不同位置。系统会询问您是想移动、复制软盘还是创建链接。您还可以从主目录复制或移动文件到软盘中。

右键点击软盘图标访问内容菜单。“卸载”（Unmount）是一个非常重要的选项。在移除驱动器之前，务必卸载驱动器，因为这是触发数据实际写入软盘的必要。

CD 和 DVD 的处理方式类似，唯一的区别是这些介质不可写。尽管如此，您必须卸载 CD 和 DVD 驱动器，否则您将无法弹出 CD。您也可以选择“弹出”（Eject），这会导致介质被卸载并弹出。两种方法仅在 CD 或 DVD 不再被访问且任何显示 CD 或 DVD 内容的文件管理器窗口已关闭时才有效。

## 5.1.4 打印机图标

点击桌面上的打印机图标启动 `KPrinter`。该程序允许您直接调整许多设置和打印作业。主窗口上部（如对对页图 5.1 所示）显示所选的打印机并允许选择不同的打印机。点击打印机名称旁的黑色箭头可显示所有可用打印机列表并选择所需的打印机。

要配置所选的打印机，点击“属性”。将打开一个类似于第 138 页图 5.2 所示的配置对话框，允许您更改纸张格式（例如从 A4 到信）或在多个纸盒之间切换。如果其中一个纸盒包含信头纸而另一个纸盒包含白纸，后者尤为有用。
