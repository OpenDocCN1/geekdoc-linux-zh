## 如果你想爬取其他标签而不是 `<title>` 标签怎么办？

```yaml
id: extract-titles
info:
  name: Extract titles
  author: cipher87
  severity: info
  description: Extract titles from web page
  tags: osint,scrap
requests:
  - method: GET
    path:
      - "{{BaseURL}}"
matches:
  - type: regex
    part: body
    regex:
      - '<title>.*'
extractors:
  - type: regex
    part: body
    regex:
      - '<title>.*'
```
