# 附录 9.5：跨进程管道

在该示例中，两个进程创建了管道。生产者进程向管道的写入端写入，消费者进程从管道的读取端读取。在 Win32 中，`spawnlp` 函数用于替代 `fork` 和 `exec`。

## UNIX 示例：跨进程

```c
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int main()
{
    int pipefd[2];
    if (pipe(pipefd) == -1) {
        perror("pipe");
    }
    pid_t pid = fork();
    if (pid == 0) { // 子进程：生产者
        close(pipefd[0]);
        char *msg = "Hello from child process!";
        write(pipefd[1], msg, strlen(msg));
        close(pipefd[1]);
    } else { // 父进程：消费者
        close(pipefd[1]);
        char buffer[BUFSIZE];
        ssize_t bytes_read;
        while ((bytes_read = read(pipefd[0], buffer, BUFSIZE)) > 0) {
            buffer[bytes_read] = '\0';
            printf("Received: %s\n", buffer);
        }
        close(pipefd[0]);
        wait(NULL);
    }
    return 0;
}
```
