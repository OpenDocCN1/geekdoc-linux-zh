关于 `printf` 仍剩下一个话题。`printf` 函数被编写成精确地写入你让它写入的内容——直到你意识到无法从键盘输入可能使用的每一个字符。`awk` 使用与 C 语言相同的转义序列来处理非打印字符。最重要的两个是用于回车的 `\n` 和用于制表符的 `\t`。

**提示：** 有两种方法打印双引号，都不显而易见。一种方法是通过 ASCII 值使用 `printf`：

```awk
doublequote = 34
printf("%c", doublequote)
```

另一种策略是使用反斜杠来转义字符串末尾的双引号：

```awk
printf("\"undoubtedly\" and hurried along.\n")
```

这种方法在大多数版本中均有效。

## 关闭文件和管道

与大多数编程语言不同，`awk` 中没有显式打开的方法；打开文件是隐式的。然而，如果你打算在写入文件后从中读取，则必须关闭文件。假设你在 `awk` 程序中输入了命令 `cat file1 > file2`。在读取 `file2` 之前你必须关闭管道。为此，使用语句 `close("cat file1 > file2")`。

你也可以使用 `getline` 隐式打开文件：

```awk
getline < filename;
```

这用于从文件 `filename` 读取数据。完成文件后，你应该使用 `close(filename)` 命令。

## 命令行参数

正如你可能注意到的，`awk` 为程序员提供了多种实现相同功能的方法。本节关注命令行。你将看到如何从命令行向程序传递参数，以及如何在命令行设置内置变量的值。本节以命令行选项的总结结束。

### 传递命令行参数

命令行参数通过 `awk` 中一个名为 `ARGV` 的内置数组提供，与 C 语言一样。再次遵循 C 的语义，内置变量 `ARGC` 的值比命令行参数少一个。给定命令行 `awk -f programfile infile1`，`ARGC` 的值为 2。`ARGV[0]` 为 `awk`，`ARGV[1]` 为 `infile1`。

**注意：** `ARGV` 的下标从 `0` 开始而不是 `1`。

`programfile` 不被视为参数。没有选项参数。如果命令行中有 `-F`，`ARGV` 也不会包含逗号。注意，这种行为与 C 程序中对 `argv` 和 `argc` 的解释也完全不同。

### 在命令行上设置变量

可以通过说明变量及其值，从命令行将变量值传递给你的 `awk` 程序。例如，对于命令行 `awk -f programfile infile x=1 FS=.`。通常，命令行参数是文件名，但等号表示赋值。这允许变量在读取文件之前之后改变值。例如，当输入来自多个文件时，它们在命令行上的列表顺序变得非常重要，因为第一个命名的输入文件是第一个读取的。考虑命令行 `awk -f program file2 file1` 和这段程序段：

```awk
BEGIN { if (FILENAME != "foo") {
  print "Unexpected input...Abandon ship!"
  exit
 } }
```

程序员编写此程序是为了接受一个文件作为第一个输入，任何其他情况导致程序除了打印错误消息外什么都不做。

```bash
awk -f program x=1 file1 x=2 file2
```
