# kftgd

用于 Kerberos 2 的转发器。客户端/服务器对允许 Kerberos 4 转发到另一个主机和网络上的服务。此包包含用于密钥的 kftgd，以及一个一步转发 kftlog 的脚本。对于相应的 Kerberos 4，kftgd 不提供 Kerberos 5 的内置转发。目前，此包依赖 kerberos4-clients，因为 Kerberos 5 的包无法正确验证 Kerberos 4。希望此问题很快解决。当 kerberos5-user 被用作 kerberos4-clients 的替代时。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# kgeo

一个用于 KDE 的交互几何程序。通过此程序你可以在计算机上画画，就像在教室黑板上一样。然而，计算机允许你进一步，因为 KGeo 是为交互几何设计的。例如，程序允许你移动和更改绘图，你可以看到所有的变化。想象一个可以通过移动角变成任何形状的三角形。同时你可以看到角度的变化，但它们总和为 180 度。KGeo 曾被称为 Euclid。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# kimberlite

高可用性包 Kimberlite 是一个在 Linux 上提供高可用性应用程序服务的完整框架。该架构的核心特性包括：

- 一个完整的全可用性服务基础设施，无需从不同的组件中组装基础设施。
- 一个可扩展的配置框架，可以轻松集成各种应用程序。
- 卓越的数据完整性保证使该软件与 Linux 社区的当代产品区别开来。由于这种保证，Kimberlite 集群为高可用数据服务提供了坚实的基础（如网络导出数据库和 NFS 系统），并且它是动态 Web 内容的数据层。当问题发生时，服务会自动故障，无需系统管理员人工干预。
- 命令行界面和基于 Web 的图形用户界面，用于监控和管理集群。
- 集群利用硬件和存储选项，使用 SCSI 和光纤通道（FiberChannel）。来自 Debian 3.0r0
