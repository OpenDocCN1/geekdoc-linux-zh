# 为什么我不叫它 GNU/UX

在某些领域，认为将该操作系统称为“GNU/Linux”是政治上正确的。“Linux”这个名字的问题在于它没有完全正确的命名方式，因为它是由许多不同的人通过巨大的努力完成的。技术上讲，Linux 是操作系统内核的名称，仅此而已。内核当然是重要的，因为它让操作系统运行，但它不足以构成完整的操作系统。

引入斯尔曼（Stallman），这位天才哲学家创立了自由软件运动，发起了 GNU 项目，编写了第一版 GNU 编译器 (`gcc`)，创建了 GNU 公共许可 (`GPL`) 等。他坚持让你称其为“GNU/”，以反映 GNU 项目的贡献。虽然 GNU 项目先于 Linux 内核，且该贡献非常值得认可，但将它们放在名称中对其他所有贡献者都是不公平的。此外，我认为“Linux/GNU”在技术上更准确，因为内核首先启动，一切运行在其之上。

在流行用法中，“Linux”指的是内核以及典型 Linux 发行版中找到的所有自由开源软件，即整个 Linux 生态系统，而不仅仅是 GNU 组件。操作系统市场倾向于单单词名称，如 DOS、Windows、macOS、Solaris、Irix 和 AI。我选择了流行的格式。然而，如果你更喜欢使用“GNU/Linux”，请在阅读本书时进行心理替换。我不会介。

## 1

什么是 SHE？

![](img/58edd539af3a70704734cedc1ac0c271_35_0.png)

当我们谈论命令行时，我们实际上是在说 shell（外壳）。shell 是一个接收键盘命令并将其传递给操作系统执行的程序。几乎所有的 Linux 发行版都提供一个来自 GNU 项目的 shell 程序，称为 `bash`。这个名字是 borne again shell（再次的 Bourne 外壳）的缩写，指的是 `bash` 是由 Steve Bourne 编写的原始 Unix shell 程序 `sh` 的增强替代版。

## 终端模拟器

在使用图形化用户界面（GUI）时，我们需要另一个名为终端模拟器（terminal emulator）的程序来与 shell 交互。如果我们查看桌面菜单，可能会发现一个。KDE 使用 `konsole`，而 GNOME 使用 `gnome-terminal`，尽管它在你的菜单上可能被简单称为“terminal”（终端）。Linux 许多其他终端模拟器可用，但它们基本上做同样的事情：提供对 shell 的访问。你将根据某个终端模拟器的功能多寡，对其中某一个产生偏好。

## 首次击键

现在，让我们开始吧。启动终端模拟器。一旦它启动，我们应该看到类似的内容：

```
$me@linuxbox-$
```

这被称为 shell 提示符（shell prompt），每当 shell 准备好接受输入时它就会出现。虽然它的外观可能根据发行版有所不同，但它通常包含你的用户名@主机名，后面跟着当前的工作目录（稍后会详细介绍）和一个美元符号。

如果提示符的最后一个字符是 bash 标记 (`#`) 而不是美元符号，则终端会话具有超级用户权限。这意味着我们要么是以 root 用户登录的，要么我们选择了一个提供超级用户（管理）权限的终端模拟器。

假设目前一切正常，让我们尝试输入。在提示符处输入一些乱码，如下所示：

```
[me@linuxbox ~]$ kaekjfaeifj
```

因为这个命令没有意义，shell 告诉了我们并给了我们另一次机会：

```
bash: kaekjfaeifj: command not found
[me@linuxbox ~]$
```

## 命令历史

如果我们按下上方向键，就会看到之前的命令 `kaekjfaeifj` 在提示符后重新出现。这被称为命令历史（command history）。大多数 Linux 发行版默认记住最后 1,000 条命令。按下下方向键，之前的命令就会消失。

## 光标移动

再次按下上方向键找回之前的命令。如果我们尝试左、右箭头，就能看到如何将光标定位在命令行的任何位置。这使得编辑命令变得简单。

> 关于鼠标和焦点的几句话
>
> 虽然 shell 完全完全依靠键盘，但你也可以在终端模拟器中使用鼠标。窗口系统（使 GUI 运行的底层引擎）内置的一种机制提供了一种快速复制和粘贴技术。如果你通过按住鼠标左键并将鼠标拖过文本（或双击）来高亮文本，它就会被复制到窗口系统维护的缓冲区中。按下中间键会将文本粘贴到光标所在的位置。在大多数桌面环境中尝试一下。
>
> 不要诱于在终端窗口内使用 CTRL-C 复制和 CTRL-P 粘贴。它们不起作用的。这些控制代码有不同的含义，并且在微软 Windows 发布很多年前就被分配了。在终端窗口中，请使用 SHIFT-CTRL-C 和 SHIFT-CTRL-V 代替。
>
> 在你的图形化桌面环境中（最可能是 KDE 或 GNOME），为了表现像 Windows，它的焦点策略被设置为“点击获取焦点”。这意味着为了让窗口获得焦点（变为活动状态），你需要点击它。这与传统的窗口系统“焦点跟随鼠标”（focus follows mouse）行为相反，后者意味着只需将鼠标经过窗口窗口即可获得焦点。在你点击它之前，窗口不会到前台，但它将能够接收输入。将焦点策略设置为“焦点跟随鼠标”会让复制粘贴技术更有用。如果你可以的话尝试一下（尽管某些桌面环境不再支持它了）。我想如果你给它一个机会，你会更喜欢它。你可以在窗口管理器的配置程序中找到此设置。

## 修改当前工作目录

要更改我们的工作目录（即我们在树形迷宫中所处的位置），我们使用 `cd` 命令。执行此操作时，输入 `cd`，后跟路径以及目标工作目录的路径名。路径是我们沿着树的分支通往目标目录所走的路线。我们可以通过两种不同的方式指定路径名：绝对路径或相对路径。让我们先来看绝对路径。

## 绝对路径

绝对路径从根目录开始，并逐个沿着树分支延伸，直到完成通往目标目录或文件的路径。例如，我们的系统中有一个目录安装了我们系统的大部分程序。该目录的路径名为 `/usr/bin`。这意味着从根目录（由路径开头的斜杠 `/` 表示）开始有一个名为 `usr` 的目录，其中包含一个名为 `bin` 的目录。

```
[me@linuxbox]$ cd /usr/bin
[me@linux bin]$ pwd
/usr/bin
[me@linux bin]$ ls
Listing of many, many files ...
```

现在我们可以看到已经将当前工作目录更改为 `/usr/bin`，并且里面充满了文件。注意 shell 提示符发生了变化。为了方便起见，它通常被设置为自动显示工作目录的。

## 相对路径

绝对路径从根目录开始并通向目的地，而相对路径则从工作目录开始。执行此操作时，需要使用一些特殊符号来表示文件系统树中的相对位置。这些特殊符号是 `.`（点）和 `..`（点点）。

`.` 符号表示工作目录，`..` 符号表示工作目录的父目录。例如，让我们将工作目录更改为 `/usr/bin`

```
[me@linuxbox]$ cd /usr/bin
[me@linux bin]$ pwd
/usr/bin
```

现在假设我们想将工作目录更改为 `/usr/bin` 的父目录，即 `/usr`。我们可以通过不同的方式实现，比如使用绝对路径：

```
[me@linuxbox bin]$ cd /usr
[me@linuxbox usr]$pwd
/usr
```

或者使用相对路径：

```
[me@linuxbox bin]$ cd ..
[me@linuxbox usr]$pwd
/usr
```

两种不同的方法结果相同。我们应该用哪一个呢？输入字符最少的那个！

同样，我们可以通过两种方式将工作目录从 `/usr` 更改到 `/usr/bin`，比如使用绝对路径：

```
[me@linuxbox usr]$ cd /usr/bin
[me@linuxbox bin]$pwd
/usr/bin
```

或者使用相对路径：

```
[me@linuxbox usr]$ cd ./bin
[me@linuxbox bin]$pwd
/usr/bin
```

现在，这里有一点重要的需要指出。在大多数情况下，我们可以省略 `./`。它是隐含的。输入

```
[me@linuxbox usr]$ cd bin
```

的效果是一样的。通常情况下，如果不对对某物指定路径名，系统将假设为当前工作目录。

## 关于文件名的重要事实

在 Linux 系统上，文件的命名方式与 Windows 等其他系统相似，但存在一些重要的区别。

- 以点开头的文件名是隐藏的。这意味着除非使用 `-a` 参数，否则 `ls` 不会列出它们。当你的账户被创建时，你的家目录中放置了一些隐藏文件，用于配置你的账户设置。在第 11 章中，我们将仔细查看其中一些文件，看看如何自定义你的环境。此外，某些应用程序会将配置和设置文件作为隐藏文件放在你的家目录下。
- Linux 中的文件名和命令像 Unix 一样对大小敏感。文件名 `File1` 和 `file1` 指的是不同的文件。
- Linux 没有某些操作系统那样的“文件扩展名”概念。你可以以任何方式命名文件。文件的内容或用途通过其他手段确定。虽然 Unix 类操作系统不使用文件扩展名来确定文件的内容或用途，但许多应用程序是。
