### 打印帮助页（man pages）有什么好的方法？

你可以通过以下方式在 Laserjet 打印机获取所有字体、行宽和大小：

`zcat manfile.1 | nroff -man -Tlj | lpr (printer)`

要使用 GNU `groff` 获取 PostScript 输出，请执行以下操作：

`zcat manfile.1 | groff -man -Tps | lpr (printer)`

对于带有表格的帮助页，你还需要将输出通过 `tbl`。

此外，某些帮助页可能需要 HP 宏才能打印。例如：

`zcat manfile.1 | groff -t -e -C -M/usr/lib/tmac -man -Tps | lp (printer)`

你也可以通过将输出通过到 `lp` 命令并使用 `-onroff` 选项来打印更粗糙版本的帮助页：

`man <manfile> | lp -onroff`

### 限制核心文件（core files）有什么好的方法？

在标准 shell 中实际上没有方法可以限制核心文件。但如果你知道核心转储可能发生的地方，就有几种变通方法。

一种是在预期发生核心转储的目录中创建一个无权限（`000`）的 `core` 目录。或者你可以在转储发生目录创建一个名为 `core` 的文件并将其链接到 `/dev/null`。

有两个程序可以作为你预期可能产生转储的其它程序的包装器。它们分别是是 `nocore` 和 `corelimit`。

此外，一些公开的 shell（如 `tcsh`）允许你限制核心文件。标准 shell 规则的唯一例外出现在 10.1 及以后的版本，其中 `csh` 允许你限制核心文件。

这里是 `corelimit` 程序的源码。编译它：

```c
#include <stdio.h>
#include <sys/resource.h>
#include <stdlib.h>
#define RLIMIT_CORE
main(int argc, char *argv[]) {
    int res;
    struct rlimit rlp;
    if (argc != 3) {
        fprintf(stderr, "%s: wrong number of arguments\n", argv[0]);
        exit(-1);
    }
    rlp.rlim_cur = atoi(argv[2]);
    res = setrlimit(RLIMIT_CORE, &rlp);
    if (res < 0) {
        perror("setlimit");
        exit(-2);
    }
    system(argv[1]);
}
```
