
添加一个弃用注释，表示此 API 不应再使用（尽管它可能仍然有效）。惯例是描述作为替代方案的 API。例如：

```java
@deprecated Replaced by setBounds(int, int, int,
```

如果该成员已过时且没有替代方案，则 `@deprecated` 的参数应为 No replacement。

```java
@since since-text
```

添加一个“自（since）”条目。该文本没有特殊的内部结构。此标签意味着此更改或功能自 `since-text` 所指定的软件（如 JDK）发布以来一直存在。

```java
@see classname
```

为类添加一个超链接的“参见（See Also）”条目。部分示例包括：

- `@see java.lang.String` `@see String`
- `@see java.lang.Object#wait(int)`
- `@see Character#MAX_RADIX`
- `@see <a href="#spec.html">Java Spec</a>`

使用 `#` 字符将类名与其某个字段、方法或构造函数分开。你可以通过在方法或构造函数名称后包含括号内的参数类型列表来选择多个重载方法或构造函数之一。`@see classname` 中的空格是有意义的。如果有多个参数，请在参数之间使用单个空格。例如：

- `@see java.io.File#File(java.io.Filejava.lang.String)`

一个文档注释可以包含多个 `@see` 标签。

```java
@version version-text
```

添加一个“版本（Version）”条目。该文本没有特殊的内部结构。文档注释只能包含一个 `@version` 标签。`version` 通常指的是包含此功能的软件（如 JDK）的版本。

## 选项

- `-author` `@author` 标签，默认省略。
- `-classpath` 一般情况下，你不应该使用 `-classpath`；请使用 `sourcepath` 来指定源文件的搜索路径。
- `-d directory` 指定 `javadoc` 存储 HTML 文件的目标。该目录可以是绝对路径，也可以相对于当前工作目录。
- `-docencoding name` 指定输出 HTML 编码名称。
- `-encoding name` 指定源文件编码，例如 EUC-SJIS。如果不指定此选项，使用平台默认转换器。
- `-J flag` 将标志直接传递给运行时。例如，如果你需要确保系统设置 32 MB 内存来存放生成的文档，请如下使用 `-J`：
- `-deprecated` 排除带有 `@deprecated` 标签的段落。请注意 `-doctype` 选项已不再可用。只能生成 HTML 文档。

# javadoc

## javadoc

指定一个包含 `String.java` 类的对应目录作为源路径。

```
castle$% javadoc -sourcepath/myapp/src/share/java/lang
```

如果你先切换到原本要指定的目录，可以省略 `-sourcepath` 选项。

- `-verbose` 打印额外的信息，说明解析每个源文件所花费的毫秒数。如果不使用 verbose 输出，则仅显示加载源文件、生成文档（每个源文件显示一条消息）和排序的消息。

- `-version` 包含 `@version` 标签（默认省略）。

## 示例

每个包名都有一个对应的目录名。在以下示例中，源文件位于 `/home/ws/src/java/awt/*.java`。目标目录为 `/home/ws/html`。

### 一个或多个包

对于包级级文档，该包的源文件（`*.java`）必须位于与包名同名的目录中。如果一个包由多个标识符（用点分隔）组成，则每个标识符代表一个不同的目录。因此，所有的 `java.awt` 类必须位于名为 `java/awt/` 的目录中。

首先，切换到最顶级包的父目录（或提供该目录的 `-sourcepath` 选项）。然后运行 `javadoc`，提供一个或多个完全限定的包名。例如，以下命令将为 `java.awt /home/ws/src/java/awt/*.java` 及其子包 `java.awt.event` 的源文件生成文档。

```
castle$% cd /home/ws/src
castle$% javadoc -d /home/ws/html java.awt java.awt.event
```

### 一个或多个类

为一个或多个类生成文档，切换到包含该类的目录（或提供该目录的 `-sourcepath` 选项）。然后运行 `javadoc`，如所示提供一个或多个类名。

```
castle$% cd /home/ws/src/java/awt
castle$% javadoc -d /home/ws/html Button.java Canvas.java
```
