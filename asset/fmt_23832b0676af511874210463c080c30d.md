当力的作用方向与运动方向相同时，功为正值；此时说功是由施力者施加在运动物体上的。当力的作用方向与施力者的方向相反时，功为负；此时功是作用于施力者和运动物体的。从角度来看，做正功是向物体流失能量，而做负功则是从物体处获得能量。

# 锻铁 (Wrought iron)

根据美国材料试验协会的定义，这是一种铁质，由高度精炼金属铁颗粒的凝固聚集，含有碳和精炼过程中氧化反应产生的均匀分布的硅酸盐渣，在不同类型的最终产品中含量于 1% 到 3% 之间。它主要与钢中存在的类金属元素之间的关系呈机械关联。

锻铁的一个显著特征是具有破碎或不规则的断口，与铁质或结晶体断口形成对比。

纤锌矿是一种成分为 ZnS（硫化锌）的矿物。它以纤维状或柱状聚集体形式存在，莫氏硬度为 3 1/2。它是同质异体，可结晶为高温形式纤锌矿 (α-ZnS) 和低温形式闪锌矿 (β-ZnS)，后者在室温下形成是更稳定的形式，与闪锌矿不同，它很少作为锌矿石出现。纤锌矿通常含有铁和镉，并以固溶体系列的形式存在于绿胶矿 (Cd) 中。见 绿胶矿 (GREENOCK)、闪锌矿 (SPHALITE)。

纤锌矿是一种黑色物质，密度约为 1.05，由 79–80% 的碳、10.5–12.5% 的氢、4–6% 的硫、1.8–2% 的氮和氧组成。它源自绿河。见 石青 (ASPHALITE) 和闪铁矿 (PHALERITE)、辉铁矿 (ESPONITE)。

# X 射线天文学 (X-ray astronomy)

对类星源射线射线的研究涉及从恒星到星系的几乎所有类型的天体。电磁光谱范围从数百到几十公里的波长延伸到极高能量（1 nm 到约 100 keV）。X 射线天文学传统上根据光子的能量分为宽带——软能和硬能。软射线（10 keV 以下）必须在大气层以上通过火箭或卫星进行观测，而硬射线观测可以在地面进行。磁辐射 (MAGNETIC RADIATION)；火箭天文学 (ROCKET ASTRONOMY)；卫星天文学 (SATELLITE ASTRONOMY)；X 射线 (X-RAYS)。

观测必须位于软能带。如 ROSAT X 射线调查探测到了数千个源，灵敏度约为最亮源强度的 1/100,000。见 X-1。源中的一些位于银河系。银系对应位于银河内，包含了大部分源和螺旋臂。外 X 射线源遍布圆盘，许多具有独立的星团、星系和类星体。见 银河 (Milky Way)。

银河系 X 射线源已识别为不同类型的物体。

虽然第一个是与天体识别的 X 射线源——恒星爆炸留下的超新星遗迹——其他还包括中心的中子星以及热气体和高能粒子簇。我们银河系 10% 的 X 射线发射来自这些遗迹。已探测许多其他超新星遗迹，在邻星系中也探测到了超新星。见 星云 (STAR NEBULA)；创星云 (CREATION NEBULA)；中子星 (NEUTRON STAR)；脉冲星 (PULSAR)；超新星 (SUPERNOVA)。

云源在银河中发射 X 射线，大部分亮度位于软能带。X 射线星在电磁范围内发现了了物体。这些被称为 X 射线星，通常是双星系统。X 射线和光学数据的结合得出结论，这些系统是由环绕另一个物体运行引力轨道的质量较大的恒星引起的。X 射线星可能是坍缩天体，例如白矮星、中子星甚至是黑洞。

这些系统中 X 射线发射的理论模型由物质从普通恒星落向致密物体组成。这一过程被称为吸积，通常会导致致密物体表面产生炽热大气层。在坠落过程中，物质达到极高温度，引力能转化为热量并以 X 射线形式发出。人们认为无论致密物体是白矮星、中子星还是黑洞，都涉及这些过程。然而，每种物体预计会有不同类型的细节。旋转的中子星导致 X 射线脉冲星。对于白矮星，几小时到几天的 X 射线通量变化可能表明吸积物质聚集表面的变化，以及热核反应能量的爆发。在黑洞的情况下，极短时间尺度上的表面活动可能指示较小的 X 射线发射值。

另一种发射由所谓的短脉冲簇或亮度增加的闪烁表示，伴有爆发。这些可能在与恒星形成相关的 X 射线过程中被探测。见 宇宙变星 (COSMIC VARIABLE)；恒星演化 (STELLAR EVOLUTION)；白矮星 (WHITE DWARF)。

星系外源。在最有趣的物体类型中是活动星系核 (AGN)，它们是强大的星系。

在活动星核中（具有强光谱线和窄连续谱），X 射线发射比普通星系大出几个数量级。发射来自星系核，由一个中心物体驱动，因为在目前几秒的观测极限下缺乏尺寸和变异性。许多天体物理学家认为星系核是质量为太阳百万倍的大质量黑洞中心，该物体由坠落释放的引力能量驱动。

属性范围如 X 射线亮度，从赛弗特星系到类星体不等。许多属性取决于观测者的视角，以及黑洞的大小。

星系团是由数百个独立星系组成的集合，形成一个引力束缚系统。

此类星系中星系间的气体足够热形成 10^7 K 的 X 射线发光气体，其质量等于或超过可见星系。见 天体物理学 (ASTROPHYSICS)；高密度 (HIGH-DENSITY)；星系 (GALAXY)；演化 (EVOLUTION)。
