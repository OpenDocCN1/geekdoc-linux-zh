## 使用 WHILE/UNTIL

![](img/0cf46e6370424e4fc9bc72ba090b1e02_406_0.png)

在上一章中，我们开发了一个菜单驱动的程序来生成各种系统信息。该程序可以工作，但它仍然有一个重大的易用性问题。它只执行单次选择然后终止。更糟糕的是，如果选择了无效选项，程序将因错误终止，而没有给用户再次尝试的机会。如果我们通过某种方式构建程序，使其能够不断重复菜单显示和选择，直到用户选择退出程序，效果会更好。

在本章中，我们将学习一种称为“循环”的编程概念，它可以让程序的某些重复。`shell` 提供了三种用于循环的复合命令。我们将在本章介绍其中两个，第三个将在后面的章节中介绍。

# 循环

日常生活充满了重复的活动。每天上班、遛狗和切胡萝卜都是涉及重复一系列步骤的任务。让我们考虑切胡萝卜。如果我们用伪代码来表示这种活动，它可能像这样：

1. 获取菜板。
2. 获取刀。
3. 将胡萝卜放在菜板上。
4. 拿起刀。
5. 推进胡萝卜。
6. 切胡萝卜。
7. 如果整根胡萝卜都切完，则退出；否则回到第 4 步。

步骤 4 到步骤 7 组成了一个循环。循环内的动作将一直重复，直到达到“整根胡萝卜切完”这一条件。

# while

`bash` 可以表达类似的思想。假设我们想按顺序从 1 到 5 显示五个数字。一个 `bash` 脚本可以如下构建：

```bash
#!/bin/bash

# while-count: 显示一系列数字

count=1

while [[ "$count" -le 5 ]]; do

  echo "$count"

  count=$((count + 1))

done

echo "Finished."
```

> 执行时，此脚本会显示以下内容：

```bash
[me@linuxbox ~]$ while-count

1

2

3

4

5

Finished.
```

> `while` 命令的语法如下：

```bash
while commands; do commands; done
```

就像 `if` 一样，`while` 会评估命令列表的退出状态。只要退出状态为零，就会执行循环内部的命令。在上一个脚本中，变量 `count` 被创建并赋予了初始值 1。只要退出状态为零，循环内的命令就会执行。当 `count` 增加到 6 后，退出状态不再为零，循环终止。在 `while` 循环中，命令会重复执行。当循环结束时，执行循环后面的语句。

我们使用 `while` 循环来改进上一章的程序。
