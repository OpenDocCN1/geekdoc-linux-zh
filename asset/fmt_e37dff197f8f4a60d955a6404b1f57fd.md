
1. **打开 httpd.conf 文件**：使用以下命令打开配置文件：`sudo nano /etc/httpd/conf/httpd.conf`。

2. **添加指令**：滚动到文件末尾（或在 `LogLevel` 指令附近的合适的全局设置部分），添加以下行：

   - `ServerTokens Prod`
   - `ServerSignature Off`

   其中：
   - `ServerTokens Prod`：这将使 HTTP 头中仅显示服务器名称（例如 “Apache”）。
   - `ServerSignature Off`：这将禁用错误页面上的页脚。

3. **保存并关闭文件**：添加指令后，在 nano 中按 `Ctrl+O` 保存，然后按 `Ctrl+X` 退出。

重启 Apache：更改后重启 Apache：`systemctl restart httpd`。

## 步骤 5：配置 Apache 安全头部

HTTP 安全头部可以保护服务器免受几种常见漏洞，例如点击劫持、XSS（跨站脚本攻击）和其他攻击。我们可以在 Apache 的虚拟主机配置中配置这些标头。

1. 打开网站的配置文件（例如 `/etc/httpd/conf.d/example.com.conf`）：`sudo nano /etc/httpd/conf.d/example.com.conf`。

2. 在当前文件的开头添加以下指令以启用安全标头：

```apache
# Add security headers
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "SAMEORIGIN"
Header always set X-XSS-Protection "1; mode=block"
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
Header always set Content-Security-Policy "default-src 'self'; script-src 'self';"
```

这些标头提供了如下保护：

- `X-Content-Type-Options`：防止浏览器将文件解释为其他类型。
- `X-Frame-Options`：防止网站被嵌入到 iframe 中以避免点击劫持。
- `Strict-Transport-Security`：强制对网站使用安全（HTTPS）连接。
- `Content-Security-Policy`：定义允许加载内容的源（有助于防止 XSS）。

3. 保存文件并重启 Apache：`sudo systemctl restart httpd`

## 步骤 6：限制敏感文件和目录的访问

Apache 配置中的某些目录和文件不应被公开访问，例如 `.htaccess` 文件和服务器配置文件。使用 Apache 的 `Require` 指令来限制这些文件的访问。

要限制 Rocky Linux 上 Apache 敏感文件和目录的访问，我们应该在 Apache 配置文件中添加必要的指令。可以按照以下步骤完成：

1. 找到 Apache 配置文件：在 Rocky Linux 上，Apache 的主配置文件通常位于 `/etc/httpd/conf/httpd.conf`。额外的配置文件通常可以在 `/etc/httpd/conf.d/` 目录下找到。

2. 编辑适当的配置文件：建议在主配置文件（`httpd.conf`）或位于 `/etc/httpd/conf.d/` 下的特定虚拟主机配置文件中添加安全指令。这种方法可以确保根据需要将指令应用于全局或特定的虚拟主机。

3. 添加访问限制指令：在所选的配置文件中添加以下指令以拒绝对 `.conf`、`.log` 和 `phpinfo.php` 文件的访问。在此之后任何其他更改都将被忽略，我们将继续本节的步骤。

```apache
sudo nano /etc/httpd/conf/httpd.conf
<Directory "/var/www/html">
  <Files "*.conf">
    Require all denied
  </Files>
  <Files "*.log">
    Require all denied
  </Files>
  <Files "phpinfo.php">
    Require all denied
  </Files>
</Directory>
```

此配置指定了任何对 `/var/www/html` 目录内匹配 `*.conf`、`*.log` 或 `phpinfo.php` 模式文件的请求都将被拒绝。

4. 保存并退出编辑器：添加指令后，保存更改并退出文本编辑器。

5. 测试 Apache 配置：在重启 Apache 之前，测试配置是否存在语法错误是重要的：`sudo apachectl configtest`。

如果输出为 `Syntax OK`，请继续下一步。

6. 重启 Apache 以应用更改：

要应用更改，请重启 Apache 服务：`sudo systemctl restart httpd`

7. 验证限制情况：重启 Apache 后，尝试通过浏览器访问指定的文件，以验证访问是否被拒绝。尝试访问这些文件时，我们应该收到 403 Forbidden 错误。

## 注意事项

- *备份配置文件*：在进行更改之前，务必备份 Apache 配置文件，以防止潜在的配置错误。

- *使用 `.htaccess` 文件*：虽然可以使用 `.htaccess` 文件覆盖全局设置，但将这些指令直接放在主配置文件效率更高，特别是当我们有权限访问它们时。

- *测试*：在应用这些更改后，彻底测试 Web 服务器，以确保合法访问不会被意外拦截。

通过遵循这些步骤，我们可以有效地限制 Apache Web 服务器上敏感文件和目录的访问，增强其安全性。

## 步骤 7：使用强密码和安全认证

如果 Web 服务器使用身份验证，使用强密码至关重要。对于 Apache，我们可以：

1. 安装 `httpd-tools` 包（如果尚未安装）：

```bash
sudo dnf install httpd-tools
```

2. 创建密码文件：

```bash
sudo htpasswd -c /etc/httpd/.htpasswd username
```

3. 编辑配置以保护所需的目录：`sudo nano /etc/httpd/conf/httpd.conf`

```apache
<Directory "/var/www/protected">
  AuthType Basic
  AuthName "Restricted"
  AuthUserFile /etc/httpd/.htpasswd
  Require valid-user
</Directory>
```
