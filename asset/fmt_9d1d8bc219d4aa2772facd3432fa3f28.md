> `echo $x` 和 `echo "$x"` 会产生不同的结果
引用变量会保留空格

```bash
[manju@localhost ~]$ let x=20+7; echo "The value of \"$x\" is $x.\nThe value of \"$x\" is 27."
[manju@localhost ~]$ x=100; let "x += 1"; echo "x = $x"
```

```
x = 101
```

```bash
[manju@localhost ~]$ x="a+b+c"; IFS=$; $x
```

```
ab b c
```
"+" 号将被解释为分隔符

```bash
[manju@localhost ~]$ x="a-b-c"; IFS=-; $x
```

```
ab b c
```
"-" 号将被解释为分隔符

```bash
[manju@localhost ~]$ x="a,b,c"; IFS=$; $x
```

```
ab b c
```
