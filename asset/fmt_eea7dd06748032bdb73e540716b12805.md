## 19.1.2 使用 Chisel 实现 HTTP 隧道

上述场景是 Chisel 的完美用，Chisel 是一种 HTTP 隧道工具，它通过 HTTP 封装我们的数据流。它还在隧道内部使用 SSH 协议，因此我们的数据将是加密。
