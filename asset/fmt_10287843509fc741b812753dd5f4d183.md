
### 进程优先级

Linux 为每个进程分配一个优先级，这决定了它对 CPU 时间的份额。`nice` 命令允许你设置进程的优先级。较低的优先级值使进程更有利，而较高的值则较不有利。

要提高进程的优先级（降低 nice 值）：

```
$ nice -n -10 command
```

要降低进程的优先级（提高 nice 值）：

```
$ nice -n 10 command
```

### 后台执行与前台执行

默认情况下，当你在终端运行一个命令时，它在前台运行，你可以看到它的输出。但是，通过在命令后添加 ampersand（`&`），你可以在后台启动进程：

```
$ command &
```

这允许你在进程在后台运行的同时继续使用终端。

### 结论

进程管理是 Linux 用户和管理员的一项关键技能。理解如何查看、控制和优先处理进程，可以帮助你优化系统性能、排除故障并高效地管理 Linux 系统上的任务。本节介绍的命令和技术只是你开启 Linux 进程管理之旅的起点。随着你越来越熟悉这些概念，你将能够更好地处理涉及你 Linux 系统中进程的复杂任务和场景。

## 第 4 章：网络与连接

## 4.1. 理解 Linux 网络

网络化是现代计算的一个基础方面，Linux 为个人和企业级使用都提供了强大的网络能力。在本节中，我们将探索 Linux 网络的基础知识，包括其架构、网络接口和关键概念。

### Linux 网络架构

Linux 网络构建在分层架构之上，符合符合 OSI（开放系统互连）模型。Linux 网络架构的关键层包括：

- 1. **物理层（第 1 层）**：该层处理实际硬件，包括网线、交换机和网络接口卡（`NIC`）。

- 2. **数据链路（第 2 层）**：在这里，数据被组织成帧，同一网络上的设备可以使用 `MAC`（媒体访问控制）地址进行通信。

- 3. **网络层（第 3 层）**：该层负责在不同网络之间路由和转发数据包。`IP`（互联网协议）在此层运行。

- 4. **传输层（第 4 层）**：它管理端到端通信，确保数据的完整性和可靠交付。`TCP`（传输控制协议）和 `UDP`（用户数据报协议）等协议在此运行。

- 5. **应用层（第 7 层）**：该层包含了各种应用程序协议，能够实现特定的网络服务，如 `HTTP`、`FTP` 和 `SSH`。

### 网络接口

网络接口通常称为 `NIC` 或网卡，是负责将计算机连接到网络的硬件或虚拟设备。Linux 识别并管理这些接口。你可以使用 `ifconfig` 或 `ip` 命令查看系统的网络接口列表：

```
$ ifconfig
```

```
$ ip link
```

### IP 地址分配

`IP` 地址分配是网络中的一个重要概念。`IP` 地址唯一地标识网络上的设备。在 Linux 中，你可以手动为网络接口配置 `IP` 地址，或使用 `DHCP`（动态主机配置协议）从 `DHCP` 服务器自动获取 `IP` 地址。

要手动为接口设置 `IP` 地址，可以使用 `ifconfig` 或 `ip` 命令：

```
$ sudo ifconfig eth0 192.168.1.100
```

```
$ sudo ip addr add 192.168.1.100/24 dev eth0
```

### 路由与网关

Linux 使用路由表来确定数据包到达目的地应采取的路径。`route` 或 `ip route` 命令允许你查看和操作路由表。

添加默认网关：

```
$ sudo route add default gw 192.168.1.1
```

```
$ sudo ip route add default via 192.168.1.1
```

### DNS 与域名解析

`DNS`（域名系统）负责将人类可读的域名转换为 `IP` 地址。Linux 系统依赖 `DNS` 服务器来解析域名。你可以在 `/etc/resol.conf` 中配置 `DNS` 设置。

### 结论

理解网络基础对于有效利用资源至关重要。在本节中，我们向你介绍了 Linux 网络架构基础、网络接口、`IP` 地址分配、路由、网关和 `DNS`。这些基础概念为进一步探索 Linux 网络任务提供了良好的起点。

## 4.2. 配置网络接口

配置网络接口是 Linux 中的一项基础任务，因为它使你的能够通过网络进行通信。在本节中，我们将探索如何在 Linux 环境中配置和管理有线和无线网络接口。

### 网络接口名称

Linux 使用可预测的网络接口名称，设计用于更容易识别和管理网络接口。命名习惯通常包括以太网的 `eth` 和无线接口的 `wlan`，后面跟一个数字。

你可以使用 `ip` 命令查看系统的网络接口名称：

```
$ ip link
```

### 配置有线以太网接口

配置有线以太网接口可以使用 `ifconfig` 或 `ip` 等工具。例如，为名为 `eth0` 的接口分配静态 `IP` 地址：

```
$ sudo ifconfig eth0 192.168.1.100
```

```
$ sudo ip addr add 192.168.1.100/24 dev eth0
```

通过 `DHCP` 自动为有线以太网接口配置 `IP` 地址：

```
$ sudo dhclient eth0
```

### 配置无线接口

配置无线接口与有线接口类似，但你需要考虑特定的无线设置，如 `SSID`。可以使用 `iw` 和 `wpa_supplicant` 工具进行无线配置。

列出可用无线网络：

```
$ sudo iwlist wlan0 scan
```

使用 `wpa_supplicant` 连接到无线网络：

```
$ sudo wpa_supplicant -B -i wlan0 -c
/etc/wpa_supplicant/wpa_supplicant.conf
```

### 网络配置文件

网络配置文件在设置和管理网络接口方面起着关键作用。在大多数 Linux 发行版中，你可以在 `/etc/network/` 或 `/etc/sysconfig/network-scripts/` 目录下找到这些配置文件。

对于有线以太网接口，你通常可以找到 `/etc/network/interfaces` 或 `/etc/sysconfig/network-scripts/ifcfg-eth0` 等配置文件。

对于无线接口，你可能有 `/etc/wpa_supplicant/wpa_supplicant.conf` 等配置文件用于存储无线网络凭据。

许多 Linux 发行版使用 `NetworkManager` 作为管理网络接口的高级工具。`NetworkManager` 图形化界面和命令行工具（`nmcli` 和 `nmtui`），用于管理有线和无线连接。

要启动 `NetworkManager` 服务：

```
$ sudo systemctl start NetworkManager
```

使用 `nmcli` 配置连接，可以使用 `nmcli con add` 和 `nmcli con up` 等命令。例如：

```
$ sudo nmcli con add type ethernet ifname eth0
```

```
$ sudo nmcli con up "Wired connection 1"
```

### 结论

配置网络接口是 Linux 用户和管理员的一项基础技能。无论你是在设置服务器、连接无线网络还是配置网络设备，理解如何管理网络接口都是至关重要的。在本节中，我们探索了配置有线和无线接口的基础知识，包括使用 `ifconfig`、`ip`、`wpa_supplicant` 和 `NetworkManager` 等命令行工具。随着经验的增加，你将能够处理更复杂的网络场景，并微调你的网络配置以满足特定需求。

## 4.3. 使用 SSH 进行安全远程访问

`SSH`（`Secure Shell`）是一种广泛用于 Linux 系统安全远程访问的协议。它在网络上提供加密通信，允许你安全地登录远程服务器或在远程机器上执行命令。在本节中，我们将探索如何在 Linux 中设置和使用 `SSH` 进行安全远程访问。

### SSH 基础

`SSH` 使用公钥加密法来验证用户身份并加密通过网络传输的数据。它同时使用私钥（仅限用户已知）和公钥（与服务器共享）进行安全身份验证。

### SSH 服务器和客户端

要使用 `SSH`，你需要一个 `SSH` 服务器（运行在远程系统上）和一个 `SSH` 客户端（在你的本地机器上）。大多数 Linux 发行版默认安装了 `SSH` 服务器，如果不存在，你可以安装 `SSH` 客户端。

### 连接到远程服务器

要使用 `SSH` 连接到远程服务器，你可以使用 `ssh` 命令后跟远程机器的用户名和主机名（或 `IP` 地址）：

```
$ ssh username@hostname_or_IP
```

例如：

```
$ ssh john@192.168.1.100
```

### 密码认证 vs 密钥认证

`SSH` 支持两种主要的认证方法：基于密码的认证和基于密钥的认证。

- **密码认证**：这种方法要求你每次连接远程服务器时输入密码。它比基于密钥的认证安全性低，因为它容易受到密码暴力破解攻击。
