# 为什么我应该创建一个用户账户？

您应该创建一个用户账户来执行日常任务。root 账户仅用于管理和维护任务，因为在使用 root 账户时可能会损坏您的计算机。

如果您计划与家庭成员或同事共享您的计算机，可以为每个人创建一个用户账户，这样他们就拥有了自身的个性化设置。
