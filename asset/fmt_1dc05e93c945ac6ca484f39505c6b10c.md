## 在 `check_password()` 中添加一个无效字节以破坏 GDB

```c
char* calc_addr(char* p_addr)
{
    return p_addr + 0x040000;
}

{
    char pass[password_size] = {};
    char* label_address = 0;
}

    "jmp unaligned\n"
    ".short 0xe8\n"
```
