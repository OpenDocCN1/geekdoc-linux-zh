
# 事件

`parent` 成员设置为父窗口。`window` 成员设置为要映射的窗口。

## ResizeRequest 事件

X 服务器可以向想要另一个客户端更改窗口大小属性信息的客户端发送 `ResizeRequest` 事件。每当另一个客户端尝试通过 `XConfigureWindow`、`XResizeWindow` 或 `XResizeWindow` 更改窗口大时，X 服务器就会生成此事件。

要接收 `ResizeRequest` 事件，请在窗口的 `event-mask` 属性中设置 `ResizeRedirect` 位。随后，其他客户端更改大小的尝试将被重定向。

此类型的事件结构包含：

```c
typedef struct {
    int type;        /* ResizeRequest */
    unsigned long serial;     /* # of last request processed by server */
    Bool send_event;    /* true if this came from a SendEvent request */
    Display display;      /* Display the event was read from */
    Window window;
    int width,height;
} XResizeRequestEvent;
```

`window` 成员设置为请求更改的窗口。`width` 和 `height` 成员设置为窗口的内部尺寸，不包括边框。

## ColormapNotify 事件

要接收 `ColormapNotify` 事件，请设置窗口的 `event-mask` 属性中的 `ColormapChangeMask` 位。

该事件类型的结构包含：

```c
typedef struct {
    int type;               /* ColormapNotify */
    unsigned long serial;  /* # of last request processed by server */
    Bool send_event;       /* true if this came from a SendEvent request */
    Display display;        /* Display the event was read from */
    Window window;
    Colormap colormap;     /* colormap or None */
    Bool new;
    int state;             /* ColormapInstalled, ColormapUninstalled */
} ColormapEvent;
```

`window` 成员被设置为关联调色板发生改变、安装或卸载的窗口。对于发生改变的调色板，`colormap` 被设置为与窗口关联的调色板。对于通过调用 `XFreeColormap` 改变的调色板，`colormap` 被设置为 `None`。`new` 成员用于指示指定窗口的调色板是被改变、安装还是卸载，其值可以 `True` 或 `False`。如果是 `True`，则调色板被改变；如果是 `False`，则调色板被安装或卸载。`state` 成员始终被设置为指示调色板是 `ColormapInstalled` 还是 `ColormapUninstalled`。

## 客户端通信事件

本节讨论了：

- `ClientMessage` 事件
- `PropertyNotify` 事件
- `SelectionClear` 事件
- `SelectionNotify` 事件
- `SelectionRequest` 事件

### ClientMessage 事件

只有当客户端调用 `XSendEvent` 函数时，X 服务端才会生成 `ClientMessage` 事件。

该事件类型的结构包含：

```c
typedef struct {
    int             type;           /* ClientMessage */
    unsigned long serial;      /* # of last request processed by server */
    Bool            send_event;     /* true if this came from a SendEvent request */
    Display         display;       /* Display the event was read from */
    Window          window;
    Atom            message_type;
    union {
        char b[20];
        short s[10];
        long l[5];
    } data;
} XClientMessageEvent;
```

`message_type` 成员被设置为一个原子（`atom`），指示接收客户端应如何解释数据。`format` 成员为 8、16 或 32，并指定数据应被视为字节、短整数（`short`）或长整数（`long`）列表。`data` 成员是一个包含 `b`、`s` 和 `l` 成员的原子。`b`、`s` 和 `l` 成员分别代表 8 位、16 位和 32 位的值。特定的消息类型可能不会使用所有这些值。服务端对 `window`、`message_type` 或 `data` 成员中的值不进行任何解释。

### PropertyNotify 事件

X 服务端可以向想要特定窗口属性变化信息的客户端报告 `PropertyNotify` 事件。

要接收 `PropertyNotify` 事件，请设置窗口 `event-attribute` 中的 `PropertyChangeMask` 位。

该事件类型的结构包含：

```c
typedef struct {
    int             type;           /* PropertyNotify */
    unsigned long serial;      /* # of last request processed by server * */
    Bool            send_event;     /* true if this came from a SendEvent request */
    Display         display;       /* Display the event was read from */
    Window          window;
    Atom atom;
    Time time;
    int             state;          /* PropertyNewValue or PropertyDelete */
} XPropertyEvent;
```

`window` 成员被设置为关联属性发生改变的窗口。`atom` 成员被设置为属性的原子，并指示哪个属性被改变或被请求。`time` 成员被设置为属性改变时的服务端时间。`state` 成员被设置为指示属性是被改变了新值还是被删除，其值可以为 `PropertyNew` 或 `PropertyDelete`。当使用 `XChangeProperty` 或 `XRotateWindowProperties` 窗口属性（即使使用 `XChangeProperty` 使用零长度数据），以及当使用 `XChangeProperty` 或 `XRotateWindowProperties` 用相同数据替换属性的全部或部分时，`state` 成员被设置为 `PropertyNew`。当使用 `XDeleteProperty` 删除窗口属性，或者当删除参数 `delete` 为 `True` 时调用 `XGetWindowProperty` 时，`state` 成员被设置为 `PropertyDelete`。

### SelectionClear 事件

X 服务端向请求选择所有权的客户端报告 `SelectionClear` 事件。当另一个客户端通过调用 `XSetSelectionOwner` 断言该选择的所有权时，X 服务端生成此事件。

该事件类型的结构包含：

```c
typedef struct {
    int             type;        /* SelectionClear */
    unsigned long serial;      /* # of last request processed by server */
```
