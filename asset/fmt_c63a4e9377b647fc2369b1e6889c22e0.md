### 关于示例 1 中使用的命令的说明：

```bash
# s $string_1_OLD/$string_1_NEW/substitute
# g 表示全局（如果字符串在行中出现多次，
# 则该字符串的所有出现处都会被更改，
# 而不仅仅是第一次。如果没有在命令末
# 加上 'g$，只有 $string_1_OLD 的第一次
# 会更改为 $string_1_NEW)。
```

```bash

# 这两个命令的作用相同：'Snickers' 的所有出现处
# 将被更改为 'Milky Way'。
### 注意结束。
```
