
#### 总结

通过添加位置参数，我们现在可以编写功能相当完善的脚本。对于简单、重复的任务，位置参数使得可以编写非常有用的 shell 函数，并将其放置在用户的 `.bashrc` 文件中。

我们的 `sys_info_page` 程序在复杂性和精细程度上有所增长。以下是完整列表，其中最近的更改已突出显示：

```bash
#!/bin/bash

# sys_info_page: program to output a system information page

PROGNAME=$(basename $0)
TITLE="System Information Report For $HOSTNAME"
CURRENT_TIME=$(date "+%x %r %Z")
TIME_STAMP="Generated $CURRENT_TIME, by $USER"

report_uptime () {
    cat <<-_EOF_
<H2>System Uptime</H2>
<PRE>$(uptime)</PRE>

```
_EOF_
    return
}

report_disk_space () {
    cat <<- _EOF_
<H2>Disk Space Utilization</H2>
<PRE>$(df -h)</PRE>
_EOF_
    return
}

report_home_space () {
    if [[ $(id -u) -eq 0 ]]; then
        cat <<- _EOF_
<H2>Home Space Utilization (All Users)</H2>
<PRE>$(du -sh /home/*)</PRE>
_EOF_
    else
        cat <<- _EOF_
<H2>Home Space Utilization ($USER)</H2>
<PRE>$(du -sh $HOME)</PRE>
_EOF_
    fi
    return
}

usage () {
    echo "$PROGNAME: usage: $PROGNAME [-f file | -i]"
    return
}

write_html_page () {
    cat <<- _EOF_
<HTML>
    <HEAD>
        <TITLE>$TITLE</TITLE>
    </HEAD>
    <BODY>
        <H1>$TITLE</H1>
        <P>$TIME_STAMP</P>
        $(report_uptime)
        $(report_disk_space)
        $(report_home_space)
    </BODY>
</HTML>
_EOF_
    return
}
```

`for`真正强大的功能在于，我们可以通过许多有趣的方式创建单词列表。例如，使用花括号展开：

```
[me@linuxbox ~]$ for i in {A..D}; do echo $i; done
A
B
C
D
```

或者使用路径名展开：

```
[me@linuxbox ~]$ for i in distros*.txt; do echo $i; done
distros-by-date.txt
distros-dates.txt
distros-key-names.txt
distros-key-vernums.txt
distros-names.txt
distros.txt
distros-vernums.txt
distros-versions.txt
```

或者使用命令替换：

```bash
#!/bin/bash

# longest-word : find longest string in a file

while [[ -n $1 ]]; do
    if [[ -r $1 ]]; then
        max_word=
        max_len=0
        for i in $(strings $1); do
            len=$(echo $i | wc -c)
            if (( len > max_len )); then
                max_len=$len
                max_word=$i
            fi
        done
        echo "$1: '$max_word' ($max_len characters)"
    fi
    shift
done
```

在这个示例中，我们要查找文件中出现的最长字符串。当在命令行中提供一个或多个文件名时，该程序会使用`strings`程序（该程序包含在 GNU binutils 软件包中）为每个文件生成一个可读文本“单词”列表。`for`循环依次处理每个单词，并判断当前单词是否是目前找到的最长单词。循环结束后，程序会显示最长的单词。

如果省略`for`命令中可选的`in words`部分，`for`默认会处理位置参数。我们将修改`longest-word`脚本，以使用这种方法：

```bash
#!/bin/bash

# longest-word2 : find longest string in a file

for i; do
    if [[ -r $i ]]; then
        max_word=
        max_len=0
        for j in $(strings $i); do
            len=$(echo $j | wc -c)
            if (( len > max_len )); then
                max_len=$len
                max_word=$j
            fi
        done
        echo "$i: '$max_word' ($max_len characters)"
    fi
done
```
