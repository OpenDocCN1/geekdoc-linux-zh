
如果你不确定已安装的应用程序版本，可以使用

```bash
# pkg_info | grep foopage
```

根据需要替换 `foopage`。如果该端口有任何问题，可以使用

```bash
# portmanager -u
```

所有已安装端口可以使用以下命令升级：

```bash
# portmanager -ui
```

### 4.5.5 端口与磁盘空间

使用端口会积累大量源文件。构建安装完成后，你应该记住使用以下命令清理目录：

```bash
# portsclean -C
```

你可以手动删除它们，或使用以下命令：

```bash
# portsclean -D
```
