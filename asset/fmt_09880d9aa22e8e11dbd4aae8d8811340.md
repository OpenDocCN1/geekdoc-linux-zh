# crontab — 用户时间任务文件

概要
`/usr/bin/crontab [filename]`
`/usr/bin/crontab [-elr] username`

描述
使用 `crontab` 命令通过复制、列出和删除 `crontab` 文件来管理用户的 `cron` 访问。如果不带选项调用，`crontab` 将指定文件或标准输入复制到存放所有用户 `crontab` 的目录中。

crontab 访问控制
允许用户访问 `crontab`：

- 如果用户名出现在 `/etc/cron.d/cron.allow`。
- 如果 `/etc/cron.d/cron.allow` 不存在且用户名不在 `/etc/cron.d/cron.deny` 中。
拒绝用户访问 `crontab`：
- 如果 `/etc/cron.d/cron.allow` 存在且用户名不在其中。
- 如果 `/etc/cron.d/cron.allow` 不存在且用户名在 `/etc/cron.d/cron.deny` 中。
- 如果两个文件都不存在。
注意，允许和拒绝规则仅在这些文件存在时才适用于 `root`。允许/拒绝文件每行一个用户名。

crontab 条目格式
`crontab` 文件由每行六个字段组成。字段由空格或制表符分隔。前五个字段是整数模式，指定以下内容：

## crontab

# 181

- 分 (0-59),
- 小 (0-23),
- 日期 (1-31),
- 月份 (1-12),
- 星期 (0-6，其中 0=星期日)。

这些模式中的每一个可以是星号（`*`，表示所有合法规则），也可以是由逗号分隔的元素列表。
元素可以是一个数字，也可以是两个由破折号分隔的数字（表示闭区间范围）。注意，日期的指定可以通过两个字段（日期和星期）来完成。如果指定为元素字段，则两个字段都必须遵守。

`crontab` 文件中行的第六个字段是一个字符串，它将在指定时间由 `shell` 执行。默认情况下（除非被 `\` 转义），它会被翻译为换行符。

`shell` 只执行命令的第一行（直到百分号 `%` 或行尾的结束）。命令的其他行将作为标准输入提供给命令。任何以井号 (`#`) 开头的行都是注释并被忽略。该文件不包含空行。

`shell` 从你的 `$HOME` 目录被调用，`arg0` 为 `sh`。希望显式执行其 `.profile` 的用户会在 `crontab` 文件中这样做。`cron` 为每个 `shell` 提供一个默认环境，定义了 `HOME`、`LOGIN`、`SHELL=/bin/sh`、`TZ` 和 `PATH`。`cron` 任务的默认 `PATH` 为 `/usr/bin`；`root` `cron` 任务默认认为 `/usr/sbin/`；你可以在 `/etc/default/cron` 中设置默认 `PATH`；参见 `cron(1M)`。

如果你不重定向命令的标准输出和标准错误，任何生成的输出或错误将通过电子邮件发送给你。

> 警告 — 如果你不小心输入了没有任何参数的 `crontab` 命令，不要使用 `Control-D` 退出。此键会删除你 `crontab` 文件中的所有条目。请使用 `Control-C` 退出。

超级修改另一个用户的 `crontab` 文件会导致不可预测的行为。特权用户在修改 `crontab` 文件之前，应该先以另一个用户的登录身份调用 `su(1M)`。

## Options

- `-e` 编辑当前用户 `crontab` 文件的副本，或者如果 `crontab` 不存在则创建一个空文件进行编辑。编辑完成后，将该文件安装为用户的 `crontab` 文件。如果给出了用户名，则编辑指定用户的 `crontab` 文件而不是当前用户的 `crontab` 文件，此操作只能由超级用户执行。环境变量 `EDITOR` 决定在使用 `-e` 选项时调用哪个编辑器。默认编辑器是 `ed(1)`。注意，所有 `crontab` 任务都应该通过 `crontab` 提交；你不应该通过直接编辑 `crontab` 文件来添加任务，因为 `cron` 感知不到这种方式进行的更改。

- `-l` 列出调用用户的 `crontab` 文件。只有超级用户可以在 `-r` 或 `-l` 选项指定用户名来删除或列出指定用户的 `crontab` 文件。

- `-r` 从 `crontab` 目录删除用户的 `crontab`。

## Examples

以下示例在每个工作日的凌晨 3:15 清理核心文件。

```
15 3 * * 1-5 find $HOME -name core 2>/dev/null | xargs rm -
```

以下示例发送生日问候邮件。

```
0 12 14 2 * mailx john%Happy Birthday!%Time for lunch
```

以下示例在每月的第一和十五以及每个周一运行命令。

```
0 0 1,15 * 1
```

要仅通过一个字段指定日期，请将另一个字段设为 `*`。以下示例仅在周一运行命令。

```
0 0 * * 1
```
