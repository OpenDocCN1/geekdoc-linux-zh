
## :n-- 下一个文件
当 `vi` 启动时，命令行上可以列出多个文件。例如，要编辑三个文件 `art1*`、`art2*` 和 `art3`，你需要输入以下 shell 命令：

```
$vi art1 art2 art3
```

`vi` 会像照常一样加载文件 `art1`，你可以开始编辑它。保存文件后，你可以使用 `:n` 命令进入下一个文件。如果你在保存当前文件之前尝试使用下一个命令，你将收到通常的警告，你可以按照通常的方式覆盖它（是的，你猜对了——使用 `n!`）。

### 在两个文件之间交替切换
`vi` 通过特殊符号保留了两个文件名，供 `ex` 命令使用。这些符号是：`#` 代表备用文件，`%` 代表当前文件。一旦你使用 `:e` 命令切换了文件，上一个（“备用”）文件就可以通过 `#` 符号引用。你只需要在想要切换时输入 `:e#` 即可在两个文件之间来回切换。

`%` 符号主要用于在 shell 命令中减少输入。

### 在文件之间移动文本
你可以使用撤销缓冲区或命名缓冲区将文本从一个文件复制或移动到另一个文件。这种方法就像“如何使用缓冲区”节所述，使用缓冲区将文本从一个文件的部分复制或移动到另一个部分一样。区别在于，完成（例如）复制（*yank*）后，使用 `:e` 命令切换到另一个文件，然后在新文件中执行粘贴（*put*）。

这种技术有效的原因是，当你使用 `:e` 命令切换文件时，所有缓冲区的内容都会保留。

### 在 vi 内部使用 UNIX
你可能已经在《UNIX Unleashed, System Administrator's Edition》第 5 章“通用命令”中见过 UNIX 结合单一用途或专用工具的功能以实现结果的通用策略。`vi` 也具有与 shell、过滤器和实用程序交互的能力，通常情况下它可以与任何从标准输入读取并向标准输出写入的程序交互。本节解释了实现这一点的各种 `vi` 命令。

## :sh--Shell
此 `:sh` 命令调用 shell。运行的 shell 取决于你的 UNIX 环境，但可以通过 *sh* 设置进行控制（参见“更改 `vi` 设置”节）。当你想要临时离开 `vi` 进入 shell，然后返回离开时的 `vi` 会话时，可以使用此命令。你通常会进入 shell 运行一个或多个 shell 命令，并在每个命令之间保持在 shell 中。你输入的命令向终端的任何输出都会正常显示，而 `vi` 会话的显示将向上滚动。

要返回 `vi` 会话，请按 `^D`（或使用你正在使用的 shell 的相应约定）。你将返回 `vi`，屏幕仍显示你 shell 会话的输出。此外，屏幕底部会显示“Press return to continue（按回车键继续）”。按下回车键后，屏幕将清除并重绘。你将回到编辑会话中离开的精确位置。

## :--Shell
在某些版本的 `vi` 中，它与 `:sh` 命令相同。其他版本会给出错误信息，提示你使用 `:sh` 形式。

## :!--Shell 命令
执行 *shellcommand* 并返回 `vi`。注意，在 shell 命令中，用于文件的 `ex` 特殊符号（在“编辑多个文件”节中引入）会被展开。这些是：`%` 代表当前文件，`#` 代表备用文件。如果你想防止这些符号展开，必须使用 `\`（反斜杠）对其进行转义。

## :!!-- 重复 shell 命令
重复上一次 `:!shellcommand`。注意，紧跟在 `:!` 命令后的任何未转义的 `!` 都会被展开为上一次通过 `:!` 发出的 shell 命令。例如，如果你输入以下序列，你将得到类似下面的结果：

```
:!ls *to display your directory*
art1 art2 !test1 lsefair *目录的内容（可能）*
[Press return to continue]
:!ls -l !\* *尝试显示所有文件的详细列表*
*以 ! 开头*
-rw-rw-rw- 1 jas system 2886 Nov 3 10:07 lsefair
[Press return to continue] *这不是你想要的！*
```
