如你所见，`adduser`命令（指向实际命令`useradd`的符号链接）会将`/etc/skel`中的所有内容复制到新的家目录，并将文件所有权和权限重置为新用户。

系统管理员可能不希望用户更改某些用户文件；可以重置`/home/username`下这些文件的权限，使用户可以读取它们但无法写入。

- `userdel`——此命令将完全删除用户账户（从而消除该用户的家目录及其包含的所有文件）。
- `passwd`——更新密码管理系统使用的“身份验证令牌”。

> 提示
要锁定用户的账户，请使用命令
```
# passwd -l username
```
这会在用户的加密密码前加上一个`l`；反转该过程的命令使用`-u`选项。与传统的UNIX手动编辑文件方法相比，这是一种优雅且更优的解决方案。

- `usermod`——此命令更改用户的多个属性。常用的参数是`-s`更改shell，`-u`更改。

- `chsh`——此命令更改用户的默认shell。对于Fedora Core，默认shell是`/bin/bash`。

## 第9章 管理用户

### 系统密码策略

有效的密码策略是良好的系统管理计划的根本组成部分。
该策略应涵盖：

- 允许和禁止的密码
- 强制更改密码的频率
- 丢失或遗忘密码的找回或替换
- 用户对密码的处理

### 系统密码文件

密码文件为`/etc/passwd`，它是系统中所有用户的数据库文件。
每行的格式如下：

```
username:password:uid:gid:gecos:homdir:shell
```

除了`gecos`字段外，其他字段都是自而易见的。该字段用于存储有关用户的杂杂信息，例如用户的全名、办公室地点、办公室和电话号码，可能还有简短的文本消息。出于安全和隐私考虑，该字段现在很少被使用；系统管理员应该注意它的存在，因为`gecos`字段会被`finger`和`mail`等传统的UNIX程序使用。
因此，它通常被称为finger信息字段。该文件中的数据是由分隔符分隔的；可以使用`echan`（更改finger）命令修改`gecos`字段。

注意，冒号分隔了`passwd`文件中的所有字段。如果某个字段没有可用信息，则留为空，但所有的冒号都会保留。

如果在密码字段中出现星号`*`，则该用户不许可登录。为什么存在这个功能？这样可以轻松地禁用用户并在以后（可能）重新启动，而无需重新创建。系统管理员手动编辑此文件，这是完成此任务的传统UNIX方式。Fedora通过前面提到的`passwd -1`命令提供了改进的功能。

有若干服务以伪用户身份运行，通常具有`root`权限。这些是之前提到的系统用户或逻辑用户。出于安全考虑，你不希望这些账户可供普通登录，因此将`nologin`分配为它们的shell（壳），这阻止了来自这些“用户”的所有登录。

### Shadow密码

在`/etc/passwd`中保留密码是一个安全风险，因为任何具有读取访问权限的人都可以运行破解程序获取密码，这非常麻烦。为了避免这种情况，使用了shadow密码，使得`/etc/passwd`的密码字段中只出现`x`；真正的密码保存在`/etc/shadow`中，该文件可以由系统管理员读取（以及PAM插件认证模块管理器；参见“什么是PAM”）。

密码和登录程序的特殊版本用于启用shadow密码。Shadow密码在Fedora Core操作系统的安装阶段自动启用。让我们查看`/etc/passwd`的伴侣文件`/etc/shadow`的列表：
