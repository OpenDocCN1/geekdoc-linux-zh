
# Ron 教堂的屋顶设计

Ron 教堂的屋顶具有独特的形状。它的东边缘和南边缘构成了设计中的一个显著特征。屋顶边缘的形状有点像船体，如图 6.9 所示。这种形状对大多数建模程序来说是一个挑战，但 `VIZ` 可以轻松处理这种独特形状的创建。

## 图 6.9

显示南角屋顶特征的视图

![](img/7e143440dd5a0ed9683d4f26f3c074f8_312_0.png)

要开始此过程，你需要绘制两条样条。其中一条样条将代表屋顶边缘的截面形状，另一条样条将定义沿东侧和南侧长度的屋顶边缘形状。截面形状和屋顶边缘形状将通过“放样”（`lofting`）过程形成 3D 屋顶边缘。

放样是一个截面形状沿路径挤出的过程。这种放样的结果被称为放样对象（`loft object`）。放样对象类似于布尔对象，因为它们是多个对象、近乎截面的形状和路径的组合。“放样”一词源于造船，指的是布局船体轮廓的方法。就像船体一样，放样对象的截面形状可以沿路径变化。正如你稍后看到的，你可以通过调整路径上各个点的形状来调整放样的形状。

让我们从关闭部分模型开始该过程，以便清楚地看到你的工作。你可以使用位图草图背景进行部分工作，东墙将有助于确定屋顶的高度，因此请关闭东墙以外的所有模型。

1. 继续之前的练习或打开 `ch06c.max`。
2. 使用选择工具（`Select tool`）选择东墙。或者，如果你愿意，可以练习使用按名称选择（`Select by Name`）对话框来执行此操作。
3. 在视口中右键点击，然后点击菜单中的“隐藏未选择”（`Hide Unselected`）。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_312_1.png)

**提示** 除了东墙外，所有的墙都消失了。现在绘制挤出屋顶边缘的轮廓：

1. 使用区域缩放工具（`Zoom Region tool`）放大图 6.10 所示的前视口部分内容。

使用区域缩放工具放大前视口的这部分内容。

2. 点击命令面板上的创建（`Create`）标签。然后点击形状（`Shapes`）按钮并点击矩形（`Rectangle`）。
3. 在前视口中，从东墙的右上角点击并拖动出一个矩形，如图 6.11 所示。你不需要对矩形的位置或大小要求完全精确。

绘制屋顶边缘的矩形

4. 在命令面板的参数展开栏中，将长度（`Length`）值更改为 1.8m，宽度（`Width`）值更改为 4m。你有了轮廓的基本框架，但右下角需要一个曲线，所以加上它。

1. 点击命令面板中的修改（`Modify`）标签，右键点击修改器栈中的矩形项目，并选择“转换为可编辑样条”（`Convert to Editable Spline`）。你不需要矩形的参数化功能，将矩形转换为可编辑样条可以节省资源。
2. 点击命令面板选择（`Selection`）展开栏中的顶点（`Vertex`）工具。在 `VIZ` 中有多种方法完成相同的任务。例如，要访问可编辑样条的顶点子对象，你也可以扩展修改器栈中的可编辑样条并在四角菜单中选择顶点。此外，你可以为可编辑样条子对象输入以下快捷键：`1` 代表顶点，`2` 代表段（`Segment`），`3` 代表样条（`Spline`）。这些键必须从键盘顶行按下，而不是数字小键盘。
3. 选择矩形右下角的顶点。右键点击，然后从四角菜单中选择贝塞尔（`Bezier`）。
4. 点击主工具栏上的选择并移动（`Select and Move`）工具。
5. 在底部的变换输入（`Transform-In`）区域，点击绝对模式变换输入（`Absolute Mode Transform-In`）。它变成黄色并变为偏移模式变换输入（`Offset Mode Transform-In`）。
6. 在 `X` 输入框中输入 `-2.5`。矩形改变了形状。
7. 使用选择并移动工具调整贝塞尔手柄，使其看起来像图 6.12 所示。

### 关闭变换坐标轴（GIZMO）

如果你发现约束一直跳转到“限制到 Y”（`Restrict to Y`），是因为贝塞尔手柄与 `Y` 轴对齐。当你点击手柄时，同时也点击了 `Y` 箭头，从而限制了你在 `Y` 轴上的运动。要解决这个问题，按 `X` 键关闭变换坐标轴。在 `XY` 平面上移动变换坐标轴，再次按 `X` 键将其开启。

8. 点击面板选择展开栏中的顶点按钮（或点击四角菜单中的顶视图 `Top`）以退出子对象级。
9. 右键点击用户视口，按 `T` 键将其切换为顶视图（`Top viewport`），然后将轮廓移动到建筑的北边缘，如图 6.13 所示。

### 对象创建与当前视口

你可能会注意到 `VIZ` 在处于顶视口时将轮廓边缘放置在 `X` 轴上。默认情况下，`VIZ` 将对象放置在由 `X`、`Y`、`Z` 轴定义的平面上。当你在顶视图中绘制对象时，它们被放置在 `X` 和 `Y` 轴定义的平面上。对于前、后视口，对象被放置在 `X` 和 `Z` 轴定义的平面上；对于左、右视口，对象被放置在 `Y` 和 `Z` 轴定义的平面上。

你已经准备好了轮廓。现在是时候创建放样的路径了。这一次，你将追踪位图草图以获取屋顶边缘的轮廓。

1. 点击全视视口（`Maximize Viewport`）放大顶视图。
2. 点击命令面板上的创建（`Create`）标签。如果形状（`Shapes`）按钮未激活，点击它。然后点击直线（`Line`）。
3. 从草图顶部开始绘制图 6.14 所示的直线。右键点击结束直线工具。
4. 点击修改（`Modify`）。然后点击选择展开栏中的顶点按钮（或打开菜单并选择顶点）。
5. 通过选择顶点并右键点击从四角菜单中选择贝塞尔，将图 6.15 所示的顶点转换为贝塞尔类型。

你可能想临时放大以调整南墙的曲线。完成后，选择“撤销视图更改”（`Views Undo View Change`）返回平面图视图。（`Shift+Z` 快捷键的功能与“撤销视图更改”相同。）

你现在已经有了放大部分（`loft`）所需的路径，但在使用该路径之前，你还需要再进行最后一步。现在该路径定义了放大部分的外边缘，但你希望形状能够顺沿着路径的内边缘延伸。我会在你创建完放大部分后再解释原因，这样更容易看出原因。

要创建一个形成挤出（`extrusion`）内边缘的路径，请使用轮廓（`Outline`）工具，并删除不需要的线段。

1. 选中修改（`Modify`）选项卡，在命令面板的选择（`Selection`）卷轴中点击样条（`Spline`）按钮（或在四角菜单中选择 `Spline`）。
2. 选择你绘制的样条。
3. 在面板底部的 `Outline` 框中，输入 `-4` 以创建一个宽度为 4 米的轮廓。这与你之前创建的屋顶边缘宽度相同。
4. 打开四角菜单并选择 `Segment`。
5. 按住 `Ctrl` 并点击图 6.16 所示的段，然后按 `Delete` 键删除它们。

如果你在步骤 3 中创建的轮廓看起来很扭曲，请点击 `Undo`（撤销），然后选择 `Reverse`（反转）按钮，它是 `Outline` 按钮上方的四个按钮之一。接下来在 `Outline` 输入框中输入 `-4`（负四）。你还可以调整顶点的 `Bezier` 手柄（`handles`）来平滑轮廓。

## 放大部分对象

现在你准备好放之前创建的形状了。你将使用 `Create`（创建）选项卡中的 `Loft` 复合对象来执行此操作。

1. 点击你之前创建的轮廓矩形以选中它。
2. 点击命令面板中的 `Create` 选项卡。然后点击 `Geometry`（几何）按钮。
