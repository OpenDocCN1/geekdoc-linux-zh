
- XC-MISC 扩展。第 6 版本的新功能，它允许客户端从服务器获取 ID 范围，这对于在整个运行周期内使用大量 ID 的长时间运行应用程序非常有用。

- 树结构重组。`xc/` 下的目录（已从 `mit/` 重命名）已过移动，以简化构建过程中的依赖关系并使内容更容易查找。

- 配置文件。配置文件已经发生变化，它们位于 `xc/config/` 下各自的目录下。

- Kerberos。这是一种用于 X 客户端的新型授权方案，实现了用户与用户之间的认证。这基于 MIT 的 Kerberos 第 5 版本。如果你的系统中安装了 Kerberos 5，请将 `site.def` 中的 `HasKrb5` config 变量设置为 `YES` 以启用 Kerberos 支持。

- xtrans (X 传输库)。这是尝试将所有系统和传输特定的代码合并到源码树中的单一位置，以实现跨平台兼容。

- 国际化。也称为 I18N，它被实现为 R5 中现有架构的增强，R5 引入了 `FontSet` 的概念。这尝试涵盖几乎所有可能的语言和文化习惯。

- Xt。针对 X 窗口系统编程和开发的 Xt 库进行了多项新增强。请参考关于程序员的 GUI 章节。

## GUI 前端

X 和 UNIX 有许多 GUI 前端。本节将简要介绍一些常用的前端及其窗口管理器。

### Sun MicrosSystems 的 OPEN LOOK

OPEN LOOK 是 Sun 公司的窗口界面。它可能是最流行的界面。它的 Open Desktop 是桌面的一套工具。

Motif 和 OPEN LOOK 之间主要的区别是 OPEN LOOK 使用圆角，而在 Motif 中几乎所有内容都是基于矩形的。参见图 1.14 和 1.15 对应的 `xterm` 和 `menu`。

Motif 和 OPEN LOOK 的另一个主要功能区别是鼠标按钮的使用。Motif 几乎完全使用左键（Button1）进行所有操作。而 OPEN LOOK 通常使用左键进行选择，右键打开菜单。

此外，OPEN LOOK 窗口菜单提供的项目与 Motif 不同。请参见表 1.2 对某些操作的对比。

| 操作 | OPEN LOOK | Motif |
| :--- | :--- | :--- |
| 退出应用程序 | "Quit" | Close |
| 窗口最小化 | "Close" | Minimize |
| 窗口最大化 | "Open" | Maximize |
| 恢复尺寸 | "Restore Size" | Restore |
| 窗口下移 | "Back" | Lower |

菜单被另一个窗口遮挡，表明它没有焦点，但在桌面上仍然可见。

Motif 引入的另一个功能是为所有会话提供虚拟背板。通用桌面环境（CDE）中的显示管理器提供了相同的功能。

## COSE 与 CDE

1993年3月，通用开放软件环境（COSE）成立。因此，OPEN LOOK 和 Motif 之间的战争就此结束了。该协议为通用桌面环境（CDE）奠定了基础。

CDE 使用户能够在登录登录之间保留他们的桌面配置。用户重新登录时，将回到他们精确的用户配置。

在线帮助提供了嵌入式图形、多种字体和超文本功能。应用程序可以访问帮助系统。

CDE 提供了一个标准的文本编辑附加小部件。这提供了类似于 Sun 的 OpenWindows 邮件工具中组合工具的功能。用户可以将非文本数据拖入文本中，系统将将其以图标的形式表示。该文本小部件预计将支持多用途互联网邮件扩展（MIME）。MIME 功能将允许用户通过电子邮件共享非文本数据。

CDE 中的打印功能得到了极大的增强。用户将能够使用拖放功能来打印文件并管理打印队列。除了这些功能外，COSE 还规定了打印 X 图像和屏幕捕捉的标准方法。这与现在几乎被遗弃的 NeWS 系统中的功能非常相似。标准要求 X 打印服务器将 X 协议转换为用户连接的打印机可以接受的格式。这允许用户更轻松地从 X 应用程序创建屏幕捕捉和位图图像。

CDE 最强大的功能之一是它的脚本语言。这种语言允许用户创建带有弹出窗口、警报和对话框的 shell 脚本。此外，邮件系统中将包含钩子（hooks），因此用户可以创建一致的帮助菜单。

## 其他 GUI 供应商

惠尔-惠普（HP）将它的 GUI 环境称为视觉用户环境（VUE）。HP 可能是对 COSE 用户界面标准影响影响力的公司。

遗憾的是，你在 Motif 中看到的标准应用程序界面在 VUE 下可能有不同的外观。HP 定制了它的 Motif 库，以符合其自己的操作方式。例如，它覆盖了所有设置菜单项背景色的尝试。在编写时，还没有办法使用 `xset` 的背景命令来覆盖此设置。

VUE 使用广播消息服务器（Broadcast Message Server）动态更改应用程序的颜色。你请求 VUE 在其色板中动态更改应用程序的颜色。按照规定，所有 X 应用程序必须符合系统上窗口管理器的偏好。产生问题的唯一情况是当你将颜色敏感的非 COSE 应用程序移植到 HP（或符合 HP 的系统）时。

有一个解决这个问题的方法。你可以通过资源文件定义你的颜色。（参见本章较前的“使用资源”部分。）这将在操作系统版本为 HP9.01 或更高版本的 HP 系统上有效。详细信息请联系 HP。

NeXT 的 NextStep 是一个完全面向对象的系统，现在已在 Intel 的 486+ 平台上发布。它基于多线程 Mach 内核。NeXT 最初为他们的操作系统开发硬件，但现在他们只是一家软件供应商。

NeStep 在最初引入时的主要问题之一是缺乏对 X Windows 支持。目前，NeXT 正在与 Sun 合作开发一种名为 OpenStep 的 GUI。这与 COSE 提出的 CDE 相矛盾，并且可能是 Sun 复兴其 OPEN LOOK 界面的方式。NeXT 还在与 HP 和 Silicon Graphics 合作，将其移植到它们的工作站。

NextStep 的 GUI 基于 Adobe Display PostScript 语言。这种方法在你可以获得 PostScript 绘图机的显示器上提供了卓越的图形能力。3.2 版本是第一个符合 POSIX 标准的版本，但当时 Motif 和 OpenWindows 均不可用。

Santa Cruz Operations (SCO) 是 IXI 公司的所有者。IXI 向 Sun 授权了 .desktop 产品。.desktop 是标准桌面。SCO 是 COSE 的创始成员并支持 CDE。

IBM 的 AIX Windows 非常类似于 OSF/Motif。AIX Windows 的后续版本具有更好的图标和文件管理功能。如果你使用 Motif，可以使用 AIX。在某些 AIX 特定区域存在特性。一个很好的例子是 `aixterm`，它被用来代替 `xterm`。排除这些特性，从另一个系统迁移到 Motif 是很容易的。数字设备公司（DEC）可能是 X Windows 最早的支持者。它的 DECWindows 版本运行在 Ultrix 上，这是 DEC 的 UNIX 版本。更多信息请拨打 800-DIGITAL。人们没有将 Apple 的 Mac 视为 UNIX 平台。凭借其已有的 GUI，Mac 是 UNIX 平台的良好候选者。Apple 的 A/UX 为原生应用程序提供了一个层。

你可以在 A/UX 中三个三个环境中工作：

- 类似 tty 的控制台

- X11 窗口管理器

- Mac 文件查找器

前两个选项几乎就像 UNIX 和 X11 会话。最后一个选项就像 Mac Finder 会话。在桌面上寻找一个标记为 `/` 的磁盘。点击它打开其下面的子目录和应用程序。你可以使用鼠标从窗口中的图标调用 UNIX 命令，如 `ls`、`ps` 等。

Softland 系统的 Linux 版本是基于 PC 的免费 UNIX。Linux 是一个 UNIX 克隆，并带有 X11R5。可以在 Linux 和其他 Motif 平台之间轻松且成功地移植代码。更多信息请直接联系 SLS：(604) 360-0188。
