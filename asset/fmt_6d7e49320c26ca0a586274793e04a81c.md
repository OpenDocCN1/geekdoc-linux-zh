
2.  `n` < 0

3.  `lda` $\leq$ 0

4.  `n` > `lda`

5.  `ldz` $\leq$ 0 且 `iopt` $\notin$ \{0, 1, 2\}

6.  `n` > `ldz` 且 `iopt` $\notin$ \{0, 1, 2\}

7.  错误 2015 可恢复或 `naux` $\neq$ 0，且 `naux` 过小，即小于最小所需值。如果错误 2015 可恢复，则返回代码 3。
