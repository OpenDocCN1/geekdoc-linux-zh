# xdm

X 显示器 `xdm` 管理一组 X 服务器，这些服务器可能在本地主机上也可能在远程机器上。它提供的服务类似于字符终端上的 `init`、`getty` 和 `login` 提供的服务：提示用户名和密码、验证用户以及运行会话。`xdm` 支持 `XDMCP`（X 显示器控制协议），还可以用于运行选择进程，该进程向用户展示提供 XDCP 管理的可能主机菜单。如果安装了工具包，`xdm` 可以使用 `ssreg` 将会话注册到系统文件中；但对于 `xdm` 的运行而言并非必须。来自 Debian 3.0r APT
