# who — 报告谁在系统上

## 语法

```
/usr/bin/who [-abdHlmpqrstTu] [file]
/usr/bin/who -q [-n x][file]
/usr/bin/who am i
/usr/bin/who am I
/usr/xpq4/bin/who [-abdHlmpqrtTu] [file]
/usr/xpq4/bin/who -q [-n x][file]
/usr/xpq4/bin/who -s [-bdHlmpqrtu] [file]
/usr/xpq4/bin/who am i
/usr/xpq4/bin/who am I
```

## 描述

`who` 命令显示有关系统当前状态的信息。它可以列出每个当前 UNIX 系统的用户名、终端行、登录时间、该线路发生活动以来的经过时间，以及命令解释器（shell）的进程 ID。

输出的一般格式为：
`name [state][time][idle][exit]`

其中：
- `name`：用户名。
- `state`：线路状态。
- `time`：登录时间。
- `idle`：该线路发生活动以来的小时数和分钟。点 (`.`) 表示终端在过去一分钟内有活动，因此是当前的。如果已经过了二十四小时或该线路自启动以来一直未使用，则标记为旧。`idle` 字段对于判断人员是否在终端前工作很有用。
- `pid`：shell 的进程 ID。
- `comment`：在 `/sbin/initab` 中与之相关的注释字段。

> 注意 在单用户状态下，`who` 返回调用者。如果你使用 `-u` 选项，会将空闲时间添加到之前格式的末尾。在 C 语言下，限制输出描述调用者。系统状态。

## 选项

`-t` 显示 root 最后修改系统时间（使用 `date` 命令）。查看 `su(1)` 和 `date(1)`。

`-u` 列出当前登录的用户。`name` 是用户名。`LINE` 是在 `/dev` 中找到线路名称。`TIME` 是用户登录的时间。`IDLE` 列包含该线路发生活动以来的小时数和分钟。点 (`.`) 表示终端在过去一分钟内有活动，因此是当前的。如果已经过了二十四小时或该线路自启动以来一直未使用，则标记为旧。`idle` 字段对于判断人员是否在终端前工作很有用。`PID` 是 shell 的进程 ID。`comment` 是注释字段。

### 操作数

- `am i` 在 C 语言下，限制输出描述调用者，等同于 `-m` 选项。你必须在 `am` 和 `i` 或 `I` 参数之间留有空格。
- `am I` 指定文件路径以替换 `who` 默认使用的登录用户数据库。
- `file`

# whoami — 显示当前有效用户名

### 概要

```
/usr/ucb/whoami
```

## 描述

`whoami` 显示与当前有效用户 ID 对应的登录名。如果你使用 `su` 临时采用另一个用户身份，`whoami` 会报告与该 ID 关联的登录名。`whoami` 从 `getuid` `getpw` 库例程获取信息（参见 `getuid(2)` 和 `getpwnam(3)`）。

## 示例

以下示例显示了当前有效用户 ID。由于 root 的搜索路径中没有 `/usr/ucbt`，因此需要完整路径名来以 root 身份执行命令：

```
castle% whoami
winsor
caste% su
# whoami
whoami: not found
# /usr/ucb/whoami
root
# exit
caste% su ray
```

```
castle% whoami
ray
castle%
```

# whocalls — 报告对特定过程的调用情况

### 概要

```
/usr/ccs/bin/whocalls whocalls [-l whol] funcname executable [executable arguments ...]
```

## 描述

`whocalls` 命令基于链接审计（Link-Auditing）库，该库允许跟踪给定的函数调用。更多信息请参见《链接器与库指南》（Linker and Libraries Guide）。执行文件按正常运行。每当调用过程 `funcname` 时，该程序的参数和堆栈跟踪都会显示在标准输出上。

## 选项

`-l wholib` 指定使用的替代 `.so` 链接审计库。

## 示例

此示例跟踪了简单的 `hello_world` 程序对 `printf()` 的调用。

```
castle% whocalls printf hello
printf(0x106e4, 0xef625310, 0xef621ba8)
hello:main+0x10
hello:_start+0x5c
hello
castle%
```
