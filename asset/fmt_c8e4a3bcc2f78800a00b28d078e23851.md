构造引用快照监控函数的语法如下：

```sql
SELECT * FROM TABLE (FunctionName, DBName, PartitionNum) AS CorrelationName
```

其中：

- `FunctionName`: 要使用的快照监控函数。
- `DBName`: 要获取快照数据的数据库。
- `PartitionNum`: 要获取快照数据的分区。
- `CorrelationName`: 为查询结果集指定的名称。

构造引用数据库管理器级别快照监控函数的语法与此相同，不同之处是不使用 `DBName` 参数。
