
`display` 指定与 X 服务器的连接。
`w` 指定窗口。
`window_name` 指定窗口名称，应该是一个以空结尾的字符串。
`icon_name` 指定图标名称，应该是一个以空结尾的字符串。
`argv` 指定应用程序的参数列表。
`argc` 指定参数的数量。
`hints` 指定窗口在正常状态下的尺寸提示。
`w_hints` 指定 XWMHints 结构。
`class_hints` 指定 XClass 结构。

`XSetWMProperties` 函数提供了一个编程接口，用于设置与与其他客户端（特别是窗口管理器）通信的必需窗口属性。如果 `name` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_NAME 属性。如果 `icon` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_ICON_NAME 属性。如果 `normal_hints` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_NORMAL_HINTS 属性。如果 `hints` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_HINTS 属性。如果 `class_hints` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_CLASS 属性。如果 `command` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_COMMAND 属性。如果 `hostname` 参数不为 NULL，则 `XSetWMProperties` 设置 WM_CLIENT_MACHINE 属性。

对于需要在区域设置处理文本的客户端，`XSetWMProperties` 将 WM_LOCAL_NAME 属性设置为当前区域设置。在存储到属性之前不会进行编码转换。

## 客户端间通信函数

`XSetWMProperties` 方便函数提供了一个编程接口，用于设置必要的窗口属性，这些属性用于与其他客户端（特别是窗口管理器和会话管理器）进行通信。

如果 `name` 参数不为 NULL，`XSetWMProperties` 会调用 `XSetWMName`，继而设置 WM NAME 属性（见第 14.1.4 节）。如果 `icon name` 参数不为 NULL，`XSetWMProperties` 会调用 `XSetWMIconName`，该函数设置 WM ICON NAME 属性（见第 14.1.5 节）。`XSetWMProperties` 会调用 `XSetCommand`，从而设置 WM COMMAND 属性（见第 14.2.1 节）。注意，允许参数为零以表示零长度命令。另注意，该机器的主机名使用 `XSetWMMachine` 进行存储（见第 14.2.2 节）。

如果 `hints` 参数不为 NULL，`XSetWMProperties` 会调用 `XSetWMNormalHints`，从而设置 WM NORMAL HINTS 属性（见第 14.1.7 节）。如果 `hints` 参数不为 NULL，`XSetWMProperties` 会调用 `XSetWMHints`，从而设置 WM HINTS 属性（见第 14.1.6 节）。

如果 `class` 参数不为 NULL，`XSetWMProperties` 会调用 `XClassHint`，该函数将 WM CLASS 属性设置为 `XClassHint` 结构，并设置 RESOURCE_NAME 环境变量，然后用该环境变量的值替换 `res_name`。如果 `res name` 不为 NULL，则不设置环境变量，并设置 `argv` 和 `argv(0)`，然后用去除任何目录前缀的 `argv(0)` 的值替换 `res_name`。

`XSetWMProperties` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

## 客户端到会话器的通信

本节讨论了如何：

- 设置和读取 WM_COMMAND 属性
- 设置和读取 WM_CLIENT_MACHINE 属性

### 设置和读取 WM_COMMAND 属性

可以使用这些 Xlib 函数来为给窗口设置和读取 WM_COMMAND 属性。

要设置窗口的 WM_COMMAND 属性，请使用 `XSetCommand`。

```
XSetCommand(display, w, argv, argc);
```

- `display`：指定到 X 服务器的连接。
- `w`：指定窗口。
- `argv`：指定应用程序的参数列表。
- `argc`：指定参数的数量。

`XSetCommand` 函数设置用于调用应用程序的命令和参数。（通常，`argv` 是你主程序的 `argv` 数组。）如果字符串不在主机可移植字符编码中（Host Portable Character Encoding），则结果取决于实现。

`XSetCommand` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

要读取窗口的 WM_COMMAND 属性，请使用 `XGetCommand`。

```
Status XGetCommand(display, w, argv_return, argc_return);
```

- `display`：指定到 X 服务器的连接。
- `w`：指定窗口。
- `argv_return`：返回参数列表。
- `argc_return`：返回返回参数的数量。

`XGetCommand` 函数从指定的窗口读取 WM_COMMAND 属性并返回一个字符串。如果 WM_COMMAND 属性存在，其类型为 STRING 且格式为 8。如果能为字符串列表分配足够的内存，`XGetCommand` 将填充 `argv` 和 `argc_return` 参数并返回非零状态。否则，它返回零状态。如果服务器返回的数据是拉丁可移植字符编码（Latin Portable Character Encoding），则返回的字符串是主机可移植字符编码。否则，结果取决于实现。要释放分配给字符串列表的内存，请使用 `XFreeStringList`。

### 设置和读取 WM_CLIENT_MACHINE 属性

Xlib 提供了这些函数来为给窗口设置和读取 WM_CLIENT_MACHINE 属性。

要设置窗口的 WM_CLIENT_MACHINE 属性，请使用 `XSetWMClientMachine`。

```
void XSetWMClientMachine(display, w, text_prop);
```

- `display`：指定到 X 服务器的连接。
- `w`：指定窗口。
- `text_prop`：指定要使用的 `XTextProperty`。

`XSetWMClientMachine` 方便函数调用 `XSetTextProperty` 来设置 WM_CLIENT_MACHINE 属性。

要读取窗口的 WM_CLIENT_MACHINE 属性，请使用 `XGetWMClientMachine`。

```
Status XGetWMClientMachine(display, w, text_prop_return);
```
