## init

`init` 是内核启动的第一个用户进程。`init` 有许多职责，例如启动 `getty`（使用户可以登录）、实施规则以及处理孤儿进程。`init` 是 Linux 系统运行至关重要的进程之一，但你仍然可以管理它。通常在你连接终端或想要更改默认级别时，可能需要担心 `init`。当内核启动（启动）后，`init` 已经启动（加载了），并启动了 `getty`（使用户可以登录），实施了规则并处理了孤儿进程。`init` 位于 `/sbin/init`。

## articles

它还为用户提供了发布界面。来自 Debian 3.0r0 APT

## inode (节点)

一种用于存储 Unix 系统中文件信息的数据结构。每个文件都有一个 inode，文件通过其所属的文件系统及其在系统中的 inode 号被唯一标识。每个 inode 包含以下信息：inode 所在的设备、位置位置信息和文件类型、指向该文件的链接数、所有者 ID 和组 ID、文件字节数、访问和修改时间、inode 自身的最后修改时间以及文件在磁盘上的数据块地址。来自 Linux Guide & FirstLinux

## http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## inode (节点)

inode 是磁盘的描述符。当你通过它查看 inode 信息时，它呈现了文件第一个块的地址。你可以使用此信息来判断两个不同名称的文件是否为同一个文件（链接）。一个文件有几个部分：名称、内容以及如权限和修改时间等管理信息。管理信息存储在 inode 中（文件内容等存储在 inode 之上）。inode 中有三个时间：文件内容最后修改（写入）的时间；文件最后一次使用（读取或执行）的时间；以及 inode 自身最后更改的时间（例如设置更改）。修改文件内容不会影响其使用，而更改权限只会影响 inode 时间。理解节点至关重要，不仅是为了理解 `ls` 命令的选项，还因为人们敏锐地察觉到节点就是文件。目录层级为文件提供了方便的名称。系统对文件的内部名称是 i-number（inode 号）：即持有该文件信息的 inode 编号。来自 UNIX Programming Environment
