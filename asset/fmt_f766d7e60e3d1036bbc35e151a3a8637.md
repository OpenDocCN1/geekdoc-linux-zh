
## 氢化物

氢化物含有氢氧离子（`OH-`），通式为 `M(OH)n`。金属氢化物是含有羟基（`OH-`）化合物的一个亚类，其性质从简单到复杂，从无机到两性。氢氧离子是一种具有单电荷的闭壳电子结构。

在刘易斯酸碱理论中，典型的氢化物碱在键强度上表现为对阳离子电子的吸引力。例如，碱金属和碱土金属的氢化物倾向于。当这些离子化合物溶解在水中，形成金属离子和氢氧离子，如反应（1）所示：

```
M(OH) + H2O → M+ + 2(OH-) (1)
```

氢化物溶液 `X(OH)n`（其中 `X-O` 键为共价键）通常是离子性的，如反应（2）所示：

```
XOH + H2O → X+ + (OH-) (2)
```

离子氢化物可能通过任何金属离子解离，取决于酸或碱的强度。参见 酸与碱。

金属氢化物如氢氧化钠（`NaOH`）在冶金中作为试剂以及实验副产物也非常重要。氢氧化钙（`Ca(OH)2`），被称为石灰，用于制备砌墙砂浆。如 `Mg(OH)2` 和辉绿石 `[FeOH]` 等金属天然存在于矿物中。

氢化物是由氧和氢组成的基，作为一个整体起。在无机化学中，羟基是氢氧离子（`OH-`），它经常与金属键合，例如氢氧化钠（`NaOH`）。在有机化学中，它经常作为亲核试剂作用，例如（`RO-`，代表醇）。参见 酸与碱。

许多氧的中间反应活性形式是危险且重要的生物分子。这种毒性源于羟基自由基（`OH.`）的形成。产生羟基最常见的方法是反应与过氧化氢（`H2O2`）反应。过渡金属离子（如铁，`Fe2+`）是产生 `OH-` 最常见的还原剂。一旦产生，羟基会接受一个质子形成稳定的 `OH-`，并从含有 `C-H` 键的有机分子中夺取氢形成水。自由基反应会导致自由基链反应。自由基反应将通过电子转移机制继续产生其他自由基。

## 水母目

水母目是刺胞动物的一纲，包括淡水和海生的，例如较小的水母、少数特殊的珊瑚和葡萄足水母。水母目可分为不同的目：水母目、珊瑚目、石目、帽水目和管水目。每个物种都表现出无性生殖。

身体形态随水母而异。它们的生命周期由水螅的类型和模式决定。
