
# 第 16 章 创建图表

WordPerfect 提供了创建图表的方法：`Insert`、`Graphics`、`Chart`。此步骤将以图表模式打开 `WP Draw`，并显示一个默认图表（图 16.1）。如果你只需要一个简单的图表（即如果你不想用 `WP Draw` 为图表添加额外元素），并且要创建的数据已经存在于 WordPerfect 表格中，通过这种方式创建图表是可以的。

1. 你可以通过选择 `Insert`、`Graphics`、`Chart`，直接从 WordPerfect Draw 窗口中创建图表。

**图 16.1**

`WP Draw` 图表窗口的上窗格工作原理类似于电子表格，下窗格则以图形形式显示图表。

![](img/fc6d0b1918f77fc89ff58d110e0a8ab2_438_0.png)

2. 你可以在普通的 WP 会话中通过选择 `Draw`、`Chart`，然后点击该区域以将其全部用于图表，或者通过点击并拖动为图表留出特定区域。无论何种情况，`WP Draw` 都会显示创建图表对话框（图 16.2）。选择你想要创建的图表类型并点击 `OK` 打开一个新的 `WP Draw` 编辑器来创建你的图表。

> 注意：无论你是直接从 WordPerfect 文档窗口还是从 WordPerfect Draw 创建图表，之后都可以更改图表类型。

→ 有关可用图表类型的更多信息，请参见“图表类型”，第 419 页。

3. 如果你在 WordPerfect 表格中有想要将其转换为图表的数据，可以右键点击表格并从右键菜单中选择 `Chart`。`WP Draw` 将以图表模式打开，并使用表格中包含的数据。

## 图 16.2

当你从 `WP Draw` 开始创建图表时，可以选择想要创建的图表类型，但如果你直接从 Word 文档窗口创建图表，则必须以后设置此选项。

![](img/fc6d0b1918f77fc89ff58d110e0a8ab2_439_0.png)

**来自 Tux Tips 的提示 #196**

右键点击表格以获取正确的右键菜单可能是有些棘手的。如果你遇到这个问题，请尝试点击表格单元格之间的其中一条线或表格边缘。

无论你如何创建 WordPerfect 图表，你始终使用 `WP Draw` 来编辑它，但是在特殊的图表模式下，如图 16.1 所示。左侧的小窗口是工具调板窗口（与你使用 WP 创建绘图时一样），你可以从中选择各种与图表相关的函数。较大的窗口是 `WP Draw` 主窗口。它被分为两个部分：上窗格以数字格式显示数据，下窗格显示正在根据这些数据构建的图表。

工具调板窗口（图 16.3）功能上与主 WordPerfect 文档窗口中的工具栏相似，但工具调板是一个独立的窗口。

## 工具调板窗口包含帮助你创建和编辑图表的工具

- **图表类型**——工具调板窗口顶部附近的六个工具组允许你选择想要创建的图表类型。你可以创建柱状图、折线图、饼图等。这些选项将在稍后详细讨论。
- **2D/3D 和方向切换**——这些工具允许你开启或关闭 3D 外观并更改其方向。
- **图表样式**——聚类、重叠、堆叠和 100% 堆叠样式按钮会更改图表的外观。这些选项仅适用于某些图表。
- **线条和填充选项**——工具调板底部的六个工具组允许你为图表数据选择各种线条、填充图案和颜色选项。当你从左侧或上方选择行或列时，这些选项才会激活。对于某些 2D 图表，它们是禁用的。

## 导入要制图的数据

图表需要数据。如果你通过右键点击表格并从上下文菜单中选择 `Chart` 来启动图表，那么表格的数据已经加载，你不需要其他操作。否则，你需要手动输入数据。如果数据不多或其不是机器可读的形式，你可以手动操作，但从外部文件导入数据通常比手动输入数据更容易。

当你在没有任何数据的情况下启动图表时，图表会自动加载一些示例数据（参见图 16.1）。如果你从其他源导入数据，可以使用 `文件`、`清除` 来删除示例数据。

从外部电子表格导入数据，应首先确保数据是 `Chart` 工具可以读取的格式。逗号分隔值 `CSV` 文件效果良好。Lotus 的 `.wk` 文件也有效。如果数据是另一种格式（例如 Microsoft Excel `.xls` 文件），你可能需要先转换此文件。`CSV` 文件是简单的 ASCII 数据，由逗号分隔，每行都有自己的行。你可以在 ASCII 编辑中创建 `CSV` 文件（通常具有 `.csv` 扩展名）。大多数电子表格也有创建 `CSV` 文件的能力。假设你有一个想要制图的文件，可以通过 `WP Draw` 主菜单选择 `文件`、`导入` 来导入文件。此步骤将打开一个标准文件选择器。当你点击导入按钮时，可能会看到文本导入对话框（图 16.4）。

## 图 16.4

在文本导入框中微调你的数据导入。

![](img/fc6d0b1918f77fc89ff58d110e0a8ab2_441_0.png)

你可以使用文本导入对话框设置影响导入数据的选项。

- **文件格式**——你可以选择 `ANSI (Windows)` 或 `ASCII (DOS)`。对于大多数文件，此选项没有区别。如果你在使用某些字符遇到问题，可能想尝试两种选项。
- **分隔符**——你可以选择 `Tab`、`逗号` 或 `空格`。分隔符用于分隔列。在 `CSV` 文件中，它是逗号。如果你有一个使用 `Tab` 或 `空格` 的数据文件，可以将其作为 `CSV` 文件导入并正确处理选项。
- **清除数据**——如果你勾选此选项（默认勾选），`Chart` 会导入文件之前删除当前数据。
- **转置数据**——如果你勾选此框，`Chart` 将交换行和列的角色。此设置决定行沿图表的 X 轴以单独柱或线条显示，反亦然。

> 要更改图表使表格中的值水平而不是垂直显示，请使用布局框中的水平选项。要学习如何更改图表的方向，请参见“布局选项”，第 427 页。如果你在加载 `Chart` 应该理解的格式的小文件遇到困难，请参见本末尾“故障排除”部分的“导入文件”。

当你导入数据时，WordPerfect 将第一行和第一列解释为标签。例如，如果你正在显示前三个月的家庭预算，你可能有标记为一月、二月和三月的列，以及房屋、汽车、公用事业和杂费行。你的实际数据是一个 `3x6` 矩阵，这就是 `Chart` 显示它的方式。你的 `CSV` 文件七行四列。如果你的输入数据没有这些标签，你可能需要在导入后编辑数据。

在前面的示例中，柱状图将显示每个月的柱体组。每个组将包含每个预算类别的单独柱。如果你更喜欢预算类别和组内每个月的单独柱，请在导入数据时使用转置选项，或对已加载的数据执行稍后描述的转置剪切并粘贴操作。

**来自 Tux Tips 的提示 #197**

## 编辑原始数据

你可能需要编辑导入的数据以修复类型或在导入过程中纠正问题。`Chart` 数据编辑器非常直观，你不应该在掌握它方面遇到困难。像 WordPerfect 表格或大多数电子表格一样，单行数据水平排列，列垂直排列。行与列的交叉点称为*单元格*，你可以通过点击它并输入值来编辑单个单元格。点击单元格后，你可以只编辑它的部分内容；你输入的*任何内容*都会立即替换单元格中的内容。因此，为了将值 `10347` 替换为 `10348`，你不能只替换最后数字；必须输入替换值。然而，你可以通过选择 `编辑`、`编辑单元格` 打开编辑单元格对话框来绕过此规则，如图 16.5 所示。从此对话框，你可以使用键盘方向键和鼠标指针定位插入点并仅编辑单元格的部分内容。

## 图 16.5

编辑单元格对话框启动时选择了所有内容，所以如果你只想编辑单元格的部分内容，在输入之前务必使用鼠标或方向键。

![](img/fc6d0b1918f77fc89ff58d110e0a8ab2_442_0.png)

你可以通过选择 `编辑`、`剪切 (Ctrl+X)`、`编辑`、`复制 (Ctrl+C)` 和 `编辑`、`粘贴 (Ctrl+V)` 对单元格中的数据进行剪切、复制和粘贴操作。如果你想编辑特定单元格，可以通过选择 `编辑`、`转到单元格` 来打开图 16.6 中的转到对话框。输入要编辑的单元格的数字-字母标识符，例如 `C4` 或 `E10`。

## 图 16.6

“转到”对话框默认指向当前单元格。

![](img/fc6d0b1918f77fc89ff58d110e0a8ab2_443_0.png)

除了编辑单个单元格的内容外，你还可以对整个行、列或单元格区域进行操作。点击列上方或行左侧的标签可以选择全部，或者点击并拖动以选择矩形单元格区域。你无法为整个区域输入值，但可以对其执行剪切、复制和粘贴操作。你还可以选择 `编辑`、`转置粘贴`，以反转行和列的角色来粘贴所选区域。

如果你需要插入行或列，可以通过 `编辑`、`插入` 来实现。如果你在选择某行或某列后选择此序列，图表会将项目插入到所选位置，并将所选行或列向下或向右移动。如果你在选择单元格区域或仅单个单元格后选择 `编辑`、`插入`，图表将显示 `插入` 对话框（图 16.7），你可以在其中指定插入行还是列以及数量。

## 图 16.7

通过 `插入` 对话框告诉 WP 要插入多少行或列。
