## 系统调用：按字母交叉引用

该工具的版本通过命令行选项 `-c`、`-s` 和 `-m` 的任意组合来选择。这些选项必须后跟一个时间和可选的日期指定符。可选的日期指定符后面可以再跟一个可选的年份指定符。此外，可以指定增量，或者配合脚本管理器。

`at` 的第二个版本通过 `-r` 选项选择，后面可以后跟一个或多个作业 ID 数字。`at` 的第三个版本通过 `-l` 选项选择，后面可以后跟零或多个作业 ID 数字。
