## 位置变量或 Shell 参数

你可能还记得，当 shell 的命令行解释器处理一行输入时，命令行的第一个单词是一个可执行文件，行的其余部分将作为参数传递给该可执行文件。如果可执行文件是一个 shell 程序，则参数将作为位置变量传递给程序。第一个参数赋值给变量 `$1`，第二个参数赋值给 `$2`，以此此类推，直到 `$9`。请注意，变量名实际上是数字 1 到 9；美元符号一如既往，是导致发生替换的特殊字符。

位置变量 `$0` 始终包含可执行文件的名称。位置变量将在本章后面的“Shell 编程”部分进行讨论。

**防止变量被更改** 如果一个变量已经分配了值，并且你想确保该值之后不再被更改，可以使用以下命令将变量指定为 `只读`（read-only）变量：

```bash
readonly variable
```

从现在起，变量将无法重新赋值。这确保了变量不会被意外更改。

使变量对子 shell 可用。当 shell 执行程序时，它会为程序的执行设置一个环境。这被称为子 shell。在 Bourne shell 中，变量被视为局部变量；在赋值该值的 shell 之外，其他地方无法识别这些变量。你可以通过 `export` 命令导出变量，使其对你执行的任何子 shell 可用。你的变量可以对其他用户可见。

当你启动一个新的 shell 时，会出现默认的 shell 提示符。这是因为对 `PS1` 的变量赋值仅在当前 shell 完成。要让新提示符在 shell 中生效，你必须像示例所示导出它。

```bash
$ PS1="Enter Command: "
```

## 什么是程序？

关于什么是计算机程序，有很多定义，但对于本文而言，计算机程序是一组有序的指令，导致计算机执行某些实用的功能。换句话说，当你让计算机按特定顺序执行任务，以便结果大于单个任务之和时，你就对计算机进行了编程。例如，你在电子表格中输入公式时，你正在进行编程。当你输入一个复杂的命令时：

`$ ls -R / | grep myname`

在 UNIX shell 中，你正在对 shell 编程；你让计算机按顺序执行一系列工具，从而得到一个比单独运行任何一个工具得到的结果更有用的结果。

## 一个简单的程序

假设你每天使用以下命令备份你的数据文件：

```bash
$ cd /usr/myname; ls * | cpio -o >/dev/rmt
```

正如你之前学到的，当你输入像这样的复杂命令时，你正在对 shell 编程。程序的有用之处之一是，它们可以存放在库中反复使用，而无需每次都重新编写。shell 程序也不例外。与其每次输入冗长的备份命令，你可以将程序存储在名为 `backup` 的文件中：

```bash
$ cat >backup
cd /usr/myname
ls * | cpio -o >/dev/rmt
Ctrl+D
```

你可以使用你喜喜欢的编辑器（unix Unleashed, Internet Edition），第 3 节“使用 vi 和 em 进行文本编辑”，实际上，对于较大的程序，你几乎会想这样做。你可以在单行中输入命令，也可以通过命令行输入，但因为 shell 中的命令（有时称为 shell 脚本）是按顺序执行的，将每个命令单独放在一行使程序更易读。随着程序规模扩大，创建易读的程序变得更加重要。

现在要备份数据文件，你可以调用 shell 程序的任何其他命令（称为子 shell），并为其提供文件 `backup` 中的找到命令。为此只需执行 shell 命令：

```bash
$ backup
```

## 对 Shell 变量进行算术运算

在大多数编程语言中，变量是有类型的，这意味着它们被限制某些类型的数据，如数字或字符。变量始终存储为字符。要对变量进行算术运算，必须使用 `expr` 命令。

`expr` 命令将其参数评估为数学表达式。命令的一般形式如下：

```
expr integer operator integer
```

由于 shell 将变量存储为字符，作为 shell 程序员，你有责任确保给 `expr` 的整数参数是事实。以下是有效的算术运算符：

| | 两个整数相加。 |

| - | 从第一个整数减去第二个整数。 |

| * | 两个整数相乘。 |

| / | 第一个整数除以第二个整数。 |

| % | 给出除法的取模（余数）。 |

```bash
$ expr 2 + 1
$ expr 5 - 3
```

如果 `expr` 的参数是变量，则在评估表达式之前会替换变量的值，如下例所示：

```
$ int=3
$ expr $int + 4
7
```

你应该避免单独使用星号运算符 (`*`) 进行乘法。如果你输入：

```
$ expr 4 * 5
```

你会得到一个错误，因为 shell 会看到星号，并在将参数传递给 `expr` 之前执行文件名替换。乘法表达式的正确形式是：

```
$ expr 4 \* 5
20
```

你还可以在以下情况下组合算术表达式：

```bash
$ expr 5 + 7 / 3
7
```

前一个表达式的结果看起来可能很奇怪。要记住的第一点是，除法和乘法的优先级高于加法和减法，因此执行的操作是 7 除以 3。由于 `expr` 只处理整数，除法的结果为 2，然后将其与 5 相加，得到最终结果 7。`expr` 不识别括号，若要覆盖优先级，你必须手动操作。你可以使用反引号来改变优先级，如下：

```bash
$ int='expr 5 + 7'
$ expr $int / 3
4
```

或者使用更直接的方法：

```bash
$ expr 'expr 5 + 7' / 3
4
```

## 向 Shell 程序传递参数

程序可以通过两种方式获取数据：要么在执行时作为参数传递给程序，要么由程序以交互方式获取。像 `vi` 这样的编辑器是在交互模式下使用的，而像 `ls` 这样的命令通过参数获取数据。Shell 程序也不例外。在“交互式读取数据到程序”章节中，你将看到 Shell 程序如何以交互方式获取数据。

在命令行上向 Shell 程序传递参数可以极大地增强程序的通用性。考虑之前介绍的备份程序的逆过程：

```bash
$ cat >restoreall
cd $WORKDIR
cpio -i </dev/rmt0
Ctrl+d
```

按照目前的写法，`restoreall` 程序通过备份方式重新加载整个磁带。但如果你只想从磁带中恢复单个文件呢？你可以通过将文件名作为参数传递来实现。增强后的 `restoreall` 程序如下：

```bash
# 用于恢复单个文件的 restore 程序
cd $WORKDIR
cpio -i $1 </dev/rmt0
```

现在，你可以向恢复程序传递一个代表要恢复的文件名的参数：

```
$ restore file1
```

在这里，`file1` 作为第一个位置参数传递给 `restore`。恢复的限制是，如果你想恢复两个文件，就必须恢复两次。

作为最后的增强，你可以使用 `$` 变量向程序传递任意数量的参数：

```bash
# 用于恢复任意数量文件的 restoreany 程序
cd $WORKDIR
cpio -i $* </dev/rmt0

$ restoreany file1 file2
```

因为未赋值的 Shell 变量会返回空值或空字符串，如果在运行 `restore` 或 `restoreany` 程序时没有命令行参数，`cpio` 命令中将放置一个空值，这会导致整个归文件被恢复。

考虑列表 9.1 中的程序；它计算行驶特定距离所需的时间。

### 列表 9.1. 两个参数的程序示例。

```bash
# traveltime - 一个计算通过固定距离所需长时间的程序
# 语法: traveltime miles $1 * 60
X60=`expr $1 * 60`
TOTMINUTES=`expr $X60 / $2`
HOURS=`expr $TOTMINUTES / 60`
MINUTES=`expr $TOTMINUTES % 60`
echo "The trip will take $HOURS hours and $MINUTES minutes"
```

列表 9.1 中的程序接受两个位置参数：距离和以小时英里为单位的的速度。里程数作为 `$1` 传递给程序，行驶速度作为 `$2`。注意，程序中的第一个命令将里程数乘以 60。由于 `expr` 命令仅在整数间工作，因此以分钟为单位计算旅行时间是有用的。用户定义的变量 `X60` 存储了中间计算结果，除以行驶速度后，得到总分钟数。然后，通过使用整数除法和模运算除法找到小时数和分钟数。

现在使用以下命令行为 90 英里、速度 40 英里/小时的路程执行 `traveltime`：

```
$ 90 40
The trip will take 2 hours and 15 minutes
```

## Shell 程序中的决策

计算机编程语言之所以强大，原因之一是它们具有做出决策的能力。当然，计算机并不思考，因此计算机程序做出的决策只是对你在程序中预设的条件的响应。计算机程序的决策以条件执行的形式存在：如果存在某个条件，则执行一组命令。在大多数编程语言中，这种设置被称为 `if-then` 结构。

### if-then 语句

Bourne Shell 也有 `if-then` 结构。该结构的语法如下：

```bash
if command_1
then
command_2
command_3
fi
command_4
```

你可能记得每个程序命令结束时都会返回一个退出状态。退出状态存储在 Shell 变量 `$?` 中。如果语句检查其命令的退出状态，且该命令成功，则 `then` 语句和 `fi` 语句之间的所有命令将被执行。在这个程序序列中，`command_1` 总是执行，`command_2` 和 `command_3` 只有在 `command_1` 成功时才执行，而 `command_4` 总是执行。

考虑以下变体，如果想在备份文件后删除目录，可以使用 `rm` 命令：

```bash
# 备份并删除文件
# 语法 - 卸目录
cd $1
ls -a | cpio -o /dev/rmt0
then
  rm *
```

起初，这个程序似乎会按你想要执行。但如果 `cpio` 命令出现问题了呢？在这种情况下，`rm` 命令就会执行并删除目录。`if-then` 结构防止了这种灾难的发生。见列表 9.2。

### 列表 9.2. 带有错误检查的 Shell 程序。

```bash
# 备份并删除文件
# 语法 - 卸目录
cd $1
if ls -a | cpio -o /dev/rmt0
then
  rm *
```

在上述所示的程序中，只有当 `cpio` 命令成功时才会执行 `rm`。

Shell 程序内部的标准输出和错误输出传递给用户。在示例 9.2 中，`cpio` 的任何错误信息都是可见。在 Bourne Shell 中，通常通过使用 `echo` 命令来实现。正如名称所示，`echo` 将参数发送到标准输出并在末尾附加换行符，如下例：

## if-then-else 语句

编程中一种常见的设计是在条件真时执行一组命令，在条件假时执行另一组命令。在 Bourne Shell 中，你可以通过使用 `if-then-else` 结构来实现这种效果：

```bash
command_1
then
  command_2
  command_3
else
  command_4
  command_5
fi
```

在这个结构中，`command_1` 总是执行。如果 `command_1` 成功，则执行 `command_2` 和 `command_3`；如果它失败，则执行 `command_4` 和 `command_5`。

现在增强卸程序使其对用户友好。例如：

```bash
# 备份并删除文件的程序
# 语法 - 卸目录
cd $1
if ls -a | cpio -o >/dev/rmt
then
  rm *
else
  echo "创建备份时发生问题。"
  echo "目录不会被擦除。"
fi
```

```
echo "Please check the backup device and try again."
```

> **提示：** 由于 shell 会忽略命令行中额外的空格，良好的程序员利用这一特性来增强程序的可读性。当在 `then` 或 `else` 子句中执行命令时，请将子句中的所有命令以相同的距离进行缩进。

## 带有测试条件

你已经看到 `if` 语句是如何通过测试命令的退出状态来控制命令执行顺序的了，但如果你想测试其他条件呢？在 shell 程序中一个非常实用的命令是 **test** 命令。**test** 命令检查某些条件，如果条件为真则返回零状态（0），如果条件为假则返回非零退出状态。这种功能使得 Bourne shell 中的 `if` 语句与其他具有此类增强的语言保持一致，而这些增强对 shell 编程非常有帮助。

该命令的一般形式如下：

```
test condition
```

条件可以分为四类：1) 测试字符字符串条件或关系的**字符串运算符**；2) 测试两个整数数值关系的**整数关系运算符**；3) 测试文件是否存在或大小的**文件运算符**；4) 测试其他条件之间与/或逻辑组合的**逻辑运算符**。

### 测试字符数据

你已经学习过 Bourne shell 不区分数据类型。输入行的每个单词和每个变量都可以被视为字符字符串。某些命令（如 **expr** 和 **test**）具有对字符串执行数值操作的能力，这些字符串可以被转换为整数值，但任何元素都可以作为字符字符串进行操作。

你可以比较两个字符串来查看它们是否等价或不相等。你也可以测试单个字符串来查看它是否有值。字符串运算符如下：

| str1 = str2 | 如果 str1 与 str2 长度相同且包含相同字符，则为真 |

| str1 != str2 | 如果 str1 不与 str2 等等，则为真 |

| -n str1 | 如果 str1 的长度大于 0（不为空），则为真 |

| -z str1 | 如果 str1 为空（长度为 0），则为真 |

| str1 | 如果 str1 不为空，则为真 |

尽管你最常在 shell 程序中使用 **test** 作为决策器，但 **test** 也是一个可以在以下情况下独立运行的程序：

```
$ str1=abcd
$ test = abcd
$ echo $?
0
$
```

注意，与上一个示例第一行的变量赋值语句不同，`test` 命令的等号两侧必须被空格包围。在这个示例中，shell 向 **test** 发送了三个参数。字符串在长度和逐字符上必须等价。

```
$ str="abcd" 
$ test "$str" = abcd
$ echo $?
1
$
```
