
# 总结

## Linux 归档程序
常用的 Linux 归档程序包括 `tar` 和 `cpio`，它们都是基于文件的工具，使用普通的文件访问方法创建文件归包。`dd` 程序是一个文件复制程序；但当它接收到一个分区设备时，它会在极低层的基础上复制整个分区，这对于创建 Linux 或非 Linux 文件系统的底层镜像备份非常有用。

## Linux 文件所有权系统
每个文件都有一个所有者和一个组，通过数字标识。文件权限可以独立地分配给所有者、文件组以及所有其他用户。

## Linux 文件权限系统
Linux 为文件的所有者、文件组和所有其他用户提供了独立的读、写、执行权限，共产生九个主权限位。还有特殊权限位可用，允许你使用修改后的账户特征启动程序文件，或更改 Linux 控制谁可以删除文件的规则。

## 修改权限的命令
`chmod` 命令是 Linux 中设置权限的主要工具。你可以使用八进制（以 8 为基数）模式或符号表示法来指定权限。`chown` 和 `chgrp` 命令分别允许你更改文件的所有者和所属组。（`chown` 命令可以同时完成这两项操作，但只能由 `root` 用户运行。）

## Linux 磁盘配额系统
使用 Linux 磁盘配额系统的前提条件是 Linux 内核支持使用配额的文件系统。你还必须运行 `quotaon` 命令（通常从 SysV 启动脚本执行）来启用此功能。

## 设置配额
你可以通过 `edquota` 命令编辑单个用户的配额，例如通过 `edquota larry` 来编辑 `larry` 的配额。该命令会在一个描述用户配额的文本文件上打开编辑器。你可以更改此描述、保存文件并退出编辑器以更改用户的配额。

## Linux 标准目录结构
Linux 的目录树从根目录（`/`）开始，它主要包含其他目录。特定的目录可能包含特定类型的信息，例如 `/home` 中的用户文件和 `/etc` 中的配置文件。这些目录及其子目录中的某些可能是独立的分区，这有助于在文件系统损坏时隔离数据。

## Linux 文件定位命令
- `find` 命令通过暴力搜索定位文件，在遍历目录树时搜索符合你指定标准的文件。
- `locate`（或 `locatedb`）命令在公共访问目录的文件数据库中搜索。
- `which` 命令搜索几个重要的目录，而 `which` 搜索路径。
- `type` 命令识别另一个命令是内置 Shell 命令、Shell 别名还是外部命令（包括该命令的路径）。
