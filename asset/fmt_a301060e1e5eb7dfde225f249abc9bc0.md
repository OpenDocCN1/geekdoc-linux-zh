`$HOME` 是你的家目录，`$PWD` 是你的当前目录，以此此类推。历史命令增加了更多变量。这里有一个你如何使用 `!!` 新命令的示例：

### 表 9-2：历史记录变量

| 变量 | 含义 |
|---|---|
| `!!` | 上一个命令 |
| `!n` | 编号为 `n` 的命令 |
| `!-n` | 当前命令减去 `n` 条命令 (`!1` 是上一个命令，`!-2` 是上上一个命令，依此类推) |

使用指示符（designators）剥离命令的部分。你也可以通过在历史变量末尾添加单词指示符来引用之前命令的部分。最有用的单词指示符是 `*`，用于引用所有参数。例如，要创建一个新目录并进入该目录，可以使用此：

```bash
!!1 (现在按 Ctrl-E)
killall
mkdir /usr/local/src
cd
pwd
```
