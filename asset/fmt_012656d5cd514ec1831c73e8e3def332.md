对于 I/O 操作，建议使用 `PerlIO` 库的自动翻译功能。这允许你为每个句柄使用不同的编码。例如，你可以使用

```perl
use Encode;

open($f, ":encoding(ascii)", "test.ascii"); print $f "Hello!\n";

open($f, ":encoding(cp37)", "test.ebcdic"); print $f "Hello!\n";

open($f, ":encoding(utf8)", "test.utf8"); print $f "Hello!\n";
```
