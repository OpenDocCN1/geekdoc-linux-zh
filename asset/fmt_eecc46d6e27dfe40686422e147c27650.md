## 32 构建你自己的服务器

```
# 运行的服务器总数限制，即同时连接的
# 客户端数量限制 —— 如果达到此限制，
# 客户端将被锁定，因此不应设置太低。
# 它主要作为制动器，防止失控的服务器
# 导致系统崩溃。

MaxClients 150
```

```
# MaxRequestsPerChild：每个子进程在死亡前
# 允许处理的请求数。子进程将退出以避免
# 使用 Apache（以及可能存在的库）导致内存
# 泄漏或其他资源。大多数系统上这并不需要，
# 但某些系统（如 Solaris）存在明显的泄漏。
# 例如，如果一个子进程处理
# 初始请求和 10 个后续的 'keepalive' 请求，
# 它将只计为 1 个。

MaxRequestsPerChild 100
```
