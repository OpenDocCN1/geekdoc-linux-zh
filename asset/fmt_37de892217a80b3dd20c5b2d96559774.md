## set

```
+   set

 name ...

 name = value ...

set name = (wordlist) ...

set name[index] = word ...

set -r

set -r name ...

set -r name = value ...

set -r name = (wordlist) ...
```

不带参数时，`set` 显示所有 shell 变量的值。包含多个单词的变量将以括号列表的形式打印。带名称参数时，`set` 定义变量并分配空字符串。带有等号分隔的名称和值时，它定义变量并分配该值。要将 `wordlist` 分配给 `name` 变量，将列表中的单词括在括号内作为赋值。要为数组中的元素分配值，使用括号指定元素的索引。该元素必须已存在。

## TCSH 命令 94

`-r` 选项用于引用只读变量。单独使用 `-r` 选项时，`set` 会列出只读变量。与变量名一起使用时，它会将该变量变为只读变量。与赋值值一起使用时，它用该值初始化该变量，并使其变为不可更改的只读变量。

在 TCSH 壳中，你需要在使用变量之前先声明它。你通过 `set` 命令后跟变量名来声明变量。变量名可以是任何字母字符组合，包括下划线。名称也可以包含数字，但数字不能作为名称的第一个字符。名称不能包含任何其他类型的字符，例如感叹号、安培符号甚至空格。这些符号被壳预留供其自身使用。名称不能包含多个单词，因为壳根据空格来解析其命令行。空格是命令行中不同元素之间的分隔符。接下来的示例声明了变量 `greeting`。你可以在稍后可以使用 `unset` 命令取消该变量的定义。

```
> set greeting
```

你还使用 `set` 命令为变量赋值。你输入关键字 `set`、变量名、赋值运算符（`=`），然后是赋值的值。任何字符组合都可以分配给变量。在接下来的示例中，变量 `greeting` 被赋值为字符串 "hello"。

```
> set greeting = "hello"
```

在 TCSH 赋值操作中，需要在赋值运算符的两侧放置空格，或者完全不留空格。赋值操作

```
> set greeting ="hello"
```

将会失败，因为赋值运算符前面有空格但后面没有。

可以通过无参数使用 `set` 命令获取所有定义变量的列表。下一个示例使用 `set` 显示所有已定义变量及其值。

```
> set
greeting hello
poet Virgil
```

## TCSH 命令 95

与 BASH 壳一样，美元符号 `$` 是一个评估壳变量的特殊运算符。评估会检索变量的值——通常是一组字符。这组字符随后会替换变量名。实际上，在变量名之前放置 `$` 的地方，壳都会将变量名替换为变量的值。在接下来的示例中，壳变量 `greeting` 被求值，其内容 "hello" 然后被用 `echo` 命令的参数。`echo` 命令在屏幕上打印一组字符。

```
> echo $greeting

hello
```

## setenv

`setenv [name {value}]`

`setenv` 用于用指定的值定义环境变量。在没有值的情况下，`setenv` 将名称设置为空字符串。在无参数的情况下，它会显示所有环境变量的名称和值。

TCSH 壳有两种变量：局部变量和环境变量。局部变量对于其声明的壳是局部的；环境变量的操作类似于作用域的变量。它对子壳是已知的，但对任何父壳都是不可见的。环境变量通过 `setenv` 命令定义。你使用 `setenv` 命令、变量名和赋值的值给环境变量赋值。这里没有赋值运算符。在接下来的示例中，`greeting` 环境变量被赋值为值 "hello"。

```
> setenv greeting hello
```

每当调用脚本时，它都会生成它自己的壳。如果从另一个壳脚本执行一个壳脚本，它将拥有自己的、独立于第一个脚本的壳。此时现在有两个壳：属于第一个脚本的父壳和一个在执行第二个脚本时生成的新壳（子壳）。当从另一个脚本内部执行脚本时，它的壳是第一个脚本壳的子壳。原始脚本的壳是父壳。

每个壳都有自己的一组变量。子壳不能引用父壳中的局部变量，但它可以引用环境变量。在父壳中声明的任何环境变量都可以被任何子壳引用。

## TCSH 命令 97

`breaksw`

`endsw`

`switch` 结构在几个可能的替代方案之间选择。它与 BASH 壳的 `case` 结构非常相似。通过将字符串与几个可能的模式进行比较来选择，每个可能的模式都与一组命令关联。如果找到匹配项，则执行关联的命令。`switch` 结构以关键字 `switch` 和括号内的测试字符串开始。字符串通常源于变量求值。后面是一系列模式。每个模式之前都有关键字 `case`，并以冒号结尾。关联的命令以 `breaksw` 结束。`switch` 结构在所有模式中匹配测试字符串直到找到匹配项。如果没有找到匹配项，则执行 `default` 选择。`default` 关键字是可选的。`endsw` 结束 `switch` 结构。

`switch` 结构经常用于实现菜单。在 `lschoice` 示例中，用户被要求输入以以列出文件的文件。请注意 `default` 选项用于警告无效输入。

## lschoice

```
#
echo s. List Sizes
echo 1. List File Information
echo c. List Files
echo -n "Please enter choice: "
set choice = $(choice)
switch ($choice)
case s:
    ls -s
    breaksw
case 1:
    ls -1
    breaksw
case c:
    ls *.c
    breaksw

default:

    echo Invalid Option

    breaksw

endsw
```

```
> lschoice

s. List Sizes

1. List File Information

c. List Files

Please enter choice: c

io.c lib.c main.c

>
```
