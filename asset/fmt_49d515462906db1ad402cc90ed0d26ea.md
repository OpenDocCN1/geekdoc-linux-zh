# lp-solve

求解（混合线性规划）问题线性规划 (`LP`) 问题可以按如下求解：`Ax= z1, V2 x`。`A` 是矩阵，`x` 是（非负）变量向量，`V1` 是称为右侧向量的向量，`V2` 是表示目标函数的向量。整数线性规划是一种满足所有变量均为整数的 `LP` 问题。在整数混合线性规划 (`MILP`) 问题中，某些变量是整数，另一些是实数。`lp_solve` 程序求解 `LP`、`ILP` 和 `MILP`。它比上述建议的更通用，`A` 的每一行（指定一个约束）都可以有自己的（不等式、<=、>= 或 =）。所有变量的结果。`lp_solve` 使用单纯形法和稀疏矩阵方法。如果一个或多个变量被声明为整数，单纯形算法结合分支界法，直到找到最优解。`lp_solve` 可以读取 `MPS` 格式。来自 Debian 3.0。

http://www.tld.org/LDP/Linux-Dictionary/html/index.html

# lpd

行式打印机溢区 来自 Whatis

http://www.tld.org/LDP/Linux-Dictionary/html/index.html

`lpd` 是行式打印守护进程（溢区处理器），通常在启动时调用 `rc(8)` 扫描 `printcap(5)` 以查找存在的打印机并在崩溃后留下的文件。然后它监听并接受打印队列中的文件，将文件传输到溢区，显示队列。在每情况下，它都会派生子进程处理请求，以便父进程继续监听更多请求。来自 Linux Guide @FirstLinux

http://www.tld.org/LDP/Linux-Dictionary/html/index.html
