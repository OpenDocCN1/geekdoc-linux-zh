# sortbib — 排序文献数据库

### 概要

`/usr/bin/sortbib [-s KEYS] database...`

## 描述

使用 `sortbib` 命令按你指定的排序包含 `refer(1)` 键的记录文件。记录可以用空行或 `.` 分隔，但两种样式不能混合。此命令读取每个数据库并提取键字段，对其进行单独排序。排序后的键字段包含文件指针、字节偏移和相应记录的长度。这些记录通过磁盘寻道和读取交付，`sortbib` 不能在管道中读取标准输入。

常见的键字母及其含义如下所示。

- `%A` 作者名。
- `%B` 引用文章的书。
- `%C` 城市（出版地）。
- `%D` 出版日期。
- `%E` 引用文章的书编辑。
- `%F` 脚注编号或标签（由 `refer` 提供）。
- `%G` 政府订单号。
- `%H` 头部注释，在引用之前打印。
- `%I` 发布者（出版社）。
- `%J` 文章的期刊。
- `%K` 用于定位引用的关键词。
- `%L` `refer -k` 选项使用的标签。
- `%M` 实验室备录（未定义）。
- `%N` 卷内编号。
- `%O` 打印在引用末尾的其他注释。

## sortbib 1257

`%P` 页码（数）。

`%Q` 机构或外国作者（未反转）。

`%R` 报告、论文或论文（未发表）。

`%S` 系列标题。

`%T` 文章或书籍的标题。

`%V` 卷号。

`%X` 摘要。供 `roffbib` 使用，而非 `refer` 使用。

`%Y`, `Z` 被 `refer` 忽略。

默认情况下，`sortbib` 按第一个 `%A` 和 `%D` 字段进行字母顺序排序，这些字段包含高级作者和日期。

`sortbib` 按 `%A` 行的最后一个单词进行排序，该单词被假设为作者姓名。在最后位置，如果该词之前的名称以逗号结尾，则该词（如 `ed.`）被忽略。对于具有双字姓氏或特殊构造的作者，可以使用 `nroff` 约定用 `\0` 代替空格来正确排序。`%Q` 字段被认为与 `%A` 字段相同，不同之处在于排序从第一个单词而不是最后一个单词开始。`sortbib` 通常按 `%D` 行的最后一个单词进行排序。在根据 `%T` 或 `%F` 中的标题排序时，它还会忽略开头的冠词（如 `A` 或 `The`）；它会忽略任何现代欧洲语言的属性。如果记录中缺少排序，`%T` 将该记录置于包含该字段的其他记录之前。

一次排序的数据库数量不超过 16 个。超过 4,096 个字符的记录将被截断。

## 选项

- `-s KEYS` 指定新的 `KEYS`。例如，`-sAT` 按作者、标题和日期排序，而 `-sA+D` 按所有作者和日期排序。第四个之后的排序键没有意义。

## sotruss — 跟踪共享库过程调用

### 概要

`/usr/bin/sotruss [-f][-F bindfromlist][-T bindtolist] -o outputfile 可执行文件 [可执行文件参数...]`

## Description

`sotruss` 命令执行指定的命令并生成其执行的库调用跟踪。在执行每个过程调用时，跟踪的每一行都会报告动态对象之间正在发生的绑定。`sotruss` 跟踪通过过程链接表（Procedure Linkage Table）发生在动态对象之间的所有过程调用，因此只有通过过程链接表绑定的过程调用会被跟踪。参见《链接器与库指南》。

## 选项

- `-f` 跟踪由 `fork()` 创建的所有子进程，并在每个子进程上打印 `truss` 输出。此选项还会在每行 `truss` 输出上输出一个 PID。
-- `-F bindfromlist` 指定一个用逗号分隔的库列表，用于跟踪这些库。仅跟踪来自这些库的调用。默认是仅跟踪来自主可执行文件的调用。
--o `outputfile` 将输出直接定向到输出文件。如果将此选项与 `-f` 选项结合，则执行程序的 PID 将放在文件名的末尾。默认情况下，输出到标准错误。
--T `bindtolist` 指定一个用逗号分隔的库列表，用于跟踪这些库。仅跟踪对这些库的调用。默认是跟踪所有调用。
