
参数是函数的参数。它们与函数名通过一个或多个空格或制表符分隔，如果有多个参数，则由逗号分隔。任何空白和逗号都不是参数值的一部分。每个参数的文本通过变量替换和函数调用进行处理，生成参数值，即函数作用的文本。替换按照参数出现的顺序进行。

逗号和不匹配的括号或花括号不能出现在参数的文本中；第一个参数的文本不允许出现领先空格。这些字符可以通过变量替换放入参数值中。首先定义值为孤立逗号和空格的变量，然后在需要这些字符的地方替换这些变量：

```make
comma := ,
empty =
space := $(empty) $(empty)
foo := a b c
bar := $(subst $(space),$(comma),$(foo))
# bar 现在是 'a,b,c'.
```

在这里，`subst` 函数通过 `foo` 的值将每个空格替换为逗号，并替换该结果。

## 8.2 字符串替换与分析函数

这里有一些操作字符串的函数：

```
$(subst from,to,text)
```

对文本 `text` 执行文本替换：`from` 的每个出现处都会被替换为 `to`。结果由该函数调用替换。例如，

```
$(subst ee,EE,feet on the street)
```

替换字符串为 'fEEt on the strEEt'。

```
$(patsubst pattern,replacement,text)
```

在 `text` 中查找匹配 `pattern` 的由空格分隔的单词，并将它们替换为 `replacement`。这里，`pattern` 可以包含一个 `%`，它作为通配符，匹配单词内任意数量的字符。如果 `replacement` 也包含 `%`，则 `%` 将被替换为匹配 `pattern` 中 `%` 的文本。只有 `pattern` 和 `replacement` 中的第一个 `%` 会被这样处理；任何随后的 `%` 均保持不变。

`patsubst` 函数调用中的 `%` 字符可以通过前面的反斜杠（`\`）进行转义。用于转义 `%` 字符的反斜杠可以使用更多的反斜杠进行转义。转义 `%` 字符或其他反斜杠的反斜杠会在比较文件名之前从模式中移除，而那些没有转义 `%` 字符风险的反斜杠则保持原样。例如，模式 'the\weird\%pattern' 在操作性 `%` 字符之前有 'the\weird%'，之后有 'pattern'。最后两个反斜杠会被原样保留，因为它们不会影响任何字符。

单词之间的空格会被合并为单个空格字符；开头和结尾的空格会被丢弃。例如，

```
$(patsubst %.c,%.o,x.c.o bar c)
```

产生值 'x.c.o bar'。

`$(strip string)`

移除每个内部的一个或多个空格字符序列的开头和结尾空格，并替换为单个空格。因此，`$(strip a b c)` 的结果是 'a b c'。

`strip` 函数在与条件判断结合使用时非常有用。当使用 `ifeq` 或 `ifneq` 将内容与空字符串比较时，你通常希望仅包含空格的字符串匹配空字符串（见第7章 [条件判断]，第69 页）。

因此，以下可能无法产生想要的结果：

```make
.PHONY: all
ifeq "$needs_made" " "
all: $(needs_made)
else
all:;echo 'Nothing to make!'
endif
```

在 `ifneq` 指令中将变量引用 `$(needs_made)` 替换为函数调用 `$(strip $(needs_made))` 使其更加健壮。

`$(findstring find,in)`

在 `in` 中搜索 `find`。如果出现，值为 `find`；否则值为空。你可以在 GNU make 的条件中使用此函数来测试给定字符串中是否存在特定的子字符串。因此，这两个示例：

```
$(findstring a,a b c)
$(findstring a,b c)
```

分别产生值 'a' 和 ''（空字符串）。关于 `findstring` 的实际应用，请见第7.3 节 [测试标志]，第72 页。

```
$(filter pattern...,text)
```

返回 `text` 中所有匹配任何 `pattern` 单词的空格分隔的单词，移除任何不匹配的单词。模式使用 `%` 编写，就像 `patsubst` 函数中使用的模式一样。`filter` 函数可以从变量中分离不同类型的字符串（如文件名）。例如：

```make
sources := foo.c bar.c baz.s ugh.h
```

```
cc $(filter %.c,$(sources)) -o foo
```

表示 'foo' 依赖于 'foo.c'、'bar.c'、'baz.s' 和 'ugh.h'，但在给编译器的命令中应仅指定 'foo.c'、'bar.c' 和 'baz.s'。

```
$(filter-out pattern...,text)
```

返回 `text` 中不匹配任何 `pattern` 单词的所有空格分隔的单词，移除匹配一个或多个模式的单词。这与 `filter` 函数的作用完全相反。

### 8.3 文件名函数

若干内置扩展函数专门用于拆分文件名。

```

```

提取 `names` 中每个文件名的目录部分。文件名的目录部分是从开头到包含最后一个斜杠的内容。如果文件名不包含斜杠，目录部分为字符串 '.'。例如，
