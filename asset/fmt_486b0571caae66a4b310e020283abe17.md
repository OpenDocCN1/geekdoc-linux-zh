## 417 套字与 Windows 的集成

### Windows NT GUI TCP 套字服务器

![](img/5c85d865d33d2c2c3c815331ae6c6f4a_428_0.png)

用户在 GUI 应用程序的“股票交易部分”输入交易信息。当点击“执行交易”按钮时，交易信息被封装进 `XPTransaction` 记录中，消息发送到 UNIX UDP 股票市场持仓跟踪系统。服务器返回一个新的 `XPTransaction` 记录，包含用户在该代码的仓位。专门接收套字的线程捕获消息并调用 `CStockPosition-ClientDlg` 的 `vldUpdatePosition()` 方法。`vldUpdatePosition()` 可以更新当天的当前仓位或将新仓位添加到显示中。`XPUdpSocket` 的 `iReceiveMessage()` 是多线程的，用户仍然可以访问 GUI 界面并滚动查看其当前仓位或执行另一笔交易。列表 5.41–45 显示了详细说明套字操作线程化的部分列表。

### 使用 UDP 的 `CStockPositionDlg` 类 `OnInitDialog()` 方法

`OnInitDialog()` 在股票仓对话框显示之前被调用。这包含了在用户访问对话框之前必须完成的所有处理。所需的处理包括初始化 `CStockPositionClientDlg` 的 `XPCudpSocket`，一旦创建 UDP 套接字，它将绑定到套接字端口。最后，创建并派生从持仓服务器接收消息的线程。该派生线程被传递 `CStockPositionDlg` 的指针，以便其在接收到消息时调用方法来更新 GUI 界面。
