### htag
邮件、新闻和 FidoNet 消息标签工具。这是一个标签工具，但现在过度设计了，它可以你想做的一切、我想做的一切，并用标签完成。或者至少你会编写相应的插件。来自 Debian 3.0rt `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### htcheck
检查无效/外部链接的工具 `htcheck` 不仅仅是一个链接检查器。它是用 `C++` 编写的 Linux 系统控制应用程序，源自互联网上最好的搜索引擎 (`GNU PL`) `ht/Dig`。它可以从 `HTTP/1.1` 获取信息并将其存储在 `MySQL` 数据库中，对于小型域名或内网特别有用。它的目的是帮助网站管理员管理一个或多个站点：在“爬取”之后，`htcheck` 提供非常有摘要和报告，包括断链、未找到锚点、内容类型和 HTTP 状态码。来自 Debian 3.0 `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### htdig
`ht/Dig` 系统用于小型域名或内网的 Web 搜索和索引系统。该系统并不是取代强大的全球搜索，而是为了满足单个公司、校园甚至网站某个子部分的搜索需求。来自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### htdig
内网或小型互联网的 WWW 搜索 `ht/Dig` 系统是用于小型域名或内网的完整世界网络索引和搜索系统。该系统并不是取代如 Lycos、Inofex、Weckaver 和 AltaVista 等强大的全球搜索系统。它是为了满足单个公司、校园甚至网站某个部分的搜索需求。与某些基于 WAIS 或 Web 服务器的搜索引擎不同，`ht/Dig` 可以跨越站点的多个服务器。不同 Web 服务器的类型并不重要，重要的是它们理解 `HTTP/1.0` 协议。

### htget
