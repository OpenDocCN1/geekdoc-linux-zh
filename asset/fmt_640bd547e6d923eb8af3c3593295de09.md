
## 监控系统负载 205

要忽略字母字符，我们使用带有 `-v` 选项的 `egrep` 命令，表示显示输出中除匹配行以外的所有内容。要指定所有字母，我们使用以下表达式：

```bash
[a-zA-Z]
```

然后为了删除所有空行，我们使用表达式：

```bash
^$
```

脱字符字符 `^` 表示开头，为了指定空行，我们使用美元符号 `$`。如果你想删除文件中所有用井号 (`#`) 注释掉的行，我们就添加 `#`。

当我们将这两个表达式合并到一个扩展 grep (`egrep`) 中时，我们得到了如下正则表达式：

```bash
egrep -v '[a-zA-Z]$'
```

此时，我们只留下了以下输出：

| 23.15 | 0.00 | 26.09 | 50.76 |

| 31.77 | 0.00 | 21.79 | 46.44 |

这带我们进入了另一种情况，使用 `case` 语句中的 `uname` 命令根据 Unix 变体来分配给 `iostat` 命令使用的开关。这里也定义了 `F1`、`F2`、`F3` 和 `F4` 变量，对应于我们需要从命令输出中提取的数据的位置索引。

现在是第一次使用。查看提取 CPU 统计数据的 `iostat` 命令。

```bash
iostat $SWITCH $SECS $INTERVAL -v '^[a-zA-Z]' | grep '$$' \
  awk '{print $F1, $F2, $F3, $F4}' | \
  while read FIRST SECOND THIRD FOURTH
```

`iostat` 语句的开头使用了由操作系统定义的正确开关，以及采样间隔间隔（这次是两个）。从 `iostat` 语句的这部分，我们得到了 Linux 上的输出。

```bash
SWITCH=-c'
SECS=300
INTERVAL=2
```

```bash
iostat $SWITCH $SECS $INTERVAL
```

Linux 2.4.2-2 (bambam) 07/31/2002

|---|---|---|---|---|

| 23.15 | 0.00 | 26.09 | 50.76 | |

| avg-cpu: | %user | %nice | %sys | %idle |

| 31.77 | 0.00 | 21.79 | 46.44 | |

记住第一行数据是自上次系统重启以来的 CPU 负载平均值，因此我们对输出的最后一行感兴趣。如果你记得 `iostat` 命令的语法，此输出的共同点是数据行完全由数字组成。使用这作为准则来提取数据，我们如下所示向 `iostat` 命令中添加了内容：

```bash
iostat $SWITCH $SECS $INTERVAL | grep '^[a-zA-Z]' | grep '$'
```

向之前的命令添加的 `grep` 为我们做了两件事：首先，它排除了输出中所有包含字母的行，只留下带有数字的行。其次，我们得到的是移除了输出中的所有空行。让我们来看每一项。

`echo "共有 $INTERVAL 个采样周期，其中"`

`echo "每个间隔持续 $SECS 秒"`

`echo "\n...正在收集统计信息...\n"`

```bash
iostat $SWITCH $INTERVAL | grep -v '^[a-zA-Z]|^$/' \
| awk '{ print "$F1", "$F2", "$F3", "$F4}' \
| while read FIRST SECOND FOURTH

if ((STATCOUNT == 1)) # 循环计数器，用于获取第二组
then # 由 "iostat" 产生的数据

case $OS in # 根据 Unix 变体显示结果
AIX)
    echo "\n用户部分是 ${FIRST}"
    echo "系统部分是 ${SECOND}"
    echo "空闲部分是 ${THIRD}"
    echo "I/O 等待状态是 ${FOURTH}\n"
    ;
Hp-UX)
    echo "\n用户部分是 ${FIRST}"
    echo "Nice 部分是 ${SECOND}"
    echo "系统部分是 ${THIRD}"
    echo "空闲时间是 ${FOURTH}\n"
    ;
Sun0)
    echo "\n用户部分是 ${FIRST}"
    echo "系统部分是 ${SECOND}"
    echo "I/O 等待是 ${FOURTH}\n"
        ;
esac

fi
((STATCOUNT = STATCOUNT + 1)) # 计数计数器
done
```
