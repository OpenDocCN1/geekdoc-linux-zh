## 一等对象

Python 中的所有对象都被说是“一等对象”。这意味着所有可以由标识符命名的对象都具有地位。它意味着所有可以命名的对象都可以被视为数据。例如，这里有一个包含两个值的字典：

```python
items = {
  'number': 42,
  'text': "Hello World"
}
```

Python 中一等对象的这一特性并没有被新程序员充分理解。然而，它可以用于编写且灵活的代码。例如，假设你有一行文本如 `"GOOD,100,490.10"`，你想将其转换为字段列表（这些字段是一等对象）并执行简单的列表操作：你可以通过创建一个带有相应类型转换的字段列表来实现。

```python
>>> line = "GOOD,100,490.10"
>>> field_types = [str, int, float]
>>> raw_fields = line.split(',')
>>> fields = [ty(val) for ty,val in zip(field_types,raw_fields)]
>>> fields
['GOOD', 100, 490.1000000000002]
>>>
```
