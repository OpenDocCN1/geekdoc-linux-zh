
`-n` 将排序键限制为初始数字字符串，该字符串由可选的空白字符、可选的减号以及零或多个数字组成（可选的进制字符和千分位分隔符，由当前区域定义），按算术值进行排序。空字符串被视为 `0`。开头的 `0` 和符号不影响顺序。

`-r` 反转比较方向。

# 字段分隔符选项

你可以使用以下选项更改对字段分隔符的处理。

- `-b` 在确定受限排序键的起始和结束位置时，忽略领先空白字符。如果你在第一个排序键之前指定 `-b` 选项，则将其应用于所有排序键。否则，你可以独立地将 `-b` 附加到 `-k field-start`、`field-end` 或 `pos1-pos2` 参数。
- `-t` 使用 `char` 作为字段分隔符。`char` 不被视为字段的一部分（尽管你可以将其包含在排序键中）。`char` 的每次出现都是有利的（例如，`charchar` 分隔了一个空字段）。如果你不指定 `-t`，则使用空白字符作为默认字段分隔符；紧随非空白字符的每个最大非空空白序列都是字段分隔符。

# 排序键选项

你可以使用以下选项指定排序键。

- `-k keydef` 定义一个受限排序键。

该定义的格式为：

```
-k field-start[type], field-end[type]
```

`type` 不被视为字段的一部分（尽管你可以将其包含在排序键中）。`type` 的每次出现都是有利的（例如，`charchar` 分隔了一个空字段）。如果你不指定 `-t`，则使用空白字符作为默认字段分隔符；紧随非空白字符的每个最大非空空白序列都是字段分隔符。

`field-start` 和 `field-end` 定义了从 `field-start` 开始到 `field-end` 结束的字段。

`type` 是 `bdfmMn` 列表中的修饰符。`b` 修饰符类似于 `-b` 选项但仅适用于其附加的 `field-start` 或 `field-end`。字段内的字符从第一个非空白字符开始计数（这分别适用于 `first-character` 和 `last-character`）。其他修饰符类似于相应的选项，但仅适用于其附加的键字段。

当有多个键字段时，后来的键在所有前面的键相等之后进行比较。除非你指定 `-u` 选项，否则相等相等的行将按如下方式排序。以下表示法定义了一个从 `field-start` 开始到 `field-end` 结束（包含在内）的键字段：

```
-k field-start[type]
```

缺失的 `field-end` 意味着行的最后一个字符。

`field-start` 位于字段。如果 `field-start` 超出了行末尾，则键字段为空。

字段由最大非分隔符字符序列组成，在缺少 `-t` 的情况下，任何前面的字段分隔符。

`keydef` 选项的 `field-start` 部分格式为：`field-number[.first-character]`

字段和内部字符从 `1` 开始编号。`field-number` 和 `first-character` 被解释为正整数，指定作为排序键部分的第一个字符。如果你省略了 `.first-character`，默认是字段的第一个字符。

`keydef` 选项的 `field-end` 部分格式为 `field-start.{last-character}`

`field-number` 与上述 `field-start` 相同。`last-character` 被解释为非负整数，指定作为排序键部分的最后一个字符。如果 `last-character` 值为 `0` 或省略 `.last-character`，默认是 `field-number` 指定字段的最后一个字符。

如果 `-b` 或 `b` 修饰符有效，字段内的字符从字段中的第一个非空白字符计数。（这分别适用于 `first-character` 和 `last-character`。）
