# 第 2 节，Korn 简介，第 32 页

查看昨天的销售交易日志，看看你是否能给我大概的想法，昨天有多少客户购买了 GO-9000 手机。

## 你的第一个任务：

你需要找出昨天有多少客户购买了型号号为 GO-9000 的手机。销售日志存储在名为 `/opt/var/LOGS` 的目录中。你需要查看的日志名为 `sales.Apr15`。

一个典型的输入记录如下：

```
APR15 08:09:57 GO-360T MOBILE_PHONE 1 37.77 37.77
```

- 记录中的字段为：
1. 日期 (`APR15`)
2. 时间 (`08:09:57`, hh:mm:ss)
3. 类型 (`GO-360T`)
4. 描述 (`MOBILE_PHONE`)
5. 购买数量 (`1`)
6. 单位单价 (`$37.77`)
7. 交易总额 (`$37.77`)

（如果客户买了两部 GO-360T 手机，那么交易总额将是 `$75.54`。）

你不需要写一个脚本来满足老板的要求。一个命令就足够了：

```
grep -c 'GO-9000' /opt/var/LOGS/sales.Apr15
```
`-c` 意味着“计数”（count）。

或者你可以这样做：

```
grep 'GO-9000' /opt/var/LOGS/sales.Apr15 | wc -l
```

第一条命令更有效：
`grep` 命令用于“抓取”日志文件中任何包含型号号 GO-9000 的记录；`grep` 的 `-c` 提供了包含该型号的记录计数。

在第二种解决方案中，没有使用 `-c`，因此我们需要某种方法来统计从日志文件中筛选出的记录数量。`wc -l` 为我们统计了行数。这两种解决方案都能为我们提供所需的数字：74。

老板再次来到你的办公桌前。（当这种情况发生时，请感到高兴。）市场部经理 Sue 想知道在在周日的报纸上看到全版广告后，有多少客户购买了 GO-360T 手机。你能按小时拆分吗？

老板定义一个“好日子”是指，如果有更多的人来接订单，他们可以卖出双倍的手机。换句话说，你需要尽快把这些信息交给 Sue。

再次，一个典型的输入记录如下：

APR15 08:09:57 GO-360T MOBILE_PHONE 1 37.77 37.77

- 记录中的字段为：
1. 日期 (`APR15`)
2. 时间 (`08:09:57`, hh:mm:ss)
3. 类型 (`GO-360T`)
4. 描述 (`MOBILE_PHONE`)
5. 购买数量 (`1`)

销售从早上 8 点开始，到下午 6 点（1800）结束。好了，你的第一个任务是获取周一日志中所有涉及 GO-360T 手机的记录。知道如何做：

```
grep 'GO-360T' /opt/var/LOGS/sales.Apr15
```

由于你全天都会使用这些记录，你决定将这些记录放入一个单独的文件：

```
grep 'GO-360T' /opt/var/LOGS/sales.Apr15 > /tmp/GO360T
```

很好；现在所有与 GO-360T 销售相关的记录都在 `/tmp/GO360T` 中（`/opt/var/LOGS/sales.Apr15` 中的记录未变）。

接下来，我们需要确定早上 8 点到 9 点之间有多少客户购买了 GO-360T 手机。假设 `/tmp/GO360T` 中的一个典型记录如下：
```
APR15 08:09:57 GO-360T MOBILE_PHONE 1 37.77 37.77
```
如果我们 `grep 'APR15 08'`，我们将抓取发生在 08:00:00 (hh:mm:ss) 到 08:59:59 之间的每一次交易。我们将使用 `-c` 选项来计数记录：

```
grep -c 'APR15 08' /tmp/GO360T
```
输出命令为 '19'，告诉我们 4 月 15 日早上 8 点到 9 点之间有 19 次涉及 GO-360T 手机的交易。

要获取下午 5 点（1700）到下午 6 点（1800）之间的销售情况，你使用这个命令：

```
grep -c 'APR15 17' /tmp/GO360T
```
你针对早上 8 点到下午 6 点之间的每个小时发布此命令，然后在老板离开后将统计数据交给 Sue。
