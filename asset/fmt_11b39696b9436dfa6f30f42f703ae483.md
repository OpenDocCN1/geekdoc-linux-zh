
### 图 3.17 `readline` 函数：从描述符一次一个字节字节地读取文本。

我们的这三个函数会查找错误 `EINTR`（系统调用被捕获的信号中断，我们将在 5.9 节中详细讨论），并在发生错误时继续读取。我们在这里处理该错误，而不是强制调用者再次调用 `read` 或 `write`，因为这三个函数的目的就是为了防止调用者不得不处理短计数（short count）。

在第 14.3 节中，我们将提到 `MSG_WAITALL` 标志可以与 `recv` 函数一起使用，以替代对单独 `read` 函数的需求。

注意，我们的 `readline` 函数会为每个字节的数据调用一次系统的 `read` 函数。这是非常低效的，这也是为什么我们在代码中注释说它“极其缓慢（PAINFULLY SLOW）”。在从套接字读取行时，使用标准 I/O 库（称为“stdio”）是非常具有吸引力的。我们将在 14.8 节详细讨论这种方法，但这可能是一条危险的路径。解决此性能问题的 stdio 缓冲也会产生许多逻辑问题，导致你的应用程序中出现难以发现的 bug。原因为 stdio 缓冲区的状态没有暴露。为了进一步解释这一点，请考虑客户端和服务器之间基于行的协议，随着时间的推移，可能会实现多个使用 stdio 的客户端和服务器（这非常常见；例如，许多 Web 浏览器和 Web 服务器是独立按照 HTTP 规范编写的）。良好的“防御性编程”技术要求这些程序不要期望对方遵循网络协议，而是要检查意外流量。协议违规应该被报告为错误，以便察觉并修复 bug（并检测到恶意尝试），同时也让网络应用程序能够从问题流量中恢复并可能继续工作。使用 stdio 缓冲数据以提高性能与这些目标背道而驰；应用程序无办法判断在任何给定时刻 stdio 缓冲区中是否存有意外数据。

有许多基于行的网络协议，如 `SMTP`、`HTTP`、`FTP` 连接协议和 `finger`。对行的操作愿望反复出现。我们的建议是基于缓冲区（buffers）而不是行来思考。编写你的代码来读取数据缓冲区，如果输出了行，则检查缓冲区是否包含该行。

图 3.18 显示了 `readline` 函数的一个更快的版本，它使用自己的缓冲而不是 stdio。最重要的是，`readline` 缓冲区的状态是暴露的，因此调用者可以清楚地看到接收了什么。即使有了这个功能，`readline` 可能会出现问题，正如我们在 6.3 节中看到的，编写不当的程序可能会发现它自己在 `select` 中等待已经接收并存储在缓冲区中的数据。对于这一点，除非修改 `readn` 以也检查缓冲区，否则混合 `read` 和 `readline` 调用将不起。

```c
#include "unp.h"

static int read_cnt;

static char *read_ptr;

static char read_buf[MAXLINE];

static size_t n;

my_readn(int fd, char *ptr) {
    if (read_cnt <= 0) {
        again:
        if ((read_cnt = read(fd, read_buf, sizeof(read_buf))) < 0) {
            if (errno == EINTR)
                goto again;
            return (-1);
        } else if (read_cnt == 0)
            return (0);
        read_ptr = read_buf;
    }
    read_cnt--;
    *ptr = *read_ptr++;
    return (n);
}
```

```c
ssize_t readline(int fd, void *vptr, size_t maxlen) {
    ssize_t n, rc;
    char c, *ptr;
    ptr = vptr;
    for (n = 1; n < maxlen; n++) {
        if ((rc = my_read(fd, &c)) == 1) {
            *ptr++ = c;
            if (c == '\n') { /* 存储了换行符，类似于 fgets() */
                break;
            } else if (rc == 0) {
            *ptr = 0; /* EOF，读取了 n 字节 */
            return (n - 1);
        } else {
            return (-1); /* 错误，read() 设置了 errno */
        }
    }
    *ptr = 0; /* 像 gets() 一样空终止 */
    return (n);
}

ssize_t readlinebuf(void **vptr) {
    if (read_cnt > 0) {
        *vptr = read_ptr;
        return (read_cnt);
    }
}
```
