# `telnet [-8ELadr] [-S tos] [-escapechar] [-l user] [-n tracefile] [host [port]]`

通过 `telnet` 协议与网络上的另一台机器交互。登录后，网络访问几乎是透明的。也就是说，你永远不知道自己是通过网络登录而不是直接连线到机器的。

# `encrypt argument ...`

控制 `telnet` 加密。有效参数有：

- `- type type` 指定使用的加密类型。
