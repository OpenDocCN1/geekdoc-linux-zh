
# Linux 词典

## GSK set
`GSK set` 是 `X` 命令行工具集的图形前端。它是一个用 `Glade` 设计的应用。`GSK set` 可以自动重复、重复点击、铃声、鼠标、屏幕保护程序和 `DPMS` 参数。它有一个字体编辑器。设置可以保存到文件中。来自 `Debian 3.0r0 APT` `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## compress
在原地处理可执行文件。来自 `wathis` `http://www.tldp.org/LDP/linux-Dictionary/html/index.html`
- 一个免费的程序，通常作为 `Unix` 命令用于文件压缩，即 `gzip`（它也适用于 `MS–DOS`），它压缩文件并在文件名后添加 `'.z'` 或 `'.gz'`。来自 `KADOWKEV` `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## Linux 字典
`gzip` 的参考文档。`Gzip` 使用 `Lempel–Ziv` 编码 (`LZ77`) 缩小指定文件的大小。每当如此，每个文件都被扩展名为 `'.gz'` 的文件替换，同时保持相同的所有模式、访问和修改时间。来自 `Linux Guide @FirstLinuxn` `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

## gzip
`gzip` 包包含了流行的 `GNU gzip` 数据压缩程序。`Gzipped` 文件具有 `.gz` 扩展名。应该在您的 `Linux` 系统上安装 `gzip`，因为它是一个非常常用的数据压缩程序。来自 `Redhat 8.0 RPM` `http://www.tdldp.org/LDP/Linux-Dictionary/html/index.html`

## Gzip (GNU zip)
用于 `UNIX/Linux` 的原始文件压缩程序。最新版本生成具有 `.gz` 扩展名的文件。（`.z` 或 `Z` 扩展名表示旧版本的 `Gzip`。）压缩用于紧缩文件以节省存储空间并缩短传输时间。（与 `Tar` 结合使用时，生成的扩展扩展可能是 `.tgz`、`.tar.gz` 或 `.tar.Z`。）来自 `I-gloss` `http://www.tdldp.org/LDP/Linux-Dictionary/html/index.html`

## H

### h2ph
将 `.C` 头文件转换为 `.ph` `Perl` 头文件。来自 `Whatis` `http://www.tdldp.org/LDP/Linux-Dictionary/html/index.html`

### h2xs
将 `.C` 头文件转换为 `Perl` 扩展。来自 `whatis` `http://www.tdldp.org/LDP/Linux-Dictionary/html/index.html`

### H4P
高性能并行处理项目 (`ICI`) 来自 `VERA` `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### HA Linux
摩托罗拉计算机组为 `Linux` 开发的高级高可用性软件。通常运行在摩托罗拉平台上。特殊/微型/来自 `LWN` 分发列表 `http://www.tdldp.org/LDP/Linux-Dictionary/html/index.html`

[已弃] 一种试图通过寻找发现敏感信息的恶意黑客。“密码黑客”，“网络黑客”。对此的正确术语是 `cracker`。“`hacker`”还倾向于在网络定义的社区中竞争成员身份。关于此的讨论，请参考如何成为黑客 FAQ。它还意味着描述的人被认为遵循某种版本的黑客准则（见黑客准则）。被他人描述为黑客比自认为更好。黑客认为自己是精英（基于能力的优胜劣），欢迎新成员。因此，认同黑客身份会有特定的自豪感（如果你声称是且不会被标记为虚假）。这个术语似乎在 1960 年代被黑客文化 `TMRC` 和 `MIT Lab` 作为标志采用。来自 1950 年代的青少年爱好者。来自 `Junior Dictionary` `http://www.tdlp.org/LDP/linux-Dictionary/index.html`
