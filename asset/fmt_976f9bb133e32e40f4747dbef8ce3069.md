
Swatch 程序将位于 `/usr/local/bin` 目录。

Swatch 需要一个配置文件。默认情况下，该文件是调用用户家目录下的 `.swatchrc`。列表 6.5 中的简单示例源于随 Swatch 软件包分发的示例。

### 列表 6.5 Swatch 配置示例

```
# 系统崩溃并停机

watchfor // (panic|halt)

echo

bell

mail

exec "call_pager 3667615 0911"

# 系统重启

watchfor /SunOS Release/

echo

bell

mail

exec "call_pager 3667615 0411"
```
