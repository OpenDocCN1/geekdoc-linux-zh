```

Usage: onparams { -a -d DBspace [-s size]
       -d -l log [-y]
       -p -s size [-d DBspace] [-y] }

-a - 添加逻辑日志
-d - 删除逻辑日志
-p - 修改物理日志的大小和位置
-y - 自动对所有提示回答“yes”。
```

我们将使用 `-p` 选项创建一个 20MB 的 `physdb`。记得，我们最初为物理日志分配了 50MB，但我们只使用了 20MB。这将为我们留出增长空间。

要创建 `physds`，请使用以下 `onparams` 命令：

```
$ onparams -p -s -d physds -y
```
