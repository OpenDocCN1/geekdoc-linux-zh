
## 为什么 CD-ROM 的文件名全大写并带有 ;1 版本号？

HP-UX 在 CD-ROM 文件名上使用这种约定，是因为它们只支持 ISO 9660。这导致它无法将全大写的 8.3 字符文件名转换为小写，也不会删除 `;` 版本号，因为它们是完全按照这种方式存储在 CD-ROM 上的。

HP-UX 存储这些文件名没有问题，但当你尝试进行简单的移动操作时（例如对这些文件），就会变成一个真正的问题，因为 `;` 是命令分隔符。

虽然这个问题更多是一个令人恼的困扰而非故障，但当并非为这种文件名格式编写的软件尝试访问这些文件时，真正的麻烦才开始出现。

基本上，你可以通过以下三种方法来解决这个问题：

1. 编写一个脚本（或使用 `cdrutil.ksh`，在许多存档站点均可用），通过创建一系列符号链接来执行转换。这些链接必须分别在 `mount` 和 `umount` 命令后创建和删除。某些 CD-ROM 可能需要 15-45 分钟来完成此任务。

2. 获取补丁（这些按系列号列出）：

- `PHKL_6075: s700 at 9.03, 9.05, 9.07 (无 9.01 或早期版本)`
- `PHKL_6272: s700: 10.01`
- `PHKL_6076: s700: 10.00`
- `PHKL_6338: s800: 9.04 (9.04 之前均无)`
- `PHKL_6077: s800: 10.00`
- `PHKL_6273: s800: 10.01`

这些补丁为 `cdfs` 代码添加了修改，它可以转换所有挂载的 CD-ROM（而非有选择地）以完成相同的任务。此补丁没有添加额外的 POSIX 或 RockRidge 扩展等文件系统支持。此补丁只能通过 `adb` 修改内核来激活。补丁中了修改 9.*xx* 内核的示例。注意，此补丁会同时影响系统中的每一个挂载的 CD-ROM。

3. 通过与 Young Minds, Inc 的协议，便携文件系统 `PFS` 代码已提供运行 9.*xx* 和 10.*xx* 的 700 和 800 系列系统。该代码不仅实现了小写转换和版本删除（两者都是独立选项，可以为每个 CD-ROM 指定开启或关闭），还提供了 RockRidge 扩展（长文件名、所有者、权限）。该代码可在 1995 年 11-12 月的应用 CD-ROM 和 700 系列磁带上，以及 1996 年 1-2 月的应用 CD-ROM 和磁带上获取。可以随时购买这些介质。`PFS` 处理 CD-ROM 文件名的导出以及从其他 HP-UX 系统导入这些名称，是解决 CD-ROM 兼容性最通用的解决方案。

**http://support.mayfield.hp.com/**

**SD-UX 是什么，为什么它取代了 `/etc/update` 工具？**

遗憾的是，这意味着 `/etc/update` 无法识别这种格式的 10.x 软件，反之亦然。

不过 SD 提供了比 `/etc/update` 更好的工具。SD 还提供了三个新的用户界面来取代 `/etc/update` 的用户界面：

1. 适用于 `swinstall`、`swcopy` 和 `swremove` 命令的交互式图形用户界面。
2. 适用于 ASCII 终端（在 S800 上）的 `swinstall`、`swcopy` 和 `swremove` 命令的交互式用户界面。
3. 适用于所有命令的非交互式命令行用户界面。

**Linux 是什么？**

Linux 是一种运行在 Intel、Sun、Digital Equipment 等计算机上的类 Unix 操作系统。尽管 Linux 被某些人诟病，但受到许多人的赞誉，它没有被任何人拥有或控制，正在稳步增长。最初 1991 年 10 月 5 日由赫尔辛基的作者 Linus Torvalds 作为爱好发布，支持多任务、多用户、多种协议，但不限于：TCP/IP, SMTP, SMB, X.25, IPX, NNTP, SLIP, CSLIP, PPP, NFS 和 LocalTalk。作为个人电脑 Unix，Linux 能够充分满足世界上多样化计算社区的需求——以更低的成本，且很多时候没有速度损失。

**怎么读音 Linux？**

有些人读作 *Lie-nucks*，而另一些人读作 *Lih-nucks*（类似于 *linen*）。一位在华盛顿特区工作的 AIX 系统管理员，也是秘密的 Linux 用户，有一个令人困扰的习惯，把 Linux 读作 *Lie-knew*。

当然，在这个计算机时代，为什么不听听 Linus Torvalds 本人的读音呢？对于喜欢使用搜索引擎的人，这里有一个练习：找到并下载 `.au` 文件，然后通过以下命令听到 *Linux*：

```
# cat english.au > /dev/audio
# play english.au
```

提示：你可以在芬兰找到多个副本。

为什么要用 Linux？

为什么不呢？你可能可以在 Linux 下完成在商业操作系统无法完成的任务。许多计算机和文件系统支持多个操作系统，但并不是所有的操作系统都支持所有的需求。许多昂贵的工作站提供特殊服务或支持特殊任务，但成本高昂。

作为个人电脑 Unix，Linux 可以很好地支持并满足许多需求。

Linux 的一个很棒特性是它收集了其他 Unix 版本的最佳特性。无论是调整你的 X GUI 还是配置网络，你都能找到从其他操作系统移植过来的喜爱的工具，或者许多独特的 Linux 工具。并不是每个人都是程序员，但我们都希望计算体验按照我们想要的方式外观和运行。在 Linux 中，你可以调整和定制你的环境。

选择和创造的自由是 Linux 的另一个特性。不喜欢某个程序的运行方式？修改它！因为你拥有源代码，你可以自由地进行改进并分享你的更改。

## 有多少人在使用 Linux？

这是一个好问题，你的猜测和我观点一样。试图弄清楚有多少人使用 Linux 的困难之一在于，它不需要注册。有些供应商拥有出货的 CD-ROM 数量数据，但你实际上无法得知具体数字，因为任何人都可以通过互联网获取副本或进行升级。

当营销人员在思考诸如全球范围内有 200 万到 1000 万用户这样的数字时，现实是，许多制造商、公司和顾问正在通过 Linux 赚钱，而政府、大学和机构正在使用 Linux 节省费用。

根据 Linux 文档项目的最后统计，有 125 家商业服务器提供商和互联网服务提供商（ISP）以及近 80 处政府、学术和组织机构正在使用 Linux。这个数字包括思科 Systems 和 Erol's Internet 等公司；德克萨斯州、密西西比州和格但斯克的大学；以及美国海岸卫队和国家科学基金会等政府机构。

## Linux 有版权保护吗？

感谢林斯·托瓦尔斯（Linus Torvalds）和自由软件基金会的 GNU 通用公共许可证（GPL），Linux 是“反版权的”（copylefted），可以免费分发和使用。虽然林斯·托瓦尔斯对内核拥有版权，但 Linux 可以被修改并获利出售，不过仅限于 GPL 的条款。Linux 发行版自带的大多数程序也受 GPL 保护。

Linux 不是免费软件或共享软件，发行版中包含的一些程序可能不属于 GNU 通用公共许可证；请始终检查你的程序文档或阅读手册页。

欲了解更多信息，请查看你的 `/usr` 目录、磁带、CD-ROM 或软盘；你可以在那里找到 GPL 的副本。想找找它？尝试输入以下命令：

```
# find /usr -name *LGPL* -print
```

## 我如何在 Linux 下打印？

Linux 使用 BSD 打印后台守护进程 `lpd` 以及相关程序（如 `lpr`、`lpq` 和 `lprm`）来处理打印任务。位于 `/etc/printcap` 的打印数据库包含了打印设备能力的定义。这些命名为 `lp0`、`lp1` 和 `lp2` 的设备可以代表不同类型的打印机。

大多数 PC Linux 用户通过并行口连接打印机。首先，查看 `/etc/printcap`；然后选择打印机并尝试输入：

```
\# cat myfile.txt >/dev/lp0
```

如果你遇到缺少回车或换行的“阶梯”问题，请查看 `/usr/doc` 下的 `Printing-HOWTO`。你可以通过为打印机的 `/etc/printcap` 条目添加过滤器来解决这个问题。RedHat Linux 用户可以使用 `printtool` 程序，但另一个很好的解决方案是由 Andreas Klemm 和 Thomas Buesgens 提供的名为 `apsfilter` 的打印包。安装 `apsfilter` 很快，使用它更加简单。你不仅可以避免阶梯效应，还可以将廉价的喷墨打印机变成彩色 PostScript 打印机！来自 Netscape 的彩色 `.TIF` 图形或 X 窗口，请在 **sunsite.unc.edu**/pub/system/Printing** 查找该程序和其他。

## 我可以获得什么样的源代码？

任何在 GNU GPL 下发布的软件必须包含源代码，或提供源代码。这一重要限制无疑促进了 Linux 的普及。你通常可以获得几乎每个程序的源代码。然而，许多作者或组织（如 XFree86）只发布程序的二进制版本。当你对某个程序或软件集合产生疑问时，请始终检查其手册页或文档。

## 我可以使用我的互联网服务提供商使用 Linux 吗？

如果你愿意投入时间、调试自己的问题，并具备提出正确技术问题的能力，你不应该与你的 ISP 遇到任何问题。大多数人使用 PPP 连接互联网。一种方法是先使用 `kermit`、`cu`、`pcomm` 或 `minicom` 确保你的调制器工作正常。然后，有了以下信息，你就可以建立连接。

你需要知道：

- 你的登录和密码
- 你的 ISP 的主、 DNS 服务器的 IP 地址
- 你的 ISP 是否动态分配 IP 地址
- 你的 ISP 是否使用邮局协议（POP）处理邮件
- 你的 ISP 邮件服务器名称
- 你的 ISP 新闻服务器名称

之后，你需要在 `/etc/resolv.conf` 中添加 DNS 地址，在 `/etc/ntpserver` 中添加新闻服务器名称，编辑 `/etc/ppp` 中的两个文件——`ppp-on` 和 `ppp-on-dialer`——以反映你的 ISP 电话号码以及你的登录和密码。然后尝试输入

```
\# /etc/ppp/ppp-on
```

启动你的 PPP 连接。但要警告的是，这种简单直接的方法假设了 root 权限。你应该多花一点精力，学习如何设置 UID 为 root，或者使用 root 任务程序。

想获取你的邮件吗？如果你使用 pine 邮件传输器，请编辑目录下的 `.pinerc` 文件，并添加你的 ISP 邮件服务器和域名。假设你的 ISP 支持 POP3 协议，请连接并尝试输入 `# popclient -3 -u your_login -p your_password your.isp.com`

## Solaris 2.x 运行在什么上？

Solaris 2.0 版本仅运行在桌面级 SPARCstations 以及其他少量 Sun 机器上。

实际上 Solaris 2.0 有两个版本：SPARC 版本和 "x86" 版本。

SPARCstations 及其克隆机将运行 Solaris 2.1（及以上）的 SPARC 版本。它们也适用于 Sun-4 家族的所有型号。对于 4/110 和 260/280，不支持 FPU（浮点运算单元）。这意味着浮点运算可以进行，但速度非常慢。

从 2.5 开始，不再支持内核架构为 `sun4` 的机器。换句话说，`uname -m` 和 `arch -k` 返回 `sun4` 的机器，而不是那些这些命令返回 `sun4c`、`sun4m`、`sun4u` 或 `sun4d` 的机器。不支持的机器包括 sun4/110（不要与 SS4 @110MHz 混淆）、sun4/2xx、sun4/3xx 和 sun4/4xx。这些都是基于 VME 的桌面级/服务器配置。所有版本的 SPARC PROM 在 Solaris 2.x 下都应该可以工作，但你可能会遇到以下问题：

1. **启动分区任何部分相对于磁盘的偏移不得超过 1 GB，除非你拥有版本为 2.6 或更高版本的 PROM。** 注意点后面的数字不是小数，而是一个整数。因此，3.0 比 2.25 新，2.25 比 2.10 新，2.10 比 2.9 新，以此类推，直到 2.0 新，而 2.0 又比 1.6 新。

## 我的 Solaris 4.1.x 可以在 SunOS 5.x 上运行吗？

SunOS 5.x 包含一种名为二进制兼容（BCP）的模式，用于运行 4.1.x 程序。存在一些开销，因为它通过动态链接 4.1.x 程序来仿真 5.x 接口。直直到 Solaris 2.2，程序需要全链接。Solaris 2.3、2.4 及更高版本支持全链接程序。有一个例外：程序不遵守 `nsswitch.conf`。它们将使用 SunOS 4.x 的“如果存在 NIS 则回退文件”的方法。在这种情况下，程序可能需要 `passwd:compat` 行，并仅与 NIS 或 NIS+ 通信或从文件中读取。随着 Solaris 2.5 的发布，支持混合模式执行文件。混合模式执行文件具有部分静态和部分动态的性质，取决于具体的链接程度。据传 Sun 在未来某个某时刻会放弃二进制兼容，因此最好尽可能将软件迁移到原生 Solaris 2.x。

## 为什么我不能在 man 上进行上下文搜索？

与其标准的 `whatis` 文件不同，Solaris 使用了一个名为 `windex` 的手册页索引。你必须使用 `catman -w -M <man-page-directory>` 构建此索引。

遗憾的是，在 Solaris 2.1 中，这将导致大量的“行过长”消息，并在 `/usr/share/man` 中产生一个伪的 `windex` 文件，以及在 `/usr/openwin/man` 中产生核心转储。在 Solaris 2.2 中也有类似的问题，其中

```
catman
```
