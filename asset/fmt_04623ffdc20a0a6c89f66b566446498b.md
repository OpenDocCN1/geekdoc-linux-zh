
`castle$% nistblad -c hobby_tbl name=S,a+r,o+m hobby=S,a+r`

`hobbies.foo.com.`

`name` 列对所有人（即所有者、组和世界）具有读取权限，仅对所有者具有修改权限。`hobby` 列所有人可读，但任何人无法修改。

在以下示例中，如果没有指定访问权限，则表的访问权限将来自标准默认值或 `NIS_DEFAULTS` 变量。

以下示例向此表添加条目。

```
castle$% nistblad -a name=bob hobby+skiing hobbies.foo.com.
castle$% nistblad -a name=sue hobby+skiing hobbies.foo.com.
castle$% nistblad -a name=ted hobby+swimming hobbies.foo.com.
```

以下示例向连接路径添加内容。

```
castle$% nistblad -u -p hobbies.bar.com:hobbies.baz.com: hobbies
```

### 935 nistblad

以下示例从列表中删除了滑雪者。

```
castle% nistblad -R hobby=skiing hobbies.foo.com.
```

> 注意 — 上一个示例使用了 `-R` 选项。该选项会失败，因为有两个值为 `skiing` 的条目。

要创建一个未设置任何标志的列表格，只需提供名称并在后面加上等号 (`=`)。

```
castle% nistblad -c notes_tbl name=S,a+r,o+m note=notes.foo.com.
```

以下示例创建了一个名为 `notes.foo.com.`、类型为 `notes_tbl` 的表，包含 `name` 和 `note` 两个列。`note` 列不可搜索。

当以值字符串的形式输入列数据时：

```
castle% nistblad -a fullname="Joe User" nickname=Joe nicknames
```

如果对字符串的解析方式有任何疑问，最好将其包含引号内。

## Warnings

要修改其中一个条目（例如从 `bob` 改为 `robert`），以下命令是错误的。

```
castle nistblad -m name=robert [name=bob], hobbies
```

`[name=bob], hobbies` 是一个索引名称，字符 `[`（左括号）和 `]`（右括号）会被 Shell 解释。在使用 NIS+ 索引名称的形式输入条目名称时，必须使用单引号保护该名称，如下所示。

```
castle nistblad -m name=robert 'name=bob], hobbies'
```

可以指定一组默认值，以便你以后无法读取或修改该表格对象。

## 938 nistest — 使用条件表达式返回 NIS+ 命名空间的状态

### Synopsis

```
/usr/bin/nistest [-ALMP] [-a rights | -t type] object
/usr/bin/nistest [-ALMP] [-a rights] indexed name
/usr/bin/nistest -c dir1 dir2
```

## Description

使用 `nistest` 验证命名空间中对象的是否存在、类型和访问权限。你可以通过 `-c` 选项测试两个目录之间的关系。如果一个目录在命名空间中位于另一个，则测试返回真。

## Options

- `-a rights`: 测试访问权限。
- `-A`: 如果初始搜索失败，则遵循连接路径。
- `-C`: 发送到主服务器。
- `-D`: 如果对象是目录对象，返回真。
- `-E`: 等于。
- `-eq`: 等于。
- `-G`: 如果对象是组对象，返回真。
- `-ge`: 大于。
- `-gt`: 大于。
- `-ht`: 高于。
- `-he`: 高于。
- `-lt`: 小于。
- `-le`: 小于或等于。
- `-L`: 如果对象是链接对象，返回真。
- `-M`: 仅限主服务器。
- `-ne`: 不等于。
- `-ne`: 不等于。
- `-neq`: 不等于。
- `-ns`: 非连续。
- `-P`: 如果对象是私有对象，返回真。
- `-t type`: 测试指定类型的对象。
- `-T`: 如果对象是表格对象，返回真。
