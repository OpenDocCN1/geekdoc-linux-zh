## SQL 注入与 Wi-Fi 破解

提到网络攻击时，最广泛的形式之一是 SQL 注入攻击。在这种攻击中，攻击者执行威胁或无效格式的 SQL 语句，用于控制 Web 应用程序的数据库服务器。它还用于在用户完全不知情的情况下修改、删除或添加数据库中的记录。这最终会损害数据的完整性。避免或防止 SQL 注入所可以采取的最重要步骤是输入验证。

## SQL 注入及其类型

今天你可以找到多种类型的 SQL 注入。让我们来看看它们：

- 经典或带内 SQL 注入：
  1. 基于错误（Error based）：攻击者利用数据库生成的错误来攻击数据库服务器。
  2. 基于并集（Union based）：在这种情况下，使用 UNION SQL 运算符来组合返回到 HTTP 响应的响应。
- 推断或盲注 SQL 注入：
  1. 基于布尔（Based on Boolean）：基于返回真或假。
  2. 基于时间（Time based）：发送 SQL 注入强制数据库在响应之前等待。
- 带外 SQL 注入（Out of band）：当攻击者无法使用类似的通道进行攻击和收集结果时，就会发生这种情况。

## Wi-Fi 破解

Wi-Fi（或无线网络）是当今世界用于网络连接的首选媒介。然而，由于其流行性，无线网络也面临各种攻击以及若干安全问题。如果攻击者获得了网络连接的完全访问权限，攻击者可以从任何附近的位置嗅探数据包。攻击者利用嗅探工具寻找 SSID，然后破解 Wi-Fi 或无线网络。在成功破解后，攻击者可以监控所有设备。

## 破解 Wi-Fi 的工具

为了破解 WEP，攻击者使用诸如 Acrack、Aircrack、Kismet、WEPDecrypt 等多种工具。为了破解 WPA，会使用 Cain 和 Cowty 等工具。还有其他常用工具，如 `wireshark`、`Airsnort`、`Wifiphisher`、`Netstumbler` 等。Android 可以被认为是最常见的手机平台，但它也非常受到某些特定类型漏洞的影响，这最终使得攻击者更容易利用设备安全并从中窃取数据。对移动设备最危险的威胁是第三方应用程序、电子邮件木马和短信。

## 如何进行 Wi-Fi 攻击？

大多数网络攻击都是通过设置流造访问点（Rogue Access Points）实现的。

- 恶意孪胎攻击（Evil Twin attack）：在这种情况下，黑客设置一个与公司场所附近的企业 AP 命名相同的虚假访问点。当公司的任何员工连接到该访问点时，该员工在不知情的情况下提供了实际访问点的所有身份验证详细信息。因此，黑客可以轻松地破坏整个连接。
- 信号干扰（Signal jamming）：黑客可以通过干扰网络信号来轻松中断网络连接。这是通过各种用于产生噪声的工具实现的。
- 配置错误攻击（Misconfiguration attack）：当网络路由器使用默认配置形式、弱加密形式、弱凭据和算法进行设置时，攻击者可以轻松破解网络。
- 热点攻击（Hotspot attack）：攻击者设置与任何公共 Wi-Fi 访问点 SSID 名称相同的虚假热点或访问点。当任何用户无意中连接到该访问点时，黑客可以轻松进入实际网络。

## 如何执行有效的攻击

“黑客”一词并不意味着它总是是负面的。只有当你对背后的过程有清晰的感知时，你才会对黑客的整个过程有一个正确的理解。你不仅能够学习黑客的过程，还能让你的系统受到来自外部攻击的保护。大多数时候，当攻击者尝试获取组织或公司的服务器访问权限时，通常是使用 5 个正确的步骤完成的。让我们来看看这些步骤。

- **侦察 (Reconnaissance)**：这可以被视为黑客过程的第一步。在此阶段，攻击者利用所有可用手段，收集有关主要目标系统的所有形式的相关信息。相关信息可能包括对目标的正确识别、服务器的 DNS 记录、目标范围内的 IP 地址范围、网络以及其他各个方面。简单来说，攻击者试图收集各种信息以及网站或服务器的联系方式。攻击者可以通过使用 `maltego` 等多种形式的搜索引擎、通过对目标系统进行研究，或者使用如 `HTTPTrack` 等各种工具下载完整网站以供后续阶段进行枚举来实现。

通过执行所有这些步骤，攻击者能够非常容易地确定组织内所有人员的名称，找到指定的职位以及员工的电子邮件地址。

- **扫描 (Scanning)**：在收集了目标的所有相关信息后，攻击者现在开始扫描过程。在此阶段，攻击者采用拨号器、端口扫描器、漏洞扫描器、扫描器和网络映射器等各种工具对目标网站或服务器数据进行扫描。在这一步中，攻击者试图寻找所有实际上有助于执行成功攻击的信息，例如系统的 IP 地址、该服务器内的用户帐户和计算机名称。黑客完成基础信息的扫描后，他们开始测试目标网络以寻找可能的攻击途径。他们还可能采用像 Kali Linux 这样的多种方法进行网络映射。黑客还会寻找任何自动电子邮件系统，通过该系统向目标公司的员工发送某些虚假查询，例如向公司人力资源部门发送职位查询。

- **获取访问 (Access gaining)**：这是所有步骤中最重要的一的一步。在此阶段，攻击者根据第一步和第二步收集的所有相关信息，设计目标网络的蓝图。在黑客完成数据枚举和系统扫描后，他们现在将转向获取系统的访问权限，这将基于所收集的信息。

- 例如，攻击者可能决定使用钓鱼攻击。攻击者总是试图采取稳妥的方法，可能会使用非常简单的攻击来获取系统的整体访问权限。攻击者还可能从 IT 部门的终端渗透系统。黑客利用公司真实的电子邮件地址使用钓鱼邮件。通过使用此钓鱼邮件 ID，攻击者将向技术人员发送邮件，邮件中将包含形式的特殊程序以及用于收集登录密码和 ID 的钓鱼网站。为此，攻击者可以使用手机应用、网站信箱或其他方法，然后要求员工使用他们的凭据登录新网站。当黑客使用这种方法时，他们已经在后台运行了一个特殊类型的程序，该程序被称为社会工程工具包（Social Engineering Toolkit），用于使用用户的地址发送邮件。

- **维持服务器的访问 (Maintaining access to the server)**：在攻击者获得目标服务器的访问后，他们将尝试一切可能的方法确保其服务器访问的安全，以便未来的攻击和利用。由于攻击者现在拥有服务器的整体访问权限，他还可能将服务器作为其启动其他形式攻击的基地。当攻击者获取整个系统的访问权限并拥有该系统时，这种系统被称为僵尸系统（zombie system）。黑客可能还会尝试通过创建一个新的管理员账户来隐藏自己，以便无人不知的情况下与系统融合。为了确保访问系统的安全，黑客会追踪所有长时间未使用的帐户，然后将所有帐户的权限提升给自己。

当黑客确保没有人察觉他在系统中的存在时，他开始复制该服务器上的所有数据，以及联系人、消息、机密文件等以备以后使用。

- **清除踪迹 (Clear of tracks)**：在开始攻击之前，黑客们会规划他们的整个轨迹，以确保无人能够追踪到他们。攻击者从更改系统 MAC 地址开始，然后通过 VPN 运行整个系统，这样就无人能追踪他们的真实身份。

## 术语

## 入口测试，渗透测试（Pentesting）

渗透测试是分析人员在明确规则内采用的方法、程序和方法论，旨在尝试绕过数据框架的安全，包括消除该框架的协调安全防护。此类测试与评估框架的技术、法规和操作设置及控制有关。

常规渗透测试仅评估处于构建状态的数据框架的安全性。目标系统的管理员和人员可能会意识到渗透测试正在进行。

## 红队，红队演习（Red Teaming）

红队在程序和方法上模拟潜在的敌人。

这些小组通常比渗透测试小组更大，拥有更丰富的经验。渗透测试本身通常是红队演习的一个组成部分，然而这些活动测试了组织安全设备的不同元素。红队经常通过技术、社交和物理方法攻击组织。他们经常利用与黑客（Black Hat Hackers）类似的程序来测试组织或数据框架对抗这些敌角色的能力。除了渗透测试，红队还将执行社会工程攻击，包括网络钓鱼和针对性网络钓鱼，以及包括翻找垃圾桶和开锁在内的物理攻击，以获取数据和访问权限。总的来说，目标组织的员工通常不会意识到正在进行红队演习。

## 道德黑客（Moral Hacking）

道德黑客是专家渗透分析师，为了框架所有者或拥有数据框架的组织的利益而攻击框架。就本书的而言，道德黑客与渗透测试是同词。

白帽（White Hat）是道德黑客或计算机安全专业人员的俚语，他们信奉能够提高数据框架安全性的哲学。

## 黑帽（Dark Hat）

黑帽是一个术语，用于区分利用专业方法在未经许可的情况下绕过框架安全实施不道德行为的个人。渗透测试人员和红队人员经常利用黑帽所使用的策略，在执行批准的活动或测试时模仿这些人。黑帽在未经授权和非法的情况下引导他们的活动。

黑帽指的是一种跨越白帽和黑帽界线的专业大师。这些人经常尝试在未经许可的情况下绕过数据框架的安全防护，不是为了利益而是为了让框架管理员意识到发现的缺陷。黑帽通常没有测试框架的授权，但通常不是财务上的额外负担。

## 无能力评估，脆弱性分析（Powerlessness Assessment, Vulnerability Analysis）

无能力评估用于评估数据框架的安全设置。此类评估包括对已应用于框架或缺失的安全补丁进行评估。漏洞评估团队（VAT）可以位于框架之外，也可以是框架支持人员的一部分。

## 安全控制评估（Security Controls Assessment）

安全控制评估评估数据框架与明确法律或行政要求的一致性。这些要求的示例包括但不限于《联邦信息安全管理法》（FISMA）、支付卡行业标准（PCI）和《健康保险可移植性与责任法》（HIPAA）。安全控制评估被用作组织用于证据链（BOE）的一部分，以批准数据框架在生成环境中的运行。一些框架要求渗透测试作为安全控制评估的主要方面。

## 恶意用户测试（Noxious User Testing, Malicious User Testing）

在恶意用户测试中，评估人员接受扮演具有恶意的内部人员、怀有敌意的客户或滥用者的工作。在这些测试中，评估人员被赋予授权或管理客户的凭证，通常作为一个测试账户。评估人员将利用这些权限尝试绕过安全限制，同时查看文件和设置以寻找记录未获得许可之处，更改不应更改的设置，并将自己的权限提升至超过记录应拥有的水平。恶意客户测试模拟了特权内部人员的行为。

## 社会工程学（Social Engineering）

社会工程学攻击通常对数据框架或客户是有害的。社会工程工程师利用人们帮助他人的自然需求来换取进入数据框架。常见的社会工程学策略包括试图让工作区域检查员重置客户账户密码，或让最终客户暴露他们的密码，从而使社会工程师能够登录他们未获得授权的账户。其他社会工程学策略包括网络钓鱼和针对性网络钓鱼。

## 网络钓鱼（Phishing）

在网络钓鱼（发音类似 angling）中，社会工程师试图让目标人物泄露个人数据，如客户姓名、账号密码和密码。这通常通过使用来自合作伙伴、银行和客户服务人员的看似真实但虚假的信息来实现。不同类型的网络钓鱼试图让客户点击虚假链接，这将能够在其不知情的情况下在目标计算机上引入恶意代码。这种恶意软件将用于从计算机中提取信息或利用计算机攻击他人。网络钓鱼通常不针对特定客户，但可能是邮件列表上的任何人或具有特定电子邮件后缀的任何人，例如每个带有 "@foo.com”后缀的客户。

## 针对性网络钓鱼（Spear Phishing）

针对性网络钓鱼是一种钓鱼，其中目标客户被明确识别。例如，攻击者可能会发现组织首席执行官（CEO）或其他官员的电子邮件地址，并仅针对这些人进行钓鱼。

## 翻找垃圾桶（Dumpster Diving）

在翻找垃圾桶中，评估人员筛选框架客户丢弃的垃圾，寻找可以进一步了解目标的数据。这些数据可能是框架设置和配置、网络拓扑图、程序版本和设备部件，甚至是用户名和密码。该术语指的是进入巨大的垃圾容器，或者“潜入”小型办公室垃圾桶，因为那里也能产生有价值的信息。

## 现场光盘、现场磁盘或现场操作系统（Live CD, Live Disk, or LiveOS）

现场光盘或现场系统指的是一个包含整个工作系统的光学光盘。这些光盘对许多评估人员非常有帮助，并可以调整以包含特定的程序段、设置和工具。虽然现场系统通常出现在 Linux 发行版中，但微软也发布了一些 Windows 版本。根据框架的设置，现场光盘可能是评估人员或分析师应该带来的主要硬件，因为目标框架可以启动到现场系统。这把数据框架的一个资源转而对抗框架本身。

Kali Linux 是由 Offensive Security 发布的最新即时系统安全发行版。此版本包含了 300 多个安全和渗透测试工具，并根据渗透分析人员和其他数据框架评估人员经常使用的支持小组进行了分类。与 Offensive Security 发布的任何发行版本不同，Kali Linux 以 Debian 7.0 发行版的基础。Kali Linux 继承了其前身 Backtrack 的血统，并由类似的团队进行维护。正如 Offensive Security 所述，名称的更改代表了组织对 Backtrack 发行版的全面重构。相比于之前的 Backtrack 版本，巨大的改进使得更名变得合理，表明这不仅仅是 Backtrack 的另一个版本。Backtrack 本身是基于 White Hat 和 SLAX 这两个安全工具的改进版。在该系列中，Kali Linux 是安全检查和渗透工具的最新表现。

## 硬盘选择

不要使用这句话，但“大小确实会有影响”。一个通用原则是：硬盘越大越好。本书建议使用至少 120 GB 空间的硬盘。由于密码破解、取证或渗透测试任务需要大量的空间，这很快就会满。由于一般的业务和安全评估，操作系统会被清理、删除或完全移除以保持初始状态。这种培训通过安全网络广泛认可，因为需要正确处理用户分类信息并防止损害组织数据的泄露。

## 硬盘分区

分区是通过设置不同的大小和划分将硬盘划分为特定部分的演示。分区可以防止操作系统被假设控制框架的文件破坏，并在特定情况下提供更高的安全性。操作系统基本上被拆分为两个不同的部分。

主部分是交换区，用于内存分页和容量。另一个部分分配给其他所有内容，并使用文件系统设计，例如扩展文件系统 3 (`ext3`) 或扩展文件系统 4 (`ext4`)。在电脑上，特别是那些经常加载操作系统的设备上，进一步分区并不重要。对于具有更稳定操作系统的特殊设备，仍需要划分出临时（tmp）文件。

硬盘的强制分区以及本书范围之外的双启动电脑是不安全的。主要的例外是附录 A，其中提供了名为 Kali Chicken 的第三方应用程序重新发行。

## U 盘安装

USB 内存设备（通常称为 U 盘）是一种通过 USB 接口连接到 PC 的简单存储设备。本书建议使用具有至少 8GB 空间的 USB 设备，理想情况下更多。新 PC 可以从 USB 设备启动。如果选择此此选项，请确保所使用的 PC 支持从 USB 设备启动。

随后的章节将介绍如何在 Windows PC 或 Linux 阶段安装 Kali Linux。请务必检查 Kali Linux 官方落地页上提供的文档，以获取此过程的更新。

关于将 U 盘作为启动设备使用，有两个关键术语：持久性（persistence）和非持久性（non-persistence）。持久性是指您的设备在关关闭后保留任何已写入或修改记录的能力。非持久性是指设备在机器重启或关闭时丢失所有设置、自定义和记录。对于本书而言，从 Windows 阶段创建的 Kali Linux U 盘安装是非持久性的，而从 Linux 阶段创建的是持久性的。

### Windows（非持久性）

所需应用程序——`Win32 Disk Imager`: `http://sourceforge.net/ventures/win32diskimager/`

在下载 Kali Linux ISO 之前，将 U 盘插入 PC 并等待 Windows 识别它，观察分配的驱动器号。接下来打开 `Win32 Disk Imager`。点击信封图标浏览并选择 Kali ISO 文件，然后点击“alight”按钮。从设备下拉菜单中选择正确的驱动器号。最后点击“State”（状态）按钮。

当 `Win32 Disk Imager` 完成消耗 ISO 后，重启 PC 并从 BIOS POST 菜单中选择 U 盘。大多数制造商有不同的启动 USB 设备的策略；请务必检查 PC 生产者的文档。

## Linux（持久性）

在构建持久性 U 盘时，再次强调，大小确实很重要！U 盘容量越大越好。此外，取决于您构建此 USB 设备的 Linux 版本，请确保已引入 `GParted` 应用程序。如果您在引入 `GParted` 时遇到问题，请检查您的工作系统的文档。如果未引入 `GParted`，以下技术之一可能对您的 Linux 安装至关重要：

- `apt-get install gparted`
- `apt install gparted`
- `yum install gparted`

下载 Kali Linux ISO 后，插入您的 U 盘。打开终端窗口并按照以下方向确认 USB 设备区域：`lsblk -l | grep awk '{print $1}'` 显示命令的输出为 "dev/sdb1"。USB 设备的输出可能根据 PC 的设置和设计而异。随后，将 "sdb" 替换为正确的标识并删除结尾的任何数字。使用 "`dd`" 命令将 Kali ISO 镜像移动到 USB 设备。`dd if=5 kali_linux_image.iso of=5/dev/sdb bs=5512k` 现在启动 `Gparted`。gparted/ 盘现在应该有一个刚刚引入的 Kali 镜像的分区。

通过从文件菜单栏点击 Partition（分区）菜单后显示的菜单中选择 New（新建），向 USB 增加另一个分区。不同设备制造商的输出可能会略有差异。通常情况下，方法如下：

- 点击灰色的“unallocated”（未分配）空间。
- 从 Partition 下拉菜单中点击“New”（新建）。
- 使用滑块或物理确定驱动器大小。
- 将文件系统设置为 ext4。
- 点击 Add（添加）。
- 在主窗口中，从 Edit（编辑）下拉菜单选择 Apply All Operations（应用所有操作）。
- 在出现提示时点击 Okay（确定）。这可能需要一些时间。

要包含持久性功能，使用以下命令：`mkdir /mnt/usb` `mount /dev/sdb2 /mnt/usb` `echo "persistence" > /mnt/usb/persistence.conf` `umount /mnt/usb`

LiveUSB 的创建已完成。重启 PC 并从 U 盘启动。

## SD 卡安装

微型计算机，例如 RaspberryPi 和 Google 的 Chrome Notebook，适合在 SD 卡上运行。这些小设备可以用于许多用途；人的限制仅限于想象力。这些设备（例如 Raspberry Pi）的优点是它们廉价且易于。以下提供了为 ARM 架构设备引入 Kali 的简短手册：

- 1. 从 Kali 官方网站 (`http://www.kali.org/downloads/`) 下载合适的镜像。
- 2. 添加一个空白 SD 卡。使用以下命令确认挂载区域：`lsblk -l | grep awk '{print $1}'`
- 3. 将 Kali.img 文件移动到 SD 卡。`dd if=5 kali_linux_image.iso of=5/dev/sdb bs=5512k`
- 4. 在提取设备之前卸载并完成任何写入任务。`umount /dev/sdb`
- 5. 插入 SD 卡。

# 第 3 章：合适的软件包处理工具

APT 软件包处理工具，被称为 "`apt-get`"，是一种用于引入和删除软件包的轻量级且极其强大的命令行设备。它构建在 Debian 包管理器 (`dpkg`) 之上。`apt get` 监控所有引入的内容以及所需的条件，即其他程序正常运行所需的额外软件包。例如，`Metasploit`（渗透测试者的亲伴）依赖于名为 Ruby 的特定编程语言。如果没有引入 Ruby，`Metasploit` 将无法运行；因此，Ruby 是 `Metasploit` 的依赖。

`apt get` 并不监控已引入程序的条件。当更新可用时，它将监控形成和封存条件。

损坏的 `apt-get` 将在下次刷新时提醒客户端，并提示移除旧的软件包。

`apt-get` 可以是一个极其基础的、也可以是一个异常复杂的工具。软件包的组织对于确保 Kali Linux 正常运行以及确保产品包处于最新状态至关重要。虽然 Kali Linux 普通用户不需要了解 `apt-get` 的内部操作，但每个用户都应该了解一些基础知识。

## 引入应用程序或软件包

引入额外的程序是操作系统最基本的能力，而且操作非常简单。下面的语法结构将提供 `introduce` 子命令的基本用法示例：

`apt-get introduce {package_name}`

尝试引入 "gimp;" 一个图像处理程序软件包：`apt-get introduce gimp`

## 更新

偶尔，应该检查源（或存储库）以获取在 Kali Linux 上引入的各种应用程序和软件包的更新。在引入任何新软件包之前应该检查更新，并且在对操作系统、程序应用程序或软件包进行升级之前也是需要这些。执行刷新的命令是：`apt-get update`

## 升级

没有任何操作系统是完美的。每个主要的操作系统都处于持续进展、改进和修复错误的状态，以提供新功能或修复 Bug。更新功能将下载并引入所有新引入的程序软件包的新版本。所有基于 Linux 的操作系统的伟大之处在于它们是开源的，这意味着地球上的任何人都可以向操作系统的发行者提交新代码，以帮助提高框架检测 Bug 或开发需求的实用性。这使得补丁可以比微软等公司更快地刷新。如前，在运行升级之前必须安装更新。使用以下命令更新：

`apt-get update`

## 发行版升级

应用程序更新的工作原理与升级工作类似。此功能同样搜索特殊软件包及其状态的热点，以及发行者分配的包含最新版本的各种软件包。例如，在执行发行版升级工作时，整个 Kali 将从版本 1.0 升级到版本 1n 或 2n 等。使用以下命令更新 Kali：`apt-get dist-upgrade`

## 移除

`apt-get` 可用于在移除特定程序时减少操作系统的印象。建议卸载所有未使用的、不满足需求或对你的操作系统冗余的软件包。例如，如果框架上不需要 Leafpad 应用程序，请将其移除。如果以后需要引入该应用程序，它通常是需要的，尽管忽略无用的东西是理想的。可以使用以下命令移除应用程序或软件包：`apt-get remove {package_name}`
