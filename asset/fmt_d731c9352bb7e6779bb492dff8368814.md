
- `font_struct` 指定与字体关联的存储。
- `atom` 指定你想要返回的属性名的 `atom`。
- `value_return` 返回字体属性的值。

给定该属性的 `atom`，`XGetFontProperty` 返回指定字体属性的值。如果属性未定义，`XGetFontProperty` 返回 `False`；如果已定义则返回 `True`。在 `<<X11/Xatom.h>` 中可以找到一组预定义的字体属性 `atom`，包含了与字体相关的标准属性。虽然不能保证，但预定义属性很存在。

要卸载由 `XLoadFont` 加载的字体，使用 `XUnloadFont`。

- `XUnloadFont(display, font);` 指定与 X 服务的器的连接。
- `display` 指定字体。

`XUnloadFont` 删除字体资源 ID 与指定字体之间的关联。当没有其他资源引用它时，字体本身将被释放。之后不应引用该字体。

`XUnloadFont` 产生 `BadFont` 错误。

## 获取和释放字体名及信息

你通过匹配通配符规范来查询字体类型的可用大小列表等，从而获取字体名和信息。

返回可用字体名列表，使用 `XListFonts`。

```
char **XListFonts(display, pattern, maxnames, actual_count_return);
```

- `display` 指定与 X 服务的器的连接。
- `pattern` 指定包含通配符字符的以空 结尾的字符串。
- `maxnames` 指定返回的最大名称数量。
- `actual_count_return` 返回字体名的实际数量。

`XListFonts` 返回一个可用字体名数组（如传递给搜索路径的；使用 `XSetFontPath`），它匹配你传递给 `pattern` 参数的模式。模式字符串可以包含任何字符，但每个 (*) 都是任意数量字符的通配符，每个问号 (?) 都是单个字符的通配符。如果模式字符串不在主机可移植字符编码中，结果取决于实现。使用大小写均不影响。每个返回的字符串都以空 结尾。如果服务器返回的数据是拉丁可移植字符编码（Latin Portable Character Encoding），则返回的字符串是主机可移植字符编码。否则，结果取决于实现。如果没有匹配的字体，`XListFonts` 返回 `NULL`。客户端在处理结果后应调用 `XFreeFontNames` 来释放内存。

释放字体名数组，使用 `XFreeFontNames`。

```
XFreeFontNames(list[]);
```

- `list` 指定你想要释放的字符串数组。

`XFreeFontNames` 函数释放由 `XListFonts` 或 `XListFontsWithInfo` 返回的数组和字符串。

获取可用字体的名称和信息，使用 `XListFontsWithInfo`。

```
char **XListFontsWithInfo(display, pattern, maxnames, count_return, info_return);
```

- `display` 指定与 X 服务的器的连接。
- `pattern` 指定包含通配符字符的以空 结尾的模式字符串。
- `maxnames` 指定返回的最大名称数量。
- `count_return` 返回字体名的实际数量。
- `info_return` 返回字体信息。

`XListFontsWithInfo` 返回匹配你传递给 `pattern` 参数的模式可用字体名数组（如传递给搜索路径的；使用 `XSetFontPath`）。模式字符串可以包含任何字符，但每个 (*) 都是任意数量字符的通配符，每个问号 (?) 都是单个字符的通配符。如果模式字符串不在主机可移植字符编码中，结果取决于实现。使用大小写均不影响。每个返回的字符串都以空 结尾。如果服务器返回的数据是拉丁可移植字符编码，则返回的字符串是主机可移植字符编码。否则，结果取决于实现。如果没有匹配的字体，`XListFonts` 返回 `NULL`。客户端在处理结果后应调用 `XFreeFontNames` 来释放内存。

释放字体名数组，使用 `XFreeFontNames`。

```
XFreeFontNames(list[]);
```

- `list` 指定你想要释放的字符串数组。

`XFreeFontNames` 函数释放由 `XListFonts` 或 `XListFontsWithInfo` 返回的数组和字符串。

获取可用字体的名称和信息，使用 `XListFontsWithInfo`。（此处重复上文）

释放字体名数组和字体数组，使用 `XFreeInfo`。

```
XFreeInfo(names, free_info);
```

- `names` 指定字体名列表。
- `free_info` 指定字体信息。

`XFreeInfo` 函数释放一个字体结构或字体结构数组。如果传递 `NULL`，则不释放字体名。如果传递的是打开字体（由 `XLoadFont` 返回）的结构，则释放该结构但不会关闭字体；使用 `XUnloadFont` 关闭字体。

## 计算字符字符串大小

Xlib 提供了一些函数，可以使用它们计算宽度、逻辑范围以及关于 8 位和 2 字节字符串的信息。宽度通过累加所有字符的宽度计算得出。字体是 8 位还是 2 字节均可。这些函数返回像素单位的总和。

确定 8 位字符字符串的宽度，使用 `XTextWidth`。

```
int XTextWidth(font_struct, string, count);
```

- `font_struct` 用于计算宽度的字体。
- `string` 指定字符字符串。
- `count` 指定指定字符串中的字符数量。

确定 2 字节字符字符串的宽度，使用 `XTextWidth16`。

```
int XTextWidth16(font_struct, string, count);
```

- `font_struct` 用于计算宽度的字体。
- `string` 指定字符字符串。
- `count` 指定指定字符串中的字符数量。

## 计算逻辑范围

要计算给定字体 8 位字符字符串的边界框，使用 `XTextExtents`。

```
XTextExtents(font_struct, string, nchars, direction_return, font_ascent_return, font_descent_return, overall_return);
```

- `font_struct` 指向 `XFontStruct` 结构。
- `string` 指定字符字符串。
- `nchars` 是字符字符串中的字符数量。
- `direction_return` 返回方向提示的值（`FontLeftToRight` 或 `FontRightToLeft`）。
- `font_ascent_return` 返回字体上升部。
- `font_descent_return` 返回字体下降部。
- `overall_return` 返回整体边界框。

`overall_return`

返回指定的 `XCharStruct` 结构体中的总体尺寸。

要计算给定字体中 2 字节字符字符串的边界框，请使用 `QTextExtents16`。

```
XTextExtents16(font_struct, string, nchars, direction_return, font_ascent_return, font_descent_return, overall_return);
```
