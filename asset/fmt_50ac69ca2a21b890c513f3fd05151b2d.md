# 网格选择 (MESH SELECT)

`Mesh Select`修改器允许你访问对象的子对象层级以选择对象的一部分。然后，你可以应用另一个修改器来仅影响你通过`Mesh Select`选择的部分。例如，你可以使用`Mesh Select`选择对象的一部分，然后使用`Taper`修改器仅对所选部分进行处理。你可以使用`Mesh Select`将选择传递给堆栈中的其他修改器，或者为 Patch 和 NURBS 表面获取网格对象选择。

# 补丁选择 (PATCH SELECT)

`Patch Select`修改器允许你访问对象的子对象层级以选择对象的一部分。它的工作方式与`Mesh Select`修改器类似，但`Patch Select`将对象视为可编辑的补丁（editable patches）而不是网格。

# 样条选择 (SPLINESLECT)

`SplineSelect`修改器允许你影响样条的对象选择。`SplineSelect`修改器的大部分功能也可以在`Edit Spline`修改器找到。

# 多边形选择 (POLY SELECT)

`Poly Select`修改器与`Mesh Select`修改器类似，因为它允许你选择多边形对象的子对象并向上传递。

# 体积选择 (VOL. SELECT)

`Vol. Select`允许你根据体积进行子对象选择。你有四种体积类型可选：盒、球体、圆柱和网格对象。在设计中，有一个与你选择的体积形状形状选择坐标轴（gizmo）。然后你可以选择`Vol Select`修改器的子对象级，将体积坐标轴移动到合适位置进行选择。这非常强大，因为你可以根据对象进行选择。例如，你可以让一个对象穿过地形移动，并根据对象的位置选择地形中的顶点。
