
## Linux 调制解调器与串口通信

默认文件传输模式为 `BINARY`。
输入 `?` 或 `HELP` 获取帮助。

```
C-Kermit set /dev/ttyS3
C-Kermit set carrier-watch off
C-Kermit speed 11500
```

`/dev/ttyS3`, `11520 bps`

```
C-Kermit c
```

连接到 `/dev/ttyS3`，速度 `11500`。
义字符是 `Ctrl-\` (`ASCII 28`, `FS`)
输入义字符后接 `C` 返回，或后接 `?` 查看其他选项。

```
+ATE1Q0V1 ; 输入此并按回车键
OK ; 应响应此内容
```

如果你的调制解调器响应 `AT` 命令，你可以假设你的调制解调器在 `Linux` 端工作正常。现在通过输入拨打另一个调制解调器：

```
ATDT765421
```

其中 `765421` 是电话号码。如果你使用的是脉冲线路，请使用 `ADTP` 代替 `ATDT`。如果拨通了，说明你的调制解调器工作正常。

要返回提示符，按住 `Ctrl` 键，按下反斜键，然后松开 `Ctrl` 键，按下 `C` 键：

```
Ctrl-\
(返回 tty)
C-quit
#
```

这是使用原始“手动”拨号方法的测试。正常方法是让它通过内置的调制解调器数据库和自动拨号功能为你拨号，例如使用 `US Robotics` (`USR`) 调制解调器：

```
kermit# kermit

C-Kermit 6.0.192, 6 Sep 1997, for Linux

Copyright (C) 1985, 1996,
纽约大学理事会。

默认文件传输模式为 BINARY
输入 ? 或 HELP 获取帮助
```

# Linux 串口教程

```
C-Kermit set modem type usr ; 选择调制解调器类型
C-Kermit set line /dev/ttyS3 ; 选择通信设备
C-Kermit speed 11500 ; 设置拨号速度
C-Kermit dial 765421 ; 拨号
Device=/dev/ttyS3, modem=usr, speed=11500
连接完成。<BEEP
连接到 /dev/ttyS3，速度 11500
义字符是 Ctrl-\ (ASCII 28, FS)
输入义字符后接 C 返回，
或后接 ? 查看其他选项。

Welcome to ...
login:
```

参见串口程序如果需要帮助。当你的 `Linux` 系统启动时，只有 `ttyS(0-3)` 配置了默认的中断 `4` 和 `3`。因此，如果你有其他板提供的串口，或者 `ttyS(0-3)` 有非标准中断，你必须使用 `setserial` 配置这些串口。完整列表请参阅主页。

## 关于 getty

`agty` 是 `getty` 的第三种变体。它是一个简单且功能完整的 `getty` 实现，最适用于控制台或终端而非调制解调器。

## 4.2 什么是 setserial？

`setserial` 是一个允许你查看和更改串口设备各种属性的程序，包括端口地址、中断和其他串口选项。你可以通过运行不带参数的 `setserial` 来查看你拥版本。当你的 `Linux` 系统启动时，只有 `ttyS(0-3)` 配置了默认的中断 `4` 和 `3`。如果参数是 `/dev/ttyS1`，你会看到关于该端口的信息。因此，如果你有其他板提供的串口，或者 `ttyS(0-3)` 有非标准中断，你必须使用 `setserial` 配置这些串口。完整列表请参阅主页。

## 5 如何用我的调制解调器拨号？

## 5.1 硬件要求

你可以使用外部或内部调制解调器。内部的成本较低且不占用桌面空间。但外部的更容易“安装”，并且有指示灯显示正在发生的情况。外部在使用时需要关闭，即使关闭也会消耗少量电力。

## 外部调制解调器

首先，确保你有正确的线缆。你的调制解调器需要直通线而非交叉线。任何计算机都应该有这些。确保你获得正确的规格。如果你使用的是 `DB25` 串口，它将始终是公头。不要与并行端口混淆，后者是母头。将你的调制解调器连接到你的串口之一。如果需要帮助，请参阅调制解调器说明如何操作。

## 内部调制解调器

对于内部调制解调器，你不需要线缆。它是内置的。你需要的是配置一个未被使用的中断，并配置 `I/O` 地址。如果卡住了，请阅调制解调器说明。如果需要帮助选择中断或地址，参见“多个串口设备”。在某些主板上，你必须禁用调制解调器正在使用的串口以避免冲突。这可以通过跳线或 `BIOS` 设置来实现，取决于你的主板。

如果你有 `IBM8514` 主板，有一个你应该知道的 Bug。如果你使用内部调制解调器作为 `tty3`，可能会遇到问题。如果 `Linux` 没有检测到 `tty3` 上的内部调制解调器，你可以使用 `setserial`，它将正常工作。`ttyS(0-2)` 不应该出现任何被检测问题。

## 5.2 与你的调制解调器通信

在进入复杂的 `SLIP` 或 `PPP` 之前，使用 `minicom` 或其他程序测试设置。你可以在 `http://www.columbia.edu/kermit/` 找到 `kermit` 的最新版本。例如，假设你的调制解调器在 `tty3` 上，速度为 `11520 bps`。执行如下操作：

```
linux# kermit

C-Kermit 6.0.192, 6 Sep 96, for Linux

Copyright (C) 1985, 1996,
纽约大学理事会。
```
