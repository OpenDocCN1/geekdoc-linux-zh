### 1.8.4 确保 GDM 在空闲时锁定（自动化）

**适用范围**

- 级别 1 - 服务器
- 级别 1 - 工作站

**描述**

GNOME 显示管理器可以在用户空闲一段时间后锁定屏幕。

- `idle-delay=uint32` 屏幕变屏前的空闲时间
- `lock-delay=uint32` 屏幕变屏后锁定秒数

**示例键文件**

```
[org/gnome/desktop/session]
# 屏幕变屏前的空闲时间
# 如果你想禁用屏幕保护程序，将其设置为 0 秒
idle-delay=uint32 900
# 屏幕变屏后锁定秒数
lock-delay=uint32 5
```

**原理**

设置锁定值可以减少未经授权的访问被无人看的会话的机会。

**审计**

运行以下脚本验证用户空闲时屏幕锁定：
