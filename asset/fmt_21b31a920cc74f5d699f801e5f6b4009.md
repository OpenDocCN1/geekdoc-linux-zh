## autoexpect

工具丰富的 Linux 环境提供了许多不同的软件工具（例如 `expect`），你可以使用它们来完成棘手的任务。另一种自动化文件传输（以及其他任务）的方法是使用 `autoexpect` 命令。`autoexpect` 命令会创建一个 `expect` 脚本，用于完成 `autoexpect` 会话期间执行的任务。

要自动化 FTP 传输，使用 `autoexpect` 命令的 `-f` 命令行选项，后跟所需命令的名称以及初始命令行，如下：

```
# autoexpect -f ftp aptiva.home.org
autoexpect started, file is eftp
```
