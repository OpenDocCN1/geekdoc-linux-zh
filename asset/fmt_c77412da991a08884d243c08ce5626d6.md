Linux 可以顺利运行所有 100% 符合 `ATAPI` 标准的驱动器，包括符合 `ATAPI` 标准的多盘驱动器。如果驱动器的 `SCSI` 控制器受支持，你可以使用任何 `SCSI CD` 驱动器（参见本节稍后的“SCSI 适配器”）。

## 获取上网设备

为了让你的系统联网，你需要一些硬件。对于大多数人来说，这意味着一个调制解调器。但并不是所有的调制解调器都与 Linux 兼容。

最常见的类型是拨号调制解调器，它们通过电话线连接到互联网。这些非常慢，速度为 `56kbps`。其次常见的是电缆调制解调器，它们通过有线电视连接到互联网。这些快得多，速度为 `1.5Mbps`。还有 `ADSL` 调制解调器，它们使用电话线但频率更高。这些也很很快，速度为 `5Mbps`。

无论你使用哪种调制解调器，都要确保它与 Linux 兼容。对于兼容性列表，请参本章前面的“获取兼容性信息”章节。

## 模拟调制解调器

对于拨号连接，你可以使用任何使用硬件而非软件进行压缩、纠错和高速操作的调制解调器（内置或外置）。

最常见的调制解调器是拨号调制解调器，它们通过电话线连接到互联网。这些非常慢，速度为 `56kbps`。其次常见的是电缆调制解调器，它们通过有线电视连接到互联网。这些快得多，速度为 `1.5Mbps`。还有 `ADSL` 调制解调器，它们使用电话线但频率更高。这些也很很快，速度为 `5Mbps`。

无论你使用哪种调制解调器，都要确保它与 Linux 兼容。对于兼容性列表，请参考本章前面的“获取兼容性信息”章节。

大多数拨号调制解调器是为 `Windows` 设计的，例如 `SupraExpress 56K` 或 `U.S. Robotics Win-Modem`。这些都是为 `Windows` 设计，且名称中带有“Win”。

## 电缆调制解调器

通常，电缆调制解调器通过网络接口卡 (`NIC`)，也称为以太网卡连接到电脑。你的 Linux 系统可以使用任何需要以太网适配器的调制解调器。

关键问题是特定的以太网适配器是否与 Linux 兼容。缆公司可能坚持给你以太网适配器；如果是这样，请确保其兼容（参见本节前面的“获取兼容性信息”章节）。

## ISDN 适配器

`ISDN`，全全服务数字网络，本应在 `ADSL` 的手中过早死亡。但 `ADSL` 有一个严重的局限性：`ADSL` 信号距离中心交换站只能传输几里。在偏远或农村地区，无法使用 `ADSL`。

`ISDN` 仍然具有许多优势，使其成为高质量互联网连接的热门选择，尤其是对于家庭办公而言。大多数供应商提供两种服务级别：单条 `56Kbps` 或 `64Kbps` 数据线，或者两条 `56Kbps` 或 `64Kbps` 语音/数据线，最大带宽可达 `128Kbps`。在这两个选项中，双线服务是最好的，而且不仅是因为它的速度更快：设备可以自动检测拨入或拨出的电话，并无缝地提供可用性。如果你以 `128Kbps` 的速度连接互联网，你仍然可以拨打和接听电话，你唯一会注意到的就是连接速度会有所下降。

你如何选择 Linux 系统来连接 `ISDN`？你可以使用任何外部 `ISDN` 适配器，它在电脑面前表现就像一个连接到串口的普通模拟调制解调器。然而，对于 Linux 系统，首选的 `ISDN` 适配器是由 `SpellCaster`（`http://www.spellcast.com/products.html`）制造的，它是 Linux 支持领域的领导者。
