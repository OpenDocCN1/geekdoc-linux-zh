## C 语言概述

与所有语言一样，C 程序必须遵循规则。这些规则描述了程序应该是什么样子以及这些单词和符号的意思。这些规则创建了编程语言的语法。你可以把程序想象成故事。每个句子都有主语和谓语。句子组成段落，段落讲述故事。同样，C 语句可以构建函数和程序。

## C 基本语法

与所有语言一样，C 主要处理数据的操作和表示。BCPL 将数据视为数据。然而，C 进一步使用了数据类型的概念。基本数据类型是字符、整数和浮点数。其他数据类型由这些基本类型构建。

整数是基础基本的数学数据类型。它们可以被分类为 `long` 和 `short` 整数，其大小取决于实现。在少数例外情况下，整数长度为四字节，范围从 -2147483648 到 2147483647。在 ANSI C 中，你在头文件 `--limit.h--` 中定义这些值为 `INT_MIN` 和 `INT_MAX`。`unsigned` 限定将范围向上移动一位，相当于 `INT_MAX-INT_MIN`。

浮点数用于更复杂的数学运算。整数运算仅限于整数结果。在整数运算中，`3/2` 等于 `1`。而浮点数为数学计算提供了更高的精度：`3/2` 等于 `1.5`。浮点数可以用小数表示，例如 `687.534`，也可以用科学计数法表示，例如 `8.87534E+2`。对于较大的数字，优选使用科学计数法。为了获得更高的精度，`double` 类型提供了更大的范围。再次，特定的范围取决于实现情况。

字符通常以单字节形式实现，尽管某些国际字符集需要两个或更多字节。最常见的字符表示集是 ASCII，常见于大多数美国计算机上。

数组用于存储一组通常与位置相关的序列值。当你需要给定类型的一范围值时，数组非常有用。与数组相关的是指针。变量存储在内存中，而指针是该块内存的物理地址。在某种意义上，指针和数组是相似的，但在调用程序时例外。数组数据所需的空间在调用需要空间的例程时分配的。对于指针，空间必须由程序员分配，或者通过解引用变量来为变量赋值。`*解引用*` 意味着要求系统返回变量的地址。你使用 符号 `&` 表示解引用，并在需要被指向的值时使用星号 `*`。以下是一些示例声明：

`int i;`
声明一个整数

`char c;`
声明一个字符

`char *ptr;` 声明一个指向字符的指针

`double temp[16];` 声明一个包含 16 个值的双精度浮点数数组

**列表 6.2。** 带有指针的程序示例。

```c
int i;
int *ptr;
i=5;
ptr = &i;
printf("%d %x %d\n", i,ptr,*ptr);
```
