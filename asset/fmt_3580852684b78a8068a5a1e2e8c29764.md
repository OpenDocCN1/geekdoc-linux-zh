# 代数

数学中处理方程求解的分支。这些方程包含未知数（或变量）以及来自指定系统的固定数字。代数的起源基于开发模拟现实世界问题的方程的需要。由此产生了一个非常广泛的理论，基于寻找可以成功用于方程中的值的需要。

## 数系

经典代数在多个数系之一中进行。最基本的数系是自然数，由计数数字 1, 2, 3, 4, ... 组成。自然数加上它们的负数和 0 形成了整数集：..., -2, -1, 0, 1, 2, ...。任何可以表示为两个整数 `$a$` 和 `$b$` 的商 `$a/b$` 的数称为有理数。如果一个数的十进制展开要么是小数循环的，要么是以一串零结尾的，那么总是可以找到整数 `$a$` 和 `$b$`，使得商 `$a/b$` 等于原数。那些十进制展开不能写成分数（整数商）的数就是所谓的无理数。早期的数学家直到几何考虑表明它们必须作为直角三角形边长存在时，才认识到这类数的存在。

有理数集和无理数集没有公共元素，它们共同构成了实数系统。代数任务最常在实数系统中执行。然而，还有一个更大的数集，称为复数，在求解方程时作用更完整。复数由形式为 `$a + bi$` 的数组成，其中 `$i$` 是代表 `$\sqrt{-1}$` 的符号。符号 `$i$` 通常被称为 -1 的虚根，形式为 `$bi$` 的数被称为虚数集。在复数 `$a + bi$` 中，实数 `$a$` 称为实部，而实数 `$b$` 称为虚部。

实数经常在数轴上表示（图 1a）。复数可以在二维平面上表示（图 1b），通过将实部画在水平轴上，虚部画在垂直轴上。

## 运算

在任何数系中，都有一套可以在该系统某些或所有成员上执行的运算。运算取系统中的一对数，并由此对产生一个新的单个数。最标准的运算是加法（`+`）、乘法（`$\times$`）、减法（`-`）和除法（`$\div$`）。如果对一个集合中任何一对数应用该运算，结果都是同一集合中的另一个数，则该集合对该运算是封闭的。例如，自然数集对 `+` 是封闭的，但对 `-` 不封闭（因为，例如，`1 - 2 = -1` 不是自然数）。有理数、实数和复数对这四个基本运算都是封闭的（除了可能出现除以 0 的情况）。参见 [算术](https://example.org/arithmetic)。

其他运算源自这四个基本运算。幂运算源自反复将一个数乘以自身的过程。如果 `$n$` 是正整数，符号 `$a^n$` 表示数 `$a$` 自乘 `$n$` 次。如果 `$n > 0$` 是整数，则 `$a^{-n}$` 指代商 `$(1/a)^n$`。也可以通过定义 `$a^{(1/n)}$` 为满足 `$b^n = a$` 的数 `$b$` 来考虑分数指数。这一概念通过令 `$a^{(m/n)} = (a^{(1/n)})^m$` 进一步扩展。对于实数，某些分数指数可能不存在。例如，`$(-1)^{1/2}$` 不是实数。然而，复数对于幂运算是封闭的。

## 代数表达式

在代数中，符号经常用于指定未知值。例如，字母如 `$x$` 和 `$y$` 可以代表满足某些条件的一组数中的任意一个。这些符号与数字和基本运算结合，形成如 (1) 这样的代数表达式。

$$3x^2 + 5yx - 6 / (y^2 + 2) = (x^5 - 1)^{3xy} / (y^2 + 2) \quad (1)$$

这些符号通常称为变量，而乘以它们的那些数字（或常数）是表达式的系数。假设系数都来自指定的数系。当涉及的每个变量被赋予一个数值时，代数表达式取特定值。

## 代数方程

陈述是几个代数表达式之间的关系。这种关系可以是等式（`=`）或不等式（`<` 或 `>`），但在任何情况下，它都对变量的值施加限制。例如，表达式 (2) 中的每一个都代表变量 `$x$` 和 `$y$` 之间的关系，而方程 (3) 涉及三个变量，`$x, y$` 和 `$z$`。

$$x^2 + 3xy = y - 3 \quad \& \quad 2xy > y^5 - 1 \quad (2)$$

$$4x - 2xy = 5 + yx^2 \quad (3)$$

如果当将适当数系中的特定值代入方程中的变量时，所得陈述为真，则称这些值为该方程的解。特定方程的解取决于所使用的数系。例如，方程 `$x^4 = 2$` 在有理数集中没有解，在实数中有两个解（`$x = 2^{1/4}$` 和 `$x = -2^{1/4}$`），在复数域中有四个解。

## 函数

一些最基本的代数方程涉及两个变量。当其中一个变量，比如 `$x$`，可以用另一个变量，比如 `$y$`，以这样的方式表达，使得 `$x$` 的每个值产生 `$y$` 的唯一值时，由方程描述的关系被称为函数。更一般的关系，可能也可能不会从 `$x$` 的每个值产生 `$y$` 的唯一值，被称为关系。在如上所述的函数中，变量 `$x$` 称为自变量，而结果变量 `$y$` 称为因变量。自变量可以使用的可能值构成了函数的定义域（或者更一般地说，关系的定义域）。因变量的结果值构成函数的值域。最常见且非常实用的是将依赖于变量 `$x$` 的变量 `$y$` 写为 `$y = f(x)$` 的形式。

## 多项式

有许多特殊的函数通常用于描述现实情况。其中最基本的是多项式，它是形式为 (4) 的函数。每个系数 `$a_0, a_1, ..., a_n$` 都是实数，且变量的指数是非负整数。`$x$` 的最大指数称为多项式的次数。当绘制图形时，`$n$` 次多项式改变方向不超过 `$n - 1$` 次。

$$f(x) = a_0 + a_1x + a_2x^2 + ... + a_nx^n \quad (4)$$

即使在实数中，多项式通常也可以分解为较低次数的其他多项式。这允许通过考虑较简单的因式来分析多项式。

## 有理函数

形式为 `$f(x) = g(x)/h(x)$` 的函数，其中 `$g(x)$` 和 `$h(x)$` 是多项式，被称为有理函数。它们经常出现在需要对两个多项式进行比较的情况下。

## 指数函数

一般来说，指数函数是形式为 `$f(x) = b^x$` 的函数，其中 `$b$` 是数系中的某个常数。这些函数的图形呈现两种基本类型之一。如果 `$0 < b < 1$`，图形是递减的（图 3a）；如果 `$b > 1$`，它是递增的（图 3b）。
