```
.L2:
```

```
![](img/a13a81f0f574b6.png)作者在程序中增加了注释。执行`strlen`函数后，控制权传递L2，接着检查两个表达式。如果第一个条件表达式为真（长度为0），计算机将不再检测第二个。这种特性称为“逻辑短路”。括地说，这个函数的流程如下：

- 执行`for()`语句的第一部分，就是调用`strlen`函数的。
- 跳到标签2，检测循环是否成立。
- 跳到标签5，进入循环；
- 执行`for()`语句，如果条件成立，直接退出。
- 执行`for()`语句的第三部分，将变量`str_len`递减。
- 再次跳到标签2，检测循环是否成立，进入循环始，直到循环成立。
- 跳到L4，准备退出。
- 制备返回值，即s。

## 47.3 x64下的GCC 4.9优化

```
str_trim:

push    rbx

mov     rbx, rdi

; RBX will be like "s"

call   strlen

; check for str_len=0 and exit if so

test    rax, rax

je      .L9

lea     rdx, [rax-1]

; RDX will always contain str_len-1, so RSI is more like buffer index

lea     rsi, [rbx+rdx]    ; RSI=s+str_len-1

movzx  ecx, BYTE PTR [rsi] ; load character

test    cl, cl

cmp      10

je      .L4                    ; exit if '\n'

cmp      cl, 13 and not '\r'

jne     .L9

.L4:

; this is weird instruction. we need RSI=s-1.

; its possible to get it by MOV RSI, DEC RSI but this is two instructions instead of one

sub     rsi, rax

; RSI = s+str_len-1

; main loop

.L12:

    test    rdx, rdx; store zero at address s-1+str_len=s+str_len

    mov     BYTE PTR [rsi+rdx], 0 ; check for str_len=0.exit if so.

    je      .L9

    sub     rdx, 1 ; equivalent to str_len--

    ; load next character at s+str_len-1
```
movzx ecx, BYTE PTR [rsi+rdx]
test cl, cl ; is it zero? exit then
je .L9
cmp cl, 10 ; is it '\n'?
je .L12
cmp cl, 13 ; is it '\r'?
je .L12
.L9:
    pop

```

实现更为复杂的。在循环体前的代码执行一次，它还会检查结束是否回车或换行。这难道多此举吗？一般来说，实现主体的流程是：

- 循环开始，检查CR/LF结束，进行判断。
- 保存零字符。但是，编译器会将这两步逆序。因此第一步保存零字符，而是判断：①第一个字符是CR/LF，如果不是，就会退出。② 循环开始，保存零字符。③ 根据检查字符是否CR/LF执行。这种处理之后，主体就小了很多，中间的变量是`str_len`。明显，GCC注意到了`str_len-1`使用了两次。因此最好的办法分配一个变量，其值总是字符串长度。
