
某些无线网卡有可以下载的受限驱动以让网卡工作。这些驱动程序通常由网卡制造商提供，所谓的“受限”意味着如果它们出现问题，Ubuntu 开发者无法修复它们（也就是说，它们不是开源的）。

你需要连接互联网才能下载受限驱动。如果你没有正常的连接（可能你正在尝试让网卡工作的过程中！），尝试使用以太网线将计算机直接连接到无线路由器或调制解调器（更多信息请参见第 4 章）。这仅在你良好的有线网卡时有效。如果你的有线网卡无法工作，你无法遵循这些指令。

- 打开 Dash 并打开“硬件驱动”。Ubuntu 将开始搜索受限驱动。如果发现任何，它们将显示在窗口顶部的列表中（如图 22-3 所示）。
- 检查是否有任何受限驱动与网络或无线有关（在它们的描述中应该会有说明）。如果你发现了相关的驱动，选择它并点击“激活”以下载并安装。某些网卡需要两个驱动程序，所以如果你发现了两个相关的驱动，请全部安装。
- 安装完成后，你可能会被提示重启电脑。尽管如此，重启一下也是个好主意。
- 理想情况下，重启并重新登录后，你现在应该能够使用网络/无线连接了。有关如何连接的详细信息，请参见第 4 章。

信不信，你有时可以在 Ubuntu 中让网络/无线连接的 Windows 驱动工作。要实现这一点，你需要显卡的 Windows 驱动程序以及一个名为 `ndiswrapper` 的程序，它可以将驱动转换为 Ubuntu 兼容的格式。完整的说明可以在 https://help.ubuntu.com/community/WifiDocs/Driver/Ndiswrapper/ 找到，但这里有一个帮助你入门的概述：

- 找到你显卡的 Windows 驱动程序。这些驱动通常随电脑附带的光盘提供，你也可以从制造商的网站下载。驱动程序列表见 http://sourceforge.org/apps/media/ndiswrapper/
- 找到你显卡 Windows XP 版本驱动的 `.inf` 文件。驱动通常以 Zip 包的形式提供，你可以打开它并在其中搜索 INF 文件，或者在驱动光盘的文件夹中查找。如果你找不到该文件，可以从上一步提到的 `ndiswrapper` 网站获取更多信息。
- 将 `.inf` 文件保存到桌面或其他其他位置。
- 借用一台接入互联网的电脑，并从以下链接下载 `.deb` 文件（在下载文件之前，你需要点击附近位置的链接）：

  - http://packages.ubuntu.com/preise/all/ndiswrapper-common/download
  - http://packages.ubuntu.com/preise/i386/ndiswrapper-utils-1.9/download
  - http://packages.ubuntu.com/preise/i386/ndisgtk/download
- 将 `.deb` 文件保存到 U 盘或其他存储设备，并用它将其拷贝到你的 Ubuntu 电脑上。同样，将其拷贝到桌面会很方便。
- 现在双击 `ndiswrapper-common` 文件并安装它（要了解如何操作，请参第 92 页的“安装无法通过 Ubuntu 仓库提供的 DEB 包”）。
- 安装完成后，安装 `ndiswrapper-utils` 文件。
- 最后，安装 `ndisgtk`。

安装这些文件的顺序非常重要。

- 现在从 Dash 视图打开“Windows 驱动程序”，并在提示时输入你的密码。无线网络驱动程序窗口将打开（图 22-11）。
- 点击“安装新驱动”并点击“位置”按钮。选择你之前找到 `.inf` 文件并点击“打开”。

# 未找到任何无线网络

如果你知道无线网卡在 Ubuntu 中工作正常，但找不到任何网络，请尝试以下步骤：

- 确保无线网卡已开启。许多笔记本电脑有一个快捷键可以切换无线卡的开启和关闭（在我的电脑上是 FN2）。某些网卡有物理开关需要你拨动。如果你的网卡带有带电线的天线，请确保电线牢固地连接在网卡上。
- 点击顶栏上的网络图标，确保勾选了**启用网络**和**启用无线**（图 22-12）。如果没有勾选，请勾选它们；然后等待一或两分钟让无线网卡唤醒。
- 如果“启用无线”选项已经勾选，尝试取消勾选，等待左右，然后重新勾选。你的无线网卡可能需要关闭再开启来唤醒它。你也可以尝试对第 1 步提到的硬件开关/键盘快捷键进行操作。
- 如果这些方法都没有效果，请尝试重启电脑。某些无线网卡在电脑休眠或挂起之前运行良好，之后它们会进入深度睡眠。重启应该足够唤醒你的网卡了。

![](img/d35fa962e6f9664d66dc83916f426418_428_0.png)

图 22-12：在网络管理器中确保启用了无线和网络连接

- 你还应该检查想要连接的网络是否有隐藏的网络名称（也称为 SSID）。如果是隐藏的，它将不会出现在网络管理器的列表中，你必须手动输入 SSID 才能连接。要此操作，点击网络图标，从菜单中选择“连接到隐藏无线网络”，并在出的窗口中填写详细信息。
- 如果你仍然很困难，你确定自己离无线基站足够近吗？如果信号太弱，你的网卡可能完全无法检测到网络。如果你在一个特别繁忙的区域（例如会议现场），连接也可能很困难。找一个流量少一点的地方看看是否有帮助。

# 我电脑上的其他用户无法连接

如果你的电脑上有多个用户，你可能会发现自己可以连接互联网，但其他用户不能。要解决这个问题，你需要让你的网络连接对所有用户可用：

- 在你的用户账户下操作时，点击顶栏上的网络图标，并从弹出菜单中选择“编辑连接”。
- 在其中选项页中找到你使用的网络连接。例如，如果你使用一个名为“Marconi”的无线网络，将点击“无线”选项页并在列表中查找 Marconi。
- 选择该网络并点击“编辑”。
- 勾选屏幕底部的“所有用户可用”选项并点击“保存”。
- 在提示时输入你的密码。网络将断开，你可能需要再次使用顶栏上的网络图标重新连接（参见第 4 章）。
- 切换到另一个用户账户。现在你应该连接网络了。

# 显示和显卡问题

最近 Ubuntu 在检测显卡方面做得非常好，因此不太可能遇到黑屏。事情并不总是顺利；本节涵盖了获取 3D 加速支持（如果缺失）以及调整屏幕分辨率（如果显示异常）的问题。以防万一，还有可以帮助处理黑屏。

## 游戏/Unity 无法工作：安装加速显驱动

如果你无法让 Ubuntu 默认界面 Unity 工作，或者某个游戏无法运行，你可能需要安装一些加速显驱动。这是因为对于某些显卡，默认只安装了基础驱动（无法处理特效和 3D），由于缺乏合适的替代方案。如果你的显卡存在加速驱动，你可以通过 Dash 打开“硬件驱动”，在列表中选择，然后点击“激活”进行安装。安装完成后，重启电脑，新驱动即可启用。

你可以直接从制造商下载 Linux 显卡驱动。这些驱动比 Ubuntu 自带的更新频繁，并且可能具有额外的功能。接下来的章节介绍了如何从两个最大的制造商 ATI/AMD 和 NVIDIA 获取这些驱动。

## ATI/AMD 卡

- 访问 https://support.amd.com/us/gpudload/Pages/index.aspx，回答关于显卡型号的问题，然后在操作系统列表中选择 Linux x86。
- 点击“显示结果”，你将进入驱动下载页。点击“下载”，并在提示时点击“保存文件”下载驱动。
- 下载完成后，驱动文件名应以 `.run` 结尾。
- 打开终端并使用 `cd Downloads`（后按回车）进入下载文件夹（如果它存储在那里）。
- 现在输入 `chmod +x amd-driver*.run` 并按回车，使其可以作为程序运行。
- 要启动安装程序，输入 `sudo ./amd-driver` 并按 TAB 键。

这应该会自动补全安装文件的名称，完成后你就可以按 ENTER 运行安装程序。

- 输入你的密码。然后按照屏幕上的指令安装驱动程序。

## Nvidia 显卡

- 访问 http://www.nvidia.com/object/unix.html，如果你运行的是 64 位的 Ubuntu，请点击 "Linux x86/IA32"或（"Linux x86_64"）标题下的最新版本链接。

注意：根据你的显卡年代陈旧程度，你可能需要下载最新的遗留（legacy）版 GPU 版本，而不是普通的旧版本。点击最新版本链接并在下载页面检查支持的产品列表；如果你的显卡不在列表中，请尝试遗留版本。
