
# 可能的 PipeWire 音频杂声与爆音修复

按下`CTRL + S`保存更改，然后按`CTRL + X`退出。此配置使Redshift在夜间提供更暖的屏幕颜色，有助于缓解眼部疲劳。

访问PipeWire官方网站`https://PipeWire.org/`获取有关PipeWire的所有信息。
通过命令行和图形界面可能修复PipeWire音频杂声和爆音：

要解决PipeWire可能出现的杂声或爆音等音频问题，首先在终端中执行以下命令以禁用音频电源管理：

```
echo "options snd_hda_intel power_save=0" | sudo tee -a /etc/modprobe.d/audio_disable_powersave.conf
```

```
echo "options snd_hda_intel power_save_controller=N" | sudo tee -a /etc/modprobe.d/audio_disable_powersave.conf
```

通过检查两个命令是否分别返回`0`和`N`来验证更改：
```
cat /sys/module/snd_hda_intel/parameters/power_save
cat /sys/module/snd_hda_intel/parameters/power_save_controller
```

接下来，编辑PipeWire配置以优化性能。使用文本编辑器打开`/usr/share/pipewire/pipewire.conf`并调整量子（quantum）设置：
- 将`#default.clock.quantum = 1024`改为`default.clock.quantum = 2048`。
- 将`default.clock.min-quantum = 16`修改为`default.clock.min-quantum = 2048`。
- 将`#default.clock.max-quantum = 2048`更新为`default.clock.max-quantum = 4096`。

保存更改并退出编辑器。然后重启PipeWire服务：

```
systemctl --user restart pipewire.service pipewire-pulse.service pipewire-media-session.service ; systemctl --user restart pipewire-multi.service
```

通过编辑`/etc/security/limits.conf`增强音频优先级，添加：

- `- @audio - nice -20`

保存并退出。通过清除`speech-dispatcher`来移除任何潜在的冲突：

```
sudo apt purge speech-dispatcher
```

最后，确保所有更改在PipeWire配置中保持一致，保存并备份必要文件，然后重启电脑以应用调整。

## Xanmod

访问Xanmod官方网站`https://xanmod.org/`获取有关Xanmod的所有信息。

在终端中通过APT仓库安装Xanmod：

只需输入这些命令：

```
sudo apt update
```

```
wget -qO - https://dl.xanmod.org/archive.key | sudo gpg --dearmor -o /usr/share/keyrings/xanmod-archive-keyring.gpg
```

```
echo 'deb [signed-by=/usr/share/keyrings/xanmod-archive-keyring.gpg] http://deb.xanmod.org releases main' | sudo tee /etc/apt/sources.list.d/xanmod-release.list
```

```
sudo apt update && sudo apt install linux-xanmod-x64v3
```

保存进度并重启电脑。

务必记录所有正在安装的`linux-xanmod`包。

## Linux Mint 变量

访问Linux Mint变量官方网站`https://linuxmint.com/`获取有关Linux Mint的所有信息。

通过命令行和图形界面设置Linux Mint变量：

要在Debian中为命令行和图形化应用程序自定义环境变量，首先使用命令编辑系统级配置文件：`sudo gedit ~/.bashrc`。滚动到文件末尾并插入以下设置以调整环境行为和性能：

### 环境变量

```
export DXVK_WRITE=1
export DXVK_ENABLE_API=1
export WINEYNC=1
export WINEDEBUG=-all
export _GL_SHADER_DISK_CLEANUP=1
export _GL_THREADED_OPTIMIZATION=1
export _GL_SHARED_MEMORY=1
export WINE_SIMULATE_WRITE=1
export DXVK_STATE_CACHE='/home/username/.wine/c/Program Files (x86)'
export _GL_SHADER_CACHE='/home/username/.wine/c/Program Files (x86)'
export VK3D_SHADER_CACHE='/home/username/.wine/c/Program Files (x86)'
export VK3D_CONFIG='dxr'
export VK3D_exclude_processes='Agent.exe'
export GOPATH=$HOME/work
export PATH=$PATH:/usr/local/bin
export PATH='/home/username/.nimble/bin'
```

### 别名 (Aliases)

```
alias update='sudo apt update && sudo apt upgrade'
alias updater='sudo apt update && sudo apt upgrade && sudo snap refresh'
alias wget='wget --limit-rate'
alias purge='sudo apt purge'
alias install='sudo apt install'
alias insnap='sudo snap install'
alias ipkg='sudo dpkg -i'
alias fix='sudo dpkg --configure -a && apt-get install -f'
alias fixit='sudo apt install -f'
alias clean='sudo apt update && sudo autoremove -y && sudo apt clean -y'
alias remove='sudo rm -r'
alias gitc='git clone'
alias gitcr='git clone --recursive'
```

将`username`替换为您的实际用户名。在添加这些行后，通过点击“保存”或通过文件菜单保存更改。这些调整增强了特定应用程序的系统性能，并设置了方便的命令别名。

## mount_options.conf

访问udisks官方网站`https://www.freedesktop.org/wiki/Software/udisks/`获取有关`udisks`的信息。

通过命令行和图形界面设置`mount_options.conf`：

只需输入这些命令：

```
sudo apt update
```

```
sudo gedit /etc/udisks2/mount_options.conf
```

使用以下内容修改上述`mount_options.conf`文件：

```
[defaults]
ntfs_defaults=uid=$UID,gid=$GID
```
