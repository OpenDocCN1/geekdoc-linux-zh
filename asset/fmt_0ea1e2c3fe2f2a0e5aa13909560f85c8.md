
## 5.2.4 如何通过 Samba 挂载远程 Windows 文件系统？

远程 Windows 文件系统可以通过 Samba 协议挂载到 Linux 文件系统上（必须安装 Samba，如果没有请安装）。输入此类命令（以 `root` 身份）：

```
smount //mars/windows /mnt/mars
```

这挂载了来自名为 `mars` 的 MS Windows 机器的 `windows` 资源。挂载发生在客户端电脑上（这本不是必要的，但在系统中是这样的）。选项 `"c"` 指定服务器是名为 `mars` 的机器——

为了实现上述操作，必须在 MS Windows 机器上授予共享驱动器或目录作为资源的权限。要做到这一点，在 MS Windows 上，使用“control panel-network”启用文件共享，启动“Windows Explorer”，在要共享的驱动器或目录上点击右键，点击“sharing”页面，赋予自己权限并给出资源名称。

卸载 MS Windows 目录：

```
smount /mnt/mars_windows
```

如果你遇到问题，请查看：

```
man smount
```

## 5.2.7 mount 命令太长了，如何用别名（alias）来简化它？

别名（`alias`）是更复杂或常用命令的缩写。为了创建别名，我以 `root` 身份编辑 `/etc/bashrc` 文件。这样别名对系统中的所有用户都可用。（如果要创建用户特定的别名，我会编辑家目录下的 `/.bashrc` 文件）。我的 `/etc/bashrc` 相关部分看起来如下：

```
alias cdrom=mount -v /mnt/cdrom
alias ucdrom=unmount -v /mnt/cdrom
alias dsdrive=mount -v /mnt/dsdrive
alias udsrive=unmount -v /mnt/dsdrive
alias zipdrive=mount -v /mnt/zipdrive
alias zipdrive=unmount -v /mnt/zipdrive
alias floppy=mount -v /mnt/floppy
alias ufloppy=unmount -v /mnt/floppy
```

选项 `-v` 代表“verbose”（详细模式），即它告诉 Linux 在漫长的挂载过程中与我交互。要生效别名，用户必须重新登录。现在用户可以使用这个简单的命令挂载软盘：

```
floppy
```

他/她可以使用以下命令卸载它：

```
ufloppy
```

## 5.2.8 我可以自动挂载吗？

可以的，你可以在访问文件系统时自动挂载，并在停止使用时自动卸载。这与你在 MS Windows 中体验的原理类似。如果你在 DOS 或 Windows 下频繁地使用可移动式介质，你会发现自动挂载并非完全万无一失。

Linux 下有两个用于自动挂载的工具，它们被称为 `"supermount"`。

### 5.2.8.1 Supermount

Mandrake 7.2 提供了使用 `"supermount"` 作为设置选项的机会。最简单的方法是安装 Supermount 并选择该选项。在运行 Mandy 的电脑上编辑 `/etc/fstab` 可能包含以下行：

```
/dev/sda1 /ext2 defaults 1 1
one /dev/pts devpts mode=020 0 0
/dev/sda4 /home ext2 defaults 1 2
/mnt/cdrom /mnt/cdrom supermount fs=iso960,dev=/dev/cdrom 0 0
/mnt/floppy /mnt/floppy supermount fs=vfat,dev=/dev/fd0 0 0
/mnt/zip supermount fs=vfat,dev=/dev/zip 0 0
one /proc proc defaults 0 0
/dev/hdb2 /usr defaults 1 2
/dev/hdb5 swap defaults 0 0
```

在上面的示例中，你可以注意到我选择了 `supermount` 处理 3 个文件系统：`cdrom`、`floppy` 和 `zipdrive`。我可以手动编辑 `/etc/fstab` 文件（例如使用 `vipco`），或者使用 `supermount` 命令根据我的需求自定义 `supermount`。

### 5.2.8.2 自动挂载 (Automount)

为了设置 `automount`，我首先运行程序 `systemctl`（以 `root` 身份）并确保自动挂载服务 (`autofs`) 已启用。

然后，我通过编辑 `/etc/auto.master` 和 `/etc/auto.misc` 来配置自动挂载。例如（以 `root` 身份）：`pico /etc/auto.master`。我的配置如下：

```
misc /etc/auto.misc  -timeout 1
```

这意味着我的设备将在我退出目录后自动卸载（你可以选择较短的时间）。详细配置文件是 `/etc/auto.misc`。我的如下：

```
kernel -ro,soft,ftp.pub/linux
cdrom -ftype=auto /dev/cdrom
floppy -ftype=auto,rw /dev/floppy
dossrive -ftype=vfat /dev/sda
dossrive -ftype=vfat,rw /mnt/data
hacker -ftype=nfs,rw /mnt/cdrom
hacker_floppy -ftype=nfs,rw /mnt/floppy
hacker_user -ftype=nfs,rw /home
```

每行由三个空格定义的字段组成。第一个是设备将挂载的子目录（在 `misc` 下）。该目录`必须不存在`。当我使用命令时它是不可见的，但当我 `cd` 进入它时，我的设备就会挂载。不要问我如何实现的，以及如何在 GUI 中使用自动挂载。我不知道。我家庭网络中另一台电脑的 `cdrom` 和 `floppy`。

我自动挂载到 `/misc` 目录（而不是 `/root`），这样我也可以使用自动挂载手动将挂载到该目录。
