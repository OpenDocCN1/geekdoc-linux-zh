# BGP (边界网关协议)

在互联网上，BGP 用于通信。例如，假设 ALICE 需要向 BOB 发。然而，ALICE 并没有直接连接到 BOB。ALICE 必须确定发送到哪个 ISP。“边界”这一名称源于 BGP 使用了它们的边界。关键点：BGP 可以被多种方式破坏。BGP 通常是未经认证的，恶意的 ISP 可能会造成破坏。来自 Hacking-Linux。

# bibindex

快速索引 BibTeX 参考文献数据库将 `.bib` 文件转换为快速文件，快速文件是 `.bib` 文件的压缩二进制表示，包含用于快速查找的哈希表以及对应 `_bib` 文件的偏移位置；`bibbook` 提供使用 `_bib` 和 `bib` 文件的交互查找功能。它验证文件号和 `bibindex` 版本号是否匹配，还会比较文件时间以检测 `.bib` 文件相对于 `.bib` 是否过期。在任何情况下，执行都会终止。此 Debian 软件包通过 GNU readline 库具有命令行历史机制。来自 Debian 3.0r APT
