## 使用 Ekiga 进行视频会议

Ekiga 是一款互联网视频会议应用程序，它通过 H.323 协议在互联网上提供双向语音和图像传输，用于 IP （也称为 IP 语音 [VoIP]）。它是一个类似于 Microsoft NetMeeting 的应用程序，并作为 Fedora 的默认视频会议客户端提供。

在充分利用 Ekiga 的电话和视频会议功能之前，你必须配置支持全双工的声卡和视频设备（参见第 7 章“多媒体”）以及摄像头。
