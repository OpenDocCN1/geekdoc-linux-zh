
### 第 3 步
你需要输入 `y` 以确认安装，这将占用系统中约 5.5MB 的存储空间。Stella 安装完成后，你可以再次看到 Mint 在菜单中自动创建了“游戏”类别以及应用程序快捷方式。

![](img/5019375da05cbf0090115165d80772a1_49_1.png)

### 第 4 步
有时，在安装软件时，你需要添加该应用程序的软件仓库。仓库（repo）仅仅是保存软件及其所有依赖项（使其正常运行所需的重要库等）的远程服务器位置。先输入以下内容：`sudo add-apt-repository ppa:peterlewi/ppa`。当被要求添加 PPA（个人软件包存档）时，按 Enter。

![](img/5019375da05cbf0090115165d80772a1_49_3.png)

#### 第 5 步
这将添加 Variety 壁纸更换器的仓库，这是一个基于 Ubuntu 的应用程序，在 Mint 中可用并能自动更换壁纸。既然仓库已添加，请输入：`sudo apt-get update`，以更新新信息并将仓库内容添加到软件包数据库中。

![](img/5019375da05cbf0090115165d80772a1_50_0.png)

#### 第 6 步
现在要安装 Variety，请输入：`sudo apt-get install variety`。按 `y` 以确认并接受安装，以继续安装过程。安装完成后，你可以在终端中输入 `variety` 来运行该应用程序。

![](img/5019375da05cbf0090115165d80772a1_50_1.png)

## 移除应用程序

除了安装应用程序外，`apt` 命令还可用于移除任何应用程序，有助于保持系统整洁并释放资源。

### 第 1 步
要卸载或移除 Variety 应用程序，请输入以下内容：`sudo apt-get remove variety`。输入 `y` 以继续卸载该应用程序；请注意，移除应用程序后，你还会收到关于硬驱动器释放了多少空间的信息。

![](img/5019375da05cbf0090115165d80772a1_50_2.png)

### 第 2 步
虽然 `apt-get remove` 命令会卸载应用程序，但它不会清除随应用程序而来的额外杂乱文件，例如配置文件和库文件。要彻底清除这些杂乱文件，请输入：`sudo apt-get purge variety`。

![](img/5019375da05cbf0090115165d80772a1_50_4.png)

### 第 3 步
当你从系统中移除应用程序时，你会收到一些自动安装且不再需要的软件包的信息。你在之前的教程中已经看到，你可以使用以下命令来清理：`sudo apt-get autoremove`，然后按 `y` 接受该过程。

![](img/5019375da05cbf0090115165d80772a1_50_3.png)

### 第 4 步
最后，为了清理系统中所有未使用的软件包，并移除 `autoremove` 命令未清理的元素，你可以输入：`sudo apt-get autoclean`。最后这几个步骤对于保持 Linux Mint 系统处于良好运行状态以及削减因安装和升级造成的不必要冗余至关重要。

![](img/5019375da05cbf0090115165d80772a1_50_5.png)

# 通过终端安装应用程序 – 第二部分

大多数时候，你可以使用标准的 `apt-get` 命令从终端安装应用程序。然而，有时应用程序需要更多的操作。这意味着从源代码安装应用程序，这听起来虽然吓人，但其实并不可怕。

## 从源代码

你需要熟悉这里的命令是 `Configure`、`Make` 和 `Install`。你会发现很多应用程序都是从源代码安装的，所以这绝对是值得投入时间掌握的一项技能。

### 第 1 步
Linux 的源代码文件通常以 `.TAR.GZ` 或 `.TAR.BZ2` 形式提供。两者都是压缩文件，包含构建应用程序所需的所有核心文件。通过这个教程，通过在主目录创建新文件夹来开始：`mkdir vim`。

### 第 2 步
顺便说一下，Vim 是一个高级文本编辑器，我们将用它作为安装示例。进入新文件夹，`cd vim`，然后在新 Vim 文件夹内，在终端中输入以下命令：`wget ftp://ftp.vim.org/pub/vim/unix/vim-7.4.tar.bz2`。

### 第 3 步
`wget` 命令从互联网获取内容，在这种情况下是 Vim 的 BZ2 文件。要检查文件是否成功下载，请输入 `ls`。根据 Mint 的文件系统颜色标记，压缩文件应以红色显示。

![](img/5019375da05cbf0090115165d80772a1_51_0.png)
![](img/5019375da05cbf0090115165d80772a1_51_1.png)

### 第 4 步
现在我们需要解压缩文件的内容，所以在终端中输入：`tar -xf vim-7.4.tar.bz2`。注意：你可以输入 `tar -xf v` 并按 Tab 键来自动填充剩余的文件名。

![](img/5019375da05cbf0090115165d80772a1_51_2.png)
![](img/5019375da05cbf0090115165d80772a1_51_3.png)

## 通过终端安装应用程序 — 第 2 部分

### 步骤 5
如果你再次输入 `ls`，你会注意到一个新文件夹已被创建：`vim74`；在 `Mint` 系统中，文件夹通常以浅蓝色文本表示。为主应用程序创建根文件夹总是很方便。你可以通过这种方法升级应用程序，每个版本将有其自己的文件夹。

![](img/5019375da05cbf0090115165d80772a1_52_0.png)

### 步骤 6
输入 `cd vim74` 以进入该文件夹，然后再次输入 `ls` 查看其内容。里面可能有很多文件；大多数是应用程序的核心文件，而另一些则标记为 `README` 或 `INSTALL`。首先阅读这些文件总是明智之举，因为它们提供了关于安装的宝贵信息。

![](img/5019375da05cbf0090115165d80772a1_52_1.png)

### 步骤 7
安装的第一部分要求你输入 `./configure`。`./configure` 命令将检查你的系统是否缺少与该应用程序相关的依赖项。如果你收到有关 C 编译器的错误，请输入：`sudo apt-get install build-essential`。第三方应用程序 `Ncurses` 被记录为缺失。我们需要使用以下命令安装它：`sudo apt-get install libncurses5-dev libncursesw5-dev`。

![](img/5019375da05cbf0090115165d80772a1_52_2.png)

### 步骤 8
根据应用程序的不同，你可能需要继续安装新的依赖项。每当安装完一个新的依赖项后，重新运行 `./configure`，当它不再报告错误时，你可以继续安装过程的下一个阶段。注意：你可能需要在线搜索某些错误信息。

![](img/5019375da05cbf0090115165d80772a1_52_3.png)

### 步骤 9
在 `./configure` 成功运行后，系统将创建一个 `Makefile`。需要通过在终端中输入 `make` 来“制作”它。根据应用程序的大小，这可能需要一些时间。

![](img/5019375da05cbf0090115165d80772a1_52_4.png)

### 步骤 10
最后，你需要在终端中输入：`sudo make install`。这将安装该应用程序，并使其在系统中就绪可用。完成后，你就可以执行该应用程序，在本例中是通过在终端中输入 `vim` 或通过 Dash 搜索它来执行。

![](img/5019375da05cbf0090115165d80772a1_52_5.png)
