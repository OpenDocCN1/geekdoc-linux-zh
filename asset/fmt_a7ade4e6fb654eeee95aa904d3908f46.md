## 第 2 章 体系体系

在学习如何编程之前，你首先需要理解计算机如何解释程序。你不需要电子工程学位，但你需要理解一些基础知识。

现代计算机架构基于一种名为冯·诺依曼架构的架构，它以发明者的名字命名。冯·诺依曼架构将计算机分为两个主要部分——CPU（中央处理单元）和内存。这种架构用于所有现代计算机，包括个人计算机、超级计算机、主机，甚至手机。

## 计算机内存结构

为了理解计算机如何看待内存，请想象你当地的邮局。他们通常有一个装满了邮箱箱（PO Boxes）的房间。这些箱与计算机内存的相似之处在于，它们都是编号的固定大小存储位置。例如，如果你有 256 MB 的计算机内存，这意味着你的计算机大约包含 2.56 亿固定大小的存储位置。或者用我们的类比，就是 2.56 亿邮箱箱。每个位置都有一个编号，且每个位置的大小都是相同的固定长度。邮箱箱和计算机内存的区别在于，你可以在邮箱箱中存储各种东西，但在计算机内存存储位置中你只能存储一个数字。

计算机内存用于许多不同的事情。所有计算结果都存储在内存中。事实上，所有“存储”的内容都存储在内存中。想象你的电脑，并想象内存里存储了什么。

- 光标在屏幕上的位置
- 屏幕上每个窗口的大小
- 使用的字体每个字母的形状
- 每个窗口的控件布局
- 工具栏图标的图形
- 每个错误消息和对话框的文本
- 列表将持续如此……

除了这些之外，冯·诺依曼架构规定，不仅计算机数据应该存在内存中，控制计算机运行的程序也应该存在那里。事实上，在计算机中，程序和程序数据之间没有区别，在于计算机如何使用它们。它们的存储和访问方式是相同的。

## CPU

那么计算机是如何运行的呢？显然，存储数据并没有太大帮助——你需要能够访问、处理和移动它。这就是 CPU 派上用场的地方。

CPU 从内存中一次读取一条指令并执行。这被称为取指-执行周期。CPU 包含以下元素：

- 程序计数器
- 指令解码器
- 数据总线
- 通用寄存器
- 算术逻辑单元

**程序计数器**用于告诉计算机从哪里获取下一条指令。我们之前提到过数据和程序的存储方式没有区别，只是 CPU 的解释方式不同。CPU 首先查看程序计数器，并获取内存中存储的任何数字。然后它被传递给解码器，由其弄清楚指令的含义。

## 术语

计算机内存是一系列带有编号的固定大小存储位置。附加在每个存储位置上的数字称为其*地址*（address）。单个存储位置的大小称为*字节*（byte）。在 x86 处理器上，一个字节是 0 到 255 之间的一个数字。

你可能奇怪，当计算机只存储 0 到 255 之间的数字时，是如何显示和使用文本、图形甚至大数字的？首先，像显卡这样的专用硬件对每个数字都有特殊的解释。在显示到屏幕时，计算机使用 ASCII 码表将你发送的数字翻译成显示在屏幕上的字母，每个数字精确对应一个字母或数字¹。例如，大写字母 A 由数字 65 表示。数字 1 由数字 49 表示。因此，要打印 "HELLO"，你实际上会给计算机数字序列 72, 69, 76, 76, 79。要打印数字 100，你会给计算机数字序列 49, 48, 48。附录 D 中包含了 ASCII 字符及其数字代码的列表。

除了使用数字表示 ASCII 字符外，你作为程序员也可以让数字代表你想要的任何。例如，如果我经营着一家商店，我会用一个数字来代表我出售的每件商品。每个数字都会与其他一系列数字相关联，这些数字就是当商品被扫描时我想显示的 ASCII 码。我还会更多的数字来表示价格、库存数量等。

¹ 随着国际字符集和 Unicode 的出现，这已不再完全正确。然而，为了让初学者易于理解，我们将假设一个数字直接翻译为一个字符。更多信息请参阅附录 D。
