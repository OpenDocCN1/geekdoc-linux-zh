## 使用 `getopts` 解析命令行

让我们首先介绍如何使用 `getopts` 命令解析命令行中的 `-s` 和 `-S` 关，以及我们用于定义浮点数精度的参数。使用 `getopts` 进行命令行解析是最简单的方法。这比尝试在壳脚本内部编写所有可能性要简单得多。关于 `getopts` 注意的第一点是，该命令不在乎命令行上是什么！`getopts` 只关心命令开关，这些开关必须以连字符 (`-`) 开头，例如此壳脚本中的 `-s` 和 `-S`。让我们看看 `getopts` 代码段及其工作原理。

```bash
# 解析命令行参数以查找精度值（如果存在）。

while getopts ":s:S:" ARGUMENT
do
  case $ARGUMENT in
    s) SCALE=$OPTARG ;;
    \?) # 因为我们可能有负数，所以我们需要
         # 测试 ARGUMENT 是否以连字符
         # (-) 开头是一个数字，而不是无效的开关！！！
         ;;
  esac

  for TEST_ARG in "$@"; do
    if [[ $(echo $TEST_ARG | cut -c1) = '-' ]] \
       && [ $TEST_ARG != '-s' -a $TEST_ARG != '-S' ];
    then
      case $TEST_ARG in
        +([-0-9])); # 无操作，什么都不做
          ;;
        +([-0-9]\.[0-9]))
          # 无操作，什么都不做
          ;;
        +([-0-9.-)); # 无操作，什么都不做
          ;;
        *) echo "ERROR: $TEST_ARG is an invalid argument"
          usage
          exit 1
          ;;
      esac
    fi
  done
done
```

## Here Document（此处文档）与结果展示

我想在这里再次介绍此处文档，因为了解这种技术可以做什么和不能做什么至关重要。创建好数学语句后，我们已经准备好创建一个此处文档，使用 `bc` 工具将所有数字相加。让我们来看所示此处文档：

- 在此处使用此处文档进行数学运算，为 `bc` 命令提供输入。数字的差被赋值给 `DIFFERENCE` 变量。

```bash
DIFFERENCE=$(bc <<EOF
scale=$SCALE
($SUBTRACT)
EOF
)
```

与列表 22.1 `float_add.ksh` 中的此处文档一样，该文档标识是 `EOF` 字符字符串。`bc` 命令通过其起始 `EOF` 标签和结束 `EOF` 标签获取输入。第一个标签开始此处文档，第二个 `EOF` 标签结束此处文档。两个标签之间的每一行都被用作 `bc` 命令的输入。此处文档有几个要求。第一个要求是：此处文档的任何行开头，语句前不能有双倍的任意空格。第二个要求是开头永远不能有任何空格。如果在第一列放置了一个空格，计算时可能会发生奇怪的事情。这是在编写此处文档时产生许多挫败感的根源。这个空格问题是在你测试或使用带有此处文档的 shell 脚本时，最难发现的编程错误之一。
