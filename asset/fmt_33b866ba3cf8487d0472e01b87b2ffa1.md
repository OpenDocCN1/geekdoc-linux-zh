
## 6.12 进程控制

### `ps`
`(="打印状态" 或 "进程状态")` 显示当前运行的进程列表及其进程 ID (`PID`) 数字。使用 `aux` 查看当前系统中正在运行的所有进程（包括其他人的或使用控制终端的进程），并显示用户名。使用 `"top"` 持续列出当前运行的进程。

### `any command &`
在后台运行任何命令（符号 `"&"` 意味着前一个命令在后台运行）。屏幕上会打印作业号，如果你需要，可以将其调回前台（见下文）。当我从 `X` 终端启动 GUI 程序时，经常使用 `"&"`。

- `jobs` 列出我的后台或已停止的进程，并显示它们的作业号。
- `fg job_number` 将后台或停止的进程调回前台。
- `bg job_number`

将进程置于后台，就像它是这样启动的一样。这将重启已停止的进程。可以通过 `<ctrl>z` 停止当前的前台进程。如果你停止了后台作业，需要连续输入两次才能注销。

### `batch`
`atupdated<ctrl>-d`

当系统负载低时运行任何命令（通常某个命令需要更多时间来完成）。当计数较低时，进程将继续运行。当命令完成后，将向你发送输出的邮件。在上面的示例中，`"at"` 代表提示符，命令开始运行，`<ctrl>-d` 终止你对 `batch` 的输入（我可以按 `<Enter>` 在运行启动许多命令）。

### `at 17:00`
在指定时间执行命令。系统会提示你要运行的命令，直到你按下 `<ctrl>-d`。`atq` 命令将显示通过 `at` 启动的进程队列，并从 `"at 队列"` 中移除进程。

### `kill PID`
`kill job_name`

强制关闭进程。使用 `ps` 确定要杀死的进程的 `PID`。

### `nohup program_name`
`(=no nohup)`。运行 `program_name` 使其在在你注销时不会终止。输出重定向到家目录下的 `nohup.out`。你肯定不想在 `nohup` 下运行交互式程序。

### `lspci`
显示主板信息以及插入 `pci` 扩展槽的显卡。我的电脑有 `Isa` 槽（或 `EISA` 槽），没有 `pci`。

### `ldev`
显示硬件信息（`DMA`、`IRQ`、`IO` 端口）。

### `llsf|more`
列出系统打开的文件。

### `kernelcfg`
（以 `root` 权限通过 `X` 终端）图形化界面，用于添加/删除内核模块。模块类似于设备驱动程序——它是 `Linux` 内核的一部分，用于为特定的硬件或功能提供支持。你也可以通过命令行使用 `insmod` 命令完成相同的功能。

### `ismod`
`(= modules)` 当前加载的内核模块。模块是一个设备驱动程序——它为特定的硬件或功能提供系统内核支持。

### `modprobe -l|more`
列出内核可用的模块。所有可用模块取决于你内核的编译方式。每个可能的模块/功能都可以在 `Linux` 上被编译为：`"内置"`（`wired`，可能快一点）、`"模块"`（`module`，可能慢一点，可加载/卸载）或`"无"`（`no`，完全不支持）。内核支持（取决于编译时）的文件都是位于 `/lib/modules` 目录及其子目录下的文件，因此如果你迷路了，浏览这些目录可能会给你线索。如果内核不支持你需要的模块，你可能需要重新编译内核并启用该模块（这很少见，因为`"标准"` `RedHat` 或 `Mandrake` 内核带有所有常见和非实验性的模块，如果你使用的是前沿版本的话……）。

### `modprobe sb`
加载 `soundblaster` (`sb`) 模块。使用之前的命令查找其他可加载的内核模块。

### `insmod proper`
将模块插入内核（模块大致等于 `DOS` 设备驱动程序）。通常使用`"modprobe"`（上一个命令）来插入模块。此示例显示了如何为外部支持端口-100-mb zip 模块（`RH6.0` 和 `6.1` 似乎无法其他方式让外部 zip 工作）。对于 250MB 的外部 zip，使用名为 `ppa` 的模块。

### `rmod module_name`
（以 `root` 权限）从内核中移除模块 `module_name`。

### `deps`
（以 `root` 权限）为内核构建依赖表。除非修改了 `etc/modules` 并想要重启，否则这是必不可少的。

### `set /dev/tty5 0x3f8 irq 4`
（以 `root` 权限）将串口设置为非标准设置。此示例显示了第一个串口 (`tty0`)的标准设置。第二个端口 (`tty1`) 的标准 `PC` 设置：`io` 地址为 `0x3f8`，`irq` `3`。第三个端口 (`tty2`)：`0x3e8`，`irq` `4`。第四个端口 (`tty3`)：`0x2e8`，`irq` `3`。如果你想在启动时设置它，请将你的设置添加到 `/etc/rc.local`。详细信息请参阅手册。在旧版本的 `Linux` 中，你还可以找到端口的替代名称（`cua0` 到 `cua3`），你可以用它们代替 `tty0` 到 `tty3`，但这些名称已经过时。

### `tune`
（以 `root` 权限，很少需要）调整你的并行端口。

### `/sbin/chkconfig --level 123456 kudzu off`
（以 `root` 权限）用于检查/启用/禁用系统服务的工具，这些服务将在不同的运行级别下自动启动
