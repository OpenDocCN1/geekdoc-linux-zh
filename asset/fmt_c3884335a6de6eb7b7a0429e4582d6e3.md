
第一个语句定义了包 `Hello`。`require Exporter;` 语句包含一个名为 `Exporter.pm` 的预定义模块；该模块为你处理了模块创建的细节。`@ISA = "Exporter";` 设置了 `@ISA` 数组，这是一个预定义数组，指定了查找子程序的包列表。`@EXPORT = ("helloworld");` 表示 `helloworld` 子程序可以被其他程序访问。如果你在模块中添加了其他子程序，请将它们的名称添加到赋值给 `@EXPORT` 的列表中。

正如你所看到的，当创建一个对象时，会假设它属于某个特定的类。要在此对象上使用另一个类的方法，请在调用方法时指定该类，例如：

`$myobject = new MyClass;`

`MyOtherClass::myMethod($myobject);`

这会调用名为 `myMethod` 的方法，该方法属于 `MyOtherClass` 类。

## 继承

Perl 允许你定义现有类的子类。这些子类继承其父类的方法。

以下代码是一个包含子类的模块示例：

`package MySubClass;`

`require Exporter;`

`require MyParentClass;`

`@ISA = ("Exporter", "MyParentClass");`

`@EXPORT = ("myChildRoutine");`

`sub myChildRoutine {`

` my ($object) = shift(@\_);`
` print ("$object[0]\n");`
`}`

`sub new { # 用于 MySubClass 的构造函数`
` my ($object) = MyParentClass->new();`
` $object[0] = "initial value";`
` bless($object);`
` return ($object);`
`}`

`1;`

该类包含一个方法 `myChildRoutine`，它会打印 `$object` 所引用数组的第一个元素。该类的构造函数调用了其父类 `MyParentClass` 的构造函数；该构造函数返回一个引用，该引用随后被 `MySubClass` 构造函数使用并返回。

注意模块开头定义的 `@ISA` 数组包含了父类 `MyParentClass` 的名称。这告诉 Perl，如果如果在 `MySubClass` 中找不到方法，则在名为 `MyParentClass` 的类中查找。

父类中的方法可以像定义在子类中一样被调用：

`use MySubClass;`

`$myobject = new MySubClass;`
`$myobject->myParentRoutine("hi there");`

这创建了一个 `MySubClass` 类的对象。代码随后调用了 `myParentRoutine`，这是一个属于 `MyParentClass` 类的方法。

## C 语言

C 是与 UNIX 关联频繁的编程语言。自 20 世纪 70 年代以来，操作系统的大部分应用程序都是用 C 编写的。由于 C 语言不直接依赖于特定的硬件

在架构方面，UNIX 是最早的可移植操作系统之一。也就是说，构成 UNIX 的大部分代码

既不知道也不在乎运行其上的实际计算机。与特定机器相关的特性被隔离在 UNIX 内核的几个

模块中，这使得在将其迁移到不同的硬件

架构时，能够修改这些模块。

C 语言最初由 Dennis Ritchie 设计，用于在 DEC PDP-11 计算机上的 UNIX 系统。该语言从

Martin Richard 的 BCPL 演变而来，其早期的形式之一是 B 语言，由 Ken Thompson 为

DEC PDP-7 编写。关于 C 语言的第一本书是 Brian Kernighan 和 Dennis Ritchie 编写的 *The C Programming Language*，并于 1978 年出版。

1983 年，美国国家标准协会（ANSI）成立了一个委员会来标准化 C 的定义。

它被称为 ANSI C，是语言语法和核心库set的公认标准。其语法与原始 C 语言 略有不同，原始 C 语言通常因 Kernighan 和 Ritchie 而称为 K&R C。本章

主要讨论 ANSI C。

## C 语言编程：基本概念

C 是一种编译型、第三代过程化语言。*编译*意味着 C 代码在 C 程序执行之前的某个时刻被分析、解释

并并翻译成机器指令。这些步骤由 C 编译器执行，并取决于 C 程序的复杂性，由 `make` 工具完成。程序编译后，可以执行多次，而无需重新编译。

*第三代过程化*这一短语描述了那些能够清晰区分程序中使用的数据与对该数据执行的操作的

计算机语言。用第三代语言编写的程序呈现为一系列显式的处理步骤（或过程），这些过程通过对数据在内存中位置的显式引用来操作数据结构的内容，并响应硬件中断来操作计算机硬件。

## C 程序中的函数

在 C 语言中，所有过程都以函数的形式存在。正如数学函数将一个或多个

数字转换为另一个数字一样，C 函数通常也是一个转换某些值或执行其他

操作并返回结果的程序。调用这种转换的行为被称为*调用函数*。

数学函数的调用可以嵌套，C 语言中的函数调用也是如此。当函数调用嵌套时，最内层函数的结果作为输入传递给下一个函数，依此类推。图 6.1 显示了对平方根函数的嵌套调用是如何进行算术求值的。

| sqrt( sqrt(256) ) = sqrt(16) | 4 |
| sqrt( sqrt( sqrt(256) ) ) = sqrt(4) = 2 |

其他语言中的非函数过程通常在程序中与其他代码共享的数据变量上操作。例如，一个非函数过程可能会在用户犯下键盘错误时更新程序范围内的 `COUNT_OF_ERRORS`。此类过程必须仔细编写，并且通常特定于最初创建它们的程序，因为它们引用了更广泛程序中特定的、共享的数据变量。

然而，函数在被调用时会接收所需的所有信息（包括每次实例中使用的数据变量的位置）。它既不知道也不在乎调用它的更广泛的上下文；它只是转换输入变量（参数）中找到的值（无论这些是什么），并将结果返回给调用它的任何其他函数。

由于过程是以函数形式实现的，用 C 编写的过程不需要知道它们将以何种或多深嵌套在其他函数调用内部。这种能力允许你在许多不同的程序中重用 C 函数，而无需修改它们。例如，图 6.2 中的 `Function 2` 可能会被另一个 C 程序中的 `Main` 逻辑直接调用。

整个 C 程序本身就是一个函数，在执行时会向调用它的程序返回一个结果代码。对于应用程序，它通常是一个外壳（shell），但也可能是操作系统的任何其他部分或其他任何 UNIX 程序。由于 C 程序都结构化为函数，它们可以被其他程序调用或嵌套在更大的程序中，而无需你以任何方式重写它们。

**注意：** C 语言的这一特性在很大程度上塑造了 UNIX 的外观和感受。与大多数其他运行环境相比，UNIX 系统由许多相互调用的小型 C 程序组成，这些程序被组合成更大的程序，或根据需要由用户调用。UNIX 通常不使用单式的集成应用程序，而是托管许多小型灵活的程序。你可以通过组合这些工具来完成新任务，从而定制你的工作环境。

## C 程序中的数据

在 C 程序中处理的数据有两种类型：字面量和变量。字面量是特定的、实际的数字或字符，例如 1、4.3。变量是与内存关联的可以存储值的名称。变量是有类型的；每个变量只持有一种类型。基本类型包括整数、浮点数和数组。数组是相同类型的序列。你也可以定义复杂结构。复杂数据将相关项汇到一个名称。典型的 C 程序几乎是一个陈词。它是“Hello, World”程序，打印简单的 `Hello, World`。
