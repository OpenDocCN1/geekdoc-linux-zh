# 20. 一个 Windows 管理员对配置的交换空间感到困惑，想知道 Linux 的推荐值。

- A. 与内存相同。
- B. 40–90MB。
- C. 与服务器相同。
- D. 内存的三倍。
- E. 没有推荐的交换空间；你需要确定具体需要多少。

- D. 虽然建议是内存的两倍，但这取决于机器的峰负载。对于内存较小的机器，交换文件有助于处理大型作业，并且在性能不足时是最佳的。事实上，你不想使用交换空间。如果你确实经常需要交换空间，那么你需要增加系统内存。
