```
while echo $var1

```

第一个测试只是显示 `var1` 变量的当前值。第二个测试使用括号确定 `var1` 变量的值。在循环内部，`echo` 语句显示一条简单消息，表示循环已被处理。注意运行示例时输出是如何结束的：

```

```

当 `var1` 变量等于 0 时，`while` 循环执行了 `echo` 语句，然后减少了 `var1` 变量的值。然后执行测试命令进行下一次迭代。执行了 `echo` 测试命令，显示 `var1` 变量的值，该值现在小于 0。直到 shell 执行测试命令，`while` 循环才终止。

这证明了在多命令 `while` 语句中，每次迭代（包括最后一个测试命令失败的最后一次迭代）都会执行所有测试命令。对此要小心。另一件需要小心的是如何指定多个测试命令。注意每个测试命令都在单独的行上！

### 使用 until 命令

`until` 命令的工作方式与 `while` 命令完全相反。`until` 命令要求你指定一个通常产生非零退出状态的测试命令。只要测试命令的退出状态为非零，Bash shell 就会执行循环中列出的命令。当测试命令返回零退出状态时，循环停止。

正如你所料，`until` 命令的格式如下：

```bash
until test commands
do
    other commands
done
```

与 `while` 命令类似，你可以在 `until` 命令语句中包含多个测试命令。只有最后一个命令的退出状态决定 Bash shell 是否执行定义的 *其他命令*。

以下是使用 `until` 命令的一个示例：

```bash
$ cat test12
#!/bin/bash
# using the until command

var1=100

until [ $var1 -eq 0 ]
do
    echo $var1
    var1=$[ $var1 - 25 ]
done
$ ./test12
100
75
50
25
$
```

此示例通过测试 `var1` 变量来确定何时停止 `until` 循环。一旦变量的值等于 0，`until` 命令就会停止循环。当你在 `until` 命令中使用多个测试命令时，我们在 `while` 命令中提到的注意事项同样适用：

```bash
$ cat test13
#!/bin/bash
# using the until command
var1=100
until echo $var1
[ $var1 -eq 0 ]
do
echo Inside the loop: $var1
var1=$[ $var1 - 25 ]
done
$ ./test13
100
Inside the loop: 100
75
Inside the loop: 75
50
Inside the loop: 50
25
Inside the loop: 25
0
$
```

Shell 会执行指定的测试命令，并仅在最后一个命令为真时才停止。

### 嵌套循环

循环语句可以在循环内使用任何类型的其他命令，包括其他循环命令。这被称为 *嵌套循环*。使用嵌套循环时应谨慎，因为你在一个迭代内执行另一个迭代，这会成倍增加命令执行的次数。如果你不密切关注这一点，可能会导致脚本中出现问题。

以下是一个将 `for` 循环嵌套在另一个 `for` 循环内的简单示例：

```bash
$ cat test14
#!/bin/bash
# nesting for loops

for (( a = 1; a <= 3; a++ ))
do
    echo "Starting loop $a:"
    for (( b = 1; b <= 3; b++ ))
    do
        echo "   Inside loop: $b"
    done
done
$ ./test14
Starting loop 1:
   Inside loop: 1
   Inside loop: 2
   Inside loop: 3
Starting loop 2:
   Inside loop: 1
   Inside loop: 2
   Inside loop: 3
Starting loop 3:
   Inside loop: 1
   Inside loop: 2
   Inside loop: 3
$
```

嵌套循环（也称为内层循环）会在外层循环的每次迭代中遍历其值。注意，两个循环的 `do` 和 `done` 命令之间没有区别。Bash shell 知道当第一个 `done` 命令执行时，它指的是内层循环而不是外层循环。

当你混合使用循环命令时也是如此，例如将 `for` 循环放在 `while` 循环内：

```bash
$ cat test15
#!/bin/bash
# placing a for loop inside a while loop

var1=5

while [ $var1 -ge 0 ]
do
    echo "Outer loop: $var1"
    for (( var2 = 1; $var2 < 3; var2++ ))
    do
        var3=$[ $var1 * $var2 ]
        echo "   Inner loop: $var1 * $var2 = $var3"
    done
    var1=$[ $var1 - 1 ]
done
$ ./test15
Outer loop: 5
    Inner loop: 5 * 1 = 5
    Inner loop: 5 * 2 = 10
Outer loop: 4
    Inner loop: 4 * 1 = 4
    Inner loop: 4 * 2 = 8
Outer loop: 3
    Inner loop: 3 * 1 = 3
    Inner loop: 3 * 2 = 6
Outer loop: 2
    Inner loop: 2 * 1 = 2
    Inner loop: 2 * 2 = 4
Outer loop: 1
    Inner loop: 1 * 1 = 1
    Inner loop: 1 * 2 = 2
Outer loop: 0
    Inner loop: 0 * 1 = 0
    Inner loop: 0 * 2 = 0
$
```
