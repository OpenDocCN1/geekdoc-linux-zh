## Glibc

### 内容

`Glibc` 软件包包含 GNU C Library。

### 描述

C库是程序中常用函数的集合。这样程序员就不需要为每个任务创建自己的函数。最常见的操作，如向屏幕写入字符串，已经存在并供程序员使用。

C库（实际上几乎所有的库）都有两种类型：动态和静态。简而言之，当程序使用静态 C 库时，C 库的代码会被复制到执行文件中。当程序使用动态库时，该执行文件不包含 C 库的代码，而是一个在程序运行时从库加载函数的例程。这意味着程序文件的大小显著减小。如果你不理解这个概念，最好阅读随附的 C 库文档，因为在这里用一两行解释太复杂了。

# Linux 内核

目录

Linux kernel 软件包包含 Linux 内核。

### 描述

Linux 内核是每个 Linux 系统的核心。它是 Linux 运行的关键。当你打开电脑并启动 Linux 系统时，加载的第一部分 Linux 软件就是内核。内核会初始化系统的硬件组件，如串口、并行口、声卡、网卡、IDE 控制器、SCSI 控制器等。简而言之，内核让硬件变得可用，从而让软件能够运行。

# Patch

# 目录

`Patch` 软件包包含 `patch` 程序。

### 描述

`patch` 程序根据补丁文件（patch file）修改文件。补丁文件通常是由 `diff` 程序创建的列表，其中包含了如何修改原始文件的指令。`Patch` 经常被用于源代码补丁，因为可以节省时间和空间。假设你有一个大小为 1MB 的包。该包的下一个版本仅对第一个版本中的两个文件发生了变化。你可以发送一个全新的 1MB 完整包，也可以提供一个 1KB 的补丁文件，将第一个版本更新到与第二个版本完全相同。因此，如果你已经下载了第一个版本，补丁文件可以节省大量的下载流量。

# GCC

# 目录

`GCC` 软件包包含编译器、预处理器和 GNU C++ 库。

## 描述 编译器

编译器将文本格式的源代码翻译成计算机可以理解的格式。在源代码文件编译成对象文件后，链接器将从一个或多个这些编译器生成的对象文件中创建一个可执行文件。

### 预处理器

预处理器对源文件进行预处理，例如将头文件的内容包含到源文件中。为了节省时间，你通常不需要手动执行此操作。你只需要插入一行 `#include <filename>` 即可。预处理器会将该文件的内容插入到源文件中。这就是预处理器的工作内容之一。

### C++ 库

C++ 库供 C++ 程序使用。C++ 库包含了 C++ 程序中频繁使用的函数。通过这种方式，程序员在每次创建程序时，都不需要从零开始编写函数（例如，向屏幕写入一段文本）。
