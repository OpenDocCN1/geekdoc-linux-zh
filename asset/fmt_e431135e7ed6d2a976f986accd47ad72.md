
`get_bit()`的工作也差不多。在`arg_C`为0的情况下，函数将清除数组中的特定位，否则设置相关位为1。已经知道数组用了64字节。无论是`set_bit()`函数还是`get_bit()`函数，它们的前两个参数相当于坐标。通过上面的分析，我们可以整理出`set_bit()`和`get_bit()`的源码：

```c
#define IS_SET(flag, bit) ((flag) & (bit))

#define SET_BIT(var, bit) ((var) |= (bit))

#define REMOVE_BIT(var, bit) ((var) &= ~(bit))

static BYTE cube[8];

void set_bit(int x, int y, int shift, int bit) {
    if (bit)
        SET_BIT(cube[x][y], 1 << shift);
    else
        REMOVE_BIT(cube[x][y], 1 << shift);
}

bool get_bit(int x, int y, int shift) {
    if ((cube[x][y] >> shift) & 1)
        return 1;
    return 0;
}
```
