
# DBA 的成长

## 第 20 章

历史上，人们通常从开发者（特别是 PL/SQL 开发人员）成长为 DBA 职位。那么，为什么你可能会回到开发岗位？实际上，有几个原因让许多人发现这条道路具有吸引力。

有些人不喜欢管理员职位的压力。它通常需要很长的时间并且压力很大。这会让一些人精疲力竭，从而回到开发者岗位。

另一个原因，也许更为常见，是语言。在合适的职位上，一名优秀的 `Java` 程序员的收入可能比 DBA 高。此外，`Java` 是新颖且令人兴奋的。因此它可以吸引许多人离开 DBA 岗位。同时，随着 Oracle 和 `Java` 变得越来越紧密，转型过程也变得更加容易。

无论你是否想学习 `Java` 这一门语言，你都需要了解它是如何在你的系统中使用的。你不需要成为一名资深的 `Java` 程序员也能理解它部署在哪里以及为什么要部署。在当今市场上，理解 `Java` 在数据库内部的角色以及 Web 服务器如何运行非常重要。未来，`Java` 可能会成为 Oracle DBA 的一项强制技能。

## 总结

本章探讨了 DBA 如何在职业和技术上成长。学习所涉及的技术已经足够困难了。一旦你掌握了这些技能，就需要保持它们的敏锐性并增加新技能。这可以通过课程、手册、书籍、网站、自主实践以及与其他共同学习来实现。这确实是一项永无止境的任务。

幸运的是，那些努力学习技术、获得认证并与他人建立人脉的人在财务上通常很好。Oracle DBA 是最受欢迎的 IT 人员列表中的顶端。无论你是顾问还是薪资员工，你应该会有不错的表现，如果没有，也有许多其他工作可以选择。大多数 DBA 还可以扩展到其他领域，包括系统管理、系统设计或 `Java` 开发。

## 附录 A：Unix 和 Linux 基础命令

本附录识别并描述了 DBA 常用的 Unix 命令。它并没有尝试提供所有可能的选项，但在实用的语境中显示命令。

- `bdf`：显示 HP-UX 服务器上的文件系统和磁盘空间量。使用此命令可以确定你拥有哪些文件系统以及每个文件系统的可用磁盘空间大小。

- `cat filename`：在屏幕上显示整个文件的内容。如果文件很大，文件输出将滚动通过。通过 `more` 管道传输此文件可以一次显示部分内容（例如 `cat long_file.txt | more`）。还使用 `/dev/null` 来擦除日志文件的内容（例如 `cat /dev/null > alertdemo.log`）。

- `cd directory_name`：移动到指定的目录。执行 `cd` 而不带目录将带你进入 `$HOME` 目录。可以使用绝对路径（例如 `cd /home/mikew/scripts`）或相对路径指定目录。要返回上一级目录，使用 `cd ..`；要回到用户的家目录，使用 `cd -username`（例如 `cd -mikew`）。

- `chgrp groupname filename`：更改指定文件的组。

- `chmod 644 filename`：更改指定文件的权限。第一个数字代表所有者的权限，第二个数字代表该组成员的权限，最后一个数字代表其他所有人的权限。读取权限 = 4；写入权限 = 2；执行权限 = 1。因此，在这种情况下，所有者具有读取和写入权限（4+2=6），其他人也是。

- `chown username filename`：更改指定文件的所有者。例如，`chown oracle test.sql` 将 `test.sql` 的所有者更改为 `oracle`。

- `clear`：清除屏幕之前的所有输出并将提示符移动到屏幕顶部。

- `compress filename`：将文件压缩到大约原始大小的三分之一，如果已压缩则添加 `.z` 扩展名。你可以预期 DMP 文件具有更高的压缩率，大约是原始的五分之一。

- `cp filename destination`：将文件复制到指定的地点。源位置和目标位置都会存在该文件的副本。在调用它到新位置时，可以使用 `-p` 选项来保留权限和修改日期。

- `crontab filename`：将文件加载到用户的 crontab 中由 cron 执行。`crontab -e` 允许你直接编辑 crontab，`crontab -l` 列出用户的 crontab。最安全的方法是使用 `crontab -l > oracle.crontab`，编辑此文件包含你的更改，然后重新加载回 `crontab oracle.crontab`。

- `date`：显示当前的日、日期时间。

- `df`：显示你的文件系统以及每个文件系统的可用空间。通常配合 `-k` 选项使用以千字节为单位显示结果（例如 `df -k`）。

- `diff filename1 filename2`：比较两个文件名并显示它们之间的差异。

- `dmesg`：显示来自操作系统生成的消息。当你正在寻找服务器问题或尝试获取更多系统信息时，这非常有用。通常通过 `more` 管道传输（例如 `dmesg | more`）。

- `du -s *`：显示你当前位置下方每个子目录的磁盘占用情况。这对于寻找包含大文件的目录进行清理非常有用。

- `echo "text string"` 或 `echo $ENV_VARIABLE`：将字符串的内容或变量的值回显到屏幕。在 shell 脚本中输出字符串很常见。输出变量有助于验证你的环境（例如 `echo $ORACLE_SID` 或 `echo $ORACLE_HOME`）。

- `env`：显示你所有的环境变量。通常通过管道输出（例如 `env | more`）以便更具可读性。

- `exit`：退出。

- `find -name filename`：在目录中搜索文件。

- `ftp`：打开 FTP（文件传输协议）连接到主机。

- `fuser filename`：识别使用文件的进程。

- `grep -i string filename`：搜索字符串的出现情况。

- `head -n filename`：显示文件的前 n 行。

- `id`：显示你的 ID、用户名、主组和其他组。

- `iostat`：监控 I/O 活动。

- `ipcrm`：移除内存段和信号量。

- `ipcs`：显示共享内存和信号量。

- `kill PID`：终止带有 PID 的进程。

- `last`：显示用户上次登录的时间。

- `ln -s target link_name`：创建软链接。

- `ls`：列出文件。

- `mail`：准备发送电子邮件。

- `gzip filename`：压缩文件并添加 `.gz` 扩展名。

- `gunzip filename`：解压/解压缩文件。

- `man command`：显示 Unix 命令的帮助页。

- `mkdir directory_name`：创建指定的目录。

- `more filename`：一页页显示文件内容。要继续逐页显示，请按空格键。要逐行推进，请按回车键。要停止查看文件，请按 `CTRL-C`。

- `mv filename destination`：将文件从一个位置移动到另一个位置。在此过程中也可以重命名文件。

- `nohup command &`：为命令指定不挂断选项。基本上，如果你执行了一个长时间运行的命令或启动了一个会话并在其结束时终止命令或程序，你的命令/程序将继续处理直到完成。这通常与 `&` 一起使用，将命令/程序放在后台运行，以便你可以从同一个提示符继续使用它。例如，`nohup exp file=customer.par &` 会启动 Oracle 导出并将任务置于后台。随后你可以注销机器，导出仍将继续运行。

- `page filename`：一页页显示文件内容。要继续逐页滚动，请按空格键。要逐行推进，请按回车键。要停止查看文件，请按 `CTRL-C`。

- `ps -ef`：调用所有运行的 Unix 进程。选项 `-elf` 显示额外信息。这通常与 `grep` 配合查找 Oracle 后台进程（例如 `ps -ef | grep ora`）。

- `rm filename`：删除指定的文件。在使用带有通配符 `*` 的 `rm` 时要极其小心，非常容易误删并不打算删除的文件。

- `rmdir directoryname`：如果目录为空则删除该目录。如果目录包含文件，请使用 `rm -r directoryname` 来删除及其所有子目录。

- `rpm -Uvh packagename.rpm`：使用 Red Hat 包管理器在 Linux 上安装 `packagename.rpm`。要查看已安装哪些包，使用 `rpm -qa`。

- `sar`：系统活动报告，可以显示各种操作系统统计数据。它经常用于监控服务器，并有多个选项。

- `script filename.txt`：创建显示在屏幕上所有内容的日志，直到你按下 `CTRL-D`。这类似于 SQL*Plus 中的输出存储。在应用补丁时运行此命令很有用。

- `su - username`：提示输入密码以指定用户登录。连字符（`-`）表示在登录时将执行用户的 `.profile` 并建立新的环境变量。如果没有指定连字符，用户将继承上一个用户的环境。通常没有理由在不设置妥当环境的情况下以某个用户身份登录，通常你应该使用连字符。

- `tail -n filename`：显示文件的最后 n 行。要持续查看正在不断添加的日志文件末尾，请使用 `tail -f filename`；该文件将一直显示文件末尾，直到你按下 `CTRL-C`。`-f` 选项通常用于监控导出或导入日志，而 `-n` 选项用于查看告警日志尾部。

- `talk username`：请求与特定用户进行在线会话。这是与登录在同一服务器上的另一个用户通信的方便方法。通信将一直持续直到你用 `CTRL-C` 退出。要刷新屏幕，请使用 `CTRL-L`。

- `tar -cvf filename.tar directory`：将目录、子目录和所有文件创建一个名为 `filename.tar` 的文件。该 TAR 文件可以压缩并通过 `cp` 或 `ftp` 传输到不同的位置。一旦移动到目标位置，可以通过在新位置执行 `tar -xvf filename.tar` 来重建目录、其子目录和所有文件。这是将目录树从一个服务器移动到另一个服务器的常用方法。Oracle 补丁通常是 TAR 文件格式。

- `top`：调用 Unix 服务器监控工具。这是一个非常有用的默认工具，因为它提供了性能和负载的良好快照。

- `touch filename`：尝试在当前目录下创建一个空文件。用此判断你是否对某个目录具有写权限。例如，在创建 `oradata` 目录后，以 `oracle` 用户身份 `touch` 文件以确认其具有必要的权限。

- `truss PID`：跟踪给定进程 ID 的所有系统调用。当你需要确切查看进程在 Unix 级别正在做什么时，此命令非常有用。

- `umask 022`：如果默认权限是 666，则将默认权限设置为 644。

- `uname -a`：显示操作系统类型和版本、服务器名称以及当前时间。这提供了关于你正在使用的服务器的基础信息。

- `uncompress filename.Z`：解压文件。确保你的文件系统有足够的空间存放解压后的文件。

- `uptime`：显示当前时间、服务器自上次重启以来已运行的时间、服务器上的用户数以及 5 分钟前和 15 分钟前的平均负载。

- `vmstat`：显示各种 Unix 监控统计数据。该命令有多个选项，非常有用。

- `wall`：向服务器上的每个用户广播消息。输入 `wall` 后按回车，输入消息，最后按 `CTRL-D` 发送。将其用于此类公告，例如“数据库将在五分钟后关闭。请立即注销！”

- `wc -l filename`：给文件行数计数。将其与 `grep` 配合使用统计找到的行数。例如，要查看 alert log 中 Oracle 错误的数量，执行 `grep -i ORA alert.log | wc -l`。这将向你显示包含 ORA 的行数。

- `which command`：确定当你执行命令时将使用哪个可执行文件。例如，`which sqlplus` 可能会显示 `/u01/app/oracle/product/8.1.6/bin/sqlplus`。

- `who`：显示登录系统的用户、其 tty 以及他们的登录时间。

## 附录 B：vi 编辑器

`vi` 编辑器是 Unix 和 Linux 上常用的编辑器。虽然最初学起来很困难，但你需要知道如何使用 `vi`，因为它是大多数机器上的标准编辑器。本附录列出了常用的 `vi` 命令。学习 `vi` 的最好方法是编辑文件。学习 `vi` 很大程度上是在学习如何打字；起初很难且笨拙，但过了一段时间，就会变成本能。在使用 `CAPS` 键时遵循以下通用规则：`vi` 有两种模式：插入模式。当你打字时，你处于插入模式。在执行任何命令或移动光标之前，必须按下 `ESC` 键进入命令模式。要离开命令模式并开始插入文本，必须按下 `i` 进行插入或 `a` 进行追加。追加允许你在光标位置后输入文本。要调用 `vi` 创建或编辑特定文件，输入以下内容：

```
vi filename
```

## 附录 C：脚本

以下是我多年来使用的一些脚本。它们都不算复杂，所以你应该能够轻松地理解它们。大多数只是为了节省输入时间而编写的固定查询，因此你不会发现它们有非常精美的注释或文档。我发现许多我再次需要的即时查询，所以为什么不把它们写成脚本呢？我通常把它们放在软盘上，带到现场，并在过程中不断添加。

如果你需要，可以随时修改这些脚本，但在使用之前请确保你理解它们。记住，在没有亲自阅读之前，永远不要运行任何人的脚本。真正复杂的脚本可以通过其他来源获取，我建议尽可能使用它们，而不是重造轮子编写自己的。然而，我不会通过从互联网或其他任何地方捡来的神秘脚本来信任我系统的安全性。

最重要的是，我希望这些脚本被证明是有用的，并能为你自己的脚本提供灵感。

### login.sql

```
REM This file provides custom display settings with SQL*Plus.
REM Have it in the directory from where you start SQL*Plus.

set pagesize 25
col member format a60
col file_name format a60
col tablespace_name format a20
col owner format a15
col object_name format a30
col initial_extent format 999,999,999
col next_extent format 999,999,999
col bytes format 999,999,999
col sum(bytes) format 999,999,999
select name, log_mode from v$database;
show user;
```

### show_session_short.sql

```
select s.username, osuser, status, server as "Connect Type",
to_char(logon_time,'HH:MI:SS AM') as "Logon Time",
sid, s.serial#, p.spid as "UNIX Proc"
from v$session s, v$process p
where s.paddr = p.addr
and s.username is not null
order by status, s.username, s.program, logon_time
/
```

### show_dba_rollback_segs.sql

```
select segment_name, owner, tablespace_name, initial_extent,
next_extent, min_extents, max_extents,
status, instance_num from dba_rollback_segs
/
```
