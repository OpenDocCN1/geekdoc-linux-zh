
变量引用 `$(foo)` 被展开，得到 `bar`，这被视为变量名。变量 `bar` 不被展开，但会检查其值以确定其是否非空。

```makefile
bar = true

foo = bar

ifeq ($(foo),bar)

else
```

```makefile
frobozz = yes

endif
```

## 7.3 测试字符串的条件

通常你可能想要测试一个变量是否具有非空值。当该值是由变量和函数的复杂展开时，你认为为空的扩展实际上可能包含空白字符，因此不被视为为空。然而，你可以使用 `strip` 函数（参见节 8.2 [文本函数]）来避免将空白解释为非空值。

```makefile
ifeq($(strip $(foo)),)

text-if-empty 文本

endif
```

如果 `$(foo)` 的展开不包含空白字符，将评估 `text-if-empty`。

```makefile
ifeq (arg1, arg2)

ifeq 'arg1', 'arg2'

ifeq "arg1" "arg2"

ifeq "arg1" 'arg2'

ifeq 'arg1' 'arg2'
```

展开 `arg1` 和 `arg2` 中的所有变量引用并对其进行比较。如果它们不同，则 `text-if-true` 有效；否则，如果存在 `text-if-false`，则它有效。

## ifdef 变量名

`ifdef` 取变量名为其参数，而不是变量的引用：该变量的值具有非空值，则 `text-if-true` 有效；否则，如果存在 `text-if-false`，则它有效。从未定义的变量具有空值。文本 `variable-name` 会被展开，因此它可能是一个变量或展开为变量名的函数。例如：

```makefile

endif
```

## 8 文本转换函数

函数允许你在 Makefile 中进行文本处理，以计算操作的文件或命令。函数的处理结果会被替换到调用处，就像变量一样。

### 8.1 函数调用语法

`text-if-true` 文本和 `text-if-false` 文本可以是任意行数的文本。如果条件为真，它们被视为 Makefile 的一部分。如果条件为假，则不使用这些文本。

### 8.2 字符串查找

`findstring` 函数确定一个字符串是否是另一个字符串的子串。如果你想测试 `-t` 标记，请使用 `-t` 作为第一个字符串，`MAKEFLAGS` 作为另一个。

```makefile
ifqfindstring t,$(MAKEFLAGS))

    touch archive.a

else

    ranlib archive.a

endif
```

## 8.2 字符串替换与分析函数

这里是一些对字符串进行的操作：

`$(sub from,to,text)`

对文本执行文本替换：*from* 的每个出现处都被替换为 *to*。结果将替换该函数调用。例如，

```
$(sub ee,EE,feet on the street)
```
在 *strEE* 上替换字符串 *fEE*。

`$(patsub pattern,replacement,text)`

在文本中查找匹配模式 *pattern* 的空格分隔的单词，并将其替换为 *replacement*。*Pattern* 可以包含一个 `%`，它作为通配符，匹配单词中任意数量的字符。如果 *replacement* 也包含 `%`，则该 `%` 被替换为匹配 *pattern* 中 `%` 的文本。只有 *pattern* 和 *replacement* 中的第一个 `%` 会被这样处理；任何后续随后的 `%` 均保持不变。

`patsub` 调用中的 `%` 可以用前面的反斜杠（\）进行引用。引用 `%` 字符的反斜杠可以使用更多的反斜杠进行引用。在模式与文件名比较或替换的字符串进行比较之前，引用 `%` 字符或其他字符的反斜杠会从模式中移除。例如，模式 '*the%weird\pattern\*' 在操作性 '%' 字符之前有 '*the%weird*'，在 '\' 之后有 '*pattern*'。这两个反斜杠会被原样保留，因为它们无法影响任何 '%'。

单词之间的空格被合并为单个空格字符；前后的空格被丢弃。

例如，

```
$(patsub %,c,o,x.c.c bar.c)
```
产生值 '*x.c.o bar.o*'。

替换引用（参见第 6.3.1 节 [替换引用]，第 62 页）是实现 `patsub` 函数效果的更简单的方法：

```
$(var:pattern=replacement)
```
等同于

```
$(patsub pattern,replacement,$var))
```

第二种简写简化了 `patsub` 最常用的用途之一：替换文件名末尾的后缀。

```
$(var:suffix=replacement)
```
等同于

```
$(patsub suffix,%replacement,$var))
```

例如，你可能有一列表对象文件：

```
objects = foo.o bar.baz
```

为了获取对应的源文件列表，你可以简单地写：

```
$(objects..o=c)
```
而不是使用通用形式：

```
$(patsub %o,%,c,$(objects))
```

`$(strip string)`

移除字符串前后的空格，并将任何一个或多个空格替换为单个空格。因此，'$(strip a b c )' 会在 'a b c' 中替换。

`strip` 函数在条件判断结合使用时非常有用。当使用 `ifeq` 与空字符串 "" 进行比较时，或者通常希望仅包含空格的字符串匹配空字符串时（参见第 7 章 [条件判断]，第 77 页）。

以下内容可能未能达到预期结果：

```makefile
.PHONY: all

ifeq "$(needs_made)" ""

all: $(needs_made)

else

all::@echo "Nothing to make!"

endif
```

在 `ifeq` 指令中将变量引用 '$(needs_made)' 替换为函数调用 '$((strip $(needs_made))' 会使其更健壮。

`$(findstring string)`

查找 find 的出现处。如果出现，则值为 find；否则，值为空。你可以使用此函数在条件测试中检查给定字符串中是否存在子字符串。因此，这两个示例：

```
$(findstring a b c)
$(findstring a b c)
```
分别产生值 'a' 和 ''（空字符串）。参见第 7.3 节 [测试标志]，第 80 页，关于 `findstring` 的实际应用。

`$(filter ...,text)`

返回文本中所有不匹配任何模式单词的空格分隔单词，并移除不匹配的单词。模式使用 `%` 编写，类似于 `patsub` 函数中使用的模式。

`filter` 函数可以用于分离变量中不同类型的字符串（如文件名）。例如：

```makefile
sources := foo.bar baz.ugh

foo: $(sources)

cc $(filter %,%,$(sources)) -o foo
```
告诉 filter。

`$(filter-out pattern,text)`

返回文本中所有不匹配任何模式单词的空格分隔单词，并移除不匹配的单词。模式使用 `%` 编写，类似于 `patsub` 函数中使用的模式。

`filter` 函数可以用于分离变量中不同类型的字符串（如文件名）。例如：

```makefile
sources := foo.bar baz.ugh

foo: $(sources)

cc $(filter %,%,$(sources)) -o foo
```
告诉 filter。

`$(find string)`

查找 find 的出现处。如果出现，则值为 find；否则，值为空。你可以使用此函数在条件测试中检查给定字符串中是否存在子字符串。因此，这两个示例：

```
$(findstring a b c)
$(findstring a b c)
```
分别产生值 'a' 和 ''。

# ($suffix names...)

提取 `names` 中每个文件名的后缀。如果文件名包含句号，则后缀为最后一个句号开始的所有内容。否则，后缀为空字符串。这通常意味着当 `names` 不为空时，结果可能为空，且如果 `names` 包含多个文件名，结果包含的文件名可能少于输入数量。

例如，

```
($suffix src/foo.c src-1.0/bar.c hacks)
```

产生结果 '.c.c'。

# ($basename names...)

提取 `names` 中每个文件名的所有后缀。如果文件名包含句号，则基名（basename）为从开始到最后一个句号（不包括句号）的内容。目录部分的句号会被忽略。如果没有句号，则基名为整个文件名。例如，

```
($basename src/foo.c src-1.0/bar hacks)
```

产生结果 '$src/foo src-1.0/bar hacks'。

# ($addsuffix suffix, names...)

该参数被视为一组由空格分隔的名称；`suffix` 被作为一个单元使用。`suffix` 的值会被附加到每个单独名称的末尾，生成的较长名称通过单空格连接。例如，

```
($addsuffix .c,foo bar)
```

产生结果 'foo.c bar.'。

# ($addprefix prefix, names...)

该参数被视为一组由空格分隔的名称；`prefix` 被附加到每个单独名称的前面，生成的较长名称通过单空格连接。例如，

```
($addprefix src/,foo bar)
```
