# 波浪号转义 (Tilde Escapes)

在编写要发送的邮件时，可以使用波浪号转义命令。你只能在输入模式下通过以波浪号转义字符 (`~`) 开头来输入它们。有关如何更改此字符，请参见第 779 页“Internal Variables”中的 `escape`。你可以通过输入将转义字符作为文本输入。

```
~shell-command
```

转义到 `shell`。如果存在 `shell-command`，则运行它。

`~` 模拟文件结束符（终止消息输入）。

```
~:mail-command ~_mail-command
```

执行命令级请求。仅在边读邮件边发送消息时有效。

`~` 打印波浪号转义的摘要。

`~A` 在消息中插入自动签名字符串 `Sign`（参见第 779 页的“Internal Variables”）。

`~a` 将自动签名字符串插入消息中（参见第 779 页的“Internal Variables”）。

`~b name...` 将姓名添加到密抄 (`Bcc`) 列表中。此转义类似于抄送 (`Cc`) 列表，不同之处 `Bcc` 列表中的姓名不会显示在邮件消息的头部。

`-d` 读取死信件文件 (`dead-letter file`)。参见死信件文件。

`-e` 读取指定的文件。如果参数以感叹号 (`!`) 开头，则将剩余字符串视为命令。

```
~f [message-list]
```

转发指定的消息或当前消息。仅在发送消息时有效。

```
~F [message-list]
```

转发指定的消息或当前消息，包括头部字段。

`~h` 提示主题行 (`Subject`)。

`~i` 将值插入消息中。

```
~m [message-list]
```

将指定的消息或当前消息插入信件中。仅在边读邮件边发送消息时有效。

```
~M [message-list]
```

将指定的消息或当前消息插入信件中。仅在边读邮件边发送消息时有效。

`~p` 打印正在输入的消息。

`~q` 通过模拟中断退出输入模式。

`~R` 标记消息待返回。

`~r file` 读取指定的文件。

`~s string` 将主题行设为 `string`。

`~t name...` 将姓名添加到收件人 (`To`) 列表。

```
~v [message-list]
```

在消息上调用首选的屏幕编辑器。默认的 `visual` 编辑器是 `vi(1)`。另请参见在第 783 页“Environment Variables”中的 `VISUAL`。

`~w file` 将消息（不带头部）写入指定的文件。

`~x` 以 `q` 的方式退出，不将消息保存到死信件。

```
~ shell-command
```

将消息正文通过给定的 `shell-command`。如果 `shell-command` 返回成功的退出状态，则用输出替换消息。
