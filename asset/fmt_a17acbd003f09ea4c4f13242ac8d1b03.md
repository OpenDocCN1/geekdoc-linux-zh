
如上所述示例所示，图 `$G$` 可以用图表表示，其中 `$G$` 的每个顶点由一个点或小圆圈表示，连接两个顶点的边由连接图表中对应点的线段或曲线表示。通常，我们将这种图表直接称为图 `$G$` 本身。此外，图中的点被称为 `$G$` 的顶点，线段被称为 `$G$` 的边。例如，顶点集 `V(G) = {u, v, w, x, y}` 且边集 `E(G) = {uv, ux, vx, vy, wy, xy}` 的图 `G` 如图 1.4 所示。尽管图 1.4 中的边 `vx` 和 `wy` 相交，但它们的交点不是 `G` 的顶点。

![](img/598a6ae3fd44120830ada34717906f29_16_0.png)

如果 `uv` 是 `G` 的一条边，则 `u` 和 `v` 是相邻顶点。两个相邻顶点互称为邻居。顶点 `v` 的邻居集合称为 `v` 的开邻域（或简称为 `v` 的邻域），记为 `N_G(v)`，如果图 `G` 是明确的，则记为 `N(v)`。集合 `N[v] = N(v) ∪ {v}` 称为 `v` 的闭邻域。如果 `uw` 和 `vw` 是 `G` 中不同的两条边，则称 `uw` 和 `vw` 是相邻边。顶点 `u` 和边 `vw` 被称为彼此**关联**（incident）。同理，`v` 和 `vw` 也是关联的。

对于图 1.4 中的图 `G`，因此顶点 `u` 和 `v` 在 `G` 中是相邻的，而顶点 `u` 和 `x` 不相邻。边 `uw` 和 `vx` 在 `G` 中是相邻的，而边 `vx` 和 `wy` 不相邻。顶点 `v` 与边 `uv` 关联，但与边 `wy` 不关联。

图 `G` 中顶点的数量称为 `G` 的**阶**（order），边的数量称为 `G` 的**大小**（size）。图 1.4 中图 `G` 的阶为 5，大小为 6。我们通常分别用 `n` 和 `m` 表示图的阶和大小。阶为 1 的图称为**平凡图**（trivial graph）。因此，非平凡图至少有两个顶点。大小为 0 的图称为**空图**（empty graph）。因此，非空图至少有一条边。在任何空图中，没有两个顶点是相邻的。另一个极端是**完全图**，其中每两个不同的顶点都是相邻的。阶为 `n` 的完全图的大小为 `C(n, 2) = n(n - 1)/2`。因此，对于阶为 `n` 且大小为 `m` 的任意图 `G`，都有 `0 ≤ m ≤ C(n, 2)`。阶为 `n` 的完全图记为 `K_n`。`1 ≤ n ≤ 5` 的完全图 `K_n` 如图 1.5 所示。

![](img/598a6ae3fd44120830ada34717906f29_17_0.png)

图 1.5：一些完全图

另外两类常见的图是**路径**（paths）和**圈**（cycles）。对于整数 `n ≥ 1`，路径 `P_n` 是一个阶为 `n`、大小为 `n - 1` 的图，其顶点可以标记为 `v1, v2, …, vn`，且其边为 `vi vi+1`（其中 `i = 1, 2, …, n - 1`）。对于整数 `n ≥ 3`，圈 `C_n` 是一个阶为 `n`、大小为 `n` 的图，其顶点可以标记为 `v1, v2, …, vn`，且其边为 `v1 vn` 以及 `vi vi+1`（其中 `i = 1, 2, …, n - 1`）。圈 `C_n` 也称为 `n`-圈，3-圈也称为**三角形**（triangle）。阶为 5 或更低的路径和圈如图 1.6 所示。请注意，`P1 = K1`，`P2 = K2` 且 `C3 = K3`。

## 1.2 顶点的度

在图 `G` 中，顶点 `v` 的**度**（degree）是 `G` 中与 `v` 相邻的顶点数量。因此，`v` 的度是其邻域 `N(v)` 中的顶点数量。等价地，`v` 的度是与 `v` 关联的边的数量。顶点 `v` 的度记为 `deg_G v`，或者如果当前讨论的图 `G` 是明确的，则简记为 `deg v`。因此，`deg v = |N(v)|`。度为 0 的顶点称为**孤立顶点**（isolated vertex），度为 1 的顶点称为**端点**（end-vertex）或**叶节点**（leaf）。与端点关联的边称为**悬挂边**（pendant edge）。`G` 中顶点最大的度称为 `G` 的**最大度**，记为 `Δ(G)`。`G` 的**最小度**记为 `δ(G)`。（符号 `Δ` 和 `δ` 分别是大写和小写希腊字母 delta。）因此，如果 `v` 是阶为 `n` 的图 `G` 的一个顶点，则：

`0 ≤ δ(G) ≤ deg v ≤ Δ(G) ≤ n - 1`。

对于图 1.4 中的图 `G`，

`deg w = 1, deg u = deg x = 2, deg v = 3 且 deg y = 4`。

因此，`δ(G) = 1` 且 `Δ(G) = 4`。

### 图论第一定理

图论中有一个著名的定理涉及图中顶点度之和，该定理由 Leonhard Euler 在其 1736 年的一篇论文 [86] 中（间接地）观察到，该论文现在被认为是第一篇关于图论的论文——尽管论文中从未提及图论学家。这一观察通常被称为**图论第一定理**（First Theorem of Graph Theory）。有些人将定理 1.4 称为**握手引理**（Handshaking Lemma），尽管 Euler 从未使用过这个名称。

**定理 1.4（图论第一定理）**

如果 `G` 是一个大小为 `m` 的图，则：

$$ \sum_{v \in V(G)} \text{deg} v = 2m $$

**证明。** 在对 `G` 的顶点的度求和时，`G` 的每条边被计算了两次，对应于其两个关联顶点各一次。

图 1.4 中图 `G` 的顶点度之和为 12，这是 `G` 的大小 6 的两倍，正如定理 1.4 所预期的那样。阶为 `n`、大小为 `m` 的图 `G` 的**平均度**（average degree）为：

$$ \frac{\sum_{v \in V(G)} \text{deg} v}{n} = \frac{2m}{n} $$

例如，图 1.4 中图 `G`（阶 `n = 5`，大小 `m = 6`）的平均度为 `2m/n = 12/5`。由于该图的最小平均度严格介于 2 和 3 之间，因此 `G` 必须有一个度至少为 3 的顶点和一个度至多为 2 的顶点。实际上，该图有度为 3 和 4 的顶点，也有度为 1 和 2 的顶点。

### 偶顶点和奇顶点

在图 `G` 中，根据顶点在 `G` 中的度是偶数还是奇数，该顶点被称为**偶顶点**（even）或**奇顶点**（odd）。因此，图 1.4 中的图 `G` 有三个偶顶点和两个奇顶点。虽然图中偶顶点的数量可以是偶数也可以是奇数，但对于奇顶点则不是这种情况。

**推论 1.5**

*任何图的奇顶点数量都是偶数。*

**证明。** 假设 `G` 是一个大小为 `m` 的图。根据定理 1.4，

$$ \sum_{v \in V(G)} \text{deg} v = 2m $$

显然，这是一个偶数。由于 `G` 中偶顶点的度之和为偶数，因此 `G` 中奇顶点的度之和也必须是偶数，这意味着 `G` 具有偶数个奇顶点。
