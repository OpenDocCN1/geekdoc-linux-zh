
`usage` 函数是一个错误处理器，虽然粗糙但方便。第一个代码块使用 Bash 内置的 `UID` 检查是否为 root，如果不是，则调用 `usage`。通过 `getopts` 检查是否被正确调用，如果语法错误则调用 `use syntax`；如果缺少参数则调用 `use arg`。

通过 `id $UNAME` 检查用户是否存在，如果不存在则调用 `use user`。`for` 循环尝试使用 `TERM`、`INT`、`HUP`、`QUIT` 和 `KILL` 信号。它会打印 `Trying $SIG`，然后使用 `pkill` 杀死属于 `$UNAME` 的进程，并将输出重定向到 `/dev/null`。`sleep 1` 语句给内核留出完成时间。如果 `pgrep` 找到进程，则退出 0。

`getopts` 处理 `optionstring` 中的每个字符，一次选取一个选项并赋值给 `varname`。后面跟着 `:` 的选项字符表示该选项需要参数，`getopts` 将该参数分配给 `OPTARG`。只要还有选项需要处理，`getopts` 就返回 0，但在处理所有参数后，它会返回 1，这使得 `getopts` 适用于用于 `while` 循环。

如你在列表 25-10 所示，有效的选项是 `x`、`y` 和 `z`。由于 `y` 和 `z` 后面都跟着 `:`，因此它们需要参数。`case` 语句处理每个有效选项，并包含一个由 `?` 表示的默认情况，如果参数无效，它将打印用法信息并退出脚本。通过 `y` 和 `z` 传递的参数存储在 `OPTARG` 中。脚本最后的 `echo` 语句报告所使用的选项，以及如果适用，其对应参数的值。

结束了你对 Bash 编程基础的快速调研。接下来两个部分“进程与作业控制”和“创建备份”将提供用于监控管理进程以及创建备份的示例脚本，使用了本节讨论的许多概念和特性。

### 列表 25-12 `kujob.sh` 杀死所有由登录名作为参数传递给脚本的用户进程

```bash
#!/bin/sh

# kujob.sh - 杀死用户拥的所有进程

# Arguments - 用户登录名

# 必须是 root

[ $UID -eq 0 ] || use root

# 我们被正确调用了吗?

getopts ":u:" OPT || use syntax

[ "$OPT" = ":" ] && use arg

# 用户是否存在？

id $UNAME & /dev/null || use user

# 杀死用户的进程

for SIG in TERM INT HUP QUIT KILL

do

    echo "Trying $SIG"

    pkill -$SIG -u $UNAME & /dev/null

    sleep 1

    pgrep -u $UNAME & /dev/null || exit 0

done
```

### 列表 25-14：收集 vmstat 统计信息用于离线分析

```bash
#!/bin/sh

# vmstat.sh - 收集 vmstat 报告供以后分析

LOG=/var/vmstat.log

[ $UID -eq 0 ] || LOG=$HOME/vmstat.log.

DELAY=${1:-60}

vmstat -n $DELAY >> $LOG
```

第一条语句设置了默认日志文件，`vmstat` 的输出将保存其中。下一句如果调用者不是 root，则更改此默认值，因为普通用户在 `/var/log` 目录树中没有写权限。`$$` 运算符返回 PID，用于区分不同的日志文件。下一条语句使用 Bash 的替换操作之一来设置 `vmstat` 更新间隔秒数的默认值。正如你记得的，`:-` 运算符将 `DELAY` 设置为位置参数 1 的值，如果为空或未设置，则分配默认值 60。脚本必须使用 `:-` 而不是 `:=`，因为位置参数在运行时是只读的。最后，脚本运行 `vmstat`，使用 `-n` 只打印一次头，延迟指定的延迟，并将输出重定向到 `LOG` 指定的文件。

## 自动化脚本

诚然，脚本在执行系统管理任务时提供了更高的定制性、灵活性和便利性，但反复输入脚本很快就会变得像完整调用命令行一样枯燥。你可以使用 `at` 和 `cron` 来自动且无人值地运行命令。

使用 `at` 命令调度在稍后运行且只需运行一次的脚本。使用 `cron` 功能处理需要定期运行的程序和脚本。

### 使用 AT 执行一次性任务

`at` 命令提供了与 `at` 守护进程调度器的接口。由 `at` 守护进程执行脚本。使用 `at` 调度任务非常简单：使用 `at` 后紧跟想要运行的时间，然后按回车。例如，以下命令序列调度 `/home/kwall/bin/incrback.sh` 在明天 01:05 运行。

```
$ at 01:05
at> /home/kwall/bin/incrback.sh
at> Ctrl+D
job 1 2003-07-10 01:05
```
