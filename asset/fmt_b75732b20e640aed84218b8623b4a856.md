# 列表 B.21 字符串参数

```c
#include <ctype.h>
#include <stdio.h>

/* 定义 uppercase 函数。 */

void uppercase(char *text);

/* 定义 main。这是程序的开始。 */

void main()
{
    char word[] = "Flowers";

    /* 调用 uppercase 函数。注意它
    * 返回一个值。 */

    uppercase(word);

    /* 打印 word 数组的内容。 */

    printf("Word contains %s\n", word);
}

/* 定义 uppercase 函数。 */

void uppercase(char *text)
{
    char *text_ptr = text;

    /* 传递 text 数组直到遇到 */

    while (*text_ptr != '\0')
    {
        /* 将每个字符转换为大写。 */

        *text_ptr = toupper(*text_ptr);

        /* 移动到下一个字符。 */

        text_ptr++;
    }
}
```

# 命令行参数

程序员特别感兴趣是将命令行参数传递到程序中。这与向函数传递参数的方式相同。列表 B.22 介绍了这一概念。

# 列表 B.22 显示命令行参数

```c
#include <stdio.h>
#include <stdlib.h>

void main (int argc, char *argv[])
{
    int inc;

    /* 打印所有参数。 */

    for (inc = 0; inc < argc; inc++)
    {
        printf("Argument %d is %s\n", inc, argv[inc]);
    }
}
```

# C 编程回顾

第 4 行为 `main()` 函数引入了参数列表。第一个参数 (`argc`) 包含命令行上的参数数量，第二个参数 (`argv`) 是字符串数组，包含了实际参数。第 10-13 行的循环显示了这些参数。

如果你使用不同的命令行参数运行此程序几次，会出现两个特性：

- 第一个参数总是程序名。结果是 `argc` 将大于 0。
- 数值作为字符串传递到程序中。需要你将这些字符串转换回数值。可以使用 `atoi()`, `atof()` 或 `sscanf()` 进行转换。

# 结构

结构允许程序员为特定的编程问题创建独特的数据类型。一个经典的例子是创建一个复制文件中数据字段的数据类型。考虑具有以下格式的文件：

- 字段 1：Name - 20 个字符。
- 字段 2：Age - 整数。

该文件可以在结构中表示例所示：

```c
struct record {
    char name[20];
    int  age;
}
```

列表 B.23 中的程序在读取文件时使用了 `record` 结构。

# 列表 B.23 结构的第一步

```c
#include <stdio.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>

void main()
{
    /* 定义一个名为 'record' 的结构。 */

  struct record
{
    char        name[20];
    int        age;
};

    /* 定义一个名为 'buffer' 的变量
     * 数据类型为 'record'。 */

    struct record buffer;

    int        fd;

    /* 程序假设 /tmp/test_file 已经
     创建适当的记录。 */

    fd = open('/tmp/test_file', O_RDONLY);

    while (read(fd, &buffer, 24) > 0)
    {
        /* 显示记录的内容。 */

        printf("%s is %d years old\n", buffer.name, buffer.age);
    }
    close(fd);
}
```

# 结构体指针

对于所有其他数据类型，你都可以创建结构体的指针。其语法与其他数据类型相同，但 C 引入了一种快捷方式来提高访问结构体成员字段时的代码可读性。列表 B.25 显示了一个示例。

# 列表 B.25 结构体指针

```c
#include <stdio.h>
#include <string.h>      /* strcpy declaration. */

typedef struct record
{
    char        name[20];
    int         age;
} record_t;

void print_buffer(record_t *buf_ptr);

void main()
{
    record_t    buffer;

    strcpy(buffer.name, "Frank");
    buffer.age = 34;

    print_buffer(&buffer);
}

void print_buffer(record_t *buf_ptr)
{
    printf("%s is %d years old\n", buf_ptr->name, buf_ptr->age);
}
```
