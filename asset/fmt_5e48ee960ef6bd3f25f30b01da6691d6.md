
```

另一个 shell 不工作的实例也与搜索路径有关。熟悉 DOS 的用户知道它会在当前目录以及搜索路径中查找可执行文件。相反，Linux 不搜索当前目录，只搜索搜索路径。因此，用户所在目录下的一个可执行文件将无法被找到。

你需要通过 `./executable name` 显式地告诉 shell 在当前目录中查找。点和正斜杠告诉 shell 查看当前目录。
```
