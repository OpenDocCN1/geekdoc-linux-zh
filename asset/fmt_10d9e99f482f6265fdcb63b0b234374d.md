
## 游戏

在 Linux Mint 21 上玩游戏为传统的游戏格局带来了令人兴奋的转折，利用了强大且稳定的 Linux Mint 环境。它的关键在于利用 `Steam Proton` 和 `Lutris` 等兼容性工具，在一个被认为不适合游戏的平台上流畅地运行从独立游戏精品到 AAA 大作的各种游戏。这种演变标志着社区的努力，旨在使 Linux 成为一个对玩家友好的操作系统，展示了性能的提升以及对多种硬件的支持。虽然驱动兼容性等挑战仍然存在，但进步是不可否认的，为 Windows 游戏提供了一个新鲜的替代方案，并强调了开源原则和用户控制。

`Wine-Staging` 是 `winehq.org` 的测试场，提供了尚未进入开发分支的错误修复和功能，以加快用户和开发者访问实验性功能。它是 `Wine` 开发版本的补丁集，允许维护人员自行选择包含的内容。`Wine-Staging` 由一个专门团队管理，审查并维护来自错误报告的补丁以提高 `WINE` 的性能（包括游戏和应用程序），区分了 `winehq-staging`（用于测试）、`winehq-stable`（稳定版本）、`winehq-devel`（开发头文件）和 `wine-development`（用于额外的调试工具）。

`Lutris` 是一个用于 Linux 的免费开源游戏管理器，与 `Steam`、`GOG`、`Humble Bundle` 和 `Epic Games Store` 等平台无缝集成。它简化了跨各种硬件和软件玩游戏的体验，支持超过 20 个模拟器和 `Wine` 社区脚本，确保新旧游戏都能流畅运行。`Lutris` 由 Mathieu Comandon 和社区开发，提倡视频游戏保护，允许用户使用他们的 PC 构建开源游戏主机。它是一个由 Linux 和 `Vulkan` 驱动的稳定平台。

## ProtonUp-Qt

访问 `ProtonUp-Qt` 官网 https://davidetek.github.io/protonup-qt/。

通过软件管理器安装 `DEB/FLATPAK` 软件包：

- 打开软件管理器并搜索 `ProtonUp-Qt`。
- 点击 `ProtonUp-Qt`，然后点击源选择框。
- 选择“System Package”（系统包）或“Flatpak”并点击“Install”。

通过 `Flatpak` 在终端安装 `ProtonUp-Qt`：
输入命令：

```bash
flatpak install flathub net.davidetek.puggui
```

通过图形界面从 `AppImage` 安装 `ProtonUp-Qt`：

导航到发布页面：
https://github.com/DavidoTek/ProtonUp-Qt/releases/
点击 `Assets` 查看文件。
选择最新版本的 `ProtonUp-Qt-x86_64.AppImage` 文件。
将文件下载到你的 `~/Downloads` 文件夹。

在你的“下载”文件夹中找到 `ProtonUp-Qt-2.9.1-x86_64.AppImage` 文件，右键点击它并选择“属性”。

在“属性”菜单中，切换到“权限”选项卡并勾选“允许作为程序执行”。

双击 `ProtonUp-Qt-2.9.1-x86_64.AppImage` 文件开始安装过程。

## 从命令行和 GUI 创建 ProtonUp-Qt AppImage .desktop 快捷方式

为 `ProtonUp-Qt.AppImage` 创建 `.desktop` 快捷方式，请在终端执行以下步骤：

使用命令进入应用程序目录：

```bash
cd /usr/share/applications
```

运行以下命令打开一个新的 `.desktop` 文件进行编辑：

```bash
sudo gedit ProtonUp-Qt.desktop
```

在打开的 `.desktop` 文件中输入以下详情：

```ini
[Desktop Entry]
Name=ProtonUp-Qt
Comment=ProtonUp-Qt
Exec=./Downloads/ProtonUp-Qt-2.9.1-x86_64.AppImage
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

要保存进度，点击“保存”。或者，你可以点击 ≡ 图标，选择“另存为”，最后点击“保存”。保存后关闭编辑器。

## 访问官方网站 https://store.steampowered.com/ 获取所有 Steam 信息。

通过软件包管理器安装 `DEB/FLATPAK` 软件包：

- 打开软件包管理器并搜索 `Steam`。
- 点击 `Steam`，然后选择源框。
- 选择软件包或 `Flatpak` 并点击安装。

## 通过 APT 安装 Steam

在终端中输入这些命令：

```bash
sudo apt update
sudo apt install steam
```

## 通过 APT 仓库安装 Steam

在终端中输入这些命令：

```bash
sudo apt update
```

```bash
sudo tee /etc/apt/sources.list.d/steam-stable.list <<EOF
deb [arch=amd64 signed-by=/usr/share/keyrings/steam.gpg] https://repo.steampowered.com/steam/ stable
deb-src [arch=amd64 signed-by=/usr/share/keyrings/steam.gpg] https://repo.steampowered.com/steam/ stable
EOF
```

```bash
sudo dpkg --add-architecture i386
```

```bash
sudo apt-get update
```

```bash
sudo apt-get install \
libgl1-mesa-dri:amd64 \
libgl1-mesa-dri:i386 \
libgl1-mesa-glx:amd64 \
libgl1-mesa-glx:i386
```

## 对于 Snap 软件包

- 在 `Snap Store` 中查找 `Steam`。
- 点击 `Steam`，然后选择源框。
- 选择 `latest/stable` 版本并点击安装。

## 通过 Snap 安装 Steam

输入此命令：

```bash
sudo snap install steam
```

## 通过 Flatpak 安装 Steam

输入此命令：

```bash
flatpak install flathub com.valvesoftware.Steam
```
