# 在 gdb 中修复 bug

有时你可以直接在 gdb 中修复 bug。对于上一节中的示例程序，你可以在可以在程序在显示错误消息并崩溃后立即尝试此修复。由于示例是人为构造的，我在 `dbgst` 程序中定义了一个名为 `buf` 的额外缓冲区，如下：

```c
static char buf[256];
```
