## 新闻组 (Newsgroups)

`N`

新闻组是一个世界上所有人都能看到的公告板。有数千个新闻组，每个组在世界上都是独一无二的。你用于读取新闻组的软件被称为读者（或新闻客户端）。`rtin` 是流行的文本模式阅读器，而 `netscape` 是图形化的。`pan` 是我使用的一个优秀新闻阅读器。新闻就像互联网主机。你可能对 `comp.os.linux.announce` 感兴趣。`comp` 是计算机；操作系统；等最广泛的主题描述。有许多其他新闻组是针对各种 `LINUX` 问题开发的。新闻组服务器是巨大的巨兽。它们在互联网上形成树状结构。当你向新闻组发送邮件时，大约需要一天时间你发送的邮件才能传播到世界上每个其他服务器。同样，你可以看到任何人从任何地方发布到每个新闻组的消息列表。新闻组和邮件列表有什么区别？新闻组的优势在于，你不需要下载你不感兴趣的消息。如果你在邮件列表中，你会收到所有发送到列表的邮件。在新闻组中，你可以查看列表并只检索你感兴趣的内容。为什么不直接把列表发布在网页上呢？如果你这样做，世界上每一个人都必须通过国际链接访问该页面。加载量将与订阅者的数量成正比。这就是 `SlashDot` 的本质。然而，你的新闻组服务器是本地的，因此你通过更快的链接检索邮件并节省互联网流量。摘自 Route-Users-Guide http://www.tldp.org/LDP/Linux-Dictionary/index.html

# NFS 网络文件系统 (Sun, RFC 1813)

`NFS` 是 `SMB` 的等价物。与 `SMB` 不同，`NFS` 发送加密密码，因此最好将其使用限制在本地网络内。网络文件系统 (`NFS`) 开发用于将远程机器上的磁盘分区挂载为本地驱动器。这允许跨网络的快速、无缝文件共享。如果你设置不当，它也会让未授权的人通过网络访问你的硬盘（从而读取你的电子邮件并删除你的所有文件）。如果你需要实现 `NFS` 设置，请阅读本文的安全章节。`Samba` (http://www.samba.org) 为 Windows 客户端提供服务。来自 IBM 的 Andrew 文件系统 (http://www.transarc.com/Product/EFS/AFS/index) 最近开源，提供了一种具有额外安全性能特的文件共享机制。`Code` 文件系统 http://www.code.cs.cmu.edu/ 在写作时仍在开发中，但设计用于与离线客户端工作。Andrew 和 `Code` 文件系统的许多功能已计划纳入 `NFS` 的下一个版本 (版本 4) (http://www.nfsv4.org)。今天 `NFS` 的优势源自 `NFS–HOWTO` (http://www.tldp.org/LDP/linux-Dictionary/index.html)，它是成熟、标准、易理解的并且在各种平台上都有稳健的支持。

`NFS` 参见网络文件系统 (`NFS`)。摘自 Redhat–9–词表 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### nfs-common

用于通用客户端和服务器的 `NFS` 支持文件。在任何需要作为客户端或服务器的机器上使用此包。包含程序有 `lockd`、`stat`、`mount` 和 `nfsstat`。上游：SourceForge 项目 "`nfs`";CVS 模块 `nfs-utils`。来自 Debian 3.0r APT

http://www.tp.org/LDP/Linux-Dictionary/html/index.html

### nfs-server

内核服务器。如果你使用的是较内核（2.2.13 或更高版本）或想使用内核模式 `NFS` 服务器，请使用此包。"`nfs-server`" 包中的用户态 `NFS` 速度较慢，但功能更丰富且比内核模式服务器更容易调试。上游：SourceForge 项目 "`nfs`"，CVS 模块 `nfs-utils`。来自 Debian 3.0r

http://www.tp.org/LDP/Linux-Dictionary/html/index.html

### nfs-user-server

用户空间 `NFS` 服务器。此包包含所有必要的程序，用于通过守护进程（`nfsd`, `mountd`）使你的 Linux 充 `NFS` 服务器。与其他 `NFS` 守护进程不同，该服务器完全运行在用户空间中。它比旧的 `NFS` 服务器慢，并且在语义上引入了一些不便（例如，将文件移动到不同的目录将导致处理程序失效）。来自 Debian 3.0r APT

http://www.tp.org/LDP/Linux-Dictionary/html/index.html

### nfs-utils

`nfs-utils` 包为内核 `NFS` 服务器提供了一个守护进程及相关工具，其提供的性能比大多数用户使用的传统 Linux 服务器高得多。此包还包含 `showmount` 程序。`showmount` 查询远程主机上的守护进程，以获取有关远程主机 `NFS`（网络文件系统）的信息。例如，`showmount` 可以显示挂载在上面的上的客户端。来自 Mandrake 9.0 RPM

http://www.tp.org/LDP/Linux-Dictionary/html/index.html
