
# Linux 词典

可扩展字体 (Scalable Fonts) 包含了以下字体族：Times, Helvetica, Palatino, Avant Garde, New School, Bookman Light 和 Teams。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalable-refs

可扩展字体 (Scalable fonts) 为 TeX 提供了可扩展字体。它安装了所有所需的 Tex 字体、虚拟字体、定义和样式包。阅读文件 `/usr/share/doc/scalablrefs/README.Debian`。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalable-cyfonts-x11

可扩展西里字体 (Scalable Cyrillic fonts) X 包将 scalable-fonts 包中的字体提供给 X 服务器或字体服务器。为了正确的编码，它需要可扩展 X 服务器或字体服务器。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalable-lap-test

可扩展线性代数包 (Scalable Linear Algebra Package ScalPACK) 是 LAPACK 的并行版本。它依赖 PVM 和 MPI。此包提供了测试程序。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalable-mpich-test

## scalable-pvm-test

可扩展线性代数包 (Scalable Linear Algebra Package ScalPACK) 是 LAPACK 的并行版本。它依赖 PVM 和 MPI。此包提供了测试程序。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalable-test-common

ScalAPACK 测试程序的测试数据。ScalAPACK-lap-test 和 scalable-mpich-test 需要此包提供的某些数据。来自 Debian 3.0r APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## scalablepack-1-lam

可扩展线性代数包 ScLAPACK 是 LAPACK 的并行版本。它依赖于 PVM 或 MPI。此包提供共享库，依赖于 MPI 的 LAM 实现。还包括 PBLAS，基础线性代数程序。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scalapack1-mpich

可扩展线性代数包 ScLAPACK 是 LAPACK 的并行版本。它依赖于 PVM 或 MPI。此包提供共享库，依赖于 MPI 的 MPICH 实现。还包括 PBLAS，基础线性代数程序。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scalapack1-pvm

可扩展线性代数包 ScLAPACK 是 LAPACK 的并行版本。它依赖于 PVM 或 MPI。此包提供运行程序的共享库。还包括 PBLAS，基础线性代数程序。源自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scan

扫描仪 这种表述是为了指出人们经常对所讨论的内容感到困惑。问题在于扫描仪可以是主动的，也可以是被动的。扫描器的示例有：持续在后台运行的病毒后台扫描器、每次访问时触发的病毒访问时扫描器、用户使用硬盘时查找病毒的按需扫描器。源自 Hacking-Lexicon `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scandett

端口扫描检测器。Scandett 记录进入主机的连接。如果连接发生在一秒内，它将记录在 syslog 中。Scandett 会识别这种模式并向（默认情况下）root@localhost 发送邮件。此时 Scandett 还会尝试识别操作系统指纹探测。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scannerlog

从 Apache 错误日志生成摘要 此程序允许人们解析来自多个源的 Apache error_log 文件，并以不同的格式（文本、html、pdf）呈现错误消息频率的摘要。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scanimage

扫描图像 源自 `http://www.tld.org/linux-Dictionary/html.html`

## scanlogd

端口检测工具 Scanlogd 是一个由 Solar Designer 编写的守护进程，用于检测你机器上的端口扫描攻击。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scanmail

针对 Postfix 的邮件扫描器 该程序从用户的 .forward 文件调用，扫描入站邮件中的 .vbs、.exe 和类似的附件。如果消息是干净的，则将其插入用户的 qmail-Mail 或暂存到 mboxes 中。否则，会被退回。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scanner

一种使用光感应器读取打印材料，并将信息作为图像数字传输到计算机系统进行处理的外围设备。源自 Redhat-9-Glossary `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scansci

扫描/探测 PBI 总线 源自 `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scansort

基于 CSV 的图像排序器和验证器 ScanSort 允许人们根据逗号分隔（CSV）文件中包含的信息对图像进行排序和验证。它是为那些从 Usenet、WWW 等收集系列图像的人设计的，这些图像对应有一个包含图像名称、大小、CRC 等信息的 CSV 文件。除了图像排序功能外，ScanSort 还可以管理 CSV 文件、创建交易图像列表等。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

## scanssh

获取整个网络的 SSH 服务器版本 scanssh 协议扫描器扫描地址列表和网络，查找运行 SSH 协议的服务器及其版本号。scanssh 协议支持从大型网络中随机选择 IP 地址，用于收集公司或整个互联网 SSH 协议服务器的统计数据。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html.html`

## scanty

扫描此电台的电视 这可以扫描电视频道集并将找到的频道写入文件（该文件也会被 fbt 等工具读取）。它尝试从 vbi 数据中提取电台名称。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`
