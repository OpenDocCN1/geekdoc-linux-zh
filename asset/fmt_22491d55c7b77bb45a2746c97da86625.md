## UNIX 哲学的 17 原则

- 模块化原则：系统应由若干良好协作且具有明确定义的组件组成。
- 清晰性原则：清晰优于聪明。
- 组合原则：创建可以与其他软件通信的软件。
- 分离原则：编程机制和规则应保持独立。分离界面和后端引擎。
- 简单原则：为简单构建，仅在需要时增加复杂度。
- 节原则：只有在证明其他方法都无效时，才编写大型程序。
- 透明性原则：设计时考虑可视化，以简化分析和故障排除。
- 健壮性原则：透明度和易用性产生健壮性。
- 表达原则：创建让参与项目的任何程序员都易理解的程序，以便维护。

```
在面临选择时，程序员应该选择复杂数据而非软件的过程逻辑，因为复杂的数据比复杂的逻辑更易于我们理解
```

- 最小惊讶原则：应该鼓励开发者创建用户友好、直观的产品。
- 沉默原则：允许程序员和其他程序从程序的输出中获取所需数据，而无需解释不必要的详尽内容。
- 修复原则：程序员创建的软件应以简单识别和诊断的方式故障。
- 经济原则：应尽可能减少项目开发成本。
- 生成原则：程序员应该开发抽象的高级程序来产生代码，而不是手动编写代码，以减少人为错误并节省时间。
- 优化原则：在优化之前，先让它运行。软件在被开发者精雕细刻之前应该经过测试。
- 多样性原则：使程序保持灵活，使其能够以预期之外的方式使用。
- 可扩展性原则：增加开发者编写代码的用途和寿命。

## Linux 命令

### 描述：
显示系统日期和时间。

命令：

```
date
```

### 描述：
显示日历。

命令：

```
cal
```

### 描述：
显示日期、时间和日历。

命令：

```
date & cal
```

### 描述：
显示 2016 年 8 月日历。

命令：

```
cal 8 2016
```

### 描述：
用于清除终端窗口。

命令：

```
clear
```

### 描述：
退出终端窗口。

命令：

```
exit
```

### 描述：
显示空闲和已使用的系统内存。

命令：

```
free
```

### 描述：
以字节为显示空闲和已使用的系统内存。

命令：

```
free -b
```

### 描述：
以千字节为显示空闲和已使用的系统内存。

命令：

```
free -k
```

### 描述：
以兆字节为显示空闲和已使用的系统内存。

命令：

```
free -m
```

### 描述：
更改用户密码。

命令：

```
passwd
```

### 描述：
关机。

命令：

```
shutdown
```

### 描述：
立即关机。

命令：

```
shutdown -h now
```

### 描述：
在 10 分钟后关机。

命令：

```
shutdown -h +10
```

### 描述：
打印当前工作目录。

命令：

```
echo $PWD
```

### 描述：
打印上一个工作目录。

命令：

```
echo $OLDPWD
```

### 描述：
执行命令历史记录中的第 11 条命令。

命令：

```
!!11
```

### 描述：
显示你的命令历史。

命令：

```
history
```

### 描述：
关机或重启操作系统。

命令：

```
sudo reboot
```

### 描述：
显示主机的 IP 地址。

命令：

```
ip address
```

### 描述：
列出文件和目录的大小。

命令：

```
ls -s
```

### 描述：
查看挂载的文件系统。

命令：

```
mount
```

### 描述：
显示文件和目录的磁盘占用信息。

命令：

```
du
```

### 描述：
告诉系统已运行了多久。

命令：

```
uptime
```

### 描述：
将当前日期设置为 1998 年 11 月 2 日。

命令：

```
date --set 1998-11-02
```

### 描述：
将当前时间设置为 IST 时间 12:11:02。

命令：

```
date --set 12:11:02
```

### 描述：
查看 Linux 中特定的磁盘分区。

命令：

```
fdisk -l /dev/sda
```

### 描述：
列出当前工作目录下的所有文件和目录。

命令：

```
ls
```

### 描述：
报告进程信息。

命令：

```
ps
```

### 描述：
显示磁盘占用。

命令：

```
df
```

### 描述：
以千字节、兆字节或千字节为显示磁盘占用。

命令：

```
df -H
```

### 描述：
删除每个文件和每个目录。

命令：

```
rm -r *
```

### 描述：
提供当前运行进程的快速概览。

命令：

```
top
```

### 描述：
系统执行立即重启。

命令：

```
reboot
```
