### 注意事项

如果你在预测示例时遇到 `SyntaxError`（语法错误），那么你可能正在使用 Python 3。如果是如此，你可以继续学习本章，但请注意在 Python 3 中 `print` 语句已变成了一个函数。只需在随后的示例中要在打印的项目周围加上括号即可。例如：

```
>>> print("Hello World")
Hello World
>>>
```

只要你打印的是单个项目，在 Python 2 中在打印的项目周围加上括号同样有效。然而，这并不是你在现有 Python 代码中常见的语法。在随后的章节中，这种写法有时用于示例，其中示例的主要关注点是与打印不直接相关的特性，但该示例应该能够在 Python 2 和 3 中同时运行。

Python 的交互式模式是它最有用的特性之一。在交互式外壳中，你可以输入任何有效的语句或语句序列，并立即查看结果。包括作者在内的许多人将交互式 Python 用作他们的桌面计算器。例如：

```python
>>> 6000 + 4523.50 + 134.12
10657.62000000001
>>> + 8192.32
18849.94000000002
>>>
```

当你交互式地使用 Python 时，特殊变量 `_` 存储上一次操作的结果。如果你想在后续语句中保存或使用上一次操作的结果，这会很有用。然而，必须强调的是该变量仅在交互式工作时才定义。如果你想创建一个可以反复运行的程序，请将其放在文件中，例如：

```python
# helloworld.py
print("Hello World")
```

Python 源文件是普通的文本文件，通常具有 `.py` 后缀。`#` 字符表示延伸到行尾的注释。要执行 `helloworld.py`，请将文件名提供给解释器：

```python
%python helloworld.py
Hello World
```

在 Windows 上，可以通过双击 `.py` 文件或在“运行”命令中输入程序名称来启动 Python 程序。然而，控制台会在程序完成后立即消失（通常在你能读到其输出之前）。对于调试，最好在如 `IDLE` 等开发工具中运行程序。在 UNIX 上，你可以在程序的第一行使用 `#!`，如下所示：

```python
#!usr/bin/env python
print("Hello World")
```

### 条件语句

`if` 和 `else` 语句可以执行简单的测试。这里有一个示例：

```python
if a < b:
    print "Computer says Yes"
else:
    print "Computer says No"
```

`if` 子句和 `else` 子句的体通过缩进来表示。`else` 子句是可选的。

要创建一个空子句，请使用 `pass` 语句，如下：

```python
if a < b:
    pass      # 什么都不做
else:
    print "Computer says No"
```

你可以使用 `or`、`and` 和 `not` 关键字来构建布尔表达式：

```python
if product == "game" and type == "pirate memory" \
    and not (age < 4 or age > 8):
    print "I'll take it"
```

#### 注意

编写测试用例通常会导致产生包含冗长代码行的语句。为了提高可读性，你可以使用反斜杠（行尾的 `\`）将任何语句延续到下一行。如果你这样做，普通规则将不再适用于下一行，因此你可以随心所欲地格式延续的行。

Python 没有特殊的 `switch` 或 `case` 语句来测试值。处理多个测试用例请使用 `elif` 语句，如下：

```python
if suffix == ".html":
    content = "text/html"
elif suffix == ".jpg":
    content = "image/jpeg"
elif suffix == ".png":
    content = "image/png"
else:
    raise RuntimeError("Unknown content type")
```

要表示真值，请使用布尔值 `True` 和 `False`。这里有一个示例：

```python
if 'spam' in s:
    has_spam = True
else:
    has_spam = False
```

所有的关系运算符（如 `<` 和 `>`）都返回 `True` 或 `False`。示例中使用的 `in` 运算符通常用于检查一个值是否包含在另一个对象中（如字符串、列表或字典）。它也返回 `True` 或 `False`，因此前面的示例可以缩短为：

```python
has_spam = 'spam' in s
```
