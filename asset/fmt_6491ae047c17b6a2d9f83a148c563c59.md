```php
// Draw caption text

  0,

  $text_color,
  $this->fontfile,
  $this->caption);
```

`imagettftext()` 函数使用八个参数：要添加文本的图像资源、字体大小、文本角度、开始绘制文本的 x 坐标、文本基线/底部的 y 坐标、文本颜色、.ttf 字体文件名，以及要渲染的实际文本，按此顺序排列。
