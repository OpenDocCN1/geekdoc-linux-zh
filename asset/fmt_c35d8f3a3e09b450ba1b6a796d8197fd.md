### 检查命令行参数 - $@ < 3

```bash
if (($# > 3))
then
    usage
    exit 1
```

注意，我们在这里使用了数学测试。关于该测试的语法需要注意的一点是，对于用户定义或脚本定义的变量，我们不需要在变量前使用美元符号 (`$`)。对于 shell 变量，你在这里也必须使用 shell 符号法。如果命令行上的参数数量超过三个，我们将显示 `usage` 函数并以返回码 1（一个）退出 shell 脚本。

## 测试有效的命令行参数

我们实际上只有三个有效的命令行参数。由于 `-n` 和 `-m` 是小写字母，我们完全可以为那些喜欢输入大写字母的人添加它们的大写对应项。现在我们只有五个有效的命令行参数了：

- 任意整数
- `-n` 和 `-N` 表示创建一个新的 `$KEYBOARD_FILE`
- `-m` 和 `-M` 表示要打印管理器的密码列表

使用 `case` 语句通过 `$@` 值来解析命令行参数进行测试似乎足够容易，`$@` 是一个由空格分隔的命令行参数列表。详情请查看列表 10.7 中的代码块。

```bash
# 测试有效的命令行参数
# 有效参数为 "-n, -N, -m, 以及任何整数
if (($# != 0))
then
    for CMD_ARG in $@
    do
        case $CMD_ARG in
            +([0-9])) # 测试符号正在寻找
                # 整数。任何整数都被赋值给
                # 密码变量长度 LENGTH
                LENGTH=$CMD_ARG
                ;;
            -n|-N)
                # 冒号 (:) 是空操作，什么都不做
                ;;
            -m|-M) # 修正：此处应为M
                ;;
            *) # 无效命令行参数，显示用法并退出
                usage
                exit 1
                ;;
        esac
    done
fi
```
