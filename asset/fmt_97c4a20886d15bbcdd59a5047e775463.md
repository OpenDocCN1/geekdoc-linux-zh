
# 客户端间通信函数

`display` 指定与 X 服务器的连接。
`w` 指定窗口。
`protocols_return` 返回协议列表。
`count` 返回列表的数量。

`XGetWMProtocols` 返回指定窗口上 `WM_PROTOCOLS` 属性中存储的原子列表。这些原子描述了该窗口所有者愿意参与的管理器。如果属性存在、类型为 `ATOM`、格式为 32 且可以转换 `WM_PROTOCOLS`，`XGetWMProtocols` 将将返回参数设置为原子列表，将 `count` 参数设置为列表中的元素数量，并返回非零状态。否则，它不设置任何返回参数并返回零状态。要释放原子列表，请使用 `XFree`。

`XGetWMProtocols` 可以产生 `BadWindow` 错误。

要设置窗口的 `WM_COLMAP_WINDOWS` 属性，请使用 `XSetWMColormapWindows`。

```c
Status XSetWMColormapWindows(display, w, colormap_windows, count);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `colormap_windows` 指定窗口列表。
- `count` 指定列表中窗口的数量。

`XSetWMColormapWindows` 函数将指定窗口上的 `WM_COLMAP_WINDOWS` 属性替换为由 `colormap_windows` 参数指定的窗口列表。如果该属性尚不存在，则 `XSetWMColormapWindows` 将在指定窗口上设置 `WM_COLMAP_WINDOWS` 属性，其存储类型为 `WINDOW`，格式为 32。如果无法内部化 `WM_COLMAP_WINDOWS` 原子体（atom），则 `XSetWMColormapWindows` 返回零状态。否则，返回非零状态。

`XSetWMColormapWindows` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

要读取窗口的 `WM_COLMAP_WINDOWS` 属性，请使用 `XGetWMColormapWindows`。

```c
Status XGetWMColormapWindows(display, w, colormap_windows_return, count);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `colormap_windows_return` 返回窗口列表。
- `count_return` 返回列表中窗口的数量。

`XGetWMColormapWindows` 函数返回存储在指定窗口 `WM_COLMAP_WINDOWS` 属性中的窗口标识符列表。这些标识符表示窗口管理器可能需要为此窗口安装的调色板（colormaps）。如果属性存在、类型为 `WINDOW` 且原子 `WM_COLMAP_WINDOWS` 可以内部化，则 `XGetWMColormapWindows` 将返回参数设置为窗口标识符列表，将 `count_return` 返回参数设置为列表中的元素数量，并返回非零状态。否则，两个返回参数都不会返回零状态。要释放窗口标识符列表，请使用 `XFree`。

`XGetWMColormapWindows` 可能会产生 `BadWindow` 错误。

# 设置和读取 WM_ICON_SIZE 属性

`Xlib` 提供了用于设置和读取给定窗口 `WM_ICON_SIZE` 属性的函数。这些函数使用了定义在 `<X11/XUtil.h>` 头文件中的 `XIconSize` 结构。

要分配 `XIconSize` 结构，使用 `XAllocIconSize`。

```c
XIconSize *XAllocIconSize();
```

`XAllocIconSize` 函数分配并返回指向 `XIconSize` 结构的指针。注意，`XIconSize` 结构中的所有字段最初都设为零。如果可用内存不足，`XAllocIconSize` 返回 `NULL`。要释放分配的内存，请使用 `XFree`。

`XIconSize` 结构包含：

```c
typedef struct {
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
} XIconSize;
```

`width_inc` 和 `height_inc` 成员定义了尺寸的等差数列（从最小到最大），代表支持的图标大小。

要设置窗口的 `WM_ICON_SIZE` 属性，使用 `XSetIconSizes`。

```c
XSetIconSizes(display, w, size_list, count);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `size_list` 指定尺寸列表。
- `count` 指定尺寸列表中项目的数量。

`XSetIconSizes` 函数仅供窗口管理器用于设置支持的图标大小。

`XSetIconSizes` 可能会产生 `BadAlloc` 和 `BadWindow` 错误。

要读取窗口的 `WM_ICON_SIZE` 属性，使用 `XGetIconSizes`。

```c
Status XGetIconSizes(display, w, size_list, count_return);
```

- `display` 指定与 X 服务器的连接。
- `w` 指定窗口。
- `size_list` 返回尺寸列表。
- `count_return` 返回尺寸列表中项目的数量。

如果窗口管理器没有设置图标大小，则 `XGetIconSizes` 返回零；否则返回非零。如果应用程序想要查找运行该应用程序的窗口管理器最欢迎的图标大小，则应调用 `XGetIconSizes`。随后，应用程序应使用 `XSetWMHints` 向窗口管理器提供处于支持尺寸之一的图标像素位图（pixmap）或窗口。要释放 `size_list_return` 中分配的数据，请使用 `XFree`。

`XGetIconSizes` 可能会产生 `BadWindow` 错误。

# 使用窗口管理器便利函数

`XSetWMProperties` 函数存储了窗口管理器属性的标准定义，这些属性使用标准编码进行国际化文本通信。给定窗口的标准窗口管理器属性有：`WM_NAME`、`WM_ICON_NAME`、`WM_HINTS`、`WM_NORMAL_HINTS`、`WM_CLASS`、`WM_COMMAND`、`WM_CLIENT_MACHINE` 和 `WM_LOCAL_NAME`。

```c
void XSetWMProperties(display, w, window_name, icon_name, argv[], argc, normal_hints, wm_hints, class_hints);
```
