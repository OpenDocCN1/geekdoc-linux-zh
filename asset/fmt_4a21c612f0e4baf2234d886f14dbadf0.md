```
H   H   H

|   |   |

H--C--C--C--

|   |   |

HH   H   H
```

它是这类键中最具特征的类型。该理论将其解释为化学科学的结果。任何分子的物理和化学性质都是其特定电子结构的结果。然而，其中一种共价键——氢分子中的`H-H`键，比任何其他键都强；例如，水分子中的`O-H`键强得多。

### 化学转化

发生了一种化学制造过程，其产物与原料不同。化学制造过程由一系列步骤组成，每一步都使通过该特定步骤的化学分子或其组合发生某些变化。

共价键理论从定性和定量两方面解释了分子的分子性质。任何键的强度都是量子理论的一个分支。见非相对性量子理论。

共价键物理描述的问题具有许多内在困难。分子成键的定性理论使用了量子化学的主要原理，如原子结构、静电和离子因素、互变异现象和电负性。定量理论在本质上是高度数学化的，使用了大量的观测器网络和计算机。

如果一个步骤具有物理性质（例如示例、蒸馏、过滤、吸收、冷凝、结晶），它就是物理步骤。如果是从一种物种到另一种物种的转化（例如燃烧、聚合、氧化），该步骤就是化学的。某些步骤涉及键，例如伴随导致相变的反应的气吸收。化学转化涉及化学变换的总过程，但也被用作单元工艺的同义词。化工工业正如石油行业那样运作。见化学工业；工艺。

共价键由原子的电子构型形成。一个极其重要的例子是碳。在它的许多化合物中：

```
H   H

|   |

H--C--H

|   |

H   H
```

原子形成双键。双键略短，因此断裂所需的比单键需要多多的能量。然而，它们所需的能量远不及三键。同样，乙炔（2）用三键表示，三键比双键短得多。碳-单键长度约为 `$1.22 \times 10^{-8}$` cm。见键角和键距。

### 转化率

转化一术语的另一个用途是定义化学反应器或单元中转化原料的百分比。这种定量单位在原料从产物流中回收并循环的情况下表示为通过通过率。见转化率。

通过化学物种的化学动力学试图解释时间依赖性现象（如能量释放和化学反应），基于构成系统的核和电子。

原则上，可以指定哪些反应决定化学反应的速率。这非常困难，特别是当产物分布复杂时，反应产率决定了动力学的预期方面。

### 能量分布

关于化学反应动力学的一个重要问题是确定内部自由度之间的产物能量分布。由于氢（`$H_2$`）键远强于氢键，`HF`反应（1）释放了大量的：

```
$F_2 \rightarrow FH + H$
```

能量（超过 30 kcal/mol或 126 kJ/mol）。能量释放的两种路径是：`HF`键能进入平动运动，或者进入`HF`的振动模式。

在这种情况下，它在 `HF` 的激发振动能级中产生反应粒子——比低能级更高的能级——并从这些激发能级发射红外光。其他反应的化学反应也会产生热能级的粒子反转，并可以供激光使用。

最有效能量。大多数化学反应的速率提供了更多的能量。在宏观背景下，这指的是提高温度，因此在较高温度下反应更快。某些类型的能量比其他能量更能加速反应，这是合理的。在反应（2）中：

```
$K + HCl \rightarrow KCl + H$
```
