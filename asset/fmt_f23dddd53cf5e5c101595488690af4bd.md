
# 术语表

## run control (rc) script（运行控制脚本）

用于启动和停止各种进程和服务的 shell 脚本（通常为 `Bourne`）。rc 脚本通常由两部分组成：启动部分和停止部分。在系统启动或关机时执行相应的部分。

## server（服务器）

一个为远程客户端提供资源的计算机系统。

## setgid

一种特殊的文件访问模式，将执行程序的用户的有效 GID 设置为程序组所有者的 GID。setgid 权限的绝对模式为 `2000`，符号模式为 `s`。

## setuid

一种特种访问模式，将执行程序的程序用户账户的有效 UID 设置为程序所有者的 UID。setuid 权限的绝对模式为 `4000`，符号模式为 `s`。

# SGML

标准泛化标记语言（Standard Generalized Markup Language），用于提供一种编码文档内容的通用方法，而不与特定格式关联。参见 `Bourne shell`。

## NFS 资源共享

使 NFS 资源可供远程 NFS 客户端挂载的过程。

## Shell

一个在用户和内核之间提供接口的软件模块。操作系统三个部分之一（其他两个部分是内核和文件系统）。

# signal（信号）

发送给进程的通知，用于指示应该执行的事件或操作。信号可终止进程。

参见 `partition`。

## small computer system interface (SCSI)（小型计算机接口）

一种基于总线的外围设备连接机制，通常用于磁盘驱动器和磁带驱动器。

## software configuration（软件配置）

见 `software group`。

## software group（软件组）

一组软件簇。根据系统的预期用途，应选择最合适的软件组来安装操作系统。

## software package（软件包）

SPARC 指令集。

## standalone system（独立系统）

一种使用本地磁盘空间存储所有操作系统文件、应用程序和用户数据的系统，具有根目录 (`/`)、`/export/home` 和 `/var` 文件系统。同样，独立系统为系统的虚拟内存提供交换空间。独立系统可以自主运行，可以是联网的，也可以是非联网的。

## sticky bit（粘滞位）

一种特殊权限，设置在目录上时，仅允许创建该文件和子目录的用户账户删除这些文件和子目录。粘滞位对于任何用户账户都可以使用的 `/tmp` 目录特别有用。粘滞位权限的绝对模式为 `1000`，符号模式为 `t`。

## striped device（条带设备）

由两个或多个切片组成。这些切片可以在同一个物理磁盘上，也可以在多个磁盘上。切片的大小也可以不同。它们以交错的方式寻址。也就是说，当需要空间时，从第一个切片分配一个块，然后从第二个切片，以此类推。

## subdisk（子磁盘）

卷管理器用于分配存储的基本单元。子磁盘是 VM 磁盘公共区域的一部分。

## SunInstall

一种交互式 Windows 安装程序，可安装 Solaris 8 软件，但不支持安装协作软件包。

## superuser（超级用户）

一种特殊的管理账户，在数据和服务访问方面提供最终权限，因为它可以覆盖系统上的任何文件权限。

## swap space（交换空间）

用作虚拟内存磁盘。交换空间可以在本地磁盘上，也可以通过网络访问的远程磁盘上。

## syslog actions（日志操作）

当 syslog 进程接收到识别出的源.优先级的消息时应执行的操作。

## syslog priority levels（日志优先级级别）

syslog 消息可以通过优先级或严重程度来识别。这种识别为根据重要性处理消息提供了另一种粒度更细机制。

## syslog source facilities（日志源设施）

生成 syslog 消息的设施可用于确定消息的去向发送或存储。这样做允许根据系统配置阶段，为不同类型的消息创建单独的日志文件。

## 安装阶段

在此阶段将识别系统的基本信息，如主机名和域名。这些信息可以选择性提前设置，并在预配置系统安装阶段。

## 系统软件安装阶段

在此阶段将安装系统软件。系统软件是 Solaris 8 软件组之一。

## 系统配置文件 (system profile)

对于使用 `sh`（Bourne shell）或 `ksh`（Korn shell）作为登录 shell 的用户账户，系统配置文件（`etc/profile`）中的命令将在用户的登录初始化文件之前执行。

## 系统运行级别 (system run levels)

定义的八个级别，每个级别都与特定功能相关，用于关闭或重启系统，并控制系统服务和资源。

## 传输控制协议/互联网协议 (TCP/IP) 网络模型

一种由五层服务组成的网络模型。每层负责处理网络通信的不同方面。

## UFS 文件日志 (UFS file logging)

UFS 文件系统的更新在应用之前记录在日志中。在系统发生故障时，系统可以重启，UFS 文件系统可以快速使用日志，而无需使用 `fsck` 命令。

## 用户账户 (user account)

一个唯一的名称和用户 ID，用于控制个人对计算机及其资源的访问。

## 用户 ID (UID)

分配给用户账户的唯一数字 ID，用于文件和进程的所有权以及访问权限。

## Veritas 文件系统 (vfs)

企业级卷管理器（Enterprise Volume Manager）支持的虚拟文件系统类型。

## 虚拟磁盘管理系统 (virtual disk management system)

该软件包允许以标准 Solaris 系统不支持的方式使用物理磁盘。它可以克服磁盘容量和架构限制，并提高性能和可靠性。此外，通过使用图形管理工具增强了管理性。

## 虚拟文件系统 (virtual file system)

一种增强型文件系统，提供了改进的性能和数据可靠性。

## 卷 (volume)

一个由最多 32 个卷（plexes）组成的企业级卷管理器虚拟磁盘设备。卷是操作系统和应用程序查看和操作的虚拟对象。

## 卷管理器 (VM) 磁盘

分配给企业级卷管理器的物理磁盘分区或切片（slice）。

## 卷索引 (VTOC)

包含分区表和关于磁盘的各种几何数据，例如每个磁道的扇区、每个柱面的磁道数、可用柱面等。

# WebNFS

一种允许 Web 浏览器访问 NFS 资源的协议。该协议由 RFC 2054 和 2055 定义。

# Web Start

一种使用 Web 浏览器界面的交互式安装方法。

# x86

基于 Intel 公司最初设计的微处理器的计算机架构，其使用 286、386、486 系列数字来表示版本。

# X/Open 联邦命名规范 (XFN)

由 X/Open 联盟定义的联邦命名服务（FNS）规范。

# 区域 (zone)

委托给 DNS 服务器的域的一部分。
