
在 `tcsh` 中，`if` 语句有两种形式。第一种形式类似于 `pdksh` 和 `bash` 的形式如下：

```tcsh
if (expression) then
    Statements
else if (expression) then
    Statements
else
    Statements
endif
```

`if` 条件是可以嵌套的——也就是说，一个 `if` 条件内部可以包含另一个条件。`if` 条件并不一定非要有 `else` 部分。如果 `if` 语句中没有指定任何表达式，且任何后续的 `else if` 语句为真，则执行相应的部分。单词 `endif` 用于表示语句的结束，这在你有嵌套条件时非常有用。在这种情况下，你应该能够匹配 `endif`，以确保所有语句的代码编写都是正确的。

在接下来的示例中，一个变量 `var` 可以具有两个值之一：Yes 或 No。任何其他值都是无效的。这可以如下所示编码：

```bash
if [ $var = "Yes" ]; then
    echo "Value is Yes"
elif [ $var = "No" ]; then
    echo "Value is No"
else
    echo "Invalid value"
fi
```

# case 语句

`case` 语句用于根据变量的值执行不同的代码块。在 `bash` 中，`case` 语句格式如下：

```bash
case variable in
  pattern1)
    statements
    ;;
  pattern2)
    statements
    ;;
  *)
    statements
    ;;
esac
```

在 `tcsh` 中，对应的语句是 `switch`：

```tcsh
switch (variable)
  case pattern1
    statements
    breaksw
  case pattern2
    statements
    breaksw
  default:
    statements
    breaksw
endswitch
```

以下是 `pdksh` 和 `bash` 中函数的格式：

```bash
func(){
  Statements
}
```

你可以如下所示调用函数：
`func param1 param2 param3`

参数 `param1`、`param2` 和 `$@` 也是可选的。

函数可以像处理单个字符串一样解析参数——例如，像从命令行作为命令行参数传递给 shell 程序的顺序参数一样，但使用的是脚本内部的值。例如，以下脚本使用了一个命名的 `Displaymonth()` 函数，它可以显示月份名称，或者如果你传递了超出 1 到 12 范围的月份数字，它会显示错误消息。此示例在 `pdksh` 和 `bash` 中均有效：

```bash
#!/bin/sh

Displaymonth() {
  case $1 in
    01 | 1) echo "Month is January";
    02 | 2) echo "Month is February";
    03 | 3) echo "Month is March";
    04 | 4) echo "Month is April";
    05 | 5) echo "Month is May";
    06 | 6) echo "Month is June";
    07 | 7) echo "Month is July";
    08 | 8) echo "Month is August";
    09 | 9) echo "Month is September";
    10) echo "Month is October";
    11) echo "Month is November";
    12) echo "Month is December";
    *) echo "Invalid parameter";
  esac
}

Displaymonth 8
```
