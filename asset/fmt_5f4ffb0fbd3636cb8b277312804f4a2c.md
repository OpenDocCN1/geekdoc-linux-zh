
A：`WorkGroup` 设计用于最多 35 个用户，且仅提供支持最多 50 个用户的级别。几乎所有高端性能功能（如数据库块、后台页面写入器和 `-spin` 参数）都是不可用的。前滚恢复、崩溃防护（`Crash Proof`）、网络化（`Networkable`）、单次连接中的多个数据库连接以及两阶段提交的所有基本功能在两种数据库中都是通用的。但如果对性能有任何要求，任何类型的用户都会考虑购买 `Enterprise` 版。

- Q：Progress 国际可用吗？

A：是的；事实上，Progress 在世界各地设有办事。在某些 Progress 没有自身机构的情况下，通过国家级分销网络提供。除了这些顶级功能外，Progress 提供了大品牌数据库的所有真正重要的功能，但成本要低得多。

# 引言

世界上每一台计算机系统都需要数据库来存储和检索信息。你使用计算机的主要目的是存储、检索和处理信息，并快速地完成所有操作，从而节省时间。同时，系统必须简单、稳健、快速、可靠、经济且易于使用。数据库是最重要的系统，因为它存储了全球每家公司任务关键的信息。电信、汽车、银行、航空公司等行业如果没有数据库系统将无法高效运行。最流行的数据库系统基于国际标准组织 (ISO) 的 SQL 规范和 ANSI SQL（美国）标准。目前业界广泛使用的规范是 ISO/ANSI SQL 1992/98。如果没有像 ANSI/ISO SQL 这样的标准，客户将很难开发一次应用就能在所有平台上运行它。终端用户希望只使用 ISO SQL、ODBC 和 JDBC 开发一次应用，然后就能将其部署到各种数据库系统中。

`PostgreSQL` 是世界上最先进的开源对象关系数据库。`PostgreSQL` 最初由加州伯克利分校计算机科学系开发，开创了许多对象关系概念。它提供了 SQL92/SQL3 支持、事务完整性、用户定义函数、存储过程、触发器和类型扩展性。`PostgreSQL` 是原始伯克利代码的公共领域、免费且开源的后代。数百万 `PostgreSQL` 数据库被安装为数据库服务器、Web 数据库和应用程序服务器。这是一个非常复杂的对象关系数据库系统 (`ORDBMS`)。`PostgreSQL` 可运行在 Solaris、SunOS、HPUX、AIX、Linux、Irix、Digital Unix、BSDi、NetBSD、FreeBSD、SCO UNIX、NEXTSTEP、Unisware 以及几乎所有的 UNIX 版本上。到 Windows NT是通过 Cygnus `cywin32` 包实现的。

- 标题：PostgreSQL SQL RDBMS 数据库（对象关系数据库管理系统）
- 当前版本：7.0
- 历史：PostgreSQL 自 1985 年开始开发，现已有 15 年历史。
- 作者：在过去的 15 年里，互联网上大学和机构的数百万人共同开发了 PostgreSQL。

`MySQL` 是另一个开源的准商业数据库系统，但它支持事务等重要功能。

# 互联网力量驱动 PostgreSQL

互联网起源于一个防御项目，后来变得如此普及，以到连接了全球各大洲的人。这促进了全球范围内信息、智能思想和研究课题的快速交换。结果是互联网成为了全球最大的软件“生成器”。软件开发方法从闭源转向开源代码，而互联网促进了这种系统的产生。互联网被用于帮助操作系统 Linux，使其变得极其受欢迎。随着 Linux 的成功，许多人决定在数据库系统、电子表格等计算机应用上延续这一理念。互联网上的开发者并没有从零开始构建系统，而是利用了加州大学分校的公共领域 Postgres 代码，并对其进行了修改和增强，最终形成了 PostgreSQL。

互联网是驱动 PostgreSQL 的真正引擎。物理学和统计学也部分对 PostgreSQL 的成功做出了贡献——它们支持像 PostgreSQL 和 Linux 这样的开源代码系统。随着互联网速度日益增长，互联网变得越来越可靠，开源代码系统将获得快速发展的动力。通过将统计学、数学和科学原理应用于软件质量，你只有在像 PostgreSQL 这样的开源代码系统中才能获得顶级的软件质量，源代码对互联网这一“信息超级公路”是开放的。编写代码的人越多，软件质量就越好。开源代码模型还将消除重复劳动、非常经济、节省分发时间，并遵循优化国家和全球资源的现代经济法则。一旦其他人生产了软件包，你就不需要浪费时间去重复已经做得很好的工作。

由于 PostgreSQL 遵循开源开发模型，你获得了许多功能。由于有大量的计算机和人员参与其中，互联网上的软件开发速度非常快。满足 ANSI/ISO SQL 的另一个系统没有意义，利用现有代码并为 PostgreSQL 添加缺失的功能或增强，然后立即开始使用将是一个巨大的优势。

预计对 PostgreSQL 这样的互联网产品的需求将呈指数级增长，因为它能够保持高质量、低成本以及庞大的用户和开发者群体。不使用互联网的国家将严重错过全球互联网革命，并被其他国家淘汰，因为互联网本身就是全球最大的“软件公司”，是一个庞大的软件工厂。
