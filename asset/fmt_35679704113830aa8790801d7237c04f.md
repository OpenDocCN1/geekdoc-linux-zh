# 在光标位置编辑

你可以输入新文本并将现有文本向右推。输入新文本不需要特殊命令。如果你输入的文本超出窗口边缘，emacs 会第 80 列放置一个反斜杠（`\`），然后将剩余文本折叠到下一行。反斜杠显示在屏幕上，但不会被打印。虽然你可以创建任意长度的行，但某些 UNIX 工具处理包含非常长行的文本文件会出现问题。你可以通过定位光标并按 `RETURN` 来拆分某行。

# 基础编辑命令

按下 `DELETE` 会删除光标左侧的字符。每当你按下 `DELETE` 时，光标和该行的剩余文本都会向左移动。要将当前行与上方行合并，请将光标置在第二行的第一个字符上并按下 `DELETE`。

按 `CONTROL-D` 删除光标下的字符。光标保持不动，该行的剩余文本向左移动以替换被删除的字符。如果这两个按键中的任何一个没有按照描述的方式工作，请参阅第 477 页的提示“更多关于删除字符的内容”。

# 保存和检索缓冲区

无论在 emacs 会话期间缓冲区发生了什么变化，在保存缓冲区之前，关联的文件都不会发生变化。如果你在未保存的情况下就退出了 emacs，文件将不会发生变化，会话的工作也将被丢弃。

如前提到的，emacs 会对缓冲区内容中未保存的更改进行提问。当 emacs 将编辑后的缓冲区写回文件时，emacs 可选择地先对原始文件内容进行备份。你可以选择不备份、一级备份（默认）或任意数量级的备份。一级备份的文件名通过在原始文件名后附加 `~-n` 形成，其中 n 是从 1 开始的顺序备份编号。

命令 `CONTROL-X CONTROL-S` 将当前缓冲区保存到其关联文件中。emacs 编辑器会在回显区（Echo Area）显示消息以确认保存成功。

如果你已经在用 emacs 编辑一个文件并想要编辑另一个文件，你可以通过输入 `CONTROL-X CONTROL-F` 命令将新文件复制到新的 emacs 缓冲区中。emacs 编辑器会提示你输入文件名，将该文件读入新缓冲区，并在当前窗口中显示该缓冲区。

# 基础编辑命令

本节将更详细地介绍基础的 emacs 编辑命令。它涵盖了在单个窗口中对单个文件进行直接编辑。

## 使用 `CONTROL-X CONTROL-F` 访问文件

使用 `CONTROL-X CONTROL-F` 时，emacs 会部分完成你将输入的文件名路径。通常情况下，这是工作目录的路径，但在某些情况下，emacs 可能会显示不同的路径，例如你的主目录路径。如果已显示的路径不是指向你想要的目录，你可以编辑此已显示的路径。

## 键：符号与用法

主流 emacs 使用 128 字符 ASCII 代码。ASCII 键盘具有打字机式的 `SHIFT` 键和 `CONTROL` 键。某些键盘还有 `META`（菱形或 `ALT`）键，用于控制第 8 位。描述一个 ASCII 字符需要七位；八位字节的第 8 位可以用于传输其他信息。由于 emacs 命令集中很大一部分都是 `CONTROL` 或 `META` 模式下的，Stallman 是首批面对开发编写按键输入符号问题的人之一。

他的解决方案使用大字母 `C` 和 `M` 分别表示按住 `CONTROL` 和 `META` 键，并对最特殊的字符使用几个简单的字母缩写，例如 `RET`、`LFD`、`DEL`、`ESC`、`SPC` 和 `TAB`。大多数 emacs 文档都使用这种符号。

## 键序列与命令

键序列与命令之间的关系非常灵活，你有很大的机会发挥自己的个人偏好。你可以将键序列翻译并重映射到其他命令，或者替换命令本身。

## `META-x`：运行未键绑定的命令

emacs 键位非常拥挤，通常无法将每一个命令都绑定到键序列上。你可以通过在命令前加上 `META-x` 来执行任何命令。emacs 编辑器会在回显区提示你命令，并在输入命令名称并按下回车键后执行该命令。

## 数字参数

某些 emacs 编辑命令接受数字参数，并将其解释为重复次数。参数紧跟在命令序列之后，没有参数的情况通常被解释为计数 1。

- 按下每个数字 `0–9` 或负号 `-`
- 使用 `CONTROL-U` 开始数字字符串，包括负号

为了方便起见，当 `CONTROL-U` 后没有跟随一个或多个数字时，它默认乘以 4。

## 点与光标

`Point` 是缓冲区中进行的地方，这也是光标所在的位置。严格来说，`Point` 是光标的左边缘——它被认为始终位于字符之间。

每个窗口都有自己的 `Point`，但只有一个光标。

你可以通过 `META-<` 将光标移动到缓冲区开头，或通过 `META->` 移动到缓冲区末尾。

## 滚动缓冲区

缓冲区通常比查看它的窗口要大得多，因此必须有一种移动显示内容的方法。

使用 `CONTROL-V` 向前滚动一个窗口。向后滚动使用 `META-v`。按 `CONTROL-L` 可以清屏并重绘屏幕，将当前行移动到窗口中心。

给 `CONTROL-V` 或 `META+v` 传递数值参数表示“向前（向后）滚动指定的行数”；例如，`CONTROL-U 10` 控制向前滚动十行。

## 删除文本

当文本被删除时，它可以被丢弃，也可以移动到一个临时区域，并在以后可选地恢复。“删除”一词意味着永久丢弃，而“杀死”一词意味着移动到临时区域。该区域被称为“杀死环”。

`META-d` 命令从光标开始杀死到当前单词末尾。`CONTROL-K` 从向前杀死到当前行结束。

## 搜索

emacs 编辑器有几种类型的搜索命令。

- 增量搜索字符字符串
- 增量搜索正则表达式
- 搜索完整的字符字符串
- 搜索完整的全正则表达式

## 增量搜索

`CONTROL-S` 开始向前增量搜索，`CONTROL-R` 开始向后增量搜索。

## 帮助命令

- `CONTROL-H k` 键序列：打印绑定到该键序列的命令名称和文档。
- `CONTROL-H f`：提示输入 Lisp 函数名称并打印其文档。
- `CONTROL-H i`：带你进入 info 的顶层菜单。
- `CONTROL-H l`：显示最后输入的 100 个字符。
- `CONTROL-H m`：显示当前主模式的文档和特殊按键绑定。
- `CONTROL-H n`：显示 emacs 新闻文件。
- `CONTROL-H t`：运行 emacs 教程课程。
- `CONTROL-H v`：提示输入 Lisp 变量名称并提供该变量的文档。
- `CONTROL-H w`：提示输入命令名称并提供绑定到该命令的键序列。

## 高级编辑主题

基础 emacs 命令足以许多编辑任务，但高级用户很快就会发现需要强大的功能。

## 撤销更改

当你将文件读取到 emacs 缓冲区时，编辑会话开始。此时，缓冲区内容与文件完全匹配。

窗口的状态行 `Mode Line` 在 emacs 的左侧有一个指示器：它显示窗口中缓冲区的修改状态。它的三种状态为 `--`、`**` 和 `%%`。

撤销键序列是 `CONTROL-u`。当你输入 `CONTROL-` 时，emacs 会撤销命令并将光标移动到缓冲区中的该位置。

## 剪切与粘贴：提取文本

记住，被杀死文本并没有被丢弃，而是保留在杀死环中。杀死环保留了最后 30 段被杀死的文本。

从杀死环中检索文本被称为提取 `yanking`。

常用 kill 和 yank 命令：

- `META-d` 向后杀死到当前单词的末尾
- `CONTROL-K` 杀死到行尾，不包括换行符
- `META-w` 将 `Point` 和 `Mark` 之间的区域复制到杀死环，但不从缓冲区中删除
- `CONTROL-W` 杀死从 `Point` 到 `Mark` 的区域
- `CONTROL-Y` 将最近杀死的文本提取到当前缓冲区的 `Point` 位置

## 插入特殊字符

emacs 会插入所有不是命令的内容。要插入 emacs 命令的字符，你可以使用 emacs 转义字符 `CONTROL-Q`。

## 全局缓冲区命令

emacs 编辑器有一类似的命令族。它们的操作区域从 `Point` 开始到缓冲区末尾。

## 行处理操作

`META-x OCCUR` 提示输入正则表达式，并在名为 `*Occur*` 的缓冲区中列出匹配该表达式的每一行

`META-x delete-matching-lines` 提示输入正则表达式，并删除匹配该表达式的每一行

`META-x delete-non-matching-lines` 提示输入正则表达式，并删除不匹配该表达式的每一行

## 无条件替换与交互式替换

`META-x replace-string` 提示输入字符串和新字符串，然后用新字符串替换所有实例。

`META-x replace-regex` 提示输入正则表达式和新字符串，然后用新字符串替换所有实例。

`META-% string` 或 `META-x query-replace` 用新字符串替换每个实例。

`META-x query-replace-regex` 提示输入正则表达式和新字符串，然后查询每个正则表达式实例。

## 文件

当你“访问”一个文件时，emacs 将其读取到内部缓冲区中，编辑缓冲区内容，最终将缓冲区保存回文件。

访问文件命令：

- `CONTROL-X CONTROL-F` 提示文件名并将其内容读取到新创建的缓冲区中
- `CONTROL-X CONTROL-V` 提示文件名并用一个包含请求文件内容的缓冲区替换当前缓冲区
- `CONTROL-X 4 CONTROL-F` 提示文件名并将其内容读取到新创建的缓冲区中，为此缓冲区创建一个新窗口

保存文件命令：

- `CONTROL-X CONTROL-S` 将当前缓冲区保存到原始文件中
- `CONTROL-X S` 对于每个修改过的缓冲区，你可能想要保存
- `META-X set-visited-file-name` 提示文件名并将此名称设置为缓冲区的“原始”名称
- `CONTROL-X CONTROL-W` 提示文件名，将该名称设置为当前缓冲区的“原始”文件，并将当前缓冲区保存到该文件中

## 缓冲区

一个 emacs 缓冲区是一个你可以编辑的存储对象。

操作缓冲区命令：

- `CONTROL-X b` 提示文件名并选择它
- `CONTROL-X 4 b` 提示文件名并在另一个窗口中选择它
- `CONTROL-X CONTROL-B` 创建名为 `Buffer*` 的缓冲区并在另一个窗口中显示
- `META-x rename-buffer` 提示新的缓冲区名称并将新名称赋予当前缓冲区
- `CONTROL-X CONTROL-Q` 切换当前缓冲区的只读状态

## 窗口

一个 emacs 窗口是查看缓冲区的视图。

分割窗口：

- `CONTROL-x 2` 将窗口拆分为两个
- `CONTROL-x 3` 将窗口拆分为两个部分，新窗口并排排列

操作窗口：

- `CONTROL-x-o` 选择另一个窗口
- `META-CONTROL-v` 命令会滚动另一个窗口

调整和删除窗口：

- `CONTROL-X 0` 删除当前窗口
- `CONTROL-X 1` 删除当前窗口外的所有窗口
- `META-shrink-window` 让窗口变短
- `CONTROL-X ^` 增加窗口高度

## 前台 Shell 命令

- `META-!` 提示 shell 命令，执行它并显示输出
- `CONTROL-U META-!` 提示 shell 命令，执行它并在 `Point` 处插入输出
- `META-|` 提示 shell 命令，将区域内容作为输入，通过命令过滤并显示输出

## 语言敏感编辑

emacs 编辑器拥有一套针对特定文本类型的特性集合。这些集合被称为 `Major mode`。

## 语言模式

人类语言最终是为了供人类使用的。

## 单词

`META-A` 和 `META-B` 在单词上向前向后移动。`META-D` 和 `META-DELETE` 向前和向后删除单词。`META-I` 将光标之前的单词替换为光标之后的单词。

## 句子

`META-A` 回到句子的开头，`META-E` 移动到句子的结尾。`META-K` 向前删除到句子的结尾。

## 段落

`META-i` 回到最近的段落开头，`META-j` 移动到下一个段落的末尾。

## 填充

`META-X auto-fill-turns` 开启或关闭自动填充模式。

## 大小写转换

- `META-I` 将光标右侧的单词转换为小写
- `META-u` 将光标右侧的单词转换为大写
- `META-c` 将光标右侧的单词转换为首字母大写
- `CONTROL-X-CONTROL-L` 将 `Point` 和 `Mark` 之间的区域转换为小写
- `CONTROL-X-CONTROL-U` 将 `Point` 和 `Mark` 之间的区域转换为大写

## C 模式

在该模式下，`TAB` 运行 `tab-stop` 函数。

## 表达式

表 11-17 列出了适用于带括号表达式和某些标记的 emacs 编辑器命令。

- `CONTROL-META-f` 向前移动一个表达式
- `CONTROL-META-b` 向后移动一个表达式
- `CONTROL-META-k` 杀掉前后的表达式
- `CONTROL-META-@` 将 `Mark` 设置在位置

## 函数定义

- `CONTROL-META-a` 移动到最近一个函数定义的开头
- `CONTROL-META-e` 移动到下一个函数定义的末尾
- `CONTROL-META-h` 将 `Point` 置于当前函数定义的开头，将 `Mark` 置于末尾

## 缩进

- `TAB` 调整当前行的缩进
- `LINEFEED` `RETURN` 后接 `TAB` 的简写
- `CONTROL-META-q` 重新缩进下一对匹配大括号内部的所有行
- `CONTROL-META-` 重新缩进 `Point` 和 `Mark` 之间当前区域的所有行
