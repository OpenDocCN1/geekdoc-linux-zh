# wmaker

为 X 的类 NeXTStep 窗口管理器。由 Alfredo Kojima (http://www.infrag.br/~kojima) 几乎从零开始，外观与 NeXTStep 非常相似，它现在是一个官方的 GNU 项目。Window Maker 功能没有过度堆载，并且比其他窗口管理器更容易配置。它的最终目标是产生一个不需要编辑配置文件的窗口管理器。Window Maker 运行速度快，且不需要大量内存。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/linux-Dictionary/html/index.html

# wmakerconf

基于 GTK+ 的 Window Maker 配置工具。Window Maker 交互式配置实用程序。它提供了使用鼠标设备和点击界面配置 Window Maker 的功能，避免直接编辑其配置文件。如果系统中没有 Window Maker，这个程序没有太大安装意义，但我认为在某些情况下它是需要的，例如，自编译的 wmaker 管理器。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Dictionary/html/index.html

# wmamager

X 启动时的窗口选择。`wmanager` 是一个在 X 启动时选择窗口管理器的小型 X11 应用程序。`wmanager` 在用户主目录下查找名为 '`wmanager`' 的文件，其中包含窗口管理器列表；你可以使用 `wmanager-update`。你也可以使用 `wmanager-loop` 运行用户选择的窗口管理器直到退出。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Dictionary/html/index.html

# wmapm
