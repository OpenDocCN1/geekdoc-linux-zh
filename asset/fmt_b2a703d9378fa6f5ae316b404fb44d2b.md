## cjk-latex
一个用于 CJK（中/日/韩）的 LaTeX 宏。CJK 是一个 LaTeX 宏包，用于启用中文、日语和韩语的排版。它支持（各种）CJK 编码，例如 Big5, GB, JIS, KS, CNS。请同时安装：

- `freetype1-tools` 用于在 CJK 中使用 TrueType 字体 (`ttf2pk` 和 `ttf2im`)。
- `tfmf-archive` 用于由 CJK 捐赠的免 DFSG 的中文 TrueType 字体 (`ttf2pk`)。
- `tfmf-archive-gshbbmm00p` 和 `tfmf-archive-bka0p` 用于 Big5 和楷体字体；

主要作者：Werner Liebig <w1@gnu.org> 源自 Debian 3.00 APT

http://www.tldp.org/LDP/Linux-Dictionary/index.html

## cksv

http://www.tldp.org/LDP/Linux-Dictionary/index.html

## clanlib
LibGame SDK 的核心运行时库。ClanLib 提供了一个平台无关的接口用于编写游戏。如果使用 ClanLib 编写游戏，则可以在任何平台下编译游戏（即在 ClanLib 支持的平台上，无需更改应用程序源代码）。ClanLib 不是一个封装库，它为为 DirectFB、DirectX、OpenGL、X11 等底层库提供通用接口。虽然平台独立性是 ClanLib 的首要目标，它也试图成为一个以服务为导向的游戏 SDK。换言之，我们在设计 API 上付出了努力，以确保 ClanLib 的易用性——同时保持其纯洁性。此包提供了核心库（layer1, layer2 等）。源自 Debian 3.0.0

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## clara
适用于 Unix 系统的免费 OCR 程序。Clara OCR 是一个（免费的）支持 C 库和 X 窗口系统的 OCR（例如大多数变种 Unix）。Clara OCR 为大型数字化项目设计。它具有强大的 GUI 和网络界面，用于协作数字化业务。源自 Debian 3.0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## ClarkConnect
ClarkConnect 是一个红帽发行版，可以将 PC 硬件转换为专用宽带网关和易于使用的服务器。该软件是小型企业、家庭办公室和网络家庭的极佳解决方案。ClarkConnect 1.1 版本于 2002 年 7 月 31 日发布。源自 LNW 分发列表 http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## clear-text
在密码学中，明文指的是未加密的消息。该词也带有已加密但并非加密数据的含义（例如明文密码）。误解：该词源于传统的密码学，指的是消息文本，现在可以指二进制数据。源自 Hacking-Lexicon

## CLI (命令行界面)
一个全屏或窗口文本模式会话，用户通过输入带或不带参数的命令进行编程。CLI 显示操作系统或程序的输出，并提供输入命令提示符。I–gloss

## cli (命令行界面)
程序与用户之间的一种基于文本输入输出的通信方式。通过键盘或类似设备输入命令，由程序进行解释和执行。结果以文本或图形形式输出到终端。源自 Linux Guide @FirstLinux

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
