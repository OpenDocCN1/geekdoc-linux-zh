
文件模式 `r` 用于读取，`w` 用于写入，`a` 用于追加。这些模式假设为文本模式并可能隐式地翻译换行符 `\n`。例如，在 Windows 上，写入字符 `\n` 实际上输出双字符序列 `\r\n`（读取文件时，`\r\n` 被翻译为单个 `\n`）。如果你正在处理二进制数据，请在文件模式中添加 `b` 或 `wb`。这禁用了换行翻译，如果你担心处理二进制数据的代码移植性（UNIX 上省略 `b` 是一个常见错误）。在这些模式下，你可能会看到文本模式 `rt`、`wt` 或 `at`，这更清晰地表达了你的意图。

文件可以使用 `r+`、`w+` 或 `a+` 打开进行更新。当打开进行更新时，你可以执行输入和输出操作，只要所有操作在后续操作之前刷新了它们的数据。如果以 `wb` 模式打开文件，它首先被截断为零。

如果以 `ur` 或 `ut` 打开文件，它提供了通用读取支持。通过将不同的换行编码（如 `\n`、`\r` 或 `\r\n`）翻译为文件 I/O 函数返回的字符串中的标准 `\n` 字符，该特性提供了跨平台支持。这非常有用，可选的 `bufsize` 参数控制文件的缓冲，0 请求系统默认值。任何其他正数表示将使用的近似字节缓冲区大小。

Python 为 `open()` 函数添加了几个参数，调用格式为 `open(name, mode[, bufsize, encoding[, errors[, newline[, closefd]]])`。`encoding` 是编码名称，如 `utf-8` 或 `ascii`。`errors` 是使用编码时的错误处理策略（更多信息请参见本章关于 Unicode 的后续章节）。`newline` 控制通用换行模式的行为，如果设置为 `None`、`\n`、`\r` 或 `\r\n`，则分别翻译 `\n`、`\r` 或 `\r\n`。如果设置为 `''`（空字符串），这些行结束符被识别为换行但在输入文本中保持不变。如果 `newline` 有任何其他合法值，则该值被用于结束行。`closefd` 控制在调用 `close()` 方法时底层文件描述符是否实际关闭。默认情况下，这是 `True`。

`read()` 方法返回整个文件，除非可选的长度参数指定了最大字符数。`readline()` 方法返回下一行输入，包括终止的换行符；`readlines()` 方法将所有输入行作为字符串列表返回。`readline()` 方法可选接受一个最大长度 `n`。如果存在大于 `n` 个字符的行，则返回前 `n` 个字符。剩余的行不会被丢弃，将在后续读取中返回。`read()` 方法接受一个 `size` 参数，指定在停止之前读取的字符数。实际字符数可能取决于已读取的数据量。

`read()` 和 `readlines()` 方法都是感知平台的，并并能正确处理不同的换行符表示（例如 `'\n'` 与 `'\r\n'`）。如果文件以通用换行模式（`'U'` 或 `'RU'`）打开，换行符将转换为 `'\n'`。

`read()` 和 `readlines()` 通过返回空字符串来指示文件结束 (EOF)。因此，以下代码显示了如何检测 EOF 条件：

```
while True:
    line = f.readline()
    if not line:
        # EOF
        break
```

读取文件中所有行的一种方便方法是使用 `for` 循环进行迭代。示例：

```
for line in f:
    # 遍历文件中的所有行
    # 对 line 执行某些操作
```

请注意，在 Python 2 中，各种读取操作无论文件类型如何，都返回 8 位的字符串。在 Python 3 中，如果文件以文本模式打开，这些操作将返回 Unicode 字符串；如果文件以二进制模式打开，则返回字节字符串。

`write()` 方法将字符串写入文件，而 `writelines()` 方法将字符串列表写入文件。`write()` 和 `writelines()` 不向输出中添加换行符，因此你产生的输出应该包含所有必要的格式设置。这些方法可以向文件写入字节字符串，但前提是文件是以二进制模式打开的。

## 标准输入、输出和错误

内部，每个文件对象都保存一个文件指针，存储下一次读取或写入操作将发生的字节偏移。`tell()` 方法返回当前文件指针的值，作为一个长整数。`seek()` 方法用于通过偏移量（offset）和位置基准（whence）随机访问文件的部分。如果 `whence` 为 0（默认值），`seek()` 假设偏移量相对于文件开头；如果 `whence` 为 1，则则相对于当前位置移动；如果 `whence` 为 2，则从文件末尾计算。`seek()` 返回文件指针的新值，作为一个整数。需要注意的是，文件指针与 `open()` 返回的文件对象相关，而不是文件本身。同一个文件可以使用 `open` 指针打开多次，且同一程序（或不同程序）中的每个文件实例都可以独立操作。

`fileno()` 方法返回文件的整数文件描述符，有时用于 carry` 模块中的低级 I/O 操作。例如，`fcntl` 模块使用文件描述符在 UNIX 系统上提供低级文件控制操作。

## 标准输入、输出和错误

解释器提供了三个文件对象，称为标准输入、标准输出和标准错误，分别在 `sys` 模块中作为 `sys.stdin`、`sys.stdout` 和 `sys.stderr` 可。`stdin` 是对应于 `print` 提供的输入字符流的文件对象。`stdout` 是接收 `print` 输出的文件对象。`stderr` 是一个接收错误消息的文件。通常情况下，`stdin` 映射到用户的键盘，而 `stdout` 和 `stderr` 则在屏幕上产生文本。

上一节描述的方法可以与用户执行原始 I/O。例如，以下代码向标准输出写入并从标准输入读取：

```python
import sys
sys.stdout.write("Enter name: ")
name = sys.stdin.readline()
```

`print("Hello", name)`
