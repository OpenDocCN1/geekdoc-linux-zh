## LINUS 新手管理员常见问题解答 (FAQ)

| 变量 | 说明 |
| :--- | :--- |
| `sd=var/spool/lpd/lp` | 打印机名称。`lp` 是你机器上默认打印机的名称。后续打印机通常默认被命名为 `lp0` 或 `lp1...`（或你喜欢的任何名称），但不应将其与它们连接的设备（并行端口）的名称混淆。 |
| `mx` | 我的打印溢池目录 `sd`。以块为单位的打印作业最大大小 `mx`。`0` 表示无限制。我要打印页眉 `sh`。页眉是在你的作业之前打印的带有该名的页面，如果你在家里，这会浪费打印机。远程机器名称 `rm`，你的系统在该机器上被称为 `mars`（我的打印机连接到另一台计算机）。远程打印机名称 `rp`，它是远程机器 `lp`（或我网络上的 `mars`）的名称。本地机器名称。`/dev/lp0` 是 RH.6 上的并行端口（以前是 `/dev/lp5`，端口编号已更改）。 |
| `if=var/spool/lpd/lpfilter` | 输入过滤器 `if`。你的打印作业在发送到打印机之前会被此“过滤器”格式化。 |
| `sf` | 假设打印完成后通常发送的表单 `sf`（如果你的打印机在每个作业结束时会留下一空白页）。 |

打印机使用 `asc` 命令 (`root`) 控制。输入 `?` 查看选项。打印机队列以其特殊性而闻名，所以不要气馁！可以使用 `lq` 查看队列，使用 `lrm` 清理队列，这两个命令普通用户（非 `root`）都可以。在 KDE 下，你可以从命令行使用 `lrm` 命令，或者通过“K-button”使用的可用程序（工具->打印队列）来控制打印机。

大多数打印机在 Linux 下都能完美工作，但由于缺少厂商的信息/驱动程序，某些可能无法发挥全部能力。因此，在购买新打印机时，你可能想咨询 Linux 打印机数据库：`http://www.linuxprinting.org/database.html`。简之，选择以下内容是稳妥的：`http://www.linuxprinting.org/suggested.htm`

## 5.4.2 设置和配置文件在哪里？

系统级设置存储在 `/etc` 目录。用户特定设置存储在你的用户主目录 `/home/user` 登录。

以下是我使用的系统级配置文件列表：

- `/etc/bashrc` - `bash` shell 的系统级默认函数和别名
- `/etc/profile` - `bash` shell 的系统级默认设置，包括系统级环境变量。

## 管理员设置

- `/etc/passwd` - 以及关于注册使用系统的用户的其他信息。可以由 `root` 直接修改，但最好使用配置实用程序，因为使用 `passwd` 编辑 `/etc/passwd` 文件很容易让 Linux 机器无法使用。

- `/etc/shadow` - 包含 `/etc/passwd` 文件的“影子”信息，即“世界”用户没有权限读取的信息片段。
- `/etc/group` - 与 `/etc/passwd` 类似，但针对组。
- `/etc/crontab` - 为 `cron` 设置，它定期运行（每小时、每天、每周、每月等）。
- `/etc/inittab` - 在系统启动时运行不同的程序和进程。
- `/etc/issue` - 伴随登录提示的消息。这通常会被本地脚本覆盖。
- `/etc/issue.net` - 与上述相同，但在尝试通过网络登录时使用。
- `/etc/motd` - “今日消息”文件，在用户登录后显示。
- `/etc/rc.local` - 系统启动时执行的最后一个脚本。但在该文件末尾的命令可以自定义你的本地机器。它的工作原理类似于 DOS 的 `autoexec.bat`。

## 网络配置

- `/etc/hosts` - 包含主机名和绝对 IP 地址列表。
- `/etc/hosts.allow` - 允许访问互联网服务的主机。
- `/etc/hosts.deny` - 禁止访问互联网服务的主机。
- `/etc/resolv.conf` - 由本地机器设置域名服务器列表。
- `/etc/inetd.conf` - 配置 `inetd` 守护进程，你的机器应该运行的 TCP/IP 服务。
- `/etc/exports` - 指定可以使用 NFS（网络文件系统）导出文件系统的主机。`exports` 包含了如何为远程用户设置此文件的信息。

## 硬件配置

- `/etc/conf.modules` - 为 Linux 内核模块设置。模块类似于 Windows 或 DOS 上的“设备驱动程序”。
- `/etc/fstab` - 包含分区和文件系统信息，系统使用它们在目录树上挂载不同的分区和设备。
- `/etc/mtab` - 显示当前挂载的设备和分区及其状态。
- `/etc/lilo.conf` - `lilo` 引导加载器的配置文件。
- `/boot/grub.conf` - `grub` 引导加载器的配置文件。
- `/etc/printcap` - 打印设置。
- `/etc/termcap` - 包含不同控制台、终端和特性的 ASCII 数据库。你通常不想更改它。
- `/etc/X11/XF86Config` - X 配置。对于 XFree 4.xx 版本，文件是 `/etc/X11/XF86Config-4`（如果尝试了 `XF86Config` 则不使用）。

## 5.4.3 所有设备文件是什么？

设备以文件形式出现在 `/dev` 目录。如果你有权限，可以读取或写入它们。文件列表显示了关于设备的某些重要细节，例如：

```
ls -l /dev/tty53
```

执行 `ls -l /dev/tty53` 在我的系统上产生以下输出：

```
crw-rw-rw- 1 root tty 4, 67 Mar 13 22:59 tty53
```
