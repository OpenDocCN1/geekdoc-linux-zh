### cmp

| 名称 | 字符串比较 |
| :--- | :--- |
| 优先级 | 12 |
| 结合性 | 非结合性 |
| 操作数类型 | 字符串 |
| 操作数个数 | 两个（二元） |
| 上文 | 标量 |

该运算符比较两个字符串，如果第一个小于第二个，则返回 -1；如果两个操作数相等，则返回 0；如果第一个大于第二个，则返回 1。

示例：

```
$ans = "abc" cmp "aba";

print("Comparing (cmp) abc with aba yields $ans (expected +1 aba > abc)\n");
```

### eq
