
```bash
# mke2fs -c /dev/hdb1
```

此时，你也可以定义 inode 的字节大小（如在设置程序中那样）。

```bash
# mke2fs -i 1024 /dev/hdb2
```

> **注意** 尽管默认 inode 大小为 4096 字节，但你必须将其定义不小于 1KB（1024 字节）。

目前不支持碎片；请勿使用 `-f` 选项。
