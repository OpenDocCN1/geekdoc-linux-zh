
# Bison

Bison 是一个解析器生成器，是 YACC 的替代品。YACC 的是“又一个编译器编译器”（Yet Another Compiler Compiler）。那么 Bison 是什么呢？它是一个用于生成分析文本文件结构的程序。你不需要编写实际程序，只需指定内容应该如何连接，程序就会根据这些规则构建出一个分析文本文件的程序。

在很多场景下都需要用到结构，其中之一就是计算器。

给定字符串：

```
1 + 2 * 3
```

你可以很容易地得到结果 7。为什么？因为有了结构。你知道如何解释这个字符串。计算机并不知道，而 Bison 是一个工具，它通过以以下方式向编译器呈现字符串来帮助计算机理解：

```
+
/\ 
  * 1
/\ 
  2 3
```

你从树的底部开始，会遇到数字 2 和 3，它们通过乘法符号连接，计算机将 2 乘以 3。乘法的结果被记录，计算机看到的下一个内容是 2*3 的结果和数字 1，它们通过加法符号连接。在上一个结果上加上 1 得到 7。在进行最复杂的计算时，可以以这种树状格式进行分解，计算机只需从底部开始逐层向上，即可得到正确答案。当然，Bison 不仅用于计算器。

# Findutils

## 目录
Findutils 软件包包含 `find`、`locate`、`updatedb` 和 `xargs` 程序。

### 描述

#### Find
`find` 程序在目录层次结构中搜索符合特定标准的文件。如果没有给出任何标准，它将列出当前目录及其子目录下的所有文件。

#### Locate
`Locate` 扫描包含文件系统中所有文件和目录的数据库。该程序列出数据库中符合特定标准的文件和目录。如果你正在寻找一个文件，该程序将扫描数据库并准确地告诉你你请求的文件位于何处。只有当你的 `locate` 数据库足够新时，这才有意义，否则它将提供过时的信息。

#### Updatedb
`updatedb` 程序更新 `locate` 数据库。它扫描整个文件系统（包括当前挂载的其他文件系统，除非你指定排除），并将每个目录和发现的内容放入 `locate` 程序使用的数据库中。每天更新一次数据库是一个良好的习惯，这样可以确保数据库是最新的。

# Ncurses

## 目录
Ncurses 软件包包含 `ncurses`、`panel`、`menu`。它还包含 `tic`、`infocmp`、`clear`、`tput` 和 `toe` 程序。

### 描述

#### 库
构成 `ncurses` 的库在你的屏幕上显示文本（通常以华丽的方式）。这些库包含了面板、菜单和表单的例程。

#### Tic
`Tic` 是 `terminfo` 编译器。该程序将 `terminfo` 源文件转换为二进制格式。

#### Infocmp
`infocmp` 程序用于将二进制 `terminfo` 项与其他 `terminfo` 项进行比较，或输出 `terminfo` 描述。

#### clear
`clear` 程序可以清除你的屏幕。它在环境中查找终端类型，然后在 `terminfo` 数据库中查找如何清除。

#### tput
`tput` 程序使用 `terminfo` 数据库为 shell 提供值。

#### toe
`toe` 程序列出所有可用终端类型及其描述。

#### tset
`tset` 程序初始化终端以便使用，但已不再被广泛使用。它是为了兼容 4.4BSD 提供的。

# Less

## 目录
Less 软件包包含 `less` 程序

### 描述
`less` 程序是一个文件分页器（或文本查看器）。它以可滚动的方式显示文件内容。

Less 是常用分页器“more”的改进版。Less 向上滚动功能，并且在启动时不需要读取整个文件，这使得它在读取大文件时更快。

# Groff

## 目录
Groff 软件包包含 `addftinfo`, `afmtdit`, `eqn`, `godvi`, `groff`, `grog`, `grohtml`, `groj4`, `grops`, `groty`。`hpftdit`, `indxbib`, `lbbib`, `lookbib`, `neqn`, `nroff`, `pfbtops`, `pic`, `psbb`, `refer`, `soelim`, `tbl`, `tfmtdit` 以及 `troff` 程序。

### 描述

#### addftinfo
`addftinfo` 读取 `troff` 字体文件并添加 `groff` 系统所需的字体信息。

#### afmtdit
`afmtdit` 创建供 `groff` 和 `grops` 使用的字体文件。

#### eqn
`eqn` 将嵌入 `troff` 输入文件的方程描述编译成 `troff` 可理解的命令。

#### godvi
`godvi` 是 `groff` 的驱动程序，产生 TeX dvi 格式。

#### groff
`groff` 是 `groff` 文档格式系统的前端。通常它会运行 `troff` 程序以及适用于选择设备的后处理器。

#### grog
`grog` 读取文件并猜测打印文件需要哪些 `groff` 选项 `-e`, `-man`, `-me`, `-mm`, `-ms`, `-p` 和 `-t`，并在标准输出打印包含这些选项的 `groff` 命令。

#### grohtml
`grohtml` 将 GNU `troff` 的输出转换为 html

#### grol4
`grol4` 是 `groff` 的驱动程序，可产生 PCL5 格式的输出，适用于 HP Laserjet 4 打印机。

#### grops
`grops` 将 GNU `troff` 的输出转换为 PostScript。

#### grotty
`grotty` 将 GNU `troff` 的输出转换为适用于打字机类设备的格式。

#### hpftodit
`hpftodit` 从 HP 标记的字体度文件创建一个供 `groff -Tlj4` 使用的字体文件。

#### indxbbib
`indxbbib` 为指定文件的书目数据库创建反向索引，供 `refer`、`lookbib` 和 `lkbib` 使用。

#### lkbibib
`lkbibib` 在书目数据库中搜索包含指定键的参考文献，并将找到的任何参考文献打印到标准输出。

#### lookbib
`lookbib` 在标准错误上上打印提示符（除非标准输入不是终端），从标准输入读取包含一组关键词的行，在指定文件的书目数据库中搜索包含这些关键词的参考文献，将找到的任何参考文献打印到标准输出，并重复此过程直到输入结束。

#### neqn
目前尚不知道 `neqn` 是什么以及它的作用。

#### nroff
`nroff` 脚本使用 `groff` 模拟 `nroff` 命令。

#### pfbtops
`pfbtops` 将 `.pfb` 格式的 PostScript 字体转换为 ASCII。

#### pic
`pic` 将嵌入 `troff` 或 TeX 输入文件中的图片描述编译为 TeX 或 `troff` 理解的命令。

#### psbb
`psbb` 读取一个符合文档结构规范的 PostScript 文档，并寻找 `%%%BoundingBox` 注释。

#### refer
`refer` 将文件内容复制到标准输出，但 `[` 和 `.` `]` 之间的行被解释为引用，`.R1` 和 `.R2` 之间的行被解释为关于如何处理引用的命令。

#### soelim
`soelim` 读取文件并将形式为 `.so file` 的行替换为文件的内容。

#### tbl
`tbl` 将嵌入 `troff` 输入文件中的表格描述编译为 `troff` 理解的命令。

#### tfmtodit
`tfmtodit` 创建一个供 `groff -Tdvi` 使用的字体文件

#### troff
`troff` 与 Unix `troff` 高度兼容。通常应该使用 `groff` 命令来调用它，该命令将以适当的顺序和选项运行预处理器和后处理器。

# Linux From Scratch

## Man

### 目录
Man 包包含 `man`、`apropos`、`whatis` 和 `makewathis` 程序。

### 描述

#### man
`man` 格式化并显示在线手册页。

#### apropos
`apropos` 在一组包含系统命令简短描述的数据库文件中搜索关键词，并将结果显示到标准输出。

#### whatis
`whatis` 在一组包含系统命令简短描述的数据库文件中搜索关键词，并将结果显示到标准输出。只显示完整的单词匹配项。

#### makewathis
`makewathis` 读取 `manpath` 指定部分中包含的所有手册页，或 `catpath` 指定部分中包含的预先格式化页面。对于每个页面，它会在 `whatis` 数据库中写入一行；每行由页面名称和简短描述组成，用破折号分隔。描述是通过手册页中 NAME 部分的内容提取的。
