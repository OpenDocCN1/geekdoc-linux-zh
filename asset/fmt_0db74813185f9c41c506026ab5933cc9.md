## 第 6 章：读取和写入简单记录

现在我们已经有了基础定义，准备好编写程序了。

### 写入记录

此程序将简单一些硬编码的记录写入磁盘。它将：
- 打开文件
- 写入三条记录
- 关闭文件

将以下代码输入名为 `write-records.s` 的文件中：

```assembly
.include "linux.s"
.include "record-def.s"
.section .data
# 我们要写入的常量数据
# 每个字段都填充到正确的长度（即 0 字节）。
# .rept 用于填充每个字段。
# .rept 告诉汇编器重复指定的次数。
# 这是在这个程序中用于填充每个字段结尾的字符。
record1:
.asc "Fredrick"
.rept 31 .db 0
.asc "Bartlett"
.rept 32 .db 0
.asc "Prairie"
.rept 232 .db 0
.byte 25
record2:
.asc "Marilyn"
.rept 33 .db 0
.asc "Taylor"
.rept 32 .db 0
.asc "Tulsa"
.rept 232 .db 0
.byte 26
record3:
.asc "Derrick"
.rept 32 .db 0
.asc "Johann"
.rept 33 .db 0
.asc "Chicago"
.rept 232 .db 0
.byte 27
file_name:
.asc "test.dat"
.byte 0
equ ST_FILE_DESCRIPTOR, -4
.glob _start
_start:
# 将栈指针复制到 %ebp
movl %esp, %ebp
# 为文件描述符分配空间
subl $4, %esp
## 打开文件
movl $SYS_OPEN, %eax
movl $file_name, %ebx
movl $001, %ecx # 这表示如果不存在则创建，并以写入模式打开
movl $666, %edx
int $LINUX_SYSCALL
# 保存文件描述符
movl %eax, ST_FILE_DESCRIPTOR(ebp)
# 写入第一条记录
pushl ST_FILE_DESCRIPTOR(ebp)
pushl $record1
call write_record
addl $8, %esp
# 写入第二条记录
pushl ST_FILE_DESCRIPTOR(ebp)
pushl $record2
call write_record
addl $8, %esp
# 写入第三条记录
pushl ST_FILE_DESCRIPTOR(ebp)
pushl $record3
call write_record
addl $8, %esp
# 关闭文件描述符
movl $SYS_CLOSE, %eax
movl ST_FILE_DESCRIPTOR(ebp), %ebx
int $LINUX_SYSCALL
# 退出程序
movl $SYS_EXIT, %eax
movl $0, %ebx
int $LINUX_SYSCALL
```

你可能已经注意到了以下几行：

```
.include "linux.s"
include "record-def.s"
```

这些语句会导致给定的文件基本上直接粘贴到代码中。对于函数，你不需要这样做，因为链接器可以处理通过 `.globl` 导出的函数组合。然而，在另一个文件中定义的常量确实需要用这样进行导入。

此外，你可能已经注意到使用了一个新的汇编器指令 `.rept`。该指令会将 `.rept` 和 `.end` 指令之间的文件内容重复，重复次数为 `.rept` 之后的数字。这通常用于我们之前使用它的方式——用于在 `.data` 段中填充值。在我们的案例中，我们向每个字段的末尾添加空字符，直到它们达到定义的长度。

要编译应用程序，请运行命令：

```
as write-records.s -o write-record.o
as write-record.s -o write-record.o
ld write-record.o write-records.o -o write-records
```

在这里，我们分别汇编两个文件，然后使用链接器将它们组合在一起。运行程序，只需输入以下内容：

```
./write-records
```

这将创建一个名为 `test.dat` 的文件，其中包含记录。然而，由于它们包含非打印字符，具体说是空字符，文本编辑器可能无法查看它们。因此，我们需要下一个程序来我们读取它们。

### 读取记录

现在我们将考虑读取记录的过程。在程序程序中，我们将读取每个记录并显示每个记录中列出的名字。

由于每个人的名字长度不同，我们需要一个函数来计算我们想要写入的字符数量。由于我们为每个字段都填充了空字符，我们可以简单地一直计数，直到遇到空字符。注意，这意味着我们的每个记录必须至少包含一个空字符。

这里是代码。将其放在名为 `count-chars.s` 的文件中：

```
#PURPOSE: 计数字符直到遇到空字节。
#
#INPUT: 字符字符串的地址
#
#OUTPUT: 将计数结果返回在 %eax 中
#
#PROCESS:
# 使用的寄存器:
# %ecx - 字符计数
# %al - 当前字符
# %edx - 当前字符地址
.type count_chars, @function
.global count_chars
# 这是我们的一个参数在栈上的位置
.equ ST_STRING_START_ADDRESS, 8
count_chars:
push %ebp
movl %esp, %ebp
#计数器从零开始
movl $0, %ecx
```
