
# 挤出竖框

你现在已经有了竖框。你已经安装了窗头，但窗户下方还需要部分墙体来填充。你需要复制窗头并更改它们的挤出数量：

1. 选择 `Layer:Wall-viz-sill` 对象。你可以使用“选择对象”对话框来操作，也可以简单地点击建筑后方的一个窗头。
2. 在选中“选择移动”工具的情况下，按住 `Shift` 点击变换手柄组件（`Transform gizmo`）的蓝色 Z 箭头并向下拖动选中的窗头，以创建窗头的克隆，大致将其放置在地面水平。
3. 在“克隆选项”（`Clone Options`）对话框中，点击“复制”（`Copy`）按钮启用它。你可以保留 `Layer:Wall-viz-sill` 名称。点击“确定”（`OK`）接受克隆。
4. 点击“绝对/偏移模式变换类型输入”工具切换到绝对模式；然后右键点击 Z 旋钮，将坐标显示中的 Z 值改为 0。
5. 将“修改”选项卡中“参数”的“数量”（`Amount`）值改为 2’。

由于由于两组墙体和垂直竖框在 AutoCAD 中是分开绘制的，以便你可以在 VIZ 中为它们每一个应用不同的材质；但由于所有对象的高度相同，你对所有它们都应用了单一的修改器。

如果你决定需要为每组墙分配独立的挤出修改器，可以点击其中一个墙体，选择堆栈中的*斜体*修改器，然后点击修改器堆栈中的“制作唯一”（`Make Unique`）按钮。

## 斜体和粗体修改器

在堆栈中以*斜体*显示的修改器是实例化的。在堆栈中以**粗体**显示的修改器是应用于已实例化对象上的修改器。

# 挤出门头

现在继续处理门头和窗周围的墙体：

1. 再次打开“选择对象”对话框。然后选择 `Layer:Wall-viz-ext-hdr`、`Layer:Wall-nviz-int-hdr` 和 `Layer:Wall-viz-sill`。
2. 再次从修改器列表中选择“挤出”（`Extrude`）；然后将“参数”展开栏中的“数量”（`Amount`）值改为 1' 6'。
3. 点击“选择移动”工具；然后点击坐标显示旁边的“绝对/偏移模式变换类型输入”工具，使其处于偏移模式。你会看到坐标显示中出现了数值。

| X 0'0.0' | Y 0'0.0' | Z 0'0.0' |
| :--- | :--- | :--- |
| 偏移模式变换类型输入 | | |

4. 在坐标显示中，将 Z 值更改为 8'0'。所有门头都移动到了门上方的位置。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_839_0.png)

你可能注意到，在第 3 步中，只有当你从“绝对/偏移模式变换类型输入”工具中选择偏移模式模式时，坐标显示才会显示数值。这是因为你选择了多个对象。对于多选，绝对模式没有意义，因为多个对象在场景中可以处于不同的位置。

此外，与墙体一样，你使用单一实例挤出修改器来将更改扩展到三个对象。
