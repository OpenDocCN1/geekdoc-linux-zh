
# 蒸汽冷凝器
`蒸汽冷凝器`用于冷凝的热转换器。蒸汽具有独特的汽化潜热，与氨相当。蒸汽的比热相对较高，在实际温度下它可以携带比其他用途更多的热能。参见锅炉；波义定律；查尔斯定律；道顿定律；电；发电机；蒸汽加热；蒸汽涡轮机；热力学循环；动态参数。

该同步发电机由两部分组成：定子（固定）和转子（旋转）。定子由一个固定在框架上的叠层圆柱体和一个和一个由绝缘叠片制成的铁芯安装在轴上组成。铁芯在轴线上开有槽，在槽内放置了场绕组。定子经过电气绝缘。转子由一个锻造实心钢轴组成。绕组沿转子轴线方向绕周缘绕制，形成了转子体。

转子旋转。带有绕组的磁场成对排列（始终为偶数以减少谐波对磁场的影响）并连接到电刷。旋转磁场在定子中感应出电流。参见电磁感应。

# 产蒸汽炉
使用封闭空间进行燃料燃烧。封闭结构包含燃烧产物，并能够承受所使用的温度和压力。设计和几何形状根据热传递、燃料类型和点火方法进行调整，以使燃烧尽可能高效和合适。水热表面吸收出口气体的温度并促进蒸汽的产生。

# 产蒸汽装置
该装置由调节和利用热源所需的部件、装置和功能组成，用于产生高达 5000 psi（兆帕）和 1100 F（600 °C）的蒸汽，通常简称为锅炉。

产蒸汽装置的基本元件包括：(1) 用于燃烧燃料的炉炉或用于裂变的核反应堆，或加热器；(2) 向锅炉供水、将水蒸发成蒸汽，然后过热到所需温度的压力容器；以及(3) 在许多设计中包含的辐射单元或热发生器。任何功能都需要各种组件，这些组件可能采用不同的材料，以确保产蒸汽过程中的耐用性、实用性和效率。这些组件的选择、设计、操作和维护构成了一个复杂的过程。

# 蒸汽加热
加热系统使用从锅炉产生的蒸汽通过管道输送到换热器、散热器、风箱、辐射单元或风扇加热，并将冷凝水返回锅炉。此类系统的运行压力通常不超过 1,000 千帕，在许多设计中，冷凝蒸汽由于回水管道中的静水头通过重力返回锅炉。利用可用的和安全控制装置，这些系统可以设计为自动运行且维护极少。
