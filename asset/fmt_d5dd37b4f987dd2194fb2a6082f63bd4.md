
如果 `RANDOM_NUMBER` 变量的值被赋值为 24，那么上一个命令的结果就是 2（此 `RN_LENGTH` 变量指向值 2），表示有两个有两个数字。我们还需要 `UPPER_LIMIT` 值的长度，并将两者的差值用于决定伪随机数输出时使用多少个零。仔细查看列表 21.4 中的代码，你将在其中找到 `in_range_fixed_length_random_number` 函数。

```bash
function in_range_fixed_length_random_number
{
  # 创建小于或等于
  # $UPPER_LIMIT 值的伪随机数，该值由用户定义。
  # 此函数还将向输出填充前导
  # 零，以保持位数一致。

  RANDOM_NUMBER=$((RANDOM % $UPPER_LIMIT + 1))

  # 查找每个字符字符串的长度

  RN_LENGTH=$(echo ${#RANDOM_NUMBER})
  UL_LENGTH=$(echo ${#UPPER_LIMIT})

  # 计算字符串长度的差

  (( LENGTH_DIFF = UL_LENGTH - RN_LENGTH ))
  # 为 $RANDOM_NUMBER 值填充前导零
  # 以保持位数一致。

  case $LENGTH_DIFF in
  0) echo $RANDOM_NUMBER
      ;;
  1) echo 0$RANDOM_NUMBER
      ;;
  2) echo 00$RANDOM_NUMBER
      ;;
  3) echo 000$RANDOM_NUMBER
      ;;
  4) echo 0000$RANDOM_NUMBER
      ;;
  5) echo 00000$RANDOM_NUMBER
      ;;
  *) echo $RANDOM_NUMBER
      ;;
  esac
}
```

**列表 21.4** `in_range_fixed_length_random_number` 函数。

在列表 21.4 中，我们使用了列表 21.3 中的相同技术来设置上限以创建数字，但我们增加了代码来查找 `UPPER_LIMIT` 和 `RANDOM_NUMBER` 值的字符串长度。通过知道两个字符串的长度，我们将随机长度减去上限长度，并在 `case` 语句中使用该差值在输出中添加正确数量的零。

由于这是一个函数，我们需要假设 `UPPER_LIMIT` 已定义，且 `RANDOM` 环境变量已经在调用它的 shell 脚本的主体中初始化。结果输出是一个固定长度的伪随机数，如果输出字符串长度小于上限长度，则会填充前导零。示例输出如列表 21.5 所示，`UPPER_LIMIT` 值为 99。

## 伪随机数生成

### 为什么要填充零？

给数字填充零的一种更简单、更整洁的方法是使用 `typeset` 命令固定长度。以下命令适用于任何长度：

```bash
typeset -Z FIXED_LENGTH
```

在列表 21.6 中，我们使用了 `typeset` 命令来固定长度。在列表 21.7 示例中，我们使用了 `typeset` 命令。结果是 00025，显示长度为五位。

```bash
function in_range_fixed_length_random_number
{
  # 创建小于或等于
  # $UPPER_LIMIT 值的伪随机数，该值由用户定义。
  # 此函数还将向输出填充前导
  # 零，以保持位数一致。

  # 找到上限字符串的长度

  UL_LENGTH=$(echo ${#UPPER_LIMIT})

  # 使用 typeset 命令固定长度
  typeset -Z$UL_LENGTH RANDOM_NUMBER=$((RANDOM % $UPPER_LIMIT + 1))

  # 返回值
  echo $RANDOM_NUMBER
}
```

**在随机数中使用 typeset。**

如你在列表 21 中所示，我们通过 `typeset` 消除了固定长度的复杂性。我们只需要知道 `UPPER_LIMIT` 的长度。例如，如果上限是 9999，长度就是 4。
