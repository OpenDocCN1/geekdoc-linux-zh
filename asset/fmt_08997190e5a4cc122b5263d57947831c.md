
`S` ∩ `T` = `S` ∩ `T`

`S`(`T` ∪ `U`) = (`S` ∩ `T`) (`S` ∩ `U`)

`S` ∪ `U` ∪ `T` = `S` ∪ `U` ∪ `T`

`S`(`T` ∪ `U`) = (`S` ∪ `T`) (`S` ∩ `U`)

`S`(`U` ∩ `T`) = (`S` ∪ `U`) (`S` ∩ `T`)

`T`(`U` ∩ `S`) = (`T` ∪ `U`) (`T` ∩ `S`)

如果 `O` 表示空集，`I` 是所考虑的所有元素的集合，那么等式 (4) 所示的定律为：

```
O ∩ S = O  O ∪ S = S

I ∩ S = S  I ∪ S = I
```

这些定律是基础性的。所有的减法代数都可以从它们推导出来。在布尔代数中观察到，共同定律下的运算组合是有效的，而不仅仅是上述指定的定律。某些定律适用于所有命题或其组合，而这些命题是复杂的。参见逻辑。

布尔强调了布尔代数与普通代数之间的代数关系。如果 `S` 被视为顺序规则，而 `S'` 对应 `1 - S`，上述内容通过许多方式进行了说明。然而，第一个是由马歇尔·亨廷顿（Marshall Huntington）清楚展示的。具体来说，给出了 `S` ∩ `T'` 的第一个例子。利用 `S` ∩ `T'` 的普通 `Sn` 类似于使用 `St`。布尔代数指的是布尔环，其中所有元素都满足 `x² = x`。

在 H. A. Newman 开发了一种现代泛化方法，其中包含了布尔代数和布尔环。这种泛化基于等式 (5) 和 (6) 所示的定律。从这些定律可以推导出交换律和结合律 (1) 和 (2)。

```
a(b+c) = ab+ac  ab+bc = bc

a1+a = a  a+0 = a  a\a' = 1
```
