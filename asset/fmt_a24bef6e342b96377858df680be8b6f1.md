
| `\l` | 在替换模式中，导致下一个字符变为大写或小写 |

| `\L` | 在替换模式中，导致替换模式的剩余部分（或扫描到 `\e` 或 `\E`）变为大写或小写 |

| `\e` 或 `\E` | 在替换模式中，终止 `\L` 的操作 |

| `~` | 匹配上一次正则表达式搜索的模式 |

注意：元字符的使用在不同的上下文中可能有所不同。`shell` 使用元字符进行文件名扩展；然而，`shell` 对元字符的解释与工具和文本编辑器的解释略有不同。（`shell` 是 UNIX 命令处理器的名称。有几个常见的 `shell` 程序版本。最常见的是 `sh`、`csh`、`ksh` 和 `bash`。关于此主题的广泛讨论，请参考 *UNIX Unleashed, System Administrator, Edition* 的第二部分“UNIX Shells）。这可能是混乱的来源，特别是对于新学者。更糟糕的是，不同的 UNIX 版本之间元字符的实现存在差异。

提示：所有正则表达式匹配都限于单行。也就是说，不允许从一行末尾到下一行开头的“跨行”匹配。

提示：所有正则表达式搜索都是区分大小写的。你必须显式地使用元字符的功能来执行区分大小写的搜索。例如，如果你想对单词 "general" 的初始 "g" 执行区分大小写的搜索，你应该使用搜索字符串 `/\[Gg\]eneral/`。

**提示：** 正则表达式通常由正斜杠（`/`）字符分隔。然而，可以使用 `"`、`|` 或 `#` 以外的任何非字母数字字符。当斜杠是搜索字符串中的字符之一且你不想转义斜杠时，这种方法特别好用。

## 使用正则表达式进行全局搜索和替换

你已经看到过如何在 `vi` 中通过使用 `/` 和 `?` 命令进行搜索。正如在介绍这些命令时提到的，

你也可以将这些命令与正则表达式以及字面量字符串结合使用。

使用正则表达式执行搜索和替换操作有两种方法。这两种方法都可以在 `ex` 命令行执行，

并且都是你已经在“搜索与替换”章节中接触过的命令的扩展。

一种方法是使用 `substitute`（替换）命令；另一种方法是通过使用 `global`（全局）命令。

### 使用正则表达式配合 substitute 命令

当你想要进行全局替换时，可以使用带有行地址和正则表达式的 `substitute` 命令。一种常用的形式是使用使用 `%` 地址符号来引用文件中的所有行。此类命令的一般形式如下：

`:address s/searchexpression/replaceexpression/options`

（上例中 `address` 之后的空格是为了清晰起见，可选的。） `options` 指表 3.17 所示的选项之一。

**表 3.17. Substitute 选项。**

| 命令 | 结果 |

| :--- | :--- |

| `g` | 使替换全局。（如果没有此选项，替换仅发生在行的第一次出现处；如果有此选项，行中的所有出现处都将被替换。不要将此选项（位于命令最右侧的替换命令）与 `global` 命令本身（位于命令行左侧靠近冒号的地方）混淆。） |

| `c` | 确认.\*.\* `vi` 显示每个找到的匹配行，并用 `^` 符号指示要替换的文本，如下所示：`this is some text ^^^` |

你必须输入 `y` 来执行替换；任何其他响应都会导致不替换。

（注意：某些版本的 `vi` 处理此方式略有不同，使用文本高亮来指示匹配的模式，并在每一步允许额外的选择。）

你可以将这两个选项合并到一个 `substitute` 命令中。

### 使用正则表达式配合 global 命令

当 `global` 命令与 `substitute` 命令结合时，它变得非常强大。使用这种组合的一种有趣方法是使用 `global` 命令选择某些行，然后使用 `substitute` 命令对这些行进行与导致该行被中的文本不直接相关的更改。

实际上，`global` 命令的作用是提供了一个两步编辑功能。首先，使用几种不同的技术（行地址和模式匹配）选择一组行。然后对所选的行使用另一个命令。当 `global` 命令在本章中首次引入时，它是以简单的方式与其他命令结合使用的，用于显示或删除文本。事实上，`global` 命令可以与几乎任何其他命令配合使用。（确实，已经发明了一些使用 `global` 命令的创意技术。其中一些在表 3.18 的示例中。）

展示 `substitute` 命令如何工作以及 `global` 和 `substitute` 命令如何配合使用的最佳方法是给出示例。表 3.18 显示了可以执行的一些搜索和替换操作类型。（注意：为了清晰，使用加粗的小写字母 `b` 来表示单个空格。）

**表 3.18. 使用 `s` 和 `g` 命令进行搜索和替换的示例。**

| 命令 | 结果 |

| :--- | :--- |

| `:%s/ex/vi/g` | 将缓冲区中所有的 `ex` 替换为 `vi`。 |

| `:.,$s/ex/vi/c` | 从当前行到缓冲区结束的每行中，将第一个 `ex` 替换为 `vi`，并确认每次替换。 |

| `:%s/\\<author\\>/contractor/g` | 将缓冲区中每个全单词 `author` 替换为 `contractor`；注意包含 `author` 子字符串的文本对象（如 `authority`）将不会被替换。 |

| `:g/editor/s/line/full-screen/g` | 在所有包含模式 `editor` 的行中，将所有的 `line` 替换为 `full-screen`。 |

| `:g/editor/s//word-processor/g` | 将所有的 `editor` 替换为 `word-processor`；注意，当第二个搜索字符串缺失时，将使用第一个搜索字符串；在这种情况下，即字符串 `editor`。 |

| `:%s/\bb\*/\b/g` | 将一个或多个空格替换为单个空格（注意：`b` 代表单个空格）。 |

| `:%s/\[:.\]\bb\*\\(\[a-z\])/\\.\bb\1/g` | 搜索所有冒号或句号后跟一个或多个空格和小写字母的情况；替换为句号、两个空格以及字母的大写形式。 |

| `:g/^$/d` | 删除所有空行（只有开头紧跟末尾的行）。 |

| `:g/^$/m` | 反转所有空行。 |

| `:g/Complete/s/$/done` | 在包含字符串 `Complete` 的所有行末尾追加 `done` |

## 文件操作

保存文件的基本命令在“启动与退出”章节中介绍。本节将显示如何用于多个文件。

### 将更改保存到文件

`w` 命令用于将缓冲区写入当前文件。如果文件自上次保存以来已更改，则不允许 `:e` 命令。相反，`vi` 会给出关于未保存文件的通常警告。

`:e!` 

**Revert（还原）：** `edit` 命令的这种特殊用法强制加载当前文件的最后保存版本进行编辑。这具有恢复到最后保存版本的效果，丢弃你从那以后进行的所有编辑。（如果你省略了感叹号，实际上你是在告诉 `vi` 开始编辑当前文件。如果还没有更改，`vi` 将顺从；然而，这是一个没用的函数。如果有更改，`vi` 将执行其常规程序，警告你有“未写入（no write）等”。因此，该命令唯一的有效版本是带感叹号的。）

### 编辑不同的文件

`:e filename` 开始编辑 `filename` 文件。如果文件不存在，则启动新文件并将 `filename` 变为当前文件。（也就是说，随后的 `:w` 命令将写入 `filename`。）

如果当前文件自上次保存以来已更改，则不允许 `:e filename` 命令。相反，`vi` 会给出关于未保存文件的通常警告，可能如下：文件更改后未写入。`edit!` 命令将强制执行。

再次，你可以使用 `:e! filename` “强制执行”。

`:e + filename` 编辑 `filename` 文件；将光标放在文件末尾。

`:e + number filename` 编辑 `filename` 文件；将光标放在第 `number` 行。

`:address r filename` `read` 命令允许将另一个文件的完整内容导入缓冲区。如果存在可选的地址，`filename` 文件的行将紧跟在地址所选行之后导入。如果省略了地址，行将紧跟在光标所在的行之后导入。地址可以是行号（用 `0` 表示文件开头）、`$` 表示文件最后一行，或搜索模式。

## 编辑多个文件

### `:n`-- 下一个文件

当启动 `vi` 时，命令行上可以列出多个文件。例如，要编辑三个文件 `art1*`、`art2*` 和 `art3`，你需要输入以下 `shell` 命令：

```
$vi art1 art2 art3
```

`vi` 会像照常一样加载文件 `art1`，你可以开始编辑它。保存文件后，你可以使用 `:n` 命令进入下一个文件。如果你在保存当前文件之前尝试使用下一个命令，你将收到通常的警告，你可以按照通常的方式覆盖它（是的，你猜对了——使用 `n!`）。

### 在两个文件之间交替切换
