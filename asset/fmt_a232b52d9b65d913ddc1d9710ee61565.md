现在我们准备好对磁盘进行分区。这些准备工作包括计算每个道包含的内容，然后估计在分区中需要的道数。对于我们的示例磁盘，我们知道每个道由轨道上的 108 个扇区组成，11 条轨道组成一个道。从我们在 `dmesg` 中看到的信息，我们知道每个块是 512 字节。在这里，如果我们想要分区为 1 GB，我们执行以下方法计算所需的块：

```
1 gigabyte = 1048576 kilobytes
  One cylinder = 108 sectors * 11 heads = 1188 blocks
  1188 blocks = 594 kilobytes
  1048576 / 594 = 1765 cylinders
  1765 * 1188 = 2096820 blocks
```

显然，1 GB 标记位于磁盘中间存在舍入误差，并且我们需要将每个分区保持在道边界上。1,765 道足够了。1,765 转换为 2,096,820 个块。

我们想要创建的新分区大小需要为 64 MB。使用相同的方法，我们发现交换空间需要 130,680 个块长。最后一个分区需要填充磁盘的剩余部分。已知我们有一个 2 GB 的磁盘、一个1 GB 的交换池和一个 64 MB 的交换分区，这应该为 `/usr/local` 留出约 960 MB。

在创建最后一个分区之前，我们需要处理一些传统的分区 c。这通常是[那个]跨越整个磁盘的分区。在创建此分区之前，我们需要做一些简单的数学计算。

108 个柱面 x 11 个磁头 x 3508 个柱面 = 4167504 个块

注意，我们计算出的块数与磁盘上实际的数量不符。这个数字是根据我们在提供磁盘类型信息时输入的信息计算的。

保持一致性非常重要。

由于 c 分区跨越整个磁盘，我们将起始柱面指定为 0。创建此分区的操作应该是这样的：

```
partition> c
partition c - starting cyl 0, # blocks 0 (0/0/0)
Enterter new starting cyl [0]: 0
Enter new # blocks [0, 0/0]: 4167504
partition>
```

我们只剩下一个分区留给 /usr/local。因为我们想填充磁盘的剩余部分，我们需要进行最后一次计算来确定剩余多少块。

这是通过取分区 c 的大小（整个磁盘）并减去现有分区的大小来实现。对于我们的示例，结果如下：

```
4167504 - 2096820 - 130680 = 1940004 remaining blocks
```
