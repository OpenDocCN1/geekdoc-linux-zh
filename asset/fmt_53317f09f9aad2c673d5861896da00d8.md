### 6.3.4 防止用户修改系统设置

| 危险等级 ☠ ☠ ☠ ☠ |

<Directory />

### 6.3.5 控制 Apache 可访问的目录

| 危险等级 💀💀💀 |

默认情况下，Apache 会访问任何它拥有权限的目录。虽然 Apache 应该在唯一的 UID 和 GID 下运行，但你仍希望它访问任何具有全局读权限（004）的文件。你可以禁止 Apache 访问版本控制系统使用的 RCS 目录。以下是 `httpd.conf` 中的典型指令：

```
<Directory />
Order deny,allow
Deny from all
</Directory>

<Directory /home/**/public_html/RCS>
Order deny,allow
Deny from all
</Directory>

<Directory /home/**/public_html>
Order deny,allow
Allow from all
</Directory>

<Directory /httpd/html/RCS>
Order deny,allow
Deny from all
</Directory>

<Directory /httpd/html>
Order deny,allow
Allow from all
</Directory>
```

killall -HUP httpd
