
一个在精神上类似于寻找图的最小生成树（`minimal connector`）的问题，是寻找图中两点之间权重最小的路径。如果我们将权重视为距离、时间或成本，那么对应的问题就是寻找两点之间最短、最快或最便宜的路线。然而，我们将继续使用距离或长度来讨论。因此，在加权图 `⟨G, μ⟩` 中，路径

$$ v_1 \to v_2 \to ... \to v_{n-1} \to v_n \quad\quad (P) $$

的*长度*是总和 `μ(v_1,v_2) + μ(v_2,v_3) + ... + μ(v_{n-1},v_n)`。我们用 `μ(P)` 表示这个总和。两个顶点 `x` 和 `y` 之间的*距离*是如果存在从 `x` 到 `y` 的最短路径，则为该路径的长度，否则为 `∞`。我们令 `d(x,y)` 表示从 `x` 到 `y` 的距离。

最短距离问题比最小生成树问题要复杂得多，原因如下。请注意，在执行 `Kruskal` 算法时，我们不需要向前看。只要我们小心不要创建任何闭合路径，我们就注定会创建一个权重最小的生成树。最短距离问题则截然不同。这一点可以从图 10.18 中给出的图的简单情况中看出。

可以看出，`a → b → c` 是从 `a` 到 `c` 的最短路径，尽管 `ad` 是最短的边，但它并未包含在此路径中。从 `a` 出发，选择边 `ad` 将是一个错误。因此，我们即将描述的用于寻找从顶点 `u` 到顶点 `v` 的最短路径的算法比 `Kruskal` 算法更复杂。它涉及检查从 `u` 到 `v` 的所有可能路径。我们在描述算法后附上一个例子。你可能会发现将两者结合起来考虑会有帮助。

我们首先概述所用的方法。它涉及分配给顶点的临时标签和永久标签。与顶点 `y` 相关的临时标签具有形式 `(x, l(y))`，其中 `x` 是 `*` 或除 `y` 以外的顶点，且 `l(y)` 是一个正数或 `∞`。从每个顶点的临时标签开始，在每个阶段，一个临时标签被变为永久，这通过将圆括号替换为方括号来表示。

当算法终止时，`l(v)` 是从 `u` 到 `v` 的最短路径长度。此外，`u = y_1 → y_2 → ... → y_n = v` 是一条具有此长度的路径，其中对于 `2 ≤ r ≤ n`，分配给顶点 `y_r` 的永久标签是 `[y_{r-1}, l(y_r)]`。

### 戴克斯特拉最短路径算法*

假设该算法在加权图 `(G, μ)` 上运行，其中 `u` 和 `v` 是顶点。

- 步骤 1. 最初，给每个顶点分配临时标签 `(*, ∞)`，除了起始顶点 `u` 被分配临时标签 `(*, 0)`。
- 步骤 2. 找到一个具有临时标签且 `l(x)` 最小的顶点 `x`，并将其标签变为永久。
- 步骤 3. 如果 `x = v`，停止。（如果 `l(x) = ∞`，则从 `u` 到 `v` 没有路径。）
- 步骤 4. 否则，对于每个具有临时标签（例如 `(w, l(y))`）且通过边 `xy` 与 `x` 连接的顶点 `y`，如果 `l(x) + μ(xy) < l(y)`，则用临时标签 `(x, l(x) + μ(xy))` 替换分配给 `y` 的临时标签。返回步骤 2。

`v ← t ← s ← n ← u`。

## 定理 10.4

将戴克斯特拉算法应用于加权图，以顶点 *u* 为起点，可以确定是否存在从 *u* 到另一顶点 *v* 的路径，并且在存在路径时，产生一条从 *u* 到 *v* 的最小长度路径。
