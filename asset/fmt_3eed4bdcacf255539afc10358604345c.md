## `cGetNextProtocol()` 成员函数（仅限 UNIX）

UNIX 提供了一种遍历协议数据库的方法。这在已知协议部分名称时非常有用。可以进行搜索以定位匹配该部分的全部协议。`cGetNextProtocol()` 成员函数返回下一个协议数据库条目。如果不存在下一个协议条目或未打开数据库进行迭代，则返回 `0`；成功时返回 `1`。

### 列表 5.4 `cGetNextProtocol()` 成员函数

```cpp
char XPCProtocol::cGetNextProtocol()
{
    // 如果迭代标记为真，则检索数据库中的
    // 下一个条目。
    if (iteratorFlag == 1)
    {
        // 如果到达结尾，getproto 返回 NULL，
        // cGetNextProtocol 返回 0。否则
        // 返回 1。
        if ((protocolPtr = getproto()) == NULL)
            return 0;
        else
            return 1;
    }

    // 如果迭代标记不是 TRUE，则返回 0。
    return 0;
}
```

## 5.5 域名与 IP 地址解析

套接字消息被发送到特定的地址位置，这些被称为 IP 地址。由于 IP 地址很难记忆，它们通常通过名称进行别名。这个名称被称为主机名（`host name`）。IP 地址可以有多个别名主机，但它始终有一个官方主机名。在很多情况下，机器的主机名已知，但 IP 地址未知。在其他情况下，IP 地址已知，但主机名未知。UNIX 和 Windows NT 都有系统调用，可以访问主机名数据库以进行 IP 地址和主机名的查找。这些系统调用提供指向 `hostent` 结构体的指针，其成员包含主机名数据库中条目的的字段。`hostent` 结构体分别在 UNIX 操作系统的 `netdb.h` 头文件和 Windows NT 操作系统的 `winsock2.h` 头文件中定义。
