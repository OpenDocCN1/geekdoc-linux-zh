## 在 Bash 中创建交互式菜单

在本教程中，我将向你展示如何在 Bash 中创建一个多选项菜单，以便你的用户可以选择要执行什么操作！

我们将复用上一章节中的部分代码，所以如果你还没有读过，请确保已阅读。

### 功能规划

让我们重新开始，回顾脚本的主要功能：

- 检查当前的磁盘使用情况
- 检查当前的 CPU 使用率
- 检查当前的内存使用情况
- 检查确切的内核版本版本

如果你手头没有脚本，这里是脚本本身：

```bash
#!/bin/bash

##
# BASH菜单脚本用于检查：
### 内存使用
### CPU 负载
### TCP 连接数
### 内核版本
##

server_name=$(hostname)

function memory_check() {
  echo ""
  echo "Memory usage on ${server_name} is:"
  free -h
  echo ""
}

function cpu_check() {
  echo ""
  echo "CPU load on ${server_name} is:"
  echo ""
  uptime
  echo ""
}

function tcp_check() {
  echo ""
  echo "TCP connections on ${server_name}:"
  echo ""
  cat /proc/net/tcp | wc -l
  echo ""
}

function kernel_check() {
    echo "Kernel version on ${server_name} is: "
    echo ""
    echo ""
    uname -r
    echo ""
}

function all_checks() {
    memory_check
    cpu_check
    tcp_check
    kernel_check
}
```

然后我们将构建一个菜单，允许用户选择要执行哪个函数。

当然，你可以根据需要调整函数或添加新函数。

### 添加一些颜色

为了让菜单更加“易读”并且一目了然，我们将添加一些颜色函数。

在脚本的开头添加以下颜色函数：

```bash
### 颜色变量
##
green='\e[32m'
blue='\e[34m'
clear='\e[0m'
### 颜色函数
##
ColorGreen(){
  echo -ne $green$1$clear
}
ColorBlue(){
  echo -ne $blue$1$clear
}
```

你可以如下所示使用颜色函数：

```bash
echo -ne $(ColorBlue 'Some text here')
```

上述代码将输出 `Some text here` 字符串并且将是蓝色的！

### 添加菜单

最后，为了添加菜单，我们将创建一个单独函数，并使用 `case` 语句来处理菜单选项：

```bash
menu() {
  echo -ne "
My First Menu
  ($(ColorGreen '1')) Memory usage
  ($(ColorGreen '2')) CPU load
  ($(ColorGreen '3')) Number of TCP connections
  ($(ColorGreen '4')) Kernel version
  ($(ColorGreen '5')) Check All
  ($(ColorGreen '0')) Exit
  ($(ColorBlue 'Choose an option:')) "
  read a
  case $a in
    1) memory_check; menu;
    2) cpu_check; menu;
    3) tcp_check; menu;
    4) kernel_check; menu;
    5) all_checks; menu;
    0) exit 0;
    *) echo -e "$redWrong option.\$clear"
WrongCommand;
  esac
}
```
