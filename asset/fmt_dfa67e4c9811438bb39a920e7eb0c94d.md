### 操作数

`month` 指定要显示的月份，用十进制整数表示，范围 1（1月）到 12（12月）。默认为当前月份。

`year` 指定显示日历的年份，用十进制整数表示，范围 1 到 9999。默认为当前月份。

## calendar — 提醒服务

### 概要

```
/usr/bin/calendar [-]
```

## 描述

你可以使用 `calendar` 命令作为简单的提醒工具来记录你的预约。`calendar` 命令查询当前目录中名为 `calendar` 的文件，并写入任何包含今天或明天日期的行。`calendar` 识别“月日”格式，例如 Aug. 24、August 24、8/24。在周五和周末，“明天”会延伸到周一。你可以使用 `crontab(1)` 或 `at(1)` 命令定期运行 `calendar`。

当可选参数 存在时，它为所有登录目录下有 `calendar` 文件的用户发送结果邮件。通常，此操作由 UNIX 系统设施完成。如果设置了环境变量 `DATEMASK`，`calendar` 使用其值作为包含格式字符串的文件路径。字符串由转换规范和文本组成，可以通过环境变量 `LANG` 或 `LC_TIME` 的适当设置提供更多语言日期格式；参见 `str(3)` 的转换规范列表。

## 注意

- 不打印以空格开头的行。
- 你的 `calendar` 必须是公共信息才能获得提醒服务。
- `calendar` 的明天不考虑假期。
- 参数仅在本地 `calendar` 文件上有效；`calendar` 设计不在通过 NFS 挂载的 `calendar` 文件上运行。因此，你应该只在存在目录的机器上运行它；在无磁盘客户端运行没有效果。
- `calendar` 不再位于默认 `crontab` 中。由于网络负载，在 `bind(1)` 环境中运行 `passwd` map。然而，如果 `calendar` 的用性大于网络影响，超级用户可以运行 `crontab -e` 编辑 root `crontab`。否则，个人用户可以使用 `crontab -e` 编辑自己的 `crontab` 来调用 `calendar`，并将输出通过邮件发送。

## 示例

如果当前目录下没有 `calendar` 文件，将显示错误消息。

```
castle%
/bin/calendar: /export/home/user/calendar not found
castle%
```

在以下示例中，用户目录下的 `calendar` 文件有三个条目：今天、明天以及几周后。从示例可以看出，只显示当前的日历项目。

```
castle% cat calendar
Sep 15 - Dentist, 4:30
Chiropractic appointment, Sept 16 at 10:00 AM
Monday, September 28. Start new contract
castle%
```

```
castle% calendar
Sep 15 - Dentist, 4:30
Chiropractic appointment, Sept 16 at 10:00 AM
castle%
```

你可以通过环境变量 `DATEMASK` 扩展 `calendar` 命令识别的日期格式。创建一个名为 `datemask` 的模板文件。在该文件中放入以下格式：

```
%B %e of the year %Y
```

`%B` 代表月份全称，`%e` 代表月份中的日期，`%Y` 代表四位年份。

此模板识别以下格式的日期：

March 7th of the year 1999 <Reminder>

当你设置环境变量 `DATEMASK` 指向 `datemask` 时，`calendar` 会识别传统日期以及扩展格式的日期。

```
castle% setenv DATEMASK datemask
castle% calendar
Chiropractic appointment September 16th of the year 1998.
castle%
```

## 环境变量

参见 `environ(5)` 获取影响 `calendar` 执行的环境变量：`LC_CTYPE`, `LC_TIME`, `LC_MESSAGES` 和 `TZ`。

## 退出状态

0 成功。

>0 发生错误。

`/tmp/cal*` `calendar` 使用的临时文件。
