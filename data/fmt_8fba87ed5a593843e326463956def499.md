
## `BEGIN`、`END` 和 `AUTOLOAD` 子程序

Perl 5 允许你定义特殊的子程序，这些子程序会在程序执行的特定时刻被调用。

如果定义了 `BEGIN` 子程序，它会在程序执行开始时调用：

```perl
BEGIN {
 print ("This is the start of the program.\n");
}
```

如果定义了 `END` 子程序，它会在程序终止时调用：

```perl
END {
 print ("This is the last sentence you will read.\n");
}
```

当你的程序尝试调用一个不存在的子程序时，会调用 `AUTOLOAD` 语句：

```perl
AUTOLOAD {
 print ("subroutine $AUTOLOAD not found.\n");
 print ("arguments passed: @_\n");
}
```

## 关联数组（Associative Arrays）

常见的编程任务是同时对几件事进行计数。你当然可以使用标量变量或数组变量来解决这个问题，但这需要一个相当混乱的 `if-elsif` 结构：

```perl
if ($fruit eq "apple") {
 $apple += 1;
} elsif ($letter eq "banana") {
 $banana += 1;
} elsif ($letter eq "cherry") {
 $cherry += 1;
}
...
```

这占用了大量的空间，而且写起来相当无聊。

幸运的是，Perl 提供了一种更简单的方法来解决这类问题——关联数组。接下来的章节将描述关联数组以及如何操作它们。

### 定义关联数组

在普通数组中，你通过指定整数作为索引来访问数组元素：

```perl
@fruits = (9, 23, 11);
$count = $fruits[0]; # $count 现在是 9
```

在关联数组中，你不需要使用像 `0`、`1` 和 `2` 这样的数字来访问数组元素。当你定义关联数组时，你指定想要使用的标量值来访问数组元素。例如，这里是一个简单关联数组的定义：

```perl
%fruits = ("apple", 9,
 "banana", 23,
 "cherry", 11);

$count = $fruits{"apple"}; # $count 现在是 9
```

在这里，标量值 `"apple"` 访问数组 `%fruits` 的第一个元素，`"banana"` 访问第二个元素，`"cherry"` 访问第三个。你可以使用任何你喜欢的标量值作为数组索引，或者使用任何标量值作为数组元素的值：

```perl
%myarray = ("first index", 0,
 98.6, "second value",
 76, "last value");

$value = $myarray{98.6}; # $value 现在是 "second value"
```

关联数组消除了对混乱的 `if-elsif` 结构的需求。例如，给 `%fruits` 数组中的某个元素加 `1`，你只需要执行如下：

```perl
$fruits{$fruit} += 1;
```

更好的是，如果你决定向列表添加其他水果，你不需要添加更多代码，因为前面的语句对新元素同样有效。`%` 告诉 Perl 该变量是一个关联数组。对于标量和数组变量，关联数组名必须以字母开头，后跟一个或多个字母、数字或下划线。

### 访问关联数组

由于关联数组的值是一个标量值，因此它可以用于任何可以使用标量值的地方：

```perl
$fruits = $fruits{"apple"};
```

这会将以下内容发送到标准输出文件：

```
===================================

Here is the text I want to display.

===================================
```

`$~` 是 Perl 使用的特殊标量变量；它告诉 Perl 使用哪种打印格式。

## 在打印格式中显示值

若要在你的打印格式中指定要打印的值，请在打印格式中添加一个值字段。以下是一个使用值字段的打印格式示例：

```
VOWELFORMAT =
==========================================
Number of vowels found in text: a: @<<< e: @<<< i: @<<< o: @<<< u: @<<< a, e, i, o, u
==========================================
```

该行包含五个值字段。每个值字段都包含特殊字符，提供了值如何显示的信息（这些特殊字符在后续章节“选择值格式”中进行了描述）。任何包含值字段的行后面必须紧跟一行，列出要在这些值字段中显示的标量（或包含值的变量）：值字段的数量必须与标量值的数量相等。

## 选择值格式

支持以下值字段格式：

- `@<<<<` 左对齐输出：宽度等于所提供的字符数。
- `@>>>>` 右对齐输出：宽度等于所提供的字符数。
- `@||` 居中输出：宽度等于所提供的字符数。
- `@####` 固定精度数值：`.` 表示小数点的位置。
- `@*` 多行文本。

在所有情况下，在计算字段中的字符数时，都会包含 `@` 字符。例如，字段 `@>>>>` 的宽度为五个字符。同样，字段 `@#####` 的宽度为七个字符：小数点前四位，小数点后二位，以及小数点本身。

## 写入其他输出文件

你还可以使用打印格式和 `write()` 写入其他文件。例如，要使用打印格式 `MYFORMAT` 写入由文件变量 `MYFILE` 代表的文件，请使用以下语句：

```perl
select(MYFILE);
$~ = "MYFORMAT";
write(MYFILE);
```

`select()` 语句指示要写入哪个文件，而 `$~ = "MYFORMAT"` 语句选择了要使用的打印格式。在用 `select()` 选择了输出文件后，它将一直保持选中状态，直到看到另一个 `select()`。这意味着如果你选择了一个标准输出文件以外的输出文件（如 `select(MYFILE)`），在 Perl 看到 `select(STDOUT)` 语句之前，`write()` 的输出不会进入标准输出文件。有两种方法可以确保你不会因此困扰：

- 始终使用 `STDOUT` 作为默认输出文件。如果你更改了输出文件，在完成后将其改回：

    ```perl
    select(MYFILE);
    $~ = "MYFORMAT";
    write(MYFILE);
    select(STDOUT);
    ```

- 在调用 `write()` 之前始终用 `select()` 指定输出文件：

    ```perl
    select(STDOUT);
    $~ = "MYFORMAT";
    write(); # 假设为 STDOUT
    ```

使用哪种方案并不重要，只要你保持一致即可。如果你正在编写一个写入特定输出文件的子程序，可以将当前选中的输出文件保存在临时变量中并在稍后恢复：

```perl
$temp = select(MYFILE); # 选择输出文件
$~ = "MYFORMAT";
write(MYFILE);
select($temp); # 恢复原始选中的输出文件
```
