## 有意思的是 `solid_box::weight()` 重量函数：

### 指令清单51.17 条/Ob0参数的MSVC 2008优化程序

```assembly
?get_weight@solid_box@@QEHXZ PROC ; solid_box:get_weight, CODAT

; this$ = ecx

push esi

mov esi, ecx

push edi

lea ecx, DWORD PTR [esi+12]

call ?get_density@solid_object@@QEHXZ ; solid_object:get_density

mov edi, esi

mov eax, edi

call ?get_volume@box@@QEHXZ ; box::get_volume

pop edi

pop esi

ret

0

?get_weight@solid_box@@QEHXZ ENDP ; solid_box::get_weight
```

函数 `get_weight()`（计算重量）时用了两个方法。在调用 `get_volume()`（计算体积）时，它传递了 `this` 指针。而在调用 `get_density()`（密度）函数时，它传递的地址是“`this`指针+12”。后面这个地址对应的 `solid_box` 字段。因此，`solid_object::get_density()` 认为处理的是 `solid_object` 类，而 `box::get_volume()` 可以正常访问原有数据，如同操作 `box` 类一样。因此我们可以继承了多个类的生成的对象，在内存之中就是一种复合类型的数据。它继承了所有的字段和方法。在这种继承对象调用特定方法时，它传递的是与基类地址相同的 `this` 指针。
