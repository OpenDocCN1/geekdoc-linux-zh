
## 日志配置指令

### `ErrorLog` filename
设置 `httpd` 记录其遇到的错误的文件。如果文件名不以斜杠（`/`）开头，则名称被视为相对于 `ServerRoot`。默认的 `ErrorLog` 是 `/etc/httpd/logs/error_log`，但 `/etc/httpd/logs` 是指向 `/var/log/httpd` 目录的符号链接。因此日志文件位于 `/var/log/httpd` 目录中。典型的错误日志条目包括服务器重启等事件以及任何警告消息，例如以下内容：

```
[Sun Jul 13 14:10:34 2003] [notice] Apache/2.0.45 (Red Hat Linux) configured -- resuming normal operations
[Sun Jul 13 15:47:03 2003] [error] [client 192.168.0.2] File does not exist: /var/www/html/sample.html
```

### `TransferLog` filename
设置 `httpd` 记录所有客户端访问（包括失败的访问）的文件。默认的 `TransferLog` 是 `/var/log/httpd/access_log`。以下示例显示了典型访问在此日志文件中的记录方式：

```
192.168.0.2 - - [13/Jul/2003:15:46:56 -0400] "GET / HTTP/1.1" 200 2898
"" "Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)"
192.168.0.2 - - [13/Jul/2003:15:46:56 -0400] "GET /icons/apache_pb.gif HTTP/1.1" 200 2326 "http://192.168.0.6/" "Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)"
192.168.0.2 - - [13/Jul/2003:15:46:56 -0400] "GET /icons/powered_by.gif HTTP/1.1" 200 581 "http://192.168.0.6/" "Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)"
```

### `LogFormat` formatstring formatname
指定 `TransferLog` 日志条目的格式。此格式也由 `CustomLog` 指令用于以特定格式生成日志。

### `CustomLog` filename formatname
设置自定义日志文件的名称，其中 `httpd` 以 `formatname` 指定的格式记录所有客户端访问（包括失败的访问）（你使用 `LogFormat` 指令定义该格式）。

### `PidFile` filename
设置 `HTTPD` 存储其进程 ID 的文件。默认的 `PidFile` 是 `/var/run/httpd.pid`。你可以使用此信息来终止或重启 HTTP 守护进程。以下示例显示了如何重启 `httpd`：

```
kill -HUP `cat /var/run/httpd.pid`
```

### `MaxClients` num
设置可以同时连接到服务器的客户端数量的限制。默认值是 150。`MaxClients` 的值不能超过 256。

### `LoadModule` module modules/modfile.so
加载作为动态共享对象（DSO）构建的模块。你必须指定模块名称和模块的对象文件。由于模块加载的顺序很重要，你应将这些指令保持为默认配置文件中的显示方式。注意 `mod_ssl` 模块提供了使用安全套接字层（SSL）协议进行加密的支持。

## 资源配置指令

资源配置指令指定网页的位置，以及如何指定各种文件的数据类型。入门时，你可以让指令保持默认设置。以下是 Apache Web 服务器的一些资源配置指令：

### `DocumentRoot` pathname
指定 HTTP 服务器查找网页的目录。在 Red Hat Linux 中，默认的 `DocumentRoot` 是 `/var/www/html`。如果将 HTML 文档放在另一个目录中，请将 `DocumentRoot` 设置为该目录。

### `UserDir` dirname
指定在 URL 中出现用户名时 HTTP 服务器查找网页的用户主目录下的子目录（例如在 URL `http://www.psn.net/~naba` 中，其中包含带波浪线前缀的用户名）。默认情况下，通过将 `dirname` 设置为 `disable` 来关闭 `UserDir` 功能。如果要启用它，可以将其设置为 `public_html`，这意味着用户的网页位于该用户主目录的 `public_html` 子目录中。

### `DirectoryIndex` filename1 filename2 ...
指示当客户端未指定文档时服务器返回的默认文件或文件。默认的 `DirectoryIndex` 是 `index.html`。如果 `httpd` 未找到此文件，它会返回该目录的索引（基本上是该目录的文件的漂亮列表），前提是允许对该目录进行索引。

### `AccessFileName` filename
指定可能出现在每个包含文档的目录中的文件名称，并指示谁有权访问该目录的内容。默认的 `AccessFileName` 是 `.htaccess`。此文件的语法与 Apache 访问控制指令的语法相同，我将在下一节中讨论这些指令。

### `AddType` type/subtype extension
将文件扩展名与 MIME 数据类型（形式为 `type/subtype`，如 `text/plain` 或 `image/gif`）关联。因此，要让服务器将 `.lst` 扩展名的文件视为纯文本文件，请指定以下内容：

```
AddType text/plain .lst
```

默认的 MIME 类型和扩展名列在 `/etc/mime.types` 文件中。

### `AddEncoding` type extension
将编码类型与文件扩展名关联。要让服务器将以 `.gz` 或 `.tgz` 结尾的文件标记为使用 `x-gzip` 编码方法编码（GZIP 编码的标准名称），请指定以下内容：

```
AddEncoding x-gzip gz tgz
```

### `DefaultType` type/subtype
指定服务器在无法从文件扩展名确定类型时应使用的 MIME 类型。如果未指定 `DefaultType`，`HTTPD` 会假定 MIME 类型为 `text/html`。在默认的 `httpd.conf` 文件中，`DefaultType` 指定为 `text/plain`。

### `Redirect` requested-file actual-URL
指定对 `requested-file` 的任何请求都应重定向到 `actual-URL`。

### `Alias` requested-dir actual-dir
指定服务器使用 `actual-dir` 来定位 `requested-dir` 目录中的文件（换句话说，`requested-dir` 是 `actual-dir` 的别名）。要让对 `/icons` 目录的请求转到 `/var/www/icons`，请指定以下内容：

```
Alias /icons/ /var/www/icons/
```

### `ScriptAlias` requested-dir actual-dir
指定用于通用网关接口（CGI）脚本的目录的实际名称。默认配置文件包含此指令：

```
ScriptAlias /cgi-bin/ "/var/www/cgi-bin/"
```

此指令意味着当 Web 浏览器请求脚本，例如 `/cgi-bin/test-cgi` 时，HTTP 服务器运行脚本 `/var/www/cgi-bin/test-cgi`。

### `DefaultIcon` iconfile
指定服务器应为没有图标信息的文件使用的默认图标的位置。默认情况下，`DefaultIcon` 为 `/icons/unknown.gif`。

### `ReadmeName` filename
指定 README 文件的名称，其内容会添加到自动生成的目录列表末尾。默认 `ReadmeName` 为 `README`。

### `HeaderName` filename
指定头文件名称，其内容会添加到自动生成的目录列表前面。默认 `HeaderName` 为 `HEADER`。

### `AddDescription` "file description" filename
指定在目录列表中将文件描述字符串显示在指定文件名旁边。您可以使用通配符，例如 `*.html`，作为文件名。例如，以下指令将以 `.tgz` 结尾的文件描述为 GZIP 压缩的 tar 归档：

```
AddDescription "GZIP compressed tar archive" .tgz
```
