#### 使用 Cloudflare 配置 DNS

```hcl
resource "cloudflare_record" "www-aws" {
  zone_id = "7b02797059c3d78208a18ba3210e36e7"
  name = "iac"
  value = aws_instance.web01.public_ip
  type = "A"
}
```
