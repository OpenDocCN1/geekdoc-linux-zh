
LXQt 和 Openbox 都是成熟的项目，已存在多年。Openbox 无疑是两者中更快的，但阻碍其夺冠的是其较弱的易用性。由于它只是一个基础窗口管理器，用户需要花一些时间组装各种组件并编写自定义配置文件，才能创建可用的桌面环境。虽然这并没有听起来那么费力，但这仍是一项练习，且耗时更长，相比于 LXQt 这类现成的解决方案。

LXQt 是 LXDE 和 Razor-Qt 桌面环境合并的结果。它启动速度非常快，并能明智地利用可用资源。尽管资源消耗仅为同级主流桌面环境的一小部分，但得益于其 Qt 底层支持，LXQt 依然看起来不错；这也是与 Openbox 相比其资源占用略高的原因。

话虽如此，LXQt 在现代机器上会感觉如鱼得水，但它依然足够轻量，足以让一台退役的电脑重新活跃在工作岗位上。

## >> 其他推荐

与其他的评测不同，除了本文介绍的之外，轻量级选项并不缺乏。还有为 OLPC 项目开发的 `Sugar` 桌面环境。虽然它不是一个常规的桌面环境，但如果你正在寻找一个专为教育电脑定制的环境，它是一个极佳的选择。

削减桌面环境臃肿功能的最流行选项之一是简单地运行其轻量级窗口管理器。我们在评测中涵盖了一些，还有很多其他的。有像 `Fluxbox`、`Fvwm`、`FVWM`、`IceWM` 和 `JWM` 这样的堆叠式窗口管理器，它们运行起来都不会给计算机的可用资源带来压力。

同时，命令行高手会欣赏平铺式窗口管理器（如 `Dtile`、`i3` 和 `xmonad`）的高度可定制性。其中许多都可以在主流桌面发行版的软件仓库中找到。然而，它们在易用性方面得分较低，因此并非人人都能接受。

## 救援发行版

Linux 相当具有韧性，但当情况失控时，Shashank Sharma 会使用这些专业发行版之一来拯救安装环境。

### 我们的测试方法……

我们的测试标准与 LXF209 之前的救援综述相比没有太大变化：我们仍然在寻找拥有最广泛工具集合的发行版，这些工具能帮助我们进行各种修复和救援操作。

然而，这并不是我们唯一关注的参数，甚至不是最重要的参数。与工具的数量相比，我们更看重完整发行版的有效性。那些帮助用户在海量工具中顺利穿行并找到合适工具的发行版，比那些仅仅声称捆绑了最多救援工具的发行版评分更高。

由于许多这些工具直接与其磁盘及其容纳的关键数据交互，如果使用不当，它们造成的危害可能大于益处。对于这种专业任务来说，文档因此起着至关重要的作用。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_39_1.png)

Linux 并不缺乏旨在将故障计算机恢复工作的修复工具和实用程序。当然，Linux 内核在设计上（以及由此延伸的 Linux 发行版）具有较高的故障阈值，但硬件故障或操作不当仍可能造成相当大的破坏。

大量的修复工具帮助用户摆脱各种棘手的情况。然而，由于提供的选项数量庞大，普通 Linux 桌面用户可能并不总是能为工作选择最佳工具。此外，虽然你可以在几乎所有主流发行版的官方存储库中找到这些工具，但由于其中许多是基于命令行的（CLI-based），它们不会出现在应用程序菜单中——因此许多新手实际上对它们的存在一无所知。这正是专业救援发行版发挥作用的地方。这些发行版不仅仅是汇集大量修复工具，它们还帮助用户找到适合任务的正确工具。我们过去曾研究过修复和救援发行版（见 LXF209，第 24 页）。但这些专业版本有相当高的淘汰率，以至于除了 Two 之外，上一期综述中的所有其他候选者都已停止维护——包括优胜者 `Rescatux`，因此再次进行一轮测试已迫在眉睫……

### 提供的工具范围

### 百宝箱里有什么？

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_40_0.png)

如果你正在寻找广泛的修复工具和实用程序，`MorpheusArch` 可能会让你失望。该发行版方法非常专注，除了用于恢复文件的 `TestDisk` 及其配套工具 `PhotoRec` 外，基本上没有其他内容。这些工具支持所有主流文件系统，并且可以识别 400 多种格式的文件。除了文件，你还可以使用它们来查找丢失的分区、重建引导扇区、修复 FAT 表、定位备份超级块等。经验丰富的用户可以使用其 Arch 基础来获取其他救援工具。

另一个基于 Arch 的救援发行版 `SystemRescueCd` 是一个稍好的选择。与 `MorpheusArch` 不同，它附带了多种修复和救援工具及实用程序，并支持所有重要的文件系统。它包含多种恢复工具、针对特定文件系统的修复工具，以及包括 `HDT` 在内的几个硬件查询引导镜像。还有 `FSArcher`，它可以帮助保存和恢复分区表或文件系统内容到压缩归档文件。

然后是 `AIO System Rescue Toolkit`，它坦率承认并未附带提供的完整救援工具系列。相反，它仅包含其创造者——一位熟练的技术人员——在现场修复机器时使用过的最实用的工具。除了 `Boot Repair`、`Clonezilla` 和 `TestDisk` 等工具外，还有几个压力测试和基准测试工具。然而，该发行版的主要目标是修复 Windows 机器，与其他 Roundup 中的选项相比，它拥有最庞大的用于此目的的工具集合。

浏览 UBCD 多样化的菜单，找到你感兴趣的工具，并直接启动其精简环境。

压力测试和基准测试实用程序也包含在 `ALT Linux Rescue` 中，该发行版打包了一百多个 CLI 工具，包括几个多功能工具。该发行版还有几个帮助恢复已删除文件和修复 Linux 和 Windows 安装常见问题的实用程序。

`Ultimate Boot CD (UBCD)` 以最大且多样化的工具集合领先。你可以使用该发行版查询并压力测试连接到系统的硬件和外围设备。它也可用于恢复 BIOS 设置以及备份和恢复 CMOS。UBCD 允许你修复引导加载程序，恢复丢失的密码和已删除文件，并在不进入安装系统的情况下调整 Windows 注册表。

### 自定义

### 它们有助于简化管理员访问吗？

`SystemRescueCd` 在自定义界面方面提供的支持并不多。该发行版有一个简单的启动选项，将你带到一个 `Xfce` 桌面环境，该环境并未提供任何便利或自定义界面来帮助新用户和不熟悉操作的用户定位。

![](img/3f314b57ad3c8b08d25e5d1ab47de56d_40_1.png)

`MorpheusArch` 项目确实提供了一个基于 `arcuses` 的脚本，名为 `LinDag`，以协助常见的系统管理和恢复任务。你可以使用它来检查服务、诊断网络、管理软件包并从驱动器中恢复数据。然而，奇怪的是，该脚本默认并未包含在发行版中，你需要从 GitHub 克隆它。
