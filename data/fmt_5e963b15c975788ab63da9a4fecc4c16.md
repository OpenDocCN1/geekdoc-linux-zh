
- `ic`: 指定输入上下文。
- `event`: 指定要使用的键事件。
- `buffer_return`: 从输入法返回多字节字符串或宽字符字符串（如果有）。
- `bytes_buffer`: 指定 buffer 的可用空间。
- `wchars_buffer`: 指定 buffer 的可用空间。

## 语言环境与国际化函数

`keysym_return` 返回如果参数为 NULL 的 KeySym。

`status_return` 返回返回数据的类型。

`XmbLookupString` 和 `XwcLookupString` 返回与语言环境编码的文本。如果返回了字符串和 KeySym，则 `keysym return` 将被改变。

`XmbLookupString` 和 `XwcLookupString` 返回字符串的字符数量。

`XmbLookupString` 和 `XwcLookupString` 返回输入法指定的字符串。

## 注意

为了确保正确的输入处理，必须向 `XmbLookupString` 和 `XwcLookupString` 传递 KeyEvents。如果组合了输入，`XmbLookupString` 和 `XwcLookupString` 在发生 KeyRelease 事件时的行为未定义。

- `BufferOverflow`: 输入字符串对于提供的缓冲区太大。`buffer return` 的内容未修改。
- `None`: 目前没有组合的输入。`buffer return` 的内容被修改。
- `Chars`: 已组合了一些输入。它们被放在 `buffer return` 中，并返回字符串长度。
- `KeySym`: 返回了 KeySym 而不是字符串，位于 `keysym return` 中。
- `Both`: 同时返回了 KeySym 和字符串；LookupChars 和 LookupSym 同时发生。

传递给 `XmbLookupString` 和 `XwcLookupString` 的输入上下文是否当前具有焦点没有区别。输入可能在获得焦点之前在输入上下文中组合，即使它没有焦点也可能被返回。

# 输入法约定

输入法对客户端是透明的。然而，客户端应该遵守若干约定以便正常工作。在远程输入服务器的情况下，客户端还必须意识到输入法和库之间可能的同步影响。

## 客户端约定

良好的客户端（或工具包）应首先查询输入法样式。如果客户端无法满足支持样式的要求（几何或回调方面），它应该与用户协商程序的继续或抛出某种异常或错误。

## 同步约定

Code 为零的 KeyPress 专门用作输入法组合了可以由 `XmbLookupString` 或 `XwcLookupString` 返回的信号。对 Code 为零的 KeyPress 事件没有其他用途。此类事件可能以实现相关的方式由前端或后端输入法生成。生成此类事件的可能方式包括：

- 输入法服务器创建合成事件
- 输入过滤器创建并推送到客户端事件队列的人工事件
- KeyCode 值被输入法修改的 KeyPress

当客户端指定回调支持时，除非输入法式调用了客户端并未获得响应，否则不会采取行动。

## 字符串常量

以下字符串常量定义在 `<X11/Xlib.h>` 中。虽然在这里使用了特定的宏定义，但它们可以实现为宏、全局符号或两者的混合。字符串指针值本身是不重要的；客户端不能假设两个值的不相等意味着实际字符串数据的不相等。
