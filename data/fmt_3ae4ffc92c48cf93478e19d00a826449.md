# 第 11 章：用户管理

以下任务涉及账户的添加、删除和管理。

1. 向 Linux 中添加本地用户，使用 `useradd` 命令。例如，创建一个名为 "john" 的用户，使用：
```
# useradd john
```

2. 为新用户设置密码，使用 `passwd` 命令：
```
# passwd john
```

3. 创建组，使用 `groupadd` 命令：
```
# groupadd testing
```

4. 将用户添加到现有组，使用 `usermod` 命令：
```
# usermod -aG testing john
```

5. 要删除用户账户，使用 `userdel` 命令：
```
# userdel -r john
```

6. 要删除一个组，使用 `groupdel` 命令：
```
# groupdel testing
```
