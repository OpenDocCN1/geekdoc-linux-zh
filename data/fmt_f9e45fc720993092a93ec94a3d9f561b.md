## time 对象

`time` 对象用于表示小时、分钟、秒和微秒的时间。它们使用以下类构造函数创建：

```
time(hour [, minute [, second [, tzinfo={}]]])
```

创建一个表示时间的对象，其中 0 <= hour < 24.0 <= minute < 60.0 <= second < 60，且 0 <= microsecond < 1000000。`tzinfo` 提供了区域信息，并且是本节描述的 `tzinfo` 类的实例。返回的时间对象具有属性 `hour`、`minute`、`second`、`microsecond` 和 `tzinfo`，这些属性保存了作为参数提供的相应对应值。

`time` 的以下类属性描述了 `time` 实例的允许取值范围和分辨率：

`time.min`

表示可表示的最小时间的类属性（`datetime.time(0, 0)`）。

`time.max`

表示可表示的最大时间的类属性（`datetime.time(23, 59, 59, 999999)`）。

`time.resolution`

非相等时间对象之间最小可解析的差异（`datetime.timedelta(0, 0, 1)`）。

`time` 对象的实例 `t` 具有 `t.hour`、`t.minute`、`t.second`、`t.microsecond` 和 `t.tzinfo`，以及以下方法：

```
t.dst()
```

返回 `t` 自午夜以值（`None`）。返回的是 `timedelta` 对象。如果没有设置时区，则返回 `None`。

```
t.isoformat()
```

返回一个表示时间的字符串 `'HH:MM:SS.ffffff'`。如果微秒为 0，则字符串的该部分将被省略。如果提供了时区信息，时间可能会加上偏移量（例如 `'HH:MM:SS.ffffff+HH:MM'`）。

```
t.replace(hour [, minute [, second [, tzinfo={}]]])
```

返回一个新的时间对象，其中一个或多个组件被提供的值替换。例如，`t.replace(second=30)` 将字段更改为 30 并返回一个新的时间对象。参数的含义与之前调用的 `time()` 函数中提供的参数相同。

```
t.strftime(format)
```

返回一个按照模块中 `time.strftime()` 函数相同规则格式化的字符串。由于数据信息不可用，应使用与时间相关信息的格式化代码。

```
t.tzname()
```

返回 `t.tzinfo.tzname()` 的值。如果没有设置时区，则返回 `None`。

```
t.utcoffset()
```

返回 `t.tzinfo.utcoffset(None)` 的值。返回的对象是一个 `timedelta` 对象。如果没有设置时区，则返回 `None`。
