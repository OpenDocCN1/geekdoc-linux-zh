## 功能丰富

Linux 一直以来支持许多服务。大多数 Linux 变体中包含的某些让 Linux 成为优秀数据库服务器的特性包括：

- 多任务处理
- SMP（对称多处理）
- 32 位和 64 位虚拟内存模型
- 受保护的内核模式
- ELF 标准二进制文件
- 多用户支持
- 免费的图形用户界面 (GUI)
- 与其他 UNIX 变体的二进制兼容性
- 广泛的网络协议和支持支持
- 所有标准的 UNIX 网络服务，如 HTTP、FTP、Telnet 等

## 多任务处理

在真正的 32 位 Intel（在受支持的 RISC CPU 上为 64 位）多任务环境中，Linux 能够显式地“同时”运行多个程序，而这在现实中是一种非常快速的轮询算法——但谁在乎呢，它运行良好。这是数据库服务器的一项基本需求。可以同时启动许多进程线程并并行执行，提供卓越的性能和 IO 通道优化。

## 对称多处理器支持

开箱即用，Linux 将支持 1 个 CPU，在某些情况下最多支持 16 个，取决于具体的变体。这种多处理器支持使 Linux 成为数据库服务器的优秀平台，能够同时处理许多线程。几乎所有主要供应商都专门为数据库和 Web 服务销售多处理器服务器。Linux 内核设计良好，可以处理这些多个处理器，为每个额外的处理器提供几乎完全的利用率，而不是像其他操作系统那样，每增加一个新处理器利用率就会下降。

## 32 位（及 64 位 RISC）虚拟内存

Linux 使用全 32 位内存管理服务，在 Intel 平台上提供 4GB 的虚拟内存，在任何 RISC 处理器上使用 64 位 Linux 时提供 16 艾字节（exabytes）。每个新进程都会获得一个独立的用户级进程，如果需要，可用 2GB 的虚拟空间；实际上，它只根据需要分配足够的 RAM 来支持进程。这为系统上的每个进程提供了安全性和独立性。

## 二进制兼容性：标准可执行和链接格式 (ELF) 二进制文件

Linux 采用了基于 ELF 的标准二进制文件和共享库（类似于动态链接库 DLL 但不兼容的应用程序策略）。这允许应用程序在多个操作系统上运行，而无需重新编译。SCO UNIX 4.2、SVR4、AIX 以及大多数基于 Intel 的 Linux 版本是转向这种兼容性设计的许多 UNIX 变体之一。例如，SCO 版 Corel Draw!也可以在 Linux 下运行。

## 多用户

真正的用户能力（不仅仅是多次访问，那是 NT 主要提供的功能——很少有单独的用户登录到同一个 NT 宿主机上）允许多个用户在单个 Linux 服务器主机上运行多个进程。

## 全受保护内核模式操作

Linux 操作系统在全受保护模式下运行所有应用程序（没有进程可以绕过操作系统）。除非专门允许，否则任何用户应用程序无法干扰其他用户应用程序，且在 Linux 中无法直接访问任何硬件。这是 DOS 类型操作系统的两个主要问题。

## 免费的 X Window GUI

Linux 图形用户界面是一个完全免费的 GUI，基于 X/Open 标准版本的 X Window 系统（大多数现有基于 X 的程序可以在无需任何修改的情况下在 Linux 下运行）。X Window 系统自 20 世纪 80 年代初以来，早于微软 Windows 的设计。你甚至可能注意到 Win9x / NT 的新界面与存在已久的 X Window 标准非常相似。

## 有限的 DOS / Windows 应用程序支持或 VMware

大多数 Linux 版本都附带了一个名为 `DOSEMU` 的 DOS 模拟器和一个名为 `WINE` 的 Windows 仿真包。这两个软件包都对不尝试遵守任何规则的应用程序（例如在某些情况下直接访问硬件）提供了简单但有限的支持。

Linux 的另一个亮点是名为 `VMware` 的虚拟内存仿真包。`VMware` 提供了对完整的 Windows 3.x / 9.x / NT 支持，允许 Linux 作为主机操作系统，在虚拟世界中安装一个或多个此类客操作系统，与 Linux 操作系统平等共享本地内存和硬件资源。同时，你可以在任何性能强大的 PC（即硬件为：266+ MHz、96+ MB 内存、磁盘空间）上为网络上的所有用户提供桌面。注意 `VMware` 为 NT 提供同等的虚拟内存管理产品。你可以将 Linux 安装为客 OS并在 Windows 窗口中同时运行两者。你可以从 `vmware.com` 下载任一系统的 30 天免费版本。

## 广泛的网络支持

对于任何 Linux 版本来说，最大的卖点可能是提供的广泛网络支持。这包括用于 PC 上常用的网络操作系统的仿真包和相关协议。此外，除了标准的以太网和环形网络外，还对多种类型的接口支持，如 ISDN 甚至无线电台支持。通过各种附加包，为 Macintosh、DOS、Windows NT / 9x / 3.xx、Novell 和 OS/2 提供全原生协议支持，使 Linux 像这些其他版本的本地原生服务器和客户端。

## 标准 Web 服务

互联网服务由 `Apache` Web 服务器（全球领先）、互联网上运行最主要的 Web 服务器产品提供，以及最新 CGI 接口的完整版本：Perl、Java 等。Linux 是优秀的 Web 服务器；`Apache` 是一款顶级的 Web 应用程序，拥有集成所有数据库服务的钩子。唯一不支持的 Web界面是 Active Server Pages。

## 标准 UNIX 服务

Linux 支持所有的 UNIX 服务：电子邮件、FTP、Usenet、Telnet、POP、IRC、NFS、DNS、NIS、SNMP、Kerberos 等，正如任何 Internet OS 所预期。

关于 Linux 是什么及不是什么的更详细概述，你可以查看 Linux International 网站 `http://www.linux.org/index.shtml`。

Linux 毕竟 Linux，在大多数情况下，工作站版和服务器版并没有真正的区别。例如，TurboLinux 工作站版的零售价格比 TurboLinux 服务器包还要便宜。唯一的区别在于你可以获得安装的软件数量和类型。工作站通常意味着与用户相关的主要的 Linux 网络服务，以及额外的办公生产力应用（如办公套件）。服务器版本默认可能不包含这些用户生产力应用，但这并不会阻止你在以后的任何时候安装它们。

如果你的 Linux 主机主要用途是文件、打印、网络和 FTP 服务，那么该主机将被视为一台服务器。如果你添加了像 Corel WordPerfect、StarOffice 或 Applware（基本上所有的 Office97 等效品）之类的办公生产力套件，你就又有了一个工作站。这种“工作站”和“服务器”的定义是基于用途的，而不是对软件的限制。大多数 Linux 版本都包含了适用于服务器和服务用户应用程序的所有可能程序；你可以根据需要选择要安装的内容。你甚至可以将安装自动化，通过单个软盘启动连接到中央安装服务，并使用脚本识别要创建哪些大小的磁盘分区，以及应该安装哪些包。RedHat 发行版提供了 `Kickstart` 自动化服务，用于在相似的 RedHat Linux 机器上进行多次安装。

## 最新最强大的硬件？

Linux 在旧设备上运行良好，是让旧设备作为防火墙、文件和打印（nfs, SMB, Novell, Mac）或 Web 或 FTP 服务器的极佳方法。对于桌面，去年的型号是最好的。你**不需要**最新最强大的硬件；很多时候它们是针对 Windows 的，例如 WinModems。通常情况下，品牌外设或使用知名芯片组的外设是最好的。Linux 拥有庞大的粉丝群体，通常可以在互联网某个地方轻松找到大多数常用设备的驱动程序。

## 奇怪的不兼容性

在最近的一课中，使用了一些本地机器。它们包含一种常见的网络接口卡（NIC），假设该卡可以在 Linux 上运行。遗憾的是，这个 NIC 只带来了挫败。快速浏览该 NIC 制造商的公司网页后，出现了一线希望。常见问题（FAQ）部分提供了一个 Linux 特定的板块，其中有一个的提示，要求下载他们的 DOS 设置磁盘文件。网站上的帮助信息是：“此 NIC 在 Linux 下不使用插入即用模式时工作效果最好。”设置程序没有办法更改这些特定 NIC 的状态，尽管该 NIC 在 Windows 和 NT 下运行良好。无论如何劝说或恳求都没有用。最后，它被一个真正的 8 位的 NIC 替代了，它从第一次开始每次都运行正常。这说明，你永远无法完全确定。
