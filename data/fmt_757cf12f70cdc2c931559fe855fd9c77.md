# 气体温度计。温度测量法。

带有气体温度计的管。温度计法是在基本物理参数——温度在 3 K 到 900 K (-454 到 116 °F) 范围内测量信息的方法。

原则上，气体温度计利用理想气体状态公式(1)作为物质的属性。体积 `n` 是

```
PV = nRT (1)
```

的摩尔数，`R` 是气体常数，`T` 是热力学温度；参考开尔文热力学温度的理想定义——水的三点。水的三点在实验室实践中定义为精确的百分之一，其值为 273.16 K (0 C 或 32.18 °F)。确定温度需要对气体属性进行两次测量。一次测量是在气体处于水点温度时进行的；第二组是在三点温度下建立的。可以通过公式(1)通过 `n = (PV)/(RT)` 来评估温度，这几组属性具有相同的值。

等容气体温度计是最常用的气体温度计法。这个名称有时会被误解，因为没有气体气泡显示

```
T = \frac{PV}{nR} (2)
```

未知温度下。在公式(2)中，没有考虑常数 `R` 和 `n` 的值。参见：气体（`GAS`）；三点（`TRIPLE POINT`）。

汽油是石油分馏中的一种碳烃混合物，其沸点在 200 °C (390 °F) 以下。汽油在环境温度下为液态；在混合物中易挥发。碳烃燃料用于提高燃烧质量。汽油主要由轻质烷烃（石蜡烷，如己烷、乙烷和辛烷）组成，以及更多沸点较高的烷烃。

汽油通常通过催化裂解或重整生产。在催化裂解中，将石油（石油衍生燃料）送入含有催化剂的反应容器中。混合物在催化剂存在下被加热，导致分子发生重排。产物即被称为汽油。

汽油范围内的碳烃分子结构中含有 4 到 12 个碳原子。它们的沸程差异很大。例如，从某些原油中可以获得高辛烷值（20%以上）的低沸组分。碳烃种类多样，正构烷、支构烷、环状化合物均有，己烷和庚烷是汽油的主要成分。

汽油成分的差异决定了为了生产均匀的混合物。混合会影响蒸汽压等各种性质。混合过程相对简单，但对混合物中成分含量的控制必须准确。操作通过同时将汽油混合物的所有成分泵入通向汽油混合物的管道来实现。通过对泵进行调节，以确保每种成分的正确量输送到管道中，以便在储罐中进行混合。
