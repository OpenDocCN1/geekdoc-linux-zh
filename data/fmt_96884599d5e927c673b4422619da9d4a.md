
## Diskless client

A client that has no local disk or file systems. The diskless client boots from the server; remotely mounts its root (`/`), `/usr`, and `/export/home` file systems from a server; allocates swap space on the server; and obtains all its data from the server. Any files created are stored on the server.

## 无盘客户端

没有本地磁盘或文件系统的客户端。无盘客户端从服务器启动；从服务器远程挂载其根目录（`/`）、`/usr` 和 `/export/home` 文件系统；在服务器上分配交换空间；并从服务器获取所有数据。创建的任何文件都存储在服务器上。

## JavaStation

Also known as a zero-administration client, this client has no local file system and its `/home` is accessed from a server across the network. The JavaStation runs only applications that are 100% pure Java. All data, applications, and configuration information reside on a centralized server that is running Netra J software, a Solaris operating environment. Java applications are downloaded on demand and are executed locally.

## JavaStation

也称为零管理客户端，此客户端没有本地文件系统，其 `/home` 通过网络从服务器访问。JavaStation 仅运行 100% 纯 Java 应用程序。所有数据、应用程序和配置信息都驻留在运行 Netra J 软件的集中式服务器上，这是一个 Solaris 操作环境。Java 应用程序按需下载并在本地执行。

## AutoClient

A client system type that caches (locally stores copies of data as it is referenced) all its needed system software from a server. The AutoClient system has a local disk, but the root (`/`) and `/usr` file systems are accessed across the network from a server and are loaded in a local disk cache. Files in the `/` and `/usr` file systems are copied to the cache disk as they are referenced. If a Solstice AutoClient client accesses an application that is not already in its disk cache, that application is downloaded. If the application already resides in the client’s disk cache, the application is accessed locally. AutoClient replaced the dataless client in Solaris 2.6.

## AutoClient

一种客户端系统类型，它从服务器缓存（在数据被引用时在本地存储数据的副本）其所需的所有系统软件。AutoClient 系统具有本地磁盘，但根目录（`/`）和 `/usr` 文件系统通过网络从服务器访问，并加载到本地磁盘缓存中。`/` 和 `/usr` 文件系统中的文件在被引用时会被复制到缓存磁盘。如果 Solstice AutoClient 客户端访问的应用程序尚未在其磁盘缓存中，则该应用程序将被下载。如果应用程序已存在于客户端的磁盘缓存中，则应用程序将在本地访问。AutoClient 在 Solaris 2.6 中取代了无数据客户端。

## 服务器的前提条件

在安装 Solaris 8 之前，服务器必须满足一些最低要求：

### The Solaris 8 release supports all sun4d, sun4u, and sun4m platforms

Some `sun4c` systems might not be supported in future releases of Solaris 8 beyond the 11/99 release. Check with your hardware vendor if you have a `sun4c` system to make sure it is supported before proceeding.

### Solaris 8 版本支持所有 sun4d、sun4u 和 sun4m 平台

某些 `sun4c` 系统可能在 11/99 版本之后的 Solaris 8 的未来版本中不受支持。如果你有 `sun4c` 系统，请在继续之前与硬件供应商确认其是否受支持。

### To run a graphical user interface (GUI) installation

The system must have a minimum of 32MB of RAM. As a server, however, it is typical to have 256MB of RAM or more.

### 要运行图形用户界面（GUI）安装

系统必须至少有 32MB RAM。然而，作为服务器，通常会有 256MB RAM 或更多。

### The disk needs to be large enough

The disk needs to be large enough to hold the Solaris operating system, swap space, and additional software, such as Solstice AdminSuite and AutoClient. You'll also need to allocate additional disk space on an operating system server in the `/export` file system for diskless clients or Solstice AutoClient systems. Plan on a minimum of 1GB of disk space, but realistically you should have 2GB or more.

磁盘需要足够大以容纳 Solaris 操作系统、交换空间以及额外的软件，例如 Solstice AdminSuite 和 AutoClient。你还需要在操作系统服务器的 `/export` 文件系统上为无盘客户端或 Solstice AutoClient 系统分配额外的磁盘空间。计划至少 1GB 的磁盘空间，但实际上你应该有 2GB 或更多。

## 在服务器上安装 Solaris 8

在开始安装之前，让我们回顾一下安装前检查清单。

首先，收集有关服务器的系统识别信息。如果系统正在运行，你可以使用表 15.1 中列出的命令收集所有这些信息。

### 表 15.1

### 系统识别信息

| 所需信息 | 用于收集信息的命令 |
|---|---|
| 系统名称 | `/usr/bin/uname -u` |
| 主网络接口 | `ifconfig -a` |
| IP 地址 | `ypmatch <system_name> hosts`<br>`nismatch <system_name> hosts`<br>`more /etc/inet/hosts` |
| 域名 | `/usr/bin/domainname` |
| 是否属于子网 | `more /etc/netmasks` |
| 使用什么名称服务 | `more /etc/nsswitch.conf` |

接下来，验证你是否有足够的磁盘空间用于 Solaris 8 以及你计划添加的所有捆绑和第三方软件。（请参考第 3 章，了解每个软件配置集群的总大小。）通常，服务器会有数 GB 的磁盘空间可用于操作系统，因此你将安装完整的发行版集群。此外，你还需要与软件供应商核实任何第三方软件包以及交换空间要求的空间需求。

此外，如果你计划运行以下软件，请确保有足够的磁盘空间：

- `AnswerBook2`
- `Desktop Power Pack`
- `Internet Mail Service`
- `ODBC Driver Manager`
- `OpenGL`
- `Solstice AdminSuite`
