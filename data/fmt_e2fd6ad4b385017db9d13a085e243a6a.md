
反应常数可能是 $k_A$ 和 $k_B$ 的平均值，单位分别为 $mol^{-1}s^{-1}$ 和 $s^{-1}$，这在室温下通过方程(6)和(7)得到满足。后述提到，当加入 1 L 氯化甲酸（带有水性危险缓冲）使氢合离子 $H^+$ 减少了几个数量级时，随后加入了了 0.5 M 水溶液钠溶液。在20世纪50年代初观察到这种插入是湍流的。湍流增加了此反应的弛豫时间（从 1 ms 到 1 s），因为弛豫时间是由 Mann 测量的，他暗示了溶剂分子的化学变化。

速率常数随温度变化，这是由于碰撞分子平均能量的变化。这遵循阿伦尼乌斯方程 $k = A e^{-E_a/RT}$，其中 $A$ 是前指数因子，$E_a$ 是活化能，$R$ 是气体常数，$T$ 是开尔文下的绝对温度。这里的关键因素是具有足够能量引发反应的碰撞比例。反应仅对于结合反应特别重要，其中 $A + B \rightarrow AB$ 将形成一个激发复合物 $AB^*$，它通过随后的碰撞稳定。提供足够能量以稳定键的概率随着碰撞频率和总压力的增加而增加。

单分子反应 $P \rightarrow R$ 的简单情况速率由方程(11)：

```
$d[P]/dt = -k[P] \quad (11)$
```

任何弛豫方法的本质都是扰动（温度、压力、电场或光学的微小变化），使得化学系统在试图达到平衡时，由于化学变化的缓慢性而被迫发生变化。

### 气相反应

气相化学反应的速率对于理解过程至关重要。与液相反应不同，气相分子碰撞必须在单步中发生，连续反应和自由基反应的碰撞也是如此。例如，氧化碳 ($CO$) 分解为二氧化碳 ($CO_2$) 并释放能量。它发生在燃烧（例如，甲烷的天然气燃烧）和大气中。在这两种情况下，反应可以写为单个反应(9)

```
$CO + O_2 \rightarrow 2CO_2 \quad (9)$
```

速率与反应物浓度成一次正比，并导致产物化学状态的变化。P随时间的变化（积分速率）在方程(12)中。下标表示 A 随时间减少，因为它随时间函数而衰减，而 P 的浓度随时间增加，并保持与 A 和 B 的浓度相等。因为一级反应在动力学上是简单的，因此处理此类反应是可能的。这对于一级反应（初始浓度）和任意时间 $t$ 成立。

```
$[A]_t = [A]_0 \exp(-kt)$
```

```
$[P]_t = [P]_0 \exp(-kt)$
```

然而，反应并非来自 $O_2$ 分子的碰撞，而是遵循两个分子之间的多个步骤。在单分子反应的情况下，单个分子发生分解或通过与其他分子的碰撞被引发。第一步涉及气相基元反应，即自由基，具有一个或多个未对电子。这些物种通常具有很高的活性，是导致气相反应的原因。

速率是指反应物或产物浓度随时间变化的速率。动力学实验的目标不是测量速率本身，而是测量优于反应物浓度随时间变化的速率的内在属性。

显微镜中的化学科学学科用于解决化学问题。形成标本的视觉图像、选择标本的小体积以及对所选体积进行化学分析的能力通过现代分析显微镜技术成为可能。

通常在上部鼻腔的嗅觉黏膜中，存在对气态化学物质敏感的神经元素。口腔的这些通道是敏感的；它们由对化学溶液产生反应的变性上皮细胞组成。常见的化学感官由鼻、口和手指膜中的游离神经末梢组成，对气态或液态的刺激物和其他化学物质敏感。

## 化学分离技术

含有价电子元素的双原子分子具有更大的电负性；电负性更强的元素始终放在方程式的前部。

在化学中，为了分析或工业目的，从物质中纯化或分离它们。对于具有多样性的产品，分离是其目标，其中分析是确定被分离物质成分或性质的首要任务。

离子化合物采用类似的表示法。在方程式中，正离子在前，负离子在随后。这表示了方程式中存在的金属元素。化合物的方程式有氯化钠；硝酸铵；硫酸铵；Al2SO4。

分离时需要考虑的三种方法：(1) 物质回收的完整性，(2) 与相关物质的分离程度，以及(3) 分离的效率。

更复杂的无机化合物以类似的方式表示。正离子由金属或配位化合物置在前，随后是负离子。化合物有 NH4Cl（氯化铵）；[Co(NH3)6]3（三草酸钴和钾）；[Fe(CN)4]；对于无机化合物，如丙烯酸盐，用化合物的方程式表示，水分子的数量用前缀表示。化合物的最后一个符号是 CuSO·H2O。

根据各种性质有许多类型的分离方法。方法将利用或分配溶解性、挥活性、吸附和影响，尽管其他方法也被有效利用。最高效率的分离将通过分离的两种物质之间的最大差异获得。

由于存在多种化合物，有机族的标记或表示法变得复杂。存在许多不同类型的有机化合物。有芳香族和脂肪族、饱和、不饱和和环状。符号系统必须区分各种烃类，并将它们与其他化合物区分来。见“化学分离过程”（CHEMISTRY-DISTINATION processes）；醇、酯和酚。见“化学”（CHEMISTRY）；“无机化学”（INORGANIC CHEMISTRY）；“有机化学”（ORGANIC CHEMISTRY）。

