
无论采取哪种方式，这都是的一项重大工程。升级较大的客户群将消耗资源和时间。你将考虑当前的网络状态、网络布线和带宽，以确保满足你的性能规范。只有当用户当前的应用程序或应用程序来自完全不同的服务器类型时，才需要对用户进行培训。

如果数据库服务器产品不变（例如仍然使用 Oracle，只是运行在新平台上），那么应用程序可能不需要更改，或者至少用户界面可能不会发生变化。如果这是一个新的数据库服务（例如从 Access 或 Dbase 迁移到 Oracle 或 Informix），那么对于新界面和相关应用程序将涉及大量的培训。对任何新或升级的产品重新培训用户将需要资源。这只是任何新开发或改进项目的一部分。其他需要考虑的资源包括数据库管理本身、开发工具、接口开发、额外的网络带宽需求以及持续的支持和帮助服务。

如果你必须将遗留数据库迁移到此新服务，你将需要重新培训使用新界面访问迁移数据的用户。还有许多其他方面，其中许多将在后面的章节中讨论。

## 硬件兼容性

首要考虑应该是硬件兼容性、可用性以及了解任何兼容性问题所需的时间。你通常可以在表 1.2 所示，在每个发行版的官方网站检查硬件兼容性信息。通常情况下，大多数情况越新越好。虽然旧且无用的硬件在某些情况下可以电子邮件、路由、防火墙和打印服务等通用用途，但必须权衡旧硬件备件的支持与去年电脑型号相对廉价之间的关系，后者是 Linux 的极佳选择。Linux 作为操作系统的开销较小，在旧硬件上应该能提供更高的性价比。

在大多数情况下，你的数据库服务器将处理关键任务数据。你将希望尽可能使用最好的硬件，而无需费力为最新的硬件设计寻找驱动程序。你还需要可靠的硬件来抵御真正的 24/7 服务。目前市售的低于 1000 美元的 PC 并没有最好的高可靠性部件，而且不太可能 24/7 运行一或两年——它的设计目标是持续最短的时间并频繁更换。通常，组件是廉价的。

## 给管理层

### 便宜就是便宜

一年前购买的一台测试系统在当时仅落后领先水平，在进入连续但非常轻负载的服务运行一个月后，它的电源供应器发生了完全故障。保修期为一年。更换部件零售价为 30 美元，但停机一天的烦恼并不值机式箱内使用的廉价电源供应器所节省的小额费用。

相比之下，较旧的 200 MHz 机器已连续服务了两多，尚未发生电源故障，五年前购买的 100 MHz 工作站也是如此。一分钱一分货，大品牌出售特定的服务器级硬件是有原因的——它是为了耐用而设计的。这是一个小众市场，因此产量较少，价格较高。准备好购买服务器级的产品。

你主要的关注点是大量的马力和 RAM 供这些“马”喂它们在巨大的磁盘阵列中奔跑。理想情况下，数据库服务器应该拥有多个 CPU，并提供你认为过倍所需的 RAM。

### 测试环境

你应该准备一个包含一台服务器和几台客户端机器的测试环境。有一个培训、部署和故障排除的计划并遵循它。测试环境往往被跳过。

### 升级

> 注意
>
> 如果你已经拥有某些版本的 Linux，某些版本的 Linux 安装程序（例如 `RedHat`）会删除所有分区（并留下任何操作系统），然后创建并安装所有新内容。
>
> 对于大多数 Linux 安装，升级选项通常涉及重新安装所有产品。
>
> 去大型硬件供应商那里，让他们向你展示运行 Linux 的硬件，与他们一起对你的初始设计进行平台测试，并感受你长期来看需要什么。

有许多培训公司提供品牌培训，例如 Global Knowledge Inc.（访问地址为 `www.globalknowledge.com`）。其他公司还包括由 Linux 发行版本身提供的培训。在任何网络引擎上搜索“Linux Training”，可以找到许多如 `www.linxtraining.org`、`www.learningtree.com`、`www.linuxsystemsgroup.com` 等机构的列表。

对用户以及支持和管理人员进行适当的培训，再怎么强调都不为过。同时也要理解，不能仅仅因为某门课程写着“……导论”且可能没有先决条件，你就不能直接把你那位每周只上网一次的阿姨作为学生送进去。任何大型企业培训公司都会提供非常高级的课程——即使是入门课程，其水平也会很高。

## 需要提交给经理的问题

**成本。** 毫无疑问，免费的没有优势。但这并不意味着没有支持；商业支持是可用的。计算机制造商的巨头开始提供预装 Linux（通常是 `RedHat`）的 PC。如果 Compaq、Dell 和 IBM 等公司在他们的硬件上支持 Linux，这无疑是 Linux 的一个巨大加分项。

**可靠性。** Linux 几乎永远不需要重启；驱动程序和应用程序可以随时重新加载。互联网几乎完全是面向 UNIX 的，因为 UNIX 非常可靠，仅此不言。UNIX 主导了生产服务器和高端图形工作站的高端市场，因为它具有持续运行的可靠性和韧性。

**安全性。** 几乎整个互联网由 UNIX 变体驱动，包括许多 Linux 服务器。内核受到了良好保护，防止任何用户的直接访问，且文件系统设计得非常安全，并在多年来互联网中被证明是安全的。大多数安全漏洞并非源于普通或甚至平均用户在任何操作系统中都能利用的弱——而是源于用户糟糕的安全实践。Win98 没有内置真正的安全功能。Linux 的安全性是内置在文件系统中的，并适用于每个文件。

## 进行适当的成本分析

你需要对在网络中引入另一个操作系统进行适当的成本分析，包括所需的支持（员工培训；客户端培训应减至最低）、集成问题（几乎没有）、接口问题（不同类型的窗口界面，但基本概念相同）以及成本节约。

## 资源

对于任何操作系统，你长期都需要提供测试资源、培训资源、再培训资源和帮助台资源。通过使用像 Linux 这样可靠、安全且强大的操作系统，你可以减少这些资源浪费。

## 总结

Linux 将长期留存是一个现象。围绕着 Linux 的草根情感、新的安装和集成的便利性，使得 Linux 成为一个极具吸引力的产品。只要你记住它本身**不是** Windows，Linux 就是任何 Windows 操作系统的稳健替代方案。Linux 在服务器领域和桌面环境中如如得之地。Linux 是 UNIX 的一个版本，你需要具有 UNIX 或 Linux 经验的人来管理它。它的界面与 Windows 非常相似，但在所有情况下并不完全相同。在 Windows 中能做的任何事情，在 Linux 中都能做到。（电影《泰坦尼克号》使用 Linux 来制作特效）。Linux 有许多用户级应用程序，可以实现所有功能，尽管有时实现方式有所不同。主要优势是 Linux 作为操作系统提供的成本、可靠性和安全性，更不用说 Oracle、Informix、IBM、Sun、Dell、Compaq 等许多行业巨头提供的支持持续增长。互联网是使用 UNIX 开发的，目前仍然主要是 UNIX，而 Linux 在今天发挥着非常重要的作用。

## 常见问题 (FAQs)

- **Q:** 我会失去对 Windows 的访问吗？
- **A:** 有的，也没有。如果你想的话，就可以；但如果你不想，就不必这样做。这在安装章节会解释得更清楚。基本上，如果你有可用的、未使用的磁盘空间，你可以将 Linux 作为备操作系统添加到大多数 PC 中，而不会丢失当前配置。如果你愿意，也可以删除任何其他操作系统的痕迹，并仅使用 Linux 使用这台机器。从现实角度来说，你应该消除数据库服务器上的任何其他操作系统。因为任何时间只能运行一个（运行 `VMWare` 的除外，但这对这个回答来说太复杂了），拥有多个是浪费空间。

- **Q:** 我需要保留 Windows 吗？
- **A:** 如果你绝对离不开它，就需要。如果你想切换，或者这台机器用于开发，就不需要。像任何操作系统一样，你随时可以以后重新构建。通常情况下，对于数据库服务器，你只使用一个；因此你不应该保留旧的 Windows 系统。

- **Q:** 我如何让它与当前的操作系统实现双引导（三引导、四引导等）？
- **A:** 记住，除非是开发系统，否则你不需要也不想要在服务器上运行两个操作系统。然而，在安装期间，你可以选择使用 `lilo` 让系统具有双引导功能，或者可以将 Linux 启动项添加到几乎所有基于 Intel 的 PC 启动管理器。

- **Q:** 它运行 Microsoft Office 97 吗？
- **A:** 并不真正，它不是原生的。使用模拟器 `WINE`，你可能可以让 Office 97 的部分或全部运行。但你可以使用许多相似但并非完全相同的替代品，例如 StarOffice 或 WordPerfect。这些中的每一个都可以读取和写入大多数文档的 Office97 格式。

- **Q:** 支持问题如何？
- **A:** 这种支持通过用户组提供，你可以从那里获得帮助。如果你需要，可以从互联网上寻找支持。大多数 Linux 发行版也可以从那里那里获得商业支持。请查阅表 1.3。

- **Q:** 哪些应用程序可以在 Linux 上运行？
- **A:** 互联网上有很多。

- **A:** 好的，关于它？商业支持可以获取到。
