## continue, break

压缩率：`xx.xx%`

压缩节省的输入百分比。（仅对 `-v` 有效。）

- - 不是普通文件：未更改
当输入文件不是普通文件（如目录）时，它保持不变。

- - 有 `xx` 其他链接：未更改
输入文件有链接；它保持不变。更多信息请参见 `ln(1)`。

路径名太长，无法添加 `.z` 后缀。

## cp — 复制文件

### 概要

```
/usr/bin/cp [-f] 源文件 目标-文件

/usr/bin/cp [-f] 源文件... 目标

/usr/bin/cp -r -R [-f] 源目录... 目标

/usr/xpg4/bin/cp [-f] 源文件 目标-文件

/usr/xpg4/bin/cp [-f] 源文件... 目标

/usr/xpg4/bin/cp -r -R [-f] 源目录... 目标
```

## 描述

通过 `cp` 命令，你可以执行以下操作：

- 复制单个文件并为它们分配新名称。
- 将一个或多个文件复制到不同的目录，保留原有的文件名。
- 递归地将整个目录结构复制到另一个目录。

当你复制源-file 时，如果目标-file 不存在则会创建。目标-file 的所有者、组和模式与源-file 相同，除非你是超级用户，否则不会设置粘滞位（sticky bit）。如果目标-file 存在，会被覆盖，但与其相关的模式（如果适用则为访问控制列表 (ACL)）、所有者和组不会改变。目标-file 的最后修改时间和源-file 的最后访问时间被设置为复制完成的时间。如果目标-file 是指向另一个带链接文件的链接，则其他链接将保留，目标-file 将变成一个新文件。当文件被复制到现有目录时，一个或多个源-file 将复制到目标所指定的目录。对于每个源-file，会在目标中创建一个具有相同模式（如果适用则为 ACL）的新文件；其所有者和组是执行复制的用户。当递归地复制整个目录结构时，由源-dir 指定的一个或多个目录将被复制到目标所指定的目录。如果目标目录不存在，`cp -r |R` 会创建它并递归地复制所有目录和子目录，保持与源-dir 相同的所有者、组和模式。

你可以使用双连字符 `--` 来显式地标记任何命令行选项的结束，以便 `cp` 能够识别以横杠（`-`）开头的文件名参数。如果你在同一命令行上包含两个 `-` 和 `-`，则第二个被解释为文件名。

## 选项

`/usr/bin/cp` 和 `/usr/xpg4/bin/cp` 都支持以下选项。

- `-f` 如果无法获取目标文件的描述符，则尝试取消目标文件的链接并继续。
- `-i` 每当复制将覆盖现有目标时，交互式提示确认。`y` 表示继续复制。任何其他答案都会阻止 `cp` 覆盖目标。
- `-r` 递归地复制目录及其所有文件（包括子目录及其文件）到目标。
- `-R` 与 `r` 相同，但不复制管道。

仅对 `/usr/bin/cp` 支持以下选项。

- `-p` 不仅复制源-file 的内容，还保留 ID、权限模式、修改和访问时间，以及（如果适用）ACL。注意，如果你将 ACL 复制到不支持它们的文件系统，命令可能会失败。如果你将 ACL 复制到不支持它们的文件系统，命令可能会失败。

仅对 `/usr/xpg4/bin/cp` 支持以下选项。

### 操作数

- `source-file` 文件的路径。
- `source-dir` 目录路径。
- `target` 文件或目录路径。

## 示例

以下示例复制了一个文件。

```
castle@ cp goodies.old

castle@ ls goodies.old
```

以下示例复制了目录中的所有文件。

```
castle@ cp src /tmp
```

以下示例将目录复制到新的或现有的目录。

```
castle@ cp -R /src /backup

castle@ ls -R /backup
```

等待，示例是：

```
castle@ x/y
```
