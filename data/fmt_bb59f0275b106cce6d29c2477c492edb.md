## 14.1 初始窗口

![](img/705a076b108ea96be0c0695efb5556ce_261_0.png)

图 14.1：窗口

在默认配置下，Mozilla 窗口包含以下元素：占据窗口大部分内容的窗口、菜单栏、导航工具栏以及个人工具栏。窗口底部还有状态栏。最后，在窗口左侧，Mozilla 提供了一个包含许多标签页的侧边栏，每个都可以访问特定任务。当你右键点击窗口时，Mozilla 会弹出一个包含许多条目的上下文菜单。例如，将当前页面添加到书签或查看源代码。

### 14.1.1 菜单栏

菜单栏包括以下菜单：

- 文件：此菜单提供了打开、保存和打印文件的常用项目。还可以作为电子邮件发送。选择“编辑页面”会将当前页面加载到 Composer 中，你可以从头创建。
- 编辑：包括常用的编辑操作，如“撤销”、“剪切”、“粘贴”和“删除”。还有一个在网页中搜索单词或字符串的项目。“查找上”会重复上一次搜索操作。“首选项”打开一个更改浏览器配置选项的对话框。相关详情见。
- 查看：“视图”菜单包含显示或隐藏浏览器隐藏元素项目，以及停止加载网页或刷新。它还有更改显示页面文本缩放或更改字符编码的项目。此菜单中的另一个项目允许你查看网页的源代码。
- 转：这是导航菜单，包含在历史记录中“后退”或“前进”或跳转到“首页”的项目。选择“历史记录”会列出浏览器访问的所有网页地址。
- 书签：使用“书签”创建和编辑书签。书签可以按文件夹分类。可以从菜单选择任何以前创建的书签。
- 工具：可以通过“工具”菜单访问许多常用的浏览器功能。例如，查找互联网特定内容的搜索引擎。Cookie 管理器控制浏览器存储在计算机上的 Cookie，并列出每个 Cookie 的来源网站地址。可以使用它来撤销之前的接受或拒绝决定。

这也带来了一定的安全风险，因此您可能无法将其用于对隐私有高要求的站点，例如在线银行网站。

`窗口` 此菜单允许您切换到其他浏览器窗口，以及其他 Mozilla 组件的窗口（如果已安装）——如邮件客户端、撰写器和地址簿。

`帮助` `Mozilla` 是一件多功能工具，因此您可能想使用此菜单来访问在线帮助，该帮助提供了有关程序功能的信息和提示。

### 14.1.2 导航工具栏

导航工具栏的按钮可以快速访问浏览器的基本功能。使用“前进”和“后退”可以在查看过的页面历史记录中向前跳一步或向后跳一步。“刷新”会更新页面内容。通常情况下，网站会在缓存中存储一段时间，以防再次调用。刷新总是会从 Internet 加载当前页面。“停止”将中止页面的加载，因此不会有进一步的数据从相应的网站传输。

位于右侧的下一个元素是地址栏，您可以在其中输入 Internet 地址 (`URL`) 或搜索词。如果您输入了搜索词并按“搜索”，Mozilla 将使用设置中配置的搜索引擎搜索该词。在访问了若干个站点后，可以通过点击向下箭头直接选择它们的地址，这会打开一个列表。Mozilla 会存储此列表的内容，以便在您的下次浏览器会话中使用。开始输入一个之前的地址，然后按 (`Tab`) 键完成输入。

“打印”打印当前页面。其右侧的向下箭头也可以访问文档的打印预览。在最右侧，导航工具栏显示 Mozilla 标志，只要浏览器正在传输数据，它就会处于动画状态。

### 14.1.3 个人工具栏

个人工具栏是一个可自定义的工具栏，预先配置为包含以下元素：

`主页` 这指向配置为显示为 Mozilla 启动页的 Web 地址。

`书签` 此按钮允许您访问从互联网或 Internet 站点收集的书签。

`Mozilla 组织` 这指向 Mozilla 项目的主页。

`SuSE — Linux 专家` 这指向 SUSE LINUX 的主页。

### 14.1.4 侧边栏（Sidebar）

侧边栏位于左侧，在一个独立的子窗口中。

`相关内容` 在此下方，Mozilla 可以列出若干个与当前主题相关的站点。

`搜索` 这是一个通向几个知名搜索引擎的接口。

`书签` 此标签页是您的书签的额外入口，书签以树形结构在此处呈现。

`历史记录` 此标签页提供了最近访问过的网页列表。

## 14.2 使用标签页

Mozilla 可以使用标签页浏览在一个窗口中同时显示多个网页。这通常比为每个新文档打开一个新浏览器窗口更方便。若要在新标签页下显示文档（打开链接），请右键点击相应的链接，从右键菜单中选择“在新标签页中打开链接”。现在，可以通过点击主窗口顶部排列的不同标签页直接访问不同的文档。

一旦您开始使用标签页，标签栏左侧就会出现一个额外按钮，允许您打开一个新的空白标签页。按 `Ctrl+T` 可实现相同的功能。要关闭当前活动的标签页，点击标签栏最右侧带有 X 的按钮。右键点击标签页可打开右键菜单，提供若干相关操作，如关闭标签页或关闭所有其他标签页。

## 14.3 首选项

在选择“编辑” -> “首选项”时打开的对话框中提供了许多经常需要的浏览器设置。

| 类别 | 导航器 |
| --- | --- |
| 外观 | 当导航器启动时，显示 |
| 导航器 | [ ] 空白页 |
| 历史记录 | [ ] 主页 |
| 语言 | [ ] 最后访问的页面 |
| 辅助应用程序 | 主页 |
| 智能浏览 | 点击主页按钮将您带到此页面或此类页面 |
| Internet 搜索 | 位置：[http://mozilla.kao.at/ [选择文件...]] |
| 标签页浏览 | [使用当前页面] [使用当前组] |
| 下载 | 选择您想在工具栏中看到的按钮 |
| 比较器 | [x] 书签 [x] 搜索 |
| 邮件与新闻组 | [ ] 打印 |
| 隐私与安全 | [x] 主页 |
| 高级 | |

图 14.2：首选项

`外观` 在此项下，设置浏览器应使用的字体和颜色，选择主题，并在德语版本和英语版本之间切换。

`导航器` 在此项下可以更改的第一内容是浏览器的启动页。配置 Mozilla 启动时使用空白页、下文定义的主页（例如，您组织的内网门户网站）或最后访问的页面。在“历史记录”对话框中，定义访问过的页面地址应存储的天数。“语言”允许您定义一个可选语言列表，这对于提供多种语言的页面非常有用。在“Internet 搜索”下，告诉 Mozilla 使用哪种搜索引擎。如果您不希望 Mozilla 在您开始输入时自动显示历史记录中匹配的 Internet 地址，请在“智能浏览” -> “自动补全在地址栏中输入的文本”下禁用此功能。或者，配置 Mozilla 在输入框本身中自动补全地址。执行此操作，请选择“高级...”按钮，然后在对话框中选择“在输入时自动补全最佳匹配”。“标签页浏览”对话框中的可用选项之一是让 Mozilla 在每当双击链接时都为页面打开一个新标签页。在“下载”下，指定如何监控文件下载进度。启用下载管理器会显示进度条。
