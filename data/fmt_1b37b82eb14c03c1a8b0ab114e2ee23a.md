
得益于 BackupPC 的 Web 化设计以及备份在线存储在备份服务器上的事实，通过 BackupPC 恢复文件变得非常简单。连接到 BackupPC Web 界面，使用 URL `http://hostname/backuppc`，其中 `hostname` 是运行 `backuppc` 服务器的主机名称。界面上会弹出一个对话框，提示你输入授权用户的登录名和密码。一旦你输入了 `/etc/backuppc/httppasswd` 文件列出的用户的用户名/密码组合，就会出现 BackupPC 服务器的主页，如图 28-1 所示。当此屏幕出现后，点击“Select host”下拉框，并从出现的列表中选择一个主机。选择任何主机的名称都将带你进入该主机的摘要页，该页面提供了状态信息、列出了可以使用 BackupPC 对此主机进行文件备份和恢复的授权用户列表，并允许你浏览该主机的现有备份以定位并恢复文件，如图 28-3 所示。

对于增量备份，点击“Start Full Backup”将备份任务列入队列，并显示一个链接，你可以点击该链接返回主机的主页以监控备份状态。

使用 Ubuntu One 备份并镜像到云

今天最热门的话题之一是“云计算”，它是对依赖于互联网的各种托管服务的通用名称。云计算包含了许多托管服务模型：

- 基础设施即服务 `IaaS`：你通过互联网使用、配置和访问虚拟计算机系统
- 存储即服务 `SaaS`：你通过互联网在远程存储上存储文件和文件夹。这些服务最广知的平台示例是亚马逊的 Simple Store `S3, http://www.amazon.com/s3`、Dropbox `https://www.dropbox.com` 以及 Canonical 的 Ubuntu One `https://one.ubuntu.com`。
- 软件即服务 `SaaS` 最常用的名称：你通过互联网访问软件，而不是在本地计算机系统上安装它。这类软件在企业级最广知的示例是 Salesforce.com。在个人和业务层面，最好的免费示例是 Google Apps `www.google.com/apps`。

无论你对云计算有什么看法，存储即服务本身就非常有用，因为它允许你从多个计算机系统访问文件，而无需在每个使用的系统之间来回传输。

# 第三部分：Ubuntu 系统管理员

如果你不想将云端作为你正在使用的设备的主要存储设备，那么存储即服务 `Storage-as-a-Service` 将是一个极其实实用的备份方法。它天生满足了备份介质最基本的要求之一，即将备份存储在异地，这样本地灾难就不会抹掉你的计算机和备份文件。Canonical 提供的 Ubuntu 存储即服务对于 Ubuntu 用户来说特别容易利用，原因有二：

- 它为任何 Ubuntu 用户提供 2GB 的免费存储空间。
- 该软件已内置在 Ubuntu Linux 发行版中。

Ubuntu One 并非纯粹的备份机制，因为它的重点实际上是将文件夹的内容镜像到你使用的任何机器上。然而，如果你只在一台或少数几机器上使用它，那么它对于关键文件来说是一个极佳的个人解决方案，只要你记得将它们复制到主目录下的 Ubuntu One 文件夹中即可。

在你的 Ubuntu 系统上安装 Ubuntu One 就像使用你喜喜欢的包管理软件在你的桌面 Ubuntu 系统上安装 `ubuntu-client-gnome` 包一样简单，还要安装底层的 `ubuntu-client` 包。安装这些包将在你的主目录中创建一个 Ubuntu One 文件夹，并在 GNOME 面板中安装一个 Ubuntu One 应用程序 `applet`。

为了使用 Ubuntu One，你需要在 Canonical 的 Launchpad 网站创建一个账户，你可以在 `https://www.ubuntu.com/plans` 页面进行操作。该页面列出了可选 Ubuntu One 计划：2GB 免费存储空间或 50GB 非免费空间。Launchpad 是 Canonical 用于与 Ubuntu 和 Canonical 交互、报告错误等的中心站点。一旦你有了 Launchpad 账户，你就可以回到你的计算机系统，使用 Ubuntu One 应用程序通过你的 Launchpad 登录名和密码连接到 Ubuntu One。当你第一次从你使用的任何计算机系统连接到 Ubuntu One 时，使用 Ubuntu One 网页是可以轻松完成的。

在任何时候，你放入主目录中 Ubuntu One 文件夹的任何文件都会自动镜像到你的 Ubuntu One 账户。要从任何其他系统访问它们，只需右键点击 Ubuntu One 应用程序，选择“连接”以授权该机器访问 Ubuntu One，Ubuntu One 文件夹中的文件将自动同步到你正在使用的计算机上。你可以通过 `/ubuntu.com/files` 网页访问你的文件。

Ubuntu 还提供了一个命令行工具 `usync`，用于自动将文件和目录同步到你的 Ubuntu 目录以外的其他目录。要使用此工具，你必须安装 `ubuntu-client-tools` 包。

一旦安装了此工具，你可以通过执行 `usync --init DIRECTORY` 命令来识别你想要从 Ubuntu One 账户同步的目录，其中 `DIRECTORY` 是你希望作为 Ubuntu One 文件夹镜像的目录名称。执行此命令将弹出一个对话框，请求授予对 GNOME keyring 的访问。点击“始终允许”。然后你可以与你的 Ubuntu 文件夹同步目录，使用 `usync --action=upload` 命令上传文件，使用 `usync --action=download` 命令下载到机器，使用 `usync --sync` 命令进行同步，依此类推。`usync` 命令的主页提供了更多细节。

有关 Ubuntu One 的更多信息，请参阅 UbuntuOne Wiki 主题：`https://wiki.ubuntuone/ubuntu0`。

### Linux 时光机

苹果的 Mac OS X 是一个极好的计算环境——它在强大的类 UNIX 操作系统之上提供了一个易于使用的图形用户界面。苹果一直提供创新的、用户友好的软件，随着 Mac OS X 10.5 的发布，他们引入了一个令人印象深刻的友好且强大的备份包——时光机 `Time Machine`。时光机会自动跟踪系统上文件和目录的更改，并将系统的多个快照备份到外部或网络存储设备上。如果不小心删除了文件或目录，或者简单地转换到旧版本，你可以图形化地浏览这些快照，并检查或恢复时光机中任何时间点的数据版本。

为了不被更多商业软件超越，提供等效功能的 Linux 软件包开始出现，其中大多数是 `rsync` 工具的图形化封装器，并带有各种功能，以便于浏览“快照”、识别特定文件的可避免版本、提取这些文件的特定版本等。这类工具为传统备份涂上了一层令人印象深刻的“无用”面具，而苹果将备份概念化和自动化到真正对用户友好的程度是值得赞的。类似于 Mac OS X 的 Time 软件，类似的 Linux 备份机制最好配合网络资源或在单系统环境使用。除非你也将“备份进行备份”到异地，否则备份无法防止灾难性问题。

以下在 Ubuntu 系统上进行快照式备份值得关注的：

- `Back In Time`：Back In Time 是一个非常好的基于 GTK 的包，提供了一个良好的、以日期为导的快照浏览器和单按钮恢复机制。图 28-7 显示了 Back In Time 的快照浏览和恢复界面。Back In Time 是 Linux 时光机重新实现中最我喜欢的，它是我个人使用的类时光机解决方案，也是我在仅限 Ubuntu 环境中推荐的方案。你可以从其主页 `www.le-web.org/back-in-time` 获取 Ubuntu DEB 包。
