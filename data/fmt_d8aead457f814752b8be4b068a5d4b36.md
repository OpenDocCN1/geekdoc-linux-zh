
## Pico 编辑器

现在你在文件中输入。只需输入文本即可。完成输入后按`^o`（写出）。`Pico`将提示你命名。如果你想编辑现有文件而不是创建新文件，请从`SHOWME`提示符输入`pico <filename>`。其中`<filename>`是你要编辑的文件名。

| --- | --- |
| `Ctrl-f` | 向前移动一个字符 |
| `Ctrl-b` | 向后移动一个字符 |
| `Ctrl-p` | 移动到上一行 |
| `Ctrl-n` | 移动到下一行 |
| `Ctrl-a` | 移动到当前行开头 |
| `Ctrl-e` | 移动到当前行末尾 |
| `Ctrl-v` | 向下移动一页 |
| `Ctrl-y` | 向上移动一页 |
| `Ctrl-w` | 搜索字符串 |
| `Ctrl-l` | 刷新屏幕显示 |
| `Ctrl-d` | 删除光标处的字符 |
| `Ctrl-k` | 剪切选中文本 |
| `Ctrl-u` | 在光标处粘贴上次剪切的块 |
| `Ctrl-r` | 在光标处插入外部文件 |
| `Ctrl-o` | 保存当前文件 |
| `Ctrl-x` | 退出 Pico |
| `Ctrl-i` | 在当前光标处插入制表符 |
| `Ctrl-j` | 对当前段落进行对齐 |
| `Ctrl-t` | 调用拼写检查 |

## vi 编辑器参考

`vi`是一种大多数 Unix 操作系统常用的基础全屏编辑器。该程序实际上是`vi`（全屏界面）和`ed`（后台宏）的结合。当你使用`:,`命令时，你调用的是`vi`编辑器的`ed`部分。这里提供了一个快速参考。

> 记住：所有的 Unix 命令都是区分大小写的！

### 缩写

| 缩写 | 含义 |
| --- | --- |
| `#` | 命令前的数字值，例如 `32G` 表示 `32G` |
| `^X` | `control-X` |
| `<sp>` | 空格 |
| `<cr>` | 回车（`return`键或`enter`键） |
| `<string>` | 字符字符串 |

### 移动命令

移动命令前的数字表示该操作重复的次数。如果命令前没有输入数字，则默认为 1。

| 命令 | 功能 |
| --- | --- |
| `#h`（或向左箭头） | 向左 |
| `#j`（或向下箭头） | 向下 |
| `#l`（或向右箭头） | 向右 |
| `#k`（或向上箭头） | 行尾 |
| `#$` | 行首 |
| `#w` | 向前移动一个单词 |
| `#b` | 向后移动一个单词 |
| `#G` | 跳到第 `#` 行 |
| `#` | 向前一个句子 |
| `#(` | 向后一个句子 |
| `#(` | 向前一个段落 |
| `#(` | 向后一个段落 |
| `^F` | 翻页 |
| `^B` | 翻页 |

### 搜索

| 命令 | 功能 |
| --- | --- |
| `/<string>` | 搜索 `<string>` 下一次出现的位置 |
| `?<string>` | 搜索 `<string>` 上一次出现的位置 |

### 撤销更改

| 命令 | 功能 |
| --- | --- |
| `u` | 撤销最近一次更改 |
| `U` | 撤销当前行的所有更改 |
| `:q!` | 不保存修改退出 |
| `:e!` | 重新编辑文件 |

### 删除与移动

所有删除的内容都存储在缓冲区中。这通过在删除命令前加上`a`和`<a-z>`实现。删除的文本将写入该字母指定的缓冲区。要向缓冲区追加文本，则使用大写字母`<A-Z>`。

| 命令 | 功能 |
| --- | --- |
| `#` | 删除光标后的字符 |
| `#X` | 删除光标前的字符 |
| `#dd` | 删除行 |
| `#dw` | 删除单词 |
| `D` | 删除行的剩余部分 |
| `P` | 将最近删除的文本粘贴在光标前 |
| `P` | 将最近删除的文本粘贴在光标后 |

### 插入与修改文本

所有这些命令都通过按下退出键键 `<esc>` 完成。

| 命令 | 功能 |
| --- | --- |
| `a` | 追加文本 |
| `i` | 插入文本 |
| `#r` | 替换 `#` 个字符 |
| `#R` | 覆盖行的剩余部分 |
| `#J` | 合并 `#` 行 |
| `:s/<string1>/<string2>` | 将所有的 `<string1>` 替换为 `<string2>` |

### 写入、编辑与退出 vi

| 命令 | 功能 |
| --- | --- |
| `:q` | 退出 `vi` |
| `:q!` | 在不更改文件退出 |
| `:w` | 写入文件 |
| `:w <string>` | 写入文件 `<string>` |
| `:w >> <string>` | 追加到文件 `<string>` 的末尾 |
| `:w! <string>` | 覆盖文件 `<string>` |
| `:wq` | 写入文件并退出 |
| `:f <string>` | 将当前文件名设置为 `<string>` |
| `:cd <string>` | 切换目录到 `<string>` |
| `:r <string>` | 读取文件 `<string>` |

## x 编辑器

`x`是 Hessling 编辑器。它的设计旨在与 VM/CMS/XEDIT 相似。对于那些已经熟悉文件编辑但尚未准备好使用`pico`或`vi`的人来说，这是一个很好的编辑器。大多数命令与 XEDIT 类似。但也有一些不同之处，功能键如下下表所示。

### 标准 x 功能键分配

设置可能有所不同。从命令行输入以查看当前设置。

| 功能键 | 功能 |
| --- | --- |
| `F1` | SOS 编辑 |
| `F2` | 分割/合并 |
| `F3` | 退出 -- 如果没有任何更改，则终止编辑。 |
| `F4` | 无操作 |
| `F5` | 未定义 |
| `F6` | ? |
| `F7` | 向后移动 |
| `F8` | 向前移动 |
| `F9` | 文件 |
| `F10` | 向右移动 55 列 |
| `F11` | 向左移动 55 列 |
| `F12` | 执行前缀命令 |

### 移动命令

| 按键 | 功能 |
| --- | --- |
| `向下箭头` | 光标向下移动一行，必要时滚动屏幕 |

| `向右箭头` | 光标向右移动一列，必要时滚动屏幕 |

## 计算集群

计算集群适用于有数值批作业的用户。集群机器通过 IBM 的 LoadLeveler 软件共享。机器上的可用软件包括 FORTRAN（包含 IMLS）、SAS 6.09、Gaussian 92 和 Mathematica。

提供了交互式 Shell 脚本以便方便提交作业。

| Shell 脚本名称 | 对应软件： |
| --- | --- |
| `fsub` | FORTRAN 和 C |
| `ssub` | SAS 6.09 |
| `msub` | Mathematica |
| `gsub` | Gaussian 92 |

设置了四个作业队列。

| 作业队列名称 | CPU 时间 | 优先级 | 软件 |
| --- | --- | --- | --- |
| `short` | 10 分钟 | 最高 | 所有 |
| `medium` | 2 小时 | ↑ | 所有 |
| `long` | 200 小时 | | FORTRAN 和 SAS |
| `g92` | 300 小时 | 最低 | Gaussian 92 |

使用`lpr`命令用于在 Unix 中打印文件。命令格式为：

```
lpr [-options] 文件名(s)
```

常用的选项是指定打印机目标`-P`。（注意：这是一个大写`P`）。没有默认打印机。如果你想将`homework.sas`打印到计算实验室的打印机，命令为：

```
lpr -P fhprpl homework.sas
```

以下是常用打印机表：

| 打印机名称 | 位置 |
| --- | --- |
| `asprl` | 10 号艺术与科学 |
| `bpprl` | 7 号 Middlebush |
| `eepril` | 17 号工程综合 |
| `fhprpl` | 23 号 Heinkel 大楼 |
| `physprl` | 127 号物理 |
