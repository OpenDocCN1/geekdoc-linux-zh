## 第十一章：磁盘配额管理

> “电脑曾经在象棋上赢过我，但在踢拳比赛中，它完全不是我的对手。” --莫·菲IPS

## 限制用户磁盘使用

磁盘配额用于防止用户滥用磁盘空间。可以设置配额来限制用户、组或两者的磁盘使用情况。配额可以根据磁盘空间或文件数量来评估使用情况。

使用以下命令显示磁盘统计信息：

```
# df
```

`df` 显示可用磁盘空间量。

```
# du
```

`du` 汇总每个文件的磁盘使用情况。

## 使用磁盘配额

要使用磁盘配额，请执行以下步骤：

1. 验证磁盘配额 RPM。
2. 修改 `/etc/fstab` 以基于每个文件系统启用配额。
3. 重新挂载修改后的文件系统。
4. 准备配额文件，然后生成磁盘使用表。
5. 分配所需的配额。

### 验证磁盘配额 RPM 是否安装

运行以下命令：

```
# rpm -qa | grep quota
```

### 启用配额

作为超级用户（`root`），在 `/etc/fstab` 文件中为目标文件系统添加 `usquota` 和/或 `grpquota` 选项。例如：

`Label=/home/home ext3 defaults,usquota,grpquota 1 2` 在 `/home` 文件系统上启用用户和组配额。

### 重新挂载修改的文件系统

如果文件系统未被使用，使用 `umount` 和 `mount` 命令重新挂载修改后的文件系统，否则最简单的方法是重启系统。

### 准备配额文件

使用 `quotacheck` 命令检查启用了配额的文件系统。`quotacheck` 将建立一个表，显示每个文件系统现有的磁盘使用情况。该表用于更新操作系统关于磁盘使用情况的信息。此外，它还会更新文件系统的磁盘配额文件。

使用此命令准备配额文件：

```
# quotacheck -cug /home
```

`-c` 为每个启用了配额的文件系统创建一个配额文件，`-u` 检查用户配额，`-g` 检查组配额。（`/home` 选项将配额文件（`aquota.user` 和 `aquota.group`）放置在 `/home` 目录中。）

在创建配额文件后，使用以下命令生成基于每个文件系统的当前磁盘使用情况表：

```
# quotacheck -vug /home
```

（选项与之前相同，但 `-v` 仅显示详细输出。）

### 分配所需的配额

`edquota` 命令用于分配配额给用户或组：

```
# edquota /home
```

要为用户分配配额，使用以下命令：

```
# edquota [username]
```

要为组分配配额，使用：

```
# edquota -g [group]
```

`edquota` 打开编辑器，你可以在其中为用户设置 `soft` 和 `hard` 配额：

```
# edquota [username]
```

`soft` 值允许用户超过它，`hard` 值是绝对限制。

使用此命令设置宽限期：

```
# edquota -t
```

### 获取配额报告

`repquota` 显示用户的配额报告：

```
# repquota [point]
```

## 检查磁盘空间占用

在目录内部时，你可以使用 `du` 命令检查磁盘空间占用：

```
# du -h -c -s
```

`-h` 包含对显示数字是否代表千字节、兆字节等单位标识，`-c` 提供总计，`-s` 使其显示短格式（而不详细列出子目录）。

```
[root@instructor samba]# cd /etc
[root@instructor etc]# du -h -c -s
166M total
[root@instructor etc]# cd /common
[root@instructor common]# du -h -c -s
4.0K total
```
