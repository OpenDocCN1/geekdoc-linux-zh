### 13.1.1 一个类比

两个男孩每人有一盒乐高®积木。一套乐高积木可以搭建玩具船，另一套可以搭建玩具飞机。男孩们打开盒子，把里面的东西扔在地上，混在了一起。乐高积木的形状和颜色各不相同。两个盒子中都有黄色的方形块、红色的三角形块和蓝色的矩形块，但现在它们混在一起了，很难分辨哪些乐高积木应该用来搭建玩具船，哪些应该用来搭建玩具飞机。如果这些积木被保留在各自的盒子里，这种混乱本可以避免。

在 Perl 中，这些独立的盒子被称为 `package`（packages），而这些乐高积木被称为 `symbols`（symbols，即标识符的名称，如变量、子程序和常量）。将符号保留在你自己的私有包中，使得你可以在程序中引入库模块和例程，而不会导致你的变量命名与所包含的模块或库文件中的命名发生冲突。

### 13.1.2 什么是包？

将数据和函数封装到独立命名空间中称为 `encapsulation`（encapsulation），在 C++ 或 Java 等面向对象语言中，这被称为 `class`（class）。独立的命名空间被称为 Perl `package`（package），它提供了一种防止一个包中的变量干扰另一个包中的变量的方法。独立的命名空间意味着，除非它们是 `my`、`our` 或 `state` 变量，否则 Perl 为命名包中的标识符维护一个独立的符号表。默认情况下，当前的包被称为 `main` 包。至此为止的所有示例脚本都在 `main` 包中。现在是时候看看包机制是如何工作的，以便使用和创建库。

包的作用域是从包的声明开始到文件结束、最内层封闭块结束，或者直到声明另一个包。通常，包具有文件作用域。下面的示例展示了如何声明一个包。特殊的 `__PACKAGE__` 字面量显示当前包名：
