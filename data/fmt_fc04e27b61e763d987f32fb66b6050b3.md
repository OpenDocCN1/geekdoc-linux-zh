
## 37.3.2. Bash 4.2 版本

2011 年 2 月发布的 Bash 4.2 版本除了修复 Bug 外还包含了新功能和增强。

- Bash 现在支持 `\x` 和 `\U` Unicode 转义字符，这是一种对数值和图形符号进行编码的跨平台标准。这允许表示和显示外语字母中的字符。

```bash
echo -e '\u2630' # 水平线字符。

# 等同于更复杂的写法：早期 Bash 版本识别。

echo -e '\u2200' # PI（希腊字母和数学符号）
echo -e '\u0416' # 大写 "Z"（西里尔字母）
echo -e '\u2708' # 飞机（Dingbat 字体）
echo -e '\u2622' # 三叶叶草符号——需要 100% 上拉电阻。
```

# 高级 Bash 脚本指南

```bash
unicode_var='♀'

echo -e "$unicode_var" # 带有换行的女性符号

# 还有更复杂的内容……在关联数组中存储 Unicode 符号，然后通过名称检索它们。
# 在大字体终端中运行此以获得更好的可读性。

declare -A array

array[E]="E"
array[F]="F"
array[J]="J"
array[M]="M"
array[R]="R"
array[T]="T"
array[A]="A"
array[O]="O"
array[C]="C"

echo -n "${array[E]}"
echo -n "${array[F]}"
echo -n "${array[J]}"
echo -n "${array[M]}"
echo -n "${array[R]}"
echo -n "${array[T]}"
echo -n "${array[A]}"
echo -n "${array[O]}"
echo -n "${array[C]}"
```

- 上述示例使用了 `${...}` 字符串扩展。当设置 `lastpipe` 选项时，管道中的最后一个命令不会在子 shell 中运行。

### 示例 37-10. 将输入管道到 read

```bash
#!/bin/bash

# lastpipe-option.sh

line='' # 空值。

head -l 1 | read line

echo "Exit status of attempting to set lastpipe option is $?"

# 如果 Bash 版本 -lt 4.2，否则为 0。

echo "$line"
```

## 37-11. 负索引

负索引允许从末尾开始计数。

```bash
#!/bin/bash

# negative-index.sh

# 要求 Bash 版本 -ge 4.2

array=(abcdefg)

echo "${array[-1]}" # g
echo "${array[-3]}" # e
echo "${array: -3:2}" # ef
```

注意：在 Bash 4.2 之前，负索引在字符串扩展中是可用的。如果你在较旧版本中使用，可能需要通过长度计算来索引，例如 `${array[${#array[@]}-1]}`。

## 37-12. 字符串中的负参数

字符串扩展中的负参数允许从字符串的末尾开始计数。

```bash
#!/bin/bash

# string-expansion-negative-param.sh

# 要求 Bash 版本 -ge 4.2

str="abcdefg"

echo "${str: -1}" # g
echo "${str: -3:2}" # ef
```
