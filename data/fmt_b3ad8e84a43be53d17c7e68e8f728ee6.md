# 传输配置

本节描述了用于本地投递到用户邮箱的传输。在 Debian 系统中，群组邮件被设置为写入 `/var/sp/mail` 目录。本节还显示了别名（alias）和 `.forward` 文件如何使用管道。Autofs 也在此节处理。

```
local_delivery:
driver = appendfile
group = mail
mode = 0660
mode_fail_narrower = false
envelope_to_add = true
file = /var/pool/mail/$(local_part)
```

```
address_pipe:
driver = pipe
return_output
```

```
address_file: appendfile
driver = appendfile
```

```
address_directory:
driver = appendfile
no_from_hack
prefix = ""
suffix = ""
# maildirir_format
```

```
address_reply:
driver = autoreply
```

```
procmail_pipe:
driver = pipe
command = "/usr/bin/procmail -d ${local_part}"
return_path_add
delivery_date_add
envelope_to_add
check_string = "From"
escape_string = ">From "
user = $local_part
group = mail
```

```
remote_smtp:
driver = smtp
```

```
end
```

# 路由配置

本节控制本地邮件投递、别名设置和转发。驱动程序、位置和传输在此处设置。本地邮件将与本地用户的邮箱进行匹配。别名的位置在此设置，用户转发其邮件的文件也在此设置。

```
real_local:
prefix = real-
driver = localuser
transport = local_delivery
```

```
system_aliases:
driver = aliasfile
file_transport = address_pipe
pipe_transport = address_pipe
file = /etc/aliases
search_type = lsearch
# user = list
```

# 路由器配置

此路由设置了通过 SMTP 发送至本服务器托管域名之外的邮件。`lookuphost` 使用默认 DNS 查找域名，而 `literal` 选项使用精确的 IP 地址。

```
lookuphost:
driver = lookuphost
transport = remote_smtp
```

```
literal:
driver = ipliteral
transport = remote_smtp
```

end

# 重试配置

本节设置了重发邮件的规则。后续示例中的设置为每 15 分钟重发一次，持续两小时。两小时后，按 1.5 的倍数尝试重试，最多持续 16 小时。从第一次投递失败开始，每隔八小时尝试一次，持续四天。

```
# 域名错误重试
#
----------------------------------------------------
* * F.2h,15m; G.16h,2h,1.5; F.4d,8h
end
```

# 重写配置

本节指定了哪里查找本地用户的真实邮件地址，并在邮件中进行重写。这对于没有自己域名的用户非常有用。

```
*mail.mydomain.com $(lookup($1)search(/etc/email-($value)fail) bcrF
```
