
你的图形化桌面环境（很可能是 KDE 或 GNOME）为了表现得像 Windows，可能将它的焦点策略设置为“点击聚焦”。这意味着要让一个窗口获得焦点（变为激活状态），你需要点击它。这与传统的 X 行为“鼠标聚焦”相反，后者的意思是窗口只需通过鼠标经过它就能获得焦点。在您点击它之前，窗口不会移动到前台，但它能够接收输入。将焦点策略设置为“鼠标聚焦”将使复制粘贴技术变得更有用。如果可以的话请尝试一下（某些桌面环境如 Ubuntu 的 Unity 已不再支持它）。我认为如果你给它机会，你会更喜欢它。你可以在窗口器的配置程序找到此设置。

# 2 导航

- `cd` 切换目录
- `ls` 列出目录内容

## 理解文件系统树

与 Windows 类似，Unix 类操作系统（如 Linux）将文件组织在所谓的层次结构目录结构中。这意味着它们以类似于树的目录模式（在其他系统中通常称为文件夹）组织，目录中可以包含文件和其他目录。文件系统中的第一个目录被称为根目录。根目录包含文件和子目录，子目录包含更多文件和子目录，依此类推。

注意，与 Windows 不同（Windows 每个存储设备都有独立的文件系统树），像 Linux 这样的 Unix 类系统始终只有一个文件系统树，无论计算机连接了多少个驱动器或存储设备。存储设备根据系统管理员的喜愿挂载在树的各个点上（更准确地说是*挂载*）。

## 当前工作目录

虽然 shell 完全依赖键盘，但你也可以在终端模拟器上使用鼠标。X Window 系统（运行 GUI 的底层引擎）内置的一种机制支持快速复制粘贴技术。如果你通过按住鼠标左键并在文本上拖动鼠标（或双击某个单词）来选中某些文本，它就会复制到由 X 维护的缓冲区中。按下鼠标键会将文本粘贴到光标所在的位置。尝试一下吧。

不要在终端窗口中使用 CTRL-C 和 CTRL-V 来执行复制和粘贴。它们不起作用的。这些控制代码对 shell 来说有不同的含义，并且在微软 Windows 发布很多年前就已经被分配了。
