## 6.4 系统信息

`pwd`
打印工作目录，即在屏幕上显示我当前目录的名称。

`hostname`
打印本地主机名（即我正在工作的机器）。使用`hostname`（以 root 身份）可以更改机器名称。

`whoami`
打印我的用户名。

`id username`
打印用户 ID (`uid`) 和其/她的组 ID (`gid`)、有效 ID（如果与实际 ID 不同）以及补充组。

`date`
打印操作系统的当前日期、时间和时区。若要使用 ISO 标准格式，我必须使用：`date --iso`。我可以使用此命令将日期时间更改为 2000-12-31 23:57：`date 123123572000` 或使用以下两个命令（更易记忆）：

```
date --set 2000-12-31
date -s 23:57:00
```

设置硬件时钟
全数字日期/时间的国际 (ISO 8601) 标准格式（作为 root）；我可以使用（作为 root）类似于 Linux 默认 "C" 本地化的命令。如果你愿意，可以使用更更精确的形式：2 2001-01-31 23:59:59.999-05:00（代表 2001 年 2 月之前的 1 毫秒，时区比世界协调时 (UTC) 早 5 小时）。同一时间点最“标准”的表示可以是：20010131T235959.999-0500。标准参见 `ftp://ftp.ql.net/pub/g1sd/8601ov3.pdf`。

`time`
确定进程运行以及其他统计所需的时间。不要将其与 `date` 命令（上一项）混淆。例如，我可以使用 `time ls` 查看列出目录内容需要多久。或者我可以使用 `time sleep 10` 测试功能（该命令执行 10 秒内无操作）。

```
clock
hwclock
```

（两个命令，任其一即可）。从计算机硬件获取日期/时间（实时、电池供电的时钟）。你也可以使用这些命令之一设置硬件时钟，`hwclock` 可能更简单（参见上面的两个命令）。例如：`hwclock --systoc` 根据系统时钟设置硬件时钟（UTC 时间）。

`who`
确定登录在系统上的用户，查找他们在做什么，他们的处理器使用率 (%) 等。这是一个非常有实用的安全命令。

`rwho -a`
(-remote) 确定登录在你网络中其他计算机的用户。必须启用 `rwho` 服务才能运行此命令。如果没有启用，请以 root 身份进行设置（RedHat 特有）以启用 "rwho"。

`finger user_name`
关于用户的系统信息。尝试：`finger`。人们可以在任何向世界开放 `finger` 服务的联网计算机上使用 `finger`，例如，我可以执行（尝试）`finger@kernel.org`。

`last`
显示登录在你的系统上的用户列表。作为系统安全措施之一，定期检查它是非常棒的好主意。

`chmod o-r /var/log/btmp`

`history | more`
"| more" 会导致当前账户从命令行执行的最后 (1000) 条命令。要查看另一个用户在你的系统上的操作，请以 root 身份登录并检查其/她的 "history"。历史保留在主目录下的 `history` 文件中（是的，可以被修改或删除）。

`!command`
运行 `bash` 历史命令中以字符串 "command" 开头的最新命令。这会自动展开。

## 文件颜色含义

普通文件，绿色 = 可执行文件，洋红色 = 图片文件，红色 = 压缩（zip）文件，浅蓝色 = 符号链接，黄色 = 设备文件，黑色 = FIFO（先进先出）命名管道。

## 6.6 文件管理

`cd directory`
切换目录。使用 "cd" 而不带目录名将带你回到主目录。使用 "cd -" 会带你回到上一个目录，这是在目录间切换的方便方法。".." 会带你进入上一级目录（非常有用）。

`/program_name`
在当前目录运行可执行文件。当可执行文件不在我的 `PATH` 中时，需要加上 `/`。在 `PATH` 中的可执行文件只需直接使用：`program_name`

`shutdown -h now`
（以 root 身份）关闭系统并停止。主要用于远程关机。在控制台使用 `Ctrl<Alt>-Del` 关机（任何用户都可以执行）。

```
halt
reboot
it 6
```

（以 root 身份，三个命令）停止或重启机器。用于远程关机，比之前的命令更简单。如果计算机“死机”（我失去了对键盘的控制权），这也非常好：通过 `net it` 到网络上的另一台机器并进行远程重启。在本地计算机的控制台使用 `Ctrl<Alt>-Del` 进行正常关机。

`vlock`
（旧版本的 RedHat 不支持。）锁定本地（文本模式）终端。将文件复制到我的当前工作目录。-a 用于锁定所有终端（这并不是个好主意）。最好的办法可能是注销。在带有密码保护屏幕保护程序和锁定工具的 GUI 窗口管理器中，可以使用它（KDE 中带锁的小图标，键盘快捷键 `Ctrl<Alt>-l`）。

`cp source destination`
复制文件。例如，`cp /home/student/existing_file` 将一个文件复制到我的当前工作目录。`cp -R` 使用 "R" 选项（递归）复制整个目录树的内容，例如 `dir/` 将我当前目录下的子目录复制到我的主目录。

`mccopy source destination`

### 额外说明：波浪字符与目录

(波浪字符 `~`) 我的家目录（通常为 `/home/login_name`）。例如，命令 `cd ~/dir` 将你的工作目录更改为家目录下的子目录 `~/dir`。输入 "cd" 等同于命令 `cd ~`。我将所有文件都放在家目录下。

(点 `.`) 当前目录。例如，`/my_program` 将尝试执行位于你当前工作目录下的 "my_program" 文件。

(两个点 `..`) 当前目录的父目录。通常，`cd ..` 将你的当前工作目录向上移动一级。

## 额外的 KDE 键盘快捷键（有用但非必须）

- `<Alt+Tab>` 在窗口间切换。向后切换：`<Alt+Shift+Tab>`
- `<Ctrl+Tab>` 在虚拟桌面间切换。向后切换：`<Ctrl+Shift+Tab>`
- `<Ctrl+Esc>` 显示系统上运行的进程列表。允许我杀死我启动的任何进程（或向它们发送信号）。
- `<Alt+F1>` 访问 K-菜单（等同于微软的“开始”菜单）。
- `<Alt+F2>` 使用键盘上的方向键模拟鼠标。
- `<Alt+MouseButton>` 拖动窗口移动它。通常我通过拖动标题栏来移动窗口以移出屏幕。使用此快捷键，我可以拖动窗口的任何部分。
- `<Alt+PrintScreen>` 将当前窗口截图到剪贴板。
- `<Alt+PrintScreen>` 将整个桌面截屏到剪贴板。
- `<Alt+L>` 切换显示/隐藏桌面（当老板进来时隐藏纸牌游戏非常有用）。
