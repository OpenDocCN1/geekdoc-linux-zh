
`apt-get` 和 `yum` 安装器都会下载、安装并配置 JDK，无需用户执行任何额外任务。

## 编写和编译 Java 程序

Java 编程语言是编译型语言的一种，程序员编写源代码，然后将其提交给编译器。编译器无非一个帮助将源代码转换为字节码的程序。

生成的字节码将通过 JRE 执行。你可以使用任何文本编辑器编写 Java 源代码，例如 Windows 中的记事本，以及 Linux 中的 `pico` 或 `nano` 编辑器，这些器用于编辑源代码文件。要开始 Java 程序，请遵循以下步骤：

- 在 Linux 中打开 shell 提示符（shell prompt）。你也可以通过在 Linux 中按下 `ALT+Ctrl+T` 实现这一点。
- 使用 `gedit` 程序创建一个新文件，只需输入：
```
gedit HelloUniverse.java
```
`gedit` 程序将打开并创建一个文件。
- 输入你的 Java 源代码。
- 完成源代码后，确保已已保存。
- 退出 `gedit` 程序。
- 现在是使用 `javac` 编译器编译程序了。命令为：`javac HelloUniverse.java`
- 如果语法没有错误，编译器将顺利运行。
- 现在你可以通过运行 `Java` 然后加上程序名来运行你创建的示例程序。

Java 编程还包含另一个名为 `class` 的组件。它是一个大型函数集合，根据可能处理的各种数据的模板执行各种工作。在刚才提到的程序示例中，`HelloUniverse` 就是程序的类。

## 在 Linux 上使用 BASH 编写脚本

`BASH` 是一种命令语言的解释器。它广泛存在各种类型的操作系统，并作为大多数 Linux 或 GNU 系统的默认命令解释器。`BASH` 与 `shell` 配合工作。`shell` 无非一个宏处理器，允许以非交互式或交互式形式执行命令。在 `BASH` 中，脚本允许执行自动命令，而这些命令在其他情况下将以交互式形式逐个执行。

## Bash Shell 基础

`shell` 允许用户通过命令与计算机交互。它还有助于存储和检索数据、处理信息以及许多其他任务。例如，你可以输入 `cal`、`date`、`pwd` 或 `ls` 等命令并按回车键。你刚刚所的操作是通过 `shell` 与系统交互以获取当前日期和时间。这是通过使用 `date` 完成的，通过 `cal` 检查日历，通过 `pwd` 查看你当前所在目录的位置，然后通过 `ls` 获取该目录下目录和文件的完整列表。

## 什么是脚本？

为了正确理解脚本，首先结合 `shell` 和你使用的文本编辑器（如 `.vi`）创建一个名为 `task.sh` 的新文件，该文件包含上述所有命令，每个命令占一行。完成后，你需要使用 `chmod` 命令配合 `+x` 选项使新文件变为完全可执行。最后，你只需要在名称前加上 `./` 来执行新脚本。

通过使用正确的脚本，任何形式的 `shell` 交互都可以脚本化并自动化。现在还可以通过 `cron` 时间调度器每天在你指定的任何时间自动执行新的 `shell` 脚本 `task.sh`，并在每次执行时将脚本输出存储到特定文件中。

## BASH 基础

到目前我们讨论了 `shell` 和脚本。但是，`BASH` 呢？正如我们之前讨论过的，`BASH` 是一种默认形式的解释器用于许多基于 Linux 或 GNU 的系统。这就是为什么我们的上一个 `shell` 脚本在没有定义 `bash` 为最终解释器的情况下也能运行的原因。要查找默认的解释器是什么，你可以执行此命令：

```
$ echo $SHELL
/bin/bash
```
