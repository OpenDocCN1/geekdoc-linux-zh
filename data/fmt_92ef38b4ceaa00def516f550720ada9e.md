
在 GNOME 桌面上打开任何文件夹、文件或目录，它都会在一个名为 `Nautilus` 文件管理器的窗口中打开。该应用程序内置于 `Fedora Linux for GNOME` 中，可以帮助你轻松、高效地访问和控制以文件、文件夹和目录形式存在的信息。`Nautilus` 文件管理器还可以帮助你使用特定的应用程序打开文件。在本节中，你将学习如何使用 `Nautilus` 文件管理器。让我们先一起用 `Nautilus` 文件管理器创建一个新文件夹。

## 创建新文件夹

你可以使用 `Nautilus` 文件管理器轻松地创建一个新文件夹来存储信息。请按照以下步骤使用 `Nautilus` 文件管理器创建一个新文件夹：

1. 双击 GNOME 桌面上的文件夹图标。在我们的示例中，我们选择了 `kogent` 的 Home（家）文件夹，如图 `Linux-4.52` 所示。

   ![](img/12ecf7a0767a6080881fb04f59162115_83_0.png)

   `kogent` 的 Home 文件夹在 `Nautilus` 文件管理器窗口中打开（图 `Linux-4.53`）。

2. 点击 `kogent` `Nautilus` 文件管理器窗口中的“File”（文件）菜单。会出现一个下拉菜单（图 `Linux-4.53`）。

3. 从下拉菜单中选择“Create Folder”（创建文件夹）选项（图 `Linux-4.53`）。

4. 按键盘上的 ENTER 键。

   在 `kogent` `Nautilus` 文件管理器窗口中创建了一个名为 `untitled folder`（未命名文件夹）的新文件夹（图 `Linux-4.54`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_83_1.png)

在创建新文件夹后，让我们重命名该文件夹。

## 重命名文件夹

你也可以使用 `Nautilus` 文件管理器更改已创建的文件或文件夹的名称。请按照以下步骤重命名文件夹：

1. 选择你想要重命名的文件夹。在我们的示例中，我们选择了 `untitled folder`（图 `Linux-4.55`）。

2. 点击菜单栏上的“Edit”（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.55`）。

3. 从下拉菜单中选择“Rename”（重命名）选项（图 `Linux-4.55`）。

   为 `untitled folder` 输入所需的名称。在我们的示例中，我们输入了 `Network` 作为文件夹的名称（图 `Linux-4.56`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_84_0.png)

   `untitled folder` 已重命名为 `Network`。

让我们学习如何将文件复制到文件夹。

## 将文件复制到文件夹

你可以通过两种方法向文件夹添加文件：在应用程序中创建新文件并将其保存到文件夹，或者从其他文件夹复制文件到该文件夹。在本节中，你将学习将文件复制到 `Documents`（文档）文件夹。

请按照以下步骤将文件复制到文件夹：

1. 选择你想复制的文件。在我们的示例中，我们选择了 `brasero.iso` 文件（图 `Linux-4.57`）。

2. 点击菜单栏上的“Edit”（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.57`）。

3. 从下拉菜单中选择“Copy”（复制）选项，如图 `Linux-4.57` 所示。

   ![](img/12ecf7a0767a6080881fb04f59162115_84_1.png)

   你现在需要打开你想粘贴文件的文件夹。在我们的示例中，我们打开了 `Network` 文件夹。

4. 点击 `Network` 窗口中的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.58`）。

5. 从下拉菜单中选择 **Paste**（粘贴）选项（图 `Linux-4.58`）。

   选中的文件 (`brasarero.iso`) 已复制到 `Network` 文件夹中（图 `Linux-4.59`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_85_0.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_85_1.png)

## 移动文件和文件夹

移动是指从一个文件夹删除文件或文件夹并将其放在另一个文件夹中。

请按照以下步骤移动文件：

1. 选择你想移动的文件。在我们的示例中，我们选择了位于 `kogent` 文件夹中的 **brasarero.iso** 文件（图 `Linux-4.60`）。

2. 点击菜单栏上的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.60`）。

3. 从下拉菜单中选择 **Cut**（剪切）选项。我们选择了任何位置的文件，你需要点击 home 窗口中的 `Documents` 文件夹（在我们的示例中，home 窗口是 `kogent`）。`Documents` 文件夹在 `Nautilus` 中打开（图 `Linux-4.61`）。

4. 点击菜单栏上的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.61`）。

5. 从下拉菜单中选择 **Paste**（粘贴）选项（图 `Linux-4.61`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_85_2.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_85_3.png)

   选中的文件从原始位置移动并出现在 `Documents` 文件夹中（图 `Linux-4.62`）。

   移动文件后，让我们学习移动文件夹。请继续后续步骤：

6. 选择你想移动的文件夹。在我们的示例中，我们选择了 `Templates` 文件夹（图 `Linux-4.63`）。

7. 点击菜单栏上的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.63`）。

8. 从下拉菜单中选择 **Cut**（剪切）选项（图 `Linux-4.63`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_86_0.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_86_1.png)

9. 双击 `Documents` 文件夹打开该文件夹（图 `Linux-4.63`）。

10. 点击菜单栏上的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.64`）。

11. 从下拉菜单中选择 **Paste**（粘贴）选项（图 `Linux-4.64`）。

    选中的文件夹已粘贴到 `Nautilus` 窗口的 `Documents` 文件夹中（图 `Linux-4.65`）。

### 为文件或文件夹创建链接

创建链接或目录允许你从原始位置以外的地方打开文件或文件夹。

请按照以下步骤为文件或文件夹创建链接：

1. 选择你想要创建链接的文件或目录。在我们的示例中，我们选择了 `Nautilus` 窗口上显示的 `Documents` 文件夹中的 `mini.txt` 文件（图 `Linux-4.66`）。

2. 点击 `Nautilus` 窗口中的 **Edit**（编辑）菜单。会出现一个下拉菜单（图 `Linux-4.66`）。

3. 从下拉菜单中选择 **Make Link**（创建链接）选项（图 `Linux-4.66`）。

   `Nautilus` 窗口中创建了 `mini.txt` 文件的链接（图 `Linux-4.67`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_87_0.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_87_1.png)

4. 将鼠标指针置在 `Nautilus` 窗口的右上角（图 `Linux-4.68`）。

5. 拖动鼠标指针以缩小 `Nautilus` 窗口的大小。当缩小到足够让 GNOME 桌面可见时，释放鼠标按钮（图 `Linux-4.68`）。

6. 将鼠标指针置在 `Nautilus` 窗口中的 `Link to mini.txt` 图标上（图 `Linux-4.69`）。

7. 拖动鼠标指针。当你拖动鼠标指针时，链接的阴影也会随着鼠标指针移动（图 `Linux-4.69`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_87_2.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_87_3.png)

8. 当指针在桌面上时释放鼠标。链接已复制到桌面（图 `Linux-4.70`）。

## 打开文件

正如你所知，`Nautilus` 文件管理器允许你使用特定的文本编辑器打开文件。现在让我们学习如何打开 Linux 中的文件。

请按照以下步骤打开文件：

1. 在 `Nautilus` 文件管理器中选择你想打开的文件。在我们的示例中，我们选择了 `Documents` 文件夹中的 `mini.txt` 文件（图 `Linux-4.71`）。

2. 点击菜单栏上的“File”（文件）菜单。会出现一个下拉菜单（图 `Linux-4.71`）。

3. 从下拉菜单中选择“Text Editor”（文本编辑器）选项（图 `Linux-4.71`）。`mini.txt` 文件在 `gedit` 文本编辑器中打开（图 `Linux-4.72`）。

4. 点击 `gedit` 文本编辑器的关闭按钮关闭窗口（图 `Linux-4.72`）。

如果你是 `root` 用户登录的，可以在 Linux 中打开并操作文件。如果你不是以 `root` 用户身份登录，你只能访问你拥有权限的文件。

## 使用应用程序打开文件

你已经知道，`Nautilus` 文件管理器允许你使用特定的文本编辑器打开文件。现在让我们学习使用 `KWrite` 应用程序打开文件。这是一个图形用户界面（GUI）文本编辑器，通常用于程序和纯文本文件。

请按照以下步骤使用应用程序打开文件：

1. 在 `Nautilus` 文件管理器中选择你想用应用程序打开的文件。在我们的示例中，我们选择了 `mini.txt` 文件（图 `Linux-4.73`）。

2. 点击菜单栏上的“File”（文件）菜单。会出现一个下拉菜单（图 `Linux-4.73`）。

3. 从下拉菜单中选择“Open with”（打开方式）选项。会出现一个子菜单（图 `Linux-4.73`）。

4. 从子菜单中选择“Open with KWrite”（使用 KWrite 打开）选项（图 `Linux-4.73`）。

5. 点击 `KWrite` 窗口的关闭关闭窗口（图 `Linux-4.74`）。

2. 点击菜单栏上的“编辑”（Edit）菜单。会出现一个下拉菜单（图 `Linux-4.76`）。

## 永久删除文件

当你删除文件时，它会从原始位置移除并存储在桌面的垃圾箱文件夹中。垃圾箱存储所有已删除的文件。要从系统中永久删除文件，你需要从垃圾箱中删除它。

执行以下步骤永久删除文件：

1. 双击桌面上的垃圾箱文件夹（图 `Linux-4.83`）。打开垃圾箱窗口（）。

2. 选择要永久删除的文件。在例中，我们选择了 `mini.txt` 文件（图 `Linux-4.84`）。

3. 右键点击选中的文件。出现右键菜单（图 `Linux-4.84`）。

4. 从右键菜单中选择“永久删除”（Delete Permanently）（图 `Linux-4.84`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_91_2.png)

   ![](img/12ecf7a0767a6080881fb04f59162115_91_3.png)

   出现一个对话框确认删除（图 `Linux-4.85`）。

5. 点击“删除”（Delete）按钮（图 `Linux-4.85`）。

   选中的文件被永久删除（图 `Linux-4.86`）。

   ![](img/12ecf7a0767a6080881fb04f59162115_92_0.png)
