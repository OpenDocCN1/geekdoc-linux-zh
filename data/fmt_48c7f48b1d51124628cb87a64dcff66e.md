如你所见，`ftp` 有许多命令。然而，你实际上只需要关注你最常用的那些。

### 启动 FTP 会话

`open` 命令用于与远程主机建立 FTP 会话。其语法如下：

```
open hostname
```

如果你在 FTP 会话期间需要连接到多个站点，通常需要此此命令。如果你只想在会话期间连接一台计算机，只需在命令行中将远程主机名作为 `ftp` 命令的参数即可。

### 结束 FTP 会话

`close`、`disconnect`、`quit` 和 `bye` 命令用于结束与远程计算机的 FTP 会话。相同的 `close` 和 `disconnect` 命令会关闭与远程计算机的连接，让你留在本地计算机的 `ftp` 程序中。`quit`、`exit` 和 `bye` 命令会断开与远程计算机的活动连接，并退出你计算机上的 `ftp` 程序。

### 更改目录

`cd [directory]` 命令用于更改远程计算机上的目录。`cd ..` 命令将你带到父目录。`lcd` 命令更改你的本地目录，以便指定本地文件的存放位置。

### 远程目录列表

`ls` 命令列出远程目录的内容，就像交互式 shell 一样。`ls` 的语法如下：

```
ls [directory] [local_file]
```

如果作为参数指定了目录，它将列出该目录的内容。如果给了本地文件名，目录列表将输出到你本地计算机上指定的文件中。

`dir` 和 `ls` 命令提供详细列表，显示权限、大小、所有者日期。`dir` 命令的语法如下：

```
dir [directory] [local_file]
```

### 从远程系统获取文件

`get` 和 `mget` 命令用于从远程计算机检索文件。`get` 的语法如下：

```
get [filename]
```

如果作为参数指定了目录，`ls` 将列出该目录的内容。如果给了本地文件名，目录列表将输出到你本地计算机上指定的文件中。

`mget` 命令一次性检索多个文件。`mget` 的语法如下：

```
mget [filename]
```

### 向远程系统发送文件

`put` 和 `mput` 命令用于向远程计算机发送文件。`put` 的语法如下：

```
put [filename]
```

`mput` 命令发送一系列文件。`mput` 的语法如下：

```
mput [filename]
```

### 更改传输模式

除非你指定其他模式，否则 `ftp` 将文件传输为 ASCII 文件。这对于纯文本是可以的，但会导致任何二进制数据失效。`ascii` 和 `binary` 命令设置传输模式，以防止损坏你的二进制文件。

许多你想要传输的文件都是二进制格式。以 `.tar` 结尾的文件使用 `tar` 命令创建。以 `.z` 和 `.gz` 结尾的文件分别使用 `compress` 命令或 GNU `gzip` 命令压缩。压缩包中的文件使用 `PKZIP` 创建。如果不确定，请使用二进制传输模式。
