# loadfont — 显示或更改 X86 显卡字体信息

### 概要

`/bin/loadfont [-f BDF-file | -c codeset] [-m mode] [-d]`

## 描述

`loadfont` 命令允许你通过文本模式下 x86 系统的 Solaris 控制台将不同的字体加载并激活到显卡的 RAM 中。你也可以使用 `loadfont` 显示当前使用的字体信息。此外，你可以使用 `-m` 选项更改屏幕上字符的大小和每屏行数。`loadfont` 始终从标准输出读取；此功能允许系统管理员从远程终端使用它。

如果不带参数使用，`loadfont` 将显示该命令的不同用法，如概要所示。

> 注意 — 系统的默认字体是 ISO 8859-1 集。可选的 IBM DOS 437 集仅在国际化级别 1 下支持。也就是说，如果你选择下载可选 IBM DOS 437 集的字体，则不支持非标准的美国日期、时间、货币、数字、单位和排序规则。不支持多字节字符支持。

## 选项

```
-f BDF-file
```

读取 `BDF-file` 的内容并将指定的字体加载到显卡的 RAM 中。文件必须是 Adobe Systems, Inc. 开发的 2.1 版本分发格式（参见 `loadfont(4)`）。

- `-c charset` 指定可用字符集的名称。该字体将加载到显卡的 RAM 并激活。使用 `?` 查看可用字符集。此选项是 `-f` 的简写形式。
- `-m mode` 以指定的模式更改字体大小和/或屏幕行数。
- `-d` 从 RAM 读取字体信息并写入标准输出。使用 `?` 查看可用模式。

# loadfont 和 pmapkeys

`loadfont` 命令与 `pmapkeys` 命令之间几乎存在一对一的关系。`loadfont` 列出或修改与各种字符对应的图像，而 `pmapkeys` 命令决定如何从键盘生成字符并使用（单字节）来表示字符。默认表示法是不同的字符集，需要不同的 `pmapkeys` 输入文件和不同的字体。如果默认字体不能满足你的希腊语需求，你需要一个配合 `-f` 选项使用的 `loadfont` 描述文件。描述 8x16 分辨率 IBM 扩展字体的示例文件 (`/usr/share/lib/fonts/437.bdf`)。第二个示例文件 `/usr/share/lib/fonts/646g.bdf` 包含德国 ASCII 的字体文件。更多细节请参见 `pmapkeys(1)` 和 `loadfont(4)`。

# loadkeys, dumpkeys — 加载和导出键盘布局

转换表

### 概要

```
/usr/bin/loadkeys [filename]
/usr/bin/dumpkeys
```

## 描述

`loadkeys` 读取由 `filename` 指定的文件并修改键盘流（streams）模块的转换表。如果你未指定文件且键盘为 Type-4 键盘，则使用由键盘上 DIP 开关指示的布局的对应的默认文件。该文件格式由 `keytables(4)` 规定。

默认情况下，`loadkeys` 加载文件

`/usr/share/lib/keytables/type_tt/layout_dd`

其中 `tt` 是由 `KIOCT` ioctl 返回的值，`dd` 是由 `KIOCLAYOUT` ioctl 返回的值（参见 `kb(7)`）。对于自识别的键盘，由 `KIOCLAYOUT` ioctl 返回的值由 DIP 开关设置。这些文件仅指定了不同 Type-4 键盘之间发生变化的条目。

`dumpkeys` 将键盘流模块转换表的当前内容输出到标准输出，格式由 `keytables(4)` 规定。

key 3 all lf(2)
key 4 all hole
key 5 all tf(1)
key 6 all tf(2)
key 7 all tf(10)

key 9 all tf(11)

# locale — 获取特定区域设置的信息

### 概要

```
/usr/bin/locale -a [-m]
/usr/bin/locale [-ck] name...
```

## 描述

`locale` 命令向标准输出写入关于当前区域设置环境或所有公共区域设置（public locales）的信息。对于此命令，公共区域设置由实现提供，应用程序可以访问。

当你不带任何参数使用 `locale` 命令时，它会根据环境变量的设置，为每个区域设置类别总结当前的区域设置环境。如果环境变量 `LANG` 设置为如下格式

```
LANG=locale_x LC_COLLATE=locale_y
```

```
locale 以以下格式显示结果：
locale_x
LC_CTYPE=locale_x
LC_NUMERIC=locale_x
LC_TIME=locale_x
LC_COLLATE=locale_y
LC_MONETARY=locale_x
LC_MESSAGES=locale_x
LC_ALL=
```

当你指定操作数时，`locale` 会写入分配给区域设置类别中关键字的值，如下：

- 指定关键字名称将选择指定的关键字以及包含该关键字的类别。
- 指定类别名称将选择指定的类别以及该类别中的所有关键字。

> 注意 - 如果你指定 `LC_TYPE` 或范围在 0x00-0x7f 的关键字，则只显示该范围的值。

如果你指定 `LC_COLLATE` 或类别 `LC_COLLATE` 中的关键字，则不会写入任何实际值。

## 选项

- `-a` 写入关于所有可用公共区域设置的信息。可用区域设置包括 POSIX，代表 POSIX 区域设置。
- `-c` 写入所选区域设置类别的名称。当你指定多个类别时（例如，多个关键字或类别名称），`-c` 选项可以增加可读性。它无论是否配合 `-k` 选项均有效。
- `-k` 写入所选关键字的名称和值。实现可以省略某些关键字的值。
- `-m` 写入可用字符映射表的名称；参见 `localedef(1)`。

### 操作数

- `-name` 指定区域设置类别名称（如 `LC_NUMERIC`）、区域设置类别中的关键字名称（如 `decimal_point`）或预留名称字符映射（`charmap`）。指定的类别或关键字将用于输出。如果单个名称同时代表区域设置类别和当前区域设置中的关键字，则结果是不指定的；否则，你可以以任何顺序指定类别和关键字名称。
