
# 经纬仪与卫星定位

经纬仪的主要用途是测量水平角和竖直角。使用一个垂直圆和一个水平圆来进行这些测量。这些圆盘由金属或玻璃制成，表面刻有或蚀刻有精确的刻度。通常使用分划板来提高圆盘读数的精度。全站仪具有与经纬仪相同的目的，且它们有许多相似的特性。主要区别在于，全站仪的测量圆盘仅由玻璃制成，并通过放大光学系统观测以提高角度读数的精度。电子全站仪使用电子读数圆盘取代光学读数的圆盘。参见分划板。

美国国防部安装了一个被称为全球定位系统的卫星系统，用于导航以及确定飞机、船舶、车辆等的位置。该系统使用特殊的接收器和软件来计算接收器的经度和纬度。在项目早期发现，两个静止接收器之间的距离可以非常精确地确定，并且接收器之间的距离可以相隔数英里。这项技术已成为高精度控制测量的标准，但由于精密接收器的费用、设置所需时间以及过程的复杂性，尚未普遍使用。参见卫星导航系统；测量。 [K.W.K.]

## 电纳

交流电路导纳的虚部。

![电纳图 1](img/2cf7974cd6027baa297e5cd95d3d6d43_2183_0.png)

![电纳图 2](img/2cf7974cd6027baa297e5cd95d3d6d43_2183_1.png)

交流电路的导纳 `Y` 是一个复数，由方程(1)给出。虚部 `B` 即为电纳。电纳的单位与导纳相同，称为西门子或姆欧。电纳可以是正或负。例如，频率为 `ω` 的电容器 `C` 的导纳由方程(2)给出，因此 `B` 为正。对于电感 `L`，导纳由方程(3)给出，因此 `B` 为负。

```
Y = G + jB                                      (1)

Y = jC\omega = jB                                (2)

Y = \frac{j}{L\omega} = jB                    (3)
```

通常，电路的电纳不仅取决于电容和电感，还取决于电阻。例如，图示电路的阻抗由方程(4)给出，导纳由方程(5)给出，因此电纳由方程(6)给出，它取决于电阻 `R` 以及电感 `L`。

```
Z = R + jL\omega                                    (4)

Y = \frac{1}{R + jL\omega}                           (5)

B = \frac{-L\omega}{R^2 + L^2\omega^2}               (6)
```

参见导纳；交流电路理论；电阻抗。

## 沼泽、湿地和泥炭地

潮湿的平地，其中中湿生植物（mesophytic vegetation）实际上比开阔水面更重要，这些地区通常形成于填平的湖泊、冰川坑和溶蚀洼地，或排水不良的沿海平原或洪泛平原。“沼泽”一词通常用于树木和灌木是植被群落重要组成部分的湿地，而“泥炭地”（bog）暗示缺乏坚实基底。有些泥炭地由漂浮在水上的厚植被层组成。

独特的植物群落在不同气候下的湿地中具有特征，并围绕边缘表现出明显的分带特性，响应坚实土壤基底之上饱和区不同厚度。所有大陆上常见被适应盐水的植被覆盖的沿海湿地。据推测，其中许多起源于更新世后期海平面上升导致的近期淹没。参见冰川地形；红树林。

## 汗腺

一种存在于哺乳动物体内的盘管状腺体。有两种类型：顶分泌型或外分泌型（merocrine or eccrine）以及顶浆分泌型（apocrine）。后者通常与毛囊相关（见插图）。外分泌型汗腺在人体中广泛分布，而顶浆分泌型则局限于头皮、乳头、腋窝、外耳道、外生殖器和肛门周围区域。除黑猩猩和人类外，顶浆分泌型汗腺在哺乳动物中更为常见，而在这些物种中，外分泌型占主导地位。乳腺可能代表一种向内生长并增加复杂度的改造顶浆分泌型汗腺。参见腺体；乳腺。

## 枫香

树 *Liquidambar styraciflua*，也称为红胶树，是一种落叶乔木，分布于美国东南部。它向北延伸至康涅狄格州西南部，也生长在中美洲。枫香很容易通过其五裂或星形的叶子以及小枝上通常发育的螺旋状翅或脊来识别。直立的树干呈深灰色，但枝条颜色较浅。冬季，持久的带刺球果是一个极佳的诊断特征。

枫香用于家具、室内装修、铁路枕木、雪茄盒、板条箱、地板、桶、木制品和木浆，它是胶合板制造最重要的材料之一。枫香是最理想的观赏树木之一，主要因其亮丽的秋色。参见悬垂理想（注：原文HANGING-IDEALES可能为笔误，通常指相关树种或特征，此处直译）。

## 鱼鳔

大多数硬骨鱼类（Osteichthyes）体腔内发现的气体填充囊。鱼鳔在不同鱼类中具有不同功能，作为提供浮力的浮囊、作为肺、作为助听器以及作为发声器官。在许多鱼类中，它同时发挥其中两种或三种功能，在非洲和亚洲的刀鱼（*Notopterichthys*）中，它可能同时发挥所有四种功能。鱼鳔中含有与空气成分相同的气体，但比例往往不同。

## 开关电路

开关或数字数据处理系统中组成电路的一部分，它以编码形式接收、存储或操纵信息以实现系统指定的目标。示例包括数字计算机、拨号电话系统以及自动会计和库存系统。参见[数字计算机](https://example.org/DIGITAL_COMPUTER)；[交换系统（通信）](https://example.org/SWITCHING_SYSTEMS)；[开关理论](https://example.org/SWITCHING_THEORY)。

在物理上，开关电路由互连离散值电气器件的导电路径组成。最常使用的开关电路器件是二值或二进制的，例如通过手动或机电驱动打开和关闭电触点的开关和继电器；真空管和充气管，以及半导体整流器和晶体管（它们导电或不导电）；以及磁性结构（它们可以在两个方向上饱和）。

控制这些开关电路器件的电气条件通常也是二值或二进制的，例如路径断开与闭合、全电压与零电压、大电流与小电流，以及高电阻与低电阻。这种二值电气条件，当应用于开关电路的输入时，代表以下之一：(1) 存在或不存在的事件或情况的组合；(2) 按特定顺序发生的事件或情况的序列；或 (3) 事件或情况的组合与序列。开关电路通过对输出（同样以二值形式）提供与输入信息在功能上相关的新信息来响应该输入。

开关电路的功能特性由组装它们的离散器件的逻辑操作和记忆能力，以及互连这些器件的方式定义。例如，开关电路体现这样的逻辑关系：输出 X 仅当输入 A 和 B 同时出现时才存在；输出 Y 仅当输入 A 或输入 B 任一出现时才存在。反过来，记忆因素使开关电路能够在产生该状态的条件消失后保持或保留特定状态。

### 基本组合电路

组合开关电路是指特定的一组输入条件始终建立相同输出，而与电路的历史无关的电路。

在电子开关电路中，所谓的门用于执行等效于开关触点串并联网络的逻辑功能。从这个意义上说，电子门是一个基本组合电路。门不是通过物理插入或移除手动操作开关或远程控制继电器触点之间的金属导电路径来工作的。相反，它们通过控制其输出的电压或电流电平来工作。

最常遇到的门是与门和或门。与门仅当其所有输入同时存在时才产生输出；或门在其任一输入或任意组合输入存在时产生输出。参见[逻辑电路](https://example.org/LOGIC_CIRCUITS)。

### 基本时序电路

时序开关电路是指其输出不仅取决于输入的当前状态，还取决于过去输入条件的电路。因此，时序电路需要存储元件。

时序电路中使用的典型电子电路元件是一种称为触发器的简单电路。触发器由两个放大器组成，连接方式使得一个放大器的输出是另一个放大器的输入。电压脉冲将使触发器进入两种状态之一，该状态保持直到另一个电压脉冲重置触发器或使其返回原始状态。因此，它可以用于记住某事件已经发生。

图 1 是一个 npn 晶体管触发器。当置位时，晶体管 A 导通，晶体管 B 截止。当复位时，晶体管 B 导通，晶体管 A 截止。可以从任一晶体管获得相对于地的正向输出电压，以指示触发器的状态。参见[晶体管](https://example.org/TRANSISTOR)。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_2184_1.png)

继电器、触发器和类似的存储元件提供静态或固定存储；它们无限期地保持存储的信息，或者直到被指示“忘记”（通常称为“复位”）。相比之下，延迟线提供瞬时存储。延迟线具有这样的特性：施加于其输入端的电信号在通往输出端的途中会被延迟。
