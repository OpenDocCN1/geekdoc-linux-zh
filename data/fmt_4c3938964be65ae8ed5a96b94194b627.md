
汇编是将你输入的内容转换为机器指令的过程。机器本身只读取数字序列，但人类更倾向于使用单词。汇编语言是一种更具人类可读性的形式。

# 第 3 章 你的第一个程序

## 输入命令

```bash
./exit
```

`/`用于告诉计算机程序不在普通目录中，而是在当前目录。你会发现当你输入这个命令时，唯一发生的事情就是你到了下一行。

那是因为这个程序除了退出什么都不做。然而，在你运行程序后，立即，如果你输入

```bash
echo $?
```

它会显示 `0`。如果每个程序在退出时都给 Linux 一个状态码，这会告诉它一切是否都正常。如果一切正常，它返回 `0`。UNIX 程序返回非零的其他数字来表示失败或其他错误或状态。程序员决定每个数字的含义。你可以通过输入来查看此代码。在接下来的章节中，我们将查看代码的每个部分的作用。

## 汇编程序大纲

看看我们刚刚输入的程序。开头有许多行以井号（`#`）开头的行。这些是注释。汇编器不会翻译注释。它们仅供程序员与未来任何查看代码的人交流。你编写的大多数程序都会被他人修改。养成在代码中编写注释的习惯，这将帮助他们理解程序为什么存在以及它是如何运行的。始终在你的注释中包含以下内容：

- 代码的目的
- 涉及的处理过程概述
- 你的程序执行的任何奇怪操作以及为什么不这样做

注释之后，下一行写着

`.section .data`

任何以点开头的内容都不会被直接翻译成机器指令。相反，它们是对汇编器本身的指令。这些被称为*汇编器直接指令或伪操作*，因为它们由汇编器处理，而实际上不会由计算机运行。`.section`命令将你的程序拆分为若干段。此命令启动数据段，你可以在其中列出数据所需的任何内存存储空间。我们的程序没有使用任何这些空间，所以我们不需要该段。它在这里仅仅是为了完整性。你未来编写的几乎每个程序都会包含数据。

紧随其后的是

`.section .text`

它启动文本段。程序的文本段是程序指令所在的地方。

下一条指令是

`.glob _start`

这条指令指示汇编器`_start`是需要的。`_start`是一个符号，意味着它在汇编或链接过程中会被替换为其他内容。符号通常用于标记程序或数据的位置，因此你可以通过名称而不是位置编号来引用它们。想象一下，如果你必须通过地址来引用每个内存位置。首先，这会非常困惑，因为你必须记忆或查找每段代码或数据的数字地址。此外，每当你需要插入一段数据或代码时，你就必须更改程序中的所有地址！符号的使用是为了让汇编器和链接器负责地址跟踪，而你可以专注于编写程序。

`.glob`意味着汇编器在汇编后不要丢弃这个符号，因为链接器需要它。`_start`是一个特殊的符号，总是需要用`.glob`标记，因为它标记了程序开始的位置。如果不以此方式标记该位置，当计算机加载你的程序时，它将不知道从哪里开始运行你的程序。

下一行

`_start:`

定义了`_start`标签的值。标签是后面跟着冒号的符号。标签定义了符号的值。当汇编器汇编程序时，它必须为每个数据值和指令分配一个地址。标签告诉汇编器将符号的值设置为下一条指令或数据元素所在。这样，如果数据或指令的实际物理位置发生了变化，你就不需要重写对它的任何引用——符号会自动获得新值。

现在我们进入真正的计算机指令。第一条这样的指令是：

```
movl $1, %eax
```

当程序运行时，这条指令将数字 `1` 传输到`%eax`寄存器。在汇编语言中，许多指令都有操作数。`movl`有两个操作数——源和目的。在这种情况下，源是字面量数字 `1`，目的是`%eax`寄存器。操作数可以是数字、内存位置引用或寄存器。不同的指令允许不同类型的操作数。关于哪些指令接受什么类型的操作数的更多信息请参见附录 B。

在大多数具有两个操作数的指令中，第一个是源操作数，第二个是目的操作数。注意在这些情况下，源操作数完全没有被修改。这种类型的其他指令例如：`add`、`subl`和`imull`。这些指令将源操作数加/减/乘到/或乘以目标操作数，并将结果保存在目标操作数中。其他指令可能硬编码了一个操作数。例如，`idivl`要求被除数在`%eax`中，且`%edx`为零，然后将商数传输到`%eax`，余数传输到`%edx`。然而，除数可以是任何寄存器或内存位置。

在 x86 处理器上，有几个通用寄存器（所有的都可以配合`movl`使用）：

- `%eax`
- `%ebx`
- `%ecx`
- `%edx`
- `%edi`
- `%esi`

除了这些通用寄存器，还有几个特殊用途寄存器，包括：

- `%ebp`
- `%esp`
- `%eip`
- `%ef`

我们稍后会讨论这些，只需知道它们存在即可。

`movl`指令将数字 `1` 移动到`%eax`。`1`前面的美元符号表示我们想要使用立即寻址（参考第 2 章中的“数据访问方法”节）。如果没有美元符号，它将是直接寻址，取决于地址 `1`处的任何数字。我们想要加载数字 `1`，所以我们必须使用立即数模式。

我们将数字 `1` 移动到`%eax`的原因是。`1`前面的美元符号表示我们想要使用立即寻址（参考第 2 章中的“数据访问方法”节）。如果没有美元符号，它将是直接寻址，取决于地址 `1`处的任何数字。我们想要加载数字 `1`，所以我们必须使用立即模式。

在`%ebx`中。该值随后返回给系统。因此，我们通过输入以下内容向`ebx`加载 `0`：

```
mov $0, %ebx
```

现在，用这些数字加载寄存器本身并无任何作用。寄存器用于系统调用之外的所有事情。它们是程序逻辑（如加法、减法和比较）发生的地方。Linux 仅要求在执行系统调用之前向某些寄存器加载特定的值。`eax`总是要求加载系统调用号。然而，对于其他寄存器，每个系统都有不同的要求。在`exit`系统调用中，要求向`ebx`加载退出状态。我们会在需要时讨论不同的系统调用。

下一条指令是“魔法”，看起来像这样：

```
int $0x80
```

`int`代表中断（interrupt）。`0x80`是使用的中断号。中断会中断正常的程序流，并将控制权从我们的程序传输给 Linux，以便它执行系统调用。你可以把它想象成蝙蝠侠（如果你喜欢也可以是 Larry-Boy）。你需要某事被完成，你发出信号，然后他就来营救了。你不关心他是如何工作的——这在某种程度上是魔法——当他完成后，你就重新获得了控制权。在我们请求 Linux 终止程序时，在这种情况下将无法重新获得控制。如果我们没有发送中断信号，那么就不会执行任何系统调用。
