## 你好，戴夫

我们在整个代码中已经使用了 `cout`（标准输出流）。现在，你将使用 `cin`（标准输入流）来提示用户响应。

- 你任何希望用户输入到系统内存中的内容都必须存储在它的某个地方。因此，任何输入都必须声明为一个变量，以便用户使用。从创建一个包含头文件的 C++ 文件开始。
- `cin` 命令的工作方式与 `cout` 命令相反。第一行 `cout` 向屏幕输出“你多大了？”，如尖括号 `<<` 所示。`cin` 使用相反的尖括号 `>>`，表示输入。输入被放在整数变量中，第二个命令中也是如此。构建并运行代码。

```cpp
userinteraction.cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "What is your age: ";
    cin >> age;

    cout << "You are " << age << " years old.\n";
}
```

### 步骤 8

虽然 `cin` 对于大多数输入任务都很良好，但它确实有一个局限性。`cin` 总是将空格视为单个单词而不是多个单词。然而，`getline` 将整行内容作为第一个参数，将变量作为第二个：


```cpp
#include <iostream>
using namespace std;

int main () {
  string mystr;
  cout << "Enter a sentence: \n";
  getline(cin, mystr);
  cout << "Your sentence is: " << mystr.length() << " characters long.\n";
}
```

### 步骤 6

你可以链式向用户请求输入，但要确保你有一个有效的变量来存储输入。假设你想让用户输入两个数字：

```cpp
#include <iostream>
using namespace std;

int main () {
  int num1, num2;
  cout << "Enter two numbers: \n";
  cin >> num1 >> num2;
  cout << "You entered " << num1 << " and " << num2 << " \n";
}
```

构建并执行代码，然后输入一个带有空格的句子。如果你读过代码，将 `getline` 那行替换为 `cin >>` 并重试，结果将显示到第一个空格之前的字符。

```cpp

using namespace std;

int main () {
  float num1, num2;
  cout << "Enter two numbers: \n";
  cin >> num1 >> num2;
  cout << "" << num1 << " + " << num2 << " is: " << num1 + num2 << " \n";
}
```
