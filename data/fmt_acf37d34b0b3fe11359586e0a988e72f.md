# mediainit(1)

## NAME

`mediainit` - 初始化磁盘或卡带介质、分区 DDS 磁带

## SYNOPSIS

`mediainit [-vr] [-f]`

## DESCRIPTION

`mediainit` 通过格式化介质、写入测试模式来验证介质，然后发现任何坏块。此过程准备好介质使用。

## Options

- `-v`（详细）向标准输出发送详细信息。
- `-f` 强制初始化介质，销毁磁带上的原有数据。
- `-p size` 将 DDS 卡带划分为两个逻辑卷：分区 0 和分区 1：
  - `size` 指定分区 1 的最小大小（单位为 Mbytes）。
  - 分区 0 是磁带的剩余部分（分区 0 物理上位于分区 1 之后）。
