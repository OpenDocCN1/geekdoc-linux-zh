在 Shell 提示符上输入的命令由三部分组成。

   定义命令行为的选项（options）
2. 参数（Arguments），即命令的目标

命令基本上定义了你想要执行的程序。跟在命令后的选项可以是零、一个或多个。选项控制命令的行为。

```bash
[student@desktop ~]$ file /home
/home: directory
```

下一组命令是 `head` 和 `tail`，它们分别打印文件的前十行和最后十行。这两个命令都可以配合 `-n` 选项使用，该选项用于指定你想显示的行数。

```bash
[student@desktop ~]$ head /etc/passwd
```

这将会打印 `passwd` 文件中的前 10 行。

```bash
[student@desktop ~]$ tail -n /etc/passwd
```

这将打印 `passwd` 文件中的最后 3 行。

`wc` 命令用于统计作为参数传递的文件的行、单词和字符。它支持 `-l`、`-w`、`-c` 等选项，分别代表行、单词和字符。

```bash

```
30 75 2009 /etc/passwd

这显示 `passwd` 文件中有 30 行、75 个单词和 2009 个字符。

如果你在在使用 `wc` 命令时传递了 `-l`、`-c` 或 `-w` 选项，它将根据你传递的选项仅显示行、单词或字符的计数。

`history` 命令显示你之前输入过的所有命令以及命令编号。你可以使用 `!` 标记配合命令编号来展开该命令输入的内容及其输出。

```bash
[student@desktop ~]$ history 1 clear
2 who
```

```bash
3 pwd@desktop ~]$ !3
```
/home/student

这显示我们使用 `!3` 展开了 `pwd` 命令，该命令显示了当前的工作目录，输出为 `/home/student`，这是学生用户的家目录。

你可以使用方向键在 `history` 命令提供的输出中进行导航。向上箭头会带你回到上方的命令，向下箭头会带你回到下方的命令。使用右箭头和左箭头键，可以在当前命令上移动并进行编辑。

## 第八章：区块链

区块链和 Linux 似乎是天生一对。它们结合在一起，使反对取消网络中立性的斗争更加强大。它们呈现了一种去中心化的范式，并使任何人都能编写和实现代码。它们确实是计算机世界中的完美结合。

### Hyperledger

Linux 会（Linux Foundation）是 Hyperledger 的幕后推动，这是一个巨大的区块链企业项目，帮助企业在其公司基础设施中实现区块链技术。Linux 会于 2015 年 12 月宣布其创建，并在 2016 年 2 月宣布了其创始成员。Hyperledger 的目标是通过区块链提高业务的问责性和透明度。IBM 和 Intel 等技术巨头已经支持该项目，并为其核心软件做出了贡献。

私有链是有争议的，因为它们实现了中心化。然而，Hyperledger 使用了私有链，但它们并没有集中在任何一个业务中。例如，作为 Hyperledger 联盟的银行并没有获得自己的区块链；它成为了一个包含多个行业的更大区块链的一部分。其他公司参与验证过程并提供数据不可篡改性，为私有链增加了一层问责机制。它并没有变得完全去中心化，但距离完全中心化还有几步之遥。

存在多个 Hyperledger 区块链和区块链框架。例如，Hyperledger Fabric 是一个允许公司创建去中心化应用程序的区块链框架，部分客户和用户可以从前端访问。人们可以使用它创建并执行智能合约，从而实现许多流程自动化。

Hyperledger 已应用于许多不同的行业。它被用于追踪供应链运输，这意味着它可以追踪人们最终消费的货物运输路线。假设父母为婴儿购买了一罐奶粉，后来发现该批奶粉被污染了。父母会立即想知道他们是可以不给宝宝喂奶，或者让宝宝立即接受医疗治疗。传统技术会在发现问题时提醒他们。而 Hyperledger 的使用让他们能够在购买之前扫描奶粉罐以追踪其整个运输路线。它还用于维护健康记录和医疗保险。它可以用于追踪汽车所有等信息，这样买车的人就可以查出特定汽车经历过什么。使用 Hyperledger 意味着客户对他们的购买的产品以及他们支持的公司更有信心。

Hyperledger 是开源的，因此任何人都可以访问源代码并从理论上对其进行改进。当然，这些改进必须经过 51% 多数节点的批准。Hyperledger 主要用 JavaScript 编写。任何所做的更改都需要用 JavaScript 编写，或者从不同的编程语言（如 Python 或 C++）编译为 JavaScript。

### 成为区块链节点

在 Hyperledger 中成为节点需要许可。除非你在该公司的内部拥有高级访问权限，否则不太可能获得。然而，你仍然可以设置你的 Linux 成为比特币、以太坊、Blockstack 或 Lisk 等公有区块链的节点。

Linux 系统相比其他操作系统并不容易受到病毒和其他形式的恶意软件的影响，因此其影响你运行节点能力的风险非常小。尽管如此，你仍然想要定期进行检查并每隔几天重启一次电脑。

请确保你正在利用运行节点带来的益处。并为自己帮助区块链保持强健和去中心化而感到自豪吧。

### 成为区块链矿工

你完全可以使用 Linux 操作系统成为一名区块链矿工。成为矿工意味着你将获得虚拟货币作为你努力的奖励！在开始之前，你需要决定想为哪种区块链进行挖掘。一些最流行的区块链（尤其是比特币和以太坊）规模如此大，矿工必须投资昂贵的技术并不断升级系统才能保持竞争力。对于这些区块链，挖掘可能完全无利。其他如 DarkCoin 和 Lisk 等区块链具有分级机制来决定谁可以挖掘。做一些研究，决定哪种区块链最适合你挖掘。

请记住，挖矿是非常高耗能的。许多人发现由于电费太高，这并不是盈利的。在开始挖矿之前，请确保你有稳定的廉价能源供应（如太阳能），以避免这种情况的发生。除了一直让电脑处于运行状态成本外，你还需要保持电脑冷却，因为矿场经常过热。这也会导致高额电费。

本节将仅关注你将电脑转变为矿工所需的软件。为了高效挖掘，可能需要很多硬件，但这超出了本节的范围。

某些区块链拥有专门为 Linux 用户设计的软件，以使挖矿变得更容易且更有利可。例如，`Cminer` 让在 Ubuntu 上挖掘比特币变得简单得多。做一些研究，看看你使用的 Linux 发行版是否有专门的矿工软件。

将必要的软件下载到你的电脑上。请记住，除非区块链相对较小（如狗狗币或其他代币），否则平板电脑甚至笔记本电脑都不适合挖矿。此外，请记住，如果你下载源代码并进行编译，许多程序在 Linux 下运行得更好。这样做实际上允许你对源代码进行修改，并让源代码运行得更好！

你还需要下载区块链的核心程序，就像你尝试将电脑变成区块链节点一样。一旦你拥有了所有必要的硬件，就可以开始运行挖矿软件并赚取虚拟货币了！

与运行节点类似，你的矿机可能会消耗大量资源，导致你无法将其用于其他任何事情。除非你决定建立自己的矿场（这是一些硬核区块链玩家尝试做的创业），否则你可能最好使用一台你不再使用的旧电脑。此外，矿场会消耗大量的能量和内存，所以请确保你有充足的供应。如果你无法投入必要的资源来运行自己的矿场，可以考虑加入基于 Linux 的矿池。矿池是一组矿工，他们将各自电脑的能量结合起来更高效地挖矿。然后他们分配利润。
