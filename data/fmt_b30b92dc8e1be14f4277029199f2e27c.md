### AddKey

将键添加到被跟踪的键集合中。我们只跟踪几个键，并忽略其余键。

# 视频游戏 365

```c
/* */
void AddKey (GdkKeyEvent *event)
{
    switch (event->keyval) {
        /* --- 左方向键 --- */
        case GDK_Left:
            keyLeft = TRUE;
            break;
        /* --- 右方向键 --- */
        case GDK_Right:
            keyRight = TRUE;
            break;
        /* --- 上方向键 --- */
        case GDK_Up:
            keyUp = TRUE;
            break;
        /* --- 下方向键 --- */
        case GDK_Down:
            keyDown = TRUE;
            break;
        /* --- 空格 --- */
        case ' ':
            keyFire = TRUE;
            break;
        /* --- 其他 --- */
        default:
            break;
    }
}
```

```c
/*
* RemoveKey
* 如果我们正在跟踪某个键且该键释放，则将其标记为未按下。
*/

void RemoveKey (GdkKeyEvent *event)
{
    switch (event->keyval) {
        case GDK_Left:
            keyLeft = FALSE;
            break;
        case GDK_Right:
            keyRight = FALSE;
            break;
        case GDK_Up:
            keyUp = FALSE;
            break;
        case GDK_Down:
            keyDown = FALSE;
            break;
        case ' ':
            keyFire = FALSE;
            break;
        default:
            break;
    }
}
```

```c
/*
* HandlePressed
* 当需要移动时，根据当前按下的键调用此例程进行移动。
*/

void HandlePressed ()
{
    /* 向每个方向移动 */
    if (keyLeft) {
        HeroMove (MOVE_LEFT);
    }
    if (keyRight) {
        HeroMove (MOVE_RIGHT);
    }
    if (keyUp) {
        HeroMove (MOVE_UP);
    }
    if (keyDown) {
        HeroMove (MOVE_DOWN);
    }
    /*
    * 尝试射击。
    * 显然，一旦射击我们就清除标记，否则玩家可以一直按住。
     */
    if (keyFire) {
        /* ... 砰 ... */
        HeroFire();
        /* 噢 ... */
        keyFire = FALSE;
    }
}
```
