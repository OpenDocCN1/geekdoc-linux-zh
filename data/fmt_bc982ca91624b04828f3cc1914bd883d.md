## 13.4 贯穿执行（Fallthrough）

`switch` 语言还有一种方法——贯穿执行（`fallthrough`）。

```c
#define R 1
#define W 2
#define RW 3

void f(int type) {
    int read=0, write=0;
    switch (type) {
        case RW:
            read=1;
            break;
        case W:
            write=1;
            break;
        case R:
            read=1;
            break;
        default;
    }
    printf("%d,%d\n", read, write);
}
```

如果 `type` 为1（参见第一行 `R` 为真），则 `read` 的设置为1；如果 `type` 为2 (`W`)，则 `write` 设置为1；如果 `type` 为3 (`RW`)，则 `read` 和 `write` 的值设置为1。无论 `type` 的值是 `RW` 还是 `W`，都会执行第四行的指令。`switch` 语句里没有 `break`，从而利用了贯穿效应。

即语法糖（`syntactic sugar`），指增强代码可读性，降低错误率的语法改进。`MSVC` 编译器在处理线程局部变量时，按照其需要，可能给这些内部变量分配以 `tv` 开头的宏。
