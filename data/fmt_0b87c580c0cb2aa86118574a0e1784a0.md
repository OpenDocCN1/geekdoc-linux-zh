## SUMMARY

每个 UNIX shell 都有一种编程语言，允许你编写程序来执行现有命令无法完成的任务。这些程序通常被称为 shell 脚本。最简单的形式，shell 脚本由 shell 逐条顺序执行的 shell 命令列表组成。更高级的脚本包含程序控制流语句，用于实现多路分支和脚本中命令块的重复执行。由 Bourne shell 命令、语句和特性组成的 shell 程序称为 Bourne shell 脚本。
