## 创建框架

框架允许你在同一个浏览器窗口中查看多个 HTML 文档。显示在浏览器窗口中的每个 HTML 文档都称为一个帧（`frame`）。浏览器窗口中的所有帧都是相互独立的。在 HTML 文档中，我们使用 `<frameset>` 和 `<frame>` 标签。`<frameset>` 标签用于将窗口划分为多个帧。`<frame>` 标签用于指定每个帧中包含哪些 HTML 文档。

## 探索 Linux Shell

`Linux shell` 是一个允许用户与 `Linux` 操作系统（`OS`）交互的程序。它也被称为命令行界面（`CLI`）。命令的输出显示在 `shell` 提示符上。`Shell` 不在内核中；它仅使用内核执行命令。内核是操作系统的核心组件，管理其资源，如内存和硬件设备。`Linux shell` 执行的基本功能是从命令行读取命令。

## 描述 Linux 中的 Shell 类型

`Linux` 提供了多种类型的 Shell，以下是：
- C shell
- TC shell
- Bash shell

## C Shell (csh)

`Csh` 是一个由 Bill Joy 开发的交互式 shell。

## TC Shell (tcsh)

`Tcsh` 是为了增强 `csh` 而设计的 shell。

## Korn Shell (ksh)

Korn shell 是 David Korn 在 1980 年代开发的。

## Bash Shell

`Bash` 是 Bourne Again Shell，它是为 GNU 项目编写的，也是大多数操作系统的默认 shell。
