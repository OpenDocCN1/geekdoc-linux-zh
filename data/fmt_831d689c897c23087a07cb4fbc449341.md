
# 用于 LinuxDoc DTD 的 SGML 转换器

LinuxDoc 是一种 SGML DTD。它是为 Linux HOWs 创建的，并一直被 Linux 文档项目（LDP）官方使用。LDP 已经积极地迁移到 DocBook 世界，但许多文档仍以 LinuxDoc DTD SGML 格式提供。用户可能仍然需要该基于 sgml–v1 创建的 LinuxDoc 工具。主命令是 `linuxdoc`，`-B` 是用于为所需的输出选择合适的后端驱动程序的选项。

- `linuxdoc -B check`：用于检查语法
- `linuxdoc -B html`：转换为 html
- `linuxdoc -B info`：转换为 info
- `linuxdoc -B latex`：转换为 latex、dvi 和 postscript
- `linuxdoc -B lyx`：转换为 lyx
- `linuxdoc -B rtf`：转换为 rtf
- `linuxdoc -B txt`：转换为文本

HTML 的生成不依赖任何其他 Debian 处理包，但对于其他格式，则将安装相关包。

- 文本转换需要 `grove`
- LaTeX 转换需要 `texet-base`、`texet-bin` 和 `hetero`
- Info 转换需要 `texinfo`

你可以包含 `linuxdoc-tools` 以作为 latex 或 info 转换的依赖。`linuxdoc-tools` 仅为 linuxdoc DTD 设计和实现。如果你想转换 Debian DTD 文档，请使用并安装 `debiogl-package`。

### LinuxDoc 的 Infoset

LinuxDoc-Tools 是仅用于 LinuxDoc DTD 的 SGML 转换器。该包用于提供 LinuxDoc info 转换所需的依赖。更多信息请参阅 `linuxdoc-packages` 的描述。来自 Debian 3.0r0 APT 工具 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### linuxdoc-latex

LinuxDoc 的 LaTeX/PS/PDF 输出功能。LinuxTools 是仅用于 LinuxDoc DTD 的 SGML 转换器。该包提供 LinuxDoc LaTeX/PS/PDF 转换功能所需的依赖。更多信息请参阅 `linuxdoc-packages` 的描述。来自 Debian 3.0r0 APT 工具 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### linuxdoc-text

LinuxDoc 的文本输出功能。LinuxTools 是仅用于 LinuxDoc DTD 的 SGML 转换器。该包提供 LinuxDoc 文本转换功能所需的依赖。更多信息请参阅 `linuxdoc-packages` 的描述。来自 Debian 3.0r0 APT 工具 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### facile

面向初学者的意大利语手册。Facile 是为那些有 GNU/Linux 经验但希望熟悉它的人编写的，旨在让学习和使用 GNU/Linux 的体验变得简单。它有多种格式，由 GNU Free 涵盖。该包包含 PostScript 版本。来自 Debian 3.0r0 APT 工具 http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

### LinuxFromScr

Linux From Scratch (LFS) 是一个通过使用 LFS 书构建你自定义系统的项目。该网站还包含邮件列表、存档、新闻组、搜索引擎和常见 等资源。在原始 BSD 下发布。开发版本 3.2-rc2 发布于 2002 年 2 月 27 日。稳定版本 3.3 发布于 2002 年 4 月 7 日。版本 4.1 发布于 2003 年 4 月 28 日。来自 LWN 列表

### GNU Linux

Linux GNU 基于 Debian 和 Ubuntu，具有许多易用性增强，如自动化安装、硬件检测和配置——面向具有 Linux 经验的用户。版本 1.0 发布于 2002 年 8 月 6 日。西班牙语发行。来自 LWN 列表

### linuxinfo

显示扩展系统信息。显示内核版本、glibc 版本、处理器类型和内存大小。来自 Debian 3.0r0 APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### LinuxInstall

LinuxInstall 1.0 基于 Red Hat Linux 8.0，包含 Mozilla 浏览器、Evolution 邮件和 OpenOffice 套件。它还带有截至 2003年1月7日的最新内核和软件更新（截至 2003年1月7日）。主要功能包括自动检测、自动创建根账户、硬盘分区、使用 DHCP 的网络以及软件包选择。安装期间不会询问任何问题，过程完全是自动化的，耗时约 15 分钟。整个系统位于 CD 上。版本 3.0 发布于 2003 年 4 月 20 日。来自 LWN 列表 http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### linuxxogo

ANSI 系统 Logo。带有系统启动时或登录提示处显示系统信息的 ANSI Logo。共有四种 Logo：Debian Swirl（默认）、Debian Banner、Tux Classic 和 Banner。包含了所有 Logo 的单色 ASCII 版本。来自 Debian 3.0r http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### LinuxPPC

LinuxPPC 在 1996 年引发了对 PowerPC 上 Linux 的关注浪潮，发布了第一个 CD-ROM 并为替代系统的开发者提供了支持。它的首次成功是 LinuxPPC 4.1、1999 (5.0)、1999 Q3 (5.5) 以及当前的发行版 LinuxPPC 2000 (6.0)。遗憾的是，现在已停止——2003 年 3 月 5 日。来自 LWN 列表 http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

### linuxvideo

MPEG-tools 图形界面。Video Studio 是一个 MPEG-tools (http://mjpeg.sourceforge.net/) 的小型 GUI。MPEG-tools 可用于从数字卡录制视频、将视频播放到摄像头并将视频编码为 MPEG。Video Studio 工具扩展了简单的编辑功能，如删除帧、从新视频添加帧、移动帧等。非自由 Debian 包必须从 http://download.sourceforge.net/mjpeg/ 下载以运行 linuxvideo。来自 Debian 3.0r0 APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html
