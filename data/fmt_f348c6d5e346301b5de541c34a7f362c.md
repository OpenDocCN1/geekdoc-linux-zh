
文档字符串存储在函数的 `__doc__` 属性中，IDE 通常利用它提供交互式帮助。
如果你使用装饰器，请注意用装饰器封装可能会破坏与文档字符串相关的帮助功能。例如，考虑以下代码：

```python
def wrap(func):
  def call(*args, **kwargs):
    return func(*args, **kwargs)
  return call

@wrap
def factorial(n):
  """计算 n 的阶乘."""
```

如果用户请求这个版本的 `factorial()`，他将得到一个相当晦涩的解释：

```python
>>> help(factorial)
Help on function call in module __main__':
call(*args, **kwargs)
(END)
>>>
```

# 第 6 章 函数与函数式编程

为了修复这个问题，可以编写装饰器函数，让它们传播函数名称和文档字符串。例如：

```python
def wrap(func):
    def call(*args, **kwargs):
        return func(*args, **kwargs)
    call.__doc__ = func.__doc__
    call.__name__ = func.__name__
    return call
```

由于这是一个常见问题，`functools` 模块提供了 `wraps` 函数，可以自动复制这些属性。惊讶的是，它也是一个装饰器：

```python
from functools import wraps
def wrap(func):
    @wraps(func)
    def call(*args, **kwargs):
        return func(*args, **kwargs)
    return call
```

`functools` 中的 `@wraps(func)` 装饰器会将属性从 `func` 传播到定义的包装器中。

## 函数属性

函数可以附加任意的属性。这里有一个示例：

```python
def foo():
    pass
foo.secure = 1
foo.private = 1
```

函数属性存储在字典中，可以通过函数的 `__dict__` 属性访问。

函数属性的主要用途是在高度专门的应用程序（如解析器生成器和应用框架）中，用于向函数对象附加额外信息。

作为文档字符串，可以使用装饰器给函数提供属性。如果函数被装饰器包装，那么对属性的访问实际上发生在装饰器函数上，而不是原始实现上。这可能是你应用程序所需的，也可能不是。要将已定义的函数属性传播到装饰器函数，请使用以下模板或如上一节所示的 `functools.wraps()` 装饰器：

```python
def wrap(func):
    def call(*args, **kwargs):
        return func(*args, **kwargs)
    call.__doc__ = func.__doc__
    call.__name__ = func.__name__
    call.__dict__.update(func.__dict__)
    return call
```

## eval(), exec(), and compile()

`eval(str [, globals [,locals]])` 函数执行表达式字符串并返回结果。这里有一个示例：

```python
a = eval('math.sin(3+x) + 7.2')
```

同样，`exec(str [, globals [, locals]])` 函数执行包含 Python 代码的字符串。用于 `exec()` 的代码将按照其在 `exec` 执行位置处实际出现的形式被执行。这里有一个示例：

```python
a = [3, 5, 10, 13]
exec('for i in a: print(i)')
```

需要注意的是，在 Python 2 中，`exec` 被定义为语句。在遗留代码中，你可能会看到没有外括号的语句调用，例如 `exec 'for i in a: print *'`。虽然这在 Python 2.6 中仍然有效，但在 Python 3 中会报错。现代程序应该使用函数形式的 `exec()`。这两者都在调用者的命名空间内执行（该命名空间用于解析字符串或文件中出现的任何符号）。可选地，`eval()` 和 `exec()` 可以接受两个映射对象作为执行代码的全局和局部命名空间。这里有一个示例：

```python
globals = {'x': 7,
'Y': 10,
'birds': ['Parrot', 'Swallow', 'Albatros']}
locals = {}
# 使用字典作为全局和局部命名空间进行 exec
e = eval('3 * x + 4 * y', globals, locals)
exec('for b in birds: print(b)', globals, locals)
```

如果省略一个或多个字典，将使用全局和局部作用域的当前值。由于嵌套作用域的问题，在函数内部使用 `exec()` 如果同时也包含嵌套函数或使用 `lambda` 操作符，可能会导致 `SyntaxError`。

当字符串传递给 `eval()` 或 `exec()` 时，第一个解析器会将其编译为字节码。由于这种开销很大，最好先编译代码并在后续调用中重用字节码，如果代码将被执行多次。

`compile(str, filename, name)` 函数将字符串编译为字节码，`filename` 是包含待编译代码的字符串（用于回溯跟踪）。`kind` 参数指定了正在编译的代码类型——`'single'` 表示单个语句，`'exec'` 表示一组语句，或 `'eval'` 表示一个表达式。`compile()` 函数返回的代码也可以传递给 `eval()` 函数和 `exec()` 语句。这里有一个示例：

```python
s = 'for i in range(0,10): print(i)'
c = compile(s,'','exec') # 编译为代码对象
exec(c) # 执行它
s = "3 * x + 4 * y"
c2 = compile(s,','eval') # 编译为表达式
result = eval(c2)
```

## class 语句

类定义了一组属性，这些属性与称为实例的对象集合相关并由其共享。类最常见的形式是函数集合（称为方法）、变量集合（称为类变量）和计算属性（称为属性/属性）。

类使用 `class` 语句定义。类体包含了命名空间。这里有一个示例：

```python
class Account:
    num_accounts = 0
    def __init__(self, name, balance):
        self.name = name
        self.balance = balance
        Account.num_accounts += 1
    def deposit(self, amt):
        self.balance += amt
    def withdraw(self, amt):
        self.balance -= amt
    def inquiry(self):
        return self.balance
```

类内部定义的函数称为方法。实例方法是操作实例的函数，作为第一个参数传递。按照约定，这被称为 `self`，尽管可以使用任何合法的标识符。在前面的示例中，`deposit()`、`withdraw()` 和 `inquiry()` 都是实例方法。

类变量如 `num_accounts` 是所有实例共享的值。在这种情况下，它是一个跟踪实例数量的变量。
