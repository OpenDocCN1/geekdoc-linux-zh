服务的主要配置是`/etc/mongodb.conf`，它包含了数据存储位置以及监听的 `IP` 地址和端口。以下是`Ubuntu`中的代码：

```yaml
storage:
  dbPath: /var/lib/mongodb
  journal:
    enabled: true
systemLog:
  destination: file
  logAppend: true
  path: /var/log/mongodb.log
net:
  port: 27017
  bindIp: 127.0.0.1
processManagement:
  timeZone: /usr/share/zoneinfo
```

默认情况下，服务仅监听`localhost`并使用默认端口`27017`。
