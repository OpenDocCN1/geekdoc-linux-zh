
## 三甘油酯
三甘油酯甘醇的三酯，存在于植物和组织中（特别是在食物储存中），以所有脂肪酸相同的酯形式存在，或以脂肪酸不同的混合酯形式存在。三甘油酯是天然油脂的主要成分。

三角函数。单位圆是半径为1且中心位于坐标系原点的圆。圆的单位是度。长度为 `theta` 的弧所对角是 `theta`。如果 `theta` 是任意实数，弧的长度等于 `theta`，点 P 是圆上作为该角终边的点。

三甘油酯的通用公式所示：

```
CH2-OC-R
CH-OC-R'
CH2-OC-R''
```

`RCOHO`、`R'COH` 和 `R''COH` 是相同或不同的脂肪酸分子，例如丁酸（链状）、棕酸（饱和）、油酸（油酸）、亚油酸（不饱和）。与碱金属皂化会释放甘醇和脂肪酸的碱盐（皂）。食物储存中的三甘油酯是浓缩能量源，

反三角函数。在正弦函数中，如果 `y` 限制为 $-\pi/2 \le y \le \pi/2$，则函数是唯一的并定义为 `y=sin^{-1}x`（`sin^{-1}` 是正弦的反函数）。对于正切函数，`x` 必须限制为 $-1 \le x \le 1$。对于余弦函数，如果 `y` 限制为 $0 \le y \le \pi$，则该函数是唯一的并定义为 `y=cos^{-1}x`（`cos^{-1}` 是余弦的反函数）。

可以找到单位圆上终边为 `pi/6` (30°)、`pi/4` (45°) 和 `pi/2` (90°) 的角的坐标。通过方程 (2)、(3) 和 (4)，可以得到这些角的函数（见表 2）。

此外，如果 `y` 限制为 $-\pi/2 < y < \pi/2$，则正切函数是唯一的并定义为 `y=tan^{-1}x`（`tan^{-1}` 是正切的反函数）。对于余切函数，如果 `y` 限制为 $0 < y < \pi$，则该函数是唯一的并定义为 `y=cot^{-1}x`（`cot^{-1}` 是余切的反函数）。

三角函数的性质。根据等式 (2) 和上述几何构造，对于 `sin theta` 和 `cos theta`，`theta` 可以是任意角，因此正弦和余弦函数的域是所有实数。如果 `theta` 是 `pi/2` 的奇倍数，则正切和割未定义。在等式 (3) 和 (4) 中，正切和余切函数未定义，因此这些函数的域是 `pi/2` 的奇倍数以外的所有实数。

直角三角形函数。直角三角形函数可以表示为直角三角形边的比。在等式 (2) 中，`sin theta=a/c`，`cos theta=b/c` 和 `tan theta=a/b`，其中 `a` 和 `b` 是直直角的边，`c` 是斜边。如图 (2) 所示，如果给定直角三角形的角和边，就可以找到剩余的角。
