# txfonts

用于 TEX 的 Times 类字体。TX 字体包括：

- 1. OT1、T1 和 LY 中的虚拟文本字体（或 URW Nimbus），带有修改的符号
- 2. OT1、T1 和 LY 中的无衬线 Adobe Helvetica（或 URW Nimbus），带有额外符号
- 3. OT1、T1 和 LY 中的等宽字体
- 4. 带有修改指标的 Adobe Times（或 URW Nimbus）数学字体
- 5. 与现代字体（CMSY, CML, CEX 和希腊字母 CMR）对应的所有符号的数学字体
- 6. 与 AMS 字体（MSAM 和 MSBM）对应的所有符号的数学字体。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

文本转 HTML 器。`txthtml` 是一个将纯文本转换为 HTML 的 Perl 程序。它支持标题、列表、字符映射、超链接，并且高度自定义。它能识别源文档的一些外观（主要是空白和排版），并尝试使用 HTML 显式构建结构。该工具的目的是提供一种将文档转换为 HTML 格式更容易的方法。`txthtml` 也可以编写新的 HTML 文档，但有更好的方法。来自 Debian 3.0r http://www.tdlp.org/

`tx2pdboc`

将纯文本转换为 Palm DOC (用于 Palm) 并反转。此工具将纯文本文件转换为用户读取器的事实 DOC 格式（例如“Spot Run”），处理 DOC 文件，`tx2pdbdoc` 将 DOC 文件转回纯文本。警告：如果你有内存卡，生成的 PDB 文件（此版本及之前的版本）可能会在 Palm 上出现问题。详情见 bug #11930。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html
