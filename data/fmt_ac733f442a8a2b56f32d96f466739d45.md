# 设置 SAMBA

## UBUNTU 中的服务器配置

服务器端配置

# 第 1 步

- 要求：
  1) UBUNTU 服务器，IP: `192.168.0.50`
  2) 客户端 (UBUNTU 或 CENTOS)，IP: `192.168.0.100`
  3) 互联网连接

# 第 2 步

更新软件库并安装必要的 samba 软件包

# Tanvir Rahman

```bash
=> apt update -y
=> apt install samba
```

# 第 3 步

创建一个组，并将可以使用 samba 共享的用户添加到组中。

```bash
=> groupadd test
=> useradd user1
=> useradd user2
=> usermod -a -G test user1
=> usermod -a -G test user2
```

# 第 4 步

检查状态

```bash
=> sudo systemctl status nmbd
=> sudo systemctl status smbd
```

# 第 5 步

创建一个目录并为该用户和组赋予适当权限

```bash
=> mkdir /share
=> chmod 777 /share
=> chgrp test /share
```

# 第 6 步

配置 SELinux。你可以禁用 SELinux 或设置正确的布尔值和安全性，否则它将不允许你连接到服务器。在这里，我们不会禁用 SELinux，而是更改布尔值。

```bash
=> setboolean -P samba_export_all_ro=1 samba_export_all_rw=1
=> getsebool -a | grep samba_export
=> manage fcontext -at samba_share_t "share/(.*)?"
=> restorecon /share
```

# 第 7 步

我们必须更改防火墙设置以允许连接

```bash
=> ufw allow 'Samba'
=> ufw reload
```

# 第 8 步

这是部分最重要的路径。我们需要编辑 samba 共享的配置

```bash
=> vim /etc/samba/smb.conf
```

```ini
[share]
comment=samba 共享目录
browsable=yes
path=/share
public=no
valid users=@test
write list=@test
```

# UBUNTU $ CENTOS 管理员

```ini
writeable=yes
create mask=0770
Force create mode=0770
force group=test
```

```ini
[share]
comment = samba 共享目录

path = /share
valid users = @test

[root@localhost ~]#
```

# 第 8 步

使用 `testparm` 命令测试配置。如果配置中有任何错误，此命令将告知你

`=> testparm`

# 第 9 步

我们必须将 test组的用户添加到 samba

```bash
=> smbpasswd -a user1
=> smbpasswd -a user2
```

# 第 10 步

重启 samba 服务使更改生效

```bash
=> systemctl start smbd
=> systemctl start nmbd
```

# 第 11 步

我们必须启用 smb 和 nmb 服务以便在开机时启动

UBUNTU $ CENTOS 管理员

```bash
=> systemctl enable smb
=> systemctl enable nmb
```
