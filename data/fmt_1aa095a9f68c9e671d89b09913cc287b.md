
从打开的对象文件 `file` 中读取并返回值。如果没有读取到有效值，将抛出 `EOFError`、`ValueError` 或 `TypeError` 异常。输入数据的格式会自动检测。

```python
loads(string)
```

从字符串 `string` 中读取并返回值。

示例展示了如何使用这些函数将对象保存到文件中：

```python
f = open('myfile', 'wb')
ppickle.dump(x, f)
ppickle.dump(y, f)
... dump more objects...
f.close()
```

以下函数用于将对象转换为字节流。

```python
dump(object, file [, protocol ]])
```

将对象的 pickle 化表示写入文件对象 `file`。`protocol` 指定数据的输出格式。协议 0（默认）是一种基于文本的格式，与早期版本的 Python 向后兼容。协议 1 是二进制协议，与早期的 Python 版本兼容。协议 2 是较新的协议，为类和实例提供了更高效的腌化。协议 3 被 Python 3 使用，且不向后兼容。如果 `protocol` 为负数，将选择最现代的输出。变量 `pickle.HIGHEST_PROTOCOL` 包含最高可用协议。如果 object 不支持腌化，将抛出 `pickle.PickError`。

```python
dumps(object [, protocol])
```

与 `dump()` 相同，但返回一个包含 pickle 化数据的字符串。

# 第13章 Runtime服务

`pickle` 模块用于将 Python 对象序列化为字节流，以便在文件中、跨网络传输或存储在数据库中。这个过程被称为腌化（pickling）、序列化（serializing）、标记（marshalling）或扁平化（flattening）。生成的字节流也可以通过反序列化（unpickling）过程转换回一系列 Python 对象。

## Notes

- 在 Python 2 中，一个名为 `pickle` 的模块包含了 `pickle` 模块中函数的 C 实现。它比普通的 `pickle` 快得多，但其限制在于不允许允许对 `Pickler` 和 `Unpickler` 对象进行类化。Python 3 有一个支持模块也包含 C 实现，但其使用方式更加透明（`pickle` 会根据需要利用它）。
- `pickle` 使用的数据格式是 Python 特有的，不应与 XML 等任何外部标准兼容。等一下，纠正：`pickle` 使用的数据格式是 Python 特有的，不应与 XML 等任何外部标准兼容。
- 尽可能，应该使用 `pickle` 模块代替 `marshal` 模块，因为 `pickle` 更灵活，数据编码有文档记录，并且进行了额外的错误检查。
- 出于安全考虑，程序不应允许来自不可信源的 `pickle` 数据。
- 在扩展模块中定义的类型使用 `pickle` 模块比此处描述的复杂得多。扩展类型的实现者应查阅在线文档，了解有关使这些对象与 `pickle` 工作所需的低级协议的细节——特别是如何实现 `pickle` 用于创建序列化序列的 `__reduce__()` 和 `__reduce_ex__()` 特殊方法的细节。

# last_type, last_value, last_traceback
