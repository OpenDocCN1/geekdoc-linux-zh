
# Linux 字典

缩写。自由软件会（Free Software Foundation）的常用口语和书写，支持 GNU 项目的非营利组织。源自术语词典

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `Free Software Foundation` (org., GNU)

自由软件基金 (`Free Software Foundation`)(org., GNU)) 源自 VERA

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `Free Software Foundation`.

自由软件基金。`FSW` 拥有大多数 `GNU SW` 以及 `GPL 3000` 和 `4000` 许可证。源自 Linux Guide @First

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- `FSF` (`Free Software Foundation`)

自由软件基金 (`Free Software Foundation`)。一家位于马萨诸塞州的非营利组织，致力于为非商业目的释放实用软件。为了实现这一目标，`FSF` 支持兼容 `UNIX` 的操作系统 (`OS`, `GNU`) 以及可自由分发的系统。

- `FSF GPL` (`General Public License`).

`FSF` 通用公共许可证 (`General Public License`)。源自 `QUCID`

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- Fast remote execution over ssh.

问题：使用加密解决方案如 `ssh` 或 `ish` 登录到远程系统，由于连接建立时的计算开销，通常使用远程 `CVS` 会触发大量远程登录，这与本地存储仓库相比极其缓慢。解决方案：一旦建立，使用安全隧道。`fsh` 是 `ssh` 的无缝替代品，可自动重用 `ssh` 隧道。源自 Debian 3.0r APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- FSP

一种用于 `FTP` 的文件传输系统 (`file transfer system`)(FSP)，其特点是服务器可以在任何地方运行而不需要特权权限，且 `FSP` 服务器的系统负载比 `FTP` 低。源自 Guide @First-Linux

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

- fsp

文件服务协议 (`File Service Protocol`) 的客户端工具 (`client utilities for File Service Protocol` (FSP))。`FSP` 是 `FTP` 的“匿名版”。用开发者的话说，`FSP` 是匿名 `FTP` “应该”具有的样子。`FSP` 是一种协议，有点像 `FTP`，用于移动文件。

- FSP

文件服务协议 (`File Service Protocol`) 服务器。`FSP` 是匿名 `FTP` 的替代方案，它是你自己的资源。服务器不进行排序，因此可以处理更多的并发用户。此外，该协议的设计考虑了任务回退机制，因此不会干扰交互式应用程序。如果你提供匿名 访问，可能也不想要这个软件。源自 Debian 3.0r0 APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
