
| `routed`/`edged` | 这两个程序中的任何一个维护路由表，使系统在发送数据包时知道采取哪条路径。 |
| `nfs`/`biod` | 网络文件守护进程，允许通过网络共享文件系统。 |
| `lpsched`/`lpd` | SYS/BSD 行打印调度器。 |
| `telnetd` | Telnet 协议服务器，允许通过网络进行交互式连接。 |
| `ftppd` | 文件传输协议 `FTP` 服务器，允许在网络上进行文件传输。 |
| `httpd` | 超文本传输协议守护进程，协调万维网服务。 |
| `rpc.*` | 远程过程调用守护进程允许通过网络调用其他连接的机器。这种类型的常见条目有 `rpc.mount`、`rpc.statd`、`rpc.locks`、`rcpd` 和 `rcpbind`。通常这些实用程序会附带一个名为 `portmap` 的程序，它将 RPC 数字转换为 TCP 或 UDP 协议数字。 |

关于启动过程的一点：如果文件 `/etc/nologin` 存在，只有超级用户可以登录。其他尝试登录的用户将看到 `/etc/nologin` 的文本内容。

## 关机

俗话所说，“有必有落”。对于计算机是如此，对于生活中的其他事物也是如此。正常关机尝试以有序的方式终止进程，以便系统启动时错误尽可能少。优雅关机将尽可能平滑地杀死运行任务。然后它会将磁盘与内存和磁盘中任何待处理的缓冲区同步。

当需要时，首先要确保关机确实需要有序进行。你决定这样做取决于你对站点的处理以及你影响了多少用户。此外，很多时候，少量的研究会让你尝试重启一个守护进程，或者忍受一个你可以在晚上修补的易发性问题。

如果系统必须关机，取决于当前情况，有多种关闭运行系统的方法。方法包括 `shutdown`、`reboot`、`sync`、`init` 和 `halt` —— 以及切断机器电源。通常，正如你预期的那样，切断电源或未完成同步（所有磁盘写入）的静止磁盘，几乎可以确保发生某些文件损坏，需要在下次启动时进行修正。

很有可能文件系统一致性检查程序 `fck` 会在系统启动时自动调用，除非专门关闭（`fastboot`）。它的功能是检查 inode 索引、空空间、链接、目录项、路径名和超级块。然而，它不会执行表面扫描或重映射坏块。

详细来说，这里是各种操作环境可能命令的摘要。请注意，这些命令并不一定包含该命令的所有可能选项。请查看你的本地手册页获取选项列表。

### HP-UX

使用以下命令重启 HP-UX 系统。

```
reboot [-t time] [-m message]
```

`time`: `+`分钟数（例如 `+5` 表示从现在起 5 分钟后），`hh:mm` 的绝对时间，或 `"now"` 直到重启消息：关于即将到来的重启的要显示的消息。

使用以下命令停止 HP-UX 系统。

```
reboot -h [-t time] [-m message]
```

参数与 `reboot` 相同。

使用以下命令同步磁盘并调用新的运行级别。

```
sync; init [run-level]
```

`Run-level`：本章较早描述的选项之一。

使用以下命令执行优雅关机。

```
# #sync [run-level]
```

与启动系统一样，关闭系统会在系统控制台和系统日志文件中反映正在发生的情况。

## 总结

回顾一下，在系统启动和关闭期间，当控制台不断输出信息时，请做一个明智的观察者；除非发生问题，否则请让你的其他系统管理技能处于后台准备就绪状态。这可能是你今天最轻松的任务。喝杯咖啡吧；你可能在今天晚些时候会需要它。

## 17 - 用户管理

由 David Gumkowski 和 John Semencar 编写

在执行用户管理时，你几乎会在系统管理的每个领域都会用到所有用户。无论是保持磁盘尽可能空闲、寻找系统瓶颈、回答问题还是添加新用户，你的工作几乎完全围绕机器用户并为用户服务。

本章涉及的操作严格限于用户 ID 的管理。将涉及添加、删除、修改、移动、跟踪、检查和限制用户。本节描述了特殊的 ID 和用户 ID 环境。

### 添加新用户

逻辑上，用户管理始于向新机器添加用户。在功能上，有多种方法可以向密码文件 `/etc/passwd` 添加信息。`/etc/group` 是另一个需要注意的文件，此外还有 shell 启动文件和系统邮件别名。

### 密码文件

`/etc/passwd` 的格式在大多数 Unix 版本中是一致的。该文件包含以下冒号分隔的条目：

```
username:password:uid:gid comments:directory:shell
```

在某些 BSD 类型系统中，该文件包含略有不同的冒号分隔条目：

```
username:password:uid:gid:user class:pswd change:acct expiration:id comments:directory:shell
```

用户名是用户在 Unix 登录提示符中输入的字符。通常，该字段由八个更少的字母数字组成，字母全小写。它应该是唯一的。该字段不应包含冒号，因为冒号被用作字段分隔符。为了最好的兼容性，该字段不应以连字符或加号开头。

密码字段是一个字段，可以有许多形式。条目可以为空，表示登录不需要密码。该位置可以包含最多 13 个字符，是用户密码的加密版本。该位置可以包含一个不在以下集合 `{ /0-9A-Za-z }` 中的字符，意味着该用户名的密码无法登录。例如，`*` 不在此集合中。如果它在其中，则该用户名是一个无法登录的有效账户。

此外，在 IRIX 和 AI-UX 下，密码条目可以包含一个逗号，后跟一个或两个字符。

字符（按顺序）为 `/0-9A-Za-z`。`/` 字符等于数字 0，`z` 等于 63。使用数值值引用字符是常见的。这些字符分别表示密码有效的周数，以及在允许更改密码前必须过期的周数。如果前者为零（点），用户必须在下次登录时更改密码。安全专家的人士通常反感这种做法，如果后者大于前者，则只有管理员可以更改密码。

> 提示：如果系统没有内置用户基础密码选择功能，Alec Muffett Crack 工具可以帮助你完成这项工作。

`uid` 或用户 ID 是用户名的某个唯一数值。通常，这个值是一个 0 到 65535 的正数，尽管某些系统可以处理不建议的双精度用户 ID。如果这是非交换的，则所有具有相同 user id 的用户名看起来都像同一个（第一个）用户名。某些用户 ID 是预留或特殊的；它们包括：

| ID | 描述 |
| :--- | :--- |
| 0: | 超级用户 `Superuser` |
| 1-10: | 守护和伪用户 |
| 11-99: | 系统、预留和“著名”用户 |
| 100+: | 普通用户 |
| 60001: | `"nobody"`（偶尔为 32000 或 65534） |
| 60002: | `"noaccess"`（偶尔为 32001） |

`gid` 或组 ID 是用户名的默认组 ID。此数字对应 `/etc/group` 文件中的一个条目。该文件稍后描述。

`uid` 字段在历史上被称为 GECOS 或 GCOS 信息，源于其所属的操作系统。为了让一个通用字段准确地显示此信息，它应该包含用户的真实姓名、公司或办公室、办公室电话和电话号码，并用逗号分隔。并不是所有条目都需要指定，尽管如果尝试保持通用的 GECOS 语法，必须保留占位符。例如，`HomerUser...,888TAM-HOME` 将显示用户的真实姓名和电话号码。真实用户名也会作为邮件头部的一部分由邮件系统显示。

`directory` 字段通常被称为用户的主目录或初始工作目录。基本上，它是系统在用户登录后放置的目录。`shell` 字段是命令解释器。许多 shell 如 `sh` `Bourne`、`ksh` `Korn`、`csh` `tcsh`、`BASH` `Bourne`。注意，如果指定了，它是默认的用户名。

`class` 字段未使用，但用于指定用户名。`pswd change` 字段指示何时必须更改密码。`acct expiration` 字段是自 epoch 以来账户过期的秒数。此外，在 IRIX 和 AI-UX 下，密码文件可以包含其他类型的条目：

| 特性 | 描述 |
| :--- | :--- |
| `+username` | 包含该显式用户名 |
| `-username` | 排除掉该显式用户名 |
| `+netgroup` | 包含目标组的所有用户 |
| `-netgroup` | 排除目标组的所有用户 |

通常，如果指定了 `uid`、`gid`、`comments`、`directory` 或 `shell` 字段，它们将取代 YP 发送的值。此外，请注意这些条目是按顺序取的，所以是第一个而不是最后一个出现的决定了结果。

### Shadow 密码文件

由于 `/etc/passwd` 是全局可读的，具有安全意识站点通常使用影子密码方案，该方案将加密的密码重定向到另一个受限制的读取文件，该文件可能包含或不包含其他信息。采用这种方案是因为如果用户的选择不当，现在的普通机器可以反复破解用户密码。糟糕的选择包括任何字典单词、登录名、密码或用户 ID 注释中包含的任何信息。各种 UNIX 变体中用于 shadow 文件的方案差异很大。

例如，IRIX 和 Solaris 系统有一个名为 `/etc/shadow` 的文件，该文件由 `pwconv` 命令生成，包含以下内容：

```
username:pswd:lastchg:min:max:warn:expire:flag
```
