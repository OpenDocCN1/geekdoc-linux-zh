# pack, pcat, unpack — 压缩和解压文件

### Synopsis

```
/usr/bin/pack [-f][-] file...
/usr/bin/pcat file...
/usr/bin/unpack file...
```

## Description

`pack`
`pack` 将指定文件以压缩存储。在可能（且有用）的情况下，每个指定的输入文件将被替换为名为 `file.z` 的压缩文件，其访问模式、访问和修改日期以及所有者与 `file` 相同。当 `pack` 成功时，原始文件将被删除。

输入文件的大小和字符频率分布决定了压缩量。由于解码树形成了每个 `z` 文件的第一部分，通常压缩小于三个块的文件是不值得的。然而，你可能会发现压缩某些小文件是值得的，例如打印图或图片，它们的字符频率分布非常倾斜。

文本文件通常会缩小到原始大小的 60–75%。加载模块使用较大的字符集且字符分布更均匀，压缩效果不明显。压缩后的版本通常是原始大小的 90%。`pack` 返回的值是未能压缩的文件数。在以下情况下将不进行任何压缩：

- 文件已压缩。
- 文件名超过 14 字节。
- 文件是一个目录。
- 文件无法打开。
- 文件是空的。
- 压缩未节省任何磁盘存储块。
- 已存在一个名为 `file.z` 的文件。
- 无法创建 `.z` 文件。

处理过程中发生 I/O 错误。文件名不能超过 14 字节，以便留出附加 `.z` 扩展名的空间。你不能压缩目录。

`pcat`
使用 `pcat` 命令处理压缩文件的方式与你使用 `cat(1)` 命令处理普通文件的方式相同。你不能将 `pcat` 作为过滤器使用。指定的文件将被解压并写入标准输出。`pcat` 返回其无法解压的文件数。在以下情况下解压可能会失败：

- 文件无法打开。
- 文件不是从 `pack` 命令输出的。

`unpack`
`unpack` 命令扩展由 `pack` 创建的文件。对于命令中指定的每个文件，都会搜索名为 `file.z` 的文件（如果 `file` 以 `.z` 结尾，则只查找 `file`）。如果该文件看起来是一个压缩文件，它将被替换为解压后的版本。新文件的文件名去掉了 `.z` 后缀，且其访问模式、访问和修改日期以及所有者与 `pack` 文件相同。

`unpack` 返回其无法解压的文件数。在以下情况下解压可能会失败：

- 文件无法打开。
- 文件不是从 `pack` 命令输出的。
- 已存在一个具有解压名称的文件。
- 无法创建解压的文件。
- 文件名（不包括 `.z` 扩展名）超过 14 字节。

## 系统上生效了 NIS 或 NIS+，passwd

当更改 NIS 或 NIS+ 密码时会更新 NIS 或 NIS+ 数据库。NIS 或 NIS+ 密码可能与本地机器上的密码不同。如果 NIS 或 NIS+ 正在运行，使用 `passwd -r` 来更改本地机器上的密码信息。

`pwconv` 命令根据 `/etc/passwd` 中的信息创建并更新 `/etc/shadow`。`pwconv` 依赖于 `/etc/passwd` 文件中密码字段的特殊值 `x`。值 `x` 表示该用户的密码已在 `/etc/shadow` 中，不应进行修改。

如果年龄限制（aging）足够，则将进行检查以确保密码符合构造要求。当你第二次输入新密码时，系统会比较两个新密码的副本。如果两个副本不相同，将重复提示输入新密码的循环，最长持续两分钟。

密码必须满足以下要求：

- 每个密码必须至少包含 `PASSLENGTH` 个字符，其中 `PASSLENGTH` 在 `/etc/default/passwd` 中定义并设置为 6。仅前八个字符有效。
- 每个密码必须包含至少两个字母字符和至少一个数字或特殊字符。在这种情况下，字母指的是所有大写或小写字母。
- 每个密码必须与用户的登录名以及该登录名的任何反转或循环移动不同。为了比较目的，大写字母及其对应的小写字母视为等价。
- 新密码与旧密码至少不同三个字符。为了比较目的，大写字母及其对应的小写字母视为等价。

如果满足所有要求，默认情况下 `passwd` 命令会咨询 `/etc/nwitch.conf` 以确定更新哪些存储。它会搜索 `passwd` 和 `passwd_compat` 条目。与这些目相关的源（存储）将被更新。然而，支持的密码更新配置限于以下五种情况。不遵守配置将导致用户无法登录系统。

- `passwd: files`
- `passwd: files nis`
- `passwd: files nisplus`
- `passwd: compat (==> files nis)`
- `passwd: compat (==> files nisplus)`
- `passwd_compat: nisplus`

拥有 NIS+ 密码表的网络管理员可以更改任何密码属性。

在文件情况下，超级用户（任何实际和有效 UID 等于 0 的用户，参见 `id(1)` 和 `su(1)`）可以更改任何密码。`passwd` 不会提示超级用户旧密码。超级用户不受强制遵守密码年龄或密码构造要求。

超级用户可以通过在响应新密码提示时按回车键创建一个空密码。（此过程与 `passwd -d` 不同，因为仍然会显示密码提示。）如果 NIS 正在生效，根主机的超级用户可以更改任何密码而无需提示旧 NIS 密码，且不受强制遵守密码构造要求。

如果使用了 `-r nisplus` 参数，用户可以使用 `-s` 选项显示其所属登录名的密码属性。否则，`-s` 参数限制为超级用户。

```
显示格式为：
name status mm/dd/yy min max warn
```

或者，如果不存在密码年龄信息：

- `name status`
`name` 是用户的登录 ID。`status` 是 `name` 的密码状态：`PS` 表示有密码或已锁定，`LK` 表示已锁定，`NP` 表示无密码。
`mm/dd/yy` `name` 上次更改密码的日期。注意，所有密码年龄日期都根据格林尼治标准时间（通用时间）确定，因此在其他时区可能会相差一天。
`min` `name` 更改密码之间所需的最少天数。`MINWEEKS` 在 `/etc/default/passwd` 中找到并设置为空。
`max` `name` 密码有效的最大天数。`MAXWEEKS` 在 `/etc/default/passwd` 中找到并设置为空。
`warn` 密码过期并命名之前相对于 `max` 的天数。
