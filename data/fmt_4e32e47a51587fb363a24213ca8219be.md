
## 日志系统

Linux 日志系统的主程序是 `syslogd` 守护进程。当系统启动时，此守护进程由启动脚本运行。系统中的几乎任何程序都可以使用日志文件，包括应用程序、驱动程序和其他守护进程。

日志条目具有标准格式。程序可以以任何格式写入条目，但大多数遵循此约定。条目使用以下格式：

```
date  time  system  facility  message
```

- `date`：这是消息的日期。
- `time`：这是消息写入的时间。
- `system`：这是生成消息的主机名。网络上的系统可以共享中央计算机上的日志文件。
- `facility`：这是生成消息的进程名称和 `PID`（进程 ID）。
- `message`：这是消息的文本内容。

## 摘要

- **任务调度**：可以使用 `cron` 自动执行任务。`cron` 是一个调度系统或单个用户任务的守护进程。系统 `cron` 任务是执行全系统定期任务的 `crons`。单个用户可以创建用户 `cron` 任务，仅为自己执行任务。
- **系统任务**：系统 `cron` 任务的调度通过 `/etc/crontab` 文件定义。该文件包含分钟、小时、日期、月份和星期几的字段，以及要在选定时间运行的程序。要运行的程序位于 `/etc/cron.X` 目录中。`X` 代表 `daily`（每日）、`weekly`（每周）等。
- **用户任务**：用户 `cron` 任务在用户的家目录中通过文本编辑器定义。然后，用户使用 `crontab` 命令告知系统该用户有要执行的 `cron` 任务。用户 `cron` 任务位于 `/var/spool/cron` 目录中。
- **核心转储**：核心转储是程序失败时内存中所有内容的列表。这些文件可以由程序员查看，以确定导致程序失败的原因。核心转储的大小可以使用 `ulimit` 命令进行限制。核心转储可能会占用大量磁盘空间，应进行备份并删除。
- **进程监控**：进程是在 Linux 操作系统上运行的程序。应监控进程的运行时和 CPU 使用情况。可以使用 `ps` 命令查看它们。有可用工具来优先处理、终止、挂起和重启进程。
- **交互式视图**：进程也可以使用 `top` 程序查看。`top` 提供正在运行的进程、CPU 使用率、内存使用率和交换分区使用率的交互式视图。有可用的 GUI 程序来查看和管理进程。也有可用的 GUI 应用程序来显示内存和 CPU 使用率的图表和图形。
- **文件系统配额**：Linux 操作系统允许配置文件系统配额。配额使 Linux 能够根据软限制和硬限制来限制文件系统的使用。软限制是数值，当达到这些数值时，仅显示警告消息，表示已达到软限制。达到硬限制后，不允许用户进一步写入。
- **日志记录**：Linux 通过 `syslog` 守护进程提供日志记录。日志文件写入 `/var/log` 目录，并可由应用程序、驱动程序和其他守护进程使用。

### 安全概述

安全是每个拥有连接到互联网的计算机的人都必须了解的一个话题。有些人认为安全仅仅是为了保护关键数据，如国防信息或每周工资单数据。实际上，计算机和网络安全与每个人息息相关。

一些狂徒似乎只想搞破坏。这些人勤奋地寻找方法来`破解`或干扰计算机系统。来自这些个人的对你计算机系统的攻击可能只是无害的，仅仅是为了证明他们能做到；但其他人会出于恶意目的攻击你的系统，即不仅闯入你的系统，还会造成严重损害。还有一些人攻击你的系统并非为了制造问题，而是为了利用你的计算机作为平台向其他人发起攻击。通常，被入侵的计算机被用来对其他媒体计算机发起拒绝服务攻击。随着当今技术提供`“始终连接”`的互联网接入，计算机比以往任何时候都更容易受到安全漏洞的威胁。

安全有一个目的——保护资产。在大多数历史时期，安全意味着拥有坚固的墙壁和严密守卫的门来阻止坏人进入。这种策略在集中式计算机系统中运作良好，那里只有少数人获得访问权限，且没有外部连接。然而，由于今天的业务是通过大型、易于访问的网络进行的，连接的计算机变得更加脆弱。

要使你的计算机完全安全的唯一方法是仅在一个锁定的房间里使用它，并且没有任何外部通信手段。在大多数情况下，这不是一个可行的选择，因此必须使用其他手段来保护你的系统。

安全是一个持续的过程，由四个阶段组成——保护、监控、测试和改进。这些阶段作为连续过程实施。
