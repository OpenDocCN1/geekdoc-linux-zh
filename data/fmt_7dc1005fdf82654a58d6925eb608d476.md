
前一个列表的输出如下：

```
0
1
2
3
4
5
```

在列表 4.7 中，程序显示变量 `num` 的值并增加变量的值，直到 `do-while` 循环的条件评估为假。

# for 循环

`for` 循环按固定次数迭代循环体。它由三部分组成：初始化、条件表达式和后表达式。初始化部分为变量初始化一个值，并只执行一次。初始化部分之后是 `conditional_expression` 部分，包含要评估的条件。`post_expression` 用于递增或递减控制循环计数器变量。

`for` 循环的语法如下：

```
for(initialization;conditional_expression;post_expression)
```

如果条件表达式的值为假，则执行 `for` 循环之后的语句。如果条件表达式的值为真，则执行 `for` 循环体。直到条件表达式评估为假，`for` 循环继续执行。简单或复合语句代表 `for` 循环体。

注意，当 `for` 包含简单语句时，循环体不使用大括号。列表 4.8 显示了带有简单语句的 `for` 循环：

### 列表 4.8：使用 for Loop

```c
#include <stdio.h>

int main() {
    int num;
    int num1;
    printf("Enter the value of num\n");
    scanf("%d", &num1);
    for(num=num1; num<=5; num++)
        printf("%d", num);
    return 0;
}
```

前一个列表的输出如下：

```
Enter the value of num
9
1
2
3
4
5
```

在列表 4.8 中，变量 `num` 初始化为 `num1`，并每次加 1，直到 `for` 循环条件变为假。当 `for` 包含另一个循环时，被称为嵌套循环。在嵌套循环中，执行从外层循环传递到内层循环。这意味着对于外层循环的每次迭代，内层循环都会完整执行一次。列表 4.9 显示了使用嵌套循环的示例：

### 列表 4.9：使用嵌套循环

```c
#include <stdio.h>

int main() {
    int i,j;
    for(i=1;i<=6;i++) {
        for(j=1;j<=i;j++)
            printf("%d",j);
        printf("\n");
    }
    return 0;
}
```

前一个列表的输出如下：

```
1
12
123
1234
12345
123456
```

# 使用跳转语句

跳转语句是将控制从程序的某部分转移到另一部分的语句。C 语言支持的跳转语句有：

- `break`
- `continue`
- `goto`

让我们详细讨论这些语句。

## break 语句

`break` 语句用于中断任何类型的循环以及 `switch` 语句。中断循环意味着终止循环。列表 4.10 显示了使用 `break` 语句的示例：

### 列表 4.10：使用 break statement

```c
#include <stdio.h>

int main()
{
    int num1;
    int j = 1;
    printf("Enter a number to check whether it is a Prime or not \n");
    scanf("%d", &num1);
    while(j <= num1-1)
    {
        if(num1 % j == 0)
        {
            printf("Number entered by you is not a Prime number\n");
            break;
        }
        j++;
    }
    if(j == num1)
    {
        printf("Number entered by you is a Prime number\n");
    }
    return 0;
}
```

上述列表的输出如下：

```
输入一个数字以检查它是否为质数
你输入的数字不是质数
```

在列表 4.10 中，变量 `j` 被初始化为值 2，并使用 `while` 循环来检查你输入的数字是否为质数。如果 `num % j` 条件等于 0，则会出现消息“Entered by you is not a Prime number”，并且 `break` 语句将跳出循环。如果第一个条件 `num % j=0` 对于所有从 `j>=2` 到 `num-1` 的值都为假，那么 `num` 将是一个质数，并显示消息“Entered by you is a Prime number”。

## continue 语句

`continue` 语句会跳出当前循环的执行，然后继续执行下一个条件。然而，`break` 语句会在满足循环的特定条件时跳出整个循环。列表 4.11 显示了使用 `continue` 语句的示例：

### 列表 4.11：使用 continue 语句

```c
#include <stdio.h>

int main() {
    int j;
    for(j=0;j<9;j++) {
        if(j==8) {
            continue;
        }
        printf("%d\n", j);
    }
    return 0;
}
```

上述列表的输出如下：

```
1
2
3
4
5
6
7
9
```

在列表 4.11 中，我们在 `if` 语句内部使用了 `continue` 语句。当 `j` 的值变为 8 时，执行控制离开当前循环并返回 `for` 循环。下一次迭代将显示剩余数字，直到 `j` 的值变为 9。因此，输出显示了从 1 到 9 的第一个数字，结果中排除了 8。

## goto 语句

`goto` 语句用于执行从一个语句到另一个语句的控制转移。用户定义的标签用于指定程序中的 `goto` 语句。使用 `goto` 语句的语法定义如下：

```
goto <label_name>;
```

```
<label_name>:statement;
```

在上述语法中，`<label_name>` 指定了用于转移控制的目标语句的用户定义标签。该标签后面应该跟着一个冒号，然后是目标语句。

列表 4.12 显示了使用 `goto` 语句的示例

### 列表 4.12：使用 goto 语句

```c
#include <stdio.h>

int main()
{
    int a;
    for(a=1;a<=5;a++)
    {
        if(a == 3)
            goto lbl1;
        else
            printf("%d\n", a);
    }
lbl1:
    printf("ABC\n");
    return 0;
}
```

上述列表的输出如下：

```
1
2
3
ABC
```

在列表 4.12 中，当 `a` 的值为 1、2 和 3 时执行循环。一旦 `a` 的值变为 4，`goto` 语句就会将控制转移到 `lbl` 标签，该标签终止了 `for` 循环。当 `goto` 语句将控制转移到 `lbl` 标签时，会出现消息“ABC”。

## 探索数组的类型

数组是一组相同类型的有序数据项。它可以大致分为两类：一维数组和多维数组。一维数组只有一个下标，而多维数组有 `n` 个下标，其中 `n` 代表数组的维度。多维数组可以进一步分为二维数组和三维数组。

现在，让我们学习以下数组类型：

- 一维数组
- 二维数组

## 一维数组

一维数组或单维数组用于存储相同类型的值列表。一维数组中的元素使用从 0 到小于数组大小的索引进行存储。一维数组中的每个元素通过相同的名称和下标来访问。一维数组类似于行矩阵或列矩阵。现在，让我们在后续章节学习如何声明、初始化和处理一维数组。

### 声明一维数组

与普通变量类似，在使用之前需要声明数组。一维数组可以使用以下语法声明：

```
data_type array_name[size];
```

在上述语法中，`data_type` 代表数组类型，`array_name` 代表数组名称，`size` 代表定义的元素数量。所有元素都是相同类型。

### 初始化一维数组

一旦声明了一维数组，你可以逐个初始化数组。初始化一维数组单个元素的语法为：

```
array_name[index] = value;
```

在上述语法中，`array_name` 代表数组名称，`index` 代表元素的位置，`value` 代表分配给数组的值。同时初始化所有元素的方法如下：

```
data_type array_name[size] = {value1, value2,...,value};
```

上述语法中，`data_type` 代表数组类型，`array_name` 代表数组名称，`size` 代表花括号内元素数量，`value1`、`value2`……`value` 分别赋值给数组的第一个、第二个……第 n 个元素。

## 二维数组

二维数组在数组名后包含两个下标。它用于存储包含相同数据类型值的表格。它类似于包含行和列的矩阵。在本节中，你将学习如何声明、初始化和处理二维数组。

### 声明二维数组

在 C 语言中，你可以使用以下语法声明二维数组：

```
data_type array_name[size1][size2];
```

在上述语法中，`data_type` 代表要声明的数组的数据类型，`array_name` 代表数组的名称，`size1` 代表行数，`size2` 代表列数。

下行代码声明了一个名为 `myArray` 的二维整数数组：

```
int myArray[4][5];
```

在上述的这行代码中，`myArray` 是一个包含 4 行 5 列的二维数组。

### 初始化二维数组

与一维数组类似，二维数组的元素可以逐个初始化，也可以一次初始化。初始化二维数组元素的语法如下：

```
data_type array_name[size][size] = {value1, value2, value3,...value};
```

在上述语法中，`data_type` 代表数组的数据类型，`array_name` 代表数组的名称，第一个 `size` 代表数组的行数，第二个 `size` 代表数组的列数，`values` 按行顺序赋值给数组的元素。语法右侧的元素值必须括在大括号内，并用逗号分隔。

下行代码初始化了一个二维整数数组 `myArray`：

```
int myArray[2][3] = {10, 20, 30, 40, 50, 60};
```

上述代码中的元素初始化等同于如下初始化每个数组：

```
myArray[0][0] = 10;
myArray[0][1] = 20;
myArray[0][2] = 30;
myArray[1][0] = 40;
myArray[1][1] = 50;
myArray[1][2] = 60;
```
