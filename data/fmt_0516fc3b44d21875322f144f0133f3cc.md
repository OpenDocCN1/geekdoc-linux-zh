
`assert` 语句不应用于 Python 在优化模式（通过解释器的 `-o` 选项指定）运行时必须执行的代码。特别是，使用 `assert` 检查用户输入是一个错误。相反，`assert` 语句用于检查应该为真的事情；如果违反了这些检查，它代表程序中存在 Bug，而不是用户的错误。

例如，如果之前显示的 `write_data()` 函数旨在供用户使用，那么 `assert` 语句应该被替换为常规——除非解释器在优化模式下运行（此时其被设置为 `False`）。

除了 `assert` 之外，Python 还提供了一个内置的只读变量 `__debug__`，除非解释器在优化模式下运行，否则其设置为 `True`。程序可以根据需要检查此变量。

`assert` 和 `__debug__` 的使用允许对程序进行双模式开发。在调试模式下，可以在代码中大量使用断言和调试检查以验证操作正确。在优化模式下，所有的额外检查都会被剥离，产生额外的性能损失。

## 函数与函数式编程

大型程序被拆分为函数以获得更好的模块化和维护性。Python 定义函数非常简单，但也包含了许多来自函数式语言的特性。本章介绍了函数、作用域规则、闭包、装饰器、生成器、协程和其他编程特性。此外还描述了列表推导式和生成器表达式——都是声明式编程和数据处理的强大工具。

### 函数

函数使用 `def` 语句定义：

```python
def add(x,y):
    return x + y
```

函数体就是一组在函数被调用时执行的语句。你通过编写函数名后跟函数参数元组来调用函数，例如 `a = add(3,4)`。参数的顺序和数量必须与函数定义匹配。如果存在差异，将抛出 `TypeError`。

你可以通过在函数定义中赋值为参数函数附加默认参数。例如：

```python
def split(line,delimiter=''):
    statements
```

当函数定义了一个带有默认值的参数时，该参数以及之后的所有参数都是可选的。如果在函数定义中没有为所有可选参数赋值，将抛出 `SyntaxError`。

默认参数值始终被设置为函数定义时所提供的对象。这里有一个示例：

```python
a = 10
def foo(x=a):
    return x
a = 5
foo()
```

返回 `10`（默认值未改变）

此外，使用可变对象作为默认值可能会导致意外的行为：

```python
def foo(x, items=[]):
    items.append(x)
    return items
foo(1) # 返回 [1]
foo(2) # 返回 [1, 2]
foo(3) # 返回 [1, 2, 3]
```

默认参数保留了从之前的调用所做的修改。为了防止这种情况，最好使用 `None` 并添加如下检查：

```python
def foo(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items
```

如果在最后一个参数名后添加星号 `*`，函数就可以接受任意数量的参数：

```python
def fprint(file, fmt, *args):
    file.write(fmt % args)
```

```python
# fprint 获取的 args 42, "hello world", 3.45
fprint(out, "%d %s %f", 42, "hello world", 3.45)
```

在这种情况下，所有参数都以元组的形式存放在 `args` 变量中。要将元组 `args` 像参数传递给函数，可以在函数中使用如下的 `*args` 语法：

```python
def printf(fmt, *args):
    # 调用另一个函数并传递 args
    print(sys.stdout, fmt, *args)
```

也可以通过显式命名每个参数并指定值来提供参数。这些被称为关键字参数。这里有一个示例：

```python
def foo(x,y,z=None):
    statements
```

```python
## 关键字参数调用
foo(x=3, y=22, w='hello', z=[1,2])
```

使用关键字参数时，参数的顺序并不重要。但是，除非有默认值，否则如果省略了任何必需参数，或者关键字名称与函数定义中的任何参数都不匹配，将抛出 `TypeError` 异常。此外，任何 Python 函数都可以使用关键字风格进行调用，因为使用具有描述性的参数名来定义函数通常是一个好习惯。

位置参数和关键字参数可以出现在同一个函数调用中，前提是所有位置参数必须在前，为所有非位置参数提供了值，并且没有参数值被定义了多次。这里有一个示例：

```python
foo('hello', 3, z=[1,2], y=22)
foo(3, 22, w='hello', z=[1,2]) # TypeError. w 有多个值
```

### 参数传递与返回值

如果函数的最后一个参数以 `**` 开头，则所有额外的关键字参数（那些不匹配任何其他参数的参数）将被放在一个字典中并传递给函数。这是编写接受大量潜在开放式配置选项函数的有用方法，因为这些选项如果作为参数列出将过于臃肿。这里有一个示例：

```python
def make_table(data, **params):
    # 从 params（一个字典）获取配置参数
    fgcolor = params.pop("fgcolor", "black")
    bgcolor = params.pop("bgcolor", "white")
    width = params.pop("width", None)
```

```python
# 没有更多选项
if params:
    raise TypeError("Unsupported configuration options %s" % list(params))
```

```python
make_table(items, bgcolor="white", border=1,
          style="grooved", padding=10,
          width=400)
```

你可以将关键字参数与可变参数列表结合，因为 `**` 出现在最后：

```python
### 接受任意数量的位置参数或关键字参数
def spam(*args, **kwargs):
    # args 是位置参数的元组
    # kwargs 是关键字参数的字典
```

关键字参数也可以使用 `**kwargs` 语法传递给另一个函数：

```python
def callfunc(*args, **kwargs):
    func(*args, **kwargs)
```

这种对 `**args` 和 `**kwargs` 的使用通常用于为其他函数编写包装器（wrappers）和代理。例如，`callfunc()` 接受任何参数组合并简单将它们传递给 `func()`。

当函数被调用时，函数参数只是指向所传递对象的名称。传递的底层语义并不整齐地契合任何单一风格，例如你可能从其他编程语言中了解的“按值传递”或“按引用传递”。如果你传递一个不可变值，则参数实际上看起来就像是按值传递的。但是，如果将一个可变对象（如列表或字典）传递给函数并在对其进行修改，这些更改将反映在原始对象中。这里有一个示例：

```python
a = [1, 2, 3, 4, 5]
def square(items):
    for i, x in enumerate(items):
        items[i] = x * x  # 原地修改 items
```

```python
square(a)  # 变为 [1, 4, 9, 16, 25]
```

改变其输入值的函数被认为具有副作用，它们会改变程序其他部分的状态。通常情况下，这是一种最好避免的编程风格，因为随着程序规模和复杂性的增加，此类函数可能会成为微妙编程错误的来源（例如，从阅读函数无法看出该函数是否具有副作用）。
