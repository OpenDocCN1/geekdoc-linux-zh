### 安装 Glibc

在 `glibc-2.1.3` 目录下解压 `glibc-crypt` 和 `glibc-linuxthreads`，而不是在 `/usr/src` 目录下。不要进入创建的目录。只需解压并保持原样。

Glibc 的几个默认参数需要修改，例如共享库的预期安装目录以及包含系统配置文件的目录。为此，您需要创建 `$LFS/usr/src/glibc-build` 目录并进入该目录：

```bash
root:src mkdir $LFS/usr/src/glibc-build
root:src# cd $LFS/usr/src/glibc-build
```

在该目录下，您创建一个名为 `configparams` 的新文件，包含以下内容：

- Begin configparams

`libdir=/lib`

`sysconfdir=/etc`

- End configparams

如果在编译过程中遇到与变量名中的非法字符 `45` 相关的错误，请运行以下命令对 `glibc-2.1.3` 目录应用 Glibc 补丁：

```bash
root:glibc-2.1.3# patch -Np1 -i ../glibc-2.1.3.patch
```

请注意，Glibc 的 `configure` 脚本可能会抱怨 `/usr/include` 目录中的某些文件太旧并将会被替换，或者某些符号链接不应存在于那里（例如 Linux 系统上存在的 `/usr/include` 符号链接）。如果它要求您移动 `scsi` 符号链接，请执行该操作。如果它说将用新的 Glibc 文件替换旧文件，您可以忽略它。在运行 `configure` 脚本时，Glibc 并不知道您正在 `$LFS` 环境下工作。

如果您已经安装了一个 glibc 版本，请切换到 `$LFS/usr/src/glibc-build` 目录并运行以下命令安装 Glibc：

```bash
root:glibc-build# ../glibc-2.1.3/configure \
> --prefix=/usr --enable-add-ons \
> --with-headers=$LFS/usr/include
root:glibc-build# make
root:glibc-build# make install_root=$LFS install
root:glibc-build# make install_root=$LFS
localedata/install-locales
root:glibc-build# localedef -i en_US -f ISO-8859-1 - en_US
```

在 `locatedef` 命令中，您必须将 "en-US" 和 "ISO-8859-1" 替换为符合您本地化需求的正确值。可以通过查看 `/usr/share/locale` 目录查找可用选项。

如果您的系统没有安装合适的 GCC 版本，请切换到 `$LFS/usr/src/glibc-build` 目录并使用您刚刚安装的 `gcc-2.95.2` 以下命令安装 Glibc：

```bash
root:glibc-build# CC=/usr/local/gcc2952/bin/gcc \
> ../glibc-2.1.3/configure --prefix=/usr --enable-add-ons \
> --with-headers=$LFS/usr/include
root:glibc-build# make
root:glibc-build# make install_root=$LFS install
root:glibc-build# make install_root=$LFS
localedata/install-locales
```

### 拷贝旧 NSS 库文件

如果您的常规 Linux 系统运行 `glibc-2.0`，您需要将 NSS 库文件拷贝到 LFS 分区。某些静态链接的程序仍然依赖 NSS 库，特别是那些需要查找用户名、`userid()` 和 `groupid()` 的程序。可以通过运行以下命令检查您的常规 Linux 系统使用的 C 库版本：

```bash
root:~# ls /lib/libc*
```

如果存在类似 `libc-2.0.7.so` 的文件，则您的系统使用 `glibc-2.0`。

如果存在类似 `libc-2.1.3.so` 的文件，则您的系统使用 `glibc-2.1`。

当然，微版本号可能不同（例如，您可能有 `libc-2.1.2` 或 `glibc-2.1.1`）。

如果您有 `libc-2.0.x` 文件，运行以下命令拷贝 NSS 库文件：

```bash
root:~# cp -av /lib/libss* $LFS
```

## 安装 Gzip

此包在某些平台上会导致编译问题。

### 内容

`Gzip` 包包含 `gunzip`、`gzexe`、`gzip`、`zcat`、`zcmp`、`zdiff`、`zforce`、`zgrep`、`zmore` 和 `znew` 程序。

### 描述

#### gunzip

`gunzip` 解压缩由 `gzip` 压缩的文件。

#### gzexe

`gzexe` 允许就地压缩可执行文件并在运行时自动解压并执行（但会损失性能）。

#### gzip

`gzip` 使用 Lempel–Ziv 编码 (`LZ77`) 缩小文件大小。

#### zcat

`zcat` 解压缩命令行中的文件列表或其标准输入，并将解后的数据写入标准输出。

#### zcmp

`zcmp` 在压缩文件上调用 `cmp` 程序。

#### zdiff

`zdiff` 在压缩文件上调用 `diff` 程序。

#### zforce

`zforce` 为所有 `gzip` 文件强制添加 `.gz` 扩展名，以便 `gzip` 再次进行压缩。这对于在传输后文件名被截断的文件很有用。

#### zgrep

`zgrep` 在压缩文件上调用 `grep` 程序。

#### zmore

`zmore` 是一个过滤器，允许在软拷贝终端上逐屏查看压缩文件或纯文本文件（类似于 `more` 程序）。

#### znew

`znew` 将文件从 Z (`compress`) 格式重新压缩为 `.gz` (`gzip`) 格式。
