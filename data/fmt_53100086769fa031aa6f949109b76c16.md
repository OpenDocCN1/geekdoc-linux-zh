## 任务 #3：确定昨天的两位数月份 (MONTH):

```bash
yesterday_mm:
# 如果今天是1号，我们需要确定上个月是几月
# $mm 是今天的两位数月份
# $sd 是今天的两位数日期。
if [ $mm == "01" ] || [ $sd == "01" ]; # 如果今天是 1 月 1 日，
then yesterday_mm=12
elif [ $mm == "01" ]; # 如果今天是本月的1 号，
then (( yesterday_mm = mm - 1 )) # 是当前月份
else yesterday_mm=$mm

# 数学计算的结果并不保留前零：
# 如果月份是 03（3月），"month - 1" 的结果将是 2，而不是 02。
# 我们需要使用 $yesterday_mm 判断是一位数还是两位数；
# 注意：shell 有一个内置变量用于确定字符串长度：${#_}
LENGTH=${#yesterday_mm}
if [ $LENGTH -eq 1 ];
then yesterday_mm=0$yesterday_mm # 强制将月份 (mm) 为两位数。
fi
```

## 快速总结：

如果你需要了解更多信息，例如 Perl 的 sort 命令，可以尝试：

`perloc -f sort` （并按回车键）

'-f' 选项表示“告诉我关于这个函数的信息”。

或者，当你需要更多关于 Perl 的 'sort' 命令的信息时，可以尝试此命令：

`perloc -q sort`

'q' 选项表示“查询所有常见问题章节”。

而且你完全不需要使用任何选项（如 -f 或 q）：

`perloc faq` # faq 常见问题。

`perloc perdoc` # 关于 perl 命令的文档。

`perloc sort`

`perloc Cwd`

`perloc -i cwd` # -i 忽略大小写。

注释：'perdoc sort' 的输出与 'perdoc -f sort' 的输出并不相同；如果你需要关于排序的细节，请同时阅读两者。

注意：主命令有 -k 选项（k = 关键字），但 perdoc 没有。

Perl 的等效选项是 -q 选项。（见上文示例）。
