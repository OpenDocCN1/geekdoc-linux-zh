# mailx, mail, Mail — 交互式消息处理系统

### 概要

`mailx [-BDeHiInNuvV-] -f [file|folder] [-T file] [-u user]`

`mailx [-BdfintTuv-] [-b b] [-c cc] [-h number] [-r address] [-s subject] recipient...`

`/usr/ucb/mail...`

`/usr/ucb/mail/...`

## 描述

列出的 mail 命令为电子发送和接收邮件提供了一个舒适、灵活的环境。

在读取邮件时，`mail` 命令便于保存、删除和回复消息。在发送邮件时，`mail` 命令允许您在输入消息时对消息进行编辑、审查和其他修改。

每个用户的收件邮件都存储在一个名为“邮箱”（mailbox）的标准文件中。

当调用 `mail` 命令读取消息时，邮箱是查找这些消息的默认位置。随着消息被读取，它们将被标记为移动到辅助文件进行存储，除非采取了特定操作，否则消息将需要再次查看。此辅助文件称为 `mbox`，通常位于用户的 `HOME` 目录下。你可以将消息保存到指定名称的辅助文件中。消息将一直保留在辅助文件中，直到最终被删除。

你可以使用 `-f` 选项访问辅助文件。然后，你可以使用与处理主邮箱相同的命令来读取或其他方式处理辅助文件中的消息。当您使用 `-f` 选项访问辅助文件时，该文件被视为当前邮箱。

## 选项

在命令行上，以横字符 (`-`) 开头。任何其他参数都将被视为目的地（收件者）。如果你没有指定收件者，`mailx` 将尝试从邮箱中读取消息。

- `-B` 不要干扰标准输入或标准输出。
- `-b bcc` 将密抄列表设置为 `bcc`。如果 `bcc` 包含多个名称，请将 `bcc` 放在引号中。
- `-c cc` 将抄送列表设置为 `cc`。如果 `cc` 包含多个名称，请将 `cc` 放在引号中。
- `-d` 开启调试输出。（既不特别有趣，也不推荐）
- `-e` 测试是否存在邮件。如果有邮件可读，`mailx` 不打印任何内容并以状态的返回码退出。
- `-f` 将消息记录在与第一个收件者同名的文件文件中。如果设置了记录变量，则将覆盖它。
- `-f [file]` 从文件而非邮箱读取消息。如果你未指定文件，则使用 `mbox`。
- `-[+] [folder]` 使用 `folder` 目录中的文件文件夹（与 `folder` 命令相同）。该目录的名称列在 `folder` 变量中。
- `-H` 仅打印头信息摘要。
- `-h number` 到目前为止的网络跳数。提供此选项供网络软件使用，以避免无限传递循环。此选项及其参数将传递给传递程序。
- `-I` 在打印邮件消息时包含新闻组和文章 ID 头部。此选项要求你必须同时指定 `-f` 选项。
- `-n` 忽略中断。
- `-N` 不打印初始头信息摘要。
- `-n` 不从系统默认的 `mailx.rc` 或 `Mail.rc` 文件初始化。
- `-s subject` 将主题头部字段设置为 `subject`。如果 `subject` 包含空格，你必须将 `subject` 放在引号中。
- `-T file` 在读取消息后将消息 ID 和文章 ID 头部记录在文件中。此选项也会设置 `-I` 选项。
- `-t` 扫描输入的 `To; Cc;` 和 `Bcc:` 字段。忽略命令行上的任何收件者。
- `-U` 将 UUCP 风格地址转换为 Internet 标准。覆盖 `conv` 环境变量。
- `-u user` 读取用户邮箱。只有当用户不受保护时，此选项才有效。
- `-V` 打印 `mailx` 版本号。
- `-v` 将 `-v` 标志传递给 `sendmail(IM)`。
- `~` 即使不是从 TTY 读取，也解释输入中的波浪转义。

### 操作数

`recipient` 消息地址。

## 使用

# 启动邮件

在启动时，`mailx` 执行系统启动文件 `/etc/mailx.rc`。如果作为 `mail` 或 `Mail` 被调用，则使用系统启动文件 `/etc/mail/Mail.rc`。

系统启动文件设置了初始显示选项和别名列表，并为某些内部变量赋值。这些变量是带有标记和数值的参数，可以通过 `set` 和 `unset` 命令进行设置和清除。见第 779 页“内部变量”。如果使用 `-n` 选项启动 `mailx`，`mail` 命令将不执行系统启动文件。

在启动文件中普通命令是合法的，以下命令除外：`!`, `Copy`, `edit`, `followup`, `Follow`, `hold`, `preserve`, `reply`, `Reply` 和 `visual`。当启动文件包含错误时，其余行将被忽略。

执行系统启动文件后，`mail` 命令将执行可选的启动文件 `$HOME/.mailrc`，它可以用于覆盖系统启动文件设置的内部变量值。
