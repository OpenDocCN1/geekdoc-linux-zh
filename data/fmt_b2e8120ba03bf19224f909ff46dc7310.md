
并自动连接（`Netscape` 将负责发送“anonymous”用户名和电子邮件地址作为密码）：

“anonymous”ftp 用户被重定向到 `/home/` 目录，该目录对他们来说似乎是根目录（他们无法访问其上任何目录）。我将我想提供的文件放在子目录 `/home/ftp/pub/` 中。

`/home/ftp/bin` 目录包含了远程用户可以执行的命令。在你的系统中，这些命令是：`compress`、`gzip`、`ls`、`sh`、`tar`、`zcat`，全部具有仅执行权限 (111)。

`/home/ftp/lib` 目录包含了匿名账户运行所需的设置文件（`editpasswd`、`group`、`ld.so.cache`）。`/home/ftp/lib` 目录包含了我允许匿名 ftp 用户运行的命令所使用的库文件。

`Red Hat 7` 使用 `xinetd` 代替 `inetd`，并且大多数网络服务默认禁用。如果你无法连接到自己或网络服务，你可能需要检查 `/etc/xinetd/` 目录下的文件并编辑服务名称，使其包含：`disabled = no`。这是出于安全考虑——你必须选择你需要的服务并仅启用它们。除非你需要使用，否则不要启用 `ftp`，该路径曾存在相当多的安全漏洞。如果你启用了网络服务，请务必保守地设置文件 `/etc/hosts.allow` 和 `/etc/hosts.deny` 以确保安全。

显示服务禁用的示例文件 `/etc/xinetd.ftp`：

```
{

    disable = yes

    socket_type = dgram

    protocol = udp

    wait = yes

    user = root

    server = /usr/sbin/tftpd

    server_args = -s /ftpboot

}
```

如果你没有这个文件，请 `cat` 查看你安装了哪些服务。如果使用 `setup` 命令（以 `root` 身份）启用了该服务，则大多数服务的守护进程将在系统启动时自动启动。

## 5.5.9 当我通过连接在上网时，如何从外部世界访问我的计算机？

唯一的困难是你的 IP 地址是由你的互联网服务提供商（ISP）从其 IP 地址池动态分配的，因此你的 IP 地址在每次连接时都是不同的（除非你与 ISP 采取了特定安排）。要从外部世界 `telnet`、`ftp` 或访问你的网页（由你的 `apache` Web 服务器提供），你必须知道自己的 IP 地址。要找到我当前的 IP 地址，我使用这个“接口配置”命令，它将在不带任何参数的情况下运行，显示你机器上所有活跃的网络接口：

```
/sbin/ifconfig
```

在我的机器上，这显示了关于以下三个部分的信息：`eth0`（通往家庭网络中其他计算机的第一个网络接口）、`lo`（回环接口，IP 为 `127.0.0.1` 的接口，每台机器上都必须存在）和 `ppp0`（第一个点对点协议接口）。我由 ISP 分配的当前 IP 地址由 `ppp0` 标题显示。你的 `Linux` 机器可以同时分配多个 IP 地址，所以如果你在家庭网络上使用“静态”IP，它仍然有效，但仅在你的家庭网络上可见。

一旦我知道了 IP 地址，我会通过 EQ 或发送给朋友，朋友就可以例如通过 `telnet` 或 `ftp` 访问我的计算机（他/她在我的机器上有一个账户）并在我的 `Linux` 机器上运行程序，或者在浏览器的“位置”中输入 `http://我的IP地址` 来浏览我的网页。如果该朋友在本地机器上运行的是 `Windows`，他/她就可以在我的机器上运行 `GUI` 程序。

我也可以写一个脚本，当我连接到互联网时自动通知我（将内容输入到文本文件中并使用 `chmod +x` 使其可执行）：

```bash
#!/bash

/sbin/ifconfig | notify email_address
```

脚本的第一行告诉我的计算机将此文本文件解释为 `bash` 脚本。第二行让脚本等待 15 秒（确保在 `ppp` 连接完全建立之前发送电子邮件）。第三行执行 `ifconfig` 命令并将输出通过管道发送到给我的 `email_address`，主题为“notification”。

访问你的家庭计算机的更灵活的方法是将其配置为拨号 `ppp` 服务器（作为你连接到 ISP 时使用的拨号客户端）。如果有人有简单的配方。

总结来说，与严格限制计算机流量的 `MS Windows 3.5/98` 不同，`Linux` 非常面向网络，并且很容易从外部和向你的计算机建立连接。强大的网络功能被认为是 `Linux` 的优势，但从真正的新手的角度来看，这可能是一个问题（参见下一个问题）。

## 5.5.10 我的家庭计算机会被入侵吗？

不幸的是，这是完全可能的，而且有很多方法可以做到。每当你连接到互联网服务提供商（ISP）时，你就面临风险。如果你想知道这是可能的，请阅读上一个答案。显然，如果你有永久的互联网连接（例如电缆调制解调器），风险要大；如果你的连接是瞬时的（通过电话调制解调器），风险则较低。

真正的危险是，入侵者如果能够登录你的账户，可能会发现（得知）“本地安全漏洞”并获得 `root` 权限。

为了保护，永远不要让陌生人登录你的计算机。为你的所有设置设置包含数字和字母的长密码。定期更改密码。在你的所有用户上强制密码策略的最佳方法是以 `root` 身份运行（如 `RedHat!.linux` 所示），并在“密码和账户策略”下将最小长度更改为 6 个或更多字符，即字母 0 到 2，密码更改后必须更改的天数设置为 90 天或。

文件 `/etc/issue` 和 `/etc/issue.net` 的内容在每次重启时都会重新创建（在使用 `script/etc/rc.local` 时）。因此，为了使更改永久生效，可以将这些文件设置为所有用户（包括 `root`）只读：

与其使用上一个命令，我可以编辑 `script/etc/rc.d/rc.local` 脚本并用 `###` 注释掉 5 行，相关部分如下：

```bash
# 这将在每次重启时覆盖 /etc/issue。因此，请对 /etc/issue 进行
# 任何你想做的更改，否则你将在重启时让它们被删除

### ### /etc/issue

### ### echo "$S" >> /etc/issue

### ### echo "$(uname -r) - $S $(uname -m)" >> /etc/issue

### ### cp /etc /etc/issue.net

### ### >> /etc/issue
```

另一个良好的安全措施是禁用 `ping`。`ping` 是你的计算机在受另一台计算机邀请时发送的一种类似声呐响应。它对于设置和调试也非常有用，可以证明你的机器在网络上是可用的。它可以用于探测你的机器和/或从该机器发送 `ping` 请求（“死亡之 ping”）。为了禁用对来自网络 `ping` 请求的响应，我使用了 IP 伪装（masquerading）。然后我稍微修改了以下命令和解释 `http://www.securityfocus.com/focus/linux/articles/imus-securing2.html`：

```
ipchains -A input -p icmp type echo-request -j pdrop - REJECT
```

`ipchains` 如下：

- 1. 添加了一条新规则。
- 2. 应用规则的链，在这种情况下，规则将应用于入站（`input`）数据包。
- 3. 应用规则的协议。在这种情况下，它是 `icmp`。
- 4. ICMP 类型，在这种情况下，`icmp echo-request` 将被拦截。“ICMP echo”意味着 `ping`。
- 5. 接口名称。在这种情况下，它是第一个拨号连接 `ppp0`。
- 6. 目标，或者说对所讨论数据包实际应该执行的操作。
- 7. 将所有匹配标准的数据包记录到系统日志文件中。

IP 伪装在本指南的“伪装”章节中进行了更详细的描述。这实际上是另一种安全预防措施。我偶尔会检查是否在我的系统上安装了“根内核（`root` kit）”。我使用工具“`chkrootkit`”（非常小，25k，从 `http://chkrootkit.org/` 下载）。

下载到之后：

```bash
su include password

cd /usr/local

tar xzvf /home/name/chkrootkit.tar.gz

cd /usr/local/chkrootkit

make

./chkrootkit
```
