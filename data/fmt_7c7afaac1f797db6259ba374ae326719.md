## Web 搜索
Firefox 导航工具栏内置了用于 Google 关键词搜索框。下拉菜单允许你搜索 Yahoo!、Answers、Creative Commons、Amazon.com 或 eBay。或者从下拉列表中选择“管理引擎”进入 Firefox 搜索引擎页面，你可以在那里从超过 20 种不同的引擎中进行选择。

## 查找文本
点击“编辑此页面”(`Edit In This Page`)，可以在窗口底部找到工具栏，用于搜索当前页面的文本字符串。这允许你搜索页面上的文本，而不会被弹出窗口干扰。输入文本字符串后，点击“查找下一个”(`Find Next`)或“上一个”(`Previous`)来搜索该字符串。你还可以点击“高亮”(`Highlight`)来高亮页面上字符串的所有实例。

## 调整网页文本大小
在 Mozilla 或 Firefox 中，有一个快速调整网页文本大小的快捷键。按住 `Ctrl` 键并按加 (`+`) 或 减 (`-`) 键。网页上的文本（大多数情况下）会相应变大或变小。那个字体小得离谱的页面突然变得可读。（记得按住 `Shift` 键来输入 `+` 字符）。

## 检查历史记录
选择“历史记录 → 显示侧边栏”，让历史记录侧边栏出现在 Firefox 屏幕上。通过侧边栏，你可以通过关键词搜索访问过的网站，以各种方式（按日期、网站名称、最常访问和最后访问）显示访问过的网站名称，并浏览和选择以重新访问网站。

Firefox 的一些最佳功能并不在表面。特别是，Firefox 的设计旨在实现安全计算，因此 Firefox 对默认允许和不予允许的操作非常谨慎。以下是 Firefox 的一些重要功能，有助于安全且风趣的 Web 浏览：

## 阻止弹出窗口
在 Firefox 中，默认阻止弹出窗口。如果你访问的一个尝试打开弹出窗口的页面，Firefox 会提示你“Firefox 已阻止此网站打开弹出窗口。点击此处查看选项……”。你可以选择允许此网站的弹出窗口、编辑你的弹出拦截器选项，或仅显示遇到的特定弹出窗口。

要查看或更改 Firefox 处理弹出窗口的方式，请选择“编辑 → 偏选项”(`Edit → Preferences`)并选择“Web 功能”(`Web Features`)。“阻止弹出窗口”(`Block Popup Windows`)选项被勾选（阻止弹出）或取消选中（允许弹出）。如果阻止了弹出窗口，你可以选择“允许的站点”(`Allowed Sites`)来添加你允许弹出窗口的站点。图 9-4 显示了 Firefox 遇到弹出窗口请求时的警告示例。

## 高级安全功能
通过 Firefox，你对哪些内容可以播放以及哪些软件可以下载到你的电脑有许多控制权。你可以从“偏选项”窗口查看或更改许多安全功能（选择“编辑 → 偏选项”）。“内容”(`Content`)选项卡允许你启用 Java 或 JavaScript、加载图像或阻止弹出窗口。“隐私”(`Privacy`)选项卡允许你管理 cookie、密码、历史记录和缓存信息。

访问 Mozilla Firefox 网站 (`www.mozilla.org/products/firefox`) 可获取更多关于 Firefox 的信息。有关如何从 Internet Explorer 切换到 Firefox 的帮助，请访问 Firefox 网站 `www.mozilla.org/products/firefox/switch.html`。

# 设置 Firefox

你有许多配置可以使 Firefox 运行得非常顺畅。以下章节描述了在 Firefox 中自定义浏览体验的一些方法。

## 设置导航器偏选项

你可以在“偏选项”窗口中设置 Firefox 偏选项。要打开 Firefox 偏选项，点击“编辑 → 偏选项”(`Edit → Preferences`)。出现“偏选项”窗口，如图 9-5 所示。

列表列出了你可能想从 Firefox 偏选项窗口更改的偏选项：

### 选择首页
要从“主页”(`Main`)选项卡中选择首页，你只需在“位置”框中输入 URL。它可以是一个本地文件 (`file://`) 或一个 Web 页面 (`http://`)。你还可以拥有多个首页，每个首页都会在 Firefox 启动时作为一个标签页出现，用竖线符号（`|`）分隔 URL（例如，`linuxuxtoys.net|redhat.com`）。

要填入你的首页位置，你还可以选择按钮。“使用当前页面”(`Use Current Pages`)将浏览器所有标签页上的当前页面添加为你的首页。“使用书签”(`Use Bookmarks`)按钮允许从你的书签列表中选择首页。“使用空白页”(`Using Blank Page`)将你的首页设置成 `about:blank`。

### 保存浏览信息
选择“隐私”(`Privacy`)选项卡来选择保存你的 Web 信息的方式。在“隐私”选项卡上，你可以选择如何保存与浏览历史记录相关的数据、你输入表单的数据、密码、下载的文件和 cookie。你可以选择清除历史记录、表单数据、密码、下载历史、cookie 和缓存的 Web 页面。如果你在别人的机器上使用 Firefox 并希望保持私密，清除这些信息是一个好主意。

### 设置语言
如果页面有多种语言版本，通过选择“高级 -> 通用”(`Advanced -> General`)并在“语言”(`Languages`)下选择“选择”(`Choose`)按钮，为特定语言设置一组偏选项列表。

### 阻止或启用内容
你遇到的一些内容在浏览器中播放或显示可能会很恼，甚至很危险。从“内容”(`Content`)选项卡中，针对弹出窗口、尝试安装扩展或图像的网站、图像显示、ava 内容和 javascript 内容选择允许和阻止的项目。你也可以为上述内容的设置通用规则设置例外。

### 定义标签页浏览
使用“标签页”(`Tabs`)选项卡上的选择来确定在打开新内容或关闭浏览器时如何使用标签页。

### 下载管理器和文件夹
选择文件下载时是否显示下载管理器。此外，你也可以选择被询问放置每个下载的文件，或者选择一个默认文件夹自动下载你的文件。通过“查看并编辑操作”(`View & Edit Actions`)配置要执行的操作。

“高级偏选项”(`Advanced Preferences`)选项卡可用于精调你的 Web 浏览体验。以下是你可能感兴趣的一些高级偏选项：

- 通用设置 — 高级部分中“通用”选项卡上的某些设置允许你更改辅助功能设置、浏览功能（如窗口自动调整大小和滚动）以及 Web 页面的显示语言。

### 获取浏览器更新
从“更新”(`Update`)选项卡，可以将 Firefox 设置为自动检查搜索引擎或已安装扩展和主题的可用更新。选择“更新历史”(`Update History`)查看你为 Firefox 安装的更新历史。

### 选择安全设置
从“加密”(`Encryption`)部分，可以选择哪些协议（SSL 和 TLS）是 Firefox 用于安全浏览的接受协议。还有一个“证书”(`Certificates`)部分，允许你管理证书以验证安全网站的真实性或向远程站点进行身份验证。（参见“安全 Firefox”部分获取更多关于使用 Firefox 安全 Web 浏览的信息。）

# 扩展 Firefox

Firefox 可以轻松处理大多数标准的 Web 内容（HTML、JPEG、文本文件）。然而，对于任何浏览器，某些内容都需要添加插件或辅助应用程序才能播放或显示该内容。Firefox 还允许你添加扩展来增强 Firefox 的功能。

## 使用插件

在 Firefox 中，通过在位置栏输入 `about:plugins` 可以查看安装了哪些插件。由于 Firefox 在 Fedora 和 RHEL 系统中提供，默认只安装了 NPAPI 插件封装器。

要找到适用于 Linux 系统 Firefox 的插件，请访问 Mozilla 插件页面 (`http://plugindoc.mozdev.org/linux.html`)。以下是你可能想添加到 Firefox 的几个插件：

- Adobe 插件 (`www.adobe.com/support/downloads`) — 显示 Adobe Systems PDF（便携文档格式）格式的文件。（如果没有安装此插件，Firefox 将使用 `evince` 命令在单独窗口中显示 PDF 文件。）

- Cult3D 插件 (`www.cult3d.com`) — 在 Web 上显示高质量、交互式的实时 3D 图像。（从网站点击“下载”找到插件。有一个可用的 `cult3d` RPM 包，需要定制以在 Mozilla 中运行。）
