## 21.4 结构的字段封装

结构的字段封装方法构成了这种数据类型的一个重要特性。[6]

我们以后通过下面的例子来加以说明。

```c
#include <stdio.h>
struct s {
    char a;
    int b;
    char c;
    int d;
}
void f(struct s s) {
    printf("a=%d; b=%d; c=%d; d=%d\n", s.a, s.b, s.c, s.d);
}
int main() {
    struct s tmp;
    tmp.a=1;
    tmp.b=2;
    tmp.c=3;
    tmp.d=4;
    f(tmp);
}
```

其中有2个单字节型char字段和2个4字节的int型变量。
