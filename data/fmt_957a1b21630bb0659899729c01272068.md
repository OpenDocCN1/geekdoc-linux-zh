# 并行处理

指通过将程序划分为多个可以同时执行的片段（每个片段在各自的处理器上运行）来加速程序执行速度的概念。在 N 个处理器上跨平台执行的程序，其执行速度比使用单个处理器执行时快 N 倍。源自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux–Dictionary/html/index.html`

# pari-gp

PARI/GP 计算机代数系统数据文件 PARI 是一种广泛的计算机代数系统，旨在数论中的快速计算（因式分解、代数数论、椭圆曲线……），但也包含许多实用的函数来计算矩阵、多项式、幂级数、代数数等数学实体，以及许多超越函数。PARI 还可以作为 C 库提供，以便进行更快的计算。最初由 Henri Cohen 和他的同事（法国巴黎第一大学）开发，现在 PARI 采用 GPL 协议并由 Karim Belaps 维护。此软件包包含 PARI/GP 的额外数据，目前是多项式的伽罗斯解。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

PARI/GP 计算机代数二进制执行文件，旨在数论中的快速计算（因式分解、代数数论、椭圆曲线……），但也包含许多实用的函数来计算矩阵、多项式、幂级数、代数数等数学实体，以及许多超越函数。PARI 还可以作为 C 库提供，以便进行更快的计算。最初由 Henri Cohen 和他的同事（法国巴黎第一大学）开发，现在 PARI 采用 GPL 协议并在许多志愿者贡献者的帮助下由 Karim Belaps（法国巴黎第一大学）维护。此软件包包含 GP 计算器。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`
