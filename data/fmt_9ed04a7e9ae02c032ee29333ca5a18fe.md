
`foreach`结构在未指定值列表时，取命令行参数作为其值列表。调用shell文件时在命令行上指定的参数会成为`foreach`结构引用的值列表。`foreach`结构中使用的变量会被自动按顺序设置为每个参数值。第一次通过循环时，变量被设置为第一个参数的值；第二次设置为第二个参数的值，依此类推。

### `function`

`function name {commands}`

`function` 用于定义函数。使用关键字 `function` 后跟你要给函数起的名称，然后是组成该函数的命令，这些命令用花括号括起来。每当指定函数名称作为命令名称时，这些命令就会执行。函数的退出状态是最后一个命令的退出状态。

```
function func_name {
    commands
}
```

或者，你可以使用一对封闭括号代替关键字 `function` 来定义函数，从而赋予其类似于 C 程序的风格。

```
func_name () {
    commands
}
```

Z shell 有几个特殊的函数名，你可以使用它们来定义函数，这些函数将在某些时候由 shell 自动执行。例如，如果你定义了一个名为 `chpwd` 的函数，那么你在该函数中定义的命令将在当前目录更改时执行。

## Z-Shell 命令

| 函数名称 | 执行时间 |
|---|---|
| `chpwd` | 每当当前工作目录更改时执行。 |
| `precmd` | 在每个提示符之前执行。如果设置了 `PERIOD` 选项，则此函数每隔 `PERIOD` 秒执行一次，恰好在提示符之前。 |
| `TRAPxxx` | 每当 shell 接收到 `SIGXXX` 时执行，其中 `xxx` 是为 `kill` 内置命令指定的信号名称。该信号号将作为函数的第一个参数传递。 |
| `TRAPZERR` | 每当命令具有非零退出状态时执行。 |
| `TRAPDEBUG` | 在每个命令之后执行。 |
| `TRAPEXIT` | 当 shell 退出时执行，或者如果使用函数定义，则在该函数结束时执行。 |

### `functions`

```
functions [±tum] [name ...]
```

`functions` 用于设置 shell 函数的属性。它等同于 `typeset -f` 命令。如果没有选项或参数，`functions` 将列出所有已定义的函数。如果使用 `-m` 选项，参数将被视为模式，选择匹配这些模式的任何函数。`-t` 选项开启对该函数的跟踪，`-u` 选项将该函数标记为自动加载。

### `getopts`

```
getopts
```

`getopts` 用于设置 shell 函数的属性。它等同于 `typeset -f` 命令。如果没有选项或参数，`functions` 将列出所有已定义的函数。如果使用 `-m` 选项，参数将被视为模式，选择匹配这些模式的任何函数。`-t` 选项开启对该函数的跟踪，`-u` 选项将该函数标记为自动加载。
