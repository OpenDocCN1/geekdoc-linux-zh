
## 描述

`groups` 命令在标准输出上打印你或可选指定的用户所属的组。每个用户属于 `/etc/passwd` 中指定的一个组，并可能属于 `/etc/group` 中指定的其他组。注意，`/etc/passwd` 指定了组的数值标识符 (`gid`)。`groups` 命令在输出中将 `gid` 转换为组名。

## hash, rehash, unhash, hashstat — 目录内容的内部哈希表

### 概要

```
/usr/bin/hash [name]

/usr/bin/hash [-r]

sh

hash [-r] [name ...]

csh

rehash

unhash

hashstat

ksh

hash [name ...]
```

## 描述

哈希是一种通过算法对信息进行索引的方法，该算法生成一组值索引，指示每个项的顺序位置。例如，当 C shell 启动时，它会找到 `path` 环境变量指定的目录中的所有命令，并构建一个完整路径名的内部哈希表。然后，当执行一个命令时，C shell 使用哈希表而不是直接搜索路径。这种哈希技术旨在提高性能。然而，如果你更改了路径或向其中一个目录添加了命令，除非你强制使用 `rehash` 命令让其重新构建哈希表，否则 C shell 将无法找到该命令。

## /usr/bin/hash

`/usr/bin/hash` 命令影响当前 shell 环境记住找到的命令的位置的方式。根据指定的参数，它会将命令位置添加到已记忆的位置列表中，或者清除列表内容。当你不指定任何参数时，它会报告列表的内容，例所示。

## $ hash

| hits | cost | command |
| --- | --- | --- |
| 2 | 3 | /bin/touch |
| 1 | 3 | /bin/ps |
| 0 | 3 | /bin/grep |
| 3 | 3 | /bin/ls |
| $ | 3 | /bin/env |

## $ hash

输出中的 `hits` 列显示 shell 进程调用命令的次数。输出中的 `cost` 列衡量在搜索路径中定位命令所需的工作。如果在搜索路径的相对目录找到了命令，在切换到该目录后，将重新计算该命令的存储位置。执行此操作的命令会在 `hits` 信息旁边用星号 (`*`) 标出。完成重新计算后，`cost` 会增加。

`hash` 不报告 shell 内置命令。

## Bourne Shell

对于每个命令名，shell 都会确定并记住搜索路径中的位置。当你对 `hash` 内置命令使用 `-r` 选项时，shell 会忘记所有已记忆的位置。如果你不指定任何参数，`hash` 会提供有关已记忆命令的信息。

## C Shell

`rehash` 重新计算 `path` 环境变量列出的目录内容的内部哈希表，以包含新增的命令。
`unhash` 禁用内部哈希表。
`hashstat` 打印统计行，指示内部哈希表在定位命令（以及避免 `exec`）方面的有效性，例所示。

```
castle% hashstat

6 hits, 1 misses, 85%

cast%
```

## hash, rehash, unhash, hashstat 465

对于路径中的每个哈希函数指示可能命中的分量，以及每个不以 `/` 开头的分量，都会尝试一次 `exec`。

## Korn Shell
对于每个命令名，shell 都会确定并记住搜索路径中的位置。如果你不指定任何参数，`hash` 会提供有关已记忆命令的信息。

### 操作数
`command` 要搜索的命令名称。

## 输出
当你不指定任何参数时，`hash` 会提供有关已记忆命令的信息。输出由一个已记忆命令的列表组成。输出中的 `hits` 列显示 shell 进程调用命令的次数。输出中的 `cost` 列是衡量在搜索路径中定位命令所需的工作。如果在搜索路径的相对目录中找到了命令，在切换到该目录后，将重新计算该命令的存储位置。执行此操作的命令会在 `hits` 信息旁边用星号 (`*`) 标出。完成重新计算后，`cost` 会增加。

## head — 显示文件的前几行

### 概要

```
/usr/bin/head [-number | -n number] [filename...]
```

## 描述
`head` 命令将每个输入文件的 `number` 行复制到标准输出。如果你不指定文件名，`head` 从标准输入读取行。`number` 的默认值为 10。
当你指定多个文件名时，每个文件的开头会在两个箭头之间显示文件名，如下所示。
`==> filename <=`
示例显示了通过名称显示一组文件的常用方法。

## head

```
castle@ head -999 kookabral kookaburra

==> kookabral <==

Kookaburra sits in the old tree

Merry merry king of the bush is he

Laugh, kookaburra, laugh, kookaburra

Glad your life must be.

```

Kookaburra sits in the old tree
Eating all the gumdrops he can see
Stop, kookaburra, stop, kookaburra
Leave some there for me.

```
==> kookaburra <=

Kookaburra sits in the old tree

Merry merry king of the bush is he

Laugh, kookaburra, laugh, kookaburra

Glad your life must be.

```

Kookaburra sits in the old tree
Eating all the gumdrops he can see
Stop, kookaburra, stop, kookaburra
Leave some there for me.
castle%

## 选项

+   `-n number` 将每个输入文件的 `number` 行复制到标准输出。
将 `number` 参数指定为正整数。
`-number` 以正整数指定行数，其效果与 `-n number` 选项相同。

如果你不指定任何选项，`head` 使用默认的 `-n 10`。

### 操作数

```
file 输入文件的路径名。如果不指定任何操作数，则使用标准输入。
```

## 用法

参见 `largefile(5)` 以获取 `head` 在遇到大于或等于 2 Gbytes (`2**31` 字节) 文件时的行为描述。

## 示例

以下示例写入目录下所有文件（（点开头的文件）的前 10 行。

```
example% head *
```
