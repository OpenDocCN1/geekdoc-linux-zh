## Cinnamon 插件

`Cinnamon` 插件（Applets）增强了您的 `Linux Mint` 体验，提供了实用的工具，例如“强制退出”插件，它可以让您点击一下即可关闭无响应的窗口。创建一个插件涉及分配一个唯一 ID、创建一个包含用于插件信息的 `metadata.json` 文件夹，以及一个包含代码的 `applet.js` 文件夹。它们存在于您的本地或系统级 `Cinnamon` 插件目录中。通过直观的 API，插件可以适应各种面板方向和尺寸，确保在多个实例中的功能性。

`Cinnamon` 中的分组窗口列表（Grouped Window List）插件是一个实用的工具，它在面板中按应用程序组织打开的窗口，类似于其他操作系统的任务栏功能。它简化了同一应用程序多个实例之间的导航，将它们分组在单个图标下，提供悬停预览，并允许快速切换或窗口管理。此插件增强了效率和工作空间组织，使用户能够更容易管理打开的应用程序并保持桌面环境的整洁。

`Cinnamon Windows Alt-Tab` 切换器提供了图标、缩略图或组合等样式，使用户可以通过更大的图标和详细预览更方便地进行导航。它通过允许用户从系统设置中调整图标大小和样式来适应偏好。`Cinnamon-Alt-Tab-Enhanced` 项目增加了诸如跨多个工作空间、更大的缩略图视图以及全面的键盘鼠标支持等功能，提升了用户体验。

`Cinnamon` 菜单插件是一个易于使用的应用程序菜单，简化了访问系统上已安装应用程序的步骤。通过它，只要有相应的 `.desktop` 文件，用户就可以通过输入名称或别名轻松地启动应用程序。该插件还将应用程序组织成类别，使导航和发现变得更加直观。它桥接了用户便利性与系统功能之间的鸿沟，确保查找和运行任何应用程序都是一个顺畅且直接的过程。

`Cinnamon` 桌面环境日历插件提供了类似于微软备受推崇的操作系统 `Windows XP` 的时间显示。此功能允许用户模仿 `Windows XP` 的外观和氛围，同时避免了其编程局限性。此外，它支持 12 小时制，与军事风格的 24 小时制形成对比，提供了一种用户友好的计时方法。

# 分组窗口列表

## 通过 GUI 设置分组窗口列表

要通过图形用户界面设置分组窗口列表，请先从应用程序菜单启动 `Firefox`。打开后，将程序最小化。接下来，右键点击面板上的 `Firefox` 图标，并选择“配置”。之后，导航到“面板”（Panel）选项卡。在那里，您将看到一个名为“按钮标签”（Button label）的选项。点击此框并选择“窗口标题”（Window Title）选项。

# Cinnamon Windows Alt-Tab 切换器

## 通过 GUI 设置 Cinnamon Windows Alt-Tab 切换器

要通过图形用户界面设置 `Cinnamon Windows Alt-Tab` 切换器，请遵循以下简单步骤。首先，打开应用程序菜单并运行命令。然后，导航到 Alt-Tab 部分并寻找名为“Alt-Tab 切换器样式”（Alt-Tab switcher style.）的选项。点击此选项旁边的复选框，并从下拉菜单中选择“仅缩略图”（Thumbnails only）。

# Cinnamon 菜单插件

## 通过 GUI 设置 Cinnamon 菜单插件

要通过图形用户界面设置 `Cinnamon` 菜单插件，请右键点击菜单按钮并选择“配置”。然后，导航到“面板”（Panel）选项卡。找到“使用自定义图标和标签”（Use a custom icon and label）选项，并将开关向右滑动以启用它。在“文本”（Text）旁边的文本字段中，按 `CTRL + A` 选择所有现有文本，然后按 `DEL` 清空字段。输入“Start”作为新标签。对于图标，点击同一行的框，然后在弹出的搜索框中按 `CTRL + A` 选择全选，随后按 `DEL` 清空它。在搜索框中输入“start-here”，当它出现时选择“start-here”图标，并点击“选择”（Select）以完成您的选择。

# Cinnamon 日历插件

## 通过 GUI 设置 Cinnamon 日历插件体验格式

若要通过 GUI 在 `Cinnamon` 日历插件中设置自定义日期格式，请遵循以下简单步骤：右键点击日历插件（通常位于屏幕右下角）。从菜单中选择“配置”。接下来，找到名为“使用自定义日期格式”（Use a custom date format）的选项并将开关向右滑动。在同一行的“日期格式”（Date format）字段中，按 `CTRL + A` 选择所有文本，然后输入 `%I:%M %p`。最后，按回车应用您的更改。此过程将自定义您的日历显示，以 12 小时制显示时间，使其阅读更加直观。

## 桌面环境

桌面环境将熟悉的桌面比喻与图形界面相结合，以简化计算机交互，其具有图标、窗口和工具栏。桌面环境起源于 PC，它们已扩展到其他领域，以统一软件外观和功能，帮助访问文件而无需深入底层系统的复杂性。流行的例子包括 `KDE` 和 `GNOME`，它们在各种系统上提供可定制的用户体验，从传统计算扩展到创新的 3D 方法。

`Tasksel` 是 `Debian` 和 `Ubuntu` 的实用工具，通过协调的任务简化相关软件包的安装。它本质上是安装包组的桥梁，使用户通过软件包解决方案更轻松地增强系统。

`GNOME` 是一个适用于 `Linux` 和类 Unix 系统的免费开源桌面环境，使计算变得简单高效。它由包括 `Red Hat` 在内的全球社区开发，是许多 `Linux` 发行版的默认桌面。`GNOME` 提供了一个直观、优雅的界面，专注于易用性和生产力，具有可以轻松访问的任务概览以及与在线账户无缝集成的功能。它旨在为用户提供一个完善、全面的套件，足以与 `Windows` 和 `macOS` rival。

`KDE Plasma 5` 发布于 2014 年 7 月 15 日，是 `KDE` 桌面环境的第五代，从 `Plasma 4` 进化而来，带有全新的“Breeze”主题、基于 `QML` 的图形界面以及更好的设备收敛。它通过 `OpenGL` 加速提升性能，提供可自定义的小部件，并包含了用于通用搜索的 `KRunner`。通过加密、会话管理和改进的 `HIDPI` 支持等功能，`Plasma 5` 增强了 `Linux` 上的用户体验。它支持 `X Window` 和 `Wayland`，不断更新丰富功能，直到 2024 年被 `Plasma 6` 取代。

`LXDE`（轻量级 X11 桌面环境）是一个免费、高效的桌面环境，为旧或配置较低的计算机设计。它使用 `GTK 2` 工具包用 `C` 编写，在类 Unix 系统上运行良好，促进快速和低能耗。它支持滚动更新，以 `Openbox` 作为默认窗口管理器（提供 `Fluxbox`、`IceWM` 等选项），并包含了混合 `GPL` 和 `LGPL` 代码。关键组件包括 `PCMan` 文件管理器、`LXPanel` 和 `LXTerminal` 等，使得 `LXDE` 在满足日常计算需求时非常多功能且不臃肿。

`XFCE`，读音为四个独立的字母，是一个为 `Linux` 和 Unix 类系统打造的免费开源桌面环境。它追求速度和效率，以其低资源占用且同时不牺牲视觉吸引力或易用性的特点而脱颖而出。最新的 `XFCE 4.18` 版本引入了显著增强，侧重于用户可见的改进。它包含一个新的文件输入组件以避免无效文件名、一个多功能快捷键编辑器，以及缩略图处理的性能提升。
