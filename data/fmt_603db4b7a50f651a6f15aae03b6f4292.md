## 10.7.8 tcp_tw_hashdance()

此例在连接移动到 TIME_WAIT 状态时调用。在这种情况下，我们需要将 TIME_WAIT 套接链接到哈希表，将其从已建立（established）状态中取消链接，并链接到 time-wait 哈希表中。套接字已通过套接字的数字字段在 bind 哈希表 `tcp_bhash[ ]` 中进行了哈希处理。我们获取第 310 行的哈希表项头部（cs 10.39）以持有 bind 哈希自旋锁。

![](img/b3f231108facab5be0138b2cfd3f681a_394_0.png)

```
static void _tcp_tw_hashdance(struct sock *sk, struct tcp_tw_bucket *tw)
{
     struct tcp_ehash_bucket *ehead = &tcp_ehash(sk->sk);
     struct tcp_bind_hashbucket *bhead;
     struct sock **skw;

     bhead = &tcp_bhash[tcp_bhash(sk->num)];
     spin_lock(&bhead->lock);
     tw->tb = (struct tcp_bind_bucket *)sk->prev;
     BUG_ON(bind_prev != tw);
     if (tw->next != NULL) {
         tw->tb->owners = &tw->bind_next;
         tw->bind_pprev = &skw;
     spin_unlock(&bhead->lock);
     write_lock(&sk->lock);
     if (sk->pprev) {
         sk->next = sk->pprev;
         *sk->pprev = sk->next;
         sk->pprev = NULL;
         sock_prot(sk)->prot;
     }
     head = &(ehead+tcp_ehash_size)->chain;
     skw = (struct sock *)head;
     if (skw->next != NULL) {
         (*head)->pprev = &skw->next;
     }
     *head = skw;
     skw->prev = head;
     atomic_inc(&sk->count);
     write_lock(&ehead);
 }
```
