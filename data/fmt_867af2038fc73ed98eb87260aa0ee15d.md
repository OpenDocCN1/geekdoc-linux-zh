# HTTP 代码

HTTP 服务器对所有请求都返回一个 HTTP 代码。某些 HTTP 服务器不返回代码描述，仅返回数值。下表可用于确定 HTTP 响应的含义。此表也可用于编写自定义客户端脚本，以分类和理解结果 HTTP 响应。

| 代码 | 描述 |
|---|---|
| 100 | 继续 |
| 101 | 切换协议 |
| 200 | OK |
| 201 | 已创建 |
| 202 | 已接受 |
| 203 | 非权威性信息 |
| 204 | 无内容 |
| 205 | 重置内容 |
| 206 | 部分内容 |
| 300 | 多重选择 |
| 301 | 永久移动 |
| 302 | 临时移动 |
| 303 | 查看其他 |
| 304 | 未修改 |
| 305 | 使用代理 |
| 307 | 临时重定向 |
| 400 | 错误请求 |
| 401 | 未授权 |
| 402 | 需要支付 |
| 403 | 禁止访问 |
| 404 | 未找到 |
