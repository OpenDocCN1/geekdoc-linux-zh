
## 10
你必须使用 Linux IP 伪装功能与其他 LAN 上的系统共享单一互联网连接。使用 IPCHAINS 软件（`/sbin/ipchains`）设置 IP 伪装。其他计算机必须使用 Linux 系统以太网卡的 IP 地址作为其网关设备，并使用 Linux 系统中 `/etc/resolv.conf` 文件中列出的名称服务器地址。

## 11
Telnet、FTP、电子邮件和万维网是一些常见的互联网服务。端口是介于 1 和 65,535 之间的一个数字，它唯一标识两个进程之间 TCP/IP 通信链路的每个端点。`/etc/services` 文件包含关于互联网服务和相应端口号的信息。

## 12
要提供或电子邮件服务，你需要一个邮件传输代理（MTA）和一个邮件用户代理（MUA）。简单邮件传输协议（SMTP）是在系统间传输电子邮件的 TCP/IP 协议。

## 13
Apache Web 服务器的配置文件位于 `/etc/httpd/conf` 目录。`/var/log/httpd` 目录是 Apache Web 服务器的访问日志和错误日志所在的位置。

## 14
`/etc/rc.d/init.d/httpd` 脚本启动和停止 `httpd` 进程，该进程控制 Apache Web 服务器。

## 15
要使用匿名 FTP 将文件传输到远程系统或从远程系统传输文件，请使用用户名 `anonymous` 登录。任何人都可以使用此用户名通过 FTP 从系统传输文件，并提供你的电子邮件地址作为密码。

## 16
要使用网络文件系统（NFS）设置文件服务器，首先在 `/etc/exports` 文件中列出以导出一个或多个目录。然后，使用 `Linuxconf` 启动 NFS 服务器。

## 17
要在客户端系统上使用 NFS 导出目录，请使用 `mount` 命令挂载服务器导出的目录。

## 18
Samba 是一种软件，它允许你的 Red Hat Linux 系统作为 Windows 文件和打印服务器运行。要配置 Samba 软件使你的 Linux 系统作为 Windows 服务器运行，请编辑 Samba 配置文件 `/etc/smb.conf`，然后使用以下命令重启 Samba 软件：

```bash
/etc/rc.d/init.d/smb restart
```

## 19
以下命令在挂载点 `/mnt/dos` 挂载 `/dev/hda2` 文件系统：

```bash
mount -t vfat /dev/hda4 /mnt/dos
```

为了确保 Linux 在系统每次启动时自动挂载 `/dev/hda2`，你将以下行添加到 `/etc/fstab` 文件中：

```text
/dev/hda2 /mnt/dos vfat defaults 0 0
```

## 20
以下命令将所有具有 `.doc` 扩展名的文件从 DOS 软盘复制到硬盘上的当前目录：

`mcopy "a:\*\*.doc"`

### 周日早晨复习答案

1. X 服务器是一个管理位图显示器、键盘和鼠标进程。X 服务器代表使用这些设备请求某种输入或输出活动的 X 客户端控制监视器、键盘和鼠标，例如请求打开一个窗口。

2. X 配置文件是 `/etc/X11/XF86Config-4`。你可以使用 `xf86config`、`X86cfg` 或 `Kconfigurator` 创建一个新的 X 配置文件。

3. 如果 X 图形屏幕部分工作，请按下 `Ctrl+Alt+F1` 切换到文本控制台，并在文本登录提示符下以 root 身份登录。然后输入 `telinit 3` 终止正在运行的 X 服务器。接下来，创建一个新的 X 配置文件，并输入 `telinit 5` 重新启动图形显示管理器。最后，输入 `Ctrl+Alt+Backspace` 终止 X 服务器并使用新的配置文件运行以重启它。

4. `init` 运行系统上的所有其他进程。它在启动时开始，主要负责启动提供基本服务的系统守护进程以及挂载文件系统。`/etc/inittab` 文件的内容控制 `init` 的行为。

5. 在 `/etc/inittab` 文件的第三个字段中查找包含关键字 `initdefault` 的行；字段由冒号 `:` 分隔。此行的第二个字段指定默认运行级别。

6. `init` 进程运行 `/etc/rc.d/rc.sysinit` 脚本。该脚本进而运行 `/etc/rc.d` 子目录中的许多其他脚本，特别是 `/etc/rc.d/init.d`。

7. `RPM` 指 Red Hat 软件包管理器，它将软件产品所需的所有文件打包到一个称为 RPM 文件的单个文件中。Red Hat Linux 和捆绑的应用程序以大量 RPM 的形式分发。
