
代表性有机硫化合物和基团的结构和名称见表。一些化合物和基团通过使用前缀“`thia`”来命名，表示氧被硫取代。前缀“`thia`”还用于指示一个或多个 `$\ce{-CH_2-}$` 基团被硫取代，例如 2,7-二硫杂壬烷 [`$\ce{CH_2S(CH_2)_4SCH_2CH_3}$`]。硫醇和硫化物分别是醇和醚的硫类似物，可通过类似于氧气化合物的取代反应制备。硫酸盐通过硫化物的进一步烷基化获得。尽管硫醇和醇在结构上类似，但这两类基团的性质存在显著差异。`$\ce{-S-H-S-}$` 类型的氢键非常弱。

### 一些类型的有机硫化合物和基团

| 结构 | 名称 |
| :--- | :--- |
| `$\ce{RSH}$` | 硫醇（巯基） |
| `$\ce{RSR}$` | 硫化物（硫醚） |
| `$\ce{RSSR}$` | 二硫化物 |
| `$\ce{RSSSR}$` | 三硫化物（三硫代烷） |
| `$\ce{R_3S^+}$` | 硫鎓盐 |
| `$\ce{R_2C=S}$` | 硫代酮 |
| `$\ce{RN=C=S}$` | 异硫氰酸酯 |
| `$\ce{R-C(=O)-SR}$` | 硫代酸酯（硫代酸 S-酯） |
| `$\ce{R-C(=O)-SR}$` | 硫代酸酯（注：原文此处重复且可能有误，通常指二硫代酸酯或类似物，此处保留直译） |
| `$\ce{R-C(S)-SR}$` | 亚磺酸酯 |
| `$\ce{R-C(S)(SR)_2}$` | 磺酸（注：原文 Sulfinate 通常译为亚磺酸，此处原文对应结构复杂，按直译） |
| `$\ce{R-S(Cl)}$` | 硫代氯化物 |
| `$\ce{R-S-O-R}$` | 亚硫代酸酯（硫醚代酸酯） |

| `$\ce{R-SO_2-R}$` | 砜 |
| `$\ce{R-SO_3H}$` | 磺酸 |
| `$\ce{R-SO_2-NH_2}$` | 磺酰胺 |
| `$\ce{R-SO_2-Cl}$` | 磺酰氯 |
| `$\ce{R-SO_3-R}$` | 硫酸酯 |

与 `–O–H–O–` 相比，巯基化合物因此具有更高的挥发性和更低的沸点；例如，甲硫醇 (`CH₃SH`) 的沸点为 5.8 °C (42.4 °F)，而甲醇 (`CH₃OH`) 的沸点为 65.7 °C (150.3 °F)。

巯基化合物会与铅或汞等重金属离子形成不溶性沉淀物。巯基化合物和硫醚都是恶臭化合物，让人联想到臭鸡蛋（硫化氢）的恶臭。然而，这些含硫化合物的微量存在是许多食物独特风味和香气的重要组成部分，如咖啡、大蒜、洋葱和烤肉。参见麦芽反应；巯基化合物；香料和调味剂。

硫羰基化合物含有碳-硫双键 (`C=S`)。硫羰基化合物（硫酮）比羰基化合物（`C=O` 键）更为罕见。简单的硫醛或硫酮倾向于形成环状三聚体、聚合物或某些高性能物质。砜类物质会依次被氧化为亚砜和砜，分别含有亚砜基（`–SO–`）和砜基（`–SO₂–`）基团，如下面的反应所示。

二甲基亚砜（DMSO）作为克拉特亚硫酸盐造纸工艺的副产品，可大量获得。它作为一种高沸点极性溶剂以及有机合成中的选择性氧化剂和试剂非常有用。参见二甲基亚砜。

含有磺酰基的化合物包括砜、磺酰氯、硫酸和磺酰胺。磺酰基在对 α-氢的酸化作用方面类似于羰基。二芳基砜结构是聚砜树脂的核心特征，用于某些高性能塑料。硫酸可通过巯基化合物的氧化或磺化获得。磺酰胺由氯化物制备，在抗生素问世之前是治疗感染的主要药物；它们目前仍用于某些病症。参见聚砜树脂；磺酰胺；硫酸。

生物系统中许多蛋白质和代谢途径依赖于氨基酸半胱氨酸和其他含硫化合物。在许多蛋白质中，例如在胰岛素酶中，由半胱氨酸单元的 `–SH` 基团形成的二硫键是结构的重要组成部分。半胱氨酸的 `–SH` 基团还在介导呼吸和光合作用中电子传递反应的金属-硫蛋白中发挥作用。参见胰岛素；光合作用。

辅酶硫辛酸是一种环状二硫化合物，它与辅酶硫胺素二磷酸协同作用，接受电子并在丙酮酸的氧化脱羧中发生 `S–S` 键的还原。代谢中的另外两个主要途径——乙酰基和甲基的转移——由有机硫化合物介导。乙酰基转移是脂质和碳水化合物代谢的关键步骤，通过硫酯进行。参见碳水化合物代谢；辅酶；脂质代谢；硫胺素。

许多天然来源的其他化合物中都含有硫。石油含有不同量的硫，既有简单的巯基和硫醚，也有苯并噻吩等杂环化合物。去除这些物质是石油炼制的重要步骤。参见石油；石油加工和精炼。

几种天然来源的含硫化合物具有重要的药理特性。例如，β-内酰胺类抗生素青霉素、头孢菌素和硫胺霉素，以及来自大蒜的血小板抗凝因子大蒜素，后者是由大蒜素通过一系列复杂的酶促反应产生的。

参见抗生素；杂环化合物；有机化学；硫。

## 东方蔬菜

东方蔬菜在亚洲国家非常重要，但在美国和欧洲被视为次要作物。然而，近年来由于它们独特的风味和质地，以及在某些情况下高营养价值，人们对这些作物的兴趣与日俱增。下面介绍了一些较常见的东方蔬菜。

- 中国白菜、芹菜白菜、绍菜或大白菜（*Brassica campestris*, pekinensis 变种群；*B. rapa*, pekinensis 变种群；*B. pekinensis*）属于十字花科（芥菜属），是一种作为一年生作物种植的二年生叶用植物。收获部分是头部，由宽大的皱褶叶片组成，具有非常宽且界限不清的白色中脉。外层叶片呈淡绿色，头部内的叶片则呈漂白状态。由于其温和的风味和爽脆的质地，它是一种极好的沙拉蔬菜。

- 小白菜、青江菜、中国芥菜或芹菜芥菜（*Brassica campestris*, chinensis 变种群；*B. rapa*, chinensis 变种群；*B. chinensis*）有许多品种。该作物作为一年生种植。小白菜不像大多数中国白菜品种那样形成头部，而是形成圆柱形的茎，长有高大的深绿色叶片，具有明显的白色叶脉和长的白色花瓣（见图）。叶柄基部可能扩展成勺状；叶片平滑，不像中国白菜那样皱褶。

- 大型长白萝卜（*Raphanus sativus*, longipinnatus 变种群）常被称为东方冬萝卜、大根（daikon）、中国冬萝卜、lo-bak 或 loo pao。萝卜是一种双子叶草本植物，栽培以获取其扩大的长根。

- 食荚豌豆、中国豌豆、糖豌豆或雪豆（*Pisum sativum*, macrocarpon 变种群）属于豆科。豌豆的原始形式略有苦味，且种皮坚硬，允许长时间的休眠期。在普通豌豆中，豆荚随种子增大而先膨胀，但在食荚豌豆中，未成熟的种子使豆荚隆起，从而标志着发育中的种子。与普通豌豆具有坚硬纤维种荚不同，食荚豌豆是为其柔嫩的豆荚而非种子而被选育的。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1587_1.png)

小白菜或中国芥菜（*Brassica campestris*）。（加州大学农业实验站）

- 长豇豆或芦笋豆（*Vigna stenensis*, sesquipedalis 变种群）属于豆科。它是一种一年生攀缘植物。它是豇豆（*V. unguiculata*）的近亲。

- 绿豆或青小豆（*Phaseolus aureus*）的豆芽已被中国人使用数千年，以其显著的愈合特性闻名。直到最近，西方世界才认识到发芽豆类种子（绿豆、大豆和苜蓿芽）的价值。未发芽的绿豆种子中维生素 C（抗坏血酸）含量微乎其微，而发芽的种子每 100 克豆芽中含有 20 毫克，与番茄汁含量相当。

- 豆薯（*Pachyrhizus erosus*），又称山药豆，原产于墨西哥和中美洲。它属于豆科。该作物栽培以获取其扩大的萝卜状根部，可生食或熟食，质地爽脆，味道微甜。

- 中国冬瓜、蜡瓜、冬瓜、白瓜、灰瓜、中国蜜瓜、灰南瓜或冬葵（*Benincasa hispida*；*B. cerifera*）是一种一年生葫芦科植物。成熟果肉用于制作中国汤。它可以生食，或制成类似柠檬皮或西瓜皮蜜饯的甜果酱。

- 苦瓜、鳄梨、苦葫芦、苦甜瓜、苦黄瓜或佛瓜（*Momordica charantia*）是一种一年生草本藤本植物。心形到圆柱形的果实极苦；在烹饪前通过去皮和盐水浸泡可去除部分苦味。未成熟果实比成熟果实苦味较轻。

- 秋葵或棱角丝瓜（*Luffa acutangula*）被中国人称为 ziti kway；它是 *L. cylindrica* 的近亲，后者被称为丝瓜、海绵瓜或洗碗丝瓜。秋葵是一种栽培以获取未成熟果实的攀缘藤本植物。完全成熟的果实可制成蔬菜海绵。

- 空心菜、蕹菜、沼泽白菜、康公或水东菜（*Ipomoea aquatica*）是一种多年生半水生植物，栽培以获取其长而嫩茎。它是甘薯（*I. batatas*）的近亲，但不产生扩大的根部。[M.V]
