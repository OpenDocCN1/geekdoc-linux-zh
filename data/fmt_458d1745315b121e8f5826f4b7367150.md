
## 55.2 锁的继承与释放的语义

如列表 55-1 所示，我们可以通过指定操作为 `LOCK_UN` 的 `flock()` 来释放文件。此外，当相应的文件描述符关闭时，锁会自动释放。然而，情况比这要复杂。通过 `flock()` 获取的文件与文件描述（i-node）关联，而不是与文件描述符关联。这意味着如果文件描述符被复制（通过 `dup()`、`dup2()` 或 `fcntl(F_DUPOPEN)`），新的文件描述符将指向同一个文件。如果我们已经对 `fd` 所指的文件获取了锁，以下代码（省略了错误检查）将释放该锁：

```c
flock(fd, LOCK_EX);
newfd = dup(fd);
flock(newfd, LOCK_UN);
/* 通过 'fd' 获取锁 */
/* 'newfd' 指向与 'fd' 相同的锁 */
```

### 列表 55-1：使用 `flock()`

```c
#include <sys/file.h>
#include <fcntl.h>
#include "curr_time.h"
#include "tlpi_hdr.h"

/* currTime() 的声明 */

int
main(int argc, char *argv[])
{
    int fd, lock;
    const char *lname;

    if (argc < 3 || strcmp(argv[1], "--help") == 0 ||
        strchr("sx", argv[2][0]) == NULL)
        usageErr("%s file [sleep-time]\n"
               "'lock' 为 's' (共享) 或 'x' (独斥)\n"
               "可选后接 'n' (非阻塞)\n"
               "'secs' 指定持有锁持续的时间\n", argv[0]);

    lock = (argv[2][0] == 's') ? LOCK_SH : LOCK_EX;
    if (argv[2][1] == 'n')
        lock |= LOCK_NB;

    /* 打开要锁的文件 */
    fd = open(argv[1], O_RDONLY);
    if (fd == -1)
        errExit("open");

    lname = (lock & LOCK_SH) ? "LOCK_SH" : "LOCK_EX";

    printf("PID %ld: requesting %s %s\n", (long)getpid(), lname,
           currTime("%T"));

    if (flock(fd, lock) == -1)
        if (errno == EWOULDBLOCK)
            fatal("PID %ld: already locked - bye!", (long)getpid());
        else
            errExit("flock (PID=%ld)", (long)getpid());

    printf("PID %ld: granted %s %s\n", (long)getpid(), lname,
           currTime("%T"));

    sleep((argc > 3) ? getint(argv[3], GN_NONGE, "sleep-time") : 10);

    printf("PID %ld: releasing %s %s\n", (long)getpid(), lname,
           currTime("%T"));

    if (flock(fd, LOCK_UN) == -1)
        errExit("flock");

    exit(EXIT_SUCCESS);
}
```
