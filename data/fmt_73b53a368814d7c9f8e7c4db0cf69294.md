
在例示例中，`adder()`函数作为服务器运行，等待管道端到达的消息。当接收消息时，它会执行某些处理并将结果传回管道。请记住，`send()`和`recv()`使用`pickle`模块对对象进行序列化。在示例中，服务器接收一个元组`(x, y)`作为输入并返回结果`x + y`。然而，对于使用远程过程调用的更高级应用程序，你应该按照接下来描述的运行进程池。

# 进程池 (Process Pools)

以下类允许你创建一个进程池，向该池提交各种数据处理任务。池提供的功能与列表推导式以及函数式编程操作（如`map-reduce`）提供的功能类似。

`Pool([nprocess, initializer, initargs])`

创建一个工作进程池；`nprocess`是你要创建的进程数量。如果省略，则使用`cpu_count()`的值。`initializer`是一个可调用对象，将在每个工作进程启动时执行。`initargs`是一个传递给`initializer`的参数元组。默认情况下，`initializer`为`None`。

`Pool`实例支持以下操作：

`p.apply(func, args, kwargs)`

在池工作进程中的其中一个执行`func(*args, **kwargs)`并返回结果。需要强调的是，这**不会**在所有池工作进程中并行执行`func`。如果你想用不同的参数并发执行，你必须从不同的线程调用`p.apply()`或使用`p.apply_async()`。

`p.apply_async(func, args, kwargs, [callback])`

在池工作进程中的其中一个执行`func(*args, **kwargs)`并异步返回结果。该方法的结果是一个`AsyncResult`实例，可用于稍后获取结果。`callback`是一个接受单个输入参数的可调用对象。当`func`的结果可用时，它会立即被传递给`callback`。`callback`不应执行任何阻塞操作，否则它将阻塞其他异步操作的结果接收。

`p.close()`

关闭进程池，防止任何进一步的操作。如果任何操作仍在挂起状态，它们将在工作进程终止之前完成。

`p.join()`

等待所有工作进程退出。这只能在调用`close()`或`terminate()`之后调用。

`p.map(func, iterable [, chunksize])`

`map()`的版本，返回一个关于结果列表的迭代器。

`p.imap_unordered(func, iterable [, chunksize])`

不同之处在于结果是根据从工作进程接收到的时间按任意顺序返回的。

`p.map(func, iterable [, chunksize])`

将可调用对象`func`应用于`iterable`中的所有项，并将结果作为列表返回。该操作通过将`iterable`分分为块并将工作分发给工作进程来并行执行。`chunksize`指定每个块中的项数。对于大量数据，增加`chunksize`的使用将提高性能。

`p.map_async(func, iterable, [ chunksize, callback])`

与`map()`相同，不同之处结果是异步返回的。返回值是一个`AsyncResult`实例，可稍后获取结果。`callback`是一个接受单个参数的可调用对象。如果提供，则在结果可用时调用`callback`。

`p.terminate()`

立即终止所有工作进程，而不执行任何清理工作工作来完成挂起的工作。如果`p`被垃圾回收，则会调用此方法。

方法`apply_async()`和`map_async()`返回一个`AsyncResult`实例。`AsyncResult`实例具有以下方法：

`a.get([timeout])`

返回值，`timeout`是可选的。如果结果在规定时间内未到达，则抛出`TimeoutError`。

`a.ready()`

如果结果已就绪，返回`True`。

`a.successful()`

如果调用完成，返回`True`。

`a.wait([timeout])`

等待结果可用。`timeout`是可选的。

以下示例说明了使用池构建 SHA12 值：

```python
import os
import multiprocessing
import hashlib

# 尝试输出
BUFFERSIZE = 8192      # 字节数
def compute_digest(filename):
    try:
        f = open(filename,"rb")
    except OSError:
        return None
    digest = hashlib.sha1()
    while True:
        chunk = f.read(BUFFERSIZE)
        if not chunk:
            break
        digest.update(chunk)
    f.close()
    return digest.hexdigest()

if __name__ == '__main__':
    pool = multiprocessing.Pool(4)
    filenames = []
    for root, dirs, files in os.walk("."):
        for name in files:
            filenames.append(os.path.join(root, name))
    
    result = pool.imap_unordered(compute_digest, filenames)
    for r in result:
        print(r)
    pool.close()
    pool.join()
```
