
# telnet

## 命令说明

- `quit` 等同于 `close`。

- `open [-l user] host [port]`

打开到指定主机的连接。如果你没有指定端口号，`telnet` 将尝试连接默认端口的 TELNET 服务器。主机规范可以是主机名（参见 `hosts(4)`）或用点表示法指定的 Internet 地址（参见 `inet(7)`）。`-l` 选项将 `user` 作为 `ENV` 变量的值传递给系统系统。

- `send arguments` 向远程主机发送一个或多个特殊字符序列。

你可以指定以下一个或多个参数：

- `abort` 发送 `ABORT`（终止进程）序列。
- `ao` 发送 `AO`（终止输出）序列以刷新来自远程的所有输出。
- `ayt` 发送 `AYT`（你在吗？）序列。远程系统可能会响应也可能不响应。
- `brk` or `break` 发送 `BRK`（中断）序列，对远程系统可能具有意义。
- `do option` `dont option` `wont option` 发送指定的协议选项协商。`option` 可以协议选项的名称或相应的数字。如果指定的选项协商在当前状态下无效，则会被静默忽略。如果你指定 `help` 或 `?` 选项，将列出已知名称。此命令主要用于异常的调试情况。
- `ec` 发送 `EC`（删除字符）序列以删除最后一个字符。
- `el` 发送 `EL`（删除行）序列以删除远程系统正在输入的行。
- `eof` 发送 `EOF`（文件结束）序列。
- `eor` 发送 `EOR`（记录结束）序列。
- `escape` 发送当前的 `telnet` 转义字符（初始为 `^`）。
- `ga` 发送 `GA`（前进）序列，对远程系统可能没有意义。
- `getstatus` 如果远端支持 `STATUS` 命令，`getstatus` 将发送子协商，以请求服务器发送其当前的选项状态。
- `ip` 发送 `IP`（中断进程）序列以终止远程系统上正在运行的进程。
- `nop` 发送 `NOP`（无操作）序列。
- `susp` 发送 `SUSP`（挂起进程）序列。
- `synch` 发送 `SYN` 序列，以丢弃远程系统中之前已输入但未读取的所有输入。该序列作为 TCP 紧急数据发送，如果远端系统是 4.2 BSD 系统，则可能无效。如果无效，终端上可能会回显一个小字母 `r`。
- `?` 打印 `send` 命令的帮助信息。

## `set argument [value]`

- `unset argument` 将一组 `telnet` 变量中的任意一个设置为特定值。特殊值 `off` 会关闭与变量关联的函数。你可以使用 `display` 命令查询变量。如果省略了 `value`，则将值设为 `true` 或 `on`。如果你使用 `unset` 形式，则将值设为 `false` 或 `off`。你可以指定以下变量。

- `ayt` 当启用 `localchars` 模式或 `LINEMODE` 且你输入状态字符时，向远端主机发送 `AYT` 序列。`ayt` 的初始值是终端状态字符。
- `echo` 设置“旧行行行”模式用于切换输入字符本地回显的值（初始为 `^^`），用于普通处理以及密码等输入字符的抑制回显。注意，在某些远程系统中，你必须在“旧行行行”模式下手动关闭 `echo`。
- `eof` 当你在“旧行行行”模式下作为行首第一个字符输入 `eof` 字符时，向远程系统发送该 `eof` 字符。`eof` 的初始值为终端的 `eof` 字符。
- `erase` 当启用 `localchars` 模式且在“逐字符处理”模式下操作时，向远程系统发送 `ES` 序列。`erase` 字符的初始值为终端的 `erase` 字符。
- `escape` 设置 `telnet` 转义字符（初始为 `^]`），连接到远程系统时通过该字符进入 `telnet` 命令模式。
- `flushoutput` 当处于 `localchars` 模式且你输入 `flush` 字符时，向远端主机发送 `AO` 序列。`flush` 字符的初始值为终端的 `flush` 字符。
- `forw1` 当在 `LINEMODE`（或“旧行行行”模式）下操作且输入 `forw1` 或 `forw2` 字符时，向远程系统转发部分行。转发字符的初始值来自终端的 `eol` 和 `eol2` 字符。
- `interrupt` 当处于 `localchars` 模式（切换 `localchars`）且输入中断字符时，向远端主机发送中断序列。中断字符的初始值为终端的 `intr` 字符。
- `kill` 当 `telnet` 处于 `localchars` 模式、以“逐字符处理”且输入 `kill` 序列时，向远程系统发送 `EL` 序列。`kill` 字符的初始值为终端的 `kill` 字符。
- `lnext` 在 `LINEMODE` 或“旧行行行”模式下操作时，假设 `lnext` 字符为终端的 `lnext` 字符。`lnext` 字符的初始值为终端的 `lnext` 字符。
- `quit` 当处于 `localchars` 模式且输入 `quit` 字符时，向远端主机发送 `BRK` 序列。`quit` 字符的初始值为终端的 `quit` 字符。
- 在 `LINEMODE` “旧行行行”模式下操作时，假设打印字符为终端的 `reprint` 字符。`reprint` 的初始值为终端的 `reprint` 字符。
- 设置登录转义字符。除非该字符出现在行首且位于其之前，否则忽略正常的 `telnet` 转义字符。当行首为 `login` 后跟接 `a` 时，关闭连接。当其跟接 `^Z` 时，挂起 `telnet` 命令。初始状态为禁用登录转义字符。
- 如果启用了 `TOGGLE-FLOW-CONTROL` 选项，将起始字符设置为终端的 `start` 字符。`kill` 字符的初始值为终端的 `start` 字符。
- `stop`

如果启用了 `TOGGLE-FLOW-CONTROL` 选项，将停止字符设置为终端的 `stop` 字符。`kill` 字符的初始值为终端的 `stop` 字符。
- `susp`

当处于 `localchars` 模式或启用 `LINEMODE` 且输入挂起字符时，向远端主机发送 `SUSP` 序列。挂起字符的初始值为终端的 `suspend` 字符。
- `tracefile`

当 `netdata` 或 `debug` 选项为 `true` 时，将输出写入此文件。如果设置为 `-`，则将跟踪信息写入标准输出（默认）。
- `wonderase`

在 `LINEMODE` 或“旧行行行”模式下操作时，将此字符视为终端的 `ordererase` 字符。`ordererase` 字符的初始值为终端的 `ordererase` 字符。
- `?` 显示有效的 `set` 和 `unset` 命令。

## `slc state`

在启用 `LINEMODE` 选项时设置或更改特殊字符的状态。特殊字符映射到 `TELNET` 命令序列（如 `ip` 和 `quit`）或行编辑字符（如 `erase` 和 `kill`）。默认情况下，导出本地特殊字符。

- `check`

验证特殊字符的设置。请求远端发送所有当前的特殊字符设置。如果与本地存在任何差异，则将本地设置切换为远端值。
- `export`

将特殊字符切换为本地默认值。本地默认是指启动 `telnet` 时本地终端的设置。
- `import`

将特殊字符切换为远端默认值。远端默认是指建立 `TELNET` 连接时远程系统的设置。
- `?` 打印 `slc` 命令的帮助信息。

## `toggle arguments...`

在 `true` 和 `false` 之间切换控制 `telnet` 响应的各种标志。你可以指定多个参数。可以使用 `display` 命令查询这些标志的状态。有效参数如下。

- `autoflush`

如果 `autoflush` 和 `localchars` 均 `true` `true`，则当识别（并转换，详见 `set`）`ao`、`intr` 或 `quit` 字符时，在远端系统使用 `TELNET` Timing Mark 选项确认已处理这些 `TELNET` 序列之前，拒绝在终端上显示任何数据。如果没有执行 `stty noflush`，则值为 `false`（见 `stty(1)`）。
- `autosynch`

如果 `autosynch` 和 `localchars` 均 `true`，则当你输入中断或退出 字符时（见 `set` 对 `interrupt` 和 `quit` 的描述），发送相应的 `TELNET` 序列后跟 `SYNC` 序列。此过程应丢弃远程系统中之前的所有输入，直到两个 `TELNET` 序列都被读取并处理。初始值为 `false`。
- `binary`

对输入输出启用或禁用 `BINARY` 选项。
- `crlf`

确定 Return 的设置。如果值为 `true`，则发送 `CR/LF`；为 `false`，则发送 `CRnull`。初始值为 `false`。
- `crmod`

切换 Return 模式。启用此模式时，从远程主机接收的大多数 Return 字符映射为 Return 加换行。此模式不影响你输入的字符，只影响从远程接收的字符。这对于只发送 Return 而不发送换行的远程主机有用。初始值为 `false`。
- `debug`

切换套字字调试（仅对超级用户可用）。初始值为 `false`。
- `inbinary`

对输入启用或禁用 `BINARY` 选项。
