
# 工作区与工具提示

工作区将桌面划分为一个或多个区域，任何时候都有这样一个区域占据屏幕。初始有两个工作区。由于桌面上的面板和对象是桌面的特性，因此所有工作区都会显示面板和对象。默认情况下，窗口出现在单个工作区中。切换允许你显示多个工作区中的一个。

工具提示是一种微上下文帮助系统，你通过将鼠标指针悬停在按钮、图标、窗口边界或小组件（如面板上的小组件）上并保持悬停来激活它。当鼠标指针悬停在对象上时，GNOME 会显示该对象的简要说明。

# 打开文件

默认情况下，双击对象以打开它；或者你可以右键点击对象并在下拉菜单中选择“打开”。当你打开一个文件时，GNOME 通过确定文件的 MIME 类型来确定使用的适当工具。GNOME 将每个扩展名与 MIME 类型关联，并将每个 MIME 类型与一个程序关联。初始情况下，GNOME 使用文件名扩展名来确定文件的 MIME 类型。如果 GNOME 不识别文件名扩展名，它会检查文件的魔数。

例如，当你打开一个扩展名为 `ps` 的文件时，GNOME 会调用 Evince 文档查看器，它以可读格式显示 PostScript 文件。当你打开一个文本文件时，GNOME 使用 `gedit` 显示并允许你编辑该文件。当你打开一个目录时，GNOME 在文件浏览器窗口中显示其内容。当你打开像 Firefox 这样的可执行文件时，GNOME 会运行该可执行文件。当 GNOME 使用错误的工具打开文件时，该工具通常会给出错误信息。请参阅第 118 页的“打开方式”，获取有关如何使用默认工具以外的工具打开文件的信息。

# 面板

如前所述，面板是最初出现在桌面顶部和底部的条。它们是桌面的一部分，因此在所有工作区之间保持一致。

## 面板菜单

在面板的空白部分点击右键会显示面板（上下文）菜单。除了帮助和信息选项外，此菜单有四个选项。选择“添加到面板”会显示“添加到面板”窗口。你可以从此窗口将对象拖到面板上，从而选择显示在哪个面板上。你也可以突出显示一个对象并点击“添加到面板”，而你用它显示此窗口的面板成员是很古怪的；尝试 `Try Guys` 并从其偏好窗口中选择 `Bloodshot`，或者尝试 `Fish`。最实用的对象之一是“搜索文件”。当你点击面板上的此对象时，它会显示“搜索文件”窗口。

![图 4-12 “添加到面板”窗口](img/556454b01d95450a92edff64b47580d6_153_0.png)

选择**属性**会显示面板属性窗口。此窗口有两个选项卡：通用和背景。

![图 4-13 面板属性窗口，通用选项卡](img/556454b01d95450a92edff64b47580d6_154_0.png)

在“通用”选项卡中，“方向”选择面板显示在哪一侧；“尺寸”调整面板的宽度。“扩展”使面板跨越工作区的宽度或高度；如果不勾选此框，面板将居中且宽度仅足够容纳其对象。“自动隐藏”使面板在鼠标指针撞击工作区侧边时消失。“隐藏按钮”的工作方式与自动隐藏不同：“显示/隐藏按钮”在面板的每个末端显示按钮。当你点击这些按钮之一时，面板会滑出视野，只留下一个按钮。当你点击该按钮时，面板会滑回位置。

面板属性窗口的“背景”选项卡允许你为任何面板指定颜色或透明度。

**删除面板**：此操作将移除面板并移除面板上的所有对象。

**新建面板**：会在桌面上添加一个新面板。GNOME 会决定它的位置。

## 移动面板

你可以将任何面板移动到桌面的四侧之一：左键点击面板上的任何空间；鼠标指针会变成一个小手。将面板拖到你想移动的位置。与跨越工作区移动对象不同，面板在你将鼠标指针完全拖到新位置之前不会移动；然后它会吸附到位。如果你有堆叠面板并在重新排序时遇到困难，请先将面板拖到空白处。

## 面板对象

面板上的图标和文字被称为面板对象，它们显示菜单、启动程序并提供信息。带有蓝色和橙色地球的图标启动 Firefox。邮件按钮（信封图标）启动 Evolution，一个电子邮件和日历应用程序。你可以使用面板对象启动系统上的几乎任何实用程序。本节介绍了面板对象的不同类型。

小组件是在面板上或相邻面板显示用户界面的小型程序。你通过它的面板对象与之交互。混音器（音量控制）、时钟（日期和时间）和工作区切换器都是小组件。

窗口列表应用虽然不是一种特定的类型，但它是一个独特且重要的工具。对于显示工作区上的每个打开或最小化的窗口，底部面板上会出现一个窗口列表应用。左键点击此应用可以最小化或恢复窗口。右键点击显示窗口操作菜单。如果窗口被埋在其他窗口下，点击你的窗口列表应用以使其可见。

![图 4-14 窗口列表组件](img/556454b01d95450a92edff64b47580d6_155_0.png)

文档、桌面和“计算机”对象是启动器，用于打开文件浏览器窗口以显示文件夹。注销按钮会显示一个窗口，允许你注销、关机或重启系统。底部面板左侧的显示桌面按钮会最小化工作区上的所有窗口。

菜单显示供你选择的选项列表。其中某些选项可以是包含更多选项的子菜单。所有其他选项都是启动器。下一节将讨论主菜单。

抽屉是面板的扩展。你可以将放在面板上的相同对象放入抽屉中，也包括另一个抽屉。当你点击抽屉对象时，抽屉会打开；然后你可以像点击面板上的对象一样点击抽屉内的对象。

## 面板对象右键菜单

有选项是面板对象右键菜单特有的（右键点击面板对象）。“从面板移除”选项正是执行此操作。“移动”选项允许你在面板内移动对象或将其移动到其他面板；你还可以通过使用鼠标中键拖拽来移动对象。“锁定到面板”选项会将对象锁定在当前位置使其无法移动。当你移动面板上的某个对象时，它可以穿过其他对象。如果另一个对象未锁定，在必要时它可以置换该对象。当对象被锁定时，“移动”选项将呈灰色。

# 主菜单

主菜单出现在顶部面板的左侧，包含“应用程序”、“位置”和“系统”。点击这些单词之一可显示相应的菜单。

“应用程序”菜单包含多个子菜单，每个菜单按应用程序分类命名（例如：游戏、图形、互联网）。最后一个选项“添加/删除”将在第 120 页讨论。子菜单中的选项——仔细查看这些选项，将鼠标悬停在它们上方时，确定会显示工具提示。

“位置”菜单包含多种启动器，其中大多数都会打开文件浏览器窗口。主文件夹、文档和桌面对象显示具有相应名称的目录。计算机、CD/DVD 刻录器和网络对象显示特殊位置。这些位置中的每一个都允许你访问文件管理器功能。例如，每个特殊的 URI 指定了这些位置。例如，“CD/DVD 刻录器”选项显示 `burn:///` URI，允许你创建 CD 或 DVD。“连接到服务器”选项会打开一个窗口，允许你连接各种类型的服务器，包括 SSH 和 FTP。在这些选项下方是挂载的文件系统；点击其中一个可显示该文件系统的顶层目录。“搜索文件”选项允许你搜索文件。

![图 4-15 典型窗口](img/556454b01d95450a92edff64b47580d6_157_0.png)

“系统”菜单包含两个子菜单（可以提供支持的选项）以及“退出”选项。这两个子菜单是配置你的账户以及设置和维护系统的关键。

“偏好”子菜单确立你账户的特征；每个用户都可以建立自己的偏好。点击这些选项中的某些，以熟悉在 Ubuntu 系统上自定义账户的方法。

“管理”子菜单控制系统的工作方式。例如，“管理 文件夹共享”允许 Ubuntu 使用 NFS 或 Samba 与其他系统共享文件夹。“管理网络”允许配置系统的网络连接。这些选项大部分都需要你拥有系统管理员权限并输入密码才能进行更改。这些菜单选项在书中都有讨论。

你可以将主菜单中的任何启动器复制到面板或桌面。不要用左键点击菜单选项，而是右键点击它。GNOME 会显示一个小菜单，你可以将启动器添加到顶部面板或桌面。

# 窗口

在工作区中，*窗口*是一个由特定程序运行或受控制的区域。因为你可以控制窗口的外观和感受——甚至是它们显示的按钮——你的窗口看起来可能与书中的不同。工作区中的每个窗口在底部面板上都有一个“窗口列表”程序。

![图 4-16 窗口标题栏](img/556454b01d95450a92edff64b47580d6_158_0.png)

标题栏出现在大多数窗口的顶部，并控制其所属的窗口。你可以更改标题栏的外观和功能，但它通常至少具有图 4-16 所示按钮的功能。

最小化（图标化）按钮会将窗口折叠，使得窗口的唯一指示是底部面板上的“窗口列表”；点击此按钮可恢复窗口。点击最大化按钮可扩展窗口以占据整个工作区；在最大化窗口的标题栏上点击同一个按钮可窗口恢复到原来的尺寸。你也可以双击标题栏来最大化和恢复窗口。用鼠标中键点击最大化会沿垂直方向扩展；使用左键则沿水平方向扩展。使用相同或不同的鼠标键再次点击最大化按钮，看看会发生什么。点击关闭按钮会关闭窗口并终止其中运行的程序。左键点击标题栏并拖动窗口以重新定位。

“窗口列表”程序显示工作区中所有已打开窗口的列表。你可以点击窗口名称将其置到最前面，或右键点击它显示选项菜单。

“窗口列表”程序是管理窗口的便捷方法，特别是当你打开了许多窗口时。你还可以在窗口列表中拖放窗口以重新排序。

# 从终端模拟器/SHELL 运行命令

**终端模拟器**是一个显示命令行界面 (CLI) 的窗口；它作为一个文本（基于字符的）终端工作，并显示在图形化环境中。

要显示名为 Terminal 的 GNOME 终端模拟器，请选择**主菜单：应用程序 > 辅助工具 > 终端**，或在运行窗口（`Alt-F2`）中输入命令 `gnome-terminal`。由于你已经登录并在桌面环境中创建了子 shell，因此你不需要再次登录。一旦打开了终端模拟器，尝试输入命令 `man man` 来阅读关于 `man` 的介绍，该用于显示 Linux 手册页。第 5 章将介绍你可以从终端模拟器运行的实用程序。

你可以在终端模拟器窗口中运行通常在终端或控制台上运行的基于字符的程序。你也可以从此窗口启动图形化程序，例如 `xeyes`。图形程序会打开它自己的窗口。

当你在终端模拟器中输入时，某些字符如 `*`、`?`、`[` 和 `]` 有特殊含义。在阅读第 146 页的“特殊字符”之前，请避免使用这些字符。

shell 一旦打开终端模拟器，你就在与名为 *shell* 的命令解释器进行通信。shell 在你与 Linux 的通信中起着重要作用。当你通过键盘输入命令以响应屏幕上的 shell 提示时，shell 会解释并启动相应的操作——例如，执行程序；调用编译器、Linux 实用程序或其他标准程序；或者显示指示你输入命令错误的错误消息。当你使用 GUI 时，你将跳过 shell 并通过点击对象或名称来执行程序。有关 shell 的更多详细信息，请参阅第 7 章。

# 对象属性窗口

对象属性窗口显示有关文件的信息，例如所有者、权限、大小、MIME 类型、方法等。此窗口标题为“属性”，其中 *文件名* 是你点击的文件名。通过右键点击对象并从菜单中选择属性来显示此窗口。本节介绍了对象属性常用的五个选项卡。

基本选项卡显示有关文件的信息，包括其 MIME 类型，并允许为文件选择自定义图标。在标记为名称的文本框中更改文件名。如果文本框未列出，说明你没有权限更改它。

![图标选项卡](img/556454b01d95450a92edff64b47580d6_163_0.png)

打开 `/usr/share/icons` 的文件浏览器。向下浏览目录找到一个图标，然后将其拖放到对象属性窗口中名称左侧。这种技术对于链接（由右上角的箭头图标指示）无效。

图标选项卡允许你通过在复选框中放置勾选来添加和删除与文件相关的图标。图 4-15 显示了对象上的图标。Nautilus 在其图标视图和列表视图中都显示图标，尽管列表视图中可能只能容纳一个图标。桌面上也显示图标。你还可以通过从侧边栏/图标拖动图标并将其放在文件浏览器窗口视图面板的对象上来放置图标。拖动图标可以移除对象上的大部分图标。
