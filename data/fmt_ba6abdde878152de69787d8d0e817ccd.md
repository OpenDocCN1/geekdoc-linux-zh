## ser2net

允许连接到串口。此守护进程允许与串口建立 `telnet` 和 `tcp` 会话。通过使用 `xterm` 等终端仿真器或 Linux 控制台，这可以作为与路由器、其他系统的串口台以及带有串口的设备通信非常简单的方法。这与 Cisco 路由器的反隧道非常相似。源自 Debian 3.0r0 `http://www.tld.org/LDP/Linux-Dictionary/index.html`

server (服务器)

一种计算机系统或软件包，提供在其他计算机上运行的特定种类的软件。该词可以指某个特定的软件，例如 WWW 服务器，也可以指运行该软件的机器，例如：“我们的服务器今天宕机了，所以邮件无法发出去。”单个服务器可以（并且通常会）运行不同的服务器软件包，其设计目的是通过通过添加小程序作为内核，为主程序添加额外功能。来自 Matisse `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

Server (服务器程序)

一种向其他（客户端）程序提供服务的程序。服务器与客户端之间的连接通常通过网络上的消息传递来实现，并使用协议对客户端的请求和服务器的响应进行编码。来自 Linux Guide @FirstLinux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

server (名词)

n。一种为请求者提供服务的守护进程（daemon），通常运行在请求者/客户端使用的其他计算机上。互联网上特别常见的一种是，丰富的“网络服务器”、“名称服务器”、“域名服务器”、“新闻服务器”、“指纹服务器（finger servers）等。来自 Dictionary dictionary `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

server message block (SMB) (服务器消息块)

一种用于促进局域网内共享文件、打印机和其他资源的协议。`Samba` 是 `SMB` 协议的 Linux 兼容实现。来自 Redhat–9–Glossary `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

Server optimized Linux (服务器优化版 Linux)

`Sol`. (Server optimized Linux) 是一种与其他 Linux 发行版完全独立的 Linux 发行版。它由 antich 从原始源代码构建，并针对重型服务器工作进行了优化。它包含了所有服务器应用程序，并采用了 XAML 启动和脚本技术，使其易于配置和运行服务器。SoL 13.37 于 2002 年 4 月 22 日发布（首次 Fresh 发布）。版本 16.00 于 2003 年 3 月 17 日发布。无盘版本 SoL–diag 1.1 于 3 月 3 日引入。桌面版本 SoL–Desktop 0.2 于 2003 年 3 月 27 日发布。来自 LWN Distribution List `http://www.tld.org/LDP-Linux-Dictionary/html/index.html`

# Serverdisk diskette distro (Serverdisk 软盘发行版)

Serverdisk diskette distro 是一个包含 FTP 和 HTTP 服务器的软盘发行版。它只是一个小型服务器，并非用于救援磁盘或独立的免费运行器。初始版本 0.1 于 2002 年 9 月发布。一种基于软盘的发行版。来自 LWN Distribution List `http://www.tld.org/LDP-Linux-Dictionary/html/index.html`

# Servlet (小型程序)

一种设计为大型软件添加功能的小型计算机程序。常见的例子是“Java servlets”，它们是用 Java 语言编写的小型程序，被添加到 Web 服务器中。通常，使用 Servlets 的 web servlet 会有很多个，每个都设计用于处理非常特定的情况，例如，一个 servlet 负责向“购物车”中添加项目，而另一个 servlet 则负责从“购物车”中删除项目。来自 Matisse `http://www.tld.org/LDP/Linux–Dictionary/html/index.html`
