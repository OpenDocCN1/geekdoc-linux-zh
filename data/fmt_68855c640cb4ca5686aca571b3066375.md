## find

在目录层次结构中查找符合给定标准的文件。操作选项允许你指定找到文件后对它们进行什么处理。

| 搜索选项 | 描述 |

| - | - |

| `-name filename` | 查找具有指定文件名的文件。 |

| `size ±` | 查找大小为 n 的文件。 |

| `-type file type` | 查找具有指定访问模式的文件。 |

| `-atime ±` | 查找 n 天前访问过的文件。 |

| `-mtime ±` | 查找比 `filename` 修改时间更近的文件。 |

| 打印选项 | 描述 |

| - | - |

| `-print` | 打印找到的每个文件的路径名。 |

| `-exec command;` | 允许你提供应用于这些文件的命令。 |

| `-ok command;` | 在应用命令前请求确认。 |
