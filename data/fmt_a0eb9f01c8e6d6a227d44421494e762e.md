# Dot file (点文件)

在 UNIX 中，一种通过正常浏览工具不可见的文件（由 UNIX 文件列出程序显示）。以点开头的命名按照习惯，经常用于用户配置，例如列出用户经常查询的组的文件。来自 QUEDIC http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# dot file (点文件)

[Unix].一种通过正常浏览工具不可见的文件（在 Unix 上，按照习惯，以点开头命名的文件不会出现在目录列表中）。许多程序在启动时定义一个或多个点文件，或者可以选择性记录配置信息；用户可以通过在当前主目录中创建适当的文件来自定义程序行为。（因此，点文件倾向于蔓延——每个非平凡的应用程序至少定义一个，用户的主目录会充满点文件的方块，而用户对此却毫无察知。）另见 profile (sense 1) 和 rc file。来自 Jargon Dictionary

### dotfile

通过 Tcl/Tk 界面对流行程序进行轻松配置。`Dotfile Generator` 是一个配置工具，用于配置你喜爱的程序的基本功能甚至是更奇特的功能。它将来自配置框、条目、菜单等的信息转换为某种代码（例如 Lisp、C、fwm 窗口管理器的配置语言或任何文本代码）。这些信息被转换为代码，程序员在代码中指定哪些元素显示复选按钮、列表等，并对每个元素提供一些帮助。在此发行版本中，存在用于配置 bash、mfw1、mfw2、tcl、elm、rcm、ipfwd、procmail 和 canmay 的模块，并可以在命名为 `dotfile-<program>` 的独立包中找到它们。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/

### doxygen

用于 C、C++ 和 IDL 的文档系统。`Doxygen` 是一个用于 C、C++ 和 IDL 的文档系统。它可以从一组带有文档的源文件生成在线类浏览器（HTML）或离线参考手册（LaTeX）。它还支持管理页面并将输出转换为 Postscript、超链接 PDF 或处理过的 HTML。文档直接从源码中提取。来自 Debian 3.0r0 APT http://www.tldp.org/LDP/
