### 5.3.6 确保 sudo 超时配置正确（自动化）

**配置描述适用性：**

*   等级 1 - 服务器
*   等级 1 - 工作站

**描述：**

`sudo` 缓存凭据的默认值为 15 分钟。可以根据安全策略修改超时。

**理由：**

设置超时时间可以减少未经授权访问的窗口。

**审计：**

确保超时时间不超过 15 分钟。使用以下命令检查：

```
# grep -roP "timestamp_timeout=\K[0-9]*" 
```

如果 `/etc/sudoers*` 中没有配置 `timestamp_timeout`，则超时时间默认为 15 分钟。通过以下命令验证：

```
# sudo -V | grep "timestamp:"
```

注意：如果值为 `-1` 表示超时已禁用。根据特定的策略，这可能意味着针对特定的会话。

**修复：**

如果当前配置的超时时间超过 15 分钟，请使用 `visudo -f <PATH TO FILE>` 编辑文件并将 `timestamp_timeout` 设置为 15 分钟或更短。参考以下示例：

```
Defaults    env_reset, timestamp_timeout=15
Defaults    timeout=15
```

### 5.3.7 限制对 su 命令的访问（自动化）

**配置描述适用性：**

*   等级 1 - 服务器
*   等级 1 - 工作站

**描述：**

`su` 命令允许用户以用户的身份运行命令或 shell。该程序已被 `sudo` 取代，后者对特权访问提供了更细粒度的控制。通常情况下，任何用户都可以执行 `su` 命令。通过取消注释 `/etc/pam.d/su` 中的 `pam_wheel.so` 语句，`su` 命令将只允许特定组的用户执行 `su`。该组应为空，以强化对 `sudo` 的使用。

**理由：**

限制 `su` 的使用并用 `sudo` 代替，可以让系统管理员更好地控制用户权限提升。`sudo` 工具还提供了更好的日志和审计机制，因为它可以记录通过 `sudo` 执行的每条命令，而 `su` 只能记录用户执行了 `su`。

**审计：**

运行以下命令：

```
# grep -Pi (^\h*auth\h+(?:required|requisite)\h+pam_wheel\.so\h+(?:\:[#n\r]+\h+))?((\group\b=use_uid\b)\group\h+(?:\:[#n\r]+\h+))?(((?!\l))\h+(?:group\b=use_uid\b)\group\h+\h+\*)? /etc/pam.d/su
```

验证输出匹配：

```
auth required pam_wheel.so use_uid group=<group_name>
```

运行以下命令并验证指定的 `<group_name>` 不包含任何用户：

```
# grep <group_name> /etc/group
```

验证输出不包含任何相关的组：

```
<group_name>:x:<GID>
```

**修复措施：**

创建一个用于 `su` 命令的空组。该组名称应根据站点策略命名。

示例：

```
# groupadd sugroup
```

将以下行添加到 `/etc/pam.d/su` 文件中，指定该空组：

```
auth required pam wheel.so use uid group=sugroup
```

### 5.4.1 确保密码创建要求已配置（自动化）

**配置适用性：**

*   等级 1 - 服务器
*   等级 1 - 工作站

**描述：**

`pam_pwquality.so` 模块检查密码强度。它执行此类检查，例如确保密码不是字典词汇、具有特定长度、包含混合字符（如字母、数字、其他）等。

在 `/etc/security/pwquality.conf` 文件中设置了以下选项：

*   密码长度：
    *   `minlen = 14` - 密码必须至少为 14 个字符
*   密码复杂度：
    *   `minclass = 4` - 新密码所需的字符类别最小数（数字、大写、小写、其他）
    *   或者
        *   `dcredit = -1` - 提供至少一个数字
        *   `ucredit = -1` - 提供至少一个大写字母
        *   `ocredit = -1` - 提供至少一个特殊字符
        *   `lcredit = -1` - 提供至少一个小写字母

**原理：**

强密码可以保护系统免受暴力破解攻击。

**审计：**

验证密码创建要求符合组织策略。

**密码长度**

运行以下命令：

```
# grep '^\s*minlen\s*' /etc/security/pwquality.conf
```

验证输出是否匹配：

```
minlen = 14
```

**密码复杂度**

**选项 1**

运行以下命令：
