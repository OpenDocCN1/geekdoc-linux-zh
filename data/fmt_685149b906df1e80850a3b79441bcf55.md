
在这个脚本中，我们确定整数 `INT` 的值是否位于 `MIN_VAL` 和 `MAX_VAL` 之间。这是通过单次 `[[ ]]` 实现的，它包含了两个由 `&&` 运算符分隔的表达式。我们也可以使用以下测试编写代码：

```bash
if [ "$SINT" -ge "$MIN_VAL" -a "$SINT" -le "$MAX_VAL" ]; then
    echo "$SINT is within $MIN_VAL to $MAX_VAL"
else
    echo "$SINT is out of range."
fi
```

取反运算符会改变表达式的结果。如果表达式为假，它返回真；如果表达式为真，它返回假。在下面的脚本中，我们修改了评估逻辑，以找到指定范围之外的 `INT` 值：

```bash
#!/bin/bash
# test-integer4: determine if an integer is outside a
# specified range of values.
MIN_VAL=1
MAX_VAL=100
INT=50
```

```bash
if [[ "$SINT" =~ ^[0-9]+$ ]]; then
    if [ ! ("$SINT" -ge "$MIN_VAL" && "$SINT" -le "$MAX_VAL") ]; then
        echo "$SINT is out of range."
    else
        echo "$SINT is in range."
    fi
else
    echo "$INT is not an integer." >&2
    exit 1
fi
```

我们还在表达式周围加上了括号以便分组。如果不包含括号，取反将只作用于第一个表达式，而不是两个表达式的组合。使用这种测试编写的方法如下：

```bash
if [ ! ("$SINT" -ge "$MIN_VAL" -a $SINT -le "$MAX_VAL") ]; then
  echo "$SINT is inside $MIN_VAL to $MAX_VAL."
fi
```

由于 `test` 使用的所有表达式和运算符都被 shell 视为命令参数，`[ ]` 和 `(( ))` 字符对 bash 具有特殊含义（例如 `<`, `>`, `)`），必须被引起来或转义。

考虑到 `test [ ]` 和 `[[ ]]` 的功能大致相同，哪种更好呢？`test` 是传统的（也是 POSIX shell 命令规范的一部分，这些命令通常用于运行系统启动脚本），而 `[[ ]]` 是 `bash` 特有的（以及其他现代 shell）。了解如何使用 `test` 是重要的，因为它被广泛使用，但 `[[ ]]` 显然更有用且更容易编写，因此在现代脚本中是首选。

# 控制运算符：另一种分支方式

`bash` 提供了两个可以执行分支的控制运算符。`&&`（与）和 `||`（或）运算符的工作方式与 `[[ ]]` 复合命令中的逻辑运算符类似。`&&` 的语法如下：

```bash
command1 && command2
```

`||` 的语法如下：

```bash
command1 || command2
```

理解这些行为非常重要。对于 `&&` 运算符，`command1` 总是会被执行，且仅当 `command1` 执行成功时才执行 `command2`。对于 `||` 运算符，`command1` 总是会被执行，且仅当 `command1` 执行失败时才执行 `command2`。

在实践中，这意味着我们可以执行如下操作：

```bash
[me@linuxbox ~]$ mkdir temp && cd temp
```

这将创建一个名为 `temp` 的目录，如果成功，当前工作目录将更改为 `temp`。只有在 `mkdir` 命令成功时，才会尝试执行第二个命令。同样，类似下面的命令：

```bash
[me@linuxbox ~]$ [[ -d temp ]] || mkdir temp
```

将测试目录 `temp` 是否，只有在测试失败时才会创建该目录。这种结构对于处理脚本中的错误非常方便，我们将在后面的章节中详细讨论这个主题。例如，我们可以在脚本中这样做：

```bash
[[ -d temp ]] || exit 1
```

如果脚本需要 `temp` 目录且它不存在，则脚本将以状态码 `1` 退出。

记住，当我们想要做一些复杂的操作时，命令可以是一个分组命令。

```bash
{ true && echo "true"; } && { false || echo "false"; }
```

分组命令返回组内最后一个命令的状态。

## 总结

我们这一章从一个问题开始。我们如何让 `sys_info_page` 脚本检测用户是否有权限读取所有目录？通过我们对 `if` 的知识，可以通过将以下代码添加到 `report_home_space` 函数中解决问题：

```bash
report_home_space () {
    if [[ "$(id -u)" -eq 0 ]]; then
        cat <<EOF
<h2>Home Space Utilization (All Users)</h2>
<pre>du -sh /home/*</pre>
EOF
    else
        cat << _EOF_
<h2>Home Space Utilization ($USER)</h2>
<pre>du -sh $HOME</pre>
_EOF_
    fi
}
```

显示一个提示，然后我们使用 `read` 为变量 `int` 输入一个值。运行此脚本的结果如下：

```
[me@linuxbox ~]$ read-integer
Please enter an integer -> 5
s is positive.
is is odd.
```

`read` 可以将输入赋值给多个变量，如下脚本所示：

```bash
#!/bin/bash
# read-multiple: 从键盘读取多个值
echo -n "Enter one or more values > "
read var1 var2 var3 var4 var5
echo var1 = '$var1'
echo var2 = '$var2'
echo var3 = '$var3'
echo var4 = '$var4'
echo var5 = '$var5'
```

在这个脚本中，我们分配并显示了多五个值。注意 `read` 在接收到不同数量的值时的行为，如下：

```
[me@linux -]$ read-multiple
Enter one or more values > a b c d e
var1 = 'a'
var2 = 'b'
var3 = 'c'
var4 = 'd'
var5 = 'e'
[me@linuxbox -]$ read-multiple
Enter one or more values > a
var1 = 'a'
var2 = ''
var3 = ''
var4 = ''
var5 = ''
[me@linux -]$ read-multiple
Enter one or more values > a b c d e f g
var1 = 'a'
var2 = 'b'
var3 = 'c'
var4 = 'd'
var5 = 'e f g'
```

如果 `read` 接收到的数量少于预期数量，多出的变量将为空；而输入量过多会导致最后一个变量包含所有额外的输入内容。

如果 `read` 命令后没有列出变量，则 shell 变量 `REPLY` 将接收所有输入。

```bash
#!/bin/bash
# read-single: 将多个值读取到默认变量
echo "Enter one or more values > "
read
echo "REPLY = $REPLY"
```

运行此脚本的结果如下：
```
[me@linux ~] read-single
Enter one or more values > a b c d
REPLY = 'a b c d'
```

## 选项

`read` 支持表 28-1 中描述的选项。

### 表 28-1: read 选项

| 选项 | 描述 |
| :--- | :--- |
| `-a array` | 将输入赋值给数组，从索引零开始。我们将在第 35 章介绍数组。 |
| `-d delimiter` | 字符串分隔符中的第一个字符用作输入的结束标志，而不是换行符。 |
| `-e` | 使用 Readline 处理输入。这允许像在命令行一样进行输入编辑。 |
| `-i string` | 如果用户仅按下回车键，则使用字符串作为默认回复。需要配合 `-e` 选项。 |
| `-n num` | 读取 `num` 个输入字符，而不是一整行。 |
| `-p prompt` | 使用字符串 `prompt` 显示输入提示。 |
| `-r` | 原始模式。不将反斜杠解释为转义字符。为了建议使用此选项。例如，在输入 DOS 路径名时，我们希望反斜杠被视为普通字符。 |
| `-s` | 静音模式。输入字符时不将其回显到屏幕上。这在输入密码和其他机信息时非常有用。 |
| `-t seconds` | 超时。在 `seconds` 秒后终止输入。如果输入超时，`read` 将返回非零退出状态。 |
| `-u fd` | 使用文件描述符 `fd` 的输入，而不是标准输入。 |

使用各种选项，我们可以对 `read` 进行一些有趣的操作。例如，通过 `-p` 选项，我们可以提供一个提示字符串。

```bash
#!/bin/bash
# read-single: 将多个值读取到默认变量
read -r -p "Enter one or more values > " 
echo "REPLY=$REPLY"
```

通过 `-t` 和 `-s` 选项，我们可以编写一个脚本读取“秘密”输入，如果输入在指定时间内未完成则超时：

```bash
# read-secret: 输入秘密口令
if read -r t 10 -s "Enter secret passphrase > " secret_pass; then
	echo -e "\nsecret=$secret_pass"
else
	echo -e "\nInput timed out" >&2
	exit 1
fi
```

该脚本提示用户输入秘密口令并等待 10 秒输入。如果输入在指定时间内未完成，脚本将带错误退出。由于包含了 `-s` 选项，口令的字符在输入时不会回显到屏幕上。

可以通过结合使用 `-e` 和 `-i` 选项为用户提供默认响应。

```bash
#!/bin/bash
# read-default: 如果用户按下按键则提供默认值。
read -e -p "What is your user name? " -i USER
echo "You answered: $REPLY"
```

在这个脚本中，我们提示用户输入用户名，并使用环境变量 `USER` 提供默认值。当运行脚本时，它会显示默认字符串，如果用户仅按下回车键，`read` 将将默认字符串赋值给 `REPLY` 变量。

```
[linuxbox ~]$read-default
What is your user name? me
You answered: 'me'
```

## IFS

通常情况下，shell 对提供给 `read` 的输入进行单词拆分（word splitting）。正如我们所看到的，这意味着由一个或多个空格分隔的多个单词变成了多个变量。内部字段分隔符 `IFS` 决定了使用哪些字符作为分隔符。默认情况下，`IFS` 包含空格、制表符和换行符。

我们可以更改 `IFS` 来改变 `read` 拆分输入的方式。例如：

```bash
IFS=":"
read -r name password uid gid <<EOF
root:x:0:0:root:/root:/bash
EOF
echo "User is $name"
```

通过将 `IFS` 设置为冒号，我们告诉 `read` 根据冒号来拆分输入。这对于解析 `/etc/passwd` 等文件特别有用。

但当命令退出时，子shell 及其会被销毁，赋值的效果也会丢失。
使用 "here strings" 是解决这种行为的方法。另一种方法将在第 36 章中讨论。

## 验证输入

能够进行键盘输入能力也带来了一个额外的编程挑战：验证输入。通常，一个编写良好的程序和一个编写糟糕的程序之间的区别在于程序处理意外情况的能力。意外情况通常以错误输入的形式出现。在上一章中，我们已经通过评估程序做了一些这类工作，当时我们检查了整数值并过滤掉了所有非数字字符。在程序每次接收输入时，执行此类编程检查是非常重要的，以防止无效数据。这对于由多个用户共享的程序来说尤为重要。如果一个程序只由作者使用一次来执行某些特殊任务，忽略这些安全措施可能是可以接受的。即便如此，如果程序执行的是删除文件等危险任务，为了以防万一，包含数据验证也是明智之举。

这里有一个验证各种类型输入的示例程序：

```bash
#!/bin/bash
read-validate: validate input
invalid_input() {
  echo "Invalid input '$REPLY" >&2
  exit 1
}
read -p "Enter a single item " "
# 输入为空（无效）
[[ -z "$REPLY" ]] && invalid_input
# 输入为多个项（无效）
(( $(echo "$REPLY" | wc -w) > 1 )) && invalid_input
# 输入是有效文件名吗？
if [[ "$REPLY" =~ ^\{[:alnum:].-]+\$ ]]; then
  echo "$REPLY' is a valid filename."
  if [[ -e "$REPLY" ]]; then
    echo "And file '$REPLY' exists."
  else
    echo "However, file '$REPLY' does not exist."
  fi
fi
```

```bash
# 输入是浮点数吗？
if [[ "$REPLY" =~ ^[[:digit:]]*\.[[:digit:]]+\$ ]]; then
    echo "$REPLY is a floating point number."
else
    echo "$REPLY is not a floating point number."
fi
```

```bash
# 输入是整数吗？
if [[ "$REPLY" =~ ^[[:digit:]]+\$ ]]; then
    echo "$REPLY is an integer."
else
    echo "$REPLY is not an integer."
fi
```

```bash
# 字符串 'REPLY' 不是有效文件名。
```

此脚本提示用户输入一个项。随后对该项进行分析以确定其内容。正如我们所见，该脚本包含了我们为止涵盖的许多概念，包括 shell 函数、`[[ ]]`、控制运算符 `&&` 和 `||`，以及大量的正则表达式。

## 菜单

一种常见的交互类型被称为菜单驱动。在菜单驱动程序中，用户会看到一个选项列表，并被要求选择其中之一。例如，我们可以想象一个程序显示如下内容：

请选择（Please Select）：

1. 显示系统信息
2. 显示磁盘空间
3. 显示主目录空间利用率
4. 退出

输入选择 [0-3] >

利用我们在编写 `sys_info_page` 程序时学到的知识，我们可以构建一个菜单驱动程序来执行一个菜单中的任务。

```bash
#!/bin/bash
# read-menu: 一个菜单驱动的系统信息程序
clear
echo ""
nPlease Select:
```

1. 显示系统信息
2. 显示磁盘空间
3. 显示主目录空间利用率
0. 退出

```bash
read -r -p "Enter selection [0-3] > " 
if [[ "$REPLY" =~ ^[0-3]$ ]]; then
  if [[ "$REPLY" == 0 ]]; then
    echo "Program terminated."
    exit
  fi
  if [[ "$REPLY" == 1 ]]; then
    echo "Hostname: $HOSTNAME"
    uptime
    exit
  fi
  if [[ "$REPLY" == 2 ]]; then
    df -h
    exit
  fi
  if [[ "$REPLY" == 3 ]]; then
    if [[ "$(id -u)" -eq 0 ]]; then
      echo "Home Space Utilization (All Users)"
      du -sh /*/*
    else
      echo "Home Space Utilization ($USER)"
      du -sh $HOME
    fi
    exit
  fi
else
  echo "Invalid entry." >&2
  exit 1
fi
```
