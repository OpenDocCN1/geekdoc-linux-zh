
该函数非常灵活。`a1`和`a2`定义了起始和结束角度。

## X 颜色模型

X *颜色模型*基于称为颜色表的数组。应用程序通过颜色表中的索引引用颜色。索引放置在应用程序的帧缓冲区，其中包含每个像素的条目。索引的位数定义了位平面数。位平面数定义了屏幕上同时显示的颜色数量。例如，每像素1位显示两种颜色，四位显示16种颜色，八位显示256种颜色。

应用程序通常继承父级的颜色表。它也可以通过调用`XCreateColormap`创建自己的颜色表。调用定义如下：

```c
Colormap XCreateColormap( Display *display,
 Window dwindow,
 Visual *vp,
 int allocate);
```

这在窗口颜色表中分配`allocate`个颜色条目。通常，视觉参数派自此宏：

`DefaultVisual (Display *display, int screenNumber);`

在大多数情况下`screenNumber = 0`。请参见第一章中的“屏幕、显示器和窗口”部分的定义。

颜色表是 X 中的重要资源，使用后必须释放。通过此调用实现：

`XFreeColormap(Display *display, Colormap c);`

应用程序可以通过`XGetStandardColormap()`调用从 X 服务器获取标准颜色表，并通过`XSetStandardColormap()`调用进行设置。这些定义为：

```c
XGetStandardColormap( Display *display,
 Window dwindow,
 XStandardColormap *c,
 Atom property);
```

以及

```c
XSetStandardColormap( Display *display,
 Window dwindow, XStandardColormap *c,
 Atom property);
```

这些是存储在服务器中的调色板（colormaps）名称。它们本身并不是调色板。

2. 通过此调用为窗口设置调色板：

`XSetWindowColormap ( Display *display,`

` Window dwindow,`

` Colormap c );`要在调色板中分配颜色，请使用`<X/Xlib.h>`中定义的`XColor`结构。

要显示亮蓝色，请使用以下段落：

`XColor color;`

`color.red = 0;`

`color.blue = 0xffff;`

`color.green = 0;`

然后通过调用函数将颜色添加到调色板：

`XAllocColor(Display *display,`

` Window dwindow,`

` XColor *color );`

光盘上的文件`2_17c`中显示了一个设置小部件颜色的示例函数。

默认的白色和黑色像素定义如下：

`Pixel BlackPixel( Display *dpy, int screen); Pixel WhitePixel( Display *dpy, int screen);`

这些将作为任何屏幕的备选方案并工作。该函数返回的索引（`Pixel`）不能保证在每次应用程序运行时都是相同的。这是因为调色板可以在多个以不同顺序请求颜色的应用程序之间共享。每个条目都是根据下一个可用条目分配的。有时，如果你覆盖了单元格中的现有条目，你可能会在完全不同的应用程序中看到变化。因此请小心。

应用程序可以通过调用此函数查询颜色的*RGB*组件：

`XQueryColor( Display *display,`

` Colormap *cmp,`

` XColor *clr);`

一次性处理许多颜色，请使用此：

`XQueryColors( Display *display,`

` Colormap *cmp,`

` XColor *clr,`

` int number);`

此时，应用程序可以修改 RGB 组件并通过此调用将其存储在调色板中：

`XStoreColor( Display *display,`

` Colormap *cmp,`

` XColor *clr);`

记住`X11`在`/usr/lib/rgb.txt`中对颜色有一些奇怪的名字。应用程序可以通过调用此项获取这些名称的 RGB 组件：

`XLookupColor( Display *display,`

` Colormap cmp,`

` char *name,`

` XColor *clr`

` XColor *exact);`

名称是在`rgb.txt`文件中搜索的字符串。返回值`clr`包含调色板中最接近的现有条目。精确颜色条目包含`rgb.txt`条目中精确的 RGB 定义。此函数并不在调色板中分配颜色。要执行此操作，请使用此调用：

`XAllocNamedColor( Display *display,`

` Colormap cmp,`

` char *name,`

` XColor *clr`

` XColor *exact);`

## 像素图、位图和图像

像素图（pixmap）类似于窗口，但它是离屏的，因此对用户是不可见的。它的深度通常与屏幕相同。你通过此调用创建像素图：

`XCreatePixmap (Display *dp,`

` Drawable dw, unsigned int width, unsigned int height, unsigned int depth);`

绘制区域（drawable）可以是窗口（屏幕内）也可以是像素图（屏幕外）。位图（bitmaps）是深度为像素的像素图。查看`/usr/include/X11/bitmaps`可获得一些标准位图的列表。

将像素图从内存拷贝到屏幕的方法是通过此调用：

`XCopyArea( Display dp,`

` Drawable Src,`

` Drawable Dst,`

` GC gc,`

` int src_x,`

` int src_y,`

` unsigned int width,`

` unsigned int height,`

` int dst_x,`

` int dst_y);`

此调用的注意事项是`Src`和`Dst`绘制区域具有相同的深度。要在屏幕上显示深度大于一个像素的位图，你必须一个平面地拷贝位图。这是通过以下调用实现的：

`XCopyPlane( Display dp,`

` Drawable Src,`

` Drawable Dst,`

` GC gc,`

` int src_x,`

` int src_y,`

` unsigned int width,`

` unsigned int height,`

` int dst_x,`

` int dst_y,`

` unsigned long plane);`

平面指定了这个位比特深位图必须拷贝到的*位平面*（bit plane）。实际操作很大程度上取决于 GC 中设置的模式。例如，为了显示`/usr/include/bitmaps`目录中的文件，一个名为`gumby.h`的示例具有三个定义值：

- `gumby_bits`: 指向字符位数组的指针
- `gumby_height`: 整数高度
- `gumby_width`: 整数宽度
