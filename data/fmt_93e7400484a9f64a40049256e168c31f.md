查找命令 `cal` 的源文件/二进制文件的位置。

# 命令

```
whereis cal
```

该命令有两种种使用方法：

- 数字模式
- 符号模式

```bash
## 覆盖现有文件
$ echo "Albert Einstein" > 1.txt
## 追加第二行
$ echo "Alan Turing" >> 1.txt
```

| 数字模式 | 权限类型 | 符号模式 |
| --- | --- | --- |
| 0 | 无权限 | --- |
| 1 | 执行 | --x |
| 2 | 写入 | -w- |
| 3 | 执行 + 写入 | -wx |
| 4 | 读取 | r-- |
| 5 | 读取 + 执行 | r-x |
| 6 | 读取 + 写入 | rw- |
| 7 | 读取 + 执行 | rwx |
