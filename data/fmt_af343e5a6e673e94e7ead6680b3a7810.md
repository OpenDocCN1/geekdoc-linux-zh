### 4. 与局域网 (LAN) 另一台计算机通信
可以使用 `ping` 命令向另一台计算机发送数据包并请求回包。你可以提供主机名 (`butch`) 或 IP 地址 (`10.0.0.10`)。例如，要 ping 网络上名为 `butch` 的计算机，输入以下命令：

```
# ping butch
```

### 5. DNS 访问检查
如果你能够通过 `ping` 访问局域网上的 IP 地址，但无法通过名称 ping 主机，则你可能没有与 DNS 服务器通信。使用 DNS 服务器的 IP 地址重试 `ping` 命令，查看它是否正常以及你能与之通信的内容。
