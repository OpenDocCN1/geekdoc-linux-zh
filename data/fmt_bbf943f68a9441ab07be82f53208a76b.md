你的程序可以有多个陷阱，且不同的内容取决于程序退出的方式。信号 0 的陷阱将在所有退出（无论正常还是异常）时触发。其他信号的陷阱仅在这些信号之一发生时才会触发。表 10.4 提供了你想要捕获的最常见信号列表。

# 表格 10.4 常见中断信号及其动作

| 中断信号 | 动作 |
| --- | --- |
| 0 | 退出 (Exit) |
| 1 | HUP—会话挂起（或断开） |
| 2 | INT—中断 (Ctrl+\+) |
| 3 | QUIT—退出 (Ctrl+\++) |
| 15 | TERM—正常的 kill 命令 |

> 注意
> 你可以捕获信号 15（正常的 kill 命令）。这是 `kill` 命令发送的默认信号。然而，你也可以捕获其他信号。
