### 精选程序

这里显示了库中的两个程序：`ReadString` 和 `WriteString`。`ReadString` 是两者中最难处理的，它必须逐个读取字符，直到遇到行尾或指定数量的字符。

#### ReadString

`ReadString` 程序从标准输入读取字符串，并将字符以空终止字符串的形式放在缓冲区中。它在用户按下回车键时终止。

```assembly
ReadString PROC
; 从标准输入读取字符串
; 输入：DS:DX 指向缓冲区，
      CX = 最大输入大小，加1。
; 返回：
      AX = 输入字符串的大小
; 注释：按下回车键 (0Dh) 时停止。
;------------------------------------------------
push cx
; 保存寄存器
push si
push cx
mov si,dx                       ; 保存计数
; 指向输入缓冲区
dec cx
L1: mov ah,1                   ; 功能：键盘输入
int 21h
cmp al,0Dh                      ; 返回字符在 AL
; 行尾？
je L2                            ; 是：退出
mov [si],al                    ; 否：存储字符
inc si                             ; 增加缓冲区指针
loop L1                         ; 循环直到 CX=0
L2: mov BYTE PTR [si],0         ; 以空字节结束
pop ax                          ; 原始计数
sub ax,cx                       ; AX = 输入的大小
push si
pop cx
ret
ReadString ENDP
```

#### WriteString

`WriteString` 程序将空终止字符串写入标准输出。它调用一个名为 `Str_length` 的辅助程序，该程序返回字符串的字节数：

```assembly
WriteString PROC
; 将空终止字符串写入标准输出
; 输入：DS:DX = 字符串地址
; 返回：无
;------------------------------------------------
pusha                            ; 设置 ES 为 DS
INVOKE Str_length, dx           ; AX = 字符串长度
mov cx,ax                       ; CX = 字节数
ret
WriteString ENDP
```

### 13.3.4 示例：读取并复制文本文件

我们在本章中介绍了 `INT 21h` 功能 `3Fh`，其应用背景是从标准输入中读取数据。如果 `BX` 中的句柄标识的是一个已为输入模式打开的文件，则该功能也可用于读取文件。当功能 `3Fh` 返回时，`AX` 标识从文件中读取的字节数。当到达文件末尾时，`AX` 中的值将小于请求的字节数（`CX`）。
