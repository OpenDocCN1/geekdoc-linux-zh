
# Linux 术语表

### 所有权 (ownership)
文件系统中，有效权限基于所有权。每个文件都有所有用户和组。

### 包 (package)
分发文件的包。包通常包含文件的压缩存档以及关于如何安装的元数据。

### 包组 (package group)
可以安装的包组。

### 包管理器 (package managers)
如 `APT` 和 `RPM` 等安装软件并跟踪已安装内容的系统。

### 分页器 (pager)
一种用于逐页浏览文本文件的程序。`less` 工具提供了最常用的分页器之一。

### PAM
参见可插身份模块 `pluggable authentication modules`。

### 父 shell (parent shell)
启动 shell 脚本或程序的 shell 环境。进程或子脚本从父 shell 继承设置。

### 分区 (partition)
硬盘的划分，在其上面创建文件系统并将其挂载到目录结构中。

### 密码 (password)
用于身份验证的令牌。密码是个人设置的单词，并以加密方式存储。

### 口令 (passphrase)
基本上是密码，但比密码长且更安全。

### 路径 (path)
文件位置的完整引用。

### PE
参见物理区 `physical extent`。

### 外设备 (peripherals)
连接到计算机的设备，如打印机和显示器。

### 权限三要素 (permission trio)
用户、组和其他人的权限集。

### 权限 (permissions)
设置在文件或目录上的属性，允许用户访问这些文件或目录。

### 允许模式 (permissive)
一种不阻塞任何操作但记录所有操作到审计日志中的模式。这种模式通常用于排查 `SELinux` 问题。

### 物理备份 (physical backup)
将包含实际数据的文件写入备份的备份。物理备份的创建比逻辑备份困难，但同时也更可靠。

### 物理区 (physical extent)
逻辑卷管理的一个组件。物理卷（如磁盘）被分割称为物理区的块。物理区构成了逻辑卷的基础。

### 物理卷 (physical volume)
`LVM` 配置的基础单元。物理卷通常对应于分区或完整的磁盘设备。

### PID
参见进程标识号 `process identification number`。

### 管道 (pipe)
一种用于将一个命令的输出重定向到另一个命令输入的结构。

### pluggable authentication modules (PAM)
一组库集合，旨在为管理员提供更改用户账户验证方式的方法。

### policy
参见 `SELinux policy`（策略）。

### port
与服务关联的端口。该服务监听分配给该端口号的入网络数据包。

### Portable Operating System Interface (POSIX)
一种为了维护操作系统之间兼容性而创建的标准。该标准主要适用于 `UNIX`，并保证不同版本的 Linux 和 `UNIX` 能够相互兼容。`POSIX` 标准非常深入，它精确定义了程序应如何运行以保持最佳的兼容性。其他操作系统也部分符合 `POSIX`，包括不同的 Windows 版本。

### positional parameters
shell 变量 `$1`、`$2` 等，代表传递给脚本或函数的参数。

### POSIX
参见 `Portable Operating System Interface`（可移植操作系统接口）。

### port forwarding
端口转发，一种防火墙技术，将进入特定端口的流量转发到另一个端口，该端口可能在同一台主机上，也可能在不同的主机上。

### portmap
端口映射器是一个远程过程调用服务，需要在提供 `RPC` 服务的系统上运行。`Portmapper` 使用不对应特定 `TCP` 或 `UDP` 端口的动态端口；只要进程处于活动状态，服务就会选择一个使用的 `UDP` 或 `TCP` 端口。重启时，可能会使用不同的端口。它们需要映射到固定的 `UDP` 和 `TCP` 端口，以便为这些端口开放防火墙。`Portmapper` 仍被 `NFS` 服务组件使用。

### portal
在 `iSCSI` 中，门户是 `iSCSI` 目标服务的 `IP` 地址和端口。

### Postfix
一种邮件传输代理，最初由 `IBM` 构建，被拆分为独立的组件以增强安全性。

### primary group
每个 Linux 用户都是一个主组的成员。创建文件时，主组被分配为文件的组所有者。

### primary key
数据库表的主索引。

### primary partition
在 `MBR` 中，主引导记录中可以创建的最多四个分区之一。参见 `extended partition`（扩展分区）。

### principal
在 `Kerberos` 中，指可以使用 `Kerberos` 凭据识别和验证的实体。

### print queue
等待打印的打印作业列表。

### print spooler
负责从打印队列中提取下一个作业并将其发送到打印机的组件。

### priority
在 `syslog` 中，用于指定日志事件的严重程度。根据严重程度，可以采取特定操作。在进程处理中，指定进程的重要性。进程优先级用数字表示（可以使用 `nice` 修改）。优先级数字较低的进程会在优先级数字较高的进程之前处理。

### private key
用于解密用公钥加密数据的密钥。

### privileged user
参见 `root`。

### proc
一种内核接口，提供访问内核信息和内核调优参数。该接口通过 `/proc` 文件系统可用。

### process
在 Linux 上运行的任务。大致来说，一个进程对应一个程序，尽管一个程序可以启动多个进程。

### process identification number (PID)
用于识别 Linux 系统上运行的进程的唯一数字。

### protocol
计算中使用的一组规则，例如在计算机网络中用于建立两台计算机之间的通信。

### pseudo root file system
在 `NFS4` 中，指由 `NFS` 服务器导出多个共享的解决方案。客户端不是挂载每个单独的共享，而是挂载 `NFS` 服务器上的根文件系统，从而访问其有权访问的所有。

### pseudofile
看起来像普通文件系统的目录，但不是由文件支持，而是存在于内存 `RAM` 中。例如，`/proc` 以伪文件的形式暴露了内核设置和进程列表。

### public key
提供给其他用户和主机用于加密数据的密钥。当这些数据返回原始主机时，可以使用私钥进行解密。

### PV
参见 `physical volume`（物理卷）。

### queue
在进程管理中，队列用于等待执行的进程。

### Qmail
一种为了安全和易用而编写邮件传输代理。

### RAID
参见 `Redundant Array of Independent Disks`（独立磁盘阵列）。

### RCP
参见 `remote query`（远程查询）。

### realm
`Kerberos` 中的认证域。

### real time clock
主板上的硬件组件，即使在计算机关闭时也能保持时间。

### reboot
停止计算机并重新启动的过程。

### record
在关系型数据库中，一组字段，用于存储数据库中关于一个对象的数据。

### recursion
在 `DNS` 中，递归当一个名称无法解析 `DNS` 查询并需要将请求转发到另一个名称服务器时发生。在文件系统中，递归指的是包含子目录的内容，如 `ls -R`。

### Red Hat Package Manager
红帽用于软件软件包的包格式以及以及包管理软件的名称。`RPM` 也已成为许多其他 Linux 发行版包管理的标准。

### Redundant Array of Independent Disks (RAID)
一种使用普通磁盘构建更大、更可靠的磁盘组的方法，例如向两个独立的磁盘进行镜像写入。

### reference clock
在 `NTP` 配置中作为时间源的时钟。通常参考时钟是互联网上高度可靠的时钟，但也可以是计算机主板上的内部时钟。

### regular expression
搜索模式，允许用户以灵活的方式搜索模式。不要与 shell 元元字符混淆。

### relational database
一种将实体建模为表的数据库，允许你编写连接和聚合多个表的查询。

### relative path
指定为相对于当前工作目录偏移量的文件位置。

### relay
一种邮件系统，从一个系统接收邮件并发送到另一个系统，而不是将邮件投递到邮箱。

### relay host
一种邮件系统，从一个系统接收邮件并发送到另一个系统，而不是将邮件投递到邮箱。

### ServerRoot
在 `Apache` 中，`ServerRoot` 指预期存放服务器配置文件的位置。

### services
在 `systemd` 中：为了提供特定功能而需要启动的进程。在防火墙中：用于允许访问特定进程的防火墙设置配置。

### SetGID
一种特殊的权限设置，在该设置下执行时将使用命令组所有者的权限。

### SetUID
一种特殊的权限设置，在该设置下执行时将使用命令用户所有者的权限。

### SGID
参见 `SetGID`。

### Shadow Suite（影子套件）
一种系统功能，允许将系统上的加密密码 `/etc/shadow` 保存在在更安全的地方，而不是安全性较低且公开可见的 `/etc/passwd` 文件中。组密码也变得更加安全，因为它们从公开的 `/etc/group` 文件移动到了更安全的 `/etc/shadow` 文件。

### share
一个目录，使用 `NFS` 或 `CIFS` 等远程文件系统协议配置的远程访问。

### shared object（共享对象）
一种被多个应用程序使用的库，并在动态链接器在运行时进行链接。共享对象文件几乎总是以 `.so` 结尾。

### shebang
用于脚本，以指示应该使用哪种 shell 来执行脚本中的代码。如果没有使用 shebang，脚本代码将由父 shell 解释，这在某些情况下可能会导致错误。shebang 以 `#` 开头，后面跟着 `!` 和 shell 的完整路径，例如 `#!/bin/bash`。

### shell
可以执行命令的环境。`Bash` 是 Linux 默认的 shell，其他其他 shell 也是如此。

### metcharacters（元字符）
如 `*`、`?` 和 `[a-z]` 等字符，允许用户以灵活的方式引用文件名中的字符。

### signal（信号）
可以发送给进程的指令。存在常见的信号，如 `SIGTERM` 和 `SIGKILL`，Linux 内核允许使用共 32 种不同的信号。要向进程发送信号可以使用 `kill` 命令。

### Simple Mail Transfer Protocol (SMTP)
一种基于文本的协议，允许不同的邮件代理之间相互发送邮件。

### skel template（模板）
一个用用文件填充新用户账户家目录的目录。

### SMB
参见 `Server Message Blocks`（服务器消息块）。

### SMTP
参见 `Simple Mail Transfer Protocol`。

### software time（软件时间）
参见系统时间。

### source context（源上下文）
在 `SELinux` 中，上下文是标识允许操作的标签。`SELinux` 环境中的一切内容都有一个上下文。源上下文是发起操作的进程或用户的上下文。

### source RPM（源 RPM）
一个包含源代码以及如何将源代码编译为二进制文件的说明的包。

### sourcing（源）
在当前 shell 的上下文中读取运行脚本，而不是在子 shell 中。被 source 的脚本可以更改当前环境，而执行的脚本只会影响子 shell 及其环境。

### SQL
参见 `Structured Query Language`（结构化查询语言）。

### SSH
参见 `secure shell`。

### SSH tunneling（SSH 隧道）
一种通过为 `SSH` 创建安全连接的技术，可以安全的方式发送隧道数据。

### standard error（标准错误）
程序发送错误信息的默认位置。

### standard input（标准输入）
程序获取输入的默认位置。

### standard output（标准输出）
程序发送常规输出的默认位置。

### static linking（静态链接）
从常用库中提取代码并使其可执行应用程序的一部分，而不是从共享库中引入内容。

### static route（静态路由）
由网络管理员手动定义的路由。

### STDERR
参见 `standard error`。

### STDOUT
参见 `standard output`。

### sticky bit（粘性位）
一种特殊的权限设置，它修改了目录写权限的含义，使得删除目录内文件的只有文件所有者、目录所有者或 `root` 用户。历史上，粘性位用于保持程序留在内存中，不允许其交换到磁盘。

### Storage Area Network (SAN)（存储区域网络)
一种在网络上以块级别共享磁盘设备的解决方案。它们可以在 Linux 系统上像本地磁盘设备一样使用。`iSCSI` 和光纤 `Fiber Channel` 是常见的 `SAN` 协议。

### storage backend（存储后端）
在 `iSCSI` 中，用于存储目标 `target` 的启动器 `initiators` 后端。

### stratum 1（层级 1）
一种使用时间同步服务器。

### strings（字符串）
一种字符集合，如数字类型。

### Structured Query Language (SQL)（结构化查询语言）
用于查询和操作数据库的语言。

### subdomain（子域名）
在 `DNS` 中，一种允许在域中进行划分的方法。

### subnet mask（子网掩码）
一种网络划分。

### subnetting（子网划分）
通过子网掩码进行网络划分。

### subshell（子 shell）
在 shell 中运行的脚本。

### SUID（设置用户 ID）
参见 `SetUID`。

### SUSE
一种 Linux 发行版。

### SUSE Enterprise（SUSE 企业版）
一种 Linux 发行版。

### superblock（超级块）
文件系统中的结构，包含指针。

### swap（交换）
当内存频繁在磁盘和内存之间交换时。

### swap partition（交换分区）
用于交换的 Linux 分区。

### swappiness（交换积极性）
内核移动内存到交换的意愿。

### symbolic link（符号链接）
一种特殊的文件类型。

### sysctl（内核参数控制）
用于设置内核的工具。

### sysctl（内核参数控制）
用于设置内核。

### sysfs（虚拟文件系统）
内核的接口。

### systemd
在 `RHEL` 启动后的系统管理器。

### system clock（系统时钟）
硬件时间。

### system time（系统时间）
由操作系统维护的时间。

### software time（软件时间）
由操作系统维护的时间。

### table（表格）
`SQL` 数据库中的行和列。

### tainted kernel（污染内核）
加载了不支持模块的内核。

### target（目标）
在 `systemd` 中，文件的集合。

### target context（目标上下文）
`SELinux` 中的上下文。

### TCP（传输控制协议）
一种协议。

### TCP wrappers（TCP 封装）
一种通过使用 `/hosts.allow` 和 `/hosts.deny` 配置文件来安全网络服务的库。

### teaming（链路聚合）
一种网络冗余技术。

### TCP wrappers（TCP 封装）
一种旨在允许安全网络服务的库。

### teaming（链路聚合）
网络中允许多个接口连接的技术。

### Telnet（远程登录）
一种允许连接远程系统的软件程序。

### terminal（终端）
最初，终端是用户输入命令的屏幕。在现代 Linux 系统上，伪终端提供了 shell 窗口。

### TFTP
参见 `Trivial Transfer Protocol`。

### thrashing（抖动）
内存频繁交换。

### thread（线程）
进程的划分。

### 时区
一组共享共同时间的位置，通过与协调世界时间 `UTC` 的偏移量来测量。

### TLS
参见传输层安全 `Transport Layer Security`。

### 顶级域名
在域名命名系统中，顶级域标识了 `DNS` 域名的最高层。最初可用的顶级域名数量有限（如 `.com`、`.org` 和 `.net`），但这一数量最近已得到扩展。

### 传输控制协议 (TCP)
专注于数据包的传输。`TCP` 与 `UDP` 的区别在于，数据包被认为是“可靠的”，因为 `TCP` 会执行错误检查以确保所有数据包都到达目的地。

### 传输层安全 (TLS)
一种用于确保计算机网络上安全通信的加密协议。在 `TLS` 中使用了公钥和私钥，以及用于验证对方身份的证书。

### 简单文件传输协议 (TFTP)
一种用于安装服务器和其他环境的服务。需要通过网卡使用 `PXE` 启动进行安装的服务器。`DHCP` 服务器首先响应此 `PXE` 启动，提供 `IP` 地址。接着，`DHCP` 服务器将请求重定向到 `TFTP` 服务器，由该服务器提供启动镜像。

### TTL
参见生存时间 `time to live`。

### TTY
Linux 上提供虚拟终端的程序。每个终端仍有一个 `TTY` 名称，对于虚拟 `TTY` 为 `tty16`，对于伪终端为 `/dev/pts/0-nn`。

### UCS-2
一种尝试用 2 字节 `65,536` 种组合定义所有字符的格式。

### udev
一个与 Linux 内核协同工作以初始化硬件的服务。

### UDP
参见用户数据报协议 `User Datagram Protocol`。

### UEFI
统一扩展固件接口。参见扩展固件接口 `Extensible Firmware Interface`。

### UID
参见用户标识符。

### ulimit
一个允许管理员限制用户和组对系统资源访问权限的功能。

### umask
一个作为 shell 属性定义默认权限的八进制值。

### umask 值
在创建新文件或目录时，应用到文件和目录默认权限的值。`umask` 会修改设置在新文件或目录上的权限。

### unbound
`RHEL 7` 上 `DNS` 服务的名称，可以作为仅缓存的 `DNS` 服务器使用。

### unit
在 `systemd` 中，指由 `systemd` 管理的项。存在不同类型的单元，包括服务、路径、挂载和目标单元。

### 协调世界时间 (UTC)
一种全球使用的时间标准，无论用户处于哪个特定时区。世界时间对应格林威治标准时间。
