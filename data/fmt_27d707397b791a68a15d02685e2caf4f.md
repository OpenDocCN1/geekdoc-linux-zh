## 12 考虑防火墙

无论你使用哪种操作系统，添加防火墙都能提高你的安全性。虽然 Raspberry Pi 有内置的防火墙，但配置起来很复杂。

幸运的是，其他人注意到这一点并安装了防火墙，这是 `iptables` 的替代方案。

## 13 安装 ufw

因为 `iptables` 在没有网络连接时非常麻烦且容易出错，`ufw` 的开发是为了让防火墙配置变得快速快捷。

我们使用 `apt-get` 命令获取并安装 `ufw`。

```bash
sudo apt-get update
sudo apt-get install ufw
```
