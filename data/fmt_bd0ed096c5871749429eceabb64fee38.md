
## Owl
"Owl" (或 "Openwall*/Linux") 是一个基于 GNU 内核的安全增强 Linux 系统。作为核心，它是一个基于 Debian 的发行版。0.1 版本于 2001 年 5 月 11 日发布。1.0 版本于 2002 年 10 月 14 日发布。一个经过安全的发行版。来自 LWN 分发列表 http://www.ldp.org/LDP/Linux-Dictionary/index

## OpenZaurus
OpenZaurus 项目旨在为 Sharp–5000 和 Sharp–5500 构建内核和文件系统。2.9.5 版本于 2002 年 8 月 8 日发布。它是基于 Debian 的发行版，类似于 Ipaq 等嵌入式系统。OpenZaurus 3.1 候选版本于 2003 年 1 月 28 日发布。针对 PDA 的发行版。来自 LWN 字典 http://www.ldp.org/LDP/Linux-Dictionary/index

## Operating system
一种管理计算机内部功能并提供控制计算机手段的主程序。个人电脑常用的操作系统包括 Microsoft Windows 和 MacOS。来自 QUECID http://www.ldp.org/LDP/Linux-Dictionary/index

`operating system`

n. [技术]（通常缩写为 OS）在用户和运行程序之间共享计算机资源（处理器、内存、磁盘、网络带宽等）。控制系统访问以提供安全性。http://www.ldp.org/LDP/Linux-Dictionary/index

`operating system`

计算机的基础；管理任务、分配存储空间并为用户应用程序提供默认界面。操作系统提供的功能及其通用设计哲学对编程风格和周围的技术产生了深远影响。黑客传说主要由 Unix、ITS、TOPS–10、TOPS–20、WAITS、CP/M、MS–DOS 和 Multics 等操作系统所引领（特别是 ITS 和 Unix）。来自术语词典 http://www.ldp.org/LDP/Linux-Dictionary/index

操作系统 (OS)

计算机系统的主要控制软件；处理任务调度以及与外围设备的通信。安装在计算机系统上的所有应用程序都必须与操作系统通信。Linux 是操作系统的一个例子。来自 Redhat–9–词表 http://www.ldp.org/LDP/Linux-Dictionary/index

# Linux 词典

- OPIE：用于维护 OTP 密钥文件的程序。创建 OTP 密钥文件。可能没有 `libpam-opie` 无法运行。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPK：OEM 预装包（MS, Windows, OEM）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPL：开放出版许可协议 (OCL)。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPL：Organizer 组织编程语言（Psion, PDA）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `opt2ofn`：将 Omega 和 TeX 属性列表文件转换为字体量文件。来自 whatis http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPM：每分钟操作数。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPS：每秒操作数（CPU）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPS：Oracle 并行服务器（Oracle）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPSEC：安全企业连接开放平台（组织、制造商、IDS）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OPT：开放协议技术。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `opt`：选项解析共享库，是一个子程序库，用于为 C 程序提供方便的参数解析。参数从命令行传递，并提供了进一步从文件、环境变量字符串或交互式环境中读取选项的辅助功能。`opt` 包的目的是允许程序对用户和程序员都友好。该包尝试提供一个直接且功能相对齐全的接口供程序用户使用，同时尽可能减少程序员在将该包“挂载”到其软件上的工作量。它类似于 GNU（at&T 的包），但使用了更简单的不同的接口。来自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `OPTARG`：`getshort` 命令处理的最后一个参数的值。来自 Rules–Guide http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `OPTERR`：如果设置为值1，bash 将显示由 `gets` 内置命令生成的错误信息（见下文 SHELL BUILTIN COMMANDS）。每次调用 shell 或执行脚本时，`OPTERR` 均初始化为 1。来自 Users–Guide http://www.tld.org/L/Linux-Dictionary/html/index.html

- `OPTIND`：`gets` 内置命令下一个要处理的参数索引。来自 Rules–Guide http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `option`：命令行参数，通常以减号开头，会影响命令的功能——也称为标志（flag）或开关（switch）。例如，`vi` 命令上的 `-x` 选项允许 vi 编辑器读取加密文件。来自 Linux Guide @FirstLinux http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OQL：对象查询语言 (ODMG)。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- OR：发送者 / 接收者 (X.400, MOTIS)，"O/R"。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- ORAIS：人工智能系统的机遇与风险（会议, GI）。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- Orange Book（橙色书）：n. 美国政府标准文档《可信计算机系统评估标准，DOD 标准 5200-28-STD，1985年12月》，它描述了安全计算架构并定义了从 A1（最安全）到 D（最不安全）等级。现代 Unix 系统是 C2 。另见 crayola books 标题。来自 Jargon Dictionary http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- Orange Linux：Orange Linux 是一种基于软盘的 Linux 发行版，包含一套用于制作发行版的工具、一个 VGA 图形库和一个小型乒乓游戏。初始版本 1.0 于 2003年3月11日发布。一种基于软盘的发行版。来自 LWN Distribution List http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- ORB：对象请求代理器 (OMA, OMG, CORBA, ORB)。来自 VERA http://www.tld.org/LDP/Linux-Dictionary/html/index.html

- `orbit`：一个 CORBA ORB（带有 Gnome）。ORBit 是一个为 Gnome 项目设计的轻量级 CORBA ORB。（尽管关于它并没有 Gnome 的内容。）此包包含 `orbit-client`、`orbit-server`、`orbit-decoder` 等命令行工具。来自 Debian 3.0r0 http://www.tld.org/LDP/Linux-Dictionary/html/index.html
