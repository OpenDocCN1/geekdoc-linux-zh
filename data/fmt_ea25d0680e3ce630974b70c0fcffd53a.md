# 命令别名规范

```
Cmd_Alias DUMPS = /usr/sbin/dump, /usr/sbin/rdump, /usr/sbin/restore, \
= /usr/sbin/rstore, /usr/bin/mt
Cmd_Alias KILL = /usr/bin/kill
Cmd_Alias PRINTING = /usr/sbin/lpc, /usr/bin/lprm
Cmd_Alias SHUTDOWN = /usr/sbin/shutdown
Cmd_Alias HALT = /usr/sbin/halalt, /usr/sbin/fasthalt
Cmd_Alias REBOOT = /usr/sbin/reboot, /usr/sbin/fastboot
Cmd_Alias SHELLS = /usr/bin/sh, /usr/bin/csh, /usr/bin/ksh, \
= /usr/local/bin/tcsh, /usr/local/bin/zsh
Cmd_Alias SU = /usr/bin/su
Cmd_Alias VIPW = /usr/sbin/vipw, /usr/bin/passwd, /usr/bin/chsh, \
= /usr/bin/chfn
```

# 用户规范

`root` 和 `wheel` 组中的用户可以在任何机器上以任何用户身份运行任何命令

```
root    ALL = (ALL) ALL
%wheel  ALL = (ALL) ALL
```

全职系统管理员可以在任何机器上无密码运行任何命令

```
FULLTIMERS  ALL = NOPASSWD: ALL
```

兼职系统管理员可以运行任何命令，但需要密码

```
PARTTIMERS  ALL = ALL
```

`jack` 可以在 `CSNETS` 机器上运行任何命令

```
jack        CSNETS = ALL
```

`lisa` 可以在 `CUNETS`（一个 B 类网络）中的任何主机上运行任何命令

```
lisa        CUNETS = ALL
```

`operator` 可以运行维护命令以及 `/usr/oper/bin/` 中的任何内容

```
operator    ALL = DOMFS, KILL, PRINTING, SHUTDOWN, HALT, REBOOT,
            /usr/oper/bin/
```

`joe` 只能切换到 `operator`

```
joe        ALL = /usr/bin/su operator
```

`pete` 可以在 `hp snakes` 上更改 `root` 以外任何人的密码

```
pete       HPPA = /usr/bin/passwd
```

`bob` 可以在 `sparc` 和 `sgi` 机器上以任何用户身份运行任何命令

```
bob        SPARC = (OP) ALL SGI = (OP) ALL
```

`jim` 可以在 `biglab` 网络机器上运行任何命令

```
jim        biglab = ALL
```

`secretaries` 组中的用户需要管理打印机，还需要添加和删除

```
secretaries ALL = PRINTING, /usr/bin/adduser, /usr/bin/rm
```

`fred` 可以以 `oracle` 身份运行任何命令，无需密码

```
fred       ALL = (DB) NOPASSWD
```

`john` 可以切换到 `root` 以外的任何用户

```
john       ALPHA = /usr/bin
```

`jen` 可以在除 `SERVERS` 以外的所有机器上运行命令

```
jen      ALL = !SERVERS
```

`jill` 可以在 `/usr/bin/` 运行任何命令，`SHELLS` 除外

```
jill      SERVERS = /usr/bin/, !SHELLS
```

`steve` 可以在 `/usr/local/op_commands` 中运行任何命令

```
steve    CNEMETS = /usr/local/op_commands/
```

`matt` 当工作站挂起时需要杀死进程

```
matt      valkyrie = KILL
```

`WEBMASTERS` (`will`, `wendy`, and `vim`) 可以以 `user` 身份运行任何命令或直接切换到 `www`

```
WEBMASTERS  www = (www) ALL, (root) /usr/bin/suSample /etc/sudoers file #1. (continued)
```
