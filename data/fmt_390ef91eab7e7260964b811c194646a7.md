## FMT

### 名称

`fmt` - 简单的最佳文本格式化器

### 概要

`fmt` [*-WIDTH*] [*OPTION*]… [*FILE*]…

### 描述

重新格式化`FILE(s)`中的每个段落，写入标准输出。选项`-WIDTH`是`--width=DIGITS`的缩写形式。

如果没有`FILE`，或者`FILE`为`-`，则读取标准输入。

长选项的强制参数对于短选项也是强制的。

- `-c, --crown-margin`

  保留前两行的缩进

- `-p, --prefix=STRING`

  仅重新格式化以`STRING`开头的行，并将前缀重新附加到重新格式化的行

- `-s, --split-only`

  拆分长行，但不重新填充

- `-t, --tagged-paragraph`

  第一行缩进与第二行不同

- `-u, --uniform-spacing`

  单词之间一个空格，句子之后两个空格

- `-w, --width=WIDTH`

  最大行宽（默认75列）

- `-g, --goal=WIDTH`

  目标宽度（默认的93%宽度）

- `--help`

  显示此帮助并退出

- `--version`

  输出版本信息并退出

## FONTTOSFNT

### 名称

`fonttosfnt` - 将位图字体封装在sfnt (TrueType)包装器中

### 语法

`fonttosfnt [ options ] -o file.ttf [ --- ] font...`

### 描述

将位图字体或一组位图字体封装在sfnt (TrueType或OpenType)包装器中。

### 选项

- `-v`

  显示详细信息。

- `-c`

  不裁剪字形。这通常会增加文件大小，但对于小字符单元字体（终端字体），有时可能会使文件大小适度减小。

- `-b`

  写入字节对齐的字形数据。默认情况下，写入未对齐的数据，这会生成较小的文件大小。

- `-r`

  不重新编码字体。默认情况下，尽可能将字体重新编码为Unicode。

- `-g n`

  设置我们要写入的可缩放字形的类型。如果n为0，则不写入可缩放字形；这是合法的，但会让当前大多数软件感到困惑。如果n为1，则写入单个可缩放字形（未定义的字形）；这是推荐的，但会触发当前版本`FreeType`中的一个bug。如果n为2（默认值），则写入足够数量的空白字形，这在`FreeType`中可以正常工作，但会增加文件大小。

- `-m n`

  设置我们要写入的可缩放度量值的类型。如果n为0，则不写入可缩放度量值，这可能是合法也可能不合法。如果n为1，则写入单个字形的完整度量值，并为其他字形仅写入左侧边距值。如果n为2，则写入所有字形的可缩放度量值，这会增大文件大小且不推荐。默认值为1。

---

选项结束。

### 错误

某些字体级别的值，特别是下标和上标位置，是占位值。

### 另请参阅

`X(7)`, `Xserver(1)`, `Xft(3x)`。*X11中的字体*。

X.Org基金会发布的此版本`Fonttosfnt`最初由Juliusz Chroboczek <jch@freedesktop.org>为XFree86项目编写。

## FOOMATIC-COMPILEDB

### 名称

`foomatic-compiledb` - 编译Foomatic打印机/驱动程序数据库

### 语法

`foomatic-compiledb [ -t type ] [ -f ] [ -j n ] [ driver ... ]`

### 描述

`foomatic-compiledb`为所有可能的打印机/驱动程序组合生成所有PPD文件或Foomatic组合XML文件，或者仅为选定范围的驱动程序生成。通常除非想要生成一组用于分发的Foomatic数据文件，否则不需要这样做。对于配置单个打印机，`foomatic-ppdfile(1)`和特别是`foomatic-configure(1)`会自动计算它们所需的内容。

### 选项

- `-t type`

  输出文件类型，即ppd或xml。

- `-f`

  强制：即使目标目录已存在也写入其中。

- `-j n`

  n = 要运行的工作进程数

- `driver ...`

  仅为这些驱动程序生成数据文件

### 另请参阅

`foomatic-ppdfile(1)`, `foomatic-configure(1)`

### 退出状态

除非发生意外情况，`foomatic-compiledb`返回0。
