
# 术语表

## 进程标识号 Process Identification Number
分配给每个运行进程的唯一标识数字。参见`任务号`。

## 协议 Protocol
定义事务必须发生方式的标准。

## 服务器 Server
一个将文本域名转换为网络 IP 连接的计算机，配置有两个域名服务器以实现冗余。

## 开源 Open Source
由开源倡议定义的术语。与自由软件一样，开源软件必须是自由分发的，并且必须向用户提供源代码。然而，开源许可证可能会限制原始源代码，因为我们可以分发补丁或微小更改。

## 软件包 Packages
一个包含安装程序所需的各种文件的归文件。软件包可能包括软件、库、源代码，供程序通过管理程序进行安装，文档以及对于顺利安装至关重要的文件。

## 数据包嗅探者 Packet Sniper
一个用于非法目的的程序。它捕获流并尝试获取明文的用户名和密码。这些程序可以通过加密通信来击败。

## 递归匿名 Recursive Anonym
将自身作为组成部分之一的缩写。递归缩写字的命名参考了递归编程。

## 递归函数
递归调用自身的函数。递归函数的格式如下：

```
function {
  function()
}
```

## 运行控制文件 Run Control Files
决定给定程序的启动方式以及在用户面前呈现的形式。参见。

## 输出池 Spool
一个包含输入数据的指定文件，例如电子邮件或未读的新闻。

## 标准输入 Standard Input
默认输入源。通常键盘是标准输入，但某些程序可能从其他设备获取输入。标准输入也可以通过重定向运算符或管道进行更改。

## 重定向运算符 Redirection Operators
用于更改程序输入或输出目的元素。重定向包括字符`<`和`>`以及管道。

## 脚本 Scripts
为了简单编写的程序，使用`bash`等原生脚本语言或解释型语言`Perl`编写。

## Shell
参见`Command Shell`。

## Shell 账户 Shell Account
用于开启与操作系统交互会话的用户账户。

## 标准输出 Standard Output
输出数据的位置。通常显示器是标准输出，但在某些情况下，它可能是通过重定向运算符定义的另一个程序。

## 正则表达式 Regular Expression
用于在指定文件或数据中匹配一个或多个字符串的表达式。正则表达式通常使用元字符来寻找可能的匹配项。它们可以在命令行或`shell`中使用。

## 字符串 Strings
一组字母数字字符。处理以及操作系统和各种程序的许多元素都依赖字符串作为其基本数据单元。

## 救援盘 Rescue Kit
一个包含操作系统基本版本和若干个管理工具（如文本编辑器）的磁盘或 ROM。当 Unix 机器损坏到无法启动的程度时，可以使用救援盘启动机器并查找问题以便进行修复。无论你实际偏好什么文本编辑器，救援盘仅提供了至关重要的`vi`。

## 字符串变量 String Variable
一个以字符串作为其值的变量。参见`Array`（数组）。

## Shell 命令 Shell Command
`shell`传递给操作系统的命令。参见`Command Word`。

## Shell 环境 Shell Environment
用户`shell`会话的“外观和感受”。这种感受可以通过可以通过配置文件和变量进行更改。大多数系统有一组定义环境的变量，用户可以对其更改。

## 子 shell Subshell
由现有`shell`启动的`shell`进程。`shell`开启足够的时间运行特定命令，并在完成后关闭。

## Root 根用户
超级用户的用户 ID。

## 超级块 Superblock
直接指向启动块的磁盘块。超级块包含关于文件系统本身的信息、内部占用和空闲的各种块的信息。

## 路由器 Router
具有用于管理网络数据传输专用软件的计算机。某些路由器被配置为本地网络和外部网络之间的交汇点，在这种情况下，它们可能被称为网关。

## 超级用户 Superuser
最高用户。超级用户可以忽略权限限制运行机器上的任何程序或文件。超级用户可以启动或停止机器、添加用户、管理软件以及任何可能的功能。每台 Unix 机器都有超级用户，它在安装操作系统时创建。

## Shell 提示符 Shell Prompt
参见`Command Prompt`。

## 源代码 Source Code
程序员编写的程序。此代码在用户使用或在`shell`程序中使用之前必须经过编译或解释。软件可以以源代码或预编译包的形式进行下载。参见`Packages`（软件包）。

## 文本模式编辑器 Text-Mode Editor
一种使用按键组合执行各种编辑功能的文本编辑器。文本编辑器包括行编辑器和视觉编辑器。

## 系统管理员 System Administrator
运行系统并拥有超级用户访问权限的人。一个系统可能有多个访问`root`的管理员。系统管理员负责机器管理和维护。

## 时间分片 Time Slicing
一种多任务处理，操作系统为每个进程轮流提供定义的资源访问期。

## 小部件 Widgets
在为同一图形界面编写的程序中可以重用的图形元素。类似于功能窗口，通常作为被称为“小部件集”的库提供。参见`Multitasking`（多任务）和`Task Switching`（任务切换）。

## 通配符 Wildcard
用于表达式，是一种表示字符范围的元字符。

## 系统调用 System Call
利用原生内核函数而非软件库提供的函数的编程结构。

## 时间戳 Timestamp
一种文件标记，带有文件最后修改的时间，取自系统时钟。

## 窗口管理器 Window Manager
图形界面的一部分，窗口管理器控制屏幕的“外观和感受”，包括窗口的外观和位置。

## 拓扑 Topology
网络架构的映射布局。

## 压缩包 Tarball
用`tar`压缩程序创建的存档文件。参见`Archive File`（存档文件）。

## Unices
Unix 的复数形式。

## 用户界面 User Interface
参见`Interface`。

## X 窗口系统
定义必须编程和执行的图形元素的标准。任何符合标准的图形界面都可以称为 X 窗口系统。

## 任务切换 Task Switching
一种多任务处理类型，操作系统在切换系统资源到下一个进程之前完成其工作。参见`Multitasking`（多任务）和`Time Slicing`（时间分片）。

## x86 处理器 x86 Processor
一种符合的进程或芯片。Intel 规范包括 886、486 和 Pentium 芯片系列。所有个人 Unix 变体（如 Linux 和 FreeBSD）都为 x86 架构编写或移植到 x86 架构。

## 变量 Variable
在编程中使用无需知道确切值的术语。

## 详细模式 Verbose Mode
程序在运行时生成输出的模式。详细模式提供关于程序执行每一步的信息。某些程序提供多个级别的详细程度，而另一些则不提供详细模式。

## 终端窗口 Terminal Window
在图形界面内打开的窗口，提供访问系统提示符和`shell`会话的。

## gdm.conf
此文件是显示器的配置文件。它控制登录界面的外观，以及各种桌面环境的行为和外观。可以使用文本编辑器进行编辑以更改这些设置。

HaltCommand=/sbin/shutdown -h now
KillInit=true
