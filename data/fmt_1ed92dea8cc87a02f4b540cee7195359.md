# 3.1.5 确保 RDS 已禁用（自动化）

**策略适用性：**

- 级别 2 - 服务器
- 级别 2 - 工作站 (Workstation)

**描述：**

可靠数据报文协议 (RDS) 是一种传输层协议，旨在为集群节点之间提供低延迟、高带宽的通信。该协议由 Oracle 公司开发。

**原理：**

如果不使用该协议，建议不要加载内核模块，通过禁用该服务来减少潜在的攻击面。

## 审计

运行脚本验证 `/bin/env bash rds` 是否禁用：

```bash
#!/usr/bin/env bash
{
  l_output="" output2=""
  l_name="rds" # set module exists on the system
  # 检查模块是否加载
  if [ -z "$(modprobe -n -v "$l_name")" ] 2>&1 | grep -Pi "modprobe:FATAL:Module+$l_name not found in directory"; then fi
  
  # 检查模块是否会被加载
  l_loadable="$(modprobe -n -v "$l_name")"
  if [ $(wc -l "$l_loadable") -gt 1 ] && [ "$l_loadable"="$(grep -P "^install\b\$l_name\b" <<< "$l_loadable")" ]; then
    if grep -Pq 'install /bin/(true false)' <<< "$l_loadable"; then
      l_output="$l_output\n module: $l_name is not loadable";
      l_loadable=""
    else
      l_output="$l_output\n module: $l_name is loadable";
      l_loadable=""
    fi
  # 检查模块当前是否加载
  if ! lsmod "$l_name" > /dev/null 2>&1; then
    l_output="$l_output\n module: $l_name is not loaded";
    else
      l_output="$l_output\n module: $l_name is loaded";
    fi
  # 检查模块是否在拒绝列表中
    if modprobe --config -- grep -Pq "^blacklist+$l_name\b"; then
      l_output="$l_output\n module: $l_name is denied list";
      $(grep -Pl "^blacklist+$l_name\b" /etc/modprobe.d/.*)
    else
      l_output="$l_output\n module: $l_name is not denied list";
    fi
  else
    l_output="$l_output\n Module - $l_name doesn't exist on the system";
  fi
  # 报告结果。如果 l_output 中没有失败项，则通过
  if [ -z "$l_output" ]; then
    echo -e "\n- Audit Report:\nn ** PASS **\n$l_output\n";
  else
    echo -e "\n- Audit Report:\nn ** FAIL **\n- Reason(s) for audit failure:\nn$l_output\n";
    [ -n "$l_output" ] && echo -e "\n- Correct set:\n$l_output\n";
  fi
}
```

## 修复

运行以下脚本来禁用 `rds`：

```bash
#!/usr/bin/env bash
{
  l_name="rds" # module exists on the system --
  # Check if -z "$modprobe -n -v $l_name" 2>&1 | grep -Pi
  if then echo "modprobe:FATAL:Module\$l_name not found in directory"; fi
  # 修复可加载模块
    l_loadable=$($modprobe -n v "$l_name") | grep -q "$l_loadable" && l_loadable=$($grep -P "\^\($wc -z "$l_loadable") <<< "$l_loadable")
    if grep -Pq -- "install\b\$l_name\b/bin/(true)" <<< "$l_loadable"; then
      echo -e "$l_name" to be not loadable
      echo -e "install $l_name /bin/false"
    fi /etc/modprobe.d/$1.conf
# 修复已加载模块
  if lsmod | grep "$l_name >/dev/null 2>&1; then
    echo -e " unloading module \$l_name"
    modprobe -r "$l_name"
  fi
  # 修复拒绝列表
  if modprobe --showconfig | grep -Pq -- "blacklist\$l_name\b"; then
    echo -e " deny list \$l_name"
    echo -e " - blacklist \$l_name" >> /etc/modprobe.d/$1.conf
    fi
  else
    echo -e " - Nothing to remediate\n - Module \$l_name doesn't exist on the system"
  fi
}
```

## 3.2 网络参数（仅主机模式）

以下网络参数用于系统仅作为主机运行的情况。如果系统只有一个接口，或者有多个接口但不会被配置为路由器，则该系统被视为仅主机模式。

**注意：**

配置文件按照优先级顺序从 `/etc/`、`/run/`、`/usr/local/lib/` 和 `/lib/` 目录读取。文件必须具有 `.conf` 扩展名`/etc/` 中的文件会覆盖 `/run/`、`/usr/local/lib/` 和 `/lib/` 中的同名文件。`/run/` 中的文件会覆盖 `/run/` 下的同名文件。

所有配置文件无论位于哪个目录，都按按字典顺序进行排序。如果多个文件指定了相同的选项，则字典顺序最晚的文件中的条目优先优先。因此，特定文件中的配置可能会被完全替换（通过在优先级更高的目录中放置同名文件），或者单独设置可能会被更改（通过在排序靠后的不同名称文件中指定额外设置）。

软件包应将其配置文件安装在 `/usr/lib/`（发行版包）和 `/usr/local/lib/`（本地安装）。`/etc/` 中的文件留给本地管理员使用，管理员可以使用此逻辑来覆盖由供应商软件包安装的配置文件。建议所有文件名都以两位数字加连字符作为开头，以简化文件的排序。

如果管理员想要禁用供应商提供的配置文件，推荐的方法是在配置目录 `/etc/` 中放置一个指向 `/dev/null` 的符号链接，文件名与供应商配置文件保持相同。如果供应商配置文件包含在 `initrd` 镜像中，则必须重新生成镜像。

### 3.2.1 确保禁用数据包重定向发送（自动化）

**配置适用性：**

- 等级 1 - 服务器
- 等级 1 - 工作站

**描述：**

ICMP 重定向用于向其他主机发送路由信息。由于主机本身不充当路由器（在仅主机配置下），因此不需要发送重定向。

**原理：**

攻击者可以使用受侵害的主机向其他路由器设备发送无效的 ICMP 重定向，试图破坏路由，并使用户访问攻击者设置的系统而非合法的系统。

## 审计

运行以下脚本进行验证：

- `net.ipv4.conf.all.send_redirects = 0`
- `net.ipv4.conf.default.send_redirects = 0`

```bash
#!/usr/bin/env bash
{
  output=""
  output2=""
  parlist="net.ipv4.conf.all.send_redirects=0 \
           net.ipv4.conf.default.send_redirects=0"
  searchloc="/run/sysctl.d/*.conf /etc/sysctl.d/*.conf \
              /usr/local/lib/sysctl.d/*.conf /usr/lib/sysctl.d/*.conf /lib/sysctl.d/*.conf \
              /etc/sysctl.conf $(cat /etc/default/ufw) | awk -F='='*IPT_SYSCTL=/ \
              $(print $2)' /etc/default/ufw"
  KPC() {
    krp=$(sysctl "$1" | awk -F'|' '{print $2}' | xargs)
    parfile=$(grep -l "$1" * | awk -v key="$1" '\b(\.**)?$' \
              $searchloc)
    parfile=$(grep -s "^$1 " $searchloc | grep -Pv -- \
              '.*#' | awk -F: '{print $1}')
    if [ -n "$2" ]; then
      output="$output\n - '$1' is set to '$2' in running configuration"
    else
      output2="$output2\n - '$1' is set to '$krp' in the running configuration"
    fi
    if [ -n "$parfile" ]; then
      output="$output\n - '$1' is set to '$2' in incorrectly in $parfile"
    else
      output2="$output2\n - '$1 = $2' is not set in a kernel parameter configuration file"
    fi
  }
  for kpe in $parlist; do
    kpname=$(awk -F' ' '{print $1}' <<< "$kpe")
    klvalue=$(awk -F' ' '{print $2}' <<< "$kpe")
    KPC "$kpname" "$klvalue"
  done
  if [ -z "$output" ]; then
    echo -e "\n- Audit Result: ** PASS\n$output\n"
  else
    echo -e "\n- Audit Result:\n ** FAIL\n- Reason(s) for audit failure:\n$output2\n"
    [ -n "$output" ] && echo -e "\n- Correctly set:\n$output\n"
  fi
}
```
