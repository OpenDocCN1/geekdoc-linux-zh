
# Linux 词典

### `ui-properties`
允许更改 Gnome 用户界面。来自 whatis `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `uic`
包含 Qt 编译器。构建更多基于 Qt 的应用程序需要它。该二进制文件有两个版本，一个带有 KDE 组件，另一个不带。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIC`
用户识别码来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UID`
在 shell 启动时扩展为当前用户的 ID。来自 Route–Users–Guide `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UID`
查看用户识别 (`Uid`)。来自 Redhat–9–Glossary `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UID`
是所有此进程的用户 ID 号。来自 Linux Guide @FirstLinux `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UID`
标识符（密码学, EES）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIDL`
唯一 ID 列表（POP, RFC 1939）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIL`
用户界面语言来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIMS`
用户界面管理系统来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIN`
通用识别码（ICQ）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UIS`
环境信息系统（UmweltInformationSystem）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `uisp`
用于 Atmel AVR MCU 的微系统内编程器（Micro In-System Programmer），由 `ava` 汇器/链接器创建对象代码。支持系统内编程、Atmel 原型板/编程器以及极低成本的并行端口编程器。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UISRM`
用户界面系统参考模型（User Interface System Reference Model）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UKERNA`
英国教育与研究网络协会（组织，英国）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UKOLN`
英国图书馆与信息网络 way（组织）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ul`
执行下划线（underline）Whatis `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULA`
未提交逻辑阵（Uncommitted Logic Array）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULANa`
统一局域网架构（Unified Local Area Network Architecture）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULCC`
伦敦大学计算机中心（组织，英国）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ulogd`
空间日志守护进程（Spacespace Logging Daemon）是一个允许处理由 `iptables` `ULOG` 目标生成的 Netlink 数据包的守护进程。基本上，它是 `syslog` 用于数据包日志的替代品，而且功能强大得多——它将日志记录到文件、`syslog`，远程支持包含在一个独立的包中，称为 `ulogd`。相关的内核支持包含在一个补丁中——`kernel-patch-ulog`。`ulogd` 主页：`http://www.gnmonks.org/projects/ulogd` 来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ulogd-mysql`
MySQL 扩展，通过此扩展为 `ulogd` 增加了 MySQL 支持；参见 `ulogd` 的描述。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULP`
上层协议（Upper Layer Protocols (FC））来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULS`
用户位置接口（User Location Interface）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `ULSI`
超大规模集成电路（Ultra Large Scale Integration）来自 VERA `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `UltraLinux`
UltraLinux 是最早的（如果不是的话）针对 SPARC 处理器家族的 Linux，这些处理器常见于 Sun 工作站及其克隆机。它支持大多数工作站，包括旧的 32 位 SPARC 处理器和基于 64 位的 UltraSPARC 工作站。来自 LWN 列表 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

### `U`
基于 GGI 的演示工具 UltraPoint 是一个简单的基于 XML 的演示程序，旨在帮助进行即时准备。（与大多数现有工具相比，这并不意味着“该程序容易使用”）UltraPoint 不需要特殊成本（例如对象的位置）。

特性：
- 使用 GGI（图形接口）绘图。
- 使用 VFlib 3.6 字体列表。
- 使用 ImageMagick 整理幻灯片。

来自 Debian 3.0r0 APT `http://www.tdp.org/LDP/Linux-Dictionary/html/html`

### `ULV`

### `UMA`

### `UMA`

### `UMA`

### `UMADS`
