
文件权限 `666` 赋予用户、组和其他人读写权限。目录权限 `777` 赋予用户、组和其他人读、写和执行权限。`umask` 分配的值会从这些值中减去。要确定你想要设置的 `umask` 值，请从 `666`（文件）或 `777`（目录）中减去你想要的权限值。剩余数即为用于 `umask` 命令的值。例如，假设你想将文件的默认模式更改为 `644` (`rw-r--r--`)。差异是 `022`，将其作为 `umask` 命令的参数。

设置 `umask` 值拒绝权限的方式与 `chmod` 命令赋予组权限的方式相同。例如，`chmod 022` 命令赋予组和其他人写权限，而 `umask 022` 则拒绝组和其他人的写权限。

# `/usr/bin/umask`
`umask` 命令将当前 shell 执行环境的文件模式创建设置为由掩码操作数指定的值。此掩码影响随后创建的文件的权限位位初始值。如果在子 shell 或单独的命令执行环境中调用 `umask`，如下所示任一情况：

```
(umask 002)
nohup umask ...
find -exec umask ...
```

它不会影响调用者环境的文件模式创建。由于此原因，你无法使用 `/usr/bin/umask` 来更改正在进行的会话中的 `umask`。它的有用性仅限于检查调用者的 `umask`。要更改正在会话的 `umask`，请使用内置命令之一。

如果你不指定掩码操作数，`umask` 命令将向标准输出显示调用的文件创建掩码的值。

## 选项
- `-S` 以符号形式指定掩码。
- 输出以符号格式显示，如下例所示。

```
castle% /usr/bin/umask -S
ruwx, g=rx, o=rx
cast%
```

字母的存在表示该位在文件创建掩码中是清除的。之前的符号语法等于八进制 `umask 022`。

```
castle% /usr/bin/umask
022
castle%
```

## 输出
当你不指定掩码参数时，`umask` 命令向标准输出写入一条信息，可以作为 `umask` 操作数。

如果你指定 `-S` `/usr/bin/umask`，输出将以符号格式显示，如下所示。

```
castle% /usr/bin/umask -S
ruwx, g=rx, o=rx
$
```

三个值是 `r`, `w`, `x` 集的组合；字母的存在表示该位在文件创建掩码中是清除的。之前的符号语法等于八进制 `umask 022`。

```
castle% /usr/bin/umask
022
castle%
```

## 示例
以下命令之一设置掩码，使得随后创建的文件清除 `S_IWOTH` 位。

```
umask a=rx, ug+w
umask 002
```

在使用上述任命令设置掩码后，你可以使用 `umask` 命令显示掩码的当前值。

```
castle% ksh
$ umask 002
$ umask
02
$ umask -S
u=wx, g=rx, o=rx
$
```

> 注意 — 输出格式未知，但历史实现使用八进制模式格式。

你随后这些这些输出之一作为后续调用 `umask` 命令的操作数。
假设掩码已如上设置，以下命令设置掩码，使得随后创建的文件清除 `S_IWGRP` 和 `S_IWOTH` 位。

```
$ umask g-w
$ umask
022
$
```

# `uname` — 输出当前系统名称

### 概要

```
/usr/bin/uname [-aimnprsvX]
/usr/bin/uname [-S system-name]
```

## 描述

`uname` 命令在标准输出上打印有关当前系统的信息。
默认情况下，不带选项的 `uname` 命令仅显示当前操作系统的名称，如下例所示。

```
castle% uname
SunOS
castle%
```
