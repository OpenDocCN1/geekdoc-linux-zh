# 为什么路由表查找使用 LPM 算法？

IP 按以下顺序在路由表中查找目标路由：

- 查找的主机地址（IP 地址）
- 查找网络地址
- 查找默认条目（0 网络地址）

匹配的主机地址（主机 IP 地址）始终在匹配网络地址之前。如果主机地址和网络地址都未匹配，我们使用默认条目（默认路由），它是路由表中定义的 ID 为 0 的网络地址。
