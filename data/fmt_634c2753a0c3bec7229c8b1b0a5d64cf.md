# 5.5 循环

在计算机编程中，循环帮助我们处理需要运行直到某些标准（迭代）耗尽的重复性任务。在 Bash 中，两种主要的循环命令是 `for` 和 `while`。

## 5.5.1 For 循环

`for` 循环将取列表中的每个项，将该项赋值为变量的值，执行 `do` 和 `done` 之间的动作，然后返回顶部获取列表中的下一个项，并重复这些步骤，直到列表耗尽。

```bash
for var-name in <list>; do
    <action to perform>
done
```

这种类型的循环有很大的潜力。虽然它非常有用，但我们可以使用循环通过 `nmap`¹²⁸ 运行端口扫描¹²⁷（我们将在另一个模块中详细讨论它）。我们也可以尝试使用 `ping` 命令来查看任何 IP 地址是否有响应。

让我们来看一个更具实操性的示例，它将快速打印出 `10.11.1.0/24` 子网¹²³ 中的前 10 个 IP 地址：

```bash
kali@kali:~$ for ip in $(seq 10); do echo 10.11.1.$ip; done

10.11.1.2
10.11.1.3
10.11.1.4
10.11.1.5
10.11.1.6
10.11.1.7

10.11.1.9
10.11.1.10
```

在这一行 Bash 单行命令（列表 158）中，我们使用 `seq` 命令来打印一组数字，在本例中是从一到十。每个数字被赋值给变量 `ip`，随着 `for` 循环的多次运行，每个 IP 地址都会显示在屏幕上，并在序列结束时退出。

## 5.7 从函数返回返回值

除了向 Bash 函数传递参数外，我们当然也可以从 Bash 函数返回返回值。Bash 函数实际上并不允许返回任意值。

列表 167 - 在 Bash 中从函数返回返回值

```bash
kali@kali:~$ cat fncrvalue.sh

  echo 'Oh hello there, I\'m returning a random value!'
  return $RANDOM

```

```bash
kali@kali:~$ chmod +x ./fncrvalue.sh

```

注意到每次运行脚本时都会返回一个随机数，这是因为我们返回了特殊的全局变量 `$RANDOM`（存入 `$?` 中）。如果我们使用带有 `$RANDOM` 参数的 `return` 语句，那么返回的将是函数的退出状态（在这种情况下为 0）。

现在我们已经对变量和函数有了基本的了解，可以深入探讨并讨论变量的作用范围。变量的作用范围简单来说就是其具有意义的语境。默认情况下，变量具有全局作用范围，这意味着可以在整个脚本中进行访问。相比之下，局部变量只能在定义它的函数、代码块或 shell 中被看到。我们可以通过在声明之前加上 `local` 关键字来“覆盖”一个全局变量，赋予它一个局部语境，同时保持全局变量不变。其通用语法如下：

```bash
local name=""
```

列表 168 - 声明一个局部变量

让我们通过一个简单的例子（变量作用范围）来查看局部变量和全局变量在实际操作中是如何工作的：

```bash
kali@kali:~$ cat ./varscope.sh
#!/bin/bash
# var scope example

name="John"
name2="Jason"

change() {
    local name="Edward"
    echo "Inside of this function, name=$name and name2=$name2"
}

echo "Before the function call, name=$name and name2=$name2"
change
name2="Lucas"
echo "After the function call, name=$name and name2=$name2"
```

```bash
kali@kali:~$ ./varscope.sh
Before the function call, name=John and name2=Jason
Inside of this function, name=Edward and name2=Jason
After the function call, name=John and name2=Lucas
```

列表 169 - 在 Bash 中演示变量作用范围

让我们突出列表 169 中的几点。首先，我们声明了两个全局变量，将 `name` 设置为 John，`name2` 设置为 Jason。

然后，我们定义了一个函数，并在函数内部声明了一个名为 `name` 的局部变量，将其赋值为 Edward。由于这是一个局部变量，之前的全局赋值没有受到影响；在函数外部，`name` 仍然是 John。

接下来，我们将 `name2` 设置为 Lucas，由于我们没有使用 `local` 关键字，因此我们正在修改全局变量，该赋值在函数内部外部都有效。

根据这个例子，以下点总结了变量的作用范围：

- 修改与全局变量同名的局部变量的值不会影响其全局值。
- 在函数内部修改全局变量的值（在没有声明同名局部变量的情况下）——会影响其全局值。
