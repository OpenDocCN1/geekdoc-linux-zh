- `util-proc`: Logging for Util Proc

## 配置 Syslog 服务器

`logging level` 命令定义了 ArubaOS 在本地生成的日志。如本章较早所述，您可以配置一个或多个 syslog 服务器，将日志自动从 Aruba 控制器移动到另一台服务器上。在配置 syslog 时，可以选择使用控制器的本地日志设置，或为给定的 syslog 服务器配置特定设置。例如，控制器的本地日志级别可以设置为默认值，而 syslog 服务器设置可以针对用户日志更激进，例如启用所有子类的调试。这样，本地日志包含较少的日志条目，而 syslog 服务器可以包含更广泛的日志条目。

在 Aruba 控制器上指定 syslog 服务器是一个简单的过程，最多需要四项信息：

- syslog 服务器的 IP 地址
- 类型（`Type`）
- 严重性（`Severity`）
- 设施（`Facility`）

将 syslog 服务器设置视为对生成的日志进行过滤和转发的过程。`logging level` 命令定义了控制器生成的日志。syslog 进程随后获取生成的日志，任何符合 syslog 设置的日志都会由 syslog 进程将这些日志转发到 syslog 服务器。作为 `logging` 命令的一部分指定的 syslog 服务器的四个参数将在本节中解释。

### Syslog 服务器的 IP 地址

Syslog 服务器的 IP 地址仅告诉控制器向何处发送日志消息，它是指定 syslog 服务器时的最少要求参数。如果需要，可以为控制器配置多个 syslog 服务器。以下 CLI 命令定义 192.168.240.31 为外部 syslog 服务器：

```
(config) #logging 192.168.240.31
```

### Type（默认值：`all`）

如果不是向 syslog 服务器发送所有日志消息，`type` 可以指定发送的日志类型。如果未指定 `type`，默认值为 `all`。您可以指定如下所示的不同类型：

- `ap-debug`
- `arm`
- `arm-debug`
- `network`
- `security`
- `system`
- `wireless`

为不同的 IP 地址指定不同的类型，从而将一种日志类型发送到一个 syslog 服务器，将其发送到另一处。以下 CLI 输出显示了两个服务器，将网络日志发送到一个，安全日志发送到另一个。该命令显示日志配置。

```
(config) #logging 192.168.240.31 type network
(config) #logging 192.168.240.32 type security
```

### Severity（默认值：`all`）

向 syslog 服务器发送的日志输出可以通过指定日志的严重性级别进一步精炼。`severity` 定义为从紧急到调试的八个级别。如果未指定 `severity`，默认值为 `all`。可以配合 IP 地址指定 `severity`，允许发送特定级别的日志到 syslog 服务器。以下 CLI 输出显示了两个服务器。严重性为错误的网络日志发送到一个 syslog 服务器，严重性为错误的安全日志发送到另一处。

```
(config) #logging 192.168.240.31 severity errors
(config) #logging 192.168.240.32 severity errors
```

### Facility（默认值：`local1`）

当控制器将日志消息转发到 syslog 服务器时，它用 `facility` 值标记每条消息。`facility` 可以是 `local0` 到 `local7` 之间的值。如果未指定 `facility` 值，默认值为 `local1`。`facility` 值仅是 syslog 服务器用于识别不同日志流的标签。每个值都没有内在含义。syslog 服务器可以使用这些不同的 `facility` 值分离来自不同源的日志并存储在不同的日志文件中。

ArubaOS 允许为发送到 syslog 服务器的所有日志指定不同的 `facility` 值。以下 CLI 命令将 syslog `facility` 从默认值 `local1` 更改为 `local5`。执行此命令后，每条日志都将带有 `facility5` 标签发送到 syslog 服务器。

```
(config) #logging 192.168.240.31 facility local5
```

以下 CLI 输出显示了两个服务器。网络日志被发送到 `facility` 值为 `local6` 的 syslog 服务器，安全日志被发送到 `facility` 值为 `local7` 的另一个 syslog 服务器。服务器配置如下：

```
(config)#logging 192.168.240.41 type network severity errors facility local6
(config)#logging 192.168.240.42 type security severity errors facility local7
(config)#show logging server

Remote Server: 192.168.240.41

FACILITY 映射表

| local-facility | severity | remote-facility |
| :--- | :--- | :--- |
| network | errors | local6 |

Remote Server: 192.168.240.42

FACILITY 映射表

| local-facility | severity | remote-facility |
| :--- | :--- | :--- |
| security | errors | local7 |
```

你还可以将多个日志发送到同一个 syslog 服务器上。要实现这一点，你只需要发布两条 `logging` 命令，指向同一台服务器并使用不同的日志参数，如下 CLI 输出所示：

```
(config) #logging 192.168.240.41 type network facility local6
(config) #logging 192.168.240.41 type security facility local7
(config) #show logging server

Remote Server: 192.168.240.41

FACILITY 映射表

| local-facility | severity | remote-facility |
| :--- | :--- | :--- |
| network | All | local6 |
| security | All | local7 |
```

如你所见，`logging` 命令提供了多种选项，用于自定义发送到一个或多个 syslog 服务器的日志。也可以使用 WebUI 配置 syslog 服务器，如图 13-2 所示。此菜单路径将带你进入可以定义 syslog 服务器的菜单：

**Configuration（配置）** ⇒ **MANAGEMENT（管理）** ⇒ **Logging（日志）** ⇒ **Servers（服务器）**
