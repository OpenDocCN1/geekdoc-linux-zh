
## Task 2

现在运行：

```
sudo chown root foo
ls -la foo
cat foo/bar
```

你刚刚将用户所有权更改为`root`，同时保留了组所有权。由于目录具有组读和世界读权限，你仍然可以查看其内容。

## Task 3

现在运行：

```
sudo chmod o-r foo
ls -la foo
cat foo/bar
```

该`chmod`命令移除了`foo`的读权限。然而，由于你仍然拥有组所有权，你仍然可以查看文件的内容。

## Task 4

现在运行：

```
sudo chgrp root foo
ls -la foo
ls -ld foo
cat foo/bar
```

你现在已经为自己设置了在`foo`目录上仅有的执行权限，这是一个有趣的场景。你不再拥有查看目录内容或向其添加新文件的权限……但是，如果你已经知道某个文件存在，你对该文件的权限仍然允许你对其进行操作。在这个例子中，你可以查看`foo/bar`的内容，甚至可以修改它们！这也适用于`foo`下的任何子目录。
