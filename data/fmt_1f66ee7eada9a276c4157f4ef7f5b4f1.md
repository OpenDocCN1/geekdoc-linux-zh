
# The Project Revision Control System PRCS

The Project Revision Control System `PRCS`, the Project Revision Control System, is the front end to a set of tools that (like `CVS`) provide a way to deal with files and directories as an entity, preserving coherence of the entire set. Its purpose is similar to that of `SCCS`, `RCS`, and `CVS`, but (according to its authors, least) much simpler than any of those systems. `Emacs-List` is supported in a separate package, `prcs-el`. Another package called `prcs-sync` contains a tool to synchronize `PRCS` projects across repositories, both locally and remotely. For further information at `http://prcs.sourceforge.net` From Debian 3.0r0

`http://www.tdlp.org/LDP/Linux-Dictionary/html.html`

## prcs-el

Elisp support for the Project Revision Control System package contains Emacs-List add-on for `PRCS`, the Project Revision Control System. It provides a useful interface for some `PRCS` commands (`check`, `diff`, `into`, and `redo`) when editing project files (`prjt`). `prcs-el` is distributed from the `prcs` package because it depends on Emacs (or another "emacs"). From Debian 3.0r0

`http://www.tld.org/LDP/Linux-Dictionary/html.html`

## prcs-sync

Synchronize `PRCS` projects between repositories The `prcs-sync` script tries to synchronize two `PRCS` (Project Revision Control System) repositories. It requires a "remote" repository, which is assumed to have recent changes, vs a "local" repository which is out of date. From Debian 3.0r0

`http://www.tdlp.org/LDP/Linux-Dictionary/html.html`

## predict

Satellite Tracking with Optional Output This is a satellite tracking program. It is mostly of interest to amateur satellites, but optionally announcing azimuth and elevation to help in manual observation of satellites. General concepts provide the ability to combine graphics with precision, earth must be used to install; it sets the "looks" for geostationary satellites based on their longitude, `predict`'s data for geospatial front-end predicting use. It is not included in the Debian package because it requires non-free library. 32-bit but not 16-bit.

## preemptive multitasking

In an operating system, means of running more than one program at a time. In preemptive multitasking, the operating system decides which application should receive the user's attention. In contrast to cooperative multitasking, in a busy application could monopolize the processor for several minutes, a computer with preemptive multitasking system seems much more responsive to commands. Windows 95 employs preemptive applications.

## preferences

`Preferences.app` is functionally a clone of NeXT/OPENSTEP tool of same name. Like the original program, it's a simple application for setting preferences for the system, with a friendly interface. The program is simple, but powerful — can create new modules, "bundles", that add new things to the program that its original developers did or even them do not require recompiling the main program. ## premail

An email privacy provides support for encrypted e-mail to your mailer, using plain `PGP`, `PGP/MIME`, `MOSS`, or `SIME`. In addition, `premail` provides a seamless, transparent interface to the anonymous releayers, with full support for `Mixmaster` releayers. `Nmymasters` provides crypto, fully anonymous accounts for both sending and receiving e-mail.
