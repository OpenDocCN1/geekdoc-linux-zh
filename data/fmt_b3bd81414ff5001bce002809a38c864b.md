# tset, reset — 建立或恢复终端特性

### Synopsis

```
/usr/ucb/tset [-InQrs] [-ec] [-m [port -ID [baudrate] type...] [type]]

/usr/ucb/reset [-] [-ec] [-kc] [-n] [-Q] [-r] [-s] [-m [indent test baudrate]]
```

## Description

`tset` 命令用于设置你的终端，通常在你首次登录时进行。它处理依赖于终端的处理，如删除和杀死字符、设置或重置延迟、发送任何正确初始化终端所需的序列等。`tset` 首先确定终端类型，然后进行初始化和模式设置。如果端口没有永久连接到特定终端（不是硬连线），则会为其分配一个通用标识符，如 `dialup`。

`reset` 通过关闭 `CBREAK` 和 `RAW` 模式、输出延迟和奇偶校验来清除终端；开启换行翻译、回显和 Tab 扩展；将未定义的特殊字符恢复到默认状态。然后它按照通常在终端类型上的设置模式（这可能会撤销上述某些设置）。更多信息参见 `stty(1)`。你可以将所有参数用于 `tset` 配合 `reset` 使用。`reset` 还使用 `rs` 和 `rf=` 来重置初始化字符串和文件。此功能在程序崩溃并让终端处于特殊状态后非常有用。通常在这种情况下，输入字符时字符不会回显。你可能需要输入换行符，因为 `reset` 可能不会返回。

当你不指定参数时，`tset` 从 `TERM` 环境变量中读取终端类型，重新初始化终端并在登录时执行模式、环境和其他选项的初始化。

当你在脚本命令中使用 `tset` 时（`sh(1)` 用户使用 `.profile` 或 `csh(1)` 用户使用 `.login`），最好为在非硬线端口上通常使用的终端类型提供信息。`/etc/termcap` 文件中给出的任何备用名称都是可能的标识符。更多信息参见 `-m` 选项。如果没有映射适用且你在命令行上指定了一个不以 `-m` 为头的最终类型选项，则使用该类型。

通常有必要将 `tset` 最终确定的终端类型以及终端能力的信息重置到 shell 的环境中。你可以通过 `-`、`-s` 或 `-S` 选项来实现。

## 1384

对于 Bourne shell，请在你的 `.profile` 文件中放入以下命令：
```
eval `tset -s options...`
```

对于 C shell，请在你的 `.login` 文件中放入以下命令：
```
set noglob

eval `tset -s options...`

unset noglob
```

对于 C shell，在 `.cshrc` 文件中包含以下别名（alias）也非常方便：
```
alias ts 'eval tset -s !*'
```

此别名还允许在终端和环境中随时调用以下命令：
```
ts 2621
```

你无法通过 Bourne shell 脚本获得这种别名效果，因为 shell 脚本无法设置父进程的环境。如果一个进程可以设置其父进程的环境，根本就不需要这些复杂的操作。一旦确定了终端类型，`tset` 就会设置终端驱动模式。这个过程通常涉及向终端发送初始化序列，设置单字符删除（以及可选的行删除（即全行扩展）字符，并设置特殊字符延迟。在传输终端初始化序列期间，制表符和换行符会被关闭。
在可以退格但不能覆盖打印的终端（如 CRT 屏幕）上，当删除字符为 `#` 时，删除字符会发生变化，就就像你使用了 `-e` 参数一样。

## 注意事项

`tset` 命令是你开始使用 UNIX 系统时必须掌握的早期命令之一。遗憾的是，它是最复杂的命令之一，这在很大程度上是因为你为了设置登录 shell 的环境必须付出的额外精力。需要采取一些措施来让这一切变得简单：要么由登录程序完成设置，要么创建一个默认的 shell 别名，或者存在一种设置父进程环境的方法。
该程序无法直觉用户对删除、中断和行删除字符的个人偏好，因此它将这些设置为本地系统标准。
可以认为，shell 应该负责确保终端处于正常状态；这将消除对 `reset` 程序的需求。

## 选项

- `-` 在标准输出上输出目标终端的名称。此信息旨在由 shell 捕获并放入 `TERM` 环境变量中。

- `-ec` 将所有终端的删除字符设置为指定的字符 `c`。默认是键盘上的退格键，通常为 `^H` (Control-H)。你可以直接输入字符 `c`，也可以使用所用的脱波符表示法进行输入。

- `-ic` 将所有终端的中断字符设置为指定的字符 `c`。默认是 `^C` (Control-C)。你可以直接输入字符 `c`，也可以使用所用的脱波符表示法进行输入。

- `-I` 抑制传输初始化字符串。

- `-kc` 将所有终端的行删除传输字符设置为指定的字符 `c`。默认是 `^U` (Control-U)。如果不指定 `-k`，删除字符保持不变。你可以通过在字母前加脱波符（如 `Control-I`）来指定控制字符，而不是直接输入控制键。这种语法允许你指定当前已分配的控制键。

- `-m [port-ID [baudrate]: type]...` 当连接到由 `port-ID` 标识的通用端口（如拨号上网或配线板）时，指定（映射）终端类型。你可以使用 `baudrate` 参数检查端口的波特率并据此设置终端类型。目标速率由以下运算符的任意组合固定，以指定进行映射的条件。

  - `>` 大于。
  - `=` 等于或。
  - `<` 小于。
  - `!` 并非。（否定上述运算符）。
  - `?` 提示终端类型。如果没有给出响应，则默认选择 `type` 类型。

在接下来的示例中，如果端口是速度大于 300 的拨号端口，则终端类型设置为 `adm3`；如果端口是波特率在 300 或更低的拨号端口，则设置为 `dw2`。在第三种情况下，终端类型前的问号表示你需要核实所预期的内容。空响应表示名称类型正确。否则，你的响应将被视为所需的类型。

```
tset -m 'dialup:300:adm3a' -m
dialup:dw2' -m
plugboard?adm3a'
```

为了防止被解释为元字符

- `-n` 指定为终端初始化新的 tty 驱动模式。除非 `tty` 是默认设置，否则此选项可能无效。

- `-Q` 抑制向消息中打印删除集（Erase set）和杀死集（Kill set）。

- `-r` 除了其他外，报告终端类型。

- `-s` 输出设置并导出 `TERM` 的命令。此选项可以配合使用：

```
set noglob

eval `tset -s...`

un noglob
```

将终端信息引入环境。这样做可以让 `vi(1)` 等程序启动得更快。如果 `SHELL` 环境变量以 `csh` 结尾，则输出 C shell 命令；否则输出 Bourne shell 命令。
