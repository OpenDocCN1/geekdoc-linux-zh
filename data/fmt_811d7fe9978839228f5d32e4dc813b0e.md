## 3. 特殊字符

```bash
echo "A comment will follow." # 这里有一条注释。
# 注意 # 前面的空格
# 注释也可以出现在行首空格之后。
```

```bash
## 此注释之前有一个制表符。
## 注释甚至可以嵌入管道符中。
```

```bash
initial={ cat "startfile" | sed -e '#/d' | tr -d '\n' | \
## 删除包含 '#' 字符的行。
sed -e 's/\_/\_/g' 
## 摘自 life.sh 脚本
```

> 注释不能在同一行内跟在另一个注释后面。没有方法可以终止注释以便在同一行开始执行“活动代码”。请使用新行执行下一个命令。

> 此外，`echo` 语句中引用或转义的 `#` 不会开始注释。同样，它出现在参数替换构造结构和数值表达式中。

```bash
echo "The # here does not begin a comment."
echo 'The # here does not begin a comment.'
echo "The \# here does not begin a comment."
echo "The # here begins a comment."
```

```bash
echo ${PATH}: # 参数替换，不是注释。
echo $(( 2#101011 )) # 进制转换，不是注释。
```

### 命令分隔符 [分号]

它允许在同一行上运行两个或多个命令。

```bash

```

```bash
if [ -x "$filename" ]; then
## 注意分号后面的空格。
  echo "文件 $filename 存在."; cp $filename.bak
else
  echo "文件 $filename 未找到."; touch $filename
fi
echo "文件测试完成。"
```

### “点”，作为文件名的一部分

在处理文件名时，开头的点是“隐藏”文件的前缀，这种文件通常不会被正常显示。

```bash
bash$ ls .hidden-file
bash$ ls -l
total 10
-rw-r---- 1 bozo bozo 4034 Jul 18 22:04 datal.addressbook
-rw-r---- 1 bozo bozo 4662 May 25 13:58 datal.addressbook.bak
-rw-r---- 1 bozo bozo 877 Dec 17 2000 employment.addressbook

bash$ ls -al
total 14
drwxrxr-x 2 bozo bozo 1024 Aug 29 20:51 ./
drwx------ 52 bozo bozo 3072 Aug 29 20:51 ../
-rw-r---- 1 bozo bozo 4034 Jul 18 22:04 datal.addressbook
-rw-r---- 1 bozo bozo 4662 May 25 13:58 datal.addressbook.bak
-rw-r---- 1 bozo bozo 877 Dec 17 2000 employment.addressbook
-rw-rw-r 1 bozo bozo 0 Aug 29 20:54 .hidden-file
```

在考虑目录名称时，单点 (`.`) 表示当前工作目录，双点 (`..`) 表示父目录。

```bash
bash$ pwd
/home/bozo/projects

bash$ cd
bash$ pwd
/home/bozo/projects

bash$ cd
bash$pwd
/home/bozo/bozo/
```

点经常出现在文件移动命令的目标位置（目录），在此语境下意味着当前目录。

```bash
bash$ cp /home/bozo/current_work/junk/*
```

将所有“junk”文件复制到 `$PWD`

### “点”字符匹配

在匹配字符时，作为正则表达式的一部分，“点”匹配单个字符。

### 部分引用 [双引号]

`"STRING"` 保留了（免受解释影响）`STRING` 内部的大多数特殊字符。参见第 5 章。

### 全量引用 [单引号]

`'STRING'` 保留了 `STRING` 内部的所有特殊字符。这是对 `"STRING"` 更强力的引用形式。参见第 5 章。

### 逗号运算符

逗号运算符 [16] 连接了一系列算术操作。会被求值，但只返回最后一个结果。

```bash
let t2 = ((a = 9, 15 / 3))
## 设置 "a = 9" 且 "t2 = 15" 拼接字符串。
```

```bash
for file in /(usr/bin)/*calc
#   查找所有以 "calc" 结尾的可执行文件
#   在 /bin 和 /usr/bin/ 目录中。
do
  if [ -x "$file" ]
    then
      echo $file
  fi

# /bin/ipcalc
# /usr/bin/xcalc
# /usr/bin/oidcalc
# /usr/bin/oocalc
```

### 转义 [反斜杠]

一种字符的引用机制。

`\X` 转义字符 `X`。这具有对 `X` 进行“引用”的效果，等同于 `'X'`。`\` 可用于转义 `"` 和 `'`，以便它们以字面形式表示。

参见第 5 章关于转义字符的深入解释。
