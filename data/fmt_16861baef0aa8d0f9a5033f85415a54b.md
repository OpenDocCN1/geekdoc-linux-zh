## 电子邮件

电子邮件是广泛使用的业务通信手段之一。它能够提供几乎即时的通信方式，且不受时间限制，因此消息可以在工作时间之外发送，发送者可以确信消息会在收件者返回工作时到达并在那里等待。它还可以提供一种传输文档的高成本效益的方法，因此它是你在桌面电脑上最依赖的应用程序之一。企业在迁移到 Linux 时面临的最困难的问题之一是对新技术的采纳。Microsoft Outlook 与 Microsoft Exchange 服务器紧密结合，已成为业务主要的消息和个人信息管理器。你可能无法打破这种依赖，如果无法，你可能希望查看有关如何将原生 Windows 应用迁移到 Linux 的讨论。否则，你可以找到一些优秀的原生 Linux 应用。

### 病毒防护

在新闻中，这些病毒造成了数百万美元的损失。然而，仅仅因为你正在运行 Linux 桌面系统，并不意味着你在处理邮件附件及其隐藏载荷时应该掉以轻心。事实是，Linux 病毒的效益远不如 Windows 病毒，因为 Linux 桌面用户处于少数群体。这些恶意程序的作者在规模小得多的 Linux 桌面上传播病毒，所获得的知名度也较低；由于病毒已经流传出去，你只是没在报纸上听说过它们。此外，如果你运行 Linux 桌面系统，你可能只是病毒的无意载体；因为你对利用 VB 脚本或 ActiveX 的病毒具有免疫力，你可能只是将它传递给在 Windows PC 上阅读邮件的同事。在转发最新的笑话或任何其他文档时，采取预防措施是非常重要的。

## 基于 Web 的邮件客户端

由于你正在逐渐迁移到 Linux，你可能仍然在两个操作系统之间工作。在过渡期间，在其中一个系统上下载并存储邮件而在另一个系统上操作可能不是你的最佳选择，或者你可能已经决定将电子邮件存储在具有计划备份的服务器上。这种方法非常有优势，因为你可以从许多平台上的任何 Web 浏览器访问你的电子邮件。此外，它符合中心化管理应用程序和数据的趋势。通过将数据保留在服务器而不是桌面 PC 上，你可以在整个组织中一致地管理数据，在服务器上应用垃圾邮件过滤和病毒检查，而不是在每个用户的桌面上。这种方法通常比每个用户单独进行要高效得多。这就是为什么提供服务器端管理和存储的解决方案（如 IMAP，互联网消息访问协议）是有价值的；它们允许你像访问本地邮件一样访问消息，但需要网络连接。如今有许多解决方案可以实现这一目标，如果你使用 POP 或 IMAP 服务器，可以使用 Squirrel、Neomail 或功能完备的 Horde 项目。底线是，减少 PC 桌面的复杂性可以更容易选择你想要的平台，避免供应商锁定，并提高你选择如何实现桌面计算目标的能力。

## Scalix 社区版

Scalix 社区版是一个基于服务器的 Linux 电子邮件和日历管理平台，由 Scalix 公司赞助，该公司拥有 HP OpenMail 的授权许可（OpenMail 是一个健壮的电子邮件平台）。Scalix 提供商业产品，但社区版免费提供，并可以升级到企业版。Scalix 软件是一个可以托管在 Linux 服务器上的产品，并为 Linux 和 Windows Outlook 客户端提供透明的电子邮件功能。对于 Linux 用户来说，Scalix 的优势在于其丰富的 Web 邮件客户端提供了一个与 Microsoft Outlook 三栏界面相似的界面。它还属于纯服务器管理办公的策略，系统管理员可以对每个人的电子邮件进行全面备份，并将客户端的更改减少到最低。

## Linux 桌面办公套件

OpenOffice.org 是 Microsoft Office 套件的替代方案，包含五个核心工具：Writer（文字处理）、Calc（表格）、Impress（演示）、Draw（绘图）和 Base（数据库）。它们分别是文字处理器、电子表格、演示工具、绘图程序和数据库。该套件的设计使得所有应用程序具有相似的外观和感受。OpenOffice.org 套件是 Linux 上流行的办公套件，并包含在每个主要的 Linux 发行版中。OpenOffice 套件默认以 OpenDocument 格式保存文件，这是一种国际 XML 文档标准。开放标准的方法更容易被程序处理，因为它有完善的文档，可以在不使用专用函数的情况下进行开发，并允许他人设计可以读取这些开放标准类型文档的程序。
