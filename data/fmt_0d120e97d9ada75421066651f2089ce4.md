# diff3 — 三路差异文件比较

### 概要

`/usr/bin/diff3 [-eEX3] filename1 filename2 filename3`

## 描述

`diff3` 比较文件的三个版本，并用以下代码标记不不同的文本范围：

```
==== 所有文件均不同。
====1 filename1 不同。
====2 filename2 不同。
====3 filename3 不同。
```

在将给定文件的某个范围转换为某些其他内容时，更改的类型通过以下方式之一进行指示：

`f : n1` 文本将追加在文件 `f` 的第 `n1` 行之后，其中 `f = 1, 2, 或 3`。

`f : n1, n2 c` 在范围 `n1` 到第 `n2` 行之间更改文本。如果 `n1 = n2`，则范围可以缩写为 `n1`。

范围的原始内容紧随在 `c`（更改）指示之后。当两个文件的内容相同时，则会抑制编号较小文件的内容。

以下命令将生成的脚本应用于 `filename1`。

```
(cat script; echo '$1,$sp') | ed - filename1
```

> 注意 — 由单个点 ( `.` ) 组成的文本行会使 `-e` 失效。大于 64 Kbytes 文件无法工作。

## 选项

+ `-e` 为编辑器 `ed(1)` 生成一个脚本，将 `filename2` 和 `filename3` 之间所有的更改合并到 `filename1` 中，即通常会被被标记为 `========` 的更改。
+ `-x` 生成一个仅包含标记为 `========` 的更改的脚本
+ `-3` 生成一个仅包含标记为 `=======` 的更改的脚本
+ `-E` 生成一个包含 `filename2` 和 `filename3` 之间所有更改的脚本，但对重叠更改（即在普通列表中标记为 `====` 的更改）进行不同的处理。两个文件的重叠行将由脚本插入，并用 `<<< >>>` 行括起来。
+ `-X` 生成一个仅包含标记为 `====` 的更改的脚本，但以 `-E` 选项的方式这些更改。

# diffmk — 标记 troff 输入文件版本间的差异

### 概要
`/usr/bin/diffmk oldfile newfile markedfile`

描述
`diffmk` 比较文件的两个版本并创建一个第三个版本，该版本包含用于 `nroff(1)` 和 `troff(1)` 的“更改标记”(`.mc`) 命令，`oldfile` 和 `newfile` 是文件的旧版本和新版本。`diffmk` 生成 `markedfile`，其中包含 `newfile` 的文本，并在 `newfile` 与 `oldfile` 不同之处插入了 `troff(1)` “更改标记”请求。`markedfile` 中格式化、已更改或插入的文本在每行的右侧边缘显示为 `|`。被删除文本的位置由单个 `*` 显示。

## 使用
关于遇到大于或等于 2 Gbytes (`**231 bytes`) 文件时 `diffmk` 的行为，请参见 `largefile(5)`。

## 示例
你也可以结合适当的 `troff` 请求使用 `diffmk` 来生成带有标记更改的列表。在命令行中：
`castle@ diffmk old.c new.c marked.c ; nroff reqs marked.c | pr`
`tfile reqs` 包含以下 `troff` 请求，用于消除分页、调整行宽、设置不填充模式、忽略字符并关闭连字符化。

```
.nf
.eo
.nh
```
如果字符 `|` 和 `*` 不合适，你可能通过 `sed(1)` 运行 `markedfile` 以进行全局更改。

## 属性

参见 `attributes(5)` 获取以下属性的描述：

| 属性类型 | 属性值 |
| --- | --- |
| 可用性 | SUNdoc |

## 参见
`diff(1)`, `attributes(5)`, `largefile(5)`
