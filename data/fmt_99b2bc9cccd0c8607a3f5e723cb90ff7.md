
这将使你进入`gnuplot`解释器，提示符看起来像`gnuplot>`。告诉`gnuplot`你将绘制一个分组条形图，带有填充的条形和黑色边框：

```
gnuplot> set style data histogram
gnuplot> set style histogram cluster gap 1
gnuplot> set style fill solid border rgb "black"
```

接下来，让它自动缩放水平轴，但确保垂直轴从零开始。从零以外开始的条形图通常被那些想要误导人们对其展示的数据产生误解的人用作工具！

```
gnuplot> set auto x
gnuplot> set yrange [0:*]
```

然后确保`gnuplot`知道数据文件使用制表符作为分隔符，因为它默认会使用任何空白字符来分隔值：

```
gnuplot> set datafile separator "\t"
```

如果没有坐标轴标签来告诉你信息意味着什么，图表就没有什么用处。添加一个标签：

```
gnuplot> set ylabel "GFLOP/s"
```

最后，你准备好绘制数据了。此命令使用了循环，因此你不需要对每一列重复输入相同的命令：

```
gnuplot> plot for [i=1:6] 'results.dat' \
> using (column(i+1)):xtic(\i) \
> title 'SOMBERO_'i
```

就这样，完成了！新窗口中会出现一个图表，以分组条形图的形式展示你不同运行的带标签比较。如果你愿意，可以将其导出为`PDF`或图像文件，发送给朋友炫耀，或者打印出来贴在冰箱上。

### 超级计算机的“王牌”

曾经有一段时间，`Linpack`基准测试——用于计算`Top500`（`www.top500.org`）——是排名超级计算机的唯一基准。然而，由于该基准测试旨在尽可能多地执行浮点运算（`FLOPs`）而尽量减少其他操作，因此它并不总是能很好地展示机器在尝试执行更实用任务时的表现。硬件制造商希望销售更多硬件，而他们通过拥有最大的数字来销售硬件，因此他们设计机器以在`Linpack`上比任何人都做得更好。由于所有硬件设计都涉及折衷，这可能会产生反常效果，为了获得更好的`TOP500`分数，反而损害了机器在真正有趣的问题上的性能。

由于这个原因，出现了大量基准测试和排名。例如，`Green500`衡量超级计算机在运行`Linpack`时的能源效率：当运行超级计算机全寿命的电力成本通常与购买机器的成本相同时，这是至关重要的。`Graph 500`（`http://graph500.org`）侧重于数据密集型应用程序，而不是计算密集型`Linpack`。`Sombro`侧重于原始计算、从`RAM`读取速度以及通过节点间高速网络发送数据所需时间的混合——不同基准测试之间这些因素的平衡会发生变化。对于每个基准测试，都会有一台不同的超级计算机成为冠军。

### 高级音频录制和编辑

**我们的专家**

大型音频套件很棒，但老实说它们可能令人望而生畏——有时你只想要一个不用想太多就能工作的东西。引入来自`www.audacityteam.org`的`Audacity`。

`Audacity`在所有桌面平台上都很受欢迎，并且开始在`YouTube`教程中频繁出现。以易用性和直观界面著称，`Audacity`也许是音频版的`Microsoft Paint`（呃……`Ed`）——它无法执行深度复杂的任务，但也没打算这样做。它围绕大多数人可以摸索着使用的简单控件设计……但这并不意味着你不能取得一些很棒的结果！

虽然从技术上讲`Audacity`可以录制多通道数字音频，但该界面真的不是为此设计的——它适用于单声道或立体声的简单录音。如果你在寻找`Pro Tools`的替代品，`Audacity`不是它；请尝试`Ardour`或`QTractor`。但如果你在寻找一个易于使用的波形编辑器以及一种快速、简单的方法来制作立体声混音，它可能是你要找的东西。`Audacity`让你可以深入波形并执行简单的剪切和编辑，这使得它在想要快速剪切剪辑并应用基本效果而不被复杂界面困扰的技术人员中非常受欢迎。

然而，`Audacity`最近经历了一些变化，乍一看，一些长期用户可能会感到不适应。所以对于新用户，我们将给你介绍主要功能；对于老手，我们将展示变化以及如何适应。我们不会展示所有功能，但我们会涵盖足够的`essentials`以开始工作流程。

### `Audacity`的界面

`![](img/3f314b57ad3c8b08d25e5d1ab47de56d_93_0.png)`

- 1. **主工具栏**

  存放你的主要工具，如选择、时间平移、缩放和包络。

- 2. **轨道控制**

  用于静音、独奏轨道以及更改增益和声像。这是你真正塑造声音景观的地方。

- 3. **轨道菜单**

  提供一组更高级的控制，如单声道/立体声转换，以及重命名和移动轨道。

- 4. **折叠按钮**

  将任何轨道压缩成一种稍后可以展开的薄片。

- 5. **缩放控制**

  用于特定缩放功能的专用按钮，包括放大波形的选定部分，或缩小至`100%`。

- 6. **录音选项**

  选择你要使用的音频系统，录音设备，单声道或立体声，以及更改播放设备。

### 听起来不错

为了向你展示`Audacity`如何工作，我们首先需要一些音频来操作。你可以导入现有音频，或者只是录制随机声音（空白静音也可以）——其实并不重要，只要有一个某种类型的音频轨道即可。

如果你想添加一些现有的音频轨道，你可以遍历一堆`GUI`提示（如果你真的喜欢的话），或者只需将它们点击并拖放到编辑字段中。至于录制音频，只需点击主工具栏中的录音按钮，如果你使用的是网络麦克风，拍手几次——这应该会在波形上显示出来。完成后按下停止，我们就可以正式查看`Audacity`了。

设备工具栏允许你更改要使用的声卡，以及哪个音频主机将运行系统——可能是`ALSA`，也许还有`JACK`的选项。对于录音设备，你可能会有`Default`（最可能是`ALSA`设备）或`Pulse`的选项。`ALSA`可能运行得更快并对系统更友好，尽管如果你的系统已经围绕它配置，`Pulse`可能更容易配置工作。

也许最重要的是录音通道数。在这里你可以选择

单声道使用一个通道，立体声使用两个通道。不要仅仅因为认为立体声更好就选择立体声。如果你正在录制单件乐器，从长远来看，将其录制为单声道可能更简单，即使你最终要创作的是立体声作品。如果你正在录制类似调频广播的内容或捕获计算机音频，那么你希望以立体声进行录制。

`Audacity`的工具栏——拥有一个响亮的名字“`Audacity`工具工具栏”——收纳了主要工具，如选择、绘制、时间推移和缩放。默认情况下，选择工具会被启用，用于在剪切、粘贴、静音某些部分等操作前高亮显示音频。剪切和粘贴通过常规快捷键完成，因此在这方面不会有任何问题，你可以使用`Delete`键删除选中的音频片段。你可以选择放大镜图标进行缩放：左键点击放大，右键点击缩小。如果你想进行高强度的手动编辑，可以一直放大到每个波形的颗粒级别；如果你选择绘制工具，甚至还可以重新绘制波形的形状。

如果你的某个轨道与其他已录制的轨道不同步，你可以使用时间推移工具来修正。如果你向左或向右点击并拖动，它会向前或向后移动时间，你甚至可以移动轨道到零秒标记之前。

右侧更远处是缩放控件，都带有不同样式的放大镜图标，它们复现了缩放工具的功能。带有加号和减号的图标让你可以完全放大到波形的细节，或者完全缩小以便查看整个轨道。

### 单独监听

不那么明显，但在你熟悉操作后变得至关重要，是接下来的两个控件：“将选定内容适应窗口”和“将项目适应窗口”。当你选中一些音频时，“将选定内容适应窗口”会放大，直到你高亮显示的选定内容正好填满屏幕——不多也不少。当你需要再次查看整个项目时，“将项目适应窗口”会在一次点击中完全缩小视图。
