
关闭之前由 `open()` 或 `pipe()` 返回的文件描述符 `fd`。

## `closerange(low, high)`

关闭范围 `low <= fd < high` 内的所有文件描述符 `fd`。忽略错误。

## `dup(fd)`

复制文件描述符 `fd`。返回一个新的描述符，它是该进程中编号最小的未使用描述符。新旧文件描述符可以互相使用。此外，它们共享状态，例如当前的文件指针和锁 (UNIX 和 Windows)。

## `dup2(oldfd, newfd)`

将 `oldfd` 复制到 `newfd`。如果 `newfd` 已经对应有效的文件描述符，则先将其关闭 (UNIX 和 Windows)。

## `fchmod(fd, mode)`

将与 `fd` 关联的文件模式改为 `mode`。关于 `mode` 的描述请参见 `os.open()` 的描述 (UNIX)。

## `fchown(fd, uid, gid)`

将与 `fd` 关联的文件的所有者和组 ID 修改为 `uid` 和 `gid`。`uid` 或 `gid` 使用值 `-1` 以保持不变 (UNIX)。

## `fdatasync(fd)`

强制所有写入 `fd` 的数据刷新到磁盘 (UNIX)。

## `fdopen(fd, mode, [, bufsize])`

创建一个与文件描述符 `fd` 关联的打开的文件对象。`mode` 和 `bufsize` 参数的含义与内置 `open()` 函数相同。`mode` 应该是类似于 'r'、'w' 或 'a' 的字符串。在 Python 3 中，此函数接受任何与内置 `open()` 的额外参数，如编码和换行符。但如果考虑到 Python 2，你应该只使用描述的 `mode` 和 `bufsize` 参数。

## `fpathconf(fd, name)`

返回与打开的文件描述符 `fd` 关联的路径变量。`name` 是要检索的名称字符串。值可能来自系统头文件（如 `<limits.h>` 和 `<unistd.h>`）中的参数。POSIX 为 `name` 定义了以下常量：

| 常量 | 描述 |
|---|---|
| "PC_ASYNC_IO" | 表示可以在 `fd` 上执行异步 I/O。 |
| "PC_CHOWN_RESTRICTED" | 表示是否使用了 `chown()` 函数。`fd` 指向目录，应用于目录内的所有文件。 |
| "PC_FILESIZE_BITS" | 文件的最大大小。 |
| "PC_LINK_MAX" | 文件链接数的最大值。 |
| "PC_MAX_CANON" | 格式化输入行的最大长度。`fd` 指向终端。 |
| "PC_MAX_INPUT" | 输入行的长度。`fd` 指向终端。 |
| 常量 | 描述 |
|---|---|
| PC_NAME_MAX | 目录中文件名的最大长度。 |
| PC_NO_TRUNC | 表示尝试为目录创建超过 `PC_NAME_MAX` 长度的文件是否会因 `ENAMETOOLONG` 错误失败。 |
| PC_PATH_MAX | `fd` 为当前工作目录时的相对路径最大长度。 |
| PC_PIPE_BUF | 当 `fd` 指向文件或 FIFO 时管道缓冲区的大小。 |
| PC_PRIO_IO | 表示可以在 `fd` 上执行同步 I/O。 |
| PC_SYNC_IO | 表示可以在 `fd` 上执行同步 I/O。 |

## `fstat(fd)`

返回与 `fd` 关联的文件信息。

## `fsync(fd)`

强制将任何写入 `fd` 的数据刷新到磁盘 (UNIX)。

## `isatty(fd)`

如果 `fd` 是终端则返回 True。

## `lseek(fd, pos, how)`

设置 `fd` 的当前位置。`how` 的值为：`SEEK_SET` 设置文件开头，`SEEK_CUR` 设置当前位置，`SEEK_END` 设置文件结尾。

## `open(file [, flags [, mode]])`

打开文件。`flags` 是以下常量的位或组合：

| 值 | 描述 |
|---|---|
| O_RDONLY | 只读打开文件。 |
| O_WRONLY | 只写打开文件。 |
| O_RDWR | 读写打开文件。 |
| O_APPEND | 附加到文件末尾。 |
| O_CREAT | 如果文件不存在则创建。 |
| O_NONBLOCK | 打开时不阻塞 (UNIX)。 |
| O_NDELAY | 等于 `O_NONBLOCK` (UNIX)。 |
| O_DSYNC | 同步写入 (UNIX)。 |
| O_NOCTTY | 打开设备时不设置控制终端 (UNIX)。 |
| O_TRUNC | 如果文件存在，则截断为零。 |
| O_RSYNC | 同步读取 (UNIX)。 |
| O_SYNC | 同步写入 (UNIX)。 |
| O_EXCL | 如果 `O_CREAT` 且文件存在则报错。 |
| O_EXLOCK | 设置文件的排他锁。 |
| O_SHLOCK | 设置文件的共享锁。 |
| O_ASYNC | 启用异步输入模式，输入时产生 SIGIO 信号。 |
| O_DIRECT | 使用直接/O 模式，读写直接通过磁盘而不使用系统缓存。 |
| O_DIRECTORY | 如果不是目录则引发错误。 |
| O_NOFOLLOW | 不跟随符号链接。 |
| O_NOATIME | 不更新文件的访问时间。 |
| O_TEXT | 文本模式 (Windows)。 |
| O_BINARY | 二进制模式 (Windows)。 |
| O_NOHERIT | 文件不被子进程继承 (Windows)。 |
| O_SHORT_LIVED | 提示系统文件用于临时存储 (Windows)。 |
| O_MEMORY | 关闭时删除文件 (Windows)。 |
| O_RANDOM | 提示系统文件将随机访问 (Windows)。 |
| O_SEQUENTIAL | 提示系统文件将按顺序访问 (Windows)。 |

同步 I/O 模式 (`O_SYNC`, `O_DSYNC`, `O_RSYNC`) 强制 I/O 操作在硬件层面完成之前保持阻塞（例如，写入将阻塞直到字节已物理写入磁盘）。`mode` 参数包含以下八进制值的位或的文件权限（这些定义在 `stat` 结构体中）：

| 模式 | 含义 |
|---|---|
| 0100 | 用户执行权限 (`stat.S_IXUSR`)。 |
| 0200 | 用户写入权限 (`stat.S_IWUSR`)。 |
| 0400 | 用户读取权限 (`stat.S_IRUSR`)。 |
| 0700 | 用户读/写/执行权限 (`stat.S_IRWXU`)。 |

### 模式含义

| Mode | 含义 |
|---|---|
| 0010 | 组具有执行权限 (`stat.S_IXGRP`)。 |
| 0020 | 组具有写入权限 (`stat.S_IWGRP`)。 |
| 0040 | 组具有读取权限 (`stat.S_IRGRP`)。 |
| 0070 | 组具有读/写/执行权限 (`stat.S_IRWX`)。 |
| 0001 | 其他用户具有执行权限 (`stat.S_IXOTH`). |
| 0002 | 其他用户具有写入权限 (`stat.S_IWOTH`). |
| 0004 | 其他用户具有读取权限 (`stat.S_IROTH`). |
| 0007 | 其他用户具有读/写/执行权限 (`stat.S_IRWXG`)。 |
| 4000 | 设置 UID 模式 (`stat.S_SUID`)。 |
| 2000 | 设置 GID 模式 (`stat.S_SGID`)。 |
| 1000 | 设置粘性位 (`stat.S_ISVTX`)。 |

文件的默认模式是 `(0777 & ~umask)`，`umask` 用于移除权限。例如，0022 的 `umask` 会移除组和其他和其他用户的权限。可以使用 `os.umask()` 函数更改 `umask`。`umask` 对 Windows 不起作用。

```python
open()
```

打开一个伪终端并返回用于 PTY 和 TTY 的对文件描述符（主端，从端）。在某些版本的 UNIX 上可用。

```python
pipe()
```

创建一个管道，可用于与另一个进程建立单向通信。返回一对可分别用于读取和写入的文件描述符 `(r, w)`；发送进程关闭管道的末端，接收进程关闭管道的另一端。此时，管道被激活，并可以使用 `read()` 和 `write()` 函数从一个进程发送到另一个进程 (UNIX)。

```python
read(fd, n)
```

从文件描述符 `fd` 读取最多 `n` 字节。返回一个包含这些字节的字符串。

```python
tcsetpgrp(fd)
```

返回与由 `fd` 提供的控制终端相关的进程组 (UNIX)。

```python
tcsetpgrp(fd, pg)
```

设置与由 `fd` 提供的控制终端相关的进程组 (UNIX)。
