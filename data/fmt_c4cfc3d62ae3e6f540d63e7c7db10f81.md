## IT 专业人员知识点

从技术上讲，可以在 Linux 中使用 FAT16 和 FAT32 格式的驱动器，但对于数据库服务器来说，这是一个糟糕的选择。对于所有数据驱动器，最佳的文件系统类型是 Linux 原生（Linux Native）。你还需要为交换分区分配磁盘空间。你可以拥有最大 4GB 的交换空间，分布在八个分区中，其中任何分区的大小不超过 2GB。建议将交换空间设置为内存大小的两到三倍。在内存达到 GB 级别之前，这是一个很好的经验法则。在此阶段，你不太可能发生交换，甚至在内存为任何 2GB 的时候都很有可能发生交换。这也有例外例，例如，如果你确实配置了如大型驻留数据库文件的单进程，那么你需要大量的交换空间。如果你的设计更倾向于较小的事务处理型进程，那么可以使用较少的总交换空间。记住，如果内存中有大型进程，由于磁盘是廉价的，请用它进行交换。在此时，在进行系统分析之前，请保持在内存的二到三倍。

## 多个交换分区

交换空间是系统在内存满时将内存驻进程集存放的地方。你需要它来系统正常工作，但你真的不希望系统使用它，因为与内存相比，它的速度极其缓慢。它的存在是为了内存过载时的紧急情况准备的，对于偶尔使用是可以的。持续使用明显表明你的内存不足。如果检测到交换空间被大量使用，请立即升级。通过将请求分散到多个磁盘或控制器可以提高任何磁盘活动，交换空间也是如此——将其分散以提高性能，并将负载均匀分布到所有磁盘上。

## 分区挂载点

当你点击 Add 时，会显示一个参数设置屏幕。有四个参数需要设置。第一个参数是挂载点。与基于 DOS 的系统为每个分区定义驱动器号不同（目前 Win2k 正在发生变化），在 UNIX 和 Linux 中，有一个文件系统使用目录名称将它们连接在一起。这些目录被称为挂载点。UNIX 有一些历史挂载点，Linux 继续保留了它们。你可以输入你选择的目录名称，也可以从下拉列表中预配置的目录名称中选择。图 2.6 显示了可用的预配置挂载点选项。这不是限制，只是一个起点。

## 分区大小

要决定的第二个参数是大小。你应该以 MB 为单位输入分区大小所需的近似值。注意，实际大小取决于物理驱动器的特性（必须使用完整的柱面计数），而不是你的实际值。不要担心确切的大小——只要接近即可。

大小选项还有一个单选按钮，你可以用它来让分区大小“填满磁盘”（Grow to fill disk）。此选项将允许此分区使用所有剩余的磁盘空间，或与同一物理磁盘上的任何其他分区等分剩余磁盘空间。对于创建的最后一个分区或想要共享所有剩余磁盘空间的多个分区来说，这是一个很好的选项。此选项始终使用所有剩余磁盘空间。如果你选择了此 Grow 按钮，可以在 Size 参数框中输入任何值。在你完成所有分区的配置后，Disk Druid 在实际执行分区时处理真实大小（这些都是在内存中完成的；在完成此屏幕之前不会创建任何内容）。图 2.7 展示了 Size 值字段以及“填满磁盘”单选按钮。

## 主机名

这仅仅是对这台机器的引用，并不一定与网络上其他地方引用此主机的名称相同。名称解析是将名称更改为 IP 地址的行为。Linux 使用 `/etc/hosts` 文件然后通过 DNS 将主机名解析为 IP 地址。但本地命名方案既不是共享的，也不是特定的；其他任何机器都可以在本地使用它们想要的任何名称来表示你机器的 IP。只有当你使用像 DNS 这样的中央服务时，你会被限制在一个特定的名称上，即使这也可以被绕过。总之，此主机名在网络上不必是唯一的，但如果你使用 DNS，它应该是唯一的。

## root 账户配置

每个 Linux 发行版都有一个特殊的账户，通常称为 `root`，有时被称为 `超级用户`（superuser）。`root` 账户可以执行任何操作。你必须以超级用户的身份配置密码。在某些 Linux 版本中，你还有机会安装你可能想要包含的其他用户。例如，在 RedHat Linux 中，你可以在安装期间轻松添加一个或多个额外用户，如图 2.11 所示。你不必添加另一个用户，但 `强烈` 建议你为工作站的日常工作创建一个非特权账户。在执行基础用户任务时，你 `不应该` 使用 `root` 身份。
