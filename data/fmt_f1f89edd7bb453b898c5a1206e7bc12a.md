
在列表 6-2 示例的全局部分，打印机是第一个被描述的共享。此示例指定了 BSD 或 Berkeley 风格的打印（我稍后会在本文中介绍关于 BSD 风格打印的更多内容）。标准的 `/etc/printcap` 是打印机定义文件，布尔变量（只能是 `yes` 或 `no` – 真或假）`load printers` 表示所有打印机都可以在网络上浏览。全局部分中的这三行指定了整个 Samba 系统的打印设置。

`/etc/printcap` 文件包含 Linux 打印机的配置信息。在 Red Hat Linux 中，`lpd` 守护进程管理 `printcap` 文件的配置信息。它监控系统的打印请求并管理打印过程。

`[global]` 部分还定义了日志和锁目录的位置。日志文件对于排除问题和调优系统很有用。锁文件防止了多个用户覆盖同一个文件。

`[homes]` 部分定义了导出个人目录的通用参数。如果你的 Windows 95 用户名与 Linux 用户名匹配，且你提供了正确的密码，你可以双击“网络邻居”中的此图标并访问你的主目录。

`[printers]` 部分则描述了如何配置打印机。当然，你可以扩展这些特殊部分来创建更具体的服务。它们本身是有用的，但你也可以将它们视为模板。

帮助页面（man page）提供了 `smb.conf` 的完整描述。要查看它，请输入以下命令：

```
man smb.conf
```

> 注意：BSD 打印可能是 UNIX（以及无疑是 Linux）最流行的打印风格。它使用了 System V 的 Berkeley 模型。守护进程 `lpd` 和程序 `lpr` 都会读取 `/etc/printcap` 文件以获取打印机定义。`lpd` 守护进程在启动时运行——并可以由 `root` 用户随时重启。它会打印任何遗留的打印作业，并在后台持续运行，监听来自 `lpr` 的打印请求。`lpr` 程序用于启动文件打印。它将文件复制到产生器目录（存放文件的临时位置），然后向 `lpd` 信号文件已就绪打印。随后，产生的文件由过滤器程序转换为可打印格式，然后由 `lpd` 发送到打印机。
