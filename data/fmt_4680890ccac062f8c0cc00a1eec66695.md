# 获取字体度量

给定的国际化文本函数的度量是根据主绘制方向定义的，该方向是字符串中每个后续字符串字符起点推进的默认方向。`Xlib` 接口目前定义为支持从左到右的主绘制方向。绘制起点是绘制文本时传递给绘制函数的位置。基线是穿过绘制起点并平行于主绘制方向的线。字符墨迹是用前景色绘制的像素，不包括行间距、字距或图像文本背景。

绘制函数允许实现文本方向控制，根据对字符串的特定语言区域词法分析，反转字符沿主绘制方向渲染的顺序。

无论字符渲染顺序如何，所有字符的起点都在原点的主绘制方向侧。特定字符图像的位置可以通过 `XmbTextPerCharExtents` 或 `XwcTextPerExtents` 确定。

绘制函数允许实现上下文渲染，即字符串的字形并非每个单独字符字形的简单拼接。使用 `XmbDrawString` 绘制两个字符可能与分开调用不同；如果客户端在之前绘制的字符串中插入或删除图像，客户端可能需要重新绘制某些相邻字符以获得正确的渲染。

要了解依赖方向的渲染，请使用 `XDirectionDependentDrawing`。

```
Bool XDirectionDependentDrawing(font_set);
```

`font_set` 指定字体集。

`XDirectionDependentDrawing` 函数在绘制函数实现文本方向控制时返回 `True`；否则返回 `False`。

要了解依赖上下文的渲染，请使用 `XContextualDrawing`。

```
Bool XContextualDrawing(font_set);
```

`font_set` 指定字体集。

`XContextualDrawing` 函数如果使用字体集绘制可能包含上下文上下文渲染，则返回 `True`；否则返回 `False`。

要了解依赖上下文或依赖方向的渲染，请使用 `XContextDependentDrawing`。

```
Bool XContextDependentDrawing(font_set);
```

`font_set` 指定字体集。

`XContextDependentDrawing` 函数如果绘制函数实现文本方向控制，或者使用字体集绘制的文本可能包含依赖上下文渲染，则返回 `True`；否则返回 `False`。

绘制函数不解释换行符、制表符或其他控制字符。绘制空格以外的非打印字符时的行为取决于实现。解释文本流中的控制字符是客户端的责任。

文本绘制层使用的字体的最大字符范围可以通过 `XFontExtents` 结构访问：

```
typedef struct {
    XRectangle max_ink_extent;      /* 遍历所有可绘制字符 */
    XRectangle max_logical_extent;  /* 遍历所有可绘制字符 */
} XFontSetExtents;
```

用于返回集合度量的 `XRectangle` 结构是常用的 `Xlib` 屏幕方向字符，其中 `x` 给出上角。最大长度范围给出所有可绘制字符的最大范围。（此处原文存在重复描述，翻译已整合）。

# 语言区域与国际化文本函数

如果 `overall_logical_return` 参数非空，则它被设置为为该字符串与其他图形特征提供最小间距的边界框。其他图形特征（例如围绕文本的边框）不应与此矩形交叉。

当 `XFontSet` 缺少字符时，每个不可用字符的度量将从 `XCreateFontSet` 返回的默认字符串中获取，以便度量代表实际绘制时的文本。对于无效的码点，其行为未定义。

要确定字符串中某个字符的有效绘制起点，客户端应对整个字符串调用 `XmbTextPerCharExtents`，然后对该字符调用，并减去返回的字符 `rectents` 的 `x` 值。这对于重绘行落或进行单词对齐很有用，但对于依赖上下文的渲染，客户端不应假设它可以自己重绘该字符并获得相同的渲染效果。

要获取字符串的信息，请使用 `XmbTextPerCharExtents` 或 `XwcTextPerCharExtents`。

```
XmbTextPerCharExtents(font_set, string, num_bytes,
k_array_return, logical_array_return, array_size, num_chars_return,
overall_ink_return, overall_logical_return);
```

```
XwcTextPerCharExtents(font_set, string, num_wchars,
ink_array_return, logical_array_return, array_size, num_chars_return,
overall_ink_return, overall_logical_return);
```

- 指定字体集。
- 指定字符字符串。
- 指定字符串参数中的字节数。
- 指定字符串参数中的字符数。
- 返回每个字符的墨水尺寸（ink dimensions）。
- 返回每个字符的逻辑尺寸（logical dimensions）。
- 指定 `ink_array_return` 的大小。调用者必须传入此此大小的数组。
- 返回字符串参数中的字符数。
- 返回整体的墨水尺寸。
- 返回整体的逻辑尺寸。

`XmbTextPerCharExtents` 和 `XwcTextPerCharExtents` 使用为指定字体集加载的字体，返回指定文本每个字符的文本尺寸。`ink_array_return` 和 `logical_array_return` 的每个后续元素被设置为后续字符的绘制度量，相对于提供的文本字符串中字符串和每个字符的绘制起点。返回给 `num_chars_return` 的 `ink_array_return` 和 `logical_array_return` 的元素数量相等。

每个 `ink_array_return` 都被设置为对应字符绘制前景色的边界框。`logical_array_return` 中的每个元素都被设置为为对应字符与其他图形特征提供最小间距的边界框。其他图形特征不应与任何 `logical_array_return` 矩形交叉。

注意，`Rectangle` 代表字符的有效尺寸，无论用于绘制该字符的字体字形数量或绘制方向如何。如果多个字符映射到单个字体字形，则它们所有 `XRectangle` 的尺寸是相同的。

当 `XFontSet` 缺少字符时，每个不可用字符的度量将从 `XCreateFontSet` 返回的默认字符串中获取，以便度量代表实际绘制时的文本。对于无效码点，其行为未定义。

如果数组大小对于提供文本中的字符数太小，函数返回 `0` 且 `num_chars_return` 设置为所需的矩形数量。否则，函数返回非零值。

如果 `overall_ink_return` 或 `logical_return` 参数非空，`XmbTextCharExtents` 和 `XwcTextCharExtents` 返回由 `XmbTextExtents` 和 `XwcTextExtents` 返回的字符串度量的最大范围到 `overall_ink_return` 或 `logical_return`。

# 使用字体集绘制文本

本节定义的函数在数据库指定绘制。它们与 `XText`、`XDrawString` 和 `XImageString` 类似，不同之处在于它们处理字体集而不是单个字体，并且通过字体集解释文本，而不是将文本视为字体索引语言区域上的字符串。有关图形上下文（GCs）的使用和可能的协议错误，请参见第 8.6 节。如果生成了 `BadFont` 错误，出错字符之前的字符可能已经绘制。

文本使用为指定字体集加载的字体绘制：GC 中的字体被忽略，并可能被字体修改。不会对所有字体是否符合某些宽度规则进行验证。

文本函数 `XmbTextDraw` 和 `XwcDrawText` 使用以下结构：

```
typedef struct {
    char *chars;        /* 指字符串的指针 */
    int nchars;          /* 字节数 */
    int delta;           /* 字符串之间的像素差 */
    XFontSet font_set;   /* 字体, None 表示不改变 */
};
```

```
typedef struct {
    wchar *chars;           /* 指宽字符字符串的指针 */
    int nchars;             /* 宽字符数 */
    int delta;              /* 字符串之间的像素差 */
    XFontExtents font_set;  /* 字体, None 表示不改变 / */
} XmbWidgetItem;
```
