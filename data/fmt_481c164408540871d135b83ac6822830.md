
`XResizeWindow` 函数更改指定窗口的内部尺寸，不包括边框。此函数不会更改窗口的左上角坐标，也不会重堆叠窗口。更改已映射窗口的大小可能会丢失其内容并生成 Expose 事件。如果已映射的窗口较小，更改其大小会在该映射窗口以前被遮挡的窗口上生成 Expose。

如果窗口的 override-redirect 标志为 False，且另一个客户端在父窗口上选择了 SubstructureMask，则 X 服务器将生成一个 ConfigureRequest 事件，且不进行任何进一步处理。如果宽度或高度任为零，将发生 BadValue 错误。

`XResizeWindow` 可能产生 BadValue 和 BadWindow 错误。

要更改边框宽度，请使用 `XSetBorderWidth`。

```
XSetBorderWidth(display, w, width);
```

- `display`：指定与 X 服务器的连接。
- `w`：指定窗口。
- `width`：指定的宽度。

`XSetBorderWidth` 函数设置指定窗口的边框宽度。`XSetBorderWidth` 可能产生 BadWindow 错误。

## 更改窗口堆叠顺序

Xlib 提供了你可以用来提升、降低、循环或重启窗口的函数。

要提升窗口使其不再被兄弟窗口遮挡，请使用 `XRaiseWindow`。

```
XRaiseWindow(display, w);
```

- `display`：指定与 X 服务器的连接。
- `w`：指定窗口。

`XRaiseWindow` 函数将指定的窗口提升到栈顶部，使其不再被窗口遮挡。如果窗口被视为叠在桌面上的纸，提升窗口就像将纸移动到栈顶部，但保持其 x 和 y 位置不变。提升已映射窗口可能会在该窗口以及任何以前被遮挡的映射窗口产生大多数事件。

如果窗口的 override-redirect 属性为 False，且另一个客户端在父窗口上选择了 SubstructureMask，则 X 服务器将生成一个 ConfigureRequest 事件，且不进行任何进一步处理。否则，将提升窗口。

`XRaiseWindow` 可能产生 BadWindow 错误。

要降低窗口使其不再遮挡任何兄弟窗口，请使用 `XLowerWindow`。

```
XLowerWindow(display, w);
```

- `display`：指定与 X 服务器的连接。
- `w`：指定窗口。

`XLowerWindow` 函数将指定的窗口降低到栈底部，使其不再遮挡任何兄弟窗口。如果窗口被视为叠在桌面上的纸，降低窗口就像将纸移动到栈底部，但保持其 x 和 y 位置不变。降低已映射窗口可能会在以前被遮挡的窗口上产生 Expose 事件。

## 窗口函数

将子窗口向上或向下循环，请使用 `XCirculateSubwindows`。

```
XCirculateSubwindows(display, w, direction);
```

`display` 指定与 X 服务器的连接。
`w` 指定指定的窗口。
`direction` 指定你想要循环窗口的方向（向上或向下）。你可以使用 RaiseLowest（提升最低层）或 LowerHighest（降低最高层）。

`XCirculateSubwindows` 在指定的方向上对指定窗口的子进行循环。如果你使用 RaiseLowest，`XCirculateSubwindows` 将被另一个子窗口遮挡的最低子窗口（如果有）提升到栈的顶端。如果你使用 LowerHighest，`XCirculateSubwindows` 将遮挡另一个子窗口的最高映射子窗口（如果有）降低到栈的底部。随后对原先被遮挡的窗口执行显示处理（Exposure processing）。如果其他客户端已在该窗口上选择了 SubstructureRedirectMask，则 X 服务器将生成一个 CirculateRequest，且不再进行后续处理。如果子窗口实际上被恢复，X 服务器将生成一个 CirculateNotify。

`XCirculateSubwindows` 可能会产生 BadValue 和 BadWindow 错误。

要将被另一个子窗口部分或完全遮挡的窗口的最低子窗口提升，请使用 `XCirculateSubwindowsUp`。

```
XCirculateSubwindowsUp(display, w);
```

`display` 指定与 X 服务器的连接。
`w` 指定指定的窗口。

`XCirculateSubwindowsUp` 函数提升指定窗口中被另一个子窗口部分或完全遮挡的最低子窗口。完全未遮挡的子窗口不受影响。这是一个便利函数，等同于使用了 RaiseLowest 的 `XCirculateSubwindows`。

`XCirculateSubwindowsUp` 可能会产生 BadWindow 错误。

要将部分或完全遮挡另一个窗口的窗口的最高映射子降低，请使用 `XCirculateSubwindowsDown`。

```
XCirculateSubwindowsDown(display, w);
```

`display` 指定与 X 服务器的连接。
`w` 指定指定的窗口。

`XCirculateSubwindowsDown` 函数降低指定窗口中部分或完全遮挡另一个窗口的最高映射子窗口。完全未遮挡的子窗口不受影响。这是一个便利函数，等同于使用了 LowerHighest 的 `XCirculateSubwindows`。

`XCirculateSubwindowsDown` 可能会产生 BadWindow 错误。

要按从上到下重新堆叠一组窗口，请使用 `XRestackWindows`。

```
XRestackWindows(display, windows[], nwindows);
```

`display` 指定与 X 服务器的连接。
`windows` 指定一个包含要重新堆叠窗口的数组。
`nwindows` 指定要重新堆叠的窗口数量。

`XRestackWindows` 函数按照指定的顺序（从上到下）重新堆叠窗口。`windows` 数组中第一个窗口的堆叠顺序不受影响，但数组中的其他窗口将按照数组顺序堆在第一个窗口下方。其他窗口的堆叠顺序不受影响。对于数组中每个不是指定客户端子窗口窗口，会导致 BadMatch 错误。

如果父窗口上的 SubstructureRedirectMask 开启了 override-redirect（覆盖重定向），当 override-redirect 标志未设置时，X 服务器为每个窗口生成 ConfigureRequest 事件，且不再进行后续处理。否则，窗口将按从上到下的顺序重新堆叠。

`XRestackWindows` 可能会产生 BadWindow 错误。

## 更改窗口属性

Xlib 提供了你可以设置窗口属性的函数。`XChangeAttributes` 是更通用的函数，允许你通过 `XSetWindowAttributes` 结构体设置一个或多个窗口属性。本节描述的其他函数允许你设置一个特定的窗口属性，例如窗口的背景。

要更改给定窗口的一个或多个属性，请使用 `XChangeWindowAttributes`。

```
XChangeWindowAttributes(display, w, valuemask, attributes);
```

`display` 指定与 X 服务器的连接。
`w` 指定指定的窗口。
`valuemask` 指定 `attributes` 参数中定义了哪些窗口属性。该掩码是值属性掩码位的按位包含“或”结果。如果 `valuemask` 为零，则属性将被忽略且不被引用。其值和限制与 `XCreateWindow` 相同。
`attributes` 指定了从中获取值（如 value mask 所示）的结构体。value mask 应该设置相应的位，以指示结构体中设置了哪些属性（见第 3.2 节）。

取决于 `valuemask`，`XChangeWindowAttributes` 函数使用 `XSetWindowAttributes` 中的窗口属性来更改指定的窗口属性。如需重绘窗口及其背景，请使用 `XClearWindow`。通过更改背景起始瓷砖来设置边框会导致边框改变。更改根窗口背景并将边框设置为 CopyFromParent（从父窗口复制）将恢复默认背景 pixmap。在 WhenMapped 或 Always 状态更改被遮挡窗口的 win-store，或者更改映射窗口的 backing-planes、backing-pixel 或 under-of，可能不会立即生效。更改窗口的调色（即定义一个新映射，而不是更改现有映射的内容）会生成 ColormapNotify 事件。更改窗口的调色可能对屏幕没有立即影响，因为映射可能尚未安装（`XInstallColormap`）。将根窗口的光标设置为 None 将恢复默认光标。尽可能，鼓励你共享调色。
