
`x = a[1:5]` # `a = __getitem__(slice(1,5,None))`

`a[1:3] = [10,11,12]` # `a = __setitem__(slice(1,3,None),(10,11,12))`

`del a[1:4]` # `a = __delitem__(slice(1,4,None))`

```
Python 的切片功能实际上比程序员认为的要强大。例如，以下扩展切片的变体都是支持的，并且对于处理矩阵和数组等多维数据结构可能很有用：
```

```
a = m[0:100] # 步长切片 (stride=10)

b = m[1:30] # 多维切片

c = m[0:100, 50:75] # 带有步长的多个维度

m[0:5:] = n # 扩展切片赋值

del m[0:15:] # 扩展切片删除
```

每个扩展切片的通用格式为：`i[j:stride]`，其中 `stride` 是可选的。与普通切片不同，你可以省略切片每个部分的起始或结束值。此外，省略号（`...`）用于表示扩展切片中的任何尾部或领先维度：

```
a = m[...,10:20] # 带有省略号的扩展切片访问

m[10:20, ...] = n
```

当使用扩展切片时，`__getitem__()`、`__setitem__()` 和 `__delitem__()` 分别实现访问、修改和删除。然而，传递给这些方法的索引是切片或省略号对象的组合。例如：

```
a = m.__getitem__((0,10,None), slice(0,100,Ellipsis))
```

Python 字符串、元组和列表对扩展切片提供了某些支持，高级类型提供了扩展切片操作的支持。

## 迭代

如果一个对象 `obj` 支持迭代，它必须提供一个 `__iter__()` 方法，返回一个迭代器对象。迭代器对象 `iter` 必须实现 `next()` 方法（在 Python 3 中为 `__next__()`），返回下一个对象或抛出 `StopIteration` 以表示迭代结束。这两个方法被 `for x in s` 语句使用。例如：

```python
iter = s.__iter__()

while True:
    try:
        x = iter.__next__()
    except StopIteration:
        break
```

## 第3章 类型与对象

在 Python 2 中，通过在程序中包含 `from __future__ import division` 语句，可以将行为作为可选功能启用。

转换方法 `__int__()`、`__long__()`、`__float__()` 将对象转换为四内置数值类型之一。这些方法通过显式转换调用，以便在数学运算中强制类型转换。例如，如果 `x` 是一个为整数定义了 `__int__()` 的用户定义对象，则表达式 `+x` 将产生 `TypeError`。
