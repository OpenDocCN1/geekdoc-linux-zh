`lftp` `LFTP` 是一个类似 shell 的命令行 ftp 客户端。与其他 ftp 客户端相比，其主要优势是可靠性和在后台执行任务的能力。如果连接中断，它将重新连接并获取正在传输的文件。所有操作都在一个进程中完成。当你启动后台作业并觉得可以退出时，只需退出 ftp，它会自动移动到后台模式并处理传输。它还有像 `reput` 和 `mirror` 这样很好的功能。来自 Mandrake 9.0 RPM

http://www.tld.org/LDP/Linux-Dictionary/html/index.html

`lftp` `LFTP` 是一个复杂的 ftp/ftp 文件传输程序。像 bash 一样，它具有控制功能并使用 readline 库进行导入。它具有书签、内置功能并可以并行传输多个文件。它的设计考虑了可靠性。来自 Redhat 8.0 RPM

http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

`lftp` 复杂的命令行 FTP/HTTP 客户端程序是一个支持在 IPv4 和 IPv6 下的 FTP 和 HTTP 协议的文件检索工具。`Lftp` 拥有一套功能，保持了其界面的简单。与其他 ftp 客户端相比的优势是可靠性和在后台执行任务的能力。如果连接中断，它将重新连接并恢复已传输的文件。你可以在后台启动传输并继续在 ftp 站点浏览。完成后，只需退出 ftp，它会自动移动到后台模式并处理传输。所有操作都在一个进程中完成。

- 高级 Linux 音频架构 (`ALSA`) 是一种模块化架构，支持广泛的 ISA 和 PCI 卡。它与旧的 OSS 驱动完全兼容（无论是 OSS/Lite 还是 OSS/commercial）。使用 alsa 的功能，可以使用旧的 oss api，而新的 alsa api 提供了许多增强功能。使用 ALSA api 需要使用 ALSA 库。来自 Mandrake 9.0 RPM http://www.tdlp.org/LDP/Linux-Dictionary/html/index
