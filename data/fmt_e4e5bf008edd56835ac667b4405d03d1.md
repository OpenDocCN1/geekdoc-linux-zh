
此命令将显示你计算机上所有的 CD-R(W) 设备。记住，此命令将显示所有 CD-R(W) 设备。

```
cdrecord -scansbus

All CD-R(W) devices found:

Device 0: drive 0, capacity 70000000, /dev/sr0
```

以下是运行 `cdrecord` 的示例输出：

```
cdrecord 1.8

-record:

scansbus:

Device 0: drive 0, capacity 700000000, /dev/sr0
```
