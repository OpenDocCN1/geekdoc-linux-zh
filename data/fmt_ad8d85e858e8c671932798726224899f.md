以下示例在 `kook.out` 中创建一个所有小写单词 `kookaburra-1` 的列表，每行一个。其中单词被视为字母的最长字符串。

```
castle$ tr -cs "[:alpha:]" "[\n*]" < kookaburra-1 > kook.out
castle$ cat kook.out
```

以下示例将文件中的所有小写字符转换为大写字母，并将结果写入到标准输出。

```
castle$ tr "[:lower:]" "[:upper:]" < kookaburra-1
KOOKABURRA SITS IN THE OLD GUM TREE
MERRYERRY KING OF THE BUSH IS HE.
LAUGH, KOOKABURRA, LAUGH, KOOKABURRA
GAY YOUR LIFE MUST BE
```

```
KOOKABURRA SITS IN THE OLD GUM TREE
EATING ALL THE GUMDROPS HE CAN SEE.
STOP, KOOKABURRA, STOP, KOOKABURRA
LEAVE SOME THERE FOR ME.
castle$
```

注意 — `XPG3(5)` 相应示例中表达的警告已不再生效。这种大小转换现在是使用 `tolower` 和 `toupper` 分类的特殊情况，确保在区域设置正确定义时能够完成正确的映射。

以下示例使用等价类来识别基础字符 `e` 的重音变体，这些变体将被去除变音并写入 `file2`。

```
castle@ tr "[=e]" e <file1>file2
```
