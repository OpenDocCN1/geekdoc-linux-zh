## Linux 内核

当你使用 `make` 命令编译 Linux 时，最后的一个 `ld` 命令构建内核文件 (`vmlinux`)：

```
ld -m elf_i386 -T /usr/src/linux/arch/i386/vmlinux.lds
-e arch/i386/kernel/head.o arch/i386/kernel/init_task.o
init/main.o init/version.o \
--start-group
arch/i386/kernel.o arch/i386/mm/o
kernel/mm.o mm/fs/fs.o ipc.o \
filesystems.a
net/network.a \
drivers/block.a drivers/char.a
drivers/misc.a drivers/net.a
drivers/cdrom.a drivers/pci.a
drivers/video.a arch/i386/math-emu/math.a
usr/src/linux/arch/i386/lib.a \
usr/src/linux/arch/i386/lib.a \
--end-group
```

`ld` 命令的一部分是 `-T /usr/src/linux/arch/i386/vmlinux.lds` 选项。该选项导致 `ld` 命令丢弃所有依赖项并使用指定的 `.lds` 文件来发现链接格式。`vmlinux.lds` 位于下方。注意 `. = PAGE_OFFSET_RAW + 0x10000;` 这一行告诉 `ld` `.text` 段应该位于 `PAGE_OFFSET_RAW + 0x10000`。此外注意 Makefile 中 `ld` 命令的 `-e text` 选项——我们将在 `arch/i386/kernel/head.S` 中看到。

```
/* 生成 i386 Linux 内核的 ld 脚本
* 由 Martin Miles 编写 */
OUTPUT_FORMAT("elf32-i386", "elf32-i386")
OUTPUT_(i386)
ENTRY(start)
SECTIONS
{
     = PAGE_OFFSET_RAW + 0x10000;
_text :       /* 代码和只读数据 */
.text : {
        *(.text)
        *(fixup)
        *(gnu.warning)
    } = 0x90000
}
```
