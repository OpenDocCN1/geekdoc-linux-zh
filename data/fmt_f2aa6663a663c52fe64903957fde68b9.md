# 列表 4.2 用于 PATH_INFO 环境变量的子程序

```perl
sub path_info {
	$path=$ENV('PATH_INFO');

	$path=s/\///;
	$return=$path;
}
```

将 `$ENV('PATH_INFO')` 赋值给 `$path` 后，脚本删除了前面的斜杠。最后的赋值确保将适当的信息返回给脚本。这简单到你可以将这段代码放入需要它的每个脚本中，既然反正要用这个库，何必麻烦？写一次代码，用一行而不是三行获取你需要的信息。
