# qsort

```c
void qsort (arr, n, size, comp_fn)
```

```c
#include <stdlib.h>

int main(void)
{
    int data[1000], comp_ints(void *, void *);
    qsort (data, 1000, sizeof(int), comp_ints);
}

int comp_ints(void *p1, void *p2)
{
    int i1 = * (int *) p1;
    int i2 = * (int *) p2;
    return i1 - i2;
}
```
