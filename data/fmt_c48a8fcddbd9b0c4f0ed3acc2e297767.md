# IPSec

IP 的安全扩展 (Security extensions to IP)。传统，加密发生在应用层或更低层。`IPsec` 为 IP 数据包提供通用加密，且应用程序感知不到这一过程。`IPsec` 过程是免费提供的。今天最主要的用途是为 VPN 流量建立隧道。它也可以用于两个主机之间数据的通用加密。算法：`Diffie-Hellman` 来自 Hacking-Lexicon `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# iptables

用于 `2.4.x` 内核的 IP 包过滤管理工具。`netfilter` 和 `iptables` 是 Linux `2.4.x` 内核内部的防火墙，启用数据包过滤、网络地址转换 (`NAT`)。`iptables` 是 Linux 网络协议栈中的一组钩子，每当一个数据包通过一个钩子时注册内核函数。IP 表规则由许多分类器（匹配）和一个连接动作（目标）。`iptables` 是一个定义规则集的通用表。重要：系统安全无法通过简单安装 `iptables` 包来实现。来自 Debian `3.0r` APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
