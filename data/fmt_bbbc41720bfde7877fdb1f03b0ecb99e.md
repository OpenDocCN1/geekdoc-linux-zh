# IMAP (互联网邮件访问协议) IMAP4
IMAP 是一种用户用于从服务器检索电子邮件的流行协议。你所使用的邮件客户端（如 Netscape 或 Outlook）很可能支持它。关键点是：IMAP 对黑客来说很重要，因为许多实现容易受到缓冲区溢出攻击。特别是某个带有漏洞的 IMAP 服务的流行 Linux 发行版默认启用了该服务。因此，即使在今天，安全人员也经常检测到针对 143 端口漏洞 IMAP 服务器的扫描。来自 Hacking-Lexicon `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# IMAP (互联网消息访问协议)
在邮件客户端与邮件服务器通信时，IMAP 正在逐渐取代 POP。使用 IMAP，邮件客户端程序不仅可以检索，而且还可以管理服务器上的存储消息，而无需实际检索消息。因此，可以删除消息，并管理其多个邮箱箱。IMAP 定义在 RFC 2060 中。来自 Matisse `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
