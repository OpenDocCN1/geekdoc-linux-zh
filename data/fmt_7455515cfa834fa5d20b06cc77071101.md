
Sound Juicer（图 15-1）是一个相对较新的程序，使用非常直观，且功能相当强大。不过，它并不完美，仍然有些古怪。此外，与其许多抓取类软件不同，Sound Juicer 不会自动为你抓取和编码的歌曲创建播放列表，而且缺乏调整编码比特率的简单方法。

![](img/ba6b82a7869bba748202d57c97336dca_266_0.png)

图 15-1：Ubuntu 默认抓取和编码应用——Sound Juicer

尽管存在局限性，仍然有很多人倾向于使用 Sound Juicer 而不是竞争对手，因此你也可以尝试看看是否喜欢。开始时，只需你想抓取的 CD 放入驱动器即可；Sound Juicer 将自动并在应用程序窗口中显示 CD 标题、艺术家名称以及所有曲目的标题。

**注意**

在这里需要说明的是，如果你没有连接到互联网，这些专辑信息将不会出现，因为专辑和曲目数据并未嵌入 CD 本身。相反发生的情况是你机器上的音频抓取器或播放器会将你播放的 CD 的数字 ID 发送到在线数据库，如 freeDB.org 或 CDDataBase (CDDB)（现在正式称为 Gracerate）。随后，在线数据库会将该 CD 的专辑信息传回播放器或写入器。

你也可以通过另一种方式：进入 **Applications（应用程序）** > **Sound & Video（音频视频）** > **Sound Juicer CD Extractor**，然后将 CD 放入驱动器。在这种情况下，你可能需要在专辑和曲目信息出现之前进入 Sound Juicer 的 **Menu（菜单）** 并选择 **Re-read Disc（重新读取磁盘）**。

## 在 Sound Juicer 中设置抓取文件的默认文件夹

抓取 CD 并将音频轨道编码为 Ogg Vorbis 格式，Sound Juicer 保存这些文件的默认位置是你的主目录。因为 Sound Juicer 与所有其他抓取器一样，会为每个抓取的 CD 创建艺术家文件夹，如果你抓取了大量艺术家的专辑，你的主目录中会有很多文件夹。最好的做法是在主目录中创建一个 `Music` 文件夹（就像你为 graphika 账户创建的那样），并将其设置为抓取音乐的默认位置。

要在 Sound Juicer 内部设置默认值，进入 **Menu（菜单）** 并选择 **Preferences（偏好）**。这将打开偏好窗口，你可以点击 **Folder（文件夹）**旁边的按钮（此时按钮应显示为 `Home`），然后在出现的菜单中选择 **Other（其他）**。之后，浏览到你的 `Music` 文件夹，在列表中点击一次选中它，然后点击 **Open（打开）** 按钮。

## 在 Sound Juicer 中抓取和编码音频文件

要抓取驱动器中 CD 的音频轨道，你首先需要选择你想要编码曲目的格式。为此，请进入 **Edit（编辑）** > **Preferences（偏好）**，然后在 **Output Format（输出格式）** 菜单中选择你喜欢的编码格式。大部分情况下是 **MP3 (MP3 audio)**，或者在 Linux 世界中的 **CD Quality, Lossy (Ogg multimedia)**（CD 品质有损 Ogg 多媒体）。做出选择后，点击 **Close（关闭）**。

之后，你需要点击 Sound Juicer 窗口底部的 **Extract（提取）** 按钮来抓取并编码 CD 上的所有轨道。如果有某些你不想抓取和编码的曲目，在点击 Extract 之前取消勾选这些名称旁边的复选框。如果你只想抓取和编码列表中的几首歌，最好先进入 Edit 菜单，选择 Deselect All（取消全选），然后勾选你想抓取的歌曲旁边的复选框，最后再点击 Extract。

在歌曲抓取和编码期间，Sound Juicer 会在窗口左下角显示进度，完成后，它会在一个小窗口中通知你。收到该消息后，点击 Close。你可以通过 File（文件）菜单并选择 Eject（弹出）来推出 CD。如果你想抓取和编码另一张 CD，和第一张一样，Sound Juicer 将自动启动并在应用程序窗口中显示 CD 标题、艺术家名称以及所有曲目的标题。

完成抓取后，你可以查看结果。添加文件和文件夹最简单的方法是将要添加到库的文件夹或歌曲拖入 Rhythmbox 窗口的右侧窗格。你也可以通过右键点击文件，并在弹出菜单中选择 **Open ▶ Open with Rhythmbox Music Player（打开 ▶ 使用 Rhythmbox 播放器打开）** 直接将歌曲添加到库中。

Rhythmbox 结合 Sound Juicer，允许你直接从 CD 将歌曲添加到库中，尽管这种方式方式有些间接。要执行此操作，选择音乐 (Music) ▸ 音频 CD (Import Audio CD)，Sound Juicer 就会出现并显示你当前驱动器中的 CD 内容。之后，你可以像通常在 Sound Juicer 中操作那样对歌曲进行抓取和编码。完成后，歌曲将自动出现在 Rhythmbox 库中。

## 浏览 Rhythmbox 库

Rhythmbox 库是你添加的所有音乐的集合，随着收藏数量的增加，它可能会变得有些臃肿。幸运的是，Rhythmbox 拥有更优秀的浏览功能，类似于 iTunes 中的功能，允许你查看库中的艺术家和专辑列表。如果你点击窗格中的某个特定艺术家，右窗格将会出现该艺术者的专辑列表。然后你可以双击右窗格中的某个专辑进行播放。如果你想播放该艺术家的所有专辑，只需双击左窗格中的艺术家名称即可。总而言之，这是一个非常实用的功能。

如果你想为浏览添加额外的分类层，只需前往编辑 (Edit) 菜单，选择偏好 (Preferences)，在弹出的窗口中选择常规 (General) 选项页，然后选择流派 (Genres)、艺术家 (artists) 和专辑 (albums)。点击偏好中的关闭按钮后，你将在 Rhythmbox 中获得一个三窗格浏览器（图 1-4）。

## 在 Rhythmbox 中创建播放列表

当然，你可以进行更进一步的定制，以适应每种情况和心情。毕竟，总有些时候你会觉得精力充沛到听不了凯莉·克拉克森（Kelly Clarkson）（谢天如此）。为了应对这些时刻，你可以创建播放列表，即按预顺序播放的歌曲列表。只需将每个播放列表想象成一个点播电台……所有的点歌都是你的。

要在 Rhythmbox 中创建播放列表，前往音乐 (Music) 菜单并选择播放列表 (Playlist) ▶ 新播放列表 (New Playlist)。当播放列表图标出现在 Rhythmbox 窗口的左窗格时，为列表输入一个名称，然后只需将歌曲从库窗格拖动到播放列表图标即可添加歌曲。歌曲本身仍留在库中，因此你并没有在移动任何东西——只是创建了别名。

你还可以创建自动播放列表，这种列表会自动扫描库以寻找符合你创建标准的歌曲。你可以选择为库中特定艺术家或特定流派的所有歌曲创建一个列表。要执行此操作，选择音乐 (Music) ▶ 播放列表 (Playlist) ▶ 自动播放列表 (Automatic Playlist)。将会弹出一个窗口，你可以在其中指定列表的内容。

创建好列表后，可以通过单击一次列表然后点击窗口顶部的播放按钮来播放，或者直接双击列表进行播放。

## 使用 Rhythmbox 流媒体

除了播放硬盘上的音乐外，Rhythmbox 还允许你播放 MP3 或 Ogg Vorbis 格式的网络电台流。要添加流媒体，请点击 Rhythmbox 窗口左窗格中的电台 (Radio) 图标，你将面对……嗯，不是第一次了。尽管如此，你仍然可以尝试可用内容。确保你已上线并双击列出的电台之一，你的电脑就会开始播放从互联网电台下载的音乐。

一旦你体验了 Rhythmbox 的电台功能，你就会大为满足了。为了丰富你的听觉食谱，你可以点击“新建互联网电台”(New Internet Radio Station)按钮添加新的流媒体。当“新建互联网电台”窗口出现时，输入流媒体的 URL，然后点击添加。如果你希望流以名称而非 URL 的形式出现在列表中，只需右键点击该流的条目，在弹出菜单中选择属性 (Properties)，然后在属性窗口中进行相应更改。

啊，但你问我在哪里找到这些电台呢？要获取最大的 MP3 流集合，请访问 `shoutcast.com`，找到你感兴趣的流，右键点击该流的收听 (Tune In) 按钮，然后在弹出菜单中选择复制链接位置 (Copy Link Location)。之后，将 URL 粘贴到 Rhythmbox“新建互联网电台”窗口的 URL 框中，并点击添加。然后双击 Rhythmbox 窗口的右窗格即可播放。
