
在下一个示例中，用户想要调用 `wc`（字计数）命令来检查文件的行数，但什么都没有发生，他不得不使用 `Ctrl+C` 组合键：

```
jumper-> wc -l test

(Ctrl-C)
jumper-> which wc
wc is hashed /home/jumper/bin/wc
jumper-> echo $PATH
/home/jumper/bin:/usr/local/bin:/usr/sbin:/usr/X11R6/bin:/usr/bin:/usr/sbin:/bin
```

### Shell 概述

- `bash` 或 Bourne Again Shell：GNU Shell，直观且灵活。对于初学者来说，这可能是最建议使用的 Shell；同时，它对于所谓的高级和专业用户来说也是一个强大的工具。在 Linux 上，`bash` 是普通用户的标准 shell。它是 Bourne shell 的一个超集，包含一组附加组件和插件。这意味着 Bourne Again Shell 兼容 Bourne shell；在 `sh` 中可以运行的命令在 `bash` 中同样可以运行。然而，反之并不如此。本书中的示例和练习均使用 `bash`。

- `csh` 或 C shell：其语法类似于 C 语言语言。有时受到程序员的青睐。

- `tcsh` 或 Turbo C Shell：常用 C Shell 的超集，增强了用户友好性和速度。

- `ksh` 或 Korn shell：有时受到具有 UNIX 背景的人士的青睐。它是 Bourne shell 的超集；在标准配置下，对于初学者来说是一场噩梦。

`/etc/shells` 文件给出了 Linux 系统上已知 shell 的概览：

```
mia-> cat /etc/shells
/bin/bash
/bin/sh
/bin/tcsh
/bin/csh
```

## 伪 Bourne shell

那个 `/bin/sh` 通常是 Bash 的链接，当调用它时，它将以 Bourne shell 兼容模式执行。

你的默认 shell 设置在 `/etc/passwd` 文件中，对于用户 `mia` 所示：

```
mia:L2NofqdlPrHWe:504:504:Mia Maya:/home/mia:/bin/bash
```

要从一个 shell 切换到另一个，只需在活动终端中输入新 shell 的名称。系统通过 `PATH` 设置查找该名称所在的目录，shell 是一个可执行文件（程序），当前 shell 会激活它并执行它。通常会显示提示符，因为 shell 有其典型的外观：

```
mia-> tcsh
[mia@post21 ~]$
```

## 我正在使用哪个 shell？

如果你不知道自己正在使用哪个 shell，可以检查 `/etc/passwd` 中你账户所在的行，或者输入命令：

```
echo $SHELL
```

## 你的主目录

你的主目录是你连接系统的默认目标。在大多数情况下，它是 `/home` 的子目录，但这可能有所不同。你的主目录可能位于远程文件服务器的硬盘上；在这种情况下，你的主目录可能会在 `/nethome/your_user_name`。

在另一种情况下，系统管理员可能选择了不太容易理解的布局，你的主目录可能在 `/disk6/HU/07/jgillardard`。

无论主目录路径是什么，你都不需要太担心。主目录的正确路径存储在 `HOME` 环境变量中，以防某些人需要。你可以使用 `echo` 命令显示此变量的内容：

```
orlando@ echo $HOME
/home/orlando
```

你可以在主目录中做任何你想做的事。你可以在许多目录中放置任意数量的文件，尽管数据和文件的总量自然地受到硬件和分区大小的限制，有时系统管理员还应用了配额系统。在硬盘空间昂昂的时代，限制磁盘使用是常见做法。现在，限制几乎完全应用于大容量。你可以通过你的配额（quota）自行查看是否设置了限制：

```
pierre@lamaison:- -v
Diskquot for user pierre (uid 501): none
```

如果设置了配额，可以获取受限分区列表及其超出限制。在宽限期内可能会容忍超出限制，且限制较少或完全没有。可以使用 `info quota` 或 `man quota` 命令查找详细信息。

### 无配额？

如果你的系统找不到配额，则没有对文件系统使用应用任何限制。

你的主目录由波浪号 (`~`) 表示，它是 `/path_to_home/user_name` 的简写。相同的路径存储在 `HOME` 变量中，因此你不需要做任何操作来激活它。一个简单的应用：使用一个优雅的命令从主目录下的 `/var/music/albums/arno/2001` 切换到 `images`：

```
rom:/var/music/albums/arno/2001 cd -~/images
rom:~/pwd
/home/rom/images
```

在本章后面的部分，我们将讨论管理文件和目录的命令，以便维护你的主目录。

## 最重要的配置文件

如前所述，大多数配置文件存储在 `/etc` 目录。可以使用 `cat` 命令查看内容，该命令将文本文件发送到标准输出（通常是你的显示器）。语法非常直观：

```
cat file2 ... fileN
```

在这一部分，我们尝试对最常见的配置文件提供概览。这显然不是一个完整的列表。添加额外的软件包也向 `/etc` 中添加额外的配置文件。在阅读这些配置文件时，你会发现它们通常注释得非常好且自显其义。某些文件还包含额外文档的页面，例如 `man` 组。
