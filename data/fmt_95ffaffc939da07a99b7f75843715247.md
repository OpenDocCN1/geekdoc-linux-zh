
使用 `dpkg` 命令检查软件包是否安装。例如，如果你想知道机器上安装了哪个版本的 Gallery：

```
nhtsw@gorefest:-$ dpkg -l *gallery*
Desired=Unknown/Install/Remove/Purge/Unpacked/Failed-config/Half-installed
Status=Not/Installed/Config-files/Err=(none)/Hold/Reinst-required
 Name            Version         Description
=================================================================
ii gallery         1.5-isarge2      a web-photo album written in php
```

“ii”前缀表示软件包已安装。你应该看到“un”前缀，这意味着软件包在记录列表中，但尚未安装。

使用 `dpkg -S` 搜索文件属于哪个软件包：

```
nhtsw@gorefest:-$ dpkg -S /bin/cat
coreutils:/bin/cat
```

更多信息可以在 `dpkg` 的 Info 中找到。

## 源软件包

Linux 程序的大部分是开源的，因此这些程序都有源包。程序的源码可以从网站下载，也可以以压缩 tar 包（`program-version.tar.gz` 或类似）的形式。对于基于 RPM 的发行版，源码通常在 `program-version.src.rpm` 中。Debian 及其大多数基于它的发行版提供了适配后的源码，可以通过 `apt-get source` 获取。

特定的需求、依赖项和安装说明在 `README` 文件中提供。你可能需要一个 C 编译器 `gcc`。这个 GNU 编译器包含在大多数 Linux 系统中，并移植到了许多其他平台。

## 自动化包管理与更新

### 通用说明

安装新系统后，你做的第一件事就是应用更新；这适用于所有的操作系统。Linux也不例外。

大多数 Linux 系统的更新通常可以在镜像你所在发行版的附近站点找到。提供此类服务的站点列表可以在你发行版的网站上找到，参见附录 A，“从这里以后去哪里？”。

如果可能，应该定期应用更新——但每隔几周一次是一个合理的开始。你真的应该尝试保持你的发行版的最新版本，因为 Linux 在不断变化中。正如我们之前提到的，新功能、改进和修复会以固定的节奏提供，并且重要的安全问题也会得到解决。

好消息是，大多数 Linux 发行版都提供了工具，让你不需要手动升级几十个软件包。接下来的章节概述了包管理器管理器。关于这个主题还有很多内容，甚至源包的定期更新也可以自动管理；我们只列出了常见的系统。请务必参考你特定发行版的文档以获取建议的操作。

### APT

高级软件包工具（Advanced Package Tool）是一个软件包管理系统。用于处理软件包的命令行工具是 `apt-get`，它附带了一份优秀的帮助页（man page），描述了如何安装和更新软件包，以及如何升级单个软件包或整个发行版。APT 起根于 Debian/GNU 发行版，在那里它是 Debian 软件包的默认管理器。APT 也被移植用于处理 RPM 软件包。APT 的主要优势是它是免费且灵活的，它允许你建立与后文列出的特定发行版（在某些情况下是商业性的）类似的系统。

通常，在第一次使用 `apt-get` 时，你需要获取可用软件包的索引。通过以下命令完成：

```bash
apt-get update
```

之后，你可以使用 `apt-get` 升级你的系统：

```bash
apt-get upgrade
```

经常执行此操作，这是保持系统更新并确保安全的简单方法。

除了这种通用用法外，`apt-get` 安装单个软件包的速度也非常快。它的工作原理如下：

```bash
[david@jupiter ~] su -c "apt-get install snow"
Password:
Reading Package Lists... Done
Building Dependency Tree... Done
The following NEW packages will be installed:
snow
0 packages upgraded, 1 newly installed, 0 removed and 3 not upgraded.
```

解压后将使用 104kB 的额外磁盘空间。

Get:1 http://ayo.freshrms.net redhat/yo/i386/snow 1.42-10 [33.6kb]

Executing RPM (-Uvh) ...

```bash

Preparing...
```

注意 `su` 命令的 `-c` 选项，它指示 root shell 仅执行此命令，然后返回用户环境。这样一来，你就不会忘记退出 root 账户。

如果有任何其他软件包的依赖关系，`apt-get` 将下载并安装这些支持性软件包。更多信息可以在 APT HOWTO [http://www.debian.org/doc/user-manuals/apt-how-to] 中找到。

## 使用 RPM 软件包的系统

Updateget 最初只支持 RedHat 软件包，现在已移植到更广泛的软件中，包括非 RedHat 存储库。这为 RedHat 或 Fedora 核心上的 RPM 软件包更新提供了一个完整的系统。在命令行上，使用 `update2` 更新你的系统。在桌面上，会激活一个默认图标，告诉你的系统是否有可用更新。

Yellow's Updater (`yum`) 是另一个最近变得流行的工具。它是一个交互但自动的程序，用于在系统上安装、更新或删除 RPM 软件包。它是 Fedora 用户的首选工具。

在 SuSE Linux 上，一切通过 YaST 完成，这是另一个设置工具，它支持各种系统管理任务，其中包括更新 RPM 软件包。从 SuSE Linux 7.1 开始，你还可以使用网络界面和 YU（Last Online Update）进行升级。

Mandra Linux 和 Mandriva 提供了所谓的 RPMI 工具，这是一组让安装新软件更方便的程序。这些工具使用 RPMrake 和 MandrakeUpdate 来提供软件软件包的平滑安装和卸载。Mandrake-Online 提供了更广泛的服务，并当你的特定 Mandrake 系统可用更新时自动通知管理员。更多信息请参见 `upgrade`。

此外，KDE 和 Gnome 桌面套件也有它们自己的（图形化）版本包管理器。

## 升级你的内核

如果你定期升级发行版，大多数 Linux 安装都是没问题的。升级程序会在需要时安装新内核并对你的系统做出所有必要的更改。只有当你需要 Linux 发行版默认内核不支持的内核功能时，才应该编译或安装新内核。

无论是编译优化的内核还是使用预编译的内核包，都将其与旧内核共存，直到一切按计划运行。

然后，通过更新引导加载程序配置文件 `grub.conf` 创建一个双引导系统，允许你选择启动哪个内核。这是一个简单的示例：

```bash
## grub.conf generated by anaconda
#
# 注意：在更改配置后你不需要重新运行 grub。
# 注意：你有一个 /boot 分区。这意味着
# /boot/grub/grub.cfg 是被读取的文件。
# 不要编辑 grub.cfg。请改编辑 vmlinuz 和 initrd 文件。
## 或者编辑 /boot/grub/grub.conf。
#
## 以下是 grub.conf 文件的示例：
### default 0
### menuentry "Linux" {
#     kernel /boot/vmlinuz-2.6.9-6-i686 root=/dev/sda
#     initrd /boot/initrd-2.6.9-6-i686
# }
### menuentry "Old kernel" {
#     kernel /boot/vmlinuz-2.6.8-i686 root=/dev/sda
#     initrd /boot/initrd-2.6.8-i686
# }
```
