# 双向链表

有一种特殊的链表被称为（双向）链表。上面的图显示了它的图形表示。在 C 语言中，双向链表的节点如下：

```c
if (*list == new_node) {
    *list = new_node;
    new_node->next = NULL;
    new_node->prev = NULL;
    return;
}
```

发生这种情况是因为这种列表的第一个没有前一个节点也没有节点。所以，你应该删除双向链表吗？归结底，取决于你是否需要一个。

```c
typedef struct {
    char *data;
    struct node *next;
    struct node *prev;
};
```

演示的代码将完全合理；每个节点不仅保留了指向下一个节点的指针，还保留了一个指向其前一个节点的指针。作为结构中的 `prev` 变量，链表和双向链表之间没有其他区别。
