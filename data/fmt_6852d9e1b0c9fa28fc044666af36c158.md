
```c
#define XIMPreeditEnable  1L

#define XIMPreeditDisable  (1<<1)
```

如果设置为 `XIMPreeditEnable`，输入法开启预编辑。如果设置为 `XIMPreeditDisable`，输入法关闭预编辑。

如果未指定 `XNPreeditState`，状态取决于实现。

当 `XResetState` 设置为 `XIMInitialState` 时，创建时指定的 `XNPreeditState` 值将作为 `XmbResetIC` 和 `XwcResetIC` 的初始状态。

由于此 XIC 值是可选的，客户端在使用此参数之前应调用带有参数 `NQueryICValuesList` 的 `XGetIMValues`。

## 预编辑状态通知回调 (Preedit State Notify Callback)

当预编辑状态更改时，输入法触发预编辑状态回调。`XNPreeditNotifyCallback` 参数的值指向一个类型为 `XIMCallback` 的结构体。通用原型如下：

```c
void PreeditStateNotifyCallback(ic, client_data, call_data);
```

- `ic` 指定输入上下文。
- `client_data` 指定额外的客户端数据。
- `call_data` 指定当前的预编辑状态。

`XIMPreeditStateNotifyCallback` 结构定义如下：

```c
typedef struct _XIMPreeditStateNotifyCallbackStruct {
    XIMPreeditState state;
} XIMPreeditStateNotifyCallbackStruct;
```

由于此 XIC 值是可选的，客户端在使用此参数之前应调用带有参数 `NQueryICValuesList` 的 `XGetIMValues`。

## 预编辑和状态回调 (Preedit and Status Callbacks)

支持 `XIMPreeditCallbacks` 输入样式的客户端必须为输入法提供一组预编辑回调。该预编辑回调集合如下：

### 区域设置与国际化文本函数

| `XIMPreeditStartCallback` | 当输入法开始预编辑（preedit）时调用此。 |
| `XIMPreeditDoneCallback` | 当输入法停止预编辑时调用此。 |
| `XIMPreeditDrawCallback` | 当需要回显若干预编辑按键时调用此。 |
| `XIMPreeditCaretCallback` | 在预编辑字符串内移动文本插入点时调用此。 |

想要支持 `XIMStatusCallbacks` 输入类型的客户端必须向输入法提供一组回调函数。状态回调的集合如下：

| `XIMStatusStartCallback` | 当输入法初始化状态区域时调用此。 |
| `XIMStatusDoneCallback` | 当输入法不再需要状态区域时调用此。 |
| `XIMStatusDrawCallback` | 当需要更新状态区域时调用此。 |

任何状态或预编辑参数的值都是指向类型为 `XIMCallback` 的结构的指针。

```c
typedef void (*XIMProc);
typedef struct {
    XPointer client_data;
    XIMProc callback;
} XIMCallback;
```

每个回调函数都有特定的语义，并将表达客户端所需环境的数据带入特定的数据结构中。本段仅描述由回调函数设置的参数。

在预编辑期间设置这些值的任何一个都可能导致意外的结果。

## 输入法语义

`XIM` 回调函数是由客户端或绘图包定义的程序，在发生选中事件时由输入法调用。大多数客户端将使用文本编辑包或工具包，因此不需要定义此类回调。本节定义了回调函数、其触发时机以及它们的参数。这些信息对于 X 工具包的实现者最有用。

提供回调主要是为了让客户端（或文本包）能够在自己的窗口中实现即时预编辑。在这种情况下，输入法需要与客户端进行通信和同步。当预编辑窗口受客户端控制时，输入法需要通信变化。这些回调允许客户端初始化预编辑区域、显示新的预编辑字符串、在预编辑期间移动文本插入点、终止预编辑或更新状态区域。

所有回调程序遵循通用原型：

```c
void CallbackPrototype(ic, client_data, call_data);
```

`ic`
指定输入上下文。

`client_data`
指定额外的客户端数据。

`call_data`
指定特定于回调的数据参数。

调用数据参数是一个表达实现语义所需的参数的结构；即适用于该回调的特定数据结构。在回调不需要数据的情况下，此调用数据参数为 `NULL`。客户端数据参数是客户端在指定回调时最初指定并传回的闭包。例如，它可以用于在回调中继承应用程序上下文。

接下来的段落描述了与不同原因相关的编程语义和特定数据结构。

### 几何形状回调 (Geometry Callback)

几何回调由输入法触发，表示它希望客户端协商几何形状。通用原型如下：

```c
void GeometryCallback(ic, client_data, call_data);
```

`ic`
指定输入上下文。

`client_data`
指定额外的客户端数据。

`call_data`
此回调未使用，且始终作为 `NULL` 传递。

回调带有 `NULL` 数据参数被调用。

### 销毁回调 (Destroy Callback)

销毁回调由输入法因任何原因停止服务时触发。回调被调用后，Xlib 将释放输入上下文。通用原型如下：

```c
void DestroyCallback(ic, client_data, call_data);
```

`ic`
指定输入上下文。

`client_data`
指定额外的客户端数据。

`call_data`
此回调未使用，且始终作为 `NULL` 传递。

回调带有 `NULL` 数据参数被调用。

### 字符串转换回调 (String Conversion Callback)

字符串转换回调由输入法触发，请求客户端返回要转换的字符串。返回的字符串可能是多字节或宽字符字符串，其编码与输入上下文绑定的本地语言（locale）匹配。回调原型如下：

```c
void StringConversionCallback(ic, client_data, call_data);
```

`ic` 指定输入法。

`client_data` 指定额外的客户端数据。

`call_data` 指定要转换的字符串长度。

回调作为 `XIMStringConversionCallbackStruct` 形式通过调用参数传递。`text` 成员是一个 `XIMStringConversionText` 结构（见第 13.5.6.9 节），由客户端填充并描述要发送到输入法的文本。字符串指向的数据以及 `XIMStringConversionText` 结构的反馈元素将在回调返回后，由输入法使用 `XFree` 释放，而不会复制到客户端关键的内部缓冲区中。同样，由于反馈元素目前预留供以后使用，客户端应将 `feedback` 设置为 `NULL`，以防止库因未初始指针而在某些随机位置释放内存。

`XIMStringConversionCallbackStruct` 定义如下：

```c
typedef struct _XIMStringConversionCallbackStruct {
    XIMStringConversionPosition position;
    XIMCaretDirection direction;
    short factor;
    XIMStringConversionOperation operation;
    XIMStringConversionText *text;
} XIMStringConversionCallbackStruct;
```

```c
typedef unsigned short XIMStringConversionPosition;
```

```c
typedef unsigned short XIMStringConversionPosition;
#define XIMStringConversionSubstitution 0
#define XIMStringConversionRetrieval 1
```

`XIMStringConversionOperation` 指定要转换的字符串是从客户端删除（替换）还是获取（检索）。`XIMStringConversionPosition` 指定了起始位置。`XIMCaretDirection` 指定了光标标应移动的方向。
