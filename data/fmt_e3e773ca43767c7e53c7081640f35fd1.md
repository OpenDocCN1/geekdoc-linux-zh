
# K Shell 编程示例

# $\Gamma_L(f) = \frac{Z_L}{Z_0}$

```bash
let ntimes=0
while (( ntimes < 50 )); do
  print -u4 'p lbo'
  # Send command to coprocess
  read -ru3 timebolt
  # Read output from coprocess
  print $timebolt >> times
  let ntimes=ntimes+1
done
```
