## idxbib — 为文献数据库创建倒排索引

### 概要
```
/usr/bin/idxbib database-file...
```

## 描述
参考文献是一组构成文献信息字段的行。每个字段都从以 `%` 开头的行开始，随后是一个键字母、一个空格，最后是字段的内容，该内容可能会持续到下一行以 `%` 开头的行。一个数据库包含由空行分隔的参考文献（或其他类型的信息）。

`idxbib` 为指定的 `database-file`（必须位于当前目录内）创建一个倒排索引，通常供 `lookbib(1)` 和 `refer(1)` 使用。作为输出，它会在工作目录下创建一个条目文件（`.ia` 后缀）、位置文件（`.ib`）和标签文件（`.ic`）。

`idxbib` 是一个 `shell` 脚本，它调用程序 `/usr/lib/refer/mkey` 和 `/usr/lib/refer/inv.mkey`，将单词截断为 6 个字符，并将大写映射为小写。它还会丢弃短于 3 个字符的单词、100 个常用英语单词中的单词以及小于 1000 或大于 2099 的数字（日期）。你可以更改这些参数。

### Bug
所有的日期可能都应该被索引，因为许多学科引用 1800 年或更早的文献。
`idxbib` 不识别路径名。

## 示例
以下示例在名为 `bibliography` 的文献数据库上运行 `idxbib` 命令，并显示输出文件的内容。

```
castle$ idxbib bibliography

castle$ more bibliography.*

:::

:::

:

ibliography.ia

:::

:::

:

((((((((((((<<<<<<<<<<<<<<<<<<<<PPPPPPPPTdddddddddd

:::

:::

:

ibliography.ib

:::

:::

:

(>)(>)(>)(>)(>)(>)(>)(>)(>)(>)(>)(>)(>)(>)))) >)))) >)))))

ibliography.ic

:::

:::

:

ibliography:0,721

ibliography:721,720

ibliography:1441,720

ibliography:2161,720

caste$
```

## 文件
- `/usr/lib/refer/mkey`: 用于映射文献数据库。
- `/usr/lib/refer/inv`: 用于反转文献数据库。
- `x.ia`: 条目文件。
- `x.ib`: 位置文件。
- `x.ic`: 标签文件。
- `x.ig`: 引用文件。
