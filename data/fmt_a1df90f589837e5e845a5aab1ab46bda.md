
### `open(filename, mode[, encoding, errors, buffering])`

在给定的模式下 `filename` 会根据 `encoding` 中指定的编码提供透明的数据编码/解码。`errors` 为 'strict'、'ignore'、'replace'、'backslashreplace' 或 'xmlcharrefreplace'。默认值为 'strict'。`buffering` 的含义与内置 `open()` 函数相同。无论指定何种模式，底层文件始终以二进制模式打开。`codecs.open()`。

### `EncodedFile(file, inputenc, outputenc [, errors])`

该类为现有文件对象 `file` 提供编码封装器。写入文件的数据将根据输入编码 `inputenc` 进行解释，然后使用输出编码 `outputenc` 写入文件。从文件中读取的数据将根据 `inputenc` 进行解码。如果省略了 `outputenc`，则它默认为 `inputenc`。`errors` 的含义与 `open()` 相同，且默认为 'strict'。

### `iterencode(iterable, encoding [,])`

一个生成器函数，按指定的 `encoding` 增量编码 `iterable` 中的所有字符串。`errors` 默认为 'strict'。

### `iterdecode(iterable, encoding [,])`

一个生成器函数，按指定的 `encoding` 增量解码 `iterable` 中的所有字节字符串。`errors` 默认为 'strict'。

## 有用常量

`codecs` 定义了以下字节序标记常量，当你不了解底层编码时可以使用它们帮助解释文件。这些字节序标记有时写在文件开头，指示其字符编码，并可用于选择合适的解码器。

| 常量 | 说明 |
|---|---|

| `BOM_BE` | 大端序字节序标记 ('\xff\xfe') |
| `BOM_LE` | 小端序字节序标记 ('\xfe\xff') |

| `BOM_UTF16_BE` | 16位 UTF-16 大端序 ('\xff\xfe') |
| `BOM_UTF16_LE` | 16位 UTF-16 小端序 ('\xfe\xff') |
| `BOM_UTF32_BE` | 32位 UTF-32 大端序 ('\x00\x00\xfe\xff') |
| `BOM_UTF32_LE` | 32位 UTF-32 小端序 ('\xff\xfe\x00\x00') |

### 注意事项

* 关于 `codecs` 模块的更多信息见第 9 章“输入与输出”。
* 对 `encode()` 和 `decode()` 操作的输入需要非常小心。所有的 `encode()` 操作都应该是 Unicode 字符串，而 `decode()` 操作应该是字节字符串。Python 2 在这方面并不完全一致；例如，Python 3 严格区分字符串和字节。

## `re`

`re` 模块用于在字符串中执行正则表达式匹配和替换。它支持 Unicode 字符串和字节字符串。正则表达式模式被指定为包含文本和特殊字符序列的字符串，在本节的剩余部分，这些序列通常以“原始”字符串的形式编写，用原始字符串语法表示。

## 模式语法

正则表达式模式中识别以下特殊字符序列：

| 字符 | 说明 |
| --- | --- |
| `text` | 匹配字面字符串。 |
| `^` | 匹配除换行符外的任意字符。 |
| `$` | 匹配字符串的末尾。 |
| `*` | 匹配前面表达式的零次或多次重复。 |
| `+` | 匹配前面表达式的一次或多次重复。 |
| `?` | 匹配前面表达式的零次或一次重复。 |
| `*?` | 匹配前面表达式的零次或多次重复。 |
| `+?` | 匹配前面表达式的一次或多次重复。 |
| `??` | 匹配前面表达式的零次或一次重复。 |
| `{m}` | 匹配前面表达式的正好 m 次重复。 |
| `{m, n}` | 匹配前面表达式的 m 到 n 次重复。如果省略 m，则默认为 0。如果省略 n，则默认为无限。 |
| `{m, n}?` | 匹配前面表达式的 m 到 n 次重复。 |
| `[...]` | 匹配字符集，如 `[abcdef]` 或 `[a-zA-Z]`。特殊字符 * 在集合内部不激活，例如 `[0-9]`。 |
| `A|B` | 匹配 A 或 B，其中 A 和 B 都是正则表达式。 |
| `(...)` | 将括号内的正则表达式作为一个组进行匹配，并保存子字符串。该组的内容可以通过匹配时获取的 `MatchObject` 对象的 `group()` 方法来获取。 |

| 字符(s) | 说明 |
|---|---|
| `(?amsux)` | 将字母 "a", "i", "L", "m", "s", "u", 和 "x" 解释为传递给 `re.compile()` 的 `re.A`, `re.I`, `re.L`, `re.M`, `re.S`, `re.X` 标志设置。"a" 仅在 Python 3 中可用。 |
| `(?...)` | 匹配括号内的正则表达式但丢弃匹配到的子字符串。 |
| `(?P<name>...)` | 匹配括号内的正则表达式并创建一个命名组。组名必须是有效的 Python 标识符。 |
| `(?P=name)` | 匹配之前某个命名组所到的相同文本。 |
| `(?=...)` | 注释。括号内的内容被忽略。只有当后面跟着括号内的模式时，才会发生匹配。例如，`r'Hello(?=World)'` 仅在后面跟着 'World' 时匹配 'Hello'。 |
| `(!...)` | 如果后面没有跟着括号内的模式，则匹配该表达式。例如，`r'Hello(!World)'` 仅在后面不是 'World' 时匹配 'Hello'。 |
| `(?<=...)` | 如果前面是括号内模式的匹配，则匹配该表达式。例如，`r'(?<=abc)` 仅在前面是 'abc' 时匹配 'def'。 |
| `(?<!...)` | 如果前面不是括号内模式的匹配，则匹配该表达式。例如，`r'(?<!abc)` 仅在前面不是 'abc' 时匹配 'def'。 |
| `(?id<name>ypat)` | 检查由 id 或 name 指定的正则表达式是否存在。如果不存在，则匹配可选的表达式 ypat。例如，模式 `r'(Hello)?(?1)(Howdy)'` 匹配 'Hello Howdy' 或字符串 'Howdy'。 |

特殊的转义字符如 `'\n'` 和 `'\t'` 被识别为标准字符（例如，`r'\n+'` 将匹配一个或多个换行符）。此外，在正则表达式中通常具有特殊含义的字面符号可以通过在其前面加上反斜杠来指定。例如，`r'\*'` 匹配字符 *。此外，

| 字符(s) | 说明 |
|---|---|
| `\number` | 匹配之前组编号匹配的文本。组从左到右编号为 1 到 9。 |
| `\A` | 仅匹配开头或结尾的空字符串。 |
| `\b` | 匹配以空白字符或其他非字母数字字符终止的字母数字序列。 |
