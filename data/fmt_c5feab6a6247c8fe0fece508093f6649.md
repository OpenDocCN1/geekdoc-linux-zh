## 分析命令

如果你想进一步了解某个特定命令，可以使用 `timex`，它会报告执行命令消耗的经过时间、用户时间和系统时间。`timex` 的用处在于它可以让你了解在发布命令时消耗的资源。以下是使用 `timex -s` 在 Solaris 上报告“总计”的两个示例：

```
$ timex listing

real            0.02

user            0.00

sys             0.02
```

```
$ timex -s listing

real            0.02

user            0.00

sys             0.01
```
