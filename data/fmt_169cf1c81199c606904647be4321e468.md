### 12.2.5 MIPS

## 指令清单12.17 Optimizing GCC 4.4.5 (IDA)

```
my_abs:

; jump $a0<0:

    blz $a0, locret_10

; just return input value ($a0) in $v0:

    move $v0, $a0

    jr $ra

locret_10:

; negate input value and store in $v0:

    jr $ra

    or $at, $zero; branch delay slot, NOP

($v0=0-$a0)

```

这里出现了新指令`BLTZ` (Branch if Less Than Zero)，以及仿指令`NEGU`。`NEGU`指令计算减去操作数的差。`SUBU`和`NEGU`指令中的后继U代表的操作数是无符号整数类型，并且在整数溢出的情况下不会触发异常处理机制。
