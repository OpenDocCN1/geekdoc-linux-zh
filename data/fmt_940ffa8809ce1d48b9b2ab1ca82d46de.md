
无论卷组状态如何，关闭系统上所有定义的 SSA 磁盘标识指示灯。因此，我们运行 `all_defined_pdisks` 函数。如果命令行上有两个参数，且其中一个是 `-y` 或 `-V`，那么我们就只对变体卷组中的 SSA 磁盘进行操作，关闭每一个 SSA 标识指示灯。

最后一个选项是在命令行上提供 `hdisk` 或 `pdisk`。我们知道此选项将针对用户指定的磁盘操作，并仅开启或关闭这些磁盘。我们允许 `hdisk` 和 `pdisk`，在调用 `list_of_disks` 函数之前，我们需要将所有的定义转换为 `pdisk`。为了实现这一点，我们利用命令行参数的 `echo` 效果并搜索 `disk` 单词。通过在列表情况中使用这一点，我们可以检测到 `hdisk` 或 `pdisk` 的存在。对于找到的每一个项，将其添加到 `HDISKLIST` 或 `PDISKLIST` 变量。测试后，我们检查 `HDISKLIST` 变量是否已赋值，这意味着该变量不为空。如果有条目，我们将 `hdisk` 转换为其关联的 `pdisk` 并在 `PDISKLIST` 变量中构建 `pdisk`。当列表完成且不为空时，我们调用 `list_of_disks` 函数。这个 shell 脚本就此。

## 伪随机数生成

在编写 shell 脚本时，我们有时会遇到这样的情况：创建文件的速度快于我们生成唯一文件名的速度。大多数情况下，可以将日期/时间戳作为文件名的后缀，但如果我们每秒创建多个文件，最终会在一秒内覆盖同一个文件。为了解决这个问题，我们可以创建伪随机数，并将其追加到日期/时间戳之后的文件之后。你可能记得在第 10 章中，我们研究过如何使用计算机生成的数字作为包含键盘字符的数组元素的指针，来创建伪随机密码。本章将对随机性进行深入讨论。

## 什么是随机数的决定因素？

在计算机系统中创建真正的随机数是非常困难的。问题在于数字的可重复和可预测性。当你开始研究数字时，会很快进入深奥的数学理论领域，许多研究人员对随机性持有不同意见。我知道的唯一真随机数是放射性衰变事件的频率变化和白噪声的频率。放射性衰变事件必须以某种方式被检测到，由于我们不想在周围使用任何放射性材料，我们可以使用称为伪随机数生成器的内置计算机程序。计算机技术能够创建适用于加密密钥和加密安全通信链路的数字。其中一些技术包括测量击键之间的时间，并使用此测量值作为内存地址的内容。

一种流行的 Unix 方法是使用名为 `/dev/random` 的特殊 Unix 设备。如果你在互联网上搜索 `/dev/random`，你将在关于随机性的主题上找到想象中更多的信息。随机性是一个讨论话题，许多领域的专家持有广泛不同的观点。我不是随机性专家，这个主题超出了本书的范围。我们在本章将集中于创建伪随机数以生成唯一文件名。

我们创建的数字对于任何类型的加密来说都不够随机，因为它们是重复且循环的，但我们将创建唯一的文件名。Shell 提供了一个环境变量——你猜对了吧——`RANDOM`。这个伪随机数生成器使用一个种子作为起点来创建数字。这是初始化种子的好方法。

## 方法

在本章中，我们将查看三种生成伪随机数的技巧：

- 在 0 和最大允许值（32767）之间创建数字
- 在 1 和用户定义的最大值之间创建数字
- 创建带有前导零的固定长度数字

## 方法 1：在 0 到 32767 之间创建数字

使用这种默认方法创建伪随机数是使用 `RANDOM` 变量的最简单方法。我们只需要初始化一个初始种子并使用 `echo` 命令显示新数字。数字范围在 0 到 32767 之间，这是 `RANDOM` 变量的最大值。你无法控制位数，除非位数不超过五位，而且在第一种方法中你无法为数字指定最大值。函数 `get_random_number`

```
function get_random_number
{
# 此函数从 $RANDOM 变量获取下一个随机数。
# 范围是从 0 到 32767。
echo "$RANDOM"
}
```

## 方法 2：创建 1 到用户定义最大值之间的数字

我们经常希望限制数字范围，使其不超过用户定义的最大值。一个例子是在 1 到最大值（可能是 36）之间创建彩票数字。我们将使用取模运算符（modulo operator）将所有数字减少到固定的数字集合 `[0..N-1]`，这被称为模 N 算术。

对于我们的数字，我们需要一个用户提供的最大值，将其赋值给变量 `UPPER_LIMIT`。模运算符是百分号 (`%`)，我们使用它的方式与你在除法中使用正斜杠 (`/`) 相同。我们仍然使用 `RANDOM` 环境变量来获取一个新的伪随机数。但这次不同，我们将使用以下方程来限制数字不超过用户定义的模 N 算术。

```
RANDOM_NUMBER=$((RANDOM % $UPPER_LIMIT + 1))
```

注意我们在方程中加了 1。使用前一个方程将产生一个 1 到用户定义的 `UPPER_LIMIT` 之间的伪随机数。使用该方程的函数是 `in_range_random_number`，如列表 21.3 所示。

```
function in_range_random_number
{
  # 创建小于或等于
  # $UPPER_LIMIT 值的伪随机数，该值由用户定义

  RANDOM_NUMBER=$((RANDOM % $UPPER_LIMIT + 1))

  echo "$RANDOM_NUMBER"
}
```

## 方法 3：1 到用户定义最大值之间的固定长度的数字

在之前的两个示例中，我们无法得知新数字将包含多少位。在创建唯一文件名时，如果文件名长度保持一致将非常有用。我们可以通过为每个缺失的数字填充前导零来产生固定长度的数字。例如，我们希望所有数字都是四位数。假设生成的数字是 24。因为我们希望 24 变成四位数，我们需要在数字前面填充两个前导零，使数字变为 0024。为了填充数字，我们需要知道组成数字的字符字符串的长度。Korn shell 使用位于花括号 `{}` 内的变量前的井号运算符 (`#`)，如下处所示。

```
RN_LENGTH=$(echo ${#RANDOM_NUMBER})
```
