# 第 12 章：Web 服务

## 规则配置选项

与`Makefile`标志一样，你不需要修改规则（`Rules`）行。但是，如果你必须修改这些规则，可以使用`configure`脚本。要启用某个规则，使用`--enable-rule=NAME`选项，其中`NAME`是规则的名称。例如：

```
./configure --prefix=/usr/local/ --enable-rule=SOCKS4
```

同样，你可以使用`--disable-rule`选项禁用规则。

前两行规则行（`SHARED_CORE`, `SHARED_CHAIN`）与动态共享对象（`DSO`）有关，支持应保持原样。

`SOCKS`功能默认是关闭的。`SOCKS`是一种控制系统，所有的`TCP/IP`网络数据流都通过`SOCKS`守护进程。这使得`SOCKS`能够对网络数据进行收集、审计、筛选、过滤和控制。大多数将其将其软件防火墙使用。如果你想开启此功能，可以在`configure`脚本的命令行中使用`--enable-rule=SOCKS4`选项将其设置为`Yes`。此外，请确保你修改了Apache配置区域中的`EXTRA_LIBS`设置，将其指向你的`SOCKS`库文件。同样，如果你想要`SOCKS5`支持，可以在`configure`脚本的命令行中使用`--enable-rule=SOCKS5`选项将其设置为`Yes`。

`IRINX`用于在运行`IRIX`和`NIS`的`Silicon Graphics`系统上使用Apache的人员。`IRINXn32`选项对于运行`IRIX`操作系统的系统也有意义。它允许Apache使用`n32`库而不是`o32`库。

`PARANOID`规则允许在配置期间如果任何Apache模块正在执行任何`shell`脚本时执行。Apache 1.3允许模块在`configure`脚本运行时执行`shell`脚本。这是默认关闭的。如果你想启用它，可以在`configure`脚本的命令行中使用`--enable-rule=PARANOID`选项将其设置为`Yes`。

`WANTSREGEX`选项自动设置为默认（`Default`）。这指定了你想使用Apache自带的正则表达式包。然而，如果你更倾向于使用自己系统的正则表达式包，可以在`configure`脚本的命令行中使用`--disable-rule=WANTSREGEX`选项将其设置为`No`。

## 模块配置选项

默认模块集通过`AddModule`行被添加到标准Apache中。模块按优先级反序列出。如果你计划添加其他模块，请勿手动修改此文件。我建议使用`configure`脚本添加、删除或启用模块。

要启用默认未启用的模块，可以使用`--enable-module=NAME`选项。要禁用模块，使用`--disable-module=NAME`选项。例如，禁用`CGI`模块可以使用：

```
./configure --prefix=/usr/local/apache --disable-module=cgi
```

或者，要启用用户跟踪模块，你可以如下运行`configure`：

```
./configure --prefix=/usr/local/apache --enable-module=usertrack
```

一旦你使用之前讨论的一个或多个选项成功运行了`configure`脚本，你就可以准备编译并安装Apache了。

## 第四部分：设置内网/外网服务

## 编译并安装 Apache

在运行`configure`脚本后，编译和安装Apache非常简单。只需在Apache源码分发的根目录下运行`make`命令即可。如果一切顺利，你将看不到任何错误信息。在这种情况下，你可以立即安装Apache。如果在运行`make`时遇到错误，请记录错误信息并重新执行配置步骤。如果仍然存在问题，请访问Apache网站并阅读`FAQ`（常见解答）以查找是否有你需要执行的操作来获取Apache。根据我的经验，标准的Apache源码发行在`Red`上编译得一帆风顺。所以如果某些运行不正常，请双检查你的步骤。
