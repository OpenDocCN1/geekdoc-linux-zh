## 实现 AppArmor

### AppArmor 简介

AppArmor 是一种 Linux 安全模块（LSM），通过将程序限制在预定义的规则范围内提供了一种限制程序能力的机制。AppArmor 通过对应用程序实施访问控制策略，来防止它们访问未经允许的资源。

AppArmor 使用配置文件来限制应用程序的能力。配置文件指定了应用程序可以访问的资源，例如文件、目录、网络套字和其他系统资源。通过定义和强制这些配置，AppArmor 有助于将应用程序限制在预期操作范围内，减少安全风险。

AppArmor 的用途：

- 定义角色并为用户和应用程序分配权限。
- 创建并实施安全策略以限制应用程序的行为。
- 使用可插拔认证模块（PAM）增强用户身份验证和访问控制。
- 限制虚拟机可以访问的资源。
- 控制 Web 访问系统资源。

## 安装并启用 AppArmor

在实现 AppArmor 之前，请确保已在你的系统中安装并启用。

### 安装 AppArmor

在 Ubuntu 上，你可以使用以下命令安装 AppArmor 及其工具：

```
$ sudo apt update
$ sudo apt install apparmor apparmor-utils
```

### 启用 AppArmor

确保 AppArmor 已经启用并运行：
```
$ sudo systemctl enable apparmor
$ sudo systemctl start apparmor
```

验证 AppArmor 的状态：
```
$ sudo apparmor_status
```

以下是示例输出：

## 定义并强制 AppArmor 策略

AppArmor 配置文件定义了应用程序的安全策略。这些配置文件可以手动创建，也可以使用 AppArmor 提供的工具生成。

### 为特定应用程序创建配置文件

我们将为示例应用程序创建一个配置文件。首先，找到应用程序的二进制文件：
```
$ which example-app
```

假设应用程序位于 `/usr/bin/example-app`，为其创建一个配置文件：
```
$ sudo aa-genprof /usr/bin/example-app
```

### 定义配置文件

此命令将启动 AppArmor 剖析模式，您可以在其中交互式地定义策略。

运行应用程序以生成日志记录：
```
$ sudo /usr/bin/example-app
```

AppArmor 将监控应用程序的行为并生成配置条目。运行应用程序后，完成配置生成：
```
$ sudo aa-logprof
```

按照提示定义应用程序的权限。完成后，该配置将强制强制执行。

### 强制执行配置文件

确保配置已强制执行：
```
$ sudo aa-enforce /etc/apparmor.d/usr.bin.example-app
```

验证配置状态：
```
$ sudo apparmor_status
```

## 基于角色的访问控制 (RBAC)

AppArmor 支持 RBAC，允许您定义角色并为用户和应用程序分配权限。

使用 AppArmor 配置文件定义角色并分配权限。例如，为 Web 服务器角色创建一个配置文件：
`/etc/apparmor.d/usr.sbin.apache2`

编辑配置文件以定义权限：
```bash
# Include common includes for apache2
#include
/usr/sbin/apache2 {
# 强制对 web 目录只读访问
/var/www/html/ r,
# 允许 apache 读取配置文件
/etc/apache2/** r,
# 允许 apache 写入日志文件
/var/log/apache2/** rw,
# 拒绝访问任何其他文件或目录
deny /home/** rw,
deny /etc/** rw,
}
```

应用并强制执行角色：
```
$ sudo aa-enforce /etc/apparmor.d/usr/sbin.apache2
```

### 将 AppArmor 与 PAM 集成

AppArmor 可以与 PAM 集成以增强用户身份验证和访问控制。

编辑 SSH 的 PAM ，通常位于
```
$ sudo nano /etc/pam.d/sshd
```

添加以下行以集成 AppArmor：
`auth required pam_apparmor.so`

为 PAM 模块创建配置文件，例如为 SSH 会话定义访问控制策略。

```bash
# Include common includes for sshd
#include
/usr/sbin/sshd {
# 允许对 SSH 配置文件的读取访问
/etc/ssh/sshd_config r,
# 允许 sshd 执行其二进制文件
/usr/sbin/sshd ix,
# 拒绝访问其他敏感文件
deny /etc/passwd rw,
deny /etc/shadow rw,
}
```

强制执行配置：
```
$ sudo aa-enforce /etc/apparmor.d/usr.sbin.sshd
```

### 限制虚拟机

AppArmor 可以限制虚拟机，限制它们对系统资源的访问。例如，为管理虚拟机的守护进程创建一个配置文件：

```
$ sudo aa-genprof /usr/sbin/libvirtd
```

运行虚拟机管理器以生成日志记录：
```
$ sudo /usr/sbin/libvirtd
```

完成配置生成：
```
$ sudo aa-logprof
```

编辑配置文件以定义虚拟机的权限：
```bash
# Include common includes for libvirtd
#include
/usr/sbin/libvirtd {
### 允许 libvirtd 读取配置文件
/etc/libvirtd/** r,
# 允许 libvirtd 管理虚拟机镜像
/var/lib/libvirtd/images/** rw,
# 拒绝访问敏感文件
deny /etc/passwd rw,
deny /etc/shadow rw,
}
```

强制执行配置：
```
$ sudo aa-enforce /etc/apparmor.d/usr.sbin.libvirtd
```

### 限制外部 Web 应用

限制 Web 应用对系统资源的访问以增强安全性。为 Web 应用创建一个配置文件，例如
```
$ sudo aa-genprof /usr/bin/webapp
```

运行 Web 应用以生成日志记录：
```
$ sudo /usr/bin/webapp
```

完成配置生成：
```
$ sudo aa-logprof
```

编辑配置文件以限制 Web 应用的访问：
```bash

#include
/usr/bin/webapp {
# 允许对 web 目录只读访问
/var/www/html/ r,
# 拒绝访问敏感目录
deny /home/** rw,
deny /etc/** rw,
deny /var/log/** rw,
}
```

强制执行配置：
```
$ sudo aa-enforce /etc/apparmor.d/usr.bin.webapp
```
