### 19.
列表主要通过在每个列表元素之间放置冒号（`:`）来存储在环境变量中（`PATH` 变量的值就是一个例子）。你可以通过将元素连接到列表前端向此类列表添加元素，如：

```
PATH=/opt/bin:$PATH
```

如果元素已经在列表中，则在列表中会有两个副本。写一个 shell 函数 `addenv`，它接受两个参数：(1) shell 变量的名称和 (2) 一个要加在列表前的字符串，仅当该字符串不是列表中的元素时，才将其前置。例如，调用

```
addenv /opt/bin
```
