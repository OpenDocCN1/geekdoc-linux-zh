### 表单

关于表单的详细信息见第 15 章“HTML--概述”和第 17 章“CGI 简介”。

CGI 脚本常用的用途之一是处理来自 HTML 表单的数据。表单方法编码为 `POST`，动作是脚本的 URL。用户通过 Web 浏览器在 HTML 描述的表单中输入数据，当他们点击 `submit` 按钮时，就会执行你的脚本。

列表 18.6 显示了一个包含表单的 HTML，当用户点击 `submit` 按钮时会执行 shell 脚本。列表 18.7 显示了 CGI 脚本的 Korn shell 版本，列表 18.8 显示了 C shell 版本。

#### 列表 18.7. Korn Shell--表单处理示例。

```bash
#!/bin/ksh
#
# forms1.ksh
#
echo "Content-type: text/html"
echo ""
echo "<html>"
echo "<head>"
#
# 处理错误情况或向用户发送成功消息
#
if [[ $CONTENT_LENGTH = 0 ]]; then
  echo "<title>发生错误</title>"
  echo "</head> <<body>"
  echo "<p>表单为空，请输入某些数据！"
  echo "<br>"
  echo "按后退键返回表单。"
  echo "</p> </</body></</html>>"
  exit 0
elif [[ $CONTENT_TYPE != "application/x-www-form-urlencoded" ]]; then
  echo "<title>发生内容错误</title>"
  echo "</head> <body>"
  echo "<p>内部错误 - 无效的内容类型。请报告"
  echo "<br>"
  echo "按后退键返回表单。"
  echo "</p> </</body></</html>>"
  exit 0
fi
echo "<title>表单已提交</title>"
echo "</head> <body>"
echo "<h1>您的表单已提交</h1>"
echo "<p> 非常感谢您的输入，它已"
echo "提交给我们的人员进行处理... "
echo "<br>"
echo "按后退键返回表单。"
#
# 创建空临时文件。使用进程 ID 确保唯一性
#
FNAME=temp_$$
> $FNAME
#
# 读取标准输入 (STDIN 并写入临时文件（转换 & 和 +）。
# 注意：这是危险且粗糙的——你应该转换
# 编码字符并确保没有任何坏信息
#
read input_line
echo 'date' >> $FNAME
echo $input_line | tr "&+" "\n " >> $FNAME
#
# 通过邮件发送表单数据，清理临时文件
#
mail -s "表单数据" someuser@somecompany.com < $FNAME
rm $FNAME
echo "</p> </</body></</html>>"
exit 0
```
