
执行带有 `-l` 选项的 `kmtune` 会生成内核的详细列表。以下仅显示其中一个参数的输出：

```
# kmtune -1
Parameter: maxuprc
Current: 77
Planned: 77
Default: 75
Minimum: -
Module: -
Version: -
Dynamic: Yes
#
```

# 修改并构建 HP-UX 内核

此参数是动态的（Yes），意味着内核可以动态更新。查看此输出后，我们现在可以修改此动态参数的值。以下命令将该参数的值从现有值 77 更改为 80：

```
# kmtune -s maxuprc=80
#
```
