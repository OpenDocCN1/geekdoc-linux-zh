
私钥密码源。关于 `arg` 格式的更多信息请参见 `openssl(1)` 中的 `PASS PHRASE ARGUMENTS` 部分。

- `-verify filename`

使用“filename”中的公钥验证签名。输出为“Verification OK”或“Verification Failure”。

- `-prverify filename`

使用“filename”中的私钥验证签名。

- `-signature filename`

要验证的实际签名。

- `-hmac key`

使用“key”创建哈希 MAC。

# mac 算法

MAC（密钥化消息认证码）。最流行的 MAC 算法是 HMAC（基于哈希的 MAC），但其他其他基于哈希的 MAC 算法，例如 `ccgos` 引擎支持的 `gost-mac` 算法。MAC 密钥和其他选项应通过 `-macopt` 参数设置。

`-macopt nm:v`

将选项传递给由 `-mac` 指定的 MAC 算法。HMAC 和 `gost-mac` 都支持以下选项：

`key:string`

指定 MAC 密钥为字母数字字符串（如果密钥包含...后续文本略）

使用 `-dsaparam` 选项生成 DH 参数快得多，且推荐的指数长度更短，这使得密钥交换更高效。注意，对于 DSA 风格的 DH 参数，每次使用都应该创建一个新的 DH 密钥以避免小子群攻击。

- `-text` 此选项以人类可读的形式打印 DH 参数。

- `-C` 此选项将参数转换为 C 代码。然后可以通过调用 `get_dhnnumbits()` 函数加载这些参数。

- `-engine id` 指定引擎（通过其唯一 ID 字符串）将使 `dhparam` 尝试获取指定引擎的功能引用，从而在需要时对其进行初始化。该引擎将被设置为所有可用算法的默认引擎。

# 警告

程序 `dhparam` 结合了以前版本 OpenSSL 和 SSLLeay 中 `dh` 和 `gendh` 程序的功能。`dh` 和 `gendh` 程序目前仍保留，但在未来的 OpenSSL 版本中可能会有不同的用途。

# 注意事项

PEM 格式的 DH 参数使用头部和页脚行：

```
-----BEGIN DH PARAMETERS-----
-----END DH PARAMETERS-----
```

OpenSSL 目前仅支持旧的 PKCS#3 DH，不支持较新的 X9.42 DH。

此程序处理的是 DH 参数而非密钥。

## 缺陷

应该有一种生成和处理 DH 密钥的方法。

## 名称

`diff` -逐行比较文件

### 概要

```
diff [OPTION]... FILES
```

### 描述

逐行比较 `FILES`。

长选项的强制性参数对于短选项也是强制性的。

- `-normal`

输出普通 `diff`（默认值）

- `-q`, `--brief`

仅在文件不同时报告

- `-s`, `--report-identical-files`

当两个文件相同时进行报告

- `-c`, `-C NUM`, `--context[NUM]`

输出 `NUM`（默认 3）行复制的上下文

- `-u`, `-U NUM`, `--unified[NUM]`

输出 `NUM`（默认 3）行统一上下文

- `-e`, `--ed`

输出一个 `ed` 脚本

- `-n`, `--rcs`

输出 RCS 格式的 `diff`

- `-y`, `--side-by-side`

分两列输出

- `-W`, `--width=NUM`

输出最多 `NUM`（默认 130）列打印

---left-column

仅输出公共行的左侧列

- `-suppress-common-lines`

不输出公共行

- `-p`, `--show-c-function`

显示每个更改所属的 C 函数

- `-F`, `--show-function-line=RE`

显示匹配 `RE` 的最后一行

- `-label LABEL`

使用 `LABEL` 作为文件名（可以重复使用）

- `-t`, `--expand-tabs`

在输出中将制表符扩展为空格

- `-T`, `--initial-tab`

通过在开头添加制表符使制表符对齐

- `-tabsize=NUM`

每 `NUM`（默认 8）个打印列停止

- `-suppress-blank-empty`

抑制空输出行之前的空格或制表符

- `-l`, `--paginate`

将输出通过 `'pr'` 进行分页

- `-r`, `--recursive`

递归比较找到的任何子目录

- `--no-dereference`

不跟随符号链接

- `-N`, `--new-file`

将缺的文件的文件视为空

- `--unidirectional-new-file`

将不存在的第一个文件视为空

- `--ignore-file-name-case`

比较文件名时忽略大小写

- `--no-ignore-file-name-case`

比较文件名时考虑大小写

- `-x`, `--exclude=PAT`

排除匹配 `PAT` 的文件

- `-X`, `--exclude-from=FILE`

排除匹配 `FILE` 中任何模式的文件

- `--S`, `--starting-file=FILE`

在比较目录时从 `FILE` 开始

- `--from-file=FILE1`

将 `FILE1` 与所有操作数比较；`FILE1` 可以是目录

- `--to-file=FILE2`

将所有操作数与 `FILE2` 比较；`FILE2` 可以是目录

- `-i`, `--ignore-case`

忽略内容的差异

- `-E`, `--ignore-tab-expansion`

忽略制表符扩展导致的更改

- `--Z`, `--ignore-trailing-space`

忽略行尾的空白字符

- `-b`, `--ignore-space-change`

忽略空格数量的更改

- `--w`, `--ignore-all-space`

忽略所有空白字符

- `--B`, `--ignore-blank-lines`

忽略空行的更改

- `-I`, `--ignore-matching-lines=RE`

忽略所有行匹配 `RE` 的更改

- `-a`, `--text`

将所有文件视为文本

- `--strip-trailing-cr`

删除输入行末尾的回车符

- `-D`, `--ifdef=NAME`

输出带有‘`#ifdef NAME`’差异的合并文件

- `--GTYPE-group-format=GFMT`

使用 `GFMT` 格式化 `GTYPE` 输入组

- `--line-format=LFMT`

格式化所有输入行=`LFMT`

- `--LTYPE-line-format=LFMT`

`LTYPE` 输入选项对 `diff` 的输出提供细粒度控制，是 `-D/--ifdef` 的扩展。

`LTYPE` 为 `'old'`、`'new'` 或 `'unchanged'`。

`GTYPE` 为 `LTYPE` 或 `'changed'`。

`GFMT`（仅）可以包含：

`%<`

来自 `FILE1` 的行

`%>`

来自 `FILE2` 的行

`%=`

`FILE1` 和 `FILE2` 的公共行
