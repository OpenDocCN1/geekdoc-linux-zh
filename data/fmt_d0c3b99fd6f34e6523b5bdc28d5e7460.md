### wget
Wget 是一个文件检索工具，可以使用 HTTP 或 FTP 协议。`Wget` 的功能包括在加载时在后台运行、递归检索目录、文件名通配符匹配、远程文件时间存储和比较、在缓慢或不稳定的连接上使用 Rest 与 FTP 服务器和 HTTP 服务器检索文件、支持代理以及配置。Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`

### wget
从网络检索文件 `Wget` 是一个使用 http 和 ftp（两种最广泛使用的 Internet 协议）从 Web 检索文件的网络工具。它以非交互方式工作，因此可以在注销后在后台运行。该程序支持按照文件站点对 网页作者页面进行递归检索——你可以使用 `wget` 制作存档和页面的 Web 镜像，或者像 WWW 机器人一样访问 Web。`Wget` 在缓慢或不稳定的连接上表现良好，因为它会继续检索直到文档完全下载。在支持此点的服务器（支持 http 和 ftp）上，可以从中断的地方重新获取文件。http 和 ftp 检索都可以标记时间戳，因此 `wget` 可以查看文件自上次检索以来是否发生变化，并在时自动检索新版本。`Wget` 支持代理；这可以限制网络负载、加速检索，并提供防火墙后的访问权限。`http://www.gnu.org/software/wget/` 来自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

### wheel bit (轮权限位)
- n. 一种权限，允许所有者在分时系统中执行某些受限的操作，例如无论保护如何如何读取或写入系统的任何文件、更改或查看运行监控器中的任何地址、崩溃或重新加载系统，以及创建和创建用户账户。该术语发明于 TENEX 操作系统，并延续到 TOPS–20、XEROX 等系统。处于特权登录状态有时被称为“轮模式”。这个术语在 20 世纪 80 年代中期从 TWENIX 进入文化，并变得越来越流行（尤其是大学站点）。参见下文。来自 Jung Dictionary `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

# 轮回 (wheel of reincarnation)
[创制于 T. H. Myr 和 I.E. Sutherland 的论文《On the Design of Display Processors》，Comm, ACM, Vol. 11, no. 6, 1968年6月] 用来指一种著名的现象，即计算系统中的功能迁移到特殊的外设硬件以提高速度，外设在执行任务时向更强大的计算能力演进，然后有人注意到在架构中支持非对称处理器是不高效的，于是将功能折回主 CPU，此时循环再次开始。在图形处理器设计中观察到了这种循环的多次迭代，并至少被称为“Wheel of Life”、“Wheel of Samsara”以及其他基本印度/佛教神学概念的变体。参见 glitter, bit map。来自 Jung Dictionary `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

# whereami
自动为你的（笔记本电脑）重新配置新位置 `whereami` 是一组实用的脚本和协调系统，用于在当前（网络）环境中自动定位你的电脑。当你在各种不同的网络/或底座环境之间移动时，你会使用 `whereami` 自动配置和重新配置笔记本电脑。虽然当所有网络地址都通过 dhcp 获取时 `whereami` 效果最好，但这并非先决条件，系统允许你在极少用户干预的情况下确定新位置。在确定正确位置后，`whereami` 将运行适当的（用户配置的）脚本来调整笔记本操作以适应当前环境。更多信息见 `http://debian.net/whereami/`。你也可以从 debian-mapping 列表获得帮助，贡献者经常搜索该列表。来自 Debian 3.0r APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`
