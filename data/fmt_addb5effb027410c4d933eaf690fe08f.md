
`list_entry(ptr, type, member)` 返回从第一个参数指向的链头返回第二个参数所示类型的结构指针，第三个参数是我们想要获取的成员。`list_for_each(pos, head)` 通过第二个参数遍历列表，对其成员执行操作。`list_for_each_prev(pos)` 反向遍历列表。`list_for_each_safe(pos, head, n)` 处理移除链表条目的情况；第二个参数是指向 `struct list_head` 的指针，用于临时存储。另一种变体是使用便利宏 `list_entry(pos, head, member)`（其中 `member` 是结构内列表的名字），使得以下两段代码实现相同的功能：

```c
struct my_struct *tmp;
struct list_head *head;
struct my_s *s;
list_for_each(entry, head) {
    s = list_entry(entry, struct my_s, list);
}
```

内核代码中的微小错误可能导致严重的泄漏。应该尽早且经常从安全角度进行代码审查。

不应信任用户空间的参数。驱动程序（以及其他设施）应该检查权限，并使用能力函数（capability functions）来检查请求是否被允许。

应注意整数类型、类型转换等，以确保没有任何因素影响其位置。资源使用应受到限制以避免拒绝服务攻击（DoS）。
