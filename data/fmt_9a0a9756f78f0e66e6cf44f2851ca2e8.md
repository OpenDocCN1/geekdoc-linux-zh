
# Linux 词典

为初始内存磁盘 (`initrd`) 镜像创建文件系统。这些内存磁盘通常用于预加载块设备（SCSI 或 RAID）以访问根文件系统。换句话说，通用内核可以在不包含 SCSI 适配器驱动的情况下构建，驱动程序作为模块加载。内核需要读取这些模块，但在这种情况下它可以访问 SCSI 适配器，使用了初始内存磁盘。内存磁盘由操作系统（通常是 `LILO`）加载，并在内存磁盘加载后供内核使用。`initrd` 程序根据 `/etc/modules.conf` 文件中的信息创建内存磁盘。来自 Mandrake 9.0 RPM

## mknbi

## mkrboot

从一个磁盘或从 DOS 创建可启动的内核 + 根镜像，`mkrboot` 生成的引导包含内核和根镜像。这使得能够从一张软盘进行 Debian 引导安装。`mbrboot` 还可以加载 `line` 以实现无软盘安装。支持的引导方法：从带有软盘的运行 DOS/Windows 加载 - 从 FreeDOS 引导盘加载 - 从一张软盘加载 `Lilo` - 从一张软盘加载内核引导加载程序 - 从一张软盘加载 `Syslinux`

来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/index.html
