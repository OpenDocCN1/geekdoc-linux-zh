# `ln` — 创建硬链接或符号链接

### 概要

```
/usr/bin/ln [-fns] source-file [target]
/usr/bin/ln [-fns] source-file...
/usr/xpg4/bin/ln [-fs] source-file [target]
```

## 描述

有时为了从多个目录访问一个文件，`ln` 是很有用的。链接文件可以减少磁盘占用，并更容易维护一致性。使用 `ln` 命令在单文件系统中创建目录项。

硬链接是文件的指针，与原始目录项无异。对文件的更改对任何引用名称都有效。硬链接不能跨文件系统且无法引用目录。

符号链接 `-s` 可以跨文件系统链接。符号链接在目录树中有一个名称但没有内容。它只是指向另一个文件或目录。

使用 `ln` 命令创建硬链接和符号链接。默认情况下，`ln` 创建硬链接。`source-file` 被链接到 `target`。如果 `target` 是目录，则创建一个名为 `source-file` 的文件并链接到它。

在第一种形式下，`ln` 命令为 `source-file` 指定的文件创建一个新的目录项（链接），位于 `target` 指定的目标路径。如果不指定 `target`，则在当前目录中链接。当最后一个操作数不是现有目录时，假设使用这种形式；如果你指定了两个操作数且最后一个操作数不是现有目录，则会出错。

在第二种形式下，`ln` 命令为 `source-file` 操作指定的每个文件在由 `target` 命名的现有目录创建一个新的目录项。

```
/usr/bin/ln
```

如果 `target` 是文件，其内容将被覆盖。`/usr/bin/ln` 确定 `target` 的模式不允许覆盖，它打印模式（参见 `chmod(1)`），请求响应并从标准输入读取一行。如果响应是肯定的，如果可能则链接；否则命令退出。

```
/usr/xpg4/bin/ln
```

如果 `target` 是文件且你没有指定 `-f` 选项，`/usr/xpg4/bin/ln` 向标准错误写入诊断消息，不再对当前 `source-file` 执行任何操作，并继续处理剩余的 `source-file`。

# `ln`

# 693

符号链接（symbolic link）是一个指向文件的间接指针；其目录条目包含所链接的文件名。符号链接可以跨越文件系统，并可以引用目录。

目标的权限可能与 `ls(1)` 命令 `-l` 列出的显示的权限不同。要显示目标的权限，请使用 `ls -L`。更多信息请参见 `stat(2)`。

# 注意事项

指向目录的符号链接在某些情况下的行为与你预期的不同。虽然在这样的链接上执行 `ls -l` 会显示指向目录中的文件，但 `ls -l` 显示的是链接本身的信息，如示例所示。

```
castle$ ln -s dir link
castle$ ls link
file2 file3 file4
castle$ ls -l link
lrwxrwxrwx 1 user      Jan 11 23:27 link -> dir
castle$ 
```

当使用 `cd(1)` 通过符号链接更改目录时，你最终进入的是文件系统中该位置的父工作目录。这意味着新工作目录的父目录不是符号链接的父目录，而是指向的目录的父目录。例如，在以下情况下，最终的工作目录是 `/usr` 而不是 `/home/user/linktest`。

```
castle$ pwd
/home/user/linktest
castle$ ln -s /usr/tmp symlink
castle$ cd symlink
castle$ cd ..
/usr
castle$ 
```

shell 用户可以通过使用 `pushd` 和 `popd` 内置命令代替 `cd` 来避免任何产生的导航问题。

## 选项

`/usr/bin/ln` 和 `/usr/xpg4/bin` 都支持以下选项：

- `-f` 即使目标模式禁止写入，也不提问直接链接文件（默认情况下，标准输入不是终端）。

- `-s` 创建符号链接。

如果你带有两个参数使用 `-s` 选项，目标可以是一个现有目录或不存在的文件。如果目标已存在且不是目录，则返回错误。源文件（`source-file`）可以是任何路径名且不需要存在。如果它存在，它可以是文件或目录，并且可以位于目标不同的文件系统中。如果目标是一个已存在的目录，将在目标中创建一个名为 `source-file` 或 `source-file` 最后组件的文件。该文件是一个引用 `source-file` 的符号链接。如果目标不存在，将创建一个名为 `target` 的文件，它是引用 `source-file` 的符号链接。

如果你带有两个以上的参数使用 `-s` 选项，目标必须是一个现有目录，否则返回错误。对于每个 `source-file`，在目标中创建一个名为 `source-file` 最后组件的链接；每个新的 `source-file` 都是原始 `source-file` 的符号链接。文件和目标可以位于不同的文件系统中。

```
/usr/bin/ln
```

- `-n` 如果链接是一个现有文件，不要覆盖文件内容。`-f` 选项会覆盖此选项。此行为是 `/usr/xpg/bin/ln` 的默认行为并会被忽略。

### 操作数

- `source-file`

要链接的文件路径名。该文件可以是普通文件或特殊文件。如果你指定了 `-s` 选项，`source-file` 也可以是目录。

- `target`

要创建的新目录条目的路径名，要在其中创建新目录条目的现有目录的路径名。
