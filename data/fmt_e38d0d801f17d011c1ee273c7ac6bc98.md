# magnus

带有 GUI 的计算群论软件。Magnus 计算群包是一个创新的符号包，提供了关于无限群的计算设施和相关功能。几乎所有的代数系统都面向有限计算，并且在提供足够的时间和资源的情况下，这些计算保证能产生答案。相比之下，MAGNUS 关注对群的实验和计算，其中一些群已知是终止的，而另一些已知是可递归枚举的。MAGNUS 具有直观的用户界面，可以在同一个问题上并行运行不同的算法，为原本不可行的问题生成近似解，并包含一个插件——包管理器。源自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index

# magpie

Debian 引用库程序，作为 `apt(8)` 和 `dpkg(8)` 数据库的“引用库”，并持有关于每个包的信息。每个包在单独页面上都有详细描述。还提供了三个额外的包列表：“被需要”、“被推荐”和“被建议”，后者是指向 Debian 错误跟踪系统的链接。如果安装了该包，它还会显示冲突以及包中所有不符合清单的文件（如果已启用）。所有包列表都提供“摘要”描述，并提供“描述”字段，按部分、优先级或关键词进行分组。还提供了所有已安装包的概述。附加索引包括包名、维护者、源、包大小、安装大小和 md5 校验和。Magpie 还具有实验性支持，但尚未有 XL 样式表。源自 Debian 3.0r0 APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# mah-jong

原始麻将游戏是一组玩原始麻将游戏的程序：包含一个服务器、一个供人类玩家使用的客户端以及一个供程序玩家使用的客户端。游戏可以由 1 到 4 名玩家进行。你应该记住那个著名的纸牌类游戏（它只使用相同的牌组）。如果你喜欢游戏，请考虑向（上游）作者捐赠。详情请参阅 `usr/share/doc/mah-jong/README.Debian`。源自 Debian 3.0r0 APT http://www.tld.org/LDP/Linux-Dictionary/html/index.html
