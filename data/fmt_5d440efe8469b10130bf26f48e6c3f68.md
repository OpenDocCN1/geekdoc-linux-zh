
# Linux 目录与常用命令示例

| 目录 | 功能 |
| --- | --- |
| `/` | Linux 系统的顶层目录，包含所有组织成目录的文件、设备信息和系统信息 |
| `/home` | 存放用户的“家目录” |
| `/bin` | 包含每个基本的命令和工具程序 |
| `/usr` | 包含系统使用的命令和文件 |
| `/usr/bin` | 包括工具程序和用户友好的命令 |
| `/usr/sbin` | 存放系统管理命令 |
| `/usr/lib` | 包含编程语言库 |
| `/usr/share/doc` | 包含 Linux 的文档 |
| `/usr/share/man` | 包含在线 "man" 手册 |

# 卸载 apache

- `read` 的值为 4
- `write` 的值为 2
- `execute` 的值为 1
- `no permission` 的值为 0

```bash
chmod 644 1.txt
```
# 用户: 4 + 2 (读和写)
# 组: 4 + 0 (读)
# 其他人: 4 + 0 (读)

- `read` = 4 + 2 + 1 (读、写和执行)
- `write` = 4 + 2 (读)
- `execute` = 5 =4 + 1 (执行)
- 4 = 0 (读)
