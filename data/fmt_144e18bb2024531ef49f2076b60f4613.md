
# Linux 命令行指南

## 基础命令与执行

命令是你输入到命令行并存储在计算机内部某处的内容；它们执行某些机器码。有时，一个内置的 Linux 命令就是这些机器码，而有时，它也是你自己编写的一些代码，可能是一个应用程序。偶尔，在另一个命令之后，我们想要运行一个命令，我们也可以使用分号 `;` 来这样做：

- 命令 `$l first (ls)` 的含义是列出工作目录的内容，然后 `$l (pwd)` 打印它的位置。
- 然后，可以使用 `&&` 来链接命令，这是另一个实用的工具。如果左侧的命令失败，右侧的命令将不会运行。在同一行，你可以多次使用 `&&` 和 `;`。

即使第一个失败，第二个也会通过 `;` 运行。`&` 执行了完全不同的功能，尽管它看起来和 `&&` 相似。通常，当你执行一个长时间运行的命令时，命令行会在等待该命令完成之前允许你进入另一个。当一个旧命令仍在运行时，你可以执行新命令，而当你把命令放在 `&` 之后就可以防止这种情况发生。

至关重要的是，由于我们假设进程或作业被“后台化”以隐藏它，我们在命令后使用 `&`。然后，使用 `job` 命令查看当前运行哪些后台作业。

## 获取帮助

### `man`

为了获取该命令的手器手册（使用 `q` 退出 `man`），在几乎任何命令之前输入 `man`。

### `-h`

为了为你调出该命令的帮助菜单，请输入 `--help` 或 `-h`。

## 查看和编辑文件

### `nano` / `nedit`

对于想要学习百万种快捷键的人或初学者来说，作为一个具有极简特征的命令行编辑器，`nano` 是一个很棒的编辑器。在编码生涯的前几年里，它对于任何开发者或程序员来说都是足够的。因为它允许语法高亮、拖放、点点编辑，`nedit` 则打开 X Window 作为一个小型图形化编辑器。当你计划对脚本进行某些更改并重新运行它时，你可能想用 `nedit`。

`Atom`、`Notepad++`、`edit`、`vi`、`emacs` 以及其他都是常见的编辑器，如图形用户界面 `GUI` 或命令行界面 `CLI`。其他还有 `VS Code`、`Light Table` 和 `Micro`。它们具有语法高亮、搜索和替换以及其他功能。

## 创建和删除文件

### `mkdir` / `rm` / `f`

为了让你创建、删除，使用 `mkdir`。

### 磁盘空间查看

- `-r`
- `-f`

对于系统的硬盘驱动或磁盘，如果你想知道文件占用了多少空间，`df` 会向你显示。如果你查看这个命令，你会注意到 `-h` 的含义是“人类可读的”，而不是“帮助”。

而且而不是写出整数、巨大的字节数，用于显示磁盘或文件大小，某些用法命令中 `G` 代表千字节（`GB`），`k` 代表千字节（`KB`）。对于特定目录的子目录，`du` 显示文件空间使用情况。你可以使用 `df` 来发现特定硬盘的剩余空间。此外，使用 `du` 还可以让你了解目录的空间质量。从指定的目录开始，标志 `--max-depth=N` 允许目录限制在 `N` 层以内或更少，这取决于具体参数。对于用户运行的当前进程，由 `ps` 显示。

## 目录结构

### `tree` / `mkdir -p`

`mkdir` 默认只创建一个单一目录。因此，仅使用 `mkdir` 可能对你来说无法创建 `d/f`，因为该目录不存在。此外，如果不存在此类目录，当我们通过 `-p` 选项向 `mkdir` 传递路径时，该路径中的所有目录都可以被创建。

此外，当我们打印出一个格式良好的目录时，我们可以通过 `tree` 的帮助更好地直视化目录的结构。在开头指定一个目录，它会打印整个树的结构。然而，使用该标志，你有将其限制在特定数量级的权限。然后，使用 `-prune`，可以在 `tree` 的输出中隐藏空目录。你必须知道目录不是空的，否则“递归空”也将由此命令移除，而这些目录内部包含递归的空目录或其他空目录。

## 其他实用命令

### 退出与登录

`exit` / `logout` / `passwd`

你可以使用 `passwd` 来更改你的账户密码。为了验证它，你可能需要提供当前正在使用的密码。然后，为了防止任何输入错误的情况，它会要求你输入两次新密码。在只有一个用户账户的情况下，你所登录的 `shell` 将通过 `logout` 退出。若要退出任何 `shell`，请使用 `exit`。

### 屏幕清理与通配符

`clear` / `*`

为了让你的终端行移动到屏幕顶部，请运行 `clear`。在你的当前提示符行下方，该命令将向其添加空行。因此，你可以借此清除你的工作区域。在寻找特定文件的情况下，通配符（也称为*克莱尼星*，`Kleene Star`）`*` 是它的完美选择。由于它在命令中等同于多个字符或零，你可以多次利用 `glob`。

### 系统资源监控

`htop` / `top` / `ncdu`

通过 `top` 可以显示最近运行的进程及其内存占用、所有者等许多信息。`top` 的交互式增强变体是 `htop`。你需要知道，通过仅传递 `-u username` 标志，可以将显示的进程限制为仅属于那些所有者。

`ncdu` 也可用于查看目录磁盘使用情况。
