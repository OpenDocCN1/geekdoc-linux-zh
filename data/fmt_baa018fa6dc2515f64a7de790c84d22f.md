
# 安非他命

一种兴奋剂，以多种方式影响大脑和身体，商品名为苯丙胺（Benzedrine）。从化学角度看，安非他命是 $\alpha$-甲基-$\beta$-苯乙胺的 L 型和 D 型异构体的外消旋混合物。L 型异构体对身体的影响更为显著，而 D 型异构体（通常称为右旋安非他命）对大脑的影响更大。总体而言，安非他明的药理作用是升高血压、放松支气管平滑肌、收缩供应皮肤和黏膜的血管，以及引起多种行为改变。安非他命产生其效应的机制尚未精确定义。对身体的影响似乎主要通过神经递质去甲肾上腺素介导交感神经系统神经元活动增加来实现。安非他命具有从神经末梢释放去甲肾上腺素的能力。释放的后果是，安非他命具有一系列与去甲肾上腺素在外周神经系统中的正常生理效应相似的活动谱。类似地，安非他命对大脑的主要影响与其在下丘脑、网状激活系统和大脑皮层释放去甲肾上腺素的能力有关。参见 CENTRAL NERVOUS SYSTEM（中枢神经系统）；SYMPATHETIC NERVOUS SYSTEM（交感神经系统）。

安非他命收缩黏膜血管和放松肺部平滑肌的能力使其成为一种有效的鼻用减充血剂。其引起高血压的特性使其被用作食欲抑制剂。其清醒和导致失眠的作用被用于治疗嗜睡症，这是一种无法保持清醒的疾病。此外，安非他命引起食欲减退的能力也促使其在减肥方案中作为食欲抑制剂使用。服用安非他命后出现的增强幸福感感和轻度欣快感，使其被用于治疗某些形式的精神抑郁。安非他明的一个重要用途是治疗多动症儿童，尽管兴奋剂如何能减少多动行为这一悖论尚不为人理解。

正如安非他明的治疗用途是其药理学的结果一样，其副作用也是。典型的对身体的副作用包括口干、心脏节律改变（心悸和心律失常）、高血压、胃痉挛和尿频减少。中枢神经系统的副作用包括头晕、痛苦感、头痛、震颤、不安、失眠、食欲减退、攻击性增加、焦虑以及偏执狂躁状态。过量服用可能导致抽搐、脑出血、昏迷甚至死亡。

安非他明的兴奋剂和致欣快副作用使得这种药物容易受到广泛滥用。然而，这种滥用的模式差异巨大。在没有适当医学监督下服用安非他明的人群多样性使得很难描述一个典型的用户。更严重的滥用发生在一些长期服用该药物的个体身上。

与其他滥用药物一样，反复用药后会产生耐受性。长期大量使用安非他命会对人格产生严重影响。已证明大量安非他命可在人类中诱发一种几乎无法与偏执型精神分裂症区分的行为状态，但在停药后可以逆转。安非他命是否会导致生理依赖的问题尚未解决。参见 ADDICTIVE DISORDERS（成瘾性障碍）；NARCOTIC（麻醉品）。

## 两栖动物

无脊椎动物亚门四足动物超纲的四个纲之一；其他三个纲为爬行纲、鸟纲和哺乳纲。现存两栖动物约有 2460 个物种，分为三个目：无尾目（Anura，亦称跳蛙目，包括青蛙和蟾蜍，略少于 2000 种）；有尾目（Urodelia，亦称尾纲，包括蝾螈，300 种）；无足目（Apoda，亦称蚓螈目，约 160 种）。异齿鳄亚纲和鱼石螈亚纲中的目存在于地质过去，现已灭绝。两栖纲的分类方案如下：

- 纲 两栖纲
    - 亚纲 异齿鳄亚纲
        - 目：异齿鳄目
        - 目：离片鳃目
        - 目：鳍脚目
    - 亚纲 真两栖亚纲
        - 目：无尾目
        - 目：有尾目
        - 目：无足目

典型的两栖动物特征是具有湿润、有腺体的皮肤，在生命史的某个阶段拥有鳃，四肢，以及缺乏称为羊膜的胚胎膜。*参见 AMNION（羊膜）；ANAMNIA（无羊膜）*。

两栖动物最亲近的亲缘是鱼类（它们由此演化而来）和爬行动物（它们演化为爬行动物）。然而，现代两栖动物是高度特化的动物，与可能最早由肉鳍鱼类起源的原始形式大不相同，也与那些演化出最早期爬行动物的形式相去甚远。

一般来说，现代成年两栖动物与鱼类的区别在于缺乏鳞片，通过皮肤和呼吸而非鳃进行呼吸，以及用四肢代替鳍。然而，这些概括有很多例外。爬行动物通常具有干燥、有鳞片的皮肤，相对不透水，水分流失少，这与皮肤湿润、允许大量蒸发的两栖动物截然不同。幼体（蝌蚪）两栖动物有鳃，但在爬行动物的生命史中并没有可比的鳃呼吸幼体阶段。这两个类群之间最重要的区别是两栖纲缺乏羊膜，而爬行纲存在羊膜。缺乏这一膜，两栖动物的卵必须产在水中或非常潮湿的地方。爬行动物卵的羊膜使其更能抵抗干燥，卵可以产在相对干燥的地方。抵抗通过皮肤失水的能力以及陆生卵的发展，可能是爬行动物与两栖动物之间具有最大进化意义的差异。*参见 REPTILIA（爬行纲）*。

两栖动物生活中至关重要的因素是水。大多数物种必须回到水中繁殖，所有物种都必须能够接触水（即使只是雨水或露水形式），否则在短时间内就会脱水死亡。这一生理学基本事实的一个重要后果是，地球上广阔的干旱和半干旱地区只生活着相对少量的特化两栖动物。大多数两栖动物物种生活在潮湿的热带地区。

两栖动物属于所谓的“冷血动物”，即两栖动物的体温不像哺乳动物和鸟类那样由内部调节到高水平，而是随环境波动。像两栖动物这样不燃烧食物能量来保暖的动物，能够以比同等大小的鸟类或哺乳动物少得多的食物生存。这种优势被两栖动物在寒冷条件下无法活跃（而这种条件并不抑制温血动物）的缺陷所抵消。因此，在世界北方和南方支持大量鸟类和哺乳动物种群的地方，两栖动物生命几乎绝迹。两栖动物标志着脊椎动物进化中的一个重要节点，即从水生到陆生生活的过渡。作为既未完全脱离水又未完全适应陆地生活的动物，它们以其中间的生活模式区别于其他。爬行动物，以及后来的哺乳动物，开始在陆地上占主导地位，鱼类在水域占主导，使得今天的两栖动物成为一个相对不重要但仍然极具研究价值的脊椎动物群体。*参见 TETRAPODA（四足动物）；THERMOREGULATION（体温调节）*。

现存三类两栖动物的化石记录非常广泛，每一类最早的成员都在中生代岩石中被发现。然而，在中生代未找到连接这三个类群的中间形式，有必要向前追溯约 10000 万年的古生代，寻找现代两栖动物的共同祖先，已知最早的两栖动物是在格陵兰的上泥盆统岩石中发现的。

显然，现代两栖动物拥有非常漫长的历史，几乎可以追溯到陆生脊椎动物起源和辐射演化时期，即 3.4 亿年前。它们独特的感官生物学和特化的腺体一定是在那个时期演化并保留至今。

## 角闪石

一组常见的铁镁硅酸盐矿物，作为主要或次要成分出现在多种岩石中。角闪石的晶体结构非常灵活，因此，角闪石显示出比任何其他矿物组更广的化学成分范围。角闪石的结构和化学复杂性揭示了关于影响其所在岩石的地质过程的相当多的信息。*参见 MINERAL（矿物）*。

角闪石的一般化学式可写为 $A_0B_2C_5T_8O_{22}W_2$，其中：

- A = Na（钠）, K（钾）, Ca（钙）
- B = Ca（钙）, Mg（镁）, $Mn^{2+}$（锰）, $Fe^{2+}$（铁）, Li（锂）
- C = Mg（镁）, $Fe^{2+}$（铁）, Al（铝）, $Fe^{3+}$（铁）, $Al^{3+}$（铝）, Mn（锰）, Li（锂）
- T = Si（硅）, Al（铝）
- W = OH（羟基）, F（氟）, $O^{2-}$（氧）, Cl（氯）

并且化学物种按重要性顺序排列。

根据 B 组中化学物种的类型，角闪石分为四个主要组：

- B = ($Fe^{2+}$, Mg, $Mn^{2+}$, Li)$_2$ — 铁镁锰角闪石
- B = Ca$_2$ — 钙角闪石
- B = NaCa — 钠钙角闪石
- B = Na$_2$ — 钠角闪石

角闪石可以具有正交晶系和单斜晶系对称性；这些可以通过 X 射线晶体学或矿物在偏振光中的光学性质来区分。*参见 X-RAY CRYSTALLOGRAPHY（X射线晶体学）*。

单斜角闪石是远为常见的。角闪石结构的特征是由共用顶点的四面体配位组构成的链。沿 y 轴观察结构表明，角闪石结构由四面体层与八面体配位的 C 组阳离子层交替组成。在单斜结构中，四面体层在 x 方向上全部以相对于下层相同的位移方向（沿 z 方向）堆叠，因此 $\beta$ 角不是 $90^\circ$，产生单斜结构。在正交结构中，四面体层的位移每三层反转一次，因此 $\beta$ 角是 $90^\circ$，产生正交结构。*参见 CRYSTAL（晶体）；CRYSTAL STRUCTURE（晶体结构）；CRYSTALLOGRAPHY（晶体学）*。

角闪石并不表现出上述一般化学式和常见理想化成分所暗示的完整成分范围。特别是，四个主要角闪石组——铁镁锰角闪石、钙角闪石、钠钙角闪石和全碱角闪石——之间没有连续的成分范围。这种缺乏所谓的固溶体的结果是，结构无法在单个晶体的结构中同一组位置容纳两种大小（或电荷）差异非常大的阳离子（带正电的原子）。

两种角闪石的不混溶性程度通常随温度和压力变化：在高压或高温下，混溶性通常增强。已知为混溶隙的不混溶区在高温时较窄，但在低温时变宽。当角闪石成分位于混溶隙内时，单一角闪石不再稳定。正是在此处发生出溶（或分异）过程。共存的角闪石和出溶结构对于结晶温度和冷却历史，特别是变质岩中的，非常有参考价值。*参见 PHASE EQUILIBRIUM（相平衡）；SOLID SOLUTION（固溶体）*。

角闪石是许多类型火成岩中的常见矿物，角闪石的成分反映岩石的二氧化硅含量。钙角闪石，特别是透闪石，是超基性和玄武岩质岩石的特征矿物
