
`mkxauth` 工具用于创建和维护 `.Authority` 文件。`.Authority` 文件被 X 服务器使用，根据 `.Authority` 内容授予或拒绝访问。如果你想为 X 系统提供访问控制，应该安装 `mkxauth` 软件包。来自 Mandrake 9.0

# mlterm

多语言终端是一个 X Window 系统的终端模拟器，它支持各种编码 ISO–8859–[1–10–13,16], TCVN5172, VISCII, KOIB–[R], EUC-JP,

# mlton

针对 Standard ML 的全程序优化器 `MLton` 运行在 Linux 下的 X86 机器上。`MLton` 生成具有良好运行时性能的独立执行文件，符合 SML 97 标准，并拥有一个主要是基础的库。`MLton` 支持分析和快速 C FML。`MLton` 具有用于延续、间隔定时器、随机处理程序、套接字、系统日志以及线程保存和恢复的额外库。它还拥有 GNU 多精度库 Intif 的快速实现。来自 Debian 3.0r APT http://www.tldp.org/LDP/Linux-Dictionary/index.html
