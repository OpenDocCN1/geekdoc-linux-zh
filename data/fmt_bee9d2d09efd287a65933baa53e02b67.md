# 线程 (threading)

`threading` 模块提供了一个 `Thread` 类以及多种同步原语，用于编写多线程程序。

## Thread 对象

`Thread` 类用于表示独立的控制线程。可以通过以下方式创建新线程：

```
Thread(group=None, target=None, name=None, args=(), kwargs={})
```

这会创建一个新的 `Thread` 实例。`group` 为 `None`，并留作未来扩展。`target` 是可调用对象，在线程启动时由 `run()` 方法调用。默认情况下，它为 `None`，意味着不调用任何内容。`name` 是线程名称。默认情况下，会创建一个格式为 `"Thread-N"` 的唯一名称。`args` 是传递给 `target` 函数的参数元组。`kwargs` 是传递给 `target` 的关键字参数字典。

`Thread` 实例支持以下方法和属性：

```
t.start()
```

通过在单独的控制线程中调用 `run()` 方法来启动线程。此方法只能被调用一次。

```
t.run()
```

此方法在线程启动时被调用。默认情况下，它会调用构造函数中传递的 `target` 函数。此方法可以在 `Thread` 的子类中重写。

```
t.join([timeout])
```

等待线程终止或发生超时。`timeout` 是一个浮点数，指定超时时间的秒数。线程不能 `join` 自己，在线程启动之前 `join` 它将是一个错误。

```
t.is_alive()
```

如果线程存活则返回 `True`，否则返回 `False`。线程从 `start()` 方法返回的那一刻开始到其 `run()` 方法结束都是存活状态。在旧代码中，`t.isAlive()` 是此方法的别名。

```
t.name
```

线程名称是一个字符串，仅用于标识，如果需要，可以更改为更有意义的值（这可能会简化调试）。在旧代码中，使用 `t.getName()` 和 `t.setName(name)` 来操作线程名称。

```
t.ident
```

一个整数型线程标识符。如果线程尚未启动，则该值为 `None`。

```
t.daemon
```

线程的布尔守护标记（daemon flag）。这必须在调用 `start()` 之前设置，初始值继承自创建线程的守护状态。当没有非守护线程留存时，整个 Python 程序将退出。所有程序都有一个主线程，代表初始的控制线程，且不是守护线程。在旧代码中，使用 `t.setDaemon(flag)` 和 `t.isDaemon()` 来操作此值。

以下是如何创建并启动函数（或可调用对象）作为线程的示例：

```python
import threading
import time

def clock(interval):
    while True:
        print("The time is %s" % time.time())
        time.sleep(interval)

t = threading.Thread(target=clock, args=(15,))
t.daemon = True
t.start()
```

以下是将相同线程定义为类的类示例：

```python
import threading
import time

class ClockThread(threading.Thread):
    def __init__(self, interval):
        threading.Thread.__init__(self)
        self.daemon = True
        self.interval = interval
    def run(self):
        while True:
            print("The time is %s" % time.time())
            time.sleep(self.interval)
```

`t = ClockProcess(15)`

`t.start()`

如果你将线程定义为类并定义了 `__init__` 方法，那么像所示调用基类构造函数 `Thread.__init__()` 是至关重要的。如果你忘记这样做，将得到名称错误。在运行 `run()` 之后，避免调用为线程定义的任何其他方法将是一个错误。

这些示例中对 `daemon` 属性的设置是后台无限运行线程的常见特征。通常，Python 会等待所有线程终止后解释器退出。然而，对于不终止的后台任务，这种行为通常是不希望的。设置 `daemon` 标记会让解释器在主程序退出后立即退出。在这种情况下，守护线程会被直接销毁。

## Timer 对象（定时）

`Timer` 对象用于在未来的某个时间执行函数。

```
Timer(interval, func, args=[], kwargs={})
```

创建一个定时器对象，在经过 `interval` 秒后运行 `func`。`args` 和 `kwargs` 提供了传递给 `func` 的参数和关键字参数。在调用 `start()` 方法之前，定时器不会启动。

`Timer` 对象 `t` 具有以下方法：

```
t.start()
```

启动定时器。

```
t.cancel()
```

如果函数尚未执行，则取消定时器。

## Lock 对象（锁）

锁（`Lock`，或互斥锁）是一种同步原语，防止多个线程同时访问共享资源。锁处于锁定或未锁定状态之一。

```
Lock()
```

创建一个新的锁对象。`Lock` 实例支持以下方法：

```
lock.acquire(blocking=True)
```

获取锁。如果锁已经锁定，此方法将阻塞直到锁被释放。如果获取成功则返回 `True`。

```
lock.release()
```

释放锁。

## RLock（重入锁）

重入锁（reentrant lock）是一种与 `Lock` 类似的同步原语，但可以被同一个线程多次获取。这允许线程执行嵌套的 `acquire()` 和 `release()` 操作。

```
RLock()
```

创建一个新的重入锁对象。`RLock` 对象 `rlock` 支持以下方法：

```
rlock.acquire(blocking=True)
```

获取锁。如果已锁定，此方法将阻塞直到锁被释放。如果此线程已拥有该锁，则递归层级增加并立即返回。

```
rlock.release()
```

通过减少递归层级来释放锁。如果减少后递归层级为零，则锁重置为未锁定状态。

## Semaphore（信号量）

信号量是一种基于计数器的同步原语，计数器每次调用 `acquire()` 时减少，每次调用 `release()` 时增加。如果计数器达到零，`acquire()` 方法将阻塞直到某些线程调用 `release()`。

```
Semaphore([value])
```
