# 样条的轮廓化和挤伸

你刚刚看到如何通过样条和旋转修改器创建一个酒杯。现在，让我们来看一种在许多方面更简单但对样条要求完全不同的对象。墙通常用直线段绘制，并且需要很高的准确性。在接下来的练习中，你将学习如何使用精确坐标绘制样条。

## 在 `VIZ` 中创建墙的其他方法

此示例旨在演示处理样条的技术，而不一定是你在现实世界中会的方法。`VIZ` 提供了一套建筑、工程和施工（`AEC`）工具，其中包括墙工具。`AEC` 工具提供了面向墙体和楼梯等建筑组件创建的专用功能。`VIZ` 的 `AEC` 墙工具工作方式与这里描述的样条略有不同，并为门窗提供了一些节省时间的功能。你将在第 5 章中学习 `AEC` 工具。你还可以将 `AutoCAD` 和建筑图纸链接到你的 `VIZ` 场景，并使用 `VIZ` 工具集在 `AutoCAD` 中操作墙。绘制链接在第 17 章介绍。

## 绘制准确的线样条

你将从在一个文件中设置视图，该文件将包含你绘制墙的区域。墙将覆盖 20 英英的正方形区域，因此你需要包含一个覆盖 20 平方英的区域。

- 1. 选择 `File` ➤ `New`，在新场景对话框中选择 `New All`，并点击确定。
- 2. 选择 `Customize` ➤ `Units Setup`。在 `Units Setup` 对话框中，确保选择了 `US Standard` 和 `Feet w/Decimals`，并在默认单位设置中勾选 `Inches`。然后点击确定。

| 单位设置 | |
|---|---|
| 显示单位比例 | `米` |
| | `米` |
| `美国标准` | |
| `英制带小数` | `英寸` |
| 默认单位：英制 | `自定义` |

- 3. 点击 `Zoom Extents` 工具将视图恢复到默认缩放因子。
- 4. 点击视口，然后点击 `Maximize Viewport Toggle` 使其扩大适应整个视口区域。
- 5. 点击缩放工具并缩小，直到你在视口中的 `X` 方向上看到 `-12'-0"` 和 `12'-–0"`。
- 6. 点击 `Pan` 工具，并将视图向下向左移动，使 `0,0` 坐标位于视口的左下角。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_156_0.png)

现在你可以准备开始绘图了。你将画一个 20 英尺乘以 20 英尺的 `L` 型房间，每条边的长度为 10 英尺。

- 1. 如果还没有被选中，点击命令面板的 `Create` 选项卡。
- 2. 确保选择了 `Shapes` 和 `Splines`。然后点击 `Line` 按钮。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_156_1.png)

- 3. 找到底部的 `Keyboard Entry` 展开栏，如有必要，点击展开。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_156_2.png)

你会看到三个坐标输入框和标记为 `Add Point`、`Close` 和 `Finish` 的按钮。这些是你用来精确放置墙墙的工具。

- 1. 点击 `Add Point` 按钮。通过在坐标输入框所示坐标处插入起点来开始绘制墙。由于输入框显示的 `X`、`Y`、`Z` 坐标均为 `0,0,0`，因此线条从 `0,0,0` 开始。
- 2. 点击 `X` 坐标输入框并输入 `20'`。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_156_3.png)

- 3. 再次点击 `Add Point` 按钮。这可能并不明显，但你刚刚添加了一条从坐标 `0°0', 0°0', 0°0'` 到 `20°0', 0°0', 0°0'` 的线段。
- 4. 双击 `Y` 坐标输入框，输入 `10'`，并点击 `Add Point` 按钮。添加另一条线段。
- 5. 双击 `X` 坐标输入框，输入 `10'`，并点击 `Add Point` 按钮。
- 6. 双击 `Y` 坐标输入框，输入 `20'`，并点击 `Add Point`。
- 7. 双击 `X` 坐标输入框，输入 `0'`，并点击 `Add Point`。
- 8. 点击 `Close` 按钮。

你刚刚画墙的基础。

- 9. 点击 `Zoom Extents` 工具来查看墙的整体视图。

![](img/7e143440dd5a0ed9683d4f26f3c074f8_157_0.png)

## 给墙赋予厚度

现在你只有一个单线表示。要给墙赋予厚度，你可以使用 `Outline` 工具，你之前在酒杯练习中使用过它。

- 1. 点击命令面板的 `Modify` 选项卡。因为你刚刚创建了墙轮廓，所以轮廓已被选中，你可以在 `Modify` 选项卡中看到样条的选项。
- 2. 点击 `Selection` 展开栏中的 `Spline` 按钮。
- 3. 向滚动 `Modify` 面板到 `Geometry` 展开栏，即可看到 `Outline` 按钮。
- 4. 双击 `Outline` 按钮旁边的输入框并输入 `5"`。注意，轮廓内部出现了一个新的样条轮廓。这是墙的内侧。
- 5. 点击堆叠以退出样条层级。

在酒杯示例中使用 `Outline` 选项时，`VIZ` 将单线变成了连续的轮廓。在这个示例中，你实际上有两个样条，一个在另一个内部。尽管有两个样条，`VIZ` 仍认为它们是一个对象。这是因为新样条是在子对象层级创建的。正如你在下一个练习中看到的，样条的行为方式很独特。

- 1. 点击 `Maximize Viewport` 工具查看其他视口。
- 2. 点击 `Zoom Extents` 查看所有视口中的整个轮廓。
- 3. 点击面板顶部的下拉列表，点击 `Object` 类别下的 `Extrude`。

- 4. 在 `Parameters` 展开栏中，点击输入框并输入 `8"`。
