
### 凯莱树公式

算法 3.21 表明，顶点集为 $\{1, 2, \dots, n\}$ 的树的 `Prüfer` 序列是一个长度为 `n-2` 的序列，其各项属于 $\{1,2,\dots,n\}$，而算法 3.22 构造了一个阶为 `n` 的图（将被证明是一棵树），其 `Prüfer` 序列是给定的序列。我们现在使用 `Prüfer` 序列来验证凯莱树公式 [44]。

**定理 3.23 (凯莱树公式)。** 对于每个正整数 `n`，存在 `n^{n-2}` 棵具有相同顶点集的不同带标签树，阶为 `n`。

**证明。** 结果对于 `n=1` 和 `n=2` 是显然的。对于 `n >= 3`，我们使用归纳法证明：由 `n` 个正整数组成的固定顶点集 `S` 的不同带标签树集合与长度为 `n-2` 且各项属于 `S` 的序列集合之间存在一一对应关系。根据算法 3.21，顶点集为 `S` 的阶为 `n` 的每棵树的 `Prüfer` 序列是一个长度为 `n-2` 且各项属于 `S` 的序列。一旦我们证明对于每个这样的序列，仅有一棵顶点集为 `S` 的阶为 `n` 的树具有该 `Prüfer` 序列，证明即完成。

对于 `n=3`，设 `S` 为三个正整数的集合，例如 `S={1,2,3}`。顶点集为 `S` 的树有三棵，如 [图 3.11](#) 所示。这些树的 `Prüfer` 序列分别为 `(1)`、`(2)` 和 `(3)`。因此，结果对于 `n=3` 成立。

假设对于 `n >= 4`，对于每个长度为 `n-3` 且各项属于固定的 `(n-1)` 个正整数组成的集合 `S0` 的序列 `s0`，算法 3.22 构造出一棵唯一的阶为 `n - 1`、顶点集为 `S0` 且 `Prüfer` 序列为 `s0` 的树。

现在设 `S = {1, 2, ..., n}`，设 `s` 是一个长度为 `n - 2` 且各项属于 `S` 的序列。设 `G` 为由算法 3.22 构造的图。目标在于证明 `G` 是具有 `Prüfer` 序列 `s` 的唯一一棵树。

设 `k` 为 `S` 中不属于 `s` 的最小元素。根据算法 3.22，`k a1` 是所构造的图 `G` 中的一条边。根据归纳假设，存在一棵唯一的树 `T'`，其顶点集为 `S' = S - {k}`，`Prüfer` 序列为 `s' = (a2, a3, ..., a_{n-2})`。由于 `G` 是通过向 `T'` 添加新顶点 `k` 并将 `k` 连接到 `a1` 得到的，因此图 `G` 是唯一确定的树。此外，`G` 的顶点集为 `S`，且其 `Prüfer` 序列为 `s`。

图 `G` 的生成树是 `G` 的一个生成子图，且该子图是一棵树。只有当 `G` 是连通图时，`G` 才可能包含生成树。由于阶为 `n` 的每棵树的度（边数）为 `n - 1`，因此可以推断，如果 `G` 是一个阶为 `n` 且度为 `m` 的连通图，则 `m >= n - 1`。

连通图 `G` 的生成树可以通过多种方式获得。一种可能的方式是从 `V(G)` 开始。为了构造 `G` 的生成树 `T` 的边集 `E(T)`，我们首先选择 `G` 的一条边 `e1`。接下来选择 `G` 中不同于 `e1` 的边 `e2`。随后选择不同于之前所选边且不会与之前所选边形成环的边 `e3`。我们以此方式继续，直到不再选择任何边 `e_{n-1}`。此时 `E(T) = {e1, e2, ..., e_{n-1}}`。

产生连通图 `G` 的生成树 `T` 的另一种方式是从 `G` 开始。如果 `G` 是一棵树，则 `G` 本身就是生成树。否则，设 `f1` 是 `G` 中某个环上的一条边，并将其移除。设 `G1 = G - f1`。如果 `G1` 是一棵树，则 `G1` 是 `G` 的生成树。否则，设 `f2` 是 `G1` 中某个环上的一条边，并将其移除。设 `G2 = G1 - f2`，并以此方式继续，直到没有环剩余。以这种方式得到的生成子图 `T` 是 `G` 的生成树。因此，必须从 `G` 中删除 `m - (n - 1) = m - n + 1` 条边以获得 `T`。数字 `m - n + 1` 被称为 `G` 的圈秩。因此，一棵树的圈秩为 `0`。

如果 `G` 是一个阶为 `n`、度为 `m` 且圈秩为 `1` 的连通图，则 `m - n + 1 = 1`，因此 `n = m`。这样的图因此是一个恰好包含一个环的连通图。这些图被称为单圈图。[图 3.14](#) 中的所有图都是单圈图。

## 3.3. 生成树

构建 `G` 的生成树 `T` 的另一种方式是从 `G` 的一个顶点 `v` 开始。假设 `v` 的离心率 `e(v)` 为 `k`。对于 `i = 0, 1, ..., k`，设

$$ A_i = \{u \in V(G) : d(u, v) = i\} . $$

`A_i`（其中 `1 <= i <= k`）中的每个顶点 `w` 都与 `A_{i-1}` 中的一个或多个顶点相邻。在 `A_{i-1}` 中恰好选择一个这样的顶点 `x`，并设 `wx \in E(T)`。那么 `T` 是一个生成树，具有性质：对于每个 `u \in V(G)`，都有 `d_T(v, u) = d_G(v, u)`。这样的生成树 `T` 被称为相对于 `v` 是距离保持的。

对于 [图 3.15](#) 中的图 `G`，树 `T1` 和 `T2` 是 `G` 的生成树。树 `T2` 是相对于 `u` 距离保持的。Lesniak [155] 的下一个结果的证明使用了距离保持树的概念，以获得连通图半径的上界。

**定理 3.24。** 如果 `G` 是一个阶为 `n` 的连通图，则 `rad(G) <= n/2`。

**证明。** 设 `u` 是 `G` 的一个中心顶点，设 `T` 是 `G` 的一个相对于 `u` 距离保持的生成树。那么 `e_T(u) = e_G(u)`。此外，对于 `G` 中的每个顶点 `z`，我们有 `e_G(z) <= e_T(z)`。因此，`rad(T) = rad(G)`，所以只需证明 `rad(T) = e_T(u) <= n/2`。

假设相反的情况成立，即 `e_T(u) >= (n+1)/2`。显然，`n >= 3`。此外，`u` 是 `T` 的一个割点。由于 `e_T(u) >= (n+1)/2`，森林 `T-u` 有一个阶至少为 `(n+1)/2` 的连通分量 `T'`。设 `v` 是 `T'` 中在 `T` 中与 `u` 相邻的唯一顶点。对于 `T'` 中的每个顶点 `w`，我们有 `d_T(v, w) = d_{T'}(u, w)-1`（注：原文此处逻辑似有笔误，通常应为 `d_T(v,w) = d_{T'}(v,w)` 或类似关系，但根据上下文推导 `d_T(v,w) < e_T(u)`），这暗示 `d_T(v, w) < e_T(u)`。对于 `T` 中不在 `T'` 中的每个顶点 `w`，我们有 `d_T(v, w) = d_T(u, w)+1`。由于 `T` 中不在 `T'` 中的顶点最多有 `(n-1)/2` 个，因此 `d_T(u, w) <= (n-3)/2`。因此，对于 `T` 中的每个顶点 `v`（注：此处原文符号混用，指代 `T` 中任意中心候选顶点或特定顶点，结合上下文应理解为对于 `T` 中任意顶点 `v'` 或特定构造的 `v`），我们有

$$ d_T(v, w) <= (n-1)/2 < e_T(u) . $$

然而，这意味着 `e_T(v) < e_T(u)`，这与 `u` 是 `T` 的中心顶点这一事实相矛盾。
