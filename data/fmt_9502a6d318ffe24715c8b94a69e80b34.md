## 进程

`iostat` 命令可用于测量系统负载的 I/O 响应，提供了通用 I/O 使用情况的简要概述。存在一些图形化前端，可以将这些命令的输出转换为人类易于理解的形式。

每个设备都有自己的问题，但网络接口可用带宽和磁盘可用带宽是 I/O 性能瓶颈的两个主要原因。

网络 I/O 问题：

- 网络过载：

  传输在网络上的数据量超过了网络容量，导致所有用户每个与网络相关的任务的执行都变慢。这可以通过清理网络（意味着禁用你不需要的协议和服务）或重新配置网络（例如划分子集、用交换机替换集线器、升级接口和设备）来解决。

- 网络完整性问题：

  当数据传输错误时发生此类问题。解决此问题只能通过隔离故障元件并将其替换来实现。

磁盘 I/O 问题：

- 单进程传输速率过低：/

  单个进程的读取或写入速度不足。

- 聚合传输速率过低：

  系统为所有运行的程序提供的最大总带宽不足。

这类问题更难检测，如果是因为硬件过载导致的问题，通常需要额外的硬件来重新划分数据流、控制器和磁盘。解决此问题的一种方案是针对输入输出操作优化的 RAID 数组配置。通过这种方式，你可以获得相同的硬件。另一种选择通常是升级更快的母板、控制器和磁盘。

如果过载不是原因，可能是你的硬件正在逐渐失效，或者与系统的连接良好。。从检查接触点、连接器和插头开始。

## 用户

用户根据其资源使用行为可以分为几类：

- 运行（大量）许多小任务的用户：例如，你这样的 Linux 初级用户。

- 运行相对较少大型任务的用户：运行仿真、计算、仿真器或其他消耗大量内存程序的用户，通常这些用户还伴有大型数据文件。

- 运行任务很少但使用的 CPU 时间很短的用户（开发者及此类人员）。

你可以发现，这些需求对于每类用户可能有所不同，而且很难满足所有人。如果你在一个多用户系统上，了解其他用户和系统的习惯是有用的（而且很有趣），以便为了你的特定目的充分利用其价值。

# 中断你的进程

作为非特权用户，你只能影响自己的进程。我们已经看到了如何显示进程并过滤掉属于特定用户的进程，以及可能发生哪些限制。

当你发现你的一个进程占了过系统资源时，你有两件事可以做：

1. 在不中断进程的情况下让进程使用更少资源；
2. 完全停止进程。

如果你想让进程继续运行，但又想给系统上的其他进程一个机会，你可以 `renice` 该进程。除了使用 `nice` 或 `renice` 命令外，`top` 是发现问题进程（们）并降低优先级的简单方法。

在 "NI" 列中识别该进程，它可能具有负优先级。输入 `r` 并输入你想要 renice 的进程的 ID。然后输入 nice 值，例如“20”。这意味着从现在起，该进程最多将占用 1/n 的 CPU 周期。

你想保持继续运行的进程示例包括编辑器、虚拟机、编译器等。

如果你因为进程挂起或在 I/O 消耗、文件创建或其他系统资源使用方面完全失控而想停止进程，请使用 `kill` 命令。如果有机会，先尝试软杀 掉进程，发送 SIGTERM 信号。这是一个指令，让通过程序代码中描述的操作来终止它：

```
joe:: ps -ef | grep mozilla
joe 25822 1 Marill 00:34:04 /usr/lib/mozilla-1.4.1/mozilla-
joe:: kill -15 25822
```

在上面的示例中，*joe* 停止了他的 Mozilla 浏览器，因为内核挂了。

有些进程很难被掉。如果你有时间，你可能想向它们发送 SIGINT 信号来中断它们。如果这也不行，请使用最强信号 SIGKILL。在下面的示例中，joe 停止了一个冻结的进程：

```
joe:: ps -ef | grep mozilla
joe 25915 1 Marill 00:15:06 /usr/lib/mozilla-1.4.1/mozilla-
joe:: kill -9 25915
```

```
joe:: ps -ef | grep 25915
joe 2634 32273 0 18:09 pts/4 00:00:00 grep 25915
```

在这种情况下，你可能想再次对 PID 使用 `grep` 过滤器来检查进程是否真的死了。如果这只返回 `grep` 进程，你就可以确定成功停止了进程。

## 利用空闲时间！

Linux 系统的 sleep 帮助页可能是最短的之一。sleep 做的就是等待。默认情况下，时间以秒为单位。

为什么它存在？一些实际例子：

有人打电话给你，你说“我半小时后给你回”，但你现在正被工作淹没，注定会忘记午饭：

```
sleep 1800; echo "Lunch time.." &
```

当你由于某些原因无法使用 at 时，是五点了，你想回家但还有工作要做，而现在你的由于系统正在崩溃：

```
sleep 10000; myprogram &
```

确保你的系统设置了自动注销，并在提交此类任务时注销或锁定你的桌面/办公室，或者在 screen 会话中运行。

当你运行一系列大文件，但其他用户仍要在期间打印时：

```
lp lotext; sleep 900; lp hugefile; sleep 900; lp anotherlargefile
```

打印文件将在第 8 章打印机与打印中讨论。

程序员经常使用 sleep 命令来停止脚本或程序执行特定的时间。
