
你还可以发现其他几种 shell 解释器，如 C shell、Korn shell 以及其他。要将脚本解释器定义为 `BASH`，你首先需要使用 `which` 命令找到其可执行二进制文件的完整路径。此命令需要以 shebang 或 `# !` 为前缀。你需要将其插入到脚本的第一行。还有其他定义你的 shell 解释器的方法，但这被认为是最佳选择。

## 文件权限与名称

为了执行 shell 脚本，你的文件需要通过 `chmod +x FILENAME` 命令被设为可执行形式。无论文件扩展名的后缀是什么，任何形式的新新创建的文件默认情况下都不会是可执行形式。在基于 Linux 或 GNU 的系统上，使用 `file` 命令来识别文件类型。

## 脚本执行

简单来说，bash 脚本无非一个简单的文本文件，其中包含了从上到下按顺序执行的指令。指令的解释方式取决于定义的 shebang 或脚本被执行的过程。

还有另一种执行 bash 脚本的方法，即按显式顺序调用 bash 解释器，例如通过 `$ date.sh`。通过显式形式调用二进制可执行文件，`date.sh` 的文件内容将被加载并被解释为 bash shell 脚本。

## 简单备份 Shell 脚本

任何可以通过 bash shell 终端成功执行的命令，都可以以类似的形式作为 bash 脚本的一部分使用。直接通过终端执行命令与在 shell 脚本中执行命令之间没有本质区别，唯一的区别在于脚本 shell 为单进程进程内的各种命令提供了一种非交互形式的执行方式。大多数命令都接受参数和选项。命令选项用于修改命令的行为，以便产生另一种形式的输出结果，这些结果以 `-` 开头。参数可以指定针对目标（如目录、文件、文本等）的命令执行。

你可以使用 `man` 命令来显示任何所需命令的帮助页。例如，为了显示 `ls` 命令的帮助页，你可以执行命令 `man ls`。要退出帮助页，你可以按 `q` 键。

## 变量

变量可以被视为编程的核心精髓。它允许程序员在整个脚本过程中存储数据、重用并修改相同的数据。你可以使用变量创建一个如 `welcome.sh` 的全新脚本。

## 输入与输出

在 Linux/GNU 命令行上执行的命令要么需要输入、产生输出或显示错误信息。这是 shell 脚本的一个非常基础的概念，与通用的 Linux 或 GNU 命令行操作一样。

每当你执行一次命令时，都有可能的结果：第一种可能性是产生输出，第二种可能性是产生错误，第三种可能性可能产生任何形式的输出。

# 第 7 章：网络基础

在当今这个万物触手科技的世界，网络已成为建立新业务或组织的必要组成部分。网络有助于通过各种形式与一组相关设备或系统（端点，或主机或主系统）进行无缝连接。它对于全球所有服务提供者、企业和消费者同时进行通信和互连占据着非常重要的地位。
网络的概念伴随着几乎所有的事物，如短信、电话通话、视频流等等。

网络的操作伴随着一些复杂的技能，这在很大程度上取决于其复杂性。例如，在一个大型企业中，有多个节点以及对网络安全的要求，例如管理员的功能、加密以及其他。另一方面，任何仅在家中使用网络和互联网进行日常工作的人，都可以轻松进行设置，并解决无线网络性质的若干基础问题。

## 网络基础

为了正确理解网络的功能及其组件，你需要了解基础知识。计算机系统网络由几个元素组成，这些元素有助于整体的运行。

## 网络类型

计算机网络可以分为两大类：有线和无线。在谈到有线网络时，它需要一种物理形式的网络，用于在两个节点之间传输信息。对于商业场所家庭的数字通信，由于其整体的成本效益和耐用性，使用了以太网线。今天，光纤也被用于跨距离的数据传输。

光纤提供的速度比以太网线更快。然而，与光纤相比，以太网线便宜得多。

在无线网络形式中，利用电波通过空气传输数据。在这种情况下，设备之间不需要任何形式的电缆连接。无线局域网（WLAN）被广泛用于网络目的。今天可以找到各种替代方案，如蓝牙、卫星、蜂窝网络和微波等。

通过各种实践经验发现，与无线网络模式相比，有线网络具有更好的速度、安全可靠性。但与有线网络相比，无线网络具有更大的扩展性、灵活性。两种类型的网络都根据网络的物理层进行分类。它还可以根据网络的构建和设计结构、网络叠加以及用于 SDN 的方法进行区分。网络还可以根据广域网（WAN）、局域网（LAN）、存储区域网（SAN）、环境等方面进行分类。

## 网络系统及其类型

当你遇到网络系统时，你会发现两种类型：开放和闭式。在开放系统中，整个系统与网络保持连接并准备进行任何类型的通信。在闭式系统中，系统与网络断开，你无法连接网络。

## 网络组件

网络系统需要适当物理形式的网络基础设施。它由多个网络组件组成，如交换机、路由器、访问点以及一些基础形式的固件，这些固件最终有助于连接组件的运行。其他组件包括用于网络安全、监控和管理的软件。

为网络中的每一个设备设置一种唯一的标识形式。网络中发现的 IP 地址采用 32 位结构。IPV4 由 IANA 为网络内的所有系统分配。

每个网络主机的物理形式形式的地址被称为 MAC 地址。它与网络接口卡（NIC）保持连接。你可以找到 48 位或 12 个半字节（nibble）的 MAC 地址。MAC 地址是在设备制造时分配给设备的。

# 第 8 章：代理与代理链

随着技术的进步，黑客的数量每天都在增加。在谈到黑客时，有些人是友好的，而另一些人可以被认为是坏的。恶意黑客利用黑客手段来偷取昂贵和机密信息，为了金钱，有些甚至为了好玩而进行黑客。恶意黑客倾向于通过传播有害恶意软件和其他恶意物品，在网络安全世界制造混乱局面。好的黑客也可能为了钱进行黑客，但他们以正确的方式进行，例如参与漏洞赏金计划、帮助他人妥善备份所有丢失的数据、学习系统内部可能的漏洞以让管理员意识到可能的威胁等。

“黑客”并不意味着他们是那些能够进入网络安全世界中任何受限区域的人；他们也是管理公司或组织安全的 IT 专家。大多数黑客在进行黑客活动时需要保持匿名，他们总是努力让自己难以被发现。黑客使用各种类型的工具来隐藏自己的身份，例如 VPN（虚拟专用网络）、RDP（远程桌面协议）和代理服务器（ProxyServers）。

为了完全匿名地执行渗透测试并降低整体被检测的概率，黑客需要使用某种中介设备，其自身的 IP 地址将留在目标系统中。黑客通过使用代理来实现这一目的。代理服务器或代理是专用软件或计算机系统的一种形式，它也运行在计算机系统上，并充客户端服务器与终端设备（如计算机系统）之间的中介。通过代理连接互联网，客户端系统的 IP 地址将不会显示，而将代之显示代理服务器的 IP 地址。这有助于在客户端直接连接互联网时提供更多的隐私保护。

## ProxyChains 的功能

ProxyChains 的主要功能是：

- 它支持 SOCKS4、SOCKS5 以及基于 HTTP CONNECT 的代理服务器。
- ProxyChains 可以与列表中的任何其他类型的代理混合。
- ProxyChains 支持多种链式方法，例如：随机模式（random），即在配置文件的列表中随机选择任何一个代理；或者按类似的列表顺序链式代理，通过文件中的换行符将不同形式的代理彼此分开。它还带有一个动态选项（dynamic），ProxyChains 只通过那些本身处于活动状态的代理。它排除了任何形式的无法访问或失效的代理。这种代理形式也被称为智能选项（smart option）。
- 你可以将 ProxyChains 与 sendmail、squid 等许多服务器一起使用。
- ProxyChains 还具有通过代理解析 DNS 的。
- 它可以处理任何形式的 TCP 客户端应用程序，如 telnet、nmap 等。

## ProxyChains 的语法

与其仅仅运行简单的渗透测试或直接使用你的 IP 地址创建各种目标请求，你可以使用 ProxyChains 来涵盖并处理这些工作。你只需要为每项任务添加命令 `proxychains` 即可。这将启用 ProxyChains 服务。

例如，你想使用 ProxyChains 通过 Nmap 扫描网络中的某些可用主机及其端口，命令看起来如下：

```
proxychains nmap 192.168.0.0/25
```
