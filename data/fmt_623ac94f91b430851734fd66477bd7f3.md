
# KeepPassXC

访问`KeepPassXC`官方网站`https://keeppassxc.org/`了解有关`KeepPassXC`的所有信息。

通过软件管理器安装`DEB`/`FLATPAK`软件包：

1. 打开软件管理器并搜索`KeepPassXC`。
2. 点击`KeepPassXC`，然后点击源选择框。
3. 选择系统软件包（System Package）或`Flatpak`，并点击安装。

通过终端通过`APT`安装`KeepPassXC`：

只需输入这些命令：

```bash
sudo apt update
sudo apt install keeppassxc
```

通过终端通过`Flatpak`安装`KeepPassXC`：

输入此命令：

```bash
flatpak install flathub org.keeppassxc.KeepPassXC
```

## Buttercup

访问`Buttercup`官方网站`https://buttercup.pw/`了解有关`Buttercup`的所有信息。

通过图形界面通过`AppImage`安装`Buttercup`：

1. 导航到发布页面：`https://buttercup.pw/`。
2. 点击`Linux (AppImage)`下载`Buttercup`。
3. 将文件下载到您的`~/Downloads`文件夹。
4. 双击`Buttercup-linux-x86_64.AppImage`文件开始安装过程。

通过命令行和图形界面创建`Buttercup AppImage .desktop`快捷方式：

要为`Buttercup-linux-x86_64.AppImage`创建`.desktop`快捷方式，请在终端中遵循以下步骤：

使用命令进入应用程序目录：

```bash
cd /usr/share/applications
```

通过运行以下命令打开一个新的`.desktop`文件进行编辑：

```bash
sudo edit buttercup1.desktop
```

在`openoffice1.desktop`文件中，输入以下信息：

```ini
[Desktop Entry]
Name=Buttercup
Comment=Buttercup
Exec=./Applications/Buttercup.AppImage
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

保存进度时，点击“保存”。或者，您可以点击“文件”，然后点击“保存”，或点击`≡`图标，选择“另存为”，最后点击“保存”。保存后关闭编辑器。

# 媒体播放器

媒体播放器（包括软件和硬件）从存储设备、光盘或互联网等各种来源播放音频和视频文件。它们可能需要解码器来播放某些格式，可以流传输在线内容，并且对`DVD`和蓝光的支持程度不相同。媒体播放器的选择会影响媒体质量，并且可以为不同的格式准备多个播放器。媒体播放器与存储和共享文件的媒体服务器不同。虽然许多播放器不是为编辑设计的，但许多播放器支持字幕、更新以及通过皮肤进行自定义。开源播放器提供广泛的格式支持和自定义。播放列表组织媒体播放，某些播放器还可以转换文件格式或播放网络电台。轻量级媒体播放器使用的系统资源极少，适用于配置较低的系统。

`VLC`是一款多功能、免费且开源的媒体播放器，适用于桌面以及`Android`和`iOS`等移动平台。它由`VideoLAN`项目开发，支持多种音频、视频和流媒体格式，包括`DVD`。特别重要的是它可以流传输媒体并转码文件。`VLC`内置解码器来自`libavcodec`库，并通过`libdvdcss`在`Linux`和`macOS`上唯一支持加密`DVD`播放。它在各大应用商店可用，由于`DVD`解密功能，其法律地位因地区而异。

`Parole Media Player`是一个为`Xf`桌面设计的简单现代媒体播放器，利用`GStreamer`框架播放各种类型的媒体，包括本地文件、`DVD`和流媒体。它轻量且支持插件扩展，旨在高效运行并最少地使用资源。虽然它支持拖放播放列表和基本的播放控制，但缺少高级配置选项，并且处理损坏文件和高分辨率显示器表现不佳，因此不如`mpv`或`VLC`灵活。

`SMPlayer`是一款适用于`Windows`和`Linux`的多功能、免费开源的媒体播放器，提供内置解码器，可无缝播放任何视频和音频格式。它独特地记录每个文件的播放设置，确保您在相同的设置下从上次离开的地方继续播放。作为`MPlayer`的图形界面，它还支持`YouTube`播放、字幕下载，并拥有一系列皮肤和高级功能，且均不需要外部解码器。`SMPlayer`支持30多种语言，让跨平台的媒体播放变得简单且可自定义。

`Haruna`是一款为`KDE Plasma`设计的开源视频播放器，提供了丰富的功能，包括通过`youtube-dl`播放在线视频、`YouTube`播放列表支持、自动播放列表和自定义快捷键。其直观的设计、易于导航以及对各种视频格式的兼容使其成为`Linux`用户的卓越选择。通过自动跳过章节和可调字幕设置等功能，`Haruna`增强了观看体验。在`Flathub`和`Ubuntu`上可用。

输入此命令：

```bash
sudo snap install smplayer
```

## 在终端通过 Flatpak 安装 SMPlayer：

```bash
flatpak install flathub info.smplayer.SMPlayer
```
