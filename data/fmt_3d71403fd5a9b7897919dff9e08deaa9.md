## Linux 字典

### `squidguard`
`SquidGuard` 的过滤器、重定向和访问控制插件是一个适用于 `squid` 的 (GPL)、灵活且极快速的过滤器、重定向和访问控制插件。它允许在 `squid` 缓存上为不同的用户组定义具有不同限制的多个访问规则。`SquidGuard` 使用 `squid` 的重定向接口。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

### `squidtaild`
`sid` 日志监控。`Squidtaild` 是一个非常快速、高度可配置的 Perl 程序，它可以动态创建 html 页面，显示人们在对 `squid` 代理系统应用的一个或多个过滤器时犯的违规行为。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

### `squirrelmail`
`SquirrelMail` 的 Webmail 是用 PHP 编写的基于标准的 Web邮箱包。它内置了对 IMAP 和 SMTP 协议的 PHP 支持，且所有页面均渲染为 HTML 4.0（不使用 Javascript），以实现跨浏览的最大兼容性。它的需求极少，且非常易于配置和安装。`SquirrelMail` 拥有邮件客户端所需的所有功能，包括强大的 MIME 支持、地址簿和文件夹映射。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

### `squishdot`
网络新闻/讨论系统。`Squishdot` 是一个针对对象发布环境 (`ZOPE`) 的基于 Web 的新闻发布和讨论项目。它允许通过最少的配置和日常管理，构建一个能够处理线程式讨论的 站点。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

### `sqwebmail`
Web邮箱。此包包含 `SqWebMail` 邮件服务器。`Courier` 邮件服务器使用 CGI 为本地邮箱提供 Web 访问。`SqWebMail` 在此处作为一个独立包提供，可以与其他邮件服务器配合使用。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html
