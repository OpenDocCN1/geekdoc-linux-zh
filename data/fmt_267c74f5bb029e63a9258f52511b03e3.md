
随着负荷的降低，由于燃料-空气混合比更稀薄以及提前断油，柴油机的有效热效率逐渐提高。这种混合比可能稀薄到无法在奥托发动机中点燃。此外，奥托发动机降低负荷需要节流，这会在进气系统中产生不断增加的泵气损失。[N MacC.; D L An.]

## 内能

热力学系统状态的一个特征属性，引入于热力学第一定律。对于一个静止、封闭的系统（没有整体运动，没有物质穿越边界），某一过程的内部能量变化等于系统从周围吸收的热量减去系统对周围所做的功。只能测量内能的变化，而不能测量其单一状态下的数值。对于给定的过程，内能的变化由初始和最终状态决定，并独立于状态变化所经过的路径。参见“热力学原理”。[P J B.]

## 国际日期变更线

180° 经线，这里是每天官方开始和结束的地方。当一个人向东旅行（逆着太阳的视运动方向）时，每跨越 15° 经度就会快 1 小时；向西旅行时，则以相同的速率变慢。如果两个人从任意一条经线出发，以相同的速度朝相反方向小步绕地球一圈，当他们相遇时，时间将是相同的，但日期会相差 1 天。当旅行者向西越过该线时，会失去一天；如果线东侧是星期一，那么旅行者越过国际日期变更线后，立即变为星期二。

180° 经线作为国际日期变更线是理想的（见插图）。它正好位于零度（格林尼治）经线的对跖点，即地球的另一侧，所有的经度都是从此处算起的。它也几乎位于最大的海洋中心；因此，就人口中心而言，带来的不便最少。为了保持某些地区在同一天内，曾对对齐方式做过一些偏离，例如将该线向东绕西伯利亚弯曲，以及向西绕阿留申群岛弯曲，以使它们与阿拉斯加其余部分处于同一天。为了同样的目的，在基里巴斯、赤道以及南太平洋的斐济群岛附近也做过其他变化。参见“数学地理学”。[V.E]

## 互联网

一个全球性的互联计算机网络系统。互联网的起源可追溯到 ARPANET（高级研究计划局网络）的创建，这是 1969 年由美国国防部主管的一个计算机网络。如今，互联网以通信史上前所未有的非层级方式连接了全球数百万台计算机。互联网是媒体、计算机和电信融合的产物。它不仅仅是一项技术发展，也是与学术界和政府（国防部）相关的社会和政治力量的产物。从其源于非工业、非公司的环境和纯粹的学术文化，互联网迅速渗透到商业领域。

互联网是几种媒体技术的结合，也是报纸、杂志、书籍、目录、公告板等的电子版。这种多功能性赋予了互联网强大的力量。

### 技术特征

互联网的技术成功取决于其主要的通信工具：传输控制协议（TCP）和互联网协议（IP）。它们常被统称为 TCP/IP。协议是一套商定的惯例，定义了通信规则。TCP 负责分解和重新组装数据包，而 IP 负责确保数据包被发送到正确的目的地。

数据通过多层网络在互联网上传输，直到到达目的地。电子邮件消息通过调制解调器连接的远程个人计算机，或局域网上的节点，到达邮件服务器（类似于当地邮局）。从服务器开始，消息通过路由器，这是一种专用计算机，确保每条消息被发送到正确的目的地。一条消息可能经过几个网络才能到达目的地。每个网络都有自己的路由器，它决定如何最好地将消息向目的地靠近，同时考虑网络上的流量。消息从一个网络传递到下一个网络，直到到达目的地网络，然后可以将其发送给位于该网络上的收件人，收件人在该网络上有一个邮箱。参见“电子邮件”；“局域网”；“广域网”。

### TCP/IP

TCP/IP 是一套旨在允许协作计算机跨网络共享资源的协议。TCP/IP 确立了消息通过网络传输的标准和规则。最重要的传统 TCP/IP 服务包括文件传输、远程登录和邮件传输。文件传输协议（FTP）允许一台计算机上的用户从另一台计算机获取文件，或将文件发送到另一台计算机。安全性通过要求用户指定另一台计算机的用户名和密码来处理。

网络终端协议（TELNET）允许用户登录到网络上的任何其他计算机。用户通过指定要连接的计算机来启动远程会话。在那里，用户可以执行会话中的任意或全部操作；用户输入的任何内容都会发送到另一台计算机。

邮件传输允许用户向其他机器上的用户发送消息。最初，人们倾向于只使用一台或两台特定的计算机。他们会在这些机器上维护“邮件文件”。计算机邮件系统只不过是用户向另一用户的邮件文件添加消息的一种方式。

服务也变得重要起来：资源共享、无盘工作站、计算机会议、事务处理、安全性、多媒体访问和目录服务。

TCP 负责将消息分解为数据报，在另一端重新组装数据报，重传任何丢失的内容，并将事物恢复到正确的顺序。IP 负责路由单个数据报。数据报通过唯一的序列号单独标识，以便按正确顺序重新组装。整个传输过程是通过使用路由器完成的。路由是两种通信站点对任何复杂程度的网络寻找并使用最优路径的过程。路由器必须支持分片，即在需要时将接收的信息划分为更小的单元，以匹配底层网络技术。路由器通过识别特定的网络号与互联网络内特定区域的关系来工作。它们在整个过程中跟踪这些号码。

### 域名系统

互联网上的寻址系统生成 IP 地址，通常由数字表示，例如 128.201.86.290。由于这些数字难以记忆，已创建一个用户友好的系统，称为域名系统（DNS）。该系统提供了数字 IP 地址的助记等价物，并进一步确保互联网上的每个站点都有一个唯一的地址。例如，一个互联网地址可能显示为 ctiro.edu。如果通过 Web 浏览器访问此地址，则被称为 URL（统一资源定位符），完整的 URL 将显示为 http://www.ctiro.edu/。

域名系统将互联网划分为一系列称为域的组件网络，这使得电子邮件（和其他文件）能够跨越整个互联网发送。连接到互联网的每个站点都属于其中一个域。例如，大学属于“edu”域。其他域包括 gov（政府）、com（商业组织）、mil（军事）、net（网络服务提供商）和 org（非政府组织）。

### 万维网

万维网（WWW）基于称为超文本的技术。Web 可以被视为互联网的一个非常大的子集，由超文本和超媒体文档组成。超文本文档是一个包含指向另一个超文本文档的引用（或链接）的文档，该文档可能位于同一计算机或位于世界任何地方的不同计算机上。超媒体是一个类似的概念，除了文本文件外，它还提供指向图形、声音和视频文件的链接。

为了让 Web 正常工作，每个客户端必须能够显示来自任何服务器的任何文档。这是通过实施一套被称为协议的集来实现的，该协议规范数据在 Web 上的传输方式。因此，数据通过称为超文本传输协议（http）的协议从客户端传输到服务器，再传回。为了访问通过此协议传输的文档，需要一个特殊的程序，称为浏览器，用于浏览 Web。参见“万维网”。

### 互联网上的商务

互联网上的商务有几个其他名称，如电子商务（e-business）、电子零售（Etail/electronic retailing）和电商（e-commerce）。电子商务的优势取决于互联网的优势。互联网商务分为两大主要部分：企业对企业（B2B）和企业对消费者（B2C）。在这两个领域中，有一些公司是在互联网上创业的，另一些公司则之前已经存在，现在正在向内部潮湿的世界过渡。某些产品和服务，如书籍、光盘（CD）、计算机软件和机票，似乎特别适合在线商务。[A.V]

## 行星际物质

填充在行星系统内行星周围或行星之间空间的低密度尘埃或气体。太阳系内部大多数行星际物质是由小行星碰撞产生的尘埃或由彗星经过太阳时释放出来的。以高速从太阳喷射出的电离气体（即太阳风）也渗透着整个太阳系，并在与行星相互作用时产生多种重要的电磁效应。

一团称为黄道尘埃的尘埃云充满了小行星带内部的太阳系平面。在地球上，观察者可以在某些晴朗无月的夜晚用肉眼看到这团尘埃，因为它将阳光散射向地球方向。参见“黄道光”。

两颗卫星，即*红外天文卫星*（IRAS）和*宇宙背景探测器*（COBE），利用对宽范围红外波长（1–200 微米）敏感的检测器，对从地球观察到的黄道尘埃云进行了详细测绘。显著的小行星族——看起来是由单一较大天体碎裂而成的小行星群——形成了 IRAS 和 COBE 均能探测到的尘埃带。IRAS 和 COBE 还探测到了由个别彗星留下的尘埃尾迹，这些尾迹混入背景尘埃中。参见“小行星”；“彗星”；“红外天文学”。

太阳风在所有方向上以超音速从日冕向外流出，典型速度为 450 千米/秒（280 英里/秒），温度约为 100,000 开尔文。与日冕类似，太阳风主要由电离氢组成。在地球轨道处，风的密度约为每立方厘米 5 个粒子（每立方英寸 80 个粒子），或者约为 $8 \times 10^{-24}$ 克/立方厘米。参见“太阳风”。

小行星带与海王星轨道之间的区域似乎相对缺乏行星际尘埃。在海王星轨道之外，一个由彗星大小的冰质天体组成的环状结构，称为柯伊伯带，围绕太阳运行。毫无疑问，柯伊伯带天体之间会发生碰撞，产生盘状尘埃云。离太阳如此遥远的尘埃非常寒冷，因此其大部分热能以远红外波长（30–200 μm）辐射出来。低温使得这团尘埃云太暗，即使它的质量可能与黄道尘埃相当，也难以从地球附近探测到。参见“柯伊伯带”。
