
一个可移植的 TeX 导入器 `dvilib2` 是一个处理由 TeX 生成的设备无关（DVI）文件的库。它可以作为 Dijkstra 的核心引擎，并能够处理各种字体。由 `graphics.sty` 管理，并支持日语 DVI 文件。注意 `dvilib2` 不是 NDVI。它是你自己的库。如果你正在寻找一个完整的 DVI 查看器，为什么不尝试 `gdxv` 呢？此包包含了 `dvilib2` 所需的共享库和配置文件。它是 TeX 分发版的一部分。来自 Debian 3.0r0 APT http://www.tmdp.org/LDP/Linux-Dictionary/html/index.html

# `dvilix`

一个由 TeX 编译的 .dvi 文件的 Dvi 查看器。它让你看到你的打印输出像什么样。你可以在黑白和灰度之间进行选择。你可以选择任意缩放比例（这会稍微影响性能）。你可以设置标记来测量距离。你可以搜索字符串。你可以访问许多 DVI 文件，设置书签并保存到启动文件中，`dvips` 不支持 `pxl` 文件，`dvips` 忽略命令且没有字体替换机制。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# `dvipdfm`

Dvi 翻译器将 Knuth 的 Dvi 格式（通常由 TeX 生成）转换为 Adobe 便携文档格式（PDF）。重要功能包括：使用 Adobe Acrobat 包含 PDF、PNG、MetaPost 和 PostScript（通过外部程序帮助）嵌入图像；支持的 Dvi 可移植性；通过 GhostScript 支持 PostScript 字体；虚拟字体；支持任意字符转换；通过页面开始（BOP）和页面结束（EOP）放置 PostScript 图形；页面字体和平面压缩以减小尺寸；以及平衡页面以提高读取速度。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

# `dvisga`

一个 SVG 的 dvi 查看器，`dvisga` 是由 TeX 编译的 .dvi 文件的预览。它让你看到打印输出像什么样。你可以在黑白和灰度之间进行选择。你可以选择任意缩放比例（这会稍微影响性能）。你可以设置标记来测量距离。你可以搜索字符串。你可以访问许多 DVI 文件，设置书签并保存到启动文件中，`dvisga` 不支持 `pxl` 文件，`dvisga` 忽略命令且没有字体替换机制。来自 Debian 3.0r0 APT http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
