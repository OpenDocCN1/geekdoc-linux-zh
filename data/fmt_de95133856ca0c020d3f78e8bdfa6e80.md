## alias, unalias — 创建或删除别名

### 概要

```
/usr/bin/alias [alias-name=string] ...
/usr/bin/unalias alias-name ...
/usr/bin/unalias -a
```

```csh
alias [alias-name] [def]
unalias alias-name

ksh
*
alias [-tx] [alias-name=value] ...
unalias alias-name...
```

## 描述

`alias` 命令允许你定义简单的别名。你指定想要作为别名的名称，并定义一些文本，每当该单词作为命令使用时，shell 就会替换这些文本。由于一位工程师经常将 `more` 命令误打为 `moer`，他创建了一个别名，以便当他们输入 `more` 时就能执行该命令。你也可以创建别名来简化复杂的命令。使用 `unalias` 命令可以删除别名。

别名可以包含任意数量的单词，只要将它们包含在引号中。你也可以包含几个通过管道连接的命令。

`/usr/bin` 目录包含 `alias` 和 `unalias` 命令。C Shell 和 Korn Shell 也提供了内置的 `alias` 和 `unalias` 命令。Bourne shell 不提供别名功能。定义别新的语法根据环境而略有不同。

## alias, unalias

## /usr/bin/alias

要显示已定义的别名列表，请输入 `alias` 并按回车。别名定义会影响当前 shell 的执行环境以及当前 shell 子 shell 的执行环境。按照此处的指定使用时，别名定义不会影响当前 shell 的父进程或 shell 调用的任何命令环境。

## /usr/bin/unalias

`unalias` 命令删除每个指定别名名的定义。别名将从当前 shell 执行环境中移除。

## C Shell

若要在标准输出上显示当前定义的别名列表，请输入不带参数的 `alias` 并按回车。

要为当前 shell 定义别名，输入 `alias alias-name def` 并按回车。因为它们是保留字，你不能使用 `alias` 或 `unalias` 作为 `alias-name` 的名称。若要在 `def` 中包含空格，请将定义包含在引号中。

要显示特定别名的定义，输入 `alias alias-name` 并按回车。

在为当前 shell 定义别名时，你必须在之前的命令行中输入过别名才能使用它。

使用 `unalias` 命令放弃与 `alias-name` 匹配的别名。要删除所有别名，输入 `unalias *` 并按回车。

为了让你喜欢的别名更易可用，请将它们包含在 `.cshrc` 文件中。

## Korn Shell

Korn Shell 自带一组默认的预定义别名。要在标准输出上显示列表，请输入不带参数的 `alias` 并按回车。

要为当前 shell 定义别名，输入 `alias alias-name=value` 并按回车。`value` 末尾的空格会检查下一个单词的别名替换。因为它们是保留字，你不能使用 `alias` 或 `unalias` 作为 `alias-name` 的名称。

要显示特定别名的定义，输入 `alias alias-name` 并按回车。

使用 `unalias` 命令放弃与 `alias-name` 匹配的别名。要删除所有别名，输入 `unalias *` 并按回车。

为了让你喜欢的别名更易可用，请将它们包含在 `.profile` 文件或你的 Korn ENV 文件中。要创建 Korn ENV 文件，创建一个名为 `filename` 的文件并将别名放入其中。然后使用以下命令导出环境文件。

```
ENV=filename; export ENV
```

## alias, unalias

## 选项

### Korn Shell

Korn Shell 为内置的 `alias` 命令提供了以下选项：

- `-t` 创建一个跟踪的别名。Korn shell 会记住命令的全路径，以便更快速地找到并从任何目录颁发。如果你没有提供 `alias-name` 参数，则列出它。
- `-x` 导出别名以便在脚本中使用。如果你没有提供 `alias-name` 参数，则列出跟踪别名。
- `-a` 从当前 shell 移除所有别名。

## 操作

`alias` 支持以下操作：

- `alias-name`: 别名的名称。
- `alias-name=value`: 将值分配给别名。
- `-a` 移除所有别名。
- `-t` 创建一个跟踪的别名。
- `-x` 导出别名。

## 输出

输出写入标准输出。
