# 友元函数

使用 `friend` 关键字以及函数的完整规范将其声明为友元。将函数声明为友元并不会赋予友元函数访问你的指针，但它提供了对所有私有和保护数据及函数的访问。

这是一个示例：

```cpp
class PartNode
{
    // ... 将另一个类的成员函数声明为友元
    friend void Lists::Insert(Part *);
    // 将全局函数声明为友元
    friend int SomeFunction();
    // ...
}
```
