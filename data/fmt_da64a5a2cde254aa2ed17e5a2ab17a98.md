## 声卡

声卡代表了一个特殊问题，因为它们在配置方面非常敏感且挑剔。你可以通过几个命令诊断该问题的硬件方面，这将让你知道系统是否识别了声卡。在命令行执行以下命令：

```
dmesg | less
```

这将允许你检查启动过程并验证系统是否识别了声卡。你可以使用命令

```
tail /var/log/messages
```

获取相同的结果。

```
cat /proc/interrupts
```
