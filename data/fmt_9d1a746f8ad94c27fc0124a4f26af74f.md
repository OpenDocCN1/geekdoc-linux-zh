## 控制流

shell 包含许多命令用于调节脚本中的控制流，并在限制范围内从终端调节控制流。这些命令通过强制 shell 重新读取输入（循环）或在某些条件下跳过（分支）来工作。

每个 `foreach`、`switch`、`while`、`if...then` 或 `else` 内置命令必须作为其输入行的第一个单词。如果 shell 的输入是不可寻的且正在读取循环，则该输入会被缓冲。shell 在内部缓冲区内执行寻址以完成循环隐含的渲染。（在允许的范围内，向 `goto` 命令在不可寻的输入上可以成功）。

> 注意 — 循环中由 `?` 提示的命令不会放置在历史列表中。

## 命令执行

如果命令是 C 内置命令，shell 直接执行它。否则，shell 将搜索具有执行权限的同名文件。如果命令名包含 `/`，则将其视为路径名进行搜索。如果命令名不包含 `/`，shell 尝试将其解析为路径名，搜索 `path` 变量中的每个目录。

当找到具有相应权限的名称时，内核派生一个新进程并传递它及其参数，使用 `exec()` 调用（见 `exec(2)`）。内核随后覆盖新进程。如果文件是文本文件且第一行以 `#` 开头，

## 信号处理

shell 通常忽略 `QUIT` 信号。后台作业对键盘生成的信号免疫，包括挂起信号 `HUP`。其他信号具有 C shell 从环境中继承的值。你可以使用 `count` 内置命令控制 shell 对脚本内中断和终止信号的处理。shell 获 `TERM` 信号；否则，该信号传递给子进程。登录 shell 读取 `.logout` 文件时，任何情况下都不允许中断。

## 作控制

shell 将编号作业与每个命令序列关联，以跟踪在后台运行或被 `TST` 信号（通常是 `Ctrl+Z`）停止的命令。当使用元字符 `&` 在分号分隔列表中的命令或命令序列在后台启动时，shell 显示一行带有括号的作业号和关联进程号列表，例如：

```
[1] 1234
```

要查看当前作业列表，使用 `jobs` 内置命令。最近停止的作业（如果没有停止的，则将其放入后台）被称为当前作业，并用 `+` 表示。上一个作业用 `-` 表示；当当前作业被终止或移动到前景时，该作业将占据其位置（成为新的当前作业）。

要操作作业，请参考 `bg`、`fg`、`stop` 和 `%` 内置命令。

对作业的引用以 `%` 开始。百分号本身指代当前作业。

```
% & 当前作业。
- - 上一个作业。
```
