
# 烯烃

碳原子数在五个以下的低分子烯烃和二烯烃在常温常压下是气体。高分子量烯烃是无色的液体或固体。与其他烃类一样，烯烃不溶于水。液态烯烃的比重远低于 1.0。烯烃可发生聚合、环化和加成反应。许多结构聚合物和弹性体都基于烯烃和二烯烃的均聚物或共聚物。烯烃和二烯烃在各种条件下都容易环化。

烯烃的加成反应是整个有机化学领域中最重要的反应之一。在工业上，通过三碳和四碳烯烃的酸催化烷基化反应生产高辛烷值汽油。通过各种烯烃对苯的烷基化反应，生产多种烷基化芳香烃。

具有商业重要性的烯烃在石油工业中通过热裂解或催化裂解过程大规模生产。在实验室中，大多数烯烃制备方法涉及某种类型的消除反应，该反应通过移除相邻碳原子上的原子或基团，同时形成碳-碳双键。参见：烷基化（石油）；裂解；卤化；加氢。 [FE,F]

在石油工业中，这是一种化学工艺，将烯烃（乙烯、丙烯等）与碳氢化合物（通常是 2-甲基丙烷）结合，以生产分子量和碳原子数更高的产物。该产物的辛烷值较高，用于提高汽油级燃料的质量。该工艺最初在二战期间开发，用于生产高辛烷值航空汽油。目前其主要应用在于生产无铅车用汽油。参见：烯烃；汽油。

## 炔烃

含碳-碳三键（—C≡C—）的一类有机化合物。它们被称为乙炔类化合物或炔烃。虽然在与不饱和性方面表现出许多烯烃的特征，但乙炔类化合物具有许多独特的性质。由于炔烃分子中的键合是线性的，R—C≡C—R，因此不存在顺反异构。最简单的炔烃乙炔 [HC≡CH] 以及单取代乙炔类化合物中，连接在三键碳上的氢具有足够的酸性，可以被钠等金属取代。几种炔烃的结构式如下：

| 结构 | 名称 |
| --- | --- |
| CH≡CH | 乙炔 |
| CH≡CCH₂—CH₃ | 1-丁炔 |
| CH≡C—CH₃ | 丙炔 |
| CH₃—C≡C—CH₃ | 2-丁炔 |

制备炔烃的一般方法取决于 α,β-二卤代烷烃的脱卤化氢、将醛或酮转化为二卤代烷烃然后脱卤化氢，以及在液氨中与烷基卤化物发生烷基化金属乙炔化物。1-炔类的格氏试剂行为类似。

三键碳化合物的反应通常类似于含乙烯基键的化合物。加成反应分两个阶段进行，首先形成乙烯基化合物或取代乙烯，其次形成烷基化烷烃。在少量醇盐催化剂存在下，乙炔加到醇和酚上生成乙烯基醚。这类通过以乙烯基取代氢而发生加成反应的被称为乙烯基化。另一种已知的加成反应形式称为乙炔基化，涉及乙炔加到不饱和化合物上。炔烃的一种通用反应涉及在羰基镍存在下加入一氧化碳和水，或其他含有活性氢原子的化合物。

炔烃的聚合可能生成无环、芳香或脂环衍生物。在氯化亚铜存在下，乙炔二聚生成乙烯乙炔，后者加入氯化氢生成氯丁二烯（2-氯-1,3-丁二烯）。在自由基引发剂存在下，氯丁二烯聚合生成商业上重要的合成聚合物氯丁橡胶。乙炔的热聚合主要生成苯，也生成多种多环芳香化合物。乙炔聚合生成环状四聚物环辛四烯，这在理论和实践上都具有重要意义。参见：乙炔；烯烃。

## 卵黄囊

一种充满液体的囊状物，或香肠状，位于爬行动物、鸟类和哺乳动物胚胎的外层羊膜（chorion）和内层绒毛膜（amnion）及卵黄囊之间的胚外膜。它由内层内胚层细胞组成，与胚胎肠道的内胚层连续，以及外层中胚层组成，与胚胎的脏中胚层连续。它起源于胚胎后肠腹侧壁的向外突出，并扩张形成一个大的卵黄囊，遍布胚外体腔。卵黄囊通过一条穿过脐带的狭窄卵黄柄与后肠保持连接。参见：绒毛膜；羊膜；胚层。

卵黄囊最终与覆盖其上的羊膜融合，形成复合的羊卵膜（chorioallantois），位于爬行动物和鸟类的壳膜下方。羊卵膜由广泛的血管网络供应，作为气体交换的重要呼吸和排泄器官。在某些哺乳动物、爬行动物和鸟类中，卵黄囊腔还作为肾脏废物的储库。在后两组动物中，卵黄囊协助白蛋白的吸收。在某些哺乳动物（包括人类）中，卵黄囊是退化的，可能会退化，但同源血管在连接胚胎与胎盘的重要脐动脉和脐静脉中持续存在。参见：胎膜；胎盘。

## 等位基因

基因的一种或多种替代形式。等位基因（Allele）是“allelomorph”的缩写，用于指定表现出孟德尔分离的单位的一种替代形式。新的等位基因通过突变从现有等位基因中产生。通过这种方式产生的等位基因的多样性是遗传变异和进化的基础。给定基因的不同等位基因决定了该基因控制的具体遗传特征表现的程度。导致该特征以正常方式表达的特定位等位基因通常被称为野生型等位基因。野生型等位基因的突变导致突变型等位基因，其在生物体发育中的功能通常相对于野生型等位基因有所削弱。参见：脱氧核糖核酸（DNA）；基因；基因作用；遗传密码；孟德尔遗传；突变。

等位基因占据染色体上的固定位置或位点。在大多数高级生物体（包括人类）的体细胞中，每种染色体有两条，因此每种基因有两个等位基因，性染色体除外。此类生物体及其体细胞被认为携带二倍体等位基因组。如果两个相同的等位基因存在，二倍体个体被称为纯合子；如果两个不同的等位基因存在，则被称为杂合子。设 A 和 a 代表给定基因的一对等位基因，AA 和 aa 是两种可能的纯合子的基因型，而 Aa 是杂合子的基因型。通常，Aa 个体的表型与 AA 类型相似；A 则被称为显性等位基因，a 被称为隐性等位基因。对于性染色体，一种性别（大多数高级动物中通常是雄性，鸟类除外）只有一条 X 染色体，而 Y 染色体几乎不含 X 染色体上的基因。因此雄性只携带一份 X 连锁基因，被称为半合子。因此，如果雄性从 X 染色体继承了隐性突变等位基因（如色盲），他会表现出色盲，因为他的 Y 染色体上缺乏野生型等位基因。参见：染色体；性连锁遗传。

在二倍体个体群体中，给定基因可能有超过两个等位基因。这类等位基因的总和被称为多重等位基因系列。由于基因是由数百甚至数千个核苷酸碱基对组成的线性序列，仅通过碱基替代就可能产生的给定基因的潜在等位基因数量巨大。

## 植物化学抑制

所有类型植物（包括微生物）之间的生化相互作用。该术语通常被解释为一株植物对另一株植物的有害影响，但越来越多地按照原本意图，涵盖有害和有益两种相互作用。至少区分两种形式的植物化学抑制：(1) 由一个物种产生和释放的化学抑制物，仅抑制相邻其他物种的生长，这可能赋予化学抑制物种竞争优势；以及 (2) 自化学抑制，其中产生化学抑制物的物种和非相关物种都无差别地受到影响。通常限制于高等植物间相互作用的“植物化学抑制”一词，现在应用于所有门植物（包括藻类）之间的相互作用。甚至植物与食草昆虫或线虫之间，其中植物物质吸引、排斥、抑制或减缓入侵昆虫或线虫生长的相互作用，也被视为植物化学抑制。土壤微生物与植物之间的相互作用在植物化学抑制中很重要。真菌和细菌可能产生并释放抑制剂或促进剂。一些细菌通过固氮促进植物生长；另一些通过提供磷来促进。固氮细菌的活动可能受化学抑制物的影响，而这种影响反过来可能影响生态格局。根际环境必须被认为是植物化学抑制相互作用的主要场所。参见：固氮；根际。

植物化学抑制与竞争有明确区别。在植物化学抑制中，植物将化学物质引入环境；而在竞争中，植物去除或减少环境组分，如矿物、水、空间、气体交换和光照。在田间，植物化学抑制和竞争通常同时起作用。

## 过敏

人类和动物对过敏原（引起过敏的身体外源性物质）通过注射、吸入、摄入或皮肤接触引起的反应性改变。过敏最常见的临床表现是枯草热、哮喘、荨麻疹、特应性（内源性）湿疹以及由直接接触变豆菜或某些化学品等过敏原引起的过度皮肤病变。

许多物质可能引起过敏：花粉、动物蛋白、霉菌、食物、昆虫毒液、外源血清蛋白、工业化学品和药物。大多数天然过敏原是中等分子大小的蛋白质或多糖（分子量在 10,000 到 200,000 之间）。低分子量的化学品或药物（半抗原）必须首先与身体自身的蛋白质（载体）结合，才能成为完全有效的过敏原。

对于临床过敏基础的过敏状态的发展，需要反复接触过敏原。致敏期的持续时间通常取决于过敏原的致敏强度和暴露强度。某些过敏原（例如，家养动物的唾液、尿液和毛发蛋白）比其他的致敏性更强。在大多数情况下，需要反复接触微量过敏原；通常在对草花粉或豚草花粉的多年季节性暴露后，才出现明显的枯草热表现。另一方面，婴儿对牛奶的过敏在几天或几周内就会发展。如果以前的接触未明显显现（例如食物中的抗生素），即使在第一次有意识接触到致敏物质时，过敏也可能在临床上显现。

## 82 短吻鳄

除了过敏原固有的致敏特性外，过敏个体对致敏的易感性也起着重要作用。某些家庭中，如花粉症、过敏性哮喘和特应性（内源性）皮炎等临床表现的发生频率更高。在其他类型的过敏临床形式中，遗传易感性虽然也可能存在，但其表现并不明显。
