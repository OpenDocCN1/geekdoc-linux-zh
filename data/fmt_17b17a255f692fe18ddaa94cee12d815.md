
# 1) Add Lower

`aspell` 会将 HTML 标签的内容视为拼写错误。这个问题可以通过包含 `-H` (HTML) 检查模式选项来解决，如下所示：

```bash
@linuxbox ~$ aspell -H check foo.txt
```

我们的结果是这样的：

```html
<html>
<head>
<title>Mispelled HTML file</title>
</head>
<body>
<p>The quick brown fox jimped over the laxy dog.</p>
</body>
</html>
```
