如果代表功能键的扫描码填充了普通字段或 shift 字段，则会产生一个自解释易懂的消息并忽略该翻译。

0x1a '||C ' ' '||N '{'|N

## Options

- `-d -e` 如果安装了键盘扩展映射，临时禁用组合键（compose key）和死键（deadkey）序列。
- `-e` 启用键盘扩展映射。
- `-f mapfile` 安装 `mapfile` 的内容，并将相应的映射设置为控制台驱动程序支持的。
- `-g` 以十六进制值显示当前映射和键盘扩展映射（如果已安装）（参见 `/usr/include/sys/emap.h`）。此选项主要用于调试。
- `-n` 禁用并拆除当前的键盘扩展映射。使用 `-f` 选项重新安装键盘扩展映射。

## pg — Files Perusal Filter

### Synopsis
`/usr/bin/pg [-number] [-p string] [-cefnrs] [+linenumber] [+pattern/] [filename...]`

## Description

`pg` 命令是一个过滤器，允许你一次查看一个屏幕的文件。如果你按下回车键（Return），将显示另一页；其他可能性列如下。

此命令与之前的分页器不同之处在于它允许你备份并查看已经离开屏幕的内容。备份方法见下文。

为了确定终端属性，`pg` 会扫描 `terminfo(4)` 数据库以查找环境变量 `TERM` 指定的终端类型。如果未定义 `TERM`，则假设终端类型为转储（dump）。

## Notes

在等待终端输入时，`pg` 通过终止执行来响应 BREAK、Control-C 和 Control-\。然而，在提示符出现之间，这些信号会中断当前任务并显示提示符。当从管道（pipe）读取输入时，请谨慎使用这些组合键，因为中断可能会终止管道中的其他命令。

如果终端制表符（Terminal Tabs）不是每八个位置设置一次，可能会出现不理想的结果。

当 `pg` 作为过滤器与其他更改终端 I/O 选项的命令一起时，终端设置可能无法正确恢复。

## Options

- `-number` 指定 `pg` 使用的替代默认值的终端大小（以行计）。在包含 24 行的终端上，默认窗口大小为 23）。
- `+linenumber` 从 `linenumber` 行开始。
- `+pattern/` 从包含正则表达式模式的第一行开始。
- `-c` 在显示每页内容之前，将光标复位到起始位置（Home）并清空屏幕。如果在 `terminfo(4)` 数据库中未为该终端类型定义 `clear_screen`，则忽略此选项。
- `-e` 不在每个文件的结束处暂停。

## 1005

- `-f` 禁止折行。如果没有此选项，`pg` 会对超过屏幕宽度的行进行折行，并显示文本中的某些字符序列（例如，下划线的转义序列产生不理想的结果）。
- `-n` 通常情况下，命令必须由换行符结束。此选项在输入命令后立即结束命令。
- `-p string` 使用字符串作为提示符。如果提示符字符串包含 `%d`，当提示符为 `:` 时，提示符中的第一个 `%d` 会替换当前页码。默认提示符字符串为冒号（:`）。
- `-r` 禁止 shell 转义（shell escape）。打印错误消息但不退出。
- `-s` 在标准输出模式（通常为反色）下打印所有消息和提示符。

## Operands

- `filename` 要显示的文本文件的路径。如果没有文件名或为 `-`，则读取标准输入。

## Usage

## Commands

当 `pg` 暂停时，你可以用三种命令进行响应：

- 允许进一步查看的命令。
- 搜索的命令。
- 修改查看环境的命令。

允许进一步查看的命令通常带有一个先前的地址，这是一个可选的有符号数字，指示从何处继续显示文本。该地址可以是页也可以是行，取决于命令。有符号地址指定相对于当前页或行的点，无符号地址指定相对于文件开头的地址。如果没有提供地址，每个命令都有一个默认地址。

查看命令的默认值如下：

- `(+1)newline | blank` 显示一页。地址以页为单位。
- `(+1) l` 使用相对地址时，向前或向下滚动指定的行数；使用绝对地址时，从指定的行开始打印屏幕。
- `(+1) d` 向前或向下滚动半屏。

# pgrep, pkill — 查找或信号进程进程

### 概要

+ `/usr/bin/pgrep [-flnvx] [-ddelim] [-Pppidlist] [-pgprplist] [-ssidlist] [-U eidlist] [-U uidlist] [-G gidlist] [-t termlist] [pattern]`
`/usr/bin/pkill [-signal] [-fnvx] [-Pppidlist] [-g pgprplist] [-s ssidlist] [-U eidlist] [-U uidlist] [-G gidlist] [-t termlist] [pattern]`

## 描述

`grep` 命令执行系统上的活动进程，并报告属性匹配命令行指定标准的进程 ID（process ID）。每个进程 ID 都以十进制值打印，并用分隔符与下一个 ID 分隔，默认分隔符为换行符。对于每个属性选项，您可以在命令行上指定用逗号分隔的可能值集合。例如，以下命令匹配实际组 ID 为 `other` 或 `daemon` 的进程。

```
castle$ pgrep -G other, daemon

120

cast$
```

如果您指定了多个标准选项，`pgrep` 会匹配属性符合所有标准选项之间逻辑“与”（AND）关系的进程。例如，以下命令匹配属性同时满足（实际组 ID 为 `other` 或 `daemon`）**且**（实际用户用户 ID 为 `root` 或 `daemon`）的进程。
