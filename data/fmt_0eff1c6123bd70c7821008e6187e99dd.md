## HorizSync

如果未指定单位，`HorizSync` 的单位为 kh。

`HorizSync` 可以是逗号分隔的离散值列表，也可以是逗号分隔的值列表。

注意：此处的数值仅为示例。请参阅您的显示器用户手册以获取正确的数字。

``` 
HorizSync 31.5 - 64.3
```

`HorizSync` 配置示例：

``` 
| HorizSync | 30-64 | # 多同步 |
| HorizSync | 31.5, 35.2 | # 多固定同步频率 |
| HorizSync | 15-25, 30-50 | # 多同步频率范围 |
```

## VertRefresh

如果未指定单位，`VertRefresh` 的单位为 Hz。

`VertRefresh` 可以是逗号分隔的离散值列表，也可以是逗号分隔的值范围列表。

注意：此处的数值仅为示例。请参阅您的显示器用户手册以获取正确的数字。

``` 
VertRefresh 50-100
```

## 模式指定

模式可以用两种格式指定：一种紧凑的单行格式，或多行格式。这两种是等效的。

``` 
# ModeLine "1024x768i" 45 1024 1048 1028 1264 768 776 784 817 Interlace
```

``` 
# Mode "1024x768i"
# DotClock 45
# HFTimings 1024 1048 1028 1264
# Vtimings 768 776 784 817
# Flags "Interlace"
### EndMode
```

这是一组标准模式。超出规格的模式会被服务器删除（只要 `HorizSync` 和 `VertRefresh` 行正确），因此不需要删除模式（除非特定时序在您的显示器上不起作用）。使用这些模式，显卡支持的针对给定分辨率的最佳模式将自动使用。

