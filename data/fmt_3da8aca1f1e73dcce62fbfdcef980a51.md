
# LineageOS 安装教程

## 简介

有一台老旧且更新严重落后的手机吗？用一个全新的、纯净的、开源的 Google 操作系统让它重获新生吧。

人们常说金钱能改变一切。在那个超流行的 Android 操作系统 CyanogenMod 的案例中，金钱改变了其母公司的哲学，将其方向从自由软件转变为商业软件，对代码库和项目负责人进行了许可授权，并最终导致了 Cyanogen Inc. 缺乏资金，从而大幅削减了其运营和对 CyanogenMod 的支持。这还导致了在开发过程中被侵入的社区夺回了他们的“孩子”并对此进行反抗。

因此，我们取代了 CyanogenMod 及其事实上的开源继承者 LineageOS —— 它由该社区开发，并得到了原 Cyanogen 项目负责人 Steve Kondik 的大量贡献。名字变了——要怪就怪商标——版本也是，14.1 是 LineageOS 的第一个版本，直接从 CyanogenMod 构建，代码库几乎没有变化。

在探索如何操作之前，让我们看看为什么人们想要控制并折腾自己的手机。不仅仅是因为 Android 感觉像是在给 Google 的移动操作系统染色；更新可以让操作系统保持最新，这可能意味着你可以享受更好的电池续航、更多的隐私保护，以及更少那些人们永远存储在手机里的臃肿软件。它是由热爱自己手机并希望它们表现更好的人开发的。

在 Android 之上安装 LineageOS 有其缺点，但 Google 在 Play 商店中实现了一个名为 SafetyNet 的系统，它允许开发者检查设备是否处于“已知良好”状态。LineageOS 明智地选择不通过此检查，这意味着你可能会发现无法通过传统渠道使用某些功能（如 Google Pay）。通常对此有绕过方法——如果你想使用 Google Play Store 以外的途径安装应用，请在网上搜索“APKs”。

安装 LineageOS 意味着你需要一台兼容的手机或平板电脑，以及连接到电脑的可靠方式。如果你有一台相当现代的设备，请访问 `https://lineageos.org/devices` 查看，你应该能够毫无问题地安装，尽管可能无法退回到你设备支持的更低版本的 Android。旧设备在某种程度上被冷落了，但你可能仍然可以使用本指南中的技巧来安装旧的 CyanogenMod。

## 安装 ADB

Android 调试桥（ADB）对于与你的操作系统进行深度通信至关重要，并处理与手机的通信。

随处可用。

进入你机器上的终端并按照以下指令配置构建工具的连接：`https://developer.android.com/studio/tools/platform-tools`。下载 zip 文件，使用 `unzip` 解压，并将路径添加到环境变量中，以确保可以使用 `adb` 和 `fastboot` 命令。

在 Android 设备上：进入“设置” > “关于手机”，连续点击“版本号”七次，然后返回主设置屏幕启用“开发者选项”。向下找到它，然后开启“USB 调试”。将手机连接到电脑，并在终端输入 `adb devices`。你的设备应该显示为已连接；你也可以运行 `fastboot` 来调出一个受限的 shell 并控制该设备。

```bash
if [ -d "/platform-tools" ]; then
  export PATH=$PATH:/platform-tools
fi
```

重启你的机器，Linux 方面的操作应该已经完成——现在是你设置设备的时间了。在你的设备上，选择“关于手机”，然后向下点击直到看到“版本号”。现在通过输入 `fastboot devices` 检查是否能看到你的手机。根据你的设置，这可能需要以超级用户身份执行；如果是这样，运行该命令并获取以下文本，那么你的设备就是唯一的：

```
> Please confirm allow debugging from this computer?
> y/n
fastboot devices
```

## 刷入 TWRP Recovery

存储：如果是这样，`adb push` 进程将无法工作（并且已知在某些设备上会失败），你可能只需要从桌面管理器复制文件，如果它已经将你的硬件识别为设备的话。

备份：如果你的内部存储处于当前状态，你现在可以对其进行备份。如果你以后想返回出厂设置，这将非常有用，因为制造商不会定期提供更新。当你想要重新安装时，转到“重置”和“高级清除”。勾选复选框和滑块来清除你的缓存和数据，并选择你想要安装的特定 LineageOS 版本。选择 LineageOS zip 文件，并滑动滑块刷入固件。如果在此过程中发生中断，你的设备可能会变砖。

重启系统后，如果你正在使用 LineageOS，系统将显示 LineageOS 启动画面。如果菜单稍显杂乱，你会看到每个应用在安装时显示为已删除。

## 获取 Root 权限

不要重启。高级用户可以依靠社区来获取 Root 权限。如果 LineageOS 提供了，它会有各种安全影响 —— 安装一个具有 Root 权限的 Root 应用，并记住相应地更改你的设备设置，因为它会略微影响一切。

你可以从 `http://download.lineageos.org/extras` 下载 LineageOS 超用户工具。获取与你的 OS 版本匹配的文件，将其作为刷机包上传到手机，并使用 TWRP 安装进行刷入。第一次启动的时间比你预期的要长，因为有很多更改需要完成。

如果你决定不 Root，你可以在同一位置找到相关工具，只需进入恢复模式，并将其刷入以获取 Root。

## 初始设置

最后，该重启你的设备了。你将获得在手机上安装 TWRP 应用的选项，这完全取决于你的决定；由于你现在使用的是一个通过一点努力就能制作的自定义固件设备，这并不是一个坏主意。

随后将经历漫长的初始启动过程，在此期间，LineageOS 会处理你的设备存储以确保所有设置就绪。请耐心等待，直到初始化完成，你将进入初始用户设置界面。这与原生 Android 非常相似，除非有来自你使用的其他设备的数据。你还被要求加入 Google 服务；如果你不使用 Google 或 Google 商店，请随意跳过此步骤。

LineageOS 特有功能 —— 在开启 Android 切换时你会遇到一点小麻烦，该功能默认是禁用的，用于控制你允许访问哪些类型的应用。你可以在“设置 > 隐私”菜单中更改设置，所以如果某个应用占用的空间太大，你也可以这样做。完成后，得到了一个干净的设备，不包含任何制造商的原始软件。如果你没有安装 GApps，你将会有较少的 Google 专有支持，但 LineageOS 开源社区会确保手机保持功能性。

## 开启 Root 权限设置

如果安装了 Root 应用，你需要启用它。进入“设置”，多次点击“版本号”以启用开发者模式。返回主屏幕，进入开发者菜单。我们现在开启“OEM 解锁” —— 这是你使用标准程序恢复引导加载程序所需的 —— 然后返回 Root 权限并选择你愿意授予的访问级别。`ADB Root` 将连接到通过 Lineage Bridge 发送的命令，这意味着你可以拉取以下应用程序。

设备选项中提供的控制比你以前在 Android 中看到的更多。你可以运行 `delete` 来检查，并对文件执行某些哈希操作，如果你想监控情况。例如，激活“不保留活动”选项，它非常适合让你从应用切换，而开启“启用本地终端”会添加一个新应用，让你像以前获得 Root 权限时一样访问你的设备。

> **小贴士**：如果你在手机上使用了那个获取的“Debian”非 Root Play 商店 —— 那么你将能够在移动设备上运行它。

如果你是超级用户，请在你移除权限时考虑一下 —— 剩余的来自同一位置 Root！不确定为什么要用 Google 应用来进入你的“新”手机？现在下载 Aurora Store 以获得一个交互式安装程序，允许你逐个选择它们。
