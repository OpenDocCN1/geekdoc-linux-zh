# 扩展模块的命名

扩展模块通常以下划线开头进行命名，例如 `_example`。这是为了与 Python 标准库本身区分开来。

# 596 第 26 章 扩展与嵌入 Python

存在一些名为 `_socket`、`_thread`、`_sre` 和 `_fileio` 的模块，分别对应 `socket`、`threading`、`re` 和 `modules` 的 C 语言组件。通常，你不会直接使用这些 C 扩展。相反，你会创建一个高层 Python 模块，如下所示：

```python
# example.py
from _example import *
# 在下方添加额外的支持代码
```

此 Python 封装的作用为你的模块提供额外的支持代码，或者提供更高级的接口。在很多情况下，在 Python 中实现扩展模块的部分比用 C 容易。这种设计使得这种实现变得简单。如果你查看标准库模块，你会发现它们都是以这种方式作为 C 和 Python 的混合模块实现的。

## 编译和打包扩展

编译和打包扩展模块的首选机制是使用 `distutils`。要做到这一点，你需要创建一个如下的 `setup.py` 文件：

```python
# setup.py
from distutils.core import setup, Extension

setup(name="example",
     version="1.0",
     py_modules=['example.py'],
     ext_modules=
         Extension("example",
             ["pyexample.c","example.c"]))
)
```

在该文件中，你需要包含高层 Python 文件（`example.py`）和构成扩展模块的源码（`pyexample.c`, `example.c`）。为了为了测试构建模块，请输入以下：

```bash
# python setup.py build_ext
```

这将将代码编译为共享库并将其留在当前目录中。该库的名称将是 `_example.so`、`_example.py` 或类似的变体。

如果编译成功，使用你的模块将非常简单。例如：

```python
# python3.0
Python 3.0(r67503, Dec 4 2008, 09:40:15)
[GCC 4.0.1] (Apple Inc. build 5465) on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> import_example
>>> example.grid(78,120)
6
>>> example.replace('Hello World!','-')
(1,'Hello-World!')
>>> example.distance()
Traceback (most recent call last):
File "stdin", line 1, in <module>
ImplementedError: distance() not implemented.
>>>
```

一些复杂的扩展模块可能需要提供额外的构建信息，例如包含目录、库和预处理器宏。它们也可以包含在 `setup.py` 中，如下：

```python
# setup.py
from distutils.core import setup, Extension
```

```python
setup(name="example",
    version="1.0",
    py_modules = ['example.py'],
    ext_modules = [
        Extension("example.c",
            include_dirs = ["/usr/include/X11","/opt/include"],
            define_macros = [['DEBUG',1],
                            [('MONDO_FLAG',1]],
            undef_macros = ['HAVE_FOG','HAVE_NOT'],
            library_dirs = ["/usr/lib/X11","/opt/lib"],
            libraries = ["X11","Xt","blah"]
        )
    ]
)
```

如果你想安装一个扩展模块供通用使用，只需输入 `python setup.py install`。关于此点的更多细节请见第8章“模块、包和发行”。

在某些情况下，你可能想手动构建扩展模块。这几乎总是需要各种编译器和链接器选项的高级知识。示例如下所示：

```bash
linux % gcc -c -fpic -usr/local/include/python2.6 example.c pyexample.c
linux % gcc -shared example.o pyexample.o -o _examplemodule.so
```
