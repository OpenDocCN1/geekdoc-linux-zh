# 使用 S-Lang 创建文本模式界面

`S-Lang` 由 John Davis 创建，是创建 TUI 的替代替代方案。除了屏幕操作和光标控制程序外，`S-Lang` 还包含一个嵌入式的 `S-Lang` 解释器、一个简化某些编程部分的内置库以及各种预定义类型和数据结构。列表 28-4 显示了与列表 28-3 相同的程序，但反映使用 `S-Lang` 的更新。

## 列表 28-4

使用 S-Lang 读取输入和写入输出

```c

/*

 * reread.c - 基于 S-Lang 的简单 UI

 */

#include <stdio.h>

#include <string.h>

#include <slang/slang.h>

int main(int argc, char *argv[]) {

    int i = 0;

    unsigned int ch;

    /* 启动 s-lang */

    init_terminfo();

    slang_init_tty(-1, 0, 1);

    smg_init_smg();

    /* 绘制一个漂亮的框 */

    smg_draw_box(0, 0, 24, 80);

    smg_moveorc(1, 1);

    smg_write_chars("INPUT: ", 7);

    smg_refresh();

    /* 读取字符直到遇到换行符 */

    while(1) {

      ++i;

      ch = smg_getkey();

      if (ch == 13)

        break;

      if (smg_get_column() == 79)

        smg_moveorc(2, 1);

      smg_write_char(ch);

      smg_refresh();

    }

    /* 打印字符计数 */

    smg_moveorc(22, 1);

    smg_write_chars("characters read: ", 17);

    smg_printf("%d", i);

    smg_refresh();

    /* 看一眼屏幕 */

    sleep(3);

    /* 关闭 s-lang */

    smg_reset_smg();

    slang_reset_tty();

    return 0;

}

```

使用以下命令编译此程序：

```
$ gcc sreadkey.c -lslang -o sreadkey
```
