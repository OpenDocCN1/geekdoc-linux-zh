### 实际安装

### 首先更新

`apt-get update`

```bash
for pkg in $(pkglist)
do
  if $(pkg -list | awk '(print $2)' | grep "^${pkg}" 2>/dev/null); 
  then
    echo "已安装 ${pkg}"
  else
    # 尝试安装
    echo -n "正在安装 ${pkg}..."
    if apt-get -y install 2>/dev/null); then
      echo "成功"
    else
      echo "--失败--"
    fi
done
```

简而言之，上面的脚本如所示工作。首先，我们使用特殊的构造（`bash`）运行 `#{command to run}`。
