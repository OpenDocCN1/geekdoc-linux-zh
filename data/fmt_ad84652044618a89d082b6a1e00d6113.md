
注意：您必须带有引号（""）输入此命令，以确保 Linux 不将星号解释为操作系统命令。如果您带有在操作系统上可能具有特殊含义的字符执行 DB2 命令，您应该像之前所示，将命令的内容包含在引号中。

- d. 输入以下命令重置数据库连接：

```
db2 connect reset
```

恭喜！您已成功安装并将 DB2 客户端连接到远程 DB2 服务器。这完成了您打算着手安装和配置的典型的客户端到服务器业务模型。

## 连接故障排除

如果您在将 DB2 客户端连接到服务器时遇到问题，请检查以下项目：

- 1. `/etc/hosts` 文件是否已更新。
- 2. 端口号是否与服务名匹配。要验证这一点，请以 db2 用户执行以下命令：

```
db2 list services
```
- 3. 要验证数据库，请以 db2 用户执行以下命令：

```
db2 list database
```
- 4. DB2 服务器未正确启动。

如果连接仍然失败，请参阅故障排除指南。

# 常见问题

- Q：我启动了 DB2 安装程序，但异常退出了。当我再次启动 DB2 安装程序时，收到了如图 7.27 所示的错误。

7.27 之前的 DB2 实例未正常停止时收到的错误。

答：由于您没有正确退出 DB2 安装程序，`/tmp/.db2inst.lck` 文件未被移除。要启动 DB2 安装程序，您必须通过输入以下命令移除该文件：

```bash
rm /tmp/.db2inst.lck
```
