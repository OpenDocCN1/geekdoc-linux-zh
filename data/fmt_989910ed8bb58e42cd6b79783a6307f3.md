# time

GNU `time` 命令。`'time'` 命令运行另一个程序，然后显示系统在程序运行期间收集的该程序使用的资源信息。你可以选择报告哪些信息以及显示格式，或者让 `'time'` 将输出报告到文件中或显示在屏幕上。`'time'` 可以报告的资源包括时间、内存、I/O 和 IPC 调用的所有通用类别。GNU 版本可以使用 `printf` 风格的字符串包含各种测量值，以任意方式格式化输出。来自 Debian 3.00 APT http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# Time-sharing

一种允许多个用户基于时间共享每部分处理器资源的方法，并在这些段内轮换每个用户的进程。（也称为多任务处理。）来自 I-gloss http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

一种运行进程的方法，允许一个以上的用户同时访问计算机系统。每个进程被连续分配一小时间段，使得每个用户看起来都自己拥有这台计算机。来自 Linux Guide@FirstLinux http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

# timeconfig

`timeconfig` 包包含两个实用程序：`timeset` 和 `setclock`。`timeconfig` 提供了一个工具用于配置 `/etc/sysconfig/clock` 和 `/etc/localtime` 中的时间参数。`set clock` 将系统上的硬件时钟设置为系统时钟中存储的时间。来自 Redhat 8.0 RPM http://www.tdp.org/LDP/Linux-Dictionary/html/index.html

# timeout

灵活的用户超时守护进程，强制 `/etc/timeout` 中指定的时间限制。在守护模式下调用（不带任何参数）时，`timeout` 会进入后台运行，然后每分钟扫描 `/var/run/utmp`，并检查 `/etc/timeouts` 中是否存在匹配你的条目，基于：

- 当前日期和时间
- 用户当前登录的终端
- 用户的登录 ID
- 用户所属的任何主组或要组

Shane Alden <shane@ion.apana.org> 。来自 Debian 3.0 http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html
