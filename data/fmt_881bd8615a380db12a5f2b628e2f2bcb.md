
更改调用者的组标识；详情请参阅 `newgrp(1)`。`newgrp` 会执行一个新的 shell，因此当前环境会丢失。

## `nice`

```bash
nice
nice +number
nice +command
```

第一种命令将此 shell 的 `nice`（运行优先级）设置为 4（默认值）。最后两种形式分别以优先级 4 和数字运行命令。具有相应权限的用户可以通过指定负数 `nice` 来提高优先级。`~number ...` 命令始终在子 shell 中执行，并适用于简单语句中的命令限制。

## `nohup [command]`

如果没有参数，`nohup` 可在 shell 脚本中使用，以忽略脚本剩余部分的挂起。如果有参数，`nohup` 执行指定的命令。

## `notify [command]`

如果没有参数，`nohup` 可在 shell 脚本中使用，以忽略脚本剩余部分的挂起。如果有参数，`nohup` 执行指定的命令。

## `notify [job]`

## `popd [+n]`

弹出目录栈，返回新的顶部。如果有参数，丢弃栈中的第 n 个条目。目录栈的元素编号为从顶部从 0 开始编号。它是 `popd` 的同义词，出于历史原因提供。不建议使用，因为它不是标准 BSD shell 的一部分，未来的发行版本可能不再支持。

## `pushd [name] [+n]`

如果没有参数，`pushd` 交换栈顶部的两个元素。给定名称参数，`pushd` 切换到新目录（使用 `cd`）并将旧的当前目录（如 `cd`）推入目录栈。带有数字参数，`pushd` 绕着顶部元素旋转目录栈并切换到该目录。目录栈的成员从顶部从 0 开始编号。

## `rehash`

重新计算 `path` 变量内容的内部哈表。如果你在登录期间向目录添加了新命令，则需要此操作。只有当你向某个目录添加了命令或系统程序员更改了某个系统目录的内容时，才可能需要这样做。

作业或进程也会收到 `CONT`（继续）信号。

## `repeat count command`

执行指定的命令（受与单行 `if` 语句中命令相同的限制）`count` 次。I/O 重定向精确发生一次，即使 `count` 为 0。

## `set`

```bash
set
set name
set name=word=word own
set name[index]=word
set name=[wordlist]
```

`set` 的第一形式显示所有 shell 变量的值。值不是单个单词的以括号列表打印。第二形式将 `name` 设置为空字符串。第三形式将 `name` 设置为单词的索引；该组件必须已存在。最后形式将 `name` 设置为 `wordlist` 中的单词列表。在所有情况下，值都经过命令和文件扩展。

## `setenv name`

将环境变量 `name` 的值设置为 `value`（单条字符串）。最常用的环境变量 `USER`、`TERM` 和 `PATH` 会自动从 csh 变量 `user`、`term` 和 `path` 导入和导出；因此不需要对这些使用 `setenv`。

## `shift [variable]`

如果不给出参数，`argv` 的成员向左移动，丢弃 `argv[1]`。如果 `argv` 未设置或分配了少于两个字符串，则发生错误。当指定变量时，`shift` 执行函数于指定的变量。

# 第 7 章 系统管理员的 Shell 编程

## `source [-h] name`

`csh` 从 `name` 读取命令。`source` 命令可以被嵌套，但如果嵌套过深，shell 可能会耗尽文件描述符。任何层级的 `source` 出现错误都会终止所有嵌套的 `source` 命令。通常情况下，命令执行期间的输入不会被放入历史列表中。`-h` 选项可将命令放入历史列表中而不执行它们。

## `stop [%job ...]`

停止当前（不带参数）或指定的在后台执行的作业。

## `suspend`

导致 shell 像接收到 suspend 信号一样停止。由于 `csh` 通常会忽略 suspend 信号，这是挂起 shell 的唯一方法。在登录 shell 中尝试执行此命令将会显示错误消息。

## `switch (string)`

```bash
switch (string)
...
breaksw
...
default:
...
breaksw
endsw
```

每个 `case` 标签 (`str`) 都会依次与指定的字符串进行匹配，该字符串首先经过命令和文件名的扩展。`case` 标签的格式为模式匹配符号，不支持带括号的表达式匹配列表（参见 `regexp`）。如果没有标签匹配，则找到一个默认标签（`default`），执行将从默认标签之后开始。每个 `case` 标签和默认标签都必须出现在行首。`break` 命令在匹配器执行后执行。否则，控制可能会像 C 语言一样穿过 `case` 标签和默认标签。如果没有标签匹配且没有默认标签，执行将在 `endsw` 之后继续。

## `time [command]`

当未指定命令时，将打印出此 shell 及其子进程使用的时间摘要。如果指定了命令，则对命令进行计时，并按 `time` 变量下的描述打印时间摘要。如有必要，将创建一个额外的 shell 以在命令完成后打印该命令的时间统计数据。

## `umask [value]`

显示当前的文件创建掩码（未指定 `value` 时），或将其设置为指定的 `value`。掩码以八进制给出。掩码的常用值为 002，它赋予所有者和组所有权限，并赋予其他人执行权限；或者 022，它赋予所有者所有权限，而仅赋予组和所有人读取和执行权限。

## `unalias pattern`

所有名称匹配指定模式的别名（aliases）都会被丢弃。因此，所有别名都通过 `unalias` 被移除。如果 `pattern` 不匹配现有的别名，则发生错误。

## `unhash`

禁用使用内部哈希表来加速执行程序的查找。

## `unset pattern`

所有名称匹配指定模式的变量都会被移除。因此，所有变量都通过 `unset` 被移除；这会产生明显的负面副作用。如果 `pattern` 没有匹配到任何内容，则不发生错误。

## `unsetenv pattern`

从环境中移除所有名称匹配指定模式的变量。另见上文的 `setenv` 命令和 `printenv(1)`。

## `wait`

等待所有后台作业终止。如果 shell 是交互式的，中断可以干扰 `wait`，此时 shell 会打印所有已知未完成作业的名称和作业编号。

## `while (expression)`

当指定的表达式求值为非零时，`while` 和匹配的 `end` 之间的命令将被执行。`break` 和 `continue` 可用于终止或继续循环过程（`while` 和 `end` 必须出现在各自的输入行中）。如果输入是终端（即不是脚本），则在循环第一次执行时作为 forecast 语句进行提示。

## `job`

将指定的作业带入前台。

## `job &`

在后台继续执行指定的作业。

## `@`

```bash
@ name=expression
@ name(index)=expression
```

第一种形式打印所有 shell 变量的值。第二种形式将指定的 `name` 设置为表达式的值。如果表达式包含 `<`、`>` 或 `|`，则至少部分必须放在 `name` 的索引参数中。`name` 和其索引组件必须已经存在。`+=` 和 `--` 运算符在 C 中是可用的。空格只能分隔 `name` 和赋值运算符。然而，在分隔表达式中否则会被视为单个单词的部分时，空格是强制性的。特殊的后缀 `++` 和 `--` 运算符分别递增和递减 `name`（例如 `@ i++`）。

## 非内置命令执行

当要执行的命令不是内置命令时，`csh` 尝试通过 `exec(2)` 执行命令。变量 `path` 中的每个单词都是 shell 尝试查找命令的目录（如果命令不以 `/` 开头）。如果没有给出 `-t`，shell 将这些目录哈希到一个内部表中，以便在可能存在命令的目录中尝试 `exec`。这在路径中存在大量目录时极大提高了执行速度。如果此机制被关闭，或者路径中的任何目录组件不以 `/` 开头，shell 将目录名和命令名拼接成文件路径名，然后尝试执行该文件。

放在括号内的命令始终在 shell 中执行。因此：

```bash
cd; pwd
```
