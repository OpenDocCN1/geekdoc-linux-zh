## cricket

Program for configuration and display of time–series data. This is Cricket. It is a configuration, polling, and data–display engine wrapped around Tobiasiet. There are three user-visible pieces to Cricket: the collector, the grapher, and config tree. The collector runs from and fetches data from a number of devices to the info it finds in config tree. The grapher is a CGI application that allows users to traverse the config tree from a web browser and see the data that the collector recorded. From Debian 3.0
