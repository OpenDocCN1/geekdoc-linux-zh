## Imagemap 模块

`imagemap` 模块是 Apache 的核心部分，并默认编译。要使用它，你首先需要配置 Apache 服务器。你应该为 `imagemap` 配置文件选择一个文件扩展名，通常为 `.map`。应将以下 `AddHandler` 命令添加到 `s.conf` 文件中：

```
AddHandler image-file map
```
