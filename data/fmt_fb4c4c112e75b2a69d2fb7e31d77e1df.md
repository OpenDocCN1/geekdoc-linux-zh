# Linux 词典

adj. [源自 'hung up'；常用] 与 `wedged`（卡死）相当，但在 Unix/C 环境中更常见。通常不用于描述人。与 `locked up`、`wedged` 同义；对比 `hoped`。另见。`hung` 状态（挂起状态）与 `crashed`（崩溃）或 `hung`的区别在于，后者是指程序或系统因没有在运行而正在等待某些内容导致无法使用。然而，这种情况的恢复通常是可能的。它与相似但程度更剧烈的 `wedged` 状态也有所区别——`hung` 软件可以通过中断循环等方式唤醒，但 `wedged` 则需要使用 `kill -9` 甚至重启。源自 术语词典 `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

### Hung

指经历了系统故障且不再处理数据的计算机，尽管屏幕上的光标可能仍在闪烁。在大多数情况下，唯一的选择是重启系统，这意味着丢失任何正在进行的工作。源自 QUEDIC `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hunglish

一种英语-匈牙利键盘布局提供了英语-匈牙利键盘布局。该布局在 Linux 控制台和 X 中相同。该包支持所有常见键盘（包括美国 101 键布局）上的所有匈牙利字母。在匈牙利语中，你可以通过按下 Print Screen 键切换模式。Windows 键作为模式切换键。请阅读 `/usr/share/doc/hunglish/README` 了解更多信息。（所有文档均为匈牙利语）。源自 Debian 3.0 APT `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hunt

一种数据包嗅探和连接入侵工具。`hunt` 用于保护连接、监控并重置连接。注意，`hunt` 是在以太网上运行的，最适合可以穿过的监控的连接。然而，也可以对其他网段上的主机或位于交换端口上的主机进行某些操作。源自 Debian 3.0rt `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### huntd

`hunt` 守护进程，`hung game` 游戏的后端。源自 Whatis `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### HURD

替代 Unix 的 DAEMONs（`GNU`, `HIRD`）。源自 VERA `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### Hurd

`Hurd` 将是整个 GNU 系统的基础。它构建在 `Mach 3` 内核之上，`Mach` 是由 CMU 开发的自由消息传递内核。`Mach` 的虚拟内存管理和消息传递机制被 `Hurd` 使用。`GNU C` 将提供 Unix 系统接口，并在需要时调用 `Hurd` 自己无法提供的服务。源自 Linux Guide /FirstLinux `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hwbrowser

用于当前硬件配置的图形化窗口。源自 Redhat 8.0 RPM `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hwclock

查询和设置硬件时钟（`RTC`）。源自 Whatis `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hwdata

硬件识别/配置数据此包包含各种硬件识别和配置数据，例如 `pci` 数据库或 `XFree86` 显数据库。它是 `kudzu` 硬件检测所需的。源自 Debian 3.0rt `http://www.ldp.org/LDP/linux-Dictionary/html/index.html`

### hwtools

低级硬件管理工具集此包是一组用于硬件故障排除和优化的工具（针对 ix86 机器）：

- `iqrtune`: 调整中断优先级（提高性能）
- `scanport`: 扫描尚未 Linux 驱动程序处理的硬件
- `memtest`: 内存测试，支持 MMX。你可能也想看看 `mem86` 包。注意，这些工具需要相关知识才能正确使用，避免对系统造成损坏。某些以前属于此包的程序已移动到单独包中（`hdparam`, `scsitools`, `memtest86`）。源自 Debian 3.0r APT `http://www.ldp.org/LDP/Linux-Dictionary/index.html`
