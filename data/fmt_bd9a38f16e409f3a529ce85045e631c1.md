
该定义中的后续两个步骤涉及定义 `PINGFILE` 和 `MAILFILE` 赋值。`PINGFILE` 包含我们想要 ping 的节点列表。shell 脚本每行一个节点（或主机名）。如果你不再想 ping 列表中的某个节点，可以使用井号 (`#`) 将该行注释掉。对于此脚本，我指定 ping 路径为 `/usr/local/bin/ping`。同样，`MAILFILE` 包含节点不可用时需要通知的电子邮件地址列表。此邮件列表位于 `/usr/local/bin/mail.list`。变量赋值所示：

- `PINGFILE`=`/usr/local/bin/ping` # 要 ping 的节点列表
- `MAILFILE`=`/usr/local/bin/mail.list` # 需要通知的人员列表

对于这两个文件，我们将检查其长度是否非零，这意味着文件存在且大小大于零字节。如果 `$PINGFILE` 不存在，我们需要向用户发送一条 ERROR 消息并让 shell 脚本退出，因为我们没有要 ping 的节点列表。如果 `$MAILFILE` 不存在，我们只需通知用户对于不可用的节点将不会有任何邮件通知。

我们还需要一个文件来存储节点不可用时通过邮件发送的数据。该文件位于 `/tmp/pingfile.out`，并赋值给变量 `PING_OUTFILE`。

```
PING_OUTFILE=/tmp/pingfile.out # 用于邮件通知的文件
>$PING_OUTFILE # 初始化为空文件
```

注意我们是如何通过重定向到文件来创建一个空文件的，该文件由 `$PING_FILE` 变量指向。你也可以使用 `cat /dev/null` 来完成相同的任务，如下：

### 带通知的自动主机 ping 323

```
cat /dev/null > $PING_OUTFILE
```

接下来，我们需要存储数值的变量——我们希望它们是数值。第一个变量名为 `INTERVAL`，它包含一个值，指定了在尝试第二次 ping 不用节点之前睡眠的秒数。我喜欢用秒作为单位。

```
integer INTERVAL="3" # 重试之间的睡眠秒数
```

正如我们之前讨论的，在标准的 ping 输出中，我们对输出中的 P Statistics 这一行感兴趣。具体来说，我们需要提取 "3 packets received" 的数值，如果节点是可用的，该值应该大于零。为了存储接收到的 ping 数量，我们需要两个变量，分别用于第一次和第二次尝试，以防节点不可用，前两个变量是 `PINGSTAT` 和 `PINGSTAT2`，并被初始化为 NULL，如下：

```
PINGSTAT= # ping 节点后收到的 ping 数量
PINGSTAT2= # 第二次尝试收到的 ping 数量
```

我们需要赋值的最后一个变量是运行此脚本的机器的主机名。我们使用主机名，是因为我们有两个节点在互相 ping，以防其中一个节点 ping 失败。对于这个变量，我们再次使用命令替换，如下：

```
THISHOST=`hostname` # 此机器的主机名
```

注意，这次我们使用了反引号（`` `command` ``）而不是双括号方法（`$(command)`）来进行命令替换。两种命令替换都会产生相同的结果，在此机器上是 yogi。

## 创建 Trap（陷阱）

在开始时我们将设置一个 trap，因为用户按下 CTRL-C 在捕获退出信号时可以捕获大多数操作。我们可以捕获除 `kill -9` 之外的大多数操作。在这个 shell 脚本中唯一想要的操作是通知用户 shell 脚本检测到了退出信号且脚本正在退出。在这个 shell 脚本中添加此 trap是为了让你养成在所有脚本中放置 trap 的习惯。我们将捕获信号 1、2、3、5 和 15。你完全可以添加更多信号，但在这种情况下那是多的。要查看完整的信号列表，请使用 `kill -l (-ell)` 命令。其命令语法所示：

```
trap 'echo "nexit on a trapped signal...\n";exit 1 2 3 5
```
