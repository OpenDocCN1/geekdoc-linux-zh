## URL 编码（Python 2 中的 urllib 模块）

以下函数用于组成 URL 的数据的编码和解码。

```python
quote(string, safe='/', encoding='utf-8', errors='strict')
```

将字符串中的字符替换为适用于包含在 URL 中的转义序列。字母、数字以及划线 (`_`)、逗号 (`,`)、句号 (`.`) 和连字符 (`-`) 保持不变。所有其他字符都被编码为 `'%xx'` 形式的序列。`safe` 提供了一个不需要被引号的额外字符字符串，默认是 `'/'`。`encoding` 指定用于非 ASCII 字符的编码。默认是 `'utf-8'`。`errors` 指定当遇到编码错误时的处理方法，默认为 `'strict'`。`encoding` 和 `errors` 参数仅在 Python 3 中。

```python
quote_plus(string, safe='/', encoding='utf-8', errors='strict')
```

调用 `quote()` 并额外将所有空格替换为加号。`string` 和 `safe` 与 `quote()` 中的相同。`encoding` 和 `errors` 与 `quote()` 相同。

```python
quote_from_bytes(bytes, safe='/')
```

与 `quote()` 相同，但接受字节字符串且不执行编码。返回的是文本字符串。仅限 Python 3。

```python
unquote(string, encoding='utf-8', errors='replace')
```

将 `'%xx'` 形式的转义字符替换为相应的单字符等效字符。`encoding` 和 `errors` 指定 `'%xx'` 转义字符中数据的编码和错误处理。默认编码为 `'utf-8'`，默认错误策略为 `'replace'`。`encoding` 和 `errors` 仅限 Python 3。

```python
unquote_plus(string, encoding='utf-8', errors='replace')
```

类似于 `unquote()`，但还会将加号替换为空格。

```python
unquote_to_bytes(string)
```

与 `unquote()` 相同，但不执行解码并返回字节字符串。

```python
urlencode(query, doseq=False)
```

将 `query` 中的值转换为 URL 编码字符串，以便包含在 URL 查询参数中或作为 POST 请求的一部分上传。`query` 是字典或 `(key, value)` 元组序列。结果是一系列由 `'&'` 分隔的 `'key=value'` 对，其中 `key` 和 `value` 使用 `quote_plus()` 进行引用。`doseq` 参数是一个布尔标志，如果任何值是字符串（代表该键的多个值），则应将其设置为 `True`。在这种情况下，会为每个 `v` 值创建一个 `'key=v'` 字符串。

## 示例

以下示例展示了如何将查询变量字典转换为适用于 HTTP GET 请求的 URL，以及你如何解析 URL：

```python
try:
    from urllib.parse import urlparse, urlencode, parse_qs  # Python 3
except ImportError:
    from urlparse import urlparse, parse_qsl  # Python 2
    from urllib import urlencode

# 创建带有正确编码查询变量的 URL 的示例
form_fields = {
    'name': 'Dave',
    'email': 'dave@dabeaz.com',
    'uid': '12345'
}

form_data = urlencode(form_fields)
url = "http://www.somehost.com/cgi-bin/view.py?" + form_data

# 将 URL 解析为组件的示例
r = urlparse(url)
print(r.scheme) # 'http'
print(r.netloc)  # 'www.somehost.com'
print(r.path)    # '/cgi-bin/view.py'
print(r.params)   # ''
print(r.query)    # 'uid=12345&name=Dave&email=dave%40dabeaz.com'
print(r.fragment) # ''
```

```python
# 提取查询字段
parsed_fields = dict(parse_qsl(r.query))
form_fields == parsed_fields
```

## urllib.error

`urllib.error` 模块定义了 `urllib` 包中使用的异常。

### ContentTooShort

当下载的数据量少于预期量（由 `'Content-Length'` 请求头定义）时抛出。在 Python 2 的 `urllib` 模块中定义。

### HTTPError

用于指示 HTTP 协议问题。此错误可能用于信号身份验证失败等事件。此异常也可以用作文件对象，读取与错误相关的服务器返回的数据。它是 `URLError` 的子类。在 Python 2 的 `urllib` 模块中定义。

### URLError

当检测到问题时由处理器抛出。它是 `IOError` 的子类。异常实例的 `reason` 属性具有关于该问题的更多信息。这在 Python 2 的 `urllib2` 模块中定义。
