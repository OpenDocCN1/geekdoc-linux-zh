
### 选项

- `-m` 移动文件。如果你指定 `posname` 操作数指定 `-a`、`b` 或 `-i`，则将文件移动到新位置；否则，将文件移动到归档末尾。

- `-p` 将归档文件的内容打印到标准输出。如果你没有指定文件，则按归档顺序写入归档所有文件的内容。

- `-q` 快速将文件追加到归档末尾。定位选项 `-a`、`b` 和 `-i` 无效。命令不检查添加的文件是否已在归档中。此选项有助于在逐个创建大型归档时避免平方行为。

替换或添加归档文件。如果归档不存在，则创建一个新的归档文件并向标准错误写入诊断消息（除非你指定 `-c` 选项）。如果未指定文件且归档已存在，则结果未定义。替换现有文件的文件不会更改归档的顺序。如果你在使用 `-r` 选项时使用 `-u` 选项，则修改日期晚于归档的文件将被替换。如果你使用 `-a`、`-b` 或 `-i` 选项，你必须指定 `posname` 并指明新文件应放置在 `posname` 之后 `-a` 或之前 `-b` 或 `-i`；否则，新文件将置于最后。

- `-r`

- `-s` 即使你没有使用修改归档内容的选项来调用 `ar`，也强制重新生成归档符号表。此命令用于在对归档文件使用 `strip(1)` 命令后恢复归档符号表。

- `-t` 打印归档的目录内容（内容列表）。由文件操作数指定的文件将包含在写入列表中。如果未指定文件操作数，则包含归档中的所有文件或按归档顺序包含文件。

- `-T` 允许对提取出的文件进行文件名截断，如果其归档名称超过了文件系统的支持。默认情况下，提取名称过长的文件是一个错误；会写入诊断消息且不提取该文件。

- `-u` 更新顺序。当与 `-r` 选项配合使用时，仅当对应文件的修改时间至少新于归档内文件的修改时间时，才替换归档内的文件。

- `-V` 在标准错误上打印版本号。

- `/usr/bin/ar` 提供详细输出。当与 `-d`、`-r` 或 `-x` 选项配合使用时，写入归档创建、组成文件以及维护活动的详细逐文件描述。

当与 `-p` 使用时，在将文件本身写入标准输出之前，先将文件名写入标准输出。

当与 `-t` 使用时，包含关于归档内文件的详细信息列表。

当与 `-x` 使用时，在每次提取之前打印文件名。

在写入归档时，向标准错误写入消息。

- `/usr/xpg4/bin/ar`

- `-v` 与 `/usr/bin/ar` 的版本相同，但在写入归档时，不向标准错误写入任何消息。

从归档中提取文件操作数指定的文件。归档的内容不会改变。如果你没有指定文件操作数，则提取归档中的所有文件。如果从归档提取的文件名长于目标目录支持的长度，则结果未定义。将每个提取文件的修改时间设置为该文件从归档提取的时间。

`-x`

### 操作数 (Operands)

- 归档文件的路径。一个路径。在与归档中的文件名比较时，仅使用最后一个组件。如果两个或多个操作数具有相同的最后一个路径组件 `basename(1)`，则结果是不确定的。实现的归档格式不会截断添加到或替换在归档中的有效文件名。

- `archive`

- `file`

- 归档文件中的某个文件名，用于相对定位；参见选项 `-m` 和 `r`。

- `posname`

### 示例 (Examples)

以下示例显示了如何找到哪些对象模块组成 `libexample.a` 归档。

```
castle% t libexample.a
```

以下示例显示了如何从共享对象中提取一个模块。如果 `module.o` 是归档库 `libexample.a` 的一部分，你可以使用以下命令提取该模块。

```
castle% ar x libexample.a module.o
```

SunOS 4.x 中的 `ranlib` 命令用于向归档库添加目录内容。`ranlib` 命令现在整合到 `/usr/ccs/bin/ar` 中。当 `ar` 归档对象文件时，它会自动创建一个符号表，如下例所示。

```
castle% rcv libfoo.a foo.o bar.o
```

以下命令强制重新构建归档库中的符号表。

```
castle% ts libfoo.a
```

## arch — 显示当前主机的架构

### 概要 (Synopsis)

```
/usr/bin/arch [-k | archname]
```

### 描述 (Description)

系统根据其架构进行粗分类，架构定义了哪些执行文件运行在哪些机器上。你可以区分内核架构和应用架构（或通常称为架构）。由于底层硬件差异运行不同内核的系统可能运行相同的应用程序。

`arch` 显示当前主主机系统的应用架构。由于该命令在历史上被广泛使用且不带任何选项，所有 SunOS 5。

## 选项 (Options)

- `-k` 显示内核架构。

- `archname` 显示应用架构。
