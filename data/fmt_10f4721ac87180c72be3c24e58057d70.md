# 第六部分附录

`cp` 复制文件。

`cp [OPTION]... SOURCE DEST`

`cp [OPTION]... SOURCE... DIRECTORY`

```bash
$ cp --verbose newbeaniebabies.dat retired_beanies.dat
newbeaniebabies.dat -> retired_beanies.dat
```

根据命令选项复制并转换格式。

`dd [options]`

```bash
$ dd if=ps of=short_ps_file obs=1
13+1 records in
6712+0 records out
```
