
# Firefox ESR

`flatpak install flathub org.mozilla.firefox`

访问 `Firefox ESR` 官方网站 `https://www.mozilla.org/en-GB/firefox/enterprise/` 了解有关 `Firefox ESR` 的所有信息。

通过软件管理器获取 `DEB/FLATPAK` 包：

- 打开软件管理器并搜索 `Firefox`。
- 点击 `Firefox`，然后点击源选择框。
- 选择系统级包（`System Package`）或 `Flatpak`，并点击安装。

通过图形用户界面使用 `.deb` 安装 `Firefox ESR`：

1. 转到发布页面：`https://www.mozilla.org/en-GB/firefox/enterprise/` 了解有关 `Firefox ESR` 的所有信息。
2. 点击“接受并下载”以下载 `Firefox ESR`。
3. 进入 `~/Downloads`。
4. 双击 `firefox-stable_122.0.2365.52-1_amd64.deb`。
5. 点击“安装”。

## Pale Moon

访问 `Pale Moon` 官方网站 `https://www.palemoon.org/` 了解关于 `Pale Moon` 的所有信息。

通过 GUI 使用 `.tar.xz` 安装 `Pale Moon`：

1. 导航至发布页面：`https://www.palemoon.org/download.shtml`。
2. 在与 `Linux 64-bit GTK3` 同一行点击 `Download tarball`（下载压缩包）下载 `Pale Moon`。
3. 进入 `~/Downloads`。
4. 双击 `palemoon-33.0.0.linux-x86_64-gtk3.tar.xz`。
5. 选择 `palemoon`，点击 `Extract`（解压）。
6. 进入 `~/Downloads`。
7. 点击 `Extract`（解压）。
8. 进入 `~/Downloads/palemoon`。
9. 双击 `palemoon`。

### 来自 GUI 的 `Pale Moon` .desktop 快捷方式：

为 `Pale Moon` 创建桌面快捷方式，首先打开终端并输入以下命令：

```
cd /usr/share/applications
sudo gedit palemoon1.desktop
```

接下来，用以下内容更新 `palemoon1.desktop` 文件：

```
[Desktop Entry]
Name=Pale Moon
Comment=Pale Moon
Exec=./Downloads/palemoon/palemoon
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

保存更改时，点击“Save（保存）”按钮，或前往“File（文件）”并选择“Save”，或点击 ≡ 菜单图标，选择“Save As（另存为）”，然后点击“Save（保存）”。完成后退出编辑器。

请确保 `Exec=` 路径正确指向您系统上 `Pale Moon` 可执行文件的所在位置。
