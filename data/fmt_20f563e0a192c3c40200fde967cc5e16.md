## 命令行参数

你已经见过几个使用命令行参数的脚本。当脚本被启动时，启动脚本的 Shell 会在命令行上寻找额外数据。脚本名称之外任何内容都被视为命令行参数并放入 Shell 变量中。用于命令行存储的 Shell 变量命名为 `$1`（第一个参数）、`$2`（第二个参数）等。这些也被称为位置参数（positional parameters），因为参数的位置决定了存放它的 Shell 变量名称。表 8.1 提供了你在 Shell 脚本中可用的位置参数和特殊参数列表。

### 表 8.1：位置参数和特殊参数

| 参数 | 含义 |
| --- | --- |
| `$0` | 脚本、shell 或函数的名称。 |
| `$1`, `$2`, `$3` 等 | 位置参数的值。 |
| `$@` | 所有由空格分隔的参数。如果 `@` 被加引号，带引号的参数将被设置为单个位置。 |
| `$*` | 与 `$@` 相同，但带引号的参数由 IFS 分隔。 |
| `$#` | 命令行参数的数量。 |

```bash
print "Argument 2 is ${2}"
print "Argument 3 is ${3}"
print "There are ${#} arguments."

Argument 2 is Pitts
Argument 3 is Ellis
There are 3 arguments.
$
$ params O'Brien Pitts Ellis Dyment
Argument 1 is O'Brien
Argument 2 is Pitts
Argument 3 is Ellis
There are 4 arguments.
$
$ params O'Brien
Argument 1 is O'Brien
Argument 2 is # 如果未使用，参数将为空
Argument 3 is
There are 1 arguments.
$
```

## 命令行参数（进阶）

在 ksh 中，`getopts` 命令还可以处理选项前的 `+`，用于处理未设置的情况。请查看帮助页以确定 `getopts` 是否具有该功能。

此外，`getopts` 内部有一种特殊语法可以处理用户提供的无效选项。选项列表前的 `:` 告诉 `getopts` 将无效参数放入 `OPTARG` 并将变量 `opt` 设置为 `?`。

下一个示例显示了使用 `getopts` 处理命令行参数和错误的基础。`getopts` 命令位于 `while` 循环顶部。循环一直持续到 `getopts` 报告失败状态，即命令行上没有更多选项。注意，额外的参数（非选项）不会被 `getopts` 处理，除非它们遵循 `-o` 或 `-n` 选项。

让我们检查选项列表 `:rwn#o:`。开头的 `:` 请求 `getopts` 将错误参数放入 `OPTARG` 并将变量 `opt` 设置为 `?`。`r` 和 `w` 是普通选项，`n#` 表示该选项后面应该跟一个数值。而 `o:` 则表示该选项后面应该跟一个参数。这对于文件输入选项非常有用。`opt` 变量持有当前正在处理的选项，因此非常适合在 `getopts` 内部的 `case` 语句中使用：

```bash
$ cat getopt
#!/bin/ksh
## 使用 getopts, OPTARG, OPTIND
## 解析命令行示例
while getopts :rwn#o: opt # 设置预期的选项
do
    case $opt in
    r) print "Processing for r option..." # 可以设置标记或调用
       ;; # 一个函数
    w) print "Processing for w option..."
       ;;
    n) print "Processing for n option..."
       num=$OPTARG # OPTARG 获取数值
       print "Number is $num" # 伴随 -n
       ;;
    o) print "正在处理 o 参数..."
       ofile=$OPTARG # OPTARG 获取参数
       print "输出文件: $ofile" # 伴随 -o
       ;;
    :) print -u2 "OPTION: $OPTARG 需要额外信息。"
       exit 1
       # 变量 opt 获取 : -o
       # 或 -n 是完整的
       ;;
    \?) print -u2 "$OPTARG 是给 $0 的无效选项"
        exit 2
        # 变量 opt 获取 ? 用于
        # 无效选项
        ;;
    esac
done
# 移动到选项后的参数
shift $((OPTIND-1)) # 从命令行中移除选项
print "正在处理文件名。" # 命令行
for nfile; # 访问剩余部分
do
    print $nfile
done
```
