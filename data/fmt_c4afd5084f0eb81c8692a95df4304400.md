# 开源 (open-source)

“开源”描述了互联网所反对的一系列政治价值观。在创建软件代码时，程序员会编写代码。“源码”是构建软件的基石。从二进制文件中重构源代码是不可行的，这意味着使用软件的人无法看到构建该软件的源代码。政治观点是，人们应该能够查看源码，即对任何人都是“开放”可读的。主要原因是开源创造了“自由”。人们可以随心意欲地对源码进行更改，修复漏洞或为软件添加功能。其中还涉及一种偏执心理：人们觉得他们无法阅读的闭源软件可能正在进行其他事情，例如为政府秘密监控人员。争议在于：开源倡导者认为由于以下原因，它是有益的：安全性建立在同行评审原则之上。这在加密世界尤为如此，在那里任何未经加密社区成员评审审核的开源软件都是不被接受的。然而，截至 2001 年，开源和闭源都是大规模问题的根源（例如许多流行的 Linux 蠕虫）。开源软件许可证通常是免费的。然而，由于许多产品的软件许可证费用远小于运营成本，因此价格并不重要。例如，BIND 和 Sendmail 并不是因为免费许可证而流行，而是因为它们作为标准已超过 15 年。这些产品易于理解，因此对公司来说操作廉廉。同行评审模型表明漏洞可以很容易发现。然而，开源和闭源都面临代码是一个不断变动目标的问题。在某些情况下，有一些开源项目（如 OpenBSD），开发者专注于稳定代码而非追求最新最强大的特性。由于源码是开放的，开发者可以轻松更改它以添加功能。然而，人们认为 Linux 代码的记录太差，因此对其进行更改可能是一种负担。例如：以下是著名的开源项目：Linux、Apache、sendmail、BIND、Samba、Perl、MySQL 源自 Hacking

# OpenGL

是多年前由 SGI 开发的立即模式编程 API。它由其先的 Iris GL 定义，多年来一直是架构评审委员会（ARB）维护的行业标准，该组织的成员包括 SGI、IBM、DEC 和微软。OpenGL 为三角形和多边形渲染的流水线硬件架构提供了 2D 和 3D 图形操作的完整功能集。从更广泛的来说，OpenGL 是一种辅助计算机图形的强大通用工具包。源自 3DFX-HOWTO
