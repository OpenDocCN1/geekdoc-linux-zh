```
# 处理空输入（翻译为 <@> 特殊情况）
R$@  $@ <@>
```

```
# 空输入现在源于列表;;语法
R$@  $@ ; <@>
```

```
# 去除角括号 - 注意 RFC733 获取最内部项的启发式算法
R$*  $1 < $>  清理 <>
R$+ < $* >  $2 < $>  去除左侧多余
R< $* > $*+  $1 < $>  去除右侧多余
R<>  $@ <@>  MAIL FROM:<> 情况处理
R< *>+  $1 : $1  移除清理 <>
```

```
# 确保 <@,b,@c:user@> 语法易于解析 - 稍后会取消
R$ + , + $  @ $1 : $2  将 a1 "," 更改为 \"
```

```
# 本地化并处理基于路由的地址
R$ $+ : $+ $+ $0 $96 < $01 > $2 处理 <route-addr>
```

```
# 查找列表语法的焦点
R$ $* : $+ @ $+ $0 $96 $1 : $2 ; < @ $3 列表语法
R$ $* : $+ $* $0 $1 : $2; 列表语法
```

```
# 查找 @ 语法的焦点
R$* @ $+ $+ $* $1 < @2 聚焦于域名
R$* @ $* $0 $96 $1 < @2 已经是规范的
