
## 6.2. M4-1.4.19

M4 包包含一个宏处理器。

估计构建时间：0.1 SBU

所需磁盘空间：31 MB

### 6.2.1. 安装 M4

为编译 M4 准备环境：

```bash
./configure --prefix=/usr \
  --host=$LFS_TGT \
  --build=$(config.guess)
```

- `--disable-libstdc++-pch`

这防止安装预编译的头文件，这些文件在此阶段是不需要的。

- `--with-gxx-include-dir=/tools/$LFS_TGT/include/c++/13.2.0`

这指定了头文件的安装目录。由于 Libstdc++ 是 LFS 的标准 C++ 库，此目录应与 C++ 编译器 `$LFS_TGT-g++` 搜索 C++ 头文件的位置匹配。

## 6.17. Binutils-2.42 - 第二阶段

Binutils 软件包包含链接器、汇编器以及处理目标文件的其他工具。

预计构建时间：0.5 SBU

所需磁盘空间：537 MB

### 6.17.1. 安装 Binutils

Binutils 的构建依赖于共享 libtool 副本来链接内部静态库，软件包提供的副本没有使用 libtool。这种不一致性可能会导致二进制文件错误地链接到主机发行版的库。解决这个问题：

```bash
sed '609s/$add_dir// -i ltmain.sh
```

再次创建一个独立的构建目录：

```bash
mkdir -v build
cd build
```

准备编译 Binutils：

```bash
./configure \
--prefix=/usr \
--build=$(config.guess) \
--host=$LFS_TGT \
--disable-nls \
--enable-shared \
--enable-gpocf=no \
--disable-weorror \
--enable-64-bit-bfd \
--enable-default-hash-style=gnu
```
