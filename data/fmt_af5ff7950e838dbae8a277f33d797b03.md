
**列表 25.12** Samba 源码安装。

## 从 Unix 发送弹出消息

安装完成后，你可以删除 `/usr/local/samba.2` 目录以恢复磁盘空间。请注意，你的文件/目录名称可能与列表 25.12 中显示的命令不同。此源码不会创建 `smb.conf` 文件。在列表 25.12 所示的过程中，`smb.conf` 文件位于 `/usr/local/samba/lib/smb.conf`。请参考你安装的版本的 Samba 文档，以了解将此配置文件放在哪里。出于我们的目的并出于安全考虑，请保持文件简单！`smclient` 命令可以使用仅包含单个分号（`;`）的 `smb.conf` 文件工作。不需要其他条目！分号（`;`）和井号（`#`）在该文件中都是注释的指定规范。如果你想使用 Samba 的任何其他功能，你需要自行解决，Samba 文档是你获取额外信息的最佳资源。

## 首次测试 smbclient 程序

在开始创建主列表和一组组列表之前，进行几次测试以确保格式正确、机器可达，并且每个节点的名称解析已解决。最初准备一个大约五台机器的列表。机器在 NetBio 中以机器名或用户名的形式引用。这种名称解析取决于你环境中的 Windows 网络。

我的家庭网络没有运行 NetBios，所以我必须做了一些研究，并发现有一个与 `smb.conf` 文件共存的文件。该文件被称为 `lnhosts`，你像普通的 hosts 文件一样在 `/etc/hosts` 文件中输入条目，其中机器名以大写字母输入。

首先尝试列出它。假设我们五个用户：JohnB、CindySue、JonnyLee 和 BobbyJoe。对于列表中的每个用户，运行以下命令。

```bash
echo "Hello World" | smbclient -M JohnB
echo "Hello World" | smbclient -M CindySue
echo "Hello World" | smbclient -M Bubba
echo "Hello World" | smbclient -M JonnyLee
echo "Hello World" | smbclient -M BobbyJoe
```
