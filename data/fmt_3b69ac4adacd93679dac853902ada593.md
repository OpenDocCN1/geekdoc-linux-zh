顺序的对称性缺尚未被完全解释。迹象表明时间顺序中存在内在的不对称性。基础物理定律并非真正的时间对称，且目前知的定律在归纳方面是非对称称的。R 过程的方向尚未知。然而，并不是说大型且奇异的时间不对称实例可以从观测到的本质上宏观的电磁现象宇宙中产生。

另一个普遍的基础不对称过程的例子是宇宙的膨胀。据测这种膨胀是导致时间不对称的原因。

或者，一个时间对称的宇宙将具有统计行为，其中分子和星系的构型仅在长时间间隔后出现。这些间隔长于宇宙及其组成部分膨胀所需的时间。时间箭头通过时间的性质或大数统计被区分出来，以填充未来。

时间常数。控制指数函数趋于稳态值的特征属性。当一个物理量是时间的递减指数函数（如方程 `(1)` 所示）或递增指数函数（如方程 `(2)` 所示）时，长时间后达到稳态由方程 `(3)` 给出的特征 `T` 控制。`T` 被称为时间常数。

```
      (1)
```

```

```

```
t = T/k
      (3)
```
