
## 5.2.2 任务 2 构建命令管道

接下来我们将分析“提取文本内容”这个问题。要解决这个问题，用的工具之一就是 Linux 的“管道（pipe）”。

本质来说，管道就是一种重定向，也就是对一个命令的输出通过管道连接（即重定向），作为下一个命令的输入。在 Linux 环境下，命令操作最常用的方式就是构造命令管道。最常用的方式用管道操作符“|”。

| 管道构造方法 | 说明 |
|---|---|
| 命令1 | stdout | 第一个命令的输出 |
| | | 传递给第二个命令的输入 (stdin) |
| 命令2 | stdout | 第二个命令的输出 |
| | | 传递给第三个命令的输入 (stdin) |
| 命令3 | stdout | 第三个命令的输出，直接显示在终端上 |

这种构造就可以通过添加命令来完成复杂的任务。Linux 管道的一个巨大优点是不涉及中间文件。第一个命令的 `stdout` 不需要写入文件，而是由第二个命令读取。

### 管道原理

```
命令1 | 命令2 | 命令3
|---|---|---|
| stdout | stdin | |
| | stdout | stdin |
| | | stdout |
```

接下来在实施的过程中尝试使用一些非常有用的工具（过滤器）来处理文本。

任务 1：统计 Apache 日志中所有客户端的数目。可以用如下清单 5-16 所示。

### 清单 5-16

```bash
cat /var/log/http/access_log | cut -d ' ' -f1 | sort | wc -l
```

下面分析管道中的命令：
- `cut` 命令：`cut -d ' ' -f1` 将日志的第一个字段（空格分隔）截取后输出到标准输出。其中，选项 `-d` 指定字段符，这里指定的是 `' '`（空格）；选项 `-f` 指定的是第一个字段。
- `sort` 命令：对输出进行排序。
- `uniq` 命令：删除输出中的重复。
- `wc -l`：统计输出的行数。

任务 2：查看日志中访问次数排名前 5 个客户端，并将 IP 保存到名为 `clients.txt` 的文件中。可以使用清单 5-21 所示的命令管道完成任务。该命令管道的前两个命令与任务 1 相同，这里就不解释了，下面从命令三开始说明。

### 清单 5-21

```bash
cat /var/log/http/access_log | cut -d ' ' -f1 | sort | sort -nr > clients.txt
```

命令三、四是 `sort` 和 `uniq`，这两个命令的作用与任务 1 类似，用于删除输出中的重复，只需对 `uniq` 使用 `-c` 选项，其作用是统计重复后的次数（即每个 IP 访问次数），显示在对应的行开头（如清单 5-22 所示）。

### 清单 5-22

```bash
cat /var/log/http/access_log | cut -d ' ' -f1 | sort | uniq -c
```

```
1280 172.18.1.4
244 172.19.19.102
106 172.30.46.8
```

接下来的第五命令 `sort -nr` 就顺理成章了。其中，`-n` 表示按数值大小排序；`-r` 反转排序方式，即从默认的升序，反转为降序。那么 `uniq -c` 的输出将第一个字段的数值从小到大排序，如清单 5-23 所示。

### 清单 5-23

```bash

```

```
244 172.19.19.102
106 172.30.46.8
```

## 5.3 学习知识

### 5.3.1 什么是 VFS 和 I/O

在任务 4 管理文件的任务 1 中提到过 Linux 中“一切文件”，这只是一种说法，“一切文件”是 UNIX（也是 Linux）的基本哲学之一。

确切来说，Linux 提供了一种特殊的机制，称为虚拟文件系统（VFS），使得不同的文件系统（file system）中普通文件、目录、各种输入设备、符号链接、管道、套接字的底层 I/O 细节被掩盖了，最终被当作了我们理解的“字符流”（character stream）或“字节流”（byte stream），也就是一种字符串或字符序列，可以用相同的方式进行读（I/O）操作。

![](img/a95c6704e7d361880a5dd1f2c0aafd0_151_0.png)

| 目录 | 文件 | 套接字 | 管道 | 设备 | 符号链接 |
| --- | --- | --- | --- | --- | --- |

图 5-7 一切都是文件

简单来说，当打开文件时，VFS 会知道该文件对应的文件系统格式；VFS 把控制权传给实际的文件系统时，实际的文件系统再做出此区分，对于不同的文件类型执行不同的操作，如图 5-8 所示。这就是“一切都是文件”的根本所在。

| read() | sys_read() | 具体文件系统的方法 |
| --- | --- | --- |
| VFS | 具体文件系统 | 物理设备 |

图 5-8 VFS 封装了底层的读写操作

因此，对于一般的用户来说，在 Linux 中没有文件系统如 `ext4` 或 `xfs` 了，写一个普通的文件和写一个设备没有任何区别，都是操作一个字符字符串或字节流。输入输出设备同样例外，当执行一个命令时，shell 会自动将其打开并建立 3 种标准输入输出：

- 标准输出 (`stdout`)，显示命令的输出，文件描述符是 1。
- 标准错误输出 (`stderr`)，显示命令的错误输出，文件描述符是 2。
- 标准输入 (`stdin`)，向命令提供输入，文件描述符是 0。

### 5.3.2 知识点 2 常用的过滤器

本节重点讲解几个在前面要用的命令，这些命令都是过滤器 (filters) 命令。这几个命令之所以称为“简单”，是相对于知识点 3 介绍的 `grep` 这个功能强大、用法复杂的过滤器命令来实现的。

#### 1. cut 命令

首先介绍 `cut` 命令的语法格式，然后用 3 个例子来展示和说明。

用法：`cut [选项] [文件]`
功能：`cut` 命令的意思是可以从文件的每一行切分字节、字符和字段到标准输出。如果不指定 `[文件]` 参数，`cut` 命令将读取标准输入。必须指定 `-b`、`-c` 或 `-f` 之一（即分隔符是按字节、字符或者字段）。`cut` 命令的所有选项详细说明见表 5-4 所示。

| 选择 | 说明 |
| --- | --- |
| `-b` | 以字节为单位分割。这些字符忽略多字节字符，除非指定了 `-n` 标志 |
| `-c` | 以字符为单位进行分割 |
| `-d"分隔符"` | 自定义分隔符，认为是分隔符，注意分隔符用双引号(`" "`)或者单引号(`''`) |
| `-f` | 与 `-d` 一起使用，指定切分字段 |

下面的 3 个例子都是用清单 5-29 所示的 `users.txt` 作为操作对象。

```
$ cat users.txt
jack:x:1001:jack:home/bin/bash
postfix:x:89:89:/var/pool/sbin/nlogin
mp:x:72:72:/sbin/nlogin
stu:x:1000:1000:/home/bin/bash
```

例 1: 以字节为单位，如清单 5-30 所示。

```
$ cut -b 6 users.txt
m:x
p:x
s:x
```

切第 6 字符和第 12 个字符：

```
$ cut -b 6,12 users.txt
m:x:tu:x
```

切第 6 字符开始到末尾：

```
$ cut -b 6- users.txt
postfix:x:89:89:/var/pool/sbin/nlogin
mp:x:72:72:/sbin/nlogin
stu:x:1000:1000:/home/bin/bash
```

例 2: 自定义分隔符，切分字段，如清单 5-30 所示。

以冒号(`:`) 为分隔符，切分字段：

```
$ cut -f1 users.txt
jack
postfix
mp
stu
```

![](img/a95c6704e7d361880a5dd1f2c0aafd0_153_0.png)

用冒号(`:`) 为分隔符，切第 2 到 4 字段：

```
$ cut -d: -f2-4 users.txt
x:1001:jack
x:89:89
x:72:72
x:1000:1000
```

例 3: 以字符为单位，在例子中字符就是单字节，所以字节和字符是等价的，而例中的操作是多字节字符，所以如清单 5-32 所示。您可以根据 Free Software Foundation 公布的 GNU 通用许可证（该许可证的 2.1 版本或任何版本）的条款将其分发或对其修改。用字节为单位，切第 2 到 4 字符，因为多字节字符不符，因此切会出现：

```bash
cut -b 2-4 license.txt
```

用字符为单位，切第 2 到 4 字符：

```bash
cut -c 2-4 license.txt
```

#### 2. sort 命令

下面首先介绍 `sort` 命令的语法格式，然后用 6 个例子来展示和说明。

用法：`sort [选项][文件]`
功能：`sort` 命令，其功能是将文件的内容按照指定规则进行排序。`sort` 命令的常用选项及其说明如表 5-5 所示。

| 选项 | 描述 |
| --- | --- |
| `-b` | 忽略每行前面出现的空格字符 |
| `-n` | 依照数值大小的升序 |
| `-r` | 以相反的顺序来排序 |
| `-t` | 指定排序时所用的字段分隔符 |
| `-k<n>` | 按指定字段 n 排序 |

下面的 6 个例子都是用清单 5-30 中的 `users.txt` 作为操作对象。所示清单 5-33。

例 1: 默认，排序按 ASCII 码排序，所以如清单 5-33。

```
$ sort users.txt
jack:x:1001:jack:home/bin/bash
postfix:x:89:89:/var/pool/sbin/nlogin
```

例 2: 在原始基础上加上 `-r` 选项，就可以实现反向排序。例如例 1 加上 `-r` 就变成降序，如清单 5-34 所示。

```
$ sort -r users.txt
stu:x:1000:1000:/home/bin/bash
postfix:x:89:89:/var/pool/sbin/nlogin
jack:x:1001:1001:jack/bin/bash
```

例 3: 指定字段，可以用 `-t` 指定分隔符，用 `-k` 指定字段，如清单 5-35 所示。

```
$ sort -t: -k6 users.txt
jack:x:1001:1001:jack/bin/bash
stu:x:1000:1000:/home/bin/bash
```

例 4: 按数字排序，如清单 5-36 所示。

```
$ sort -n users.txt
postfix:x:89:89:/var/pool/sbin/nlogin
jack:x:1001:jack:home/bin/bash
```

例 5: 按字段 1 中的第 2 个字符排序，如清单 5-37 所示。

```
$ sort -t: -k1,2 users.txt
jack:x:1001:jack:home/bin/bash
stu:x:1000:1000:/home/bin/bash
```

例 6: 使用多字段实现，如清单 5-38 所示。

```
$ sort -t: -k6,2 users.txt
jack:x:1001:1001:jack/bin/bash
```

#### 3. uniq 命令

下面首先介绍 `uniq` 命令的语法，然后用 4 个例子来展示和说明。

用法：`uniq [文件]`
功能：`uniq` 命令是英文单词 unique 的缩写，它的功能是检查及去除文件中连续的重复行。`uniq` 命令的常用选项如下表 5-6 所示。

| 选项 | 说明 |
| --- | --- |
| `-c` | 去除连续重复，并在每一行的字符显示重复次数 |
| `-d` | 显示重复出现的行 |
| `-u` | 显示只出现一次的行 |

下面的 3 个用例是用清单 5-39 显示的文本文件 `uniq.txt` 作为操作对象。

```
1 jack:x:1001:jack:home/bin/bash
1 postfix:x:89:89:/var/pool/sbin/nlogin
1 stu:x:1000:1000:/home/bin/bash
```

例 3: 显示文中没有重复的行，要和 `sort` 命令配合来实现，如清单 5-42 所示。

例 4: 显示文本中重复出现的行，要用 `sort` 命令管道才能实现，如清单 5-43 所示。

```
$ sort uniq.txt | uniq -d
jack:x:1001:1001:jack/home/bin/bash
postfix:x:89:89:/var/pool/sbin/nlogin
```

## 5 wc 命令

下面将首先介绍 `wc` 命令的语法格式，然后用 1 个例子来演示和说明。

用法：`wc [选项] [文件]`
功能：`wc` 命令是 word count 的缩写，其功能是统计文件的字数、字符数、单词数或行数，若未指定名称或所指定的文件名为“--”，则 `wc` 命令会从标准输入设备读取数据。
`wc` 命令的常用选项及其说明如表 5-8 所示。

表 5-8 `wc` 命令的常用选项及其说明

| 选项 | 说明 |
|---|---|
| `-c` | 统计文件的字节数 |
| `-w` | 统计文件中的单词数，指单词（word）在这里与英语中的单词概念完全不同，指的是一个由空格、Tab 键或换行符分隔的字符串 |
| `-l` | 统计文件的行数 |
| `-L` | 文本中最长行的长度 |

举例：分别列出输出文件的行数、单词数、字数和最长行的长度，如清单 5-49 所示。

### 清单 5-49

```
$ wc /etc/passwd
44 87 2287 /etc/passwd

# 显示行数
$ wc -l /etc/passwd
44

# 显示单词数的定义
$ wc -w /etc/passwd
87

# 显示字数
$ wc -c /etc/passwd
```
