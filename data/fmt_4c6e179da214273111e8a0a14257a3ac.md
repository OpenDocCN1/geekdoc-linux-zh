
# 安装第三方库

查找 Python 第三方库和扩展权威资源是 Python 包索引（PyPI），它位于 `http://pypi.python.org`。安装第三方模块通常很简单，但对于某些依赖其他第三方模块的大型包，过程可能会变得相当复杂。对于更主要的扩展，你将找到一个平台原生安装程序，它会通过一系列对话框引导你完成过程。对于其他模块，你通常需要解压下载的内容，寻找 `setup.py` 文件，并输入 `python setup.py` 来安装软件。

默认情况下，第三方模块安装在 Python 标准库的 `site-packages` 目录。访问此目录需要 root 或管理员权限。如果不是，你可以输入 `python setup.py --user` 将模块安装在每个用户的库目录中。这会将包安装在用户级目录，例如 UNIX 上的 `"Users/beazly/.local/lib/python2.6/site-packages"`。

如果你想将软件安装在其他地方，使用 `setup.py` 的 `--prefix` 选项。例如，输入 `python setup.py --prefix=/home/beazly/packages` 将模块安装在 `/home/beazly/packages` 目录下。在非标准位置安装时，你可能需要调整 Python 中 `sys.path` 的设置以定位新安装的模块。

请注意，许多 Python 扩展涉及 C 或 C++。如果你安装了 C++ 编译器，就可以运行安装程序。在 UNIX、Linux 和 OS X 上，这并不是问题。在 Windows 上，传统上需要安装一个版本的 Microsoft Visual Studio。如果你在该平台上工作，最好寻找你扩展的预编译版本。

如果你已经安装了 `setuptools`，可以使用名为 `easy_install` 的脚本来安装包。只需输入 `easy_install pkgname` 即可安装特定包。如果配置正确，它将从 PyPI 下载相应的软件以及任何依赖项，并为你安装。当然，你的实际使用情况可能会有所不同。

如果你想将自己的软件添加到 PyPI，只需输入 `python setup.py register`。这会将关于你软件最新版本的元数据上传到索引中（注意，你必须先注册用户名和密码）。

# 输入与输出

本章描述了 Python 输入和输出（I/O）的基础知识，包括命令行选项、环境变量、文件 I/O、Unicode 以及如何序列化 `pickle` 模块。

## 读取命令行选项

当 Python 启动时，命令行选项被放在 `sys.argv` 列表中。第一个元素是程序的名称。随后的项目是程序名后命令行上显示的选项。下面的程序显示了手动处理简单命令行参数的基础原型：

```python
import sys

if len(sys.argv) != 3:
    sys.stderr.write("Usage %s inputfile\n" % sys.argv[0])
    raise SystemExit(1)

inputfile = sys.argv[1]
outputfile = sys.argv[2]
```

在这个程序中，`sys.argv[0]` 包含执行的脚本名称。向 `sys.stderr` 写入错误信息并带有非零退出码抛出 `SystemExit` 是命令行工具中报告用用法的标准做法。

虽然你可以手动处理简单脚本的命令行选项，但对于复杂的命令行处理，请使用 `optparse` 模块。这是一个简单的示例：

```python
import optparse

parser = optparse.Parser()
# 带有接收参数的选项
parser.add_argument("--input")
# 必需参数
parser.add_argument("-o", "--output")
# 布尔标记
parser.add_argument("-d", "--debug", action="store_true")
```

在示例中，添加了两种类型的选项。第一个选项 `-o` 或 `--output` 有一个必需参数。第二个选项 `-d` 或 `--debug` 通过在 `add_argument()` 调用中指定 `action='store'` 来选择行为。`p.set_defaults()` 方法为多个选项设置默认值。如果没有选择默认值，默认是 `None`。使用 `p.parse_args()` 方法解析返回一个元组 `(opts, args)`，其中 `opts` 是包含解析值的对象，`args` 是命令行项列表。使用 `opts.dest` 获取选项值，`dest` 是目标名称。`optparse` 模块自动提供 `-h` 或 `--help` 选项，列出用户请求的选项。错误的选项会导致错误。程序识别所有命令行样式：

```bash
# python prog.py -o infile ...
# python prog.py --output=outfile ...
# python prog.py -h
```

## 环境变量

在字典 `os.environ` 中访问环境变量。这是一个示例：

```python
import os
path = os.environ["PATH"]
user = os.environ["USER"]
editor = os.environ["EDITOR"]
```

为了修改环境变量，设置 `os.environ` 变量。例如：`os.environ["FOO"] = "BAR"` 对 `os.environ` 的修改会影响运行的程序和 Python 创建的子进程。

## 文件与文件对象

内置函数 `open(name, mode [,bufsize]])` 打开并创建一个文件对象，如下所示：

```python
f = open("foo") # 读取
f = open("foo", "r") # 读取（与上面相同）
f = open("foo", "w") # 写入
```
