
注意前面的列表中，`[`、`]` 和 `$` 字符通过添加反斜字符进行了转义，以消除它们的特殊功能。如果没有这些字符，当你尝试加载或显示数组元素时，可能会出现错误和奇怪的行为。你将在脚本看到看到应用。此外记住，如果你将列表包含在双引号或单引号中，它被视为单个数组元素，而不是独立的数组元素。

### 逐个加载数组 "KEYS"

加载 `KEYS` 数组的第二种方案是使用 `while read` 循环，并使用文件作为循环的输入。在示例中，我们使用计数器作为 `KEYS` 数组的索引，逐个加载数组元素。

```
X=0

while read ARRAY_ELEMENT

do

  (X = X + 1)

  KEYS[$X]=$ARRAY_ELEMENT

done < $ARRAY_ELEMENT_FILE
```

## 第 10 章

第一种加载选项使用 `set -A` 命令，它要求将键盘布局硬编码到 shell 脚本中，这会消除你在限制或扩展密码内容时所希望的大部分灵活性。通过使用 `while` 循环，我们可以使用外部文件并加载包含我们任何喜欢的字符的文件，并且可以根据需要为密码定义尽可能多或尽可能少的字符。我们还可以根据意愿重复字符并更改字符的顺序。

随着每次 `while` 循环迭代计数器的递增，我们按顺序加载数组元素，从数组元素 1，`KEYS[1]` 开始。当我们到达文件末尾时，通过计数器的值 `$X`，我们就知道我们已经在数组中加载了多少个元素。要查看数组元素 22 的具体值，可以使用以下语法：

```

```

从响应可以看出，加载的第 22 个数组元素是分号 (`;`)。我们也可以使用以下两种方式之一显示数组元素的数量：

```
# echo $(KEYS[*])

# echo $(KEYS[@])
```

注意，我们是从数组元素 1 开始的，Korn shell 支持数组元素 0，但我们用 1 而不是 0 来创建伪随机数。在编写脚本时，我们将更深入地查看数组。

### in_range_number_number 函数描述

内核提供了一个环境变量——你猜得没错——`RANDOM`。这个伪随机数生成器使用种子作为起点来创建序列中未来的所有数字。初始种子被用于创建一个伪随机数。该生成的数字将用作下一个种子，以创建下一个随机数，依此类推。正如你预期的那样，如果你每次都从相同的种子开始生成随机数，你每次都会得到完全相同的数字序列。为了改变可重复性，我们需要一种机制，在每次开始生成数字时更改初始种子。我喜欢使用 shell 脚本的当前进程 ID (`PID`)，因为这个数字变化很大，是每次开始生成数字时更改种子值的一种简单方法。

我们想要限制数字范围，使其不超过用户定义的最大值。一个例子是在 1 和最大值之间创建彩票号码，最大值可能是 36。我们将使用取模运算符将所有数字减少到一组固定数字 `[0-N]`，这就是对 N 取模算术。我们将使用这个伪随机数来索引 `KEYS` 数组中的数组元素。

对于我们的数字范围，我们需要一个脚本定义的最大值，将其赋值给变量 `UPPER_LIMIT`。当 `KEYS` 数组加载时定义 `UPPER_LIMIT` 变量，因为它代表了 `KEYS` 数组中包含的元素总数。取模运算符是百分号 (`%`)，我们使用的方法与你在除法中使用斜杠 (`/`) 的。我们仍然使用 `RANDOM` shell 获取一个新的伪随机数。但这次，我们将使用以下方程限制数字不超过最大值。

```
RANDOM_NUMBER=$((RANDOM % UPPER_LIMIT + 1))
```

注意我们在结果上加了 1。使用前面的方程将产生一个 1 到脚本定义的 `$UPPER_LIMIT` 之间的伪随机数，它是 `KEYS` 数组中的元素总数。使用该方程的函数是 `in_range_random_number`，显示在 10.1 中。
