
# Shell 循环基础

循环是 Shell 脚本的基础部分。它们允许一组命令重复执行多次，直到满足指定的条件。Shell 循环有几种类型，但最常用的是 `for` 循环和 `while` 循环。

## `for` 循环

Shell 中的 `for` 循环是一种用于多次多次执行一组语句的循环控制结构。它允许你遍历项序列（如数字、字符串或文件），并为序列中的每个项执行一系列语句。

### 通用语法

```
for VARIABLE in SEQUENCE
do
COMMAND1
COMMAND2
...
done
```

`VARIABLE` 是一个迭代变量，在每次循环中它取 `SEQUENCE` 中每个元素的值。

`SEQUENCE` 可以是一个由空格分隔的值列表、数字范围或包含数据的文件。

`COMMAND1`、`COMMAND2` 等是在循环的每次迭代中将执行的命令。

### 示例 1

```
for i in 1 2 3 4 5
do
echo "iteration $i"
done
```

此脚本使用 Shell `for` 循环来遍历从 1 到 5 的数字列表。对于每次迭代，都使用 `echo` 命令显示 `i` 的当前值以及消息 "iteration $i"。

循环按照以下步骤执行：

- 将变量 `i` 初始化为列表中的第一个值，即 1。
- 检查循环条件，如果为真，则执行循环体。在这种情况下，将显示消息 "iteration 1"。
- 将 `i` 的值更新为列表中的下一个值，即 2。
- 再次检查循环条件，如果为真，则执行循环体。在这种情况下，将显示消息 "iteration 2"。
- 重复此步骤，直到列表中的所有值都被处理，循环停止。

因此，最终结果将显示：

- iteration 1
- iteration 2
- iteration 3
- iteration 4
- iteration 5

在以下用中，`for` 循环遍历 `/home/user/documents` 目录下的所有文件，并每次显示正在处理的文件名。你还可以添加其他命令来对每个文件执行操作，例如压缩、复制、删除等。

```
for file in $(ls /home/user/documents)
do
echo "Processing file $file"
# 其他处理文件的命令
done
```

请注意，你必须将表达式 `$(ls /home/user/documents)` 括在引号中，以确保带有空格的文件名在循环时不会被拆分成多个项。

### 示例 2：使用算术 `for`

`for` 循环遍历从 0 到 10 的数字序列。在循环的每一轮，`if` 条件使用 `%` 取模运算检查当前数字是偶数还是奇数，并显示相应的消息。

```
for (( i=0; i<=10; i++ ))
do
if [ $((i%2)) -eq 0 ]
then
echo "$i is an even number"
else
echo "$i is an odd number"
fi
```

语法 `(( i=0; i<=10; i++ ))` 用于为循环定义迭代序列。`i=0` 定义了变量 `i` 的初始值，`i<=10` 定义了循环的退出条件，`i++` 在循环的每次迭代中增加 `i` 的值。

此示例展示了如何通过结合条件和运算符使用 `for` 循环来完成更复杂的任务。

```
files=(/home/user/documents/*)
for (( i=0; i<${#files[@]}; i++ ))
do
file=${files[i]}
if [ -f $file ]
then
echo "Processing file $file"
# 其他处理文件的命令
elif [ -d $file ]
then
echo "Processing directory $file"
# 其他处理目录的命令
fi
done
```

在这种情况下，`for` 循环遍历一个文件和目录列表，这些列表存储在使用语法 `files=(/home/user/documents/*)` 创建的数组 `files` 中。在循环的每一轮中，`if` 条件使用 `-f` 或 `-d` 命令检查当前元素是文件还是目录，并执行执行相应的操作。

语法 `${files[i]}` 用于在循环的每次迭代中访问数组 `files` 的第 i 个元素，而 `${#files[@]}` 返回数组中的元素数量。

此示例展示了如何使用 `for` 循环遍历文件和目录列表，并根据它们的类型执行不同的操作。

## `while` 循环

Shell `while` 循环只要满足指定的条件就会重复执行命令序列。`while` 循环的基本语法如下：

```
while condition
do
commands
done
```

只要条件为真，`do` 和 `done` 之间的命令就会执行。

### 简单示例

```
number=1
while [ $number -le 10 ]
do
echo $number
number=$((number + 1))
done
```

此脚本将显示从 1 到 10 的数字。

注意的是，条件必须写在方括号 `[ ]` 中才能被正确解释为 Shell 命令。

还可以使用 `break` 和 `continue` 语句控制循环。`break` 立即退出循环，而 `continue` 则移动到下一个序列。

### 使用 `break` 和 `continue`

```
number=1
while [ $number -le 10 ]
do
if [ $number -eq 5 ]
then
break
fi
if [ $number -eq 3 ]
then
number=$((number + 1))
continue
fi
echo $number
number=$((number + 1))
done
```

变量 `number` 初始化为 1。

验证条件 `[ $number -le 10 ]`。只要该条件为真，就会执行循环。

在循环中，检查条件 `[ $number -eq 5 ]`。如果为真，则执行 `break` 退出循环。

检查 `[ $number -eq 3 ]`。如果为真，则将 `number` 增加 1 并执行 `continue`，跳到循环的下一次迭代。

显示 `$number`。

`number` 值增加 1。

循环重复，直到 `[ $number -le 10 ]` 不再为真。

循环结束后，将显示以下数字：1 2 4。

善用 `break` 和 `continue` 语句对于避免脚本出现无限循环或意外行为很重要。总之，`for` 和 `while` 循环是自动化重复任务的强大工具。充分理解它们及其语法对于在脚本中有效使用它们很重要。

### 练习 1

练习：使用 `for` 循环编写一个显示从 1 到 10 数字的 Shell 脚本。

```
#!/bin/bash
for i in {1..10}
do
echo $i
done
```

此脚本使用 `for i in {1..10}` 语法定义从 1 到 10 的数字序列。在每次循环中，使用 `echo` 命令显示 `i` 的当前值。

要运行此脚本，请将其保存为扩展名为 `.sh` 的文件，使用命令 `chmod +x file_name.sh` 赋予执行权限，然后运行 `./file_name.sh`。脚本将显示从 1 到 10。

### 练习 2

练习：编写一个 Shell 脚本，接收用户名作为输入，并使用 `for` 循环显示用户主目录下的所有目录。

解决方案：

```bash
#!/bin/bash
read -p "Enter a username: " username
for directory in /home/$username/*
do
if [ -d $directory ]
then
echo $directory
fi
done
```

此脚本使用 `read` 命令读取用户名，然后使用该用户名创建用户主目录的路径。`for` 循环遍历主目录下的所有项，`if` 条件使用 `-d` 命令检查每个项是否为目录。如果是目录，则使用 `echo` 命令显示。

要运行此脚本，请将其保存为扩展名为 `.sh` 的文件，使用命令 `chmod +x file_name.sh` 赋予执行权限，然后运行 `./file_name.sh`。脚本将显示输入用户主目录下的所有目录。

# 正则表达式

正则表达式，也称为 "regex" 或 "regexp"，是一组描述文本模式的字符集。正则表达式用于许多应用程序，包括文本编辑器、编程语言、搜索工具、文字处理工具和数据验证工具。

正则表达式是执行文本搜索和替换操作的强大工具。通过使用正则表达式，你可以使用模式、特殊字符和量符搜索复杂的字符字符串。

以下是正则表达式中使用一些常用的特殊字符：

- `.` : 匹配任意字符。例如，正则表达式 `ct` 将匹配 "cat"、cot"、cut" 等。
- `^` : 匹配字符字符串的开头。例如，正则表达式 `^cat` 将匹配 "cat and dog" 中的 "cat"，但不会匹配 "I love cats" 中的 "cat"。
- `$` : 匹配字符字符串的结尾。例如，正则表达式 `dog$` 将匹配 "cat and dog" 中的 "dog"，但不会匹配 "I love dogs" 中的 "dog"。
- `[]` : 匹配一个字符集。例如，正则表达式 `[aeiou]` 将匹配任何元音，而 `[AZ]` 将匹配任何大写字母。
- `[^]` : 匹配不在字符集中的任何字符。例如，正则表达式 `[^aeiou]` 将匹配任何辅音，而 `[^0-9]` 将匹配任何非数字字符。
- `*` : 匹配前一个字符的零次或多次。例如，正则表达式 `ca*t` 将匹配 "ct"、"cat"、"caat"、"caa" 等。
- `+` : 匹配前一个字符的一次或多次。例如，正则表达式 `ca+t` 将匹配 "cat"、"caat"、"caat" 等，但不会匹配 "ct"。
- `?` : 匹配前一个字符的零次或一次。例如，正则表达式 `ca?t` 将匹配 "ct" 或 "cat"。
- `()` : 用于分组正则表达式。例如，正则表达式 `(cat|dog)` 将匹配 "cat" 或 "dog"。
- `|` : 匹配任一正则表达式。例如，正则表达式 `cat|dog` 将匹配 "cat" 或 "dog"。
- `\` : 用于转义特殊字符。例如，`\.` 将匹配字面上的句号 (.)，而不是任意字符。
- `\d` : 匹配数字。例如，`\d+` 将匹配一个或多个数字。
- `\D` : 匹配非数字的任何字符。例如，`\D+` 将匹配一个或多个非数字字符。
- `\s` : 匹配空白字符（空格、制表符等）。例如，`\s+` 将匹配一个或多个空白字符。
- `\S` : 匹配非空白的任何字符。例如，`\S+` 将匹配一个或多个非空白字符。
- `\w` : 匹配字母或数字字符。例如，`\w+` 将匹配一个或多个字母数字字符。
- `\W` : 匹配非字母数字的任何字符。例如，`\W+` 将匹配一个或多个非字母数字字符。

### `grep` 示例

- 查找文件中按顺序包含字母 "a"、b" 和 "c" 的所有行，中间由任意字符分隔。

```
grep 'abc' file.txt
```

此命令将搜索 file.txt 中所有按顺序包含字母 "a"、b" 和 "c" 且由任意字符分隔的行。

- `^`: 查找文件中所有以字母 "a" 开头后跟着一个小写字母的行。

```
grep '^a[az]' file.txt
```

此命令将搜索 file.txt 中所有以字母 "a" 开头后跟着一个小写字母的行。

- `$`: 查找文件中所有以字母 "e" 结尾后跟着一个大写字母的行。

```
grep '[AZ]e$' file.txt
```

此命令将搜索 file.txt 中所有以字母 "e" 结尾后跟着一个大写字母的行。

- `*` : 查找文件中包含字符字符串 "cat" 或 "cats" 的所有行。

```
grep 'cats*' file.txt
```

此命令将搜索 file.txt 中包含字符串 "cat" 或 "cats" 的行。

- `[]`: 查找文件中包含字符串 "dog" 的所有行。

```
grep 'dog' file.txt
```

此命令将搜索 file.txt 中包含字符串 "dog" "行" 的行。

- `|` : 查找文件中包含字符串 "apple" 或 "orange" 的所有行。

```
grep 'apple|orange' file.txt
```

此命令将搜索 file.txt 中包含字符串 "apple" 或 "orange" 的行。

- `()` : 用于分组正则表达式。例如，正则表达式 `(cat|dog)` 将匹配 "cat" 或 "dog"。

```
grep '(cat|dog)' file.txt
```

此命令将搜索 file.txt 中匹配 "cat" 或 "dog" 的行。

# 文件排序与重定向

```bash
sort list_of_files.txt
```

`sort` 命令对 `list_of_files.txt` 文件的行进行排序。重定向标准输入（`<`）告诉 `sort` 命令从该文件读取输入，而不是从键盘。

重定向错误输出允许将命令的错误输出定向到文件而不是显示在屏幕上。要执行此操作，你必须使用 `2>` 运算符，后跟要保存错误输出的文件名。

这是一个示例：

```bash
ls /foo/bar 2> errors.txt
```

`ls` 命令尝试显示 /foo/bar 目录下的文件列表，但该目录并不。重定向错误输出（`2>`）将此命令生成的错误输出发送到名为 `errors.txt` 的文件中，而不是显示在屏幕上。

可以使用 `|`、`>`、`<` 和 `2>` 组合多个重定向。

这是一个示例：

```bash
grep "pattern" < file.txt | sort > result.txt 2> errors.txt
```

`grep` 命令从 `file.txt` 读取输入，搜索包含指定模式的行，并将输出发送给 `sort` 命令。`sort` 命令的输出保存到名为 `result.txt` 的文件中，而错误输出保存到名为 `errors.txt` 的文件中。

# 邮件发送

从命令行发送电子邮件有多种方法，但最常用的之一是使用 `mail` 命令。

`mail` 命令允许你从命令行发送电子邮件。要使用此命令，你必须首先确保系统上安装了邮件客户端（例如 Sendmail）。

这是一个从命令行发送电子邮件的简单 mail 命令示例：

```bash
echo "This is the message body" | mail -s "This is the subject" recipient@example.com
```

在此示例中，使用 `echo` 命令来创建消息正文。然后使用 `mail` 命令将消息发送到指定的收件人邮箱地址，并通过 `-s` 选项指定主题。

然而，为了使此方法生效，你需要确保系统的邮件服务器已正确配置以发送电子邮件。如果你在使用此方法时遇到问题，可以使用另一种方法，即使用 `sendmail`。

`sendmail` 是一个使用现有的邮件服务器从命令行发送电子邮件的程序。要使用 `sendmail`，你必须创建一个包含消息信息的文件，包括邮件头、正文和收件者。

这是一个简单的 sendmail 命令示例：

```bash
(echo "To: recipient@example.com"; echo "Subject: This is the subject"; echo "This is the message body") | /usr/sbin/sendmail -t
```

在此示例中，消息信息存储在子 shell 中，然后通过 `-t` 选项发送给 `sendmail`。

注意，要使用 `sendmail`，你必须确保系统上安装了 `sendmail` 程序，并且你有有运行它的权限。

## 示例：监控目录并发送邮件

假设你有一个 shell 脚本，它可以监控某个目录并在向该目录添加文件时发送电子邮件。这是一个使用 `sendmail` 发送电子邮件的 shell 脚本示例：

```bash
#!/bin/sh
WATCH_DIR="path/to/directory"

while true; do
  file_count=$(ls $WATCH_DIR | wc -l)
  if [ $file_count -gt 0 ]; then
    mailbody="There are $file_count new files in the $WATCH_DIR directory."
    echo $mailbody | /usr/sbin/sendmail -t <<EOF
To: recipient@example.com
Subject: Notification: New files added in $WATCH_DIR directory

$mailbody
EOF
  fi
  sleep 60
done
```

在此示例中，脚本使用 `while true` 循环持续监控 `WATCH_DIR` 变量中指定的目录。`file_count` 变量存储目录中的文件数量，如果该数字大于零，脚本将使用 `sendmail` 发送电子邮件。

邮件正文存储在 `mailbody` 变量中，并使用 `echo` 命令显示消息正文。然后使用 `sendmail` 命令将消息发送到邮件头中指定的邮箱地址。

注意，`sendmail` 命令配合 `-t` 选项使用，指定邮件头和收件人。消息头和正文随后通过命令输入块（这里使用 `<`）提供。

最后，脚本使用 `sleep` 命令在再次开始循环之前暂停 60 秒。

# 日期命令

该命令显示当前的系统日期和时间。它也可以用于设置系统日期和时间。

以下是最常用的 date 选项：

- `%d`: 日（01 到 31）
- `%m`: 月份（01 到 12）
- `%y`: 两位数的年份（例如，2021 年为 21）
- `%Y`: 四位数的年份
- `%H`: 24 小时制的小时（00 到 23）
- `%M`: 分（00 到 59）
- `%S`: 秒（00 到 59）

要显示当前的系统日期和时间，只需输入不带选项的 `date` 命令：

```bash
date
```
