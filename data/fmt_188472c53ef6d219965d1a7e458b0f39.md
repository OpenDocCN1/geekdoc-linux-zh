确保您在正确的语境中使用 Informix 命令；也就是说，您首先以 KB 为单位进行思考，而不是 MB。您可以以 MB 来思考，但仅限于将 KB 转换为 MB。底线原则是，这些命令指的是 KB 而不是 MB。

## Logdsbs

现在，让我们创建一个 `logdsbs` 作为我们逻辑日志的家，目前这些日志驻留在 `rootdbs` 中。请确保您的引擎处于静止模式（`quiescent mode`），然后按照以下步骤创建 `logdsbs`。

我们将创建 20 个新的逻辑日志，每个 1MB，因此我们需要至少一个 26MB 的逻辑数据库空间（logical dbspace），如果不够的话，将其做得大一点也是个好主意，这样你就可以根据需要添加更多。我们的第一个 `logdsbs` 将是 50MB，以便为后续增长留出空间。
在 `rootdbs` 中有 6 个逻辑日志，而我们想要 26 个，因此我们将创建 20 个新的。

首先，我们想要创建 `logdsbs`：

```
rebel:root # onspaces -c -d logdsbs -p /opt/data/logdsbs -o 0 -s 50000

Verifying physical disk space, please wait ...
```

现在 `logdsbs` dbspace 已经存在，你可以将逻辑日志从 `rootdbs` 移到 `logdsbs`。为了我们的安装目的，我们将为 26 个创建新的逻辑日志。当安装启动时，它创建了 6 个逻辑日志，因此我们将添加 20 个逻辑日志，总计为 26 个。为什么呢？添加 20 个日志是一个非常好的练习，能让你对引擎的工作原理有一个良好的理解。拥有许多小的逻辑日志是一个好主意；相关指南已在《管理员指南》（Administrator’s Guide）中介绍。

要把日志移出 `rootdb`，你必须已经有了可供引擎使用的新日志，它们将取代现有的逻辑日志。逻辑日志的最少数量为 3 个，因此为了实现这一点，我们必须告诉引擎哪些日志是有效的，哪些可以删除。我们还不能删除或移除任何正在使用的逻辑日志，因此我们需要告诉引擎使用新日志，以便可以移除旧日志。

### Create logdsbs

确保您已经在本节开头讨论过的 `onspaces` 命令创建了新的 `logdsbs` dbspace，然后继续。运行 `onmode -sy` 命令确保引擎处于单用户模式：

```
rebel:root # onmode -sy
```

执行一次 0 级备份以清理任何待处理的日志条目。

```
rebel:root # ontape -s -L 0

Archive to tape device '/dev/null' is complete.
```

程序结束。

## New Logical Logs

多次运行 `onparams` 命令来创建逻辑日志：

```
rebel:root # onparams -a -d logs -s 1024

Logical log successfully added.

rebel:root # onstat -1
```
