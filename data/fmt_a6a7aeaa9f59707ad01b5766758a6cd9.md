## units — 将标准比例表示的数量转换为其他单位

### 概要

```
/usr/bin/units
```

### 描述

`units` 将以各种标准比例表示的数量转换为其他比例的等值。它以以下交互方式工作：输入 `units` 启动命令。显示 `you have:` 提示。输入第一个标准比例并按回车。显示 `you want:` 提示。输入第二个标准比例并按回车。结果将如下例所示。

```
castle$ units

you have: inch

you want: cm

* 2.5400000e+00

/ 3.937008e-01

you have: 15 lbs force/in2

you want: atm

* 1.0206896e+00

/ 0.9792299e-01

you have: 3 teaspoon

you want: tablespoon

* 1.0000000e+00

/ 1.0000000e+00
```

```
you have: 45 liters

you want: gallons

  * 1.188774e+01

  / 8.412026e-02

you have: 12 gallons

you want: liters

  * 4.542494e+01

  / 2.201434e-02
```

## unix2dos — 将文本从 ISO  DOS

### 概要

```
/usr/bin/unix2dos [-ascii] [-iso] [-7] originalfile
```

### 描述

`unix2dos` 将 ISO 标准字符转换为 DOS 扩展集中对应的字符。你可以从 DOS 或 SunOS 调用此命令。然而，文件名必须符合。

### 选项

- `-ascii` 返回原始文件。
- `-iso` 将 ISO 标准字符转换为 DOS。
- `-7` 将 8 位 SunOS 字符。
