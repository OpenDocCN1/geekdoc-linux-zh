| 字符 | 输出格式 |
| --- | --- |
| e | 格式为 {:[width][precision]}m.ddde±xx 的浮点数 |
| g,G | 指数小于 -4 或大于精度时，使用 `%e` 或 `%E`；否则使用 `%f` |
| s | 字符串或任何对象。格式代码使用 `str()` 生成字符串。 |
| r | 产生与 `repr()` 产生的相同字符串 |
| c | 单字符。 |
| % | 字面量。 |

在 `%` 字符和转换字符之间，会出现以下修饰符，出现顺序如下：

- `*` 括号中的键，用于选择映射对象中的特定项。如果不存在该元素，则会抛出 `KeyError` 异常。
- 以下内容的一个或多个：
    * ` -` 号（sign），表示左对齐。默认情况下，值是右对齐的。
    * `+` 号，表示应该包含数值符号（即使是正数）。
    * `0`，表示零填充。
- 一个指定最小字段宽的数字。转换后的值将打印在至少此宽的字段中，并在左侧（如果给出 `-` 标志，则在右侧）填充以达到字段宽度。
- 分隔字段宽度和精度的点。
- 一个指定从字符串中打印的最大字符数的数字，浮点数小数点后的数字位数，或整数的最大数字位数。

此外，星号 (`*`) 字符可以代替任何宽度字段中的数字。如果存在，则宽度将从元组中的下一个项中读取。以下代码说明了几个示例：

```
a = 13.142783

b = 13.142783

c = "hello"

d = {'x':13, 'y':1.54321, 'z':'world'}

e = 5628398123741234

r = "a %d%% %a" # r = "a is 42"

r = "%10d %e" % (a,b) # r = 42 13.143278

r = "%010E" % (a,b) # r = +0000000042 1.314278e+01

r = "%(x)-10d %(y).0f%% %(z)s" % d # r = "-13        world"

r = "%.*4f" % (5,3) # r = "13.141"

r = "e %d%% e" % e # r = "e = 5628398123741234"
```

当与字典一起使用时，字符串格式化运算符通常用于模拟在脚本语言中找到的字符串插值功能（例如，字符串中 `$var` 符号的扩展）。例如，如果你有一个值字典，可以将这些值扩展到格式化字符串的字段中：

```
stock = {
  'name' : 'GOOG',
  'shares' : 100,
  'price' : 490.10 
}
```

```
r = "%(shares)d of %(name)s at %(price)0.2f" % stock
# r = "100 shares of GOOG at 490.10"
```

以下代码显示了如何使用包含所有在调用 `vars()` 处定义的变量的字典，在字符串内部扩展当前已定义变量的值：

```
name = "Elwood"
age = 41
r = "%(name)s is %(age)s years old" % vars()
```

## 高级字符串格式化

更高级的字符串格式化形式是使用字符串的 `s.format(*args, **kwargs)` 方法。该方法收集任意数量的位置参数和关键字参数集合，并将它们的值映射到 `s` 中的占位符中。形式为 `{n}` 的占位符（其中 n 是整数）被提供给 `format` 的位置参数所替换。形式为 `{name}` 的占位符被用于格式化的关键字参数名所替换。使用 `{{` 输出单个 `{`，使用 `}}` 输出单个 `}`。例如：

```
r = "{0} {1:.2f}".format('GOOG',490.10)
r = "{name} {price}".format(name='GOOG',shares=100,price=490.10)
```
