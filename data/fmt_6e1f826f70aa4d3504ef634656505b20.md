## 监听小部件

由于存在许多数据类型，从小部件中检索参数值比设置值要困难。为了检索值，你需要传入参数值的名称和一个 `GtkArg` 结构体。如果找到的名称存在且其值可读，该值将存储在 `GtkArg` 结构体中。为了实现这一点，`GtkArg` 结构体必须被设计为接受所有可能的数据类型。该结构体中只有三个组成部分：一个指定数据类型的 `GtkType` 字段、一个指向指定参数名称的字符串的指针，以及一个包含各种数据类型的联合体（union）：

```c
typedef struct _GtkArg GtkArg;

struct _GtkArg {
GtkType type;
gchar *name;
union {
gchar char_data;
guchar uchar_data;
gboolean bool_data;
gint int_data;
guint uint_data;
glong long_data;
gulong ulong_data;
gfloat float_data;
gdouble double_data;
gchar *string_data;
gpointer pointer_data;
GtkObject *object_data;
struct {
GtkSignalFunc f;
gpointer d;
} signal_data;
struct {
gint n_args;
GtkArg *args;
} args_data;
struct {
GtkCallbackMarshal marshal;
gpointer data;
GtkDestroyNotify notify;
} callback_data;
struct {
GtkFunction func;
gpointer func_data;
} c_callback_data;
struct {
gpointer data;
GtkDestroyNotify notify;
} foreign_data;
} d;
};
```
