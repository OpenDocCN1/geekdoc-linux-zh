
# File: `/etc/logrotate.conf`
# Description: sample logrotate configuration file
# Global options can be overridden by local options
`weekly`
`rotate 4`
`errors root@some.host`
`compress`
`create`
# Also read configuration directives in logrotate.d directory,
# where rotation instructions for individual applications
# are specified

`include /etc/logrotate.d`
`/var/log/messages` {
`rotate 5`
`weekly`
`nocompress`
`postrotate`
        `/sbin/killall -HUP syslogd`
`endscript`
}
`/var/log/httpd/access.log` {
`rotate 5`
`mail webmaster@some.host`
`errors webmaster@some.host`
`size=100k`
`postrotate`
        `/sbin/killall -HUP httpd`
`endscript`
}
`/var/log/wtmp` {
`monthly`
`create 0664 root utmp`
`rotate 1`
}
`/var/log/lastlog` {
`monthly`
`rotate 1`
}

> **注意**
>
> 以井号（`#`）开头的行是注释行，`logrotate` 程序会忽略这些行。

> **注意**
>
> 以下文件中添加了行号，仅供参考，并非文件的实际内容。

第4至8行设置了全局选项。`weekly` 指令将默认的日志轮转间隔设置为每周一次。`rotate 4` 指令指定保留4个历史文件。`errors` 指令指定将日志处理过程中产生的错误发送给谁。在此示例中，所有错误输出都发送给 `root@some.host`，除非被局部选项覆盖。`compress` 指令指定历史日志在轮转后应进行压缩。

第12行的 `include` 指令指定可能需要从 `/etc/logrotate.d` 目录读取额外的日志轮转配置文件。在某个特定的 Linux 系统上，该目录的内容显示如下：

```text
# ls /etc/logrotate.d

apache  ftpd      mars-nwe.log  samba    slrnpull  syslog

cron    linuxconf mgetty        sendfax  squid     uucp
```
