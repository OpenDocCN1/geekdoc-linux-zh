
`node (head) -> node -> node -> node -> NULL`

链表的用在于它可以包含未知数量的节点。这与在定义或分配数组时确定有限数量元素的数组形成对比。

在使用链表结构时，细致地维护头（或列表开头）是非常重要的。如果丢失对列表开头的任何引用，整个列表也将丢失。如此之前的链表所示，`NULL`指针标记了列表中的节点。
