## 18.2.2 传真操作

发送传真需要进一步的说明。命令行工具 `capuitefax` 可发送传真。它接受一个或多个目标号码和一个或多个 PostScript 格式的文档。

它支持如下参数：

- `-h` 或 `-help`：返回有效参数的简要摘要。
- `-d <number>` 或 `-dialstring=<number>`：此参数声明应发送传真的的目标号码。
- `-q` 或 `-quiet`：`capuitefax` 通常会生成一些信息消息。此选项将抑制这些消息并仅显示错误消息。

以下命令会将 `document1.ps` 和 `document2.ps` 发送到目标号码 089123456：

```
capuitefax -d 089123456 document1.ps document2.ps
```

在标准的 KDE 桌面，可以通过 KDEPrintFax 工具从任何应用程序轻松发送传真。按照以下方式配置 KDEPrintFax：

- 启动 KDEPrintFax。可以通过按 `Alt+F2` 并输入 `kdeprintfax` 来。
- 选择`Settings` ->`Configure KDEPrintFax`。
- 点击左面板中的`System`图标。
- 由于 `capuitefax` 与 HylaFAX 件兼容，在`Fax system`下选择 HylaFAX。
- 将`Command`设置为 `/usr/bin/capuitefax -d %number %files`。
- 点击`OK`并关闭 KDEPrintFax 完成配置。

在任何 KDE 应用程序的`打印`菜单中都可以看到“发送传真”。选择它将启动 KDEPrintFax，请求目标电话号码并发送传真。

如果打印命令可以手动设置，非 KDE 应用程序也可以使用此功能。在这种情况下，将 `lpr` 替换为 `kprinter`。当打印文档时，将显示 KDE 打印菜单，并带有传输传真消息的可能性。
