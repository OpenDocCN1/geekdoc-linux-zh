
# 重定向与管道

使用重定向时要小心，重定向指定了标准输出的目标。标准输出被保存并存储在那个目标文件中。一旦保存，就没有输出可以管道到另一个命令。虽然重定向可以发生在一系列管道操作的末尾，但它不能发生在管道操作内部。下一个示例是`sort`命令被管道到带有`-n`的`cat`命令以显示行号。

```
$ sort -n | cat -n
```

## 背景：&

你通过在命令行的末尾添加一个安符（`&`）来在后台执行命令。当你这样做时，系统会显示一个用户作业号和一个系统进程号。放在括号中的用户作业号是用户引用该作业的数字。系统进程号是系统识别该作业的数字。在下一个示例中，打印文件`mydata`的命令被放置在后台执行。

```
$ lpr mydata &
[1] 534
$ $
```

## && 和 ||

```
command && command
command || command
```

逻辑命令对两个 Linux 命令执行逻辑操作。对于逻辑“与”（`&&`），如果两个命令都执行成功，则逻辑命令执行成功并返回退出状态`0`。对于逻辑“或”（`||`），如果任一命令执行成功，则逻辑或执行成功并返回退出状态`0`。逻辑命令允许你在控制结构中使用逻辑操作作为测试命令。

## 函数：(){}

```
function-name () {commands;}
```

你可以定义一个由放置在一对括号之间的多个命令组成的函数。函数通过函数名后的对括号来指定。每当函数名被指定为简单命令名时，该列表就会执行。函数的退出状态是函数内部执行的最后一个命令的退出状态。

# 24 BASH 命令

以下是每个 BASH 内置命令的描述。命令按字母顺序列出。大多数情况下，每个描述都以命令的语法开头。

## 冒号 (:)

```
: [arguments]
```

冒号（`:`）允许你在同一行命令行上列出多个命令，每个命令用冒号隔开。退出码为零。

## source, .

```
. filename [arguments]
source filename [arguments]
```

点（`.`）或`source`从当前 shell 中读取并执行文件中的命令。它返回该文件中执行的最后一个命令的退出状态。如果文件名不包含完整路径，则将使用`PATH`中定义的路径来定位文件名所在的目录。

## CTRL-Z：中断

你可以使用`CTRL-Z`命令中断作业并停止它。该作业并未结束；它只是保持挂起状态，直到你想继续为止。当你准备好时，可以使用`fg`或`bg`命令在前台或后台继续该作业。`fg`命令将在前台重启被中断的作业。`bg`命令将把中断的作业放入后台。

有时，你需要将一个正在运行的作业放置在后台。然而，你不能直接将正在运行的作业移动到后台。你首先需要用`CTRL-Z`中断它，然后用`bg`命令将其放入后台。在下一个示例中，

## BASH 命令 25

列出并重定向`.c`文件的当前命令首先被`CTRL-Z`中断。然后该作业被放置在后台。

```
$ cat *.c > myprogs
^Z
$ bg
```

通常，在 Vi 编辑器中，你可能会误输入`CTRL-Z`而不是`SHIFT-ZZ`来结束会话。`CTRL-Z`会中断 Vi 编辑器并返回到 Linux 提示符。编辑会话并没有结束；只是被中断了。在你尝试注销之前，你可能无法发现这种错误。在存在被中断作业时，系统不允许你注销。要注销，你必须先用`fg`命令重启被中断的作业。在 Vi 编辑器中断的情况下，`fg`命令会将你带回 Vi 编辑器。然后通过`ZZ`命令结束 Vi 编辑器作业，此时你就可以注销了。在接的示例中，`jobs`命令显示有一个停止的作业。`fg`命令将作业带回前台。

```
$ jobs
[1] + Stopped vi mydata
$ fg %1
```

## alias

```
alias [alias-name=[value]] ...
```

单独使用`alias`命令会显示已定义的别名列表。要显示特定别名的值，你可以仅使用其名称作为参数。如果你提供了一个未定义为别名的名称，则命令返回假（`false`）；否则返回真（`true`）。你也可以使用`alias`命令来定义别名，提供用等号（`=`）分隔的名称和值。值后面末尾的空格会导致在展开别名时，检查下一个单词是否需要进行别名替换。

## at

使用`at`命令，你可以在指定的时间执行命令。与其立即将作业`own`后台，不如你可以指定你希望执行它的时间。然后你注销，系统将跟踪需要执行哪些命令以及何时执行它们。

### BASH 命令

`at`命令的参数是你希望执行命令的时间。该时间是一个指定小时的数字，后面跟有关键词`am`或`pm`。你还可以添加日期。如果未指定日期，则假设为今天。`at`命令将从标准输入读取 Linux 命令。你可以通过键盘输入这些命令，并用`CTRL-D`结束标准输入。你也可以将命令输入文件，然后通过标准输入重定向该文件。

## bg

```
bg [jobspec]
```

`bg`将作业放入后台。如果不存在`jobspec`，则使用 shell 对当前作业的概念。`bg`命令返回`0`，除非在禁用作业控制运行时，或在启用作业控制运行时未找到`jobspec`或启动。

## bind

```
bind [-m keymap] [-lvvd] [-q name]
bind [-m keymap] -f filename
bind [-m keymap] keyseq:function-name
```

`bind`命令显示当前的键和函数绑定，或将键序列绑定到`readline`函数宏。绑定语法与`inputrc`相同，但每个绑定必须作为单独参数传递（例如`"\C-x-\C-r": 重新配置文件`）。返回值为`0`，除非给出未识别的选项或发生错误。如果提供了选项，具有以下含义：

| 选项 | 描述 |
| :--- | :--- |
| `-m keymap` | 使用`keymap`作为受后续绑定影响的键`map`。接受的`keymap`名称有`emacs`, `emacs-standard`, `emacs-meta`, `emacs-ctlx`, `vi`, `vi-move`, `vi-command`和`vi-insert`。`vi`等于`vi-command`；`emacs`等于`emacs-standard`。 |
| `-l` | 列出所有`readline`函数名称。 |
