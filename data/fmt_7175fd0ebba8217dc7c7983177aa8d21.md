
（即在 `/bin` 和 `/usr/bin` 目录均出现了同名程序），我们将在管道中添加 `uniq`。

```
[me@linuxbox ~]$ ls /bin /usr/bin | sort | uniq | less
```

在这个示例中，我们使用 `uniq` 来移除 `sort` 命令输出中的任何重复项。如果我们想查看重复项的列表，则对 `uniq` 使用 `-d` 选项，如下所示：

```
[me@linuxbox ~]$ ls /bin /usr/bin | sort | uniq -d |
```

## tee: 从 stdin 到 stdout 和文件

延续管道的比喻，Linux 提供了一个名为 `tee` 的命令，在管道中间创建一个“分支”。`tee` 读取标准输入并将其复制到输出（允许数据继续向下传递）以及一个或多个文件。这是为了在处理中间阶段捕捉整个目录列表到 `ls.txt`。`grep` 过滤管道：

## 扩展 (Expansion)

每当你输入命令并按下回车键时，bash 在执行我们的命令之前会对文本进行多次替换。我们已经看到简单的字符序列（例如 `*`）对 Shell 有许多意义的例子。导致这种发生的过程被称为“扩展”。通过扩展，我们输入内容，它在 Shell 对其处理之前会被扩展为其他内容。为了演示我们的意思，让我们看看 `echo` 命令。`echo` 是一个执行简单任务的 Shell 内置命令。它将其文本参数打印到标准输出。

```
@me@linux ~]$ echo this is a test
this is a test
```
