
### Red Hat Package Manager（RPM）
大多数 Linux 系统使用的软件包管理系统。SUSE Linux 以 RPM 格式分发其安装包。

### 独立磁盘冗余阵列（RAID）
一系列用于在不同硬盘上存储数据以提高性能并提供容错的方法。

### 普通用户
可用于交互式登录系统的用户账户。

### Reiser
SUSE Linux 系统上使用的默认文件系统。

### `reject` 命令
防止打印作业进入打印队列的命令。

### 相对区别名称（RDN）
LDAP 中对象的简单名称。

### 相对路径
相对于树中当前目录的目标目录的名称。

### 远程过程调用（RPC）
在远程计算机上执行的例程。

### `renice` 命令
用于更改正在运行进程优先级的命令。

### 存储库
安装服务器上包含软件的目录。

### Rivest Shamir Adleman（RSA）
一种常见的非对称加密算法。

### `rlogin` 命令
用于在远程计算机上获取 shell 的命令。

### `rm`（remove）命令
用于删除文件和目录的命令。

### `rmdir`（remove directory）命令
用于删除空目录的命令。

### 路由器
用于将 IP 数据包从一个 IP 网络中继到另一个 IP 网络的设备。

### 路由
将 IP 数据包从一个 IP 网络发送到另一个 IP 网络的过程。也称为 IP 转发。

### 路由表
存储在每个主机上的表，其中包含本地和远程网络以及路由器的列表。

### `rpcinfo` 命令
显示 RPC 端口及其关联服务的命令。

### `rpm` 命令
用于安装、删除 RPM 软件包以及查找 RPM 软件包信息的命令。

### `rsh` 命令
用于在远程计算机上获取 shell 或运行程序的命令。

### `rug` 命令
用于管理 SUSE Linux 中的软件更新服务的命令。

### 运行级别
取决于当前正在运行的进程数量和类型的 Linux 系统状态。

### `runlevel` 命令
用于显示当前和最近运行级别的命令。

### 运行级别编辑器
YaST 模块，可用于配置在每个运行级别启动的守护进程。

### sabayon
桌面配置文件编辑器的软件包名称。

### Samba
Linux 中提供 SMB 和 NetBIOS 协议以与 Windows 计算机进行文件和打印机共享的一组服务。

### `sax2` 命令
用于在 SUSE Linux 系统上启动 X 配置实用程序的命令。

### 模式
LDAP 数据库的对象和对象属性列表。

### `scp` 命令
使用 SSH 从一台主机复制文件到另一台主机的命令。

### 搜索模式
可用于匹配多个文件名的特殊字符。也称为通配符。

### 次要组
用户所属的非用户主组的组。

### 安全外壳（SSH）
提供到远程计算机的加密通信的软件服务。它也可以用于创建 VPN。

### 串行高级技术附件（SATA）
现代计算机中常用的 EIDE 的串行版本。

### 服务器消息块（SMB）
Windows 系统使用的文件和打印机共享协议。

### 服务器进程密钥对（SK）
启动 SSH 守护进程时生成的非对称加密密钥对。此密钥对从未存储在文件中，并在每次重新启动守护进程时重新生成。

### 服务
请参阅守护进程。

### 服务定位协议（SLP）
Novell 网络使用的网络浏览协议。

### 会话密钥
SSH 用于对称加密的随机生成的密钥。

### 设置组 ID（SGID）
设置在可执行文件和目录上的特殊权限。当您运行设置了 SUID 权限的可执行程序时，您将在程序运行期间成为可执行文件的组所有者。在目录上，SGID 设置了新创建文件的附加组。

### 设置用户 ID（SUID）
设置在可执行文件上的特殊权限。当您运行设置了 SUID 权限的可执行程序时，您将在程序运行期间成为可执行文件的所有者。

### `sftp` 命令
使用 SSH 从一台主机复制文件到另一台主机的命令。

### 共享库
存储系统上大多数程序使用的公共函数的文件。

### 共享
Windows 或 Samba 计算机上的共享目录或打印机。

### shell
Linux 命令解释器。

### shell 变量
仅在当前 shell 中可用且用于配置 shell 本身的变量。

### `shutdown` 命令
用于在特定时间更改为运行级别 0 的命令。

### siga（系统信息收集）
Linux 实用程序，可创建有关 Linux 系统硬件和软件的报告。

### 信号
发送到进程的终止请求。

### 信号控制守护进程
当系统上发生事件时启动的守护进程。

### 小型计算机系统接口（SCSI）
服务器和高性能工作站计算机中常用的硬盘技术。

### `smbclient` 命令
用于查看和访问 Windows 和 Samba 文件和打印机共享的命令。

### smbd
Samba 守护进程。

### 套接字
两个主机之间建立的网络连接。CUPS 可以使用套接字打印到远程系统，反之亦然。

### 套接字
连接两个不同计算机上进程的有名管道；它们也可以由文件系统上的文件表示。

### 软件管理
YaST 模块，用于在 SUSE Linux 中安装和管理软件包。

### 软件 RAID
由操作系统软件管理的 RAID 实现。

### 软件更新程序
桌面实用程序，可使用在线更新快速更新您的 SUSE Linux 软件。

### `source` 命令
用于在当前 shell 环境中执行文件的命令。

### `ssh` 命令
用于从远程 SSH 服务器获取 shell 的命令。

### `ssh-add` 命令
用于为 ssh-agent 命令注册新的 RSA 和 DSA 密钥的命令。

### `ssh-agent` 命令
用于执行 SSH 身份验证的命令。

### `ssh-copy-id` 命令
用于将 SSH 密钥从一台计算机复制到另一台计算机的命令。

### `ssh-keygen` 命令
用于为 SSH 生成 RSA 和 DSA 密钥的命令。

### `ssh-keyscan` 命令
用于显示 SSH 使用的非对称公钥的命令。

### 粘滞位
设置在目录上的特殊权限，可防止用户删除他们不拥有的文件。

### `su`（switch user）命令
用于更改当前用户账户的命令。

### 子网掩码
用于确定 IP 地址的哪些部分是网络部分和主机部分的数字。

### `sudo` 命令
用于通过 `/etc/sudoers` 中的条目以其他用户身份运行命令的命令。

### SuSEconfig
使用 `/etc/sysconfig` 目录中的条目配置系统的软件实用程序。

### SuSEFirewall
限制 SUSE Linux 计算机上某些网络流量的服务。

### SuSEfirewall2
用于配置 netfilter 框架以在网络接口上提供数据包过滤的 SUSE Linux 实用程序。

### 交换
硬盘上保留用于存储通常存储在计算机内存中的信息的区域。

### 符号链接
指向同一文件系统或另一文件系统上另一个文件的指针；通常称为快捷方式或软链接。

### 对称加密
使用相同密钥加密和解密数据的一种加密类型。

### Syslog 守护进程
提供 Linux 系统上大多数日志服务的守护进程。

### syslog-ng
SUSE Linux 系统上使用的 Syslog 守护进程。

### 系统用户
可由系统服务使用的用户账户，不能由用户交互式登录系统。

### Tab 窗口管理器 (twm)
一个小型独立的窗口管理器，使用系统资源很少，可替代 KDE 或 GNOME 桌面使用。

### `tail` 命令
一个 Linux 命令，用于显示文件中最后设定数量行的文本；默认情况下，`tail` 命令显示文件的最后 10 行。

### TCP/IP
Linux 系统上使用的默认网络协议。它代表传输控制协议/互联网协议。

### 模板
在 OpenOffice.org 等程序中用于创建新文档的示例结构。

### 票证授予票证 (TGT)
Kerberos 票证，在成功进行身份验证请求后授予已通过身份验证的计算机。

### TightVNC
一个提供 SUSE Linux 中 VNC 服务器功能的软件包。

### 生存时间 (TTL)
IP 数据包内部的一个值，标识数据包还能经过多少个路由器。每个路由器都会递减通过其的数据包的 TTL。当数据包的 TTL 达到零时，它将被从网络中移除。

### `top` 命令
一个用于查看、重新设置优先级并终止使用最多 CPU 时间的系统进程的命令。

### `touch` 命令
一个用于创建新文件的命令。它最初用于更新文件的时间戳。

### `traceroute` 命令
一个用于识别 IP 数据包到远程主机的路由的命令。

### 传输控制协议 (TCP)
TCP/IP 协议套件的一部分，为网络上的主机之间提供可靠的通信。

### 传输控制协议/互联网协议 (TCP/IP)
用于与其他计算机在网络上通信的一组协议。

### Triple-DES (3DES)
一种常见的对称加密算法，使用 112 或 168 位密钥。
