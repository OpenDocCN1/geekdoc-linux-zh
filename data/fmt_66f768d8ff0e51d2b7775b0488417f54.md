# Flat address space (扁平地址空间)

一种组织计算机内存的方法，操作系统可以无限制地分配部分内存。扁平地址空间的对面是 MS–DOS 和 Microsoft Windows 3.1 的分段内存架构，它将内存划分为 64K 的区域（称为段）。分页内存空间设计更高效，因为处理器不需要将每个内存地址映射到 64K 段，但这种设计要求使用 32 位内存地址。采用 32 位内存地址的 Microsoft Windows 95 为你的应用程序创建了扁平地址空间。来自 QUEDIC `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

Lisp 机器中用于面向对象意义上的“类” (`class`) 的术语（特别是由 Common Lisp 设施设计的），Lisp 黑客仍将“flavor”作为“class”的通用同义词。源自日本词典 (Japon Dictionary) `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

# flink

一个支持多账户的 GNOME 邮件检查小插件。`Flink` 邮件检查器是 GNOME 面板的一个小型小插件。它具有多账户功能，因此你不需要为检查不同的账户而设置多个输入口，`Flink` 能够配置（几乎）无限数量的账户。`Flink` 现在已支持 POP3、IMAP4 和 mbox。未来将逐渐添加对其他类型邮件账户的支持。来自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

# flip

在 Unix 和 DOS 格式之间转换文本文件行尾的工具，用于转换 MS–DOS 和 Unix 格式文本文件的行尾。它能以近乎万无一失的方式检测文件，除非你覆盖它，否则会保持原样。它还会保留已经是正确格式的文件并保护文件时间戳。`flip` 中断处理得非常优雅，不会留下垃圾文件或损坏的文件。‘`flip`’ 不会转换为不同的字符集，且无法处理 Apple Macintosh 缩进（CR）。对于这些（以及更多功能），你可以使用 ‘`recode`’（package_recode 软件包）。来自 Debian 3.0r0 APT `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`

# flood

一种黑客攻击类型，受害者会被流量淹没，例如：2000 年初的一些大型网站遭受 DDoS 攻击被流量淹没，阻塞了 1-gbps 高带宽互联网连接。IRC 聊天室中的用户会被命令淹没，或者用户的客户端被邀请到对服务器的淹没攻击中。无论哪种，用户都必须注销或被踢出去。RAIF 过去有一种 UNIX 命令向用户的终端发送大量文本，强迫他们面对 `/dev/tty` 持续的伪造、随机/数据攻击洪流，这些工具淹没了 IDS 控制台，导致操作员无法恢复真实攻击。黑客词汇表 `http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html`
