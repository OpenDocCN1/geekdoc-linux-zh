
# elw: 构建一个嵌入式 Linux 研讨会项目

本代码根据通用公共许可证（GPL）的条款和条件进行分发

```perl
#!/usr/bin/perl
############################################################
# elw: 构建一个嵌入式 Linux 研讨会项目
# 本代码根据通用公共许可证 (GPL) 的条款和条件
# 进行分发
############################################################
use Getopt::Long;

############################################################
# 解析命令行参数
############################################################
$VERB=basename '$0'; chop $VERB;
$ELHOME="";
$CONFIG="";
$EXECUTE="";
$DEFINES = ();
Getopt(
    "elhome=s" => \$ELHOME,
    "config=s" => \$CONFIG,
    "define=s" => \DEFINES,
    "execute=s" => \$EXECUTE,
    "help?" => \$HELP,
    "newproject=s" => \$NEWPROJECTNAME,
    "verbose=v" => \$VERBOSE
);
$ELHOME=ENV{\'$ELHOME'} if ($ELHOME eq '');
$ELHOME="/usr/local/elw" if ($ELHOME eq '');
chomp(\$CONFIG) if ($CONFIG eq '');
$EXECUTE="menu_run" if ($EXECUTE eq '');
usage() if (\$HELP);
```

我非常喜欢 Perl 的一点是 `do_this() if (this_is_true);` 这种结构。它让代码变得易读得多——每当我写 C 代码时，我都会想念它。

## 计算常量

```perl
############################################################
# 计算常量
############################################################
$ELW_VERSION = qx(cat \$ELHOME/VERSION 2>/dev/null);
chomp(\$ELW_VERSION)
if (\$ELW_VERSION eq "") {
    print "\$0: 设置 ELHOME 环境变量。\n"
    exit;
}
```

这部分代码查找 `ELW_VERSION`，并验证 `$ELHOME` 变量是否指向嵌入式 Linux 研讨会的根目录。

这部分验证了 `$CONFIG` 变量指向的是一个有效的项目。我将在后的章节讨论项目。

```perl
@OPTDIR="$CONFIG,$ELHOME"; # OPTDIR - 查找 opts 的位置
```

`$OPTDIR` 变量跟踪了 opt 包的可能位置。如果 config 和 `*.style` 文件需要定义可能找到 opt 目录的其他地方，也可以向此变量添加内容。注意，`$CONFIG` 目录（即我们正在工作的特定项目）名称是排在前面的。这样，你就可以针对特定项目修改 opt 包。

## 加载配置文件

```perl
eval 'cat $CONFIG/config';
```

```perl
if ( !r "$ELHOME/bin/$STYLE") {
    die "无法加载样式: $ELHOME/bin/$STYLE"
}
eval `$ELHOME/bin/$STYLE";
```

啊，Perl 自修改代码的力量（以及危险）。第一个 `eval` 加载了项目的配置。是的，配置文件本身就是 Perl 源代码——因此它可以执行任何操作。你不仅可以添加简单的键值对（例如设置 `$STYLE` 变量以执行你选择的构建），还可以做诸如为菜单添加选项等操作。

## main()

```perl
eval $EXECUTE;
```

很有可能，`$EXECUTE` 变量包含 `menu_run`，因此它会运行菜单。但你可以使用 `-e` 选项作为用法运行特定的命令。

# bin/syslinux.style

当项目配置中的 `STYLE` 变量设置为 `syslinux` 时，`syslinux` 脚本片段会被加载到运行中的 `elw` 脚本中。当你使用 `--newproject` 命令创建一个新项目时，它是配置文件中的默认选定项。`syslinux.style` 与所有 `.style` 文件一样，包含了实际构建目标镜像的代码。它将 `arch/*/opt` 目录、内核二进制以及任何启动代码作为输入，并将文件输出到项目中的 `obj` 目录。

简而言之，`syslinux.style` 文件如下：

```perl
################################################################
# syslinux.style: 用于构建 syslinux 镜像的 ELW perl 脚本
# 本代码根据通用公共许可证 (GPL) 的条款和条件
# 进行分发
################################################################
```
