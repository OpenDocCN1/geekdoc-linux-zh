# 使用 Hydra 自动化密码攻击

工具作者：Van Hauser, Roland Kessler

工具网站：https://www.thc.org/thc-hydra

Hydra 是一个暴力破解程序，它接受用户列表和密码列表，并尝试它们的不同组合来攻击服务器服务。如果我们为上面获取的用户名和密码各创建一个文件，就可以将它们喂给 Hydra 这样的程序。这些工具自动化了使用破解账户攻击服务的任务。

创建以下两个文本文件（Users, Passwords），输入从密码文件中恢复的值并将它们保存到 Desktop 目录下：

## Users

- msfadmin
- sys
- klog
- service
- postgres
- user

## Passwords

- msfadmin
- batman
- 1234567898
- service
- postgres
- user

我包含了 msfadmin，因为我认为它以前被包含在字典文件中。如果你还记得，我们在查看 Metasploit 章节中的 telnet 服务器时已经发现它了：

```
root@kali:~# telnet 192.168.1.68

```

现在，使用 Hydra 使用我们新发现的密码来攻击 SSH 服务：

# 第 22 章：Mimikatz - 明文密码

## Mimikatz

**工具作者：** Benjamin Delpy

**工具网站：** http://blog.gentilkiwi.com

在本节中，我们将学习如何恢复明文形式的远程密码。你没读错，就是明文！Windows 7 在 Windows 进程的多个位置以明文形式存储密码，你可以使用 Delpy 的强大工具来恢复这些密码。Mimikatz 已经作为一个独立程序运行了一段时间，并被添加到 Metasploit 框架中作为一个可加载的 Meterpreter 模块，这使得在获得远程会话后恢复密码变得极其简单。我提到过密码是明文的吗？虽然在较新的操作系统（如 Windows 10 和 Server 2016）中，它返回的是需要破解的 NTLM 哈希。

在本章中，我们将看到如何通过 Metasploit 使用 Mimikatz 从远程系统恢复密码。然后我们将看到如何将 Mimikatz 用于物理攻击，即安全测试人员拥有系统物理访问的攻击。还有其他几种你可以使用 Mimikatz 的方法我们不会涵盖，而且 Benjamin 在更新工具和添加新功能方面做得非常出色，因此我强烈建议访问该工具博客以获取最新信息。
