# 第 7 章：安全与加固

# 7.1. `Linux` 安全基础

安全是计算世界中一个首要考虑的问题，`Linux` 也不例外。理解 `Linux` 安全基础对于确保你的系统和数据的完整性、机密性和可用性至关重要。本节涵盖了保护 `Linux` 系统的关键概念和实践。

### 用户帐户与密码

用户账户是保护 `Linux` 系统的第一道防线。以下是一些与用户账户相关的安全实践：

- **用户身份验证：** `Linux` 依赖用户名和密码的组合进行用户身份验证。强且唯一的密码对于防止未经授权的访问至关重要。
- **用户帐户：** 限制具有管理员权限的用户数量（例如，`root` 帐户）。日常活动使用普通用户帐户。
- **密码策略：** 强制执行需要强密码和定期更改密码的策略。
- **禁用未使用帐户：** 禁用或删除不再需要的用户帐户。

### 文件权限与所有权

`Linux` 采用强大的文件权限系统来控制对文件和目录的访问。妥善管理权限和所有权对于安全性至关重要：

- **最小权限原则：** 用户和进程应该拥有执行其任务所需的最小权限。
- **`chmod`：** 使用 `chmod` 命令显式地设置文件权限。例如，`chmod 600` 限制文件所有者访问。
- **`chown`：** `chown` 命令更改文件和目录的所有权。确保敏感文件由受信任的用户或系统帐户拥有。

# 防火墙配置

防火墙对于网络安全至关重要。`Linux` 提供了 `iptables` 和 `firewalld` 等工具来配置防火墙：

- **`iptables`：** `iptables` 工具允许对网络流量进行细粒度的控制。根据 IP 地址、端口和协议创建规则，以允许或拒绝特定连接。
- **`firewalld`：** `firewalld` 是一个更用户友好的防火墙管理界面。它简化了规则管理，并通常用于现代 `Linux` 发行版中。

# 定期更新与补丁管理

保持 `Linux` 系统通过安全补丁更新至最新状态至关重要：

- **包管理器：** 使用包管理器（例如 `apt`、`yum`、`dnf`）更新已安装的软件和操作系统。
- **自动更新：** 考虑启用自动更新，以确保及时应用安全补丁。

# 审计与监控

`Linux` 提供了审计工具来监控系统活动：

- **`auditd`：** `auditd` 守护记录系统事件，包括用户登录、文件访问和系统更改。定期检查审计日志以检测可疑活动。

# 安全策略与 `SELinux`

`SELinux`（安全增强型 `Linux`）和 `AppArmor` 是执行安全策略的强制性访问控制 (`MAC`) 系统：

- **`SELinux`：** `SELinux` 使用安全上下文来定义进程和文件的访问控制。它是一个强大的工具。
- **`AppArmor`：** `AppArmor` 为应用程序配置配置文件，限制它们的功能与系统的交互。

### 结论

`Linux` 安全基础涉及用户帐户管理、文件权限、防火墙配置、定期更新、审计以及 `SELinux` 和 `AppArmor` 的使用。通过遵循这些实践并保持警惕，你可以显著增强 `Linux` 系统的安全性并防止受到各种威胁。安全是一个持续的过程，了解新威胁和最佳实践对于适应和维护安全的 `Linux` 环境至关重要。

# 7.2. 防火墙配置与管理

防火墙通过控制网络流量和防止未经访问在保护 `Linux` 系统方面着核心作用。本节关注 `Linux` 环境下的防火墙配置和管理，涵盖了 `iptables` 和 `firewalld` 的使用。

# 理解防火墙

防火墙是一种根据预定义的安全规则监控并过滤入出网络流量的安全设备或软件。它是受信网络与不受信任的网络（如互联网）之间的屏障。

# `iptables`

`iptables` 是配置 `Linux` 内核 `netfilter` 防火墙的强大命令行工具。它允许你定义如何处理网络包的规则。

# 基础 `iptables` 使用

以下是一些基础 `iptables` 命令：

- **列出当前规则：** 查看当前的防火墙规则，使用：

```
$ sudo iptables -L
```

- **允许 SSH 访问：** 要允许进入 SSH（安全外）连接，可以运行：

```
$ sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```

- **阻止特定 IP 地址：** 要阻止来自特定 IP 地址的入站流量，使用：

```
$ sudo iptables -A INPUT -s <IP_ADDRESS> -j DROP
```

- **保存规则：** 为了重启后保留规则，你可以使用：

```
$ sudo service iptables
```

- **启动/停止/重启：** 启动、停止或重启 `iptables`，使用：

```
$ sudo service iptables
```

```
$ sudo service iptables
```

```
$ sudo service iptables restart
```

# 高级 `iptables` 配置

高级 `iptables` 配置涉及定义复杂的规则集和管理状态化连接。虽然 `iptables` 提供了细粒度的控制，但其设置过程可能非常复杂。

## `firewalld`

`firewalld` 是一个更用户友好且动态的防火墙管理工具，通常用于现代 `Linux` 发行版中。它为配置防火墙规则提供了更简单的接口，并支持网络区域。

## `firewalld` 基本用法

以下是基本的 `firewalld` 命令：

- **检查防火墙状态**：要检查 `firewalld` 的状态，请使用：

```
$ sudo firewall-cmd --state
```

- **列出允许的服务**：要列出允许的服务，请使用：

```
$ sudo firewall-cmd --list-services
```

- **允许服务**：要允许某个服务（如 SSH），请使用：

```
$ sudo firewall-cmd --add-service=ssh --permanent
```

```
$ sudo firewall-cmd --reload
```

- **阻止 IP 地址**：要阻止来自特定 IP 地址的流量，请使用：

```
$ sudo firewall-cmd --zone=public --add-rich-rule='rule family="ipv4" source address="<IP_ADDRESS>" drop'
```

```
$ sudo firewall-cmd --reload
```

- **更改区域**：要更改网络区域，请使用：

```
$ sudo firewall-cmd --set-zone=home
```

```
$ sudo firewall-cmd --reload
```
