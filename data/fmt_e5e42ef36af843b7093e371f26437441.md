
Python 3.0 面临的一个主要问题涉及第三方库的兼容性。它的很大力量来自于其种类丰富的框架和库。然而，除非这些库被显式地移植到 Python 3，否则它们几乎肯定不会迁移。这个问题在许多依赖其他库的库中已然暗示。截至写本文时（2009 年），一些主要的 Python 库和框架尚未移植到 Python 2.4，更不用说 2.6 或 3.0 了。因此，如果你打算使用 Python 3 来运行第三方代码，你最好现在坚持使用 Python 2。如果你拿了这本书且现在是 2012 年，希望情况已经有所改善。

尽管 Python 3 清除了语言中的一些微小瑕疵，但尚不清楚 Python 3 对于只想学习基础的新用户来说是否明智的选择。几乎所有现有文档、教程、食谱和示例都假设使用 Python 3，并使用了不兼容的编码规范。不用说，如果一切看起来都是坏的，将无法获得积极的学习体验。即使是官方文档也没有完全更新 Python 3 的编码要求；在编写本书期间，作者提交了许多关于错误和遗漏的 报告。

最后，Python 3.0 是最新且最强大的，但它遭受着许多性能和行为问题。例如，初始版本中的 I/O 系统表现出真正可怕且不可接受的运行时性能。字节和 Unicode 的分离并不是没有问题。甚至某些内置库模块在 I/O 和字符串处理方面也是损坏的。显然，随着更多程序员对发布版本进行压力测试，这些问题将随着时间的推移而改善。然而，在作者看来，Python 3.0 真的只适用于经验 Python 老兵的实验性使用。如果你寻找稳定性和生产级代码，请坚持使用 Python 2，直到 Python 3 系列的一些缺陷有时间得到解决。

## 集合字面量

现在可以通过将项目包含在大括号中来定义集合。例如：

```python
days = {'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'}
```

## 集合和字典推导式

语法 `{expr for x in s}` 是集合推导式。它对集合中的所有元素应用操作，并可以类似于列表推导式的方式使用。例如：

```python
>>> values = {1, 2, 3, 4}
>>> squares = {x*x for x in values}
{1, 4, 9, 16}
```

语法 `{kexpr:vexpr for k,v in s}` 是字典推导式。它对序列 `s` 中的键值元组应用操作并返回字典。这可以被视为 `dict()` 函数的强大版本。

为了说明，假设你有一个这样的 `prices.dat` 文件：

```text
GOOG 509.71
YHOO 28.34
IBM 106.11
MSFT 314.47
AAPL 122.13
```

这是一个使用字典推导式将该文件读取为映射股票名称到价格的程序：

```python
fields = {line.split() for line in open("prices.dat")}
prices = {sym:float(val) for sym, val in fields}
```

这是一个将价格字典的所有键转换为小写的示例：

```python
d = {sym.lower():price for sym, price in prices.items()}
```

这是一个创建超过 100.00 美元股票字典的示例：

```python
d = {sym:price for sym, price in prices.items() if price >= 100.0}
```

## 扩展迭代解包

在 Python 2 中，可以使用如下语法将项解包到变量：

```python
items = [1,2,3,4]
a,b,c,d = items    # 将项解包到变量
```

为了使这种解包工作，变量和项的数量必须匹配。

在 Python 3 中，你可以使用通配符解包序列中的部分项，并将剩余值放入列表中。例如：

```python
*rest = items    # a = 1, rest = [2,3,4]
*rest,d = items  # a = 1, rest = [2,3], d = 4
*rest, d = items  # rest = [1,2,3], d = 4
```

在这些示例中，带有 `*` 前缀的变量将接收所有的额外值并将它们放入列表中。如果没有额外的项目，该列表可能为空。此功能的一个用例是在对元组（序列）的列表进行循环遍遍历时，其中这些元组的大小可能不相同。例如：

```
points = [(1,2), (3,4,'red'), (4,5,'blue'), (6,7) ]
x,y, *opt in points:
    if opt:
        # 发现了额外的字段
        statements
```

# 非局部变量

内部函数可以使用 `nonlocal` 声明修改外部函数中的变量。示例：

```
def countdown(n):
    def decrement():
        nonlocal n
        n -= 1
    while n > 0:
        print("T-minus", n)
        decrement()
```

在 Python 2 中，内部函数可以读取外部函数中的变量，但不能对其进行修改。`nonlocal` 声明实现了这一功能。

# 函数注解

函数的参数和返回值可以使用任意值进行注解。示例：

```python
def foo(x:1,y:2) -> 3:
    pass
```

函数属性 `__annotations__` 是一个将参数名称映射到注解值的字典。特殊的 `'return'` 键映射到返回值注解。示例：

```python
>>> foo.__annotations__
{'y': 4, 'x': 3, 'return': 5}
>>>
```

解释器不会为这些注解分配任何内容。事实上，它们可以是任何值。然而，预期的类型信息在未来将是最有用的。例如，你可以写：

```python
def foo(x:int,y:int) -> str:
    statements
```

注解不仅限于单个值。注解可以是任何有效的 Python 表达式。对于位置参数和关键字参数，也适用相同的语法。例如：

```python
def bar(x, *args:"additional", **kwargs:"options"):
    statements
```

再次，重要的是强调，Python 并没有赋予注解任何特殊意义。其意图用法是在第三方库和框架中，这些库可能会将它们用于各种应用程序元编程。示例包括但不限于：静态分析工具、文档、测试、函数重载、序列化、远程过程调用、IDE 等。以下是一个对参数和返回值强制断言的装饰器示例：
