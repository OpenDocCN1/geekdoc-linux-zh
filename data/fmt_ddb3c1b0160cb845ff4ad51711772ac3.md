
# 多功能智能处理器 SmartList

多功能智能处理器 `SmartList` 是一个构建在 `procmail` 处理系统之上的邮件列表管理器。功能：

- 足够智能，可以克服某些订阅者的无知，他们退订普通列表并自动订阅到 `(-request 地址)`。
- 无需硬件即可处理 `(in)` 订阅请求（即新订阅者不需要被教育，已订阅的用户不需要记住任何语法）。
- 自动消除重复提交。
- 自动删除过多的重复项。
- 你可以设置邮件列表作为独立的邮件服务器。源自 Debian 3.0r `http://www.ldp.org/LDP/linux-Dictionary/index.html`

## SMB

引言 本 `SMB HOWTO`。本文描述了如何使用 `Samba` 使用 Server Message Block (`SMB`) 协议，也称为 Session Message Block、NetBIOS 或 Lan Manager 协议。本文以 Linux 为中心，`Samba` 运行在类 Unix 操作系统上。本文由 David Wood (`dwood@plugged.net.au`) 维护。可以通过邮件发送添加、修改或修正以包含在下个版本中。更多文档可以在 `Samba` 网站找到，地址为 `http://www.samba.org/`。那里有大量信息；在寻求帮助之前请先查看！你可以尝试 `comp.protocols.sm` 新闻组。`SMB` 协议被 Microsoft Windows 3.1、NT 和 95/98 用于共享磁盘和打印机。在 Windows 主机上使用 `Samba` 工具包。由 Paul-Kr. (`engstad@intermetrics.com`) 和 Volker Lendecke (`lendecke@nam01.gw.de`) 的 `smbfs` 工具允许 Unix 机器能够从 Windows 或 `Samba` 挂载 `SMB` 共享。你可以使用 `Samba` 做四件基本事情：

## SMB

`SMB` 是 Microsoft 用于文件和打印共享的协议。`SMB` 代表 Server Message Block，尽管这并没有实际意义。`SMB` 运行在 `NetBIOS` 之上，在 `Win2k` 中可以跳过 `NetBIOS`。历史：`SMB` 最初为 `DOS` 机器开发。后来升级到 `OS/2`，作为 `DOS` 机器的服务器。该协议后来升级到 Windows (`FW = Windows for Workgroups`) 和 Windows `NT`。后续版本还增加了 Windows Windows。这种不断的演进和对后兼容的需求导致了协议内部的安全漏洞。最严重的是“`LAN Manager`”认证。`SMB` 是一个应用层协议，可以运行在许多不同的传输之上，包括 `TCP/IP`。一个常见问题是用户如何在 `TCP/IP` 上启用 `SMB`，允许互联网上的任何人访问他们的硬盘。他们应该安装一个仅限本地的传输层作为 `SMB` 的 `NetUI`，这将允许本地机器之间的文件访问，但不允许跨互联网的远程机器访问。`SMB` 嗅探器可以从线路上读取加密的密码并发送给密码破解器。源自 `Hacking-Linux` `http://www.ldp.org/LDP/Linux-Dictionary/index.html`

## smbfs

用于 `smbfs` 的 `mount` 和 `umount` 命令。`smbfs` 是一个理解 `SMB` 协议的文件系统。这是用于 Workgroups、NT 或 `LAN Manager` 之间通信的协议。它受到 Andrew Trigdell 编写的 `samba` 程序启发，该程序将任何 `unix` 转换为 `DOS` 或 Windows 客户端的文件服务器。如果你想使用 `smclient`、`smbar` 和 `smbd` 等命令行工具，只需安装 `smbfs` 包。从 Debian `Samba` 软件包 `2.0-1` 开始，旧的 `smutils` 已被移除。没有根据内核版本调用特定 `smbfs/smbount` 的封装脚本。如果你正在使用 `2.0` 内核，请升级或使用最新的 `Samba 2.0.7` Debian 包。源自 Debian 3.0r `APT` `http://www.ldp.org/LDP/Linux-Dictionary/index.html`
