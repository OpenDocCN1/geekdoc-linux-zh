## 5.3.10 如何使用 VNC 显示并控制远程桌面

(VNC = 虚拟网络计算)。一个非常实用的应用程序——不要错过。
VNC 是一个跨平台实用，允许我通过标准网络连接显示远程图形桌面。例如，我可以在 MS Windows PC 上运行 VNC，显示远程 Linux 服务器的 X 窗口环境。VNC 可以在 56k 调制解调器上运行，但仅用于娱乐或紧急情况（正常工作太慢了）。

最近的 Mandrake 或 RH 发行版中包含了 `vnc`。MS Windows 版本需要你自己下载。请访问 `http://www.uk.research.atht.com/vnc/` 获取下载信息和更多细节。URL 视为路径/资源名，加反引号。

`vncserver`：必须在远程（主机）计算机上运行的服务器。以你要显示桌面的用户身份启动服务器（不要以 root 身份运行服务器，否则可能会劫持你的电脑！）。
