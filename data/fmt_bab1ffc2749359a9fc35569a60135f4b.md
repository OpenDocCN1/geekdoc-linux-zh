## 创建 `/var/run/utmp`, `/var/log/wtmp` 和 `/var/log/btmp` 文件

像 `login`、`shutdown`、`uptime` 等程序需要读取和写入 `/var/run/utmp`、`/var/log/btmp` 和 `/var/log/wtmp`。这些文件包含了当前登录用户的信息。它包含了计算机最后启动和关机的时间，以及错误登录尝试的记录。

运行以下命令以以正确的权限创建这些文件：

```
root:~# touch /var/run/utmp /var/log/wtmp /var/log/btmp
root:~# chmod 644 /var/run/utmp /var/log/wtmp /var/log/btmp
```

# 第 7 章 创建系统启动脚本

## 本章内容

本章将创建启动时运行所需的脚本。这些脚本执行的任务包括：将内核只读挂载的根文件系统重新挂载为读写模式、激活交换分区、对根文件系统进行检查以确保其完整以及启动系统使用的守护进程。

## 创建目录

我们需要首先创建几个启动脚本使用的额外目录。运行以下命令创建这些目录：

```
root:~# cd /etc
root:etc# mkdir sysconfig rc0.d rc1.d rc2.d rc3.d
root:etc# mkdir rc4.d rc5.d rc6.d init.d rc8.d
```

## 创建 rc 脚本

第一个主启动脚本是 `/etc/init.d/rc`。创建一个新文件 `/etc/init.d/rc`，包含以下内容：

```bash
#!/bin/sh
# Begin /etc/init.d/rc
#
# By Jason Pearce - jason.pearce@linux.org
# Modified by Gerard Beekmans - gerard@linuxfromscratch.org
# print_error_msg based on ideas by Simon Perreault - nomis80@yahoo.com
source /etc/init.d/functions
print_error_msg() {
	echo
	$FAILURE
	echo -n "You should not read this error message. It means "
	echo "that an unforeseen error"
	echo -n "took place and subscript $i exited with"
	echo "return value"
	echo -n "Error_value for an unknown reason. If you are able "
	echo "to trace this error down"
	echo -n "to use a bug in one of the files provided by this book,"
	echo "please be kind to"
	echo -n "inform us at lfs-discuss@linuxfromscratch.org"
	$NORMAL
	echo
}
# Un-comment the following for debugging.
# debug-echo
#
# Start script or program.
#
artup() {
	case "$1" in
	.*.sh)
		debug sh "$@"
		;
	*)
		debug "$@"
		;
	esac
}
# Ignore CTRL-C only in this shell, so we can interrupt subprocesses.
trap ":INT QUIT TST"
# Set onlcr to avoid staircase effect.
stty onlcr 0&&1
# Now find out the current and what the previous runlevel are.
runlevel=$RUNLEVEL
# Get first argument. Set new level to this argument.
```
