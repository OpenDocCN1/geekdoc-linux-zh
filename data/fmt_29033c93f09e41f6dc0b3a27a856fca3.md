# rextk

Regina 的 Tcl/Tk 接口。Regina REX/Tk 通过与 Tcl/Tk 库交互，为解释型语言 Regina Rxx 提供了 GUI 能力。它使 Rxx 程序员能够调用封装 Tcl/Tk 包中 GUI 部分的函数来编写移植的 GUI 应用程序。它也适用于其他操作系统。所有的 Ttk 函数都已实现，并支持某些第三方控件，如组合框（combobox）和多列列表（multicolumn-listboxes）。出自 Debian 3.0r0 APT `http://www.tdp.org/LDP/Linux-Dictionary/index.html`

RFC

/RFC–C/ 数字. [意见请求] 一个历史悠久的互联网信息文档和标准系列，被商业软件以及和 Unix 社区广泛遵循。也许影响最大的一个是 RFC 822，它是电子邮件格式的标准。RFC 由互联网任务组（IETF）编写，以定义新标准。RFC 是提议标准的主要手段（尽管并非所有 RFC 都包含新标准）。网络信息中心（NIC）可以访问 1000 多份 RFC。目前 RFC 的发布由互联网架构委员会（IAB）控制。

RFC (Request For Comments)

服务管理员或开发者不可或缺的信息源是 RFC。文档通常会引用 RFC。
