
然后，选择 `Blizzard Battle.net` 并点击酒杯图标旁边的箭头，选择“Wine 配置 (Wine Configuration)”。

当 Wine 配置窗口打开后，找到“Windows 版本 (Windows Version)”下拉菜单，选择 `Windows 11` 或 `Windows 10`。

下一步，移动到“驱动器 (Drives)”选项卡，点击添加按钮，并分配新的驱动器号。在这里，你需要定位并选择魔兽世界目录（该目录包含 `retail`、`classic` 和 `classic_era` 文件夹），然后点击“确定”。

点击“应用 (Apply)”应用这些设置，并再次点击“确定”进行确认。

确保没有设置 `WINEESYNC` 变量且没有运行的 `esync` 实例，这对于这些更改的正常生效至关重要。如果你仍然遇到问题，请考虑将显卡驱动更新到最新版本。例如，更新到 `NVIDIA` 的 `545` 驱动已解决了某些用户的崩溃问题。

## DirectX 12 图形错误可能解决方法

访问 `DirectX` 官方网站 `https://www.microsoft.com/en-gb/download/details.aspx?id=35` 获取所有 `DirectX` 信息。

通过 `GUI` 解决 `DirectX 12` 错误：

要通过用户界面解决 `DirectX 12` 错误，从应用程序菜单打开战网。然后，点击大型蓝色“播放 (Play)”或“更新 (Update)”按钮旁边的齿轮图标。选择“游戏设置 (Game Settings)”并找到你想玩的魔兽世界版本（例如正式版魔兽世界）。勾选“额外命令行参数 (Additional command line arguments)”并在相邻的框中输入 `"-d3d11"`，然后点击“完成 (Done)”。启动魔兽世界后，进入“选项 (Options)”菜单，选择“系统 (System)”下的“图形 (Graphics)”选项卡，并滚动到“高级 (Advanced)”下的“图形 API (Graphics API)”。确保已选择 `DirectX 11`；如果不是，从“图形 API”旁边的下拉菜单中选择 `DirectX 11` 并重启魔兽世界以有效应用更改。

## 通过命令行和 GUI 创建 Curseforge AppImage .desktop 快捷方式：

要为 `Curseforge` 创建 `.desktop` 快捷方式，请在终端中执行以下步骤：

导航至应用程序目录：

```
cd /usr/share/applications
```

运行以下命令打开新的 `.desktop` 文件进行编辑：

```
sudo gedit Curseforge1.desktop
```

在打开的快捷文件中输入以下详细信息：

```
[Desktop Entry]
Name=Curseforge
Comment=Curseforge
Exec=./Downloads/Curseforge-244.4-16117.AppImage
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

保存进度时点击“保存 (Save)”。或者，你可以点击“文件 (File)”然后点击“保存”，或点击 `≡` 图标选择“另存为 (Save As)”最后点击“保存”。保存后关闭编辑器。
