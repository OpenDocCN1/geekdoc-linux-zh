
大多数 Linux 或 UNIX 主机的登录可以在本地验证，也可以通过 NIS 或 NIS+ 等集中服务进行远程验证，如图 2.12 所示。使用任种身份验证方法，你都可以包含额外的安全设置，如 MD5 和影子密码（shadow passwords），这两者都是高度推荐的。MD5 是一种更安全、集成的密码形式；影子密码实际上是针对 UNIX 和 Linux 密码文件的改进安全方案。通常，UNIX 和 Linux 将每个用户的设置信息存储在所有用户都可读的文件中。开启影子密码后，信息中一些重要的部分将存储在一个所有人不可读的文件中，通常称为 `/etc/shadow`，但它是完全可配置的。

## 使用 NIS 或 NIS+

标准的基于 UNIX 和 Linux 的集中域登录由目前称为命名为网络信息服务（NIS）的服务提供，或者由 Sun Microsystems 公司提供的更更新的版本 NIS-PLUS (NIS+) 提供。只有 Sun 公司提供 NIS+ 服务器。Linux 拥有兼容的客户端。

NIS 提供了一套集中的用户管理数据文件（NT 中的 PDC），复制到从 NIS 服务器（NT 中的 BDC），这些服务器验证基于 NIS 客户端的登录（通过 Netlogon 进行 NT LOGON）。图 2.12 显示了未提供信息的 NIS 设置（默认设置）。你需要知道 NIS 域名称，并可以使用广播寻找最近的从 NIS 服务器，或者在知道其 IP 地址的情况下直接输入。

## X Window 安装（可选）

对于普通 PC 用户来说，这可能是安装过程中最难理解的部分。X Window 系统实际上是一个用户级程序，而不是内核级程序，它希望直接访问显卡的硬件。在 Windows 环境中，你会获得一个视频控制器的驱动程序。同样，你也会获得一个驱动配置文件（在此情况下是文本格式），它指向视频驱动程序并设置某些配置选项，特别是分辨率设置。

运行 Linux 并不需要 X Windows，而且非常消耗 CPU。在真正的专用服务器上，你通常不会安装 X Windows。如图 2.14 所示，除非你已经包含了 X Window 软件包以及至少一个桌面环境（Gnome 或 KDE），否则你应该选择**跳过 X 配置**选项。

以下是在基础系统上安装 X Window 的粗略概述。该系统通常能够探测显卡，除非它是非常新的技术硬件，但通常情况下，大多数已视频芯片组会被自动发现，就像在 Windows 中一样。在这种情况下，请记住避免使用任何 Windows 专用的硬件。

## X 服务器软件

每种类型的硬件都有不同的 X Window 软件包：通用 VGA 或 SVGA；以及针对著名的 S3、ATI 型硬件的芯片组。如果探测成功，将显示显卡名称和芯片组。如果探测失败，你可以从提供的列表中选择硬件。通用显卡通常基于 S3、ATI 等标准视频芯片组之一。如果无法探测（在笔记本电脑上尤为如此），你应该选择通用 SVGA 驱动程序，然后选择通用多同步显示器（Generic Multi-sync Monitor）。这应该适用于大多数基础硬件，但不能保证。有一个网站专门为各种笔记本电脑提供配置文件，这些笔记本几乎总是包含某些无法正常探测的专有硬件。你可以从以下网站获取更多信息：
