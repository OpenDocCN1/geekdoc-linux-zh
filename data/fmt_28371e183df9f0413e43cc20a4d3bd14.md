
`cachedir`提到`yum`用作缓存内存存储临时文件的目录。`keepcache`值如果为0，会在成功安装后删除文件头和缓存文件，值为1则保留文件。这是`yum`写入日志信息的地方。`gpgcheck`选项如果为1，则强制`yum`检查gpg密钥。`yum`检查gpg密钥。`[root@localhost ...]ls /etc/yum.repos.d`

| update | 更新软件包 | `yum` |
| check-update | 检查是否有可用更新 | `yum` |

## 4.4. 使用 make

软件软件包以`tar.gz`、`tgz`和`tar.bz2`格式提供。这些包需要解压缩，然后使用`./configure`、`make`和`install`命令进行源码构建。

使用以下命令解压缩`tar.gz`扩展名的包：

```
gunzip realplay.tar.gz
```

这将形成`realplay.tar`

然后使用命令

```
tar xvf realplay.tar
```

生成目录`realplay`。

这两个命令可以合并为一个命令：

```
tar xvfz realplay.tar.gz
```

生成目录`replay`。

如果源码是`tar.bz2`格式，则使用命令：

```
bzip2 -d replay.tar.bz2
```

它将形成目录`replay`。

在解压缩包后，将终端的工作目录更改到`replay`目录。

现在运行以下命令安装软件包：

```
./configure
```

```
make
```

```
make install
```

`./configure`命令为系统平台配置软件包。

`make`命令为系统制作软件包。

`make install`命令将软件包安装到系统上。

# 5. 用户和组管理

## 5.1. 概述

Linux是一个多用户操作系统。在安装期间，必须创建`root`用户账户（`root`用户是系统的管理员）。系统会要求创建一个额外的用户账户（用户可以选择创建或跳过）。安装后也可以创建用户账户。每个用户都属于一个组账户。安装后也可以创建组账户。

## 5.2. 创建用户账户

`useradd`命令用于创建新用户。它也用于在创建新用户时更新默认值。`useradd`命令的一般格式为：

```
useradd user-name
```

```

```
