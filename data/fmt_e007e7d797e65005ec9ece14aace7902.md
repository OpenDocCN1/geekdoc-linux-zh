在所有设置异常的方法中，`grep` 似乎出现得最多。请避免使用 `grep` 的错误！`EXCEPTIONS` 文件中的两个字段是 `/mount_point` 和 `NEW_MAX` 值。直觉上是对 `/mount_point` 进行 `grep` 查询，但如果 `/mount_point` 是根目录怎么办？如果你使用 `grep` 且该条目不是异常文件的第一项，那么你会在错误的条目上得到模式匹配，然后使用 `NEW_MAX` 来判断挂载点是否已。如果你对异常文件进行 `grep` 查询，你每次都会得到第一项的匹配。列表 5.3 显示了代码是如何犯下这个错误的：

```
while read FSDEVICE FSMOUNT
do
  # 如果存在 % 号，则去掉 % 号
  VALUE=$(echo $VALUE | sed s/%//g) Remove the % sign
  if [ -s $EXCEPTIONS ]; # 我们有非空文件吗？
  then
    # 在文件中查找 $FSMOUNT
    # 错误代码，不要使用 grep 犯这种错误
    cat $EXCEPTIONS | grep -v "#" | grep $FSMOUNT
    if [ -eq 0 ]; # 找到了！
    then
      if [[ $FSNAME == $FSMOUNT ]]; # 安全检查
      then
        NEW_MAX=$(echo $NEW_MAX | sed s/%//g)
        if [ $VALUE -gt $NEW_MAX ]; # 使用 NEW_MAX
        then
          echo "$FSDEVICE on $FSMOUNT is ${VALUE}%" >> $OUTFILE
        fi
      elif [ $VALUE -gt $FSMAX ]; # 不在 EXCEPTIONS 文件中
      then
        echo "$FSDEVICE on $FSMOUNT is ${VALUE}%" >> $OUTFILE
    else # 无异常文件...使用脚本默认值
      if [ $VALUE -gt $FSMAX ];
      then
        echo "$FSDEVICE on $FSMOUNT is ${VALUE}%" >> $OUTFILE
      fi
    fi
done < $WORKFILE
```

**列表 5.3** 使用 `grep` 的错误方法。

列表 5.3 中的代码看起来似乎是可以运行的，而且在某些时候确实有效！为了规避 `grep` 引入的错误，我们需要设置一个函数，对异常文件中的每个条目进行精确匹配。

现在让我们来看这种新技术。我们想写两个函数：一个用于加载不带注释行的 `EXCEPTIONS` 文件（以 `#` 开头的行），另一个用于对异常文件中的每个条目进行精确匹配。

这是一个简单的函数，用于加载 `EXCEPTIONS` 文件并排除注释行。通过 `grep -v` 排除以 `#` 开头的行，并重定向到 `EXCEPTIONS`。

```
function load_EXCEPTIONS_file
{
  # 排除以 # 开头的行
  cat $EXCEPTIONS | grep -v "^#" | sed '/$/d'
}
```

在 `check_exceptions` 函数中，我们使用 `grep -v` 排除以 `#` 开头的行，并使用 `sed` 过滤掉空行，重定向到 `EXCEPTIONS`。

```
function check_exceptions
{
  # set -x # 注释以调试此函数
  while read FSNAME_NEW_MAX # 在循环中读取数据
  do
    if [[ $FSNAME == $FSMOUNT ]]; # 挂载点匹配
    then
      # 如果存在 % 号，则去掉 %
      NEW_MAX=$(echo $NEW_MAX | sed s/%//g)
      if [ $VALUE -gt $NEW_MAX ]; # 使用 NEW_MAX
      then # 超过阈值...返回 "0"
        return 0 # 超过阈值 - 返回 0
      else # 在阈值范围内
        return 2 # 正常
      fi
    fi
  done < $DATA_EXCEPTIONS # 从数据文件中读取
  return 1 # 未找到条目
}
```

`check_exceptions` 函数在主循环中被调用，如果挂载点超过 `NEW_MAX%` 则返回 `0`；如果挂载点在阈值范围内返回 `2`；如果在异常文件中未找到条目，则返回 `1`。该函数返回的返回值决定了是否将输出结果到文件中。
