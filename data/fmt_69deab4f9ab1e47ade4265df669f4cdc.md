# Framebuffer

`framebuffer` 是图形缓冲区的抽象。它代表视频硬件的缓冲区，并允许应用程序通过定义良好的接口访问硬件，因此软件不需要了解底层接口。来自 Geert 的 `framebuffer.txt` 在内核源码 `framebuffer-HOWTO` `http://www.tldp.org/LDP/Linux–Dictionary/html/index.html`

# freeamp

可扩展跨平台音频播放器 FreeAmp 是一个可扩展的跨平台音频播放器。它具有优化的 GPL 引擎版本，使其成为最快和声音最好的播放器之一。FreeAmp 在整洁易于使用的界面中提供了许多常用功能。某些功能包括：播放所有 MPEG 1、MPEG 2 和 MPEG 5 编码的文件。支持 Vorbis 或 Shout 的变比特率编码技术。通过互联网通过 HTTPcast (Shoutcast) 或 Icecast 流播放歌曲：使用 RMP (Realukebox) 解码器保存 Icecast 流。音乐播放器和播放列表编辑器：一个支持下载文件的内置下载管理器。来自 Debian 3.0 APT `http://www.tldp.org/LDP/Linux-Dictionary/index.html`

# freebirth

低音合成器/采样播放器/序列器，类似于 Rebirth。freebirth 是一个用于 Linux 系统的自由软件合成器/序列器/采样播放器。它目前是 v.3.2 版本。低音合成器虽然普通，但在作者看来，它具有更强的音效能力：三个振荡器（锯波、正弦波、方波）——每个振荡器的相位偏移。独立的滤波器和振幅效果：每个振荡器的独立调音——两种效果（混响和延迟）

# freefem

# freenet
