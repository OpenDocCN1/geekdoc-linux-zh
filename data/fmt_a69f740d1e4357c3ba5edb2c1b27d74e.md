## 第93章 安腾指令

来说，安腾 (Itanium)处理器几乎是失败。但是Itanium (IA64)架构非常研究。乱序执行（OoO）侧于CPU指令的片段，再把重组后的指令到并行。而特尔（Intel）架构的并行技术（Explicitly Parallel Instruction Code, EPIC），让编译器这种并行技术的编译器因为复杂而引起了争议。本章从Linux内核取了部分。Intel和HP的开发者针对常见指令进行了划分，从而得出了指令类型（即指令模板）。CPU据此将指令分为基本类型（basic types），基本类型又分为带有停止位的指令和不停止位的实例。例如，0类指令叫做`MFII`指令，依次由内存读写操作（`M`）和两类整数操作（`II`）构成；最后一种，`0xd1`类，又叫`MFB`类，依次由内存读写操作（`M`）、浮点数操作（`B`）构成。如果汇编器在指令槽（instruction slot）上没有操作指令，那么它可能在这些位置上插入`nop`。在人工汇编中，`m`代表内存。

## 指令清单93.1 Linux kernel 3.2

```c
#define TEA_ROUNDS 32
#define TEA_DELTA 0x9e37b9

static void tea_encrypt(struct crypto_ctx *tfm, u8 *dst, u8 *src)
{
	u32 y, z, n, sum = 0;
	u32 k0, k1, k2, k3;
	struct crypto_ctx *ctx = tfm;
	const le32 *in = src;
	le32 *out = dst;

	y = le32_to_cpu(in[0]);
	z = le32_to_cpu(in[1]);

	k0 = ctx->KEY[0];
	k1 = ctx->KEY[1];
	k2 = ctx->KEY[2];
	k3 = ctx->KEY[3];

	n = TEA_ROUNDS;
	while (n-- > 0) {
		sum += TEA_DELTA;
		y += ((z << 4) + k0) ^ (z >> 5);
		z = ((y << 4) + k2) ^ (y >> 5) + k3;
	}
	out[0] = le32_to_cpu(y);
	out[1] = le32_to_cpu(z);
}
```
