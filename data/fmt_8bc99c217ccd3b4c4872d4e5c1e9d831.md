
3. 请勿实际执行此命令：你认为 `rm -ri /*` 会做什么？（诚实地说，不要尝试这样做！）

它将删除你的用户账户可写的文件和目录。这包括任何网络文件系统。

4. 除了使用 `-i` 之外，是否可能防止 `mv` 覆盖目标文件？

可以，`-n` 或 `--no-clobber` 选项防止 `mv` 覆盖文件。

```bash
$ cat a

  a

$ cat b

  b
```

5. 解释命令 `cp -u`。

`-u` 只在源文件比目标文件新或目标文件不存在时进行复制。

```bash
$ mv -n a b

$ cat b

b
```

`-u` 选项导致 `cp` 只在目标文件缺失或比源文件旧时才复制文件。

### 引言

压缩用于减少一组特定数据所占的空间。压缩通常用于减少存储文件所需的空间。另一种常见方法是减少通过网络连接发送的数据量。

压缩通过替换数据中的重复模式来工作。假设你有一本小说。有些单词非常常见但包含多个字符，例如“the”这个词。如果你将这些常见的多字符单词和模式替换为单字符替换，就可以显著减小小说的大小。例如，将“the”替换为文中其他地方未用过的希腊字母。数据压缩算法与此类似，但更为复杂。

压缩分为两种类型：无损和有损。用无损算法压缩的内容无法解压回原始形式。用有损算法压缩的数据通常用于图像、视频和音频，在这些情况下，质量损失对人类是不可感的、与上下文无关，或者损失相对于节省的空间或网络吞吐量是值得。

# Linux Essentials (版本 1.6) | 3.1 在命令行上归档文件

归档工具用于将文件和目录打包成单个文件。一些常见用途包括备份、打包软件代码和数据保留。

归档和压缩通常结合使用。某些归档工具默认就会压缩其内容。另一些则可以选择压缩其内容。如果你想压缩内容，某些归档工具必须与独立的压缩工具配合使用。

Linux 系统上最常用的归档工具是 `tar`。大多数 Linux 发行版都带有 GNU 版本的 `tar`，因此这是本课程将涵盖的内容。`tar` 本身管理文件的归档，但不对其进行压缩。

Linux 上有很多压缩工具可用。一些无损工具是 `bzip2`、`gzip` 和 `xz`。你会在大多数系统中都找到这三者。你可能会遇到没有安装 `xz` 或 `bzip` 的奇特或极精简系统。如果你成为 Linux Linux 用户，你可能会遇到使用这三种工具压缩的文件。它们都使用不同的算法，因此某些存在权衡。如果你使用高压缩率，压缩和解压文件将花费更长时间。这是因为高压缩需要更多工作来寻找更复杂的模式。所有这些工具都可以但不创建包含多个文件的归档文件。

Windows 系统通常不提供独立的压缩工具。Windows 的归档和压缩工具通常是整合的。如果你有共享文件的 Linux 和 Windows 系统，请记住这一点。

Linux 系统也拥有处理 Windows 系统常用的 `.zip` 文件的工具。它们被称为 `zip` 和 `unzip`。这些工具在所有系统上并不是默认安装，因此如果你需要使用它们，可能必须手动安装。幸运的是，它们通常可以在发行版的软件包仓库中找到。
