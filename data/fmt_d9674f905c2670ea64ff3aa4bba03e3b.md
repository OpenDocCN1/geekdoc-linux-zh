
# 查找“大”文件

```bash
find $SEARCH_PATH -size +5000000c -print
```

`+`（加号）表示大于，`c` 表示字节。注意在上命令中，我们指定了在变量 `$SEARCH_PATH` 中搜索的路径。`find` 命令要求在第一个参数中定义搜索路径。

```bash
# set -n          # 取消注释以不执行即可检查语法
# set -x          # 取消注释以调试此脚本

SCRIPT_NAME=$(basename $0)

############################################################

function usage
{
    echo "\n************************"
    echo "\n用法: $SCRIPT_NAME [文件大小(单位：MB)]"
    echo "\n示例: $SCRIPT_NAME 5"
    echo "\n将在当前目录下查找大于并等于 5 Mb 的"
    echo "\t文件..."
    echo "\n\t...正在退出..."
    echo "\n************************************"
}

############################################################

function trap_exit
{
    echo "\n*"
    echo "\n\n* 捕获到信号正在退出...*"
    echo "\n\n********************************************\n"
}

############################################################

# 设置陷阱以退出。请记住 - 无法捕获 KILL -9 信号
trap 'trap_exit; exit 2' 1 2 3 15

############################################################

# 检查参数数量是否正确
if [ $@ -ne 1 ]; then
    usage
    exit 1
fi

############################################################

# 检查是否为整数
case $1 in
+(([0-9])) : # 无空操作 -- 什么都不做！
;;
*) usage
exit 1
;;
esac

###########################################

# 检查是否大于零的整数
if [ $1 -lt 1 ]; then
  usage
  exit 1
fi

###########################################

# 在此定义并初始化文件和变量...
THISHOST=$(hostname) # 本机的主机名
DATEAMP=$(date +'%Y%m%d:%H:%M:%S') # 时间戳

SEARCH_PATH=$(pwd) # 要搜索的顶层目录（当前目录）
MEG_BYTES=$1 # 触发文件大小的 MB 数值

OUTFILE="/tmp/largefiles.out" # 输出用户文件
cat /dev/null > $OUTFILE # 初始化为空文件

HOLDFILE="/tmp/hold_file.out" # 临时存储文件
cat /dev/null > $HOLDFILE # 初始化为空文件

###########################################

# 准备输出头部
echo "\n正在查找大于 ${MEG_BYTES} 的文件，开始于"
echo "\n=> 等待搜索结果..."
echo "\n大文件搜索结果: >> $OUTFILE"
echo "\n主机主机: ${THISHOST} >> $OUTFILE"
echo "\n搜索顶层目录: >> $OUTFILE"
echo "\n=>$SEARCH_PATH >> $OUTFILE"
echo "\n搜索时间: ${date}" >> $OUTFILE
echo "\n按修改时间排序的搜索结果: >> $OUTFILE"

###########################################

# 在 $SEARCH_PATH 开始搜索大于 $MEG_BYTES 的文件
find $SEARCH_PATH -type f -size +${MEG_BYTES}000000c \
-print > $HOLDFILE

# 找到了多少文件？
if [ -s $HOLDFILE ] -eq 0; then
  NUMBER_OF_FILES=$(cat $HOLDFILE | wc -l)
  echo "\n找到的文件数量: => $NUMBER_OF_FILES\n" >> $OUTFILE

  # 追加到输出文件的末尾...
  ls -lt $HOLDFILE >> $OUTFILE

  # 显示按时间排序的输出文件...
  more $OUTFILE

  echo "\n搜索结果存储在 => $OUTFILE"
  echo "\n搜索完成... 正在退出...\n"
else
  cat $OUTFILE # 显示头部信息！
  echo "\n在搜索路径中没有找到大于"
  echo " ${MEG_BYTES}Mb 的文件\n"
  echo "\it...正在退出...\n"
fi

rm -f $HOLDFILE # 删除临时文件
```

让我们更详细地查看 `findlarge.ksh` shell 脚本。我们在脚本中添加了两个函数。我们需要一个 `usage` 函数，并且在按下 `CTRL-C` 时，我们添加了一个 `trap_exit` 函数。该陷阱会在退出信号 1、2、3 和 15 时执行，并在以返回代码 2 退出之前显示“EXITING ON TRAPPED”。如果我们之前讨论的三个数据测试中的任何一个失败，将执行 `usage` 函数，脚本以返回代码 1 退出，表示脚本错误。

在下一个代码块中，我们为主机名、日期/时间戳和搜索路径（当前目录！）使用了 `find` 命令。所有这些系统数据都用于 `$OUTFILE` 的文件头部。对于搜索路径，我们本可以使用一个点 `.` 来指定当前目录，但这种简写表示法会导致报告中出现相对路径。以正斜杠 (`/`) 开头的完整路径提供了更清晰的信息，并使报告更易于阅读。

## 优化建议

- 3. 当搜索大型文件系统时，可能需要长时间才能完成。为了给用户提供搜索过程正在进行的反馈，你可能想添加第 4 章中研究过的进度指示器。使用两种进度指示器比较合适：旋转线和一系列点。详情请参阅第 4 章。
- 4. 当我们指定搜索值时，其实只是在用户提供的指示值后面添加了零。但我们回到了一个基础问题：1 MB 等于 1,000,000 还是 1,024,000？因为系统管理员可能不是阅读报告的人（也许是经理），所以我使用了数学上的 1,000,000，而不是系统报告的 2 的幂值。这实际上是一个取决于个人喜好的选择，你可以根据需要决定要使用的数值。通过简单的数学计算（将用户提供的值乘以 1,024,000），可以很容易地更改该值。
- 5. 如果你需要在文件系统满后查找新创建的文件，可以添加以下命令作为交叉引用，以找到文件系统写满的真实原因：

```bash
find $SEARCH_PATH -mtime 1 -print
```

此命令将找到在过去 24 小时内修改或创建的所有文件。你可以将此输出重定向到文件中，并进行交叉引用，以分离出真正导致文件大小写满的文件和用户。
