
使用`ed`打开文件编辑后，当前行是文件的最后一行。要查看当前行号（`ed`应用更改的行），使用`=`命令：

```
:=
```

要看到如下结果：

```
8
```

此输出告诉你`fstab`文件有8行。（你的系统`/etc/fstab`文件可能有不同的行数，在这种情况下你可以使用`l,$p`命令查看行）：

```
l,$p
```
