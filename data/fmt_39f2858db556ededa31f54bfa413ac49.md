# 链反应（物理学）

重原子核发生分裂（称为核裂变）后会释放出一代中子。该过程释放出约 200 MeV (3.2 × 10⁻¹ J) 的能量，形式为包括两个或三个中子的粒子。其中这一代中子被裂变物种（$^{235}$U、$^{238}$U、$^{239}$Pu）捕获，从而引发下一代的裂变。

主要由钙质生物和微生物的遗骸组成。大多数海洋生物生活在海洋和近岸水域，如球石藻（藻类）和浮游生物（原生动物）。可能存在较大的化石，但含量较少。钙质生物的主体骨骼遗骸沉积在深度小于 40 米（或 13,000 英尺）的海床上（碳酸盐在更深的水层沉积会减缓）。典型的沉积速率在数百万间变化。该地层的形成还取决于粘土等稀释材料的沉积。

# 蓝铜矿

蓝铜矿的化学成分为 $CuSO_{4}\cdot5H_{2}O$。蓝铜矿呈蓝绿色晶体状。它是高度无水的。莫氏硬度为 2.5 到 5，比密度为 2.8。它溶于水且味道酸，但质脆。它在空气中会脱水变成白色粉末。尽管它在某些地区存在，但通常不是重要的天然矿石来源。其存在在美国西部已有记录。

这种颜色和成分纯度的独特组合，被许多早期时期用于在板上书写。蓝铜矿还用于水泥颜料、肥料、磨料剂以及化妆品中。

# 玉石

玉石是石英（二氧化硅）的一种细颗粒变体。其纤维结构由隐晶质结构组成。根据颜色可分为不同的亚种；某些自古以来就被珍视为宝石材料，如红玉髓（深红色至珊瑚色）、橙玉髓（橙红色至棕红色）和碧玺石（苹果绿）。

玉石呈现圆形、微晶体或葡萄状的表面，是结节状玛瑙的主要成分。莫氏硬度为 6.5–7。比密度为 2.57–2.6。

大多数玉石由汇集到表面的细层组成。玛瑙是玉石的一种常见且重要的变体，具有颜色和透明度不一的条纹。在某些情况下，玛瑙的种类根据材料形成时的空腔形状呈弯曲和同心状。参考玛瑙。

# 方解石

方解石是一种在热液系统（217°F 或 107°C）中结晶的白色矿物。晶体细小且稀有，通常具有高光泽和美丽的色泽。最常见的是，这种矿物呈细粒块状，具有金属光泽和浅灰色，与铜发生改变时产生。它发现于硫化铜的氧化。

# 黄铁矿

黄铁矿是一种采铜矿物 $CuFeS_{2}$。晶体细小呈块状，具有黄褐色的金属光泽和不定的色调。莫氏硬度为 3.5 到 4.0。

黄铁矿是最主要的铜矿石。它发现于许多国家（比格姆矿，智利；科罗拉多州；德国；英国；匈牙利；法国；萨克森州；俄罗斯；里约；内华达州；阿拉斯加州；田纳西州，美国西南）。

# 粉笔

广义上指任何软、脆或风化的细粒石灰岩；然而，该术语主要局限于深海（生物源）石灰岩。它通常是细粒、浅色的碳酸盐石灰岩。

# 变色龙

变岩指的是非洲和马达加斯加属于变色科的所有 80 种中小型蜥类。变色龙（Anoles）属于另一个蜥类科，变色蜥科。

变色龙也是物种种类最多的，是一个典型的例子。变色龙是树栖的。变色龙具有变色能力。变色龙的四肢适应了树栖生活。变色龙的眼睛很大。变色龙的变色可以独立移动很远距离。变色龙的舌很长，用于捕食昆虫。变色龙是卵繁殖的。变色龙在巢中产卵。

# 灌木丛 (Chaparral)

在历史上，人们相继利用魔法、宗教和科学，试图在一个看似混乱无意义的世界中感知秩序和意义。这种对秩序的追求在17世纪达到了顶点，当时动力学提供了一个关于整个宇宙的有序、确定性的观点，体现在 P.S. 拉普拉斯的陈述中：“我们知道的现在状态是由于其过去的影响，也是由于其存在的原因。”

但如果拉普拉斯和牛顿的机制并非偶然，那么很难解释赌博游戏的不可预测性，或者更广义地说，在许多自然系统中观察到的不可预测的随机行为。这种行为的常见例子包括香烟产生的烟雾、从天花板掉落的柱体并突然爆发成湍流（湍流）；以及气压的不规则波动。

在更技术性的层面上，牛顿观点在1900年左右灭亡了。问题在于，许多系统表现出的行为对初始条件非常敏感，以至于初始状态受到轻微扰动，从意义上说，预测虽然在数学上是有效的，但失去了意义。我们发现混沌轨道的特性是：它们与随机事件无法区分，尽管从统计学上讲，它们是严格确定的、最常见的行为。

经典力学：确定性随机过程。

混沌的一个方面是地球生命的演化。如果没有对几个世纪以来出现的每一次危机的预判，加上对整个过程中可能的生态位的预判，这种演化是不可能的。然而，自然通过混沌演化并利用机会的深处。随机突变在混沌中提供了足够的变异，而自然选择选择了合适的变异。参见[进化](EVOLUTION)。

另一个例子涉及人体在防御所有可能的入侵者时所面临的问题。在自然界中，混沌似乎是最经济的解决方案。当谈到瞬态或病毒时，身体防御是通过反馈回路随机产生的，该回路通过其卓越性指示了正确的策略。巨大的混沌允许自然繁荣并找到有效的处理方法。

另一个需要考虑的问题是天气或气候的预测。这两个系统都是混沌的，只能以每年为单位进行多或少的预测。通过对天气气候的混沌本质进行建模，可能准确确定概率分布，尽管不一定达到那种精度，因为从现在两个月后有90%的失败率。通过混沌理论来选择相关的分布。参见[预测](PREDICTION)。

物理系统表现出从秩序到混沌的转变，如图所示，或包括心脏攻击、癫痫、躁狂郁症和精神分裂症。心理学家在混沌中挣扎生存，他们需要学习这些人类问题是可以局部的。

归于本质，混沌和噪声本质上是同一个东西：孤立系统中的随机性；没有随机性是与外界隔绝的。如果源头是混沌形成的复合系统，就会产生混沌。参见[电气](ELECTRICAL)。[J.F]。

灌木丛 (Chaparral) 一种以矮植物（0.3到1-3米）为特征的植被，具有严酷、坚硬、不规则的分枝以及小型、波状的常绿叶。该术语再次指的是西班牙灌木丛，它是北美洲特有的。这种植被仅出现在山地到坡地地形区域，并连续分布。老中海环境等同于在南非、中国和澳大利亚西部地中海气候地区的类似植被，这些地区夏季干燥，凉冷季节降水量最大。这五个具有地中海气候地区的植物群总和如下。

加州真正的灌木丛的特征植物是伞叶岩鼠属、叶石属、矮叶菊属、山毛梅属、毛花菜、直立毛花菜和木杨属，加上许多鼠尾属和锥果属等特有种。这些植物形成了该植被的系统发育。这是一种密集的、不形成的常绿植物，具有硬叶和深根。

从生态学上讲，灌木丛出现在夏季炎热干燥的气候中，但冬季并不冷得多，雨少或无雨，且降水过剩导致土壤养分流失。植物是错位的。
