
```bash
function ping_host()
  HOST=$1 # 从 ARG1 获取要 ping 的主机名。
  PING_COUNT=3
  PACKET_SIZE=54

  # 下面的 case 语句根据 Unix 变体执行
  # 正确的 ping 命令

  case $(uname) in

    AIX|Linux)
      ping -c$PING_COUNT $HOST 2>/dev/null
      ;;

    HP-UX)
      ping $HOST $PACKET_SIZE $PING_COUNT 2>/dev/null
      ;;

    SunOS)
      ping -s $HOST $PACKET_SIZE $PING_COUNT 2>/dev/null
      ;;

    *)
      echo "\nERROR: 不支持的操作系统 - $(uname)"
      echo "\n\t...正在退出...\n"
      exit 1
  esac
```

shell 脚本的主体必须提供要 ping 的主机名。这通常通过 `while` 循环完成。

## 在文件中高亮特定文本

这里展示的技巧在显示整个文件的同时，使用反转视频（reverse video）高亮文件中的特定文本。在反转视频部分，我们必须使用 `sed` 语句配合 `put` 命令进行一些命令替换。在我们指定 `new_string` 的地方，我们将使用命令替换添加对反转视频的控制，一个用于高亮，一个用于关闭。当添加命令替换后，我们的 `sed` 语句如下：

```
sed s/current_string/$(put smso)new_string$(put rmso)/g
```

在这种情况下，`current_string` 和 `new_string` 将是相同的，因为我们只想高亮现有文本而不改变它。我们还希望在下一步中将字符串赋值给变量：

```bash
sed s/"STRING$\$(put smso)""STRING$\$(put rmso)/g
```

注意变量 `"STRING"` 外围的引号。不要忘记在变量周围加上双引号！

作为一个使用命令替换的实验，尝试下一个这个命令语句来高亮任何 Unix 机器上 `/etc/hosts` 文件中的主机名：

```bash
cat /etc/hosts | sed s/'hostname`$(put smso)`hostname`$(put rmso)/g
```

## 保持打印机持续打印

在大型商店中保持打印机启用有时会让人难以应付。有两种技术可以让打印机持续打印。一种技术用于 AIX “经典”打印机子系统，另一种用于 System V 打印。

### AIX “经典”打印机子系统

要保持 AIX “经典”打印机系统队列运行，使用以下命令之一。

```bash
enable $(enq -AW | tail +3 | grep DOWN | awk '{print $1}') 2>/dev/null
```

或者

```bash
enable $(lpstat -W | tail +3 | grep DOWN | awk '{print $1}') 2>/dev/null
```

## 捕获大于 MEG 的文件列表

是谁填满了文件系统？如果你想快速查找大文件，请使用以下语法。

```bash
# 从 $SEARCH_PATH 开始搜索大于 >MEG_BYTES 的文件
#
HOLD_FILE=/tmp/largefiles.list
MEG_BYTES=$1 # 使用当前目录
SEARCH_PATH=$(pwd)
```

```bash
find $SEARCH_PATH -type f -size +($MEG_BYTES)000000 -print $HOLDFFILE
```

注意，`-size` 参数之后的 `find` 命令中有一个加号 (`+`) 前缀文件，并作为后缀添加。这种组合指定了大于 `$MEG_BYTES`（以字节计算）的文件，而不是块。

## 捕获用户的按键

在许多大型商店中，有时需要监控用户的操作。你可能甚至想审计任何拥有系统 root 权限或如 oracle 等管理类型账户的按键。现场的承包商可能会带来特殊的安全风险。通常会有一两个承包商在现场停留一段时间，用于安装、故障排除和对人员进行培训。


```bash
chown $LOGNAME $LOGDIR/$LOGFILE # 让用户在脚本执行期间拥有文件
chmod 600 $LOGDIR/$LOGFILE # 修改文件权限
```

## 测试空变量

没有赋值任何内容的变量有时很难处理。以下测试将确保变量要么为空（Null），要么已赋值。双引号非常重要，且必须使用！

```
VAL= # 创建一个 NULL 变量

if [[ -z "$VAL" && "$VAL" = '' ]];
then
    echo "The VAL variable is NULL"
fi
```

或者

```bash
VAL=25

if [[ -z "$VAL" && "$VAL" != '' ]];
then
    echo "The VAL variable is NOT NULL"
fi
```
