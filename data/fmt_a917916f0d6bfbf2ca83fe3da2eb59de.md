`procmail` 过滤器可以用于过滤邮件、创建邮件列表、预处理邮件、选择性转发邮件等。随附的程序（以及其他）实现了自动回复和拆分邮箱。`procmail` 在 UNIX 和 Linux 机器上已经存在多年，是一个健壮的系统，设计即使在最糟糕的情况下也能工作。更多信息可以在 `/usr/share/doc/procmail[<version>]` 目录和主页中找到。

# 关于邮件礼仪的说明 (A note on E-mail Etiquette)

如今有些人人似乎认为电子邮件信息不应该是正式的。当然，这取决于具体情况。如果你是在给一个你不认识的人写信，最好是保持一些距离，就像你写传统信件一样。不要忘记：你不认识的人可能是男性也可能是女性……

# Web (Web)

## Apache Web 服务器

Apache 是目前最流行的 Web 服务器，被超过一半的互联网服务器使用。大多数 Linux 发行版都包含 Apache。Apache 的优势包括它的模块化设计、SSL 支持、稳定性和速度。在适当的硬件和配置下，它可以支持最高的负载。

在 Linux 系统上，服务器配置通常在 `/etc/httpd` 完成。最重要的配置文件是 `httpd.conf`。在适当的硬件和配置下，它可以支持最高的负载。

## FTP 是不安全的！

除非你清楚自己在做什么，否则不要对非匿名登录使用文件传输协议（FTP）。你的用户名和密码可能会被网络中恶意的用户捕获！请改用安全文件传输协议（Secure FTP）；`sftp` 程序包含在安全外壳（Secure Shell）套件中，请参见“安全远程复制”章节。
