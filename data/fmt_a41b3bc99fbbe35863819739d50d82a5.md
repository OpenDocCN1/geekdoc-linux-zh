
开源软件受公共许可的保护。这些许可防止了商业公司通过添加少量的自己的修改、对这些更改拥有版权并将软件作为他们自己的产品销售来获取开源软件的控制。最流行的许可是由自由软件基金提供的 `GNU 公共许可 (GNU Public License)`。这是 Linux 发行时遵循的许可。`GNU 公共许可`保留了版权，免费许可软件，并要求软件及其对它的任何修改必须始终是免费可用的。还创建了其他公共许可以支持不同类型的开源项目的需求。`较级 GNU 公共许可 (LGPL)`允许商业应用程序使用 GNU 许可软件库。Netscape 在 `Netscape 公共许可 (NPL)`下提供了其 Netscape Communicator 软件，该许可了直接对 Netscape 源代码进行的修改。对 Netscape 的添加内容受 `Mozilla 公共许可`覆盖。`QT 公共许可 (QPL)`允许开源开发者使用对 KDE 桌面至关重要的 QT 库。你可以在 `www.opensource.org` 找到完整的列表。

Linux 目前根据自由软件基金提供的 `GNU 公共许可`受版权保护，通常被称为 GNU 软件（参见 `www.gnu.org`）。只要是免费分发给他人，GNU 软件就是免费分发的。GNU 软件既可靠又有效。与你的 Linux 发行版一起带的许多流行的 Linux 实用程序包括 GNU C++ 和 Lisp 编译器、Vi 和 Emacs 编辑器、BASH 和 TCSH 壳，以及 Ghostscript 文档格式器。此外，还有许多根据 `GNU 公共许可 (GPL)`许可的开源软件项目。这些许多软件应用程序可以在不同的互联网站点获得，并列在表 1-2 中。第 4 章和第 26 章详细描述了从互联网站点下载软件应用程序并将其安装到系统上的过程。

根据 `GNU 通用公共许可`的条款，原作者保留版权，只要包含源代码，任何人都可以修改并重新分发软件。出售软件或免费赠送软件没有任何限制。一个发行者可以对软件收费，而另一个可以免费提供。

## 互联网服务器

Linux（以及 UNIX 系统）最重要的特性之一是其的一系列互联网客户端和服务器。互联网是在 UNIX 系统上设计和开发的，而互联网客户端和服务器（如 FTP 和 Web 客户端）最初是在 BSD 版本的 UNIX 上实现的。互联网的前身 DARPANET 是为了为了连接美国全范围内不同大学的 UNIX 系统而建立的。Linux 包含了一套完整的互联网客户端和服务器，包括邮件、新闻、FTP 和 Web，以及代理客户端和服务器。适用于 Linux 的互联网服务器软件站点列在表 1-4 中。其中大部分已经包含在随本书附的 Red Hat CD-ROM 中；不过，你可以直接从服务器的网站获取新闻、文档和最新发布。
