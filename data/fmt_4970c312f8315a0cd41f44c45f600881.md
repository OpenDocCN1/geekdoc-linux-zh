
- 服务器端不存储状态：你可以离开座位并在另一台机器上恢复，从离开的地方继续。当你运行 PC 服务器时，如果 PC 崩溃或重启，你运行的所有应用程序都会停止。而使用 VNC，它们会继续运行。
- 简单直接，无需安装，需要时可以从软盘运行。
- 使用 Java 客户端，平台无关，运行在所有支持 X 的设备上。
- 可共享：一个桌面可以在多个查看器上显示。

## 日志文件

## 入侵检测

入侵检测系统（IDS）旨在捕获可能绕过防火墙的行为。它们既可以设计为捕获正在进行的活跃入侵尝试，也可以在入侵成功后进行事后检测。在后一种情况下，虽然要防止任何损害已经太晚了，但我们至少对问题有了早期的警觉。IDS 有两种基本类型：保护网络和保护个人。

对于主机型 IDS，这是通过监控文件系统的实用程序实现的。如果系统文件发生了某种变化，但它们本不应该发生变化，这就是情况出现异常的明显迹象。任何进入并获得访问的人可能都会对系统进行某些修改。这通常是他们做的第一件事，要么是为了留后门以便回来，要么是为了对某些系统发动攻击。可以使用 `triwire` 监控系统，该系统记录在 Tripwire 开源项目网站 [http://www.tripwire.org] 上。

网络入侵检测由一个系统处理，该系统可以看到通过防火墙的所有流量（而不是通过端口扫描器，扫描器会显示可用端口）。`Snort` [http://www.snort.org] 是此类程序的开源示例。Whitehats 拥有一个开放入侵检测数据库 `arachNIDS` [http://www.whitelats.com]。

## 更多提示

你应该记住的一些通用要点：

- 不要允许 `root` 登录。UNIX 开发者在二十多年前就发明了 `su` 命令来提供额外的安全性。
- 直接访问 `root` 总是危险的，并且容易受到人为错误的影响，无论是允许 `root` 登录还是使用 `su` 命令。与其使用 `su`，不如使用 `sudo` 仅执行你所需的权限的命令，然后返回到你自己的环境。
- 认真对待密码。使用密码。定期更改你的密码。
- 尝试始终使用 `SSH` 或 `SSL`。避免使用 `telnet`、`FTP` 和电子邮件客户端以及其他在网络上使用未加密密码的客户端程序。安全不仅是保护你的电脑，也关保护你的密码。
- 使用 `quota` 和 `limit` 限制资源。
- 发给 `root` 的邮件应该送达给、或至少由真实人员阅读。
- SANS 学院 [http://www.sans.org] 提供了更多按发行版分类的技巧，并带有邮件列表服务。
- 检查新软件的来源，从受信任的地方/网站获取。在安装之前验证新包。
- 使用非永久性连接时，在不再需要时将其关闭。
- 将私有服务运行在奇数端口，而不是黑客可能预期期的端口。

## 我被入侵了吗？

- 了解你的系统。一段时间后，你几乎可以感觉到事情正在发生。

如何判断？这是一份可疑事件清单：

- 神秘的开放端口、奇怪的进程。
- 系统工具（常用命令）行为异常。
- 登录问题。
- 日志文件损坏或丢失，`syslog` 守护进程行为异常。
- 处于异常模式的接口。
- 意外修改的配置文件。
- `shell` 历史文件中异常条目。
- 未识别的临时文件。

## 入侵后的恢复

简而言之，保持冷静。按以下顺序采取行动：

- 将机器与网络断开。
- 尝试尽可能多地找出你的安全是如何被破解的。
- 备份重要的非系统数据。如果可能，将这些数据与系统被破坏之前的现有备份进行对比，以确保数据完整性。
- 重新安装系统。
- 使用新密码。
- 从系统和数据备份恢复。
- 应用所有可用更新。
- 重新检查系统：阻塞不需要的服务，检查防火墙规则和其他访问策略。
- 重新连接。

## 总结

Linux 和网络是密不可分的。Linux 内核支持所有常见和大多数不常见的网络协议。标准的 UNIX 网络工具在每个发行版中提供。除此之外，大多数发行版还提供了便于网络安装和管理的工具。

Linux 以运行各种互联网服务的稳定平台而闻名，互联网软件是无限的。与 UNIX 不同，Linux 同样可以从远程位置进行管理，使用几种远程执行程序的解决方案之一。

我们简要提到了安全问题。Linux 是一个理想的防火墙系统，轻量且廉价，也可以作为路由器和代理服务器或其他网络功能。

提高网络安全主要通过频繁更新和常识来实现。

## 音频和视频播放

### CD 播放与复制

`cdp` 包包含在大多数发行版中，`cdp` 或 `cdplay` 是一个基于文本的 CD 播放器。桌面管理器通常包含一个图形化工具，例如 Gnome 中的 `gnome-cd player`，可以通过菜单启动。

请确保理解音频 CD 和 CD 数据之间的区别。你不需要为了听而将 CD 挂载到文件系统。这是因为 CD 数据不是 Linux 文件系统数据；它们直接使用 CD 播放器程序访问并发送到音频输出。如果你的 CD 是一个包含 `.mp3` 文件的 CD，你首先需要将其挂载到文件系统，有关如何将 CD 挂载到文件系统，在“从安装 CD 安装额外包”章节中进行了解释。

同名包 `paranoia` 直接从数据中读取音频，不进行转换，并将数据以不同的格式写入文件或管道，其中 `.wav` 可能是最流行的格式。用于转换为其他格式（如 `.mp3`）的各种工具也包含在大多数发行版中，或者可以作为单独包下载。GNU 项目提供了多种 CD 播放、抓取和编码工具以及数据库管理器；详细信息请参见自由软件目录音频部分 [http://www.gnu.org/directory/audio/]。

音频 CD 的创建通过许多其他工具变得简单，例如 KDE 套件中的 `kaudiocreat` 工具。它带有来自 KDE 帮助中心的清晰信息。

CD 刻录见“使用 CD 刻录机制作副本”章节。
