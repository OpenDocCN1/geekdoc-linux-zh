
- `pool` - 对于类型 `s` 地址，此命令与多个远程服务器建立持久的客户端模式关联。在这种模式下，本地时钟可以同步到远程服务器，但远程服务器永远无法同步到本地时钟。

- `server` - 对于类型 `s` `r` 地址，此命令与指定的远程服务器或无线时钟建立持久的客户端模式关联。在这种模式下，本地时钟可以同步到远程服务器，但远程服务器永远无法同步到本地时钟。此命令不应用于类型 `b` 或 `m` 地址。

### Rationale:

时间同步对于支持时间敏感型安全机制以及确保企业日志具有一致的时间记录至关重要，这有助于取证调查。

## Audit:

如果系统在使用 `ntp`，运行以下命令显示服务器和/或 `pool` 模式：

```bash
# grep -P -- '\^h*(server|pool)\h\H+\' /etc/ntp.conf
```

验证返回了至少一条 `pool` 行和/或至少三行 `server` 行，且返回行上的时间服务器符合本地站点策略。

### Output examples:

`pool` mode:

```bash
pool time.nist.gov iburst maxources 4 # maxources 选项是 pool 指令特有的
```

`server` mode:

```bash
server time-a-g.nist.gov iburst
server 132.163.97.3 iburst
server time-d-b.nist.gov iburst
```

## Remediation:

编辑 `/etc/ntp.conf` 并根据本地站点策略适当添加或编辑 `server` 或 `pool` 行：

```bash
<server pool]<[remote-server|remote-pool]>
```

### Examples:

`pool` mode:

```bash

```

`server` mode:

```bash

server 132.163.97.3 iburst
server time-d-b.nist.gov iburst
```

运行命令将更新的时间源加载到 `ntp` 运行配置：

```bash
# systemctl restart ntp
```

或者

如果系统在使用另一个时间同步服务，运行以下命令从系统中移除 `ntp`：

```bash
# apt purge ntp
```

### Description:
