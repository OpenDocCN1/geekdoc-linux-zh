
## 选项

- `-d dataspec` 根据指定的数据规范生成报告。将 `dataspec` 指定为嵌入了形如 `:key:` 格式数据关键字的引号字符串。`prs` 命令在生成的输出中扩展这些关键字。要在输出中指定制表符，请使用 `\t`；要在输出中指定换行符，使用 `\n`。

- `-r sid` 指定想要获取信息的增量的 SCCS ID (`sid`)。如果没有 `sid`，使用最近创建的增量。

# sccs-prt, prt — 显示 SCCS 文件的增量表信息

## 摘要

```
/usr/ccs/bin/prt [-abdefistu][-c date-time] [-r date-time] [-y sid]
s.filename....
```

## 描述

使用 SCCS `prt` (print) 命令打印 SCCS 文件的选部分。默认情况下，`prt` 增量表（版本日志）。如果用目录名代替 `s.filename` 参数，`prt` 命令将适用于该目录下的所有 s 文件。不可读的文件会产生错误；将继续处理下一个文件（如果有）。使用破折号 (`-`) 作为 `s.filename` 参数表示从标准输入读取文件名称，每行一个文件。

## 选项

如果你提供了 `-y`、`c` 或 `-r` 以外的任何选项，每个处理的文件名（前跟一个换行，后跟两个换行符）将出现在其内容之前。如果你使用 `-u`、`ff`、`t` 或 `-b` 选项之一，则假设使用 `-d`。`s` 和 `-i` 互斥，`-c` 和 `-r` 也互斥。

- `-a` 显示所有标记为已删除的增量的日志项。

- `-b` 打印 s 文件的正文。

- `-c date-time` 排除具有指定日期和时间的表条目。将每个条目作为单行打印，前面是 SCCS 文件名。这种格式（也由 `-r` 和 `-y` 产生）方便按顺序排序多个增量表。当你同时提供 `-y` 和 `-c` 或同时提供 `-y` 和 `-r` 时，在满足第一个条件时停止打印。

- `-d` 打印增量表条目（默认）。

- `-e` 执行所有操作。此选项隐含 `-d`、`-i`、`-u`、`-f` 和 `-t`。

- `-f` 打印每个命名 s 文件的标记。

- `-i` 打印包含、排除和忽略的增量的序列号。

- `-r date-time` 排除晚于指定日期和时间的增量表条目。

- `-t` 仅打印增量表条目的的第一行；即只打印到统计信息。

- `-t` 打印 s 文件包含的描述性文本。（注：此处重复了 `-t`）

- `-u` 打印允许创建增量的用户名和/或数字组 ID。

- `-y sid` 排除指定 `sid` 之前创建的增量表条目。如果表中没有指定 `sid` 的增量，则打印整个表。如果你未指定 `sid`，则打印最近的增量。
