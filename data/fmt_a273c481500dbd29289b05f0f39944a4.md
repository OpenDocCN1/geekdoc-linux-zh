# 第 11 章

# 非平面图

我们在第10章中看到，如果 `G` 是一个包含两个不相邻顶点 `u` 和 `v` 的最大平面图，那么通过添加边 `uv` 得到的图 `G + uv` 是非平面图。虽然 `G + uv` 是非平面图，但它非常接近平面图。我们现在来研究衡量非平面图与平面图接近程度的各种方法。

## 11.1 图的交叉数

非平面图当然不能嵌入平面中。因此，每当试图在平面中绘制非平面图时，其某些边必须相交。这个相当简单的观察引出了一个概念。

图 `G` 的**交叉数** `cr(G)` 是 `G` 在平面中所有画法中（其边的）最少相交次数。在继续深入之前，我们评论一下关于所考虑的所有画法的假设。特别是，我们假设

- 相邻的边永不相交
- 两条不相邻的边最多相交一次
- 没有边自交
- 平面上同一点处最多有两条边相交
- 平面中对应于图中某边的（开）弧不包含该图的任何顶点。

一些观察将证明是有用的。如果 `G ⊆ H`，则 `cr(G) ≤ cr(H)`；而如果 `H` 是 `G` 的细分，则 `cr(G) = cr(H)`。图 `G` 是平面图当且仅当 `cr(G) = 0`。特别地，如果 `G` 是阶数为 `n ≥ 3`、边数为 `m` 的最大平面图，则 `m = 3n - 6` 且 `cr(G) = 0 = m - 3n + 6`。如果 `m > 3n - 6`，从而 `m - 3n + 6 > 0`，则 `G` 是非平面图，因此 `cr(G) ≥ 1`。事实上，数值 `m - 3n + 6` 提供了阶数为 `n ≥ 3`、边数为 `m` 的图的一个交叉数下界。

### 定理 11.1

如果 `G` 是一个阶数为 `n ≥ 3`、边数为 `m` 的图，则

$$
\operatorname{cr}(G) \geq m - 3n + 6.
$$

**证明。** 设给定 `G` 在平面中的一个画法，其交叉数 `cr(G) = c`。在每个交叉点处引入一个新顶点，生成一个平面图 `H`，其阶数为 `n + c`，边数为 `m + 2c`。由于 `H` 是平面，由定理10.3可知

$$
m + 2c \leq 3(n + c) - 6.
$$

因此，`cr(G) = c ≤ m - 3n + 6`。
