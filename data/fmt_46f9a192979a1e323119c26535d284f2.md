def process_request(self, op, url):
    if op == "GET":
        if not os.path.exists(url):
            self.send_error(404, "File %s not found\r\n")
        else:
            type, encoding = mimetypes.guess_type(url)

            self.push_text("HTTP/1.0 200 OK\r\n")
            self.push_text("Content-Length: %s\r\n" % size)

            self.push_text("\r\n")
            self.push_with_producer(file_producer(url))

## asyncore

`asyncore` 模块用于构建网络应用程序，在这些应用中，网络活动作为由使用 `select()` 系统调用构建的事件循环分发的系列被异步处理。这种方法对于希望提供并发性但不想使用线程或进程的网络程序有用。该模块的所有功能都由 `dispatcher` 类提供，该类是对普通套接字对象的薄封装。

`dispatcher({sock})`

定义事件驱动的非阻塞套接字对象的基类。`sock` 是一个已存在的对象。如果省略，则必须使用 `create_socket()` 方法创建 socket（稍后描述）。一旦创建，网络事件将由特殊的处理方法处理。此外，所有打开的调度器都存储在一个内部列表中，该列表被许多轮询函数使用。

`dispatcher` 类的以下方法用于处理网络事件。它们定义在派自 `dispatcher` 的类中。

- `d.handle_accept()`
当监听的套接字上有新连接到达时调用。

- `d.handle_close()`
当套接字关闭时调用。

- `d.handle_connect()`
当连接建立时调用。

- `d.handle_error()`
当发生未捕获的 Python 异常时调用。

- `d.handle_expt()`
当接收到套接字的带外数据时调用。

- `d.handle_read()`
当从套接字有新数据可读时调用。

- `d.handle_write()`
当尝试写入数据时调用。

- `d.readable()`
此函数由 `select()` 循环使用，检查对象是否愿意读取。如果是，则返回 `True`，否则返回 `False`。此方法用于检查是否应该调用 `handle_read()` 处理新数据。

- `d.writable()`
由 `select()` 循环调用，检查对象是否想要写入。如果是，则返回 `True`，否则返回 `False`。此方法用于检查是否应该调用 `handle_write()` 输出。

除了上述方法外，以下方法用于执行底层套接字操作。它们与 socket 对象的方法相似。

- `d.accept()`
接受连接。返回一个对 `(client, addr)`，其中 `client` 是用于发送接收数据的 socket，`addr` 是客户端。

- `d.bind(address)`
将套接字绑定到地址。`address` 通常是元组 `(host, port)`，取决于 `family`。

- `d.close()`
关闭套接字。

- `d.connect(address)`
建立连接。`address` 是元组 `(host, port)`。

- `d.create_socket(family, type)`
创建一个新的套接字。参数用于 `socket()`。

- `d.listen(backlog)`
监听连接。`backlog` 是传递给底层 socket 的整数。

- `d.recv(size)`
接收最多 `size` 字节。空字符串表示客户端已关闭。

- `d.send(data)`
发送数据。`data` 是一个字节字符串。
