
点击“存储”选项后，右侧会出现一个 IDE 控制器和一个 SATA 控制器。SATA 控制器下是虚拟机的虚拟磁盘设备，而默认的 IDE 控制器为空并显示“无磁盘”。点击“无磁盘”选项，右侧将出现 IDE 控制器的属性设置。点击“属性”下方的 CD 图标。将出现所有可用设备，包括物理设备和虚拟设备。这里的物理设备“F:”是物理主机的 CD-ROM 驱动器。选择它后，点击“确定”按钮。使用物理 CD-ROM 安装系统。

最后，点击“Oracle VirtualBox 管理器”界面上的“启动”图标启动虚拟机。VirtualBox 将自动读取物理机的 CD 并进入 Linux 启动安装界面。

### 2) ISO 文件安装方法

ISO 文件是一种 CD 镜像文件。刻录软件可以直接将 ISO 刻录成可安装的系统。由于 ISO 文件直接在硬盘上运行，数据传输速度非常快。CD 安装方法简单，但由于普通 CD-ROM 驱动器的传输速度较慢，安装过程也相对缓慢。

因此，建议在虚拟机上通过 ISO 文件安装系统。

### 1) 与 CD-ROM 安装法类似，在“ISO VirtualBox 管理器”界面中选择要安装的虚拟机，然后点击“设置”图标进入虚拟机设置界面。然后选择“存储”选项，点击“选择磁盘”按钮并指定物理机上相应的 ISO 文件。最后点击“确定”按钮完成 ISO 镜像文件的加载。

### 2) 点击“Oracle VirtualBox 管理器”界面上的“启动”图标启动虚拟机。VirtualBox 将自动读取 ISO 文件并引导进入 Linux 安装界面。

### 3) 有时虚拟机无法从 CD-ROM 驱动器或 ISO 文件启动，你可能需要修改虚拟机的启动顺序。虚拟机启动后，快速按下键盘上的 `F12` 键进入虚拟机启动顺序配置界面。

### 4) 虚拟机的默认启动顺序是硬盘、软盘驱动器、光驱和网络。如果你想从光驱启动，直接在界面按 `c` 键即可进入 CD 启动。其他操作类似。

### 5) VirtualBox 虚拟机启动后，将进入一个新的虚拟计算机控制台。进入新计算机控制台时，会遇到虚拟机与物理机之间切换键盘鼠标的问题。

### 6) 默认切换键是右 `Ctrl` 键，即当虚拟机独占键盘鼠标时，按下右 `Ctrl` 键退出独占模式，再次按下右 `Ctrl` 即可进入独占模式。此右 `Ctrl` 键也称为热键。

### 7) 主机键（Host key）与其他键的组合可以实现虚拟机上的快捷操作。例如，`Host+Del` 组合键代表键盘上的 `Ctrl+Alt+Del` 组合，`Host+R` 代表重启虚拟机，`Host+H` 组合键代表正常关闭虚拟机，等等。

### 什么是黑客？

由于流行文化中对黑客的持续性错误介绍，这个问题可能看起来很随意。从 90 年代的电影、书籍和漫画中，黑客被描绘成试图破坏系统和击垮互联网的阴暗人物。

但，这正确吗？或者黑客真的如他们所代表的那样吗？我的意思是，确实有一些坏人留在暗网中，并为愿意剥削的人廉价出售盗取的信用卡信息。

但在硬币的另一面，还有成千上万的道德黑客，他们努力工作，保护复杂的网络系统免受某些试图破解系统的恶作分子的攻击。

黑客行为（Hacking）是一门计算机学习，人们在尝试破坏系统。虽然破坏似乎是一件坏事，但他们实际上是在帮助我们理解开发软件、操作系统和应用程序时可能出现的漏洞。

早期，黑客技术是一种同时需要硬件和软件访问的技能。但现在，随着互联网和网络架构的出现，任何东西都可以仅通过电脑借助少量软件被黑入。

### 对黑客来说，Linux 是什么？

所有著名的黑客都强烈建议新手（他们也称为脚本小子 `script kiddies`）停止使用 Windows 或 macOS 进行黑客攻击。Windows 和 macOS 不仅对黑客来说是非常糟糕的操作系统，而且在攻击和破解系统时还可能损害你的安全。

`Linux` 是一个高度安全的内核级系统，预装了网络监控工具和其他命令行实用程序，可以帮助你监控流量。

### 什么是黑客程序？

黑客使用不同的协议来破解系统。还记得几年前摧毁许多行业的勒索软件吗？它利用了 Windows 中的未知漏洞进行剥削。

有才华的黑客在攻击之前总是会对目标进行彻底研究。新手在这个阶段会通过同时攻击多个目标来浪费系统资源。

### 有多少类型的黑客？

技术领域通常将黑客分为三类。其中最重要的是道德黑客，他们通过渗透测试技能和漏洞检测来帮助保护系统。

以下是对每种类型黑客的简要描述：

#### 1) 黑客（Black hackers）

这类黑客为了个人利益而进行黑客活动。他们带有动机利用系统并窃取数据。根据最新统计，黑客每年从互联网上盗取超过 20 亿美元。更多科技公司担心黑客，并投入巨额资金开发入侵检测系统。如果你学习这本书是为了成为黑帽黑客，我们警告你那里并不容易。

#### 2) 白帽黑客（White hackers）

这类黑客是为了保护系统而进行黑客活动。几乎所有的安全研究人员都属于这一类。不仅是黑客，法医专家和逆向工程师也属于这一类。白帽黑客在知识和速度上与黑帽黑客一样成熟。白帽黑客相对于黑帽黑客拥有的唯一优势是他们拥有良好的信息。

#### 3) 灰帽黑客

如果黑客落在其他两者之间，我们可以简单地称其为灰帽黑客。为政府或大学工作的黑客属于这一类。

## KALI LINUX 中的工作工具

在本书的之前的模块中，我们讨论了黑客哲学以及 `Kali Linux` 的介绍。虽然 `Kali Linux` 是掌握和利用工具的极佳途径，但我们也需要关注其中一些监控工具。网络是互联网通信的骨干，对于每个程序员来说，理解其基础知识是必修的。

`Linux` 为开发者提供了许多实用工具来调试和评估服务器程序。熟练的网络程序员会在开发服务器程序的整个过程中不断使用这些工具中的一个一个来监控服务器的行为。

其中一些工具对于黑客来说是常见的。

本章将讨论一些常用的工具：`tcpdump`, `nc`, `trace`, `lsof`, `netstat`, `vmstat`, `ifstat` 和 `mpstat`。这些工具支持许多选项，但我们的讨论限于最常用且实用的部分。此外，请记住，我们仅提供了供您理解工具能力的重要命令。为了进一步了解和实验该工具，我们首先建议您：

### TCPDUMP

`Tcpdump` 是一个经典的网络包捕获工具。即使在今天，我们也有像 `Wireshark` 这样更容易使用和掌握的抓包工具，但 `tcpdump` 仍然是网络程序员必不可少的的工具。`tcpdump` 为用户提供了大量选项来过滤数据包或自定义输出格式。

在学习更多 `tcpdump` 之前，我们建议您先理解网络包的本质以及如何使用 `Wireshark` 等工具进行追踪。如果您是一个高效的黑客，学习一些网络嗅探以从收集的数据中获取敏感信息也是重要的。

我们在本章中引入了许多不同的黑客工具，现在我们总结了常用选项并带有示例，以便您更好地理解这个工具可以完成的奇功能。

在 4.0 及之前的版本中，默认捕获长度为 68 字节。这对于 IP、TCP 和 UDP 等协议足够了，但对于 DNS 和 NFS 等协议，68 字节通常无法容纳完整的数据包。

例如，当我们抓取 DNS 包时，我们使用 `-s` 选项（测试机上的 `tcpdump` 版本为 4.0）。

```
root@server : tcpdump -s 192.132.112.11
```

然而，在 4.0 之后的版本中，默认捕获长度被更改为 65535 字节，因此我们不需要担心捕获长度了。`-s`，TCP 段的序列号以绝对值显示，而不是相对值。`-w`，将 `tcpdump` 的输出重定向到特殊格式的文件。而 `-r` 将从文件中读取包信息并显示出来。

除了使用选项外，`tcpdump` 还支持使用表达式来过滤过滤包。`tcpdump` 表达式的操作数分为三类型：类型（type）、方向（direction）和协议（protocol）。本节将依次介绍这些。类型将解释紧随其后的参数的含义。`tcpdump` 支持的所有类型包括 `host`（主机）、`net`（网络）和 `portrange`（端口范围）。

它们分别指定主机名（或 IP 地址）、CIDR 方法表示的网络地址、端口号和端口范围。例如，要抓取整个 `1.2.7.0/255.253.231.0` 网络上的数据包，可以使用以下命令。

```
root@server : $ tcpdump net 1.2.7.0/13
```

在这里，`src` 指定数据包的发送者，`dst` 指定数据包的目的地。

例如，要抓取进入端口 `13111` 的包，可以使用以下命令：

```
root@server : $ tcpdump dstport 13111
```

例如，要抓取所有的互联网控制消息协议（ICMP），可以使用以下命令。

```
root@server : $ tcpdump ICMP
```

你可以将其用于其他几种协议，如 `SMTP`、`FTP` 等。

当然，我们也可以使用逻辑运算符来组织上述操作数以创建更复杂的表达式。`tcpdump` 支持的逻辑运算符与编程语言中的完全相同，包括 `(&&, or (||), not (!))`。

例如，要抓取主机 `-laptop` 和非源主机交换的 IP 数据包，可以使用以下命令。

```
root@server : $ tcpdump IP host
```

如果表达式很复杂，可以使用括号将它们分组。然而，在使用括号时，我们要么使用反斜杠 "\" 进行转义，要么将其包含在单引号 "'" 中，以避免被 shell 解析。

例如，要抓取来自主机 `8.0.2.4` 且目标端口为 `3369` 或 `12` 的包，可以使用以下命令。

```
root@server : $ tcpdump src 8.0.2.4 and (dstport 3369 or 12)
```

此外，`tcpdump` 还允许直接使用包中的某些协议字段来过滤包。例如，要仅提取 TCP 同步段，可以使用以下命令。

```
root@server : $ tcpdump TCP [13]&2!=0
```

因为 TCP 头部第 14 字节的第二位是同步标志，所以我们可以从数据中获取大量信息。最后，`tcpdump` 的特定输出格式不仅与协议有关，还与其他协议有关。我们讨论了 IP、TCP、ICMP、DNS 的 `tcpdump` 输出格式。对于其他协议的 `tcpdump` 输出格式，请参考相关手册。到此，我们完成了对这种流行的监控工具的简要介绍。在下一节中，我们将讨论 `lsof`，另一个流行的监控工具。

### LSOF

`lsof`（list open file）是一个列出系统打开的文件的工具。通过它，我们可以知道哪些进程打开了文件。该选项的用法如下：

```
$ lsof [-4|-6] [protocol] [@hostname | ipaddr] [:service | port]
```

其中 `4` 代表 IPv4 协议，`6` 代表 IPv6 协议。`Protocol` 指定传输层协议，可以是 `TCP` 或 `UDP`。`Hostname` 指定主机，`ipaddr` 指定 IP 地址。`Service` 指定服务名，`Port` 指定端口号。例如，要显示连接主机 `192.168.1.108` 的 socket 文件描述，可以使用命令。

```
root@server : lsof -i192.168.1.108:22
```

如果 `-i` 选项没有指定参数，`lsof` 命令将显示所有文件描述。`-u` 显示由指定用户启动的进程，`-c` 显示由指定命令启动的进程。例如，要查看 `websrv` 打开的文件描述，可以使用以下命令。

```
root@server : $ lsof -c websrv
```

要显示指定进程打开的文件描述使用 `-p`。它只显示目标进程的 PID。我们可以直接文件名作为 `lsof` 命令的参数来查看哪些进程打开了文件。从列表中可以看到测试机上的程序文件和动态库存储在设备 `"8,3"` 中。其中，“`8`” 表示 SCSI 硬盘，“`3`” 表示该硬盘上的第三个分区，名为 `sda3`。

对应于 `websrv` 程序的标准输入、标准输出和标准错误的设备是 `"136,3"`。其中，“`136`” 表示这是一个伪终端，“`3`” 表示它是第三个伪终端，即 `./dev/pts/3`。

对于 FIFO 类型文件（如管道和 socket），此文件将显示内核引用文件的地址或其 inode 节点。如果文件显示为 `"Ot"` 或 `"Ox"`，则意味着它是一个偏移值，否则意味着它是一个大小。对字符设备或 FIFO 类型文件定义文件大小是没有意义的，因此该文件将显示偏移值。对于 socket，它显示协议类型，如 `"TCP"`。`Name` 显示文件的名称。如果我们使用 `telnet` 命令连接到 `websrv` 服务器，当我们再次执行 `lsof` 命令时，以下行将被添加到其输出中。

```
websrv63466shuang5gu IPv4 442880tcp localhost: 13579-> localhost: 48215
(ESTABLISHED).
```

此输出表示服务器已打开一个值为 `5` 的 IPv4 类型 socket，且处于已建立（established）状态。与该 socket对应的连接本地套接地址为 `(127.0.0.1, 13579)`，远程套接地址为 `(127.0.0.1, 48215)`。

虽然 `lsof` 不具备像 `tcpdump` 那样的高级功能，但它仍然实现了其设计初衷。在本章的下一节中，我们将详细介绍 `netcat`。请继续阅读下去！

### NC(NETCAT)

`netcat` 命令短小、高效且强大，被称为“瑞士军刀”之誉。它主要用于快速建立网络连接。我们可以让它作为服务器，监听某个端口并接收客户端连接，因此它可以调试客户端程序。我们也可以让它作为客户端，发起对服务器的连接并接收数据，因此它可以调试服务器程序，这有点像 `telnet` 程序。

`nc` 命令默认使用的传输层协议是 `TCP` 协议。

- `-w`，如果 `nc` 客户端在指定时间内没有检测到任何输入，则退出。
- `-x`，指定 `nc` 客户端与代理服务器之间通信时使用的通信协议。目前，`nc` 支持的代理协议包括 `"4"socks v.4`）、`"5"socks v.5`）和 `"connect"`（https 代理）。`nc` 默认使用的代理协议是 `SOCKS v.5`。
- `-x`，指定目标代理服务器的 IP 地址和端口号。

例如，要从源笔记本连接到 `squid` 代理服务器并通过它访问 `www.google.com` 的 Web 服务，可以使用以下命令。

```
root@server: $ nc -x source: 1080 -x Connect www.google.com 80 -z, 并扫描目标机器上的一个或多个服务是否开启（端口扫描）。
```

例如，要扫描 `ernst-laptop` 机器上端口号在 20 到 50 之间的服务，可以使用以下命令。

```
root@server: $nc -z source 20-50.
```

例如，我们可以使用以下方法连接到 `websrv` 服务器并向其发送数据。

```
root@server :$nc -C 127.0.0.1 13579 (服务器监听端口 13579)
http://localhost/a.htmlHTTP/1.1 (回车)
```

它将提供在该服务器上未找到请求文件的提示。在这里我们使用 `-C` 选项，这样每当我们按下键向服务器发送一行数据时，`nc` 客户端程序都会向服务器发送一个额外的 `<CR> <LF>`，这正是 `websrv` 预期的 HTTP 行终止符。

在发送第三行数据后，我们收到了服务器的响应，这与我们的预期完全一致。服务器没有找到请求资源文件 `a.html`。因此，`nc` 命令是一个方便且快速的测试工具，通过它我们可以快速发现服务器的逻辑错误。

在本章的下一节中，我们将讨论 `strace` 工具，它可以方便地帮助我们跟踪数据包的路径。请继续阅读下去！

### STRACE

`Strace` 是测试服务器性能的重要工具。它跟踪程序运行期间接收到的系统调用和信号，并将系统名称、参数、返回值和信号名称输出到标准输出或指定的文件。

格式为：

```
[qualifier=][!value1,value2]..
```

限定符（qualifier）可以是 `trace`, `abbrevi`, `verbose`, `raw`, `signal`, `read` 和 `write` 之一，默认是 `trace`。值（Value）是用于进一步限制所跟踪系统调用的符号或数值值。它的两个特殊值是 `all` 和 `none`，分别意味着跟踪限定符指定类型的所有系统调用，以及不跟踪任何此类类型的系统调用。

例如，`-e read=3, 5` 表示输出从文件描述符 `3` 和 `5` 读取的所有数据。

- `-o`，将 `strace` 的输出写入指定的文件。`strace` 命令的每行输出包含这些字段：系统名称、参数和返回值。

例如，以下示例：

```
root@server: $ strace /dev/null open("/dev/null", O_RDONLY | O_FILE) = 3.
```

此行输出表示程序 `"cat/dev/null"` 在运行期间执行了 `open` 系统调用。

`Open` 以只读方式打开了大文件 `/dev/null`，然后返回一个值为 `3` 的文件描述符。需要注意的是，此示例命令将输出大量内容，在这里我们省略了很多次要信息。在随后的示例中，我们只显示与主题相关的内容。

当系统调用发生错误时，`strace` 命令将输出错误标识和描述，如下例所示。

```
root@server : $ strace /foo/bar open("/foo/bar", O_RDONLY | O_FILE) = -1
```

这将输出显示为 `ENO (no such file or directory)`。
