### None 类型

`None` 类型表示一个空对象（没有值的对象）。Python 提供了一个空对象，在程序中写为 `None`。该对象由没有显式返回值的函数返回。`None` 经常用可选参数的默认值，以便函数可以检测调用者是否传递了参数值。`None` 没有属性，并在布尔表达式中求值为 `False`。

### 数字类型

Python 使用五种数字类型：布尔值、整数、长整数、浮点数和复数。除了布尔值外，所有数字对象都是符号的。所有数字类型都是不可变的。

布尔值由两个值表示：`True` 和 `False`。`True` 和 `False` 的名称分别重映射为数值 1 和 0。

整数表示 −2147483648 到 2147483647 范围内的整数（在某些机器上范围可能更大）。长整数表示内存不受限制的整数（仅限于可用内存）。尽管有两种整数类型，但 Python 尝试使用单一整数类型。因此，你有时会在现有的 Python 代码中看到整数的引用，这大部分是一个可以忽略的实现细节——对所有操作都使用整数类型即可。唯一的例外是 `forms` 对整数进行显式类型检查。在 Python 2 中，如果 `$x$` 是一个已提升为 long 的整数，`isinstance(x, int)` 将返回 `False`。

浮点数使用机器上的原生双精度（64 位）浮点数表示法。通常是 IEEE 754 标准，它提供了约 17 位精度以及范围在 -308 到 308 之间的指数。这与 C 语言中的 `double` 类型相同。Python 不支持 32 位单精度浮点数。如果你的程序中，对数字的空间和精度的精确控制是一个问题，请考虑使用 `numpy` 扩展（可以在 http://numpy.sourceforge.org 找到）。

复数表示为一对浮点数。复数 `$z$` 的实部和虚部分别可以通过 `$z.real$` 和 `$z.imag$` 获取。方法 `z.conjugate()` 计算 `$z$` 的复数共轭（`$a+b$` 的共轭是 `$a-b$`）。

数字类型具有属性和方法，可用于简化涉及混合算术的操作。为了与有理数（定义在 `fractions` 模块中）保持简单兼容性，整数具有 `x.number` 和 `x.denominator` 属性。整数或浮点数 `$y$` 也具有 `y.real` 和 `y.imag` 属性，以及用于与复数兼容的 `y.conjugate()` 方法。浮点 `$y$` 可以通过 `y.as_integer_ratio()` 转换为表示分数的两个整数对。方法 `y.is_integer()` 测试浮点数是否表示整数值。`y.hex()` 和 `y.fromhex()` 可用于通过低级表示来处理浮点数。

库模块中定义了若干数字类型。`decimal` 模块提供了通用的基 10 算术。`fractions` 模块增加了有理数类型。这些模块将在第 14 章“数学”中介绍。

### 序列类型

序列表示由非负整数索引的有序对象集合，包括字符串、列表和元组。字符串是字符序列，列表和元组是任意 Python 对象的序列。字符串和元组是不可变的；列表允许插入、删除和替换元素。所有序列都支持迭代。

### 字符串

Python 2 提供了两种字符串类型。字符串是包含 8 位数据的序列。它们可能包含二进制数据。字符串是 Unicode 字符序列，由 16 位整数表示。这允许 65536 个字符值。然而，这些字符默认不支持这些字符。相反，它们被编码为特殊的字符（4字节）序列。作为附加功能，Python 使用 32 位整数构建 Unicode 字符。这允许 Python 表示从 U+0000 到 U+FFFF 的 Unicode 范围。所有 Unicode 相关的函数已相应调整。

字符串支持表 3.5 所示的方法。虽然这些方法在字符串实例上操作，但没有一个实际上修改字符串数据。因此，`capitalize()`、`center()` 和 `expandtabs()` 等方法返回新字符串而不是修改字符串 `$s$`。字符测试如 `isalnum()` 和 `isupper()` 如果字符串中的字符满足测试返回 True 或 False。此外，如果字符串长度为零，这些测试返回 False。

`s.find()`、`s.index()`、`s.rfind()` 和 `s.rindex()` 方法用于搜索子字符串。所有这些函数都返回子字符串在 `$s$` 中的索引。此外，`find()` 方法未找到子字符串时返回 -1，而 `index()` 方法会抛出 ValueError 异常。`s.replace()` 方法用于用替换文本替换子字符串。

`s.split()` 和 `s.rsplit()` 方法根据分隔符将字符串分割为字段列表。`s.partition()` 和 `s.rpartition()` 方法将 `$s$` 分为三个部分，分别对应分隔符之前的文本、分隔符本身之后的文本。

许多字符串方法接受可选的 `$start$` 和 `$end$` 参数，这些参数是指定 `$s$` 中起始和结束索引的整数值。在许多情况下，这些值可以取负值，在这种情况下，索引将从字符串末尾开始计算。

`$s.translate()$` 方法用于执行高级字符替换，速度快于剥离字符串中的所有字符。作为参数，它接受一个翻译表，其中包含原始字符串中字符到字符的一一一映射。对于 8 位字符串，翻译表是一个 256 个字符的字符串。对于 Unicode，翻译表可以是任何序列 `$s$`，其中 `$s[n]$` 返回一个整数字符码或与值为 `$n$` 的 Unicode 字符对应的 Unicode 字符。

`$s.encode()$` 和 `$s.decode()$` 方法用于在字符串数据与指定的编码之间转换。作为输入，它们接受编码名称，如 'ascii'、'utf-8' 或 'utf-16'。这些方法通常用于将 Unicode 字符串转换为用于 I/O 操作的数据编码，并在第 9 章“输入与输出”中进一步描述。在 Python 3 中，`$encode()$` 仅适用于字符串，而 `$decode()$` 仅适用于 bytes 数据类型。
