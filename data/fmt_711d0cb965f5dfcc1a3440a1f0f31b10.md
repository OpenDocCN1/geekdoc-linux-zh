
当你指定选项时，代表一个或多个系统特征的符号将写入标准输出。选项打印由 `uname(2)`、`sysinfo(2)` 或两者返回的选定信息。
独立软件供应商 (`ISVs`) 以及其他需要确定软件安装或执行的平台详细特征的人应该使用 `uname` 命令。
要确定操作系统名称和发布级别，请使用 `uname -sr`。要仅确定操作系统发布级别，请使用 `uname -r`。

> 注意 — 操作系统发布级别不保证为 x.y 格式（例如 5.5, 5.6, 5.7）；未来的发布可能是 x.y.z 格式（例如 5.3.1, 5.3.2, 5.4.1）。

在 `SunOS 4.x` 版本中，`arch` 命令经常用于获取与 `uname` 命令获得的类似信息。`arch` 命令的输出 `sun4` 经常被错误地解释为 `SunOS SPARC` 系统。
`arch -k` 和 `uname -m` 命令返回等的值；不建议第三方程序使用这些命令中的任何一个，正如使用 `arch` 命令一样。要确定系统的指令集架构 (`ISA` 或处理器类型)，请使用带有 `-p` 选项的 `uname`。

# 1404

## 选项

- `-a` 打印系统当前可用的基本信息。
- `-i` 打印硬件实现的名称（平台）。
- `-m` 打印系统硬件名称（类）。不建议使用此选项；请使用 `uname -p` 代替。
- `-n` 打印节点名称（节点名称是系统在通信网络中的标识名称）。
- `-p` 打印当前的 `ISA` 或处理器类型。
- `-r` 打印操作系统发布级别。
- `-s` 打印操作系统名称（默认值）。
- `-v` 打印操作系统版本。
- `-X` 打印扩展系统信息，每行一个元素，符合 `SCO UNIX` 的预期。显示的信息包括：
  - 系统名称、节点、发布、版本、系统和 `CPU` 数量。
  - `BusType`、`Serial` 和 `Users`（在 `Solaris` 中设置为 "`unknown`"）。
  - `OEM#` 和 `Origin#`（分别设置为 `0` 和 `1`）。
- `-S system-name`

通过指定 `system-name` 参数来更改节点。`system-name` 参数限制为 `SYS_NMLN` 字符。`SYS_NMLN` 是 `<utsname.h>` 中定义的特定实现值。只有超级用户可以更改名称。

## 示例

以下示例显示了操作系统名称和发布级别，用空格分隔。

```
castle% uname -sr

SunOS 5.7

cast%
```

以下示例显示了系统当前知的基本信息。

```
castle% uname -a

SunOS castle 5.7 Generic sun4m sparc SUNW, SPARCstation-10

castle%
```

列出的七个项目包括操作系统名称、节点名称、操作系统发布级别、内核 `ID`、系统硬件名称、当前处理器类型和平台名称。

以下示例使用 `-X` 选项显示扩展系统信息。

```
castle% uname -X

System = SunOS

Node = castle

Release = 5.7

KernelID = Generic

Machine = sun4m

BusType = <unknown>

Serial = <unknown>

Users = <unknown>

OEM# = 0

Origin# = 1

NumCU = 1

caste%
```

`SYS3` 覆盖 `uname` 的默认行为，以便某些交互式 `UNIX` 系统和 `SCO UNIX` 程序及脚本能够正常工作。许多脚本使用 `uname` 来确定 `OS` 类型或 `OS` 版本以确保软件与该 `OS` 兼容。将 `SYS3` 设置为此。

## uniq 1409

## 描述

`uniq` 命令通过过滤或删除重复行来生成文件中的唯一行列表。它通常与先用 `sort(1)` 命令排序过的文件一起使用。
`uniq` 读取一个输入文件，比较相邻行，并将每行输入的一个副本写入输出。重复的相邻行，其第二个及随后的副本将不会被写入。
如果输入中的重复行不相邻，则无法检测到。

## 选项

- `-c` 在每行输出前置一个该行在输入中出现的次数。
- `-d` 抑制写入输入中不重复的行。
- `-f fields` 在比较时忽略每行输入中的前 `fields` 个字段，其中 `fields` 是一个正十进制整数。字段是由正则表达式匹配的最长字符串：`[[:blank:]]*([^[:blank:]]*`
如果 `fields` 指定的字段多于输入行中显示的字段，则使用空字符串进行比较。
- `-s chars` 在比较时忽略前 `chars` 个字符，其中 `chars` 是一个正十进制整数。如果与 `-f` 选项配合使用，则忽略第一个字段后的前 `chars` 个字符。如果 `chars` 指定的字符多于输入行剩余的字符，则使用空字符串进行比较。
- `-u` 抑制写入输入中重复的行。
- `-n` 等同于 `-f fields`，并将 `fields` 设置为 `n`。
- `-m` 等同于 `-s chars`，并将 `chars` 设置为 `m`。

### 操作数

- `input-file` 输入文件的路径名。如果不指定 `input-file` 或 `input-file` 为 `-`，则使用标准输入。
- `output-file` 输出文件的路径名。如果不指定 `output-file`，则使用标准输出。如果名为 `output-file` 的文件与由 `input-file` 指定的文件同名，则结果未定义。

## 示例

以下示例列出了 `uniq.test` 文件的内容，并输出重复行的副本。

```
castle$ cat uniq.test

This is a test.

This is a test.
```
