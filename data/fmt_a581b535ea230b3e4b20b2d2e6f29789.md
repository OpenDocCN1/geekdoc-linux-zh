
# 第 2 章 使用 `ln -s` 链接（软链接）

现在，假设你想把整个工作负载托给你的新助手。与其仅仅给他访问单个文件的权限，你可能希望让他更方便地访问你的整个项目目录。你可以使用软链接（通过 `ln -s` 创建）来实现这一点，它们本质上为其他用户提供了指向文件或目录的快捷方式。

与硬链接一样，软链接允许文件同时存在于多个位置；但是对于软链接，它只有一个副本，而且通过软链接你还可以链接目录。如果原始文件或目录被删除，被链接的文件或目录将无法使用。

软链接特别方便，因为既可以用于目录也可以用于单个文件，并且可以跨不同的文件系统工作（即不仅是在 `/home` 内，而是在 Unix 系统的任何地方）。

与硬链接一样，软链接有时要求你有访问另一个用户的目录和文件的权限。有关文件权限和所有权的更多信息请参阅第 5 章，文件系统的详情见第 7 章。

## 创建软链接

1. `ls -l /home/deb /home/helper`

   首先，列出两个用户的家目录内容。在这里，我们正在验证要链接的目录是否存在于 Deb 的目录中，并且在 helper 的目录中不存在匹配的目录或文件。请参见代码列表 2.15。

2. `ln -s /home/deb/Projects/ /home/helper/Project`

   此命令创建一个软链接，使得 Deb 的家目录的内容也可以从 helper 的目录方便地访问。

3. `ls -la /home/helper`

   列出 `/home/helper` 的内容显示了指向目录的软链接的存在。注意代码列表 2.15 中显示链接的箭头。

### Tip

如果你只需要在同一个文件系统的两个文件之间创建链接，请考虑使用硬链接，如上一节“使用 `ln` 链接（硬链接）”中所讨论的。

```

/home/deb: Projects
/home/helper: our.projects
$ ls -d /home/deb/Projects /home/helper
```

# 第 3 章 操作你的 SHELL

当你访问 Unix 系统时，首先看到的是提示符，称为 shell 提示符（shell prompt），这是你与 Unix 交互的地方。shell 决定了你多么容易地输入和重新输入命令，以及你如何控制你的环境。Unix 的酷之处在于，你并不局限于某一个 shell——也就是说，在大多数系统中，你可以选择具有不同功能和能力的 shell。

在本章中，我们将查看你的 shell，展示如何更改 shell，并引导你开始使用一些常用的 shell。

## 发现使用什么 Shell

当你第一次登录 Unix 账户时，将使用默认 shell。它的功能和选项完全取决于你的系统指定。代码列表 3.1 和 3.2 显示了不同系统中 shell 差异的示例。

要发现你正在使用什么 shell：

- `echo $SHELL`

在你的 shell 提示符处输入 `echo $SHELL`（注意大小写！）。此命令告诉 Unix 显示你的 shell 设置。顺便说一下，这些信息包含在一个环境变量中，所以你在 Unix 圈子里会听到这样的说法：“系统的响应将是你 shell 的完整路径——类似于 `/bin/csh`、`/bin/bash` 或 `/bin/ksh`。”

### Tips

- 你也可以使用 `userid`（将你的登录名替换为 `userid`）来查找。

## 使用 `chsh` 更改 shell

```
[ejr@hobbes ejr]$ cat /etc/shells
/bin/bash
/bin/sh
/bin/tcsh
/bin/zsh
[ejr@hobbes ejr]$ chsh
```
