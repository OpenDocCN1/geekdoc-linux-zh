
## 设置 ACL

```bash
setfacl -m user:jon:rw- memtool.c
```

## 查看 ACL

```bash
getfacl memtool.c
```

输出：
```
file: memtool.c
owner: rmc
group: staff
user:
user:jon:rw- #effective:r-
group:r-- #effective:r-
mask:r--
other:--
```

## 查看文件权限

```bash
ls -l memtool.c
```

`-r--r--r+ 1 rmc staff 638 Mar 30 11 memtool.c`
