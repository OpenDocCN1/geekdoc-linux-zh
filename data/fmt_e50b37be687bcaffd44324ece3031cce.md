### 3.6.2 如何编写一个简单的 GUI 程序（使用 Tk）？

`Tk` 是简单但功能强大的 `tcl` 编程语言的 `GUI` 扩展。例如，我可以使用 `pico` 创建一个包含一个简单 `tk` 程序的文本文件：

```
pico try_tk
```

并输入一个简单的 `tk` 代码示例来查看它是否可以运行：

```wish
#!/usr/bin/wish
button .my_button -text "Hello World" -command exit
pack .my_button
```

第一行（以 `"#!"` 开头的 pound-bang）告诉 `shell` 使用什么实用程序来执行我的文本文件。接下来的两行是简单的 `tk` 程序示例。首先，我创建了一个名为 `"my_button"` 的按钮，并将其放置在类层次结构的根节点（`"my_button"` 前面的点）。我为按钮绑定了 `"Hello World"` 文字以及一个退出程序的命令（当点击按钮时）。最后一行使我的程序窗口调整大小，使其足以容纳我的按钮。

保存文件后，我可以将其设为可执行：

```
chmod a+x try_tk
```

之后我可以通过输入以下命令来运行它（在 X 终端中，因为需要 X-windows 运行）：

```
./try_tk
```

`Tk` 是构建 `GUI` 前端非常流行的工具。

### 3.6.3 如何编写一个简单的 perl 脚本？

`Perl` 是一种以其强大性、灵活性以及可能晦涩的语法而闻名的脚本语言。它在 `Linux` 和 `Unix`（而不仅仅是大师）中也非常流行。我使用 `pico`（或任何你喜欢的文本编辑器）创建了一个简单的 `perl` 脚本。下面的脚本并没有什么用处，但展示了 `perl` 的一些特性：

```perl
#!/usr/bin/perl -w
#sample perl program
#  own变量以 $ 开头
$a=2;
$b=3;
print $a**$b, "\n";
$hello_world='Hello World';
print $hello_world,"\n";
system "ls";
```

第一行告诉 `shell` 如何执行我的文本文件。选项 `"-w"` 会让 `perl` 输出一些额外的警告，这可能对调试有用。接下来的几行几乎是不言自明的：我给两个变量（`$a` 和 `$b`）赋值，将 `$a` 升为 `$b` 次幂方并打印结果。`"\n"` 打印换行，就像 `"c"` 编程语言一样。然后我定义了另一个变量来包含字符串 `"Hello World"`，并在下一行将其打印到屏幕上。最后，我执行了本地操作系统命令 `"ls"`，它在 `Linux` 上会列出当前目录的内容。真是个愚蠢的脚本。

当然，我必须记得保存文件，然后将其设为可执行（参见之前的答案），然后就可以准备好运行它了。

### 3.6.4 如何编译一个简单的 C 程序？

启动你最喜欢的文本编辑器并输入你的源代码。例如，我可以使用 `pico`：

```
pico hello.c
```

```c
#include <stdio.h>
void main(void) {
    printf("hello world\n");
}
```

我保存文件，然后调用 GNU C 编译器编译文件 `"hello.c"`：

```
gcc hello.c
```

`gcc` 编译器生成一个可执行的二进制文件 `"a.out"`，我可以运行它：

```
./a.out
```
