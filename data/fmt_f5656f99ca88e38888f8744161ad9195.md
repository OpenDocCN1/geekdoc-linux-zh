## matwrap

矩阵语言的包装器 Matrap 是一个将 C++ 代码接口到矩阵导向脚本语言（如 Octave, Tela 或 Matlab 5）的工具。它生成所有代码以将脚本语言输入转换为 C++ 理解的类型（例如 `double`、`char *`、`float`、`struct *`）。无需理解任何 API 细节即可使用你的 C++ 代码；只需编写描述函数的 .mat h 文件。功能列表：

- 函数自动向量化。
- 包含不同顺序向量和矩阵参数的参数可以自动计算，但需要指定。
- 支持指向结构体和类的指针。可以调用类的公共成员，并对公共数据进行评估或增强。支持继承。来自 Debian 3.0r APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html

## mawk

模式扫描和文本处理语言 `awk` 解释器。`awk` 是 AWK 编程语言的解释器。AWK 语言用于数据文件操作、文本检索和处理，以及算法的原型设计和实验。Mawk 是一种新的 `awk` 语言，它实现了 Aho, Kernighan 和 Weinberger 定义的 AWK 语言。《AWK 编程语言》，Addison-Wesley 出版社，1988 年（以下简称 AWK 书）。Mawk 符合 Posix 1003.2 (草案 11.3) 对 AWK 语言的定义，包含了 AWK 书中未描述的功能，`mawk` 提供了少量扩展。Mawk 比 `gawk` 更小且快得多。它有编译限制，例如 `NF = 32767` 和 `sprintf` 缓冲区 `1020`。来自 Debian 3.0r0 APT http://www.tdlp.org/LDP/Linux-Dictionary/html/index.html
