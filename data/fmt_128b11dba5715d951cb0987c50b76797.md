
# 术语表

### `burn-at-once` (一次性刻录)
一种 CD/DVD 刻录机制，它写入整个 CD 或 DVD 磁盘表面，而不仅仅是包含你正在录制的信息所需的存储量。

### `DMCA` (千年版权法案)
美国通过的一项法律，其据称目标是保护数字媒体的版权，但它被用于压制反向工程、消除对加密技术的自由言论讨论，并剥夺用户对合法购买的音频和视频文件的自由使用权；一个变质的良良主意。

### `DR` (数字权利管理)
一种拒绝合法用户自由复制和使用音频及视频文件能力的技术。

### `DSP` (数字信号处理)
使用各种算法转换或修改数字音频和视频信号。`DSP` 可以在硬件、软件或软硬件结合的方式完成。

### `DVD` (数字视频光盘)
一种能够存储约 4.7GB 数字信息的存储设备。

### `EQ` (均衡)
一种录音效果，用于增加或减少音频信号中不同频率变化的音量。均衡频率范围可以通过防止不同频率范围之间音量的极端差异来使音频信号变得平滑。

### `FP` (FLAC 指纹)
通常与 `FLAC` 编码文件一起分发的校验和文件，以便你验证其完整性。参见本术语表中 `MD5` 条目以获取有关校验的更多信息。

### `LAC` (免费无损音频编码器)
一种无损音频编码器，通常在不减少原始录制质量的情况下，实现 30% 到 50% 的压缩率。

### `freedb` (免费数据库)
`CDDB` 的开源替代方案，允许用户贡献有关 CD 的信息。

### `ID3 标签`
`MP3` 文件中的 128 字节头部信息，用于提供有关音频文件的信息。`ID3v1` 标签提供专辑、艺术家、通用评论、流派和标题。`ID3v2` 标签以更灵活的形式提供这些信息以及更多内容，允许使用更大的、用户定义的标签，这些标签支持所有 `ID3v1` 标签，但也可以包含歌词和图像等信息。

### `ISO` (国际标准组织)
在 CD 和 DVD 的背景下，`ISO` 指添加到 CD 和 DVD 镜像中的三个字母文件扩展名，用以文件内容符合 `ISO9660` 规范，该规范定义了 CD 和 DVD 格式。人们通常将包含完整 CD 或 DVD 镜像的符合规范的镜像称为 `ISO`。

### `lossless formats` (无损格式)
非有损的文件格式，即提供原始录制、绘图或捕获时音频、图形或视频信息中存在的所有信息的格式。

### `lossy formats` (有损格式)
以牺牲质量来减小文件大小的文件格式。“有损”一词指的是用于减小文件大小的数据压缩算法，原始文件中某些信息实际上被删除了，以生成更小的压缩文件，因此原始文件永远无法从压缩版本中完全重建。在音频文件的情况下，有损图像通常同时降低比特率和录制音频的频率范围，其理论是这些信息的大部分对大多数人来说是不可听的。

### `M4A`
一种音频容器格式，可以包含 `AAC` 或（更常见的）`ALAC` 文件。经过数字权利管理的保护版 `M4A` 文件以 `M4P` 文件的形式交付。

### `MD5`
一种流行的机制，被称为`校验和`，用于验证数字数据文件（尤其是无损音频文件）的完整性。带有此扩展名的文件是文本文件，通常包含一个或多个辅助数据文件的唯一 32 位字符 ID 号。`MD5` 校验值对于随附的数据文件是唯一的，因此通常用于对该文件进行指纹识别（即唯一标识该文件）并验证其完整性。如果你生成了 `MD5` 校验和（使用 Linux 应用如 `md5sum`）且该校验值与文件自带的校验值匹配，则说明文件未被修改。

### `MP3` (MPEG-1 音频层 3)
目前最流行的音频格式，`MP3` 是一种专有的有损编码器，能够从较小的音频文件中产生相对较高质量的声音。

### `MP3 CD`
一张包含 `MP3` 文件而非传统 `CDDA` 音频的光盘。由于 `MP3` 文件比 `CDDA` 音频小，`MP3 CD` 可以存储比传统 CD 多得多的音乐。

### `MPAA` (美国电影协会)
一个致力于以牺牲用户为代价追求行业收入最大化的团体。

### `MPEG` (运动图像专家小组)
负责定义音频和视频标准的财团。

### `MPEG-4`
本书编写时 `MPEG` 的最新代。

### `VBR` (可变比特率)
一种编码类型，通过改变记录音频信息时的比特率，尝试在不显著牺牲质量的情况下减小文件大小。更复杂的音频以更高的比特率记录，而较简单的音频段落则以较低的比特率记录。

### `VCD` (视频光盘)
一种存储设备，能够容约 650MB 的预录制/重写的数字视频和音频信息，这些信息采用 `MPEG-1` 格式编码。大多数 DVD 和 CD 播放器都可以播放 `VCD`，因为它们支持用于解码视频和音频数据的 `MPEG-1` 解码器。

### `WAV`
一种最初由微软和 IBM 开发的数字音频格式，已成为分发无损音频（波形）文件的标准格式。`WAV` 文件由数据块组成，实际上可以使用任何解码器进行解码，但最常见的是包含原始脉冲编码 (`PCM`) 音频数据，这种数据是无损的，因此体积巨大。音频专业人士经常使用 `WAV` 文件来确保最高质量和对原始录音的完全保真。

### `Wavpack`
一种免费的无损音频解码器，主要用于 Windows 系统，但也适用于许多不同的 Linux 发行版、架构和应用程序（如 `XMMS`）。我在 Windows 社区之外没有见过 `Wavpack`，但情况可能有所不同。`Wavpack` 压缩和解压缩文件非常快，且不会损失质量。有关 `Wavpack` 的更多信息，请访问 `www.wavpack.com/`。
