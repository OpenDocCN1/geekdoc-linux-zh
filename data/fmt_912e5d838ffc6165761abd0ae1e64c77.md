
# VPN 简介

首先，什么是 VPN，为什么你需要 VPN？你看，在当今世界，安全是一个巨大的担忧。由于安全漏洞，成千上万甚至数百万美元可能会丢失。当你的绝密或机密信息被盗，或者有人闯入你的计算机系统并删除有价值的数据时，你将遭受巨大的损失。为了防止这种情况发生，创新的开发人员想出了一个被称为 VPN（虚拟私人服务器）的解决方案。VPN 旨在保护你的系统和网络免受入侵。换句话说，你不希望任何人未经授权访问你的网络。这将有助于在你工作时保持数据的安全。

## VPN 的工作原理

下面简要介绍 VPN 是如何工作的。当你在互联网上浏览时，你实际上是在公共网络上。这意味着，如果你的系统完全没有保护，任何怀有恶意的人都可以给你制造各种麻烦。这些问题包括间谍软件、病毒、入侵攻击等。

为了防止这种情况发生，你可以安装额外的硬件或软件。当你安装了作为活动防火墙作用的新设备时，这可能有助于阻止许多攻击。有些人更喜欢用软件来实现，这就是 VPN 的用武之地。

VPN 是虚拟专用网（Virtual Private Network）的缩写。实际情况是你将设置一个私密的隧道，其他人将难以定位。换句话说，对于外界来说，你看起来是匿名的。你通过连接到另一个服务器来实现这一点，该服务器充当你与公共网络连接的代表。当你以这种方式连接到互联网时，你实际上是在一个专用网络上。这是一种更安全的浏览互联网的方式。这种解决方案被称为 VPN。

## VPN 的好处

正如你所能想象的那样，使用 VPN 有很多好处。你享有更多的安全和隐私。例如，如果你正在从无线热点进行浏览，你的用户名和密码可能会被网络上的嗅探器捕获。嗅探软件拦截系统中传输的数据，这就是你的用户名和密码如何被捕获的。但当你通过 VPN 连接时，不存在这种风险。

此外，由于你在专用网络中浏览，你保持了匿名。一些网站会自动记录你的 IP 地址，尤其是那些需要表单提交的地方。当你处于封闭系统中时，你的 IP 地址无法被追踪。这意味着你浏览时享有更多的隐私。

## VPN 网络与安全性

在计算机网络中，信息可以通过加密来保护。加密意味着用一串无意义的乱码替换数据。使用两台机器共享的密钥，可以将这些乱码还原为原始数据。这种加密几乎无法破解，当用于业务通信时，它大大增加了业务享有的安全级别。它对个人连接也非常有用。VPN 服务使用加密以及其他方法来保护信息的安全。

### 隐身模式

VPN 经常被描述为提供用户通过公共网络创建安全隧道的方式。这个类比在解释发生的事情方面相当准确。通过 VPN 交换的信息在互联网上的人员看来是不可见的。这意味着，通过 VPN 连接的人员可以访问其工作资源、私人计算机上的应用程序以及许多其他类型的信息，而无需担心其数据被拦截。正如你可以想象的那样，这项技术有很多用途，但企业是特别重的使用者。

### 无法追踪

VPN 服务提供的另一种安全形式是掩盖你的 IP 地址。你的 IP 地址是服务器用来向你发送你请求信息的数字地址。VPN 服务通过一个服务器为你路由，该服务器将向你访问的网站提供其 IP 地址，而不是你的 IP 地址。这防止了这些网站获取你的个人信息，当然，这也使得任何窥探者都无法说出你在哪里。

### 为什么这对安全很重要

有很多方法你的 IP 地址可能会被用来对付你。如果一个怀着恶意的人知道在你的 IP 地址处建立了业务网络，他们就有了目标。该目标可能会接受端口扫描测试，成为 DDoS 攻击的对象，或者遭受其他各种破坏。隐藏你的 IP 地址是在线保护你安全的一个重要方式。

对你的数据进行加密也是保持在线安全的重要组成部分。在计算机革命到来之前，普通人无法获得现代加密提供的这种安全类型。如今，你可以从 VPN 提供商那里获得加密级别，这使得任何人几乎不可能看到你的信息。

如果你感兴趣在浏览时提高你的安全级别，考虑将 VPN 服务添加到你使用的工具中。这是增加你网络安全水平的强大、有意义且有效的方式。对于你的员工或你来说，这是一种简单的方法，可以从世界任何地方访问你服务器上的信息，而不会暴露它们于攻击之下。这些服务非常实惠，如果你需要从远程位置获取信息，这是一个巨大的技术功能。当你可以控制你的个人信息以及它们在线上对他人如何呈现时，出于业务或娱乐目的浏览都更加安全。

## Tor 是什么，它是如何工作的？

Tor 网络，通常被称为“Tor”，是一个由志愿者运行的系统，有助于让互联网使用更加匿名。

当用户连接到 Tor（通常是通过 Tor 浏览器）时，他们的出站互联网流量在到达目的地（用户想要访问的网站）之前，会先被重新路由通过一系列至少三个随机节点（称为中继）。你的电脑连接到一个入口节点，流量最后通过的节点是出口节点，之后它才到达目的地（你想访问的网站）。传入流量以类似的方式重新路由。
