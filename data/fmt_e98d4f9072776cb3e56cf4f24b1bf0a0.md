## 5.12 Debian 内核

在配置完成后，树树中的头文件封装了所有的选择；源文件本身不会被修改。

正如我们在第8.1.3节中看到的，可以为实际源码树外的任何Debian软件包轻松构建额外的内核模块，这只需要与运行内核对应的头文件。为了实现这一点，Debian存档库为其包含的每个内核镜像提供了一个独立的`kernel-headers-version`软件包，以封装针对特定架构和处理器类型的内核配置。解压后，头文件被安装在`/usr/src/kernel-headers-version`。管理员的工作是提供`/usr/src/linux-symlink`指向其中一个内核头文件目录。

使用适当的内核头文件包，可以构建出与相应内核协同工作的模块，而无需编译内核本身。内核源码包不用于此目的，因为内核树尚未经过配置。如果你正在从内核源码构建自己的内核（参见第8.1节），你可以在该过程的一部分中构建任何额外模块（参见第8.1.3节）；如果你使用的是预包的内核镜像，则需要相应的头文件包才能构建模块（参见第8.1.3节）。

注意，`kernel-headers-<version>`软件包中的内核头文件不应用于开发内核头文件的用户空间软件。对于用户软件，使用与编译C库相同的内核头文件至关重要。填充`/usr/include`的头文件由`linux-kernel-headers`软件包提供。

内核文档（内核源码Documentation目录下的所有内容）可以通过`kernel-doc-<version>`软件包获取，该包会将文件安装到`/usr/share/doc`的相应子目录下。因此，文档已从内核源码包中移除，为只需要安装源码的系统节省空间。

### 5.12.4 内核模块与补丁

Debian内核包为上游内核提供了少量Debian特有的修改和错误修复。额外的功能包含独立的软件包中，并以三种形式之一提供：预编译内核模块、内核模块源码和内核补丁。只有最流行的内核模块扩展，例如PCMCIA模块⁷⁰

> 69 关于此主题的信息可以从此处总结的详细线程中获得：http://www.kerneltraffic.org/kernel-traffic/20000814_80.html#4，以及来自/usr/share/doc/lib6/README.Debian.gz

> ⁷⁰ Debian为2.4内核发布版本的PCMCIA提供了两个独立的模块包：`pcmia-modules-<version>`提供由Linux Card Projects (http://pcmia-cs.sourceforge.net/)提供的成熟驱动，`kernel-pcmia-modules-<version>`是内核自身的驱动。

Linux架构(ALSA)驱动以预编译模块的形式提供给可用内核镜像。例如，`alsa-modules-2.47-2-k7`包含2.47-2-k7内核的ALSA驱动，它安装在`/lib/modules/2.47-2-k7`下的目录中以便与运行的内核直接集成。在编写此时，官方存档中2.6内核系列没有预编译模块，因为大多数模块已在在内核（包括PCMCIA和ALSA驱动）。

与内核独立开发的驱动通常由模块源码包提供。这些模块由独立项目提供，在kernel.org提供的原生内核源码中找不到。例如，`opensaf-modules-source`提供了构建为特定内核版本提供AFS文件系统所需模块的源码。第8.1节涵盖了细节以及如何从此类源码创建模块包。如果一个内核模块包强制要求内核源码，这几乎是一个错误。

Debian分发了许多内核补丁，允许用户单独配置内核以满足某些需求。这些补丁以常规Debian软件包的形式出现，并设计为与`make-kg`集，以便通过单个命令构建修改后的内核。`make-kg`将解释如何进行这些大量的内核定制。例如，`kernel-patch-openmissian`可以让Debian内核轻松转换为兼容OpenSSH的内核，而`kernel-patch-redhat`将Debian内核转换为RedHat选择应用于其内核的相同版本的RedHat内核。Debian内核与其原生版本之间的差异也针对每个版本进行了封装。此外，Debian内核补丁具有“取消还原”的能力。因此，通过`kernel-patch-debian-2.6.8`的帮助，可以使用内核源码包获取原始的内核源码（以2.6.8内核为例）。输出中是否存在Debian修订版本表明源码树对应于Debian还是上游内核。

```bash
# apt install kernel-source-2.6.8

# apt install kernel-patch-debian-2.6.8

# tar xf /usr/src/kernel-source-2.6.8.tar.bz2

# cd kernel-source-2.6.8

# /kernel-source-2.6.8 cat version.Debian

2.6.8

# /kernel-source-2.6.8 /usr/src/kernel-patches/all/2.6.8/unpatch/debian

# /kernel-source-2.6.8 cat version.Debian

2.6.8
```
