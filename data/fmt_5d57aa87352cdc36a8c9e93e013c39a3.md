
Use the `renice` command to alter the scheduling priority of one or more running processes. By default, specify the processes to be affected by their process IDs.

If the first operand is a number within the valid range of priorities (−20 to 20), `renice` treats it as a priority; otherwise, `renice` treats it as an ID.

## Altering Process Priority

Users other than `superuser` can only alter the priority of processes they own and can monotonically increase their nice value within the range 0 to 19. This limitation prevents administrative fiats. `Superuser` can alter the priority of any process and set the priority to any value in the range −20 to 19. Useful priorities are:

- 19—Run the
- 0—Default
- -20—Highest priority

> Note — The `priocntl` command subsumes the function of `renice`.
