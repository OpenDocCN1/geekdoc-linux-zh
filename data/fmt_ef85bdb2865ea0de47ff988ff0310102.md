## linear-gradient()

`linear-gradient()` 函数允许使用 CSS 创建线性渐变。CSS 渐变允许对元素应用多种颜色，并从一种颜色混合到下一种颜色。要创建线性渐变，使用 `linear-gradient()` 作为任何接受图像的属性的值。

### 设置渐变的角度

## opacity()

使用 `opacity()` 函数使图像部分或完全透明。`opacity()` 与过滤器（filter）配合使用，对图像样本应用透明度。`opacity()` 需要传递一个参数。此外，它决定了应用于图像的透明度比例。参数可以是值也可以是数字。

示例：

```html
<!DOCTYPE html>
<html>
<head>
<style>
body {
  padding:0;
  margin:0;
  box-sizing: border-box;
  background: gold;
}
.demo_container{
  padding:20px;
  width:900px;
  margin:0 auto;
justify-content: center;
align-items: center;
}
.box-1{
  transform-origin: 0 0;
  padding: 20px;
  width: 300px;
  height:300px;
  background-color: green;
  filter: opacity(10%);
  color: white;
  font-family: sans-serif;
}
.box-2{
  transform-origin: 0 0;
  padding: 20px;
  width: 300px;
  height:300px;
  background-color: green;
  filter: opacity(40%);
  color: white;
  font-family: sans-serif;
}
```
