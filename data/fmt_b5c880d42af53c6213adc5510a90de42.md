# Linux 词典

webcam
从类似 btv 的 video4linux 设备中捕获并上传摄像头图像，对其进行注释，并使用 ftp 在无限循环中将其上传到 Web 服务器。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

WEBAV
Web 分发与版本控制 (WWW)，来自 Vera 的 "webDAV" `http://www.tld.org/LDP/Linux-Dictionary/index.html`

Webfish Linux
Webfish 是一种基于 GNU 源码包的轻量级精简版 Linux 发行版。Webfish 的设计考虑了经验更丰富的用户，并旨在用于安装了软件包的小型、快速、安全的服务器工作站系统。Webfish Linux 的初始版本 0.9b 早于 2002 年 6 月 20 日发布。1.0pr1 版本于 2003 年 3 月 25 日发布。Webfish Firewall-1 分支于 2002 年 7 月 24 日发布了其初始版本 1.1。Fishwall 1.2 于 2002 年 8 月 27 日发布。源自 LWN 分发列表 `http://www.tld.org/LDP/Linux-Dictionary/index.html`

websf
用于静态内容的轻级 HTTP 服务器。这是一个用于静态内容的简单 HTTP 服务器。例如，你可以通过 ftp 使用平直服务器的内容。它也非常好方便，可以在几秒钟内启动 HTTP 服务器来快速导出文件，而无需编辑某些配置文件。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

weblint
一个用于 HTML 的语法和最小样式更改器。这是一个 Perl 脚本，它提取 HTML 页面的方式与传统的列表编辑器提取 C 程序的方式以同比拟。该脚本本质上是 Berlin 模块的封装器。它支持 HTML 4.0（且仅支持 HTML 4.0）。它可以帮助用户或通过系统级配置文件启用或禁用各种语法和样式选择。注意：这是 Weblint 2.0 的测试版本，提供了最终功能的子集。1.020 版本中的一或两个功能目前不可用。但它实现了几乎所有 1.020 中的警告，并使用了当前的 HTML 标准。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

webmagick
为 WebMagick 创建库缩略图，WebMagick 提供了一种轻松将集合放在网络上的方法。它递归遍历目录树，构建 HTML 和图像（GIF 或 JPEG），允许用户浏览缩略图集（类似于 'xv'）并通过鼠标点击选择图像。源自 Debian 3.0r0 APT `http://www.tld.org/LDP/Linux-Dictionary/index.html`

webmin
一种用于系统的 Web 界面界面。使用 Webmin 可以配置 DNS、samba、NFS/本地、远程文件系统、Apache、Sendmail/postfix，以及更多你的 Web。安装后，在浏览器中输入 URL `http://localhost:10000/` 并以 root 身份登录密码。出于安全考虑，请考虑登录并修改你的密码：请注意，此版本不使用安全的 Web 传输：你必须登录 "`https://localhost:10000/`" 而不是 "`localhost:10000/`"。源自 Mandrake 9.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`
