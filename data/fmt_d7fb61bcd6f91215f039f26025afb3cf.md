## 命令重入

从终端设备输入的最后 `HISTSIZE`（默认128）条命令文本保存在文件中。如果没有设置 `HISTFILE` 变量或文件不可写，使用 `$HOME/.sh_history` 文件。shell 可以访问使用相同 `HISTFILE` 名称的所有交互式 shell 的命令。特殊命令 `fc` 用于列出或编辑此文件的部分。可以通过编号或提供起始和结束部分来选择要编辑或列出的文件部分。如果你指定编辑器程序作为 `fc`，则使用 `FCEDIT` 的值。如果 `FCEDIT` 未定义，则使用 `/bin/ed`。离开编辑器后，编辑后的命令将打印并重新执行。编辑器名称 `-` 用于跳过编辑阶段，并使用 `old=new` 格式的参数在执行前修改命令。例如，如果 `r` 别名为 `fc -`，那么输入 `r bad=good` 将重新执行以字母 `c` 开头的最新命令，将字符串 `bad` 替换为字符串 `good`。

在组合中使用 `fc` 命令从历史文件中删除整个命令。

## 选项

- `-e` 使用名为 `editor` 的编辑器编辑命令。编辑器字符串是一个命令名，取决于 `PATH` 变量。当你没有指定 `-e` 时，使用 `FCEDIT` 变量的值作为默认。如果 `FCEDIT` 为空或未设置，则使用 `ed` 作为编辑器。
- `-h` 显示不带前导数字的历史。使用此选项产生的文件可以通过 csh 内建命令的 `-h` 选项进行加载。

- `-r` 反转列出（-i）或编辑命令的顺序。
- `-s` 在不调用编辑器的情况下重新执行命令。

## 描述

命令历史会创建一个你最近使用过的命令的编号列表。你可以显示这些命令并按照原始发布的方式重新执行它们。你可以通过编辑来更改命令。历史命令的语法和参数在每个 shell 中都不同。

## `/usr/bin/fc`

`fc` 命令列出或重新执行之前在交互式 sh 中输入的命令。
命令历史列表通过数字引用命令。列表中的第一个数字是任意选择的。当你登录且没有其他进程访问该列表时，数字与命令之间的关系不会改变，此时系统可能会重置编号，使最旧的命令从另一个数字（通常是 1）开始。当数字达到 `HISTSIZE` 或 128（以较大者为准）时，shell 可能会循环数字，让下一个命令从较小的数字（通常是 1）开始。然而，尽管有可选的数字循环，`fc` 仍然保持命令的时间顺序。例如，如果按顺序给四个命令赋予数字 32766、32767、1（循环）和 2 执行，那么命令 32767 被视为命令 1 之前的命令，尽管它的数字更高。

当你编辑命令且没有指定 `-1` 选项时，结果行将插入到历史列表的末尾，然后由 sh 重新执行。`fc` 命令本身不会进入历史列表。如果编辑器返回非零退出状态，则该状态将抑制进入历史列表和命令的重新执行。配合 `fc` 使用任何命令行变量赋值或重定向操作符都会同时影响命令本身以及生成的命令。例如，以下命令重新调用了上一个命令，并抑制了 fc 和上一个命令的标准错误。

```
$ fc -s -1 >/dev/null

$
```

### 历史替换

历史替换允许你在命令行中使用之前命令行中的单词而无需输入。这种替换简化了复杂命令或参数的纠正和重复。命令行保存在历史列表中，其大小由 `history` 变量控制。你可以设置 `history` 变量来指定保存的最大命令行数。

```
castle set history = 200
```
