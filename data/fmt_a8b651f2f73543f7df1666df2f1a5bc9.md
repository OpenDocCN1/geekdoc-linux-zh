## 31 流程控制：使用 `case` 进行分支

在本章中，我们将继续研究流程控制。在第 28 章中，我们构建了一些简单的菜单并构建了用于对用户选择采取行动的逻辑。为此，我们使用了一系列 `if` 命令来识别所选的可能选项中的哪一个。这种类型的结构在程序中经常出现，以至于许多编程语言（包括 `shell`）为多项选择决策提供了流程控制机制。

### `case`

`bash` 多项选择复合命令称为 `case`。它具有以下语法：

```
case word in

    [pattern [| pattern]...) commands ;;]...

esac
```

如果我们查看第 28 章中的 `read-menu` 程序，我们可以看到用于对用户选择采取行动的逻辑：

```
#!/bin/bash

# read-menu: a menu driven system information program

clear

echo "

Please Select:

1. Display System Information

2. Display Disk Space

3. Display Home Space Utilization

0. Quit

"

read -p "Enter selection [0-3] > "

if [[ $REPLY =~ ^[0-3]$ ]]; then

    if [[ $REPLY == 0 ]]; then

        echo "Program terminated."

        exit

    fi

    if [[ $REPLY == 1 ]]; then

        echo "Hostname: $HOSTNAME"

        uptime

        exit

    fi

    if [[ $REPLY == 2 ]]; then

        df -h

        exit

    fi

    if [[ $REPLY == 3 ]]; then

        if [[ $(id -u) -eq 0 ]]; then

            echo "Home Space Utilization (All Users)"

            du -sh /home/*

        else

            echo "Home Space Utilization ($USER)"

            du -sh $HOME

        fi

        exit

    fi

else

    echo "Invalid entry." >&2

    exit 1

fi
```

使用 `case`，我们可以用更简单的方式替换这个逻辑：

```
#!/bin/bash

# case-menu: a menu driven system information program

clear

echo ""

Please Select:

1. Display System Information

2. Display Disk Space

3. Display Home Space Utilization

0. Quit

"

read -p "Enter selection [0-3] > "

case $REPLY in

  0)      echo "Program terminated."

          exit

          ;;

  1)      echo "Hostname: $HOSTNAME"

          uptime

          ;;

  2)      df -h

          ;;

  3)      if [[ $(id -u) -eq 0 ]]; then

              echo "Home Space Utilization (All Users)"

              du -sh /home/*

          else

              echo "Home Space Utilization ($USER)"

              du -sh $HOME

          fi

          ;;

  *)      echo "Invalid entry" >&2

          exit 1

          ;;

esac
```

`case` 命令会查看 `word` 的值——在我们的例子中，即 `REPLY` 变量的值——然后尝试将其与指定的模式之一进行匹配。当找到匹配时，将执行与该指定模式关联的命令。一旦找到匹配，就不会再尝试其他匹配。

### 模式

`case` 使用的模式与路径名展开所用的模式相同。模式以`)`字符结尾。表31-1显示了一些有效的模式。

#### 表31-1：`case`模式示例

| 模式 | 描述 |
|---|---|
| `a)` | 如果 `word` 等于 `a`，则匹配。 |
| `[[[:alpha:]]]` | 如果 `word` 是单个字母字符，则匹配。 |
| `???` | 如果 `word` 恰好有三个字符长，则匹配。 |
| `*.txt)` | 如果 `word` 以 `.txt` 字符结尾，则匹配。 |
| `*)` | 匹配 `word` 的任何值。最好将其作为 `case` 命令中的最后一个模式，以捕获未匹配前面模式的任何 `word` 值；也就是说，捕获任何可能的无效值。 |

下面是一个模式起作用的例子：

```
#!/bin/bash

read -p "enter word > "

case $REPLY in

  [[[:alpha:]]]    echo "is a single alphabetic character." ;;

  ABC[0-9]          echo "is A, B, or C followed by a digit." ;;

  ???               echo "is three characters long." ;;

  *.txt)            echo "is a word ending in '.txt'." ;;

  *)                echo "is something else." ;;

esac
```

### 组合多个模式

还可以使用竖线字符作为分隔符来组合多个模式。这会创建一个“或”条件模式。这对于处理大写和小写字符等情况很有用。例如：

```
#!/bin/bash

# case-menu: a menu driven system information program

clear

echo ""

Please Select:

A. Display System Information

B. Display Disk Space

C. Display Home Space Utilization

Q. Quit

read -p "Enter selection [A, B, C or Q] > "

case $REPLY in

  q|Q)  echo "Program terminated."

        exit

        ;;

a|A)

    echo "Hostname: $HOSTNAME"

    uptime

    ;;

b|B)

    df -h

    ;;

c|C)

    if [[ $(id -u) -eq 0 ]]; then

        echo "Home Space Utilization (All Users)"

        du -sh /home/*

    else

        echo "Home Space Utilization ($USER)"

        du -sh $HOME

    fi

    ;;

*)

    echo "Invalid entry" >&2

    exit 1

    ;;

esac
```
