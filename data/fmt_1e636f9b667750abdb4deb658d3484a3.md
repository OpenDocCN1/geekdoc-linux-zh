现在我们到了有趣的部分！让我们先开始这三个函数，因为它们承担了所有的工作。第一个函数是 `ping_host`。这里的思路是设置一个 `case` 语句，并根据 `uname` 命令的响应（该响应被赋值给定义部分的 `UNAME` 变量），如果给出 Unix Linux 变体，则执行 `ping` 命令；否则给用户一个 `ERROR` 信息，并且 shell 脚本以返回代码 `1` 退出。我们必须这样做，因为我们不知道未知操作系统的 `ping` 命令正确语法应该是。

`ping_host` 函数在每次循环迭代中从 `ping_nodes` 函数被调用。在 `ping_nodes` 函数内部，我们确保 `$PINGNODES` 变量设置为 `TRUE`；否则，节点 `ping` 检测将被禁用。

我们使用 `$PINGFILE` 来加载一个变量 `PINGLIST`，其中包含我们想要 `ping` 的节点列表。如果没有 `$PINGFILE`，用户可能会因为单个节点在一段时间内宕机的所有通知而感到苦恼。这里显示了删除注释行并保留剩余节点的命令。

```bash
PINGLIST=$(cat $PINGFILE | grep -v '^#')
```

注意此命令替换是如何工作的。我们 `cat $PINGFILE` 并将其输出通过传输到 `grep` 命令。在语句的 `grep` 部分，我们使用了 `-v` 选项。`-v` 通知 `grep` 列出除模式以外的所有内容，在这种情况下模式是 `^#`。现在让我们来看 `##` 部分。当你在此 `grep` 语句的模式前面加上插入符号 (`^`) 时，我们正在忽略任何以井号 (`#`) 开头的行。插入符号 (`^`) 表示开始。

使用 `$PINGLIST` 变量作为列表启动循环，其中包含了 `/usr/local/bin/ping.file` 列表中未被注释的每个节点。对于列表中的每个节点，我们在屏幕上 `echo` 下一个名称，并在每次循环迭代的命令替换内部调用 `ping_host` 函数，如下：

```bash
echo "Pinging -- $(ping_host $PINGHOST)\c"
PINGSTAT=$($PINGHOST | awk '{print $4}')
```

## 其他需要考虑的选项

一如既往，我们可以改进任何壳脚本，这个脚本也不例外。我列出了一些你可能想要考虑的选项。

### `$PINGLIST` 变量限制问题

在这一脚本解决方案中，我们赋予了用户在 `$PINGFILE` 中注释特定节点的能力。我们将节点列表（带有注释的列表）分配给一个变量。对于较短的节点列表这没有问题，但当超过最大变量长度（通常为 `2048` 个字符）时，问题就出现了。如果你有一个很长的节点列表，你就有问题了。或者如果你看到一个看起来奇怪的主机名（可能是由于变量限制截断并与系统错误消息关联的主机名），你就有问题了。要解决这个问题，定义一个新文件来指向 `PINGLIST` 变量，然后我们将使用该文件来存储 `PING` 列表数据而不是变量。要将 `PINGLIST` 作为文件使用，请添加/修改以下行：

添加此行：

```bash
PINGLIST=$tmp/pinglist.out
```

修改此行：

```bash
cat $PINGFILE | grep -v '^#'
```

修改为此行：

```bash
cat $PINGFILE | grep -v '^#' | > $PINGLIST
```

修改此行：

```bash
for HOSTPING in $$(echo $PINGLIST)
```

修改为此行：

```bash
for HOSTPING in $$(cat $PINGLIST)
```
