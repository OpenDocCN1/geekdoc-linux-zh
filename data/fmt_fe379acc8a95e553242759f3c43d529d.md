
## UninstallColormap

`- display` 指定到 X 服务器的连接。
`- colormap` 指定调色板。

`UninstallColormap` 函数从屏幕所需的列表中移除指定的调色板。结果是，指定的调色板可能被卸载，X 服务器可能会隐式地安装或卸载调色板，所需列表必须保持安装。

如果指定的调色板变为未安装，X 服务器会在每个拥有该调色板的窗口上产生 `ColormapNotify` 事件。此外，对于调用 `UninstallColormap` 导致安装或卸载的其他调色板，会在每个拥有该调色板的窗口上产生 `ColormapNotify` 事件。

`UninstallColormap` 可能会产生 `BadColor` 错误。

要获取给定屏幕当前已安装调色板列表，请使用 `XListInstalledColormaps`。

```
XListInstalledColormaps(display, w, num_return);
```

`- display` 指定到 X 服务器的连接。
`- w` 指定定义屏幕的窗口。
`- num_return` 返回当前已安装调色板的数量。

`XListInstalledColormaps` 函数返回指定屏幕当前已的调色板列表。列表中调色板的顺序并不重要，且没有显式的所需列表。当分配的列表不再需要时，使用 `XFree` 释放它。

`XListInstalledColormaps` 可能会产生 `BadWindow` 错误。

## 设置和检索字体路径

从服务器获取可用字体取决于字体搜索路径。Xlib 提供了设置和检索服务器搜索路径的函数。

要设置字体路径搜索，请使用 `XSetFontPath`。

```
XSetFontPath(display, directories, ndirs);
```

`display` 指定到 X 服务器的连接。

`directories` 指定用于查找字体的目录路径。将路径设置为空路径将恢复 X 服务器的默认路径。

`ndirs` 指定路径中的目录数量。

`XSetFontPath` 函数定义了字体查找的目录搜索路径。每个 X 服务器只有一个搜索路径，而不是每个客户端一个。字符串的编码和解释取决于实现，但通常按顺序对特定目录或字体服务器进行搜索。X 服务器允许缓存字体信息：例如，它可以缓存字体路径的条目。当字体路径更改时，并不要求 X 服务器刷新。其含义取决于实现。

`XSetFontPath` 可能会产生 `BadValue` 错误。

要获取字体路径，请使用 `XGetFontPath`。

```
char **XGetFontPath(display, npaths_return);
```

`display` 指定到 X 服务器的连接。

`npaths_return` 返回字体路径中字符串的数量。

`XGetFontPath` 函数分配一个包含字体路径的字符串数组。这些字符串的内容取决于实现，且不供应用程序解释。当不再需要时，使用 `XFree` 释放它。

```
XFree(list);
```

`list` 指定你想要释放的字符串数组。

## 锁定服务器（Grabbing the Server）

Xlib 提供了你可以使用的函数来锁定和解锁服务器。这些函数可以用于控制其他连接上的输出。当服务器被锁定状态时，任何连接上都不会发生请求处理或关闭操作。关闭的客户端会自动解锁服务器。虽然强烈不建议锁定服务器，但有时是必要的。

要锁定服务器，请使用 `XGrabServer`。

```
XGrabServer(display);
```

`display` 指定到 X 服务器的连接。

`XGrabServer` 函数禁用除请求到达连接之外的所有连接的请求处理和关闭操作。你不应该在绝对必要的情况下锁定服务器。

要解锁服务器，请使用 `XGrabServer`。

```
XGrabServer(display);
```

`display` 指定到 X 服务器的连接。

`XGrabServer` 函数重启其他连接上的请求处理和关闭操作。

## 杀死客户端（Killing Clients）

Xlib 提供了一个函数关闭与客户端的连接并销毁其资源。要销客户端，请使用 `XKillClient`。

```
XKillClient(display, resource);
```

`display` 指定到 X 服务器的连接。

`resource` 指定你想销毁的与客户端关联的任意资源或 `AllTemporary`。

如果指定的资源有效，`XKillClient` 函数强制关闭创建该资源的客户端。如果客户端已经在 `EitherRetain` 或 `RetainTemporary` 模式下终止，则客户端的所有资源将被销毁。如果指定为 `AllTemporary`，所有在 `RetainTemporary` 模式下终止的客户端资源将被销毁（见第 2.5 节）。这允许实现辅助调试的窗口管理器。客户端可以选择将其关闭模式为 `RetainTemporary`。如果客户端崩溃，其窗口将不会被销毁。程序员随后可以应用程序的窗口树并使用窗口管理器销毁这些僵尸窗口。

`XKillClient` 可能会产生 `BadValue` 错误。

## 控制屏幕保护器

Xlib 提供了你使用的函数来设置或重置屏幕保护器的模式、强制或激活屏幕保护器，或获取当前的屏幕保护器值。

要设置屏幕保护器，请使用 `XSetScreenSaver`。

```
XSetScreenSaver(display, timeout, prefer_blanking, allow_exposures);
```

`display` 指定到 X 服务器的连接。

`timeout` 指定以秒为单位的超时时间，直到屏幕保护器开启。

| `interval` | 指定屏幕保护程序更改之间的间隔（单位：秒）。 |
| `prefer_blanking` | 指定如何启用屏幕保护程序的留白。你可以传递 `DontPreferBlanking`、`PreferBlanking` 或 `DefaultBlanking`。 |
| `allow_exposures` | 指定屏幕保护的控制值。你可以传递 `DontAllowExposures`、`AllowExposures` 或 `DefaultExposures`。 |

`Timeout` 和 `interval` 以秒为单位指定。超时为 0 表示禁用屏幕保护程序（但已激活的保护程序不会被禁用），超时为 -1 则恢复默认值。其他负值将产生 `BadValue` 错误。如果值不为零，`XSetScreenSaver` 将启用屏幕保护程序。`interval` 为 0 则禁用随机图案运动。一旦屏幕保护程序激活，如果在指定的 `timeout` 秒数内没有产生来自设备（键盘、鼠标等）的输入，则保持该状态。

对于每个屏幕，如果首选留白且硬件支持视频留白，屏幕将直接变黑。否则，如果允许暴露（exposures）或可以在不向客户端发送事件的情况下重新生成屏幕，则屏幕每隔 `interval` 秒就会使用根背景瓷砖重新排列一次。否则，屏幕状态不会改变，且不会激活屏幕保护程序。在下次键盘或指针输入，或者下次调用模式为 `ScreenSaverReset` 的 `XForceScreenSaver` 时，屏幕保护程序将被禁用，所有屏幕将恢复。

如果取决于服务器的屏幕保护程序支持定期更改，则参数作为关于更改周期的提示，零提示表示不进行周期更改。更改屏幕的方法包括：正确打乱调色板、定期移动屏幕上的图标图像，或定期使用根背景瓷砖对屏幕进行随机重新排列。

`XSetScreenSaver` 产生 `BadValue` 错误。

要强制开启或关闭屏幕保护程序，请使用 `XForceScreenSaver`。

`XForceScreenSaver(display, mode);`

| `display` | 指定到 X 服务器的连接。 |
| `mode` | 指定要应用的模式。你可以传递 `ScreenSaverActive` 或 `ScreenSaverReset`。 |

如果指定的模式为 `ScreenSaverActive` 且屏幕保护程序当前处于禁用，`XForceScreenSaver` 将激活屏幕保护程序，即使该保护程序曾被设置超时为 0 来禁用。如果指定的模式为 `ScreenSaverReset` 且屏幕保护程序已启用，`XForceScreenSaver` 将禁用已激活的屏幕保护程序，并将激活计时器重置为初始状态（如同接收到设备输入）。

`XForceScreenSaver` 产生 `BadValue` 错误。

要激活屏幕保护程序，请使用 `XActivateScreenSaver`。

```
XActivateScreenSaver(display);
```

`display` 指定到 X 服务器的连接。

要重置屏幕保护程序，请使用 `XResetScreenSaver`。

```
XResetScreenSaver(display);
```

`display` 指定到 X 服务器的连接。

要获取当前的屏幕保护程序值，请使用 `XGetScreenSaver`。

```
XGetScreenSaver(display, timeout_return, interval_return,
prefer_blanking_return, allow_exposures_return);
```
