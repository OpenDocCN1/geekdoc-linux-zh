# 调试工具

调试本身是一门科学，也是一种艺术。有时，最简单的工具是代码列表。在其他时候，你需要使用其他工具。其中三个是`lint`、`gprof`和`gdb`。

`lint`是一个检查源代码可能问题的命令。代码可能符合C标准并正确编译，但执行可能不正确。`lint`检查函数调用的不匹配和参数计数错误。`lint`也使用预处理器，因此你可以使用与`gdb`类似的命令行选项。

`gprof`提供了一个研究程序运行时间的环境。如果编译和链接程序时带有`-p`标志，会创建一个`monout`文件，记录每个函数被调用的次数和花费的时间。`gprof`解析并显示这些数据。对`gprof`生成输出的分析有助于确定瓶颈所在。虽然优化器可以加速程序，但`gprof`分析将显著提高程序性能。

# C++ 简介

虽然C语言是与UNIX关联最密的语言，但C++是当今可用大多数图形界面的底层语言。

C++最初由Bjarne Stroustrup博士在AT&T贝尔实验室（新泽西州穆雷希尔）的计算机研究中心开发，那里也是UNIX本身的诞源地。Stroustrup博士最初的目标是一种面向对象的模拟语言。由于许多硬件上都提供了C编译器，这使他决定将该语言设计为C的扩展，允许预处理器将C++程序翻译成C以进行编译。

在1989年美国国家标准协会和国际标准组织（ISO）的联合委员会对C语言标准化后，一个新委员会开始努力定稿C++。这项工作产生了若干个新特性，并显著改进了对其他语言特性的解释，但尚未产生正式的语言标准。

# C++ 编程：基本概念

C++是C语言的面向对象扩展。由于C++是C的超集，C++编译器可以正确编译C程序，而且在C++中可以编写非面向对象的代码。

面向对象语言与过程化语言之间的区别可能是微妙且难以的，特别是对于C++，因为它保留了C的所有特性和概念。描述这种差异的方法是：当程序员用过程化语言编写代码时，他们指定了影响数据的操作；而当他们编写面向对象的代码时，他们创建数据对象，并请求这些对象对自身或关于自身执行操作。

一个C函数接收一个或多个值作为输入，以某种方式对其进行转换或处理，并返回结果。如果传递的值包含指针，数据变量的内容可以被函数修改。然而，作为标准库例程，调用函数的代码可能不知道也不需要知道函数在被调用时采取的步骤。但是，输入参数的数据类型和结果代码等事项是在函数定义时指定的，并且在整个执行过程中保持不变。

函数也与C++对象相关。但正如你所看到的，当调用对象函数时执行的操作取决于与其关联的数据结构的特定类型，存在着巨大且实质性的差异。这被称为重载（overloading function names）。重载与C++的第二个特征有关——函数可以被定义为属于C++数据结构，这一特性是更广泛语言特性“封装”的一个方面。

除了重载和封装外，面向对象语言允许程序员定义新的抽象数据类型（包括关联函数），然后从它们派生出后续的数据类型。除了整数、浮点数和字符等内置类之外，增加一类新的数据对象超越了C语言中熟悉的定义复杂数据对象的能力。就像C数据结构（例如包含一个整数）会继承适用于整数的属性和函数一样，派生自另一个类的C++类也会继承该类的函数和属性。当定义该类类型的特定变量或实例时，它（父类或子类）被称为实例化（instantiated）。

# C 和 C++ 的区别

除了显明显的面向对象特征外，C++在某些细节上与C不同。其中一些是浅层次的，包括：

- 在块内任何位置定义变量的能力
- 增加数据类型以方便基于值的逻辑
- 将函数指定为内联（inline）的能力，导致编译器在程序的该点生成函数的另一个副本，而不是共享代码

其他差异涉及高级概念，如内存管理以及变量和函数名的引用作用域（scope of reference）。

# C 和 C++ 中的引用作用域

“引用（reference）”一词用于讨论C或C++如何允许程序中出现多个同名实例。考虑列表23.10中的代码，它定义并调用了两个不同的函数。每个函数都有一个名为`tmp`的内部变量。同样，在`printnum`中定义的`tmp`局部于`printnum`函数。每个`tmp`的引用作用域局限于`printnum`和`printchar`函数。

## 列表 23.10。引用作用域示例 1。

```

void printchar( char );    /* 函数声明 */
main() {
    printnum(5);
    printchar('a');
}
void printnum(int inputnum) {
    int tmp;
    printf("%d\n",tmp);
}
void printchar(char inputchar) {
    char tmp;
    printf("%c\n",tmp);
}
```
