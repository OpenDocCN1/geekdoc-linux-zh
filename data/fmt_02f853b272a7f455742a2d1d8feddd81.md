## 在 Linux 上使用 Java 编程

Java 是最流行的编程语言之一。它被广泛用于开发从手机到电缆电视盒的几乎所有软件，并将其用途扩展到大型企业信息系统。编写 Java 源代码、编译然后运行的整体概念在大多数操作系统中大同小异。

在很大程度上，过去的编程语言需要你为想要运行程序的每一个新操作系统重新编译所有源代码。例如，一个为在 Windows 上运行而编译的程序，在带有 Linux 的系统上是无法运行的，除非它经过了重新编译。鉴于操作系统和硬件元素之间的巨大差异，这一过程的执行非常困难且复杂。Java 的主要动力之一是，它能够只编写一套唯一的源代码，然后让生成的程序具有在某些不同的操作系统或运行环境中运行的能力。

Java 之所以具有“编写一次，到处运行”的能力，仅仅是因为编译器将特定文件中的整个源代码翻译为一种称为 `字节码`（Byte Code）的形式，这种字节码可以在任何形式的支持的 JRE 或 Java 运行环境下运行。

Java 的开发过程涉及以下步骤：

- 编写 Java 源代码并将其保存在一个或多个纯文本文件中。所有这些文件通常以 `.java` 格式结尾。
- 运行 Java 编译器 (`javac`) 将你编写的源代码编译成字节码文件。字节码的文件名通常以 `.class` 结尾。
- 在将字节码提交给 JRE 后运行程序。
