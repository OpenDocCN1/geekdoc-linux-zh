
具有相同分子式和相同结构，但在空间中原子三维排列不同的化合物被称为立体异性构体。立体异性构体分为两类：彼此互为镜像的称为对映异物，不互为镜像的称为对映异体。对映异物总是成对出现。它们要么与其镜像重合，要么与其镜像不重合并具有一个对映异物。对映异物与其他具有相同熔点、沸点和自由能的异性构体对相似得多。对映异体具有不同的空间排列，当一组中多于两个异性构体时，它们类似于构造异构体，因此它们的物理性质通常不同。

用于预测化学、材料及相关研究中感兴趣的具有计算价值的功能性质的工具。这些包括热力学、电子、光谱和传输性质，以及位点和晶体结构的信息（如形状和尺寸结合）。

两种分子模拟技术是分子动力学和蒙特卡洛模拟，两者都植根于经典统计。分子的结构数学模型提供了势能，可以描述分子的每种构型的能量以及分子之间的相互作用（分子间势能提供了分子在特定构型之间的相对能量），经典力学提供了一个框架，基于对可能性的统计平均来预测大分子集合的性质。

## 分子尺寸

分子的大小与其内部原子的数量和大小成正比。当原子连接时，分子可以被看作半径为 r 和 r' 的原子硬球。核间距离的平衡值约为原子半径之和。

然而，两个分子中的原子核相互靠近不能比 r + r' 更近，其中 r 是原子的范德华半径。

要描述多原子分子，不仅要指定其尺寸，还要指定其形状或构型。例如，二氧化碳 (`CO2`) 是一个线性分子，O—C 角为 180°。正常水分子中的 H—O—H 角为 104.5°。对于包含数千或数百万原子的分子，这些通常被称为扭曲或交叉链，对于它们的功能生物学至关重要。

仅包含振动或转动状态变化的光谱由在空气中精细标记的光带组成。每个带由一组密集的线组成，每条线对应一个中心频率。液体和溶液的振动转动带用于化学分析。所示的异转是模糊的，只出现一个“包络”。参见红外光谱。

偶极矩。大多数分子都有电偶极矩，因为电子通过静电中心围绕原子核，原子中心偶极矩为零；然而，分子偶然可能具有永久偶极矩。

电子带谱是最普通的光谱。对于任何单个分子，光谱由于不同原子能级之间的电子跃迁由许多线组成。参见分子间；分子量；拉曼效应；散射实验（原子与分子）；化价。(R.S.M.)。

因此，当 `H2` 的原子结合在一起时，H 原子电子的某些位移会产生具有电偶极矩的 `H2`，而偶极矩是分子的特征，且偶极矩仅为 10⁻³ D。

分子量。所有原子重量之和。分子量是指分子的分子量，这也称为重量。

原子质量单位 (`amu`) 定义为碳-12 质量的 1/12。参见原子质量单位；相对质量；同位素。

分子是含有阿伏伽德常数 6.022 × 10²³ 原子或分子的物质。它被理解为组成化合物的粒子，质量在数值上等于单位。

分子能量。分子中的运动状态由量子力学决定形成特定的能级。

能量最低的状态是基态；其他都是激发态。激发态仅瞬时存在，或者是振动或电的。

原子的激发可以通过其电子的位移。分子的激发也可以发生，而且此外，分子可以通过振动和转动被激发。

任何分子的总能量可以写为方程 (1)。电子能量 `E_e` 和振动能量 `E_v` 都表示

```
E = E_e + E_v + E_r + E_n + E_{fine}
```

离散或连续。`E_r`、`E_fine` 和 `E_n` 表示转动、精细结构和超细结构。后两者是低能级的微小或分裂。它们通常按顺序排列。

```
E_n > E_fine > E_r > E_v > E_e
```

方程 (1) 指由于将分子置于外场（塞曼效应）或电场（斯坦道效应）产生的额外精细结构。参见精细结构（分子）；超细结构；状态效应；塞曼效应。

分子的总能量比振动和转动能级复杂得多，特别是电子-原子。

分子频率。能量频率可以通过因斯坦-普朗克定律表示：

```
hν = E - E'
```
