# nroff — 为显示或行打印机格式化文档

## 概要
`/usr/bin/nroff` `[-ehiq]` `[-nname]` `[-nN]` `[-opagelist]` `[-raN]` `[-sN]` `[-Tname]`

## 描述
`nroff` 为类打字机设备格式化命名文件中的文本。另请 `troff(1)`。
如果你未指定文件参数，`nroff` 将读取标准输入。由横字符 `-` 组成的参数被视为对应于标准输入的文件。

## 注意事项
之前的文档错误地将数字寄存器 `yr` 描述为“当前年份的最后两位”。实际上，`yr` 是自 1900 年以来的年数。为了获取 2099 年之前当前年份的最后两位，你可以在文档中包含字符串寄存器 `yr` 的以下定义以显示两位年份。注意，你可以用任何其他单字符或双字符寄存器名称替换 `yr`。

## 选项
你可以按任何顺序指定选项，只要它们出现在文件之前即可。

- `-e`
使用全终端分辨率在调整后的行中产生等间距的单词。
- `-h`
在水平间距期间使用输出 Tab 字符以加快输出并减少输出字符数。假设 Tab 设置为八个等宽的名义字符宽度。
- `-i`
在输入文件耗尽后读取标准输入。
- `-mname`
在输入文件之前加上加上宏文件 `/usr/share/lib/tmac/tmac.name`。
- `-nN` 为生成的第 N 页 编号。
- `-opagelist` 打印页码仅出现在逗号分隔的数字和范围列表中的页面。范围 `N-M` 表示从第 N 到第 M 页；初始 `-N` 表示从开始到第 N 页；最后的 `N-` 表示从 N 到结束。
- `-q` 调用 `rd(9F)` 请求的同步输入输出模式。
- `-raN` 将寄存器（单字符）设置为 N。
- `-sN` 每 N 页停止一次（默认 N=1）以允许装纸或更换。在收到换行符时恢复。
- `-Tname` 为指定名称的设备准备输出。已知的名称有：

- `37` Teletype Corporation Model 37 终端（默认）。
- `1p | tn300` GE 任意行打印机或不具备半行能力的终端。
- `300` DASI-300。
- `300-12` DASI-300–12-pitch。
- `300S` DASI-300S。
- `300S-12` DASI-300S。
- `382` DASI-382 (fancy DTC 382)。
- `450` DASI-450 (Diablo Hyterm)。
- `450-12` DASI-450 (Diablo Hyterm)–12pitch。

## `-C`
- 根据当前 `LC_TYPE` 语言类别的设置，将字节解释为单字节或多字节字符。将可打印的多字节字符写入对应字符第一个字节的区域；在字符的每个剩余字节对应的区域写入双字符序列 `**`，用以指示该字符是连续的。某些非图形字符以 C 转义字符的形式出现：

+ `-` `\0` 空格符。
+ `\b` 退格符。
+ `\f` 换页符。
+ `\n` 换行符。
+ `\r` 回车。
+ `\t` 制表符。

其他不可打印字符显示为字符中每个字节的一个 3 位八进制数。

- `-d` 以无符号十进制解释字（words）。此选项等同于 `-t u2`。
- `-D` 以无符号十进制解释长字。此选项等同于 `-t u4`。
- `-f` 以浮点数解释长字。此选项等同于 `-t f4`。
- `-F` 以扩展精度解释双倍长字。此选项等同于 `-t f8`。
- `-j skip` 跳过输入开头的 skip 字节。如果 `od` 命令读取或寻到的连接输入中的第一个 skip 字节短于 skip 字节，则向标准错误写入诊断消息并以非零退出状态退出。

默认情况下，skip 参数被解释为十进制数。如果以 `0x` 或 `0X` 开头，偏移量被解释为十六进制数；否则，如果以 `0` 开头，偏移量被解释为八进制。以 `b`、`k` 或 `m` 结尾的字符将其解释为 512、1024 或 1048576 字节的倍数。如果 skip 数字是十六进制，考虑任何从 `0000000` 开始的附加部分，不要根据 skip 参数的基数推断其基数。

- `-N count` 格式化不超过 count 字节的输入。默认情况下，count 解析为十进制。如果以 `0x` 或 `0X` 开头，count 被解释为十六进制；否则，如果以 `0` 开头，则解释为八进制。如果（在成功指定 `-j skip` 后）没有足够的 count 字节输入，则不被视为错误；`od` 命令将格式化可用的输入。显示地址的基数不由 count 参数的基数推断。

+ `-o` 以八进制解释字。此选项等同于 `-t o2`。
+ `-O` 以无符号八进制解释长字。此选项等同于 `-t o4`。
+ `-s` 以有符号十进制解释字。此选项等同于 `-t d2`。
+ `-S` 以有符号十进制解释长字。此选项等同于 `-t d4`。
+ `-t type-string` 指定一个多个输出类型。type-string 参数必须是一个指定写入输入数据时使用的类型的字符串。该字符串必须由类型规范字符组成。

+ `-a` 将字节解释为命名字符。对于此类型规范，仅使用每个字节的低位。使用下表值的字节将使用其对应的名称写入。

| 值 | 名称 | 值 | 名称 | 值 | 名称 | 值 | 名称 |
|---|---|---|---|---|---|---|---|
| `\000` | null | `\001` | soh | `\002` | st | `\003` | etx |
| `\004` | eot | `\005` | enq | `\006` | ack | `\007` | bel |
| `\010` | bs | `\011` | ht | `\012` | lf | `\013` | vt |
| `\014` | ff | `\015` | cr | `\016` | so | `\017` | si |

| `\030` | can | `\035` | gs | `\036` | rs | `\037` | us |

根据当前 `LC_CTYPE` 语言类别的设置将字节解释为单字节或多字节字符。将可打印的多字节字符写入对应字符第一个字节的区域；在字符的每个剩余字节对应的区域写入双字符序列 `**`，用以指示该字符是连续的。某些非图形字符以 C 转义字符的形式出现：`\0`, `\a`, `\b`, `\f`, `\n`, `\t`, `\v`。其他不可打印字符显示为字符中每个字节的一个 3 位八进制数。

- `-x` 以十六进制解释字。此选项等同于 `-t x2`。
- `-X` 以十六进制解释长字。此选项等同于 `-t x4`。
- `-v` 显示所有输入数据（详细模式）。如果没有 `-v` 选项，将所有与紧邻输出行相同（字节偏移除外）的输出行替换为星号（`*`）。

## 操作数
`/bin/od` 和 `/usr/bin/od` 均支持以下操作数。

+ `-A` 将标准输入用于任何文件。当你不指定此操作数时，只有在没有指定文件操作数时才使用标准输入。
+ `file path` 要读取的文件路径。如果没有指定文件操作数，则使用标准输入。如果有两个以上的操作数，且指定了 `-A`、`-j`、`-N` 或 `-t` 选项中的任意一个为真，则假设对应的操作数是文件。

# on — 在远程系统上执行命令，并使用本地环境

### 概要
`/usr/bin/on [-i][-d][-n] host command [argument] ...`

## 说明
使用 `on` 命令在另一个系统中以类似于调用程序的环境执行命令。所有的环境变量都会传递，并且保留了当前的工作目录。为了保留工作目录，当前的工作文件系统必须已经在主机上挂载或导出到该主机。相对路径名仅当它们位于当前文件系统内时有效；绝对路径名可能会问题。
标准输入连接到远程命令的标准输入，而远程命令的标准输出和标准错误发送到 `on` 命令对应的文件中。

### 缺陷
当工作目录通过 NFS 远程挂载时，Control-Z 会挂起窗口。
root 用户无法使用 on..

# Options

- `-i` 使用远程回显和特殊字符处理。此选项对于期望与终端通信的程序所需的。所有的终端模式和窗口大小变化都会传递。
- `-d` 按照执行情况打印调试信息。
- `-n` 当 `on` 命令从标准输入读取时，获取文件结束符，而不是从 `on` 程序的标准输入传递标准输入。例如，当在作业控制下在后台运行命令时，需要使用 `-n` 选项。
