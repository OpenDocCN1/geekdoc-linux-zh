
## 技术

我们之前提到过 `/etc/shadow` 是由 `/etc/passwd` 生成的。在 Red Hat 和 Solaris 上执行此任务的命令是 `pwconv`。它不接受任何参数并执行以下任务：

- 检查 `/etc/shadow` 是否存在，必要时创建它。

对于新的 `/etc/shadow` 文件：

- 为每个用户创建一个新条目。
- 在新条目中添加用户名、密码哈希和密码过期信息（如果有）。
- 更新“自上次修改密码以来的时间”字段。

对于已存在的 `/etc/shadow` 文件：

- 检查每个用户 `/etc/passwd` 第二字段中是否存在 `'x'`。如果找到，则不会修改 `/etc/shadow` 中该用户的密码哈希。
- 为出现在 `/etc/passwd` 中但不在 `/etc/shadow` 中的用户添加条目。将用户名、密码哈希和密码过期信息（如果有）添加到新条目中。
- 删除出现在 `/etc/shadow` 中但不在 `/etc/passwd` 中的用户条目。
- 更新每个剩余条目的密码哈希、密码过期信息和“自上次修改密码以来的时间”字段。

让我们通过一个用户条目的转换示例将所有内容整合在一起：

原始 `/etc/passwd` 条目：

```
valjean:uOPX3ZMn:Ji::246010:Jean Valjean:/home/users/valjean:/bin/tcsh
```

运行 `pwconv` 之后，有两个条目。`/etc/passwd` 中修改后的：

```
valjean:x:246010:10:Jean Valjean:/home/users/valjean:/bin/tcsh
```

这里是 `/etc/shadow` 中的新条目：

```
valjean:uOPX3ZMn:Ji::11369:::::
```

你可能注意到，这个 shadow 条目中的数字比图 4.3 显示的示例少得多。这是因为我们没有在 `/etc/shadow` 文件中存储任何密码过期信息。第九个也是最后一个字段包含一个预留供未来使用的标志。它目前对系统没有影响，但建议将该字段留空。

## 基础操作

第一部分

设置所有可能的密码过期和活动字段涉及两个步骤。第一步是修改 `pwconv` 在转换时使用的模板文件。第二步是发布 `usermod` 命令来设置非活动锁定。当然，在 Red Hat 系统上，`/etc/login.defs` 包含了应用于所有用户账户的默认值。三个变量设置了系统密码过期的参数：`PASS_MAX_DAYS`、`PASS_MIN_DAYS` 和 `PASS_WARN_AGE`。要让 `valjean` 拥有图 4.3 所示的设置，文件中显示为：

```
PASS_MAX_DAYS 120
PASS_MIN_DAYS 3
PASS_WARN_AGE 21
```

要添加最大非活动天数的进一步限制，调用 `usermod` 命令：

```
usermod -f 7 valjean
```

另一方面，Solaris 将密码过期信息保留在自己的文件中：`/etc/default/passwd`。相关的参数名为 `MINWEEKS`、`MAXWEEKS` 和 `WARWEEKS`。要让 `valjean` 拥有图 4.3 所示的设置，这些设置在文件中显示为：

```
MINWEEKS=1
MAXWEEKS=17
WARWEEKS=3
```

> 注意：Solaris 强制你使用周作为时间单位。当然，这意味着你不能将最小过期时间设置为少于七天的任何值（除非你将其设置为 0）。你还被限制将最大密码寿命设置为 119 天（17 周）而不是 120 天。

现在，为了添加最大非活动天数的进一步限制，调用 `usermod` 命令，如下：

```
usermod -f 7 valjean
```

注意，即使在 Solaris 下，此值也是以天指定的。

现在 `valjean` 的 `/etc/shadow` 条目看起来像我们之前的示例：

```
valjean:uOP3ZMQm:Ji::11369:3:120:21:7::
```

Red Hat 提供了一种方便且直观的方法来退出影子密码架构：`pwunconv`。该命令在 Solaris 上不可用。`pwunconv` 解析 `/etc/shadow` 中的条目并更新 `/etc/passwd` 中对应用户名的密码哈希。任何存在于 `/etc/passwd` 中但不在 `/etc/shadow` 中的条目都会被该命令原样保留。成功运行后，`pwunconv` 会删除 `/etc/shadow`。注意 `pwunconv` 会丢失一些密码过期信息。

## `/etc/gshadow`

Red Hat 还提供了对 `/etc/gshadow` 中组条目的影子处理能力。如果你的系统中具有非空密码的组，这将非常有用。

`/etc/gshadow` 文件中的条目由冒号分隔的字段组成，其功能与通用 `/etc/shadow` 文件相同：

```
groupname:password_hash:admin-list:<user-list>
```

第一个字段包含该条目的组名。它是唯一能匹配 shadow 条目与 `/etc/group` 条目的字段。

第二个字段包含密码哈希，其特征已在前面关于 `/etc/passwd` 的章节中描述。

第三个字段是新的。它包含一个用逗号分隔的用户列表，这些用户被指定为组管理员。组管理员允许更改组密码和成员。

第四个字段是属于该组的用户列表。
