# 处理 SGML 页面

通过存在字符串 `<DOCTYPE>` 来识别标记为 SGML 的手册页。如果文件还包含 `SHADOW_PAGE` 字符串，则该文件引用另一个手册页的内容。通过实体引用引用手册页。这种机制类似于 nroff 格式手册页中使用的 `.so` 机制。

# 处理 nroff 页面

在格式化 nroff 页面时，`man` 检查第一行以确定是否需要特殊处理。如果第一行是如下形式的字符串：


其中 X 与 `"` 之间由单个空格分隔，并由以下列表任意字符组成：`eqn(1)`。如果调用 `eqn` 或 `neqn`，`man` 将自动读取文件。如果调用 `nroff(1)`，则将自动使用 `col(1)`。对于 `eqn` 标志产生的垂直运动，请参见 `eqn(5)`。

# mconnect — 连接到 SMTP 邮件服务器套接

# 语法

```
/usr/bin/mconnect [-p port][ -r][hostname]
```

## 描述

`mconnect` 打开到给定主机邮件服务器的连接，以便独立于所有主机软件测试邮件服务器。如果没有给出主机，则连接到本地主机。服务器期望在此连接上使用简单邮件传输协议 `SMTP`。输入 `quit` 命令退出。输入 EOF 会向服务器发送文件结束符。中断将立即关闭连接并退出。

## 选项

- `-p port` 指定端口号作为下一个参数，而不是默认的 SMTP 端口（数字 25）。
- `-r` 禁用默认行缓冲和输入处理，以原始模式运行。此选项产生的效果类似于 telnet 到第 25 端口。

# mcs — 操作对象文件的注释段

# 语法

```
/usr/ccs/bin/mcs {-c | -d | -p | -V | -a string | -n name}... file...
```

## 描述

使用 `mcs` 命令操作 ELF 对象文件中的某个段（section）。默认段是 `.comment`。`mcs` 用于添加、删除、打印和压缩 ELF 对象文件中的某个段的内容，并仅打印通用对象文件格式 `COFF` 对象文件中某个段的内容。`COFF` 是一种在某些计算机架构上早于 ELF 的对象文件格式。`mcs` 无法对段（segment）内的段内容进行添加、删除或压缩。

如果输入文件是归档文件（参见 `ar(4)`），则归档文件被视为一组单独的文件。例如，如果你指定了 `-a` 选项，字符串将附加到归档中每个 ELF 对象文件的注释段中；如果该归档成员不是 ELF 对象文件，则保持保持不变。

> 注意 — 当 `mcs` 使用 `-d` 选项删除一个段时，它会尝试将类型为 `SHT_REL` 的段以及由 `sh_info` 段标头字段指向的目标段结合在一起。如果其中一个需要被删除，`mcs` 会尝试删除该对中的另一个。

# mcs 823

## 选项

你必须指定下面描述的一个或多个选项。每个指定的选项都将按顺序应用于每个文件。

- `-a string` 在 ELF 对象文件的注释段末尾附加 `string`。如果 `string` 包含空格，请用引号将其括起来。
- `-c` 压缩 ELF 文件的内容。
- `-d` 删除 ELF 文件的内容。
- `-n name` 指定段的名称。
- `-p` 打印段的内容。
- `-v` 打印段的版本。

## 826 mkdir

## 选项

`-m mode` 指定用于新目录的模式。模式的选择可以在 `chmod(1)` 中找到。

- `-p` 通过先创建所有不存在的父目录来创建目录。赋予中间目录的模式是 777 与文件模式创建掩码（`umask`）中设置位之间的差值。该差值至少为 300（用户的写入和执行权限）。

### 操作数

- `dir` 要创建的目录的路径名。

## 用法

关于 `mkdir` 在遇到大于或等于 2 Gbytes (`2**31` 字节) 的文件时的行为描述，请参阅 `largefile(5)`。

## 示例

以下示例创建了子目录结构 `ltr/jw/jan`。

```
castle% mkdir -p ltr/jw/jan
castle% ls -la

2 drwxr-xr-x 10 winsor staff 512 Mar 15 15:30 ..
2 drwxr-xr-x 3 winsor staff 512 Mar 15 15:30 ltr
castle% cd ltr
castle% ls -la
total 6
2 drwxr-xr-x 3 winsor staff 512 Mar 15 15:30 .
2 drwxr-xr-x 3 winsor staff 512 Mar 15 15:30 ..
2 drwxr-xr-x 3 winsor staff 512 Mar 15 15:30 jw
castle% cd jan
castle% ls -la
total 4
2 drwxr-xr-x 2 winsor staff 512 Mar 15 15:30 .
2 drwxr-xr-x 3 winsor staff 512 Mar 15 15:30 ..
```
