
# Linux 常用命令示例

## 查找 Linux 打开文件限制

**Command:**
```bash
cat /proc/sys/fs/file-max
```

**Description:**
查找 Linux 打开文件限制

## 检查 Linux 硬限制

**Command:**
```bash
ulimit -Hn
```

**Description:**
检查 Linux 中的硬限制

## 检查 Linux 软限制

**Command:**
```bash
ulimit -Sn
```

**Description:**
检查 Linux 中的软限制

## 显示系统当前的时间和日期

**Command:**
```bash
timedatectl status
```

**Description:**
显示系统当前的时间和日期

## 查看所有可用时区

**Command:**
```bash
timedatectl list-timezones
```

**Description:**
查看所有可用时区

## 根据位置查找本地时区

**Command:**
```bash
timedatectl list-timezones | egrep -o "Asia/B.*"
timedatectl list-timezones | egrep -o "Europe/L.*"
timedatectl list-timezones | egrep -o "America/N.*"
```

**Description:**
根据你的位置查找本地时区

## 在 Linux 中设置本地时区

**Command:**
```bash
timedatectl set-timezone "Asia/Kolkata"
```

**Description:**
在 Linux 中设置你的本地时区

## 查看设备交换分区使用摘要

**Command:**
```bash
swapon --summary
```

**Description:**
查看设备交换分区使用摘要

## 检查交换分区使用信息

**Command:**
```bash
cat /proc/swaps
```

**Description:**
检查交换分区使用信息

## 开始记录 Linux 终端

```bash
# start recording of Linux terminal
script history_log.txt
Script started, file is history_log.txt

Script done, file is history_log.txt
```

## 列出文件及其按块计算的尺寸

**Command:**
```bash
dir -shl
```

**Description:**
列出文件及其按块（blocks）计算的尺寸

## 显示关于 CD-ROM 的信息

**Command:**
```bash
less /proc/sys/dev/cdrom/info
```

**Description:**
显示关于 CD-ROM 的信息

## linux

### 命令
```bash
find . -user root
```
**说明:**
输出当前目录中由用户 `root` 拥有的文件

### 命令
```bash
strace pwd
```
**说明:**
追踪命令 `pwd` 的执行

### 命令
```bash
top -u manju
```
**说明:**
显示特定用户 `manju` 的进程详情

- 大数据的三个特征：
- **数据量（Volume）** —— 数据量有多大？
- **多样性（Variety）** —— 不同类型的数据有多多样？
- **速度（Velocity）** —— 新数据的生成速度有多快？

```bash
[manju@localhost ~]$ netstat -plunt
# 打印所有监听端口

[manju@localhost ~]$ netstat -plunt | grep 8080
# 检查服务器是否监听 8080 端口

[manju@localhost ~]$ netstat -s
# 列出所有端口的统计信息
```

```bash

# 在当前目录及其所有子目录下查找以 .txt 结尾的文件
```

```bash
find /etc > 12.txt
# 查找 /etc 下的所有文件并将列表存入 12.txt

```

```bash

false
```

```bash
true

```

