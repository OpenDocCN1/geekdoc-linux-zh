### 8.9 mprotect: 设置内存权限

监控程序内存使用的一种方便方法是使用 `top` 命令。在 `top` 的输出中，`SIZE` 列显示每个程序的虚拟地址空间大小（程序代码、数据和堆栈的总大小，这些部分可能被映射到交换空间）。`RSS` 列（驻留内存集）显示每个程序当前所占用的物理内存大小。所有程序的 `RSS` 值之和不能超过计算机的物理内存，且所有地址空间之和被限制为 2GB（对于 32 位的 Linux 版本）。

监控内存访问的一种高级技术是使用 `mmap` 或 `mprotect` 保护内存区域，并处理 Linux 在访问该内存时发送给程序的 `SIGSEGV` 信号。代码列表 8.7 中的示例说明了这种技术。

代码列表 8.7 `mprotect.c` 使用 mprotect 检测内存访问

```
#include <fcntl.h>
#include <signal.h>
#include <stdio.h>
#include <string.h>
#include <sys/mman.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <unistd.h>

static int alloc_size;
static char *memory;

void segv_handler(int signal_number)
{
    printf("memory accessed!\n");
    mprotect(memory, alloc_size, PROT_READ | PROT_WRITE);
}

int main ()
{
    int fd;
    struct sigaction sa;

    /* 将 segv_handler 作为 SIGSEGV 的处理器。 */
    memset(&sa, 0, sizeof(sa));
    sa.sa_handler = &segv_handler;
    sigaction(SIGSEGV, &sa, NULL);

    /* 通过映射 /dev/zero 分配一页内存。初始将内存
    映射为只写。 */
    alloc_size = getpagesize();
    fd = open("/dev/zero", O_RDONLY);
    memory = mmap(NULL, alloc_size, PROT_WRITE, MAP_PRIVATE, fd, 0);
    close(fd);

    /* 写入页以获取私有副本。 */
    memory[0] = 0;
    /* 使内存变为不可写。 */
    mprotect(memory, alloc_size, PROT_NONE);

    /* 写入分配的内存区域。 */
    memory[0] = 1;
```

```
/* 全部完成；取消内存映射。 */
printf("all done\n");
munmap(memory, alloc_size);
return 0;
}
```

该程序遵循以下步骤：

1. 程序为 `SIGSEGV` 安装了信号处理函数。

2. 程序通过映射 `/dev/zero` 分配一页内存，并向分配的页写入值以获取私有副本。

3. 程序通过调用带有 `PRO_NONE` 权限的 `mprotect` 来保护内存。

4. 当程序随后写入内存时，Linux 发送 `SIGSEGV`，该信号由 `nanosleep_handler` 处理。信号处理函数取消内存的保护，允许内存访问继续。

5. 当信号处理函数完成后，返回 `main` 函数，程序在主函数中使用 `munmap` 释放内存。

### 8.10 nanosleep: 高精度睡眠

`nanosleep` 系统调用是标准 UNIX `sleep` 的高精度版本。`nanosleep` 的第一个参数是 `timespec` 结构指针，表示要睡眠的时间；第二个参数是用于在中断时返回剩余时间的 `timespec` 结构指针。如果第二个参数为 `NULL`，则不返回剩余时间。

`nanosleep` 与 `sleep` 的区别在于它能提供纳秒级的精度，并且在被信号中断时可以返回剩余的睡眠时间。

`nanosleep` 的 `timespec` 结构包含两个字段：`tv_sec`（秒）和 `tv_nsec`（纳秒）。`tv_nsec` 的值必须在 0 到 999,999,999 之间。如果 `nanosleep` 成功，返回 0；如果被信号中断，则返回 -1 并将 `errno` 设置为 `EINTR`。

代码列表 8.8 `better_sleep.c` 高精度睡眠

```
#include <errno.h>
#include <time.h>
#include <unistd.h>

int better_sleep(double sleep_time)
{
    struct timespec tv;
    /* 从秒数构造 timespec */
    tv.tv_sec = (time_t)sleep_time;
    tv.tv_nsec = 0;

    while (1) {
        int rval = nanosleep(&tv, &tv);
        if (rval == 0)
            /* 完成了整个睡眠 */
            return 0;
        else if (errno == EINTR)
            /* 被信号中断。重试。 */
            continue;
        else
            /* 发生其他错误；打印通用消息。 */
            perror("nanosleep");
    }
}
```

### 8.12 sendfile: 快速数据传输

`sendfile` 系统提供了一种从一个文件描述符拷贝数据到另一个文件描述符的高效机制。这些文件描述符可以是磁盘文件、套接字或其他设备。

通常，为了从一个文件描述符拷贝到另一个文件描述符，程序分配一个固定大小的缓冲区，从源描述符拷贝一些数据到缓冲区，将缓冲区写入另一个描述符，并重复直到所有数据拷贝完成。这在时间和空间上都是低效的，因为需要额外的内存作为缓冲区，并且会对该缓冲区执行额外的数据拷贝。

使用 `sendfile` 可以消除中间缓冲区。调用 `sendfile` 并传递用于写入的文件描述符；读取的描述符；指向偏移量变量的指针以及要传输的字节数。偏移量变量包含输入文件中从读取开始的偏移量（0 表示文件开头），并在传输后更新为文件中的相应位置。返回值为传输的字节数。如果你使用 `sendfile`，请在程序中包含 `<sys/sendfile.h>`。

列表 8.10 中的中的程序是一个简单而高效的文件复制实现。当在命令行带有两个文件名调用时，它会将第一个文件的内容复制到由源定义的名称中。它使用 `stat` 来确定源文件以字节为单位的大小。

#### 列表 8.10 使用 sendfile 复制文件

```
#include <fcntl.h>
#include <stdlib.h>
#include <stdio.h>

#include <sys/sendfile.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <unistd.h>

int main(int argc, char *argv[]) {

    int read_fd;
    int write_fd;
    struct stat stat_buf;
    off_t offset = 0;

    /* 打开输入文件。 */
    read_fd = open(argv[1], O_RDONLY);
    /* 统计输入文件以获取大小。 */
    fstat(read_fd, &stat_buf);
    /* 打开输出文件进行写入，权限与源文件相同。 */
    write_fd = open(argv[2], O_WRONLY | O_CREAT, stat_buf.st_mode);
    /* 将字节从一个文件传输到另一个文件。 */
    sendfile(write_fd, read_fd, &offset, stat_buf.st_size);
    /* 关闭。 */
    close(read_fd);
    close(write_fd);

    return 0;
}
```

`sendfile` 可以用于许多地方以使复制更高效。一个很好的例子是在 Web 服务器或其他网络守护进程中，它们通过网络向客户端程序提供文件内容。通常，会从连接到客户端计算机的套接字接收请求。服务器程序打开本地磁盘文件以检索要提供的数据，并将文件内容写入网络套接字。使用 `sendfile` 可以显著加快操作速度。为了使网络传输尽可能高效，还需要采取其他步骤，例如正确设置套接字参数。然而，这些超出了本书的讨论范围。

### 8.13 setimer: 设置间隔定时器

`setimer` 调用是 `alarm` 调泛化。它调度在固定时间流逝后，在未来的某个点递送信号。程序可以使用 `setimer` 设置三种类型的定时器：

- 如果代码为 `ITIMER_REAL`，则在指定的挂钟时间通过后，向进程发送一个 `SIGALRM` 信号。

- 如果代码为 `ITIMER_VIRTUAL`，则在进程执行指定时间后，向进程发送一个 `SIGVTALRM` 信号。进程未执行的时间（即内核或其他进程正在运行的时间）不计入内。

- 如果代码为 `ITIMER_PROF`，当在进程执行期间或代表进程执行系统调用期间指定的时间通过时，向进程发送一个 `SIGPROF` 信号。

`setimer` 的第一个参数是定时器代码，指定要设置哪种定时器。第二个参数是指向 `struct itimer` 对象的指针，指定了该定时器的新设置。第三个参数如果不为空，则是一个指向另一个 `struct itimer` 对象的指针，用于接收旧的定时器设置。

`struct itimer` 变量有两个字段：

- `it_value` 是一个 `struct time` 字段，包含到定时器过期并发送信号所需的时间。如果其为 0，则定时器被禁用。
