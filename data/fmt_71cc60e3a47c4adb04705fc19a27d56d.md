
# files_struct

`files_struct` 数据结构描述进程已打开的文件。

```c
struct files_struct {
  int count;
  fd_set close_on_exec;
  fd_set open_fds;
  struct file *fd[NR_OPEN];
};
```

> `include/linux/sched.h`

struct fs_struct {

# gendisk

`gendisk` 数据结构持有关于硬盘的信息。它们在初始化期间发现磁盘并对分区进行探测时使用。

> `include/linux/genhd.h`

```c
struct hd_struct {
  long start_sec;
  long nr_sects;
};
```

```c
struct gendisk {
  int major; /* 驱动的主号 */
  const char *major_name; /* 主驱动的名称 */
  int minor_shift; /* 次号左移的次数 */
  get real minor(); /* 每个设备的最大分区数 */
  int max_p;
  int max_nr; /* 真实设备的最大数量 */
};
```

```c
void (*init)(struct gendisk *);
/* 在我们之前调用初始化
struct hd_struct *part;    /* 分区表 */
int *sizes;                /* 设备块大小，复制到 */
int *nr_real;               /* 真实设备数量 */
void *real_devices;        /* 内部使用 */
struct gendisk *next;
```

# ipc_perm

`ipc_perm` 数据结构描述 System V 对象的权限。

```c
struct ipc_perm {
  key_t key;
  unsigned short uid; /* 所有者 */
  unsigned short gid; /* 创建者 */
  unsigned short cgid;
  unsigned short mode; /* 访问模式 */
  unsigned short seq; /* 序列号 */
};
```

# mem_map_t

`mem_map_t` 数据结构（也称为 `page`）用于持有物理内存每页的信息。

```c
typedef struct page {
    /* 必须是（空闲区域处理） */
    struct page *next;
    struct page *prev;
    struct inode *inode;
    unsigned long offset;
    struct page *next_hash;
```
