
Tor 基于与 Firefox 相同的代码，因此如果你使用过 Mozilla 的网页浏览器，一切似乎都会相当熟悉。即使你以前没有使用过 Firefox，你也不需要太久就能感觉宾至如归——它与 Edge、Chrome 和 Safari 等浏览器并无太大不同。

### 3. 选择你的安全级别

在开始之前，值得注意的是，使用 Tor Browser 是在隐私/安全和网页可用性之间寻求平衡。默认情况下，安全级别设置为“标准”——尽管这仍然比任何其他网页浏览器安全得多。

如果你想增加安全级别，请点击地址栏左侧的洋葱图标并选择“安全设置”。使用“安全级别”滑块选择你首选的保护级别，同时留意关于可能会在你访问的网站停止工作的功能的警告。

### 4. 重新思考你的浏览习惯

为了充分利用 Tor，你需要改变一些浏览习惯——其中第一个就是你使用的搜索引擎。

与其选择 Google 和 Bing 等搜索引擎，建议改为使用 Disconnect.me。这是一个防止搜索引擎在线跟踪你的网站，你可以将其与 Bing、Yahoo 或 DuckDuckGo 一起使用。

既然提到了改变习惯，你还需要避免安装浏览器扩展程序，因为这些扩展程序可能会泄露私人信息。

### 5. 理解 Tor 电路

当你浏览互联网时，Tor 浏览器通过避免直接连接到网站来帮助你保持安全。相反，你的连接会在 Tor 网络上的多个节点之间跳跃，每次跳跃都包含匿名化过程。

这不仅使网站几乎不可能追踪你是谁以及你身在何处，也是导致你在使用 Tor 浏览时注意到稍慢性能的原因。

如果你觉得性能异常低或页面不再响应，你可以通过点击汉堡图标并选择“为此网站创建新的 Tor 电路”选项来开始一个新的 Tor 电路，这将强制 Tor 寻找到该网站的新路线。

### 6. 创建新的身份

新电路选项仅适用于当前活动的标签页，你可能需要更严格的隐私安全网。点击汉堡图标并选择“新身份”，请记住这将关闭并重启 Tor 以获得新的 IP 地址。

当你使用 Tor 连接到网站时，你可能会注意到出现一个弹出窗口，警告你某个特定网站正在尝试做一些可能会用于跟踪你的事情。这些消息出现的频率不仅取决于你访问的网站，还取决于你设置的隐私设置。

### 7. 使用 HTTPS

在线保持安全和匿名的一个重要部分是确保你使用网站的 HTTPS 版本而非 HTTP 版本。为了让你不必记住每个访问的网站都要这样做，Tor Browser 默认安装了 HTTPS Everywhere 扩展程序。如果网站提供安全版本，它将尝试将你重定向到该版本，但你应密切关注地址栏作为额外的保障措施。

如果你连接到安全网站，你将看到一个绿色的锁图标。如果不存在此图标，请点击“i”图标以获取更多信息。

### 8. 访问 .onion 网站

然而，通过 Tor 连接互联网的最安全方式是访问 `.onion` 网站。这些也被称为隐藏 Tor 服务，搜索引擎无法访问；要找到它们，你必须直接访问。

这些网站只能使用 Tor 访问，但你需要注意——遇到包含非法内容、销售非法产品或推广非法活动的网站相当常见。

### 9. 尝试 Tor over VPN

如果你想将隐私提升到下一个级别，你可以在启动 Tor 浏览器之前连接到 VPN。VPN 无法看到你在 Tor 浏览器中做什么，你将获得额外的好处，即没有 Tor 节点能够看到你的 IP 地址。它还将防止你的网络运营商甚至知道你正在使用 Tor，如果你所在的地区恰好封锁了 Tor 网络，这将很有帮助。

## 如何使用 Proxychains 通过代理服务器重定向流量

有时我们安装代理服务器，但只有特定程序（如 Firefox 和 Google Chrome）提供代理设置。幸运的是，我们可以使用一个名为 `proxychains` 的命令行实用工具来将任何应用重定向通过我们的代理服务器。本教程将向您展示如何在 Debian、Ubuntu、OpenSUSE、Fedora、CentOS/Red Hat、Arch Linux 及其衍生版本上进行设置。

如果您不知道如何设置代理服务器，请查看这篇文章以了解 `shadowsocks` 代理。之后，再回到这里。

### 在 Linux 上安装 proxychains

#### Debian/Ubuntu/Linux Mint/Elementary OS

```
sudo apt-get install proxychains
```

#### OpenSUSE Leap 42.1

Proxy chains 可从 packman 仓库获取。

```
sudo zypper install proxychains
```

#### Fedora

```
sudo dnf install proxychains
```

#### CentOS/Red Hat

```
sudo yum install proxychains
```

#### Arch Linux

```
sudo pacman -S proxychains-ng
```

在 Kali Linux 上，`proxy chains` 是默认安装的。

### 在 Proxychains 中添加代理服务器

打开配置文件。

```
sudo nano /etc/proxychains.conf
```

在文件末尾，像这样添加您的代理：

```
socks5 127.0.0.1 1080
```

`socks5` 是代理类型，您也可以根据情况添加其他类型，如 HTTP、https、socks4 等。`127.0.0.1` 是代理主机，`1080` 是代理服务器监听的端口。再次强调，请根据您的具体情况更改它们。

默认代理为 `socks4 127.0.0.1 9050`，您可以安全地将其移除。

### 设置默认 DNS 服务器

强烈建议您将默认的 `4.4.2.2` DNS 服务器更改为其他服务器，例如 Google 的 DNS 服务器 `8.8.8.8` / `8.8.4.4`。或者 OpenDNS 服务器 `203.67.222.222` / `203.67.220.220`。打开 resolv 配置文件。

#### Debian/Ubuntu

```
sudo nano /usr/lib/proxyresolv
```

#### Linux Mint/Elementary OS

```
sudo nano /usr/lib/proxychains3/proxyresolv
```

#### Fedora/CentOS/Red Hat/OpenSUSE

```
sudo nano /usr/bin/proxyresolv
```

找到以下行：

```
DNS_SERVER=4.4.2.2
```

将其值更改为类似 `8.8.8.8` 的值。然后保存并关闭文件。在 Arch Linux 上，没有 `proxyresolv` 配置文件。

### 测试

只需在执行的任何命令前加上 `proxychains`，如下所示。

```
proxychains youtube-dl -citv https://www.youtube.com/channel/<channel-id>
```

如果您使用 `youtube-dl`，您可能知道它没有内置的 socks 代理支持，但 Proxychains 会将 `youtube-dl` 重定向通过代理服务器。

### 静默模式

默认情况下，`proxychains` 会将其活动输出到终端。如果您不想看到此信息，则可以通过编辑 `/etc/proxychains.conf` 文件来禁用它。

## 如何入侵无线网络

### 如何入侵 WiFi（无线）网络

无线设备在路由器的传输半径内对任何人都是可访问的。这使得它们容易受到攻击。机场、餐厅、公园等公共场所都有热点网络。

在本教程中，我们将向您介绍用于利用无线网络安全实现中弱点的常规技术。我们还将查看您可以采取的一些对策，以保护免受此类攻击。

### 什么是无线网络？

无线网络是使用无线电波将计算机和其他设备连接在一起的计算机网络。其实施是在 OSI 模型的第 1 层（物理层）完成的。

### 如何访问无线网络？

您需要一个支持无线网络的设备，例如笔记本电脑、平板电脑、智能手机等。您还需要位于无线网络接入点的传输半径内。大多数设备（如果打开无线网络选项）都会为您提供可用网络列表。如果系统没有密码保护，则必须点击连接。如果它受密码保护，则需要密码才能获取访问权限。

### 无线网络身份验证

由于任何拥有无线设备的用户都可以轻松访问网络，因此大多数系统都受密码保护。让我们看看一些最常用的身份验证技术。

#### WEP

`WEP` 是 Wired Equivalent Privacy（有线等效隐私）的缩写。它是为 IEEE 802.11 WLAN 标准开发的。其目标是为提供与有线网络相当的隐私保护。`WEP` 通过加密在网络上传输的数据来防止窃听，从而保持数据的安全。

#### WEP 身份验证

- **开放系统身份验证 (OSA)** – 此方法根据配置的访问策略，授予请求站点身份验证的访问权限。
