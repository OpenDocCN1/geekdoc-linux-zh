## TCSH 命令

```
#
set tdate=`date +%D`
foreach grocery ($argv[*])
echo "$grocery" $tdate
end
```

```
> mylistarg
milk 05/23/99
cookies 05/23/99
apples 05/23/99
cheese 05/23/99
>
```

你可以使用 `argv*` 特殊参数显式引用命令行参数。在下一个示例中，当调用 shell 脚本 `cbackuparg` 时，在命令行上输入 C 程序文件列表。在 `foreach` 循环中，`argv*` 引用命令行上的所有参数。每个参数将被连续分配给 `foreach` 循环中的变量 `backfile`。循环第一次时，`$backfile` 等于 `argv[1]`。第二次时它等于 `argv[2]`。变量 `argnum` 用于引用每个参数。显示参数和 `backfile` 的值以证明它们是相同的。

```bash
#
@ argnum = 1
foreach backfile ($argv[*)
  cp $backfile sourcebak/$backfile
  echo "$backfile $argv[$argnum]"
  @ argnum = $argnum + 1
end
```

```
> cbackuparg main.c lib.c io.c
main.c main.c
lib.c lib.c
io.c io.c
```

## hup

```
hup [ command ]
```

如果包含命令参数，`hup` 运行该命令，使其在接收到挂断信号时退出，并安排 shell 在退出时向其发送挂断信号。注意，命令可能会设置它们对挂断的响应，从而覆盖 `hup` 的设置。如果没有参数（仅在 shell 脚本中允许），`hup` 会导致 shell 在脚本剩余部分在接收到挂断信号时退出。

## if-then

```
if ( expression ) then
  commands
  endif
```

`if-then` 结构为多个 Linux 命令设置了一个条件。该条件是一个表达式。如果表达式的结果结果为非 0 的值，则该表达式为真，并执行 `if` 结构中的命令。如果表达式的结果为 0 值，则该表达式为假，不执行 `if` 结构中的命令。

## TCSH 命令

`if-then` 结构以关键字 `if` 开始，后面跟着一个括在括号内的表达式。关键字紧跟在表达式之后。你可以在接下来的行中指定任意数量的 Linux 命令。关键字 `endif` 结束 `if` 命令。请注意，在 BASH shell 中，TCSH shell 的 `then` 关键字独占一行，而 `then` 与测试表达式在同一行。

接下来显示的 `ifls` 脚本允许你按大小列出文件。如果你在提示处输入 `s`，将列出当前目录下的每个文件，随后是它使用的块数。如果用户输入其他内容，则 `if` 测试失败，脚本什么都不做。

## if-then-else

```
if ( expression ) then
    commands
else
    commands
endif
```

通常，你需要根据表达式是否为真两种方案之间进行选择。`else` 关键字允许 `if` 结构在两种方案之间进行选择。如果表达式为真，则执行紧随测试表达式之后的命令。如果表达式为假，则执行 `else` 关键字之后的命令。

下一个示例中的 `elsels` 脚本执行 `ls` 命令，以两种可能的选项列出文件，要么按大小，要么按所有文件信息。如果用户输入 `s`，则按大小列出文件；否则，列出所有文件信息。注意其语法与 BASH shell 版本的 `elsels` 脚本不同。

## elsels

```
## necho Enter s to list file sizes,
echo otherwise all file information is listed.
echo -n "Please enter option: "
set option = $<
if ($option == "s") then
  ls -s
else
  ls -1
endif
echo Gobd-bye
```

```
> elsels
Enter s to list file sizes,
otherwise all file information is listed.
Please enter option: s
total 2
  1 monday      2 today
Good-bye
>
```

## jobs

```
jobs [-1]
```

`jobs` 列出活动作业。使用 `-1` 时，它除了普通信息外，还会列出进程 ID（`PID`）。

## kill

```
kill [-signal] %job|pid ..
kill -1
```

`kill` 用于终止进程或作业。使用 `-signal` 选项，你可以指定要发送的信号。默认情况下，发送的信号是 `SIGTERM`。使用 `-l` 选项，命令将列出信号名称。

对于通过 `-I` 选项提供的信号数字，将列出相应的信号名称。

## logout

此命令终止登录 shell。如果设置了 `ignoreeeof`，则它特别有用。

## nice

```
nice [+number] [command]
```

`nice` 为 shell 设置调度优先级，如果没有包含数字，则设置为 4。如果指定了命令，`nice` 将以相应的优先级运行该命令。数字越大，进程获得的 CPU 时间就越少。

## nohup

```
nohup [command]
```

如果没有命令参数，`nohup` 指示 shell 忽略任何挂断信号。如果有命令，它将执行该命令并忽略其任何挂断信号。

## onintr

```
onintr [-i|label]
```

`onintr` 控制 shell 在挂断时的动作。不带参数时，恢复默认动作。带 `-i` 参数时，忽略所有挂断。带 `label` 参数时，会导致命令终止。

## popd

```
popd [-p] [-l] [-v] [+n]
```

`popd` 从列表中移除目录项。不带参数时，`popd` 移除顶部的目录。

`popdilent` shell 变量可以设置为抑制显示目录列表，使用 `-p` 选项可以用来覆盖 `popdilent`。

## printenv

```
printenv [name]
```

`printenv` 显示所有环境变量的名称和值，或者在带名称参数时显示环境变量的值。

## pushd

```
pushd [-p] [-l] [-v] [name|+n]
```

`pushd` 将目录添加到记忆列表中，然后显示目录列表。不带参数时，`pushd` 交换两个目录并返回 0，除非目录列表为空。

`+n` 旋转列表，使 `dirs` 显示列表中从左侧第 `n` 个目录位于顶部。然而，如果设置了 `extract`，则 TCSH 命令 93 `pushd +n` 提取第 `n` 个目录，将其推入栈顶并切换到它。

`-n` 旋转栈，使从右侧第 `n` 个目录位于顶部。`dir` 将目录添加到列表顶部，使其成为当前目录。

如果设置了 `pushdhtome`，`pushd` 不带参数时执行 `pushd ~`。

如果设置了 `dunique`，`pushd` 在将名称推入栈之前从栈中移除该名称的所有实例。
