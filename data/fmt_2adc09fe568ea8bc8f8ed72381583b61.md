### 9.3 smsh1—命令行解析

Shell 的第一个改进是添加命令行解析。这个版本称为 `smsh1.c`。用户现在可以输入单行命令，例如

```
find /home -name core -mtime +3 -print
```

程序将命令行分成字符串数组，准备传递给 `execvp()`。`smsh1.c` 的程序逻辑如图 9.1 所示。

`psh2.c` 包含了将命令行拆分为参数；在 shell 中忽略 `SIGINT` 和 `SIGQUIT`，但在子进程中恢复它们的默认动作；并允许用户通过按下文件结束符 Ctrl-D 退出。

shell 的主函数是：

```c
int main() {
    char *cmdline, *prompt, **arglist;
    int result;
    void setup();

    prompt = DFL_PROMPT;
    setup();
    while ( (cmdline = next_cmd(prompt, stdin)) != NULL ) {
        if ( (arglist = splitline(cmdline)) != NULL ) {
            result = execute(arglist);
            freelist(arglist);
        }
    }
    free(cmdline);
    return 0;
}
```

这三个函数负责完成工作：

#### next_cmd

`next_cmd()` 从输入流中读取下一条命令。它调用 `malloc()` 来接受任何长度的命令行。在文件末尾时返回 `NULL`。

#### splitline

`splitline()` 将字符串拆分为单词数组并返回该数组。它调用 `malloc()` 来接受带有任意数量参数的命令行。该数组以 `NULL` 指针结束。

#### execute

`execute()` 使用 `fork()`、`exec`、`execvp()` 和 `wait()` 来运行命令。`execute()` 返回命令的终止状态。

### smsh1.c 的代码

```c
smsh1.c small-shell version 1
/**
** 提示 shell 后第一个真正实用的版本
** 这个版本将命令行解析为字符串
** 使用 fork, exec, wait 并忽略信号
*/

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include "smsh.h"

#define DFL_PROMPT " *"

int main() {
	char *cmdline, *prompt, **arglist;
	int result;
	void setup();

	prompt = DFL_PROMPT ;
	setup();
	while ( cmdline = next_cmd(prompt, stdin)) != NULL ) {
		if ( arglist = splitline(cmdline)) != NULL ) {
			result = execute(arglist);
			freelist(arglist);
		}
		free(cmdline);
	}
	return 0;
}
```

```c
void setup()
/**
 * 目的：初始化 shell
 * 返回：无。如果出现问题调用 fatal()
 */
{
    signal(SIGINT, SIG_IGN);
    signal(SIGQUIT, SIG_IGN);
}

void fatal(char *s1, char *s2, int n)
{
    fprintf(stderr,"Error: %s,%s\n", s1, s2);
    exit(n);
}
```

### execute.c 的代码

```c
/* execute.c - 小 shell 用于执行命令的代码 */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include <sys/wait.h>

int execute(char *argv[])
/**
 * 目的：运行程序并传递参数
 * 返回：通过 wait 返回的状态，或出错时返回 -1
 * 错误：fork() 或 wait() 错误返回 -1
 */
{
    int pid;
    int child_info; /* 无操作成功 */
    if ( argv[0] == NULL )
        return 0;
    if ( pid = fork()) == -1)
        perror("*fork()*");
    else if ( pid == 0 ) {
        signal(SIGINT, SIG_DFL);
        signal(SIGQUIT, SIG_DFL);
        execvp(argv[0], argv);
        perror("cannot execute command*");
        exit(1);
    } else {
        if ( wait(&child_info) == -1 )
            perror("*wait()*");
    }
    return child_info;
}
```
