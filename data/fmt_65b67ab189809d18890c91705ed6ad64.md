
# Glossary

### audit log
位于 `/var/log/audit/audit.log` 的主日志，包含了由审计服务记录的所有消息。

### autoffiguration
自动分配网络配置（如 IP 地址、主机名、网关和子网掩码）的过程。

### autofs
一种在访问特定目录时自动挂载网络文件系统的服务。该服务对于确保集中式用户管理系统（可通过 LDAP 服务实现）中的用户自动挂载主目录非常有用。

### automount
由 `autofofs` 服务启动的过程。更多信息请参阅 `autofs`。

### background
在系统上运行且不主动占用控制台的进程。可以通过在启动进程的命令后添加 `&` 来在后台启动进程。

### backup
重要数据的副本，可以在原始数据出现问题时的任何时间点进行恢复。

### bash
大多数 Linux 系统上使用的默认 shell。

### Basic Input Output System (BIOS)
基础输入输出系统，是在旧版 IBM 兼容计算机启动时运行的第一个软件。BIOS 中的设置可以使用 BIOS 设置程序进行更改。

### binary
一种基于位值（开或关）的计数方案。二进制数是 0 和 1。由于它们难以使用，在大多数情况下使用十进制、十六进制或八进制数。

### binary packages
一组应用程序、文档、库和配置文件的集合，无需从源码编译即可下载并运行。

### BIOS
参见 Basic Input Output System。

### bonding
在网络中，指允许创建一个由多个捆绑接口组成的网络躯干（trunk）的技术。Bonding 用于冗余和性能。

### boolean logic
如 OR 和 AND 等操作，这些操作作用于计算机理解的“真”和“假”原语，而不是人类理解的数字。

### boot manager
计算机启动时运行的一段软件。引导程序管理程序负责加载操作系统内核。

### boot loader
由 BIOS 调用以启动计算机的程序，负责加载操作系统内核和 initramfs。

### bounce
在发现邮件无法投递后将其退回（退信）。

### broadcast address
广播地址，IPv4 网络上的一个网络地址，用于将网络消息发送到子网上的所有主机。

### btrfs
一种通用的 Linux 文件系统，预计在未来的发行版本中成为某些 Linux 发行版的默认文件系统。

### buffer
在内存管理中指存储非结构化数据的内存区域。

### bus
一种硬件组件，允许其他组件通过共享连接进行连接和通信，而不是每个组件都需要与每个组件建立唯一连接。

### cache
在内存管理中指存储最近使用的文件的内存区域。缓存是服务器加速运行的重要机制。

### capability
Linux 上可以执行的特定任务。用户 root 拥有所有权限；普通用户仅拥有有限的权限集。更多信息请参阅 `man 7 capabilities`。

### CentOS
一种 Linux 发行版，使用了所有 Red Hat 软件包，但从这些软件包中删除了 Red Hat Logo，以便免费分发软件。

### certificate
在 PKI 密码学中，证书包含发行者的公钥。该公钥由证书颁发机构的证书签名，以保证其可靠性。

### Certificate Authority
一种通常可用于保证 PKI 证书可靠性的常用组织。证书颁发机构提供用于签名公钥证书的证书。除了使用常用组织，内部目的也可以使用自签名证书。

### CGI
参见 Common Gateway Interface（通用网关接口）。

### chronyd
Linux 发行版中提供时间同步服务的新服务。

### chroot
一种环境，其中文件系统的部分被呈现为文件系统的根目录。`chroot` 用作安全特性，隐藏特定服务不需要的操作系统部分。

### CIFS
参见 Common Internet File System（通用互联网文件系统）。

### client-server
一种应用程序架构，面向用户的客户端从共享的后端服务器获取信息和指令。

### cloud
允许灵活使用托管计算资源的计算平台。

### code pages
将特定集合中的字符映射到数字的表格。

### code point
代码页中字符到数字的单个映射。

### coldplug
一种需要关闭计算机才能被识别的硬件设备。

### column
在关系型数据库中，列由不同记录的相似字段组成。列可用于对数据进行排序。

### command substitution
一种 shell 脚本技术，运行一个命令并将其结果注入另一个命令中。

### Common Gateway Interface (CGI)
通用网关接口，使用脚本技术生成动态网页的标准。CGI 不规定使用哪种特定的脚本技术。

### Common Internet File System (CIFS)
微软服务器区块 (SMB) 协议的标准版本，用于以与 Windows 服务器和客户端兼容的方式访问打印机、文件和目录。CIF 已成为 IT 领域文件共享的事实标准。

### Common Unix Printing System (CUPS)
大多数 Linux 系统上负责打印的软件。

### compression
一种通过分析冗余模式并高效存储来减小文件大小的技术。主要用于节省存储空间、减少网络流量或提高网络传输速率。

### conditional loop
shell 脚本中仅在满足特定条件时执行的一组命令。

### conditionals
shell 代码的一部分，测试给定条件并根据结果执行不同的代码。

### connection
在网卡配置中：与网络接口关联的一系列网络配置参数。在网络通信中：两个初始化双方之间的会话，一直持续到连接关闭为止。

### console
在 Linux 中，控制台是用户的主要终端。它也是一个名为 `/dev/console` 的特定设备。

### context（上下文）
在 SELinux 中，上下文是一个用于定义用户、进程、端口和目录安全属性的标签。这些规则在 SELinux 策略中用于定义安全规则。

### context switch（上下文切换）
当 CPU 从执行一个任务切换到执行另一个任务时，就会发生切换。

### context type（上下文类型）
在 SELinux 中，上下文类型用作标签，识别用户、进程和端口的 SELinux 属性。

### 创建、读取、更新和删除 (CRUD)
在关系数据库（以及持久化存储）中，创建、读取、更新和删除是基本操作。在 MariaDB 数据库中，CRUD 通过使用 `INSERT`、`SELECT`、`UPDATE` 和 `DELETE` 命令实现。其他协议也是如此。例如在 HTTP 中，CRUD 通过 `POST`、`GET`、`PUT` 和 `DELETE` 命令实现。

### credentials file（凭据文件）
用于从 `/etc/fstab` 文件自动挂载 CIFS 文件系统的文件。凭据存储存储安全的地方（例如 root 用户目录），包含了用于挂载远程文件系统的用户名和密码。

### cron
在计划时间运行后台作业的服务。

### CRUD
创建、读取、更新和删除。

### cryptography（密码学）
用于保护数据的技术。这通常通过将信息转换为不可读状态来实现，使用密钥来解密加密后的数据。密码学不仅用于保护传输中的文件，还可以用于保护身份验证过程。

### CUPS
参见 Common Unix Printing System（通用 Unix 打印系统）。

### CUPS backend（后端)
通用 Unix 打印系统的一部分，负责将处理过的打印作业发送到打印机。

### daemon（守护进程）
在后台运行并向本地机器或远程机器提供某种服务的进程。

### database（数据库）
在关系数据库中，用于存储数据的表集合。

### database schema（数据库架构）
对关系数据库中所有表、列和关系的描述。

### Daylight Saving Time（夏令时）
开发者和系统管理员共同的痛苦之源。在夏季，时钟会提前一小时以利用更长的夜晚。

### decimal（十进制）
基于 0-9 数字的计数方案。这种计数方案对人类来说很容易使用，但在计算机环境中并不易用，因此经常使用二进制、八进制和十六进制计数方案。

### default gateway（默认网关）
主机默认使用的网关。另请参见 gateway。

### default route（默认路由）
默认用于转发目标位于外部网络的 IP 数据包的路由器。

### dependency（依赖关系）
通用含义：一个项目需要另一个项目的情况。依赖关系在 Linux 中以多个层次出现。在 RPM 软件包管理中，依赖关系是指在安装另一个包之前必须存在的软件包。在 systemd 中，依赖关系是指在加载另一个单元（unit）之前必须加载的系统单元。

### dependency hell（依赖地狱）
指在安装包时，由于需要其他包，而这些其他包本身可能也需要依赖的情况。通过引入仓库基础系统，解决了依赖地狱问题。

### desktop（桌面）
作为用户与 GUI 环境之间接口的软件程序。

### destination（目标）
在 syslog 中，指定将日志消息发送到日志系统的目标。目标通常是文件，也可以是输入模块、输出模块、用户或主机。

### device（设备）
连接到计算机以执行特定任务的外围设备。

### device file（设备文件）
在 `/dev` 目录中创建的用于表示和与设备交互的文件。

### device mapper（设备映射器)
Linux 内核用于与存储设备通信的服务。Device mapper 被 LVM、multipath 和其他设备使用，而不是普通硬盘。由 device mapper 创建的设备可以在 `/dev/mapper` 目录下找到。

### DHCP
参见 Dynamic Host Configuration Protocol（动态主机配置协议）。

### directive（指令）
Apache 配置中参数的名称。

### direct mount（直接挂载）
在 autofount 中，指在执行自动挂载之前已经必须存在的目录上执行自动挂载。直接挂载始终以 `/` 为挂载点，且只能由 root 用户创建。

### directory（目录）
文件系统中的文件夹，可以组织的方式存储文件。

### directory entries（目录项）
文件系统的一部分，存储目录中的文件列表以及指向文件 inode 的指针。

### display manager（显示管理器）
为用户提供 GUI 登录的软件程序。

### distribution（发行版）
一种自带安装程序或即插即用的 Linux 版本。由于 Linux 是不同工具和其他组件的集合，Linux 发行版收集了这些工具和其他组件，可能会也可能对它们进行增强，并分发给不需要自己收集所有不同组件的用户。

### dmesg
用于读取内核缓冲的实用程序，其中包含 Linux 内核生成的日志消息。

### DNS
参见 Domain Name System（域名系统）。

### DNSSEC
一种用于保护 DNS 的系统。在 DNSSEC 中，密钥用于保证所连接服务器的真实性。

### DocumentRoot（文档根）
在 Apache 中，DocumentRoot 定义了 Apache Web 服务器查找提供给 Apache 客户端文档的位置。

### domain（域）
域名系统，定义了域的层次结构。在这个层次结构中，域是一个由全球唯一名称（如 example.com）标识的对象。在域叶节点内，通常创建对象以以全球唯一的方式标识资源。

### Domain Name System (DNS)（域名系统）
使计算机名称转换为 IP 地址以及反之成为可能的系统。在域名系统中，使用了多个域层级，类似于文件系统中的目录结构。

### dotted quad notation（点分四位表示法）
由四个字节组成的 IPv4 地址。

### dracut
用于生成 initramfs 的实用程序，它是操作系统的重要部分，包含了启动 Linux 系统所需的驱动和其他文件。

### drift（漂移）
计算机时与实际时间之间逐渐增长的差异。

### driver（驱动程序）
允许内核理解如何与特定设备或一组设备通信的软件。

### Dynamic Host Configuration Protocol (DHCP)（动态主机配置协议）
通常由服务器实现的协议，负责提供 IP 地址和其他配置。使用 DHCP 使得网络中的系统无需手动配置 IP 地址和相关参数。

### dynamic linker (ld.so)
Linux 系统中负责查找动态库并将其提供给应用程序的库。

### dynamic linking（动态链接）
应用程序之间共享库代码的过程，而不需要每个程序保留库副本。

### dynamic route（动态路由）
由自动路由管理的网络路由。

### EFI
参见 Extensible Firmware Interface（扩展固件接口）。

### embedded database（嵌入数据库）
不需要作为独立守护进程运行的数据库（如 SQLite）。

### enforcing（强制模式）
SELinux 的完全运行模式，应用了为特定系统配置的所有限制。

### environment（环境）
用户或进程用于工作的集合。

### epoch time（纪时间）
在 Linux 中，纪对应于 1970 年 1 月 1 日凌晨。Linux 时间计算为从纪以来经过的秒数。这个秒数被称为纪时间。某些实用程序使用纪时间而非时钟时间。

### escaping（转义）
在 shell 环境中，转义确保特定字符不被 shell 解析。转义可能是为了在屏幕上显示特定字符，或者确保正则表达式元字符不会先被 bash shell 预解析。

### exim
一种邮件传输代理，像 sendmail 一样是单体结构的，但配置更简单。

### export
在 NFS 中，指在 NFS 服务器上共享的目录，允许其他服务器进行访问。

### Ext2, Ext3, 和 Ext4
三个不同版本的 Ext 文件系统。目前，Ext4 是某些 Linux 发行版的默认文件系统。它现在被认为无法满足现代存储需求，这就是为什么 RHEL 7 中的 Ext4 已被 XFS 替换为默认文件系统。

### Extensible Firmware Interface (EFI)
可扩展固件接口，是基本输入输出系统的替代品，用于用于旧的 IBM 兼容计算机，作为计算机启动时运行的第一个程序。EFI 是操作系统和计算机固件之间的层。

### extended partition
扩展分区——在 MBR 磁盘上，分区表最多可以存储四个分区。为了超过这一数量，可以将这四个分区中的一个创建一个扩展分区。在扩展分区内部，可以创建逻辑分区，其运行方式与普通分区相同，允许系统管理员创建更多分区。

### external command
外部命令——以文件形式存在磁盘上的命令（与 bash 内部“内置”命令相反）。

### Fedora
由红帽赞助的免费社区 Linux 发行版。在 Fedora 中，提供并测试新功能。其中某些功能将包含在 Linux 企业发行版的后续版本中。

### fiber channel
光纤通道——一种可用 SAN 环境的基础设施。它的对手是 iSCSI。

### field
字段——在关系型数据库中，字段用于组成记录。一个字段通常是一个键值对。记录由多个字段组成。

### file descriptor
文件句符——Linux 进程用于引用进程正在使用的文件的指针。

### file system
文件系统——在存储设备上创建的逻辑结构。在 Linux 文件系统中，使用 inode 进行文件系统管理，实际数据写入块中。

### File System Hierarchy (FSH)
文件系统层次结构——一个定义哪些 Linux 目录应该用于什么用途的标准。参阅 `man 7 hier` 获取 FSH 规范。

### File Transfer Protocol (FTP)
文件传输协议——一种允许用户在远程系统之间复制文件的软件程序。遗憾的是，该过程以明文形式发送数据，使其成为糟糕的方法。

### filesystem
文件系统——既是呈现给 Linux 系统的虚拟磁盘，也是磁盘上文件的布局。

### firewall
防火墙——一种用于过滤网络数据包的解决方案。防火墙用于确保只有授权的流量才能到达系统。防火墙可以通过 Linux 内核的 Netfilter 功能提供，但通常也作为网络设备提供。

### firewalld
RHEL 7 中使用的现代服务，基于 Linux 内核防火墙框架实现防火墙功能。

### flush
刷新——在电子邮件中，可以刷新邮件队列。如果消息在第一次尝试时无法发送，则这非常有用。默认情况下，电子邮件软件将尝试再次发送消息，通常每小时一次。通过刷新邮件队列，会触发邮件服务器并尝试立即发送被停滞的消息。在文件系统中，刷新指的是将文件直接写入存储介质，而不是先写入文件系统缓存（然后从缓存同步到磁盘盘片上）。

### folder
文件夹——也称为目录（directory），文件系统中用于组织相互关联文件的结构。

### foreground
前台——用户启动的 Linux 进程可以在前台或后台启动。如果一个进程作为前台进程启动，那么在 particular进程完成或移动到后台之前，无法在同一个终端中启动其他进程。

### forwarding
转发——将发给 A 人的邮件自动发送给 B 个人。

### FQDN
参阅 Fully Qualified Domain Name（完全限定域名）。

### FSH
参阅 File System Hierarchy（文件系统层次结构）。

### fstab
Linux 上使用的配置文件，用于在系统启动时自动挂载文件系统。

### FTP
参阅 File Transfer Protocol（文件传输协议）。

### Fully Qualified Domain Name (FQDN)
完全限定域名——在 DNS 中，一个完整的主机名，包括主机所在的域名子域名。`server1.example.com` 是 FQDN 的示例。

### function
函数——一段可重用的 shell 代码，可以被用户或其他 shell 脚本调用，可选带有参数。

### gateway
网关——用于允许主机与其他网络通信的主机。也称为路由器。

### GECOS
最初代表通用电气操作系统（General Electric Comprehensive Operating System）。在 Linux 中，它保留为 `/etc/passwd` 文件中的 Geos 字段，该字段可存储有关 Linux 操作系统用户的个人数据。

### GID
参阅 group identification number（组标识符）。

### Global Unique ID (GUID)
全局唯一标识——由多个部分组成的数字，确保其在全球范围内是唯一的。
