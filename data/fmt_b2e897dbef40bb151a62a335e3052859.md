
`copyfile(f1, f2 [, length])`

从打开的文件 `f1` 将所有数据复制到打开的文件 `f2`。`length` 指定了要使用的最大缓冲区大小。负长度将不会通过一次操作完全复制数据（也就是说，所有数据将作为一个数据块被读取然后写入）。

`copymode(src, dst)`

将权限位从 `src` 复制到 `dst`。

`copystat(src, dst)`

将权限位、最后访问时间和最后修改时间从 `src` 复制到 `dst`。`dst` 的内容、所有者和组不变。

`copytree(src, dst, [ignore])`

递归复制 `src` 处的目录树。目标目录 `dst` 将创建（且不应存在）。单个文件通过 `copy2()` 复制。如果 `symlinks` 为 True，源树中的符号链接将表示为新树中的符号链接。如果 `symlinks` 为 False 或省略，则会将链接文件的内容复制到新目录中。`ignore` 是一个可选函数，可用于过滤特定文件。作为返回值，它返回一个要忽略的文件名列表。如果在复制过程中发生错误，该异常将以元组列表的形式抛出，包含所有发生错误的 `(arcname, dst, exception)`。

```ignore_pattern(pattern1, pattern2, ...)
```

创建一个函数，该函数可以用于忽略 `pattern1`、`pattern2` 等给出的所有全局样式模式。返回的函数接受两个参数，第一个是目录，第二个是目录列表。返回一个要忽略的文件名列表。其主要用途是 `copytree()` 函数的 `ignore` 参数。然而，生成的函数也可能用于涉及 `os.walk()` 的操作。

## tarfile

```move(src, dst)
```

将文件或目录 `src` 移动到 `dst`。如果移动到不同的系统，则将递归复制 `src`。

```rmtree(path [, ignore_errors [, onerror]] )
```

删除整个目录树。如果 `ignore_errors` 为 True，则将忽略错误。否则，错误将由 `onerror` 函数处理（如果提供了）。此函数必须接受三个参数（`func`、`path` 和 `excinfo`），其中 `func` 是引起错误的函数（`os.remove()` 或 `os.rmdir()`），`path` 是传递的路径名，`excinfo` 是 `sys.exc_info()` 返回的异常信息。如果发生错误且省略了 `onerror`，则抛出异常。

`tarfile` 模块用于操作归文件。使用此模块可以读取和写入 tar 文件，无论是否压缩。

```is_tarfile(name)
```

如果 `name` 看起来是一个由此模块读取的有效 tar 文件，则返回 True。

`open([name, mode [, fileobj, bufsize]])`

创建一个带有路径名的 TarFile 对象。`mode` 是一个字符串，指定打开文件的方式和压缩方案：`file[:compression]`。有效组合包括：

| Mode | 描述 |
| :--- | :--- |
| 'r' | 读取。如果文件是压缩的，则进行解压缩。这是默认模式。 |
| 'r:' | 不压缩读取。 |
| 'gz' | 以 gzip 压缩读取。 |
| 'bz2' | 以 bzip2 压缩读取。 |
| 'a', 'a:' | 不压缩追加。 |
| 'w', 'w:' | 不压缩写入。 |
| 'gz' | 以 gzip 压缩写入。 |
| 'bz2' | 以 bzip2 压缩写入。 |

以下模式模式用于创建允许顺序 I/O 的 TarFile 对象（不支持随机访问）：

| Mode | 描述 |
| :--- | :--- |
| 'r' | 打开未压缩流读取。 |
| 'gz' | 打开 gzip 压缩流读取。 |
| 'bz2' | 打开 bzip2 压缩流读取。 |
| 'w' | 打开未压缩流写入。 |
| 'gz' | 打开 gzip 压缩流写入。 |
| 'bz2' | 打开 bzip2 压缩流写入。 |

如果指定了默认的 `fileobj`，它必须是一个打开的文件对象。`bufsize` 指定了 tar 文件中使用的块大小。默认是 `20*512` 字节。

`open()` 返回的 TarFile 实例支持以下方法：

```add(name [, arcname [, recursive]])
```

向归文件添加一个新文件。`name` 是文件的 tar 名称。`arcname` 是归文件中的替代名。`recursive` 是一个指示是否递归添加子目录的标志。

```addfile(tarinfo [, fileobj])
```

向归文件添加新条目。`tarinfo` 是一个 TarInfo 实例。`fileobj` 是一个打开的文件对象。

```close()```

关闭归文件。

```debug()```

控制产生的调试信息的量。如果设置为 0，则不向 sys.stderr 写入消息。

```dereference()```

如果设置为 True，则对符号链接和硬链接进行解引用。

```errorlevel()```

确定如何处理错误。如果设置为 0，则忽略错误。如果设置为 1，错误导致 `OSError`。如果设置为 2，错误导致 `TarError`。

```extract(member [, path])```

从归文件中提取一个成员。`member` 是名称或 TarInfo 实例。`path` 指定目标位置。

```extractfile(member)```

从归文件中提取一个成员并返回一个类文件对象。

```getmember(name)```

在归文件中查找成员。如果不存在该成员，则抛出 `KeyError`。

```getmembers()```

返回所有成员的 TarInfo 对象列表。

```getnames()```

返回所有成员名称的列表。

```gettarinfo([name [, arcname [, fileobj]])```

返回一个对应于文件的 TarInfo 实例。`name` 是名称，`arcname` 是替代名，`fileobj` 是一个打开的文件对象。

```ignore_zeros()```

如果设置为 True，则在读取归文件时将跳过空块。如果设置为 False（默认值），空块表示归文件的结束。

```list([verbose])```

将归文件的内容列到 sys.stdout。`verbose` 决定详细程度。如果设置为 False，则只打印归文件名称。否则，打印详情（默认值）。

```next()```

用于遍历归文件成员的方法。返回下一个成员的 TarInfo 结构或 None。

```posix()```

如果设置为 True，则根据 POSIX 1003.1-1990 标准创建文件。这会对文件名长度和文件大小施加限制（文件名必须小于 256 个字符，文件大小小于 2GB）。如果将此属性设置为 False，则使用 GNU 扩展创建归文件，以消除这些限制。默认值为 False。

许多之前的方法返回 TarInfo 实例。以下是 TarInfo 实例 `i` 的后续方法和属性：

| 属性 | 描述 |
| --- | --- |
| ti.gid | 组 ID |
| ti.idname | 组名 |
| ti.isblk() | 如果对象是块设备，则返回 True |
| ti.ischr() | 如果对象是字符设备，则返回 True |
| ti.isdev() | 如果对象是设备（字符或 FIFO），则返回 True |
| ti.isdir() | 如果对象是目录，则返回 True |
| ti.isfifo() | 如果对象是 FIFO，则返回 True |
| ti.isfile() | 如果对象是普通文件，则返回 True |
| ti.islink() | 如果对象是硬链接，则返回 True |
| ti.isreg() | 同于 isfile() |
