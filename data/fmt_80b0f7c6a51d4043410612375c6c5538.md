  ```
  dvipdf my.file.dvi output_file.pdf
  ```

  ```
  ps2pdf my.file.ps
  ```
- 你可以查看任何一个文件（`dvi`、`ps` 或 `pdf`），例如在 `X` 终端中使用：
  ```
  kvi my.file.dvi&

  ```

## 7.3 Calc

### 7.3.1

我目前使用一个名为 `Calc` 的优秀电子表格程序，它是 `OpenOffice` 的一部分。可以通过点击你喜爱的菜单项（"KOffice-OpenOffice-Calc"）或在 `X` 终端输入来运行它。

我是一个资深电子表格用户，所以这里是我关注的一些推荐程序。在我看来，Linux 还没有非常优秀的电子表格程序，但 `Calc` 可以完成很多工作。用户可以在 `Calc` 中定义自己的函数。例如，我可以在编辑器（"Tools=Macros”）中编写如下函数：

```

Function myfunction(r1,r2)

REM 使用变量返回值

Function myabs(pi(r1*r2) - pi(r2^2))

End Function
```

## 鼠标操作

使用鼠标选择：
`<左键>` 选择单元格等。
`<Shift><左键>` 扩展当前选择。

使用鼠标拖拽：
`<左键>` 拖动选择内容进行移动。
`<Ctrl><左键>` 将选择内容复制到拖动位置。
