
### `s.send(string [, flags])`

将 `string` 中的数据发送到已连接的 socket。可选的 `flags` 参数与之前描述的 `recv()` 相同。返回发送的字节数，可能少于 `string` 中的字节数。如果发生错误，则抛出异常。

### `s.sendall(string [, flags])`

将 `string` 中的数据发送到已连接的 socket，但在之前之前尝试发送所有数据。成功时返回 `None`；失败时抛出异常。`flags` 的含义与 `send()` 相同。

### `s.sendto(string [, flags], address)`

将数据发送到 socket。`flags` 的含义与 `recv()` 相同。`address` 是格式为 `(host, port)` 的元组，指定远程地址。socket 不应已经连接。返回发送的字节数。此函数主要与 UDP 协议配合使用。

### `s.setblocking(flag)`

如果 `flag` 为零，则将 socket 设置为非阻塞模式。否则，将 socket 设置为阻塞模式（默认）。在非阻塞模式下，如果 `recv()` 调用未找到任何数据或 `send()` 立即找到数据，将抛出 `socket.error` 异常。在阻塞模式下，这些调用将阻塞直到可以继续。

### `s.setsockopt(level, optname, value)`

设置给定的 socket 选项的值。`level` 和 `optname` 的含义与 `getsockopt()` 相同。值可以是整数，也可以是表示缓冲区内容的字符串。对于后者，由调用者确保包含正确数据的字符串。选项名称、值和描述请参阅 `getsockopt()`。

### `s.settimeout(timeout)`

为 socket 操作设置超时时间。`timeout` 是一个以秒为单位的浮点数。如果值为 `None`，则表示禁用超时。如果发生超时，将抛出 `socket.timeout` 异常。作为一个一般原则，应该在创建 socket 时立即设置超时时间，因为它们可以应用于涉及建立连接的操作（例如 `connect()`）。

### `s.shutdown(how)`

关闭连接的一半或两半。如果 `how` 为 0，则不允许进一步接收。如果 `how` 为 1，则不允许进一步发送。如果 `how` 为 2，则不允许进一步发送和接收。

除了方法外，socket 实例 `s` 还具有以下只读属性，它们对应于传递给 `socket()` 函数的参数。

| 属性 | 描述 |
| :--- | :--- |
| `s.family` | socket 地址族（例如 `AF_INET`） |
| `s.proto` | socket 协议 |
| `s.type` | socket 类型（例如 `SOCK_STREAM`） |

## 异常

以下是 `socket` 模块定义的异常。

### `error`

当发生 socket 或地址相关的错误时抛出此异常。它返回一个二元组 `(errno, mesg)`，其中包含底层系统调用返回的错误和消息。继承自 `IOError`。

### `error`

当发生地址相关错误时抛出的异常。返回一个包含错误代码和错误消息的元组 `(herno, hmesg)`。继承自 `error`。

### `gaierror`

当 `getaddrinfo()` 和 `getnameinfo()` 函数中发生地址相关错误时抛出的异常。它返回一个元组 `(errno, mesg)`，其中 `errno` 是错误代码，`mesg` 是包含消息的字符串。`errno` 是 `socket` 模块定义的以下常量之一：

| 常量 | 描述 |
| :--- | :--- |
| `EAI_ADDRFAMILY` | 不支持的地址族。 |
| `EAI_AGAIN` | 名称解析出现临时故障。 |
| `EAI_BADFLAGS` | 无效的标志。 |
| `EAI_BADHINTS` | 错误的提示。 |
| `EAI_FAIL` | 域名解析出现不可恢复的失败。 |
| `EAI_FAMILY` | 主机不支持的地址族。 |
| `EAI_MEMORY` | 内存分配失败。 |
| `EAI_NODATA` | 名称没有关联的地址。 |
| `EAI_NONAME` | 未提供节点名或服务名。 |
| `EAI_PROTOCOL` | 不支持的协议。 |
| `EAI_SERVICE` | 该 socket 类型不支持的服务名。 |
| `EAI_SOCKETTYPE` | 不支持的 socket 类型。 |
| `EAI_SYSTEM` | 系统错误。 |

### `timeout`

当 socket 操作超时时抛出的异常。如果使用 `settimeout()` 方法设置了超时，则会发生。

## 示例

一个简单的服务器示例：

```python
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

s.bind(('localhost', 8080))

s.listen(1)

print("Server listening...")

while True:

    conn, addr = s.accept()

    data = conn.recv(1024)

    if data:

        print(f"Received from {addr}: {data.decode()}")

        conn.sendall(b"Message received")

    conn.close()
```

一个简单的客户端示例：

```python
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

s.connect(('localhost', 8080))

s.sendall(b"Hello, server!")

data = s.recv(1024)

print(f"Received from server: {data.decode()}")

s.close()
```
