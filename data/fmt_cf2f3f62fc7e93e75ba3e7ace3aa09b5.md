
关联数组的前缀是百分号（`%`），但数组的每个值都是标量，所以你使用标量前缀（`$`）来引用单个元素。以下是设置关联数组的方法：

```
%array = ("key1" => "value1", "key2" => "value2");
```

你可以使用键访问关联数组的值：

```
$value = $array{"key1"};
```

## 脚本基础

### foreach
Perl 中另一个常见的流程组件是 `foreach`，它允许你遍历所有元素。在这里，`foreach` 语句将 `@buffer` 分为它的组成元素，在循环期间将每个每个元素赋值给 `$line`，并允许你根据数组中元素的数量多次地使用它：

```
foreach $line (@buffer) {
    print $line;
}
```
