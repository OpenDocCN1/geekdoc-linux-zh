### 选择帧和帧集

在项目的这一部分，你将学习选择帧和帧集以便对其进行修改。

12. 打开文档时，通过选择 `Window`| `Frames` 使帧面板可见。通过 `Window`| `Properties` 激活属性检查器。![](img/eb7bf63026b0f3188f312686de439a8a_316_0.png)

13. 在帧面板中点击其表示来选择帧。注意帧面板中的轮廓从灰色变为黑色。点击帧面板中的轮廓来选择整个帧集。![](img/eb7bf63026b0f3188f312686de439a8a_316_1.png)

14. 检查属性检查器，你会发现它已变为显示所选帧的名称和属性。正如你在后续项目中所学的，你可以从属性检查器更改帧的许多特性。![](img/eb7bf63026b0f3188f312686de439a8a_316_2.png)

15. 你也可以通过点击窗口中帧的边界来选择帧。帧周围会出现一条虚线，其在帧面板中的表示将被高亮，让你知道它已被选中。![](img/eb7bf63026b0f3188f312686de439a8a_317_0.png)

### 修改帧和帧集

为了此 Web 页面的设计，我们将通过拆分帧并更改单个属性来修改帧的结构。Dreamweaver 提供了完成此点的工具。

16. 从设置帧集属性开始。在帧面板或窗口中点击边界以选择帧集。属性检查器将变为显示帧集的当前属性。![](img/eb7bf63026b0f3188f312686de439a8a_317_1.png)

17. 点击 `Borders` 下拉菜单并向下滚动选择 `Yes`。这将设置帧集的边界在浏览器中显示为 3D 条。在 `Border Width` 文本框中输入“10”（像素）。点击 `Border Color` 框从调色板中选择一种颜色。你选择的结果出现在窗口中。

18. 在属性检查器（Property Inspector）底部的 `Value`（值）框中设置框架集（frameset）中框架的比例。在框中输入“25”，点击 `Units`（单位）行按钮，滚动下拉菜单并选择不同的单位：`Pixels`（像素）、`Percent`（百分比）和 `Relative`（相对），观察每种选择的结果。然后将 `Percent`（百分比）设为你的单位。![](img/eb7bf63026b0f3188f312686de439a8a_318_0.png)

19. 点击属性检查器右下角的缩略图图形，以选择框架集内不同的行或列，对其应用测量单位。从 `Unit`（单位）菜单中选择 `Relative`（相对），指定浏览器用该框架填充窗口的剩余空间。![](img/eb7bf63026b0f3188f312686de439a8a_318_1.png)

## 将一个框架划分为多个框架

当你想要在 Web 页面上打开新区域显示内容时，Dreamweaver 提供了方法。在项目的这一部分，你把一个框架划分为多个框架。

20. 点击框架边界内部，选择一个要一分为二的框架。![](img/eb7bf63026b0f3188f312686de439a8a_318_2.png)

21. 选择 `Modify`（修改）| `Frameset`（框架集），滚动下拉菜单选择 `Split Frame Left`（向左分割框架）。![](img/eb7bf63026b0f3188f312686de439a8a_319_0.png)

22. 框架中心出现了一个分割线，由原始的一个框架变成了两个。![](img/eb7bf63026b0f3188f312686de439a8a_319_1.png)

23. 使用此方法继续划分并创建新框架。注意 `Frames`（框架）面板每次都会更新，以显示新框架并指示当前活动的框架。![](img/eb7bf63026b0f3188f312686de439a8a_319_2.png)

## 保存框架和框架集

为了在浏览器中预览由框架组合的页面，你必须保存框架或框架集。你可以使用 Dreamweaver 的多个选项之一保存整个框架集或其包含的单个框架。

24. 一旦你创建了想要保存的框架集布局，选择 `File`（文件）| `Save Frameset`（保存框架集）。![](img/eb7bf63026b0f3188f312686de439a8a_320_0.png)

25. 在 `Save As`（另存为）对话框中，选择你想保存框架集的文件夹，在 `Name`（名称）文本框中输入它的名称以便以后识别。点击 `Save`（保存）。![](img/eb7bf63026b0f3188f312686de439a8a_320_1.png)

26. 使用类似的方法保存单个框架。选择一个框架并选择 `File`（文件）| `Save Frame`（保存框架）。当对话框打开时，确保文件保存在正确的文件夹中，为它命名，并点击 `Save`（保存）。![](img/eb7bf63026b0f3188f312686de439a8a_320_2.png)

## 设置单个框架属性

框架集中的每个框架本质上都是独立的 Web 页面。因此，你像处理任何 Web 页面一样更改它的属性和内容：在文档窗口（Document Window）中打开框架，并使用 Dreamweaver 的工具设置其属性。

27. 从已保存的框架列表中选择一个要处理的框架并在文档窗口中打开它。![](img/eb7bf63026b0f3188f312686de439a8a_321_0.png)

28. 选择 `Modify`（修改）| `Page Properties`（页面属性）。![](img/eb7bf63026b0f3188f312686de439a8a_321_1.png)

29. 在出现的 `Page Properties`（页面属性）对话框中，你可以为框架设置新属性，包括背景颜色、背景图像（正如你在第4章中学会的那样），一旦你对新属性设置满意，选择 `File`（文件）| `Save`（保存）。![](img/eb7bf63026b0f3188f312686de439a8a_321_2.png)

30. 继续在其他文档窗口中打开框架集中的其他框架。为每个框架赋予新属性并保存文件。![](img/eb7bf63026b0f3188f312686de439a8a_322_0.png)

31. 打开包含你刚刚修改的框架集文件。你会发现框架集已更新，反映了你在每个单独框架中做的更改。![](img/eb7bf63026b0f3188f312686de439a8a_322_1.png)
