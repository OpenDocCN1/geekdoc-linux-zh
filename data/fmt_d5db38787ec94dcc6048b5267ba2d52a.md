
如果指定 `FILE`，你必须指定要记录哪个文件名。可选地，你还可以指定文件大小的软限制——当文件变大时，会生成一条额外的日志消息。如果指定了软限制，也可以生成硬限制。在硬限制处没有显式定义的情况下，将进行额外的记录。它设置为：

```
log_type = FILE /var/log/xinetd.log 1024 5120
```
