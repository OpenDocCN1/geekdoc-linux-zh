
> **提示** 这些选项与 `mount` 命令使用的选项大部分等同。

所有文件系统（包括软盘）都可以列在虚拟文件系统表中。软驱的挂载点配置通常如下所示：

```
fd -dev/fd fd - no
```

与其使用 `mount` 命令逐个挂载文件系统，`/etc/fstab` 中定义的所有文件系统都可以使用 `mountall` 命令挂载：

```
# mountall
mount: /dev/disk/c0t2d0s5 already mounted
```
