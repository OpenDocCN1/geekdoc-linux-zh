
# 值

```c
typed struct {
    Pixmap background_pixmap; /* 背景, None 或 ParentRelative */
    unsigned long background_pixel; /* 背景像素 */
    Pixmap border_pixmap; /* 边界或 CopyFromParent */
    unsigned long border_pixel; /* 边界像素 */
    int bit_gravity; /* 位重力 */
    int win_gravity; /* 窗口重力 */
    int backing_store; /* NotUseful, Always */
    unsigned long backing_planes; /* 如果保留保留层 */
    unsigned long backing_pixel; /* 用于恢复层的值 */
    Bool save_under; /* 应该保存下方内容？（弹出窗口） */
    long event_mask; /* 应该保存的事件 */
    long do_not_propagate_mask; /* 不应该传播的事件 */
    bool override_redirect; /* override_redirect 的布尔值 */
    Colormap colormap; /* 与窗口关联的调色板 */
    Cursor cursor; /* 显示的光标（或 None） */
} XSetWindowAttributes;
```

以下列出了每个窗口属性的默认值，并指示该属性是否适用于输入输出和输入仅窗口：

| 属性 | 默认值 | 输入输出 | 输入仅 |
|---|---|---|---|
| `background-pixmap` | `None` | Yes | No |
| `background-pixel` | Undefined | Yes | No |
| `border-pixmap` | `CopyFromParent` | Yes | No |
| `border-pixel` | Undefined | Yes | No |
| `bit-gravity` | `ForgetGravity` | Yes | No |
| `win-gravity` | `WestGravity` | Yes | No |
| `backing-store` | `NotUseful` | Yes | No |
| `backing-planes` | All | Yes | No |
| `backing-pixel` | zero | Yes | No |
| `save-under` | False | Yes | No |
| `event-mask` | empty set | Yes | Yes |
| `do-not-propagate-mask` | empty set | Yes | Yes |

## 窗口属性默认值续

| 属性 | 默认值 | 输入输出 | 输入仅 |
|---|---|---|---|
| `override-redirect` | False | Yes | Yes |
| `colormap` | `CopyFromParent` | Yes | No |
| `cursor` | `None` | Yes | Yes |

## 背景属性

只有输入输出窗口具有背景。你可以通过像素或位图设置输入输出窗口的背景。

窗口的 `background-pixmap` 属性指定了用于背景的位图。该位图可以是任何尺寸，尽管某些尺寸可能比其他更快。窗口的 `background-pixel` 属性指定了绘制窗口的像素值。

你可以将 `background-pixmap` 设置为 `None`、`default` 或 `ParentRelative`。你可以将窗口的 `background-pixel` 设置为任何值。

如果你设置了 `background-pixmap`，它将覆盖默认背景或你设置的任何值。`background-pixmap` 和窗口必须具有相同的深度，否则会导致 `BadMatch` 错误。如果你将 `background-pixmap` 设置为 `None`，则窗口没有背景。如果你将 `background-pixmap` 设置为 `ParentRelative`：

- 使用父窗口的 `background-pixmap`。然而，子窗口的深度必须与父窗口相同，否则会导致 `BadMatch` 错误。
- 如果父窗口的 `background-pixmap` 为 `None`，则该窗口的 `background-pixmap` 也为 `None`。
- 不创建父窗口 `background-pixmap` 的副本。每当需要子窗口的 `background-pixmap` 时都会检查父窗口的 `background-pixmap`。
- 背景平铺起点始终与父窗口的背景平铺对齐。如果 `background-pixmap` 不是 `ParentRelative`，则背景平铺起点为子窗口的起点。

设置新背景（无论是设置 `background-pixmap` 还是 `background-pixel`）都会覆盖之前的背景。如果没有对 `background-pixmap` 进行显式引用，则可以立即释放该位图（X 服务器将保留一个副本以备在需要时使用）。如果你稍后向用于背景的位图进行绘图，发生的情况是未定义的，除非 X 实现可以自由创建位图的副本。

当窗口区域没有可用内容时，且这些区域可见或服务器正在维护备份存储时，服务器将自动用窗口的背景填充这些区域，除非窗口的背景为 `None`。如果背景为 `None`，则使用来自其他窗口的先前屏幕内容。

## 窗口函数与暴露

与窗口深度相同的深度，只要内容来自窗口的父窗口或父窗口的子窗口，就会保持在原处。否则，暴露区域的初始内容是未定义的。如果 `background-pixmap` 为 `None`，则为这些区域生成暴露事件（见第 10.9 节）。

## 边框属性

只有 `InputOutput` 窗口可以有边框。你可以使用像素（pixel）或 `pixmap` 来设置 `InputOutput` 窗口的边框。

窗口的 `border-pixel` 属性指定了用于窗口边框的 `pixmap`。窗口的 `border-pixel` 属性指定了一个填充了该像素的尺寸未定义的 `pixmap`，用于窗口的边框。背景像素不会进行范围更改；它仅被截断为相应的位数。边框平铺起点（tile origin）始终与边框平铺起点相同。

你还可以将 `border-pixmap` 设置为任意大小的 `pixmap`（某些可能比其他更快）或设置为 `CopyFromParent`（默认值）。你可以将 `border-pixel` 设置为任何值（无默认值）。

如果你设置了窗口-`pixmap`，它将覆盖默认值。`border-pixmap` 和窗口必须具有相同的深度，否则会发生 `BadMatch` 错误。如果你将 `border-pixmap` 设置为 `CopyFromParent`，则复制父窗口的 `border-pixmap`。父窗口边框属性的后续更改不会影响子窗口。然而，子窗口必须与父窗口具有相同的深度，否则会导致 `BadMatch` 错误。

如果不再对 `border-pixel` 进行显式引用，可以立即释放它。如果你以后向用于边框的 `pixmap` 绘图，结果是不定义的，因为 X 实现可以自由创建 `pixmap` 的副本或使用同一个 `pixmap`。如果你设置了 `border-pixel`，或者你在默认 `border-pixmap` 中设置的任何值，它将覆盖默认，窗口边框将被设置为 `border-pixel`。设置新边框（无论是通过设置 `border-pixel` 还是设置 `border-pixmap`）都会覆盖任何之前的边框。

到窗口的输出始终被裁剪在窗口内部。因此，图形操作永远不会影响窗口边框。

## 重力属性

窗口位重力（bit gravity）定义了当 `InputOutput` 窗口调整大小时，应该保留窗口的哪个区域。`bit-gravity` 属性的默认值为 `ForgetGravity`。窗口的窗口重力（window gravity）允许你定义当 `InputOutput` 或 `Only` 窗口调整大小时，如何对其重新定位。`win-gravity` 的默认值是 `NorthWestGravity`。

如果窗口的内部宽度或高度没有变化，且窗口移动或其边框发生变化，则窗口的内容不会丢失，而是随窗口移动。更改窗口的内部宽度或高度会导致内容移动或丢失（取决于窗口的位重力），并导致子窗口重新配置（取决于它们的 `win-gravity`）。对于宽度和高度的变化，定义了以下 (x, y) 坐标对：

| 重力方向 | 坐标 |
|---|---|
| `NorthWestGravity` | `(0, 0)` |
| `NorthGravity` | `(Width/2, 0)` |
| `NorthEastGravity` | `(Width, 0)` |
| `WestGravity` | `(0, Height/2)` |
| `CenterGravity` | `(Width/2, Height/2)` |
