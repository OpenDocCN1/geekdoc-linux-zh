# sccs-rmdel, rmdel — 从 SCCS 文件中删除 Delta

### 概要

`/usr/ccs/bin/rmdel -r sid s.filename...`

## 描述

使用 SCCS `rmdel` 命令删除由 `-r` 选项提供的 SCCS delta (`sid`) 选项指定的 delta。要删除的 delta 必须是该分支中最新的（叶节点）delta。此外，该 `sid` 不能是已检出待编辑的版本；它不能出现在版本锁文件 (`p. file`) 的任何条目中。

如果你创建了该 delta，或者拥有该文件和目录并具有写权限，你可以可以使用 `rmdel` 删除它。

如果你使用目录名代替 `s.filename` 参数，则 `rmdel` 命令适用于该目录下的所有文件。不可读的 `s.` 文件会产生错误；程序继续处理下一个文件（如果有）。使用破折号 (`-`) 作为 `s.filename` 参数表示从标准输入中读取文件名，每行一个 `s.` 文件。

## 选项

`-r sid` 删除与指示 `sid` (delta) 对应的版本。

## 文件

- `p. file` 权限文件。
- `s. file` 历史文件。
- `z. file` `s.` 文件的临时副本。

# sccs-val, val — 验证 SCCS 文件

### 概要

`/usr/ccs/bin/val [-s] [-m name] [-r sid] [-y type] s.filename...`

## 描述

使用 `val` 命令来确定 `s.`文件是否符合指定参数的特征。`val` 在单个命令行上可以处理 50 个文件。

`val` 有一个特殊的破折号 (`-`) 参数，从标准输入读取直到检测到文件结束。读取的每行都被独立处理，就像命令行列表一样。

`val` 为每个命令行和文件向标准输出生成诊断信息，并在退出时返回一个下述的单一 8 位代码。

`val` 返回的 8 位代码是可能错误的并集，也就是说，它可以被解释为位字符串（从左到右），设置的位位解释如下：

* 位 0 = 缺失文件参数。
* 位 1 = 未知或重复选项。
* 位 2 = `s.` 文件 损坏。
* 位 3 = 无法打开文件或不是 `s.` 文件格式。
* 位 4 = SCCS delta ID (`sid`) 无效或模糊。
* 位 5 = `sid` 不存在。
* 位 6 = `%Y%` 与 `-y` 参数不匹配。
* 位 7 = `%M%` 与 `-m` 参数不匹配。
