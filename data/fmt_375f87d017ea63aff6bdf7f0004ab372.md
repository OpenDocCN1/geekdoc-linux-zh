
# 第一部分 Shell 脚本基础

## 第 2 章 24 种逐行处理文件的方法

### 方法 13：`while_LINE_line_bottom_FD_OUT`

```bash
# 清空 $OUTFILE
> $OUTFILE

# 将标准输出与文件描述符 4 关联
# 并将标准输出重定向到 $OUTFILE
exec 4<&1
exec 1> $OUTFILE

while read LINE
do
    echo "$LINE"
    :
done < $INFILE

# 恢复标准输出并关闭文件描述符 4
exec 1<&4
exec 4>&-
```

### 方法 17：`_outfile___`

```bash
# 清空 $OUTFILE
> $OUTFILE

# 将标准输入与文件描述符 3 关联
# 并将标准输入重定向到 $INFILE
exec 3<&0
exec 0< $INFILE

# 此函数处理 $INFILE 的每隔一行，因此不要使用 while read
while read
do
    line >> $OUTFILE
done

# 恢复标准输入并关闭文件描述符 3
exec 0<&3
exec 3>&-
```
