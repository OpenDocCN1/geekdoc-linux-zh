
# SuSE 代理
SuSE 代理——SuSE 代理是一组增强防火墙安全的程序。发布的第一个（也是目前唯一的）组件是 FTP 代理：它在客户端和服务器之间中继 FTP 连接或从主动模式切换到反之，利用用于控制和数据的端口，并提供详尽的审计（作为系统日志或记录日志文件），或者可以将用户相关的审计与触发的审计事件分开，或者根据登录用户名限制命令，允许使用正则表达式进行域名参数检查，完全符合 RFC 959 和 1123（FTP RFC 的基础），源自计划支持 RFC 1579（文件友好型 FTP”）或计划支持 RFC 2428（FTP 的 IPv6 扩展）。基于 GNU AutoConf，可以在许多 Unix 系统上运行，源自 Debian 3.0r APT http://www.ldp.org/LDP/Linux-Dictionary/html.index

## Linux 字典

## `ftp`
支持 SSL 加密的 FTP 客户端。`ftp` 是 ARPANET 标准文件传输协议的用户界面。该程序允许用户向远程站点传输文件。`ftp` 使用 SSL 身份验证和加密取代了普通的 `ftp`。它能与普通 `ftp` 互操作。它会检查对方是否也在进行通信，如果失败，将回退到普通 `ftp` 协议。与普通 `ftp`(d) 相比的优势：您的密码和发送的数据将不会以明文形式在网络上传输。没有人可以使用 `tcpdump` 或类似的工具获取它们。来自 Debian 3.0r0 APT
http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## `ftp-upload`
通过脚本上传文件 `ftp-upload` 使用 FTP 将文件传输到另一台机器。它旨在供脚本等进行交互使用。它没有用户界面，程序严格通过命令行进行控制。它的状态输出非常严谨。来自 Debian 3.0r0 APT
http://www.ldp.org/LDP/Linux-Dictionary/html/index.html

## `ftp-utils`
用于脚本的 ftp 支持 `ftp-utils` 是一小组用于 FTP 协议的工具。使用它，您可以编写脚本，对于本地文件系统和通过 FTP 访问的远程文件系统同样有效。该发行版包含一个小型脚本，用于构建或维护 FTP 镜像（从镜像推送到目标）。来自 Debian 3.0r0 APT

## `ftp-ssl`
支持 SSL 加密的 FTP 服务器。这是一个支持加密的 netkit ftp 服务器，`ftp-ssl` 使用 SSL 身份验证和加密取代了普通 ftp。它与普通 ftp 互操作。它会检查对方是否也在进行通信，如果失败，将回退到普通 ftp 协议。与普通 ftp(d) 相比的优势：您的密码和发送的数据将不会以明文形式在网络上传输。没有人可以使用 `tcpdump` 或类似的工具获取它们。来自 Debian 3.0r0 APT

## `ftfps-src`
透明 FTP 文件系统的虚拟文件系统是一个 Linux 内核模块，它增强了 VFS 具有 FTP 卷挂载能力。也就是说，您可以在您的个人文件系统中“挂载”FTP 共享目录，并利用本地文件操作优势。此包包含了准备好的源代码，您可以使用 `make-kpkg` 为您的内核构建模块包。来自 Debian 3.0r0 APT

Mount for FTP 软件包包含 `ftp` 工具程序，用于挂载 FTP 文件系统。还有一个名为 `auto.ftp` 的辅助应用程序，允许在 `autofofs` 中使用 FTP 传输。来自 Debian 3.0r0 APT

## `ftpgrab`
文件镜像 `ftpgrab` 用于维护 FTP 镜像。尽管与 "Mirror" 程序相似，但它获取的是软件的版本。`ftpgrab` 的主要“优点”在于它非常智能，可以通过解析文件中的 ftp 文件名做出决策。例如，`ftpgrab` 会根据版本字符串识别出文件 "linux-2.2.2.tar.gz" 比 "linux-2.2.1.tar.gz" 新。它将下载新版本并在完成后删除旧版本，为您节省了镜像 10 个每个大于 10mb 的内核版本的空间。来自 Debian 3.0r0 APT
http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
