将数字从一个进制转换为另一种的最早方法是使用带有 `-ibase` 选项的 `typeset` 命令。

一个整数值。这一次我们通过通过 `typeset -i VAR_NAME` 指定的整数设置来添加内容，方法是添加该变量要保持的数值进制。例如，如果变量 `BASE_16_NUM` 始终接受十六进制数，那么下一条命令将设置该变量的环境：

```bash
typeset -i16 BASE_16_NUM
```

在 `BASE_16_NUM` 变量被类型设置为 16 进制之后，赋值给此变量的任何值都会自动转换为十六进制。我们也可以在分配数字后对变量进行类型设置。这不仅适用于 10 进制数字，也适用于任何系统限制内的数字（至少是 16 进制）。让我们来看一些进制转换的示例。

## 示例 23.1：从 10 进制转换为 16 进制

```bash
[root@yogi:/scripts] typeset -i16 BASE_16_NUM
[root@yogi:/scripts] BASE_16_NUM=47295
[root@yogi:/scripts] echo $BASE_16_NUM
```

注意示例 23.1 中的输出。输出首先设置了所表示的进制，即 16 进制。井号 (`#`) 之后的字符串是十六进制数 `b8bf`。接下来我们将从 8 进制转换为 16 进制十六进制。我们使用相同的技术，只不过如示例 23.2 所示，这次我们必须在赋值时指定八进制的进制。

## 示例 23.2：从 8 进制转换为 16 进制

```bash
[root@yogi:/scripts] typeset -i16 BASE_16_NUM
[root@yogi:/scripts] BASE_16_NUM=8#472521
[root@yogi:/scripts] echo $BASE_16_NUM
```

```bash
16#73c9
```

在示例 23.2 中，注意我们通过指定进制后跟数字 8（`BASE_16_NUM=8#472521`）将八进制 472521 分配给了 `BASE_16_NUM` 变量。当这个 8 进制数赋值给 `BASE_16_NUM` 变量时，它会自动转换为 16 进制。正如你所看到的，系统可以为我们完成这些工作。

在 Unix 中，完成任务绝不仅有一种方法，数字转换也不例外。我们也可以使用 `printf` 命令在数字之间转换。`printf` 命令接受 10 进制整数值并将数字转换为指定的进制。可用选项有：

- `o` 接受一个 10 进制整数并以八进制打印该数字
- `x` 接受一个 10 进制整数并以十六进制打印该数字

让我们来看使用 `printf` 命令的两个示例。

## 示例 23.3 将 10 进制转换为八进制

```bash
root@yogi:/scripts> printf %o 20398
47656
```

在示例 23.3 中，注意在 `printf` 命令选项之前添加了百分号 (`%`)。这个 `%o` 告诉 `printf` 小写 `o` 是到八进制的数字进制转换。

## 示例 23.4 将 10 进制转换为十六进制

```bash
root@yogi:/scripts> printf %x 20398
4ae
```

虽然不如 `typeset` 命令灵活（它允许你进行从 10 进制到 8 进制和 16 进制的进制转换），但我喜欢 `typeset` 命令提供的额外灵活性，因此这是我们在本章将使用的转换方法。

## 2 进制（二进制）到 16 进制（十六进制）shell 脚本

这是大多数计算机科学学生在学校学习的第一个转换。用铅笔和纸进行转换很容易，但嘿，我们想要自动化！这个 shell 脚本将使用 `typeset` 技术从二进制转换为十六进制，正如所有这些脚本都使用它的那样。你已经知道了转换的基本原理，所以让我们展示这个 shell 脚本并在最后介绍细节。列表 23.1 显示了 `equate_base_2_to_16_sh` shell 脚本。

```bash
#!/usr/bin/ksh

#
# SCRIPT: equate_base_2_to_16.ksh
## AUTHOR: Randy Michael
# DATE: 07/07/2002
# REV: 1.2.P
#
# PURPOSE: 此脚本用于将 2 进制数
# 转换为16 进制表示。
此脚本期望 2 进制数
# 作为单个参数提供。
# EXIT CODES:
# 0 成功
# 1 错误
#
# 检查参数是否为 1
if [[ $# -ne 1 ]]; then
	echo "用法: $0 [2进制数字]"
	exit 1
fi

# 获取输入参数
binary_num=$1

# 检查输入是否为合法的二进制
if [[ ! $binary_num =~ ^[01]+$ ]]; then
	echo "错误: $binary_num 不是有效的 2 进制数"
	exit 1
fi

# 使用 typeset 技术进行转换
typeset -i16 BASE_16_NUM=$((16#$binary_num))

# 输出结果
echo "十六进制结果: $BASE_16_NUM"
```
