
创建一个元组的子类，其名称为 `typename`。`fieldnames` 是字符串列表。此列表中的字符串必须是有效的标识符，不能以下划线开头，并且顺序与元组中的项相同。或者，`fieldnames` 可以指定为字符串，例如 `'hostname port'`。该函数返回的值是一个使用过的类。`verbose` 标志如果设置为 `True`，则会打印结果类。

这是一个使用该函数的示例：

```
>>> from collections import namedtuple
>>> NetworkAddress = namedtuple('NetworkAddress', ['hostname', 'port'])
>>> a = NetworkAddress('www.python.org', 80)
>>> a.hostname
'www.python.org'
>>> a.port
80
>>> len(a)
2
>>> type(a)
<class '__main__.NetworkAddress'>
>>> isinstance(a, tuple)
True
```

在这个示例中，命名元组 `NetworkAddress` 在某些方面与普通元组无异，增加了可以使用属性查找 `a.hostname` 或 `a.port` 的支持。底层实现是高效的——该类没有使用实例字典，也没有比内置元组消耗额外的内存。所有正常操作仍然有效。

命名元组可以用于定义仅作为数据结构的对象。例如，与其定义一个如下的类：

```
class Stock(object):
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
```

你可以定义一个命名元组：

```
import collections
Stock = collections.namedtuple('Stock', 'name shares price')
```

命名元组经常被用于 Python 标准库的其他部分。在这里，它们的返回值在某种程度上具有历史性——在许多库模块中，元组最初被用于返回有关文件、帧或其他低层细节的信息。使用这些元组的代码并不总能在不破坏向后兼容的情况下清理其使用方式。元组的另一个微妙问题是，一旦你开始使用元组，预期的字段数量就会永久锁定（例如，如果你突然添加一个新字段，旧代码将会崩溃）。命名元组的变体已用于库中为某些函数返回的数据添加新字段。例如，一个对象可能支持旧的元组接口，但随后提供了只能作为命名属性访问的额外值。

## 抽象基类 Abstract Base Classes

`collections` 模块定义了一系列抽象基类。这些类的目的是描述各种类型容器（如列表、集合和字典）的编程接口。这些类主要有两个用途：首先，它们可以作为用户定义对象的基类，用以模拟内置容器类型的功能；其次，它们可以用于类型检查。例如，如果你想检查 `s` 是否工作得像一个序列，可以使用 `isinstance(s, collections.Sequence)`。

### Container 容器

所有容器的基类。定义了一个单一抽象方法 `__contains__()`，该方法实现了 `in` 运算符。

### Hashable 可哈希

可以作为哈希表键对象的基类。定义了一个单一抽象方法 `__hash__()`。

### Iterable 可迭代

支持迭代协议对象的基类。定义了一个单一抽象方法 `__iter__()`。

### Iterator 迭代器

迭代器对象的基类。定义了抽象方法 `next()`，但同时也继承自 `Iterable` 并提供了 `__iter__()` 的默认实现，该方法简单什么都不做。

### Sized 有长度

可以确定大小的容器的基类。定义了抽象方法 `__len__()`。

### Callable 可调用

支持函数调用的对象的基类。定义了抽象方法 `__call__()`。

## Sequence 序列

看起来像序列对象的基类。继承自 `Container`、`Iterable` 和 `Sized`，定义了 `__getitem__()` 和 `__len__()` 的实现。还提供了 `__contains__()`、`__iter__()`、`__reversed__()`、`__index__()` 和 `__count__()` 的默认实现，这些实现仅使用 `__getitem__()` 和 `__len__()` 方法。

## MutableSequence 可变序列

可变序列的基类。继承自 `Sequence` 并添加了抽象方法 `__setitem__()` 和 `__delitem__()`。还提供了 `append()`、`reverse()`、`extend()`、`pop()`、`remove()` 和 `__iadd__()` 的默认实现。

## Set 集合

工作像集合的对象的基类。继承自 `Container`、`Iterable` 和 `Sized`，并定义了抽象方法 `__len__()`、`__iter__()` 和 `__contains__()`。还提供了集合运算符 `__le__()`、`__lt__()`、`__eq__()`、`__ge__()`、`__and__()`、`__or__()`、`__xor__()`、`__sub__()` 和 `isdisjoint()` 的默认实现。

## MutableSet 可变集合

可变集合的基类。继承自 `Set` 并添加了抽象方法 `discard()`。还提供了 `clear()`、`pop()`、`remove()`、`__ior__()`、`__iand__()`、`__ixor__()` 和 `__isub__()` 的默认实现。

## Mapping 映射

支持映射（字典）查找对象的基类。继承自 `Sized`、`Iterable` 和 `Container`，定义了抽象方法 `__getitem__()`、`__len__()` 和 `__iter__()`。提供了 `__contains__()`、`keys()`、`items()`、`values()`、`get()`、`__eq__()` 和 `__ne__()` 的默认实现。

## MutableMapping 可变映射

可变映射的基类。继承自 `Mapping` 并添加了抽象方法 `__setitem__()` 和 `__delitem__()`。增加了 `pop()`、`popitem()`、`clear()`、`update()` 和 `setdefault()` 的实现。

## MappingView 映射视图

映射视图的基类。映射视图是一种用于像集合一样访问映射对象项的对象。例如，键是一个类集合对象，用于显示映射中的键。更多详细信息请参见附录 A，“Python 3”。

## KeysView 键视图

映射键视图的基类。继承自 `MappingView` 和 `Set`。

## ItemsView 项视图

映射项视图的基类。继承自 `MappingView` 和 `Set`。

## ValuesView 值视图

映射的（键, 元素）视图的基类。继承自 `MappingView` 和 `Set`。

Python 的内置类型已根据需要注册到所有这些基类中。此外，通过使用这些类，可以编写出类型检查更精确的程序。以下是一些示例：

```python
# 获取序列的最后一个项
if isinstance(x, collections.Sequence):
    last = x[-1]
```

```python
# 仅当大小已知时对对象进行迭代
if isinstance(x, collections.Iterable) and isinstance(x, collections.Sized):
    for item in x:
    statements
```

```python
# 向集合中添加新项
if isinstance(x, collections.MutableSet):
    x.add(item)
```
