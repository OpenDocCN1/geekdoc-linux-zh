## Description

- `-h`

  显示 `smart2cfg` 命令的在线帮助。

- `-l logical-drive-num controller-num`

# sort — 排序、合并或顺序检查文本文件

### 概要

```
/usr/bin/sort [-bdfimMnru] [-k keydef] [-o output] [-t char...] [-T directory][-y [k mem]] [-z rec z][+pos1][-pos2]][file...
/usr/xpg4/bin/sort [-bdfimMnru] [-k keydef] [-o output] [-t char...] [-T directory][-y [k mem]] [-z rec z][+pos1][-pos2]][file...
```

## 描述

使用 `sort` 命令对文件中的行按字母顺序（默认）或数字顺序重新排列，并将结果写入标准输出。

默认情况下，`sort` 命令使用行的开头作为用于排序的键字段。你可以指定文件中的任何字段作为键字段。行根据当前区域（locale）的排序序列进行排序。默认情况下，`sort` 使用 ASCII 排序序列，该序列先排序空白字符，接着是大多数标点符号，然后是数字、大写字母，最后是小写字母。当键字段中的第一个字符相同时，`sort` 在需要时会查看换行符之前的每个后续字符，以确定正确的排序顺序。

对于数字排序，除非使用 `-n` 选项，否则数字不会按照真正的数字顺序排序。相反，数字排序的结果可能如下例：

```
1
10
11
2
20
21
3
30
```

你得到这个结果是因为所有以 1 开头的行都被分在一起，然后是所有以 2 开头的行，依此类推。

注意 — 如果输入文件的最后一行缺少换行符，`sort` 会附加一个换行符，打印警告消息并继续。`sort` 不保证在等等键上保持相对行顺序。

## 选项

### /usr/bin/sort

- `-c` 检查单个输入文件是否按照参数和当前区域的排序序列进行了排序。设置退出码，除非文件超出排序顺序，否则不产生输出。

### /usr/xpg4/bin/sort

- `-c` 与 `/usr/bin/sort` 相同，但在任何情况下都不产生输出。

- `-m` 合并。假设输入文件已经排序。

- `-u` 排序时抑制每组具有相等键的行中除一个以外的所有行。与 `-c` 选项配合使用，除了检查输入文件已排序外，还会检查没有重复键的行。

- `-o output` 指定用于替代标准输出的输出文件名称。该文件可以是输入文件之一。

- `-T directory` 指定用于临时文件的目录名称。

- `-y k mem` 指定初始使用的内存量。开始使用该数量的字节内存，除非超过了管理的最小值或最大值，如果是这样，则执行相应的表达式。因此，`-y 0` 保证从最小内存开始。不带 `k mem` 参数的 `-y` 则从最大内存开始。如果你省略此选项，将从默认内存大小开始使用，并根据需要继续使用更多空间。

- `-z recs z`（已弃）。用于在遇到超过系统默认缓冲区的行时防止异常终止。由于 `sort` 会自动分配足够容最长行的缓冲区，因此此选项没有作用。

## 排序选项

以下选项将覆盖默认排序规则。当排序选项独立于任何键字段规范出现时，所请求的字段排序规则将全局应用于所有排序键。当附加到特定键上时，指定的排序规则将覆盖该键的所有全局排序选项。在已弃的形式中，如果一个或多个这些选项位于 `+pos` 选项之后，则仅受该先决选项指定的键字段的影响。

- `-d` 按字典顺序排序。在比较时，仅认为字母、数字（空格和制表符）是有效字符。

- `-f` 将小写字母转换为大写字母。

- `-i` 忽略不可打印字符。

- `-M` 按月份进行比较。将字段前三个非空白字符转换为大写并进行比较。例如，在英语中，排序顺序为 JAN < FEB ... < DEC。无效字段的比较顺序低于 JAN。以月份字母之一开头的无效字段会使 `sort` 产生困惑。`-M` 选项隐含了 `-b` 选项。
