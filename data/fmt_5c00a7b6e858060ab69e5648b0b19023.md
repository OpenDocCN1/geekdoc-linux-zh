
## 选项

- `-l` 如果你指定了 `no-job-id` 操作，则报告为调用用户调度的所有作业。如果你指定了 `at-job-ids`，则报告这些作业的信息。

- `-m` 在 `at` 任务运行后向调用用户发送邮件通知其已完成。除非重定向到其他地方，否则会将 `at` 任务产生的标准输出和标准错误发送给用户。即使作业没有产生输出也会发送。如果你不使用 `-m`，除非重定向到其他地方，否则作业的标准输出和错误将邮件发送给用户；如果没有可提供的此类输出，则不会通知用户作业已完成。

- `-q` `queuename` 指定用于调度作业提交的队列。当与 `-l` 选项配合时，将搜索限制在该特定队列。`queuename` 的值限于小写字母 a 到 z。默认情况下，`at` 任务调度在队列 `a` 中。相比之下，队列 `b` 留给批处理作业。由于队列 `c` 留给 cron 作业，因此无法配合 `-q` 选项使用它。

- `-r` `at-job-id` 删除之前通过 `at` 命令调度的具有指定 `at-job-id` 参数的作业。

- `-t` `time` 提交作业在选项参数的时间运行，该参数采用十进制格式 `[[CC YY] MMDDhhmm[. SS]]`，其中每两个数字代表：

  - `MM` 年的月份 [01-12]。
  - `DD` 月的几号 [01-31]。
  - `hh` 当天的小时 [00-23]。
  - `mm` 小时的分钟 [00-59]。
  - `CC` 年的前两位数字。
  - `YY` 年的后两位。
  - `SS` 分钟的后两位 [00-61]。

更多详情请参考 `touch(1)` 手册页。

## 参数

`at_job_id` 已调度 `at` 任务的标识符。

`timespec` 提交作业在指定的日期和时间运行。所有的 `timespec` 参数都被解释为用空格分隔并连接。日期和时间被解释为用户所在的时区（由 `TZ` locale 决定，除非时间名称作为时间的一部分出现）。

在 C locale 中，以下描述了时间规范字符串的三个部分。C locale 中 `LC_TIME` 类别中的所有值均不区分大小写。

`time` 你可以指定一位、两位或四位数字。一位和两位数字被解释为小时和分钟。四位数被解释为小时和分钟。或者，你可以用冒号分隔的两个数字来指定时间：`小时:分钟`。你可以指定一个 a.m./p.m. 值（LC_TIME locale 类别中 `am_pm` 关键字的值之一）。该值可以跟在时间后面。否则，理解为 24 小时制。可以跟随 `GMT`、`UCT` 或 `ZULU`（不区分大小写）时区名称，以指定该时间为协调世界时。你可以通过 `TZ` 环境变量指定其他时区。时间字段在 C locale 中也可以是以下标记之一：

- `- midnight` 表示时间 12:00 a.m. (00:00)。
- `- noon` 表示时间 12:00 p.m.。
- `- now` 表示当前的日期和时间。调用 `at now` 提交一个可能立即执行的 `at` 任务（即仅取决于未指定的调度延迟）。

`date`

你可以指定可选日期为月份名称（LC_TIME locale 类别中 `mon` 或 `abmon` 关键字的值之一）后跟日期数字（或可能是由逗号之前的年份）或星期几（LC_TIME locale 类别中 `day` 或 `abday` 关键字的值）。在 C locale 中识别两个特殊日期：

`today`

当前日期。

`tomorrow`

今天的后一天。如果没有给出日期，且给定的时间大于当前时间，则假设为今天；如果小于当前时间，则假设为明天。如果给定的月份小于当前月份（且未给出年份），则假设为明年。

`increment`

可选的增量是一个以加号 (+) 开头的数字，并以以下之一结尾：`minutes`, `hours`, `days`, `weeks`, `months`, 或 `years`。（也接受单数形式）。关键字 `next` 等同于增量数字 `+1`。例如，以下这些是等效的命令：

```
at 2pm + 1 week
at 2pm next week
```

## 使用

此处显示的 `at` 命令行格式仅在 C locale 中保证。其他 locale 不支持 `midnight`, `noon`, `now`, `mon`, `abmon`, `day`, `abday`, `today`, `tomorrow`, `minutes`, `hours`, `days`, `weeks`, `months`, `years` 和 `next`。

由于命令在单独调用中运行，在没有控制终端的单独进程组中运行会导致丢失自调用环境的文件描述符、陷（traps）和优先级。

## 环境变量

参阅 `environ(5)` 了解影响 `at` 和 `batch` 执行的环境变量描述：`LC_TYPE`、`LC_MESSAGES`、`NLSPATH` 和 `LC_TIME`。

- `SHELL`: 确定用于调用 `at` 任务的命令解释器的名称。如果变量未设置或为空，则使用 `sh`。如果它被设置为 `sh` 以外的值，则实现将使用该 shell；并打印警告说明使用的是哪种 shell。

- `TZ`: 根据相对于 `TZ` 变量指定的时区，确定任务在 `times` 或 `- t` 指定时间提交以供执行的时间。如果 `times` 指定了时区，它将覆盖 `TZ`。如果 `times` 未指定时区且 `TZ` 未设置或为空，则使用一个未分配的默认时间。

- `DATEMSK`: 如果环境变量 `DATEMSK` 已设置，`at` 将其值作为包含格式化字符串的模板文件的完整路径。这些字符串由格式说明符和文本字符组成，通过对环境变量 `LANG` 或 `LC_TIME` 进行适当设置，为不同语言提供更丰富的允许日期格式集。允许的格式说明符列表位于 `getdate(3)` 手页中时间和日期参数的“Operations”部分。当设置 `DATEMSK` 时，无法识别 `noon`、`midnight`、`now`、`next`、`today`、`tomorrow` 以及增量参数。

## 退出状态

- `0`: `at` 命令成功提交、删除或列出了一个或多个任务。
- `>`: 发生错误，且任务未被调度。

```
/usr/lib/cron/at.allow
```


每行一个、被拒绝访问 `at` 和 `batch` 命令的用户名。
