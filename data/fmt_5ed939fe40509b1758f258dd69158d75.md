图 E.20 拷贝操作的源目重叠。

如果拷贝是从源的开始到目的的开始，如 C 代码片段所示：

```c
while (nbytes--)
    *dst++ = *src++;
```

则会执行两个赋值语句：

```c
x[1] = x[2];
x[2] = x[3];
```

这是正确的。但如果按反方向拷贝，如 C 代码片段所示：

```c
src += nbytes;
dst += nbytes;
while (nbytes--)
    *--dst = --src;
```

那么两个赋值语句为：

```c
x[2] = x[3];
x[1] = x[2];
```

这是错误的（为什么？）。`memcpy` 拷贝的方向是不保证的，因此当字段重叠时，必须调用 `memmove`。`memmove` 通过在“正确”的方向进行拷贝来处理重叠，取决于源和目的之间的关系。
