
#### 7.11. Header Definitions

Each line begins with the `H` command, which is optionally followed by header flags enclosed in marks. The header flags control whether the header is inserted into mail for a specific mailer.

*   If no flags are specified, the header is used for all mailers.
*   If a flag is specified, the header is used only for a mailer that has the same flag.

(Mailer definitions are covered later.)

Each line also contains a header name and a header template. These fields define the structure of the actual header. Macros in the header template are expanded before the header is inserted in the message.

The first header in Listing 7.11 contains `$g`, which tells `Sendmail` to use the value stored in the `g` macro. The `g` macro holds the sender's email address. Assume that the sender is `user@example.com`, the header might contain:

```
From: user@example.com
```
