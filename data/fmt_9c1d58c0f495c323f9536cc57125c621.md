
从特定位置观察到的天文对象磁盘上被照亮部分的分数变化。月亮的月相是一个熟悉的例子（见图）。当太阳大致位于月亮（从地球看）的远端（合）时，月亮的暗面朝向地球，这就是新月。随着月亮被照亮面逐渐增大的分数被看到，月相变亮，从新月开始经历蛾眉月。在象限位置，当月亮可见面的一半被照亮时，该月相被称为上弦月，因为月亮此时正处于其月相周期的四分之一处。变亮的月亮继续经历盈凸月阶段，直到到达冲的位置；月亮的整个可见面被照亮，即满月。在满月期间，月亮和太阳位于地球的两侧；这是一种称为朔望（syzygy）的合。然后月亮变暗，经历亏凸月、下弦月和残月阶段，直到再次变成新月。月相周期大约需要 29.53 天，这也解释了“月”（month）一词的起源。参见 `MOON`（月亮）。

# 相位角测量

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1659_0.png)

正弦波的相位含义示意图。波1和波2之间的相位差为 $\varphi$，称为*相位角*。对于每个波，`A` 是振幅，`T` 是周期。

相位角测量是测量两个周期性信号之间时间延迟的方法。两个频率相同且无直流分量的正弦波形之间的相位差，可以方便地按示意图所示的方式描述。可以看出，相位角可以被视为两个周期性信号之间以波周期分数表示的时间延迟度量。这个分数通常以角度为单位表示，一个完整周期对应 $360^\circ$。例如，在示意图中，电压 `v1` 比第二个电压 `v2` 提前一个周期通过零点，则它超前 $360^\circ/8$ 或 $45^\circ$。相位角通常定义为各波形基波分量；因此，任一或两个信号的失真都可能引起误差，误差程度取决于失真的性质和测量方法。参见**失真**（电子电路）。

大多数现代相位测量设备都基于零交叉检测器的使用。通常通过平方电路（例如过驱动放大器）后接高速比较器来确定每个信号穿过零电压轴的时间。这在每个通道中产生一个触发脉冲，用于驱动双稳态触发器。双稳态触发器的输出是一个矩形波，其占空比与输入信号之间的相位差成正比。如果该信号通过适当的滤波器进行积分，就会产生一个直流电压，它是相位角的模拟表示。该电压随后在面板仪表（模拟或数字）上显示，并按度或弧度进行适当的刻度。采用此原理的仪器能够在广泛的振幅和频率范围内测量相位差，精度约为 $\pm 0.05^\circ$。参见**放大器**；**比较器**；**电子滤波器**；**多谐振荡器**；**开关电路**；**波形整形电路**。

传统相位计的频段上限为几百千赫。这一限制主要受由比较器和触发器组成的电路在高速运行条件下维持干净且精确的矩形波的能力所决定。为了在约 100 kHz 到数吉赫之间的频率下测量相位角，有必要将射频信号下变频到相位计能够正确处理 的频率。在微波频率下，槽线、空气线和矢量网络分析仪等仪器也用于相位角测量。参见**微波测量**。[J.Hu.]

# 相差显微镜

一种用于使透明或反射标本中的相位或光路差异可见的显微镜。它是研究活细胞最重要的仪器之一，并广泛应用于生物和医学研究。相差显微镜的基本特征在示意图中展示。实际问题在于找到某种方法将入射光（或直射光）与物体衍射的光分离开来。这是通过将具有易于识别形状（例如圆环）的光阑 `D` 置于物镜下聚光镜 `C` 的前焦点平面来实现的。来自焦点平面每个点的光以平行光束通过标本 `S`，并在物镜 `O` 的后焦点平面 `P` 处聚焦。因此，在移除光阑后，可以在物镜后看到圆环的像。该像对应入射光。此外，当存在标本时，部分光被其衍射并扩散以充满物镜的后透镜。因此，除了圆环像上的小重叠区域外，直射光和衍射光在平面 `P` 处基本上被分离。此时在该平面插入一块相位板。相位板可以是带有环形凹槽的透明圆盘，其尺寸恰好与光阑 `D` 的像重合。现在所有直射光都通过相位板中的凹槽，而衍射光主要穿过凹槽外部。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1659_2.png)

相差显微镜示意图。

由于衍射光必须穿过比直射光更厚的透明材料，因此会在两者之间引入相位差，该相位差取决于相位板材料的折射率和凹槽的厚度。如果这个相位差约为一个波长，则已经实现了相位对比的基本条件。如果相位板使入射波延迟四分之一波长，两列波的波峰和波谷将重合，产生振幅更大的合成波。折射细节将表现为亮色（负对比）而不是暗色（正对比）。

相差显微镜是检查活细胞的常规仪器，因为可以在优异的光学条件下研究细胞结构，且不会损失分辨力。该方法也适用于未染色组织切片的观察，并广泛用于电子显微镜和光学显微镜中材料的比较。参见电子显微镜；显微镜；光学显微镜。

[R. Ba.]

# 相平衡

物理化学的一个通用领域，研究两个或多个相（或聚集态）在热力学平衡中共存的各种情况，相之间的转变性质，以及温度和压力对这些平衡的影响。该主题的许多表面方面主要是定性的，例如相图类型的经验分类；但基本问题总是可以进行定量热力学处理，在许多情况下，统计热力学方法可以应用于简单的分子模型。

热力学要求，当两个相，`α` 和 `β`，可以自由交换热量、机械功和物质（化学物种）时，在平衡状态下，温度 `T`、压力 `P` 以及每个特定组分 `i` 的化学势（偏摩尔自由能）`μ_i` 在两个相中必须相等。代数上，当 `T_α = T_β`，`P_α = P_β`，且 `μ_i,α = μ_i,β` 时，存在平衡。

如果相之间的平衡受到抑制性限制，热、机械和物质平衡的条件不一定都成立。例如，对于非挥发性溶质与其溶质蒸气处于平衡的溶液，溶质化学势相等条件 `μ_1,α = μ_1,β` 不一定适用，因为蒸气相中不可能有溶质分子。类似地，在渗透平衡中，溶剂分子可以通过半透膜，而溶质分子不能，则 `μ_2,α = μ_2,β` 和 `T_1,α = T_2,β`，但溶质化学势 `μ_2,α` 和 `μ_2,β` 不相等，膜两侧的压力也不相等。参见渗透、溶液。

如果系统由 `P` 个相和 `C` 个可区分的组分组成，则有 `C + 2` 个热力学变量（`C` 个化学势 `μ_i`，加上温度和压力），它们通过每个相的方程相互关联。由于有 `P` 个独立方程联系 `C + 2` 个变量，只需固定 `F = C + 2 - P` 个变量即可完全定义系统在平衡状态下的状态，其余变量则通过控制确定。关于自由度 `F`，或变度，数的这个关系式称为相律。事实证明，它是解释和分类相平衡类型的有力工具。

当系统中可能发生化学变化时，组分数 `C` 是可以通过实验者改变数量的独立组分数；这等于存在的化学物种总数减去它们之间独立化学平衡的数目。

无变量系统没有自由度（`F=0`），此时相的数目为 `C+2`。对于单组分系统，这种无变量状态是三重点，在此处三个相在单一温度和压力下共存；对于双组分系统，四重点（四个相）将是无变量的。参见三重点。

(R. L. S.)

# 相位倒相器

主要功能是将信号相位改变 $180^\circ$ 的电路。相位倒相器最常用作推挽放大器的输入级。因此，相位倒相器必须提供两个幅度相等且相位差为 $180^\circ$ 的电压。相位倒相器有多种电路形式可用。参见推挽放大器。

相位倒相器和推挽放大器的整体保真度可能因相位倒相器的不当设计而受到不利影响。主要设计要求是推挽放大器一个输入通道的频率响应必须与另一个通道的频率响应相同。

最简单的相位倒相器电路形式是带有中心抽头副边的变压器。仔细设计变压器可确保副边电压相等。当倒相器必须向推挽放大器的输入提供功率时，变压器形成良好的倒相器。变压器倒相器有几个缺点。它通常成本更高，占用空间更大，重量也更重，且比晶体管电路更重。此外，必须找到某种方法来补偿变压器的频率响应，其响应可能不像固态电路所能获得的那样均匀。参见变压器。
