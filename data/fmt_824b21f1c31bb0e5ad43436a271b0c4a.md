## Internet 发布器

Internet 发布器将帮助你使用适当的 HTML 代码创建新文档。它还可以将现有文档转换为可用于 Web 的 HTML 格式。然而，你应该知道，如果你转换现有文档，HTML 不支持一些功能。其中包括列、下沉首字母、脚注、页码、制表符和缩进以及宏。有关不支持功能的完整列表，请参阅随个人版附带的 WordPerfect 用户指南第 281 页。

### 创建新的 Web 文档：

1. 从文件菜单中选择 Internet 发布器（图 1）。Internet 发布器窗口将打开（图 2）。
2. 单击新建 Web 文档。Web 编辑器将出现，并在编辑器窗口中打开一个空白文档，准备好让你创建 Web 页面（图 3）。

### 提示

Web 编辑器实际上是正常文档窗口的特殊版本，专门用于创建 Web 页面。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_225_0.png)
![](img/02dde5e0b11c4f9add393f2d6c89d9a5_225_1.png)
![](img/02dde5e0b11c4f9add393f2d6c89d9a5_225_2.png)

### 将现有文档转换为 Web 文档：

1. 打开你要转换的文档（图 4）。
2. 从文件菜单中选择 Internet 发布器（图 1）。Internet 发布器窗口将打开（图 2）。
3. 单击格式化为 Web 文档。Web 视图对话框将打开，提示你部分格式将会丢失（图 5）。
4. 单击是继续转换。文档将被转换为 Web 文档并出现在 Web 编辑器窗口中（图 6）。

### 提示

- WordPerfect 在执行转换时会尽可能保留文档的格式。然而，由于普通文档和 Web 文档是两种完全不同的东西，它们的外观会略有不同。
- 如果你决定最终不想将文档转换为 Web 格式，可以将其恢复到之前的形式。转换后立即单击 Web 编辑器窗口右上角的关闭按钮关闭文档。再次打开时，你会看到它已恢复到原始形式。

### 添加标题

创建新的Web文档并将普通文档转换为Web格式后，接下来要添加文本、图形和格式，使您的Web页面独具特色。

您要做的第一件事是为Web页面添加标题。标题会显示在Web浏览器的标题栏中。如果您不指定标题，WordPerfect会自动使用第一个标题。

#### 添加标题：

1. 从“格式”菜单中选择“标题”（图7）。将出现“标题”对话框（图8）。
2. 选择“自定义标题”单选按钮，然后在文本框中输入标题。标题不宜过长，只需能描述页面或您的Web站点即可。
3. 单击“确定”。“标题”对话框将关闭。当您使用浏览器查看Web页面时，将看到标题（图9）。

![](img/02dde5e0b11c4f9add393f2d6c89d9a5_227_0.png)
![](img/02dde5e0b11c4f9add393f2d6c89d9a5_227_1.png)
![](img/02dde5e0b11c4f9add393f2d6c89d9a5_227_2.png)

### 标题

Web页面使用特殊的标题样式。共有六个级别——标题1最大，标题6最小。图10显示了相对的标题大小。

#### 添加标题：

1. 单击属性栏上的“标题和段落样式”按钮（图11）。
2. 从下拉列表中选择您想要使用的标题大小。
3. 输入标题。
4. 按键盘上的Enter键结束标题。标题确实能吸引人们的注意（图12）。

### 提示

- 您也可以选择要格式化为标题的文本，然后按照步骤2-3操作。

### 输入和格式化文本

在Web文档中输入和格式化文本与普通WordPerfect文档相同。您此前在本书中学到的所有技能都可以在这里应用。文本格式可分为两类：字符级格式和段落级格式。

#### 添加文本：

将插入点放置在要添加文本的位置，然后输入文本（图13）。

### 提示

- 当您按Enter开始新段落时，段落之间会插入一个双倍行距的行。
- 如果您想开始新行而不开始新段落，请从“插入”菜单中选择“换行符”（图14）。

#### 编辑文本：

选择要更改的文本，然后输入替换文本（图15）。所选文本将被删除，替换文本将取代其位置。

#### 删除文本：

选择要删除的文本，然后按键盘上的退格键或Delete键。

### 段落格式

就像普通的 WordPerfect 文档一样，网页文档中的段落格式会影响整段文本。一些段落格式包括对齐、项目符号和编号列表，以及双重缩进。

#### 对齐段落文本：

1. 选择要对齐的文本。
2. 在属性栏上单击对齐按钮，从下拉列表中选择一种对齐方式（图 23）。
