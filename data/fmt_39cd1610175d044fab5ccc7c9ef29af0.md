## 总结

本节为你提供了基于 GUI 的 RedHat 系统的快速步骤安装。使用 RedHat 是因为它是主地位的 Linux 发行版。

市场。

- 你需要做的第一件事是有一个经过充分考虑的计划和设计，以便将硬件与你的需求匹配。
- 你需要确保你拥有兼容的硬件，以及适合 Web 服务器任务的硬件——最好是多个 CPU、大量的内存（RAM），以及一个具有大量磁盘空间且极快速的磁盘 I/O 子系统。
- 你需要理解英特尔 PC 主板的分区概念、IDE 硬盘 16 个分区的限制，以及 SCSI 硬盘 15 个分区的限制。
- 你需要意识到，将文件系统划分为较小的、易于管理的部分对于大多数 Linux 和 UNIX 版本都是良好且符合预期的。
- 系统的关键分区包括 `/`、`/usr`、`/var`、`/home`、`/usr`、`/opt` 和 `swap` 等，仅列举几个。
- 你将看到的安装选项可能允许你保留当前的操作系统并与其进行双启动，某些选项可能会擦除任何其他操作系统分区。
- 要安装的软件包非常多，应该只安装必要的包。
- 你应该在安装结束时创建启动盘。
- 你不应该将此数据库服务器兼作用户工作站；为了获得最佳性能，它应该专用于数据库服务。
- 系统管理工具在 Linux 和 UNIX 之间差异很大；请随身提供的书籍。
- 强烈建议你找一个具有以前 Linux 或 UNIX 系统管理经验的人，因为 Windows 系统管理技能并不容易迁移。

**注意**：请注意，除非你使用 RedHat 的衍生版（如漫红 Linux或 SuSE），否则基于文本的安装是菜单驱动的。如果需要，RedHat 衍生版也提供该功能。

如果你既没有 UNIX 也没有 Linux 经验，你将会在硬件、软件、接口方面探索一个全新的世界。尽管进去尝试吧，但请使用测试机。

# 常见问题

- Q：我有一个非常旧的硬盘，我应该用它吗？
A：*不*，在很多情况下，旧硬盘不使用主板的高级 IO 功能，会显著减慢你的机器速度。

- Q：我听说可以在 Windows 上运行 Linux；这是真的吗？
A：是的，有一个名为 `VMware` (`www.vmware.com`) 的非常智能的产品，允许你使用几乎任何操作系统（如 NT 或 Linux）作为主机 OS，在其中你可以安装一个或多个虚拟操作系统（如 Win9x、NT 和 Linux）。本手册中使用的截图是在一台 NT 4.0 机器上安装 Linux 时获得的，当时所有驱动器已格式化为 FAT 和 NTFS。`VMware` 在一个 FAT 卷上创建一个虚拟磁盘，该卷恰好有 1.8GB 空闲空间。RedHat Linux 的完整安装创建了模拟分区（如前文如图所示），使用了 1.3GB 的 FAT 分区（可能是压缩格式）作为虚拟磁盘。注意：推荐硬件至少是 266 MHz 的 PC 配配 96MB RAM，而且和所有建议一样，这是很低的。如果可以，获取更多的内存和更多的动力，或者准备好在安装的泥潭中缓慢进行（在 166 MHz、64MB RAM 的机器上需要 16 小时）。

- Q：为什么选择 RedHat？
A：因为它是最为人知的；有完整的支持服务、培训服务和大量的书籍；它是市场领导者，而且它是免费的。

- Q：支持重要吗？
A：这取决于情况。如果你有支持人员，你付钱让他们做什么？你可以为某些支持组织支付费用，也可以花同样的费用提升你员工的技能。

- Q：如果我从未见过 UNIX 怎样？
A：那又怎样？互联网的 90% 以上是基于 UNIX 的，到目前为止这并不是什么糟糕的经历。电影《玩具总动员》完全是在 UNIX 机器上用生成的。电影《泰坦尼克号》在 Alpha CPU 服务器上的 Linux 渲染了所有的特效。UNIX 无处不在——它不像竞争对手那样向 PC 世界进行大众营销。

- Q：我听说安装界面非常丑！这是真的吗？
A：对于获得一台配置好即用机器的普通 PC 用户来说，是的，你必须稍微研究一下。但有了目前 Linux 的 GUI 安装程序，你应该能够摸索着完成基础安装并使其运行，而没有太大麻烦。如果不是，找一个尝试过或想尝试的人，让他们先来做。请求帮助可能很困难，但那里有很多学生和失业者正急于展示他们的才华。
