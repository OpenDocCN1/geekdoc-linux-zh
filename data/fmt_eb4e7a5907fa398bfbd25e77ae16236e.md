
```
libs_for_gcc = -lgnu
normal_libs =
ifeq ($(CC),gcc)
libs=$$(libs_for_gcc)
else
libs=$$(normal_libs)
endif
```

```
foo: $(objects)
$(CC) -o foo $(objects) $(libs)
```

### 7.2 条件语句的语法

没有 `else` 的简单条件语句语法如下：

```
conditional-directive
text-if-true
endif
```

`text-if-true` 可以是任意文本，如果条件为真，则被视为 Makefile 的一部分。如果条件为假，则不使用该文本。

复杂条件语句的语法如下：

```
conditional-directive
text-if-true
else
text-if-false
endif
```

如果条件为真，使用 `text-if-true`；否则，使用 `text-if-false`。`text-if-false` 可以是任意行的文本。

无论条件是简单还是复杂，条件指令的语法都是相同的。这里有四种不同的指令可以测试不同的条件。以下是它们的表格：

| 指令 | 说明 |
| :--- | :--- |
| `ifeq (arg1,arg2)` | 展开 `arg1` 和 `arg2` 中的所有变量引用并进行比较。如果它们相同，则执行 `text-if-true`；否则，执行 `text-if-false`（如果有的话）。 |
| `ifneq (arg1,arg2)` | 展开 `arg1` 和 `arg2` 中的所有变量引用并进行比较。如果它们不同，则执行 `text-if-true`；否则，执行 `text-if-false`（如果有的话）。 |
| `ifndef variable-name` | 如果 `variable-name` 有非空值，则执行 `text-if-true`；否则，执行 `text-if-false`（如果有的话）。从未定义的变量值为空。 |
| `ifdef variable-name` | `ifdef` 测试变量是否有值。它不会展开变量来检查该值是否非空。因此，使用 `ifdef` 的测试对于所有像 `foo =` 这样的定义都返回真。 |

注意，`ifdef` 测试变量是否有值。它不会展开变量来检查该值是否非空。因此，使用 `ifdef` 的测试对于所有像 `foo =` 这样的定义都返回真。要测试空值，使用 `ifeq ($(foo),)`。例如：

```
bar =
foo = $(bar)
ifdef foo
frozz = yes
else
frozz = no
endif
```

将 `frozz` 设置为 'yes'，而：

```
foo =
ifdef foo
frozz = yes
else
frozz = no
```

将 `frozz` 设置为 'no'。

`ifndef variable-name`

如果 `variable-name` 有空值，则执行 `text-if-true`；否则，执行 `text-if-false`（如果有的话）。在指令行的开头允许额外的空格，但不允许使用制表符。（如果行以制表符开头，它被视为规则的命令。）在此之外，在指令名或参数内部插入额外的空格或制表符不会产生影响。以 '#' 开头的注释可能出现在行的末尾。

测试其他条件的指令是 `else` 和 `endif`。`endif` 指令结束条件语句。每个条件语句必须以 `endif` 结束。之后是无条件的 Makefile 文本。

如示例所示，条件语句是在文本层面工作的：条件语句的行根据条件被视为 Makefile 的一部分或被忽略。这就是为什么 Makefile 中较大的语法单元（如规则）可能会跨越条件语句的开始或结束。

当变量 `CC` 的值为 'gcc' 时，上述产生产生效果：

```
foo: $(objects)
  $(CC) -o foo $(objects) $(libs_for_gcc)
```

当变量 `CC` 为任何其他值时，效果如下：

```
foo: $(objects)
$(CC) -o foo $(objects) $(normal_libs)
```

通过对变量赋值进行条件化然后无条件使用，可以用另一种方式获得等的结果：

```
libs_for_gcc = -lgnu
normal_libs =
ifeq ($(CC),gcc)
libs=$$(libs_for_gcc)
else
libs=$$(normal_libs)
endif
```

```
foo: $(objects)
$(CC) -o foo $(objects) $(libs)
```

通常你可能想要测试一个变量是否具有非空值。当值是由变量和函数的复杂展开产生时，你认为为空的展开实际上可能包含空白字符，因此不被视为为空。然而，你可以使用 `strip` 函数（见第 76 页第 8.2 [文本函数]）来避免将空白字符解释为非空值。例如：

```
ifeq ($(strip $(foo)),)
text-empty
endif
```

如果 `$(foo)` 的展开为空，将求值为 `text-empty`。

## 第 8 章：文本转换函数

# 8 文本转换函数

函数允许你在 Makefile 中进行文本处理，以计算要操作的文件或要使用的命令。你在调用中使用函数时，给出函数名称以及供函数操作的文本（参数）。函数处理的结果将替换到调用处的 Makefile 中，就像变量一样。

### 8.1 函数调用

函数调用类似于变量引用。它看起来如下：

```
$(function arguments)
```

或者看起来如下：

```
${function arguments}
```

这里 `function` 是函数名；是 make 的一部分短名称列表。你也可以通过使用 `call` 内置函数来创建自己的函数。
