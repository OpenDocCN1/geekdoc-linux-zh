# tty — 返回用户的终端名称

### 概要
`/usr/bin/tty [-l][-s]`

## 描述
`tty` 命令写入作为标准输入打开的终端的标准输出名称。所使用的名称等同于 `ttyname(3)` 函数返回的字符串。

## 选项
- `-l` 如果用户的终端连接到活跃的同步行上，则打印该同步行的行号。
- `-s` 抑制终端路径名的打印；允许你仅测试退出状态。它不依赖于形成有效路径名的能力。

## 示例
以下示例显示了从两个单独终端窗口执行 `tty` 命令的输出。

```
castle% tty
/dev/pts/4
castle% tty
/dev/pts/5
castle%
```

## 环境变量
参阅 `environ(5)` 获取以下影响 `tty` 执行的环境变量的描述：`LC_CTYPE`, `LC_MESSAGES` 和 `NLSPATH`。

## 退出状态

| 值 | 描述 |
|---|---|
| 0 | 标准输入是终端。 |
| 1 | 标准输入不是终端。 |
| >1 | 发生错误。 |

参阅 `attributes(5)` 获取以下属性的描述：

| 属性类型 | 属性值 |
|---|---|
| 可用性 CSI | SUNWcu Enabled |

### 另请
`isatty(3)`, `tname(3)`, `attributes(5)`, `environ(5)`

## 诊断
不在活跃同步行上：
标准输入不是同步终端，且你指定了 `-l`。
不是 tty：
标准输入不是终端，且你没有指定 `-s`。

# type — 写命令类型的描述

### 概要
```
/usr/bin/type name...
```

## 描述
`type` 命令指示每个操作数在用作命令时如何被解释。`type` 显示有关每个操作数的信息，将操作数识别为 shell内置、函数、别名、哈希命令或关键字，并在适用时显示操作数的路径名。shell 内置版本的 `type` 与 `type` 命令类似。

### 操作数
`name` 一个要被解释的名称。

# typeset, whence — 获取/设置 shell 变量和函数属性及值的内置命令

### 概要
```
typeset [+ HLRZfilrtux[n]] [name=value]...
whence [-pv] name...
```

## 描述
`typeset` 内置命令为 shell 变量和函数设置属性和值。当你在函数内部调用 `typeset` 时会创建一个变量名的新实例。当函数完成时，变量的值和类型将恢复。你可以指定以下属性：
- `-f` 指定名称指向函数名而非变量名。不能进行赋值，`-t`, `-u` 和 `-x`。`-t` 选项仅在对此函数的执行跟踪时有效。`-u` 选项标记此函数为未定义。指定 `FPATH` 变量在引用时查找函数定义。`-x` 选项允许函数定义在通过名称调用的 shell 过程中保持有效。
- `-H` 在非 UNIX 系统上提供 UNIX 到主机的文件映射。
- `-i` 指定参数为整数以加快算术运算。如果 `n` 不零，则定义输出算术基；否则，使用第一次赋值来确定输出基。
- `-l` 将所有大写字符转换为小写。关闭 `-u` 选项。
- `-L` 值左对齐并移除前导空格。如果 `n` 不零，则定义字段宽度；否则，使用第一次赋值的宽度来确定其值。当变量赋值时，会在右侧用空格填充，或在必要时截断以适应字段。如果指定了 `-z` 选项，则移除前导零。`-R` 选项被关闭。
- `-r` 将指定的名称标记为只读。不能通过后续赋值更改这些名称。
- `-R` 右对齐并用前导空格填充。如果 `n` 不零，则定义字段宽度；否则，通过第一次赋值的值的宽度确定。如果变量被重新赋值，字段在左侧用空格填充或从末尾截断。`-L` 选项被关闭。
- `-t` 给变量标记标签。标签由用户定义。
- `-u` 将所有小写转换为大写。关闭 `-l`。
- `-x` 标记指定的名称为导出。
- `-Z` 右对齐并用前导空格填充。如果 `n` 不零，则定义字段宽度；否则，通过第一次赋值的值的宽度确定。`-L` 选项被关闭。

## 描述
`typeset` 内置命令为变量设置属性和值。
对于每个名称，`whence` 指示它如何被解释为命令。
- `-p` 产生详细报告。
- `-v` 即使名称是别名、函数或保留字也进行搜索。

# ul — 在终端显示中下划线文本

### 概要
`/usr/bin/ul [-i][-t terminal][filename...]`

## 描述
`ul` 读取文件名，如果未指定文件名，则读取标准输入，并使用环境变量 `TERM` 确定如何将下划线转换为指示你的终端显示下划线的序列。`ul` 使用 `/usr/share/lib/terminfo` 条目来确定合适的下划线方式。如果终端不支持下划线但支持突出显示模式，`standout mode`，则改用该模式。如果终端可以重叠或自动处理下划线，`ul` 将退化为 `cat(1)`。如果终端无法下划线，则忽略下划线。

### 缺陷
`nroff` 通常会生成一系列与文本混合的退格符和下划线来表示下划线。`ul` 尝试优化后退移动。

## 选项
- `-i` 使用包含适当横线（-）的单独行来指示下划线；当你想查看在 CRT 终端上 `nroff(1)` 输出流中存在的下划线时，此选项非常有用。
- `-t terminal` 覆盖环境变量中指定的终端类型。如果终端无法下划线，则忽略下划线。如果找不到终端名称，则执行下划线。

## 退出状态
如果找不到指定的文件，`ul` 返回退出代码 1。

## 文件
`/usr/share/lib/terminfo/*`

## 属性
参见 `attributes(5)` 获取以下属性的描述：

| 属性类型 | 属性值 |
| --- | --- |
| 可用性 | SUNwdoc |

## 参见
`cat(1)`, `man(1)`, `nroff(1)`, `attributes(5)`

# umask — 获取或设置文件创建掩码

### 概要
```
/usr/bin/umask [-S][mask]
sh, csh
umask [ooo]
ksh
umask [-S][mask]
```

## 描述
当你创建一个文件或目录时，分配给文件或目录的默认权限由用户掩码控制。你可以在如 `/etc/profile` 或 `.bashrc` 等用户初始化文件中通过 `umask` 命令设置用户掩码。通过输入 `umask` 并按回车可以显示用户掩码的当前值。
你使用三位八进制值，例如 `022` 来设置用户掩码。第一位设置用户权限，第二位设置组权限，第三位设置其他权限。要将 `umask` 设置为 `022`，输入：

```
umask 022
```
