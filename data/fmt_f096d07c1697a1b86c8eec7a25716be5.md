
## KLimit

### Examples
```
<Printer name>
...
KLimit 1234
</Printer>
```

### Description
`KLimit` 指令定义了 `job-k` 属性的值。该指令必须出现在 `Printer` 或 `DefaultPrinter` 定义内部。

## State

### Examples
```
<Printer foo>
...
State idle
</Printer>

<Printer bar>
...
State stopped
</Printer>
```

### Description
`State` 指令定义了 `printer-state` 属性的初始值。字符串 `idle` 和 `stopped` 对应于 IPP 枚举值。该指令必须出现在 `Printer` 或 `DefaultPrinter` 定义内部。
