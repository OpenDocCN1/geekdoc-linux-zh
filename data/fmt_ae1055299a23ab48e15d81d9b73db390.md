
# 录 E：术语表

### .shrc 文件
当你登录系统时，C shell 会检测此文件，并设置你登录时使用的变量和别名（`aliases`）。

### 守护进程 (daemon)
一个在后台运行并执行功能且不锁定到终端的进程。如果发生错误，输出将记录在系统消息或日志文件中，并显示在控制台上。

### 设备 (device)
A 是一种简单的外围设备。它可以是磁盘驱动器、打印机、终端、网卡或任何通过内部或外部连接到计算机的 IO 单元。

### 设备驱动程序 (device driver)
这些通常内置在 UNIX 内核中，用于控制磁盘驱动器、平板电脑或终端等设备。

### 设备文件 (device file)
所有连接到计算机的设备都通过位于 `/dev` 目录下的实际设备文件进行访问。设备文件有时也被特殊文件。

### 目录 (directory)
在 UNIX 中，目录实际上是目录文件的缩写。它是一个包含其他文件和目录文件的文件。

### 磁盘分区 (disk partition)
当一个磁盘被分成若干部分时，这被称为分区。这通常是为了平衡磁盘上 IO 操作的访问时间。它可以防止所有数据被完全损坏。如果磁盘上的某个分区失败，可以在磁盘的其余部分挽救数据。

### 虚假文件 (dummy files)
这些文件除了测试外没有任何实际作用。通过创建大型虚假文件并测试磁盘驱动器上的 IO 吞吐量来创建突发系统。小型虚假文件用于测试网络、发送邮件和打印。

### 编辑器 (editor)
一用于创建和修改文本文件的实用程序或工具。`vi` 和 `ed` 编辑器属于 UNIX 系统。许多 UNIX 系统自带其他编辑器，在互联网上也可以找到许多不同的编辑器。

### 环境 (environment)
每个登录系统的用户都有一个环境，该环境会被命令处理器引用并提供。在环境中，它是你访问的所有变量及其在每种情况下的取值的列表。

### EOF
文件结束符（End of file）。

### 退出状态 (exit status)
进程返回的状态；要么成功（通常为 `0`），要么不成功（通常为 `1`）。这些值可以传递给变量，在 shell 脚本中非常有用。

### 文件扩展名 (filename extensions)
这是文件名末尾点号之后的部分。有许多类型，而且似乎每周都会有新类型。包括 `.uu`、`.tar`、`.gz` 和 `Z`。

### 文件系统 (filesystem)
一种存储在磁盘上的数据结构。所有 UNIX 系统都有一个根文件系统，根据系统配置和磁盘空间大小至少还有几个其他文件系统。每个文件系统由三部分组成：包含文件系统信息的超级块（`superblock`）、包含单个文件信息的索引节点（`inodes`）以及存储文件中所有信息的数据块（`data blocks`）。

### 标志 (flag)
指向参数的信号，标志表示执行命令时要执行的特定选项或修改。在许多情况下，标志以连字符开头。

### 前台 (foreground)
当后台任务未附加到终端时，前台必须在终端的直接控制下运行。在此期间，在前台作业完成或挂起之前，终端无法用于其他操作。可以使用命令 `Ctrl-Z` 随后在 shell 提示符处输入 `bg`（后台）将前台作业置于后台。

### 派生 (fork)
当一个进程创建另一个进程时使用的术语。这也称为派生进程（spawning a process）。

### GECOS 字段
密码文件中的第五个字段。这通常被称为注释字段。GECOS 字段包含了用户的所有联系信息：姓名、电话和任何其他识别信息。

### 图形控制台 (graphic consoles)
这些是支持窗口环境且物理上仍连接到本地 CPU 的控制台。一个用户可以显示多个窗口来监控发送到控制台的错误消息。图形控制台上的其他窗口可用于执行日常任务。

### 组 (group)
指用户集合。组的建立是确定用户之间文件访问权限的基础。如果你不是文件的所有者且属于它分配的组，你就可以被授予访问该文件的权限。在 BSD 系统上，用户可以同时属于多个组。在 AT&T 系统上，每个用户只能属于一组，但可以使用 `newgrp` 命令进行更改。

### 组 ID (group ID)
`/etc/passwd` 第四个字段中的此数字直接与 `/etc/group` 中的数字相关。如果这个数字没有名称，则存在安全风险，必须在 `/etc/group` 中定义。

### 历史记录 (history)
记录用户执行过的命令。

### 主目录 (home)
每个登录系统的用户都有一个被引用并提供给命令处理器的环境。在环境中，它是你访问的所有变量及其在每种情况下的取值的列表。

### 登录文件 (login)
登录时 C shell 执行的主目录下的此文件。它提供了每次登录时运行的命令。

### 登录名 (login name)
用户的唯一标识符，即用户 ID。登录名是 `/etc/passwd` 中的第一个字段。

### 登录 shell (login shell)
你登录时使用的 shell。登录 shell 可以派生其他进程。

### 注销文件 (logout file)
当你注销时，C shell 执行你主目录下的此文件。你可以在此文件中放入每次注销时运行的命令。

### 宏 (macro)
程序替换几条更复杂指令的单条指令。这可以在 `vi` 中设置，以便在尝试节省时间时生效。

### 映射 (map)
这为终端键分配新的解释。这在 `vi` 编辑器中使用。

### 多任务处理 (multitasking)
UNIX 能够同时运行多个复杂的应用程序、程序和其他进程。

### 多用户 (multi)
使用 UNIX 的两个大原因之一是每台机器可以处理的用户数。UNIX 服务器可以处理数千个用户。多任务处理是另一个大原因。

### NFS
一种在网络上和本地系统中可见的像本地挂载设备一样的远程文件系统。

### 网络 (network)
多个系统通过局域网（LAN）或广域网（WAN）进行互连、连接。

### 空设备 (null device)
这是 `/dev/null` 中的一个特殊文件。任何发送到它的内容都会被丢弃。你可以将文件复制到这里或重定向输出；如果你正在创建大文件，可以将符号链接指向它。

### OSI
开放系统连接。这是一个显示数据如何在网络中移动的模型，它由七层组成，跨越：应用层、表示层、会话层、传输层、网络层、链路层和物理层。

### 外围设备 (peripheral device)
参见设备。进程标识。通常后面跟着一个数字。当新进程启动时，操作系统会分配一个。

用于处理的唯一 PID 号。

### 管道 (pipe)
管道是两个程序之间的连接，其是将第一个程序的标准输出（`STDOUT`）发送到下一个程序的标准输入（`STDIN`）。

### 强力工具 (power tools)
对强大的脚本、程序和实用实用程序的泛指，这些工具通常由 UNIX 管理员编写，并且在很大程度上可以在互联网上免费获取。

### 配置文件 (profile)
此文件用于为 Korn 和 Bourne shell 运行命令、设置变量并定义函数。

### 递归 (recursive)
当涉及目录结构时，指遍历该结构。

### 重定向 (redirection)
将标准输入、输出或错误重定向到文件或其他设备。

### 根目录 (root)
目录结构中的顶层目录。

### 根文件系统 (root filesystem)
位于根目录下的文件系统。它由 UNIX 管理员编写，且大多数情况下可以在互联网上找到。

### root 登录 (root login)
具有特殊权限的超级用户登录过程。

### 运行 (run)
执行程序的过程。

### shell (shell)
命令行解释器，用于用户与操作系统之间的交互。

### 脚本 (script)
包含一组要执行的命令的文件。

### 单用户模式 (single-user)
系统仅允许一个用户登录的模式。

### 软链接 (soft link)
指向另一个文件路径的目录项。

### 标准错误 (STDERR)
用于输出错误信息的标准通道。

### 标准输入 (STDIN)
程序接收输入数据的标准通道。

### 标准输出 (STDOUT)
程序输出结果的标准通道。

### 启动文件 (startup file)
shell 登录时运行的文件。

### 字符串 (string)
字符的序列。

### 子目录 (subdirectory)
位于另一个目录内部的目录。

### 超级块 (superblock)
包含文件系统控制信息的块。

### 超级用户 (superuser)
具有最高权限的用户，即 root。

### 交换 (swap)
操作系统在内存和磁盘之间移动进程的过程。

### 系统管理员 (system administrator)
负责系统日常运行和维护的人员。

### 系统控制台 (system console)
系统的物理终端。

### System V
UNIX 系统的两个主要版本之一，是 AT&T 的产品。
