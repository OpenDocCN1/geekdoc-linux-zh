
`tclex` 是一个词法分析器（lexer analyzer）生成器扩展。它的灵感来自 Unix 和 GNU `flex`，这些是用于生成执行模式匹配程序的工具。`tclex` 与这些程序非常相似，它使用 `Tcl` 的哲学和语法，而其他工具使用自己的语法并与 C 语言结合。使用 `flex` 或 `lex` 的人会对 `tclex` 感到。`tclex` 和 `Tcl` 库一样小。Windows 版本超过 20kb，大小约为 150kb，因为它大量使用了它。然而，当前版本不再使用现在包含在 `Tcl` 中的 `regexp`，这使其略微变大（几 kb）。`tclex` 应该兼容 `Tk` 8.0 及更高版本，`tclex` 永远不会与旧版本兼容，因为它使用了 `Tcl` 8.0 的对象系统来实现性能。跨平台性能卓越，得益于 `Tk`。它在 Windows 上开发并在 Unix 上运行，只要平台上存在 `Tcl`，它就应该在所有平台上运行。支持的 `Tcl` 平台包括 Windows 95/NT、Unix (Linux, Solaris...) 和 Macintosh。所有平台都是虚拟机，不像 `flex` 和 `flex`，它们只动态生成可以在 `Tcl` 脚本或程序中像其他命令或 `Tcl` 过程一样使用的 `Tcl` 命令。*它使用 `Tcl` 正则表达式。这意味着你不需要学习另一种正则。*它与 `Tcl` 命名空间工作 * 生成的词法分析命令可以一次或多次增量地使用，因为它们维护了状态信息。然而，同一个词法分析器的多个实例（例如 HTML 解析器）可以同时冲突运行并维护独立的状态（局部变量...）。词法器并不是专门设计为顺序增量地使用的，同一个词法器可以一次或增量传递。此功能在处理来自文件或 Internet 套接字的文本（例如网页）时特别有用。

## telllib

标准 `Tcl` Telllib 库（`Tcl` 库）是工具函数和模块的集合。包含内容：

- `base64`: 一个 base64 编码器和解码器
- `calendar`: 用于处理日期
- `cmdline`: 类似于 opt 的命令行参数处理
- `comm`: 通信设施
- `control`: 用于流结构的程序
- `counter`: 提供计数器功能，并对收集到的数据计算统计信息和直方图
- `crc`: 校验和计算程序 (`crc32`, `cksum`, `csum`)
- `vs`: csv 的处理程序
- `fileutil`: 某些 Unix 工具的 `Tcl` 实现
- `ftp`: FTP 协议的 `Tcl` 接口
- `ftpd`: FTP 服务器所需的函数实现
- `http`: 解析和控制 HTML 标签
- `interp`: HTML 字符串处理
- `javascript`: 用于缩短常用 javascript 函数的脚本
- `logs`: 使用各种设施记录消息的函数
- `common functions`: 如 min, max 等常用函数
- `md5`: 哈希函数
- `mime`: MIME 编码器
- `ncg`: CGI 处理模块：用于 NTP 协议
- `pop3`: pop3 实现
- `function`: `Tcl` 源代码本身：用于生成和格式化报告的对象
- `sha`: 哈希函数
- `smtp`: SMTP 服务器所需的函数实现
- `stats`: 用于计数器、直方图和统计
- `stoop`: 仅限 `Tcl` 的面向对象编程方案
- `C++/Java-like OOP interfaces`: 类的面向对象接口
- `struct`: 常用数据结构（树、图等）的 `Tcl` 实现
- `text`: 字符串处理库
- `uri`: 用于生成和操作常用的 URI。来自 Debian 3.0r0 `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
