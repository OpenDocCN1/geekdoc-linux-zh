> **重掷 (`The re-roll`)**
在这里我们开始第二次掷骰子，使用长循环 `if` 语句。

```python
def roll(number):
    numbers = range(1,7)
    dice = [0] * number
    iterations = 0
    while iterations < number:
        iterations += 1
        dice[iterations-1] = random.choice(numbers)
    return dice

result = roll()
print("You finish with,", result)
```
