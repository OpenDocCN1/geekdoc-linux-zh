# 调幅广播

中频段的`AM`（调幅调制）广播电台使用载波的幅度调制来传输信息。波的幅度被修改以表示音频波振幅的变化。`AM`接收机将这些变化转换回音频信号，然后可以在换能器或扬声器上进行放大和还原。

音频频率范围通常限制在`20`到`20 kHz`之间。因此，`AM`传输限制在`50`到`10 kHz`的范围内。由于语音成分的保真度受限，音乐的保真度进一步受到严重限制，尽管仍然可行，但`AM`广播受到了限制。

`AM`电台可能使用单座塔作为天线进行全向辐射；或使用两座塔向特定方向进行辐射，如定向天线。天线的限制在白天和夜间之间可能不同，许多天线的差异以`1 km`（`0.62`英里）处的每米英里表示。参阅天线（电子学）。

`AM`广播通过沿地面（边界）传输的波以及穿过地球和大气的波从发射器传播。地波的质量因为电流流动而降低。在夜间，天线还会产生通过大气层传输到接收器的波。空间传播受地球曲率的影响。当波指向地平线或被大气层反射回地球时，空间波就会传播。

# `FM`广播

`FM` `VHF`频段，`FM`（调频调制）广播成为美国主要的广播服务，是因为其高保真度和其频谱，该频谱比`AM`频率不易受到噪声和干扰的影响。`FM`通过载波的频率调制或偏置进行调制。在美国，载波频率可以在载波频率周围偏移`±75 kHz`。在美国，频率（或通道）间隔为`200 kHz`；其他少数国家使用略有不同的通道间隔。所有`FM`电台都是陆式的。

`FM`电台的服务区域取决于从发射器到接收器的波传播。空间波通过大气传播，并在山脉、建筑和其他物体上折射和产生角度。当发射器和接收器之间存在无阻挡的视线时，就会发生传播且更加可靠。

# 短波广播

为了接触大洲或遥远地区的听众，经常使用短波接收机。全球范围内有`6`亿台短波接收机在`5950`到`2600 kHz`的频段内进行广播。分配的发射频率在用于音频广播的有限频带内以`5 kHz`的间隔分布。

短波通过空间波传播，这些波在电离层的`E`层和`F`层反射一次或多次。多次反射是可能的，因为信号在电离层反射后也可以从地球表面反射：欧洲已建立了一种数字广播服务，特别是在`1452–1492 kHz`频段。数字`FM`电台位于高处（山顶、屋顶），提供通往目标接收器的视线。信号与模拟信号的区别在于，音频信号（语音或音乐）首先转换为表示信号的数字位（二进制数据）。这些数字位随后被转换为无线频载波并通过波传输。无线频载波在接收机处被解调以恢复数据位，然后这些位转换回音频。高质量和高保真度允许使用数字信号中的纠错代码消除传输过程中发生的许多故障。

# 无线频率阻抗测量

无线频率下的阻抗测量很难实现。在电气背景下，阻抗被定义为电压与电流的比值（或电场与磁强的比值），以欧姆为单位测量。

然而，在低频率下，当电压由直流驱动时，电压和电流都是实数。它们的比值——电阻是一个（实）数。然而，在无线频率下，电压与电流同相位，因此用复数表示。为了区分射频电阻的标量与矢量，使用“阻抗”一词表示电压与电流的复数比值。交流电；直流；电阻。

# `180`无线寻址系统

变压器电桥能够工作高达`100 MHz`。使用变压器具有以下优点：`1`需要两个臂式电桥，即标准型；`2`源和检测器的末端均可接地，从而最大限度地减少地环路问题和泄漏。

电容桥用于`20 MHz`至`15 MHz`之间。电流从公共节点流向三个并联支路，并由三个电极采样，这些电极是静电成型型环路，其输出并联连接。

与阻抗（电压）反射系数相关的物理量，定义为当传输线不匹配时，反射电压与入射电压之比。通常用`$\Gamma$`或`$\rho$`表示反射系数。当阻抗为`$Z_0$`的传输线被阻抗为`$Z_L$`的负载终止时，驻波比（`VSWR`）与`$\Gamma$`的关系如下：

$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

$$VSWR = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

参见 传输线（`TRANSMISSION LINES`）。

当只需测量驻波比时，可以使用电阻电桥。作为不匹配源和检测器的电阻电桥与惠斯石桥不同，惠斯石桥的目标是使用零阻抗源和无限阻抗检测器。

某些专用仪器利用阻抗的定义，并有效地测量电压和电流。使用电桥法。通过同时测量电压和电流，它驱动未知阻抗产生产生恒定电流，并测量出电阻。

矢量电压计（`VIM`）是带有高阻抗电压计的仪器，它们探测每个点（相对于地）的电压以及点与点之间的相位差。它们通过寻址工作于从`20 kHz`到第一个中频的频率。

当在给定频率下，阻抗无性部分的幅度远大于电阻部分时，使用电抗计。为此目的最常用的仪器是`Q`表计。

# 无线接收机

无线通信系统中从天线接收的无线射频（`rf`）中提取信息的部分。无线接收机是最常见的电子设备，也是所有寻址系统的关键部分。尽管外差差接收机性能良好，但也出现过剧性故障。过去，无线接收机由模拟电路构建，现在由数字电路实现。参见 接收机（`Receiver`）。

天线拦截射频范围内的一段能量，该能量包含许多频率。寻址系统使用幅度调制（`AM`）或频率调制（`FM`）。信号幅度在一个很大的范围内，从几伏到微伏的分之一不等。接收机必须具有选择性，解调信号，放大来自无线波的刻印信息并将其输出。

单边带（`SSB`）系统用于仅传输一个侧带并排除载波。单边带具有重要意义，因为它节省了电磁频谱。数字调制系统也越来越重要。
