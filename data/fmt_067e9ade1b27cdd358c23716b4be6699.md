```
!more
```

```
!!
```

### 在需要时成为 root

常识认为你不应该通常以 root 登录。当你是 root 时，你可以很容易删除所有文件，特别是当你在输入命令时。例如，你可能会输入 `rm *.html` 命令来删除所有扩展名为 `.html` 的文件。如果你不小心在星号 (`*`) 后按了空格键怎么办？shell 会将命令解释为 `rm *.` —— 因为 `*` 匹配任何文件名 —— 删除当前目录下的所有内容。
