# Linux 文档项目

“宣言”

最后修订日期：1998 年 9 月 21 日，修订人：`Michael K. Johnson`

本文件描述了 Linux 文档项目的目标和当前状态，包括项目名称、志愿者、FTP 站点等。

## 概述

Linux 文档项目正致力于为 Linux 操作系统开发优质、可靠的文档。LDP 的总体目标是协作处理所有 Linux 文档相关问题，范围从在线文档（`man` 页面、`texinfo` 文档）到涵盖安装、使用和运行 Linux 等主题的打印手册。LDP 本质上是一个松散的志愿者团队，几乎没有中央化组织；欢迎任何感兴趣帮助的人加入。我们认为，共同工作并对 Linux 文档的方向和范围达成共识是解决问题的最佳方式，以减少重复劳动导致的问题——如果两个人针对 Linux 的同一个方面编写两本书将完全浪费双方的时间。

LDP 旨在制作 Linux 官方的在线和打印文档集。由于我们的文档是免费提供的（类似于根据 `GNU GPL` 许可的软件）并在网上分发，我们能够轻松更新文档，以跟上 Linux 世界许多变化。如果您兴趣发布任何 LDP 作品，请参见下文“发布 LDP 手册”章节。

LDP 作品可以在 `metalab.unc.edu` 的 `/pub/Linux/docs` 目录下找到。LDP 手册位于 `/pub/Linux/docs/LDP`，HOWTO 及其他文档位于 `/pub/Linux/docs/HOWTO`。

## 文档规范

以下是 LDP 手册目前使用的规范。如果您有兴趣使用不同的规范编写另一本手册，请先告知我们您的计划。

`man` 页面（Unix 在线文档的标准）是使用 Unix 标准 `nroff man`（或 BSD `mdoc`）宏创建的。

指南（LDP 制作的完整书籍）在历史上一直使用 `LaTeX` 编写，因为其首要目标是打印文档。然而，指南作者正转向带有 `DocBook DTD` 的 `SGML`，这允许他们创建更多类型的输出，包括打印和在线。如果您使用 `LaTeX`，我们有一个样式文件可以使用，以保持您的外观与其他 LDP 文档一致，我们建议您使用它。

HOWTO 均要求使用 `SGML` 格式。目前，我们使用 `linuxdoc` `DTD`，它非常简单。随着时间的推移，我们正转向 `DocBook DTD`。

LDP 文档必须允许免费分发且不向作者收取费用。并不要求文本必须是可修改的，但鼓励这样做。您可以想出满足此限制的自定义许可条款，也可以使用以前准备好的许可。LDP 提供了一个可以使用的模板许可，一些人喜欢使用 `GPL`，而另一些人则编写自己的。

每本手册的版权应在项目首席写作者或协调人的名下。“Linux 文档项目”。

## 发布 LDP 手册

如果您是希望发行任何 LDP 手册的公司，请继续阅读。

根据上一节的许可，任何人允许发布并分发 LDP 手册的原件。这不需要我们的明确许可。然而，如果您想分发基于任何 LDP 手册的翻译或衍生作品，必须在在此之前获得作者的书面许可。

所有 LDP 手册的翻译和衍生作品必须采用上一节的 Linux 文档许可。也就是说，如果您计划发布某本手册的翻译，它必须是免费分发的。

当然，您可以为了利润出售 LDP 手册。我们鼓励这样做。但请记住，由于 LDP 手册是免费分发的，如果您愿意，任何人都可以免费复印或发行打印版。

我们不要求出售 LDP 手册的利润支付版税。然而，我们建议如果您为了利润出售 LDP 手册，可以向作者支付版税，或将部分收益捐给作者、LDP 整体或 Linux 开发社区。您可能还想向作者赠一份或多份正在分发的 LDP 手册。您对 LDP 和 Linux 社区的支持将令不胜感激。

我们希望了解任何出版 LDP 手册的计划，以便我们知道它们是如何获取的。如果您正在或计划出版任何 LDP 手册，请发送邮件至 `Matt Welsh` (`mdw@metalab.unc.edu`)。
