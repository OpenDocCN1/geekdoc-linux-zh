
- `display`: 指定与 X 服务的连接。
- `rid`: 指定与数据关联的资源 ID。
- `context`: 指定数据所属的上下文类型。

`XDeleteContext` 函数从数据结构中删除给定资源 ID 和类型的条目。如果使用相同的参数调用该函数，它返回与 `XFindContext` 相同的错误代码。`XDeleteContext` 不会释放已保存地址的数据。

要创建一个可能在后续 `XSaveContext` 和 `XFindContext` 调用中唯一上下文类型，请使用 `XUniqueContext`。

```
XContext XUniqueContext();
```
