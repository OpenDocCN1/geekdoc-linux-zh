
相反，它会选择最可能的有效名称 `Fred`，而该变量可能未被设置。

如果参数扩展发生在双引号内：

- 扩展的结果不会对扩展结果进行路径扩展（`path expansion`）。
- 扩展的结果不会对扩展结果进行字段拆分（`field splitting`），但 `@` 除外。

此外，参数扩展可以通过以下格式之一进行修改。在需要单词值（根据下文描述的参数状态）的每情况下，单词将经过波浪扩展、参数扩展、命令替换和算术扩展。如果不需要单词，则不进行扩展。

分隔后续参数扩展修改的 `)` 字符按照本节之前的描述确定。（例如，如果 `foo` 未设置，则 `$foo-bar xyz` 的结果是扩展的 `foo` 后面跟上字符串 `xyz`；扩展后的字符串为 `barxyz`）。

### 使用默认值

```
${parameter:-word}
```

使用默认值。如果参数未设置或为空，则替换为 `word` 的扩展；否则，替换为参数的值。

### 分配默认值

```
${parameter:=word}
```

分配默认值。如果参数未设置或为空，则将 `word` 的扩展赋值给参数。在所有情况下，替换为参数的最终值。你只能通过这种方式给变量赋值，而不能给位置参数或特殊参数赋值。

### 如果为空或未设置则指示错误

```
${parameter?word}
```

如果为空或未设置则指示错误。如果参数未设置或为空，则向标准错误（`stderr`）写入 `word` 的扩展（如果你省略了 `word`，则写入指示其未设置的消息）并以非零退出状态退出。否则，替换为参数的值。交互式 `shell` 不需要退出。

### 使用替代值

```
${parameter:+word}
```

使用替代值。如果参数未设置或为空，则替换为空值；否则，替换为 `word` 的扩展。

在上述参数扩展中，格式中的冒号用于对参数是否未设置或为空进行测试；省略冒号则对参数是否仅未设置进行测试。下表总结了冒号的作用：

| 格式 | 参数设置且为空 | 参数设置但为空 | 参数未设置 |
| --- | --- | --- | --- |
| `${parameter:-word}` | 替换参数 | 替换 `word` | 替换 `word` |
| `${parameter-word}` | 替换参数 | 替换为空 | 替换 `word` |
| `${parameter:=word}` | 替换参数 | 赋值 `word` | 赋值为空 |
| `${parameter=word}` | 替换参数 | 替换参数 | 赋值为空 |
| `${parameter:?}` | 替换参数 | 错误；退出 | 错误；退出 |
| `${parameter?}` | 替换参数 | 替换为空 | 错误；退出 |
| `${parameter:+}` | 替换 `word` | 替换为空 | 替换为空 |
| `${parameter+word}` | 替换 `word` | 替换 `word` | 替换为空 |

所有显示为“替换”（Substitute）的情况都将表达式替换为显示的值。所有显示为“赋值”（Assign）的情况都将该值赋予参数，这也会替换表达式。
