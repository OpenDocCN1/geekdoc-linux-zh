
## 描述

`postio` 命令将文件发送到连接到 `line` 的 PostScript 打印机。如果你未指定文件，则发送标准输入。

### 注意事项

输入文件被视为单个 PostScript 作业。发送多个不同的且每个带有其内部作业结束标记 `^D` 的作业，并无法保证能够正常工作。`postio` 可以在所有作业完成之前退出，并可以在最后一个作业完成之前重启。

下述的所有功能可能在每台机器上均可用，甚至在该程序支持的不同 UNIX 系统版本之间也不可能可用。

可能没有默认的 `line`，因此强烈建议使用 `-l` 选项。如果你省略了 `-l` 选项，`postio` 可能会尝试使用标准输出连接打印机。如果涉及 Datakit，`-b` 选项可能无效，且 `postio` 尝试对双向数据实施流控制的操作可能无效。如果打印机连接到 RADIAN，`-q` 选项会有帮助。通常不建议使用 `-S` 选项，只有在所有其他建立可靠连接的选项都失败时才使用。

## 选项

以下选项组对于大多数应用程序足够。

- `-b speed` 以波特率速度通过 `line` 传输数据。识别的波特率有 `1200,2400,4800,9600` 和 `19200`。默认速度为 `9600`。
- `-B num` 设置读取和写入文件的内部缓冲区大小为 `num` 字节。默认情况下，`num` 为 `2048` 字节。
- `-D` 启用调试模式。保证在 `line` 上读取到的所有内容都被添加到日志文件中（默认为标准错误）。
- `-l line` 连接到连接在 `line` 上的打印机。在大多数情况下，没有默认值，且 `postio` 必须能够读写 `line`。如果 `line` 不以 `/` 开头，则它可能被视为 Datakit 目标。
- `-L file` 将在 `line` 上接收到的数据存入文件。默认日志文件是标准错误。通常不将未显示状态变化的打印机或状态消息写入文件，但可以使用 `-D` 选项强制写入。
- `-P string` 在输入任何文件之前向打印机发送字符串。默认字符串是禁用超时时的的简单 PostScript 代码。
- `-R num` 如果 `num` 为 `1`，则作为单进程运行 `postio`；如果 `num` 为 `2`，则作为独立的读取和写入进程运行。默认情况下，`postio` 以单进程方式运行。
- `-q` 在向打印机发送文件时防止状态查询。当禁用状态查询时，会在每个数据块传输之前向日志文件追加一个伪消息。

接下来的两个选项是为那些期望自己运行 `postio` 的用户准备的。这两者都不适用于 `spoller` 接口程序。

- `-i` 在交互式模式下运行程序。首先发送任何文件，然后是标准输入。强制使用独立的读取和写入进程并覆盖许多选项。要退出交互式模式，请使用你的中断或退出字符。要与打印机建立友好的交互式连接，请在单独的一行中输入 `execute`。
- `-t` 将在 `line` 上接收到且未识别为打印机或状态信息的数据写入标准输出。强制使用独立的读取和写入进程。如果你有一个向宿主机返回有用数据的 PostScript 程序，这会非常方便。

以下选项通常不建议使用，只有在其他一切都无法提供可靠连接时才使用。

- `-S` 减慢向打印机传输数据的速度。严重限制吞吐量，作为单进程运行，禁用 `-q` 选项，并将内部缓冲区限制为 `1,024` 字节。此选项可能会大量的 CPU 时间，并在交互式模式下无效。

通常通过使用大型内部缓冲区 `-B` 选项并作为独立的读取和写入进程运行程序 `-R 2` 选项获得最佳性能。无法创建额外的进程将继续作为单读/写进程运行。当使用单个进程时，只对发送到打印机的数据进行流控。

选项并不是互斥的。`-i` 选项始终优先，选择其自己的设置以独立于命令行上发现的任何内容运行交互式模式。交互式模式作为独立的读取和写入进程运行，在存在 `-i` 选项的情况下，其他很少有选项能起作用。`-t` 选项需要与打印机建立可靠的双向连接，因此尝试分离读取和写入进程。`-S` 选项依赖于状态查询机制，因此 `-q` 被禁用且程序作为单进程运行。

## postio

在大多数情况下，`postio` 开始与 `line` 连接，然后通过发送适当的 `^T`（状态查询）、`^C`（中断）和 `^D`（作业结束）字符强制打印机进入 IDLE 状态。当打印机变为 IDLE 时，文件将连同偶尔的 `^T` 传输（除非你使用了 `-q` 选项）。所有文件发送完毕后，程序将等待直到作业可能完成。除了建立初始连接期间（或运行交互式模式时）外的任何时间打印机生成的错误消息都会以非零状态退出 `postio`。除了添加到日志文件外，打印机错误消息也会回到标准错误。

## 示例

以下示例以 9600 波特率作为单进程运行，并将 `file1` 发送到 `/dev/tty`。

```
postio -b 9600 -l /dev/tty file1
```

以下示例与之前相同，但使用了两个进程，这对于处理大文件有用。

```
postio -R 2 -b 9600 -l /dev/tty file1
```

以下示例与打印机建立交互式连接。

```
postio -i -l /dev/tty
```

以下示例将程序发送到 `/dev/tty` 并结果放在文件中。

```
postio -t -l /dev/tty program > results
```
