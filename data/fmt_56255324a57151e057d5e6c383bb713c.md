返回的字符串被放在 `returnString` 中。`compose` 参数被忽略。

**跨窗口事件**

当指针进入窗口时，服务器生成 `EnterNotify` 事件；当指针离开窗口时，生成 `LeaveNotify` 事件。`CrossingEvent` 结构如下：

```c
typedef struct {
    int type; /* 事件类型 */
    unsigned long serial; /* 服务器处理的最后一个请求数 */
    Bool send_event; /* 如果此来自 SendEvent 请求则为 true */
    
    Display *display; /* 读取事件的显示器 */
    Window window; /* 相对于报告的“事件”窗口 */
    Window root; /* 事件发生的根窗口 */
    Window subwindow; /* 子窗口 */
    Time time; /* 毫秒 */
    int x, y; /* 事件窗口中的指针 x, y 坐标 */
    int x_root, y_root; /* 相对于根的坐标 */
    int mode; /* NotifyNormal, NotifyGrab, NotifyUngrab */
    int detail; /* NotifyAncestor, NotifyVirtual, NotifyInferior, 
                  NotifyNonlinear, NotifyNonVirtual */
    Bool same_screen; /* 同一屏幕标志 */
    Bool focus; /* 布尔焦点 */
    unsigned int state; /* 键或按钮掩码 */
} XCrossingEvent;
```

`typedef XCrossingEvent XEnterWindowEvent;`

`typedef XCrossingEvent XLeaveWindowEvent;`

这些通常用于在用户进入和离开窗口时更改窗口颜色。

**事件掩码**

应用程序通过调用函数 `XtAddEventHandler` 请求特定类型的事件。

```c
XtAddEventHandler(Widget,
                 EventMask,
                 Boolean maskable,
                 XtEventHandler handlerfunction,
                 XtPointer clientData);
```

处理函数的形式如下：

```c
void handlerFunction(Widget w, XtPointer clientData,
                     XEvent *ev, Boolean *continueToDispatch);
```

前两个参数是传递给 `XtAddEventHandler` 的客户端数据和窗口。`ev` 参数是触发此调用的事件。最后一个参数允许将此消息传递给该类型的其他消息处理程序。这应该默认设置为 `TRUE`。

你可以在窗口（`w`）上使用以下调用，以接收该窗口上所有类型为 `ButtonMotion` 和 `PointerMotion` 的指针事件。

```c
extern void handlerFunction(Widget w, XtPointer clientData,
                           XEvent *ev, Boolean *continueToDispatch);

XAddEventHandler(w, ButtonMotionMask | PointerMotionMask, FALSE,
               handlerFunction, NULL);
```

## 管理队列

`XtAppMainLoop()` 函数通过以下函数处理所有传入的事件：

- `XtAppPending`: 检查队列查看是否有待处理的事件。

- `XtAppNextEvent`: 从队列中移除下一个事件。

- `XtDispatchEvent`: 将消息传递给相应的窗口。

在检查和移除消息之间，可以通过替换代码段来执行其他操作：

```c
while (!done)
{
    while (XtAppPending(applicationContext))
    {
        XtAppNextEvent(applicationContext, &ev);
        XtDispatchEvent(&ev);
    }
    done = interEventFunction();
}
```

该方案还存在以下警告：

- 这是一个非阻塞函数。它必须不断地接收事件，否则它将占用所有其他应用程序的时间。

- 如果队列被事件淹没，无法保证你的事件间函数（inter-event function）何时运行。

- 注意用于检查消息的 `while` 循环。先刷新队列再调用你的函数，比每检查一次消息就调用一次函数要效率更高。

- 事件间函数必须是快速的，否则你将看到用户界面变慢。如果你想在长时间的事件间函数期间向用户提供反馈，可以通过调用 `XmUpdateDisplay(Display *)` 仅处理 `Expose` 事件。这将只会处理队列中的 `Expose` 事件，以便你更新状态显示。
