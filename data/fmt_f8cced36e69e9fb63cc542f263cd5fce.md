
## `bsdmainutils`
来自 FreeBSD 的更多实用工具。此包包含了许多人在使用 BSD 风格的 Unix 系统时期望找到的小型工具。包括：`banner`, `ncal`, `cal`, `calendar`, `colct`, `col`, `colum`, `fmt`, `hexdump`, `look`, `order`, `ul`, `write`。此包曾包含 `whos` 和 `who`，它们现在分发在独立的包中。这也包含 `tsort`，它现在位于 "`textutils`" 包中，版本 2.0–1，源自 Debian 3.0r0 `APT`
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## `bsdutils`
来自 4.4BSD–Lite 的基础工具。这些工具需要启动系统。你应该安装 `bsdmainutils` 来获取标准的 BSD 实用。包括：`logger`, `renice`, `replay`, `script`, `wall`。源自 Debian 3.0r0 `APT`
http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## `bsh`
一种脚本环境。`BeanShell` 是一个小型、免费、可嵌入的 Java 源解释器，具有脚本语言特性，用 Java 编写。`BeanShell` 执行标准语句和表达式，此外允许脚本命令和语法。`BeanShell` 支持简单的对象闭包，类似于 Perl 和 JavaScript(tm)。你可以交互式使用 `BeanShell` 进行 Java 实现和调试，或将其作为应用的简单脚本引擎。简而言之：`BeanShell` 是动态解释的 Java 加上一些实用的东西。源自 Debian 3.0r0 `APT`
http://www.tldp.org/LDP/linux-Dictionary/html/index.html

## `bsgn`
损坏与入侵检测。此包将哈希值（SHA1）和数字签名（GNU Privacy Guard）嵌入文件中以进行验证。目前的目标是 ELF 可执行文件、内核模块和静态库。该程序具有类似于无需维护数据库即可触发的相似性。源自 Debian 3.0r `APT`

## `bsmtp`
用于 `send` 和 `postfix` 的 SMTP 邮件发送器。此包为 `postfix` 中添加了一个名为 `smtp` 的新“发送器”，你可以选择将其作为 SMTP。`BSSMTP` 用于 UUCP 环境，并将许多文件作为（压缩的）批次传输，而不是传输单封邮件。`smtp` 是 `mail` 的替代方案。此包用 C 编写的功能包括：可配置的批量大小（达到大小时自动向你发送批量）– 创建输出批量（并定期删除）– `sendmail` 和 `postfix`。源自 Debian 3.0r `APT`
http://www.tldp.org/LDP/linux-Dictionary/html/index.html
