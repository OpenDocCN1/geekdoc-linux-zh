
* 通过在挂载为本地目录的远程目录中创建备份归档，将你的备份文件写入远程存储。

这些场景场景提供了通过网络挂载目录满足备份的基本离线需求的方法。

## 面向 Linux 的网络导型备份软件

如上一节所述，所有工具都会创建本地归档文件或将其归档写入本地设备（或看起来是本地的存储）。本节讨论的备份工具与此不同——它们本质上具有网络感知能力，因此允许你创建和管理远程系统的本地内容。以下是 Linux 可用的一些常用的网络感知备份系统；还有更多，你可以通过启动 `apt` 包管理器并搜索术语 `backup` 来找到。以下是我的收藏：

### Amanda

高级马里兰网络磁盘归档器（Advanced Maryland Network Disk Archiver）是一个开源备份系统，最初于 20 世纪 90 年初为马里兰大学的 Unix 系统开发。Amanda 可以方便地将任意客户端工作站备份到中央备份服务器，支持通过 Samba 进行 Windows 备份，并为你的 Ubuntu 系统提供完整的备份管理系统。Amanda 支持具有不同配置的多组备份，支持光盘和磁带备份，跟踪客户端系统的备份级别和日期，通过电子邮件自动发送详细报告，并保留大量的日志，以便于诊断和纠正大多数问题产生的原因。Amanda 客户端和服务器之间的通信经过加密以提高安全性。Ubuntu 默认未安装 Amanda，但在 Ubuntu 存储库中可用，并可以使用 `Synaptic`、`apt-get` 或 `aptitude` 轻松安装。Amanda 由两个包组成：`amanda-server` 和 `amanda-client`。Amanda 的主站为 www.amanda.org。

### BackupPC

BackupPC 是一个很好的备份系统，它提供了一个基于 Web 的界面，允许你使用 `smb`、`tar` 或 `rsync` 备份远程系统。图 22.1 显示示例 BackupPC 服务器的 Web 页面。BackupPC 创建远程系统的备份并存储管理在你的 BackupPC 服务器上，同时允许授权用户从这些归档中恢复自己的文件，消除了系统管理员头疼的首要源。每个客户端系统的配置数据存储在 BackupPC 服务器上，这允许你使用不同的命令或协议备份不同类型的系统，并轻松识别你想备份的远程目录或文件系统。BackupPC 一个特别棒的特性是它在服务器上使用标准的 Linux 命令创建备份，因此不需要在客户端系统上安装任何软件，尽管某些备份命令可能需要一些客户端侧配置。

**图 22.1** Firefox 中的 BackupPC 服务器主页

BackupPC 的主页地址为 http://backuppc.sourceforge.net。有关关于安装、设置和使用 BackupPC 的更多信息，请参阅本章后半部分的“安装和使用 `backuppc` 实用程序”章节。

### Bacula

Bacula 是一组非常强大的程序，它提供了一个可扩展的网络备份和恢复系统，支持 Linux、Unix 和 Microsoft Windows 系统。它的强大和灵活性可以轻松与 Amanda 媲美，但在备份的存储方式和存储位置方面，它比后者更灵活。Ubuntu 系统默认不安装 Bacula，但 Ubuntu 存储库中提供了该程序，并可以使用 `Synaptic`、`apt-get` 或 `aptitude` 轻松安装。Bacula 非常强大，但可能很复杂——如果你有兴趣探索 Bacula，你可能想从安装 `bacula-doc` 包开始，并阅读其文档，以确定它是否适合你的环境。Bacula 主要面向命令行，但也提供了一个图形化控制台（如图 22.2 所示），作为其命令行界面的封装器。Bacula 的主页为 www.bacula.org。

### rsync

Rsync（远程同步）是一个命令行文件和目录同步程序，可以轻松地将文件和目录从一个主机复制到另一个主机。当文件或目录层次结构同时存在本地和远程副本时，`rsync` 能够利用内置功能帮助减少需要传输的数据量，以确保这些文件和目录的本地和远程副本完全一致。`rsync` 实用工具使用的远程更新协议允许 `rsync` 仅传输两组文件和目录之间的差异。该同步程序作为 Ubuntu 默认安装的一部分自动安装，但需要对你想要复制到本地主机的远程系统进行一些配置。

## 将文件备份到本地可移动介质

本章的上一一节标题为“备份 101”，引入了备份的基本概念，其中许多概念对于家庭使用来说似乎并不实际。它们是否真的不实际取决于你想要通过备份解决什么问题。如果你主要的是保护自己防止硬件故障或意外删除正在工作的关键文件，你可能不需要进行归档备份和增量备份——将重要文件和目录备份到 CD-R 或 DVD-R 进行点对备份可能足够了。同样，如果你不需要能够从任何时间恢复任何文件，而只需要文件的最新副本，那么对你备份的目录进行点对备份可能足够，并按你觉得舒服的频率进行即可。如果你不担心房屋或公寓被毁会导致丢失所有数据，那么你就不需要执行异地存储备份的操作。

底线是，我无法告诉你你对什么感到舒服——这取决于你自己，并定义了你的策略。接下来的几节重点介绍了你如何使用本章前面提到的某些实用程序（甚至是标准的 Linux `cp` 命令）来创建重要文件的备份副本。对于家庭使用，最流行的备份方法简单地将目录拖放到 CD-R 或 DVD-R 介质上，以创建这些目录的点对备份。备份系统的第二种流行方法是使用可以通过 USB 或 FireWire 连接到你系统的硬盘硬盘。优点是，除非你使用的是非常小的移动硬盘，否则这为你提供了一个比 CD 或 DVD 更大的备份存储池，并允许你存储更多重要文件和目录的备份，或者在可移动存储器上为每个重要目录创建一个单独副本，并在每次备份时更新它。缺点是，移动硬盘比 CD-R 或 DVD-R 磁盘大得多，异地存储和每次备份时的检索也要麻烦得多。

## 使用 `tar` 备份和恢复文件

`tar` 是最老、最经典的 Linux/Unix 实用程序之一。尽管它可以写入磁带驱动器等备份设备，但 `tar` 命令最常用于创建归档文件（例如 `.tar`），这些文件可以方便地与其他共享。使用 `tar` 命令创建的归档文件通常具有 `.tar` 文件扩展名。GNU `tar` 命令（Ubuntu 和 Linux 系统上找到 `tar` 版本）提供了内置的压缩功能，能够自动实时压缩文件。压缩后的 tar 归档通常具有 `.tgz` 扩展名，表示它们使用 `gzip` 应用程序压缩（并可以解压），或者具有 `.tbz2` 扩展名，表示它们使用 `bzip2` 应用程序压缩（并可以解压）。使用 `tar` 实用程序产生的归档通常称为 *tarballs*（压缩包）。

**由于其历史久远，向 `tar` 命令传递参数时必须小心，因为在某些情况下必须按照特定的顺序指定它们。**

使用 `tar` 创建归档文件很容易的。例如，要为 `/home` 中的所有目录创建一个名为 `home_dir_backup.tgz` 的 tar 包，你可以使用如下命令：

```bash
sudo tar czcvf /tmp/home_dir_backup.tgz /home
```

**注意，你想将备份文件写入其他地方。**

使用 `tar` 命令创建归档文件的选项含义如下：

- `c`：创建归档文件。

- `z`：通过 `gzip` 压缩。

- `v`：显示处理过程。

- `f`：指定归档文件名。
