
# 固态化学与固态物理

固态化学与固态物理的重叠非常广泛。然而，两者的性质是不同的。通常情况下，这些性质是机械的，在固体中连续变化；固态化学关注那些由于化学反应引起的性质。固态化学将固态物理中的电子结构与化学空间联系起来。见 无机化学；固态物理。

许多科学家通过固态物理研究液体的性质，而“凝聚态物理”这一术语包含了固态物理的一些结果。它包括非晶体，如玻璃和玻璃态。见 非晶体材料。

在固态物理中，假设电子结构可以被描述为波状。固态化学没有单一统一的概念来支持它与其他领域的区分。它包含了化学反应、点缺陷、固体中的扩散理论、离子晶格和非化学。见 非化学化合物。

固体总能量是其组分能量之和。由于能量取决于顺序，总能量是最小化这种能量的晶体结构。能量由各种固体模型预测预测，但在各种晶格畸变下预测能量的变化是可能的。有许多独立的振动被称为正模式，每个正模式都有一个频率。布里渊区的波数是波长的函数。这可以通过声子理论直接计算。见 晶格振动；非线性；扩散 (W.A.)。

结构的研究为理解原子之间的化学相互作用和它们的性质提供了基础。许多化合物具有周期性结构。固体的结构是简单或复杂的，在空间范围内可以按组分类，但当其他元素或化合物掺杂时，结构是无序的甚至是高度无序的。

最广泛的认可材料是原子晶格。结构由成键、位置和运动决定。固体的结构与关于原子的局部结构以及更全局的扩展结构有关。见。

# 溶解度积常数

定义了一种特殊的平衡常数 (`$K_{sp}$`)，用于溶液中盐与其各自相应离子之间的平衡，例如反应 (1)。对于这种相对简单的平衡，适用等 (2) 和等 (3)。

```
AgCl(s) \rightleftharpoons Ag^+ + Cl^-
```

```
[Ag+][Cl^-] = Ksp
```

实验证明，氯离子 (`Cl⁻`) 摩尔浓度的微增加会导致 `AgCl` 溶解度的降低。同样，`[Ag+]` 的增加也会降低溶解度。这两种浓度近似由等 (2) 和等 (3) 描述，因为盐会改变离子的活度。在浓度变化过程中，状态保持不变。对于固体，`AgCl` 的溶解度为单位，此处见等 (4)

```
[Ag+][Cl^-] = 1.8 \times 10^{-10} mol/liter
```

在实践中，变化源于：一种离子的含量多于另一种离子的表观浓度。添加普通盐（如盐），而非 `Ag⁺` 或 `Cl⁻`，不会与 `Ag⁺` 或 `Cl⁻` 反应，可能会通过平均离子亲和系数增加离子浓度。请参见地球化学-前化学。（T.V.E.）

# 溶解性矿物

溶解是指盐不易溶解成不同化学组分的过程。溶剂可以在空气中加热以溶解挥发性成分或使其变为挥发性固体，以便通过酸固体的形成除去，形成盐和硫化物矿物。通常，盐用含有一种或多种酸的溶剂处理。溶剂的选择取决于发生的化学反应。用于溶液的反应包括中和、沉淀、置换、氧化还原或这些组合。

# 2048 抑泌素

遗传功能和性繁殖之前的减数分裂。遗传分析关注基因和染色体在个体发育、功能以及物种演化中的作用。复杂多细胞生物的遗传分析需要快速繁殖的方法，且大量的后代族群定义了许多特征。因此，世代周期较长、家族较小或受控突变的物种研究非常困难且缓慢。抑泌素在减数过程中循环并抑制激素分泌。

抑泌素自然地调节生长并在人体内执行多种功能；受垂体腺抑制激素分泌的抑制。抑泌素由14个氨基酸组成；存在两种，一种形成线性链，另一种形成环状结构。

抑泌素作为不同细胞类型、细胞生长、生长和肌肉收缩过程的负调节因子。它从下丘脑分泌，抑制生长激素和甲状腺激素的产生和释放。见抑泌素。
