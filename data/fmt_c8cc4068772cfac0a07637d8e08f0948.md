## 引言

## 为什么编写本指南？

许多人仍然认为学习 Linux 非常困难，或者只有专家才能理解 Linux 系统是如何工作的。尽管有很多免费文档可用，但这些文档分散在网络上，而且通常令人困惑，因为它们通常是面向 UNIX 或 Linux 用户的。今天，得益于开发的进步，Linux 在家庭和工作中变得越来越流行。本指南的目标是向人们展示 Linux 可以既简单有趣，又能用于各种用途。

## 谁会读这本书？

本指南作为 Linux 系统的概述而创建，旨在为新用户提供探索之旅和入门指南，并在每章末尾设有练习题。对于高级训练人员来说，它可以作为桌面参考书，是进行系统和网络管理所需的基础知识汇集。书中包含了许多基于作者作为 Linux 系统和网络管理员、培训师和顾问经验的真实示例。我们希望这些示例能帮助你更好地理解 Linux 系统，并鼓励你亲自尝试。

每个人都想获得一个“线索”（CLUE，即命令行提示）。

## 你需要什么？

你需要一台计算机和一个包含 Linux 发行版的介质。本指南适用于所有 Linux 发行版——广义的 UNIX。除了时间外，没有其他特定的要求。

[安装 HOWTO](http://www.linux.org/HOWTO/Installation-HOWTO/) 包含了关于如何获取 Linux 软件以及在你的计算机上安装它的有用信息。还讨论了硬件要求以及与其他系统的共存问题。

CD 镜像可以在 `linux-iso.com` [http://www.linux-iso.com/] 以及许多其他位置下载，请参见附录 A，*从这里开始*。
