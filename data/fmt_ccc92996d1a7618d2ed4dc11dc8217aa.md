# strace

# structured programming

一组使程序更冗长但更易读、易维护的特性。结构化编程的目标是避免由于 GOTO 语句导致的“面条代码”，这种问题在 BASIC 和 FORTRAN 中很常见。结构化编程——由 C、Pascal、Modula-2 以及该软件命令推广——坚持整体结构应反映程序应该执行的操作，从第一个任务开始按逻辑进行。缩进有助于使代码清晰，并鼓励程序员在 GOTO 语句之后使用循环和控制结构。来自 QUCED http://www.ldp.org/LDP/Linux-Dictionary/html/index.html
