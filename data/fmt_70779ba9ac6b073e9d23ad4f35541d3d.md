这些目录中的大部分在所有 Linux 系统中都是一致的。从服务器到超级计算机再到微型嵌入式系统，丰富的 Linux 用户可以放心地使用 `/bin` 内的 `ls` 命令，通过修改 `/etc` 中的文件来更改系统配置，并在 `/var` 中读取系统日志。这些文件和目录的标准位置由文件系统层级标准 (FHS) 定义，我们将在后的课程中进行讨论。随着你继续学习 Linux，你将了解到更多关于这些目录的内容，但目前请记住：

- 你在根文件系统中所做的更改将影响所有用户，并且
- 在根文件系统中更改文件需要管理员权限。

这意味着普通用户被禁止修改这些文件，也被禁止读取这些文件。我们将在后的部分介绍权限的主题。

现在，我们将关注 `/home` 目录，到目前你应该对它有些熟悉：

```
$ tree -L 1 /home

/home

  user

    michael

  lara
```

我们的示例系统有三个普通用户，每个用户都有自己的专有位置，他们可以在那里创建和修改文件及目录，而不影响邻居。例如，在上一节中，我们处理的是以下文件结构：

```
$ tree /home/user

user

└ Documents

  ├ Mission-Statement

  └ Reports

    └ report2018.txt
```

实际上，真实的文件系统可能像这样：

```
$ tree /home

/home

└ user

  └ Documents

    ├ Mission-Statement

    └ Reports

      └ report2018.txt

└ michael

  └ Documents

    └ presentation-for-clients.odep

  └ Music
```

...对于 `lara` 也是如此。

在 Linux 中，`/home` 类似于公寓楼。许多用户在这里拥有自己的空间，被分成独立的公寓。楼本身的实用和维护由管理员用户 `root` 负责。

### Home 的特殊关系路径

当你在 Linux 中启动一个新的终端会话时，你会看到这样的提示符：

```
user@hostname~$
```

波浪号 (`~`) 代表你的家目录。如果你运行 `ls` 命令，你会看到：

```
$ ls ~
```

## `ls -lh`

将长列表格式与人类可读的文件大小结合，可以让我们得到非常有用的后缀，例如代表兆字节的 `M` 或代表千字节的 `K`。

## `ls -d */`

`-d` 选项将列出目录而不显示其内容。将此与 `/*` 结合将只显示子目录而不显示任何文件。

## `ls -lrt`

将长列表格式与按（修改）时间排序结合，并结合 `-r` 反转排序。现在，最近更改的文件将位于列表的末尾。除了按修改时间排序外，还可以按访问时间或状态时间对文件进行排序。

## `ls -lx`

将长列表格式与按文件扩展名排序的选项结合。例如，这会将所有 `.txt` 文件归为一类，所有 `.jpg` 文件归为一类，此类推。

## `ls -S`

`-S` 按文件大小排序，这与 `-t` 和 `-X` 分别按时间和扩展名排序的方式相似。最大的文件排在前面，最小的排在最后。注意，排序不包含子目录的内容。

### Bash 中的递归

递归是指“某物”根据自身定义定义。

```bash
$ ls ~~
Documents
```

我们从之前就知道用户有一个家目录，并且在这个目录下有一个子目录。`ls` 现在只显示了某个位置的文件和子目录，但不能告诉我们这些子目录的内容。在这些课程中，当我们想要显示许多目录的内容时，我们一直在使用 `tree` 命令。遗憾的是，`tree` 并不是 Linux 的核心实用程序之一，并且并不总是可用的。请对比以下示例中 `tree` 的输出与 `ls -R` 的输出：

```
$ tree /home/user

user

  Documents

    Mission-Statement

    Reports

      report2018.txt

$ ls -R

/home/user/:

Documents

/home/user/Documents:

Mission-Statement

Reports

/home/user/Documents/Reports:

report2018.txt
```

如你所见，通过递归选项，我们得到了一个长得多的文件列表。事实上，这就像我们在家目录下运行 `ls` 命令并遇到了一个子目录。然后我们进入该子目录并再次运行 `ls` 命令。我们遇到了文件 `Mission-Statement` 和另一个名为 `Reports` 的子目录。再次进入该子目录并再次运行 `ls` 命令。本质上，运行 `ls -R` 就像是告诉 Bash：“在这里运行 `ls`，并在发现的每一个子目录中重复该命令。”

递归在文件修改命令（如复制或删除目录）中特别重要。例如，如果你想复制 `Documents` 子目录，你需要指定递归复制，以便此命令扩展到所有子目录。

### 总结

在本次实验中，你学习了：每个 Linux 用户将有一个家目录，当前用户的家目录可以使用 `~` 访问，这被称为相对路径。

你还学习了修改 `ls` 命令的一些最常用方法：

- `a` (all) 打印所有文件，包括隐藏文件
- `d` (directories) 列出目录，而不是其内容
- `h` (human readable) 以人类可读的格式打印文件大小
- `l` (long list) 提供额外的细节
- `r` (reverse) 反转排序
- `R` (recursive) 递归列出每个文件
- `S` (size) 按大小排序
- `t` (time) 按修改时间排序
- `X` (extension) 按扩展名排序
