
1. 通过 GNOME 面板中的 Places（位置）菜单并选择 Home Folder（主目录），打开一个新的 Nautilus 窗口。完成后，同样的操作打开另一个 Nautilus 窗口。

2. 在其中一个 Nautilus 窗口中，进入 Go（前往）菜单并选择 Location（位置）。窗口按钮栏下方会出现一个 Location 输入框。你也可以通过按 CTRL-L 来实现相同的结果。

3. 在 Location 框中输入 `fonts://` 并按回。完成后，窗口将充满许多代表你已经在系统中本地安装的字体的图标。

你在那里时，将此窗口书签以备后用并不是坏主意。

4. 从另一个打开的 Nautilus 窗口（你的主目录窗口）选择你想要安装的解压字体，将其拖到 `fonts://` 窗口中。

你会发现，当你从主目录将新字体拖动到 `fonts://` 窗口时，新字体的图标并没有立即出现。事实上，似乎什么都没有发生，你的安装尝试失败了。嗯，尽管缺乏这种确认，但事情正在发生。当你第一次以这种方式安装字体时，系统会自动在你的主目录下创建一个隐藏的 `.fonts` 文件夹并放在那里。如果你不喜欢这种缺乏即时反馈，可以在一个 Nautilus 窗口的 Location 框中输入 `~/.fonts` 来检查你的字体。这将显示你本地安装了哪些字体——此时只有一种。

现在你已经安装了字体，可以在其中一个应用程序中使用它，例如 OpenOffice.org Writer。（任何正在运行的应用程序在新字体出现在应用程序的字体菜单之前，都需要重新启动。）

## 11A-3：本地安装字体的另一种方法

如果你更喜欢在安装过程中获得真正的即时反馈，可以尝试以下安装过程的变体，其结果与第 191 页项目 11A-2 相同。然而，由于这种安装方法使用了项目 11A-2 第 4 步中创建的 `.fonts` 文件夹，你必须执行项目 11A-2 中的过程，或者在尝试这种安装方法之前先创建文件夹，或者打开 Terminal 窗口（应用程序 ► 附件 ► Terminal），在窗口中输入 `mkdir ~/.fonts` 并按回。现在你已经有了 `.fonts` 文件夹，让我们使用下载的另外两个字体来尝试这些步骤：

1. 假设你已经关闭了项目 11A-2 的两个窗口，打开两个新的 Nautilus 窗口。

2. 在一个 Nautilus 文件夹中输入 `~/fonts` 并按回。Nautilus 窗口的主面板将只显示一种字体，或者如果你跳过了项目 11A-2 并自己创建了 `.fonts` 文件夹，则什么都没有。在那里时，将此位置书签非常有用。

3. 在打开的 Nautilus 窗口（即你的主目录窗口）中，按住 CTRL 键并点击每个字体的图标，高亮你想安装的两种字体。释放 CTRL 键，右键点击高亮的字体之一，并在弹出菜单中选择 Copy Files（复制文件）。

4. 在 `.fonts` 窗口中，右键点击窗口中的任何空白区域，并在弹出菜单中选择 Paste Files（粘贴文件）。字体将出现在 Nautilus 窗口中。

当然，你可以直接将字体从主目录拖动到 `.fonts` 文件夹，而不是执行步骤 3 和 4 中的程序。这完全取决于你。无论哪种方法，这种方法取决于个人喜好。

## 11A-4：本地卸载

如果你想移除用本项目介绍的任何本地安装方法安装的字体，可以按照以下方式操作：

1. 打开 Terminal 窗口，输入 `sudo rm ~/.fonts/fontname.ttf`。请务必将 `fontname` 替换为你正在安装的字体名称。

## 项目 11C：通过 Synaptic 安装 Microsoft Windows 核心字体

无论如何，计算世界在很大程度上仍然是微软的世界，这意味着大多数用户（即使是 Mac 用户）都在使用微软的核心字体。既然如此，你不可避免地需要处理如 Georgia、Verdana、New Roman 和 Courier 等字体的文档。当然，你的系统可以用其已有的字体替换文档中使用的字体，但为了确保你看到的是你预期的效果，并让他人能够以你预想的方式查看你的文档（网页就是一个很好的例子），在自己的系统上安装微软核心字体可能是一个明智之举。

幸运的是，你有两种方法可以获取这些字体。一种是通过 Synaptic 下载并安装，另一种对于那些使用双系统启动的用户来说，只需从你的 Windows 分区复制即可。在这个项目中，我将解释如何执行第一种操作，所以如果你是一个没有安装 Windows 的 Ubuntu 用户（或使用 Synaptic 方法的双系统用户），这里你需要执行以下操作：

1. 运行软件包管理器（系统 ► 管理），并在提示时提供你的用户名。

2. 点击搜索按钮。在出现的搜索窗口中，输入 `mstcorefonts`，然后点击该窗口中的搜索按钮。

3. `mstcorefonts` 包现在应该出现在 Synaptic 主窗口的列表面板中，点击包名，在弹出菜单中选择“标记为安装”，然后按照第 5 章中学的通过 Synaptic 安装包的标准程序进行操作。

过程完成后，你的新微软字体将成功安装，并可供机器上的每个用户账户立即使用。

## 项目 11D：从你的 Windows 分区安装微软核心字体（针对双系统用户）

如果你是一个在硬盘另一个分区上安装了 Windows 的双系统用户，你可以利用 Windows 分区中已经拥有的字体。这可能像你在项目 11A 和 11B 中做的那样简单，也可能更困难，取决于你在第 9 章是否安装了 Automatis 读写 NTFS 和 FAT32 挂载器。如果你安装了它，你的 Windows 分区应该已经挂载，你可以直接跳到项目 11D-3。

如果你没有安装 Automatis M，你可以回去重新安装，也可以手动挂载你的 Windows 分区。如果你选择这种更繁琐的手动路线，请继续执行 11D-1。

### 11D-1：寻找你的 Windows 分区

在挂载 Windows 分区之前，你需要找到它在哪里，以及它是以什么文件系统格式化的，是文件分配表 (FAT) 还是新技术文件系统 (NTFS)。像 Linux 中一样，有几种方法可以实现。如果你喜欢命令行，可以打开终端窗口，输入 `sudo fdisk -l`（那是小写的 L，不是数字 J），然后按回车键。系统会提示你输入密码，输入后按回车。硬盘上的分区列表将出现（图 11-3）。

图 11-3：在 fdisk 表中寻找你的 Windows 分区

看看这个看似不可理解的列表，然后通过扫描列找到第一个带有硬盘 FAT32 或 NTFS 的条目，从而找到 Windows 分区在硬盘上的位置和格式。大多数情况下，这将是分区 `/dev/hda1`，但在图 11-3 所示的硬盘列表中，第一个分区被制造商 Windows 安装盘上的某个诊断工具占用了。如果你使用的是来自品牌制造商的电脑，你可能会发现自己处于类似的情况下。

一旦找到了 FAT32 或 NTFS 分区，记下文件系统类型，然后对列表最左侧的位置进行同样的操作。在我的案例中，那是 `/dev/hda2` 和 `FAT32`。

### 11D-2：挂载你的 Windows 分区

有了收集到的信息，你现在可以通过以下步骤挂载你的 Windows 分区：

1. 打开终端窗口，输入 `sudo mkdir /media/windows` 并按回车，为你的 Windows 分区创建一个挂载点。第一次尝试挂载分区时需要执行此步骤。之后，只需执行步骤 2 和 3 即可。

2. 在这一步中要做什么取决于你的 Windows 分区是 FAT32 还是 NTFS 格式。选择合适的步骤，如果你的 Windows 分区恰好是 `/hda2`，请确保将 `/hda1` 替换为 `/hda2`。

如果你的 Windows 分区是 FAT32 格式，输入：

```bash
sudo mount /dev/hda1 /media/windows/ -t vfat -o charset=utf8,umask=000
```

如果是 NTFS 格式，输入：

```bash
sudo mount /dev/hda1 /media/windows/ -t ntfs -o nls=utf8,umask=0222
```

3. 输入正确的条目后，按回车。如果要求输入密码，输入密码并按回车。Windows 分区将被挂载。你可以通过打开 Nautilus 窗口并点击该分区来双重检查。

### 11D-3：从你的 Windows 分区安装字体

现在你的 Windows 分区已经挂载，你可以复制你拥有的字体。开始时，Windows 的路径将是 `/media/windows`，但根据你使用的 Windows 版本可能会稍不同。

## 本地安装字体

要在本地安装字体，只需返回终端窗口。通过输入 `cp fontname.ttf /fonts/` 将你想要的字体复制到字体文件夹。如果你想要复制目录中的所有字体，可以使用 `*.ttf` 代替 `fontname.ttf`。
