要设置 `AMDGPU` 风扇配置，首先打开终端并输入 `sudo gedit /etc/amdgpu-fan.yml`。接下来，使用以下内容更新文件：

```yaml
speed_matrix:
  - [0, 0]
  - [30, 15]
  - [50, 30]
  - [70, 70]
  - [90, 100]
```

点击保存您的更改。

# `LibreOffice`

访问 `LibreOffice` 官方网站 `https://www.libreoffice.org/` 了解关于 `LibreOffice` 的所有信息。

通过软件管理器获取 `DEB`/`FLATPAK` 软件包：

打开软件管理器并搜索 `LibreOffice`。

点击 `LibreOffice`，然后点击源选择框。

选择系统软件包或 `Flatpak` 并点击安装。

在终端中通过 `APT` 安装 `LibreOffice`：

只需输入以下命令：

```bash
sudo apt update
sudo apt install libreoffice
```

通过 `Snap Store` 获取 `Snap` 软件包：

在 `Snap Store` 中查找 `LibreOffice`。

点击 `LibreOffice`，然后点击源选择框。

选择 `Snap` 下的最新/稳定版本并点击安装。

在终端中通过 `Snap` 安装 `LibreOffice`：

输入此命令：

```bash
sudo snap install libreoffice
```

## 在终端中通过 `Flatpak` 安装 `LibreOffice`：

输入此命令：

```bash
flatpak install flathub org.libreoffice.LibreOffice
```

# `Apache OpenOffice`

访问 `Apache OpenOffice` 官方网站 `BLANK` 了解关于 `Apache OpenOffice` 的所有信息。

通过 `GUI` 使用 `AppImage` 安装 `Apache OpenOffice`：

导航至发布页面：

`https://github.com/area-of-dev/OpenOffice.AppImage/releases`

点击“Assets”（资源）选项卡查看文件。

选择最新版本的 `OpenOffice.AppImage` 文件。

将文件下载到你的 `~/Downloads` 文件夹。

在 `Downloads` 文件夹中找到 `OpenOffice.AppImage` 文件，右键点击它并选择“属性”。

在属性菜单中，转到“权限”选项卡，并勾选“允许作为可执行文件”。

双击 `OpenOffice.AppImage` 文件开始安装过程。

从命令行和 `GUI` 创建 `Apache OpenOffice` `AppImage` `.desktop` 快捷方式：

要为 `Apache OpenOffice` `AppImage` 创建 `.desktop` 快捷方式，请在终端中执行以下步骤：

使用命令导航到应用程序目录：

```bash
cd /usr/share/applications
```

运行以下命令打开一个新的 `.desktop` 文件进行编辑：

```bash
sudo gedit openoffice1.desktop
```

在 `openoffice1.desktop` 文件中，输入以下详细信息：

```ini
[Desktop Entry]
Name=Apache OpenOffice
Comment=Apache OpenOffice
Exec=./Applications/OpenOffice.AppImage
Icon=terminal
Terminal=false
Type=Application
Categories=Utility;Game;
```

保存进度时，点击“保存”。或者，你可以点击“文件”，然后点击“保存”，或点击 `≡` 图标，选择“另存为”，最后点击“保存”。保存后关闭编辑器。
