## 第 8 章：命令行教程

现在你已经知道 Linux 是做什么的了，是时候开始实际使用它了。我们将从基本的命令行教程开始，但首先你需要知道如何打开终端。这并不难，但所有系统都不同，所以请将其仅作为指南使用：

- Mac 用户应该打开应用程序、实用工具，然后点击终端。快捷方式是按下 Command+Space，这将打开 Spotlight，之后你可以输入单词 Terminal。当结果显示出来时，点击该结果。
- Linux 用户应该在应用程序>系统或应用程序>实用工具中查找。快捷方式是右键点击桌面，查找“在终端中打开”选项。如果该选项存在，请点击它。
- Windows 用户可以简单地在开始菜单的搜索栏中输入单词 Command。点击命令提示符选项，它将直接带你进入。

如你所知，命令行是你输入命令并接收输出或反馈（作为文本）的地方。命令行以提示符开头，你输入的文字显示在该提示符之后。你的大部分工作将是命令工作，例如：

```
1. ls -l/home/Simon
2. total 3
3. drwxr-xr-x 2 Simon users 4096 Mar 23 13:34 bin
4. drwxr-xr-x 18 Simon users 4096 Feb 17 09:12 Documents
5. drwxr-xr-x 2 Simon users 4096 May 05 17:25 public_html
6.
```

让我们分解那段代码，看看它都意味着什么：

第 1 行始终以你的用户名@bash 提示符开头。我们也在那里放了一个命令 – `ls` – 并且命令总是你输入的第一个东西。紧随其后的是我们所有的命令行参数。要注意，命令和第一个参数之间必须始终有一个空格。第一个命令行参数是 (`-l`)，这被称为选项。

这些参数用于改变命令的执行方式。它们总是列在任何其他参数之前，并以连字符 (`-`) 开头。

第 2 至 5 行是运行你输入的命令后产生的输出。几乎所有命令都会产生输出，并且它总会紧跟在已发出的命令下方列出。少数命令仅执行不产生任何信息，除非发生错误。

第 6 行再次显示提示符。一旦命令运行完毕，终端便再次准备好接受输入，并显示提示符。如果没有显示提示符，那么该命令很可能仍在运行中。

## 快捷键

虽然终端起初可能显得有点让人望而生畏，但无需担心。Linux 内置了许多实用的快捷键，能大大简化操作，还能帮助你避免诸如拼写错误等失误。在讲解本章内容时，我会陆续介绍其中的一些，请在遇到时加以记录。

你的第一个快捷键是这样的——每次你输入一条命令时，它都会被存储到历史记录中，你可以通过使用上、下箭头键来翻阅这些历史记录。因此，你不必重新输入已经打过字的命令；如果需要再次输入相同的命令，只需使用箭头键找到它即可。如果你想编辑某条命令，请使用左右箭头键将光标移动到需要修改的位置。

## 基础导航

我们要查看的第一个命令是 `pwd`，即“打印工作目录”（Print Working Directory）的缩写。（许多 Linux 命令都被缩写以方便记忆。）该命令的作用正如其名——将当前工作目录打印到屏幕上。试一下：

```bash
pwd
```

```bash
/home/Simon
```

在终端输入的大多数命令只有在正确的位置才能正常工作。但因为你将在系统中四处移动，很容易迷路。只需在命令提示符处输入 `pwd`，就能告诉你当前位置，所以每当不确定时都应善用它。

接下来你可能想知道当前位置里有什么。用于查明此信息的命令是 `ls`，即“列表”（list）的缩写。

```bash
ls
```

```bash
bin Documents public_html
```

`pwd` 可以不带参数运行，而 `ls` 则拥有更多功能。在上例中，我们没有提供任何参数，因此只是列出了当前位置的内容。但你可以用更多方式操作它，例如：

```bash
ls [options] [location]
```

方括号 `[]` 表示其中的文本是可选的，因此该命令可以带或不带这些参数运行。下面的示例展示了以多种方式运行 `ls` 命令，以便让你了解它的功能：

```bash
ls
```

```bash
bin Documents public_html
```

这是最基础形式的 `ls`——结果列出当前目录的内容。

```bash
ls -l
```

```bash
total 3
drwxr-xr-x 2 Simon users 4096 Mar 23 13:34 bin
drwxr-xr-x 18 Simon users 4096 Feb 17 09:12 Documents
drwxr-xr-x 2 Simon users 4096 May 05 17:25 public_html
```

使用命令行选项 (`-l`) 运行 `ls` 表示我们要执行长列表显示，其内容包括：

- 第一个字符指示文件类型 – 普通文件 (`-`) 或目录 (`d`)
- 随后的九个字符是文件或目录的权限
- 下一个字段是块的数量
- 下一个字段指示文件或目录的所有者
- 下一个字段指示目录或文件所属的组
- 接着是文件大小
- 接着是文件修改时间
- 最后 是目录或文件的名称

```bash
ls /etc
```

```bash
a2ps.cfg aliases alsa.d cups fonts my.conf systemd
...
```

这一次，`ls` 是带有一个命令行参数 (`/etc`) 运行的，这告诉 `ls` 不应列出当前目录；而是应该列出该目录的内容。（省略号 (...) 表示部分输出被删减以节省空间；如果你实际运行此命令，将获得更长的目录和文件列表。）

```bash
ls -l /etc
```

```bash
total 3
-rwxr-xr-x 2 root root 123 Mar 23 13:34 a2ps.cfg
-rwxr-xr-x 18 root root 78 Feb 17 09:12 aliases
drwxr-xr-x 2 Simon users 4096 May 05 17:25 alsa.d
...
```

现在 `ls` 是带命令行选项和命令行参数一起运行的，结果是 `/etc` 目录的长列表。

## 路径

在上述最后的几个命令中，我们开始引入路径的概念。学习这些路径是什么以及如何运用它们至关重要，因为在未掌握这一点之前，你无法精通 Linux 语言。当我们在命令行讨论某个目录或文件时，我们谈论的就是一个路径。就像在现实世界中一样，路径是到达某处的方式，在这里是指系统中特定的目录或文件。

### 绝对路径与相对路径

我们使用两种不同的路径——绝对路径和相对路径——来引用目录或文件。两者都可以使用，因为它们都会带你到达系统中的同一位置。首先，你需要了解 Linux 具有所谓的分层结构。最顶端是根目录，由单个斜杠 (`/`) 表示。根目录包含子目录，这些子目录又有自己的子目录，依此类推。其中任何一个子目录都可以包含文件。

绝对路径指定相对于根目录的特定文件或目录。它们可以通过都以斜杠开头这一特征来识别。相对路径指定相对于你在系统中当前位置的文件或目录，并且不以斜杠开头。

看看这个例子：

```bash
pwd
```

```bash
/home/Simon
```

通过运行 `pwd` 确认当前位置。

```bash
ls Documents
```

```bash
file1.txt file2.txt file3.txt
...
```

现在 `ls` 是带有相对路径运行的。当前位置是 Documents 目录，但此命令的结果取决于你在系统中的位置。如果你在其他系统用户的家目录中，它会为你提供该用户 Documents 目录内容的列表。
