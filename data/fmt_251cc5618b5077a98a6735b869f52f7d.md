参见 `environ(5)` 以了解以下影响 `make` 执行的环境变量的描述：`LC_CTYPE`、`LC_MESSAGES` 和 `NLSPATH`。

`KEEP_STATE` 产生与 `.KEEP_STATE` 特殊函数目标相同的效果。启用命令依赖、隐藏依赖以及状态文件的写入。

`USE_SVR4_MAKE`

调用一个代表系列选项的字符字符串 (`/usr/ccs/lib/svr4.make`)。参见 `SysV-make(1)`。

`MAKEFLAGS` 指定一个代表用作默认选项的一系列选项字符的字符串。该实现接受以下两种格式（但不要求混合使用）：

- `-` 字符是选项字母，没有前导横字符，也不使用命令行中的空白字符分隔。
- 字符的格式类似于 `make` 命令行的一部分：选项以横字符开头并用 `-` 字符分隔。也可以包含 `macro=name` 宏定义操作数。`MAKEFLAGS` 的内容与命令行之间的区别在于，变量的内容不受与解析命令行值相关的词法展开 (`wordexp(3)`) 影响。

当你使用命令行选项 `-f` 或 `-p` 时，无论它们是否出现在 `MAKEFLAGS` 中，都会生效。如果它们在其他地方出现在 `MAKEFLAGS` 中，则结果是未定义的。

在读取 `makefile` 之前，会从环境中访问 `MAKEFLAGS` 变量。此时，所有选项（`-f` 和 `-p` 除外）以及尚未被包含在 `MAKEFLAGS` 中的命令行宏都会添加到 `MAKEFLAGS` 宏中。`MAKEFLAGS` 宏将作为环境变量传递给所有子进程。如果随后由 `makefile` 设置了 `MAKEFLAGS` 宏，它将替换环境变量中当前找到 `MAKEFLAGS` 变量。

## 退出状态

当你指定 `-q` 选项时，`make` 命令以以下值之一退出。

- `0` 成功完成。
- `1` 目标不是最新的。
- `>1` 发生错误。

当你未指定 `-q` 选项时，`make` 命令以以下值之一退出。

- `0` 成功完成。
- `>0` 发生错误。

# 源码格式

参考手册页使用 `nroff(1)` 或 `sgml(5)`（标准泛化标记语言）标记进行标记。`man` 命令会识别标记类型并据此处理文件。各种源文件根据标记类型存储在不同的目录中。

# 手册页的位置

在线参考页目录传统上位于 `/usr/share/man/`。`nroff` 源码位于 `/usr/share/man/man*` 目录中。`SGML` 源码位于 `/usr/share/man/sman*` 目录中。每个目录对应手册的一个章节。由于这些目录是可选安装的，它们可能并不存在于你的主机上；你可能需要从包含这些目录的主机上移动 `/usr/share/man`。

如果在相应的 `cat*` 或 `fmt*` 目录中存在预格式化的、更新的版本，则会使用它们。如果感兴趣的预格式化版本过时或缺失，`man` 将在显示之前进行重新格式化，如果 `cat*` 或 `fmt*` 可写，则会存储预格式化版本。`windex` 数据库不会更新。请参阅 `cat(1)`。如果没有提供这些目录，`man` 在每次请求时都会重新格式化页面；它使用临时文件在显示期间存储格式化后的文本。

如果标准输出不是终端或你指定了 `-t` 选项，`man` 将输出通过管道 `cat(1)`；否则，`man` 将输出通过管道 `more(1)` 以处理屏幕上的分页和下划线。

## 选项

- `-t` 将输出通过管道 `cat(1)` 而不是 `more(1)`。
- `-a` 按照 `MANPATH` 搜索路径中匹配名称的显示所有手册页。
- `-d` 显示章节指定符求值结果、使用的搜索方法以及 `man` 搜索的路径。
- `-f file...` 定位与任何文件相关的手册页。剥离每个文件开头的路径名称组件，并打印包含结果文件名或名称的单行摘要。此选项使用 `windex` 数据库。
- `-F` 强制 `man` 搜索 `MANPATH` 或 `man.cf` 文件指定的所有目录，而不是使用 `windex` 查找数据库。如果数据库没有更新，此选项非常有用。如果 `windex` 数据库不存在，则假设使用此选项。

# man 817

- `-k keyword...` 从 `windex` 数据库（目录）中打印包含任何给定关键词的单行摘要。`windex` 数据库通过 `catman(1)` 创建。
- `-l` 列出搜索路径中找到的匹配名称的所有手册页。
- `-M path` 为手册页指定备用搜索路径，路径是用于冒号分隔的包含手册页目录的目录列表。例如，如果 `path` 为 `/usr/share/man:/usr/local/man`，`man` 将先在标准位置查找名称，然后在 `/usr/local/man` 查找。当与 `-k` 或 `-f` 选项配合使用时，`MM` 必须放在第一个。假设路径中的每个目录都包含每个章节的 `section*` 格式子目录。此选项覆盖 `MANPATH` 环境变量。
- `-r` 重新格式化手册页但不显示。此选项取代了 `man -t name` 的组合。
- `-s section...` 指定 `man` 搜索的手册章节。搜索名称的目录限制为 `section` 指定的章节。`section` 可以是一个数字（后面可能紧跟一个或多个字母）、一个单词（例如：`local`, `new`, `old`, `public`）或一个字母。要指定多个章节，请用逗号隔开。此选项覆盖 `MANPATH` 环境变量和 `man.c` 文件。
- `-t` 使用 `scrot` 处理并将手册页发送到合适的光栅输出设备（参见 `scrot(1)`）。如果你同时使用 `-f` 标志，`man` 将更新每个 `man` 名称的版本（如果需要），但不会显示页面。
- `-T macro-package` 使用宏包格式化手册页，而不是使用 `/usr/share/lib/tmac` 中定义的标准 `-man` 宏。

> 注意 — `-f` 和 `-k` 选项使用 `windex` 数据库，该数据库由 `catman(1)` 创建。

### 操作数

`name`: 关键词或标准命令的名称。

## 用法

# 手册章节

参考手册中的条目组织成章节。章节名称由主章节名称（通常是单个数字）和可选的子章节名称（通常是一个或多个字母）组成。例如，命令 `ls(1)` 位于章节 `(1)` 用户命令，属于 `BSD` 兼容包子章节。修饰的主章节作为同名章节及其所有子章节的缩写。

# 搜索路径

在搜索名称之前，`man` 会构建一个候选目录列表。如果没有设置 `MANPATH`，则默认搜索 `/usr/share/man`。在目录内部，`man` 按以下顺序查找章节：

- 命令行上指定的章节。
- `MANPATH` 环境变量中指定的章节。
- `man.cf` 文件中指定的章节。
