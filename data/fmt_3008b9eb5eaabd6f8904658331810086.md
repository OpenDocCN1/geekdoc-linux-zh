## 任务 11.8：vi 中的冒号命令

在没有太多解释的情况下，你学习了一些冒号命令，即以冒号作为第一个字符的命令。冒号会立即光标移动到屏幕底部以便进一步输入。这些命令实际上是一个很大命令范围的子集，都属于基于 vi 的 ex 编辑器。最有用的命令如下：

## vi 编辑器简介

| 命令 | 功能 |
| --- | --- |
| `q` | 退出编辑器。 |
| `q!` | 无论是否发生更改，均退出。 |
| `r filename` | 将指定文件的内容包含在当前正在编辑的文件此处位置。 |
| `w` | 将文件保存到磁盘。 |
| `w filename` | 以指定的指定保存文件到磁盘。 |
