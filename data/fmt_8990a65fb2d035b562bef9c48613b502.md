
`d` 命令不仅可以删除文本，还会“剪切”文本。每当我们使用 `d` 命令时，删除的内容都会复制到粘贴缓冲区（想象成剪贴板）中，我们稍后可以使用 `p` 命令调回它，从而在光标之前或之后粘贴缓冲区的内容。

`y` 命令用于“提取”（复制）文本，其用法与 `d` 命令剪切文本相同。表 12-4 提供了了一些使用各种移动命令进行操作的示例。

## 表 12-4：复制命令（Yanking Commands）

| 命令 | 复制内容 |
|---|---|
| `yy` | 当前行 |
| `5yy` | 当前行及后续四行 |
| `yw` | 从当前光标位置到当前行首 |
| `y$` | 从当前光标位置到当前行尾 |
| `yo` | 从当前光标位置到行首 |
| `y^` | 从当前光标位置到该行第一个非空白字符 |
| `yG` | 从当前行到文件末尾 |
| `y20G` | 从当前行到文件的第 20 行 |

让我们尝试一些复制和粘贴。将光标放在文本的第一行，并输入 `yy` 复制当前行。接下来，将光标移动到最后一行（`G`），并输入 `p` 在当前行下方粘贴该行。

```
The quick brown fox jumped over the lazy dog. It was cool.
Line 2
Line 3
Line 4
Line 5
```

敏捷的棕色狐狸跳过了只懒狗。它很酷。

和之前一样，`u` 命令将撤销我们的更改。当光标仍停留在文件的最后一行时，输入 `P` 在当前行上方粘贴文本。

```
The quick brown fox jumped over the lazy dog. It was cool.

```

尝试表 12-4 中的其他 `y` 命令，并了解 `p` 和 `P` 命令的行为。操作完成后，请将文件恢复到原始状态。

## 合并行

`vi` 对其“行”的定义相当严格。通常情况下，无法将光标移动到行尾并删除行尾字符来将一行与其下方的一行合并。由于由于，`vi` 提了一个特定的命令 `J`（不要与用于光标移动的 `j` 混淆）来将行合并。

如果我们把光标放在第 3 行并输入 `J` 命令，会发生以下情况：

```
The quick brown fox jumped over the lazy dog. It was cool.
Line 2
Line 3 Line 4
Line 5
```

## 搜索与替换

`vi` 具有根据搜索将光标移动到特定位置的能力。它可以在单行上进行，也可以在整个文件中进行。它还可以在用户确认或不确认的情况下执行文本替换。

### 行内搜索

`f` 命令搜索某行并将光标移动到指定字符的下一个出现处。例如，命令 `fa` 将光标移动到当前行内字符 `a` 的下一个出现处。在行内执行字符搜索后，可以通过输入分号来重复搜索。

### 搜索整个文件

要将光标移动到单词或短语的下一个出现处，使用 `/` 命令。这与我们之前在 `less` 程序中学习的方法相同。接下来，当你输入 `/` 命令时，屏幕底部会显示一个 `/`。接着输入要搜索的单词或短语，然后按回车。光标将移动到包含搜索字符串的下一个位置。可以使用 `n` 命令使用上一次搜索字符串重复搜索。这是一个示例：

```
The quick brown fox jumped over the lazy dog. It was cool.
Line 2
Line 3
Line 4
Line 5
```

> 将光标放在文件的第一行。输入以下并按回车：
>
> `/Line`
>
> 光标将移动到第 2 行。接下来，输入 `n`，光标将移动到第 3 行。重复 `n` 命令将使光标向下移动文件，直到没有匹配项为止。虽然目前为止我们的搜索模式只使用了单词和短语，但 `vi` 允许使用正则表达式，这是一种表达复杂文本模式的强大方法。我们将在第 19 章详细介绍正则表达式。

## 全局搜索与替换

`vi` 使用 `ex` 命令对范围范围或整个文件执行搜索与替换操作（在 `vi` 中称为替换）。要将整个文件中的单词 `Line` 更改为 `line`，我们需要输入以下命令：

```
%s/Line/line/g
```

让我们将此命令分解为各个项目并查看每个项目的作用（参见表 12-5）。

## 表 12-5：全局搜索与替换语法示例

| 项目 | 含义 |
|---|---|
| `:` | 冒号字符启动命令。 |
| `%` | 这指定了操作的行范围。`%` 是从第一行到最后一行的简写。或者，范围也可以指定为 `1,5`（因为我们的文件有五行）或 `1,$`，意味着“从第 1 到文件的最后一行”。如果省略行范围，则仅对当前行执行操作。 |
| `s` | 这指定了操作。在这种情况下是替换（搜索并替换）。 |
| `/Line/line/` | 这指定了搜索模式和替换文本。 |
| `g` | 这意味着“全局”，意味着在行内对所有匹配项执行操作。 |

虽然我们可以从一个文件移动到另一个文件，但 `vi` 强制执行策略：如果当前文件有未保存的更改，则阻止切换文件。要强制 `vi` 切换文件并放弃更改，请在命令后添加一个感叹号 (`!`)。

除了已经描述的切换方法外，`vim`（以及 `vi` 的某些版本）提供了一些更容易管理多个文件的命令。我们可以通过 `:buffers` 命令查看编辑过的文件列表，它将在屏幕底部显示文件列表。

```
:buffers
1 % "foo.txt" line 1
2 "ls-output.txt" line 0
Press ENTER or type command to continue
```

要切换到另一个缓冲区（文件），输入 `:buffer` 后跟你想要编辑的缓冲区编号。例如，要将文件 `foo.txt` 切换到包含文件 `ls-output.txt` 的缓冲区 2，我们使用以下类型：

```
:buffer 2
```

我们的屏幕现在显示第二个文件。另一种更改缓冲区的方法是使用之前提到的 `:bn`（buffer next 的缩写）和 `:bp`（buffer previous 的缩写）命令。

## 打开额外的文件进行编辑

还可以将文件添加到当前的编辑会话中。命令 `:edit`（"edit" 的缩写）后跟文件名将打开一个额外的文件。让我们结束当前的编辑会话并返回命令行。

仅一个文件启动 `vi`。

```
[melinuxbox ~]$ vi foo.txt
```

要添加我们的第二个文件，输入以下内容：

```
:edit ls-output.txt
```

它应该出现在屏幕上。我们可以验证的是，第一个文件仍然存在。

```
:buffers
1 # "foo.txt" line 1
2 % "ls-output.txt" line 0
Press ENTER or type command to continue
```

## 将内容从一个文件复制到另一个文件
