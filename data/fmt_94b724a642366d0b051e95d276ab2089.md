如果进行了替换，则将模式空间追加写入 `wfile`。第一次调用 `w` 会清空 `wfile`。后续调用 `w` 则会追加。每次使用 `sed` 命令时，`wfile` 都会被覆盖。

2

`y/string1/string2/`

将 `string1` 中所有字符的出现替换为 `string2` 中对应的字符。`string1` 和 `string2` 的字符数必须相同；如果 `string1` 中的任何字符出现超过一次，则结果是未定义的。你可以使用任何字符作为分隔符，而不是使用反斜杠（`\`）和换行符来分隔字符串。在 `string1` 和 `string2` 中，如果分隔符前面有反斜杠，可以使用分隔符本身作为字面字符。例如，`y/abc/ABC` 会将 `a` 替换为 `A`，将 `b` 替换为 `B`，将 `c` 替换为 `C`。

参见 `largefile(5)` 以了解 `sed` 在遇到大于或等于 2 Gbytes (`2**31` 字节)的文件时的行为描述。

## Examples

```
sed -n '

d}
# 写入一个空行，然后寻找更多空行。
^$
np
# 获取下一行，丢弃保留的换行符（空行）
# 并寻找更多空行。
:Empty
/^$
{
s////
b Empty
}
# 在返回 sed 行为之前写入非空行
# 针对一组空行中的第一个。
np
```

## Description

### Bourne Shell

Bourne shell `set` 命令具有以下选项。

- `-a` 将修改或创建的变量标记为导出。
- `-e` 如果命令以非零退出状态退出，则立即退出。
- `-f` 禁用文件名生成。
- `-h` 在定义函数时定位并记住函数命令（函数命令通常在执行函数时定位）。
- `-k` 将所有关键字参数放入命令的环境中，而不仅仅是命令名之前的参数。
- `-n` 读取命令但不执行。
- `-t` 在读取并执行一个命令后退出。
- `-u` 在替换时将变量视为错误。
