
# 构建 Linux 内核

### 1. 从 `kernel.org` 获取最新的内核源代码。

### 2. 将存档解压到目录并 `cd` 进入该目录：

```bash
tar xf linux-*.tar.xz
cd linux-*
```

### 3. 构建 `ncurses` 配置界面：

```bash
make menuconfig
```

### 4. 要接受默认配置，按 `→` 高亮显示 `< Exit >`，然后按 `Return`。

### 5. 再次按 `Return` 保存配置。

### 6. 使用 `make` 构建内核：

```bash
make
```

请注意，您可以使用 `-j` 标志并行编译文件并利用多核优势。

压缩的内核镜像可以在 `arch/[arch]/boot/bzImage` 中找到，其中 `[arch]` 等于 `uname -a`。
