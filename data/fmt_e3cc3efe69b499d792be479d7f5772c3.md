# 第 17 章：进程与线程

### 异常

在编写多线程程序时，任何未被捕获的异常都会导致线程终止。因此，捕获所有异常对于追踪意外情况和程序缺陷至关重要。即使使用了 `OnTerminate` 事件处理程序，在 `Execute` 方法中捕获异常也能节省时间，因为在 `OnTerminate` 事件中无法获取异常信息。

```go
procedure TThread.Execute;
begin
try
// 线程代码将在此此处
except
on e : exception do
begin
// 妥善地处理异常
// 记录日志、通知用户等
end;
end;
end;
```
