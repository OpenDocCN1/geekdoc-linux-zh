# 管理磁盘空间 第17 章

# 磁盘空间信息

> 磁盘空间不足是非常严重的问题
许多 UNIX 命令和程序需要创建新文件或扩大现有文件。如果文件系统磁盘空间耗尽，这些程序可能会终止，导致更新部分完成。有时将文件恢复到一致状态的方法是从上次备份中恢复所有文件。

要评估文件系统上的可用空间，你可以使用 `df` 命令。如果你想了解所有文件系统的细节，可以使用不带选项的命令：

```
df
```
