## 6.4 进程控制

`ps status` 显示当前运行的进程列表及其进程 ID (`PID`)。使用 `ps axu` 查看系统上的所有进程。

`fg` 将后台进程带到前台。

`bg` 将进程发送到后台。`fg` 的相反。

`any_command&` 在后台运行任何命令。符号 `"&"` 表示后台运行。

`kill PID` 强制停止进程。确定要杀死的进程 `PID`。

`killall` 按名称杀死程序。`programname`（在 `xwindow` 中）杀死 `GUI` 程序。用鼠标指向你想杀死的窗口。

`lpc`（作为 `root`）检查并控制进程。使用 `"top"` 查看可用命令列表。

`job_number` 从队列中移除打印作业。

`nice` 运行程序并调整其优先级。由于示例中未指定优先级，它将被调整 `10`（默认值为 `0`）。`nice` 值越低，优先级越高。优先级值范围为 `-20` 到 `19`。只有 `root` 可以设置负值。使用 `"top"` 显示运行进程的优先级。

`renice -1 PID`（作为 `root`）将进程优先级改为 `-1`。普通用户只能调整其拥有的进程的当前值。

请注意以下快捷键：`<Ctrl>c`、`<Ctrl>z`、`<Ctrl>s` 和 `<Ctrl>q`。它们之前描述过。

## 6.5 管理命令

- `prntool`（作为 `root` `X-terminal`）打印机配置工具。设置位于文件 `/etc/printcap`。
- `setup`（作为 `root`）配置鼠标、声音、键盘、`X-windows`、系统服务。
- `linuxconfig`（文本或图形界面）。你可以通过它更改数百种设置。非常强大——不要同时更改许多项，并谨慎更改你不懂的内容。
- `xvolume`（在终端中）。调整图形显示设置以消除黑边，左右移动显示，使用调整适应你的显示器以适应文本模式。要使更改永久生效，在屏幕上显示频率。
- 为 `"ls"` 命令设置别名以增强色彩格式。在示例中，该别名也称为 `"alias"`。将别名放入 `/etc/bash`，如果你希望系统上的所有用户始终可以使用。输入 `"alias"` 查看系统上的别名列表。
- 创建新账户（需要 `root`）。例如：`adduser password`
- `adduser user_name` 不要忘记在系统中为新用户设置密码。主目录为 `/home/user_name`。
- `useradd user_name` 等同于命令 `"adduser user_name"`
- `userdel name` 删除一个账户（你必须是 `root` 用户）。用户的家目录和未投递的邮件必须单独处理。
- `groupadd` 在你的系统中创建一个新组。对于用户数量较少的家用机器，此命令不是必须的。
- `passwd group_name` 修改你当前账户的密码。如果你是 `root`，可以使用 `user_name` 更改任何用户的密码。
- `chmod`（-更改模式）更改你所拥有文件的访问权限（除非你是 `root`，在这种情况下你可以更改任何文件）。你可以通过三种模式使文件可访问：读 (`r`)、写 (`w`)、执行 (`x`)，适用于三类用户：所有者 (`u`)、所有者所在组的成员 (`g`)、系统上的其他用户 (`o`)。使用以下命令检查当前访问权限：

```
ls -l filename
```

如果对所有用户都可访问，它将显示：

三元组显示了文件所有者的权限、文件所属组的权限，第三个是针对其他人的权限。“无权限”将向对读取文件“`junk`”的权限添加到所有用户（=`user`+`groups`）：

```
chmod a+ junk
```

这将移除 `junk` 文件的执行权限：

```
chmod o-x junk
```

也可以在此处尝试获取更多信息。

你可以使用命令 `umask` 为你创建的新文件设置默认权限（参见 `man umask`）。

- `chown new_owner filename` 更改文件所有者。当你复制一个文件供他人使用后，应该使用这两个命令。
- `chgrp new_group filename`（替换 `id`）假设是超级（`root`）身份（将提示你输入密码）。输入 `"exit"` 返回原来的位置。不要在你的机器上以 `root` 身份工作。`root` 账户用于管理，`sudo` 命令确保你在需要时具有管理访问权限。
- `rpm -ivh filename.rpm`（=`RedHat` 软件包，安装，显示哈希以显示进度，以 `root` 身份运行。）安装 `RedHat` `rpm` 包的内容并打印发生情况的信息。如果你正在进行 `GUI` 安装，则可以保留它。
- `rpm -qpi filename.rpm`（=`RedHat` 软件包，查询， 软件包, 列表。）读取未安装的 `package.rpm` 内容的信息。
- `rpm -ql filename.rpm`（=`RedHat` 软件包，查询， 软件包, 信息。）查找未安装的软件包文件名（在你的硬盘上）中包含包含的文件。
- `rpm -e packagename`（=`RedHat` 软件包，删除-卸载。）安装包。`Packagename` 与 `.rpm` 相同（不带连字符和版本号）。

（在 `X` 终端中，假设你能够安装这三个。使用这三个命令来查看可用的软件包 ：`RedHat` 软件包管理器 (`rpm`)、带有 `RH2.2` 的行、带有 `RH6.0` 的 `"gop"`、`package` 必须在你的系统中单独安装、`RedHat` `CD` 上可用的未安装软件包、显示它们的信息，并在如果你需要时安装它们（安装必须以 `root` 身份进行）。
