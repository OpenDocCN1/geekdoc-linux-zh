
# Shell 编程示例集

## 1. 打印指定范围内的素数

```bash
cat > prime.sh
echo "Enter lower Limit"
read x1
echo "Enter Higher Limit"
read x2
while [ $x1 -le $x2 ]
do
    i=2
    while [ $i -le $x1 ]
    do
        if [ $(expr $x1 % $i) -eq 0 ]
        then
            break
        else
            i=$(expr $i + 1)
        fi
    done
    if [ $i -eq $x1 ]
    then
        echo $x1
    fi
    x1=$(expr $x1 + 1)
done
```

## 2. 判断闰年

```bash
cat > leap.sh
year=0
echo "Enter Year:"
read year
if [ $year -eq 0 ]
then
    da=$(date "+%Y")
    year=$da
fi

    echo "The Year $year is Leap Year"

    echo "The Year $year is Not Leap Year"
fi
```

## 13.5 条件语句

`awk` 还提供了非常类似于 C 语言的 `if` 语句。如果你愿意，可以使用 `if` 语句重写之前的脚本：

```awk
{
    if ( $5 ~ /root/ ) {
        print $3
    }
}
```

使用 `if` 语句，我们还可以转换这段代码：

```awk
{
    if ( $0 ~ /matchme/ ) {
        print $1 $3 $4
    }
}
```

这两个脚本都只输出不包含 `matchme` 序列的行。同样，你可以选择适合你代码的方法。它们的作用相同，`awk` 还允许使用布尔运算符 `||`（表示“逻辑或”）和 `&&`（表示“逻辑与”）来创建更复杂的布尔表达式：
`($1 == "foo") && ($2 == "bar") { print }`

## 13.6 AWK 中的循环

`for` 循环和 `while` 循环用于 `awk` 中的循环目的。

### for 循环的语法

```
for (expr1; condition; expr2)
{
    Statement 1
    Statement 2
    Statement N
}
```

语句会重复执行，**直到**条件为真。在第一次迭代**之前**，会评估 `expr1`。这通常用于初始化循环变量。在循环每次迭代**之后**，会评估 `expr2`。这通常用于递增循环计数。

示例 `al.awk`：

```awk
BEGIN {
    printf "Press ENTER to continue with for loop example from LSST v1.05r3\n"
}
{
    sum = 0
    i = 1
    for (i=1; i<=10; i++) {
        sum += i; # sum = sum + i
    }
    printf "Sum for 1 to 10 numbers = %d \nGoodbuy!\n\n", sum
    exit 1
}
```

运行方式：
```bash
awk -f al.awk
```

输出：
```
Press ENTER to continue with for loop example from LSST v1.05r3
Sum for 1 to 10 numbers = 55
Goodbuy
```

上面的循环打印了 1 到 10 之间所有数字的和。它使用 `i` 从 1 到 10 取数字，并将其加到变量中，即 `sum = 之前的和 + 当前数字（即 i）`。

考虑另一个 `for` 循环示例 `for_loop`：

```awk
BEGIN {
    printf "To test for loop\n"
    printf "Press CTRL + C to stop\n"
}
{
    for (i=0; i<NF; i++) {
        printf "Welcome %s, %d times.\n", ENVIRON["USER"], i
    }
}
```

运行示例（输入 `Welcome to Linux!`）：
```bash
awk -f for_loop
```

输出：
```
To test for loop
Press CTRL + C to Stop
Welcome to Linux!
Welcome Anoop, 0 times.
Welcome Anoop, 1 times.
Welcome Anoop, 2 times.
```

## 13.7 启动与清理操作 (BEGIN & END)

`BEGIN` 规则只执行一次，在读取第一个输入记录之前。同样地，`END` 规则只执行一次，在读取完所有输入后。

示例：
```bash
awk '
BEGIN { print "Analysis of \"foo\"" }
/foo/ { ++n }
END { print "\"foo\" appears", n, "times." }' BBS-list
```

输出：
- Analysis of foo
- "foo" appears 4 times.

此程序查找输入文件 `BBS-list` 中包含字符串 `foo` 的记录数。`BEGIN` 规则为报告打印标题。不需要使用 `BEGIN` 规则将计数器 `n` 初始化为零，因为 `awk` 会自动这样做。第二个规则在每次读取到包含模式 `foo` 的记录时增加 `n` 的值。`END` 规则在运行结束时打印 `n` 的值。

特殊模式 `BEGIN` 和 `END` 不能在范围或与布尔运算符一起使用。`awk` 程序可以有多个 `BEGIN` 和/或 `END` 规则。它们按照出现的顺序执行：启动时执行所有的 `BEGIN` 规则，终止时执行所有的 `END` 规则。`BEGIN` 和 `END` 规则可以与其他规则混合。此功能是在 1987 版本的 `awk` 中引入的，并包含在 POSIX 标准中。

### while 循环

```awk
while (condition)
{
    statement1
    statement2
    statementN
}
```

示例 `while_loop`：

```awk
BEGIN {
    printf "To test while loop\n"
    printf "Press CTRL + C to stop\n"
}
{
    i = 0
    while (i < NF) {
        printf "Field %d: %s\n", i, $i
        i++
    }
}
```

运行方式：
```bash
awk -f while_loop
```

输出示例（输入 `Welcome to Linux!`）：
```
To test while loop
Press CTRL + C to stop
Field 0: Welcome
Field 1: to
Field 2: Linux!
```

## 13.8 内置变量

大多数 `awk` 变量都可以供你使用；除非你的程序为其赋值，否则它们永远不会被设置。然而，有少数变量具有特殊的内置含义。某些是自动设置的，因此允许你携带信息。分类如下：

- **用户定义**：你更改的内置变量。
- **自动设置**：`awk` 赋予你的内置变量。
- **ARGC 和 ARGV**：使用 `ARGC` 和 `ARGV` 的方法。

### 13.8.1 控制 awk 的内置变量

这是一个按字母顺序排列的列表，你可以更改它们来控制 `awk` 如何执行某些操作。

- `CONVFMT`：此字符串控制数字到字符串的转换。它通过作为 `sprintf` 函数的第一个参数传递来起作用。它的默认值为 `"%.6g"`。
- `FS`：这是字段分隔符。它的默认值是一个包含单个空格的字符串，这意味着输入记录由单行文本组成。
- `OFMT`：此字符串控制用于 `print` 语句的数字到字符串的转换。它通过作为 `sprintf` 函数的第一个参数传递来起作用。它的默认值为 `"%.6g"`。
- `OFS`：这是输出字段分隔符。它输出在 `print` 语句输出的字段之间。它的默认值是 `""`，一个由单个空格组成的字符串。
- `ORS`：这是输出记录分隔符。它位于每个 `print` 语句的末尾。它的默认值为 `"\n"`。
- `RS`：这是 `awk` 的输入记录分隔符。它的默认值是一个包含单个换行符的字符串，这意味着输入记录由单行文本组成。它也可以是空字符串，在这种情况下记录由连续空行隔开；或者是一个正则表达式，在这种情况下通过输入文本中的正则表达式来匹配记录。

### 13.8.2 传递信息的内置变量

这是一个按字母顺序排列的列表，这些变量在特定情况下由 `awk` 自动设置，以便为你的程序提供信息。

- `ARGC`：`awk` 程序可用的命令行参数数量。
- `ARGV`：`awk` 程序可用的命令行参数数组。
- `SUBSEP`：`SUBSEP` 是下标分隔符。它的默认值为 `"\034"`。

# Unix Shell 编程

`ARGC` 是存在的命令行参数的数量。与大多数 `awk` 数组不同，`ARGV` 的索引从 `0` 到 `ARGC-1`。

示例：
```awk
BEGIN {
  for (i = 0; i < ARGC; i++)
    print ARGV[i]
}
```

运行命令：
```bash
awk -f script.awk inventory-shipped BBS-list
```

输出：
```
awk
inventory-shipped
BBS-list
```

在这个示例中，`ARGV[0]` 包含 `"awk"`，`ARGV[1]` 包含 `"inventory-shipped"`，而 `ARGV[2]` 包含 `"BBS-list"`。`ARGC` 的值为 `3`，比 `ARGV` 中最后一个元素的索引多一，因为元素是从零开始编号的。

以下片段通过处理 `ARGV` 来检查并移除命令行选项：

```awk
BEGIN {
  for (i = 1; i < ARGC; i++) {
    # 处理逻辑
  }
}
```
