## lastcomm — 显示最后执行的命令

### 概要

```
/usr/bin/lastcomm [command-name] [user-name] [terminal]
```

## 描述

`lastcomm` 命令显示之前执行的命令信息。不带参数的 `last` 显示所有。如果你指定了命令、用户或终端，`lastcomm` 只显示匹配这些条目。

对于每个条目，`lastcomm` 显示：

- 调用时的命令名称。
- 一个或多个指示进程是否执行了 fork 但以 setuid 运行的标志。
- 运行进程的用户名。
- 进程使用的 CPU 时间（秒）。
- 进程退出的日期。

## 示例

以下命令使用终端 `/01` 列出了 `a.out` 的所有执行。

```
castle% lastcomm a.out root /01
```

以下命令列出了 `root` 执行的所有。

```
example% lastcomm
```

## ld - 对象文件的链接器

## 描述

`ld` 命令是对象文件的链接器。它通常由编译器命令 `cc` 自动调用。

`ld` 命令合并可定位对象文件，执行重定位并解析外部符号。`ld` 以两种模式运行，静态或动态，如

# ld

# 645

由 `-d` 选项控制。使用 `-dn` 指定静态模式，使用 `-dy` 指定动态模式。

在 `-dn` 静态模式下，作为参数指定的多个重定位对象文件将被合并并生成一个可执行对象文件。如果你指定了 `-r` 选项，可重定位对象文件将被合并生成一个可重定位对象文件。

在 `-dy` 动态模式（默认）下，你作为参数指定的多个重定位对象文件将被合并生成一个共享文件，该文件在执行时将与你作为参数指定的任何共享对象文件链接。如果你指定了 `-G` 选项，可重定位对象文件将被合并生成一个共享对象。在所有情况下，`ld` 的输出默认保存在为 `a.out`。

如果任何参数是库，`ld` 会在参数列表中遇到该库时恰好搜索一次。该库可以是可重定位归档（archive），也可以是共享对象。对于归档库，`ld` 只加载那些定义了未解析外部引用的例。`ld` 会按顺序搜索归档库符号表，进行若干次扫描，直到通过库成员解析外部引用。参见 `ar(4)`。因此，除非存在多个定义相同外部符号的库，否则库中成员的顺序在功能上是无关。

共享对象由一个不可分割的整体组成，该整体是由一个或多个文件的链接编辑生成的。当链接编辑器处理共享对象时，共享对象的全部内容将成为结果输出文件的逻辑部分。在链接编辑期间，共享对象不会被物理复制，因为其包含被延迟到进程执行阶段。这种逻辑包含意味着共享对象中定义的所有符号条目都对链接编辑过程可用。

没有特定的选项告诉 `ld` 去链接 64 位对象；由 `ld` 处理的第一个对象的类型决定了它是应该执行 32 位还是 64 位的链接编辑。

## 选项

- `-a` 在静态模式下，生成一个可执行对象文件。针对未定义的引用显示错误（静态模式的默认设置）。你不能将 `-a` 与 `-r` 选项一起使用。
- `-b` 仅在动态模式下，在创建可执行文件时，不对引用共享对象中符号的重定位进行特殊处理。如果没有 `-b` 选项，则会为共享对象中定义的函数创建特殊的位置无关重定位，并安排共享对象中定义的数据对象由运行时链接器复制到可执行文件的内存映像中。使用 `-b` 选项，输出代码可能更高效，但共享性较低。
- `-B static` 控制库包含的选项。`-B dynamic` 仅在动态模式下有效。你可以在命令行上多次指定这些选项作为切换器：如果你使用 `-B static` 选项，在看到 `-B dynamic` 之前不会接受任何共享对象。另见 `-l` 选项。
- `-B eliminate` 不要将任何全局符号分配给要从符号表中消除的版本定义。此选项实现的符号消除效果与 `mapfile` 版本定义中提供的自动消除（auto-elimination）指令相同。
- `-B group` 将一个共享对象及其依赖项建立为一个组。组内的对象在运行时绑定到组内的其他成员。包含此选项的对象的运行时处理模拟了通过 `dlopen(3)` 以 `RTLD_GROUP` 模式将对象添加到进程的情况。由于组必须是自包含的，因此使用 `-B group` 同时也断言了 `-z def` 选项。
- `-B local` 将任何未分配给版本定义的全局符号还原为本地。你可以从 `mapfile` 提供版本定义，并指示在生成的对象中应保持可见的全局符号。此选项实现的符号减少效果与 `mapfile` 版本中提供的自动减少（auto-reduction）指令相同，在合并版本化和非版本的可重定位对象时有用。
- `-B reduce` 在生成可重定位对象时，减少由任何版本定义的符号信息。你可以从 `mapfile` 提供版本定义，指示在生成的对象中应保持可见的全局符号。当生成可重定位对象时，默认版本定义仅记录在输出映像中。符号信息的实际减少发生在对象被用于构建动态可执行文件或共享对象时。此选项在创建动态可执行文件或共享对象时自动应用。
- `-B symbolic` 动态模式下。在构建共享对象时，将对全局符号的引用绑定到对象内部的定义（如果可用）。通常，如果存在定义，共享对象内部的引用在运行之前不会被绑定，以便可执行文件或共享对象中相同符号的定义可以覆盖对象的内部定义。除非 `-z def` 覆盖，否则 `ld` 会未定义符号发布警告。
- `-dy | n` 当你指定 `-dy`（默认）时，使用动态链接；当指定 `-dn` 时，使用静态链接。另见 `-B dynamic|static`。
