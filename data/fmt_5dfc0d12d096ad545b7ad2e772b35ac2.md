示例 6-8 涉及线程内部简单的异常线程。它还展示了混合 POSIX 线程和 C++ 在不同平台上如何产生不同的结果。

## 示例 6-8

`exception_3.cc` 内容

```cpp
#include <iostream>
#include <stdio>
#include <cstdlib>
#include <pthread.h>
#include <unistd.h>
using namespace std;
void * thread_func(void *);
int main(int argc, char *argv[]) {
    pthread_t t;
    int i;
    int status;
    try {
        if( pthread_create(&NULL, thread_func, (void *)i) != 0) {
            cerr << "thread_create failed" << endl;
            return 1;
        }
        pthread_join(t, NULL);
        cout << "end of thread " << endl;
    } catch(...) {
        cout << "unexpected exception" << endl;
    }
}
void * thread_func(void *arg) {
    int i;
    for (i=0; i<4; i++) {
        sleep(1);
        try {
            cout << "throwing exception" << endl;
            throw "exception";
        } catch(char *st) {
            cout << "thread_func caught" << st << endl;
        }
    }
    return 0;
}
```

### 在 Linux 上编译并运行 `exception_3.cc` 的结果如下：

```bash
$ g++ exception_3.cc -o exception_3 -lpthread -D_REENTRANT
$ ./exception_3
throwing check
Aborted (core dumped)
```

### 在 HP-UX 上编译并运行 `exception_3.cc` 的结果如下：

```bash
$ aCC exception_3.cc -o exception_3 -lpthread -D_REENTRANT -g
$ ./exception_3
throw check
Aborted (core dumped)
```

将 `thread_func` 改为抛出一个整数而不是 `char *` 会使程序的行为变为能够完成运行而不会中止：

```cpp
void * thread_func(void *arg) {
  int i;
  for (i=0; i<4; i++) {
    sleep(1);
    try {
      cout << "throwing exception" << endl;
      throw 1;
    } catch(int) {
      cout << "thread_func caught" << endl;
    }
  }
  return 0;
}
```
