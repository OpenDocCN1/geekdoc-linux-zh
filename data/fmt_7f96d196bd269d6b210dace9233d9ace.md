### 表达式

第三种控制流是 `for` 循环，它更为复杂。其语法为

`for(expr1;expr2;expr3) statement`

当第一次遇到该表达式时，会评估 `expr1`。接着，评估 `expr2`。如果 `expr2` 非零，则执行语句，随后执行 `expr3`。然后再次测试 `expr2`，接着执行语句和 `expr3`，直到 `expr2` 的评估结果为零。严格来说，这种用法是为了符号上的方便，因为你可以构建一个 `while` 循环来执行相同的操作。这里有一个示例：

```
expr1;
while (expr2) {
 statement;
 expr3
 }
```

循环可以通过三种方式中断。`break` 语句终止循环的执行并退出循环。`continue` 语句会终止当前迭代，并在可能重新执行语句之前重新测试循环。对于非常规的退出，可以使用 `goto`。`goto` 会将程序的执行跳转到带有标签的语句。根据许多程序员的观点，使用 `goto` 是一种糟糕的编程习惯，因此你应该避免使用它。

语句也可以有条件地执行。同样，你可以使用三种不同的格式来执行语句。最简单的是 `if` 语句。其语法为

`if (expr) statement`

如果表达式 `expr` 的评估结果非零，则执行该语句。你可以通过 `else` 扩展此语句，这是第二种条件执行。`else` 的语法为

`if (expr) statement else statement`

如果表达式的评估结果为零，则执行第二条语句。

注意：
`else` 条件中的第二条语句可以是另一个 `if` 语句。如果结构如下

`if (expr) if (expr) statement else statement`

没有被清晰地解析，这种情况可能会导致语法出现不确定性。

按照代码的编写方式，`else` 被认为适用于第二个 `if`。要让它适用于第一个 `if`，你可以用大括号将第二个 `if` 语句括起来，如下例所示：

`$ if (expr) {if (expr) statement} else statement`

第三种条件执行更为复杂。`switch` 语句首先评估一个表达式。然后它会向下查找一系列 `case` 语句，找到一个与表达式值匹配的标签，并执行标签后的语句。如果没有满足其他条件，则存在一个特殊的标签 `default`。如果你只想为每个标签执行一组语句，则必须使用 `break` 语句来离开 `switch` 语句。
