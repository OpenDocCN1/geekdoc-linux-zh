若要自动连接到网络，我运行一个名为`'ppp-on'`的脚本：

```bash
#!/bin/sh
echo calling...
pppd
```

`pppd`有一个`options`文件，告诉它具体的连接方法。一旦连接建立，它会启动一个脚本：

```bash
#!/bin/sh
interface="$1"
device="$2"
ip="$3"
name="$4"
status="$5"
```
