# apropos — 通过关键字查找定位命令

## 概要

```
/usr/bin/apropos keyword...
```

## 描述

`apropos` 显示每行包含 `keyword` 的每个手册页名称、章节号和简短描述的大小写情况。这些信息包含在 `catman(1M)` 创建的 `/usr/share/man/windex` 数据库中。如果没有运行 `catman(1M)` 或使用 `-n` 选项运行，`apropos` 将失败。每个单词被单独考虑，并忽略字母的大小写。作为其他单词部分的会被考虑；例如，当查找 `compile` 时，`apropos` 也会找到所有 `compiler` 的实例。

> 注意 — `apropos` 实际上只是 `man(1)` 命令的 `-k` 选项。

# ar — 维护可移植归档或库

## 概要

```
/usr/ccs/bin/ar -d [-Vv] archive file...
/usr/ccs/bin/ar -m [-Abiv] [posname] archive file...
/usr/ccs/bin/ar -p [-SVv] archive [file...]
/usr/ccs/bin/ar -q [-CVv] archive file...
/usr/ccs/bin/ar -r [-abci] [posname] archive file...
/usr/ccs/bin/ar -t [-SVv] archive [file...]
/usr/ccs/bin/ar -x [-Csv] archive [file...]
/pg4/bin/ar -d [-Vv] archive file...
/pg4/bin/ar -m [-Abiv] [posname] archive file...
/pg4/bin/ar -p [-SVv] archive [file...]
/pg4/bin/ar -q [-CVv] archive file...
/pg4/bin/ar -r [-abci] [posname] archive file...
/pg4/bin/ar -t [-SVv] archive [file...]
/pg4/bin/ar -x [-Csv] archive [file...]
```

## 描述

该命令将文件组组合成单个归档文件。其主要用途是创建和更新库文件；但你可以将其用于任何类似的目的。`ar` 使用的魔法字符串和文件头由 ASCII 字符组成。如果归档由可打印文件组成，则整个归档都是打印的。

当 `ar` 创建归档时，它以跨所有机器的格式创建头。可移植归档格式和结构在 `ar(4)` 中详细说明。归档符号表（在 `ar(4)` 中描述）被链接编辑器高效地对对象库进行多次处理。当归档中至少有一个文件时，`ar` 才会创建并维护归档符号表。归档符号表位于特殊命文件中，该文件总是归档中的第一个文件。该文件永远不会被提及或访问。每当你使用该命令创建或更新此类归档的内容时，符号表都会被重建。你可以通过 `-s` 选项强制重建符号表。

> 注意 — 如果在参数列表中多次提到同一个文件，它可能会被放入归档两次。

按照惯例，归档以 `.a` 字符结尾。

## 选项

- `-a` 将新文件放在归档中 `posname` 操作数指定的文件之后。
- `-b` 将新文件放在归档中 `posname` 操作数指定的文件之前。
- `-c` 抑制创建归档时默认写入标准错误的诊断消息。
- `-C` 防止有效地替换文件系统中的同名文件。当你也使用 `-T` 防止截断的文件名替换相同前缀的文件时，此选项很有用。
- `-d` 从归档中删除一个或多个文件。
- `-i` 将新文件放在归档中 `posname` 操作数指定的文件之前（同于 `-b`）。
