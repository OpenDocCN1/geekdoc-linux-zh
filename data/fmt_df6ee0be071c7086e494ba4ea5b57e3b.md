
默认情况下，Windows NT、2000、2000 和 XP 版本使用 NTFS 文件系统。与 FAT 文件系统不同，NTFS 文件系统（目前）只能从 Linux 读取。因此，你可以从 Linux 读取 Windows 文件，但不能对其进行编辑。如果你需要对 Windows 数据的写访问权限且不需要 NTFS 文件系统，请在 FAT32 文件系统上重新安装 Windows。在这种情况下，你将从 SUSEUX 完全访问 Windows 数据。

> 注意

## 更多分区提示

如果由 YaST 执行分区并在系统中检测到其他分区，这些分区也会输入到 `/etc/fstab` 文件，以便方便访问这些数据。该文件包含系统中的所有分区及其属性（参数），例如文件系统、挂载点和用户权限。

### 示例 2.1：/etc/fstab：分区数据

| /dev/sda1 | /data1 auto | noauto,user 0 0 |
| /dev/sda8 | /data2 auto | noauto,user 0 0 |

分区无论是 Linux 分区还是 FAT 分区，都通过 `noauto` 和 `user` 选项指定。这允许任何用户挂载或卸载它们。出于安全考虑，YaST 不会自动挂载它们，但 `exec` 选项除外，这对于从位置执行程序是所需的。当你遇到如“拒绝访问”之类的系统消息时，此措施是必要的。

有关分区的详细背景信息请参考《管理指南》。

## 2.5.6 软件

SUSE Linux 包含了许多用于各种应用程序的软件包。由于逐个选择所需的软件包非常繁琐，SUSE Linux 提供了具有不同安装范围的系统类型。根据可用磁盘空间，YaST 会选择一个系统并在建议屏幕上显示。

- 最小系统（仅建议用于特殊目的）

安装带有各种服务的无图形界面操作系统。机器只能通过 ASCII 控制台操作。这种系统类型特别适用于需要直接交互的服务器应用程序。

- 最小图形系统（不带 KDE）

如果你不需要 KDE 桌面或磁盘空间不足，请安装此系统。安装的系统包含简单的图形界面和终端窗口，但没有真正的桌面。你可以使用所有自带图形界面的程序（如 Netscape）。未安装办公软件。

- 默认系统（带 KDE 和办公软件包）

这是所有提供的基础系统中最大的。它包含了 KDE 桌面以及大部分 KDE 程序和办公软件。对于普通独立式机器最合适的系统类型。如果 YaST 选择此系统类型。

点击建议屏幕上的“软件选择”，打开一个用于选择一个基础系统的对话框。要启动软件安装模块（包管理器）并修改安装范围，点击“默认选择”（见图 2.11）。

### 更改安装范围

如果你以默认设置安装系统，通常不需要添加或删除单个软件包。该基础系统由满足要求的软件选择组成，无需任何更改。如果你有特定需求，请使用包管理器修改此选择。

过滤器选择框位于菜单栏下方的左侧。启动时，“选择”（Selections）过滤器处于激活状态。此过滤器根据应用程序用途对程序包进行分组，例如多媒体或办公应用程序。“选择”过滤器的各个分组组列在过滤器选择框下。所选系统类型中包含的软件包已预勾选。点击相应的复选框以选择或取消要安装的项目。

窗口右侧部分显示当前选择中包含的各个软件包。左侧的表格显示每个软件包的当前状态。有两个状态标记对安装特别重要：安装（Install，软件包名称前的复选框已勾选）和不安装（Do Not Install，复选框为空）。要选择或取消单个软件软件包，请点击状态框直到显示所需的所需的为止。

或者，右键点击软件包行以访问列出各种状态选项的弹出式菜单。然而，安装时不需要其他状态设置。详细说明请见第 59 页的第 4.3.4 节。

### 其他过滤器

点击过滤器选择框以查看可能的过滤器范围。安装也可以使用根据“软件包组”（Package Groups）的进行进行安装。此过滤器按主题以树形结构对程序包进行排序并在左侧。展开的分支越多，软件包的选择就越具体，右侧关联软件包列表中显示的软件包就越少。

使用“搜索”（Search）搜索特定软件包。详细说明请见第 59 页的第 4.3.4 节。

### 软件包依赖关系与冲突

程序员并不是在每个软件包中重写相同的函数，而是访问其他软件包的函数。因此，许多软件包要求安装其他软件包以便程序正常运行。在少数情况下，程序会相互干扰，导致冲突。在此对话框中选择和取消软件软件包时，可能会显示关于未解决的软件包依赖或冲突的警告。如果您是第一次安装 SUSE LINUX 或者您不理解这些警告，请阅读第 59 页的第 4.3.4 节，该节提供了关于软件包管理器操作的详细信息，以及对 Linux 软件结构的简要总结。

### 注意事项

预选安装的软件是基于长期的经验，通常适用于大多数新手和高级家庭用户的需求。通常情况下，没有这里更改这里的任何内容。但是，如果您决定选择或取消任何软件包，您应该意识到其后果。特别是，请注意任何警告，并避免取消基础系统的任何软件包。

### 退出软件选择

当对您的软件选择满意且没有更多未解决的软件包依赖或冲突时，点击“接受”（Accept）以应用更改并退出程序。如果此模块在已安装的系统中启动，更改将立即应用。在安装期间，更改会被记录在内部并在实际安装开始后应用。

## 2.5.7 引导配置（引导程序安装）

一种可能性是配置引导机制依赖特殊的引导软盘。虽然有需要在驱动器中有引导软盘的缺点，但它允许您保持现有的引导机制不受影响。然而，这通常没有必要，因为 YaST 可以配置引导程序以引导现有的操作系统。配置的另一种可能性是更改引导机制在硬盘上的位置。

要更改 YaST 建议的引导配置，选择“引导”（Booting）打开一个对话框，在其中更改引导机制的许多细节。更多信息请阅读第 120 页的第 4.8.4 节。
