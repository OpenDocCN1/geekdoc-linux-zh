
### cdcontrol

一个并行刻录机，允许你同时写入一个或多个刻刻录机（IDE 和 SCSI）。`CDcontrol` 是我知道的第一个用于 nix 系统的刻录系统，采用 GPL 许可。它的某些功能比我听过的商业系统更好（完全支持 CD 镜像和 cdrogram 支持的所有数据类型），其中一个功能是对每个录制器进行单独控制（避免其他故障或速度问题引起的问题）。`CDcontrol` 本身对每个刻录机和写入错误有每日报告，如果发生更严重的错误，可以在子目录 `SLOC_DIR/` 中找到技术报告。来自 Debian 3.0（需硬件支持）；可启动的 El Toronto CD 创建；多平台 CD 创建。来自 Debian 3.0

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### cd2wav

`Cda2wav` 是一个 CD-ROM 驱动器的采样程序，能够为主机提供数字格式的 CD 音频。CD 音频可以保存为 `.wav` 或 sun 格式。记录包含立体/单声道、8/12 位和不同的速率。`Cda2wav` 也可以作为 CD 播放器。来自 Redhat 8.0 RPM

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

### cdd2wav

从音频 CD 创建 WAV 文件。`cdd2wav` 允许你数字复制音频轨道，避免读取声卡时产生的失真。选项控制记录格式（立体/单声道；8/16 位；采样率等）。来自 Debian 3.0

http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## (通用桌面环境 - Common Desktop Environment)

UNIX 传统上并不打算作为一种桌面操作系统使用，因此缺乏 Windows 和微软 PC 的许多功能。`CDE` 受许多 UNIX 供应商的支持，旨在在 X Windows 和 RPC 之上提供一个常用的桌面环境。黑客感兴趣的是以下内容：服务：`ToolTalk` `pricdb` 提供了“桌面”服务的内核，提供了一个可以链接到“应用程序”的应用程序间通信库。`ToolTalk` 曾出现过两个导致 root 权限的重大漏洞。1999 年发现了一个缓冲区溢出漏洞。2001 年发现了一个成型漏洞。结果导致系统被破坏。来自 Hacking-Linux-http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## deconf

Debian 配置管理系统（C 语言实现）`Deconf` 是一个用于 Debian 软件包的配置管理系统。它使用某些软件包在安装前提示你提供信息。这是对原始 `deconf` 版本的 C 重新实现。现在安装此包相当危险。它会破坏 `deconf`。你已收到警告！Debian 3.0 apt APT http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## cdecl

将英语转换为 C 或 C++ 类。`Cdecl` 是一个程序，可以将类英语的短语（例如“declare foo as 5 of pointer to returning int”）转换为 C 声明（例如“int (foo[5])”）；它还可以将 C 翻译成伪英语。它也能处理 `ctypes`。以及 C++。此外，它具有带有 GNU readline 库的命令行编辑功能。来自 Debian 3.0 apt http://www.tldp.org/LDP/Linux-Dictionary/html/index.html

## cdfs-src

显示 CD 上的轨道和普通文件。`CDfs` 是适用于 Linux 系统的文件系统，它将 CD 上的所有轨道和启动镜像“导出”为普通文件。这些文件可以被挂载（例如用于 ISO 和启动镜像）、复制、粘贴（WAVE 音频和 VideoCD 轨道）……开发此文件系统的主要目标是“解锁”旧 ISO 镜像中的信息。来自 Debian 3.0 apt http://www.tldp.org/LDP/Linux-Dictionary/html/index.html
