速率常数随温度变化，这是由于碰撞分子平均能量的变化。这遵循阿伦尼乌斯方程 `$k = A e^{-E_a/RT}$`，其中 `$A$` 是前指数因子，`$E_a$` 是活化能，`$R$` 是气体常数，`$T$` 是开尔文下的绝对温度。这里的关键因素是具有足够能量引发反应的碰撞比例。反应仅对于结合反应特别重要，其中 `$A + B \rightarrow AB$` 将形成一个激发复合物 `$AB^*$`，它通过随后的碰撞稳定。提供足够能量以稳定键的概率随着碰撞频率和总压力的增加而增加。

单分子反应 `$P \rightarrow R$` 的简单情况速率由方程(11)：

```
$d[P]/dt = -k[P] \quad (11)$
```

### 气相反应

气相化学反应的速率对于理解过程至关重要。与液相反应不同，气相分子碰撞必须在单步中发生，连续反应和自由基反应的碰撞也是如此。例如，氧化碳 (`$CO$`) 分解为二氧化碳 (`$CO_2$`) 并释放能量。它发生在燃烧（例如，甲烷的天然气燃烧）和大气中。在这两种情况下，反应可以写为单个反应(9)

```
$CO + O_2 \rightarrow 2CO_2 \quad (9)$
```

速率与反应物浓度成一次正比，并导致产物化学状态的变化。P随时间的变化（积分速率）在方程(12)中。下标表示 A 随时间减少，因为它随时间函数而衰减，而 P 的浓度随时间增加，并保持与 A 和 B 的浓度相等。因为一级反应在动力学上是简单的，因此处理此类反应是可能的。这对于一级反应（初始浓度）和任意时间 `$t$` 成立。

```
$[A]_t = [A]_0 \exp(-kt)$
```

```
$[P]_t = [P]_0 \exp(-kt)$
```

然而，反应并非来自 `$O_2$` 分子的碰撞，而是遵循两个分子之间的多个步骤。在单分子反应的情况下，单个分子发生分解或通过与其他分子的碰撞被引发。第一步涉及气相基元反应，即自由基，具有一个或多个未对电子。这些物种通常具有很高的活性，是导致气相反应的原因。

速率是指反应物或产物浓度随时间变化的速率。动力学实验的目标不是测量速率本身，而是测量优于反应物浓度随时间变化的速率的内在属性。
