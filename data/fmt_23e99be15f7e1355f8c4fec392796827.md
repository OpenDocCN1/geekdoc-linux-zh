
每一层都只能使用下方层的功能；每一层只能向上一层导出功能。换句话说：层与只与相邻层进行通信。再次以你的电子邮件为例：你通过应用层输入它。在你的计算机中，它向下经过传输层和网络层。你的计算机通过接入层将其置于网络中。该层也是将消息传遍全球的层。在目的地，接收计算机将通过自己的网络层接收消息，并使用传输层和应用层向接收者显示它。

### 它真的非常复杂

包含上述及后续章节是因为你迟早会遇到一些网络问题；它们将为你提供起点，使你可能想要进一步了解细节。

### 一些流行的网络协议

Linux 支持许多不同的网络协议。我们只列出最重要的：

### TCP/IP

传输控制协议（TCP）和互联网协议（IP）是互联网上最常用的通信方式。许多应用程序（如你的浏览器和电子邮件程序）都是构建在该协议族之上的。

简单来说，IP 为一台机器向另一台机器发送数据包提供了解决方案，而 TCP 则确保数据包排列成流，以便不同应用程序的数据包不会混合，并且包按照正确的顺序发送和接收。

学习 TCP 和 IP 的良好起点是以下文档：

- `7 ip`：描述 Linux 上的 IPv4 协议实现（目前版本 4 是 IP 协议最广泛的版本）。
- `7 tcp`：TCP 协议的实现。
- RFC793, RFC1122, RFC2001 用于 TCP；RFC791, RFC1122 和 RFC1112 用于 IP。

意见征询（http://www.ietf.org/rfc/）文档包含了网络标准、协议、应用程序和实现的描述。这些文档由互联网工程任务组（IETF）管理，这是一个关注互联网顺畅运行和互联网架构发展的国际社区。

你的 ISP（互联网服务提供商）通常提供 RFC 存档，或者你可以在 http://www.ietf.org/ 浏览 RFC。

### IPv6

没有人预料到互联网的增长如此之快。当大量计算机接入时，IP 被证明存在相当大的缺点，最重要的是无法为每个参与的机器分配地址。因此，设计了 IP 版本6 以满足今天互联网的需求。

遗憾的是，并不是所有的应用程序和服务都支持 IPv6。在许多可以从升级 IPv6 中受益的环境中，迁移正在进行。对于某些应用程序仍然在使用旧协议，而对于已重写的应用程序，新版本已经激活。因此，在检查网络配置时，有时可能会有点困惑，因为可以采取各种措施隐藏一种协议以防止两种协议的连接混合。

在以下文档中可以找到更多信息：

- `man 7 ipv6`：Linux 的 IPv6 协议实现。
- RFC1883 描述 IPv6 协议。

### PPP, SLIP, PLIP, PPOE

Linux 内核内置了对 PPP（点对点协议）、SLIP（行链路 IP）、PLIP（并行链路 IP）和 PPP 以太网的支持。PPP 是个人用户访问 ISP 的最常用方式，但在人口密集地区，它通常被 PPPOE 取代（ADSL（非对称数字用户线路）连接使用的协议）。

大多数 Linux 发行版提供了易于使用的工具来建立互联网连接。你基本上只需要连接到互联网提供商（ISP）的用户名和密码，在 PPP 的情况下还需要电话号码。这些数据在图形化配置工具中输入，可能会允许你启动和停止与提供者的连接。

### ISDN

Linux 内核内置了 ISDN 能力。Isdnlinux 控制 ISDN 卡并可以使用 Hayes 命令集（"AT"）模拟调制解调器。可能性范围从简单地使用终端协议全连接互联网等。

请检查你的系统文档。

### AppleTalk

AppleTalk 是 Apple 网络栈之一。它是一种点对点网络模型，提供文件和打印机共享的基本功能。每台机器都可以同时充当客户端和服务器，软件和硬件都包含在每台 Apple 计算机中。

Linux 提供完整的 AppleTalk 网络。Netatalk 是 AppleTalk 协议族的内核级实现，最初用于类 BSD 的系统。它包含了对路由 AppleTalk、使用 AppleShare 服务 UNIX 和 AFS 文件系统以及服务 UNIX 打印机和 AppleTalk 流量的支持。

### SMB/NMB

为了与 MS Windows 兼容，可以在任何类 Unix 系统上安装支持 NMB 和 SMB 协议的 samba 服务器。服务器消息块协议（也称为会话消息块、NetBIOS 或 LanManager 协议）用于 Windows 3.11、NT、95/98、2K 以及

Samba 套件的基本功能是：与 Windows 共享 Linux、从 Linux 机器访问 samba、与 Windows 共享 Linux 打印机以及 Linux 共享 Windows 打印机。

大多数 Linux 发行版提供 samba 软件包，它完成了大部分设置，并在启动时运行 samba（samba 服务器）和 netbd（名称服务器）。Samba 可以通过图形界面、Web 界面或命令行以及文本配置文件进行配置。守护进程使 Linux 机器看起来像 MS Windows 的我的网络场所/网络邻域窗口；Linux 机器的共享在 MS Windows 环境中与任何其他主机的共享没有区别。

可以在以下位置找到更多信息：

- `man smb.conf` 描述了 Samba 主配置文件的格式。
- [Samba 项目文档](http://www.samba.org/)（或检查你本地的 samba.org 镜像）包含阅读安装和测试指南的条目，它还解释了如何将你的 Samba 服务器配置为主域控制器。所有主页面都可以在这里找到。

Linux 还支持业余无线电、WAN 互联（X25、帧中继、ATM）、红外以及其他无线连接，但由于这些协议通常需要特殊的硬件，我们不会在本文中讨论它们。

## 网络配置与信息

### 网络接口的配置

所有主流且友好的 Linux 发行版都附带有各种图形化工具，方便在局域网中设置计算机、连接到互联网提供商（ISP）或进行无线访问。这些可以通过命令行或菜单启动：

- Ubuntu 配置方法：选择（Selecting） -> 管理（Administration） -> 网络（Networking）。
- RedHat 带有 `redhat-config-network`，它具有图形和文本模式界面。
- Suse 的 YAST 或 YAST2 是一个全功能配置工具。
- Mandrake/Mandriva 带有网络和互联网配置向导，最好从 Mandrake 的控制中心启动。
- 在 Gnome 系统上：`gnome-network-preferences`。
- 在 KDE 系统上：`networkconfig`。

你的系统文档提供了许多关于工具的可用性和使用的建议和信息。

你将需要的信息：

- 连接到局域网（例如连接你的家庭电脑或工作电脑）：主机名（`hostname`）、域名名（`domainname`）和 IP 地址。如果你想最好地配置网络，请先进行更多阅读。在工作场所，这些信息可能在系统启动时自动提供给你的计算机。如果不确定，最好不要指定任何信息，而不是随意编造。
- 连接互联网：你的 ISP 用户名和密码，使用调制解调器时的电话号码。你的 ISP 通常会自动为你分配 IP 地址以及让你的互联网应用程序工作所需的所有其他内容。

## 网络配置文件

图形化工具使用一些基本命令来编辑特定的网络配置文件。配置文件的准确名称及其在文件系统中的位置很大程度上取决于你的 Linux 发行版和版本。然而，所有 UNIX 系统都有通用的几个网络配置文件：

### /etc/hosts

`/etc/hosts` 文件始终包含本地 IP 地址 `127.0.0.1`，用于进程间通信。永远不要删除此行！它有时包含额外主机的地址，可以在不使用 DNS（域名服务器）等外部命名服务的情况下与它们建立联系。

一个小型家庭网络的示例 hosts 文件：

```
# 不要删除以下行，否则各种需要网络功能的
# 程序将无法运行。
127.0.0.1 localhost.localdomain localhost
192.168.52.10 tux.mylan.com tux
192.168.52.11 winxp.mylan.com winxp
```

请阅读 `man hosts`。

### /etc/resolv.conf

`/etc/resolv.conf` 文件配置对 DNS 服务器的访问，请参见“域名系统”章节。该文件包含了你的域名以及要联系的服务器：

```
mylan.com
nameserver 193.134.20.4
```

请请在 `resolv.conf` 手页中阅读更多信息。

### /etc/nsswitch.conf

`/etc/nsswitch.conf` 定义了联系不同名称服务的顺序。对于互联网使用，确保 `dns` 出现在“hosts”行中是有关重要的：

```
[bob@tux ~] grep /etc/nsswitch.conf
hosts: dns
```

这指示你的计算机首先在 `/etc/hosts` 文件中查找主机和 IP 地址，如果给定的主机不在本地 hosts 文件中出现，则联系 DNS 服务器。其他可能联系的名称服务还有 LDAP、NIS 和 NIS。
