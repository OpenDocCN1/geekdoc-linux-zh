## 二进制文件存储的位置

与任何其他文件一样，可执行文件位于挂载在根目录 `/` 下的目录。具体地说，程序分布在三级结构中：第一层（`//`）包含单用户模式下可能需要的程序；第二层（`/usr`）包含许多多用户程序；第三层（`/usr/local`）用于存储未由发行版提供并在本地编译的软件。

程序的典型所在位置包括：

- `/sbin`

它包含系统管理必需的二进制文件，如 `parted` 或 `ip`。

- `/bin`

它包含所有用户必需的二进制文件，如 `ls`、`mv` 或 `mkdir`。

- `/usr/sbin`

它存储了系统管理所需的二进制文件，如 `deluser` 或 `grouppadd`。

- `/usr/bin`

它包含了大多数所有用户都可以使用的执行文件——如 `free`、`pstree`、`sudo` 或 `man`。

- `/usr/local/sbin`

它用于存储本地安装的、不由系统包管理的系统管理程序。

- `/usr/local/bin`

对于普通用户程序，它的作用与 `/usr/local/sbin`。

最近某些发行版开始将 `/bin` 和 `/sbin` 替换为指向 `/usr/bin` 和 `/usr/sbin` 的符号链接。

- 注意：`/opt` 目录有时用于存储可选的第三方应用程序。

除了这些目录之外，普通用户可以在以下位置拥有自己的程序：

- `/home/$USER/bin`

- `/home/$USER/.local/bin`

> 你可以通过执行 `echo $PATH` 引用 `PATH` 变量来查看哪些目录是可以运行二进制文件的。有关 `PATH` 的更多信息，请复习关于变量和 Shell 自定义的课程。

我们可以通过 `which` 命令找到程序的位置：

```bash
$ which git
usr/bin/git
```

## 内核存储的位置：/boot

内核位于 `/boot` 中——与其他启动相关文件。这些文件大多数包含了内核版本（内核版本、主版本号、次版本号和补丁号）。

`/boot` 目录包含以下类型的文件，其名称与内核版本对应：

```bash

```

内核设置，例如与内核一起编译的选项和模块。

```bash
initrd-img-4.9.0-9-amd6
```

初始内存磁盘通过将临时根文件加载到内存来帮助。

```bash
System-map-4.9.0-9-amd6
```

`System-map`（在某些系统上为 `System.map`）文件包含内核符号的内存位置。每当重新构建内核时，由于内存位置可能不同，该文件的内容发生变化。内核使用该文件查找特定内核符号的内存位置，反之亦然。

```bash

```

以自提取、节省空间的压缩格式的内核本身（因此 `vmlinuz` 中的 `z`；`vm` 代表虚拟内存，内核首次获得虚拟内存时开始使用）。


`grub2` 引导程序的配置目录。
