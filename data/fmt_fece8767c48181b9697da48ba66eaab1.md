# Telnet

一种提供命令行 shell 的协议。`Telnet`创建于20世纪70年代初，目前仍被广泛使用（截至2000年初）。`Telnet`最常见的用途是远程登录`UNIX`系统。它也被广泛用于在路由器和交换机等网络设备上获取命令提示符。事实上，我们可能指的是一个误解：`Telnet`既是协议的名称，也是使用它的客户端程序的名称。该客户端内置在许多系统中。使用`Telnet`程序，你可以对目标计算机上的任何端口打开`TCP`连接，以便直接与基于文本的协议交互。但是，当我们谈论连接到某个服务器时，通常指的是一个原始连接。事实上，我们可能指的是一种没有使用`Telnet`程序的情况，例如使用`netcat`连接到端口`80`。示例：`Telnet`连接到你自己的邮件服务器，第二个参数指示要连接的端口（默认端口`23`之外）。现在按照你看到的文本输入文本：

## Telnet

一种允许互联网用户登录到另一台连接到互联网的计算机的互联网协议，包括那些无法直接与`TCP/IP`协议通信的计算机。它建立了一个名为“网络虚拟终端”的“原生”终端。这种功能经常用于与公告板系统（`BBS`）和许多交互式计算机通信。例如，在浏览万维网（`WWW`）时，你会看到`Telnet`会话中的超链接。如果你点击超链接，你的浏览器会启动一个`Telnet`辅助程序，你会看到一个纯文本的命令。在这个窗口中，你输入命令并看到远程系统的响应。出自`QUCIED` http://www.tld.org/LDP/Linux-Dictionary/html/index.html

## telnet-ssl

带有`SSL`加密的`telnet`。`telnet`客户端用于通过`TELNET`协议与另一个主机进行交互式通信。`SSL telnet(d)`使用`SSL`认证和加密替换了普通的`telnet(d)`。它与普通的`telnet(d)`交互，如果另一端也是`SSL`，否则会回退到普通的`telnet`协议。相对于普通的`telnet(d)`的优势：你发送的密码和数据不会以明文传输。`tcpdump`或类似工具无法获取。通过网络你也可以连接到像`https://www.netscape.com`这样的服务器。

```
do telnet www.netscape.com 443
```

出自 `Debian 3.0 APT`
