## 自动化利用

## 什么是利用程序

利用程序是利用应用程序中漏洞或缺陷的程序。它由安全研究人员或恶意攻击者编写，用于他们的操作。在使用时，利用程序允许攻击者远程访问网络、获取提升权限或进一步渗透网络。在某些情况下，利用程序可能作为多组件攻击的一部分。

## 攻击性安全项目：什么是漏洞数据库 (EDB)？

漏洞数据库（Exploit Database）是安全研究人员和分析师使用的最大的开源漏洞集。它的目标是成为各种来源收集的漏洞的最全面的汇总，并提供一个免费且易用的仓库。漏洞数据库包含 CVE 编号，对于想要查找这些编号的人非常有用。

### 5. 调整 BlueKeep 漏洞利用 (GhostBase)

蓝屏显示我们存在页错误（page fault），这意味着某些内存地址没有被正确设置。我们的漏洞利用实际上需要的是合适的 `GhostBase`，它是非分页池区域（Non-Paged Pool Area, NPP）的起始地址。我们需要从目标机器的数据转储中提取 NPP 地址。通过 VirtualBox 可以轻松获取目标机器进程的内存转储。你必须在 VirtualBox 中启动机器并运行相应的指令（Windows 下）来获取内存转储：

```cmd
C:\ProgramFiles\Oracle\VirtualBox\VBoxManage.exe debugvm "vm name" dumpcore=vm.mem
```

如果你在 Linux 服务器上使用 VirtualBox，也可以实现同样的功能。注意：免费的 Workstation Player 版本不允许运行 VirtualBox。

#### 提取 NPP 地址

此过程在 Docker 容器中使用 Rekall。以下是我们在宿主机上上传 Docker 镜像的方法：

```bash
docker pull remux/rekall
```

现在我们将内存转储拷贝到主目录，并使其能够被 docker 工作进程访问。你需要运行后续命令来尝试这样做：

```bash
rekall output
```

此输出显示了虚拟机上 NPP 的起始地址，该地址将存储在 `GhostBase` 变量中。

#### 编辑漏洞利用程序

漏洞利用代码位于 `exploits/windows/rdp/cve_2019_0708_bluekeep.rb`，你需要通过替换为提取的 NPP 起始地址来设置 `GhostBase` 变量。在我们的案例中：`0xff8018400`。

现在，你需要使用以下命令重新加载 Metasploit 模块：


#### 运行 BlueKeep 模块

你可以从 Metasploit GUI 开始配置该模块。第一件事是将 `GhostSIZE` 参数调整为 50。这与虚拟机拥有的空间大小有关，这是在我们情况下有效的配置。注意：以 RDP 开头的参数预计不需要进行配置。这不会影响漏洞利用的可用性。
