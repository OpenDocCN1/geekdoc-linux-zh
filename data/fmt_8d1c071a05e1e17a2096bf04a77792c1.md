
**man** is always preconfigured to be used with a specific pager. UNIX systems currently use these pager programs:

- Berkeley's pager, which is now available universally as a superior alternative to the old AT&T `pg` command (now obsolete). We'll be considering more in this text.
- `less`, the standard pager on Linux systems, but also available for all UNIX platforms. `less` is modeled on `vi` and is more powerful than `more` because it replicates many of `vi`'s navigational and search functions. The features of `less` are described briefly in Section 3.16.
