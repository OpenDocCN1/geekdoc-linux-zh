# 2 导航

我们需要学习的第一件事（除了如何打字之外）是在我们的 Linux 系统上导航文件系统。在本章中，我们将介绍以下命令：

- `pwd` 打印当前工作目录名称
- `cd` 切换目录
- `ls` 列出目录内容

## 理解文件系统树

与 Windows 类似，Unix 类操作系统（如 Linux）将文件组织在所谓的层次结构目录结构中。这意味着它们以类似于树的目录模式（在其他系统中通常称为文件夹）组织，目录中可以包含文件和其他目录。文件系统中的第一个目录被称为根目录。根目录包含文件和子目录，子目录包含更多文件和子目录，依此类推。

注意，与 Windows 不同（Windows 每个存储设备都有独立的文件系统树），像 Linux 这样的 Unix 类系统始终只有一个文件系统树，无论计算机连接了多少个驱动器或存储设备。存储设备根据系统管理员的喜愿挂载在树的各个点上（更准确地说是*挂载*）。

## 当前工作目录

绝对路径从根目录开始，并沿着树的分支，直到完成到目标目录或文件的路径。例如，你的系统中有一个目录，安装了大多数系统程序。该目录的路径是 `/usr/bin`。这意味着从根目录（由路径开头的斜杠表示）有一个目录叫 `usr`，其中包含一个目录 `bin`。

```
[me@linuxbox ~] cd /usr/bin
[me@linuxbox bin] pwd
/usr/bin
[me@linuxbox bin$] ls
...Listing of many, many files ...
```

现在我们已经更改了当前工作目录为 `/usr/bin` 它充满了文件。注意提示目录。我们所在的目录被称为*工作目录*。要显示当前目录，我们使用 `pwd`（print工作 directory）命令。

```
me@linuxbox ~$ pwd
/home/home
```

当我们首次登录（或启动终端会话）时，我们的当前目录设置为家目录。每个用户账户都有自己的家目录，它是普通用户允许写入文件的唯一。

## 相对路径

绝对路径从根目录开始并通向目的地，而相对路径则从工作目录开始。为了做到，它使用了一些特殊符号来表示文件系统树中的相对位置。这些特殊符号是 `.`（点）和 `..`（点点）。

`.` 符号表示工作目录，而 `..` 符号表示工作目录的父目录。以下是工作原理。让我们再次切换工作目录到 `/usr/bin`。

```
@me@linuxbox ~$ cd /usr/bin
@me@linuxbox $ pwd
/usr/bin
```

现在假设我们想将工作目录切换到 `/usr/bin` 的父目录，即 `/usr`。我们可以通过两种不同的方式实现，一种使用绝对路径：

```
@me@linuxbox $ cd /usr
@me@linuxbox usr$ pwd
/usr
```

或者使用相对路径：

```
@me@linuxbox $ cd ..
@me@linuxbox usr$ pwd
/usr
```

两种不同的方法得到相同的结果。我们应该用哪一个呢？

用打字量最少的那个！

同样，我们可以通过两种不同的方式将工作目录从 `/usr` 切换到 `/usr/bin`，一种是使用绝对路径：

```
@me@linuxbox usr$ cd /usr/bin
@me@linuxbox bin$ pwd
/usr/bin
```

或者使用相对路径：

```
@me@linuxbox usr$ cd ./bin
@me@linuxbox bin$ pwd
/usr/bin
```

现在，这里有一点需要指出。在几乎所有情况下，我们可以省略 `.` 部分，因为它是隐含的。输入以下命令的效果是一样的：

```
@me@linuxbox usr$ cd bin
```

通常情况下，如果我们没有为某个操作指定路径，系统将假设为工作目录。

## 关于文件名的重要事实

在 Linux 系统上，文件的命名方式与 Windows 等系统相似，但存在一些重要的区别。

- 以点字符开头的的文件是隐藏的。这这意味着 `ls` 不会列出它们，除非你使用 `ls -a`。当你创建账户时，系统会在你的主目录下放置若干个隐藏文件，用以为你的账户进行配置。在第 11 章中，我们将更仔细地查看其中一些文件，了解如何自定义你的环境。此外，某些应用程序会将配置和设置文件作为隐藏文件存放在你的主目录下。
- Linux 和 Unix 中的文件名和命令是区分大小写的。文件名 `File1` 和 `file1` 指的是不同的文件。
- 虽然 Linux 支持包含嵌入空格和标点字符的长文件名，但请在你创建的文件名中限制标点字符的使用，使用连字符和下划线。最重要的是，不要在文件名中嵌入空格。如果你想在文件名单词之间表示空格，请使用下划线。你以后会感谢自己自己的。
- Linux 没有像其他操作系统那样的“文件扩展名”概念。你可以任意命名文件。文件的内容或用途由其他手段决定。虽然 Unix 类系统不使用扩展名来确定文件的内容/用途，但许多应用程序是。

## 更多 ls 玩法

`ls` 命令可能是最常用的命令，这很有道理。通过它，我们可以查看目录内容并确定各种文件目录属性。正如我们看到的，只需输入 `ls` 即可获取工作目录下的文件和子目录列表。

```
@me@linuxbox ~$ ls
Desktop Music Templates
```

除了当前工作目录，我们还可以指定要列出的目录，如下：

```
@me@linuxbox ~$ ls /usr
bin include sbin src
```

我们可以指定多个目录。在下面的示例中，我们列出了用户的主目录（由 `~` 符号表示）和 `/usr` 目录：

```
@me@linuxbox ~$ ls ~ /usr
home:
Desktop Music Templates Videos
/bin include sbin src
```

我们可以更改输出格式以显示更多细节。
