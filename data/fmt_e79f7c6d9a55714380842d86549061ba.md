`[]` 用于匹配范围或字符类。`[]` 的工作方式与 POSIX 正则表达式中的 `do` 相似，但在 `^` 代替 `!` 时除外。

```bash
$ ls [a-z]*
```

创建一些文件进行实验：

```bash
$ mkdir brackets
$ cd brackets
$ touch file1 file2 file3 file4 fileb filec file5 file6 file7
```

`[]` 括号内的范围使用 `-` 来表示：

```bash
$ ls
file1 file2 file3 file4 file5 file6 file7 fileb filec
$ ls file[1-2]
file1 file2
$ ls file[1-3]
file1 file2 file3
```

可以指定多个范围：

```bash
$ ls file[1-25-7]
file1 file2 file6 file7
$ ls file[1-35-6a-c]
file1 file2 file3 file5 file6 fileb file
```

方括号也可以用于匹配特定的字符集。

```bash
$ ls file[1a5]
file1 file5 filea
```

你可以使用 `^` 字符作为第一个字符，来匹配除某些字符以外的所有内容。

```bash
$ ls file[^!]
file1 file2 file3 file4 file5 file6 fileb filec
```

本节涵盖的最后一个内容是字符类。要匹配字符类，你需要使用 `[:classname:]`。例如，要使用数字类（匹配数字），你可以像这样操作：

```bash
$ ls file[:digit:]]
```

```bash

$ touch file1 file1
$ ls file[:digit:]a
file1 file2 file3 file4 file5 file6 file7 filea
$ ls file[:digit:]a
filea
```

`glob file[:digit:]a` 匹配 `file` 后面跟着一个数字或字母 `a` 的文件。

支持的字符类取决于你当前的语言区域（`locale`）。POSIX 要求所有语言区域都包含以下字符类：

`[:alnum:]`
字母和数字。

`[:alpha:]`
大写或小写字母。

`[:blank:]`
空格和制表符。

`[:cntrl:]`
控制字符，例如退格、响铃、NAK、转义字符。

`[:digit:]`
数字 (`0123456789`)。

`[:graph:]`
图形字符（除 ctrl 和空格字符以外的所有字符)。

`[:lower:]`
小写字母 (`a-z`)。

`[:print:]`
可打印字符（`alnum`, `punct`, 和空格字符）。

`[:punct:]`
标点符号，即 `!`, `&`, `"`, `"`。

`[:space:]`
空白字符，例如制表符、空格、换行符。

`[:upper:]`
大写字母 (`A-Z`)。

`[:xdigit:]`
十六进制数字（通常为 `0123456789abcdefABCDEF`）。

### 总结

Linux 命令行环境提供了管理文件的工具。一些常用的工包括 `cp`、`mv`、`mkdir`、`rm` 和 `rmdir`。这些工具结合 `glob`，允许用户非常快速地完成大量工作。

许多命令都有 `-i` 选项，它会在你执行任何操作之前向你提示。如果你输入了错误，提示可以为你节省很多麻烦。

许多命令都有 `-r` 选项。`-r` 选项通常意味着递归。在数学和计算机科学中，递归函数是指在定义中调用自身的函数。在命令中，它通常将命令应用于目录及其内部的所有内容。

2. `rmdir -p` 命令的作用是什么？尝试一下并解释它与 `rm -r` 有何区别。

它让 `rmdir` 的行为类似于 `mkdir -p`。如果传递一个空目录树，它将删除所有。

```bash
$ find
  /a
    /a/b
      /a/b/c
  $ rmdir -p a/b/c
  $ ls
```
