## 第 12 章：自动化系统任务 515

# 当我们的 UPS 告诉电源故障时，假设我们还有几分钟的电。
# 在现在 2 分钟后关机。
# 当然，这假设你安装了电源，并且你的
# UPS 连接并工作正常。

```
pf:powerfail:/bin/shutdown -f +h2 "Power Failure, System Shut Down"
```

# 如果在关机前恢复了电源，则取消。

```
pr12345:powerkick:/bin/shutdown -c "Power Restored, Shutdown Cancelled"
```
