# for, foreach, repeat — Shell 内置函数

### 概要

```
sh
for word [in wordlist ...] ; do actions
csh
foreach word (wordlist)
end
repeat count command
```

# for, foreach, repeat

## 描述

你可以在脚本中使用循环来控制执行流。循环是一种迭代机制，会重复一系列指令直到满足预设条件。`for`/`foreach` 循环为循环变量的每个值执行一次命令列表。

# Bourne Shell

每次执行 `for` 命令时，`word` 被设置为 `wordlist` 中的下一个项。如果未指定 `wordlist`，则为每个位置参数执行一次 `actions`。当列表不再有单词时，执行结束。

## C Shell

`word` 依次设置为 `wordlist` 的成员。该命令与 `end` 之间的序列为每个 `word` 新值执行一次。`foreach` 和 `end` 必须单独出现。`repeat` 执行命令 `count` 次。`command` 限制为单行语句。

## Korn Shell

每次执行 `for` 命令时，`word` 被设置为 `wordlist` 中的下一个项。如果未指定 `wordlist`，则为每个位置参数执行一次 `actions`。当列表不再有单词时，执行结束。

> 注意 — Bourne shell (`sh`) 和 Korn shell (`ksh`) 均可以在其、`for` 和 等内置命令的语法中交替使用分号和回车。

# 循环中断

所有 shell 都有内置 `continue` 和 `break` 命令，可以用它们跳出 `for`/`foreach` 循环。`continue` 终止 `for` 或 `foreach` 循环的当前迭代。`break` 命令终止 `for` 或 `foreach` 命令的执行。

## 示例

在使用 `for`/`foreach` 的示例中，代码计算当前目录中以 `.` 结尾的文件的行数。

# Bourne 和 Korn Shell

以下 Bourne 和 Korn shell 示例计算当前目录中以 `.c` 结尾的文件的行数。

```
for file in *.c ; do wc -l $file ; done
```
