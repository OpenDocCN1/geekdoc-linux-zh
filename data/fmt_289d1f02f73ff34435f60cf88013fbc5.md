# Glib Dictionary

`Glib` 是一个实用的实用函数库。该库旨在解决某些问题并提供许多程序所需的其他功能。`Glib` 被 `GDK`、`GTK+` 和许多应用程序使用。您安装 `Glib`，因为您的许多应用程序都依赖于此库。此包包含运行 `glib` 动态所需的库。源自 Mandrake 9.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`

### libgnmp3

`gmp` 包包含 GNU MP，这是一个用于任意精度算术、符号整数、操作和浮点数的库。GNU MP 无论对于小整数还是大整数，速度都很快。GNU MP 运行快的原因有几点：

- 它使用了尽可能快的算法
- 它针对许多 CPU 的常见内层循环进行了仔细的代码优化
- 在操作中，它通常优先考虑速度而非简洁性/优雅性

源自 Mandrake 9.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`

### libgnat

`GNAT` 是 `GCC` 的 Ada 95 前端。此包包含了运行用 `GNAT` 编译的程序所需的共享库。源自 Redhat 8.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`

### libgnet1.1

`Gnet` 是一个简单的网络库。它用 C 语言编写，面向对象并基于 `glib` 构建。它旨在快速、易用且易于移植。其接口类似于 Java 网络库接口。特性：

- TCP '客户端'套字
- TCP '服务器'套字
- 非阻塞 TCP 套字
- UDP 多播
- 互联网地址抽象

`Gnet` 需要 `Glib 1.2`。源自 Mandrake 9.0 RPM `http://www.tld.org/LDP/Linux-Dictionary/index.html`
