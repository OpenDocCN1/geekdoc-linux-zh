## Here: <<

通常情况下，一个 shell 脚本包含一系列命令。但有时，你可能想将数据行包含在 shell 脚本中，作为其中一个命令的输入。`Here` 操作允许你实现这一点，它由两个小于号（`<<`）表示。这是一种重定向操作，将 shell 脚本内部的数据重定向为命令的输入。它之所以被称为 `Here`，是因为重定向的数据就在这里（即 shell 脚本中），而不是在另一个文件的任何地方。

`<<` 运算符置于要重定向输入的命令之后。`<<` 运算符后续行将作为命令的输入。输入的结束可以通过文件结束符（`CTRL-D`）指定，或者你可以指定自己的分隔符。在同一行中，`<<` 运算符后面的单词将用视为输入行的结束分隔符。分隔符可以是任意符号集。到分隔符为止的所有行都将被读取为命令的输入。

在下一个示例中，`message` 被发送给用户 `mailmark`。消息的输入获取自 `Here` 操作。`Here` 操作的分隔符是单词 `myend`。

### `mailmark`

```
mailmark << myend
Did you remember
the meeting
robert
myend
```

# 双引号、单引号和反斜杠: " " ' \

你赋值给变量的值可以由任何字符集，但当你想要包含被 shell 用作运算符的字符时，就会出现问题。在大多数情况下，你需要使用单引号、双引号、反斜杠或反引号对你的值进行引用，这允许你以不同的方式对字符串进行引用。命令行上对特殊字符的引用使其变成另一个普通字符。它不会被 shell 求值。反引号具有执行 Linux 命令并使用结果作为参数的特殊功能。

双引号和单引号允许你一次对特殊字符进行引用。双引号或单引号内的任何特殊字符都会被引用。反斜杠引用单个字符——即它所紧 preceding的那个字符。如果你想给一个变量赋值多个单词，你需要对分隔这些单词的空格进行引用。你可以通过将单词封装在双引号内来实现此。你可以认为这是在创建一个要赋值给变量的字符字符串。或者，在双引号内的其他特殊字符也将被引用。

以下示例展示了引用字符串的三种方式。在第一个示例中，双引号封装了由空格分隔的单词。由于空格被包含在双引号内，它们被视为字符，而不是用于解析命令行参数的分隔符。在第二个示例中，单引号也包含了一个句号，将其仅视为一个字符。在第三个示例中，星号也被包含在双引号内。星号被视为字符串中的另一个字符，且不会被求值。

```
$ notice="The meeting will be tomorrow"
$ echo $notice
The meeting will be tomorrow
```

```
$ message='The project is on time.'
$ echo $message
The project is on time.
```

```
$ notice="You can get a list of files with *"
$ echo $notice
You can get a list of files with *
```

### 反引号:

虽然你可以向脚本传递参数，但你也可以将命令的输出作为参数。这是通过反引号实现的。反引号内的命令将被执行，其输出将替换反引号所在的位置。在下面的示例中，使用了 `date` 命令来获取当前日期。

```
$ currenttime=`date`
$ echo $current
Wed Oct 25 10:00:00 UTC 2023
```

### `greetargs`

使用每个对应的参数编号进行处理。在下一个示例中，命令行上输入了四个参数。

```
echo "The first argument is: $1*"
echo "The second argument is: $2*"
echo "The third argument is: $3*"
echo "The fourth argument is: $4*"
```

```
$ greetargs Hello Hi Salutations "How are you"
The first argument is: Hello
The second argument is: Hi
The third argument is: Salutations
The fourth argument is: How are you
```

一组特殊的变量 `*`、`$` 和 `$#` 允许你引用命令行参数的不同部分。`##` 参数包含命令行上输入的参数数量。这在脚本需要固定数量的参数时非常有用。变量 `$*` 引用命令行上输入的所有参数。命令行可能有超过九个参数。`$@` 也引用命令行上的所有参数，但允许你对每个参数单独加引号。在没有使用 `for-in` 控制结构来引用参数之前，`*` 和 `$@` 之间的区别并不明确。因此，我们在这里只对它们进行了简要讨论，并在本章稍后的控制结构部分中进行更详细介绍。

在下一个示例中，首先使用特殊变量 `$*` 和 `$@` 显示命令行参数。参数的数量使用特殊变量 `$#` 显示。

### `sargs`

```
echo $*
echo $@
echo "There are $# arguments"
```

```
$ sargs Hello Hi Welcome
Hello Hi Welcome
There are 3 arguments
```
