## 动态和静态地使用 Numba

`Numba` 包含一个装饰器，你可以用它来选择性地从普通 Python 程序中编译部分代码。这在本质上允许你即时编译特定的代码段。一个非常典型的例子如下：

```python
from numba import jit

@jit
def my_func(x, y):
    return x + y
```

在输出中，你将得到：

- `12`
