
某些变量需要你的关注。在大多数情况下，Korn shell 在启动时会为变量分配默认值。你可以在你的登录配置文件（家目录下的一个文件）中或在之后的任何时间通过键盘赋值来覆盖此默认值。这些变量的值影响 shell 的工作方式。正确设置这些变量可以提高你的效率和生产力。

表 11.11 列出了 Korn shell 使用的变量。

## 11.11. Korn shell 使用的变量

| 变量 | 说明 |
|---|---|
| `CDPATH` | `$CDPATH` 的值是一个由冒号分隔的目录路径列表。该值仅由 `cd` 命令引用。使用 `CDPATH` 变量可以在在使用 `cd` 配合文件名时指定要搜索的目录列表。`CDPATH` 的好处是它允许通过文件名而非完整路径切换到目录。`CDPATH` 没有默认值。 |
| `COLUMNS` | `$COLUMNS` 的值定义了 Korn shell 命令编辑模式（vi 或 EMACS）作为行窗口的宽度，以及作为打印 select 列表的宽度。默认值为 80。 |
| `EDITOR` | `$EDITOR` 的值主要用于 Korn shell 以外的程序。如果你在配置文件中或键盘上设置了 `EDITOR` 的值，Korn shell 会检查该值是否为 vi 或 emacs 的路径。这会调用命令编辑。这仅仅是为了方便。你可以通过 `-o` 命令切换命令编辑模式。`EDITOR` 没有默认值。 |
| `ENV` | `$ENV` 的值是包含在调用 Korn shell 时要执行命令的 shell 脚本的路径。请注意，每次你调用写成 shell 脚本的命令都会运行 Korn shell。你也可以从 `vi` 和 `pg` 等 UNIX 命令内部调用 Korn shell。通过将 `alias`、`export` 和 `set` 命令放在一个文件中并将该路径作为 `$ENV` 的值提供，你可以确保在调用 Korn shell 时具有相同的 shell 环境。保持 `$ENV` 文件较小，因为每个 shell 脚本的执行都会增加执行时间。（欲了解更多信息，请参阅本章后后的“Korn Shell”。） |
| `FCEDIT` | `$ENV` 的值是包含调用 Korn shell 时要执行命令的 shell 脚本的路径。在 Korn shell 中，`FCEDIT` 的值是文本编辑器。 |
| `FPATH` | `$FPATH` 的值是一个冒号分隔的目录列表，每个路径标识一个要监控的文件。Korn shell 在执行时会搜索 `$FPATH`。`FPATH` 没有任何默认值。 |
| `HISTFILE` | `$HISTFILE` 的值是指定 history 文件的文件名。Korn shell 使用 `$HISTSIZE` 来限制 history 的行数。 |
| `HISTSIZE` | `$HISTSIZE` 的值是指定 history 文件中保留的行数的整数。Korn shell 在显示 history 时使用它来限制行。`$HISTSIZE` 的默认值是 128。 |
| `HOME` | `$HOME` 的值在 Korn shell 中工作时与 Bourne shell 相同。`$HOME` 是你的家目录。 |
| `IFS` | `$IFS` 的值在 Korn shell 中工作时与 Bourne shell 相同。Korn shell 在解析行时作为分隔符使用 `$IFS`。其值可以修改。 |
| `LINES` | `$LINES` 的值是指定 shell 显示的行数的整数。Korn shell 使用 `$LINES` 来限制显示。其没有默认值。 |
| `LOGNAME` | `$LOGNAME` 的值是用户名，在 Korn shell 中工作时与 Bourne shell 相同。 |
| `MAIL` | `$MAIL` 的值在 Korn shell 中工作时与 Bourne shell 相同。`$MAIL` 是你的邮件文件。 |
| `MAILCHECK` | `$MAILCHECK` 的值是指定 shell 每隔多久检查一次邮件的整数。Korn shell 的其默认值是 600。 |
| `MAILPATH` | `$MAILPATH` 的值是一个冒号分隔的路径列表，每个路径标识一个要监控的文件。 |
| `PATH` | `$PATH` 的值在 Korn shell 中工作时与 Bourne shell 相同。`$PATH` 的值取决于系统。 |
| `PS1` | `$PS1` 是主提示符字符串。shell 在显示每个命令行提示符之前会对 `$PS1` 的值进行完全替换。在使用 Bourne shell 时，你可以自定义你的提示符。指定 `PS1='$PWD'` 可以让提示符变为当前目录。（引号很重要，可以防止赋值时对 `PS1` 进行替换；替换发生在显示 `PS1` 值之后）。你还可以在提示符中使用感叹号（!），它会被替换为命令号（“命令历史”，见前文）。默认值为 # |
| `PS2` | `$PS2` 是次级提示符字符串。它与 Bourne shell 相同。默认值为 ">"。 |
| `PS3` | `$PS3` 是选择提示符字符串。`PS3` 的值被 `select` 命令作为提示符使用。（使用 select 语句，见本章）。 |
| `PS4` | `$PS4` 是调试提示符字符串。`PS4` 的值会被变量替换，并打印在 `trace` 或 `x` 选项显示的每行前面。 |
| `SHELL` | `$SHELL` 是 shell 的路径。如果 ksh 启动时没有设置，Korn 会为 `$SHELL` 设置一个默认值。该值不被 Korn shell 直接使用，但许多其他命令（如 `vi` 和 `go`）使用 `$SHELL` 的值作为调用子 shell 时的 shell 路径。当 `$SHELL` 变量在 ksh 启动时定义并以 `r` 开头时，Korn 以限制模式运行。这意味着用户无法调用完整路径，不能使用 `cd` 命令，且不能修改 `PATH` 变量。 |

### `TERM`

`TERM` 的值是一个符号字母数字字符串，用于识别您终端的类型。Korn shell 不使用 `TERM` 变量，该变量预留供一般系统使用。`$TERM` 的正确设置对于终端的正常且合理运行至关重要，并且在您登录时应适当初始化。对于您安装系统中允许的值，请咨询您的系统管理员。`TERM` 没有默认值。

### `TMOUT`

`TMOUT` 的值是一个整数，指定在终端活动后多少秒，Korn shell 应该自动注销。值为 0 则禁用自动注销功能。

### `VISUAL`

`VISUAL` 的值主要供 Korn shell 外的其他程序使用。如果你设置了 `VISUAL` 的值（在你的配置文件或通过键盘设置），Korn shell 将检查该值是否为以 .vi、emacs 或 emacs 结尾的路径名。如果发现其中任何一个值，Korn shell 将设置相应的 vi、emacs 或 emacs 选项，启用命令编辑。这是一种便利。你可以通过使用 `set -o` 命令切换命令编辑模式。`VISUAL` 没有默认值。

注意：我总是将定义放在我的登录配置文件中：

```
CDPATH=..:$HOME
```

命令 `cd src` 首先在当前目录中查找子目录 src。如果查找失败，`cd` 命令将在父目录中查找 src。如果在两个地方都没有找到目录名，它将尝试切换到我主目录下的 src。你会发现正确使用 `CDPATH` 变量可以节省大量的输入工作。

与 Bourne shell 类似，Korn shell 中的变量名以字母或下划线开头，包含任意数量的字母、下划线和数字。变量是其变量值的符号表示，可以通过赋值语句；通过 `set`、`read` 或 `select` 语句；通过执行内置 shell 或其他命令的副作用；或者通过 Korn shell 本身来更改。你可以定义的变量数量没有上限，但 shell 可用的内存量设定了实际的（通常是上限的）限制。

你可以使用 `name=value` 格式的赋值为变量名显式分配一个值。注意，在编写赋值时，不要在 name 前包含美元符号 ($)。在引用该值时，使用美元符号是合适的。

变量的值是一个字符串——即一系列字母数字和特殊字符的序列——长度是任意。Korn 提供了一系列扩展，允许通过算术方法操作变量的值。变量的值是以字符串形式存储的。

变量从设置开始（无论是你显式设置还是由 Korn shell 隐式设置）一直到值改变或 shell 退出。注意，除非变量被标记为导出，否则该值不会传递给你调用的命令和脚本。你可以使用内置命令 `typeset` 或 `export` 别名将变量标记为导出。或者，如果开启了 export 选项（例如通过输入 `set -o export`），所有变量将自动导出。导出的变量将成为所有调用命令的环境的一部分。

由于变量的值由 shell 在内部的内存表中保留，所有 shell 在退出时没有继承的变量都是。你无法在 shell 脚本（即对 shell 的任何调用）内部为变量赋值，并期望该值在 shell 脚本退出后仍然保留；此时 shell 会返回到更高层级的 shell。换句话说，你可以为变量赋值并导出变量以将值向下传递给当前 shell 的 shell，但你不能将值向上传递给更高级的 shell 或 shell 脚本。

这种对 shell 变量使用的限制通常在键盘操作上是不可见的。它通常出现在与 shell 编程相关的问题中。然而，如果你直接调用 shell（通过输入 sh、ksh 或 bash 命令）或间接调用 shell（通过另一个 UNIX 命令，如 vi 或 pg 进入环境），你会发现当通过退出 shell 回到原始 shell 层级时，任何对 shell 环境的更改（包括变量设置和别名）都会丢失。

## 引用变量

Korn 会将命令行中以 $ 开头并后跟引用表达式的字符串替换为该引用表达式的值。同一条命令行中可以出现任意数量的引用表达式。相邻的引用在被替换时，会在命令行中引入新的单词边界。也就是说，一个单一的单词名、选项或参数——即使被替换的值包含制表符、空格或其他分隔符字符——也会被拆分成两个或多个单词。当你希望引用文本中的分隔符导致进一步的单词拆分时，可以使用内置 shell 命令 `eval`。

Korn shell 的有效表达式如下：

| name | `{name#pattern}` |
|---|---|
| `{name}` | `{name##pattern}` |
| `{name[n]}` | `{name%pattern}` |
| `{name[*]}` | `{name%pattern}` |
| `{name[@]}` | `{#@}` |
| `{name:word}` | `|*}` |
| `{name-word}` | `{#name}` |
| `{name=word}` | `{#name=*}` |
| `{name?word}` | `{#name[@]}` |
| `{name+word}` | `|` |

表达式 `$name` 被替换为 shell 变量名的当前值。如果没有为变量定义值，则符号和变量名将被替换为空字符串。例如，

```
$ today="January 13"
$ print Today is:$today.
Today is:January 13.
$ print Today is $tomorrow.
Today is:
```

表达式 `$(name)` 被替换为 shell 变量名的当前值。使用大括号将变量与周围文本隔开，在变量名后可能跟随字符时是必要的。例如，`$(name)` 不同于 `$(name)x`。

表达式 `$(name)` 被替换为 shell 变量名的当前值。大括号将变量与周围文本隔开，在变量名后可能跟随字符时是必要的。例如，`$(name)` 不同于 `$(name)x`。

表达式 `$(name)` 被替换为 shell 变量名的当前值。大括号将变量与周围文本隔开，在变量名后可能跟随字符时是必要的。例如，`$(name)` 不同于 `$(name)x`。

表达式 `$(name)` 被替换为 shell 变量名的当前值。大括号将变量与周围文本隔开，在变量名后可能跟随字符时是必要的。例如，`$(name)` 不同于 `$(name)x`。

这看起来与之前的表达式 `${name:-word}` 相似，为了清楚，看这个示例：

```
$ month=""
$ echo $(month:-unknown)
echo $(month:-unknown)
unknown
```

`${name=word}` 如果变量有值，表达式替换为 name 的。否则，word 被赋值为 name 的值，表达式替换为 word。你可以使用 `${name:=word}` 在变量未设置或为空时赋值 word name。例如，

```
$ print This month is $month.
This month is =
$ print This month is ${month=January}
This month is January
$ print This month is $month.
This month is January.
```

`${name=word}` 如果变量有值，表达式替换为 name 的。否则，字符串 word 被识别为错误消息。未设置的变量被识别为错误并停止处理命令行。如果在 shell 脚本内部识别出错误，则终止脚本的执行。使用 `${name?:word}` 来识别未设置的变量或未设置的值。表达式可以省略 word；如果省略，则显示标准的错误消息。例如。

```
$ month=January
$ print This month is ${month?unknown}
This month is January
$ print This year is ${year?unknown}
ksh: year: unknown
$ print This year is ${year?}
ksh: year: parameter null or not set
```

`${name+word}` 如果变量名有值，表达式替换为 word 的。如果没有设置，则表达式被替换为空字符串。如果 name 有值，它临时地将该值视为 word。如果 name 没有值，表达式也没有值。使用 `${name:+word}` 来视为一个

null 值等同于未设置值。例如，

```
$ month=January
$ print This month is $(month+unknown)
This month is unknown.
$ print This year is $(year+unknown)
This year is .
```

`name#pattern` 表达式的值为 `name` 删除了最左侧首次出现的 `pattern` 后的值。系统会识别 `pattern` 的最短匹配项。*Pattern*，指定一个包含任何字符序列、变量命令替换和通配符的字符串。删除第一个出现的 *pattern*。例如，

```
$ print PWD
/usr/home/${PWD*}\n$ print ${PWD**}
usr/home/valley
```

`name#pattern` 表达式的值为 `name` 删除了 `pattern` 最长匹配项左左侧的所有内容后的值。例如，

```
$ print PWD
/usr/home/valley
$ print ${PWD**}
valley
```

`name#pattern` 表达式的值为 `name` 删除了匹配 `pattern` 的最右侧最短字符串后的值。例如，

```
$ print $FNAME
s.myfile.c
$ print ${FNAME%}
s.myfile
```

`name#pattern` 表达式的值为 `name` 删除了匹配 `pattern` 的最右侧最长字符串后的值。例如，

```
$ print $FNAME
s.myfile.c
$ print ${FNAME%}
s
```

`##@` 表达式的值是 `$@` 返回的参数整数个数。`{#*}` 表达式的值是 *$ 返回的参数整数个数。它与 $$ 相同。`{#name)` 表达式的值是字符串变量 `name` 的长度。例如，

```
$ print $FNAME
s.myfile.c
$ print ${FNAME}
10
```

`{#name*]}` 表达式的值是数组变量 `name` 中已设置的元素个数。例如，

```
$ set -A planets Mercury Venus Earth Mars
$ print ${planets[*]}
4
```

`{#name[@]}` `${name[@]}` 与 `${name[]}` 相同。

## 数组变量

数组变量是具有多个值的变量。数组变量对于管理字符串列表非常有帮助，因为你可以无需借助字符串分割技术即可处理列表中的单个元素。

你可以通过赋值语句一次性为数组分配值。例如，

```
$ planets[1]=Mercury
$ planets[2]=Venus
$ planets[3]=Earth
$ print ${planets[2]}
Venus
```

Shell 支持使用通用语法 `name[script]` 来引用数组元素。下标支持 0 到 511 范围内的整数，或者编写一个具有所需元素编号值的变量表达式。元素从 0 开始。数组中的第一个元素是 `${name[0]}`。

你可以使用 `set -A` 命令通过一条语句设置多个数组元素。例如，前面的代码可以重写为：

```
$ set -A planets Mercury Venus Earth
$ print ${planets[2]}
Venus
```

你还可以使用特殊符号 `${name[*]}` 或 `${name[@]}` 来替换数组的元素。

```
$ set -A planets Mercury Venus Earth
$ planets[5]=Pluto
$ planets[7]=Uranus
$ print The known planets are: ${planets[*]}
The known planets are: Mercury Venus Earth Uranus Pluto
```

使用数组变量时你应该记住以下几点：
