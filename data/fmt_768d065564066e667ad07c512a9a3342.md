
## 15.3 哈希表

哈希表是实现字典的一种高效方法。基本思想是为字典中的每个项的键计算一个哈希值（hash value）。哈希值的目的是将键分散到整个数组中。一个完美的哈希函数会将每个键映射到数组中用于哈希的唯一位置，但这种实现很难实现。相反，我们必须处理发生“冲突”的键。

处理冲突最简单的方法是在哈希数组的每个位置使用链表。请考虑下方的图：

![](img/443639abd490bee82d518502d35b07b9_175_0.png)

在这个哈希表中，键 12、4、16 和 9 的哈希值均为 1，并被放置在哈希数组位置 1 的列表中。键 13 和 8 的哈希值均为 3，并被放置在数组位置 3 的列表中。剩余的键被映射到 5 和 7。

哈希的一个关键问题之一是开发良好的哈希函数。哈希函数应该看起来是随机的。每当为某个键调用它时，必须为该键计算相同的值，但哈希值本身并不重要——我们想要的是键到列表的分布，即我们希望许多短列表。这意味着数组的大小至少要与预期键数量一样大。然后，通过良好的哈希函数，链表通常会非常短。

### 15.3.1 适用于整数的良好哈希函数

通常建议哈希表的大小为质数。但是，如果用作键的数字没有底层模式，那么这并不重要。在这种情况下，你可以简单地使用 `n mod t`，其中 `n` 是键，`t` 是数组大小。如果存在某种模式（例如许多相同数的倍数），那么使用质数作为 `t` 就很有意义。以下是示例代码的哈希函数：

```
i = hash ( n )

mov rax, rdi

and rax, 0xff

ret
```

示例中的表大小为 256，因此使用 `and` 相当于 `n mod 256`。

### 15.3.2 适用于字符串的良好哈希函数

字符串的良好哈希函数是将字符串视为包含多项式系数，并对某个质数 `n` 计算 `p(n)`。在下面的代码中，我们在评估中使用质数 191。在计算多项式值后，你可以使用表大小（示例代码中为 100000）执行模运算。

```
int hash ( unsigned char *s )

{

  unsigned long h = 0;

  int i = 0;

  while ( s[i] ) {

    h = h*191 + s[i];

    i++;

  }

  return h % 100000;

}
```

### 15.3.3 哈希表节点结构和数组

在示例哈希表中，表大小为 256，因此程序启动时我们需要一个包含 256 个 NULL 指针的数组。由于这很小，它被实现在数据段中。对于更真实的程序，我们需要一个哈希表创建函数来分配数组并用 0 填充它。下面是数组的描述以及每个数组位置链表的结构定义。

```
segment .data 0

table times 256 dq

struct node

n_value resq 1

n_next resq 1

nalign 8

endstruct
```

### 15.3.4 在哈希表中查找值的函数

哈希表的根本目的是存储与键关联的某些数据。在示例哈希表中，我们简单地存储了键。`find` 函数遍历哈希表以查找键。如果找到了，函数返回指向带有键的节点的指针。如果没找到，它返回 0。更真实的程序可能会返回指向与键关联的数据的指针。

`find` 函数的工作原理是调用 `hash` 来计算可能持有所求键的链表在哈希数组中的索引。然后，函数遍历列表上的节点以查找键。

```
; p = find ( n );

p = 0 if not found

find:

.n equ 0

push rbp

mov rbp, rsp

sub rsp 16

mov [rsp+.n], rdi

call hash

mov      rax, [table+rax*8]

mov      rdi, [rsp+.n]

cmp      rax, 0

je       .done

.more cmp rdi, [rax+n_value]

      je       .done

mov      rax, [rax+n_next]

cmp      rax, 0

jne       -more

.done leave

      ret
```

### 15.3.5 插入代码

将键插入到哈希表的代码首先调用 `find` 以避免重复插入键。如果找到了键，则跳过插入代码。如果没找到键，函数调用 `hash` 来确定添加该键的链表索引。它为新节点分配内存并将其插入到列表开头。

```
; insert ( n );

insert:

.n      equ     0

.h      equ     8

      push    rbp

mov      rbp, rsp

sub      rsp, 16

mov      [rsp+.n], rdi

call     find

cmp      rax, 0

ne       .found

mov      rdi, [rsp+.n]

call     hash

mov      [rsp+.h], rax

mov      rdi, node_size

call     malloc

mov      r9, [rsp+.h]

mov      r8, [table+r9*8]

mov    [rax+n_next], r8

mov    r8, [rsp+.n]

mov    [rax+n_value], r8

mov    [table+r9*8], rax
```

### 15.3.6 打印哈希表

`print` 函数遍历从 0 到 255 的索引，打印索引号以及每个非空列表上的键。它使用寄存器 `r12` 和 `r13` 来安全地存储循环计数器（用于遍历哈希表数组的位置）以及一个用于遍历每个链表节点的指针。使用寄存器更加方便，因为其他方法在每个 `printf` 调用周围都需要保存和恢复寄存器。这确实需要在函数开始和结束处推入和弹出这两个寄存器，以便为调用函数保留它们。注意，推入和弹出 16 字节对于保持正确的栈对齐是必要的。你会注意到代码在数据段和文本段之间切换，以便 `printf` 格式字符串将放置在代码中使用它的点附近。

```
print:

push    rbp

mov     rbp, rsp

push    r12            ; i: 表的整数计数器

push    r13            ; p: table[i] 列表的指针

xor     r12, r12

.more_table:

mov     r13, [table+r12*8]

cmp     r13, 0

je      .empty

segment  .data

.print1 db    "list %3d: ",0

segment  .text

lea     rdi, [.print1]

mov     rsi, r12

call   printf

.more_list:

    segment  .data

    print2 db    "%ld:",0

    segment  .text

    lea     rdi, [.print2]

    mov     rsi, [r13+n_value]

    call   printf

    lea     rdi, [.print3]

    mov     rsi, r12

    call   printf

    inc     r12

    mov     r13, [rax+n_next]

    cmp     rax, 0

    jne     .more_list

.empty:

    pop     r13

    pop     r12

    leave

    ret
```

### 15.3.7 测试哈希表

哈希表的 `main` 函数通过 `scanf` 读取数字，插入哈希表，并在每次插入后打印哈希表：

```
main:

    .k equ 0

    segment .data

.scanf_fmt:

    db "%ld",0

    segment .text

    push .rbp

    mov rbp, rsp

    sub rsp, 16

.more lea rdi, [.scanf_fmt]

      lea rsi, [rsp+.k]

      call scanf

      cmp rax, 1

      jne .done

      mov rdi, [rsp+.k]

      call insert

      call print

      jmp .more

.done leave

      ret
```

下面是在插入 1, 2, 3, 4, 5, 256, 257, 258, 260, 513, 1025 和 1028 后哈希表的打印结果：

+   list 0: 256
+   list 1: 1025 257 1
+   list 2: 258 2
+   list 3: 3
+   list 4: 1028 260 4
+   list 5: 5

## 15.4 二叉树

二叉树是一种包含许多节点的结构。它有一个根节点，可以有左或右子节点（或都有）。

通常二叉树是根据键的排序构建的。例如，你可以拥有这样一种二叉树：每个节点将键分为小于节点键的（在左子树中）和大于节点键的（在右子树中）。

有序二叉树（通常称为二叉搜索树）使得能够快速搜索键，同时保持按升序或降序遍历节点的能力。

在这里我们将展示一个带有整数键的二叉树。首先是用于树的结构。

### 15.4.1 二叉树节点和树结构

二叉树中的节点包含一个整数值和两个指针。下面的结构定义在命名上使用了前缀约定，将值字段命名为 `n_value`，将左右指针分别命名为 `n_left` 和 `n_right`。

```
struct node

n_value resq 1

n_left resq 1

n_right resq 1

        align 8

endstruct
```

虽然可以使用一个指向根节点的指针来表示树。但是，我们可以为树添加功能，例如节点删除或平衡，这些操作可能会改变树的根。将根节点存储在一个结构中是有逻辑的，这可以让我们免受未来树根变化的影响。我们还在树结构中包含了树节点数量的计数。

```
struct tree

t_count resq 1

t_root resq 1

        align 8

endstruct
```

### 15.4.2 创建空树

`new_tree` 函数为树结构分配内存，并将新树的计数和根节点设置为 0。通过将树的根放在一个结构中，使用二叉树的代码始终通过 `new_tree` 返回的指针来引用特定的树。

```
new_tree:

push rbp

mov rbp, rsp

mov rdi, tree_size

call malloc

xor edi, edi

mov [rax+t_root], rdi

mov [rax+t_count], rdi

leave

ret
```

### 15.4.3 在树中查找键

在二叉搜索树中查找键时，你从一个指向根节点的指针开始，将节点的键与要查找的键进行比较。如果匹配，则完成。如果目标键小于节点的键，则将指针更改为节点的左子节点。如果目标键大于节点的键，则将指针更改为节点的右子节点。然后你对新节点重复这些比较。如果你到达一个 NULL 指针，说明该键不在树中。下面是在二叉树中查找键的代码。它返回一个指向正确树节点的指针，如果未找到则返回 NULL。

```
; p = find ( t, n );

; p = 0 if not found

find:

    push rbp

    mov rbp, rsp

    mov rdi, [rdi+t_root]

    xor eax, eax

.more cmp rdi, 0

    je .done

    cmp rsi, [rdi+n_value]

    jl .gleft

    jg .gright

    mov rax, rsi

    jmp .done

.gleft:

    mov rdi, [rdi+n_left]

    jmp .more

.gright:

    mov rdi, [rdi+n_right]

    jmp .more

.done leave

ret
```

### 15.4.4 向树中插入键

插入键的第一步是使用 `find` 函数查看该键是否已经存在。如果存在，则不需要插入。如果不存在，则分配一个新的树节点，将其值设置为新的键值，并将它的左右子节点指针设置为 NULL。然后，是时候寻找在树中放置该节点的位置了。

在树中插入第一个节点时有一个特殊情况。如果树中的节点计数为 0，则计数加 1，并将树的根指针设置为新节点。

如果树非空，则你首先设置一个当前指针指向根节点。如果键小于当前节点的键，则新节点应该属于左子树。为了处理这种情况，你检查当前节点的左子指针。如果它是为空的，你你找到了插入点，因此将左指针设置为新节点的指针。否则，更新你的当前节点指针为左指针，并与该节点开始比较。如果它小于当前节点的键，那么它一定大于该键。在这种情况下，你检查当前节点的右子指针，要么将其设置为新节点的指针，要么将你的当前指针移动到右子节点并重复比较过程。

```
; insert ( t, n );

.n equ 0

.t equ 8

push rbp

mov rbp, rsp

sub rsp, 16

mov [rsp+.t], rdi

mov [rsp+.n], rsi

call find

cmp rax, 0

je .done

mov rdi, node_size

call malloc

mov rsi, [rsp+.n]

mov [rax+n_value], rsi

xor edi, edi

mov [rax+n_left], rdi

mov [rax+n_right], rdi

mov rdx, [rsp+.t]

mov rdi, [rdx+t_count]

mov rdi, 0

jne .findparent

inc qword[rdx+t_count]

mov [rdx+t_root], rax

mp .done

.findparent:

mov rdx, [rdx+t_root]

.repeatfind:

cmp rsi, [rdi+n_value]

je .done

.gleft:

mov rdi, [rdi+n_left]

jmp .repeatfind

.gright:

mov rdi, [rdi+n_right]

jmp .repeatfind

.done leave

ret
```

### 15.4.5 按序打印键

按序打印键可以通过递归中序遍历轻松完成。基本思想是访问左子树，打印根节点，然后访问右子树。

```
; print_order ( t );

print:

    push rbp

    mov rbp, rsp

    mov rdi, [rdi+t_root]

    cmp rdi, 0

    je .done

    push rdi

    mov rdi, [rdi+n_left]

    call print

    pop rdi

    mov rsi, [rdi+n_value]

    mov rdi, format

    call printf

    push rdi

    mov rdi, [rdi+n_right]

    call print

    pop rdi

.done:

    pop rbp

    ret
```
