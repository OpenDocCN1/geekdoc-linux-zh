
```c
#include <sys/pstat.h>

main()

{

  struct pst_static buf;

  pstat(PSTAT_STATIC, &buf, sizeof(buf), 0, 0);

  printf("Physical RAM = %ldMB\n", buf.physical_memory/256);

}
```

如果你是 `root` 用户，可以如下所示使用 `adb`：

```bash
echo "physmem/D" | adb /hp-ux /dev/kmem | tail -1 | awk '$2 > 0 { print $2 / 256 }'
```

当然，检查内存的简便方法（如果 `/etc/dmesg` 仍然是最新的）是使用 `grep` 查找：

```bash
/etc/dmesg | grep "real mem" | tail -1 | awk '$4 > 0 { print $4 / 1048576 }'
```

## 如何让打印后台程序创建封页？

有几种方法可以实现这一点。如果你只想针对某个作业关闭它，可以使用 `lp -onb` 的别名。

如果你想为所有打印作业关闭封页，请根据你正在使用的打印后台程序类型选择以下方法之一：

1. 你可以编辑文件 `/usr/spool/lp/interface/*printer name*` 并注释掉横幅页（banner page）。如果你在使用 JetAdmin 工具，实际使用的脚本是 `/usr/spool/lp/interface/model.orig/*printer name*`。

2. 在 `/usr/spool/lp/interface/` 目录下有更新版本的接口文件。这些文件调用 `/usr/lib/rlp`，如果你的模型脚本是这样操作的，你可以在 `/usr/lib/rlp` 语句之前插入以下行：

```bash
BSDh="-h"
```

模型脚本现在看起来可能像这样：

```bash
...
shift; shift; shift; shift; shift
# 你应该在这里输入无横幅选项
BSDh="-h"
/usr/lib/rlp -I$requestid $BSDC $BSDJ $BSDT $BSDi $BSD1 $BSD2 ...
...
```
