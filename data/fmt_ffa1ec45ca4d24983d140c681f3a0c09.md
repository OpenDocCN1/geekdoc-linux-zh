# user（用户）

- 1. 使用计算机进行“真实工作”，将其作为手段而非目的。付费使用计算机的人。参见 `real user`（实实用户）。

- 2. 一个会相信你告诉他的任何事情的程序员。一个提问的人。[GLS 观察到：这有点不公平。用户确实会提问（出于需要）。有些人深思熟虑或很有深度。但他们往往非常烦人或简直愚蠢，因为用户在打扰维护者之前没有思考两秒或查阅文档。参见 `user`（用户）。]

- 3. 有些人从外部使用程序，无论多么巧妙地进入程序内部。报告 bug 而不是直接去修复它们的人。这里的通用理论是，与程序工作的人分为两类：实施者（黑客）和用户。用户在某种程度上被黑客锁定了，因为他们不理解系统在所有辉煌状态下的影响。（该术语是相对的：熟练的黑客可能对他编写的程序有一丝尊重。用户是指无论熟练与否使用程序的人。黑客是指维护程序的人。两者之间存在重叠；细微的区别由语境解决。）源自 术语词典

# 用户账户和用户组 (User Accounts and User Groups)

UNIX 原生支持多用户。每个用户都有一个个人家目录 `/username>`，用户的文件存储在此处并对其他用户隐藏。因此，你可能以 `root` 用户身份使用机器，`root` 是系统管理员并访问系统上的每个文件。`root` 也称为超级用户（superuser）。这里存在歧义：根目录是最顶层目录，称为 `/`。注意 `root` 的家目录是 `/root`，称为 root 的家。除了超级用户之外，其他所有用户对文件和目录的访问都是有限的。始终作为普通用户。登录 `root` 进行系统管理。这就是手动和自动创建具有权限的用户的方法。所有用户都可以属于几个组，系统上可以有任意多个组。每个组由用户列表定义，此外，许多用户可以属于多个组。每个用户都属于一个 root 组，这被称为 root 组。除了 root 组，每个其他用户都有自己的初始组（primary group）。每个用户可以加入多个组（secondary groups），这些组通过权限列表进行定义。源自 VERA

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# 用户级 (user–level)

在操作系统中，程序可以运行的两种上下文。内核上下文在操作系统内部运行，另一个是用户级，在此处系统是被隔离的。这意味着当远程黑客入侵此类服务时，无法获得完全控制权。他们可能需要某种权限漏洞来获取 `root`。源自 黑客词典

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

# 用户模式 (user-mode)

用户模式（内核）是在另一个内核下运行的一种进程。这对于内核开发、沙箱和许多其他事情非常有用。该包包含了执行文件以及相关的内核模块。源自 Debian 3.0r APT
