#### 通过模式搜索定位

| 命令 | 结果 |
| :--- | :--- |
| `/*pattern*` | 移动到包含 `*pattern*` 的下一行 |
| `?*pattern*` | 移动到上一个包含 `*pattern*` 的行 |

| `?` | 向后重复上一次搜索 |
| `n` | 在相同方向重复上一次搜索 |
| `N` | 在相反方向重复上一次搜索 |
| `/*pattern*/+*nbr*` | 到包含 `*pattern*` 的下一之后的 `*nbr*` 行 |
| `?*pattern*?-*nbr*` | 到上一个包含 `*pattern*` 的行之前的 `*nbr*` 行 |
| `/*pattern*/z-` | 重绘屏幕，将包含 `*pattern*` 的下一行置底（其他 `z` 选项将提供相应的定位） |
| `%` | 到与当前光标位置匹配的括号或括号 |
