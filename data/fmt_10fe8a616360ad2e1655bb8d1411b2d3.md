
这个非常简单的distfile定义了一个名为`HOSTS`的变量，它有两个值：`updater@student1.an-university.edu`和`updater@student2.an-university.edu`。这告诉`rdist`在`student1.an-university.edu`和`student2.an-university.edu`上使用`updater`用户账户进行连接。

下一个变量`FILES`定义了`rdist`要分发的目录。这里只分发`/csc101`目录。

第三个变量是`EXCLUDE_DIR`，它被设置为列出所有你想要从分发中排除的文件和目录。示例中的值是`/csc101/instructors`（这可能包含只有教师才能访问的文件）和`/csc101/secret`（学生不应有权访问的目录）。文件的其余部分描述了一个简单的命令：

```
${FILES} -> ${HOSTS}
    install ;
    except ${EXCLUDE_DIR};
```

此命令获取`FILES`变量指向的所有文件和目录，并将它们安装在`HOSTS`变量指示的主机上。它还告诉`rdist`排除由`EXCLUDE_DIR`变量指定的文件和目录。要以`(updater)`身份运行`rdist`，请从命令行执行以下操作：

- 以`updater`身份登录。（如果你是主系统上的`root`，也可以使用`su`将UID更改为`updater`。）

- 以`updater`身份运行以下命令：

```
 /usr/bin/rdist -p /usr/sbin/rdist -oremove,quiet \
      -f /usr/local/rdist/rdist_distfile
```

以下是选项的说明：

- `-p`。指定`rdist`所需的`rdist`程序的位置。

- `-o`。指定后面跟随一个或多个选项——在本例中为`remove`和`quiet`。

- `remove`。告诉`rdist`删除在目标系统目标目录中发现的任何多余文件。这为在每个学生系统上维护文件的相同副本提供了一种简单的方法。

- `quiet`。告诉`rdist`在操作期间尽可能安静。

- `-f`。指定`distfile`的位置。

为了减少运行此命令时的人为错误，请创建一个名为`r-distribute.sh`的`sh`脚本，如清单13-2所示。

### 清单13-2：`rdistribute.sh`脚本

```
#!/bin/sh
#
# This script runs rdist to update Web servers via the
# non-routable lan an-university.edu. The script is run
# by cron at a fixed interval.
#
# /etc/rc.d/rc.local starts the script to clean up
# left-over tempfile that might have been left
# at shutdown. This process also removes the
# log file.
```

```
# $Author$ (kabir@nitec.com)
# $Version$
# $ID$
# $Date$
# $Status
###############################################

# If the script is called with an
# argument then
case "$1" in
boot)

    # since the argument is 'boot' the script is being
    # called at system start-up so remove all old lock
    # files and logs.
    echo -n "Cleaning up rdist.rsh tmp files: "
    rm -f /tmp/rdist.lck
    rm -f /tmp/rdist.log
    echo "Complete."
    exit 0;
 ;;

    # since the argument is 'restart' the script
    # needs to clean up as if the system just booted.
restart)
    $0 boot
 ;;

esac
```

### 清单13-2（续）

```
# If the lock file exists then don't do anything.
if [ -f /tmp/rdist.lck ]; then
  exit 0
fi

# Otherwise create the lock file using /bin/touch
/bin/touch  /tmp/rdist.lck

# Run rdist
/usr/bin/rdist -p /usr/sbin/rdistd \
  -oremove,nochkgroup,nochkmode,nochkowner,quiet -f \
  /usr/local/rdist/rdist_distfile

# Remove the lock file
rm -f /tmp/rdist.lck

# Write the time and date in the log file
echo `date` >> /tmp/rdist.log

# Exit the script
exit 0
```

该脚本足够智能，可以通过使用锁文件来检测正在进行的`rdistribute.sh`进程，锁文件可以判断之前的`rdistribute.sh`是否已经在运行并继续。当大量文件在多个服务器上更新时，可能会发生这种情况。该脚本还接受一个名为`boot`的参数，可用于在启动过程中清理它创建的锁文件和日志文件。该脚本应从`/etc/rc.d/rc.local`调用，如下所示：

```
/usr/local/rdistribute.sh boot
```

可以通过`/etc/crontab`中的`cron`条目来安排此脚本运行。例如，要每小时运行此脚本一次，可以在`/etc/crontab`中添加以下`cron`条目：

```
01 * * * * updater /usr/local/rdistribute.sh > /dev/null
```

`cron`守护进程将以`updater`身份运行该脚本。或者，你可以根据需要从`/etc/cron.hourly`（或`/etc/cron.daily`、`/etc/cron.monthly`等）创建指向`rdistribute.sh`的链接。

### 安装XFree86

当你从官方CD-ROM安装Red Hat Linux时，你有机会安装和配置XFree86。如果你还没有这样做，可以使用CD-ROM上的RPM包轻松安装XFree86。要从CD-ROM的RPMs目录安装XFree86，请运行以下命令：

```
rpm -ivh XFree86*.rpm
```

这将从CD-ROM安装所有XFree86包。

在为你的系统配置XFree86之前，你需要知道以下信息：
