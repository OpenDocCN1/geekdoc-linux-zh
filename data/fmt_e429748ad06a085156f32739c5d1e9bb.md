
交互式进程通过终端会话初始化和控制。换句话说，有人连接到系统才能启动这些进程；它们不是作为系统功能的一部分启动的。这些进程可以在前台运行，占用启动程序的终端，由于该进程正在前台运行，你无法启动其他应用程序。或者，它们可以在后台运行，这样你启动程序的终端就可以在程序运行的同时接受新命令。到目前为止，我们主要关注在前台运行的程序——它们运行的时间通常太短，不足以察觉——使用 `less` 命令查看文件就是一个占用终端会话的命令示例。在这种情况下，被激活的命令正在等待你执行某些操作。程序仍然连接到它启动的终端，而该终端仅用于输入该程序能理解的指令。其他命令将导致错误或系统无响应。

当进程在后台运行时，用户并不会被阻止做其他事情。Shell 提供了一种名为“作业控制（job control）”的功能，可以方便地在前台和后台之间切换进程。使用这种机制，程序可以立即在后台开始运行。

在后台运行进程通常适用于不需要用户输入的程序。通过在命令末尾添加符号 `&` 可以实现这一点。例如：

```
billy:-> xterm &
```

下表显示了如何使用作业控制管理进程：

| 命令部分 | 含义 |
| :--- | :--- |
| `&` | 在后台运行命令。 |
| `Ctrl+C` | 中断（终止）进程。 |
| `Ctrl+Z` | 挂起（停止）进程。 |
| `jobs` | 显示所有作业 |
| `bg` | 在后台运行作业。 |
| `fg` | 将作业放回前台。 |
| `kill` | 终止进程。 |

### 自动进程

自动进程（或批处理进程）不连接到终端。相反，这些任务被排入队列区域，并按照先进先出（FIFO）原则执行。此类任务可以使用以下两种标准之一进行执行：

- 在指定的日期和时间：使用 `at` 命令。
- 在系统负载足够时：使用 `batch` 命令。

大多数情况下，进程拥有与发行用户相同的权限。一个说明此点的例子是：`/usr/bin` 中的浏览器 `mozilla` 由 root 用户使用：

```
theo:> ls -1 /usr/bin/mozilla
-rwxr-xr-x 1 root root 4996 Nov 20 18:28 /usr/bin/mozilla*
theo:> mozilla &
```

### 守护进程

守护进程是持续运行服务器进程。大多数情况下，它们在系统启动时初始化并在后台等待，直到需要它们的服务。一个典型的例子是网络守护进程 `xinetd`，它在几乎引导过程中都会启动。系统启动后，网络守护进程一直等待，直到客户端程序（如 FTP 客户端）连接。

### 进程属性

进程有一系列特征，可以通过 `ps` 命令查看：

- 进程 ID `PID`：用于引用进程的唯一标识。
- 父进程 ID `PPID`：启动该进程的进程 ID。
- Nice 值：该进程对其他进程的友好程度（不要与进程优先级混淆，优先级根据该值和最近的 CPU 使用情况计算）。
- 终端或 TTY：进程连接的终端。
- 真实用户和有效用户 `RUID` 和 `EUID`：进程的所有者。真实所有者是使用的用户，有效用户是决定系统资源访问的用户。`RUID` 和 `EUID` 通常相同，进程拥有与发行用户相同的权限。

[1] 26595

```
theo:-> ps -af
UID PID PPID CIME TTY TIME CMD
theo 26601 26599 15:04 pts/5 00:00:00 /usr/lib/mozilla/mozilla-bin
theo 26613 26569 15:04 pts/5 00:00:00 ps -af
```

当用户启动此进程时，该进程本身以及由初始进程启动的所有进程都将由用户所有，而不是系统管理员所有。当 `mozilla` 需要访问文件时，该访问将由用户的权限决定，而不是由 root 决定。

- *实际和有效组所有者 `RGID` 和 `EGID`：进程的实际组所有者是启动该进程的用户的主组。有效组所有者通常相同，除非对文件应用了 SGID 访问模式。*

## 显示进程信息

``ps` 命令是可视化进程的工具之一。该命令有多个选项，可以组合起来显示进程属性。

在不带任何选项的情况下，`ps` 仅提供关于当前 shell 和最终进程的信息：

```
theo:-> ps
PID TTY TIME CMD
4245 pts/7 00:00:00 bash
5314 pts/7 00:00:00 ps
```

由于它没有提供足够的信息——通常，你的系统中至少运行着上百个进程——我们将使用管道中的 `grep` 命令从所有进程列表中选择特定的进程（请参见文中的“使用 `>` 和 `[]` 减少输出”章节），此行命令将选择并显示特定特定用户的所有进程：

```
ps -ef | grep username
```

此示例显示了所有名为 `bash` 的进程，这是 Linux 系统上最常见的登录 shell：
