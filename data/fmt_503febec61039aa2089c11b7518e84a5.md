# logname — 返回用户的登录名

### Synopsis

```
/usr/bin/logname
```

## Description

`logname` 命令将你的登录名写入标准输出，如下所示：

```
castle% logname
winzor
cast%
```

登录名是 `getlogin(3)` 函数返回的字符串。在 `getlogin()` 失败的情况下，`logname` 向标准错误写入诊断消息并以非零状态退出。

# Environment Variables

见 `environ(5)` 描述影响 `logname` 执行的环境变量：`LC_CTYPE`、`LC_MESSAGES` 和 `PATH`。

# Exit Status

- 0 完成成功。
- 0 发生错误。

```

# look — 在系统字典或排序列表查找查找单词

Synopsis

```
/usr/bin/look [-d][-f][-tc] string [filename]
```

## 描述

`look` 命令查询一个排序后的文件名并打印所有以字符串开头的行。如果你未指定文件名，`look` 将使用 `/usr/share/lib/dict/words` 并配合 `-df` 排序序列。`look` 将搜索长度限制为 256 个字符。

## 选项

- `-d`

  字典顺序。在比较时仅使用字母、数字、制表符（Tabs）和空格字符。

- `-f`

  折大小写。比较时不区分大写字母和小写字母。

- `-tc`

  设置终止字符。忽略字符串中字符 c 之后的所有字符。

## 示例

以下示例使用默认字典列出所有以字符串 `sun` 开头的行。

```

# lookbib — 在文献数据库中查找引用

### 概要

```
/usr/bin/lookbib database
```

## 描述

文献引用是一组行，构成了文献信息字段。每个字段从以百分号（%）开头的行开始，后面跟着一个字母、一个空格，最后是字段内容，该内容可能一直持续到下一个以 % 开头的行为止。

`lookbib` 使用由 `lookbib` 创建的反向索引来查找参考文献集。它读取在终端 `>` 提示符后输入的输入的关键词，并检索包含所有这些关键词的记录。如果没有匹配项，除了返回另一个 `>` 提示符外，不返回任何内容。

只要多个数据库具有由 `lookbib` 创建的共同索引，你就可以搜索多个数据库。在这种情况下，只需指定给 `lookbib` 的第一个参数。

如果 `lookbib` 未找到索引文件（`.i[abc]` 文件），它会查找与参数同名但不带后缀的引用文件。它会创建一个带有 `.ig` 后缀的文件，适用于 `grep`（参见 `grep(1)`）。然后 `lookbib` 使用 `grep` 来查找引用。这种方法用起来更简单，但 `.ig` 文件比 `.i[abc]` 文件慢，且不允许使用多个引用文件。

### 缺陷

所有的日期可能都应该索引，因为许多学科都引用了 1800 年或更早编写的文献。

## 示例

以下示例访问名为 `bibliography` 的文献文件，显示指令，并搜索关键词 `dreams` 的引用。

```
castle@ lookbib bibliography
Instructions? y
```

在提示符后输入关键词（如作者和日期）。如果存在带有这些关键词的引用，将将其打印；如果没有匹配项，将会给你另一个提示符。要退出 `lookbib`，请在 `>` 提示符后按 CTRL-d。

```
> dreams
%A Janice Winsor
%T Opening the Dream Door
%P 15
%I Merrill-West Publishing
%C Carmel, California
%D 1998
%K dreams, psychic development
%X Not just another dream interpretation book! Opening the Dream Door is a practical guide to psychic development. *Opening the Dream Door* 以一种亲切、个人化的风格编写，并不尝试解释梦的象征。作者认为每个人都有自己个人的神话和符号，这些无法以集体的方式进行解读。通过使用自己的梦作为例子，Janice Winsor 为扩展潜意识生活和连接其他领域提供了实用的建议。书中以易于理解的方式教授了记忆和进入梦境的方法。
```
