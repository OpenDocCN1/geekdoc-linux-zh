# fdformat — 格式化磁盘或 PCMIA 内存卡

## 摘要

```
/usr/bin/fdformat [-dDeEfH1MMUqvx] [-b label] [-B filename] [-t dos] -t nec [devname]
```

## 说明

使用 `fdformat` 命令格式化磁盘和 PCMIA 内存卡。你不需要在使用之前对它们都进行格式化。`fdformat` 会格式化并验证介质，并指示是否遇到任何坏道。磁盘或 PCMIA 内存卡上的所有现有数据（如果有）都会在格式化时被破坏。如果你不指定设备名称，`fdformat` 将使用磁盘作为默认值。

默认情况下，`fdformat` 使用驱动器的配置容量来格式化磁盘。3.5 英高密度驱动器使用格式化容量为 144 兆字节的磁盘。5.25 英高密度驱动器使用格式化容量为 1.2 兆字节的磁盘。在任何情况下，当你使用容量低于驱动器默认值的磁盘时，都需要指定密度。`-H` 选项用于在超高密度（ED）驱动器中格式化高密度磁盘（144 兆字节容量）。使用 `-D` 选项、`-l` 选项或 `-L` 选项在 HD 或 ED 驱动器中格式化双面（或低密度）磁盘（720 千字节容量）。对于中等密度磁盘（1.2 兆字节容量），使用配合 `-t nec` 的 `-M` 选项（这与配合 `-t nec` 使用 `-m` 选项相同）。

扩展密度使用双面扩展密度（或超高密度）介质（DS/ED）磁盘。中等密度和高密度使用相同的介质：双面高密度（DS/HD）磁盘。双密度（低密度）使用双面双密度（DS/DD）磁盘。

> 注意 — 用更高或更低密度的磁盘替换另一种密度的磁盘通常无法运行。每当磁盘被格式化为与其密度不匹配的容量时，无法保证数据完整性。

你可以使用 `fdformat` 命令格式化密度从 512 千字节到 64 兆字节的 PCMIA 内存卡。除非使用 `-x` 选项，否则 format 会为所有轨道上的每个扇区写入新的标识数据字段。对于磁盘，如果你指定了 `-v` 选项，将验证每个扇区。

格式化并验证后，`fdformat` 在块 0 上写入操作系统标签。使用 `-t dos` 选项（与 `-d` 选项相同）在格式化完成后磁盘或 PCMIA 内存卡上建立 MS-DOS 文件系统。使用配合 `-M` 选项的 `-t nec`（与 `-m` 选项相同）在磁盘建立 NEC-DOS 文件系统。否则，`fdformat` 在块 0 写入 SunOS 标签。

**注意** - 包含在 SPARC 系统上创建的（通过使用 `fdformat` 和 `newfs(1M)`） ufs 文件系统的磁盘或 PCMCIA 内存卡，与在 x86 系统上创建的文件系统的磁盘或 PCMCIA 内存卡是不相同的。不要在这些平台之间交叉 ufs 磁盘或内存卡；请使用 `cpio(1)` 或 `tar(1)` 在磁盘或内存卡之间传输文件。

使用 `-t dos` 选项 (`-d`) 为 MS-DOS 格式化的磁盘或 PCMCIA 内存卡没有必要的系统文件，因此无法启动。在 PC 上尝试从其启动将显示以下消息：

Non-System disk or disk error
Replace and strike any key when ready

## 错误

目前，磁盘或 PCMIA 内存卡不支持坏道映射。因此，如果 `fdformat` 发现错误（坏道），则磁盘或内存卡将不可用。

## 选项

- `-D` 格式化 720 千字节（3.5 英寸）或 360 千字节（5.25 英寸）双密度磁盘（与 `-l` 或 `-L` 选项相同）。此选项是双密度类型驱动器的默认选项。仅当驱动器是高密度或扩展密度类型时才使用它。
- `-e` 完成后弹出磁盘。（此功能并非所有系统上均可用。）
- `-E` 完成后弹出磁盘。（此功能并非所有系统上均可用。）
- `-f` 不询问确认。
- `-H` 在超高密度（ED）驱动器中格式化高密度磁盘（144 兆字节容量）。
- `-l` 在 HD 或 ED 驱动器中格式化双面（或低密度）磁盘（720 千字节容量）。
- `-L` 在 HD 或 ED 驱动器中格式化双面（或低密度）磁盘（720 千字节容量）。
- `-M` 对于中等密度磁盘（1.2 兆字节容量），使用配合 `-t nec` 的 `-M` 选项（这与配合 `-t nec` 使用 `-m` 选项相同）。
- `-m` 对于中等密度磁盘（1.2 兆字节容量），使用配合 `-t nec` 的 `-M` 选项（这与配合 `-t nec` 使用 `-m` 选项相同）。
- `-q` 不打印状态。
- `-t dos` 在格式化完成后磁盘或 PCMIA 内存卡上建立 MS-DOS 文件系统。
- `-t nec` 在磁盘上建立 NEC-DOS 文件系统。
- `-U` 卸载所有文件系统。
- `-v` 验证每个扇区。
- `-x` 跳过为所有轨道上的每个扇区写入新的标识数据字段。

## 示例

在下面的示例中，软盘已使用 `volcheck` 命令挂载。`fdformat` 显示了一个错误信息，提示您在格式化之前使用 `-U` 选项卸载软盘。

```
castle$ volcheck

castle$ fdformat

fdformat: /vol/dev/rdiskette0/unnamed_floppy is mounted (use -U flag)

castle$
```

在下面的示例中，使用 `fdformat -U` 命令，`fdformat` 检测到格式化错误（如 e 所示）并退出。

```
castle$ fdformat -U

Formatting 1.44 MB in /vol/dev/rdiskette0/unnamed_floppy

Press return to start formatting floppy.
```

```
fdformat: can't read format data, I/O error

castle$ eject
```

接下来的示例使用了不带参数的 `fdformat`（针对新软盘），在软盘上成功创建了 SunOS 文件系统。

```
castle$ fdformat

Formatting 1.44 MB in /vol/dev/rdiskette0/untitled

Press return to start formatting floppy.
```

接下来的示例使用 `-d` 选项在软盘上成功创建了 DOS 文件系统。

```
castle$ fdformat -d

Formatting 1.44 MB in /vol/dev/rdiskette0/untitled

Press return to start formatting floppy.
```

castle$
