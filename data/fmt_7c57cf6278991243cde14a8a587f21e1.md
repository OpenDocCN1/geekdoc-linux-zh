
将微软 Windows Server 替换为托管 Linux 和开源解决方案的服务器是一个合理的替代方案，它能够以极小的麻烦提供类似的功能，并且成本可能更低。最大的考虑是支持该服务器的技术人员的教育。你可以遵循两条路径：一种是在内部获取知识，另一种是在你的 IT 部门外部寻求不同程度的帮助。在早期阶段，你可能会选择聘请系统集成商来用 Linux 和开源软件替换遗留系统，或者获取带有供应商支持的商业 Linux 软件包。

# Linux 服务器发行版

许多提供桌面 Linux 发行版的发行商也提供服务器发行版。你可能考虑对服务器和桌面使用同一家供应商以提供单一的联系点，尽管这并非必须。由于 Linux 服务器和桌面使用开放标准进行通信，一家公司的桌面系统将与另一家公司的服务器产品兼容。这是相比于微软后台的巨大优势，因为如果你对某个供应商的产品感到幻灭，你可以转向另一个供应商，他们仍然拥有核心产品，但呈现方式和支持机制略有不同。

## 通用服务器发行版

Linux 服务器和服务，无论供应商如何，都可能利用从操作系统内核到文件和打印服务的相同核心技术。区别将在于支持你发行版选择的供应商或项目，以及管理工具和其他增值功能。根据你对桌面发行版的选择，你的选择将会有所不同，你应该像选购任何 IT 解决方案一样进行货比三家。以下发行版都已成功用于提供服务器操作系统。

### Novell

Novell 提供了两种服务器操作系统发行版。Novell Open Enterprise Server 结合了 NetWare 和 SUSE Linux Enterprise Server，以支持 NetWare 和 Linux 网络。SUSE LINUX Enterprise Server 是一个纯正的 Linux 解决方案，可以为任何基于开放标准的企业提供企业级基础设施。Novell 还为其产品提供专业支持。

### Red Hat

Red Hat 有两种服务器解决方案：Red Hat Enterprise AS 和 Red Hat Enterprise ES。ES 产品是入门级产品，限制用于特定的 CPU 数量和总内存，但非常适合小型企业。AS 服务器产品是为大型 SMP 服务器和非 Intel 平台（如 PowerPC 和 IBM zSeries）设计的。AS 服务器还通过提供企业支持合同有所不同。两种操作系统都可以通过付费订阅 Red Hat Network 获取更新。

### Mandriva

Mandriva Corporate Server 是一种可扩展的服务器，与所有其他服务器方案一样，具有相同的服务集（如文件和打印服务），但包含了他们发行版特定的安全系统管理和处理服务器更新的 `Drakpar` 工具。他们计划保持十二到十八个月的升级周期和五年的维护承诺。Mandriva 是中小企业稳定可靠的选择。

### Debian

Debian 是最成熟的 Linux 发行版之一，与上述 Linux 发行版相比，它是完全免费的并由活跃的开发者和用户社区支持。它的受欢迎通常归功于 `apt` 安装系统使得更新和安装变得非常简单。Debian 项目创始人 Ian Murdock 是 Progeny 的 CTO，Progeny 是一家基于 Debian 构建自定义 Linux 的咨询公司。他们还为其他发行版提供定制和支持。在大型企业中，像 Progeny 这样的公司可以帮助根据特定的软件需求构建并提供更新。2005年8月，多家公司宣布了 Debian Core联盟（由 Linsp、Xandros、MEPIS 等公司支持），他们合作开发基于 Debian 的商业发行版。无论采取哪种方式，你都可以选择自力更生的方法，或者确保通过公司获得支持。

这些只是可替换 Microsoft 服务器的众多发行版中的几个。还有其他选项，但它们通常是基于任务的，例如通过商用的 Astaro Linux 提供防火墙。

## 特殊服务器发行版

有成百上千种特殊的 Linux 发行版可能用于提供取证数据或安全服务。根据你的具体需求，你可能会找到已经为你解决过问题的人。这些发行版中的许多在设计时都有特定的侧重点，例如安全性，或单一任务（如防火墙）。

### 安全增强型 Linux (SELinux)

美国国家安全局 (NSA) 致力于为 Linux 提供增强的安全功能，用于管理访问控制以及如何将这些功能添加到 Linux 中。简而言之，SELinux 是一种增强型的 Linux 内核，它能够最大限度地减少用户执行工作所需的程序权限。将用户限制在所需的最小空间内有助于降低安全漏洞的风险。SELinux 可以安装到像 Red Hat 这样的 Linux 发行版中，以增强其已有的安全功能。

### Scyld 平台

Scyld 是一个旨在提供基于标准的 Linux 发行版的示例，它包含了所有工具，用于部署和管理执行大型复杂计算的高性能 Linux 集群。在研发设施中，集群是有效的，它们利用商品化的 x86 服务器和 Linux 并配合 Scyld 工具来实现增值。

### BlueCat Linux

BlueCat Linux 是来自 Linuxworks 的一种嵌入式 Linux，可以用于多种方式，但与 Scyld 不同的是，它也可以运行在小型消费级设备上。Blue 提供开发和调试工具作为增值服务。

提到这些特殊 Linux 发行版的目的是为了让你意识到，你有非常非常多的选择可供选择。如果你有主流 Linux 供应商无法满足的特殊需求，那么花时间去研究其他发行版可能是值得的。

# 后台基础设施的开源服务

Microsoft Windows 服务器提供的几乎所有服务，在 Linux 提供的基础设施服务中都有功能上等同的替代品。从历史长河来看，微软并不一直都占据着主导地位；事实上，在过去的 30 年或更长的时间里，Unix 操作系统的变体在网络计算服务中一直发挥着作用。Linus Torvalds 最初整合到 Linux 的许多功能灵感源于 Andrew S. Tanenbaum 开发的 Unix 克隆版本 MINIX。它在互联网上传输的 TCP/IP 协议栈最初是在 Unix 上开发的。对于文件和打印共享，Microsoft 服务器和客户端通过 TCP/IP 使用 CIFS-SMB（通用互联网文件系统-小消息块）协议进行通信，而 Unix 服务器使用由 Sun Microsystems 开发的 NFS（网络文件系统）协议。NetBIOS（网络基本输入输出系统）基于 IBM 和 Vect 开发的 SMB 格式，很快变成了一个标准，现在被称为基于 TCP/IP 的 NetBIOS (NBT)。NetBIOS 提供了在 Windows 中浏览 Microsoft Windows 服务器名称的能力。Linux 桌面用户要与这些 Microsoft Windows 机器交互，他们需要使用允许他们通过 SMB 协议进行通信的网络软件。Unix/Linux 用户与 Microsoft Windows 客户端或服务器通信的事实标准软件是 Samba 项目的一部分。1992 年，澳大利亚程序员 Andrew "Tridge" Turnbull 正苦于如何让 Unix 服务器在 Windows 机器看起来像 PC 文件服务器的问题。为了实现这一点，Andrew 对 SMB 协议进行了反向工程，并在 Unix 上实现了它。不久后，它被移植到 Linux，从那以后，它已成为 Windows 和 Unix/Linux 互操作性最重要的技术之一。

## Samba 文件和打印服务

Samba 通常是一组工具，对于文件和打印共享以及使用 SMB 协议非常有用。组成 Samba 的两个主要程序是 `smbd` 和 `nmbd`。它们共同提供了四种 CIFS 服务：

- **文件打印服务：** 这些服务由 `smbd` 提供，也称为 SMB 守护进程（daemon）。
- **身份验证与授权：** 这些服务由 SMB 守护进程提供，允许用户共享打印机和文件空间。访问文件空间和打印受密码控制。这些共享资源被称为“共享”（shares）。这是 Microsoft Active Directory 服务器的主要功能之一。
- **名称解析：** 在连接到局域网（LAN）时解析计算机名称的能力。
- **服务公告：** 浏览也由 `nmbd` 处理，它通过广播公告然后接收网络上其他 PC 的响应来工作。

说有一个完全替代 Active Directory 的方案是不准确的。对 Active Directory 的 Linux 替代方案的需求最终可以通过更新版本的 Samba 来解决，但当你查看开源替代方案时，这一点值得注意。
