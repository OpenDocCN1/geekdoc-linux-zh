
使用 CD-RW 磁盘与使用 CD-R 磁盘非常相似。如果磁盘是空白的，过程没有任何区别，这使得事情变得非常简单。而且，如果 CD-RW 磁盘上已经是你想要替换的数据，过程仅略有不同。

这些区别之一是，Nautilus 将你的 CD-RW 磁盘视为普通数据磁盘而非空白磁盘。这意味着当你将磁盘插入驱动器时，会自动打开一个普通的 Nautilus 窗口，而不是 CD/DVD 刻录器窗口。

要写入磁盘，你需要手动从 Nautilus 窗口切换到 CD 刻录器窗口，这可以通过在打开的 Nautilus 窗口的“转”（Go）菜单中选择“CD/DVD Creator”来轻松实现。

## 将 ISO 镜像刻录到磁盘

你已经完成了这一步，窗口将变为 CD/DVD 刻录器窗口。现在将想要刻录到 CD 的文件拖到该窗口，一旦准备好刻录，点击**写入磁盘**按钮。

与普通的 CD-R 磁盘或 DVD 一样，会出现一个写入磁盘窗口。然而，当驱动器中使用使用的 CD-RW 磁盘点击该窗口中的**写入**按钮时，会发生细微的变化。此时，会出现一个类似图 6-14 所示的新窗口，提示磁盘似乎已经写入了文件。点击该窗口中的**擦除磁盘**（Erase Disc），CD/DVD 刻录器将擦除 CD-RW 上已有的文件，并用你拖到 CD/DVD 刻录器窗口的新文件替换它们。很不错，对吧？

![](img/ba6b82a7869bba748202d57c97336dca_113_0.png)

图 6-14：使用 Nautilus 擦除 CD-RW 磁盘

当你从互联网下载 Fedora Core 或其他 Linux 发行版时，你通常以一个或多个磁盘镜像的形式下载，这些通常被称为 ISO。如果你想知道如何复制 CD，Nautilus 无法进行写入。要实现这一点，你需要另一个不同的磁盘刻录应用程序。我推荐 GnomeBaker。

你可以从 Synaptic 下载并安装 GnomeBaker（搜索 `gnobaker`）。安装后，可以通过应用程序菜单中的“辅助工具 > CD/DVD Writer”来运行。

要将第一个会话刻录到 CD，点击 GnomeBaker 窗口下半部分的**数据 CD**（Data CD）按钮。之后将想要刻录的文件拖到 GnomeBaker 窗口右下角的面板，数据 CD 标签下（图 6-15）。你可以从 GnomeBaker 两个面板的浏览器、Nautilus 窗口或桌面拖动文件。

当你将所有想要刻录的文件就位后，点击屏幕右下角的**刻录**（Burn）按钮。会出现一个名为“创建 CD”（Create CD）的新窗口。在该窗口中，在“模式”（Mode）旁边的下拉菜单中选择。完成后，在驱动器中插入空白磁盘，并点击**开始**（Start）。刻录过程将开始。GnomeBaker 将完成后弹出磁盘。

## 复制 CD

复制时，确保 GnomeBaker 窗口右下角的面板是空的（如果不是，点击**清除**按钮），然后将多会话磁盘插入驱动器。在驱动器完成会话且你移开该导航窗口后，进入 GnomeBaker 的**项目**（Project）菜单，选择**导入会话**（Import Session）。会弹出一个窗口要求你选择多会话磁盘的位置。你可能只有一个驱动器，正确的设备应该已经显示。如果是这样，点击**确定**。

之前会话的文件现在将出现在底部面板。要向磁盘添加更多要刻录的文件（从而创建新会话），按照刻录初始会话的操作程序即可。

## USB 存储设备

在任何涉及文件处理和存储的章节中，如果不谈及 USB 存储设备这一话题将是不完整的，而这正是我现在要转而讨论的话题。除非你过去几年里一直使用数字机架，否则你无疑对 USB 设备并不陌生。你的打印机很可能是一个 USB 设备，扫描仪也是。尽管你的数码相机在传统意义上不是 USB 设备，但很有可能每当你为了传输照片而将其连接到计算机时，都是通过 USB 接口进行的。

在最受欢迎的 USB 设备中，用于文件存储的设备是主流。这些包括外部硬盘、闪存阅读器以及被称为闪存盘的指头大小微型设备（图 6-16）。闪存盘今天非常流行，这实至名归：它们非常廉价，当你需要从计算机之间传输相当大但并非巨量的数据时（例如，从公司带到家里），它们极其方便；而且在跨平台（包括 Linux）的兼容性方面也相当安全。

## 让 USB 存储设备投入工作

让我们先从一个好消息开始，即使用 USB 存储设备实际上非常简单。只需将设备插入计算机上的任一 USB 端口。当系统读取设备上的内容时，设备上的 LED 指示灯会闪烁，之后桌面上会出现该设备的磁盘图标。几刻之后，一个 Nautilus 窗口将打开，显示设备的内容。然后你就可以使用在本章前面提到的拖放或复制/粘贴程序在设备之间复制文件了。

一旦完成操作并想要移除设备，右键点击其桌面图标，并在弹出菜单中选择“卸载（Unmount）”。如果有任何需要写入设备的数据，系统将开始写入并在屏幕右下方的消息中通知你（如 6-17 左侧所示）。写入完成后，相同位置会显示另一条消息，告诉你可以安全地从 USB 端口移除驱动器（图 6-17 右侧）。

## 项目 6：创建和提取压缩文件

既然我一直在谈论文件存储，那么在本章结束时教你如何创建和提取压缩文件似乎是恰当的。在 Windows 世界中，这些通常被称为 Zip 文件，而在 Linux 世界中，tarball（压缩包）是操作名称。如果你好奇的话，Linux 的名称来自于用于创建此类文件归档的应用程序 Tar。

无论如何，为了进行一些实际操作，我们将创建一个 Windows/Mac 兼容的 Zip 文件并提取它。我们可以通过打开一个 Nautilus 窗口并创建两个虚拟文件来开始工作。你可以通过进入 Nautilus 的“文件”菜单并选择“创建空文档（Create Document Empty File）”来实现。Nautilus 窗口会出现一个新文件，文件名会被高亮。你现在可以为文件命名，例如我正在使用的：`dogwood`。现在重复此过程创建第二个文件。我将它命名为 `violet`。你也可以用类似的名称命名你的。

现在我们有两个文件可以操作了，让我们按照以下步骤开始创建压缩归档：

1. 通过鼠标点击文件侧边，然后拖动光标（保持按住鼠标键）越过两个文件直到它们被高亮，或者通过按住 CTRL 键并分别点击每个文件。

2. 一旦两个文件都被高亮，右键点击其中任意一个，并在弹出菜单中选择“创建归档（Create Archive）”。

3. 在随后出现的“创建归档”窗口中，在“创建归档”框中输入 `blossoms`，然后从右侧的下拉菜单按钮中选择 `zip`。一切看起来就像我在图 6-18 中设置的那样，点击“创建”按钮，随后两个文件的压缩包（`blossoms.zip`）就会出现在你的主目录中。

1. 将压缩文件拖到桌面。

2. 双击压缩文件。

3. 在出现的窗口中，点击“提取（Extract）”按钮。

4. 将创建一个包含压缩归档内容的文件夹。
