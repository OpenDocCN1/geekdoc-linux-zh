## 引言

在 Unix 中，有许多方法可以完成特定的任务。对于要解决的问题，我们可以通过任何方式获得解决方案。当然，某些方法更有效，占用的磁盘空间或内存更少，或者可能向用户提供反馈，提供更准确的细节和更精确的结果。在本书，我们将详细介绍编写 Shell 脚本以解决现实中的 Unix 问题和任务。脚本范围涵盖了使用伪随机数生成器创建伪随机密码，到检查 Unix 机器的磁盘空间，以及向 Windows 桌面发送弹出消息。编写这些 Shell 脚本所需的细节是通过良好的风格使其易于维护，并对每个步骤都提供良好的注释。其他细节包括在可行的情况下将命令合并为一个语句，在概念可能难以理解时将命令拆分为多行，并使脚本易于维护。我们将看到使用变量和文件存储数据的用处，展示如何从命令输出中剔除不需要的数据，并对数据进行格式化。此外，我们还将展示如何在脚本中包含函数，并演示不使用函数的脚本优势。

## 本书与技术概述

本书旨在作为学习脚本的工具和学习指南。它适用于 Unix，但其重点包含了 AIX、Linux 和 Solaris。我发现书中的 Shell 脚本可以在任何版本的 Korn shell 上运行。

## 你将需要的工具

为了从书中获得最大的益处，你需要访问一台 Unix 机器，最好安装了 AIX、HP-UX、Linux 或 Solaris。你可以在标准的 PC 硬件上运行 Linux 和 Solaris，而且相对廉价。将你的默认 shell 环境设置为 Korn shell (`ksh`) 是一个好主意；Linux 上的标准 shell 是 Bourne shell (`bash`)，其他则使用 Bourne shell (`sh`) 作为默认。你可以通过输入 `echo SHELL` 来找到你的默认值。书中的所有脚本都不需要图形终端，但运行 `GNOME`、`CDE`、`KDE` 或 `X-Windows` 也没有坏处。这样你就可以同时在多个窗口中工作，并在它们之间复制粘贴代码。

你还需要一个你习惯使用的文本编辑器。大多数 Unix 系统都带有 `vi` 编辑器，许多系统还包含 `enacs`。记住，编辑器必须是按标准 ANSI 格式存储文件的文本编辑器。CDE 和其他 X 编辑器也能运行良好。你还需要一些时间、耐心以及一个准备好学习的开放、创造的心灵。

## 变量命名注意

另一个注意的是，书中 shell 脚本和函数使用的所有变量都是大写的。这样做是因为如果你能快速知道变量在代码中的位置，跟随 shell 脚本容易得多。当你编写自己的 shell 脚本时，对所有的 shell 脚本和函数变量使用小写。这之所以很重要是因为操作系统和应用程序中的环境变量都是大写的。如果你不小心，可能会用自己的值覆盖系统或应用程序变量并导致系统崩溃；然而，这取决于变量在代码中可见的范围。在此警告一下，使用大写变量要小心！
