## 19.7 WAV 文件的直接录制和播放

`alsa` 软件包中的 `record` 和 `aplay` 提供了 PCM 设备的简单接口。`record` 和 `aplay` 可用于录制和播放 WAV 格式的音频数据。使用命令 `record -d 10 -f wav mysong.wav` 录制一个 10 秒的 WAV 文件（CD 质量）。通过运行 `--help` 选项列出 `record` 和 `aplay` 的所有选项。

qaRecord 是一个具有图形界面和电平显示的简单录制程序。由于该程序使用了内部缓冲区 1MB（通过 `--buffersize` 配置），即使在慢硬件上也能实现不中断的录制，特别是当以实时优先级运行时（参见第 308 页的第 19.4 节）。在录制期间，当前使用的缓冲区显示在状态栏的“缓冲区 (Buffer)”下，到目前为止的最大缓冲区显示在“峰值 (Peak)”下。

## 19.8 压缩数据

CD 质量的未压缩音频数据每分钟占用十 MB。MP3 程序是为了大幅压缩数据而开发的。遗憾的是，该程序拥有专利。因此，发行 MP3 编码器的公司需要支付许可费。强大的 MP3 编码器 Lame 是为 Linux 开发的。虽然 Lame 的源代码遵循 GPL，但 SUSE 不允许我们的发行版包含此编码器。有关法律状况的更多信息，请访问项目网页 http://lame.sourceforge.net。在某些国家（包括德国和美国），仅允许出于研究目的使用 Lame。

Ogg Vorbis（软件包 `vorbis-tools`）是一种免费的音频压缩格式，现在大多数音频播放器都支持它。项目网页为 http://www.xiph.org/ogg/vorbis。Vorbis-tools包含一个编码器和一个简单的播放器。编码器通过命令行 `oggenc` 启动。唯一需要的参数是待压缩的 WAV 文件。选项 `-h` 显示了其他参数的概述。最新版本的 Ogg 编码器甚至支持 en-

使用变比特率进行编码。通过这种方式，可以实现更高程度的压缩。与其指定比特率，不如使用参数 -q 指定所需的质量。参数 -b 决定平均比特率。

参数 -m 和 -M 可用于指定最小和最大比特率。

ogg123 是一个命令行 Ogg 播放器。该程序需要指定播放设备。使用 `ogg123 -d alsa0 mysong.ogg` 等命令启动它。

## 19.9 ALSA 与 MIDI

除了播放 PCM 数据的能力外，许多声卡还提供 MIDI 功能。ALSA MIDI 序列器实现了用于路由 MIDI 数据的客户端架构。你需要安装 `pmidi、aseqview、vkeybd、awesfx、snd_sf2 和 alsatools` 软件包。许多声卡具有外部 MIDI 端口，用于连接 MIDI 设备（如合成器、键盘和音模块）。如果 ALSA 支持声卡的 MIDI 端口，可以使用序列器应用程序（如 `jazz`）来录制和播放 MIDI 文件。你的声卡提供的 MIDI 设备概览可以在 KDE 控制中心通过“音频与多媒体”->“系统”->“MIDI”查看。此外，还要确定播放 MIDI 文件的设备。在命令行上，使用命令 `pmidi -1` 列出可用的 MIDI 设备及其内部 ALSA 端口号。对于 Soundblaster Live!，列表将如示例 19.1 所示。

示例 19.1：Soundblaster Live! 的 MIDI 设备

| 端口 | 客户端名称 | 端口名称 |

|---|---|---|

| 72:0 | External MIDI 0 | MIDI 0-0 |

| 73:0 | Emu10k WaveTable | Emu10k Port 0 |

| 73:1 | Emu10k WaveTable | Emu10k Port 1 |

| 73:2 | Emu10k WaveTable | Emu10k Port 2 |

| 73:3 | Emu10k WaveTable | Emu10k Port 3 |

第一列列出了 ALSA 驱动程序寻址设备的内部端口号。其他列显示了设备的名称和端口名称。除了外部 MIDI 端口外，还列出了几个 WaveTable 端口。使用类似 `pmidi -p 73:0 mysong.mid` 的命令通过列出的端口之一播放 MIDI 文件。

如果 MIDI 播放器在播放期间被中断，可能会持续发出声音。如果发生这种情况，请运行 `all_notes_off` 脚本或以 root 身份运行 `rcalsasound restart` 重启 ALSA。

许多声卡（如 Soundblaster AWE 和 Live!）具有内部 WaveTable 合成器，可将 MIDI 事件转换为可听声音。这些 MIDI 事件可以通过外部 MIDI 键盘或程序（如 MIDI 播放器或序列器）发送 WaveTable 合成器。对于 Soundblaster AWE 和 Live! 声卡，在听到任何声音之前，必须使用音色（sound font）初始化 WaveTable 合成器。

### 19.9.1 加载音色：SB Live 和 AWE

软件包 `aeswf` 包含 `sfxload` 命令用于为 Soundblaster AWE 和 Live! 声卡加载音色。声卡驱动程序光盘上提供了适当的音色文件。只要使用 YAST 从 Creative 驱动程序安装了相应的文件，ALSA 的启动就可以自动加载 WaveTable 合成器所需的音色。目前，该脚本对一个声卡有效。然而，ALSA 可以轻松管理多达八块声卡。

可以使用类似 `sfxload -D <n> /usr/share/sfbank/8BMGSFSX.SF2` 的命令加载音色，`(n)` 代表声卡的编号（0, 1 等）。这可能不是配置声卡时的编号。该编号是由各个单独声卡驱动程序加载的顺序决定的。

你也可以加载安装在 `/usr/share/sounds/sf2` 中的音色之一。由 I WILSON 提供的音色 `Vintage_Dreams_Waves_v2.sf2` 包含 128 种模拟合成器声音和八个鼓组。它适用于 SB AWE 以及 SB Live! 声卡。由 SAMUEL COLLINS 提供的 ROM 音色 `gull-rom.sf2` 仅适用于 SB AWE 声卡。它为这些卡提供了扩展的通用 MIDI 库。查看 `/usr/share/doc/packages/snd_sf2` 中的版权纠纷和文档。更多音色可以在 http://www.hammersound.net 等 URL 找到。

### 19.9.2 vkeybd — 虚拟 MIDI 键盘

如果你没有连接到声卡的外部 MIDI 键盘，可以使用虚拟键盘 vkeybd。为此，上述通过 `pmidi -1` 列出的内部端口号非常重要。要从命令行启动程序，输入 `vkeybd--addr 73:0 &`。端口地址必须根据系统进行调整。指定列表中第一个 WaveTable 端口。如果连接了外部声音发生器，也可以指定外部 MIDI 端口的端口号。

vkeybd 支持若干额外选项。例如，输入 `vkeybd--addr 73:0 --octave 5` 来增加八度数。可以通过 `vkeybd --help` 访问命令行概述。端口映射可以在 `~/.keybdrc` 文件中配置。

### 19.9.3 建立 MIDI 端口连接

![](img/705a076b108ea96be0c0695efb5556ce_337_0.png)

图 19.14：连接 MIDI 端口

ALSA 为 MIDI 端口连接提供了高效的基础。声卡和 MIDI 程序（前提是支持 ALSA 序列器）有一个或多个 MIDI 端口。可以使用 `connect` 连接这些端口。启动时，kconnect 显示可读和可写端口。要测试此过程，用命令 `vkeybd` 和 `aseview` 启动 MIDI 程序。对于 MIDI 端口之间的连接，指定程序的端口地址。例如，将端口号 128:0 分给第一个程序，将 129:0 分给第二个程序。kconnect 也会显示程序的端口。

由于执行 vkeybd 时没有 --addr 参数，现在可以手动建立程序端口与 WaveTable 端口（或外部 MIDI 端口）之间的连接。为此选择相应的端口并点击“connect”。使用命令行工具 connect，输入 `connect 128:0 73:0`（或相应的端口）以在发送端口 128:0 和接收端口 73:0 之间建立单向连接。
