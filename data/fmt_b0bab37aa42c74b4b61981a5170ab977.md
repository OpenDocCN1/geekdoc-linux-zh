## Z-Shell 命令

你可以使用本章前面“算术运算符”部分列出的任何操作符作为你的操作符。`let` 命令会自动假设操作符是算术或关系性的。你不需要对类 shell 操作符加引号。`let` 还会自动求值任何变量并将其值转换为算术值。这意味着你可以将算术操作写为简单的算术表达式。在下一个示例中，`let` 命令将值 2 和 7 相乘。结果被输出到标准输出并显示。

```bash
$ let 2*7
```

如果你想在算术表达式的操作数之间留有空格，则必须对表达式加引号。`let` 命令期望一个参数。

```bash
$ let "2 * 7"
```

你还可以在 `let` 表达式中包含赋值操作。在下一个示例中，乘法的结果被赋值给 `res`。

```bash
$ let "res = 2 * 7"
$ echo $res
```

## `notify`

`notify` job-number

在 Linux 中执行任何命令后，系统会告诉你你运行的后台作业（如果有的话）到目前为止完成了哪些。系统不会中断任何操作（如编辑）来通知你已完成的任务。如果你希望在特定作业结束时立即收到通知，无论你正在系统上做什么，都可以使用 `notify` 命令指示系统通知你。`notify` 命令的作业号作为参数。当该作业完成时，系统将中断你正在进行的操作并通知你作业已结束。下一个示例告诉系统在作业 2 完成时通知用户。

```bash
$ notify %2
```

## `popd`

`popd` [+n]

`popd` 从目录列表中移除目录条目。如果没有参数，它会移除列表中的顶层目录，并执行 `cd` 到新的顶层目录。`+n` 从 `dirs` 显示的列表右侧开始计数，移除第 n 个条目（`popd +0` 移除第一个条目）。`-n` 从 `dirs` 显示的列表右侧开始移除第 n 个条目，`popd -0` 移除最后一个目录。如果目录列表为空、指定的目录条目不存在或目录更改失败，则 `popd` 返回假。如果设置了 `PUSH_MINUS` 选项，在此上下文中 `+` 和 `-` 的含义将交换。

## `print`

`print` [-RnrslzpNDPoOic] [-un] [argument ...]

在没有选项的情况下，`print` 的操作类似于 `echo` 命令，将字符串和变量（参数）作为文本输出到标准输出。`print` 识别以下额外的转义字符：`\M-x` 元字符 x（设置最高位），`\C-x` 生成一个控制字符，`\E` 是 `\e` 的同义词。如果字符不在转义序列中，`\\` 会对其进行转义且不被打印。

| 选项 | 功能 |
|---|---|
| `-r` | 忽略 echo 的转义约定。 |
| `-R` | 忽略 echo 的转义约定并打印随后的参数和选项。 |
| `-s` | 将结果放在历史列表中而不是标准输出。 |
| `-n` | 抑制通常在输出末尾添加的换行符。 |
| `-l` | 分行输出参数，而不是用空格分隔。 |
| `-N` | 用空字符分隔并终止输出参数。 |
| `-o` | 按升序输出参数。 |
| `-O` | 按降序输出参数。 |
| `-i` | 如果与 `-o` 或 `-O` 一起使用，排序时忽略大小写。 |
| `-c` | 分列输出参数。 |
| `-u` | 将参数输出到文件描述符。 |
| `-p` | 将参数输出到协进程的输入。 |
| `-z` | 将参数置于编辑缓冲区栈中，用空格分隔；不识别转义序列。 |
| `-D` | 将参数视为目录名，根据情况将前缀替换为 `~` 表达式。 |
| `-P` | 识别与 `PROMPT` 变量中使用的相同的转义序列。 |

## `pushd`

`pushd` [dir]
`pushd` old new
`pushd` +n

`pushd` 将目录添加到已记忆目录列表中并切换到该目录。如果没有参数，它交换前两个目录并切换到第二个。如果没有设置 `PUSH_SILENT` 选项，在执行 `pushd` 后将打印目录栈。如果指定了 `old` 和 `new` 参数，则当前目录中旧字符串出现的位置将被替换为新字符串，并切换到结果目录。

使用新的数字参数 `n`，你可以引用目录列表中的条目。`+n` 旋转列表，使第 n 个目录（从 `dirs` 显示的列表左侧计数）位于顶部。

## `pwd`

`pwd` 显示当前目录的路径。如果使用 `-L` 选项，则打印逻辑路径。如果使用 `-P` 选项，则打印物理路径。

## `repeat`

```
repeat Linux command
do
    commands
done
```

`repeat` 循环重复命令。`repeat` 循环以关键字 `repeat` 开头，后面跟着一个 `Linux command`。`Linux command` 被视为算术表达式，返回一个作为重复次数的数字。下一行是关键字 `do`。循环的结束由关键字 `done` 指定。

## `return`

```
return [n]
```

`return` 退出函数或 shell 脚本。如果提供了参数，则它将成为该函数的返回值。如果没有参数，返回状态为上一个执行命令的状态。如果在函数外部但在 shell 脚本内部，`return` 会停止脚本的执行。如果没有指定作为返回值的参数，它将返回脚本中最后一个执行命令的退出状态。如果在函数外部且不在脚本中，则返回状态为假。

## `select`

```
select variable in list-of-items
do
    commands
done
```

`select` 命令用于显示一个简单的编号菜单供用户选择。`in` 之后的项目列表显示在标准错误上，每个项目前面都有数字。如果省略 `in`，则使用位置参数的值。显示项目后，将显示 `PS3` 提示符，提示用户输入数字。从标准输入读取该数字，并逐个与每个项目的数字进行匹配。如果找到对应的值，则 `select` 将该赋值

## 142 Z-Shell 命令

将单词传递给变量。如果用户输入空行，则再次显示菜单。如果读取到 `EOF`，则命令终止。`select` 的退出状态是最后一个执行的命令的退出状态，如果没有执行任何命令，则为 0。下面的示例展示了使用 `select` 命令为列出文件提供三种不同的选择。

```
select mychoice in Sizes Information Cfiles
  do
    case $mychoice in
      Sizes)
        ls -s
        ;
      Information)
        ls -1
        ;;
      Cfiles)
        ls *.c
    esac
  done
```
