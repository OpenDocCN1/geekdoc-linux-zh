
# `wmagload`

类 NeXTStep 系统管理器。`wmagload` 提供集成 5 秒（主窗口）、30 秒和 60 秒的 CPU 负载情况。它占用空间非常小（64x64 正方形）。程序中没有任何让它*需要* `WindowMaker` 的内容，它可以与其他窗口管理器配合。但如果你在寻找桌面面上的无缝集成，`wmagload` 将符合你的需求。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# wmbattery

显示笔记本电池，可停靠在 `Window Maker`。`Wmbattery` 以小图标显示笔记本电池状态。如果插了电源，是否正在充电，剩余多少分钟（高-绿色，低-黄色或紧急-红色）。程序中没有任何让它需要 `WindowMaker` 的内容，剩余电池电量（同时带有百分比和图表）以及电池状态。它可以停靠在 `Window Maker` 或 `AfterStep` 的 dock 中。相关问题在“字符设备”部分。它仅在带有 APM BIOS 的笔记本电脑上运行。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP-Dictionary/html/index.html`

# wmbiff

一个显示邮箱信息的等可停靠应用。`Wmiff` 是一个窗口停靠实用程序，显示五个邮箱箱中已读和未读消息的数量。你可以定义动作来接收新邮件（例如，播放声音），[点击鼠标时从远程服务器获取或执行你的邮件读取器]。`Wmiff` 支持入站 Licq 消息通知，因此你可以将 Licq 放在后台。目前，`wmiff` 支持 unix 全局域、`mailird`、`pop3`、`APOP`、`IMAP` 和 `IMAPS` 邮箱，以及 Licq 和 GnomeICU 历史文件。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/`

# wmcube

显示当前 CPU 负载的旋转3D 对象。`wmcube` 是一个显示实时旋转3D 对象的 dock，指示当前的 CPU 负载。负载越高，物体旋转越快。在 SMP 机器上可以为每个处理器运行。最初 `wmcube` 只能旋转立方体，因此得名。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# wmdate

用于窗口 dock 的日历。`wmdate` 为窗口使用生成 64x64 像素的日历。它是专门为 `Window Maker` 编写的，并带有“仅时钟”应用的 dock 配合得很好。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# wmf

网络邮件文件夹转换为 HTML 并创建索引（按作者、日期、主题）。当然还有其他程序可以同样的事，但它有一些特殊功能：

- 无限制线程
- 引用纯文本编码
- 页面超链接 (`X-URL`)
- 拆分页面以减小（线程前）
- 索引时间限制（旧邮件消失）
- 框架支持来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`

# wmgtemp

`Window Maker` 的温度传感器 dock。它以数字和图形方式显示带有 VIA866A 芯片组的主板的 CPU 和 SYS 温度，以及一些其他传感器，使用 `W8378ID`、`W33627HF` 和 `AS9912FT`。未来还将添加对其他芯片组的支持。你需要编译了 i2c 功能的内核来使此工作，使用 `i2c-source` 软件包为自己制作。来自 Debian 3.0r0 APT `http://www.ldp.org/LDP/Linux-Dictionary/html/index.html`
