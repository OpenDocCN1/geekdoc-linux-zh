
`property` 指定属性名称。

`XDeleteProperty` 函数仅当属性已在指定的窗口上定义时才删除指定的属性，并导致 X 服务器在窗口上生成 `PropertyNotify` 事件，除非该属性不存在。

```
XDeleteProperty 可以产生 BadAtom 和 BadWindow 错误。
```

## 选择 (Selections)

选择是应用程序交换数据的一种方法。通过使用属性机制，应用程序可以交换任意类型的数据并协商数据的类型。选择可以被视为一种具有动态类型的间接属性。也就是说，属性并不是存储在 X 服务器中，而是由某些客户端（所有者）维护。选择本质上是全局的（被认为是由用户定位的而不是特定窗口子层结构或特定客户端组私有的）。

Xlib 提供了你可以使用的函数来设置、获取或请求转换选择。这允许应用程序实现当前选择，这要求在应用程序不再使用该选择时向应用程序发送通知。支持选择的应用程序通常会高亮当前选择，并且在应用程序获取选择后必须被通知，以便它们取消高亮该选择。

当客户端请求选择的内容时，它指定一个选择目标类型。该类型可以用于控制传输内容的表示形式。例如，如果选择是“用户最后点击的”且当前是图像，则目标类型必须指定图像内容应该是 `XY` 格式还是 `Z` 格式。

目标还可用于控制被翻译内容的类别，例如，请求段落选择的“外观”（字体、行间距、缩进等），而不是段落的文本。目标类型也可用于其他用途。协议并不限制语义。

要设置选择，请使用 `XSelectionOwner`。

- `XSetSelectionOwner(display, selection, owner, time);`

`display` 指定到 X 服务器的连接。

`selection` 指定选择原子（atom）。

`owner` 指定指定选择原子的所有者。你可以传递单词或 `None`。

`time` 指定时间。你可以传递时间戳或 `CurrentTime`。

`XSetSelectionOwner` 函数更改指定选择的所有者和最后更改时间；如果指定的时间早于指定选择当前的最后更改时间，或晚于当前的 X 服务器时间，则没有影响。否则，最后更改时间被设置为指定的时间，并将 `CurrentTime` 替换为当前服务器时间。如果窗口的所有者指定为 `None`，则选择的所有者变为 `None`（即没有所有者）。否则，选择的所有者变为执行请求的客户端。

如果新所有者（客户端或 `None`）与当前选择的所有者不同，且当前所有者不是 `None`，则向当前所有者发送 `SelectionClear` 事件。如果选择的所有者随后终止（即连接被销毁），或者请求中指定的属性窗口随后被销毁，则选择的所有者自动恢复为 `None`，但属性不会发生更改。

`XRotateWindowProperties` 可以产生 `BadAtom`, `BadMatch`, 和 `BadWindow` 错误。

要删除给定窗口上的属性，请使用 `XDeleteProperty`。

```
XDeleteProperty(display, w, property);
```

`display` 指定到 X 服务器的连接。

`w` 指定你想要删除属性的窗口。

`property` 指定属性名称。

`XDeleteProperty` 仅在当属性已在指定的窗口上定义时才删除指定的属性，并导致 X 服务器在窗口上生成 `PropertyNotify` 事件，除非该属性不存在。

```
XDeleteProperty 可以产生 BadAtom 和 BadWindow 错误。
```

# 第 5 章 Pixmap 和 Cursor 函数

## 创建和释放 Pixmap

Pixmap 只能在创建它的所在屏幕上使用。Pixmap 是离屏资源，用于各种操作，作为定义光标的平铺模式或栅化操作源。大多数图形请求可以在窗口或 pixmap 上操作。Pixmap 是单位平面。

要创建一个大小的 pixmap，请使用 `XCreatePixmap`。

```
Pixmap XCreatePixmap(display, d, width, height, depth);
```

`display` 指定到 X 服务器的连接。

`d` 指定在哪个屏幕上创建 pixmap。

`width` 和 `height` 指定 pixmap 的尺寸。

`depth` 指定 pixmap 的深度。

`XCreatePixmap` 函数创建一个宽度、高度和深度 pixmap，并返回标识它的 pixmap ID。将 `InputWindow` 传递给 drawable 参数是有效的。`width` 和 `height` 参数必须非零，否则将产生 `BadValue` 错误。`depth` 参数必须是 drawable 屏幕支持的深度之一，否则将产生 `BadValue` 错误。

服务器使用指定的 drawable 来确定在哪个屏幕上创建 pixmap。pixmap 只能在该屏幕上使用，并且只能与其他深度相同的 drawable 使用（例外请参见 `XCopyPlane`）。mipmap 的初始内容是未定义的。

`XCreatePixmap` 可以产生 `BadAlloc`、`BadDrawable` 和 `BadValue` 错误。

要释放与 pixmap 相关的所有存储，请使用 `XFreePixmap`。

```
XFreePixmap(display, pixmap);
```

`display` 指定到 X 服务器的连接。

`mipmap` 指定 pixmap。

`XFreePixmap` 首先删除 pixmap ID 与 pixmap 之间的关联。然后，当没有引用时，X 释放 pixmap 存储。pixmap 不应再次被引用。

`XFreePixmap` 可以产生 `BadPixmap` 错误。

## 创建、重着色和释放光标

每个窗口都可以定义不同的光标。每当指针位于可见窗口内时，它会被设置为该窗口定义的光标。如果该窗口没有定义光标，则使用父窗口定义的光标。

从 X 的角度来看，光标由光标源（source）、掩码（mask）、颜色和一个热点（hotspot）组成。源位map 的深度必须为 1，且颜色决定了源的颜色。热点定义了在发生指针事件时报告的光标上的指针位置。硬件可能会对光标的大小以及是否实现掩码施加限制。可以使用 `XQueryBestCursor` 来查找哪些尺寸是可能的。有一个用于创建光标的标准字体，Xlib 提供了你可以使用的函数，从任意字体或位图创建光标。

要从标准光标字体创建光标，请使用 `XCreateCursor`。

```c
#include <X11/cursor.h>

Cursor XCreateFont(display, shape);
```

`display` 指定与 X 服务器的连接。
`shape` 指定光标的形状。

X 在一个名为 cursor 的特殊字体中提供了一组标准光标形状。鼓励应用程序使用此接口处理光标，因为字体可以针对单个显示器进行自定义。`shape` 参数指定使用标准字体中的哪个字符（glyph）。

热点来自存储在光标字体中的信息。光标的初始颜色是黑色背景和白色背景（参见 `XRecolorCursor`）。关于光标形状的更多信息，请参见附录 B。

`XCreateCursor` 可以产生 `BadAlloc` 和 `BadValue` 错误。

要从字体字符创建光标，请使用 `XCreateFontCursor`。

```c
Cursor XCreateFontCursor(display, source_font, mask_font, source_char, mask_char, foreground_color, background_color);
```

`display` 指定与 X 服务器的连接。
`source_font` 指定源字符的字体。
`mask_font` 指定掩码字符的字体或为 `None`。
`source_char` 指定源的字符字符。
`mask_char` 指定掩码的字符字符。
`foreground_color` 指定源前景的 RGB 值。
`background_color` 指定源背景的 RGB 值。

## Pixmap 和光标函数

`XCreateGlyphCursor` 函数与 `XCreatePixmapCursor` 类似，不同之处在于源和掩码位map是从指定的字符字体获取的。`source_char` 必须是源字体中定义的字符，否则将产生 `BadValue` 错误。如果给了 mask，则 `mask_char` 必须是掩码字体中定义的字符，否则将产生 `BadValue` 错误。掩码和字符是可选的。源和掩码点（如果字符是连续的）定义了热点。`source_char` 和 `mask_char` 不需要具有相同的边界框（bounding boxes），且热点相对于边界框没有限制。如果没有给出 mask，则将显示源的所有像素。如果没有对字体进行任何显式引用，可以通过调用 `XFree` 来释放字体。

对于 2 字节格式，16 位值应由 `byte1` 和 `byte2` 分别最高位字节和最低位字节组成。

`XCreateGlyphCursor` 可以产生 `BadAlloc`、`BadFont` 和 `BadValue` 错误。
