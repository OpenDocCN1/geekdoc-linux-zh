## 将 Python 数据写入 CSV 文件

```python
def write_csv_data(filename, headers, rows):
    with open(filename, 'w', newline='') as file:
        out = csv.writer(file)
        out.writerow(headers)
        out.writerows(rows)
```

## 期望接收文件的函数

```python
def greeting(file):
    file.write('Hello\n')
    file.write('World\n')
```

## 使用真实文件调用该函数

```python
with open('out.txt', 'w') as file:
    greeting(file)
```

## 使用“伪”文件调用函数

```python
import io
file = io.StringIO()
greeting(file)
```
