
# Fedora 概述

## 软件打包
红帽公司创建了 `RPM` 包管理器（`RPM`）方法用于 Linux 软件打包。`RPM` 使得技术熟练度较低的用户也能轻松安装、搜索、管理和验证 Linux 软件。使用 `RPM` 工具，您可以从 CD、硬盘、局域网或互联网进行安装。追踪已安装的软件包或查看软件包内容都很容易。由于 `RPM` 可供 Linux 社区使用，它已成为打包 Linux 软件的事实标准之一。利用 `RPM` 技术构建的工具，如 `yum` 和 `PackageKit`，已被添加到 Fedora 中，以扩展您安装和更新软件包的能力。这些工具可以指向在线仓库，因此最新的软件包往往只需点击即可获取。

**交叉参考：** 第 5 章描述了如何安装 `RPM` 软件包以及使用 `yum` 仓库。

## 简易安装
Fedora 安装软件（称为 `anaconda`）提供了安装 Linux 的简易步骤。在安装过程中，`anaconda` 还帮助用户完成前几项迈向配置 Linux 的若干步骤。你可以选择要安装哪些软件包以及如何分区你的硬盘。你甚至可以配置用户账户、键盘、鼠标以及网络设置，从而让你的桌面图形用户界面（GUI）即可使用。在 Fedora 12 中，你可以直接从正在运行的实时 CD 进行安装，或者从几种不同的仅安装介质中进行选择。

**交叉引用：** 第 2 章涵盖了 Fedora 的安装。

## UNIX System V 风格的运行级别脚本
为了使系统服务（守护进程）以有组织的方式启动和关闭，Fedora 和 RHEL 支持 UNIX System V 机制来启动和停止服务。shell 脚本（易于阅读和修改）位于 `/etc` 的子目录中。当运行级别发生变化时，例如系统启动时或你切换到单用户模式时，系统消息会告知你每个服务是否正确启动或未能正确执行。新的系统启动技术，如 Fastboot 和 Upstart 技术，正在被引入以帮助开发人员将其服务迁移到更快的启动技术上。第 11 章描述了如何使用 runlevel 脚本以及这些服务如何逐渐从 System V 脚本演变而来。

## 桌面环境（GNOME 和 KDE）
为了让使用 Linux 变得更加容易，Fedora 附带安装了 `GNOME` 和 `KDE` 桌面环境。默认安装的是 `GNOME`，它提供了一些很好的功能，包括拖放协议以及用于配置桌面外观和感觉的工具。`KDE` 是另一个流行的桌面管理器，它包含了一组针对 `KDE` 环境定制的工具，例如 `Konqueror` 网络浏览器。你可以尝试针对 `GNOME` 和 `KDE` 的独立 Fedora 实时 CD，然后直接从这些 CD 安装软件到你的硬盘上。（本书包含 `GNOME` 实时 CD。）

## GUI 管理工具
有一些有用的配置工具用于设置 Linux 中一些更复杂的任务。几种不同的 GUI 工具提供了图形化、表单驱动的界面，用于配置网络、用户、文件系统、安全性和初始化服务。这些图形工具可以自动设置这些文件，而不必创建晦涩难懂的命令行或创建复杂的配置文件。

> **注意：** 使用基于 GUI 的程序来操作基于文本的配置文件既有优点也有缺点。基于 GUI 的配置工具可以引导你完成设置过程，并对你输入的信息进行错误检查。然而，某些功能无法通过 GUI 访问，如果出现问题，调试起来可能会更复杂。在 Linux 中，除了 GUI 管理工具，你还可以使用命令行选项。由 Christopher Negus 和 Francois Caen 撰写的《Fedora Linux Toolbox》（Wiley, 2008）是学习更多 Linux 命令的好方法。

## 测试
你在 Fedora 发行版上获得的精确配置已经由世界各地的专家进行了彻底测试。由于 Fedora 现在由一个巨大的单一软件库代表，测试最集中的软件将是官方 Fedora CD 和 DVD 版本中提供的软件。

## 自动更新
构成 Fedora 的软件包不断以各种方式被修复。为了提供自动选择、下载和安装更新软件包的机制，Fedora 主要依赖 `yum` 设施。

随着互联网上包含 Fedora 软件包的 `yum` 软件库的加入，可以用单个 `yum update` 命令更新整套 `RPM` 软件包。`PackageKit` 设施提供了图形化工具，可以从互联网上的多个软件库安装软件（与本地 CD 或 DVD 介质相对）。桌面小工具会在有可用的更新包可下载和安装时自动提醒你。有关这些工具的说明，请参见第 5 章。

# 迈向 Red Hat Enterprise Linux 6

Red Hat 尚未正式宣布 Red Hat Enterprise Linux 6 的功能，预计其发布时间在 2010 年的某个时候。然而，自 Red Hat Enterprise Linux 上一个主要版本以来，几个关键功能已被 Fedora 中的新软件项目所取代。因此，尽管目前还没有官方的功能列表，但至少学习以下当前 Fedora 功能中的一些，应该有助于你为 RHEL 6 做好准备：

### 软件包管理
预计诸如 `pup`（软件包更新器）和 `pirut`（软件包管理器）等工具将被 `PackageKit` 取代。`PackageKit` 设施包括安装和更新软件包的功能。新的面板图标可以让你查看 `PackageKit` 管理和安装软件的活动。

### 网络接口
虽然 `NetworkManager` 在 RHEL 5 中可用，但预计它将成为 Fedora 中管理网络接口的默认工具。`NetworkManager` 特别擅长管理无线接口和 VPN 连接。

### 加密文件系统
在 Fedora 中测试的许多安全功能（在进入 RHEL 之前）包括加密文件系统的能力。说到文件系统，你还可以预期 `ext4` 将成为 RHEL 6 中的默认文件系统类型。

### 虚拟化
随着 Red Hat 收购了 Kernel Virtual Machine (`KVM`) 技术的开发者 Qumranet，你可以预期 RHEL 6 中的虚拟化支持将从 `Xen` 转向 `KVM`。`KVM` 已经包含在多个 Fedora 版本中。

这些只是 Fedora 最新版本中的众多功能中的一部分，你可以在 Red Hat Enterprise Linux 6 中寻找它们。

# Fedora 12 的新功能

就随附 Fedora 的不同软件项目版本而言，Fedora 12 的主要组件包括（带版本号）：

- Linux 内核：版本 2.6.31
- `GNOME`（桌面环境）：版本 2.28.0
- `KDE`（桌面环境）：版本 4.3.3
- X Window 系统（`X.org` 图形窗口系统）：版本 11，Release 1.7.1
- `OpenOffice.org`（办公套件）：版本 3.1.1
- `GIMP`（图像操作应用程序）：版本 2.6.7
- `GCC`（GNU C 语言编译系统）：版本 4.4.2
- `Apache`（Web 服务器）：版本 2.2.13
- `Samba`（Windows SMB 文件/打印共享）：版本 3.4.2
- `CUPS`（打印服务）：版本 1.4.2
- `Sendmail`（邮件传输代理）：版本 8.14.3
- `vsFTpd`（安全 FTP 服务器）：版本 2.2.0
- `INN`（Usenet 新闻服务器）：版本 2.5.0
- `MySQL`（数据库服务器）：版本 5.1.39
- `BIND`（域名系统服务器）：版本 9.6.1

> **提示：** 这些功能不断得到更新。Fedora 附带了有助于保持系统处于软件最新版本的工具。

以下章节描述了 Fedora 12 的主要新功能（除了刚才提到的那些基本组件的最新版本之外）。

## PackageKit 软件管理改进

从 Fedora 9 开始，`PackageKit` 成为管理软件更新和添加软件包的默认 GUI 软件包。它是一个社区开发的软件管理系统，取代了由 Red Hat 开发的 Package Updater 和 Package Manager 应用程序。

使用 `PackageKit` 时，顶部面板中的一个图标会在有软件更新可用时提醒你。或者，你可以使用 `GNOME` 的 `PackageKit` 软件包管理器来搜索和安装额外的软件包。

> **注意：** `PackageKit` 在 Fedora 最新版本中一个更具争议的新功能，是允许普通用户在不输入 root 密码的情况下使用 `PackageKit` 安装签名软件包。Fedora 12 发布后，该功能已被撤销。因此，一旦你获取了 Fedora 的第一轮更新，你将再次需要提供 root 密码来安装软件包。`PackageKit` 在第 5 章中有描述。

## NetworkManager 改进

在 Fedora 12 中，`NetworkManager` 是连接和管理有线及无线网络接口的默认方法。Fedora 12 中 `NetworkManager` 的新功能包括对移动宽带卡的扩展支持。这些改进包括显示信号强度和扫描可用的蜂窝网络的功能。当前版本还为 `NetworkManager` 添加了完整的 IPv6 支持。
