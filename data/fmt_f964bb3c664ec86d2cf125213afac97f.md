### 图 5.14 创建两个相互依赖表的 SQL 代码。

```sql
CREATE TABLE authors (
  lname VARCHAR(30) PRIMARY KEY,
  fname VARCHAR(30),
  initial CHAR(1)
)
```

```sql
CREATE TABLE chapters (
  chapter_number NUMERIC(10.0) PRIMARY KEY,
  author_name VARCHAR(30) REFERENCES authors(lname),
  title VARCHAR(100)
)
```
