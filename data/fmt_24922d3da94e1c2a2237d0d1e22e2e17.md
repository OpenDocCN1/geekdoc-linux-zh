## 条件控制结构：`if-then`, `else`, `switch`

### 功能

```bash
if(expression) then commands
endif
```

如果表达式为真，则执行命令。（你可以指定多个 Unix 命令。）

```bash
if(expression) then commands
else commands
endif
```

如果表达式为真，则执行 `then` 之后的命令。如果表达式为假，则执行 `else` 之后的命令。

```bash
switch(string) case pattern:
commands
break
default:
commands
endswitch
```

允许在几个替代命令之间进行选择，将字符串与不同的模式进行比较。

## 测试表达式：`()`

`if` 和 `while` 控制结构使用表达式作为它们的测试。真测试是任何结果非零值的表达式。假测试是任何结果为 0 值的表达式。在 TCSH shell 中，关系和等式表达式可以很容易地用测试，因为它们在真时结果为 1。表达式中可以使用许多可能的运算符。测试表达式也可以是算术运算或字符串比较，但字符串只能进行相等性或不相等性的比较。

与 BASH shell 不同，你必须将 TCSH shell 中的 `if`、`while` 表达式放在括号内。下一个示例显示了一个简单的测试表达式，用于测试两个字符串是否相等。

```bash
if ($greeting == "hi") then
echo Informal Greet
```

TCSH shell 拥有一套独立的运算符，用于测试字符串与其他字符串或正则表达式。`==` 和 `!=` 运算符测试字符串的相等和不等相等。`==` 和 `!` 运算符测试字符串与用于文件名替换的模式，查看匹配是否成功。正则表达式可以包含 shell 的任何特殊字符。在下一个示例中，任何以大写或小写 h 开头的 `greeting` 值将匹配模式 `[Hh]*`。

```bash
if ($greeting == [Hh]) then
echo Informal Greet
```

模式使用 `*`、`?` 和 `[]` 特殊字符。`*` 匹配任何字符串，包括空字符串。`?` 匹配单个字符。`[]` 匹配包含其中的任何字符。字符范围由连字符分隔的两个边界指定——`[b-k]` 匹配从 b 到 k 之间及内的任何字符（例如，它可以匹配 c 或 f 或范围内的其他字符）。如果你在 `[]` 的第一个位置包含 `^`，则它否定后面的字符。`[^agm]` 将匹配 a、g、m 以外的任何字符，`[^a-z-Z]` 将匹配字母以外的任何字符，例如标点符号或数字。你也可以

## 数值变量：`@`

在 TCSH shell 中，你可以使用 `@` 命令代替 `set` 命令来声明数值型变量。你可以对这些变量进行算术、关系和位运算。在这方面，TCSH shell 与编程语言相似。数值型变量和字符串型变量是两种不同类型的对象，其管理方式也完全不同。你不能对数值型变量使用 `set` 命令。`@` 命令由关键字 `@`、变量名、赋值运算符和表达式组成。下一个示例声明了数值型变量 `num` 并为其赋值 `10`。

```
> @ num = 10
```

有许多不同的赋值运算符可以使用，例如自增运算符和算术赋值运算符。它们与 Unix 编程工具 `awk` 以及 C 编程语言中使用的运算符相同。表达式可以是任何算术、关系或位表达式，你可以使用括号创建复杂的表达式。表达式中的操作数应与运算符用空格隔开；例如，`10*5` 不是一个有效表达式，应该写成 `10 * 5`。你也可以将数值型变量作为表达式中的操作数。在下一个示例中，变量 `count` 被声明为数值型并用于算术表达式中。注意 `count` 是通过 `$` 运算符进行求值的，因此 `count` 的值 `3` 被用在表达式中。本章前面的“运算符”部分提供了数值运算符的列表。

```
> @ count = 3
> @ num = 2 * ($count + 10)
> echo $num
```

## `alias`

`alias [name [command]]`

你使用 `alias` 命令为命令创建另一个别名。别名就像宏一样，会展开为它所代表的命令。别名并没有字面上替换命令名称；它只是给该命令提供了另一个名称。

`alias` 命令以关键字 `alias` 和命令的新名称开头，随后是别名将引用的命令。在下一个示例中，`ls` 命令被别名为 `list`，这成为了 `ls` 命令的另一个名称。

```
> alias list ls
> ls
mydata intro
> list
mydata intro
```

如果你要别名的命令带有选项，你需要将命令和选项封装在单引号内。名称中包含空格的别名命令也需要引号。在下一个示例中，带有 `-l` 选项的 `ls` 被赋予了别名 `longl`。

```
> alias longl 'ls -l'
> ls -l
-rw-r--r--r-- 1 chris weather 207 Feb 20 11:55 mydata
> longl
-rw-r--r--r-- 1 chris weather 207 Feb 20 11:55 mydata
```
