## 杂命令 ❤

| `rlwrap` | 为尚不支持这些功能的 REPL 添加历史记录和 ctrl 支持（`rlwrap` 代表 readline） |
| :--- | :--- |

```
$ rlwrap python
```

| `watch` | 每隔 2 秒重新运行一次命令 |
| :--- | :--- |

| `pv` | "管道查看器"，为你提供通过管道的数据统计信息 |
| :--- | :--- |

| `file` | 弄清楚一个文件是哪种类型的文件（png? pdf?） |
| :--- | :--- |

| `cal` | 一个微型日历 ♡ |
| :--- | :--- |

| `ts` | 在每一行输入前添加时间戳 |
| :--- | :--- |

| `ncdu` | 弄清楚哪些文件占用了你所有的磁盘空间 |
| :--- | :--- |

| `diff` | 比较 2 个文件。运行时使用 `-U 8` 查看上下文 |
| :--- | :--- |
