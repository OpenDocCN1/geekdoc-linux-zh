
# 软件清单

`Microsoft’s Visual Studio` - 由微软开发的跨平台开源文本编辑器。

## 图像编辑器
- `GIMP` - 一个开源的 GNU 图像处理程序。
- `Pinta` - Windows 画 的 Linux 版本。
- `DigiKam` - 一款为摄影师设计的开源照片编辑应用。
- `ShowFOTO` – 一个具有强大图像编辑工具的免费独立图像编辑器。
- `RawTherapee` – 一个用于优化照片的免费图像编辑应用。
- `Fotoxx` – 一个开源的照片集管理器，也可用于照片编辑。
- `F-spot` – 一款用于 Gnome 桌面面的开源图像编辑应用。

## 电影字幕
- `VLC Media Player` – 一款具有字幕功能的开源音频视频播放应用。
- `Subliminal` - 一款用于搜索和下载电影字幕的易用程序。
- `SubDownloader` - 一个自动为电影查找并下载/上传字幕的程序。
- `SMPPlayer` - 一个带有字幕功能的免费 GUI 媒体播放器。

## 音乐制作软件
- `Audacity` - 一款开源跨平台的音频录制和编辑应用。
- `Cecilia` - 一个面向音效设计者的音频信号处理平台。
- `Mixxx` – 一款音乐混合软件，可以帮你成为专业的 DJ。
- `Ardour` – 一款为 Linux 和 Mac OS X 专业人士提供的完整音乐制作应用。
- `Hydrogen Drum` – 适用于 Linux 系统的先进鼓机采样应用。
- `Gitarix` – 一款虚拟吉他放大器应用。

## PDF 查看器
- `Okular` – 一款免费的通用文档查看器。
- `Evince` - Gnome 桌面系统的默认轻量级文档查看。
- `Foxit` - 一款安全的跨平台 PDF 阅读器。
- `PDF JS` - 基于 Web 的 PDF 查看器。

## 安全
- `ClamAV` - 适用于 Linux 系统的病毒引擎。
- `Fail2ban` - 一个开源入侵防御框架。
- `GuFW` - 由 `UFW`（防火墙）驱动的防火墙。
- `Mod_Security` - 用于 Web 应用的开源入侵检测和防御软件。
- `Iptables` - 一种用于配置 Linux 内核防火墙的命令行工具。
- `Firewalld` - 一个无需重启即可生效更改的防火墙。
- `Shorewall` - 适用于 GNU/Linux 的开源网关/防火墙配置工具。

## Torrent 下载客户端
- `aria2` - 一款开源跨平台的命令行下载管理器。
- `Deluge` - 一款被认为最好的 Torrent 下载应用。
- `qBittorent` - 一款跨平台 Torrent 客户端。

## 文本编辑器
- `ViVim Editor` - 一款基于命令行的文本编辑器，拥有丰富功能使其成为常用。
- `Gedit` - 一款通用的文本编辑器。
- `Nano` - 一款易用的命令行文本编辑器。
- `Emacs` - 一款高度自定义的命令行文本编辑器。
- `Kate` - 一款功能丰富且高度自定义的文本编辑器。

## 视频播放器
- `VLC Media Player` - 一款具有字幕功能的开源音频视频播放应用。
- `Kodi` - 由 XBMC Foundation 开发的媒体播放软件。
- `Miro Music` - 一款跨平台视频播放应用，允许观看网络电视。
- `SMPPlayer` - 一个带有字幕功能的免费 GUI 媒体播放器。

## 视频编辑器
- `Open Shot` - 一款功能丰富的跨平台视频编辑应用。
- `Pitivi` - 一款开源视频编辑应用。
- `Avidemux` - 一款简单易用的开源跨平台视频编辑软件。
- `Blender` - 一个支持所有 3D 工作流 3D 创建套件。

## 浏览器
- `Google Chrome` - 由谷歌开发的、在 PC 和手机上最流行的浏览器。
- `Firefox` - 最近备受关注的开源跨平台网络浏览器。
- `Vivaldi` - 一款基于 Chromium 引擎、界面优美的浏览器。
- `Opera` - 一款于 90 年代发布的浏览器，是最老的浏览器之一。
- `Chromium` - 一款轻量级开源跨平台浏览器。与 Google Chrome 不同，Chromium 更快。
- `Midori` - 一款许多 Linux 系统的默认开源浏览器。
