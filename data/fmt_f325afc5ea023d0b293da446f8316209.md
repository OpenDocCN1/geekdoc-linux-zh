# rdiff-backup

用于编辑器的备份程序 `rdiff-backup` 是一个将一个目录备份到另一个目录的脚本。目标是源的副本，但额外的差异存储在目标的特殊子目录中，你仍然可以恢复以前的文件。其核心思想是结合主备份和增量备份的最佳特性，`rdiff-backup` 保留了目录、符号链接、文件权限、`uid/gid` 所有权（如果通过 root 运行）和修改信息。最后，`rdiff-backup` 可以像 `rsync` 一样通过管道以高效的方式运行。因此，你可以使用 `rdiff-backup` 和 `ssh` 将硬盘安全地备份到远程位置，差异将被传输。源自 Debian 3.0r0 APT

http://www.tld.org/LDP/Linux-Dictionary/index.html

# rdist

是一个在多个主机上维护相同文件副本的开源程序。它保留文件的所有者、组、模式和 mime 类型，并可以更新正在执行的程序。几乎所有的 UNIX 版本都包含 `rdist`。大多数版本还包含一个被称为“4.2BSD rdist”、“rdist classic”或“rdist version 3”的旧版本。源自 MagniComp
