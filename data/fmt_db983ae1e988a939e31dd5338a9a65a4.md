并被称为基本单位或模数。假设这四个单位具有以下乘法表：

$i^2 = 1, \quad i^2 = j^2 = k^2 = ijk = -1$

$ij(k) = (ij)k = ijk$

$li = 11, \quad 1j = j1, \quad 1k = k1$

$i, j, k$ 在乘法中彼此不满足交换律，即 $ij \neq ji, jk \neq kj, ki \neq ik$ 等。但所有实数和复数都与 $i, j, k$ 满足交换律，因此如果 $c$ 是一个实数，则 $c = ci, jc = cj, kc = ck$。在 $jk = -1$ 的左侧乘以 $i$，即 $ijk = j(i - 1) = -i$，由于 $i^2 = -1$，可得 $k = -i$。类似地 $jk = ji = -k$；当此过程穷尽时，导出了 $i, j, k$ 所有简单的非交换关系，即：

$ij = -ji = k, \quad jk = -kj = i, \quad ki = -ik = j$

更复杂的产品（例如 $kji = -k(ji = j)$），通过用前一系列关系中给出的值替换任何相邻对的值，然后对新产品中的任何其他相邻对进行类似的操作，以此类推，直到产品被简化为 $+1, \pm i, \pm j$ 或 $\pm k$。右侧的乘法也是允许的；因此，由 $ij = k$，我们有 $jj = jj$，或 $-i = kj$。诸如 $jj$ 和 $ji$ 等产品可以写为 $i^2$ 和 $ji$。在四元数代数的定义中，假设普通代数的所有定律和运算都有效，除了单位 $i, j, k$ 的乘法交换律。加法和乘法的结合律和分配律在整个过程中都适用且没有限制。加法是满足交换律的，例如 $i + j = j + i$。[D.M.Y.]

# 刺桐属树木（Quebracho）

属于不同属但具有相似品质的一系列树木，均原产于南美洲，其木材和树皮很有价值。一种南美树木（*Schinopsis lorentzii*，漆树科）的心材被称为 Quebracho（意为“斧头破碎者”），指的是其极其坚硬的木材，这是已知最硬的木材之一。Quebracho 是世界上最重要的单宁来源。参见 腐生植物；单宁。 [PD, SUC, L.C]

# 排队论

关于队列或等待线形成和行为的数学理论。该术语也松散地应用于与交通拥堵和存储系统相关的一系列广泛问题的数学研究。通过服务点的不均匀流动，伴随着波动的到达和服务时间，构成了运筹学的一个主要课题。对于数学家来说，排队论特别有趣，因为它涉及相对简单的随机过程，这些过程通常是非马尔可夫型的，且可能是平稳的。参见 运筹学；随机过程。 [PD, SUC, L.C]

排队论的主要先驱 A. K. 厄朗（A. K. Erlang）从 1908 年开始研究电话拥塞问题。研究手动系统中的用户等待时间是很有趣的——例如，平均等待时间以及用户无需等待即可立即获得服务的可能性——并考察如果改变操作员数量或以其他任何方式改变条件，等待时间会受到多大影响。如果有更多的操作员或服务可以加快，用户不太可能需要等待，等待人数可以减少，但改进后的设施维护成本更高；因此，必须达成一个合理的平衡。

在使用自动电话交换设备和只能同时承载有限数量消息的长途线路方面的相关问题，导致了大量关于电话流量问题的数学研究。类似的拥塞情境在其他背景下也会出现。在工厂中，若干机器（如织布机）可能由一名或多名维修人员负责。如果机器故障，它必须闲置，直到一名维修人员完成其他机器的维修有空为止。在这里，机器对应于电话用户，故障对应于呼叫尝试，维修对应于连接。其他拥塞情境的例子包括：飞机在机场跑道外盘旋等待使用跑道、汽车在收费站排队、以及顾客在零售店柜台前排队等待服务。

最值得研究的变量因情况而异。有时是客户的平均等待时间，有时是队列长度超过给定限制的频率，有时是服务器空闲时间所占的比例，有时是服务器持续占用期间的平均持续时间。在研究仓库或零售店的库存（通常称为库存理论）时，在各种重新订购策略下，会考虑库存耗尽的频率。类似的考虑也适用于大坝和水利储存理论。参见 线性规划；系统工程。 [A.R.V]

# 榅桲

落叶树 *Cydonia oblonga*，原产于亚洲，因其可食用果实而种植。果实是梨形或苹果形的浆果，特征是有绒毛、芳香、酸味、绿色，成熟时变为清澈的黄色。主要用于制作果酱和果冻，或作为炖煮水果，榅桲在烹饪过程中会呈现粉红色。参见 落叶植物；果实；果树果实；蔷薇目。 [H.B.T]

# 藜（Quinua）

一种一年生草本植物，*Chenopodium quinoa*（藜科），原产于秘鲁，是南美洲许多人的主食。这些植物在高海拔地区生长，产生大量高营养价值的种子，可用于汤中整体食用或磨成面粉，制成面包或糕点。种子也用作家禽饲料、药物以及酿酒。在美国，其叶子有时被用作菠菜的替代品。参见 果实解剖学。 [PD, SUC, L.C]

# 醌

一类芳香族二酮，其中羰基的碳原子是环结构的一部分。“醌”这个名字适用于整个类别，因此它常被具体用来指代 *p*-苯醌 **(1)**。*o*-苯醌 **(2)** 也是已知的，但对位异构体并不存在。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1845_1.png)

醌是通过氧化相应的芳香族环系统制备的，其中氨基 ($\ce{NH2}$) 或羟基 ($\ce{OH}$) 基团位于一个或两个被转化为羰基的碳原子上。

几种可能的由萘衍生的醌中，有三种是已知的：1,4-萘醌 (3)、1,2-萘醌和 2,6-萘醌 (4)。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_1846_1.png)

重要的天然萘醌包括维生素 K<sub>1</sub> 和 K<sub>2</sub>，它们存在于血液中，并负责正常的血液凝固反应。从动植物中分离出了许多醌类色素。这些的例证包括在未成熟的胡桃壳中发现的胡桃醌和从霉菌 *Penicillium spinulosum* 中分离出的 spinulosin。9,10-蒽醌衍生物是一类重要的染料，其中紫精（alizarin）是母体类型。对苯醌被制造出来用作显影剂。参见 蒽醌色素；芳香烃；染料；氢醌；酮；氧化还原；维生素 K。 [D.A.S.]

# 狂犬病

一种急性的病毒性脑炎感染。人类通过被患有狂犬病的动物（通常是狗）咬伤而感染。犬狂犬病可以感染所有温血动物，通常导致死亡。参见 动物病毒。

据认为，病毒从唾液注入的伤口通过感觉神经移动到中枢神经系统，在那里繁殖并破坏脑细胞，从而产生脑炎，伴有严重的兴奋、吞咽时的喉部痉挛（因此称为恐水病，即怕水）、抽搐和死亡——有时在死亡前会出现瘫痪。

所有咬伤应立即用肥皂和水彻底清洗，并应考虑注射破伤风疫苗。是否注射狂犬病抗体、狂犬病疫苗或两者，取决于四个因素：咬人动物的性质；该地区是否存在狂犬病；攻击的方式（挑衅或非挑衅）；咬伤的严重程度以及动物唾液的污染；以及当地卫生官员的建议。参见 公共卫生；破伤风。

人类的诊断是通过观察接种了患者唾液的动物或患者死后的大脑中的内格里小体（Negri bodies，即胞质内包涵体）。咬伤人的狗会被隔离并观察 10 天，看是否有狂犬病迹象；如果没有发生，则说明没有狂犬病。如果出现迹象，动物将被处死，并检查其大脑中的内格里小体，或通过荧光抗体测试检查狂犬病抗原。参见 荧光显微镜；病毒包涵体。

高风险个体（如兽医）必须接受预防性免疫。如果认为暴露有危险风险，应进行暴露后预防。如果迅速注射抗体或具有免疫原性的疫苗，可以阻止病毒侵入中枢神经系统。美国有灭活的狂犬病病毒疫苗可用。它是用人体或猴细胞培养中生长的病毒制成的，不含早期巴斯德型疫苗中存在的大脑蛋白。这种材料的抗原性足够强，只需注射四次到六次病毒即可获得大量的抗体反应。参见 疫苗接种。 [J.L.Me]
