# 附录 E

## Shell 语法

### SH

```
command:
if list then list
{ elif list then list }*
{else list } fi
case word in [pattern list;]* esac

while list do list done
for name in word ; do list done
for name in $@ ; do list done

simple_command
list:
pipeline ;
pipeline ; list
pipeline & list
pipeline && list
pipeline || list
pipeline:
command
command | pipeline
```

### KSH

```
if list then list { elif list then list }*
case name in ( { word { | word } ) list ; }* esac
list:
cond;
cond; list
cond & list
cond:
pipe
pipe && cond
pipe || cond
pipe:
statement { | statement }*
```

### BASH

```
if list then list
[ elif list then list ]*
[else list] fi
case word in [ pattern [ | pattern]*) list ; ] ... esac
pipeline:
[!] command [ | command]*
list:
pipeline ;
pipeline ; list [; & or <newline>]
pipeline & list [; & or <newline>]
pipeline && list [; & or <newline>]
pipeline || list [; & or <newline>]
```

### CSH

```
if ( expr ) commands
if ( expr ) then
commands
else if ( expr2 ) then
commands
else
    commands
endif

switch ( string )
case str1:
breaksw
default:
endsw

while ( expr )
    commands
end

foreach name (wordlist)
    commands
end

expr:
== != =~ !~
<= >= < >
<< >>
+ -
* / %
{ cmd }
-[rwxoeozfd] filename
```
