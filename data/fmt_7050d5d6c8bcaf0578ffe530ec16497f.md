# Linux 词典

## kworldclock

用于 KDE 显示的地球观察器，根据时间显示世界各地的光亮与昏暗状态，并提供全球所有主要城市的时间。它可以独立运行，也可以作为 KDE 面板上的小部件运行。该包是 KDE 官方玩具（toys）模块的一部分。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## kwufpd

wu-fptd 配置工具。此程序允许你操作 wu-fptd 的配置文件。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

## kxmeditor

用于 KDE 的 XML 编辑器。KXML Editor 是一个简单的程序，用于显示和编辑 XML 文件的内容。左侧包含 XML 文档结构的树形，右侧包含所选 XML 元素的属性列表及其内容。来自 Debian 3.0r0 APT `http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
