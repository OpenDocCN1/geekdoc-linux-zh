## 用户输入

我们之前已经看到了一些与代码的基础用户交互，现在是专门关注你如何从用户那里获取信息并将其呈现的好时机。

## 用户友好

你想要从用户那里获取的输入类型很大程度上取决于你正在编写的程序类型。例如，游戏可能会询问角色的名字，而数据库可能会询问个人详情。

### 步骤 1
如果你还没有打开，打开 Python 3 IDLE Shell，并在编辑器中新建一个新文件（New File）。让我们从一个非常简单的开始吧：

```python
print("Hello")
firstname=input("What is your first name?")
print("Thanks.")
surname=input("And is your surname?")
```

### 步骤 2
保存并执行代码，正如你毫无疑问猜到的那样，在 IDLE Shell 中，程序会询问你的名字，并将其存储在变量中（`firstname`, `surname`）：

### 步骤 3
现在由于我们已经将用户的名字存储在两个变量中，我们可以随时随地调用它们：

```python
print("Welcome", firstname, surname, ". I hope you're well today.")
```

### 步骤 4
运行代码，你会发现一个小问题，姓氏后面的句号留了一个空格。为了消除这个问题，我们可以在逗号处添加一个加号，代码如下：

```python
print("Welcome", firstname, surname + ". I hope you're well today.")
```

### 步骤 5
你并不总是需要在 `input` 命令中包含引号文本。例如，你可以询问用户名字，并在行中留空输入：

```python
print("Hello. What's your name?")
name=input()
```

### 步骤 6
上一步的代码通常被认为比在 `input` 命令中带有固定长度的文本要更好一点，但这不是一个板成不变的规则，因此在这些情况下你可以根据自己的喜好操作。扩展代码如下如下：

```python
print("Wait who goes there?")
name=input()
```

### 步骤 8
你在这里创建的是一个条件，我们很快就会涵盖它。简而言之，我们将使用用户的输入并将其与条件进行比较。所以，如果用户输入 David 作为他们的名字，卫兵将允许他们无恙通过。如果他们输入除 David 外的其他名字，卫兵将挑战他们进行战斗。

### 步骤 9
正如你之前学过的，用户的任何输入都自动是字符串，因此你需要应用类型转换（TypeCast）来将其转换为其他类型。这为 `input` 命令创建了一些有趣的方面。例如：

```python
# 计算费率和距离的代码
print("A rate and a distance")
rate=float(input("Rate: "))
```

### 步骤 10
为了完成费率和距离，我们可以添加：

```python
distance = float(input("Distance: "))
print("Time: ", (distance / rate))
```

## 创建函数

现在你已经使用了 Python 中大部分实用的功能，下一步是处理函数。你已经用过一些函数，例如 `print` 命令，但 Python 允许你定义自己的函数。

## 奇妙函数

函数是你输入到 Python 中执行某些操作的命令。它是一小段自包含的代码，接收数据、对其进行处理并返回结果。

- **步骤 1** 函数处理的不仅仅是数据。它们可以做事情：排序数据、将项目从一种格式转换为另一种格式，以及检查项目的长度或类型。基本上，函数是一个紧跟在括号后面的短单词。例如，`len()`、`list()` 或 `type()`。

- **步骤 3** 你可以用同样的方式通过函数传递变量。假设你想知道一个人姓氏的字母数量，你可以使用以下代码（为此示例进入文本编辑器）：

```python
name=input("Enter your surname: ")
count=len(name)
print("Your surname has", count, "letters in it.")
```
