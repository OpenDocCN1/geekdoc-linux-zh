
`movl %eax, 8(%ebx,%edi,4)`

在 Intel 语法中，这将写为：

```
mov [8 + %ebx + 1 * edi], eax
```

与 AT&T 对应版本相比，内存引用更容易读，因为它准确地说明了地址将如何被计算。然而，Intel 语法中操作数的顺序可能会令人困惑。

## 附录 E. 汇编语言中的 C 语言

本附录面向学习汇编语言的 C 程序员。旨在提供关于 C 构造如何在汇编语言中实现的通用概念。

### if 语句

在 C语言中，`if` 语句由三部分组成：条件、真分支和假分支。然而，由于汇编语言不是块结构化语言，你必须通过一些工作来实现 C 的块状特性。例如，看下面的 C 代码：

```c
if(a == b)
{
    /* 此处为真分支代码 */
}else{
    /* 此处为假分支代码 */
}
```

* 在此处，汇合 *

在汇编语言中，这可以渲染为：

```assembly
#将 a 和 b 移动寄存器进行比较
mov a, %eax
mov b, %ebx
## 比较
cmpl %eax, %ebx
## 如果为真，跳转到真分支
je true_branch
```

```assembly
false_branch:    # 此标签是不必要的，
               #仅用于文档说明
## 此处为假分支代码
```

```assembly
## 跳转到汇合点
jmp reconverge
```

```assembly
true_branch:
## 此处为真分支代码
```

```assembly
reconverge:
## 两个分支都汇合到此处
```

如你所见，由于汇编语言是线性的，代码块之间必须相互跳转。汇合是由程序员处理的，而不是系统。

`case` 语句的写法就像一组顺序的 `if` 语句。

### 函数调用

汇编语言中的函数调用只需要将函数参数按逆序推入栈中，并发出调用指令。调用完成后，参数将从栈中弹出。例如，考虑以下 C 代码：

```c
printf("The number is %d", 88);
```

在在汇编语言中，这将被渲染为：

```assembly
.section .data
```
