
从该集合中同一时刻或不同时刻的任意数量信号的联合分布函数是一个多元正态分布。鉴于自然随机过程通常是大量独立贡献因素的总和这一事实，这一实验事实并不令人惊讶。例如，热噪声是由于数十亿个电子和原子的热运动造成的。在特定时间和地点的海浪高度是之前一段时间内大面积上风生波的总和。参见分布（概率），电气噪声；随机过程。

生成随机过程的潜在机制通常可以用物理或数学术语来描述。例如，产生散粒噪声的潜在机制是热电子发射。如果生成机制不随时间变化，则随机过程的任何测量平均特性都与测量时间无关（除了统计波动），并且该随机过程称为平稳的。如果生成机制发生变化，则随机过程称为非平稳的。参见控制系统。[S.S.I.C.]

# 斯石英

天然存在的斯石英，SiO$_{2}$，是在极高压力下形成的矿物，其中硅原子处于六配位或八面体配位，而不是通常的四配位或四面体配位。斯石英的存在表明形成压力超过 $10^{8}$ lb/in.²（7.5吉帕）。斯石英在极大深度存在的可能性强烈影响了地质物理学家和固体物理学家关于矿物物质相变的解释，以及在地学内部研究中地震数据的解释。参见二氧化硅矿物。

斯石英以亚微米大小以极少量（小于岩石的1%）出现在亚利桑那州陨石坑的Carbonia砂岩样品中，该砂岩含有高达10%的柯石英，即二氧化硅的另一种高压同质多异物。由于其极细的晶粒尺寸以及该矿物在岩石中的稀少性，只有经过化学富集后通过X射线衍射法才能对矿物进行阳性鉴定。参见柯石英，陨石。

根据X射线数据计算的斯石英比重为4.28，而合成材料的值为4.35。它比柯石英密度高46%，且比其他二氧化硅变体密度大得多。参见金红石。[E.C.T.C.]

# 随机过程

物理随机过程是由概率定律控制的任何过程。示例包括（1）受孟德尔遗传控制的种群发展；（2）受分子碰撞作用的微观粒子的布朗运动，或者在不同尺度上，恒星在空间中的运动；（3）赌场中游戏的连续进行；以及（4）车辆通过指定公路点。

在每种情况下，概率系统都在演变；也就是说，其状态随时间变化。因此，时刻 `t` 的状态取决于偶然：它是一个随机变量 `x(t)`。涉及的 `t` 的值的参数集通常是（在本文中始终是）一个区间（连续参数随机过程）或一组整数（离散参数随机过程）。然而，一些作者仅将随机过程这一术语应用于连续参数情况。

如果系统状态由单个数字描述，则 `x(t)` 是数值型的。在其他情况下，`x(t)` 可能是向量型的，甚至更复杂。对于数值型情况，随着状态变化，其值确定了一个时间函数，即样本函数，且控制该过程的概率定律确定

分配给样本函数各种可能性质的概率。

数学随机过程是一种受物理随机过程概念启发的数学结构，其研究原因在于它是物理随机过程的数学模型，或因其固有的数学兴趣及其在概率论领域内外应用而被研究。数学随机过程被简单地定义为一族随机变量。也就是说，指定了一个特定的集合 `I`，并为每个参数点 `t` 指定了一个随机变量 `x(t)`。如果回顾随机变量本身也是一个函数，如果用 `ω` 表示随机变量 `x(t)` 定义域中的一个点，`i` 并且如果用 `x(t0, ω)` 表示该随机变量在 `t0` 的值，那么结果就是该随机过程完全由上述定义的函数对 `(t, ω)` 以及概率的分配所指定。如果 `t` 固定，这个双变量函数定义了 `ω` 的函数，即表示为 `x(t)` 的随机变量。如果 `ω` 固定，这个双变量函数定义了 `t` 的函数，即过程的样本函数。

概率通常通过为其随机变量分配联合概率分布来分配给随机过程。这些联合分布以及从中导出的概率，可以被解释为样本函数性质的概率。例如，如果 `t0` 是一个参数值，那么样本函数在时间 `t0` 为正的概率就是随机变量 `x(t0)` 具有正值概率。在此层面的基本定理是，对于任何自洽的联合概率分布的分配，都有一个随机过程与之对应。

平稳过程是指随机变量任何有限个数的联合分布不受参数平移影响的随机过程；也就是说，`x(t1 + h)`、...、`x(tn + h)` 的分布不依赖于 `h`。参见[概率论](https://www.example.org/probability)。

马尔可夫过程是指这样一个过程：如果已知现在，则未来和过去相互独立。更精确地说，如果 `t1 < … < tn` 是参数值，且 `1 < j < n`，那么给定 `x(tj)` 时，随机变量集合 `[x(t1), ..., x(tj-1)]` 和 `[x(tj+1), ..., x(tn)]` 是相互独立的。等价地，给定 `x(t1), ..., x(tn-1)` 时 `x(ti)` 的条件概率分布仅依赖于 `x(tn-1)` 的指定值，并且实际上是给定 `x(tn-1)` 时 `x(ti)` 的条件概率分布。一个重要的简单例子是马尔可夫链，其中状态数是有限的或可数无限的。

鞅是具有以下性质的随机过程：如果 `t1 < … < tn` 是参数值，给定 `x(t1), ..., x(tn-1)` 时 `x(ti)` 的期望值等于 `x(tn-1)`。换句话说，给定当前和过去值时，未来值的期望值等于当前值。显然，可以将鞅解释为在公平赌博游戏连续博弈后玩家资产的状况。

独立增量过程是一个连续参数过程，具有这样的性质：如果 `t1 < … < tn` 是参数值，则 `x(t2) - x(t1)`, ..., `x(tn) - x(tn-1)` 中的连续增量是相互独立的。如果 `y(t) = x(t) - x(t0)`，其中 `t0` 是固定的，则 `y(t)` 过程是一个马尔可夫过程。参见[博弈论](https://www.example.org/game_theory)；[信息论](https://www.example.org/information_theory)；[线性规划](https://www.example.org/linear_programming)；[运筹学](https://www.example.org/operations_research)。 [J.L.D.]

# 化学计量学

所有化学测量，例如原子和分子权重及尺寸、气体体积、蒸汽密度、偏离气体定律的测量，以及分子结构。在确定原子相对重量时，科学家依赖于化合比、比热容和气体体积的测量。所有此类测量以及将它们相互关联的计算，构成了化学计量学领域。由于测量是以数学术语表达的，化学计量学可以被视为普通化学的数学部分。

在一般用法中，化学计量学术语指化学过程中涉及的物质或能量测量量之间的关系；这些量的计算包括假定确定比例定律以及物质和能量守恒定律的有效性。参见[能量守恒](https://www.example.org/conservation_of_energy)；[质量守恒](https://www.example.org/conservation_of_mass)。

典型的化学计量问题涉及预测在化学反应中产生所需量产物所需的反应物重量。例如，磷可以通过某种工艺从磷酸钙 `Ca3(PO4)2` 中提取，产率为 90%（部分磷酸钙未反应或部分磷丢失）。在一个具体问题中，可能需要通过该反应确定制备 16.12 磅磷所需的磷酸钙质量。制备的平衡方程式如反应 (1) 所示。在该方程式中，
