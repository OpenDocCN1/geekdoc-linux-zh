# 测试和修复文件系统

在我们早期关于 `/etc/fstab` 的示例中，我们看到每行末尾有一些神秘的数字。系统每次启动时都会在挂载前常规检查文件系统的完整性。这是通过 `fsck` 程序（“文件系统检查”）完成的。`fstab` 条目中的最后一个数字指定了检查设备的顺序。在我们之前的示例中，我们看到首先检查根文件系统，然后是 `home` 和 `boot` 系统。最后数字为零的设备不进行常规检查。

除了检查文件系统的完整性，`fsck` 还可以修复文件系统，成功程度取决于损坏程度。在 Unix 类文件系统中，恢复的文件分区放在每个文件系统根目录下的 `lost+found` 目录中。

要检查 `EXT4_Disk` 分区（应先卸载），我们可以这样做：

```
me@linuxbox~$ sudo umount /dev/sdd
me@linuxbox~$ sudo fsck /dev/sdd
fsck from util-linux 2.37.2
efck 1.46.5 (38-Dec-2021)
EXT4_Disk: clean, 11/7331840 blocks, 60693/2926640 blocks
```

如今，文件系统损坏非常罕，除非存在硬件问题（例如硬盘故障）。在大多数系统上，启动时检测到的文件系统损坏将导致系统停止并要求你运行 `fsck` 后再继续。

在 Unix 文化中，`fsck` 这个词经常被用来代替一个与其共享三个字母的流行词汇。考虑到当你发现自己处于被迫运行 `fsck` 的境地时，很可能会脱口而出上述那个词，这种用法显得尤为恰当。

## 在设备间直接传输数据

虽然我们通常认为计算机上的数据是组织成文件的，但也可以将数据看作“原始”形式。例如，如果我们观察一个磁盘驱动器，会发现它由大量的数据“块”组成，操作系统将这些块视为目录和文件。如果我们把磁盘驱动器简单视为数据块的集合，就可以执行一些有用的任务，例如克隆设备。

`dd` 命令执行此任务。它将数据块从一个地方复制到另一个地方。它使用独特的语法（出于历史原因），并且在这种情况下非常非常好用：

```bash
dd if=input_file of=output_file bs=block_size [count=blocks]
```

## 警告

`dd` 命令非常强大。尽管它的名字来源于“data definition”（数据定义），但它有时被称为“destroy disk”（毁灭磁盘），因为用户经常会混淆 `if` 或 `of` 指定。在按下回车键之前，务必双重检查输入和输出指定！

假设我们有两个大小的 USB 闪盘，并想将第一个精确复制到第二个。如果我们将两个驱动器连接到计算机，它们分别被分配到设备 `/dev/sdb` 和 `/dev/sdc`，我们可以通过以下命令将第一个驱动器上的所有内容复制到第二个：

```bash
[me@linuxbox ~] sudo dd if=/dev/sdb of=/dev/sdc
```

或者，如果计算机只连接了第一个设备，我们可以将其内容复制到一个原始文件中，以备日后恢复或复制。

```bash
[me@linuxbox ~] sudo dd if=/dev/sdb of=flash_drive.img
```

## 创建 CD-ROM 镜像

写入可录刻 CD-ROM（CD-R 或 CD-RW）包含两个步骤：

- 1. 构建一个 ISO 镜像文件，它是 CD-ROM 的精确文件系统镜像

- 2. 将镜像文件写入 CD-ROM 介质中

## 创建 CD-ROM 的镜像拷贝

如果我们想为现有的 CD-ROM 创建一个 ISO 镜像，可以使用 `dd` 读取 CD-ROM 上的所有数据并将其到本地文件中。假设我们有一个 Ubuntu CD，并想制作一个 ISO 文件，稍后可以用它制作更多副本。在插入 CD 并确定其设备名称（我们假设为 `/dev/cdrom`）后，我们可以这样创建 ISO 文件：

```bash
dd if=/dev/cdrom of=ubuntu.iso
```

这种技术也适用于数据 DVD，但对于音频 CD，因为它们不使用文件系统进行存储。对于音频 CD，请查看 `cddao` 命令。

## 从文件集合创建镜像

要创建一个包含目录内容的 ISO 文件，我们使用 `genisimage` 程序。要做到这一点，我们创建一个包含所有想要包含在镜像中的文件的目录，并执行 `genimage` 命令来创建镜像文件。例如，如果我们有一个名为 `~/cd-rom-files` 的目录，并向其中填充了用于 CD-ROM 的制文件，我们可以通过以下命令创建一个名为 `cd-rom.iso` 的镜像文件：

```bash
genisimage -o cd-rom.iso -R -J ~/cd-rom-files
```

`-R` 选项为 Rock Ridge 扩展添加元数据，允许使用长文件名和 POSIX 风格的文件权限。同样，`-J` 选项启用 Joliet 扩展，允许 Windows 使用长文件名。

## 即使换个名字…… . . .

> 如果你查看关于创建和刻录 CD-ROM 和 DVD 等光介质的在线教程，你会经常遇到两个名为 `mkisofs` 和 `cdrecord` 的程序。这些程序是 Jorg Schilling 编写的名为 `cdtools` 的流行包的一部分。在 2006 年夏天，Schilling 先生对 `cdtools` 包的部分内容进行了许可变更，在 Linux 社区许多人看来，这导致了与 GNU GPL 许可的不兼容性。结果，`cdtools` 项目启动了一个分支，其中包含了对 `cdrecord` 和 `mkisofs` 的替代程序，分别名为 `wodlin` 和 `genimage`。

## 写入 CD-ROM 镜像

得到 ISO 文件后，我们就可以将其刻录到光介质上。我们在接下来的章节中讨论的大多数命令都适用于可录刻的 CD-ROM 和 DVD 介质。

## 直接挂载 ISO 镜像

有一个技巧，我们可以在 ISO 镜像仍在硬盘上时将其挂载，并将其视为已存在于光介质上。通过向 `mount` 添加 `-o loop` 选项（以及 `-t` 文件系统类型），我们可以像对待设备一样挂载镜像文件并将其附加到文件树上：

```bash
mkdir /mnt/iso_image
mount -t iso9660 -o loop image.iso /mnt/iso_image
```

在这个示例中，我们创建了一个名为 `/mnt/iso_image` 的挂载点，然后在该点挂载了 `image.iso`。镜像挂载后，可以被视为真实的 CD-ROM 或 DVD。记住在不再需要时卸载镜像。

## 擦除可重写 CD-ROM

可重写 CD-RW 介质在重新使用之前需要擦除或清空。为了做到这一点，我们使用 `cdis` 命令。`-b` 选项用于清空光盘，`-e` 选项用于擦除它。

```bash
cdis -b /dev/sr0
cdis -e /dev/sr0
```

## 检查和监控网络

即使你不是系统管理员，检查网络的性能和运行状况通常也有帮助。

## ping

最基础的网络命令是 `ping`。`ping` 向指定的主机发送一个名为 `ICMP ECHO REQUEST` 的特殊网络数据包。大多数接收此数据包的网络设备都会对其进行响应，从而验证网络连接。

> 注意

可以配置大多数网络设备（包括 Linux 主机）忽略这些数据包。这通常出于安全考虑，目的是从潜在的攻击者面前部分隐藏主机。防火墙也经常被配置为拦截 ICMP 流量。

例如，为了查看我们是否到达 https://linuxcommand.org（我们最喜欢的网站之一），我们可以这样使用 `ping`：

```
@linuxbox ~$ ping linuxcommand.org
```
