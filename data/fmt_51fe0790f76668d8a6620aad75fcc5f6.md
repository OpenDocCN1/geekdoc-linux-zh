## 微分数学
用于确定自变量值变化的影响的操作。在本文中，考虑一个变量。参见偏微分。多元函数的求导

如果 `$f$` 是一个包含 `$x_0$` 导数的区间函数，则定义如方程 (1) 所示：

```
$f'(x_0) = \frac{f(x) - f(x_0)}{x - x_0} \quad (1)$
```

定义 `f(x_0)` 的极限可能不存在。如果 `f` 在 `x_0` 处可微。

`f` 在 `x_0` 处连续，如果 `x_0` 在 `f` 的定义域内且：

```
$$\lim_{x\to x_0} f(x) = f(x_0)
```

此处使用的极限概念的精确定义如下：设 `g` 为一个函数，`a` 为一个数。方程 (2) 意味着每一个数 `a` 对应于：

```
$$\lim_{x\to a} g(x) = g(a) (2)
```

`g` 定义域内的某点 `a`，使得 `g(x) < a` 永远不在包含包含 `x_0` 附近数值且 `x < x_0` 的 `g` 定义域内。要求是 `g` 必须包含所需的 `x_0` 附近的数值，且从 `g` 的定义域也必须包含 `x_0`，但它是内部的。

然而，如果 `f` 在 `x_0` 处可微，则 `f` 在 `x_0` 处连续。如果 `f` 在 `x_0` 处不连续，则它不可微的。例如：在 `x=0` 处，`f(x) = |x|`。函数也可能在某点连续但在该点附近的任何点均不可微。

微分 (1) 的主要应用是表示变化率（速度、加速度），以及解决一个变量的变化率与另一个变量成函数关系进行计算的问题，通常用于研究平面或空间中的曲线 (2)，在微分形式的表达式 (3) 中，以及该法则各种扩展和应用中的极值中，包括泰勒公式和泰勒级数等主题。

微分的通用技术建立在函数组合求导规则的基础上：如果 `u=f(x)` 和 `v=g(x)` 在 `x` 取值范围内可微，那么当 `v != 0` 时，`u+v` 和 `u/v` 是可微。公式所示：(3)。如果是

```
$$\frac{d}{dx}(u+v) = \frac{du}{dx} + \frac{dv}{dx}$$
$$\frac{d}{dx}(uv) = u\frac{dv}{dx} + v\frac{du}{dx}$$
$$\frac{d}{dx}(\frac{u}{v}) = \frac{v\frac{du}{dx} - u\frac{dv}{dx}}{v^2}$$
```

值，则 `v != 0`。一种非常强大的技术工具体现在复合函数的规则中：如果 `y` 是 `u` 的可微函数，`u` 是 `x` 的可微函数，那么 `y` 是 `x` 的可微函数，

## 衍射

衍射是所有电磁辐射的现象，包括无线波；微波；红外、可见光、紫外线和 X 射线。

## 扩散
是由于分子随机运动从一个地方到另一个地方质量传输。在气体、液体和固体中，扩散同样表现为通过膜的扩散、液体蒸发、纤维干燥、水溶液中溶质扩散以及核反应堆中热分子的传输过程。化学反应速率受快速扩散的限制，缓慢反应受光或催化剂的限制。分子之间的过程受物种扩散的限制。在细胞运输中；集成电路；热笔记。

气体（和液体）中的分子在不断运动。例如，在静止空气中，氮分子和氧气分子的运动速度不同，通过在墨水玻璃管上方倒层水可以很容易地证明。当分子向上扩散到清水水中时，墨水和水之间的边界保持清晰。最终，墨水在没有任何气体帮助的情况下填满了整个管子。用于测量气体扩散的技术有很多：两个气体双室容器通过一管连接，扩散在该管中发生。扩散之后是每个使用气体成分随之的变化。通过在垂直管中将一种气体混合物放在另一种气体混合物上方并在一段时间后测量沿管的成分，也可以获得理想的结果。

气体中的扩散速率随温度 (`T`) 的增加而近似为 `T^{3/2}`，并与成分的独立性成反比。混合物的扩散在很大程度上与成分无关。

动力学理论表明，分子的自扩散与分子量的平方根和速度的平方成反比。气体的扩散系数可以通过这种方式估计。动力学理论的预测在高达 10 atm 的压力下准确率约为 5%。此时，分子之间的作用力变得更加重要，特别是对于致密气体。

液体扩散的测量是通过创建溶液并使用光学方法跟踪沿溶液柱折射率的变化来完成的。尽管发明了许多实验技术，但通过膜隔室扩散也可以获得实验结果。
