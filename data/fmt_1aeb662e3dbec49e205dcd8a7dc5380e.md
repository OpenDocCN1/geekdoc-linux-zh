
## 微扰论的失效

亨利·庞加莱在19世纪末发现，对于许多问题，微扰论并不完全令人满意。他展示了在月球绕地球运动的情况下，太阳的摄动强度足以使这种标准数学程序失效。主要罪魁祸首是共振，它发生在不同自由度的频率通过它们的非线性耦合相互组合时。工程师们已知的一种关键非微扰现象被称为相位锁定：当不同频率以简单倍数关系出现时，整个动力系统陷入动态陷阱，并且对于初始条件的连续范围，相互作用会改变单个自由度的频率，从而将运动“锁定”在共振中。参见[小行星](https://example.com/asteroid)；[锁相环](https://example.com/phase_locked_loops)；[共振（声学与力学）](https://example.com/resonance_acoustics_and_mechanics)。

## KAM定理

20世纪50年代，A. N. 科尔莫戈洛夫首次阐述了弱耦合的加入如何在相空间中产生混沌区域和岛屿。这个问题后来由 V. 阿诺尔德和 J. 莫泽详细解决，从而得出了KAM定理。该定理提供了关于随着耦合强度增加而失去规则结构的详细信息。然而，它并未说明在新创建的混沌行为区域中的轨迹。这些进一步的调查是混沌或复杂性等领域的主要目标。庞加莱的普遍论证和KAM定理的影响遍及非线性物理的每一个领域。其中领头的领域是流体力学，其中的湍流现象迄今为止仍有效控制。这使得天气预报如此困难。沿神经的信号传播和通过突触连接的电脉冲传输是其他众所周知的非线性过程。参见[混沌](https://example.com/chaos)；[神经生物学](https://example.com/neurobiology)；[非线性声学](https://example.com/nonlinear_acoustics)；[非线性光学](https://example.com/nonlinear_optics)。

## 非线性规划

应用数学和运筹学的一个分支，涉及在变量受到约束或限制的情况下寻找函数的最大值或最小值。非线性规划有时也被称为非线性优化。

一个有用的例子涉及使用水库水冷却电厂的电厂。加热后的水随后被管道输送到湖中。为了效率，电厂应以与安全性考虑相一致的最高可能温度运行，但对从电厂泵出的水量也有限制，并且对湖泊温度升高的幅度也有生态约束。优化问题是在满足安全约束、水泵入电厂水率的限制以及湖泊温度升高上限的条件下，最大化电厂的温度。

非线性规划问题特指待最小化或最大化的函数（称为目标函数）和描述约束的函数均为非线性函数的情况。通常，变量是连续的；本文仅局限于此情况。

非线性规划的研究人员考虑这些问题的理论和实际方面。理论问题包括研究表征解的代数和几何条件，以及决定解的存在性和唯一性的凸性的一般概念。所解决的实际问题包括特定问题的数学表述，以及寻找此类问题解的算法的开发与分析。

一般非线性规划问题可以表述为在所有满足一组约束的向量 `x` 上最小化标量目标函数 `f(x)`。约束形式为非线性方程和不等式。数学上，非线性规划问题可表示如下，其中 `x = <x_1, x_2, ..., x_n>` 是问题的变量：

最小化 `f(x)` 关于 `x`

约束条件：

`g_i(x) <= 0, i = 1, 2, ..., m`

`h_j(x) = 0, j = 1, 2, ..., p`

其中 `f` 是目标函数，`g_i(x)` 是不等式约束，`h_j(x)` 是等式约束。这种表述具有普遍性，因为最大化 `f(x)` 的问题等价于最小化 `-f(x)`，且约束 `g_i(x) >= 0` 等价于约束 `-g_i(x) <= 0`。

由于一般非线性方程无法以封闭形式求解，必须使用迭代方法。此类方法生成一系列近似值（即迭代值），在指定条件下收敛到解。牛顿法是最著名的方法之一，是解决非线性规划问题最快的许多方法的基础。

## 非金属

元素被方便但任意地分为金属和非金属。非金属不容易导电，不具延展性，没有复杂的折射率，并且通常具有很高的电离势。

# 非牛顿流体

非牛顿流体是指偏离经典线性牛顿应力与剪切速率关系的流体。严格来说，流体是指任何非固体的物质状态，而固体是具有唯一无应力状态的物质状态。一个概念上更简单的定义是：流体能够在没有外力作用的情况下获得其容器的形状并永远保持该形状。因此，流体涵盖了多种多样的物质状态，包括气体和液体，以及许多更奇特的状态（例如，等离子体、液晶和泡沫）。参见：流体、泡沫、气体、液体；液晶；等离子体 [物理学]。

牛顿流体是指其流变行为仅由温度的单一函数——即粘度——来表征的流体，粘度是衡量流体“滑溜程度”的指标。以图 1 中的例子为例，当流体在固定板和移动板之间受到剪切时，粘度由公式 (1) 给出。因此，随着流体粘度的增加，在给定速度下移动上板所需的力就越大。对于简单的牛顿流体，粘度是仅取决于温度的常数；但对于非牛顿流体，当剪切速率（图 1 中的速度/高度）变化时，粘度可能会变化好几个数量级。通常，这些流体的粘度 (`η`) 被表示为剪切速率 (`dot{γ}`) 的函数。图 2 给出了这种函数关系的一种常见形式。对于其他非牛顿流体，随着剪切速率的增加，粘度可能会增加（剪切增稠流体）。参见：牛顿流体；粘度。

日常生活中遇到的许多流体（如水、空气、汽油和蜂蜜）都可以被充分描述为牛顿流体，但非牛顿流体甚至更多。常见的例子包括蛋黄酱、花生酱、牙膏、蛋白、液体肥皂和多级发动机油。其他例子，如熔融聚合物和浆料，具有重大的技术重要性。许多非牛顿流体的一个显著特征是，它们具有微观或分子水平的结构，这些结构在流动中可以发生显著的重排。参见：颗粒流动；聚合物。

我们对流体行为和流动的直观理解，主要建立在牛顿流体的观察和体验之上。然而，非牛顿流体表现出丰富的行为，这些行为往往与这些预期形成鲜明对比。例如，通过在手指间摩擦流体，可以直观地感受流体的滑溜程度。此外，以这种方式体验到的水的滑溜程度，预期与汽车轮胎在湿滑路面上的滑溜程度相同。然而，许多非牛顿流体的滑溜程度（粘度）会根据其移动速度或施加于其上的力而发生巨大变化。

对于当流体被搅拌时（流体在容器壁处聚集）流体表面变形的直观预期，也与非牛顿流体的行为形成鲜明对比。当一根圆柱形杆在装有牛顿流体的容器中旋转时，离心力会使流体在壁处升高。然而，对于非牛顿流体，法向应力差会导致流体沿杆向上爬升；这被称为威森贝格效应。关于当流体流动突然停止（例如，关闭水龙头）时物料运动的直观理解，在非牛顿流体的行为情况下也是无效的。参见：离心力。

非牛顿流体在从开口挤出时也表现出违反直觉的行为。牛顿流体在离开开口时会逐渐变细，截面变小，但非牛顿流体的截面在最终变细之前会先增加。这种现象称为口模膨胀。参见：喷嘴。

当牛顿流体被虹吸且液面降到虹吸管入口以下时，虹吸作用停止。然而，对于许多非牛顿流体，虹吸作用会持续，流体从虹吸管爬升并继续进入管内。这种现象称为无管虹吸。

非牛顿流体最引人注目的行为可能是其粘弹性的结果。固体可以被认为具有完美的记忆。如果在力的作用下变形，当力被移除时，它们会恢复原来的形状。当一个橡胶球弹起时，就会发生这种情况；球撞击表面时发生变形，橡胶“记住”其未变形的球形。形状的恢复使球反弹。相比之下，牛顿流体没有记忆；当力被移除时，它们保持在力被移除时的状态（或因惯性继续移动）。当牛顿流体滴到表面上时，它不会反弹。非牛顿流体具有粘性弹性，因为它们具有 fading memory（消退记忆）。如果在施加力后不久移除力，流体将记住其未变形的形状并趋向该形状。然而，如果力在流体上施加很长时间，流体最终会忘记其未变形的形状。如果将非牛顿流体的样品滴到表面上，它会像球一样反弹。然而，如果流体只是放在表面上，它会缓慢流动。粘性弹性通常是非牛顿流体中观察到的许多二次流动的原因。这些流体的运动对于牛顿流体来说很小（例如，旋转运动），但对于非牛顿流体可能成为主导。参见：弹性。

流体流动过程的分析通常是通过检查局部守恒关系——质量、动量（牛顿第二定律）和能量的守恒——来进行的。这种分析需要特定的材料信息（例如，密度、压力和温度之间的关系），统称为本构关系。致力于获得合适的本构方程以描述非牛顿流体行为的科学称为流变学。流体力学中最重要的本构方程是将流体中的应力与运动学（即速度、速度随位置的变化率以及速度的时间历史）联系起来的方程。
