## 词汇表

这个关于 UNIX、安全和互联网相关的术术语语语库面向普通读者。更多术语和定义可以在 http://www.netdictionary.com 找到。

# A 可接受使用政策

简写 AUP。一套规范网络如何使用的正式规则集合。例如，最初的 NSFnet 可接受使用政策禁止商业组织进行非研究性用途。AUP 有时会限制可以公开的材料类型；许多 AUP 禁止传输色情材料。AUP 的执行在历史上是非常不均衡的。

# 访问控制

确保用户仅访问那些资源和服务。

# 积极攻击

一种绕过安全控制的攻击。

# 非对称加密

参见公共密钥加密。

# 攻击

一种尝试绕过安全。

# 审计

对记录进行符合政策和流程的独立检查。

# 审计追踪

在计算机安全中是系统使用的顺序记录。

# 身份验证

确保用户是其所声称的。

# 可用性

确保系统在给定时刻是运行且正常的。

# 后门

由设计者或维护人员留下的隐藏软件或硬件机制；等同于*陷门*。

# 波特

1. 调制器速度的过时术。具体来说，波特是指信道每秒改变信号的次数。2400 波调制器每秒变化 2400 次。波特常与每秒比特 (bps) 混淆。

2. 最初是一种电报信号单位，以法国工程师 J.M.E. Baudot (1845-1903) 命名。

# Blowfish

由 Bruce Schneier 在 1993 开发的一种块加密，用于替代 DES。

# 炸弹

隐藏在程序中的恶意代码，直到被触发为止保持。*逻辑炸弹*由用户操作或事件触发；*定时炸弹*在经过一段时间后或到达特定日期时触发。

# 暴力破解

一种依赖于计算机原始处理能力的编程风格，而非程序员的智能设计和实施决策。暴力破解的一个例子是向目标系统输入字典中的所有单词的密码破解程序。

# BSD

伯克利软件发行版的缩写。由 Bill Joy 等人在 1980 年起在加利福尼亚大学伯克利分校开发的 UNIX 版本。BSD 4.1、4.2 和 4.3 版本具有分页虚拟内存、TCP/IP 网络增强以及其他在 Sun Microsystems 等商业 UNIX 系统中广泛实施的功能。当前版本是 4.4；它在 FreeBSD、OpenBSD 和 NetBSD 中实现。BSD 有时与 AT&T UNIX 进行比较和对比。

# Bug

导致计算机软件或硬件发生故障或崩溃的问题。

# 证书颁发机构

简写 CA。一种为了网络安全目的证明个人或组织身份的实体。

# 校验和

对数据包或文件在传输之前之后对其内容的数学计算。如果“传输前”计算与“传输后”计算不匹配，则传输存在错误。

# 加密

参见密码学。

# 电路交换

电话公司传统在呼叫方和被呼叫方之间建立连续物理连接的信号交换方式。对比分组交换。

# 机密性

确保信息不被未经授权的人访问。

# 连接时间日志

由各种程序执行，将记录写入 `/var/log/wtmp`（或 `/var/adm/wtmp`）以及 `/var/run/utmp`（或 `/etc/utmp`）。诸如 `login` 等程序会更新 `wtmp` 文件，以便管理员能够跟踪谁登录了系统以及用户登录的时间。

# Cookie

电子标识符，使 Web 服务器能够记录并跟踪用户在网站内的移动轨迹。Cookie 是设计用于支持购物车应用程序的小型文件；当用户返回网站时，将使用一个 Cookie 回忆其在上一次会话中放入购物车的物品。Cookie 还用于帮助广告商向重复访问者投放横幅广告，并存储用户名和密码，这样在每次访问安全网站时无需重新输入。Cookie 由 Lou Montulli 在任职 Netscape 时发明，它们引发了关于隐私和安全的争议性问题。一项提议的互联网标准（RFC 2109）将赋予用户不仅禁用所有 Cookie 还能检测网站何时跟踪用户的权力。它还允许用户根据个人偏好接受 Cookie。

# 破解者 (cracker)

一种恶意黑客，通过破坏（或破解）计算机系统的安全性来访问、盗取或破坏敏感信息。“Hacker”一词经常被错误地用来替代 cracker，尤其是媒体。如此。请对比 *hacker*。

# 加密程序 (crypt)

一种基于二战时期 Enigma 密码机的原始 UNIX 加密程序。
