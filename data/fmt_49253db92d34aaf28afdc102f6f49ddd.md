
## 基础术语

### 记录（record）
在网络中，在通信信道上与其他消息隔开的消息。消息边界由发送者创建，并传递给接收者。写或读操作从单个记录传输数据，但某些协议允许通过多次写或读操作传输一条记录。

### 恢复风暴（recovery storm）
当服务器在经历一段时间不可用后恢复服务并变得拥塞时可能发生的故障状态。如果对服务器有巨大需求，它可能会被请求淹没。如果服务器简单地忽略无法处理的请求，客户端将迅速重新发送这些请求。因此，服务器会对尚未准备好服务的请求回复“稍后试”。收到此类响应的客户端在重新发送请求之前等待的时间比典型的超时时间长得多。

### 红区（red zone）
紧邻每个进程内核模式运行栈最后一页下方的只读内存区域。系统设置红区，以便当进程溢出分配给其内核栈的空间时会发生故障。

### 被引用页面（referenced page）
在虚拟内存系统中，被读取或写入的页面。

### 引用字符串（reference string）
描述进程在执行执行期间引用的页面的数据集。该描述代表了进程在生命周期内离散时间点的与内存相关的行为。

### 区域（region）
以相同方式处理的内存范围。例如，进程的文本是一个只读区域，并从包含它的磁盘文件上按需进行分页加载。

### 相对路径名（relative pathname）
参见`路径名（patname）`。

### 可靠传递消息（reliably-delivered-message）
一种保证数据可靠交付和内存边界保留、且未连接的套字类型。

### 重定位（relocation）
将程序内容从地址空间的一个位置复制到另一个地方。这种复制可能伴随着对镜像的修改，以便在程序复制后保持正确。未绑定到特定内存地址的代码被称为`可重定位（relocatable）`。

### 远程过程调用（RPC）
从客户端到不同服务器进程子程序的过程调用。通常，客户端和服务器进程运行在不同的机器上。远程过程调用的操作类似于本地过程调用：客户端发起过程调用，并在过程执行时等待结果。参见序列化（marshalling）。

### 替换策略（replacement policy）
按需分页虚拟内存管理系统在内存其他不可用时使用的页面集策略。

### 驻留对象（resident object）
存在于内存中的对象。例如，如果进程虚拟地址空间中的页面位于内存中，则它是驻留。

### 驻留集大小（resident-set size）
进程拥有的物理内存页面数。在一个调良好的系统中，进程的驻留集大小将是该进程的工作集。通常无法精确计算工作集，因此进程将拥有超出工作集的额外页面。

### 资源映射（resource map）
系统用于管理可用一组线性范围描述的资源分配的数据结构。

### 重传计时器（retransmit timer）
TCP 用于触发数据重传的计时器。该计时器每次将数据传输到远程主机时都会被设置。它的设置值预计大于接收主机接收数据并返回确认的时间。

### 反向映射页表（reverse-mapped page table）
参见`反向页表（inverted page table）`。

### 向前回滚（roll forward）
读取已提交操作日志的双重行为，从检查点开始，并重新应用任何未在底层存储系统中的操作。

# 术语表

### 根目录 (root directory)
内核在解析绝对路径名时使用的目录。每个进程都有一个根目录，可以通过 `chroot` 系统调用进行设置，且系统有一个唯一的根目录，其标识在系统引导时设置。

### 根文件系统 (root filesystem)
包含根目录的文件系统，它被视为机器上所有文件系统的根。默认根文件系统的标识被编译到内核中，尽管系统实际使用的根文件系统可能被设置为与系统引导时使用的系统之外的另一个文件系统。

### 旋转布局表 (rotational-layout table)
一种快速文件系统（Fast Filesystem）数据结构，用于描述文件系统中块的旋转位置。文件系统在选择优化块分配给文件时使用旋转布局表。

### 轮询 (round Robin)
队列中的一种算法，其中按照先来后到的顺序为每个请求提供固定时间的服务；如果请求在服务后仍未完成，则将其放在队列末尾。

### 路由 (route)
在数据交换网络通信中，通往目的地的路由指定了数据包必须通过的主机或多个主机。

### 路由器 (Router)
一种机器，也称为网关，具有两个或多个网络接口，并在其可以访问的网络之间转发数据包。通常，路由器运行一个路由进程，通过网络拓扑结构收集信息；使用这些信息制定一套下一跳路由，并将其安装在内核的路由表中。参见“路由机制；路由策略”。

### 路由守护进程 (routing daemon)
4.4BSD 中的一个进程，为系统提供路由管理服务。该服务使用路由信息的分布式数据库，该数据库通过动态更新以反映拓扑连接的变化。

### 路由机制 (routing mechanism)
内核中包含的用于实现外部定义策略的路由设施。路由机制提供了一种查找机制，为每个目的地提供第一跳路由（一个特定的网络接口和即时目的地）。参见“路由器；路由策略”。

### 路由策略 (routing policies)
用户级进程提供的用于定义外部策略的设施。路由策略包括路由守护进程在选择第一跳路由时使用的所有组件，例如本地网络拓扑的发现、各种路由协议的实现以及指定本地策略的配置信息。参见“路由器；路由机制”。

### 路由重定向消息 (routing redirect message)
网关识别出收到的消息可以通过更直接的路由递送时生成的消息。

### RPC
参见远程过程调用 (remote procedure call)。

### 运行队列 (run queue)
就绪执行的进程队列。

### 保存的组 ID (saved GID)
一种机制，通过在程序执行 `exec` 时复制有效 GID 的值来记录 `setgid` 程序的标识。在执行期间，程序可能通过将有效 GID 设置为其真实 GID 来临时撤销其 `setgid` 权限。稍后可以通过将有效 GID 恢复为保存 GID 来恢复其特权。另见“有效组标识符 (effective group identifier)”。

### 保存的用户 ID (saved UID)
一种机制，通过在程序执行 `exec` 时复制有效 UID 的值来记录 `setuid` 程序的标识。在执行期间，程序可能通过将有效 UID 设置为其真实 UID 来临时撤销其 `setuid` 权限。稍后可以通过将有效 UID 恢复为保存 UID 来恢复其特权。另见“有效用户标识符 (effective user identifier)”。

### 调度 (scheduling)
在操作系统中，计划的单元被用于共享资源。例如，进程调度用于共享 CPU 和主内存。

### 调度优先级 (scheduling priority)
内核满足的一个进程级参数，规定了内核调度进程执行的优先级。当进程在用户模式下执行时，系统会使用进程优先级和 `nice` 参数定期计算调度优先级。

### 次级存储 (secondary storage)
用于存放无法放入主内存的数据。次级存储通常位于旋转磁介上，如磁盘驱动器。另见“备份存储 (backing storage)”。

### 扇区 (sector)
磁盘上可以通过单次 I/O 操作访问的最小区域。

### 段 (segment)
由基地址 (base) 和范围 (extent) 定义的连续数据范围。在内存管理中，段描述进程地址空间的一个区域。在通信协议中，段由一组连续的序列号定义，这些号关联的数据。在日志结构文件系统（Log-Structured Filesystem）中，段是清理的逻辑单元。

### 段表 (segment table)
三级页表算法的顶层，用于描述进程的虚拟地址空间。段表中的每个项都指向中间级页表的页。PC 和 Motorola 68000 架构使用了三级映射层次。另见“前向映射页表 (forward-mapped page table)；页表项 (page-table entry)：页表页”。

### 发送窗口 (send window)
在 TCP 中，序列号范围定义了系统在连接上可以传输的数据，并确保接收方在收到后有空间存放这些数据。序列号在发送窗口开始之前的数据已经发送并确认。序列号在窗口结束之后的数据在发送窗口改变包含它们之前将不会发送。另见“滑动窗口方案 (sliding-window scheme)”。

### 感知请求 (sense request)
由于进程对套接字执行 `stat` 系统调用而传递给通信协议模块用户请求例程的请求。

### 序列空间 (sequence space)
分配给通过 TCP 连接传输的数据的序列号范围。在 TCP 中，序列号取自一个 32 位循环空间，称为初始序列号 (`initial sequence number`)。

### 序列包套接字 (sequenced-packet socket)
一种类型化的、可靠的基于连接的通信套接字，保留消息边界。

### 串行 IP (SLIP)
用于在异步串行路上传输 IP 数据报的封装。此外，线路规程（line discipline）实现了这种封装。

### 服务器进程 (server process)
通过进程间通信为客户端进程提供服务的进程。参见“客户端进程 (client process)”。
