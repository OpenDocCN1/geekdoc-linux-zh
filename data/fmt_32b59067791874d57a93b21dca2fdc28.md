
# 10.8 控制

## 10.8.12 关于 `$#` 的说明

注意到，虽然 Perl 似乎采用了 C shell 的 `$#` 符号，但其含义显著不同。在 Perl 中，该操作符产生数组中最后一个元素的索引。但这等同于元素的数量，因为 Perl 数组像 C 语言一样，从 0 开始而不是 1 开始。因此，空数组返回的值将是 -1 而不是 0。

## 错误处理与控制

OpenVMS 使用 `ON WARNING THE`、`ON ERROR THEN` 和 `ON WARNING_ERROR` 结构在发现错误或警告条件时引导 DCL 命令过程的执行流。错误或警告条件适用于该语句之后当前过程中的所有命令行，直到你引入新条件或使用 `SET NOON` 完全关闭错误处理。UNIX 以逐个命令为基础处理错误，使用内置的 C shell 变量 `status` 或其在 bash 和 Korn shell 中的等价符号 `?`。当从 Perl 内部调用外部程序时，此状态代码会被 Perl 捕获并可供检查。因此，Perl 程序可以检测是否发生了错误并进行妥善处理。然而，原生 Perl 语句本身实际上通过始终返回一个值来返回一个状态。而且任何 Perl 值都可以在“逻辑上”地被使用，这意味着 Perl 将未定义、0 或空字符串视为假，将非空或非零值视为真。

你还可以使用比较操作符 `||` 和 `&&` 为 Perl 语句或 shell 命令调用错误处理。作用于这些操作符的条件如下：

| 命令 1 | 命令 2 | 操作符 | 执行 |
| :--- | :--- | :--- | :--- |
| 成功 | | <code>&#124;&#124;</code> | 是 |
| | 执行 | <code>&#124;&#124;</code> | 否 |
| 否 | 否 | <code>&#124;&#124;</code> | 是 |
| | 成功 | <code>&amp;&amp;</code> | 是 |
| | 否 | <code>&amp;&amp;</code> | 否 |

我们将用示例说明操作符的每种形式。

![](img/e259ba2750941fa3d146eda78c65e89d_324_0.png)

### UNIX shell

**格式：**

```
command1
command1 || command2
```

**示例：**

```
% cc test.c >& err1 || mail fred < err1
```

**格式：**

```
command1 && command2
```

**示例：**

```
% grep csh /etc/passwd > cusers && ipr cusers
```

### Perl

**格式：**

```
command1 || command2
defined($x) || die ("required value missing") ;
```

**格式：**

```
command1 && command2
-e $fspec && rename($fspec, "$fspec.bak") ;
```

在 shell 示例中，`cc test.c >& err1 || mail fred < err1` 编译 C 程序。如果编译没有错误，命令执行停止。如果发生错误，包含错误的文件将发送给用户 fred。在 Perl 示例中，语句 `defined($x) || die ("required value missing")` 测试值是否已赋值，若未赋值则终止程序。

在 shell 示例中，`grep csh /etc/passwd > cusers && ipr cusers` 在 `/etc/passwd` 中搜索 `csh`，将输出重定向到 `cusers`，如果成功则处理 `cusers`。在 Perl 示例中，语句 `-e $fspec && rename($fspec, "$fspec.bak")` 测试 `$fspec` 指定的文件是否存在，如果存在，则通过添加 `.bak` 扩展名进行重命名。

## Flow 控制

这些示例通过使用 `grep` 命令说明了上述陈述。

如果命令执行正确并找到了搜索字符串，它返回值 0。如果命令执行正确但没有找到搜索字符串，它返回值 1。如果文件本身未找到，情况更严重，将返回值 2。将其与 OpenVMS 进行比较，在 OpenVMS 中，如果命令执行成功，`$STATUS` 返回一个奇数值。在 Perl 示例中，我们看到成功时的值相同 (0)，但失败的返回值似乎并不相同。这是因为返回的值不仅仅是退出值：它还包含了进程死亡时的信号编号（如果有）。换句话说，该状态实际上在一个 16 位的数字中包含两个 8 位的值。Perl 语句 `$exit_value = $status >> 8` 是一个如何从返回状态中解码退出值的示例，它产生的值与 shell 示例中看到的值完全相同。然而，在整个返回状态值中还可以找到其他有用信息，因此请务必参阅 Perl 文档以获取有关可以检测到哪些其他退出条件的更多细节。
