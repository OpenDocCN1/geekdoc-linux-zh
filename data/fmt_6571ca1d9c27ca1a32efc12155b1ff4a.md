你会发现，如果我们一次性制作这些按钮，效率会非常低——如果有数百个 `RSS` 源，它会减慢组件和 `GUI`。这个问题可以通过使用 `Listview` 来解决，它可以在内部附加按钮，但对大多数人来说这应该不是问题。

import feedparser

class Manager(ScreenManager):
  def get_feed(self, name):
    self.feed_name = name
