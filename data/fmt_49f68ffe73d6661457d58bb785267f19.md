
# 砷

砷有三种同素异形体。黄色立方 $\alpha$-型是通过在极低温下凝结蒸气制得的。黑色 $\beta$-同质多象体在结构上与黑磷相同。这两种形态在加热或曝光于光线下都会转变为稳定的 $\gamma$-型，即灰色或金属的、菱方晶系的砷。金属形态是中等的热和电导体，质地脆，易断裂，延展性低。

天然砷以矿物舍曼柯里白铁矿（`shermankolibait`）的形式存在，但通常与硫或锰、铁、铜、镍、银或锡等金属结合存在于地表岩石中。主要的含砷矿物是 `FeAsS`（砷毒砂，辉砷镍矿）；其他金属砷化矿石有 `FeAs$_2$`（毒砂，黄砷镍矿），`NiAs`（镍矿），`CoAs`（辉钴矿），`NiAsS`（杰斯多夫矿），和 `CoAs$_2$`（方钴矿）。天然存在的砷酸盐和硫代砷酸盐很常见，大多数硫化物矿石都含有砷。`As$_2$S$_3$`（雌黄）和 `As$_2$S$_2$`（雄黄）是最重要的含硫矿物。氧化物，砷华（arsenolite），`As$_2$O$_3$`，作为其他含砷矿物风化的产物被发现，也可从镍、铜和锡提取过程中收集的烟道灰中回收；当 Fe、Co、Ni 的砷化物在空气或氧气中煅烧时也会生成。该元素可通过在缺氧环境中煅烧 `FeAsS` 或 `FeAs$_2$`，或通过碳还原 `As$_2$O$_3$`（此时 `As$_4` 可被升华去除）来获得。

单质砷用途有限。它是少数几种可用 99.9999+% 纯度获得的矿物之一，主要用于激光材料 `GaAs` 以及作为制造各种固态器件的掺杂剂。砷氧化物用于玻璃制造。硫化砷用作颜料和烟火制品。亚砷酸盐用于医学，其他几种砷化合物也用于医学。砷化合物的大多数药用特性取决于其毒性。参见 [锑；磷] [L.T.W.]

# 毒砂

一种成分为 `FeAsS` 且结晶于单斜晶系的矿物。由于双晶现象，晶体具有假正交晶系对称性。莫氏硬度为 5.5–6.0，比重为 6.0。光泽为金属光泽，颜色为银白色。毒砂是最分布广泛的含砷矿物。它常见于含金矿脉（南达科他州利德，科罗拉多州，安大略省）、含锡或钨矿物（玻利维亚；英国康沃尔郡），或含镍-钴-银矿物（德国科布伦茨，弗赖贝格）。参见 砷。

# 艺术品保护化学

将化学应用于文化遗产的技术检查、鉴定和保存。博物馆工作的化学家从事广泛的调查研究，最经常研究的是文物的化学成分和结构、其腐蚀产物以及用于修复、复原和保护的材料。博物馆环境的影响，包括空气污染物、温度和相对湿度波动、生物活动以及紫外线和可见光照，代表了第二个主要研究领域。第三个感兴趣的领域是评估保护艺术作品的材料和技术的效能、安全性和长期稳定性。尽管分析技术看似占主导地位，但化学、生物学、物理学和工程学的许多其他领域，包括聚合物化学、动力学研究、成像方法、生物降解研究、测年方法、计算机建模、金相学和腐蚀工程，在保护科学中也发挥着积极作用。

检查方法可分为两类：那些提供整个物体（整体检查）或其某一部分图像的；以及那些在物体上某一点进行分析的，无论是否取样。不需要取样的非破坏性方法总是更可取。然而，现代分析方法可以应用于如此微小的样品，以至于实际上是非破坏性的。在某些情况下，对于原则上非破坏性的方法，由于物体太大无法放入样品室，因此必须取样。分析微量样品的能力引入了一个严重的问题，即样品可能不能代表文物的成分，而是由实验者引入的包裹体或污染物。对于来自涂漆表面的标本，必须特别注意识别修复区域。

另一种担忧来自于信号产生的不同深度。在金属表面上，离子散射光谱学（ISS）将使用初始的纳米分之一部分，主要是吸附的物种和化合物。其次，二次离子质谱（SIMS）将开始穿透氧化区域；俄歇电子能谱（AES）将检查氧化层的本体；而 X 射线光电子能谱（XPS）将提供样品表面下方约 10 nm 处的本体样品数据。参见 活化分析；分析化学；俄歇效应；表面物理；X 射线。

最常用的一种整体方法是 X 射线照相术，其中样品密度和平均原子序数的变化会衰减 X 射线束，在胶片上留下负像。其他方法，如紫外和红外反射和荧光，用于显示成分差异区域，指示修复或艺术家使用的颜料变化。参见 红外成像器件；红外辐射；发光；射线照相术；紫外辐射。

在绘画检查中，在双目显微镜下取出小样品，嵌入透明树脂中，并抛光以产生用于显微镜检查的横截面。这允许研究艺术家的绘画技术，并展示多层如何叠加以达到预期效果。关于成分和技术的保护研究涵盖了现代化学分析的全谱系。参见 化学显微镜；图像处理；显微镜。

将赝品与真品区分开来是文物技术检查中一个虽小但往往具有戏剧性的方面。在某些情况下，可以直接进行断代（面板画的树木年轮学，铀玻璃的径迹测年法，有机材料的放射性碳测年法，陶瓷的热释光测年法）。参见 考古编年学；测年方法；树木年轮学；径迹测年法；放射性碳测年法。

更常见的是，真实性问题在于，当将相关文物与公认的同期文物进行比较时，其成分或技术中存在时代错误。因此，保护实验室的大部分工作有助于建立成分分析、微量元素分布和技术研究的数据库。

许多文物对博物馆大气中的破坏性因素敏感。相对湿度的快速变化会导致木制家具、多色雕塑和绘画的尺寸变化，导致木材开裂和分裂，并丢失表面装饰画。高相对湿度会导致书籍和版画上长霉和出现斑渍，而低相对湿度会使照片和电影胶片变脆。

博物馆中经常观察到铁制品氧化、银器变黑以及木制展示柜释放的甲酸和乙酸导致铅制品腐蚀堆积。

常见的空气污染物二氧化硫（`SO2`）和臭氧（`O3`）在博物馆、图书馆和档案馆中被监测到高水平。这些污染物会导致皮革退化、照片斑点以及颜料褪色。使用化学分析方法鉴定降解产物并研究降解机制的动力学。分析污染控制专家使用分析仪器测量博物馆中的环境污染水平。

# 动脉粥样硬化

这是一种动脉退行性疾病的名称，其特征是血管壁增厚和变硬。该组包括三种类型的病变：

- 动脉粥样硬化涉及主动脉及其主要分支；
- 中层硬化涉及腿部肌肉动脉；
- 小动脉硬化涉及动脉树的小分支，称为小动脉。

动脉粥样硬化是动脉粥样硬化中最常见和最重要的形式，这两个术语经常互换使用。动脉粥样硬化在全球范围内分布，在西方工业化国家中几乎都以流行病学的比例发生。与动脉粥样硬化（动脉粥样硬化的解剖病变）高发率和严重程度相关的因素包括高总热量摄入、高脂肪摄入、久坐不动的生活方式、好斗的人格、情绪压力以及吸烟。高血压（高血压）并不会诱导动脉粥样硬化，但如果存在，它会加剧其发展并加速疾病进程。吸烟者心肌梗死（心脏病发作）发病率高的事实已被明确记录。高血脂水平，特别是胆固醇和甘油三酯，也与高发病率有关。因此，强烈推测环境因素和营养因素在该疾病的发展中具有主要的病因学重要性，尽管具体原因尚未确定。参见 心脏疾病；高血压。

粥样斑块开始于主动脉（内膜）或其分支的内衬层，随后扩展到这些血管的中层。基本病变已被证明是这些层平滑肌细胞的局灶性过度生长，可能继发于黏液瘤。细胞随后退化，产生细胞质中脂质的积聚，然后是坏死，最后是钙化和空洞。随着这些病变在内膜中扩大，覆盖其上的内皮细胞可能会受损，纤维蛋白血凝块沉积在表面。血管腔的直径（狭窄）既被粥样斑块也被覆盖的血凝块所减小。连续层血凝块和扩大的发生

# 自流井水系统

由含水层岩石（含水层）形成的地下水条件，其中的水在上下方均被不透水层封闭。由于自流系统的集水区含水层水位高于其自流区含水层的顶部，因此水具有足够的静压头，使其能够在井中上升至含水层顶部以上。许多系统的静压头足够大，至少在地表相对较低的地区，会导致水溢出到地表。在灌溉井泵站发展的早期阶段，涌泉自流井至关重要，因为无需抽水。随着许多自流系统中静压头的下降以及高效泵和廉价动力的发展（用于操作这些泵），它们的重要性已经减弱。[A.N.S.R.K.L]

# 关节炎

一组影响关节或其组织成分的疾病的总称。已识别出几种类型的关节炎，并根据其临床病程和病理表现将其分为几组。有四种基本类型的关节炎：炎症性关节炎、退行性关节病、非关节性风湿病和混合性关节炎。
