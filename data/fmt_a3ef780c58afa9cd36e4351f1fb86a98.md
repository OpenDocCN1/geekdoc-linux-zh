## diff3

`diff` 命令比较两个文件。如果你想同时比较三个文件，请使用 `diff3` 命令。
`diff3` 命令将输出写入标准输出，其中包含以下标识差异的符号：

- `====` 表示三个文件都不同。
- `====1` 表示第一个文件不同。
- `====2` 表示第二个文件不同。
- `====3` 表示第三个文件不同。

以下是用于 `diff3` 的标志列表：

- `-3`: 为三个文件生成输出。
- `-u`: 以统一格式生成输出。
- `-y`: 以并排格式生成输出。

三个文件的 `diff3` 示例：

```
diff3 file1 file2 file3
```

这是第十一行

```
diff3 -e file1 file2 file3
```

9

```

diff3 -x file1 file2 file3

## dircmp

如果你想比较两个目录的内容，请使用 `dircmp`。该命令比较每个目录中文件的名称，并生成一个仅存在于其中一个目录的文件名列表，随后是存在于两个目录中且相同或不相同的文件名。以下是可以与 `dircmp` 命令使用的列表：

- `-d` 生成一个存在于任意一个目录中的文件列表，随后是存在于两个目录中的文件列表以及它们是否相同。随后是对不同文件对执行 `diff` 命令的输出。
- `-s` 生成一个存在于任意一个目录中的文件列表，随后是不同的文件列表。

示例：让我们假设在当前目录下有两个目录 `testdir1` 和 `testdir2`。这些目录中的文件列表如下：

```
ls testdir1
file1 2 3 4 5 6
ls testdir2
file2 3 5 6 7 8
```

如果你想对这两个目录进行普通 `diff` 比较，请执行以下命令：

```
diff testdir1 testdir2
```

上述的第一部分显示了左侧仅存在于 `testdir1`、右侧仅存在于 `testdir2` 的文件。第二部分显示了目录的比较，并显示了哪些文件是相同的哪些是不同的。如果你想获取有关这些目录文件中差异的更多信息，请在后续命令中使用 `-d` 标志：

```
diff -d testdir1 testdir2
```

如果你只需要每个目录特有的文件以及不同文件的列表，请在后续命令中使用 `-s` 标志：

```
diffmp -s testdir1 testdir2
```

如果你想抑制相同文件的显示，但又想要不同文件的列表以及这些文件之间的差异，请同时使用 `-s` 和 `-d` 标志执行 `diffcmp` 命令。

## sdiff

`sdiff` 命令比较两个文件并在并列格式的标准输出上显示结果。以下是 `diff` 格式的详细说明：

- 如果两行相同，则显示两个文件的每一行，它们之间有一系列空格
- 如果行仅存在于第一个文件中，则在行尾显示一个 `<`（小于号）
- 如果行仅存在于第二个文件中，则在行首显示一个 `>`（大于号）
- 如果两行不同，则在两行之间显示一个 `|`（竖线）

`sdiff` 命令可以使用的标志如下：

- `-s` 如果你不想显示相同的行
- `-w number` 将显示宽度设置为 `number`
- `-1` 如果两行相同，则只显示来自第一个文件的行
- `-0 file` 根据你可以指定的若干子命令从第一个文件和第二个文件创建一个合并文件

**示例** 让我们假设我们有两个文件 `file1` 和 `file2`，其内容使用 `more` 显示如下：

```
more file1

这是第二行
这是第三行
这是第四行
这是第五行
这是第六行
这是第七行
这是第八行
这是第九行
```

```
more file2
这是第一行
这是第二行
这是第三行
这是第四行
这是第五行
这是第六行
这是第七行
这是第八行
这是第九行
```

权限的值可以从 0（无读、写、执行权限）到 7（读、写、执行权限）。

例如，如果你想提供读取和写入权限但没有执行权限，那么使用的值应该是：

```
(4 * 1) + (2 * 1) + (1 * 0) = 6
```

你应该意识到，目录的执行权限意味着可以访问该目录。也就是说，可以对目录中的文件进行操作。如果你对目录提供了写权限，用户将能够读取、写入、删除和执行该目录中的所有文件，而无论单个文件的权限如何。

通过 `chmod` 命令，你可以指定想要对文件或目录设置的新权限。新权限可以通过以下方式之一指定：

- 作为三位数字八进制代码
- 符号模式

示例：如果你想让 `testfile` 拥有以下权限：所有者具有读、写、执行权限；组仅读取权限；其他人仅执行权限，你必须执行以下命令：

```
chmod 741 testfile
```

使用符号模式时，需要指定以下内容：

- 你想要更改谁的（所有者、组或其他人）权限。
- 你想要对权限执行什么操作（`+` 添加、`-` 减去或 `=` 等于）。
- 权限类型（`r`, `w`, `x` 等）。

如果你想为当前目录下由你拥有的 `testfile` 设置权限，使得只有你和你组的用户可以读取和写入该文件，请使用绝对权限执行以下命令：

```
chmod 660 testfile
```

如果你想为当前目录下的 `testfile` 组添加写权限（假设 `testfile` 目前具有 741 权限），请执行以下命令：

```
chmod g+w testfile
```

同样，如果你想撤销当前目录下 `testfile` 对其他人的权限，请执行以下命令：

```
chmod o-r testfile
```

如果你想让当前目录下 `testfile` 的世界（其他人）与组相同的权限，请执行以下命令：

```
chmod o=g testfile
```

> 注意：修改权限对 `root` 用户没有任何影响。`root` 用户可以访问所有文件和目录，无论你可能授予了什么权限。

## chgrp

如果你想更改文件所属的组，请使用 `chgrp` 命令。该组必须是所有者所属的组之一。也就是说，该组必须是所有者的主组或次要组之一。

示例：假设 `testuser` 拥有 `testfile`，文件的组为 `staff`。同样假设 `testuser` 属于 `staff` 和 `dev` 组。要将 `testfile` 的组从 `staff` 更改为 `dev`，执行以下命令：

```
chgrp dev testfile
```

## chown

如果你想更改文件或目录的所有者，请使用 `chown` 命令。

> 注意：在具有磁盘配额的 UNIX 系统上，只有 `root` 用户可以更改文件或目录的所有者。

示例：如果 `testfile` 属于用户 `testuser`，要将文件所有权更改为 `friend`，你必须执行以下命令：

```
chown friend testfile
```

## rm

一旦你使用了一个文件并且不再需要使用它，你就想要删除该文件以恢复文件占用的空间。`rm` 命令允许你通过从磁盘上永久删除文件来实现这一点。如果一个条目是文件的最后一个链接，它将被删除。要从目录中删除文件，你不需要对文件具有读或写权限，但你需要对包含文件的目录具有写权限。`rm` 通常用于删除文件，但它提供了一个特殊标志 `-r` 用于递归删除目录中的文件，包括目录本身及其子目录。

以下是可以与 `rm` 命令一起使用的标志列表：

- `i`：交互式地删除文件。
- `f`：在不带任何消息的情况下删除文件。当文件不存在或你没有权限删除一个或多个文件时，这不会生成任何消息。
- `-r`：递归删除目录内的文件和目录本身。

`rm` 命令的原始版本在删除文件时不会询问确认。因此，在使用 `rm` 命令配合通配符时要小心。

**示例** 如果你想删除当前目录下所有包含 `test` 字符串的文件，请执行以下命令：

```
rm test*
```

然而，如果你操作错误并输入了以下内容：

```
rm test *
```

由于星号（`*`），你将删除所有文件。

> 注意：在使用 `rm` 命令配合通配符时要小心。在删除文件之前请务必确认，因为文件一旦被删除，就无法恢复。

为了避免任何错误，使用 `-i` 标志表示你想在交互模式下执行 `rm` 命令。在这种模式下，系统会在删除文件之前询问你进行确认。只有当你用 `y` 确认时，系统才会删除文件。如果你想使用 `rm` 命令的 `-i` 标志删除当前目录下的两个文件 `testfile` 和 `testfile2`，你将得到如下系统对话框：

```

Remove file testfile? y

## cat

你已经看到 `cp` 命令允许将一个文件复制到另一个文件中。但是，它不允许你使用 `cat` 命令将多个文件合并到一个文件中。默认情况下，`cat` 命令将输出生成到标准输出并接受标准输入的输入。`cat` 命令接受一个或多个文件名作为参数。文件按照它们在参数列表中顺序进行合并。

以下是可以与 `cat` 命令一起使用的标志列表：

- `-b`：与 `-n` 标志配合使用时消除空行的行号。
- `-e`：在每行末尾显示 `$`（美元符号），由 `-v` 标志指定。
- `-n`：在输出行前显示数字，从 1 开始顺序编号。
- `-q`：如果 `cat` 命令找不到一个或多个输入文件，则抑制信息。
- `-v`：将文件中的不可打印字符显示为打印字符。

注意：如果你使用输出重定向操作符 `>` 来重定向 `cat` 命令的标准输出，请注意不要将其中一个文件名作为输出文件名。如果你这样做，输入文件名将被覆盖。某些 Unix 版本在你尝试这样做时可能会给你一个错误信息，但仍会覆盖文件。

在接受来自标准输入的输入时，你应该使用 `Ctrl-d` 表示输入结束。

示例：在最简单的形式下，你只需要输入命令 `cat`，此时你应该进入输入模式。在这种模式下，你可以输入多行，然后按 `Ctrl-d` 信号结束。`cat` 命令将显示你刚刚输入的行：

```
cat
This is test line 1
This is test line 1
This is test line 2
This is test line 2
Ctrl d
```

你应该意识到在上述情况下 `cat` 命令不提供任何提示。

如果你想在终端上显示当前目录下的文件 `testfile`，请执行以下命令：

```
cat testfile
```

这将产生如下输出：

```
This is a test file
This does not contain anything meaningful
This is for demo only
```

如果文件很大，你应该要小心。大文件将在你的终端上快速滚动，你只能看到最后几行。你可以通过如下所示将此输出通过管道到 `more` 或 `pg` 命令来解决这个问题：

```
cat testfile | more
```

要合并多个文件以便在终端上显示，请使用以下命令：

```
cat testfile1 testfile2 testfile3
```

如果你想将这些文件合并到一个文件 `testfile` 中，请使用重定向操作符 `>`：

```
cat testfile1 testfile2 testfile2 > testfile
```

如果文件 `testfile` 已存在，它将被合并后的 `testfile1,testfile2` 覆盖。如果你想在现有文件的末尾合并，而不是使用重定向操作符，你必须使用 `>>`（两个大于号）操作符：

```
cat testfile1 testfile2 >> testfile
```
