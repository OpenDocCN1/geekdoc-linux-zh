
```c
struct license {

  char name[128];

  char address[3][128];

  int zipcode;

  int height, weight, month, day, year;

  char license_letter;

  int license_number;

};

struct license licensee;

struct license *user;
```

由于加州驾执照号码由一个字符后跟七位数字组成，因此执照 ID 被分为两个部分。同样，`newlicensee` 的地址被分为三行，由三个 128 字符的数组表示。

访问结构体的单个字段需要两种不同的技术。要读取局部定义结构的成员，你需要在变量后添加一个点，然后是字段名，如示例所示：

`newlicensee.zipcode = 94404;`

要使用指向结构的指针，需要使用 `->` 来指向成员：

`user->zipcode = 94404;`

这里有一个有趣的点：如果结构体指针增加，地址增加的数值不是 `1`，而是结构体的大小。

使用函数是分组语句并给它们命名的简单方法。它们通常是执行重复性任务（如 I/O）的关联语句。之前描述过的 `printf` 就是一个函数。它由标准 C 库提供。列表 6.4 阐了一个函数定义、函数调用和函数体。
