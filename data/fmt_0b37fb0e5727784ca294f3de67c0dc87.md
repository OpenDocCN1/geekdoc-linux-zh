
# 10.14 脏页限流

在回写过程中，确保系统不会被回写请求淹没到导致不稳定的程度是非常关键的。在这种情况下，系统可能会变得不稳定，因为交换分区等关键函数会被阻塞，导致计算机完全无法正常运行。此外，当脏页数量达到使得页缓存与磁盘状态严重不一致的程度时，如果回写不能快速解决问题，将极大地增加数据损坏的风险。

在通常情况下，不应用任何限制，页可以被标记为脏并按正常方式回写。一旦脏页达到一定程度，内核必须采取措施来缓解这种场景。缓解这一状况的主要手段是通过 `vm.dirty_background_ratio`（或者使用 `vm.dirty_background_bytes`）和 `vm.dirty_ratio`（或者 `vm.dirty_bytes`）可调参数实现的。

这些参数指定了系统累积脏页的最大程度，比例值表示为可用“脏”内存（即可能被标记为脏的内存）的比例，在内核采取某些行动之前：

- **后台脏页限制** `vm.dirty_background_ratio`（或 `vm.dirty_background_bytes`）决定了内核何时通过启动回写来解决页缓存与磁盘状态严重不一致的问题。顾名思义，这在后台进行，利用了第 10.11 节描述的文件系统回写。默认值 `vm.dirty_background_ratio` 等于脏内存的 10%。
- **前台脏页限制** `vm.dirty_ratio`（或 `vm.dirty_bytes`）规定了一个硬限制，当进程在标记脏页而不进行回写的情况下回写到块设备时，该限制可以确保脏页比例再次下降到此阈值以下。默认值 `vm.dirty_ratio` 等于脏内存的 20%。

然而，这并不是全貌。在这两个限制之间，确保我们根据每个块设备使用的带宽水平来限制脏页的标记是非常重要的，采取主动措施以避免全局达到硬性限制的最坏情况发生。同样重要的是，所有由于脏页限流实际发生的回写都是通过后台回写执行的，我们通过简单地“暂停”需要的进程来保持脏页处于可接受的速率。激活后台回写并阻塞进程以管理回写的整个过程就是脏页限流。

我们将详细检查其工作原理，在此之前，我们将先检查上述可调参数的比例版本是相对于什么基准的。这被称为全局（即全系统范围）脏页计数。这由 `global_dirtyable_memory()` 函数决定，如列表 10-108 所示（省略了 32 位系统高内存的范围）。

```c
/**

 * Return: 全局页数
 */
```

## 尽早地节流线程

与其仅在达到脏阈值时让线程休眠，我们在达到该限制之前就开始这样做，以避免不必要的长时间停顿。

## 进入作用域设计

在脏操作发生的范围内指定两个不同的“作用域”：一个自由运行范围，在此范围内没有任何脏线程会被休眠；以及一个全局脏控制范围，在该范围内线程将被休眠适当的时间，直到达到脏阈值。

## 跟踪回写带宽

为了告知线程暂停的程度，我们记录了每个 `struct bdi_writeback` 的带宽，即在 `struct bdi_writeback->avg_bandwidth` 中平均每秒回写的页数。

## 根据脏速率缩放线程

线程对脏页数量的贡献程度等于自上次暂停以来产生的脏页数，因此我们使用此指标来对每个线程的节流进行缩放。

## 跟踪每个线程的脏速率

为了进行这种缩放，跟踪每个线程弄脏了多少页至关重要。这是通过 `struct task_struct->nr_dirtied` 完成的，它记录了自上次 `balance_dirty_pages()`（我们在列表 10-97 中检查了该函数）在 `struct task_struct->dirtied_when` 检查以来产生的脏页数。

## 建立基于块设备的线程脏速率限制

每个线程被限制在等于回写带宽的脏速率上。我们无法确定任何时刻有多少个线程正在回写（这可能会有巨大差异），但我们可以推断出来。确定的脏速率存储在 `struct bdi_writeback->dirty_ratelimit` 中。

## 建立全局脏页的理想设定点

我们希望在导致线程过度睡眠和达到脏阈值之间取得平衡，因此将这两者之间的中点设置为全局脏页的设定点，我们在脏速率执行回写带宽期间旨在维持该值。

## 平滑调整脏速率以维持设定点

“平滑”处理我们暂停线程的程度至关重要，我们通过平滑化调整 `struct bdi_writeback->dirty_ratelimit` 的速率来实现这一点。我们通过位置系数对每个线程的脏速率进行缩放来实现，该系数范围从 0 到 2，经过调整最终将收敛于值 1，此时脏页数量将等于设定点。

## 根据与脏速率的距离缩放线程

一旦我们建立了平滑的每个线程每个块的脏速率，我们就可以利用它来缩放暂停时间，让每个线程暂停较短或较长的时间，使得脏速率向设定点移动。

## 维护最小和最大线程暂停时间

为了避免暂停对脏速率产生没有实质性影响，或因时间过长导致线程变得无响应，使用 `wb_min_pause()` 和 `wb_max_pause()` 维护最小和最大暂停时间（上限为 `MAX_PAUSE`，硬编码为 200ms）。

从自由运行到全局脏控制范围的转换点由 `dirty_freerun_ceiling()` 决定，我们在列表 10-80 中检查了该函数，它被确定为背景阈值和脏阈值之间。

```c
static unsigned long dirty_freerun_ceiling(unsigned long thresh,
                                           unsigned long bg_thresh)
{
    return (thresh + bg_thresh) / 2;
}
```

## 速率限制脏节流

执行这种平衡操作相对昂贵，即使结果没有采取任何操作；在执行此平衡的同时，我们还对操作本身进行速率限制。我们在 `balance_dirty_pages_ratelimit()` 中观察到这一点，我们在列表 10-81 中检查了该函数。

```c
/**
 * balance_dirty_pages_ratelimit - 平衡脏内存状态。
 * @mapping: 被弄脏的地址空间。
 * @flags: BDP 标志。
 *
 * 正在弄脏内存的进程应对每个新弄脏的页
 * 调用此函数。该函数会定期检查系统的
 * 脏状态并在需要时启动回写。
 * 返回: 如果 @flags 包含 BDP_ASYNC，它可能返回 -EAGAIN
 * 以明内存失平衡，调用者必须等待
 * I/O 完成。否则，它将返回 0 表示
 * 内存已经平衡，或者它可以睡眠
 * 直到脏内存回到平衡状态。
 */
int balance_dirty_pages_ratelimit(struct address_space *mapping,
                                  unsigned int flags)
{
    struct inode *inode = mapping->mapping_inode;
    struct backing_dev_info *bdi = inode_to_bdi(inode);
    struct bdi_writeback *wb = NULL;
    int ratelimit;
    int ret = 0;
    int *p;

    if (!(bdi->capabilities & BDI_CAP_WRITEBACK)) {
        if (write_enabled(inode)) {
            wb = wb_get_create(bdi, GFP_KERNEL);
            if (!wb) {
                wb = &bdi->wb;
            }
            ratelimit = current->nr_dirtied_pause;
            if (wb->dirty_exceeded) {
                ratelimit = min(ratelimit, 32 << PAGE_SHIFT);
            }
        }
        return ret;
    }

    preempt_disable(); /* 防止一个 CPU 在不调用
     * balance_dirty_pages() 的情况下积累太多脏页，这可能发生在
     * 任务在同一时间弄脏页时，导致巨大的 task-dirtied_pause。 */
    p = cpu_ptr(&ratelimit);
    if (unlikely(current->nr_dirtied >= ratelimit)) {
        *p = 0;
    } else if (unlikely(*p >= ratelimit)) {
        *p = 0;
        ratelimit = 0;
    }

    /* 获取退出的任务的脏页。这避免了
     * 短寿命任务（例如多次调用）逃避了
     * 长运行任务的脏节流 */
    p = cpu_ptr(&dirty_throttle_leaks);
    if (*p > 0 && current->nr_dirtied < ratelimit) {
        unsigned long nr_pages_dirtied;
        nr_pages_dirtied = min(*p, ratelimit - current->nr_dirtied);
        *p -= nr_pages_dirtied;
        current->nr_dirtied += nr_pages_dirtied;
    }

    preempt_enable();

    if (unlikely(current->nr_dirtied >= ratelimit)) {
        ret = balance_dirty_pages(wb, current, flags);
    }

    wb_put(wb);
    return ret;
}
```
