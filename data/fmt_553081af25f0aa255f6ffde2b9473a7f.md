# 正则表达式

`awk` 命令使用扩展正则表达式表示（参见 `regex(5)`），但它允许使用 C 语言约定来转义 ERE 中的特殊字符，即 `\a`、`\b`、`\f`、`\n`、`\t`、`\v` 以及表中指定的字符。这些转义序列在括号表达式内外均可识别。

> 注意 — 你不需要用换行符分隔记录，字符串常量可以包含换行符，因此 `\n` 序列在 `awk` ERE 中是有效的。在正则表达式中使用斜杠字符需要如表表所示进行转义。

| 转义序列 | 描述 | 含义 |
|---|---|---|
| \" | 反斜杠引号。 | 引号。 |
| / | | 斜杠字符。 |
| \ddd | 一个反斜杠后跟最长的一位、两位或三位八进制数字序列 (01234567)。如果所有数字均为 0 (空字符)，则行为未定义。 | 由一位、两位或三位八进制整数编码的字符。多字节字符需要多个连接的序列，包括每个字节前面的 \。 |
| \c | 一个反斜杠后跟任何未在此表中描述的字符或特殊字符 `\`、`\a`、`\b`、`\f`、`\n`、`\r`、`\t`、`\v`。 | 未定义。 |

正则表达式可以使用两个匹配运算符 `~` 和 `!=` 来匹配特定字段或字符串。这些运算符将右操作数解释为正则表达式，将左操作数解释为字符串。如果正则表达式匹配字符串，则表达式求值为 1，而 `!=` 表达式求值为 0。如果正则表达式不匹配字符串，`~` 表达式求值为 0，而 `!=` 表达式求值为 1。如果右操作数是词法标记 `E` 以外的任何表达式，则该表达式的字符串值被解释为扩展正则表达式，包括上述的转义约定。注意，这些转义约定也应用于确定字符串字面量的值（词法标记 `STRING`），并且在此语境下使用字符串字面量时会应用第二次。
