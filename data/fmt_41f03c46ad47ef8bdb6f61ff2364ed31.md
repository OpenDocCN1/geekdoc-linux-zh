
为了运行我们安装的程序，我们可以从启动栏（dash）中搜索它们，也可以直接在终端中输入包名。输入`chromium-browser`启动它与双击其图标完全相同。某些程序必须通过在命令行输入包名来启动，因为这些包不会出现在启动栏搜索中。总的来说，利用终端可以节省时间，并且是远离缓慢且复杂的图形用户界面的绝佳方法。

软件包的安装和管理是 Linux 的一项特性，它变得非常有用——掌握它能提升你的体验。安装包的第三种方法是涉及从互联网下载并运行`.deb`文件。某些软件是以这种格式打包的，它们的作用类似于`.exe`文件，只需要双击即可开始安装过程。

## 更多终端命令

这里有几个你应该熟记并应用到系统中的更多基础终端命令。完全理解基础知识将为你后续的构建奠下坚实的基础。

- `cp` – `cp image1.jpg image2.jpg` – 将第一个参数复制（并重命名）到提供的第二个参数。使用`-r`选项复制目录。
- `mv` – `mv cat.jpg /home/Pictures` – 将指定的文件移动到指定的目录。
- `shutdown` – `shutdown -h now` – 关闭电脑。`-h`是一个表示“停止(halt)”的标签，但你也可以使用`-r`重启。`now`指执行所需的时间。
- `date` – `date` – 显示当前的日期和时间。
- `free` – `free -g` – 显示程序的当前 RAM 使用情况。
- `du` – `du -h` – 显示硬盘空间使用情况。
- `ps` – `ps` – 显示使用 CPU 时间的活动进程。
- `touch` – `touch memo.txt` – 用于在当前目录下创建一个指定名称的新空文件。
- `ifconfig` – `ifconfig` – Linux 等同于`ipconfig`，它显示网络信息。

某些命令带有相关的“标签”或“开关”。这些是以破折号开头的字母。它们的作用各不相同，学习针对什么目的使用哪些开关，最好的方法是查看该命令的帮助手册（manual pages）。查看高级章节以打开手册。

命令行最实用的程序之一`nano`，是一个简单的文本编辑器，可用于编辑文件并快速更改设置或脚本。通过在命令行输入`nano`即可访问它。你可以根据需要输入文件名，然后按`ctrl+x`保存并退出。在保存时，你会提供与其相关的名称和文件扩展；`notes.txt`将创建一个名为“notes”的文本文件。或者，你可以通过输入`nano notes.txt`编辑文件。在示例中，我们在编辑器中打开`notes`并在可编辑状态下显示其内容。

可能非常简单，但它无疑是强大的，并且是快速更改和创建文件的节省时间的利器。

## 连接到 Windows / Mac 计算机

Windows 和 OSX 具有内置的网络功能，如工作组、域、共享等。将 Linux 计算机集成到由 Windows 服务器计算机主导的网络基础设施中相当容易，尽管正确的设置将允许你看到 Windows 共享并加入公司域。

实现相互通信的第一步是安装`samba`包。可以通过软件中心找到它，或者输入`sudo apt-get install samba`来获取并安装必要的软件。

从你的 Ubuntu 机器向其他电脑共享文件涉及创建`samba`。Samba 运行与其他流行的文件共享方法相同的协议，因此从 Ubuntu 机器共享的文件可以很容易在 Windows 上看到。安装`samba`后，使用`sudo nano /etc/samba/smb.conf`开始编辑配置文件。在文件的最底部添加以下几行：

```
[share]
comment = File Share from Ubuntu
path = /srv/samba/share
browsable = yes
guest ok = yes
read only = no
```

现在，创建`path`指定的文件夹（`sudo mkdir -p /srv/samba/share/`）并设置权限（`sudo chown nobody:nogroup /srv/samba/share/`），以便任何人访问内容。在该目录下放置你想共享的文件，然后重启服务（`sudo restart smbd`）使共享生效。最后，登录你的其他电脑并导航到网络共享。在 Windows 中，它们将出现在资源管理器的左侧。如果共享没有自动出现，在路径框中输入 IP（通过`ifconfig`获取 Ubuntu IP）。现在你可以从其他操作系统访问。

你可能还需要在 Ubuntu 计算机上查看文件。首先，打开 Ubuntu 文件管理器。从菜单栏点击“文件”，然后选择“连接服务器”。在弹出的框中输入你想要访问的共享 URL。可以是`ftp://test.com`地址、`http://test.com`地址或共享地址（`smb://share/Folder`）。无需任何额外的硬件或设置，你就可以这种方式查看文件。

最后，加入如 Active Directory 等域允许你的计算机与网络上的其他操作系统交互并完成其他面向业务的任务。无论你是一个小型家庭网络，还是将 Linux 计算机加入公司域，过程都是相同的。安装一些额外的包（`realmd`, `sssd`, `sssd-tools`, `samba-common`, `samba-common-bin`, `samba-libs`, `krb5-user`, `adcli`, `packagekit`）。在安装它们时，它会询问你的域名。使用全大写字母。输入`kinit -V adminname`替换为实际的管理员账户名称。输入密码后，你已通过域的身份验证。现在可以使用`realm --verbose join -U adminname domainname.loc`加入。

如果失败，意味着你设备上的 DNS 配置错误。输入`echo 'ad_hostname = nix01.domainname.loc' /etc/sssd/sssd.conf`，然后输入`echo 'rdndns_update = True' >> /etc/sssd/sssd.conf`，最后使用`service sssd restart`使用新设置重启。第一行设置了我们计算机的 FQDN，因此该行需要根据我们的域设置进行更改。在使用正确配置设置重启后，终端将声称已加入域。通过`realm list`进行测试。现在连接到 AD 后，你可以从服务器管理 Linux 设备！

如果你正在寻找某种形式的“控制面板”，你可以在“系统设置”（System Settings）应用程序中找到网络、打印、键盘、外观等其他管理工具的快捷方式。某些 Ubuntu 变体使用“设置管理器”或直接称为“设置”来实现相同的目的。

启动后，将会有指向其他默认配置程序的链接；只需点击你需要的程序，即可通过图形界面（GUI）对选项进行设置。但并非所有的管理操作都能通过 GUI 找到。大多数低级设置只能通过命令行进行，因此，你需要确切知道要输入什么来编辑它们。

例如，在 Ubuntu 中添加新用户需要使用`adduser`命令。通过在命令后加上用户名，终端会提示你输入基本信息和密码。将该新用户设置为管理员可以通过`usermod -aG sudo username`完成。此外，可以使用`deluser`删除用户。这些选项在 GUI 中很难找到，但在终端中几秒钟即可完成。

“任务管理器”或对 Ubuntu 内部运行应用程序的管理也是通过终端完成的。`top`程序在所有发行版中（大部分）都是预安装的，启动它将显示类似于任务管理器的、当前正在运行的所有进程列表。但默认情况下，进程列表会更新并移动，导致可能难以阅读我们所需的数据。按`f`调出排序列表，用方向键导航到`PID`并按`s`设置该选项。现在使用`escape`返回`top`，我们现在可以使用向上页（page-up）和向下页（page-down）滚动列表来查看任务。例如，假设我们在“Pidgin”无响应时关闭它。在列表中找到它（或使用上述过滤命令进行搜索）并记住`PID`（进程 ID）数字。按`q`退出，然后输入`kill 4653`，显然要将数字替换为`PID`。在任何时候你都可以按`h`查看各种操作的键盘快捷键列表。如果`top`难以使用，可以考虑安装`htop`，它是该程序的“人类可读”版本。它实际上显示了整洁的 ASCII 图表，详细列出 CPU、RAM 和其他使用统计数据。使用`F3`搜索程序，然后使用`F9`和回车将其杀死。

对于服务，你可能注意到我们使用`service`命令来更改它们的状态。因此，启动 Web 服务器可以使用`service apache2 start`，通过将`start`替换为`restart`来重启，通过将其替换为`stop`来停止。使用`service --status-all`查找服务列表。服务是守护进程，或持续运行的后台任务。它们可以收集数据、运行蓝牙和 Wi-Fi 等服务，或等待用户交互。

Linux 整体关注安全性，这促进了它在企业和服务器环境中的应用。利用安全协议意味着你比其他操作系统更安全，计算机被入侵的概率更低。当然，这需要良好的安全原则，并且始终在网上保持安全。没有密码的计算机几乎没有受到保护。
