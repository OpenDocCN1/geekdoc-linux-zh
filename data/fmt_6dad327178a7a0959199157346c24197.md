
# 通过 GUI 将 AppImages 设置为可执行文件

在图形界面中将 `AppImage` 设置为可执行文件，打开文件管理器，按下 `CTRL + L` 并导航到文件夹。右键点击 `AppImage` 文件，进入“属性”选项卡，并勾选“允许文件作为程序执行”。

## 示例桌面快捷方式创建

```
[Desktop Entry]
Name=AppImage
Comment=AppImage
Exec=/Applications/appimage
Icon=appimage
Terminal=false
Type=Application
Categories=Utility;
```

`.desktop` 文件中的每个字段都有其用途：`Name` 是应用名称，`Comment` 提供简要描述，`Exec` 指定应用路径，`Icon` 定义应用图标，`Terminal` 指示其是否在终端中运行，`Type` 通常为 `Application`，`Categories` 帮助在菜单中对应用进行分类。此过程有效地将你的 `AppImage` 集成到桌面环境中。

## NVM

访问 `NVM` 官方网站 `https://github.com/nvm-sh/nvm` 了解关于 `NVM` 的所有信息。

在终端中通过 `APT` 安装 `NVM`：

输入以下命令：

```
sudo apt update

curl -o https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash

export NVM_DIR="$HOME/.nvm"

[ - "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh" # 这加载 nvm

[ - "$NVM_DIR/bash_completion" ] && . "$NVM_DIR/bash_completion" # 这加载 nvm bash_completion

sudo reboot
```

### NVM 使用示例

要安装特定版本的 `Node.js` 和 `npm`，只需打开终端并执行命令 `nvm install 16` 即可。要切换到特定版本的 `Node.js` 和 `npm`，在终端中输入 `nvm use 16`。这个简单的过程允许根据项目需求方便地管理和使用不同的 `Node.js` 版本。

# 软件与硬件安全

`Linux Mint` 21.3 增强了软件和硬件的安全性，针对漏洞提供了强有保护。它结合了先进的用户权限管理，确保限制对关键系统文件的访问，并引入了 `SELinux` 用于强制访问控制。开源代码允许广泛的社区及时审查并修补漏洞。此外，系统事件日志对异常活动提供全面的监控，有助于快速响应潜在威胁。`Linux Mint` 的架构从根本上减少了风险，使其成为优先考虑计算机安全的用户的可靠选择。

`UFW`（或不复杂的防火墙）是 `Ubuntu` 管理 `netfilter` 的默认工具，使防火墙配置变得更加简单。它支持 `IPv4` 和 `IPv6`，旨在便于设置基于主机的防火墙。默认情况下，`UFW` 阻塞入站流量而允许出站流量，并提供详细的规则配置选项以适应各种安全需求。它对初学者和高级用户都非常友好，对于喜欢图形界面的用户，通过 `Gufw` 提供 `GUI` 选项。`UFW` 确保了防火墙管理在强效安全性与易用性之间的平衡。

`ClamAV`® 是一款开源杀毒引擎，旨在检测各种恶意威胁，包括病毒、恶意软件和木马。它被广泛用于邮件扫描、Web 扫描和端点安全。凭借多线程守护进程、命令行扫描器和高级数据库更新等功能，它为高性能和多功能性而构建。`ClamAV` 支持多种文件格式，并每天更新多次，以确保对新威胁的强力防范。作为邮件网关扫描软件的标准，其开源特性允许用户访问并贡献其开发，确保其作为数字安全的可靠工具。

`ClamTk` 是 `ClamAV` 杀毒软件的图形化前端，为 `Linux` 桌面设计，提供按需和定时扫描。它由 Dave Mauroni 于 2004 年 2 月启动，从使用 `Tk` 工具包演变为 `Perl` 中的 `GTK`，随着时间的推移改进了其界面和功能。`ClamTk` 支持文件或目录扫描，包含递归扫描和 `PUA`（潜在有害程序）检测等功能，尽管存在误报的可能。它与各种文件管理器集成，以便进行文件扫描，并支持手动和自动病毒定义更新。`ClamTk` 可于许多 `Linux` 发行版的仓库中，也可以通过其网站的 `rpm` 和 `deb` 文件进行安装，采用 `GPL` 和艺术许可协议授权。

`Chrootkit` 是一种用于检测系统是否存在 `rootkit` 的安全工具。它由 Nelson Murilo 和 Klaus Steding-Jessen 开发，检查各种系统二进制文件和网络接口的入侵迹象。可以在 `http://www.chk-rootkit.org/` 免费获取，包含了脚本和编译后的二进制文件，用于审查网络接口是否存在混杂模式、日志文件更改、隐藏进程等。`Chkhrootkit` 支持广泛基于 `Unix` 的系统，并为初学者和专家用户配备了功能，包括手动检查和自动扫描的选项。
