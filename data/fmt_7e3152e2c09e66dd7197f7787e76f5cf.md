
## pkgtrans — 转换包格式

### 概要

`/usr/bin/pkgtrans [-inos] device1 device2 [pkginst...]`

### 描述

`pkgtrans` 命令将可安装的包从一种格式转换为另一种格式。它执行以下转换：

- 文件系统格式到数据流。
- 数据流到文件系统格式。
- 从一种文件系统格式到另一种文件系统格式。

设备规格可以是特殊名称（例如 `/dev/diskette`）或设备别名（例如 `diskettell`）。设备池指示了默认的池目录。源设备和目标设备不能相同。

默认情况下，如果目标设备上已存在包的实例，`pkgtrans` 不翻译该包。使用 `-n` 选项如果已存在任何实例包，则创建一个新实例。使用 `-o` 选项如果已存在该包的实例，则覆盖该实例。如果目标设备是数据流，这两个选项都没有用处。

### 选项

- `-i`
  仅拷贝 `pkginfo(4)` 和 `pkgmap(4)` 文件。

- `-n`
  如果目标设备上已存在该包的任何实例，则创建一个新实例，受 `pkginfo(4)` 文件中 `MAXINST` 变量指定的数量。

- `-o`
  如果目标设备上已存在相同的实例，则覆盖该实例。

- `-s`
  将包作为数据流写入 `device2`，而不是作为文件系统。默认行为是写入文件系统格式或使用支持这两种格式的设备。

### 操作数

`device1`
源设备。此设备上的包（或包）将被翻译并放在 `device2` 上。

`device2`
目标设备。翻译后的包放置在此设备上。

`pkginst` 指定应翻译 `device1` 上的哪些包实例或实例。您可以使用标记 `all` 来表示所有包。您可以使用 `pkginst.*` 表示某个包的所有实例。如果没有定义任何包，提示将显示设备上的所有包并询问要翻译哪些。

星号 (`*`) 是某些 shell 的特殊字符，可以进行转义。在 C shell 中，您必须用单引号 (`''`) 包围 `*` 或在其前面加反斜杠 (`\`)。

### 示例

以下示例翻译了软盘驱动器 `/dev/diskette` 上的所有包并将它们放置在 `/tmp`。

```
castle@ pkgtrans /dev/diskette /tmp all
```

以下示例翻译 `/tmp` 上的 `pkg1` 和 `pkg2`，并将它们的翻译结果（即数据流）放在 `9track1` 输出设备上。

```
castle@ pkgtrans /tmp 9track1 pkg1 pkg2
```

以下示例翻译 `/tmp` 上的 `pkg1` 和 `pkg2`，并将它们以数据流格式放在软盘上。

```
castle@ pkgtrans -s /tmp /dev/diskette pkg1 pkg2
```

### 环境变量

`MAXINST` 变量设置在 `pkginfo(4)` 文件中，声明了实例的数量。

### 退出状态

- `0` 成功完成。
- `1` 发生错误。
