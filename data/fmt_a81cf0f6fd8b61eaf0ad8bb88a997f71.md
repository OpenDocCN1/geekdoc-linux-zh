## UNIX 的演变

UNIX 的演变总结在表 13.1 中，它始于 1965 年的一个研究项目，那是贝尔实验室（AT&T 的研发部门）、通用电气和 MIT（马萨诸塞理工学院）的一项合资项目。

当贝尔实验室于 1969 年退出该项目时，AT&T 管理层决定不再开发任何新的操作系统——但这并没有阻止该项目的两个年轻老兵：Ken Thompson 和 Dennis Ritchie。有人说：

| 年份 | 发布版本 | 特性 |
| :--- | :--- | :--- |
| 1969 | — | Ken Thompson 编写了 UNIX 的第一个版本 |
| 1975 | UNIX V6 | 第一版本在工业界和学术界广泛可用 |
| 1984 | UNIX System V Release 2 | 共享内存，更多命令 |
| 1997 | Single UNIX Specification 2 | 支持实时处理和 64 位处理器 |
| 2001 | Mac OS X 10.0 | 命名为 Cheetah，由 Apple 发布，具有图形界面的 UNIX 内核 |
| 2005 | FreeBSD 6.0 | 多线程文件系统；扩展了对无线技术的支持 |

他们需要一种新的操作系统来支持他们喜爱的电脑游戏。无论他们开发的理由为何，UNIX 已经成为世界上使用最广泛的操作系统之一。

Thompson 和 Ritchie 设计的第一个官方 UNIX 版本目标是“做好一件事”，并运行在一种流行的微型计算机上。不久，UNIX 被广泛采用，成为市场中一个强有力的竞争者。对于第 3 版本，Ritchie 采取了创新的步骤，开发了一门新的编程语言，他将其命名为 C；并编写了一个编译器，使得设计人员编写代码更加容易且快速。

随着 UNIX 声誉和普及度的提高（图 13.2），AT&T 发现陷入了如此艰难的境地。当时，该公司处于法律垄断地位，因此根据美国联邦政府的反垄断法规定禁止出售软件。但只需收取名义费用即可向大学提供操作系统。在 1973 年到 1975 年之间，开发了几个改进版本，其中最受欢迎的是在加州大学伯克利分校编写的版本，即 BSD（Berkeley Software Distribution 的缩写）。随着时间的推移，它在程序员中的流行导致了商业和工业界对 UNIX 的需求。

1991 年，IBM 和惠普公司是建立开放小组（The Open Group）的公司之一，该组织拥有 UNIX 名称的商标。

Thompson 和 Ritchie 的原始哲学得到了极大扩展，其命令现在提供了许多选项和控制。操作系统可以相对容易地适应新情况。从本质上说，早期系统的关键特征被保留了下来，命令的潜力增加以满足新需求。图形用户界面的引入（特别是 Mac OS 版本的 UNIX）使得许多代用户都能轻松使用。

由于存在多种标准导致许多早期问题，行业可以通过建立标准来确保程序从一个系统到另一个系统的可移植性。

## Ken Thompson 和 Dennis Ritchie

Ken Thompson 和 Dennis Ritchie 在 20 世纪 60 年代计算科学研究中心（贝尔实验室的一部分）共同工作时，创建了一个名为 UNIX 的新操作系统的缩小版本。不久后，Ritchie 创建了 C 语言，在用 C 语言重写 UNIX 后，它变成了一个真正可移植的操作系统，因为它可以运行在许多不同的平台上。C 和 UNIX 持续在整个行业中被广泛使用。由于他们的工作，Thompson 和 Ritchie 荣获了许多共同奖项，包括 IEEE 计算机先驱奖（1994 年）、美国国家技术与创新奖（1999 年）以及日本信息奖。
