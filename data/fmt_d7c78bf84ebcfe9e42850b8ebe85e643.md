
在化学中，为了分析或工业目的，从物质中纯化或分离它们。对于具有多样性的产品，分离是其目标，其中分析是确定被分离物质成分或性质的首要任务。

离子化合物采用类似的表示法。在方程式中，正离子在前，负离子在随后。这表示了方程式中存在的金属元素。化合物的方程式有`氯化钠`；`硝酸铵`；`硫酸铵`；`Al2SO4`。

分离时需要考虑的三种方法：(1) 物质回收的完整性，(2) 与相关物质的分离程度，以及(3) 分离的效率。

更复杂的无机化合物以类似的方式表示。正离子由金属或配位化合物置在前，随后是负离子。化合物有 `NH4Cl`（氯化铵）；`[Co(NH3)6]3`（三草酸钴和钾）；`[Fe(CN)4]`；对于无机化合物，如丙烯酸盐，用化合物的方程式表示，水分子的数量用前缀表示。化合物的最后一个符号是 `CuSO·H2O`。

根据各种性质有许多类型的分离方法。方法将利用或分配溶解性、挥活性、吸附和影响，尽管其他方法也被有效利用。最高效率的分离将通过分离的两种物质之间的最大差异获得。

由于存在多种化合物，有机族的标记或表示法变得复杂。存在许多不同类型的有机化合物。有芳香族和脂肪族、饱和、不饱和和环状。符号系统必须区分各种烃类，并将它们与其他化合物区分来。见“化学分离过程”（CHEMISTRY-DISTINATION processes）；醇、酯和酚。见“化学”（CHEMISTRY）；“无机化学”（INORGANIC CHEMISTRY）；“有机化学”（ORGANIC CHEMISTRY）。

## 化学发光

释放足够能量以发射光（紫外、可见光、红外线）且在相同温度和相同样品范围内超过热辐射（黑辐射）的化学反应类型。在 900°F (482°C) 以下，化学发光是一种化学反应。燃烧管的内芯或科曼灯就是例子。参见 EXAMPLES.；

许多化学反应会产生能量。除非能量以热、平移、旋转、振动能量的形式流失，可见发光的过程之一必须在激发态（由原子表示）产生，并通过发射光子发生衰减。化学发光反应如动作 (1) 和 (2) 所示，可以视为光化学反应。

```
A + B → C + D (1)
C* → C + hv (2)
```

光光子的能量，其中 `h` 是普朗克常数，`v`（光频率）取决于 `C` 的基态与第一激发电子态之间的分离，化学发光的光谱通常与发射器的荧光光谱匹配。偶尔会存在额外的步骤，即电子能量从 `C*` 到其他分子的转移，这种转移不一定在反应中。如果任何一种激发态可以被证明化学发光光谱是分子荧光的连续延续，正如 SEE LIGHTUMINESCENCE: PHOTONS 中所示。

只有极高能的或“自由能的”化学反应预计才会产生化学发光。由于这个原因，大多数反应涉及化学发光、氧化和还原过程。这些最高有效的例子是酶介导反应。参见 BIOLUMINESCENCE。

电化学化学发光，也称为电化学发光，是一种通过电化学形成物种的化学反应。电化学反应涉及电化学池中的自由基反应。对于化学发光，激发来自电极过程。荧光通过由试剂混合触发的化学反应被激发到较高能态。在电化学发光中，发光分子是通过工作电极的通过状态形成的。

化学发光强度的测量非常敏感，与光浓度成正比。可以检测低至 10-15 ppb 的浓度，这使得电化学发光非常有用。

该现象的商业应用形成了一种高灵敏技术，用于临床实验室检测生物物质以及 DNA、蛋白质、氨基酸和治疗药物。该技术结合了结合亲和力和检测电化学化学发光的系统。

#### 化学的分支。

化学的各种活动、专业组织和文献存在许多细分。

分析化学涉及混合物中每种成分的位置和量的。分析方法是所有有机化学不可或缺且独立的部分。分析化学对材料的检测、分离和鉴定，以及化合物原子式和分子式的确定，是任何研究的前提；开发在分子尺度上进行这些工作的天平和技术对有机化学至关重要。仪器设备变得日益精密；质谱法是此类方法的一个显著例子，在化学中有广泛的应用。分析化学的一个恒恒目标是开发精度更高的方法和仪器。现在可以检测浓度达到十亿分之一（ppm 级别）的化合物。

物理化学涉及对化学性质及其底层过程的解释。物理化学的经典物理涉及热力学，而量子力学对分子中物质的物理状态提供了更好的描述。实验和技术分析已发展用于研究平衡、行为和动力学。其中一个分支是量子化学，它提供了许多支持。物理化学的方法和仪器，如光谱学、磁共振和衍射，是每个领域不可或缺的一部分。化学物理；物理化学；量子化学。

生物化学关注从植物和动物细胞中发生的化学过程和反应研究活体系统。活组织中的物质包括碳水化合物、脂质、蛋白质、核酸和荷尔蒙，是定义良好的有机物质。水和无机收集物的其结构和行为是生物学的特殊功能。主要领域之一是酶及其有机催化的表征。其他感兴趣的话题包括离子和分子的跨细胞运输、神经递质的靶位点和其他调节机制。生物化学方法跨越内分泌学、免疫学和生物学领域。见生物化学（BIOCHEMISTRY）。
