
要完成此过程，请点击磁盘实用程序窗口工具栏上的“刻录”图标，然后按照提示向你的驱动器中插入一张空白 CD。一旦空白光盘被插入并识别，你就可以从“速度”字旁边的下拉菜单中调整刻录速度。根据你的硬件允许范围选择速度，这取决于你的 Mac 的旧程度，通常为 4X 到 8X。最后，点击同一窗口中的“刻录”按钮，刻录过程将开始。

## 从 Ubuntu 订购安装盘

获取 Ubuntu 桌面 CD 最简单且最稳妥的方法是直接从 Ubuntu 免费订购一张（或多张）；你甚至不需要支付运费或处理费。Ubuntu 不仅会为你这种特定架构的机器发送安装 CD，他们实际上还会为你选择的每种架构（i386 和 AMD64）各发送一张。事实上，你甚至无法选择其中一种；这基本上是一个“全或无”的交易，在这种情况下这并不是什么坏事。当然，这种方法的唯一缺点是时间。通过这种方式获取 CD 可能需要四到六周的时间，所以如果你没有耐心，可能想要选择其他方法。

要从 Ubuntu 订购安装 CD，请访问 `https://shipit.ubuntu.com` 并按照那里的说明操作。这很简单。

## 论坛

当你寻找建议、尝试解决某个特定问题或只是在寻找一些通用技巧时，在线论坛是最好的选择。幸运的是，Ubuntu 有它自己的论坛，由于 Ubuntu 主要是一个面向桌面的 Linux 发行版，你很可能会在那里发现许多新手和对新手友好的帖子，而不是你在某些其他网站上可能看到的硬核极客风格。当然，也有新手友好的论坛，尽管它们不是专门针对 Ubuntu 的，但也应该能为你提供很多帮助的信息。

无论你在哪个论坛发帖，务必提到你正在使用 Ubuntu（如果你忘记了，它是 Feisty Fawn），并且你是 Linux 新手。记住，当你得到你不理解的答案时，务要寻求澄清。同一个发帖者通常会回来为你解释清楚。你应该会在这些大多数网站上感到如归家，尽管你可能会觉得其中一个或多个比其他的更好。

- `http://www.ubuntuforums.org` 官方 Ubuntu 社区论坛。当你遇到困难、有疑问或只是想了解发生了什么时，这里始终是一个很好的起点。

- `http://www.ubuntu.org/forum` 另一个稍小的 Ubuntu 专用论坛。如果你觉得 UbuntuFor.org 的内容太多难以读完，这里是一个很好的去处。

- `http://www.kubuntuforums.net` 一个专门针对 Ubuntu 的论坛，一个基于 KDE 桌面环境的官方 Ubuntu 版本。

- `http://www.justlinux.com` 如果你在上述论坛中没有找到你想要的，可以尝试这个或以下处理通用 Linux 问题的论坛。你一定可以在其中任何一个上找到许多 Ubuntu 用户。
