
`-i` 表示所有作为 `env` 命令一部分设置的变量都将用于指定的命令，并忽略所有当前的变量设置。

示例：如果你想显示当前环境，请使用以下命令：

```
env
```

假设我们有一个名为 `my_job` 的脚本，它会显示变量 `LANG` 的当前设置。

如果你在 `env` 命令执行中执行脚本 `my_job` 而不修改 `LANG` 变量，你将得到以下结果：

```
env PATH=/u/testuer/jobs:$PATH my_job
LANG = C
```

如果你在 `env` 命令中修改了 `LANG` 变量，你将得到以下结果：

```
env LANG=C++ PATH=/u/testuer/jobs:$PATH my_job
LANG = C++
```

如果你使用 `-i` 标志且未在 `env` 命令中修改 `LANG`，则 `my_job` 无法获取该变量，你将得到以下结果：

```
env -i PATH=/u/testuer/jobs:$PATH my_job
LANG =
```

## iostat

`iostat` 命令可获取有关系统 CPU、磁盘和 TTY 的统计信息。在系统最近重启后首次运行 `iostat` 时，`iostat` 提供自那以来的统计数据。之后，`iostat` 提供自上一次执行 `iostat` 命令以来的统计数据。

`iostat` 命令显示以下细节：

- TTY 和 CPU 头部
- TTY 和 CPU 统计详情
- 物理卷头部
- 每个物理卷占一行

以下是 TTY 和 CPU 统计中显示的数据项列表：

- `tin` 显示系统为所有 TTY 读取的字符数。
- `tout` 显示系统为所有 TTY 写入字符数。
- `%user` 显示应用层面的 CPU 利用率百分比。
- `%system` 显示系统层面的 CPU 利用率百分比。
- `%idle` 显示 CPU 等待时的利用百分比（这代表 CPU 的空闲率）。
- `%iowait` 显示 CPU 等待 i/o 请求的空闲百分比。

以下是物理卷利用率显示的数据项列表：

- `%tm_act` 显示物理卷的活动利用百分比。
- `Kbps` 显示每秒传输到或从物理卷的字节数。
- `tps` 显示指向物理卷的物理 i/o 请求数。
- `msps` 显示物理卷每次寻道所需的平均毫秒数。
- `Kb_read` 显示从物理卷读取的字节数。
- `Kb_wrtn` 显示写入到物理卷的字节数。

以下是可以与 `iostat` 命令配合使用的标志列表：

- `-d` 仅显示物理卷利用率报告。此不能与 `-t` 标志配合使用。
- `-t` 仅显示 TTY 和 CPU 利用率报告。此不能与 `-d` 标志配合使用。

示例：如果你只想显示 TTY 和 CPU 利用率，请在以下命令中使用 `-t` 标志：

```
iostat -t
```

| tty: | tin | tout | cpu: | % user | % sys | % idle | % iowait |
|---|---|---|---|---|---|---|---|

| | 0.5 | 78.7 | | 32.6 | 25.2 | 35.7 | 6.4 |

如果你只想获取磁盘的物理卷利用率，请在以下命令中使用 `-d` 标志：

```
iostat -d disk1
Disks: % tm_act Kbps tps Kb_read Kb_wrtn
disk1 6.7 4.3 5.0 2339721 4048758
```

## sar

你可以使用 `sar` 命令报告系统信息。`sar` 命令允许你保存信息并对其进行报告。默认情况下，`sar` 命令生成 CPU 利用率报告，但你可以使用各种标志从收集其他系统活动的信息。

以下是可以与 `sar` 命令配合的一些标志列表：

- `-A` 报告所有系统活动的数据。
- `-a` 报告文件系统访问例程的使用数据。
- `-b` 报告缓冲区活动。
- `-c` 报告系统调用（如 forks、execs 等）。
- `-e` 后面可选跟接 `hh:mm:ss` 格式的时间，用于指定停止数据累积的时间。
- `-f` 从指定文件中提取数据。
- `-i seconds` 从文件中提取最接近指定秒的数据。
- `-k` 报告内核活动。
- `-m` 报告信号量和消息活动。
- `-o file` 将活动保存到指定文件中。
- `-r` 报告分页统计信息。
- `-s` 后面可选接 `hh:mm:ss` 格式的时间，用于指定开始数据累积的时间。
- `-v` 报告进程和 i-node 活动。
- `-y` 报告 TTY 活动。

## vmstat

`vmstat` 命令可获取有关进程、虚拟内存、物理卷和 CPU 活动的信息。该信息包含了 CPU、虚拟内存和物理卷的利用率，用于监控系统负载。

`vmstat` 的首次调用显示自系统启动以来的统计数据，后续调用显示自上次调用以来的统计数据。你可以指定计数和间隔参数来控制生成的数量以及报告之间的间隔。

`vmstat` 显示的细节如下：

- 进程
- 虚拟内存
- 页面
- 故障
- CPU

进程的细节如下：

- `r` 显示处于就绪执行队列的进程数。
- `b` 显示处于等待执行队列的进程数。

内存的细节如下：

- `avm` 显示正在消耗的页面数（来自页空间）。
- `fre` 显示空闲列表中的页面数。

页面的细节如下：

- `re` 显示指定间隔内每秒回收的页面数。
- `pi` 显示指定间隔内从页空间换入的页面。
- `po` 显示指定间隔内交换到页空间的页面数。
- `fr` 显示指定间隔内释放的页面数。
- `sr` 显示指定间隔内检查以判断是否可以释放的页面数。
- `cy` 显示每秒时钟周期数。

故障的细节如下：

- `in` 显示指定间隔内每秒中断数。
- `sy` 显示指定间隔内每秒系统调用数。
- `cs` 显示指定间隔内每秒上下文切换数。

CPU 的细节如下：

- `us` 显示指定间隔内应用层 CPU 利用率百分比。
- `sy` 显示指定间隔内系统层 CPU 利用率百分比。
- `id` 显示指定间隔内无 IO 等时的 CPU 空闲百分比。
- `wa` 显示指定间隔内等待磁盘 i/o 请求的 CPU 空闲百分比。

你可以指定最多四个物理卷名称，以获取这些磁盘中发生的传输次数，在指定的间隔。

以下是可以在 `vmstat` 命令中使用的标志列表：

- `-s` 显示自系统初始化以来的统计数据。

## 处理

UNIX 提供了几个用于处理文件内容的命令。

## cut

你可以使用 `cut` 命令从文件的每一行中提取数据。该命令可以用于包含数据的文件，其中每行包含一个或多个由制表符分隔的字段。

以下是可以在 `cut` 命令中使用的一些标志列表：

- `-ccharacterlist` 指定要从每行中截取的字符列表。
- `-ffieldlist` 指定要从每行中截取的字段列表。你还可以额外指定一个标志 `-dcharacter` 来覆盖解释为字段分隔符的字符。你也可以指定标志 `-s` 来抑制不包含指定分隔符字符的行。

**示例** 假设我们有一个名为 `file1` 的文件，其内容如下：

```
more file1
Misty Ghosh
Saptarsi Guha
Sanjiv Guha
```

在该文件中，字段是由制表符分隔的。

如果你想提取第一个字段，请使用以下命令：

```
cut -f1 file1
Misty
Saptarsi
Sanjiv
```

如果你想截取第 2 到 6 个字符，请使用以下命令：

```
cut -c2-5 file1
isty
apta
anji
```

如果你想截取第一个字段中从第一个字符到第一个 s 字符的所有字符，请使用以下命令：

```
cut -d"s" -f1 file1
Mi
Saptar
Sanjiv Guha
```

你会注意到行被完全截断了。要抑制不包含 s 字符的行，请在以下命令中使用 `-s` 标志：

```
cut -d"s" -s -f1 file1
Mi
Saptar
```

## ex

`ex` 命令调用 `ex` 编辑器来编辑一个或多个文件。

以下是在 `ex` 命令中可以使用的一些标志列表：

- `-c subcommand` 在调用 `ex` 命令之前在指定的文件上执行指定的子命令。
- `-R` 不允许更新文件。
- `-size` 设置窗口行数等于 size。
- `-v` 调用 `vi` 编辑器。
- `-r file` 对指定的文件进行恢复。

一旦你进入了 `ex` 编辑器，你就可以使用以下子命令在文件中移动并编辑文件：

- `-z` 调用全屏模式。
- `-u` 撤销上一次更改。
- `-n` 如果你使用多个文件调用了 `ex` 编辑器，则移动到下一个文件。
- `/pattern/` 在文件中查找匹配模式。
- `-d` 删除一个或多行。
- `-a` 追加。

`ex` 在以下模式下运行：

- 命令模式：编辑器启动时，它处于命令模式，此时有一个 `:`（冒号）提示符，你可以在其中输入子命令。
- 文本输入模式：在此模式下，你可以添加或更改文件文本。你可以使用 `a`、`i` 或 `c` 子命令输入文本。使用这些子命令将允许你在缓冲区中输入文本。你可以通过在文本缓冲区的首字符输入一个 `.`（点）来返回命令模式。

## uniq

`uniq` 命令用于删除文件中相邻的重复行。在使用之前，通常需要对文件进行排序。

以下是可以在 `uniq` 命令中使用的标志列表：

- `-c` 显示重复行的次数。
- `-d` 只显示重复的行。
- `-u` 只显示不重复的行。
- `-i` 忽略大小写。
- `-fn` 跳过前 n 行。

**示例** 假设我们有一个文件 `file1`，其内容如下：

```

more file1

apple

apple

banana

banana

cherry

```

如果你想删除重复行，请使用 `uniq`：

```

uniq file1

```

```输出将是：

```
apple
banana
cherry
```

如果你想显示每行重复的次数，请执行以下命令：

```
uniq -c file1
```

```

2 apple

2 banana

1 cherry

```

如果你只想显示重复的行，请执行以下命令：

```

uniq -d file1

```输出将是：

apple

## paste (合并)

`paste` 命令用于从一个或多个文件（其中一个可以是标准输入）合并行到标准输出，标准输出可以重定向到文件。`paste` 命令将每个输入文件的行连接到输出文件中，并用制表符（默认）将它们分隔。

以下是可与 `paste` 命令配合标志列表：

- `-d` 指定分隔符字符列表，这些字符将用于分隔输出文件中输入文件中对应的行。如果你有多个输入文件，可以指定多个字符。
- `-s` 为每个输入文件合并其随后的行（一次处理一个），并用指定的分隔符字符进行分隔。

**示例** 让我们假设我们有两个文件，`file1` 和 `file2`，其内容所示：

```
more file1
computer1 16MB 1.2GB 17inch CDROM
computer2 8MB 840MB 14inch
computer3 12MB 1.6GB 17inch
computer4 4MB 270MB 14inch
```

```
more file2
computer1 1stfloor office5
computer3 2ndfloor office9A
computer4 1stfloor office2
computer5 3rdloor office1
```

如果你想合并 `file1` 和 `file2`，使用以下命令：

```
paste file1 file2
computer1 16MB 1.2GB 17inch CDROM computer1 1stfloor office5
computer2 8MB 840MB 14inch computer3 2ndfloor office9A
computer3 12MB 1.6GB 17inch computer4 1stfloor office2
computer4 4MB 270MB 14inch computer5 3rdloor office1
```

来自 `file1` 和 `file2` 的行用制表符分隔。
