# 野牛

哺乳纲偶蹄目牛科两个物种的名称，分布于北美和欧洲。欧洲野牛（`Bison bonasus`）通常被称为 wisent（欧洲野牛）。北美物种（`B. bison`），如下图所示，常被称为 buffalo（水牛），但不应与非洲水牛混淆。

欧洲野牛在晚古近纪时期曾广泛分布于西欧的森林地区。wisent 是一种在林地中觅食的动物，通常聚集在较小的群体中。它在自然栖息地几乎灭绝，尽管存在一些牛群，但主要仅存于动物园和野生动物园中保存的数百只个体中。

![](img/2cf7974cd6027baa297e5cd95d3d6d43_308_0.png)

北美野牛（`Bison bison`）。

人们已做出巨大努力，通过人工饲养和在圈养条件下维持该物种来保护它。

尽管存在差异，wisent 与北美物种关系密切。wisent 头较小且位置较高，鬃毛较短，比北美物种更优雅且体型不那么庞大。其肩胛隆起不那么明显，腿更长，角更细长，体毛也不那么蓬松。

巨大的北美野牛群曾在 19 世纪存在于加拿大西部和美国西部的北美大平原地区。据估计，加拿大和美国的保护区和国家公园中仍有约 2,000 只野牛。这些牛科动物体型庞大，雄性长度可达 9 英尺（2.7 米），肩部高度达 6 英尺（1.8 米），重量高达 3,000 磅（1350 公斤）。它们是草食动物，原本在草或饲料稀缺时会迁徙。其巨大的头部位置较低，颈部后方有一个特征性的隆起。前半身毛发蓬乱，雄性的毛发比雌性更显著。嗅觉和听觉发达，但视觉较差。雄性和雌性都有角，角较小且间距较远。参见**偶蹄目、水牛、哺乳纲**。[C.B.C.]

# 比特

二进制位。在计算机、电子和通信领域，“bit”通常被理解为“binary digit”（二进制位）的缩写。在数值二进制系统中，比特是 0 或 1。比特通常用于表示可取两个值或两种状态的情况，例如开和关、真或假、是或否。按惯例，1 代表一种特定状态，则 0 代表另一种状态。例如，如果 1 代表“是”，则 0 代表“否”。参见**布尔代数**。在计算机系统中，比特被视为存储的基本单位，按惯例只能存储 0 或 1。在计算机内存中，连续的比特被分组形成较小或较大的存储“单元”。根据计算机的设计，最高可达 64 比特的单元已被考虑。虽然关于构成字节的比特数量有普遍共识，但对于较大的存储单元，术语完全取决于制造商使用的惯例。在所有这些单元中，最左边的比特通常称为最高有效位（msb），最右边的称为最低有效位（lsb）。

字节和更大的单元用于表示数值量。在这些情况下，最高有效位用于表示被表示数值的“符号”。按惯例，msb 中的 0 代表正数；1 代表负数。根据用于表示这些数字的惯例，其余比特可用于表示数值。除了数值量外，字节还用于在计算机内部表示字符。这些字符包括英文字母表中的所有字母、数字 0 到 9，以及诸如逗号、句号、左右括号、空格和制表符等符号。字符可以使用 ASCII（美国信息互换标准码）或 EBCDIC（扩展二进制编码十进制交换码）进行表示。后者用于某些大型机计算机。计算机被设置只处理这两种字符编码之一。通常，字符在这两种代码中的内部表示是不同的。例如，在 ASCII 中，加号由数值序列 0010111 表示，而在 EBCDIC 中，由 01001110 表示。[R.A.M.T.]

# 沥青

用于指定天然存在或商业获取的深黑色物质的术语，主要由碳和氢组成，含有很少的氧、氮和硫。沥青的硬度和挥发性可变，范围从原油到沥青岩，大多易溶于二硫化碳。参见**沥青**和**沥青岩**。[I.A.B.]

# 双壳纲

软体动物门五个纲之一，有时也称为双叶目。所有双壳类动物都生活在水中，生活在海洋的各个深度以及咸水和淡水中。约有 25,000 个现存物种，双壳纲在软体动物物种多样性方面仅次于腹足纲（超过 74,000 个物种）。然而，双壳类的总生物量要大得多，且某些双壳类物种在许多底栖生态系统中在数量上占主导地位。最原始的双壳类动物是底栖生活的，钻入软沉积物中，但许多科是表面生活的，附着在岩石或贝壳上，或居住在沉积物表面。由于具有钙质外壳，双壳类动物在古生代早期的化石记录中有很好的代表。

一般来说，双壳类动物具有两侧对称性和侧向压缩性。它们有一层分泌贝壳的肉质外套膜

## 软体动物门（续）

包裹着身体（见插图）。双壳类的口位于身体前部；在双壳纲最大的亚纲——瓣鳃纲（Lamellibranchiata）中，口两侧具有一对唇瓣，在摄食前起到筛选食物的作用。感觉器官位于外套膜边缘外侧，此处与外界环境接触最紧密。这些感觉器官通常着生在触手上，对触觉和化学刺激敏感。某些扇贝种类的外套膜触手上具有高度发达的感光器官或“眼睛”。

贝壳由两个壳瓣组成，两个壳瓣通过一个未钙化的韧带（连接韧带）在铰合处连接在一起。贝壳层结构包括：外层角质壳皮（保护层），在某些物种中可能缺失或磨损；中间层为棱状层，由结晶碳酸钙组成；内层为层状层或珍珠质层。在某些科，如贻贝科（Mussels，指贻贝）和扇贝科（Pectinidae，指扇贝或珍珠贝，此处原文可能指珍珠贝科 Pinctadae 或 Ostreidae，但保留 Pectinidae 对应扇贝科，然而扇贝科通常不以珍珠层著称，珍珠贝科才以珍珠层著称，但按照原文翻译，暂译扇贝科）中，珍珠质层可以展现出美丽的虹彩光泽，而在大多数双壳类中，内层光滑但呈粉白色外观。铰合韧带的张力使壳瓣保持在微开状态，壳瓣的闭合则由闭壳肌完成。

具纤毛的软体动物鳃，正确名称为栉鳃（ctenidia），包含在瓣鳃纲（Lamellibranchiata）中，并占据了外套腔的相当大一部分。栉鳃由分层的丝状结构组成，主要功能是将水抽入外套腔，并从入水流中过滤出颗粒状食物。原始鳃纲（Protobranchia）双壳类的栉鳃也起到泵水的作用，但它们比瓣鳃类的栉鳃更小且发育程度较低，且不用于过滤食物颗粒。原始鳃纲双壳类是底质摄食者，它们通过伸出肌肉发达的触手（吻部）到海底沉积物中，捕获有机碎屑颗粒。异形齿纲（Septibranchia，有时称为 Anomalodeonta）双壳类具有高度特化的栉鳃，缺乏丝状结构。中隔将外套腔分为背侧和腹侧腔室，水通过中隔壁肌肉的收缩被泵动。

一些双壳类具有用于运动的足。如果存在，足可以通过血压从壳中伸出，并扩张作为外部锚点，通过缩肌的收缩来实现运动。扇贝科（Pectinidae，扇贝）的一些双壳类没有足，但它们是通过拍打壳瓣和通过铰合部附近的孔口喷水来进行高速游泳的高度活跃游泳者。一些双壳类，如牡蛎和巨型蛤（砗磲），是固着生活的，成体没有足。

双壳类展示了多种繁殖策略。大多数双壳类是雌雄异体的，而另一些则表现出各种形式的雌雄同体。例如，成熟的成年扇贝同时携带卵子和精子，而牡蛎则表现出先雄性后雌性的雌雄同体现象，即牡蛎首先发育为雄性，在随后的几年里改变性别发育出卵巢。

大多数双壳类物种直接将卵和精子排入水中，在那里发生受精；在其他物种中，卵可能保留在育幼室中，在那里由当前水流中的精子受精，并作为发育良好的幼虫释放到水中。大多数双壳类在沉降和变态为底栖形态之前要经历几个浮游阶段。

许多双壳类物种因食用肉或贝壳制品而被积极养殖。世界上大多数宝石级珍珠来自日本、澳大利亚和热带太平洋岛屿养殖的珍珠贝属（`Pinctada`）珍珠贝。淡水珍珠产自美国、中国和日本的淡水贻贝。其他双壳类物种由于是有害生物或生物入侵者而具有经济重要性。
