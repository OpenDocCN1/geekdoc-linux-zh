
在此示例中，`strip`前缀（字段1）为空，因为它尚未实现，所以此规则不适用于`strip`前缀。此规则的第二个字段包含`.Z`后缀，因此它处理已用`compress`工具压缩过的文件。该规则不涉及附加前缀或后缀，所以字段3和字段4为空。字段5（外部命令字段）告诉服务器运行`compress`工具来解压所有具有`.Z`扩展名的文件，正如`-d`参数所指示的那样。`-c`选项告诉`compress`将`compress`工具的输出写入标准输出，在本例中即服务器。`%s`是应用该规则的文件名。字段6指定该文件是ASCII格式的常规文件。字段7（选项字段）告诉服务器此命令解压该文件。最后，最后一个字段是注释，帮助管理员快速解码转换规则的功能——即解压文件。

## 使用`ftphosts`文件允许或拒绝FTP服务器连接

`ftphosts`文件的目的是允许或拒绝特定用户或地址连接到FTP服务器。该文件的格式是单词`allow`或`deny`，后面可选地跟一个用户名，再跟一个IP或DNS地址。

```
allow username address
deny username address
```

### 清单18.3 用于允许或拒绝用户的`ftphosts`配置文件

```
# Example host access file
#
# Everything after a '#' is treated as comment,
# empty lines are ignored
allow tdc 128.0.0.1
allow tdc 192.168.101.*
allow tdc insane penguin.net
allow tdc *.exodus.net
deny anonymous 201.*
deny anonymous *.pilot.net
```

`*`是一个通配符，匹配该地址的任意组合。例如，`allow tdc *.exodus.net`允许用户`tdc`从任何包含域名`exodus.net`的地址登录FTP服务器。类似地，如果匿名用户来自`201`公共C类IP地址，则不允许其访问FTP。

```
# /etc/init.d/inetutils-inetd restart
```

## 使用命令进行服务器管理

`wu-ftpd`提供了一些用于辅助服务器管理的命令。这些命令是：

- `ftpwho`—显示当前FTP服务器用户的信息
- `ftpcount`—按类别显示当前服务器用户的信息
- `ftpshut`—提供自动服务器关闭和用户通知
- `ftprestart`—提供自动服务器重启和关闭消息移除

每个命令都必须以超级用户权限执行，因为它们引用`ftpaccess`配置文件以获取有关FTP服务器的信息。

## 使用`/usr/sbin/ftpshut`安排FTP服务器停机

与任何公共服务器管理一样，让FTP服务器用户了解即将发生的停机、服务器何时更新以及其他相关站点信息始终是良好的做法。`ftpshut`命令允许管理员让FTP服务器自动完成其中大部分工作。

`ftpshut`命令使管理员能够在特定时间根据传递给它的某些参数关闭FTP服务器。命令的格式如下，并在`ftpshut`手册页中有记录：

```
ftpshut [ -V ] [ -l min ] [ -d min ] time [ warning-message ... ]
```

`-V`参数显示命令的版本信息。`time`参数是`ftpshut`命令将停止FTP服务器的时间。此参数采用从当前时间开始的`+`数字表示的分钟数，或采用24小时制格式的特定小时和分钟，语法为`HH:MM`。

`-l`参数使FTP服务器管理员能够指定在关闭前服务器将禁用新连接的时间，单位为分钟。默认值为10分钟。如果给定的关闭时间少于10分钟，新连接将立即被禁用。

`-d`参数与`-l`参数类似，但控制FTP服务器终止当前连接的时间。默认情况下，这发生在服务器关闭前五分钟。如果关闭时间少于五分钟，服务器将立即终止当前连接。
