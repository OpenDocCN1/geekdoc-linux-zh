#### 2.18.2 移除网络接口

如果你有多个以太网`NIC`适配器并且想要移除适配器`eth1`，请遵循以下步骤：

1.  执行命令停止接口：

    ```
    /sbin/ifdown eth1
    ```

2.  执行命令删除`/etc/sysconfig/network-scripts/ifcfg-eth1`文件：

    ```
    rm /etc/sysconfig/network-scripts/ifcfg-eth1
    ```

当你定义了多个适配器时，此过程适用于所有适配器。
