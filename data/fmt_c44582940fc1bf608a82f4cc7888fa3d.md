### 练习 4 答案

```bash
#!/bin/bash
POISK_TEXT="Une certaine phrase"
VVOD_FILE="path/to/input/file.txt"

while read line; do
  if [[ "$line" == *"$POISK_TEXT"* ]]; then
    echo "$line"
  fi
done < "$VVOD_FILE"
```

> 注：“`#!/bin/bash`”行表示解释器（这是大多数 Linux 发行版中的标准 Shell 解释器），将用于执行脚本。

字符串“`#!/bin/bash`”中指定的解释器指的是 shell 编程语言，也称为命令行 Shell。
