### 9.3.3 区分服务 (Differentiated Services)

区分服务基于数据标记。根据各种过滤器进行标记，然后根据行为进行处理。

/*
 * class       标记
 * n/a
 * x:0           使用项 [0]
 * x:y           使用项 [y]
 * indices     
 * indices-1  使用项 [1]
 */

struct dmsark_qdisc_data {
    struct qdisc         *q;
    struct tcf_proto      *filter_list;
    __u8                *mask;
    __u8                *value;
    __u16               indices;
    __u16               default;
};
