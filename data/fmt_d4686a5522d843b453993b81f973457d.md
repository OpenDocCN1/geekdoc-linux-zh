在设置好 `ppp` (`ppp0`) 并连接到你的互联网服务提供商 (ISP) 后，你将拥有另一个网络接口，然后就可以连接世界了。以下是 `IP` 数字含义的总结。`IP` 数字（有时称为“IP 地址”）被分为由点分隔的四组数字。例如，`123.123.123` 是有效数字（所有数字均以十进制显示）。在每组数字中，值范围可以是 0 到 255（8 位）。从点到点的数字组通常被称为“字节”（octet），因为它包含一个“网络号”和一个“主机号”，即网络内的单台计算机。网络可能由一、二或三字节表示。当主机号填充为 0（所有字节）时，结果 `IP` 地址被解释为该网络上的所有主机（被称为“广播地址”）。当网络号填充为 255（所有字节）时，`IP` 地址被解释为网络。

网络分为几类。最重要的是 `A`、`B` 和 `C` 类。
- `A` 类网络：数字在 `0.0.0.0` 到 `127.0.0.0` 之间。网络包含第一个字节。主机包含后三个字节。这种划分产生了 128 个网络，每个网络最多包含 1600 万主机。
- `B` 类网络：数字在 `128.0.0.0` 到 `191.255.0.0` 之间。主机包含后两个字节。这产生了 16384 个网络，每个网络最多包含 65536 个主机。
- `C` 类网络：数字在 `192.0.0.0` 到 `223.255.255.0` 之间。网络包含前三个字节。主机包含最后一个字节。这种划分产生了 200 万个网络，每个网络最多包含 256 个主机。
- `D`、`E` 和 `F` 类：地址范围在 `224.0.0.0` 到 `255.255.255.255` 是实验性的或留供未来使用的。它们不指定任何网络。

私有地址。以下 `IP` 范围留供私用：
- `10.0.0.0-10.255.255.255` (8 位前)
- `172.16.0.0-172.31.255.255` (12 位前)
- `192.168.0.0-192.168.255.255` (16 位前)

从问题上讲，`IP` 地址留给了防火墙后的网络（没有连接到互联网）。有效的 `IP` 地址由 `DNS` 服务器注册和解析。

默认路由。这是一个特殊的 `IP` 地址 `0.0.0.0`。它用于标记流量将去的网络接口。例如，默认路由可以分配给 `eth0`（以太网卡的符号名称）或 `eth1`（第二个以太网卡），或 `ppp0`（第一个点点连接，调制解调器）。

本地主机。这是一个特殊的 `IP` 地址 `127.0.0.1`，用于计算机的本地流量，不涉及任何网络硬件。它通常被称为“环回地址”。计算机可能同时拥有许多 `IP` 地址；因此它通常有一个 `127.0.0.1` 环回地址作为另一个单独分配的 `IP` 地址。

### 5.5.3 配置我的 ppp 拨号的问题

`GUI`。如果我是你，我会安装 `kde` 并使用 `ppp`。它很容易配置和运行。要设置你的 `ppp` 拨号，在“Internet”菜单下运行 `ppp`，或者你可以在 `xterm` 中输入 `ppp` 运行它，将“setup”设置为开启，创建一个账户并填写所需信息：电话号码、验证协议以及你的互联网服务提供商 (ISP) 域名和域名服务器 (`DNS`) 号。所有信息都应该由你的 `ISP` 提供。

接下来，我检查设备 `/dev/modem` 是否存在并指向正确的端口。如有必要，我通过符号链接到 `/dev/ttyS1`（作为 `root`）创建它：

```
ls -l /dev/modem
ls -l /dev/ttyS1 /dev/modem
```

如果你的调制解调器在 COM2 端口，`/dev/ttyS1` 应该可以工作。使用 `/dev/ttyS0` 用于 COM1，`/dev/ttyS2` 用于 COM3，`/dev/ttyS3` 用于 COM4。对于标准的串口设置，请查看手册。如果选择了错误的端口，调制解调器将无法拨号。

对于旧版本，你可能会收到显示“lock”的错误消息。解决方案是通过编辑文件（作为 `root`）确保 `/etc/ppp/options` 文件是空的：`vi /etc/ppp/options` 并删除“lock”一词，保存文件。这个问题在最近的 `ppp` 版本中不存在。

`RedHat 6.0` 需要一个额外的设置：“suid”（替换用户 ID），以便 `ppp` 以有效用户 ID 直接访问硬件。如果没有它，它会抱怨设置不当且无法无法锁文件”。这必须以 `root` 执行：

```
cd /dev
chmod +x *
```

故障排除。如果你的调制解调器在选定的端口拒绝拨号，可能是调制解调器设置不当（或者它是 winmodem）。那么把它扔掉买一个真正的调制解调器。例如，如果你有 `ppp` 设置，启用“调制解调器命令”并将 `ATZ` 作为“初始化字符串”（对于标准的兼容调制解调器使用 `ATZ`）。这种特定的调制解调器在用这种典型字符串“`ATZ`”初始化之前无法拨号。

如果你的电话线使用脉冲拨号（而不是音调拨号），你可能需要将调制解调器拨号命令从“`ATDT`”（注意拨音）更改为“`ATDP`”（注意拨脉冲）。这些命令适用于任何标准的兼容调制解调器。

对于你计算机上的某些硬件组合，可能需要将调制解调器设置在 `/dev/ttyS2` 或 `/dev/ttyS3`（而不是被鼠标占用的 `/dev/ttyS1`），因为中断冲突，例如与网卡冲突。通过设置调制解调器硬件（你的调制解调器上的跳线可能需要移除或重新配置），你需要查看调制解调器手册的规格并将其放置：

```
serial /dev/ttyS1 /dev/ttyS3
```
