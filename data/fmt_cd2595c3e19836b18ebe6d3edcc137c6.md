
`sudo btrfs subvolume snapshot /path/to/source /path/to/snapshot`

该命令在指定路径创建源子卷的快照。快照是只读的，但你可以创建一个快照的读写副本以进行更改。

### ZFS 快照

ZFS 作为一种文件系统和卷管理器，也提供了快照功能。要创建一个 ZFS 快照，请使用 `zfs snapshot` 命令：

```
sudo zfs snapshot pool/dataset@snapshot_name
```

ZFS 快照默认是只读的，但你可以克隆它们来创建可写副本。

### 配额

磁盘配额允许你限制用户或组在文件系统上使用的磁盘空间。此功能对于多用户系统或共享环境至关重要，可以防止用户消耗过多存储空间。

要在 Linux 文件系统上启用配额，你通常需要：

- 1. 确保内核支持并启用了配额。
- 2. 编辑 `/etc/fstab` 文件，为相关文件系统包含 `usquota` 和 `grpquota` 选项。
- 3. 使用 `quotacheck`、`edquota` 和 `quotacheon` 等工具为用户和组设置并管理配额。

### 扩展属性

扩展属性 (xattrs) 与文件和目录相关的元数据，提供了传统权限和所有权之外的信息。它们可以存储各种类型的信息，例如安全标签、文件元数据和用户定义属性。

ext4 和 XFS 等 Linux 文件系统支持扩展属性。你可以使用 `getfattr` 和 `setfattr` 等命令来查看和操作文件及目录的扩展属性。

### 文件系统级加密

文件系统级加密提供了一种在文件系统级别加密数据的方法，确保即使未经授权的用户访问了存储设备，数据仍然保持机密性。`dm-crypt/LUKS` 是一种常用的块级加密解决方案，它可以与各种文件系统结合以实现文件系统级加密。

### 结论

Linux 提供了满足各种需求的高级文件系统功能，从数据保护、安全到存储管理和性能。理解这些功能及其用例可以帮助你在为 Linux 系统选择和配置文件系统时做出明智的决策。无论你需要高效的快照、磁盘配额、扩展属性还是文件系统级加密，Linux 均提供了满足你需求的工具和选项。

## 10.5. 数据恢复技术

数据丢失可能是一次毁灭性的经历，当灾难发生时，拥有正确的数据恢复技术至关重要。在本节中，我们将探索可以帮助你在 Linux 系统上恢复丢失数据的各种方法和工具。

### 1. 定期备份

防止数据丢失的最佳方法是建立定期备份。`rsync`、`tar` 和专门的备份方案等工具可以帮助你创建备份。维护最新的备份并遵循正确的备份策略，可以显著减少数据丢失的影响。

### 2. PhotoRec

PhotoRec 是一种强大且免费的数据恢复软件，可以从广泛的文件系统中恢复丢失的文件。它对于从损坏或格式化的存储设备恢复数据特别有用。PhotoRec 是一个命令行工具，是 TestDisk 包的一部分。

要使用 PhotoRec 恢复数据，你通常运行如下命令：

```
photorec /dev/sdX
```
