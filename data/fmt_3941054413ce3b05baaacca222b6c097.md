# 第 10 章通过 JAVA 提供动态内容

## 10.5.3.3 `web.xml` 文件

`web.xml` 文件是一个 J2EE 标准 XML 文档，用于描述 Java Web 应用的内容。该部署描述符包含了 Java Web 应用的部署和配置信息。`web.xml` 文件的格式和内容在 Java Servlet 规范 2.5 版本中定义。如果存在，`web.xml` 文件必须位于应用程序的 `WEB-INF` 子目录下。Web 应用并不要求包含 `web.xml` 文件。

应用程序 `web.xml` 文件中指定的类型类型包括：

- Servlet 定义和映射
- JSP 配置
- Servlet 过滤器定义和映射
- Session 配置
- 安全配置
- 欢迎文件顺序
- 应用 (`ServletContext`) 初始化参数和生命周期监听器
- 语言和编码映射
- 错误页面声明

有关此部署描述符中每个元素的详细信息，请参阅《Java Servlet 规范 2.5 版本》。

示例 10.7 展示了一个示例 `web.xml` 文件。
