
## 表 8.4：`format` 命令的子命令和子菜单

| 子命令或子菜单 | 描述 |
|---|---|
| `show` | 翻译磁盘地址（仅限 Intel 兼容设备） |
| `label` | 向所选磁盘写入标签 |
| `analyze` | 对所选磁盘进行表面分析（子菜单） |
| `defect` | 显示所选磁盘的缺陷列表（子菜单） |
| `backup` | 搜索备份标签 |
| `verify` | 显示所选磁盘的标签 |
| `save` | 保存新的磁盘/分区定义 |
| `inquiry` | 显示所选磁盘的厂商、型号和修订版本（仅限 SPARC） |
| `volname` | 为所选磁盘定义一个 8 字符的卷名 |
| `!_cmd` | 使用用户的 shell 执行 `cmd`，然后返回 `format` 命令 |
| `Quit` | 退出 `format` 命令 |

当 `format` 命令启动时，它会列出所有可用的磁盘驱动器，你选择其中一个。`format>` 被用作命令提示符。

以下列表显示了启动 `format` 命令的过程：

```bash

Specify disk (enter its number): 0

se c0d0

Controller working list found

[disk formatted, defect list found]

Warning: Current Disk has mounted partitions.

FORMAT MENU:

+   - disk - 选择一个磁盘

type - 选择（定义）磁盘类型

partition - 选择（定义）分区表

current - 描述当前磁盘

format - 格式化并分析磁盘

fdisk - 运行 fdisk 程序

repair - 修复缺陷扇区

show - 翻译磁盘地址

label - 向磁盘写入标签

analyze - 表面分析

defect - 缺陷列表管理

backup - 搜索备份标签

verify - 读取并显示标签

save - 保存新的磁盘/分区定义

volname - 设置 8 字符卷名

!<cmd> - 执行 <cmd>然后返回

format>
```
