
```
> element(1, T1).
   linux
```

如你所见，元组中第一个元素的索引号为`1`。类似地，`setelement()`函数允许你更改现有元组项的值以创建新的元组：

```
> T2 = setelement(1, T1, unix).
   {unix,1}
```

元组非常实用，因为它们让你能够分组数据，并且在Erlang以及其他编程语言中经常被使用。

函数的参数数量被称为函数的`arity`（元数）。模块名（`m`）、函数名（`f`）和元数（`N`）的组合唯一地标识一个函数为`m:f/N`。正如你可能记得的，你必须导出（`export`）一个函数，才能在该函数所属模块之外使用它。

```erlang
100
4> F(18).
20
```

在这里，你定义了两个匿名函数，命名为`F()`和`Five()`。`Five()`函数接受两个参数，即一个整数`N`和一个函数`Function`，并将`Function(N)`的数值结果乘以`5`！
