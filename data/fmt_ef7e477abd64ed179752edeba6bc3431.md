## 打印文件

### 将文件送到打印机

在应用程序内部打印非常简单，只需从菜单中选择“打印”选项即可。

从命令行开始，使用 `lp` 或 `lpr` 命令。

```
lp file(s)
lpr file(s)
```

这些命令可以从管道读取，因此你可以使用以下方法打印命令输出：

```
command | lp
```

有许多选项可以调整页面布局、副本数量、如果你有多个可用打印机则选择打印到的打印机、纸张大小、如果打印机支持此功能则单面或双面打印、边距等。阅读 man 页面以获取完整概述。

### 你的打印任务状态

一旦文件被打印队列接收，就会为该打印任务分配一个识别号：

```
davy-> lp /etc/printqueue
request id is blob-253 (1 file(s))
```

要查看（查询）打印队列，使用 `lpq` 或 `lpstat` 命令。在不带参数执行时，它会显示默认打印的内容。

```
davy-> lpq
blob is ready and printing
Rank Owner Job File(s) Total Size
active davy 253 profile 1024 bytes
davy-> lpstat
```

`blob-253` `davy` 1024 Tue 25 Jul 2006 10:20_01 AM CEST

### 你的打印机状态

在一个可以访问多个打印机的系统中，默认打印机是哪一个？

```
lpstat -d
```

```
davy-> lpstat -d
system default destination: blob
```

你的打印机状态是什么？

```
lpstat -p
```

```
davy-> lpstat -p
printer blob now printing blob-253. enabled since Jan 01 18:01
```

### 从打印队列中删除任务

如果你不喜欢状态命令显示的内容，可以使用 `lprm` 或 `cancel` 来删除任务。

```
davy-> lprm 253
```

在图形环境中，`lpc` 你任务已取消。在较大的环境中，`lpq` 会显示状态。

CUPS 有许多选项，但最常见的方法是：

- `lp`: 打印文件
- `lpr`: 打印文件
- `lprm`: 删除任务
- `lpq`: 查询打印队列
- `lpstat`: 显示打印机状态
- `cancel`: 删除任务

为什么命令 `tail testfile > testfile` 不起作用？这是因为 shell 在读取文件之前对其进行了截断。

打印有许多方法，最常见的是：

- BSD 风格: 使用 LPD 和 `lpr`
- SystemV 风格: 使用过滤器和 `lp`
- CUPS: 使用 `lp` 和 `lpstat`

在这些风格中，CUPS 是最现代且最流行的。

## 服务器端

## 通用

几年前，Linux 用户的选择非常简单：每个人都运行来自 BSD Net-2 代码的相同 LPD。后来 LPRng 变得更流行，但现在大多数现代 Linux 发行版

使用 CUPS [`http://www.cups.org`]，即通用打印系统。CUPS 是互联网打印协议 (IPP) 的实现，该协议是用于替代老旧（且笨重）的 LPD 协议的类 HTTP 标准替代方案。CUPS 遵循 GNU 公共许可证发布。CUPS 也是 macOS 上默认的打印系统。

## 图形化打印机配置

大多数发行版都带有用于配置网络和本地（并行或 USB）打印机的图形界面。它们允许你从列表中选择打印机类型并能够方便地进行测试。你不需要担心语法。在尝试安装打印机之前，请检查你的文档。CUPS 也可以使用运行在计算机端口 631 上的 Web 界面进行配置。要检查此功能是否已启用，请尝试访问 `http://localhost:631`。

## 为 Linux 购买打印机

随着越来越多的厂商为 CUPS 提供驱动程序，CUPS 将允许你轻松连接几乎任何可以插入 USB 端口或设备的打印机，以及网络上的任何打印机。CUPS 将确保向你统一呈现所有不同类型的打印机。如果打印机仅提供 Windows 驱动且没有其他支持，则可能会出现问题。

过去，你最好的选择是固件中带有原生 Postscript 支持的打印机，它产生 Postscript 输出（出版业的控制语言）。Postscript 打印机通常贵一些，但它们是设备无关的开放编程语言，你总是 100% 确定它们能够工作。然而，如今这种角色的重要性正在降低。
