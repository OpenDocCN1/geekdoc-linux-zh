以下示例将主机 `lizard` 上的 `lizard.file` 重定向到同样位于 `lizard` 上的 `lizard.file2`。

# `rusers` — 显示远程系统的登录用户

### 概要

`/usr/bin/rusers [-hil]`

## 描述

`rusers` 命令为远程系统产生类似于 `who(1)` 的输出。列表是按照接收响应的顺序排列的，但你可以通过指定下面列出的选项之一来更改此顺序。

当你指定 `host` 参数时，`rusers` 不再进行广播，而是仅查询指定的主机列表。

当远程主机运行 `rstatd` 守护进程时，才会响应，该守护进程通常从 `inetd(1M)` 启动。

通常，列表是按照接收响应的顺序排列的，但指定 `rusers` 显示登录所有系统的用户列表，以及登录 TTY 端口的日期。如果你指定 `-l` 选项，将为每个用户打印额外信息。如果主机名相同，则不显示空闲字段。同样，如果主机空闲，则不显示空闲时间。

## 选项

- `-a` 即使没有用户登录也报告所有用户。
- `-h` 按主机名字母顺序排序。
- `-i` 按空闲时间排序。
- `-l` 按平均负载排序显示。
- `-u` 按用户数量排序。

## 示例

以下示例显示了小型网络的 `rusers` 输出。

```
castle% rusers
sending broadcast for rusers version 3...
castle winsor
castle
```

以下示例显示了城堡系统的详细列表。

```
castle% rusers -l castle
winsor          console      Mar 30 08:04      (:0)
castle
```
