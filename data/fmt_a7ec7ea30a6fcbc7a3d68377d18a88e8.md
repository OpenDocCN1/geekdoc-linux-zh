
然后登录过程将像你直接连接到这台机器一样进行。所有的信息和文件都从远程获取。远程密码包含用户账户信息，包括要执行的登录 shell 和起始（HOME）目录。所有的 shell 启动文件（在远程上找到）都会执行，从而进一步初始化你的环境。当启动完成后，你看到的 shell 提示符显示它运行在远程主机上。

注意：在某些局域网环境中，网络配置为你的 HOME 目录位于远程文件服务器上，该服务器挂载在每台机器上。在这种情况下，你实际上只有一个物理 HOME 目录，因此只有一组点文件（例如 `.login`）。这导致每台机器都具有相同的登录环境。然而，这使得你的文件变得稍微复杂，因为你需要考虑要适应的所有不同机器。

提示：由于远程提示符和本地提示符可能相同，你可能希望在提示符变量（`PS1`）中包含主机名。

`display`

显示 telnet 配置的当前设置。

`status`

显示 telnet 连接的当前状态。

`?`

提供帮助。

接下来的章节将详细介绍其中的一些内容。`open` 命令接受两个参数：`host`（主机）和 `port`（端口）。`host` 是强制性的，可以是主机名或 IP 地址。它指定了建立连接的远程主机。该远程主机必须可以通过网络访问，并且必须支持 telnet 服务。`port` 是可选的，指定连接到远程主机时使用的端口。默认情况下，telnet 连接的端口是已知的 telnet 端口 (23)。当你通过同一个端口连接到远程主机时，telnet 服务将处理该连接。`remotenet` 服务确保本地连接器想要登录，并在连接时调用登录过程。这有助于调试和故障排除。例如，若想要连接到某台机器上的邮件服务器，可以使用 `telnet hostname smtp`（如果第一个不起作用，请将 `smtp` 替换为 `25`）。这将直接你连接到简单邮件传输协议主机名，你可以使用此连接来排查邮件问题。某些网络通过 telnet 提供特定的端口。例如，gopher 和 WWW 提供者为 telnet 访问该服务提供了特殊端口。

在此模式下，`telnet open` 类似于 `login`。在远程主机上启动一个远程登录。telnet 协议不会为你执行任何约定操作。它不会传播你本地环境的任何内容。它不会执行登录过程的任何部分（身份识别和身份验证）。

如果你是第一次使用 `telnet` 执行 `open` 命令，你完全不需要进入 telnet 模式。在 `telnet` 命令行，你可以可选地通过参数输入 `host`。这会导致 telnet 立即对 `open` 命令行执行操作。`close` 命令会终止 `open` 连接（如果已存在）。在某些版本的 telnet 中，这并不会退出 telnet 模式。如果你连接到了主机 B 但真的想退出，则应在结束对 telnet 的使用时使用 `quit` 命令。这将执行关闭连接（如果已存在）。它会终止 telnet 服务，并返回到你的本地 shell 提示符。`set telnet` 有几个用于配置的内部变量。你可以使用 `set` 命令更改这些值。要查看当前的变量值，请使用 `display` 命令。可以通过 `set` 更改 telnet 转义字符。

- 提示：你可以使用 telnet 设置特殊字符（如 erase），但这些设置仅在行模式（line mode）下运行 telnet 时有效。行模式通常用于连接到具有行式用户界面的远程机器，允许你在发送到远程端之前（在你按下回车时）组合一整行文本输入。在连接到 UNIX 交互式命令（如 `vi`）、作业控制以及某些历史（ksh 交互式编辑命令）时不应使用行模式，因为这些功能依赖于识别实时输入的字符。

`?` 是一个 telnet 命令，在不带参数的情况下会列出所有 telnet 命令。如果你忘记了命令的名称，这非常有用。要获取有关特定命令的帮助，请将命令作为参数使用 `?`。`?` 也可以作为 `set` 和 `toggle` 命令的参数，列出命令的有效参数。

## 使用 ftp

ftp 服务是文件传输协议的接口。该服务提供了与远程计算机的连接，具有文件操作功能，包括发送和接收文件。它还提供了类似于 rcp 的用户身份验证功能。它支持不同的文件类型。

连接到远程主机，只需输入 `ftp hostname`。主机可以是主机名，也可以是 Internet 地址。如果你没有在命令行中指定远程主机，你将进入 ftp 命令模式。然后你使用 `open` 命令启动连接。

默认情况下，当通过 ftp 建立连接时，远程 ftp 服务器会启动登录过程。你必须输入有效的用户名和密码才能访问远程系统。一旦通过身份验证，你就会连接到了远程 ftp 服务器，它将等待你的命令。

ftp 服务有许多命令。表 6.2 涵盖了其中几个常用命令。详细信息，请参阅你系统的 ftp 手册。

**连接相关命令**

与 ftp 相关的命令非常直观。`open` 命令尝试连接到远程主机上的 ftp 服务器。`close` 命令终止已打开的连接（如果存在）并返回命令模式。这通常用于当你想要连接到不同的主机时，因此你通常会在其后跟着一个 `open`。`quit` 命令关闭连接并退出 ftp。

**文件传输相关命令**

ftp 服务定义了传输的文件表示类型。最常用的是 `ascii` 和 `binary`。默认情况下，类型设置为 `ascii`。任何 ASCII 文本文件都可以使用 `ascii` 类型传输。二进制文件（如编译的可执行文件）必须使用 `binary` 类型传输。

> 提示：使用 binary 类型在 UNIX 机器之间传输 ASCII 文本文件会快一点，但使用 binary 类型在 UNIX 和非 UNIX 机器之间传输 ASCII 文本文件可能会损坏文件。

> 提示：如果你在其他地方解码或执行二进制文件遇到困难，请检查确保使用了 **binary type**。

`get` 和 `mget` 命令将文件从远程传输到本地。`put` 和 `mput` 命令将文件从本地传输到远程主机。`get` 和 `put` 每次传输一个文件。在这两个命令中，你可以指定文件的目的。如果没有指定目的，文件将放在当前工作目录。`mget` 和 `mput` 每次传输多个文件。文件放在当前工作目录。

**目录管理命令**

目录管理命令类似于 UNIX 目录命令。在表 6.2 中，给出了类似于 ftp 的 UNIX 命令。对于所有这些命令，使用 `lcd` 切换到远程系统。如果你需要更多本地文件管理，使用 shell 命令 (`!`) 切换到子 shell。

**其他命令**

`?` 命令提供关于 ftp 的帮助。如果你想获取特定命令的帮助，可以将该命令作为 `?` 的第一个参数。shell 命令 (`!`) 用于在本地主机上启动一个子 shell。当你连接到远程服务器并在本地主机上执行某些操作时，这非常有用。在本地主机上完成后，退出（子 shell）并返回 ftp。
