
```perl
print "name is $name\n";
```

它产生此输出：

```
Use of uninitialized value in concatenation (.) or
string at line 3.
name is
```

与大多数指令一样，你可以通过使用 `no` 关键字反转含义，这将在块结束之前关闭警告。

```perl
use warnings;
my $name;
```

## 附录 C (Appendix C)

```perl
{
    no warnings;
    print "name is $name\n"
}
# warnings are back on
```

警告分为以下几类：

- `closure` (闭包)
- `deprecated` (弃用)
- `exiting` (退出)
- `glob` (通配符)
- `io` (输入输出)
- `misc` (杂项)
- `numeric` (数值)
- `once` (一次)
- `overflow` (溢出)
- `pack` (打包)
- `portable` (可移植)
- `recursion` (递归)
- `redefine` (重定义)
- `regexp` (正则表达式)
- `severe` (严重)
- `signal` (信号)
- `substr` (子字符串)
- `syntax` (语法)
- `taint` (污染)
- `threads` (线程)
- `uninitialized` (未初始化)
- `unpack` (解包)
- `untie` (取消绑定)
- `utf8` (UTF-8)
- `void` (空)
- `y2k` (千年问题)

你可以使用这些类别对启用或禁用哪些警告进行精细控制。在之前的示例中，你可以完全关闭某些类别的警告：

```perl
use warnings;
my $name;

{
    no warnings "uninitialized";
    print "name is $name\n"
}
# warnings are back on
```
