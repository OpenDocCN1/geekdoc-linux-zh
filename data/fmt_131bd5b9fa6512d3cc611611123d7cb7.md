
Airdump 是一种网络监控工具，其工作与上述工具相同，但提供了更多选项和自定义功能。Airodump 甚至提供了虚造的钓鱼页面，通过社会工程攻击从目标用户处获取信息。

到此，我们完成了对 Kali Linux 工具集的简要介绍。在模块的下一个章节中，我们将介绍不同的网络监控工具，这些工具可以帮助分析网络并破解它们。让我们开始吧！

# 第五章

## 用于渗透测试的 BURPSITE

在之前的章节中，我们讨论了网络监控工具，这些工具可以帮助我们理解目标系统中存在的不同网络模块。虽然网络破解在几年前是一种很流行的破解程序，但随着互联网和 Web 应用的普及，我们现在处于仅通过浏览器就能被窃取的边缘。

### 什么是 Web 应用？

Web 应用是运行在浏览器中的软件，只需通过 URL 即可访问。例如，`we.gmail.com` 就是一个 Web 应用，可以向全球任何拥有电子邮件地址的人发送邮件。

对于经验丰富的程序员来说，在 Web 应用中寻找漏洞是非常的。为了寻找这些漏洞，他们使用像 `Burp suite` 这样的软件。`Burp suite` 是目前最流行的 Web 应用漏洞扫描软件。它提供社区版和专业版。社区版免费且不提供自动扫描功能，而专业版则以低廉的价格出售，并提供目标的自动爬取和扫描功能，同时为企业提供文档支持。`Burp suite` 还有一个插件商店，包含大量免费和付费的插件，让 Web 应用渗透测试员的生活变得简单得多。

## 如何使用 BURPSUITE？

要安装 `Burp suite`，请前往官方网站并在使用 `chmod` 命令授权后进行安装。

如果你正在使用 Kali Linux，那么你很幸运，因为 `burp` 社区版已经预装在这个破解发行版中了。从开始菜单中的“Web application”菜单栏打开 `Burp suite`。

打开 `Burp suite` 后，按照以下指令操作：

- 1) 使用代理选项（proxy options），在 `Firefox` 和 `burp suite` 中将 `127.0.0.1` 作为主机地址。通过此操作，所有来自浏览器的 HTTP 请求都将发送到 `Burp suite`。
- 2) 你还可以使用来自 `port swigger` 安全网站的证书运行 HTTPS 协议请求。
- 3) 接收请求后，你需要输入“Accept（接受）”或“Reject（拒绝）”将其发送 `Burp` 监控。你也可以输入 URL 让 `Burp` 爬取整个网站。然而，在扫描网站时要现实な，因为你不会通过扫描器得到令人惊叹的结果。要发现漏洞，你需要更深层次的挖掘和大量的测试。
- 4) `Burp suite` 还有其他界面，如 `Burp suite intruder`、`Burp suite comparer`，用于自动化暴力破解和分析 cookie 信息。
- 5) `Burp suite` 还提供了一个文档面板，你可以在那里为你发现的漏洞编写 POC（证明）。

在下一节中，我们将提供如何使用 `Burp suite` 中提供的 `Burp intruder` 选项破解在线网页密码的详细说明。我们希望你仔细遵循练习，以理解如何破解你喜欢的任何网站账户。这有时很棘，但如果操作正确，你可以获得丰硕的成果。

`Burp intruder` 是 `Burp suite` 软件中的一个重要组件。使用 `intruder`，你可以单独发送请求，并使用可用字典和选项对其暴力破解。`Intruder` 可以发送 GET 和 POST 请求，并可以轻松用于分析结果。

使用 `intruder`，安全分析师通常可以了解入侵检测系统的性能。许多其他 Web 渗透漏洞，如 XSS 和 CSRF 攻击也可以使用 `Burp intruder` 组件进行检测。

### 如何使用它？

第一步：

找到你想要破解的网页。可以是支持 HTTP 或 HTTPS 的网站。如果你不确定网站施加的攻击限制，我们建议你尝试专门为 Web 应用渗透测试员练习开发的示例测试网站。

第二步：

开启 `burp` 拦截代理（intercept proxy）并进入该网页。几秒钟后，你将在 `Burp` 界面中收到一个请求。只需查看它并接受所有出现的请求。如果你拒绝了任何请求，有时网页可能无法正常打开。因此，确保网页已出现在 `Burp site` 菜单中。

第三步：

现在仔细观察 `burp inspector` 获得的所有请求。在这些请求中找到带有“POST”标识符的请求。通常，所有请求都带有“GET”标识符，因为它们正在向服务器请求某些信息。而登录页面和其他敏感框使用“POST”标识符，因为它们正在向服务器发送信息。

第四步：

找到你想要暴力破解的登录表单后，会出现一个菜单。在 `Burp` 菜单中点击“Send to intruder（发送到 intruder）”。现在你可以进入 `intruder` 界面查看该页面已准备好执行（字典）攻击。

第五步：

现在，使用底部框中出现的 HTML 代码选择参数。在这里选择“login（登录）”和“password（密码）”框以便于攻击。选择选项菜单后，选择你想使用的字典类型。

从数字到常用密码，有几十种选项供你考虑。你也可以在 `Burp suite` 的专业版中上传自定义字典列表。不要忘记选择你想执行的暴力破解攻击类型。我通常使用“pitchfork（叉叉模式）”，因为它简单快捷。

第六步：

现在点击 `start（开始）`，几秒钟内请求将开始涌入你的结果屏幕。暴力破解后仔细观察结果。所有带有“404”错误的结果都是坏结果。如果你收到任何成功消息，它们可能就是良好的结果。交叉检查良好的结果并对攻击场景编写一份文档。

到此，我们已经提供了关于 `Burp suite` 的清晰指令以及各种重要信息。
