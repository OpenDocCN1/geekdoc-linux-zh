## 第74章 修改任务管理器 (Vista)

如果主机上安装的是四个 CPU，那么 Windows 任务管理器应当通过 `GetSystemInfo()` 函数确保显示出 4 个 CPU 的性能计划图。本章将要微调任务管理器，让它显示更多的 CPU 运行核心。

首先需要的问题是：任务管理器如何知道 CPU 有多少个运算核心？虽然 `GetSystemInfo()` 函数可以确保反馈这一信息，但是任务管理器 `taskmgr.exe` 没有直接调用这个函数。多次通过 NTAPI 中的 `NtQuerySystemInformation()` 函数获取的各种系统信息，也是通过后者来理解具体的状况。

`NtQuerySystemInformation()` 函数有四个参数：第一个参数是查询的系统类型；第二个参数是指针，用于返回的 HandleList；第三个参数是程序员指定的 HandleList 内存空间；第四个参数是 `NtQuerySystemInformation` 返回的 HandleList 的大小。获取 CPU 信息，就要获取它的时候把第一个参数设置为常量 0。我们将它的调用拆解为 `NtQuerySystemInformation(0, ?, ?)`。第一步使用 IDA 打开 `taskmgr.exe`。在微软官方程序过程中，IDA 能够与之相关的 PDF 文件。易见的，任务管理器是用 C++ 编写的，它使用的函数名称和类名是不知的。它使用的类名中，我们可以看到 `Adapter`、`Net`、`CProc`、`TaskPage` 和 `UserPage`。这些类和任务管理器窗口有对应关系。在跟踪 `NtQuerySystemInformation()` 函数的每次调用之后，我们可以算出函数的第一个参数。在图 74.1可以看到，部分调用里的第一个数值明显为零，所以标记了“Not Zero”。还有一些函数调用的情况非常特殊，本章将进行详解。总之，我们要找那些参数为零的 `NtQuerySystemInformation()` 函数语句。
