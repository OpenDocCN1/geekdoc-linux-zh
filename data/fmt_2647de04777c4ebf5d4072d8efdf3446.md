
## 函数命名

对于函数，请使用以下命名方案：

- `printString` 用于显示消息的函数。这里 `String` 描述了所显示消息的类型。
- `promptString` 用于提示用户输入的函数。这里 `String` 是函数在从用户处读取输入后设置的变量名。
- `getString` 用于获取某种类型数据的函数。这里 `String` 描述了所获取的信息。

### 显示消息

shell 脚本显示的大多数消息不需要特殊处理（例如在消息前加上一个单词）。以下函数处理了这些工作：

```############################################################

# Name: printERROR

# Desc: 将消息打印到 STDERR

# Args: $1 -> 消息

############################################################

printERROR() {

  echo "ERROR: $1" >&2

}

############################################################

# Name: printWARNING

# Desc: 将消息打印到 STDERR

# Args: $1 -> 消息

############################################################

printWARNING() {

  echo "WARNING: $1" >&2

}

############################################################

# Name: printUSAGE

# Desc: 打印用法消息并退出

# Args: $1 -> 消息

############################################################

printUSAGE() {

  echo "USAGE: $1"

  exit

}

```

使用这些函数的优势是，它们为你的整个脚本中的错误和警告提供了标准的输出格式。例如，接下来的错误消息

```
echo "ERROR: $MYFILE was not found." >&2
```

可以写为：

```
printERROR "$MYFILE was not found."
```

由于 `printERROR` 函数总是会在你想显示的消息前加上 ERROR 单词，并将输出重定向到 STDERR，所以你在显示错误消息时不需要担心忘记这些。

### 提问

在交互式 shell 脚本中，你需要从用户处获取输入。有时这涉及询问简单的是或否问题。在其他情况下，你需要向用户提出一个需要复杂回答的问题。例如，许多脚本需要获取要操作的文件名。

在本节中，我介绍了两个帮助你提示用户并获取响应的函数：

- `promptYESNO`
- `promptRESPONSE`

#### 询问是或否问题

shell 脚本询问的最常见类型之一是是或否问题。例如，这个 shell 脚本

```
Make backup (y/n)?
```

询问你是否要备份。

函数 `promptNO` 提供了一种可重用的方法来询问是或否问题并获取响应。在函数完成后，用户的响应（y 表示是，n 表示否）将存储在变量 `YESNO` 中。

```############################################################

# Name: promptYESNO

# Desc: 询问是/否问题

# Args: $1 -> 提示内容

#      $2 - 默认答案（可选）

# Vars: YESNO -> 设置为响应

#      y 表示是，n 表示否

############################################################
```

```bash
def promptYESNO() {
  printERROR "Insufficient Arguments."
  return 1
  fi
  DEF_ARG=""
  YESNO=""
  case "$2" in
    [yY] | [yY] [eE] [sS])
      DEF_ARG=y ;;
    [nN] | [nN] [oO])
      DEF_ARG=n ;;
  esac
  while :
  do
    printf "$1 (y/n)? "
    if [ -n "$DEF_ARG" ]; then
      printf "[$$DEF_ARG] "
    fi
    read YESNO
    if [ -z "$YESNO" ]; then
      YESNO="$DEF_ARG"
    fi
    case "$YESNO" in
      [yY] | [yY] [eE] [sS])
        YESNO=y ; break ;;
      [nN] | [nN] [oO])
        YESNO=n ; break ;;
      *)
        YESNO="" ; ;;
    esac
  done
  export YESNO
  unset DEF_ARG
  return 0
}
```
