
一旦安装了 BamAV，你可以通过 Applications（应用程序）> Accessories（附件）> Virus Scanner（扫描器）执行病毒扫描。这将弹出 ClamTk 扫描器窗口（图 18-5）。如果它出现了，你应该设置 BamAV 自动扫描任何病毒。为此，进入 Actions（操作）菜单并选择 Quarantine Infected Files（隔离感染文件）。然后进入 File（文件）菜单，选择 Scan Directory（扫描目录），选择扫描的文件夹或磁盘。完成后，点击 OK 按钮，BamAV 将开始扫描你的系统。ClamTk 会在按钮下方的空白区域告诉你（或者准确地说告诉 ClamAV）正在扫描什么。如果它发现任何可疑项，将在窗口的主区域中列出该项目。

## 项目 18：使用 avast! 进行病毒扫描

虽然 ClamAV 可能是 Linux 世界中首选的病毒扫描器，但我最喜欢的仍然是 avast！它在我使用 Windows 的多年里保护过我。我觉得它更容易使用，而且说实话，界面也更好看。缺点是，它要求你每年注册以获取许可证密钥，但这并不是什么艰巨的任务，而且它对于家庭和非商业用途仍然是免费的——如果我对本书目标读众的预测是正确的，那么你应该在此内。至少如此，它也值得一试，所以尽管去尝试吧。

### 18-1：下载 avast! DEB 程序包和许可证密钥

首先，你需要获取 avast! 文件和许可证密钥。你可以打开网络浏览器并访问 www.avast.com/eng/download-avast-for-linux.html 来实现。访问后，点击 avast! Linux 家庭版 DEB 软件包的 **Download**（下载）按钮。当 Firefox 弹出“你想如何处理此文件”窗口时，点击 **OK**（确定）接受默认设置（`gdebi-gtk`）。下载完成后，你可以将软件包保存到硬盘并双击它打开 Debian 安装程序。

当软件包安装程序窗口出现时，在提示时输入你的密码并点击 **OK**。下载和安装将开始。进程完成后，关闭通知窗口和软件包安装程序本身。一旦下载并安装了 avast!，你需要一个许可证密钥才能使用。只需返回 Firefox 中的 avast! 下载页面，点击 **registration form**（注册表单）链接，然后填写并提交该表单。你应该在几分钟后通过邮件收到许可证密钥，尽管页面显示可能需要长 24 小时。

### 18-2：运行和使用 avast!

一旦安装了 avast!，你可以通过点击 Run Application（运行应用程序）面板（或按下 ALT-F2），在其中输入 `avastgui` 并点击 **Run**（运行）按钮来启动它。第一次运行 avast! 时，会弹出一个小窗口要求你输入许可证代码。假设你已经按照我的指示，在项目开始时注册了 avast! 的免费代码，那么你的注册密钥应该已经在邮箱收件箱中等候你了。查看一下，复制密钥，并将其粘贴到 Registration（注册）窗口的文本字段中（你必须使用 CTRL-V 组合键完成此操作）。许可证密钥到位后，点击 **OK** 按钮。

主窗口（图 18-7）将会出现，但在开始扫描任何内容之前，检查病毒数据库是否有更新是一个好主意。新病毒不断出现在网络空间，所以你应该保持 avast! 病毒数据库的更新，以便它识别任何新出现的病毒。要执行更新，只需点击 Update database（更新数据库）按钮，让 avast! 处理即可。

图 18-7：avast! 病毒扫描器

当 avast! 正在更新病毒数据库时，你可以先决定是扫描 Home 目录、整个系统还是选定的文件夹来开始病毒扫描。你还可以通过窗口中间提供的三个选项来决定想要扫描的彻底程度：Quick（快速）、Standard（标准）或 Thorough（彻底）。

你选择其中哪种敏感模式取决于你想要扫描得有多彻底。快速扫描只扫描以特定扩展名（.exe, .com, .doc 等）结尾的文件，因为这些文件类型是病毒常见的病毒载体。标准扫描针对更多文件，忽略扩展名，但仍将扫描限制在通常与病毒相关的文件类型中。最后，彻底扫描将扫描一切并搜索所有类型的病毒。

一旦你做出选择，点击 **Start scan**（开始扫描）按钮，avast! 将开始执行该操作——而且直接在同一个窗口内显示进度。扫描完成后，会弹出一个小窗口告诉你——希望地，希望——没有发现病毒。（你上一次在 Windows 机器上收到这样的信息是什么时候？）

# 适用于 AMD64 用户的 UBUNTU 桌面版 CD

正如我在第 1 章中提到的，随书附的 Ubuntu Desktop CD 版本是为 PC 或基于 Intel 的 Mac 上的 i386 处理器设计的。它也可以适用于 AMD64 处理器，尽管不是在 64 位模式下运行。为了在 64 位模式下使用带有 AMD64 处理器的 Ubuntu，你必须自己获取光盘。有几种方法可以实现：

- 下载 ISO（磁盘镜像）并自己刻录
- 向 Ubuntu 订购 CD（免费）
- 从在线 CD 供应商处订购（需少量费用）

## 下载并将 Ubuntu ISO 刻录 CD

要下载 Ubuntu Desktop 的 ISO，请访问 Ubuntu 网站 www.ubuntu.com，找到下载页链接，然后选择并下载适用于你机器的相应版本。记住，你将下载的 ISO 文件是重量级的，大小略超过 700MB，所以下载将需要一些时间。如果你恰好使用拨号连接，不要指望在明天之前下载并完成。

## 在 Windows 中将 ISO 刻录到 CD

下载完桌面 ISO 后，你需要将其刻录到 CD 才能使用。虽然 Windows 有内置的 CD 刻录功能，但它没有在 Windows 中将 ISO 刻录到 CD 的功能；因此，你必须使用第三方程序。由于 Windows 不具备将 ISO 刻录到 CD 的能力，你必须使用如 Nero 等第三方应用程序。如果你的系统中没有安装 CD 刻录工具，请尝试免费的 ISO Recorder。要获取 ISO Recorder，访问 http://isorecoder.com/。下载完成后，双击磁盘上的 `isorecorder.exe` 进行安装。安装完成后，通过双击你的 ISO 文件并在弹出菜单中选择 *Copy to CD* 来刻录。Recording（记录）窗口将如图 A-1 所示出现。

图 A-1：使用 ISO Recorder 将 ISO 刻录到 CD

以低于驱动器允许的最大速度刻录通常是最好的，以减少错误概率（考虑 2X 到 4X 速度）。这样做，点击 Recording 窗口中的 Properties 按钮，并将滑块拖到 4X。接下来，将空白 CD 插入驱动器并点击 Next。刻录将开始。完成后，CD 将从驱动器弹出，如果一切顺利，你就有了一个兼容的 live CD。你可以按照书开头的说明使用它。

注意：如果 CD 无法工作，可能是 ISO 文件存在问题。可以通过 https://help.ubuntu.com/community/mdsum 进行方法检查。

## 在 OS X 中将 ISO 刻录到 CD

虽然 Ubuntu 不再提供 PowerPC 版本，但 i386 版本可以在基于 Intel 的 Mac 上安装和运行。你当然也可以在 Mac 上下载其他架构的 ISO，并将其刻录到 CD 以供其他机器使用。

要在 OS X 中将 ISO 文件刻录到 CD，首先检查 ISO 镜像是否未挂载：打开 Finder 窗口并检查左侧面板顶部的磁盘区域。如果已挂载，会出现一个白色驱动器图标。如果图标在那里，点击该条目旁边的箭头或卸载。

之后，点击同一个 Finder 窗口中的 Applications，然后查找并打开 Utilities 文件夹。在文件夹中，找到并双击 Disk Utility。如果打开时 ISO 未列在左侧面板，返回 Finder 窗口，找到你下载的 Ubuntu Live CD ISO，将其拖入 Disk Utility 窗口的左侧面板（当前驱动列表下方）。如果 ISO 出现在列表中，点击一次将其高亮。此时你的 Disk Utility 窗口应该像图 A-2 所示。
