## `declare` 变量属性

### `-r` 只读型

```bash
declare -r varl=1
echo varl = $varl    # varl = 1

(( varl++ ))
# x.sh: line 4: readonly variable
```

### `-i` 整数型

```bash
declare -i number
# 脚本将后续出现的 "number" 视为整数。

number=3
echo Number = $number    # Number = 3

number=three
echo Number = $number    # Number = 0
# 尝试将字符串 "three" 求值为整数。
```

声明的整数变量允许算术运算，不需要 `expr` 或 `let`。

```bash
n=6/3
echo "n = $n"    # n = 6/3

declare -i n
n=6/3
echo "n = $n"    # n = 2
```

### `-a` 数组型

```bash
declare -a indices
# 变量 indices 将视为数组。
```

### `-f` 函数型

```bash
declare -f
# 脚本中不带参数的 declare -f 行会创建脚本中定义的所有函数的列表。
```

```bash
declare -f function_name
# 脚本中的 declare -f function_name 会列出指定的函数。
```

### `-x` 导出型

```bash
declare -x var3
# 声明一个变量并导出到脚本本身的环境中。
```

### `-x var=$value`

```bash
declare -x var3=373
# declare 命令允许在设置属性的同一语句中为变量赋值。
```

### 示例 9-10. 使用 `declare` 为变量指定类型

```bash
#!/bin/bash

funccl () {
  echo 这是一个函数。
}

declare -f      # 列出上面的函数。
echo
declare -i var1 # var1 是一个整数。
var1=2367
echo "var declared as $var1"
var1+=1        # 整数声明消除了对 'let' 的需要
echo "var incremented by 1 is $var1"
# 尝试更改声明为整数的变量。
echo "Attempting to change var1 to floating point value, 2367.1"
var1=2367.1     # 结果报错，变量没有变化。
echo "var is still $var1"

declare -r var2=13.36 # 'declare' 允许在设置变量属性
# 同时进行赋值。
echo "var2 declared as $var2" # 尝试更改只读变量。
var2=13.37      # 生成错误信息并退出脚本。
echo "var2 is still $var2"  # 这一行不会执行。

exit 0          # 脚本不会在此退出。
```

使用 `declare` 内置命令会限制变量的作用范围。

```bash
foo () {
  FOO="bar"
}

bar () {
  foo
  echo $FOO
}

bar      # 打印 bar。
然而...

foo () {
  declare FOO="bar"
}

bar () {
  foo
  echo $FOO
}

bar      # 什么都不打印。

# 感谢 Michael Iatrou 指出。
```

## 9.2.1. `declare` 的另一个用途

`declare` 命令对于识别变量（环境变量或其他变量）很有帮助。这在处理数组时特别有用。

```bash
bash declare | grep HOME
HOME=/home/bozo

bash$ zzy=68
bash$ declare | grep zzy
zzy=68

bash$ Colors={[0]="purple" [1]="reddish-orange" [2]="light green"}
bash$ echo ${Colors[@]}
purple reddish-orange light green
bash$ declare | grep Colors
Colors={[0]="purple" [1]="reddish-orange" [2]="light green"}
```

## 9.3. `$RANDOM`: 生成随机整数

`$RANDOM` 是一个内置变量，返回 0 到 32767 之间的随机整数。

### 生成随机数的方法

```bash
# 生成 0 到 N 之间的随机数：
echo $(( RANDOM % (N + 1) ))

# 生成 MIN 到 MAX 之间的随机数：
echo $(( (RANDOM % (MAX - MIN + 1)) ) + MIN ))
```

### 示例 9-11. 生成随机数

### 示例 9-14. 范围随机数生成器

```bash
#!/bin/bash

## random-between.sh

# 两个指定值范围的随机数。

# 脚本由 Bill Gradwohl 编写，文档作者进行了微调。

# Anthony Le Clezio 对第 187 行和 189 行进行了修正。

# 经许可使用。
```

```bash
randomBetween() {

# 在 $min 和 $max 之间生成一个正或负的随机数

# 且能被 $divisibleBy 整除。

# 为返回值提供一种“合理随机”的分布。

# Bill Gradwohl - 2003年10月1日

minimum=$1
maximum=$2
divisibleBy=$3

if [ $minimum -gt $maximum ]
then
    echo "Min must be less than max."
    exit 1
fi

if [ $divisibleBy -eq 0 ]
then
    echo "Divisible by cannot be zero."
    exit 1
fi

# 确保 maximum 能被 divisibleBy 整除
if [ $((maximum % divisibleBy)) -ne 0 ]
then
    maximum=$(((((maximum/divisibleBy)-1)*divisibleBy))
else
    maximum=$((divisibleBy*(maximum/divisibleBy)))
fi

# 我们只需要生成正数组下标
# 因此，我们需要一个位移量来保证
# 结果为正数。

disp=$((0-minimum))

for (i=$((minimum)); i<=($maximum); i+=divisibleBy); do

  answer[i+disp]=0

done

# 现在循环多次，看看我们会得到什么。
loopIt=1000 # 脚本作者建议用 100000，
# 但那需要很长一段时间。

for (i=0; i<($loopIt); i++); do

# 注意，我们在这里反反倒指定了 min 和 max，
# 以确保函数在这种情况下是正确的。

randomBetween$(max) $min$(divisibleBy)

# 如果结果不符合预期，则报告错误。
[[$randomBetweenAnswer -lt $min -o $randomBetweenAnswer -gt $max ]] \
&& echo MIN OR MAX error -$randomBetweenAnswer! \
[[$randomBetweenAnswer$(divisibleBy)] -ne 0 ]] || \
echo DIVIBLE BY error -$randomBetweenAnswer!

# 统计性存储答案。
answer[randomBetweenAnswer+disp]=$(answer[randomBetweenAnswer+disp]+1)

done

# 让我们检查结果

for (i=$((minimum)); i<=$(maximum); i+=divisibleBy); do

  [ \${answer[i+disp]} -eq 0 ] \
&& echo "We never got an answer of \$i." \
|| echo "\$i occurred \${answer[i+disp]} times."

done
```
