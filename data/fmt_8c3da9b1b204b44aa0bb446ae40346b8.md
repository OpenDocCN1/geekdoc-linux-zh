### `/proc/net/sys` 目录

该目录包含了按子目录分类的内核配置设置文件：

```
$ ls /proc/sys kernel net user vm
abi debug dev fs kernel user vm
```

这些文件中的大多数都像一个开关——因此——它们只包含两个可能值之一：0 或 1（“开启”或“关闭”）。例如：

### `/proc/sys/net/ipv4/ip_forward`

用于启用或禁用我们的机器作为路由器运行（能够转发数据包）的值：

```
$ cat /proc/sys/net/ipv4/ip_forward
0
```

不过，也有一些例外：

### `/proc/sys/kernel/pid_max`

允许的最大 PID：

```
$ cat /proc/sys/kernel/pid_max
32768
```

> 警告 更改内核设置时要格外小心，因为错误的值会导致系统不稳定。

## 硬件设备

记住，在 Linux 中“万物皆文件”。这意味着硬件设备信息与内核配置设置一样，都存储在位于虚拟目录中的特殊文件中。

## `/dev` 目录

设备目录 `/dev` 包含所有连接硬件设备的设备文件（节点）。这些设备文件用作设备与使用这些设备的进程之间的接口。每个设备文件属于两类之一：

## 块设备

是指以块为单位进行读写且可以被单独寻址的设备。示例包括硬盘（及其分区，如 `/dev/sda1`）、USB 闪盘、CD、DVD 等。

## 字符设备

是指数据以一次一个字符的方式顺序读写的设备。示例包括键盘、文本控制台（`/dev/console`）、串口（如 `/dev/ttyS`）等。

在列出设备文件时，请确保使用 `ls -l` 关键来区分两者。例如——检查硬盘和分区：

```
$ ls -l /dev/sd*
brw-rw---- 1 root disk 8, 0 /dev/sda
brw-rw---- 1 root disk 8, 1 /dev/sda1
brw-rw---- 1 root disk 8, 2 /dev/sda2
```

或者对于串口设备 (tty)：

```
$ ls -l /dev/tty*
crw-rw---- 1 root tty 5, 0 /dev/tty0
crw-rw---- 1 root tty 5, 1 /dev/tty1
crw-rw---- 1 root tty 5, 2 /dev/tty2
```

注意：`free` 命令中带有 `*` 符号的内存是可使用的。
