
# Perl 脚本示例

```perl
# 处理第一个参数
open(DATA, $ARGV[0]) || die "无法打开数据文件";

# 初始化运行总和
$length=0.0;

# 数据文件必须至少有一行
# @oldcoordinate 存储上一行，
# @coordinate 存储当前行
```

```perl
if (<DATA>) {
    # 将第一行的字段提取到
    # 数组 @oldcoordinate 中
} else {
    # 如果数据文件为空则终止
    die "无数据";
}
```

```perl
# 遍历文件的每一行
while (<DATA>) {
    # 当前线段通过从
    # 旧坐标中减去
    # 新坐标计算出来
    @coordinate = split;
    $x = $coordinate[0] - $oldcoordinate[0];
    $y = $coordinate[1] - $oldcoordinate[1];
```

```perl
# 使用勾股定理！
$d = sqrt ($x*$x + $y*$y);

# 更新运行总和
$length += $d;

# 现在新行变成上一行
```

```perl
# 坐标
@oldcoordinate = @coordinate;
}
```

```perl
# 清理打开的文件句柄
close (DATA);
```

```perl
# 最后，输出答案
printf "行程长度为 %0.2f km.\n", $length;
```
