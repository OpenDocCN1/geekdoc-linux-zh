## horde
Horde 应用程序的核心元素。一组实现 Web 应用的 PHP 脚本。此软件包是运行其他程序（如基于 Web 的 IMAP 客户端 IMP）所需的。其他应用程序将在可用后出现。请注意，你必须本地或远程设置数据库以安装此软件包，否则安装可能会失败。来自 Debian 3.0 Urt APO `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## host
连接网络并与其他系统通信的计算机。主机通常被分配唯一的名称或地址以与其他区分。来自 Redhat-9-Glossary `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## host
具有“主机”互联网地址的物理或虚拟设备，即 123.2.3.4。而不是网络地址 123.2.0.0。通常，该设备是网络接口设备，如以太网卡或 PPP 控制的串口接口。通常一台计算机只连接到一个设备，因此将“主机”和“计算机”等同对待起来是自然的，而且经常这样做。来自 Linux Guide @FirstLinux `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

## Host
网络上为网络上其他计算机提供服务的存储的任何计算机。通常一个主机提供多种服务，例如 SMTP（电子邮件）和 HTTP（网页）。来自 Matisse `http://www.tld.org/LDP/Linux-Dictionary/html/index.html`

### Host（主机）
在互联网中，任何可以作为数据传输起点和终点的计算机都称为主机。互联网主机有一个唯一的地址（称为 IP 地址）和一个唯一的域名。在一般的网络和电信中，主机是指执行集中化功能的计算机，例如为其他计算机提供程序或数据文件。源自 QUECID

### hotkeys
X 程序中用于你的互联网/多媒体键盘的守护进程，它运行在后台并监听你通常在互联网/多媒体键盘上使用的“特殊”热键。这些按钮执行预期的行为，如音量调大/调小、静音扬声器、启动应用程序等。它具有屏幕显示（OSD），可以显示音量、已启动的程序等。它的特点是基于 XML 的键码配置格式，这使得定义链接到任何程序的热键成为可能。源自 Debian 3.0r APT

### hotplug
Linux 热插拔脚本。此包包含了支持热插拔所需的脚本，允许你插入新设备并立即使用它们。它包括对 USB 和 PCI (Cardbus) 设备的支持，并自动配置网络接口。源自 Debian 3.0r APT

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`

“热插拔”（hotplugging）术语是指设备连接到系统后的动态重新配置。此包包含了内核在添加 USB 设备时调用的应用程序；随后 `hotplug` 会为该设备加载所需的模块。源自 Redhat 8.0 RPM

`http://www.tldp.org/LDP/Linux-Dictionary/html/index.html`
