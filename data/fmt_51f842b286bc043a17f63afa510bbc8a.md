
`for` 循环会展开 shell 命令并将结果转换为一个标记（token），每次循环迭代将一个标记赋值给变量 `file`。

Bourne shell `for` 循环的一个缺点是，它始终会执行一次循环，即使求值后的语句没有产生任何标记。

Bourne shell 脚本中还存在许多其他内部命令和特性。前面的章节为编写 shell 脚本提供了一个极佳的起点。

## 使用函数调用编写脚本

使用你喜爱的编辑器打开文件，并添加必要的首行，以指示 shell 使用哪种 shell 解释器。

然后，开始输入 shell 或 UNIX 命令以完成脚本的目的。

> 注意：保存文件后，务必使用命令 `chmod +x filename` 添加执行权限。

列表 A.3 显示了一个用于打印菜单并响应用户输入的示例 shell 脚本。

### 列表 A.3 示例脚本 menu.sh

```bash
1:  #!/bin/sh

2:

3:  print_menu() {

4:    echo

5:    echo "* Sample Menu *"

6:    echo "*"

7:    echo "1) Print a file"

8:    echo "2) List a file"

9:    echo "3) Remove a file"

10:   echo "4) Exit"

11:   echo

12:   echo -n "Selection: *"

13:

14: }

15:

16:  #

17:  # Shell execution starts here

18:  #

19:  forever=0

20:  while [ $forever -lt 1 ]

21:    do

22:      print_menu

23:

24:      #

25:      # get user input

26:      read ans

27:

28:      case "$ans" in

29: 1) echo -n "Enter filename: "

30:    read filename

31:    if [ "$filename" ]; then

32:        echo "Printing file ($filename) to default printer..."

33:        lp "$filename"

34:    else

35:        echo "No file specified"

36:        fi

37:    sleep 2 # pause so message is read

38: ## end condition

39: 2) echo -n "Enter file: "

40:    read filename

41:    if [ -f "$filename" ]; then

42:        ls -l "$filename"

43:    else

44:        echo "No file to list..."

45:        fi

46:    sleep 2

47:

48: 3) echo -n "Enter file to remove"

49:    read filename

50:    if [ -w "$filename" ]; then

51:        echo -n "Are you sure [yes/no]:"

52:        read ans

53:        if [ "$ans" = "yes" ]; then

54:            rm -f "$filename"

55:        fi

56:    else

57:        echo "You do not have permission to remove $filename"

58:        fi

59:    sleep 2

60:

61:    *) echo "Bye!"

62:        exit 0

63:    ;

64:    esac

65:    done

66:    #

67:    # end of menu.sh

68:    
```

列表 A.3 中出现了两个新约定，特别是 `print_menu` 函数的定义以及 `sleep`、`read` 和 `exit` 命令。

在 Bourne shell 中，函数的定义是通过提供一个名称后跟一对左括号和右括号完成的。使用大括号 `{}` 来标记函数体的开始和结束。

通过直接输入其名称来调用函数：

    print_menu

`sleep`、`read` 和 `exit` 命令执行其名称所蕴含的功能。

### sleep 命令

`sleep` 命令导致 shell 脚本在执行时按参数指定的秒数进行暂停。

```bash
sleep 2
```

### read 命令

`read` 命令用于从标准输入读取内容并赋值给变量。

```bash
read
```

### exit 命令

`exit` 命令退出 shell 脚本。

```bash
exit 0
```

```
/*
 ** 2D 图形编辑器 (2d-gx)
 **
 ** gxMain.c
 */
 #include <stdlib.h>
 #include <stdio.h>
 #include <X11/Intrinsics.h> /* 用于创建例程 /
 #include <X11/StringDefs.h> /* 资源名称 */
 #include <X11/Xaw/Form.h>

 #include "gxGraphics.h"
 #include "gxProtos.h"

/*
 * 应用程序的入口
 */
int main(int argc, char **argv)
{
    XtAppContext appContext;
    Widget tolevel;
    Widget form;
    Widget canvas;

    toplevel = XtvaAppInitialize(&appContext, "2D Graphical Editor",
    NULL, &argc, argv, NULL,
    NULL);

    form = XtvaCreateWidget("topForm",
    formWidgetClass, tolevel,
    NULL);

    canvas = create_canvas(form );
    create_status(form, canvas );

    create_buttons( form );

    XtManageChild( canvas );
    XtManageChild( form );

    XtRealizeWidget( tolevel );
    XtAppMainLoop(appContext);

    exit(0); /* XtAppMainLoop 是无限循环的，永远不会到达 */
}

/**
 ** gxMain.c 结束
 */
```
