## 运行环境

安装 MySQL 后，有多种工具可以收集有关数据库的信息。第一个工具 `mysqladmin` 执行你可能需要的大多数管理任务，包括创建和删除数据库、刷新表、更改用户密码、重载、关闭以及查找数据库状态。

首先，进入 MySQL 安装目录下的 `bin` 目录：

```
shell$ cd /my/path/mysql/bin
```

你可以不带任何参数运行 `mysqladmin` 来查看其所有功能的完整列表：

```
shell$ ./mysqladmin
```

查找版本：

```
shell$ ./mysqladmin version

./mysqladmin Ver 7.15 Distrib 3.22.30, for pc-linux-gnu on i686

TCX Datakont AB, by Monty
```

```
Server version 3.23.30

Protocol version 10

Connection Localhost via UNIX socket

UNIX socket /tmp/mysql.sock

Uptime: 10 min 33 sec
```

Threads: 1 Questions: 3 Slow queries: 0 Opens: 6 Flush tables:
1 Open tables: 2

查找状态：

```
shell$ ./mysqladmin status
Uptime: 901 Threads: 1 Questions: 4 Slow queries: 0 Opens: 6
Flush tables: 1 Open tables: 2
```

你还可以通过以下命令查看所有的环境变量：

```
shell$ ./mysqladmin variables
```

要创建你的第一个数据库，请使用 `mysqladmin` 创建数据库。`-p` 选项会提示你输入密码：

```
shell$ ./mysqladmin -p create MYDATABASE
```

创建后，可以使用以下命令将其删除或“丢弃”：

```
shell$ ./mysqladmin -p drop MYDATABASE
```

要正常关闭数据库，你也会使用 `mysqladmin`：

```
shell$ ./mysqladmin -p shutdown
```

你可以使用 `mysqldump` 和 `mysqlimport` 轻松地从 MySQL 导入和导出数据。通过这些工具，你可以导出整个数据库，以便以后重新导入数据库。这是备份数据库中所有数据的一种简单形式。

MySQL 发行版中附带的其他工具包括：

- `mysisamchk`: 检查、优化、修复和描述 MySQL 表。
- `make_binary_release`: 从编译版本创建 MySQL 的二进制发布版。
- `mysql2sql`: 将为 `mysql` 编写的程序转换为 MySQL。
- `mysqlaccess`: 从数据库中检查主机、用户和数据库的访问权限。
- `mysqladmin`: 为 MySQL 提供通用管理功能。
- `mysqlbug`: 向 MySQL 邮件列表提交 报告。
- `mysqld`: 实际 MySQL 数据库守护进程。
- `mysqldump`: 将数据库导出到文件。
- `mysqlimport`: 将文件导入数据库。
- `mysqlshow`: 显示数据库和表的信息。
- `mysql_install_db`: 安装开始时使用的脚本，用于设置初始表。
- `replace`: 替换字符串的脚本；供 `mysql2mysql` 使用。
- `safe_mysqld`: 保持 `mysqld` 守护进程运行并在崩溃时重新启动的脚本。

## 故障排除

对于 MySQL 数据库服务器，数据目录中有一个 `.err` 扩展名的日志文件。当发生错误时，该文件可能包含日志信息。如果没有关于崩溃原因的信息，你可能还想启用 mysql 的 `-log` 运行选项。这将添加有关运行的额外日志信息。

以下几点注意：

- 确保发行版支持数据库。
- 确保你拥有最新的 `glibc` 或 `libc`（取决于发行版）。
- 检查数据库用户的所有文件权限。
- 检查 `mysqladmin` 状态以确保没有异常。
- 确保用户、密码和主机名配置正确；可以通过 `ps` 命令检查服务器正在运行。
- 确保没有其他程序占用了 MySQL 运行的端口。
- 如果线程已崩溃，你需要杀死它并重新启动。
- 尝试本地和远程连接。如果远程失败，请确保网络选项已开启。如果本地失败，请确保 UNIX socket 已开启。
- 确保为所有客户端提供足够的连接。
- 确保数据库有足够的内存。大型数据库往往迅速消耗资源。
- 确保性能设置对于表大小是正确的。
- 自打印以来数据库的操作没有发生重大变化。参考 MySQL 附带的文档了解更改。

## 总结

MySQL 安装最初看起来很复杂，但通过查看选项并选择最适合你的课程，你可以很快让数据库运行起来。MySQL 有多种发行版：二进制、RPM 和源码。二进制发行版针对特定平台定制的，不适用于其他平台。它们相对容易安装，但可能需要 root 权限安装到系统目录。RPM 发行版是最简单的，但前提是你使用 RedHat。这些发行版甚至会为你完成部分配置。我们推荐的最后一种类型是源码发行版。它们附带大量的文档和示例，并可以根据你的喜好进行高度定制。
