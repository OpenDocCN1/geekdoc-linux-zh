## 使用 Godot 引擎创建游戏

Godot 引擎自2014 年以来一直在开发——它最近完成了从 3x 到 4x 的版本跨越，自从 4.0 发布以来，有大量工作要做。Epic 提供了 250 美元的开发资助，俄罗斯游戏开发者 Kefer 提供了 120 美元的资助，Ubisoft 和 Embark Studios 也提供了慷慨捐赠。这些都是针对开源项目的，说明了该项目已变得多么重要。

Godot 受到关注是因为它填补了一个重要的角色，就像 Linux 一样。它是一个帮助开发者创建游戏的引擎，也是除 Unity 和 Unreal Engine `UE` 之外最广泛使用的开源引擎。使用任何一个系统开发游戏的成本与你在 20 世纪 90 年代中期开发时一样，不同的是这是开源开发，你不会被锁定，不会被强制安装升级，而且不会获得游戏销售额的百分比。

- 1. 节点和场景：所有游戏都有元素，可以通过简单设计和组织它们来创建游戏节点。
- 2. 视口：创建视图以查看和定位游戏中的节点，并创建玩家看到的内容。
- 3. 标签：可以同时打开多个视图并像在 Blender 中一样通过 X、Y、Z 手柄进行操作。
- 5. 属性：同样在编辑器中，无需编写任何代码即可编辑属性。
- 6. 检查器：在属性、节点和编辑历史之间切换。
- 7. 输出页面：查看游戏各个部分的调试信息。
- 8. 资源：游戏所需的所有内容都列在这里，包括代码和着色器文件。

第4 版本是一个巨大的升级，它标志着 Godot 从业余原型设计转变为可以直接与 Unity 和 UE 的统治地位竞争的专业游戏开发引擎。

## 代码操作

使用 Markdown 语法编写文本文档已成为许多项目和团队的默认选择。它易于学习和理解，而且当你没有 Markdown 预览时，它能突显原始文档的可读性。

对于多种标准的 Markdown，`markdownlint` 是适应性强的。它是一个命令，接受 Markdown 文件作为参数，并报告文件内使用的语法的任何问题。每个问题都会附带行号、错误代码和文本描述，例如“内联 HTML”或“应该被空行包围的列表”。它有 47 条规则，从正确的标题到以单个换行符结束文件，再到可选的连续损坏规则。

基于表格的 Markdown，`markdownlint` 帮助你确保语法是正确的。

尽管存在这些混乱和复杂性，而且在有你自己的系统的开发项目中，很少有工具可以根据你的喜好和要求检查 markdown 的有效性。Markdown 就是其中之一，它还可以添加或编辑样式以匹配你偏好的 Markdown 风格。如果这也很简单，你可以使用 `mdlint --rule "MD013: line length => 580"` 来限制超过 500 个字符的行。
