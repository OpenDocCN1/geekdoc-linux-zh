
可选地，您可以通过在 `ftpshut` 命令的最后一个参数中提供警告消息来警告用户服务器即将关闭。消息应该是用双引号括起来的文本字符串。您可以在消息文本中使用几个特殊符号来强制包含动态信息。这些符号在表 27.3 中列出。

| 符号 | 描述 |
|---|---|
| `%s` | FTP 服务器关闭的时间 |
| `%r` | FTP 服务器拒绝新连接的时间 |
| `%d` | FTP 服务器终止现有连接的时间 |
| `%c` | 当前工作目录 |
| `%E` | `/etc/ftpaccess` 中定义的 FTP 管理员的电子邮件地址 |
| `%F` | 当前工作目录中可用的可用空间（以千字节为单位） |
| `%L` | 本地主机名 |
| `%M` | 用户类别中允许的最大用户数 |
| `%N` | 当前登录到用户类别的用户数 |
| `%R` | 远程主机名 |
| `%t` | 本地时间 |
| `%U` | 登录时提供的用户名 |

### FTP xferlog 文件

`wu-FTPd` 守护进程将传输信息记录到 `xferlog` 文件中。通常，此日志文件创建在 `/var/log/` 目录中。`xferlog` 文件由一系列条目组成，每行一个，每个条目采用以下形式：

```
<current time> <transfer time> <remote host> <file size> <filename>

<transfer type> <special action flag> <direction> <access mode>

<username> <service name> <authentication method>

<authenticated user ID> <completion status>
```

这些字段的含义如下：

- **当前时间：** 传输的日期和时间
- **传输时间：** 总传输时间（以秒为单位）
- **远程主机：** 远程主机名
- **文件大小：** 传输文件的大小（以字节为单位）
- **文件名：** 传输文件的名称
- **传输类型：** 传输类型（a 表示 ASCII，b 表示二进制）
- **特殊操作标志：** 指示是否执行了特殊操作（如压缩、解压缩、tar 打包或不执行任何操作）的标志
- **方向：** 传输方向（o 表示传出，i 表示传入）
- **访问模式：** 用户的访问类别（a 表示匿名，g 表示来宾，r 表示真实）
- **用户名：** 匿名用户提供的电子邮件地址
- **服务名称：** 所使用的服务（通常为 `ftp`）
- **认证方法：** 指明所使用的认证方法（通常是没有认证或 RFC931 认证）
- **已认证用户 ID：** 已认证用户的用户名，或使用 `*` 表示用户未经过认证（例如匿名用户）
- **完成状态：** 指示传输的状态（`c` 表示完成或 `i` 表示未完成）

以下是匿名 FTP 用户的典型条目示例：

```
Fri Nov 12 21:23:20 1999 1 localhost 27 /home/ftp/pub/README \
        b__ 0 a user@some.host ftp 0 *

Fri Nov 12 21:23:25 1999 1 localhost 33 /home/ftp/pub/README \
        b 0 a user@some.host ftp 0 * i

Fri Nov 12 21:24:29 1999 1 localhost 50 /home/ftp/incoming/test \
        b__ i a user@some.host ftp 0 *
```

### 专业 FTP 守护进程——ProFTPD

`ProFTPD` 是一个新兴的开发项目，正日益流行，尤其在 Linux 社区中，因为它提供了更好的安全性和对虚拟 FTP 服务器的出色支持。

`ProFTPD` 的开发者受到了 Apache Web 服务器设计的启发。`ProFTPD` 服务器比 `WU-FTPd` 具有更多功能。他们没有尝试扩展 `WU-FTPD` 代码，而是决定从头开始编写服务器。设计目标之一就是更好的安全性。尽管 `WU-FTPD` 很可能是使用最广泛的 FTP 守护进程，并且性能很好，但在过去几年中它经历了多个安全漏洞。因此，`ProFTPD` 的开发者决定从头开始编写一个全新的 FTP 守护进程，使其具有更严格的安全性和更多功能。

`ProFTPD` 可以在许多 Unix 版本上编译和运行，Linux 就是其中之一。实际上，Linux 是 `ProFTPD` 重点测试的核心平台之一。

`ProFTPD` 提供以下功能：

- 它使用一个类似于 Apache Web 服务器的主配置文件。配置指令设计得直观易用，尤其便于已经管理 Apache Web 服务器的管理员。
- 它通过使用类似于 Apache 的 `.htaccess` 文件的 `.ftpaccess` 文件提供基于目录的访问控制。
- 它对虚拟 FTP 服务器有出色的支持。
- 配置匿名访问非常容易。
- 它既可以作为独立守护进程运行，也可以从 `inetd` 守护进程启动。
- 它不需要在其 `bin` 或 `lib` 目录中放置任何特殊二进制文件即可支持匿名 FTP。
- 与大多数 FTP 服务器不同，为了更好的安全性，它不支持任何 `SITE EXEC` 命令。此外，它不使用任何外部程序，而外部程序也是大多数 FTP 守护进程中安全问题的重大来源。
- 它以一个可配置的非特权用户身份运行，从而提供更高级别的安全性。
- 它支持隐藏目录和文件。
- 它提供与 `WU-FTPd` 日志兼容的日志。还可以进行更扩展的日志记录。
- 它支持影子密码。

### 安装预编译的二进制文件

适用于 Linux 的 `ProFTPD` 预编译二进制发行版可从 `ftp://ftp.proftpd.net/pub/proftpd` 获得。撰写本文时的最新版本是 `proftpd-1.2.0pre10`。请注意，这些是开发版本；稳定版本尚未发布。

要在一台支持 Red Hat 软件包文件的 Intel 架构机器上安装独立版本，请下载 `proftpd-core-1.2.0pre10-1.i686.rpm` 和 `proftpd-standalone-1.2.0pre10-1.i686.rpm`，然后运行以下命令：

```bash
# rpm -i proftpd-core-1.2.0pre10-1.i686.rpm
# rpm -i proftpd-standalone-1.2.0pre10-1.i686.rpm
```

如果要改为安装 `inetd` 版本，请下载 `proftpd-core-1.2.0pre10-1.i686.rpm` 和 `proftpd-inetd-1.2.0pre10-1.i686.rpm`，然后运行以下命令：

```bash
# rpm -i proftpd-core-1.2.0pre10-1.i686.rpm
# rpm --install proftpd-inetd-1.2.0pre10-1.i686.rpm
```

`ProFTPD` RPM 软件包会安装以下文件：

- `/usr/sbin/proftpd`
- `/usr/sbin/ftpshut`
- `/usr/bin/ftpwho`
- `/usr/bin/ftpcount`
- 一个指向 `/usr/sbin/proftpd` 的符号链接 `/usr/sbin/in.proftpd`

此外，一个默认配置文件 `proftpd.conf` 被放置在 `/etc` 目录中。

`ProFTPD` `inetd` 版本的 RPM 安装会编辑 `/etc/inetd.conf` 文件，并向 `inetd` 发送 `SIGHUP` 信号。它会添加一个条目，以便在检测到对端口 21 的连接尝试时启动 `proftpd`。

`ProFTPD` `standalone` 版本的 RPM 安装也会编辑 `/etc/inetd.conf` 文件，以移除对 FTP 守护进程的任何调用，并向 `inetd` 发送 `SIGHUP` 信号。此外，它会在 `/etc/rc.d/init.d` 目录中放置一个名为 `proftpd` 的启动脚本。独立版本安装完成后，可以通过执行以下命令启动 `ProFTPD`：

```
# /etc/rc.d/init.d/proftpd start
```

### 从源代码构建

从源代码构建 `ProFTPD` 相当简单。将 `ProFTPD` 源代码归档文件 `proftpd-1.2.0pre10.tar.gz` 下载到合适的目录，例如 `/usr/local/src`。按如下方式解包：

```
# cd /usr/local/src
# tar xzf proftpd-1.2.0pre10.tar.gz
```

这将创建一个名为 `proftpd-1.2.0pre10` 的目录。将当前目录更改为该目录，并按如下方式运行 `configure`：

```
# cd proftpd-1.2.0pre10
# ./configure --prefix=/usr
```

`configure` 脚本执行后，将创建一个顶层 `makefile` 和 `modules` 子目录中的 `makefile`。现在运行 `make` 来构建可执行文件：

```
# make
```

这将创建 `proftpd` 守护进程和三个实用程序：`ftpwho`、`ftpcount` 和 `ftpshut`。

现在安装二进制文件：

```
# make install
```
