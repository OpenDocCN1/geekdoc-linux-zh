
```sql
mysql> SELECT person,password,executeparm
-> FROM people
```

### 先决条件

安装以下软件包：

- `mysql-client`
- `mysql-server`

安装`mysql-server`软件包时，`dpkg postinst`脚本会显示一个伪图形窗口，要求您为名为`root`的MySQL用户提供密码。此用户不是系统`root`用户。请提供一个密码。

根据需要发出以下`initctl`命令（第434页）以重启MySQL：

```bash
$ sudo restart mysql
mysql start/running, process 3433
```

### 备注

与Oracle不同，创建用户时，MySQL不会自动创建数据库。在MySQL中，用户和数据库不像在Oracle中那样紧密结合。

MySQL拥有一套独立于Linux用户的用户集合。在安装完成后，MySQL管理员的名称为`root`。由于MySQL`root`用户与Linux`root`用户不同，因此它可以拥有不同的密码。

## 选项

本节描述了可以在`mysql`命令行中使用的部分选项。由单个连字符开头和由两个连字符开头的选项是等效的。

- `--disable-reconnect`

  如果连接断开，则不尝试重新连接到服务器。参见`--reconnect`。

- `--host=`*hostname*  `-h` *hostname*

  将*hostname*指定为MySQL服务器的地址。如果没有此选项，MySQL将连接到本地系统（127.0.0.1）上的服务器。

- `--password[=`*passwd*`*]`

  `-p[*passwd*`*]`

  将*passwd*指定为MySQL密码。为了提高安全性，请勿在命令行上指定密码；MySQL会提示输入密码。默认情况下，MySQL不使用密码。在此选项的短形式中，请勿在`-p`和*passwd*之间留出空格。

- `--reconnect`

  如果连接断开，尝试重新连接到服务器（默认值）。使用`--disable-reconnect`禁用此行为。

- `--user=`*usr*  `-u` *usr*

  将*usr*指定为MySQL用户。初次安装MySQL时，有一个用户`root`，该用户没有密码。

- `--verbose`  `-v`

  增加MySQL显示的信息量。多次使用此选项可进一步提高详细程度。

## .MY.CNF 配置文件

您可以使用`~/.my.cnf`文件来设置MySQL选项。以下示例显示了Max的`~/.my.cnf`文件。`[mysql]`指定了MySQL组。下一行将Max的密码设置为`mpassword`。有了此设置，Max就不必在命令行上使用`-p`；MySQL会自动登录他。

```
$ cat /home/max/\.my.cnf
[mysql]
password="mpassword"
```

## 使用 MYSQL

### 添加用户

在开始处理数据库之前，请创建一个用户，这样您就不必以MySQL`root`用户身份进行操作。如果添加的MySQL用户名与您的Linux用户名相同，则无需在MySQL命令行上指定用户名。在下面的示例中，Max以MySQL`root`（`-u` `root`）用户身份工作，创建一个名为`maxdb`的数据库，并添加名为`max`的MySQL用户，其密码为`mpassword`。作为对`Enter password`（输入密码）提示的响应，Max提供了名为`root`的MySQL用户的密码。`GRANT`语句授予了Max处理`maxdb`数据库所需的权限。您必须以MySQL`root`用户身份操作才能设置MySQL用户。`-p`选项会导致MySQL提示输入密码。

使用MySQL解释器时，`Query OK`表示前面的语句在语法上是正确的。您必须将所有字符和日期数据包含在单引号内。

```
$ mysql -u root -p
Enter password:
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 12
Server version: 5.1.40 Source distribution

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql> CREATE DATABASE maxdb;
Query OK, 1 row affected (0.00 sec)

mysql> GRANT ALL PRIVILEGES
    -> ON maxdb.* to 'max'
    -> IDENTIFIED BY 'password'
    -> WITH GRANT OPTION;
Query OK, 0 rows affected (0.00 sec)

mysql> SELECT user, password
    -> FROM mysql.user;

+--------------------+-------------------------------------------+
| user               | password                                  |
+--------------------+-------------------------------------------+
| root               | *96D4C5B9348F896B0B593E4ADC1B653156799FDD |
| max                | *34432555D06C778C7C4B40EE4551425CE3AC0E16 |
| debian-sys-maint   | *E41C0008AE5D3C42D15447ABC53308E62505ADF1 |
+--------------------+-------------------------------------------+
3 rows in set (0.00 sec)

mysql> quit
Bye
$
```

在上述示例中，创建数据库并设置新用户后，Max查询`mysql`数据库的用户表以显示`user`和`password`列。现在存在两个用户：`root`和`max`。Max输入命令`quit`以退出MySQL解释器。

以MySQL用户`max`身份操作，Max现在可以设置一个简单的数据库来跟踪用户。他不需要在命令行上使用`-u`选项，因为他的Linux用户名和他的MySQL用户名是相同的。

### 指定默认数据库

对于后续命令，如果不告诉MySQL您正在使用哪个数据库，则必须在表名前添加数据库名称作为前缀。例如，您需要将`maxdb`数据库中的`people`表指定为`maxdb.people`。当您使用`USE`语句指定`maxdb`数据库时，您可以将同一表引用为`people`。在下面的示例中，Max指定`maxdb`为他正在使用的数据库：

```
mysql> USE maxdb;
Database changed
```

接下来，Max在`maxdb`数据库中创建一个名为`people`的表。该表具有六种不同类型的列。创建表后，Max使用`DESCRIBE`语句显示表的描述。

```
mysql> CREATE TABLE people ( person VARCHAR(20), password CHAR(41),
-> created DATE, readperm BOOL, writeperm BOOL, executeperm BOOL );
Query OK, 0 rows affected (0.01 sec)
```

```
mysql> DESCRIBE people;

+-------------+-----------+------+-----+---------+-------+
| Field | Type | Null | Key | Default | Extra |
+-------------+-----------+------+-----+---------+-------+
| person | varchar(20) | YES | | NULL | |
| password | char(41) | YES | | NULL | |
| created | date | YES | | NULL | |
| readperm | tinyint(1) | YES | | NULL | |
| writeperm | tinyint(1) | YES | | NULL | |
| executeperm | tinyint(1) | YES | | NULL | |
+-------------+-----------+------+-----+---------+-------+
6 rows in set (0.00 sec)
```

MySQL将Max指定的`BOOL`（布尔值）列更改为类型`tinyint(1)`，即8位整数，因为MySQL没有原生（位）布尔支持。对于`tinyint(1)`，`0`评估为`FALSE`，`1–255`评估为`TRUE`。**图 16-6**显示了输入数据后`people`表的一部分。

Max决定`readperm`、`writeperm`和`executeperm`列的默认值应为`0`。他使用`ALTER TABLE`语句修改表，这样他就不必删除表并重新开始。然后他使用`DESCRIBE`语句检查其工作结果。

### 输入数据

您可以使用几种技术将信息输入到数据库中。以下命令从Linux文本文件中向`maxdb`添加三行。在文件中，每行位于单独的一行上，制表符将每个列与下一个列分隔开，`\VN`指定一个空字符。该文件末尾没有换行符。

```
$ cat /home/max/people_to_add$
max     \V        2008-02-17        1         1         1
zach    \V        2009-03-24        1         1         0
sam     \V        2009-01-28        1         0         0

mysql> LOAD DATA LOCAL INFILE '/home/max/people_to_add'
    -> INTO TABLE people;
Query OK, 3 rows affected (0.00 sec)
Records: 3  Deleted: 0  Skipped: 0  Warnings: 0
```

下一条命令使用`INSERT`语句添加一行：

```
mysql> INSERT INTO people
    -> VALUES ('topsy', NULL, CURDATE(),1,1,1);
Query OK, 1 row affected (0.01 sec)
```

在`INSERT`语句中，您可以指定要输入数据的列：

```
mysql> INSERT INTO people (person,created,readperm)
    -> VALUES ('bailey',CURDATE(),1), ('percy',CURDATE(),0);
Query OK, 2 rows affected (0.01 sec)
Records: 2  Duplicates: 0  Warnings: 0

mysql> SELECT * FROM people;
```

|---|---|---|---|---|---|
| `max` | `NULL` | `2008-02-17` | `1` | `1` | `1` |
| `zach` | `NULL` | `2009-03-24` | `1` | `1` | `0` |
| `sam` | `NULL` | `2009-01-28` | `1` | `0` | `0` |
| `topsy` | `NULL` | `2010-03-05` | `1` | `1` | `1` |

| `percy` | `NULL` | `2010-03-05` | `0` | `0` | `0` |

`CURDATE()`函数返回今天的日期。由于`readperm`、`writeperm`和`executeperm`的默认值为`0`，因此您不必为这些字段指定值。

接下来，一条`DELETE FROM`语句将删除满足指定条件的行。在此处，条件是通过`WHERE`子句中的等式指定的：

```
mysql> DELETE FROM people
     -> WHERE person='bailey' OR person='percy';
Query OK, 2 rows affected (0.02 sec)
```

您也可以使用`LIKE`子句来指定条件。以下`SELECT`语句显示包含字母`m`的所有行。`%`运算符是通配符；它们匹配任意字符。

```
mysql> SELECT * FROM people
     -> WHERE person LIKE '%m%';
```
