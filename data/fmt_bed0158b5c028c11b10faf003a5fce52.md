# 使用 ulimit 解决问题排除

当尝试用 `ulimit` 增加进程文件限制时，会返回以下错误：

```bash
bash: ulimit: cannot modify limit: Operation not permitted
```

系统对非 `root` 用户修改核心文件的 `ulimit` 有限制锁定。当非具有超级用户权限的用户 ID 尝试增加文件大时，就会发生此错误。解决方法是使用 `su` 切换到 `root` 并获取超级用户权限，或者让 `root`
